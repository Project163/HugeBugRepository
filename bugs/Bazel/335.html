Title

Building 0.4.2 for SDK7 from source: "BUILD file not found on package path."

Description
Please provide the following information. The more we know about your system and use case, the more easily and likely we can help.

### Description of the problem / feature request / question:

When building bazel from source from bazel-0.4.2-jdk7-dist.zip, the build fails with the following error:

    ERROR: no such package '@bazel_tools//tools/jdk': BUILD file not found on package path.

### If possible, provide a minimal example to reproduce the problem:

It should be possible to reproduce this by just running "./compile.sh" from the root of the distribution tree.
