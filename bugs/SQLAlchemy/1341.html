Title

column warning emits during sync_session auto check

Description
this while editing the PGValues wiki entry:

```
py
from sqlalchemy import Column
from sqlalchemy import create_engine
from sqlalchemy import Integer
from sqlalchemy import MetaData
... [Log Snipped] ...
    {"mytext": t2.c.mytext, "myint": t2.c.myint},
)
```

this warning was added in   for #4073 and as we can see in the above example, it's just wrong; the names of the cols match here but they are not the correct cols to be "evaluated".  so this needs to all just be "unevaluable" and that's it.

