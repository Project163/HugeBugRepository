- In  PartitionUpdate ,  isBuilt  is non-volatile, and it is set once the  Holder  ref has been updated.  build()  is synchronized but  maybeBuild()  where we check  isBuilt  is not. That means this is basically double checked locking, but since  isBuilt  is not volatile, the assignments in  build()  can be reordered, making  isBuilt  true before  holder  is assigned. 

 It stops reproducing if I set  isBuilt = this.holder != null  instead of  isBuilt = true  to make sure that  holder  is set before  isBuilt  but making  isBuilt  volatile should be the correct solution.
