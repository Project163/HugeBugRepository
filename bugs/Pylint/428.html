Title

Pylint crashes for ``pyproject.toml`` configuration mixed with another tool

Description
I have 
```toml
[tool.pylint.MASTER]
load-plugins = "pylint_websockets"
```

With Pylint failing with

```
AttributeError: 'str' object has no attribute 'items'
```

_Originally posted by @ThatXliner in [URL]
Discussion
- In my case, my Pylint config was in the middle of another config. The red is the Pylint config and the green is the other tool's config:

```diff

+ [tool.poe.tasks]
+ docs = {cmd = "sphinx-build docs build", help = "Build documentation"}
- [tool.pylint.MASTER]
- load-plugins = 'pylint_websockets'
+ format = ["black", "isort"]
```
- This does not crash anymore following the implementation of #4583
