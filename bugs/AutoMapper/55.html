Title

string -> int? conversion returning 0 rather than null

Description
We have a situation where we're mapping between two objects, and the source object has a particular property as a string, but the destination uses a nullable int:

```
public class Model
{
	public string Max { get; set; }
}

... [Log Snipped] ...
	public int? Max { get; set; }
}
```

When we're mapping from a null string value, it's returning 0 instead of null. Here's a test that recreates the issue:

```
[Test]
public void Map_ReturnsNullIntForNullString()
{
	// Arrange
	var mapperConfig = new MapperConfiguration(cfg => cfg.CreateMap ());
... [Log Snipped] ...
	Assert.IsNull(dto.Max);
}
```

I've tested this against 5.2.0-alpha-01245 and the issue still exists.
