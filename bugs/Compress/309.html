Title

Discussion
- Is there any chance you can use  ZipFile  instead of  ZipArchiveInputStream ? 

 The file contains some sort of header that  unzip  skips over and  ZipArchiveInputStream  will not do that. The way  ZipFile  works should help with this. An alternative is to first scan your input stream until you hit the real archive (like a sequence of 0x50 0x4b 0x03 0x04 and hand over the stream positioned at these bytes.
- Yes skipping the first 566 bytes in the input stream fixed this issue for this file.
