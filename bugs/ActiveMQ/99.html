Title

Not all properties of the Message are copied during a call to Message.copy(Message)

Description
Noticed that when using copyOnSend feature and compression, sent messages were not being compressed. It was then found that this was due to the fact that the connection that is used to determine whether compression should be performed or not, was null for the copied message. A look into the Message found that the connection and a number of other properties of the Message were not copied in the copy(Message)  

 The patch attached copies the remaining properties of the Message to the message copy.
