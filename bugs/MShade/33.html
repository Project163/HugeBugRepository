Title

META-INF/services files not merged properly if some input files are missing a terminating newline

Description
This issue came up with use of the shade plugin with GeoTools where many of the SPI files were missing a terminating newline. The resulting merged file would contain a line with the last entry from an offending input file concatenated with the first entry of the next file.
