Title

Enclosures rendered twice in derived component

Description
Minimal changes to the Quickstart causes it: 

 Add this to the HomePage: 
   HomePage.html   
 <p wicket:enclosure= "version" >
    Please mention the correct Wicket version: <wicket:container wicket:id= "version" >1.5-SNAPSHOT</wicket:container>.
</p>
<wicket:child/>
 
  

 And then a new derived page: 

   NewPage.java   
  public   class  NewPage  extends  HomePage {
     public  NewPage(PageParameters parameters) {
         super (parameters);

        add( new  Label( "id" ,  "test" ));
    }
}
 
  
   NewPage.html   
 <wicket:extend xmlns:wicket= "http: //wicket.apache.org" >
     <div wicket:enclosure= "id" >
        xxx
        <wicket:container wicket:id= "id" ></wicket:container>
    </div>
</wicket:extend>

Discussion
- Attached quickstart with unit test
- Quick investigation reveals that this is caused by two  InlineEnclosure  s in the same scope. It looks like the internal counter in  InlineEnclosureHandler  is being reset for the derived component, however they share the same scope. A temporary fix that worked for me was to specify a  wicket:id  for all enclosures in the derived markup like so: 

  
  <div wicket:enclosure= "child"  wicket:id= "enclosure-id" >
