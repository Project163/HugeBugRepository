Title

Bake fails to create correct links for associated data with aliased tables

Description
Given a model with an association like:

```
$this->belongsTo('Creators', [
    'className' => 'Users',
    'foreignKey' => 'creator_id'
]);
```

`cake bake view Users` created views with links like that:

```
 has('creator') ? $this->Html->link($user->creator->username, ['controller' => 'Creators', 'action' => 'view', $user->creator->id]) : '' ?>
```

As the `className` in the model suggests, I would expect it to bake links for the `users` controller instead:

```
 has('creator') ? $this->Html->link($user->creator->username, ['controller' => 'Users', 'action' => 'view', $user->creator->id]) : '' ?>
```
