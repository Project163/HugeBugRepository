Description

 There is an initial  SSLProtocolException  from the protocol error:

 error:10000416:SSL routines:OPENSSL_internal:SSLV3_ALERT_CERTIFICATE_UNKNOWN (external/boringssl/src/ssl/tls_record.cc:579  : )
