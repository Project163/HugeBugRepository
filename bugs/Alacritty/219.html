Title

On aarch64, crash on suspend/sleep since glutin 0.27 bump

Description
Since the bump to glutin 0.27, on my aarch64 laptop (Lenovo C630), when I suspend the desktop, or it goes to sleep, alacritty crashes.  Forcing the glutin dependency back down to 0.26, and the crash no longer occurs.  I'm assuming this is probably something that should go to the glutin repo, but I figured I would report it here.


### System

OS: Linux (aarch64)
Version: 0.10.0-dev (7913aa55)
Linux/BSD: X11, Budgie WM
