Title

panic: runtime error: index out of range [-1]

Description
### What happened?

After some facepalm changes in the `.stignore` file, and then moving files into an ignored folder, and then realizing they would just be removed on other systems, reverting this, reverting that again, and more file-moving, I started receiving this error right after startup with no indication what might be the problem.

It started with v1.28.0, so I tried the new RC, but no difference.

It may not be related with the aforementioned file-moving. There's nothing in the logs that may indicate a source of the problem.

This happens _after_ the Completed initial scan of the aforementioned folder.

Discussion
- So the moving around probably did confuse something, and it triggers a debug log that tries to describe an index inconsistency, but there is a bug so it crashes when doing that. 🤦  I'll push a fix for that shortly. You can probably work around the problem in the meantime by starting Syncthing from the command line once with `syncthing serve --reset-deltas` to force an index refresh. If that doesn't work, removing the folder and re-adding it would probably fix it.
- The index refresh did the trick. Thank you for such a quick workaround and fix 🙏🙏
