Title

OSGi specs should be used with scope provided

Description
Currently the OSGi spec jars are listed with default scope. So they are also added to the project using connect. When the default scanner is used this results in running the specs as bundles which is not recommended in OSGi. 

 The specs should not be necessary as they are already embeded during the build. 

 I will create a PR for the fix.
