Title

MediaItem.Subtitle is missing some text-related fields.

Description
### [REQUIRED] Issue description
2.12 changed the setup of `SingleSampleMediaSource` to always use a `MediaItem.Subtitle` instead of a `Format` object to define the properties of the single sample track. This removed the possibility to set any `Format` values that are not part of the `MediaItem.Subtitle` config. 

The following values are potentially text-related but can't be set anymore:
 - `Format.label`
 - `Format.roleFlags`
 - `Format.accessibilityChannel`

### [REQUIRED] Reproduction steps
Build a `SingleSampleMediaSource` with 2.11.0 and 2.12.0. Try to set `Format.label` or other values mentioned above.
