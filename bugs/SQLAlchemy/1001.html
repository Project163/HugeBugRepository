Title

Another exception raised during fetch interruption

Description
**Describe the bug**

`During handling of the above exception, another exception occurred` happens on `KeyboardInterrupt` during fetch

**Expected behavior**

No nested throw

**To Reproduce**

Query large amount of rows and hit `Ctrl+C`

```py
q = session.query(MyTable.id).yield_per(1024)
for table_id in q:
    pass 
```

**Error**

```
Traceback (most recent call last):
  File " /venv/lib/python3.8/site-packages/sqlalchemy/engine/cursor.py", line 1093, in fetchmany
    buf.extend(dbapi_cursor.fetchmany(size - lb))
KeyboardInterrupt

... [Log Snipped] ...
    self.handle_exception(result, e)
TypeError: handle_exception() missing 1 required positional argument: 'err'
```

**Versions.**
 - OS: Ubuntu 20.04
 - Python: 3.8.2
 - SQLAlchemy: 1.4.0b1.dev0
 - Database: 
 - DBAPI: postgresql+psycopg2
