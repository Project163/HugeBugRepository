Title

Support templated union types

Description
Union types for callable template params only infer the first type.

Template `T` should be inferred as `int|false`, but it's inferred as `int`.

Example (https://psalm.dev/r/b94061e018):
```
php
 , array{0:int|false} provided
```
Discussion
- Templated unions are not supported atm - you can work around this for the moment with `@param scalar $x`
- Good to know, and thanks for the hint about `scalar`. Some more complex types still require `mixed`, but it's a good idea for the example.

- Realising that it prevented `ArrayObject ` (which is necessary to allow `$a[] = "hello"`)
