Title

Exception when using datetime-formatting of log_time

Description
I'm logging errors using Yii/log/DbTarget with the default migration for mysql.
Then I use yii\widgets\DetailView to display the log, and added a datetime-formatter to the attribute log_time, like this:

```
'log_time:datetime',
```

This causes errors occasionally like this...

```
exception 'Exception' with message 'DateTime::__construct(): Failed to parse time string (@1477307739.608) at position 12 (6): Unexpected character' in C:\...\vendor\yiisoft\yii2\i18n\Formatter.php:675
Stack trace:
#0 C:\...\vendor\yiisoft\yii2\i18n\Formatter.php(675): DateTime->__construct('@1477307739.608', Object(DateTimeZone))
#1 C:\...\vendor\yiisoft\yii2\i18n\Formatter.php(594): yii\i18n\Formatter->normalizeDatetimeValue(' formatDateTimeValue(' asDatetime('
    
Discussion

    
- Is it valid for `DateTime` to use timestamp with microseconds at all? According to [Link: docs] the regex for this is

```
"@" "-"? [0-9]+
```
- Added fix to that behavior, actualy DateTime doesn't store milliseconds, so we can ommit them silently
