Title

Allow multiple subcodes in a SOAP 1.2 fault

Description
Currently CXF only allows one subcode to be set via in a  SoapFault  object, but the SOAP 1.2 spec allows nested subcodes like so: 

  
  <soap:Envelope  xmlns:soap = "[URL]
   <soap:Body> 
     <soap:Fault> 
       <soap:Code> 
         <soap:Value> soap:Receiver </soap:Value> 
         <soap:Subcode> 
           <soap:Value  xmlns:ns1 = "[URL] class="code-tag"></soap:Value> 
           <soap:Subcode> 
             <soap:Value  xmlns:ns1 = "[URL] class="code-tag"></soap:Value> 
           </soap:Subcode> 
         </soap:Subcode> 
       </soap:Code> 
       <soap:Reason> 
         <soap:Text xml:lang= "en" > Error by Failure </soap:Text> 
       </soap:Reason> 
     </soap:Fault> 
   </soap:Body> 
 </soap:Envelope>
