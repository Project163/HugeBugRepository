## Current behavior
When I run ngc on my library, it generates `.metadata.json` files even for files that have no exports (previously with 4.x no metadata files were generated for such files). The content of the metadata file is just `[null]`. This causes AoT compilation (with `@ngtools/webpack`/`@angular/cli`) to throw an error:
