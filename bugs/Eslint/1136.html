Eslint --fix is breaking code with ".bind(this, variable)".

Description

Windows 10
* **ESLint Version:**  v3.19.0
* **Node Version:** v6.10.2
* **npm Version:** 4.5.0

default

```
  "parser": "babel-eslint",

    "airbnb"

  }
}
```


**What did you do? Please include the actual source code causing the issue.**

I was converting some ES5 code to ES6 and `eslint --fix` broke some code. Here is a small example:

 
```
js
let queue = require('d3-queue').queue
const attrName = 'hi';

let q = queue()
... [Log Snipped] ...

}.bind(this, attrName));
```

**What did you expect to happen?**
I expected the code to stay as valid Javascript. Here is one valid transformation:
```
js
const queue = require('d3-queue').queue;
const attrName = 'hi';

const q = queue();
... [Log Snipped] ...

}).bind(this, attrName)); // This line is now valid because of the added parens.
```

**What actually happened? Please include the actual, raw output from ESLint.**

```
js
const queue = require('d3-queue').queue;
const attrName = 'hi';

const q = queue();
... [Log Snipped] ...

}.bind(this, attrName)); // This line is now invalid because the function has been transformed into an arrow function. This now gives an Error: 10,2: Parsing error: Unexpected token, expected ,
```
