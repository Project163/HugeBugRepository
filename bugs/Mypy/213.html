Title

**args type checking problem with bare asterisk

Description
The following code is rejected by the type checker, even though it should be valid:

```
def f(a, *, b=None) -> None: pass
a = None # type: Any
b = None # type: Any
f(a, **b)   # "Too many positional arguments"
```
Discussion

- I've seen way too many occurrences of this. Let's fix it!

```

+ actual_kinds[formal_to_actual[i][0]] not in [nodes.ARG_NAMED, nodes.ARG_STAR2]):
```

Is the right fix. (It fixes the two examples)
