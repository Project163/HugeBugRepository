Title

Duplicate values in unique index of primary key column do not raise error

Description
When a unique index is created on a non-primary-key column, duplicate-value error is raised when duplicate values are inserted into the column.

```
cqlsh:k> create table t (h int, r int, v int, primary key ((h), r)) with transactions = {'enabled' : true};
cqlsh:k> create unique index t_by_v on t (v);
cqlsh:k> insert into t (h, r, v) values (1, 1, 1);
cqlsh:k> insert into t (h, r, v) values (1, 2, 1);
InvalidRequest: Error from server: code=2200 [Invalid query] message="SQL error: Execution Error. Duplicate value disallowed by unique index k.t_by_v
... [Log Snipped] ...
---+---+---
 1 | 1 | 1
```

In the uncommon case, when a unique index is created on a primary key column of a table instead, no duplicate-value error is raised:

```
cqlsh:k> create unique index t_by_r on t (r);
cqlsh:k> insert into t (h, r, v) values (2, 1, 2);
cqlsh:k> select * from t;
 h | r | v
---+---+---
... [Log Snipped] ...
---
 2
```

The common case of unique index on non-primary-key columns works fine and is unaffected by this issue.
