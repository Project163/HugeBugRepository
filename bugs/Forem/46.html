Title

& in Org Name

Description
**Describe the bug**

When creating an org, if a user puts an ampersand (`&`) in the title of their org, it's shown as `&`.

Here's an image:

[Image: [URL]

**Expected behavior**

The ampersand should show up as normal.
Discussion
- Here's the test org I created - [URL] ... happy to delete whenever.
- Well, I think the culprit is here [URL]

According to issue [Link: 28060 on the rails project], strip_tags since v1.0.3 encodes special html characters (&,   ...) by default. To restore its previous behaviour, we can use Loofa directly:

```
Loofah.fragment(value).text(encode_special_chars: false)
``` 

 **This solution, however, does *NOT* fix existing organizations.** 

Another way to fix this would be to mark the fields in the view ``app/views/users/_profile_header.html.erb`` as ``raw`` or ``html_safe``. This solution DOES fix existing organizations, but it won't scale well: we would have to mark every existing field that accepts & (and any new ones we might add in the future) as ``raw`` before displaying it.

I'd love to make a pull request to fix this issue later today, but I want to make sure these solutions don't introduce a sneaky security bug.
