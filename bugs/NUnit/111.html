Title

Classname for inherited test is not correct

Description
I'm creating this issue to correspond to PR #1365, which was intended to fix it. The PR aims to resolve nunit/nunit3-vs-adapter#133 but the corresponding issue in NUnit has not yet been confirmed.

Since classname was added solely for the purpose of determining the location of each test in the source code, it should reflect the class where that code is located, not the class of the fixture we are working with, which may be based on a  derived class.

The name is currently taken from the TypeInfo stored with the MethodWrapper. That TypeInfo relates to the class of the fixture we are working with. It was added in support of platforms where ReflectedType is not available. All considered, this is a bit complicated. We want to change classname but we don't want to break anything else that depends on the TypeInfo.

First step should be to confirm the problem.
