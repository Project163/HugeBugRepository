Title

3.3 Regression: Streamed request bodys are broken

Description
With 3.3.3 and the new middleware streamed bodys seems to be broken, throwing a `RuntimeException` with "**Callback streams cannot rewind position**"

Code:

```
php
$this->response->type('png');
$this->response->body(function () use ($imageClipped) {
    imagepng($imageClipped);
});
... [Log Snipped] ...
$this->response->body(ob_get_clean());*/
return $this->response;
```

This code worked before 3.3 but is now broken. The commented code is a easy work-around, but for me this looks like a regression. My app was updated from 3.2 using the code from the app-template.
