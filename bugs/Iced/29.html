`Toggler` has right padding (a.k.a. spacing) even when no label is present.

### What happened?

The `Toggler` widget has right-padding even when no label is used.

[Image: Image]

I wanted the label on the left, so I created a row like this:

```rust
let row = row![
    container(text("Ch. Link:")),
    toggler(...).on_toggle(...)
].spacing(10);
```

In the screenshot, you can see that there is some padding to the right - spacing for when there is a label present.

I can override this by selecting `Toggler::spacing(0)`, which fixes the problem, but I would expect spacing to be 0 by default when no label is present.

### What is the expected behavior?

When no label has been associated with the `Toggler` via the builder methods, I would expect there to be no right-padding.
