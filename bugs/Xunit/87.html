Title

AllException.Message will crash when an object is null

Description
The issue is encountered when intermixing `Assert.All` and `Assert.NotNull`

Repro:

```
git clone [URL]
```

Rather than inform me why my test fails, VSRunner will produce an error.  The actual test will always appear to not have run.

Showing output from tests:

```
------ Run test started ------
[xUnit.net 00:00:00.1633259]   Starting:    XunitAssertNullRef
[xUnit.net 00:00:00.2909625]   Finished:    XunitAssertNullRef
System.NullReferenceException: Object reference not set to an instance of an object.
   at Xunit.Sdk.AllException.<>c. b__6_0(Tuple`3 error)
... [Log Snipped] ...
   at System.Threading._ThreadPoolWaitCallback.PerformWaitCallback()
========== Run test finished: 0 run (0:00:00.3248127) ==========
```
Discussion
- In `AllException`, I believe `Item2` is the object that was tested by `Assert.All`.  If that object is null then this won't go well.

```cs
return string.Format(CultureInfo.CurrentCulture,
    "{0}Item: {1}{2}{3}",
    indexString,
    error.Item2.ToString().Replace(Environment.NewLine, spaces),
    spaces,
    error.Item3.ToString().Replace(Environment.NewLine, spaces));
```
