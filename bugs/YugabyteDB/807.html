Title

[YSQL] Premature return in PG_TRY block in relcache.c

Description
Jira Link: [Link: DB-4444]
### Description

We return from that function within a try block [Link: here] before we hit PG_END_TRY()  where we’d restore the previous jump buffer, mistakenly leaving PG_exception_stack  with a bad jump buffer pointer.

Through tracing through the debugger we can see that `PG_exception_stack` changes in value before and after this PG_TRY block.
