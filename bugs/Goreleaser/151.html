Title

Linux packages (via nFPM) doc still contains nFPM v1 properties

Description
### What happened?

I am looking at [Link: Linux packages (via nFPM) document], in the `available options` section, there are:
```
# Some attributes can be overridden per package format.
 overrides:
...
   rpm:
     replacements:
... [Log Snipped] ...
       "tmp/man.gz": "/usr/share/man/man8/app.8.gz"
...
```
The point is that `files` configuration property was part of nFPM v1 and with the migration to nFPM v2, it's not supported any more. I am not sure whether there is a replacement or it just has to be removed.

### How can we reproduce this?

It's a documentation issue and there are no steps to reproduce.
