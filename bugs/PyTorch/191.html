Title

INTERNAL ASSERT FAILED in mse_loss when mixing CPU and CUDA tensors

Description
### 🐛 Describe the bug

Calling nn.MSELoss() with a mix of CUDA and CPU tensors leads to an internal assert failure inside PyTorch's CUDA backend instead of a standard Python RuntimeError.
