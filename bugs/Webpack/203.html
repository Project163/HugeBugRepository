Title

innerGraph incorrectly marking function as unused resulting in broken build

Description
# Bug report

 
 
 
 

**What is the current behavior?**

Using the default optimizations for production is causing used functions to be marked as unused. I have pinned it down to the option `innerGraph`, setting this option to false seems to fix it.

**If the current behavior is a bug, please provide the steps to reproduce.**

See the reproduction repository: [URL]

Reproduction steps:

1. yarn build
2. yarn run

 
 
 
 
 
 

**What is the expected behavior?**

Expected behaviour is that the `O.if` is working in the production build, currently it isn't because the underlying export is marked as unused.

 
 

**Other relevant information:**
webpack version:  5.21.2
Node.js version: 14.10.1
Operating System: Arch Linux
Additional tools: N/A
