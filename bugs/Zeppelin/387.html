Title

Re-order Zeppelin-web karma.conf

Description
If you do a build from a clean repository, karma-conf will be modified to re-shuffled alphabetically (like it is supposed to be) the order of the dependencies. 

 Since it isn't a code modification we want after build, we should change the un-ordered dependency and commit it to the source code.
