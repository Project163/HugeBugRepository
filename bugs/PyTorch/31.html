Title

`torch.set_default_dtype` will crash with `complex` dtype

Description
### 🐛 Describe the bug

`torch.set_default_dtype` will crash with `complex` dtype

```python
import torch
d = torch.complex64
torch.set_default_dtype(d)
# segmentation fault
```

### Versions

pytorch: 1.10.1
