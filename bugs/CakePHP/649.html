Title

SQL Error when paginating results from query with $query->bind

Description
I have following query object which returns data as it should:

```
php
$query = $this->Users
    ->find()
    ->contain( $this->getAssociations() )
    ->matching('TableB.TableC', function($q) {
... [Log Snipped] ...
    ->bind(':end', new \DateTime(date('Y-m-t')), 'date')
    ->distinct(['Users.id']);
```

I got associated data exactly as I wanted it to be but when I give it to paginator it fails to select count for results:

``` php
$this->set('data', $this->paginate($query));
$this->set('_serialize', ['data']);
```

It gives following SQL error:

```
Error: SQLSTATE[HY093]: Invalid parameter number: no parameters were bound
SQL Query:
SELECT (COUNT(*)) AS `count` FROM (SELECT Users.id ...
```

Without parameter bindings in query it works without any problems.
Only thing that fails is counting through paginate, it seems that paginate does not bind parameters to underlying PDO statement.
