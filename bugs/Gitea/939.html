Title

When official review is deleted, previous review should become official

Description
### Description

As stated [Link: here], only reviewers latest review of type approve and reject shall count as "official". So when submitting a new "official" review, the "official" status of existing reviews of that user are cleared.

However, when deleting a review (currently only possible through the API), the "official" status of the previous approval/rejection of that user is never restored.

1.18.0
