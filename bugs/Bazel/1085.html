Title

HOME is not set in tests

Description
### Description of the problem:

When running a test, bazel uses:
```sh
env - KEY=VALUE ... external/bazel_tools/tools/test/test-setup.sh test+parameters
```

to run the test.  `test-setup.sh` does set `HOME` but does not export it:

[URL]
  
And so the tests run without `HOME` set.
