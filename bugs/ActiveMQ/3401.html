Title

Default maven build does not build all modules

Description
There are some optional modules defined under the profile "full.test". These modules need to be added by default back to the normal build so they are compiled and installed as there are dependencies on them for other modules. The tests can be skipped by default but the actual modules need to still always be built. This is a problem as now version 5.18 fails to build without old snapshots plus it means all of the testing in CI is using stale snapshots.
