## Current behavior
 
When attempting to use a translated xliff file containing segmentation tags I get the error message
`Unexpected tag ("[ERROR ->] OK "): i18n@0:0`

## Expected behavior
 
The inner xml of these tags should be returned. 

## Minimal reproduction of the problem with instructions
 
An example of translation file containing this kind of tag is
```
xml
```
