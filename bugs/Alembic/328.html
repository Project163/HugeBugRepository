Title

Lint with attempts to fix using "ruff" does not work from scratch provided in alembic.ini

Description
**Describe the bug**
Creating migration with turned on linting with attempts to fix using "ruff", provided in alembic.ini, does not work from scratch. Migration is created, but linting attempt fail with error.

**Expected behavior**
Linting step should not fail with error.

**To Reproduce**

1. Setup environment

```console
python3 -m venv .venv
source .venv/bin/activate
pip install alembic ruff
alembic init alembic
```

2. Uncomment linting by ruff rows in `alembic.ini`:

```py
# lint with attempts to fix using "ruff" - use the exec runner, execute a binary
hooks = ruff
ruff.type = exec
ruff.executable = %(here)s/.venv/bin/ruff
ruff.options = --fix REVISION_SCRIPT_FILENAME
```

3. Make revision:

```console
alembic revision -m "Initial"
```

**Error**

```
  Generating /home/rishat/Desktop/mre/alembic/versions/720731c267cb_initial.py ...  done
  Running post write hook 'ruff' ...
error: unexpected argument '--fix' found

Usage: ruff [OPTIONS]  

For more information, try '--help'.
  done
```

**Versions.**
 - OS: Ubuntu 24.04
 - Python: 3.12
 - Alembic: 1.14.1
 - Ruff: 0.9.9
