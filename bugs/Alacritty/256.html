Title

Crash during live search

Description
Alacritty will crash if you do the following from the repo:

1. `cargo run -- --config-file=/dev/null`
2. `cat -v /dev/urandom`
3. Start a search `Ctrl + Shift + F`.
4. Type `.` into it, so all characters will match
5. Do a fast resize to make it 1 cell width o closer.
