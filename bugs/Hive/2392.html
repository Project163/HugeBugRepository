Title

Fix eclipse:eclipse after HIVE-7496

Description
HIVE-7496   removes "hive-default.xml.template" from the source control.   

 However, hive-common still refers to this file in the build-resources.  Thus trying to build eclipse projects on fresh checkout of branch will get "hive-common missing required source-folder: ../conf/" 

 NO PRECOMMIT TESTS
Discussion
- Attaching a fix, that moves the hive-common's build-resource specification to the "dist" profile as well. 

 Normal invokation of "eclipse:eclipse" outside of "dist" profile will not try to add this as build-resource.
- This has been fixed in 0.14 release. Please open new jira if you see any issues.
