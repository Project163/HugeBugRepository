Title

RollingFileAppender should be able to create files on-demand

Description
RollingFileAppender should be able to create files lazily. 

 Add a  createOnDemand="true|false"  attribute to  RollingFileAppender . The default is "false" for backward compatibility (which we can revisit of course).
