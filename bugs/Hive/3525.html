Title

WebHCat specific resources should be added to HADOOP_CLASSPATH first

Description
When submitting jobs via WebHCat the user may specify additional jars to be included with the job.  Sqoop jobs is one such example where user may need to supply a jar with JDBC classes for a given database.  If the a different version of the same jar is already present in HADOOP_CLASSPATH, we need  to make sure user specified jar is used.
