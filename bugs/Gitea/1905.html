Discussion
- ->  Fix submodule relative path handling #35056
- This still seems to be an issue with relative submodules in subdirectories. Maybe the unit tests are not so correct. For example,

```
[submodule "rel1"]
	path = foo/bar/rel1
	url = ../test
```

If the repository is

`gitea.demo.com/org/repo`

The above submodule is then mounted on path,

`gitea.demo.com/org/repo/foo/bar/rel1 -> gitea.demo.com/org/test`

but Gitea resolution seems to apply the relative url to the *path*, and not just the repository location. No matter where the submodule is moved to, the path changes, but the relative url remains as-is. The above example would then be resolved in Gitea as,

`gitea.demo.com/org/repo/foo/bar/rel1 -> gitea.demo.com/org/repo/foo/test`
