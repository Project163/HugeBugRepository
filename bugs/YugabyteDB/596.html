Title

[YQL/Platform][DB Observability] Realtime connections across cluster metrics

Description
Jira Link: [Link: DB-3149]
Spawned from issue #7843 .

```
Realtime connections across cluster: A count of total number of YSQL connections across the cluster, and another showing the corresponding breakdown of the num connections per node in the cluster in realtime summarized on a single page
```

Basically, we want to expose our ysql server connection-related data to internal users, like the Prometheus server. This will help us gain real-time insights into our systems to help root cause issues, like OOMs, high CPU usage. 

The basic goal is to
1. publish connection related metrics to Prometheus endpoint.
2. identify if the connection related statics collected for `/rpcz` is useful or not. If so, convert them into Prometheus format.

Some information collected so far:
1. Confirmed the existing statistics for '/rpcz' is what we want.
2. Confirmed with Platform team's @amalyshev that Platform cannot directly consume JSON metrics from the '/rpcz' endpoint.
3. Confirmed that Platform doesn't expect a strict format from the `/prometheus-metrics` endpoint, such as names in labels.

The next steps are
1. Add conversion logics in sql-webserver to publish connection metrics in Prometheus entries.
2. Discuss with Platform team's contact for verification/testing.
