Title

Fatal error on non-existing association

Description
On Cake3.0.0-RC1, when trying to do a find with a contain to a model that is not associated to the current one, a fatal error occurs. Using this code in my Table model:

```
php
public function findLatestPost($forumId)
{
    $query = $this->Threads->find('all', [
            'contain' => ['Posts'],
... [Log Snipped] ...
    return $query->first();
}
```

I got this error:

As it turned out I forgot to associate the `Posts` model to the `Threads` model. Once I associated them properly, the error disappeared. But the error message is not clear and I'm not sure why this is a fatal error and the ORM doesn't just "skip" this query (or return an empty result set) when it can't do the join.

Note that even when wrapping the `$query` bit into a try/catch block, a fatal error is still thrown.
