Title

The stats table limits are too large for innodb

Description
The limits were increased to a reasonable value some time ago, apparently these values are too large for innodb due to some index limit nonsense. We need to decrease them a little bit. 
There's no need to decrease them in an upgrade script; if they were already created successfully it's ok to have them as is.
