- There seems to be an unresolvable circular incompatibility issue here: 
 
	 Java 11 is incompatible with Scala 2.10, needs newer version, like Scala 2.12 
	 Scala 2.12 is incompatible with Scrooge 4, needs newer version, like Scrooge 19. 
	 Scrooge 19 is incompatible with our  parquet.thrift  file for two reasons:
	 
		 It doesn't handle one of our empty structs correctly. Update: This turned out to be due to using a javadoc-style comment in the empty struct. 
		 It doesn't handle the  String  logical type correctly, because in the code it generates it does not use fully qualified names. Since the name of this logical type shadows the stock String type, this leads to a compilation failure in the generated  LogicalType.scala  file.
