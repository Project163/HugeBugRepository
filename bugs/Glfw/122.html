Title

Joystick disconnection not emitted on event poll

Description
Hello,
I don't know if it's a bug but it took me some good minutes of work :/
The event GLFW_DISCONNECTED only occurs when the glfwGetJoystickAxes or glfwGetJoystickButtons is called in main loop.

To produce this issue try to remove the call of function
`        draw_joysticks(window);`
in test file "joysticks.c" at line 204, and disconnect the joystick. 

Version tested: GLFW 3.2.1
