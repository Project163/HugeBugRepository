Title

Null as HTTP header value results in hanging thread

Description
## Describe the bug

Restassured or quarkus hangs when a response header value is null.


### Expected behavior
1.  Send a response with a response header which has no value.

### Actual behavior

1. No response.

## To Reproduce

1.  Do a restassured request in a junit test method using @QuarkusTest: 

` given()
    .when()
    .contentType("application/json")  
    .get("hangs").andReturn();
`

2. have a @PreMatching Filter with sets 
   responseContext.getHeaders().putSingle("HANGQuarkus",null);

3. Test hangs waiting for a response. After 30 sec you will see
