- At  [URL] the Wicket devs agreed to deprecate the new functionality introduced with Wicket 7.0.0 for collecting the wicket.properties and use ServiceLoader instead.  

 The deprecated functionality will not throw exception like the one in the description if the UrlConnection is not JarURLConnection until it is completely removed.
