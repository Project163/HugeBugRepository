Title

Psalm expects array keys can have impossible types

Description
Psalm doesn't perform the same type casts when creating arrays that PHP does:

[URL]

When using a key `null` in an array, you can't call `array_merge` on it because `null` isn't an `array-key` like it expects. Psalm should be able to detect `null` being cast to `''`
