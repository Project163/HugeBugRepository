Title

Suppress MixedAssignment when variable is explicitly annotated mixed

Description
The following code triggers MixedAssignment when f() is of type mixed:

```php
/** @var mixed */
$x = f();
```

However, since the variable is explicitly annotated mixed, it might as well be allowed. The real danger is when the variable is not given a type explicitly.
