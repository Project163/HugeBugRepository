Title

Segmentation fault in aten.lstm.data operator if batch_sizes tensor is NOT on the CPU

Description
### 🐛 Describe the bug

Invoking torch.ops.aten.lstm.data directly results in SEGFAULT if batch_sizes is not on the CPU.

Other entry points (like through PackedSequence) verify that the tensor is on the CPU, but not the lstm.data operator. [URL]

Repro - requires GPU/CUDA device

```
python
import torch

# Check for GPU availability
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
... [Log Snipped] ...
    bidirectional,  # bool bidirectional
)
```

Running repro as is results in:
```
$ python3 lstm_test.py
Using device: cuda
Segmentation fault (core dumped)
```
