Title

Kraft bootstrap metadata file should use snapshot header/footer

Description
The bootstrap checkpoint file that we use in kraft is intended to follow the usual snapshot format, but currently it does not include the header/footer control records. The main purpose of these at the moment is to set a version for the checkpoint file itself.
