Title

Bevy 0.13 `RenderAssetUsages` fails to build due to `serde::Deserialize`.

Description
## Bevy version

Bevy 0.13.0.

## \[Optional\] Relevant system information

If you cannot get Bevy to build or run on your machine, please include:

- Using Rust 1.76.0
- Windows 10

## What you did

Compiled my library which uses Bevy, with default features off, but with bevy_asset and bevy_render enabled.

## What went wrong

Failed to compile with the folling error:
```
error[E0277]: the trait bound `render_asset::_::InternalBitFlags: color::_::_serde::Serialize` is not satisfied
   --> E:\Programs\Cargo\registry\src\index.crates.io- \bevy_render-0.13.0\src\render_asset.rs:70:14
    |
53  | / bitflags::bitflags! {
54  | |     /// Defines where the asset will be used.
... [Log Snipped] ...
75 | | }
   | |_^ the trait `Deserialize ` is not implemented for `render_asset::_::InternalBitFlags`
```
Discussion
- Looks like we're missing the serde feature for bitflags in bevy_render. I added an explicit dependency on bitflags with this feature enabled and everything compiled correctly.
