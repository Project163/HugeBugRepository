Title

Android support for EFrame, including support for suspend + resume events

Description
**Describe the bug**
As a continuation of the work started with [URL] it would also be good to update EFrame to be able to defer the initialization of render state until the app is first resumed (and be able to re-create windows/surfaces for further Suspend/Resumed events) so that EFrame can be used to build Android applications.

Right now if you try and run an EFrame based application on Android you will simply get a black screen.

 

**To Reproduce**

The Android example here can potentially be used to reproduce this: [URL] - though there's a chicken / egg situation since that test has actually been updated to work with [Link: a branch] I will submit as a PR soon.


**Expected behavior**
 

It should be possible to run an eframe application on Android with input handling and correct rendering, as well as be able to suspend and resume when switching between applications.
