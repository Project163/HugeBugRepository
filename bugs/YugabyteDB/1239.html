Title

[CDCSDK] Memory Leak in Postmaster (WALsender process) Detected During Long Retention Experiment with PG Connector

Description
Jira Link: [Link: DB-13887]
### Description

Please view slack thread in JIRA description for conversation.

During a long retention experiment using the YugabyteDB (YBDB) PG connector, a memory leak has been observed in the postmaster process. This issue arises under normal operation ("happy path") and significantly affects memory consumption.

_Experiment Context:_ 
The experiment involved testing long retention capabilities with the PG connector.

_Observation:_ 
Memory consumption for the postmaster process, specifically on the node where the walsender is running, showed an increasing trend. When the memory usage dropped, it indicated that the postmaster had reached a tipping point, leading to the walsender starting on a different node.
