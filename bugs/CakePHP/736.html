Title

[3.1] Fail to properly configure Redis cache engine via DSN string

Description
Hi, I can't get the Redis Cache engine to work using a DSN string.
## The problem

My configuration (`config/app.php` excerpt):

```
php
  getenv('DEBUG'),
... [Log Snipped] ...
    ],
];
```

What I get (logs extracted from a Docker container, I had to reformat them, might not be the "standard" CakePHP log format):

```
2015-12-06 10:23:51 Error
#1 /app/vendor/cakephp/cakephp/src/Cache/Cache.php(154)
#2 /app/vendor/cakephp/cakephp/src/Cache/Cache.php(186)
#4 /app/vendor/cakephp/cakephp/src/I18n/I18n.php(137)
#5 /app/vendor/cakephp/cakephp/src/I18n/functions.php(81)
... [Log Snipped] ...
#11 [internal function]
#12 {main}
```
## My (temp?) fix

The problem seems to be originated by the fact that the DSN string is correctly parsed by the `Cake\Core\StaticConfigTrait`, correctly merged in the `Cake\Cache\Engine\RedisEngine::$_config` array (hence, the DSN scheme is mapped to the correct cache engine class), but then `$this->_config['host']` is never used. :wink: 

So, what I did was:

``` php
$this->_Redis->connect($this->_config['server'], $this->_config['port'], $this->_config['timeout']);
$this->_Redis->pconnect($this->_config['server'], $this->_config['port'], $this->_config['timeout'], $persistentId);

// Became...

$this->_Redis->connect($this->_config['host'] ?: $this->_config['server'], $this->_config['port'], $this->_config['timeout']);
$this->_Redis->pconnect($this->_config['host'] ?: $this->_config['server'], $this->_config['port'], $this->_config['timeout'], $persistentId);
```

I don't know what is your approach to the `?:` operator. In any case, it might not be the best solution, but it does apparently work. :smile: 

I have also checked the Memcached engine, and it seems to be OK: it does already handle the case when no `server` key is passed, while `host` is populated.
