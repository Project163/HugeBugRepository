Title

Vagrant 1.9.1 break 'service-manager' plugin 'install-cli' command

Description
Hi,

We have been using Vagrant to provide cross platform development environment for [Link: ADB].

One of plugin i.e [Link: service-manager] is now breaking for [Link: 'install-cli'] command when upgrading to version 1.9.1.

This was working fine in Vagrant version `1.8.1`.

Error is :
```
$ vagrant service-manager install-cli docker
undefined method `upcase' for nil:NilClass
```

After bit of debugging we found that [Link: this line] return empty since `data` seems to be empty.
Further debugging shows us that now `data` part fills on second iteration as:
```
$ vagrant service-manager install-cli docker
Ignoring ruby-libvirt-0.7.0 because its extensions are not built.  Try: gem pristine ruby-libvirt --version 0.7.0
================== before execute in os_variant ============
data: , type: stdout
data: VARIANT_ID="adb", type: stdout
================== after execute in os_variant ============
undefined method `upcase' for nil:NilClass
``` 

#### We would be interested to know, is there any design change here? For us, the fix seems to be simple as [Link: this PR]. More question in comment [URL] as

*Steps to reproduce*
- vagrant init projectatomic/adb
- vagrant plugin install vagrant-service-manager
- vagrant up
- vagrant service-manager install-cli docker
