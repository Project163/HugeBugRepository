Discussion
- The example is no longer the recommended way to generate or test config files. Instead, you should now be using the Tika command line app, with an option such as  --dump-minimal-config  or  --dump-static-config  - can you try that and see if it fixes your issue? 

 Otherwise, make sure you only have one copy of Tika on your classpath - with both the Tika App and Tika Parsers jars on your classpath you can get doubled entries
- The double classes stem from maven (tika-parser is embedded twice).
