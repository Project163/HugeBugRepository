Title

Unexpected line when type # after completion

Description
### Neovim version (nvim -v)

NVIM v0.7.0 release

### Vim (not Nvim) behaves the same?

Yes, Vim 8.2.4710

### Operating system/version

MacOS 12.1

### Terminal name/version

iTerm2

### $TERM environment variable

xterm-256color

### Installation

repo

### How to reproduce the issue

Issue happens on neovim >= 0.7.0.
Issue happens when `#` is not in `iskeyword`
``` sh
nvim -u NORC t.js
```
``` vim
call setline(1, 'foo foot')
call feedkeys("o  f\ #")
```

### Expected behavior

Second line should be `   foo#`

### Actual behavior

Second line becomes `#foo`
Discussion
- A workaround is use a key-mapping like:
```vim
inoremap #   #
```
- Bug also exists in Vim.
- This bug was caused by [Link: patch 8.2.4710]
