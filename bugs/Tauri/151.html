Title

Http Type "Part" [bug]

Description
### Describe the bug

In the `http` module, we have a `Part` type that uses `'string` instead of the primitive `string` type.

```ts
// http.ts line 40
type Part = 'string' | number[]
```

It should be 
```ts
type Part = string | number[]
```
