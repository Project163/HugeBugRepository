Title

camel-rest-openapi: OpenApi specification in the rest configuration will be ignored in Camel Spring Boot

Description
Given the  Camel Example OpenAPI Contract First  with the configuration  

  
 
 rest ().openApi().specification( "petstore.json" ).missingOperation( "ignore" );
 
  

 and the consumer route 

  
 
from( "direct:getPetById" )
 
  

 we expect that the rest configuration will use the  petstore.json  in the classpath to configure the exposed endpoints, but the application will not start using the command  

  
 
mvn spring-boot:run
 
  

 due to  

  
 
ERROR 37424 --- [           main] o.s.boot.SpringApplication               : Application run failed
org.apache.camel.FailedToStartRouteException: Failed to start route route3 because of The given OpenApi specification cannot be loaded from: openapi.json
 
  

 so the application is looking for the  openapi.json  file instead of the configured  petstore.json
Discussion
- yes sorry I did not specify it
- replacing the configuration in the code with the property 
  
 
camel.component. rest -openapi.specification-uri=petstore.json
 
  
 solves the issue but it should be configurable in both ways
- Okay I have a fix going to backport this
