Title

Migration Generator ignores the "bigPrimaryKey:unsigned" decorator

Description
### What steps will reproduce the problem?

Use Migrations Generator with the "bigPrimaryKey:unisgned" decorator:
`
yii migrate/create create_brands_table --fields="brand_id:bigPrimaryKey:unsigned"
`
### What is the expected result?

```
$this->createTable('brands', [
        'brand_id' => $this->bigPrimaryKey()->unsigned(),
    ]);
```
### What do you get instead?

```
$this->createTable('brands', [
        'id' => $this->primaryKey(),
        'brand_id' => $this->bigPrimaryKey()->unsigned(),
    ]);
```
