Title

ValidationException when validating beans without validation annotations

Description
Without any bean validation annotations, "validator.validate(object)" leads to:
javax.validation.ValidationException: HV000249: Uninitialized bean metadata for class: io.github.joht.quarkvent.message.command.account.CreateAccountCommand. Please register your bean class as a class to initialize when initializing your ValidatorFactory.

StackTrace:
org.hibernate.validator.internal.metadata.PredefinedScopeBeanMetaDataManager.getBeanMetaData(PredefinedScopeBeanMetaDataManager.java:99)
org.hibernate.validator.internal.engine.ValidatorImpl.validate(ValidatorImpl.java:156)

Debugging into PredefinedScopeBeanMetaDataManager shows an empty "beanMetaDataMap", if no annotations are used.

As far as i know there shouldn't be ValidationException on beans that are not annotated for bean validation.

**Environment (please complete the following information):**
 - Output of `java -version`: openjdk version "1.8.0_202"
 - Quarkus version or git rev: 0.15.0
