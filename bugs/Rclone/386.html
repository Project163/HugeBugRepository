Title

ncdu misses Chinese characters and formats incorrectly

Description
#### What is the problem you are having with rclone?
`ncdu` doesn't format Chinese characters correctly.
Specifically, it misses one character every two characters on all systems tested.
On Windows it also has formatting issues

Example 1:
```
$ rclone lsf gdrive:test
一二三四五六

$ rclone ncdu gdrive:test

rclone ncdu v1.46 - use the arrow keys to navigate, press ? for help               
-- gdrive:test --------------------------------------------------------------------
       0 [          ]  一三五                                                      
```
