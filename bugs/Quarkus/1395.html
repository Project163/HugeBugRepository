Title

ConcurrentModificationException from Micrometer extension on shutdown

Description
### Describe the bug

I've been seeing `ConcurrentModificationException`s being reported during the shutdown of tests with Quarkus 2.5.0.

The problem is caused by [URL] since the Micrometer `CompositeMeterRegistry#getRegistries()` method doesn't return a copy and `Metrics#removeRegistry()` modifies the same instance in the for loop.

### Expected behavior

No error on shutdown.
