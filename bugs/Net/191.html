Title

FTPClient#initFeatureMap should not initialize empty map if reply code is 530

Description
Some servers reply with 530 when requesting features before being logged in. However sending FEAT is used to determine if the server supports secured connection before attempting to login using an unsecured connection. 

 Due to the caching of the empty map subsequent feature detection fails.
