Title

Ignoring import does not always work

Description
The `# type: ignore` comment does not work in the example below:

```
from google.protobuf import reflection
from google.protobuf import descriptor_pb2 # type: ignore

descriptor_pb2.foobar
```

If I comment out the first line it works.
Discussion
- `type: ignore` is icky because it does two separate things:
1. Disable type-checking within a line
2. Act like `type: Any` if there is an assignment on the line.
- This seems to work as expected now:
```
$ mypy samples/gpro.py 
samples/gpro.py:1: error: No library stub file for module 'google.protobuf'
samples/gpro.py:1: note: (Stub files are from [URL]
```
