Title

Unexpected behavior with inheritance and -Dtest with Surefire

Description
Having such a construct

```
java
public abstract class SomeAbstract5Test {
    @Test
    public void abstr() {
        System.out.println("abstr");
... [Log Snipped] ...
    }
}
```

When executing tests with `mvn test -Dtest=SomeConcrete5Test` only tests defined in concrete test class are executed. The expected behavior (and the behavior provided by JUnit 4) would be to execute all tests inherited, too.

Is there a way to achieve this using JUnit Platform 1.2 and JUnit Jupiter 5.2?
