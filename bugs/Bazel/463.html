Title

0.5.3 brought UI regression of repository rules

Description
Please provide the following information. The more we know about your system and use case, the more easily and likely we can help.

### Description of the problem / feature request / question:

I have a repository rule which takes some time to complete.
It calls `repository_ctx.execute(args, quiet = False)` to do the actual action and the executed process prints its progress.
In 0.5.2 the rule printed its progress as it worked.
In 0.5.3 the output is printed after the rule finishes so effectively there is no output and when it finishes I get ~30 lines in one batch.  

### If possible, provide a minimal example to reproduce the problem:
given this [Link: repo]
run `bazel build //...` with bazel 0.5.2 and see the progress.
Do `bazel clean --expunge` and run the build again with bazel 0.5.3 to see the progress is only flushed at the end.

### Environment info
* Operating System:
Mac OS 10.12
