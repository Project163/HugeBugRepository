Title

derive(Queryable) doesn't work with a field of `Field` type

Description
## Setup

### Versions

- **Rust:** 1.78.0
- **Diesel:** 2.2.0
- **Database:** PostgreSQL
- **Operating System** Linux

### Feature Flags

- **diesel:** none

## Problem Description


### What are you trying to accomplish?

I'm trying use a type called `Field` in my `Queryable` data structure. In my case it has `FromSql` implementation from `Jsonb`, but in a minimal example for reproduction below I aliased `i32` to make things as simple as possible.

### What is the expected output?

It should work.

### What is the actual output?

```
error[E0106]: missing lifetime specifier
 --> src/main.rs:7:12
  |
7 |     field: Field,
  |            ^^^^^ expected named lifetime parameter
... [Log Snipped] ...
Some errors have detailed explanations: E0106, E0107, E0782.
For more information about an error, try `rustc --explain E0106`.
```

### Are you seeing any additional errors?


### Steps to reproduce

 

Compile the following code.

```
rust
use diesel::Queryable;

type Field = i32;

... [Log Snipped] ...

fn main() {}
```

- Thanks for reporting. This is caused by a import to the `Field` trait in the relevant code generated by the `Queryable` derive here:

[URL]

The fix for that issue is to replace this (and all the other trait imports there) with `use diesel::row::Field as _;` to avoid the name collision. 

A fix should also add this example (maybe extended with other fields to match the other traits) as compile pass test there:

[URL]
