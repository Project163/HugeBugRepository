Discussion
- So it seems like there's a space leak (in ant?  ant/junit?).  A PermGen space error is an 
error indicating that the permanent generation has gotten full, meaning that there 
are too many long lived objects.  There are two simple solutions, one is for the user 
to increase the limits set by the jvm:

ANT_OPTS="-Xmx2048m -XX:MaxPermSize=1024m"; ant clean && time ant test

The other is to fork for each test, so in build.xml:
-     
+     

Forking has a speed penalty, so running all tests goes from ~60 seconds to ~140 
seconds.  On the other hand, I don't see any way to set JVM arguments to ant once 
you're in ant.
