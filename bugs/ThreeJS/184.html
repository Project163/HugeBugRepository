Title

Inconsistent Default CORS Behavior for MTLLoader?

Description
**Problem:**
In [Link: Line 168] of `MTLLoader.js`:

	materialCreator.setCrossOrigin( this.crossOrigin );

`this.crossOrigin` is `undefined` by default for `THREE.MTLLoader`, so the default value given by `THREE.MTLLoader.MaterialCreator` at [Link: line 210]:

	crossOrigin: 'anonymous',

is overwritten and ignored.

**Suggestion to Fix:**
Either `THREE.MTLLoader` should set a default value for `crossOrigin` as well or the `setCrossOrigin` method ([Link: line 212]) of `THREE.MTLLoader.MaterialCreator` should return early for a null input.
Discussion
- I think it should be sufficient if `MTLLoader` defines `crossOrigin: 'anonymous',` for its prototype similar to `GLTFLoader` or `ColladaLoader`. Would you like to do a PR with the change?
