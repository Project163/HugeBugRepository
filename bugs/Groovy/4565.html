Title

Immutable fails with defaults=true

Description

@Immutable(defaults= true , noArg= false )
 class  Foo {
   String  bar, baz
}
 
  

 If "noArg=false" is removed there is a compiler error "Unable to compile class Foo due to hash collision in constructors".
