Title

0=>false in pagination params

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.5.11
* Platform and Target: Apache, Windows, PHP 7

### What you did

Read the paging parameters after using the paginate component.

```
            $posts = $this->paginate($this->Posts);
            $pagingParams = $this->request->getParam('paging', []);
            dd($pagingParams);
```

Which generates this output.

```
[
	'Posts' => [
		'finder' => 'all',
		'page' => (int) 1,
		'current' => (int) 20,
... [Log Snipped] ...
	(int) 0 => false
]
```

### What you expected to happen

Was only expecting to see `$pagingParams['Posts']` as the only array element and for the array to have only 1 element (`count($pagingParams) === 1`).

This array contains `0 => false` and I'm not sure why. So I'm assuming this is a bug, and that the array should only contain `Posts`.
