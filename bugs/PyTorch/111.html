Discussion
- We should add the appropriate TORCH_CHECK to ensure these size are correct. Feel free to send a PR fixing this!
- @albanD There is inconsistency between python API and C++ API.

[Link: Python]:
```python
for d in range(len(kernel_size)):
    default_size.append((input_size[-len(kernel_size) + d] - 1) * stride[d] + kernel_size[d] - 2 * padding[d])
```
[Link: C++]:
```c++
for (const auto d : c10::irange(kernel_size.size())) {
  default_size.push_back(
      (input_size[d + 2] - 1) * stride[d] + kernel_size[d] - 2 * padding[d]);
}
```
In python frontend, the base index of `input_size` is `len(input_size) - len(kernel_size) - 1` while C++ frontend simply uses `2`. It seems clear than the length of `kernel_size`, `stride`, and `padding` should be same, but I'm not sure about `input_size`.
