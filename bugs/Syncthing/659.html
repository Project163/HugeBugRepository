Title

Build information missing in discovery and relay server binaries

Description
Since v1.2.2, the discovery and relay server releases are missing the `build user, build host` and `build date` information. This causes the following awkward output on startup:

```
Started Syncthing Discovery Server.
stdiscosrv  (go1.12.9 linux-amd64) @ 1970-01-01 00:00:00 UTC
```
and

```
Started Syncthing Relay Server.
main.go:149: strelaysrv  (go1.12.9 linux-amd64) @ 1970-01-01 00:00:00 UTC
```

The builder info is just an @ and the build date is the UNIX timestamp of zero.

Older releases (v1.0.1) print correct data here, for example `stdiscosrv v1.0.1 (go1.11.5 linux-amd64) teamcity@build.syncthing.net 2019-01-18 10:34:18 UTC`.

The main syncthing binary is also fine and prints everything correctly, for example:

`syncthing v1.2.2 "Fermium Flea" (go1.12.9 windows-amd64) teamcity@build.syncthing.net 2019-08-15 13:51:09 UTC`

As far as I've diagnosed the issue apart from the output on startup everything works OK.

I haven't looked at any other `/cmd` binaries apart from the three mentioned above, so I don't know if other executables are affected.

### Version Information

Syncthing Version: v1.2.2 (syncthing, discovery, relay)
OS Version: Bug discovered/verified on Linux amd64.

EDIT: Just for the sake of completeness: I forgot to mention that the `version` information is missing too, there's just a whitespace where "v1.2.2" should have been.
