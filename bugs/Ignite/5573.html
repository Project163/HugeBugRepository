Discussion
- Implementor for  OR  operator ( IN  operator is translated to  SEARCH / SARG  and than translated to  OR ) generates a lot of not-null checks for the same input operand, since the input operand is nullable. But we can make a little hack - check for nulls once and convert input operand to not-nullable type. In this case  OR  implementor will skip not-null checks for this opeand. 
POC implementation shows reduction of generated bytecode size.
