Title

jui\DatePicker shows an error field when used with Required validator

Description
In model:

```
    public function rules()
    {
        return [
            ['activeUntilDate', 'required'],
        ];
    }
```

in view:

```
 field($model,'activeUntilDate')->widget(DatePicker::className(),['clientOptions' => ['dateFormat' => 'yy-mm-dd']]) ?>
```

Goto page with form.
Click on datepicker field.
Try to select any month or click and hold the button on any date.

[Image: 2014-07-08_1817]
Discussion
- Added `validateOnBlur`. Your problem can be solved now with

``` php
 field($model,'activeUntilDate', ['validateOnBlur' => false])->widget(DatePicker::className(),['clientOptions' => ['dateFormat' => 'yy-mm-dd']]) ?>
```
- Don't know what is better - now if you put caret in the field and then leave it without selecting date from calendar - empty field is not highlighted.

Maybe somehow attach validation to the event when calendar popup hides?
- Well, you can use custom js code to achieve this.
