Title

VerifyError when using Float in Model deserialized by Jackson

Description
### Describe the bug

If I want to deserialize a model that contains a float, a `VerifyError` occurs during deserialization because the deserializer which is generated during the build uses a `Double` instead of a `Float`. 

The error only occurs if reflection free serializers are enabled.

```
2025-04-22 12:14:59,534 ERROR [io.qua.ver.htt.run.QuarkusErrorHandler] (executor-thread-1) HTTP Request to /v1/products failed, error id: 94f8448d-b4e0-4258-9bac-f7dd12ef09c4-1: java.lang.VerifyError: Bad type on operand stack
Exception Details:
  Location:
    io/i15s/quarkus/Product$quarkusjacksondeserializer.deserialize(Lcom/fasterxml/jackson/core/JsonParser;Lcom/fasterxml/jackson/databind/DeserializationContext;)Ljava/lang/Object; @243: invokevirtual
  Reason:
... [Log Snipped] ...
	at io.netty.util.concurrent.FastThreadLocalRunnable.run(FastThreadLocalRunnable.java:30)
	at java.base/java.lang.Thread.run(Thread.java:1583)
```

### How to Reproduce?

I've created a small reproducer project.  [URL]
In principle, however, a normal Java POJO with a Float member is sufficient and the reflection free serializers must be activated.

```properties file=application.properties
quarkus.rest.jackson.optimization.enable-reflection-free-serializers=true
```

```
java

    @NotBlank(message = "Name must not be blank")
```
