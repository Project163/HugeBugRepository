Title

'SELECT *' causes 'Ambiguous column name' error when accessing returned rows

Description
### Describe the bug

When using a query of the form `SELECT *, some_column FROM some_table` (in sqlalchemy core via `text('*')`), `some_column` is not accessible by name in the returned rows.

Also, the error does not appear for a specific ordering combined with `label` (see code example).

### To Reproduce

```
python
from sqlalchemy import select, text
from sqlalchemy.engine.base import Connection

some_table = # initialize table with column 'some_col'
... [Log Snipped] ...
row = connection.execute(stmt).first()
print(row.label)  # WORKS!
```

### Error

```
  File "/home/***/.local/lib/python3.9/site-packages/sqlalchemy/engine/cursor.py", line 625, in _raise_for_ambiguous_column_name
    raise exc.InvalidRequestError(
sqlalchemy.exc.InvalidRequestError: Ambiguous column name 'some_column' in result set column descriptions
``` 

### Versions

- OS: Debian GNU/Linux 11 (bullseye)
- Python: 3.9.2
- SQLAlchemy: 1.4.29
- Database: PSQL 13.8
- DBAPI (eg: psycopg, cx_oracle, mysqlclient): psycopg2
