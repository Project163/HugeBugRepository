Title

Failing tests for `DateValidator` with ICU tzdata 2017c

Description
I'm not sure is it related to Yii itself or not.

### What steps will reproduce the problem?

0. Catch the fact that built-in ICU tzdata became outdated. Same timestamp with specific time zone produce different output between intl and native PHP's TZ handling.
1. Update ICU tzdata to latest [Link: 2017c] according to [Link: ICU manual] linked from [Link: Yii guide]. Same things are described [Link: here (ru)].
2. Run Yii2 tests for validators.

### What is the expected result?

Tests passed.

### What do you get instead?

```
There were 3 failures:

1) yiiunit\framework\validators\DateValidatorTest::testIntlValidationWithTime with data set #0 ('UTC')
Failed asserting that false is true.

... [Log Snipped] ...

FAILURES!
```

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.13
| PHP version      |  7.0.22-0ubuntu0.16.04.1
| Operating system | Ubuntu
| libicu55 | 55.1-7ubuntu0.3
Discussion
- The data format has slightly changed, I think. I just debugged this on PHP 7.2.

When changing the failing lines to:

    $this->assertTrue($val->validate('31/05/2017, 12:30'));
    $this->assertTrue($val->validate('31.05.2017, 12:30'));

...tests pass. I found this by using the formatter.
