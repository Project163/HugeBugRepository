Title

ZAP attempts to use a client certificate even if none set

Description
Issue reported in IRC channel: [URL]

Steps to reproduce the issue:
1. Run ZAP;
2. Enable the option Options > Certificate > Use client certificate;
3. Attempt to access a HTTPS site through ZAP and note that the browser shows an error;
4. Check the log file, there should be some exceptions, for example:
