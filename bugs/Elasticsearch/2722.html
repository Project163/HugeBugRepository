Title

SQL: Incorrect stats reported when sorting by aggregated values

Description
The following query increases the `rest.total` counter by 11 and the `rest.paging` counter by 10 (as returned by `_sql/stats`):

```
GET [URL]

{
  "fetch_size": 10,
  "query": "select last_name, sum(languages) from test_emp group by 1 order by 2"
}
```

Expected behavior would be to only increase `rest.total` by 1.

The bug is caused by `LocalAggregationSorterListener` using `PlanExecutor` to fetch all records before sorting.
