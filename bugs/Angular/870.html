Title

Ivy: Generic type 'ɵɵBaseDef ' requires 1 type argument(s).

Description
# 🐞 bug report

### Affected Package
@angular/material
@angular/flex-layout


### Is this a regression?
Yes - works prior to building with Ivy.

### Description

  Building with Ivy causes .d.ts files to be modified. As part of those modifications, the following line is added:
    `static ngBaseDef: ɵngcc0.ɵɵBaseDef;`

This causes the build to fail. Switching 'enableIvy' back to false still results in a broken build due to the .d.ts file modifications (although the 'WARNING' lines disappear).
