Title

Handle Collection as defaultValue in GUI.select() method

Description
Description 

 Currently, when using GUI.select() with a Collection as the defaultValue parameter, the entire Collection object is used as the default value. This causes issues since the select form expects a single value, not a Collection. 

 Problem 
  - When a Collection is passed as defaultValue to GUI.select(), the Collection object itself is used as the default value 
  - This behavior is incorrect as the select form expects a single value 
  - This can lead to unexpected behavior in GUI forms 

 Solution 
  Modify GUI.select() method to: 
  - Check if defaultValue is a Collection (excluding String, which implements CharSequence) 
  - Extract the first element from the Collection if it's not empty 
  - Use null if the Collection is empty 
  - Use the extracted element as the actual default value 

 Test Coverage 
  - Added testSelectWithCollectionDefault() test case 
  - Verifies that a Collection containing  ["2"]  is properly converted to default value "2" 
  - Ensures the form's default value is correctly set

  - No breaking changes for existing users 
  - No documentation updates required 
  - No license file updates needed
