Title

Append with setValue and shouldDirty is not working correctly

Description
**Describe the bug**
When appending values to field arrays with `setValue` and `{ shouldDirty: true }`, neither `dirtyFields` nor `isDirty` are being updated properly.

**To Reproduce**
Steps to reproduce the behavior:

1. Check `isDirty` and `dirtyFields` values
2. Click on the "add array field" or "add nested array field" button
3. Check that `isDirty` and `dirtyFields` values are not updated
4. Click on the "add array field" or "add nested array field" button again
5. Check that `isDirty` and `dirtyFields` values are updated but with previous values

**Codesandbox link (Required)**
[URL]

**Expected behavior**
`isDirty` and `dirtyFields` should be updated right after triggering a `setValue` with `{ shouldDirty: true }`
