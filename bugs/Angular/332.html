Title

change publish-build-artifacts.sh to publish non-master branch builds to a custom branch

Description
`publish-build-artifacts.sh` currently publishes build artifacts from any `angular/angular` (upstream) travis builds to `angular/core-builds` and friends.

It always uses the master branch in these `-builds` repos, even for builds that originate from patch branches.

The docs team needs to be able to pull in master and 2.2.x (soon to be 2.3.x) builds separately which is currently not possible.

We should modify the `publish-build-artifacts.sh` script to publish into a branch that matches the current branch (if such branch doesn't exist in angular/core-builds and friends, this branch should be created automatically).
