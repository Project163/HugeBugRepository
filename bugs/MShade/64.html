Title

Shade plugin does unbuffered output

Description
maven-shade-plugin does unbuffered output: 

  
         JarOutputStream jos =  new  JarOutputStream(  new  FileOutputStream( shadeRequest.getUberJar() ) );
 
  

 This results in massive amounts of single-byte writes, which kills performance, particularly on network shares. 

 Changing the code to  

  
         JarOutputStream jos =  new  JarOutputStream(  new  BufferedOutputStream(  new  FileOutputStream( shadeRequest.getUberJar() ) ) );
 
  

 Fixes the problem.
