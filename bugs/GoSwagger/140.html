Title

Models: Invalid pointer redirect

Description
## Problem statement

Generated code includes incorrect pointer operation.

```
go
// GroupPreference group preference
// swagger:model groupPreference
type GroupPreference map[string]float32

... [Log Snipped] ...
	return nil
}
```

`*m[k]` causes compiler error `invalid indirect of m[k] (type float32)`. It should be `m[k]`

## Swagger specification

The swagger definition is :-

```
yaml
  groupPreference:
    type: object
    additionalProperties:
      type: number
... [Log Snipped] ...
      GB: 0.5
      NL: -5
```

`format: float` or `format: double`, both have the same issue.

## Steps to reproduce

swagger generate client -f spec_containing_definition.yaml -t $GOPATH/github.com/user/repo

## Environment
swagger version: 0.14.0  
go version: go version go1.10 linux/amd64
OS:  Linux 4.13.0-41-generic #46-Ubuntu SMP
Discussion
- OK from reading [Link: comment on another issue], adding `x-nullable: false` is a workaround for now.
- I am currently working on a fix for that.
The problem is that the map element is independently elected as nullable and rendered as a pointer (because minimum < zero value of number < maximum) and the aliased map currently ignores this.

See also #1561
