Title

Deadlocks randomly, occasionally

Description
### What happened?

Situation: I have 'bout a dozen servers syncing some files with Syncthing. All are on Debian 12. Never a real issue, but right after update to 1.29.0 strange things happen (one or more at the same time):

* Hosts are marked as "synchronizing" and/or a few files unable to sync (which aren't present on either the host itself or the host that it displays that the missing file would be present)
* Syncthing processes just stop responding (no more loglines in syslog)
* All shared resources on a host are marked "unavailable" (but the files are just there)

Restarting syncthing resolves it, but it returns after a random amount of time.

Have downgraded syncthing to 1.28.1 on the hosts 5 hours ago and 0 issues since then.

Submitting the report in case others experience the same behaviour since 1.29.0 and maybe a common denominator can be found.

### Syncthing version

v1.29.0

### Platform & operating system

Linux amd64 (Debian 12 Bookworm) - installed through official syncthing repo

### Browser version

Firefox 133.0.3

### Relevant log output

```shell
No logs; just stops logging in syslog. Process isn't crashed (web interface still works), but a restart is necessary
```

- I think we need a goroutine dump from a hung instance to figure out what's going on. When it's in a bad state, figure out the pid of the processes; there will be two of them (plus maybe the grep etc):

```
jb@jbo2:~ % ps aux | grep syncthing
jb               87691   0.0  0.7 412468848 267104   ??  SN    8:02AM   2:08.77 /Users/jb/bin/syncthing
jb               87690   0.0  0.0 411936912   9312   ??  S     8:02AM   0:00.32 /Users/jb/bin/syncthing
jb               91971   0.0  0.0 410060064     32 s000  S+   11:16AM   0:00.00 grep syncthing
```

Take the higher PID of the two and send it a SIGQUIT:

```
jb@jbo2:~ % kill -QUIT 87691
```

You'll get a very long thread/routine dump in the log output. Where that is depends on how it's set up, but wherever you get Syncthing logs. Upload the whole thing...
