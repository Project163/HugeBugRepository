Title

C# generates unsigned byte for Thrift "byte" type

Description
Given the code 

  
 struct test {
  1:  byte  field
}
 
  

 the C# Generator generates  

  
  public  partial  class  test : TBase
{
   private   byte  _field;
   // more code
 }
 
  

 which is wrong, as all Thrift integer types are considered signed.
