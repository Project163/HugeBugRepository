Title

[Composable template] Simulate error when index pattern matches existing template

Description
If we create a composable index template like this one

```
PUT _index_template/hello
{
  "index_patterns": ["foo*"]
}
```

And then we do a simulation, using a matching index pattern

```
POST /_index_template/_simulate
{
  "index_patterns": ["foo"],
  "template": {
    "settings": {
... [Log Snipped] ...
  }
}
```

we get the following error

```
{
  "error" : {
    "root_cause" : [
      {
        "type" : "illegal_argument_exception",
... [Log Snipped] ...
  "status" : 400
}
```

Which we should not receive as this is a simulation of the final composition.
