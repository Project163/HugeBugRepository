Title

`return"field" in Module` will be evaluated as `returntrue` or `returnfalse`

Description
# Bug report
Hi, Webpack team. I found a bug when I upgrade it's version in my work project.

in version 5.71.0, there is a commit  .
It can evaluate the statement like `"Component" in React` to `true` on build time.
However, the is a edge case:
``` js
function foo() {
  return"Component" in "React"
}
```
that will be transformed to "returntrue". It misses a space before "true"

 
 
 
 

**What is the current behavior?**
`returntrue` or `returnfalse` will be a transformed result.
And will cause runtime error as `returntrue is not defined`

**If the current behavior is a bug, please provide the steps to reproduce.**
## reproduce
I create a PR for fix it. #15760.
comment this line [URL]
and run 
```
 yarn jest test/TestCasesDevelopment.test.js -t harmony-export-import-specifier
```
the test will produce an error:
[Image: image]


 
 
 
 
 
 

**What is the expected behavior?**
Should be transformed to `return true` or `return false`
