Title

The Web UI defaults to Filipino on Finnish browsers.

Description
### What happened?

On a browser with the language set to Finnish (fi), Syncthing's Web UI mistakenly sets the language to Filipino (fil).

Reproduction steps:
- Clear the cookies for the web UI or use a blank browser profile.
- Set the browser's primary language to Finnish.
- Open the Web UI.

### Syncthing version

v1.27.10

### Platform & operating system

Linux (64-bit Intel/AMD)

### Browser version

Mozilla Firefox 129.0.1 and Chromium 127.0.6533.99
