Title

CDATA end marker in exception message of failed test must not break XML output

Description
## Overview

Exception messages that contain the XML CDATA end marker `]]>` currently cause the XML output to be invalid, e.g. the message `   ` results in the following document:

```
xml
 
 
 
    
... [Log Snipped] ...
 
 
```

## Deliverables

- [x] Ensure exception messages that contain the CDATA end marker `]]>` result in valid XML
