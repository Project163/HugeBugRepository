Title

[helm3] helm template with --output-dir doesn't write template with a hook to file

Description
Output of `helm version`:
3.1.2

Output of `kubectl version`:
1.18.0

Cloud Provider/Platform (AKS, GKE, Minikube etc.): 
CentOS Linux release 7.7

The same problem still persists in Helm 3.1.2.
[Link]

If a template contains hook annotation `helm template --output-dir mydir` works incorrectly.
It does not write generated text for template with a hook to the file.
Instead it prints the output to the console.

**Example**
```
cat init-job.yaml

apiVersion: batch/v1
kind: Job
metadata:
... [Log Snipped] ...
  name: init
  ...
```
