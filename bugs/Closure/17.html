Title

fails to build from source without binary blobs

Description
The closure-compiler source contains compiled classes. If these are removed
the build fails:

$ rm --force lib/google_common_deploy.jar
lib/google_compiled_protos_deploy.jar lib/junit.jar
lib/libtrunk_rhino_parser_jarjared.jar tools/FlagProcessorFactory_deploy.jar
$ ant jar
    [...]

    [javac] [...]: package com.google.common.base does not exist
    [javac] [...]: package com.google.common.collect does not exist
    [javac] [...]: package com.google.common.flags does not exist
    [javac] [...]: package com.google.common.io does not exist
    [javac] [...]: package com.google.javascript.jscomp.mozilla.rhino does
not exist
    [...]

Nicholas

Guava
