Title

Async appender should use shutdown hook for logback graceful shutdown

Description
This applies to all Play 2.x versions:

The async appender in `logback.xml` uses an async appender:

[URL]

```xml
   
     
   
```

There's a note saying that when logback closes down, there's a small chance that logged messages will still be in the queue, because Logback does not do graceful shutdown by default.  

The logstash-logback-encoder notes reference this "In order to guarantee that logged messages have had a chance to be processed by asynchronous appenders (including the TCP appender) and ensure background threads have been stopped, you'll need to [Link: cleanly shut down logback] when your application exits." [URL]

Cleanly in this case means adding a shutdown hook [URL] but you must specify `DelayingShutdownHook` explicitly, otherwise you'll get a warning [URL]
