Title

yii\db\mysql\QueryBuilder::upsert produce invalid SQL on upsert if all columns in table are unique

Description
Lets take a SQL table with 2 columns, which is composite primary key:

```sql
CREATE TABLE `blog_categ` (
  `categ_id` int(10) unsigned NOT NULL,
  `blog_id` int(10) unsigned NOT NULL,
  PRIMARY KEY (`categ_id`,`blog_id`),
)
```
Executing model upsert:
```php
static::getDb()->createCommand()->upsert(static::tableName(), $values, true)->execute();
```
Produce incorrect SQL error with empty UPDATE list:
```sql
INSERT INTO `blog_categ` (`categ_id`, `blog_id`) VALUES (2244, 139) ON DUPLICATE KEY UPDATE
```
The correct SQL will be:
```sql
INSERT INTO `blog_categ` (`categ_id`, `blog_id`) VALUES (2244, 139) ON DUPLICATE KEY UPDATE `categ_id`=`categ_id`
```
If all columns are unique, then QueryBuilder::prepareUpsertColumns return empty list of $updateNames and produce incorrect sql.  So, when $updateNames is empty, the behavior must be the same as when $updateColumns = false.

Small fix to yii\db\mysql\QueryBuilder::upsert($table, $insertColumns, $updateColumns, &$params)
```php
        --- } elseif ($updateColumns === false) {
        +++ } elseif ($updateColumns === false || empty($updateNames)) { 
```
Please, add this fix.
