Title

FragmentCache doesn't clean view's cacheStack on empty content

Description
When nested cache components has empty content parent component doesn't handle dynamic content.
Code from FragmentCache::run():
`if ($content === false || $content === '') {
                return;
            }
            array_pop($this->getView()->cacheStack);`

so when content is empty array_pop is not called.
Then:
`if (empty($this->getView()->cacheStack) && !empty($this->dynamicPlaceholders)) {
                $content = $this->updateDynamicContent($content, $this->dynamicPlaceholders);
            }`
and `empty($this->getView()->cacheStack)` returns false.
So i get unhandled dynamic placeholders in parent component.
