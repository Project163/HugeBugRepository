Title

`clearErrors` clears all nested errors unexpectedly

Description
**Describe the bug**

Recursive form with nested arrays, due to mount effect order, `clearErrors` runs on the root item last, and that appears to clear all nested orders as well.

**To Reproduce**
Steps to reproduce the behavior:

1. Go to [URL]
2. Click on console
3. Click on "Remove Condition"
4. Note: Error on root item
5. Click on "Add Logical Group"
6. Note: There should be an error on the most nested item, but it's cleared because root item `clearErrors` fires last (see console)

**Codesandbox link (Required)**

 [URL]

**Expected behavior**

Only the ErrorOptions at the specified path are cleared -- `{ type, types, message }` and if its an empty object, then it can be removed...

Suggest the above logic or adding opts as second param to `clearErrors(arg1, { exact: true })` for backward compatibility
