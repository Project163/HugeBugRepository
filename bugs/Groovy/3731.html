Title

grammar ambiguity with ternary expression being confused with safe indexing

Description
The following works fine in 2.5.9 and 3.0.1: 
  
 
 false  ? [ 'abc' ] : [ 'def' ]
 
  
 but the following onyl works in 2.5.9: 
  
 
 true  ? [ "abc" ]  as   String [] :  new   String [0]
 
  
 In 3.0.1 it gives: 
  
 groovy.lang.MissingPropertyException: No such property: abc for class: java.lang.Boolean
Discussion
- The ideal solution is to make  ?[   become a real operator, the side effect of the solution is that it may break existing code, e.g.  true? [1] : [2]  , but will not break  true ?  [1]  :  [2]  . Actually the latter is the recommended code style for ternary expression.
- Here is the workaround. Remember we can always eliminate ambiguities with parentheses. 
 true ? ( ["abc"]  as String[]) : new String [0]
- Is it reasonable to back out of safe indexing until this is looked into further?
