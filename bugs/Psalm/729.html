Title

Falsy UnusedVariable error

Description
Hello,
currently I'm trying to introduce the `findUnusedVariablesAndParams` feature to the [Link: Shopware platform].
Unfortunately I get and error  in some of our tests files which I cannot comprehend. They do all the same as the [Link: CartAmountRuleTest]
the error:
```
	ERROR: UnusedVariable - platform/src/Core/Checkout/Test/Rule/Rule/Cart/CartAmountRuleTest.php:18:9 - Variable $cart is never referenced
	        $cart = Generator::createCart();
	
	
	ERROR: UnusedVariable - platform/src/Core/Checkout/Test/Rule/Rule/Cart/CartAmountRuleTest.php:19:9 - Variable $context is never referenced
	        $context = $this->createMock(SalesChannelContext::class);
```

best regards from Schöppingen :wave:
Discussion
- It seems Psalm does not mark variables as used when they are used in a call to methods on mixed var (`$rule` is mixed there, as you omitted the return type in `AssignArrayTrait`). This is easily fixed with the following patch:
```
patch
diff --git a/src/Core/Framework/Struct/AssignArrayTrait.php b/src/Core/Framework/Struct/AssignArrayTrait.php
index c4a0d1e0b2..e9de27c1b6 100644
--- a/src/Core/Framework/Struct/AssignArrayTrait.php
+++ b/src/Core/Framework/Struct/AssignArrayTrait.php
... [Log Snipped] ...
     {
         foreach ($options as $key => $value) {
```
- Reproduced here:

```
php
/**
 * @psalm-suppress MixedAssignment
 * @psalm-suppress MixedMethodCall
 * @psalm-suppress MissingParamType
... [Log Snipped] ...
    $a->foo(new Exception($m));
}
```
