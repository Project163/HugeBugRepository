Title

Camel polling the files from S3 only once if deleteAfterRead is false

Description
if deleteAfterRead option is kept false while fetching all the files in the S3 bucket to linux machine, Camel polls all the files only once. I tried to debug org.apache.camel.component.aws.s3.S3Consumer.java class inside method poll() there is check for filesConsumed boolean variable which seems to be always true after the first polling and then it never access any files. 

 Same issue was reported  [URL] but the suggestion was to downgrade to 2.16.0 which has many different issues which got fixed in 2.17.0
Discussion
- Can you work on a patch to fix this?
- Have you configured the fileName option? What is the actual endpoint configuration you are using?  

 The one time polling only happens if you set the fileName. Its there to avoid polling the same file over and over again. That said I dont think the fileName option have so much value if it can only be used to poll a single file once.
