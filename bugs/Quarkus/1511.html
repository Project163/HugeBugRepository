Title

RR endpoints analysis treats subresource as JSON serializable entity

Description
### Describe the bug

During analysis phase declaring a resource method returning an subresource will result in a warning about missing JSON extension

### Expected behavior

Compilation should complete without warning because code is returning a subresource and not an entity to serialize

### Actual behavior

`WARN  [io.qua.res.rea.ser.dep.QuarkusServerEndpointIndexer] (build-56) Quarkus detected the use of JSON in JAX-RS method 'reactivedevmode.Resource#subresource' but no JSON extension has been added. Consider adding 'quarkus-resteasy-reactive-jackson' or 'quarkus-resteasy-reactive-jsonb'.`

### How to Reproduce?

Link to reproducer [URL]
mvn quarkus:dev to start

With 2.7.1 compilation will fail due to another error already fixed, but in console warning is present

### Output of `uname -a` or `ver`

### Additional information

Using the non-reactive version of Resteasy works without warning
