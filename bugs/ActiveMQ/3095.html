Title

Queue left StoreUsage object in memory. Memory leak

Description
Our services create queues on broker. It queues exists in 1 day then they become inactive, cause clients turned off. Active mq removes them by Inactivity timeout 60 seconds. But memory consumption of broker grows permanently. We acquired heap dump, and saw that org.apache.activemq.usage.StoreUsage contains 2.7 millions of object with 1.5 gb. That objects belongs to StoreUsage of queues.  

 I don't sure that we uses broker as it should be used. Maybe we shouldn't create new queues. But this behavior is stranged for me.
