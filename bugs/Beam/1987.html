Title

HCatalogIO.Read transform does not survive multiple serialization round trips

Description
The PartInfo from the ReaderContext loses state during serialization such that it can't be serialized again after deserialization. 

 When trying to upgrade to a newer version to see if the version was fixed, I ran into the following isseus: 
 
	 2.1.1 - 2.2.0: configuration issue "message:Version information not found in metastore." 
 

 
	 2.3.0 - 2.3.7: method not found error with jackson-databind since hive updated from Jackson 2.4.x to Jackson 2.6.x
