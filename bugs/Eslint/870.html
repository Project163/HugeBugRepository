Title

Unexpected parsing error with trailing comma in destructuring pattern

Description
**What version of ESLint are you using?**
v2.2.0

**What parser (default, Babel-ESLint, etc.) are you using?**
`"ecmaVersion": 7,`

**Please show your full configuration:**

```
"extends": ["airbnb"],
  "plugins": [
    "react",
    "import"  
  ],
... [Log Snipped] ...
    "jsx": true
  },
```

**What did you do? Please include the actual source code causing the issue.**

```
return Promise.all([
    getIsFoo(),
    getIsBar(),
    getIsBaz(),
  ]).then(([
... [Log Snipped] ...
    isFoo && isBar && isBaz
  ));
```

**What did you expect to happen?**
No linting errors.

**What actually happened? Please include the actual, raw output from ESLint.**
`Error - Parsing error: Trailing comma is not permitted in destructuring patterns`

From what I understand, the trailing comma _should_ be permitted in destructuring patterns. This seems like a bug. When adding the trailing comma, I then got the conflicting ``Error - Missing trailing comma. (comma-dangle)` (due to my eslint config), so there was no way to satisfy this condition. But more importantly, the trailing comma with destructuring should have been allowed.
