Title

PageDrawer does not take the full CropBox into account

Description
A client sent me a PDF which was basically a double-sided page of which only the right side was shown by the CropBox. But PDFBox displayed the left side in the PDFReader. I've created a minimal test case with FOP and a Hex Editor showing the problem. It seems as if the PageDrawer doesn't take the full CropBox information into account when painting the page.
Discussion
- I'm attaching a patch for this issue. I'd like a second pair of eyes before applying this. Also, because PDFBox has a problem with the TJ operator generated by FOP with a base 14 font active. But that's a different issue. Thanks.
- What version are you using? The latest trunk version (1003396) includes a fix for the extraction/rendering of text and one of the key issues was the handling of the TJ operator. See   PDFBOX-828   for further details.
