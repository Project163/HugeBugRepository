Title

The file consumer should use the charset encoding when reading the file if configured

Description
See   CAMEL-5215  . 

 This applies to the consumer as well. We should tighten this up, to ensure the charset is always used if configured. Currently the charset option could be shadowed if you did a convertBodyTo and specified another charset etc. 

 Also we should tighten up to use the charset configuration on the file endpoints. And added DEBUG logging which charset is being used for reading/write the files.
