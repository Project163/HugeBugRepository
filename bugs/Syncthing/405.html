Title

Weak hashing is extremely slow on ARMv8 (Android)

Description
```
[ZYPSC] 03:41:31 INFO: Single thread SHA256 performance is 559 MB/s using minio/sha256-simd (10 MB/s using crypto/sha256).
[ZYPSC] 03:41:33 INFO: Actual hashing performance is 84.14 MB/s
```

Weak hashing slows the actual hashing down almost an order of magnitude. It seems there is no hardware acceleration for it. I'm not sure what the requirements for a weak hash function are, but it could be much faster if it's hardware accelerated.

According to  `/proc/cpuinfo`, these features are supported:
```
Features        : fp asimd evtstrm aes pmull sha1 sha2 crc32
```

Maybe we can use one of those for the weak hash?

### Version Information

    Syncthing Version: v0.14.21
    Android Version: Android 7.0
    Device: LG G4 (Snapdragon 808)
