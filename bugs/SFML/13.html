Title

Xcode 4 templates don't always copy frameworks/dylibs

Description
The frameworks/dylibs are not always copied to the user application bundle directory when the project is build.

The following warnings are then printed when the application is launched (and don't start at all on system where SFML is not explicitly installed) :

```
warning: Unable to read symbols for @executable_path/../Frameworks/sfml-*.framework/Versions/2.0.0/sfml-* (file not found). 
```

see [URL] for more details.
Discussion
- If you created your project with an older version of the templates you still can apply this fix directly to your project. Follow instructions given here : [URL] .
