Title

PageCache: problem with DbDependency. [sql] is array instead of string

Description
I am still trying to use PageCache this time with yii\caching\DbDependency.
Get notice:
In file vendor\yiisoft\yii2\yii\db\Command.php
Array to string conversion. 
At line 414:

``` php
$message = $e->getMessage()  . "\nThe SQL being executed was: $rawSql";
```

Code I am using in controller:

```
php
public function behaviors() {
    return [
        'cache'=> [
            'class'=>yii\web\PageCache::className(),
... [Log Snipped] ...
        ];
    }
```

The same error happens when I use FragmentCache widget.

The problem probably occurs because yii\db\Connection::createCommand gets 
array instead of string in sql param
Discussion
- Could you check the content of `$rawSql`?
- Sure, here it is:

``` php
var_dump($rawSql);
```

```
array(1) { ["sql"]=> string(33) "SELECT max(time_modify) FROM post" }
```
- It's caused by the dependency class. Need to remove all constructors of dependency classes so that they can be instantiated by `Yii::createObject($dependencyConfig)`.
