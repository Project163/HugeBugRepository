Title

Bind IPC connections to kerberos UPN host for proxy users

Description
The IPC client will only bind to a kerberos UPN host for the effective user.  For proxy users, it does not bind to the authenticating real user's UPN host.  This is inconsistent and prevents strict host checking of connection.
