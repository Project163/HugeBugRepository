Title

Static variable breaks pure function (while static property does not)

Description
I'm not really sure what's the correct behaviour, so...

[URL] — this is an example, with two cases (both identical, but implemented slightly different). In the first case (`Number1::zero()`) a static property is used. Psalm doesn't show any errors here.

The second case (`Number2::zero()`) uses a static variable, and here Psalm raises "Cannot use a static variable in a mutation-free context" error.

IMO Psalm should be consistent in both solution and raise two errors respectively or be silent.
