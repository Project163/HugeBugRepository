Title

Cypress doesn't set cookies on 3xx redirects when they are cleared by the intermediary redirect

Description
In our tests, we do `cy.visit("localhost:8080/logout")`, which resets 2 named cookies and 303 redirects to `"localhost:8080/"`. The cookie sets are not happening correctly with cypress.

Here is an example request from Chrome which correctly sets the cookies.
[Image: image]
Discussion
- I'm able to reproduce. This will be fixed soon.
- Hi @brian-mann any update on the expected time of this fix?  I believe that this is blocking our company from upgrading to the 0.17.x branch which is a real pain since I'd like to pull in some of the new 0.17 features like custom mocha reporters.
- The problem here is that when cookies are cleared from the `jar` due to an intermediary redirect that these cookies which were "cleared" do not get properly set on the current browsing session and are therefore "lost".

Cookies which are updated or created during an intermediate redirect _are_ correctly handled, so this is only for cookies which were purged in between.
