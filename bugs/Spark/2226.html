Title

Remove highly unnecessary accumulators stringify methods

Description
def stringifyPartialValue(partialValue: Any):  String  =  "%s" .format(partialValue)
def stringifyValue(value: Any):  String  =  "%s" .format(value)
 
  
 These are only used in 1 place (DAGScheduler). The level of indirection actually makes the code harder to read without an editor. We should just inline them...
Discussion
- I see a  lot  of  string interpolation  uses in the codebase (grepping  '\bs\".*?\"' ), hinting at how this is probably a well-accepted alternative to  .format()  inlining. Should be easier to read.
- Yes, I think this is just because Spark started before Scala 2.10 and that's when interpolation was added  . I think we have been replacing uses of  format()  as we go. I'm happy to fix this one up if nobody's taking it.
