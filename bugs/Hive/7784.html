Title

HMS and HS2 needs to support keystore/truststores types besides JKS by config

Description
When HiveMetaStoreClient connects to HMS with enabled SSL, HMS should support the Keystore type configurable and default to keystore type specified for the JDK and not always use JKS. Same as   HIVE-23958   for hive, HMS should support to set additional keystore/truststore types used for different applications like for FIPS crypto algorithms. 
Also, make hive keystore type and algorithm configurable.
