Title

Handle invalid client id gracefully in Camel Box component

Description
Box component uses HtmlUnit to perform a login and authorization on user's behalf for OAuth. Box.com returns an error message instead of a login page on an invalid client id, which the component should handle gracefully, instead of the missing HTML element it throws currently.
Discussion
- Fix committed to master and camel-2.14.x, component now throws an IllegalArgumentException on invalid client id.
