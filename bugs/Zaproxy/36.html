Title

Exception when trying to add users before loading an authentication script

Description
Steps to reproduce the issue:
1. Run ZAP (2.4.2);
2. Open "Session Properties" dialogue, select "Authentication" panel and choose "Script-based Authentication";
3. Now select "Users" panel and try to add a user;
4. Note that nothing happens;
5. Check the log file, there should be an exception:

```
62346 [AWT-EventQueue-0] ERROR org.zaproxy.zap.ZAP$UncaughtExceptionLogger  - Exception in thread "AWT-EventQueue-0"
java.lang.NullPointerException
    at org.zaproxy.zap.authentication.GenericAuthenticationCredentials. (Unknown Source)
    at org.zaproxy.zap.authentication.ScriptBasedAuthenticationMethodType$ScriptBasedAuthenticationMethod.createAuthenticationCredentials(Unknown Source)
    at org.zaproxy.zap.extension.users.DialogAddUser.init(Unknown Source)
... [Log Snipped] ...
    at org.zaproxy.zap.extension.users.ContextUsersPanel$UsersMultipleOptionsPanel.showAddDialogue(Unknown Source)
    at org.zaproxy.zap.view.AbstractMultipleOptionsBaseTablePanel$1.actionPerformed(Unknown Source)
```

Remarks:
The user should be informed that it needs to select and load the script before being able to add the users.

ZAP Version:
Versions >= 2.3.0
