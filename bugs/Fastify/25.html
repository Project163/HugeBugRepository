Title

TS type defs for inject query is wrong

Description
## 🐛 Bug Report

after updating from fastify 2.12.1 to 2.13.0 the typescript definition for `fastify.inject` only supports a `string` for the `query` option.

## To Reproduce

Steps to reproduce the behavior:

Paste your code here:

```typescript
      const response = await fastify.inject({
        method: 'GET',
        url: `/myuri`,
        query: {
          param: 'value',
        },
      })
```
now throws a ts compiler error. Previously this was working fine.

The problem appears to stem from wrong typedefs in `light-my-request/index.d.ts` where query is defined as a string

```
typescript

  interface InjectOptions {
    url?: string | {
      pathname: string
... [Log Snipped] ...
    headers?: http.IncomingHttpHeaders | http.OutgoingHttpHeaders
 =>   query?: string
``` 
## Expected behavior

the above code should compile and work just as before.

## Your Environment

- *node version*: 12.13
- *fastify version*: >=2.13.0
- *os*: Mac
