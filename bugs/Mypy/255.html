Title

Confusing message if the wrong version of typed-ast is installed

Description
If I have the wrong version of typed-ast installed, mypy shows this message:

```
$ mypy x.py
You must install the typed_ast package before you can run mypy with `--fast-parser`.
You can do this with `python3 -m pip install typed-ast`.
```

It has a few issues:

* The pip command doesn't actually resolve the issue (`-U` is required).
* Unlike what the message says, `typed_ast` was installed, but I had the wrong version.
* `--fast-parser` is no longer required to use the fast parser.
