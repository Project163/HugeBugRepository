Title

Problems with inner enum

Description
I don´t understand the behaviour of inner enums. 

 class Mother { 
	String name 
	Mother.Child child 

 	enum Child 
{
		Franz,
		Ferdi,
		Nand
	}
 } 

 Without a package are all things fine. 
But when I use the package familie the groovy compiler have this problem: 

 unable to resolve class Mother.Child  
 @ line 5, column 2. 
   	Mother.Child child 
    ^
Discussion
- For the class generated for an inner enum with outer class having a package name, the class name was not getting set properly resulting in class resolution error.
