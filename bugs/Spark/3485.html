Title

Clarify the docstring for DataFrameReader.jdbc()

Description
The doc for the  properties  parameter  currently reads : 

 
         :param properties: JDBC database connection arguments, a list of arbitrary string 
                           tag/value. Normally at least a "user" and "password" property 
                           should be included.  

 This is incorrect, since  properties  is expected to be a dictionary. 

 Some of the other parameters have cryptic descriptions. I'll try to clarify those as well.
