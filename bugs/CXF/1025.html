Title

CXF does not create a Holder for the headers

Description
When the body part name attribute and the header part name attribute have the same name in the wsdl, CXF do not create holders correctly for headers causing an IllegalArgumentException when invoking service implementation. 

 Attached you can found a wsdl and xsds for that wsdl. 

 If you change header part name attribute to something different then it will work.
