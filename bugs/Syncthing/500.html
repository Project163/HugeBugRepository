Title

Un-ignoring a file that doesn't exist locally results in deletion on remote devices

Description
Reported by cosas in the forum: [URL]

Steps to reproduce:  
 1. Create ignore patterns
```
/foo
```
on device A.
2. Create file `foo/bar` on device B and make sure it is scanned and "synced" to A (creating the invalid file info).
3. Change ignore patterns on A to
```
!bar
/foo
```

Result:
`foo/bar` is deleted on B

Expected result:
`foo/bar` is created on A
