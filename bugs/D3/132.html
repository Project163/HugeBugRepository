Title

Color Transition (Chrome Version 41.0.2272.101 (64-bit)) Issue

Description
I noticed that transition for a background-color attribute does not work with some colors.

``` javascript

d3.select('svg')
    .transition()
    .duration(5000)
    .style('background-color', 'SteelBlue');
```

The color appears but does not transition
If you replace the color string to say yellow it does work as expected.

Kinda silly but still wanted to know if there was a reason this (bug) is occurring.
Has anyone ever seen this?
Discussion
- The starting value of the transition wasn’t explicitly specified, so D3 is using the computed value, as described in the [Link: Working with Transitions] tutorial. If that’s not what you want, you should specify a starting value explicitly (as described in the previous link). Please use Stack Overflow if you seek further assistance.
- Actually, I think there is a bug: detecting colour names should be case insensitive.
