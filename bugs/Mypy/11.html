Title

Disallow access to __init__ with statically typed receiver

Description
Type checker should not let code access the `__init__` method if the receiver has a static type. The reason is that subclasses can override `__init__` with an incompatible signature (`__init__` is different from ordinary methods).

This code should not be accepted:

```
class A:
    void __init__(self, int x): pass

a = A(2)
a.__init__(3)  # Should be a static type error
```

This was implemented in Alore, but it was lost at some point.

As an exception, it is valid to use super() to access `__init__` (we know the exact method to call).
