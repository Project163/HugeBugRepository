Title

NullPointException occurs if extendedBounds is not set and minBound/maxBound is called

Description
**Elasticsearch version** : 8.0.0

**JVM version** : 11.0.8

**OS version** : 18.04.1-Ubuntu

**Description of the problem including expected versus actual behavior**:
The methods `minBound()` and `maxBound()` in `HistogramAggregationBuilder` return double which leads to `NullPointException` if the optional `extendedBounds` is not set and these methods are called. A possible fix is to set the return type to Double.
[URL]

**Steps to reproduce**:

 1. Create a test that does not set the `extendedBounds`.
 2. Check for the values of `minBound` and `maxBound`.
 3. `NullPointException` occurs since the return type is primitive and `extendedBounds.getMin()`/`extendedBounds.getMax()` is null.
