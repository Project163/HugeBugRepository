Title

no-multi-spaces does not allow non-last function param to be commented-out

Description
Consider the following example:

```
function logAndCompare(a, b, c) {
    console.log(c);
    return a === b;
}
```

_listing 1.1 all params are used_

this is valid.
But if I want to temporarily comment-out the use of `c`, like this:

```
function logAndCompare(a, b, c) {
//    console.log(c);
    return a === b;
}
```

_listing 1.2: usage of the last param commented out_

I get noticed, that there's an unused param `c` and i get noticed by `no-unused-vars`. Reasonable.
Then I comment out the last param like this:

```
function logAndCompare(a, b/*, c*/) {
//    console.log(c);
    return a === b;
}
```

_listing 1.3: declaration of the last param commented out_

so I will remember what it was when I come back some days later to bring it back.

If I don't need `a` or `b` I will not get noticed by `no-unused-vars` since generally in JS the position of param does matter and it's required to define both `a` and `b` to be able to use `c`
If I ever wanted to comment out `b` the order of params will not be the same and when my function gets called `c` is now `b`.

For the AngularJS environment however position of function params is not as important as their names. With this in mind let's say my function is a service (i'm not using the annotated form on purpose - there's [Link: ngAnnotate] for that):

```
angular.module('foo').service('fooService', function (aService, bService, cService) {
    aService.doAStuff();
    bService.doBStuff();
    cService.doCStuff();
})
```

_listing 2.1: all injected services used_

If I want to comment out `aService` I'm aware that 'no-unused-vars' won't warn me:

    bService.doBStuff();
    cService.doCStuff();
})
```
