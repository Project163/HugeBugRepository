Title

enum constant initializer parsing

Description
can't compile enum constant initializer which contains method without explicit type declaration 

  
  enum  E {
  enConst {
    def foo(){}
  }
}
Discussion
- The same thing with fields of constant initializer
- An example showing the field case also: 
  
  enum  E {
  enConst {
     float  pi = 3.14
    void foo(){ println  "" +  new  Date() + "  " + pi }
  }
}
E.enConst.foo()
 
  
 If either the "void" or "float" types are changed to "def" we get a syntax error. A preceding "def" does not cause the issue but the grammar currently requires the type to be present regardless of whether "def" is found unlike other places in Groovy which allows "def" only.
- The following now works: 
  
  enum  E {
  enConst {
    @Lazy pi = 3.14
    def twopi = 6.28
    def foo(){  "" + pi + "  " + twopi }
     public  bar(){  "" + twopi + "  " + pi }
  }
}
 assert  E.enConst.foo() ==  '3.14 6.28' 
 assert  E.enConst.bar() ==  '6.28 3.14'
