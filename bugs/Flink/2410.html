Title

Accumulators are not UI accessible running in FLIP-6 mode

This error does not occur when running the same job in legacy mode.
Discussion
- the reason because of , SubtaskCurrentAttemptDetailsHeaders used url pattern :  

   
  
 
/jobs/:%s/vertices/:%s/subtasks/:%s
 
  
 but SubtasksAllAccumulatorsHeaders used url pattern :  
  
 
/jobs/:%s/vertices/:%s/subtasks/accumulators
 
  
 so it routed error. 

 consider the pattern : 
  
 
/jobs/:%s/vertices/:%s/subtasks/:%s
 
  
  used for  subtaskindex  

 I suggest we could replace the url pattern : 
  
 
/jobs/:%s/vertices/:%s/subtasks/accumulators
 
  
 to  
  
 
/jobs/:%s/vertices/:%s/subtasksaccumulators
 
  
 what's your opinion? cc  till.rohrmann  and  GJL
