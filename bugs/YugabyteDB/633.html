Title

[PITR] Reword error message to use the word `cluster` instead of `database`

Description
Jira Link: [Link: DB-632]
### Description

Steps to reproduce the Error:
- Create a tablegroup in the cluster
- Create a database
- Setup a snapshot schedule on the above database
This is the error message displayed: We must use the word `cluster` instead of `database` since the user has not created a tablegroup in the database and in order for a user to take a corrective action on this, cluster will be a more useful work in the message.

```
Error running create_snapshot_schedule: Not implemented (yb/master/catalog_manager_ent.cc:2503): Not allowed to create snapshot schedule when one or more tablegroups exist on the database
```
