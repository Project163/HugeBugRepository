Title

ItemDelegate has dependency to TreeImpl#NullLocation

Description
The item-delegate has a dependency to NullLocation which is a 
inner class of TreeImpl and as such is an implementation detail.
Discussion
- This is in effect a workaround for Java's missing support for deconstructing type hierarchies. The correct way to deal with this is through a visitor for tree location hierarchies. However, this seems to be quite an overkill here. Instead I suggest to either leave this as it is or replace it with another workaround and pollute the  TreeLocation  interface with a  isValid  method.
