- Подтверждаю.
При обновлении на одном проекте аналогично сломались редиректы после сохранения различных форм и даже авторизации.

Причина в этом обновлении [URL]

Чтобы повторить, достаточно добавить проверку `\Yii::$app->request->getIsAjax()`
Данный метод теперь всегда возвращает `TRUE`. Отрабатывает условие` ($origin !== null && $origin !== $this->getHostInfo())`
Далее по коду отслеживается, что проблема тут
```
 $secure = $this->getIsSecureConnection(); // возвращает всегда FALSE
 $http = $secure ? 'https' : 'http';
```

P.s. домен работает на HTTPS и серт действительный. На пред версиях проблемы с этим не было
