Title

behavior change in Camel 3

Description
Hello everyone, 

 I just noticed a behavior change when using the <threads> tag in Camel 3.x compared to Camel 2.x. 

 The code snippet is the following 
  
 
    <route>
        <from uri= "timer:foo?repeatCount=1" />
        <log message= "Before threads" />
        <threads poolSize= "5" >
            <log message= "In threads" />
        </threads>
        <log message= "After threads" />
    </route>
 
  

 In Camel 2.x, the "In threads" message is displayed which is not the case in 3.x. This is due to  this commit . 

 In fact in Camel 2.x the following snippet (defined in the documentation) doesn't work 
  
 
    <route>
        <from uri= "timer:foo?repeatCount=1" />
        <log message= "Before threads" />
        <threads poolSize= "5"  />
        <log message= "After threads" />
    </route>
 
  

 I don't know if the new behavior is the right one or not. It's either a bug in 3.x or a missing information in the  migration guide  (searched from "threads" but couldn't find anything). 

 Can you have a look? Thanks
