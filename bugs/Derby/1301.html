Title

Embedded ResultSet.getStatement() returns incorrect reference for dynamic result sets

Description
ResultSets returned as dynamic results sets, ie. those created in a java procedure and returned via the java.sql.Statement that executed the call of the procedure, do not return the correct statement reference for getStatement. Need to return reference to statement that executed the CALL and returned the ResultSet instead of the statement that performed the executeQuery.
