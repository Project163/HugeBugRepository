Title

Fatal error: Call to undefined method Memcached::quit()

Description
This isn't a bug with CodeIgniter but wanted to get it logged here in case someone searched for it, then they'll find a workaround. I'll post this in the forums, too.

I'm testing the 3.0.6 release and came across this error on all of my pages that use the Memcached caching driver.
release 3.0.6 of CodeIgniter added a destructor to the Cache_memcached.php driver that calls close() (if using the memcache) or quit() (if using memcached.) If you use a sufficiently old version  of the memcached PECL extension (such as EPEL's php-pecl-memcached RPM for RHEL6) then you will get this error message.

Cause: the quit() method was not added to the memcached PECL extension until version 2.0.0.
