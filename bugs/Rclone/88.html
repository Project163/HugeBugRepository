Title

Backblaze B2: large files continually re-uploaded during sync operation

Description
When filing an issue, please include the following information if
possible as well as a description of the problem.

I am trying to do an `rclone sync` of a local directory to the B2 service. Everything seems fine except for large files. There are several thousand files in this directory but only one that is over the large file limit (5GB) of the B2 api. Every time I run the `sync` operation the large file is re-uploaded. Also it seems like the large file is not uploaded to the correct path.

For example, the directory hiearchy I am sync'ing is `/files/photos` -> `BUCKET/files/photos`. The large file is `/files/photos/wedding-photos.zip` which should be uploaded to `BUCKET/files/photos/wedding-photos.zip` but instead it is landing at the root of the bucket: `BUCKET/wedding-photos.zip`.

Summary: The upload seems to complete OK, for what it's worth, it just ends up in the wrong place on the destination and is uploaded everytime a `sync` is run.

I am using the v1.30-21-g018fe80β build which I found in another thread about Backblaze bugs/imiprovements.
