Title

Asserts on array offsets have no effect on array type

Description
[URL]
```
php
 ' is more general than the declared return type 'array{0:Exception, 1:Exception}' for f

INFO: MixedTypeCoercion - 6:7 - The declared return type 'array{0:Exception, 1:Exception}' for f is more specific than the inferred return type 'array '
```
**Workaround**:
```php
    return [$ret[0], $ret[1]];
```
[URL]

So it appears offset types are inferred, but not propagated to the containing array.
Discussion
- After about four hours' work I've fixed for the special case where the array is `array ` (i.e. no further types).

Beyond that, it's a hard problem as Psalm only has two ways of representing arrays - generic (`array `) and objectlike (`array{somefoo:bar,otherfoo:bar}`). Objectlike arrays decompose to generic arrays whenever they're combined with generic arrays:

```
objectlike + objectlike => objectlike
objectlike + generic => generic
generic + generic => generic
```

In order to support the following, more refined example:

```
php
/**
 * @param array  $ret
 * @return array{0:InvalidArgumentException,1:InvalidArgumentException}
 */
... [Log Snipped] ...
    return $ret;
}
```

[URL]

I'd have to allow `objectlike` types to also have generic parameters, and that logic would be _super_ convoluted, so I'd really rather not.
