Title

[Transform] Malformed remote cluster causes checkpointing to hang

Description
[URL]

When `remoteClusterResolver.resolve(transformConfig.getSource().getIndex())` returns no results, the `ActionListener > listener` is never called, causing the Transform to be started but stuck in `indexing`.

Any subsequent call to the `stats` API will cause the API call to timeout and the transport task to hang indefinitely.

### Steps to Reproduce

- spin up cluster
- add `Sample Web Logs` sample data
- create a working transform:
```
PUT _transform/last-log-from-clientip
{
  "source": {
    "index": [
      "kibana_sample_data_logs"
... [Log Snipped] ...
  }
}
```
- create a failing transform:
```
PUT _transform/last-log-from-clientip-failed
{
  "source": {
    "index": [
      "*:blah"
... [Log Snipped] ...
  }
}
```
