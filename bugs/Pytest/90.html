Title

UnicodeDecodeError (INTERNALERROR) when doctests contain Unicode

Description
Originally reported by: **Jason R. Coombs (BitBucket: [Link: jaraco], GitHub: [Link: jaraco])**

---

Consider this test:

```
def foo():
    """
    'anything'
    """
```

Note that isn't the letter 'c' but instead Cyrillic 's'.

Save it as mod.py, then invoke `pytest --doctest-modules`. It will fail with this output:

```

platform win32 -- Python 3.4.2 -- py-1.4.26 -- pytest-2.6.4
collected 1 items

```
