Title

build: bring back log -n 1 for postgres build

Description
I missed the pathspec in the git command for getting the latest commit hash.  It's not just the latest commit; it's the latest commit that touches postgres files.  In case the latest commit didn't touch those files, the output for `git show` will be nothing, which is not what we want.  `git log -n 1` is fitting here.
