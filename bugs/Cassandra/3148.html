Title

commitlog segments may not be archived after restart

Description
commitlog segments are archived when they are full, so the current active segment will not be archived on restart (and its contents will not be available for pitr).
Discussion
- actually it's not just the current active segment; it could include any other segments for which archive is not complete at restart time.  No state is kept by the segment manager to record which have been archived and which have not. 

 Keeping this state in a system table would have the obvious problem that you need to replay the CL before you know which segments have not been archived yet.  (because of how pitr works, it would be much better to be able to archive before replaying.)  So it's a tough problem to solve.
