Title

Focus systems of bevy_ui break with nested focusable nodes

Description
## Bevy version

Main branch

## What you did

Run the following bevy app:
[URL]

## What you expected to happen

While a button is actively clicked (i.e. you're holding left mouse button), its `Interaction` component value should only be changed from `Interaction::Clicked` when you release the mouse button. Hovering other nodes should only affect those nodes and not the one that's actively clicked.

## What actually happened

Hovering over interactable nodes that are children of the button will make the clicked button lose its "clicked" state.

## Additional information

The child node doesn't have to have the `Interaction` component. Any node with the `FocusPolicy::Block` component value will break the hovering logic in this way.

This may seem like a weird use-case at first, but I noticed this while implementing a window-like widget in Bevy. If you're dragging the window's title bar around and you hover the window's close button (which is a child of the title bar), the dragging stops because the title bar loses its `Interaction::Clicked` value.
