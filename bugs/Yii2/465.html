Title

Formatter asDuration(0) returns nulldisplay instead of 0 seconds

Description
`Yii::$app->formatter->asDuration(0)` returns the `nullDisplay` variable. Is this by design or can we enhance the output to either `'0 seconds'` or `'<1 second'`.
Discussion
- I don't think it is by design, we do not have a test for it, so I would consider it a mistake that should be fixed. Can you send a pull request?
- Easy to fix, but what about the wrong values? Maybe we should throw a human-readable exception for all cases
