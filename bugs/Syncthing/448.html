Title

Hashed GUI password should not be rehashed

Description
Currently a config POST cannot set the password by hash. Posting something like

```
...
  "gui": {
    "password": "$2a$10$v9x2...",
    "user": "jb"
  },
...
```

will instead make the new password the hash (literally). I think it would be desirable to be able to post a GUI section from one device onto another and have the password actually work.
