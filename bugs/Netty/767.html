Title

OioWorker fails to fire channelConnected event for OioAcceptedSocketChannel

Description
In 3.3.x we introduced a regression which prevent the channelConnected event to get fired for OioAcceptedSocketChannel instances. This can "break" the OIO impl usage for some users. 

Beside this we also have a race in there which may lead to some events that will not get fired on a channel close.
