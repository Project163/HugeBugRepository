Title

"TypeError: Cannot read property 'id' of null" in SystemImportDependency

Description
I'm seeing SystemImportDependency throw an error with a module containing `System.import('missing')`:

```
$ cat input.js
System.import('missing')
$ ./node_modules/.bin/webpack input.js output.js
Hash:  
Version: webpack 2.1.0-beta.9
... [Log Snipped] ...
output.js
Cannot read property 'id' of null
```

The error is caused by `dep.module.id` in [SystemImportDependency.js:27:14
7](https://github.com/webpack/webpack/blob/v2.1.0-beta.9/lib/dependencies/SystemImportDependency.js#L27). The `missing` module doesn't exist, so `dep.module` is null.
Discussion

```
Time: 56ms
   [0] ./input.js 24 bytes {0} [built] [1 error]

... [Log Snipped] ...
output.js

```
