Title

Method type parameter resolved to class with anonymous inner class

Description
compiling 
  
  class  A {
   public  <R> void bar() {
    List<R> a =  new  ArrayList<R>() { };
  }
}
 
  

 fails with "Groovy:unable to resolve class R"
Discussion
- Note that the example doesn't really make sense: a placeholder at the method level is supposed to be used in the method signature itself. Here, it's neither used in the return type nor the parameters. This means that it's useless, as the compiler cannot infer its type.
