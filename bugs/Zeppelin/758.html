Title

GetUserList.getUserList leaks JdbcRealm connections

Description
GetUserList.java#241  is not closing the connections that it borrows from the datasource, preventing them to be returned to the connection pool (if one is used)
Discussion
- In order to fix this issue we just need to add JdbcUtils.closeConnection(con); to the finally block of that method. I will submit a PR.
