Title

Undefinded index when JOIN and indexBy

Description
When i try use this code

```php
Printer::find()->select(["concat(printer.name,' в ', o.name) name"])
            ->joinWith('cartPrinters c')->joinWith('auditories o')
            ->where(['c.id_cart'=>$this->id])
            ->indexBy('printer.id')->column();
```

rised exception


but in SQL all work normaly 


```sql
SELECT concat(printer.name,' в ', o.name) name, printer.id FROM `printer` LEFT JOIN `cart_printer` `c` ON `printer`.`id` = `c`.`id_printer` LEFT JOIN `printer_auditory` ON `printer`.`id` = `printer_auditory`.`id_printer` LEFT JOIN `auditory` `o` ON `printer_auditory`.`id_auditory` = `o`.`id` WHERE `c`.`id_cart`=45
```

When i try indexBy('**id'**)

```php
Printer::find()->select(["concat(printer.name,' in', o.name) name"])
            ->joinWith('cartPrinters c')->joinWith('auditories o')
            ->where(['c.id_cart'=>$this->id])
            ->indexBy('id')->column();
```

SQL rised exception
Discussion
- I solve this problem by use indexBy with callable

```php
Printer::find()->select(["concat(printer.name,' в ', o.name) name, printer.id"])
            ->joinWith('cartPrinters c')->joinWith('auditories o')
            ->where(['c.id_cart'=>$this->id])
            ->indexBy(function ($row) {
                return $row['id'];
            })->column();
```

But why **indexBy('printer.id')->column();** not working?
