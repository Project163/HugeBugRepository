Title

object-shorthand rule errors on getters and setters

Description
The following code generates an error with `"object-shorthand": [2, "always"]`:

``` js
var x = {
    get y() {},
    set y(z) {}
};
```

Did a little digging and `node.shorthand === false` for those, so maybe the rule should exclude nodes where are `node.kind === "get"` or `node.kind === "set"`.

Using version 0.21.1.
Discussion
- Makes sense. In the future, please be sure to include the exact output from ESLint when reporting an issue.
