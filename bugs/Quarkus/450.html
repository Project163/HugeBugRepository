Title

Kubernetes Extension and Secrets generates incorrect deployment file.

Description
**Describe the bug**

When trying to configure the generation of Kubernetes deployment file with secrets as volume, it ignores the properties.

**Expected behavior**

File should be generated correctly.

**Actual behavior**

Defaults are used instead of the configured ones. 

**To Reproduce**

```
kubernetes.env-vars[0].name=GITHUB_API_KEY_TOKEN
kubernetes.env-vars[0].secret=greeting-security
kubernetes.env-vars[0].value=github.api.key.token

kubernetes.mounts[0].name=github-token
... [Log Snipped] ...
kubernetes.secret-volumes[0].volume-name=github-token
kubernetes.secret-volumes[0].secret-name=greeting-security
```

The generated YAML file is:

```
yaml
spec:
        containers:
        - env:
          - name: "KUBERNETES_NAMESPACE"
... [Log Snipped] ...
            defaultMode: 384
            optional: false
```

Notice that readOnly configuration is ignored as well as secret-volumes configuration which is empty with defaults.
