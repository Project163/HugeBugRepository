Title

Implicitly enabled display of deprecation details is not disabled when it should be

Description
#### Configuration: XML
* `displayDetailsOnTestsThatTriggerDeprecations="true"` is not configured
* so the default of `displayDetailsOnTestsThatTriggerDeprecations="false"` is used
* `failOnDeprecation="true"` is configured

#### Configuration: CLI Options
* `--do-not-fail-on-deprecation` is used

#### Actual Outcome
* Details for deprecations triggered by tests are displayed

#### Desired Outcome
* Details for deprecations triggered by tests are not displayed
Discussion
- Of course, the same applied to all other `failOn*` and `displayDetailsOn*` as well as `--do-not-fail-on-*` configuration settings.
