Title

path.posix.relative returns different results for *nix and Windows versions of node

Description
* **Version**: 8.1.1
* **Platform**: Windows Server
* **Subsystem**: path.js

 

This code returns different values depending on whether run on *nix or windows:
```
path.posix.relative('a/b/c', '../../x');
'../../../..../x' // on windows
'../../../../../x' // on *nix
```
