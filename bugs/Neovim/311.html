Title

First byte of truncated double-width character is missing after syntax conceal with matchgroup

Description
### Neovim version (nvim -v)

v0.9.0-dev-530+gde90a8bfe5

### Vim (not Nvim) behaves the same?

No

### Operating system/version

Arch Linux

### Terminal name/version

kitty 0.26.5

### $TERM environment variable

xterm-kitty

### Installation

build from repo

### How to reproduce the issue

1. Run `nvim --clean`
2. Source the following file:
```vim
call setline(1, ['', repeat('a', &columns - 3) .. '<>个'])
setlocal conceallevel=2
syntax region foo matchgroup=NonText start=" " concealends
```

### Expected behavior

The `个` is shown correctly:
[Image: vim]

### Actual behavior

The first byte of the `个` is missing:
[Image: nvim]
Discussion
- This was fixed in Vim in patch 8.1.2153.
- This is also reproducible with extmarks:
```vim
call setline(1, ['', repeat('a', &columns - 3) .. '<>个'])
setlocal conceallevel=2
call nvim_buf_set_extmark(0, nvim_create_namespace('foo'), 1, &columns - 3, #{end_col: &columns - 1, conceal: ''})
```
- This case seems fixed in v0.10.
