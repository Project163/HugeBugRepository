Title

Shadowing api var in generated main.go

Description
## Problem statement
Shadowing `api` var in generated `main.go` if `go-swagger` was run with `--server-package=api`. This leads to failed compilation when call `go get -u -f ./...`.

```
# test/cmd/a-todo-list-application-server
cmd/a-todo-list-application-server/main.go:27:15: api.NewServer undefined (type *operations.ATodoListApplicationAPI has no field or method NewServer)
```

## Swagger specification
Any. I check spec from [Link: Simple Server tutorial]

## Steps to reproduce
1. Take swagger specification from [Link: Simple Server tutorial] as `swagger.yaml`
2. Call `go module init test` in same dir where `swagger.yaml` was placed
3. Call `swagger generate server --server-package=api`
3. Call `go get -u -f ./...`

## Environment
swagger version: 
```
version: v0.25.0
commit:  
```
go version: `go version go1.14.2 darwin/amd64`
OS: `macOS Catalina 10.15.6`
