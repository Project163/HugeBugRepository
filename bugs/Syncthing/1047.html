Title

Dial errors from previous disconnections are shown on paused devices

Description
### What happened?

Device B has been added to device A and vice versa.

Steps to reproduce:
1. Pause device B on device A (or shutdown Syncthing on device A)
2. Wait until dial errors show on device B's side
3. Resume device B on device A (or if you shutdown Syncthing, restart it on device A)
4. Wait until they reconnect
5. Pause device A on device B

Now you will see the same dial errors on device B that you saw after step 2, but they will never change or go away because we don't dial paused devices.

[Image: dial errors on device B's web GUI]

### Syncthing version

v1.29.7

### Platform & operating system

Linux amd64

### Browser version

Firefox 139.0.1, Chromium 137.0.7151.68
