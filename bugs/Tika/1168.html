Title

Text File identified as message/rfc822

Description
Text file containing the word Received: is identified as message/rfc22. 

 We were earlier using version 1.9 and it used to identify file type properly as text/plain. 

 Even if multiple lines are there, if one line with Received: is present, content type is incorrectly identified. 

 To check we can run java -jar tika-app-1.24.1.jar TextFileIdentifiedAsMessage.txt
