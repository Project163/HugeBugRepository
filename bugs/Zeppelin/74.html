Title

Tutorial notebook fails if fs.defaultFS is set to non-local FS in Hadoop core-site.xml

Description
I've noticed that if fs.defaultFS is set to a non-local FS (like HDFS) in the Hadoop core-site.xml, the Zeppelin Tutorial notebook will fail to find the example data because it will attempt to look in, for example, hdfs://master-node:hdfs-port/data/bank-full.csv instead of looking in the local filesystem, where the tutorial downloaded the data files just a few lines earlier.  This can be fixed by prepending the url with "file://" in the call to sc.textFile().
