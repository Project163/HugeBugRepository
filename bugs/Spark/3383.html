Title

RRDD faces with concurrency issue in case of rdd.zip(rdd).count()

Description
In Kmeans algorithm, there is a zip operation before taking samples, i.e.  [URL] which can be simplified in the following code: 

   zip.scala   
 val rdd =  ...
val rdd2 = rdd.map(x => x)
rdd.zip(rdd2).count()
 
  

 However, RRDD fails on this operation with an error of "can only zip rdd with same number of elements" or "stream closed", similar to the JIRA issue:  [URL]
