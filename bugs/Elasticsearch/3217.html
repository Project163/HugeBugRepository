Title

[ML] no error when updating num_threads in inference endpoint

Description
**Version:** 
9.2.0

**Step to reproduce:**

Right now, it is not allowed to update `num_threads` in inference API. ( [Link: code reference]). However, the update request still returns a successful 200 response, we should throw an error instead.

Requests:

```
PUT _inference/rerank/mytest
{
    "service": "elasticsearch",
      "service_settings": {
        "num_threads": 1,
... [Log Snipped] ...
      }
}
```

It returns:
```
{
  "inference_id": "mytesta",
  "task_type": "rerank",
  "service": "elasticsearch",
  "service_settings": {
... [Log Snipped] ...
  }
}
```
you can see it still has ` "num_threads": 1,`.  it should throw an error instead.
