Title

Mouse enabled hint only highlights first match

Description
With this simple hint:

```yaml
hints:
  enabled:
    - regex: foo
      action: Select
      mouse:
        enabled: true
```

And the following text in the grid:

```
foo foo
```

Only  the first `foo` will be highlighted on mouseover.

This does not seem to be an issue for the keyboard hints.
Discussion
- Huh, that's somewhat odd. This isn't an issue with the URL hint.
- I stand corrected actually: It seems like multiple URLs do **not** work correctly in all cases. The only thing that works is multiple URLs found through sub-matching as a result of `post_processing`.
