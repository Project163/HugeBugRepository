Title

circular definitions cause compiler to hang

Description
The following example causes the compiler to get into an infinite loop in `check_unique_interface_implementations`:

``` python
class A(A):
    pass
```

CPython gives the following error for the same case:

```
NameError: name 'A' is not defined 
```
Discussion
- For anyone interested in how I noticed it, this bizarre situation arises in the auto-generated stubs for `sched.Event`. The original code is along the lines of

``` python
class Event(namedtuple('Event', ...)):
    ...
```

This results in two classes called `Event` being defined in the `sched` module.
