- I feel this is the crux of the issue. Logically there are 3 seperate node types in play - a TextNode, a DataNode, and a CDataNode. Each are leaf nodes -- logically a TextNode (or DataNode) could not contain a CDataNode. Either the parser parses each individually (so perhaps if this were in a ` ` element, it might be TextNode, CData, TextNode, Cdata).

In a HTML parse, the contents of a ` ` are tokenized in the [Link: Script Data State]. There is no concept of a CData node. Only DataNodes or potentially HTML comments.
