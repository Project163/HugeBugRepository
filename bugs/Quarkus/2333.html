Title

Returing a file from Quarkus REST endpoint with `Uni` leads to Vert.x error now that Vert.x Pump was replaced

Description
### Describe the bug

I have a REST endpoint like this:

```
@GET
    @Path("/download")
    public Uni  download() {
        return Uni.createFrom().item(file);
    }
```
