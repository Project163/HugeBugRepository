Title

Invalid TestCaseOrderer not reported correctly

Description
If using a `TestCaseOrderer` attribute and the custom orderer isn't found, or throws an exception, it's not reported correctly. The console runner will sometimes throw a `NullReferenceException` if the type can't be found, but without a useful stack trace. Other times, it doesn't show anything. The Visual Studio runner just doesn't run the test, with no indication of why. Enabling diagnostic messages makes no difference.

The same happens for `TestCollectionOrderer`, except it gives a `NullReferenceException` in `OrderTestCases`.
