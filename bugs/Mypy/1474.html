Title

dmypy suggest gives wrong type (datetime vs datetime module)

Description
**Bug Report**

the suggestion from `dmypy` recommends `datetime` when it should suggest `datetime.datetime`

**To Reproduce**

```python
import datetime

def f(x):
    print(x.isoformat())

f(datetime.datetime.now())
```

```ini
[mypy]
check_untyped_defs = true
```

**Expected Behavior**

```console
$ dmypy run .
...
$ dmypy suggest t.f
(t:datetime.datetime) -> None
```

**Actual Behavior**

```console
$ dmypy run .
...
$ dmypy suggest t.f
(t.datetime) -> None
```

**Your Environment**

 

- Mypy version used: 1.15.0
- Mypy command-line flags: see above
- Mypy configuration options from `mypy.ini` (and other config files): see above
- Python version used: 3.13.1
