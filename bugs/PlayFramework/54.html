Title

Incorrect Filename when downloading from Play 2.6 application Ask Question

Description
### Incorrect downloaded filename

I downloaded [Link: Play 2.6 Scala Starter Example] from [Link: playframework.com].

Added route to `conf/routes`
```
GET     /readme                    controllers.AsyncController.readme
```
Added _Action_ to `app/controllers/AsyncController.scala`
```
  def readme = Action {
    Ok.sendFile(
      content = new java.io.File("README.md"),
      inline = false)
  }
```
When I try to `[URL] I'm expecting file **README.md** to be downloaded, instead I get **utf-8"README.md".
[Link: Related question on stackoverflow]


### Play Version (2.5.x / etc)

**2.6.0**

### API (Scala / Java / Neither / Both)

**Scala**

### Operating System (Ubuntu 15.10 / MacOS 10.10 / Windows 10)

**Windows 10**

### JDK (Oracle 1.8.0_72, OpenJDK 1.8.x, Azul Zing)

```
java version "1.8.0_131"
Java(TM) SE Runtime Environment (build 1.8.0_131-b11)
Java HotSpot(TM) 64-Bit Server VM (build 25.131-b11, mixed mode)

```
### Library Dependencies

**None**

### Expected Behavior

Downloaded filename should be **README.md**.

### Actual Behavior

Downloaded filename is **utf-8"README.md**.

Discussion
- There are these spurious characters (**utf-8''**) on line 410, **play.api.mvc.Results.scala"".
```
s"""$dispositionType; filename="$name"; filename*=utf-8''${UriEncoding.encodePathSegment(name, StandardCharsets.UTF_8)}"""
```
I removed those and checked with local build, and the file-name is proper.

The line needs to be changed to 
```
s"""$dispositionType; filename="$name"; filename*=${UriEncoding.encodePathSegment(name, StandardCharsets.UTF_8)}"""
```
