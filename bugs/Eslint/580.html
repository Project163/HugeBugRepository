Title

Rule "comma-dangle" does not apply to ES2015 import statements

Description
```
import { apple, orange, } from 'fruits';
```

does not trigger rule `comma-dangle": [ 2, "never" ]`.

I'm using the current stable version, 1.4.1.
Discussion
- Verified in the demo that all cases below are caught except `import`.

``` js
import { apple, orange, } from "fruits";
var c = [ 1, 2, ];
var d = { a: 1, b: 2, };
var [e, f, ] = c;
var { a, b, } = d;
```
- The same probably applies for the various export forms that include export specifiers.
