Title

[Bug]: Scoop pipeline does not write out .json file with --skip-publish

Description
### What happened?

When having a valid scoop config in the .gorelease.yml and running `goreleaser release --skip-publish` it should write the  .json file to the dist/ folder but not publish it. This is how the homebrew pipeline works and should be consistent with the --skip-publish flag according to the docs (user is resposible for publishing the produced files).

### How can we reproduce this?

Run `goreleaser release --skip-publish` in the goreleaser (this repo:s) top folder. A goreleaser.json is not written to the dist/ folder.
