Title

Commit a4697fd ("Make C++ archiving use action_configs instead of hardcoded flags") broke cgo builds in MacOS

Description
Starting with commit  , Bazel invokes `/usr/bin/libtool` with flags that aren't recognized in the MacOS version.

Old invocation (succeeds):
```
$ bazel build -s //vendor/gopkg.in/mgo.v2/...
[...]

```
