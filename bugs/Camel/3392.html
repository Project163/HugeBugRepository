Title

Redelivery doesn't work correctly on Dynamic Routers

Description
When redelivery occurs for dynamic routers, the properties are being kept. So if the dynamic router uses a property to store the current state such as used in example  [URL] , then the redelivery actually ends up skipping the endpoint that caused the exception 

 Here is my dynamic router class 
  
 public class Router {
	public String route(Exchange exchange) {
		Boolean invoked = exchange.getProperty("invoked", Boolean.class);
		if (invoked == null) {
			exchange.setProperty("invoked", true);
			return "mock:route";
		} else
			return null;
	}
}
