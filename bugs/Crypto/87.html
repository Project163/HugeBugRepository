Title

OpenSslCryptoRandom.isNativeCodeEnabled() throws if library cannot be loaded

Description
OpenSslCryptoRandom.isNativeCodeEnabled() currently throws an Exception if the native cannot be found. 

 This is wrong, because the static method should return false if native cannot be enabled (e.g. missing SSL dynamic library or wrong type)
