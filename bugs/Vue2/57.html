Title

node with v-show inside v-if is reused in the adjacent v-else

Description
### Vue.js version
2.1.6

### Reproduction Link

[URL]

### Steps to reproduce

Code

```html
  hidden content  
  visible  content  
```

1. `bln=true`, the `span` element in `el-if` is hidden

2. `bln=false`, the `span` element in `el-else` is __hidden__

### What is Expected?

When `bln=false`, the `span` element should be __visible__

### What is actually happening?

`patchVnode` will check the nodes is same:

```
js
function sameVnode (vnode1, vnode2) {
  return (
    vnode1.key === vnode2.key &&
    vnode1.tag === vnode2.tag &&
... [Log Snipped] ...
  )
}
```

Because the old vnode `vnode1.data` is 

```
js
{
  directives: [{
     def: {bind: fn, update: fn}
     expression: "false"
... [Log Snipped] ...
  }]
}
```

and the new vnode `vnode2.data` is

```js
{
  on: {click: fn}
}
```

So `sameVnode(span1, span2)` result  is `true`, but `updateDirectives` will be call `v-show` directive's `unbind` hook function.
