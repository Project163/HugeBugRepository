Title

Minor bug with mixin plus equal sign

Description
``` Jade
mixin foo
  block

bar = "baz"

+foo= bar
```

don't work.

However those two workarounds work well:

``` Jade
+foo
  = bar

+foo #{bar}
```
Discussion
- following also works well

``` jade
+foo:= bar
```

But hope it gets fixed someday, 'cause if you forget about ":", you wont see you block rendered.
