Title

@app, @webroot and @web not working in modules

Description
I have two modules admin and user. I need separate theme for each module. 
I am trying to change the user theme in module initialization but @app, @webroot and @web not working as expected. It works as string.

namespace app\modules\user;

class Module extends \yii\base\Module
{
public $controllerNamespace = 'app\modules\user\controllers';

public function init()
{
parent::init();

\Yii::$app->view->theme->pathMap = ['@app/views' => '@webroot/themes/basic'];
\Yii::$app->view->theme->baseUrl = '@web/themes/basic';
}
}
Discussion
- I think it is not fixed. When we access \Yii::$app->view->theme->baseUrl inside module, it returns @web/themes/basic
- What else do you expect?
- Is it possible to get theme->baseUrl inside theme/basic/layout file using \Yii::$app->view->theme->baseUrl
- @web not replaced with URL it just printing "@web".

eg: "link rel='stylesheet' type='text/css' href='@web/themes/basic/css/main_style.css' "
