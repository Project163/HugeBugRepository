Title

with_loader_criteria should be ignored for refresh

Description
contnuing from #5761 .   makes no sense for a with_loader_criteria() to apply to a refresh() operaion at all. 

```
from sqlalchemy import Column
from sqlalchemy import create_engine
from sqlalchemy import Integer

from sqlalchemy import String
... [Log Snipped] ...

```

SQL:

```
SELECT a.id, a.data 
FROM a 
WHERE a.id = ? AND a.data = ?

```

that's wrong, the option should be omitted, use a flag include_refresh=False.
