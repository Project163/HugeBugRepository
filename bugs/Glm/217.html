Title

glm::step doesn't work with scalars

Description
Using step with scalars won't compile:
```
glm::step( 0.0f, 1.0f )
```
Happens because glm::step is using glm::lessThan internally and lessThan has no scalar version in GLSL (and thus in GLM). Yet, glm::step has a scalar version in GLSL.

I'm not sure if this is intended or not, since the spec is quite ambiguous about this.
Discussion
- This issue is fixed in master branch.
