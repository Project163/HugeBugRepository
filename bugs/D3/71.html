Title

Pack layout overlaps circles when large variation in values.

Description
I am trying to create a pack layout - I am using the standard code, no additions.
Some of the circles seem to be overlapping. In the layout, group18 and group15 are overlapping (see 'Poland')
See the sample here : [URL]

If I remove the largest data item - Indonesia, it starts behaving well.  If I add more values, there are more similar problems.
Note that there is a lot of variation in the values - not sure if that is causing a problem.
Discussion
- It’s definitely related to the variation in the values. You can fix it by setting a minimum value of 7e7:

``` js
var pack = d3.layout.pack()
    .size([diameter - 4, diameter - 4])
    .value(function(d) { return Math.max(d.size, 7e7); });
```
- It seems more related to the large values.  I divided d.size by 1000000 and it seems to work.

var pack = d3.layout.pack()
    .size([r, r])
    .value(function(d) { return d.size/1000000; })
- Fixed in #1285 for 3.2.
