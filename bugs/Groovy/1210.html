Title

ClassCastException on every()

Description
The following code throws a ClassCastException  

 int[] a = [ 2, 2, 2, 2, 2] 

 println (1..4.every  
{ a[it] == a[0] }
  )
Discussion
- Range operator has a lower precedence here, so your code is becoming println (1..(4.every  
{ a[it] == a[0] }) ), which in turn becomes println (1..true), which is not correct. 
 
You need to use parentheses around the range and make it
  
  
   
int[] a = [ 2, 2, 2, 2, 2] 
println ((1..4).every { a[it] == a[0] }
  ) 
  
  
  

 For some relevant details of range operator precedence, see   GROOVY-254  .
