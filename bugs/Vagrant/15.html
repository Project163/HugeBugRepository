Title

Ansible provisioner with Docker provider

Description
Hi there,

If I'm using the Ansible provisioner in order to provision a box created using the Docker provider it fails with an SSH timeout.

It appears that the Ansible provisioner is attempting to SSH _directly_ to the target box rather than going via the intermediary host VM. This was seen via comparing `vagrant ssh-config` and the output of a verbose (`vvvv`) ansible run.

Thanks :smile:
Discussion
- I have been able to get Ansible connecting to the container via adding the following to my `Vagranfile`:

``` ruby
ansible.raw_ssh_args = ['-o ProxyCommand=\'ssh docker@localhost -A -p 2222 -i ~/.vagrant.d/insecure_private_key exec nc %h %p 2>/dev/null\'']
```

However, it appears to run extremely slowly. I guess this is more of a VirtualBox/container issue?
- @jabclab Thanks for reporting this problem and its workaround!

Indeed, when `@machine.provider_name == :docker && machine.provider.host_vm?`, the ansible provisioner should use the SSH ProxyCommand to pass through the docker host.

@mitchellh do you see a different/better approach?
