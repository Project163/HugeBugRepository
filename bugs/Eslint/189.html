Title

Fix site generation script

Description
The site generation script has an improper regular expression that rewrites `.md` extensions to `.html`. 

``` js
text = text.replace(/.md\)/g, ".html)").replace("README.html", "index.html");
```

The `.` in `.md` needs to be escaped so it doesn't match other characters.
