Title

Undefined reference to aligned_alloc on Win7 MSYS+Vulkan

Description
I'm in a Windows 7 64-bit system with MinGW, MSYS, Nvidia Vulkan drivers.

Current revision:  

Cmake:

```
cmake -G "MSYS Makefiles" -D BUILD_SHARED_LIBS=ON -D VULKAN_INCLUDE_DIR=/c/MinGW/include/vulkan/ ..
```

Make:

```
Scanning dependencies of target vulkan
[ 96%] Building C object tests/CMakeFiles/vulkan.dir/vulkan.c.obj
c:/Users/Colonel/Downloads/glfw/tests/vulkan.c: In function 'myalloc':
c:/Users/Colonel/Downloads/glfw/tests/vulkan.c:1671:5: warning: return makes pointer from integer without a cast
     return aligned_alloc(alignment, size);
... [Log Snipped] ...
make[1]: *** [tests/CMakeFiles/vulkan.dir/all] Error 2
make: *** [all] Error 2
```

The warnings happen when doing anything with Vulkan functions with MinGW, but Vulkan still works. However, it seems that `aligned_alloc` isn't implemented.

Since the files are being built to `./tests/`, I'm assuming that these are just tests that I can ignore, right?
Discussion
- The Vulkan loader import library is intended for Visual C++, which is causing the error. I don't know offhand how to resolve this and I don't have time to look into it right now. Sorry.

Yes, the tests directory can be safely ignored.
- You can create a compatible import library for the Vulkan loader DLL with [Link: dlltool] or (probably) link against it directly since the MinGW tools are smarter about that sort of thing.
- This is also a problem on Linux builds with GLIBC older than 2.16
