Title

inccommand: causes "E171: Missing :endif" - fails to parse one-line "if … endif"

Description
Given `t.vim`:

```
vim
set inccommand=split

fun! F(...)
  echom 'called: '.&buftype
... [Log Snipped] ...

call timer_start(3000, function('F'))
```

Calling `nvim -u t.vim` and quickly typing `:%s/` (before the timer times out) will result in:

```
called:                                                                            
Error detected while processing function F:
line    2:
E171: Missing :endif
:%s/
```

For some reason the `if … endif` gets not parsed properly in this case.

This happens with both `set inccommand=split` and `nosplit`, but not without inccommand.

Is this related to something similar to `-bar` for commands?!

NVIM v0.3.2-52-g9abe0bdb5 (master).
Also happens with v0.3.1.
