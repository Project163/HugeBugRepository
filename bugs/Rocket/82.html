Title

Limits in Rocket.toml not working

Description
**Description**

I was trying to config some limits in the Rocket.toml like:
```
[global.limits]
json = 104857600
bytes = 104857600
"PhactoryAPI.DispatchBlocks" = 104857600
```
Found it doesn't work.

It is because that rocket deserializes the Limits from a Figment with `figment::util::vec_tuple_map`:

[URL]

And later trying to binary search the enties in the limits would fail because the deserialized limits are unsorted .
