Discussion
- I figured out that the error arises from this line:

```
n_reassigns = min(to_reassign.sum(), X.shape[0])
```

If the number of clusters that should be reassigned is bigger than `X.shape[0]` then `n_reassigns` gets the value of `X.shape[0]` and the following assignment fails:

```
centers[to_reassign] = X[new_centers]
```

This assignment fails because the length of `new_centers` is different than the sum of `True` values in `to_reassign`.

This computation of `n_reassigns` was changed in [Link: `e3583da`] and I would suggest to change this computation back into:

```
n_reassigns = to_reassign.sum()
```

But I'm not completely sure about the reason for this change in [Link: `e3583da`], so maybe there is a better way to fix this bug.
- I screwed up that commit. Reverted it in master, thanks for looking into this (and sorry to keep you waiting).
- I wrote a test for this case in #3064, maybe you are interested in merging that in.
