Title

Confusing results w/ __filename and no-path-concat rule

Description
### Steps to reproduce:

``` javascript
// only start the server if the file is called directly, otherwise wait until
// module.exports is called.
if (process.argv[1] === __filename) {
  module.exports();
}
```

My .eslintrc file doesnt explicitly mention the `no-path-concat` rule, but running `$ eslint **/*.js` gives me the following error:

```
bash
$ eslint **/*.js

scripts/run_locally.js
  16:9   error    ['PORT'] is better written in dot notation                      dot-notation
... [Log Snipped] ...

✖ 4 problems
```
### Actual results:

### Expected results:

No warning. I'm not using `path.join()`, `path.resolve()` or `+`. I simply referenced the `__filename` global.
### Workaround:

Explicitly specify the `no-path-concat` flag in your .eslintrc file, although this is a bit brute-force and undesirable:

```
json
{
  "env": {
    "node": true
  },

  }
}
```
