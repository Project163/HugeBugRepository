- Thanks for the reproduction. It's very helpful in debugging in the issue.

We're now suspecting there's bug in the implementation of batching all reduces. We're still triaging the issue. As a workaround, could you try

```
tf.distribute.experimental.MultiWorkerMirroredStrategy(communication=
    tf.distribute.experimental.CollectiveCommunication.NCCL)
```

MultiWorkerMirroredStrategy can work with a single host. It has a different implementation of all-reduce which doesn't appear to have this issue. 

or

```
tf.distribute.MirroredStrategy(cross_device_ops=
    tf.distribute.NcclAllReduce(num_packs=0))
```

which disables batching.

Both seems work with your code snippet.
