Title

Incorrect Validation generated for object field Test API

Description
## Problem statement
I'm trying to express an object with a object field. That field allows keys of any name. Something like this...

```json
{
   "entree_choice": {
        "james": "Beef",
        "julia": "Vegan",
        ...
    }
}
```

The generated code contains an extra dereference that on line 75 that causes it to not compile. 

```shellsession
$ go build
# models
./my_first_object.go:75: invalid indirect of m.EntreeChoice[k] (type string)
```

Here's a yml spec.

Generated code
```
go
package models

// This file was generated by the swagger tool.
// Editing this file might prove futile when you re-run the swagger generate command
... [Log Snipped] ...
	return nil
}
```

## Swagger specification
```
yaml
swagger: '2.0'
info:
my test
... [Log Snipped] ...
            - Beef
            - Vegan
```

## Steps to reproduce
```shellsession
/usr/local/Cellar/go-swagger/0.7.4/bin/swagger generate model --spec=models/test.yml
cd models
go build
```
Discussion
- The fix to is remove an extra pointer deref on the line here.

```
		if err := m.validateEntreeChoiceValueEnum("entree_choice"+"."+k, "body", *m.EntreeChoice[k]); err != nil {
```
