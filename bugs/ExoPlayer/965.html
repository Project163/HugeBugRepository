Title

Android 13 requires runtime POST_NOTIFICATIONS permission for DownloadService notifications

Description
Reading though Android 13 changes, I've noticed that we now need to add `android.permission.POST_NOTIFICATIONS` in the manifest. 

As Exoplayer provides a [Link: `DownloadService`] should the next versions of Exoplayer/Media3 add this permission and implements something about it ?
Discussion
- I'm not sure if it's the right thing to do to add this permission to a manifest of the library that then is automatically merged into an app manifest. Not every app may use the `DownloadService`. 

I think an app that includes the `DownloadService` wants to add this permission, but I also think it  should be left to the app to do that. 

I agree though that we should add this permission to the `AndroidManifest.xml` of the main demo app as an example to do the right thing. Is this what you are asking for?
- It was an open question whether a comment should be added to the `abstract class DownloadService` in order to specify that if the permission is not asked for A13+ it won't prompt the notification. 
I agree that handling the permission should fall upon the app using `DownloadService, also yes the demo might need an update regarding this permission.
