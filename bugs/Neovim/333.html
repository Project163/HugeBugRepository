Title

`Ctrl+o` and `Ctrl+i` behave unintuitively when deleting buffers

Description
### Problem

I noticed that navigation with `Ctrl+i/o` is very weird after closing buffers that were part of the jump list.

To be honest, I'm not really sure if this is really a bug since `vim` behaves the same way and it seems to me like someone would have complained about this already if it was not intended behavior, but I couldn't find any issues or posts about this.

Regardless, this is something that really hinders my workflow (I use `oil.nvim` and every time I use it to navigate to a file it basically renders my jump list unusable) so I would really like to find a solution for my problem. 

### Steps to reproduce

I was able to reproduce this behavior with with `nvim --clean` on `0.10.0` and `stable`. I have added screenshots of the output of `:ju` in hopes of making it easier to follow.
