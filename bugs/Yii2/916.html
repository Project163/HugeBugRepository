Title

PHP notice when request param is incompatible with action argument type

Description
If a controller action argument specifies an `int` or `float` argument and PHP can’t convert the corresponding request param to that type, a PHP notice will occur.

### What steps will reproduce the problem?

1. Create a controller action with an argument that has an `int` type declaration.
    ```php
    public function actionTest(int $foo) {
        return 'hello';
    }
    ```
2. Send a request to that controller action, and set that param to a non-integer value, such as `foo=oops`.

### What is the expected result?

A `BadRequestHttpException` should be thrown.

### What do you get instead?

A PHP notice will occur:


### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.30
| PHP version      | 7.3.9
| Operating system | Ubuntu 18.04.1
