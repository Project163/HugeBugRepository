Title

Make function subtyping more flexible

Description
The following code is not accepted by the type checker, even though there seems to be no reason to reject the assignment:

```
func  f
def g(*a): pass
f = g # error
```

In general, a *arg in a callable type should be compatible with any number of fixed positional arguments (if their types are compatible).
