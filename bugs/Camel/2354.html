Title

camel-netty - Add option to enrich Camel message with client certificate details to make it easy to get these details

Description
Adding a new option  sslClientCertHeaders  which can be set to true, and then Camel Netty consumer will enrich the Message with headers that has the client certificate information out of the box. 

 This allows end users to get this details a bit easier, for example to be used in content based routing without having to code to get the details.
