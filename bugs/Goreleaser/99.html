Title

[Bug]: After Hooks Env (Pro) does not work as advertised

Description
### What happened?

Following [URL] I wrote a hook like this:

```

after:
  hooks:
  - cmd: "bash <(curl -s [URL]
    env:
      TAG_VERSION: "{{ .Tag }}"
      DOCS_VERSION: "{{ .Major }}.{{ .Minor }}"
```

Running `goreleaser check` though results in:

```
% goreleaser check    
   • running goreleaser v1.1.0-pro
   • loading config file       file=.goreleaser.yml
   ⨯ command failed            error=failed to load config: yaml: unmarshal errors:
  line 21: cannot unmarshal !!map into []string
```

### How can we reproduce this?

See above

```bash
1.1.0-pro
```
