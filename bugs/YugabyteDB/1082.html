Title

[YSQL] Test org.yb.pgsql.TestPgConnection#testConnectionKillsAndRestarts is unstable

Description
Jira Link: [Link: DB-9571]
### Description

Sometimes it fails with `java.lang.AssertionError: Expected connection to fail because we have exceeded the maximum`.
The reason is that the connection that is made to count existing connections is getting closed by the garbage collector, which may or may not happen while test is making more connections to take available slots. If connection is closed, there's room for one more connection.
We can explicitly close the connection to eliminate that random factor.

### Issue Type

kind/failing-test
