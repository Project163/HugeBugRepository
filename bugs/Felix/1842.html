Title

iPOJO Proxies strategy cannot be configured dynamically on Equinox and KF

Description
As equinox and KF takes a snapshots of the system properties before the startup of the framework, it's not possible to configure the proxies strategy of iPOJO dynamically using a system property using BundleContext.getProperty. An explicit call on System.getProperty has to be done.
