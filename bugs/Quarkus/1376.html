Title

Kafka Streams extension fails to compile with Kafka clients 3.0.0

Description
### Describe the bug

Quarkus application BOM doesn't have the Kafka client version 3.0.0 yet. 
When forced to be used with 3.0.0 KafkaStreams extension doesn't compile because of the removal of deprecated classes such as `PartitionAssignor` and `DefaultPartitionGrouper`

### Expected behavior

Kafka extensions should continue to work with Kafka clients version 3.0.0

### Actual behavior

_No response_

### How to Reproduce?

1. In kafka-streams-quickstart/producer, force dependency org.apache.kafka:kafka-clients:3.0.0
2. Compilation fails
