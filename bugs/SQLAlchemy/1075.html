Title

LegacyRow breaks column names used by abc.Sequence ('index', 'count')

Description
**Describe the bug**

`LegacyRow` inherits from `Row` which inherits from `abc.Sequence`. `abc.Sequence` has a method `index`. This means that if a table has a column named `'index'`, that cannot be accessed via `getattr`. Therefore 1.4 breaks behavior that worked in 1.3.

This is also true for columns named `'count'`.

**Expected behavior**

Attribute-based access should work for columns named `'index'` or `'count'`.

**Workaround**

It works if I use `__getitem__`-based access, i.e., `result['index']`.

**To Reproduce**

```
py
import sqlalchemy
engine = sqlalchemy.create_engine('sqlite:///:memory:')
metadata = sqlalchemy.MetaData(bind=engine)

... [Log Snipped] ...

print(" ".join([f"{finger}={getattr(result, finger)}" for finger in fingers]))
```

In 1.3:

```
thumb=3 index=1 middle=4 ring=1 pinky=5
```

In 1.4:

```
thumb=3 index=  middle=4 ring=1 pinky=5
```

**Versions.**
 - OS: macOS 10.15.7
 - Python: 3.7.3
 - SQLAlchemy: 1.3.6/1.4.0
