- I tried in MySQL, when input data is null, MySQL will use 0 as the seed 
  
 mysql> select rand(0);
+---------------------+
| rand(0)             |
+---------------------+
| 0.  |

mysql> select rand(NULL);

| rand(NULL)          |
+---------------------+
| 0.  |
+---------------------+
