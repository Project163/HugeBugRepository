Title

Memory leak in RoutingAppender for every hive operation

Description
Each new operation creates new entry in the ConcurrentMap in RoutingAppender but when the operation ends, AppenderControl stored in the map is retrieved and stopped but the entry in ConcurrentMap is never cleaned up.
Discussion
- Attached patch makes sure that entries in ConcurrentMap are removed when the operation is cleaned-up
