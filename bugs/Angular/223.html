Title

ValidatorFn not included in the src/common/forms barrel

Description
- **I'm submitting a ...**
- [x] bug report
- [ ] feature request

**Current declaration**

Building my own Form Validators, I found that there's no easy way to get the ValidatorFn interface, as it's not included in the barrel, so we need to import it like:

```
import {ValidatorFn} from 'angular2/src/common/forms/directives/validators';
```

**Expected/desired declaration**

It would be cool to have something like:

```
import {ValidatorFn} from 'angular2/common';
```

so we can easily define our own validator functions with parameters enabled:

```
export class MyValidator
{
  static myValidatorFunction(param: any): ValidatorFn {
    return (control: AbstractControl): {[key: string]: any} => {
      ...
    };
  }
}
```

please include it in the barrel :)

**Statement** 

I know this isn't a bug, but it would be nice if this have a little attention as it's easy to resolve. I would submit a pull request but I'm not familiar enough with any JS builds there.
Thanks in advance
