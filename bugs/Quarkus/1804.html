Title

build fail with --enable-preview and hibernate-orm

Description
**Describe the bug**
Build fails as soon as --enable-preview is passed to the maven-compiler-plugin compilerArgs

Affected quarkus versions (at least): 
1.3.2.Final
1.4.0.Final

**Expected behavior**
Build without fail

**Actual behavior**
Build failed or at least maven stacktrace + missing .class files


**To Reproduce**
Steps to reproduce the behavior:
1. Check out [URL]
2. configure JDK13
3. `./mvnw clean install`

```
[INFO] --- quarkus-maven-plugin:1.3.2.Final:build (default) @ enable-preview-fail ---
[INFO] [org.jboss.threads] JBoss Threads version 3.0.1.Final
[INFO] [org.hibernate.Version] HHH000412: Hibernate ORM core version 5.4.14.Final
[ERROR] [io.quarkus.hibernate.orm.deployment.HibernateOrmProcessor] Failed to generate build time Hibernate proxy definitions. This is a bug, please file an issue at [URL] and this stack trace.
java.lang.UnsupportedClassVersionError: Preview features are not enabled for org/acme/FooEntity (class file version 57.65535). Try running with '--enable-preview'
... [Log Snipped] ...
    at java.lang.Thread.run (Thread.java:830)
    at org.jboss.threads.JBossThread.run (JBossThread.java:479)
```

**Additional context**
Interesting thing is: `./mvnw clean compile quarkus:dev` works!

Possibly the `--enable-preview` flag is not passed from compilerArgs/jvmArgs on to the java compiler/runtime (whatever quarkus is executing) when running the `build` goal.

There are two hints to support this guess:
