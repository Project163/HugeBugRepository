Title

`import-error` when importing another module from same namespace

Description
### Bug description

After #6405, linting `b.py` below raises `import-error`, so long as the parent of `test` is on `sys.path`:

```
test
    a.py
    b.py
```
**a.py**
```python
"""This module is a"""
print("You are importing a")
```
**b.py**
```python
"""This module imports a"""
import a
```

### Configuration

_No response_

### Command used

```shell
pylint test/b.py
--or (no difference)--
cd test
pylint b.py
```


### Pylint output

```shell
************* Module b
test/b.py:2:0: E0401: Unable to import 'a' (import-error)

--------------------------------------------------------------------
Your code has been rated at 0.00/10 (previous run: 10.00/10, -10.00)
```


### Expected behavior

No msg, since `b.py` executes fine:
```shell
$ python3 b.py
You are importing a
```
