Title

Invalid link library for port simdjson found by find_library.

Description
**Describe the bug**
With cmake function find_library, it returns an invalid path for libsimdjson.a.

**Environment**
- OS: Mac OS

**To Reproduce**
Steps to reproduce the behavior:
1. ./vcpkg install simdjson
2. in my project CMakeLists.txt, add 
```cmake
find_path(SIMDJSON_INCLUDE_DIR simdjson)
message("SIMDJSON_INCLUDE_DIR: ${SIMDJSON_INCLUDE_DIR}")
find_library(SIMDJSON_LIBRARY NAMES simdjson)
message("SIMDJSON_LIBRARY: ${SIMDJSON_LIBRARY}")

target_include_directories(main PUBLIC ${SIMDJSON_INCLUDE_DIR})
target_link_libraries(main ${SIMDJSON_LIBRARY})
```
got output
```
SIMDJSON_INCLUDE_DIR: .../vcpkg/installed/x64-osx/include
SIMDJSON_LIBRARY: .../vcpkg/installed/x64-osx/debug/lib/libsimdjson.a
```
3. compile project and got linker failures
4. change the last line of CMakeLists.txt to 
```cmake
target_link_libraries(main .../vcpkg/installed/x64-osx/lib/libsimdjson.a)
```
5. compile project and it succeeded

**Questions**
With find_library(SIMDJSON_LIBRARY NAMES simdjson), it returned SIMDJSON_LIBRARY with value .../vcpkg/installed/x64-osx/debug/lib/libsimdjson.a which failed. And the path ".../vcpkg/installed/x64-osx/lib/libsimdjson.a" succeeded.
1. What's the difference between the two libs and why the first one fails?
2. Why the function find_library doesn't find .../vcpkg/installed/x64-osx/lib/libsimdjson.a?
