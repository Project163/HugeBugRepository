Title

Gradle "clean build" failure due to deprecated "junit-jupiter-migration-support"

Description
Tried to build master on my Mac but `:platform-tests:junitPlatformTest` failed.

```
Failures (1):
  JUnit Jupiter:AutomaticModuleNameTests:automaticModuleName(String):[3] junit-jupiter-migration-support
    MethodSource [className = 'org.junit.AutomaticModuleNameTests', methodName = 'automaticModuleName', methodParameterTypes = 'java.lang.String']
    => org.opentest4j.AssertionFailedError: `Automatic-Module-Name` not found in manifest of JAR: ../junit-jupiter-migration-support/build/libs/junit-jupiter-migration-support-5.0.0-SNAPSHOT.jar ==> expected: not  
```

* At SHA -  
* Build Scan: [URL]

## Reason

See [URL] for details

## Solution
Manually remove `junit-jupiter-migration-support` or use `git clean -d`
Discussion
- Known issue, working on it... see [URL]

Try a `gradlew clean build` to force all jars to be rebuild.

## fails

- `gradlew clean test`
- `gradlew clean check`


## works

- `gradlew clean :platform-tests:junitPlatformTest`
- `gradlew clean :platform-tests:test`
- `gradlew clean assemble test`
- `gradlew clean jar test`
- `gradlew clean build`

## possible solution

`junitPlatformTest.dependsOn project.subprojects.tasks["assemble"]` doesn't fix it. The jars of the 3 projects are still not being built:
- junit-jupiter-migrationsupport
- junit-platform-gradle-plugin
- junit-platform-surefire-provider
- Adding following lines to `platform-tests/platform-tests.gradle` seems to solve the issue.
```
junitPlatformTest.dependsOn(
  project(':junit-jupiter-migrationsupport').jar,
  project(':junit-platform-gradle-plugin').jar,
  project(':junit-platform-surefire-provider').jar
)
```

I guess, there's a more Gradle-y way to solve it.
