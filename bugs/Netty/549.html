Title

ChannelInitializer doesn't works properly for parent channel in ServerBootstrap

Description
Netty version: 4.1.3.Final, 4.0.39.Final

Context:
Initialization of parent channel handler using ChannelInitializer doesn't work properly for ServerBootstrap

Steps:

1) Create server using

```
    ServerBootstrap sb = new ServerBootstrap();
    sb.channel(...).group(...).childHandler(...).handler(ourHandler);
```

2) Create server using

```
ServerBootstrap sb = new ServerBootstrap();
    sb.channel(...).group(...).childHandler(...).handler(
        new ChannelInitializer () {
            @Override
            protected void initChannel(Channel ch) throws Exception {
... [Log Snipped] ...
        }
    );
```

Expected result:
`ourHandler` receives all lifecycle calls fine in both cases.

Actual result:
1. First exampe works fine, `ourHandler` receives `handlerAdded()` call and `channelRead` calls if we receive message from client.
2. In the second example, `ourHandler` receives `handlerAdded()` call and no any `channelRead` calls after that.

Tests reproduce bug: [URL]

`testParentHandler()` emulates first scenario and works fine
`testParentHandlerViaChannelInitializer()` emulates second scenario and fails
