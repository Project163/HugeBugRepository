Title

TCP port 0 is announced in the LAN beacon

Description
### Does your log mention database corruption?

No

### Include required information

There is code that end up making connections to tcp port 0 announced in the LAN beacon:

[URL]

That makes clients try to connect to TCP port 0, and firewalls log those attempts - this is the main annoyance of these undesired connections.

I think that port-0 has a special meaning changing to a proper port if using a Discovery Server, but I have Global Discovery disabled in my setup, only LAN discovery. In any case, I think that  port 0 should not be announced in the LAN beacon.

LAN Beacon announcement from tcpdump:
```

         ....

         :  2f30 2e30 2e30 2e30 3a30 1214 7175 6963  / :0..quic
         :  3a2f 2f30 2e30 2e30 2e30 3a32 3230 3030  :// :22000
         :  1880 d3c8 f4c2 bdf4 fb39                 .........9
```
