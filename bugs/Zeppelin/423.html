Title

Markdown table looks unsupported

Description
It looks the markdown table is not supported when using the markdown interpreter. 

 Concrete example: 

  
 %md
|| H1 || H2 ||
| a | b |
| c | d |
 
  

 The raw result is returned  
  
 || H1 || H2 || 
| a | b | 
| c | d |
 
  
 instead of a nice table like this 

 
  
 
  H1  
  H2  
 
 
  a  
  b  
 
 
  c  
  d
Discussion
- The markdown4j library doesn't support table syntax currently. ( [URL]

 Maybe we could implement a table plugin for markdown4j based on the existing work like  [URL]

 I think it would be more easier and reliable way to use well-managed markdown libraries such as pegdown if the license doesn't matter ( [URL]
