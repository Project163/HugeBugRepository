Title

Kubernetes 2.0 Spec

Description
Wanted to drop this here for testing and reference. As of commit 3da0b00 there are a few issues with building a client.

```
 models/integer.go:15: invalid receiver type Integer (Integer is an interface type)
models/unversioned_patch.go:15: invalid receiver type UnversionedPatch (UnversionedPatch is an interface type)
models/v1_capability.go:15: invalid receiver type V1Capability (V1Capability is an interface type)
models/v1_finalizer_name.go:15: invalid receiver type V1FinalizerName (V1FinalizerName is an interface type)
models/v1_persistent_volume_access_mode.go:15: invalid receiver type V1PersistentVolumeAccessMode (V1PersistentVolumeAccessMode is an interface type)
```

It's also important to note that a few objects had types of string in the spec but could be either string or int32 from kubernetes. I have added a simple workaround for this by removing the type information from the spec for:

```
HTTPGetAction#port
TCPSocketAction#port
ServicePort#targetPort #
```
