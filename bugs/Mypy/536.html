Discussion
- Mypy has special treatment of `assert isinstance(obj, ...)`, they work as runtime-checked casts, and are normally used to narrow types. In your case it actually widens the type. I would say, we should not widen type after an assert (unless I am missing some use cases).

Anyway, IIUC you should just do this:
```
python

So, I just want to make sure that `M` is only accepted for class `T` which returns objects of class `A` which could be an `MA` object. What you proposed looks like an acceptable solution.
