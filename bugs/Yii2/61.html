Title

BUG: in LinkPager, disabled button is still clickable

Description
In \yii\widgets\LinkPager::renderPageButton, disabled flag only adds CSS class, not prevents regular link from being generated.

IMHO should be: non-link tag and no href attribute for disabled button.
