Title

eslint run with --stdin does not correctly set the exitCode

Description
**What version of ESLint are you using?**
v3.0.1

**What parser (default, Babel-ESLint, etc.) are you using?**
default

**Please show your full configuration:**

**What did you do? Please include the actual source code causing the issue.**
cat file | eslint --stdin
echo $?

**What did you expect to happen?**
I expect 1 to be printed

**What actually happened? Please include the actual, raw output from ESLint.**
0 is printed

This is due to exitCode being set in a callback, but process.exitCode being set outside the callback and thus executing before exitCode is set.
I have a fix for this locally and would like to submit a PR.
