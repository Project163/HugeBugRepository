Title

No data in ObjectBrowser tables when started from groovyConsole or groovysh

Description
Open groovysh or groovyConsole. 
Evaluate a String, i.e. 
 '' 
('go' or Ctrl-Enter) 
bring up the ObjectBrowser 
('inspect' or Ctrl-I) 
-> the Browser comes up without data in the tables.
Discussion
- The problem is that the column model is being set, and then cleared when the table sorter model is installed.  We need to tell JTable to not auto-create a column model when the builder makes one.
- Thankfully solved by Danno Ferrin. 

 Tested manually in groovyConsole and groovysh.
