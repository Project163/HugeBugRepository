Title

Error while applying rule AggregateJoinTransposeRule

Description
AggregateJoinTransposeRule seems to cause errors. We have to investigate if this is a Flink or Calcite error. Here a simplified example: 

  
 select
  sum(l_extendedprice)
from
  lineitem,
  part
where
  p_partkey = l_partkey
  and l_quantity < (
    select
      avg(l_quantity)
    from
      lineitem
    where
      l_partkey = p_partkey
  )
