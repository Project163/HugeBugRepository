Title

setNotFoundHandler is suppressing duplicated routes checking

Description
When enabling setNotFoundHandler handler, Fastify is not performing a check for duplicated routes. This is an example:

```
javascript
const fastify = require('fastify')();

// Declare a route
fastify.get("/", function (request, reply) {
... [Log Snipped] ...
	console.log('Fastify app listening on port 3000!');
});
```

With setNotFoundHandler enabled I get "Fastify app listening on port 3000!", and I get "1" in the console.
It setNotFoundHandler is removed, I get "GET already set for /"

Thanks!
