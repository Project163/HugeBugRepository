Title

Documentation bug: StringUtils.split

Description
The documentation for StringUtils.split(String, String, int) contains wrong strings: 

 StringUtils.split("ab de fg", null, 0)   =  ["ab", "cd", "ef"]  
StringUtils.split("ab   de fg", null, 0) =  ["ab", "cd", "ef"]  

 This should read: 

 StringUtils.split("ab cd ef", null, 0)   =  ["ab", "cd", "ef"]  
StringUtils.split("ab   cd ef", null, 0) =  ["ab", "cd", "ef"]
