Title

The WS-SecurityPolicy TransportBinding does not respect the digest method of the algorithm suite

Description
The WS-SecurityPolicy TransportBinding does not respect the digest method of the algorithm suite. So if a SHA-256 digest policy is enabled, the signature digest method will still use the default SHA-1.
