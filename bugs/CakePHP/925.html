Title

Route::match ignores request _scheme and _port when _host option is defined.

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.5.5.
* Platform and Target: ubuntu 14.04 nginx, mysql

### What you did

Created routes in `routes.php` which contain the `_host` option.

### What happened

When `Router::url` is called two things happen:
 - Regardless of the value of the `$full` param, the host is prepended to the url
 - The `_scheme` and `_port` default to default values.

### What you expected to happen
 - The value of the `$full` param should determine if the host is prepended (but maybe there is a reason for this?)
 - The `_scheme` and `_port` should use the current request values
