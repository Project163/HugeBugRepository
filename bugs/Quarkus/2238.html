Title

REST request fails after adding maven dependency to quarkus-opentelemetry

Description
### Describe the bug

After adding the _quarkus-opentelemetry_ dependency to our maven project, we have experienced endpoints using URL prefix and a default empty path is failing.

If we don't use URL prefix we don't see the error, and this is currently our workaround.

Apparently the way URLs are evaluated in _quarkus-opentelemetry_ is different from _resteasy reactive_
I expect the solution to this issue is to use the same _getPathWithoutPrefix_ method both places.
