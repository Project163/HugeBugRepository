Title

Files missing one or more important parts of the file header DocBlock parts.

Description
The files listed in the following CakeBin URL
[URL]
are missing one or more important parts of the file header DocBlock parts.

I have identified those files by using the following shell "script":

``` bash
grep -R -Lc -e "* CakePHP(tm) : Rapid Development Framework (http://cakephp.org)" --include=*.php --include=*.ctp > grep1.txt;grep -R -Lc -e "* Copyright (c) Cake Software Foundation, Inc. (http://cakefoundation.org)" --include=*.php --include=*.ctp > grep2.txt;grep -R -Lc -e "* Licensed under The MIT License" --include=*.php --include=*.ctp > grep3.txt;grep -R -Lc -e "For full copyright and license information, please see the LICENSE.txt" --include=*.php --include=*.ctp > grep4.txt;grep -R -Lc -e "Redistributions of files must retain the above copyright notice." --include=*.php --include=*.ctp > grep5.txt;grep -R -Lc -e "* @copyright     Copyright (c) Cake Software Foundation, Inc. (http://cakefoundation.org)" --include=*.php --include=*.ctp > grep6.txt;grep -R -Lc -e "* @license       [URL] MIT License" --include=*.php --include=*.ctp > grep7.txt;cat grep1.txt grep2.txt grep3.txt grep4.txt grep5.txt grep6.txt grep7.txt | sort | uniq > greps.txt
```

The parts which are checked are:
`* CakePHP(tm) : Rapid Development Framework (http://cakephp.org)`
`* Copyright (c) Cake Software Foundation, Inc. (http://cakefoundation.org)`
`* Licensed under The MIT License`
`For full copyright and license information, please see the LICENSE.txt`
`Redistributions of files must retain the above copyright notice.`
`* @copyright     Copyright (c) Cake Software Foundation, Inc. (http://cakefoundation.org)`
`* @license       [URL] MIT License`

Due to the nature of how they are checked (literal), some reported file could have also have the checked string formatted somewhat differently.
