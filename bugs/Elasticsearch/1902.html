Title

FS-based repository does not honour readonly setting when restoring from a broken snapshot

Description
The FS-based repository does not honour the `readonly` setting when restoring from a broken snapshot (in fact, restoring a snapshot should not require any writes at all).

A write can currently happen, however, if the repository has missing index folders.

Reproduction scenario:

1) Create snapshot of an index
2) Remove the folder in the repository under `indices`
3) Try to restore the snapshot. This will try to recreate said folder.
