Title

Parts of translation are omitted in localize build, if HTML is nested

Description
# 🐞 bug report

### Affected Package
@angular/localize


### Is this a regression?

No


### Description

If I use the following code in the template:

```
 
   THIS PHRASE IS MISSING  my bold text  other phrase of this paragraph. 
 
```

The extraction (`npm run extract`) is fine and creates a xliff2 unit like the following:

```
 
       
         src/app/app.component.html:5,7 
       
       
... [Log Snipped] ...
       
     
```

In the translation file for french the target looks like that:
```
 
 THIS CETTE PHRASE EST MANQUANTE  mon texte en gras  autre phrase de ce paragraphe. 
 
```

After build with localize option the HTML output of the ng-container above is the following:

`  mon texte en gras  autre phrase de ce paragraphe. `

The part "THIS CETTE PHRASE EST MANQUANTE " was omitted.

Expected result of the localized build for french is:

```
 THIS CETTE PHRASE EST MANQUANTE  mon texte en gras  autre phrase de ce paragraphe. 
```

## 🔬 Minimal Reproduction
checkout: [URL]
run command: `npm install && npm run build -- --localize`
