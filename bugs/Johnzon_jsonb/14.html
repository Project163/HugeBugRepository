Title

JsonArray support is missing for ObjectConverter

Description
JsonArray support is missing for ObjectConverter. We currently only support ObjectConverters for JsonObjects.
Discussion
- It's now possible to apply @JsonbTypeSerializer and @JsonbTypeDeserializer to a Collection.

@JsonbTypeDeserializer(FooDeser.class)
 public  List<Foo> moreFoos =  new  ArrayList<>();
