Title

Invalid code after indented `# fmt: off`

Description
Input:
```py3
def x():
    # fmt: off
    return

def y():
    return
```

Invalid code produced:
```py3
def x():
    # fmt: off
    return

    def y():
        return
```
Discussion
- Is this supposed to work?

It leaves the file unchanged, but I would expect something like this

`in.py`
```
python
# fmt: off
def x():
    return pow(
2,3)
... [Log Snipped] ...
2,3
)
```

`out.py`
```python
# fmt: off
def x():
    return pow(
2,3)
    # fmt: on
    return pow(2,3)
```
