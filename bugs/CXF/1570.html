Title

cxf-utils.js missing from release zip file

Description
I downloaded apache-cxf-2.5.0.zip many moons ago. It had cxf-utils.js available in the 'etc' directory as advertised on  [URL] Version 2.5.0 is no longer available from  [URL] Version 2.5.6 is the latest 2.5.x release available for download. Version 2.5.6 does not have etc/cxf-utils.js. I need cxf-utils.js. I found cxf-utils.js in the source code distribution but cxf-utils.js should be available in the binary distribution. 

 I think cxf-utils.js is missing from the 2.6.x and 2.7.x releases as well.
Discussion
- It appears that the <directory> entry used in distribution/src/main/assembly/bin.xml is incorrect. 

 It currently is: 
        <fileSet> 
            <directory>../rt/javascript/src/main/resources/org/apache/cxf/javascript</directory> 
            <outputDirectory>apache-cxf-${cxf.version}/etc</outputDirectory> 
            <includes> 
                <include>cxf-utils.js</include> 
            </includes> 
        </fileSet> 

 The <directory> entry is incorrect and probably should be: 
            <directory>../rt/javascript-rt/src/main/resources/org/apache/cxf/javascript</directory>
- Incidentally, older releases are always downloadable here:  [URL] (link on the download page you gave earlier.)  Still, the problem you've given needs to get fixed.
- Fixed on all three branches, you'll see it in the next release--thanks for researching the problem for us!
