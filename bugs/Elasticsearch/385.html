Title

Network: A closed channel might not always fire up a close event

Description
For some reason, it seems like netty will not always fire up a proper close event on a channel, thus causing us to propagate it up the stack to treat a node as disconnected. It does throw a failure up the networking handlers in that case, which we catch. We should try and disconnect on those events as well...
