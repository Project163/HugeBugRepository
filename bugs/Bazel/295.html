Title

Module names for objc_libraries in external repositories importable because "@"s aren't removed

Description
When using `--experimental_objc_enable_module_maps`, the default clang module name given to external targets start with an `@` which is not possible to import in swift or objective-c (using `@import` syntax).

For example, the clang module for target `@SocketRocket//:SocketRocket` would become `@SocketRocket_SocketRocket`

Solution for this is to remove `@` from generated name
