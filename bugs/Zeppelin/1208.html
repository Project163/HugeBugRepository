Title

User notebook information is leaked through home page

Description
Steps to reproduce:  
 
	 Have at least two users and two browser sessions simultaneously, users A and B 
	 User A creates a notebook and navigates to the home page.  Their notebook will display 
	 User B creates a notebook and navigates to the home page.  Their notebook will display 
	 However, in User A's browser session, User B's notebook will display.   
 

 Note that notebook sharing is disabled.  This seems to be like some global state that websockets is mistakely updating.  More than that I haven't determined
Discussion


 Because the commented out line is not called or the equivalent, the new note list is that of the latest user to have the note list broadcast.  That is, if User A adds a note, all other users will see User A's list regardless of their own permissions.

 These are the steps that I also used to confirm that this is visible through websockets when using developer tools in Chrome and to see it in my Zeppelin homepage:
