Title

Create view fails when definition contains a materialized view definition

Description
View definition contains the materialized view definition as subquery: 
  
 
create materialized view mv1 as
select * from t1 where col0 > 2 union select * from t1 where col0 = 0;

explain cbo
create view v1 as
select sub.* from (select * from t1 where col0 > 2 union select * from t1 where col0 = 0) sub
where sub.col0 = 10
