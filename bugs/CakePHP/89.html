Title

Xml::build add escape amp

Description
When the method Xml::build receives XML that contains in a string with "&" the method fails. 
For example: 

```
  
  
               TOWN & COUNTRY   
  
```

To resolve this may be added the following code in the method (as [URL]

```
$input = preg_replace('/&[^; ]{0,6}.?/e', "((substr('\\0',-1) == ';') ? '\\0' : '&'.substr('\\0',1))", $input);
```
Discussion
- Your XML is invalid. `&` cannot be bare in XML.
- cdata to your rescue :)
