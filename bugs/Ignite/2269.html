Title

     Sql queries supports table alias.
- H2Indexing.generateQuery() method should provide correct column names in "SELECT" part of query. The correct way is analyze "FROM" part of query, choose suitable alias and rewrite "SELECT" part with correct alias. But it is not obvious how to choose right alias if multiple tables or subquery is present in "FROM" part. 

 Fix in PR allow alias to be provided as an argument.
