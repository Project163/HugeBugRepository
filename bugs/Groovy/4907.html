Title

CompileStatic does not detect type mismatch on "+="

Description
Hello, 

 I'm using Groovy 4.0.25 on OpenJDK 21. I'm using static compilation. It seems like the static typechecker is unable to find type issues related to the "+=" operator. I have a full self-contained JUnit test for you below. 

 In the test class, there are two test methods that check the output of the type checker. 

 Please note that "<number> += <string>" compiles without problems (and it really should report an issue here), but "<number> = <number> + <string>" produces the expected compilation issue.
