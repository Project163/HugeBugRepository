Title

The clear_cache API doesn't clear fielddata cache by default

Description
In 0.90.RC3, a call to clear the cache without specifying any options doesn't clear the fielddata cache, but it does in v0.20.6:

```
curl -XPUT '[URL]  -d '
{
   "settings" : {
      "number_of_shards" : 1
   }
... [Log Snipped] ...
}
'
```

In 0.90.RC3, a clear cache request without params:

```
curl -XPOST '[URL] 
```

The fielddata is not cleared:

```
curl -XGET '[URL] 

#             "fielddata" : {
#                "evictions" : 0,
#                "memory_size_in_bytes" : 120,
#                "memory_size" : "120b"
#             },
```

It is cleared when specifying `field_data`:

```
curl -XPOST '[URL] 

curl -XGET '[URL] 

#             "fielddata" : {
... [Log Snipped] ...
#                "memory_size" : "0b"
#             },
```

In 0.20.6, it is cleared even though `field_data` is not specified:

```
#             "cache" : {
#                "id_cache_size_in_bytes" : 0,
#                "field_evictions" : 0,
#                "field_size_in_bytes" : 0,
#                "id_cache_size" : "0b",
... [Log Snipped] ...
#                "filter_evictions" : 0
#             }
```

The docs [URL] say  "The clear cache API allows to clear either all caches..."
