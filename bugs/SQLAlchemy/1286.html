Title

add new construct OperatorExpression, is a ClauseList with a binary operator

Description
### Discussed in [URL]

if we have:

a + b

that give us BinaryExpression(a, b, operator.add).  If we do a + b+ c, that gives us BinaryExpression(BinaryExpression(a, b, +), c, +) and hence we start nesting as in #7743.

Years ago we had this come up and we gave someone some kind of function to flatten this out.

however, this can flatten automatically into a ClauseList by detecting BinaryExpression().same_operator(...) -> OperatorExpression.  this is ClauseList + ColumnElement,  we have this now already with BooleanClauseList so it would look mostly like that, except it does math operators also, we likely should use BCL and change its name.

The construction for BinaryExpression would need to check for same operator incoming and produce a single construct.  

this is not too hard and we can make it happen just for binarys that dont have anything else going on:

**tentative** 2.0 if this can go in later, it's not that involved.
