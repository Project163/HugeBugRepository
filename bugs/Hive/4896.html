- liwenhe ,  Spring , thanks for pointing this out. There was indeed a bug in the logic introduced in   HIVE-13639   to infer constant values that can be pull up from the Union. 

 I have just uploaded the fix, and I added the queries in the description to the testsuite.
- ... [Middle Discussions Snipped for Brevity] ...
- HIVE-13639   extended the logic to pull up predicates (and thus constants) through Union operators. 

 Originally, we were extracting them as a single disjunction of all the predicates in each input. For instance, for a Union with  n  inputs: 
  [pred1 OR pred2 OR ... predn]    

 Instead, we factorize and identify common elements: 
  [pred1, ..., predx, residualpred1 OR residualpred2 OR ... residualpredn]   
where  pred1, ..., predx  are common elements found in every Union input, while  residualpred1 OR residualpred2 OR ... residualpredn  are preds found only in input  1, 2, ..., n , respectively. 

 This helped us identifying more expressions to pull up, and reducing the complexity of doing so. However, there was a bug that was making us pull up expressions even if they had not been found in every union input. This patch fixes that issue.
