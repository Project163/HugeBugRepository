Title

[DocDB] Alter Universe Replication for multiple tables with bootstrapIds updates only 1 stream to ACTIVE state

Description
Jira Link: [Link: DB-1837]
### Description

When alter_universe_replication is used to setup replication for multiple tables along with bootstrapIds, only one of the streams is transitioned to 'ACTIVE' state. The remaining streams remain in 'INITIATED' state.

When bootstrap_cdc_producer is run for a set of tables, it internally creates CDC streams in 'INITIATED' state. Subsequently when alter_universe_replication is run for the tables, at the end of setting up the CDC streams, the streams are transitioned to an ACTIVE state. This is done by the UpdateCDCStream RPC for a given stream.

When multiple tables are involved in the ALTER, UpdateCDCStream is being invoked on a successful completion callback only after all the tables have setup their CDC streams.  In the ALTER case, this is invoked because the UpdateCDCStream is invoked upon successful completion of ALTER on all the tables, however the on success callback is associated with only 1 table/stream, so  only 1 stream gets transitioned to ACTIVE state.
