Title

--no-extensions CLI option only prevents extension PHARs from being loaded

Description
| Q                   | A
| --------------------| ---------------
| PHPUnit version     | 9.5.25
| PHP version         | 8.1
| Installation Method | Composer

#### Summary
the --no-extensions cli option does not apply to the ` ` element configured in the `phpunit.xml`

#### Current behavior
while passing the `--no-extensions` cli option, extensions configured in the [Link: extension element] of `phpunit.xml` are loaded when running phpunit.

i'm not sure whether this is intended behaviour or an oversight tho (happens here)
[URL]

minimal, self-contained test case to reproduce can be found over [Link: here]

the extensions configured in the extension element are not loaded like the ones from the `pharDirectory`
