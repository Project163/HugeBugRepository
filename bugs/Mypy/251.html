Title

Crash when class defined in method used for instance variable's type

Description
While thinking about [URL] I realized there's a similar case not involving NamedTuple (nor TypedDict):

- main.py:
```python
import crash
blah  # anything that triggers an error
```

- crash.py:
```python
class C:
    def f(self) -> None:
        class A:
            pass
        self.a = A()
```
This triggers a very similar crash in fixup.py when running `mypy -i main.py` **TWICE** (from a cold cache):
```
$ rm -rf .mypy_cache/
$ mypy -i main.py 
main.py:1: error: Name 'blah' is not defined
$ mypy -i main.py 
Traceback (most recent call last):
... [Log Snipped] ...
    assert '.' in head, "Cannot find %s" % (name,)
AssertionError: Cannot find A
```
