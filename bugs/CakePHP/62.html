Title

2.4.5: id changed in 2.4.5 (perhaps invalid DOM ids)

Description
if we have:

```
$users = array(
  "test@gmail.com" => "Test"
)
```

and use:

```
$this->Form->input('sendTo', array('type' => 'select', 'multiple' => 'checkbox', 'label' => false, 'options' => $users));
```

in CakePHP 2.4.4 we get:

```
   Test  
```

in CakePHP 2.4.5 we get:

```
   Test  
```

it seems to me that CakePHP 2.4.5 generates invalid ids ?
Discussion

```
The value must be unique amongst all the IDs in the element's home subtree and must 
contain at least one character. The value must not contain any space characters.
```
