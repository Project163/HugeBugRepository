Title

Watched fields are not updated after hot reload

Description
**Describe the bug**
Watched fields are not updated after hot reload.

**To Reproduce**
1. Given something along the lines of:
```
const {watch, register} = useForm();
const email = watch("email");
return (  
Email: {email} );
```

2. `Email: {email}` is updated to whatever value is entered in the input field. 
3. Edit the code to trigger hot reload
4. `Email: {email}` is no longer updated when editing ` `.
