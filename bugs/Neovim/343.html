Title

typing ". " in `:insert` swallows dot

Description
While trying to figure out how to insert "." literally using the :insert command, I found an inconsistenty between neovim and vim. (I still haven't figured out how)

- `nvim --version`: v0.4.4
- `vim -u DEFAULTS` (version: 8.2) behaves differently? yes
- Operating system/version: Manjaro Linux
- Terminal name/version: xfce4-terminal  
- `$TERM`: xterm-256color

### Steps to reproduce using `nvim -u NORC`

```
nvim -u NORC
:insert
. 
.
```

Please mind the space following the first dot.

### Actual behaviour

inserts " " into the buffer

### Expected behaviour

inserts ". " into the buffer
