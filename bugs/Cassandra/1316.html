Title

nodetool info reports inaccurate datacenter/rack for localhost

Description
The datacenter & rack information provided by 'nodetool info' is incorrect when using 'nodetool -h localhost info'. This is because the IP address passed to the EndpointSnitch to determine the datacenter & rack is sourced from the host parameter provided to nodetool and not the actual endpoint address used in the ring.
Discussion
- Attached patch resolves the issue by looking up the local endpoint's "real" hostname by token.
- "fall back if we can't find it for some reason" is shouldn't-ever-happen territory, right?  Would prefer to throw assertionerror, if so.
