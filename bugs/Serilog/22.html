Title

Loging byte array smaller than 1 Kb

Description
What is expected behavior for logging byte arrays smaller then 1 Kb?

When the file is smaller than 1 Kb I got value `"System.Byte[]"`. When the file is bigger than 1 Kb I got descriptive value, `" ... (2296396 bytes)"`, which is fine 

I taught that smaller than 1 Kb values should be logged as complete value? Am I doing something wrong?
