Title

mariadbconnector doesn't pass along query parameters in the url as arguments to connect method as mysqldb does

Description
While trying to ensure our codebase works with both connectors the first issue was that appending, in our case, `?unix_socket=/path/to/socket` wasn't having any effect while using mariadbconnector while mysqldb passes it as args to the connect method.

Both drivers are very similar and supports the same argument in almost all cases so I assume it would work fine just doing the same call in both drivers (or if that is not a desired usage deprecate passing it as url_params and document that it's prefered to pass it as explicit options to create_engine).

We can work around it either way but it feels like an unnecesary inconsistency.

I havn't checked the behavior of other dialects in this regard but the difference between these to is simply the call to `opts.update(url.query)` at 
[URL]

which has no corresponding call in mariadbconnector.
Just adding it here [URL]

works reasonably in my preliminary testing.
