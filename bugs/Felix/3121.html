- The problem here is that ComponentRegistry.m_componentHoldersByName can legally contain null values (via checkComponentName()), thus ComponentRegistry.getComponentHolders() will return a List containing null values – a situation getComponentHolders() and others do not account for nor is it documented in ComponentRegistry.getComponentHolders() API spec.
