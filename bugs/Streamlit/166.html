Title

Rerunning the session does not work inside callbacks

Description
### Summary

`st.experimental_rerun()` and `Session.request_rerun()` do not work correctly inside callbacks.

This is similar to [URL]

### Steps to reproduce
This report is based on `streamlit==0.89.0`.

#### Ver. 1
Code snippet:

```
py
import streamlit as st


text_value1 = st.text_input("input1")
... [Log Snipped] ...
text_value3 = st.text_input("input3")
st.write(f"text_value3={text_value3}")
```

1. Input texts to the `input1` and `input3`, for example, "aaa" and "ccc" respectively. Make sure the each input value is displayed throught `st.write()`.
2. Input a text to the `input2`, for example "bbb" and hit the enter key, which triggers `st.experimental_rerun()` in the callback function.
3. Then, **all the component values of `st.text_input()`-s are reset so that `st.write()`-s show empty values**.
    - Hey @whitphx Thanks for the report! Can you describe for me the use case for experimental_rerun inside a callback? Callbacks are triggered before the rerun, so, effectively, experimental rerun should not be needed.
- As you said, the code above was trivial examples.
The original problem was on my [Link: `streamlit-server-state`] library, described in [URL] and [URL]

This library reruns sessions via `ReportSession.request_rerun()`. Yes, it's hacky and uses a private API, so not worth supporting.
In addition, thanks to your statement "Callbacks are triggered before the rerun", I found a workaround for my library: [URL] so finally this became no longer a problem for my case.

---

However, as shown in the example above, this problem still exists with a public API `st.experimental_rerun()` and the example is possible code without any alerts.
So I think the ver. 1 code above is still worth considering to fix anyway.
- Thanks for the additional info @whitphx.

As `experimental_rerun` is still in the `experimental` namespace, a fix for this may not end up being the highest priority for us. However, taking a glance at the code, I think it should actually be pretty straightforward to do, so I'll see if I can get a fix out some time in the next few weeks.
