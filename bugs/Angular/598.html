Title

regression(compiler): new transformer pipeline breaks .tsx support

Description

## Current behavior
 

After introducing to new transformer pipeline based compiler (directly [URL] the compatibility for `.tsx` files are completely broken.

Currently compiler will generate an `app.component.tsx` file with content of `app.component.metadata.json` due to the failure of file rename. (https://github.com/angular/angular/blob/5.1.0-beta.1/packages/compiler-cli/src/transformers/program.ts#L341)

Update: The root problem is compiler [Link: reuse extension of source file for generated files], however, the generated files should always be `.ts` in AOT.

## Expected behavior
 

Angular compiler should support `.tsx` file as it used to be. (See [URL] easy to reproduce in 4.x)

## Minimal reproduction of the problem with instructions
 

1. Create a project: `ng new --minimal tsx-problem`;
2. Add `"jsx": "react"` to `tsconfig.json`;
3. Rename `app.component.ts` to `app.component.tsx`;
4. Run `ngc -p src/tsconfig.app.json`;

## What is the motivation / use case for changing the behavior?
 

Since Angular compiler is just an extension of TypeScript compiler, it should still support TypeScript functionalities. (And it was supported before using TypeScript transformer API)

And it's quite easy to fix (I will raise a PR to fix it).
