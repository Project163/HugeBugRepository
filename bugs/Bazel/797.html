Title

Cycle error when --platforms is not a platform

Description
### Description of the problem / feature request:

If you try to use a number of things as a platform, you get a massive garbage error from the cycle detector.

Examples include:
* `sh_binary`
* `rust_binary`
* `config_setting`

### Bugs: what's the simplest, easiest way to reproduce this bug? Please provide a minimal example if possible.

This can be reproduced in the repo at [URL] by running `bazel build //... --platforms=//:garbage` or even `bazel build //... --platforms=//:test`.
