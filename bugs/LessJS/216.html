Title

Container style queries unexpected space

Description
**To reproduce:**

[URL]

```less
@container style(--theme: dark){
  .main{
    color: #000;
  }
}
```

**Current behavior:**
There's a space between "style" and the bracket.
```less
@container style (--theme: dark)
```

**Expected behavior:**
No space  between "style" and the bracket.
```less
@container style(--theme: dark)
```

**Environment information:**
- `less` version: 4.2.0
