Title

Selection mode persists after commenting

Description
### Reproduction steps
1) Enter selection  mode with "v"
2) Press "j" multiple times to select several lines
3) Press a key sequence that is configured to comment line(s) of code
4) Press "j" or "k"
5) Observe that the selection mode is still on

### Environment
- Platform: Linux
- Helix version: v0.4.1-5-g4b5090a

I know that in recent version yanking resets mode to normal. Would be good if same happens after commenting lines.
