Title

MiniCluster::RestartSync causes No master address specified by ''

Description
On 2019-12-16, I found a cause for several occasional test failures on `PgMiniTest`: `MiniCluster::RestartSync`.  `PgMiniTest.BulkCopyWithRestart` and `PgMiniTest.DropDB*` encounter this.  A key message I found is

```
E1214 04:05:16.640359 23514 async_initializer.cc:83] Failed to initialize client: Invalid argument (yb/client/client-internal.cc:1431): Could not locate the leader master: No master address specified by '' (all master server addresses: [])
```

The message

```
2019-12-14 04:04:25.798 UTC [22576] FATAL:  the database system is starting up
```

seems to be a red herring as I got tests to pass while having it.
