Title

No monitors found on Windows XP guest on VMware

Description
This is a bit of a trivial issue (and is clearly related to running on a virtual machine) but I thought I would bring it up anyways. After calling glfwInit() on a Windows XP virtual machine the glfw error callback says "No monitors found". This happens before calling any OpenGL or other glfw functions so I believe this is not due to the obvious hardware rendering limitations of using a virtual machine but some problem actually getting the monitor.

**Steps to reproduce:**

Run the following code on a Windows XP virtual machine (vmware):

```
#include "GLFW/glfw3.h"

void error_func(int ec, const char* errStr);

int main(int argc, char *argv[])
... [Log Snipped] ...
    printf("\n %s \n",errStr);
}
```
