Title

Segmentation fault when trying to use secure-transport with curl 8.12.0 multissl

Description
### I did this

Configured and built curl with:
```
$ ./configure \
--with-secure-transport \
--with-openssl \
--with-default-ssl-backend=openssl
$ make
```

Ran curl and got:
```
$ CURL_SSL_BACKEND=secure-transport ./src/curl -q -s -v [URL] >/dev/null
Segmentation fault: 11
```

Then I rebuilt curl with `./configure --enable-debug ...`, the crash log shows:
```
Thread 0 Crashed:: Dispatch queue: com.apple.main-thread
0   ???                               0 + 0
1   libcurl.4.dylib                   multissl_init + 48 (vtls.c:918)
2   libcurl.4.dylib                   Curl_ssl_init + 68 (vtls.c:427)
3   libcurl.4.dylib                   global_init + 189 (easy.c:168)
... [Log Snipped] ...
6   curl                              main + 151 (tool_main.c:277)
7   libdyld.dylib                     start + 1
```

My guess: Does vtls.c:918 need the same `if(Curl_ssl->init)` test as vtls.c:426?

### I expected the following

Able to use secure-transport with multissl.
