Title

html content directly under body node not parsed correctly

Description
The html parser does not correctly parse content that is directly under the body node, when passing html like this: <html><body>This is my content</body></html>, an empty string is returned when calling BodyContentHandler#toString()
Discussion
- This was caused by the XHTMLContentHandler postponing the output of the XHTML prefix to when the first start tag inside the <body> is seen. 

 Fixed in revision 757747.
