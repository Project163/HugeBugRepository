Title

Layer sublayers have an invisible bounding box

Description
**Describe the bug**
The Pan Zoom demo currently has contained windows get stuck on the original container bounds in the north/west/northwest directions

**To Reproduce**
Steps to reproduce the behavior:
1. Go to egui.rs
2. Open the Pan Zoom window
3. Try to drag any contained window too far in any direction

**Expected behavior**
Sub-windows/sub-areas/sub-layers don't get stuck
