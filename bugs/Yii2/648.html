Title

Catched View exception still messes up page output

Description
Migrated from [URL]

### What steps will reproduce the problem?

1) Create web controller action:

```
php
    public function actionRender()
    {
        try {
            return $this->render('exception');
... [Log Snipped] ...
        }
    }
```

2) Create view file `exception.php` which throws some exception inside:

```php
 File Begin 
 
 File End 
```

### What is the expected result?

Fallback view rendered correctly

### What do you get instead?

Line ` File Begin ` from the view, which causes an exception appears at the top of the render result.

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.10

Discussion
- I am unsure if this actually can be fixed.
Obvious solution will be wrap `View::render()` internal code with `try..catch` block and call `ob_clean()` on exception.
However, output buffering may go deeper during single file rendering, in case such widgets as `ActiveForm`, `Spaceless` or `FragmentCache` are used.

We can clear all output buffering like it is done at `ErrorHandler::clearOutput()`:
[URL]
But this also may break application logic.
