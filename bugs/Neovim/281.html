Title

Terminal buffers with single quotes in cmd break session restoration

Description
- `nvim --version`:

```
NVIM v0.3.4
Build type: Release
LuaJIT 2.0.5
Compilation: /usr/local/Homebrew/Library/Homebrew/shims/mac/super/clang -Wconversion -U_FORTIFY_SOURCE -D_FORTIFY_SOURCE=1 -DNDEBUG -DMIN_LOG_LEVEL=3 -Wall -Wextra -pedantic -Wno-unused-parameter -Wstrict
-prototypes -std=gnu99 -Wimplicit-fallthrough -Wvla -fstack-protector-strong -fdiagnostics-color=auto -DINCLUDE_GENERATED_DECLARATIONS -D_GNU_SOURCE -DNVIM_MSGPACK_HAS_FLOAT32 -DNVIM_UNIBI_HAS_VAR_FROM -I
... [Log Snipped] ...

Run :checkhealth for more info
```

- Operating system/version: macOS 10.14.3
- Terminal name/version: iTerm2
- `$TERM`: `xterm-256color`

### Steps to reproduce using `nvim -u NORC`

```
nvim -u NORC
:terminal echo 'hello'
:mksession! | q
nvim -u NORC -S Session.vim
```

### Actual behaviour

```
Error detected while processing /Users/chris.larose/Session.vim:
line   22:
E116: Invalid arguments for function bufexists
E15: Invalid expression: bufexists('term://.//53492:echo\ \'hello\'') | buffer term://.//53492:echo\ \'hello\' | else | edit term://.//53492:echo\ \'hello\' | endif
line   51:
E171: Missing :endif
```

### Expected behaviour

nvim restores the session with the terminal buffer using the command specified in its buffer name

### Additional info

`Session.vim` contains this line

```
if bufexists('term://.//53492:echo\ \'hello\'') | buffer term://.//53492:echo\ \'hello\' | else | edit term://.//53492:echo\ \'hello\' | endif
```

The buffer name is

```
term://.//53492:echo 'hello'
```

So I think the desired line should read

```
if bufexists('term://.//53492:echo\ ''hello''') | buffer term://.//53492:echo\ \'hello\' | else | edit term://.//53492:echo\ \'hello\' | endif
```
