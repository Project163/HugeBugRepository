Title

Framework should provide service capabilities for registered services

Description
The Felix framework registers the following three service: 

  
 org.osgi.service.resolver.Resolver
org.osgi.service.packageadmin.PackageAdmin
org.osgi.service.startlevel.StartLevel 
  

 The OSGi specifications define the  osgi.service  capability (chapter 135.5), the framework should provide these capability for these services.
