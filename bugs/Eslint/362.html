Title

Node.js API modifies global defaults

Description
In ESlint v0.20.0, using `CLIEngine` modifies the `linter.defaults()` object or the passed-in `baseConfig` option directly before it is cloned.

```
javascript
var eslint = require('eslint');
var CLIEngine = eslint.CLIEngine;
var linter = eslint.linter;

... [Log Snipped] ...
new CLIEngine({format: 'compact'}).getConfigForFile('.');
console.log(linter.defaults().format);
```

The `getConfigForFile` call causes `format` to be reset. This logs

```

undefined

undefined
compact
```
