Title

“AssertionError: Cannot find component” for local NamedTuple inside class method

Description
**Crash Report**

This is a variant of #7281 that still crashes incremental checking on 0.910 and `master` ( ), both of which include #10432, which was supposed to fix #7281.

The difference in this case is that the local `NamedTuple` is defined inside a class method rather than a global function.

**To Reproduce**

```
sh
#!/bin/sh -eux

rm -rf .mypy_cache

... [Log Snipped] ...
echo 'import breaking' >script.py
mypy script.py
```
