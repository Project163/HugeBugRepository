Title

Global assert wrappers break preloading

Description
| Q                   | A
| --------------------| ---------------
| PHPUnit version     | 9.3.7
| PHP version         | 7.4.9
| Installation Method | Composer

#### Summary

When using PHP 7.4 with preloading, Composer and PHPUnit there is always a fatal error because the global assert functions of PHPUnit are included via preloading and via Composer for each script, leading to a cannot-redeclare-function error.

#### Current behavior + How to reproduce

Enable preloading in php.ini and use the autoload.php file from Composer as a preload file, which will automatically preload `PHPUnit\Framework\Functions.php`. Then load any PHP file which includes autoload.php from Composer and there will be this error:

```PHP Fatal error:  Cannot redeclare PHPUnit\Framework\assertArrayHasKey() (previously declared in /var/www/html/vendor/phpunit/phpunit/src/Framework/Assert/Functions.php:84) in /var/www/html/vendor/phpunit/phpunit/src/Framework/Assert/Functions.php on line 84```

This happens because the file is included again by composer and PHPUnit only checks the `__PHPUNIT_GLOBAL_ASSERT_WRAPPERS__` constant to check if the functions have been loaded, which is not set through preloading (only functions and classes are preloaded), yet all the functions are already permanently defined via preloading.

#### Expected behavior

PHPUnit could check if at least the first function is defined, or even if each function is defined in the file. Replacing

```php
if (!defined('__PHPUNIT_GLOBAL_ASSERT_WRAPPERS__')) {
  // function definitions
}
```

with

```php
if (!defined('__PHPUNIT_GLOBAL_ASSERT_WRAPPERS__') && !function_exists(__NAMESPACE__ . '\assertArrayHasKey')) {
  // function definitions
}
```

would already solve the problem and lead to preloading and PHPUnit working again when used together.
