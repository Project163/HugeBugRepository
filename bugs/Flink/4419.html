Discussion
- The issue is caused by when we create a file under the current user directory, we need to create the parent directory if not exists (in this case it is the current user directory), then 
 
	 path.getParent() returns the current directory, namely "." in this case. 
	 Flink Path object stores the path in a URI. However, according to  RFC-3986  Section, 5.2.4, "." and ".." will be removed when the path is stored, thus Path.toUri().getPath() will return "". 
	 When trying to create the directory, the Path is transformed into new File("") via  LocalFileSystem#pathToFile.   
	 Then the _  condition to judge if the directory creation is successful in _LocalFileSystem#mkdirsInternal , it will return false since  new File("").isDirectory()  returns false. 
 

 Therefore, when transforming the Path to File in the LocalFileSystem, if the path is "", we should return new File(".") instead, whose  isDirectory()  judgement returns true and also represents the current directory.
