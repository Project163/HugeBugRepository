Title

Description
This lua script causes redis (atleast 2.6.9) to segfault:

redis.call("SET", KEYS[1], struct.pack(("H"):rep(288), unpack(t))) 
t = struct.unpack(("H"):rep(288), redis.call("GET", KEYS[1]))
