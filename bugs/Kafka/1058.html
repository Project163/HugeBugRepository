Title

Connector target state changes not propagated to all workers

Description
Current handling of target state changes to a connector in DistributedHerder seems dubious. We don't appear to propagate changes to the worker unless it is running the connector itself, which means tasks running on separate workers will not be notified of state changes. This should have been caught with unit tests, but current coverage seems quite poor, so we should improve that as well.
