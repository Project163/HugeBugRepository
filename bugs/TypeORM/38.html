Title

postgres DATE hydrated as DATETIME object

Description
Similar to #49 the date string `2017-01-25` is getting converted to a js date object instead of a string formatted as a date. This incorrectly adds timezone information and localizes the time to midnight. 

output from postgres:
`2017-01-25`
expected js value:
`'2017-10-25'`
actual value:
`2017-01-25T00:00:00.000+8000`
Discussion
