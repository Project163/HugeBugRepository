Title

Watcher can stop on elder nodes during a rolling upgrade to 7.16

Description
When Watcher is upgraded to 7.16 it is possible that during the rolling upgrade Watcher gets stopped on the elder nodes and will not function until all the nodes are fully upgraded. There is a specific order of events that must happen for this bug to present itself (sometimes it works fine but other times it can stop Watcher) and once fully upgraded Watcher should be fully functional. 

This bug was discovered via the rolling upgrade tests and additional information can be found [URL]

- Here are my raw notes to track the requirements needed for Watcher to perform a rolling upgrade such that it will pass the validation check:

tl;dr
1) revert the Watcher changes from #80937 for 7.x (its fine to keep it for 8.x)
2) ignore `.triggered_watches, .watch-history-9, .watches` templates from the deprecation info API template check 
3) change the validation logic for 8.0 to avoid this mess in the future
4) remove the extraneous templates in `x-pack/plugin/core/src/main/resources` this includes watches-11.json, triggered_watches-11.json, watcher-history-[no-ilm]-[10|11].json
