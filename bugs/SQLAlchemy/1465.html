Title

Dataclass callable default no longer works in 2.0.16

Description
### Describe the bug

After upgrading SQLAlchemy 2.0.16 from 2.0.15, INSERT in mysql with DateTime type meet error "incorrect datetime value". I'm using the ORM API to define my tables, using seesion.add() and session.commit() to submit the orm object, seesion is created with scoped_session(sessionmaker(bind=engine)).
