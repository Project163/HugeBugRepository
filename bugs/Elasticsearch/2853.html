- In case this is useful: I managed to reproduce this issue on 8.5.1 from a clean install with a log4.properties file coming from 7.17.5. The AccessControlException are thrown at shutdown with the bundled JDK only and are not thrown when `Oracle Corporation/OpenJDK 64-Bit Server VM/18.0.2/18.0.2+9-61` is used.
- @tlrx This is helpful, and it promoted me to look again at WHY this started happening recently. In JDK 19, the reaper thread was changed to be an innocuous thread, see [URL] therefore its inherited ACC has no permissions ( where it previously inherited from whatever thread triggered its creation ).
