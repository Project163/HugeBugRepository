Discussion
- I think we have a greater problem with IDN coding. If I try to execute a request against  xn--- dtbqigoecuc.xn -p1ai   I get 
  
``` 
Exception in thread "main" java.net.UnknownHostException: поиск-слов.рф: Name or service not known 
``` 

 We normalize hostnames to Unicode internally and then feed the normalized host name to `InetAddress#getAllByName` that chokes on it. It looks like `InetAddress#getAllByName expects IDN encoded hostnames as input.
