Title

Sending an Empty MapMessage over HttpTransport fails with exception

Description
When sending a MapMessage with no body to a client that's connected via HTTP an exception is thrown when the message is unmarshaled from XML and the copy method is invoked.
Discussion
- The ActiveMQMapMessage command needs to implement the serialization method readResolve in order to ensure that the transient Map object is created on when the object is de-serialized from the XML stream.
