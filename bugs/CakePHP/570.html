Title

3.0 WidgetRegistry fail to load custom widgets

Description
Following [1], I did a plugin to customize my forms, but I found a odd behavior:

In AppController I've:

```
php
public $helpers = [
    'Form' => [
        'templates' => 'C3b3.forms',
        'widgets' => [
... [Log Snipped] ...
    ]
];
```

I think this syntax are correct (default FormHelper has a block like that), but the line '_default' cause a fatal error. When remove that line, the code ran, but my widgets are ignored (FormHelper are using default's one).

If I change block as below:

```
php
public $helpers = [
    'Form' => [
        'templates' => 'C3b3.forms',
        'widgets' => [
... [Log Snipped] ...
    ]
];
```

Widgets and __default_ just works, except 'datetime', where I can't use string sintax (constructor need Select as parameter).

I don't know if it is a WidgetRegistry or FormHelper issue. Or maybe a case for documentation in code or book. But my suspect is difference between WidgetRegistry::load and WidgetRegistry::add.
