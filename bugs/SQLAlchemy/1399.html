Title

Typing: Support MappedColumn in UniqueConstraint

Description
### Describe the typing issue

MyPy gives an error when passing a `Mapped` column to `UniqueConstraint`, even though it seems to work correctly at runtime.

A workaround is to pass strings instead, e.g. `UniqueConstraint("thing_one", "thing_two")`, although using the columns directly seems nicer.

I'd guess this might also apply to other constraints, and possibly other things too, although haven't looked into it.

### To Reproduce

```
python
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy import UniqueConstraint


... [Log Snipped] ...

    unique_constraint = UniqueConstraint(thing_one, thing_two)
```


### Error

```
test.py:9: error: Argument 1 to "UniqueConstraint" has incompatible type "Mapped[int]"; expected "Union[str, Column[Any], DDLConstraintColumnRole]"  [arg-type]
test.py:9: error: Argument 2 to "UniqueConstraint" has incompatible type "Mapped[int]"; expected "Union[str, Column[Any], DDLConstraintColumnRole]"  [arg-type]

```
