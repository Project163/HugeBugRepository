Title

Edge case in DEB package version

Description
**Describe the bug**
It appears that when using github actions to create a snapshot release, the output deb has the incorrect version:
```
Get:1 /src/dist/dive_SNAPSHOT-4c07245_linux_amd64.deb dive amd64 SNAPSHOT-4c07245 [4742 kB]
debconf: delaying package configuration, since apt-utils is not installed
dpkg: error processing archive /src/dist/dive_SNAPSHOT-4c07245_linux_amd64.deb (--unpack):
 parsing file '/var/lib/dpkg/tmp.ci/control' near line 2 package 'dive':
 error in 'Version' field string 'SNAPSHOT-4c07245': version number does not start with digit
Errors were encountered while processing:
 /src/dist/dive_SNAPSHOT-4c07245_linux_amd64.deb
```
Confirmed with dpkg:
```
dpkg -I dist/dive_*.deb

       1 bytes,     0 lines      conffiles
```
