Title

DataFrame.drop loses MultiIndex

Description
```
In [2]: df = DataFrame({'a': [1,2,3], 'b': [1,2,3], 'c': [4,5,6]})

In [3]: df.set_index(['a','b'], inplace=True)
Out[3]: 
     c
... [Log Snipped] ...
2 2  5
3 3  6
```

MultiIndex is gone! (2,2) and (3,3) are now plain tuples
