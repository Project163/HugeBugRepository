Am I making any sense at all?
- That is correct.  Rclone is doing translations of file characters on cloud storage systems that have restricted characters.

In this case it is Windows that has the restricted file name characters.  So if you download a file from google drive with 1.50 that has a `*` in then rclone will translate it into `＊` for windows.  It also does the translations in the other direction.

I think this is what you are seeing.

So you could rename the troublesome files on the google drive web interface from  `＊` to `*` etc and rclone syncing will work from there on with v1.50 (or you could get rclone to do it for you with --track-renames).
