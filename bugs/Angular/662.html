- I have ran into this bug as well. The router cannot parse URLs with a matrix parameter containing `(` or `)` in its value. Replacing them with `%28` and `%29` respectively fixes the problem invoking the application but when navigating inside the application and setting such a parameter, the characters remain unquoted.

I find this rather problematic because I couldn't come up with a good workaround. As soon as the `(` etc. appears in the browser's URL bar, I have a link that cannot be copied and pasted.
- I've tried a really wild solution as I read the comment from @dchacke.

As a workaround what about patching encodeURIComponent?
```typescript
const encode = encodeURIComponent;
window['encodeURIComponent'] = (component: string) => {
  return encode(component).replace(/[!'()*]/g, (c) => {
    // Also encode !, ', (, ), and *
    return '%' + c.charCodeAt(0).toString(16);
  });
}
```
It seems working for me, but I cannot predict the side effects of patching a global function.
