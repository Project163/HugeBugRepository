Title

Window cursor with negative colors

Description
## Subject of the issue

Whenever I try to load a window icon over the Windows platform, using a 32-bits PNG image, the resulting colors are inverted. I determined that the color format of the image I use is RGBA meanwhile the correct format for a window cursor is BGRA. I then inverted the colors through a loop that changes every pixel in the image and the problem was fixed.

In the documentation there's written that the required format is RGBA, but I find it wrong. I don't know if it's an issue related to how the Windows API manages cursors or if I'm totally wrong.

## Your environment

* Windows 10 x64 Version 10.0.17134 Build 17134
* SFML from git master
* Microsoft (R) C/C++ Optimizing Compiler Version 19.14.26433 for x64
* No special compiler flags
