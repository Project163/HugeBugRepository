Title

[docker]vcpkg install returns "A suitable version of git was not found (required v2.7.4)"

Description
**Describe the bug**
After a fresh install of vcpkg I run `./vcpkg install boost` and get the following output:

```
A suitable version of git was not found (required v2.7.4) and unable to automatically download a portable one. Please install a newer version of git.
```
My git version is fine:
```
bash-4.2# git --version
git version 2.23.1
```

The actual problem appears to be that no URL is provided for a git tool download in the [Link: scripts/vcpkgTools.xml] file and since I am not using the `-useSystemBinaries` when bootstrapping it never attempts my local git version in [Link: toolsrc/src/vcpkg/tools.cpp] because the git provider has no fallback.

Given vcpkg itself is downloaded using git could we not at least have a fallback to the git in path? The version check would still take place. This may make sense to add as a generic fallback to all of the providers in the case a local version cannot be downloaded. 

I've temporarily fudged this by running the following command: 

```
sed -i 's/get_path(paths, GitProvider())/{\"git\", \"0\"}/g' toolsrc/src/vcpkg/tools.cpp
```
which forces the use of my local git version.

**Environment**
- OS: Amazon Linux 2 (RHEL 7 equivalent)
- Compiler: GNU 7.3.1

**To Reproduce**
Steps to reproduce the behavior:
1. git clone [URL]
2. cd vcpkg
3. ./bootstrap-vcpkg.sh
4. ./vcpkg integrate install
5. ./vcpkg install boost
6. See error

**Expected behavior**
Boost libraries should install
