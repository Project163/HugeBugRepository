Title

Guides about JSON support misleading

Description
I went to [URL] trying to find how to write a JSON web client, so searched for `json` and only found [URL] which does not even mention a client.

My first impression was that we just did not support JSON web clients. We should make sure this never happens.

We need to make sure people find the rest client guide from the rest server guide, and vice-versa. Especially since the REST client guide at [URL] does mention the JSON dependency as a first thing. Both of these guides should point to each other, and the index page should make them both discoverable with the `json` term.
Discussion
- Is it really an issue?

In the TOC on the left of the guides page, you have:
 * Writing REST JSON Services
 * Validation with Hibernate Validator
 * Using the REST Client

That seems good enough to me.
- It's really not good enough. This works only for people who think "I want a client" but not for people who think "I need to call a JSON service". We have to make sure every kind of user finds our way in our documentation.
- @FroMage could you either create a PR or close this one? I don't think it's worth keeping it open for months.

Thanks.
