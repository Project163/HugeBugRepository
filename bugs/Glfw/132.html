Title

Command-tabbing issues with fullscreen windows

Description
I used the code directly from the HTML guide for creating "windowed full screen" windows to modify the Boing demo application.  Specifically, I replaced this line:
```c
   window = glfwCreateWindow( 400, 400, "Boing (classic Amiga demo)", NULL, NULL );
```
with the following code:
```c
   GLFWmonitor* monitor = glfwGetPrimaryMonitor();
   const GLFWvidmode* mode = glfwGetVideoMode(monitor);
   glfwWindowHint(GLFW_RED_BITS, mode->redBits);
   glfwWindowHint(GLFW_GREEN_BITS, mode->greenBits);
   glfwWindowHint(GLFW_BLUE_BITS, mode->blueBits);
   glfwWindowHint(GLFW_REFRESH_RATE, mode->refreshRate);
   window = glfwCreateWindow( mode->width, mode->height, "Boing (classic Amiga demo)", monitor, NULL );
```
The fullscreen window is created correctly and initially works fine, but problems ensue when command-tabbing from and then back to the Boing application.  First, when command-tabbing from Boing to another application, the fullscreen window is iconified rather than simply hidden.  Second, a number of issues occur when command-tabbing back to the Boing application: (1) the fullscreen window remains iconified and does not reappear; (2) when you click on the Boing application in the Dock, the fullscreen window is de-iconified, but then is immediately hidden (and remains hidden) leaving you with only the menu bar; (3) if you then click anywhere but the menu bar, the fullscreen window re-appears, but then is immediately iconified.

This, at least, is the general behavior.  However, if you repeatedly command-tab back to the Boing application (or try to activate it by clicking on its icon in the Dock), the fullscreen window will sometimes no longer re-appear at all.
