Title

Hang when using Redis as a cache provider on some configurations

Description
### Issue description

When using Redis as a cache provider, the app hangs when establishing a connection to the database.

### Expected Behavior

TypeORM does not hang.

### Actual Behavior

TypeORM hangs when trying to establish a connection to the database when using Redis as the cache provider.

This issue happens on :
- Debian 11 (using [Link: Node Source builds])
- Fedora 37
- Docker

This issue *does not happens* on :
- Arch Linux
- Fedora 38

Each run was done on a freshly installed virtual machine to get a clean environment.
