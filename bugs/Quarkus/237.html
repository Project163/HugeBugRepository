Title

Class not found when using java.time classes in @ElementCollection

Description
**Describe the bug**
I built a simple application with Quarkus 0.21.2 which uses hibernate orm panach to save a entity to a h2 database. The entity includes a ElementCollection of DaysOfWeek. I also created some tests to ensure CURD works. The tests all work fine but when I run them nativly I get the following exception:
```
Exception in thread "main" java.lang.RuntimeException: Failed to start quarkus
    at io.quarkus.runner.ApplicationImpl1.doStart(ApplicationImpl1.zig:126)
    at io.quarkus.runtime.Application.start(Application.java:91)
    at io.quarkus.runtime.Application.run(Application.java:204)
    at io.quarkus.runner.GeneratedMain.main(GeneratedMain.zig:34)
... [Log Snipped] ...
    at io.quarkus.hibernate.orm.runtime.service.FlatClassLoaderService.classForName(FlatClassLoaderService.java:37)
    ... 19 more
```

I wrote about this on StackOverflow before and got a Workaround and got quested to post it as a issue here too: [URL]

What I found strange as I tried the workaround was, that the text file with the used classes (`used_classes_events-service-1.0-SNAPSHOT-runner_20190917_084733.txt`) which was generated while creating the native runner already included the `java.time.DayOfWeek`. But the exception was only fixed when I added the workaround.

**Expected behavior**
Tests run successfully like the non native tests.

**Actual behavior**
The native tests errored with an exception.
