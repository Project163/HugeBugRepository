Title

Wrong template infer inheritance

Description
**EDIT**: see comment below, this isn't a problem with stubs, I can reproduce it on playground: [URL]

I'm creating a plugin with stubs, and I created a [Link: dedicated branch] for this issue.

The problem is with method [Link: `Identity::map()`].
It's the implementation from the interface [Link: Functor], which is another stub with the same signature.

Psalm doesn't recognize the return type as you can see from the CI (https://github.com/thomasvargiu/psalm-plugin-fantasy-land/runs/1376311199?check_suite_focus=true#step:8:50).

So, calling the following method with `fn (T): int` returns a `Functor ` instead a `Functor `.
```
php
/**
 * @template T
 */
interface Functor
... [Log Snipped] ...
    public function map(callable $function) : Functor;
}
```

The weird thing is that if I remove the docblock from the the [Link: original interface file] it works as expected.
