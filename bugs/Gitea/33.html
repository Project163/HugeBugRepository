## Description

The repository order feature works fine but I find it a little bit confusing. By default, the order is made on "Most recent" which means "Most recently **created**". But in the repository listing, there is only the last modification date which doesn't match the order.
A tiny improvement would be to add a label like so:

```
Created: 2 month ago - Updated : 2 days ago
```
I think I would be more understandable.
