Title

IdleVerify hangs when called on inactive cluster with persistence

Description
When you call  control.sh --cache idle_verify  on inactive cluster with persistence, control script hangs and no actions are performed. As you can see below in 'rest' thread dump,  VerifyBackupPartitionsTaskV2  waits for checkpoint start in  GridCacheDatabaseSharedManager#waitForCheckpoint . 

 It seems, that we can interrupt task execution and print message in control script output, that IdleVerify can't work on inactive cluster.
