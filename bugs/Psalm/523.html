Title

Diff ignores new suppressions in code

Description
In the last few releases of Psalm, there is a regression bug where running Psalm with both types of diff enabled, will ignore newly added suppressions that you put directly in the code, such as:

```
/**                                                                                                                                     
 * @psalm-suppress MixedMethodCall                                                                                                      
 */
```

This is how I am running Psalm: `psalm --diff --diff-methods --show-info=false`
I tried deleting the temporary files, but the problem comes back again (immediately or delayed, I can't remember..). Here is another way of explaining it. Let's say you run that command and it shows an issue. If you then go to that line of code and add the suppression above it, and then run that command again, it will still report that issue.

I will try to do some more testing and edit this report as I get more information, as well as try to narrow down exactly which release introduced the bug.
Discussion
