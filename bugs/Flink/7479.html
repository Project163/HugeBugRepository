- Thanks  macdoor615  for reporting this. When we create the  RestClient , we load all the configuration options, but when we create the rest server, we only load the  EndpointOptions . As a result, the client will enable SSL, but the server does not. I will fix this asap.
- Hello. In the embedded mode, we always assume the started gateway is only visible to the current client. I think it's not a big problem to enable SSL or not.
