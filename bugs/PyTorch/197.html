Title

Update RuntimeError message in `is_nonzero(input)` method from `bool` to `Boolean`

Description
### 📚 The doc issue

Should we update the Error message that we are supposed to get in the following case:
```python
t = torch.tensor([])
torch.is_nonzero(t)
```
or 
```python
t = torch.tensor([1,2])
torch.is_nonzero(t)
```

Error message in documentation:
- for case 1: `RuntimeError: bool value of Tensor with no values is ambiguous`
- for case 2: `RuntimeError: bool value of Tensor with more than one value is ambiguous`

Error message produced in actual code:
- for case 1: `RuntimeError: Boolean value of Tensor with no values is ambiguous`
- for case 2: `RuntimeError: Boolean value of Tensor with more than one value is ambiguous`
