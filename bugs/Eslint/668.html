Title

Bug: Handle comments in comma-spacing

Description
Right now, `comma-spacing` doesn't correctly handle comments.

This should not error:

``` js
myfunc(404, true /* bla bla bla */, 'hello');
```

And this should be valid:

```
js
        {
            code: "myfunc(404, true/* bla bla bla */ /* hi */, 'hello');",
            output: "myfunc(404, true/* bla bla bla *//* hi */, 'hello');",
            errors: [
... [Log Snipped] ...
            ]
        }
```
