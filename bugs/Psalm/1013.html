Title

Template with nullable constraint does not work as expected

Description
When Psalm encounters a nullable type, it is able to correctly understand it is not null if it evaluates to true.

For example Psalm will not complain `echo` possibly called on null in this case:

```php
/** @var string|null $var */
if ($var) {
  echo $var;
}
```

However when using nullable template constraint this is not true.

Note that even using Psalm assertions to tell Psalm the templated type is not null does not help.
