Discussion
- Hmm, the show_mapping config item is defined as hidden in the configurator as it is not normally the sort of thing you want configured permanently, you just use `--crypt-show-mapping`.

[URL]

So I think it shouldn't have shown the `show_mapping` at all in the configurator but it returning is probably due to the fact it is marked as hidden.

What do you think the best solution for this is?
- don't show the hidden values at all?
- allow editing of the hidden values if they are set?
- something else?
- Thanks for your response.

I agree, at least for my use case, that there is little reason to have it on permanently and showing it only if set may result in confusion, so I would vote for option 1 - don't show the hidden values at all.
