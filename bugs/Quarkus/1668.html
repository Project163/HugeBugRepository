Title

quarkus-integration-test-liquibase-mongodb fails in native with latest GraalVM 22.3-dev build

Description
### Describe the bug

`liquibase-mongodb` quarkus integration test fails with latest GraalVM CE dev build in native mode with:

```
========================================================================================================================
GraalVM Native Image: Generating 'quarkus-integration-test-liquibase-mongodb-999-SNAPSHOT-runner' (executable)...
========================================================================================================================
[1/7] Initializing...                                                                                    (8.8s @ 0.32GB)
 Version info: 'GraalVM 22.3.0-dev Java 17 CE'
... [Log Snipped] ...
Caused by: java.lang.ClassNotFoundException: org.osgi.framework.BundleActivator
	... 49 more
```

### Expected behavior

Native image build works.

### Actual behavior

Native image build fails with: `java.lang.ClassNotFoundException: org.osgi.framework.BundleActivator`

### How to Reproduce?

Steps to reproduce:

1. Download the latest 22.3.0-dev GraalVM CE build. For example from here: [URL]
2. Use it as `GRAALVM_HOME`
3. Run the `liquibase-mongodb` integration test:
```
pushd integration-tests
../mvnw --fae -pl 'liquibase-mongodb' -Dnative -Dtest-containers -Dmaven.test.failure.ignore=true -Dstart-containers -Dnative.surefire.skip -Dformat.skip -Dno-descriptor-tests  -Dlog.level=ALL clean verify
popd
```

Discussion
- This is also reproducible with just `liquibase` (no mongodb):

```
========================================================================================================================
GraalVM Native Image: Generating 'quarkus-integration-test-liquibase-999-SNAPSHOT-runner' (executable)...
========================================================================================================================
[1/7] Initializing...                                                                                    (7.5s @ 0.31GB)
 Version info: 'GraalVM 22.3.0-dev Java 17 CE'
... [Log Snipped] ...
[ERROR] For more information about the errors and possible solutions, please read the following articles:
[ERROR] [Help 1] [URL]
```
- [URL] seems to be the reference that's triggering this.
- Proposed fix in #27366
- Relevant code in Liquibase core looks like this:

```
rootScope.values.put(Attr.osgiPlatform.name(), Activator.OSGIContainerChecker.isOsgiPlatform());
```

That triggers loading of the `Activator` [Link: class] which implements `BundleActivator` et.al.
