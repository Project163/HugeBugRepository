Title

other_bucket_key does not implicitly set other_bucket => true

Description
**Elasticsearch version**: 5.0.2

**Plugins installed**: []

**JVM version**: 1.8.0_66

**OS version**: Mac OS X 10.12.1 (Sierra)

**Description of the problem including expected versus actual behavior**:

During a "filters" aggregation, setting the ```other_bucket_key``` does NOT implicitly set the ```other_bucket``` option to true, as mentioned in : [URL]

**Steps to reproduce**:
 1. Create a "filters" aggregation
 2. Set ```other_bucket_key``` option to the desired bucket name, but do NOT include the ```other_bucket: true``` option.
 3. The other_bucket is missing from the response.

Reproduce:
```
curl -XPUT 'localhost:9200/test/'

curl -XPUT 'localhost:9200/test/document/1?pretty' -d'

     "a" : 1,

  }
}
```
