Title

Wrong rounding?

Description
The following simple code shows a possible bug with rounding %-numbers:

```
css
@x1a: 0.  * 86;
@x1b: 0.  * 86%;
@x1: round(@x1a);
@x2: round(@x1b);
... [Log Snipped] ...
  x2:@x2;   // 0%
}
```

Why is @x2 not  "1%"? Thanks in advance and greetings from Berlin.

...Rolf

PS. I use the version 1.3.1
Discussion
- There's generally a /100 going on whenever there's a percentage involved, and that's enough to make your values small enough that they get rounded to 0.
- And we should call this a bug. Right?

...Rolf
- ... [Middle Discussions Snipped for Brevity] ...
- We are going more towards taking into account the unit - in 1.4 there will be code that adjusts units to be the same before doing maths. wonder if it treats this different?

you can use the new unit function to change the unit (1.3.2)

but actually I think it is a bug.. because we are multiplying a % by a constant and getting a percentage.. we shouldn't divide by 100 unless we are multiplying by say px. e.g.

86% of 100px = 86px
so..

86% of 100 = 86 (note - it would have to have no unit output)
or
10% of 86% = 8.6%
0.1 of 86% = 8.6%

e.g. think we need to either remove the % sign or not divide by 100.
- btw, checked and not yet fixed in 1.4.0
