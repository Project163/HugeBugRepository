- Thanks for reporting!

The few files that cannot be parsed are a bug, I'll fix those. The one that produces invalid code is also a bug. For the ones where you can't use `--safe`, well, you can't use `--safe` on those files. Re-run with `--fast`.
- That invalid code looks like a bug in string normalization.
This:
```
        y = '\n\
The \"quick\"\n\
brown fox\n\
jumps over\n\
the \'lazy\' dog.\n\
'
```

Is converted to
```
        y = "\n\
The \\"quick\\"\n\
brown fox\n\
jumps over\n\
the 'lazy' dog.\n\
"
```

I'll fix this
- @zsol, another example:
```
-escapesre = re.compile(r'[\\"]')
+escapesre = re.compile(r"[\\"]")
```
