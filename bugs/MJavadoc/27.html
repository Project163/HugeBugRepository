Title

The javadoc plugin seems to ignore package-info.java

Description
The javadoc plugin seems to ignore the information contained in package-info.java. As soon as this information is included in package.html, the information is correctly displayed in the package summary in the javadoc documentation.
Discussion
- I am also seeing this bug in Maven 2.0.4.
- Weird issue! Javadoc in jdk1.6.0 handles correctly the package-info.java files. Unfortunately, it seems to not work in Sun jdk 5.0. I tried with several Sun jdk 5 (1.5.0, 1.5.0_06, 1.5.0_08). 
So, my gutfeeling is that it is not a bug in javadoc plugin but in javadoc itself. 

 Maybe do you have a project 5.0 to provide with the waited generated javadoc? Thanks.
