Title

MalformedURLException with Quarkus 1.12 (or master) when the app in `,;~!@#$%^&()` directory

Description
Getting MalformedURLException with Quarkus 1.12 (or master) when the app in `,;~!@#$%^&()` directory. Works well with Quarkus 1.11.
Quarkus 1.12 - tests are working, dev mode is working, but running `java -jar ...` fails. Using JDK 11.
Seems `#` character is problematic for SRYE Config, `Caused by: java.net.MalformedURLException: no !/ found in url spec:file:/Users/rsvoboda/tmp/,;~!@` mentioned just part of `,;~!@#$%^&()` directory

Reproducer:
```
mkdir ',;~!@#$%^&()'
cd ',;~!@#$%^&()'
mvn io.quarkus:quarkus-maven-plugin:1.12.0.Final:create \
    -DprojectGroupId=org.acme \
    -DprojectArtifactId=getting-started \
... [Log Snipped] ...
mvn package
java -jar target/quarkus-app/quarkus-run.jar
```
