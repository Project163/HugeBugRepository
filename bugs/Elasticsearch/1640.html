Discussion
- Thanks for reporting.

I suspect the `discovery.zen.ping_timeout: 5s` is used to calculate the `join_timeout` setting which is `ping_timeout x 20` by default. Then the resulting `100s`  value is rendered as a fractional time value string by the setting framework before being parsed again... and failed.
