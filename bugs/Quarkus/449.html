Title

NullPointerException with mixed media types

Description
When there are different `@Produces`/`@Consumes` media types a `NullPointerException` is returned inside the body of a `400 Bad Request` response. No error/stacktrace in the log.

**Steps to reproduce the behavior:**
1. Use the code from rest-json-quickstart (https://github.com/quarkusio/quarkus-quickstarts/tree/master/rest-json-quickstart) 
2. Add `quarkus-resteasy-jaxb` dependency to the pom
3. Change `FruitResource` to
```java
@Consumes(MediaType.APPLICATION_XML)
@Produces(MediaType.APPLICATION_JSON)
```
4. Add `@XmlRootElement` to `Fruit` 
3. Change `FruitResourceTest.testAdd()` test to send proper XML:
```java
given()
   .body("  Pear  Winter fruit  ")
   .header("Content-Type", MediaType.APPLICATION_XML)
```

**Expected result**: test passes

**Actual result**: test fails with `Expected status code   but was  `

The actual response is:
```
HTTP/1.1 400 Bad Request
Content-Length: 30
Content-Type: text/html;charset=UTF-8

 
   java.lang.NullPointerException 
 
```

Quarkus version: 1.2.0.Final
