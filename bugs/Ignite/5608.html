Title

Remove from core/pom.xml resources to provided deps

Description
Currently ignite-core/pom.xml contains custom resources directory that links to provided deps target directories. 

 This configuration is wrong and misleads Intellij IDEA about sources directories. That sometimes lead to failing code generation in   IGNITE-25490  . 

 The configuration looks like a hot fix that makes ClassGenerator works (that prepares  
classnames.properties file)
