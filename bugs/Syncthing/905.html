Title

[URL] contains non-valid URLs with spaces

Description
Hi,

When I fetch the public list of relays via the url `[URL] some urls contains spaces, i.e.

```

```

(the `providedBy=Jon Penn` piece) . However, it should not; the spaces have to be escaped. As this is non-valid urls, and they are completely rejected by 3rd party parsers, like [URL] I use.
