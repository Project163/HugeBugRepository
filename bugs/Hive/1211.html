Title

NPE in constant folding with decimal

Description
The query: 

 SELECT dec * cast(' .1234567' as decimal) FROM DECIMAL_PRECISION LIMIT 1 

 fails with an NPE while constant folding. This only happens when the decimal is out of range of max precision.
Discussion
- Don't you need to do same null check for all the other UDF/UDAFs which deal with HiveDecimal?
- Actually it's the other way around. I don't have to update the UDAFs. Fixed it now the same way other types work.
