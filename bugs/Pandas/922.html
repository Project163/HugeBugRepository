Title

Empty TypeError message with bad column selection

Description
I was trying to guess, in a dataframe with multi-indexed columns, how to select all columns with a given second-level value.

And then I hit an empty `TypeError` message

```
In [8]: df = pd.DataFrame(columns=['i', 'c', 'x', 'y'], data=[[0, 0, 1, 2], [1, 0, 3, 4], [0, 1, 1, 2], [1, 1, 3, 4]])

In [9]: dg
Out[9]: 
   x     y   
... [Log Snipped] ...

TypeError:
```
Discussion
- For the completeness of the discussion, after reading the documentation (which is more sure but less fun than guessing), I was able to (almost) obtain what I wanted with

```
In [26]: dg.loc[:, (slice(None), 0)]
Out[26]: 
   x  y
c  0  0
i      
0  1  2
1  3  4
```
- yeh I suppose the `TypeError` could _maybe_ be more informative, though you really were passing bad values.
