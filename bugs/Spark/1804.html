Title

Support effectful / non-deterministic key expressions in CASE WHEN statements

Description
Currently we translate CASE KEY WHEN to CASE WHEN, hence incurring redundant evaluations of the key expression. Relevant discussions here:  [URL]

 If we are very in need of support for effectful key expressions, at least we can resort to the baseline approach of having both CaseWhen and CaseKeyWhen as expressions, which seem to introduce much code duplication (e.g. see  [URL] for a sketch implementation).
