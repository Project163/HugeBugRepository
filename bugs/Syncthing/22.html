Title

Syncing to Windows doesn't work for big files

Description
When I try to sync big files from my linux machine to a Windows one, the file transfer almost always stops.
The Windows machine makes a pull request to the right node ID, there is traffic on tcpdump, but suddenly all the traffic stops and the consoles don't show anything that could help to debug.
Then I have an incomplete .syncthing.{nameoffile}.time in my sync dir and the linux computer then wants to pull that file (BTW, I think these .syncthing files should be ignored by the walker).
When I restart syncthing on Windows, it requests from the beginning, linux pulls the temporary file and everyting stops again.

Actually, after testing again the transfer stops as soon as the walker finds the .syncthing file on Windows, tells it to the other computer and the other computer tries to pull it.
Maybe a lock problem?
Discussion
- `path.Base` returns a string beginning with "X:\", so `strings.HasPrefix(path.Base(name), ".syncthing.")` (walk.go; line 42) always returns false.
