Title

Extend a shareable config from another package

Description
This issue is in reference to [URL]

When using a shareable config package in another shareable config, it does not resolve to the second config in Node < v5.x. The example here is with `eslint-config-google` extending from `eslint-config-xo`, but `eslint-config-xo` does not resolve unless it is installed in the original package using eslint: `Error: Cannot find module 'eslint-config-xo'`. Is this supposed to resolve to npm dependencies of the first shareable config package, or the dependencies of the package using eslint? Probably both--checking the former first, then the latter.

The example code in the issue mentioned above is running eslint v2.2.0 and babel-eslint v5.
