Title

Mypy crashes on invalid superclass list

Description
Type checking the following invalid Python code causes mypy to crash:

```
python
class A:
    pass

class B(A):
... [Log Snipped] ...
class E(C, D):
    pass
```

Instead of recognizing and reporting the invalid superclass list of `D`, mypy crashes with the following traceback: 

```
Traceback (most recent call last):
  File "C:\Program Files\Python35\Scripts\mypy", line 6, in  
    main(__file__)
  File "C:\Program Files\Python35\lib\site-packages\mypy\main.py", line 54, in main
    res = type_check_only(sources, bin_dir, options)
... [Log Snipped] ...

NOTE: you can use "mypy --pdb ..." to drop into the debugger when this happens.
```

I am running mypy 0.4.2 and Python 3.5.2.
