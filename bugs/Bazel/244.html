Title

cc_inc_library contents stale

Description
```
$ cat BUILD
cc_inc_library(name="hdrs", hdrs=["foo.h", "bar.h"])
cc_binary(name="prog", srcs=["foo.c"], deps=[":hdrs"]) # includes both foo.h and bar.h via <>
$ bazel build :prog
...
... [Log Snipped] ...
  'bazel-out/local-fastbuild/include/_/hdrs/bar.h'.
Target //:prog failed to build
```

Bazel fails to remove now stale links due to modifications to the hdrs of :hdrs, and with `--spawn_strategy=standalone`, this deps order-dependent stale artifact is seen - flipping the order presumably changes the include chain and the compiler sees the bar_hdrs path providing bar.h.  The disparity between the manifest of hdrs and the contents of its include directory persists until a clean occurs.
