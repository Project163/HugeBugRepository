Title

Failed to compile GRPC under SLES11: pthread_setname_np is missing

Description
GRPC 1.39.1 failed to compile under SLES11 because pthread_setname_np was introduced in glibc 2.12.

Glibc version used in SLES11 is libc 2.11.3
    bash-3.2$ getconf GNU_LIBC_VERSION
    glibc 2.11.3

1.39.1 / C++

### What operating system (Linux, Windows,...) and version?

### What runtime / compiler are you using (e.g. python version or version of gcc)
