Title

Fix ZRANGE/ZREVRANGE Bug with Exclusive Bounds

Description
Currently, our implementation of ZRANGE/ZREVRANGE supports exclusive bounds, even though the redis standard returns an error:

```
 :6379> zadd key 0 a 0 b 0 c 0 d 0 e
(integer) 5
 :6379> zrevrange key 0 4
1) "e"
2) "d"
... [Log Snipped] ...
(error) ERR value is not an integer or out of range
 :6379>
```
