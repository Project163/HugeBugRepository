Title

iOS Simulator not rendering due to missing CUBE_ARRAY_TEXTURES capability

Description
Seems like the iOS Simulator uses an MTLFeatureSet not including CUBE_ARRAY_TEXTURES so currently nothing gets rendered with this error message:

```
2024-02-19T14:59:34.896266Z ERROR bevy_render::render_resource::pipeline_cache: failed to create shader module: Validation Error

Caused by:
    In Device::create_shader_module
    
... [Log Snipped] ...
    Type [40] '' is invalid
    Capability Capabilities(CUBE_ARRAY_TEXTURES) is required
```

Saw that this was discussed in #10266 and that it might lead to a potential issue. Any pointers on how this could be fixed?

I'm open to work on it and make a PR for it, simply just using the DownLevel flags don't seem to work as it will just lead to a downstream error in naga_oil instead.

## Bevy version

0.13

## Relevant system information

XCode 15.2.0 - iOS 17.2 Simulator - iPhone 15 Pro
