Title

TestSQLHandler failures on windows jenkins machines

Description
Windows  jenkins builds frequently - but  not always  - fail on  TestSQLHandler  @ L236 

 In cases where a windows jenkins build finds a failing seed for  TestSQLHandler , and the same jenkins build attempts to reproduce using that seed, it reliably encounters a  different  failure earlier in the test (related to docValues being missing from a sort field). 

 These seeds do not fail for me when attempted on a Linux machine, and my own attempts @ beasting on linux hasn't turned up any similar failures.
