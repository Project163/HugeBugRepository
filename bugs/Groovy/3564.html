Title

@CompileStatic of closure calls with OWNER_FIRST fail at runtime with ClassCastException

Description
The attached script fails with a ClassCastException, when method m2 is annotated with  

   
  
 
strategy = Closure.OWNER_FIRST
 
  
  but work with  

   
  
 
strategy = Closure.DELEGATE_FIRST
 
  
  The expected system-out should be  

   
  
 
c1Method called

Discussion
- When the compiler gets to  StaticInvocationWriter.tryImplicitReceiver , it has determined that the implicit receiver is "delegate.delegate".  That is your script is interpreted as: 
  
 
@CompileStatic
void test() {
  m1 {
    m2 {
       this .delegate.delegate.c1Method()
    }
  }
}
 
  

 It then converts to  ((C1) ((Closure) ((Test$_test_closure1$_closure2) this).getDelegate()).getDelegate()).c1Method() .  As you stated, the leftmost "getDelegate" should be "getOwner".  An instance of  C2  is the return value of this first call, which cannot be cast to  Closure .
- The  DelegationMetadata  is deciphered by this method in  StaticTypeCheckingVisitor  to produce "Receiver{type=Test.C1, data=delegate.delegate}":
