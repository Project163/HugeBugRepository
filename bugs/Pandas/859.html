Title

diff(axis=1) after insert results in unexpected NaN column

Description
The following code in pandas 0.16.2 demonstrates the problem:

```
python
   y  z
... [Log Snipped] ...
    x   y  z
0 NaN NaN  1
```

The following workaround produces the expected result:

``` python
    x  y  z
0 NaN  1  1
```

```
python
```
