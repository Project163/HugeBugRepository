Title

Bug in padded-blocks rules

Description
I think that there is a bug in the `padded-blocks` rule. Set it to `never` and try the following code:

```
function () {
  /* foo */
  console.log('bla');
  /* bar */
}
```

Then, `padded-blocks` will complain about two empty lines. Apparently it doesn't work correctly with comments.
