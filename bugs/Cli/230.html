Title

Date processing tests fail on some systems

Description
On one of my systems the date conversions do not work as expected.  I suspect this is some sort of entanglement between time zones and environment settings. 

 I was able to fix the problem by creating the expected values from known values rather than hardcoding the expected date time strings.
