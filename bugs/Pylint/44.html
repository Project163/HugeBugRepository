Title

Documentation is misleading regarding the importing of modules

Description
Originally reported by: **Claudiu Popa (BitBucket: [Link: PCManticore], GitHub: @PCManticore)**

---

From documentation:

You should give Pylint the name of a python package or module. Pylint will `import` this package or module, so you should pay attention to your `PYTHONPATH`, since it is a common error to analyze an installed version of a module instead of the development version.

The use of `import` in `Pylint will import this package or module` is wrong, because Pylint doesn't actually import the module, like a normal `import module`. Should it be replaced with `find` as in `Pylint will find this package or module`?
