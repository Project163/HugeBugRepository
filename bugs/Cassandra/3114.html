Title

ALTER TYPE RENAME TO no longer parses as valid cql

Description
Type renaming seems to be broken. The error looks like perhaps the syntax has changed or there's a problem parsing the cql. 

  
 cqlsh:test> create type foo (somefield int);
cqlsh:test> alter type foo rename to bar;
<ErrorMessage code=2000 [Syntax error in CQL query] message="line 1:22 no viable alternative at input 'to' (alter type foo rename [to] bar...)">
Discussion
- I think this is supposed to be: 

  
 alter type foo rename somefield to bar;
 
  

 At least in the spec it only lets you change a field name.  Not the type name. 
 [URL]

  
 <alter-type-stmt> ::= ALTER TYPE <typename> <instruction>

<instruction> ::= ALTER <field-name> TYPE <type>
                | ADD <field-name> <type>
                | RENAME <field-name> TO <field-name> ( AND <field-name> TO <field-name> )*
- We've got some dtests from the past that successfully used the type rename syntax so I just want to be sure it's not a bug. 

 If the syntax is no longer supported I will adjust the tests. 

 /cc  slebresne
