Title

App instance cannot render inside larger SVG

Description
### Version
3.0.5

### Reproduction link
[Link]







### Steps to reproduce
1. Use `createApp` to encapsulate a ` ` element with children representing SVG shapes.
2. Mount the app inside an existing ` ` element.

### What is expected?
The nodes added by Vue app to the parent SVG image should be instances of `SVGElement` and should be able to affect the drawing.

### What is actually happening?
The app nodes are added to DOM, but they are not instances of `SVGElement` and they don't draw anything on the parent SVG image.

---
In Vue2 I was able to add my component to existing SVG image (not created by Vue). In Vue3 SVG rendering only seems to work when the ` ` element itself is rendered by the Vue instance.

Here is example when the drawing works (the only difference from repro is that `id="app"` is above the ` ` element instead _on_ it):
