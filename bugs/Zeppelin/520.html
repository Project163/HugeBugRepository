Discussion
- I could find couple issues with https (latest release as well as master): 
1) always use server port, instead of SSL port when SSL is enabled 
2) the zeppelin-site.xml says that if you are not using truststore for client auth the properties would default to keystore, but in my tests, I noticed that you MUST setup the truststore properties to point to keystore otherwise you will get some NPE in the logs.  

 If you workaround the items above, it seems to work then.  

 Let me do some further investigation on other scenarios, and prepare a PR with code fixes and documentation updates on how to setup SSL.
