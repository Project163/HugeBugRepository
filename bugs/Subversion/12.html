Title

diff --git added/deleted filenames should not be /dev/null

Description
Our "svn diff --git" output uses /dev/null as the nonexistent side filename for added or removed files, yet "man git-diff" says "even for a creation or a deletion, /dev/null is not used in place of the a/ or b/ filenames". 

 (Regarding non-git mode, see also  SVN-2527  "svn diff does not use /dev/null as filename for added or removed files".)
