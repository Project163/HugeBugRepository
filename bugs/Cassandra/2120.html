Title

cassandra-shuffle with JMX usernames and passwords

Description
Unlike nodetool, cassandra-shuffle doesn't allow passing in a JMX username and password. This stops those who want to switch to vnodes from doing so if JMX access requires a username and a password. 

 Patch to follow.
