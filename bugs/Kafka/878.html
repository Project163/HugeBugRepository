Title

Kafka Connect javadocs not built properly

Description
It looks like the filters used in other projects aren't working properly for the nested connect projects, resulting in javadocs not being generated. 

 We also probably only want the javadocs for connect:api to be generated. The rest of the packages are all private implementation and any docs are better handled in the regular docs instead of as javadocs (e.g. config options).
