Title

Problem with cacheSchema component: infinite loop

Description
If in the db component configuration we specify custom cache component like:

```
php
//...
'db' => [
    //...
    'enableSchemaCache' => true,
... [Log Snipped] ...
]
// ...
```

and create component "cacheSchema":

```
php
   'dbSchemaCache' => [
        'class' => '\yii\db\Connection',
        'dsn' => 'sqlite:' . dirname( __DIR__ ) . '/../runtime/cacheSchema.db',
        // 'enableQueryCache' => false
... [Log Snipped] ...
        'autoCreate' => true
    ],
```

~~and in case "cacheSchema.db" doesn't exist~~, and if we try to use

``` php
$schema = $this->getTableSchema( $name )
```

so application will go to infinite loop. I figured out to set **'enableQueryCache' => false** in cacheSchema connection configuration to avoid infinite loop, since it is **true** by default.

Inside \app\components\yiiExt\DbCache I use code for check and autocreate table:

```
php
/**
 * Class DbCache
 * @package app\components\yiiExt
 *
... [Log Snipped] ...

}
```

There is error:
PHP Fatal Error 'yii\base\ErrorException' with message 'Maximum execution time of 10 seconds exceeded'

in /.../application/vendor/yiisoft/yii2/db/Connection.php:768

I checked that method (in Connection.php:768), and it called in loop with $sql:

``` sql
PRAGMA table_info(`cache`)
```
