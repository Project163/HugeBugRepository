Title

reference to the constructor of an abstract class is not detected

Description
I have the following program 
  
 
 import  java.util.function.*;

 abstract   class  Foo {
  Foo( String  x) {}
}

 class  Test {
   public   static  void main( String [] args) {
    Function< String , Foo> x = Foo:: new ;

  }
