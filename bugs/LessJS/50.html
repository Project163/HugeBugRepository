
LESS code:

```
@import "elements";

   background: ~"#fff6bf url(images/exclamation.png) 15px center no-repeat";
   text-align: left;
... [Log Snipped] ...
   .box-shadow(0 1px 2px #999999);
}
```

Running this gives me a `c is undefined` error in the less file, around line 8/9 of the Less library? I know it is something to do with the @import that is causing the problem, as removing it works absolutely fine. I'm using Textpad 6.0 with Firefox 16 as my browser - any one got any ideas as to what I am doing wrong please?
