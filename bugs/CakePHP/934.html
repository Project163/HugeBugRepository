Title

Empty OR conditions in Query::where() cause invalid SQL

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.6

### What you did

After upgrading to Cake 3.6 I've got a fatal with a query that had nothing after the WHERE and was invalid SQL because of that. Debugged it and found out that an empty OR is generated by the marshaller when using the append strategy for many.

@lorenzo guess is that the cause is this commit: [URL]

Test case, you can copy and paste this into the Table test of CakePHP to reproduce it.

```
php
    /**
     * Testing that a find with an empty OR won't cause a problem
     *
     * @return void
... [Log Snipped] ...
        $this->assertInstanceOf(ResultSet::class, $result);
    }
```
