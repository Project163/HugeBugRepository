Title

Fix java.lang.OutOfMemoryError: Java heap space on gradle 5

Description
With gradle 5 
  
 All workers, including compilers and test executors, now start with 512MB of heap. 
The previous default was 1/4th of physical memory. Large projects may have to increase
this setting on the relevant tasks, e.g. JavaCompile or Test.
 
  

 This change cause some of our test to fail.
