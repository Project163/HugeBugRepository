Title

Vector is-not-a Point

Description
The class hierarchy for geometry claims that Vector is-a Point:  [URL]

 This is mathematically incorrect, see e.g.  [URL]

 Just because they share the same numerical representation, Point and Vector shouldn't be crammed into a common class hierarchy.
Discussion
- I think that  Point  here is just meant to be a base class of  Vector .

 T(point) != point 

 T(vector) = vector
