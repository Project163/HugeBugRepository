Title

When size=0 SearchResult.String() returns "no matches" but should return "no hits"

Description
When calling index.Search with bleve.NewSearchRequestOptions and size=0 the returned number of hits is 0 even if the search has succesfully found matches (I may use it to just check if something exists, or to run facet queries).

The String() method in this case should return something like "# matches, took #s" but instead returns "no matches" (the check is on len(sr.Hits)>0 but it should really be on sr.Total>0)
