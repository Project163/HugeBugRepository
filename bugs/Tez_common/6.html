Title

Untangle MR configuration in YarnTezDagChild

Description
MR configuration is set in several different places in YarnTezDagChild (and MRTask), some of which is used during task initialization, other after. This makes the runtime brittle, and changing it tedious. If possible, we should simplify individual task setup - and differentiate between Tez and MR configuration.
Discussion
- Patch makes the following changes 
 
	 Removes all MR references from YARNTezDAGChild. 
	 Introduces a new Task - MRRuntimeTask, which is responsible for all the MR initialization 
	 Couple of new Tez config parameters 
	 Fixes config parameters which are meant to point to a list of directories versus a single job directory. 
 

 Passes all unit tests, and tested on a local cluster. Will commit this in a bit.
