Title

CUDA compiler error in type_vec.hpp

Description
When I try to use glm in CUDA I get some compile errors:

CUDA Version: 7.5
C++ Compiler: Visual C++ 2013
Errors:
`glm/detail/type_vec.hpp(23): error : constant "size" is not a type name`
`glm/detail/type_vec.hpp(23): error : expected a ";"`

It seems like the structure alignment used for CUDA (`__attribute__((aligned(X)))`) is not supported by CUDA. I hope I can find a fix to this and post it here.
