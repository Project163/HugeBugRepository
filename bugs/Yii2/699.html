Title

DbCache to a PostgreSQL database

Description
### What steps will reproduce the problem?

Enable `DbCache` to a `PostgreSQL` database
Turn on `enableSchemaCache` in the database connection
 
### What is the expected result?

Yii2 will use the `cache` table to cache the results of its schema description queries. 

### What do you get instead?

`yii\base\ErrorException`
`unserialize() expects parameter 1 to be string, resource given`

### Additional info

The cache database uses `bytea` to store the values, when loading these from a query you get back a stream rather than a value.

The `getValue` method of `DbCache` uses `queryScalar` which automatically checks for a stream and calls `stream_get_contents`.

The `getValues` method does a `queryAll` which does not do the check, which means the return values are streams rather than the underlying data.
