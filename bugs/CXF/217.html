- This error message comes from someone doing some sort of "GET" on the service, but not the ?wsdl type thing.   In that case, the URI interceptor comes into play to try and map the URI into a request.   In this case, it failed to find an operation or anything so it throws the exception. 

 I've change the error message a bit to be something like: 

 No such operation:  (HTTP GET PATH_INFO: /services/MyService ) 

 to explain that it's an HTTP GET issue.
