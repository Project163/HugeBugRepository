Title

Default storage policy if not configured cannot be "NONE"

Description
HBase can't use 'NONE' as default storage policy if not configured because HDFS supports no such policy. This policy name was probably available in a precommit or early version of the HDFS side support for heterogeneous storage. Now the best default is 'HOT'.
Discussion
- Simple patch. Eliminates log noise that can come about when WAL storage policy isn't set in the site file.
- -1 overall
