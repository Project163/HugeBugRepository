Description
### What happened?

The [Link: documentation] says to create a GitLab personal token.


But this creates a token which has too much power.
In GitLab it is now possible to create token which have only the project scope.

GitLab CI now even exposes a `$CI_JOB_TOKEN` variable that _may_ already have all the credentials needed.
