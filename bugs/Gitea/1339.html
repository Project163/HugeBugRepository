Title

User Issues page no longer shows issues in all repositories

Description
### Description

To reproduce:
* Have a Gitea instance with an existing repository
* Create a new user
* With that new user, create a new issue in the repository
* Navigate to the Issues page, "Created by you" shows no issues

If the user owns the repository or is a member of a team with access it will show the issues. But it's useful to e.g. see all bugs you reported to projects you are not a member of.

This was caused by #26545. That fixed a bug when a team is selected but probably should not have affected the case where a user is selected?
