Title

GlobalAlternatives must not get handled for OpenWebBeans

Description
We currently also rewrite the AnnotatedType for OWB. But this is not needed for OWB because we handle the BDA flat anyway. Thus standard <alternatives> in beans.xml is plenty enough for OWB. OWB users of containers which come with BDA enabled (e.g. IBM WebSphere) should instead just disable this feature via openwebbeans.properties
