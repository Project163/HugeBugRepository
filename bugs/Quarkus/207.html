Title

Issue with generic bean injection

Description
When there's a generic bean with an unbounded type parameter T [Link: (example)] and an injection point that declares a particular type for T [Link: (example)], ARC blows up with `UnsatisfiedResolutionException`. I assume this setup should be valid, because the CDI [Link: spec] says


in our case,
- _required type parameter is an actual type_ - `java.lang.Long`
- _the actual type is assignable to the upper bound of the type variable_ - `Long` is assignable to `java.lang.Object` 

The Metrics TCKs, from which I link examples, work without changes with Weld. To make this test work with Quarkus, I had to add an upper bound for the bean (`ConcurrentGaugedMethodBean `)
