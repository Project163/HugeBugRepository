Title

`array-bracket-spacing` sometimes fails on empty arrays

Description
`array-bracket-spacing` will fail if set to  `[ 2, "never", {"arraysInArrays": true } ]` or `[ 2, "never", {"objectsInArrays": true } ]` for empty arrays:

``` js

var foo = [];
```
