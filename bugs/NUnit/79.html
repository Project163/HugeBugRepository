Title

Description
After fixing #515 so that MacOSX is correctly returned when running on a Mac, the three tests fail because they are using the directory separator char to determine the platform and setting it to Linux where it could be MacOSX.

To get the tests passing on Mac, I added a platform attribute for now. These should be fixed properly when we have more time.
