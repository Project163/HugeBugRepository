Title

[Bug]: Storybook 8/9 - Playwright Portable Stories error with `Unexpected Value` if function is passed as a prop, despite it being supported by underlying CT core

Description
### Describe the bug

This bug occurs on Storybook 8 as well as 9. It's possibly been there since the experimental Playwright CT portable stories feature was added.

When using Playwright component testing with the experimental portable stories integration, any test which passes a function as a prop to the story from the test, blows up with:

```
    Error: Unexpected value

      15 | test('render button with function was passed to props', async ({ mount }) => {
      16 |
         |                           ^
      18 |   await expect(component).toContainText('label from test');
      19 | });
```

Even though the test is in node JS, and the story itself is in the browser -- functions should be allowed to be passed. [Link: See the example] on the main page of the playwright CT docs. Playwright's own core mount handles this situation, with the caveats mentioned [Link: here].

This works fine with the base playwright `mount()`, so the problem is within the modified version of mount that is bound to the augmented `test` function that originates from `createTest` in the `@storybook/react/experimental-playwright` package.

See additional details for more info on proposed fix.
