Title

Bwlimit is restricted to approx. 2.5Gbps

Description
Referencing forum post
[URL]

bwlimit does not allow speeds of >2.5Gbps 

rclone v1.56.0
os/version: Microsoft Windows Server 2019 Standard 1809 (64 bit)
os/kernel: 10.0.17763.2061 (x86_64)
os/type: windows
os/arch: amd64
go/version: go1.16.5
go/linking: dynamic
go/tags: cmount


rclone sync sourceuser:sourcebucket destuser:destbucket --bwlimit 500M --transfers 400 --checkers 500 --max-delete 10000 --log-level INFO --stats 1m --stats-log-level INFO --use-mmap --fast-list --modify-window 1s

Increasing maxBurstSize from 4*1024*1024 to 16*1024*1024 allows the maximum bandwidth limit to be 10Gbps.
[URL]
Discussion
- I found the discussion about this in  


  was an attempt to make the bandwidth limiter smoother by making it smaller for the "edge" bandwidth limiters.

So what that is saying is that reducing the maxBurstSize to 4k from 4M made it unusable on Windows.

Increasing it from 4M to 16M will make the bandwidth limiter less smooth.

A max bandwidth limit of 2.5Gbps for 4M is approx 74 x 4M buffers per second which is well inside the 1mS time resolution for Windows so whatever is happing here probably isn't to do with the timer resolution of Windows

Here is a beta which scales the maxBurst linearly above 2 Gbps - I think this should work for you - can you give it a try?
