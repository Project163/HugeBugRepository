Title

[YSQL] Cannot connect a PostgreSQL client to YugaByte DB after restart

Description
After a YugaByte DB with PostgreSQL support is restarted, the following error is encountered when connecting psql to it:

```
psql: FATAL:  Not found: Failed Read(tablet:  , num_ops: 1, num_attempts: 1, txn: 00000000-0000-0000-0000-000000000000) to tablet   on tablet server { uuid:   private: [host: " " port: 7100] cloud_info: placement_cloud: "cloud1" placement_region: "datacenter1" placement_zone: "rack1" after 1 attempt(s): table   not found in tablet  
```

This happens because the tablet metadata of PostgreSQL sys catalog tables in yb-master is not persisted.
