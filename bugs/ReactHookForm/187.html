Title

Validation resolver is called with invalid values when the last item of a field array is removed

Description
**Describe the bug**
If the last item of a field array is removed. the resolver is not called with all the data.
Also for some reason an additional field is added to the data passed to the resolver (see below for more details)

**To Reproduce**
Steps to reproduce the behavior:

1. Go to [URL]
2. Click on APPEND NESTED
3. See the log and notice there's a field 'test[0].nestedArray' added to the data passed to the resolver
4. Click DELETE (the innermost one, for the nested array)
5. Click DELETE again (the innermost one, for the nested array)
6. Notice in the log the value for the 'name' field is not passed to the resolver this time

**Codesandbox link (Required)**
[URL]


**Expected behavior**
The resolver should received all the data and there's should be no additional fields.



**Desktop (please complete the following information):**

- OS: Mac OS
- Browser Safari
- Version 14.0
