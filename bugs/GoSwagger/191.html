Title

Swagger generates and uses different models in case of definition name starts with Digit

Description
In swagger.yml file my definitions named like "400Schema", "404Schema" and etc. When I generate source from swagger, it was created models in the form "NR404Schema" but restapi code was used it as "X404Schema". Hence restapi could not find proper model objects. 
It is happening only in case when definitons' name starts with digit.
