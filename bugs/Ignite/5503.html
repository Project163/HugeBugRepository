Title

Calcite. Least restrictive type priority DOUBLE over FLOAT

Description
Calcite derives least restrictive approximate numeric type by comparing the precisions. While  FLOAT  has the same precision as  DOUBLE  (currently 15), the least restrictive type may variate between them and issue  FLOAT  instead of  DOUBLE . DOUBLE is more preferable: 
  
 
IgniteTypeFactory#leastRestrictive(List<RelDataType> types) 
 
  
 may produce  FLOAT  when  types  has a  DOUBLE .
