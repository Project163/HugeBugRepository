Title

Unnecessary warnings for constructors defined inside goog.scope

Description
What version of the product are you using? On what operating system? 
Closure Compiler (http://code.google.com/closure/compiler)
Version: v20140110
Built on: 2014/01/14 16:25

Debian GNU/Linux Xfce

 Please provide any additional information below. 
First, try compiling the following program with ADVANCED_OPTIMIZATIONS:

(function () {
  /**
   * @constructor
   */
  function Foo(x, y) {
    this.x = x
    this.y = y
  }

  console.log(new Foo(x, y))
})()

This works as expected. Now, try compiling this program:

goog.scope(function () {
  /**
   * @constructor
   */
  function Foo(x, y) {
    this.x = x
    this.y = y
  }

  console.log(new Foo(x, y))
})

This produces the same result, *except* the compiler emits warnings about "dangerous use of this in static method".

To suppress these warnings, you must wrap the inside of goog.scope in another function, which is ridiculous:

goog.scope(function () {
  (function () {
    /**
     * @constructor
     */
    function Foo(x, y) {
      this.x = x
      this.y = y
    }

    console.log(new Foo(x, y))
  })()
})
