Title

``pyreverse`` does not handle arguments of form ``Optional[int]`` correctly

Description
### Bug description

Given a file ``a.py``:

```python
from typing import Optional


class DoSomething:
    def __init__(self, a_string: str, optional_int: Optional[int] = None):
        self.my_string = a_string
        self.my_int = optional_int
```


### Configuration

_No response_

### Command used

```shell
pyreverse -ASmy a.py
```


### Pylint output

Output of pyreverse (unfortunately I can't upload images with the new forms?) displays the type of ``my_int`` just as ``Optional``, not as ``Optional[int]``.

Note that if the code is changed to:

```python
class DoSomething:
    def __init__(self, a_string: str, optional_int: int = None):
        self.my_string = a_string
        self.my_int = optional_int

The output correctly displays ``my_int`` as ``Optional[int]``.
```


### Expected behavior

Display ``my_int`` as ``Optional[int]`` in both cases.

### Pylint version

```shell
pylint 2.10.0-dev0
astroid 2.6.6
Python 3.9.6 (default, Jul 28 2021, 21:15:06) 
[Clang 12.0.5 (clang-1205.0.22.9)]
```


### OS / Environment

macOS Big Sur 11.4
