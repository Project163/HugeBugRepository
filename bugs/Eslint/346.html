Title

Allow ~.eslintrc to be ignored

Description
I have a `.eslintrc` in my home directory as a default linter for small experiments, and different `.eslintrc` files in a number of projects. Those projects run eslint as part of a git commit hook.

My problem is that when I lint my project files, I inherit additional rules from my personal `.eslintrc` (which is technically in a parent directory). This means that code which is proper by the standards of the project is still causing lint tasks in the projects to fail.

I've searched the documentation for some option to disable my persional `~/.eslintrc`, or designate a certain `.eslintrc` as the root one (which would mean eslint should start cascading from that file). So far I haven't been able to find anything. Have I overlooked something?
