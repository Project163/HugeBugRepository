Title

Introduce performant and memory efficient APIs to create ArrayBasedMapData

Description
In HiveInspectors, I saw that converting Java map to Spark's `ArrayBasedMapData` spent quite sometime in buffer copying :  [URL]

 The reason being `map.toSeq` allocates a new buffer and copies the map entries to it:  [URL]

 This copy is not needed as we get rid of it once we extract the key and value arrays.
