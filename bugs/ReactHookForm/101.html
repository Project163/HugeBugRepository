Title

Value returned by watch doesn't change when typing for array fields

Description
**Describe the bug**

When generating fields from an array(similar to [URL] and using `watch` to detect a change the value retuned by watch doesn't change as the user type in the field.

The name of the field is generated as `field.${item.id}` and watch is called with `watch('field')`.

This used to work in version 4.9.8 and stopped working in 4.9.9-beta.1.

**To Reproduce**
Steps to reproduce the behavior:
1. Go to [URL]
2. Type some text in the input field
3. Message "new field value" appears in the console
4. Change the react-hook-form dependency to 4.9.9-beta.1 or above
5. Type some text in the field
6. Nothing is logged in the console

**Codesandbox link (Required)**
Working version (4.9.8): Go to [URL]
Version with issue (4.9.9-beta.1): [URL] 

**Expected behavior**
The watched value should be updated as it used to be in 4.9.8
