Trouble with parallel GridSearchCV [update]

Description
I am not sure what the root is but the following was reported on IRC and I could reproduce:
~~when doing a nested cross-validation with `GridSearchCV` and `cross_val_score`, there seem to be some parallelization issues.~~

Reproduce using

