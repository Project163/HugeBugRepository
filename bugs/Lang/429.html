Title

StringUtils#isAnyEmpty and #isAnyBlank should return false for an empty array

Description
An empty array does not contain any empty/blank CharSequences, so isAnyEmpty/isAnyBlank should return false for an empty array.
Discussion
- Here's some more context on the change: 

   

 $ jshell --class-path ~/.m2/repository/org/apache/commons/commons-lang3/3.4/commons-lang3-3.4.jar 
 jshell> import org.apache.commons.lang3.StringUtils; 
 jshell> StringUtils.isAnyEmpty((String[])null) 
 $2 ==> true 
 jshell> StringUtils.isAnyEmpty(new String [0] ); 
 $3 ==> true 

 $ jshell --class-path ~/.m2/repository/org/apache/commons/commons-lang3/3.10/commons-lang3-3.10.jar 
 jshell> import org.apache.commons.lang3.StringUtils; 
 jshell> StringUtils.isAnyEmpty((String[])null) 
 $2 ==> false 
 jshell> StringUtils.isAnyEmpty(new String [0] ); 
 $3 ==> false
