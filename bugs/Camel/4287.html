Title

Using MongoDB Tailable Cursor Consumer on non-capped collection results in NullPointerException (instead of proper error message)

Description
When using the Camel MongoDB component with a tailable cursor consumer on a non-capped collection, you get a NullPointerException (also see  [URL] on this). While using this feature on a non-capped collection is not supported, the error message should be better (at the moment it only throws a NullPointerException because the code tries to unbox a null in a Boolean object). The code actually already has a better error message, but there is a small logic flaw that prevents the error message from showing up. See  [URL] for the code.
