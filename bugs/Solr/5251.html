Title

Spelling bugs in the Solr reference guide

Description
The reference guide contains lots of typos which should ideally be fixed.
Discussion
- Someday I'd love to get spell checking (and even stylistic tooling like  [URL] ) integrated!   We tend to fix them a bit piece meal, and it would be good to get the code base into the best shape it can be.  Especially with Solr 10x coming up, this is a good time for fixing typos in the source that maybe would be hard to back port (like method names).     

 When I am working in the Java code, I use IntelliJ and it's features some advice on grammer for your comments, so I try to fix them one by one.  More eyes and hands getting the grammer and spellings fix is very much appreciated.
- Related fix:  [URL] Personally I have good experience with the combination of `codespell` and `typos`, both Python command line applications which are easy to install and which can also be integrated into CI tests.
