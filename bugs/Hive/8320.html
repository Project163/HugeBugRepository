Title

Make commons-pool2 an explicit dependency (and upgrade to 2.11.1)

Description
HIVE-26242   started using the commons-pool2 which is getting pulled in a transitive dependency through commons-dbcp2 or calcite-core. It would be better to make it an explicit dependency to ensure it gets packaged properly and/or things do not suddenly break if the transitive dependencies change.
Discussion
- The patch makes the dependency version 2.11.1 -> the original version being transitively imported was 2.7.0. I went with the newest version since I saw no issues with it and to attempt to be safe from a CVE standpoint.
- Merged to master.
