Title

HCat e2e tests broken by changes to Hive's describe table formatting

Description
In Hive 0.11 the default formatting for describe table changed.  A number of the HCat e2e tests do describe table and apply regular expressions to the output to make sure the table looks correct.  These formatting changes broke those tests.
