Title

`id-match` should use boolean schema type

Description
The schema of `id-match` is currently:

```
js
    {
        "type": "string"
    },
    {
... [Log Snipped] ...
        }
    }
```

I think it should be:

```
js
    {
        "type": "string"
    },
    {
... [Log Snipped] ...
        }
    }
```

The difference being use of the boolean type rather than an enum.  I don't think it causes any problems the way it is, but it should probably be corrected just for the sake of correctness and consistency.
