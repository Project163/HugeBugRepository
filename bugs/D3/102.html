- Here’s an example of the difference. In Stable, we resample from [Link: -6. -17, -7. -33, -1] to [-1, -1. -16, 0]. In Canary, we resample from [0, 0, -1] to [-1, 0, 0].

The divergence seems to happen in computing λ2. In Stable:

``` js
a = -0. 
b = -8. -17
λ2 = Math.atan2(b, a) // -3.141592653589793
project(λ2, φ2) = [71.59295503332692, 352.10176124166827]
```

In Canary:

``` js
a = -0. 
b = 0
λ2 = Math.atan2(b, a) // 3.141592653589793
project(λ2, φ2) = [888.4070449666731, 352.10176124166827]
```
