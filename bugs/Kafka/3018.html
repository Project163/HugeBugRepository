Title

Owned partitions in the subscription must be sorted

Description
While investigating  [URL] I have noticed that the leader was always sending the same subscribed partitions but not always in the same order. The group coordinator compares the provided subscription with the store subscription based on their bytes representation. So if the subscribed partitions are not in the same order, the group coordinator would consider that they are different and rebalance the group.
