- @kekel87 - sorry it has taken a while to look into this. Your reproduction project was already really close to solving this as it stands.

You had already correctly added in an `ngcc.config.js` at `projects/ngx-openlayers/ngcc.config.js` with the correct format:

```js
module.exports = {
  ignorableDeepImportMatchers: [/ol\//]
};
```

(this is a "package" version of the file, which is slightly different to the "project" version which must also contain a `packages` property in the exported object.)

All you had to do now was to ensure that the `ngcc.config.js` file ends up in the distributable built files by modifying the `ng-package.json` file:

```json
{
  "$schema": "../../node_modules/ng-packagr/ng-package.schema.json",
  "dest": "../../dist/ngx-openlayers",
  "assets": [
    "ngcc.config.js"
  ],
  ...
```

This means that the generated package folder under `dist` contains the `ngcc.config.js` which ngcc can then read and configure the deep-import ignoring appropriately.
- Closing this issue now as ngcc already supports ignoring these warnings for local packages in `dist`.
