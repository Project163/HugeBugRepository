Title

Blender Exporter: JSONLoader not firing load callback for exported scene

Description
I am using the blender exporter to export a scene to three.json that has a few meshes.
The exporter seems to be successful and the json file has, what looks like, accurate data.

you can check the scene json here: 
[URL]

I am using the following code to load the scene

``` javascript
var loader = new THREE.JSONLoader();
debugger;
loader.load( 'models/animated/pleb/pleb.json', function ( geometry, materials ){
    debugger;
    //...
});
```

The second `debugger` break point is never triggered.
The browser console look like the images has loaded successfully.
[Image: screenshot 2015-01-19 14 17 28]

I am doing all this on a local filesystem with the the crhome `--allow-file-access-from-files`
`/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --allow-file-access-from-files ./kev_test.html`

This is a large export ~20Mb I suspect maybe theres some hidden file access limit from Chrome in this mode.

I am able to export individual selected meshes from the same blend file using the exporter. How can I validate the export data or further debug this?
Discussion
- with this new blender exporter r70 you need to use THREE.ObjectLoader()
- Added a check in `JSONLoader` for this. Thanks for reporting!
