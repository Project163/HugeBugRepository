Title

Folder label missing from folder path when adding new folders

Description
1. Share a new folder from Device A to Device B.
2. On Device B, click the Add button. The label has been added to the path.

   [Image: image]

3. Click the Close button.
4. Click the Add button again. The label is gone from the path.

   [Image: image]

5. From now on, the label is not added to the path for any newly added folders.
6. Restarting Syncthing temporarily brings back the proper behaviour from 2., but then the process repeats itself again.

Tested with `v1.16.0-rc.2.dev.3.ge4c995a3`.
