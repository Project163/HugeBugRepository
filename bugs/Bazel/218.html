Title

remote string in label_list default leads to RuntimeException

Description
When I add  the following line in external repo `foo`

```
"_python_runfiles": attr.label_list(default=["@python//:whatever"]),
```

Bazel excepts:

```
Unhandled exception thrown during build; message: Unrecoverable error while evaluating node 'SKYLARK_IMPORTS_LOOKUP:com.google.devtools.build.lib.skyframe.SkylarkImportLookupValue$SkylarkImportLookupKey@b926050d' (requested by nodes 'PACKAGE:@foo//')
INFO: Elapsed time: 0.604s
java.lang.RuntimeException: Unrecoverable error while evaluating node 'SKYLARK_IMPORTS_LOOKUP:com.google.devtools.build.lib.skyframe.SkylarkImportLookupValue$SkylarkImportLookupKey@b926050d' (requested by nodes 'PACKAGE:@foo//')
at com.google.devtools.build.skyframe.ParallelEvaluator$Evaluate.run(ParallelEvaluator.java:1024)
at com.google.devtools.build.lib.concurrent.AbstractQueueVisitor$WrappedRunnable.run(AbstractQueueVisitor.java:474)
... [Log Snipped] ...
at com.google.devtools.build.skyframe.ParallelEvaluator$Evaluate.run(ParallelEvaluator.java:975)
... 4 more
```

Now looking at the code it seems like the problem originates from this call in `Type.java:85`

```
return convert(x, what, null);
```

It can be worked around by wrapping `@python//:whatever` in `Label`.
So if in lower code the context is actually necessary to convert values I think it needs to be passed.
OR there needs to be check in `Attribute.java:620`, whether a conversion without context is actually possible (or catch the exception).
