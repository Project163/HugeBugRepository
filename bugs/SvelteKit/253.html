Title

Returning a native `fetch()`-response throws `TypeError: immutable`

Description
### Describe the bug

According to the `fetch()`-specification, a header can have an `immutable`-guard which will throw a `TypeError` if the  header is changed:  [URL]
    
When using `fetch()`, the spec requires the response header to be `immutable` (see step 12/4):
[URL]
    
This is implemented in undici (used by Node.js for native fetch() under the hood):
[URL]

The change introduced in [URL] will try to mutate the response header in certain scenarios, thus causing a `TypeError`.

### Reproduction

A reproduction via failing test-case can be found in PR #10367.
