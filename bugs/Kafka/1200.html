Title

Minor issue with throttle argument in kafka-reassign-partitions.sh

Description
1. 
kafka-reassign-partitions —-verify prints Throttle was removed regardless of whether a throttle was applied. It should only print this if the value was actually changed.  

 2. 
—verify should exception if the —throttle argument. (check generate too)
