Title

S3 SDK Upgrade causes AccessPoint ARN endpoint mistranslation

Description
Since upgrading the  SDK to 1.12.132  the access point endpoint translation was broken. 

 Correct endpoints should start with "s3-accesspoint.", after SDK upgrade they start with "s3.accesspoint-" which messes up tests + region detection by the SDK.
