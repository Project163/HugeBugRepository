Title

nvim diff aborted with ``src/nvim/drawline.c:2051: win_line: Assertion `extra_attr_next >= 0' failed.`` in some locales

Description
### Problem

In diff mode, nvim aborts with ``src/nvim/drawline.c:2051: win_line: Assertion `extra_attr_next >= 0' failed.``

[URL]

when

- foldtext has non latin1 characters, i.e. `LANG=ja_JP.UTF-8` or `uk_UA.UTF-8`; nvim works fine with `en_US.UTF-8`
- one of lines around diff is sufficiently long (length > 2×window width?)

The text seems to be translated in Japanese and Ukrainian only:

[URL]
[URL]

### Steps to reproduce

Generate locale of `ja_JP.UTF-8` or `uk_UA.UTF-8`.
Build nvim with `ENABLE_TRANSLATIONS` ON.
Prepare files:
```sh
{ yes | head -n 8; echo 123456789 123456789 123456789 123456789 123456789 123456789 ; } > foo.txt
yes | head -n 9 > bar.txt
```

Set the terminal size to 80×24 and `LANG` to `ja_JP.UTF-8` or `uk_UA.UTF-8`, then `nvim -d --clean foo.txt bar.txt` and `G$`.

[Link: [Image: asciicast]]

### Expected behavior

No assertion failure occurs.
