Discussion
- You are right, JWA Base64urlUInt can not represent negative BigIntegers.
- With this bug, when you upgrade to Java 8u161 or higher, you can start getting "java.security.InvalidKeyException: exponent is larger than modulus". This is because Oracle added a check to reject negative RSA modulus in 8u161 and higher (changeset JDK-8174756). Upgrading CXF to a version with this bug fix makes that error go away. Started getting that exception randomly (it only happens if the first byte of the encoded modulus is -128, so there is a roughly 1-in-256 chance of any key getting hit by it), it took me a while to realise that this bug was the root cause. So just putting this pointer here in case anyone else has the same symptoms in the future.
