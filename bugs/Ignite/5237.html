Title

Mapping of partition states to nodes can erroneously skip lost partitions on the coordinator node

Description

  Update : 
    The root cause of the issue is that the coordinator node incorrectly update mapping nodes to partition states on PME (see GridDhtPartitionTopologyImpl.node2part). It seems to me, that the coordinator node should set partition state to LOST on all affinity nodes (if this partition is assumed as LOST on the coordinator) before creating and sending a “full map” message.
