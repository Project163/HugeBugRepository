Title

@Singleton doesn't support getInstance() as documented

Description
e.g. 
  
 @Singleton  class  MyService{
}

println MyService.instance  // it works as expected
 println MyService.getInstance()  // throw  exception: No signature of method:  static  MyService.getInstance() is applicable  for  argument types: () values: [] 
 
  

 p.s. i found an old issue about Singleton in Groovy that probably could be closed   GROOVY-1870
Discussion
- For the non-lazy variation of @Singleton, the getInstance() was not being added. Only "instance" was being added as a public property. So, getInstance() call was failing. 

 Attaching a patch that adds property as private and its getInstance()  [same as lazy variant of @Singleton] .  

 Let me know if it looks ok.
- Any review comments on the patch?
- Roshan, I think it is no problem if there is a public field and the getter. In the non lazy case the getter should simply return the field, without any further checks. So I would remove the null check from the patch. In  [URL] I suggested the use of a final static property and I still think that is the way to go for the non lazy variant.
- Fixed. Added the getter getInstance() for non-lazy variant of Singleton annotation.
