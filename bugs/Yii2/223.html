Title

Number formatter error for strings

Description
The Yii Number format function uses `number_format` which requires the value must be passed as floating point, else an exception is thrown for strings (even if it consists numeric digits)
Discussion
- Proposed PR #3758 as a fix for this.
- There is still a problem with the number formatting. The problem occurs if you pass a string to the function `asShortSize`, which is the case if you pass the variable directly from DB.

``` php
var_dump(
    Yii::$app->formatter->asShortSize(28406984038),
    Yii::$app->formatter->asShortSize((string)28406984038),
    Yii::$app->formatter->asShortSize((28406984038 + 28406984038)),
    Yii::$app->formatter->asShortSize((string)(28406984038 + 28406984038))
);
```

output

```
string(9) "28,407 GB"
string(8) "2,147 GB"
string(9) "56,814 GB"
string(8) "2,147 GB"
```
