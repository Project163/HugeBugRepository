Title

commons html - document creation fails with tag stream on certain input

Description
This occurred due to a conflict between an HTML parser and a need to support an XML interface. In HTML a processing instruction is merely an undefined tag. Which in the SAX parser needs to be handled as a processing instruction, except for the case where the instruction is '?xml' 

 Additionally the EOF tag may not be generated, so I explicitly call the end of document for the handlers.
Discussion
- This is only necessary if you are attempting to replace all the implementations of the HTML4 parser with the HTML5 parser which is not a workable end goal. As their are some fundamental differences between the two with Document structure.
