Title

Need button to save paragraph text changes without executing

Description
I'm using the Zeppelin "%sql" interpreter to run SQL through the Spark Hive Context.  If I make edits to the comments in my SQL, and then change to another notebook, my edits go unsaved.  It appears that running the SQL (shift-Enter) is the only way to ensure the text edits are persisted.
Discussion
- I've been bitten by the same issue. Should it have some sort of periodic saving? Or should it prompt you to save before you navigate away?
- Currently a workaround could be collapse and expend code area. that action will saves your code changes without run it. 

 Until now, Zeppelin tried to not have save button for simplicity of use. 

 I think we can solve the problem with 
 
	 periodic saving 
	 automatic save when closing browser 
	 notification when there're unsaved changes 
	 save button.
