Title

Lower default minimalFreeDiskGB for the AffinityPlacementPlugin

Description
The default minimalFreeDiskGB for the AffinityPlacementPlugin is 20GB, which is probably some arbitrary number determined when the AffinityPlacementPlugin was introduced. Unfortunately in test environments, it is somewhat common to have less than 20GB available (Jenkins, Github Actions, etc). We should lower this number, since its pretty arbitrary in the first place, and so that the tests will pass on test infrastructure.
