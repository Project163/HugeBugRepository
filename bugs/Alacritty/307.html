Title

Setting hints with `alacritty msg` doesn't update keyboard bindings

Description
Hey!

Currently when using `alacritty msg config` to update hints, it doesn't update the keyboard shortcuts. 

To reproduce, start an alacritty and run:

```
$ # my-tag 
$ alacritty msg config 'hints.enabled = [ { command = "my-command", hyperlinks = true, post_processing = false, mouse.enabled = true, binding = { key = "M", mods = "Control|Shift" }, regex = "my-tag" } ]'
```
You'll notice that `Control+Shift+M` doesn't show my-tag as possible targets, however cursor hover will still work. 

Alacritty version: 0.15.0
Discussion
- Hm that does indeed not seem to work.
- It also seems that changing the `general.import = [ "~/.hints-file" ]` to `general.import = []` with `alacritty msg config` doesn't remove hints either.
- Imports not being changeable through IPC is fine since there's better ways to do that really. But hints really should work.
