Title

Groovy Console binding's output-transform missing yields a stacktrace when context is cleared

Description
The Groovy Console uses a mechanism that users can use to define visual representations of outputs in the console (for instance displaying a map in the form of a JTable). 

 Such "output transforms" are stored in a special variable in the binding. 

 When calling the "clear context" action, a new binding is created, but the output transforms variable is not added back to the binding. And when you execute a script which will yield some resulting output, Groovy Console won't find the output transforms variable, and will throw a stacktrace complaining about that.
