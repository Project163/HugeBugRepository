- This particular error happens because we configured the compiler for the language service to skip modules that aren't exported. This was done because the program used for the language service generally includes a much larger set of files than what is used to compile the application. That is, `tsconfig`s often include the `*spec` files as well. The result is that modules defined in tests could cause errors for various reasons (for example, a component is declared in the application module as well as the test module). 
To get around this, we skip non-exported modules, assuming those would be test modules. Our check for that needs to be more robust so that it does not skip modules which are exported later on in the file as in `export {DrawerModule}`. 
I should be able to get a fix out for this today.

@arndwestermann your issue doesn't seem related to this. If you can figure out a way to reproduce the error and share a project that we can use to debug, please provide that information in [URL]
