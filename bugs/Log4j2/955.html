Title

2.7 - ThreadContextAccess.getThreadContextMap NPE when specifying BasicContextSelector

Description
We have a custom OSGi based application. We specify Log4jContextSelector=org.apache.logging.log4j.core.selector.BasicContextSelector. We initialize log4j through  
Configurator.initialize("main", logConfigPath); 

 Starting from log4j2 2.7 above line fails due to NPE/ExceptionInInitializerError in LogManager static init block. I found a work around by specifying disableThreadContextMap=true. This is 2.7 specific change.
