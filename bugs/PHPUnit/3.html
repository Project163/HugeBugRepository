Title

Diff fails when comparing DomDocuments

Description
While testing me and @edorian found a little issue with assertions on Dom mocks.

```
PHP Catchable fatal error:  Argument 1 passed to PHPUnit_Util_Diff::longestCommonSubsequence() must be an array, null given, called in /usr/share/pear/PHPUnit/Util/Diff.php on line 193 and defined in /usr/share/pear/PHPUnit/Util/Diff.php 
```

Reproduce:

```
php
 run() /usr/share/pear/PHPUnit/TextUI/Command.php:130
... [Log Snipped] ...
PHP  14. PHPUnit_Util_Diff::diffToArray() /usr/share/pear/PHPUnit/Util/Diff.php:75
PHP  15. PHPUnit_Util_Diff::longestCommonSubsequence() /usr/share/pear/PHPUnit/Util/Diff.php:193
```
Discussion
- Still fails with 3.7.1 (just as a note for me)
- Weird, as it works fine with `assertEquals()`:

```
➜  ~  cat Test.php 
saveXML()` in `PHPUnit_Framework_Comparator_DOMDocument::domToText()` returns `NULL`. This is because it is passed a stubbed `DOMDocument` object that does not invoke the original `saveXML()` method. `NULL` is then passed on to `PHPUnit_Util_Diff::diffToArray()` where it breaks.

I am afraid that there is nothing we can do about this, so I am closing this issue.
