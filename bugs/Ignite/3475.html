Title

Web console: Incorrect behavior of cluster activation control

Description
start node 
	 activate 
	 go to Queries history tab, click Refresh 
	 deactivate cluster using component- after several seconds component gets switched to 'Activating...' stage and hangs in this state for about minute
Discussion
- After digging deeper into cluster activation found that cluster doesn't have state: activation in progress, deactivation in progress. I think we should emulate it on server side of Web-Console.  Emulating on frontend side will be not displayed on other user tabs or for other user that what work with this cluster.
- This issue can not be fixed without changes in cluster behaviour.
