Title

SPDY Session Handler behavior changed

Description
In netty 3.x, the SessionHandler's handleDownstream method would report user-level protocol errors (such as attempting to write to a closed stream) by failing the write future associated with that object. In netty 4 this behavior has been changed to firing an exception upstream. This both unintended consequence based on where the write is originating (for example if it originates in an exceptionCaught block) as well as being undesired because these types of failures are recoverable and in some situations expected.
