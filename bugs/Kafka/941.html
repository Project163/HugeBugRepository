Title

Mirror maker doesn't commit offset with new consumer when there is no more messages

Description
Mirror maker doesn't commit messages with new consumer enabled when messages are sent to source within the time range that is smaller than commit interval and no more messages are sent afterwards. 

 The steps to reproduce: 

 1. Start mirror maker. 
2. The default commit interval is 1 min. Send message for less than 1 min for example 10 seconds. 
3. Don't send more messages. 
4. Check committed offset with group command. The lag remains unchanged for ever even though the messages have been sent to destination.
