Title

Assignment to array elements is inconsistent with assignment to fields and variables

Description
As detailed in the specific case of char[] in   GROOVY-3165  , assignment to array elements in a value context is inconsistent with the same operations on fields and variables. 

 Generally these should all be true: 
  
 T x
def v = (x = <any>)

 assert  x.is(v)

T[] x =  new  T[1]
def V = (X[0] = <any>)

 assert  X[0].is(V)
 
  
 In the case of primitive types, then equality rather than identity should be true.
