Title

WS-RM client keeps using an expired source sequence

Description
The WS-RM client does not check if the current source sequence has expired or not. Consequently, the client keeps using the expired source sequence to transmit the messages. 

 When the current sequence has been expired, a new sequence should be created as in the handling of the very first message.
