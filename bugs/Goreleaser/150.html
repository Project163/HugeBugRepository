Title

error updating brew formula file statusCode=403

Description
### What happened?

I created a Personal Access Token under [URL] (I also tried Project a project access token created at the brew tap repo)

After publishing `publishing ->  scm releases` it fails:

```
⨯ error updating brew formula file             branch=main err=PUT [URL] 403 {message: 403 Forbidden} fileName=my-go-program.rb projectID=buschco/homebrew-tap statusCode=403
  • took: 3s
  ⨯ release failed after 2m29s               error=homebrew tap formula: failed to publish artifacts: PUT [URL] 403 {message: 403 Forbidden}
```

Either a GitLab upgrade or a new version of `goreleaser` broke my pipeline

### How can we reproduce this?

.goreleaser.yml
```
yml
brews:
  - name: my-go-
```

### Additional context

- It seems like the Personal Access Token is never used.
- We ran in to this over here as well...I think this is caused by unexpected behavior with the `use_job_token: true` config. I think this is because the brew pipe calls `NewIfToken` [Link: here]. When that gets passed to the `NewGitLab` function, it's returning a client using the CI_JOB_TOKEN again from [Link: this] stanza:

```go
	if ctx.Config.GitLabURLs.UseJobToken {
		client, err = gitlab.NewJobClient(token, options...)
	} else {
		client, err = gitlab.NewClient(token, options...)
	}
```
If I'm reading that right, it means if UseJobToken is set to true, it's always going to return a client using the CI_JOB_TOKEN instead of a client that can use a personal access or project token.

Tryin to think of a workaround for that...
