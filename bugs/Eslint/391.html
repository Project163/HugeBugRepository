Title

no-shadow ignores function and class names that shadow outer vars

Description
``` js
(function a() {
  function a(){}
})()
```

This should have a `no-shadow` error, but does not. Same goes for 

``` js
(function a() {
  class a{}
})()
```

``` js
(function a() {
  (function a{});
})()
```

``` js
(function a() {
  (class a{});
})()
```

This behaviour is undocumented and was introduced in [Link: an upgrade of escope].
Discussion
- Are you saying this may be an escope bug?
- No. These are [Link: explicitly ignored] for some reason. The comment does not explain why. The "upgrade of escope" commit also changed unrelated things like this.
- They aren't unrelated - escope changed how things worked, so our code had to change accordingly based on the tests we already had.
