Discussion
- @mahi-kandiar after the 3.6.9 release a check was included which valides the configuration for injecting rest links. The way you are using it is incorrect, but was silently ignored upto release 3.6.9. Which is why you are getting the IllegalStateException. You are using the `HalCollectionWrapper` to provide the links. The annotations should then not be used. 

Looking at the code I assume you want to have paging support. I'm not sure paging is supported in general for `resteasy-reactive`. If you are working with entities you could take a look at [URL] which shows how to use paging with `rest-data-panache`.
- Thank you @bpasson. Removing the annotations fixed it. Regarding panache, I don't have control over the data access layer yet. Would you be kind and remove the annotation at [URL] too please. If I add that annotation, the exception reappears.
- @mahi-kandiar Looking at that documentation mentioning the possibility to add extra links programmatically, this might still require a fix. It seems it was broken already before my PR. Could you reopen the issue? I will see if I can come up with a fix.
