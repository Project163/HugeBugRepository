Title

Bug in `first_or_initialize` after recent change to quoting

Description
find_or_initialize results in badly quoted strings if string value was specified as an integer.

``` ruby
a = Person.where(:name => 3).first_or_initialize
a.name
=> "'3'" # Notice the extra quotes!

a = Person.where(:name => 3.to_s).first_or_initialize
a.name
=> "3"
```
