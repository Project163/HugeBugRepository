Title

Phrase Suggester "size" should override "shard_size" when searching on index with 1 shard

Description
When using the phrase suggester against and index with 1 shard, setting the "size" parameter > 5 will not return the correct number of suggestions unless you also set "shard_size" to the same number.   The minimum "shard_size" should be set to something like ceil(size/num_shards) to ensure the correct number of suggestions are returned.
Discussion
- hey @mattweber I pushed a fix for this to simply use the size as the shard size if it isn't explicitly specified. I mean there could be situations where you want this behaviour so we should support it but be smarter by default. Thanks for reporting
