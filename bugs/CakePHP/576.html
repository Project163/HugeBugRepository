Title

pagination union

Description
CakePHP 3.0
Pagination does not work on union query.

Users belongsToMany Contacts

```
php
$myContacts = $this->Contacts->find()
                ->matching('Users', function($q) {
                        return $q->where(['Users.id' => 1]);
                    });
... [Log Snipped] ...
$contacts = $myContacts->union($hisContacts);
$this->set('contacts', $this->paginate($contacts));
```

This gives the following error: SQLSTATE[21000]: Cardinality violation: 1222 The used SELECT statements have a different number of columns
Discussion
- Closing as there is a pull request open
- I got back to this problem. The update solved the original problem, but pagination's sorting still does not work.
Clicking on $this->Paginator->sort('name'), or try $this->set('contacts', $this->paginate($contacts->order(['name']))); gives the same error.
The ORDER BY statement added to the first SELECT and not to the end of the whole union. So the SQL query gives an Incorrect usage of UNION and ORDER BY error.
- The problem are describing here is unlikely to be fixed, as there are many different valid interpretations of what the correct output should be.
- For @rrd108 and anyone else having trouble working with union queries, the answer to [Link: this Stack Overflow question] points out that `Query::epilog()` (a method not currently in the docs) can be used to solve this problem.
