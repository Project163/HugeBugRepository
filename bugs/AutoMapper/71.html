Title

Static field requires null instance, non-static field requires non-null instance

Description
We just upgraded AutoMapper from 10.0.0 to 10.1.0 and the Microsoft DI extension from 8.0.1 to 8.1.0. It broke during automated testing with XUnit, in a .net core 3.1 environment, with c#8 and nullable reference types enabled.

In the test we scan the same assemblies for profiles as in the main application, and then do IMapper.ConfigurationProvider.AssertConfigurationIsValid().

When updateing from 10.0.0 to 10.1.0 the tests break when trying to resolve IMapper through an IServiceProvider, with this stack trace:
```
System.ArgumentException
Static field requires null instance, non-static field requires non-null instance. (Parameter 'expression')
   at System.Linq.Expressions.Expression.Field(Expression expression, FieldInfo field)
   at System.Linq.Expressions.Expression.MakeMemberAccess(Expression expression, MemberInfo member)
   at AutoMapper.Execution.TypeMapPlanBuilder.CreatePropertyMapFunc(IMemberMap memberMap, Expression destination, MemberInfo destinationMember)
... [Log Snipped] ...
   at Microsoft.Extensions.DependencyInjection.ServiceProviderServiceExtensions.GetRequiredService[Link: T]
   at ApplicationName.Application.Tests.MappingTests..ctor(IServiceCollection services) in C:\***\ApplicationName.Application.Tests\MappingTests.cs:line 12
```

I read the release notes for [Link: 10.1.0] but I did not see any breaking change there that might cause this. Do you have any idea what would cause an exception like this?
