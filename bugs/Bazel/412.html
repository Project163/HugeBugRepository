Title

An empty external/ directory causes java.lang.NullPointerException

Description
Creating an external/ directory under the workspace is a stupid thing. However, due to the lack of useful debug information, I spent like 10 minutes before discovered it was caused by my stupidness. Maybe we could use some better diagnostics.
Discussion
- Can you provide steps to reproduce? Just doing a `mkdir external` and building various targets isn't causing an NPE for me.
- I can reproduce it with the following steps:

```
$ mkdir empty_project
$ cd empty_project
$ touch WORKSPACE
$ bazel build //...:all
ERROR: no targets found beneath ''.  // This is a reasonable error message
$ mkdir external
$ bazel build //...:all
*Bazel now throws NPE*               // This confuses people
```

Possibly related: `bazel build //external:all` always throws NPE, regardless if you have the `external` directory.
