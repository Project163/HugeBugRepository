Title

Error code misc and build errors

Description
It probably shouldn't be possible to "disable" build errors at all, let alone under an overloaded and innocuous looking error code (note the new, clearer summary for blocking errors is unreleased / from [URL]

```
λ mkdir -p package/a  
λ mkdir -p package/b
λ echo 'x: int = "asdf"' >> package/b/x.py
λ echo 'y: str = 0' >> package/a/x.py
λ echo 'another_error: int = "adsf"' > package/unrelated.py
... [Log Snipped] ...
λ mypy package --show-error-codes --disable-error-code misc
Success: no issues found in 3 source files
```

Thanks to @ehossack for mentioning that people are doing this.
