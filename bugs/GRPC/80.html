Title

Fail to build grpcio_reflection when using grpc as bazel external dependence

Description
### What version of gRPC and what language are you using?

Python

### What operating system (Linux, Windows,...) and version?
Ubuntu 20.04

### What runtime / compiler are you using (e.g. python version or version of gcc)
Python 3.8.10
gcc 9.4.0

### What did you do?
A minimal demonstration.
```
# WORKSPACE file
load("@bazel_tools//tools/build_defs/repo:http.bzl", "http_archive")

_RULES_PYTHON_VERSION = "0.8.0"
http_archive(
... [Log Snipped] ...
    requirements = "@com_github_grpc_grpc//:requirements.bazel.txt",
)
```

running 
```
bazel build -s @com_github_grpc_grpc//src/python/grpcio_reflection/grpc_reflection/v1alpha:reflection_py_pb2_grpc
```
shows
```
ERROR: /home/user/.cache/bazel/_bazel_user/ /external/com_github_grpc_grpc/src/python/grpcio_reflection/grpc_reflection/v1alpha/BUILD.bazel:24:16: output 'external/com_github_grpc_grpc/src/python/grpcio_reflection/grpc_reflection/v1alpha/reflection_pb2_grpc.py' was not created

Target @com_github_grpc_grpc//src/python/grpcio_reflection/grpc_reflection/v1alpha:reflection_py_pb2_grpc failed to build

### What did you expect to see?
I'm trying to use grpc_reflection on a bazel project with grpc as external dependency, which should depend on `"@com_github_grpc_grpc//src/python/grpcio_reflection/grpc_reflection/v1alpha:grpc_reflection"`. Such python library will fail to build due to  the above issue.
