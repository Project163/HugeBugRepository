Title

space-before-keywords in jsx context (bug)

Description
In js, 

``` js
/*eslint space-before-keywords: [2, "always"]*/
(function() {})()
```

is not considered an error.

But in jsx

``` jsx
/*eslint space-before-keywords: [2, "always"]*/
onClick={function foo() {…}}
```

flags one (using v1.4.1)
Discussion
- Could you provide console output of the error please?
- `Missing space before keyword "function". (space-before-keywords)`
- hmm, maybe `space-before-keywords` should not concern itself with spaces between `{` and keywords but instead let `block-spacing` handle them... I'm happy to work on this but would love to hear what others think :)
- Sounds good. You should double-check how this works right now outside of JSX.
