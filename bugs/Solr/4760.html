Title

ResourceLoader should better respect allowed paths

Description
ResourceLoader only returns files relative to instanceDir or resources from Classpath, but we have a few file-exists checks that are done prior to these checks, which can cause weird bugs. In this issue we'll clean up this, along with a few refactorings and code simplifications.
