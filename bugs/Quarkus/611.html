Title

Unable to run docker image + jdk 11 + maven +ubuntu

Description
**Describe the bug**
Docker image built with `quarkus-container-image-docker` not working.

**Expected behavior**
Service should run with docker image

**Actual behavior**
Service failed when starting but works in dev mode .


**To Reproduce**
Steps to reproduce the behavior:
1. mvn clean package -Dquarkus.container-image.build=true
2. docker build -f src/main/docker/Dockerfile.jvm -t quarkus-service .
3. ocker run -it quarkus-service -p 9092:9092 -e QUARKUS_HTTP_PORT=9092
