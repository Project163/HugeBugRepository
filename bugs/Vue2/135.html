Title

filter with empty arguments cause error in chrome 57-

Description
### Version
2.5.13

### Reproduction link
[Link]

### Steps to reproduce
in chrome 57 and 56, 

1. filter with empty arguments:

    ```html
     {{text | someFilter()}} 
    ```

2. when no parentheses:

    ```html
     {{text | someFilter}} 
    ```


### What is expected?

1. no error
2. no error

### What is actually happening?

1.in chrome 57 and 56, report error:

```
[Vue warn]: Error compiling template:

 {{text | someFilter()}} 

- invalid expression: Unexpected token ) in
... [Log Snipped] ...

(found in  )
```

2.no error

---
I have also examined the chrome 58 and 63 which have no errors both, so i guess this bug only occurs in chrome 57-.
