Title

XMLBuilder makes broken XML if data contains &

Description
data = ['Rod':  ['Misha':'a & b', 'Bowie':2] , 'Eric':  ['Poe':4, 'Doc':3] ] 
xml = new groovy.xml.MarkupBuilder() 
people = xml.people(){ 
	for(entry in data){ 
		person(name: entry.key){ 
			for (dog in entry.value) 
{
				pet(name:dog.key, age:dog.value)
			}
 		} 
	} 
} 

 produces: 

 <people> 
  <person name='Rod'> 
    <pet name='Bowie' age='2' /> 
    <pet name='Misha' age='a & b' /> 
  </person> 
  <person name='Eric'> 
    <pet name='Poe' age='4' /> 
    <pet name='Doc' age='3' /> 
  </person> 
</people> 

 which is broken xml
Discussion
- There is a convenient place in MarkupBuilder to add support for this. We could call it an enhancement rather than a bug, since it's easy to work around by providing the escaped character entities in Groovy. Nevertheless, there is already support for escaping single-quote characters in MarkupBuilder, so I am adding same support for ampersand, greater-than and less-than characters.
- NOTE: something else I noticed – no support for XML comments or CDATA in MarkupBuilder. It might be handy to provide some helper methods such as comment() and cdata() for use in MarkupBuilder, but, not sure how to add that right now.
- Fixed for element and attribute values, so this example markup builder sytnax: 
// create MarkupBuilder . . . 
chars = builder.chars() { 
            ampersand(a:"&", "&") {} 
            quote("\'") {} 
            lessthan(attr: "value", "chars: & < > \'") {} 
            element(attr: "value 1 & 2", "chars: & < > \' in middle") {} 
            greaterthan(">") {} 
        } 

 Will come out looking like this in XML: 
<chars> 
  <ampersand a='&'>&</ampersand> 
  <quote>"</quote> 
  <lessthan attr='value'>chars: & < > "</lessthan> 
  <element attr='value 1 & 2'>chars: & < > " in middle</element> 
  <greaterthan>></greaterthan> 
</chars>
