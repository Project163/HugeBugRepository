 The exception happens when executing task stage-2. The ReduceSinkDesc for RS10 has keycols type as  
{int, map<string,string>, int}
  and the intermediate file for this table is stored in SequenceFileInputFormat and using LazyBinarySerDe. However, the LazyBinarySerDe is not able to deserialize non-primitive type from the intermediate file which causes the exception.    

 Using the TextInputFormat and LazySimpleSerDe for the intermediate file, the exception is gone. However, changing the intermediate file InputFormat and SerDe is not a preferred solution.
