Title

Cells inside subdirectory

Description
This is a (multiple allowed):
- [x] bug
- [ ] enhancement
- [ ] feature-discussion (RFC)
- CakePHP Version: 3.2.5
- Platform and Target: Apache 2, PostgreSQL 9.4
### What you did

I tried to use cells withing subdirectory, e.g. `src/View/Cell/Admin/AdminMenuCell.php` and call ` cell('Admin/AdminMenu') ?>` inside of the view file.

The display file is: `src/Template/Cell/Admin/AdminMenu/display.ctp`
### Expected Behavior

It should load the cell.
### Actual Behavior

The error says `Could not render cell - Cell view file "display" is missing. [CORE/src/View/Cell.php, line 264`.

I would say an issue within in these lines: [URL]

Currently it expects the display file to be in `src/Template/Cell/AdminMenu/display.ctp`
Discussion
- `$this->cell('Admin/AdminMenu')` is not a valid cell name.

You are assuming that cells are named the same way as elements, but they are classes and follow Cake's naming convention for `plugin.classname` patterns.

Someone correct me if I'm wrong.
- @Laykou Is your Cell in the `App\View\Cell\Admin` namespace? Looking at how the [Link: template paths are generated] it won't handle sub-namespaced cells. Until this issue is fixed you can always set the templatePath manually:

``` php
// In the cell action
$this->viewBuilder()->templatePath('Cell/Admin/AdminMenu');
```

- Using `Prefix/Name` style doesn't work for generating any class type except when generating plugins. Have you instead tried using option `--prefix Admin` when baking the cell?
