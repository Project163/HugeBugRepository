- If you change the light to a `SpotLight`, your program works correctly.

This is a bug in setting the `#defines` in the shader. To get your program to work with a `DirectionalLight`, the following change in `ShaderChunks.js` must be made _everywhere it occurs_.

```
-   "#if MAX_SPOT_LIGHTS > 0 || defined( USE_BUMPMAP )",
+   "#if MAX_SPOT_LIGHTS > 0 || defined( USE_BUMPMAP ) || defined( USE_ENVMAP )",
```

The problem is that while this change guarantees that all needed variables are defined when needed, it leads to warnings if the only material texture is an environment map.

```
 WARNING: Output of vertex shader 'vWorldPosition' not read by fragment shader
```

Getting the `#defines` correct is a little tricky...
