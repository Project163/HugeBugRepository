Title

[yii\validators\EmailValidator] $checkDNS does not work on alpine

Description
### What steps will reproduce the problem?

Fire up Yii in php container from alpine linux
Make a `yii\validators\EmailValidator` with `$checkDNS` option being `true`
validate for example `test@dfjkdfjkdf.dk`

### What is the expected result?

this email is invalid due to host not existing

### What do you get instead?

email is perfectly valid

### Additional info
`checkdnsrr()` returns true always on alpine linux even tho `dns_get_record()` returns empty array
