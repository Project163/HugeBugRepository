Title

markUnused set to false adds @@ anyway

Description
### What steps will reproduce the problem?
Running `yii message path/to/config` and having manually added translations to the messages files - just keys, with empty values.

### What is the expected result?
When markUnused is set to false, the @@ tags shouldn't be added.

### What do you get instead?
The @@ tags are added.

### Additional info
The translations are kept in files.
I've got some messages, that are translated dynamically, so they won't be extracted from sources, hence I add them manually. The source language has only keys defined, with empty values.
This doesn't occur when the value is not empty.
It also happens on extracted messages with empty value that are not being used.
