Discussion
- This is actually not an issue with animations (or mdTabs), but with angular.io.

It happens because of [this line][1], which is supposed (based on the comment) to just remove the ripple effect (no idea why 😞), but is sure does more than that :smiley:
While animating, mdTab will set a `transform` style on the tab content element, which should have no effect (due to our `transform: none !important` style afaict), so Firefox seems to do the right thing. For some reason, Chrome doesn't respect the `!important` part and executes the animation anyway.
