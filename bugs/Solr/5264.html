Title

CoreContainer does not obtain a lock when unloading cores

Description
CoreContainer uses  solrCores.waitAddPendingCoreOps(name)  when doing an operation on a core. And the documentation for  SolrCores.waitAddPendingCoreOps(name)  mentions that: 

  // Wait here until any pending operations (load, unload or reload) are completed on this core.  

 However, CoreContainer does not use this locking when unloading a core. This is the reason why we are seeing race condition issues when deleting and reloading a collection at the same time. 

 Loading a core can possibly require unloading said core, when "deleteUnknownCoresOnStartup" is used, thus we need a way of unloading without a lock. But other than this edge case, locking the unload operation should only improve stability in Solr.
