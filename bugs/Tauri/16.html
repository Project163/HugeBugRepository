Title

cli must not be null

Description
**Describe the bug**
```
 ERROR: tauri.conf.json > tauri > cli should be object +0ms
error Command failed with exit code 1.
```

A fresh app has an invalid object:
```
  "tauri": {
    "cli": null,
```

**To Reproduce**
Steps to reproduce the behavior:
1. `yarn tauri init`
2. `yarn tauri dev`

**Expected behavior**
No error and an appropriate config object shape.
Discussion
- To fix: track down the template file, replace `null` with `{}`.

Happy hunting
- Temporary Fix: remove `"cli": null,` entirely.
- I am also a little concerned that our test harness did not catch this. 
`yarn tauri init` + `yarn tauri dev` should have `exit code 1` and broken the test, thereby stopping the release.
