## Current behavior
 
In an app with custom routing behavior (without _router-outlet_) everything works fine but when navigating from a path with a parameter to the same path with another parameter value.
It then crashes with the error **_TypeError: Cannot read property 'component' of null_** in the router function **_PreActivation.traverseRoutes_**

## Expected behavior
 
No error, or not being able to use the router without any outlets.
