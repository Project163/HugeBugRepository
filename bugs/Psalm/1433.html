Title

Multiple array/list are incorrectly merged as return type

Description
Symfony has a fairly complex return type specified on their [Link: EventSubscriberInterface].

`@return array >`

I copied both their `@return` and the phpdoc (which includes examples), so you can just read the psalm.dev-snippet:

[URL]

When using the most complex variant (a string-key => list of array ), Psalm fails to recognize that.

```
does not match the declared return type array , array{0: string, 1?: int}>}|string>
```

So according to Psalm the array-value should be either of these:
- `string`
- `array{0?: array{0: string, 1?: int}|string, 1?: int, ... , array{0: string, 1?: int}>}`

That second option seems to be a mix of the array and list options from the phpdoc, but merged such that this bit doesn't match anymore, while it should match the list-option:
```
'b' => [
                ['methodB1', 0],
                ['methodB2', 10],
            ],
```

The snippet also fails with only the above key 'b'.
