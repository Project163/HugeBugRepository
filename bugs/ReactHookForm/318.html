Title

issue: Stange behaviour isValid form state

Description
### Version Number

7.17.5

### Codesandbox/Expo snack

[URL]

### Steps to reproduce

The value of isValid is different from exporting useFormState and exporting useForm.
The result is therefore incorrect via useFormState.

My form is here in onBlur mode but I want to have specific fields with onChange so I am using the trigger on my onChange for this field.

I invite you to uncomment my sandbox code in order to see the problem.
The values ​​displayed by the export of useFormState are not logical (undefined)

Example in sandbox with useFormState:
- value length = 5 -> isValid = undefined
- value length = 6 -> isValid = true
- value length = 7 -> isValid = undefined

Example in sandbox with useForm:
- value length = 5 -> isValidUseForm = false
- value length = 6 -> isValidUseForm = true
- value length = 7 -> isValidUseForm = true

Example in sandbox with useForm **AND** useFormState:
- value length = 5 -> isValid = isValidUseForm = false
- value length = 6 -> isValid = isValidUseForm = true
- value length = 7 -> isValid = isValidUseForm = true

However, if I export both at the same time, it fixes the export of useFormState.

Tested only on isValid

### Expected behaviour

Same Result when i use useFormState and export from useForm

### What browsers are you seeing the problem on?

Chrome
