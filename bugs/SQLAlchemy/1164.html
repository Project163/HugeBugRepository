Title

"bake" flag documentation / caching control for loaders

Description
the "enable_baked_queries" flag on Session has misleading documentation.  it only applies to the legacy "Baked" query extension which is seldom used and is no longer used by the ORM.   so this should be clarified.

next, the "bake_queries" flag on relationship() only has partial effects with the lazy loader; it will cancel the internal "lambda" process but does not actually disable query caching.   the docs for this flag should be chagned to reflect that this disables a partiular internal thing, but to turn off caching, this should be done engine-wide.   or if bake_queries is False then we send compiled_cache=None:

```

         if self._order_by:
```

finally, there realy should be a way to disable caching for real, in the engine.  right now you can disable ORM query caching like this:

```
from sqlalchemy import event
@event.listens_for(Session, "do_orm_execute")
def do_orm_execute(execute_state):
    execute_state.update_execution_options(compiled_cache=None)


```

but an engine that has query_cache_size=0 should probably refuse to do any caching for anyone, including lazy loaders that send another cache in.   or we have a whole new flag "enable_caching=False", which means any compiled_caches passed in are also ignored.   we would need to note this at query_cache_size as well.      it's good to be able to fully turn the caching off entirely for debugging.
Discussion
- note also that LazyLoader is not using the strategy-local statement cache for loads that are not use_get, apparently.   We should likely move to having LazyLoader/SelectInLoader use the regular engine cache for statement caching and their own local cache just for the lambda part of it.
- I'm trying to disable caching on 1.4.15, and I can't get the above to work. The `compiled_cache` option doesn't seem to be updated to `None`, and this breakpoint is hit:

```py
@event.listens_for(Session, "do_orm_execute")
def do_orm_execute(execute_state):
    execute_state.update_execution_options(compiled_cache=None)
    after = execute_state.execution_options.get("compiled_cache")
    if after is not None:
        breakpoint()
```
