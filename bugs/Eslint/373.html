Title

no-wrap-func rule does not catch parenthesised FEs in certain positions

Description
This program will trigger no warnings when the `no-wrap-func` rule is enabled, though I would expect one per line:

``` js
a[(function(){})];
f((function(){}));
new f((function(){}));
```
Discussion
- @michaelficarra I think this rule was meant for function declarations/expression vs. invocation. It's been a long while since I wrote that rule, but based on documentation, the original idea was to disallow parentheses to provide visual difference between functional expression and IIFE.
- Sorry ignore the comment above. I missed the first example, which is a bug no matter what.
