Title

redirection in reactive code examples is unnecessarily verbose

Description
### Describe the bug

In the reactive code examples, the following idiom is used:

```java
public Uni  create(Fruit fruit) {
	return Panache. withTransaction(fruit::persist)
			.onItem().transform(inserted -> Response.created(URI.create("/fruits/" + inserted.id)).build());
}
```

But this is much too verbose, and the call to `onItem().transform()` should be replaced with `replaceWith()`:

```java
public Uni  create(Fruit fruit) {
	return Panache. withTransaction(fruit::persist)
			.replaceWith(Response.created(URI.create("/fruits2/" + fruit.id)).build());
}
```
