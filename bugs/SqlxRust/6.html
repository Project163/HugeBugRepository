Title

Description
sqlx version: 0.3.2
database: postgres 10.12
os: ubuntu 18.04
cargo: 1.42.0

To reproduce create a cargo project with following main.rs file and execute "cargo build":
```
#[derive(sqlx::Type)]
#[sqlx(rename = "order_type")]
struct OrderType {
    price: String,
    quantity: String,
```
