Title

Upgrade jodd-core due to CVE-2018-21234

Description
Hive makes use of 3.5.2 version of the `jodd-core` library which is susceptible to CVE-2018-21234. Below is a description of that vulnerability. 
CVE-2018-21234  suppress 

 Jodd before 5.0.4 performs Deserialization of Untrusted JSON Data when setClassMetadataName is set. 
CWE-502 Deserialization of Untrusted Data 

 CVSSv2: 
Base Score: HIGH (7.5) 
Vector: /AV:N/AC:L/Au:N/C /I /A  
CVSSv3: 
Base Score: CRITICAL (9.8) 
Vector: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H 

 References: 
MISC -  [URL] -  [URL] -  [URL] Software & Versions: 
cpe:2.3:a:jodd:jodd: : : : : : : :  versions up to (excluding) 5.0.4 
  

 This library needs to be upgraded. We use a couple of classes `JDateTime`( [URL] ) and `HtmlEncoder`, which have either been deprecated and/or have been moved to a different package called jodd-util.
