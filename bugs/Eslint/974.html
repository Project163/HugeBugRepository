Title

Allow setting "extends" via the Node.js API

Description
The [Link: `CLIEngine` constructor] seems to be missing an `extends` option.

My workaround is to use `baseConfig`, like this:

``` js
var CLIEngine = require("eslint").CLIEngine
var cli = new CLIEngine({
  baseConfig: {
    extends: [ 'standard' ]
  }
})
```

Is there a reason why this isn't exposed like `rules`, `globals`, `env`, etc.?
