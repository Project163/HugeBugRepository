Using multiple "[@triggerName]" on single element stops removal of node after ":leave" animation completes

## Current behavior
When using multiple `[@triggerName]` attributes on a single element, then when `'* => void'` or `:leave` completes, the node that was about to be removed from the DOM is not removed.

Okay:

```html
 
```

Not okay (but fine in Angular 4.4.6):

```html
 
```

## Expected behavior
The node which removal triggered the animation, should be removed after the animation completes.

Note: this **assumes** that defining multiple `[@triggerName]` attributes is actually supported. 

Using multiple `[@triggerName]` attributes worked in Angular 4.4.6, but it seems it was not actually documented. In Angular 5, this no longer works. The extensive example at [URL] might indicate that one should use at most one `[@triggerName]`, in which case the bug report is moot and the documentation might simply be clarified instead.
