Title

TypeError in CsrfProtectionMiddleware

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 4.2.8
* Platform and Target: nginx, php-fpm 7.4.23

### What you did
After update from 4.1.7, where issue with malformed/crafted cookies/form-params was manifested by NoticeException **Array to string conversion** on line 300 of vendor/cakephp/cakephp/src/Http/Middleware/CsrfProtectionMiddleware.php

In 4.2.8 it's manifested by TypeError **strlen() expects parameter 1 to be string, bool given** on line 281 of vendor/cakephp/cakephp/src/Http/Middleware/CsrfProtectionMiddleware.php

### What happened
Someone enumerating/bruteforcing endpoints crafted request and provided invalid values where CsrfProtectionMiddleware expected valid, previously framework-set, data.
