Discussion
- Looks like most modules are also missing a peer dependency on rxjs - core has it, but of the modules I have installed, it's missing from common, compiler, platform-browser, platform-browser-dynamic. Most likely in some others too. 

These missing dependencies cause issues automating dependencies using the package.json files. In my case, I'm using JSPM to generate a systemjs config file, which scopes each module as a systemjs package such that they can't request dependencies from other modules that they don't themselves declare.

To repro, use jspm to install any module, say @angular/upgrade:
`jspm install npm:@angular/upgrade`
Produces a systemjs config file with the relevant section:

... [Log Snipped] ...
```
