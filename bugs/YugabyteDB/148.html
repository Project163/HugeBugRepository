Title

[YSQL] Index entries not deleted in a DELETE statement

Description
When a row is deleted from a table with index, the index entry is not deleted. This can cause a subsequent insert to fail when the index is unique. For example,

```
postgres=# create table t (k int primary key, v int); 
CREATE TABLE
postgres=# create unique index on t (v);
CREATE INDEX
postgres=# insert into t values (1, 1);
... [Log Snipped] ...
postgres=# insert into t values (1, 1);
ERROR:  Query error: Duplicate key found in primary key or unique index
```
