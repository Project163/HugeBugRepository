Title

yii\console\widgets\Table fail rendering with associative array as rows

Description
### What steps will reproduce the problem?
As console command/application
```
echo Table::widget([
    'headers' => ['Project', 'Status', 'Participant'],
    'rows' => [
        ['project'=>'Yii', 'status'=>'OK', 'Participant'=>'@samdark'],
        ['project'=>'Yii', 'status'=>'OK','Participant'=> '@cebe'],
    ],
]);
```
### What is the expected result?
```
╔═════════╤════════╤═════════════╗
║ Project │ Status │ Participant ║
╟─────────┼────────┼─────────────╢
║ Yii     │ OK     │ @samdark    ║
╟─────────┼────────┼─────────────╢
║ Yii     │ OK     │ @cebe       ║
╚═════════╧════════╧═════════════╝

```
### What do you get instead?

```
╔═════════╤════════╤═════════════╗
║ Project │ Status │ Participant ║
╟─────────┼────────┼─────────────╢
║         │        │             ║
╟─────────┼────────┼─────────────╢
║         │        │             ║
╚═════════╧════════╧═════════════╝
```
