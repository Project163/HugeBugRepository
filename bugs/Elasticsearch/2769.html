Title

significant_texts aggregation not working for multi-field

Description
Elasticsearch version: 7.14.0
Java version: 1.8.0_73
OS version: Windows 10

After upgrading to v7.14.0 significant_texts aggregations no longer work for multi fields. This was working before v7.14.0 . But now it doesn't work including v7.16.3.

Steps to reproduce:
```
sh
# create the index
curl -XPUT "[URL] -H 'Content-Type: application/json' -d '
{
  "mappings": {
... [Log Snipped] ...
  "size": 0
}'
```

before v7.14.0 the result was as follows
```
json
{
  "took" : 3,
  "timed_out" : false,
  "_shards" : {
... [Log Snipped] ...
  }
}
```

but after v7.14.0 the result is 
```
json
{
  "took" : 16,
  "timed_out" : false,
  "_shards" : {
... [Log Snipped] ...
  }
}
```
