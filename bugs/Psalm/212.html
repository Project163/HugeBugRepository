Title

Incorrect return type for core next() function

Description
I'm getting false positive `MoreSpecificReturnType`/`LessSpecificReturnStatement` issues from `next()` but not from `reset()`

Both `next()` and `reset()` are supposed to return an array element or false on failure. Since the parameter in question is typehinted as `array[]` the result of `reset($trace)` must be `false|array`.

The same should apply to `next($trace)` but psalm is identifying that as 'mixed' causing the false positive. Here's a demonstration:

```
php
 , caller:mixed}' is more general than the declared return type 'array{callee:array |false, caller:array |false}' for test

INFO: MoreSpecificReturnType - 6:12 - The declared return type 'array{callee:array |false, caller:array |false}' for test is more specific than the inferred return type 'array{callee:false|array , caller:mixed}'
```
