Title

bash-autocompletion does not recognize files and paths

Description
If your command parameter is a local file or path, it would be nice to have the "standard" autocompletion.
Would be OK if this is just done when using `/` or `.` as the first char.

### What steps will reproduce the problem?

     yii db/import /dumps[TAB][TAB]

### What is the expected result?

     yii db/import /dumps/my-dump.sql

### What do you get instead?

     yii db/import /dumps
