Title

HostBinding style parsing fails for custom properties with numbers under Ivy

Description
# 🐞 bug report

### Affected Package
The issue is caused by package @angular/core

### Description
Custom properties with names that contain numbers cannot be used in a host binding with the Ivy renderer. It works fine if the custom property doesn't contain a number.
