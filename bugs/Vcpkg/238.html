Title

[pcre2] jit causes crashes on macOS

Description
### Is your feature request related to a problem? Please describe.

I'm having crashes on macOS because of PCRE2's JIT as it's being used by QRegularExpression in Qt. We're using the Qt 6 `qtbase`, but I would assume this issue should happen with Qt 5 as well.

### Proposed solution

Add `& !osx` to the supported platforms for the `jit` feature for PCRE2.

### Describe alternatives you've considered

Disabling it by setting `default-features` to `false` for PCRE2 in vcpkg.json, but this does not seem to apply when it is a transitive dependency.
