Title

Error page handling does not respect ssr: false in handle() hook

Description
### Describe the bug

I have a handle() function in my hooks.js which always returns ssr: false to the resolve function.  This works.

But if I browse to a non-existent page, SvelteKit appears to import my __layout.svelte, then import __error.svelte, then call the load() function in both files, on the server.  On the client, I see the same, then it runs the client side script block.
