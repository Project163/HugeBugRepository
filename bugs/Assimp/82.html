Title

matrix4x4 operator[] is broken

Description
The operator[Link: ] of matrix4x4 gives me nonsense values, probably from uninitialized memory. According to the comment in [matrix4x4.inl:243], that's a known problem.

Code snippet that reproduces the problem:

```
aiMatrix4x4 transform = node->mTransformation;

std::cout  .000000   - .000000     -322887.250000  -322887.281250
  -322889.093750    - .000000     -322887.250000  0.000000
  0.000000  0.000000    0.000000    0.000000 ]
... [Log Snipped] ...
  0.000000  0.000000    1.000000    0.000000
  0.000000  0.000000    0.000000    1.000000 ]
```
Discussion
- Some system information:

```
distribution:     Ubuntu 14.04.3 LTS

CMAKE_BUILD_TYPE: Debug
```

- Thanks a lot for the report, I will fix that issue!
- Checked this: the []-operator will return a pointer showing to the first entry of the row of the matrix. I added a test to show this.
You can use it as following:

```
TEST_F( utMatrix4x4Test, indexOperatorTest ) {
    aiMatrix4x4 m;
    float *a0 = m[ 0 ];
    EXPECT_FLOAT_EQ( 1.0f, *a0 );
    float *a1 = a0+1;

}
```
