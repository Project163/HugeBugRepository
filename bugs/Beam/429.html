Title

Spark runner does not shut down after pipeline completion

Description
The Spark runner creates a transient executor service to run pipelines, but never tears it down. This prevents graceful JVM termination after pipelines have completed. 

 A fix should shut down the service once all asynchronous jobs have been submitted.
