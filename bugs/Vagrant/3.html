Title

Issue with cable not connected with the VirtualBox 4.3 provider and the host only adapter

Description
Vagrant 1.5.1 with the VirtualBox 4.3 provider plugin seems to have an issue with the "cable connected" checkbox for host-only adapter. This could possible affect VirtualBox 4.2 (and earlier, maybe) but I have not been able to verify that.

This issue causes VMs with host only adapters to not be visible in the network, which is quite annoying. Toggling the "Cable connected" checkbox fixes the issue.

This issue is related to #2906, but that only took care of the fix for bridged adapters. Compare this (https://github.com/mitchellh/vagrant/blob/master/plugins/providers/virtualbox/driver/version_4_3.rb#L106):

```
            if adapter[:bridge]
              args.concat(["--bridgeadapter#{adapter[:adapter]}",
                          adapter[:bridge], "--cableconnected#{adapter[:adapter]}", "on"])
            end
```

with this (https://github.com/mitchellh/vagrant/blob/master/plugins/providers/virtualbox/driver/version_4_3.rb#L111):

```
            if adapter[:hostonly]
              args.concat(["--hostonlyadapter#{adapter[:adapter]}",
                          adapter[:hostonly]])
            end
```

Adding the --cableconnected parameter to the hostonly configuration fixes the problem.

I can send a pull request for the fix in 4.3 for hostonly adapters; this may also affect other network adapters but I don't use them (nor do I have test cases for them) so I won't be able to verify the fix.
