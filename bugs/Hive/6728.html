Title

Follow redirects when hive connects to a passive druid overlord/coordinator

Description
When we have multiple druid coordinators/overlords and hive tries to connect to a passive one, it will get a redirect. Currently the http client in druid storage handler does not follow redirects. We need to check if there is a redirect and follow that for druid overlord/coordinator
