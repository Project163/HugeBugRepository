Title

Framework does not offer J2SE-1.2 Execution Environment

Description
The framework does not offer the J2SE-1.2 execution environment. The list of EEs offered by the framework when running on java 1.6 is as follows: 

     JavaSE-1.6,J2SE-1.5,J2SE-1.4,J2SE-1.3,OSGi/Minimum-1.2,OSGi/Minimum-1.1,OSGi/Minimum-1.0 

 I don't see any reason why that list excludes J2SE-1.2, JRE-1.1 and JRE-1.0.
