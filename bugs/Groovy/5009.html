- For the case of  CreatePluginCommand , super interfaces declare  getDescription()  and  setProfileRepository(org.grails.cli.profile.ProfileRepository) .  These are both implemented by Groovy properties of the super class  CreateAppCommand . 

 Property methods are added to a class by  Verifier#visitProperty .  As above, the inner class of  CreateAppCommand  results in a new order for classes during verification.  Adding an inner class to  CreatePluginCommand  can cause it to be processed after  CreateAppCommand  and the error then moves to  CreateProfileCommand .
