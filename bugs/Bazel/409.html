Title

Changing --action_env doesn't cause actions to be rerun

Description
E.g.,

```
$ bazel test --test_output=all --action_env=TZ=Local :tz_test 
...
timezone: Local
================================================================================
Target //:tz_test up-to-date:
... [Log Snipped] ...
================================================================================
//:tz_test                                                      (cached) PASSED in 0.0s
```

The only way to get it to pick up on the new value is by doing a clean in-between.
Discussion
- And I believe even then it wouldn't pick up the new value. For some strange historic
reasons (with some strong opinions upon) the test-environment does not inherit from
the action environment. Does using ``--test_env`` have the desired effect?
