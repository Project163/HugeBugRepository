Title

Zombie entries in cache with SortedEvictionPolicy

Description
Sometimes test  GridCacheConcurrentEvictionConsistencySelfTest.testPolicyConsistencySortedLocal  fails because cache contains entries that are untracked by  SortedEvictionPolicy .
Discussion
- After gathering trace info I noticed that one thread adds entry to backed collection, while other thread invokes  shrink , poll this entry from backed collection and doesn't invoke eviction because entry has no associated meta yet. Thus entry is removed from eviction policy but not evicted.
- Fixed. Also removed unreacheable code branch for LRU, FIFO and sorted policies.
- Merged into master branch.
