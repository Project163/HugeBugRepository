Title

camel-aws can allow SNAPSHOT transitive dependencies

Description
The camel-aws component depends on aws-java-sdk which has several dependencies defined using version ranges. The problem with version ranges is that they can introduce SNAPSHOT versions if they are available on your system which is not so good... in my case I had this  [URL] jar in my local repo so camel-aws promptly used that SNAPSHOT lib.
