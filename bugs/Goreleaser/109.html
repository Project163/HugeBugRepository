Title

Wrong paragraph breaks in man page

Description
### What happened?

The goreleaser man page has a bunch of errorneous paragraph breaks like this:

```
DESCRIPTION
       GoReleaser is a release automation tool for Go projects.

       Its goal is to simplify the build, release and publish steps while
       providing
... [Log Snipped] ...

       single .goreleaser.yaml file.
```

This is because the [Link: long description] has hard line breaks but the package you use to generate a man page from that takes any line break to mean a paragraph break.  Please fix the formatting of the man page so it is pleasant to read.

### How can we reproduce this?

Generate a man page with

    goreleaser man >goreleaser.1

and view it with

    man -l goreleaser.1 # linux
    mandoc -a goreleaser.1 # FreeBSD
