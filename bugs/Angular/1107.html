Discussion
- This is because StackBlitz uses the UMD bundles (instead of the ES2015 ones), so you need a polyfill.
You can add this at the bottom of `src/polyfills.ts` (and also install the dependency):

```ts
import '@webcomponents/custom-elements/src/native-shim';
```
