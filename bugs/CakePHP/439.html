Title

Controller doesn't load default model in plugins - fix in issue #3682 doesn't work

Description
In issue #3682 was added some fix, but it doesn't work.
In `__get()` method is

```
list($plugin, $class) = pluginSplit($name, true);
...
$this->loadModel($plugin . $this->modelClass)
```

, but `$this->modelClass` is still "Course.Courses", and with `$plugin` its like

```
$this->loadModel('Course.Course.Courses');
```

I think it should be

```
$this->loadModel($plugin . $class);
return $this->{$class};
```
