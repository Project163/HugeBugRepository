Title

repository_ctx.which('python') returns a directory called 'python'

Description
bazel/src/main/java/com/google/devtools/build/lib/bazel/repository/skylark/SkylarkRepositoryContext.java

contains a method which() which ostensibly does the same thing as the unix `which` command

```
private SkylarkPath findCommandOnPath(String program) throws IOException {
    for (String p : getPathEnvironment()) {
      PathFragment fragment = PathFragment.create(p);
      if (fragment.isAbsolute()) {
        // We ignore relative path as they don't mean much here (relative to where? the workspace
... [Log Snipped] ...
    return null;
  }
```

It is not sufficient to check if the path is executable, since directories are executable.  It should also check that the path is a file.

I ran into this problem because my path included a directory that itself contained a "python" directory, which meant that repository_ctx.which('python') returned the path to a directory instead of the real python binary.
