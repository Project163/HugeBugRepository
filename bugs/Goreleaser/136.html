Title

Error with the {{ .ReleaseURL }} templating field on Slack notification

Description
### What happened?

I enabled the Slack announce with the default `message_template` from a Gitlab CI/CD job and received a missing `{{.Env.CI_SERVER_URL}}` environment variable substitution in the message : 

```
myApp 2.0.0-rc1 is out! Check it out at {{.Env.CI_SERVER_URL}}/ /-/releases/2.0.0-rc1
```

I also tried it from my local and got the same. I was expecting this environment variable to be replaced.

### How can we reproduce this?

I tried to reproduce the behavior by exporting all environment variables needed and the `CI_SERVER_URL` one and tried a
