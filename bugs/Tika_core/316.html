Title

Text files starting with MOVI are detected as X-SGI-Movie

Description
If a plaintext file starts with "MOVI" Tika labels it as an SGI Movie. 

 The hex conversion for MOVI is 4D 4F 56 49 which is the same as the header for the SGI Movie file format 

  [URL]

   

 This SGI format isn't supported so any information from a text file starting like this would be lost. I've attached a simple file that should recreate the problem.
Discussion
- I regret that I know nothing about this format.

 I couldn't quickly find a signature in Pronom. 

  file  requires only "MOVI" 

   

 From the files linked here:  [URL] it looks like they all start with "MOVI\u0000".   

   

 Any objections to adding a 0x00 after MOVI?
- Assuming that the byte after MOVI is part of a version or length field, perhaps safest to check for 0x00 or 0x01 or 0x02? That shouldn't trigger on text, but probably would help with the detection of the real thing. (Some sort of "not a printable ascii field" is probably a step too far and probably wouldn't help much either!)
