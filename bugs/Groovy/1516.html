   int  a
}

@Immutable

- Grails compilation uses the Joint compiler. Currently, not all transforms are guaranteed to work with joint compilation. I have tweaked stub generation to not interfere with (the constructor creation part of) @Immutable. If you can test this out, that would be great. Only in 1.7.11-SNAPSHOT for now. Committed in subversion and should be available as a jar once the CI build finishes.
