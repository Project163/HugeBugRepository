Title

Scope Hoisting - Variable Rename Issue

Description
**Do you want to request a *feature* or report a *bug*?**

Bug

**What is the current behavior?**

the following code with scope hoisting goes wrong because the variable is not renamed

file1
```
export function a() {
}
```

```
import { a as b } from 'file1';

var c = {
    a: function a() {
        b();
    },
};
```

When scope hoisted, webpack ends up with the following

```
function a() {
}

var c = {
    a: function a() {
        a();
    },
}
```

**What is the expected behavior?**

Not sure ;- you'd need to create a new variable to do the rename
