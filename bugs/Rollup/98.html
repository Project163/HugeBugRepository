Title

SystemJS confused by missing semicolon after default export

Description
while trying to replicate [URL] I stumbled upon this issue. Sorry about the missing REPL (rollup/rollupjs.org#124).

test.js:
```
export default { x: 0 }
```
When compiled with ```rollup -f system test.js```, it contains
```
var test = exports('default', { x: 0 )}
```
Note the parenthesis and curly brace in wrong order.

After adding a semicolon the output is correct:
```export default { x: 0 };``` -> ```var main = exports('default', { x: 0 });```
