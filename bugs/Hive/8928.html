Title

Default port appended should respect transport mode when host is specified without port

Description
As of now, when the port is not specified in the JDBC URI, 1000 gets appended by default irrespective of transport mode being binary/http. 

 When HS2 is running in http mode and user tries to connect without specifying the port explicitly, it tries to connect to port 10000, running into error 

 Sample error: 
  
 
Error: Could not open client transport with JDBC Uri: jdbc:hive2: //localhost:10000/ default ;transportMode=http;httpPath=cliservice: Could not establish connection to jdbc:hive2://localhost:10000/ default ;transportMode=http;httpPath=cliservice: org.apache.http.conn.HttpHostConnectException: Connect to localhost:10000
