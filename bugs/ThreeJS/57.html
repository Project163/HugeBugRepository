Title

TextGeometry Parameters Defaults

Description
According to the source code of TextGeometry, each option should have a default. Surely this means that options are optional?

The following works perfectly fine:

``` javascript
var options = {
  size: 50,
  height: 20
};
var textGeometry = new THREE.TextGeometry("Hello World!", options);
var text = new THREE.Mesh(textGeometry, material);
scene.add(text);
```

However if I want to just use the defaults (which are a good place to start) by dropping options then it produces the following error:

Uncaught TypeError: Cannot read property 'height' of undefined 

This appears to be a bug.

Thanks,
Shane
Discussion
- Do you mean defaults by

```
var textGeometry = new THREE.TextGeometry("Hello World!");
```

That's because 

```
var textGeometry = new THREE.TextGeometry("Hello World!", {});
```

works.
- @ShaneHudson No no, not your fault. The API should have been a bit nicer to the user here. Solved!
