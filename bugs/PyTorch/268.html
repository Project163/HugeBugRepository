Title

[Inductor] F.pdist fails with "RuntimeError: _pdist_forward requires contiguous input" on non-contiguous inputs

Description
### 🐛 Describe the bug

When using `torch.compile` (Inductor backend) with `torch.nn.functional.pdist`, the compilation fails if the input tensor is non-contiguous (e.g., resulting from a `.permute()` or `.transpose()` operation).

The error message `RuntimeError: _pdist_forward requires contiguous input` indicates that the lowering logic for `pdist` does not automatically handle memory layout requirements (i.e., inserting a `.contiguous()` call), which is inconsistent with Eager mode behavior where this is handled transparently.
