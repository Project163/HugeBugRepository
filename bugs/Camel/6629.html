Title

StringSource and SourceCache using the isEmpty method will always return true

Description
When using StringSource#isEmpty or SourceCache#isEmpty it will always return true because the StreamSource#isEmpty of java 17 works on member variables instead of the getters.
Discussion
- The JDK17 implementation is 

     public boolean isEmpty()  
{
        return (publicId == null && systemId == null && isStreamEmpty());
    }

 And isStreamEmpty then fetches the input stream and check that. So that will check correct in camel. 
However we can optimize isEmpty to check the given input string directly instead, that is faster.
- Maybe i'am seeing it wrong but Java 17 use the member variable 'inputStream' and 'reader' (instead of getInputStream() and getReader()) which are both null in the StringSource which results in isEmpty returning true. 

   

 The linked pull Request would fix the problem
- The JDK implementation seems okay. But we have improved it for 4.3 with our own isEmpty method
