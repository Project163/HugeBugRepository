Title

The graph legend truncates at the nearest period (.) in its grouping

Description
To reproduce: 
Use the following query 
%sh echo -e "%table name\tgroup\tvalue\n1\t2.3.4.5\t100000" 
After running, select the line graph. Use name as keys, group as groups, and value as values. 
Expected 
Graph legend in top left and overlay displays   as a group. 
Actual 
Graph legend only shows 2 as a group (truncating off the rest of the number).
