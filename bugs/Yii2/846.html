Title

Console controller optionAliases are not always displayed in help text

Description
### What steps will reproduce the problem?

In a console controller, add an option that will render hyphenated, e.g. `numMessages`. Also add an alias for this option:
```
public function optionAliases()
{
    return array_merge([
        'n' => 'numMessages',
    ], parent::optionAliases());
}
```

### What is the expected result?

When rendering the help for the command, I expect the option to be rendered as
```
--num-messages, -n: text to go with option
```

### What do you get instead?

```
--num-messages: text to go with option
```

So  no option alias is rendered. It turns out that I need to specify the alias to the _rendered_ value of the option:
```
public function optionAliases()
{
    return array_merge([
        'n' => 'num-messages',
    ], parent::optionAliases());
}
```
