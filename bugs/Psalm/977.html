Title

Add a way to escape/unescape array keys of object-like arrays

Description
(aka. array shapes)

1. Escape the key if it contains characters that aren't in a whitelist (e.g. use similar escaping to string())

```
  'bar'];
echo strlen($value);
```

Note that the error output contains a literal newline, which may be a problem for some machine-readable formats

```
ERROR: InvalidArgument - src/what.php:3:13 - Argument 1 of strlen expects string, array{a
b:string(bar)} provided
echo strlen($value);
```

---

Also, any ideas on how to represent this?

I'd be in favor of `array{foo\\bar\nbaz:'literal'}` for the expression `["foo\\bar\nbaz" => "literal"]` (escape non-whitelisted characters)

Alternately, forcing those to be quoted (`array{'foo\\bar\nbaz':'literal'}`) may also work and allow using commas and `:` inside the key without escaping them, if the parser allowed it)
