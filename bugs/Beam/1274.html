 SGTM. We can expand the scope of inventory job to do the machine house keeping.
- This is done in #9138. One possible side-effect is that `docker system prune` races with docker-based builds: an unused image being removed while a build checks that it is there and tries to use it. 

 Another is increased downloads of images (since pruning is according to "created" not "last used" date): longer builds (should be negligible), flakes due to failed downloads (unaware of such issues).
