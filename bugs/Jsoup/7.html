Title

Should treat unknown tags as inline, not block

Description
See: [URL]

We should probably treat unknown tags as inline, rather than block tags. Otherwise an unknown tag within a ` ` causes the auto-closer to close the P, so `  Test  ` parses to `   Test `.

Need to think about what impact that would have on unknown tags that _should_ be blocks.

Thanks to François Goldgewicht (http://francois.goldgewicht.com) for reporting the issue.
Discussion
- Parse unknown tags as inline elements that can contain blocks.

Ensures `  Test  ` parses like that, and not
`   Test `.
