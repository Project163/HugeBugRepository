Title

d3.svg.axis does not support quantize / quantile / threshold scales.

Description
Hi, I tried to create a Quantize Scales and I have the following error

Object doesn't support property or method 'rangeBand' (I develop on Visual Studio 2012)

But I never call this method.

Here you can see the entire code: jsfiddle.net/h2juD/1/
Discussion
- The issue you are encountering is that d3.svg.axis does not currently support quantize scales. Quantize scales do not support a ticks method (because the domain is discrete), and in this case the axis assumes that the scale exposes a rangeBand method. Ordinal scales do this, but quantize scales do not.

Since you are using an axis, I assume you are using a position encoding for your data, in which case it is much more common to use a linear scale rather than a quantize scale. So, consider using a linear scale as a workaround for this problem. Quantize scales are primarily intended for colors which are otherwise difficult to distinguish, whereas our ability to distinguish position is much more precise.
