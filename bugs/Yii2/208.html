Title

Bug: pgsql wrong identify column type

Description
I have table that has column with `double precision` data type . When i generate AR model by gii, it will create 'string validator' instead of 'number validator'. Ok, i can fix it manually. But, the problem not stop here. When i try to insert or update the table with empty value, yii rise throw exeption like below

`QueryBuilder` produce `"item_discount"=''` instead of `"item_discount"=null`. IMO, it's because wrong result of `ColumnSchema::typecast()`.

I try to find, where the problem is. So, i execute the sql statement [Link: here]  and got the `data_type` of `item_discount` is `float8`.

But, there is no `float8` key for `yii\db\pgsql\Schema::typeMap`. So, i add 
`'float8' => self::TYPE_FLOAT` to my local source and so far, it work correctly

i hope u to verify this error, thank you.
