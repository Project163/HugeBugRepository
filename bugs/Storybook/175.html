Title

[Bug]: Interactions using `expect(...).toSatisfy(...)` fail after upgrade to Storybook 9

Description
### Describe the bug

After upgrading to Storybook 9, a simple play function like this
```
tsx
export const Primary: Story = {
  args: {
    primary: true,
    label: 'Button',
... [Log Snipped] ...
  },
};
```
fails with
```
Error: Invalid Chai property: toSatisfy. Did you mean "satisfy"?
```

Although replacing `toSatisfy` with `satisfy` makes the tests run, doing this introduces a TypeScript error:
```
Property 'satisfy' does not exist on type 'Assertion '. Did you mean 'toSatisfy'?
```

It seems like the type definition for `expect` doesn't match the implementation?
