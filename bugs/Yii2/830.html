Title

[yii\db\ActiveRelationTrait] ActiveRecord Relation Query Missing Some Data

Description
[URL]

Why here use `array_unique($values, SORT_REGULAR)` instead of `array_unique($values)`? it cause some problem in my case. 

Two tables are designed as below:

Table A:

id  | name
---| -------
1   | 001
2   | 0001

Table B：

id  | name
---| ------
1   | 001
2   | 0001

In my case, i use the relation `hasOne` in the Table A ActiveRecord like below:

```php
public function getB() {
    $this->hasOne(TableB::className(), ['name' => 'name'])
}
```

and for a better query performance, i use function `with('b')` to reduce query times. But from the db log, i got the sql:

```sql
select * from B where name = '001'
```

not the expectant one:

```sql
select * from B where name in ('001', '0001')
```


I don`t know if this is a bug or It is intentionally.
