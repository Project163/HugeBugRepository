Title

HttpShardHandler can wait indefinitely when retrying after certain failures

Description
If a The LBHttp2SolrClient is used to do an asynchronous request, then any error that has a null message can result in that request not having its future completed. The HttpShardHandler loops indefinitely until all responses have been processed. So if a future is not completed, then its response will not be added to the list.
