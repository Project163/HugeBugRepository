Title

Running application build with JDK21 and target Java 17 crash with NoClassDefFoundError: java/util/SequencedCollection

Description
### Describe the bug

An application with targeting Java 17, built with JDK 21, running with Java 17 fails on startup with NoClassDefFoundError: java/util/SequencedCollection when a config property is mapped to a list.
```
@ConfigProperty(name = "configlist")
List  aConfig; // has value configlist=A,B in application.properties.
```


### Expected behavior

Since the application is built with target set to Java 17 I expected the application to run on Java 17.

### Actual behavior

fails on startup with NoClassDefFoundError: java/util/SequencedCollection

### How to Reproduce?

Generate a minimal app with Quarkus app-generator.
add 
```java
@ConfigProperty(name = "configlist")
List  aConfig;
```
to GreetingResource and 
```properties
configlist=A,B
```
Run `mvn package` with JDK 21 as JDK. 
Run the application with Java 17.

### Output of `uname -a` or `ver`

na

### Output of `java -version`

21 on build, 17 on run.

### Quarkus version or git rev

3.6.3

### Build tool (ie. output of `mvnw --version` or `gradlew --version`)
