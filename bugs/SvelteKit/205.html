Title

Cookies API doesn't work with redirect helper in hooks

Description
### Describe the bug

I have an auth token stored in cookies, and use hooks to validate the token.
When the token expires, it should clear the cookie and then redirect to the login page.
But it does not, the redirect is successful but the cookies still exist.
```
if (token_is_expired(token) {
  event.cookies.delete('auth');  // doesn't work
  event.cookies.set('auth', '', { maxAge: 0 });  // doesn't work either
  throw redirect(303, '/login');
}
```

### Reproduction

[URL]
1. `npm run dev` and visit `[URL]
2. Click the login button
3. You'll be automatically returned to the login page (to simulate the token expired situation).
4. If the cookie is deleted, you'll see the login button, otherwise you'll only see the text 'already logged in'.
