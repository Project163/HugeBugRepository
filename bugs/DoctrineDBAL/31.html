Title

schema generation maps oracle DATE fields to datetime

Description
I am using the schema generation tool to generate create/update scripts for my database from yaml entities.
Using [URL] as a guide, I have a date column of type 'date', which correctly generates an oracle column with type DATE.
However, when I try to generate update scripts, OraclePlatform::doctrineTypeMappings maps the oracle DATE to a doctrine DateTimeType. The columns are seen as different because DateType != DateTimeType.
If I change the mapping date->datetime to date->date, it correctly sees that the database column matches the entity definition.

I think this is a bug, although minor since the update sql is generated from the entity definition and ends up being a no-op.
