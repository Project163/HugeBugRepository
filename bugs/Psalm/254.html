Title

Type information missing from autoloaded functions?

Description
I'm not sure if I'm doing something wrong, but it seems that psalm has some issues getting type information for functions defined in autoloaded files via configuration or include files from autoloaded composer files.

To illustrate, let's say that we have a project with following files

* `src/functions.php`
* `src/MyClass.php`
* `autoload.php`
* `composer.json`

The `src/functions.php` is defined like:

```
php
 ` tag seems to have no effect.

It seems an odd inconsistency that adding the file directly to the autoloaded files will result in the types being detected correctly, but it no other case they are.
