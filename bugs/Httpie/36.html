Title

http: error: TooManyRedirects: Exceeded 30 redirects.

Description
This happens in HTTPie, but running the exact same thing in curl works perfectly fine. Haven't been able to quite figure out what's going on.

```
~ 
 ❱ http -h --verify no [URL] Host:nodejitsu.com
HTTP/1.1 301 Moved Permanently
connection: keep-alive
date: Thu, 22 Aug 2013 16:54:17 GMT
... [Log Snipped] ...
x-powered-by: flatiron 0.3.8
x-response-time: 0ms
```

```
 ~ 
 ❱ http -h --follow --verify no [URL] Host:nodejitsu.com

http: error: TooManyRedirects: Exceeded 30 redirects.
```

Now, in curl:

```
~ 
 ❱ curl -kIL [URL] -H "Host: nodejitsu.com"
HTTP/1.1 301 Moved Permanently
x-powered-by: flatiron 0.3.8
location: [URL]
... [Log Snipped] ...
date: Thu, 22 Aug 2013 17:05:56 GMT
connection: keep-alive
```
Discussion
- I've taken a look at this issue, and the reason of TooManyRedirects error is in requests. Fix and details here: kennethreitz/requests#1628
