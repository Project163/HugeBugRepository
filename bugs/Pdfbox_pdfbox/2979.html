Discussion
- That's because  Color.RED.getComponents(null)  returns a 4 component array, which includes the alpha, so this appears as  1 0 0 1 /p1 scn  in the PDF (4 components instead of 3). I suspect Safari uses the last 3 components, while the others including PDFBox use the first 3. Use  new float[] {1,0,0 } instead.
