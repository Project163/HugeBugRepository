Title

"AcquireSRWlockExclusive" not found in KERNEL32.dll

Description
I'm getting an error on beta-latest-windows-386 (rclone v1.36-169-g9a11d3ef) about "AcquireSRWlockExclusive" not found in KERNEL32.dll - using my Windows 2003 SP1 32bit.

It didn't work even with a rclone -V command.
