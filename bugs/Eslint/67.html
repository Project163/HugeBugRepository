Title

context.report fails to parse opts into message

Description
When using all of `context.report`'s options, the message will not be parsed with opts:

``` js
context.report(node, node.loc.end, "Problem with {{type}}", {type: node.type});

// Expected: "Problem with ArrayExpression"
// Actual: "Problem with {{type}}"
```
Discussion
- I'm really surprised it output "Problem with {{type}}" because judging from the code, it should've been something like "34". report function only accepts 3 parameters:

```
    this.report = function(node, message, opts) {
        eslint.report(ruleId, node, message, opts);
    };
```

node.loc.end seems like an extra parameter.
- Underneath that, in `/lib/eslint.js` we have `api.report` with the following signature:

``` js
api.report = function(ruleId, node, location, message, opts) {
```
- Nice investigative work, sir.
