Title

Unable to uninstall when using Skip UAC Task

Description
### **Describe the bug**

When the new `enableElevatedUpdateTask` is set to `true` the user is unable to uninstall the application because the uninstaller isn't able to successfully remove the Windows Task that is used to skip the UAC prompt.

### **To Reproduce**
Steps to reproduce the behavior:
1. In the tauri.conf.json file, set the "tauri" -> "windows" -> "wix" -> "enableElevatedUpdateTask" to `true`
2. Run `npm run tauri build` to generate an installer
3. Install the application
4. Try to uninstall the application - It will fail

### **Expected behavior**
The uninstall process is successful and the Windows Task for updating the application has been removed.
