Title

"promtool update" is missing

Description
**What did you do?** We did a dist-upgrade of our Debian machine, which involves migrating to Prometheus 2.0. We are getting obscure error messages that, I think, are about our old rules not being in the new format. According to [Link: the latest migration docs], we can run `promtool update` to convert our rules.

**What did you expect to see?** `promtool update` should do what it says it does in the latest documentation.

**What did you see instead? Under which circumstances?**

```
$ sudo promtool update rules summed_traffic.rules 
promtool: error: expected command but got "update", try --help
```


**Environment**

* System information: Linux 4.19.0-8-amd64 x86_64

* Prometheus version:

```
prometheus, version 2.7.1+ds (branch: debian/sid, revision: 2.7.1+ds-3+b11)
  build user:       pkg-go-maintainers@lists.alioth.debian.org
  build date:       20190608-09:54:04
  go version:       go1.11.6
```
Discussion
- Thanks for the report.

`promtool update` has been removed as part of [URL] Prometheus 2.5.0 seems to be the last release, which still contained the subcommand -- the 2.6.0 release notes [Link: mention the removal].
I agree that the docs are confusing. Apparently it still makes sense to keep a notice regarding rule conversion. I'll open a PR to extend the docs a bit.

In your case, I suggest getting Prometheus 2.5.0 and using promtool from there to convert your rules. I don't think there were any incompatible changes afterwards, so this should work flawlessly. Also, you don't need to install anything.

If Debian did not provide an intermediate version between 1.x and 2.7, then you might want to take this issue up with the maintainers of the Debian package to provide extended update instructions.
- It makes more sense to ask questions like this on the [Link: prometheus-users mailing list] rather than in a GitHub issue. On the mailing list, more people are available to potentially respond to your question, and the whole community can benefit from the answers provided.
- Nope, [Link: oldstable is on 1.5 and stable is on 2.7].

Looks like Debian users will have to convert their rules manually then, that's a bummer. :/  Would have been good to keep that conversion tool around a bit longer...

Oh well. Thanks for the quick response, anyway!
- You can still download the tar ball and just use the contained promtool binary. No need to install anything, so there is no risk of conflicts with the packaged version.
