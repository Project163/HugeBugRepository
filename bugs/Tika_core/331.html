Title

Method getEnableImageProcessing() in TesseractOCRConfig should be renamed

Description
Method getEnableImageProcessing() in TesseractOCRConfig should be renamed to isEnableImageProcessing() to follow Java convention of using 'is' in the case of a bookean
Discussion
- I have a feeling this may be due to the magic reflection-based stuff for whitelisted property setting via HTTP headers in the server. So, would need to check and possibly update that too at the same time
- I actually think it happened because the field used to be an int (0 or 1) and was changed to boolean, but the method name was not renamed.
- There are numerous cases of this throughout the codebase, esp in config objects.  We can do a bulk change for 2.0.0.
