Title

Remove unnecessary Py4J ListConverter patch

Description
In   SPARK-6949   davies documented a couple of bugs with Py4J that prevented Spark from registering a converter for date and datetime objects. Patched in  [URL]

 Specifically  [URL] dealt with ListConverter automatically converting bytearrays into ArrayList instead of leaving it alone. 

 Py4J #160 has since been fixed in Py4J, since the 0.9 release a couple of months after Spark #5570. According to spark-core's pom.xml, we're using 0.10.3. 

 We should remove this patch on ListConverter since the upstream package no longer has this issue.
