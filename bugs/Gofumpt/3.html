Title

Empty Lines After Conditions Isn't Respected if there is a Comment

Description
Hello and happy Thanksgiving. 🦃 

`gofumpt` recently implemented the feature of leaving along the following code:

```
if longCondition1 &&
	longCondition2 &&
	longCondition3 &&
	longCondition4 &&
	longCondition5 {

	return 123
}
```

However, it seems that `gofumpt` will still mess up code with comments.
For example, the following code:

```
if longCondition1 &&
	longCondition2 &&
	longCondition3 &&
	longCondition4 &&
	longCondition5 {
... [Log Snipped] ...
	return 123
}
```

Will be transformed into:

```
if longCondition1 &&
	longCondition2 &&
	longCondition3 &&
	longCondition4 &&
	longCondition5 {
	// We specifically want to return 123 here because of quantum fluctuations
	return 123
}
```

This is undesired for the same reason as [Link: the original issue].
Is this a bug?
