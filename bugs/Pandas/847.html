Title

BUG: Index doesn't take over the Categorical name

Description
`Series` can take over the `Categorical.name`.

```
import pandas as pd
c = pd.Categorical([1, 2, 3], name='xxx')
pd.Series(c)
#0    1
#1    2
#2    3
# Name: xxx, dtype: category
# Categories (3, int64): [1, 2, 3]
```

But `Index` doesn't.

```
pd.Index(c)
# CategoricalIndex([1, 2, 3], categories=[1, 2, 3], ordered=False, dtype='category')
pd.CategoricalIndex(c)
# CategoricalIndex([1, 2, 3], categories=[1, 2, 3], ordered=False, dtype='category')
```
Discussion
- Why does `Categorical` have a `name` attribute at all? This seems strange to me, given that it's not a feature of other dtypes (which are just numpy arrays). @JanSchulz ?
- As far as I can see, that's a quite old property of `Categorical` from the time before a cat could be used as a `Block`.

This commit seems to have introduced the property: [URL] 

From reading this commit and [URL] it seems that the name is needed when a Categorical is (or was?) used in groupbys.
