Title

Render3 should support listener return value

Description
Render3 needs to retain return values of event handlers so that preventDefault is called when appropriate in the DOM renderer.

[URL]

Currently for a click handler like this:

```html
  
```

we generate:

```ts
E(0, 'button');
  L('click', function() { ctx.onClick(); } )  ;
e();
```

However, this loses the return value. The compiler could generate:

```ts
E(0, 'button');
  L('click', function() { return ctx.onClick(); } )  ;
e();
```

This is slightly more complicated for chains like:

```html
  
```

Which becomes:

```ts
E(0, 'button');
  L('click', function() { ctx.onClick(); return ctx.otherFn(); } )  ;
e();
```

Downsides: more code size for each listener defined :-( 

Since this involves compiler changes, @chuckjaz will probably want to weigh in on what makes the most sense to generate.

cc @chuckjaz
