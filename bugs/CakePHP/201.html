Description
Undefined index: beforeSave [CORE/Cake/Model/Behavior/TranslateBehavior.php, line 409] on REST

$this->{$this->modelClass}->save() = Bug
$this->{$this->modelClass}->save(null, array('callbacks' => false, 'validate' => false)) = No bug
Discussion
- What are you expecting to save when you call save with no arguments?
- I've this notice when a use $this->{$this->modelClass}->save()
I force save with the 'validate' => false argument
I'm on PUT request. I read value wifth file_get_content('php://input') ;
- I found solution:

My model is an admin model into admin area: I want to use global field to translate anywhere.
I setup locale false: 

$this->{$this->modelClass}->locale = false;

After:

if (isset($this->{$this->modelClass}->actsAs['Translate'])) {
     $this->{$this->modelClass}->locale = Configure::read('Config.admin_language'); // Or any language...
 }

then:
$this->{$this->modelClass}->save(); // work...
- Setting the locale to false is not a good idea, as there is no reasonable way translatebehavior can operare. I am glad you figured out the source of your issue.
