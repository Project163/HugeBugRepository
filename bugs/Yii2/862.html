Title

Respose::sendFile() does not correctly generate Content-Disposition header for UTF8 filenames with character 127

Description
### What steps will reproduce the problem?
Execute `Respose::sendFile()` with a filename containing US-ASCII character with code 127 (hex 7F).

### What is the expected result?
Generated response does not contain `Content-Disposition` HTTP header with a character 127.
Successful file download (no errors).

### What do you get instead?
Generated response contains `Content-Disposition` HTTP header with a character 127. This leads to Internal Server Error 500 under Apache httpd server.
