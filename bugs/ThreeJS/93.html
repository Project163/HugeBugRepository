Title

BoxHelper class does not initially render properly

Description
When creating a mesh and then a attaching a BoxHelper to it, the BoxHelper seems to reset the transformations to the mesh on the initial render. See this [Link: jsFiddle] (by WestLangley on StackOverflow) and uncomment the line indicated in the js code. Also for reference is the original [Link: stack overflow] question that first raised the issue.

Calling renderer.render twice in a row seems to render the scene correctly.
