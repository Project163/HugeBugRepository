Title

Hybrids defined without decorator return error when queried as a separate attribute

Description
**Describe the bug**

In SA 1.4 hybrid property defined without decorator returns error when queried as a separate attribute.

**Expected behavior**

The given query should work.

**To Reproduce**

```
py
import sqlalchemy as sa
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.ext.hybrid import hybrid_property
from sqlalchemy.orm import sessionmaker
... [Log Snipped] ...
print(session.query(City.some_hybrid).all())  # works!
print(session.query(City.some_hybrid2).all())  # throws error :(
```

**Error**

```
Traceback (most recent call last):
  File "script.py", line 31, in  
    print(session.query(City.some_hybrid2).all())  # throws error :(
  File "python3.8/site-packages/sqlalchemy/orm/query.py", line 2685, in all
    return self._iter().all()
... [Log Snipped] ...
    self.expr = getattr(_entity.entity, orm_key)
AttributeError: type object 'City' has no attribute ' '
```

**Versions.**
 - SQLAlchemy: 1.4

**Additional context**

We've been trying to get SA-Utils to support SA 1.4. This bug is currently causing problem with [Link: SA-Utils translation hybrid]
