Title

[bug] Failed to bundle an NSIS installer under linux in tauri 2.0.0-alpha.8

Description
### Describe the bug

While trying to cross-compile a hello-world tauri-app for Windows from Linux (docker), I got at the very end an error at the bundling phase complaining about some missing folder. 

### Reproduction

0. `apt-get install --no-install-recommends -y nsis libwebkit2gtk-4.1-dev build-essential curl wget libssl-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev`
1. `cargo create-tauri-app`
2. choose Rust, Vanilla
3. change the bundle identifier in `tauri.conf.json > tauri > bundle > identifier` to something else than its current value
4. bump  version in `Cargo.toml > dependencies > tauri` to `2.0.0-alpha.8` to get rid off the `error: failed to select a version for tauri.` problem
5. `cargo tauri build --target x86_64-pc-windows-msvc`

### Expected behavior

the command executes successfully and an NSIS bundler is created
