Title

.NET: Unable to locate external assembly with enabled peerAssemblyLoading

Description
Original reproducer:  [URL] With two server nodes, and a client that spawn a computation with a simple cache iteration for custom class value 

 Problem: 

 If peer assembly loading enabled and no assembly exist for the nodes, then there is an endless loop: nodes are requesting the assembly from each other and no one is able to locate it. 

 As an example of missing dll there could be a "System.Configuration.Configuration" for the .NET Core app  [URL]
Discussion
- Analysis: 
 
	 .NET Core is used 
	 PeerAssemblyLoading for System.Configuration.ConfigurationManager hangs: this assembly is not present on any of the nodes (see  [URL]
 

 Root cause: 
 
	 Assembly.Load during peer loading triggers more peer requests if the assembly is not present, this goes on forever if the assembly is not found on any nodes
