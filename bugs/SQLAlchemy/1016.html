Title

emit wanrings when any combination of returning(), return_defaults() are called, as these all replace each other.

Description
**Describe the bug**

We cannot use several returning() calls with the same statement. The last call erases the previous calls.   

**Expected behavior**

This statement:
```
statement = statement.returning(user.c.firstname)
statement = statement.returning(user.c.lastname)
```

Should be equivalent to:

```
statement = statement.returning(user.c.firstname, user.c.lastname)`
```

**To Reproduce**

```
py
from sqlalchemy import Table, MetaData, Integer, String, Column
from sqlalchemy.dialects import postgresql

metadata = MetaData()
... [Log Snipped] ...

print(statement.compile(dialect=postgresql.dialect()))
```

**Error**

```
UPDATE "user" SET firstname=%(firstname)s, lastname=%(lastname)s RETURNING "user".lastname
```

**Expected Output**

```
UPDATE "user" SET firstname=%(firstname)s, lastname=%(lastname)s RETURNING "user".firstname, "user".lastname
```

**Versions.**
 - OS: Fedora (5.8.11-200.fc32.x86_64)
 - Python: Python 3.8.5
 - SQLAlchemy: 1.3.20
 - Database: postgres:9.6.19
 - DBAPI:  aiopg
