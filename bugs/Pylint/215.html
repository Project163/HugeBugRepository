Title

Unexpected undefined-variable error in lambda functions

Description
### Steps to reproduce

Create a file `test.py` and add the following to it.

```python
class MyObject(object):
	method1 = lambda function: function()
	method2 = lambda func: func()
```

Run pylint against the file.

### Current behavior

The variable name `function` is considered undefined in `method1` but `func` in `method2` is fine! Pylint produces the following output:

```
E:  2,28: Undefined variable 'function' (undefined-variable)
R:  1, 0: Too few public methods (0/1) (too-few-public-methods)
```

### Expected behavior

No undefined variable errors.

### pylint --version output

pylint 1.7.1, 
astroid 1.5.3
Python 2.7.12 (default, Nov 20 2017, 18:23:56) 
[GCC 5.4.0 20160609]
