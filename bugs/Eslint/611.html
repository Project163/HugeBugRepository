Title

Autofix unit test fails on Windows

Description
Using version 1.5.1. (Well, this is really a development issue, no functional impact to consumers.)

Test "CLIEngine executeOnFiles() Fix Mode should return fixed text on multiple files when in fix mode" fails in my environment. In the `output` properties, the linefeeds are `\n`, but that code produces `\r\n` in my environment.
