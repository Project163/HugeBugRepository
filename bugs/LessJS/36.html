Title

Nested media query inside a media query using a variable causes compile exception

Description
Here's the test case (using 1.3.1):

```
.bg() {
    background: red;

    @media (max-width: 500px) {
        background: green;
... [Log Snipped] ...
    }
}
```

This will not compile, instead it throws an error (using non-minified):

```
Object # has no method 'toCSS'
in core.less 
at [URL]
at Array.map (native)
at Object.tree.Value.toCSS (http://localhost:49753/less.js:3535:27)
... [Log Snipped] ...
at [URL]
at Array.map (native)
```

If I remove the `@bpMedium` variable from the top-level media query, it works fine (`@media (max-width: 1000px)`).

Any ideas for a workaround (besides not using a variable) or will this need to be fixed?
