Title

Static Resources in devmode doesn't provide filtered ones

Description
**Describe the bug**
Static resources are directly provided from source project directory in dev mode and the filtering process is ignored. 

**Expected behavior**
The filtered resources with interpolated Maven properties are provided by static handler for `src/main/resources/META-INF/resources` files when running in dev mode.

**Actual behavior**
The original resources without Maven properties resolution are provided by static handler for `src/main/resources/META-INF/resources` files when running in dev mode.

**To Reproduce**
The project bellow was generated at [Link: Quarkus Code Start]. The resources filtering was enabled and the `src/main/resources/META-INF/resources/index.html` was changed to use some Maven properties.

[URL]

Steps to reproduce the behavior:
1. Enable resources filtering
2. Use Maven property interpolation in some static provided resource
3. Run application in dev mode
4. The provided resource is the original non-filtered file without properties interpolation

**Configuration**
No special configuration needed.
