Title

form select shows error when optgroups is numeric

Description
I want to group options in a `find('list')` by year so I did something like

```
find('list', ['groupField' => 'year])
```

And I  get an array like this

```
$options = [
   2014 => [
      'Value 1' => 'Label 1',
      'Value 2' => 'Label 2'
   ],
... [Log Snipped] ...
   ]
];
```

and in my view

```
echo $this->Form->select('test', $options);
```

then I get this notice

Notice (8): Undefined index: text [CORE/src/View/Widget/SelectBoxWidget.php, line 256
Discussion
- While the notice error should not be there, you will likely have to convert your keys into strings. The reason is that with integer keys, the data you have is impossible to disambiguate from the 'complex' option format:

``` php
['value' => 'a', 'text' => 'Albatross'],
['value' => 'b', 'text' => 'Budgie', 'data-foo' => 'bar'],
```

Because integer keys create ambiguity in the input types, we require that the keys for optgroups be strings, or if you cannot convert the keys to strings, you can also define the 'options' key for nested options:

``` php
2014 => [
    'options' => [
        'beaver' => 'Beaver',
        'elk' => 'Elk',
    ]
]
```
