Title

Reconfiguring the web console location fails

Description
As reported by Ciprian Popa in   FELIX-2005    [1]  reconfiguring the web console location fails. 

 This is because the reconfiguration changes the global console location before unregistering the web console. Thus unregistration fails and re-registration fails, too, because the console servlet is still registered. 

  [1]   [URL]
Discussion
- Fixed in Rev. 903286 by first making sure, the location has really changed before re-registering. And then unregistration takes place with the old location and re-registration then uses the new location.
