Title

SQLSTATE[42000]: [Microsoft][ODBC Driver 18 for SQL Server][SQL Server]Incorrect syntax near the keyword 'nchar'

Description
I recently enabled useStrictMode for the session component and when I went to my website I got this error.

```
2025-08-13 07:57:43
[xx.xx.xx.xx][-][4c6lbacej8f13b7mqrvv868fae][error][yii\db\Exception]
PDOException: SQLSTATE[42000]: [Microsoft][ODBC Driver 18 for SQL
Server][SQL Server]Incorrect syntax near the keyword 'nchar'. in
/vendor/yiisoft/yii2/db/Command.php:1320
... [Log Snipped] ...
yii\base\Application->run()
#15 {main}
```

I suspect the issue is related to this
`yii\db\mssql\QueryBuilder->insert()`
```
if (in_array($dbType, ['char', 'varchar', 'nchar', 'nvarchar', 'binary', 'varbinary'])) {
    $dbType .= '(MAX)';
}
```

SQL Server does not support "MAX" for "char" or "nchar"
