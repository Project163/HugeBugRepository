Title

Scope of the variable with angular and zeppelin interpreter

Description
I want to get some values from angular JS to Spark. 

 I tried using z.angular("variable_name"), it returns me null. But "%angular {  
{variable_name} }" prints the value. But I can't use the value returned "%angular { {variable_name}
  }" as it just fetches the value and prints in notebook. When we do subString, it has the values as "{  
{variable_name} }". I think while printing the value gets substituted. Since it can be used just for display I am not able to use it in spark paragraph. 
 
Note:- I've added space after curly brace in { {variable_name}
  }, just to display properly in jira 

 But in these links,  [URL] and  [URL] Value of selectedTable is read using "z.angular("selectedTable")" in paragraph 3 and 4. 

 So I tried the same sample in my zeppelin instance. In my local zeppelin the "selectedTable" is not passed to other paragraph. It is reflected only in angularJS paragraph. 

 There is question in StackOverflow as well regarding the same.   [URL]

 This seems to be a regression as it was working fine in demo video.
Discussion
- Have you tried z.angularBind() before z.angular(), especially after zeppelin restart? 
Zeppelin restored previously binded angular value to front-end side after restart but does not  restore it backend side. 

 So you may able to read binded value after restart in the frontend, but not in backend before do z.angularBind() again
- By using z.angularBind() before z.angular(), it worked. 

 But the textbox is having a issue. When we type something in normal speed, that characters are getting replaced. We have to type very slowly to enter the correct text into text box. Is this a known issue?
