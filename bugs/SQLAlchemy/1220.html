Title

[1.4] hybrid_property not working well with query.update()

Description
### Describe the bug

Hello,

I've noticed a regression between version 1.4.25 and 1.3 of SQLAlchemy. Some updates on hybrid properties do not raise any error in 1.4, but still do not update data in the database. If targeting the real column directly, the update is done correctly.

### To Reproduce

```
python
from sqlalchemy import Column, DateTime, ForeignKey, Integer, String, Table, create_engine, func
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.ext.hybrid import hybrid_property
from sqlalchemy.orm import backref, contains_eager, joinedload, relationship, sessionmaker
... [Log Snipped] ...
session.flush()
assert session.query(City._name).one()[0] == "marseille"
```

The test case breaks for 1.4 but not 1.3.


### Versions

- OS: Ubuntu
- Python: 3.8
- SQLAlchemy: 1.4.25
- Database: Tested on postgresql and sqlite
- DBAPI (eg: psycopg, cx_oracle, mysqlclient): psycopg2
