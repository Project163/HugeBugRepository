Title

MinimizeExitPoints does not properly hoist function definitions.

Description
What steps will reproduce the problem? 
1. Start with this code snippet:
function a(b) {
  if (b) {
    c()
    return undefined
  }
  function c(){}
}
a(1)

2. Observe that it runs without error in Firefox 3.5.5
3. Compile the snippet with either simple or advanced optimizations
4. Observe that you get the following output:
function a(b){if(b)c();else{function c(){}}}a(1);

5. Run the output code in Firefox 3.5.5

 What is the expected output? What do you see instead? 

Expected output: code without errors will compile into code that does not 
raise errors

Instead I get the error: "c is not defined"

code without error.
