Title

IndicesExistsRequest throws IndexMissingException

Description
The IndexExistsRequest is throwing an IndexMissingException instead of setting exists to false in an IndicesExistsResponse object.
Discussion
- I'm also seeing that sometimes a RemoteTransportException is being thrown instead of the IndexMissingException. I had to update our code to check for IndexMissingException and the cause of RemoteTransportException. It appears that your fix should take care of any type of excepting being thrown, but I've also seen this behavior when sending a create index request when that index already exists. It will throw a RemoteTransportException or IndicesAlreadyExistsException.
- When it comes over the wire, it will have a remote exception type to indicate when ti came from... . You can catch an ElasticSearchException and call #unwrapCause()
