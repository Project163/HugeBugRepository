Title

backdrop label doesn't work for angled labels when showLabelBackdrop is true

Description
### Expected behavior

When showLabelBackdrop is set to true, I expect the scale labels along the x/y axis to have a backdrop, even if the labels are angled

### Current behavior

Because the backdrop is added before the canvas is rotated, the backdrops are mis-aligned with the angled labels.
