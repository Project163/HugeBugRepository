Title

Null pointer exception when nested top_hits inside terms

Description
I'm using the official Docker image: docker.elastic.co/elasticsearch/elasticsearch:6.5.4

**Elasticsearch version** (`bin/elasticsearch --version`): 6.5.4

**Plugins installed**: []

**JVM version** (`java -version`): 11.0.1

**OS version** (`uname -a` if on a Unix-like system): Linux 267b34f6bf59 4.9.93-linuxkit-aufs #1 SMP Wed Jun 6 16:55:56 UTC 2018 x86_64 x86_64 x86_64 GNU/Linux

**Description of the problem including expected versus actual behavior**:

When having a nested `top_hits` aggregation inside a nested `terms` aggregation inside a `children` aggregation, I'm getting a `null_pointer_exception`. I expect to get a valid response.

**Steps to reproduce**:

 1. create mapping

```
PUT [URL]

{
    "mappings": {
        "doc": {
... [Log Snipped] ...
    }
}
```
 2. insert example post

```
PUT [URL]
{
    "joinField": {
        "name": "post"
    },
    "docType": "post",
    "title": "Example Post"
}
```

 3. insert comment
```
PUT [URL]

{
	"joinField": {
		"name": "comment",
... [Log Snipped] ...
	"docType": "comment"
}
```

4. Perform search

```
POST [URL]

{
	"aggs": {
		"to-comment": {
... [Log Snipped] ...
	}
}
```

Response:
```
{
    "took": 10,
    "timed_out": false,
    "_shards": {
        "total": 5,
... [Log Snipped] ...
    }
}
```

It works if I remove the query, but in the actual hits I want to get all the posts only. It also works if I remove the terms aggregations, but I want to filter the posts by other queries (e.g. match on title).
