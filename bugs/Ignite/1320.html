Title

Assertion error is thrown in OFFHEAP_TIERED mode and near cache enabled.

Description
The attached test fails.
Discussion
- The reason behind the failure (see GridNearGetFuture#map()) 

 
	 When data node is stopped, near entry becomes invalid because primary owner is changed 
	 When  get()  is called on near node, local variable  entry  is first initialized with near entry, but  innerGet()  returns  null  because near entry is invalid 
	 Since offheap is enabled and node is client,  dht.entryEx  throws invalid partition exception 
	 Local variable  entry  remains initialized with near entry, however  finally  block assumes that  entry  is a DHT entry if not null
- There are two points that should be addressed: 
 
	 Code that works with DHT entry should work with another local variable just to make it safer 
	 The DHT lookup should not be performed on a client node
