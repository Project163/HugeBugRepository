Title

Bug with annotation with closure on method of anonymous class

Description
Annotations on method with Closure value can't be used with anonymous classes 

 Test with NotYetImplemented included: 

  [URL]
Discussion
- A second possibly unrelated (but maybe same root cause) example: 
  
  import  java.lang.annotation.*

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
@ interface  Bar{  Class  value() }

@Bar( String )            // OK
  String  toString() {}

 return   new   Object () {
  @Bar( String )          // Error!
    String  toString() {}
}
 // Error:
  // Only classes and closures can be used  for  attribute  'value'  in @Bar
