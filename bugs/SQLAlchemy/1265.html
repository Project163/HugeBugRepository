Title

add create_constraint kwarg to enum repr

Description
**Describe the bug**
 

As I use the SQLite database and it does not have the `Enum` type, I wanted to use the `create_constraint` property for my `Enum`.
I add it like: `status = Column(SQLAlchemyEnum(ExampleEnum, create_constraint=True), nullable=False)` and after running the automatic revision generation, it gets ignored in the process and it results in a column of `Enum` type but without the property mentioned: `sa.Column('status', sa.Enum('first', 'second', name='exampleenum'), nullable=False),`

When I add the `create_constraint=True` by myself to to revision, the database table generates as expected.

**Expected behavior**
 

The `create_constraint` property present in the `Enum` in the generated revision.
