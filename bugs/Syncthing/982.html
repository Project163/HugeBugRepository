Title

Description

It does work when i do starting V 1.23.7 on the server. (before it was finished syncing i switched back to 1.24.0 and it stopped working again)

It also does work when undedup the volume and using V1.24.0

```
$VHD   = New-VHD -Path D:\DedupTest.vhdx -SizeBytes 1GB
$mount = $VHD | Mount-VHD -Passthru
$mount | Initialize-Disk -PartitionStyle GPT
$part  = New-Partition -DiskNumber $mount.DiskNumber -UseMaximumSize -AssignDriveLetter
$Vol   = $part | Format-Volume -FileSystem NTFS -NewFileSystemLabel "TestDedup"
