Title

Incorrect type hint for argument "of" of with_for_update()

Description
### Describe the typing issue

The type hint for `with_for_update(of=elem)` appears to be incorrect. It should accept ORM tables instances

### To Reproduce

```
python
from sqlalchemy import Integer, Select, select
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column


... [Log Snipped] ...
        of=Table,
    )
```

### Error

```
error: Argument "of" to "with_for_update" of "GenerativeSelect" has incompatible type "Type[Table]"; expected "Union[_HasClauseElement, SQLCoreOperations[Any], ExpressionElementRole[Any], Callable[[], ColumnElement[Any]], LambdaElement, Sequence[Union[ColumnElement[Any], _HasClauseElement, SQLCoreOperations[Any], ExpressionElementRole[Any], Callable[[], ColumnElement[Any]], LambdaElement]], None]"  [arg-type]
``` 

### Versions

- OS: Ubuntu 22.04
- Python: 3.11
- SQLAlchemy: 2.0.0
- Type checker: mypy 0.991
