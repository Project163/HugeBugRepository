Title

prunmgr does not handle invalid command lines well

Description
prunmgr does not handle invalid command lines well. 

  prunmgr //1234  

 causes a crash: 

 EventType : BEX     P1 : prunmgr.exe     P2 :       P3 : 4cbfeb21      
P4 : prunmgr.exe     P5 :       P6 : 4cbfeb21     P7 : 000013d8      
P8 : c0000409     P9 : 00000000   

  prunmgr //123  

 results in the error message: 

 
 An attempt has been made to operate on an impersonation token by a thread that is not currently impersonating a client. (0) 
Error parsing command line
Discussion
- A similar problem happens with prunsrv: 

  prunsrv //1234  

 EventType : BEX     P1 : prunsrv.exe     P2 :       P3 : 4cbfeb12      
P4 : prunsrv.exe     P5 :       P6 : 4cbfeb12     P7 : 000013d8      
P8 : c0000409     P9 : 00000000      

 However 

  prunsrv //123  

 results in: 

  [2010-10-30 15:48:49]   [error]  Unrecognized cmd option //123 
 [2010-10-30 15:48:49]   [error]  Invalid command line arguments 
 [2010-10-30 15:48:49]   [error]  Commons Daemon procrun failed with exit value: 1 (Failed to parse command line arguments) 

 which is better than the prunmgr message.
- Fixed in the SVN. Will be part of 1.0.6 release
