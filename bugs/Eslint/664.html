Title

Properties are not always ignored in the `id-length` rule

Description
1. **The version of ESLint you are using**
   
   1.8.0
2. **What you did (the source code and ESLint configuration)**
   
   ``` js
   myObj.env = true;
   ```
   
   with the following configuration:
   
   ``` js
     "id-length": [2, {
         "min": 4,
         "properties": "never",
     }],
   ```
3. **The actual ESLint output complete with numbers**
   
   `error  Identifier name 'env' is too short. (< 4)  id-length`
4. **What you expected to happen instead**
   
   No error. Since `"properties"` is set to `"never"`, this error should not occur.
Discussion
- Reproducible in online demo. Looks like a bug.
