- Each of the associations should be added to $_accessible. I can take care of updating bake.
- Looks like this issue is caused because the table class does not exist when bake starts. If the table class is created before bake runs the entity class is generated correctly.

I'm not sure how fixable this is as `class_exists()` seems to cache its results and even after the table class has been written to disk, `class_exists()` continues to return false as the class loader generated by composer caches that the file did not exist the first time around. I'll look into syncing the in memory object as a solution.
