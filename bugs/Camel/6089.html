Title

camel-csv - Empty header uri parameter interpreted as fixed column ""

Description
Since the last "big" change to camel-csv in Camel 3.12.0 an empty header in uri like 
  
 
<to uri= "dataformat:name:marshal?header=&delimiter=;" />
 
  
 is interpreted as fixed column empty String. 

 Maybe do empty String check while creating marshaler in ( Link )
Discussion
- What is the use case for setting header = blank
- We use the marshaler in a dynamic endpoint (tod) where the fixed headers are calculated at runtime. In some cases, they are null to use dynamic columns.
- Ah okay, you are welcome to send a PR where we check for isNotEmpty instead of null check
- PR is ready. I first thought about reuse method from ObjectHelper, but this class exists twice in package org.apache.camel.support and org.apache.camel.util. One was already in use! So did it manually.
