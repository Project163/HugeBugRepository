Title

FetchFailedException should be thrown when local fetch has failed

Description
In BasicBlockFetchIterator, when remote fetch has failed, then FetchResult which size is -1 is set to results. 

  
         case  None => {
          logError( "Could not get block(s) from "  + cmId)
           for  ((blockId, size) <- req.blocks) {
            results.put( new  FetchResult(blockId, -1,  null ))
          }
 
  

 The size -1 means fetch fail and BlockStoreShuffleFetcher#unpackBlock throws FetchFailedException so that we can retry. 

 But, when local fetch has failed, the failed FetchResult is not set. 
So, we cannot retry for the FetchResult.
