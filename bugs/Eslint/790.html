Title

2.0 eslint rule newline-per-chained-call bug with array access

Description
``` javascript
var currentUrl = window
    .location
    .href
    .match(/(^[^#]*)/)[0];
```

Output:

```
1:18  error  Expected line break after `window\n    .location\n    .href\n    .match(/(^[^#]*)/)`
```

But:

``` javascript
var currentUrl = window
    .location
    .href
    .match(/(^[^#]*)/);
```

Work fine.
