Title

Web-Console viewing a message increments the messages received counter

Description
Here is how to reproduce the bug: 
1) Browse to a queue 
2) Click on any message to view the message 
3) Then go back to the Queues statistics page 
You'll see that the number of received messages increased by 1 although there aren't any actual received messages
Discussion
- It seems like you don't have to do step 2. Steps 1 and 3, will reproduce the bug.
- Attached is a patch that fixes this JIRA
