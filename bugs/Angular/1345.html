Title

HashLocationStrategy does not change hash when redirecting in canActivate Guard

Description
# 🐞 bug report

### Affected Package
  The issue is caused by package @angular/router


### Is this a regression?

 
  No, at least I can confirm that this issue was also present in version 8 of Angular


### Description
Please have a look at the reproduction example at Stackblitz. The issue can be reproduced as follows:
1. Open the application
1. Change the URL in the URL Bar to `.../#/bar` and hit  Enter  OR change the location by entering `location.href = '#/bar` in the console.
1. The state of the application does not change (this is expected as we are on `/start`)
1. The URL still displays `.../#/bar` even though we have been redirected to `/start`.
