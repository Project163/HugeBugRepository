Title

generated engine namespaced action route can't be found by app

Description
Using Rails 4.1.0beta1

steps to reproduce:
- create new mountable engine

```
rails plugin new School --mountable
```
- generate a controller for the engine (from the engine root)

```
rails g controller dashboard history main_dashboard
```

here are the generated routes (routes.rb) at the engine:

```
ruby
School::Engine.routes.draw do
  namespace :school do
  get "dashboard/history"
  end
... [Log Snipped] ...

end
```
- execute rails server from the dummy app root

```
rails s
```
- visit **[URL] the route can't be found
  [Image: error]
- the generated link would be like **school/school/dashboard#history**.
- i think the first 'school' is coming from the engine, while the later is coming from the namespace
- if i delete the namespace at the block, **[URL] will be just like usual (responding with correct controller and action)
- it is funny, because if i generate a scaffolding for the engine, there is no namespace generated for the resource...
- i tested this at a dummy app and a real app
- it is okay to delete the namespace block, but if i need to generate more than 20 actions, i will cry

Is this a bug, or am I doing something wrong?
