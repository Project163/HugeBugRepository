Title

Files Get and Glob add new lines. Impossible to use as documented for secrets.

Description
This will not work:

```
apiVersion: v1
kind: Secret
metadata:
  name: very-secret
type: Opaque
data:
{{ (.Files.Glob "bar/*").AsSecrets | indent 2 }}
```

A new line is added to the contents of the file by `Glob` (and `Get` for that matter). Lost 4 hours of my life debugging this.
Discussion
- I was able to confirm this with a basic chart.

```
apiVersion: v1
kind: Secret
metadata:
  name: very-secret
... [Log Snipped] ...
data:
  foo.txt: aGkK
```

However, I found out that this can be mitigated by using a trailing dash to trim all trailing whitespace.

```
{{ (.Files.Glob "foo.txt").AsSecrets | indent 2 -}}
```

Does that solve your issue?
- After experimenting I think this has something to do with `.AsSecrets` as opposed to `.Files.Glob` or `.Files.Get` though. Those seem to work as intended.
