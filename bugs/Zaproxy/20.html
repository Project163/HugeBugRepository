Title

Plugin enabled even if dependencies are not, "hangs" active scan

Description
Issue reported in OWASP ZAP User Group: [URL]

Steps to reproduce the issue:
1. Run ZAP with "Active scanner rules" version 18;
2. In the "Scan Policy" dialogue for "Default Policy" select "Injection" panel and disable "Cross Site Scripting (Persistent) - Prime" ("Threshold" to "OFF"), note that the other XSS persistent scanners were also disabled. Save the changes;
3. Open the dialogue again, select "Injection" panel and enable "Cross Site Scripting (Persistent)", note that its dependencies (XSS Prime and Spider) were not enabled.

Remarks:
If the active scan is run it will never finish because the XSS scanner has unfulfilled dependencies (regression #377).

ZAP Versions:
Versions >= 2.4.0
