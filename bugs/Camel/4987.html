Title

JMS Producer not useable under camel-blueprint

Description
The karaf feature actually does not install camel-caffeine-lrucache. With DefaultLRUCache the JMS producer will get stopped causing a java.util.concurrent.RejectedExecutionException at runtime. 

 This can be reproduced (even non OSGi environment!) if camel-caffeine-lrucache is explicitly excluded in e.g. camel-test.
