Title

rclone hangs on CLOSE when transferring large FTP files

Description
#### What is the problem you are having with rclone?

rclone is hanging when transferring large files from FTP to google storage, file size was about 36 GB. The files are successfully transferred to google storage, but rclone never exits.

I captured this stackdump  (below) during the hang. I believe it shows the process is hanging waiting for a response after sending the remote FTP server the CLOSE command. Sending CLOSE is nice but not necessary to complete the transfer, so maybe we could add a timeout to that after which rclone gives up on hearing back a response to the CLOSE command.
