Title

Bundled Jython jar in Pig 0.10.0-RC breaks module import in Python scripts with embedded Pig Latin

Description
Using Pig 0.9.0 I was running into   PIG-1824   when using import statements (e.g.  import os ) in a Python script with embedded Pig Latin.  Dmitriy Ryaboy pointed me to the new Pig 0.10 release candidate ( [URL] so that I could test whether my issue was solved by the new Pig version.  During testing I run into the error described below. 

  Summary (TL;DR)  

 
	 Even a minimal Python script with embedded Pig Latin will throw an error if there is a single import statement in the Python code. 
	 The fix is to replace the bundled  lib/jython.jar  with a standalone version of the same jar.
