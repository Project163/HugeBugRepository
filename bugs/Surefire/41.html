Title

With testng, incorrect test numbers are reported if setup method throws exception.

Description
If an exception is thrown in a testng setup method, the testing related numbers displayed by the plugin are incorrect. 

 For example... 

 Run a build with a single testng test class with three tests. If everything passes, the output looks like this: 

     ------------------------------------------------------- 
     T E S T S 
    ------------------------------------------------------- 
    Running mypackage.TestClassOne 
    Tests run: 3, Failures: 0, Errors: 0, Skipped: 0, Time elapsed: 0.046 sec 

     Results : 
    Tests run: 3, Failures: 0, Errors: 0, Skipped: 0 

 If the same test class throws an exception in the setup method  [annotated with @Configuration(beforeTestMethod=true)] , the output looks like this 

     ------------------------------------------------------- 
     T E S T S 
    ------------------------------------------------------- 
    Running mypackage.TestClassOne 
    Tests run: 6, Failures: 1, Errors: 0, Skipped: 5, Time elapsed: 0.156 sec <<< FAILURE! 

     Results : 
    Tests run: 6, Failures: 1, Errors: 0, Skipped: 5
