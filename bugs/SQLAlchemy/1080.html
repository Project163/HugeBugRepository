Title

case() with single-item dict breaks

Description
**Describe the bug**
`case()` with a single-item dict fails; this used to work in 1.3

**To Reproduce**
```
py
from sqlalchemy import *
from sqlalchemy.orm import *


... [Log Snipped] ...
print()
print(case({'a': 'aa'}, else_='c', value=Test.foo))
```

**Error**

```
$ python /tmp/satest.py
CASE test.foo WHEN :param_1 THEN :param_2 ELSE :param_3 END

Traceback (most recent call last):
  File "/tmp/satest.py", line 16, in  
... [Log Snipped] ...
    for (c, r) in whens
ValueError: not enough values to unpack (expected 2, got 1)
```

**Versions.**
 - OS: Linux
 - Python: 3.9.1
 - SQLAlchemy: 1.4.1
 - Database: n/a
 - DBAPI: n/a
Discussion
- workaround, pass whens w/ the param name:


    case(whens={'a': 'aa', 'b': 'bb'}, else_='c', value=Test.foo)
- **Mike Bayer** has proposed a fix for this issue in the **master** branch:

**Correct for coercion from list args to positional for case** [URL]
