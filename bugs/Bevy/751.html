Title

track_location shows spawn location as despawn location

Description
## Bevy version and features

0.17.0-rc.2

## What you did

Enabled `track_location` feature to debug double-despawn.

## What went wrong

The location pointed to as `despawned by` is actually where entity is spawned.

Minimal reproduction code:

```
    let entity = commands.spawn(()).id(); // line 35
    commands.entity(entity).despawn();  // line 36
    commands.entity(entity).despawn();
```

0.16
```
WARN bevy_ecs::error::handler: Encountered an error in command ` >>::with_entity::{{closure}}`: The entity with ID 6v1 was despawned by src\main.rs:36:29
```

0.17
```
WARN bevy_ecs::error::handler: Encountered an error in command ` >>::with_entity::{{closure}}`: The entity with ID 12v0 was despawned by src\main.rs:35:27

    If you were attempting to apply a command to this entity,
    and want to handle this error gracefully, consider using `EntityCommands::queue_handled` or `queue_silenced`.
```
