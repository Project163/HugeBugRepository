Title

ClientDriver ResultSetMetaData.isAutoIncrement(column) always returns false

Description
With ClientDriver, resultSet.getMetaData().isAutoIncrement(column) always returns false.  

 EmbeddedDriver correctly returns the true value (true or false)

- I have created a quick patch for this. 

 It is evident from DRDA spec that, sqlxGenerated can tell if 'generated' attribute of a particular column is true. If the column is auto generated then sqlxgenerated will be 2. The same check can be used to validate AutoIncrement attribute in isAutoIncrement. I would like to know from the NetworkClient experts if this is the right fix. 

 I have started the testruns and will also look into if there is an existing test which needs modification, else I will add a new case.
