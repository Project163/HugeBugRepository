Title

NPE during build when multiple decorators have the same priority

Description
## Describe the bug
NPE during build when multiple decorators have the same priority (or no priority defined)

### Expected behavior
App builds and both decorators are instantiated properly (according to CDI spec execution order is undefined for decorators with the same priority though)
