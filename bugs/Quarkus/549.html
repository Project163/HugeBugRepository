Title

Unable to listen startup event and to schedule when insecure-requests is disabled (SSL/TLS)

Description
**Describe the bug**
When using SSL/TLS with property quarkus.http.insecure-requests = disabled :

- onStart(@Observes StartupEvent evt) is not called
- Method annotated with @Scheduled are not invoked

**To Reproduce**
Steps to reproduce the behavior:
1. Create a project
```
mvn io.quarkus:quarkus-maven-plugin:1.3.1.Final:create -DprojectGroupId=org.acme -DprojectArtifactId=foo-server -DclassName="org.acme.FooResource" -Dpath="/foo" -Dextensions="scheduler"
```
2. In src/main/java/org/acme add FooService.java
```
java
package org.acme;

import io.quarkus.runtime.ShutdownEvent;
import io.quarkus.runtime.StartupEvent;
... [Log Snipped] ...

}
```
3. In src/main/resources , Create a foo.jks file with self-signed certificate
```
keytool -genkey -keyalg RSA -alias selfsigned -keystore foo.jks -storepass fooPass -validity 365 -keysize 2048
```
4. In src/main/resources/application.properties
```properties
quarkus.http.insecure-requests = disabled
quarkus.http.ssl.certificate.key-store-file = foo.jks
quarkus.http.ssl.certificate.key-store-file-type = JKS
quarkus.http.ssl.certificate.key-store-password = fooPass
```

**It is working if (but http stays active)**
In src/main/resources/application.properties
```properties
#quarkus.http.insecure-requests = disabled
quarkus.http.ssl.certificate.key-store-file = foo.jks
quarkus.http.ssl.certificate.key-store-file-type = JKS
quarkus.http.ssl.certificate.key-store-password = fooPass
```

**Environment**
 - Java versions: 11 & 14
 - Quarkus versions: 1.3.0.Final & 1.3.1.Final
