## Current behavior
 
Request throws an error when trying to parse a response of `"ok"` which is considered valid json according to [URL] 

---

request: 
```

    this.httpClient.request('GET', './mockjson.json', requestOptions)
    ...
```

---

error: `"Unexpected token o in JSON at position 0"`


## Expected behavior
 
No error should be thrown for a response of `"ok"`
