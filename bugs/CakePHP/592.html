Title

[2.5] HttpSocket request protocol version

Description
Hey!

As explain in the [Link: documentation], we can use the `HttpSocket` with the following configuration in order to use it with the `1.0` http protocol:

``` php
$response = $httpSocket->request(array(
    'version' => '1.0',
    'uri'     => $uri,
    'method'  => 'GET',
));
```

The issue is the `version` options is nerver used in the code. Futhermore, the protocol version is determined via `_buildRequestLine` version token which is by default `HTTP/1.1`, so, not sure how to fix it properly.

What about removing the version token parameter and only rely on the `version` option in order to build the verion token?
Discussion
- Looks like the documentation is wrong and the client is always `HTTP/1.1`. Is there a reason you need a HTTP/1.0 client?
- Basically, I maintain a [Link: library] which allows to use the http adapter you want and it allows to configure the protocol version according to the PSR-7 spec. 

I just try to integrate the cake http client in egeloen/ivory-http-adapter#46 but my test suite was broken with the 1.0 protocol version so, I report the issue :) If it is not supported it is not the end of the world but I report it as it is documented as configurable.
- Neat! I don't see why HttpSocket shouldn't honor the version if set, I can get that fixed.
- Fixed with #5253
