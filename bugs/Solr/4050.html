Title

Solr Guide references CloudSolrClient.uploadConfig() method which no longer exists

Description
The uploadConfig() method seems to have been removed from the CloudSolrClient class in the 7.0 release, but the Solr Ref Guide still references it. 

 See section on "Uploading Configuration Files using bin/solr or SolrJ"  at  [URL]   

 Poking around in the source code it seems that perhaps this should be changed to reference ZkConfigManager.uploadConfigDir() instead, but not really sure if this is best.
Discussion
- The attached patch replaces the reference to  CloudSolrClient.uploadConfig  with a small SolrJ snippet showing how to use ZkStateManager to upload configsets.  The snippet is pulled in from a JUnit test using asciidoc's "include" syntax, so it should stay up to date if anything happens to those interfaces in the future.
