Title

Invalid Log Level Error When Writing to Additional Log Configuration

Description
While in development (debugging on) I'm attempting to write messages to sync.log, but receive this: Error: Invalid log level "info"

config/app.php

```
'Log' => [
        'debug' => [
            'className' => 'Cake\Log\Engine\FileLog',
            'file' => 'debug',
            'levels' => ['notice', 'info', 'debug'],
... [Log Snipped] ...
        ],
    ],
```

ServersController.php

```
public function logTest(){
        $this->autoRender = false;
        Log::write('info', 'Results of synchronization script...');
    }
```
