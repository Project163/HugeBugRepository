Title

Table Helper incorrectly calculates row widths involving styled text

Description
This is a (multiple allowed):
* [x] bug

* CakePHP Version: 3.7.5.
* Platform and Target: Linux CLI.

### What you did
Attempting to use the Table Helper to output info containing styled text.
```
$io->helper('Table')->output([
  ['Test', 'Status'],
  ['PHP Version > 7.1.0', ' passed ']
]);
```
### What happened
The table is rendered with the header row width calculated including the style tags. However, the data row is rendered with the actual width of the output string. Something like this:
 
+----------------------------------------------------+
| Test                     | Status                  |
+--------------------------+-------------------------+
|PHP Version > 7.1.0       | Passed |
+--------------------------+-------------------------+
 

### What you expected to happen
 
+----------------------------------------------------+
| Test                     | Status                  |
+--------------------------+-------------------------+
|PHP Version > 7.1.0       | Passed                  |
+--------------------------+-------------------------+
