Title

Allow custom end-of-line with JsonLayout

Description

 Example:- {"key":"value", "key":"value"}\r 

   

 Problem - Currently we are using Splunk for log analysis, which is not able to render Log string as JSON, due to \r getting printed. Can we avoid it getting printed?
