Title

UI: Cloud Graph misaligned

Description
The cloud graph is badly mis-aligned. If you have many nodes/replicas, it is cut off on the right margin and also overlaps the legend box.
Discussion
- Looking at the SVG, there is an invisible "lvl-0" graph node circle on the far left side, with invisible lines to the collections. Also, there is a fixed 100px padding to the left of the entire graph, pushing the rest of the graph to the right. 

 Is this some limitation of the graph component we use, that there needs to be a level-0 node? If so, could we compress it to take less horizontal space?
- The PR fixes these issues 
 
	 Take hostname width into account when positioning graph in SVG canvas 
	 Reduce left-pad 100px to 10px 
	 Auto refresh graph when resizing window
