- Actually, I figure out this problem just few hours ago.

I think the point is, the bounds of LottieDrawable have no effect when drawing itself.

Actually, LottieDrawable.setBounds() work, so the blank move. However, the bounds have no effect when drawing itself, so the content is still at the original place.

Here is my code.

`class MyLottieDrawable : LottieDrawable() {

    override fun draw(canvas: Canvas) {
        canvas.save()
        canvas.translate(bounds.left.toFloat(), bounds.top.toFloat())
        super.draw(canvas)
        canvas.restore()
    }
}`

`
class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        val lottieDrawable = MyLottieDrawable()  //this is the point
        LottieCompositionFactory.fromRawRes(this, R.raw.swimming).addListener{ //R.raw.swimming is a lottie json file
            lottieDrawable.composition = it
        }
        lottieDrawable.scale = 0.2f

        val seekBar = findViewById (R.id.seek_bar)

        val button = findViewById (R.id.button)
        button.setOnClickListener{
            seekBar.thumb = lottieDrawable
            //lottieDrawable.callback = seekBar   //this is useless
        }
    }
}`
