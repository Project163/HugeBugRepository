Title

target_metadata typing don't support metadata sequences

Description
**Describe the bug**
 

From the [docs](https://alembic.sqlalchemy.org/en/latest/autogenerate.html#autogenerating-multiple-metadata-collections
):


But `target_metadata` typing is only `MetaData`.

[URL]
[URL]

**Expected behavior**

The `target_metadata` type must include `Sequence[MetaData]`.

**To Reproduce**

Run mypy on this file.

```python
from sqlalchemy import MetaData
from alembic.migration import EnvironmentContext, Config, ScriptDirectory

context = EnvironmentContext(Config(), ScriptDirectory("."))
context.configure(target_metadata=[MetaData(), MetaData()])
```

**Error**

```
5: error: Argument "target_metadata" to "configure" of "EnvironmentContext" has incompatible type "list[MetaData]"; expected "MetaData | None"  [arg-type]
```

**Versions.**
 - OS: Ubuntu
 - Python: 3.11.4
 - Alembic: 1.12.1
 - SQLAlchemy: 2.0
