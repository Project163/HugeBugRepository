Title

NIST suite run as a Junit test fails on J2ME with WCTME 5.7

Description
Seems the authentication being setup somehow fails.
Discussion
- Seems like the current default user name is not used when opening a connection in the JUnit setup.
- The user name and password are never set on the DataSource that TEstConfiguration uses. 
Looking at this exposes the bigger issue that the data sour setup for JUnit is using code from the 
old harness including checks about frameworks. Much cleaner to separate the code 
into the junit package rather than try to support two modes.
- Committed revision 472187 - data source fixes now ensure user name and password are set for a JSR169 run. 
Tested with IBM's  WCTME 5.7
