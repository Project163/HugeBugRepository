Title

Problem with yii\db\Expression and mysql date functions

Description
I have datetime column `date` and get no results when I use mysql date functions (tried NOW and CURDATE) in `yii\db\Expression` with query builder

``` php
(new Query)->select('*')->from('log')->where(['>=', 'date', new Expression('DATE_SUB(NOW(), INTERVAL 1 MONTH)')])->all()
```

but it works fine when I copy resulting select statement from Yii debugger log and make direct query

``` php
Yii::$app->db->createCommand("SELECT * FROM `log` WHERE `date` >= DATE_SUB(NOW(), INTERVAL 1 MONTH)")->queryAll()
```
Discussion
- What is the SQL executed when you use the first approach?
- Exactly the same as second approach:

``` sql
SELECT * FROM `log` WHERE `date` >= DATE_SUB(NOW(), INTERVAL 1 MONTH)
```
- ... [Middle Discussions Snipped for Brevity] ...
- Did some digging and the problem lies in `yii\db\QueryBuilder::buildSimpleCondition()`, where `Expression` values are passed on as prepare statement parameters and not injected directly into sql.
- Fixed, thanks for finding the cause!
