Title

Error in Serializing the fault mediator fault code with a QName having default prefix

Description
When I set the FaultCode vaule as given below, 

 faultMediator.setFaultCodeValue(new QName("[URL]

</syn:makefault>

 faultMediator.setFaultCodeValue(new QName("[URL]
