Title

Update TApplicationException codes

Description
THRIFT-378   added a new TApplicationException type, but only defined the type code in Java.    THRIFT-689   is about to do the same.  We should resynchronize these.
Discussion
- This patch (  THRIFT-690  .python_app_exception_codes_update.patch) adds python library support for two new TApplicationException codes (INTERNAL_ERROR and PROTOCOL_ERROR).  It also corrects the write() method to use "is not" instead of "!=" to compare against None (python's NULL).
- I've added the constants to the PHP library, although they're never used. 

 If anyone has any pointers on where PROTOCOL_ERROR and INTERNAL_ERROR might be applicable to the PHP library I'm all ears.
