Title

ansible_local provisioner in Vagrant 2.2.5 fails to install Ansible on an Arch, SuSE and FreeBSD guests

Description
### Vagrant version

Vagrant 2.2.5

### Host operating system

* Arch Linux x86_64
* Windows 10 1903 64-bit

### Guest operating system
archlinux/archlinux (virtualbox, 2019.08.05)

### Vagrantfile
```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "archlinux/archlinux"
  config.vm.provision "ansible_local" do |ansible|
    ansible.install = true
    ansible.playbook = "playbook.yml"
  end
end
```

### Debug output

[URL]

### Expected behavior
The `ansible_local` provisioner should install Ansible on the Arch Linux box.

### Actual behavior
Vagrant fails to install Ansible on the box and bails out. This used to work with Vagrant 2.2.4 against the very same box.

### Steps to reproduce
1. Create a `playbook.yml` files alongside the `Vagrantfile`. This can even be empty: Ansible will fail when trying to execute it but this will prove that it was installed at least;
2. `vagrant up` the provided `Vagrantfile`.
