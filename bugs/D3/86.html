Title

d3.time.scale ticks throws error with degenerate domain.

Description
If a time scale passed to the `d3.svg.axis` component has the same date for min/max in the domain, calling the axis component will throw `Error: infinite range`.

To reproduce:

```
var s = d3.time.scale()
  .domain([new Date(), new Date()])
  .range([0, 100]);

var axis = d3.svg.axis().scale(s);

d3.select("g").call(axis);
```
Discussion
- Simplified test case:

``` js
d3.time.scale().domain([new Date(0), new Date(0)]).ticks(10); // Error: infinite range 
```
- What would the right behavior here be?
- Returning an empty array, I expect.
