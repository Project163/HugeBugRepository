Title

[bug] Data URI is not working when the `window-data-url` feature enabled

Description
### Describe the bug

The [Link: document] says the data URL (such as `data:text/html, ...`) is supported when enabled by the `window-data-url` feature. But the fact is that an error occurred when loading the data URL.

### Reproduction

Create a `WebviewWindow` in JS, and it will throw an error.

```js
const webview = new WebviewWindow('my-label', {
      url: 'data:text/html, hello, world '
});
```

### Expected behavior

Can create WebviewWindnow with the data URL successfully.
