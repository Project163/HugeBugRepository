Title

Field and max_docs_per_value arguments in sampler agg on ES5

Description
**Elasticsearch version**: 5.0

I'm having trouble with the `field` and `max_docs_per_value` arguments that control diversity in the sampler aggregation for ES 5.0. With code that previously worked in ES 2.x which simply defines a field to control diversity on, I now get the following error when trying to define the arguments in ES 5.0:

`RequestError: TransportError(400, 'parsing_exception', 'Unsupported property "field" for aggregation "sampler')`

The documentation seems to be the same between the versions. I'm using the elasticsearch and elasticsearch_dsl python packages to do this, although this seems like an ES error?
