Title

indy caching bug for static method invocations

Description
class  A {
     static  bar() {1}
}
 class  B {
     static  bar() {2}
}
 static  foo( Class  c) {
    c.bar()
}
 assert  foo(A)==1
 assert  foo(B)==2
 
  
 This fails because the indy code adds only a guard for the receiver being a Class, but not for the class itself
