Title

Indent rule errors if an array literal starts a new statement

Description
This issue appeared with v1.1.0.

Rule:

``` yml
indent: [2, 2, {"SwitchCase": 1, "VariableDeclarator": 2}]
```

Code:

```
js
[
  ['gzip', 'gunzip'],
  ['gzip', 'unzip'],
  ['deflate', 'inflate'],
... [Log Snipped] ...
  console.log(method);
});
```

Error:

```
  1:1  error  Expected indentation of 2 characters but found 0  indent
  2:3  error  Expected indentation of 4 characters but found 2  indent
  3:3  error  Expected indentation of 4 characters but found 2  indent
  4:3  error  Expected indentation of 4 characters but found 2  indent
  5:3  error  Expected indentation of 4 characters but found 2  indent
  6:2  error  Expected indentation of 2 characters but found 0  indent
```
