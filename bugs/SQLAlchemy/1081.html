Title

Boolean column crashes mypy plugin

Description
**Describe the bug**
Using a `Boolean` column in an ORM class crashes the mypy plugin

**Expected behavior**
`mypy` should exit with `Success: no issues found in 1 source file`

**To Reproduce**

```
py
from sqlalchemy import Boolean, Column
from sqlalchemy.orm import declarative_base

Base = declarative_base()
... [Log Snipped] ...

    flag = Column(Boolean)
```

**mypy.ini**

```
[mypy]
plugins = sqlalchemy.ext.mypy.plugin
```

**Error**

```
$ mypy --show-traceback test_boolean.py    
test_boolean.py:7: error: INTERNAL ERROR -- Please try using mypy master on Github:
[URL]
Please report a bug at [URL]
version: 0.812
... [Log Snipped] ...
```

 - SQLAlchemy: 1.4.2
