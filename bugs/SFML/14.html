Title

sf::Joystick not detecting controllers designated as "Gamepad"

Description
Wrote a post about it before realizing that submitting it here might be better: [URL]

Long story short, in the Mac OS X SFML2 Joystick implementation currently only processes HID game controllers that are designated as "Generic Desktop Joystick" by their driver, ones designated as "Generic Desktop GamePad" (such as the wired xbox 360 controller with open source mac driver, are not detected.

Fix: filter HID devices not only by Joystick, but also add Gamepad (IE.  kHIDUsage_GD_Joystick and kHIDUsage_GD_Gamepad )
