Title

Intermittent failures to initialize dockerized Postgres metastore in tests

Description
In some cases tests relying on a dockerized Postgres metastore (see  Postgres JUnit rule ) fail to establish a connection with the database; as a consequence the HikariPool cannot be created and after multiple failed attempts the test fails.
