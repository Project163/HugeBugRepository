Title

Object Rest Spreads not quite working

Description
Object Rest Spreads aren't quite right in the esilnt though.  You can enable them with `experimentalObjectRestSpread`, however ESLint still considers the resulting variables as not defined.

```
js
function stealTheBacon(stuff) {
  var {bacon, ...others} = stuff;
  console.log('The bacon is mine', bacon);
  return others;
... [Log Snipped] ...
  tomatoe: "juicy"
});
```

```
json
{
  "env": {
    "es6": true
  },
... [Log Snipped] ...
  }
}
```

``` sh
4:10  error  "others" is not defined  no-undef
```

This is troublesome for React JSX since the feature is recommended by the docs.
[URL]

You can somewhat work around this by declaring ahead of time

``` js
function stealTheBacon(stuff) {
  var others;
  var {bacon, ...others} = stuff;
  console.log('The bacon is mine', bacon);
  return others;
}
```

You're re-declaring though, so now the linter should be complaining at you.
