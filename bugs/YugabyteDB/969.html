Title

[DocDB] Update to NULL could be lost after compaction when packed row is enabled

Description
Jira Link: [Link: DB-6638]
### Description

Consider the following scenario:

```
CREATE TABLE test(v1 INT, v2 INT) SPLIT INTO 1 TABLETS;
INSERT INTO test VALUES (1, 1);
UPDATE test SET v2 = NULL;
```

Compact all tablets;

```
SELECT v2 FROM test;
```

NULL should be returned by the last select, but we get 1. I.e. update to NULL is lost during compaction.
