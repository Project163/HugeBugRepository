Title

"fullTemplateTypeCheck" build error when using parameters from structural directives

Description
# 🐞 bug report

### Affected Package
 
  The issue is caused by package @angular/core

### Description

An error occurred, when using a parameter from a structural directive that is coming from **an external library that is built by the old engine**. 
On a regular `aot` build everything is working fine, but when setting `fullTemplateTypeCheck` flag I am getting the following error: 

[Image: Capture]

The directives `$implicit` context is declared as `any`

## 🔬 Minimal Reproduction

Install `@ngneat/transloco@2.0.0-rc.3`

In an HTML template add:

```html
 
  {{t('title')}}
 
```
