Title

Native tests fail on OS X, because DYLD_LIBRARY_PATH is not defined to include libhadoop.dylib.

Description
OS X uses  DYLD_LIBRARY_PATH  instead of  LD_LIBRARY_PATH  to control the dynamic link path.  If we set  DYLD_LIBRARY_PATH  in the test configuration, then we can run native tests on Mac.
