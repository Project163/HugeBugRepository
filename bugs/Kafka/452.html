Discussion
- The issue seems to be there is no resend in the test. We should configure enough retries (default to 0) and retry backoff time to allow metadata to be propagated to the broker after auto topic creation.
- I think this is a duplicate of   KAFKA-1395  . My proposal is to unify createProducer to ensure acks = -1 and type = sync, in which after the send call if no exception is thrown for failed message sending we are assured that the topic is created, hence no need to check waitUntilMetadataIsPropagated either.
