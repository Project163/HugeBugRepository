Title

Errors no longer updating after field touched in 7.39.6 when using `useFormContext`

Description
### Version Number

7.39.6

### Codesandbox/Expo snack

[URL]

### Steps to reproduce

With `react-hook-form=7.39.5` selected:
1. Click on and off the input box
2. Error is updated and shown "First name is required!"

With `react-hook-form=7.39.6` selected:
1. Click on and off the input box
2. Error is not updated

### Expected behaviour

The behavior should match `7.39.5`, with the `formState` `errors` updating after the `firstName` field is touched.
