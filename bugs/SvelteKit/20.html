Title

Routing on Rest Parameter Route does not execute load() function after initial call

Description
**Describe the bug**
I have a route `[...slug].svelte` which loads data within the `load()` function.

On the first impression everything works as expected, but on every next navigation route, hitting the `[...slug].svelte` route the content does not change.

By navigating from a [...slug].svelte route to another route eg index.svelte - the load() function from the index.svelte template is executed.

**Logs**
No logs available

**To Reproduce**

this repository produces the bug: [URL]

I created 2 routes: index.svelte and [...slug.svelte]. In [...slug].svelte the `load()` function return the `page.path` as `pagePath` property and this value is displayed on the page. When you navigate within [...slug].svelte routes, you see that the url is changing but the content does not.

**Expected behavior**
By navigating from page "1" to page "2" the content should display `page path is /one` and after the navigation `page path is /two`.
