- It's the opposite, see Ascent in the PDF 32000 specification: 
 
 The maximum height above the baseline reached by glyphs in this font. The height of glyphs for accented characters shall be excluded.  
 So the value for the type1 font are correct, and the one for the embedded type0 fonts are slightly incorrect. "Ä" should not be considered. I thought about getting all heights in the code and excluding accents, but I don't how. See glyphlist.txt in the source code, there are many things that can be considered accents and I'm not sure about them. 

 The best for you would be not to trust these values and do your own calculations, similar to what is done in DrawPrintTextLocations.
