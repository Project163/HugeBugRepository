Title

TemplateRef shares context between instances when none is provided

Description

**Current behavior**
`angular/modules/@angular/core/src/linker/template_ref.ts` currently uses a single object for `EMPTY_CONTEXT`. The problem is when `ViewContainerRef #createEmbededView` is called without providing a context object the shared one is used causing pollution between all instances utilizing the context.

**Expected/desired behavior**
Object sharing doesn't happen between instances relying on the context.

Maybe some solutions could be:
- `TemplateRef_ ` instantiates a new object when none is provided
- `ViewContainerRef #createEmbededView` makes context mandatory and `TemplateRef_ ` stops checking isBlank of context.
