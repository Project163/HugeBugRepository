Title

NFS Gateway may release buffer too early

Description
After upgrading Netty from 4.1.68 to 4.1.77 (  HADOOP-18079  ), NFS Gateway started crashing when writing data (can be easily reproduced by a few 10MB+ files).  The problem was triggered by  reduced default chunk size in PooledByteBufAllocator  (in 4.1.75), but it turned out to be caused by a buffer released too early in NFS Gateway.
