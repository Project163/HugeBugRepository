Title

File generated differently depending on test call

Description
Something weird is happening in  TestCreateSignature.testPDFBox3978 . The file  EmptySignatureForm.pdf  that is generated has different object streams depending on whether it is generated within a full test of the examples package, or if the  TestCreateSignature  class is tested. The two files should be identical except for the ID.
Discussion
- The files are equivalent, they merely use different object numbers (from different object number ranges) for the objects. 

 A possible issue, though: The first cross reference table in a PDF may not be segmented. It might be analogously assumed that in a PDF with cross reference streams only the equivalent shall hold for the first cross reference stream. 

 In both files, though, there is a more or less large gap between two sections.
