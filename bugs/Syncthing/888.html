TypeError: Object doesn't support property or method 'startsWith' in IE 11 / Windows 7

Description

The method seems to be completely unsupported in IE (see [URL] but I do not have these errors in IE 11 under Windows 10. I am not sure what the difference is though.

Discussion
- Honestly, I don't think we should make an effort to support a [Link: soon to be officially dead] "browser" on an officially dead OS, if the user can just install a real browser.
- This appears to be an IE thing. There are polyfills, but ... 🤷

[Image: image]‍
- The news is not about IE 11 support though. The browser itself is going to be supported until at least 2029 (as a part of Windows 10 Enterprise LTSC 2019 and Windows Server 2019), and probably longer than that if it stays a part of the future LTS Windows releases.

There are situations where the user is not allowed to install "a real browser", e.g. education, enterprise, various offices, etc.

I do not think that all functionality needs to be available in older browsers, but a constant spam of errors does not look good.
- Fixing this won't hurt anything else, so if someone wants to do that it's all right.
