Title

Strip UTF-8 BOM bytes (if present) in TextSource.

Description
TextSource in the org.apache.beam.sdk.io package can handle UTF-8 encoded files, and when the file contains byte order mark (BOM), it will preserve it in the output. According to Unicode standard ( [URL] "Use of a BOM is neither required nor recommended for UTF-8". UTF-8 with a BOM will also be a potential problem for some Java implementations (e.g.,  [URL] As a general practice, it's suggested to use UTF-8 without BOM. 

 Proposal: remove BOM bytes in the output from TextSource.
