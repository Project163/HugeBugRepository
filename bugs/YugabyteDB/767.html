Title

[DocDB] yb_build.sh fails on Ubuntu 20.04

Description
Jira Link: [Link: DB-3878]
### Description

**Overview**

When following the steps outlined [Link: here] to build from source on Ubuntu, the build script downloads the dependencies for almalinux and then fails.

**Steps to reproduce**

These steps are taken directly from the docs:
1. Install prerequisites
```
sudo apt-get update
sudo apt-get install uuid-dev libbz2-dev libreadline-dev maven ninja-build \
                     cmake curl rsync python3-pip python3-venv zip autoconf libtool \
                     pkg-config libssl1.0-dev libicu-dev bison flex \
                     libncurses5-dev
```

Clone the repo and run `./yb_build.sh release`

**Results**

Initially the build scripts failed to find my C compiler:
```
-- Check for working C compiler: /opt/yugabyte-db/build-support/compiler-wrappers/cc -- broken
CMake Error at /usr/share/cmake-3.16/Modules/CMakeTestCCompiler.cmake:60 (message):
  The C compiler

    "/opt/yugabyte-db/build-support/compiler-wrappers/cc"
... [Log Snipped] ...
    /opt/yugabyte-db/build-support/compiler-wrappers/../common-build-env.sh: line 1102: cc_executable: unbound variable
    ninja: build stopped: subcommand failed.
```
Despite clang and gcc being in `/usr/bin`
```
root@208d3277a61c:/opt/yugabyte-db# which clang
/usr/bin/clang
root@208d3277a61c:/opt/yugabyte-db# which gcc
/usr/bin/gcc
```
