Title

brace-style "allman" fails with switch

Description
**What version are you using?**

v1.5.1

**What did you do?**

Using `"brace-style": [2, "allman"]`, I wrote the following code:

``` js
switch (foo)
{
    case 1:
        break;
}
```

**What happened?**

eslint flagged the `switch` with the message "Opening curly brace does not appear on the same line as controlling statement.".

**What did you expect to happen?**

Nothing. With "allman" style the opening curly brace should be on the next line.

I have a fix, I'll be submitting a PR.
