Title

Print a warning when using an oldName of a flag

Description
### Description of the problem / feature request:

In [URL] a user was confused by the fact that `--experimental_enable_runfiles` still exists (undocumented) when `--enable_runfiles` also exists. They thought that these are two different flags, the experimental one maybe being a newer or different implementation.

In fact, they're the same flag, but `--experimental_enable_runfiles` was the `oldName` of the flag: [URL]

### Feature requests: what underlying problem are you trying to solve with this feature?

We should print a warning if a flag is passed by its `oldName` to Bazel that tells the user that the name is deprecated and might go away in the future. The warning should also contain the new name of the flag.
Discussion
- In fact, the JavaDoc says that this should already work: "If the old name is used, a warning will be printed indicating that the old name is deprecated and the new name should be used." 😏
