Title

Bug: Exporting GLB has validation errors

Description
**Describe the bug**
GLB exported from assimp is missing the ``POSITION'' key in its attribute buffer.
This manifested when I was attempting to load a mesh exported from assimp into trimesh (see this [Link: issue]). This mesh loads fine in Blender, but it seems that is more due to luck, as the official GLTF validator reports multiple errors.

**To Reproduce**
Currently I don't have a public method to replicate this. The mesh is imported fine, then modified and exported, but the modification is not public.

**Expected behavior**
