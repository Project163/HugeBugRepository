Title

[bug] resources are missing after installer upgrade (works after re-install)

Description
### Describe the bug

When upgrading from a previous installation, the `resources` specified in `tauri.conf.json` are skipped. Uninstalling and re-installing the program fixes it.

I saw this bug on the latest beta/production release of my application. There was a smaller update this Monday (5/16) that worked correctly. Maybe this is a regression in recent changes to the installer?

I can post the diff of `tauri.conf.json` for the previous and current version if it is helpful.

### Reproduction

1. Download and install v0.9.2 of the application: [URL]
2. Check `C:\Program Files\hypetrigger` to see that all resources have been bundled (`tensorflow.dll`, `tensorflow.lib`, `ffmpeg.exe`, and `data` folder)
[Image: hypetrigger-0 9 2-program-files]

3. Either accept the auto-update request to v0.10.0, or download the v0.10.0 installer (both approaches cause the bug): [URL]
4. After installation, attempt to launch `Hypetrigger.exe`
5. Error: `tensorflow.dll is not installed`

[Image: tensorflow dll]

6. Check `C:\Program Files\hypetrigger`. Notice that all the assets are missing from this version of the installation, even though all the same resources are present in `tauri.conf.json`

[Image: hypetrigger-missing]

7. Run the 0.10.0 installer again to uninstall the program, and then reinstall from scratch
8. Launch `Hypetrigger.exe`. This time, the app loads correctly and all the resources are correctly located in the installation folder.

### Expected behavior

The installer should always bundle the correct resources when installing.
