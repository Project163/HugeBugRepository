Title

glfwVulkanSupported emits VK_ERROR_OUT_OF_HOST_MEMORY error on systems without ICD

Description
When a Windows system has the Vulkan runtime installed but drivers that do not support Vulkan glfwVulkanSupported invokes _glfwInputError instead of returning GLFW_FALSE.

glfwVulkanSupported invokes _glfwInitVulkan with _GLFW_FIND_LOADER, and gets as far as vkEnumerateInstanceExtensionProperties before falling foul of the lack of driver support.

This might be considered an edge-case not a worth the effort to fix, but it makes it a pain for applications to report a sensible response to the user when they don't have a complete Vulkan stack.

The machine has the Vulkan RT installed, as I have it installed wherever I'm developing.  The application has bespoke OpenGL and (WIP) Vulkan renderers.
