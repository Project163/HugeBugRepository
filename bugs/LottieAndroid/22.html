Title

Dynamically updating LottieProperty.TRANSFORM_POSITION does not work with split dimensions

Description
**Link to fork with a repro in the issue-repro module**
[URL]

**Describe the bug**
`addValueCallback` does not work correctly when trying to dynamically update `LottieProperty.TRANSFORM_POSITION`. The value override callback is never called by Lottie.
```Kotlin
        lottieAnimationView.addValueCallback(someKeyPath, LottieProperty.TRANSFORM_POSITION) { value ->
            PointF(100F, 200F)
        }
```

After some debugging, it looks like the bug is in `SplitDimensionPathKeyframeAnimation`. This appears to be used to animate positions but ignores value callbacks entirely. Below is a screenshot of a debugger output showing that there is a value callback set correctly on the animation object.
- After some more digging, I figured out this bug only exists when the animation file has split x/y keyframes. We re-exported our animation with "combined" keyframes and it works as expected. Let me know if you want me to close this.
