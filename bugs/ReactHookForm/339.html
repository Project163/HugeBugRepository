Title

Unregistering deep nested array positions, unregisters the full array

Description
### Version Number

7.27.1

### Codesandbox/Expo snack

[URL]

### Steps to reproduce

1. Fill first name and last name
2. Submit
3. Note that the form object is in the following form: {"contact": { "fields": ["last name here", "first name here"]}}
4. click in the button "UNREGISTER FIRST NAME". The field should be gone and unregistered.
5. The last name should be unchanged.
6. Click submit.
7. The alert shows a empty object.


### Expected behaviour

After unregistering the first name field, and submitting the form, the last name field should be kept untouched, but it isn't. The resulting submit should produce something like this:

{"contact": { "fields": ["last name here"]}}

I forked the codesanbox present in [URL] and using the version 7.2.2 with these modifications, it works as expected.

### What browsers are you seeing the problem on?

Chrome
