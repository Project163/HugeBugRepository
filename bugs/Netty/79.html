Title

SwappedByteBuf.unwrap() should return null

Description
Unlike other derived buffers such as `SlicedByteBuf`, `SwappedByteBuf` shares everything including the indexes with the original buffer.  Also, `SwappedByteBuf.free()` will also free the original buffer.

This is an intentional decision to allow a user to deal with little-endian protocols.

Currently, we call `unwrap()` to determine whether a buffer is derived or not.  In spite of the fact that `SwappedByteBuf` is not a derived buffer but a special buffer, `SwappedByteBuf.unwrap()` returns non-null, leaving enough room for confusion.

Because we can get the original buffer by calling `SwappedByteBuf.order(BIG_ENDIAN)`, there's not really need to make `unwrap()` return the original buffer.
