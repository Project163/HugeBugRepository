Title

Adding semi-transparent background color to Text component causing display issue on iOS

Description
## 🐛 Bug Report
[Image: IMG_5858 (1) (1)]
Adding semi-transparent background color to Text component causing display issue on iOS. 
It seems that background color is unnecessary reapplied under text characters inside Text component.

## To Reproduce
Apply semi-transparent `backgroundColor` to Text component (ex. `"rgba(255,0,0,.5)"`).

## Expected Behavior
Background color isn't reapplied under text characters.
(There is an easy workaround by adding `View` component wrapper to `Text` and applying background color to the wrapper)
