Title

Request_gzip = True

Description
In order to receive gzipped content, requests should send the header:

```
'Accept-Encoding': 'gzip'
```
Discussion
- This is intentional and correct behavior. 

If the server responds with gzip-encoded content, requests will handle it. 

I think the user should be explicit with the headers they send up if they'd like to change the default behavior of the server.
- Perhaps a `requests.settings.request_gzip = True` is in order?
- Yes, but what about deflate compression?
Maybe simply something like `settings.compression = True` that enable both gzip and deflate compression?
