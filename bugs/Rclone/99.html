Title

[Dropbox] HTTP error 461 - don't retry

Description
Hi, I'm running RClone version 1.3 and I'm trying to migrate Dropbox files to Google Drive for a friend, however, it seems to be erroring out on one of her files with HTTP error code 461. From what I can tell from Google (Can't find official documentation), it seems to be related with a DMCA strike:-
