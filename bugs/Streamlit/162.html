Title

Dataframe header coloring in v0.89 and above

Description
### Summary

With v0.89, we made updates the design, where the dataframe header coloring was changed.  

### Steps to reproduce

Code snippet:

```python
import streamlit as st
import pandas as pd

data = [['tom', 10], ['nick', 15], ['juli', 14]]
df = pd.DataFrame(data, columns = ['Name', 'Age'])

st.dataframe(df)
```


**v0.89**

- Clarified with @tvst that this is working as intended and in the future we want to move away from tying together `secondaryBackgroundColor` with the dataframe headers. 

Requesting @snehankekre to remove the section about the above from our documentation.
- @asaini I've created a [Link: PR] to remove this section from the docs.
