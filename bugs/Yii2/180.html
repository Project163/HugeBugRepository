Title

JSON MIME format and failing unit test

Description
JSON MIME test in FileHelperTest::testGetMimeType() fails if extension fileinfo not installed. It returns **null** since the definitions of mime types in /helpers/mimeTypes.php have no definitions for json/jsonp.

There are two issues to solve:
- correct JSON MIME type should be **application/json** for standard *.json extensions, and text/javascript for jsonp extension.
- unit test should consider option that fileinfo extension is optional and not all users have it installed. Also it returns not quite correct MIME type for json "text/plain".

To fix these issues, following should be done:
- added JSON, JSONP mappings into mimeTypes.php
- unit test should accept both results as correct ones (text/plain, application/json) 

This would fix test breaks for users without fileinfo extension and accept also correct MIME type. However, if the extension "fileinfo" is meant to be required, then before executing this unit test, the test for its should be executed and the test should be skipped rather than let failed.
