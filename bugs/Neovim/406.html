Title

Assertion failed: (opt_idx != kOptInvalid) when accessing invalid options

Description
### Problem

Nvim 0.11-dev crashes with the following error

```
Assertion failed: (opt_idx != kOptInvalid), function get_option, file option.c, line 3399.
```

when accessing an option that does not exist. This is a regression since   (#31066). /cc @famiu

### Steps to reproduce

```
:lua vim.api.nvim_get_option('invalid')
```

To my knowledge, this bug was first reported in [URL]
```bash
nvim --clean --headless -c "py3 vim.current.buffer.options['invalid-option']"
```

### Expected behavior

Should raise an error: `Invalid option name: 'invalid-option'`

0.11 commit 29ded8895
