Title

Metrics handler throws an error if there are transient cores

Description
My environment is as follows 
 
	 Solr 7.2.1 in standalone mode. 
	 32GB heap 
	 150 cores with data getting continuously ingested to ~10 cores and all of the cores queried. 
	 transient cache size is set to 30. 
 

 The solr.xml is as follows 
  
 
 <?xml version= "1.0"  encoding= "UTF-8"  ?> 
 <solr> 

   <int name= "transientCacheSize" > 32 </int> 
   <str name= "shareSchema" > true </str> 
   <str name= "configSetBaseDir" > ${configSetBaseDir:configsets} </str>

     <int name= "socketTimeout" > ${socketTimeout:600000} </int>
