Title

[middlewares via next dev]: WebCrypto issue with Uint8Array and key generation

Description
### What version of Next.js are you using?

12.0.1

### What version of Node.js are you using?

v14.18.0

### What browser are you using?

Chrome

### What operating system are you using?

macOS

### How are you deploying your application?

next dev

### Describe the Bug

The polyfill implementation of webcrypto for `next dev` is throwing errors that the cloud environment on vercel.com does not.

Issue is most likely because the Uin8tArray constructor is different between the context in which peculiar/webcrypto is required and the unique vm context which the middleware code is executed in. Solution would be to require the polyfill inside the vm context, not outside, or to pass all the [Link: Indexed Collections] to the context.

### Expected Behavior

Both environments work as expected.
