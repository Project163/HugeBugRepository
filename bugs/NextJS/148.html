### Describe the Bug

Due to #34823, `@typescript-eslint/parser` version is now locked (canary currently at 5.10.1) by `eslint-config-next`. For TypeScript 4.6 support, a minimum version of 5.14.0 is required which would have been installed prior to the version being locked. Now for projects using TypeScript 4.6, ESLint displays the following message:

```
=============

WARNING: You are currently running a version of TypeScript which is not officially supported by @typescript-eslint/typescript-estree.

You may find that it works just fine, or you may not.
... [Log Snipped] ...

=============
```

### Expected Behavior

The warning message should not be displayed.

### To Reproduce

1. Use `npx create-next-app --typescript` to create a project.
2. Update `typescript` to version 4.6.2 or newer, if necessary.
3. Use `npm run lint`.
