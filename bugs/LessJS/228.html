Title

At-rule declarations may go missing are or incorrectly merged under certain nesting conditions

Description
@jpattishall-ebay raised an issue in [URL] where they noted ```@media``` and ```@container```  are not properly nesting in some cases.

Currently I see in 4.2.1 [Link: Playground] I see this:

```css
@media only screen and (min-width: 768px) {
  @container (min-width: 500px) {
    .primary-content {
      font-size: 1rem;
    }
  }
}
```

results in:

```css
@container only screen and (min-width: 768px) and (min-width: 500px) {
  .primary-content {
    font-size: 1rem;
  }
}
```

But I see [Link: 4.1.3] produced the expected output:

```css
@media only screen and (min-width: 768px) {
  @container (min-width: 500px) {
    .primary-content {
      font-size: 1rem;
    }
  }
}
```
