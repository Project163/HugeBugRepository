Title

Get waring by react after pushing to another route

Description
**Describe the bug**
You get warning each time when change route from form submit handler

```
Warning: Can't perform a React state update on an unmounted component. This is a no-op, but it indicates a memory leak in your application. To fix, cancel all subscriptions and asynchronous tasks in a useEffect cleanup function.
in App (created by Context.Consumer)
```

**To Reproduce**
Steps to reproduce the behavior:
1. Add `history.push(ROUTE)` to submit handler
2. Click submit

**Expected behavior**
As expected you move to another route, but you get warning by react

**Versions**
 - `react: 16.8.6` `react-dom: 16.8.6`
 - `react-hook-form: 3.11.3`
