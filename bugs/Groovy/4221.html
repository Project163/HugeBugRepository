Title

Regression with static and non static class mixing

Description
This issue started after the upgrade from 3.0.7 -> 3.0.9 

   

 Given the following code: 
  
 
 class  A {

      static   class  B {
          String  throwC() {
              throw   new  C()
         }
     }

      class  C  extends  RuntimeException {

     } 
}

Discussion
- Just a note, since C is a non-static inner class, it requires a reference to A in its constructor.  The code example happens to rely on the implicit null argument supplied by the compiler when a 1-parameter constructor/method is called with 0 arguments. 

 If the C exception type was static there would be no issue.  I'll try to fix, but it is a bit of an edge case.
- The example will properly produce compiler error: "No enclosing instance passed in constructor call of a non-static inner class"
