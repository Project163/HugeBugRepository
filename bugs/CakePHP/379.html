Title

Get a Notice when calling updateCounterCache() with empty data

Description
I ran a deleteAll in my 'Order' model, then called $this->updateCounterCache(); but because I didn't have any data in $this->data[$this->alias], it through an error:

Notice (8): Undefined index: Order [APP/Vendor/pear-pear.cakephp.org/CakePHP/Cake/Model/Model.php, line 2027]

adding the following code before the updateCounterCache() removed the notice:

$this->data[$this->alias] = array();
$this->updateCounterCache();
