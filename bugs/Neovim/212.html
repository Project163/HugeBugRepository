Title

undofile() result different from actual undo file

Description
- `nvim --version`: v0.3.5 release build
- Vim (version: 8.1) behaves the same
- Operating system/version: Linux

Opening a file at path `//tmp/foo` results in an undo file named `%tmp%foo`: the path is normalized before replacing path separators with `%`. On the other hand, `undofile('//tmp/foo')` returns `%%tmp%foo`. Shouldn't these two things be the same?

To reproduce:

`nvim -u NORC`

```
:set undofile
:e //tmp/foo
" write something
ibar 
:x
```

Find the created undo file at `~/.local/share/nvim/undo/%tmp%foo`.

Then compare against running `:echo undofile('//tmp/foo')`.
