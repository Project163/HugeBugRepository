Title

Task inputs for junitPlatformTest are broken

Description
## Status Quo

Executing `gradlew clean test; gradlew test; gradlew test` results in **all** `junitPlatformTest` tasks being executed **thrice** instead of just once. In other words, the _task inputs_ for the task created by the `JUnitPlatformPlugin` no longer work, thus rendering incremental builds with Gradle not so very useful.

## Deliverables

- [x] Revise task inputs for `junitPlatformTest` so that incremental builds work once again.
Discussion

- Sure.

    onlyIf {

- ```

BUILD SUCCESSFUL

Total time: 1.974 secs
```
