Title

quarkus-websockets-next client adds / to empty path

Description
### Describe the bug

Using @WebSocketClient(path = "") with an empty path is not possible.
io.quarkus.websockets.next.runtime.WebSocketConnectorBase line 128:
`return path.startsWith("/") ? sb.toString() : "/" + sb.toString();`
This adds a / even if the path is empty

### Expected behavior

Add no / for an empty path

### Actual behavior

Adds a / to an empty path
