- If turning off AV and Windows Search consistently fixes this I consider this an external/environment problem and not a problem with our code-base w/regards to stopping.  Pre 3.0 (and w/memory-mapped I/O when we go back down that route), file sharing violations like this from outside programs are, by default, a problem we're going to stop the database for rather than allowing failed deletions to potentially fill a drive on a node.
