Discussion
- Removing fix version of 1.2.0 in preparation of release, since this is not a blocker for 1.2.0.
- HS2 provide two fetch types when fetchResult: Query_Output and LOG. When hive.server2.logging.operation.enabled is false, it is normal behavior that HS2 throw exception when client try to fetchResult using LOG. The problem here is that in hive jdbc getQueryLog method, it just blindly call FetchResult method with fetchType LOG without checking if server enable logging or not.  
Fix this issue by checking before call FetchResult.
