Title

Cannot resolve entry module

Description
With webpack 0.9.0-beta35, when I type

`webpack main.js --output-file bundle/main.js`

in a folder where a `main.js`-file exists, webpack says that it can't find the entry module main.js. It works with `./main.js`, though. I think it's common that in a cli you don't have to write relative style for paths.
Discussion
- This style worked also with webpack@0.8.3 :smile:
- Yes, I changed it...

It is resolved like any expression in `require(...)` so you may pass modules, files, anything with loaders as entry.
- Ah cool. So this will work with webpack 0.9?
- yes, but only if you pass an filename:

This will work:

```
webpack main.js
webpack js/main.js
webpack entry1.js entry2.js
webpack page1=entry1.js page2=entry2.js
```

This will not work:

```
webpack main  -> extension missing, use webpack ./main
webpack js/main  -> use webpack ./js/main
webpack main.js?parameters  -> use webpack ./main.js?parameters
webpack loader!main.js  -> use webpack loader!./main
```
