Title

Index updates lost

Description
[Link: This forum thread] details troubleshooting of deletes that don't sync. (I don't think deletes are special, other than being a terminal state for a file so a further update never  happens which otherwise might resolve the issue.)

After poring through logs we can see one thing that is bad. The sending size (TXZZI) sends index updates. The receiving side (JKZ4T) gets them, but does not apply them all to the database.

- So the problem here is that we don't do the files + sequence updates in a single transaction.  The sequence updates happen first, in one transaction, and then the file updates. If a WithHaveSequence walk is started after the sequence updates but before the file updates bad things happen. It's possible for a sequence entry to point to either something that doesn't exist or (like in the panic above) an older file entry.
