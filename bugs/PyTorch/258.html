Discussion
- Hi, I would like to work on the issue. 

The issue appears to be caused by a missing validation for the step value in the unfold_backward function. When step < size, the _unfold_backward_internal_kernel is being called directly , which accepts 0 as step value, causing divide by 0 or FPE.

Minimum reproducer example:

```
import torch

grad_in = torch.full((), 0, dtype=torch.double)
input_sizes = []
dim = 0
size = 1
step = 0
torch.ops.aten.unfold_backward(grad_in, input_sizes, dim, size, step)
```

Adding a PR soon.
