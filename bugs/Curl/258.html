Title

LDAP segmentation fault

Description
### I did this

```
curl --insecure --user ozanadmin@corp.sunnyvalley.io:Ozn.1234! ldap:// :389/DC=corp,DC=sunnyvalley,DC=io??sub?(|(userPrincipalName=ozanadmin@corp.sunnyvalley.io)(sAMAccountName=ozanadmin@corp.sunnyvalley.io))
```
When i run this command it crashes with segmentation fault.

- Curl binary is built from master but it is same in `8.5.0`. According to my findings, it is related with `openldap.c`. It doesn't happen with `ldap.c`. It doesn't happen when i use `ldaps`.

#### Console output at the segmentation fault.
``` 
*   Trying  :389...
* Connected to   ( ) port 389
* LDAP local: ldap:// :389/DC=corp,DC=sunnyvalley,DC=io
```
#### Why does it crash ?
At this [Link: line] `li->send` is `NULL` so it gives segmentation fault.
