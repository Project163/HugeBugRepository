Title

BUILD.bazel in external repo doesn't work

Description
in Bazel 0.4.1, packages are defined in BUILD.bazel as well as BUILD files. But it don't work if an external repository have BUILD.bazel.

### Description of the problem:

Here is the sample of using BUILD.bazel file.
[URL]

Building it with `bazel build //:all` in it works fine.

Create another directory, with WORKSPACE file as following:
```
git_repository(
    name = "examples_cpp",
    remote = "[URL]
    commit = " ",
)
```

And do `bazel build @examples_cpp//:all` will result:
```
ERROR: while parsing '@examples_cpp//:all': no such package '@examples_cpp//': BUILD file not found on package path.
```

It works just fine if the samples is using BUILD instead of BUILD.bazel, but BUILD.bazel should work too.
