Title

yii session is not active when log message to file

Description
Hi,
I find that yii session component is inactive when the work flow process to log messages. In file yii/web/log/Target.php, line 286:

```
 $sessionID = $session && $session->getIsActive() ? $session->getId() : '-';
```

The asset $session->getIsActive() always returns false and thus sessionID is '-' in the log files. Where in controllers, function getIsActive returns true. I guest that session component calls close() method before logger logs messages.
