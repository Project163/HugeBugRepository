Title

brace-style: don't warn about one-line form without braces

Description
`brace-style` rule should warn about incorrect brace style only when braces are actually present, since brace presence is controlled by another rule (`curly`).

I want to enforce a brace style while also supporting no-braces one-line form. Sample code:

``` js
if (tag === 1) glyph.id = pbf.readVarint();
else if (tag === 2) glyph.bitmap = pbf.readBytes();
else if (tag === 3) glyph.width = pbf.readVarint();
else if (tag === 4) glyph.height = pbf.readVarint();
```

`"brace-style": [2, "1tbs", {"allowSingleLine": true}]` will say:

```
Closing curly brace does not appear on the same line as the subsequent block
```
