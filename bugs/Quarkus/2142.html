Title

quarkus.native.enabled=false is not reflected when maven profile has native

Description
### Describe the bug

quarkus.native.enabled=false is not reflected when maven profile has  native 

This got noticed after [URL] change CC @dmlloyd 

Generated Quarkus applications always have native profile with  native .

### Expected behavior

quarkus.native.enabled=false is gets reflected even if maven profile has  native 

### Actual behavior

quarkus.native.enabled=false is not reflected when maven profile has  native 

native build is performed

### How to Reproduce?

 - Build the latest Quarkus
 - Use [Link: code-with-quarkus.zip]
 - Run `mvn clean verify -DskipTests -Dnative`
 - Check the log to see NativeImageBuildRunner in action

Change the maven profile id to see that ` false ` settings get reflected.
