Title

has_child & has_parent queries don't take deletes into account

Description
If score mode: `max`, `avg` or `sum` is specified for `has_child` and if score mode `score` is specified for `has_parent` query then deletes aren't taken into account.

This affects all version from 0.90.0.Beta1
