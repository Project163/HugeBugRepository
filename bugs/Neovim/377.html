Title

Ctrl-Z in insert-mode, when `'insertmode'` is set.

Description
- `nvim --version`:
0.1.7
- Vim (version: ) behaves differently?
8.0 No, same problem

### Actual behaviour
After suspending neovim with C-Z in insert mode, while `'insertmode'` is set the command register `":` is set to `st`.
### Expected behaviour
The command register should not be changed.
### Steps to reproduce using `nvim -u NORC`

```
nvim -u NORC
:set insertmode
C-o:registers
C-z
C-o:registers
```

Observe that the command register is `st`.

# Cause
This functionality is implemented by stuffing `readbuf1` with an ex command -- see `edit.c:1028`
`readbuf1` is treated like user input, and hence the `":` register is set when the command is read.
