Title

Hygienic rename breaks shorthand destructuring assignments

Description
Consider following code:

index.js:

``` javascript
import { useModuleStuff } from './module';
const Stuff = 'localStuff';

useModuleStuff();
```

module.js:

``` javascript
const { Stuff } = GlobalNamespace;

export function useModuleStuff() {
  return new Stuff();
}
```

In order to avoid conflicts between local and imported `Stuff` variables, Rollup renames the latter one, which is a good thing, but it doesn't take into account the destructuring semantics and generates following code:

``` javascript
const { Stuff$1 } = GlobalNamespace;

function useModuleStuff() {
  return new Stuff$1();
}

useModuleStuff();
```

As you can see, destructuring got the form `const { Stuff$1 } = GlobalNamespace` which is not semantically equivalent to `const Stuff$1 = GlobalNamespace.Stuff` anymore.
