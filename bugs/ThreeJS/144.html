Title

texture.needsUpdate does not work (r73)

Description
[URL]

In the following example, the

hudTexture.needsUpdate = true;

does not work with three.js r73, so the text drawn to the texture is not refreshing. It worked in version r71.
Discussion
- With bisect, i found the following commit cause the problem:

[ ] WebGLRenderer: Convert to power of two textures that require it instead of giving wrap/minFilter warnings.
- @mrdoob Here is a r.74dev [Link: fiddle] that reproduces the problem.

If the HUD is not a power-of-two, the text does not update.
