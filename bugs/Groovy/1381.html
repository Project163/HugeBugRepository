Title

Script extension set on groovyc does not flow down to the CompilerConfiguration

Description
Groovyc supports an attribute called scriptExtension, that is used to compile the files with that particular extension instead of standard *.groovy extension. 

 It seems like Groovyc doesn't pass this information to CompilerConfiguration - in forked or non-forked compilation both, which continues to see as "*.groovy" always and it may cause to compilation inconsistencies.
