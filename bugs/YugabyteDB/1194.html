Title

[YSQL][ASH] Prepared statements are not tracked if pg_stat_statements.track = 'all' is not set

Description
Jira Link: [Link: DB-12675]
### Description

Pg stat statements doesn't track the execution of PREPARE, EXECUTE and DEALLOCATE

```
yugabyte=# create table n(a text, b int, c float);
CREATE TABLE
yugabyte=# insert into n values('abc',1,1.1);
INSERT 0 1
yugabyte=# insert into n values('abc',2,2.2);
... [Log Snipped] ...
(1 row)
...
```

From tserver-ip:13000/statements
```
{
            "userid": 13256,
            "dbid": 13257,
            "query_id": - ,
            "query": "prepare st(text, int, float) as select * from n where a = $1 and b = $2 and c = $3",
... [Log Snipped] ...
            ]
        },
```

This is the only entry in pg_stat_statements, which is the underlying query that is executed by the executor hooks when EXECUTE is called.

This query id is not present in ASH if `pg_stat_statements.track`  is not set to `all`
