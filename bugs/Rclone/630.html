Title

Description
#### What is the problem you are having with rclone?
The problem is described in detail on: [URL]
It looks like the modification time is not updated until the cache writeback completes, rather than when the file was written.

    rclone mount -vv --vfs-cache-mode full --dir-cache-time 10s s3:rclone /mnt/tmp/
