Title

--ignore-watch="*.log" has crashed pm2

Description
I just observed that pm2 server crashed and killed all of my node apps simply by trying to start another application by doing following.

```
pm2 start progress.js --watch --ignore-watch="error.log"
```

I see following in the pm2 logs

```
2015-09-02 16:27:32: Process with pid 13717 killed
2015-09-02 16:27:36: [PM2] Error caught by domain:
SyntaxError: Invalid regular expression: /*.log/: Nothing to repeat
    at new RegExp ( )
    at Object.ClusterMode.God.watch.enable (/usr/lib/node_modules/pm2/lib/Watcher.js:33:17)
... [Log Snipped] ...
        throw er; // Unhandled 'error' event
              ^
```

2 requests...

1) Make pm2 not crash if it received any uncaught exceptions.
2) Make --ignore-watch to accept wild cards (like *.log)
(I just realized I could do --ignore-watch=".log$".. however)

Thank you!
Discussion
- This has been fixed in PM2 #dev so:

```
$ npm install Unitech/PM2#development -g
$ pm2 update
```
