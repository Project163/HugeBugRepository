Title

[YSQL] Fix read restart errors on disjoint writes

Description
Jira Link: [Link: DB-14401]
### Description

Table

```
CREATE TABLE keys(k1 INT, k2 INT, PRIMARY KEY(k1 ASC, k2 ASC));
```

Batched SELECT raises a read restart error on concurrent writes to a disjoint key.

SELECT

```
SELECT k1 FROM keys WHERE k1 IN (0, 9);
```

happens concurrently with

```
INSERT INTO keys VALUES (1, 1);
```

leads to a read restart error.
