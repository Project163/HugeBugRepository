Title

DNS Resolution broken in sandboxes with `requires-network`

Description
I am currently trying to download some javascript dependencies with a sandboxed gen-rule. I added the `requires-network` tag, but it appears that DNS resolution is broken. I confirmed that I could reach the localhost and that I could reach external hosts if I used the IP, but any attempts using host names fails.

This is reproducible with the following rule

```
python
genrule(
    name = "network_test",
    srcs = glob(["some/input/files/*"]),
    cmd = """
... [Log Snipped] ...
    tags = ["requires-network"]
)
```

The first 2 curl commands succeed, and the third fails with `curl: (6) Could not resolve host: google.com`

I'm on Ubuntu 15.10 with kernel 4.2.0-18.  This issue appeared both on bazel release 1.2 and master at the time of writing
