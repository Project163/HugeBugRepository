Title

AffinityPlacementPlugin can fail when using spread-domains feature and there are replicas of the shard in DOWN nodes

Description
When using AffinityPlavementPlugin and the new "spread-domain" option, the placement computation can fail when there are replicas in DOWN nodes because the "spread_domain" sys prop can't be fetched.
