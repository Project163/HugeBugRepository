Title

Pixel wide gaps between adjacent UI nodes

Description
## Bevy version

main

## What you did

- I think this is probably Taffy related. It seems to round the length of certain nodes but not others.

There are subtle problems with Bevy UI Text that are similar where what I suspect is happening is that you ask for a width of x pixels for your text with the MeasureFunc, but then Taffy rounds it down a pixel and so the Text no longer fits the width, so the last word of the text gets pushed down to a new line. But the Node itself stays at a height of only one line of text, so the text renderer doesn't draw the second line of text and it just looks there are missing words at the end of sentences with certain text layouts.
- Hmm... I feel like the text renderer probably shouldn't count a glyph as fitting if it requires a partial pixel.


Taffy's rouding is pretty simple. It computes the entire layout using floats, and then rounds everything at the end.
