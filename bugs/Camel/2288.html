Title

Property placeholder optimization broke placeholders in Spring camelContext configuration

Description
We are upgrading from 2.10.0 to 2.11.0, and are getting an error on startup. 

 Example Spring configuration: 

  
  <camelContext id= "camel"  handleFault= "true"  autoStartup= "{{autoStartup}}"  xmlns= "[URL]
     <contextScan /> 
     <jmxAgent id= "camelAgent"  createConnector= "true"  registryPort= "{{jmxPort}}"  /> 
 </camelContext> 

 <bean id= "properties"  class= "org.apache.camel.component.properties.PropertiesComponent" > 
     <property name= "location"  value= "classpath:foo.properties" /> 
 </bean> 
 
  

 As you can see, we use the Camel properties component to configure Camel auto-startup, JMX port, etc. 

 This is the error we're getting on startup:
