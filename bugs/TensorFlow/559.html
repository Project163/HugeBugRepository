### Current Behaviour?

```shell
The following code can trigger a crash in `tf.raw_ops.MatrixLogarithm` due to check-fail in the latest version of TensorFlow.
```

### Standalone code to reproduce the issue

```shell
import tensorflow as tf
with tf.device("CPU"):
    input = tf.complex(tf.random.uniform([0, 9, 13, 15, 13,  ], dtype=tf.float32, minval=-1024, maxval=1024),tf.random.uniform([0, 9, 13, 15, 13,  ], dtype=tf.float32, minval=-1024, maxval=1024))
    res = tf.raw_ops.MatrixLogarithm(
        input=input,
    )
```
