Title

Args is creating a actionHandler() method when onClick is added as a prop but isn't required

Description
**Describe the bug**
Currently when you write a story for a component that has an optional onClick prop, it doesn't define that method as undefined when values are passed as an arg. It instead returns an "actionHandler()" method. You can even go as far to explicitly define the method as undefined and this doesn't work either.

```JS
Default.args = {
	onClick: undefined
};
``` 

**To Reproduce**
Create story for component that has `onClick` prop. 

```JS
export const Default = (args: ChipProps): JSX.Element =>  ;

Default.args = {
	children: "Exercitation quis",
};
```

```
JS
export interface ChipProps {
	onClick?: VoidFunction;
}

... [Log Snipped] ...
	... rest of code
}
```

**System**
```
Environment Info:

  System:

```

**Additional context**
My current workaround is to avoid using args for those stories:
```JS
export const Default = (): JSX.Element =>  Exercitation quis ;
```
