Title

Correct doc and usage of preservesPartitioning

Description
The name `preservesPartitioning` is ambiguous: 1) preserves the indices of partitions, 2) preserves the partitioner. The latter is correct and `preservesPartitioning` should really be called `preservesPartitioner`. Unfortunately, this is already part of the API and we cannot change. 

 We should be clear in the doc and fix wrong usages.
