Title

the query node returns to the login page after clicking on the model page

Description
Reproduction method: configure two nodes, an all/job + a query node, 

 visit the query node and click on the model page will flashback！
Discussion
- Initially localized to: 

 Individually, spring-boot-autoconfigure is downgraded to 2.6.14-2.7.11, spring-boot stays at 2.7.12, and starting KE initializes the cookieSerializer and then the AppInitializer 

         <dependency 
            <groupId>org.springframework.boot</groupId> 
            <artifactId>spring-boot-autoconfigure</artifactId> 
            <version>2.6.14</version> 
        </dependency 

 Only spring-boot-autoconfigure 2.7.12 has a problem 
   RC  

 2.7.12 entered a commit: Prevent early initialization of SessionRepository beans 

  [URL]  

 The dependencies in kylin cookieSerializer are as follows 

     

 org.springframework.boot.autoconfigure.session.SessionRepositoryFilterConfiguration.sessionRepositoryFilterRegistration(org.springframework.boot.autoconfigure.session.SessionProperties,org.springframework.session.web.http.SessionRepositoryFilter 

  So the cookieSerializer is not initialized preferentially  
   Fix Design 

 By injecting the cookieSerializer into the AppInitializer, the cookieSerializer will be initialized before the init, and the meta_url read will be the original value.
