Title

mutex for particularly likely to race relationship methods

Description
if we look at where class_mapper() with configure=False occurs:

```
$ grep -H configure=False lib/sqlalchemy/orm/*.py
lib/sqlalchemy/orm/base.py:def _inspect_mapped_class(class_, configure=False):
lib/sqlalchemy/orm/mapper.py:                self.inherits = class_mapper(self.inherits, configure=False)
lib/sqlalchemy/orm/relationships.py:            return mapperlib.class_mapper(argument, configure=False)
lib/sqlalchemy/orm/relationships.py:            self.parent.class_, configure=False

```


it's pretty easy to get a race for relationship.mapper() (or relationship.entity() in master), script below.     Other race conditions, like someone calling query(Class) while Class is still being configured, are not possible because we are calling configure() on those.

I'm not sure if this can be solved without extensive addition of locks, I thought adding it into relationship.mapper might be enough but at the moment it isn't working, test script:

```
import random
import threading
import time

from sqlalchemy import Column

        t.join()
```
