**To Reproduce**

[URL]

```python
# This crashes
from typing import Callable
Ts = TypeVarTuple("Ts")  # <- oops forgot to import TypeVarTuple
Alias = Callable[[*Ts], int]

```

And this
```python
from typing import Callable, TypeVar
T = TypeVar("T")
Alias = Callable[[*T], int]

```

And this
```python
from typing import Any, Callable
unknown: Any

```
