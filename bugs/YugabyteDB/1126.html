Discussion
- cc: @rthallamko3 @bmatican @lingamsandeep
- Analyzing a heap snapshot revealed the root cause of the high memory usage: overly large error messages generated in the `AsyncRpc::Failed` function. The large error message came from lock timeouts in `LockBatch::Init`("Failed to obtain locks until deadline +  ") after the test disabled packed rows.
