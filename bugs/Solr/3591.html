Title

Mark all Trie/LegacyNumeric based fields @deprecated in Solr7

Description
If we want to be able to remove support for legacy numerics from Solr in 8.0, we need to forbid the use of Trie*Field in indices that are created on or after 7.0. 
 
 At a minimum, we can mark them deprecated and plan to remove them in 8.0, so the usual compatibility rules will apply. 

 at a later date we can (in theory) provide a conversion tool – or convert automatically – to point fields
Discussion
- I put the blocker priority since I think it is a better experience if all 7.x indices can be used with Solr 8, but there is also the possibility of just removing Trie*Field in 8.0 and refusing to open any index that would make use of those fields, even if they were created in 7.x.
- That's a good idea. Disallow to create new indexes with trie fields. Maybe also similar stuff to prevent FieldCache usage?
