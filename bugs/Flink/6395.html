Title

Remove log-related configuration from predefined options in RocksDB state backend

Description
After   FLINK-23791  , the RocksDB log should be enabled by default. However, the log-related configuration remains in  PredefinedOptions , which will override the default value provided in  RocksDBConfigurableOptions . 
We could remove the values in  PredefinedOptions  and let  RocksDBConfigurableOptions  take control of the default value.
