Title

Some Users report seeing no results in AST Browser

Description
Martin C Martin reported that on some operating systems the Tree view of AST Browser was not showing any contents, and there were no exceptions listed.  

 He tested a solution of adding to AstBrowser.groovy:  
 jTree.showsRootHandles =true 
after the line: 
jTree.setRootVisible(false)
Discussion
- GroovyConsole AST Viewer was not displaying any tree nodes on WinXP SP3, Java 1.6.0_14b08. This fix was tested by  the user but I was not personally able to ever reproduce it.
