Title

EquivalentWithExclusions ignores all child properties when only one child property is excluded

Description
I'm so happy this feature was added, but it seems like all child properties are being ignored if only one of its properties is added to the exclusion list. I would expect the below to fail given that Shallow.Value3 is a mismatch, but it passes (same when using lambda expressions).

```
Assert.EquivalentWithExclusions(
    new DeepClass { Value0 = 21.12m, Shallow = new ShallowClass { Value1 = 42, Value2 = "Hello", Value3 = 2 } },
    new DeepClass { Value0 = 42.24m, Shallow = new ShallowClass { Value1 = 42, Value2 = "World", Value3 = 4 } },
    "Value0",
    "Shallow.Value2"
);
```

Current workaround is to ignore nested objects and verify them separately.
