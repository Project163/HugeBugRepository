Title

gui: CSRF cookie expiring can cause UI to remain out of sync but look "live"

Description
_computer A_ runs Syncthing, shares files with _device X_ and GUI listens on LAN-IP:8080

Steps
1. open web GUI on _computer A_
2. open web GUI  via LAN from _computer A_ on _computer B_
3. add files on _computer A_ and sync starts

Result
- web GUI on _computer A_ shows: active transfer rate, _device X_ with blue header - e.g. syncing (13%)
- web GUI on _computer B_ shows: active transfer rate, _device X_ with green header - up to date (100%)

Expected
- web GUI always show same status

Workaround
- reloading browser window on _computer B_, then GUI displays correct sync status / values
- only seems to happen if web GUI is accessed _before_ Syncthing on _computer A_ starts sync
Discussion
- It's updated once every 10 seconds, so inconsistencies are possible.
The fact that you had some stale data already could also be an issue, but all you need to do is refresh.
- The percentages will always differ if both devices have different contents and the index syncing is not completed.
