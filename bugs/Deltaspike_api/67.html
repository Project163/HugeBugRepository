- johndament  txs, will debug into. I know this exact use case did work in the past. If we did not find any BMI associated with the current TCCL then we a.) look up in JNDI and associate it. b.) go up the ClassLoader parent hierarchy until we find something. 

 The container thus is allowed to even add client classloaders later on.  
What you usually have when integrating OWB or Weld into Tomcat is that you use exactly the same WebAppClassLoader for boot and runtime. This is because the CDI container most time gets booted via ServletContextListener#contextInitialized. And this gets fired when the WebAppClassLoader is perfectly set up already.
- I've committed a fix for it. BMP did miss the parent lookup.
