Title

IllegalStateException for MPEG-TS when FLAG_DETECT_ACCESS_UNITS is used

Description
### [REQUIRED] Issue description

Playback of MPEG-TS fails with assertion when `FLAG_DETECT_ACCESS_UNITS` is used.
Video plays well in vlc/mplayer.

### [REQUIRED] Reproduction steps
Start demo app with provided asset and `FLAG_DETECT_ACCESS_UNITS` enabled.
* [URL]

```

... [Log Snipped] ...
```

Removing `FLAG_DETECT_ACCESS_UNITS` solves the issue.
Replacing asserts with:
```
java
private boolean isFirstVclNalUnitOfPicture(SliceHeaderData other) {
  if (this.spsData == null || other.spsData == null) {
    return true; 
    // return false;
... [Log Snipped] ...
  // SpsData spsData = Assertions.checkStateNotNull(this.spsData);
  // SpsData otherSpsData = Assertions.checkStateNotNull(other.spsData);
```
workarounds the issue. Video plays well with both (true/false) variants.
