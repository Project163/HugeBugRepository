Title

coerceStringToType conversion, convert in case of array conversion '' to ['0'=>'']

Description
### Description

The CoerceStringToType function in vendor\cakephp\cakephp\src\Controller\ControllerFactory.php [268], convert in case of string to array conversion a empty string '' to ['0' =>''].

Better is when check in type of string to array conversion if the string match '' then return []

Old:
return explode(',', $argument);

New:
return $argument === '' ? [] : explode(',', $argument);


### CakePHP Version

4.3.4

### PHP Version

8.0
Discussion
- We had a discussion about this in the dev channel and one reason to retain the existing behavior is that it replicates how PHP handles string to array conversions.

```php
$s = '';

var_dump((array)$s);
```

Will output `[0=> '']`.
