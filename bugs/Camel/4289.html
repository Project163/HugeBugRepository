 I mean this router start/run without any exception, and consume all files in input folder. 

 But shouldn't it throw "bean not found" exception when start/run?
- If you enable trace logging in camel context you will see the exception  ClassNotFoundException .  

 First the bean is looked up in the contet and if the bean is not resolved  BlueprintContainerImpl  will try to instante the bean by it's name. The  OsgiClassResolver  will try to load the the class which it will not find and hence this exeption.  

 The loading of a class sometimes is done as optional. So the log level is kept as  TRACE .
