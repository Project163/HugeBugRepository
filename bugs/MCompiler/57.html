Title

Plugin 3.0 does not compile src/main/groovy if neither src/main/java nor src/main/resources folders exist

Description
The previous version 2.5.1 compiled the project that only had groovy-sources, but after switching to version 3.0, the created jar was empty and no sources had been compiled. 

 project-layout 
pom.xml 
src 
  main 
    groovy 
       MyClass.groovy 

 After adding a dummy-file into src/main/resources, it works.

Discussion
- a bit weird issue. 
As a workaround you can add this configuration in the plugin 
  
   <build>
    <sourceDirectory>src/main/groovy</sourceDirectory>

<plugin>
...
<includes>
  <include>**/*.groovy</include>
</includes>
....
</plugin>
