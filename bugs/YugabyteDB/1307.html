Title

[YSQL] Specifying SeqScan hint disables Parallel Seq Scan

Description
Jira Link: [Link: DB-14254]
### Description

* Parallel Seq Scan stops kicking in when SeqScan hint is specified.
* On the other hand, I can get Parallel Seq Scan with`Set(enable_indexscan off)` hint or `set enable_indexscan=off;` GUC flag setting in the test case shown below.
* No problem with IndexScan and IndexOnlyScan hints.
* Reproducible on recent master ( ).
