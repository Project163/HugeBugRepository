Title

False positive for W0633 on platform.uname()

Description
Originally reported by: **Andreas Maier (BitBucket: [Link: andi0661])**

---

The following code causes pylint to incorrectly raise W0633: "Attempting to unpack a non-sequence defined at line 1126 of platform":

```
import platform
def myfunc():
    system, node, release, version, machine, processor = platform.uname()
    # The previous line raises W0633
    return system, node, release, version, machine, processor
```

The relevant code in platform.py of Python 2.6 is:

```
_uname_cache = None     # line 1126

def uname():
    global _uname_cache
    # ...
... [Log Snipped] ...
    _uname_cache = system,node,release,version,machine,processor
    return _uname_cache
```

It seems pylint goes by the initial value of _uname_cache and ignores the logic which ensures that the value is always a sequence before it is returned.

Versions: pylint 1.1.0 (with astroid 1.0.1, common 0.61.0) using Python 2.6.8

Regards,
Andy
