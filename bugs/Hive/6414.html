Title

QueryCache: Transaction lists needed for pending cache entries

Description
Hive query-cache needs a transactional list, even when the entry is pending state so that other identical queries with the same transactional state can wait for the first query to complete, instead of triggering their own instance.
Discussion
- Lookups that happen too early are triggering this NPE.
