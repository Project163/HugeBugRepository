Title

Solr throws 500 instead of 400 on some malformed requests

Description
If you submit a malformed xml document to update, Solr returns a 500 error.  Clients often treat this as a failure in the server, but it's really a 400 invalid request.  Trivial patch is attached, although there may be similar cases (i.e. malformed json) that are also worth investigating.
