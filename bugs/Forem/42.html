Title

TwitchWebhookRegistrationJobs fail when twitch_username is invalid

Description
Some of the `Streams::TwitchWebhookRegistrationJob`s fail with:
```
undefined method `first' for nil:NilClass
/app/app/services/streams/twitch_webhook/register.rb:17:in `call'
/app/app/services/streams/twitch_webhook/register.rb:12:in `call'
/app/app/jobs/streams/twitch_webhook_registration_job.rb:9:in `perform'
```
It happens when the response from the Twitch api doesn't contain `"data"`. Probably it happens when a user sets a non-existent twitch username in their profile.

Possible solution:
Check if the response from twitch API contains the required data before proceeding.
Maybe it's worth to notify the user in some way if their `twitch_username` is invalid.

I also think we only need to run the job when the `twitch_username` was updated, not every time when user updates their profile:
