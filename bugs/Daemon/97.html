Title

jsvc does not play nice with JMX

Description
Installed Commons Daemon through Ports, installed Tomcat 8.5 (uses JSVC) through Ports. 
	 Started Tomcat 
	 Launched JConsole locally to attach to VM 
 

 The VM does not display with its PID. After some search, I figured out that  com.sun.management.jmxremote  is not set, but enabled by  java(1)  since version 6. I'd expect the same behavior. After setting it, the VM is visible in JConsole, but the startup class is not visible.
Discussion
- That you need to set com.sun.management.jmxremote is not a Commons Daemon nor a Tomcat issue. You'd need to take that up with your JVM vendor. 

   

 The empty name column in jvm mode is a result of how JConsole obtains the name and Daemon starts Java. After some digging into the JRE source, it appears that setting the sun.java.command system property will cause the name column in JConsole to be populated. That should be possible to do when creating the JVM.
- The whole point is that the behavior is different to the one in java directly. I'd expect this to be as  similar as possible or properly documented.
