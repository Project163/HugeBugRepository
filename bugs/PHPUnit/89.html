Title

6.4.2 breaks tests using expectExceptionMessage that worked in 6.4.1

Description
| Q                   | A
| --------------------| ---------------
| PHPUnit version     | Upgraded from 6.4.1 to 6.4.2
| PHP version         | 7.1
| Installation Method | Composer 

The following test passes in `6.4.1`.

```php

    public function test_exception() {
        $this->expectExceptionMessage("hello");
        throw new \Exception("hello");
    }
```

It no longer passes in `6.4.2`. Running it in `6.4.2` produces the following output:

```
Testing started at 13:35 ...
PHPUnit 6.4.2 by Sebastian Bergmann and contributors.

Runtime:       PHP 7.1.8 with Xdebug 2.5.5
Configuration: /X/phpunit.xml
... [Log Snipped] ...
ERRORS!
Tests: 1, Assertions: 0, Errors: 1.
```
Discussion
- It seems like this has been an issue before that has been reintroduced:

[URL]
- A workaround is to expect an exception before expecting the exception message.

```php
public function test_exception() {
        $this->expectException(\Exception::class);
        $this->expectExceptionMessage("hello");
        throw new \Exception("hello");
}
```
