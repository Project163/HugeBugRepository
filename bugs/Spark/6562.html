Title

Check overflow in decimal UDF

Description
Udf resulting in overflowing BigDecimal currently returns null. This is inconsistent with new behavior allow option to check and throw overflow introduced in  [URL]
  
 
 import  spark.implicits._
val tenFold: java.math.BigDecimal => java.math.BigDecimal = 
  _.multiply( new  java.math.BigDecimal( "10" ))
val tenFoldUdf = udf(tenFold)
val ds = spark
  .createDataset(Seq(BigDecimal( " .123" )))
  .select(tenFoldUdf(col( "value" )))
  .as[BigDecimal]
ds.collect shouldEqual Seq( null ) 
  
 The problem is at the  CatalystTypeConverters  where  toPrecision  gets converted to null
