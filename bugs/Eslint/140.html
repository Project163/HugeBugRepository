Title

Broken getSource(node) content (shifted to 2 chars) if hashbang present.

Description
If file starts with

```
#!/usr/bin/env node
```

it's replaced with

```
//#!/usr/bin/env node
```

That breaks offset calculations for columns in some cases (when direct assess to sources used). I suggest instead of adding `//` replace first 2 chars to keep offsets intact:

```
///usr/bin/env node
```

In other case `context.getSource()` / `context.getSourceLines()` should be fixed to reflect changes.

- Can you give an example where this problem occurs?

We were touched by this bug in internal rule `indent`. But it will affect all rules, which try to analyze node source. `getSource()` without params seems to work, but `getSource(node)` will be broken if file starts with hashbang.
