Title

Unable to add S3 object metadata on uploads

Description
#### What is the problem you are having with rclone?

```
Failed to copy: s3 upload: 403 Forbidden:    AccessDenied  There were headers present in the request which were not signed  x-amz-meta-test  removed  removed  
```

CentOS 7.8, 64-bit

####  Which cloud storage system are you using? (eg Google Drive)

