Title

3.0 - Paginator dumps associations as arrays

Description
Using CakePHP 3.0.0-beta3 I noticed something in the Paginator results which I find odd.
When doing a very basic Pagination (as the bake template for controllers does):

``` php
public function index()
    {
        $this->paginate = [
            'contain' => ['ParentForums']
        ];
        $this->set('forums', $this->paginate($this->Forums));
    }
```

I noticed that the resulting `$forums` object has a `parent_forum` node, as you would expect. Although, this is an array of data, rather than an object.

[Image: image]

Any reason as of why? To me, it would seem cleaner to return that as an object as well, rather than an array.
Discussion
