Title

`:redrawstatus` Triggered by a Timer Cancels IncSearch Highlighting when `cursorline` is set

Description
### Neovim version (nvim -v)

0.8.0-dev commit  

### Vim (not Nvim) behaves the same?

yes, vim 8.1.3741. Vim has the same behavior when `laststatus` is 2.

### Operating system/version

Ubuntu 20.04 focal(on the Windows Subsystem for Linux)

### Terminal name/version

xterm 3.1

### $TERM environment variable

xterm-256color

### Installation

build from repo

### How to reproduce the issue

1. Create file `~/init.vim`
2. Write into `~/init.vim` (this is the minimal config that can reproduce the issue, notice that `cursorline` has to be set):

```vimscript
set incsearch
set cursorline
func RedrawStatus(timer)
  execute "redrawstatus"
endfunc
let timer = timer_start(1000, 'RedrawStatus', { 'repeat': -1 })
```
3. Open nvim using `nvim -u ~/init.vim`
4. In nvim open an arbitraty file, use `/` to search for a word
5. You can observe that IncSearch highlight disappears when `:redrawstatus` is fired by the timer
6. Vim have the same problem. You can verify it by using the same config file and **set `laststatus` to 2 explicitly**.


### Expected behavior

IncSearch highlighting should not disappear when `:redrawstatus` is fired.

### Actual behavior

IncSearch highlighting disappears when `:redrawstatus` is fired.
