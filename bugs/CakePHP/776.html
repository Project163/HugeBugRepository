Title

Description

- CakePHP Version: 3.2.5
- Platform and Target: Postgresql with Schemas
### What you did

Update cakephp with composer
### Expected Behavior

Update cakephp and app still working
### Actual Behavior

SQLSTATE[42P01]: Undefined table: 7 ERROR: relation "plans" does not exist

Plans is define in PlansTable as: 

```
public function initialize(array $config)
    {
        parent::initialize($config);
        $this->table('keyword_ranking.plans');
  }
```

And all works in all versions from 3.0 to 3.2.4 (not in 3.2.5 release).
