Title

Unfollowing a follower index that has had its remote cluster deleted throws 500 error

Description
Discovered via [URL] To reproduce, create a follower index, remove its remote cluster, and then try to unfollow the follower index.

```
# Delete remote
PUT _cluster/settings
{
  "persistent": {
    "cluster": {

# This will timeout
POST /my-index/_ccr/unfollow
```
