Title

eslint can't find plugins in the node search path but outside eslint's parent directory

Description
**What version of ESLint are you using?**
2.2.0

**What configuration and parser (Espree, Babel-ESLint, etc.) are you using?**
babel-eslint

**What did you do? Please include the actual source code causing the issue.**
.eslintrc:

```
{
  "parser": "babel-eslint",

  "env": {
    "node": true,
    "es6": true
  }
}
```

Take the built eslint npm artifacts and put them in one directory -- let's call that $eslint_parent.

Take the built babel-eslint npm artifacts and put them in another directory -- let's call that $babel_eslint_parent.

Create a symlink farm of node modules, call that $symlink_farm:

```
$symlink_farm
 |- eslint -> $eslint_parent/eslint
 |- babel-eslint -> $babel_eslint_parent/babel-eslint
 |- resolve -> ... # some other root
 |- ...  # other modules
```

Run this command:

```
export NODE_PATH=$symlink_farm
node $symlink_farm/eslint/bin/eslint.js  --no-ignore src/ 
```

**What did you expect to happen?**
No errors.
