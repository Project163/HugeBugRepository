Title

bazel_apple_test does not support XCode 9.0.0

Description
All tests in //src/test/shell/bazel/apple:bazel_apple_test are failing in Jenkins:
[URL]

The problem is that the only installed XCode is version 9.0.0. But bazel_apple_test has the following check at [URL]
```

```

This fails with no visible error (it's inside the subshell) beyond that the command failed.
