Title

False positive for W0105

Description
Originally reported by: **the mulhern (BitBucket: [Link: the_mulhern])**

---

Mini example:

```
#!python

class Junk(object):

    def __init__(self, priority, *args, **kwargs):
        self.priority = priority
        """a legal attribute docstring"""
```

Pylint reports:

W0105(pointless-string-statement) String statement has no effect

for """a legal attribute docstring"""

But, according to PEP 257 [URL] this line is an "attribute docstring" and therefore a legal docstring, not a pointless string statement.
