Title

Gradle build does not work when an "application.properties" exists at the root of the project

Description
### Describe the bug

I am not sure if this is supposed to be supported or not, but by mistake I created a file `application.properties` at the root of my project and the gradle build stop to work with an error:

```
FAILURE: Build failed with an exception.

* What went wrong:
Could not determine the dependencies of task ':quarkusBuild'.
```

What is wired is that the lookup inside the global `gradle` cache makes no sense at all.

  Complete stacktrace 
 
```

### Expected behavior

Not sure if a file `application.properties` at the project root is legit or not (I created it by mistake)

Failing the build because of the presence of that file is really disturbing.

### Actual behavior

Build is failing.
