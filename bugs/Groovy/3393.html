Title

Instanceof inference does not work on field assigning

Description
If instanceof inference works as expected  [URL] So probably this code should work to: 
  
 
 import  groovy.transform.CompileStatic

@CompileStatic
 class  Foo {
     Object  str =  new   Object ()
    def bar() {
        str =  "str" 
        str.toUpperCase()  // here compile error
     }
}
Discussion
- This shouldn't be expected to work since the type checker can't make any guarantees about concurrent usage of Foo objects e.g. another thread could set the 'str' field to a non-string object prior to the toUpperCase call.
