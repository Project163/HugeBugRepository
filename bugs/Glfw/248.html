Title

Fullscreen cropped when scale factor changes

Description
This is on the latest Windows 10. Probably a Windows bug that will get fixed sometime in future, but I'll just leave this here, since GLFW is affected.

1. Make sure monitor scale factor is at 100%
2. Create window in windowed mode (can use Boing example)
3. Set monitor scale factor to 125%
4. Set window mode to fullscreen (Alt+Enter for Boing)
5. Now Alt+Tab and change monitor scale factor to 100%
6. Open your window - it now doesn't cover the screen and appears cropped
