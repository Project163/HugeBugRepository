Title

Restrict possibility to create two caches with the same schema and index name

Description
It’s possible to create two different caches with the same schema and index name inside it from a client and after that get a failing of the server node during start-up with the error "Duplicate index name... " during start caches. 

 scenario: 

 start at least two server nodes 

 start client node which creates two different caches during start-up (via setting cache configs to config of client node) with the same schema name and index name, it leads to crushing the cluster 

 then try to start the cluster and get the error "Duplicate index name..."
