Title

Unnecessary message 'IPython is available, use IPython for PySparkInterpreter'

Description
When using IPython the following message is printed each and every time an IPython interpreter (%python or %pyspark) is started the first time. 
  
 IPython is available, use IPython for PySparkInterpreter 
  
 I would expect to see only a message when ipython is configured but NOT working. Of course the error case message already exists, but this positive message is kind of annoying.
