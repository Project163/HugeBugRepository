Title

Zeppelin UI fails to load page with HTTP 500 error when user tries to login from dialog box

Description
Zeppelin UI hit HTTP 500 error if user uses "login dialog box" to login as different user. 
It is reproducible using below steps: 
 
	 Login as admin user. 
	 Create a notebook called "admin_user1" 
	 set read permission = admin and write permission = admin 
	 In new window, login as hrt_1 user 
	 click on "admin_user1" notebook. On clicking this link, dialog box appears to notify that hrt_1 user do not have read/write permission. This dialog box has login button. 
	 click on login button 
	 enter admin user credentials. 
	 click on login 
 

 After logging in , Zeppelin UI fails to load page. It fails at "[URL] Host>:<Zeppelin Port>/api/login"
