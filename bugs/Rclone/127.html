Title

Files, that do not differ in size, are not synced

Description
I'm using rclone 1.34 on Microsoft Windows.  My storage provider is Yandex with Crypt on top.

Syncing works.  Except that changed files, which do not differ in size, are not picked up.  Neither by `rclone check`, nor by `rclone sync`.  It seems that modification times and checksums are ignored, and only sizes are compared.
Discussion
- try these:
```
--ignore-size                  Ignore size when skipping use mod-time or checksum.
-I, --ignore-times           Don't skip files that match size and time - transfer all files
```
- I tried `--ignore-size` and `--checksum` and both don't change anything.
`--ignore-times` syncs all files every time, which is unacceptable for me.
