Title

crash when set cmdheight if have floating window open

Description
- `nvim --version`:  v0.4.0-1424-g7e6fce069
- Operating system/version: mac os 10.13.6
- Terminal name/version:  iterm2
- `$TERM`: xterm-256color

### Steps to reproduce using `nvim -u NORC`

test.vim:

```vim
function! g:Open_float_open() abort
  let s:bufnr = nvim_create_buf(0,1)
  let s:winnr = nvim_open_win(s:bufnr, v:false, 20, 20, { 'relative': 'editor', 'row': 1, 'col': 1 })
endfunction
```

open:

```bash
nvim -u NORC test.vim
```

final:

```vim
call g:Open_float_open()
let &cmdheight=4
```

### Actual behaviour

Neovim crash `fish: 'nvim -u NORC test.vim' terminated by signal SIGSEGV (Address boundary error)`

### Expected behaviour

Neovim will not crash.
