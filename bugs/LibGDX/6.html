Title

Quaternion.setFromAxes() does not work for scaled matrices

Description
Quaternion.setFromAxes() (and therefore Quaternion.setFromMatrix() and Matrix4.getRotation()) does not produce correct results for scaled matrices. A proposed fix is to normalize all axes, although this might not be a good idea for performance reasons.
Discussion
- I think it would make sense to add a new method that explicitely normalizes the axes. I'd welcome pull requests.
