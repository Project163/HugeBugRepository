- Problem was that getCanonicalPath() needed a security permission on Windows (but not on Solaris/Linux). In addition the Derby engine had to be shut down before derby.log could be deleted on Windows. 

 This patch should fix the problem. At least it worked for me on windows, running the test standalone and as part of suites.All. Also ran the test standalone on Solaris, and it still worked as expected.
