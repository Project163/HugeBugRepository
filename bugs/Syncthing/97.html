Title

Not existing folder - crashes on startup

Description
hi!

kubuntu 14.04 64bit

/media has [drwxr-xr-x root root]
/media/USERNAME/data/\* has [drwxrwxr-x USERNAME USERNAME]

I set a repo at /media/data/folder - so I forgot to set the USERNAME-folder.
syncthing is started with USERNAME-user with upstart or manual. it immediately shuts down with:

[3455Y] 10:25:37 INFO: syncthing v0.8.21 (devel +6bdbf9086c00 Thu Jul 17 17:02:46 2014 +1000 linux-amd64 default) jb@jborg-mbp 2014-07-24 10:59:51 UTC
[3455Y] 10:25:37 INFO: My ID: xxx
[3455Y] 10:25:37 FATAL: mkdir /media/data: permission denied

it is not possible to fix it - until you restart with root. Then it creates the folders with the root user and starts up again.

In my opinion it should not mkdir, it should just show an error in the gui that the repo could not be found, so it doesn't break the application when it fails to find it in a folder where syncthing has no rights to write in. Or at least not break at mkdir.

Best regards and thanks for the great software!
