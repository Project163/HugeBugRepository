Title

TestLocalFileSystem#testListStatusWithColons cannot run on Windows

Description
HADOOP-8962   added a new test,  TestLocalFileSystem#testListStatusWithColons , covering the case of files that contain ':'.  This test cannot pass on Windows, because on Windows, the local file system does not support ':' in file names.
Discussion
- The attached patch uses JUnit  assumeTrue  to skip running the test on Windows.  Otherwise, the rest of the test suite runs successfully on Windows.
