Title

no-new description text is inaccurate/confusing

Description
Quoting the [Link: no-new description]:

This is simply untrue, more-so considering 3rd party APIs that you don't know the implementation thereof.

Consider:

``` js
function Thing() {
    if (this instanceof Thing) { /*do the awesome*/ }
    else throw new Error('Called without `new`');
}

Thing();
```

Or, a slightly less contrived example:

```
js
//
// 3rd party lib implementation
//
function Thing() {
... [Log Snipped] ...
Thing(); // throws because the `this` binding inside of the constructor
         // resolves to the global object and not an instance of Thing.
```
