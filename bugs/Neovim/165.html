Title

Sourcing of autoload file via :runtime triggers re-sourcing it when parsing function

Description
Neovim will source an autoload file twice, when using `runtime` and it parses the first function in there.

Given `t.vim`:
```vim
let &rtp = getcwd()

2verbose runtime! autoload/myplug/foo.vim
```

And `autoload/myplug/foo.vim`:
```vim
echom 'source: BEGIN'

function! myplug#foo#bar() abort
endfunction

echom 'source: END'
```

`nvim -u t.vim`:
```
Searching for "autoload/myplug/foo.vim" in "…/Vcs/neovim/t-runtime-sourced-twice"
line 3: sourcing "…/Vcs/neovim/t-runtime-sourced-twice/autoload/myplug/foo.vim"
source: BEGIN
Searching for "autoload/myplug/foo.vim" in "…/Vcs/neovim/t-runtime-sourced-twice"
line 3: sourcing "…/Vcs/neovim/t-runtime-sourced-twice/autoload/myplug/foo.vim"
... [Log Snipped] ...
finished sourcing …/Vcs/neovim/t-runtime-sourced-twice/autoload/myplug/foo.vim
continuing in …/Vcs/neovim/t-runtime-sourced-twice/t.vim
```

`vim -u t.vim`:
```
Searching for "autoload/myplug/foo.vim" in "…/Vcs/neovim/t-runtime-sourced-twice"
line 3: sourcing "…/Vcs/neovim/t-runtime-sourced-twice/autoload/myplug/foo.vim"
source: BEGIN
source: END
finished sourcing …/Vcs/neovim/t-runtime-sourced-twice/autoload/myplug/foo.vim
continuing in …/Vcs/neovim/t-runtime-sourced-twice/t.vim
```

Neovim v0.2.3-754-g4a8f08197.
Vim 8.0.1531.

This might be just some missing Vim patch after all?
