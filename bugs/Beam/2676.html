Title

Serialization of AvroCoder for dataflow workers discard reflect option

Description
AvroCoderCloudObjectTranslator   used to serialize AvroCoder to the dataflow worker does not take in account the 'useRelectApi'  AvroCoder  parameter, and will deserialize coders with default value (true). 

 The CloudObjectTranslator should propagate this setting so that the deserialized coder behaves the same way as the serialized one.
