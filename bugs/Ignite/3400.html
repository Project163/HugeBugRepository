Title

Incorrect size for switch segment record

Description
We have invariant that switch segment record should have the size of one byte. 
Although, in the current implementation, size calculation with overhard for storing CRC and WAL pointer. 

 In current implementation, we can suddenly stop WAL iteration which may result in random data store corruptions or missing updates on node recovery.
