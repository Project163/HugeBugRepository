Title

Unnecessary ParadoxicalCondition with repeated assignments in conditional

Description
With this not-so-great code:

```php
if ($a = rand(0, 1)) {} elseif ($a = rand(0, 1)) {}
```

[URL]

Alternative 

```php
$a = rand(0, 1);
if ($a) {
} else {
  $a = rand(0, 1);
  if ($a) {}
}
```

is fine
