Title

JUnit Jupiter Assumptions do not work in @BeforeAll methods

Description
* JUnit version: 5.1.0
* JUnit platform version: 1.1.0

The following test will fail with a `TestAbortedException`:

```
java
public class AssumptionTestJUnit5 {

    @BeforeAll
    static void setup() {
... [Log Snipped] ...
    }
}
```

I would expect that a failed assumption in the setup method would simply skip the tests instead of triggering a test failure.

The following JUnit4 test (run against the JUnit4 test runner) matches my expectations; it skips the tests instead of reporting a failure:

```
java
public class AssumptionTestJUnit4 {

    @BeforeClass
    public static void setup() {
... [Log Snipped] ...
    }
}
```
Discussion
- Thanks for bringing this to our attention!

I have confirmed that this is in fact a _bug_.

Specifically, it's a bug in the internals of the `HierarchicalTestEngine`, and the bug exists currently on the `master` branch.

Note that executing the example `AssumptionTestJUnit4` test class on the JUnit Platform via the `VintageTestEngine` also results in a failure instead of the test class being skipped.
- I believe the _fix_ for this bug must go into `org.junit.platform.engine.support.hierarchical.NodeTestTask.executeRecursively()` (on `master`).
