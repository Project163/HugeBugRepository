Title

Fixtures example should specify the port to avoid ConnectionRefusedError

Description
Running the example code in [URL]

```
python
import pytest

@pytest.fixture
def smtp():
... [Log Snipped] ...
    assert response == 250
    assert 0 # for demo purposes
```

Doesn't raise an AssertionError, but instead ConnectionRefusedError during the setup.  Changing the one line to use port 587 fixes this.

```python
    return smtplib.SMTP("smtp.gmail.com", 587)
```

This is with pytest 3.1.1 on Mac OS X 10.12.5.
