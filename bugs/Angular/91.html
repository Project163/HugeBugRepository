Title

fix(router): linking to redirects

Description
In the below example, the link from the parent to the grandchild would not work:

```
@View({
  template: ` link to default child `
})
@RouteConfig([
  { path: '/child/...', component: ChildCmp, as: 'child' }
... [Log Snipped] ...
class ChildCmp {
}
```

A way to provide defaults for params might cover this use case:

```
@View({
  template: ` link to default child `
})
@RouteConfig([
  { path: '/child/...', component: ChildCmp, as: 'child' }
... [Log Snipped] ...
class ChildCmp {
}
```

Alternatively, we could mark certain child routes as "default", so this would work:

```
@View({
  template: ` link to default child `
})
@RouteConfig([
  { path: '/child/...', component: ChildCmp, as: 'child' }
... [Log Snipped] ...
class ChildCmp {
}
```
Discussion
- tracks internal bug: b/22617861
- @IgorMinar @matsko I'd like your help designing this.
- I'm still trying to design a good design for this; it's tricky because you can't easily work backwards from an arbitrary partial URL to a set of components to properly generate the instruction.

For now, I have a solution that only handles the case where you have a link like this:

```
@RouteConfig([
  new Redirect({path: '/', redirectTo: '/second'}),
  new Route({path: '/second', component: DummyCmpB, as: 'secondCmp'})
])
class ParentRedirectCmp {
... [Log Snipped] ...
class AppCmp {
}
```

So if you redirect from a child to another route within that child, everything works just fine.

But trying to deeplink a redirect from parent into a deep hierarchy will not work.
