### Describe the Bug

[Link: CSS Cascade Layers] are an exciting feature in CSS with [Link: strong browser support]. An example use case would be to make sure that utility classes could always override component styles, or that local styles could override imported shared company-wide styles to allow modifications on a per-app basis.

The [Link: order that the browser discovers layers is very important]. Users of CSS cascade layers and Next.js need a way to define their layers before any other CSS is encountered by the browser, or else the order of the layers that the browser picks may not be what the developer wanted. 

This seems difficult at the moment as layout CSS appears in the DOM after per-page or per-component styles:

[Image: image]

## Workarounds
