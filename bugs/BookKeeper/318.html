Title

bookkeeper script should fall back to java in path if JAVA_HOME is not set

Description
The current behaviour requires JAVA_HOME to be set, which isn't set by default on all machines. So machines on which bookkeeper ran fine, no longer work. 

 Solution is to fallback to java in path is JAVA_HOME not set.
Discussion
- Falls back to PATH if JAVA_HOME not set. I also moved the java check to after the sourcing of bkenv.sh so that JAVA_HOME can be set there if needed.
