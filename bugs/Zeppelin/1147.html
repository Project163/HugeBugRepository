Title

Zeppelin FlinkInterpreterLauncher not work in Zeppelin cluster mode

Description
When using Zeppelin in cluster mode, I found FLINK_CONF_DIR , FLINK_LIB_DIR and FLINK_PLUGINS_DIR are not correct, it leads to some exceptions when submitting the Flink SQL job on Yarn. I guess FlinkInterpreterLauncher is not working in Zeppelin cluster mode. 

 I must set FLINK_CONF_DIR/FLINK_LIB_DIR/FLINK_PLUGINS_DIR for the flink interpreter, then everything is right.
