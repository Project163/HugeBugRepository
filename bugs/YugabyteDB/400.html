Title

[YCQL] Server crashes when processing ORDER BY with invalid column name.

Description
Test case:
- Create table with range column j->>'x'
- Query table order by wrong column name j->>'y'

Create table and index
```
cqlsh:test> create table tab(i int, j jsonb, k int, primary key (i, k)) with transactions = { 'enabled' : true };
cqlsh:test> create index tab_idx on tab(k, j->>'x');
```

CORRECT name (j->>'x') works while INCORRECT name (j->>'y') crashes
```
cqlsh:test> select * from tab where k = 1 order by j->>'x';
 i | k | j
---+---+---
(0 rows)
cqlsh:test> 
cqlsh:test> select * from tab where k = 1 order by j->>'y';
NoHostAvailable: 
```
