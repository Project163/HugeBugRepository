Title

Order of records is not ensured in delete delta files when reduce deduplication is off

Description
When  
  
 
set hive.optimize.reducededuplication= false ;
 
  
 Reduce sink operators in delete statements are not merged. Delete delta files must be sorted by RowID and this is ensured by the parent Reduce sink operators. In this case the child Reduce sink operator has only partition key column:  UDFToInteger(_col0)  and sort order may broken and invalid delete delta files are written. 

  Reduce Output Operators  in  Map 1  has sort keys defined (RowId) but the one in  Reducer 2  has only Map-reduce partition columns.
