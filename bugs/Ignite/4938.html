Discussion
- The issue is caused by the race during processing of near atomic update request and concurrent client PME. 

 If the request is validated during active client PME, updateAllAsyncInternal0 can be called recursively and re-acquires entry locks, causing unlockEntry not actually release locks and triggering assertion. 

 The fix is to remove extra server side validation, because it’s already performed in GridNearAtomicAbstractUpdateFuture.
