Title

`lines-around-comment` causes crash with some constructs

Description
In the `lines-around-comment` rule, the following will make ESLint crash:

``` js
var a,
// line
b;
```

using

``` js
{
  "allowBlockStart": true,
  "beforeLineComment": true
}
```

or

``` js
{
  "allowBlockStart": true,
  "beforeLineComment": true
}
```
