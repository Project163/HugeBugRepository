Title

Serialization bug in PagedRangeCommand

Description

    
Discussion

    
- There is a typo in the serialization of PagedRangeCommand so that if it has index expressions, it serializes their value with a 4-bytes length but read them with short 2-bytes length. In practice, this ends up breaking the underlying connection and results in query timeouts as described in  this thread . 

 Patch attached. The patch also fixes a few problem in the serializedSize() method (though I don't think it's used in practice).
