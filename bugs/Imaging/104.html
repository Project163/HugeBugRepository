Title

Failure when reading a partial raster from a floating-point TIFF

Description
When reading a partial raster from a floating-point TIFF file that uses a tiled format, the read will fail if the starting position is beyond the first row of tiles.  The result will be a raster subset filled with zero values.
Discussion
- This glitch is now fixed in the Github repository, and will be included in the next release (Alpha-3).
- Apache Commons Imaging 1.0-alpha3 has been released.
