Title

[ES|QL] TS Command: mv_expand followed by stats when getting from multiple indices causes unexpected partial results

Description
Example query:
```
ts k8s-downsa*,k8s
| mv_expand `client.ip` 
| stats  GIndJeyVxxBh = count(rate(network.total_bytes_in)) by event_log, UXhUADzsJqyi = bucket(@timestamp,1hour)
;
```
