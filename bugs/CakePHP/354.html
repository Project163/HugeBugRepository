Title

Issue with Vendor/bin/cake.bat when installing with Composer on Windows

Description
When installing CakePHP 2.4.1 via Composer on a Windows machine, the Vendor/bin/cake.bat attempts to use bash. Whilst handy for those using Git for Windows, and running from a bash shell, bash doesn't exist in a Windows environment by default.

I'm assuming the .bat commands are there for the benefit of developers using Windows.

If bash was replaced with cmd /C, this would work for Windows environments.

In a possibly related note, when doing the install via composer, a note is given about skipping the installation of bin/cake.bat for package pear-pear.cakephp.org/cakephp. Here is the transcript:

```
C:\\>php composer.phar install
Loading composer repositories with package information
Initializing PEAR repository [URL]
Installing dependencies (including require-dev)
  - Installing pear-pear.cakephp.org/cakephp (2.4.1)
... [Log Snipped] ...
Writing lock file
Generating autoload files
```

I couldn't see a repository that stored the Vendor/bin/cake.bat file, so I've logged the issue here, anyway.
Discussion
- Interesting, I've never tried to install our pear packages on windows. I suspect the issue is there and not related to composer based installation. Have you ever had success installing CakePHP with the pear installer?
- I just tried it with PHP 5.4.20, and a fresh installation of pear.  Seemed to go okay, except I had to remember to start a new command shell between installing pear, and attempting to install cakephp.

The cake.bat in the php5.4.20 directory from a pear install is a match for the Vendor/pear-pear.cakephp.org/CakePHP/bin/cake.bat, which just calls php, and does not have an issue.

There does not seem to be a match for the Vendor/bin/cake.bat that seems to be generated from the initial "php composer.phar install" command.

Perhaps Vendor/bin/cake.bat is auto generated from Composer, because it has no headings. In fact, here's the contents, just in case you might recognise them somewhere else.

```
@echo off
pushd .
cd %~dp0
cd "../pear-pear.cakephp.org/CakePHP/bin"
set BIN_TARGET=%CD%\cake
popd
cmd /C "%BIN_TARGET%" %*
```

I've altered the last line from bash to cmd /C
