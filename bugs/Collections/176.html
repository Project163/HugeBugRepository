- Hi  Guoping  

 >Can the checkstyle NewlineAtEndOfFile be warning not error ? 
>I don't think the checkstyle would affect the used with the software. 

 I think if this is changed to a warning, it might be ignored. The reason for having these checks enabled in the CI is exactly to alert us to fix. Preferably before merging pull requests. But eventually broken builds get merged and master may be broken for a while (which is not a huge problem IMO). 

 So if disabled, eventually we would get other PR's to fix the missing newline at end of file. I think it's better to ask the PR creator to fix that, instead of needing an extra PR from another contributor or developer. 

 I've fixed it locally by adding the newline, and then running each file through `dos2unix $FILE_NAME`. Creating PR now. 

 Thanks! 

 Bruno
