Title

AttributeError with abstract property setter and "# type: ignore"

Description
I noticed the following change in behavior after upgrading to `0.511`  from `0.501`.

Using the following minimal example
```
$ cat abstractproperty.py |nl -b a
     1	from abc import ABC
     2	from abc import abstractmethod
     3	from typing import List
     4
... [Log Snipped] ...
    14	    def foo(self, value: List) -> None:
    15	        """Setter"""
```
the new version of mypy gives the following error
```$ mypy abstractproperty.py                                                                                                                                                              
abstractproperty.py:14: error: Function is missing a type annotation for one or more arguments
```
While the error itself is a bit unclear in terms of what exactly is missing the type annotation, attempting to ignore line 14 with a `# type: ignore` comment 
```
python
from abc import ABC
from abc import abstractmethod
from typing import List

... [Log Snipped] ...
    def foo(self, value: List) -> None:  # type: ignore
        """Setter"""
```
results in an `AttributeError`
```
Traceback (most recent call last):
  File ".../bin/mypy", line 6, in  
    main(__file__)
  File ".../lib/python3.5/site-packages/mypy/main.py", line 46, in main
    res = type_check_only(sources, bin_dir, options)
... [Log Snipped] ...
    'fallback': self.fallback.serialize(),
AttributeError: 'NoneType' object has no attribute 'serialize'
```
My `mypy.ini` has the following
```
ini
[mypy]
disallow_subclassing_any = false
disallow_untyped_defs = true
follow_imports = skip
... [Log Snipped] ...
warn_redundant_casts = true
warn_unused_ignores = true
```
