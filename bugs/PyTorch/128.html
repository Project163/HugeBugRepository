Title

Segmentation Fault in `torch._C._nn.replication_pad2d` with Incorrect Inputs

Description
### 🐛 Describe the bug

Using `torch._C._nn.replication_pad2d` with an empty padding list leads to a segmentation fault. 
This is a fuzzed test input.

## Error log

```bash
Segmentation fault (core dumped)
```

## Minimied repro
```python
import torch
torch._C._nn.replication_pad2d(torch.rand([2]), padding=[])
```
