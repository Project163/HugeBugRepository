Title

Quarkus Hibernate ORM - Jboss logger instantiation issue

Description
### Describe the bug

We are using Hibernate ORM with JBOSS Logmanager - in Quarkus 3.17.7 - with JDK 17 and by startup of the application we get the following error:

```
java.lang.IllegalArgumentException: The given lookup does not have access to the implementation class constructor
	at org.jboss.logging.Logger.doGetMessageLogger(Logger.java:2641)
	at org.jboss.logging.Logger.getMessageLogger(Logger.java:2570)
	at org.jboss.logging.Logger.getMessageLogger(Logger.java:2552)
	at io.quarkus.hibernate.orm.runtime.migration.MultiTenancyStrategy. (MultiTenancyStrategy.java:38)
```

Please see the JBOSS Logging code for the error [Link: here]

**Workaround for the problem:**

Disabling the hibernate logging and excluding the Jboss dependency from hibernate temporary fixes the issue, but this can't be a longterm solution:

`quarkus.log.category."org.hibernate".level=OFF`
