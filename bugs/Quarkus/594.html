Title

Quarkus master can't handle space in path for native mode, 1.4.1.Final can

Description
Quarkus master can't handle space in path for native mode, 1.4.1.Final can handle space in path

Build generates native app but it is not working and immediatelly ends with exit code 1.

Reproducer:
```
bash
rm -rf directory\ with\ spaces
mkdir directory\ with\ spaces
cd directory\ with\ spaces
mvn io.quarkus:quarkus-maven-plugin:999-SNAPSHOT:create \
... [Log Snipped] ...
mvn clean verify -Dnative  #FAIL
mvn clean verify -Dnative -Dquarkus.platform.version=1.4.1.Final -Dquarkus-plugin.version=1.4.1.Final # OK
```
