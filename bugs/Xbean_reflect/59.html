Title

trunk does not build due to unused import

Description
Attempting to build the trunk version (4.19-SNAPSHOT) under Linux with OpenJDK 8 and maven 3.0.5 fails with the following error message: 
  
 
[ERROR] Failed to execute goal org.apache.maven.plugins:maven-compiler-plugin:3.8.1:compile ( default -compile) on project xbean-reflect: Compilation failure
[ERROR] /trunk/xbean-reflect/src/main/java/org/apache/xbean/propertyeditor/PropertyEditors.java:[22,42]  package  com.sun.org.apache.regexp.internal does not exist
 
  

 The cause of this failure is a missing (and actually unused) import in PropertyEditors.java. This can be simply removed which will make the build succeed as in: 
  0001-Remove-unused-import.patch      .
