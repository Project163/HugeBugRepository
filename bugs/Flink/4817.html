 The above fix is incomplete. Because class  SqlTableRef  is not copied to legacy planner, once both planner jars are in the lib directory, and the classloader loads the classes in legacy planner first (the class  SqlTableRef  in Calcite will be loaded, which is unexpected), the exception will occur.  
The solution is: copy  SqlTableRef  class in blink planner to legacy planner.
