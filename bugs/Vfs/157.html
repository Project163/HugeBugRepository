Title

[HTTP] File can't be read if HEAD method is not supported (405 status)

Description
[URL]
(try to read by VFS) 

 If HEAD method is not supported, server returns 405 status, which is not recognized as correct one by HttpObject class. 

 10.4.6 405 Method Not Allowed 
The method specified in the Request-Line is not allowed for the resource identified by the Request-URI. The response MUST include an Allow header containing a list of valid methods for the requested resource.  

 Thus, resource DOES exist. Patch included.
