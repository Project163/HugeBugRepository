Title

Task can be stuck in deploying state forever when canceling job/failover

Description
We observed that task can be stuck in deploying state forever when the task loading/instantiating logic has some issues. Cancelling the job / failover caused by failures of other tasks will also get stuck as the cancel watch dog won't work for tasks in CREATED/DEPLOYING state at present. We should make cancel watch dog cover tasks in DEPLOYING as well (no need for tasks in CREATED state has there is no real logic between  CREATED->DEPLOYING).
