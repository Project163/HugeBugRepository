Title

AudioBundle with PlaybackSettings::Despawn leaves trash entities if Parented to something

Description
## Bevy version
0.13

## Relevant system information
`cargo 1.77.0-nightly (1ae631085 2024-01-17)`

`AdapterInfo { name: "Apple M1 Pro", vendor: 0, device: 0, device_type: IntegratedGpu, driver: "", driver_info: "", backend: Metal }`

## What you did
Spawned an audio bundle and parented it to an entity.

```rust
        // Audio
        commands.entity(audio_effects_parent).with_children(|child_builder| {
            child_builder.spawn(AudioBundle {
                source: Firearm::Ak105.get_audio_source(&game_assets, &FirearmAudio::Shoting(FirearmAudioShotType::CloseOutdoors)),
                settings: PlaybackSettings::DESPAWN.with_spatial(true),
            }).insert(TransformBundle::from_transform(bullet_fired_event.global_transform.compute_transform()));
        });
```

## What went wrong
"Entity 123 inexistent" being left inside of the parent. 
[Image: Screenshot 2024-03-10 at 11 31 04 AM]

I could easily just add a timer on any audiobundle to remove them when their time is up. So this isn't really the biggest priority.
