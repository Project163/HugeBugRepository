Title

CI_Email: Garbled non-ascii strings with spaces in email header when MB library is enabled

Description
Input "From": `Orange portál`

Output of [Link: mb_encode_mimeheader]: `Orange =?UTF-8?Q?port=C3=83=C2=A1l?=`
Shown in e-mail client as: `Orange portÃ¡l`

If MB_ENABLED !== TRUE && ICONV_ENABLED === TRUE:
Output of [Link: iconv]: `=?UTF-8?Q?Orange=20port=C3=A1l?=`
Shown in e-mail client as: `Orange portál`

So, from this I can see that I guess the problem is that UTF-8 string is not at the beginning. So I tried to remove the space from input and it was fine then:

Input "From": `Orange_portál`
Output of [Link: mb_encode_mimeheader]: `=?UTF-8?Q?Orange=5Fport=C3=83=C2=A1l?=`
Shown in e-mail client as: `Orange_portál`

This problem occurs in both "From" and "Subject" headers.

Swiftmailer handles this correctly.
