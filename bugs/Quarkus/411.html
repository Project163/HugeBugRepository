Title

Raise more meaningful exception when referencing non-existent type in Qute template

Description
I have a type `com.example.Item` but accidentially referred to it using a different name in a Qute template: `{@org.acme.Item item}`. There should be a clear error message indicating that `org.acme.Item` doesn't exist, instead I'm getting this stacktrace which isn't very helpful:

