Title

Checkstyle-2.2-SNAPSHOT not working with Maven 2.0.9

Description
The changes in Maven 2.0.9 is causing the plugin to use commons-collection 2.0 instead of 2.1 required by checkstyle. Forcing the commons-collection version 2.1 in the plugin config fixes this issue.
