Title

`q:` does not clear pending character buffer

Description
### Problem

`q:` does not clear the `:` from the pending character buffer. A operation resulting in operator pending (like `"`) results in `:"` showed as pending while only `"` is actually pending

### Steps to reproduce

1. `nvim --clean`
1. Press `q`, `:`, `"` which results in `:q` in the preview while only `"` is actually pending (register selection)

### Expected behavior

It should reset the buffer and only show the actually pending characters
i.e. for `q`, `:`, `"` it should be just `"`

### Nvim version (nvim -v)

NVIM v0.11.3

### Vim (not Nvim) behaves the same?

yes, but still a bug (9.1.2024)

### Operating system/version

NixOS 25.05

### Terminal name/version

Kitty

### $TERM environment variable

xterm-kitty

### Installation

sligthly outdated nixpkgs version
