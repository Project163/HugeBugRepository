Title

DragValue max_decimals not working on master

Description
**Describe the bug**
Max decimals for drag value seems to not be working on master? Maxes out at 2-4 seemingly random.
[Image: drag_value_max_decimals]

**To Reproduce**
Steps to reproduce the behavior:
1. Change the hello_world example to use:
    ``` rust
    ui.add(
        egui::DragValue::new(&mut self.height)
            .min_decimals(1)
            .max_decimals(10),
    );
    ```
2. Add a height f32 to the `MyApp` struct.
3. Try to enter a value with 10 decimals
4. Observe that you cannot get past 2-4 decimal places.

**Expected behavior**
It should allow you to enter more decimal places like it did in 0.19.0

**Desktop (please complete the following information):**
 - OS: Windows
 - Version: 11 22H2 22621.819

**Additional context**
Might be related to the recent change to dragvalue in   which will be greatly appreciated and is the reason I tried out master, but for my application I'll need to be able to enter higher precision values sometimes.
