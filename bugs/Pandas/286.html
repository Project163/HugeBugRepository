Title

A bug in HDFStore with MultiIndex

Description
``` python
randn = np.random.randn
from pandas import *
index = MultiIndex.from_tuples([('a', 0), ('b', 'y')])
df = DataFrame(randn(3, 2), columns=index)
store = HDFStore('/tmp/testpandas.hdf5')
store['multi'] = df
```

raises `ValueError: invalid literal for long() with base 10: 'y'`
Discussion
- This is a bug in HDFStore which assumes that Index is homogeneous in dtype and only checks the first element as the dtype.  I just put in a fix for this.

randn = np.random.randn
from pandas import *
index = MultiIndex.from_tuples([('a', 0), ('b', 'y')])
df = DataFrame(randn(3, 2), columns=index)
store = HDFStore('/tmp/testpandas.hdf5')
store['multi'] = df
