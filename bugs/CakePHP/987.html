Title

Let Cake\Database\Type::buildAll also return types added with Type::set

Description
This is a (multiple allowed):

* [x] bug

* CakePHP Version: 3.7.5
* Platform and Target: not relevant for this issue

### What you did
I register a type with
```php
Type::set('somename', $someInstance);
```

Note that I can't use `Type::map` because I want an *instance*, because I have things configured on it that are needed when converting data to/from the database.

### What happened
My fields are not correctly converted from the database to PHP and vice versa.

### What you expected to happen
I would expect that my data would get correctly converted using the type.

### Further info
After some debugging and digging, I found out that if I change `Type::buildAll()` to return `static::$_builtTypes` instead of `$result` all works well, because any types that are set using `Type::set` will then be returned.
I am not sure if this is indeed the best fix, but it seems logical to me. Either that or `Type::set` should be changed/removed.

p.s. the documentation of `Type::set` also seems confusing to me.
