Title

handleError and handleFatalError log the same error twice

Description
I've noticed that handleError and handleFatalError will log the same error twice, with the default configuration of `Monolog\ErrorHandler::register()`. Here's a simple example:
## Code

```
require_once('vendor/autoload.php');

$logger = new Monolog\Logger('test');
$logger->pushHandler(new Monolog\Handler\StreamHandler(STDOUT, Monolog\Logger::DEBUG));

Monolog\ErrorHandler::register($logger);
user_error('test', E_USER_ERROR);
```
## Output

```
[2015-08-05 11:31:02] test.ERROR: E_USER_ERROR: test {"code":256,"message":"test","file":"/Users/sminnee/Sites/ss4/test.php","line":9} []
PHP Fatal error:  test in /Users/sminnee/Sites/ss4/test.php on line 9
PHP Stack trace:
PHP   1. {main}() /Users/sminnee/Sites/ss4/test.php:0
PHP   2. user_error() /Users/sminnee/Sites/ss4/test.php:9
... [Log Snipped] ...

[2015-08-05 11:31:02] test.ALERT: Fatal Error (E_USER_ERROR): test {"code":256,"message":"test","file":"/Users/sminnee/Sites/ss4/test.php","line":9} []
```
