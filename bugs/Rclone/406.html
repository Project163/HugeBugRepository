Title

Issues when excluding permission denied directories

Description
I'm running rclone on Android7 with Termux. I'm trying to copy the SD mountpoint over a Google Team Drive, but i'm getting permission denied errors because of the .android_secure folder: 

`2019-05-09 17:26:47 ERROR : Attempt 1/3 failed with 1 errors and: failed to read directory "": lstat /storage/SD/.android_secure: permission denied`

Excluding the folder (`--exclude /.android_secure/**`) doesn't change anything. It seems there is no way to skip this folder, and after 3 retries rclone quits.

```
rclone v1.47.0
- os/arch: android/arm64
- go version: go1.12.2
Android 7, ARMv8-A 64-bit
```
Any way I could skip folders that give permission denied errors?
Discussion
- Unfortunately the filtering works at a layer above the local backend which is where the error is generated...

I haven't figured out a sensible workaround for that.  To fix properly I need the local backend to read the flters and ignore errors for files/directories which are excluded.

A workaround might be to introduce a new flag which causes the local backend to ignore errors.  There is one already `--skip-links` for symlinks, maybe we need `--ignore-permissions-errors` or something like that.
- A `--ignore-permissions-errors` flag would be perfect, since there is no way to keep rclone from stopping when this type of errors happen. Playing with `--retries ` and  `--retries-sleep` doesn't work either since it keeps hanging on that one first directory and doesn't continue.
