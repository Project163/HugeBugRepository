Title

SSL: Missing HTTPS protocol when building in Native

Description
## Describe the bug

According to the guide `[URL] for native, the next SSL configuration needs to be set:

```
-H:EnableURLProtocols=http,https --enable-all-security-services -H:+JNI
```

The problem is that these properties are not being set by default:
- Creating a new app using Maven command line:

```
mvn io.quarkus:quarkus-maven-plugin:1.13.2.Final:create \
    -DprojectGroupId=org.acme \
    -DprojectArtifactId=rest-json-quickstart \
    -DclassName="org.acme.rest.json.FruitResource" \
    -Dpath="/fruits" \
    -Dextensions="resteasy,resteasy-jackson"
cd rest-json-quickstart
```

Adding the `server.keystore` into `src/main/resources/META-INF/resources`.
Having the properties:

```
quarkus.http.ssl.certificate.key-store-file=META-INF/resources/server.keystore
quarkus.http.ssl.certificate.key-store-password=password
```

It seems that I need to provide also the following property:

```
quarkus.ssl.native=true
```

And also I think the guide should say that the ssl certificates should be under the `src/main/resources/META-INF/resources` folder.
