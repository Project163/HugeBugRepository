no-var should not fix variables named 'let'

Description

* **ESLint Version:** 5.16.0
* **Node Version:** 10.16.0
* **npm Version:** 6.9.0

**What parser (default, Babel-ESLint, etc.) are you using?**

 Configuration 

 
```

  parserOptions: {
    ecmaVersion: 6,
  },
... [Log Snipped] ...
  }

```

 

**What did you do? Please include the actual source code causing the issue, as well as the command that you used to run ESLint.**

 
```
js
// this is valid code in non-strict mode

function foo() {
  var let;
... [Log Snipped] ...
  var { let } = {};
}
```

 
```bash
eslint index.js --fix
```

**What did you expect to happen?**

No autofix, because it produces SyntaxError.

**What actually happened? Please include the actual, raw output from ESLint.**

```js
function foo() {
  let let; // SyntaxError
}

function bar() {
  let { let } = {}; // SyntaxError
}
```

Off topic: ESLint parser doesn't treat `let { let } = {}` as SyntaxError (probably an Acorn bug)
