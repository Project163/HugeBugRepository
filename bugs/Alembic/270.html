Title

type error in env.py from documentation

Description
When using the examples in the documentation for env.py, there is a type error:

```
alembic/env.py:53:13: error: Argument 1 to "engine_from_config" has
incompatible type "Optional[Dict[str, str]]"; expected "Dict[str, Any]" 
[arg-type]
                config.get_section(config.config_ini_section),
                ^~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
```

Seems that there should be a check for `None` in these examples, or `engine_from_config()` should accept a `None` value.
