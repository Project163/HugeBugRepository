Title

Simple Syncthing invocations take a long time to run

Description
running simple info commands takes a long time.



root@openwrt:/mnt/bin/syncthing-linux-mips-v1.1.1-rc.2# time ./syncthing --version
syncthing v1.1.1-rc.2 "Erbium Earthworm" (go1.12.1 linux-mips) teamcity@build.syncthing.net 2019-03-25 11:43:21 UTC
real    0m **31.01s**
user    0m 12.05s
sys     0m 2.68s

root@openwrt:/mnt/bin/syncthing-linux-mips-v1.1.1-rc.2# time ./syncthing --help > /dev/null
real    0m **27.99s**
user    0m 11.92s
sys     0m 3.02s
