Title

to_tsvector regconfig does not work with psycopg3

Description
### Describe the bug

I am not able to specify language configuration when using PostgreSQL full-text search functions (`to_tsvector`, `websearch_to_tsvector`, `plainto_tsvector`) with psycopg3. The cause appears to be sqlalchemy casting the configuration string to `VARCHAR`.

The example is adapted from the tutorial and works as intended with psycopg2 (so does omitting language configuration in psycopg3).

### To Reproduce

```
python
import sqlalchemy as sa

url = "postgresql+psycopg://postgres:pgpass@localhost:5432/mydb?sslmode=require"
engine = sa.create_engine(url, echo=True)
... [Log Snipped] ...

t.drop(engine, checkfirst=True)
```
