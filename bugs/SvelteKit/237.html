Title

Trailing slash redirect does not work for prerendered pages

Description
### Describe the bug

After building the app, trailing slash redirects do not work for prerendered routes, returning a 404 instead.

This is because the @sveltejs/kit `server.respond` looks up the SSR manifest first, but cannot find the prerendered route, as they were removed from it in [URL]

[URL]

### Reproduction

[URL]

1. Run `pnpm build && pnpm preview`
2. Navigate to `/test/` and refresh the page.

#### Expected
Redirect from `/test/` to `/test`.

#### Actual
404 not found.
