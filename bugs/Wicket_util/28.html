Title

Remove usage of System.gc() in Wicket code

Description
org.apache.wicket.util.file.Files.remove(File) calls System.gc() when a file cannot be removed for any reason. 
This call popped up in our performance tests. 

 I suggest to try to delete the file at most N times and if it still not deleted then log a warning and schedule it for deletion when the JVM exists (java.io.File.deleteOnExit())
Discussion
- Files.remove() was the only place where System.gc() has been used.
