Title

[YSQL] Data modifying statements in CTE fails for temporary tables

Description
Jira Link: [Link: DB-2405]
Creating a CTE with data modifying statement on a temporary table fails as shown below. Similar behavior is observed for UPDATE/DELETE as well (Below example demonstrates the behavior for INSERT).
```
CREATE TEMPORARY TABLE y (a int);
WITH t AS (
    INSERT INTO y
    VALUES
        (11),
... [Log Snipped] ...
)
SELECT * FROM t ORDER BY a;
```
An assertion fires for the above query:
```
ts1|pid90242|:31982|[URL] TRAP: FailedAssertion("!(!((allPgXact[proc->pgprocno].xid) != ((TransactionId) 0)))", File: "../../../../../../../src/postgres/src/backend/storage/ipc/procarray.c", Line: 438)
```

However, if the above temporary table is replaced by a normal persistent table, everything works as expected for INSERT, UPDATE and DELETE.
