Title

TYPE_CHECKING-only `Final`-annotated nested `always-true/false` flags crashes with conditional type aliases

Description
**Crash Report & To Reproduce**

See [Link: mypy Playground] (reproduces on both 1.15 and 1.16).

The motivation in this snippet is to avoid runtime imports from `typing`.

```
python
# mypy: always-false=INTERNAL_DEVELOPMENT_FLAG

TYPE_CHECKING: Final = False
INTERNAL_DEVELOPMENT_FLAG: Final = False
... [Log Snipped] ...

class MyClass(tuple["T1", "T2"]): ...
```

The crash seems to be avoidable if the flags aren't annotated with `Final`, or the `typing.*` imports aren't under one of the flags.

**Traceback**

- Mypy configuration options from `mypy.ini` (and other config files): None
- Python version used: 3.9, 3.12
