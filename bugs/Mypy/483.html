Title

Fix definition of abs to not use overloading

Description
Currently the definition of abs in builtins uses overloading, even though we should be able to just use SupportsAbs if int and float would subclass it.

This would fix type checking issue with int arguments. For example, this does not generate a type check error:

```
abs(1) + 'x'
```
