Title

Gradle doesn't work if using JDK 11

Description
**Describe the bug**

When calling `./gradlew build` having `JDK11`, you get that:
```
com.oracle.svm.core.util.UserError$UserException: Class initialization of io.quarkus.runner.ApplicationImpl6 failed. Use the option --initialize-at-run-time=io.quarkus.runner.ApplicationImpl6 to explicitly request delayed initialization of this class.
Detailed message:

        at com.oracle.svm.core.util.UserError.abort(UserError.java:75)
        at com.oracle.svm.hosted.FallbackFeature.reportAsFallback(FallbackFeature.java:223)
... [Log Snipped] ...
        at io.quarkus.runner.ApplicationImpl6. (ApplicationImpl6.zig:106)
        ... 34 more
```

We fixed it using (but it needs further tests with Kotlin and Scala):
```
java {
    sourceCompatibility = JavaVersion.VERSION_1_8
    targetCompatibility = JavaVersion.VERSION_1_8
}
```
