Title

Accept header is not compliant with IETF RFC-7231

Description
When the "Accept" http header is sent to remote system it can contain a "charset=<charset>" statement.  According to RFC 7231 this should be in an "accept-charset" header.  See  [URL]   [URL]
This format is acceptable in a "content-type" response header.
