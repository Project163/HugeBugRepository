Title

Cannot parse CSV record starting with separator character

Description
Camel Bindy is not able to parse a CSV file where one value starts with a separator character. Example of such a record: 

  
  'text1' , ',text2' ,3
 
  

 And the Java class used: 

   Bar.java   
 @CsvRecord(separator =  "," , quote =  "'" )
 public   class  Record {

    @DataField(pos = 1)
     private   String  text1;

    @DataField(pos = 2)
     private   String  text2;

    @DataField(pos = 3, pattern =  "########.##" )
     private  BigDecimal number;

}
