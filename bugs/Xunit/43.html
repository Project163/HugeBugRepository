Title

xunit.console.exe fails on tests decorated with both [Fact] and [Theory] when traits filer is applied

Description
Steps:
1. Test class looks like this

```
[Xunit.Trait("Category", "Smoke")]
    public class TestClass
    {
        [Xunit.Theory()]
        [Xunit.Fact()]
... [Log Snipped] ...
        }
    }
```
1. run xunit console like this;

```
xunit.console.exe TestXunit.dll -trait Category=Smoke
```
1. Actual result:

```
System.InvalidOperationException: Sequence contains more than one element
```

Expected is more meaningful error message that states that [Fact] and [Theory] are not allowed together on the same method with test name included.
