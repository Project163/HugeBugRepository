Title

Hive.get(HiveConf) returns same Hive object to different user sessions

Description
Current Hive.get(HiveConf) creates and returns a new Hive object when the ThreadLocal Hive is null or HMS config is not compatible, but does not do that when it is called in a thread which has been switched to execute a session with a different userId. It will cause the impersonation issue to HMS. 
It is related to   HIVE-7890  .
Discussion
- A quite straightforward patch which adds the check of session owner in Hive.get(HiveConf).
