Title

mypy fails if WriteOnlyMapped is used in join()

Description
### Ensure stubs packages are not installed

- [X] No sqlalchemy stub packages is installed (both `sqlalchemy-stubs` and `sqlalchemy2-stubs` are not compatible with v2)

### Verify if the api is typed

- [Link: X] The api is not in a module listed in [#6810] so it should pass type checking

### Describe the typing issue

Mypy blames the relationship constructed with `WriteOnlyMapped` type annotation cannot be used in `Select.join()` method.

### To Reproduce

```
python
from sqlalchemy import select
from sqlalchemy.orm import DeclarativeBase, Mapped, WriteOnlyMapped, relationship


... [Log Snipped] ...

query = select(Parent).join(Parent.children).where(Child.name == 'abc')
```

### Error

```
1.py:17: error: Argument 1 to "join" of "Select" has incompatible type "WriteOnlyCollection[Child]"; expected
"Union[Union[FromClauseRole, Type[Any], Inspectable[_HasClauseElement], _HasClauseElement], JoinTargetRole]"  [arg-type]
    query = select(Parent).join(Parent.children).where(Child.name == 'abc')
                                ^~~~~~~~~~~~~~~
Found 1 error in 1 file (checked 1 source file)
``` 

### Versions

- OS: Ubuntu 23.04
- Python: 3.11
- SQLAlchemy: 2.0.16
- Type checker (eg: mypy 0.991, pyright 1.1.290, etc): mypy 1.3.0 

### Additional context

The runtime works fine, it is the type checker error only.
