Title

Hot asset reloading example does not update when saving torus.gltf

Description
## Bevy version

0.14.1

## Relevant system information

Tested on:
- Windows 10
- Linux (Ubuntu)


## What you did

Ran the [Link: hot_asset_reloading] example on my Window 10 desktop, and Ubuntu laptop.

CLI args:
```bash
cargo run --example hot_asset_reloading --features file_watcher
```

## What went wrong

Updating the [Link: torus] gltf file does not update the model while running. Specifically, I updated the rotation quaternion in the file. Only restarting the app shows me the change.

## Additional information

Editing the base color of the [Link: monkey model] (same example) in version 0.11 seems to work,
though if I add a rotation quaternion, the monkey's rotation only updates upon restarting the app.
