Title

When updating an element or attribute that contains the list delimiter the character is escaped even if delimiting is disabled.

Description
When updating an attribute or element using an XMLConfiguration, if the new value contains a delimiter the delimiter will be escaped with a '\' even if delimiters have been disabled.
Discussion
- XMLConfiguration has been modified to not call PropertyConverter.escapeDelimiters if attributeSplitting or delimiterParsing have been disabled.
