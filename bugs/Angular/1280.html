## Current behavior
 

HttpObserve can't be used in application code, although it's part of the public API

## Expected behavior
 

HttpObserve should be usable. I should be able to have, for example:

    import { HttpObserve } from '@angular/common/http';
    const observe: HttpObserve = 'body';

I should also be able to know, by reading the documentation, what I can pass as value for the observe attribute of the options.
