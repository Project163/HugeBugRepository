Title

BUG LabelBinarizer returns label indicator matrices unchanged

Description
`preprocessing.LabelBinarizer`, when passed an indicator matrix, returns it unchanged. It should return it with correct `pos_label` and `neg_label` indicator values.
Discussion
- I think LabelBinarizer was intended as a no-op in the case when the input is already an indicator matrix but technically, it indeed violates the "contract" of the constructor.
- retagging for 0.14 for discussion.
