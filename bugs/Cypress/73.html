Title

Cannot select item from dropdown list with optgroups

Description
**Description**

I cannot select an item from a list when the list uses optgroups to separate groups of items.

**Steps To Reproduce**

I have a page 'index.html' with a dropdown list called 'cars' with two optgroups:
```
 
 
   
     
       
... [Log Snipped] ...
   
 
```
When I try to select 'Volvo' I as follows:
```
cy
      .visit('/index.html')
      .get('[name="cars"]').select('Volvo')
```

I get an error: 
```
Command:     select
runner.js:62350 Applied to:   ​…​ ​
runner.js:62350 Error:       CypressError: Timed out retrying: cy.select() failed because it could not find a single   with value or text matching: 'Volvo'
```
When I remove the optgroups, the selection succeeds.

I would expect I don't need any special syntax to select an item from a dropdown list which has optgroups.
Discussion
- If there is a workaround for this issue than I would be happy to hear 😄
- Cypress `.select()` is only traversing one DOM level down to find available `options`. The code needs to be updated to account for `optgroups`. 

Using `.click()` on ` ` elements currently throws the error 

```
cy.click() cannot be called on a   element. 
Use cy.select() command instead to change the value.
```

So, the way to workaround this would be to use plain ol' JavaScript & jQuery:

```
cy.get('select').then(function($select){
  $select.val('volvo')
})
cy.get('select').should('have.value', 'volvo')
```
- Fixed in [Link: `0.19.1`].
