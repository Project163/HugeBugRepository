Title

Default query cache using wrong object

Description
On the fix of PHP 7 [Link: bug], `ReflectionProperty#getValue()` is now raising a `Notice` when accessing an undefined property. That change revealed a false positive on ORM tests!

As you can see [Link: here] the `DefaultQueryCache` is always trying to fetch data from `$entity` even when the association is not with that object (the test is failing because `DefaultQueryCache` is trying to get the `country` from the `City` instead of the `State`).

**How to reproduce:** execute the test suite while running PHP 7.0.7
Discussion
- @lcobucci can you take a look at #5856? It fixes the issue, but also disables some of the SLC caching happening during hydration of multi-level DQL fetch-joins.

I'd say it's fixed, let's close it?
