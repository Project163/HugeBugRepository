Title

Editing the `reply_to` and `from` addresses on an email

Description
Hi there,

Is there a simple way to set custom `reply_to` email addresses with a DeviseMailer?

I'm working on a project where I need to set a differenct `reply_to` address for an email message to the `from` address, and I didn't see a particularly nice way to do this.

I'd normally expect to add it here, in a custom subclass Invite Mailer, like so:

```
class InviteMailer   Rails.configuration.invite_email_reply_to])
 output
end
```

But I can't be the only person needing to have different `reply_to` and `from` addresses when using devise, and I'd like to have devise pick this up like so in the mailer_sender section:

```
def mailer_sender(mapping)
    if default_params[:from].present?
```
