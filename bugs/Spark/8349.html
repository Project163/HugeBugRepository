Title

HiveExternalCatalog.listPartitions is failing when partition column name is upper case and dot in partition value

Description
HiveExternalCatalog.listPartitions method call is failing when a partition column name is upper case and partition value contains dot. It's related to this change  [URL]

 The test casein that PR does not produce the issue as partition column name is lower case.
