Title

Column naming strategy doesn't work in csv datastore

Description
METAMODEL-244   introduces the ability to define column names for csv, fixed-width and excel datastores. For csv datastores this doesn't work however, because the CsvConfiguration constructor which takes ColumnNamingStrategy as an argument doesn't actually assign it to its columnNamingStrategy field.
