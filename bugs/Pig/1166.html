Title

AvroStorage gives wrong schema for schemas with named records

Description
Given the Avro schema: 

  
 { "type" : "record" ,
  "name" : "toplevel" ,
  "fields" :[{ "name" : "a" ,"
             "type" :{ "type" : "record" ,
                     "name" : "x" ,
                     "fields" :[{ "name" : "key" , "type" : " int " },
                              { "name" : "value" , "type" : "string" }]}},
           { "name" : "b" , "type" : "x" }]}
 
  

 we should get back the Pig schema 

  
  {a: (key:  int ,value: string),b:(key:  int ,value: string)}  
  
 but instead it is 

  
  {a: (key:  int ,value: string),b: bytearray}
Discussion
- This was introduced with the added support for recursive schemas in   PIG-2875  . I've attached a patch to fix.
- +1.
