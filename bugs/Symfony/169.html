Title

[TwigBundle] FilesystemLoader::findTemplate() breaks FilesystemLoader::exists() with Twig3

Description
**Symfony version(s) affected**: 4.4.1 (with Twig `>= 3.0`)

**Description**  
Symfony TwigBridge (4.4.1) FilesystemLoader extends `\Twig\Loader\FilesystemLoader` and overwrites `findTemplate()` (`\Twig\Loader\FilesystemLoader::findTemplate`).

With Twig3 the return values of the `findTemplate()` method has been changed and should return `string|null` (please see  assertFalse(…)` but should be changed to `assertNull()`.


**Possible Solution**  

I've prepared a pull request which fixes the test and the return value.
