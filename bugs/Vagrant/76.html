Title

ansible_local: Destroy fails if guest lacks playbook

Description
When destroying a machine built with the new `ansible_local` provisioner that hasn't sucessfully recieved its playbook, Vagrant will show the following message:

```
$ vagrant destroy -f
There are errors in the configuration of this machine. Please fix
the following errors and try again:

ansible local provisioner:
* `playbook` does not exist on the guest: /vagrant/terraform.sample.yml
```

The expected behavior is that Vagrant will destroy the VM, with or without the playbook existing.
