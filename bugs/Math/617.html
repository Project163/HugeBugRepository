Title

WilsonConfidenceInterval returning negative values

Description
Wilson confidence intervals sometimes return negative values as the lower bound, e.g. 
IntervalUtils.getWilsonScoreInterval(19436, 0, 0.95).getLowerBound() returns -1. -20 

 This is causing assertion fails in our code, which we have fixed it now by wrapping the confidence score bounds in Math.max(0, Math.min(1, bound)) until the method doesn't return wrong results anymore.
