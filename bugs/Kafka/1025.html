- Thanks for reporting this. I reproduced the error by creating producer retry scenario.  
Below exception is occurring when producer is trying to append a record to a Re-enqueued record batch in the accumulator.  We should not allow to add a record to Re-enqueued record batch. This is happening due a bug in MemoryRecords.java/hasRooFor() method. After calling MemoryRecords.close() method, hasRooFor() method should return false. I will submit patch soon.
