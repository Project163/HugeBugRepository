Title

`no-undef` fails on a simple array desctructuring

Description
command:

``` bash
eslint --no-eslintrc --config ./testconf.json ./test.js
```

test.js:

``` javascript
var obj = {
  first: "first",
  second: "second"
};

[obj.first, obj.second] = [obj.second, obj.first];
```

testconf.js:

``` javascript
{
  "ecmaFeatures": {
    "destructuring": true
  }
}
```

output:

```
./test.js
  6:5   error  "first" is not defined   no-undef
  6:16  error  "second" is not defined  no-undef

✖ 2 problems (2 errors, 0 warnings)
```
