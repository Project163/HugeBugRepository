Title

Gnome Tweaks Scaling Factor garbles OBS interface in 26.1

Description
## Platform
 
 
Operating system and version: Arch Linux (5.10.4-arch2-1)
OBS Studio version: 26.1.0-2

## Expected Behavior
 
OBS interface should look normal when font scaling is applied in Gnome Tweaks
[Image: [URL]

## Current Behavior
 
 
OBS interface is completely garbled when font scaling is applied in Gnome Tweaks
[Image: [URL]

When going from windowed to maximized makes it worse: [Image: [URL]

## Steps to Reproduce
 
 
 
1. Open Gnome Tweaks and go to the Fonts tab
2. Set the Scaling Factor to 0.90 [Image: [URL]
3. Open OBS
4. Interface unusable
5. In Tweaks, set Scaling Factor to 1 [Image: [URL]
6. OBS looks normal

## Additional information
 
 
This issue was not present in version 25.x, as I always had the Scaling Factor set to 0.90. KeepassXC had a similar problem earlier this year: [URL]

- I could have sworn we had a ticket for this already. Hmm.

This can be considered a known issue, basically we added improved scaling support (as did our UI library, Qt) which supports fractional scaling.

Unfortunately, it seems to misbehave on Linux. The plan is to verify whether the fractional scaling support causes any issues on macOS, and then submit a PR that disables it on (at least) Linux.
