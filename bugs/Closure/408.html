Title

goog.isArray doesn't hint compiler

Description
What steps will reproduce the problem? 
 1. 

/**
 * @param {*} object
 * @return {*}
 */
var test = function(object) {
  if (goog.isArray(object)) {
    /** @type {Array} */ var x = object;
    return x;
  }
};
