Title

[DocDB] [Table locks] pg_locks does not display the expected results when enable_object_lock_fastpath is enabled.

Discussion
- This is because of how we track locks for pg_locks: we have ObjectLockTracker at the TSLocalLockManager level, instead of querying ObjectLockManager directly. This approach is incompatible with shared memory fastpath locking, which loads locks directly from PG to ObjectLockManager, skipping TSLocalLockManager.
