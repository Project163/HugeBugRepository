Title

Fix flacky CppCassandraDriverTest.TestCreateIndexSlowTServer

Description
Jira Link: [Link: DB-4637]
If an index is failing, we go through multiple schema changes before the index is deleted.

 A YCQL query will retry if it sees a schema mismatch, but do so only onec. So, If a query is unlucky,
 it may hit "Schema version mismatch" error on both the tries. So, queries that run concurrent
 with a backfill should account/allow for these errors.
