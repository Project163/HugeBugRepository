Title

Dynamically generated models should inherit the Config of their __base__

Description
# Bug

Thanks for the great library, @samuelcolvin! I have been using it quite extensively in the past weeks and hope to contribute a possible bug (+ a suggested fix).

* OS: **Mac OS**
* Python version `import sys; print(sys.version)`: **3.6.4**
* Pydantic version `import pydantic; print(pydantic.VERSION)`: **0.12.1**

A self contained code snippet describing the bug:

```
py
import pydantic

class Foo:
    pass
... [Log Snipped] ...
# throws RuntimeError: no validator found for  
Baz = pydantic.create_model('Bar', __base__=Bar, y=(Foo, ...))
```

I think that [Link: this line] should be changed either to

```python
config = __config__ or __base__.Config
```

or to

```python
config = __config__ or __base__.Config or BaseConfig
```

if the meta-class does not set `__base__.Config = BaseConfig` by default.
