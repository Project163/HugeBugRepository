Title

[Aggregation Group API] Indexes added via the Aggregate Group API, the order of dimensions displayed on the page is inconsistent with the order passed in by the api

Description
[Aggregation Group API]  Calling the newly added index of the aggregation group API, the order of dimensions displayed on the page is inconsistent with the order passed in by the api
Discussion
- Root Cause 

 Because the dimension order will affect the generated index, it is necessary to ensure that the dimension order stored in the metadata database is consistent with the dimension order entered by the user calling the API. Currently, when parsing the dimension name -> dimension id, the TreeSet is used to save the dimension name, so the collection will be iterated according to the natural order instead of the incoming order. 
   Fix design 

 change TreeSet to LinkedHashSet.
