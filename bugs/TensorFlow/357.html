- I did manage to get around it by not relying on numpy. The new code is:

def cal_sigma(y):
    return 1 / (1 + e**-y)

@tf.function
def get_derivative2(x, y):
    with tf.GradientTape(persistent=True) as tape:
        tape.watch(y)
        y_sigma = cal_sigma(-y)
        f = (x + y_sigma) / ((x -y)**2)
    df_dy = tape.gradient(f, y) 
    return df_dy

With these changes, it does work also for y. However, it gives an unpredictable answer. See [URL]
