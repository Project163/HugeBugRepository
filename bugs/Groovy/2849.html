Discussion
- I have fixed it on master. Basically it will be a compile time error if you use  @CompileStatic  to call a protected method from a wrong context, like the  clone  method here. 

 I am only setting this to be fixed in 2.5 for now because I am unsure if there's not a regression somewhere so I'd like to give people chances to report it.
