Title

Crash in union with a forward reference to a bad type.

Description
This code causes a crash:
```
python
Alias = Union[Bad, C, D]

Bad = object()

... [Log Snipped] ...
if isinstance(option, C):
    pass
```
Here is a traceback:
```
tmp.py:3: error: Invalid type "tmp.Bad"
tmp.py:13: error: INTERNAL ERROR -- please report a bug at [URL] version: 0.570-dev- -dirty
Traceback (most recent call last):
  File "/Users/ilevkivskyi/mypy/bin/mypy", line 11, in  
    load_entry_point('mypy===0.570-dev- -dirty', 'console_scripts', 'mypy')()
... [Log Snipped] ...
    assert False, 'Not supported'
AssertionError: Not supported
```

It looks like the problem is that clearly erroneous types are not wrapped in `ForwardRef` and are not post-processed in third pass. There are two options that I see now for `UnboundType`s (maybe there are other):
* Expect them in type checker and amend the corresponding visitors
* Replace them with `Any` after giving an `Invalid type` error (maybe with better error message, but we already have an issue for this.)

I would prefer the second option, since this seems simpler and would probably minimize the amount of not useful errors (because of the initially invalid type).
