## Triage Summary: Issue #28 — Facet query crashes the cluster

### Overview

This issue reports that executing a facets query causes the Elasticsearch cluster to become unresponsive. One node's memory balloons to ~631MB, the cluster stops responding to queries, and shard recovery failures occur during shutdown with `RecoveryFailedException` and `ElasticSearchInterruptedException` errors.
