Title

Update the EnhancedDoubleHasher to correct the cube component of the hash

Description
The EnhancedDoubleHasher currently computes the hash with the cube component lagging by 1: 
  
 hash[i] = ( h1(x) - i*h2(x) - ((i-1)^3 - (i-1))/6 ) wrapped in [0, bits) 
  
 Correct this to the intended: 
  
 hash[i] = ( h1(x) - i*h2(x) - (i*i*i - i)/6 ) wrapped in [0, bits) 
  
 This is a simple change in the current controlling loop from: 
  
 
 for  ( int  i = 0; i < k; i++) {  
  
 to: 
  
 
 for  ( int  i = 1; i <= k; i++) {
