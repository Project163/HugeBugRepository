Title

Upgrade Thrift dependency to 0.9.0

Description
I work on HCatalog (0.2). Recently, we ran into HCat_server running out of memory every few days, and it boiled down to a bug in thrift, (  THRIFT-1468  , recently fixed). 

 HCat-0.2-branch depends on Hive-0.8, which in turn depends on thrift-0.5.0. (The bug also exists on 0.7.0.) 

 May I please enquire if Hive can't depend on a more current version of thrift? (Does it break the metastore?) I'm afraid I'm not privy to the reasoning behind Hive's dependency on a slightly dated thrift-lib.
Discussion
- Looks like the fix for   THRIFT-1468   will be included in the as-yet-unreleased 
version 0.9.0. We can update Hive's Thrift dependency once this release 
goes GA.
- Also, Hive 0.8.0 depends on Thrift 0.7.0, not 0.5.0.
