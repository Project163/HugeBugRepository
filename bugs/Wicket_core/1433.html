Title

Ajax Buttons do not check for the HTTP method and thus don't respect Form#onMethodMismatch

Description
Pretty much what it says in the summary: The HTTP method check is only done in onFormSubmitted(), not in onFormSubmitted(submitter), which is what AjaxButton and friends call directly.
