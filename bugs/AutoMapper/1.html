Title

When a target type property is of ISet , the CollectionMapper incorrectly attempts to set it to a List

Description
A target type may have a property with type of ISet, and the source may be an IEnumerable. AutoMapper detects that the ISet is an ICollection, but assumes that all ICollection instances can be satisfied with a List. This is not true with ISet.

This is a duplicate of issue #27, which was accidentally closed (how?) and cannot, apparently, be reopened.
