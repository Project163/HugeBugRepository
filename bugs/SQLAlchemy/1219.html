Title

orm plugin not applied to labeled ORM column or expression

Description
### Describe the bug

Using `label` in a `select` construction with an ORM column causes `with_loader_criteria` to lose the association of the column with the ORM entity.

I've also noticed that `column_descriptions` is not populated for these queries, indicating that the ORM plugin is not being used (which may be leading to this issue).

```
# Querying a single column uses the ORM plugin.
(Pdb) select(A.id).column_descriptions
[{'name': 'id', 'type': Integer(), 'aliased': False, 'expr':  >, 'entity':  }]
# Querying a column with a label does not use the ORM plugin.
(Pdb) select(A.id.label('id')).column_descriptions
... [Log Snipped] ...
(Pdb) select(A.id.label('id'), A.data).column_descriptions
[{'name': 'id', 'type': Integer(), 'aliased': False, 'expr':  >, 'entity':  }, {'name': 'data', 'type': String(), 'aliased': False, 'expr':  >, 'entity':  }]
```

I've attached code to reproduce this behavior with `with_loader_criteria`.  The above debug output I observed by interacting with `pdb` at the breakpoint within `test_select`.
