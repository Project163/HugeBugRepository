Title

Should provide node / npm / package installation proxy for Helium

Description
1. Zeppelin installs nodejs / npm on startup but there might be trouble if you can connect to the official nodejs site. So we need proxy option for them.  

 
	 For example we should use  [URL] in China 
 

 2. Additionally, helium will install nodejs packages at runtime. So we have to provide proxy option for that too.
