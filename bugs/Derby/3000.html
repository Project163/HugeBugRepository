Discussion
- BootLockTestMinion uses EmbeddedDataSource, which does not work on compact2. It should use BasicEmbeddedDataSource40 instead on that platform.
- The patch   d6651-1a.diff      makes BootLockMinion use JDBCDataSource.getDataSource() to create the DataSource, so that we get one that works on the platform on which the test runs. Since the framework adds the prefix "system/" to relative database path names, some path names in BootLockTest had to be changed to compensate for that.
