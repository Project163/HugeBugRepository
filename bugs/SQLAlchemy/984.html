Title

switch pkg_resources use to importlib.metadata, if installed

Description
As dialect discovery relies on `pkg_resources`, if `setuptools` is not installed (which is rare, but possible), the discovery process is skipped.

[URL]

Is this an optional feature where the user needs to ensure `setuptools` is installed, or should it be a runtime dependency?
Discussion
- if you want to use plugins you would need to have setuptools installed.  a plugin itself installed via setup.py would probably not be installable without setuptools being present, so i think that's how it works out.
- Right, but that just means `setuptools` is available during installation. Since nothing declares a runtime dependency on it, it does not have to be available when plugin discovery happens. I encountered this issue in a situation where we package application dependencies based on the dependencies they declare, and deploy those as a bundle. As nothing declares the `setuptools` dependency, custom dialects stop working.
