Title

KafkaOffsetRangeCalculator.getRanges may drop offsets

Description
KafkaOffsetRangeCalculator.getRanges may drop offsets due to round off errors. 

   

 This only affects queries using "minPartitions" option. A workaround is just removing the "minPartitions" option from the query.
Discussion
- This is resolved via  [URL]
- Does this affect non-structured streaming?
- klaustelenius  No. The "minPartitions" option for batch queries is added in Spark 3.0. Batch queries before Spark 3.0 will ignore the "minPartitions" option.
