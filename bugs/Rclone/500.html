Title

Problems with folder name contains "：" on Windows.

Description
#### What is the problem you are having with rclone?

When you have folder with "：" you can't access the folder with `rclone ncdu` or copy the folder. (you can however access the parent directory and then navigate to the problematic folder)

#### What is your rclone version (output from `rclone version`)

Tested on Windows: 1.50.1, 1.50.2-059-g1db31d71-beta

#### Which OS you are using and how many bits (eg Windows 7, 64 bit)

Windows 10 1903 64bit

Can't replicate on Ubuntu 16.04.

####  Which cloud storage system are you using? (eg Google Drive)

local harddrive

#### The command you were trying to run (eg `rclone copy /tmp remote:tmp`)

rclone ncdu "test：a"

(or cd into "test：a" and do rclone ncdu .)

#### A log from the command with the `-vv` flag (eg output from `rclone -vv copy /tmp remote:tmp`)


terminal is cleared so the log isn't useful...

I've ran `mkdir "test：a"` before running that command so folder "test：a" does exist.
Discussion
- I think this is the restriction that windows puts on all directory names. IMO, your best bet is to rename the folder before copy it in windows platform.
- I think this is the same issue as #3723

The work-around would be to add a ‛ before the ： so

rclone ncdu "test‛：a"

I need to think of a work-around for this!
- Please can you try this with the `--local-encoding None` flag?  You can put that as `encoding = None` in your config.

That disables the character name conversion and should fix the problem for you.
