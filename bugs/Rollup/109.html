Title

Rollup JavaScript slice/push does not appear to work

Description
Rollup's rollup.config.js processing fails to process the following JavaScript correctly.
--------------------------------------
NodeJS example:
$ cat example.js
var someArray = [ 'a' ];
var copyOfArray = someArray.slice();

someArray.push('b');
console.log('someArray = ' + someArray);

copyOfArray.push('b');
console.log('copyOfArfay = ' + copyOfArray);

$ node example.js
someArray = a,b
copyOfArfay = a,b

--------------------------------------
Rollup example:
If place the same code in a rollup.config.js file, I see incorrect results:
$ cat rollup.config.js
var someArray = [ 'a' ];
var copyOfArray = someArray.slice();

someArray.push('b');
console.log('someArray = ' + someArray);

copyOfArray.push('b');
console.log('copyOfArray = ' + copyOfArray);

$ node_modules/rollup/bin/rollup -c rollup.config.js
someArray = a,b
copyOfArray = a

copyOfArray should report a,b, not just a.
Discussion
- The issue I reported is NOT with what rollup generates, but with rollup's JS engine as it reads and processes JavaScript in its JavaScript-based configuration file (i.e., the file that is passed via the -c command line option).
- But Rollup does generate incorrect code for the repl link above.

The config file is a different matter, although probably related.
