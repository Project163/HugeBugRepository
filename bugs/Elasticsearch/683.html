Title

Percolator response should always return the `matches` key

Description
Only including the `matches` key can be cumbersome for anyone parsing the percolator response. Also it is inconsistent with the search api, where the `hits` key is always returned regardless if there are any hits.

So we should always include the `matches` key in the percolator response.
