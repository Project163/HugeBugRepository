Title

MaxTime doesn't work when used for TestCase

Description
If using [MaxTime] and [TestCase] for a test exceeding the MaxTime, the test will pass, when it should fail.

[Image: nunitbug_maxtime_testcase]
[Image: nunitbug_maxtime_testcase_2]
Discussion
- The MaxTime attribute doesn't work on a testcase. Unfortunately, it is simply ignored rather than giving an error when used in this way. I have confirmed that the same error happens in the NUnit 3.0 codebase. We'll fix it for the 3.0 release.
- Ah... turns out it _does_ work in the 3.0 code. I added a test to confirm.
