Title

Fields erroneously validating on initial render

Description
**Describe the bug**

I'm using the awesome React Hook Form on a Gatsby.js site I'm building, using Yup for field validation.

I'm having an issue with forms validating on initial render - meaning all form inputs are marked as having errors before a user has interacted with them.

**To Reproduce**

Steps to reproduce the behaviour:

1. Go to the Codesandbox below
2. See validation errors marked on initial render

**Codesandbox link**

Forked from the provided `useForm` template:
[URL]

**Expected behaviour**

On initial render, the fields should not be validated or marked as having errors before a user has interacted with them.

**Desktop**

- OS: MacOS 10.15.7
- Browser: Confirmed on Chrome & Safari so far
- Version: Chrome 85.0.4183.121 & Safari 14.0

**Additional context**

I've been busy focusing other components of the site I'm working on, however I don't recall getting this error whilst using earlier version(s) of React Hook Form and/or @hookform/resolvers.

Additionally I'm sure this issue isn't specific to Gatsby.js SSR as I get the same issue on the Codesandbox when using vanilla React.
