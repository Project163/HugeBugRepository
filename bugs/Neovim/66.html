- Using valgrind I was able to reproduce the issue and then use `--vgdb=full` to see what's happening.

As @mordak found [URL] is the problem.

`syn_getcurline()` is returning an empty string (the next line), so `syn_getcurline()[current_col + 1]` indexes past the end of the string.

This fixes it for me and doesn't break any tests.  However, I haven't checked yet if there's a smaller test case that can reproduce the issue, so it can be added to the regression tests.
