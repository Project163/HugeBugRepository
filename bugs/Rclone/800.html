I think rclone is doing the right thing

The first query is this when looking for a file

    q=trashed=false and ('root' in parents) and (name='\'') and mimeType!='application/vnd.google-apps.folder'

And the second query is this when looking for a directory

    q=trashed=false and ('root' in parents) and (name='\'') and mimeType='application/vnd.google-apps.folder'

Which look correct for looking for a directory called `'` in the root.

So this could well be a bug in google drive rather than rclone.

Still an issue
- I'm pretty sure this is a bug in google drive and its handling of the `name` parameter. Rclone is doing the escaping the same for all of these:

| Folder | Works |
|:-------:|:--------|
| `'` | No |
| `''` | No |
| `'a'` | No |
| `'a` | Yes |
| `a'` | Yes |

We maybe should stop searching for specific names and list the entire directory. This would be less efficient though.

An alternative would be to not search for specific names if they had `'` or `\` in - that would be a pretty easy work-around.
