select[multiple] selection clearing when updating options

Description

**Current behavior**
When changing the options in a multi-select box, the existing value sometimes loses it's selection.

**Expected behavior**
The selected option should remain selected

**Minimal reproduction of the problem with instructions**
I created a demo here:
[URL]

To reproduce:
1. Select option 2 on the first select box
2. Select any option on the second box
3. Notice that the selected value disappears

**What is the motivation / use case for changing the behavior?**
The app I am building takes a large data set that can be filtered by selecting values for the different properties in objects. The intent is that the user can filter the data set down to a single object by selecting all of the values. It is also true, that some selections can limit what you can select for the other options.
