Title

[Blocker] NIOChannels can go into 100% CPU spin after being closed.

Description
In my exception channel I catch the exception, log it and then call channel.close(). The returned future completes successfully.
However (especially after I spam the server with as many connections a second as possible), when I terminate these connections causing an IOException - Connection Reset, followed by calling channel.close() - the server CPU usage immediately jumps up to 100% CPU.
Even calling all this in succession does not help:
         ctx.channel().close().addListener( trace );
            ctx.channel().disconnect().addListener( trace );
            ctx.channel().deregister().addListener( trace );

Trace just logs the result of the future.
