Title

`-p` fails to find packages that are found by `-m`

Description
## 🐛 Bug Report

Search path logic mismatch between `-p` and `-m` inputs severely limits the usefulness of the former.

## To Reproduce

Install a package into a virtualenv in develop/editable mode

Try to typecheck the package within that venv using `mypy -p import.path.to.package`

## Expected Behavior

Package typechecks

## Actual Behavior

mypy fails with `Can't find package`

## Your Environment

Tested in both mypy 0.780 and mypy 0.790+dev. 
Python 3.7
macOS 10.14
