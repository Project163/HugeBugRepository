Title

geo_shape query with circle does not work for legacy geo_shape field

Description
We currently do not support circle queries for geo_shape fields using BKD_backed geo_shape but it should be possible to do it using legacy indexing strategy.

This is currently broken. They issue seems to be in the [Link: serialisation mechanism] which throws an error for circle geometries.
