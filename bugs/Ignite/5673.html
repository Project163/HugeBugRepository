Title

IndexQuery queries backups instead of primary partitions

Description
When IndexQuery.setPartition is set, IndexQuery can query local backup partition instead of remote primary partition, even for partitioned caches. This breaks ReadOwnWrites consistency. 

 The bug happens due to 2 issues: 
 
	 CacheQuery#nodes mixes nodes that own partition (primary is not first) 
	 CacheQueryDistributedFuture#nodes always returns local node if it owns partition (even if it backup). 
 

 For querying backups there is CacheQuery#includeBackups.
