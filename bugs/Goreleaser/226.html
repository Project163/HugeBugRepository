Title

JSON schema incorrect for `builds.hooks.(pre|post)`

Description
### What happened?

When editing ` .goreleaser.yml`, VSCode gives this error:

```
Incorrect type. Expected "array".
(yaml-schema: Goreleaser)
```

However, as per [URL] `BuildHooks` should be of type `string` instead of `Hooks`.

### How can we reproduce this?

```yml
# .goreleaser.yml
builds:
  - hooks:
      pre: echo pre
      post: echo post
```
