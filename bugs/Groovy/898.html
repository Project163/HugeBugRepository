Title

Calling a vararg method with no varargs causes IllegalArgumentException

Description
"".metaClass.hasMetaMethod(" trim")
 
  

 causes: 

  
 java.lang.IllegalArgumentException: wrong number of arguments
 
  

 Apparently MetaMethod#invoke is used where it should be MetaMethod#doMethodInvoke. 

  [URL]
Discussion
- Even on 1.5.6,  I see this issue present. The call "".metaClass.hasMetaMethod("trim") does not go through on that version too. 
Another thing I am not sure is how it is related to varargs. Even on the mailing list thread, I didn't see any example of that.
- I don't remember to 100% what I tested, but getting the method did work, invoking it did lead to the exception. The problem was that the arguments given to the method are not in the format reflection expects them. For a varargs method something has to be present for the array. In the version above a String is given for the first argument, but the second vargs argument is a Class[] and nothing is given to there. So as soon as you invoke the method without transforming the arguments array before you get an exception. doMethodInvoke is doing that transformation for you
