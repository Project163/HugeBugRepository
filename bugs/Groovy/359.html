Title

Can't override EMC added static methods if method has arguments

Description
Best explained by example ... 

 class T {} 

 T.metaClass.'static'.f =  
{ "first" }
 T.metaClass.'static'.f =  
{ "second" }

 T.metaClass.'static'.echof =  
{ println delegate.f() } 
 
T.echof() 
 
Results in 'first' being written instead of 'second'. 
 
However the following works properly .. 
 
class T {} 
 
T.metaClass.'static'.f = { -> "first" } 
T.metaClass.'static'.f = { -> "second" } 
 
T.metaClass.'static'.echof = { println delegate.f() }

 T.echof() 

 Prints 'second'.
