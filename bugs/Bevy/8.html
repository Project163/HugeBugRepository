Title

Scene reloading does not work on windows.

Description
This can be reproduced with the "scene" example.

## Reproduction
Clone bevy repo.
Run `cargo run --example scene`.
Change property `x` of entity `328997855` from `3.0` to `5.0`.
Save the file.

## Expected

## Actual
No console message.
