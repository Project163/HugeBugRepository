Title

'PageLoad is declared but its value is never read' when running svelte-check

Description
### Describe the bug

When running `svelte-check` against a new project with a `+page.ts` that uses the `PageLoad` type, the `PageLoad` type is not used in the generated `proxy+page.ts` in the `.svelte-kit` directory. This causes the hint `'PageLoad' is declared but its value is never read` to be thrown.

### Reproduction

Create a new Svelte Kit app:

```
npm create svelte@latest my-app

Need to install the following packages:
  create-svelte@latest
Ok to proceed? (y) y
... [Log Snipped] ...
✔ Add Prettier for code formatting? Yes
✔ Add Playwright for browser testing? Yes
```

Install dependencies:

```sh
cd my-app
npm i
```

Add the following code to the end of `src/routes/about/+page.ts`:

```ts
import type { PageLoad } from './$types';

export const load: PageLoad = () => {
  console.log('loading about page');
  return {};
};
```

Run Svelte Check:

```
npm run check
```
