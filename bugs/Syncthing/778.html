Title

Deleting a folder containing a symlink results in a permanently out of sync on windows

Description
I have seen this with 1.8.0 and later.

My share has 2 members - one linux and one windows 10.

The same files (soft links) are reported under out of sync items and failed items on the windows side.

To reproduce:

1) share a folder between linux and windows.
2) on linux:
cd \ 
mkdir x
ln -s ~/.bashrc x/y
\ 
rm -rf x

I have not tried this between 2 linux instances.

I understand that soft links are supposed to be ignored - and for my application that works fine. Adding the files to the ignore list might work, but I would rather not have to keep track of all the names.
