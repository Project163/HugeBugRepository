Title

ModelAwareTrait::modelClass can work with FQCN, but Controller __get not

Description
This is a (multiple allowed):

* [x] bug
* [x] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 4.1.0
* Platform and Target: any

### What you did

I want to override my controller default model, defining it property `modelClass`:

```php
public function initialize(): void
{
    parent::initialize();

    $this->modelClass = MyPostsTable::class;
}
```

### What happened

Controller failed to recognize my custom table because its only parse dot notation.

```
php
public function __get(string $name)
{
    if (!empty($this->modelClass)) {
        [$plugin, $class] = pluginSplit($this->modelClass, true);
... [Log Snipped] ...
        }
    }
```

If I pass `$this->loadModel(MyPosts::class)` at my controller initialize, everything works (ModelAwareTrait can parse both formats)

### What you expected to happen

Using FQCN as a `$modelClass` should work - its easier to lint/check/refactor code with class names than strings.
