Title

Regression in Formatter fallback methods for very small numbers

Description
### What steps will reproduce the problem?
```Yii::$app->formatter->asCurrency(1E-10, 'EUR');```

### What is the expected result?
```€0.00```

### What do you get instead?
```EUR 1.0E```

### Additional info
The expected result was achieved before `asCurrencyStringFallback()` was added ( [URL]

Related similar issue: [URL]

I applied the following quick workaround in my project:

    /**
     * Quick workaround when formatting very small numbers.
     * @see [URL]
     *
     * @inheritdoc
     */
    public function asCurrency($value, $currency = null, $options = [], $textOptions = [])
    {
        if (abs($value) < 1E-9) {
            $value = 0.00;
        }
        
        return parent::asCurrency($value, $currency, $options, $textOptions);
    }
