Title

addFooter mailet doesn't work for multipart mail

Description
The addFooter mailet doesn't work for multipart mail, though It works for text mail. (Tested with 3.0.1.) 

 The addFooterTest ends successfully but the mailet doesn't work on the real James server. 
The addFooterTest uses javax.mail.internet.MimeMessage, but the real mailet uses org.apache.james.server.core.MimeMessageCopyOnWriteProxy which extends MimeMessage.
Discussion
- Attached is the patch to fix the issue by modifying AddFooter.java. 
This approach may be the same way which is discussed in  JAMES-1910  &   JAMES-443  , 
but I wonder if this is the right approach. 

 Maybe it's better to make a modification to MimeMessageCopyOnWriteProxy.java. 

 I'm also concerned if other similar mailets which modify contents have the same issue with multipart mail, because the issue here is essentially that MimeBodyPart.setContent(String) is not effective unless you call MimePart.setContent(Multipart) on its ancestor.
