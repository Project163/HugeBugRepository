Title

Current CMake build documentation leads to undefined references

Description
OS: **Ubuntu 19.04**
CMake: **3.15**

Page: [URL]

Documentation states to use the `OPENGL_gl_LIBRARY` cache variable. However, this appears to be `null` (leads to undefined references during compilation) when using **CMake 3.15** on **Ubuntu 19.04**. Using the `OPENGL_LIBRARIES` result variable stated [Link: here in the cmake.org documentation] instead does work.

**Doesn't work (current documentation)** `target_link_libraries(myapp ${OPENGL_gl_LIBRARY})`
**Works** `target_link_libraries(myapp ${OPENGL_LIBRARIES})`

I believe this will likely be an issue on other distributions aswell.
