Title

Cannot set nested value when array is in an object ?

Description
Hey ! First of all, thanks for this amazing library 🙏  It's my absolute must use when I build forms in react.

I might be missing something, but it seems to me that `setValue` is somehow buggy when I use it to set a value on a nested array, which is itself inside an object. I tried to simplify the codsandbox the best I could to make it more obvious. The same problem seems to happen with `append` of `useFieldArray`. Am I missing something ?

```
            setValue("obj.test", [
              {
                name: "append",
                nestedArray: [{ field1: "append", field2: "append" }]  // <---- this line is ignored
              }
            ]);
```

Note that if I remove `obj.` from my form/data structure, everything works just fine.
