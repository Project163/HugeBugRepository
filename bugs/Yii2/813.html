Title

MessageController (message/extract) does not delete files with removeUnused=true

Description
### What steps will reproduce the problem?

1. PhpMessageSource
2. Files `messages/ /category/subcategory.php`:
```php
  'Translation',
];
```
3. Source code to extract messages from does not contain anymore any messages the category `Yii::t('category/subcategory', ...)`;
4. `./yii message/extract message/config.php` so `removeUnused` is `true`

### What is the expected result?

Since there are no more messages in the category `category/subcategory`, I extect a deletion of files `messages/ /category/subcategory.php` (with directories becoming empty) or at least see any notice about such files or categories.

### What do you get instead?

Neither the files was deleted, nor notices are displayed.
