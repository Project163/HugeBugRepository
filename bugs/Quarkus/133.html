Title

MicroProfile Rest Client @RegisterRestClient ignoring baseUri property

Description
**Describe the bug**
MicroProfile Rest Client 1.2 added the baseUrl property to the @RegisterRestClient annotation, which seems to be ignored.

**Expected behavior**
Utilize the baseUrl from the @RegisterRestClient(baseUrl = ...) even when.../mp-rest/url property in application.properties does not exist.

**Actual behavior**
"NoSuchElementException: Property org.acme.restclient.CountriesService/mp-rest/url not found"

**To Reproduce**
Steps to reproduce the behavior:
1. In the rest-client Quarkus quickstart, comment out the mp-rest/url property in application.properties
2. In the rest-client Quarkus quickstart, in CountriesService.java replace @RegisterRestClient with:
`@RegisterRestClient(baseUri = "[URL]
3. Run `mvn quarkus:dev` and hit the endpoint ([Link]). Kablooey!

**Environment (please complete the following information):**
 Quarkus 0.15.0 rest-client quickstart, which I believe supports MP Rest Client 1.2

**Additional Information**
Visual Studio Code does offer the option to auto-complete baseUri, so it does exist, implying MP Rest Client 1.2 support.
