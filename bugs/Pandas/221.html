Title

Error when subtracting mixed type DataFrame

Description
Sample code to reproduce the error:

import numpy as np
import pandas

X = np.random.rand(10,10)
Y = np.ones((10,1),dtype=int)
df1 = pandas.DataFrame(X)
df1 = df1.join(pandas.DataFrame(Y),lsuffix='.X')

print df1-df1.mean()
