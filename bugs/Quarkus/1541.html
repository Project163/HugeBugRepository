Title

Referencing Context APIGatewayV2HTTPEvent in RestEasy Method Throws Exeception

Description
### Describe the bug

White using RestEasy-Reactive and Lambda HTTP.  Referencing @Context APIGatewayV2HTTPEvent throws IllegalStateException

**Method:**

```
 @GET
 @Produces(MediaType.TEXT_PLAIN)
  public String hello(@Context APIGatewayV2HTTPEvent event) 
 {
        return "Hello RESTEasy";
 }
```

**Exception Thrown:**

```
2022-03-07 23:02:59,967 DEBUG [org.jbo.res.rea.ser.han.ParameterHandler] (executor-thread-0) Error occurred during parameter extraction: java.lang.IllegalStateException: Unsupported contextual type: class com.amazonaws.services.lambda.runtime.events.APIGatewayV2HTTPEvent
	at org.jboss.resteasy.reactive.server.core.parameters.ContextParamExtractor.extractParameter(ContextParamExtractor.java:94)
	at org.jboss.resteasy.reactive.server.handlers.ParameterHandler.handle(ParameterHandler.java:41)
	at org.jboss.resteasy.reactive.server.handlers.ParameterHandler.handle(ParameterHandler.java:15)
	at org.jboss.resteasy.reactive.common.core.AbstractResteasyReactiveContext.run(AbstractResteasyReactiveContext.java:141)
... [Log Snipped] ...
	at io.netty.util.concurrent.FastThreadLocalRunnable.run(FastThreadLocalRunnable.java:30)
	at java.base/java.lang.Thread.run(Thread.java:829)
```

This appears to only happen when using `RestEast-Reactive`

### Expected behavior

No exception is thrown and the `@Context APIGatewayV2HTTPEvent` parameter is available for reference.

### Actual behavior

Exception is Thrown
