Title

[bug] Prevent `.app` in identifier

Description
### Describe the bug

This will cause undesired behavior on macOS cause `.app` is a system thing for apps.

 

### Reproduction

use any `identifier` that ends in `.app` and you'll see macOS thinking it's an app instead of a directory.

### Expected behavior

The tauri runtime should throw an error and if people still want this behavior have a flag to allow it.
