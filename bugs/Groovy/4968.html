Title

STC: method call with class literals

Description
Consider the following: 
  
 
 class  A {}
 class  B  extends  A {}
 class  C  extends  B {}
@groovy.transform.TypeChecked test() {
     def  list = Arrays.asList(A.class, B.class, C.class)
}
test()
 
  

 This fails with "Cannot call <T> java.util.Arrays#asList(T[]) with arguments  [java.lang.Class<A>, java.lang.Class<B>, java.lang.Class<C>] "
