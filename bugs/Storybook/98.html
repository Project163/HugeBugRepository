Title

[addon-docs] Story name & path appended with "Story" when using "CSF Stories with MDX Docs"

Description
**Describe the bug**
When organizing my stories and docs using the [Link: "CSF Stories with MDX Docs" recipe], the displayed story name is appended with `" Story"` and the path is appended with `"-story"`, unless I define an explicit `name` for the story. The displayed name is a bit annoying, but the path breaks existing story permalinks.

**To Reproduce**
_See code snippets_

**Expected behavior**
I would expect the displayed story name and path to be unaffected, regardless of story organization method.

**Code snippets**

```
jsx
// Component.stories.jsx

import { Component } from '..';

... [Log Snipped] ...

export const Example3 = () =>  ;
```

```
jsx
// Component.stories.mdx

import { Component } from '..';
import * as stories from './Component.stories';
... [Log Snipped] ...

 
```

The three stories in the snippets above display as:

1. "Example1 Story" (/?path=/story/component--example-1-story)
    - Incorrect; should be: "Example1" (/?path=/story/component--example-1)
1. "Example2" (/?path=/story/component--example-2)
    - Correct
1. "Example3" (/?path=/story/component--example-3)
    - Correct

**System:**

- @storybook/addon-docs@6.0.12
- @storybook/react@6.0.12
