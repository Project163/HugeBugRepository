Title

Reduce test matrix on Travis

Description
We have 11 profile in the Travis matrix and tests are running for a long time. We should consider streamlining it: 

 
	 do we really support that many versions of Spark? how about just 1.6.x, 2.0.x and 2.1.x? 
	 could we merge the python 2 and 3 tests into other profiles? 
	 could we merge the Livy test into another profile?
Discussion
- livy test could be merged into spark 1.6 when livy 0.3 is released in the near future. 

 BTW, Usually my own travis CI would finish quicker when apache travis CI is busy. Is it possible to only run my own travis CI without triggering apache travis CI ? so that we won't block in the apache travis CI queue.
- Personally, I agree with removing Spark 1.4 and 1.5. How about emailing this issue?
