Title

Configuration.update() must not send CM_UPDATED event

Description
The Configuration.update() method should just cause any configuration client (ManagedService or ManagedServiceFactory) to be updated with the current configuration. A CM_UDPATE event must not be sent in this case. [ Unlike the Configuration.update(Dictionary) which causes the CM_UPDATED event to be sent. ]
Discussion
- Fixed in Rev. 806062 indicating to the ConfigurationManager whether the CM_UPDATED event must be fired after the update or not.
- Close all issues now this version has been released
