Title

Form control's pristine attribute is not updated properly.

Description
I have a component that uses forms API. I use the `pristine` attribute of the control to check if data has been changed or not. But looks like it returns me _dirty_ only after a second change.

Example: I have a textbox where just blank spaces are not allowed. Right now, if I type just one space, then during validation, the control says that it is pristine. After any other change, the control becomes dirty, as far as the validators are concerned.
