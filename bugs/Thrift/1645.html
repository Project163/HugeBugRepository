Title

Appveyor builds reference an openssl version that is no longer there

Description
It looks like we download openssl 1.0.2g from an external site; the external site has revved to 1.0.2h so we need to update our URL.  As a general comment, our build should not depend on any external downloads or it will be continue to be fragile in this way (also see   THRIFT-3793  ).
