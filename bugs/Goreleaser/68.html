Title

getTag return incorrect tag, if we have more than 1 tag for 1 commit

Description
**Describe the bug**
**To Reproduce**

Steps to reproduce the behavior:
1. Create new repo
```
mkdir test_goreleaser && git init
touch test.txt
git commit -m 'test'
```
than create few tags:
```
$ git tag 0.10.1-rc.3
$ git tag 0.10.1-rc.4
$ git tag 0.10.1-rc.5
$ git log
commit   (HEAD -> master, tag: 0.10.1-rc.5, tag: 0.10.1-rc.4, tag: 0.10.1-rc.3)
... [Log Snipped] ...

    init commit
```

if you run goreleaser it will run under the hood (`git describe --tags --abbrev=0`):
release tag `0.10.1-rc.3`

**Expected behavior**
goreleaser will release latest tag `0.10.1-rc.5`

**Environment (please complete the following information):**

- OS: all
- GoReleaser Version: master
