Title

RevisionComparator my incorrectly report a revision as FUTURE

Description
The DocumentNodeStore periodically instructs the RevisionComparator to purge old seen-at revisions. The comparator will purge all seen-at revisions of a cluster node if there were no changes propagated from that cluster node. This will cause incorrect revision comparisons later, because now all revisions from the other cluster node are considered not yet seen.
