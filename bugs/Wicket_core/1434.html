Title

SubmitLink.onSubmit not invoked when using GET-method

Description
When using method GET on a form, onSubmit is not invoked on the submitting component, such as a SubmitLink. This is regression since 7.x. The attached quickstart renders 'form.onSubmit' for wicket 8.0.0-SNAPSHOT and 'link.onSubmit, form.onSubmit' for 7.9.0.
