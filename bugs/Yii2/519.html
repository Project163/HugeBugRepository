Title

Improve the documentation

Description
In [URL]

``` php
// allow multiple files to be uploaded:
echo $form->field($model, 'uploadFile[]')->fileInput(['multiple'=>'multiple']);

// allow multiple items to be checked:
echo $form->field($model, 'items[]')->checkboxList(['a' => 'Item A', 'b' => 'Item B', 'c' => 'Item C']);
```

**PROBLEM:** Periodically it (`'items[]'`) causes confusion for some people.
### Ex1 with items[]

``` php
$model = new \yii\base\DynamicModel(['items' => ['a', 'b']]);
$form = \yii\widgets\ActiveForm::begin();
echo $form->field($model, 'items[]')->checkboxList(['a' => 'Item A', 'b' => 'Item B', 'c' => 'Item C']);
$form::end();
```

[Image: image]
name of input is correct but **default value not setted.**

 
### Ex2 without items[]

``` php
$model = new \yii\base\DynamicModel(['items' => ['a', 'b']]);
$form = \yii\widgets\ActiveForm::begin();
echo $form->field($model, 'items')->checkboxList(['a' => 'Item A', 'b' => 'Item B', 'c' => 'Item C']);
$form::end();
```

[Image: image]

name of input is correct and **default value setted.**

Need to have finally add the sample code to set the initial values and the correct the documentation
(checkboxlist could be remove from the example for `items[]`).
