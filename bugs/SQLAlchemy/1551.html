Title

TypeDecorator pickling error in 2.0, works fine in 1.4.54

Description
### Discussed in [URL]

 

 Originally posted by **rad-pat** October 15, 2024 
When trying to upgrade to 2.0.35 from 1.4.54, we cannot because we get a pickling error in 2.0.35. 

I'm sure pickling queries is not the best way to transport between app layers, however it is currently being done in our app until I can update it. 

We have a couple of custom types to control behaviour across dialects where certain types are not yet supported. It's possible that some of them are not needed any longer. However, here is a very quick example of the pickling error in case it is something easy to address.

```
python
import pickle
import sqlalchemy as sa

class MyType(sa.TypeDecorator):
... [Log Snipped] ...
#        ^^^^^^^^^^^^^^^^^^^^^^^^^^
#_pickle.PicklingError: Can't pickle  : attribute lookup TDComparator on sqlalchemy.sql.type_api failed
```
