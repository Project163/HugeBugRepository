 Also we used to be able to create our own new MaximumProfileTable() but this is not public anymore.  

 You can't create any tables anymore, because FontBox can't write them. Basically FontBox is read-only, those setter methods were only for TTFParser in 1.8, which is why they're now private in 2.0. If you're wanting to manipulate a FontBox font then I'd recommend doing it like TTFSubsetter does and then just parse the result as a new FontBox font. I assume as you're writing to the font file you must be doing something somewhat similar at the moment (as FontBox doesn't support writing).
