Title

Missing line number in "multiple units" error report

Description
Error caused by syntactically incorrect less:

```
#first {
  // blah
}
#second {
  property: (1cm/1mm);
}
```

reports `line null,` as line number and unrelated code line instead of faulty line:

```
SyntaxError: Multiple units in dimension. Correct the units or use the unit function. Bad unit: cm/mm in c:\...\test.less on line null, column 0:
1   // blah
```

It should show syntactically incorrect line and its number:

```
SyntaxError: Multiple units in dimension. Correct the units or use the unit function. Bad unit: cm/mm in c:\...\test.less on line 6, column xxx:
6     property: (1cm/1mm);
```

Tested on less-1.4.0-b1 with windows node.js.
