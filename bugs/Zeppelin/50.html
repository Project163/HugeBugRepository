Title

Interpreter property 'spark.replClassServer.port' does not affect actual classServer port

Description
Code here  [URL] makes initialise SparkIMain  [URL] with empty SparkConf, so property with the user-set port number is not propagated.
Discussion
- For now, the workaround could be use  
  
 export ZEPPELIN_INTP_JAVA_OPTS=-Dspark.replClassServer.port=11111 
  
  inside  conf/zeppelin-env.sh
- Currently, it can be done by exporting environment variable like,  
  
 export ZEPPELIN_INTP_JAVA_OPTS= "-Dspark.replClassServer.port=11111"  
  

 I think   ZEPPELIN-95   will resolve this issue. Do you mind move fix version to 0.6.0 or something other?
