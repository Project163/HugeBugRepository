Title

CollectionAssert.AreEquivalent fails for ValueTuple Wrapped Dictionary

Description
The following code:

```
C#
var a = new Dictionary  d)>()
{
    { "key", ("name", new Dictionary ())}
};
... [Log Snipped] ...

CollectionAssert.AreEquivalent(a, b);
```
fails the assert with message:

```
  Expected: equivalent to  )] >
  But was:   )] >
  Missing (1):  )] >
  Extra (1):  )] >
```
I'm using the 3.10.1 release.
Discussion
- Actually, I think that the problem can be simplified as follows:
```csharp
            var a = new ValueTuple >("name", new Dictionary ());
            var b = new ValueTuple >("name", new Dictionary ());
            Assert.That(a, Is.EqualTo(b));
```
which gives
```
  Expected: ("name",  )
  But was:  ("name",  )
```
The problem is that we try to compare the values with `EquatablesComparer` before `TupleComparer`/`ValueTupleComparer`, and `EquatablesComparer` does not use `NUnitEqualityComparer` for the individual elements of the tuple, but just regular comparison and for Dictionaries this is regular reference equality. So the current code only works for tuples with elements that are compared using value equality.

The problem can probably be solved by moving `EquatablesComparer` to after `TupleComparer` and `ValueTupleComparer` in the list of `IChainComparer`  in `NUnitEqualityComparer`, but it requires some more thought than just a quick brainstorm from my side.
