Title

`postMessage` not injected by webview when loading svelte applcation with `bind:clientHeight`

Description
### **Describe the bug**
When loading a svelte application with `bind:clientHeight` or `bind:clientWidth` on one of the elements on the page, `window.chrome.webview.postMessage()` is undefined due to delayed firing of `DOMContentLoaded` event

### **To Reproduce**
Steps to reproduce the behavior:
1. Clone [Link: this] repo (or use `bind:clientWidth` on any component)
2. `yarn tauri dev && yarn dev`
3. Open Browser DevTools
4. See error



### **Expected behavior**
No Error
