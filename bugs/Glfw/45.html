Title

glfwGetMonitors not returning sleeping monitors

Description
Hi,

First of all let me thank you for GLFW. I think it is a very well run project (implementation wise, documentation, etc.)

I have a bunch of [Link: small test apps] that use GLFW, but after upgrading from GLFW 3.0 to 3.1 they refuse to run on MacOSX, because `CGDisplayIsAsleep()` returns true for the one and only monitor on the test machine.

I think it would be better to not fail in such case.  Not all OpenGL apps need user intervention, there are many cases where an app might want to run without user (e.g., automatic image processing, etc.)
