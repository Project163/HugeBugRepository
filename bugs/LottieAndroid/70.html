- Soon. You can also use snapshot builds if you really need it.
I think you're setting/clearing LottieDrawables on multiple threads though. This is likely caused by a race condition in which you're clearing LottieDrawable while the set one is buildings its rendering layers on a different thread. If you can work out how/why that's happening, you can probably avoid this crash. The specifics of your setup that is causing this is likely why others haven't encountered it.
