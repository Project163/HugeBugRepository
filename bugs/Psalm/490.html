Title

Should report issue when expanding variable in string that would produce issue with string casting

Description
When a class does not implement __toString(), casting a variable of that type to a string will cause Psalm to report an issue, which is all good. When you embed that same variable into a double quoted string for expansion, Psalm should report a similar issue.
