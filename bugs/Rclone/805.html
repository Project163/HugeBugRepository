Title

DLNA Browse+BrowseMetadata not to spec, angers pedantic client.

Description
#### The associated forum post URL from `[URL]

Irrelevant.

#### What is the problem you are having with rclone?

Rclone DLNA server doesn't conform to [Link: spec] when replying to a Browse request. Section  . _Argument Descriptions_ says it should include `NumberReturned` and `TotalMatches`.

[Link: Current rclone code] only returns `Result`.

This was discovered using the [Link: DLNA Digital Media Integration] in Home Assistant.

This results in a failure to browse and inability to go further. Granted, the client could be more tolerant. But the fix seems trivial and would probably benefit everyone.
