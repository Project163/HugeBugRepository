Title

Bundle-ClassPath contains "." despite using _wab instruction

Description
Since I didn't get much response in the forum  [1] , I am beginning to believe that it's not currently possible to easily build a WAB without "." in Bundle-ClassPath. It is important to have it fixed so that people can build valid web applications easily while using maven-bundle-plugin. While it is reasonably straight forward to build WABs with no embedded libraries, I have not found ways to build WAB with embedded libraries and yet no "." in BCP. Although I believe the fix should be in bnd as I suspected in the forum question I raised, it can also be in the plugin side if bnd is not changed.
