Discussion
- The tearDown() method first drops the test tables and then waits for the other threads to complete. If the other threads have more work when the test finishes, they may not find the tables since they've been dropped. Changing the order in tearDown() so that we wait for the threads to finish first, and then drop the tables, should fix this issue. See the attached patch.
