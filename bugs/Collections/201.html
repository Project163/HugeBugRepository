Title

MapUtils.getLongValue(Map , K, Function ) returns a byte instead of a long

Description
When using the following method 
  
 
org.apache.commons.collections4.MapUtils.getLongValue(Map<?  super  K, ?>, K, Function<K,  Long >)
 
  
 the resulting value no matter if it is the value returned by the defaultFunction or the value contained in the map is returned as byte: 
  
 
 return  applyDefaultFunction(map, key, MapUtils::getLong, defaultFunction, 0L).byteValue();
 
  
 The problem ist the final call to  byteValue() . If the returned value is greater than 127 the implicit cast back to a long will make it a negative number (e.g. the byte 0xaf/175 will become  /-81).
