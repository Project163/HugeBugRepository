Title

WASB: Update azure-storage-java SDK

Description
WASB depends on the Azure Storage Java SDK.  There is a concurrency bug in the Azure Storage Java SDK that can cause the results of a list blobs operation to appear empty.  This causes the Filesystem listStatus and similar APIs to return empty results.  This has been seen in Spark work loads when jobs use more than one executor core.  

 See  [URL] for details on the bug in the Azure Storage SDK. 

 This issue can cause data loss.
