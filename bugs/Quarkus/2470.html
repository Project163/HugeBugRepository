Title

Exception on deserialization of list of objects from JSON when using kotlin serialization

Description
### Describe the bug

When quarkus deserializes JSON body of POST method and

- kotlin serialization is used for JSON serialization
- JSON on top level contains array of objects (instead of single object) 

then error occurs.

### Expected behavior

Deserialization is done without errors. Objects are populated with data from JSON.

### Actual behavior

Next error occurs:
```
ERROR [io.qua.ver.htt.run.QuarkusErrorHandler] (executor-thread-1) HTTP Request to / failed, error id: d958fb94-6811-4bea-934a-affc35d22c2b-1: kotlinx.serialization.json.internal.JsonDecodingException: Expected JsonObject, but had JsonArray as the serialized body of kotlinx.serialization.Polymorphic  at element: $
JSON input: [{"number":773211},{"number":562867}]
	at kotlinx.serialization.json.internal.JsonExceptionsKt.JsonDecodingException(JsonExceptions.kt:24)
	at kotlinx.serialization.json.internal.JsonExceptionsKt.JsonDecodingException(JsonExceptions.kt:32)
	at kotlinx.serialization.json.internal.StreamingJsonDecoder.decodeSerializableValue(StreamingJsonDecoder.kt:400)
... [Log Snipped] ...
	at io.netty.util.concurrent.FastThreadLocalRunnable.run(FastThreadLocalRunnable.java:30)
	at java.base/java.lang.Thread.run(Thread.java:842)
```

### How to Reproduce?

1. Extract project [Link: serial-quarkus.zip]
2. In project directory run `./gradlew quarkusDev`
3. With any HTTP tool (Postman, CURL, etc) send `POST [URL] with next body
```
[
    {
        "number": 773211
    },{
        "number": 562867
    }
]
```
4. Error described above is produced.
