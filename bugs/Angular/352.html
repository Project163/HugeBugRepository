Title

i18n Xlif Load and Parse repeated calls (perfomance impact)

Description
**I'm submitting a ...**  (check one with "x")

[x] bug report => search github for a similar issue or PR before submitting

**Current behavior**

Actually, the xlif file used for translation seems to be loaded and parsed multiple times (one for each component in the app) wich lead to a severe loss in performances at bootstrap in our applications.

We've used the profiler in chrome to see why the bootstraping was taking so long (around 16 sec) :

[Image: xlifissue]

After that, we have setup a new repo with the minimal basics, based on the webpack config we are using, and our actual translation file and did the same : 

[Image: withourtranslationfile]

And finally, with the actual translation file of the repo : 

[Image: withnewfile]

**Expected behavior**

The Xlif file should be loaded and parsed once, and not for every component to avoid performance loss.
