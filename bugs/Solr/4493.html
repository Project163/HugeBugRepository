Title

solr admin ui: zkstatus: For input string: "null" with zk 3.6.x

Description
When i select in solr 8.5.1 webinterface: Cloud - ZK Status i got 
For input string: "null" 

 This happens after upgrading the leader to zookeeper 3.6.1 (upgrading the followers before was not a problem). From my view configuration is running, just the status web page doesn't. 
I remember that there was similar problem before with solr/zk version incompatibilities. From zookeeper documentation 3.6.1 should be fully compatible with 3.5 clients. 
Annoyingly there is no official zk 3.6.1 docker container available, but i think it is easy to reproduce.
