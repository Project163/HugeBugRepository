Title

Fullscreen not working for most resolutions

Description
GLFW reports various valid video modes on a Mac Book Pro Retina 15" early 2013:

```
640x480
800x600
1024x768
1280x800
1440x900
... [Log Snipped] ...
2560x1600
2880x1800
```

The first issue is that not all possible resolutions are reported. Here's what the display really supports according to SwitchResX, which also allows setting those modes:

[Image: [URL]

As a test, i simply modified [Link: simple.c], passing in any of the video mode resolutions that GLFW reports. Here's the results for various resolutions set in line 89, using the primary monitor:

800x600
[Image: [URL]

1280x800
[Image: [URL]

1440x900
[Image: [URL]

1680x1050
[Image: [URL]

2880x1800
[Image: [URL]

Only 1440x900 and 2880x1800 work. This seemed a bit to convenient (the latter being a multiple of the former), so i checked my system settings. Low and behold:

[Image: [URL]

It looks only resolutions that are a multiple of the currently set screen resolution work. To test this theory, i set the current scaled resolution to this:

[Image: [URL]

And as expected, only 1680x1050 worked, the others showed either a black screen or an incomplete triangle.

This must obviously have something to do with HDPI scaling. I used `GLFW_USE_RETINA` for this build.

Disabling `GLFW_USE_RETINA` does not help:

[Image: [URL]

I'd be happy to help any way i can to resolve this issue.
Discussion
- FWIW those additional modes are not officially supported by OS X. I believe SwitchResX might be using private Apple APIs which will get Mac App Store apps rejected. ResXtreme does the same thing: [URL]
- The full screen window positioning part of this appears to be a bug. I will look into it.

As for what video modes are exposed, have a look at `modeIsGood`.

Also FWIW, I don't think there are any valid reasons for games to change the resolution nowadays. It's slow, bug-prone, messes up window and monitor viewport positions, makes application switching flaky and on OS X forces you to choose between disabling Cmd+Tab and messing up the desktop icons, all of which annoys users. If you want to render at a lower resolution, render to a texture. **Edit:** But that doesn't mean I won't fix bugs related to mode switching.
