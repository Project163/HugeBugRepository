Title

Nested functional selector goes cuckoo

Description
[URL]

LESS:

```
ul{
    li{
        &:nth-child(odd):not(:nth-child(3)){
            color: #ff0000;
        }
    }
}
```

HTML:
     
         
             
             
         
             
                 Bo 
                 ll 
                 oc 
                 ks 
                 !! 
             
         
     

It is the `)` before `{` not being accepted.

No existing workaround yet unless you are filtering first or last element, you may replace `nth-child` with `first-child` or `second-child`.
