Title

Inconsistent handling of final fields

Description
Snippets v1 and v2 below are equivalent but v1 compiles and v2 does not. v1 should also not compile. 

   v1   
  class  Test {
     private   final   String  prop = ""
    void setProp(val) {
         this .prop = val  /* compiles, when it shouldn't */ 
    }
}
 
  

   v2   
  class  Test {
     private   final   String  prop = ""
    void setProp(val) {
        prop = val  /* correctly fails to compile saying  "cannot modify  final  field  'prop' "  */ 
    }
}
