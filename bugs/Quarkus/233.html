Title

${project.groupId} does not work well with Maven 3.6.2

Description
Just reported [URL] 

What it means for Quarkus: If you are building the Quarkus source tree using Maven 3.6.2, Maven will take the latest release (currently 0.22.0) of `quarkus-maven-plugin` instead of the extpected `999-SNAPSHOT`. We either have to stay with Maven 3.6.1 or we have to replace `${project.groupId}` with `io.quarkus`.
Discussion
- Why are we actually using `${project.groupId}`?
- No real reason I suppose except we had plans to rename the project, which we did.
- Robert Scholte [Link: says]


So replacing `${project.groupId}` with `io.quarkus` might be the preferred solution.
