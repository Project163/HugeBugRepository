Title

Some minor bugs in Postgres Driver (invalid reference to 'key' attribute)

Description
I was actually going to issue a pull request but am not quite sure how to make that happen. So far I've cloned the repository, made suggested bug fixes in a new branch and committed the branch (locally). I'm not sure what to do after that.

Anyway, the issue is with the postgres driver (system/database/drivers/postgre/postgre_driver.php) which errors if using a connection string (with extra options) to connect to the database. When cycling over the options there are several references to $this->key that should read $this->$key.

Also, a fairly common option (sslrootcert) is missing from the list.
