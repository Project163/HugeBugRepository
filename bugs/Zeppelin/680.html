Title

Minor focus transfer issue while navigating through paragraphs with keyboard

Description
Suppose we have three paragraphs Para-A, Para-B, Para-C. In A and B, the editor is hidden 

 When I use down arrow to navigate between paragraphs(one's with editors hidden) 
It jumps directly from Para-A to Para-C 

 But, if I go up using keyboard up-arrow 
The focus is transferred as Para-C -> Para-B -> Para-A 

 Please see the screenshots
