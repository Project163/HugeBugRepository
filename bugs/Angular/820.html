Title

[ivy] ERROR in Expected array when reading property exports using concat()

Description
# 🐞 bug report

### Affected Package
 
  The issue is caused by package @angular/cli ?


### Is this a regression?

 
  NO


### Description
When using .concat() to concat two arrays in the `exports` field of a Module, ivy throws an 
`ERROR in Expected array when reading property exports`

The compiled version of the package `@swimlane/ngx-charts` contains such an concat() that seems to prevent ivy to recognize the export variable as array. 
Removing `concat()` and merge the arrays by hand resolves the error. 
Since `concat()` returns an `Array` itself, I see the issue in angular / ivy, not in the ngx-charts package.
