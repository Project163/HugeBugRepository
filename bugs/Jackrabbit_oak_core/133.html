Title

Log (slow) queries

Description
Queries should be logged if the log level is set to debug. 

 In addition to that, arguably very slow queries should be logged with level warning.
Discussion
- The first part is implemented in revision 1404899
- In revision 1408729, after each 100 traversed nodes, a log message with level warning is written: "Traversed <count> nodes with filter <filter and query statement>; consider creating an index or changing the query". 

 This will not detect all slow queries (only those that traverse the repository), but let's leave it at that for now.
- There are queries that use an index but are still quite slow, because the index is very unspecific (for example an index on a basic node type). Such queries should also be logged. 

 Also, logging once per 100 nodes is too much it seems. Logging once per 1000 nodes should be enough.
