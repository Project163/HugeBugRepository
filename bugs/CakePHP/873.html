Title

i18n causes problems in new Validator/ORM when used outside of framework

Description
This is a (multiple allowed):

* [x] bug

* CakePHP Version: 3.4.9
* Platform and Target: [Link: Homestead Improved] VM on OS X

### What you did
Only using ORM. ORM seems to be requiring Validator, which now requires i18n (didn't before). i18n needs the `_cake_core_` cache config value (if Cache is installed, and it is), but has no defaults it uses if this value is not installed.

### What happened
At this point, Cache crashes because it can't find this value.

### What you expected to happen
Ignore the absence of this value by using defaults, or don't pay attention to i18n at all since the app doesn't make use of it. Alternatively, make it easier to set config options for this in projects that don't use the framework but just some components.
