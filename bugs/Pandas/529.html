Title

drop_duplicates regression with variable name

Description
I just updated to master and now this doesn't work.

```
df = pandas.DataFrame([1,1,2,2,3,3,4,5], columns=['variable'])
df.drop_duplicates('variable')
```

I believe cfe674e is the offending commit. A string is iterable but we don't want to iterate over it.
Discussion
- thanks. the danger of using 1-letter variable names in unit tests
- My mistake, i introduced the np.iterable(cols) check to close another ticket, but did not think about the scenario where cols can be a single column label that is iterable. Like a _string_, which is covered now by @wesm his fix, and also _tuple_ (which is still a problem), others? Maybe better to check if cols is in self.columns and if not, go from there to iterate or not.
