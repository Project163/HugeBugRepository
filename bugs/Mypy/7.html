Title

Keep track of types of stack frame locations (int vs non-int)

Description
The C back initializes all stack frame locations to 0, which is wrong for reference types. Initialize reference types to None. 

The following changes are needed:
- Icode generation keeps track of the types of registers. This includes locals (and  
  function arguments, though they don't have to be initialized).
- Register initialization in the generated C depends on the type.
Discussion
- Actually this is really only needed for variables. Temporaries are always initialized explicitly.
