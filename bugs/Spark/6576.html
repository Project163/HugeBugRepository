Title

Update the docs for spark.sql.statistics.fallBackToHdfs

Description
Size in bytes of the query is coming in EB in case of parquet datasource. this would impact the performance , since join queries would always go as Sort Merge Join. 

  Precondition :  spark.sql.statistics.fallBackToHdfs = true 

 Steps:

 +---------+--+

+---------+--+
