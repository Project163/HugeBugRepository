Title

Pretty print leaves extra space at end of many lines

Description
This one demonstrates far easier.  At end of most lines, there is an extra whitespace being added.  This should be trimmed so there is no extra whitespace at end of tags.

Discussion
- A fix can either be added to the code, or if you're doing in yourself you could add `"String".stripTrailing()` to remove the trailing whitespace from a string.
- we have it fixed on our end but prefer its fixed in the source of the issue.

Here is how.

```
/** The Constant REMOVE_TRAILING_PATTERN. */
private static final Pattern REMOVE_TRAILING_PATTERN = Pattern.compile("\\p{Blank}+$", Pattern.MULTILINE);
...
// Fixing trailing space issue caused by jsoup
formattedCode = REMOVE_TRAILING_PATTERN.matcher(formattedCode).replaceAll("");
```

This approach covers entire file at one go.
