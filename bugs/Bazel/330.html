Title

IllegalStateException in CyclesReporter when you have a folder named "workspace"

Description
Please provide the following information. The more we know about your system and use case, the more easily and likely we can help.

### Description of the problem / feature request / question:

We have a folder called bazel/workspace with a .bzl file in it and when we try to load this .bzl file we would encounter an IllegalStateException when we do bazel build ...

When the folder is renamed to "verification" the build works.  I think it is due to some changes in cycle detection.  This seems to have started happening in 0.4.1.
