Title

UrlStr gives unhelpful validation errors

Description
# Bug

For bugs/questions:
* OS: macOS
* Python version `import sys; print(sys.version)`: 3.7.1
* Pydantic version `import pydantic; print(pydantic.VERSION)`: StrictVersion ('0.25')

Here's a short example:

```
py
...     url: urlstr(schemes={'postgresql'}, require_tld=False) = ...
... 
... [Log Snipped] ...
url
  url string does not match regex (type=value_error.url.regex)
```

So, couple of problems:

- This url is valid, it works ;-) 
- "does not match regex" isn't at all helpful to the end user, we should at least include the pattern being matched.
