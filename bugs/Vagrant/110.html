Misleading plugin error after vagrant update.

Description
### Vagrant version
After updating vagrant basically every vagrant call resulted in a plugin error.

Before upgrade:
Installed Version: 1.8.6
After upgrade:
Installed Version: 1.9.3

N/A

### Expected behavior

1) 'plugin expunge --reinstall' shouldn't result in more plugin errors.
2) The error message should suggest trying 'vagrant plugin update', which fixed the problem for me:

 space@FeTap.local$ vagrant plugin update
Updating installed plugins...
Updated 'vagrant-share' to version '1.1.7'!

After this everything worked like expected again.

### Actual behavior

Neither 'vagrant plugin repair' nor  'plugin expunge --reinstall' fixed my post ugrade plugin errors.

### Steps to reproduce
1. Upgrade vargant  1.8.6 to 1.9.3 with an incompatible version of vagrant-share installed.
