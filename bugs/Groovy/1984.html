Discussion
- I could reproduce outside of GMock. It was a call site caching bug introduced by    GROOVY-5730  . 

 Test case: 
  
  class  Groovy5806Bug  extends  GroovyTestCase {

    void doWork(code) {
        code.call();
    }

    void testCallSiteCachingOfCallMethod() {
         try  {
            ExpandoMetaClass.enableGlobally()
            10.times {
                doWork {
                    println  'ok' 
                }
            }
            doWork( new  Callable() {
                def call() {
                    println  'callable' 
                }
            })
        }  finally  {
            ExpandoMetaClass.disableGlobally()
        }

    }
