```
private void index() throws IOException {
    for (int i = 0; i   without a sort not all docs get updated for a query).

Later I introduced new Date().getTime() in indexing function (so I can sort on it) and added .addSort("postDate", SortOrder.ASC) in a scroll query, but unfortunately at the same time I introduced an automatism in testing where in test function I call:

```
    index();

```

    } catch (InterruptedException e) {
        e.printStackTrace();
    }
    scrollUpdate();
```

or 

```
    index();
    client.admin().indices().prepareRefresh().execute().actionGet();
    scrollUpdate();
```
