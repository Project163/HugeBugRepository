Title

@CompileStatic class property accessed instead of map property

Description
class  MyMap  extends  LinkedHashMap {
  def foo = 1
}

@CompileStatic
 class  Main {
   static  void main( String [] args) {
    def map =  new  MyMap()
    map.put( 'foo' , 42)
    println map.foo  // 1 is printed, should be 42
   }
}
