Title

NPE in ClassLoaderUtils

Description
A NullPointerException can be thrown when the JVM's boot classloader is set as the thread's context classloader.  Ex: 

 URL url = Thread.currentThread().getContextClassLoader().getResource(resourceName); 

 The call to getContextClassLoader() could return null - that is a valid return from that method.  In that case, we should use ClassLoader.getSystemClassLoader() instead.

       CXF-7349  : NPE when thread context classloader is null 

     A null context classloader is valid - it means that the JVM's boot classloader is the context.  When using the ClassLoaderUtils class, there are a few places where we get the thread's context classloader, but don't check it for null before invoking methods on it - such as getResource/getResources/etc. 

     This change ensures that we get a non-null classloader by using the system classloader when the current thread context classloader is null.
