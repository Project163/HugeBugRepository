Title

RssHelper adding .rss to all links

Description
$entryLink always ends up with a .rss at the end, adding _ext => false does nothing to rectify.

[URL]
Discussion
- I tried reproducing but was not able to. Using your routes.php, I put the following in a view template:

``` php
 Url->build(['controller' => 'Tasks', 'action' => 'index', '_ext' => false]) ?>
```

It correctly output `/tasks`. But by default it was including the `.rss` extension as you pointed out. However, I don't think that generated URL's should automatically pick up the extension from the request they were generated in. This was not how Router behaved in 2.x and feels like an accidental regression, not a 'feature'.
- Closing as there is a pull request up now.
