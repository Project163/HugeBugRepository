Title

Schema already declared on first addSchema within decorated function

Description
## 🐛 Bug Report

If `.addSchema` is called within decorated function (using `fastify.decorate`) it throws an error that such schema already exists, however it is called only once

## To Reproduce

Steps to reproduce the behavior:

```
js
const fp = require('fastify-plugin');
const app = require('fastify')();

app.register(
... [Log Snipped] ...
  console.log('app started');
})();
```

## Expected behavior

App starts without errors.

## Your Environment

- *node version*: 11.10.0
- *fastify version*: >1.13.4 & <2.0.0
- *os*: Mac, Linux

NOTE: this bug reproduces only on fastify v1.X.X. On fastify v2.X.X it works fine.
