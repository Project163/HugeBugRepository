Title

The VFS transport sender should trigger an error when used with the wrong message exchange pattern

Description
VFS is an out only transport and doesn't support synchronous responses. To avoid issues like   SYNAPSE-543  , the transport sender should trigger an error when invoked with the wrong (out-in) message exchange pattern.
