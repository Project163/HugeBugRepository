Title

Complete quoting for parameters of some CMake commands

Description
Some parameters (like "[Link: ${CMAKE_HOME_DIRECTORY}/lib]" and "[Link: ${ASSIMP_LIB_INSTALL_DIR}]") are passed to CMake commands in your build scripts without enclosing them by quotation marks. I see that these places will result in build difficulties if the contents of the used variables will contain special characters like spaces.
