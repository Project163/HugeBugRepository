Title

Cannot tell diff between percentages and pixels

Description
when using guards less cannot tell the diff between percentage values and pixels.

``` css
@width = 100px;

.mixin(@a) when (@a = 100%) {
color:black;
}

.mixin(@width);
```

will cause .mixin to pass the test and have the color black;
Discussion
- you can use the is functions to get round this.. but equally i see your point.
- 100% != 100px, so to me, that's a definite bug.

I would expect LESS to evaluate like this:

``` css
@width: 100px;
.mixin(@width);
.mixin(@a) when (@a = 100%) {}  // FALSE, not the same type (implicit unit comparison)
.mixin(@a) when (@a = 100) {}  // TRUE, has the same numerical value
```
