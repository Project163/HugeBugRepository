Title

[YSQL] YbGate does not properly clean up after error

Description
Jira Link: [Link: DB-10115]
### Description

```
#define PG_STATUS_OK() \
		} \
		else \
		{ \
			YbgStatus status = (YbgStatus) YBCPgSetThreadLocalErrStatus(NULL); \
... [Log Snipped] ...
		return (YbgStatus) YBCPgSetThreadLocalErrStatus(NULL); \
	} while(0)
```
The `else` block (long jump handler) does not reset the jump buffer.
It shouldn't cause issues if YbGate is coded properly, that is all PG code invocations are surrounded by PG_SETUP_ERROR_REPORTING/PG_STATUS_OK, but if it is not, segmentation fault is possible instead of proper error.
Currently PG code is invoked without PG_SETUP_ERROR_REPORTING/PG_STATUS_OK only in tests, and tests failures are possible if tests run in certain order.
