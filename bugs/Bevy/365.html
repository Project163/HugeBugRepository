Title

Taffy rounding bug can cause UI nodes to expand each update

Description
## Bevy version

main   

## What you did

```
rust
use bevy::prelude::*;
use bevy::window::WindowResolution;

fn main() {
... [Log Snipped] ...
        });
}
```

## What went wrong

[URL]

The inner leaf node expands by a physical pixel each time the UI updates.

The problem is with how Taffy rounds the layout coordinates. The rust `round` function rounds away from zero, so x bounds from  -100.5 to 99.5 (width 200) will be rounded to -101 to 100 (width 201), gaining a pixel.

The accumulated error resets after a full update (triggered when the window is resized or the scale factor changes).
Discussion
- Replicated in Taffy: [URL]
- Fixed the example, previously it would only show the bug with window scale factor at specific values like `1.5`. Now it overrides the window scale factor and should work for all configurations.
- The Taffy fix for this has now landed in `v0.3.13`
