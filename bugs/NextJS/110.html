Title

Cms-cosmic example uses image domain that's not in next.config.js

Description
### What example does this report relate to?

cms-cosmic

### What version of Next.js are you using?

12.0.4

### What version of Node.js are you using?

7.20.3

### What browser are you using?

Chrome

### What operating system are you using?

Windows

### How are you deploying your application?

next 

### Describe the Bug

## Summary
The cms-cosmic example uses images from the following domain `'imgix.cosmicjs.com'` but that domain is not listed in the `next.config.js` file.
 
To fix the problem it needs to be listed as an external domain as explained in [URL]


### Expected Behavior

I expect the example to work out of the box following it's readme.

### To Reproduce

### Steps
I've downloaded the example with
```
npx create-next-app --example cms-cosmic cms-cosmic-app
```
After installing it and running `npm run dev` I got the following output:
```[bash]
event - compiled successfully in 129 ms (552 modules)
error - node_modules\next\dist\client\image.js (660:33) @ defaultLoader
Error: Invalid src prop (https://imgix.cosmicjs.com/8efcc570-9a21-11ea-bf2a-2b6ff88d4f06-e73aee30-1db0-11ea-a594-a170ead8b2cb-12.jpg?auto=format,compress,enhance&w=100&h=100) on `next/image`, hostname "imgix.cosmicjs.com" is not configured under images in your `next.config.js`
See more info: [URL]
null
```
