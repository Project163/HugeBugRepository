Title

Qute: `this` usage in `each`

Description
[URL] says:

```
 
{#each items}
   
  {#item this showImage=true /} 
   
{/each}
 
```

I disagree that `this` is meaningful in this context. We already have a default name for the iterated item and it's `it`. We should be passing `it` and not resolve something arbitrary for `this`.
Discussion
- That's a bug in docs. We use `it` in the loop section. See also [URL]
- Well, given the footnote of "this is resolved to an iteration element and can be referenced using the it key in the tag template." I thought this was intentional.

But OK, great, thanks.
