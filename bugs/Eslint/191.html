Title

Unable to set no-mixed-requires when in node env

Description
Hello!

This issue is similar to #1108 however a little different.

My `.eslintrc` files looks like: 

```
{
      "env": {
            "node": true
      },
      "rules": {
            "no-mixed-requires": 0
      }
}
```

However when I lint a file that looks like:

```
var _               = require('lodash'),
    http            = require('http'),
    xml             = require('xml'),
    pingList;
```

Eslint still throws an error that you shouldn't mix require with other declarations.

I believe that the `rules` object should overwrite the `env` definition however it does not appear to be the case.
