Title

named function expression shadowed via var declaration breaks code

Description
What steps will reproduce the problem? 
1. create a variable with same function expression name but different value
2. try to operate as expected with that variable
3. see code breaking for no reason

var o = {
    draw: function draw() {
        var draw = [];
        return draw.push(123);
    }
};

// compiles into
var o={draw:function draw(){draw=[];return draw.push(123)}};
// problem is in draw=[]

 What is the expected output? What do you see instead? 
expected output is 1
I see an error since function draw has no method push
The fact a variable has same function expression name means the function expression name could be removed from its inner scope since var sameName will shadow it in any case.


 What version of the product are you using? On what operating system? 
it does not matter, the output is wrong


 Please provide any additional information below. 
Function declarations do not have this problem.
Whenever this is a good technique or not, there is a logic problem with the parser when function expression name is shadowed.

Same happens within a closure:
this.o = (function(){
    return {
    draw: function draw() {
            var draw = [];
            return draw.push(123);
        }
    };
}());
