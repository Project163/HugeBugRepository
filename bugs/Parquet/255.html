Title

Dictionary filter fails on FIXED_LEN_BYTE_ARRAY

Description
DictonaryFilter does not handle FIXED_LEN_BYTE_ARRAY. Moreover,  DictionaryFilter.expandFilter(ColumnChunkMetaData)  returns an empty map instead of null therefore the row-group might be dropped as the value seems to not being in the dictionary.
