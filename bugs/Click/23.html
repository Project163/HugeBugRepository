Title

Bug: Optional value not optional anymore

Description
### Outline

As stated in [Link: official documentation]: 

Since 8.3.0 this doesn't work anymore, instead `SystemExit` with "Error: Option '--xyz' requires an argument." is thrown.

### Replication of bug

Example taken from documentation:
```python
@click.command()
@click.option("--name", is_flag=False, flag_value="Flag", default="Default")
def hello(name):
    click.echo(f"Hello, {name}!")
```

```shell
$ hello --name
Error: Option '--name' requires an argument.
```

### Expected behavior

The code example above should work as
```shell
$ hello --name
Hello, Flag!
```

It's not even working in the generated documentation anymore: while [Link: documentation up to Sep, 10th] shows the expected and correct behavior, [Link: current documentation] demonstrates the bug.

- Python version: 3.11
- Click version: 8.3.0
