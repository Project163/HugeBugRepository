Title

[YSQL][ASH] YSQL samples have incorrect wait event aux

Description
Jira Link: [Link: DB-9984]
### Description

Aux info for YSQL samples should not be tablet-id. These  Right now, while fetching YSQL samples, aux info should be cleared out.

Steps to reproduce

1. Start a cluster with these flags

```
bin/yb-ctl start --tserver_flags="TEST_yb_enable_ash=true,ysql_pg_conf_csv='yb_ash_sampling_interval=10'"
```

2.  Fire this query

```
select
  query_id, wait_event_component, wait_event_class, wait_event, wait_event_aux, count(*)
from yb_active_session_history
group by query_id, wait_event_component, wait_event_class, wait_event, wait_event_aux
order by query_id, wait_event_component, wait_event_class, wait_event_aux;
```

3. You might see some samples with the component `Postgres` and non-null wait_event_aux

```
       query_id       | wait_event_component | wait_event_class |             wait_event             | wait_event_aux  | count 
----------------------+----------------------+------------------+------------------------------------+-----------------+-------
 -  | Postgres             | TServerWait      | CatalogRead                        | dd1d22a58b614ab |     1
 -  | Postgres             | YsqlQuery        | QueryProcessing                    | a5f5264c614d44e |     1
 -  | YCQL                 | Client           | YBC_WaitingOnDocdb                 |                 |     1
```
