Title

Tests are hanging when using a Kafka consumer and the mailer.

Description
**Describe the bug**
Tests are hanging when using a Kafka consumer and the mailer.
The simple POC provide a simple kafka consumer and just a dependency to `quarkus-mailer` to describe this bug.

**Expected behavior**
At the end of the test we should see this message:

`2019-10-24 13:15:54,718 INFO  [io.sma.rea.mes.ext.MediatorManager] (main) Cancel subscriptions`

Next junit should stop and display tests statuses.

**Actual behavior**

The subscription is not canceled. Tests are hanging forever.

**To Reproduce**
Steps to reproduce the behavior:
1. git clone [URL]
2. start containers by running `run_containers.sh` script (warning: it will kill and remove all running containers)
3. execute test by running `mvn clean test`

**Configuration**
application.properties is provided in the POC.

**Additional context**

My objective is to be able to consume events from kafka to send mails from them.

- @cescoffier I started looking into this and it seems that when adding the mailer, `io.smallrye.reactive.messaging.kafka.KafkaSource#closeQuietly` waits forever in `latch.await()`.
I got as far as being able to see that this happens because the task in 

```
            this.consumer.close(ar -> {
                if (ar.failed()) {
                    LOGGER.debug("An exception has been caught while closing the Kafka consumer", ar.cause());
                }
                latch.countDown();
            });
```

never gets executed because in `io.vertx.kafka.client.consumer.impl.KafkaReadStreamImpl#close` 

the task in 

```
        this.context.runOnContext(v -> {
          this.worker.shutdownNow();
          if (completionHandler != null) {
            completionHandler.handle(Future.succeededFuture());
          }
        });
```

does not get executed due to `io.vertx.core.impl.ContextImpl#runOnContext` failing. Now of course the real question is what does mailer do that could cause such a failure.
