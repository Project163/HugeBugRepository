- I want to see the model labels in placeholders. For this feature I set 'fieldConfig' property in ActiveForm config. There are problem when I use widget to render field.

` field($model, 'name', ['inputOptions' => ['placeholder' => 'one nice placeholder']]) ?>`
Generates input with placeholder

` field($model, 'phone', ['inputOptions' => ['placeholder' => another placeholder']])->widget(MaskedInput::className(), ['mask' => '+7 (999) 999-99-99']) ?>`
There are no placeholder
- ... [Middle Discussions Snipped for Brevity] ...
- It works great when I set widget placeholder directly:

` field($model, 'phone')->widget(MaskedInput::className(), ['mask' => '+7 (999) 999-99-99', 'options' => ['placeholder' => 'Your phone here']]) ?>`

The problem occurs because widget "options" not set from "inputOptions" property in "widget" function.

MaskedInput support placeholder. Mask renders only when mouse on.

The solve of this issue is in the first post.
- if the $config params not include options key already this lines case error

`        foreach ($this->inputOptions as $key => $value) {
            if (!isset($config['options'][$key])) {
                $config['options'][$key] = $value;// need to add $config['options'] = [];
            }
        }`
