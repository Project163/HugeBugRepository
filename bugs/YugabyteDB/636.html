Title

[YSQL] pg_hint_plan doesn't clean up its global hint state

Description
Jira Link: [Link: DB-627]
### Description

pg_hint_plan doesn't clean up its global hint state variable `current_hint_retrieved` after execution. In effect, if a connection were to receive a hintless query and set `current_hint_retrieved` to `true`, any further queries would not have their hints parsed unless they were to reset this variable. ~~Non-utility queries using the extended query protocol only reset this in the Parse stage~~. (CORRECTION: Non-utility queries that are using custom plans with the extended query protocol only reset this in the parse stage). Therefore, any previous parsed query that tried to bind and replan when `current_hint_retrieved` has been set to `true` will not have their hints parsed, effectively ignoring the hint.
Discussion
