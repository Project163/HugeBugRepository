Title

Literal short-hand does not resolve local references

Description
Reported by Micheal Brand on gitter.

**I'm submitting a ...**  (check one with "x")
```
[x] bug report => search github for a similar issue or PR before submitting
```

**Current behavior**

When collecting metadata for an object literal, local references are not resolved correctly resulting in an external reference which fails during compile.

**Expected behavior**

Local (non-exported) values should be correctly collected.

**Minimal reproduction of the problem with instructions**

Run the collector on the following source:

```
const children = { f1: 1 };
export const r = {children};
```

Expected: the value should be collected as `{ children: { f1: 1 } }`.
Received: a reference to global `{ __symbolic: 'reference', name: 'children' }`.
