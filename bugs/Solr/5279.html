Title

V2 API: Raw uploads should use correct content-type: application/octet-stream not JSON

Description
When the V2 Upload file API is called, the content-type header indicates JSON but actually it's anything, probably not JSON.  The general type is "application/octet-stream".   

 Furthermore, for non-raw, JacksonContentWriter is used but it should not accept the content type as a param; Jackson is always JSON (notwithstanding CBOR/Smile but we don't do that now).
