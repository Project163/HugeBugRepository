Title

WebPage cannot find the head container if TransparentWebMarkupContainer is associated with

Description
If a page uses TransparentWebMarkupContainer to set some attributes to the <html> tag then org.apache.wicket.markup.html.WebPage.validateHeaders() cannot find the HtmlHeaderContainer because it expects to find it at the first level of children tree.
Discussion
- A quickstart demonstrating the problem. 

 A log message similar to: 
ERROR - WebPage                    - You probably forgot to add a <body> or <head> tag to your markup since no Header Container was  
found but components were found which want to write to the <head> section. 
<link rel="stylesheet" type="text/css" href="someCss" />

is logged.
