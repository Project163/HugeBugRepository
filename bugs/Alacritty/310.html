Title

RegexSearch fails if line wraps at full width character

Description
If a line wraps at a full width character, search fails:

```
use alacritty_terminal::{
    index::{Column, Direction, Line, Point, Side},
    term::{search::RegexSearch, test::mock_term},
};

... [Log Snipped] ...
    assert_eq!(matched, Some("broken例search".to_string()))
}
```
Discussion
- I'm surprised this was working for fullwidth characters wrapping into fullwidth characters, which is likely why it wasn't noticed before. #8587 should fix it, hopefully without introducing any other fullwidth regressions.
