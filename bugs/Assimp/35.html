Title

VS2013 failed to build v5.0.0

Description
The Visual Studio 2013 build currently fails with the 5.0.0 release. This seems to be due to the lack of implementation bracket list initialises since Visual Studio 2013 Update 3 (Update 4 is current). Here is an example of the errors emitted (there are 114 of them, all similar):

```
Error   1   error C2797: 'Assimp::BaseImporter::importerUnits': list initialization inside member initializer list or non-static data member initializer is not implemented (C:\Temp\assimp-5.0.0\code\Common\ImporterRegistry.cpp) C:\Temp\assimp-5.0.0\include\assimp\BaseImporter.h  203
```

This is the problematic part of the file.

```
    std::map  importerUnits = {
        {ImporterUnits::M, 1},
        {ImporterUnits::CM, 0.01},
        {ImporterUnits::MM, 0.001},
        {ImporterUnits::INCHES, 0.0254},
        {ImporterUnits::FEET, 0.3048}
    };
```

I've attempted using `std::make_pair` on the inner list instead but that doesn't help. I'm sure someone else already knows the proper fix.
