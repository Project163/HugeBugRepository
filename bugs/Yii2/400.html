Title

oci schema map wrongly NUMBER dbType to either type INTEGER or DECIMAL

Description
In /yii2/db/oci/Schema.php
extractColumnType method wrongly map NUMBERS to INTEGER or DECIMAL.

According to Oracle documentation
[URL]

When scale is 0 the number should be treated as an integer.
But if "If a precision is not specified, the column stores values as given."
As I tested, even is is not clear from the docs, this override the scale.

So if the NUMBER column has scale=0 and precision=0 a double value is stored correctly.
