Title

Cannot create console controller in advanced app

Description
I've been searching for hours why this doesn't work, so I'm considering the possibility of some a bug.

I'm trying to add a console controller to my app, which is based on the advanced template.

I have created a controller with filename `XmlController.php` in `console/controllers`:

```
php
  'console\controllers',
    'controllerMap' => [
        'xml' => [
            'class' => 'console\controllers\XmlController'
        ],
    ]
```

When I run `php yii help` the xml command is listed among the available commands, but when I try to run my newly created xml controller using `php yii xml`, I get the following error:

```
exception 'ReflectionException' with message 'Class console\controllers\XmlController does not exist' in /Users/username/Sites/projectname/vendor/yiisoft/yii2/yii/BaseYii.php:374

... [Log Snipped] ...
#6 /Users/username/Sites/projectname/yii-dev(22): yii\base\Application->run()
#7 {main}
```

I checked the file permissions, the file is 100% sure in the right directory, and the namespace seems correct to me. Anyone got an idea why this won't run?

Thanks!
