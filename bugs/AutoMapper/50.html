Title

UseDataSource() with property-path expression leads to exception

Description
given the following DTO hierarchy

 
private class Master
        {
            public Master()
            {
                Details = new HashSet();
            }
            public Guid Id { get; set; }
            public string Name { get; set; }
            public ICollection Details { get; set; }
        }

        private class Detail
        {
            public Guid Id { get; set; }
            public string Name { get; set; }
            public Master Master { get; set; }
        }
 

the following expression fails to be mapped

 
var detailDtoQuery = detailQuery.UseAsDataSource()
                .OnError(ex => exceptions.Add(ex))
                .For()
                .Where(d => d.Master.Name == "Harry Marry");
 

To fix it, you just need to rename one of the "Name" properties. Problem is that the outer Expression (of type DetailDto) is used to retrieve the property "Name" and thus the MethodInfo points to the wrong class (DetailDto).
