Title

right-aligned text panic

Description
## Bevy version

0.11 & main

## What you did
```
rust
use bevy::prelude::*;

fn main() {
    App::new()
... [Log Snipped] ...
    );
}
```

## What went wrong
```
thread 'Compute Task Pool (3)' panicked at 'min > max, or either was NaN. min = 15.000002, max = 10.000001'
```

This bug was reported before on [Link: discord] but without a replication

##  Additional Details

The horizontal bounds for right-aligned text containing spaces are calculated incorrectly. In the example above the space is counted twice causing the min-content-width to be larger than the max-content-width, causing a crash when the measure func attempts to clamp the available space.
Discussion
- The key is the missing colon in the first line of the text:
```rust
format!("JustifyContent: {justify_content:?}\nTextAlignment::{text_alignment:?}")
```
Fix it:
```rust
format!("JustifyContent: {justify_content:?}\nTextAlignment::{text_alignment:?}")
```
The example no longer panics:

 JustifyContent:
----------------->End
TextAlignment::Right


and the max-content-width version should be like this:

-JustifyContent: End
TextAlignment::Right
- Got it, with `TextAlignment::Right` it`s adding extra space between the text and the right edge.
