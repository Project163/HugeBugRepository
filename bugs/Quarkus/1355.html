Title

Missing Logs when using async logs and have wrong config

Description
### Describe the bug

If i have the wrong value in my application configuration (for example mongodb connection string) while async logging is enabled:

```
quarkus:
  log:
    console:
      async: true
  mongodb:
    connection-string: wrongValue
```

The app crashes without any error logs,

If however I disable log async:

```
quarkus:
  log:
    console:
      async: false
  mongodb:
    connection-string: wrongValue
```

This error appears:

```
2021-10-08 10:11:09,170 ERROR [io.qua.run.Application] (main) Failed to start application (with profile local): java.lang.IllegalArgumentException: The connection string is invalid. Connection strings must start with either 'mongodb://' or 'mongodb+srv://
        at com.mongodb.ConnectionString. (ConnectionString.java:290)
        at io.quarkus.mongodb.runtime.MongoClients.createMongoConfiguration(MongoClients.java:251)
        at io.quarkus.mongodb.runtime.MongoClients.createMongoClient(MongoClients.java:107)
        at io.quarkus.mongodb.runtime.MongoClientRecorder.mongoClientSupplier(MongoClientRecorder.java:45)
... [Log Snipped] ...
        at io.quarkus.runtime.Quarkus.run(Quarkus.java:119)
        at mt.com.ecabs.bookingdata.BookingDataApplication.main(BookingDataApplication.java:9)
```

### Expected behavior

The same error message should be available in logs to identify the issue

### Actual behavior

No log is message

### How to Reproduce?

1. Enable async logging
2. use a wrong connection string for mongodb
3. Start the application
