Title

ip_address() hangs when reverse proxy is IPv6

Description
This is a bug I originally posted here:

[URL]

I have done some more digging and found this is a bug in Code Igniter's core `ip_address()` function. This bug is in CI 3.0.6.

When a reverse proxy uses an IPv6 address that is in the `proxy_ip` list in the config file, the `ip_address()` function gets stuck in a loop. 

The PHP file below is a stripped out version of `/system/core/Input.php` that recreates the problem. I hard coded `$proxy_ips`, the `HTTP_X_FORWARDED_FOR` header, and the `REMOTE_ADDR` header to simulate the bug. 

Save the code below as `Input.php` and run it with 

```
$ php Input.php
```

Comment out line 35 to see the function run properly with an IPv4 Address.

```

    
Discussion

    
- Here is the problem: There are nested `for` loops both using `$i`. The inner `for` loop is setting `$i` back to zero so it never breaks out of the outer loop.

Change this:

```
for ($i = 0; $i < 8; $i++)
{
    $netaddr[$i] = intval($netaddr[$i], 16);
}
```

To this:

```
for ($j = 0; $j < 8; $j++)
{
    $netaddr[$j] = intval($netaddr[$j], 16);
}
```

Edit: This code is found on line `522` of `/system/core/Input.php`
