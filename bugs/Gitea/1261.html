Title

NPM Package Registry returns HTTP400 for packages with single-character names

Description
### Description

Steps to reproduce the issue:
1. Create new token or find existing token with privileges to publish packages.
1. Install NPM locally or use container.
1. Run `npm i q` in environment from previous step
It'll download `[URL] as your dependency and put it in `./node_modules/q/` directory.
1. Run
    ```
    npm config set registry [URL]
    npm config set -- '//{gitea_url}:3000/api/packages/{username}/npm/:_authToken' "{token}"
    ```
1. Run `npm publish ./node_modules/q/` to publish this package to Gitea.
1. Error from NPM
   ```
   npm ERR! code E400
   npm ERR! 400 Bad Request - PUT [URL] - package name is invalid
   ```
Error from Gitea log
```
2023/08/16 23:11:16 ...ges/helper/helper.go:34:LogAndProcessError() [D] package name is invalid
2023/08/16 23:11:16 ...eb/routing/logger.go:102:func1() [I] router: completed PUT /api/packages/{username}/npm/q for  :52196, 400 Bad Request in 19.4ms @ npm/npm.go:154(npm.UploadPackage)
```
