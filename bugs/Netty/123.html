Title

Cannot ByteBuf.wrap a read-only non-direct buffer

Description
ByteBuf.wrappedBuffer(ByteBuffer buffer) assumes that if a buffer does not have an array it is direct.  But, read-only ByteBuffers block array access.

As a contrived example, this fails:
ByteBuf.wrappedBuffer(ByteBuffer.allocate(16).asReadOnlyBuffer());

Incidentally, the reason I'm finding these bugs is (I think) because I'm not working with ByteBuf other than in classes that are part of the Netty pipeline.  In Netty 3, I would have used ByteBuf everywhere, but with Netty 4 I have to be careful because if I pass one of my "application" ByteBufs to an encoder, then I have to duplicate().retain() it first, or the encoder will free it after writing.  Similarly I have to be careful not to retain any ByteBuf sources from any decoder, because it will also be freed if I forget to call retain().  I find it easiest to enforce this by copying in and out of nio ByteBuffers.  Am I missing a trick here?

Thanks for fixing all these bugs :-)
