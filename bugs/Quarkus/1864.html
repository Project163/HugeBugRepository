Title

RequestScoped context not active when using a ReaderInterceptor with large HTTP requests

Description
### Describe the bug

I have a [Link: `ReaderInterceptor`] to intercept my RestEasy reactive API. This interceptor calls a `@RequestScoped` service to do some actions.

With small HTTP requests, it works fine. But if my request is bigger than 10KB then it fails. The source is that the request scoped context is not active, so the request scoped service can't be injected. Which is quite weird because it works with requests lighter than 10KB.
