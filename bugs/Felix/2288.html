Title

missing (&(osgi.ee=JavaSE)(version=1.8)) when embedding in org.apache.felix.framework

Description
When I try to deploy a bundle from a OBRepo occur the below error 'Unsatisfied requirement'. 

 g! obr:deploy any.bundle

--------------------------- 
   (&(osgi.ee=JavaSE)(version=1.8)) 

 I would expect that this capability will be provided by system-bundle.

- While looking at it, I realized that we're basically constructing the  osgi.ee  capability here for the system bundle, but the system bundle already has this capability, so I thought it might be easier to copy it. For example you can find the  osgi.ee  capability of the system bundle with the following code: 
  
         Bundle b = context.getBundle(0);
        BundleRevision br = b.adapt(BundleRevision.class);
        List<Capability> caps = br.getCapabilities( "osgi.ee" );
         System .out.println("caps); 
  
 Which prints out: 
  
 osgi.ee; {osgi.ee=OSGi/Minimum, version=[1.0.0, 1.1.0, 1.2.0]}, [0] osgi.ee; {osgi.ee=JavaSE, version=[1.0.0, 1.1.0, 1.2.0, 1.3.0, 1.4.0, 1.5.0, 1.6.0]}] 
  

 So I started thinking, would it not be better to simply copy  all  the capabilities from the system bundle? I've attached  cap.diff  patch that does this to this issue. This would create a  lot  of capabilities (e.g. every exported package from the system bundle is also represented as a capability) but I have the feeling that this is more generic and more complete... 

 Thoughts anyone?
