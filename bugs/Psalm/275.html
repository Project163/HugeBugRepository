Title

false positive of MissingFile with 2-param dirname call

Description
It looks like psalm 1.x doesn't take the second parameter of a `dirname()` call into account when checking if a file is found, i.e. a file `./foo/Tests/Test.php` calls `include(dirname(__DIR__, 2) . '/app/config.php')`, psalm is looking for `./foo/app/config.php` instead of `./app/config.php` .
