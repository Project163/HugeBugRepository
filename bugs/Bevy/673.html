Title

Add explicit type annotations to debug asserts in Bevy ECS

Description
## Bevy version

0.15.1 (I've tried 0.15.2, it happens with that version too.)

## \[Optional\] Relevant system information

cargo 1.87.0-nightly (ce948f461 2025-02-14)
rustc 1.87.0-nightly

I also tried:

cargo 1.84.1 (66221abde 2024-11-19)
rustc 1.84.1 (e71f9a9a9 2025-01-27)

## What you did

I tried building a crate that has both `bevy_ecs` and `serde_json` as a dependency for `wasm32-unknown-unknown`.

## What went wrong

The Rust compiler seems to get confused by the fact that both `usize` and `serde_json::value::Value` implement `From `.
For some reason I've only experienced that when building for `wasm32-unknown-unknown`. Building for Linux, Windows or Mac OS doesn't seem to run into this. I really don't know why.
