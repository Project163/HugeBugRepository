Title

Improper tilde in CDPATH causes segfault

Description
Trigger
export CDPATH=~bogus
where ~bogus is not a valid path

Causes a segfault. Replicated with several versions of nvim and several platforms.
Discussion
- gdb output:


This happens because `event_poll()` runs on this codepath before `event_init()`. This patch prevents the segfault for me (naive solution).

```
patch
diff --git a/src/nvim/main.c b/src/nvim/main.c
index a03fd2e..86fa229 100644
--- a/src/nvim/main.c
+++ b/src/nvim/main.c
... [Log Snipped] ...
    * Set the default values for the options that use Rows and Columns.
    */
```

A quick scan of `event_init()` shows that most of the functionality does not seem to depend on the state of any other modules, so we can perhaps make an `event_early_init()` to run before `set_init_1()`, as a more permanent solution. Not going to work on this tonight, though.
- I amended a commit to #2307 that fixes this. I decided to just add a check to `event_poll()` that `immediate_events != NULL` because there may be more bugs now or in the future caused by `_poll()` running before `_init()`, and changing the initialization order can have profound effects.

On the other hand, if we must worry about events being enqueued before `event_init()`, then `event_early_init()` might be more sane.
