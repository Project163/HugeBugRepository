Title

WordUtils.wrap throws StringIndexOutOfBoundsException when wrapLength is Integer.MAX_VALUE

Description
This is the sample code. 
  
 
 int  max =  Integer .MAX_VALUE;   // 2147483647
 WordUtils.wrap( "foobar" , max,  "\n" ,  true );
