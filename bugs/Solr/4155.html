- SOLR-13284.patch      
Here, I have removed  getResponseWriter  from V2HttpCall. I think this method was initially added here because in Solr6.x, default response writer for old API is XML and to make JSON as default for V2 API this method as added 

 After Solr7, JSON is the default response writer. So, this method is not required. With this change, V2 API behavior would be same as V1 API behavior with respect response writers
