Title

Correct some builtin functions' return type inference in Blink planner

Description

ReturnTypes.cascade(ReturnTypes.explicit(SqlTypeName.VARCHAR), SqlTypeTransforms.TO_NULLABLE) 
  
 which should be

 instead.
