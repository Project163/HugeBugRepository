Title

Segmentation fault after closing the last window on OS X

Description
This is a dupe of #321, please have a look at it.
Occurs on OSX, atom-shell version 19.1.
Just like what @marcbachmann said in #321, sometimes we just get a short notice "segmentation fault".
Discussion
- Looks like the problem lies here:

Code Example:

mainWindow.on('closed', function() {
    app.quit();
}

After we closed this mainWindow, if we call app.quit(), it will emit signals trying to close this mainWindow again. But this window is already closed. 

This issue only occurs on Mac OS.

So app.quit() is a little bit dangerous.
Suggest to attach it to only "window-all-closed" event.

Or you may be able to update the logic of app.quit() on MAC? @zcbenz
