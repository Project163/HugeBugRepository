### Current Behaviour?

Horovod does not build with `tf-nightly` anymore, see [URL]

The code includes `tensorflow/core/framework/op.h` at [URL] Header files in `tensorflow/core` are included with the pip package. However, this ultimately includes `tensorflow/tsl/platform/stack_frame.h`, which does not come with the package.

This appears to have changed with [URL] cc @joker-eph
