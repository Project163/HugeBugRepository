Title

CollapseQParser: inconsistent error handling when a field is indexed=false docValues=false

Description
The CollapseQParser behaves oddly and gives inconsistent error messages if you try to use it on a field that is  indexed="false docValues="false"  – particularly when  hint=top_fc  is also used and a NullPointerException gets thrown.
