Title

Snappy unable to decompress previously compressed data

Description
Well, I've finally had a chance to update my snapshot of Netty -- and pull in the fixes for issue [URL] however trying to DECOMPRESS the data with snappy fails.

If I tweak the SnappyFramedDecoder (changing line 98) to the following, it will try to decompress, but will fail the checksum. [Link: Line 98]

```
 if (chunkLength == 0 || (chunkType != ChunkType.COMPRESSED_DATA && in.readableBytes() < chunkLength)) {
```

By the way, in line [Link: SnappyFramedDecoder:98], shouldn't it check to see if the data is compressed? Otherwise, it's looking at (in this example) a uncompressed chunk length of 274, but the input stream only has 171 bytes of data (as it's compressed), so it fails, thinking there should be more data when there shouldn't.
