- Thanks for the SIQQUIT output - very useful.

At first glance rclone appears to have deadlocked...

The smoking gun points to the progress flag, so if you try without `-P` I suspect it will work without deadlocking.

This isn't the first deadlock in the progress code alas :-(

I used [Link: panicparse] to condense the traceback

    pp --aggressive   rclone_3505_deadlock.txt
