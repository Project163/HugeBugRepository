Title

Web Console should be configurable for IPv4 connections

Description
When an IPv6 network interface is available, NodeJS will always prefer that to an IPv4 interface.  This causes problems if IPv6 is not fully operational on the network.   

 This fix will add the ability to specify that IPv4 should be used.
Discussion
- For the implementation we can either 

 1.  Make an IPv4/IPv6 flag in configuration. 
or 
2.  Allow the host parameter to be configured, so that the server can be bound to any specific IP address on the machine.
- There appears to be a bug in NodeJS such that when [1] is called, a Server object is returned by when [2] is called a null value is returned. 

 Therefore a workaround will be necessary when passing the server object to the "onListening" function. 

 [1]:  server.listen(3000);  

 [2]:  server.listen(3000,' ');
