Title

Add external client ID to LLAP external client

Description
There currently is not a good way to tell which currently running LLAP tasks are from external LLAP clients, and also no good way to know which application is submitting these external LLAP requests. 
One possible solution for this is to add an option for the external LLAP client to pass in an external client ID, which can get logged by HiveServer2 during the getSplits request, as well as displayed from the LLAP executorsStatus.
