Title

Externals not added as dependencies when building AMD modules using require

Description
I came across an issue with one of our big projects, when I was bundling an AMD module. The module will be used by another project which already uses these external dependencies.

External dependencies does not become a part of the define dependency array if the external dependency is not a part of the main entry point dependencies. Leading to `Uncaught ReferenceError: __WEBPACK_EXTERNAL_MODULE_X__ is not defined`

I have created a simple project which displays this issue below

Example:
[URL]

[Link: `webpack-config.js`]

```
javascript
var config = {
    context: './src',
    entry: {
        main1: 'main1.js',
... [Log Snipped] ...

module.exports = config;
```

[Link: `src/main2.js`]

```
javascript
define(['underscore'], function(_) {
    console.log('main2 loaded');

    return function() {
... [Log Snipped] ...
    }
});
```

[Link: `src/modules/other2.js`]

``` javascript
define(['jquery', 'backbone'], function($, Backbone) {
    return function() {
        return 10;
    }
});
```

This fails on runtime, because [Link: `src/modules/other2.js`]'s external dependencies cannot be loaded. If however the `other2` dependency becomes a part of the entry point's define dependency array, it works fine:

[Link: `src/main1.js`]

```
javascript
define(['underscore', 'modules/other'], function(_, other) {
    console.log('main1 loaded');
    console.log('other from main1 loaded');

... [Log Snipped] ...
    }
});
```

[Link: `src/modules/other.js`]

``` javascript
define(['jquery'], function($) {
    return function() {
        return 3;
    }
});
```
