Title

`ngc --help` and `ngc --version` result in compilation rather than providing help/version output

Description
# Bug Report

### Affected Package
 
The issue is caused by package @angular/compiler-cli


### Is this a regression?
no

### Description
`ngc --help` doesn't print any help output, but instead performs program compilation.
`ngc --version` does the same.

This is confusing because we claim that `ngc` is wrapper around `tsc` and `tsc` has all of these flags.

It would be great if the command behaved as a true wrapper around ngc and either returned a reasonable (augmented) output from tsc, or we'd error on these as unsupported flags.

The origin of this request is #29623 where the developers believe that the `ngc --help` hangs, when it fact it's just unexpectedly busy compiling the program.

I have not checked the behavior of all flags, but it would be great if we had a deterministic and intentional behavior for all `tsc` flags.


## Minimal Reproduction
 
```
ng new test-app
cd test-app
$(npm bin)/ngc --help
$(npm bin)/ngc --version
```

**Angular Version:**
  
 
v12.0.1
