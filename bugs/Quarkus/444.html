Title

Using -Dquarkus.native.container-build to build container native build should display progress logs

Description
**Describe the bug**
I was trying to create a container native build using:
```
$  mvn package -Pnative -Dquarkus.native.container-build=true 
````
It got stuck for a while without any info, it was pulling the 400MB image in background (which can take a while on a slow network).

**Expected behavior**
It should display docker output in the console.

**Actual behavior**
It doesn't show anything

**To Reproduce**
Steps to reproduce the behavior:
1. Have slow connection
2. Remove the `quay.io/quarkus/ubi-quarkus-native-image` from your docker cache
3. Run `mvn package -Pnative -Dquarkus.native.container-build=true `

**Environment (please complete the following information):**
 - Quarkus version or git rev: 1.2.0.Final
