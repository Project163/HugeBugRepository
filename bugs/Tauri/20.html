Title

top-level Cargo.toml breaks bundler

Description
**Describe the bug**
If you have a `Cargo.toml` file above the `/src-tauri` folder, then bundler fails to copy to the right place. 

**Expected behavior**
The bundler should find the right folder and not bail.
