Title

CCE in closure shared variable assignment

Description
class  A {}
 class  B {}

@groovy.transform.CompileStatic
def cs() {
    def  var 
     var  =  new  A()
    def c = {
         var  =  new  B()  // Cannot  cast  object  'B@4e234c52'  with class  'B'  to class  'A' 
     }
    c()
     var .toString()
}

 assert  cs() !=  null
Discussion
- Variable metadata is saved before visiting a closure expression and restored afterwards.  This resets the inferred type of "var" to A and so when classgen runs, "var = new B()" has a cast inserted for the inferred type A.
