Title

X3D importer converts polylines into polygons

Description
Assimp (5.0.1) imports from X3D IndexedLineSet as a polygon.
How to reproduce:
`assimp export IndexedLineSet.x3d IndexedLineSet_exported.x3d`
The input file has IndexedLineSet, the output file has IndexedFaceSet.
In addition 
`assimp info IndexedLineSet.x3d `
reports two meshes. while the dump 
`assimp dump IndexedLineSet.x3d`
has only one mesh.
