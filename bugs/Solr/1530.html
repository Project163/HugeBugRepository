Title

Sorting on dynamic fields using DocValues sorts empty values always first

Description
When using DocValues for sort fields, "sortMissingLast=true" seems not to work - which makes sense as DocValues require a value for every document. The workaround is to use a default value which is alphanumericly sorted last. But when specifying the sort field as a dynamic field, the default value is not applied when a document does not contain that field. 
To make it work, I had to define every single sort field explicitly.
Discussion
- In the past docValues  required  having a default Value in order to work, so i'm actaully suprised that you were even allowed to configure a dynamicField using docValues – that probably should have just given you a hard error on startup. 

 fortumately this limitation (requiring a default value) has already been removed so in Solr 4.5 it will no longer be required, and sortMissing will work on dynamic fields with docValues (see   SOLR-5165  ) 

 I've got a patch to DocValuesMissingTest in progress to prove this - i'll finish it up and commit after i get back from lunch.
- Seems like the real bug is unrelated to docvalues: if you try to supply a default value for a dynamic field you should get an exception.
