Title

traceLevel doesn't appear to work [Logger]

Description
Yii2 beta.

There is a `traceLevel` option for log component that is supposed to write some extra data for a call stack for each message appended to the log. It never worked in my development environment, I'm not really sure why.

Log component configuration:

``` php
        'log' => [
            'traceLevel' => 3,
...
```

I added the following to the end of init() of Logger:

``` php
var_dump($this);
die;
```

This is what I get:

```
object(yii\log\Logger)#13 (6) {
  ["messages"]=>
  array(0) {
  }
  ["flushInterval"]=>
... [Log Snipped] ...
  NULL
}
```

traceLevel = 0 for some reason, even though it is supposed to be 3. As the result, the message never have those extra bits this parameter supposed to bring.
Discussion
- fixed. Thanks for reporting. Traces where just not added to the log messages in log target.
