Title

Console: InputInterface::getOption is missing the "int" return type

Description
**Symfony version(s) affected**: 5.2.4, 4.4.20, 

**Description**
Console's `InputOption::getDefault` will return the following types:
```
php
/**
 * Returns the default value.
 *
 * @return string|string[]|int|bool|null The default value
... [Log Snipped] ...
    return $this->default;
}
```

`Input::getOption` (with `Input` implementing `InputInterface`falls back to the default value:
```
php
    public function getOption($name)
    {
        if (!$this->definition->hasOption($name)) {
            throw new InvalidArgumentException(sprintf('The "%s" option does not exist.', $name));
... [Log Snipped] ...
        return \array_key_exists($name, $this->options) ? $this->options[$name] : $this->definition->getOption($name)->getDefault();
    }
```

So `InputInterface::getOption` should provide all these types as well, but is it missing the `int` type:
```
php
    /**
     * Returns the option value for a given option name.
     *
     * @param string $name The option name
... [Log Snipped] ...
     */
    public function getOption($name);
```
This will confuse static type checkers like PHPStan when an int is handled.

**Possible Solution**
Add the `int` type the the return type annotation of the interface.
