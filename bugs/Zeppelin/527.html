Title

Editor code is not visible after page refresh.

Description
After a notebook has been created and the page refreshed the editor code is no longer visible when clicking the show/hide editor button. If you click "Show Editor" and then refresh the page, the editor code is shown again.
Discussion
- Detailed step to reproduce: 
1. Hide editor 
2. refresh page 
3. Show editor 
4. Editor won't show up 

 This seems to happen after ace editor version upgrade
