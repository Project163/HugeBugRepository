Title

ContentNegotiator should set Vary header

Description
### What steps will reproduce the problem?

Use ContentNegotiator and HttpCache behaviors together in a controller.

Related to yiisoft-contrib/yiiframework.com#403

### What is the expected result?

Get cached data stored in browser cache for each Content-Type variant.

### What do you get instead?

Cached data does not vary based on requested content type.

Browser caches and other HTTP proxies do not seem to store different variants of the HTTP body for different Content-Types by default. Adding the `Vary: Accept` header fixes this.

To solve this problem the `ContentNegotiator` should set the `Vary: Accept` header by default.
