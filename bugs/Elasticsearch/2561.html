Title

[Painless] Augmentation.join can't handle empty strings at the start

Description
**Elasticsearch version** (`bin/elasticsearch --version`):

6.3.1

The issue is not exclusive to the mentioned version, as the code is faulty on master too.

Source links relevant:
[URL]
[URL]

**Plugins installed**:

`[]` (none)

**JVM version** (`java -version`):

zulu 1.8.0_172 build of java8

**OS version** (`uname -a` if on a Unix-like system):

`3.10.0-693.el7.x86_64 #1 SMP Thu Jul 6 19:56:57 EDT 2017 x86_64 x86_64 x86_64 GNU/Linux`
But this has been tested on Debian, Ubuntu, CentOS, and other Redhat machines.

**Description of the problem including expected versus actual behavior**:

The `join` method for `Iterable`s provided by the `Augmentation` class for Painless can't deal with iterables containing zero-length members at the head of the iterable.
This script: `"script": "['', 0, '', 1, null, 3, ''].join(';')"` should output
`";0;;1;null;3;"`
But it outputs
`"0;;1;null;3;"`

The empty string on the start is appended to the StringBuilder, but the second pass will see it as `sb.length() == 0` still, and then will continue without a separator until it finds a non-zero-length member.

As counter-examples of why it should be different, the following cases output the expected one:
- In groovy: `['', 0, '', 1, null, 3, ''].join(';')`
- In java8: `String.join(";", Arrays.asList("", "0", "", "1", "null", "3", ""))`
- In java8: `Stream.of("", "0", "", "1", "null", "3", "").collect(Collectors.joining(";"))`
- In javascript: `['', 0, '', 1, null, 3, ''].join(';')`
