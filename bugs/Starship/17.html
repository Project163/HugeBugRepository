Title

status module broken in PowerShell

Description
#### Current Behavior
status module never kicks in because `Invoke-Starship-PreCommand` is invoked before saving `$?` and `$LASTEXITCODE`. Therefore the values are overwritten.

#### Expected Behavior
`$?` and `$LASTEXITCODE` must be saved as the first step in the prompt function so they can be passed to starship and properly restored after the prompt function.
