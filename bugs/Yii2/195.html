Title

Cookies

Description
If set a cookie

``` php
$cookie = new \yii\web\Cookie([
    'name' => 'teste',
    'value' => 'teste',
    'expire' => time() + 86400 * 365,
]);
\yii::$app->response->cookies->add($cookie);
```

 and then removed

``` php
\yii::$app->response->cookies->remove('teste');
```

He is seen as if it existed

``` php
\yii::$app->response->cookies->has('teste'); // returns true
```

 but the value is an empty string.

This is the behavior of the browser? It gets a little more complicated, because it must be checked if value is not an empty string.
Discussion
- Yes. In order to delete a cookie from a browser one must send empty one in the same request `\yii::$app->response->cookies->has` gives you `true`. On the next request it should give you `false`.
- Shouldn't hascookie then check for empty if empty means that it should be deleted?
