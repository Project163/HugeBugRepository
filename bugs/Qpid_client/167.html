Title

client should desire the SHARED-SUBS connection capability

Description
The client looks for servers offering the SHARED-SUBS connection capability to decide whether they support the shared subscription functionality added for JMS 2.0 (see   QPIDJMS-220  ). It does not however currently set this as a desired capability in its connection Open frame, which it should be doing. (A desired capability is set on the link-level detection performed if the server didn't offer the connection level capability)
