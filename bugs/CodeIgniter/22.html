Title

Autoload libraries with alternate names

Description
I just configured my fresh downloaded 3.0.0 to use alternate library name in controller. Here is my code:

```
php
/*
| -------------------------------------------------------------------
|  Auto-load Libraries
| -------------------------------------------------------------------
... [Log Snipped] ...
// Load the user_agent for monitoring
$autoload['libraries']['user_agent'] = 'client';
```

The output is an error, it said: _Unable to load the requested class: Client_
Here is the log content:

```
INFO - 2015-04-04 09:36:45 --> Config Class Initialized
INFO - 2015-04-04 09:36:45 --> Hooks Class Initialized
DEBUG - 2015-04-04 09:36:45 --> UTF-8 Support Enabled
INFO - 2015-04-04 09:36:45 --> Utf8 Class Initialized
INFO - 2015-04-04 09:36:45 --> URI Class Initialized
... [Log Snipped] ...
INFO - 2015-04-04 09:36:45 --> Session: Class initialized using 'database' driver.
ERROR - 2015-04-04 09:36:45 --> Unable to load the requested class: Client
```
Discussion
- Found a solution! Edit the ./system/core/Loader.php near 1308, Look for this:

``` php
            // Load all other libraries
            foreach ($autoload['libraries'] as $item)
            {
                    $this->library($item);
            }
```

Change to this:

```
php
            /**
             * Load all other libraries with custom names
             *
             * @description: this will fix the issue #3733
... [Log Snipped] ...
                }
            }
```
