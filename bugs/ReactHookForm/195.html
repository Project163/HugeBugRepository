Title

When a form element's value is an array, dirtyFields behaviour is different

Description
**Describe the bug**
When a form element's value is an array, dirtyFields behaviour is different.

**To Reproduce**
Steps to reproduce the behavior:

1. Go to sandbox
2. Remove 'Afghanistan' option. **dirtyFields will set 'true' for countries.**
3. Re-select 'Afghanistan' option. **dirtyFields of countries is still 'true'.**

**Codesandbox link (Required)**
- [Link: Material UI Autocomplete Multiple] Template

**Expected behavior**
**dirtyFields** behaviour should be same for all types of values. i.e (string, number, array). Ideally, the dirtyFields should not include countries in the above case as the selected option (Afghanistan) is the same when the form was initally loaded and at the end of the third step. 

**Desktop (please complete the following information):**

- OS: [macOs Catalina]
- Browser [chrome]
- Version [e.g. 81]

**Additional context**
I'm have'nt gone through how the dirtyFields are being built in react-hook-form. But for reference types values like arrays, I think we need to compare it with its values instead of their references.
