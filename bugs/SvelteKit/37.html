Title

server-side endpoint fetch fails if both `paths.base` and `paths.assets` are specified

Description
### Describe the bug

Innocuous code like this...

```
svelte
 
  import { base } from '$app/paths';

  export async function load({ fetch }) {
... [Log Snipped] ...
  }
 
```

...will fail if _both_ `base` and `assets` are set. The internal `fetch` wrapper gets confused about what the proper URL should be.
