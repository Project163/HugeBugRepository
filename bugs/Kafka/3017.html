Title

Add a check whether the Task's statestore is actually a directory

Description
I found this problem while working on  KAFKA-10585 . 

 As of present, StateDirectory checks whether the Task's statestore directory exists and, if not, creates it. Since it does not check whether it is actually a directory, for example, if a regular file occupies the Task's statestore's path, the validation logic may be detoured.
