Title

Accepted UDTChannel is never closed

Description
I'm having trouble catching the close event of an UDTSocket when the other side of the channel disconnects.

Here is my situation:
1. Server is running and accepting new UDT Sockets
2. Client connects and server accepts a new UDT socket.
3. Client shuts down and closes the socket (clean shutdown).

The problem on the server is that I don't get notified of the fact that the underlying UDT Socket has been closed. 
The UDTChannel stays active forever.
