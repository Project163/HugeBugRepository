Title

Groovy annotations that support closures don't get stubs generated correctly

Description
This: 
  
 @Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
@ interface  Get {
	 Class  value()  default  { return   true }
}
 
  

 Generates: 

  
 @java.lang.annotation.Target(value=java.lang.annotation.ElementType.TYPE) @java.lang.annotation.Retention(value=java.lang.annotation.RetentionPolicy.RUNTIME)  public  @ interface  Get
 {
 java.lang. Class  value()  default  { -> ... }.class;
}
Discussion
- Thanks for reporting this.  I'm not sure why yet, but when I give Groovy a target bytecode when generating stubs, this problem manifests.  The fix seems to be to just not do that.  I've checked in that change and will release this week.

- Should be fixed. Thanks for spotting the issue.
- The stub now has  Closure.class  as the constant for  Class  members which have closures as their default value. Obviously, the stub is just an interim artifact so the real closure will still be available in the final class file from the Groovy artifact.
