```
php
class User extends AppModel {
    public $hasAndBelongsToMany = array(
        'DiscountGroup' => array(
            'with' => 'DiscountGroupsUsers',

```

When HABTM data is not empy it works as expected: delete from HABTM join table, then insert into HABTM join table:

``` php
$data = array('DiscountGroup'=>array(
    0=>array('DiscountGroupsUsers'=>array('discount_group_id'=>1, 'custom_discount_rate'=>11)),
));
$this->User->create();

$this->User->save($data, array('validate'=>false));
```

But when all checkboxes on form are unset and array with HABTM data is empty, deleting is not performed (Its wrong behavior I think):

``` php

```

I checked in code and I see that issue is in Model::set that is called from Model::save.
