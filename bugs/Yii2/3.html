Title

ActiveRecord::tableName() not working properly on MAMP

Description
On a MAMP environment ActiveRecord::tableName() returns the full namespace path instead of just the tablename. e.g. 'tbl_app\models_post' instead of 'tbl_post'.
probably because 'basename()' is nog working correctly with \ backslashes on MAMP.
(MAMP 2.05 php5.3.6)
Discussion
- Specify the tableName
example.

```
public static function tableName() {
    return 'tbl_post';
}
```
- Fixed, thanks for reporting!
