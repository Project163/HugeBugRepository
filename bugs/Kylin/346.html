Title

Check segment overlap before return models

Description

    
Discussion

    
- Root Cause 

 The reason for this problem is that the checkpoint file generated during the streaming segment building process was mistakenly deleted during the automatic garbage cleanup process, which caused the newly generated segment to automatically start building from 0, thus creating an overlap in scope with the previous segment, resulting in a checksum error being reported.
- Dev Design 

     

 Note: After discussion, modifying the directory name itself risks triggering the segment overlap issue and does not guarantee reliability in scenarios such as accidental deletion, so the fix is abandoned; 

 On the other hand, we need to detect the mods that have already gone wrong and mark them as broken to avoid query hits on this type of segment;
