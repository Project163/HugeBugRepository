Title

Column names from JDBC Interpretations don't respect capitalization.

Description
The names of columns in both tables and graphs do not respect the capitalization from the SQL query.  

 For example: "select YTD_Revenue" would return a column named either "Ytd_Revenue" or "ytd_revenue" depending on if you're viewing the data in table or graph format.
