Title

Make rows=0 queries fast again

Description
SOLR-17732   improved score returning for distributed requests, but unfortunately it also slowed down queries that fetch no documents. This is because it added the  score  "field" to fl whenever the sort spec needed it (including when no sort was provided), because the distributed merge logic would need the value. However when zero docs are requested, there is no distributed merging to be done. So we are asking for scores, which make the search scan all documents to generate scores even though we don't need any.
