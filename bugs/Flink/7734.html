Title

Usrlib symlinks are not followed

Description
[URL] has changed the Java File API that is used to traverse the usrlib from Files.list to Files.walk. 

 Files.list was following symlinks, but Files.walk needs an option passed to follow symlinks. This caused symlinks to no longer be followed. Which seems like an unintended side effect and broke my setup.
