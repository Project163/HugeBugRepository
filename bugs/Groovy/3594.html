Title

CLONE - Use of an inner enum causes compilation to go into infinite loop - antlr2 fix

Description
The following piece of code causes the compilation to go into infinite loop 

   Groovy Compiler - To infinity and beyond..   
  enum  Outer {
    A, B
     enum  Inner{X, Y}
}
