Title

Strange issue with utf8 symbols in completion menu

Description
- `nvim --version`: 0.3.0
- Vim (version: 8.1.22) behaves _correctly_
- Operating system/version: Arch Linux (recently updated)
- Terminal name/version: urxvt v9.22
- `$TERM`: xterm

### Steps to reproduce using `nvim -u NORC`

1. Create file test with content:

    ```
    testø
    testæ
    testå
    ```

2. Go to last line, do `o ` to open keyword completion menu.

### Actual behaviour

The letters `æøå` are not displayed correctly, see screenshot:

### Expected behaviour

The letters are displayed correctly.
