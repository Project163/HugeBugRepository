Title

Enum unfolding doesn't work in some cases

Description
I hope it's not too annoying posting all these tiny little bugs, but I try to keep code as verbose as possible and let the compressor do the rest. In this case I found a strange behavior, that CG doesn't unroll the following enum:

(function(window) {

/**
*
* @enum {number}
*
*/
var STATUS = {
PLAY: 0,
PAUSE: 1,
GAMEOVER: 2,
WAIT: 3
};

function integratePiece() {
gameStatus = STATUS.GAMEOVER;
}

function loop() {
integratePiece();
setTimeout(loop, speed);
}

loop();

})(this);

In simple mode I just get:

(function(c){function a(){gameStatus=b.GAMEOVER;setTimeout(a,speed)}var b={PLAY:0,PAUSE:1,GAMEOVER:2,WAIT:3};a()})(this);

Advanced mode isn't much better:

(function(){function a(){gameStatus=b.a;setTimeout(a,speed)}var b={c:0,b:1,a:2,d:3};a()})(this);

I tried to add a @const annotation as well, without any effect.

P.S.: The variables are all global because I reduced the code as much as possible to proof the problem. In the real code all the variables are defined in the closure.

Thanks!

Robert
Discussion
- This is a function declaration ordering issue.  Change this function declarations to var initializations:

var loop = function() {...}

Fixes this issue.
