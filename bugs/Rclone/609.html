- @ncw since you implemented `--onedrive-server-side-across-configs` for #4058, are you sure that OneDrive supports server-side copy between accounts/drives? I didn't see that in their [Link: documentation]... But they explicitly say that the [Link: move] operation does not support this.
- I think it's not supported. [URL]
- Ah, thanks for the investigation @Cnly and @Dibbyo456 

I think [Link: copying] across drives is supported though - at least that was what #4058 was about. Reading the stack overflow link, it looks like it might work between two personal drives for example.

It also looks as if Microsoft might implement that one day too!

So @tachikoma-beep I think you are out of luck - you'll have to remove --server-side-across-configs and transfer the data via rclone.

I wonder if we could detect this better somehow to come up with a better error message.
- So it looks like this server-side copy feature can only be used when:
* Copying files already shared between different OneDrive Personal accounts, or
* Copying within the same drive on OneDrive for Business.

Let me clarify the error message and make rclone fall back to a manual copy.
