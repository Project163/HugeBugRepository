Title

Dev mode not working in 1.3.0

Description
**Describe the bug**
As discussed in [Link: zulip chat] our application is not working in dev mode after migrating to quarkus 1.3.0.

**Expected behavior**
We should be able to run our application in dev mode.

**Actual behavior**

After we start the application and access index page we got following exception:

```
quarkus-myfaces-showcase 1.0-SNAPSHOT (powered by Quarkus 1.3.0.Final) started in 3.097s. Listening on: [URL]
Profile dev activated. Live Coding activated.
Installed features: [cdi, myfaces, servlet, undertow-websockets]
java.lang.IllegalArgumentException: argument type mismatch
        at sun.reflect.NativeConstructorAccessorImpl.newInstance0(Native Method)
... [Log Snipped] ...
        at org.jboss.threads.JBossThread.run(JBossThread.java:479)
MyFaces Core CDI support enabled
```

**To Reproduce**
Steps to reproduce the behavior:
1.  Clone this repo: [URL]
2. cd into `myfaces` and install it `mvn clean install -DskipTests`
3. cd into `myfaces/extensions/quarkus` and `mvn clean install`
4. cd into `myfaces/extensions/quarkus/showcase` and `mvn clean compile quarkus:dev`
5. access localhost:8080/index.xhtml

 

**Screenshots**
Following is a screenshot of the code which throws the exception: 

 ; 2019-08-27T17:06:16+02:00)`


**Additional context**

* The issue **cannot** be reproduced in jar mode: `mvn clean package -DskipTests && java -jar target/quarkus-myfaces-showcase-1.0-SNAPSHOT-runner.jar`
* Also **cannot** be reproduced in native mode (tested with graalvm 20): 
`mvn clean package -DskipTests -Pnative && ./target/quarkus-myfaces-showcase-1.0-SNAPSHOT-runner`
* The application works in both jar and dev mode on quarkus 1.2.1.Final, you can check apache myfaces master repository: [URL]
