Title

[MPS] MaxPool2d/3d fails to raise error for invalid output size (Silent Failure / Undefined Behavior)

Description
### 🐛 Describe the bug

### Bug description

- The MaxPool2d and MaxPool3d operators on the MPS backend fail to check if the calculated output dimension is valid.
- When the input dimension is smaller than the kernel size (and padding is insufficient), the expected behavior is to raise a RuntimeError: Output size is too small, which correctly happens on CPU.
- However, on MPS, the operation proceeds silently, returning a tensor with invalid/garbage values (Undefined Behavior) instead of raising an exception.
