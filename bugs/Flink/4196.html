Title

LIMIT queries are failed when adding sleeping time of async checkpoint

Description
When we change the timing of operations (sleep after emit first record and sleep for async operation of checkpoint) with this  commit , the test  org.apache.flink.table.planner.runtime.stream.sql.AggregateITCase#testDifferentTypesSumWithRetract  in flink-table-planner-blink is failed.
Discussion
- Should this be a blocker for 1.11?

That's why I created it as CRITICAL. 

 But I guess either way, this indeed should be a blocker  gyfora . If we decide to limit support to one input operators, we still need to at least verify it this upon job submission.
