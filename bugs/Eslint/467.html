Title

Destructuring issue: Cannot call method 'toLowerCase' of undefined

Description
When linting the following code:

``` js
var p = {m: 'M'};

var {m} = p;
```

I get the following error:

```
TypeError: Cannot call method 'toLowerCase' of undefined
    at /Users/*******/node_modules/eslint/lib/rules/sort-vars.js:24:57
```
Discussion
- `destructuring` is enabled in the config.
- I have been looking at this quite a bit.

In the VariableDeclaration function, the `lastVariableName` is assigned to `memo.id.name`;

It looks like when a something is below is declared,

``` javascript
const sounds = {dog: 'woof'};
const {dog} = sounds;
```

the node param comes in as an `ObjectPattern` type. The `memo.id` itself is an array of "Property" objects with a key object and a value object. The `name` property resides within the key and value objects and doesn't actually have the `name` property. I am unsure of the complete intended portion of this code so I haven't found a good solution to this.
- We probably just need to skip destructured declarations.
