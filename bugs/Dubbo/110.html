Title

ConcurrentHashMapUtils无法解决jdk8的循环bug

Description
### Environment

* Dubbo version: 3.2, 3.3
* Operating System version: Windows11
* Java version: jdk8

### Steps to reproduce this issue

[Link: ConcurrentHashMapUtils] 中提供的`computeIfAbsent`方法没有解决jdk8的循环问题，复现代码如下：

```java
final ConcurrentHashMap  map=new ConcurrentHashMap<>();
// // map.computeIfAbsent("AaAa", key->map.computeIfAbsent("BBBB",key2->42));
ConcurrentHashMapUtils.computeIfAbsent(map, "AaAa", key->map.computeIfAbsent("BBBB",key2->42));
```

[Link: Hutool] 中的解决方案是：

```java
V value = map.get(key);
if (null == value) {
	map.putIfAbsent(key, mappingFunction.apply(key));
	value = map.get(key);
}
return value;
```
