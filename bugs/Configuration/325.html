Title

OSGi Import-Package in 2.12.0 now requires jakarta.servlet

Description
We use commons-configuration2 in ActiveMQ Artemis which includes some OSGi integration. Recently when  attempting to move from 2.11.0 to 2.12.0  an OSGi-related test started failing, and it turns out that the culprit is that  Export-Package  in  MANIFEST.MF  now contains: 
  
 uses:="jakarta.servlet,javax. servlet" 
  
 I can update our configuration to account for this, but it's not clear to me that this change was intentional given that the Maven dependencies for these artifacts are marked as  optional . 

 Does 2.12.0 really have a hard dependency on jakarta & javax servlet?
