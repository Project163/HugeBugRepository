Title

`CLIEngine#getFormatter()` is no longer a static function- throws an error

Description
`CLIEngine.getFormatter` used to be available as a static function.
It's also mentioned in [Link: the docs] that it's "available as a static function".
Since the introduction of the CLIEngine `cwd` option this is no longer the case since it calls `this.options.cwd` internally and `options` is undefined (because `options` is set with `defaultOptions` in the constructor which isn't called).

My use-case that made me encounter this is trying to use a custom formatter. I use `grunt-eslint` which calls `getFormatter` as static internally and passes a string as the argument, which means I expect it to infer it as a relative path which needs to concatenated to the current working directory.
Previously the cwd was resolved by calling `process.cwd()` and now it's resolved by calling `this.options.cwd` which as I mentioned is now undefined.
- **The version of ESLint you are using** 2.2.0
- **What you did** Call `getFormatter` as static and pass a path of a custom formatter as the argument
- **What you expected to happen** No error thrown. A custom formatter is returned.
- **What actually happened** Error: `Cannot read property 'cwd' of undefined`
