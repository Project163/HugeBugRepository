Title

Web console: MS SQL server missing JDBC download link

Description
What happens:  
In configuration / advanced / caches / store if user selects "JDBC Pojo store factory" and "MS SQL Server" dialect, a link labeled "Download JDBC drivers?" is displayed. When "oracle" or "IBM" dialects are selected, the link leads to a proper download page, while "MS" dialect link leads nowhere. 

       

  Expected behavior:  
If there is a download page for MS JDBC driver, add it's URL to JDBC_LINKS provider. If there's none, maybe don't show the link or show appropriate plain text? 

 The issue was reproduced in master.
Discussion
