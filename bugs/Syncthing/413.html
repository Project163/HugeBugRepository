Title

Invalid (ignored?) files cause protocol error

Description
```
[D6C7D] 15:15:28 INFO: Connection to [desktop-id] closed: protocol error: index update:
  "House move/~$House move 2015.xlsx": file with empty block list
```

Caused by:

```
[device] F:2 D:1 N:"House move/~$House move 2015.xlsx" V:File{Name:"House move/~$House
  move 2015.xlsx", Sequence:23915, Permissions:0644, ModTime:2015-10-01 20:57:24 +0200 CEST,
  Version:{[{EL6TCCQ 1} {5F2O44H 1}]}, Length:165, Deleted:false, Invalid:true,
  NoPermissions:false, Blocks:[]}
```

Presumable we've set the invalid bit and cleared the block list at some point. We should probably accept those files.
