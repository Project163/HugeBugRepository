Title

Windows drive letter in vm.box_url is ignored

Description
This is a case of missing a single slash character in [Link: box_add.rb].
### Vagrant version

1.8.4
### Host operating system

Windows 7
### Guest operating system

CentOS 6
### Vagrantfile

``` ruby
Vagrant.configure(2) do |config|
  config.vm.box = my/centos6-64"
  config.vm.box_url = 'Y:/vagrant/centos6-64/centos6-64.box'
end
```
### Debug output

[URL]
### Expected behavior

Vagrant finds .box file from any attached drive on Windows, eg. `Y:/vagrant/centos6-64/centos6-64.box`.
### Actual behavior

`vagrant up` fails with error `Couldn't open file /vagrant/centos6-64/centos6-64.box`.
### Steps to reproduce
1. Store .box file locally on a different drive from the Vagrantfile
2. Run `vagrant up`
### Root cause

Windows paths are converted to URLs with `file:` scheme in [Link: box_add.rb]. Three slashes should follow `file:` but only two are added. As a result cURL interprets the drive letter as the authority section of the URL.

There is a [Link: cURL FAQ] explaining how it interprets file: URLs containing drive letters.
