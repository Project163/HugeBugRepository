Title

Replay feature broken for inline scripts

Description
Currently, it is impossible to call replay_request in a response script hook.
[Link: FlowMaster.replay_request] fails if the flow is still live, presumably because [Link: RequestReplayThread] `ask`s the master which would cause a deadlock. We should 
- [x] Add an option to RequestReplayThread to not ask the master
- [x] Allow replay_request to work if flow.live is set, but suppress asking the master then.
- [x] Adjust tests
