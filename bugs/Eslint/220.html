Title

block-scoped-var doesn't work with labels

Description
When `block-scoped-var` (set to `both`) is used in conjunction with `labels`, it throws `outside of binding context` error.

ESLint version: `0.11.0`

config:

```
"no-inner-declarations": [ 1, "both" ],
"no-labels": [ 0 ]
```

code:

```
function test () {
    "use strict";
    var i, j;

    outer:
... [Log Snipped] ...
    }
}
```

Error:

```
5:4   error  "outer" used outside of binding context  block-scoped-var
8:18  error  "outer" used outside of binding context  block-scoped-var
```
Discussion
- Looks like we are misidentifying a label as a variable.
