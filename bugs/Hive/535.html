Title

Set the version of Hive trunk to '0.7.0-SNAPSHOT' to avoid confusing it with a release

Description
The build.properties file currently sets version=0.7.0, which results in artifacts named 
hive-xxx-0.7.0.jar and a tarball with the name hive-0.7.0.tar.gz. Only the actual 0.7.0 release 
should generate JARs and tarballs with this name.
