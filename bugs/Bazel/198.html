Title

Can't disable error-prone in Bazel 0.3.1rc2

Description
Consider the repository here. [URL]

It has a blank `WORKSPACE` and a single `App.java` file, which compiles in `javac` but fails under [Link: Error Prone].

``` java
public class App {
    public static void main(String[] args) {
        System.out.println("" + args);
    }
}
```

``` python
java_binary(
    name='x',
    srcs=['App.java'],
    main_class='App',
    javacopts = ['-extra_checks:off'],
)
```

When I `bazel build :x` in Bazel 0.3.0, the build succeeds.

In Bazel 0.3.1rc2, the build fails, `blaze javac: invalid flag: -extra_checks:off`. If I comment out `javacopts`, the build fails with an `ArrayToStringConcatenation` error from Error Prone.
