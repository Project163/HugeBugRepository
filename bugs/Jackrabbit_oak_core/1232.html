- Looks like the issue is in AsyncIndexUpdate around what is considered as concurrent update. The above test runs a 5 node cluster and creates and index and triggers a reindex. It can happen and infact here does happen that on 2 cluster node AsyncIndex job is fired at same time and they both try to set the lease which can result in conflict at DocumentStore layer (and hence not detected by CommitHook).
