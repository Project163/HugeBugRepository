Title

Printer class does not handle "file does not exists"-problems correctly

Description
I am getting the following error when running PHPUnit and the destination directory does not exists.

PHP Warning:  fopen(/opt/cruisecontrol/projects/bms-whitelabel/source/application/tests/report/logfile.xml): failed to open stream: No such file or directory in /usr/share/pear/PHPUnit/Util/Printer.php on line 101
PHP Warning:  fwrite() expects parameter 1 to be resource, boolean given in /usr/share/pear/PHPUnit/Util/Printer.php on line 157

In Printer.php You are checking if the resource is null, but not if it's boolean:false which is the return value of fopen if it fails.
