Title

Error while synchronous `transition.redirect()` in `willTransitionTo` hook

Description
I have these two routes:

``` xml
 
 
```

`UserGoods` handler has `willTransitionTo` hook that looks like this:

``` js
willTransitionTo: function (transition, params, query) {
    if (params.status !== 'active' && params.status !== 'inactive') {
        return transition.redirect('goods', { status: 'active', page: 1 });
    }
}
```

When I'm navigating to `/goods` url from the main page, an error `Cannot dispatch in the middle of a dispatch` occurs. Note, that this bug doesn't appear when you open `/goods` page from the browser's location bar.
Discussion
- Which version?

- This probably happens in 0.9. We probably can't use FB's dispatcher for redirects in sync transitions, which makes me wonder if we want to use it at all.
- ok, let's ditch the dispatcher. It's probably a good idea to bring back the `onChange` arg that we used to give location objects, and then just use that to notify ` ` components the route has changed.
