Title

typo in cql examples

Description
Data Definition example use wrong definition
Discussion
- hi, in  [URL] the data definition of "The primary key", the definination of table t primary key is wrong. 
~~~  
CREATE TABLE t ( 
    a int, 
    b int, 
    c int, 
    PRIMARY KEY (a, c, d) 
); 

 SELECT * FROM t; 
   a | b | c 
  --   -   -- 
   0 | 0 | 4     // row 1 
   0 | 1 | 9     // row 2 
   0 | 2 | 2     // row 3 
   0 | 3 | 3     // row 4 
~~~ 
I think the primary key should be (a, b, c) from context. 
~~~ 
PRIMARY KEY (a, b, c) 
~~~
