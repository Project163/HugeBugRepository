Title

Using fast-jar packaging + AppCDS with Quarkus 1.11.0

Description
Dears,
I am unable to create docker image using fast-jar packaging, AppCDS & docker image plugin, it looks like docker image building is being executed before AppCDS generation which results in docker image building failure,  here is a sample output of maven package command :

```
[INFO] [io.quarkus.container.image.docker.deployment.DockerProcessor]  > [7/7] COPY --chown=1001 target/app-cds.jsa /deployments/:

[INFO] [io.quarkus.container.image.docker.deployment.DockerProcessor] ------

[INFO] [io.quarkus.container.image.docker.deployment.DockerProcessor] failed to compute cache key: "/target/app-cds.jsa" not found: not found
... [Log Snipped] ...
To ensure they are loaded properly, run the application jar from its directory and also add the '-XX:SharedArchiveFile=app-cds.jsa' JVM flag.
Moreover, make sure to use the exact same Java version (11.0.4) to run the application as was used to build it.
```


and a sample snippet of modified docker fast jar file :
```
# Configure the JAVA_OPTIONS, you can add -XshowSettings:vm to also display the heap size.
ENV JAVA_OPTIONS="-Dquarkus.http.host=  -Djava.util.logging.manager=org.jboss.logmanager.LogManager -XX:SharedArchiveFile=/deployments/app-cds.jsa"
# We make four distinct layers so if there are application changes the library layers can be re-used
COPY --chown=1001 target/quarkus-app/lib/ /deployments/lib/
COPY --chown=1001 target/quarkus-app/*.jar /deployments/
COPY --chown=1001 target/quarkus-app/app/ /deployments/app/
COPY --chown=1001 target/quarkus-app/quarkus/ /deployments/quarkus/
COPY --chown=1001 target/app-cds.jsa /deployments/
```


.dockerignore is modified with below line :
```
!target/app-cds.jsa
```


Environment :

Java 11

Quarkus 1.11.0.Final

Maven 3.6.3

properties :
```
# Packaging options
quarkus.package.type=fast-jar
quarkus.package.create-appcds=true
quarkus.docker.dockerfile-jvm-path=src/main/docker/Dockerfile.fast-jar
```

Regards.
