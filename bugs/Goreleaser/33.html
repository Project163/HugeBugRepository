Title

nfpm on windows

Description
**Describe the bug**
Using goreleaser on windows produced a deb package with incorrect folder paths.
i.e. `\`s instead of `/`s

**To Reproduce**

```
yaml
nfpm:
  name_template: "{{ .ProjectName }}_{{ .Version }}_{{ .Os }}_{{ .Arch }}"
  formats:
    - deb
... [Log Snipped] ...
  files:
    "init.d/imgsvr": "/etc/init.d/imgsvr"
```

Got 
```
$ dpkg -L imgsvr
/var
/var\log
/var\log\imgsvr
/etc
... [Log Snipped] ...
/usr\bin
/usr\bin\imgsvr
```

Expected
```
$ dpkg -L imgsvr
/var
/var/log
/var/log/imgsvr
/etc
... [Log Snipped] ...
/usr/bin
/usr/bin/imgsvr
```

**Environment (please complete the following information):**

- OS: windows
- GoReleaser Version: 0.79.1, commit  , built at 2018-07-04T15:52:18Z
