Title

torch.tril lacks of checking 'out of bound' on cuda

Description
### 🐛 Describe the bug

```
results = dict()
import torch
arg_1 = torch.rand([4], dtype=torch.float32)
try:
  results["res_cpu"] = torch.tril(arg_1,)
... [Log Snipped] ...
  results["err_gpu"] = "ERROR:"+str(e)
print(results)
```

The result is {'err_cpu': 'ERROR:Dimension out of range (expected to be in range of [-1, 0], but got -2)', 'res_gpu': tensor([0.6544, 0.0000, 0.0000, 0.0000], device='cuda:0')}.

### Versions

pytorch: 1.8.1
python: 3.8.3
os: win11

cc @ngimel
Discussion
- Find the same problem on torch.triu.
```
results = dict()
import torch
arg_1 = torch.rand([], dtype=torch.float32)
try:
  results["res_cpu"] = torch.triu(arg_1,)
... [Log Snipped] ...
  results["err_gpu"] = "ERROR:"+str(e)
print(results)
```
The output is {'err_cpu': 'ERROR:dimension specified as -2 but tensor has no dimensions', 'res_gpu': tensor(0.2756, device='cuda:0')}.
- Should be easy to add the dimension test for tril, if you submit a PR add me as reviewer.
