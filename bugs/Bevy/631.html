Title

sub app cannot run as the official example suggested

Description
## Bevy version
0.14.2

## What you did

I tried to run some code in sub app, then I use the example from official documentation:

```
rust
use bevy_app::{App, AppLabel, Main, SubApp};
use bevy_ecs::system::{Res, Resource};

fn main() {
... [Log Snipped] ...

}
```

## What went wrong

The function in sub app can never be executed
Discussion
- It looks like the `SubApp` doesn't have any schedules. Adding one like

```rust
let mut sub_app = SubApp::new();
sub_app.update_schedule = Some(Main.intern());
```

Seems to fix things. So I guess this is a documentation issue?
