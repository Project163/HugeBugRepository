Title

rclone sync a file bigger than 5GB to Amazon S3 throws "Failed to read set modification time: InvalidRequest: The specified copy source is larger than the maximum allowable size for a copy source" error

Description
**Issue?**
I'm using rclone to sync file against Amazon S3. When it sync a file bigger than 5GB, it will throws the error " Failed to read set modification time: InvalidRequest: The specified copy source is larger than the maximum allowable size for a copy source: 5368709120". However, the file gets uploaded to Amazon S3 but the "rcloen sync" command keep throw the error and I'm unable to write a script to wrap rclone properly as it return status is "1".

rclone v1.30

**Which cloud storage system are you using? (eg Google Drive)**

- This is because the [Link: COPY] command used to set the metadata can't set metadata on files bigger than 5 GB.

I think an acceptable work-around would be just to ignore requests to set the metadata for files > 5GB.
