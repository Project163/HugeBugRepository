Title

Support for @counter-style rule

Description
The new [Link: counter-style rule] gives an error in Less because the `@` rule is unrecognized:

``` css
@counter-style triangle {
  system: cyclic;
  symbols: ‣;
  suffix: " ";
}
```

PS - Would it be possible to add support for `@unknown` rules, or will this clash with variables, this will also solve lots of similar issues in the future when new `@` rules emerge.
Discussion
- It's not that it really clashes with variables, but since at -rules have quite wide range of possible syntaxes this may need too deep look-ahead parsing to be worth it (new at-rules were not introduced that often to bother).

Curiously versions before 1.7.0 did support unknown at-rues but only those ending with `;` (And it looks like this was broken unintentionally).

Either way for a simple `{}`-block at-rule one can always use selector interpolation as a workaround, e.g.:

```
@counter-style: ~"@counter-style";

@{counter-style} triangle {
    system: cyclic;
    symbols: ?;
    suffix: " ";
}
```
- Added bug because its a bug we don't support `@counter-rule`.

It was unintentional that we stopped supporting non rule directives. We could try parsing for rulesets too if the rule is not recognised I guess.
