Title

RowSchema not updated for some ops when columns are pruned

Description
When columns are pruned in ColumnPrunerProcFactory, updating the row schema behavior is not consistent among operators: some will update their RowSchema, while some others will not.
Discussion
- The row schema of the lateral views and table scan operators are updated now after column pruning is applied; thus, the schema conforms to the tuples that go through the operator, which is important e.g. for   HIVE-8435  . 

 As a side effect, the statistics for the lateral views change, so I have uploaded the changes in those tests files.
