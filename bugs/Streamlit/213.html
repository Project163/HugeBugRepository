Discussion
- Thanks for pointing this out @Zerohertz! Looking at the pillow documentation, `Image.Resampling.BILINEAR` used to be `Image.BILINEAR` until it was deprecated, but the deprecation ended up being reversed in version 9.4.0 (before the constant was scheduled to be fully removed), so using `Image.BILINEAR` should just work with all supported versions. I think switching back to using it would be preferable to changing the version pins since I don't think there's any reason we can't support older pillow versions as well.

I'll go ahead and make this change myself while I'm looking at this issue since it's a pretty trivial one-liner.
