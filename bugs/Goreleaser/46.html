Discussion
- you have 2 builds:

```yaml
builds:
- main: ./cmd/pdfcpu/main.go
- env:
  - CGO_ENABLED=0
```

builds have an `id` field, so you can archive specific build results... they have a default mechanism, which in your case gave both the same ID: `pdfcpu`

anyway, your config seems to have a typo, should probably be:

```yaml
builds:
- main: ./cmd/pdfcpu/main.go
  env:
  - CGO_ENABLED=0
```
