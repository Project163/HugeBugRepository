Discussion
- Thank you for your report.

Indeed, this is false positive.

The rule checks read-update-write which is across `await`/`yield` expressions. That code reads `count` before an `await` expression and writes the `count` after the `await` expression, but those are independent. Currently, the rule doesn't check if the update is independent or not.
