Title

[bug] 2.0.0-beta.3 Cannot unlisten "once" event handlers

Description
### Describe the bug

`once` method of `WebviewWindow` does not return an event id in v2, thus the handler cannot be deregistered in case it is not called.

### Reproduction

```rust
let handler = window.listen("cancel_token_request", |_| {
  // Do things...
});

window.unlisten(handler);
```

Results in

```
         window.unlisten(handler);
                -------- ^^^^^^^ expected `u32`, found `()`
```

### Expected behavior

This is expected to work just like the v1, without errors.
