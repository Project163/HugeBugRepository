Title

Server accepts an unsigned message when the policy requires a signed message.

Description
A policy is attached to the request message that requires the message body to be signed and timestamped. 
Due to an error on the client side, a message is sent with a security header and time stamp but is not signed. 
The server accepts the message anyway.
