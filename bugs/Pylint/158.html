Title

[regression] New node visit methods not backwards compatible - custom checkers with old visit_ methods cause built-in checkers to fail

Description
Originally reported by: **BitBucket: [Link: carlio], GitHub: @carlio?**

---

I created a custom checker for a pylint plugin here:
[URL]

Recently methods for visiting nodes changed:
[URL]

`visit_class` should now be `visit_classdef`

When my checker still defines a `visit_class` method, then the logic in the `PylintASTWalker` assumes that _all_ checkers have a `visit_class` method:
[URL]

This means that `visit_classdef` is not called for any of the built-in pylint checkers, especially the [Link: ClassChecker] which breaks (as `_accessed` does not get populated)
