Title

Cannot submit jobs from Web UI in FLIP-6 YARN Session

Description
In YARN session mode the WebMonitorEndpoint listens on a random port. The RestClusterClient used by the JarRunHandler is currently configured with the reserved port 0 in YARN session mode.
