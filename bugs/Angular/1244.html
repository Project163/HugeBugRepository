Title

zone.js incorrectly throws an error when rejecting a Promise with the `DISABLE_WRAPPING_UNCAUGHT_PROMISE_REJECTION` flag enabled

Description
# 🐞 bug report

### Affected Package
zone.js

### Is this a regression?
No.

### Description
Recently the flag `DISABLE_WRAPPING_UNCAUGHT_PROMISE_REJECTION` was added with #35873 to allow disabling of the wrapping behavior that zone.js performs on rejected promise values. Unfortunately, when this flag is enabled the zone.js code throws an unexpected error when a non-Error value is rejected, due to the code attempting to set various properties on the rejected value regardless of type: [URL]

For example, if I reject a Promise with the value "42" the following error occurs:
`Error: Cannot create property 'rejection' on number '42'`

## 🔬 Minimal Reproduction
[URL]

## 🔥 Exception or Error
If I reject a Promise with the value "42" the following error occurs:
  
`Error: Cannot create property 'rejection' on number '42'`
  

This is reproducible with any non-error value (number, string, null, etc.)
