Title

camel-kafka - KafkaProducerCallBack can execute the continuation twice

Description
KafkaProducerCallback uses the following pattern with LongAdder to execute the continuation. This approach is not thread safe and thus it is possible the continuation is executed twice, once from the thread executing the onCompletion method and once from the thread executing the allSent method. 
  
 
       count.decrement();
         if  (count.intValue() == 0) {
            ...
            callback.done()
        }
