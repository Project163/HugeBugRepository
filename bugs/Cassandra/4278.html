Title

cqlsh show sessions truncates time_elapsed values > 999999

Description
Output from show session in cqlsh: 
 
 Submit hint for /   [EXPIRING-MAP-REAPER:1]  | 2016-05-11 15:57:53.730000 |   |         283246

  1bbce5c0-1791-11e6-9598-3b9ec975a2e6 | 1ee37a20-1791-11e6-9598-3b9ec975a2e6 |                         Submit hint for /  |   |        5283246 |                     EXPIRING-MAP-REAPER:1  
 Notice that the 5 (seconds) part is being truncated in the output.
