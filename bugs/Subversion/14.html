Title

Drop client support for copyfrom-over-update

Description
The copyfrom-on-update enhancement has been deemed too much pain for too little gain, and inferior to the Subversion project's vision for future handling and optimizations of such things.  This issue tracks the removal of the code which handles that feature from our client libraries.
