Title

Ignite does not recognize the right number of CPU cores when running under Docker

Description
Run Ignite under a Docker container. 

 Limit Ignite from using all CPUs by way of Docker settings (which internally uses Linux CGROUPS).  

 Ignite will still report that all available CPUs are used ignoring Docker settings.
Discussion
- I didn't find a standart Java API which allows to get available cpu counts when CGROUPS configured. We can get right number of CPU by native API (nproc) and manage which API will be using (java or native) by env variable.
- My understanding that it will be only supported in Linux environments, right? I am going to mark this ticket as "newbie" - it looks like a good one for new contributors to tackle.
