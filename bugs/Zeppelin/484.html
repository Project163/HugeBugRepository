Title

Changing Value in Select Form Runs Paragraph Instantly

Description
Zeppelin runs the paragraph each time I change a value in a select form. This leads to issues when you have multiple forms in the same paragraph.  

 If I need to alter multiple values then I have wait for the query to complete every time I change one. My hive query can take quite a long time to run so this seriously slows down development.
