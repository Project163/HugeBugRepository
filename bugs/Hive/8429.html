Title

When kerberos is enabled, hiveserver2 error connecting metastore: No valid credentials provided

Description
If the environment variable HADOOP_USER_NAME exists, hiveserver2 error connecting metastore: No valid credentials provided. 

 There is a problem with the getUGI method of the org.apache.hadoop.hive.shims.Utils class to obtain the UGI. It should be added to determine whether 'UserGroupInformation IsSecurityEnabled () `. If it is true, it returns' UserGroupInformation GetCurrentUser() `. If it is false, the user name is obtained from the environment variable HADOOP_USER_NAME to create a UGI
