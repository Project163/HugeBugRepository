Title

Limit the maximum length of the title

Description
When trying to set a long window title either with ANSI escape codes or on the command line, `alacritty` closes with a panic.

```shell
echo -ne "\033]0;$(cat /dev/urandom | base32 -w0 | head -c4084)\007"
```

Not that I want to use such long titles, but this happened to me because I configured zsh to set the window title to the currently running command.

I found a similiar issue for `kitty`, which was [Link: solved] by limiting the title that will be send to the window manager to 2048 bytes.

### System

OS: Linux
Version: `alacritty 0.4.3`
Linux/BSD: swaywm + Wayland
