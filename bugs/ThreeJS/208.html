Title

Missing argument on addEventListener for 'drop' event.

Description
On the dev branch, on [Link: ui.three.js], and also on the master branch same [Link: ui.three.js] file, there's an event listener being added that uses the `event` variable inside the callback function, but that parameter isn't present.

***Code***

```
canvas.addEventListener( 'drop', function () {

	event.preventDefault();
	event.stopPropagation();
	loadFile( event.dataTransfer.files[ 0 ] );

}, false );
```

**Expected**

Callback function with the parameter `event` as used inside.

```
canvas.addEventListener( 'drop', function ( event ) {

	event.preventDefault();
	event.stopPropagation();
	loadFile( event.dataTransfer.files[ 0 ] );

}, false );
```

**Platform:**

Detected on Three.js version [master, r126], still present on [dev, r129] and [master, r129].
