Title

log.Printf() and log.Infof append a newline to the output

Description
I just started using logrus by replacing the import for log. Previously I had used log.Printf("bla\n") to log messages, but logrus appends an extra \n so that there is an empty line after each log message. What am I missing? If this is supposed to be API-compatible, this should behave differently.
Discussion
- I would also be interested in this, would be nice to be able to print progress messages without a newline.
- You're right, with the text formatter this is not API-compatible, this is rather inherent to field-logging the way I see it.
- This has come up again. I'm thinking we should escape the character instead. It doesn't make sense with the current formatters to actually do a newline.
- I'd like to see this #674 674 as an option
