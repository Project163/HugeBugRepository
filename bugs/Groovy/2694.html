Title

Regression with @DelegatesTo wrt to maps

Description
The following code now fails with Groovy 2.3.4 at runtime with an  IncompatibleClassChangeError : 

  
            @CompileStatic
             class  MyHandlers  {
              Map execute() {
                againstList {
                  foo =  "bar" 
                }
              }

              Map againstList(@DelegatesTo(Map) Closure<?> c) {
                def l = [:]
                c.delegate = l
                c.call()
                l
              }
            }

            def map =  new  MyHandlers().execute()
             assert  map.foo ==  'bar'
