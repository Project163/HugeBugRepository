Title

jvm-dtest unhandled exceptions failing the test no longer work

Description
Seems that (  CASSANDRA-16925   CEP-10 Phase 1: Mockable Task Execution) refactored and avoided using AbstractCluster.uncaughtException, this means that the logic to detect unexpected exceptions to fail tests no longer works.
Discussion
- marking 4.1 as this feature detects subtle bugs, so with this broken we could have subtle things failing, so we may actually have failing tests but think passing.
- > avoided using AbstractCluster.uncaughtException 

 It simply doesn't use  Thread.getDefaultUncaughtExceptionHandler , which appears to be how in-jvm dtests currently specify the uncaught exception handler that they monitor.
