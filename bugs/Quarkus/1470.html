Title

Build fails when parsing an endpoint that has a bean annotated with @BeanParam when the target object is inheriting its fields from a parent class

Description
### Describe the bug

When using version **2.6.2.Final**, the build fails when parsing an endpoint that has a bean annotated with @BeanParam, if the bean is inheriting its fields from a parent class:

```
[INFO] ------------------------------------------------------------------------
[INFO] BUILD FAILURE
[INFO] ------------------------------------------------------------------------
[INFO] Total time:  12.850 s
[INFO] Finished at: 2022-01-17T15:37:28Z
... [Log Snipped] ...
[ERROR] For more information about the errors and possible solutions, please read the following articles:
[ERROR] [Help 1] [URL]
```

### Expected behavior

Project should compile and run regardless of inheritance on the annotated bean.

### Actual behavior

Project's build fails and no artifact is generated.

### How to Reproduce?

1. Clone the project: [URL]
2. Run `./mvnw clean package` or `./mvnw clean install` or `./mvnw quarkus:dev`
3. Build fails and aforementioned Exception is shown.
