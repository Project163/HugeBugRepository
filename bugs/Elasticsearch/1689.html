Title

Pre-registered indexed search template not working

Description
I have worked with Search-Templates before. In older versions of ES it worked.
But now in ES 5.0.1 it is not working anymore.
I'm following the docs here:
[URL]


	POST /_search/template/template1
	{
	  "template": {
	    "size": 10,
	    "query": {
	      "multi_match": {
		"query": "{{query_string}}",
		"fields": [
		  "description",
		  "title"
		]
	      }
	    }
	  }
	}


	GET /_search/template
	{
	    "id": "template1", 
	    "params": {
		"query_string": "search for these words"
	    }
	}

Storing the template returns a success message.

Searching returns:

	{
	  "error": {
	    "root_cause": [
	      {
		"type": "illegal_state_exception",
		"reason": "There are no external requests known to support wildcards that don't support replacing their indices"
	      }
	    ],
	    "type": "illegal_state_exception",
	    "reason": "There are no external requests known to support wildcards that don't support replacing their indices"
	  },
	  "status": 500
	}


The .scripts index is empty aswell.

Is the documentation wrong or is it a bug?

- @svola you didn't mention that you have x-pack installed.  this is a bug with the interaction between search templates and x-pack security.  If you specify an index it'll work (eg `GET my_index/_search/template`)

We'll work on a fix for the search template API
