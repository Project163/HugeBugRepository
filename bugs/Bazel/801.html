Title

CC Toolchain broken with BAZEL_DO_NOT_DETECT_CPP_TOOLCHAIN=1

Description
The cc toolchain autodetection is supposed to honor the `BAZEL_DO_NOT_DETECT_CPP_TOOLCHAIN` environment variable and disable itself. However, due to a bug in cc_configure.bzl, this does not work:

Error:
```
$ BAZEL_DO_NOT_DETECT_CPP_TOOLCHAIN=1 /tmp/bazelisk query 'deps(//:hello)'
INFO: Call stack for the definition of repository 'local_config_cc' which is a cc_autoconf (rule definition at /root/.cache/bazel/_bazel_root/ /external/bazel_tools/tools/cpp/cc_configure.bzl:143:15):
 - /root/.cache/bazel/_bazel_root/ /external/bazel_tools/tools/cpp/cc_configure.bzl:179:5
 - /DEFAULT.WORKSPACE.SUFFIX:385:1
ERROR: An error occurred during the fetch of repository 'local_config_cc':
... [Log Snipped] ...
		paths( )
'dict' object is not callable
```

[Link: Actual cause]:
```
repository_ctx.symlink(paths("@bazel_tools//tools/cpp:BUILD.empty"), "BUILD")
```

The `paths` variable is a dict and the value should be accessed as `paths[...]`, not `paths(...)`.
Discussion
- Reproduction:
```
sh
touch WORKSPACE
cat >>hello.cc  

... [Log Snipped] ...
EOF
BAZEL_DO_NOT_DETECT_CPP_TOOLCHAIN=1 bazel build //:demo
```

This should give an error, but not this error.
