Title

DateTimeUtilsSuite fails for JDKs using the tzdata2018i or newer timezone database

Description
org.apache.spark.sql.catalyst.util.DateTimeUtilsSuite 'daysToMillis and millisToDays'  test case fails because of an update in the timezone library: tzdata2018h. This retroactively changes a the value of a missing day for the Kwalalein atol. See for more information:  [URL]

 Let's fix this by excluding both dates.
