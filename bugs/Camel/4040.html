Title

PGP Decryptor does not make Integrity check

Description
A PGP Message can contain a Modification Code Detection Packet (MDC) which contains a hash value of the clear text data. This hash value can be used to check the integrity of the clear text data. Currently this check is not executed in the unmarshall method of the PGP Data Formater.
