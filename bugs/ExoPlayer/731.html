Title

AdaptiveTrackSelection can't be extended in Kotlin

Description
I'm currently updating ExoPlayer in my app from 2.12.1 to 2.13.3.
Until now we were subclassing `AdaptiveTrackSelection` with a custom Kotlin class that fits our needs, but with commit [URL] it is no longer possible because `AdaptativeTrackSelection.AdaptationCheckpoint` is `protected`.

Here is a minimal sample code in Kotlin showing the problem:
```
class CustomAdaptiveTrackSelection(
    group: TrackGroup,
    tracks: IntArray,
    bandwidthMeter: BandwidthMeter,
    private val someParameter: Int
... [Log Snipped] ...
    }
}
```
With the compilation error being:
```
'protected (in Factory)' function exposes its 'protected (in AdaptiveTrackSelection)' parameter type argument AdaptationCheckpoint
```
Discussion
- Thanks for reporting - it looks like Kotlin is very defensive about subclasses 'accidentally' increasing the visibility of elements:
[URL]

Slightly different to your reported problem: I think the `protected AdaptationCheckpoint` class is also problematic in a pure Java subclass of `AdaptiveTrackSelection.Factory` that isn't itself inside a subclass of `AdaptiveTrackSelection`, which is something someone might want to reasonably do (e.g. `DefaultMediaSourceFactory` isn't nested inside a `MediaSource` implementation). Concretely, this doesn't compile:

```
java
class CustomAdaptiveTrackSelectionFactory extends AdaptiveTrackSelection.Factory {
  @Override
  protected AdaptiveTrackSelection createAdaptiveTrackSelection(
      TrackGroup group,

  }
}
```
