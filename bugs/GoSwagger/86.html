Title

Code generated from spec file does not compile

Description
## Problem statement

We have encountered a problem where the Go project generated from the "generate server" command does not compile in certain situations.  

The swagger specification attached uses inheritance.  Cat and Goat definitions inherit from Pet. There is a post operation under the /Pets resource that returns Pet.  However the code generated from this spec file does not compile.  There is a pointer problem and we get the following error...

_"cannot use payload (type *models.Pet) as type models.Pet in assignment:"_
## Swagger Specification

```
JSON
{
    "swagger": "2.0",
    "info": {
        "title": "Pet Testing",
... [Log Snipped] ...
    }
}
```
## Steps to reproduce
1. Execute Go-Swagger over the provided Swagger specification file using the "generate server" command.
2. Build the created project using the "go build" command.
