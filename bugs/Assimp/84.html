Title

Triangulation issue with some meshes

Description
For some meshes (example in the attached zip file), the triangulation using `aiProcess_Triangulate` doesn't seem to work correctly. In the example, a part of the mesh is missing when importing it. When the mesh is imported to Blender, then exported with triangulation, the missing part is included.
The problem is not limited to .obj files, the mesh has the same problem when exported as .fbx or .3ds file.
