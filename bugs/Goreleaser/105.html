Title

post_install only properly indents the first line

Description
### What happened?

If you create a goreleaser file with multiple lines in the post_install specified, only the first line is indented properly in the generated formula. This causes syntax errors and the formula does not install properly.

If your goreleaser config has the following:
```yml
...
brews:
    ...
    post_install: |
        etc.install "config1.conf"
        etc.install "config2.conf"
        etc.install "config3.conf"
```

The generated formula outputs the following:
```rb
...
  def post_install
    etc.install "config1.conf"
etc.install "config2.conf"
etc.install "config3.conf"
  end
```

Instead of the expected:
```rb
...
  def post_install
    etc.install "config1.conf"
    etc.install "config2.conf"
    etc.install "config3.conf"
  end
```

### How can we reproduce this?

You can just create a goreleaser config with multiple lines in the `brews.post_install`
