Title

3.0 Query function builder does not handle numeric literals

Description
Trying to build something like this....

```
php
// Query
$Query->where(function ($expr) use ($field, $value1, $value2, $Query) {
    $field = $Query->func()->left([$field, '32' => 'literal']);
    return $expr
... [Log Snipped] ...
    ]
]
```

The [Link: FunctionExpression] class checks if the `$k` is a string and if value `=== 'literal'` which in this case it actually is however `debug(is_string('32'));` will return `true`. I also have trouble generating SQL similar to `CAST(SUBSTRING(field, 32) AS SIGNED)` because I can't overload the [Link: `$conjunction`] option. I'm not sure if this is an _official_ issue as it does kind of seem like a grey area of me just making my own `CastExpression` class but I kind of felt like the literal was an issue.

While this did solve my specific issue I was not able to use the literal flag on the `32` so this is still a bug. Also it is difficult to handle `CAST()` functions since there is no separator.
