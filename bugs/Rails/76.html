Title

Content-Type:#

Description
In Rails 4.0.1, the generated Content type is the following:
- for `template.haml` it is `text/html; charset=utf-8`
- for `template.en.haml` it is `# ; charset=utf-8`
- for `template.en.html.haml` it is `text/html; charset=utf-8`

I'm expecting not to get the NullType as a content type when I use localized HAML templates, as it breaks the rendering in browsers (Chrome shows the HTML source).

With Rails 4.0.0, the generated content type was correct in all cases. I think this is related to [URL]
