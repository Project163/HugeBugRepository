Title

[bug] armv7 & aarch64 appimage bundler script 404 links

Description
### Describe the bug

The [Link: appimage bundler] on armv7 devices attempts to download AppImageKit using armv7 which doesn't exist. The correct link uses armhf.

[Link: appimage.rs (line 25)] 
This function rewrites the architecture binary names so would be appropriate to change armv7 to armhf here.

### Additional context

Change
```rust
let arch = match settings.binary_arch() {
    "x86" => "i386",
    "x86_64" => "amd64",
    other => other,
};
```

To
```rust
let arch = match settings.binary_arch() {
    "x86" => "i386",
    "x86_64" => "amd64",
    "armv7" => "armhf",
    other => other,
};
```
