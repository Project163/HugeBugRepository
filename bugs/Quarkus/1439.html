Title

Hibernate Panache sorting not working with Named Query

Description
### Describe the bug

Sorting not working with Named Query

```
@Entity
@NamedQueries({
        @NamedQuery(name = "countFruit",
                query = "FROM Fruit")
})
... [Log Snipped] ...

}
```

### Expected behavior

find, list and stream functions should support sorting for named queries also. 

### Actual behavior

No errors, but the result list is not sorted if named query is used

Discussion
- When using a named query, we have no idea what is the query so we cannot just "blindly" add an ORDER BY clause.
That's why you cannot use sorting, you should add your own order by clause in your named query.
Maybe we should add in the documentation that sorting should be made manyally with a named query
- Or even better, we should throw an exception instead of silently ignoring when someone tries to sort and we cannot apply the sort.
- ... [Middle Discussions Snipped for Brevity] ...
- It was invalid usage, and it didn't behave as expected. That's reason enough to break backwards compatibility IMO.
If we can only change behavior when there's an actual exception, there's a whole lot of bugs we'll never be able to fix.
- OK then, I'll implement an IllegalArgumentException when using named query and sort
