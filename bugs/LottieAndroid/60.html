Title

LottieAnimationView progress value might get greater than value set in setMaxProgress previously.

Description
**Link to fork with a repro in the issue-repro module**
[URL]

**Describe the bug**
LottieView progress field value could be greater than setMaxProgress(`value`).

**Use case:**
We are trying to use LottieView as a progress view, where we can animate between progress states.
We use setMaxProgress(`value`) and playAnimation() to display current progress.
However sometimes LottieView displays wrong progress. (Greater than `value` used in `setMaxProgress`)

**Issue details**
It looks like when we call `setMaxProgress` on `LottieAnimationView` with some particular value.
`LottieAnimationView` do not fully respect `setMaxProgress` value and actual `progress` of the view might get greater than max value previously set.

**Steps To Reproduce**

1. Run the issue IssueReproActivity activity
2. No loop, no autoplay
3. setMaxProgress(value) to 0.32f (just as an example)
4. Start animation with playAnimation()
5. Wait till animation end
6. Compare progress value with 0.32f
Actual Result: progress is  0.32752827 that is greater than 0.32
Expected Result: progress is <= 0.32

See details in the PR at the top.
