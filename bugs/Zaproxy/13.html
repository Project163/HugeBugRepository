Title

Context's technologies not used in active scan unless overridden

Description
Steps to reproduce the issue:
1. Run ZAP (easier to see the issue with ZAP built from @  and "Active scanner rules" add-on built from zaproxy/zap-extensions@ );
2. Configure a context and disable DB technology;
3. Active scan the node of the selected context;
4. Note that the "SQL Injection" scanner was run even if DB was not enabled;
5. Run again the active scan but this time override the technologies of the context and disable the DB technology (in "Technology" tab after enabling "Show advanced options").
6. Note that this time the "SQL Injection" scanner was not run as expected.

Remarks:
This also affects the API when active scanning as an user (although in this case it's not possible to override the technology).

ZAP Version:
Version 2.4.0 (and weekly releases).
