Title

no-trailing-spaces does not properly handle skipBlankLines

Description
When running

```
eslint --reset --rule 'no-trailing-spaces: [2, {skipBlankLines:true}]' test.js
```

with `test.js` as (where `_` is a space and `>` is a tab character)

``` javascript
var a = 'bar';__
_
```

outputs the following:

```
test.js
  2:0  error  Trailing spaces not allowed  no-trailing-spaces
  3:0  error  Trailing spaces not allowed  no-trailing-spaces

✖ 2 problems (2 errors, 0 warnings)
```

which is incorrect. The expected outcome is

```
test.js
  1:14  error  Trailing spaces not allowed  no-trailing-spaces

✖ 1 problem (1 error, 0 warnings)
```

This is being caused by the [Link: regex used for detecting trailing whitespace].
Discussion
- Which version of ESLint are you using? And which parser?
- I was able to reproduce this with the default parser and latest version of ESLint. Seems like a bug to me.
- That [Link: regex] is a little weird.

```
var BLANK_PREFIX = "[^( |\t)]"
```

It could be reduced to this. Not sure if that makes any difference. 

```
var BLANK_PREFIX = "[^ \t]"
```
