Title

Incorrect warning printed when setting server config options via CLI flag

Description
This bug is actually caused by #2989, but I'm filing it separately as fixing #2989 may end up being a few days worth of effort while a small workaround to fix this apparently incorrect behavior (that's just a bandaid until the real issue is fixed) would likely only take a couple hours.

What happens here is that a file calls `config.get_option` on import, causing config files to be parsed, then when `load_config_options` later gets called to set config options set via CLI flag, a change to the `[server]` section is detected and thus a warning about this is incorrectly printed.
