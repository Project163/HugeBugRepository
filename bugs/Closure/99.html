Title

Numbers and quoted property names reject for get and set properties.

Description
- Use --language_in=ECMASCRIPT5.
- Note that these definitions cause parse errors:

var x = { get 'x'() { return 1 } };
var x = { get 1() { return 1 } };

ES5 allow these.  The Rhino parser needs to be updated.
Discussion
- Rhino was patched so these are now accepted.  Numbers aren't pass through properly yet.
