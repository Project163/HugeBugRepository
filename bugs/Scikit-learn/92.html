Title

Searching across FeatureUnion transformer_weights in a GridSearchCV

Description
I have a Pipeline set up very similar to the FeatureUnion with heterogeneous data sources example (http://scikit-learn.org/dev/auto_examples/hetero_feature_union.html), but I'm attempting to grid-search over the different ways of weighting the transformers in the FeatureUnion:

``` python
parameters = {
    'features__transformer_weights': [{'summary_stats': 1.0, 'vocab': 0.5},
                                      {'summary_stats': 1.0, 'vocab': 1.0},
                                      {'summary_stats': 1.0, 'vocab': 0.1}]
}

grid_search = GridSearchCV(full_clf_with_length, parameters, n_jobs=1, verbose=1, scoring='roc_auc')
```

However, it looks like parameters of FeatureUnion objects aren't accessible from within a GridSearch. This would be a useful feature for me, and I'd be happy to contribute a PR if someone could point me in the right direction.
Discussion
- You're right: the exclusion of `transformer_weights` from `FeatureUnion.get_params(deep=True)` is a bug.
- This is broadly related to #1769 which reworks the `get_params` interface for `Pipeline` and `FeatureUnion`
- Fixed in #4467
