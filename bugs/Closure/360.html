Title

Incomplete annotations for the animate & queue functions in jquery externs

Description
The animate and queue functions need slightly more flexible annotations on their arguments.

.animate():
The easing argument can be dropped with the callback becoming the 3rd argument.
See the 2nd example under Basic usage: [URL]

.queue();
The queue-name can be dropped with the queue becoming the 1st argument.
[URL]

Here's what I've changed them to. Somehow I can't create a diff because the file is marked as a binary file in the svn (application/javascript mime-type)..

/**
 * @param {Object.<string,*>} properties
 * @param {(string|number|Object.<string,*>)=} arg2
 * @param {(string|function())=} arg3
 * @param {function()=} complete
 * @return {jQuery}
 */
jQuery.prototype.animate = function(properties, arg2, arg3, complete) {};


/**
 * @param {(string|Array.<function(this:jQuery)>|function(function()))=} arg1
 * @param {(Array.<function(this:jQuery)>|function(function()))=} arg2
 * @return {(Array.<Element>|jQuery)}
 */
jQuery.prototype.queue = function(arg1, arg2) {};
Discussion
- The jQuery extern is generated from [URL]

For animate, I've contacted the jQuery documentation team to ask that a signature be added to the API that reflects this usage.

For methods who have an optional first parameter, I'll need to make some corrections on my end.
- The jQuery team has confirmed that for all methods, you may omit an optional parameter without omitting any following parameters. This will significantly change my generation program and add complexity. I'm working on addressing this, but it will take time.
- Thanks for looking into this. I figured functions like .click() work in a similar way - the 2nd arg can also become the first one. But I see now that the 2nd arg is mandatory there..
