Title

RuleTester prints `\u000a` instead of newline

Description
Since eslint 6, rule tester prints newline in codes as `\u000a`. It is hard to read for plugin developers. 

#### Code to repoduce
```
npx mocha index.js
```

```
js
// index.js

const {RuleTester} = require('eslint');

... [Log Snipped] ...
  ],
});
```
#### Actual output
Note the lines with `\u000a`.
```
0 passing (46ms)
  1 failing

  1) some-rule
       invalid
... [Log Snipped] ...
      -0
      +1
```

#### Expected ouput
This is the behavior with `npm i eslint@5`.
```
1) some-rule
       invalid
         
        var a;
        var b;
... [Log Snipped] ...
      -0
      +1
```
