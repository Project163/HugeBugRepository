Title

[Libtorch C++] `torch::save` crash if the folder is not created

Description
### 🐛 Describe the bug

example
```
int main(int argc, char* argv[]) {
    auto m = torch::nn::Linear(5, 5);
    torch::save(m, "./aaa/bbb.pt");
}
```
If the folder `aaa` does not exist then it will crash. The correct behavior should be logging error message or creating the folder.

### Versions

Libtorch 1.11.0 (for cuda 11.3)
MSVC2019
