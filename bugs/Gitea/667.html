### Description

The comment edit history dropdowns are only initialized once when the page loads.
If additional diffs are loaded afterwards (via "Show More" or "Load Diff"), their code comments don't have the edit history. 

Example:
* [URL] -> "Show More" -> you'll see the edited comment on file 99 has the edit history dropdown, while the edited comment on file 105 does not
* [URL] -> "Load Diff" -> the edited comment does not have the dropdown
