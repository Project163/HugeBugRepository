Title

Large Files uploading to dropbox restarting from 0

Description
```
file1.mkv: 17% done, 7.613 MBytes/s, ETA: 14m3s
file1.mkv:  0% done, 17.252 MBytes/s, ETA: 7m30s
file1.mkv:  1% done, 946.785 kBytes/s, ETA: 2h18m49s
file1.mkv: 17% done, 2.200 MBytes/s, ETA: 48m38s
file1.mkv:  2% done, 2.071 MBytes/s, ETA: 1h1m34s
```

It's like dropbox keeps being told to "start again". This can get very tiring when you cannot upload large files (40GB)
Discussion
- found this error `Post [URL] http: server closed idle connection`
- Found more information

```2017/11/08 03:02:05 DEBUG : pacer: low level retry 1/1 (error Post [URL] unexpected EOF)
2017/11/08 03:02:05 DEBUG : file1.mkv: Received error: upload failed: Post [URL] unexpected EOF - low level retry 1/10
2017/11/08 03:02:05 DEBUG : pacer: Reducing sleep to 15ms```

Basically on the first error, it restarts from the start, rather than uploading the same "block"
