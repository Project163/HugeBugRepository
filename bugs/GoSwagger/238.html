Title

Updating go-openapi breaks $ref on windows

Description
## Problem statement

Updating to latest go-openapi/spec exposed a known issue on windows with $refs (see #go-openapi/spec#97).

Since the update brought a lot of improvements and bug fixes from various contributors, I am updating go-swagger
and temporarily disable our appveyor CI run on windows.

Solving the windows issue on go-openapi/spec is not that easy, however. My hunch is that we have to change the
ref normalizer and canonicallize URIs on local files (e.g. file:///C:/mypath instead of C:\mypath).
