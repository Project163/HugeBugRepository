Title

Subpackage extraction that contains vlt:definitiion might already have installed state

Description
installing a package with subpackages just writes their packages node to the repository. if the subpackage contain a vlt:definition node, that contain a  lastUnwrapped  property, then the sub packages is already considered installed.
Discussion
- fixed in r1738155
- Note that the sub-packages handling is not optimal yet. if a sub-package is already installed, its installed state should not be reset when the uber package is extracted. otoh, it should clear potential lastUnwrapped properties.
