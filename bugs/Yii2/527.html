Title

Bug on migration tool when creating fields with brackets in comment

Description
### What steps will reproduce the problem?

./yii migrate/create create_sets_table --useTablePrefix=1 --fields="name_ru:string(255):notNull:comment('Name of set (RU)')"
### What is the expected result?

$this->createTable('{{%sets}}', [
     'id' => $this->primaryKey(),
     'name_ru' => $this->string(255)->notNull()->comment('Name of set (RU)'),
]);
### What do you get instead?

$this->createTable('{{%sets}}', [
     'id' => $this->primaryKey(),
     'name_ru' => $this->string(255)->notNull()->comment('Name of set (RU)')**()**,
]);

| PHP version | 7.0.8 |
| Operating system | Ubuntu 16.04 |
