Title

Add a warning when implicitly converting a function to a boolean

Description
Compile the following code:

  goog.require('goog.structs.Map');

  var main = function() {
    var map = new goog.structs.Map();
    if (map.isEmpty) { // <-- *
      alert('empty');
    }
  };

  main();

What is the expected output?
A warning that says something like "Warning: map.isEmpty is a function. Did you mean "map.isEmpty()"?

What do you see instead?
No warning.
Discussion
- This has come up before. The counter-argument is that this is a very common pattern in JS
if (element.chromeMagic) {
  element.chromeMagic()
}
- This is used widely. This problem is made worse by the fact that property renaming invalidates the following pattern:

if ('getContext' in element) {
  element.getContext('2d');
}

I could see such a warning being part of a diagnostic group that wasn't enabled by default.
