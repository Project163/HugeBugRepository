### Current vs. Expected behavior

## Current behavior
Page revalidation is getting (mostly) stale fetch data, causing every second revalidation to reuse old data.

## Expected behavior
The page derives it's revalidation from the fetch call. So it makes sense that when the page is revalidated it's because it should be re-rendered with updated fetch data. 

The time in the example should update every ~5 seconds.
