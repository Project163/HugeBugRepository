Title

Sub-configs stopped supporting json files

Description
**What version of ESLint are you using?**
2.0.0

**What configuration and parser (Espree, Babel-ESLint, etc.) are you using?**
Babel-ESLint

**What did you do? Please include the actual source code causing the issue.**
Updated eslint from v1 to v2 with my shareable config.

**What did you expect to happen?**
My shareable config would continue to work with sub-configs as json files.

**What actually happened? Please include the actual, raw output from ESLint.**

```
D:\Projects\project\node_modules\eslint\lib\config\config-file.js:361
            throw e;
            ^

Error: Cannot find module 'eslint-config-noamokman/test' from 'D:\Projects\project\node_modules'
... [Log Snipped] ...
    at getLocalConfig (D:\Projects\project\node_modules\eslint\lib\config.js:129:23)
    at Config.getConfig (D:\Projects\project\node_modules\eslint\lib\config.js:222:22)
```

Hi, now that we got the formalities out of the way,
I have a shareable config called [Link: eslint-config-noamokman].
I recently updated it to work with eslint 2.
But it seems that the `test` sub config stopped working.
After checking the problem, it seems that the resolve module can't search for a json file when given: `eslint-config-noamokman/test`.

My module has an `eslint.json` for the main config, and a `test.json` for testing.
Changing from `test.json` to `test.js` fixes the problem, but I would like to add support for both.

I know that I have to open an issue first, so if everything looks good I would like to submit a PR.

Thanks,
Noam.

- YAML subconfigs work fine. We use one in the ESLint repo.
