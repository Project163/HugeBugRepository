Title

FixedChannelPool throw java.lang.IllegalStateException: Channel is unhealthy not offering it back to pool

Description
Hi, i am trying to write some TCP stuff with FixedChannelPool. The documentation says i have to return any channel that borrow from pool even if the channel already dead, but when i do return the channel, FixedChannelPool throw java.lang.IllegalStateException: Channel is unhealthy not offering it back to pool.
Is this bug ?
if i don't release the channel to FixedChannelPool its never give any connection when dead channel count = max_pool_size.
if i just ignore the exception, everything works fine, but i think this should never happend.

### Expected behavior
i expect no exception thrown
### Actual behavior
throw  java.lang.IllegalStateException: Channel is unhealthy not offering it back to pool.
### Steps to reproduce
1. Create FixedChannelPool.
2. call aquire channel
3. kill channel
4. call release channel, but the returned ChannelFuture call get()
5. TA DA throw  java.lang.IllegalStateException: Channel is unhealthy not offering it back to pool.
