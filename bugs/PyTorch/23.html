Title

einsum shape zero

Description
## 🐛 Bug

`torch.einsum` crashes when the shape of the input contains zeros. 

## To Reproduce

Steps to reproduce the behavior:

```python
torch.einsum('ij,j', torch.randn(0, 3), torch.randn(3))
```
```
RuntimeError: shape '[1, 1, 3]' is invalid for input of size 0
```

- What do you expect, btw? An empty tensor or a better error message?
- We expect numpy's behavior:
```
In [29]: np.einsum('ij,j', np.random.randn(0, 3), np.random.randn(3))
Out[29]: array([], dtype=float64)
```
- I expect a tensor of shape `[0]`
- ## zeros in the output indices
If I run `torch.einsum('anything->ijkl', ...)` I expect the output to have dimension 4 and the shape corresponding to the indices `i`, `j`, `k` and `l`.

Example
```
torch.einsum('ijk,k->ij', torch.randn(3, 0, 6), torch.randn(6)) == torch.empty(3, 0)
```

## zeros in the contracted indices
If one of the contracted indices is shape zero it means that you sum over nothing, therefore the result is well defined and is a zero tensor.
```
torch.einsum('ij,j->i', torch.randn(4, 0), torch.randn(0)) == torch.zeros(4)
```
