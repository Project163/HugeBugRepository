Title

Problem of using multiple selection in filter

Description
### What steps will reproduce the problem?

1. Add drop-down list that allows multiple selections to GridView filter.
2. Select some value from drop-down.
3. Select any page from grid pagination.
4. Select different value from drop-down.

### What is the expected result?
After step 4 drop-down value should be changed to new.

### What do you get instead?
Value that was selected before.

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.10
| PHP version      | 5.6
| Operating system | Linux
