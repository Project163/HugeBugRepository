Title

MediaTypeHeaderProvider not handling all invalid media types

Description
According to  [URL] there are a lot of characters that are not allowed in the type or subtype fields of a MIME /MediaType.  Currently, CXF only checks for '/' in the subtype. 

 Instead it should be checking for: 
     tspecials :=  "(" / ")" / "<" / ">" / "@" / 
                   "," / ";" / ":" / "\" / <"> 
                   "/" / " [" / "] " / "?" / "=" 
                   ; Must be in quoted-string, 
                   ; to use within parameter values
