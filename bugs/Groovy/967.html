Title

closer calls with array as argument fail

Description
def doSomething={ list ->
    println list
}

 String [] x=[ "hello" ,  "world" ]
 String [] y=[ "hello" ,  "world" ]

doSomething(x as  String [])  //works
 doSomething(y)  //fails with Exception thrown: No signature of method: ConsoleScript15$_run_closure1.call() is applicable  for  argument types: (java.lang. String , java.lang. String ) values: [hello, world]

- Seems to have been caused by the array unwrapping logic introduced in the fix of   GROOVY-2266  .  

 The array unwrapping should not happen if argument passed is an array that contains more than 1 element. Because then there is no call() / doCall() that can take more than 1 arg, which is what is happening in this JIRA.  
{"hello", "world"}
  array gets unwrapped as 2 individual elements and then there is no closure call()/doCall() to handle that call with 2 args.
