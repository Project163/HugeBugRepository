### Describe the Bug

When using `next/image` in a component library with `priority` and custom `devicesSizes`, the custom `deviceSizes` are ignored for production runs. The generated `srcset` contains the default widths instead of the custom ones.

Similar issues have been reported previously (https://github.com/vercel/next.js/issues/33228, [URL] but the implemented fix (https://github.com/vercel/next.js/pull/33559) doesn't resolve the issue described above.

I've managed to create a failing test (see [URL] but I'm not sure whether I should create a PR for a failing test.

### Expected Behavior

The custom `devicesSizes` specified in `next.config.js` are used for `next/image` when using `priority`.
