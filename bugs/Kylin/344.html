Title

Fix async query status for out of segment range situation

Description

    
Discussion

    
- RC 

 In the query logic for out of segment range, the current behavior is to just return empty results 
This is fine for normal queries, but in this case asynchronous queries do not generate the _SUCCESS file used to determine the results, resulting in the status of the asynchronous query never being updated
- Dev Design 

 After determining out of segment range, record the status to QueryContext and continue to release the query logic for asynchronous query until it reaches the location where the asynchronous query result is saved, and then write the corresponding KE-xxx error code in the _SUCCESS file to give the corresponding hints to the interface of the asynchronous query status.
