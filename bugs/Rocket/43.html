Title

Cookies from error handlers are ignored

Description
Consider the following application running under `0.4.2`:

```
rust
#![feature(proc_macro_hygiene, decl_macro)]

#[macro_use] extern crate rocket;

... [Log Snipped] ...
        .launch();
}
```

Cookies set by the `index` route will be reflected as normal. Cookies set by `net_found`, however, are not reflected. Rocket should reflect cookies set by error handlers.
