Title

curl with wolfSSL and renegotiation

Description
Hi, 

I am using curl (with wolf ssl lib) to connect https endpoint, but connection with this https endpoint gets terminated because server initiates the renegotiation and client does not handle renegotiation. To enable the renegotiation feature in wolf ssl, I have compiled wolf ssl with --enable-secure-renegotiation and use that version to compile with curl, but I am still getting same results.

Build steps:

cd  /home/ /gitroot/curl/
 ./configure --prefix=/home/ /wolfsslinstall --enable-postauth --enable-tls13 --enable-libwebsockets --enable-harden --enable-aesni  --enable-psk --enable-stacklog --enable-sni --enable-alpn --enable-trustedca --enable-truncatedhmac --enable-stunnel --enable-certservice --enable-enckeys --enable-secure-renegotiation --enable-debug
make 
make install

cd /home/ /gitroot/curl
./configure   --with-wolfssl=/home/ /wolfsslinstall --without-ssl --without-zlib --enable-debug 
 make 
make install


### curl/libcurl version
Both for curl and woflssl I am using master HEAD.

### operating system
Linux krtos 5.3.0-1032-azure #33~18.04.1-Ubuntu SMP Fri Jun 26 15:01:15 UTC 2020 x86_64 x86_64 x86_64 GNU/Linux
