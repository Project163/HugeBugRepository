Title

"fields" is missing in hit if script field returns a null value

Description
I use Elasticsearch 2.2 & 1.7.

With this query:

``` json
{
  "script_fields": {
    "test": {
      "script": "return null"
    }
  }
}
```

Elasticsearch 1.7 returns:

```
json
{  
  "_index":"xxx",
  "_type":"yyy",
  "_id":" ",
... [Log Snipped] ...
  }
}
```

Elasticsearch 2.2 returns:

``` json

{  
  "_index":"xxx",
  "_type":"yyy",
  "_id":" ",
  "_score":1
}
```

Is it a bug or a feature?
Discussion
- This is the result of #8592. If we want to support `null` as a valid return value from scripts, we would need to remove the first `if` condition added there. @jpountz thoughts?
- @rjernst Sounds good to me.
