Title

CompileStatic: long loses type when bitwise OR applied to it

Description
This code: 

  
 @groovy.transform.CompileStatic
 class  Test {
   long [] data
   long  topMask
    
  void doSomething() {
     long  mask = 0
    mask = mask | 0x1L
    data[ 0 ] = data[ 0 ] | mask
  }
}

 new  Test()
 
  

 Gives the error: 

  
 [Static type checking] - Cannot assign value of type java.lang. Number  to variable of type  long 
 
  

 A workaround is to add a cast: 

  
     data[ 0 ] = data[ 0 ] | ( long )mask
 
  

 But I think that might cause   GROOVY-5921   to rear its head again... 

 Investigating
Discussion
- StaticTypeCheckingVisitor#getResultType(...) doesn't unwrap from java.lang.Long to long. Therefore, the inferred type of mask is java.lang.Long. (long | java.lang.Long) in the end leads to taking the return type from the DGM.or(Number, Number) method.
