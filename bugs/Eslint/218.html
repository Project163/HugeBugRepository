Add --no-eslintrc to eslint -h

Description
The `--no-eslintrc` flag is undiscoverable from `eslint -h`; I was looking for a way to disable eslintrc and only stumbled upon it by searching the docs.

- I started working on it but have bumped into an issue.

A flag can have multiple aliases, including a shorthand one letter alias. These can be specified together (eg. `-abcd`). There is no way to negate a one letter shorthand flag. Say I've defined an option `colour` with aliases `color` and `c`, and the default is `true`. We can obviously display `--no-colour` and `--no-color`, but how should we display the shorthand flag? I think it should be consistent, and either all flags should show the "on" variant or all the "no" variant.

So, we can either:
- Come up with some way to negate one letter flags - but I can't think of a nice way to do this
- Only change all boolean default=true flags to `--no` if they don't have a one letter alias
- I'd go with option #2.
