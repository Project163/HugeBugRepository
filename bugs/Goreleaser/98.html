Title

[Bug]: Docker images and custom release notes file don't seem to mix

Description
### What happened?

Created a new release for Changie which writes its own release notes file and passes it to goreleaser. In the latest release I also added docker releases and the body of the release only has the docker image details and not the contents of the release notes file.

I edited the release so below is what the output was versus what I expected.

Output was:
```


## Docker images

- `docker pull ghcr.io/miniscruff/changie:v1`
- `docker pull ghcr.io/miniscruff/changie:v1.1`
- `docker pull ghcr.io/miniscruff/changie:v1.1.0`
```

Expected: ( release note file should be above docker images )
```
## v1.1.0 - 2021-10-24
### Added
* [Ref: #166] Option to use environment variable for config path
* [Ref: #166] Try and load .changie.yml if .changie.yaml fails
```
