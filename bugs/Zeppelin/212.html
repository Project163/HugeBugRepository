Title

JDBC Interpreter mangles SQL

Description
Reproducer: 
  
 %jdbc
select max(ss_promo_sk), ss_customer_sk from qhive.tpcds_orc_500.store_sales where ss_sold_date_sk >= 2452640 and ss_customer_sk > 3 and ss_customer_sk < 20 group by ss_customer_sk
 
  

 Actually runs 
  
 _promo_sk), ss_customer_sk from qhive.tpcds_orc_500.store_sales where ss_sold_date_sk >= 2452640 and ss_customer_sk > 3 and ss_customer_sk < 20 group by ss_customer_sk'
 
  

 It looks like it is trying to find a property key which is a feature I do not understand. 

 Logs: 
  
  INFO [2016-01-22 19:16:02,306] ({pool-2-thread-3} JDBCInterpreter.java[interpret]:344) - Run SQL command  'select max(ss_promo_sk), ss_customer_sk from qhive.tpcds_orc_500.store_sales where ss_sold_date_sk >= 2452640 and ss_customer_sk > 3 and ss_customer_sk < 20 group by ss_customer_sk' 
 INFO [2016-01-22 19:16:02,307] ({pool-2-thread-3} JDBCInterpreter.java[interpret]:355) - PropertyKey: ss_promo_sk, SQL command:  '_promo_sk), ss_customer_sk from qhive.tpcds_orc_500.store_sales where ss_sold_date_sk >= 2452640 and ss_customer_sk > 3 and ss_customer_sk < 20 group by ss_customer_sk' 
 
  

 The workaround is to run: 

  
 ( default ) select max(ss_promo_sk), ss_customer_sk from qhive.tpcds_orc_500.store_sales where ss_sold_date_sk >= 2452640 and ss_customer_sk > 3 and ss_customer_sk < 20 group by ss_customer_sk
 
  

 If you can explain why a propertyKey is required, I can try to provide a patch. I do not understand the intention behind propertyKeys.
