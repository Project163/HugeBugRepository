Title

Join-Dependent Relationship Hybrid Bug v1.4

Description
Join dependent relationship hybrid don't work the same way in 1.4 as they do in 1.3.  Take the example in the docs:

```
py
from sqlalchemy import Column, Integer, ForeignKey, Numeric, String
from sqlalchemy.orm import relationship
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.ext.hybrid import hybrid_property
... [Log Snipped] ...
...       join(User.accounts).filter(User.balance > 5000))
```

Works fine. However  if I change the name of the expression to test

```
py
from sqlalchemy import Column, Integer, ForeignKey, Numeric, String
from sqlalchemy.orm import relationship
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.ext.hybrid import hybrid_property
... [Log Snipped] ...
    
print(Session().query(User, User.test).join(User.accounts).filter(User.test > 5000))
```

Then I get this error:

AttributeError: type object 'SavingsAccount' has no attribute 'test'

Couldn't find a mention of this in the changelog and it worked fine in 1.3.  Sqlalchemy version is 1.4.7
