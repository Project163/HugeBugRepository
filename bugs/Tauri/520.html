Title

[bug] the asset protocol should respect HEAD method and not return body

Description
### Describe the bug

In the HTTP standard, a HEAD request is similar to a GET request but [Link: does not return a message body in the response]. 

In the current implementation of the asset protocol, the response body includes the entire file content regardless of whether a HEAD method is used, which can result in unnecessary memory consumption in certain cases.
```

      b
    } else {
```
