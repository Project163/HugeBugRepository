Title

Crash when using a template inside a Generator

Description
I have an immutable templated class with a method that return a new instance of itself with a first argument being a generator. Inside this generator I do a `foreach` on an iterator of my template.

By default psalm indicate that the value declared in this `foreach` is assigned to mixed raising an error. But when I add the comment `@var T $value` psalm crash with the message `Could not get class storage for t`.

Reproducible code can be found at [URL]

On my machine I use Psalm  `3.11.2` and PHP `7.4.1`. I have this problem since Psalm `3.11`, version `3.10.1` works fine.
