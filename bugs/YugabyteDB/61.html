Title

[dist-txns] rebalance (remote bootstrap) of "system.transactions" (txn status table) tablets does not work

Description
When adding a node the tablets of the internal txn status table (system.transactions) do not seem to be rebalance and yb-tserver attempting to remote bootstrap such a table complains with the following error:

```
W1001 16:29:08.800905 74055680 tablet_service.cc:1447] Start remote bootstrap failed: Remote error (yb/rpc/outbound_call.cc:375): \
Unable to begin remote bootstrap session: Error initializing remote bootstrap session for tablet  : \
Not found (yb/common/wire_protocol.cc:152): Received error code UNKNOWN_ERROR from remote service: Unable to create checkpoints directory \
/Users/kannan/yb-data/node-3/disk-1/yb-data/tserver/data/rocksdb/table- /tablet- /checkpoints: /Users/kannan/yb-data/node-3/disk-1/yb-data/tserver/data/rocksdb/table- /tablet- /checkpoints: No such file or directory (error 2)
```

Steps to repro on a local/pseudo cluster:
```
# create a cluster
% ./bin/yb-ctl --rf 3 --data_dir $HOME/yb-data start
# run unique-sec-index workload
% java -jar yb-sample-apps.jar --workload CassandraUniqueSecondaryIndex --nodes  :9042 --num_threads_read 4 --num_threads_write 2
let above run for a little bit...

# Add a 4th node
./bin/yb-ctl --rf 3 --data_dir $HOME/yb-data add_node
```
Check [URL] to see if tablets and leaders end up balancing or not. In my test it gets stuck when we try to move the first tablet of the system.transactions table.
