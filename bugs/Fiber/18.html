Title

Fiber Client does multiple requests when using Timeout() and MaxRedirectsCount() 🐛

Description
**Fiber version**
2.15.0
**Issue description**
With fiber.Client whenever you use a.Timeout() or a.MaxRedirectsCount() a request is made by any of these functions, therefore, more than one HTTP request is sent.
**Code snippet**
A first API:
```
go
package main

import (
	"fmt"
... [Log Snipped] ...
	log.Fatal(app.Listen(":3000"))
}
```
A second API:
```
go
package main

import (
	"github.com/gofiber/fiber/v2"
... [Log Snipped] ...
	log.Fatal(app.Listen(":3001"))
}
```

Output:

The second API receives a request for each of the mentioned methods.

[Image: image]
Discussion
- As @ReneWerner87 said on discord, here [URL] we can see that both methods: `a.HostClient.DoTimeout(req, resp, a.timeout)` and `a.HostClient.DoRedirects(req, resp, a.maxRedirectsCount)`already do a request.

Could be fixed with else if conditions or return statements, although this solution would mean the two methods wouldn't be able to work together.
