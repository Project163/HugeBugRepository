Title

after upgrading to 2.3.5 CliBuilder doesn't work.

Description
After upgrading to 2.3.5 code depending on CliBuilder doesn't compile. It fails with "unable to resolve class CliBuilder". 

 Am attaching an example gradle project. To reproduce error, just bump groovy version in the build.gradle. The same code works just fine for 2.3.4.
