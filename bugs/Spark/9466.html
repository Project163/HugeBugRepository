Title

Loading of Spark UI blocks for a long time when HybridStore enabled

Description
In our SparkHistoryServer, we used these two property to speed up Spark UI's loading: 
  
 
spark.history.store.hybridStore.enabled  true 
spark.history.store.hybridStore.maxMemoryUsage 16g  
  
 Occasionally, we found it took minutes to load a small eventlog which usually took seconds.
