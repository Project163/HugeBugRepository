Discussion
- It seems condition triggering test failure is small timeout for lock/put operations (it was 2 sec). On timeout test started to stop nodes while put/lock operations were in progress. When node is stopped then exchange future and all current update futures were completed with IgniteInterruptedCheckedException (GridCachePartitionExchangeManager.onKernalStop0), and this caused infinite loop in GridCacheAdapter.lockAll: 
  
 
 while  ( true ) {
     try  {
         return  fut.get();
    }
     catch  (IgniteInterruptedCheckedException ignored) {
         // Interrupted status of current thread was cleared, retry to get lock.
         isInterrupted =  true ;
    }
} 
  
 I think it is not correct to complete operations with IgniteInterruptedCheckedException on node stop, so I changed it to use regular IgniteCheckedException. 

 I increased timeout in original test and added special test reproducing this hang. 

 Changes are in branch ignite-9213.
