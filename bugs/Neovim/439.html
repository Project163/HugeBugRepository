Title

Crash after ` ` when using 'omnifunc' and `fuzzy` flag in 'completeopt'

Description
### Problem

Nvim can unexpectedly exit after ` ` when using 'omnifunc' that returns -2 or -3 and `fuzzy` is present in 'completeopt'.
Bisected commit: bcfc22853af1 (cc @zeertzjq, cc @glepnir).

### Steps to reproduce

1. Create the following 'init.lua':

    ```
lua
    local do_complete = false
    _G.omni = function(findstart, base)
      if findstart == 1 then do_complete = not do_complete end
      if do_complete then
... [Log Snipped] ...
    vim.o.completeopt = 'menuone,fuzzy,noinsert'
    vim.o.omnifunc = 'v:lua.omni'
```
2. `nvim --clean -u init.lua`
3. Type `abc` and press `  `. Two suggestions should appear.
4. Press ` `. Nvim exits.

Removing `fuzzy` flag makes it work as expected.

### Expected behavior

No unexpected exit.

### Nvim version (nvim -v)

NVIM v0.12.0-dev-545+gcb4559bc32

### Vim (not Nvim) behaves the same?

Probably yes, couldn't check

xterm-ghostty
