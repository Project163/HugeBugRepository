Title

Using `ReactivePanacheMongoEntity` creates `io.quarkus.bootstrap.classloading.QuarkusClassLoader` error

Description
### Describe the bug

Working with [Link: mongo reactive entities with panache] I'm finding that having an entity class that extends `ReactivePanacheMongoEntity` blows up with


Discussion
- MongoDB with Panache uses an annotation processor, if you declare your own annotation processor this will exclude the panache one.

So you need to add the Panache annotation processor:

```xml
         
           io.quarkus 
           quarkus-panache-common 
           ${quarkus.platform.version} 
         
```

Maybe this should be documented somewhere, the following section explain that an annotation processor is used but don't tell that it must be configured manually if another one is used:[URL]
- Thanks @loicmathieu adding that works. It should definitely be documented somewhere. I banged my head against a wall for a few hours yesterday trying to figure out what the issue was.
- @loicmathieu I created #26355 to update the docs for this.
