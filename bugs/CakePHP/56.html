Title

Default database must exist to load Fixtures

Description
I was following the guidelines here: [URL]

I had a clean linux box for my Jenkins server so only created the "test_XX" database and added the $test datasource to Config/database.php as per instructions.

When running the test suite after following the guidelines, I kept getting the error that database "default" did not exist.  So I added the $default database to Config/database.php and created a blank default DB.   Now got errors that table XX did not exist.  It was clearly trying to connect to the default DB and read the table.

I have had a look at the code and I think the code in lib/Cake/TestSuite/Fixture/CakeTestFixture.php#init() function is wrong.  The $this->Schema->connection is correctly set to "test" within the _construct() function (line 97) yet it is overwritten to "default" in the array_merge call in init() function at line 122.

I proved the issue by copying my dev DB over to the jenkins server and was then able to run the tests.
Discussion
- What do your fixtures look like? If you are using import fixtures you'll need to have the default db. Otherwise it is not required.
- Ah yes, they are using public $import = 'ModelName';

My mistake.
