Title

Connection.isReadOnly() returns false for network client when connection is read-only due to connection level authorization.

Description
If a user has been set to read-only status using connection level authorization (e.g. is listed in derby.database.readOnlyAccessUsers) then embedded will return true for Connection.isReadOnly() but network server returns false.
Discussion
- jdbcapi.AuthenticationTest has a comment with this bug number where the isReadOnly call is only asserted for embedded.
- DERBY-2738  is related to  DERBY-911  but not the same.
- Triaged for 10.5.2: Assigned normal urgency and flagged as difference between client and embedded usage.
