Title

ExecuteProcess NullPointerException when not Triggered

Description
When an "ExecuteProcess" processor is configured to run only on the primary node of a cluster, the "Run Once" and "Stop" commands cause an NPE to be thrown on all non-primary nodes. 

 This would also happen on any node if the "Cron" scheduling strategy was used, and the processor was started and stopped without being triggered by the cron expression.
Discussion
- Null guard around the reference to "this.externalProcess.isAlive()" in the "@OnUnscheduled" method should be sufficient.
