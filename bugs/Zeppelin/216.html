Title

Shortcut interact with interpreter with French Keyboard

Description
When you try to make some chars  ' 
{' or '}
 ' or '|' that are use in all interpreters for form, in french keyboard you need to use the 'ALT GR' key with the '4' key to make a '{'. So the shortcut 'CTRL+ALT+4' is execute and then reduce the note on 4 columns. 
A solution may be to change the shortcut or give a solution to change the shortcut in the installation.
Discussion
- Some possible reads about it that give us 2 solutions for that issue: 

 Change shortcuts in general: 
 [URL]

 Make Profiles:

 Key remapping would probably too much of a hassle to do for anybody, so either we change the shortcuts (but we might have them similar to other software on purpose), or we create different shortcut profiles based on languages. 
However, not everybody an an instance of Zeppelin might use the same keyboard profile, so config doesn't make since at instance level. 
Either we successfully implement, a keyboard detection on webapp side, or we should be able to change the profile from the UI (and save those preferences in a cookie or something)
- +1 I'm typing on a German keyboard, and it's the same problem - I cannot type square brackets. I could see how only AltGr could active 3rd level (like " [" or "] "), but Crtl+Alt is received as something else (like in Linux). However I wondered if a minor feature like changing node width should overwrite such a common shortcut (for every non-English keyboard).
