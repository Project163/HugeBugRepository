Title

Some tests depend on the culture for their success

Description
The `Failure` test method in the `Equal_Decimal` class checks to see what the values of the `Expected` and `Actual` properties are:

```
Assert.Equal("0.111 (rounded from 0.11111)", ex.Expected);
Assert.Equal("0.114 (rounded from 0.11444)", ex.Actual);
```

This test fails on my machine (located in the Netherlands), as the decimal separator on my machine is a comma instead of a period:

```
Expected: 0.111 (rounded from 0.11111)
Actual:   0,111 (rounded from 0,11111)
```

The test should be modified to use culture-specific strings.
