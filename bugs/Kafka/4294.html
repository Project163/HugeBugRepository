Title

Incorrect leaderId and leaderEpoch logged in Partition#makeFollower

Description
Partition::makeFollower  logs the existing leader-id and existing leader epoch if the partition registration has a leader epoch > the existing leader epoch. 

 There's a bug in the logging as we update the existing leaderId and leaderEpoch with the latest values from partition registration prior to logging them, thereby never logging the existing values.
