Title

Docker extra_files fails if path begins with ctx.Config.Dist

Description
### What happened?

Adding docker.extra_files in directory `dist_files/*` fails with  `invalid docker.files: can't be . or inside dist folder: dist_files`. 

The problem occurs because the docker.extra_files only checks strings.HasPrefix() between `dist` folder and `files_extra` folder. 

### How can we reproduce this?

Create a config file and build a release. The build task will fail.
```
yaml
# .goreleaser.yaml

dist: ./dist
dockers:     
... [Log Snipped] ...
       - dist_files/   #Fails
       - ./dist_files/   #Works
```
