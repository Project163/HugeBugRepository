Title

Expand CREATE TABLE CQL on a coordinating node before submitting to CMS

Description
This is done to unblock  CASSANDRA-12937  and allow preserving defaults with which the table was created between node bounces and between nodes with different configurations. For now, we are preserving 5.0 behaviour.
