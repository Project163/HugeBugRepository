Title

Validation bug of \yii\base\DynamicModel class

Description
Hello!

After [URL]  `EachValidator` using `DynamicModel` class. In case model has validation error, message will be created with attribute name, not a label.

### What steps will reproduce the problem?
Rule:

       [['sshftp_ips'], 'each', 'rule' => ['ip']]

Attribute label:

       'sshftp_ips' => Yii::t('dictionary', 'Default allowed IPs for SSH/FTP accounts'),

### What is the expected result?

When I do `$model->validate()` I want to see error:

       Default allowed IPs for SSH/FTP accounts must be a valid IP address.

### What do you get instead?

       Sshftp Ips must be a valid IP address.
