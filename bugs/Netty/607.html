Title

Calls to discardSomeReadBytes() causes the JsonDecoder to get corrupted.

Description
### Expected behavior
JsonDecoder should keep reading bytes even if the call to discardSomeReadBytes() is made.

### Actual behavior
JsonDecoder internal idx value is not reset, so the reader can no longer read bytes.

### Steps to reproduce
Send lots of data to a connection with a JsonDecoder, when a call to discardSomeReadBytes() is made the readerIndex will be reset. The internal idx of the JsonDecoder won't be reset so the decoder won't be able to read anymore bytes.
