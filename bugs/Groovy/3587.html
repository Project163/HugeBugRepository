Title

AutoExternalize AST transform replaces custom read/write method

Description
A class defined as 
  
 
@groovy.transform.AutoExternalize
 class  ClassUnderTest { 
    void writeExternal(ObjectOutput out)  throws  IOException { }
    void readExternal(ObjectInput oin) { }
}
 
  
 Will override the definition of  readExternal/writeExternal  every single time. 

 In contrast with  @Canonical  for example where explicit  toString()  is not overridden.
Discussion
- Actually, I see that the method is not overridden but is still marked as @Generated. Fixing  addGeneratedMethod  should actually fix all cases and numerous others.
- Should be fixed. I didn't add tests since your PR#950 should cover that.
