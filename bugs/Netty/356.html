Title

Noisy exception while try to detect NetUtil.SOMAXCONN on non-linux

Description
As `/proc/sys/net/core/somaxconn` does not exists on non-linux platforms you see a noisy stacktrace when debug level is enabled. 

```
java.io.FileNotFoundException: /proc/sys/net/core/somaxconn (No such file or directory)
    at java.io.FileInputStream.open(Native Method) ~[na:1.7.0_65]
    at java.io.FileInputStream. (FileInputStream.java:146) ~[na:1.7.0_65]
    at java.io.FileInputStream. (FileInputStream.java:101) ~[na:1.7.0_65]
    at java.io.FileReader. (FileReader.java:58) ~[na:1.7.0_65]
... [Log Snipped] ...
    at io.netty.bootstrap.AbstractBootstrap.bind(AbstractBootstrap.java:269) [classes/:na]
    at io.netty.bootstrap.AbstractBootstrap.bind(AbstractBootstrap.java:244) [classes/:na]
```

Better to just check if file exists before try to read it and make it so less noisy.
