Title

`st.Page` modifies the `title` parameter when displaying the page label

Description
### Checklist

- [Link: X] I have searched the [existing issues] for similar issues.
- [X] I added a very descriptive title to this issue.
- [X] I have provided sufficient information below to help reproduce this issue.

### Summary

For MPA v1, there is an algorithm for extracting a page label from the filename. MPAv2 falls back on this algorithm if no `title` is declared. However, some of this modification still occurs within the label in navigation even when `title` is declared.

### Reproducible Code Example

```Python
import streamlit as st

a = st.Page("a.py")
b = st.Page("3_real__2.py", title="1_page__2")

st.navigation([a, b])
```


### Steps To Reproduce

1. Create `app.py` as above with addition pages `a.py` and `3_real__2.py`.
2. Run the app.
3. Go to page "1_page__2" and look at navigation.
