Title

`torch.sparse.log_softmax` crash with `Floating point exception (core dumped)` in PyTorch 1.12.0

Description
### 🐛 Describe the bug

In PyTorch 1.12.0, `torch.sparse.log_softmax` will crash directly with the specific input on Cuda device , without any valid error message returned.
Similar problems also occur in 1.11.0 or earlier versions.
The root cause seems to be similar to [Ref: #82107]


### To Reproduce
```python
import torch
input=torch.sparse_coo_tensor([[]], [], (3,), device='cuda')
def test():
    result=torch.sparse.log_softmax(input,0)
    return result
print(test())
```

The error result is 
```
Floating point exception (core dumped)
```

### Expected behavior

Not crash, return empty tensor or print error message.
