Title

Malformed SQL Generated in Pagination with complex Matching() added

Description
This is a:

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.4.5
* Platform and Target: Apache2, PHP v. 5.6.2, MySQL v. 5.5.38 

### What I did

I set up a beforeFind on my ArticlesTable that adds a few matching() queries to the find Query, with one having a matching() as a sub-query.

**Relevant code from ArticlesController.php:**
```
public function index()
    {
        $articles = $this->paginate($this->Articles);

        $this->set(compact('articles'));
        $this->set('_serialize', ['articles']);
    }
```

**ArticlesTable.php**
```
...
class ArticlesTable extends Table
{
    public function initialize(array $config)
    {
... [Log Snipped] ...
    }
}
```

**TagsTable.php**
```
...
class TagsTable extends Table
{
    public function initialize(array $config)
    {
... [Log Snipped] ...
    }
}
```

**TagOptionsTable.php**
```
...
class TagOptionsTable extends Table
{
    public function initialize(array $config)
    {
... [Log Snipped] ...
    }
}
```

### What happened
I get the following SQL error:
`Error: SQLSTATE[42S22]: Column not found: 1054 Unknown column 'TagOptions.name' in 'on clause'`

And the following SQL is generated, pay special attention to the COUNT(*) call(s):
```
SELECT 
  Articles.id AS `Articles__id`, 
  Articles.title AS `Articles__title`, 
  Articles.content AS `Articles__content`, 
  Articles.created AS `Articles__created`, 
... [Log Snipped] ...
    AND TagOptions.id = (TagsTagOptions.tag_option_id)
  )
```

As you can see, the SQL generated for the COUNT(*) seems malformed.

### What I expected to happen
I expected pagination to work, with the added matching() queries.
Discussion
- I am not sure that nested matching() calls will work in this situation. I will see if I can reproduce though.
- I was able to reproduce this issue in the test suite, I'll look for a fix.
- Until this can be fixed you should use matching 'paths'. Your query can be better expressed as:

```php
$query->matching('Tags.TagOptions', function(Query $q) {
	return $q->where(['TagOptions.name' => 'display_tag']);
})
->matching('Icons', function(Query $q) {
	return $q->where(['Icons.icon' => 'sad']);
});
```
