Title

Ajax Validation with checkboxList only triggered on first select

Description
Hi I have to check that in a checkboxList are min 2 and max 3 checkboxes selected. I had written a simple inline validator for that case, which is not the problem. The Ajax validation is enabled and works for the other fields. If I select the first checkbox in the checkboxList it sends the ajax request and gives me the error, that I have to select min 2 and max 3 checkboxes, which is not that nice but also not really a problem.

The problem is that if the next checkbox is selected nothing happens, it does not send any ajax request and the error message doesn't disappear.
Discussion
- I have located the problem at `yii.activeForm.js` in function `getValue` at line ~596.

add this

``` javascript
if ($realInput.length > 1) {
    var values= [];
    $realInput.each(function(index) {
        values.push($($realInput.get(index)).val());
    });
    return values;
}
```

brefore

``` javascript
if (!$realInput.length) {
    $realInput = $form.find('input[type=hidden][name="' + $input.prop('name') + '"]');
}
```

The problem is just because the `getValue` function does not support arrays, but if you can select more than one checkox it is an array which should be supported.
