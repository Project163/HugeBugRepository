Title

Fastify Typescript RouteSchema missing headers?: JSONSchema

Description
Hello

Thank you for the great Fastify project. We're moving from Express to Fastify, because of async/await support and schema driven approach.

While using fastify v2 with typescript the following code:

```js
  const endpointsSchemas: fastify.RouteSchema = {
    querystring: '#schema-id-1#',
    headers: '#schema-id-2#',
    response: {
      200: '#schema-id-3#',
    },
  };
```

produces ts error:

```sh
error TS2322: Type '{ querystring: string; headers: string; response: { 200: string; }; }' is not assignable to type 'RouteSchema'.
  Object literal may only specify known properties, and 'headers' does not exist in type 'RouteSchema'.
         headers: '#schema-id-2#',
```

fix seems simple:
instead of [URL]
```
js
  interface RouteSchema {
    body?: JSONSchema
    querystring?: JSONSchema
    params?: JSONSchema
... [Log Snipped] ...
    }
  }
```

it should be

```
js
  interface RouteSchema {
    body?: JSONSchema
    querystring?: JSONSchema
    params?: JSONSchema
... [Log Snipped] ...
    }
  }
```

If that is correct I'd be happy to open PR with the fix.

Meanwhile we're using self declared type.
