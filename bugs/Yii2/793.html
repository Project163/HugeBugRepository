Title

ActiveField 'text' input with maxlength not working

Description
### What steps will reproduce the problem?
```
public function rules()
{
    return [
         [['username'], 'string', 'min' => 3, 'max' => 15],
    ];
}

 field($model, 'username')->input('text', ['maxlength' => true]); ?>
```
### What is the expected result?
It should output `maxlength="15"` to the rendered input field. 
### What do you get instead?
`maxlength=""`

However if I use `$form->field()->textInput()` instead it works as expected.

I prefer to use `$form->field()->input('text')` for consistency in my forms for different input types.

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      |  ?
| PHP version      | 7.2
| Operating system | Windows 10
Discussion
- Hi!
The cause of the problem is the loss of the length normalization function. When you add a function, everything falls into place.

Writing options:

**Option 1:**
```php
 field($model, 'username'); ?>
```
```html
 
```
**Option 2:**
```php
 field($model, 'username')->textInput(['maxlength' => true]); ?>
```
```html
 
```
**Option 3:**
```php
 field($model, 'username')->input('text'); ?>
```
```html
 
```
**Option 4:**
```php
 field($model, 'username')->input('text', ['maxlength' => true]); ?>
```

