Title

Failed upgrade leaves a syncthing file in program folder

Description
Syncthing 0.13.9 continuously failed to upgrade to 0.13.10 (even though 0.14.4 was available at the time) on one device, stating access was denied to C:\syncthing\syncthing.exe.

I was in a hurry to get Syncthing upgraded to 0.14.x to restore connectivity to our other devices, so rather than look into permissions I just upgraded it manually to 0.14.4. While doing this, I noticed an issue:
**Multiple files named syncthing  in C:\syncthing\ totalling over 4 gigabytes.**
These files were roughly 15 megabytes in size each, similar to syncthing.exe.

Unfortunately, I had no opportunity to see whether the files would be removed if permissions were fixed and Syncthing was upgraded normally.
### Version Information

Syncthing Version: v0.13.9
OS Version: Windows 7 32-bit
