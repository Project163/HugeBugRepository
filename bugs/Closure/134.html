Title

Description
What steps will reproduce the problem? 
1. write some js code that requires goog.i18n.DateTimeSymbols (I am not so sure about the minimal code, I discovered this bug compiling a big project)
2. compile it with advanced optimizations option
3. check out the compiled code

 What is the expected output? What do you see instead?
