Discussion
- I ran into this too. There's a similar discussion on this topic here.
[URL]
- This is caused by `ssr: false`. One workaround for now is to move the Server Action import to be outside of that dynamic import, and pass it to the component via a prop.
- This approach doesn't work if you use sub-modules that depend on variables to render the component, though.
