Title

Crash when following imports in daemon

Description
To reproduce, first create a file like this (`t.py`):
```
import pymssql
```

Then follow these steps:
1. Ensure stubs are missing (`pip uninstall types-pymssql`)
2. Run daemon with missing stubs (`dmypy run -- -2 t.py`)
3. Install stubs (`pip install types-pymssql`)
4. `dmypy run -- -2 t.py` -> ok
5. `dmypy run -- -2 t.py` -> crash

Here's the traceback:
```
Daemon crashed!
Traceback (most recent call last):
  File "/Users/jukka/src/mypy/mypy/dmypy_server.py", line 221, in serve
    resp = self.run_command(command, data)

... [Log Snipped] ...

ValueError:   is not in list
```

This also repros with various other stub packages.
