Title

Subtyping broken for generic function types

Description
Mypy complains about this code even though is should be valid:

```
from typing import AnyStr, Function
def f(x: AnyStr) -> AnyStr: pass
def g(f: Function[[str], str]) -> None: pass
g(f)
```

The problem is that a generic function is not considered a subtype of a non-generic function, even if it is possible to substitute types to make them compatible.

Type checking the above code gives this error:

```
t.py, line 4: Argument 1 to "g" has incompatible type Function[["AnyStr"] -> "AnyStr"]; expected Function[["str"] -> "str"]
```
