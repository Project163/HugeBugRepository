Title

! is not respected on a template type with a parameterized subclass

Description
What steps will reproduce the problem? 
1. Compile the attached js file with type checking.  I used the following: 
java -jar compiler.jar --warning_level=VERBOSE --js=snippet.js --closure_entry_point=snippet --js=closure/goog/base.js --js_output_file=out.js       

 What is the expected output? What do you see instead? 
Output: 
snippet.js:32: WARNING - actual parameter 1 of requiresNonNull does not match formal parameter
found   : (Object|null)
required: Object
  requiresNonNull(nonNullable);  //nonNullable is !Object, should be no error, is error
                  ^

snippet.js:35: WARNING - actual parameter 1 of requiresNonNull does not match formal parameter
found   : (Object|null)
required: Object
  requiresNonNull(nullable);  //nullable is Object|null, should be and is error
                  ^

Line 35 is correctly identified as an error, but line 32 should not be an error.

 What version of the product are you using? On what operating system? 
v20131014, Ubuntu 12.04 and others

 Please provide any additional information below. 
When BadChild extends ParentObject.<Object>, (new BadChild()).doThing should take {!Object} as its first argument, and {Object} as its second.  The type checker believes that nonNullable in that case is (Object|null), despite the type declaration of its parent requiring non-null.

GoodChild extends ParentObject.<!Object>, which silences our compiler warnings with redundant !s, and prevents us from taking the second argument of doThing as null.
