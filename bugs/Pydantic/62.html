Title

`default_factory` being run prior to object init

Description
# Bug

```
             pydantic version: 1.5.1
```

`default_factory` gets run twice before any object instantiation. This is obvious for callables with side-effects:

```
py
...     def __init__(self):
...         self.v = 0 
... [Log Snipped] ...
MyModel(id=3)
```
