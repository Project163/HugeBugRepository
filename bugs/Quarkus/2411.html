Title

Failed to pass quarkus.profile to more than one integration test case when testing native executable

Description
### Describe the bug

If there are two integration test cases and run the following command:
`mvn test-compile failsafe:integration-test -Dnative -Dquarkus.profile=test` 

only the first test case takes the test profile for the test and the second test case takes the prod profile for the test

### Expected behavior

all test cases should take the option passed by the command line for the test

### Actual behavior

only the first test case takes the test profile for the test

### How to Reproduce?

Steps to reproduce:
1. create two different profiles in application.properties and two integration test cases
2. build native executable: `mvn package -Dnative -Dquarkus.native.container-build=true -DskipTests -Dskip.surefire.tests=true -Dquarkus.profile=test`
3. run integration tests: `mvn test-compile failsafe:integration-test -Dnative -Dquarkus.profile=test`
4. check console outputs and quarkus.log and you can find that the seconad test cases is using the prod profile, for example console outputs:
