Title

Inconsistencies for the kernel documentation

Description
Here some inconsistencies that I have encountered when I wanted to use kernel:
- [Link: x] The degree In KernelPCA, svm-kernel and SVC, they don't agree with the presence of the parameter degree for the sigmoid kernel.parameter of [KernelPCA] is said to be used for the rbf kernel. However in the [Link: svm kernel documentation], there isn't any mention of the degree parameter.
- [Link: x] In [KernelPCA], [Link: svm-kernel] and [Link: SVC], they don't agree with the presence of the parameter degree for the sigmoid kernel.
- [Link: ] In the [kernel pca narrative doc] and in [Link: KernelPCA], there isn't any link to the kernel definition
- [Link: ] When you browse the narrative doc in [Pairwise metrics, Affinities and Kernels], there is no pointer to the kernel approximation, definitions of all kernels and estimators/transformers that can use kernels.
