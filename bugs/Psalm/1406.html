Title

False positive when comparing ReflectionNamedType::getName() with 'static'

Description
When `ReflectionNamedType::isBuiltin()` returns `false`, Psalm assumes that `getName()` returns a `class-string`:

```php
if ($returnType instanceof \ReflectionNamedType) {
    if (! $returnType->isBuiltin() && $returnType->getName() !== 'static') {
        
    }
}
```


Demo: [URL]

Even though `'static'` is also a valid return type since PHP 8.0: [URL]
Discussion
- Looks to me like the assertion in the stub needs changed from `class-string` to `class-string|'static'|'self'`. Are there any other possible return values we're missing?
- @AndrolGenhald Good point about `self`, I thought this would be replaced with the FQCN by reflection or even at compilation time, but it looks like it's not, it's actually returning `'self'`: [URL]

I don't see any other possible return value, so `class-string|'static'|'self'` should be alright.

I couldn't find where the return type is documented, it's not in the [Link: CallMap] at least. Because the result is dependent on whether `isBuiltin()` has been called first, I guess there's some custom logic around this class.
- It's in `stubs/Reflection.phpstub`, it just uses `@psalm-assert-if-false` to assert the type of `$this->getName()`.
- @AndrolGenhald TIL, thanks! Fixed in #8201.
