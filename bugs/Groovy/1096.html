Title

methodMissing is called twice instead of once

Description
methodMissing should be called only once for a given missing method call. However, when this method throws a MissingMethodException, the methodMissing method is called twice. The method works as expected in Groovy 1.6, but has this odd behavior in Groovy 1.7-beta-2.
Discussion
- This behavior seems to have been introduced by the revision 17769 (faster exceptions handling - less InvokerInvokationException). 

 Because CachedMethod now MissingMethodException instead of InvocationTargetException, it is again caught by PogoMetaClassSite, which re-invokes that method causing an extra invocation of missingMethod. 

 Should MissingMethodException get special handling in the changes that revision 17769 introduced and change  
  
 ...
 catch  (InvocationTargetException e) {
             throw  e.getCause()  instanceof  RuntimeException ? (RuntimeException)e.getCause() :  new  InvokerInvocationException(e);
        }
 
  

 to  
  
 ...
 catch  (InvocationTargetException e) {
             throw  (e.getCause()  instanceof  RuntimeException && !(e.getCause()  instanceof  MissingMethodException)) ? (RuntimeException)e.getCause() :  new  InvokerInvocationException(e);
        }
- Fixed - was required only in 1.7 branch.
