Title

[DocDB] docdb: Fix bug in ExternalMiniCluster initialization to unblock enabling table locking

Description
Jira Link: [Link: DB-18859]
### Description

The `ExternalMiniClusterOptions` comments say:
```
  // Specifies the replication factor for the cluster. If this is not set, default to the number
  // of masters in the cluster.
  int replication_factor = 0;
```

This default is misleading. If `replication_factor` is unset, a bug causes replication factor to default to 3 on the yb processes spawned by the test harness, regardless of what `ExternalMiniClusterOptions::num_masters` is set to. This bug is causing some tests to fail when trying to enable object locking because the test does not set `replication_factor`, only spawns a single tserver, and does not create any tables. With object locking enabled the master leader tries to create a table for the `pg_advisory_locks` feature when handling the first pg connection. With only one tablet server and a replication factor of 3 this does not succeed, failing the test.
