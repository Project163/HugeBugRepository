Title

Bug: Incorrect location for padded-blocks

Description
Using master, the location of the error for closing padded block is wrong:

```
{

  a();
}
```

produces:

```
4:2 - Block must be padded by blank lines. (padded-blocks)
```

Column number should be `1`
Discussion
- @ilyavolodin #4896 is about parse errors. This is about rule errors
- Could still be a duplicate if column numbers in the parser are always off by one.
- This has to do with the rule using `node.loc.end` as the location of the report, while I think eslint uses exclusive ending notation (range is really `[start, end)`)
