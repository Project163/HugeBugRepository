Discussion
- MultipartProvider accumulates multiple parts with the same name into a collection. The concrete use case arose few years back when a browser was submitting multiple files, typically one should have a 'files' part with multiple file parts embedded inside of that single 'files' part: 

  [URL]

 (see the last example). 

 However what was happening was that a browser was sending multiple 'files' part, one per each file. Therefore, by default, if a given part is expect to be read into a Collection then all the parts with a given name will be found and then read and added into a collection allocated by the provider. 

 I've added a property, "single.multipart.is.collection", that can be set in jaxrs:properties. That will read the content of the individual part to the explicit collection, if applicable
