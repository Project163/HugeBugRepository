Title

Disabling allow_explicit_index breaks bulk

Description
The documentation on URL-based access control implies that bulk operations still work if you set `rest.action.multi.allow_explicit_index: false`, as long as you specify the index in the URL. However, it doesn't work:

```
POST /foo/bar/_bulk
{ "index": {} }
{ "_id": 1234, "baz": "foobar" }
```

returns 

```
explicit index in bulk is not allowed
```

See [URL] for the discussion.
