Title

goto_word keybind behaviour

Description
### Summary

I am activating and exiting from goto_word mode clicking again keybind. I use "A-s". When goto_mode is active and there is too much jump labels on the screen (that's my observation, i am not sure), if i click "A-s" second time, it will be interpretied as "s" symbol for jumping, instead of closing goto_word mode. Also if remove "s" from jump-label-alphabet in editor settings, clicking "A-s" will close "goto_word" mode as expected.

### Reproduction Steps

I tried this:

bind "A-s" = [ "normal_mode" "goto_word" ];
open some file with many words

I expected this to happen:
first click A-s: goto_word mode active;
second click A-s: exit from goto_word mode

Instead, this happened:
first click A-s: goto_word mode active;
second click A-s: behavior as if clicked "s" without Alt
