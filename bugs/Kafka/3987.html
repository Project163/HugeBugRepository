- Hi  kirktrue , I found two potential race conditions: 

 P1. When a member receives heartbeat response with revoked partitions, a member with auto commit config will send OffsetCommit request before doing SubscriptionState#assignFromSubscribedAwaitingCallback. However, the member doesn't make sure the FetchBuffer is empty before building the request, so it may send a request with error offset. 
P2. The member doesn't stop to send FetchRequest when the membership reconciliation is in progress. Before the member does SubscriptionState#assignFromSubscribedAwaitingCallback, a new FetchRequest with revoked partitions may be sent to a broker.
