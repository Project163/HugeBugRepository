Title

Completion of subcommand options after last argument does not work

Description
* Install latest `HEAD` version of `click`:
```
$ pip3 install -e git+git://github.com/pallets/click.git@ #egg=click
```
* Save the following in a file called `foo` on your `PATH`, ensuring it's executable:
```
python
#!/usr/bin/env python3

import click

... [Log Snipped] ...

entrypoint()
```
* Source completion code
```sh
source  
abc  def  ghi  jkl  mno  pqr  stu  vwx  yz

$ foo subcommand whatever --opt  
abc  def  ghi  jkl  mno  pqr  stu  vwx  yz
```
**Actual Behaviour**
```
# WORKS
$ foo subcommand --opt  
abc  def  ghi  jkl  mno  pqr  stu  vwx  yz

# BROKEN
$ foo subcommand whatever --opt  
 
```
