- Update: the correct commit is [URL]
- Not really an external repo bug. It happens when an executable rule tries to provide the executable from a different package (and it is actually enabled by a  [URL] where we enabled arbitrary artifacts as executables). The small(er) repro is:

rulez.bzl
```
python
def  _impl(ctx):
  return [DefaultInfo(executable = ctx.executable.runme,
                      files = depset([ctx.executable.runme]),
                     )]
... [Log Snipped] ...
         },
)
```
tools/BUILD:
```python
sh_binary(name = "tryme",
          srcs = [":tryme.sh"],
          visibility = ["//visibility:public"],
)
```
src/BUILD
```python
load("//:rulez.bzl", "r")
r(name = "r_tools", runme = "//tools:tryme")
```
