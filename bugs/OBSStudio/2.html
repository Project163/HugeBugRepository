Title

[PATCH] Build failure in obs-x264-test.o due to missing X11 linkage?

Description
## Platform
Operating system and version: openSUSE Tumbleweed, kernel 5.8.1, custom-built ffmpeg from latest git
OBS Studio version: current git master ( )

## Current Behavior
Compiling with `cmake -DUNIX_STRUCTURE=1 -DCMAKE_INSTALL_PREFIX=/usr -DBUILD_BROWSER=ON -DCEF_ROOT_DIR="../../cef_binary_3770_linux64" ..`, fails to build from source with 
```
[ 44%] Linking C shared module obs-x264.so
/usr/lib64/gcc/x86_64-suse-linux/10/../../../../x86_64-suse-linux/bin/ld: ../../libobs/libobs.so.0: undefined reference to `XOpenDisplay'
/usr/lib64/gcc/x86_64-suse-linux/10/../../../../x86_64-suse-linux/bin/ld: ../../libobs/libobs.so.0: undefined reference to `XLookupString'
/usr/lib64/gcc/x86_64-suse-linux/10/../../../../x86_64-suse-linux/bin/ld: ../../libobs/libobs.so.0: undefined reference to `XDefaultScreen'
[ 44%] Building C object plugins/obs-outputs/CMakeFiles/obs-outputs.dir/ftl-sdk/libftl/gettimeofday/gettimeofday.c.o
... [Log Snipped] ...
make[1]: *** [CMakeFiles/Makefile2:1496: plugins/obs-x264/CMakeFiles/obs-x264-test.dir/all] Error 2
make[1]: *** Waiting for unfinished jobs....
```
The following patch fixes the issue for me:
```
nettings@roman:/local/build/obs-studio/plugins/obs-x264> diff -urN CMakeLists.txt~ CMakeLists.txt
--- CMakeLists.txt~	2020-08-21 19:58:42.000000000 +0200
+++ CMakeLists.txt	2020-08-21 21:49:33.559479366 +0200
@@ -40,5 +40,5 @@
 
... [Log Snipped] ...
+target_link_libraries(obs-x264-test PRIVATE libobs obs-x264-util X11)
 add_test(NAME obs-x264-test COMMAND obs-x264-test)
```
