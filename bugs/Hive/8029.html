Title

Nullify summary for non-native tables

Description
When creating non-native tables like kudu, hbase and so on,  we create a warehouse location for these tables, though these tables may not use the location to store data or for job plan, we should skip getting the input summary of non-native tables when optimising joins,  as which may cause oom problem when the non-native table is on the build side.
