* Open your ‘init.vim’ (or some Vim file).
* [Link: `packadd vim-white`] (will start profiling into ‘white.log’).
* [Link: `packadd vim-commentr`].
* Press  K  on some function (maybe relevant).
* Hit  Enter  until all red goes away (`vim-white` generates a bunch of error messages, so will not call `profile stop`).
* Go back to your opened Vim file.
*  Leader  c  c .

**UPDATE:** commentr no longer needed. You can enjoy the never ending fun using `--cmd 'source happy.vim'`. (white still required to generate errors.)
```vim
" happy.vim
nnoremap X :call X() 
fun X()
	new
	set ft=vim
endfun
```

So the one-liner:
```sh
nvim -u NORC +'h nextnonblank' --cmd 'packadd vim-white' --cmd 'source happy.vim' '+normal X'
```
