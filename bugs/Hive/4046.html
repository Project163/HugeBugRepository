Title

Added resource path is sent to cluster as an empty string when externally removed

Description
Sometimes the resources (e.g. jar) added via command like "add jars <filepath>" are removed externally from their filepath for some reasons. Their paths are sent to cluster as empty strings which causes the failures to the query that even do not need these jars in execution. The error look like as following:
