Title

Forked JVM terminates with 'halt' when another module's tests fail

Description
Steps to reproduce:  

 Run the attached project with the following command: 
  
 mvn test -T2 
  

  Expected outcome:  

 The 'long' modules's test's shutdown hook should be called 

   
 Actual outcome:  

 The 'long' modules test's shutdown hook is never called 

   

  Workaround:  

 Use  shutdown=exit  configuration as below: 
  
                 <plugin>
                    <artifactId>maven-surefire-plugin</artifactId>
                    <configuration>
                        <shutdown>exit</shutdown>
                    </configuration>
                </plugin>
Discussion
- While running tests of a multi-module project in parallel, as soon as one module's tests fail, the maven parent process exits without waiting for the other forked test processes to run through their  'acknowledgedExit'  procedure, so the forked processes hang until they are killed by a `halt` call in the  `kill`  method.
