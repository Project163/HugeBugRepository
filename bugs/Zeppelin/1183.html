Title

Editor settings aren't getting applied based on the interpreter specified in the paragraph

Description
I've tested this on the 0.9.0 docker container issued by apache found [here| [URL] When I create a new notebook the MD/angular/etc interpreters no longer get the niceties like syntax highlighting, code completion, etc on this version of zeppelin. Angular and MD also do no autohide their code when running. 

   

 I believe part of the issue is that their configs aren't being set on the back end. If you look in the json of the note you'll notice that, aside from the default interpreter, they are all treated as text. The notes in 0.9.0 are also missing these two settings in the json for the appropriate paragraphs: 

   
  "editorHide": true, 
 "tableHide": false  
   

 If you import a note from 0.8.2 which has these settings and the correct language set in the json the note will correctly hide the code when run but you still do not get the other things like code completion.
Discussion
- I've tested out a fix, replacing line 597 of InterpreterSettingManager: 

   

 return interpreterSetting.getDefaultInterpreterInfo().getEditor(); 

   

 With this: 

   

 return interpreterSetting.getInterpreterInfo(intpName).getEditor(); 

   

 Gives me the correct behavior. I believe the previous line being set to always get the default interpreter is why the editor of the  default interpreter would work correctly but none of the others would.
