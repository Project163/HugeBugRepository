Title

BelongsToMany association doesn't always add _joinData property to new assigned entities after save.

Description
I have structure like that:

``` php
// OffersTable.php
public function initialize(array $config) {
   $this->belongsToMany("Offers.Products", [
      'through' => 'Offers.OffersProducts'
   ]);
}
```

When I have no related products to offer, and I create first set of offer's products then after save every product entity has _joinData entry:

``` php
$offer = $offersTable->find(...)->contain('Products');
$product = $productsTable->find(... id = 1 ...);
$offer->products[] = $product;
$offersTable->save($offer);
debug( $offer->products[0]->_joinData ); //_joinData exists
```

but after that, when relation offers   products just exists, then new relations to products doesn't have _joinData entry.

``` php
$offer = $offersTable->find(...)->contain('Products');
debug( $offer->products[0]->_joinData ); // this entry exists
$product = $productsTable->find(... id = 2 ...);
$offer->products[] = $product;
$offersTable->save($offer);
debug( $offer->products[1]->_joinData ); //_joinData doesn't exists for this product.
```

saveStrategy property relation doesn't matter for this example.
