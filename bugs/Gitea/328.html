Title

Feature: File locking in User interface

Description
Git LFS support [Link: file locking]. File locking with git lfs can be used without storing the file as a git lfs file. 

I would like to have the following functionality in Gitea UI:
- [x] Respect file locking when editing. If a file is locked with git lfs it shall not be editable in the UI. (#8719)
- [x] Respect file locking, no upload of file if locked (#8769)
- [x] Show if a file is locked and who locked it (#8719)
- [x] See all locks and force unlock in repo setting interface (#8726)
- [ ] Check locks on server side when pushing (#11094)
- [ ] Warn if user edits file that is lockable (.gitattributes), but not locked (?)
- [ ] Support lock file and unlocking (your own lock) in UI. Files not marked as lockable can be locked but with warning?
