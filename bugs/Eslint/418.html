Title

context.report() does not handle 'my message {{0}}'

Description
I'd like the following to work, when writing a custom rule:

``` js
context.report(node, 'my message {{0}}', ['testing'])
// should result in "my message testing"
```

The reason is this line:
[URL]

``` js
var rx = new RegExp("{{" + escapeRegExp(key) + "}}", "g");

// should be replaced by
var rx = new RegExp(escapeRegExp("{{" + key + "}}"), "g");
```
Discussion
- why don't you do it like this:

``` js
context.report(node, 'my message {{name}}', {name: 'testing'})
```
