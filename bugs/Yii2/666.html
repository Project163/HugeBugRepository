Title

Typecasting in batchInsert

Description
I'm trying to insert data in the table

``` php
        Yii::$app->db->createCommand()->batchInsert(
            self::DB_CITY_TABLE_NAME,
            ['id', 'name', 'region_id', 'latitude', 'longitude'],
            $cities
        )->execute();
```

`$cities` is array 

