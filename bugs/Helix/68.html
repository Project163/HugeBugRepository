Title

Panic on close last buffer

Description
### Summary

Bug on closing buffers. Helix crashes with panic error:
```thread 'main' panicked at 'called `Option::unwrap()` on a `None` value', helix-view/src/editor.rs:630:51```

### Reproduction Steps

  

I tried this:

1. `hx`
2. open file with (space + f)
3. open another file (space + f)
4. switch buffer to first file (space + b) 
5. use command `:bc` to close file
6. use command `:bc` to close last file

I expected this to happen:
Helix should remain open with an empty buffer.

Instead, this happened:
Helix crashes with panic error
