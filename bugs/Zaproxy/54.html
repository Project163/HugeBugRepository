Title

AJAX Spider does not click all elements set in the options

Description
Steps to reproduce the issue:
1. Run ZAP with "Ajax Spider" add-on (and its dependencies);
2. Disable the option "Click default elements only" in "AJAX Spider" options panel;
3. Access a page that contains the non-default elements, for example, WIVET's [1] page number 9;
4. Run the AJAX Spider against the page and note that it does not click all elements.

ZAP Version:
Versions >= 2.4.0.

Add-on version:
"Ajax Spider" versions >= 12.
