Title

Dependency on pysqlcipher3

Description
File ``lib/sqlalchemy/dialects/sqlite/pysqlcipher.py`` depends on ``pysqlcipher3`` (https://pypi.org/project/pysqlcipher3/) which is no longer maintained (https://github.com/rigglemania/pysqlcipher3) and reads ``Security vulnerabilities may exist in this code. Use at your own risk.``
``sqlcipher3`` (https://github.com/coleifer/sqlcipher3) serves the same purpose as ``pysqlcipher3``, and is actively maintained.

Install of ``pysqlcipher3`` fails on some systems with python3.9+ due to deprecation of certain functions (``Py_DEPRECATED(3.9) PyAPI_FUNC(void) PyEval_InitThreads(void);``)
Which then causes import error in ``lib/sqlalchemy/dialects/sqlite/pysqlcipher.py``.
