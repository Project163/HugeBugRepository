Which commit does the label 0.3.2rc2 refer to? The error seems to indicate that your
debian package is combining the latest additional files (bazel.bazelrc) with a binary
based on an old source version (that does not yet know the --action_env option).

Note that not keeping packaging and sources in sync is usually a bad idea; so the
rollback only treats the symptoms and not the underlying cause that files intended
to be packaged with only a newer source version get packaged with an older source
version. Should we reopen this bug to address the actual issue that when packaging
an old version we don't use the packaging script from that source version (and
roll forward the rolled back commit)?
