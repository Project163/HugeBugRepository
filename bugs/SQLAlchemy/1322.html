Title

Polymorphic query with CTE used in multiple places fails with 'Multiple, unrelated CTEs found with the same name'

Description
### Describe the bug

In certain cases, when a polymorphic model query refers to a CTE multiple times (e.g., once for filtering, another time for sorting), the query fails with "Multiple, unrelated CTEs found with the same name". This doesn't seem to happen with non-polymorphic models.

In the attached example, changing `Thing` to extend directly from `Base` instead of `Resource` resolves the problem. The example is very contrived; our actual query uses a recursive CTE in both a filter clause and an order by clause.

python

from sqlalchemy.sql.schema import Column, ForeignKey
