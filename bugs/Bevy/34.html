Title

Panic when despawning camera on state change

Description
**Bevy version**
Master  

**Operating system & version**
Windows 10

**What you did**
1. Added an `on_state_exit` system that despawns a camera using `commands.despawn_recursive()`
2. Changed the state with `state.set_next()` in another system

**What you expected to happen**
The camera should despawn and the next stage should start

**What actually happened**
The game panicked:
```
thread 'Compute Task Pool (5)' panicked at 'called `Result::unwrap()` on an `Err` value: NoSuchEntity', 
C:\[..]\.cargo\git\checkouts\bevy- \f8292cc\crates\bevy_render\src\render_graph\nodes\camera_node.rs:84:27
```
Discussion
- I was able to workaround this panic using the following `on_state_exit` system code, right before despawning the cameras:

```
rust

```
