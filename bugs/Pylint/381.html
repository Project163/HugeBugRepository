Title

[self-tests] test_expand_modules[files_or_modules1-expected1] fails on Pylint 2.8.2

Description
I'm trying to update Pylint for ALTLinux to latest 2.8.2.
Pylints' self-tests periodically fails with:
```
=================================== FAILURES ===================================
_______________ test_expand_modules[files_or_modules1-expected1] _______________

files_or_modules = [PosixPath('/usr/src/RPM/BUILD/python3-module-pylint-2.8.2/tests/lint')]
expected = [{'basename': 'lint', 'basepath': '/usr/src/RPM/BUILD/python3-module-pylint-2.8.2/tests/lint/__init__.py', 'isarg': Tr.../src/RPM/BUILD/python3-module-pylint-2.8.2/tests/lint/__init__.py', 'isarg': False, 'name': 'lint.unittest_lint', ...}]
... [Log Snipped] ...
FAILED tests/lint/unittest_expand_modules.py::test_expand_modules[files_or_modules1-expected1]
==== 1 failed, 1312 passed, 27 skipped, 200 deselected in 97.72s (0:01:37) =====
```

The problem is that astroid's `get_module_files` is based on `os.walk`, which in turn calls `os.scandir` or `os.listdir` (depending on Python version),  but both document that  entries are yielded in arbitrary order:
```
-> ignore_list, ignore_list_re = [], []
(Pdb) n
-> modules, errors = expand_modules(files_or_modules, ignore_list, ignore_list_re)
... [Log Snipped] ...
(Pdb) sorted(modules, key=lambda d: d["name"]) == expected
True
```
