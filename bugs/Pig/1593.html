- Ignore the map entry with null key. Hive does it the same way (  HIVE-8115  ). Hive also plan to disable storing map with null key. For legacy data, Pig should not die.
- Clarified with Daniel why we can't support null keys in Pig. Pig can support null keys, but we are dropping them only to have same behavior while processing as hive 0.14 and HCatLoader.
