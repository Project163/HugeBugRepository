Title

Test flake: Crash in getenv

Description
Saw a crash in getenv [URL]

getenv/setenv/unsetenv are not thread-safe and we can run into data race issues without synchronization. We believe this is mostly an issue for tests, since we do not expect applications to modify the environment after initialization, but in our tests, we modify the environment multiple times.

```

PC: @        (unknown)  getenv
    @              576  absl::lts_20240722::AbslFailureSignalHandler()
    @        (unknown)  (unknown)
```
