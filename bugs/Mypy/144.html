Title

Ambiguous error / bug around modulo usage

Description
Code with mypy error inline

```
from typing import Any, Dict, Tuple, Union, cast

y = 3.1
y = int(y)
x = y % 180  # mypy error: Function does not return a value
```

Also, using `cast` does not fix the problem, but adds a new error:

```
from typing import Any, Dict, Tuple, Union, cast

y = 3.1
y = int(y)
y = cast(int, y)  # mypy error: Function does not return a value
x = y % 180  # mypy error: Function does not return a value
```
Discussion
- Hmm this is bizarre. I'll look into it.
- Simpler repro:

```
y = 0.0
y = 0
y()  # None not callable
```

Apparently narrowing the type from `float` to `int` breaks stuff. This is probably related to the special `int` / `float` subtyping.
