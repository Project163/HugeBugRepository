Title

NumberValidator use validateValue method not use message property

Description
### What steps will reproduce the problem?

```php
$validator = new NumberValidator(['message' => 'must be an integer']);
$validator->validator('aaa', $error); 
echo $error; // the input value is invalid.
```

### What is the expected result?

```php
$validator = new NumberValidator(['message' => 'must be an integer']);
$validator->validator('aaa', $error);
echo $error; // must be an integer
```

### What do you get instead?
custom error message
