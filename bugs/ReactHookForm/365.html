Title

issue: Setting `keepDirtyValues` in `useForm`'s `resetOptions` stops the values from being cleared with `reset`

Description
### Version Number

7.48.2

### Codesandbox/Expo snack

[URL]

### Steps to reproduce

1. Add `keepDirtyValues: true` to `resetOptions` of `useForm`
2. Make any change in the form 
3. Click reset button
4. Notice that you need to click reset again after the first time for the form to be cleared 

### Expected behaviour

The form values should be cleared alongside `isDirty` when `reset` is called,  and `resetOptions` of `useForm` should not affect the behaviour of `reset`.

Similar issue is #9736
