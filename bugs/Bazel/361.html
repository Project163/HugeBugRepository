Title

Worker process crashes after bazel clean

Description
/CC @hanwen @damienmg 

I'm using Bazel 0.4.5. To reproduce, use Gitiles project: [1].

The sequence `bazel build gitiles; bazel clean; bazel build gitiles` consistently leads to worker process crash:

```
$ bazel build gitiles
.
INFO: Found 1 target...
Target //:gitiles up-to-date:
  bazel-bin/gitiles.war
... [Log Snipped] ...
Use --verbose_failures to see the command lines of failed build steps.
INFO: Elapsed time: 2.914s, Critical Path: 1.06s
```

Workaround: killing the worker process with `bazel shutdown` fixes the problem:

```
$ bazel shutdown

$ bazel build gitiles
.
INFO: Found 1 target...
Target //:gitiles up-to-date:
  bazel-bin/gitiles.war
INFO: Elapsed time: 8.641s, Critical Path: 5.41s
```
