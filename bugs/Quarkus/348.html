Title

quarkus-smallrye-fault-tolerance extension should not have a hard dependency to quarkus-smallrye-metrics

Description
**Describe the bug**
When including the `quarkus-smallrye-fault-tolerance` extension, we automatically have the metrics extension as it have a hard dependency to it.

**Expected behavior**
Metrics should be included only if the `quarkus-smallrye-metrics` extension is added in the pom.xml


**Environment (please complete the following information):**
 - Quarkus version or git rev: 0.26 or master

**Additional context**
The Jaeger extension only includes `smallrye-metrics` maybe the same approach can be use to avoid having the metrics extension directly as a dependency. 
But this does not fully solves the issue of having an un-necessary dependency (smallrye-metrics).
