- @dareid is right, I had the same problem, when setting up instances on aws using the cloud init script, the home directory was not set (amazon linux instance)

If I connect via ssh to the server and execute pm2 manually its ok, but if I tell cloud init to switch to the user (I created in my cloud init script) to execute the "pm2 start server.js" command, then it fails because the home directory is undefined

I now set the home directory (in my cloud init script), the same way as I do for the environment and it works:
- export NODE_ENV=production
- export HOME=/home/www_user
