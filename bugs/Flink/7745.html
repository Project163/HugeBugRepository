Title

Correct the state cache behavior during bump beam version

Description
It has changed the state cache strategy from size based to bytes based since Beam 2.42.0 (See  [URL] for more details). We should also support memory based state cache in the long term. Before that, we should correct the behavior which seems broken after bumping the Beam version. It may cause the state cache continuously increase and finally cause the job OOM.
