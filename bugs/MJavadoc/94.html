Title

location of doc-files is wrong on page [URL]

Description
On the web-page  
     [URL]  
there is a  tree-view of a directory layout (see below) 

 It shows the hypothetical path: 
   src/main/javadoc/org/apache/myapp/doc-files/app.png 

 This is a bad example as it will not work w/o fiddling around with pom configuration. 

 It should say: 
    src/main/javadoc/doc-files/app.png 

 If you were to use the layout given, you would discover that app.png is never copied into the 
target directory.
