Title

NumberTextField renders its value in unsupported number format

Description
The issue is similar to   WICKET-3591   but its fix doesn't help when the model object of the NumberTextField is a BigDecimal because BigDecimalConverter#convertToString() produces something like "123, 456, 789" and this is not supported by <input type="number">'s spec:  [URL]
