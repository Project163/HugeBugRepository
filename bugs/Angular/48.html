Title

Host properties are not set on root component

Description
Repro: [URL]

This seems to be caused by the fact that we are creating a second temporary host element for the root component and calling `setAttribute` _before_ we attach content to the target host element.

/cc @jakemac53
Discussion
- Note that this might be fixed by [URL] as this is changing the `DomRenderer`...
- Let's make sure the following scenarios work:
1. You can set `'[class]': 'allOfMyClasses'` in the `host` property in a component
2. This also works on dynamically loaded components
3. This also works on the root-level (E.g. application shell component)
- Here is a PR that verifies that we can set properties, attributes and classes on the root element: [URL]

Angular supports using `'[className]':'allOfMyClasses'` and `'[attr.class]':'allOfMyClasses'`. Only `'[class]':'allOfMyClasses'` does not work as `class` is not a property on DOM elements.
- Checked with @matanlurey that this is ok.
