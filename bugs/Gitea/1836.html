Title

Docker root setup ssh cert location unexpected

Description
### Description

In the [Link: setup] script of root-docker the ssh-certs are only tested to be in a certain location ( _cert), but this is
1. not documented as far as I could find
2. not the expected location; when signing a public key `key.pub` the certificate is automatically generated in `key-cert.pub`, at least for `OpenSSH_9.9p2, OpenSSL 3.3.3`

There is nothing that doesn't actually work, I'd just suggest that the `-cert.pub` should be checked too, since that is where most would try and place the file.
