Title

Streaming sql throw hive exception when it doesn't use any hive table

Description

 SQL

FROM (
   SELECT *,
     ROW_NUMBER() OVER(
       ORDER BY event_ts) AS rownum
   FROM source_kafka)
WHERE rownum <= 10
