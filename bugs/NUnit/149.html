Title

Timeout failures on MacOS

Description
After setting up the macOS build on VSTS, I am seeing the following test failures occasionally,

```
1) Failed : NUnit.Framework.Attributes.RepeatableTestsWithTimeoutAttributesTests.ShouldPassAfter2RepeatsAndTimeoutIsResetEachTime
Test exceeded Timeout value of 85ms

2) Failed : NUnit.Framework.Attributes.RepeatableTestsWithTimeoutAttributesTests.ShouldPassAfter3RetriesAndTimeoutIsResetEachTime
Test exceeded Timeout value of 85ms
```

[URL]
Discussion
- I thought this might be a difference in the resolution of the system clock on macOS vs Windows, but the tests use a sleep of 30 ms. The resolution on macOS is 10ms and on Windows 15.6 ms. so that isn't it. Possibly just slower macOS machines in the VSTS build pool?
- Running the test three times, with a sleep of 30ms and a timeout of 85ms seems like a very chancy way to verify that the timeout is reset correctly for each execution. The other one with two repeats sounds like it has a better chance of success, but my own experience has been that sleeps can easily end up taking two or three times longer than the value you set. It may be that the entire approach to testing this feature needs to be reviewed.
