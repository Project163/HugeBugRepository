Title

[Bug]: Validation errors are cleared when checkbox is checked in Field Array

Description
### Version Number

7.15.0

### Codesandbox/Expo snack

[URL]

### Steps to reproduce

1. Added new field by clicking `Add new profile`
2. Click `Submit` to see validation errors
3. Check `Checkbox`
4.  All validation errors are cleared, even for the untouched input fields.
5. Can see the input fields' validation errors when submitting the form again 

PS: It only happens with the checkbox in the field array while the other fields work well.

### Expected behaviour

The validation error should only be removed for the field that cleared all the validations.

### What browsers are you seeing the problem on?

Firefox, Chrome, Safari
