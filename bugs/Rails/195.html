Title

ActiveStorage: has_many_attached only persists the last added file when attaching via file i/o

Description
### Steps to reproduce

I've set up a sample repo here: [URL]

Create a new rails 6.0.0.rc2 app. Install activestorage. Add the `has_many_attached` macro to a record. Go to the console, build a new record, start adding File/IO objects via the `attach` method, and then save the record. The first attachment will not be found on the disk, throwing a `ActiveStorage::FileNotFoundError (ActiveStorage::FileNotFoundError)`.

```
ruby
% rails c
Running via Spring preloader in process 16465
Loading development environment (Rails 6.0.0.rc2)
2.6.3 :001 > u = User.new
... [Log Snipped] ...
  Disk Storage (6.1ms) Downloaded file from key: yb1cq10ztku7kybhz9i2oxupyofq
 => "biography2"
```

### Expected behavior

For any record with a `has_many_attached` macro, building a new record and then attaching File/IO objects via `attach` persists all attachments.


### Actual behavior

The first attachment is not persisted.

### System configuration
**Rails version**: 6.0.0.rc2

**Ruby version**: 2.6.3
