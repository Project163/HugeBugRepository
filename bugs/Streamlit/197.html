Title

Using `switch_page` forces the page to finish running before rendering

Description
### Checklist

- [Link: X] I have searched the [existing issues] for similar issues.

### Summary

When switching pages via a button and `switch_page`, instead of the following page being loaded as expected, the screen freezes until the code of the page finishes executing. This does not occur if I use the sidebar to load the other page.

### Reproducible Code Example

```
Python
# in main.py
import streamlit as st


... [Log Snipped] ...
time.sleep(1)
st.text("Operation done")
```

### Steps To Reproduce

1. Create empty project with `main.py` and `pages/page1.py` as specified in the reproducible code example.
2. Run `streamlit run main.py`.
3. Click `"Go to page1"` button.
4. Like 95% of the times, the page freezes as shown in the image below, instead of showing progress bar.
    [Image: image]

### Expected Behavior

If I go to `pages/page1` directly (instead of using the button that calls the `switch_page`) by typing the page address directly or using the sidebar, the progress bar is shown as expected (see image below).
[Image: image]

### Current Behavior

Like 95% of the times, the page freezes as shown in the image below, instead of showing progress bar.
[Image: image]
