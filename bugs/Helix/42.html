Title

Goto Crash on last modification `g` + `.` after using `space` + `r`

Description
### Reproduction steps

1. Use `space` + `r` to change a symbol.
2. Press `u` to undo the action
3. Save file with `:w`
4. Use `g` + `.` then helix will crash.
  

### Environment

- Platform: Linux (Ubuntu 20.04)
- Helix version: v0.5.0-165-g0dd2303
