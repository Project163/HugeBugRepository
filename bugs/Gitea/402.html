## Description
The code comment is not invalidated (marked as outdated) if line it is referencing is removed by future commit. Example can be seen on [URL] The comment was made against lines that were removed in `a25e77b1d3` however it is not marked as outdated and attempting to comment on it will raise HTTP 500:

```
[E] CreateCodeComment: LineBlame ... exit status 128 - fatal: file ... has only ... lines
```
