Title

ScrollView with another View with SafeAreaView inside causes incorrect initial scroll position in ScrollView

Description
## 🐛 Bug Report

In a vertically placed `ScrollView` (with `contentInsetAdjustmentBehavior="automatic"` prop) and `View` with `SafeAreaView` inside, the default position of contents of ScrollView are off the screen (left picture). But on scroll, the position is fixed. If you log the scroll position, the position in left image is `0` on y and on right image it's some negative value.
