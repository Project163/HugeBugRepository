Title

Fix inconsistent behavior of LOAD DATA command for partitioned and non-partitioned tables

Description
For partitioned tables, while executing LOAD DATA/ LOAD DATA LOCAL commands, the check for file existence is not executed on HiveServer2, and this in turn throws an error during Runtime once the job is launched.  
  
 
java.io.FileNotFoundException: File file:/<filepath> does not exist. 
  

 Non-partitioned tables do not follow this control flow, and the checks are run appropriately at compile time.  

 Incase the file does not exist, user is presented with the error. 
  
 
Invalid path "file: ///<filepath>: No files matching path file:/<filepath>  
  
 This is inconsistent and error prone behavior.
