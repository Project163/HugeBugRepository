Title

Catch-22 with input

Description
### Steps to reproduce
1. Use `pylint --py3k`
2. Run on a file like this
```python
try:
    blank = raw_input("Oops!")
except:
    blank = input("Oops!")
```
3. Get frustrated by conflicting errors.

### Current behavior
```
************* Module demo
W:  2, 9: raw_input built-in referenced (raw_input-builtin)
W:  4, 9: input built-in referenced (input-builtin)
```

### Expected behavior
Nothing, as this should be recognized the same way as:
```python
try:
    blank = xrange(0, 1)
except:
    blank = range(0, 1)
```
