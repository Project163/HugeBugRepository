Title

Create model CC conflicts are used in dimensions, measures, and filter conditions, and the model creation fails

Description
创建模型API，CC同表达式，设置computed_column_name_auto_adjust=true改名，如果CC被用到维度，度量，过滤条件中，模型创建失败  

   
   Root Cause 

 创建模型API，cc存在表达式冲突，并且 computed_column_name_auto_adjust=true，  

 自动调整CC名称时，未对维度、度量、模型过滤条件中用到的列做替换。导致无法识别CC名 

   
   Fix Design 

 自动调整CC名称时,对维度、度量、模型过滤条件中用到CC列做替换。
