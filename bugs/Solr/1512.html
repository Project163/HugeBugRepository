Title

SOLR Admin gui works in IE9, breaks in IE10. Workaround.

Description
Solr Admin.html does not work in IE10. Thought it was unmatched tags. It's a document mode issue.  

 Workaround for IE10. Modify Admin.html by adding the metatag after doctype <meta http-equiv="x-ua-compatible" content="IE=9">.
