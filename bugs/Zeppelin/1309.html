Title

Zeppelin server needs to obtain the permission to create "configmaps" under k8s mode

Description
Since the spark interpreter pod need to create the resource "configmaps" (please refer to  [URL] for more information), Zeppelin Server also needs to obtain relative permissions when it is running inside k8s cluster.  

   

 Otherwise, it will generate such error: 
  
 
io.fabric8.kubernetes.client.KubernetesClientException: Failure executing: POST at: https: // /apis/rbac.authorization.k8s.io/v1/namespaces/ default /roles. Message: Forbidden!Configured service account doesn't have access. Service account may have been revoked. roles.rbac.authorization.k8s.io  "spark-filwnx"  is forbidden: user  "system:serviceaccount: default :zeppelin-server"  (groups=[ "system:serviceaccounts"   "system:serviceaccounts: default "   "system:authenticated" ]) is attempting to grant RBAC permissions not currently held:
 {APIGroups:[ ""], Resources:[" configmaps "], Verbs:[" create " " get " " update " " list " " delete " " watch"]}.
