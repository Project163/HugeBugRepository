Title

[CDCSDK] CDC service populating an empty `old_tuple` for update

Description
Jira Link: [Link: DB-11901]
### Description

Consider the following set of operations in YSQL:

```sql
CREATE TABLE test (id INT PRIMARY KEY, bigint_col BIGINT);

INSERT INTO test VALUES (1);

UPDATE test SET bigint_col = NULL WHERE id = 1;
```

In the above set of statements, we're setting a `NULL` value for the column `bigint_col` which is already `NULL`. When CDC is enabled on the above table and the same set of operations are performed, the CDC service does not populate the `old_tuple` for the `UPDATE` record and the tuple looks like empty like the following:

```
old_tuple {
}
```
