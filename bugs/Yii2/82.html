Title

Logging while logs are processes causes infinite loop

Description
Hi,

On my production server I have configured Yii's log module to send me an e-mail whenever any error (except for 404's) occurs.

I used this configuration in my parameters:

```
php
    'components.log' => [
        'traceLevel' => 0,
        'targets' => [
            'file' => [
... [Log Snipped] ...
        ],
    ]
```

The result was that no pages are rendered, and the log in the /runtime folder was not filled. When looking in my syslogs, I found this error:

```
Allowed memory size of 134217728 bytes exhausted (tried to allocate 130968 bytes) in /home/web/vendor/yiisoft/yii2/yii/BaseYii.php on line 47
```

When I increase PHP's allowed memory size in php.ini, the number of exhausted bytes just goes up.

When I remove the email target, it works again. Sending e-mails also works on my machine. When I call \Yii::$app->mail->compose() in a script, I'm perfectly able to send an e-mail.

Any idea why this is happening?
I'm using PHP 5.5, Apache2 and Ubuntu.
