Title

More than one tag on a path breaks server code generation Multi tag API

Description
## Problem statement

A swagger definition that includes more than one tag in a path's tag definitions generates bad code. It appears to nest a second `operations` directory within the first.

## Swagger specification
```
yaml
swagger: '2.0'
info:
multi tag api
... [Log Snipped] ...
Explanation of the errors
                items: { type: string }
```

## Steps to reproduce
`swagger generate server` with the above, and attempt to go build.

You'll get the following error:
```
restapi/operations/multi_tag_api.go:54: undefined: GetMultiHandler
```

## Environment
swagger version: dev
go version: 1.7.4
OS: macOS
