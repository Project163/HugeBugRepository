Title

urlManager: rules based on domain name

Description
I tried to run DefaultController in Mymodule based on the host name using the following code: 

```
'rules' => [
  ['pattern' => '', 'route' => 'mymodule/default/index', 'host' => '[URL]
]
```

It doesn't work. Function parseRequest in framework/web/UrlRule.php returns false in the place above (https://github.com/yiisoft/yii2/blob/master/framework/web/UrlRule.php#L223):

```
if (!preg_match($this->pattern, $pathInfo, $matches)) {
                        return false;
                }
```

preg_match returns 0 because $pathInfo ends with / but pattern don't ('#[URL] and '[URL] respectively).

It is a bug or I wrote the wrong rule?
Discussion
- Even back in Yii1 the rule for the default page (just host name without route specification) used pattern ‘/’.

```
'rules' => [
    ['pattern' => '/', 'route' => 'mymodule/default/index', 'host' => '[URL]
]
```
- I tried with 'pattern' => '/', but '/' has been trimmed after:

```
$this->pattern = '#^' . trim(strtr($this->_template, $tr), '/') . '$#u';
```

- Fixed.
