Title

ArrayUtils.toArray(T... items) has unsafe use of varargs

Description
ArrayUtils.toArray(T... items)  is marked as  @SafeVarargs , but I suspect the use of the varargs is unsafe. 

 An example, drawn heavily from  this StackOverflow answer , demonstrates this: 

  
  static  <T> T[] arrayOfTwo(T a, T b) {
     return  ArrayUtils.toArray(a, b);
}

@Test
 public  void testBadVarArgs()  throws  Exception {
    @SuppressWarnings( "unused" )  // Need to assign to trigger exception
      String [] result = arrayOfTwo( "foo" ,  "bar" );
}
 
  

 the above code throws an exception:  java.lang.ClassCastException: [Ljava.lang.Object; cannot be cast to [Ljava.lang.String; .
Discussion
- Unfortunately, this method seems to do exactly what you're not supposed to do with varargs. 

 We may have to deprecate this and warn people off using it. 

 I'm going to create another issue for the  addAll  method, since the solution (and discussion thereof) is likely to be different.
- A version of commons-lang containing this method with the @SafeVarargs annotation has not been released yet, so the annotation can just be removed.
- ... [Middle Discussions Snipped for Brevity] ...
- As I first step I have just removed the SafeVarargs annotation from the method.
- I am definitely -1 for deprecation. We have a lot of unit tests for this method, that demonstrate, what actually works (incl. indirect generic calls). In the case above, you get a compiler warning for the return value of the method arrayOfTwo if the @SafeVarargs is missing.
