Title

$query->bind() to array of strings/integers broken, or example code for $query->bind() incorrect

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.7.8

### What you did

When trying to use $query->bind() like the example in [URL]

```
->order(['FIELD(Table.field, :sortValues)'])
->bind(':sortValues', $options['ids'], 'integer[]');
```

### What happened

Following error was thrown:
`Unknown type "integer[]"`

[Image: Screenshot 2019-05-31 at 16 27 43]


### What you expected to happen

Array of values bound to the `:sortValues` placeholder
Discussion
- The documentation block on `bindValue()` is incorrect.  List type expansion can only be done inside condition and comparison expressions.
- I have a pull request up to fix the documentation. To do what you are trying to do I think you'd need to use a function expression

```php
$func = $query->func()->field(array_merge(
  ['Table.field' => 'identifier'],
  array_values($options['id'])
));
```
