Title

clipboard=unnamedplus : Extra spaces after yank and put blockwise visual

Description
### Problem

After yanking with blockwise Visual and putting, unexpected spaces appear in the output.

### Steps to reproduce

Create a text file (tmp.txt) with the following contents:
```
aaaaa
b,
```

Start Neovim:
$ nvim --clean --cmd ":set clipboard+=unnamedplus" tmp.txt
Perform these keystrokes:
Ctrl-v, 4, l, y, p, j, h, Ctrl-v, y, a, Space, Esc, p

Four extra spaces are inserted after “b”:
```
aaaaaaaaaa
b b    ,
```

### Expected behavior

No extra spaces should be put; the result should be:
```
aaaaaaaaaa
b b,
```

### Nvim version (nvim -v)

v0.12.0-dev-1445+gc5ed5504f4

### Vim (not Nvim) behaves the same?

no, vim 9.1.1582

### Operating system/version

Ubuntu 24.04 6.8.0-85-generic

### Terminal name/version

gnome-terminal 3.52.0

### $TERM environment variable

xterm-256color

### Installation

build from repo
