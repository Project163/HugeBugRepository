Title

camel-jbang: camel run --runtime=quarkus does not shut down cleanly

Description
With Camel JBang if you do: 

  
 
camel run foo.java --runtime=quarkus
 
  

 Then ctrl-c to stop the application, shutdown does not happen cleanly due to an exception. On Linux / Mac you're forced to search for the pid and kill -9.  

 I think it's due to the shutdown hook removing the app directory before Quarkus is fully stopped.
