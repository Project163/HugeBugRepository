Title

Query with interval literal in join condition fails

Description
Reproducer  
  
 
>  create   table  date_dim_d1(
	d_week_seq                 int ,
	d_date                     string );

>  SELECT  
       d1.d_week_seq
 FROM    
       date_dim_d1 d1 
        JOIN  date_dim_d1 d3 
 WHERE   
        Cast (d3.d_date  AS   date ) >  Cast (d1.d_date  AS   date ) +  INTERVAL   '5'   day  ;
