Title

Checkpoints for jobs in non-terminal state (e.g. suspended) get deleted

Description
For example, when shutting down a Yarn session, according to the logs checkpoints for jobs that did not terminate are deleted. In the shutdown hook, removeAllCheckpoints is called and removes checkpoints that should still be kept.
Discussion
- The shut down hook is actually not a problem, because it is only active in standalone recovery mode. The issue is that a suspended execution graph will shut down the checkpoint coordinator, which discards all checkpoints on shut down. We still need to call shutdown in order to free some resources like the timer task, but have to skip discarding the checkpoints if the execution graph is suspended and not in a globally terminal state.
