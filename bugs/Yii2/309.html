Title

Plurals Parsing Incorrect in yii\i18n

Description
The advanced features as stated in this [Link: docs example for plurals] does not work for ICU Library version < 4.8. The translation of recursively embedded variables do not happen properly.

Refer also the use case details in this [Link: forum discussion].

On quick glance at the code maybe something to do with the `replaceNamedArguments` function in the `yii\i18n\MessageFormatter` class.
