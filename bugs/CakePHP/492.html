Title

3.0 Cannot paginate named routes

Description
Sorry if this isn't an issue. I searched issues and checked the [Link: 3.0 Roadmap] but couldn't find anything. Using the following route will cause a `MissingRouteException`.

```
php
Router::scope(
    '/inventory',
    [
        'plugin' => 'Inventory',
... [Log Snipped] ...
    }
);
```

This route will generate a link to the index page just fine using `Router::url('view-all-inventory-assets');` but if in the template `Plugins/Inventory/Templates/Admin/Assets/index.ctp` I use the PaginatorHelper to generate any links it will throw the exception. The problem is solved by removing the `_name` key.

Since this error ultimately comes from the [Link: Cake\View\Helper::url()] call I would imagine all helpers that use it have the same problem (though I haven't tested that). I've been calling `Router::url()` every time I need to generate a link which has become tedious (but great because of named routes!). I apologize if it was intended to be this way, I just didn't expect it.
Discussion
- I can look into this, as there is another related issue open too.
- Named routes don't get added into the standard reverse routing lists presently as I figured people would always be using the route name and not relying on reverse routing. Having routes in both the named list and reverse route list might make using routes a bit simpler.
- Possibly related to #4120.
- Closing as #4129 is open now.
