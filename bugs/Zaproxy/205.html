Title

Manual Request Editor keeps using Forced User even if disabled

Description
Steps to reproduce the issue:
1. Run ZAP;
2. Set up context authentication, with wrong logged in/out indicators to force the re-authentication (easier to notice/reproduce the issue).
3. Enable Forced User mode;
4. Send/re-send a message with Manual Request Editor, notice that the authentication is attempted (History or Output tabs);
5. Disable Forced User mode;
6. Send the same message again, note that it keeps trying to authenticate even with the Forced User mode disabled.

Remarks:
Changing the user (in context's Forced User panel) also has no effect after sending the message once.

ZAP
Version 2.7.0 (and older).
