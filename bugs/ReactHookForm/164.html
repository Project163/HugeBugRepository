Title

Field does not dirty when when selecting a nested object.

Description
**Describe the bug**
Possibly related to #2706.

When selecting a value with nested properties from a `react-select` dropdown, the property `formState.isDirty` does not change.

As far as I can tell, the combination of `watch` and nested properties, breaks the formState. When removing the `watch` on the selected item, the `formState.isDirty` changes correctly.

When you downgrade to `6.4.1`, the code works as expected when you select an item from the dropdown. (i.e. the button is not disabled when an item is selected).

**To Reproduce**
Steps to reproduce the behavior:

1. Go to [URL]
2. Click on the first item in the dropdown
3. See that the button remains disabled even though the form is dirty

**Codesandbox link (Required)**
[URL]

**Expected behavior**
The `formState.isDirty` property should change when clicking on an item in the dropdown field. (in combination with `watch`)

**Desktop (please complete the following information):**

- OS: OSX Catalina 10.15.6
- Browser Firefox
- Version 80
