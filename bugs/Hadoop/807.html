Title

Remove jline from distribution

Description
Dist bundles ancient jline-0.9.94 as transitive dependency of zookeeper-3.4.2 (it is used in the ZK CLI and not in Hadoop). Please exclude this jline dependency so that other projects that rely on hadoop classpath can use their own version (there is a newer JLine 2.x that contains history search etc.)
