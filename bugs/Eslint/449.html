Title

Indent rule ignores single statement if, while, for, do-while

Description
The following examples results in having no error:

``` js
if (a)
c();
else if (b)
d();
else
e();
```

``` js
while (a)
b();
```

``` js
for (;;)
a();
```

``` js
for (a in b)
c();
```

``` js
do
a();
while (b);
```

I would expect to have an error if a body statement is not indented.
