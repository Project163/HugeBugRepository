- Great testing - thanks!

`--cutoff-mode cautious` has a race condition namely it checks to see if there is enough space only at the start of the transfer. However it doesn't include the files currently transferring in the space it is looking at.

So I think if you try your test with `--transfers 1` then it will work.

To fix this would need a lot of extra infrastructure so I think I will leave it as it is. The transfer limits will always be somewhat approximate due to buffering etc anyway.
