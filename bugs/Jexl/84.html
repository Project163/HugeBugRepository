Title

Unable to invoke a call operator using antish style variable resoltion

Description
Suppose I have declared an antish style context variable under the name  java.math.BigDecimal  of the  Class<java.math.BigDecimal>  type. 

 To test that it works correctly I use the following script 
  
  var  x = java.math.BigDecimal; x( "1234" ) 
  
  which returns correct value. 

 Now I want to invoke an overloaded call operator directly for this variable using  
  
 java.math.BigDecimal( "1234" ) 
  
   

 which returns an error  

  
 undefined variable java.math 
  

 The expected behaviour is to return the same value as in the first script. 

 I have created a test case for this, please have a look. 

 Thanks!
