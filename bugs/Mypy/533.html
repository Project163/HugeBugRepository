Title

New semantic analyzer: Check type argument count for type aliases

Description
This is a follow-up for [URL]

Unfixed instances in type aliases cause new semantic analyzer to crash, for example:
```
python
class C(Generic[T]):
    ...
def func(x: List[C[T]]) -> T:
    ...
... [Log Snipped] ...

reveal_type(func(x))  # Crash here with list index out of range
```
See also TODO here [URL]
Discussion
- It looks like it is possible to get the crash from unfixed instance even with builtin aliases:
```python
x: Optional[List] = None  # incomplete instance here
y: List[str]

x = ['a', 'b']
x.extend(y)
```
