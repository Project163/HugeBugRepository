Title

Solr 9 standalone mode nullPointerException when ShardHandlerFactory defined

Description
Solr fails to create cores with a “NullPointerException" error when “shardHandlerFactory” is defined for any handlers in the solrconfig.xml file.  

  Snippet from solrconfig.xml:  
  
 
<requestHandler name= "/select"  class= "solr.SearchHandler"   default =" true ”>
        <shardHandlerFactory name= "shardHandlerFactory"  class= "HttpShardHandlerFactory" >
            < int  name= "socketTimeout" >${socketTimeout:800}</ int >
            < int  name= "connTimeout" >${connTimeout:500}</ int >
        </shardHandlerFactory>
</requestHandler>
