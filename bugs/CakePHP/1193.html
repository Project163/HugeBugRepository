Title

toDateTime returns null when passing a Date

Description
### Description

I would expect the function to return a DateTime with zero hours, but instead it returns null.
I think this is a bug because it's checks DateTimeInterface, which was removed when converting FrozenDate to Date.

**Suggested solution**
Replace ```if ($value instanceof DateTimeInterface) {``` with  ```if ($value instanceof DateTimeInterface || $value instanceof Date) {```
