Title

infinite filesystem recursion due to missing file id

Description
I'm trying to use syncthing with a folder exposed by cryptomator. 

The problem is that I'm getting for all folders / files "infinite filesystem recursion" as the virtual filesystem of cryptomator seems to not generate a unique file id for each file.

As example:
X:>fsutil file queryfileid keyfiles
File ID is  

X:>fsutil file queryfileid pictures
File ID is  

As far as I have seen syncthing relies on the unique file id for internal purposes. So far so good. However, I've created an issue on the cryptomator side (see [URL] but as I understood having a unique file id (provided by the file systems) is nothing you can rely on, according to the cryptomator developers. 

I'm not sure if this is true or not, but it seems to be true, as e.g. almost all tools can work with a cryptomator drive without issues - but syncthing. 

As syncthing is a greate / cool tool, I'd like to bring this to your attention.

Syncthing in use: V1.13.1, Windows 10 20H2.
