Title

Zip decompressor has issues with symlinks

Description
Suppose we have the zip file:

```
$ zipinfo -l foo.zip 
Archive:  foo.zip
Zip file size: 617 bytes, number of entries: 4
drwxr-x---  3.0 unx        0 bx        0 stor 16-May-18 13:46 lib-1.0/
-rw-r-----  3.0 unx        0 bx        0 stor 16-May-18 13:46 lib-1.0/thing1
lrwxrwxrwx  3.0 unx        7 bx        7 stor 16-May-18 13:46 current
lrwxrwxrwx  3.0 unx       14 bx       14 stor 16-May-18 14:10 t1
4 files, 21 bytes uncompressed, 21 bytes compressed:  0.0%
```

This gets turned into:

```
$ ls -l .../execroot/a/external/foo
total 24
-rw-r----- 1 kchodorow eng  118 May 18 14:20 BUILD
-rwxrwxrwx 1 kchodorow eng    7 May 18 14:20 current
-rw-r----- 1 kchodorow eng  617 May 18 14:20 foo.zip
drwxr-x--- 2 kchodorow eng 4096 May 18 14:20 lib-1.0
-rwxrwxrwx 1 kchodorow eng   14 May 18 14:20 t1
-rw-r----- 1 kchodorow eng  104 May 18 14:20 WORKSPACE
```
