Title

Recoverable fatal error: Method Psalm\Type\Union::__toString() must return a string value

Description
With our codebase, psalm (from commit   ) crashes with the following message:

```
Recoverable fatal error: Method Psalm\Type\Union::__toString() must return a string value in /data/phplib/vendor/vimeo/psalm/src/Psalm/Context.php on line 218
```

It's easy enough to work around this:

```
$ git diff Union.php
diff --git a/src/Psalm/Type/Union.php b/src/Psalm/Type/Union.php
index bbdbe5e..069dce2 100644
--- a/src/Psalm/Type/Union.php
+++ b/src/Psalm/Type/Union.php
... [Log Snipped] ...
         return substr($s, 0, -1);
     }
```

However, it seems likely that this does not fix the issue, it merely hides it.

substr() is defined by PHP to return false if $s is an empty string.  In this case, $this->types is empty when this happens, leading to an empty $s.  An expression with no type at all seems like a deeper-rooted problem.

Unfortunately, I was not able to determine was what in our code was causing this behavior.

Is there some way to poke at this (perhaps from Context::getRedefinedVars(), where the error is getting detected) to get the relevant source file and line number to figure out what's going on and try to come up with a self-contained reproduction?

The $var variable appears to contain the variable name, but in this case it's a very generic name ("$match") that's used in many places in our code and in third-party libraries.  At least it's not $x.

Running psalm with --debug only generates two lines of "Visiting (path).php" before the error, neither of which refer to a file containing a $match variable.

Thanks!
