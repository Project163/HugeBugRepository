Title

"Speed" field of /core/stats api response gets inaccurate over time

Description
#### What is the problem you are having with rclone?
The field "speed" of the API endpoint  /core/stats seems to drift over time. I'm uploading since 8 days straight now and currently the value is at about 400 MBPS (406479450.72536063). This is absolutely impossible because my upload is 80 times slower. When starting rclone the problem does not occur so this looks like the sum of a few million precision errors.


#### What is your rclone version (output from `rclone version`)
v1.52.3-309-g47d08ac1-beta. I can't use the newest one since I have to let it run for a few days for the error to occur :-)



#### Which OS you are using and how many bits (eg Windows 7, 64 bit)
Raspbian OS 32bit


####  Which cloud storage system are you using? (eg Google Drive)
Jottacloud
