Title

Disabled "line too long"(C0301) not working on comment lines

Description
### Steps to reproduce
1. Disable "line too long" warning in a python script (# pylint: disable=c0301)
2. Place a overlong comment line.

### Current behavior
Disabled warning works for normal code lines, however on comment lines still warns.

### Expected behavior
Warning should not be shown.

### Environment
(K)ubuntu 16.04.4
Atom 1.25.0
