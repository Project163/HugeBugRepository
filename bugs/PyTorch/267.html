Title

Floating Point Exception in nnq.Conv2d with stride=0

Description
### 🐛 Describe the bug

A floating point exception (core dumped) occurs when creating a nnq.Conv2dlayer with stride=0. This is invalid because stride must be ≥1. The error happens during layer initialization or forward pass due to division by zero in internal calculations (e.g., output shape computation).

```python
import torch
import torch.nn.quantized as nnq

conv_layer = nnq.Conv2d(3, 16, kernel_size=3, stride=0, padding=1, bias=True)  # stride=0 causes crash
```
