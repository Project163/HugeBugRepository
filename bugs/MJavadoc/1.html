Title

Plugin should be configured in not

Description
The documentation at 

  [URL]

 indicates that you configure this plugin inside the <build> element of the pom; some research revealed that it is part of the <reporting> element. As a new Maven (2) user, this really caught me unawares.
Discussion
- Javadoc plugin config inside  <build>...</build>  isn't honored when javadoc is generated as part of  site:site  but it is honored by  javadoc:javadoc . 

 See a related issue MNG-1857.
- need to determine the best way to document this, and remove the misleading section in the javadoc plugin. 

 <reporting> - always used, for general report settings 
<build> - used when run in the build lifecycle (for stuff not related to generating the site, eg clover:check might set a failure attribute)
- I've updated the docs with examples for both scenarios.
- This project has moved from Jira to GitHub Issues. This issue was migrated to  olamy/maven-javadoc-plugin#395 .
