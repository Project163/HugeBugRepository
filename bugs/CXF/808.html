Title

JAX-RS: org.apache.cxf.jaxrs.utils.Messages properties file missing definition for NO_CRI_MATCH

Description
JAXRSUtils.selectResourceClass expects a message keyed by "NO_CRI_MATCH". However, when you look in the Messages properties file (org.apache.cxf.jaxrs.utils.Messages), it is absent. 

 Because this message is absent, the Java runtime needlessly generates a ResourceNotFound exception for every resource in your application that it examined and couldn't match the incoming method. 

 The suggested fix, is of course, to define that string. Here's what I came up with: 

 NO_CRI_MATCH=Resource class  
{1}
  will not be selected, request path :  
{0}
