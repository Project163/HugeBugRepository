Title

tauri runner loads html from filesystem instead of asset when embeddedServer is not active

Description
**Describe the bug**
[URL]

tauri runner loads html from filesystem instead of asset when `embeddedServer` is not active

**To Reproduce**
Steps to reproduce the behavior:
1. Make a hello world tauri project
2. Set `tauri.embeddedServer.active` to `false`
3. `yarn tauri build`
4. Remove or rename `../dist/index.tauri.html`
5. Click `app.exe`, the there is nothing happend. If build with `--debug` you will see a panic:

```
thread 'main' panicked at 'Failed to build webview: Error(Io(Os { code: 2, kind: NotFound, message: "系统找不到指定的文件。(File not found)" }), State { next_error: None, backtrace: InternalBacktrace { backtrace: None } })', src\libcore\result.rs:1188:5
```

**Expected behavior**
tauri should load html from packed asset like what embedded server did
