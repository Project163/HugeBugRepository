Title

Enum model validation broken

Description
A little context.  I'm generating only the models, and marshalling json into the models and calling Validate().

I have the following property in my model:

```
            "region": {
                "type": "string",
                "enum": [
                    "us-west-2",
                    "us-east-1"
                ]
            },
```

The resultant validateRegionEnum method fails due to the call to validate.Enum.  Digging deeper it looks like there are a few issues:
- validate.Enum expects the "value" to be a slice, but a string is passed
- upon early failure (mismatching types) nil is returned, but the method returns a *errors.Validation type.  This causes a nil != nil issue (http://www.coldcode.net/2011/06/golang-interface-is-not-nil-even-if.html) and causes an dereferencing nil error.
- even if we get past that (hack), the enum comparison fails "Invalid request validation failure list:\nregion in body should be one of [117 115 45 119 101 115 116 45 50]\n"
