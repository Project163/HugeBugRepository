Discussion
- First, you have to add async runtime(tokio) to `Cargo.toml` and open `postgres` feature if you want to use postgresql.

```toml
[dependencies]
sqlx = {version = "0.4.0-beta.1", default-features = false, features = ["runtime-tokio", "macros", "postgres"]}
tokio = { version="0.3.3", features=["full"]}
anyhow = "1.0.34"
```


Second, you can use `Box ` or `anyhow:Error` or `Box ` to fix the error.
