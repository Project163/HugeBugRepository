Title

Race during concurrent node stop and cache creation

Description
When node attempts to create a cache and is being stopped, both processes hang. The hang happens because gateway is blocked and cache create future is not cancelled.
Discussion
- Semyon, please review my changes (branch ignite-1400). I changed  CacheProcessor  to call  onKernalStop  on exchange manager before stopping caches so that no caches are added after we iterate over the started caches.
