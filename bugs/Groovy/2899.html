Title

Builders don't work in Traits

Description
Traits don't take into account closure delegates, this completely breaks any builder or dynamic behaviour. The following example: 

  
  import  groovy.xml.*

trait MyBuilder {
    def build2() {
        def mkp =  new  MarkupBuilder()
        
        mkp.foo {
            bar()
        }
    }
}

 class  Foo  implements  MyBuilder {

    def build1() {
        def mkp =  new  MarkupBuilder()
        
        mkp.foo {
            bar()
        }
    }
}

foo =  new  Foo()

foo.build1()
foo.build2()
