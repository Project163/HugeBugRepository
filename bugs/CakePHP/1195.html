Title

Mutators always run even when field is not dirty

Description
### Description

Since upgrading to 5.2.0 (and also patch 5.2.1) upon editing an entity via a form & `patchEntity()` all magic `_set()` mutators run even when the field is not dirty. The setter did not previously run when no changes had been passed in `patchEntity()` this is a big behaviour change that is not mentioned in the migration guide that i feel is an unexpected behaviour.

I see there were fixes for loss of context in 5.2.1 

_Fixed regression where custom validation methods would have not get `$context` passed._

Could this be related and a similar issue?  

### CakePHP Version

5.2.1

### PHP Version

8.3.14
