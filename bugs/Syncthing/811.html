- Actually no, this **is** the deadlock, restartFolder holds both pmut and fmut while pausing the sender.

[Image: image]
- For the blocking index-sender `(*indexSender).pause(#703)` there is no `Serve` routine running, but the connection isn't closed either. When a sender is regularly stopped, it is also removed from the index sender map under lock, i.e. the `pause` call shouldn't happen in the first place. The only way I can see this happening is on a db error, in which case the index-sender stops without dropping the connection, and no-one knows about that.
