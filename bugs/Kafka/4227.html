Title

Group coordinator and share coordinator runtime metrics are aliased

Description
Both the group coordinator and share coordinator runtime metrics use the same sensor names and so end up with the same  Sensors . These sensors have both the group and share coordinator metrics as children. When data is reported to a sensor, the data gets added to all the child metrics of the sensor, so both the group coordinator and share coordinator metrics end up adding together and have identical values. 

 We can fix this by ensuring that  GroupCoordinatorRuntimeMetrics  and  ShareCoordinatorRuntimeMetrics  use different  Sensors .
