Title

quarkus.init-and-exit no longer works

Description
### Describe the bug

The runtime configuration property: `quarkus.init-and-exit' is meant to be used to interrupt the execution right after the initialization is complete.

Interruption is achieved by firing a `PreventFurtherStepsException`. However, even when the exception is fired the application stays in a hung state. It does neither start nor exit.
