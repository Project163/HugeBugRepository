Title

[DocDB] TServer may crash when replaying alter schema during local bootstrap

Description
Jira Link: [Link: DB-8334]
### Description

It could happen that server will have to replay alter schema during local bootstrap.

But commit  /D19063 added regression, when Prepare is not called on `ChangeMetadataOperation` in `PlayChangeMetadataRequest`.

It results in failure of this check:
```  
RSTATUS_DCHECK_NE(operation->schema(), static_cast (nullptr), InvalidArgument,
                  "Schema could not be null");
```
in `Tablet::AlterSchema`.
