Title

Checks fail if Docker version contains a non-numeric classifier.

Description
On one of my Linux system the version `from docker version` is reported as `18.06.0-dev`. This causes the version check to fail as it assumes that the version should be purely dots and numbers.

*Edit*:  The correct fix for this should be the following:

- [ ] Have the ability to turn off the version check (either on it's own or as part of `checks.disable=true`
- [ ] Only compare numerical parts of the version and remove and non-numeric classifiers. (For instance this is how Grolifant does version comparisons: [URL]
