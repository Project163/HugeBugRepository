Title

Since Quarkus 3.19 quarkus-junit5-mockito doesn't clean up mocks properly when used in combination with @TestInstance(TestInstance.Lifecycle.PER_CLASS)

Description
### Describe the bug

When using `@InjectSpy` inside a QuarkusTest the mock isn't reset/cleaned up properly between runs if the test has `@TestInstance(TestInstance.Lifecycle.PER_CLASS)` set. If I downgrade to Quarkus 3.18 it works.

### Expected behavior

Tests using this behaviour which were working in Quarkus 3.18 work the same in 3.19

### Actual behavior

Tests that use this that worked in Quarkus 3.18 now fail because the mock isn't cleaned up and mocks from other tests "leak" into other tests.

### How to Reproduce?

See readme in [URL]

### Additional information

It seems like the change that has introduced this behavour was [URL]

We're currently using Quarkus 3.20 LTS. If this issue were to result in a change it'd be great for us if this would be included as a bugfix for 3.20
