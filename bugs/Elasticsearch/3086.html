Title

The `error_trace` parameter should be considered supported on all REST endpoints

Description
### Elasticsearch Version

8.14

### Installed Plugins

_No response_

### Java Version

_bundled_

### OS Version

N/A

### Problem Description

When a `RestHandler` specifies its set of `supportedQueryParameters`, incoming requests will be validated to ensure they contain only the supported set of parameters. 

There are some query parameters that are interpreted by the REST infrastructure and available on every endpoint. They are considered "supported" by every endpoint without every endpoint having to list them in their `supportedQueryParameters`. `error_trace` is missing from that set, [Link: despite being available on every endpoint].

### Steps to Reproduce

Specify `supportedQueryParameters` for an endpoint. Send a request to that endpoint including `error_trace=true`.

The request will be rejected due to an unsupported parameter.

It should not be rejected.
