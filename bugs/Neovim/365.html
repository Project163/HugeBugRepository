Title

NoMatchParen doesn't clear highlights in Neovim v0.10.0

Description
### Problem

Using NoMatchParen doesn't clear the active highlights in Neovim v0.10.0. In Neovim v0.9.x the active highlights are cleared.

### Steps to reproduce

- Call DoMatchParen if not already enabled
- Place cursor over a parenthesis
- Call NoMatchParen

The parentheses will remain highlighted

### Expected behavior

The highlights over the parentheses are cleared.

### Neovim version (nvim -v)

0.10.0

### Vim (not Nvim) behaves the same?

no

### Operating system/version

Ubuntu 23.10

### Terminal name/version

kitty 0.34.1

xterm-kitty
