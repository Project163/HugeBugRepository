Title

7.0.0 regression: Existence of conftest.py messes up package discovery with importlib + pythonpath mode (ModuleNotFoundError: No module named 'tests. ')

Description
Consider the following demo project:

**`setup.cfg`**
```
ini
# The idea is to use `pythonpath = .` to enable imports from the `tests` folder
# like `import tests. `.
# Note that all involved directories have proper __init__.py, and importing e.g.
# `import tests.subpath.helper` works from a Python REPL.
... [Log Snipped] ...
addopts =
    --import-mode importlib
```

**`tests/__init__.py`**
```python
# just empty
```

```python
# just empty
```

```python
# just empty
```

```python
# just empty
```
