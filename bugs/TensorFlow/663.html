**Describe the current behavior**

Given a tensor X with shape (1, 1, 256), matmul gives slightly different output for matmul(X, W) and matmul(tf.tile(X, [1, 2, 1]), W)

**Describe the expected behavior**

The 60 elements of the output of matmul(X, W) should match exactly the first 60 outputs of matmul(tf.tile(X, [1, 2, 1]), W)

Discussion
- I can reproduce this with Tensorflow 2.0.0 and `dtype=tf.float64`
Choose X with shape (a,b) and W with shape (b, c).
Now, I reduce the c dimension of the W tensor using `tf.boolean_mask` to filter out some columns. The results then differ by up to 1e-14.
Interestingly, this happens only to some values but not to others. 
While I can imagine it has to do with some precision problems, there are two reasons it shouldn't happen:
- X is a design matrix in my case, thus containing only the values 0 and 1 for which I don't expect such differences when performing `matmul` operations.
- As @fast-reflexes pointed out, the shape shouldn't make any difference.
