Title

Undefined method `source' in routes with format constraints as String or Symbol

Description
Rails 4.0.0.beta1
Ruby 1.9.3-p385

I have routes like this:

```
get '/photos.:format' => 'feeds#photos', constraints: {format: 'xml'}
```

If I change it to Regexp it works

```
get '/photos.:format' => 'feeds#photos', constraints: {format: /xml/}
```
Discussion
- Did this code work previously? The documentation for `:constraints` states:

```
:constraints
Constrains parameters with a hash of regular expressions or an object that responds to matches?
```

So I think you should pass a Regexp. As this might be a common mistake though I'm not sure if we should present the user with a better error message.

@pixeltrix thoughts?
- It works in 3.2.12. I agree this is against the documentation for `constraints`. But the [Link: Rounting guide] has an example:

```
match "photos", :constraints => {:subdomain => "admin"}
```

But I agree this is not expected behavior if it is not documented for constraints.
