Title

Broken handling of $ref to a definition which maps to interface{}

Description
## Problem statement

Using a $ref which maps to an empty schema generates code, that is not compilable. It seems like commit   broke this.

Generating a server with the following swagger spec and building it results in a compiler error: 
`../restapi/operations/get_test2_responses.go:55:25: invalid type for composite literal: models.Error`

## Swagger specification

```
json
{
    "swagger": "2.0",
    "info": {
        "title": "test",
... [Log Snipped] ...
    }
}
```

## Steps to reproduce

Using the above swagger.json generate a server and build it.
- `swagger generate server -f swagger.json`
- `cd cmd-server`
- `go build` 

## Environment
swagger version: master with commit  
go version: 1.11.4  
OS:   osx mojave
