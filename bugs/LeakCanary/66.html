### Additional Information
Discussion
- The line involved in the crash is (2nd line):

```
      val info = context.packageManager
        .resolveContentProvider(authority, PackageManager.GET_META_DATA)!!
```

It looks like resolveContentProvider() is unexpectedly returning null.

The AndroidX implementation ran into the same issue and simply added more details to the exception being thrown, because they believe this is an error of the app developer.

[URL] 

calling FileProvider.getUriForFile() with a non-existent authority the
PackageManager.resolveContentProvider() call inside FileProvider.parsePathStrategy() will return
null. Throw an error letting the developer know for which authority we expected to find metadata.

```kotlin
if (info == null) {
  throw new IllegalArgumentException(
    "Couldn't find meta-data for provider with authority " + authority);
}
```
