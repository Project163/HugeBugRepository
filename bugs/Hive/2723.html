Title

Hive select query hang when fields contain map

Description
Attached the repro of the issue. When creating an table loading the data attached, all hive query with hangs even just select * from the table. 

 repro steps: 
1. run createTable.hql 
2. hadoop fs -put data /data 
3. LOAD DATA INPATH '/data' OVERWRITE INTO TABLE testtable; 
4. SELECT * FROM testtable;
Discussion
- wedcsProperties column starts with ��� [SOH]  [ETX]  [STX] , where SOH is start of heading with value '\001' in terms of OCT, ETX is end of text with end of text with value '\003' , and STX is start of text with value '\002'.  [STX]  [ETX]  is the format good for map's key/value pair representation.  

 In the data file,  [STX]  [ETX]  means empty map pair, this will make query hanging forever by complaining nothing. 

 Of course ' [' and '] ' don't exist, only for notation purpose in the comment. Be sure to use Notepad++ to view these special chars.
- Just verified,  [STX] my-key [ETX]  is fine for empty value with specific key, however,   [STX]  [EXT] my-value doesn't really work. So the conclusion is empty key will hang the query.
