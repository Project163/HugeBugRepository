Title

Newly added languages to message config.php are not working when using yii\i18n\DbMessageSource

Description
### What steps will reproduce the problem?

Add i18n to application components

```
'i18n' => [
    'translations' => [
        '*' => [
            'class' => 'yii\i18n\DbMessageSource',
            'sourceLanguage' => 'en'
        ],
    ],
],
```

create **messages-config.php** file using `yii message/config-template messages-config.php`
configure messages-config.php to use **db** and to translate to **'ar'**

```
return [
    'sourcePath' => __DIR__ . DIRECTORY_SEPARATOR . '../..',
    'languages' => ['ar'],
    'translator' => 'Yii::t',
    'sort' => false,
... [Log Snipped] ...
    'messageTable' => '{{%message}}',
];
```

now run `yii message messages-config.php`

The tables in the database gets populated with no problem **source_message** contains the messages and their categories and **message** contains foreach source message a row containing the language **ar** and an empty translation (all good till now)

now go back to messages-config.php and add **fr** to the list of languages `'languages' => ['ar', 'fr'],` and run `yii message messages-config.php` you get a message at the end `Inserting new messages...Nothing new...skipped.` and after looking at the database no new row in **message** table is added with **fr** as language
### What is the expected result?

I expected that, for each source message, a new row in the **message** table is added with newly added language to the configuration file and/or translated messages, for any removed language, are deleted from the **message** table
### Additional info

If we add both languages  `'languages' => ['ar', 'fr'],` before the first `yii message messages-config.php` then foreach source message, two rows in the message tables are created as expected.
