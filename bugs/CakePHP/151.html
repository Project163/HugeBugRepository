Title

3.0 Checkbox widget ignores checked key when contained data exists

Description
This may not be an issue so much as it is a user error. I'm trying to create a form where a list of comments are output as checkboxes so the user can select which ones they would like to delete. Using the following results in the checkbox always being checked:

``` php
// Controller

    'contain' ['Comments']
]);
$this->set('post', $post);
```

```
php
// View
echo $this->Form->create($post, ['action' => 'deleteComments']);

for ($i = 0; $i  comments); ++$i):
```
