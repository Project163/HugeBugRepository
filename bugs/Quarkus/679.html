Title

Dependency parity validator is missing dependencies with different versions

Description
Reproducible with the camel-quarkus-amqp module of `quarkus-master` branch of Camel Quarkus [URL]

From my point of view, the dependencies of the amqp runtime and deployment modules a in a perfect parity:

[URL]

```
