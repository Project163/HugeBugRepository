Title

cqlsh HELP SELECT_EXPR gives outdated incorrect information

Description
Within cqlsh, the HELP SELECT_EXPR states that COUNT is the only function supported by CQL. 

 It is missing a description of the SUM, AVG, MIN, and MAX built in functions. 

 It should probably also mention that user defined functions can be invoked via SELECT. 

 The outdated text is in pylib/cqlshlib/helptopics.py under def help_select_expr
