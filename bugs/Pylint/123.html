Title

False positive "pointless-except" with "--disable=all --enable=W"

Description
Originally reported by: **Steven Myint (BitBucket: [Link: myint], GitHub: @myint?)**

---

I originally asked this in #499.

Is the below, expected behavior?

``` python
try:
    import os
    os.listdir('nothing')
except OSError:
    pass
```

Normally, `pylint` gives the correct output.

``` text
$ pylint --report=no example.py
************* Module example
C:  1, 0: Missing module docstring (missing-docstring)
```

But with `--disable=all --enable=W`, it produces something that does not make sense.

``` text
$ pylint --report=no --disable=all --enable=W example.py
************* Module example
W:  4, 7: Except doesn't do anything (pointless-except)
```

Without the `except`, you won't handle the `OSError` that `os.listdir()` will raise. I'm not sure why `pointless-except` shows up in the latter.
