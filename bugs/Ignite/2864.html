Title

SQL: Forbid NOT NULL constraints usage for a cache with configured read-through cache store

Description
We need to throw an exception when user attempts to create or alter a table with a field declared as NOT NULL in a case the corresponding cache configuration employs read-through cache store  CacheConfiguration.setReadThrough() . 

 These features seem to not fit together quite well, so we skip the support at the moment and the check will keep things consistent.
