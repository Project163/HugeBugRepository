Title

Cursor disappears after resizing the window

Description
When I resize the window the cursor disappears...
PS: i'm using a mac book air 11.
Discussion
- This continues to be an issue on OS X as of a commit from a week ago (I can try again with the latest master). It has been reported previously in #100.

**Edit:** Confirmed to occur with current master  . OS X 10.9.2 (latest public release). It happens with `./tests/clipboard` program, exactly as described in [URL]
- Strange, the programs in `./tests/` folder seem to have the bug as described above (i.e. cursor becomes hidden while over the window after a resize). However, apps in `./examples/` (e.g., Boing.app, Gears.app, etc.) appear to have the cursor in GLFW_CURSOR_HIDDEN mode from the start (i.e. no resize necessary).

It feels that the relevant factor is whether the app is launched from the terminal (as in the case of `./tests/*`) or from Finder (the case for `./examples/*.app`).
