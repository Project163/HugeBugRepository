Title

Warnings for failed HTTP requests even when the "throw" option is enabled

Description
The following code:
```
js
import http from "k6/http";

export let options = {
    throw: true,
... [Log Snipped] ...
    http.get("wat://asdgasdg");
}
```

would emit both a warning, and it would throw an error:
```
WARN[0000] Request Failed                                error="Get wat://asdgasdg: unsupported protocol scheme \"wat\""
ERRO[0000] GoError: Get wat://asdgasdg: unsupported protocol scheme "wat"
	at native
	at file:///path/to/script.js:8:24(5) 
```

I think the warning message shouldn't be shown, given that users would either handle the thrown error themselves, or it would bubble up and be logged as an error anyway.
