Title

`ng g @angular/core:standalone` duplicates comments on top of classes

Description
### Which @angular/* package(s) are the source of the bug?

core

### Is this a regression?

No

### Description

```
ng new standalone-migration --defaults
cd standalone-migration
ng update @angular/core@next @angular/cli@next --force
```

Add a comment on top of a class like the following one in `app.component.ts`:
```
ts
import { Component } from '@angular/core';

/**
 * Comment
... [Log Snipped] ...
  title = 'standalone-migration';
}
```

and run the migration:
```
ng g @angular/core:standalone --defaults --mode standalone-bootstrap
```

then the migrated component has a duplicated comment:

```
ts
import { Component } from '@angular/core';
import { NgSwitch, NgSwitchDefault, NgSwitchCase } from '@angular/common';

/**
... [Log Snipped] ...
  title = 'standalone-migration';
}
```
