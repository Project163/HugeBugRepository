Discussion
- Some investigations: 
 
	 The case only happens on Microsoft-hosted agents, whose limit on disk space is 10GB. 
	 The local Maven repo (.m2) is cached across pipeline runs, which is ~15GB currently, and it kept growing in the past year.  
 

 I think the root cause is that the cached local Maven repo has a lot of outdated dependencies and never get cleared. I created a PR to invalidate the cache per year so that the size of local Maven repo won't grow indefinitely.
