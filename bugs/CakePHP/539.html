Title

3.0 table ->save($entity) default validation

Description
As discussed with @lorenzo in #cakephp, the save isn't validating as I'd like it to.

**In short:** I'd like `->save()` to run validation on all the first level entities, on submit even if the _main_ Entities validation fails.

**What it does now:** It validates the _main_ entity first.  If the validation passes it will validate the associations, if the validation failed it wont validate the associations and just display the _main_ error fields error messages.

**I can fix it** by just calling the `->validate()` function before the `save()` will make all the messages appear as you'd expect.
