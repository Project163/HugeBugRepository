Title

support -1

Description
Seems the parser can't handle -1 

 x = -1 
l =  [1, 2, 3]  
last = l [-1]
Discussion
- This is deeper than it appears.  We don't handle these type of unary expressions at all in the AST builder.  We need a "negation" operator somewhere in the system. It is pretty easy to fix it for constants but more difficult in the general case.
- added support for negation expressions
