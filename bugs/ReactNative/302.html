- Hello @cani1see, how are you feeling today? I looked at your example and I concluded that this is NOT a react-native bug. You see, at line 23 (https://github.com/cani1see/AnimationDemo/blob/ /src/RotateWheel.js#L23) you create a new Animated.Value before starting the animation, which overrides the callback listener register that you did in here [URL]
.
You have two options to fix this problem.
At line 23 you could replace the
```javascript
this.rotateDeg = new Animated.Value(0)
```
to
```javascript
this.rotateDeg.setValue(0)
```

This would lead to the following implementation
```
javascript
  rotateImgDelegate = () => {
    if (!this.state.rotating) {
      this.rotateDeg.setValue(0)
      this.setState({
... [Log Snipped] ...
    }
  };
```

Or if you really want to create a new Animated.Value you will need to do the following

```
javascript
  rotateImgDelegate = () => {
    if (!this.state.rotating) {
      this.rotateDeg = new Animated.Value(0)
       this.rotateDeg.addListener(this.rotateListener)
... [Log Snipped] ...
    }
  };
```
