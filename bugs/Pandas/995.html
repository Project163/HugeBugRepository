Title

to_datetime can't handle int16 or int8

Description
#### Code sample

```
df = pd.DataFrame({'year': [2015, 2016],
                       'month': [2, 3],
                       'day': [4, 5]})
pd.to_datetime(df.astype('int16'))
```
#### Expected Output

```
0   2015-02-04
1   2016-03-05
dtype: datetime64[ns]
```
