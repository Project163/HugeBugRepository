Title

rclone reporting incorrect directory listings in Mega

Description
#### What is the problem you are having with rclone?

This issue was reported to Mega and this was the response from Mathias Ortmann at Mega:

- os/arch: darwin/amd64
- go version: go1.10.3

#### Which OS you are using and how many bits (eg Windows 7, 64 bit)

and Debian 9

####  Which cloud storage system are you using? (eg Google Drive)
Mega

rclone ls mega:/TV
