Title

Cluster names should be restricted to ASCII

Description
We no longer use index names for dir/filenames for various reasons, one of which is that unicode and filesystems often don't play well together.

Similarly, we should restrict the cluster name to ASCII only, as the cluster name is used as a directory name.  This is a breaking change, but possibly all that is required is to change the cluster name and rename the directory.  Not sure about snapshots?
Discussion
- We could use the cluster UUID instead of the cluster name same as we do for indices now.  We should also provide a command line tool to allow renaming clusters and indices.
