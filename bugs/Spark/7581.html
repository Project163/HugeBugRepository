Title

python/run-tests.py calling python3.8

Description
this line in run-tests.py on master: 
 
  
 
 python_execs = [x for x in  ["python3.6", "python3.8", "pypy3"]  if which ]

 python_execs = [x for x in  ["python3.8", "python2.7", "pypy3", "pypy"]  if which ]
