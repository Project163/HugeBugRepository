Title

File.eachLine reports line numbers starting with 1, 2,...

Description
file.eachLine  
{ line, number -> assert number > 0 }

 Programmers would expect the line numbers to start with 0, 1,... 

 Furthermore the current behaviour is incompatible with e.g. List.eachWithIndex what makes it difficult to write closures that work in both cases.
Discussion
- It depends on whether you expect to be able to open a file in an editor and move to the relevant line.
- Yes, user interfaces often have strange conventions to be more intuitive. Editors usually start with line=1, column=1 in the top left corner. From this point of view String.eachWithIndex should probably also start with index 1
