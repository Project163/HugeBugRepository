Title

Specify the target API Region in the Content Package to Feature Model converter

Description
The Content Package to Feature Model converter should be able to set the API Regions that the generated feature belongs to.  

 It should be possible to pass a command-line argument to the converter that lists the API regions, and the generated feature file should be part of these API regions. It should not need to export any packages to the regions, but just be part of them.
