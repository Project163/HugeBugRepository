Title

Transfering ownership of repo with issues in a project board to another org breaks project board columns

Description
### Description

Hello everyone, I've noticed that when I move repositories that currently has issues in the project board to another organization, the project board still has the issues from the moved repo which now kinda break the columns they are in. Sometimes other issues can't be moved in or out of the bugged columns. The only solution I currently have is to go to the moved repositories and edit the issues so they don't have the project board referenced there. 

I think a solution would be that if you transfer ownership to another organization that all issues in that repo get their project board reference removed and that this would be mentioned in the warning. 

I've replicated the issue on the demo instance, you can find my bugged project board here: [URL]

If you need any further information of testing from my side, please let me know!
