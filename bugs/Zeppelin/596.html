Title

Hive Jdbc interpreter does not relogin if kerberos ticket expired when hive.server2.transport.mode is http

Description
Hive Jdbc interpreter does loginUserFromKeytab at startup which expires after kerberos ticket lifetime  (1 day always due to a JDK Bug  [URL]  Hadoop Client will re-login once the ticket expired in case of RPC and so when hive.server2.transport.mode is binary, Hive Jdbc interpreter does a relogin and works fine. But when Rest API is used i.e when hive.server2.transport.mode is http, it is not doing a re-login and so fails with GSS exception.
