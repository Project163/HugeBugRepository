Title

List extension of sqlalchemy objects doesn't terminate

Description
### Describe the bug

Extending a list of sqlalchemy objects with themselves runs forever, i.e. list += list doesn't terminate.

### To Reproduce

```
python
from sqlalchemy import Column, ForeignKey, Integer, String
from sqlalchemy.orm import declarative_base, relationship

Base = declarative_base()
... [Log Snipped] ...
testlist += company.employees
print("Finished")
```

### Error

No output.

### Versions

- OS: Linux Mint 20.2
- Python: Python 3.8.10
- SQLAlchemy: 1.4.27
- Database: n/a (also tested with sqlite)
- DBAPI (eg: psycopg, cx_oracle, mysqlclient): n/a

### Additional context

Changing line 32 (testlist = company.employees) to testlist = company.employees.copy() fixes the problem. Otherwise the program runs forever.
