Title

Join in local mode matches null keys

Description
Semantics of join and cogroup dictate that null values for the keys from different inputs are NOT supposed to match. This is true in map reduce mode but local mode incorrectly matches these records.
Discussion
- Attached patch which addresses the issue - the fix is in POCogroup to make the comparator of group keys treat two keys with null value as different if they are from different inputs
