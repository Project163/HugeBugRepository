Title

Upgrade hadoop to 2.7.4 or later; will use current 3.2.0

Description
The reason why the Travis builds currently fail for JDK 13/EA is due to this Hadoop issue:   HADOOP-14586   

 I've tested it locally (JDK 13, Build 33) with Hadoop 2.7.4 and all tests pass. As this does bump the Hadoop dependency from 2.6 to >=2.7.4 you probably want to do this for a VFS 2.5 release and in the mean time disable the 13/EA builds in Travis.
