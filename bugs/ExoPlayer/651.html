Title

running the demo in pre 21 can not handle headphone physical pause/play button

Description
running the demo app in android 4.3 while connecting it with a headphone, pressing the puase/play button on the headphone doesn't do anything. while debugging the issuse i found that the headphone sends KEY_EVENT_HEADSETHOOK on pressing play/pause button which isnt captured by isHandledMediaKey.

### proposed solution:
in [Link: **PlayerControlView**] class make the following changes
1-Add missing keyCode to isHandledMediaKey function
```
java
@SuppressLint("InlinedApi")

    return keyCode == KeyEvent.KEYCODE_MEDIA_FAST_FORWARD
        || keyCode == KeyEvent.KEYCODE_MEDIA_REWIND

  }
```

