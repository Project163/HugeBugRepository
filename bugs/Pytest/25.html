Title

ValueError: unsupported format character in assert reporting

Description
Originally reported by: **BitBucket: [Link: armooo], GitHub: [Link: armooo]**

---

There is a problem when an assert contains a '%'. Here is an example.

```
def test():
    assert '%test' == 'test'
```

Which will raise this exception.

ValueError: unsupported format character 't' (0x74) at index 2
