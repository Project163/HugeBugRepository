Title

Cannot use UriInfo context in resteasy-reactive `@ServerResponseFilter`

Description
### Describe the bug

According to the [Link: RESTeasy Reactive guide], filter parameters can take any [Link: context object]. However, declaring `UriInfo` as a parameter in a response filter results in a runtime error. (This happens for a few other context objects.)

It seems that `UriInfo` is a valid parameter for `getRequestFilterResultHandles` but not for [Link: `getResponseFilterResultHandles`].
[URL]

I'm not sure if this is a documentation or implementation issue.

### Expected behavior

It's possible to access `UriInfo` in a response filter with `ContainerRequestContext#getUriInfo()`. Ideally, response filters could directly declare `UriInfo` without error.
