Title

[DocDB] Use-after-free in RefinedStream::Connected failure path

Description
Jira Link: [Link: DB-8548]
### Description

`RefinedStream::Connected` calls `context_->Destroy(status)` when `StartHandshake()` or `refiner_->Handshake()` fail. `TcpStream::Handler` calls `RefinedStream::Connected()`, but in this code path, `context_->Destroy(status)` eventually destroys the `TcpStream` object, and the subsequent call to `TcpStream::WriteHandler()` in `TcpStream::Handler` results in a write to freed memory.
