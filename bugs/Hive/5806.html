Title

repl load task during subsequent DAG generation does not start from the last partition processed

Description
DAG generation for repl load task was to be generated dynamically such that if the load break happens at a partition load time then for subsequent runs we should start post the last partition processed. 

 We currently identify the point from where we have to process the event but reinitialize the iterator to start from beginning of all partition's to process.
