Title

Important Semicolon Is Removed

Description
With these files:

`a.mjs`:
```js
import rollup from 'rollup'
;(async()=>{
    let
        bundle=await rollup.rollup({input:'b.mjs'}),
        {code}=await bundle.generate({format:'iife'})
    console.log(code)
})()
```

`b.mjs`:
```js
import c from './c.mjs'
;(()=>{
    console.log(c)
})()
```

`c.mjs`:
```js
export default 0
```

Run: `$ node --experimental a.mjs`

Output:
```
(function () {
    'use strict';

    var c = 0

... [Log Snipped] ...

}());
```

Expected: At least one semicolon between `var c = 0` and `(()=>{`.

`$ node -v`: `v9.10.1`
`$ npm -v rollup`: `5.8.0`
