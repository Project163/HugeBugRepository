Title

Match phrase prefix query seems to ignore boost value.

Description
There seems to be no effect on score on changing boost value on match_phrase_prefix query. 

My query is:
   "query": {
        "bool": {
            "should": [
                {"match_phrase_prefix": {
                        "firstName": {
                            "query": "is", 
                            "boost":2.0
                        }
                    }} ,
                    {"match_phrase_prefix": {
                        "userName.raw": {
                            "query": "Tiv", 
                            "boost":4.0
                        }
                    }}
              ]
        }
    }  

I am trying this on Elasticsearch-1.7
