Title

Xmlrpc library debugging generates PHP error

Description
When invoking an xmlrpc remote method call with $this->xmlrpc->set_debug(TRUE), I'm getting a PHP error when displaying the headers.

---DATA---
HTTP/1.1 200 OK
Content-Type: text/xml;charset=UTF-8
Server: Microsoft-IIS/8.5
X-Powered-By: PHP/7.2.7
Date: Thu, 16 Aug 2018 18:04:49 GMT
Connection: close
Content-Length: 2606

 
 
...
 
---END DATA---

A PHP Error was encountered
Severity: Warning
Message:  count(): Parameter must be an array or an object that implements Countable
Filename: libraries/Xmlrpc.php
Line Number: 1216
Backtrace:
...
---HEADERS---
HTTP/1.1 200 OK
Content-Type: text/xml;charset=UTF-8
Server: Microsoft-IIS/8.5
X-Powered-By: PHP/7.2.7
Date: Thu, 16 Aug 2018 18:04:49 GMT
Connection: close
Content-Length: 2606
---END HEADERS---

Changing libraries/Xmlrpc.php, line 1216 from:
			if (count($this->xh[$pname]['headers'] > 0))
to:
			if (count($this->xh[$pname]['headers']) > 0)

fixes the problem.
