Title

Attribute.isBooleanAttribute() should not be case sensitive

Description
The isBooleanAttribute() method of org.jsoup.nodes.Attribute is case sensitive.  The test for a boolean attribute should not be case sensitive.

isBooleanAttribute("REQUIRED") returns false
isBooleanAttribute("required") returns true
