Title

NamedTuple should not satisfy Protocol with mutable fields

Description
The following code doesn't produce a type error, but will crash at runtime, because the named tuple's fields cannot be set

```
python
from typing import NamedTuple
from typing_extensions import Protocol

class HasX(Protocol): 
... [Log Snipped] ...
a: HasX = A("foo")
a.x = "bar"
```
Since `HasX` requires `x` to be settable, `A` should not be a structural subtype of `HasA`.
Discussion
- OK, the solution is super-simple here. Since named tuple variables are "artificial" (auto-generated), and therefore are always created directly as a `Var` with `is_property` set to `True`, they are not identified as immutable by protocol check (it looks for a `property` decorator).

So it would be just one line fix in `subtypes.get_member_flags`, we need to add a check for `v.is_property` in this code:
```pthon
    # just a variable
    if isinstance(v, Var):
        flags = {IS_SETTABLE}
```
