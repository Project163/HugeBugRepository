Title

sha256 checksum files for the binary installer can't be used with `sha256sum -c`

Description
The sha256 file for the Linux installer contains the following:

```
 
```

The usual way of providing sha256 checksums would be:

```
   bazel-0.1.0-installer-linux-x86_64.sh
```

This way the file can easily be checked with `sha256sum -c bazel-0.1.0-installer-linux-x86_64.sh.sha256`.
