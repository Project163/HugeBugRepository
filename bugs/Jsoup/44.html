- @AllanWang - the issue that was fixed specificall in this bug is as mentioned on [URL] - IOExceptions should be thrown as checked IOExceptions, not as Unchecked Errors. Those are still thrown in the event of an IO exception, such as the server not writing all the bytes to the stream that it promised for a gzip stream. You need to catch those.
