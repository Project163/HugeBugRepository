Title

Using the remote's Play/Pause button when player controls are visible cause repeated plays/pauses

Description
When the player controls are visible and holding down the Play/Pause button on the remote (e.g. an Amazon FireTV remote) causes the player to play/pause repeatedly.

You can see the behaviour here: [URL]

Steps to reproduce:

1. When video player is open, give focus to the player controls's Play/Pause button
2. On your remote hold down the Play/Pause button (see: [URL]
3. Notice the play/pause button on the screen toggles repeatedly

Likely issue is this case statement:
[URL]
Discussion
- I think you're right. We should be checking `event.getRepeatCount()` so that we can ignore subsequent events. The exceptions to this rule are `KEYCODE_MEDIA_FAST_FORWARD` and `KEYCODE_MEDIA_REWIND`, for which we it is correct that we take action for each repeated event.
