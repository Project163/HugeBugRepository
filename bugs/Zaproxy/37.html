Title

Connection closed without response, with an Authentication script with errors

Description
Steps to reproduce the issue:
1. Run ZAP (version 2.4.2);
2. Create an "Authentication" script with a call to an undefined function;
3. Setup the authentication of a context to use the created authentication script and enable "Forced User";
4. Proxy a request;
5. Note that the user-agent doesn't get a response, but it should even if the authentication was not successful;
6. Check the log file, there should be an exception:
