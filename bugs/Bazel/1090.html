Title

test.xml is not always downloaded with BwoB even if --remote_download_regex='.*/test.xml' is specified

Description
### Description of the bug:

I'm trying to make Bazel unconditionally download the `test.xml` output files of the test runs from the remote cache and whether this works is hit-or-miss.

The scenario I'm trying is:

```
$ bazel test --config=remote-only --remote_download_regex='.*/test.xml' //some:test
$ fd --follow test.xml bazel-testlogs/some                                                                       
bazel-testlogs/some/test/test.xml    <-- This is sometimes missing
```

Here is what I have found:

* The `test.xml` is downloaded if the test results are NOT cached yet (`--nocache_test_results`).
* The `test.xml` is NOT downloaded if the test results are cached.
* The `test.xml` is correctly downloaded in either case if I run `bazel clean` first.
* Running with "remote download all" causes the `test.xml` to be downloaded in all cases.

This seems like a bug.

I've also found [URL] which is NOT related to this problem but the discussion there seems to imply that `test.xml` is "special" so it wouldn't surprise me if it isn't accounted for somehow.
