Title

OpenAPI: Use standard value for query parameter "format"

Description
As discussed with @EricWittmann on gitter, the MicroProfile specification is clear about the optional query parameter `format` that is used to control the format of the OpenAPI specification:

```
GET [URL]
```

The ` ` can be:
* `YAML`
* `JSON`

See: [URL]

—

The current implementation checks for following values:

* `application/yaml`
* `application/json`

Those are the values expected for the `Accept` header (that can also be used to control the format of the generated OpenAPI)
