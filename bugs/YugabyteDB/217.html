Title

SST File metrics are not updated real-time on tservers

Description
While manually flushing tables through `yb-admin`, I noticed that metrics like `rocksdb_total_sst_file_size` do not update real-time for tserver (works on master). I have to manually run `yb-ctl restart` to get the metrics to update.

Steps to reproduce:

1. `bin/yb-ctl start`
2. `java -jar target/yb-sample-apps.jar --workload CassandraKeyValue --nodes  :9042`
3. Checking tserver metrics at `localhost:9000/metrics` shows `rocksdb_total_sst_file_size` is 0. Master on the other hand is updated at `localhost:7000/tablet-servers` and `localhost:7000/metrics`.
4. `build/latest/bin/yb-admin flush_table ybdemo_keyspace cassandrakeyvalue`
5. `localhost:9000/metrics` is still not updated.
6. `bin/yb-ctl restart`
7. `localhost:9000/metrics` is updated.
