### What happened?

I would like to reuse a `docker-compose.yml` instead of configuring all the containers from scratch. I noticed that this is possible using the Docker Compose Module:

```java
    @Container
    public static ComposeContainer compose = new ComposeContainer(
            new File("docker-compose.yml"),
            new File("docker-compose.override.yml")
            )
            .withExposedService( // ...)
            .withLocalCompose(true);
```

However, the `docker-compose.override.yml` file uses the YAML tag `!reset` to "reset" the volumes:

```
services:
  localstack:
    volumes: !reset []
```
This is the error I see when I run the tests:

```
could not determine a constructor for the tag !reset
```
