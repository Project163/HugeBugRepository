Title

Support docstrings on hybrid attributes

Description
**Migrated issue, originally created by David Baumgold ([Link: @singingwolfboy])**

Currently, it appears that there is no way to set a docstring on a hybrid attribute: even if there is a docstring on the function, the `@hybrid_property` and `@hybrid_method` decorators don't copy it over to the objects they return. There should be way to set docstrings on hybrid attributes.

My ultimate goal is to get [Link: Sphinx's] [Link: autodoc] extension working properly with hybrid attributes, so that I can write RST-formatted docstrings for the hybrid attributes of my data models, and generate beautiful documentation from those docstrings.

I started putting together a fix for this bug in [Link: a GitHub pull request], but the problem turned out to be more complicated than I expected.
