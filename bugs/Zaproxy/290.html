Title

Default policy on start up not using edited policy rules

Description
### Describe the bug

modified rules of the auto selected scan policy are not used. 'Default' is shown and used for the active scans.

### Steps to reproduce the behavior

Change the rules of the default policy, then close zap and restart. 

Attempt an active scan, the default policy is used however the edited rules that I changed are not shown. It states 'Default' for all rules. 

If reselect default policy from drop down in active scan pop up then modified rules show.

From then on the default policy has the correct modified rules for all active scans.

### Expected behavior

Show and use modified rules

2.11.1
