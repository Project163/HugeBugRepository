Title

multi_match query with wildcard against boolean doesn't expand

Description
**Elasticsearch version** : 6.3.0
**JVM version** : 1.8.0_144
**OS version** : OSX

**To Reproduce:**

1) Index various data types:

```
PUT test3/doc/1
{
  "obj": {
    "flag": true,
    "text": "asdf",
    "numeric": 42
  }
}
```

2) Search the boolean value with wildcard in field name:

```
GET /test3/_search
{
  "query": {
    "multi_match": {
      "query":    true,
... [Log Snipped] ...
  }
}
```

The above fails, even though the same search without expansion succeeds:

```
GET /test3/_search
{
  "query": {
    "multi_match": {
      "query":    true,
... [Log Snipped] ...
  }
}
```

Text or Numeric searches with expansion succeed:

```
GET /test3/_search
{
  "query": {
    "multi_match": {
      "query":    42,
... [Log Snipped] ...
  }
}
```
