Title

Couldn't use Comparison in Query::where() method in more complex cases

Description
I have query like that (its simplified for better readability):

``` php
$query = $this->Customers->find();
$query->where(
    ['OR' => [
        new Comparison('first_name', $queryString, 'string', 'ILIKE')
    ]]
);
$query->all();
```

And after that, I get sql error: `SELECT [...] FROM "customers" "Customers" WHERE ()`.
If I add query like:

``` php
$query->where(
    new Comparison('first_name', $queryString, 'string', 'ILIKE')
);
```

or

``` php
$query->where(
    ['OR' => [
        'first_name ILIKE' => $queryString
    ]]
);
```

I have no errors.
I do some research, and I found that, `QueryExpression::add()` is called with parameter `Array[Comparasion]`, and after that is called `$this->_addConditions()`
Method `_addConditions` gets simple array with Comparasion object, but after some ifs condition isn't added to $this->_conditions stack.

I remember that, this query was working few weeks ago.
