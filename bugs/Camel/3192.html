Title

url.getPort returning -1, needs additional check

Description
In our environment, the camel-swagger component is building relative urls with a port of -1.  [URL] is what is returning -1. 

 The fix is to change 

       if (url.getPort != 80) { 

 to 

       if (url.getPort != 80 && url.getPort != -1) { 

 in RestSwaggerApiDeclarationServlet.scala. See  [URL] for the line of code that is affected.
