Title

Printing script causes the editor font to change

Description
If you click the Print menu option from inside the Groovy Console, it causes the font in the editor to change 

 And writes: 

  
 2009-08-19 15:28:19.884 java[1597:613] Error loading /Library/Printers/hp/PDEs/hpPostScriptPDE.plugin/Contents/MacOS/hpPostScriptPDE:  dlopen(/Library/Printers/hp/PDEs/hpPostScriptPDE.plugin/Contents/MacOS/hpPostScriptPDE, 265): no suitable image found.  Did find:
	/Library/Printers/hp/PDEs/hpPostScriptPDE.plugin/Contents/MacOS/hpPostScriptPDE: no matching architecture in universal wrapper
 
  

 to the command line
Discussion
- Actually, this could be an HP driver issue on OS X, causing the Java Print to crash and the font change being a side effect of this crash
- I've got the same issue, the font becomes Arial, or something like that. 
Changing back the font size brings the original font though. 
I've also got an HP printer, and I'm also on OS X.
- ... [Middle Discussions Snipped for Brevity] ...
- But it doesn't really give the solution to our problem, does it? 
We just call a print job, and we don't do much more, nowhere where we set the font or anything (beside in the console that is). 
Am I missing something?
- After looking into it, it seems to be because the font in the PRINT_PANE is not set to the same as in the actual component, and this causes corruption to the font in the Document object somehow 

 I didn't even know it was recommended to use the same Document in 2 separate components 

 The attached diff seems to fix the font changing, but not the HP Driver exception or the fact that you need to CTRL-C the console after printing as Quit no longer works (I guess due to the exception)
