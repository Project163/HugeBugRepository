Discussion
- This might actually be a real bug (it shouldn't crash), but you also shouldn't prepend "assets" to your path.

So, in short, replace this:

```
if(!font.loadFromFile("assets/sansation.ttf"))
```

with this:

```
if(!font.loadFromFile("sansation.ttf"))
```
- I see, so the top directory is already "assets" and it crashed because it couldn't find the font since I provided the wrong path.

I moved the font into assets/test subdirectory and tested it by this line `if(!font.loadFromFile("test/sansation.ttf"))` and it works without a crash. Thank you.
