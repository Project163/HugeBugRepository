Title

x-www-form-urlencoded cannot be consumed in go-swagger 0.5.x

Description
## Problem statement

I have an swagger api with some endpoint that consumes x-www-form-urlencoded, it used to work fine, but the newest go-swagger throws an error 500, no default consumer for x-www-form-urlencoded.

go-swagger does not use a consumer for x-www-form-urlencoded, it uses the golang request.ParseForm method. In the bind request method of the parameters, which is perfectly fine:-)

```
if err := r.ParseMultipartForm(32 << 20); err != nil {
        if err != http.ErrNotMultipart {
            return err
        } else if err := r.ParseForm(); err != nil {
            return err
        }
    }
```
## Hack

However the newest go-swagger 0.5.x insist on validating that at producer is registered for x-www-form-urlencoded

The only way to come around is to make a hack in the restapi/x_api.go adding the following to the switch statement in ConsumersFor: 

```
case "application/x-www-form-urlencoded":
   result["application/x-www-form-urlencoded"]= httpkit.ConsumerFunc(func(reader io.Reader, data interface{}) error {
             return nil
            })
```
## Steps to reproduce

Make a swagger document that consumes x-www-form-urlencoded
