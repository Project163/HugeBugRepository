Title

ESQL: Full task queue leads to 500 errors instead of 429

Description
Sometimes, the compute engine's tasks get rejected by the thread pool executor because its queue is full. These rejections get bubbled up as internal server errors (500), but they should be 429 as we receive more esql requests than can currently be handled.

The failures happens at `ExchangeSourceImpl.checkFailure(ExchangeSourceHandler.java:56)`
