Title

Mirror update does not respect restrictions

Description
- Gitea version (or commit ref): current master

## Description

If repository migration is restricted with `setting.Migrations.AllowedDomains`, `setting.ImportLocalPaths` or `setting.Migrations.AllowLocalNetworks` these are [Link: only enforced at the initial migration]. After the first migration you can change the mirror url to any disallowed domain. The settings page also doesn't work with local paths because `The provided url is invalid. Only http(s):// or git:// locations can be mirrored from.` which is not true. Both modules should share the same logic.

An other question: Should a mirror sync be cancled if the original clone url gets disallowed afterwards?
