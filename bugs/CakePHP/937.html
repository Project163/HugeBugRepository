Title

PDOStatement fetchAll('obj') using fetch() instead

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.6.4
* Platform and Target: N/A

### What you did
Called PDO fetchAll('obj')

### What happened
Got a single object of the first record back.

### What you expected to happen
Expected to get an array of record objects.  I can see that in src/Database/Statement/PDOStatement.php, the fetchAll function contains the wrong function (fetch()) for when the $type is 'obj':

```
public function fetchAll($type = parent::FETCH_TYPE_NUM)
    {
        if ($type === static::FETCH_TYPE_NUM) {
            return $this->_statement->fetchAll(PDO::FETCH_NUM);
        }

        return $this->_statement->fetchAll($type);
    }
```
