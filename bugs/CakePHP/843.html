Title

Redirects not working after upgrade to 3.4.0 due to a route defined with an accent.

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.4.0
* Platform and Target: All of them (checked under ubuntu and debian, but should fail in any OS)

### What you did
Upgraded from Cake 3.3.14 to 3.4.

### What happened
A redirect to an old defined route with an accent (`/alta/confirmación`) stopped working. As a workaround I've changed the route to `/alta/confirmar` and it works as expected now.

### What you expected to happen
The redirect should work with and without accents on it.

The `NamedRouter` is just a class extending `Router` to just add a helper method for named routes:

~~~php
// src/Routing/NamedRouter.php
namespace App\Routing;

use Cake\Routing\Router;

class NamedRouter extends Router
{
    public static function scope($path, $params = [], $callback = null)
    {
        $builder = new NamedRouteBuilder(static::$_collection, '/', [], static::$_collection->extensions());
        $builder->scope($path, $params, $callback);

// src/Routing/NamedRouteBuilder.php
namespace App\Routing;

use Cake\Routing\RouteBuilder;

class NamedRouteBuilder extends RouteBuilder
{
    public function connectNamed($_name, $route, array $defaults = [], $options = [])
    {
        return $this->connect($route, $defaults, $options += compact('_name'));
    }
}
