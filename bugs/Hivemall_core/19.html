Title

[BUG] feature_binning does not work properly under certain conditions

Description
feature_binning does not properly work in certain condition. 

 It might be a bug in quantiles lookup by a different key type object at  this line . 

   
  
 
WITH extracted as (
  select
    extract_feature(feature) as index,
    extract_weight(feature) as value
  from
    input l
    LATERAL VIEW explode(features) r as feature
),
bins as (
   select
     map(index, build_bins(value, 5,  true )) as quantiles -- 5 bins with auto bin shrinking
   from
     extracted
   group by
     index
)
select
  l.features as original,
  feature_binning(l.features, r.quantiles) as features
from
  input l
  cross join bins r
;
Discussion
- The query was wrong.  It worked properly. So, it's not a bug. 

   
  
 
WITH extracted as (
  select 
    extract_feature(feature) as index,
    extract_weight(feature) as value
  from
    input l
    LATERAL VIEW explode(features) r as feature
),
quantiles as (
  select
    index, 
    build_bins(value, 5,  true ) as quantiles -- 5 bins with auto bin shrinking
  from
    extracted
  group by
    index
),
bins as (
   select 
    to_map(index, quantiles) as quantiles 
   from
    quantiles
)
select
  l.features as original,
  feature_binning(array( '40:1' ,  '70:14' ,  '70:15' ), r.quantiles) as features
from
  input l
  cross join bins r
limit 10;
