Title

ReplicaNotAvailableException must be retriable to handle reassignments

Description
ReplicaNotAvailableException should be a retriable `InvalidMetadataException` since consumers may throw this during reassignments.
Discussion
- Hi,  rsivaram . Is this only 2.6.0 issue?
- dongjoon  This is not a 2.6.0 issue, ReplicaNotAvailable has always been non-retriable. This turned out to be a bigger issue in non-Java consumers since fetch-from-follower was introduced in  2.4.0. Java consumers always handled this case correctly and were not affected.
