Title

H2TlsStrategy does not handle proxy connections correctly

Description
I'm setting up a CloseableHttpAsyncClient with an AsyncClientConnectionManager that sets up an H2TlsStrategy for the https scheme. In my integration tests, I have one test that calls a target host,  [URL] over a proxy located at  :8900. This mostly works: the client sends a CONNECT request to  :8900 to set up a tunnel, and then sends a ClientHello to the target via the tunnel. 

 The problem is that my HostnameVerifier is getting called back with the wrong hostname: instead of the target hostname ("localhost"), it is getting called back with the proxy hostname (" "), and this then causes hostname verification to fail.
