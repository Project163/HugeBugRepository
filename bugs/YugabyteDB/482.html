Title

Cluster Start taking about a minute longer than usual

Description
PG Sys tables aren't getting created during build. Because of this, they get created when the cluster is started leading to the nodes taking longer (~1 min) than usual to start. The check for creating the initial snapshot is being bypassed due to a typo in CMakeLists.txt This GH has been created to track this.
