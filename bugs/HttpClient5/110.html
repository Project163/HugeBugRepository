Title

Async client incorrectly pipes CONNECT requests through the main request protocol chain

Description
HttpRequestInterceptor can be added to both CloseableHttpClient and CloseableHttpAsyncClient, but a CONNECT request can be caught only with CloseableHttpAsyncClient.  
Even if I use the following examples:  for async  or  for classic  from GitHub. 

 Could it be possible to fix this issue and cover the "connect" request in CloseableHttpClient's request interceptor?
