Title

`null === undefined` and similar expressions evaluate to true in the template compiler.

Description
**I'm submitting a ...**  (check one with "x")

```
[x] bug report => search github for a similar issue or PR before submitting
[ ] feature request

```

**Current behavior** 
`variable === undefined` is true when `variable` is `null`, and `null === undefined` is true in templates.
`variable === null` is false (as expected) when `variable` is `undefined`, but `undefined === null` is true.

**Expected behavior**
`variable === undefined` should evaluate to false when `variable` is `null`, and `null === undefined` should evaluate to false.
`variable === null` should evaluate to false (as it does) when `variable` is `undefined`, and `undefined === null` should evaluate to false.
