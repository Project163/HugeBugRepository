Title

linebreak-style: throws error if file is one line without line ending.

Description
I'm experiencing the following error.

```
                lineOfError = linebreaks.indexOf(expectedLF ? "\r\n" : "\n");
                                         ^
TypeError: Cannot call method 'indexOf' of null
```

This happened with a file that was only 1 line long with no actual `LF` or `CRLF` at the end of the file.

This was due to the following line in [Link: lib/rules/linebreak-style.js#L21] not matching any linefeeds.
