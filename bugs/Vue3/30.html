Discussion
- Why is Vue 3 even doing this to begin with? It seems to be a convenience feature that was introduced intentionally ([Link: there's a test for it]), but it's a breaking change:

In Vue 2, ` ` would result in an element with ID "null", in line with the normal DOM API where the value is automatically stringified (for better or worse). Only attributes had special treatment, where `null` or `undefined` meant removing the attribute.
- FYI: there is no `.prop` modifier in Vue 3 anymore. Vue 3 intelligently determines if the key should be set as a prop or an attribute.

A result of this is that ` ` also sets `id` as a prop - so it needs to coerce nullish values to strings in this case.
