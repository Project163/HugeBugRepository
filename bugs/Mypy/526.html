Title

Type check super() arguments

Description
Currently the arguments in `super()` calls are not checked.
Discussion
- Actually this is not that urgent, since this is mostly relevant for Python 2 code.
- For example, mypy doesn't report an error for this code:

```
class A:
    def f(self) -> None: pass

class B(A):
    def f(self) -> None:
        super(1, '', '').f()   # ouch, should generate an error
```
