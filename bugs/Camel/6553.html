Title

Camel-AS2: exception on empty response

Description
When Camel-AS2 client doesn't request the MDN (dispositionNotificationTo isn't set) many  AS2 servers (and camel AS2 as well) respond with empty HTTP body. This cause exception in 
EntityParser.parseAS2MessageEntity. 
There is a workaround - you just always need to set dispositionNotificationTo.
