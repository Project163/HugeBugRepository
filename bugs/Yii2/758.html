Title

Getting error with relation records when we have more 1000 parent records

Description
### What steps will reproduce the problem?
When model **A** have more 1000 records and we need to get **relation** records:
```php
A::find()->with(['relation'])->limit(1001)->all();
```
### What is the expected result?
Relation records

### What do you get instead?
Error in ./vendor/yiisoft/yii2/db/QueryBuilder.php at line 1544
```php
strtoupper() expects parameter 1 to be string, object given
```
First elements isn`t string. All elements is objects ("in condition"):
```php
$operator = strtoupper(array_shift($condition));
```

| Yii version      | 2.0.15
| PHP version      | 7.0.25
| DB | Oracle OCI
