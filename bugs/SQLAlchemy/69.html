Title

Indexed is a reserved keyword for SQLite since SQLite 3.6.4

Description
**Migrated issue, originally created by Anonymous**

Since the SQLite version 3.6.4 (2008 Oct 15) 'indexed' is a reserved keyword. This change make the creation of new tables with 'indexed' column name not working.
