Title

Building curl via cmake ExternalProject_Add does not set CURL_CA_PATH

Description
Hi,

I discovered that CURL_CA_BUNDLE and CURL_CA_PATH does not set properly if I used ExternalProject_Add to build curl as my dependency.

### I did this

The following snippets are how I reproduced this issue. 

```
cpp
// a.cc
#include  
#include  
#include  
... [Log Snipped] ...
  curl_easy_cleanup(curl);
}
```

```
cmake
# CMakeLists.txt

cmake_minimum_required(VERSION 3.10)
project(test)
... [Log Snipped] ...
    "-DCMAKE_INSTALL_PREFIX:PATH=${CMAKE_BINARY_DIR}"
)
```

### I expected the following

After running my test program, I expected a response from ``github.com``. However, I received the following error:

Build and run commands:

```
bash
$ ls 
a.cc  CMakeLists.txt
$ mkdir build
$ cd build
... [Log Snipped] ...
$ ./test
SSL peer certificate or SSH remote key was not OK
```

I think the issue is from cmake cache. Probably, we need to ``set(CURL_CA_PATH_SET FALSE) `` and ``set(CURL_CA_BUNDLE_SET FALSE)`` on [Link: CMakeLists.txt:819] and [Link: CMakeLists.txt:808]?

### curl/libcurl version

master branch

### operating system

ubuntu 20.04
