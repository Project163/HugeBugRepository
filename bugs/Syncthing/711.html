Title

gui: Number of days must be number flashes red then disappears

Description
# What happened

When adding a new directory (6th one, all others were synced already), using trashcan versioning, I entered "150" without the quotes for the number of days to keep the files in trash. When I pressed the continue or create button, a number of things flashed up as red but the dialog closed so quickly I could just hardly read "Number of days must be a number ...".

Then on the other computer, with exactly the same browser version and linux version, I agreed to add the new shared folder, and filled in the same entries, including "150" for the number of days, and got the same unexpected behaviour.

# What I expected to happen

Either 150 is a number, and the dialog closes and all is well, or my input is invalid and the dialog does not close, leaving all the red areas and text to show me what to change.

### Version Information

Syncthing Version: v0.14.14 Linux (64 bit) "Dysprosium Dragonfly"
OS Version: Linux 3.16.0-4-amd64 #1 SMP Debian 3.16.36-1+deb8u2 (2016-10-19) x86_64 GNU/Linux
Browser Version: Firefox 45.4.0
