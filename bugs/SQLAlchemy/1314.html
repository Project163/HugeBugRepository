Title

mypy plugin crashes on lambda

Description
### Describe the bug

The mypy plugin crashes when encountering a lambda in a column definition (_fixable by [URL]


### To Reproduce

```python
import uuid
from sqlalchemy import Column

class MyClass(Base):
    id = Column(String, default=lambda: uuid.uuid4(), primary_key=True)
```
