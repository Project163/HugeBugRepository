Title

The new SslHandler does not work with OpenSSLEngine from: org.apache.tomcat.jni.ssl

Description
```
WARNING: Unhandled exception, shutting down connection
javax.net.ssl.SSLException: Encrypted packet is oversize
at org.apache.tomcat.jni.ssl.OpenSSLEngine. (OpenSSLEngine.java:30)
...
at org.jboss.netty.channel.socket.nio.NioServerBoss.registerAcceptedChannel(NioServerBoss.java:134)
...
```

The following is the offending code in OpenSSLEngine:

```
// protect against protocol overflow attack vector
if (src.remaining() > MAX_ENCRYPTED_PACKET) {
    isInboundDone = true;
    isOutboundDone = true;
    engineClosed = true;
    shutdown();
    throw ENCRYPTED_PACKET_OVERSIZE;
}
```

OpenSSLEngine really should not raise an exception.  However, I'll apply some workaround so that SslHandler passes the sanitized input to OpenSSLEngine.
