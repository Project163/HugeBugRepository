Title

The error message "given name ... differs from filesystem name ..." does not help users to resolve the issue

Description
I am running Syncthing on Android (1.18.0) and on Arch Linux (1.17.1) to sync my smartphone's storage to my notebook. On my smartphone, I get a lot of messages like

```
2021-07-18 10:27:29 Puller (folder "Speicher" (t66yq-r9o4p), item "Music/Einzel/The King's Singers/This Is The King's Singers"): syncing: checking file to be replaced: given name "Music/Einzel/The King's Singers/This Is The King's Singers" differs from name in filesystem "Music/Einzel/The King's Singers/This Is the King's Singers"
```

I don't know what to do with this information. What is the "given name"? How can a file have a different name than its file system name? Can this error message be reformulated to something that tells me as a user how to resolve this?
