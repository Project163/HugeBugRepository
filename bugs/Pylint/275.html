Title

IntEnum non-iterable error

Description
### Steps to reproduce
```
from enum import IntEnum


class Color(IntEnum):
    RED = 1
... [Log Snipped] ...
for c in Color:
    print c
```

### Current behavior
`E: 10, 9: Non-iterable value Color is used in an iterating context (not-an-iterable)`

### Expected behavior
If I do the mixin explicitly, Pylint doesn't complain
```
...
class Color(int, Enum):
...
```
