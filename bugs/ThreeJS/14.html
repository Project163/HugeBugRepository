Title

Uninitialized GLSL variable in ShaderExtras.js

Description
The ShaderExtras.js file contains the following code:

```
"vec4 color, org, tmp, add;",
...
"add += color = org = texture2D( tDiffuse, uv );",
```

The 'add' variable isn't initialized before being used. This causes random behavior on some graphics drivers. It's affecting for instance ro.me and oos.moxiecode.com/js_webgl/xwing/.

The fix is to simply replace += with =.
