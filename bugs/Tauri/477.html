### Describe the bug

Invoke keys generated by [URL] (as introduced by [URL] can include the consecutive characters (`*/`), which when included in a comment, can cause the comment to close (with approximately 0.3% probability). 

[Image: image]
(https://github.com/tauri-apps/tauri/blob/ /core/tauri/scripts/ipc-protocol.js#L5-L13)

This means on some compilations of an app, IPC calls break entirely. 

### Reproduction

This is difficult to reproduce as it occurs on approximately 1 in every 300 compilations, but using a test invoke key of `*/` should do the trick. 

### Expected behavior

`ipc-protocol.js` should be parsed correctly and IPC requests should be possible.
