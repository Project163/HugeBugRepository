Title

Missing vertical bars in console tree

Description
## Overview

Follow up from #1524: the console tree lacks vertical bars when a report entry is issued in the context of a container, i.e. not a test context.

Current output:
```
text
╷
├─ JUnit Jupiter ✔
│  ├─ BarTest ✔
│  │     2018-08-05T09:09:25.959 log = `started class  BarTest`
... [Log Snipped] ...
│  │  │     2018-08-05T09:09:25.970 log = `started testBaz03(TestReporter, TestInfo)`
...
```

Expected output:
```
text
╷
├─ JUnit Jupiter ✔
│  ├─ BarTest ✔
│  │  │  2018-08-05T09:09:25.959 log = `started class  BarTest`
... [Log Snipped] ...
│  │  │     2018-08-05T09:09:25.970 log = `started testBaz03(TestReporter, TestInfo)`
...
```
