Title

[YCQL] Updating multiple fields in JSONB column causes write amplification

Description
### Description

Trying to update multiple fields of a JSONB column, causes the whole JSONB to be written as many times. In case, the JSONB has a large number of fields, and we update all the fields this causes huge write amplification. 

**Steps to reproduce:**

```
create table k.t(col1 int primary key, col2 jsonb);

insert into k.t (col1, col2) values ( 1, '{"a":1, "b":1, "c":1, "d":1}');

update k.t set col2->'a' = '3', col2->'b' = '3', col2->'c' = '3', col2->'d' = '3'  where col1 =1;

```
**WAL Content for above update:**

```
write_batch {
      write_pairs {
        key: "G\022\020H\200\000\000\001!!K\213"
        value: "2\000\000\000\000\000\000\000\001 \000\000\004\000\000\000\001\000\000\000\002\000\000\000\003\000\000\000\004`\000\000\010`\000\000\014`\000\000\020`\000\000\024abcd\200\000\000\003\200\000\000\001\200\000\000\001\200\000\000\001"
      }
... [Log Snipped] ...
      }
}
```

We updated 4 fields of the JSONB column. In the above write_pairs corresponding to the update, the last one contains the changes of all the updates. If we can avoid writing the changes for the first 3 updates, then we can avoid write/space amplification.
