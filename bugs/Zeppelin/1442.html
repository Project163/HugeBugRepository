 From above videos, you can see that in the Classic UI, word wrap is applied when editing an paragraph, but in the New UI it is not, which makes editing difficult. From a user’s perspective, the lack of word wrap can make editing both inconvenient and confusing, so this issue should be addressed. Also, in the case of  .md  files, word wrap is applied when the file is executed, but it is not applied when editing, which seems to cause an inconsistency.
