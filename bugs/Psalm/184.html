Title

Infer closure types when return type is given

Description
This is fine:

```php
$adder = function(int $i) {
  return function(int $j) use ($i) : int {
    return $i + $j;
  };
};

$a = $adder(1)(2); // typed to int
```

But this has a `MixedAssignment` issue:

```php
$adder = function(int $i) : callable {
  return function(int $j) use ($i) : int {
    return $i + $j;
  };
};

$a = $adder(1)(2); // typed to mixed
```

Psalm uses the explicit `callable` return type and doesn't bother inferring it.
