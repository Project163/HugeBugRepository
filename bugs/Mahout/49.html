Title

Add licenses for 3rd party jars to mahout binary release and remove additional unused dependencies.

Description
The binary release produced by   MAHOUT-215   includes some 3rd party jars that require licenses and other 3rd party jars (xpp3 + xstream) that are not required at all (eclipse core, a transitive dependency of hadoop, jfreechart a transitive dependency of watchmaker-swing).
Discussion
- Added exclusion for eclipse core to hadoop dependency in maven/pom.xml 
	 Added license for xstream, xpp3 in src/main/assembly, these get copied into the binary release lib directory. 
	 Moved servlet api to provided scope taste-web/pom.xml 
	 Added exclusion for jfreechart to watchmaker-swing examples/pom.xml 
 

 The only controversial thing here is the removal of the cglib dependency in examples/pom.xml, but I'm uncertain why that was in there in the first place. 

 It appears everything else included in the binary jar used and is under the Apache License.
