Title

vagrant box outdated didn't take provider into account

Description
### Vagrant version
$ vagrant -v
Vagrant 2.0.0

### Host operating system
$ cat /etc/debian_version 
9.1

### Guest operating system
(irrelevant)

### Vagrantfile
(irrelevant)

### Debug output

### Expected behavior
output should be
* 'debian/testing64' (v2017.02.10) is uptodate! 

### Actual behavior
* 'debian/testing64' is outdated! Current: 2017.02.10. Latest: 2017.03.21

### Steps to reproduce
1. $ vagrant box add debian/testing64 --provider lxc
2. $ vagrant box outdated --global

### References



This bug surfaces when there are more than 1 variants of a certain box (sama name but different provider), each has different version:
$ vagrant box list | grep testing
debian/testing64                (lxc, 2017.02.10)

In this case provider lxc has version 2017.02.10 while provider virtualbox has version 2017.03.21
