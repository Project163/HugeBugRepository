Title

Configuration file changes are lost if rclone is running

Description
rclone v1.33

ubuntu server, 14.04

amazon

When modifying .rclone.conf while existing rclone process is running any changes are lost as running process rewrites configuration file back to disk (updates token?).

This is especially disastrous if user has added encrypted remote and started transferring files to it as keys are lost.
