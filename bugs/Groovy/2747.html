Title

Default methods on closures coerced to interfaces don't work

Description
Seems like the default method doesn't get called, and a stub noop impl is used. 

  
  import  java.util.function.Consumer

def consume(Consumer< String > consumer) {
  consumer
    .andThen({ println  "2"  })
    .accept( "foo" )
}

 // Works
 consume( new  Consumer< String >() { void accept( String  s) { println  "1"  } })
 
 // Fails, andThen() returns  null 
 consume({ println  "1"  })
Discussion
- Raising the priority to blocker as it's a blocking problem for Ratpack.
- This should work now. It is actually quite difficult to call an interface default method properly from a proxy
