Title

set_index breaks with multi keys but one empty

Description
Migrated from StackOverflow: [URL]

```
df = DataFrame([
    dict(a=1, p=0), 
    dict(a=2, m=10), 
    dict(a=3, m=11, p=20), 
    dict(a=4, m=12, p=21)
], columns=('a', 'm', 'p', 'x'))
```

```
     a     m    p     x
  0  1   NaN    0   NaN
  1  2    10  NaN   NaN
  2  3    11   20   NaN
  3  4    12   21   NaN
```

```
# single column index on an empty column works
df.set_index(['x'])
# two-columns index on non-empty columns works
df.set_index(['a', 'm'])
df.set_index(['a', 'p'])
... [Log Snipped] ...
# but two-columns index including an empty column fails
df.set_index(['a', 'x'])
```
