Title

rclone crashes if run without any arguments (ie., just `./rclone`)

Description
#### What is the problem you are having with rclone?

Building rclone from git commit  , and running it with just `./rclone`, it crashes with the below error:

```
➜  ~/dev/rclone git:(test) ./rclone
panic: runtime error: index out of range [1] with length 1

goroutine 1 [running]:
github.com/rclone/rclone/cmd.initConfig()
... [Log Snipped] ...
main.main()
        /home/janne/dev/rclone/rclone.go:14 +0xf
```

The crash happens in `cmd/cmd.go`:

```
	// Start the metrics server if configured and not running the "rc" command
	if os.Args[1] != "rc" {
		_, err = rcserver.MetricsStart(ctx, &rc.Opt)
		if err != nil {
			fs.Fatalf(nil, "Failed to start metrics server: %v", err)
		}
	}
```

I think this is a regression caused by commit  .
