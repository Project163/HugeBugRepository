Title

Adding plugin to project fails to install NPM dependency

Description
# Problem
`pnpm tauri add process --verbose`

```
    Info [tauri_cli::helpers::cargo] Installing Cargo dependency "tauri-plugin-process"...
    Info [tauri_cli::helpers::npm] Installing NPM dependency "@tauri-apps/plugin-process@2.0.0-rc"...
    Error [tauri_cli_node] Failed to install NPM dependency
 ELIFECYCLE  Command failed with exit code 1.
```

# Reproduce
The issue is reproducable on a dummy project: 
```
pnpm create tauri-app --rc
cd tauri-app
npm install
npm run tauri dev
```

# Hypothesis
The script attempts to install `@tauri-apps/plugin-process@2.0.0-rc`. Version `2.0.0-rc` doesn't exist, but `2.0.0-rc.0` does ([Link: npm versions]).

- `pnpm tauri add process@2.0.0-rc.0` works. But the default command is still expected to successfully install the latest or smth.
