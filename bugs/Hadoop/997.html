Title

FsShell -put/copyFromLocal should support Windows local path

Description
In current trunk code, running 'hadoop fs -put c:\windows\path /hdfs/path' will lead to an error  put: unexpected URISyntaxException . This is a regression to the 1.0 fs shell commands. FsShell put and copyFromLocal should support Windows local path formats as localSrc argument to the two commands.
