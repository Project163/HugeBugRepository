Title

Since 2.11.0 TrueHD videos stuck and playback time goes backwards

Description
Since 2.11.0 library version videos with TrueHD audio track - stuck, when audio track is selected.
Also, playback time goes backwards.

The bug was reproduced on Nvidia Shield TV device and tested with different video samples.
There is no such issue on all previous library versions, up-to 2.10.8.
Also, no such issue on Sony Bravia TV, as it does not support TrueHD decoding.
