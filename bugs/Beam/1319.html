Title

Python doesn't shut down Flink job server properly

Description
Using the new Python FlinkRunner  [1] , a new job server is created and the job succeeds, but seemingly not being shut down properly when the Python command exits. Specifically, the java -jar command that started the job server is still running in the background, eating up memory. 

 Relevant args: 

 python ... 
 --runner FlinkRunner \  
 --flink_job_server_jar $FLINK_JOB_SERVER_JAR ...
