Title

Page layout is not "centered" by default in multipage apps

Description
### Checklist

- [Link: X] I have searched the [existing issues] for similar issues.
- [X] I added a very descriptive title to this issue.
- [X] I have provided sufficient information below to help reproduce this issue.

### Summary

Page layout is not "centered" by default in multipage apps, as would be expected by the default value in [Link: st.set_page_config]. 

Instead, it inherits the layout from the previously visited page.

I would call it a bug, but could also hear that this is expected because no explicit call to st.set_page_config was made... 

Example:
[Image: CleanShot 2023-03-06 at 15 48 29]

### Reproducible Code Example

```Python
#streamlit_app.py
import streamlit as st

st.write(st.__version__)
st.title("Hello world")
```

```
#pages/one.py
import streamlit as st

st.set_page_config(layout="wide")
st.title("Wide layout")
```

```
#pages/two.py
import streamlit as st

st.set_page_config(layout="centered")
st.title("Centered layout")
```
```

### Expected Behavior

The `streamlit_app` page should have its layout = `"centered"`, as is meant to be the default for `st.set_page_config()`.

### Current Behavior

The `streamlit_app` page inherits its layout from the previously visited page

- K just read through this again and I think I agree with y'all. So basically the behavior should be:

- In a single-page app, don't reset the layout to avoid flickering (I assume this is what the original comment in App.tsx means?). 
- In a multipage app and while viewing a single page, don't reset the layout (same as in a single-page app). 
- In a multipage app with v2 where `set_page_config(..., layout=...)` is called in the entrypoint file, don't reset the layout (same as in a single-page app). 
- In a multipage app (v1 or v2) when switching from one page to another and if `set_page_config(layout=...)` is called inside of the page, reset the layout to the default value (centered) and update it if `set_page_config` is called again. 

Does that sound about right?
