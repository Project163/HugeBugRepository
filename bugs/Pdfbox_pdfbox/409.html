Title

Support MMType1 (Multiple Master) Fonts

Description
MMType1 Fonts are not supported. They are described on p.416 of the 1.7 spec. I attach a sample file.
Discussion
- This seems like it should be fairly easy to add as no changes are needed to any of the Type 1 parsing code, see PDF 32000 p257: 

 
 If the font program for a multiple master font instance is embedded in the PDF file, it shall be an ordinary Type  1 font program, not a multiple master font program. This font program is called a snapshot of the multiple master font instance that incorporates the chosen values of the design coordinates.
- I know, but it sounds too good to be true. So MMType1 fonts are only different when they are not embedded? (Which is unlikely because it would mean that the recipient of the file must have the font) 

 So either PDFontFactory.createFont() should return a PDType1Font, or the PDMMType1Font class should extend PDMMType1Font instead of PDSimpleFont (which I'd prefer). 

 I tried both, and in both cases I get excellent images.
