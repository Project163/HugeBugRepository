Title

Exclusion of log4j Reactive Messaging Kafka

Description
The extension:

```
     
       io.quarkus 
       quarkus-smallrye-reactive-messaging-kafka 
     
```

has a transitive dependency from log4j.

This print a WARNING with quarkus:dev, and prevent logging in @QuarkusTest.

I needed to exclude it:

```
       
         
           log4j 
           log4j 
         
       
```

to let tests log again correctly.
