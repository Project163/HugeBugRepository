Title

better 'this' type checking

Description
/** @constructor */
function F() {}
F.prototype.bar = function() { this.baz(); };
F.prototype.baz = function() { };

/** @constructor */
function G() {}
G.prototype.bar = F.prototype.bar;

We should notice that "F.prototype.bar" and "G.prototype.bar" have different "this" types, and emit a warning.
Discussion
- Relatedly, new: types in @return should be checked against what's really returned:

Below, constructorFactory returns a constuctor that doesn't match the
declared return type, yet no warning ensues:

/**
 * @typedef {{
 *   foo: function()
 * }}
 */
var Type;

/**
