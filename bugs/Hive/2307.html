Title

BINARY columns use BytesWritable::getBytes() without ::getLength()

Description
The Text conversion for BINARY columns does  

  
      case  BINARY:
        t.set(((BinaryObjectInspector) inputOI).getPrimitiveWritableObject(input).getBytes());
         return  t;
 
  

 This omission was noticed while investigating a different String related bug, in a list of functions which call getBytes() without calling getSize/getLength().
