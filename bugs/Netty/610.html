I use the handshake with client authentication required as a way for my company proxies to connect to each other. The main connection stays encrypted (administrative connection), but the other bulk data like file sending and specific messages go over a second non encrypted connection. Initially it starts out encrypted as my way of authenticating the connection and exchanging connection data to confirm the new connections legitimacy and tying it to a existing session, each proxy has its own private key the SSL is broken down once the connection is good for those bulk data I do not need secured. I was designing a inner connected Proxy system to help mitigate DDOS/DOS and thus proxies talk to each other and replicate resources for the Massively Multiplayer game.
