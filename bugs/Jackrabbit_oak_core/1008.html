Title

The query engine should not return hidden nodes

Description
In   OAK-2059   we found that indexes can contain hidden nodes. This is now solved, but existing indexes could still contain them (until the index is re-built). 

 The query engine should log a warning (just one per query) for such cases, and not return the nodes to the caller.
