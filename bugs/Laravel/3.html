Title

[4.2] Bug in named resource within domain grouping

Description
Please have a look at the routing. If you define a resource named routing within a group and use a domain there with a wildcard. The route names getting wrong. There is one "." too much in the route names. Instead of having api.test.create, you get api..test.create

Example code that reproduces this bug:

``` php
Route::group(['domain' => '{user}.domain.tld'], function() {
    Route::resource('user', 'UsersController', ['as' => 'test']);
});
```

With that route above you get something like

```
test..user.index
test..user.create
test..user.store
...
```
