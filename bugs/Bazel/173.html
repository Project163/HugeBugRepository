Title

Crash when switching between git_repository and local_repository

Description
In 0.2.0, switching a local git_repository to a local_repository, and then back to a git_repository causes Bazel to crash with a "Invalid BUILD file name for package" error. After the crash, "bazel clean --expunge" is needed to return to a working state.

(This is an improvement over 0.1.5, where simply switching a local_repository to a git_repository will trigger the same error.)
