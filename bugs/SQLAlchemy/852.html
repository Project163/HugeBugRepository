Title

GenericFunction register is case-sensitive

Description
The `GenericFunction` instances are registered in `sqlalchemy.sql.functions._register`, which is a `collections.defaultdict(dict)`. The `sqlalchemy.sql.functions.func()` function uses the `get()` method to retrieved registered functions, which means that the search is case-sensitive.

This case-sensitivity can have some drawbacks, e.g.:

```
python
from sqlalchemy import func
from sqlalchemy.sql.functions import GenericFunction
from sqlalchemy.types import Text, Integer

... [Log Snipped] ...
print(func.CaseSensitiveFunc().type, func.CaseInsensitiveFunc().type)  # Out: (Text(), Integer())
print(func.CaSeSeNsItIveFuNc().type, func.CaSeInSeNsItIveFuNc().type)  # Out: (NullType(), NullType())
```
In this example, the `GenericFunction(s)` are not retrieved by the `sqlalchemy.sql.functions.func()` function when their letter case is not exactly the same as in their definitions. So in this case, they are just sent to the DBMS as they are and the DBMS silently interpret them without considering the letter case, which can lead to some weird bugs (see here for example: [URL]

Some simple changes in `sqlalchemy.sql.functions` could add the possibility to register a `GenericFunction` without being case-sensitive. In this case we would have the following:

```
python
from sqlalchemy import func
from sqlalchemy.sql.functions import GenericFunction
from sqlalchemy.types import Text, Integer

... [Log Snipped] ...
print(func.CaseSensitiveFunc().type, func.CaseInsensitiveFunc().type)  # Out: (Text(), Integer())
print(func.CaSeSeNsItIveFuNc().type, func.CaSeInSeNsItIveFuNc().type)  # Out: (NullType(), Integer())
```

Here the case-insensitive function is retrieved by `sqlalchemy.sql.functions.func()`.
