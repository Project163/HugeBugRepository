Title

Infinite loop in GeolocationContextMapping

Description
The parsing logic has the following loop that never terminates:

```
while (token != Token.END_ARRAY) {
  result.add(GeoUtils.parseGeoPoint(parser).geohash());
}
```

It misses a `token = parser.nextToken();` between iterations.
