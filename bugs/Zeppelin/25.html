Title

SparkSQL returning java.lang.NumberFormatException: For input string: "5s"

Description
#When I run this from Zeppelin: 

 case class Health (year:  String, state: String, category:String, funding_src1: String, funding_scr2: String, spending: Integer) 
val health = dataset.map(k=>k.split(",")).map( 
    k => Health(k(0),k(1),k(2),k(3), k(4), k(5).toInt) 
    ) 

 health.setName("health_table") 

 %sql 
select state, sum(spending)/1000 SpendinginBillions  
from health_table  
group by state  
order by SpendinginBillions desc 

 #I get the following error: 

 java.lang.NumberFormatException: For input string: "5s"
Discussion
- Humm, I have the feeling that the culprit is here: 

  
 k(5).toInt
 
  

  Are you sure that in your data set , the  6th column  is ALWAYS a number ?
- I think it's correct because "5s" is not a number. As mentioned above, if k(5) is not a number, NFE occurs. What do you think the problem is?
- I was getting the same error when trying to run SparkSQL jobs. My environment consisted of HDP 2.2.4 with Spark 1.3.1. I found that, by default, hive-site.xml has a problematic value that causes this issue: 

  
 [root@sandbox conf]# grep -B 1 5s *
hive-site.xml-      <name>hive.metastore.client.connect.retry.delay</name>
hive-site.xml:      <value>5s</value>
 
  

 Simply changing this value from '5s' to '5' resolved the issue. I'm not sure if this affects other platforms/versions as well, but it turned out to be the culprit in my case. 

 Best, 
Ara
