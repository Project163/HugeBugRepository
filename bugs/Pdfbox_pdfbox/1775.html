Discussion
- The cause is this: 
  
 /Title (ILIANE160721142(0A7011106.pdf)
 
  
 overwriting the "(" allows PDFBox to handle the file. The code in BaseParser has this: 
  
              else   if ( ch == openBrace )
            {
                braces++;
                out.write(ch);
            }
 
  
 The specification mentions 
 
 Balanced pairs of parentheses within a string require no special treatment.  
 Adobe is able to display the file, but the /Info object is lost. Maybe they give up parsing when the offset boundary of the object is passed.
