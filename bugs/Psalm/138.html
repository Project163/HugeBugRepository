Title

False positive for PossiblyNullArrayOffset

Description
```php
if (isset($this->someProperty[$variable][$otherVariable])) {
    return $object->withProperty((string)$this->someProperty[$variable][$otherVariable]);
}
```

In a psalm run, this yields a `PossiblyNullArrayOffset` on the second line.
Discussion
- Reproducible with:

```php
$arr = [[1, 2, 3], null, [1, 2, 3], null];

$b = 2;
$c = 0;
if (isset($arr[$b][$c])) {
  echo $arr[$b][$c];
}
```

The fix is to allow array variables with variable offsets into the list of known types, and to invalidate when any of the variable offsets is reassigned, or falls out of scope.
- Thanks! Fixing this means Psalm can find issues like [URL] now.
