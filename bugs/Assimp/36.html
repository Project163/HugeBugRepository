Title

[glTF 2] KHR_materials_pbrSpecularGlossiness glossinessFactor in wrong object

Description
Currently the glossinessFactor in glTF 2 PBR materials using the `KHR_materials_pbrSpecularGlossiness` extension is being written directly to the main material object instead of the `extensions.KHR_materials_pbrSpecularGlossiness` object. So you get this:

```
{
    "name": "test",
    "pbrMetallicRoughness": {
        "baseColorFactor": [ 1.0, 1.0, 1.0, 0.0 ],
        "metallicFactor": 0.0
... [Log Snipped] ...
    }
}
```

Instead of this:

```
{
    "name": "test",
    "pbrMetallicRoughness": {
        "baseColorFactor": [ 1.0, 1.0, 1.0, 0.0 ],
        "metallicFactor": 0.0
... [Log Snipped] ...
    }
}
```

Looks like a simple fix, I will submit a pull request shortly.
