Title

BlobServer isn't associated with the correct bind-host

Description
In a flink cluster, if the JobManager bind-host is configured with an address, this creates a mismatch where clients expect to connect to BlobServer at same address, but it's actually bound to localhost. The BlobServer becomes unreachable to clients, causing "Could not connect to BlobServer" errors. 

 This can be reproduced when uploading a JAR file to the cluster for UDF registration, and configuring the JobManager bind-host to an external address.
