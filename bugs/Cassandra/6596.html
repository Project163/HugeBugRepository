Discussion
- By the way ... for exactly what reason are we attaching that stopping transformation to the stack again here? (1). Why don't we just do (same logic is done in applyToRow already). 

  
 
        @Override
         protected  UnfilteredRowIterator applyToPartition(UnfilteredRowIterator partition)
        {
            maybeCancel();
             return  partition;
        }
 
  

 I just don't see the reason why we are trying to attach that all over again. We should just check if we should cancel. 

 Also, currently, applyToPartition will never return null because we are returning iterator again by applying that stopping transformation to that iterator, so the logic here (2) will see next as non-null too and it will continue that loop till the end with a side effect of adding that transformation at the end of the stack (which actually fails, because re-attaching is not possible).
