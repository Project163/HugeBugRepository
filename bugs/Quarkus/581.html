Title

Forwarding to JAX-RS from ServletFilter returns 404

Description
**Describe the bug**
When a servlet filter tries to forward a request to a valid JAX-RS (Resteasy) endpoint, undertow cannot locate the endpoint and returns a 404 not found

**Expected behavior**
Undertow should be able to forward the request successfully as JAX-RS should just be another endpoint on the same server and accessible with a forward.

**Actual behavior**
404 not found is returned


**To Reproduce**
git clone [URL] cd quarkus-forward; mvn clean install

**Configuration**
```
Empty properties file
```
