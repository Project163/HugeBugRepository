Title

Do not add empty first and last lines in the license header for certain families

Description
For families with asymmetrical comment formats like C and SGML it makes sense to have specially crafted first and last lines, simply because the format demands them. For other families it makes no sense because they are just empty (commented out) lines, so they should be removed.
