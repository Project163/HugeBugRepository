Discussion
- I think the problem is that we have a background task running which recreates the parent nodes. The background task originates from a  NodeCache  which we use for the  ZooKeeperLeaderRetrievalService . I think it can happen that such a background task won't be immediately executed which can lead to the following interleaving: 

 1.  ZooKeeperHaServices#deleteOwndZNode()  
2.  background-task  (recreate the parent zNodes) 
3.  ZooKeeperHaServices#closeInternal()
