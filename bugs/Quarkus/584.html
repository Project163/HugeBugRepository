Title

.env file at project root replaced with symbolic link pointing back to the same location

Description
**Describe the bug**
When running Quarkus with `mvn quarkus:dev`, `.env` file at project root gets replace with symbolic link pointing to that same location. The behaviour seems to be related to having `workingDir`set in pom.xml.

**Expected behavior**
While running Quarkus in dev mode `.env` should be read from project root.

**Actual behavior**
`.env` file at project root gets replaced with symbolic link pointing to the same location. 

**To Reproduce**
Steps to reproduce the behavior:
1. Clone example from: [URL]
2. Observer that you have `.env` file at the root
3. Run `mvnw quarkus:dev`
4. Observer how `.env` file is replaced with symbolic link pointing to it
