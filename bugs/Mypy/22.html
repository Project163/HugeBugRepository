Title

Modules dict has invalid __main__ module when using -m cmd line option

Description
If a module is run using the -m command line option, the `__main__` module in the sys.modules dict refers to the automatically generated 'driver' module, not the actual module being run. This breaks some Python std library test suites, for example.
