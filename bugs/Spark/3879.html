Title

Hive settings in hive-site.xml may be overridden by Hive's default values

Description
When we create the HiveConf for metastore client, we use a Hadoop Conf as the base, which may contain Hive settings in hive-site.xml ( [URL] However, HiveConf's initialize function basically ignores the base Hadoop Conf and always its default values (i.e. settings with non-null default values) as the base ( [URL] So, even a user put  javax.jdo.option.ConnectionURL  in hive-site.xml, it is not used and Hive will use its default, which is  jdbc:derby:;databaseName=metastore_db;create=true .
Discussion
- This issue only appear if the value of  spark.sql.hive.metastore.jars  is not builtin because if  spark.sql.hive.metastore.jars  is builtin, Hive can find the hive-site.xml and make it a overlay of the HiveConf.
