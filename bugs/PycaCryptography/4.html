Title

Elliptic Curve loading from PEM files does not include curve type

Description
Loading Elliptic Curve public and private key files from PEM files in the PEM Serialization Backend results in a curve type of None, the easiest argument to initialise the objects. Most functionality remains, but it could be possible to retrieve known curve types from PEM private key parameters given in the file. I don't think that the same can be done for public keys, as they are just a point on a curve, but I may be wrong.
