Title

hadoop-env.cmd sets HADOOP_CLIENT_OPTS with a max heap size that is too small.

Description
HADOOP-9211   increased the default max heap size set by hadoop-env.sh to 512m.  The same change needs to be applied to hadoop-env.cmd for Windows.
Discussion
- Patch attached. Change the HADOOP_CLIENT_OPTS to use 512m as heap size, aligned with   HADOOP-9211  .
