Title

Race in WAL segment leading to ClosedChannelException

Description
In current flushOrWait() code we acquire writtenBytes before we try to flush. If flush fails, we wait for written be equal to expWritten. 
When a segment is being closed, this leads to one thread returning from flushOrWait early because written is updated, but expWritten does not match the last record position.
