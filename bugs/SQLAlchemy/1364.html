- Hi,

I think this goes into the realm of expected behaviour.

You are passing an int instead of a string and the db does not like that. Pass a string and it will work correctly.
If you want to pass strings or int, you can probably create a TypeDecorator that does the string conversion
- On second look it seems that pyodbc is trying to do the opposite, so string to int, even if the type is a string.
