Title

x-go-type for a custom type in models/ "Test API" ... [Log Snipped] ... x-go-type: type: MyType ``` ## Steps to reproduce Using v0.25.0: ``` swagger generate server -f api.yaml ``` ## Environment swagger version: 0.25.0 go version: 1.15 OS: Linux x86_64

Description
## Problem statement

Before #2340 I was able to declare a type in my spec that was already present in `models/` (= not auto-generated). Here `MyType` used in a `Zzz` object type:

```
type Zzz struct {
        // meta
        Meta MyType `json:"meta,omitempty"`
}
```

Now it generates bad go code as the "import.package" is empty (then gofmt glues field name and the type together):

```
type Zzz struct {
        // meta
        Meta.MyType `json:"meta,omitempty"`
}
```

Is there a way to overcome this behavior? (excluding the move of custom types outside models/, of course)
