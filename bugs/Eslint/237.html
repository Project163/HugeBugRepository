Title

let/const scope is calculated incorrectly

Description
The following valid code:

``` js
/* global a: false */
if (a) {
    let b = 2;
} else {
    let b = 3;
}
```

triggers the `b is already defined` error in the `no-redeclare` rule.
Discussion
- This is important to me since I write most of my code in the `const`/`let` style thanks to awesome @olov's [Link: defs] project but still has to sometimes write sth using `var` so I cannot just enable `block-scoped-var`.
- I think you may not understand the `block-scoped-var` rule. When you do use `var`, just place it at function or program level and you're good. escope should treat `const`/`let` like `var`, and `block-scoped-var` will ensure they're used only within their respective blocks.
