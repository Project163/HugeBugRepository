Title

data-uri and filepaths

Description
Currently the new data-uri function (when called from command line) loads files relative to the working directory, not the less file.

I think this is a bit counterintuitive to how @imports and relative urls work, and would like it to either load relative to the less file or at least use the search paths. 

From what I've gathered by reading the source, that would mean assigning the filename/paths in tree.parseEnv and use this information in data-uri.

What do you think?
