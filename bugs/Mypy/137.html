Title

Name not defined errors accessing functions defined later in a function

Description
This:

```
def test():
    def foo():
        return bar()

    def bar():
        return "bar"
```

Throws:

```
/home/tabbott/foo.py: note: In function "foo":
/home/tabbott/foo.py:6: error: Name 'bar' is not defined
```
Discussion
- A potential workaround is to change the order of nested functions, assuming that they aren't mutually recursive.

There should be a new pass when semantically analyzing function bodies. The first pass would analyze the body of the function but ignore the bodies of any nested functions. The second pass would only analyze bodies of nested functions. That way all the names defined in the enclosing scope would be defined, instead of just those that textually precede a function definition. These passes can be specific to each function instead of being file-level.
- I'm going to give this a go.
