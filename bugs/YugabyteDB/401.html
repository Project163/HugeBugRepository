Title

[YCQL] Fatal when using order by for non-existent column with index scan.

Description
### Example:

#### Set up a table with an index.
```
create keyspace sample;
use sample;
create table test(a int primary key, b int, c int) with transactions = {'enabled' : true};
create index on test(b);
```
#### Sequential (primary key) select works as expected
```
select * from test where a = 3 order by non_existent_column;
```
```

```
