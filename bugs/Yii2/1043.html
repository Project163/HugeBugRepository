Title

The Logger is impossible to configure

Description
If `YII_DEBUG` is `true`, the `yii2/log/Logger.php` is impossible to configure.

1. In `Application::bootstrap()` `Yii::debug()` is called and is creating a default `Logger` w/o settings. Then it writes it into `BaseYii::$_logger`. 
2. Next, Logger isn't overwritten and it's used everywhere.

[Image: image]


### What steps will reproduce the problem?

You have to configure a log inside an application's configuration and set `'profilingAware' => true,`
[Image: image]


### What is the expected result?
If we configure the Logger, it will be used in the entire application.


### What do you get instead?
Inside `yii2/log/Dispatcher.php`, in the moment of call `setLogger`, you have to add `Yii::setLogger($value);`.
[Image: image]
