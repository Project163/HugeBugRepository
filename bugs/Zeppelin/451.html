Title

JDBC Intrepreter throws error while the interpreter is downloading dependencies

Description
Once i update JDBC interpreter settings for the first time, dependencies for the interpreter are downloaded in background. If we execute the notebook during that time, paragraph throws error, instead of waiting for the dependencies to download to complete and continue the execution of the paragraph.
