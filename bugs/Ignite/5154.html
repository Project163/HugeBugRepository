Title

Prevent checkpoint buffer overflow in case of the speed-based throttling

Description
When speed-based throttling is turned on, in the very beginning of a checkpoint, there is a short period of time when checkpoint progress information is not yet available. Current implementation does not protect the Checkpoint Buffer during that period. If there is really high load of writes hitting the CP Buffer, it can be overflowed.
