Title

Fix username output when OIDC is enabled

Description
SecurityUtils.getPrincipal() should not use toString() wen principal implements java.security.Principal. 

 Our Principal implementation contains user's roles, permissions and tokens. All of this information is part of the toString() output, and is sent to Zeppelin's client via websocket. It appears in the web browser when running a paragraph in a notebook. 

 When Principal implements java.security.Principal, it would be better to use getName() instead of toString().
