Title

Incorrectly generated Marshaller causes unlimited recursive Marshal calls

Description
## Problem statement

When defining a model with `additionalProperties`, the generated code causes unlimited recursive Marshal calls which ends up stack overflow.
## Swagger specification

```
yaml
swagger: '2.0'
definitions:
  GenericResource:
generic resource
... [Log Snipped] ...
    additionalProperties:
      type: object
```
## Steps to reproduce

The generated model is:

```
go
...

// MarshalJSON marshals this object with additional properties into a JSON object
func (m GenericResource) MarshalJSON() ([]byte, error) {
... [Log Snipped] ...
    }
...
```

The line `props, err := json.Marshal(m)` is obviously wrong as `json.Marshal` will again call into this method.
Discussion
- Similarly, the generated `UnmarshalJSON` is also wrong.
- Unmarshal is not fixed
