Title

Settings passed via sf::ContextSettings not used in glXChooseFBConfig

Description
This results in problems such as not having a stencil buffer even though there are FBConfigs with stencil buffer, and even though a valid value is set in sf::ContextSettings.

As far as I can work out the offending line is nr 242 in SFML/src/SFML/Window/Linux/GlxContext.cpp

The call to glXChooseFBConfig should pass an attrib_list based on the values set in the sf::ContextSettings.
