- To clarify, this is true whether you're capturing the chunks with either the `renderChunk` hook or `generateBundle`.
- The bug is [Link: here], specifically with this line:

```js
const imports = chunk.getImportIds();
```

`chunk.getImportIds()` looks like this:

```js
getImportIds(): string[] {
  return this.dependencies.map(module => module.id);
}
```

`chunk.dependencies` is an array of `ExternalModule | Chunk`. In other words, we're setting `chunk.id` in the same loop that *depends* on `chunk.id` for imported chunks having already been set, but the chunks aren't necessarily ordered correctly for that to work.

It's much easier to fix than I feared. Working on a PR now.
