Title

SQLSTATE[01000]: Warning: 1265 Data truncated for column 'date_field' at row 1

Description
- Laravel Version: 8.61.0
- PHP Version: 8.0.10
- Database Driver & Version: MySQL 8 (strict mode)

### Description:

Colleagues, when working in strict mode with a database, we get an error, because after the implementation of this functionality #38720, the date fields are saved to the database in the format specified in the grammar, ignoring the caster parameters, i.e. in case of mysql format "Y-m-d H:i:s", although the database for the date type expects "Y-m-d".

In version 8.60, the format coincided with the format specified in the caste.
