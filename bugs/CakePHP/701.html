Title

LocaleSelectorFilter shouldn't set default locale

Description
Hello!
Recently I had some problems with the _Translate behavior_ in a new app I'm developing using CakePHP 3.0. The prob was that translations queries were never executed because of this two reasons:
- [Link: the comparison between the current locale and the default locale at the beginning of the _beforeFind_].  
- I loaded the _LocaleSelectorFilter_ in my bootstrap, and this filter [Link: sets the default locale to the one in the HTTP header].

So, in this case, current locale and default locale will never differ. If you don't call explicitly `I18n:locale('whatever')`, or `$model->local('whatever')` in your code, i18n tables will never be accessed.

My suggestion is to change [Link: this line] to be `I18n:locale($locale)`. Actually, when you make a request with an accept language header, it shouldn't affect the default locale that (AFAIK) should be a static configuration parameter.

Thanks in advance and congrats for your good work!
