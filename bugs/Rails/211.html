Title

Can't rescue_from ActiveRecord::ConnectionTimeoutError in production

Description
### Steps to reproduce

* Create a new rails app ( )
* In the application controller add:
```ruby
  rescue_from ActiveRecord::ConnectionTimeoutError do
    Rails.logger.warn "AR connection timeout"
  end
```
* Launch rails in `production` mode.
* See the app failing

**Quick notes:**
* This was working in Rails 5.2.x
* This work in `development`

### Expected behavior

Should rescue the exception

### Actual behavior

```
` ': uninitialized constant ActiveRecord::ConnectionTimeoutError (NameError)
Did you mean?  ActiveRecord::ConnectionAdapters
```
