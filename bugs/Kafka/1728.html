Title

TaskManager should be type aware

Description
Currently, in  TaskManager  we don't distinguish between  StreamTask  and  StandbyTask . However, both have quite different live cycles and thus we should try do distinguish between both. 

 This also affect interface  Task  that should only contain method we need for both type of tasks, but not contain sub type specific methods.
