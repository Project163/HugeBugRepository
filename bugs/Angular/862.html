Title

ivy providers don't work with config object passed to forRoot

Description
# 🐞 bug report

### Affected Package
 
@angular/compiler

### Is this a regression?

 
No, it's ivy only


### Description
I tried out ivy on my project and the only error I got was 
```
ERROR in Invalid map access: [] dot eventTitleFormatter
```

The issue is caused by this line: [URL]

Where I pass a config object of providers
```

  static forRoot(
    dateAdapter: Provider,
    config: CalendarModuleConfig = {}
  ): ModuleWithProviders {
... [Log Snipped] ...
  }
}
```

Removing it and the app compiled and everything else worked great, very impressive to see the commitment to backwards compatibility 🎉
