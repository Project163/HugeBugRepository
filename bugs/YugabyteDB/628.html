Title

[Materialized Views Regression] Drop Materailized view fails in databases with PITR schedule setup

Description
Jira Link: [Link: [DB-331]]
### Description

CC: @vkulichenko , @m-iancu , @bmatican 

This issue is observed in branch  ** -b131** onwards
This issue can also be reproduced in master.

Steps:
- Create a database
- Create a snapshot schedule on the database
- Create a table
- Insert rows
- Create a materialized view
- Insert more rows
- Refresh the materialized view
- Drop the materialized view
**Issue:**
The drop command fails-
```
no_pitr=# drop materialized view mv_orders ;
ERROR:  Service unavailable: The object ' .mv_orders' is not running: OBJECT_NOT_FOUND
```
