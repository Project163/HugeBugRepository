Discussion
- One observation: the samples contain a lot of equal values. 

 The KS test statistic is implemented using Arrays.binarySearch, but this does not specify which index will be found when looking for a given value in a sorted array. 
E.g. if you have samples  [0, 0, 0, 0, 0, 1]  and you search for 0, you might get an index in the range  [0, 4] . As far as I understand the KS statistic, it is an empirical distribution function which calculates the cumulative density based on how many values are less or equal than the given observation, which is not equal to the result returned by Arrays.binarySearch.
- Yes, this is a bug.  Arrays.binarySearch should not have been used here.
