Title

hiddenField for radio input not set correctly

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 2.9.7 (also present in 2.10.0)
* Platform and Target: All

### What you did
echo $this->Form->input('some_name', array('type' => 'radio', 'options' => $options, 'hiddenField' => 'some value');

### What happened
The hidden field is not rendered with the value "some value" as documented here: [URL]

### What you expected to happen
Have the hidden field's value attribute set with the provided value.
