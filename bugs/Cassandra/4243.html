Title

Don't require HEAP_NEW_SIZE to be set when using G1

Description
Although cassandra-env.sh doesn't set -Xmn (unless set in jvm.options) when using G1GC, it still requires that you set HEAP_NEW_SIZE and MAX_HEAP_SIZE together, and won't start until you do. Since we ignore that setting if you're using G1, we shouldn't require that the user set it.
