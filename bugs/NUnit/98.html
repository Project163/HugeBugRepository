Title

"No arguments were provided" with Theory and Values combination

Description
Having such test definition I recieve "No arguments were provided" error:

```
[Theory]
public void ShouldGenerateForAnyTimePeriod(
   bool isCoApplicant,
   SomeEnum timePeriodInputType,
   [Values(0, 2)] Int32 years,
... [Log Snipped] ...
...
}
```

If I remove first two arguments or last two arguments NUnit behaves as expected. I tried to declare Datapoints, but this did not change the result:

```
[Datapoints]
public Boolean[] bools = { true, false };

[Datapoints]
public TimePeriodInputType[] timePeriodInputTypes = { TimePeriodInputType.FromTo, TimePeriodInputType.YearsMonths };
```

NUnit v3.0, test runner v3.
Discussion
- NUnit v3 console returns error message:

[Image: image]

NUnit v2.6.4 executed the test
[Image: image]

source of test:

```
c#
        [Theory]
        public void ShouldGenerateForAnyTimePeriod(
            bool isCoApplicant,
            TimePeriodInputType timePeriodInputType,
... [Log Snipped] ...
            Console.WriteLine("years={0}, months={1}", years, months);
        }
```
- This is a much more general problem than the example initially suggested. NUnit 2.6.4 allows a Theory to combine data provided by a parameter attribute with data supplied by a datapoint. NUnit 3.0 is not allowing that - the data must be entirely supplied by attributes or entirely by datapoints.

To complicate things, when I initially wrote a test for this, it passed! Turns out that the running of tests at the second level using TestBuilder uses a slightly different implementation. So this issue is not seen by the unit tests at all!
