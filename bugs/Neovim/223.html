Title

Occasional segmentation fault triggered by attempting completion

Description
### Neovim Version

v0.6.0-dev+84-gac5139eae

### Operating system/version:

Fedora 34

### Terminal name/version:

tmux 3.1c

### TERM environment variable

tmux-256color

### Installation

copr (agriffis/neovim-nightly)

### Steps to reproduce

Unfortunately, I don't know of a reliable repro, so I'm mainly posting this here so that it's logged.
I've also had this occur on my Ubuntu 20.04 LTS system that uses nvim installed from source via `make install`.

After using vim-lsp for a while, using ` ` or ` ` completion will sometimes only show one result (even if there should be more), then crash once you try to select it. I don't know if this occurs with the other completion methods.

Note that this does not happen when using nvim's native lsp, or when using vim-lsp in Vim.
