Title

Invalid type is passed for Generated Primary Column in case if CockroachDB

Description
## Issue Description

```
ts

class A {
  @PrimaryGeneratedColumn() // adding { type: 'bigint' } fixes the problem
  @Generated('rowid')
... [Log Snipped] ...
  public id
}
```

The default primary key for cockroach ist with int an 64 bit integer

### Expected Behavior

 

loading now entity B with id   works. I would now expect a.id to be " "

```
const a = repo.findOne(A, ' ')

console.log('a.id', a.id) // should output the string ' '
```


### Actual Behavior

 

loading now entity B with id   works. but when I take a look at the value of id it will be converted to   (cropped as a 32 bit integeR)

```
const a = repo.findOne(A, ' ')

console.log('a.id', a.id) // outputs the number ' '
```

I've debugged it to know at least that the database layer returns the right string value, but in [URL] the passed type is Number.

I could not figure out why this is set this way.

by passing the type to the generated column it will work correctly.

### Steps to Reproduce

 

The issue seems to stem from the type that is inferred from the Referenced column in the OneToOne releationship.
