Title

DNS discovery fails with error when hostnames are used

Description
Using `-discovery-srv` with FQDNs in `-initial-advertise-peer-urls` crashes etcd with:

```
etcd1 has different advertised URLs in the cluster and advertised peer URLs list
```

The issue appears to be at [URL]

`apurls` are the exact strings passed in through the command line, but `m.PeerURLs` is a list of IPs.

Everything does work when you pass in IP addresses over the command line.
