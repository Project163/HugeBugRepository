Title

Bug: dropDownList encodeSpaces.

Description
Options `encodeSpaces` not affected to value under groups.
Discussion
- What do you mean by `under groups`?
- ```
php
$items=[
    'group1'=>[
        'a'=>'one',
        'b'=>'two',
... [Log Snipped] ...
];
Html::dropDownList($name, $selection = null, $items,['encodeSpaces'=>true]);
```

sub item or something like that (i dont know what it name :D). space of 'one','two','tri' not encoded.
- [URL]
IMO, it should be

``` php
$attrs = ['options' => $options, 'groups' => $groups, 'encodeSpaces'=>$encodeSpaces];
```

or [URL]

``` php
$lines[] = static::tag('option', ($options['encodeSpaces'] ? str_replace(' ', ' ', static::encode($value)) : static::encode($value)), $attrs);
```
