Title

[1.13.3] Static resources disappear in native executable

Description
## Describe the bug
Static resources aren't available with a native image. The only extension added is resteasy-reactive.
Dev mode works as expected.

### Expected behavior
curl to respond with 200 OK

### Actual behavior
curl gives 404 Not Found
