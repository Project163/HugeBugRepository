Title

Scoped sessions missing 2.0 API `get` method

Description
**Describe the bug**
The objects coming from the [Link: `scoped_session()`] factory do not have the recently added [Link: `Session.get()`] method (2.0 API).

**Expected behavior**
The method [Link: `Session.get()`] should be populated into [Link: `scoped_session()`] created objects.

**To Reproduce**
```
python
from sqlalchemy.engine import create_engine
from sqlalchemy.orm import declarative_base
from sqlalchemy.orm import scoped_session
from sqlalchemy.orm import sessionmaker
... [Log Snipped] ...
controller.setup()
record = controller.retrieve("example")
```

**Error**

```sh
Traceback (most recent call last):
  File " /src/test.py", line 37, in  
    record = controller.retrieve("example")
  File " /src/test.py", line 32, in retrieve
    return self.session.get(self.model, id)
AttributeError: 'scoped_session' object has no attribute 'get'
```

**Versions.**
 - OS: mac OS 11.2.3
 - Python: Python 3.7.9
 - SQLAlchemy: 1.4.3
 - Database: PostgreSQL
 - DBAPI: psycopg2

**Additional context**
I believe that when the [Link: `Session.get()`] method was introduced (in [Link: this commit]), it was not populated to [Link: the list of methods] that the scoped session objects _inherits_ via the `@create_proxy_methods` decorator.
Discussion
