Title

Action prompt in dev mode only seems to appear if tests are present for the app

Description
## Describe the bug
With Quarkus 2.0, it's possible to interact with the app at runtime during dev mode, relaunch tests, force a restart, etc. However, this appears that this only happens if there are tests for the app. If you launch an app in dev mode that doesn't have any associated tests, no prompt is available to interact with the app.

### Expected behavior
Prompt for action should always be available even in the absence of tests.

### Actual behavior
If the app has no tests, then there is no way to interact with the app in dev mode


## To Reproduce
Any app without tests should reproduce the issue (I think).
