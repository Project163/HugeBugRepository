Title

js form afterValidate executes only if form being submitted

Description
### What steps will reproduce the problem?

Setup before and afterValidate events for form, for example for blocking submit button:

``` javascript
  $('form').on('beforeValidate', function (e) {
    $(e.target).find(':submit').prop('disabled', true);
    console.log('beforeValidate');
  }).on('afterValidate', function (e) {
    $(e.target).find(':submit').prop('disabled', false);
    console.log('afterValidate');
  });
```
### What is the expected result?

Both event triggered
### What do you get instead?

Only beforeValidate event happens
### Additional info

In yii.activeForm.js afterValidate event described as it is triggered after validating the whole form.
But actually it happens only after validation triggered by form submission: see updateInputs method: it placed only if submitting is true
