Title

OpenMapRealVector.getSparcity should be getSparsity

Description
The term for describing the ratio of nonzero elements to zero elements in a matrix/vector is sparsity, not sparcity.  Suggest renaming getSparcity() to getSparsity()
Discussion
- The policy of this project is to not remove methods from the public API in a point release.  However, the misspelled method has been deprecated and the correctly spelled method has been added.
- Closing issue as it was included in version 2.2, which has been released
