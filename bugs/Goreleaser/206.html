Title

ko build/release not honouring `bare: true`

Description
### What happened?

Using `ko` builds with `goreleaser` [URL] is not honouring the `bare: true` attribute of `ko`  that strips the import path.

in the above example the image should be built and pushed to `docker.io/kameshsampath/go-hello-world: ` instead I see it pushing to `docker.io/kameshsampath/go-hello-world/github.com/kameshsampath/go-hello-world:v0.0.100-next`

```
text
    • ko
2023/02/01 11:10:53 Building github.com/kameshsampath/go-hello-world for linux/arm64
2023/02/01 11:10:53 Building github.com/kameshsampath/go-hello-world for linux/amd64
2023/02/01 11:10:53 Publishing docker.io/kameshsampath/go-hello-world/github.com/kameshsampath/go-hello-world:v0.0.100-next
... [Log Snipped] ...
  ⨯ release failed after 8s                  error=ko: failed to publish artifacts: publish: writing sbom: HEAD [URL] unexpected status code 401 Unauthorized (HEAD responses have no body, use GET for details)
make: *** [release] Error 1
```

### How can we reproduce this?

Install goreleaset >= v0.1.5 and run the release from [URL]
