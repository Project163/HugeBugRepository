Title

`File`>`Persist Session...` should be disabled with open session

Description
### Describe the bug

If one creates a session and selects the option to persist (I can't recall what it's called) then the persist option does nothing remotely useful.

### Steps to reproduce the behavior

1. Create a default session (that will save its stuff)
2. Use `File`>`Persist Session...`

### Expected behavior

* It should not be possible to get a dialog saying "you can't do this"
* The menu item should not be enabled if it won't function

2.11.1
