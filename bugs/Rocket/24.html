Title

HEAD response bodies are stripped before fairings are run

Description
I believe response fairings should run before the body is stripped. Currently it is not possible for a fairing to access the body, and one can also add a body to a HEAD response because of this.

I was attempting to implement a fairing for automatic ETag generation / conditional get when I discovered this. ETags are intended to be generated and checked for HEAD requests as well, but this is impossible in an `on_response` fairing because the body is stripped before the fairing is run.
