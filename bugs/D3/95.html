Title

Subticks division not available when there is just one major tick

Description
Hello, I have a chart showing data from two weeks, with a major tick for each week and a minor tick for each day.

I implemented this using:

```
xAxis.ticks(d3.time.weeks).tickSubdivide(6);
```

I was surprised in finding today the minor ticks disappearing. This was due to the time interval coming with the data, which you can understand looking the attached screenshot.

[Image: Screenshot from 2013-03-04 11:13:28]

Days and day numbers are not ticks, they are added by extra code. The subticks, here, should be vertical lines similar to the week major tick. In this case, there is one start tick, one end tick, and just one major tick. I discovered with the debugger that in this case, the `d3_svg_axisSubdivide` function inside `svg/axis.js` does not compute any subtick, because ticks.length is not greater then one.

Before trying to add some tests to `svg/axis-test.js` and to fix the problem, I wanted to have some comments from you. Thanks!
Discussion
- Yeah, tick subdivision probably requires creating two additional major ticks outside the original ticks before doing the subdivision. This will require some thought.

In the meantime, I think in your case it might be cleaner to use axis.ticks(d3.time.days) and then use post-selection to do something special for the weeks.
- Thank you for the suggestion, I never used post-selection, I will deepen the topic. About the idea of creating two additional major ticks, I can't see any drawback in it.
