Title

Invalid generic cast generated in super constructor call in a Java stub

Description
For this Groovy class: 
  
  class  TaggedsMap  extends  TreeMap {

    TaggedsMap() {  super () }

    TaggedsMap(Comparator comparator) {  super (comparator)}

    TaggedsMap(Map m) {
         super ()
        putAll( m)
    }

    TaggedsMap(SortedMap m) {
         super ()
        putAll (m)
    }
}
