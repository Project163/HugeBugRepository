Title

Calcite. Query validation failure with a dynamic parameter.

Description
There is a issue with casting and inferring expression/value type with a dynamic parameter: 
  
 
         // Works
         assertQuery( "select 1 + ?" ).withParams(1).returns(2).check();
         // Works
         assertQuery( "select 1 + CAST(? AS INTEGER)" ).withParams(2L).returns(3).check();
        
         // Fails
         assertQuery( "select 1 + ?" ).withParams(1L).returns(2L).check();
