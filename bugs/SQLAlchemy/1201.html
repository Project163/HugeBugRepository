Title

apply str() to the password field of URL

Description
### Describe the bug

On the [Link: documents], it's said that the password attribute may be any object with a `__str__` method. 

While this interface works with psycopg2, it doesn't with asyncpg. Checking `asyncpg.connection.connect`, it requires either a string or a callable that returns a string.

Passing a password object that implements both `__str__` and `__call__` makes it work.

### To Reproduce

```
python
import asyncio
from dataclasses import dataclass

from sqlalchemy.ext.asyncio import create_async_engine
... [Log Snipped] ...

asyncio.run(async_main())
```
