Title

Regression: fadeOut function no longer interpreted when compiled from command-line.

Description
I noticed last night that when compiling a LESS sheet that uses the fadeOut function, the compiled CSS also has the fadeOut function and therefore isn't valid CSS. Here's how I duplicated this issue:

```
bash
$ cat test.less

    color: fadeOut(#336699, 30%);
}
... [Log Snipped] ...
  color: fadeOut(#336699, 30%);
}
```

Let me know if you have any questions. Thanks!
