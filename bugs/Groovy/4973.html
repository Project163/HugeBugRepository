Title

SC: implicit-this call to static method of super class from another package

Description
Consider the following: 
  
 
 package  p
abstract  class  A {
  protected static pm() {
  }
}
 
  

  
 
 package  q
@groovy.transform.CompileStatic
 class  C  extends  p.A {
  void test() {
    pm()
  }
}
 
  

 Compiler emits error: "Cannot access method: pm() of class: p.A"
