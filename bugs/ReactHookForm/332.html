Title

issue: setFocus with shouldSelect breaks for inputs created with useController

Description
### Version Number

7.32.2

### Codesandbox/Expo snack

[URL]

### Steps to reproduce

1. Set up an input with `useController`, e.g. `'firstName'`
2. Call `setFocus('firstName', { shouldSelect: true })`


### Expected behaviour

The input should be focused and selected.

### Actual Behavior

A `TypeError` is thrown: `TypeError: s.select is not a function`

### What browsers are you seeing the problem on?

Chrome
