Title

false positive MissingParamType when implement a abstract method of a trait

Description
Consider the following code:
```
php
/**
 * @template T
 */
trait ValueObjectTrait
... [Log Snipped] ...
    abstract protected function validate($value): void;
}
```

```
php
final class UniqueDocumentCode
{
    /**
     * @use ValueObjectTrait 
... [Log Snipped] ...
    }
}
```
I get the following error:
```
INFO: MissingParamType - UniqueDocumentCode.php:15:33 - Parameter $value has no provided type protected function validate($value): void
```
But i have already declared the parameter type in ValueObjectTrait, so i should not get the notice.
