Title

Replace 2.3.1 with 2.3.2 in HiveExternalCatalogVersionsSuite

Description
This issue aims to prevent test slowdowns at HiveExternalCatalogVersionsSuite by using the latest Spark 2.3.2 because the Apache mirror will remove the old Spark 2.3.1 eventually. HiveExternalCatalogVersionsSuite will not fail because   SPARK-24813   implements a fallback logic, but it causes many trials in all builds over `branch-2.3/branch-2.4/master`. We had better fix this issue.
