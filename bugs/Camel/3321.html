Title

Http Post from a streaming client sometimes fails to parse

Description
When upgrading from camel 2.14.1 to 2.15.0 our http posts from clients were sometimes failing.  Traced issue to  [URL]  The linked issue added a check of InputStream.available() which on a slow or remote client the binary stream isn't always immediately available.  Since this is done as part of the initial setup the data is never parsed when it becomes available.
Discussion
- There is a new option eagerCheckContentAvailable that is default false to correct this behavior. You can set it to true to have the 2.15.x situation.
