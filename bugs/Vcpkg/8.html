- If one removes the following line in ports/boost/portfile.cmake, it works again.

`file(APPEND ${CURRENT_PACKAGES_DIR}/include/boost/config/user.hpp "\n#define BOOST_AUTO_LINK_NOMANGLE\n")`

This line was added as part of   in order to enable boost's system install (= library names without mangled suffixes).

This option was later disabled in   but the line setting `BOOST_AUTO_LINK_NOMANGLE` was kept.

I'm not sure if removing this line will work across all projects but at least Wt builds again and I'll be testing a few more ports.
- This also fixes the build for cpprestsdk (and probably others).
