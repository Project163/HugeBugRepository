Title

Resolving a DTD from Schema fails when Endpoint definition uses wsdlLocation

Description
This bug affects endpoints, which have schema validation enabled and also contain a wsdlLocation. If a schema of the WSDL holds a reference to a DTD, the resolution of the DTD fails. These results in the fact that schema validation is repealed. This issue has already been raised on the mailing list (cf.  [URL] and  [URL] , respectively).
