Title

WordExtractor - bold hyperlink not closed properly

Description
If a Word document contains a bold hyperlink, the resulting xhtml is: 

 <a href="[URL] link</a></b> 

 The closing bold and anchor tags are transposed, which isn't valid XHTML.
