Title

Don't assume that every "*Interface" class is an interface

Description
Originally reported by: **Radek Holý (BitBucket: [Link: PyDeq], GitHub: @PyDeq?)**

---

Pylint assumes that every class of which `__name__.endswith('Interface')` is an interface which results in an `Interface not implemented (interface-not-implemented)` false positive in my code:

```
#!python

class WebInterface(object):

    """The web interface to the program."""

    ...
```

The actual cause is `elif klass.name.endswith('Interface'):` in `astroid`. I don't mind if it gets fixed in `astroid` (if it's a bug) or if you add an configuration option to `pylint`. Personally, I believe that `pylint` shouldn't make such assumption by default.
