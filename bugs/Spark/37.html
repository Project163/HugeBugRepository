Title

PySpark does not add Python *.zip and *.egg files to PYTHONPATH

Description
When a list of *.zip or *.egg files is passed to SparkContext via pyFiles these do not get added to PYTHONPATH on the worker. The situation is different for *.py files since for these it is sufficient to add the working directory to PYTHONPATH (via sys.path).
