Title

Assume variable used in undefined class as used, like it's done for functions

Description
when a variable is used as an arg for an undefined function, psalm assumes the variable is used (= not reported unused). This makes sense, as in 99% of cases there is just a typo in the function (or a stub missing) and the function will be used by this class.

However for classes, this does not work. All variables passed as args to an undefined class, gets additionally reported as unused.

Please change it, so it a variable passed to an undefined class is NOT reported as unusedVariable.
(like it works for functions)
