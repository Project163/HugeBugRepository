Title

Dev Services for quarkus-mongo-client don't start if @MongoClientName used

Description
### Describe the bug

Quarkus doesn't try to start MongoDB in dev mode if you inject `MongoClient` with `@MongoClientName`.
There's nothing in logs (with debug logging enabled) about reason why Quarkus did't start db.

### Expected behavior

Dev service started and same `MongoClient` injected for all injection points.

### Actual behavior

Quarkus silently skips starting mongodb container and ArC fails to create bean.

### How to Reproduce?

```
quarkus create app -x resteasy-reactive -x mongodb-client
# edit src/main/java/org/acme/GreetingResource.java to include @Inject @MongoClientName("test") MongoClient client; 
# and invoke something on the client like client.getDatabase("test")
quarkus dev
# curl [URL]
```

You'll get something like this:
```
java.lang.RuntimeException: mongo config is missing for creating mongo client.
        at io.quarkus.mongodb.runtime.MongoClients.createMongoConfiguration(MongoClients.java:253)
        at io.quarkus.mongodb.runtime.MongoClients.createMongoClient(MongoClients.java:118)
```
