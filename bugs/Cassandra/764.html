Title

CassandraStorage for pig checks for environment variable on mappers/reducers, but it should only need to be set on the machine launching pig.

Description
Only error out if necessary pig settings have not previously been set in job config. CassandraStorage checks for environment variables on mappers/reducers, but it should only need to be set on the machine launching the pig jobs.
Discussion
- If the environment variable is set, it wins. If not, and it's already stored in the job configuration, do nothing. If it doesn't exist at all, fail.
- +1 - works where before it would error out in mapreduce mode (post storefunc). I did suggest maybe unifying the conditions and using an else or something to make it more concise, but that's a trivial thing.
