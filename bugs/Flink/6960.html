- Hi  tanjialiang , thank you for reporting the issue. I have reproduced the same error with the code you provided.  
According to  FLIP-107 , it is possible to write metadata columns in SQL. 

 The cause of this error is a bug that it excludes all computed columns and metadata columns when doing appendPartitionAndNullsProjects in PreValidateReWriter. Actually, it is expected to include all persisted columns. I would like to fix it.
- I have created a pull request to fixed the issue, Anyone who help review the PR will be highly appreciated.
