Title

BUG: boolean/string in OdsWriter

Description
### Pandas version checks

- [X] I have checked that this issue has not already been reported.

- [Link: X] I have confirmed this bug exists on the [latest version] of pandas.

- [Link: X] I have confirmed this bug exists on the [main branch] of pandas.


### Reproducible Example

```python
import pandas as pd
pd.DataFrame([[True, "string", 1, 1.0]]).to_excel("output.ods")
```


### Issue Description

OdsWriter doesn't follow [Link: specification] when writing boolean/string value (passing those values in `office:value` attribute of `table-cell`). Below screenshot from `content.xml` and LibreOffice, which can't represent bad boolean.

[Image: image]


### Expected Behavior

Boolean value in `office:value-boolean` and string value in `office:string-value` attributes.

[Image: image]
