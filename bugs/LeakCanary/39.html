Title

Beta3 crashes during analysis with leakcanary-android-process

Description
### Description
When run in a separate process, Leakcanary crashes during heap analysis with:

```
Process: com.airbnb.android.development:leakcanary, PID: 1125
 java.lang.ExceptionInInitializerError
 	at leakcanary.internal.ForegroundService.showForegroundNotification(ForegroundService.kt:50)
 	at leakcanary.internal.ForegroundService.onCreate(ForegroundService.kt:33)
 	at android.app.ActivityThread.handleCreateService(ActivityThread.java:3532)
... [Log Snipped] ...
 	at leakcanary.internal.Notifications. (Notifications.kt:36)
 	... 11 more
```

I can get it to work if I manually add the app watcher during application creation with
```
if (LeakCanaryProcess.isInAnalyzerProcess(application)) {
      AppWatcher.manualInstall(application)
 }
```

### Steps to Reproduce
Follow the documentation to run heap analysis in a separate process by replacing the normal `leakcanary-android` dependency with `leakcanary-android-process`. 

1. Open Leaks activity
2. Import any hprof file for analysis
3. Note crash

The same crash also happens if the analysis happens because of routine usage of the app.

### Version Information

* LeakCanary version: v2-beta3
* Android OS version: 28
* Gradle version: 5.1

### Additional Information

N/A - Don't do any custom configuration, this is using the defaults and automatic setup that leak canary applies.
