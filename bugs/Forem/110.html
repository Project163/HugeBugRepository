Title

Banished User Podcast Submissions Not Removed Upon Being Banished

Description
**Describe the bug**

When a user is banished (for spam) their podcast submissions are not removed, and clog up the queue in `/admin/content_manager/podcasts`.

**To Reproduce**

1. Create a burner account on Forem
2. Submit a podcast via `/podcasts/new`
3. Log into another account with admin credentials
4. Banish the burner account
5. Navigate to `/admin/content_manager/podcasts`
6. See that podcast is still there

**Expected behavior**

When a user is banished, their podcast submissions should be deleted in the process.

**Additional context**

This may be considered a feature request, but I think the lack of this feature is buggy — we always delete all content from banished users, so I think this is just an area that we missed.

Also, here is a related feature request that should also be tackled - [URL] ... currently there is no way for an admin managing podcast to delete any submissions. As such, spammy/junk submissions cannot be removed.
