Title

Nested @import is better inherit from parent option (multiple|once)

Description
Have 3 less files. "parent.less", "node.less", "child.less"

parent.less:
  @import (multiple) 'node.less'
  @import (multiple) 'node.less'

node.less:
  @import 'child.less'

child.less:
  .class{ color:white; }

For this scenario, node.less's @import didn't inherit from it's parent. The final out put would be one line of ".class { color: white; }.

It's better to let @import inherit (multiple|once) option from it's parent, then the output would be 2 lines of ".class { color: white;}
