Title

Generic function type inference broken for arguments with union types

Description
This code is not accepted due to the union type argument with type variable reference within the union items:

```
from typing import List, Union, typevar
T = typevar('T')
def f(a: Union[List[T], str]) -> None: pass
f([1]) # Argument 1 to "f" has incompatible type List[int]; expected "Union[List[None], str]"
```

Another example:

```
from typing import Union, typevar
T = typevar('T')
def f(a: Union[T, str]) -> None: pass
f(1)  # Not accepted
```
