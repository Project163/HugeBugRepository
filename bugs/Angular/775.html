- @jenniferfell I was able to reproduce this. Make sure you have 'EasyList' selected in AdBlock, that's the one that is doing it for me.

[Image: image]
- I am able to reproduce this as well (Chrome 70.0.3538.102 with Adblock Plus). The culprit seems to be in the `ad-banner` class in ad-banner.component.ts. Like @StephenFluin mentioned, this is due to EasyList being selected in ABP. It injects `display:none` in elements with the `ad-banner` class name.

An easy fix for this is to just rename the `ad-banner` class to `ad-banner-example`, after which the banner works as expected.
