Title

Gradle Extension Plugin: "Configuration with name 'implementation' not found", when setting quarkusExtension.deploymentModule

Description
### Describe the bug

[Link: According to the documentation] on the Gradle Quarkus extension plugin, the deployment module name can be set using the `quarkusExtension.deploymentModule` property. However, setting this to a non-default value, will result in an error.

### Expected behavior

It should work

### Actual behavior

Any Gradle command will result in the following error:

```
$ gradle clean --stacktrace

FAILURE: Build failed with an exception.

* What went wrong:
... [Log Snipped] ...

BUILD FAILED in 3s
```

Leaving the property at the default value, with the module being called something else, produces a warning:

```
Unable to find deployment project with name: deployment. You can configure the deployment project name by setting the 'deploymentModule' property in the plugin extension.
```

### How to Reproduce?

I've created [Link: a project here] that reproduces the issue.

Any Gradle command will reproduce the issue, e.g. `gradle clean`.

I tried figuring out in QuarkusExtensionPlugin.java what goes wrong, but I don't understand half of the lines.
- An alternative workaround seems to be to set `quarkusExtension.deploymentModule="name of runtime module"`. This will build without errors or warnings, and will produce a jar-file with a `META-INF/quarkus-extension.properties` with a `deployment-artifact` with the name of the runtime module appended with `-deployment`. I assume this only works if the name of the deployment module is equal to that of the runtime module, with `-deployment` appended.
