Title

Some of the JDBC test cases are failing on Windows because of the longer class path.

Description
If the class path size is more than 8K then we can’t set the environment variable so some of the test cases are failing on Windows. Remove the duplicate JAR entries from the class path to reduce the chance of exceeding the 8K limit.
