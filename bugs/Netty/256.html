Title

The promise of the outbound operation that causes a channel closure should be notified before channelInactive()

Description
Surfaced during the discussion for #1525.

For example, in `AbstractNioUnsafe.connect()` and `AbstrcatNioUnsafe.finishConnect()` notifies the promise in different timings.  One calls `tryFailure()` _before_ `channelInactive()` and the other _after_.  We need to review the overall code base to find the inconsistencies and fix them.  The correct behavior should be to notify the promise before `channelInactive()`.
