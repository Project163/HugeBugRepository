Title

Discussion
- I suspect this is a bug in ASM's stack frame computation.  When I set system property  groovy.log.classgen  to true, the only difference I see between the example code and the same plus a newline between the two assignments is an extra label and  LINENUMBER  instruction. 

 If I manually write an extra label before the second assignment expression, there is no verify error.  So I could pursue some kind of fix where there are extra labels written between statements.  Or do we want to wait for ASM devs to have a look?
