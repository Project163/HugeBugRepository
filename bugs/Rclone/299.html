Title

rclone to Qnap Webdav fails with subfolders that contain multiple files.

Description
#### What is the problem you are having with rclone?
When trying to transfer files to a qnap nas with webdav access setup the transfer fails if the folder i'm trying to transfer has another folder in it with more then 1 file. Also any encrypted transfers fail.

If I copy over 1 folder that contains 1 folder and 1 file it transfers ok.
Also I can use cyberduck to transfer folders with as many sub folders and files with not issues and I can even create an encrypted vault and transfer files to that. So I beleive that the Qnap Webdav is set up correctly.
