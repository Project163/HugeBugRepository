Title

List#getAt(Range) works differently than documented

Description
The documentation for List#getAt(groovy.lang.Range range) says: 
"returns: java.util.List - a range of a list from the range's from index up to but not including the ranges's to value" 
  However, the eanges to value seems to be included: 

 groovy> def l =  [0,1,2,3,4]  
groovy> println l [1..3]  
groovy> go 
 [1, 2, 3]  

   So, either the documentation or the implementation is wrong. I'm not sure which, but I would expect getAt(Range) to work similar to List#subList(begin, end), which excludes the end, like this: 

 groovy> println l.subList(1,3) 
groovy> go 
 [1, 2]
Discussion
- Right, the documentation is not clear and should be fixed, but the results you get are what should be expected: 

 def l =  [0, 1, 2, 3, 4]  
println l [1..3]  // will print  [1, 2, 3]  

 but println l [1..<3]  will print  [1, 2]  

 It all depends on the kind of range you're using, inclusive or exclusive. 

 Action: fix the Javadoc
