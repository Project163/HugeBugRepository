Title

Warning on insert when primary key is Date

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.7.1 and 3.7.3
* Platform and Target: apache2 (not relevant), PHP 5.6.38, MySQL 5.5.62

### What you did
I am using the CakePHP ORM only.
I have the following table:
```
sql
CREATE TABLE `thing` (
	`somedate` DATE NOT NULL DEFAULT '0000-00-00',
	`someval` FLOAT NULL DEFAULT NULL,
	PRIMARY KEY (`somedate`)
... [Log Snipped] ...
ENGINE=InnoDB
;
```

And the following code, which creates a record:
```
php
 save($thing);
```


### What happened
When the record is new (that is, we do an insert and not an update) PHP complains:
```
PHP Warning:  strlen() expects parameter 1 to be string, object given in /var/www/cake_test/vendor/cakephp/orm/Table.php on line 2089
```

[Link: That line] is running strlen over the values of the primary key - that is, over the following array:
```php
["somedate" => new \DateTime("2018-01-01")]
```
Now I don't know what the point of that line is, but obviously running strlen on a DateTime doesn't make a lot of sense.

### What you expected to happen
I expect no warnings.
