Title

Native + Oracle JDBC + Quarkus NativeImageBuildStep fails

Description
### Describe the bug

Quarkus Upstream
Extension: `quarkus-jdbc-oracle / quarkus-reactive-oracle-client`

Error:

```
Error: Classes that should be initialized at run time got initialized during image building:
 oracle.jdbc.driver.BlockSource$ThreadedCachingBlockSource 
```

Stacktrace:

```
[1/7] Initializing...                                                                                    (9.3s @ 0.39GB)
 Version info: 'GraalVM  -Final Java 11 Mandrel Distribution'
 C compiler: gcc (redhat, x86_64, 8.5.0)
 Garbage collector: Serial GC
 6 user-provided feature(s)
... [Log Snipped] ...
[INFO] BUILD FAILURE
[INFO] ------------------------------------------------------------------------
```
Workaround: 
You could add the following native arguments to your application properties:
```
quarkus.native.additional-build-args=--initialize-at-run-time=oracle.jdbc.driver.BlockSource$ThreadedCachingBlockSource
```

### Expected behavior

Build succeed without any extra arguments

### Actual behavior

BUILD FAILURE
