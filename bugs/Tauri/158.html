Title

[bug] cli.rs > dev command failing with clap short option duplicates

Description
### Describe the bug

The cargo-tauri dev command fails at runtime with a clap assertion failure due to a name collision with two flags.

### Reproduction

```
git clone [URL]
cd tauri/tooling/cli.rs
cargo run dev foo
```

### Expected behavior

Dev command does not panic.

### Platform and versions

```shell
Manual checkout of tauri-apps/tauri/next
```

- Just realized this is not reproducible in release mode, since it's a debug assertion, so it's less of an urgent issue. That's probably why it remained undiscovered too.
