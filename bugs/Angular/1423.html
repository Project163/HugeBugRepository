Title

Form required validator uses length attribute on object also

Description
# 🐞 bug report

### Affected Package
@angular/forms


### Description

We use require form validators to check whether an object is assigned inside a form.
Because our object has a field called "length", the required validators fail.

```typescript
function isEmptyInputValue(value: any): boolean {
  // we don't check for string here so it also works with arrays
  return value == null || value.length === 0;
}
```

The function should check if value is string or array before using the "length" attribute,
for example:

```typescript
function isEmptyInputValue(value: any): boolean {
  !(Array.isArray(value) && value.length === 0 || !value ) 
}
```
