Title

Automated authentication requests shown in HTTP Sessions tab

Description
Issue reported in OWASP ZAP User Group: [URL]

Steps to reproduce the issue:
1. Run ZAP;
2. Set up a context with users (Cookie-based session management and the session token must match one defined in Options > HTTP Sessions);
3. Spider (or active scan) the context with the defined user;
4. Note that for each authentication attempt it's created a new entry in HTTP sessions tab. As with other automated requests (spider, active scanner, fuzzer...) the authentications requests should not be (processed and) shown in HTTP Sessions tab.

ZAP Versions:
Versions >= 2.0.0
