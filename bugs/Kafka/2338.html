Title

RocksDBTimestampedStore should open in regular mode for new stores

Description
KIP-258  introduced `RocksDBTimestampedStore` that supports an "upgrade mode" to migrate data in existing persistent stores to the new storage format. However, `RocksDBTimestampedStore` incorrectly also uses "upgrade mode" for new stores instead of opening them in "regular mode".
