Title

error for enum constant with comma followed by method

Description
Consider the following: 
  
 
 enum  Orientation {
  LANDSCAPE, PORTRAIT,
  
  @Override
   String  toString() {
     name().toLowerCase().capitalize()
  }
}

println Orientation.values()
 
  
 Parser error "unexpected token" for comma after PORTRAIT. Remove comma and no issue. Parsers support enum with trailing comma (no class members). 

 See also   GROOVY-4438  ,   GROOVY-7773   and   GROOVY-8507
