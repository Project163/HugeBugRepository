Title

Console Table Widget does not render correctly in combination with ANSI formatting

Description
### What steps will reproduce the problem?

```
php
$table = new Table();
$table->setHeaders(['test1', 'test2', Console::ansiFormat('test3', [Console::FG_RED])]);
$table->setRows([
        [Console::ansiFormat('testcontent1', [Console::FG_BLUE]), Console::ansiFormat('testcontent2', [Console::FG_YELLOW]), 'testcontent3'],
... [Log Snipped] ...
$table->setScreenWidth(200);
echo $table;
```

### What is the expected result?

correctly rendered table.

### What do you get instead?

[Image: bildschirmfoto von 2018-10-26 16-11-02]

This happens because ANSI formatting characters are considered for calculating cell width. These characters are zero-width and thus need to be removed when calculating width.
