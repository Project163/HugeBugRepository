Title

Rule "no-useless-concat" reports false positive

Description
ESLint version:

```
v1.3.0
```

Source code:

``` javascript
var number = 10;
var string = (number + 1) + 'px';
window.alert(string); // eslint-disable-line no-alert
```

ESLint output:

```
2:27  error  Unexpected string concatenation of literals  no-useless-concat
```

If I'm not mistaken then this concatenation is not useless because `number` is not a string.
Discussion
- I think it's because it can be written as:

``` js
var string = 11 + 'px';
window.alert(string); // eslint-disable-line no-alert
```
- That's only true for the simple test case.

The following code causes the same error and cannot be modified as proposed:

```
function foo(number) {
    var string = (number + 1) + 'px';
    window.alert(string);
}
```
