Title

Issue using isset with multiple arguments

Description
I don't think Psalm correctly understands passing multiple arguments to `isset`. I expect the following two code blocks to behave the same but Psalm generates two `PossiblyNullOperand: Cannot concatenate with a possibly null string|null` messages with the second one where multiple arguments are being passed to `isset`.

1. [URL]

```php
function test(?string $a, ?string $b): string {
    if (!isset($a) || !isset($b)) {
      return '';
    }
    return $a.$b;
}
```

2. [URL]

```php
function test(?string $a, ?string $b): string {
    if (!isset($a, $b)) {
      return '';
    }
    return $a.$b;
}
```
