Title

TestComponentBuilder.overrideDirective does not work with Lists of directives

Description
Having a component "TaskItem" configured like this:

``` javascript
@Component({
  selector: 'task-item',
  directives: [ROUTER_DIRECTIVES],
  ...
})
export class TaskItem {
}
```

and trying to override the RouterLink Directive in the test like this:

```
 return tcb
      .overrideDirective(TaskItem, RouterLink, DummyRouterLink)
      .createAsync(TaskList)
      .then((fixture: any) => {
```

leads to the exception:

```
Overriden directive RouterLink not found in the template of TaskItem
```

configuring the component like:

``` javascript
@Component({
  selector: 'task-item',
  directives: [RouterLink, RouterOutlet],
  ...
})
export class TaskItem {
}
```

works fine...
Discussion
- @juliemr could you take a quick look? It seems as though this is a general issue with our ability to test child directives? @wardbell would be happy to pair with you on repro cases.
- The issue is that the override happens before the expansion of `ROUTER_DIRECTIVES` into its parts - this shouldn't be a more general issue.
