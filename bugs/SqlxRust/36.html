PgHasArrayType is not implemented for Vec

Description
### Bug Description
after upgrading to `0.7.0` I'm getting this error when using [URL]
```
error[E0277]: the trait bound `Vec : PgHasArrayType` is not satisfied
 --> src/lib.rs:1:10
  |
1 | #[derive(sqlx::Type)]
  |          ^^^^^^^^^^ the trait `PgHasArrayType` is not implemented for `Vec `
... [Log Snipped] ...
For more information about this error, try `rustc --explain E0277`.
error: could not compile `sqlx-test2` (lib) due to previous error
```

### Minimal Reproduction
```console
cargo init --lib sqlx-test

`Cargo.toml`:
```
rust

name = "sqlx-test2"

* SQLx version: 0.7.0
