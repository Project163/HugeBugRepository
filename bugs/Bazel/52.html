Title

Prevent self-referencing external repo

Description
Currently if you by accident specify an external repo in the external repo (self-reference), Bazel does accept the path, but does not seem able to handle the path correctly. This leads to nasty errors and currently I cannot think of a reason, why you would want to be able to reference the current external repo inside the repo.
Discussion
- What do you mean by "specifying an external repo in the external repo"? A few WORKSPACE/BUILD file excerpts and maybe the directory structure of your repositories would help tremendously.
- The entry in `WORKSPACE`:

```
new_http_archive(
  name = "boost",
  url = "[URL]
  build_file = "my.BUILD",
)
```

and a `my.BUILD` with

```
cc_library(
  name = "my",
  srcs = "@boost//glorioussource.cpp",
)
```

should demonstrate the issue.
There may be one reason, when this may make sense - when you use `my.BUILD/my` from different repos.
