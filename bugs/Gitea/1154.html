Title

Webhook create events return incorrect `ref_type`

Description
### Description

Since commit   (PR #24634), Gitea webhooks for `create` events have a `ref_type` of `tags`, rather than `tag` as it used to be and currently is on GitHub. This breaks webhook receivers such as Woodpecker CI. I don't think this change was intentional. If it was, I'll file an issue on the Woodpecker repo instead.
