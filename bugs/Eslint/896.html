Discussion
- Could you try the same file without `babel-eslint`? `babel-eslint` is not 100% compatible with ESTree, as such some of the errors might be due to the parser.
- After experimentation, using the default parser and

```
"experimentalObjectRestSpread": true
```

along with

```
"no-loop-func": [1],
```

causes the error. When I remove either of those, it works.
- ... [Middle Discussions Snipped for Brevity] ...
- Can you run it with `--debug`? It should tell you the file it was linting when it failed
- I got it.

If a reference in a function in a loop uses a `let` variable before the declaration, this crash happens.

``` js
/* eslint-env es6 */
/* eslint no-loop-func:2 */

while (true) {
    (function() { a; });
}
let a;
```
