Title

Make github bot merge conflict messages more friendly

Description
Current:
[URL]

Suggestion from @jelbourn with small tweaks by me:
```
Hey there!

This is an automated message to let you know that this PR now has merge conflicts. Updating the PR to resolve these conflicts will help a lot in getting it merged. Thanks!
```

Why change? Because while the original message is funny, first time contributors or contributors with PRs stuck in in a review queue for a long time will only get frustrated if we pester them with "funny" messages about not so funny merge conflicts.
Discussion
- @vicb is suggesting dropping the "Hi there!" since it's just noice. I kind of agree. how about:

```
Automated Notification: Due to recent upstream merges, this PR now has merge conflicts.
@ , please help to unblock this PR by resolving these conflicts. Thanks!
```
- Why do we need "Automated Notification: " ? 
The UI has a "bot" label on the message already -> we know it's a bot so it does not have to be funny or too much polite but informative.
- Making it super explicit doesn't hurt. 

I like having a greeting since it helps establish a friendly tone (would be even better if it could use their name, e.g. `Hi @jelbourn!`) and prevents the message from sounding too robotic.
- @vicb @jelbourn then how about:

```
Hi @jelbourn! Due to recent upstream merges, this PR now has merge conflicts.
Please help to unblock this PR by resolving these conflicts. Thanks!
```
