Title

no consumer registered error when "Transfer-Encoding: chunked" is provided

Description
## Problem statement
On my app, I can run:
```
curl -v -X POST [URL]
```
and all is well (I get a 200 response)

But when I add `Transfer-Encoding: chunked`, then it errors:

```
curl -v -H"Transfer-Encoding: chunked" -X POST [URL]
{"code":500,"message":"no consumer registered for application/octet-stream"}
```
