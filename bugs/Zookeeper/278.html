- this patch logs and error if only a single server is specified and starts in "standalone" mode. 

 This is similar to what happened pre-3.3 (we ignored the server line but didn't log it). In 3.3 having a single server line would cause the server to fail (infinite loop if server.0 for example)
- +1 i think we should log the message as a warning rather than error since we completely recover from the situation. we may also want to log a warning for 2 servers to indicate that failures will not be tolerated. (feel free to ignore both comments and commit the patch
