Title

SQL: Verifier confuses Filter (WHERE) on top of Aggregate with HAVING

Description
The following queries do not pass the Verifier:

```java
    public void testGroupByWhereSubselect() {
        accept("SELECT b, a FROM (SELECT bool as b, AVG(int) as a FROM test GROUP BY bool) WHERE b = false");
        accept("SELECT b, a FROM (SELECT bool as b, AVG(int) as a FROM test GROUP BY bool HAVING AVG(int) > 2) WHERE b = false");
    }
```

rather they give the following `VerificationException`:

```
Cannot use HAVING filter on non-aggregate [bool]; use WHERE instead
```

even though the query is valid and filter could be pushed down below the `Aggregate` and can be flattened into a single query.
