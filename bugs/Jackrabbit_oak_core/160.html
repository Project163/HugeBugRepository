Title

Internal class PropertyValue exposed through Oak API

Description
The  PropertyValue  class introduced with   OAK-371   is referenced in the Oak API. We should introduce an interface for this purpose.
Discussion
- with revision 1397604 I transformed the PropertyValue into an interface and renamed the existing impl to PropertyStateValue
- Thanks for taking care of this.  

 For a moment I though we could get rid of the methods that are duplicate in the new  PropertyValue  interface and the  PropertyState  interface by extending the latter from the former. However, it turns out that this creates a mess with equality: when using  PropertyState  s as  PropertyValue  s and comparing them  equals()  would still consider the name of the  PropertyState .
- Revision 1417455 - PropertyValue is now in the oak-core API, so it seems it's better to use it instead of PropertyStateValue directly.
