Title

XmlNodePrinter fails to print GString attribute values correctly

Description
When XmlNodePrinter prints out an attribute, it embeds strings within quotes, but only strings - not GStrings. 
This is very counter-intuitive. Here's a failing test (easier to c'n'p than upload): 

 int x = 5 
Node node = new Node (null, 'root',  [attr:"$x"] ) 

 StringWriter sw = new StringWriter() 
PrintWriter pw = new PrintWriter(sw) 
new XmlNodePrinter(pw).print(node) 
assert sw.toString()=='<root attr="5">' 

 The actual value is <root attr=5> which isn't valid XML. Changing "$x" to "$x".toString() works, but is clunky. 

 It's not clear to me why XmlNodePrinter.printNameAttributes expects the value to quote itself if it's not a String. What kind of value  would  quote itself?
