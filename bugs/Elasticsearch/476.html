Title

Error on MoreLikeThis API with Non Stored Numeric Fields

Description
According to the documentation:

Note: In order to use the mlt feature a mlt_field needs to be either be stored, store term_vector or source needs to be enabled.

But,running this:

```

curl -XPUT [URL] -d '{"id":1, "content":"foo bar foo2 bar2 foo3 bar3"}'
curl -XPUT [URL] -d '{"id":2, "content":"foo3 bar3 foo4 bar4"}'
```
