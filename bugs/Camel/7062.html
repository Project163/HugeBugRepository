Title

camel-http does not encode path correctly when used with HTTP_QUERY header

Description
During update from Camel 2.x to 4.x we found a bug in Camel-http. It no longer encodes Http path correctly when used with header HTTP_QUERY. 

 The problem is that HttpProducer does not convert the path to ASCIIString, since it uses the wrong variable when creating HttpUriRequest. 

 Camel 2.x:  
  
 
http-outgoing-0 >>  "GET / rest /service?ProcesName= 'Ans%C3%A6ttelse'  HTTP/1.1[\r][\n]" 
 
  
 Camel 4.x: 
  
 
http-outgoing-0 >>  "GET / rest /service?ProcesName= 'Ans[ ]ttelse'  HTTP/1.1[\r][\n]"   
  
 The problem was introduced in version 3.10.0.
