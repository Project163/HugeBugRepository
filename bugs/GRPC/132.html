Title

[Python] Channel creation conflicts with class definition.

Description
Version:

python：3.11.7
grpcio：1.63.0
grpcio-tools：1.63.0
os：Windows

Hello, when I create such a channel in the program:

```python
channel = grpc.aio.insecure_channel('localhost:50051')
```

Afterwards, I defined two objects and used the "Union" module to provide type prompts for them. Once my "Union" list includes the name of my custom object (in this case, "Leaf"), the following error output will appear:

```shell
Error in sys.excepthook:

Original exception was:
```

If I do not use my custom object names, such as using "str", the above errors will not occur. When using "Leaf" alone, the same problem occurs.

For more detailed information, you can refer to the comments in the code. I think this may be an internal issue with the "grpc" library, because without the code for "creating channels", there would be no error output as mentioned above. How to solve this problem, what factors are causing this phenomenon? Thank you.

Attached, problem codes and error prompts:

```
python
from typing import Union
import grpc

# Example: Creating a channel
... [Log Snipped] ...
7. Class "Leaf" with any content     Problem occurred
"""
```
