Title

tinyint column with windowing fn crashes at runtime

Description
Using a tinyint column in a windowing function is causing a runtime exception. 

 The following SQL 

   
  
 
CREATE TABLE t_test(
  int_col  int ,
  tinyint_col tinyint
);
insert into t_test values (1, 1);
select 
count(int_col) over (order by tinyint_col)
from t_test;
