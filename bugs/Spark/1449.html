Title

Spark SQL does not correctly set job description and scheduler pool

Description
Spark SQL current sets the scheduler pool and job description AFTER jobs run (see  [URL] – which happens after calling hiveContext.sql).  As a result, the description for a SQL job ends up being the SQL query corresponding to the previous job.  This should be done before the job is run so the description is correct.
