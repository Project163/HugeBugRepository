Title

Including resource bundles for different languages doesn't work

Description
### Describe the bug

When running the following code, there are differences between Native mode and JVM mode:

```java
Log.fatal(Locale.ITALY.getDisplayCountry(Locale.ENGLISH));
Log.fatal(Locale.ITALY.getDisplayCountry(Locale.GERMAN));
```

JVM mode output:

```
FATAL [] (executor-thread-1) Italy
FATAL [] (executor-thread-1) Italien
```

Native mode output:

```
FATAL [] (executor-thread-1) Italy
FATAL [] (executor-thread-1) Italy
```


The "LocaleNames" bundle was included via a resources-config.json file:

```json
{
  "bundles": [
    { "name": "sun.util.resources.LocaleNames" }
  ]
}
```

This JSON file was passed via the additional build arguments:

`quarkus.native.additional-build-args=-H:ResourceConfigurationFiles=resources-config.json,-H:+IncludeAllLocales,-H:DefaultLocale=en`

The language-specific Quarkus configurations have also been set:
```
quarkus.locales=en,de
quarkus.default-locale=en-US
quarkus.native.user-country=US
quarkus.native.user-language=en
```
