Title

Callout Mediator contais hardcoded path to a samples config file

Description
in the init function of  org.apache.synapse.mediators.builtin.CalloutMediator 

 is a hardcoded path to a samples config file, i.e.: 

                 ConfigurationContextFactory.createConfigurationContextFromFileSystem( 
                    "./samples/axis2Client/client_repo", "./samples/axis2Client/client_repo/conf/axis2.xml"); 

 This introduces a unwanted dependancy on sample code/config, perhaps the config, should be moved inside the 'core' .
Discussion
- This can be easily fixed by exposing these values as callout parameters....
- Fixed on the SVN trunk. Now the client repo and the axis2.xml can be configured using the callout mediator configuration itself. You can add the following element to configure these properties; 

 <configuration axis2xml="string" repository="string"/> 

 but these are optional and if not provided, will be taken the values hardcoded earlier as defualt values, keeping the backward compatibility as well.
