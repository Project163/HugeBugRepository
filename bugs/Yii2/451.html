Title

Translate messages with byte size

Description
I've struggled into some ugly things with the ICU translation.

The original error message for uploaded file which are too big is:

```
The file "{file}" is too big. Its size cannot exceed {limit, number} {limit, plural, one{byte} other{bytes}}.
```

Which results at 20MB in:

```
The file "xyz" is too big. Its size cannot exceed 20971520 bytes.
```

This message is not that user friendly, because nobody knows how much 20971520 bytes really is.

My current workaround is this:

```
php
public function rules()
{
    return [
        ['attachments', 'file', 'maxFiles' => 10, 'maxSize' => 20 * 1024 * 1024,
... [Log Snipped] ...
    ];
}
```
