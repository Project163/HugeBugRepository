Title

negative pixel values for ssim input?

Description
ssim, and ms_ssim take images as input and max_val which is defined as the dynamic range, implying that images can be eg in [-1,1] with maxval = 2. however they call convert_image_dtype() which assumes pixels are in [0,?]. so it is not clear whether ssim, ms_ssim can take images with negative pixel values.

- the issue is not platform dependent, however: tf-gpu 1.12, windows 64. pip installed.
given img1 and img2 in [0,1] you can compare:
```
ms_ssim_op1 = tf.image.ssim_multiscale(img1, img2, 1) # reference images in [0,1]
ms_ssim_op2 = tf.image.ssim_multiscale(img1*2, img2*2, 2) # scaling to [0,2] will give same result
ms_ssim_op3 = tf.image.ssim_multiscale(img1*2-1, img2*2-1, 2) # scaling to [-1,1] will give different result
```
- So this is a documentation problem? Want to send a PR clarifying that negative values are not allowed?
