Title

glfwCreateWindow always "Activate" windows regardless of GLFW_FOCUSED

Description
Hello,

A)
This code in win32_window.c:
```
void _glfwPlatformShowWindow(_GLFWwindow* window)
{
    ShowWindow(window->win32.handle, SW_SHOW);
}
```

I believe should be:
```
void _glfwPlatformShowWindow(_GLFWwindow* window)
{
    ShowWindow(window->win32.handle, SW_SHOWNA);
}
```

Right now if you call `glfwCreateWindow()` with the `GLFW_FOCUSED` hint set to FALSE, the code in glfwCreateWindow does:
```
_glfwPlatformShowWindow(window);
if (wndconfig.focused)
    _glfwPlatformFocusWindow(window);
```
And _glfwPlatformShowWindow() alone with SW_SHOW "activates" the Windows. Now honestly, I am confused about the exact meaning of "activation" in the Win32 api but essentially it looks like we are losing the focus, and this defeat the purpose of GLFW_FOCUSED as documented:  `GLFW_FOCUSED specifies whether the windowed mode window will be given input focus when created. This hint is ignored for full screen and initially hidden windows. `

I will post a PR shortly to make it easy to test that change. I think it should probably be checked/confirmed by people who are more expert of the Win32 api that I am. 

(PS/1: My usage context is I am trying to get this feature working in my GLFW backends: [URL] / the code create undecorated window dynamically and it is a problem and overly noticeable by the end-user if the parent window lose its focus.)

(PS/2: Out of curiosity I traced the history for `_glfwPlatformShowWindow()`: 
May 2014:   Changed `SW_SHOWNORMAL` to `SW_SHOW` for #264
Jan 2013:   Refactor, didn't affect functionalities
Aug 2012,   Initial version)
