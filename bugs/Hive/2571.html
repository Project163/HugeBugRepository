Title

Read ACID tables with FetchOperator returns no rows

Description
After inserting records into a table that uses OrcOutputFormat with the transaction manager set to DbTxnManager,  select count ( * )  will return the number of rows inserted, while  select *  returns nothing.
Discussion
- The issue is in FetchOperator not understanding that it needs to read ACID compliant directories recursively.
- This patch fixes FetchOperator to always read files recursively if the directory is in ACID format. 

 This steals some code from   HIVE-7812  , since I needed the new AcidUtils.isAcid method that was added in that patch.  If that patch is committed before this one this patch will need to be rebased.
