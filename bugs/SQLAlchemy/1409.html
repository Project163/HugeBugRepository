Title

Using `select(Model).from_statement(stmt)` no longer works when `stmt` contains a labeled column

Description
### Describe the bug

When attempting to use `select(Model).from_statement(stmt)` where `stmt` is selecting from a subquery, running a function on one of the subquery's columns, and labeling the result of that function, the ORM sets the labeled column as deferred and tries to refresh.

### To Reproduce

```
python
from __future__ import annotations

import asyncio

... [Log Snipped] ...

asyncio.run(main())
```
