Title

Synthetic release events not sent on virtual desktop switch

Description
Steps to reproduce this issue are:
1. Launch the `events` test.
2. Hold down a key (for example, caps lock, any key will do).
3. Use a keyboard shortcut to switch desktops (e.g. ctrl+alt+arrow down).
   - The window doesn't lose focus, maybe a bug?
4. Release the key.
   - The application doesn't ever see this.
5. Switch back to the screen with the `events` test on it.
   - The window still has focus.
6. Press another key.
   - BUG: The application still thinks the keys (caps lock+ctrl+alt).

For reference, the `events` test logs the following during this:

```
stephen@stephen-laptop:~/Desktop/glfw/tests$ ./events 
Library initialized
Creating windowed mode window 1 (640x480)
Main loop starting
00000000 to 1 at 0.044: Window position: 65 24
... [Log Snipped] ...
00000013 to 1 at 20.276: Key   Scancode   (A) (with no mods) was released
00000014 to 1 at 25.345: Window close
```
- Ubuntu 14.04 / unity 7.2.3.
Discussion
- Sounds like a valid bug to fix, but hopefully it can be scheduled for 3.2 instead of 3.1.
- :+1: agree; It also might not be fixable anyway if it's a WM issue.
