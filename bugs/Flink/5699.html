Title

Add RocksDB packages to parent-first classloading patterns.

Description
RocksDB classes are currently loaded child-first. 

 Because of that, it can happen that the RocksDB library is attempted to be loaded multiple times (by different classloaders). 

 That is prevented by JNI and results in an error as reported in this mail for example 
 [URL]

 We should prevent accidental repeated loading of RocksDB, because we rely on the fact that only one DB is created per task.
