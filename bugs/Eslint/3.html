Title

Don't report no-empty warnings when a parent is FunctionExpression / FunctionDeclaration

Description
When target is

``` js
function t() {
}
```

or

``` js
(function () {
}());
```

eslint should not report `no-empty` warnings.

version is 0.0.7-dev master.
Discussion

1. JSHint doesn't report this warning when empty function is defined
2. Empty functions are used in some idioms,

for example,

```

    if (!cond) {
        throw new Error(msg);
```
