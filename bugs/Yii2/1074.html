Title

Cant save empty record to DB

Description
Hello! 

I have a simple model. All fields are optional - have default values set in DB.

I would like to save an empty object
`
$model = new Item();
$model->save()
`
But I get following error

`
SQLSTATE[23000]: Integrity constraint violation: 1062 Duplicate entry '0' for key 'PRIMARY'
The SQL being executed was: INSERT INTO ``items`` (``id``) VALUES (DEFAULT)
`

Is it expected behavior ?

Also when I try to execute this SQL directly I get the same error message:

`
mysql> INSERT INTO ``items`` (``id``) VALUES (DEFAULT);
`
`
SQLSTATE[23000]: Integrity constraint violation: 1062 Duplicate entry '0' for key 'PRIMARY'
`
### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.11?
| PHP version      | 7.0 
| Operating system | Debian 9
| MySQL | Server version: 5.7.20-18-log - Percona Server (GPL), Release '18', Revision '7ce54a6deef'
Discussion
- You have a primary key defined and you get the error `Duplicate entry '0' for key 'PRIMARY'`(for your second entry), since it's empty. Use an auto-increment value for your PK.
- PK has AUTO_INCREMENT, looks like this is issue in generated SQL query.
When I set any of attributes it works, this error appears only when I try to save an emtpy model.

Following also works
`
INSERT INTO `items` VALUES();
`
It just create new record in DB with all fields NULL and auto incremented field `id`
- ... [Middle Discussions Snipped for Brevity] ...
- If it fails with SQL then I don't see how we can provide workaround.
- Only first execuiton of  `INSERT INTO items(id) VALUES (DEFAULT);` is Ok, if table does not have PK id == 0
As workaround I suggest pass NULL instead of DEFAULT  (only for PK), because following query works fine:
```
INSERT INTO `items` (`id`) VALUES (NULL);
```
