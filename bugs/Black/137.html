Title

Fail gracefully when unaligned or missing 'fmt: off/on' found

Description
The following snippet makes black fail with "Black produced code that is not equivalent to the source.".

```
import typing as t

class Named(t.Protocol):
    # fmt: off
    @property
... [Log Snipped] ...
    def __call__(self, **kwargs) -> Named: ...
    # fmt: on
```

The following works:


```
import typing as t

class Named(t.Protocol):
    # fmt: off
    @property
... [Log Snipped] ...
    def __call__(self, **kwargs) -> Named: ...
    # fmt: on
```
---

Side note: mistyping causes black to indicate the wrong error:

```
import typing as t

class Named(t.Protocol):
    # fmt: off
    @property
... [Log Snipped] ...
    def __call__(self, **kwargs) -> Named: ...
    # fmt: on
```

In this case, black says "`Cannot parse: 13:4:     def __call__(self, **kwargs) -> Named: ...`"; which is misleading.
