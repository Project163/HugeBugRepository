Title

Failure to include a declare_directory in inputs of run action causes silent failures.

Description
### Description of the problem / feature request:

I have been experimenting with declare_directory and Args.add_all. If in declare_directory output is used in an Args object but the declare_directory output was not added to inputs or tools, the args expansion is suddenly just an empty list.

It would be expected that the directory still be expanded (thus causing a script error when the files are not present).

The following code sample demonstrates trying to consume a arbitrary files and directories. Not having the inputs line is an error; however, the script only fails when at least one files are passed srcs since directories get expanded to an empty list.

```
python
def _concatenate_files_impl(ctx):
    outfile = ctx.actions.declare_file(ctx.attr.name + ".txt")

    args = ctx.actions.args()
... [Log Snipped] ...
    },
)
```

### What operating system are you running Bazel on?

Debian Linux

### Version of Bazel

I am using the google-internal version of Bazel released as of Oct. 23, 2018
