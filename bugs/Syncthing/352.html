Title

Receiving device gets stuck in "out of sync" when sending device disconnects/reconnects

Description
The files are available and could be pulled, but they are not:

[Image: screen shot 2016-07-27 at 21 55 34]

The reason is that the puller loop runs when the device is disconnected, doesn't queue any files because they are all unavailable so it concludes there is nothing to do, and goes into holding pattern waiting for the index information to change (which would indicate new files available). But that never happens, because delta indexes.
