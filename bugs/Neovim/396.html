Description
### Neovim version (nvim -v)

NVIM v0.6.0-dev+507-g9f392c071

### Vim (not Nvim) behaves the same?

N/A (extmarks)

### Operating system/version

Ubuntu 20.04

### Terminal name/version

wsltty

### $TERM environment variable

xterm-256color

### Installation

build from repo

### How to reproduce the issue

```
build/bin/nvim --clean +'luafile minimal.lua'
```

minimal.lua
```lua
local ns = vim.api.nvim_create_namespace("myplugin")
local id = vim.api.nvim_buf_set_extmark(0, ns, 0, 0, {virt_text = {{"1"}}})
vim.api.nvim_buf_set_extmark(0, ns, 0, 0, {id = id, virt_text = {{"1"}, {" 2"}}})
```

### Expected behavior

virtual texts are displayed: `1 2`

### Actual behavior

virtual texts are not displayed.
