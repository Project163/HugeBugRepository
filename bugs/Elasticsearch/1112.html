Title

indexName is lost after server restart

Description
Hiya

My server is set up to use `gateway.type=fs`

Put a mapping as follows:

```
curl -XPUT '[URL]  -d '
{
   "properties" : {
      "single" : {
         "type" : "long"
... [Log Snipped] ...
#    "acknowledged" : true
# }
```

Set a record:

```
curl -XPOST '[URL]  -d '
{
   "single" : 123,
   "multis" : 123
}
... [Log Snipped] ...
#    "_type" : "bar"
# }
```

Check the terms:

```
curl -XGET '[URL] 
# {
#    "fields" : {
#       "single" : {
#          "terms" : [
... [Log Snipped] ...
#    }
# }
```

Then restart the server.

```
curl -XGET '[URL] 
# {
#    "fields" : {
#       "single" : {
#          "terms" : [
... [Log Snipped] ...
#    }
# }
```

Note that now `multi` is `[]`, and search requests no longer understand the fieldname `multi`
