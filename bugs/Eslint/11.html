Title

Invalid 'new' statement throws `TypeError: Cannot call method 'charAt' of undefined`

Description
I'm using ESLint0.1.0 with nodev0.10.21 on Windows7

The following code in a file, with or without `"use strict";` and with or without the appended comment

`var arr = new []; // interpreter throws 'TypeError: [] is not a constructor'`

generates the following error:

```
C:\Users\someuser\AppData\Roaming\npm\node_modules\eslint\lib\rules\new-cap.js:25
            if (constructorName.charAt(0) === constructorName.charAt(0).toLowe
                            ^
TypeError: Cannot call method 'charAt' of undefined
    at EventEmitter.NewExpression (C:\Users\someuser\AppData\Roaming\npm\node_modules\eslint\lib\rules\new-
... [Log Snipped] ...
    at Array.reduce (native)
    at processFiles (C:\Users\someuser\AppData\Roaming\npm\node_modules\eslint\lib\cli.js:165:27)
```

This was an edge case where I was replacing `new Array()` with `[]`.... but forgot to remove the `new`.

Same error also occurs with `var obj = new {};`

No (internal) error occurs with `var obj = new;` or `var obj = new` or `var obj = new ();`
