Title

RedHat init script status is a no-op

Description
The current bare-bones init script is a little too bare-bones. The "status" argument make a successful no-op, which can be pretty misleading.
Discussion
- Do a pretty minimal status check.
- Also include the status option in the Usage section.
- Works as advertised:  
 
	 /etc/init.d/cassandra status 
cassandra (pid  1101) is running... 
 

 After shutdown: 
 
	 /etc/init.d/cassandra status 
cassandra is stopped
