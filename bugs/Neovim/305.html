Title

Keymap containing `*` doesn't work as expected on nightly

Description
### Problem

It is not possible to use the below keymap on `HEAD`:

```lua
vim.api.nvim_set_keymap("v", " rp", "*Ncgn", {noremap = false, silent = true})
```

This is not an issue on `stable`.

### Steps to reproduce

Open Neovim, create the keymap (`:lua vim.api.nvim_set_keymap("v", " rp", "*Ncgn", {noremap = false, silent = true})`) then try to use it.

### Expected behavior

It's expected to `*` the visual selection and then enter insert mode on that selection.

### Neovim version (nvim -v)

NVIM v0.10.0-dev-741+g996dd36c7-Homebrew

no
