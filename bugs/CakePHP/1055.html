Title

Wrong case of alias in having/where clauses

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 4.1.4.
* Platform and Target: Mysql 5.7.14, PHP 7.2.28.

### What you did
```
CREATE TABLE test (
	id INT NOT NULL PRIMARY KEY AUTO_INCREMENT, 
	test VARCHAR(250)
) ENGINE=INNODB CHARSET=utf8mb4;
```

```
// in a controller
$this->loadModel('Test');

$test = $this->Test->find()->group(['Test.test'])->having([
	'COUNT(DISTINCT Test.id) >' => 1,
]);

debug($test);
```

### What happened

The query generated was:

```
SELECT Test.id AS Test__id, Test.test AS Test__test FROM test Test GROUP BY Test.test  HAVING COUNT(DISTINCT test.id) > :c0 
```

And the MySQL error:

```
Error: [PDOException] SQLSTATE[42S22]: Column not found: 1054 Unknown column 'test.id' in 'having clause'
```

### What you expected to happen

I was expecting the query to be:

```
SELECT Test.id AS Test__id, Test.test AS Test__test FROM test Test GROUP BY Test.test  HAVING COUNT(DISTINCT Test.id) > :c0 
```

The case of the column after the `DISTINCT` has been lowered. That was fine with a MySQL database on Windows, but when I moved the database to Linux, which is case-sensitive, an error of unknown column occurred.

Adding backticks didn't worked also:

```
$test = $this->Test->find()->group(['Test.test'])->having([
	'COUNT(DISTINCT `Test.id`) >' => 1,
]);
```

Generates:

```
SELECT Test.id AS Test__id, Test.test AS Test__test FROM test Test GROUP BY Test.test  HAVING COUNT(DISTINCT `test.id`) > :c0 
```

The same happens on `where` clause function also.

I think it it related to spaces in the string of the clause, because the following code will also lowercase the alias:

```
$test = $this->Test->find()->group(['Test.test'])->where([
	'AAA(BBB( Test.id)) >' => 1,
]);
```

Output:

```
SELECT Test.id AS Test__id, Test.test AS Test__test FROM test Test WHERE AAA(BBB( test.id)) > :c0 GROUP BY Test.test 
```
