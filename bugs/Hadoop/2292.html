Discussion
- Unnecessary retries on authentication failure has been a general issue (re)introduced around 2.7 or so that I fixed long and haven't had time to re-fix.  The IPC layer itself has already attempted retries for SASL exceptions.  If one bubbles out, it's game over. 

 Don't make this kerberos specific at all.  Just make SaslException fatal.
- The patch should eliminate this disaster:
