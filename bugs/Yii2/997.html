Title

DI Container behavior seems to have changed since version 2.0.39

Description
Since version 2.0.39 the following exception occurs. I have a DynamicModel with a Recaptcha Validator:

```
[['reCaptcha'], \himiklab\yii2\recaptcha\ReCaptchaValidator3::class, 'threshold' => 0.5],
```

[URL] => [URL] it seems this is resolved different then before?

Of course it might be a problem/adjustment needed with the 3rd party library, but since it worked before i would say its BC.

The yii2-httpclient is installed by composer `Installing yiisoft/yii2-httpclient (2.0.12): Loading from cache`. This library has no new release since over 1 year, which means its still the same code, not a problem from a recent update. The package does have a lot of installations (https://packagist.org/packages/himiklab/yii2-recaptcha-widget/stats) so i don't think i am the only one receiving this exception in near future
