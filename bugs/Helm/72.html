- I believe the users in #6031 stumbled across the same root cause (albeit in Helm 2). In certain cases, multiple Releases may show up as DEPLOYED, which may cause various problems.
- I managed to reproduce this bug with Helm (v3.0.2) as follows:

```
helm create foo
cd foo
helm upgrade foo . --install --wait
sed -i -e 's/^replicaCount: .*/replicaCount: 3/' values.yaml
helm upgrade foo . --install --wait
```

While the last command executes, in a different terminal, wait for `pending-upgrade` status, then type:

```
helm upgrade foo . --install --wait
```

The two `helm upgrade` commands must run in parallel. `helm history foo` will look as follows:

```
$ helm history foo
REVISION	UPDATED                 	STATUS         	CHART    	APP VERSION	DESCRIPTION      
1       	Wed Jan  1 23:28:25 2020	deployed       	foo-0.1.0	1.16.0     	Install complete 
2       	Wed Jan  1 23:30:23 2020	pending-upgrade	foo-0.1.0	1.16.0     	Preparing upgrade
$ helm history foo
