Title

insecureSkipTLSVerify, Not working for wss

Description
When testing a web socket ssl end point (wss) the option to ignore TLS does not work, for example: 
```
import ws from "k6/ws";
import { check } from "k6";
export let options = {
   insecureSkipTLSVerify: true
};
... [Log Snipped] ...
  check(res, { "status is 101": (r) => r && r.status === 101 });
}
```
It will still give the error 
ERRO[0001] GoError: x509: certificate has expired or is not yet valid
Discussion
- this can be fixed by adding 
´´´
wsd.TLSClientConfig = &tls.Config{InsecureSkipVerify: true}
´´´
after the websocket.Dialer 
```
wsd := websocket.Dialer{
		NetDial: netDial,
		Proxy:   http.ProxyFromEnvironment,
	}
	
	
	wsd.TLSClientConfig = &tls.Config{InsecureSkipVerify: true}
```

But not sure how to put that according to the param 
```
export let options = {
   insecureSkipTLSVerify: true
};
```
