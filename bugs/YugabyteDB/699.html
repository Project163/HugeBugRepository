Title

[YSQL] Flaky test in org.yb.pgsql.TestAlterTableWithConcurrentTxn.testDmlTransactionBeforeAlterOnCurrentResource

Description
Jira Link: [Link: DB-3086]
### Description

Similar to the Github issue #10368, unexpected error message of `Transaction aborted: kAborted ` occurs.
Due to the new change where active DML transactions are aborted when DDL is performed concurrently on the same resource, an error could be raised at the transaction replication phase where transaction coordinator detects that RAFT already aborted the transaction. 
This error can be included as one of the expected errors in the unit test.
