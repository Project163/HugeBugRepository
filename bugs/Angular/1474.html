- This is introduced by #46096, which fixed a bug that could result in compiler crashes for certain pipes. However, there is a pre-existing bug in which pipes are considered in this check; the compiler incorrectly looks at _all_ pipes in the compilation scope of the NgModule, whereas it should only consider the _used pipes_ in the template.
