Title

Syncthing seems to ignore Minimum Free Disk Space on folders

Description
### What happened?

When sharing a folder between devices, Syncthing seems to ignore Minimum Free Disk Space, only stopping when the target disk is truly filled to the brim. I originally experienced the issue sharing large folders to a laptop with a small drive, but managed to replicate the problem on a VM as follows:
1) Share a folder with a device that can't fit it
2) Set some minimum space limit when accepting the folder on the target device

 

3) Syncthing will fill up the entire disk with no regard for the previous limit, to the point of lagging the whole system.

 

Also, the size of the folder is misreported by the UI
 

Expected behavior: Folder should stop syncing when the minimum space limit is reached

PD: I'm not sure if the log is even useful, since the VM crashed shortly after running out of space and it seems that it didn't catch anything super useful before that happened.

### Syncthing version

v2.0.6

### Platform & operating system

Windows 11 x64
