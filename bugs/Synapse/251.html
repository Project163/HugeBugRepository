Title

Attributes of a SOAP Fault Generated by the Callout Mediator Cannot be Accessed

Description
When the callout mediator receives a SOAP fault the fault handlers are triggered by the accompanying exception but there is no way of accessing the error code, error message etc at mediation level. Therefore we should set the standard error detail properties (ERROR_CODE, ERROR_MESSAGE etc) when the callout mediator receives a SOAP fault.
