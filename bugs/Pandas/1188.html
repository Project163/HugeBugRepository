Title

index locators cast bool to float (and not to int)

Description
#### Code Sample, a copy-pastable example if possible

```
python
In [2]: pd.Index([0, 1, 2, 3]).get_loc(True) # right
---------------------------------------------------------------------------
KeyError                                  Traceback (most recent call last)
/home/pietro/nobackup/repo/pandas/pandas/core/indexes/base.py in get_loc(self, key, method, tolerance)
... [Log Snipped] ...
In [3]: pd.Index([0, 1, 2, 3.]).get_loc(True) # wrong
Out[3]: 1
```

#### Problem description

Given that bools are not casted to ints (which I think is good), even less one would expect that they are casted to float.

#### Expected Output

``KeyError: True`` in both cases.
