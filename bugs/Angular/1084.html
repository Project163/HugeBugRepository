- @princemaple, thank you for the issue!

The type error as reported is indeed correct. It looks like `keyvalue` pipe typings (and TypeScript limitations) are at fault here. This is the essential shape of `keyvalue`:

```typescript
class KeyValuePipe {
  transform(value: null): null;
  transform(value: Map ): Array >;
  transform(...) { ... }
}
```

Looking at this, you might think it's safe to call `KeyValuePipe.transform` with a `Map |null`, like the `async` pipe produces. However, TypeScript currently considers this a type error. It tries to use each overload signature in turn and checks if it can accept the argument type(s). Since none of `KeyValuePipe`s signatures can accept the _whole_ type of `Map |null`, it eventually concludes this call isn't allowed, even though each part of the union is individually compatible with at least one of the signatures.

I think we need to update `KeyValuePipe`'s signature list to be a little more permissive. Many thanks!

- Okay, few observations:

1. There is no usage of the `keyvalue` pipe in that code, so this issue does not appear to be related.
2. `signInUser` is of type `FireUser` but you're passing it to the `async` pipe that operates only on `Observable` or `Promise`. So the error looks correct to me.

will do absolutely nothing, as observables won't execute until they are subscribed to. There's two approaches possible:

1. Subscribe to the `Observable` and assign `this.signInUser` from within its next callback:

```ts
    const subscription = this.store.select(selectSignInUser).pipe(
      tap((u: FireUser) => {
        console.log("FirebaseTrackService|selectSignInUser: ", u);
      })
    ).subscribe((u: FireUser) => {
      this.signInUser = u;
    });
```

(you can keep the `tap` as above, or you could move it into the subscribe callback as well and get rid of the `tap` operator).

This approach does not need the `async` pipe as you're manually dealing with the subscription, but this also means that you'd need to properly unsubscribe from the `subscription` variable I introduced above when necessary (e.g. in `ngOnDestroy`).

2. Assign the `Observable` coming from `this.store.select` to `this.signInUser` and change `signInUser` to be of type `Observable `:

```ts
    this.signInUser = this.store.select(selectSignInUser).pipe(
      tap((u: FireUser) => {
        console.log("FirebaseTrackService|selectSignInUser: ", u);
      })
    );
```

This now does require the usage of the async pipe.
