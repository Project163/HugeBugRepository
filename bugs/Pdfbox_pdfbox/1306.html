 if the font is composite and uses a predefined cmap (excluding Identity-H/V)  
or if its descendant font uses Adobe-GB1/CNS1/Japan1/Korea1 then ...  

 So there's special handling where we need to check if the dependent font identifies itself as CJK in its CIDSystemInfo. If so, then we know which UCS-2 CMap to use. I was actually been working on a patch for this already.
