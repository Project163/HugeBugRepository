Title

Groovy Console looking for wrong LAF on Snow Leopard

Description
The Groovy Console is looking for the wrong LAF on Snow Leopard and not using the OS/X LAF as a result. The code is checking for 'apple.laf.AquaLookAndFeel' but the LAF was moved to 'com.apple.laf.AquaLookAndFeel'. The switch statement is in groovy.ui.ConsoleView.groovy but I assume groovy.ui.view.MacOSXDefaults.groovy and groovy.ui.view.MacOSXMenuBar.groovy will also need to be updated.
Discussion
- When was the laf moved? Was it moved only for Snow Leopard? Or is it for all Leopards? (ie. non-snow as well)
- I'm not sure when it was moved, I just know that I'm running Snow Leopard and it has been moved. Some Googling around indicates it might have been moved in the Java 1.6 timeframe which would seem to indicate all Leopards are affected.
