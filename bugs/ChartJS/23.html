Title

Add "reverse" option to Legend Configuration in documentation.

Description
The Legend Configuration supports a `reverse`option which will reverse the order of the legend labels, but this is not documented.
Example: 
`legend: {
                reverse: true,
                position: 'right'
            }
`
Discussion
- Hi, the reverse option is misplaced in the docs. It should be in the "Legend Configuration" instead of "Legend Label Configuration".
