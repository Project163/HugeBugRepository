- What I can observe is that....

Running `clean assemble` does not compile the test sources.

And then running `clean check` will in fact compile the test sources but seemingly _after_ the `junit5Test` task has been executed. Thus there physically are no tests when the JUnit 5 Gradle plugin executes.
- Oddly enough, the following does run the tests... but only for the second execution of `clean check`... which seems a bit like a bug in Gradle or otherwise a bug in the JUnit 5 Gradle plugin.

```
gradlew clean assemble
gradlew clean check
gradlew clean check
```
