Title

Field watch not registering correctly when blurring without typing

Description
**Describe the bug**
I have a form with multiple fields (important!) where at least one field is filled in.
Another field is empty and when I focus this field, and then defocus it (causing the onBlur to trigger, marking the field as touched), my watch will no longer correctly register.

**To Reproduce**
[URL]

The first field `ignore me` is already filled. If you click in the second field and start typing, the value will be appended to the right.
If you focus the second field and blur it before typing in it, the value will not appear on the right, the watch is never registered nor triggered.

**Expected behavior**
As I did not do anything to the field (and even if I did) I would still expect the watch to correctly fire updated no matter how many times I focus or defocus the input.

**Screenshots**
I think this piece of code might be a good starting point to debug it, but I cannot find a fix for now:
[Image: image]
That line makes sure the component is updated when I start typing (on the initial focus). After blurring the input once, this `shouldUpdateState` is no longer set to true, causing the component to not rerender and thus not start watching. This is because watches are only registered if there is an actual value (probably for performance, but the fallback here does not seem to be flawless).
