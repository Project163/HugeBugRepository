Title

Increase max heap size of Maven javadoc plugin

Description
It's easy to reproduce: 
  
 cd hadoop-common-project/hadoop-common/
mvn javadoc:test-javadoc 
  

 The build will fail. I tried it on OSX (2 different ones). 
  
 ERROR] javadoc: error - Java heap space
[ERROR] 
[ERROR] Command line was: /Library/Java/JavaVirtualMachines/jdk1.8.0_74.jdk/Contents/Home/jre/../bin/javadoc -J-Xmx512m @options @packages
Discussion
- Attaching trivial patch which increases the max heap size of javadoc plugin.
