Title

MaxScale proxy server interferes with mysql / mariadb version information

Description
**Migrated issue, originally created by Curtis McCully ([Link: @cmccully])**

In version 1.1.15, a system variable was changed from tx_isolation to transaction_isolation following MySQL. Mariadb however has not followed suit on this change as of yet so versions 1.1.15 and later are no longer compatible and fail with the following error:
_mysql_exceptions.OperationalError: (1193, “Unknown system variable ‘transaction_isolation’“)
