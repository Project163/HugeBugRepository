Title

Line numbers should always be reported from rethrow

Description
I'm using jade as a simple preprocessor during an offline build phase, passing in the contents of a file I've read elsewhere. It would be nice to document that setting the options filename reads the file instead of just using it in the error messages (which is what my read through the README suggested). Also rethrow should add the line number to the rethrown error even if the filename is not defined:

``` javascript
exports.rethrow = function rethrow(err, filename, lineno){
  err.lineno = lineno;
  if (!filename) throw err;
  ...
```
Discussion
- We should be able to report everything but the filename for the compile time errors too.
