Title

SliderInput not properly initialized and not showing selected value

Description
I've tried adding a SliderInput widget to my form for an integer field:

 field($model, 'nof_employees')->widget(SliderInput::classname(), ['clientOptions' => ['min' => 0, 'max' => 100]]) ?>

This created this field on my form:
[Image: 2013-12-26_1109]

This html was generated:
<div class="form-group field-project-nof_employees">
    <label class="control-label" for="project-nof_employees">NOF Employees</label>
    <div id="project-nof_employees-container"></div><input type="hidden" id="project-nof_employees" name="Project[nof_employees]" value="49">
    <div class="help-block"></div>
</div>
(NB: this is the html during an update action. The value stored in the database is 49)

This javascript code was generated:
jQuery('#project-nof_employees-container').slider({"min":0,"max":100});
jQuery('#project-nof_employees-container').on('slide', function(event, ui) {
                $("#project-nof_employees").val(ui.value);
            });
$("#project-nof_employees").val($("#w1").slider("value"));

I found two issues with this widget:
- The slider is not initialized with the amount stored in the database. It always starts to the left.
- The selected amount is not visible and because the range is also not visible it is 
  not possible to see what amount is selected
