Title

Allow cc_common.link() to create interface libraries for Windows.

Description
cc_binary with linkshared=1 allows generation of interface libraries for Windows. On Windows it is not possible to link against a .dll and we must link against an .if.lib file.

This is controlled [Link: here] for cc_binary.

We must have something similar for cc_common.link() right after [Link: this line]. We could have:
