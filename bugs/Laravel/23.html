Title

Signed URLs containing empty querystring values will not validate

Description
- Laravel Version: 8.41.0
- PHP Version: 7.4.16
- Database Driver & Version: n/a

### Description:

If a url contains querystring parameters with empty values, the generated signed url will not validate. 

### Steps To Reproduce:

```
php
 name('signature-required');
```

This will generate a url that looks like this:
[URL]

Not sure what possible use cases there are for empty string values, perhaps one just wants to check for the presence of a parameter? Of course, the workaround is to not use empty values. But since the signed url has been created, one would at least not expect that it wouldn't validate.
