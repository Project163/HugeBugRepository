Title

Item names starting with '{X}' cause RepositoryException

Description
The exception is RepositoryException: Invalid name or path:  
{0} foo 
 
E.g. for an item named '{0}
  foo'. 

 I guess oak-jcr tries to interpret it as a name in expanded form but does not find a namespace uri for '0'. IIRC these names are valid in Jackrabbit 2.x.
Discussion
- Ah, that's probably a bug in the way I updated the name mappers.
- Yes,  LocalNameMapper.getJcrName  should not do  checkArgument(!oakName.startsWith("{"))  since this will also catch names legitimately starting with a curly brace.
- Fixed at revision 1463964. 
I added additional test coverage for observation
