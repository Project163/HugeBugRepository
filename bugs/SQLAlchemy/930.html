- the issue does not appear in 1.4, only in 1.3.   the commit that breaks it is   which is the reference cycle refactor.  The specific sub-commit within that breaks it is the path registry refactor in [URL] .   The error so far seems to be that because PathRegistry does not have a `__ne__()` method, only an `__eq__()`, the SlotsEntityRegistry falls into a negation of `__eq__()`, which fails, but the CachingEntityRegistry which is the original version is a subclass of `dict` so `__ne__()` is going down some other path.
