- We are experiencing the same issue here. Cassandra version 2.1.12, operating system is "Red Hat Enterprise Linux Server release 6.4 (Santiago)".  

 
 cqlsh> DESC SCHEMA; 

 'NoneType' object has no attribute 'replace'
- A better workaround to the one above is to run the following for each columnfamily in the keyspace in cassandra-cli 

 ``` 
use <keyspace> 
update column family <column family name> with column_metadata = []; 
``` 

 This will ensure that system.schema_columnfamilies gets updated correctly without the need for trying to figure out how many columns you need for the update statement in cqlsh.
