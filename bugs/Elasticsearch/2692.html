Title

Autoscaling and disk threshold disabled

Description
If disk thresholds are disabled on a cluster, storage based autoscaling will no longer trigger an up-scale since the mechanism detects an up-scale need based on shards that are not allocated or unable to be moved.

I think there are 3 directions we can take:

1. Accept this and document it. Perhaps improve the messaging.
2. Make `cluster.routing.allocation.disk.threshold_enabled` and operator-privileged setting, avoiding that this is done inadvertently by users.
3. Make autoscaling still trigger even with `cluster.routing.allocation.disk.threshold_enabled=false`.
Discussion
- Pinging @elastic/es-distributed (Team:Distributed)
- We discussed this at autoscaling sync this morning (thanks @henningandersen for raising this issue) and decided to go with option 2, with input from @jasontedor
