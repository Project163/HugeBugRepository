Title

SpdySession.getActiveStreams() does not return all streams (4.0.21)

Description
When there are more than one stream with the same priority, the set returned by `SpdySession.getActiveStream()` will not include all of them, because it uses `TreeSet` and only compares the priority of streams.  If two different streams have the same priority, one of them will be discarded by `TreeSet`.
