Title

OSGi jakarta.xml.bind version mismatch

Description
There is a version mismatch between the used jakarat.xml.bind-api version and the generated OSGi Metadata. 

 The OSGi Metadata is generated based on the following property: 
  
 
<cxf.osgi.jakarta.bind.version>[3,4)</cxf.osgi.jakarta.bind.version> 
  

 While the jakarta.xml.bind-api dependency management uses 
  
 
<cxf.jaxb.version>4.0.2</cxf.jaxb.version> 
  

 We have problems with our Karaf application to fulfill the requirements. 
  
 
Caused by: org.apache.felix.resolver.reason.ReasonException: Unable to resolve org.apache.cxf.cxf-core/4.1.1: missing requirement [org.apache.cxf.cxf-core/4.1.1] osgi.wiring. package ; filter:= "(&(osgi.wiring. package =jakarta.xml.bind)(version>=3.0.0)(!(version>=4.0.0)))"  
  

 While glassfish wants a newer version: 
  
 
  org.glassfish.jaxb.runtime [org.glassfish.jaxb.runtime/4.0.5]
     import : (&(osgi.wiring. package =jakarta.xml.bind)(version>=4.0.0)(!(version>=5.0.0)))
