Title

QuarkusSecurityTestExtension fails to read class annotation

Description
**Describe the bug**
In QuarkusSecurityTestExtension#beforeEach() the code tries to load the TestSecurity annotation from the method and falls back to the class if not present on the method. The variable "test" unfortunately is a subclass (e.g. if the test is "mypackage.MyTest" the class will be "mypackage.MyTest_Subclass". Therefore the annotations on the class level is not evaluated.

**Expected behavior**
The class-annotation should be read. A solution for doing so properly in JUnit 5 was described in [URL]

**Actual behavior**
The annotations on the class level is not evaluated.

**To Reproduce**
```
@QuarkusTest
@TestSecurity(user = "tom", roles = { "A","B" })
public class MyTest {
  @BeforeEach
  void beforeEach() {
... [Log Snipped] ...
  }
}
```
