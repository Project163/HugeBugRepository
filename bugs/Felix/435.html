Title

Jetty HTTP service is exporting the incorrect version of the service package

Description
The pom.xml file hard codes version 1.1 on the service package, but it should actually be 1.2. The result is that the bundle exports 1.1, but imports 1.2, which makes it impossible to resolve standalone and defeats the whole point of embedding the service package. We should remove the hard coded version and just let BND pick up the version from the included package.
