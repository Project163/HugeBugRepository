Title

Failed to move newly written config - v1.37

Description
Hi,

After updating to the last rclone version, every time the access token expires, I get this error:

Failed to move newly written config from C:…\Temp\usr.conf496256607 to final location
: rename C:…\Temp\usr.conf496256607 usr.conf: The system cannot move the file to a different disk drive.

Windows 7
rclone v1.37
Run as Admin, UAC is disabled.

Command used:
`F:\rclone>rclone.exe --config usr.conf ls UD:Backups`

The current copy of the config file gets an ".old" added to it's name, copying the newly created config file manually solves the problem until the access token expires again.

Using the same exact command and same OLD config file with the previous rclone version works as expected.

Thanks.
