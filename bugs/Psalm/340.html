Title

Overriding interface method's return type via @method in implementation does not work

Description
In one of our projects (Yii2) we have models based on `ActiveRecord`. Psalm is complaining:

```
ERROR: UndefinedMethod - 57:9 - Method ActiveQueryInterface::viatable does not exist
```
even if `ActiveRecord` has `@method` override in phpDoc and `ActiveQuery` should be considered as a result of `hasMany()`, so `viaTable()` is available. But Psalm considers `ActiveQueryInterface` as a result of `hasMany()`, as `BaseActiveRecord::hasMany()` defines.

I have `usePhpDocMethodsWithoutMagicCall` set to `true`, still there is an error.
