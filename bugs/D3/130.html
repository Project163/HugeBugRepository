Title

d3.mean not converting to number

Description
Calling d3.mean on an array of strings will not give the expected result, because the values are not parsed to numbers. This can be bypassed easily with an accessor function, but this behavior is different to the d3.sum function.

d3.mean(["1", "2", "3"]) will give 41 instead of expected 2, where d3.sum(["1", "2", "3"]) returns the correct and expected value 6.
