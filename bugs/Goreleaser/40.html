Title

Installation fails due to dep ensure

Description
**Describe the bug**

In the [Link: documentation], under "Using go get", you advise
```
$ go get -d github.com/goreleaser/goreleaser
$ cd $GOPATH/src/github.com/goreleaser/goreleaser
$ dep ensure -vendor-only
$ make setup build
```
However, it appears that goreleaser has been updated to use go modules, and when I try to do this I get the error:
`could not find project Gopkg.toml, use dep init to initiate a manifest
The command '/bin/sh -c go get -d github.com/goreleaser/goreleaser &&     cd $GOPATH/src/github.com/goreleaser/goreleaser &&     dep ensure -vendor-only &&     make setup build' returned a non-zero code: 1`

**To Reproduce**

See above.

**Expected behavior**

The documentation should be updated to provide instructions for using goreleaser with `go get` now that the project uses Go modules.

**Environment (please complete the following information):**

Attempted to build in `golang:1.11-alpine` Docker image.

Add any other context about the problem here.
