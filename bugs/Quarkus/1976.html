Title

Quarkus resteasy-reactive (RestClientBuilder) HTTP2

Description
### Describe the bug

We are in the process of upgrading our services to http2. We use the RestClientBuilder client because the url of our services are dynamic. Normally HTTP2 is supported by the restEasy-reactive client. It works when the url is static (using **@RestClient** and 
 the url is static in application.poperties. **quarkus.rest-client."org.NetworkService ".uri=[URL]
 but if you use   **RestClientBuilder.newBuilder().baseUrl(new URL("[URL] .build(OurService.class)**					   

```
 quarkus.rest-client."org.NetworkService".uri=[URL]
 quarkus.rest-client.http2=true
```

```
@RestClient
NetworkService netService;

public List getNetwork() {
 return netService.getNetwork();
}
````
HTTP2 Work  

and with RestClientBuilder

```
extensionsService =  RestClientBuilder.newBuilder()
			           .baseUrl(new URL("[URL]
			           .build(NetworkService.class);
extensionsService .getNetwork()
```
even if  **quarkus.rest-client.http2=true** is set we always use Http1 instead of Http2

HTTP2 not work in this case


configuration application.properties
