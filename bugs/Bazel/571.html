Mac: Warning about /dev/null having been modified

Description
### Description of the problem / feature request:

cc @ola-rozenfeld 

I'm using 0.10.1 plus cherry-picks of fixes for #3360 — I cherry-picked   and   onto the top of 0.10.1.

When compiling a large project on Mac (sorry, I don't have a small repro case for you), I saw this warning about ten times:

    WARNING: /dev/null was modified during execution
