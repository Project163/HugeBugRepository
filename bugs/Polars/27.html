Title

`pl.from_repr` doesnt respect sign of `duration` type

Description
### Checks

- [x] I have checked that this issue has not already been reported.
- [Link: x] I have confirmed this bug exists on the [latest version] of Polars.

### Reproducible example

```
python
pl.from_repr(
        """
        shape: (7, 2)
        ┌──────────────┬──────────────┐
... [Log Snipped] ...
        """
    )
```

### Log output

```
shell
shape: (7, 2)
        ┌──────────────┬──────────────┐
        │ time_offset  ┆ normal_curve │
        │ ---          ┆ ---          │
... [Log Snipped] ...
        │ 3h           ┆ 0.011109     │
        └──────────────┴──────────────┘
```

### Issue description

does no respect sign of duration

### Expected behavior

should respect sign for the `duration` type

Discussion
- fyi, easy temp fix:
```
pl.from_repr(  
        """
        shape: (7, 2)
        ┌──────────────┬──────────────┐
        │ time_offset  ┆ normal_curve │
... [Log Snipped] ...
        """
    ).with_columns(pl.col("time_offset").mul(pl.Series([-1, -1, -1, 1, 1, 1, 1])))
```
