Title

Description
something is up local to the selectinload option on this one, taken from #4421

```
#!/usr/bin/env python

import sqlalchemy

from sqlalchemy import Column, ForeignKey, Integer, create_engine, orm

child = session.query(mapped_child).options(orm.selectinload('parent')).first()
```
