Title

RSS feeds use relative links (missing instance address)

Description
### Description

The Gitea RSS links are relative, so they seem to be nonfunctional outside of web browsers assuming the links are meant to be clicked.

Example item from try.gitea.io:

```
xml
     
       Mikaela pushed to <a href="/Mikaela/gist-manual/src/branch/master">master</a> at <a href="/Mikaela/gist-manual">Mikaela/gist-manual</a> 
       /Mikaela/gist-manual/commit/  
       <a href="/Mikaela/gist-manual/commit/ "> </a>
matrix/m.room.join_rules: add FluffyChat to knock_restricted 
... [Log Snipped] ...
       Sun, 07 Aug 2022 22:25:56 +0000 
     
```

I got this from `curl -LO [URL] and the issue has been observed using Limnoria IRC bot and Maubot RSS plugin on Matrix.

1.17.1
