Discussion
- In TestExecDriver for each test it fails to compare the result files with static files because the content of the result file is double then expected. 
On further investigation found that the static initialization block in TestExecDriver is executed twice, hence for second run src table is updated 2 times.

- Couple of probable fixes are: 
1. Not to use TestExecDriver reference in TestOperators class. 
2. Write the code for cleanup in TestExecDriver.class. 
The second option will need an explicit call for cleanup from TestOperators as it is a static call. I am going with the first option as only code used is creating instance of ExprNodeColumnDesc.
