Title

Transactions do not work in Cakephp 2.6 with TranslationBehaviour

Description
There was apparently a change in the way model saving works in CakePHP 2.6 beta, which seems to cause problems with transactions and behaviours. If model uses TranslationBehaviour and atomic is set to false in saveAll or saveAssociated call, the TranslationBehaviour doesn't respect this setting, but starts new transactions.
Discussion
- In 2.x option `'atomic'` has also been added to `Model::save()` too, which is `true` by default and enables transasactions. So that might be the cause of the issue.

Seems like the value of `atomic` specified for `saveAll()`, `saveAssociated()` isn't being passed to `save()`.
- Actually the `'atomic'` value for `saveAll()` / `saveAssociated()` is being passed to `save()`. Can you provide some sample code and the queries generated to reproduced this issue.
