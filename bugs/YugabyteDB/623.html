Title

[Backups] Incorrect duration of phases in the yb_backup summary

Description
Jira Link: [Link: DB-595]
### Description

For the test:
```
time.sleep(1)
self.timer.log_new_phase("phase 1 body")
time.sleep(3)
self.timer.log_new_phase("phase 2 body")
time.sleep(5)

self.timer.print_summary()
```
It shows:
```
[app] Summary of run:
0:00:01 : PHASE 1 : phase 1 body
0:00:03 : PHASE 2 : phase 2 body
Total runtime: 0:00:09
```
Expected:
```
[app] Summary of run:
0:00:03 : PHASE 1 : phase 1 body
0:00:05 : PHASE 2 : phase 2 body
Total runtime: 0:00:09
```
