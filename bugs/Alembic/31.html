Title

bulk_insert example does not import op like other examples

Description
**Migrated issue, originally created by markhildreth ([Link: @markhildreth])**

In most other examples in the [Link: operation documentation], `op` is inserted. For example, `create_check_constraint` shows:

```
from alembic import op
from sqlalchemy.sql import column, func

op.create_check_constraint(
    "ck_user_name_len",
    "user",
    func.len(column('name')) > 5
)
```

However, the [Link: bulk_insert] example does not show op being imported, or use with the `bulk_insert` function. The `from alembic import op` line should be added, and the `bulk_insert` should be changed to `op.bulk_insert` to make it more like the other examples.
