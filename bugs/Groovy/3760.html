Title

JSP style loop in StreamingTemplateEngine template results in TemplateParseException

Description
The example below works as expected when run in Groovy 2.5.8, yet it fails when run in Groovy 3.0.3 

   

   
  
 
TemplateEngine engine =  new  StreamingTemplateEngine()

Template template = engine.createTemplate('''
<ul>
    <% items.each { %>
    <li>${it}</li>
    <% } %>
</ul>
''')

println template.make([items : [1,2,3,4]])
 
  
   

 Expected output (and the output 2.5.8 yields): 

   
  
 
<ul>
    
    <li>1</li>
    
    <li>2</li>
    
    <li>3</li>
    
    <li>4</li>
    
</ul>
 
  
   

 Exception 3.0.3 gives: 

   
  
 Exception in thread "main" groovy.text.TemplateParseException: Template parse error 'Unexpected input: '{'; Expecting RBRACE ' at line 3, column 27
         2:         <ul>
     --> 3:             <% items.each { %>
         4:             <li>${it}</li>
Discussion
- A workaround would be to use SimpleTemplateEngine or GStringTemplateEngine - though they may not be as performant in some scenarios.
- The issue can illustrated outside templates and seems to be an issue with the grammar. It can be simplified to: 
  
 
 null .each { ; x = 0 }
 
  
 which passes under 2.5.x but fails in 3+ with: 
  
 Unexpected input: '{'; Expecting <EOF> at line: 1, column: 11
 
  
 It can be fixed by removing the unneeded semicolon. I don't know whether we could adjust StreamingTemplateEngine to do that but seems worth seeing if the grammar can be tweaked first.
