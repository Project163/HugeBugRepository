Title

False positive "Exception type must be derived from BaseException"

Description
Mypy incorrectly emits an error when using a variable typed as a variadic tuple of exception classes in an `except` clause. `fn1` and `fn2` below trigger an error:

```
from typing import Tuple, Type, Union

def fn1(exc: Tuple[Type[Exception], ...]) -> None:
    try:
        1 / 0
... [Log Snipped] ...
    except exc:  # no error
        pass
```

I came across this trying to add types to a function similar to `@retry()` from [URL]
Discussion
- Good find. Looks like these cases can all easily be added to `visit_except_handler_test()` in checker.py. (The variadic tuple case should go in the initialization of `test_types`, the union case should go in the if/elif sequence.)
