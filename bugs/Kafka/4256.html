Title

Fix typo in state-change log filename after rotate

Description
The log4j2 config file was incorrectly rotating the state-change.log to  stage-change.log. [date]   (changing the filename from state to stage). The below PR corrects the file name for rotated logs. 

 After this change is applied, the log4j2 config will not take any actions with previously-created  stage-change.log. [date]   files. These may need to be manually removed by users.
