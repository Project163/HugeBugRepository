Title

Incorrect "unused-variable" for nonlocals

Description
Originally reported by: **Antony Lee (BitBucket: [Link: anntzer], GitHub: @anntzer?)**

---

Nonlocal uses are missed, e.g

```
#!python
def f():
    x = True
    def set(val):
        nonlocal x
... [Log Snipped] ...
        return x
    return set, get
```

triggers an unused-variable warning on x.
