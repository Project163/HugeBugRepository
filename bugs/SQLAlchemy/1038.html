Title

Values do not convert / coerce properly

Description
**Describe the bug**
When using `Values`, with a specific `Column`, I would expect the `data` entries to be converted into something acceptable for the provided `Column`, just like we assign a value to a given `Column`. Instead we are getting `NULL`.
This happens with regular / sqlalchemy `Enum` and also with Numpy strings (`str_` types)

**To Reproduce**
Run the code below:

```
py
from sqlalchemy import String, values, column
import numpy
import enum
from sqlalchemy import Enum as SQLEnum
... [Log Snipped] ...
print("\nEnum - Fixed")
print(values(column("value", SQLEnum(MyEnum)), name="enums", literal_binds=True).data([(_enum.name,) for _enum in enums]))
```

**Output:**
```
py
Numpy - Issue
VALUES (NULL), (NULL)

Numpy - Fixed
... [Log Snipped] ...
Enum - Fixed
VALUES ('A'), ('B')
```

**Versions.**
 - OS: OSX
 - Python: 3.8
 - SQLAlchemy: 1.4.01b
 - Database: PostgreSQL
 - DBAPI: psycopg2
