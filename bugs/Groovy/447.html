Title

DGM.getAt(Collection, String) should not flatten result

Description

    
Discussion

    
- p 209 of GINA states that list.property is equal to: 
list.collect 
{ item -> item?.property }
 i.e. is the same as list*.property if property isn't a property of list itself. 

 If this is indeed the case, then we should change DGM.getAt(Collection, String) from: 
  
             if  (value  instanceof  Collection) {
               answer.addAll((Collection) value);
           }  else  {
               answer.add(value);
           }
 
  

 to: 
  
            answer.add(value);
 
  

 I.e. we should remove the flattening behaviour.
- Sounds coherent to me.
