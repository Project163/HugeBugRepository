Title

Tuples with same collection values do not match

Description
Example: 
  
 
Tuple.tuple(1,[2]) == Tuple.tuple(1,[2])
===>  false
Discussion
- First found out the problem via failed unit tests after upgrading Groovy from 2.5.14 to 3.0.7.  
  
 
Groovy Shell (2.5.14, JVM: 1.8.0_241)
Type  ':help'  or  ':h'   for  help.
-------------------------------------------------------------------------------
groovy:000> >  new  Tuple2(1,[2]) ==  new  Tuple2(1,[2])
 new  Tuple2(1,[2]) ==  new  Tuple2(1,[2])
===>  true
- I checked that the problem exists since 3.0.0 
  
 
Groovy Shell (3.0.0, JVM: 1.8.0_241)
Type  ':help'  or  ':h'   for  help.
-------------------------------------------------------------------------------
groovy:000> >  new  Tuple2(1,[2]) ==  new  Tuple2(1,[2])
 new  Tuple2(1,[2]) ==  new  Tuple2(1,[2])
===>  false
- Hmmm...  Tuple  now implements  Comparable  which it didn't before: 
 [URL]

 But we mistakenly assume that the tuple components themselves are comparable: 
 [URL]
which  ArrayList  is not. We'll have to re-work that a little.
