Title

BaseStringHelper::truncateHtml calls HTMLPurifier lexer with null $context

Description
### What steps will reproduce the problem?

Calling `StringHelper::truncateWords($model->body, 20, '...', true)` on server without php-xml package installed (DOMDocument class missing in php).
### What is the expected result?

StringHelper truncates $model->body to 20 words
### What do you get instead?

 PHP Fatal Error – yii\base\ErrorException
Call to a member function register() on null in /basepath/vendor/ezyang/htmlpurifier/library/HTMLPurifier/Lexer/DirectLex.php at line 79 
### Additional info

[Link: BaseStringHelper::truncateHtml line 157] calls HTMLPurifier lexer->tokenizeHTML with $context set to null. It works in case of DOMLex (which depends on DOMDocument class) but in case it uses DirectLex, it tries to [Link: call register method on null context]. I assume DirectLex is poorly programmed here but I think a fix should be also considered on the yii2 side, maybe something like

```
$lexer = \HTMLPurifier_Lexer::create($config);
$context = new \HTMLPurifier_Context;
$tokens = $lexer->tokenizeHTML($string, $config, $context);
```

in truncateHtml() would be sufficient.
