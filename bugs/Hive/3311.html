Title

ANALYZE TABLE statement fails on postgres metastore

Description

 Current JDBC driver doesn't implements this method.

Discussion
- A quick fix should be to call this method with value 0. This doesn't throw exception in this case.
- Using this property seems to solve the problem. 
  
 <property>
  <name>hive.stats.jdbc.timeout</name>
  <value>0</value>
</property>
 
  
 More a hack than a solution IMHO.
