Title

Avoid failing queries when epoch changes and replica goes up/down

Description
To make sure that we got responses from the correct replicas we recompute the replica plan for queries if the epoch changes during the query to make sure we got responses from a quorum of the nodes in the recomputed replica plan.  

 Problem is that this recomputation is filtering away down nodes, so we can fail queries if the coordinator marks a replica down during the query and the epoch changes, even though the placements have not changed.
