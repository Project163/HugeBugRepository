Title

Bower package does not contain unpacked modules

Description
In order to use any imported modules other than the main one (e.g. BrowserHistory, which is essential to a lot of people's setups), the unpacked Javascript files in `lib/` need to be present in the distributed build. While this is the case in the NPM package, it is not in the Bower package:

Good:

```
asa@asa-thinkpad:~/src/bower_test$ ls -R node_modules/react-router/lib/
node_modules/react-router/lib/:
AsyncUtils.js      DOMUtils.js     History.js  Location.js       NavigationTypes.js  Route.js               RouteUtils.js             State.js           umd
BrowserHistory.js  experimental    index.js    MemoryHistory.js  PropTypes.js        RouterContextMixin.js  RoutingUtils.js           TransitionHook.js  URLUtils.js
DOMHistory.js      HashHistory.js  Link.js     Navigation.js     Redirect.js         Router.js              ScrollManagementMixin.js  Transition.js
... [Log Snipped] ...
node_modules/react-router/lib/umd:
ReactRouter.js  ReactRouter.min.js
```

Bad:

```
asa@asa-thinkpad:~/src/bower_test$ ls -R bower_components/react-router/lib/
bower_components/react-router/lib/:
umd

bower_components/react-router/lib/umd:
ReactRouter.js  ReactRouter.min.js
```
Discussion
- (This is in 1.0.0-beta3.)
- Please use NPM instead of Bower. We're going to remove Bower support in the next release.

See #1864
- Makes sense. Better no support than broken support.
