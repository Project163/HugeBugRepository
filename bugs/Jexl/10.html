Title

Div operator does not do integer division

Description
The "div" operator behaves the same as "/" - however it should do integer division according to the web-site: 

  [URL]
Discussion
- Just found out: the JSP 2.0 documentation states that "/" and "div" are equivalent in the expression language so perhaps it is the documentation that is wrong. 
The division will return a BigDecimal if either input is BigDecimal or BigInteger, but the division is rounded up. 

 Likewise, Velocity returns an integer if the operands are integers - but I'm not sure what rounding is applied. 

 It would be useful to have an IntegerDivide operator, but perhaps it needs a new token.
