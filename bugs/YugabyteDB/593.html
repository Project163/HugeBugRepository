Title

[YSQL][Colocation] Disable combination of pre-splitting and colocation

Description
Jira Link: [Link: DB-378]
### Description

Colocation and tablet splitting are converse to each other and hence we should not allow splitting on colocated tables.

`cl_pitr=# CREATE TABLE e (id int PRIMARY KEY, first_name TEXT, last_name TEXT) WITH (colocated = true) SPLIT INTO 10 TABLETS;
CREATE TABLE`
