Title

Cookie with unknown path is falsely rejected by ZAP

Description
Application is running on app.domain.com
During authentication a session cookie is set by identity provider on idp.domain.com with Path=/private and domain=.domain.com. Zap seems to try to validate the path which does not exist for idp.domain.com and rejects the cookie. 
2017-11-24 06:46:09,524 [ZAP-SpiderThreadPool-0-thread-1] WARN  HttpMethodBase - Cookie rejected: "ID_TEST=yyyy". Illegal path attribute "/yyy". Path of origin: "/sso/login"

comment from #websectools 
thc202 | it is, "we musn't allow the server to give us a cookie that doesn't match this path" we should remove that (latest rfc does not pose any restriction, and newer version of the library doesn't either)
