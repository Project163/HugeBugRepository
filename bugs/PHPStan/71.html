- Hi @staabm.

There is no error if you add
```
assert(array_key_exists('token', $data));
```
it also works by changing the order
```
assert(array_key_exists('password', $data));
assert(array_key_exists('email', $data));
$data['token'] = $_POST['token'];
```

Things is that
```
$data = $_POST['resetPassword'];
$data['token'] = $_POST['token'];
\PHPStan\dumpType($data);
```
is considered as `mixed` and then only the following array_key_exists are narrowing the type.

I dunno if it's worthy to allow phpstan understanding type like
```
mixed&hasOffset('token')
```
or if you should just write
```
$data = $_POST['resetPassword'];
assert(is_array($data));
$data['token'] = $_POST['token'];
```
