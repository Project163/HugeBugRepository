Title

Double "_protect_identifiers" when calling update() method without parameters.

Description
If you set the table to update with the from() method and then call the update() method without parameters, the table to update is double escaped: `prefix_`prefix_table`.

Example:

``` php
ci()->db->from('table')->set('field', 'value')->update();
```
Discussion
- Confirmed, even though `update()` is not designed to be used with `from()`.
- Maybe it makes no sense in a query like the one I wrote, but I think it may make sense when you have a method that returns a query object, with it you could want to get the result, delete the rows or just perform an update.
