Title

psalter incorrectly removes variable assignment in loop

Description
For code similar to one showed below, using `psalm --alter --issues=UnusedVariable` incorrectly removes the `$first = false;` statement inside the loop.

```
$first = true;
foreach ($array as $item) {
    if ($first) {
       //do something
    }
    $first = false;
}
```

- SO

Psalm currently supports three different ways of annotating arrays:

- the generic `array `
  - which has a subtype `list ` for arrays where all items are indexed by sequential integers starting at zero
- the object-like array type `array{foo: string, bar: int}`

Calling `array_reverse` [Link: without that second argument] with both `list ` and `array ` returns a `list `.

That PR proposes adding another subtype to `array ` of `associative-array ` where Psalm will preserve those key-value associations. Importantly, a property of type `list` could not be assigned an `associative-array`-typed value and vice-versa.

So this code would not pass Psalm's checks:

```
php
class A {
  /** @var associative-array  */
  public array $map;
```
