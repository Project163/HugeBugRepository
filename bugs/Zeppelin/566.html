Title

Run paragraph on enter when z.select form value changed

Description
PR#1647 disabled instant on select value change. 
In report view mode, the only way to apply changed value is running whole note. 
There should be a way to run with new selected value in report mode and I suggest to enable run by hitting 'enter' key after selection.
