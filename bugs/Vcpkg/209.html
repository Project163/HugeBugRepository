- Ok, good news. I have fixed all these three issues.
For x86/arm I added next lines to the triplets:
```
set(VCPKG_CXX_FLAGS -DNO_RECVMMSG)
set(VCPKG_C_FLAGS -DNO_RECVMMSG)
```
Looks like OpenSSL doesn't detect availability of the libc functions (I'm not very familiar with Perl and OpenSSL configure file, so if anyone points me to the place where they check for the functions - I'll happily add the patch to the OpenSSL upstream).

For armv6 the situation is more interesting: they have added a `quicserver` tool that looks like not needed at all when building an OpenSSL library, and used only for testing. They have no separate flag to disable building this particular utility, so I have to patched that in the next PR: #35838
