Title

ApcEngine not compatible with some apcu versions

Description
When doing a simple cache clear like this:

``` php
Cache::clear(false, 'default')
```

I receive a lot errors like this:

```
Notice (8): Undefined index: info [APP/Vendor/cakephp/cakephp/lib/Cake/Cache/Engine/ApcEngine.php, line 132]
```

I've discovered that in apcu (Not sure starting from which version) the 'info'-key was changed to 'key', causing the undefined index.

A bug report exists here: [URL]

Maybe ApcEngine should check for both 'info' and 'key'? 

I'm using PHP 5.5.9 with apcu 4.0.6, Ubuntu 14.04 and CakePHP is the latest 2.5.2.
