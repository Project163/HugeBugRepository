Title

SslHandler duplicates SSLHandshakeException

Description
With Netty 3.6.5, when a hanshake fails because of a non trusted certificate (X509TrustManager fails checkClientTrusted), a duplicated SSLHandshakeException is thrown.

SslHandler, fires an exception if the handshake fails (line 1546):

```
        handshake().addListener(new ChannelFutureListener() {
            public void operationComplete(ChannelFuture future) throws Exception {
                if (!future.isSuccess()) {
                    fireExceptionCaught(future.getChannel(), future.getCause());
```

But the same exception is also thrown by the unwrap method after setting the handshake failure (line 1294):

```
        setHandshakeFailure(channel, e);
        throw e; 
```

Maybe the handshake listener shouldn't fire an exception? It seems this code has been introduced by #358.
