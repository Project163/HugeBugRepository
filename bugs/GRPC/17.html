Update from @jtattermusch: it seems that this is happening for bazel 0.23+ (build works fine for bazel 0.20, 0.21, 0.22 based on my testing)
Discussion
- The issue here is that the WORKSPACE file under /usr/local which is specified in this error message is expecting only a grpc_archive rule while bazel is supplying a http_archive rule as well as a grpc_archive rule. The workaround here is to remove the else condition that fails the build if it doesn't receive a grpc_archive rule.
This way WORKSPACE file would ignore the http_archive rule and proceed with compilation on receiving the grpc_archive rule
Basically - 
 ```
 for dep in rem:
    rule = dep.pop("rule")
    if "grpc_archive" == rule:
      grpc_archive(**dep)
    else:
       fail("Unknown loading rule %s for %s" % (rule, dep))

```
To

 ```
 for dep in rem:
    rule = dep.pop("rule")
    if "grpc_archive" == rule:
      grpc_archive(**dep)
```
