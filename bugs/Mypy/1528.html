Title

Spurious type error with async function + generic callable argument + optional return type

Description
Here's a minimized repro:

```python
from collections.abc import Callable

async def f[Link: T] -> T | None:
    return None

async def f2[Link: T] -> T | None:
    return await f(g)
```

```
console
$ mypy bug.py
bug.py:7: error: Argument 1 to "f" has incompatible type "Callable[[T], bool]"; expected "Callable[[T | None], bool]"  [arg-type]
Found 1 error in 1 file (checked 1 source file)

... [Log Snipped] ...
$ uname -v
Darwin Kernel Version 24.6.0: Mon Jul 14 11:28:30 PDT 2025; root:xnu-11417.140.69~1/RELEASE_ARM64_T6030
```

An alternative type checker works fine with the above code:

```console
$ pyright bug.py
0 errors, 0 warnings, 0 informations
$ pyright --version
pyright 1.1.404
```

Close variations seem to work fine:

**No async**

```python
from collections.abc import Callable

def f[Link: T] -> T | None:
    return None

def f2[Link: T] -> T | None:
    return f(g)
```

```console
$ mypy bug.py
Success: no issues found in 1 source file
```

**No generic in callable argument**

```python
from collections.abc import Callable

async def f[Link: T] -> T | None:
    return None

async def f2[Link: T] -> T | None:
    return await f(g)
```

```console

Success: no issues found in 1 source file
```

**No optional return type**

```python
from collections.abc import Callable

async def f[Link: T] -> None:
    return None

async def f2[Link: T] -> None:
    return await f(g)
```
