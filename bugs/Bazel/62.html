Title

empty file in {new_,}http_archive results in no caching across Bazel server restarts

Description
Any actions with empty files from a new_http_archive etc get rebuilt every time the Bazel server is restarted because the files get re-extracted which changes their timestamps, which is what [Link: ActionMetadataHandler] uses to check if empty files have changed. It's not a problem for non-empty files because changes in those are identified using a hash of the file contents.

In my particular case (files in Linaro GCC tarballs which don't seem to do anything useful), removing the files as inputs is an easy workaround. However, that might be a problem in some cases and it's really hard to figure out what the problem is.

Here's a patch which adds a failing test (please do commit it along with a fix):
