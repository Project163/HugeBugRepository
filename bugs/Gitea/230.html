## Description
When disabling the deletion of a branch in update's hook on a repository, Gitea perform a "git branch -d  " so it does not trigger the hook.

It should use "git push --delete    " or "git push   : " like the creation of a branch via the UI.
Discussion
- Using remote push would require local checkout that would be quite performance killer. I think this way is better
