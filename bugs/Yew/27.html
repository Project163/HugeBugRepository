Title

yew/examples/function_todomvc -> unable to exit edit mode of an item

Description
**Problem**
After double-clicking an item to edit, there is no way to exit edit mode. The behavior is different from the non-function todomvc.

**Steps To Reproduce**
Steps to reproduce the behavior:
1. Go to yew/examples/function_todomvc
2. Run 'trunk serve'
3. Open browser to localhost:8080
4. Click in the text input field.
5. Enter text and hit Return.
6. Double Click on the text for the item and edit it and hit Return.


**Expected behavior**
The item should exit edit mode, as it does in yew/examples/todomvc.

Discussion
- Can confirm this issue does exist. I've done some digging and discovered that it seems the Entry component is not getting rerendered when its description changes.

When the component is rendered it's set to a not being edited state, when the description is submitted by pressing enter it should be re-rendered, and thus into its regular state. The description is successfully updated when you press enter, but for some reason, the component just doesn't rerender when it's prop is updated.
