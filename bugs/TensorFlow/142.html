Discussion
- Yes, I think is a result of `np.array(x)` returning a different array type (when `x` is a Python `int`) on Windows and Linux. If I remember correctly, on Windows the array will have type `np.int32` and on Linux the array will have type `np.int64`. This behavior in `Dataset.from_generator()` is inherited from `tf.py_func()`, which performs the NumPy conversion automatically (as discussed in #8196). To write platform independent code that handles this case, you should explicitly wrap the return value in a NumPy array.
- On second thoughts... I think this is really easy to fix. I'm working on a patch.
