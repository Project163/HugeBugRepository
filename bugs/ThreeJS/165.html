Title

OBJLoader2 loadMtl Does Not Accept Array Buffer

Description
##### Description of the problem

[Link: OBJLoader2 .loadMtl docs] state content is text or array buffer, however array buffer is not supported. `_loadMtl` function in `OBJLoader2` calls the following:

`processMaterials(Validator.isValid(resource.content) ? mtlLoader.parse(resource.content) : null);`

`mtlLoader.parse` doesn't take an array buffer, just text.

##### Three.js version
r92
