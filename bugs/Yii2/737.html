Title

ActiveForm - *attribute* is not defined

Description
### What steps will reproduce the problem?

Reseting any ActiveForm (clearing errors). The `attribute` variable does not exist within the scope.

### What is the expected result?

JS should find either container or attribute.

### What do you get instead?

Error message `attribute is not defined`.

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.14
| PHP version      | any
| Operating system | any

This is line to be fixed:

[URL]

**The `attribute` variable does not exist within the scope**. The line:
`$input = findInput($form, attribute),`

should read:
$input = findInput($form, this),

since `this` refers to each element from collection `data.attributes` - but please verify, I have not tested newly introduced feature which caused this error.
