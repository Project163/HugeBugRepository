Title

.update() does not update the dataset label colour

Description
Today I came across a weird bug where some chart types are not updating the dataset label colour when `update();` is called. Well, they are updating, but they are always one colour behind...

The following charts **show** this bug:

- Bar
- Horizontal Bar
- Doughnut
- Pie
- Polar Area
- Bubble

The following charts **do not show** this bug:
- Line
- Radar
- Scatter

Gif below:

[Image: vuechartjs]


### Expected Behavior

`update();` should update the dataset label colour for all charts.

### Actual Behavior

The above chart types do not update the dataset label colour.

### Workarounds

Destroying and recreating the chart each time the colour changes works, but is expensive.
Double calling `update();` also works!

Reverting from 2.9.x to ChartJs 2.8.0 removes the issue.

Seems to me like the label colour is being set after the `update()` method has done its thing for some charts.

### Environment
- 2.9.x
