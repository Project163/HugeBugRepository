Discussion
- Dev Design 

 Currently kylin metadata about library table columns are in uppercase, so converting case sensitive input parameters to uppercase can avoid errors. 

 The api inputs are based on the ModelRequest class and include the following fields that need to be converted to uppercase: 
  fact_table 

 simplified_dimensions#column 

 join_tables#table 

 join_tables#join#foreign_key 

 join_tables#join#primary_key 

 join_tables#join#simplified_non_equi_join_conditions#foreign_key 

 join_tables#join#simplified_non_equi_join_conditions#primary_key
