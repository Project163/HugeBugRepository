Title

Item "type" of "Union[Type[Foo], Type[Bar]]" has no attribute "x"

Description
```
# mypy 0.530
foo.py:14: warning: Returning Any from function declared to return "int"
foo.py:14: error: Item "type" of "Union[Type[Foo], Type[Bar]]" has no attribute "x"
```

```
python
from typing import *

class Foo(NamedTuple):
    a: int
... [Log Snipped] ...
def foo(t: Type[Union[Foo, Bar]]) -> int:
    return t.x()
```

If I make them usual classes instead of namedtuples, it works
Discussion
- Good catch. Looks like the code that checks for class attributes doesn't handle unions yet.
- This has nothing to do with unions. Accessing x in `Type[FOO]` does not work either, specifically for NamedTuple. Probably something about the combination of TypeType and TupleType.
- ... [Middle Discussions Snipped for Brevity] ...
- @Daenyth 

Yes they aren't yet.  They are planned for Python 3.7.
- This also happens for classes that aren't named tuples:

```
py
from typing import Tuple, Type

class C(Tuple[int, str]):
    @classmethod
... [Log Snipped] ...
t: Type[C]
t.f()  # "Type[C]" has no attribute "f"
```

I'm increasing priority to normal because the above example seems quite reasonable.
