Title

Instance::ensure() doesn't check type if 'class' field is presented in $reference param

Description
### What steps will reproduce the problem?
Make the code like that:

```
php
$instance = \yii\di\Instance::ensure(
    [
        'class' => \foo\Bar::className(),
        'param1' => 'value 1',
... [Log Snipped] ...

var_dump($instance instanceof \yii\db\Connection);
```
### What is the expected result?

Thrown `InvalidConfigException`

### What do you get instead?

The "`false`" string

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.11
| PHP version      |7.1
| Operating system |Fedora release 25 (Twenty Five)
Discussion
- Here's a test:

```php
public function testExceptionInvalidDataTypeInArray()
    {
        $this->setExpectedException('yii\base\InvalidConfigException', 'Invalid data type: yii\db\Connection. yii\base\Widget is expected.');
        Instance::ensure([
            'class' => Connection::className(),
        ], 'yii\base\Widget');
    }
```
