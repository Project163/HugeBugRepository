Title

CompactObjectInputStream fails to resolve interfaces which leads to NPE

Description
In CompactObjectInputStream we changed to use ObjectStreamClass.lookup(..) to find the ObjectStreamClass for a class name. Unfornally this does not work for interfaces, see also NETTY-419.

We was using ObjectStreamClass.lookupAny(..) in 3.2.6.Final but replaced it by ObjectStreamClass.lookup(..) to be compatible with java5. Unfortunally this breaks it and makes it un-usable. We should just use ObjectStreamClass.lookupAny and add some javadocs that explain that it only works on jdk6+.
Discussion
- As I commented in the commit, we can continue using `lookup()` and write fat descriptors for interfaces.
