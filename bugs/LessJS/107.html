Title

Guard on css style applies only on last selector

Description
If the selector contains multiple css styles, guard applies only on last of them. However, only last selector is allowed to have guard.

Less: guard applies only on last selector:

```
@variable: 1;
.guarded, .false when (@variable=2) {
  property: value;
}
```

compiles into:

```
.guarded {
  property: value;
}

```

However, following causes compilation error:

```
@variable: 1;
.guarded when (@variable=1), .both when (@variable=1) {
  property: value;
}
```

error:

```
SyntaxError: Guards are only currently allowed on a single selector. in node.js-1.6.0\test.less on line 2, column 30:
1 @variable: 1;
2 .guarded when (@variable=1), .both when (@variable=1) {
3   property: value;
```

I think it would me more consistent it guards would either:
- 1. apply to all selectors in style,
- 2.  be allowed after any selector.

I prefer the option 1, but both of them are ok.

Tested on windows node.js  1.6.0.
