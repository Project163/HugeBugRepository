Title

Error message for "cannot instantiate abstract class" should indicate how many methods

Description
E.g. I got this message:

```
test-data/samples/crawl.py:824: error: Cannot instantiate abstract class 'AbstractEventLoop' with abstract attributes 'add_reader', 'add_signal_handler', 'add_writer', 'call_at' and 'call_exception_handler'
```

But in fact there are a total of 38 abstract methods in that class. It would be nice if `format_string_list()` could replace some part of a large list with an ellipsis and perhaps an indication of how many items it suppressed.
