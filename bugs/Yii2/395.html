Title

AR::findOne($condition) transformed into IN

Description
The code 

``` php
User::find()->where(['email'=>2, 'auth_key'])->one()
```

performed to 

Ok.

The code

``` php
User::findOne(['email'=>2, 'auth_key'])
```

produce

``` sql
SELECT * FROM `user` WHERE `id` IN (2, 'auth_key')
```

Strange. I came across this when I wanted to run

``` php
User::findOne(['email'=>2, new \yii\db\Expression('username IS NOT NULL')
```

and get 

``` sql
SELECT * FROM `user` WHERE `id` IN (2, username IS NOT NULL)
```

p.s I know about need run

``` php
User::find()->where(['email'=>2])->andWhere(new Expression('username IS NOT NULL'))->one()
```

But `findOne` behaves strangely in the case. And I didn't find the description of this behavior in any documentation.
