Title

Parent directories of unignored files keep being included and immediately ignored again

Description
All credits to cosas for being tenacious and providing perfect logs, until I finally understood the issue: [URL]

In #4811 the scanner was made to include items below ignored parent directories, but I didn't adjust the model side of things. In the model the db is walked and to detect deleted and newly ignored files. Ignored parents of included items must be filtered out as well.

Reproducer (sloppy, unit test already exists):

1. Add ignores like this
```
!foo
*
```
2. Create a file `/bar/foo`.

Result: On every scan, `bar` features as modified in the recent changes list.  

Expected: `bar` should feature once in that list, then a scan shouldn't do anything.
