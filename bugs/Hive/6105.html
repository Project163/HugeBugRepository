Title

Vectorization: Vectorized PTF operator should not set the initial type infos

Description
The Vectorized PTF operator is mistakenly setting the initial type infos for its output VectorizationContext.  It should not.  It is only creating a projection of the initial column names/type infos from ReduceSink (i.e. keys, values) plus scratch columns for output columns for which the type infos are already known.
