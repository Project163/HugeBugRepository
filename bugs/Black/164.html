Title

`wrap_long_dict_value_in_parens` can introduce unnecessary nesting for dicts in dicts

Description
Originally reported at [URL]

Repro:
```
class Random:
    def func():
        random_service.status.active_states.inactive = (
            make_new_top_level_state_from_dict(
                {
... [Log Snipped] ...
            )
        )
```

Enabling just `wrap_long_dict_value_in_parens` turns this into:
```
class Random:
    def func():
        random_service.status.active_states.inactive = (
            make_new_top_level_state_from_dict(
                {
... [Log Snipped] ...
            )
        )
```
