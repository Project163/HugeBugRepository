Title

JOBS testsuite in WebHCat E2E tests does not work correctly in secure mode

Description
JOBS testsuite performs operations with two users test.user.name and test.other.user.name. In Kerberos secure mode it should kinit as the respective user. 
NO PRECOMMIT TESTS
Discussion

	 kinit with relevant user between individual tests
