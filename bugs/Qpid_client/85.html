Title

ObjectMessage does not always snapshot the store value

Description
In some cases the ObjectMessage does not take or return a snapshot of the stored value allowing for changes to one instance being reflected in the other which is not in accordance with the JMS spec.

   QPIDJMS-178   Ensure that the object stored in the ObjectMessage has a

as pre the spec.
