Title

Set empty query params should only reset the params portion, not the entire URL

Description
### Summary

When set an empty params to experimental_set_query_params(), the URL is set to the base URL.

Sample url: link.com/subfolder/?st_params=foo

Actual result: link.com

Expected result: link.com/subfolder/

### Snippet Code
```
import streamlit as st

params = {}
st.experimental_set_query_params(**params)
```
I'm not sure how to run a streamlit app with a link with a sub directory though.

`streamlit run my_code.py`will open a web page at "[URL]

### Is this a regression?
I don't know

### Debug info

- Streamlit version: 0.72.0
- Python version: 3.6.9
- OS version: Linux
- Browser version: Chrome

### Additional information
It looks like an additional check is needed here when updating the URL:
[URL]

Currently, when the query_param is empty, it's used '/', which will reset the URL.
Discussion
- Regression: I suspect not, more likely a discovered corner case.

Worth explicitly noting that apps served from subfolders do not lose the subfolder in the URL if the params are not empty.
- Hi @hieunguyen88 I am facing the same issue. I was able to reproduce it as follows.

Write a python file identical to what you have specified:
```py
import streamlit as st

params = {}
st.experimental_set_query_params(**params)
```

Run your streamlit app like so:
streamlit run   --server.baseUrlPath="example_folder"

When you open localhost:8501/example_folder it will redirect you to localhost:8501.
