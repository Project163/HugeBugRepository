Title

no-spaced-func tends to report on the wrong line with long function chains

Description
Given code like:

``` js
return _(foo)
  .map((el) => ...)
  .uniq()
  .value ();
```

Here the error is on the last line, but since `no-spaced-func` reports on the function callee, it reports on the `MemberExpression` and the output shows the first line.

Instead if the callee is a `MemberExpression`, it should report on `node.callee.property`, or alternatively `lastCalleeToken`.

**Edit**: Yes, I'd be willing to work on this.
