Title

REST Client is added to OpenAPI file

Description
### Describe the bug

When I use a REST Reactive client in my Quarkus project, which has a path annotation at the class level, it is automatically added to the OpenAPI specification. Unfortunately hiding it via `@Schema(hidden = true)` does not work.

Following client shows in OpenAPI specification:
```java
@RegisterRestClient
@Path("/get")
public interface VisibleHttpClient {

    @GET
    String get();
}
```

Following client isn't shown:
```java 
@RegisterRestClient
public interface InvisibleHttpClient {

    @GET
    @Path("/get")
    String get();
}
```


### Expected behavior

REST clients shouldn't be added to OpenAPI spec.
