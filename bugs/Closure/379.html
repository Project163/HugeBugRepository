Title

"invalid property id" errors using reserved names as IdentifierNames

Description
What steps will reproduce the problem? 
1. use a reserved word as an IdentifierName (vs Identifier)
i.e. a={class: 123, import: "abc"}
2. compile

 What is the expected output? What do you see instead? 
As "class" and "import" are used as an IdentifierNames and NOT as as Identifiers (as described in es5.github.com/#A.1).
Still the Closure Compiler returns
"JSC_PARSE_ERROR: Parse error. invalid property id at line 1 character 3"

It should be completely valid and works (at least) in FF 17 and Chrome 23 and IE 10.

A example similar to the one above is provided by Mozilla [URL]
