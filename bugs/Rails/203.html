Title

Every test run creates a new unique set of parallel databases

Description
### Steps to reproduce
1. Create a new app using Rails master and mysql (may apply to others too). I tested with:
    ```ruby
    gem "rails", github: "rails/rails", ref: " "
    ```
1. Run the tests, list the databases, repeat:
    ```
sh
    $ rails test
    ...

    $ mysql -u root -e "show databases;" | grep blah
... [Log Snipped] ...
    blah_test-9ad84ce2-b2cf-4774-9085-1d02256c0860
    blah_test-ed192204-5b14-4b85-b874-0accf893cee4
```

    ```
sh
    $ rails test
    ...

    $ mysql -u root -e "show databases;" | grep blah
... [Log Snipped] ...
    blah_test-cf265a0d-060c-4bf5-a80d-188ccc5fd13c
    blah_test-ed192204-5b14-4b85-b874-0accf893cee4
```

    ```
sh
    $ rails test
    ...

    $ mysql -u root -e "show databases;" | grep blah
... [Log Snipped] ...
    blah_test-e217d33b-447d-41d5-afda-bd0b44908ca6
    blah_test-ed192204-5b14-4b85-b874-0accf893cee4
```
### Expected behavior
Only one set (e.g. number of CPU cores) of parallel test databases are created.

### Actual behavior
A new set of unique databases are created with every test run.

### System configuration
**Rails version**: Edge ( )

**Ruby version**: 2.7.1
