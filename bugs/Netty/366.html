Title

Unexpected behaviour: ChannelFuture.setFailure(null) results in (ChannelFuture.isSuccess == true)

Description
I expected  ChannelFuture.setFailure(Throwable cause)  to always terminate the future with negative ending, especially because  (ChannelFuture.setFailure(null) == true) . This behaviour is not made fully clear in the documentation and as mentioned the return value for input  null  is  true  and for that the documentation states: "true if and only if successfully marked this future as a failure".
Netty: 3.9.2.Final

Cheers and best regards
Martin
Discussion
- My unit test:

 
import junit.framework.Assert;
import org.jboss.netty.channel.ChannelFuture;
import org.jboss.netty.channel.DefaultChannelFuture;
import org.junit.Test;
public class ChannelFutureTest {
    private final ChannelFuture future = new DefaultChannelFuture(createChannel(), false);
    @Test
    public void setSuccess() {
        Assert.assertTrue(this.future.setSuccess());
        Assert.assertTrue(this.future.isDone());
        Assert.assertTrue(this.future.isSuccess());
        Assert.assertNull(this.future.getCause());
    }
    @Test
    public void setFailure() {
        Assert.assertTrue(this.future.setFailure(new IllegalStateException()));
        Assert.assertTrue(this.future.isDone());
        Assert.assertFalse(this.future.isSuccess());
        Assert.assertNotNull(this.future.getCause());
    }
    @Test
    public void setFailureWithoutException() {
        Assert.assertTrue(this.future.setFailure(null));
        Assert.assertTrue(this.future.isDone());
        Assert.assertFalse(this.future.isSuccess());
        Assert.assertNull(this.future.getCause());
    }
}
