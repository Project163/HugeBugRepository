Title

Bytecode cache needs to expire when __debug__ changes

Description
Originally reported by: **Dag Odenhall (BitBucket: [Link: dag], GitHub: [Link: dag])**

---

I can't figure out the exact conditions that result in this, but sometimes the pycache for the assert rewriting isn't recreated between running pytest in optimized and normal Python.
- Using Python 3.2
- pytest 2.1.0/2.1.1
- python -B / PYTHONDONTWRITEBYTECODE makes no noticeable difference

I'm testing code that both uses the assert statement (outside of tests) and checks `__debug__` and I'm using an `xfail('not __debug__')` combined with lots of `with raises(AssertionError)`. Sometimes (but not every time) after `python -Ompytest`, normal pytest runs fail because they seem to run on an optimized bytecode cache but with `__debug__ = True`.

I'm setting priority to minor because I suspect I'm hitting an edge case that isn't relevant to most people.
