Title

Fix control.sh --kill compute command permissions check and authorization errors propagation

Description
The control.sh --kill compute command ignores any errors that occur during its execution. 
For example, control.sh --kill compute may fail if the user does not have sufficient privileges, but currently, in this case, the command completes with success status and no sign of errors. 
see org.apache.ignite.internal.management.kill.ComputeCancelSessionTask#reduce0 

  It also requires excess ADMIN_OPS permission along with TASK_CANCEL.
