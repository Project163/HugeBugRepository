Title

Updating issues via API does not work if "state" field is present but unchanged

Description
### Description

If i try to update an issue via:
```
curl --location --request PATCH '[URL] \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer ***' \
--data '{
  "assignees": [],
... [Log Snipped] ...
  "state": "open"
}'
```
The issue is updated just fine but Gitea returns status code 500.

The problem here is the `state` field. Without the `state` field everything works just fine.

I think the problem was introduced with [URL] @yp05327 maybe you can have a look at it.

The problem occured because Renovate Bot useses the `state` field in its model (see [URL] for issue creation / update via the Gitea API.
