Title

[YSQL] Table count shown wrong on colocated tables post restore.

Description
Jira Link: [Link: DB-19037]
### Description

**Version:  -b126**
**Steps -**
1. Create db with colocation
2. Create table and load some data
3. Do some alters, table rename, drop columns, etc
4. load more data, delete some data and get table count -- eg: 1800
5. Take a backup and restore to db1

Connect to db1
`select count(*) from table; --> 0`
when do select * on restored table, see data is still there -
`select * from table;
(1800 rows)`
