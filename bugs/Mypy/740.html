Title

Type of property unknown before its declaration

Description
Source:

```
class X:
    def x(self):  # type: () -> str
        return self.y

    @property
    def y(self):  # type: () -> str
        return "hello"
```

Gives:

```
test.py: note: In member "x" of class "X":
test.py:3: error: Cannot determine type of 'y'
```

Moving `y` above `x` gives a clean typecheck. Mypy should typecheck cleanly even if `x` is declared before `y`.
