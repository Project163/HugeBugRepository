Title

property expressions using "this" as object part won't work in combination with @Category

Description
@Category(Distance)
 class  DistanceCategory {
    Distance plus(Distance increment) {
         new  Distance(number:  this .number + increment.number)
    }
} 
  
 here this.number is a PropertyExpression and the this needs to be transformed, but is not. The transform uses ClassCodeExpressionTransformer which does not transform the object part in Propoertyxpressions. ResolveVisitor makes use of that class too, so a fix has to take special attention to that
Discussion
- A basic question. In an example like yours, where the category DistanceCategory has non-static methods, the non-static methods get mapped to static methods with $this as the first parameter, right? 

 So, the transformation that should happen for a property-expression like "this.number" should transform object expression "this" to the first parameter "$this" that groovy compiler(CategoryASTTransformation) adds to the method when transform the non-static method "plus" to make it a static one? Is that understanding correct? 

 rgds, 
Roshan
