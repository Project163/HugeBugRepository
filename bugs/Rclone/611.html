Discussion
- The problem seems to be the specific combination of `--vfs-cache-mode full` and `--buffer-size 0` when using `rclone mount`

I managed to reproduce this

```
rclone mount -vv --buffer-size 0 --vfs-cache-mode full TestDrive: /mnt/tmp/
```

And doing this on an uncached file

```
md5sum /mnt/tmp/10M
```

This seems to open more and more downloaders which explains the symptoms.
