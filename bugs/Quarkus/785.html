Title

auto-service-loader-registration=true does not work in quarkus/integration-tests

Description
**Describe the bug**
I'm creating a project in devtools/cli where I want to build a native image and set auto-service-loader-registration=true within src/main/resources/application.properties.  This flag is completely ignored.

**To Reproduce**
Steps to reproduce the behavior:

You can reproduce by going to quarkus/integration-tests/amazon-lambda and adding auto-service-loader-registration=true to that project's application.properties and running -Dnative.  Notice that -H:+UseServiceLoaderFeature  IS NOT set, but -H:-UseServiceLoaderFeature  is.
