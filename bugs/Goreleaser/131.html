Title

Tests fail on a system OS set up in languages other than English

Description
**Describe the bug**

When trying to execute `make test` on an OS set up in Spanish language, all the git error messages show up in Spanish, making the tests checking for those messages in English fail.

**To Reproduce**

- Set up your OS in a language different than English
- Execute `make test`

**Expected behavior**

We should be able to execute the test suite independently of the locale
