- This commit only fixed the classloader problem for scala 2.11, while Spark 3.x with scala 2.12 still has this problem. 

 I've tracked down the reason why scala 2.12 cannot be fixed by  setting the thread context classloader : IMain.setContextClassLoader was deprecated and became a no-op in scala 2.12, so the interpreter  silently skipped setting the thread context classloader , then weird things happen. 

 Changing `intp.setContextClassLoader()` to `Thread.currentThread.setContextClassLoader(intp.classLoader)` seems to fix the problem. I've tested my fix locally on Spark 3.1.2, I'll submit a PR if this approach is considered OK.
