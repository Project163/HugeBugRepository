Title

acd: Stop waiting for files to appear when we got a 429 error

Description
I see lots of failures for many different reasons to ACD.  Is there an ability to reduce the amount of time/retries for these type of failures?  Currently it waits 24 times (about 2 minutes) to verify the file was not uploaded correctly.  In the end 99.9% of the time the file does not exist and it just re-uploads it.  I'd like to cut down on the time and only try a few times thus reducing the sync times.
