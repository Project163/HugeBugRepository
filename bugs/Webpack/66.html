Title

Webpack 2 incorrectly assumes a default export when no default was defined (harmony)

Description
**I'm submitting a bug report**

**Webpack version:**
2.1.0-beta.15

**Current behavior:**
When a CommonJS module has no default exports, Webpack's harmony-handling seems to incorrectly generate a "default" export.
It's important to distinguish when a CommonJS module uses:
`module.exports.default = ...` vs `module.exports = ...`.

Webpack doesn't seem to distinguish those two cases when importing via Harmony, and both examples result in the same treatment:

`exports-equal.js`:

``` js
module.exports = function() {}
```

`exports-default-equal.js`:

``` js
module.exports.default = function() {}
```

`incorrect-behavior.js`:

``` js
import * as a from './exports-equal';  // should be equivalent to: var a = require('exports-equal');

// following is false, should be true:
typeof a === 'function'; 

// following is true, should be false, because 'a' doesn't define any default exports!
typeof a.default === 'function';
```

`correct-behavior.js`:

``` js
import * as a from './exports-default-equal';  // should be equivalent to: var a = require('exports-default-equal');

// 'a' is an Object and correctly defines a default export:
typeof a.default === 'function';
```

Note that this problem is separate to what [URL] is concerned with. 

**Expected/desired behavior:**
Just as Webpack doesn't assume anything automatically with the standard `require()` syntax, the new Harmony syntax shouldn't assume that `exports = ...` is equal to `exports.default = ...` and should treat both cases differently. 
- **What is the motivation / use case for changing the behavior?**
  This will ensure compatibility with transpilers such as TypeScript, which treats both cases accordingly. It is also closer to what the spec defines and in line with the older CommonJS syntax:

``` js
import * as a from 'a';
// is equal to:
var a = require('a');
```

import {default as a} from 'a'; // explicit 'default'
// is equal to:
import a from 'a'; // implicit 'default'
