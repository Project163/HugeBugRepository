Title

Integers not automatically converted to Bytes

Description
Integers are not converted to  Byte  unless cast to  byte  first. For example, this throws an  ArrayStoreException : 
  
  Byte [] bytes = [1, 2, 3, 4, 5]
bytes[1] = 50
 
  
 Test case attached.
Discussion
- Attaching the patches for 1.6-RC-1 and 1.7-beta-1. 

 Its root cause was similar to that of the issue reported in   GROOVY-3165  . 

 The implementation of ObjectArrayPutAtMetaMethod.invoke() had logically deviated from what was implemented in "DefaultGroovyMethods->putAt(Object[] array...)" because of which auto-conversion between number types had got affected, some more examples of which are :- 

 Short[] shorts =  [1, 2, 3, 4, 5]  
shorts [1]  = 50 

 Float[] floats =  [1.0f, 2.0f, 3.0f, 4.0f, 5.0f]  
floats [1]  = 50.0d
- Roshan, how about applying the fix?I would fix he cases with Short and Float too, or not?
- The patches have already been applied on 1.6.x and trunk alongwith a test for it making sure that in addition to the reported Integer to Byte conversion, other related conversions are also covered and tested. Marking it as fixed now as   GROOVY-3173   remains open for the remaining regression issues related to assignment to array elements.
