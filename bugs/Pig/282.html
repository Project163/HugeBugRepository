Title

javac warnings: cast, fallthrough, serial

Description
Pig have javac warnings when you build it with the option "-Dall.warnings=1". We need to suppress all of them. This issue is to track the javac warnings in the following categories: 

 cast (49) 
fallthrough (1) 
serial (19) 

 The number in the parenthesis is the times of occurrence of particular javac warning.
Discussion
- The plan is:  
1. Suppressing warnings in the code level as much as possible 
2. Some "cast" warnings are from the generated code of javacc, which is out of our control. As a result, we will suppress all "cast" warnings in build.xml.
- Attached patch address target javac warnings in the code level. Still couple of warnings from javacc which is out of our control, we will suppress it in build.xml. The change of build.xml will be included in   PIG-1033  .
