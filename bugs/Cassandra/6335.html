Title

DDM's mask_default function should support vectors

Description
DDM uses the CQL function  mask_default  as the default masking function. This function supports all CQL data types except for  vector , which didn't exist when DDM was added.  

 We should make  mask_default  (and thereof default masking) work with vector columns.
