Title

Duplicate Repository Mirrors Scheduled

Description
### Description

When a repository is still in the process of being mirrored and the interval for running the mirror sync expires another mirror job is scheduled. This may not lead to any ultimate failure, but it does consume excess system resources with the duplication.

My problem is likely unusual since I am having a secondary problem with some of my repositories taking far too long to mirror. As in over 8 hours long! That is another problem and is something I'm still investigating so no need to go into any detail on that.
