Title

[DocDB][Advisory Lock] Concurrent Lock Acquisition Without Waiting in pg_advisory_lock(key1 int, key2 int)

Description
Jira Link: [Link: DB-15046]
### Description

Version: ** -b212**

While using pg_advisory_lock(key1 int, key2 int), session 2 acquired the lock without waiting, even though Session 1 was already holding it.

```
Session 1                                          Session 2

yugabyte=# SELECT pg_advisory_lock(1,1);
 pg_advisory_lock 
------------------
... [Log Snipped] ...
 
                                               (1 row)
```
