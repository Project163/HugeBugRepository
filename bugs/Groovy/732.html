Title

MarkupBuilder indentation fails when combining yield statements and empty tags

Description
MarkupBuilder seems to become confused if yield / yieldUnescaped calls and empty element are mixed within a single tag. All lines from that tag up to the end are 1 step less idented than they should be. 
Example Groovlet: 

  
 def html =  new  groovy.xml.MarkupBuilder()
html.html {
	head {
		title ( "test" )
	}
	body {
		p {
			yield  "Some Text" 
			br()
			yield  "Another Text" 
		}
	}
}
 
  

 The output. You can see that there should be more whitespace before </p> and </body>. 
  
 <html>
  <head>
    <title>test</title>
  </head>
  <body>
    <p>Some Text<br />Another Text
  </p>
</body>
</html>
Discussion
- Well, actually you can't see any whitespace. Just imagine it, or test it yourself
- add noformat tags and markup builder definition to allow the fragment to be run standalone
- fixed in trunk and 1.5.7 branch
- Output from above is now: 
  
 <html>
  <head>
    <title>test</title>
  </head>
  <body>
    <p>Some Text
      <br />Another Text
    </p>
  </body>
</html>
