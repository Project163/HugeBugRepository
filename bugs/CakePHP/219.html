Title

3.0 - TranslateBehavior bug with empty association

Description
Hey guys. Another weird one from me. If I have a Table1 that belongs to Table2, Table2 is translated, but Table1's foreign_key associates to a non-existing record in Table2 (Table1.table2_id = 0, and Table2 has no record for that), it will error with:

```
Fatal error: Call to a member function clean() on array in stuff/SITE/vendor/cakephp/cakephp/src/Model/Behavior/TranslateBehavior.php on line 336
```

A slightly inelegant solution I put in to TranslateBehavior which works is:

```
if (!is_null($row)) {
    $row['_locale'] = $locale;
    if ($hydrated) {
        $row->clean();
    }
}
```

If you guys think it makes sense I can make a PR.

Thanks!
