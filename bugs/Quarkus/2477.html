Title

QuarkusMainTest with Database Access not Working

Description
### Describe the bug

I'm trying to test an application running with a Quarkus main method annotated with `@QuarkusMain`. For test reasons I annotated my test class with `@QuarkusMainTest` which works fine so far. Now that I implemented a storing of data into a database I need to enrich the test with database look-ups. No matter how I try, I always get the error

```
java.lang.IllegalStateException: This method is normally automatically overridden in subclasses: did you forget to annotate your entity with @Entity?
     at io.quarkus.hibernate.orm.panache.common.runtime.AbstractJpaOperations.implementationInjectionMissing(AbstractJpaOperations.java:452)
     at io.quarkus.hibernate.orm.panache.PanacheEntityBase.listAll(PanacheEntityBase.java:419)
```

In another test class annotated with `@QuarkusTest` the same code works fine.

Since I'm using the `quarkus-test-h2` dependency for database tests, I also tried to annotate the test class with `@QuarkusTestResource(H2DatabaseTestResource.class)` without any effect.

My H2 configuration:

```
quarkus:
  datasource:
    db-kind: h2
    jdbc:
      url: 'jdbc:h2:mem:default'
      driver: 'org.h2.Driver'
    username: sa
    password:
```
Also I tried an Oracle database, but the error still occurs. Also I tried an injection of an `EntityManager` instead of using `Panache` which throws a different error but is also not working. But injecting an `EntityManager` would be the last thing that I want to do.

### Expected behavior

No error occurs, just as in the `@QuarkusMain` and the `@QuarkusTest` annotations' context.

### Actual behavior

The error in the description occurs.
