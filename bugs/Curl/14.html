Title

GnuTLS backend skips really long certificate fields

Description
at [URL] and forward, libcurl calls `gnutls_x509_crt_get_dn` with a fixed buffer size and if the field is too long in the cert, it'll just return an error and the field will be displayed blank.

The GnuTLS function actually returns a suggested buffer value for a renewed attempt but libcurl just doesn't take advantage of this.

According to this [Link: old post] there are a few extreme certificates in use out there that will go past this limit.

Problem brought to us by @yujokang
