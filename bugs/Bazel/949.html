Title

Unvaried output path when using --platform flag

Description
### Description of the problem / feature request:

When building using using the `--cpu=custom_cpu` flags, I get my artifacts in the `bazel-out/custom_cpu- ` folder.
However, when I use the new platforms flag, my build artifacts always end up in `bazel-out/k8- `, so the path is completely independent of the platform. This results in builds for different platforms clobbering each other's intermediate artefacts and effectively changing incremental builds into full builds. 

I would expect that when I'm using `--platform=custom_platform`, then the build artifacts should end up in `bazel-out/custom_platform- ` and not default to k8 CPU name. Alternatively there should be some way to specify the output path for a custom platform.

### Bugs: what's the simplest, easiest way to reproduce this bug? Please provide a minimal example if possible.

Run any build using platform flag in a project with more than one platform

### What operating system are you running Bazel on?

Centos 8 Stream
