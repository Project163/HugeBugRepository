Title

bug: rcserver not checking the existence of static files

Description
#### What is the problem you are having with rclone?

rclone is accepting `--rc` as a global config to enable the rcserver. However, it is not checking if the web GUI exists or not and trying to serve it directly. This will cause exception if the web gui is not here.


#### What is your rclone version (output from `rclone version`)

rclone v1.49.5
- os/arch: darwin/amd64
- go version: go1.12.10


#### The command you were trying to run (eg `rclone copy /tmp remote:tmp`)

Minimum reproductive: `rclone config --rc --rc-web-gui`

Expected: Download the web gui tarball and unzip it

Exception: shows 404 instead.


#### Possible fix

Check if the GUI exists or not as `rclone gcd` does.

Please also refer to [URL] for a reproduction.
