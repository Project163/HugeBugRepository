Title

Fixtures from plugin and subfolder

Description
I'm trying to load a fixture that is in a subdirectory of a plugin. My plugin is `MysqlBackup` and the subfolder is `Sqlite` (uppercase first).

Reading from [Link: CookBook], I would expect the correct syntax to be:

        plugin.mysql_backup.sqlite/articles

But running phpunit, I get this:


Note: incorrect slash and class name with lowercase initial.  
From here it seems that the subfolder should have the uppercase letter: in my case this is so, but the CookBook provides examples (`app.blog/articles`) with the lowercase letter (in other words: how should I do if the subfolder was `sqlite`?).

So the only way I have to load my fixture is this syntax:

        plugin.mysql_backup.sqlite\Articles

And this works.

This is a bit strange, does not it seem to you?
Discussion
- Does using `'plugin.MysqlBackup.Sqlite/Articles'` work?
- I can take a look what you are describing should work.
- Another thing: fixture is not loaded anyway.  
I mean. Until now I used `$autoFixtures` as `false`, I was getting errors by just specifying the class of fixtures.

In other words, this is the only syntax that does not give me any errors:

    public $autoFixtures = false;

    public $fixtures = [
        'plugin.mysql_backup.sqlite\Articles',
    ];

If I try to load fixtures:

        $this->loadFixtures('Articles');

I get: 

        `UnexpectedValueException: Referenced fixture class Articles not found`

Instead, setting `$autoFixtures` as `true` that syntax (`plugin.mysql_backup.sqlite\Articles`) works.

***

**EDIT:**

This works:

        $this->loadFixtures('Sqlite\Articles');
