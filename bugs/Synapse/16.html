Title

Some of the dependancy jars are not included in Synapse

Description
Following jars are required for synapse security configurations 
-xalan.jar 
-xercesImpl.jar 
-xml-apis.jar 

 serializer.jar is required to get ?wsdl of a proxy service. 

 However the above dependancy jars are not included in the latest Synapse distribution.
Discussion
- fixed
- The specified jars are included in the latest Synapse version. However the serializer jar is not included but you can view the ?wsdl of Proxy services.  

 Tested on 1.2_SNAPSHOT. The issue can be closed after verifying whether the serializer jar is actually required.
