Title

Module diagrams missing from javadoc for release candidate

Description
This must be fixed for the release.
Discussion
- The problem appears to be that Java 11 generates the javadoc into a different structure than Java 9. The module diagrams are included by <img> tags whose src attributes are relative file names. The location of the generated html has changed and now the relative paths point nowhere. The trunk public api on the Derby website is built by Java 9 and so it looks good. However, the javadoc in the 10.15 distributions was built by Java 11, hiding the module diagrams. I will ask the experts for advice about whether there is a best practice for handling this problem.
- Javadoc generated by JDK 10 looks good. It is Java 11 which introduced this new directory structure.
