Title

StringUtil.hyphenate not handling names ending in multiple uppercase

Description
The org.jboss.shamrock.deployment.util.StringUtil.hyphenate method is not handling a name that ends in multiple uppercase characters. For example: 

        String hyphenated = StringUtil.hyphenate("btSBV");
        System.out.printf("hyphenated: %s\n", hyphenated);

outputs:
        hyphenated: bt-sbv-v
