Title

Libfb303.so not copied to target lib directory

Description
I'm building contrib/fb303 on Ubuntu 9.10 like this: 

 cd contrib/fb303 
./bootstrap.sh --prefix=$HOME/fb303-bin -with-thriftpath=$HOME/thrift-0.2.0-bin --disable-static 
make 
make install 

 and 'make install' doesn't copy libfb303.so to the expected directory $HOME/fb303-bin/lib
Discussion
- Looks like a small bug in cpp/Makefile.am. 

 Libfb303.so is currently copied to ./lib instead of the target install lib directory. 

 I'm attaching a small patch that fixes it.
