Title

No logs on exception in QuarkusTestResourceLifecycleManager.start

Description
**Describe the bug**
Imagine having a QuarkusTestResourceLifecycleManager, which might throw an exception, if you have got a bug in your manager or haven't properly prepared your environment. If this manager throws an exception in the start method, no logs except the thrown exception are outputted on console.

**Expected behavior**
All logs, including already logged messages and the stack trace of the uncaught exception, are logged.

**Actual behavior**
Only the stack trace of the uncaught exception are logged.

**To Reproduce**
Steps to reproduce the behavior:
1. Create a test using a QuarkusTestResourceManager.
2. In the QuarkusTestResourceLifecycleManager, log something and throw a RuntimeException.
3. See the log not containing the logged entry from the manager.
