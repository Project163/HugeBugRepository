Title

when use \Doctrine\DBAL\Schema\Comparator to compare two table schema, has a problem

Description
when use \Doctrine\DBAL\Schema\Comparator to compare two table schema.

testing 2.5.4 on mysql

from table schema:

```
CREATE TABLE `cart` (
  `cart_id` int(10) unsigned NOT NULL AUTO_INCREMENT,
  `user_id` int(11) NOT NULL DEFAULT '-1' ,
  PRIMARY KEY (`cart_id`,`user_id`),
) ENGINE=InnoDB CHARSET=utf8 COLLATE=utf8_unicode_ci;
```

to table schema:

```
CREATE TABLE `cart` (
  `cart_id` int(10) unsigned NOT NULL AUTO_INCREMENT,
  `user_id` int(11) NOT NULL DEFAULT '-1' ,
  PRIMARY KEY (`cart_id`),
) ENGINE=InnoDB AUTO_INCREMENT=222 DEFAULT CHARSET=utf8 COLLATE=utf8_unicode_ci
```

And the schema diff sql is :

```
ALTER TABLE systrade_cart DROP PRIMARY KEY
ALTER TABLE systrade_cart ADD PRIMARY KEY (cart_id)
```

the execution wil fail: 

i find the code and old issue, guess this is a bug.

the bug like DBAL-464, but is difference
