Title

Virtual topic wildcard consumers don't receive some messages

Description
When using mqtt with virtual topic subscription strategy, it shows some failures when dealing with wildcard subscriptions. The problems are related to how we deal with wildcards in virtual topic consumer, leading to messages sent to child topics are not forwarded properly.
Discussion
- This is now fixed with  [URL]

 We need to treat virtual topic wildcard subscriptions differently as they need to be represented by a dedicated queue. The subscription to that queue should not subscribe to other child queues (as in the normal case) or we'll get duplicates.
