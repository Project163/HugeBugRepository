Title

Environmentally enabled reporters should override explicit reporters

Description
If a user wants Verbose or Quiet reporters by default, that should not disable TeamCity or AppVeyor support.

Affected: Console Runner, MSBuild Runner

Workaround: Do not set an explicit reporter for builds which will run in TeamCity or AppVeyor.
