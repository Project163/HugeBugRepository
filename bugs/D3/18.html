Title

d3.geom.voronoi yields strange results if any two vertices are the same

Description
To see this in action, just add

``` javascript
vertices.push([100,100]);
vertices.push([100,100]);
```

To examples/voronoi/voronoi.js before and see the result. It's a bit strange (if you turn down the opacity on the paths you can see that there are many overlapping paths that are made).

I think that there either should be a check for this when d3.geom.voronoi is called, or there should be a warning in the example/documentation. I know that this is a bit of a corner case but it definitely comes up in real-world usage (I was trying to do a Voronoi of a subway map, two stations had the same coordinates...)
Discussion
- Yep, that sounds like a bug. I'm not sure what the appropriate behavior is in this case; perhaps ignore the duplicate point?
- What I did in my particular case was remove duplicate points -- not sure that this is generally the solution, since having multiple points at one vertex could indicate something about the data (in my case, one station where two or more subway lines converged) that might be used for coloring the region, for example.

Perhaps just adding a warning might help people who are trying to make a Voronoi layout and get unexpected results.
