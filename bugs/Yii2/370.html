Title

debug panel: phpinfo rendering problem

Description
In some cases phpinfo part is rendered not perfectly, out of bootstrap grid.
For example, it happens when running on **PHP 5.6.4 VC11 x64 Non Thread Safe (2014-Dec-18 00:02:02)**
It's because first **table** tag in phpinfo() output may be without any attributes, so no spaces after **table** itself.
To correct this, in file "yiisoft\yii2-debug\panels\ConfigPanel.php", function getPhpInfo() replace

to

I.e. remove space after **table**.
