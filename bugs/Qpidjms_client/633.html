Title

[Java Client, AMQP 0-x] SCRAM SASL implementation incorrectly encodes "=" and "," for passwords

Description
Currently the Qpid Client for Java for AMQP 0-x encodes the characters "=" and "," in passwords when using the SCRAM SASL mechanism. 
This is incorrect.  The spec  requires encoding of those characters for the username. Not for the password. 

 This was reported on the  user mailing list
Discussion
- The SCRAM SASL implementation was ported from the AMQP 0-x client to the new AMQP 1.0 client. This porting included this bug.
