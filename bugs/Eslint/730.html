Title

"space-after-keywords: never" + "space-before-blocks: always" incompatible with try & `else

Description
Using eslint 1.5.1. This issue might be related to #1338.

I want to configure the following code style:

``` js
function() {}

if(true) {}
else {}

try {}
catch(e) {}
```

Obviously I have to enforce spaces before blocks via `space-before-blocks: always`. To additionally forbid things like `if () {}` I only found the `space-after-keywords: never` rule.

This however makes it impossible to write `try` and `else` statements:

``` js
try {} // space-after-keywords: Keyword "try" must not be followed by whitespace.
   ^

try{} // space-before-blocks: Missing space before opening brace.
   ^

```

I see that this configuration is kind of contradictory. Is there another way to achieve what I want?
