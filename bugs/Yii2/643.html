Title

"yii message" does not support extracting concatenated constant strings

Description
### What steps will reproduce the problem?
1. Install the [Link: basic application template] via Composer.
2. In `views/site/index.php`, change the paragraph that starts at line 23 (the first "Lorem Ipsum" one) with:

```
   
```

3. In `config/web.php`, add the internationalization (`i18n`) component in the `components` section:

```
'i18n' => [
    'translations' => [
        'app*' => [
            'class' => 'yii\i18n\PhpMessageSource',
            'basePath' => '@app/messages',
... [Log Snipped] ...
    ],
],
```

4. Create a directory named `messages` in the root directory of the application.
5. Open a terminal, `cd` to the root directory of the application. Run `./yii message/config-template messages/config.php` and then `./yii message messages/config.php`.
6. Open `messages/de/app.php`.

### What is the expected result?
The concatenated constant string passed as an argument to `Yii::t` in step 2 should be rendered in the message file as a single string, as follows:

```
return [
    'Lorem ipsum dolor sit amet, consectetur adipisicing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat. Duis aute irure dolor in reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla pariatur.' => '',
];
```

### What do you get instead?
Only the first token of the string (the one before the first line break) is saved into `messages/de/app.php`:

```
return [
    'Lorem ipsum dolor sit amet, consectetur ' => '',
];
```

| PHP version      | 7.1.3
| Operating system | Arch Linux
