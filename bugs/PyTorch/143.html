Title

[MPS] Typo in error message for supported autocast type

Description
### 🐛 Describe the bug

In [URL] @awmartin wrote:


There had been some back and forth regarding which type to support - fp16 or bf16 (ref [URL] [URL] A decision was made to go with fp16. I think this was an oversight when going from bf16 to fp16.

The error message should be updated to `MPS Autocast only supports dtype of torch.float16 currently.`. Consider adding a regression test in order to prevent a similar bug in the future.

Minimal repro:

```python
import torch
with torch.autocast("mps", dtype=torch.bfloat16):
    x = torch.tensor(1)

# /Users/hvaara/dev/pytorch/pytorch/torch/amp/autocast_mode.py:332: UserWarning: In MPS autocast, but the target dtype is not supported. Disabling autocast.
# MPS Autocast only supports dtype of torch.bfloat16 currently.
#   warnings.warn(error_message)
```

I was able to repro on `main` and `v2.5.0`.

Fix incoming.
