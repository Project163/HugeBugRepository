"Fixing" this as attempted in [URL] will regress [URL] for `system()`, `systemlist()`, and `:!`. So CTRL-C on `:echo system('sleep 30|sleep 30|sleep 30')` will leave orphan processes.

Vim's approach is:

1. block signals
2. fork()
3. unblock signals in the child
4. on CTRL-C, send SIGINT to the process-group id (parent (`vim`) ignores the signal, child and its descendants do not)

To do this in Nvim AFAICT would require adding a case to `process_spawn()` to work without using libuv. Possibly this could be implemented like how `src/nvim/os/pty_process_unix.c` implements `ProcessType.kProcessTypePty`. We could add a `ProcessType.kProcessTypeUnix` and special-case it.

I'm pretty sure I don't want to spend my time doing this. But if anyone else wants to, it's welcome.
