Title

SASL GSSAPI not working with librdkafka and AK 4.x

Description
By running librdkafka with AK 4.0 we see that SASL GSSAPI isn't working. 
The feature is missing because librdkafka is incorrectly checking for JoinGroup v0 only and not v0+. 

 When testing librdkafka versions with 4.0 we missed this case so JoinGroup v0 and v1 were removed. 

 A  fix  is already merged in librdkafka and will be released in v2.11.0. 
Enabling back the deprecated JoinGroup RPC versions will help the users looking to continue using Kerberos authentication without upgrading.
Discussion
- librdkafka v2.11.0 with the fix was released
- Even though this is a bug in librdkafka, the goal of KIP-896 was to avoid breaking the popular client libraries listed in the KIP. The cost of adding JoinGroup v0-v1 back is pretty low and hence I suggest we do that.
- I updated the KIP to reflect this change.
- Filed   KAFKA-19494   for undeprecating these versions from 3.x
