Title

Rule 'strict' advising unnecessary "use strict" directives.

Description
If you run latest master on this file:

``` js
/* eslint strict:2 */
/* jshint strict:true */
function a() {
    function b() {
    }
}
```

You'll get these errors:

```
  4:1  error  Missing "use strict" statement  strict
  3:0  error  Missing "use strict" statement  strict
```

If you run jshint on the same file, you'll get just one error:

```
line 4, col 5, Missing "use strict" statement.
```

(Note that it appears at line 4 because jshint generates this error on the first non-"use strict" statement of a function rather than at the function declaration - it is still referring to function a.)

jshint is arguably more correct in this case because you only need the one `"use strict";` directive in function a to make both functions run in strict mode. If you filled in all the strict statements that eslint prompts you to here, then you will get errors if you enable the no-extra-strict rule.
Discussion
- Yup, seems like we should be warning only on the outermost function.
