Title

Multi-merged partitions exchange future may hang if node left event is received last

Description
The scenario is similar to   IGNITE-11204  , but several exchanges should be merged. If in this case a merged-exchange node is left and all other nodes messages are already received, the exchange will not be completed because  F.isEmpty(mergedJoinExchMsgs)  is  false .  
Looks like we should decrement the  awaitMergedMsgs  and check this field for  0 .
