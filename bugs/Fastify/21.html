Title

Why is reply.request not documented?

Description
Like in the title. I was looking for a way to use `decorateReply`, but still have access to the `Request` object. I didn't see any information in the `Reply` documentation, so I started digging and doing some `console.log`s, and actually, there IS a `Request` object under `reply.request`. So my question is: is it not documented by purpose (maybe because it's not a good practice to use it), or just an oversight?

`fastify@2.3.0`
