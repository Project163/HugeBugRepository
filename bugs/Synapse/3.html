Title

When Synapse is used to talk to a WS-Sec endpoint, the response back to the [non WS-Sec] client is encrypted

Description
This is because the same Axis2 message context for the incoming message was used to send out the request to the endpoint. During this process the message context is altered to use WS-Security, and the response received has WS-Sec as well. The response is now received to Synapse decrypted, but when its sent out again, Rampart gets engaged to re-encrypt is before sending back to the client.
Discussion
- Fixed with a sample to demonstrate the correct behaviour and related documentation
