Title

False positive `unnecessary-ellipsis` when multiple conditions in `if` statement

Description
### Bug description

```python
# test.py
def func(val1, val2):
   if val1 is not ... and val2:
        pass
```

Above code raises error, but the following does not:
```python
def func(val1, _):
   if val1 is not ...:
        pass
```

So, it probably is something to do with multiple conditions here.
