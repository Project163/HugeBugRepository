Title

Change CheckConnectJvmClientCompatibility to deny list to increase the API check coverage

Description
The current compatibility check only checks selected classes. So when adding a new class, if a developer forgets to add this class into the checklist, then this API is not covered in compatibility tests. Thus we should change this API check to always include all APIs by default.
