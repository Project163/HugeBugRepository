Title

window.tauri is undefined upon reloading

Description
**Describe the bug**


Upon reloading the webview (manually or via HMR), `window.tauri` is `undefined`, and the APIs are unreachable.

**To Reproduce**
Steps to reproduce the behavior:
1. Run `tauri dev` and open the devtools console
2. Notice that `window.tauri` is populated
3. Reload
4. Try getting `window.tauri` again in console -> `undefined`

**Expected behavior**
I guess it shouldn't be undefined, maybe it's a security feature.
