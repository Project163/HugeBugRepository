Title

Python worker reuse causes Barrier tasks to run without BarrierTaskContext

Description
Running a barrier job after a normal spark job causes the barrier job to run without a BarrierTaskContext. Here is some code to reproduce. 

   
  
 
def task(*args):
  from pyspark  import  BarrierTaskContext
  context = BarrierTaskContext.get()
  context.barrier()
  print( "in barrier phase" )
  context.barrier()
   return  []
a = sc.parallelize(list(range(4))).map(lambda x: x ** 2).collect()
 assert  a == [0, 1, 4, 9]
b = sc.parallelize(list(range(4)), 4).barrier().mapPartitions(task).collect()
