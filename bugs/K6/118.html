Title

HTTP methods are wrongly overwritten in the tracing instrumented client

Description
### Brief summary

Tracing instrumentation wrongly overwrites HTTP methods in the client and assigns `PATCH` method to both `POST` and `PUT` requests.

### k6 version

0.43

### OS

all

### Docker version and image (if applicable)

_No response_

### Steps to reproduce the problem

1. Instrument code with `tracing.instrumentHTTP`
2. Call `http.post` or `http.put`


### Expected behaviour

Instrumented tracing HTTP client sends:
* a `POST` request when `http.post` is invoked
* a `PUT` request when `http.put` is invoked

### Actual behaviour

Methods `http.post` and `http.put` methods after calling `tracing.instrumentHTTP` send HTTP `PATCH` request.
