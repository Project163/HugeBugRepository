Title

Explicit Tests get run when using --exclude

Description
Running an Assembly with a TestFixture like the following, the Explicit Tests will be run by the console-runner if the --exclude argument is used.

nunit-console.exe NUnitFailers.dll --shadowcopy --exclude=mytest

```
[TestFixture]
    public class ExplicitTest
    {
        [Test]
        [Explicit]
... [Log Snipped] ...
        }
    }
```

- Confirmed by code inspection. NotFilter has a boolean property TopNode, which causes explicit tests to be skipped when true. The code to actually set TopNode never made it into 3.0. It's a fairly simple fix to TestFilter.cs.
