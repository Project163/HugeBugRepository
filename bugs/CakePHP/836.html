Title

assertHtml() should ignore multiple spaces and tabs

Description
This is `$result`:

```
########## DEBUG ##########
'
 
     Popular tags 
     
... [Log Snipped] ...
'
###########################
```

The problem is `assertHtml()` does not properly ignores multiple spaces and tabs. Output:
```
Item #8 / regex #27 failed: Close div tag
Failed asserting that '     
 
' matches PCRE pattern "/^ [\n\r]*/s".
```

Instead, this works:
```
$result = preg_replace('/\s{2,}/', null, $result);

```
(note that in my case, there are multiple spaces before the tag)

This is the `$expected` value:
```
$expected = [
            ['div' => ['class' => 'widget']],
            'h4' => ['class' => 'widget-title'],
            'Popular tags',
            '/h4',
... [Log Snipped] ...
            '/div',
        ];
```
