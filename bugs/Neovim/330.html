Title

nvim_input_mouse("left", "release", "A", …) leaves insert mode

Description
- `nvim --version`: NVIM v0.5.0-dev+1053-g459a6c845

### Steps to reproduce using `nvim -u NORC`

Using any gui (reproduced with Firenvim and Goneovim), enter insert mode and click somewhere while pressing `Alt`.

### Actual behaviour
Neovim leaves insert mode.

### Expected behaviour
Neovim stays in insert mode. This is the behavior Neovim has in v0.4.4. I'll try to bisect when I have time.
Discussion
- Change introduced in   in [URL] by @godlygeek.

In my opinion this change is very wrong. If a key isn't mapped, it shouldn't have any effect. Having all alt/meta keys result in leaving the current mode serves no purpose and worse: people might start relying on ` ` to leave the current mode, which means that when neovim makes ` ` a default to, say, call `DoWhatever()`, people's workflow will break.

This change is also buggy as it makes ` ` leave insert mode even if something is bound to it with `:inoremap   ...`.

I think there is still time to revert this as v0.5 hasn't been released yet. What do the maintainers think?
