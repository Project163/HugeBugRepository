Title

Unused variable when binding as a default value inside a lambda

Description
Originally reported by: **Torsten Marek (BitBucket: [Link: tmarek], GitHub: @tmarek?)**

---

The code snippet

```
#!python
def function():
    for i in range(10):
        return lambda i=i: i
```

triggers unused-variable for `i`, but only if the argument to the lambda has the same name.
