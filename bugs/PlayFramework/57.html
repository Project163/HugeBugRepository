Title

Lowercase authorization header when using custom signature calculator

Description
### Play Version (2.5.x / etc)

2.6.3

### API (Scala / Java / Neither / Both)

Scala

### Operating System (Ubuntu 15.10 / MacOS 10.10 / Windows 10)

MacOS 10.12.6

### JDK (Oracle 1.8.0_72, OpenJDK 1.8.x, Azul Zing)

1.8.0_131

### Expected Behavior

1. Send a request with a custom SignatureCalculator
2. Set the Authorization header in the signature calculator like this: `requestBuilder.addHeader(HeaderNames.AUTHORIZATION, "some value")`
3. Use the signature calculator like this in a unit test like described below.
4. One would expect the Authorization header to be written like in `HeaderNames.AUTHORIZATION` (i.e. "Authorization")

### Actual Behavior

When the test case below is executed, `authorization -> ...` is part of the printed Map, `Authorization` does not occur in it. The authorization header is written in lowercase.

### Reproducible Test Case

```
Server.withRouter() {
      case GET(p"/some-resource") => Action { request =>
        println(request.headers.toMap)
        Results.Ok("")
      }
... [Log Snipped] ...
      }
    }
```
