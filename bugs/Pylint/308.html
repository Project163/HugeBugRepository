Title

A pylint stopIteration Runtime Error caused by runpy.run_path()

Description
### Steps to reproduce

1. Install the latest pylint (2.3.1).
2. Write a `run.py` file.
3. Run `pylint run.py`.

The content of `run.py` file:

```python
from runpy import run_path
_STH = run_path('hello.py')
```

### Current behavior

```
shell
$ pylint run.py
************* Module run
run.py:1:0: C0111: Missing module docstring (missing-docstring)
Traceback (most recent call last):
... [Log Snipped] ...
    yield from _infer_context_manager(self, mgr, context)
RuntimeError: generator raised StopIteration
```

### Expected behavior

Do not crash.

### pylint --version output

```shell
$ pylint --version
pylint 2.3.1
astroid 2.2.5
Python 3.7.2 (default, Dec 30 2018, 16:59:44)
[Clang 10.0.0 (clang-1000.11.45.5)]
```
Discussion
- `pip install 'pylint =2.2.0, but you'll have astroid 2.1.0 which is incompatible.
```
- Doesn't seem to reproduce any longer with the latest unreleased code.
