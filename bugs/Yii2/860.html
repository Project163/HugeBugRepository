Title

Js error from activeForm in strict mode

Description
### What steps will reproduce the problem?

1. Enable javascript strict mode (which happens automatically when you combine scripts e.g. with browserify)
2. Create a form with client validation enabled
3. Validate the form

### What is the expected result?

No error on client validation even in strict mode.

### What do you get instead?

```
yii.activeForm.js:868 Uncaught TypeError: Cannot read property 'input' of undefined
    at k (yii.activeForm.js:868)
    at O (yii.activeForm.js:710)
    at yii.activeForm.js:410
```

### What is the proposed fix?

There's a bug in `yii.activeForm.js` around line 710:

```js
        if (submitting) {
            var errorAttributes = [];
            var $input = findInput($form, this);
            $.each(data.attributes, function () {
```

Here `this` in the `$input = ...` line is not defined. The assignment must be moved inside the `$.each()`.

I'll provide a pull request with this fix.
