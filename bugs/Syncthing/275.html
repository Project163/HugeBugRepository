Title

Security section: breaking out of repo dir?

Description
The README.md has a security section, but it doesn't mention if there is protection against a malicious node in a cluster, e.g. requesting files outside of the repo dir (../../../../etc/passwd or similar).

Maybe too much detail for this stage, but just a suggestion.
Discussion
- Never mind the documentation, it should be tested and verified, which it currently isn't. :) Thanks for bringing it up.
- From the way I understood the protocol documentation a file exists in the local model if it exists on the local node, and in the global model as a union of all files across all nodes sorted by mtime. If there is no path breakout checking done, does this mean that checking if the file exists in both the local and the global model won't catch a request like ../../../etc/passwd, or am I missing something basic?
- The model (index) only includes what is found in the repository, so .. will never be in there.
