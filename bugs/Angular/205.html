Title

Angular 2, IE9 & pushState issue!

Description
Hi,

I'm having some issues with Angular 2, pushState & IE9 as I've documented initially in [URL] before carrying out much more investigation!

I've read [URL] and attempted to apply the history.js script with mixed results!

I have had to modify angular2.dev.js locally to return window.History instead of window.history (not a long term solution really!)

In Everything but IE9 things work as expected using path location mode - in IE9 history.js takes over and injects urls to look like [URL]

But those hashtag paths are then not recognised by the angular router..!!

So I turn on the hash location strategy and that works fine in chrome etc but in IE history.js kicks in and alerts the following..

The root issue is found in the following code in the router..

```
    PlatformLocation.prototype.pushState = function(state, title, url) {
        console.log('pushState line 2022');
      this._history.pushState(state, title, url);
      console.log('after push line 2026');
    };
```

If I comment out the pushState line then everything works.. but of course the url is not updated in the browser window :(

It feels a bit like a catch-22 situation!!

a) Is this a bug??
b) Does the Angular team have a compatible IE9 routing solution?

Help!!!

