Title

Can't build with Cargo resolver 2

Description
With a Cargo.toml using latest git version and [Link: new feature resolver] enabled:

```
toml
[package]
name = "bug-repro"
version = "0.1.0"
authors = ["Malloc Voidstar  "]
... [Log Snipped] ...
[dependencies]
rocket = { git = "[URL] rev = " " }
```

plus a `main.rs` containing `fn main() {}`.

```
[...]
   Compiling rocket_codegen v0.5.0-dev (https://github.com/SergioBenitez/Rocket.git?rev= #d03a07b1)
error[E0432]: unresolved import `syn::visit`
 --> C:\Users\L\.cargo\git\checkouts\rocket- \d03a07b\core\codegen\src\derive\form_field.rs:4:10
... [Log Snipped] ...
warning: build failed, waiting for other jobs to finish...
error: build failed
```

`codegen` is using syn's visit module without actually enabling it; it gets enabled elsewhere on the old resolver (I can't figure out where). The new resolver will be [Link: the default in Rust 2021] and is available since 1.51.

Adding the dependency `syn = { version = "1.0", default-features = false, features = ["parsing", "visit", "visit-mut"] }` to codegen's Cargo.toml fixes this, didn't make a PR since I'm not sure if those are the complete set of features.
Discussion
- `syn` is a transitive dependency through `devise`. We should enable `visit` there, perhaps as a `syn/visit` `devise` feature.
