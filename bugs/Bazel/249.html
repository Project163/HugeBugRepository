Title

OSX sandboxing doesn't seem to restrict network access

Description
We've run into this issue a few times now, where unit tests written on OS X pass, but then fail when run on Linux machines, and we need to go back and either change the test or add the `requires-network` tag.

It looks like it's possible to restrict network on os x with `sandbox-exec -n no-network command`. Is there any reason why Bazel doesn't do this?

We are running off of 60af9db, somewhere past 0.3.1.
