Title

Quarkus Spring Data documentation should document newly supported interfaces and update existing examples

Description
### Describe the bug

Following [URL]

- 2 new interfaces are supported: `ListCrudRepository` and `ListPagingAndSortingRepository`. This has been mentioned in the migration guide [URL] but is completely omitted from [URL]

                .when().delete("/fruits/1")
                .then()
