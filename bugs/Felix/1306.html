Title

No log message on missing activate method

Description
DS spec 112.5.8 says: 

 If the activate attribute is specified and no suitable method is located, SCR must log an error message with the Log Service, if present,... 

 This is not implemented and the lack makes it really hard to figure out why the DS isn't activated.
Discussion
- logs missing activate, deactivate, and modified methods
- Thanks for reporting the bug and providing the patch. 

 Actually, the situation of a declared method not being found is already logged in the BaseMethod.setMethod method. But this is logged at DEBUG level, which is why the message is generally not printed. 

 I fixed this to log an error level message as stipulated by the spec in Revision: 1125294
