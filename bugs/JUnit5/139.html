Title

Ensure test classes cannot be private

Description
## Overview

If a test class is discovered via class path or module path scanning, it cannot be `private`; however, if the test class is _selected_ explicitly (e.g. via `DiscoverySelectors.selectClass(Class)`) it can then be `private`.

The downside is that such `private` test classes will **never be executed** with a typical build configuration that relies on class path or module path scanning.

## Deliverables

- [x] Ensure that test classes can never be `private`.
