Title

JSCompiler does not recursively resolve typedefs

Description
goog.provide('a.b.c');

goog.scope(function() {
var b = a.b;
var c = b.c;

/** @typedef {string} */
c.MyType;

/** @param {c.MyType} x The variable. */
c.myFunc = function(x) {};

});

results in a compiler error.

given that JSCompiler *does* recursively resolve other names, this appears to be a bug rather than an intended limitation.
Discussion
- I'm fairly certain that typedefs have to be in the global scope. Although I'm not sure that has been documented anywhere or is the intent.

If you remove the goog.scope wrapper, your code compiles correctly.
- no, typedefs don't have to be in the global scope. goog.scope must enclose everything in the file except goog.provide/goog.require
