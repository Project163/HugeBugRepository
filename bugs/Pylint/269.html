Title

logging checker doesn't recognize Logger subclasses

Description
If I create a subclass of `logging.Logger`, Pylint's `logging` checker does not seem to recognize instances of this class to be checked:
### Steps to reproduce

```
python
# logger.py
import logging

l1 = logging.getLogger('one')
... [Log Snipped] ...
l3.info('testing {0}'.format('info'))
l3.info('testing %s' % 'info')
```

``` bash
pylint --disable=all --enable=logging-format-interpolation,logging-not-lazy logger.py -rn 
```

At first I thought this might be an issue with `logging-modules` but setting that doesn't seem to help:

``` bash
pylint --disable=all --enable=logging-format-interpolation,logging-not-lazy logger.py -rn --logging-modules=logging,logger
```
### Current behavior

```
No config file found, using default configuration

W: 16, 0: Specify string format arguments as logging function parameters (logging-not-lazy)
```

Note that the calls to my Logger subclass are not flagged by the logging checker.
