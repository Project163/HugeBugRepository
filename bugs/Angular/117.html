Title

Transformer does not handle const instance annotations on properties.

Description
For example:

```
@Component(...)
@View(...)
class MyComponent implements MyFieldGetter {
  @override
  String get myField => 'Yeah!';
}
```

Registers the annotation as:

```
const [const override()]
```

Rather than

```
const [override]
```
