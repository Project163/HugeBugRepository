Title

Limit produce wrong number of records after foreach flatten

Description
From user mailing list:  [URL] Sungho reported the following script produce wrong result as expected: 

 data = LOAD '1.txt' AS (k, v); 
grouped = GROUP data BY k; 
selected = LIMIT grouped 2; 
flattened = FOREACH selected GENERATE FLATTEN (data); 
dump flattened; 

 1.txt: 
1       A 
1       B 
2       C 
3       D 
3       E 
3       F 

 Expected result: 
(1, A) 
(1, B) 
(2, C) 

 We get: 
(1, A) 
(1, B)
Discussion
- I believe this should go into 9.1 given that we might producing wrong results
