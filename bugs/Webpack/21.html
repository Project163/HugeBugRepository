Title

Watch breaks files outputted by CommonsChunkPlugin

Description
I am running across a bug where Webpack generates an invalid Javascript file when running in watch mode. This bug occurs 100% of the time, the first time I modify `Cards.js` in watch mode. Once the file is in a bad state, I keep on getting the following error:

```
 undefined is not a function
__webpack_require__@[URL]
Object.webpackJsonp.0@[URL]
__webpack_require__@[URL]
webpackJsonpCallback@[URL]
(?)()@[URL] printUncaughtErrorCommon.js:1285 window.onerror
Common.js:51 Uncaught TypeError: undefined is not a function
```

The only way to fix the problem is to clean-build the entire project (further incremental changes to the file do not fix the problem).

Here is a copy of `Common.js`: [URL]
Here is a copy of `Cards.js`: [URL]

I am modifying `Cards.js` line 54 over and over in order to trigger this problem.

I walked through the code and discovered that the browser hits line 51 with `module[moduleId]` equal to 29. This is problematic for two reasons:
1. Usually `module[moduleId]` points to a function, not a number.
2. Module 29 is generated by a call to `require("./ResourceTable.scss")`. If you look for it in `Common.js` you will notice it is not defined.
Discussion
- I think I figured out the problem.
1. I have multiple entry points, one of them is called `Cards.js`
2. At build-time, webpack outputs `Cards.js`, `Common.js` and JS files for other entry points.
3. At watch-time, I modify `Cards.js` and Webpack outputs:

```
[00:11:48] Compiling webpack config ~\Documents\realestate\frontend\webpack.config.js
[00:11:48] 
              Asset  Size  Chunks             Chunk Names
Authentications.css   335       4  [emitted]  Authentications
          Index.css   510       2  [emitted]  Index
          Cards.css   531       3  [emitted]  Cards
         Common.css   190       5  [emitted]  Common
```

Fortunately, I've got [URL] enabled, and its plugin outputs:

```
[BS] 4 files changed (Authentications.css, Index.css, Cards.css, Common.css)
```

Meaning, in step 3 Webpack is modifying `Cards.js` but not `Common.js`. This means that module IDs change in `Cards.js` which will cause `Common.js` to break.

Here is a copy of my `webpack.config.js`:


I believe that in order to fix this issue, webpack needs to rewrite `Common.js` on watch.
