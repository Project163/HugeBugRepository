Title

IndexOutOfBoundsException in FullHttpResponse.copy() (using CompositeByteBuf)

Description
netty version 4.0.4.Final

copy() and duplicate() don't works for FullHttpResponse with zero length content
for instance when I have 304 response: FullHttpResponse.toString()

```
DefaultFullHttpResponse(decodeResult: success)
HTTP/1.1 304 Not Modified
Server: MochiWeb/1.0 (Any of you quaids got a smint?)
Date: Wed, 24 Jul 2013 00:01:07 GMT
Cache-Control: max-age=10
Content-Length: 0
```

then calling FullHttpResponse.copy() produce next exception 

```
java.lang.IndexOutOfBoundsException: index: 0 (expected: range(0, 0))
    at io.netty.buffer.AbstractByteBuf.checkIndex(AbstractByteBuf.java:1119)
    at io.netty.buffer.CompositeByteBuf.toComponentIndex(CompositeByteBuf.java:566)
    at io.netty.buffer.CompositeByteBuf.copy(CompositeByteBuf.java:985)
    at io.netty.buffer.AbstractByteBuf.copy(AbstractByteBuf.java:905)
    at io.netty.handler.codec.http.DefaultFullHttpResponse.copy(DefaultFullHttpResponse.java:93)
```

I believe same issue exists for DefaultFullHttpRequest and duplicate() call
