Title

Strange high CPU usage / staggering framerates in fullscreen in macOS Mojave.

Description
Hello.
This is something I noticed while I built my 3D engine using glfw in macOS Mojave.
The framerates were off. It was like the vsync was not happening, and the engine would be blasting frames to the screen too fast. I tried both with vsync enabled and disabled, no difference.

I also noticed my program was using unusually high CPU times, like around 50-60% for just a very simple scene, like one simple dodecahedron rendered, which previously hadn't taken anything above 10% ever IIRC. 

I was wondering what the heck was happening, because I hadn't change anything, only thing I had done I had not built my engine on Mojave, last time I tried it was in High Sierra (10.13).

Now, trying to pinpoint the problem I started to look at how the examples shipped with glfw were behaving. Running even the basic examples that are bundled with glfw I'm seeing strange things. Running the bounce app in windowed mode is taking nearly 85% in CPU usage, as seen here reported by top:
