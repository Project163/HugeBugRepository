Title

Modules imported to top level of class cause error.

Description
When you have an import statement inside a class, mypy throws an error. An example that causes this error is:

```
class _coconut:
    import collections, functools, imp, itertools, operator, types, copy
```

The error thrown is:

```
Traceback (most recent call last):
  File "C:\Users\fred\Anaconda3\Scripts\mypy", line 6, in  
    main(__file__)
  File "C:\Users\fred\Anaconda3\lib\site-packages\mypy\main.py", line 54, in main
    res = type_check_only(sources, bin_dir, options)
... [Log Snipped] ...
    if func.type:
AttributeError: 'MypyFile' object has no attribute 'type'
```

Thanks in advance.
