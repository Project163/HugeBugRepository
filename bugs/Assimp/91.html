Title

Bug: Heap-based Buffer Overflow in Assimp::LWO::AnimResolver::UpdateAnimRangeSetup

Description
### Summary

heap buffer overflow in `Assimp::LWO::AnimResolver::UpdateAnimRangeSetup`. An attacker could potentially exploit the vulnerability to cause a remote code execution, if they can trick the victim into running assimp on a malformed LWO file.

### Affected

assimp>=5.4.3

### Details

In `code/AssetLib/LWO/LWOAnimation.cpp:210` , `n` is reading out of bound variable than allocated `it (Assimp::LWO::Key)`, which caused heap buffer overflow.

```
cpp
// code/AssetLib/LWO/LWOAnimation.cpp:210
n = (*it).keys.end() - (old_size + 1);

// code/AssetLib/LWO/LWOAnimation.cpp:213
... [Log Snipped] ...

        (*n).time -= cur_minus;
```
