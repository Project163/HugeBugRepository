Title

NUnitLite can't load assemblies by their file name

Description
Create new console project 'test', add nunitlite nuget package to the project, compile and run the project:

`test.exe test.exe`

There will be an error: `the file or assembly "test.exe" could not be loaded`. nunitlite requires to pass assembly name instead of file name as parameter, and this does not allow to pass assemblies which are located in other directories and differs from behaviour of nunit-console, which requires to pass file names in command line. 

More info in #481
