Title

3.0.4 - Unable to get virtual field after a save

Description
Hello,

Today i saw a test failed in my application, after some debug, i saw that it's work with the version 3.0.3 but fail with the 3.0.4.

The bug is that when calling a virtual field just after saving an Entity, it doesn't return the expected result.

How to reproduce :
src\Model\Entity\User.php :

```
php
 loadModel('Users');

$custom = [
    'user_id' => 1,
... [Log Snipped] ...

debug($user->premium); // Return true with the version 3.0.4 and 3.0.3
```

And i expect that, just after the `$this->Users->save($user)`, the `$user->premium` should return `true`.
Discussion
- This is probably related to mutator caching. Dynamic time based properties will not work with cached values. We might be missing a cache clear when saving.
