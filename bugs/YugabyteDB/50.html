Title

JSON: Unknown data type code error with cqlsh

Description
For the JSON type (new in upcoming 1.1), the default cqlsh bundled with YugaByte needs to be updated to the version that has the updated wire protocol type code for JSON type. 

Current version seems to be older.

```
[ tserver]$ ./bin/cqlsh  
Connected to local cluster at  :9042.
[cqlsh 5.0.1 | Cassandra 3.9-SNAPSHOT | CQL spec 3.4.2 | Native protocol v4]
Use HELP for help.
cqlsh> describe my_keyspace.employee;
... [Log Snipped] ...
    raise self._final_exception
NotSupportedError: Unknown data type code  . Have to skip entire result set.
```

**Workaround for now:**

For now, to workaround, you can download the correct version of cqlsh from [URL]
