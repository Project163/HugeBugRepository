Title

snapshot with exclude expression `-` does not work if you specify explicit index name

Description
### Elasticsearch Version

7.16.2

### Installed Plugins

_No response_

### Java Version

_bundled_

### OS Version

OS X

### Problem Description

On [URL] you can see that `-*` allows you to exclude all data streams and indices and I thought a single hyphen `-` works as exclude expression.

Then I wanted to only exclude certain index and I used `-us` which resulted in the error below.
The workaround I found was  `-u*` to exclude index named `us`.

I am not sure if this is intended, but if it is, I think it might be helpful to indicate that you cannot specify explicit index name like I did and it has to be combined with wildcard `*` to do so.


(Optional, string or array of strings) Comma-separated list of data streams and indices to include in the snapshot. Supports [Link: multi-index syntax]. Defaults to an empty array ([]), which includes all regular data streams and regular indices. To exclude all data streams and indices, use -*.
