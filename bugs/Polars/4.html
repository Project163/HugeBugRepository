Title

DataFrame.__add__ string returns empty column names

Description
#### Are you using Python or Rust?

Python


#### What version of polars are you using?

0.10.25

#### What operating system are you using polars on?

W10

#### Describe your bug.
Trying to cover some final gaps in our test coverage. It seems to me  that this should work, given the code that handles strings explicitly, and that it does work on `pl.Series`:

```python
def test_add_string() -> None:
    df = pl.DataFrame({"a": ["hi", "there"], "b": ["hello", "world"]})
    result = df + " hello"
    expected = pl.DataFrame({"a": ["hi hello", "there hello"], "b": ["hello hello", "world hello"]})
    assert result.frame_equal(expected)
```
It also returns nearly the right output, except for the column names:

```
shape: (2, 2)
┌─────────────┬─────────────┐
│             ┆             │
│ ---         ┆ ---         │
... [Log Snipped] ...
│ there hello ┆ world hello │
└─────────────┴─────────────┘
```
Whereas for numeric operations, the column names are preserved.
