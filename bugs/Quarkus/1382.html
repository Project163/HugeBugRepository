Title

QuarkusUnitTest.getLogRecords() cannot be used from within a test method

Description
### Describe the bug

The returned list is always empty, i.e. you can't do something like this:
```
java
public class MyTest {

    @RegisterExtension
    static final QuarkusUnitTest config = new QuarkusUnitTest()
... [Log Snipped] ...
   }
}
```

It can be a problem related to the fact that the test class is initialized twice, i.e. there are two instances of `QuarkusUnitTest` created for each test class.

Note that `QuarkusUnitTest.assertLogRecords(Consumer >)` works just fine and since the consumer is called during `AfterAllCallback` it can be used to assert log messages published during execution of test methods.
