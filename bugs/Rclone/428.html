Title

Google Drive: tls: bad record MAC

Description
Firstly I would like to say that I have viewed the similar issue reports and have tried the debugging methods suggested (i.e the disabling of checksums)

I am getting this issue when copying large files from my Raspberry Pi 4 (4gb) running the latest and fully updated Raspbian Buster Lite.

I am attempting to copy files to a Team Drive. I get this issue whether I use rclone copy or do a regular copy command to the rclone mount.

The issue comes up only after 1 or 2 large transfers, I can normally upload 1 or 2 files but then each large file after that will fail. After a prolonged period of time, if I try the upload again, it will succeed.

The files are between 1 and 2gb, but anything larger suffers from the same issue.

The file fails to upload with the "tls: bad record MAC" error, retries 3 times (which fail with the same error each time) then cancels the upload.
