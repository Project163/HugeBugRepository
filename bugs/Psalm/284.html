Title

false positive MixedArrayAssignment when typecasting array elements with null coalesce

Description
[URL]
```php
function (array $out) : array {
  $out['attr'] = (array) ($out['attr'] ?? []);
  
  $out['attr']['media'] = 'screen';
  
  return $out;
}
```

* if `'attr'` is present on `$out`, the value will be `$out['attr']`.
* if `'attr'` is not present, it is set to `[]` via a null coalescing operation
* in both cases, it is typecast to an array.
* therefore, `$out['attr']` will always be an array.

`$out['attr']['media'] = 'screen';` triggers `ERROR: MixedArrayAssignment - 6:3 - Cannot access array value on mixed variable $out['attr']['media']`

versions affected:
*   aka 1.1.7
* 200ea70 (from getpsalm.org)
Discussion
- Can be worked around by adding `/** @param array{dummy?:string} $out */` docblock: [URL]
