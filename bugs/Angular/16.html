Title

Inifinite recursion in gulp task 'cleanup.builder'

Description
see [URL]

I was able to workaround by modifying the `gulpfile.js`:

```
js
// register cleanup listener for ctrl+c/kill used to quit any persistent task (autotest or serve tasks)
process.on('SIGINT', function() {
  gulp.start('cleanup.builder');
  process.exit();
... [Log Snipped] ...
  //gulp.start('cleanup.builder');
});
```

To reproduce the issue: add an unexisting file in `vendorScriptsTree` (`browser_tree.ts`) : 

``` js
  var vendorScriptsTree = flatten(new Funnel('.', {
    files: [
      '/path/to/nowhere',
      ...
    ]
  }));
```
