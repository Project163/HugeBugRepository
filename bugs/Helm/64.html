Title

Revision flag missing in help for helm status

Description
With the changes of #7917 , the help text for `helm status` no longer shows the `revision` flag.

My guess is that this is caused because helm status creates its revision flag as a PersistentFlag:
[URL]

However, the kubectl package used to group commands, I'm guessing shows persistent flags in a `helm   options`.

I think there is no need to use a persistent flag for `helm status --revision` (a persistent flag is a flag that is inherited by sub-commands).  Note that the `--revision` flags of the different `helm get` commands are not persistent.

Output of `helm version`:
version.BuildInfo{Version:"v3.2+unreleased", GitCommit:" ", GitTreeState:"clean", GoVersion:"go1.13.7"}
