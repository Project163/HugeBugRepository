Title

compact.sw approval test fails in 2.2.1

Description
## Description
As a supplemental to issue #1200, we are trying to build and test Catch 2.2.1, and in addition to the path-related issues with the XML tests, we are getting complaints with the compact.sw test. In contrast to issue #1200 we appear to get the same problems with an in-source build.

### Steps to reproduce

CXX=g++ CC=gcc cmake -DCMAKE_INSTALL_PREFIX=  -DUSE_CPP14:BOOL=ON .
make -j 
ctest -j  --output-on-failure

### Extra information

* Catch version: **v2.2.1**
* Operating System: **Scientific Linux 7**
* Compiler+version: **GCC 7.3.0, C++14**
* CMake version: **CMake 3.10.1**

Discussion
