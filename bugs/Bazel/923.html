Title

"test" exec group fails to properly inherit from default exec group

Description
(This is a copy of an internal issue that was filed on 2021/03/20).

Exec group inheritance is complicated, and does not correctly inherit from the default exec group properties when they come from the execution platform.

The fix involves a large rework of exec group inheritance, which is currently in progress.
Discussion
- Previous commits in the fix:
-  : Split ExecGroup into a new target
-  : Move DEFAULT_EXEC_GROUP_NAME from ToolchainCollection to ExecGroup
-  : Rename ToolchainCollection.getExecGroups to getExecGroupNames
-  : BuildViewForTesting should directly call into ConfiguredTargetFunction
-  : Move exec group tests out of platforms_test and into integration
-  : Update creating exec groups that explicitly copy from defaults
- There are a few more commits coming to finish this fix.
