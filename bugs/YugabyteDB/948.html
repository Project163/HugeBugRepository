Title

[Xcluster] [Packed columns] ERROR: Schema packing not found: 0, available_versions: [1]

Description
Jira Link: [Link: DB-6280]
### Description

On version: **_2.18.0.0-b24_**

On Target side of a x-cluster, `select count(*)` query fails with the below error for a few non-colocated table.

`ERROR:  Schema packing not found: 0, available_versions: [1]`

Note: Packed columns was enabled on both Tserver and Master

Steps:
```
1. At source universe, restore a backup which contains 10k colocated tables(1k rows in each table)
2. Create 100 non-colocated tables and load 100k rows in each table
3. Execute count(*) on colocated and non-colocated table at source -> Works fine
4. Execute count(*) on non-colocated table at Target universe -> Fails for some non-colocated tables
```
**Instance Used**: c5.2xlarge(8 core and 16GB) with RF3
