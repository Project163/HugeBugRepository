Title

adding default format option to [directory] disables read_only trait

Description
#### Current Behavior
 
adding default `format` option to [directory] removes the read only symbol lock

ie:
```
[directory]
style = "bold black dimmed"
format = "[Link: $path][Link: $lock_symbol]"
```

#### Expected Behavior
 
if i remove format the read only lock symbol  correctly shows up
