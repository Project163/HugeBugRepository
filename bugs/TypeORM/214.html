Title

Relation columns in embedded entities are not prefixed

Description
## Issue Description

When using relations inside embedded entities (`@ManyToOne`), their columns are not prefixed with the embedded entity prefix, unlike with normal `@Column`s. Whether a custom prefix is provided or the property name is used makes no difference.

See also: #3226, #3132 and #2254. Partially fixed by PR #3025.

Example scenario:

```
typescript
import { Column, createConnection, Entity, ManyToOne, PrimaryGeneratedColumn } from "typeorm";

@Entity()
export class UserEntity {
... [Log Snipped] ...

createConnection().then(async () => {}).catch(error => console.log(error));
```

### Expected Behavior
```sql
CREATE TABLE `user_entity` (
  `id` int NOT NULL AUTO_INCREMENT,
  `banUserId` int NULL,
  `banReason` varchar(255) NULL,
  PRIMARY KEY (`id`)
) ENGINE = InnoDB
```


### Actual Behavior
```sql
CREATE TABLE `user_entity` (
  `id` int NOT NULL AUTO_INCREMENT,
  `userId` int NULL, # Missing ban prefix
  `banReason` varchar(255) NULL,
  PRIMARY KEY (`id`)
) ENGINE = InnoDB
```

### Steps to Reproduce

1. `git clone [URL]
2. `npm install`
3. `npm run start`
