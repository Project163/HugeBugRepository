Title

Newly installed instance could use incorrect "utf8" charset for MySQL

Description
A default install could produce such app.ini:

```

RUN_USER=xiaoguang
RUN_MODE=prod

[database]
... [Log Snipped] ...
PATH=/Users/xiaoguang/work/gitea/data/gitea.db
LOG_SQL=false
```


"utf8mb4" is required for MySQL to work with emoji.
