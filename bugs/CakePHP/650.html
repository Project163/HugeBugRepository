Title

Host key included during connection when I set postgres host config to blank

Description
According to the docs [http://book.cakephp.org/3.0/en/orm/database-basics.html#configuration]

```
unix_socket
    Used by drivers that support it to connect via Unix socket files. If you are using PostgreSQL and want to use Unix sockets, leave the host key blank.
```

However, when I leave the host key as blank, I get this error:

```
SQLSTATE[08006] [7] could not translate host name "port=5432" to address: Name or service not known 
```

My intention was to leave out the host param when connecting - according to 
[http://php.net/manual/en/ref.pdo-pgsql.connection.php#80091]
