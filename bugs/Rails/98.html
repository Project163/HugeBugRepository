Title

as_json produces `too few arguments` error when used in a view

Description
I'n not entirely sure where the error is, but if I use a json output for a column named `format` in a view it produces the error: 

```
too few arguments
```

This is reproducible with Rails (Active Record 4.1.1)

**This error does not happen in Rail 4.0.4**

I have a table with a column named `format`, when doing this inside a view:

```
= BookFormat.where(format: 'paperback').as_json
```

I get the `too few arguments` error. Without `as_json` it outputs fine. 

In an IRB it works fine, even with JSON:

```
BookFormat.where(format: 'paperback').as_json
BookFormat Load (0.5ms)  SELECT `book_formats`.* FROM `book_formats`  WHERE `book_formats`.`format` = 'paperback'  ORDER BY format
[{"id"=>3, "format"=>"Paperback"}, {"id"=>194, "format"=>"Paperback"}]
```

So I figured out the cause. It was working purely by accident in 4.0. This stopped working after [URL]

The reason is that the code there used to call `respond_to?`, which is [Link: another trigger point] to generate the attribute methods. Presumably, that code path was executed when AR was trying to see if there's an `after_initialize` callback.

So, now that the code doesn't need to call `respond_to?` anymore after the refactor, things stopped working because of what I said earlier. :neutral_face:
