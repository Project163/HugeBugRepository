Title

[Angular 9 - i18n] Cannot use empty strings as translations anymore

Description
# 🐞 bug report

### Affected Package

The issue is caused by package `@angular/localize` and/or Ivy (not sure).
The crash happens here: [URL]


### Is this a regression?

Yes, the last previous version in which this bug was not present was: Angular 8.2.14.


### Description

When translating an app in different locales, it may be wanted to translate some strings to `""`.
With Angular 8, it was possible to let some translation ` ` with empty value in XLIFF 1.2 files. The result would be an empty HTML element.
But with Angular 9, it seems not possible anymore. When a ` ` is left empty and the corresponding bundle generated, [Link: the app crashes at this line] when the page containing the empty target is rendered:

    TypeError: Cannot read property 'directiveStart' of null

Please note that this crash only happens when the empty ` ` concerns an HTML tag content. When the empty ` ` concerns an HTML *attribute* translation, the app won't crash.

## 🔬 Minimal Reproduction

Minimal reproduction available at: [URL]

I've generated this example using `ng new myapp` and added `@angular/localize` using the [Link: official documentation].
The `i18n` tagged span is [Link: here].

Build steps:
- `npm install`
- `npm run build`
- `http-serve dist/myapp`
- Navigate to the `/fr/` build and look at the console.

- Hello,

I have the same problem: `Cannot read property 'directiveStart' of null` with since Angular 9.

The crash happens because [Link: inside `ɵɵelementEnd()`], `previousOrParentTNode.parent` is `null` (a type forcer `!` is added to override this case, but it happens to be `null` anyway).
Then, `registerPostOrderHooks()` is [Link: called with `previousOrParentTNode = null`, which shoudn't happen and creates the crash].

The following diff in `@angular/core` suppresses the crash, but results in some HTML tags being closed prematurely:
```
diff
--- a/packages/core/src/render3/instructions/element.ts
+++ b/packages/core/src/render3/instructions/element.ts
@@ -126,6 +126,8 @@ export function ɵɵelementEnd(): void {
   ngDevMode && assertDefined(previousOrParentTNode, 'No parent node to close.');
```
