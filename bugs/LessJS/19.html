Title

Line breaks in selectors generate wrong rule

Description
This valid CSS works well with LESS:

.tabs a {color:#454545;}

is converted into

.tabs a {
  color: #454545;
}

But it the selector contains a line break LESS converts it into a wrong rule:

.tabs 
a {color:#454545;}

is converted into

.tabsa {
  color: #454545;
}

which, of course, breaks my layout completely :-)
