Title

[YSQL] Unique Index creation succeeds even when unique constraint fails

Description
While creating unique index on existing data, if unique constraint fails for one/more of the rows, the index still gets created with incorrect data.
See this example:
```
yugabyte=# create table foo(a int primary key, b int);
CREATE TABLE
yugabyte=# insert into foo(a) select generate_series(1,1000);
INSERT 0 1000
yugabyte=# \timing on
... [Log Snipped] ...

Time: 9.469 ms
```
Discussion
- Partial transactional DDL implemented in #3108 wasn't applied to `CREATE [UNIQUE] INDEX`, leading to this issue.
FIxed in 39e4845.
