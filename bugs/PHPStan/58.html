Title

Type hint elements in an associative array

Description
# Support question

Is there a way to type hint associative array members?

Given the following array:

```php
$model = [
  'id' => 123,
  'name' => 'Some name',
];
```

what would the `@param`/`@var` for this look like? If I have a method that takes such an array as a parameter, and simply add `@param array $data` I get the following error:

    Method Model::doSomething() has parameter $data with no value type specified in iterable type array.

as seen in this snippet: [URL]
Discussion
- You can do it like this
```php
/**
 * @param array{id:int, name:string} $data
 */
```
- Thanks. This seems to work in some cases, but not all.

If you have a look at [URL] the "validation" in `doSomething` seems to cause the error messages. It seems that the `isset` confuses PHPStan to think that the elements can be either an `int` or a `string`.

- If you want to typehint the specific value types of each property I don't have a solution beyond what was already mentioned, but if you just want to say "this array contains multiple data types" then you can typehint it with `mixed[]`
