Title

Refresh method does not use an alias in the condition

Description
When the model has an alias (by alias() method) – refresh() method does not apply an alias in where condition.

### What steps will reproduce the problem?
Create a model and set an alias in find().
```
public static function find(): ModelQuery
{
    return (new ModelQuery(get_called_class()))->alias('alias');
}
```

Then call $model->refresh();

### What is the expected result?
The query must be like 
```
SELECT * FROM `table` `alias` WHERE `alias`.`id`=1
```

### What do you get instead?
Result:
```
Column not found: 1054 Unknown column 'table.id' in 'where clause'
The SQL being executed was: SELECT * FROM `table` `alias` WHERE `table`.`id`=1'
```
