Title

Collection classes require a len implementation

Description
**Migrated issue, originally created by jek ([Link: @jek])**

InstumentedList is (accidentally?) requiring collection classes to implement `__len__`.  Attached is a patch to use `__len__` if available on the collection class implementation, otherwise transparently emulate it through counting `__iter__`.
