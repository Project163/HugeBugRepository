Title

[Docs] Missing password for 'kibana_system' after update to 7.8

Description
**Elasticsearch version** (`bin/elasticsearch --version`):
`Version: 7.8.0, Build: default/tar/ /2020-06-14T19:35:50.234439Z, JVM: 11.0.7`

**JVM version** (`java -version`):
`OpenJDK 64-Bit Server VM AdoptOpenJDK (build 11.0.7+10, mixed mode)`

**OS version** (`uname -a` if on a Unix-like system):
`Linux 3.10.0-1127.el7.x86_64 #1 SMP Tue Feb 18 16:39:12 EST 2020 x86_64 x86_64 x86_64 GNU/Linux`

**Description of the problem including expected versus actual behavior**:
Just updated from 7.7 to 7.8 and changed the `Kibana` config to use the `kibana_system` user instead of `kibana`, as described in [Link: BreakingChanges]. Unfortunately afterwards `Kibana` can no longer authenticate to `Elasticsearch`. I had to explicitly set the password for `kibana_system` to the one of `kibana` to make it work again.

Please update the release docs to clearly state that the password for `kibana_system` must be set explicitly. The current description of "user was `renamed`" implies that the existing password would be preserved, which is not the case.

`curl -s -k -u kibana_system:  [URL]
