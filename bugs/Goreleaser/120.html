Title

ProjectName doesn't get populated in before pipe

Description
### What happened?

When `project_name` is not specified, Goreleaser guesses the project name from the git remote URL. However, not during the before pipe. During the before pipe, `{{.ProjectName}}` is empty and not guessed from the remote url.

### How can we reproduce this?

A sample repository

```sh
mkdir test
cd test
git init
git remote add origin git@github.com:example/test.git
```

Goreleaser config

```yaml
before:
  hooks:
    - echo "{{.ProjectName}}"

release:
  footer: abc
```
