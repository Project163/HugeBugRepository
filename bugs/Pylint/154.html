Title

unpacking-non-sequence raised when calling subclass methods (pylint 1.5-master)

Description
Originally reported by: **BitBucket: [Link: ThomasChiroux], GitHub: @ThomasChiroux?**

---

Pylint raises errors "Attempting to unpack a non-sequence defined at line xx (unpacking-non-sequence)" when calling a subclassed method wich overrides the method of the upper class. The subclassed method returns a good sequence, the upper-class method may not return a good sequence.

astroid/pylint installed from master:

```
#!bash

pip install hg+[URL]
pip install hg+[URL]
```

ex:

```
#!python

class TestBase:

    def __init__(self):
... [Log Snipped] ...
    def test(data):
        return (1, 2, 3, 4, 5)
```

pylint raises:

```
#!bash

E: 14, 8: Attempting to unpack a non-sequence defined at line 15 (unpacking-non-sequence)
```

for the class Test, and does not raise the error for the class Test2.

It seems that pylint looks at the _test_ method from TestBase even if super() is not called in the _test_ method of class Test.
