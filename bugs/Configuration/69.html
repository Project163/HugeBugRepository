Title

Incorrect date format in XMLPropertyListConfiguration

Description
The date format used in XMLPropertyListConfiguration is incorrect, it should be : 

     <date>2002-03-22 11:30:00 +0100</date> 

 instead of : 

     <date>2005-01-01T12:00:00-0700</date> 

 See  [URL]
Discussion
- The date format I used for the implementation was taken from the DTD at  [URL] it doesn't match the format documented on the GNUStep site. The date format we are using currently is rejected by the plutil tool, I'll check if the gnustep format is accepted.
- It's seems I'm not the only one to notice this inconsistency : 

  [URL]

 I suggest to support both formats for parsing, and ouput only in the Apple format, that's 2005-01-01T12:00:00Z (and not 2005-01-01T12:00:00-0700 which was incorrect).
- Fixed on the trunk and the 2.x branch.
