Title

[Rest Api Compatibility] Do not throttle logs for different deprecated routes

Description
At the moment compatible log for deprecated rout is using the same key for different routes - `deprecated_route`
That means that if someone calls post /{index/{type}/_doc and then any other deprecated route like  get /{index}/{type}/3 
he will only be informed about the first route. No other deprecation logs for `deprecate_route` key will be visible in logs/index as they will be throttled.
We should possibly suffix the key with the path/method to prevent this
