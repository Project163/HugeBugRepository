- sch.oh  You could refer to  state schema_evolution  docs to know how to migrate your state when schema changed. Please note there is no guarantee that any kind of schema change could be migrated well, you'd better follow the instruction in this doc to evolve your classes. 

 Last but not least, I don't think this is a bug with your current provided information. IMO,  user mail list  should be a better place to ask for help.
- yunta  Thank you for your reply. 

 I had already read the schema evolution document. But I can't change all kinds of my classes to POJO or Avro. 

 So I found another solution. 

 I changed the serializer(FieldSerializer => CompatibleFieldSerializer) through the ExecutionConfig.addDefaultKryoSerializer function with trait. 

 I will end the issue. 

 Thank you again.
