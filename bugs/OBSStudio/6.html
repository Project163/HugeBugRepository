Title

libobs: obs_data_item_get_default_obj/_array returns bad data.

Description
## Platform
Operating system and version: Windows 10 2004
OBS Studio version: master

## Expected Behavior
Calling `obs_data_item_get_default_obj` and `obs_data_item_get_default_array` should return the default values of an item.

## Current Behavior
Calling either of the functions returns the current user data, instead of the default data.

## Steps to Reproduce
1. Call `obs_data_item_set_default_obj` or `obs_data_item_set_default_array` with valid objects.
2. Call `obs_data_item_set_obj` or `obs_data_item_set_array` with valid or invalid objects.
3. Call `obs_data_item_get_default_obj` or `obs_data_item_get_default_array`.
4. Returned values mismatch actual default objects. Objects are now inaccessible.

2. [URL]

This was accidentally found while testing the libobs validation layer I built to verify my plugin against. An obs_data test would always fail, despite being correct in theory, so investigation revealed that these two functions are the cause.

- Weirdly, `string`, `int`, `double`, and `bool` use `get_item_default_data` as their second parameter. I'll make a PR with that change instead, and we'll see from there.
