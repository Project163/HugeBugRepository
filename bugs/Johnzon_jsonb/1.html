Title

@JsonbTransient is not working

Description
When annotating a field with  @JsonbTransient  that field is still included in the JSON. 

 Example: 

  
  public   class  Book {

  @JsonbTransient
   private   long  id;

  @JsonbProperty( "_name" )
   private   String  name;

   // getters & setters
 }
 
  

 The output of that example is: 
  
 { "_name" :  "test" ,  "id" :123}
