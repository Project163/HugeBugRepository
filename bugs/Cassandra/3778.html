 I'm a little concerned that we had to up MAX_ATTEMPTS, however. Not that I mind having a higher number (I'd be happy with it being higher still), but if we're hitting it with any frequency I suspect something else is up other than jenkins' servers being slow (and if so, we're at risk of hitting this in production). The loop is only to avoid race conditions - repeating once should ordinarily be sufficient, as the race has (or should have) already passed by the time we're done. So this would imply we're hitting five races in a row, which seems like it should be a very rare event. Are we perhaps missing something?
