Title

Incorrect superfluous-parens in 'in' short-circuit

Description
Originally reported by: **Anonymous**

---

Pylint incorrectly reports superfluous-parens when using short-circuit assignment. This happens both in if statements and comprehensions.

`$ cat test.py`

```
#!python

foo = None
if 'bar' in (foo or {}):
    pass
```

```
#!

$ pylint --version
pylint 1.4.3, 
astroid 1.3.6, common 0.61.0
... [Log Snipped] ...
************* Module pytest
C:  3, 0: Unnecessary parens after 'in' keyword (superfluous-parens)
```
