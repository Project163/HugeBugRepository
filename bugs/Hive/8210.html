Title

Fail to rename a partition with customized catalog

Description
How to trigger it?  
 1. Create a customized catalog in HMS 3.x 
 2. Run a sql like "ALTER TABLE student PARTITION (age='12') RENAME TO PARTITION (age='15');" 

 Error message: 
  
 
spark-sql> ALTER TABLE student PARTITION (age= '12' ) RENAME TO PARTITION (age= '15' );
Error in query: org.apache.hadoop.hive.ql.metadata.HiveException: Unable to rename partition. Unable to alter partition because table or database does not exist.;
 
  
 We can fix if by replacing  DEFAULT_CATALOG_NAME  with  catName  in the following line( [URL]
  
 
 Table tbl = msdb.getTable(DEFAULT_CATALOG_NAME, dbname, name,  null );
