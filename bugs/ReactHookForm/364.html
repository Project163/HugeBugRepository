Title

issue: toggling "disabled" in useController invalidates input entry

Description
### Version Number

7.47.0

### Codesandbox/Expo snack

[URL]

### Steps to reproduce

1. Go to CodeSandbox
2. Enter value inside "name" field (any non empty string value is okay)
3. Click submit and verify that form is submitted
4. Toggle on/off "disable" switch (Input should become grayed out and then normal)
5. Verify that initial value is still inside the field (meaning it should be valid)
6. Click submit and verify that form is invalidated, and "name" field is registered as invalid.

### Expected behaviour

Form submission should be allowed, the value exists. 
Value is visible as "field.value" inside `ControlledTextField` component, I've left a console.log to verify that as well.
