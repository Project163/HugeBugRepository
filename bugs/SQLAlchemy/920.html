Title

Regression: unable to eagerly fetch related entity through polymorphic join

Description
When trying to configure an eager join on an entity related to a polymorphic subclass of a related entity, the leaf related entity is not eagerly fetched.

Between release 1.3.0b2 and 1.3.0b3, this behavior changed. The likely commit that introduced this behavior change is  , related to #4469.

Example:

```
python
from sqlalchemy import (
    Column,
    ForeignKey,
    Integer,
... [Log Snipped] ...
user.foos[0].bar.fred
print("##########end")
```
