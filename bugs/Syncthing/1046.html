Title

TestCopyRange fails on Windows 2025

Description
### What happened?

Locally, on Windows 11, and on the windows-2025 GitHub runner (go 1.23 and 1.24), the `TestCopyRange` test is failing with `The request is not supported.`

To fix this, we need to change:

```go
err == syscall.ENOTSUP
```
to
```go
errors.Is(err, errors.ErrUnsupported)
```
a PR is forthcoming.
