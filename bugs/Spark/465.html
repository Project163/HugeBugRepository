Title

Stabilize the computation of logistic function in pyspark

Description
exp(1000) throws an error in python. For logistic function, we can use either 1 / ( 1 + exp( -x ) ) or 1 - 1 / (1 + exp( x ) ) to compute its value which ensuring exp always takes a negative value.

 def logistic(x):
   if  x > 0:
     return  1 / (1 + math.exp(-x))
   else 
     return  1 - 1 / (1 + math.exp(x))
