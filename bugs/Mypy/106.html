Title

Scope management of with-statement is wrong

Description
This code works in Python:

```
import contextlib

@contextlib.contextmanager
def f():
    yield 42
... [Log Snipped] ...

main()
```

Note that in main(), the return of f() (a) is used as the argument for g(a). Mypy doesn't understand that the scope of a extends into the next context manager call:

```
/Users/guido/mypy_tests/mypy_repro.py: note: In function "main":
/Users/guido/mypy_tests/mypy_repro.py:12: error: Name 'a' is not defined
```
