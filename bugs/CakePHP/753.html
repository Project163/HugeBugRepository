Title

Lowercased prefixes instead of camelized

Description
In 3.1.9 this commit,  , made it to the release. This currently breaks this [Link: 3.x project (Croogo)] because all prefixes are camelized in the folder structure and the namespaces. When chancing a camelized prefix folder and namespace to lowercase, it works flawless. On the error page (thrown by the `MissingControllerException`) also shows camelized prefix folders and namespaces, so I don't think it should be lowercased.

When reverting the code in `ControllerFactoryFilter` it works flawless with camelized prefixes.

We're using the `DashedRoute`.
Discussion
- I can confirm that this issue is both present in 3.1.9 (3.1.8 is OK) and 3.2.0.
The issue is effecting all prefix URLs, e.g.
URL `/admin` => routing to `OverviewController::index()` in `src/Controller/Admin` subfolder

Is now also not found anymore etc.

``` php
Router::prefix('admin', function ($routes) {
    $routes->connect('/', ['controller' => 'Overview', 'action' => 'index']);
}
```
