### Current Behaviour?

```shell
The `tf.linalg.inv` does not support `half` data type, while the doc on [Link] said `half` can be used.

The latest version (tf 2.9) also has this issue.
```

### Standalone code to reproduce the issue

```shell
import tensorflow as tf
import numpy as np

x = np.array([[1, 2], [3, 4]], dtype=np.half)
tf.linalg.inv(x)
```
