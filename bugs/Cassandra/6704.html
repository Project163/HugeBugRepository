Title

CEP-15 (C*) increase message timeouts for range barrier messages

Description
Messages involved in the coordination of accord barriers and sync points can take longer than those involved in typical operations and are not blocking client requests. Subjecting them to the same timeouts as client operations can destabilize the system by preventing background bookkeeping operations from completing and putting them into a retry loop. This patch special cases the timeouts for messages coordinating range barriers.
Discussion
- +1, arguably this might be something we want to do for more commands than just sync points, but this is pretty easily updated so no need to over engineer now.
