Title

3.0 Custom view object with email

Description
I trying to use a custom view with the Email, using the method  viewRender() , but Email always use the default class  Cake\View\View . Debugging into this I see the following bug, In the method  _renderTemplates  specifically in the following lines
Email.php:1713

``` php
        $viewClass = $this->_viewRender;
        if ($viewClass === 'View') {
            $viewClass = App::className('View', 'View');
        } else {
            $viewClass = App::className($viewClass, 'View', 'View');
        }
        $viewClass = 'Cake\View\View'; //  Cake\View\View  as the class to use, commenting this statement my code works fine and I can use my custom view.
