Title

Async Examples are broken on wasm32 backend

Description
Hey there, 

I tried to compile the Pokedex example with `cargo build --target wasm32-unknown-unknown` but it failed, saying that there was a problem with the types of my futures not being `Send`. 

Basically, the `From ` implementation for `Command ` in `iced_futures/src/command.rs` is requiring - even on wasm32 targets - that the A generic (so, the future) be Send. That's fine for the native backend, but the iced-futures wasm-bindgen backend doesn't want its futures to be Send because it's storing them in an Rc >, thus making the example crash. 

Fiddled around in the source code, managed to get the example to work on wasm32 backend after this diff : 

```
diff --git a/futures/src/command.rs b/futures/src/command.rs
index d4f99b8..60e08b7 100644
--- a/futures/src/command.rs
+++ b/futures/src/command.rs
@@ -27,6 +27,7 @@ impl  Command  {
... [Log Snipped] ...
     fn fmt(&self, f: &mut std::fmt::Formatter ) -> std::fmt::Result {
         f.debug_struct("Command").finish()
```

Granted, the implementation is a bit hacky :smile: do you have a better way in mind ? I can make a PR with whatever you feel applicable.  

Cheers!
