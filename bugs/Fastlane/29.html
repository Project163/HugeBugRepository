Title

[deliver] Incorrectly allows 5.5 inch screenshots @ native device resolution

Description
### Issue Description

Deliver has some validation and screenshot resolution detection logic that incorrectly thinks that iPhone 6/7/8 Plus screenshots at the devices native display resolution (1080x1920 pixels) are supported however when uploading such screenshot to via Spaceship, the following error is reported:

```
Spaceship::UnexpectedResponse: [!] [IMG_BAD_DIMENSIONS] The image dimensions are not supported. Please adjust to acceptable dimensions and re-save it.
```
