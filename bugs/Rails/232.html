Title

can't bypass strict_loading on new records

Description
### Steps to reproduce

Set up a one-to-many relationship, with `strict_loading` enabled:

```
rb
class User < ApplicationRecord
  self.strict_loading_by_default = true

  has_many :checks
... [Log Snipped] ...
  belongs_to :user
end
```

And try to access the `checks` on a new `User`:

```rb
user = User.create!
puts user.checks
```

### Expected behavior

This should not cause an error, or there should be a way to trigger the checks to be loaded. It looks like right now the only options are to directly set the relationship when the parent record is created:

```rb
user = User.create!(checks: [])
```

Or to disable `strict_loading` entirely:

```rb
user = User.create!
user.strict_loading!(false)
```

I'd rather not disable it, so for now I'll set the relationship to an empty array.

### Actual behavior

A strict loading error is triggered:

```
ActiveRecord::StrictLoadingViolationError:
  `User` is marked for strict_loading. The `Check` association named `:checks` cannot be lazily loaded.
```

### System configuration
**Rails version**: 6.1.3

**Ruby version**: 2.7.2
