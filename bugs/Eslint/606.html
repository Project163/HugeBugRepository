Title

The `complexity` rule shows "anonymous" for shorthand methods.

Description
The rule should show the method name instead of "anonymous".
Plus, the position should be at the head of each method name.

**Code:**

``` js
/* eslint-env es6 */
/* eslint complexity: [2, 1] */
var obj = {
    foo(a) {
        return a ? 0 : 1;
    }
};
```

**Actual:**

ESLint v1.5.1

[Image: image]

**Expected:**

```
4:5 - Function 'foo' has a complexity of 2. 
```
