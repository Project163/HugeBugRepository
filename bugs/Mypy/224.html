Title

Bug: traceback error from importing type with import *?

Description
Ran into a bug that prompted me to report a traceback here. I fiddled with the code and narrowed down the issue to this example.

 In test.py:

``` python
from foo import *
from typing import Any

def bar(x: Any, y: AnyCallable) -> Any:
    return 'foo'
```

And in foo.py:

``` python
from typing import Callable, Any

AnyCallable = Callable[..., Any]
```

This hits an error in mypy. If I switch "from foo import *" to "from foo import AnyCallable", everything works great.
