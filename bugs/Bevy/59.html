Title

Shader hot reloading does not work for shader loaded in FromResources

Description
**Bevy version**

Master

**Operating system & version**

MacOs 10.14.6

**What you did**

Loaded a shader in `FromResources` instead of in a startup system. 

`AssetServer::watch_for_changes` is being called, both on the `FromResources` method and on a startup system.

**What you expected to happen**

Shader should have hot reloading, as when loaded from a startup system.

**What actually happened**

Shader isn't being reloaded.

Other shaders that are being loaded from a system do have reloading enabled.

**Additional information**

Here's a minimal example, which is a changed version of the current `hot_shader_reloading.rs` example:

```
rust
use bevy::{
    prelude::*,
    render::{
        mesh::shape,
... [Log Snipped] ...
        });
}
```

As a side note, adding another system that loads the shader but doesn't use the handle, activates hot reloading. For example:

```rust
fn asset_server_changes(asset_server: ResMut ) {
    asset_server.watch_for_changes().unwrap();

    // HACK To get hot reloading
    asset_server.load:: ("shaders/hot.frag");
    asset_server.load:: ("shaders/hot.vert");
}
```
Discussion
- I've done a bit of digging, and here's what I've found: `FileAssetIo::watch_for_changes` seems to be called correctly before any of the shaders are loaded, and `FileAssetIo::watch_path_for_changes` is being also called for both the fragment and vertex shader when loaded in `FromResources`. This seems to be called correctly too:

[URL]

As I understand it, the watcher is set up successfully, and the issue is in actually reloading the asset. I don't understand the asset section of Bevy enough to know if this is true though.

I'd be very glad if anyone can point me in the right direction for trying to implement a fix for this issue.
- It also doesn't work when loading the shaders from a `SystemSet::on_enter` system, only when using the startup system (both for 0.5 and main).  
Maybe that's the expected behaviour, but it caught me offguard.
- `FromResources` is no longer a part of the rendering system. If you can still reproduce this in the post-0.6 rendering system, please reopen this issue or file a new one.
