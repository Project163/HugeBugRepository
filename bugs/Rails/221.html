Title

#number_to_currency is broken for negative values with custom #to_s

Description
### Steps to reproduce

This happens when using the [Link: money] gem and German locale, which has `,` instead of `.` as separator, but affects simple Strings and maybe other libraries as well.

### Expected behavior
```ruby
number_to_currency('-1,11') # => "$-1,11"
```

### Actual behavior
```ruby
number_to_currency('-1,11') # => "$-1,00"
```

caused by [URL]

because `"-1,11".to_f == -1`

**Rails version**:  

**Ruby version**: 2.7
