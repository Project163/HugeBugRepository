Title

Replace Charset.defaultCharset() with StandardCharsets.UTF_8

Description
When running tests where `getBytes(Charset.defaultCharset())` is called, and `locale` is not set to "UTF8", the test fails. 

   

 I am going to replace all mentions of `Charset.defaultCharset()` to `StandardCharsets.UTF_8` so testing is not affected my computer settings.
