Title

BufferOverflowException when encoding message with null testId

Description
The problem seems to have been introduced here:  [URL]

  
 
         int  bufferMaxLength = estimateBufferLength( eventType.getOpcode().length(), runMode, encoder, 0,
            testRunId ==  null  ? 0 : 1, message );
 
  

 The buffer estimate seems to ignore the testRunId field completely when the testRunId is null, but the  encodeHeader  method still adds content to the buffer even when the testRunId is null, resulting in a buffer overflow:  [URL]

  
 
        result.put( ( byte ) ( testRunId ==  null  ? 0 : 1 ) );
         if  ( testRunId !=  null  )
        {
            result.putLong( testRunId );
        }
        result.put( ( byte )  ':'  );
