Title

`/_app/version.json` is marked `immutable` and cached forever

Description
### Describe the bug

As mentioned in [URL] I suspect recent changes to the way that `/_app/version.json` is served have caused it to be treated as a static asset.

### Reproduction

See this simple repro: [URL]

The offending network requests are visible every 10 seconds:

 
   Example request 
  
```
curl '[URL] \
  -H 'sec-ch-ua: " Not A;Brand";v="99", "Chromium";v="100", "Google Chrome";v="100"' \
  -H 'pragma: no-cache' \
  -H 'cache-control: no-cache' \
  -H 'Referer: [URL] \
... [Log Snipped] ...
  -H 'sec-ch-ua-platform: "macOS"' \
  --compressed
```
 

 
   Example response headers 
  
```
cache-control: public,max-age=31536000,immutable
connection: keep-alive
content-length: 24
content-type: application/json
date: Fri, 06 May 2022 08:28:08 GMT
... [Log Snipped] ...
last-modified: Fri, 06 May 2022 08:21:59 GMT
vary: Accept-Encoding
```
 

A `immutable` cached response for `version.json` means my app will always believe there's an upgrade pending, as the browser has cached the initial version response.
