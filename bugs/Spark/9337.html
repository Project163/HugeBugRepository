Title

Broken backward compatibility in PySpark: StreamingQueryListener due to the addition of onQueryIdle

Description
We observed the issue that existing StreamingQueryListener implementations in PySpark start to fail after upgrading to 3.5.0. We identified that the root cause is  [URL] since onQueryIdle was defined as `@abstractmethod`, requiring all exiting implementations to implement the method. 

 It seems like abstractmethod annotation should be removed to retain backward compatibility.
