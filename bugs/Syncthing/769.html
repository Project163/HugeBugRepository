Title

Auto accepted folders not saved

Description
When a folder is auto accepted the configuration is not saved. This means that:

- The folder isn't visible in the GUI automatically because there's no config saved event to trigger the reload (reloading the GUI brings it up)
- Restarting Syncthing forgets the auto accepted folder, and next time the auto accept will use another directory name since the preferred one is "taken"
- Any config change without reloading the GUI first wipes out the folder config
