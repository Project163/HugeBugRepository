Title

Build with empty quarkus.container-image.group failing

Description
### Describe the bug

When starting `quarkusBuild` on a project configured with:

```properties
quarkus.container-image.group=
```

the build fails with:

```
The supplied combination of container-image group '' and name 'application-name' is invalid
```

This could probably be due to [URL]

### Expected behavior

It should build and then create a docker image without a group.

### Actual behavior

_No response_

### How to Reproduce?

Add

```properties
quarkus.container-image.group=
```

and run 

```
gradlew quarkusBuild
```
