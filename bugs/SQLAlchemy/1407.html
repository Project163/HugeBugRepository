Title

Documentation Issue

Description
It is not a typing issue, I just want to report an error in the documentation of Basic Relationship Patterns in the Late-Evaluation of Relationship Arguments section, to be specific, line 1050 of the file: [Link: basic_relationships.rst]

The parentheses of the function should not go, because if we leave the parentheses, the function will be executed when the application is initialized and it may be possible to throw an ImportError exception

### Suggested Change

Just remove the parentheses from the Late-Evaluaton function

```
python
import typing

    from sqlalchemy import desc

... [Log Snipped] ...
            primaryjoin=lambda: Parent.id == _resolve_child_model().parent_id,
        )
```
