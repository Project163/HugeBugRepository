Title

Adding DefaultHttpHeaders to itself creates infinite loop

Description
Example:

```
public void test() {
    HttpHeaders headers = new DefaultHttpHeaders();
    headers.add("foo", "bar");
    headers.add(headers);
    // This will never end
    headers.forEach(entry -> {});
}
```
