Title

EXISTS returns NULL instead of FALSE

Description
The reference manual topic on Boolean expressions -  [URL] - says that EXISTS should return FALSE if the subquery returns no rows. In reality, it returns NULL: 

 ij> create table t(x int); 
0 rows inserted/updated/deleted 
ij> values exists(select * from t); 
1     
 
 NULL  

 1 row selected 

 SQL:2011, part 2, 8.10 <exists predicate> also says that FALSE is the correct result if the cardinality is 0.
Discussion
- Possibly related problem (I think both this query and the EXISTS query in the bug description will be flattened into an EXISTS join, as explained in  [URL]

  
 ij> values 1 in (select 2 from sysibm.sysdummy1);
1    
-----
NULL 

1 row selected
 
  

 It should have returned FALSE, not NULL.
