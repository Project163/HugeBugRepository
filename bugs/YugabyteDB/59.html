Title

SELECT with WHERE and ORDER BY incorrectly displays static column value as null

Description
See the following [Link: post]for details. The `testStaticColumns()` of `SimpleQueryTest.java` can be used to reproduce the below issue.
```
    createTable("CREATE TABLE %s (k text, t int, s text static, v text, PRIMARY KEY (k, t));");
    execute("INSERT INTO %s (k, t, v, s) values (?, ?, ?, ?)", "key1", 1, "foo1", "st1");
    execute("INSERT INTO %s (k, t, v, s) values (?, ?, ?, ?)", "key1", 2, "foo2", "st2");
    ....
    assertRows(execute("SELECT * FROM %s WHERE k = ? AND t = ?", "key1", 2),
      row("key1", 2, "st5", "foo2"));
```
The above assert succeeds. But the below **SELECT with an ORDER BY is the issue**
`    displayRows(execute("SELECT * FROM %s WHERE k = ? AND t = ? ORDER BY t DESC", "key1", 2));`
`Displays: Row 0 = Row[key1, 2, NULL, foo2]`

So the below assert fails since col2 is `NULL `instead of `st5`. Looks like `ORDER BY t DESC` handling in SELECT maybe causing the issue?
```
    assertRows(execute("SELECT * FROM %s WHERE k = ? AND t = ? ORDER BY t DESC", "key1", 2),
      row("key1", 2, "st5", "foo2"));
```
