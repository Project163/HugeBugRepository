Title

LoadDistributorFeature not comaptible with JAX-RS subresources

Description
LoadDistributorTargetSelector seems to be confused by subresources. 

 I'm attaching a test that demonstrates it below.  
When no clustering features or FailoverFeature is applied, the client tries to invoke '[URL] as expected. – `noClustering` and `failover` pass. 

 When LoadDistributorFeature is applied, the request is to '[URL] (path segment contributed by the root resource is lost) – `loadDistributor` fails.
