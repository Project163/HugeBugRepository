Title

Black specifies a requirement for click>=7.1.2 but actually requires click>=8.0

Description
**Describe the bug**

Installing `black` from the head of the `main` branch and `click 
    from black import patched_main
  File "/home/enpaul/black-click-compat-bug/lib64/python3.10/site-packages/black/__init__.py", line 34, in  
    from click.core import ParameterSource
ImportError: cannot import name 'ParameterSource' from 'click.core' (/home/enpaul/black-click-compat-bug/lib64/python3.10/site-packages/click/core.py)
```

**Expected behavior**

Black should specify a requirement for `click>=8.0.0` ([Link: actual specification] is for `>=7.1.2`)

**Environment**

 

- Black's version: `21.12b1.dev40+g565f9c9`
- OS: Linux (Fedora 35)
- Python: `Python 3.10.1`

The action would just need to install those pinned versions before installing black and we run our CI suite and maybe integration tests with diff shades/primer to find errors like this reported behavior.
