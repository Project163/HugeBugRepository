Title

Atomic updates with add-distinct can add duplicates

Description
When using add-distinct operation in atomic updates, it can end up adding duplicates to the document. 
The issue was reported in the  user-list  

 According to the report, the issue doesn't occur in solr 8 or in standalone mode but when going through the code, I came across a bug (maybe related to it) which can lead to duplicates
