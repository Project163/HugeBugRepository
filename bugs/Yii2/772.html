Title

Cookie method has returns wrong value when using in response

Description
### What steps will reproduce the problem?
Add cookie

```
Yii::$app->response->cookies->add(new Cookie([
                'name' => 'test',
                'value' => 1,
            ]));
```

### What is the expected result?
When checking if the CookieCollection has the current cookie, it should return true.
`$value = Yii::$app->response->cookies->has('test')`

### What do you get instead?
`$value` is actually false.

I suppose its because in the Yii code `expire` is checked and the cookie has `expire` 0 in my case. But it's a valid value, it means 'until the browser is closed'.

```
return isset($this->_cookies[$name]) && $this->_cookies[$name]->value !== ''
    && ($this->_cookies[$name]->expire === null || $this->_cookies[$name]->expire >= time());
```

### Suggested solution
I’d updated the code like this, but I'm really not sure if it's enough and won't break anything.
```
return isset($this->_cookies[$name]) && $this->_cookies[$name]->value !== ''
    && ($this->_cookies[$name]->expire === null || $this->_cookies[$name]->expire === 0 || $this->_cookies[$name]->expire >= time());
```
