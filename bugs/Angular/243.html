- @cghislai apart from the regression (?) that you are seeing here- what would be the case for having an empty event handler? I mean - if you don't take any action on a given event, why adding `(fileread)` at all?

I would say that in this case we should simply throw a good error, but maybe you've got a valid use-case?
- It was an hack.
I had a filereader that read the file then stored the dataURI in a field. I had an img component with the src attributed bound to that dataURI field. The issue was that the img was not reloaded once the file was read. Triggering that event triggered change detection and the image was updated.

I now moved that job in a Promise, and update the dataURI field in the then clause, and image updates automatically.
