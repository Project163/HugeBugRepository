Title

Blueprint property placeholder does not work with http conduit configuration.

Description
I cannot setup an HTTP conduit configuration that uses the Apache Aries Blueprint property-placeholder to inject trust store parameters. The conduit works when I explicitly configure the trust store properties. Unfortunately, when I use placeholders it fails.

Discussion
- This test attempts to use the CXF STS. However, if I use the blueprint property placeholder configurer it fails to even get the WSDL for the STS with the error below. If I explicitly configure the trust store parameters for the HTTP conduit in my blueprint configuration then the conduit works and it gets the WSDL for the STS, successfully constructs the STS client and executes the request for security token against the STS. 

 It seems that blueprint property placeholders do not work with the trust store configuration of the CXF http conduit.
