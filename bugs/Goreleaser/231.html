Title

continue --merge fails with custom dist folder

Description
### What happened?

I've specified the `dist` folder in the `.goreleaser.yaml` file and on `continue --merge`, the process fails with the error `did not find any contexts to merge`. When removing that configuration, the process succeeds. 

### How can we reproduce this?

Use the same setup as [URL] but specify the `dist` folder in the `.goreleaser.yaml` file and make sure the cache directories have the same base path.

### goreleaser version

```bash
goreleaser/goreleaser-action@v5
```

- for continue to work on a folder different than the default, you'll need to use `goreleaser continue --dist ./folder`

This is required because on continue it doesn't parse the configuration file, instead, it loads the previous context. This allows to run `continue` with the dist folders without any source, with the bad side effect that `dist` will not be automatically carried on.

I'll document this better.
