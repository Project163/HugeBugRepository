- This might be already fixed as a side effect of   GROOVY-6390  . If it still fails against  2.1.9-SNAPSHOT , then this is a distinct bug.
- The stack contains an evaluateEqual, so I think it is not fixed by   GROOVY-6390
- reduced example: 
  
  class  A{}
 class  B {
    A a =  new  A()
    @groovy.transform.CompileStatic
    B(){}
}
