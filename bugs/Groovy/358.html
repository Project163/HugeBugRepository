Title

MarkupBuilder doesn't allow entities (like nbsp)

Description
Currently, there is no way to get this HTML code: 

 <span>a: b</span> 

 If you try 

 span 'a: b' 

 you'll get: 

 <span>a:&nbsp;b</span> 

 ie. the "&" gets escaped.
Discussion
- Here is a simple patch for the issue. Use it like this: 

 builder.span builder.verbatim(' ') 

 The new method MarkupBuilder.verbatim() wraps a string in a special object which protects the contents against escaping. 

 Maybe a similar method can be used to fix the CDATA issue (see   GROOVY-267
- Please try to use the groovy.xml.Entity class for this. 

 This is what StreamingMarkupBuilder uses and it would be a bad idea for MarkupBuilder and StreamingMarkupBuilder to handle entities differently. 

 For this to work MarkupBuilder would have to understand the groovy.lang.Buildable interface and to provide an property called unescaped. 

 This would allow  

 <span>"a${Entity.nbsp}b"</span> 

 or 

 <span>unescaped << "a: b"</span> 

 Note that you can put an nbsp into an HTML document with MarkupBuilder using the literal Unicode value of nbsp you just can't use an entity at the moment.

- Just submitted a fix to HEAD. It doesn't provide hooks for getting to groovy.xml.Entity, I guess that is a potential additional enhancement. It does allow code like this: 

  
 xml.p {
    em( 'Usually' )
    mkp.yield  ' Hearts & Diamonds ' 
    b( 'beats' )
    mkp.yieldUnescaped  ' Spades &amp; Clubs' 
}
 
  

 The fix should be enough to allow you to manually add: 

  
 span {
    mkp.yieldUnescaped  'a:&nbsp;b' 
}
