Title

Cannot Connect to Database in Containerized Integration Test

Description
### Describe the bug

Hello,
I've encountered an issue while running integration tests using the quarkusIntTest task with the -Dquarkus.container-image.build=true flag.
When using Docker Compose-based DevServices (e.g., PostgreSQL) during integration tests with the following command:
```
./gradlew clean build quarkusIntTest -Dquarkus.profile=test -Dquarkus.container-image.build=true
```
The containerized application starts successfully and initializes the Hibernate SessionFactory without any issues.
However, when I try to configure the datasource port in application.yml like this:
```
quarkus:
  datasource:
    devservices:
      port: 55432
```
The specified port is ignored, and a random port is assigned instead. This leads to connection failures during startup, as the container cannot communicate with db

### Expected behavior

Port is assigned correctly

### Actual behavior

Random port is assigned

This behavior is demonstrated in the following [Link: reproducer project]:

Scenario 2 (broken due to ignored port) — available on the devservices branch
