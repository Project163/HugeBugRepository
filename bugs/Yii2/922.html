Title

dispatch crash, if logtarget::collect throw \Throwable

Description
### What steps will reproduce the problem?

1. `$target->collect()` throw `\Throwable`
2. Further targets can no longer run. the developer toolbar cannot save the log file.

[URL]

### What is the expected result?

The other logs work correctly.

### What do you get instead?

After the first error, the other logs are no longer running.

### Additional info

The code below fixes the bug, but require PHP 7.0+ 
```php
                 try { 
                     $target->collect($messages, $final); 
                 } catch (\Throwable $e) { 
```

Separate try-catch block for PHP 7.0+ and PHP <7.0 can solve the problem, but need to consider whether there is a better solution.

| ---------------- | ---

Discussion
