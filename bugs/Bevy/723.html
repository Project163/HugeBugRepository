Title

Cargo run failure after setting up for fast compile on OS-X

Description
I cannot set up a new Bevy project on the Mac, using the fast compile settings as described on the getting started section of the guide. I installed `zld` using brew and added the config file as instructed.

Cargo run gives the following error on a new project:

```
The following warnings were emitted during compilation:

warning: error: invalid argument '-std=c++11' not allowed with 'C'

error: failed to run custom build command for `spirv-reflect v0.2.3`
... [Log Snipped] ...

  error occurred: Command "sccache" "c++" "-O0" "-ffunction-sections" "-fdata-sections" "-fPIC" "-g" "-fno-omit-frame-pointer" "-m64" "-arch" "x86_64" "-stdlib=libc++" "-I" "src" "-Wall" "-Wextra" "-std=c++11" "-Wno-missing-field-initializers" "-Wno-sign-compare" "-Wno-deprecated" "-o" "/Users/christianvogel/Projects/rust/bevy-drop7/target/debug/build/spirv-reflect- /out/vendor/spirv_reflect.o" "-c" "vendor/spirv_reflect.c" with args "c++" did not execute successfully (status code exit code: 1).
```

Noticed that this error looks a lot like [URL] however gcc is installed and runs from the command line, and rustup show gives the following active toolchain:

```
nightly-x86_64-apple-darwin (default)
rustc 1.48.0-nightly (d006f5734 2020-08-28)
```
Discussion
- I've had the same issue that I "solved" by not using `sccache`...
I think it has to do with the build script of `spirv-reflect` that doesn't like being used by `sccache`
