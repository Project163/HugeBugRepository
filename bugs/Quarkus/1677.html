Title

RESTEasy Reactive: Explicit @RequestScoped resource and instance variable with @PathParam or @RestPath does not work

Description
### Describe the bug

Hey Guys, 

when I currently switched to RESTEasy Reactive the following issue came up. 

The instance variable environment is always null if the annotation `@Requestscoped` is explicitly used.

```
java
@Path("/hello/{environment}")
@RequestScoped
public class GreetingResource {

... [Log Snipped] ...
  }
}
```

### Expected behavior

`curl -X GET --location "[URL]

Output: 
Hello from RESTEasy Reactive
Environment: env1
Message: message1%

### Actual behavior

`curl -X GET --location "[URL]

Output: 
Hello from RESTEasy Reactive
Environment: null
Message: message1%

### How to Reproduce?

Reproducer: [URL]

To reproduce remove `@Requestscoped` from resource class.
