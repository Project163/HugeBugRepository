Title

Join columns are not using correct length

Description
I have an entity that uses a `char(12)` as primary key and I have other entities with FKs for this column. When TypeORM synchronizes the schema on connect, the join columns are created as `char` (no length specified) instead of `char(12)`.

Env:
Node.js 6.11.0
NPM 3.10.10
TypeORM 0.1.0-alpha.32
MariaDB 10.1.25

```
typescript
@Entity('devices')
export class Device {
  @PrimaryColumn({ name: 'id', type: 'char', length: '12' })
  id: string;
... [Log Snipped] ...
  type: string;
}
```

Log:
```
START TRANSACTION
creating a new table: devices
CREATE TABLE `devices` (`id` char(12) NOT NULL, `registration_token` decimal(6) NOT NULL, PRIMARY KEY(`id`)) ENGINE=InnoDB
creating a new table: device_instances
CREATE TABLE `device_instances` (`id` char(36) NOT NULL, `instance` smallint(5) NOT NULL, `type` varchar(30) NOT NULL, `device_id` char, PRIMARY KEY(`id`)) ENGINE=InnoDB
creating a foreign keys: fk_0f5d95667138c6e39d1224f2bd7
ALTER TABLE `device_instances` ADD CONSTRAINT `fk_0f5d95667138c6e39d1224f2bd7` FOREIGN KEY (`device_id`) REFERENCES `devices`(`id`)
COMMIT
```
