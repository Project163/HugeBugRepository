Title

st.experimental_audio_input widget shows recording started from 30:00 minutes instead of 00:00

Description
### Checklist

### Summary

I am trying to use st.experimental_audio_input voice recorder widget.
But When I start recording my voice, the time counter starts counting from 30:00 minutes.

### Reproducible Code Example

```Python
import streamlit as st

audio_recorded = st.experimental_audio_input("Record a voice message")

if audio_recorded:
    st.audio(audio_recorded)
```


### Steps To Reproduce

1. Click on Voice Recording button
2. You'll see that recording time starts from 30:00

### Expected Behavior

It should show recording time from 00:00.

### Current Behavior

See, Recorded time shown in the 2nd attached image is 30:11, while the actual length of the recorded voice is only 11 seconds.
