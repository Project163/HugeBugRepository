At the end I get the feeling the Mirror is not properly implemented.
- The main camera's aspect ratio is never copied to the mirror camera.

```js
// "examples/Mirror.js" (lines 142-146)
mirrorCamera.near = camera.near;
mirrorCamera.far = camera.far;
mirrorCamera.updateMatrixWorld();
mirrorCamera.updateProjectionMatrix();
```

Should be changed to:

```js
mirrorCamera.updateMatrixWorld();
mirrorCamera.projectionMatrix.copy(camera.projectionMatrix);
```

I'll send a PR for this later!

Another problem with the mirror (and the planar ocean) is that it doesn't seem to work when the```logarithmicDepthBuffer``` is enabled. Oblique near plane clipping messes with depth and I never found a solution for this. I wish WebGL had ```glClipPlane``` 😞
