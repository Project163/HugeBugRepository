Title

valid-jsdoc doesn't test exported functions

Description
The following will cause linter errors (e.g. "Missing JSDoc parameter description", "Use `@return` instead") when using the valid-jsdoc rule:

``` js
/**
 * Does…something.
 * @param {string} a
 * @return {Array } The result of doing it
 */
function doSomething(a) {
}
```

However, if you export the function, no errors are raised (i.e. the code passes the linting test unexpectedly):

```
js
/**
 * Does…something.
 * @param {string} a
 * @return {Array } The result of doing it
... [Log Snipped] ...
export default function doSomethingElse(a) {
}
```

My eslintrc doesn't seem to be a factor as I still see the issue when I remove all other rules:

```
json
{
  "ecmaFeatures": {
    "modules": true
  },
... [Log Snipped] ...
  }
}
```

I'm seeing this with 0.19 and 0.21.
