Title

Steam overlay unresponsive on Linux

Description
The Steam overlay on Linux is unresponsive to mouse motion events (it works correctly on Windows and OS X). It appears the cursor position is refreshed only if it comes together with a mouse click event.

The issue seems to be due to capturing XI_Motion events with XInput [URL]

```
    XISetMask(mask, XI_Motion);
    XISelectEvents(_glfw.x11.display, window->x11.handle, &eventmask, 1);
```

The X11 manual (http://www.x.org/archive/X11R7.5/doc/man/man3/XISelectEvents.3.html) says:

```
    XISelectEvents sets the event mask for this client on win.
    Further events are only reported to this client if the event
    type matches the selected event mask. The masks overrides the
    previously selected event mask for the given device.
```

SDL seems to get around this by setting the mask for XI_RawMotion instead of XI_Motion (confirmed to work) [URL]

```
    XISetMask(mask, XI_RawMotion);
```
