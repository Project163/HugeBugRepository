Title

Can't combine brew and multiple goarm versions

Description
**Describe the bug**

When building multiple `goarm` versions and releasing on brew, an error is returned:
```
homebrew tap formula: failed to publish artifacts: one tap can handle only 1 linux and 1 macos archive
```

**To Reproduce**
We encounter this issue when releasing with [Link: this `.goreleaser.yml`]. I expect anything using brew and having multiple goarm versions returns this error.

**Expected behavior**
I'd expect either one of these things:
1. Nothing is added to the brew formula for ARM architectures (as was the case in goreleaser `v0.117` and earlier).
2. An entry is added to the brew formula for each of the goarm versions and the formula determines which to use.

**Environment**
GoReleaser Version: `v0.118.0` (works as expected in `v0.117.2`)

**Additional context**
The error first occurs after #1140
