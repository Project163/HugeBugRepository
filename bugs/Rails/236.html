Title

No way to list common rails commands from CLI outside a rails app directory

Description
### Steps to reproduce
- `rails --help`
- `rails help`
- `rails -h`

### Expected behavior

Using `rails --help` should print usage instructions for common Rails commands.

```
rails --help
```

The most common rails commands are:

 test:system  Run system tests
 dbconsole    Start a console for the database specified in config/database.yml
              (short-cut alias: "db")
