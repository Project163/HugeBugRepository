Title

Update quotaTypesEnabled on quota removal in ClientQuotaManager

Description
In kafka.server.ClientQuotaManager class, quotaTypesEnabled is not updated when a quota is removed via removeQuota method in DefaultQuotaCallback class. This field is set when quotas are added in updateQuota but it's never changed or cleared. This can lead to incorrect behaviour in the quotasEnabled method. So in case all the quotas have been removed dynamically, the system may incorrectly assume the quotas are active, which leads to unnecessary metric creation or updates until the broker is restarted.
