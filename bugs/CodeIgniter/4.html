Title

Whitespace in queries removed when it shouldn't

Description
Consider the following:

```
$search 'Some      random              item';       
$this->db->from('items');
$this->db->where("(name LIKE '%".$this->db->escape_like_str($search)."%' or 
item_number LIKE '%".$this->db->escape_like_str($search)."%' or 
category LIKE '%".$this->db->escape_like_str($search)."%') and deleted=0");
$this->db->order_by("name", "asc");
$this->db->limit($limit);
return $this->db->get();    
```

On line 1260 of DB_driver.php the following happens:
    $item = preg_replace('/[\t ]+/', ' ', $item);

This removed the whitespace I actually want to search for in my query. (Some user's copy/paste into fields and put extra spaces in their inputs)

This can be easily solved by removing the space from the character class in the regular expression.
Discussion
- This change would prevent table aliases from working for many.  What you need to do is set the escape parameter to FALSE in your where() call.

e.g.
```$this->db->where('MATCH (field) AGAINST ("value")', NULL, FALSE);
