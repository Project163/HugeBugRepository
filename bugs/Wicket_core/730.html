Title

BaseWicketTester discards cookies with MaxAge = -1 when processing a new request

Description
BaseWicketTesters' method processRequest only copies cookies with maxAge > 0 to the new request, discarding cookies with maxAge = -1. However  [URL] states that cookies with maxAge = -1 are session cookies, and should be deleted when the browser is closed, not when a new request is handled.
