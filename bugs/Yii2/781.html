Title

ActiveForm - EVENT_AFTER_RUN

Description
Событие EVENT_AFTER_RUN для \yii\widgets\ActiveForm задано неверно, я ожидаю контент в $event->result, но в итоге там пусто.

Вот бехейвер, который подключается к форме, в нем фукнция на событие EVENT_AFTER_RUN 
```
php
class MyBehavior extends Behavior
{
    public function events()
    {
... [Log Snipped] ...
    }
}
```

Не срабатывает потому, что в функции  \yii\widgets\ActiveForm::run() контент сразу `выводится`, а не `возвращается`
```
php
    public function run()
    {
        if (!empty($this->_fields)) {
            throw new InvalidCallException('Each beginField() should have a matching endField() call.');
... [Log Snipped] ...
        echo Html::endForm();
    }
```
Если переработать функцию, то все работает

```
php
    public function run()
    {
        if (!empty($this->_fields)) {
            throw new InvalidCallException('Each beginField() should have a matching endField() call.');
... [Log Snipped] ...
        return $html;
    }
```
