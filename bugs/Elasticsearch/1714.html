- btw @hrahal - regardless of this bug, I would definitely not try to solve your problem using parent-child.  You're essentially trying to impose a relational design onto elasticsearch, and it is bound to fail. Instead, denormalise your data.
- This one is funky. In 5.x we added a rewrite method on the query builders (like the one for Lucene query) in order to be able to optimize some queries at the ES level. In this example you have a range query on a date field and since the index contains only one document the range query builder is rewritten in a match all docs query. When the inner query of the FunctionScoreQueryBuilder is rewritten we create a new object that contains the new query plus the other parameters of the FunctionScoreQueryBuilder. The `boost_mode` was just ignored during the copy so the default value (which is SUM) is applied.
