Title

Gridview or Listview 'maxButtonCount' attribute is not working when it's assign with 2

Description
### What steps will reproduce the problem?

In gridview or listview when we configured the max count button to 2 then it's not working. When you click on the 2 button then 3 button is not showing while going next in list otherwise it working fine when we go to previous in list.

Below is my configuration for my current project.

```
php
'pager' => [
        'activePageCssClass' => 'page-item active',
        'prevPageLabel' => false,
        'nextPageLabel' => false,
... [Log Snipped] ...
        'maxButtonCount' => 2,
    ],
```

### What is the expected result?
When I click 2 button then 3 button will show up and the active button will be 2 at that moment.

### What do you get instead?
Right now when I click 2 button then 3 button will not show up even though I have a lot of pages ahead.
