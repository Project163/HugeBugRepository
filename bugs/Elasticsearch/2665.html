Title

GeoIpDownloader can't be disable by elasticsearch.yml

Description
**Elasticsearch version** (`bin/elasticsearch --version`): `7.14`, `master`

**Steps to reproduce**:

1. Start node with default settings and shut it down after geoip download is done
2. Add `"ingest.geoip.downloader.enabled": false` to `elasticsearch.yml`
3. Start node again

**Expected behavior**:
There should be no logs from `GeoIpDownloader` and no databases downloads

**Actual behavior**:
`GeoIpDownloader` is still active and new databases are downloaded even with setting disabled
