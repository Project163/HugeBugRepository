Title

Migrating to 1.4 breaks pickeling of joinloaded relationships

Description
### Describe the bug

Pickeling an object loaded with `session.query(Child).options(joinedload(Child.parent), raiseload("*").first()` fails if `Parent` has relationship(s) of it's own because the `PathToken` object created in that case fails to be pickled. The issue occurred after migrating from 1.3 to 1.4 (independent of the `future`-flag). 

### To Reproduce

```
python
from pickle import dumps

import sqlalchemy as sa
from sqlalchemy import orm, schema
... [Log Snipped] ...
if __name__ == "__main__":
    main()
```


### Error

```
SQLAlchemy 1.4.25
Traceback (most recent call last):
  File "./it_is_a_pickle.py", line 65, in  
    main()
  File "./it_is_a_pickle.py", line 61, in main
... [Log Snipped] ...
    [m.class_ for m in [path[i] for i in range(0, len(path), 2)]],
AttributeError: 'PathToken' object has no attribute 'class_'
```

### Versions

- OS: Ubuntu 20.04.3
- Python: 3.8.10 (also tested with 3.7 on Debian with the same result)
- SQLAlchemy: 1.4.25 (also tested with 1.4.0 with the same result)
