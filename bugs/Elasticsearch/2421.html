Title

testMovesShardsOffSpecificDataPathAboveWatermark fails if disk ≥90% full

Description
`gradle-loop ':server:internalClusterTest' --tests "org.elasticsearch.cluster.routing.allocation.decider.MockDiskUsagesIT.testMovesShardsOffSpecificDataPathAboveWatermark"` apparently fails if it's running on a disk that's more than 90% full:

```
$ df -h | grep /$
/dev/mapper/vg00-root  468G  395G   50G  89% /
$ ./gradlew -s ':server:internalClusterTest' --tests "org.elasticsearch.cluster.routing.allocation.decider.MockDiskUsagesIT.testMovesShardsOffSpecificDataPathAboveWatermark" > /dev/null && echo "ok"
ok
$ dd if=/dev/zero of=consumes-space-2 bs=1M count=5000
... [Log Snipped] ...

FAILURE: Build failed with an exception.
```

Running this on `master` ( ) but no reason to believe it's only a problem there.
