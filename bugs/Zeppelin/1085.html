Disable zeppelin-web war file extraction when pointing to a .war file

Description
The local extraction of zeppelin-web.war file can create some problems: 
 
	 We observe that sometimes the local zeppelin-web extraction gets corrupted following the termination of Zeppelin process. This leads to issues with launching Zeppelin at any subsequent run. 
	 The extraction of zeppelin-web.war process also adds to the Zeppelin launch time, making it unnecessarily slower.
