I am facing same issue.
- Facing the same issue, I believe it is because of this line: [URL]

Comparing arrays with `===` will always return false, so the column is always added to the `diffColumns` which triggers an update to the DB.

Just adding the following block before the switch block should fix the issue. This is a similar comparison as what is done for json/jsonb columns.

```ts
if (column.isArray) {
     if (OrmUtils_1.OrmUtils.deepCompare(entityValue, databaseValue))
        return;
}
```
