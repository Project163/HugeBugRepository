Title

Side effect detection failure in cycle

Description
I noticed this while [Link: fiddling in the repl]

even.js:

```
js
import { odd } from './odd'

export var counter = 0;

... [Log Snipped] ...
  return n == 0 || odd(n - 1);
}
```

odd.js:

``` js
import { even } from './even';

export function odd(n) {
  return n != 0 && even(n - 1);
}

export const bar = even(11);
```

With main.js like so:

``` js
import { counter, even } from './even'

console.log(even(5))

console.log(counter)
```

The output is:

```
js
function odd(n) {
  return n != 0 && even(n - 1);
}

... [Log Snipped] ...

console.log(counter)
```

with `foo` missing. 
If `console.log(even(5))` is commented out, `foo` magically appears!

```
js
function odd(n) {
  return n != 0 && even(n - 1);
}

... [Log Snipped] ...

console.log(counter)
```
