Title

src/main/javadoc of sub modules ignored for generation of aggregated javadoc

Description
In a reactor build with aggregated javadocs, only resources put into the src/main/javadoc directory of the top project are used for javadoc generation. Anything in the src/main/javadoc directories of the sub modules is ignored.
