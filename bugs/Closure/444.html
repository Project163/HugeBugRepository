Title

Access to `arguments` members is replaced with access to actual arguments.

Description
An example of changed behavior before and after munging:

  (function() {
    alert(arguments[0] + '; ' + arguments['callee'].length);
  })();

munges to:

  (function(a){alert(a+"; "+arguments.callee.length)})();

function hello(a){alert("Hello, "+a)}hello("New user");
