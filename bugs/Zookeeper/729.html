Title

QuorumPeer does not listen on passed client IP in the constructor

Description
QuorumPeer does not listen on passed client IP in the constructor, for client  connection. It always listens on all IP(  or 0:0:0:0:0:0:0:0). This happens only when QuorumPeer is created using any of the bellow constructors
