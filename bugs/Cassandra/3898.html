Title

Error: unmappable character for encoding MS949 in ant build-test task.

Description
While setting up a new Cassandra project, noticed "build-test" ant task fails due to "unmappable character for encoding MS949". 
An addition of encoding="UTF-8" parameter fixed this. 

  
     <javac
     debug= "true" 
     debuglevel= "${debuglevel}" 
     destdir= "${test.classes}" 
     includeantruntime= "false" 
     source= "${source.version}"  
     target= "${target.version}" 
     encoding= "UTF-8" >
