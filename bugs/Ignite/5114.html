Title

Query with 'in' condition with a sub-query returns multiplicative data.

Description
A query like  
  
 
select * from T1 where T1.col1 > 0 or T1.col1 in (select T2.col1 from T2)  
  
 where T1 is replicated and T2 is partitioned, may return duplicate rows on the multinode cluster. 

   

 Ket's treat Replicated cache as Partitioned one, like we do when joining replicated cache to a  partitioned.
