Title

@SplitRestriction should execute after @Setup on SplittableDoFn

Description
The method annotated with @SplitRestriction is the method where we can define the RestrictionTrackers (splits) in advance in a SDF. It makes sense to execute this after the @Setup method given that usually connections are established at Setup and can be used to ask the different data stores about the partitioning strategy. I added a test for this in the SplittableDoFnTest.SDFWithLifecycle test.
