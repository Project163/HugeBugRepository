Title

Invalid identifier decoding.

Description
What steps will reproduce the problem? 
1. In [URL] compile the below

    // ==ClosureCompiler==
    // @compilation_level SIMPLE_OPTIMIZATIONS
    // @output_file_name default.js
    // ==/ClosureCompiler==

    var \u0069\u0066 = 1;

What is the expected output?

    var \u0069\u0066 = 1;

What do you see instead?

    var if = 1;


"if" is not a valid identifier since it is a reserved word, but \u0069\u0066 is a valid identifier.
Try running the below in squarefree.com/shell/shell.html

var \u0069\u0066 = 1;
alert(window['if'])
