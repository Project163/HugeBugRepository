Title

[YSQL] Indexes on system catalog tables are not updated during DDL

Description
This is currently a known issue that indexes on system catalog tables are not updated during DDL. This can lead this incorrect result when querying the tables using the indexes.

E.g.

```
postgres=# create table t (k int primary key);
CREATE TABLE
postgres=# select * from pg_type where typname = 't';
```
