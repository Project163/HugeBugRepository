Title

Rigged collada model crashes three

Description
##### Description of the problem

I'm trying to import a rigged Collada mesh from Blender. I'm using the latest [Link: ColladaLoader.js] file.

It crashes on [Link: this line in SkinnedMesh] with the error

The line in question:

``` js
bones[ gbone.parent ].add( bones[ b ] );
```

You can download my test mesh: [Link: test-export.dae.zip]

That happens because it tries to look up `bones[ gbone.parent ]`, but `gbone.parent` is a string, and `bones` is an array. So it returns undefined and crashes
