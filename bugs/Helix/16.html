Title

panic while removing characters in a line with "special" chars

Description
When a line includes an "uncommon" character (I assume this happens with chars that are > 1 byte) helix panics if you move the cursor with the arrow keys and remove any other character up to that point on the same line (using  Backspace  or  Del ).

### Reproduction steps

1. in `INS` mode, type anything with uncommon characters - `x²` for example
2. *without leaving* `INS` mode, move the cursor one to the left with the arrow keys and hit backspace (removing `x`)
3. helix panics
