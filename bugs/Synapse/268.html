Title

Create a XPath function for base64 encode strings

Description
It is nice to have a XPath function for encoding strings to base64.
Discussion
- Added base64Encode Xpath function to synapse.
- Since base64 is an encoding scheme for binary data, the XPath function either needs an encoding argument, or it should use a standard encoding such as UTF-8. Using String#getBytes() is a programming error (except when preparing data for communication with other processes on the same system) because it uses the platform's default charset encoding. The same is true for new String(byte[]).
- Thanks for pointing this out. I'll improve the function to add the charset as a argument to the function as well and use the default as UTF-8. 

 Thanks, 
Supun..
- Added a second argument to the encode function. If the second argument is not specified we use the UTF-8 encoding.
