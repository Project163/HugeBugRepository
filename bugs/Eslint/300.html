Title

TypeError: Cannot set property 'check' of undefined

Description

```

        linesToCheck[line].check = true;

    at markCheckLine (/usr/local/lib/node_modules/eslint/lib/rules/indent.js:95:34)
... [Log Snipped] ...
```

Discussion
- Just to confirm, you're using 0.16.2? Can you share the code you were linting?
- Yep, version is `v0.16.2`
code is

```
import {addons} from 'react/addons'\Mimport React from 'react'
```
- So it looks like you're using `\r` as a line break instead of `\n`, so the line breaking is getting confused.

Out of curiosity, why are you using `\r`?
- It's not the actual rule, but rather `getSourceLines()` that is returning the wrong results due to the unexpected line break. According to ECMA-262, `\r` is a valid line break by itself, but we're not treating it as such.
