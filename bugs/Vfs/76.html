Title

RamFileRandomAccessContent.seek() allows seeking before file start.

Description
MRAC simply calls RFRAC with no attempt to clip pos which results in filepoitner being set to negative values which are wrong. 

 MonitorRandomAccessContent { 
    public void seek(long pos) throws IOException 
    {
        content.seek(pos);
    }
 } 

 RamFileRandomAccessContent 
    public void seek(long pos) throws IOException  
{
        this.filePointer = (int) pos;
    }
Discussion
- seek will now verify that the position is not less than zero and will throw an IOException if it is. Please verify and close.
- Will keep it in "Resolved" state till 2.1 is shipped.
- Apache Commons VFS 2.1 has been released. It includes this (total 171) resolved issues.
