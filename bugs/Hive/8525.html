Title

Incorrect filter selectivity of BETWEEN expressions when using histograms

Description
For all cases using the BETWEEN key word, the selectivity is outputted as the default value because the conditions currently in place make it impossible to enter the BETWEEN histogram selectivity code. In addition, NULLs are not properly accounted for in the BETWEEN selectivity calculation.
