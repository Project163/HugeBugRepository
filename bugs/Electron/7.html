Title

Setting long tooltip on Windows causes abrupt crash

Description
On `google-music-electron`, we got a report about issues with abrupt crashes when playing certain songs. After some triaging, we discovered it was caused by going over 127 characters on Windows.

[URL]

We have created a proof of concept gist to reproduce the issue. We are using Windows 7 from `ievms` but the initial report was on Windows 10 so that should work as well.

[URL]

We aren't sure whether this is something that `electron` can resolve or not. But at the very least, we think it should be documented.

In the meantime, we will be adding truncation in `google-music-electron` to avoid future issues.
