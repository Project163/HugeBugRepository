Title

Custom SerDes throw cast exception when there are complex nested structures containing NonSettableObjectInspectors.

Description
The approach for   HIVE-5199   fix is correct.However, the fix for   HIVE-5199   is incomplete. Consider a complex nested structure containing the following object inspector hierarchy: 
SettableStructObjectInspector 
{ 
  ListObjectInspector<NonSettableStructObjectInspector> 
}
