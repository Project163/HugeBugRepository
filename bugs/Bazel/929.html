Title

Iterating over settings.items() in transition implementation yields invalid list values

Description
### Description of the problem / feature request:

Below is a minimal example, running `bazel-dev build --features=y //:lib_with_feature_x` on it results in `Error: unsupported binary operation: List + list`.
This object has `type(value) != type([])` and normal list operations cannot be performed on it. Trying to use it in a test with not operator even results in a java exception with `invalid Starlark value: class com.google.common.collect.SingletonImmutableList`

Both `settings["//command_line_option:features"]`  and `settings.items()[0][1]` works as expected.

def _add_feature_x_transition_impl(settings, attrs):
