Title

Non-empty empty beans.xml files

Description
**Describe the bug**
The repository contains a number of beans.xml files containing two newlines.

**Expected behavior**
The beans.xml files should either be empty (0 bytes) or contain valid XML to comply with the CDI spec.

**Actual behavior**
The non-empty empty beans.xml files cause weld to explode because it tries to parse them as XML.

**To Reproduce**
I have a branch in my project:
[URL]
