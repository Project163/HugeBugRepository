Title

Page subscribe only works once after introducing $app/state

Description
### Describe the bug

When the [Link: $app/state] module was added, a regression happened in `$app/stores`, breaking subscribing to the old page store there. This is the gist:

```ts
import { page } from '$app/stores';
page.subscribe((page) => console.log('Page update'));
```

This only works once if you have a callback on `use:enhance` and submits a form. After submitting the form multiple times, the subscribe callback isn't triggered.
