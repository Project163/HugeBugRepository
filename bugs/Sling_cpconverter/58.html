Title

CPConverter dropping type information on sling:OsgiConfig nodes

Description
The implementation of the converter for sling:OsgiConfig nodes (XmlConfigurationEntryHandler) currently ignores the type of the properties and transforms everything into Strings (as DocViewProperty returns values as String representations with separate type property). 

 This leads to broken configurations in case of the use of those config nodes with typed properties.
