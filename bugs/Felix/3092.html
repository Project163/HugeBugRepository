Title

The converter fails to properly convert null to array types

Description
The Converter specification  says in    that null should be converted to an empty array, however the current implementation converts to an empty `Object[]` regardless of the target type, for example a `byte[]`. This is clearly wrong as the returned object cannot be assigned to the target type!
