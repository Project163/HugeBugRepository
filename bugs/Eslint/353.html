Title

newline-after-var declare and export

Description
Another issue with newline-after-var when it is enabled I get an error when exporting one let after another. This is in version v0.19.0

```
export let A = "A";
export let B = "B";
```

Which seems to be an error given that this does not 

```
 let A = "A";
 let B = "B";
```

the message is `warning  Expected blank line after variable declarations  newline-after-var`
Discussion
- The second example definitely should warn.
- @nzakas I think the second example does give out errors.
But the first example is a bug for sure.
Do we need to think about import statements also?

I will work on this.

**Correction**
second example does **not** give out errors.
- I would leave import out of this rule.
- newline-after-var has an exception for consecutive variable declarations so that only the last one is followed by a blank line. The second example is behaving as expected.
