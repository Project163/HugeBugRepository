Title

Invalid function error when using custom udaf

Description
When a permanent udaf used before over() function, hive will throw invalid function error. 

   

  In   HIVE-12719   , it fix this issue for hive 3, but it can't work in hive 2.   

 This issue reproduce on master. 

   

 In hive 2, it should get FunctionInfo from FunctionRegistry before get WindowFunctionInfo same to hive 3. Because it will register window function to session. Then hive can get WindowFunctionInfo correctly. 

   

 ---------------------------- err detail ---------------------------- 

 register a permanent udaf: 
  
 
create function row_number2 as  'org.apache.hadoop.hive.ql.udf. generic .GenericUDAFRowNumber' ;  
  
 execute query in a new cli session: 
  
 
select row_number2() over();
