Title

[bug][2.0.0-beta] DevTools cannot be toggled by keyboard shortcut

Description
### Describe the bug

I noticed from upgrading 2.0.0-alpha to 2.0.0-beta that the DevTools cannot be toggled by  CTRL  +  SHIFT  +  i  anymore, like it is documented in [URL]

When opening the DevTools by context menu "Inspect element" I can spot this error message:
`Unhandled Promise Rejection: window.internal_toggle_devtools not allowed. Permissions associated with this command: `

It seems there isn't a permission associated that could be configured in [Link: ACL/Capabilities] and setting the only cap that made sense to me `webview:allow-internal-toggle-devtools` did not work.

### Reproduction

In debug build press the keyboard shortcut (on Linux:  CTRL  +  SHIFT  +  i ) on the webview . Nothing happens. Then open the DevTools using "Inspect element" and note the mentioned error message.

### Expected behavior

Should toggle the DevTools as documented.
