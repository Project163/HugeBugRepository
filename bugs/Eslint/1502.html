Title

Bug: missing property `fatalErrorCount` in ignored file results

Description
### Environment

Node version: 17.3.1
npm version: 8.3.0
Local ESLint version: 8.6.0

### What parser are you using?

Default (Espree)

### What did you do?

**Code**

```js
// test.mjs
import assert from 'assert/strict';
import { ESLint } from 'eslint';

const eslint = new ESLint({ useEslintrc: false });
const results = await eslint.lintText('', { filePath: '/a/b/c/.ignored.js', warnIgnored: true });
assert.equal(results[0].fatalErrorCount, 0); // fails
```

**Output**

```
AssertionError [ERR_ASSERTION]: Expected values to be strictly equal:

undefined !== 0
```

### What did you expect to happen?

Results produced by ignored files with the `warnIgnored` option should have a `fatalErrorCount` property like other results.
The assertion in the repro code should pass.

### What actually happened?

Results produced by ignored files have no `fatalErrorCount` property.
