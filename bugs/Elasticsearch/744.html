Title

Blocking writes on a tribe node creates a "blocks" tribe

Description
From [Link: the configuration] a tribe node can block write operations with the following configuration:

``` yaml
tribe:
  blocks:
    write: true
  t1:
    cluster: ...
```

However when I do this, as well as getting the `t1` tribe, I also end up with a `blocks` tribe that fails to find a cluster:

```

      "name" : "Kohl Harder Boulder Man/blocks",
      "transport_address" : "inet[/ :9302]",

    },
...
```
