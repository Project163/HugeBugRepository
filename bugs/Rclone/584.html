Title

mail.ru: cannot unmarshal number NNN into Go struct field ListItem.body.list.mtime of type int64

Description
rclone reports the following error when trying to synchronize with mail.ru cloud:
```
$ rclone sync ~/cloudmailru mailru:
2020/05/13 23:37:34 ERROR : Photos: error reading destination directory: json: cannot unmarshal number   into Go struct field ListItem.body.list.mtime of type int64
```

**rclone version:** v1.51.0 linux/amd64 go1.13.7
**OS:** Debian Linux x64
**cloud storage system:** [Link: mail.ru cloud]
