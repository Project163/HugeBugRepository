Title

False positive superfluous-parens

Description
### Bug description

```python
tuple(x for x in ((a, str(a)) for a in ()))
```

### Command used

```shell
pylint test.py
```


### Pylint output

```shell
************* Module test
test.py:1: [C0325(superfluous-parens), ] Unnecessary parens after 'in' keyword
```

### Expected behavior

No errors.

### Pylint version

```shell
pylint 2.10.2
astroid 2.7.2
Python 3.8.10 (default, Jun  2 2021, 10:49:15) 
[GCC 9.4.0]
```


### OS / Environment

Ubuntu 20.04.3 LTS

                        )
