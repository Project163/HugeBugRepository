Title

Reproduce lines incorrect for 6.8 when running with Java 14+

Description
When a build failure occurs on the 6.8 branch and the Java version used to run the tests is JDK 14 or newer, the reproduction line will contain the incorrect value, `13`, for `runtime.java`. This is due to the implementation of Gradle's `JavaVersion`, which only has a value for the JDK version one newer than the latest at the time the version of gradle was released. 

This is problematic for build failures that only occur with a specific version of Java. For example, #57749 only occurs under JDK 15 yet blindly running the reproduce line found in the scan [URL] will result in the test passing when the reproduce line would reproduce the failure if the correct runtime java value was reported.

Technically this issue could also occur on master and 7.x but we are keeping more up to date with gradle versions on those branches.
