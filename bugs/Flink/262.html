Title

Suppress Akka's Netty Shutdown Errors through the log config

Description
I suggest to set the logging for `org.jboss.netty.channel.DefaultChannelPipeline` to error, in order to get rid of the misleading stack trace caused by an akka/netty hickup on shutdown.
Discussion
- The logged error is below. 
Setting the log level to "ERROR" should allow us to see critical messages and suppress the confusing warnings that seem to be an akka/netty bug.
