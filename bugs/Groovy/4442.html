Title

Elvis assignment operator loses type information

Description
This class works as expected: 

  
 
 class  RoutingInfo {
   String  to

  void hello() {  this .to ?=  'alice'  }
}
 
  

 Trying to use Elvis assignment from a class  in another file  (it must be another file) causes the STC to lose track of the type of the RHS and complain that it can't assign Object to String: 

  
 
 class  Other {
  void world() {
     new  RoutingInfo().to ?=  'bob' 
  }
}
 
  

  
 
Groovy:[Static type checking] - Cannot assign value of type java.lang. Object  to variable of type java.lang. String
Discussion
- If you change "String to" to "public String to" or "void setTo(String to)  
{ ... }
 " do you get the same thing?  There is some special property node handling and I'm trying to see if that is where the problem lies. 

 Update: field works fine.  Must have something to do with property.
- The static type checker creates expression "%.setTo((new RoutingInfo().to) ? new RoutingInfo().to : 'bob')" and tries to get the method target for the target type.  When the expression is reused for its getter semantic, something is going wrong.
