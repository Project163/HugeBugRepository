- The swagger ui configuration is build time only and it is not runtime overridable. 
You can enable or disable swagger ui on profile basis as shown here [URL]
- Thanks @machi1990 but it's not what the documentation says:
[URL]
[Image: image]
Either the code or the documentation are wrong.
- @brunobat thanks for the feedback. 

The documentation just means that if you want to activate the swagger ui in prod you have to always include it by setting the appropriate property to `true`.

 
Since the swagger-ui configurations are not overridable in runtime i.e (the configs are only used during application build time), you can still activate them via build system props during app packaging as shown below:

If you have in your `application.properties` something like:
```
....
quarkus.swagger-ui.always-include=false 
``` 

```
mvn clean install -Dquarkus.swagger-ui.always-include=true 
java -jar  
```
