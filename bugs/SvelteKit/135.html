Title

The postinstall script for a SvelteKit project runs in the root of a monorepo resulting in failure to generate the .svelte-kit folder

Description
### Describe the bug

My .svelte-kit folder wasn't getting generated on initial npm install from the root of my monorepo, so I dug in and saw that when the @sveltejs/kit postinstall script was running, it's trying to access the svelte.config.js from the root rather than the project that has the dependency.

### Reproduction

Run "npm install --foreground-scripts" from the root of the following repo to see the errors about a missing svelte.config.js:
