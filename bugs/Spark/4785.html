Title

Exception between "create table as" and "get_json_object"

Description
I encounter this problem when I want to create a table as select xxxx, get_json_object from xxx; 
It is wrong. 
  
 create table spark_json_object as
select get_json_object(deliver_geojson, '$.xxxx' )
from dw.dw_prd_order where dt= '2017-04-24'  limit 10;
 
  
 It is ok. 
  
 create table spark_json_object as
select *
from dw.dw_prd_order where dt= '2017-04-24'  limit 10;
 
  
 It is ok 
  
 select get_json_object(deliver_geojson, '$.xxxx' )
from dw.dw_prd_order where dt= '2017-04-24'  limit 10;
