Title

Truthy check fails to refine type

Description
```php
$s = rand(0, 1) ? 0 : 1;

if ($s) {
  $s = 3;
}

if ($s === 1) {}
```

Expected: Strict comparison using === between 0|3 and 1 will always evaluate to false.
Actual: [Link: No issue]

Fixed by making the comparison explicit:

```php
$s = rand(0, 1) ? 0 : 1;

if ($s === 1) {
  $s = 3;
}

if ($s === 1) {}
```
