Title

[bug] nsis uninstall delete menushort error when use perMachine mode

Description
### Describe the bug

The nsis uninstaller, when uninstalling, deleted the wrong shortcut, causing the file to not exist and causing an error.
When you update your app, the installer received exit code 2, indicating that it cannot be uninstalled

### Reproduction

Use nsis, the mode is perMachine, after installation and then uninstall, you will find that the shortcut is still there

### Expected behavior

Shortcuts should be removed after uninstall
