Title

Args and Globals broken in docs viewMode [6.4-beta]

Description
Globals get updated on canvas but not on docs tab

Reproduction: [URL]

1. Use the theme switcher on any component in canvas/docs
2. Then upgrade to `6.4.0-beta.0` and do the same

Thanks @frassinier for the report 🙏
Discussion
- As I said in #16243, there is no re-render of `DocsContainer` when we change an option from the toolbar and we can deal with it, but its `Canvas` are not re-rendered too.
You can't apply globals or parameters anymore in docs view mode.
- So the reason for this issue is hinted at in the discussion in #16243.

In the new store, when you render a **story** it sets up handlers to re-render on various events: [URL]

When you render docs in the v7 inline mode (not quite ready), it will call `renderStoryToElement` and setup the same handlers.

When you render docs in v6 inline mode it does not. So we should probably make docs do what it used to do and re-render whenever the globals change and the args change for **any** story. WDYT @shilman?
- Yowza!! I just released [URL] containing PR #16264 that references this issue. Upgrade today to the `@next` NPM tag to try it out!

```
npx sb upgrade --prerelease
```

Closing this issue. Please re-open if you think there's still more to do.
