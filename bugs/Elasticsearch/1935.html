- @clintongormley This looks to be caused by the fact breadth first collection mode is used. Using the same query with depth first collection mode succeeds:

```
curl -XPOST "[URL] -d'
{
  "query": {
    "bool": {

  }

Looking at `BestBucketsDeferringCollector.java`, it doesn't take into account that it may be used in a global aggregation when scores are needed. For example that the main query has matches for all segments and that the saved docids are the same to the matching docid with the main query are not true. I'll try to think about a proper fix.
