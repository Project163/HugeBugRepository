Discussion
- Failed feature: Index Backfilling.

Root cause: in the method `Tablet::FlushWriteIndexBatch` - the `YBMetaDataCache` object can be destroyed between 2 calls of `Tablet::YBMetaDataCache()`.

Fix: 2 calls of `Tablet::YBMetaDataCache()` should be replaced by a single one.

Code:
```
Status Tablet::FlushWriteIndexBatch(
    const HybridTime write_time,
    const CoarseTimePoint deadline,
    docdb::IndexRequests* index_requests,
    std::unordered_set * failed_indexes) {
... [Log Snipped] ...
  constexpr int kMaxNumRetries = 10;
  auto metadata_cache = YBMetaDataCache(); <<<<<< CALL-2, `metadata_cache`==NULL by the moment
```
