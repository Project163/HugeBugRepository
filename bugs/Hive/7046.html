Title

Repl checkpointing doesn't work when retry bootstrap load with partitions of external tables.

Description
Repl checkpoint feature optimises the retry logic of bootstrap repl load by skipping the properly loaded tables and partitions. In case of retry of bootstrap load with external tables having partitions, the checkpoint doesn't work and load partitions always.
