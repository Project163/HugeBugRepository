Discussion
- Looks like we should probably change that HashMap and make it static. The reason why it wasn't concurrent is that it is an instance field. But ParquetFileReader keeps a static ParquetMetadataConverter around, assuming that it is thread-safe. At the same time, we should make sure the rest of the class is thread-safe.
- How important is it to cache this state? Simply not cacheing this (and any other instance variables) will make this class thread safe / stateless. 

 Or, how about using a ThreadLocal cache? Does recomputing this per-thread ruin the performance gain?
