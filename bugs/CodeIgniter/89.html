Title

Form_validation always accepts empty array

Description
See the following code:

```
php
        $this->load->library('form_validation');

        $inputData = ['inp' => []];
        $this->form_validation->set_data($inputData);
... [Log Snipped] ...
        //Will return true
        $this->form_validation->run();
```

This behaviour seems to be caused by a missing check in the following code:

```
php
    protected function _execute($row, $rules, $postdata = NULL, $cycles = 0)
    {
        // If the $_POST data is an array we will run a recursive call

            return;
        }
```

Discussion
- There's no missing check.

An empty array means no data, which in turn means no form was submitted - the library doesn't "accept" it; it _ignores_ it. That's the intended behavior.
- Forgive me, but either I did not explain my problem well enough, or I have to reread the manual again.
