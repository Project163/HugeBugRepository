Title

ExpandoMetaClass doesn't handle no arg borrowing of methods in current form

Description
No arg method borrowing stopped working for EMC in recent builds. In particular, the example on the website no longer works. 

  
  class  Person {
     String  name
} 
 class  MortgageLender {
   def borrowMoney() {
       "buy house" 
   }
}

def lender =  new  MortgageLender()

Person.metaClass.buyHouse = lender.&borrowMoney

def p =  new  Person()

 assert   "buy house"  == p.buyHouse()
