Title

array_shift($arr) does not take type of $arr[0]

Description
This seems unexpected. Surely `$arr[0]` and `array_shift($arr)` should have the same type? (Or am I missing something?)

```

    
Discussion

    
- That'd make sense for a `list`, and possibly also for object-like arrays (array shapes) (from literals) with known keys, but doesn't apply to all `array`s

```
php > $x = [-1 => 'x', 0 => 'y'];
php > var_export($x[0]);
'y'
php > var_export(array_unshift($x));
2
```
- Hinting the function as `/** @param list $arr */` still generates an error, though.

Interestingly, though, hinting it as `@param list  $arr` _doesn't_ raise an error.
