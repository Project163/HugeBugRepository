Title

Mixins no longer work at end of file

Description
This has been true for the whole of version 1.0.0 so we don't have to fix it.  At the moment a mixin that is at the end of  the jade goes wrong.

If the last thing in a file is a mixin's block then a misterous `  ` tag seems to be being inserted.

We also no longer have variable hoisting for mixins.
Discussion
- +1 also getting this. This breaks our last-child CSS selectors
- Adding a newline to the end of the file seems to fix this BTW

Here is my mixin:

```
jade
mixin slide
  section.slide(data-background-image=attributes.background)
    if block
      block
... [Log Snipped] ...
        if block
          block
```

No newline at the end of this file = k element, broken CSS
newline = no k element, working CSS
- this worked for me. ends up with the newline space in the rendered html ...

``` jade
+el foo bar baz
```

``` html
 
   foo bar baz 

 
```

but c'lest la vie -- removes the little `  ` gremlins. thanks for the update, @Contra.
