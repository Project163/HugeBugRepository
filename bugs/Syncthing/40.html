Title

Deleting all my repositories creates a new one

Description
If I remove all my repositories, syncthing tells me it needs to restart. On restart, ~/Sync is created.
Discussion
- Yeah. Syncthing can't run without a repository; when there are none configured it assumes a new/blank configuration and creates the default.
- (The reason I haven't yet tagged this as enhancement or bug is that I'm not sure if it should be considered a bug, something to enhance, or just "functions as designed" and thus closed. I could probably be convinced in either direction.)
- It's useful to get everything up and running and then to configure the repo.

But... it's good behaviour to use ~/Sync on the first run (maybe prompt if it does/doesn't already exist), but re-adding it after explicitly removing it seems a bit counter intuitive.
- Agreed. It should learn the difference between no repo because it's the first launch (create the default) and because it was explicitly removed (leave it alone).
