Title

Regression: MutableDict.pop(..., None) throws an exception

Description
### Describe the bug

Using `MutableDict.pop(..., None)` worked with versions 1.4.x, but throws an exception if the key is missing with version 2.0.4. I tripped over this when attempting to upgrade a project using `asyncpg` but this also works with the sync API and the `sqlite` driver (see reproducer).

I’ll submit a PR which should fix this.
