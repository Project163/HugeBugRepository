Title

Helm tries to parse non-yaml/json files in crds/

Description
Output of `helm version`:
`version.BuildInfo{Version:"v3.0.2", GitCommit:" ", GitTreeState:"clean", GoVersion:"go1.13.5"}`

I put a script for updating third party CRDs and some markdown instructions in the crds/ directory of my chart. Helm apparently tries to parse these to install them, and then panics. Is this intended? I would have expected it to only read `*.yaml` and possibly `*.json`.
