Title

AsyncProducerStats is not a singleton

Description
AsyncProducerStats is not a singleton. This means that if a client instantiates multiple producers, the stat is collected for only 1 instance, instead of all instances.
Discussion
- Make AsyncProducerStats a singleton that tracks dropped events from all AsyncProducer instances. Add a separate jmx bean that reports the queue size for each AsyncProducer instance.
