Title

Unhandled error when initializing client for unknown user

Description
## What's going wrong?

This was discovered while trying to run applications with ldap authenticated environment.

If the pm2 tried to run with ldap authenticated user, pm2 crashed with unhandled error. The error related to (https://github.com/Unleash/unleash-client-node/issues/35), that crash occurred if the user doesn't have entry in /etc/passwd file.  Here is a stack trace from our app:

```
[~]$ pm2 status
[PM2] Spawning PM2 daemon with pm2_home=/home/deploy/.pm2
[PM2] PM2 Successfully daemonized
/usr/local/lib/node_modules/pm2/lib/API/CliUx.js:224
    current_user = os.userInfo().username;
... [Log Snipped] ...
    at writeOrBuffer (_stream_writable.js:320:5)
    at Parser.Writable.write (_stream_writable.js:247:11)
```

## How could we reproduce this issue?

- Login with ldap authenticated user (no entry in /etc/passwd)
- Run `pm2 status`

## Supporting information

Please run the following command (available on PM2 >= 2.6)

```
$ pm2 report
```
