Title

OSX mount fixes

Description
This issue captures various fixes required for OSX.  Full details are available in this thread:

[URL]

Fixes can be summarised as:

1) Remove special characters : and / from the volume name
1.b) Allow volname to be overridden with a flag.

2) Remove noapplexattr from the default config
2.b) Optionally allow it to be added back with a flag.

3) Change the exit code for the xattr calls to ENOSYS to stop OSXFUSE repeatedly calling them.
