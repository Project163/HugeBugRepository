Title

Static resources need the "application/javascript" content type for javascript files

Description
The static block of AbstractHTTPServlet (org.apache.cxf.transport.servlet.AbstractHTTPServlet) needs more content types, specifically for javascript files:  
STATIC_CONTENT_TYPES.put("js", "application/javascript");
Discussion
- Custom cxfServletStaticResourcesMap.txt file can be used to further customize the mapping
