Title

rclone move recreates folders even when empty

Description
for the rclone move command every time it goes to upload it remakes the directory tree on the remote

My current command line is

`rclone move -vv --checkers=50 --transfers=40 --drive-chunk-size=64M --stats=10s --no-traverse --exclude .\* /home12/jrwr/incoming/ google:/incoming/`

and outputs this: 
```
2018/12/28 01:43:37 DEBUG : tumblr2-test/pietja: Making directory
2018/12/28 01:43:37 DEBUG : tumblr-static-test: Making directory
2018/12/28 01:43:37 DEBUG : tumblr2-test: Making directory
2018/12/28 01:43:37 DEBUG : tumblr-static-test/JRWR: Making directory
2018/12/28 01:43:37 DEBUG : tumblr2-test/DLoader: Making directory
2018/12/28 01:43:37 DEBUG : tumblr2-test/SUNDAY: Making directory

```

with directories with a boatload of subdirectories, it causes a ton of API calls, (Thanks for adding in no-traverse!) I also noticed that if you use cache not on top of mount, these mkdir command clean out the file cache causing too many misses. now what I expected was that it could check if the path existed and if not to make the path, but not remake the folders every single time.
