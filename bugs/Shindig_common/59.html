Title

MakeRequestHandler and HttpRequestHandler do not use a real gadget when rewriting responses

Description
When the MakeRequestHandler or HttpRequestHandler rewrites HTML content it does not use the gadget context of the gadget making the request. The downside is that if the gadget specifies specific URLs that should not be rewriten via the content-rewrite feature the rewrite feature will not honor those URLs.
