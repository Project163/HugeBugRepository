Title

AttributeError raised from junitxml with pytest-flakes and pytest-pep8

Description
An exception is raised from junitxml when used with pytest-flakes and pytest-pep8.

```
_pytest/junitxml.py", line 334, in update_testcase_duration
AttributeError: '_NodeReporter' object has no attribute 'duration'
```

To reproduce : 

```
#!/bin/bash
virtualenv node_reporter_bug_env
. node_reporter_bug_env/bin/activate
pip install pytest pytest-flakes pytest-pep8
touch src.py
py.test --flakes --pep8 --junit-xml=report.xml src.py
```

This was introduced by the 2.8.5 release, it does not occur in 2.8.4. It is related to this : [URL]

I don't know if the 'finalize' method is called too early or if it should not do so much cleaning. If someone could give some hints on what is wrong, I would be glad to try to provide a patch.
