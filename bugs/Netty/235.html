Title

HttpHeaders.get documented to return the first entry, but actually return the last one

Description
The HttpHeaders.get() method stats that "If there are more than one values for the specified name, the first value is returned."

But If I do:

HttpHeaders headers = new DefaultHttpHeaders();
headers.add("Foo", "1");
headers.add("Foo", "2");

headers.get("Foo") returns "2" and not "1" as documented.
