Title

[DocDB] Extra space before . in Flush output after #28467

Description
Jira Link: [Link: DB-18266]
### Description

After applying changes from [Link: commit], the Flush output format shows an unexpected difference — an extra space is introduced before the . at the end of the message.

Previous behaviour (expected):
`Flushed [db_dr_non_col.employees_hash_non_col [ysql_schema=public] [ ]] tables.`

Current behaviour:
`Flushed [db_dr_non_col.employees_hash_non_col [ysql_schema=public] [ ]] tables .`

Issue:
The space before the period (tables .) is not expected and looks inconsistent with previous logging output.

Steps to Reproduce:

Run a workload that triggers a table flush after applying #28467 .

Check the log output.

Observe the extra space before the . at the end of the line.Minor, but causes inconsistency in log formatting.
