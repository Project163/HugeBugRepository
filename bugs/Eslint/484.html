Title

space-after-keywords allow enter

Description
Following code is allowed by _space-after-keywords_ in _always_ mode

``` javascript
if
(a == 1) {
    console.log(a);
}
```

Expected force

``` javascript
if (a == 1) {
    console.log(a);
}
```

In plugin should be check for count of spaces between. Currently there is only:

``` javascript
hasSpace = left.range[1] < right.range[0];
```

Version: 1.0.0 RC3
Discussion
- Yeah, we should double check that it's a space rather than a new line.
- Hmmm, I think this may have been too hasty and has caused some weirdness with keywords like `else`.

For example, with `"space-after-keywords": [2, "always"]` and the following code:

``` js
if (a == null)
  doThing()
else
  doOtherThing()
```

I get the error: `Keyword "else" must not be followed by a newline`

I don't think this is the intent of this rule.
