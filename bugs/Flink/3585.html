Title

Fix code generation in windowed join function

Description
In WindowJoinUtil#generateJoinFunction, When otherCondition is none, it will go into  statement: 
  
 
 case  None =>
  s"""
     |$buildJoinedRow
     |$collectorTerm.collect($joinedRow)
     |""".stripMargin
