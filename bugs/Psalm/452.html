Title

@psalm-suppress not working for MissingThrowsDocblock

Description
I'm not sure if this is due to my own misunderstanding of how Psalm works, but I figured this was the best place to report/ask this question.

|                         |                                          |
| --------------|-------------------------|
| **Expected** | Psalm reports no errors |
| **Actual**      | Psalm reports a `MissingThrowsDocblock` error |

I set the `checkForThrowsDocblock` attribute to true in `psalm.xml` and ran the tool. It reported a few missing `@throws` annotations which I fixed. One of the methods that Psalm reports an error for doesn't throw an exception on its own, rather a method it calls throws one which then bubbles up through the call stack.

I added `@psalm-suppress MissingThrowsDocblock` annotation above the method declaration and later inline, immediately above the call that would throw an exception.

```php
/**
* @template T as Throwable
*
* @param class-string  $throwable
*/
public function expectException(string $throwable) { }
```

i.e.
```php
public function testThing() : void {
```
