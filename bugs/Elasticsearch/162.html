Title

Search API: REST endpoint should use default operation_threading of thread_per_shard

Description
`operation_threading`, which defaults to `thread_per_shard` on the Java API, should default to it also in the REST API (it defaults to `single_thread` now). This only applies for search executed on the node the request was received on.
