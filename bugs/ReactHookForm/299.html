Title

Description
Apologies.

[Link: Small Sandbox]

**Working example:** 
- Enter input into box and click next
- Form resets ReValidation at each section
- Values are maintained when moving back/forward between sections
- Information for all sections is displayed as an alert when submitting section 3

**Issue:** 
- Values not being maintained with **reset({}, {keepValues: true})** when updating react-hook-form above 7.12

**Steps to reproduce:** 
- Update sandbox react-hook-form package above 7.12.2  
- Step through form as per working example

**Issue Outcome:** 
- Values are lost after moving between sections of the form

Expected Outcome: 
- Values will persist after **reset({}, {keepValues: true})** is called.
