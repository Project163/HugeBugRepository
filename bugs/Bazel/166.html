Title

Incorrect Traceback-like Message in GitCloner.java

Description
The changes in   are a step in the right direction to provide a traceback-like message to git clone problems.  However, the message that gets appended at each level is always the original message, so you get stuff like this (newlines added for clarity):

```
ERROR: /path/to/tensorflow/tensorboard/bower/BUILD:5:1:
no such package '@paper_menu_button//':
Error cloning repository:
[URL] cannot open git-upload-pack
caused by [URL] cannot open git-upload-pack
... [Log Snipped] ...
caused by [URL] cannot open git-upload-pack
and referenced by '//tensorflow/tensorboard/bower:bower'.
```

In the exception hander [Link: here] I think

``` java
errmsg.append(" caused by " + e.getMessage());
```

should be

``` java
errmsg.append(" caused by " + throwable.getMessage());
```

(Is there a way to format a code diff in issues markdown?)
