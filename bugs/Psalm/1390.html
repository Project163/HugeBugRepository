The static keyword will be used as return type, like psalm.

Thue current issue is that `parent::xxx()` is analysed by `AtomicStaticCallAnalyzer`, so in case of magic method, it'll check for `__callstatic` method existence, and read the MethodStorage from `pseudo_static_methods`.

This issue do not occurs on instance methods, because static and instance methods are all stored into `methods` property of `ClassLikeStorage`.
- Your diagnostic seems correct, I fixed the issue by adding handling for `pseudo_methods` when we detect a call with `parent::` but I have an issue with the static return type resolution. I'll push the PR when I find the issue. Thanks!
