Title

java.lang.ArrayStoreException on attempt to assign number to an element of a string array for a second time

Description
The following code demonstrates the problem: 

  
 def recreateProblem() {
    val =  "a;2" .split( ";" );
    val[1] = 1;
}

recreateProblem();

 //  this  second call will  throw  java.lang.ArrayStoreException
  //
 recreateProblem();
