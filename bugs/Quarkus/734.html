Discussion
- After review other issues opened regarding 'podman', I found the [Ref: #10637] where I could see the following argument to compile:

`-Dquarkus.native.container-runtime=podman`

That parameter is not described in the [Link: Quarkus - Container Images] reference. 

Using that parameter in my command then I reproduce the same issue described in [Ref: #10637]. That parameter should be added in the documentation to allow developers to set up the container runtime to use (docker | podman).
- Thanks for reporting!

You are correct that the docs are currently a little confusing... Basically `quarkus.native.container-runtime` has nothing to do with the `quarkus.container-image.....` properties but that is not evident from the docs.
