Title

Cyclomatic Complexity rule documentation links to jscomplexity.org which is no longer available.

Description
**Tell us about your environment**

* **ESLint Version:** Latest

**What did you expect to happen?**

Visit the further detail links on [URL] and find valid sites.

**What actually happened?**

[URL] is unavailable. The second link also has links to the first one, which is unavailable.

Hence it is difficult to determine the basis for how complexity is calculated without reading the code.
