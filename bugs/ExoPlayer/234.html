Title

Demo app: DefaultDrmSessionManger.EventListener callbacks not received in EventLogger

Description
### Issue description
`DefaultDrmSessionManger.EventListener` callbacks are not received in `EventLogger` in the demo app. 

I believe this is simply because the drmSessionManger is created with a null `EventListener` (`eventLogger` in this case). Creating the `eventLogger` before creating any components requiring event listeners should fix this.

### Reproduction steps
Play any protected sample provided in the demo app.

### Link to test content
