Title

Search templates for rank_eval endpoint currently only work when sent through REST end point

Description
In it's current implementation, templates used in a rank eval request are executed when parsing the REST request like so:

[URL]

However we also allow templates to be set through a Java API call to "setTemplate" on that same spec. This doesn't go through template execution so fails further down the line.

To make this work, I believe we'd have to move template execution further down, probably to TransportRankEvalAction.

With the new Java REST client being refined and improved, I'm wondering if that change is actually worth it: I think, as soon as Java calls also go through REST the above refactoring would be obsolete.

Opening this issue to track further discussion.
