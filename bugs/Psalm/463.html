Title

Class template params conflict with static method template params

Description
When a class has a template parameter, for example `T`, static methods on that class can define a template parameter with the same name `T` without any explicit error from Psalm. However, the template parameter on the static method(s) will not work as expected.

[URL]
[URL]

I think it would make sense for static method templates param names not to conflict with class template param names, given that the templates apply to different scopes. However, if they must continue to conflict, an explicit error from Psalm would be good imo.
