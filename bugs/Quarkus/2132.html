Title

Gradle build cache prevents source packages to be installed to local Maven repository

Description
### Describe the bug

Gradle build cache prevents source packages to be installed to local Maven repository

### Expected behavior

`mvn install -Prelease` should install the source package to local Maven repository

### Actual behavior

`mvn install -Prelease` gets the source package from the cache, puts to `target` but does not install it to local Maven repo.

### How to Reproduce?

```
rm -r ~/.m2/repository/io/quarkus/resteasy/reactive/resteasy-reactive-vertx/999-SNAPSHOT
cd quarkus

mvn install -DskipTests -ntp -Prelease -f independent-projects/resteasy-reactive/server/vertx/pom.xml
...
[INFO] --- source:3.2.1:jar-no-fork (attach-sources) @ resteasy-reactive-vertx ---
[INFO] Loaded from the build cache, saving 0.029s
...
```

After that the source package is in target

```
ls -l independent-projects/resteasy-reactive/server/vertx/target | grep sources.jar
-rw-r--r--. 1 ppalaga ppalaga  21826 Mar 15 23:21 resteasy-reactive-vertx-999-SNAPSHOT-sources.jar
```

But not in local Maven repo:

```
ls -l ~/.m2/repository/io/quarkus/resteasy/reactive/resteasy-reactive-vertx/999-SNAPSHOT | grep sources.jar
# no output
```

Workaround: run the build with `-Dno-build-cache`.
