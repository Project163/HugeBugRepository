Title

Object tree shaking removes properties that are being used

Description
### Rollup Version

4.27.2

### Operating System (or Browser)

MacOS 14.3

### Node Version (if applicable)

21.6.0

### Link To Reproduction

[URL]

```
js
export const getBuilder = () => {
  const variantShapeId = {
    errors: 1n,
    events: 2n,
... [Log Snipped] ...
  };
};
```

### Expected Behaviour

The object `variantShapeId` should be left as-is, since it's being indexed by an external parameter.

### Actual Behaviour

The object tree-shaking removes properties from `variantShapeId` that should be accessible.

In this specific example, this only happens when wrapping the statement that accesses the object with a try-catch.

### Additional context

This is a regression introduced in 4.27, related to #5420 

The example is the minimum reproduction case based on [Link: existing code of our library].
