Discussion
- This is working as expected. When you set `let index = $index`, it means that the index is available under `index`, instead of `$index`. You can fix it by changing the tracking expression to `track index`.
- Community opinion was asked by @JeanMeche , so here is my opinion: it would be more intuitive and less fragile if this syntax created aliases.
- ... [Middle Discussions Snipped for Brevity] ...
- This looks really counter-intuitive. Maybe allow track by $index with aliases?
- Coming back to this issue in preparation for graduating control flow from developer preview. 

To sum up what is going here, it seems to confuse people that the implicit `$index` variable can't be used in the tracking expression when aliased. That is, given:

```
@for (transaction of transactions; track $index; let index = $index) {
  ...
}
```

the ` let index = $index` aliasing "steals" the implicit `$index` variable. The reasoning for the current logic is that alias makes it ... an alias - if one maps a variable to a different name than the mapped name should be used.

Having said this I can see how this could be confusing, especially if one operates with the JavaScript's `let` model where both the new and and assigned variables are "visible". At the same time we couldn't go with the `let` mental model since it would mean that `$index` is _always_ available and "shadows" a component's property named `$index`. This is a real problem since, all of the sudden the `$index` would not be accessible from a template.

What we _could_ do, though, is to expose `$index` in the tracking expression (and not in the template) even if aliased. So far we didn't do so since this is a special case that would need explaining, documentation etc.

Hope that this comments explain our reasoning so far and actually demonstrates a straightforward mental model here. Still, I'm going to keep this issue open to see how many people bump into it. If this is a common source of confusion we can consider adding `$index` as always present in the tracking expression.
