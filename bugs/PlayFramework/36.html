Title

[2.5.0-M1] Bug in JavaScript reverse routes

Description
#5129 introduced a bug which appears in Play 2.5.0-M1 now.

Because of the PR JavaScript reverse route functions like this will now be generated:

```
javascript
...
_nS('controllers.Application'); _root['controllers']['Application']['scalaIntRoute'] = 
        function(id0) {

... [Log Snipped] ...
      ;
...
```

As you can see `id0` is passed to the function but then only `id` (without the trailing zero) is used as variable within the `if (...) {` statements which obviously does not exist (Chrome throws a exception like "`undefined variable`").

You can reproduce the bug with [Link: this simple project]. Just run it via `activator run` and have a look at `/assets/routes.js` in your browser.
