Title

Do not send full top-level `TransportNodesAction` request to individual nodes

Description
Expanding on #99744, there are several other `TransportNodesAction` implementations which send requests to the individual nodes each of which contains a copy of the top-level request, including all the irrelevant and heavyweight `DiscoveryNode` objects resulting from resolving the requested nodes. We should trim these down:
