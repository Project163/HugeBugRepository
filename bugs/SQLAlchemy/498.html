Title

Pickle of Properties object fails

Description
**Migrated issue, originally created by Pieter Mulder ([Link: @pieterproigia])**

Trying to pickle a Properties object as shown below fails.

```
import pickle

from sqlalchemy.util import Properties

data = {'hello': 'bye'}
... [Log Snipped] ...

pickle.loads(pickle.dumps(props))
```

```
Traceback (most recent call last):
  File "test_collections.py", line 14, in  
    pickle.loads(pickle.dumps(props))
  File "/usr/lib64/python2.7/pickle.py", line 1380, in dumps
    Pickler(file, protocol).dump(obj)
... [Log Snipped] ...
    raise AttributeError(key)
AttributeError: __dict__
```
It's clear Properties is ```__slot__``` based and thus has no ```__dict__```.
SQLAlchemy 1.0.13
