Title

Unpooled buffer acquired from pooled allocator may have .alloc() returning null

Description
### Expected behavior
- .alloc() returns allocator that buffer originated from. Backed by following behavior:
 - `allocator` field is reset on `deallocate()`.
 - `allocator` field is set properly in `initUnpooled()`
### Actual behavior
`.alloc()` returns null if buffer is initialized through `initUnpooled()` and was just created. It also may return wrong allocator if it was previously backed by chunk from different pooled buffer allocator.

### Steps to reproduce
[URL] -- `alloc()` is backed by `allocator` field. As object is pooled it must be initialized during `init()` or `initUnpooled()`

[URL] -- `allocator` initialized (as expected)

[URL] -- `allocator` is not initialized.

### Netty version
current 4.1 branch code.
