Title

[DocDB] Max aggregated metrics do not use max entry's metadata

Description
### Description

When we roll up tablet level metrics on a per table level, we grab the metadata from the first entry in `/metrics` that we find. However, if we're aggregating on max value, we don't update this metadata with the new max's attributes, which can lead to `/prometheus-metrics` displaying mismatched value / metadata.
