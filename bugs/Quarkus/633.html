Title

Bytecode recorder can not record ResteasyDeployment properties

Description
**Describe the bug**

When using a `ResteasyDeploymentCustomizerBuildItem` to customize the deployment, properties set using the build item are not recorded.

It seems the recorder can not record the properties because`ResteasyDeploymentImpl` is lacking a getter/setter.

**Expected behavior**

Resteasy extension should respect the properties set by an extension using `ResteasyDeploymentCustomizerBuildItem`.

`ResteasyDeployment` properties are not recorded.
