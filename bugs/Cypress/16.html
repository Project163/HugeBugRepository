Title

cy.visit and cy.request doesn't submit current browser's User-Agent header

Description
We are using ruby gem [URL]
to check if the browser is supported by our App. 
They are using request.headers["User-Agent"] to identify the browser.

In an normal chrome instance User-Agent is set correctly and Cypress "Chrome" it is suppressed and not submitted.
Discussion
- The problem isn't the browser or the way we spawn the browser - we simply omitted (through sheer oversight) to manually set `User-Agent` headers when making a request _outside_ of the browser.

During a `cy.visit` and `cy.request` we make HTTP requests outside of the browser, and that's where the problem is.

The correct approach would be to pass along the current browser's user agent when these underlying API's are called so it's completely seamless.
- Fixed in [Link: `0.17.6`].
