Title

Do not clear "Authorization" header if Z-server is running behind proxy

Description
There can be a case where Zeppelin-Sever is running as Form-Based-Authentication, however, it can be running behind a proxy which may be requiring Authorization header. 
The idea of this JIRA is to not clear that header when it behind a proxy and control it with config.
