Discussion
- The JDBCAppender will by default suppress any exceptions and log them. In the failover case this is not intended, so you need to set the "suppressExceptions" parameter to "false", so the exception is correctly propagated to the FailoverAppender and the event is correctly logged with the configured failover appender. 

 Unfortunately, the JDBCAppender has a bug with this setting, the line 83 in the current trunk should be changed to: 

  
         final boolean handleExceptions = suppressExceptions == null || Boolean.parseBoolean(suppressExceptions);
 
  

 The naming is confusing, handleException=true actually has the same meaning as suppressExceptions=true, as handleException means to handle the exception internally.
- The same bug is actually present in the JPAAppender and the NoSQLAppender.
