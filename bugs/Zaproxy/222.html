Title

Not all data is persisted for manual authentication method

Description
From OWASP ZAP User Group: [URL]

Steps to reproduce the issue:
1. Start ZAP;
2. Create a context that uses manual authentication;
3. Persist the session;
4. Create a new session then load the persisted session. Check the log file or output, there should be some exceptions:
```
66807 [Thread-11] ERROR org.zaproxy.zap.users.User  - An error occured while decoding user from: 0;true;QQ==;0;U2Vzc2lvbiAw
java.lang.IllegalStateException: Manual Authentication Credentials cannot be decoded.

	at org.zaproxy.zap.users.User.decode(User.java:331)
	at org.zaproxy.zap.users.User.decode(User.java:305)
```

This is a known limitation of the authentication method:
[URL]
