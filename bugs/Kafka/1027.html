Title

Connector REST endpoint allows incorrectly overriding the connector name

Description
If you PUT a connector config and it includes a connector name that doesn't match the URL, the request will succeed. It obviously shouldn't since the wrong connector name will be included. This should trigger an error in the 400 range instead.
