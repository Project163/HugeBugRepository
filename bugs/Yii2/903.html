Title

Comment on a column in a migration is at the wrong place, causing a syntax error

Description
### What steps will reproduce the problem?
Creating a table-column with a "check" and a "comment".
Either by putting it inside of the initial creation or by adding it afterwards.
This is in a default yii-migration-class:
```php
$this->createTable('something', [ 'test' => "longtext NULL DEFAULT NULL COMMENT 'this works' CHECK(json_valid(`test`))" ]);
$this->addCommentOnColumn('something', 'test', 'this breaks');
$this->createTable('something2', [ 'test' => $this->json()->comment('this breaks') ]);
//Created Type: longtext NULL DEFAULT NULL CHECK(json_valid(`test`)) COMMENT 'this breaks'
```

### What is the expected result?
The both not working commands should create MySQL similar to the working example included above.
In the end the column should have the check and the comment.

### What do you get instead?
A Syntax error from MariaDb (and probably MySql if I used that). According to the MySql-reference, comment should be way earlier than check_constraint_definition:
