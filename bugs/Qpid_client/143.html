Title

creating a Connection can time out if a pipelined Open frame arrives before the client sends its own

Description
If a server sends its AMQP connection Open frame immediately after the SASL process and it arrives before the client attempts to send its own Open frame, then the client can fail to complete the Connection creation and instead time the process out.
