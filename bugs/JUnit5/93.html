Title

Ensure that tags are trimmed

Description
## Overview

As purported in #927, it would appear that we do not consistently trim user-supplied tags.

## Deliverables

- [x] Investigate the validity above the above claim.
  - See _Analysis_ and _Correction_ comments below.
- [x] Ensure that individual tags supplied to a `TagFilter` are trimmed.
- [x] Ensure that individual tags supplied via `@Tag` are trimmed.
