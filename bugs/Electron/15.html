Title

Rendering crashes (white screen) when FontAwesome is used (Archlinux)

Description
With version 0.36.7 on Archlinux, if the html contains any glyph from FontAwesome, the rendering crashes and gives a white screen.

This only happens if the glyph is actually rendered, i.e. not hidden by CSS.

This can be reproduced using this example :
<!DOCTYPE html>

<html lang="en">
<head>
    <meta charset="utf-8" />
    <title>Font Awesome Crash</title>
    <link href="css/font-awesome.css" rel="stylesheet" type="text/css" />
</head>
<body>
    <i class="fa fa-trash-o"></i>
    <!-- Remove the line above and the rendering works fine -->
    Hello World !
</body>
</html>
