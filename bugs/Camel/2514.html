Title

CBR - Should break out if exception was thrown when evaluating predicate

Description
If having a CBR and the predicate throws an exception, then the next predicate is called before error handler triggers. 

 We should break out when exception is detected like pipeline/multicast can do.
Discussion
- I was the one asking about this on IRC earlier - just going to document that we found a workaround here. We made the bean implement Predicate and use when(bean) instead of when(method(bean)) and the error handling appears to work correctly.
