Discussion
- I think the root cause is because  RemoveSingleAggregateRule::onMatch  assumes  SqlSingleValueAggFunction   
 returns a  nullable  value, which is wrong because  SqlSingleValueAggFunction 's return type inference is  ReturnTypes.ARG0  and doesn't guarantee nullability.
