Title

Intermittent IllegalStateException with ByteToMessageDecoder impl with bounded inbound buffer.

Description
`ByteToMessageDecoder` calls `ByteBuf.unsafe().discardSomeReadBytes()` to discard decoded bytes from an inbound buffer efficiently.  In some cases, `discardSomeReadBytes()` can decide not to discard anything to save memory bandwidth.  At the same time, if the inbound buffer is not writable and the decoder decided to wait for more data without updating buffer indexes, a transport implementation will complain that the decoder did not consume anything even if the buffer is full.

The correct behavior is to:
- discard read bytes completely for this specific case.
