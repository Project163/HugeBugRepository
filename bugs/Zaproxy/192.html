Title

API Spider call not taking existing URLs as input

Description
Hi,

I imported set of urls in zap using API and tried to run the spider using API.  However, the spider is not taking the imported urls as input, only the scanner use it for finding vulnerability.  But, the scanner checks only the url and not processing any Forms inside the given url. 

If you right click and run the spider from GUI, it is taking the imported urls as input.  

Note: When i unchecked the "recurse" option in GUI and run the spider, it didn't take the imported urls as input.  So i tried to pass different values to recurse parameter in API(like "yes",1,true,True..),  but still it didn't do.
Discussion
- Please provide further details, what API endpoints are you using and with what parameters? (When importing, when spidering, etc)

In general it is best to get things working as you intend in the GUI then recreate that flow with the API. You can even run in GUI mode and execute with API then you can see what's going on.

If all of you're endpoints are within a part of the path (eg: example.com/API/endpoint1, etc) and you're starting point is example.com or /API then yes you have to recurse as the targets are "below" the starting point.
