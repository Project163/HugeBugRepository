Title

Auto import default exported component will break the imports

Description
### Which @angular/* package(s) are the source of the bug?

language-service

### Is this a regression?

No

### Description

When I try to auto import a component that is exported as default : 

```ts
export default class TestComponent {}
```

the vscode plugin will import it as: 

```
ts
import { default } from "./test.component";

@Component({
    template: `
... [Log Snipped] ...
})
export class AppComponent {}
```

This will make the build fail. 

- Importing the component as: 

```ts
import TestComponent from "./test.component";
```

works fine!
