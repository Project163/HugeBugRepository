Title

Redirect routes not compatible with old dispatcher

Description
This is a (multiple allowed):
- [x] bug
- [ ] enhancement
- [ ] feature-discussion (RFC)
- CakePHP Version: 3.3.2
- Platform and Target: Apache/2.4.18 
### What you did
- create new app `composer create-project cakephp/app test_routing`
- replace `webroot/index.php` with the old dispatcher
- add old dispatch factory filters to bootstrap
- add a redirect route to the main scope: `$routes->redirect('/test', '/pages/display/home');`

### Expected Behavior

Visit `/test` in the browser and see the home template.
### Actual Behavior

I get a `\Cake\Routing\Exception\MissingControllerException` exception. I noticed this when upgrading our app from 3.2 but keeping the old dispatch process as we need to right now. (Am I missing something?)

I'll be happy to submit a PR but I can't quite figure out what's going on yet, but if you debug the exception and die in the `RoutingFilter` it's throwing the `RedirectException` but it carries on into the controller factory anyway.
