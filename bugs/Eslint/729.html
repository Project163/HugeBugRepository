Title

"space-before-keywords" and "space-unary-ops" conflict [$10]

Description
Using eslint 1.5.0 and this config:

```
{
  "space-before-keywords": [2, "always"],
  "space-unary-ops": [2, { "words": true, "nonwords": false }]
}
```

You run into this problem:

```
js
(async function () {
  // Missing space before keyword "await".
  !await true

... [Log Snipped] ...
  !(await true)
})()
```

Should we change `space-before-keywords` "always" to make an exception for unary operators? The rule was meant to prevent these kinds of situations:

```
js
/*eslint space-before-keywords: [2, "always"]*/

if (foo) {
    // ...
... [Log Snipped] ...
    if (foo) {return; }            /*error Missing space before keyword "return".*/
}
```

So ignoring unary operators seems okay. Thoughts?
