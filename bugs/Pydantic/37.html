Title

Const validation error cannot be json serialized

Description
# Bug
A const validation error results in a `TypeError: Object of type SubForm is not JSON serializable` when using nested forms


Please complete:
* OS: **Ubuntu**
* Python version `import sys; print(sys.version)`: **3.7.3**
* Pydantic version `import pydantic; print(pydantic.VERSION)`: **0.32.2**

**Please read the [Link: docs] and search through issues to
confirm your bug hasn't already been reported before.**

```
py
import pydantic
import json


... [Log Snipped] ...
    # This fails because it can't serialize SubForm

```
results in

Discussion
- Better to use something like

```py
from typing_extensions import Literal

class SubForm(pydantic.BaseModel):
    field: Literal[2]
```

But I guess this might be possible to support and/or the error message should be better.
- We currently generate a form based on a homegrown data structure and set const to true for fields that are read only. It thus makes more sense to use this instead of generating a completely different form
