Title

StreamingConfig getConsumerConfiigs uses getRestoreConsumerConfigs instead of getBaseConsumerConfigs

Description
When starting a KafkaStreaming instance the StreamingConfig.getConsumerConfigs method uses the getRestoreConsumerConfigs to retrieve properties. But this method removes the groupId property which causes an error and the KafkaStreaming instance shuts down.  On KafkaStreaming startup StreamingConfig should use getBaseConsumerConfigs instead.
