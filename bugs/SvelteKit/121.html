Title

silence errors coming from `data-sveltekit-prefetch`

Description
### Describe the problem

Now that we have [Link: the option to prefetch all links inside a certain region of the DOM], I want to enable for all links instead of passing it to each link individually. I have added `data-sveltekit-prefetch` to the `body` tag.

But now I get a lot of errors:
```
Error: Attempted to prefetch a URL that does not belong to this app
````
some of my links will open to an external ressource.

### Describe the proposed solution

It would be great if `data-sveltekit-prefetch` would not throw errors and instead could silently fail.

Maybe a second optional param could be added to the `prefetch` function to allow to control if an error should be thrown or if the function should just returns.

This would also make it possible to have the same feature when calling `prefetch` programmatically.

- Next.js has a [Link: `prefetch()`] function that stops external URLs by returning early after checking with [Link: `isLocalURL()`]. This happens silently, without any warning.

SvelteKit already has a [Link: similar solution] that warns about external URLs, and easily could be modified into an early return instead.

Perhaps the easiest solution to close this issue would be to just do an early return and remove the warning. The warning does make sense to make you aware - but in practice there wouldn't be any need for developers to take action, if SvelteKit would ignore external links automatically just like Next.js does.
