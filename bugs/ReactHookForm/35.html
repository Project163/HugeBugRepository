Title

Validation error focus state for checkboxes/radios

Description
**Describe the bug**
Form validation will refocus on an input field if no value is entered. But this does not work for a checkbox or radio control. 


**To Reproduce**
Steps to reproduce the behavior:
1. Press submit and focus will go back to the first text field
2. Fill in the text field
3. Press submit
4. There will be a validation error on the checkbox field but it will not grab focus

**Codesandbox link**
[URL]

**Expected behavior**
Focus should be placed back on to the radio or checkbox group if this is the next top most error in the form.
