Title

SQLAlchemy 1.2 Loading Strategies Break Pickling

Description
**Migrated issue, originally created by Nick Pilon ([Link: @npilon])**

Setting a loading strategy on a query can result in the query returning ORM objects that are not pickle-able. This was not the case in SQLAlchemy 1.1.

Test case: [URL]

Name and version of database in use:
- PostgreSQL 9.6 / psycopg2 2.7.3 (originally discovered)
- SQLite 2.8.17 (minimal example)
