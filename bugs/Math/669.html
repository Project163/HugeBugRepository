Title

RealVector.sparseIterator() throws OutOfRangeException for empty vectors

Description
When calling  sparseIterator()  on an empty  RealVector  (dimension = 0), an  OutOfRangeException  is thrown instead of returning an empty iterator. This violates the expected behavior of iterator pattern where empty collections should return empty iterators. 

  Test Case:  
  
 
RealVector v = create( new   double [0]);
Iterator<Entry> it = v.sparseIterator(); // Throws OutOfRangeException
