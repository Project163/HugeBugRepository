Title

WS-RM persistent store recovery is not re-associated sequences together

Description
When a persistent endpoint is restarted, the destination and source sequences are recovered from persistent store.  However, the OfferingSequenceIdentifier is not re-associated with the source sequence.  This results in trying to create a new response sequence which can fail if using anonymous addresses.
Discussion
- If this worked correctly and the server was using persistent store, then   CXF-7392   likely shouldn't occur at all.
