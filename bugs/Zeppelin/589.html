Title

Default interpreter list should honour order of zeppelin.interpreters property in zeppelin-site.xml

Description
default interpreter list should honour order of zeppelin.interpreters property in zeppelin-site.xml
Discussion
- Hello! 

 Could you please explain, why order is important?
- Yes, because this is always honoured as long as the name is same as default name. But if a user changes the default interpreter name, for example in the default configuration in which zeppelin is shipped is; "spark" is default interpreter, now if user decides to change this name to "spark_2" or say we decides to have two spark interpreter with different names, in both of these cases the one which does not have name "spark" comes to the last, and other becomes default. 

 IMHO, this should behave like we do order by on a table. Hence, in this case first all spark interpreters together, then say all JDCB, angular and so on.
