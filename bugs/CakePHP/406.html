Title

3.0 - Form helper field names

Description
**What I tried**
I created a login form and tried to login to my application.  

``` php
    echo $this->Form->create('Users');
    echo $this->Form->input('email');
    echo $this->Form->input('password');
    echo $this->Form->submit('Login');
    echo $this->Form->end();
```

**Issue**
The issue I found after debugging the core was that the FormHelper no longer creates 'full' names for fields. This means that you cannot login, because [Link: `FormAuthenticate::_checkFields()`] cannot find the fields in the request because they are named using just the field name.

``` html
 
 
 
 
```

**Suggested**
I would suggest that the FormHelper still outputs 'fully qualified' field names for two reasons. Firstly it will help with backwards compatibility, and secondly it will mean that Form authentication will work `out-of-the-box'.

**Workaround**

``` php
echo $this->Form->input('email', ['name' => 'Users[email]']);
echo $this->Form->input('Users.email');
```
