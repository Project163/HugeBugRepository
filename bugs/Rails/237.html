Title

Getting Started Guide: Section 9 Need to close browser to retest.

Description
### Steps to reproduce
Follow Getting Started Guide 
[URL]
up to section 9 [URL]
Test the Create and Destroy methods for articles

### Expected behaviour
Only authenticated user can create or destroy articles

### Actual behaviour
You only need to sign in ONCE per session, so testing the articles Destroy method after authenticating (when you have just tested the Create method) does NOT present an authentication message (you're already signed in).
Using Cancel a couple of times does NOT show the sign in pop up either, you are automatically sent to the 'not authenticated' page (you're assumed to be signed out).

To test both articles methods (and the comments Destroy method in section 9.2) you need to close the tab and close the browser and start a new session for each new test.

This may seem obvious to experienced developers but this guide is aimed at those who are at least new to Rails.

**Rails version**:  

**Ruby version**: 2.7.0p0 (2019-12-25 revision 647ee6f091) [x86_64-linux]

OS Windows 10 20H2 (Insider's Slow edition) running WSL2 and Ubuntu 20.04 LTS
