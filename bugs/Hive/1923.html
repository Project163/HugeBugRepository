Title

LazyBinaryColumnarSerDe-based RCFile tables break when looking up elements in null-maps.

Description
RCFile tables that use the LazyBinaryColumnarSerDe don't seem to handle look-ups into map-columns when the value of the column is null. 

 When an RCFile table is created with LazyBinaryColumnarSerDe (as is default in 0.12), and queried as follows: 

  
 select mymap[ '1024' ] from mytable;
