Title

unexpected field [remote_cluster] error may occur under some specific conditions when executing cross cluster search (CCS)

Description
### Elasticsearch Version

8.15.0

### Installed Plugins

_No response_

### Java Version

_bundled_

### OS Version

any

### Problem Description

Elasticsearch 8.15 [Link: introduced] a "remote_cluster" concept to the Elasticsearch role. Under a specific scenario this new field may result in an error that appears:

                            "type": "parse_exception",
                            "reason": "failed to parse role [superuser]. unexpected field [remote_cluster]"
                        }

The specific scenario is as follows : 
* The local cluster is on 8.15.0 (or newer versions until this bug is fixed) 
* The remote cluster is on a version before 8.15
* Certificate based security model is in use (the elder RCS 1.0)
* An API key is used to authenticate to the local cluster
* The API key was created in 8.15.0 or newer
* The API key references "remote_cluster" either explicitly or implicitly via the creator user's role (likely superuser) 

### Steps to Reproduce

* 2 Clusters
* 8.15.0 -> 8.14.0 (wired together via certificates, not API keys) 
* In 8.15.0 cluster, log in as a "superuser" (which has has the "remote_cluster" privilege) and create an API key
* Execute a CCS request from the 8.15.0 cluster to the 8.14.0 cluster using the API key that implicitly references the remote_cluster
