- Hey, **I would like to work on this issue**. What I got from the description is, during the test when we don't have an internet connection, and we try to get the hostname of a claimed url we still get the `gaierror` exception. When we have a working internet connection, `gethostbyname` waits for a timeout to occur if url is unclaimed, due to which the test slows down. 

The solution you suggested was to mock the external communication for **testing purposes only**. I think that it would be a great idea because as of now tests are slow. But I wonder what would be the best way to mock the communication.
Is there a way we can know we are in a testing environment in `test_xss_scanner.py` If yes then we can have an array storing some URLs we assume to be claimed and during testing can check from that array only rather than using `gethostbyname`. Or we can provide an optional parameter to the `find_unclaimed_URLs` holding this array to check from.

I'm new to the community so not familiar with the protocols here.
Any suggestion from your side would be appreciated.
