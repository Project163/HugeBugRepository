Title

[YSQL] Memory leaks when transaction does not commit

Description
When an SQL process ends before a transaction is committed, server would leaks memory.  Sometimes, the following test passed, but most of the time it failed because one or more serializable transactions were not committed (For some reasons, DocDB aborted some of the transactions for this test, but that is a different issue from this memory leaking report).
```
ybd asan --cxx-test pgwrapper_pg_libpq-test --gtest_filter PgLibPqTest.SerializableColoring
```
