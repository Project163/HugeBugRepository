Title

Csv Serialization schema contains line delimiter

Description
CsvRowSerializationSchema.serialize(Row.of("f0", "f1")) => f0,f1\n 

 Csv Serialization schema is for one line, why contains line delimiter?
Discussion
- Now the filesystem wants to reuse serialization schema, but the behavior of each format is inconsistent. For example, the line separator is written in CSV, but JSON does not.
- I think  csv.line-delimiter  is not a good option for csv format, the  line-delimiter  should be an option of filesystem, because it is never used for message queues.  
For the row-wise formats, it should consume and produce the bytes for a row. The line splitting should be handled by connectors.  

 I also searched the mailing list, and I didn't find any user asking questions about  csv.line-delimiter , only some people are asking  csv.field-delimiter .  
Therefore, I think we can remove  csv.line-delimiter  option (mention this in release note) and not append a new line in  CsvRowDataSerializationSchema .  

 What do you think?
