Title

Cursor colour is incorrect after displaying ~2000 lines of dmesg

Description
Ubuntu 18.04, X11, alacritty 0.3.0

This is the weirdest bug: if I open a new terminal and run `dmesg`, the cursor consistently turns red.

[Image: image]

Typing doesn't make it change colour, but backspacing over characters makes it turn white (the original colour). Running `dmesg` again in the same terminal results in it turning white also; after this, I can't reliably reproduce the bug in the same terminal window.

The following file reproduces this (just `cat` it): [Link: dmesg.txt]

If I truncate that file much more, it no longer causes this to happen.
