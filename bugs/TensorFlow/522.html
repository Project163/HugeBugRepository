- @tonysung as [Link: freedomtan] mentioned new chipset doesn't use the Hexagon NN, so we can't support it currently.

For the other supported use cases of Samsung S8
You will need to make libhexagon_interface.so in the LD library path so it can be loaded
Example
```
LD_LIBRARY_PATH=/data/local/tmp/android-benchmark-tools:${LD_LIBRARY_PATH}
```

See example [Link: here] when it is done for testing.
For benchmark tool we set [Link: rpath] to /data/lcoal/tmp/ by default to ease running. See [Link: instructions]
- One more thing for pixel phones DSP access is disabled so it will not work.
If you have the Pixel phone rooted you can run these commands first
```
adb root
adb shell setenforce 0
```
