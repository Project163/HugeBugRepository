Title

Select.limit and .offset allow None as parameters

Description
### Describe the typing issue

According to the [Link: `GenerativeSelect.limit`] and [Link: `GenerativeSelect.offset`] docs, `None` can be passed to reset limit / option.

However the type checker doesn't allow those parameters to be `None`.

### To Reproduce

```
python
from sqlalchemy import Select, select
from sqlalchemy.orm import DeclarativeBase


... [Log Snipped] ...
        Table,
    ).offset(None)
```


### Error

```
testcase.py:16: error: Argument 1 to "limit" of "GenerativeSelect" has incompatible type "None"; expected "Union[int, _HasClauseElement, SQLCoreOperations[int], ExpressionElementRole[int], Callable[[], ColumnElement[int]], LambdaElement]"  [arg-type]
testcase.py:22: error: Argument 1 to "offset" of "GenerativeSelect" has incompatible type "None"; expected "Union[int, _HasClauseElement, SQLCoreOperations[int], ExpressionElementRole[int], Callable[[], ColumnElement[int]], LambdaElement]"  [arg-type]
``` 

### Versions

- OS: Linux Mint 21.1 Vera
- Python: 3.11
- SQLAlchemy: 2.0.0
- Type checker (eg: mypy 0.991, pyright 1.1.290, etc): mypy 0.991
