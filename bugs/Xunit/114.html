Title

Can't have a dash in the name of a test project

Description
It is not possible to have a test project with a dash in the name. My example below uses F#, but the problem seems to exist both for C# and F#.

To reproduce this, save the following as  `fsharp-tests.fsproj` and run `dotnet test`:
```
 

   
     net9.0 
   
... [Log Snipped] ...

 
```

This will fail with the following error message:
`C:\repos\fsharp-tests\obj\Debug\net9.0\XunitAutoGeneratedEntryPoint.fs(5,1): error FS0010: Unexpected symbol '[  This file has been auto generated by xunit.v3.msbuildtasks.  

module internal fsharp-null-tests.AutoGenerated

[ ]
... [Log Snipped] ...
    else
        global.Xunit.Runner.InProc.SystemConsole.ConsoleRunner.Run(args).GetAwaiter().GetResult()
```

The problem probably exists for other types of characters as well.
