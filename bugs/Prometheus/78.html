Title

PromConsole area renderer elevates a time series unexpectedly

Description
**What did you do?**

I used PromConsole.Graph with `renderer: "area"`, and often see time series elevated more than they should be, as if they were stacked on other time series which are not actually under them.  I attach a screenshot.

See [URL] for a small working example (well, non-working, which is the point).  For the purposes of that example, I monkey-patch `PromConsole.Graph.prototype.buildQueryUrl` to inject data which provokes the issue -- I copied this data from an actual `query_range` response, formatted it, and reduced it to a manageable size.

**What did you expect to see?**

Time series resting on the x-axis.

**What did you see instead? Under which circumstances?**

Time series elevated off the x-axis.  The linked example repo has sample data that provokes the problem.

**Environment**

The linked example uses the docker image `prom/prometheus:v2.19.3` with its standard configuration file.
