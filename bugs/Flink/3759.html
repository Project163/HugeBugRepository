Title

BinaryGeneric serialization error cause checkpoint failure

Description
The serialization error occurs from time to time when we're using  RoaringBitmap  as the accumulator of a UDAF. 

 I've attached the screenshot of the error.
Discussion
- Based on the stack trace, It looks like we forgot to duplicate the field serializers when duplicating  BaseRowSerializer . And it works fine after I duplicate the field serializers like this 
  
 
TypeSerializer<?>[] duplicateFieldSerializers =  new  TypeSerializer[fieldSerializers.length];
 for  ( int  i = 0; i < fieldSerializers.length; i++) {
        duplicateFieldSerializers[i] = fieldSerializers[i].duplicate();
}
 return   new  BaseRowSerializer(types, duplicateFieldSerializers);
- Thanks  wind_ljy  for reporting, and you are right, it is bug here.
