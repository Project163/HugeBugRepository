Title

System bundle location incompatible with fileinstall

Description
Fileinstall accesses the system bundle by its location "System Bundle". Connect uses the location "felix-connect" though. So fileinstall fails with a NPE.  

 I think it would be better to change the location to "System Bundle" as this might happen with other bundles too. Additionally we could check if fileinstall could simply load the bundle 0 which I think should always work.
