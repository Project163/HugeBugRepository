Title

Regression in `ToNodeIterator` for `HtmlIterable`

Description
**Problem**

#1452 changed the implementation of `ToNodeIterator` for `HtmlIterable` to use the helper function `yew::utils::into_node_iter`.
This cleaned up the code a lot, but it has the unfortunate consequence that it always returns `Iterator ` now.
This violates an invariant imposed by the `ToNodeIterator` trait: 

`T` is no longer inferred by the compiler but instead explicitly set to `Html`.
The consequence of this is that it can no longer be used with `html_nested!`.

**Steps To Reproduce**
See #1524

**Expected behavior**
The macro should allow `Into ` for any `T`, not just `T = Html`.

The previous implementation looked like this (minus macro verbosity):
```rust
(#expr).into_iter().map(|n| n.into())
```

The key difference is that `n.into()` isn't explicitly typed and so it can convert into any type that implements `From `, not just `Html`.


**Environment:**
 - Yew version: 0.17.3
