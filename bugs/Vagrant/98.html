```
end
```

Discussion
- Just to complete the above description, the vagrant file and behavior worked very fine with vagrant 1.8.7 before I upgraded to 1.9.3
- Update:
If I try adding this in vagrant file:
hv.ExposeVirtualizationExtensions = false

Then it tells:
Hyper-V:
* The following settings shouldn't exist: ExposeVirtualizationExtensions
- ... [Middle Discussions Snipped for Brevity] ...
- The culprit is here:

C:\HashiCorp\Vagrant\embedded\gems\gems\vagrant-1.9.3\plugins\providers\hyperv\scripts\import_vm_xml.ps1

```
# Enable nested virtualization if configured
if ($enable_virtualization_extensions) {
    Set-VMProcessor -VM $vm -ExposeVirtualizationExtensions $true
}
```

Change it to:

```
# Enable nested virtualization if configured
if ($enable_virtualization_extensions -eq "True") {
    Set-VMProcessor -VM $vm -ExposeVirtualizationExtensions $true
}
```

Then it will works fine in W8.1!

Because the Bool became a string for some unknown reason between 1.8.7 and 1.9.3...
I'll not commit this myself, I let devs do this.
