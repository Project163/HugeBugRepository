Title

Replace forward() in vectorized operators with vectorForward().

Description
I found that VectorAMEventOperator and VectorPTFOperator use the raw forward() instead of vectorForward(). Since using forward() in a vectorized operator leads to an incorrect count of processed rows and may cause wrong results when there are multiple child operators, these calls should be updated to use the proper version.
