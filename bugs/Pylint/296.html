Title

unused-import with typing when using module import

Description
This snippet detects that the import is used via type comments correctly:

```python
from typing import Optional
a = None  # type: Optional[str]
```

However, when importing the `typing` module instead:

```python
import typing
a = None  # type: typing.Optional[str]
```

or

```python
import typing
a: 'typing.Optional[str]' = None
```

we get:

```
W0611: Unused import typing (unused-import)
```

- pylint 2.3.1
- astroid 2.2.5
- typed-ast 1.3.5
- Python 3.7.3

Also reproducible with git master for pylint/astroid.
