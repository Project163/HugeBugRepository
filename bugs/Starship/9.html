Title

Battery module percentage display like '100%{' on Zsh. looks like mixed '{' Unintentionally.

Description
## Bug Report

#### Current Behavior
when battery module enable, show battery status like this. (I'm changed show threshold for this)
```
⚡️68%{ 🦄 💬 ❯
```

looks like mixed `{` Unintentionally.

#### Expected Behavior
```
⚡️68% 🦄 💬 ❯
```

#### Additional context/Screenshots
I see this problem on zsh.
on Bash, display `100%`.

#### Environment
- Starship version: 0.12.0
- Shell type: zsh
- Shell version: zsh 5.7.1 (x86_64-apple-darwin18.2.0)
- Shell plugin manager: none
- Terminal emulator: iTem
- Operating system: OSX 10.14.5

#### Relevant Shell Configuration
```
bash
setopt correct
setopt re_match_pcre
setopt prompt_subst
autoload -U compinit
... [Log Snipped] ...

eval "$(starship init zsh)"
```

#### Starship Configuration
```
[battery]
full_symbol = "🔋"
charging_symbol = "⚡️"
discharging_symbol = "💀"
```

#### Possible Solution
Discussion
