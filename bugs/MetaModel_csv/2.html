Title

CSV datastore should skip empty lines instead of presenting them as rows

Description
I've been working with some CSV files that contained empty lines either inbetween every record, or in the end of the file (trailing). Our current CSV datacontext "respects" these empty lines as real "rows". I believe it shouldn't... They are in my opinion just noise. 

 Will post a patch for fixing it and then let's discuss if everyone agrees that this is something we should get rid of.
