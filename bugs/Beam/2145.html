Title

User-friendly stage name for packed combiners

Description
BEAM-10409   adds the pack_combiners and eliminate_common_key_with_none optimizers, which replace multiple stages with one stage. Currently, the resulting stage uses the same naming scheme as fusion i.e. the component stage names concatenated with `+`. This creates ambiguity and also could render strangely on graphical UIs (e.g. Dataflow). This should be replaced with a more user-friendly naming scheme.
