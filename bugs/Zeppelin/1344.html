Title

The current version of Jetty is known to have security vulnerabilities

Description
The current version of Jetty that is used by zeppelin: 9.4.31.v20200723 - is known to have vulnerabilities. See  here  for more details. The recommended upgrade version is: 9.4.42.v20210604
Discussion
- How soon can this issue be addressed?  The current Jetty version has these CVEs. 

 CVE-2021-28169 
 CVE-2021-34428 
 CVE-2021-34429 

 Please upgrade the jetty to 9.4.43
