Discussion
- hmm this seems maybe specific to `PY_COLORS`
- ahah so here's what's happening:

1. monkeypatch set up
2. pytester set up
3. pytester creates its own monkeypatch and adds it as a `request.addfinalizer`: [URL] (it records it as setting PY_COLORS to 0 from unset)
4. test runs and sets `PY_COLORS` (it records it as swapping PY_COLORS from 0 to 1)
5. request finalizers run deleting `PY_COLORS`
5. monkeypatch tears down (setting PY_COLORS from 1 to 0)

since they're not done in order it breaks
