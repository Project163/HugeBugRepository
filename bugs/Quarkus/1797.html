Title

Blocking anotation does not work with Mutiny and gRPC

Description
### Describe the bug

When using Blocking on a Mutiny style gRPC service it fails with 

```
WARN  [io.qua.grp.stu.ServerCalls] (vert.x-eventloop-thread-0) gRPC service threw an exception other than StatusRuntimeException: org.jboss.resteasy.reactive.common.core.BlockingNotAllowedException
```

### Expected behavior

I expect it to work the same as Non-Mutiny style - without failing with the above exception and returning the answer.

```
@GrpcService
public class SteamService  extends GameServiceGrpc.GameServiceImplBase{
    @Inject
    GameFetch gameFetch;

... [Log Snipped] ...

}
```

### Actual behavior

Example code where gameFetch is blocking the method fails with org.jboss.resteasy.reactive.common.core.BlockingNotAllowedException.

```
@GrpcService
public class MutinyStreamService implements GameService {

    @Inject
    GameFetch gameFetch;
... [Log Snipped] ...
    }
}
```
