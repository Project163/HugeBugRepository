Title

namespace should be null when we can not find related schema

Description

    
Discussion

    
- in org.apache.cxf.jaxb.JAXBEncoderDecoder.marshallException(Marshaller, Exception, MessagePartInfo, Object):

                if (!sch.isElementFormQualified())  
{
                    namespace = null;
                } 
            } else {

When we have not found related schema, we just issue a warning. But instead we need to set the namespace = null.

            if (sch != null) {

             } else
