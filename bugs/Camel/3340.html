Title

JGroups managed routes can be started too early

Description
JGroupsFilters#dropNonCoordinatorViews  doesn't filter non-view messages properly which can cause the wrong route to be started. This issue was not so easy to detect, as usually the channels used for cluster management doesn't send any other messages, than view ones.
