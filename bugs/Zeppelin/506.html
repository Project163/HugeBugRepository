Title

Support absolute path to local repo in DependencyResolver

Description
DependencyResolver gets localRepoPath to constructor. But when the path is absolute local repo is created in incorrect place 

 Example from travis-ci: 

  
 08:27:20,280  INFO org.apache.zeppelin.dep.DependencyResolver:148 - load /home/travis/build/DrIgor/zeppelin/zeppelin-interpreter/../tmp/ZeppelinLTest_1481704039604/test-repo/com/databricks/spark-csv_2.10/1.3.0/spark-csv_2.10-1.3.0.jar
 
  

 Absolute repo path (/tmp/ZeppelinLTest_1481704039604/test-repo) is appended to the end of ZEPPELIN_HOME (/home/travis/build/DrIgor/zeppelin/zeppelin-interpreter/..)
