Title

Decorating QuarkusApplication won't build

Description
## Describe the bug
Creating a decorator for the `QuarkusApplication` interface gives a build error about only decorators can declare a delegate (even if the decorator is properly marked as `@Decorator`)

### Expected behavior
According to conversation on Zulip, this should work, so the app should build and the whole Quarkus execution decorated

### Actual behavior
Build error:
```java
[ERROR] Failed to execute goal io.quarkus:quarkus-maven-plugin:2.0.0.CR3:build (default) on project app: Failed to build quarkus application: io.quarkus.builder.BuildException: Build failure: Build failed due to errors
[ERROR] 	[error]: Build step io.quarkus.arc.deployment.ArcProcessor#validate threw an exception: javax.enterprise.inject.spi.DeploymentException: Only decorators can declare a delegate injection point: CLASS bean [types=[io.quarkus.runtime.QuarkusApplication, java.lang.Object, AppDecorator], qualifiers=[@Default, @Any], target=AppDecorator]
[ERROR] 	at io.quarkus.arc.processor.BeanInfo.init(BeanInfo.java:457)
```

## To Reproduce

Reproducer: [Link: main-decorator.zip]

Steps to reproduce the behavior:
1. Just build with Maven

Discussion
- I can confirm that it's a bug. First of all, we should skip decorators [Link: here]. Furthermore, a `QuarkusApplication` impl annotated with `@Decorator` should not be registered as an additional bean [Link: here]. Finally, the container should throw a definition error if a decorator declares any scope other than `@Dependent`.
