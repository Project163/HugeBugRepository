Title

Enable back Tag compression on HFiles

Description
HBASE-10443   disables tag compression on HFiles. This Jira is to fix the issues we have found out in   HBASE-10443   and enable it back.
Discussion
- When the store file is being read, as part of reseek to a key if we find the if we have jumped a given key we do a move previous. Incase of DBEs we have already decoded this KV and so tags in that. Suppose this KV had some tags which are like not present in Dict already. So as part of decode we read the actual tag from file buffer and adds an entry into Dict.  Now after moving to previous we once again decode this kv and so tags in that and again will make a duplicate entry into Dict (In next index). This makes the Dict structure totally gone.
- Interesting part is if we have tags of the same size this does not come out as Index out of bound, but silently will give wrong tag for the given KV which is more dangerous.
