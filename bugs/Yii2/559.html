Title

ColumnSchemaBuilder: {pos} placeholder should always be last

Description
### What steps will reproduce the problem?

Noticed this by trying to move a `primaryKey` column. It is not possible (at least in MySql), as the `PRIMARY KEY` gets defined twice, resulting in an error.

Workaround would be to use syntax like:

```php
/**
 * This doesn't work
 * $this->alterColumn('bb', 'id', $this->primaryKey()->first());
 */

$this->alterColumn('bb', 'id', $this->integer()->append('AUTO_INCREMENT')->first());
``` 

### What is the expected result?

`ALTER TABLE 'bb' CHANGE 'id' 'id' int(11) AUTO_INCREMENT FIRST`

### What do you get instead?

`ALTER TABLE 'bb' CHANGE 'id' 'id' int(11) FIRST AUTO_INCREMENT`
