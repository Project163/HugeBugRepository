Title

Regression: no-unused-vars fails on for blocks with let declarations

Description
The following file:

```
js
(function () {
    "use strict";
    const box = {a: 2};

... [Log Snipped] ...
    }
})();
```

fails with the following `.eslintrc`:

``` json
{
    "ecmaFeatures": {
        "blockBindings": true
    }
}
```

with a message:

```
app/modules/components/base/item-panel/page-view/pdf/pdf.js
  5:13  error  prop is defined but never used  no-unused-vars

✖ 1 problem
```

ESLint 0.13.0. It used to work in 0.12.0.
Discussion
- Related to the escope upgrade. In 0.12.0, this wasn't technically working correctly because it was applying the same scoping rules to `var` and `let`. Most likely a bug in escope.
- Reported to escope: [URL]
- Found a workaround that doesn't involve fixing escope.
