Title

Provide short name invocations for useful tools

Description
We have some tooling that can be made more friendly. 

  bin/hbase ltt  with no arguments should print usage instead of a stack trace. 
 bin/hbase canary  usage should refer to itself as  canary  not  o.a.h.h.tool.Canary  
 bin/hbase org.apache.hadoop.hbase.util.RegionSplitter  should be shortened to  bin/hbase regionsplitter . Usage should be updated to reflect the short name. 

 The fix here MUST also include updates to the book/documentation for the tools.
