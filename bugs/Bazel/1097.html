Title

Incorrect auto value handling --local_resources

Description
### Description of the bug:

When passing cpu=auto error message complains about value auto and suggest using auto.

`bazel build --local_resources=cpu=auto //...`

`ERROR: While parsing option --local_resources=cpu=auto: Parameter 'auto' does not follow correct syntax. This flag takes an integer, or a keyword ("auto", "HOST_CPUS", "HOST_RAM"), optionally followed by an operation ([-|*] ) eg. "auto", "HOST_CPUS*.5".`
