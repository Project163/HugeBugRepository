Title

V2 dictionary workaround fixes

Description
In some scenarios, AQE optimizes the step of writing the dictionary from repartition in the execution plan, skips the encoding of some partitioned dictionaries, and there is no abnormal prompt in the task status, which eventually leads to an error in the calculation of the count distinct metric. 

 So consider turning off AQE during dictionary construction
Discussion
- Fix Design： 

 Temporarily close aqe before the real build dict code 

 Then after the build is over, restore aqe to the initial value
