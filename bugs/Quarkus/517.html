Title

Exceptional CompletionStage in HttpAuthenticator#sendChallenge causes requests to hang

Description
**Expected behavior**
The request should return an error response.

**Actual behavior**
The request hangs. 

I have seen some "blocked thread" warnings, but I'm unsure if that's caused by the debugger:


**Describe the bug**
In `HttpSecurityRecorder#authenticationMechanismHandler`, `authenticator.sendChallenge` is called:
```
if (throwable instanceof AuthenticationFailedException) {
    authenticator.sendChallenge(event, new Runnable() {
        @Override
        public void run() {
            event.response().end();
        }
    });
} 
```

In `io.quarkus.vertx.http.runtime.security.HttpAuthenticator#sendChallenge`:
```
public CompletionStage  sendChallenge(RoutingContext routingContext, Runnable closeTask) {
    return mechanism.sendChallenge(routingContext).thenRun(closeTask);
}
```

If the `CompletionStage` returned by `mechanism.sendChallenge` is exceptional, the `thenRun` method won't be invoked, when means that the `closeTask` is never executed.
