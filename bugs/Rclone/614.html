- Hmm, this looks like an encoding problem.

We normally encode `#` characters into a similar looking unicode `＃` character.

However it looks like onedrive **does** allow `#` in directory names.

Here is one work-around


```
$ rclone lsf  --onedrive-encoding Slash,LtGt,DoubleQuote,Colon,Question,Asterisk,Pipe,Percent,BackSlash,Del,Ctl,LeftSpace,LeftTilde,RightSpace,RightPeriod,InvalidUtf8,Dot onedrive:#test
logo_symbol_color_16px.png
```

Another would be to rename the `#` to `＃` then it will work as expected.

Rclone uses the superset of reserved characters for onedrive business and onedrive
