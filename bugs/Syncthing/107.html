Title

ST tries to create Sync folder before creating config file while first start

Description
Trying to install ST on a ZTE Open C (Snapdragon CPU/ARMv7) with rooted Firefox OS 1.3.

Pushed the unpacked syncthing-linux-armv7-v0.9.4 to /data/local/tmp/syncthing on the device.

Typed in adb-shell for this directory:

./syncthing -home="/data/local/tmp/syncthing"

I get:

18:17:06 INFO: Generating RSA key and certificate...
[GKUTG] 18:17:58 INFO: syncthing v0.9.4 (go1.3 linux-arm default) jb@jborg-mbp 2014-08-12 22:35:37 UTC
[GKUTG] 18:17:58 INFO: My ID: Blablabla
[GKUTG] 18:17:58 INFO: No config file; starting with empty defaults
[GKUTG] 18:17:58 main.go:960: FATAL: mkdir /Sync: read-only file system

As mentioned in issues 400 and 401, the config file should be edited and the default ~/Sync location be overridden. But the config file has not yet been created.
Discussion
- Syncthing creates a ~/Sync directory on first start. In your case, your home directory seems to be set to /.
- You can hack around this by doing `HOME=/path/to/some/dir ./syncthing -options`

- Please try the latest build at [URL]
- 0.9.5: The config file is created now in the directory specified with the "-home" option.
