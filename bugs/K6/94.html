Title

k6 shows default with red cross during simple test instead of green checkmark

Description
### Brief summary

Hi *,
I don't know why but I get different result from MacOS than Linux when running a simple test `k6 run test.js` with `test.js`:
```
import http from 'k6/http';

export default function () {
  http.get('[URL]
}
```
This is the output:
- MacOS
**running (00m00.7s), 0/1 VUs, 1 complete and 0 interrupted iterations
default ✓ [======================================] 1 VUs  00m00.7s/10m0s  1/1 iters, 1 per VU**
- Linux
**running (00m00.5s), 0/1 VUs, 1 complete and 0 interrupted iterations
default ✗ [======================================] 1 VUs  00m00.5s/10m0s  1/1 iters, 1 per VU**

all seems to be fine with --verbose, but in Linux shows the red cross ✗.

MacOS 12.3.1 and `brew install k6`. (green checkmark)
Linux: Oracle/Red Hat/Rocky Linux and `dnf install [URL] + `dnf install k6`. (red cross)

The fact is that with a more simple test:
```
let counter = 0;

export default function() {
    counter;
};
```

both MacOS and Linux doesn't show any cross.

Thnx in advance.

### k6 version

k6 v0.37.0 ((devel), go1.18.1, linux/amd64)

### OS

Linux Oracle/Red Hat/Rocky 8

### Docker version and image (if applicable)

_No response_

### Steps to reproduce the problem

k6 run test.js

- test.js
import http from 'k6/http';

export default function () {
  http.get('[URL]
}

### Expected behaviour

show green checkmark in the default label.

### Actual behaviour

show red cross in the default label.

- Thanks for reporting this @hecnavsanz :bow: 

It seems to be a race condition in the code that updates the UI, which has no effect on anything else. It also only happens for me using GOMAXPROCS=1 - so having only 1 thread that runs go code, which is extremely unlikely in real life. 

I would expect that it was possible even without that ... but much less likely, as I don't remember ever seeing it, and couldn't reproduce it once.

I have a fix for it [here](https://github.com/grafana/k6/pull/2502

Also, it seems to me that you compiled k6 locally as both you are using go version that we haven't built with `1.18.1`. Also, prior to some changes *after* v0.37.0 it seems like instead of a cross, there was nothing-  no tick or cross.  I am mostly mentioning this, so you look into your setup.
