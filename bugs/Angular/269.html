**Current behavior**

AOT in prod mode produces this snippet in the ngfactory files

``` js
function viewFactory_SearchVideos0(viewUtils, parentInjector, declarationEl) {
   if ((renderType_SearchVideos === ((null)))) {
       (renderType_SearchVideos = viewUtils.createRenderComponentType('path/to/template/template.html', 0, import22.ViewEncapsulation.None, styles_SearchVideos, {}));
```
