Title

Description
I've been getting segmentation faults when running Nvidia SPADE repo (https://github.com/NVlabs/SPADE) with default parameters on AWS (Deep Learning AMI (Ubuntu 18.04) Version 26.0 and pytorch_p36 environment).

I'm using default parameters, one time it happened on 1st epoch, another was 4th epoch of training. (30 mins in). I've seen this using 1 GPU DataParallel and 8 GPU DataParallel.
