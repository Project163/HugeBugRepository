Title

MSSQL column nullability should be explicit

Description
**Migrated issue, originally created by Anonymous**

The nullability of an MSSQL column for which neither NULL or NOT NULL is defined in the  corresponding CREATE TABLE statement is determined using a combination of database setting and 'session' setting[Link: 0]. The DDL that the SA MSSQL dialect generates emits no specification of nullability for columns with 'nullable=True' set on their SA Table definition. So a table defined as nullable in its SA definition will have its nullability determined by database setting.

Attached find a test case that illustrates the current behavior and a patch to make the MSSQLSchemaGenerator explicitly emit nullability specifications in all cases.
