Title

Wrong value stored for a radio button with an /Opts entry

Description
When a radio button has an  /Opts  entry PDFBox saves the index of the value in the  /Opts  array as the fields value in  /V  instead of the appearance entries name for the  On  state the index is pointing to.
Discussion
- The above comment is describing the handling of Adobe Acrobat for the form test.pdf with the  On  states being name  a ,  b ,  c  in   PDFBOX-3656  . The names are not in line with the spec as  

 
 When the  Opt  entry is present, the names used to represent the on state in the AP dictionary of each annotation are computer-generated numbers equivalent to the numerical posi- tion (starting with 0) of the annotation in the Kids array.  

 so the names should be  0 ,  1 ,  2 . 

 Acrobat handles that so that the name the  On  state has is taken although it's not a number.
