Title

MP rest client interfaces do not support MP FT annotations

Description
SmallRye FT implementation is using an additional interceptor binding `@HystrixCommandBinding` to bind `HystrixCommandInterceptor` to all bean clasess that declare an MP FT annotation (such as `@Fallback`). In order to make it work SM FT portable extension adds `@HystrixCommandBinding` to [Link: all FT annotations] and since interceptor bindings are transitive it works as expected.

However, quarkus does not support transitive interceptor bindings yet and so the `HystrixCommandInterceptor` is not bound to the following rest client interface:
```
java
@RegisterRestClient
interface MyClient {

        @Fallback(MyFallback.class)
... [Log Snipped] ...
        JsonArray get();
    }
```
WORKAROUND: annotate the rest client with `@HystrixCommandBinding` (this annotation comes from SM FT).

I think we should support transitive interceptor bindings.
