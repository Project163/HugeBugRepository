Title

Datagen connector cannot set length for collection type

Description
I use the following DDL to generate collection type data: 

  
 
CREATE TABLE Orders (
    f0 Array<INT>,
    f1 Map<INT, STRING>,
    f2 MULTISET<INT>
) WITH (
   'connector'  =  'datagen' ,
   'fields.f0.length'  =  '10' ,
   'fields.f1.length'  =  '10' ,
   'fields.f2.length'  =  '10' 
);
 
  

 But got: 

  
 
Unsupported options:

fields.f0.length
fields.f1.length
fields.f2.length
 
  

 This should be valid options per our documentation: 

 ``` 
Size or length of the collection for generating varchar/varbinary/string/bytes/array/map/multiset types. Please notice that for variable-length fields (varchar/varbinary), the default length is defined by the schema and cannot be set to a length greater than it. for super-long fields (string/bytes), the default length is 100 and can be set to a length less than 2^31. for constructed fields (array/map/multiset), the default number of elements is 3 and can be customized. 
```
