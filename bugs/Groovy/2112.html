Title

groovy.util.slurpersupport.GPathResult is not java.lang.Iterable

Description
Despite it has an iterator() method, GPathResult is not Iterable. 

 For this reason constructs like e.g. 
  
 xml.theElement.collectEntries{  /* */  } 
  
 don't work.
Discussion
- I assume that GPathResult was implemented before java.lang.Iterable. If there isn't any (non-obvious) reason to not implement java.lang.Iterable, this would be the patch to solve this issue: 

  [URL]

 Please note: this patch DOES NOT introduce generic types along the GPathResult#iterator() class hierarchy. It just adds java.lang.Iterable<Object> to the GPathResult interfaces.
- Pull request merged into master. If there is sufficient interest and no unintended side effects observed we could also consider merging into 2_1_X (for 2.1.1).
