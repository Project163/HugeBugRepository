Discussion
- Thanks for reporting this! I'm not sure what caused the regression, but HDF5 unfortunately was not looking for the correct library names on windows. It additionally discounted the CMake config file, because we only install one of `{static, dynamic}` and it requested both.

I fixed this by manually specifying the locations and names of the `szip` library files. This isn't ideal, but it works.
