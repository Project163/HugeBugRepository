Title

Advanced application installation broken

Description
There are two issues with advanced application template installation.

First is related to missing directive `components.security.autoGenerateSecretKey` in config which is supposed to be `true`. Otherwise application throws exception:

```
Invalid Parameter – yii\base\InvalidParamException
Unknown secret key 'yii\web\Request/app-backend'
in C:\www\yii2-advanced\vendor\yiisoft\yii2\base\Security.php at line 304
```

``` php
throw new InvalidParamException("Unknown secret key '{$name}'");
```

file_put_contents($keyFile, json_encode($this->secretKeys));
