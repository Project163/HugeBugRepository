Also maybe it helps to know that that particular example isn't meant to run on its own, it is purely a reference to syntax. So `item` won't be defined unless you define it. For example, this `*ngFor` part in the example app's template for that doc:

```
 
   {{hero.name}} 
 
```
requires that it be defined in the template:

```
import { Hero, heroes } from './hero';
...
export class AppComponent {
  heroes = heroes;  // <--here
  hero = this.heroes[0];
```

Notice that `Hero` and `heroes` are imported from `hero.ts`:

```
export class Hero {
  id: number;
  name: string;
  emotion?: string;
}
... [Log Snipped] ...
  { id: 4, name: 'Magneta'}
];
```
So that's why those work and the small inline snippet wouldn't — there is no place where `items` is defined. You'd have to have each of those pieces in your app. The word `item` is used in the same way that one might use `foo` to explain a concept.
