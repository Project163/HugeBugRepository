Title

Plugin no longer picked up by default

Description
In GitLab by @adamchainz on Nov 17, 2016, 13:02

*Please describe how you installed Flake8*

From pip

*Please provide the exact, unmodified output of `flake8 --bug-report`*

N/A.

*Please describe the problem or feature*

My plugin `flake8-comprehensions` with its `C`-based error codes was picked up by default before on 3.0.4. Now on 3.2.0 (probably 3.1.0 too) it is not and users have to use `--enable-extensions C`, afaict. I noticed this whilst upgrading my tests ([Link: github pr]).

*If this is a bug report, please explain with examples (and example code) what you expected to happen and what actually happened.*

The plugin should still be picked up automatically. From reading the changelog, #239 was the only thing that changed this behaviour in 3.1.0, but it should have only affected plugins with `off_by_default = True`, which `flake8-comprehensions` does not have.
