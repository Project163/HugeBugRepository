Title

Add workaround for a deadlock issue of Class.getAnnotation()

Description
JDK-7122142  mentions that there is a race condition in getAnnotations. This problem can lead deadlock. The fix on JDK will be merged on jdk8, but hive supports jdk6/jdk7 currently. Therefore, we should add workaround to avoid the issue.
