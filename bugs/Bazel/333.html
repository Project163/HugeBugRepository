Title

Docker image with file from genrule has incorrect name

Description
I noticed an issue where I have a top level `genrule` which has an outs (e.g. `abcd`):

```
genrule(
  name = "myfile",
  visibility = ["//visibility:public"],
  cmd = 'echo hello > $@',
  outs = ["abcd"],
  srcs = [],
)
```

And then I create a docker image with that genrule, the filename inside the image is always the last letter of the filename instead of the whole name:

```
docker_build(
  name = "mydocker",
  tars = ["alpine.tar"],
  files = ["//:myfile"],
)
```

Then, the filename will be `d` instead of `abcd`.

Here's a demo repository showing the bug: [URL]

I saw this on bazel versions 0.2.0 and 0.2.2.
