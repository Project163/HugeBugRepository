Title

drive: special oauth text has gone missing

Description
In v1.52 `rclone config` says

```
Storage> drive
** See help for drive backend at: [URL] **

Google Application Client Id
Setting your own is recommended.
... [Log Snipped] ...
Enter a string value. Press Enter for the default ("").
client_id>
```

Wheras in 1.53 it says

```
Storage> drive
** See help for drive backend at: [URL] **

OAuth Client Id
Leave blank normally.
Enter a string value. Press Enter for the default ("").
```

So when we unified the oauth config in   we forgot about this special message, which is actually quite important!

@tgallant since you did the original refactor, do you want to have a go at fixing this?
