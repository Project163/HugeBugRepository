Title

PDF files with unusual Japanese font can not be rewrite correctly

Description
While rotate attached pdf file, The Japanese characters cannot display in the output pdf file.  
This problem can also occur when marge PDF files. 
We suspect that this caused by the name of font type. 

 Environment 
------------------------------------------------- 
OS    : Windows 7 (32bit) 
jvm   : 1.6 
pdfbox: 1.8.5 
------------------------------------------------- 

 Code to reproduce the problem 
------------------------------------------------- 
    public static void main(String[] args) { 

         String filePath = "D:\\test landscape.pdf"; 
        String newPDFFile = "D:\\test new_landscape.pdf"; 

         try { 
            PDDocument rotatedDocument = PDDocument.load(filePath); 
            PDDocument document = new PDDocument(); 

             int pageNumber = document.getNumberOfPages(); 
            for (int i=0; i<pageNumber; i++)  
{
                PDPage page = (PDPage)document.getDocumentCatalog().getAllPages().get(i);
                page.setRotation(-90);
                rotatedDocument.addPage(page);
            }
             rotatedDocument.save(newPDFFile); 

             document.close(); 
            rotatedDocument.close(); 
        } catch (Exception e)  
{
            e.printStackTrace();
        }
     } 
-------------------------------------------------
Discussion
- It is worse - it has nothing to do with the rotation, even code like this produces a PDF that can't be opened by Adobe: 
  
 PDDocument doc = PDDocument.load(....);
doc.save(....");
- In the original PDF, the name is 
  
 OXPCPR+07#82#e2#82#b3#82#b5#82#b3#83S#83V#83b#83N#83#7b#81#5b#83#8b#83h
 
  

 In the saved PDF, the name is 
  
 OXPCPR+07#82#E2#82#B3#82#B5#82#B3#83S#83V#83b#83N#83{#81#5B#83#8B#83h
 
  
 changing back the "{" to "#7b" allows to display the file with Adobe Reader.
