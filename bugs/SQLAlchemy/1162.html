Title

pysqlalchemy dialect does not send the pragma params specified in the connection URL

Description
In SQLAlchemy 1.3.(24) the pragma params specified in the connection URL are not sent to the backend, hence the default values are used no matter what params are specified in the URL.

example URL: sqlite+pysqlcipher://:{passwd}@/{file}?cipher=aes-256-cfb&kdf_iter=64000

In addition to not respecting the user's security preferences, the fact that this problem does not exist in SQLAlchemy >= 1.4,
confuses the user when migrating SQLAlchemy 1.3 -> SQLAlchemy 1.4.

A small bugfix (PR) will be linked to this issue.
