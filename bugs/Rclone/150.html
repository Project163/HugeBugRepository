Title

Check local directory exists before doing remote check

Description
I attempted to clone a directory on path on a mounted drive which normally works, but on this occasion it didn't  because the drive wasn't mounted yet, as I hadn't tried to access it since booting up. So I got this error:

Local file system at /media/andrew/ /WIN_DEV: directory not found

No problem there, but I think it would better if rclone did basic checks on the local directory FIRST, instead of after doing all the checks on the remote, which can take a very long time. I'm presuming the same sequence applies if there are other issues with the local directory such as permissions, so this enhancement would just save a bit of frustration, on some occasions.

Low priority of course.

rclone v1.35
Linux mint 18.1 64bit
Google Drive
rclone sync /media/andrew/ /WIN_DEV GoogleDrive:backup/WIN_DEV --exclude-from /home/andrew/Documents/backup/rclone-ignore.txt
Local file system at /media/andrew/ /WIN_DEV: directory not found
