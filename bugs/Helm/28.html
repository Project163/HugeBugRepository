Title

helm-3.0.0-beta.5: unable to return any non-zero exit status other than 1 from helm plugins

Description
helm-3.0.0-beta.5 swallows and rounds any non-zero exit status greater than 1 from a helm plugin to `1`.

This, for example, breaks `helm-diff` which relies on helm able to return `2` when `helm-diff` returned `2`.

This is a regression since helm-3.0.0-beta.5. The problem is exactly the same as #6384, which had been fixed in helm-3.0.0-beta.4 via #6385, but was reintroduced to helm-3.0.0-beta.5 via #6341.
