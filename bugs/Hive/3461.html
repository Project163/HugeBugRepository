Discussion
- Failure appears to be related to use of IMetaStoreClient in HCatUtil, which was done in  [URL]
It looks like one simple fix for this issue is to avoid using HCatUtil.assertNotNull() in HCatFieldSchema, since it looks like the error is coming from HCatUtil.
- I'm not sure that the original stack trace is from an environment that's set up correctly, since it seems to ultimately be complaining of a NoClassDefFoundError, and hcatalog does have a hard dependency on hive-metastore, which IMetaStoreClient is part of. 

 That said, I'm still +1 to the patch - moving from assert to an IllegalArgumentException is the right call in general here, I think, since as far as the HCatFieldSchema is concerned, it is an illegal argument to pass in a null typeinfo.
