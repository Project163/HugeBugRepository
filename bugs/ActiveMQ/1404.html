Title

Failover cluster update broken when url contains server side options

Description
When transport connector contains some server side config options like 

  
 tcp: //localhost:61617?transport.closeAsync= false   
  

 failover transport can fail as it can try connecting to that url with all its server side options.
Discussion
- Fixed with svn revision 1236707
- Another commit (svn revison 1239118) goes further and improves the behavior of this feature in situations like: 

 
	 using backup transports 
	 using multiple transport connectors per broker
