Title

doh: memory leak in conjunction with proxy use

Description
I am running a modified version of the existing TLV http fuzzer (available here: [URL]
I have gotten a leak when using doh and setting proxy option CURLOPT_PROXY (here: [URL]

The fuzzer sets the following options:
```
CURLOPT_URL=' :55770\x00\xff                          '
CURLOPT_NOBODY='    ')
CURLOPT_FOLLOWLOCATION='    ')
CURLOPT_ACCEPT_ENCODING=''
CURLOPT_DOH_URL='*:2'
CURLOPT_PROXY='*:2\x00'
```
The fuzzer (server) replies with the following garbage (the snipped tail is probably irrelevant):
```
'HTTP/2.0 301    \nLocation:       \xff\n    \xff   ' (snipped, continuous with more of the same)
```
and I get a leak report at the bottom of the message.

This reproduces well (tested two different machines, several times).
 
To reproduce, build the fuzzers according to [URL] and run (the provoking file is base64 encoded in the bottom of this report)
