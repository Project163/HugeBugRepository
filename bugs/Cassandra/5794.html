Title

Bloom filter miss counts are not measured correctly

Description
Bloom filter hits and misses are evaluated incorrectly in  BigTableReader.getPosition : we properly record hits, but not misses. In particular, if we don't find a match for a key in the index, which is where almost all non-matches will be rejected,  we don't record a bloom filter false positive . 

 This leads to very misleading output from e.g.  nodetool tablestats .
