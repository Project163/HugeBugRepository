Title

Unable to call native addon's async function from iframe

Description
* Electron Version: 2.0.7
* Operating System (Platform and Version): Windows 10
* Last known working Electron version: 

**Expected Behavior**

I expect native addon's async functions to work in iframes

**Actual behavior**
If to call native addon's async function from iframe DevTools will be disconnected, app will not respond until reload

**To Reproduce**
I created repository with minimalistic setup [URL] (check readme.md for instructions how to run easily). It basically use example [URL] for simplicity. Please note that if to comment runAsync(); in app.html (iframe) and uncomment the same statement in index.html electron app will be able to print async function's result without any problems. Apart from that any syncronous code could be called from iframe without any issues.
