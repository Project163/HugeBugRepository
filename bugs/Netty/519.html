Title

JsonObjectDecoder does not handle escaped backslash

Description
I've noticed the JsonObjectDecoder checks end of value string by looking at the previous char and if its the escape char \ then it's not the end of string if the current char is double quote. This is not correct.

Let's send the json object with key "key" and value "something\" , it is serialized as this:

{"key":"something\\"}

The decoder will not decode this since the last double quote is  after a backslash.
However this backslash is escaped but this is not handled in the code:
