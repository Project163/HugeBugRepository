Title

Junit custom tags do not get picked up by Continuous Testing engine

Description
### Describe the bug

We have defined our own custom Junit test tags (e.g. @UnitTest see below) for annotating our test methods for easy filtering and consistency, but Quarkus only picks up test classes where at least one method is annotated directly with @Test or the class is annotated with @QuarkusTest.

```
@Target({ ElementType.TYPE, ElementType.METHOD })
@Retention(RetentionPolicy.RUNTIME)
@Tag("unit")
@Test

public @interface UnitTest {
}
```

### Expected behavior

Custom tags should be handled like @Test tags as long as they also contain reference to @Test.

### Actual behavior

Quarkus only picks up methods tagged with @Test or classes tagged with @QuarkusTest.

### How to Reproduce?

Create Custom Tag e.g.:
```
@Target({ ElementType.TYPE, ElementType.METHOD })
@Retention(RetentionPolicy.RUNTIME)
@Tag("unit")
@Test

public @interface UnitTest {
}
```

Refer @UnitTest in Junit test method, e.g.

```
class CustomTagTest {

    @UnitTest
    void testMethod(){
(...)
```
