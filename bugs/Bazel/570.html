Title

toolchains: crash on two `register_toolchain` calls with non-existent toolchains

Description
### Description of the problem / feature request:

Calling `register_toolchain` twice in the `WORKSPACE` file with non-existent toolchains, then trying to build a toolchain-using rule crashes Bazel built at HEAD.

Bazel 0.11.0 displays a proper error message about the missing toolchains.

### Bugs: what's the simplest, easiest way to reproduce this bug? Please provide a minimal example if possible.

In an empty directory, create:
-  `WORKSPACE` file:
    ```
    register_toolchains("//:bad1")
    register_toolchains("//:bad2")
    ```
-  `BUILD` file:
    ```
    load(":rules.bzl", "foo")
    foo(name = "foo")
    ```
-  `rules.bzl` file:
    ```
    def _impl(ctx):
      toolchain = ctx.toolchains["//dummy"]
      return []

    foo = rule(
      implementation = _impl,
      toolchains = ["//dummy"],
    )
    ```

Build with release Bazel:
```
  $ bazel build //:foo
..........

INFO: Elapsed time: 1.584s

```
