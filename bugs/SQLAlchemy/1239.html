Title

Crash with @declared_attr on non-trivial __mapper_args__

Description
**Describe the bug**
When using `@declared_attr` on a `__mapper_args__` method with a return type annotation and non-trivial body, the plugin crashes.

**Expected behavior**
No crash.

**To Reproduce**
With test.py as
```
py
from sqlalchemy.orm import declarative_base
from sqlalchemy.orm import declared_attr
from sqlalchemy.orm import Mapped

... [Log Snipped] ...
        else:
            return {}
```

and setup.cfg as
```ini
[mypy]
plugins = sqlalchemy.ext.mypy.plugin
```

run
```
 python3 -m venv venv
./venv/bin/pip install 'sqlalchemy[mypy]'
./venv/bin/mypy --show-traceback test.py
```

**Error**

```
test.py:-1: error: INTERNAL ERROR -- Please try using mypy master on Github:
[URL]
Please report a bug at [URL]
version: 0.910
Traceback (most recent call last):
... [Log Snipped] ...
TypeError: unhashable type: 'list'
test.py:-1: : note: use --pdb to drop into pdb
```

**Versions.**
 - OS: Reproduced on OpenBSD and Alpine.
 - Python: Reproduced with 3.8.10, 3.8.12, and 3.9.7
 - SQLAlchemy: 1.4.27
 - mypy: 0.910
 - SQLAlchemy2-stubs: 0.0.2a19

**Additional context**
I believe the requirements to crash are

* The class must be derived from `declarative_base`.
* `@declared_attr` must be used.
* There must be a return type annotation. `dict` is sufficient (as is `typing.Dict`). The `Mapped` bit is just to kill off a warning `test.py:9: error: [SQLAlchemy Mypy plugin] Can't infer type from @declared_attr on function '__mapper_args__'; please specify a return type from this function that is one of: Mapped[ ], relationship[ ], Column[ ], MapperProperty[ ]`
* The body can't be trivial i.e. `return {}` wasn't sufficient to produce the crash.
