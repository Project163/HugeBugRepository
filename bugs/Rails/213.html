- Hi! Any update on this? We also have the same issue with Rails 6.1.
- @javierav The issue of reloading an app from one thread while another thread owns a database connection has not been solved.  However, since #39718, `Rails.application.reloaders.map(&:updated?).any?` should be `false` when starting a fresh Rails console via Spring.  Thus, as long as you avoid making changes that would require a reload (and `Rails.application.config.reload_classes_only_on_change` is `true`), you should not experience a hang.  When you do make such changes, calling `reload!` in the console before triggering a job may prevent the hang.  Restarting the console should also prevent the hang, though that may be less convenient.
