Title

PlayerNotificationManager should behave independently of when the player is set

Description
The UI generated by `PlayerNotificationManager` for a `Player` in a given state, should be independent of when the player was passed to `setPlayer`. This is currently not always the case. For example if the player is already in `STATE_IDLE` when `setPlayer` is called, no notification will be displayed.  However if the player were passed in some other state and later transitioned to `STATE_IDLE`, a notification will be displayed.
