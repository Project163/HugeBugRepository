Title

debug() of db query result with "->all()" throws error in 4.1

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 4.1.0
* Platform and Target: Development with XAMPP (7.3.14) on Windows 10: Apache 2.4.41, MariaDB 10.4.11, PHP  7.3.14)

### What you did
I build a simple DB Query like this `$query = $this->Surveys->find('all');` and getting the result with `$result = $query->all()`. For debugging I call `debug($result);`

### What happened
With 4.1. this error is thrown
`Argument 1 passed to Cake\Error\Debug\PropertyNode::__construct() must be of the type string, int given, called in C:\ ... \vendor\cakephp\cakephp\src\Error\Debugger.php on line 745
`
### What you expected to happen
I expected an output as with 4.0.8 with no errors.

Hint: With `$result = $query->toArray()`. + `debug($result);` in 4.1 the output is very nice with the new "unfold / fold" possibility.
