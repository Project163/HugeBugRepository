Title

Tarball as local resource type archive fails to localize on Windows

Description
When trying Tez out on Windows, the tez tar.gz failed to localize on Windows env.  

 Also. reproduced the same issue with a similar tarball when used with distributed cache with an MR sleep job.
Discussion
- Some tar files do not have directory entries before files contained in that directory (this doesn't happen with command line tar tool on mac...), I suspect it's an issue with how ant/gradle/mvn/whatnot is generating the file, that it is failing to include the directory entries.  In any case, this change checks for the existence of a parent directory and creates it if it is missing before attempting to write a file.  (prevously, only the top level directory was checked for, now the parent of any file is checked for)
