Title

Need to remove basename from location for StaticRouter

Description
## Version
    "react-router": "4.0.0-beta.3",

## Test Case
Server Rendering with a nested Route

## Steps to reproduce
Use React on Rails and server rendering as shown in the below file for the app. This SPA with react-router is rendered under Rails routes that start with `/browse`. So that is the "basename". The problem is that the location has to strip the basename.

```
js
import React from 'react';
import { renderToString } from 'react-dom/server';
import { StaticRouter } from 'react-router';

... [Log Snipped] ...

export default BrowseApp;
```

## Expected Behavior

You should not have to remove the basename from the location every time. In other words, the location should contain the basename.


## Actual Behavior

I have to remove the basename from the location every time.
