Title

Named docker containers and docker-run conflict

Description
When using docker as a provider and specifying `name` option in machine [Link: configuration], eg.

``` ruby
  config.vm.define 'php' do |machine|
    machine.vm.provider 'docker' do |d|
      d.name = 'myapp.php'
      d.build_dir  = 'docker/php'
    end
  end
```

then starting the container with `vagrant up` and trying to run a command with eg `vagrant docker-run php -- env` the error appears: `Conflict, The name myapp.php is already assigned to 0120a863a93d. You have to delete (or rename) that container to be able to assign myapp.php to a container again.`.

So when using `name` option it's impossible to run `vagrant docker-run` at all.
Discussion
- Second this, should ignore d.name, but there is a work around!

```
if ARGV[0] != "docker-run" then
  d.name = 'myapp.php'
end
```
- Thanks! This will be fixed soon.
