Title

Editing Repositories via API ignores default_merge_style

### Description

When editing repos via the API, the value of `default_merge_style` is ignored.

Querying the API with curl/jq before the change:
```
$ export GITEA_ACCESS_TOKEN=[...]
$ curl -s -H "Authorization: token $GITEA_ACCESS_TOKEN" [URL] | jq .default_merge_style
"merge"
```

Trying to change the setting via the API:
```
$ curl -s -H "Authorization: token $GITEA_ACCESS_TOKEN" -X PATCH -H 'Content-Type: application/json' -d '{"default_merge_style": "rebase"}' [URL] | jq .default_merge_style
"merge"
```
This **should** have returned `"rebase"`.

After changing the default merge style through the UI:
```
$ curl -s -H "Authorization: token $GITEA_ACCESS_TOKEN" [URL] | jq .default_merge_style
"rebase"
```
