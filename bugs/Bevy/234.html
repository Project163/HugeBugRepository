Title

glTF scene loader uses wrong color space

Description
## Bevy version

0.9.1

## What you did

Loaded a glTF scene

```
rust
use bevy::prelude::*;

fn main() {
    App::new()
... [Log Snipped] ...
    });
}
```

## What went wrong

 
 The colors of all of the models were different than they were in Blender: 

Blender:
[Image: cyan-blender]
Bevy:
[Image: cyan-bevy]
Blender:
[Image: grey-blender]
Bevy:
[Image: grey-bevy]
Blender:
[Image: lime-blender]
Bevy:
[Image: lime-bevy]

 

## Additional information

Bevy's glTF loader [Link: interprets colors in the sRGB color space,] which is incorrect - glTF mandates that colors be specified in linear color space.

Initially I assumed that Bevy was correct and Blender was at fault, but this was disproved shortly after I [Link: reported it as a bug in Blender].
