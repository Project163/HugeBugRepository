Title

shada: heap-use-after-free

Description
### Problem

When running Nvim with ASAN and `UBSAN_OPTIONS=print_stacktrace=1 ASAN_OPTIONS=abort_on_error=1:log_path=/tmp/nvim_asan`, ASAN detects a heap-use-after-free on exit:
```
=================================================================
==808198==ERROR: AddressSanitizer: heap-use-after-free on address   at pc   bp   sp  
READ of size 1 at   thread T0
    #0   in strcmp.part.0 asan_interceptors.cpp.o
    #1   in strequal **/src/nvim/memory.c:550:49
... [Log Snipped] ...
  Right alloca redzone:    cb
==808198==ABORTING
```

This is bisected to <[URL] (#34373).

Note that the `abort_on_error=1` is required for bisecting, otherwise the ASAN log somehow isn't written before <[URL] and the heap-use-after-free is not observable.
