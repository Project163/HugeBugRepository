Title

exist and visible options are not displaying in command log when implicit assertion passes

Description
When I pass the options exist or length to a DOM traversal, they do not print in the command log when the implicit assertion passes.

**Example Code**

``` coffee
it"displays options", ->
  cy.get(".answers-list tr", exist: true)
  cy.get(".answers-list tr", visible: true)
  cy.get(".answers-list tr", length: 55)
```

Discussion
- Fixed in [Link: `0.6.2`].  Note the `{exist: true}` would not log out since that is the default option. Only the `length` key was buggy and not logging out.
