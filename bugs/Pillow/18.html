Title

TypeError in PngImagePlugin._save

Description
Using Python 2.7.9 for 64-bit Windows. Pillow 3.0.0 installed via `pip install pillow`. Script file:

```
import os

import PIL.Image
basedir = "../data/PIL_Images"
im = PIL.Image.open(os.path.join(basedir, "tinysample.tiff"))
im.save(os.path.join(basedir, "tinysample.png"))
```

Error traceback:

```
Traceback (most recent call last):
  File "pyi_lib_PIL_img_conversion.py", line 17, in  
    im.save(os.path.join(basedir, "tinysample.png"))
  File "c:\Users\Rio\Documents\src\pyinst1328\.env27\lib\site-packages\PIL\Image.py", line 1665, in save
    save_handler(self, fp, filename)
  File "c:\Users\Rio\Documents\src\pyinst1328\.env27\lib\site-packages\PIL\PngImagePlugin.py", line 757, in _save
    data = name + b"\0\0" + zlib.compress(im.info["icc_profile"])
TypeError: must be string or read-only buffer, not tuple
```

[Link: Input image file is here.]

This code previously worked with `pillow==2.9.0` installed.

With `pillow==3.0.0`, `im.info["icc_profile"]` is a tuple of length 1 containing a single bytestring. With `pillow==2.9.0`, `im.info["icc_profile"]` is a bytestring.
