Title

accessing nullptr on curl_easy_cleanup when using SSL

Description
I am building on windows 10 64bit, with Visual Studio 2017, a static version of libcurl (based on this [Link: commit], build options: `nmake /f Makefile.vc mode=static MACHINE=x64 DEBUG=yes`).

When trying to make a simple get request with HTTPS and calling curl_easy_cleanup I get a read access violation on this callstack:
```
Curl_ssl_sessionid_lock(connectdata * conn) line 283 (vtls.c)
    Curl_schannel_shutdown(connectdata * conn, int sockindex) line 1916 (schannel.c)
    Curl_ssl_shutdown(connectdata * conn, int sockindex) line 557 (vtls.c)
    Curl_schannel_close(connectdata * conn, int sockindex) line 1821 (schannel.c)
    Curl_ssl_close(connectdata * conn, int sockindex) line 553 (vtls.c)
... [Log Snipped] ...
    Curl_close(Curl_easy * data) line 331 (url.c)
    curl_easy_cleanup(Curl_easy * data) line 826 (easy.c)
```

I is probably due to the line 317 in conncache.c (function Curl_conncache_remove_conn) added in the [Link: commit]. It sets conn->data to null and gets called in line 786 of conncache.c (function Curl_disconnect) before Curl_ssl_close (see stack).
