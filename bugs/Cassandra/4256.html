Title

javadoc for UnfilteredSerializer is not formatted correctly

Description
The javadoc for o.a.c.db.rows.UnfilteredSerializer is the most authoritative information I was able to find that defines the structure of a Row object or a RangeTombstoneMarker object. However, currently  it  has a lot of incorrect usage of tags which makes its javadoc very hard to read. It should be pretty trivial to reorganize the text so that it can follow javadoc's markup convention.
