Title

In some cases, the javascript client will not output the ns declaration for wrapper element of an rpc/lit method

Description
The javascript generator collects the namespace prefix for the RPC wrapper element AFTER the list of prefixes has been written out.  Thus, if something else hasn't happened to add the namespace to the list, the resulting XML is invalid.
