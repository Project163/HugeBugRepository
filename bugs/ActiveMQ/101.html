Title

create a super pom for tooling projects in activemq so we can create a nightly build of the various maven plugins

Description
We need to move all the m2 plugins under tooling/ (they nearly all are) then create a pom.xml there for building all the tooling plugings. 

 Folks from there can then do 'mvn clean install' to build and install all the m2 plugins. We can then create a nightly build of the m2 plugins easily. 

 (Right now plugins are not always auto-downloaded when folks try to use stuff in say activemq-perftest module)....
