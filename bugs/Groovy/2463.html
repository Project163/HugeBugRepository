Title

exception in phase 'class generation' using getAt()

Description
Compiling the testcase generates the following error message: 

  BUG! exception in phase 'class generation' in source unit '/home/ataylor/dev/groovybug/testcase.groovy' At line 13 column 23 

 The test case: 

  
      class  Foo {
         String  getAt( int  i) {
             "0" 
        }
    }
    @groovy.transform.CompileStatic
     class  Bar {
        def bug() {
            def foo =  new  Foo()
            def bar = [ "bar" ]

             for  (i in 1..2) {
                bar[i] = foo[i]
            }
        }
    }
Discussion
- On the mailing-list, someone mentioned that using an Integer as index for the getAt signature makes things work, as a workaround till this problem is fixed.
