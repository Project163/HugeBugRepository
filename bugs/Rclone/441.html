Title

Not saved random generated password in config for "crypt"

Description
## What is the problem you are having with rclone?
In version v1.49.0, configure crypt remote password is not working with randomly generate password, manual password is correct. In saved conf file, password obscure's IV (16 bytes) are saved but nothing followed, so it treated null password / salt. It seems be working correctly crypt remote but its password is null. In display, random generated password is shown but is not saved and gone.

## Version
v1.49.0 is not working, v1.48.0 is correctly woking.
