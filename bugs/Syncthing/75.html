Title

Information in WebGUI not displayed properly (Repository Name Limitation)

Description
Bug:
- If you have a period (“.”) in the repository name then then the detailed repository information is inaccessible

Reproducing the bug:
1. download the latest version of Syncthing and start the app
2. create a node with a period in its name (“1F4.Test”)
3. in the left column try clicking on its name (folder path)

Expected Result:
- Additional repository related information will expand form the proper heading

Current Result:
- Nothing Happens

Speculation:
 -I think the affected code would be either java-script or CSS, likely in the portion of the code that is responsible for showing and hiding information. 
## 

Other non bug related information:
I setup synching back around v8.6-8, I share information between 3 Desktops, 1 Laptop and 1 RaspberryPi using multiple repositories. I mainly use Syncthing to share between my personal computers, a few shares for friends/family.

I use a 3 character prefix for all my repositories for the following reasons, [ex 1F4.Test]
- represents the repository owner
- prevents common name collisions between synching networks such as sync or documents
