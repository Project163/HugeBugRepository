Title

FormHelper error message options not used

Description
This is a (multiple allowed):
- [x] bug
- [ ] enhancement
- [ ] feature-discussion (RFC)
- CakePHP Version: detected on 3.0.18, master also has it.
- Platform and Target: not relevant
### What you did

I have a field "vat_number" which returns a validation message that contains HTML I don't want to be escaped, so I write:
` Form->input('vat_number', ['error' => ['escape' => false]]) ?>`
It keeps escaping the HTML, but if I write directly:
` Form->error('vat_number',null,['escape' => false]) ?>`
... it works.
### Expected Behavior

Validation message is not escaped when you set the options from the input function of FormHelper.
### Actual Behavior

It keeps escaping the message.
### Fix proposed

The fix is to change FormHelper 'cause it's not passing the parameters in the right order to the "error" function. Also if the "error" option is not passed it should be converted to an empty array.

```
...
        if ($options['type'] !== 'hidden' && $options['error'] !== false) {
            $options['error'] = isset($options['error']) ? $options['error'] : [];
            $error = $this->error($fieldName, null, $options['error']);
            $errorSuffix = empty($error) ? '' : 'Error';
            unset($options['error']);
        }
...
```
