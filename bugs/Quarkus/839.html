Title

Logging issues with log4j2-jboss-logmanager

Description
**Describe the bug**
When using the **log4j2-jboss-logmanager**, logs are not printed when running tests.
Furthermore, when using a log4j logger next to a jboss logger, a stack trace is reported "Maximum number of attachments exceeded".

**Expected behavior**
I would expect logs to be printed during tests.
I would also expect the runner jar to start when using log4j + jboss loggers.

**To Reproduce**

A reproducer could be found at [URL]
Steps to reproduce the behavior:
1. mvn clean package
2. => NO logs are issued to console during tests (while they are when using the runner jar)
3. Uncomment the two jboss logger related lines in HelloResource.java
4. mvn clean package
5. Still no logs are issued during tests
