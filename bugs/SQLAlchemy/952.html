Using the code you provided in the original post
If i print order_items where selectable=pjoin and **flat=True**
i get the following output:
```
SELECT "order".id AS order_id, "order".user_id AS order_user_id 
FROM "order" JOIN (SELECT order_test_item.order_id AS order_id, order_test_item.test_id AS test_id, 'order_test_item' AS type 
FROM order_test_item) AS pjoin_1 ON "order".id = pjoin.order_id
```


If i print order_items where selectable=pjoin and **flat=False**
```
SELECT "order".id AS order_id, "order".user_id AS order_user_id 
FROM "order" JOIN (SELECT order_test_item.order_id AS order_id, order_test_item.test_id AS test_id, 'order_test_item' AS type 
FROM order_test_item) AS pjoin ON "order".id = pjoin.order_id
```
The alias in the first case is pjoin_1 and in the second case (where flat=False) it is pjoin.

Currently in the source code for with_polymorphic(), if flat=True then the following condition is ran:
```
if aliased or flat:
    selectable = selectable._anonymous_fromclause(flat=flat)
```
This returns an Alias object that generates an anonymous name because the default argument for name is None. This causes the anonymous name pjoin_1 to override the initial selectable name "pjoin". Which breaks the code.

If I amend the code for with_polymorphic() to something like the below. It works even if flat=True
```
if aliased or flat:
    if selectable is not None:
        name = selectable.name
        selectable = selectable._anonymous_fromclause(name=name, flat=flat)
    else:
        selectable = selectable._anonymous_fromclause(flat=flat)
```
