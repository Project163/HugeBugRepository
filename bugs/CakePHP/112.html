Title

3.0 - Fix composer autoloader for plugin

Description
After [URL] automatic class loading for plugins does not work anymore. The reason is that this rule was made ineffective: [URL]

One solution would be to make `cake bake plugin` modify the composer.json from the app to include the autoloader rules for the newly baked plugin.
Discussion
- Alternatively we could offer to create the plugins composer.json and update the app composer.json to require it.
- The original intention was to not require people using 'first-party' plugins to update their composer.json and re-generate an autoloader.
