Title

pyreverse crashes on dataclasses

Description
### Steps to reproduce
1. Create a module that has a dataclass:
    ```
python
    from dataclasses import dataclass

    @dataclass
    class InventoryItem:
... [Log Snipped] ...
        def total_cost(self) -> float:
            return self.unit_price * self.quantity_on_hand
```
    Note: this is an example from the offical [Link: python docs].

2. Run `pyreverse` against that module.

### Current behavior
`pyreverse` crashes with the following traceback:
```
parsing tests/test_simple.py...
Traceback (most recent call last):
  File "/home/enkidulan/.cache/pypoetry/virtualenvs/pylintdev-py3.7/bin/pyreverse", line 7, in  
    exec(compile(f.read(), __file__, 'exec'))
  File "/home/enkidulan/projects/pylint/pylint/bin/pyreverse", line 4, in  
... [Log Snipped] ...
    current = set(parent.instance_attrs_type[node.attrname])
AttributeError: 'Unknown' object has no attribute 'attrname'
```

### Expected behavior
`pyreverse` exits with 0 code and produces `classes.dot` file that looks something like this:
```bash
digraph "classes" {
charset="utf-8"
rankdir=BT
"0" [label="{InventoryItem|name\lquantity_on_hand : int\lunit_price\l|total_cost()\l}", shape="record"];
}
```
