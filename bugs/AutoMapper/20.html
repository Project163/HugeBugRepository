Title

Automatically-mapped Properties are now case sensitive

Description
I'm not sure if this is an intentional change, as I could find no mention of it in the 4.1.0 release notes or the titles of the fixed issues, but automatically mapped properties are now case sensitive.  The following code worked in 4.0.4, but fails in 4.1.0:

```
[TestClass]
public class UnitTest1
{
    [TestMethod]
    public void TestMethod1()
... [Log Snipped] ...
    }
}
```

- It's used so that if you have foo_bar in one class map to a class with foobar and FooBar, it will pick FooBar consistantly instead of foobar or FooBar based on the position of the property in the code.

```
var asExpando = value as ExpandoObject;
```
