Title

issue: isDirty flips to true when used as dependency in useEffect and default value is null

Description
### Version Number

7.39.7

### Codesandbox/Expo snack

[URL]

### Steps to reproduce

1. Open codesandbox and observe initial values for Touched and Dirty are empty and isDirty is false in the console. Note different default values have been set for each fields: null and empty string. `useEffect` has been set up with `isDirty` as a dependency.
2. Gain focus on `null default` field via tab or click.
3. Lose focus on the field.
4. Observe `isDirty` has been flipped to true however Dirty still reports an empty array.
5. Refresh the page in codesandbox and verify inital state looks like described in step 1.
6. Gain focus on `empty string default` field via tab or click.
7. Lose focus on the field.
8. Observe no additional logging because `isDirty` remains false has not triggered `useEffect`.


### Expected behaviour

`isDirty` should not change its value if the user has touched the field, but not input any values regardless of the default value.
