Title

remove hive.server2.thrift.http.min/max.worker.threads properties

Description
PROBLEM: 
Those properties are not used even when hiveserver2 in http mode. The properties used are hive.server2.thrift.min/max.worker.threads. 
Remove those 2 properties as they are causing confusion.
Discussion
- Were they ever used?  They've been in the code since 0.12.0 and they're documented in Configuration Properties too: 

 
	  hive.server2.thrift.http.min.worker.threads   
	  hive.server2.thrift.http.max.worker.threads   
 

 I recommend removing them from Setting Up HiveServer2 but keeping them in Configuration Properties with a "removed" flag and an explanation that they were never useful (if that's the case).
- leftylev  Thanks for pointing this out. I looked at the code base and  these parameters were used until   HIVE-7935   was checked in. So we should rather mark them as deprecated since 0.14.0 than removing them all together.
