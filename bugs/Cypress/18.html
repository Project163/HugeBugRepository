Title

Cypress fails to set cookies in headed GUI mode when expirationDate is in the past

Description
Chrome Automation API performs an undocumented / unexpected behavior when cookie props are set with an `expirationDate` in the past.

Due to this our code assumes something failed, and passes up a `undefined` error which then causes the extension to crash and the error is swallowed entirely.

This ends up causing `cy.visit` to timeout unexpectedly with no errors.
