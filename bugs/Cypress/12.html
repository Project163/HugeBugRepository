Title

Fixture files fail with non-standard characters

Description
```
js
...
  .fixture('test').as('fxTest')
  .route(/some\/route/, function() {
    return {
... [Log Snipped] ...
  })
...
```

where test.json is:

``` json
[
  {
    "test": "We’ll"
  }
]
```

The right-single quote character code 8217 makes the route fail.
There are no errors except a red `-` under the routes table for the test.
Discussion
- This is due to not properly `encodeURI` values set in XHR headers.
- Fixed in [Link: `0.16.3`].
