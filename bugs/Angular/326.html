AOT (AngularFire) broken in 2.3.0

**Current behavior**

In 2.3.0 in AOT mode, my AngularFire application cannot inject `AngularFireDatabase` from a service. The generated DI code is:

```
get _DbService_36():import20.DbService {
    if ((this.__DbService_36 == null)) { (this.__DbService_36 = new import20.DbService(this.parent.get(import29.AngularFireDatabase))); }
    return this.__DbService_36;
  }
```

`this.parent.get` is incorrect here, as `AngularFireDatabase` is available at this level.

**Expected behavior**

It works in 2.2.x.

**Minimal reproduction of the problem with instructions**

This repro trivially reproduces the issue: [URL] `npm run build` builds the app in AOT mode with rollup, then `app.js` and `index.html` in the root can be served. AOT code is generated in `ngfactory/`.
