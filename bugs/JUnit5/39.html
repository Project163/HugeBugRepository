Title

JUnitPlatformTestTree does not add dynamic containers to test plan

Description
I'm trying to register dynamic tests in a hierarchy but when I run from my IDE via `RunWith(JUnit5.class)` I get `org.junit.gen5.commons.util.PreconditionViolationException: No TestIdentifier with unique ID [$uniqueId] has been added to this TestPlan`.

I've put together a `DemoTestEngine` to reproduce the issue which you can simply run via your IDE like you'd run any JUnit 4 test after registering it as a test engine.

From a quick look at the code it appears that `JUnit5RunnerListener` does not add dynamic containers to its test plan so creating a hierarchy of dynamic tests causes the precondition to fail.

Discussion
- Thanks for raising the issue.

Your analysis is correct: it is not currently possible to add a dynamic `TestDescriptor` for a _container_. 

Your example engine is based on an older version of the code base. `JUnit5RunnerListener` is now `JUnitPlatformRunnerListener`.

In any case, the actual problem is in `JUnitPlatformTestTree.addDynamicDescription()`, and I will soon be committing a fix for that.
- If you want to continue your work against the current state of `master`, the following updated version of your demo engine will work (once I submit the fix).
