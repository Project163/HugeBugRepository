Title

renderAs() duplicates folder name ajax/json

Description
This is a (multiple allowed):

* [x] bug


* CakePHP Version: 3.4.3
* Platform and Target: Linux, PHP 7.0.19-1 (Debian)

### What you did
on ajax-only action i'm calling 
```php
if (!$this->request->is('ajax')) {
    throw new NotFoundException();
}
$this->RequestHandler->renderAs($this, 'json');
```

### What happened
Two types of errors can be seen in logs/error.log
```
Error: [Cake\View\Exception\MissingTemplateException] Template file "Pages/json/json/my_ajax_action.ctp" is missing 
Error: [Cake\View\Exception\MissingTemplateException] Template file "Pages/ajax/json/my_ajax_action.ctp" is missing
```
### What you expected to happen
Expected CakePHP to correctly address existing template in path `Pages/json/my_ajax_action.ctp`

Duplication occurs when request is already recognized as ajax/json one by framework, and calling `renderAs()` adds another directory level to already established template path
