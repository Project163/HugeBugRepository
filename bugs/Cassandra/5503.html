- ���I have a patch ready for review here:  [URL] This fixes the issue for dropping columns as well as adding them, which would also throw validation errors. 

 Dropped columns are handled by checking that the columns we're serializing and the header columns are actually equal, not just the same length, and ignoring situations where we have a column not specified by the read command. 

 Added columns are handled by returning placeholder columns when deserializing columns instead of throwing an exception. We will throw an exception if we attempt to deserialize any data with a placeholder column.
