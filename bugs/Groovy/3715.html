Discussion
- RetentionPolicy.SOURCE  is the JVM default.  Is the retention policy also dropped for  CLASS  or  RUNTIME ?
- RetentionPolicy.SOURCE is the JVM's default.  RetentionPolicy.CLASS and RetentionPolicy.RUNTIME are written to the annotation class file.
- ... [Middle Discussions Snipped for Brevity] ...
- And using a Groovy annotation with source retention annotation seems to default to CLASS as per the JLS, so it seems like it is needed: 
  
 
@JavaSourceRetentionAnno
@GroovySourceRetentionAnno
 class  UseAnno { }
 
  
 results in javap output like: 
  
 SourceFile: "UseAnno.groovy"
RuntimeInvisibleAnnotations:
  0: #8()
    GroovySourceRetentionAnno
 
  
 We could arguably leave it out for the CLASS case but I am inclined to follow  javac  also in that case.
- Behavior should be the same as in Java now. Thanks for spotting the issue.
