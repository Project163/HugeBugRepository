Title

IllegalAccessError trying to run UberJar when public class C extends public class B extends package class A

Description
My class inheritance looks like this:

class Apackage.A
public class Apackage.B extends A
public class Bpackage.C extends B

This has been working up to now with Wildfly/Thorntail, etc.
When trying to run an UberJar quarkus built, I'm getting:

java.lang.IllegalAccessError: tried to access class A from class C_Bean

I couldn't find any good documentation on transitive class access though, so maybe this is not a bug as such. Also have no idea how C_Bean comes into life (presumably already including all of B's funtionality, therefore stripping access to B and directly accessing A?)

I cannot easily change Apackage.A to have public access as that comes from a library.
