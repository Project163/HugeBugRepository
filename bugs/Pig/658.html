Title

Dereference partial name failed

Description
The following script fail: 
  
 a = load  '1.txt'  as (a0: int , a1);
b = group a by a0;
c = foreach b generate flatten(a);
d = cogroup c by (a0);
e = foreach d generate c.a0 as e0;
f = foreach e generate e0;
describe f;
