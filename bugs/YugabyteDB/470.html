Title

[YSQL] Enum types use unsupported scan method internally

Description
Jira Link: [Link: DB-1980]
`systable_beginscan_ordered` method is not formally supported in Yugabyte as there is no native implementation.
Internally it will use the ybc access method so things may work in most cases, but we should either avoid using it, or implement it to directly call ybc methods (e.g. like `systable_beginscan`).
Currently the main place where this is used is in `enum.c` for enum types.
Other places where this is used are not supported in YSQL yet:
* toast types (`tuptoaster.c`)
* large objects (`inv_api.c`)
* text search (`ts_cache.c`)
