Title

Description
I recently installed and configured Syncthing to sync files across multiple devices. It seemed to work on some folders, but then I ran into an issue or maybe even 2 different issues.

There's one folder X shared from device A (Home PC) to device B (Brix).
The current issue is:
1. Device B shows (in syncthing UI) that it's "Up to Date" with device A.
2. Device B shows local state different from global state for the folder X. Both device A and device B show the same global state (which is expected).
3. Device A shows "syncing" with device B, but nothing really happens.
4. Device A shows some "Out of Sync Items" - I randomly checked 4-5 files on device B - they exist there. But the total folder sizes are different on device A and device B (the latter is smaller).
