Title

Active Record Calculations on Enum breaking change in 6.1.3

Description
In Rails 6.0.3 an ActiveRecord calculation on an enum field stored in a Model would result in an integer value.  In 6.1.3, it results instead in a string.  This breaks existing code.
### Steps to reproduce
Define a model like this:
```
class UserRole  
UserRole.maximum(:role) #results in integer
UserRole.roles(:guest) #results in integer
# So, we can check if any UserRole are higher than guest
if UserRole.maximum(:role)  > UserRole.roles(:guest) ...
```
### Actual behavior
```
#Rails 6.1.3
UserRole.maximum(:role) #results in string !!!
# So comparison throws an error
if UserRole.maximum(:role)  > UserRole.roles(:guest) ...
ArgumentError (comparison of String with 5 failed)
```


### System configuration
**Rails version**: 6.1.3

**Ruby version**: 2.6.6
