Title

WebGPUAttributes: Improper 4-byte alignment computation.

Description
I just noticed this:

[URL]

This doesn't yield a new size with 4 byte alignment ( for example 5 + (5%4) = 6) Usually you would do

```
 size = size + (4-size%4);
```

but again, this is wrong when size is already mod 4 = 0, so probably what you want to use is

```
size = size + (4-size%4) % 4;
```
Discussion
- Good catch! How about:
```
let size = array.byteLength;
size = size + ( 4 - ( size % 4 ) ) % 4;  // ensure 4 byte alignment, see #20441
```
Would you like to make a PR with the change?
- BTW: This bug does not affect current demos 😇 .
