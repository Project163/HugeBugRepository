Title

Need to limit the length of Pig counter names

Description
Some version of Hadoop now restrict the length of the names for the counters. Pig counters (e.g. multi-input/multi-output counters) needs to take this into account so that Pig can correctly retrieve its counters.
Discussion
- Attaching patch that limits the string size of the Pig counter name to less than 64 characters.
