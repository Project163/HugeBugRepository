Title

starargs result in no-value-for-parameter

Description
Originally reported by: **Alexey Kotlyarov (BitBucket: [Link: koterpillar], GitHub: @koterpillar?)**

---

The following code:

``` python
def foo(one, two, three):
    pass

def bar(*args):
    foo(*args)
```

Produces:

```
E:  6, 4: No value for argument 'one' in function call (no-value-for-parameter)
E:  6, 4: No value for argument 'two' in function call (no-value-for-parameter)
E:  6, 4: No value for argument 'three' in function call (no-value-for-parameter)
```

If `**kwargs` are added to the signature and `foo` call in `bar`, the warning disappears. The following also hides the warning:

``` python
def bar(*args):
    foo(*args, **{})
```

Therefore calling without `kwargs` should also work IMO.
