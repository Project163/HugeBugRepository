Title

Rendering: Email addresses don't start with a special char (do they?)

Description
### Description

Related to [URL]

Email addresses can only start with an alphanumeric character. Hence these are not valid email addresses:

```
?a@example.com
~a@example.com
*a@example.com
~a@example.com
```

However, Gitea renders them as such:

[Image: screenshot_2023-10-30-202802]

The `mailto` link should only start at the `a`. GitHub handles this correctly:

?a@example.com
~a@example.com
*a@example.com
~a@example.com
