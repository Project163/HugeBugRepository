Title

Interpreter Binding menu of note only shows default interpreter

Description
In latest master branch (0.9.0-SNAPSHOT) the interpreter binding menu of a note doesn't list any other interpreter but the default one. 

 When creating a note I can select between various interpreters.  

     

   

 However in the interpreter binding menu of the note only the default interpreter is shown. 

     

 Our endusers in < 0.9.0 are used to only define %pyspark in every paragraph and adjust the desired default interpreter in the binding menu at runtime from time to time. (e.g. select Spark Interpreter with different sizing). This isn't possible anymore in 0.9.0.
