Title

HttpContentCompressor compresses compressed content

Description
`HttpContentCompressor` compresses the content of the outbound HTTP message even if it's compressed already.  The expected behavior is send the outbound message in verbatim if `Content-Encoding` header is set to a value that is not equal to `identity`.

To fix issue, the signature of `HttpContentEncoder.newContentEncoder()` must be changed due to its design flaw.
