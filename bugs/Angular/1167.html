Title

Deependancy Injection it is possible to inject ViewRef and EmbeddedViewRef

Description
# 🐞 bug report

### Affected Package
 
  The issue is caused by package @angular/9.0.7


### Is this a regression?

 
  Yes, the previous version in which this bug was not present was: 9.0.7 Ivy disabled


### Description

  In Ivy you can inject ViewRef and EmbeddedViewRef in component/directive constructor, this was not possible in VE. I don't know if you consider this bug or I can rely on this behaviour?
