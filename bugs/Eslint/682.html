Title

brace-style for object literal in if-else

Description
Here's the code I'm linting:

```
function f() {
    if (true)
        return {x: 1}
    else {
        var y = 2
        return y
    }
}
```

Here's my package.json:

```
{
    "scripts": {
        "lint": "eslint src"
    },
    "devDependencies": {
... [Log Snipped] ...
    }
}
```

I get the following output:

```
/home/andy/git/ESLINT/src/foo.js
  4:7  warning  Closing curly brace does not appear on the same line as the subsequent block  brace-style
```

This shouldn't be considered an error because the closing brace is for the object literal, not for `if`.
Discussion
- Confirmed. This appears to be a problem only when there's no semicolon before the `else`
- This might behave correctly with `acorn`.
- I'm not sure that's true. I think the rule is just looking at the token before `else`
