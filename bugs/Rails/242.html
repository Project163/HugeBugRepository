- Also, not sure if it's related to the issue you're seeing but if you don't have replicas, you shouldn't create connections for them. You're just doubling the number of open connections to your database without the benefit of using replicas.

```
ruby
# application_record.rb
class ApplicationRecord < ActiveRecord::Base
  self.abstract_class = true
