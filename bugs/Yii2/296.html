Title

composite authentication create unnecessary error log if one of the method fails in multiple authentication method

Description
Hi all,
I am also having similar issue..

scenario..

I have 2 authentication method defined in my application
1. http basic
2. http digest

code..

```
'authenticator' => [
                'class' => CompositeAuth::className(),
                'authMethods' => [                    
                    [
                        'class' => 'common\filters\auth\HttpBasicAuth',
... [Log Snipped] ...
                ],
            ],
```

Now when i make curl call from other application which used digest authentication. Now in application whats happened is..
1. try to authenticate using http basic.
   - get authentication error.
   -  send authentication fail header (401)
2. Now again try to authenticate using http digest
   - got authenticated
   - send continue header (100)
   - now application  proceed further.

Now in this case it always generate error and if logger enable then it keep on adding in into log but this is actually not an error.
