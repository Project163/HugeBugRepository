Title

query string handling of query that only contains MUST NOT clauses

Description
If you write a query of the form:

```
-field:term
```

The query will return no results.  The reason is that when we rewrite this to a BooleanQuery, there are no MUST or SHOULD clauses, and this violates a pre-condition of the BooleanQuery.

When I originally ported this from Lucene I thought this was the corresponding behavior.  However, after this issue was raised on the bleve list, I checked Elasticsearch, and I observe different behavior.  Elasticsearch will return the equivalent of all docs except those containing the term.
