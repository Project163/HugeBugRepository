Title

Improper handling of wide characters in conceal

Description
### Neovim version (nvim -v)

NVIM v0.6.0-dev

### Vim (not Nvim) behaves the same?

Yes

### Operating system/version

Windows 10, Ubuntu 20

### Terminal name/version

Windows Terminal, mintty

### $TERM environment variable

vtpcon, screen, xterm-256color

### Installation

github release, nightly ppa

### How to reproduce the issue

`nvim -u NONE`

```vimscript
i👍abc
:call matchadd('Conceal','^.', 999, -1, {'conceal':''})
:set concealcursor=n
:set conceallevel=2
$
```

### Expected behavior

The cursor should be over `c` at the end.

### Actual behavior

Cursor moves one extra column beyond `c` as if there was a trailing space.
