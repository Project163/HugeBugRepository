Title

\Psalm\Internal\Scanner\DocblockParser::parse() mangles the parsed docblock

Description
Since `\Psalm\Internal\Scanner\DocblockParser::parse()` calls `str_replace()` to remove the matched tags, if there are any tags that are substring of previous tags OR for whatever reason one tag's text appears in the description, they will get removed, therefore mangling the parsed description.

Example:

```
php
/**
 * some self-referential desc with " * @return bool
 * " as part of it.
 *
... [Log Snipped] ...
 * @return bool
 */
```

will roundtrip as:

```
php
/**
 * some self-referential desc with "
 * " as part of it.
 *
... [Log Snipped] ...
 * @return bool
 */
```
