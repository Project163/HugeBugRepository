Description
I think it was a some point, but possibly when refactoring we lost that capability.

Discussion
- Should be possible to configure the color, and the color codes should be made public so you can reference them when configuring.
- That's great, I am now able to change the highlight style:

```
searchRequest.Highlight = bleve.NewHighlightWithStyle("ansi")
ff := ansi.NewFragmentFormatter(ansi.Underscore)
bleve.Config.Cache.Highlighters["ansi"].SetFragmentFormatter(ff)
```

Thanks for the rapid fix.
