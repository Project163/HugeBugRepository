Title

WebSocket Encoder has to be explicitly registered for reflection

Description
**Describe the bug**
Using a custom encoder in the native mode fails with a failure on reflective instantiation.
A user needs to use `@RegisterForReflection` to make it work.

**Expected behavior**
I'd expect all encoders and decoders to be registered for reflection automatically

**Actual behavior**
Application fails to instantiate a [custom encoder](https://github.com/michalszynkiewicz/failing-email-service/blob/master/src/main/java/com/example/JsonEncoder.java#L16
) for a [Link: web socket server].

**To Reproduce**
Steps to reproduce the behavior:
1. `git clone [URL]
2. `mvn clean package -Pnative`
3. go with your browser to `[URL]
