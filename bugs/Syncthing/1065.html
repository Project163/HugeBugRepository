Title

Re-synchronization of Large Files different in v2?

Description
### What happened?

I have a large file (several GB) that is synchronized across several devices and changes frequently, but only in very small parts. The majority of the file remains identical.

On v1, the change in change date would trigger syncthing to run through the file, and transfer only the changed parts over the network connection, while seemingly only limited by ssd speed and cpu for how long it takes to update the file.

But now, on v2, it seems to download the entire file every time, no matter how small the changes. This is a major issue since on bad internet connections, this can take hours every time. Is there a setting to adjust this behavior, or is this just v2 being different?

edit: Possibly related to this  change?

Rolling hash detection of shifted data is no longer supported as this
effectively never helped. Instead, scanning and syncing is faster and more
efficient without it.

Possible to add a feature toggle for this one?

v2.0.8
