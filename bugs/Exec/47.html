Title

DefaultExecutor swallows IOException cause instead of propagating it

Description
DefaultExecutor line 372 does: 

  
                 } catch (Exception e) {
                    throw new IOException(e.getMessage());
                }
 
  

 when it may be better to do: 

  
                 } catch (Exception e) {
                    throw new IOException(e.getMessage(), e);
                }
 
  

 This didn't cause any real issues for me - I just came across it as I was browsing the Commons Exec source, in the context of implementing a launch helper (BTW: see  [URL] - would that, once further cleaned-up, potentially be something of any interest to you for integration into Commons Exec?).
