Title

Groovy calls wrong method if there is a static method on an interface

Description
If there is an interface having the static method  foo  and a class  Impl  implementing this interface also having a static method  foo , then calling  Impl.foo()  calls the method on the interface. For an easy self contained example have a look at  [URL]

 This can yield class cast exceptions on Java 8 and from Java 9 build 125 onwards this yields  
  
 java.lang.IncompatibleClassChangeError: Method ... must be InterfaceMethodref constant
 
  
 This verification has been introduced here:  [URL]
