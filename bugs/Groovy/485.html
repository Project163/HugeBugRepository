Title

Endless-loop with nested 'each'

Description
List list = [ 'groovy' ,  'java' ]

Map map = [a: 1, b: 2]

list.each {
    map.keySet().each {Date d ->
        println d
    }
}
 
  

 The script above produces and endless loop (stopped by a StackOverflowError). I guess this should not happen. I would expect the same behavior as when executing solely: 

  
 Map map = [a: 1, b: 2]

map.keySet().each {Date d ->
        println d
 }
 
  

 which stops with an: Caught: groovy.lang.MissingMethodException: ...
Discussion
- Jochen! 

 Could you please have a look. The problem is that ClosureMetaClass choose doCall of outer closure because inner one explicitly declares Date param type and instead of failing we choose doCall of parent. Probably for call and doCall we need to ignore delegates 

 Here is test case for your convenience 

  
  package  groovy.bugs

 class  Groovy2339Bug  extends  GroovyTestCase {

    void testBug () {
        List list = [ 'groovy' ,  'java' ]

        Map map = [a: 1, b: 2]

        list.each {
            map.keySet().each {Date d ->
                println d
            }
        }
    }
}
- fixed by not going to the delegate if a doCall/call method is called
