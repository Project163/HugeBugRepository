Title

Potential NPE in util.introspection.MethodKey

Description
There are two potential NPEs in util.introspection.MethodKey (discovered by Eclipse) 

 isInvocationConvertible 
isStrictInvocationConvertible 

 Both methods check for actual == null, but the check is part of a compound and condition so actual may still be null. 

 The comments suggest that actual should not be null, so the code should either drop the null check entirely or check it properly.
