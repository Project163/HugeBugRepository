Title

Using defaults in URLManager

Description
I'm using Yii 2.0.2 and I have an issue when I use defaults in my rule definition. 
For example:

Following rule works perfectly

``` php
                [
                'pattern' => '[URL]
                'route' => 'site/home'
                ], 
```

When this one returns an error

``` php
                [
                'pattern' => '[URL]
                'route' => 'site/home',
                'defaults' => ['page'=>1],
                ], 
```
