Title

Internal Server error when doing a POST with invalid emails on /v1/user/emails

Description
### Description

While doing some fuzzing using [URL] I discovered an issue for the `/v1/user/emails` endpoint. Doing a POST with an invalid email address results in a 500, rather that something more meaningful.

You can reproduce the issue using (just replace $token with your own token):

`cats replay Test228.json`

Or using the payload:

```json
{
  "emails": [
    "yCUjse4J",
    "yCUjse4J"
  ],
  "catsFuzzyField": "catsFuzzyField"
}
```
[Link: Test228.json.zip]
