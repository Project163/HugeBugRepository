Title

Issue with computed columns and SQL Server 2005 or later

Description
### What steps will reproduce the problem?
I have a table in SQL Server 2014 that has one column that is computed by a function call.
```
create table [user]
(
    ...
    computed_column AS [Link: getValue]
    ...
)
```

With Yii version 2.0.36  (Issues: #13828, #17474) the inserted date is returned by the insert statement using a temporary table and an OUTPUT clause.


### What is the expected result?
The result should not be returned when the table has computed columns with function calls. This was the default behavior before version 2.0.36.
Only the insert statement should be triggered without temporary table.

`INSERT INTO [user] (...) VALUES (...);`

### What do you get instead?

The executed query was something like this:
```
SET NOCOUNT ON;
DECLARE @temporary_inserted TABLE (..., [computed_column] varchar(2) NULL, ...);
INSERT INTO [user] (...) OUTPUT INSERTED.* INTO @temporary_inserted VALUES (...);
SELECT * FROM @temporary_inserted
```
