Title

Fails to proper remove note when interpreter settings are not saved

Description
When first time entering notebook, there's a window to save interpreter bindings for the note. If we want to remove note without specifying the interpreters bindings, the note will be deleted incorrectly, meaning it will disappear from the list of notes but the real removal from the physical storage will fail with NPE.
