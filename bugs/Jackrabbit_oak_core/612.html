Title

Use identifier for jcr:frozenUuid when node is not referenceable

Description
This is a follow up issue to   OAK-999  . The frozen tree in Oak now always uses nt:frozenNodes like in Jackrabbit. The jcr:frozenUuid property for non-referenceable nodes is now set to a dummy (empty string) value. To be spec compliant these nodes should rather use the identifier of the node instead.
