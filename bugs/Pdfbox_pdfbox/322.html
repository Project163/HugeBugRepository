Title

Type 3 Fonts are not processed by PDPage.createImage

Description
PDType3Font does not fetch the correct charprocs entry for a character. 
When that is corrected, one finds that Type3StreamParser is incomplete and cannot process the charprocs stream.
Discussion
- This file contains Type 3 fonts and displays as blank in PDPage.createImage
- Diffs to improve PDPage.createImage provessing of FontType3. These changes make sure the right informatino is available for character painting. What remains is to get the transformation matric and the position of the glyph on the page.
- I added rendering support for type3 fonts in revision 1504498. I didn't apply Freds patch by used it as inspiration on how to implement the whole stuff. 

 As a sideeffect I moved  PDFont#drawString to the PageDrawer class to minimize the AWT-stuff.
