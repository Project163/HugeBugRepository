Title

Thrift compiler will generate wrong code if IDL struct's name is 'a' or 'b'

Description
test.thrift file is as below: 
struct a  
{
 1: string name,
 2: double price
}

 struct b  
{
 1: i8 size,
 2: i32 seq
}

 struct a1  
{
 1: i8 size,
 2: i32 seq
}

 struct a2  
{
 1: i8 size,
 2: i32 seq
}

 When struct is named as 'a' or 'b' will throw compile errors as below:

 ^

 ^~~~

 ^~~~~
