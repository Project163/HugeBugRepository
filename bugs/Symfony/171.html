Title

[Console][5.0] FatalError due to typehint mismatch

Description
**Symfony version(s) affected**: 5.0.2

**Description**  
Adding typehint for interface in [URL] caused inconsistency, resulting in the following fatal error:
```
Fatal error: Declaration of Symfony\Component\Console\Input\Input::getArgument($name) must be compatible with Symfony\Component\Console\Input\InputInterface::getArgument(string $name) in .../vendor/symfony/console/Input/Input.php on line 28
```
I gave a fast look, it looks the problem is with these 2 methods: `getArgument`, `setArgument`.

**Possible Solution**  
I guess we just need to add proper typehints.
