Title

Column sorting broken on web ui console

Description
Sorting columns of queues, topics, and other items on the web ui console in ActiveMQ Classic is no longer available.  This was discovered after upgrading from v6.1.5 to v6.1.7. 

 Sorting columns is a very valuable feature in that it provides quick visual feedback on queue counts and consumer counts.  Sorting on "Number of Pending Messages" and/or "Number of Consumers" allows quick identification of consumers that might be having issues.  This feature is used frequently in my deployments.
