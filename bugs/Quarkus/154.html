Title

Java 11+GraalVM: Kafka Crc32C uses method handle

Description
**Describe the bug**
The `org.apache.kafka.common.utils.Crc32C` class is using a method handle under Java 9+ to access the public constructor of `java.util.zip.CRC32C`; this fails with `native-image`.

Ideally the Kafka library would utilize a multi-release JAR to just call the constructor directly instead of resorting to reflection to solve this issue.  Failing that, we should just do it ourselves using a MR-JAR substitution.
