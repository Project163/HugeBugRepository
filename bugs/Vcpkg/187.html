Title

[qt5] module "QtQuick.Dialogs" is not installed

Description
**Describe the bug**
While #14594 fixed a few bugs related to QML deployment I still get the error
```
QQmlApplicationEngine failed to load component
qrc:/main.qml:4:1: module "QtQuick.Dialogs" is not installed
```
when I do `import QtQuick.Dialogs 1.2` inside a QML file.

**To Reproduce**
Steps to reproduce the behavior:
1. `./vcpkg install qt5`
(`./vcpkg install qt5-declarative` should be enough in this case, but I tested with both to be sure)
2. `import QtQuick.Dialogs 1.2` inside a QML file.
3. Build & run project.

**Expected behavior**
All imports inside a qml file should be deployed to the output folder.

**Additional context**
Inside `{output path to binary}/qml/QtQuick` the Dialogs folder is indeed missing.
