Title

Non-200 responses lack Content-Type: application/json header in v0.5.0-alpha.1

Description
- Expected: all JSON responses have `Content-Type: application/json` header
- Actual: Error responses have Content-Type: text/plain; charset=utf-8

```
sh
$ # with httpie
$ http localhost:4001/v2/keys/does-not-exist/
HTTP/1.1 404 Not Found
Content-Type: text/plain; charset=utf-8
... [Log Snipped] ...
{"errorCode":100,"message":"Key not found","cause":"/does-not-exist","index":26}
* Connection #0 to host localhost left intact
```
Discussion
- error#Error.WriteTo never sets the header to `application/json`: [URL]
- @schmichael This is fixed and tests have been added.
