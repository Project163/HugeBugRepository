Title

Engine finds .NET 4.0 Client Profile twice

Description
When listing AvailableFrameworks, .NET 4.0 Client may be listed twice. This is due to the presence of two different registry keys:
  HKLM\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Client
and
  HKLM\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4.0\Client

We should add a test that makes sure there are no duplicates and fix this.

It's high priority because of the GUI.
