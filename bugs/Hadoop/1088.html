Title

Deadlock while logging tokens

Description
Ran into a deadlock between two threads that were both wielding Tokens.  One was trying to log a token while the other was trying to set the token service on a different token.
Discussion
- Stack traces showing the deadlock.  One thread has the Token class lock and is trying to log a warning, while the other thread has the logger lock and is trying to acquire the Token class lock.
