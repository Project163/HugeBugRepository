Title

segfault when / is read-only

Description
### Neovim version (nvim -v)

NVIM v0.9.0-dev (current master, built with the flake in the contrib dir)

### Vim (not Nvim) behaves the same?

no, vim 9.0.609

### Operating system/version

nixos 22.11

### Terminal name/version

xfce4-terminal version 1.0.4

### $TERM environment variable

xterm-256color

### Installation

the flake in the contrib directory

### How to reproduce the issue

To reproduce, we'll prepare a chroot containing nvim and bind-mount it read only. I do it with nix, I suppose debootstrap also works. 

```
mkdir -p /tmp/chroot/nix/store /tmp/ro
# build nvim
nix build "github:neovim/neovim?dir=contrib" --extra-experimental-features nix-command --extra-experimental-features flakes    
# copy nvim into the chroot
for i in $(nix-store -qR ./result); do cp -r $i /tmp/chroot/nix/store/.; done
... [Log Snipped] ...
# execute nvim
chroot /tmp/ro $(readlink -f result)/bin/nvim
```

### Expected behavior

no segfault

### Actual behavior

```
