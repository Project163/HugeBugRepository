Title

Http Basic Auth doesn't work

Description
### What steps will reproduce the problem?
Http Basic Auth doesn't work if the server uses a special configuration where PHP is not loaded as module...

References
#13654
#18315

### Additional info
In the yii\web\Request::getAuthCredentials()
```
/*
 * Apache with php-cgi does not pass HTTP Basic authentication to PHP by default.
 * To make it work, add the following line to to your .htaccess file:
 *
 * RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]
 */
$auth_token = $this->getHeaders()->get('HTTP_AUTHORIZATION') ?: $this->getHeaders()->get('REDIRECT_HTTP_AUTHORIZATION');
```
**The problem is that HTTP_AUTHORIZATION and REDIRECT_HTTP_AUTHORIZATION are not HEADERS, but environment variables!** 

In the yii\web\Request::getHeaders() HTTP headers parsed by
`getallheaders()`
or
`http_get_request_headers()`
or
custom expression `(strncmp($name, 'HTTP_', 5) === 0)` - will not return REDIRECT_HTTP_AUTHORIZATION as a header.


In the tests/framework/web/RequestTest.php
```
testHttpAuthCredentialsFromHttpAuthorizationHeader()
$request->getHeaders()->set('HTTP_AUTHORIZATION', 'Basic ' . $secret);
$request->getHeaders()->set('REDIRECT_HTTP_AUTHORIZATION', 'Basic ' . $secret);
```
It's not correct to set headers! You must set ENV variables!


### Solution
1. Get auth data from 'Authorization' header not from env vars, replace
```
$auth_token = $this->getHeaders()->get('HTTP_AUTHORIZATION') ?: $this->getHeaders()->get('REDIRECT_HTTP_AUTHORIZATION');
```
with
`$auth_token = $this->getHeaders()->get('Authorization');`

2. Update custom headers parser and add expression for 'REDIRECT_HTTP_' prefix:
`(strncmp($name, 'HTTP_', 5) === 0 || strncmp($name, 'REDIRECT_HTTP_', 14) === 0)`
