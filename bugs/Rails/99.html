Title

Hash preloading fails with multiple associations in Rails 4.1

Description
Preloading using hash syntax fails with multiple associations in Rails 4.1. git bisect points to [Link: this commit] specifically removing preloading of more than 1 association. Since this is working in Rails 4.0.x, I'm wondering if this is a breaking change in Rails 4.1 or a bug.

Reproducible test case:

```
# Activate the gem you are reporting the issue against.
require 'active_record'
require 'minitest/autorun'
require 'logger'

  end
end
```
