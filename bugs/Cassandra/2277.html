- Looks like this is a regression from   CASSANDRA-5555  . 
(I think workaround is to use sstableloader from 1.2.6). 

 Attached unit test for SSTableLoader. if run with 'ant test-compression -Dtest.name=SSTableLoaderTest', it fails as described above.
