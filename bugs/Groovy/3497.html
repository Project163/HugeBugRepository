Title

Static factory method does not compile anymore with 2.5.3 (was ok with 2.4.x)

Description
I just tried to update our codebase from 2.4.15 to 2.5.3. 

 This doesn't compile anymore: 
  
 @groovy.transform.CompileStatic
@groovy.transform.Immutable
class Foo {

   static Foo create(){
      return new Foo()
   }
} 
  
 I get 
  
 ...
> Task :compileTestGroovy
startup failed:
C:\Dev\Foo\src\test\groovy\Foo.groovy: 6: [Static type checking] - Cannot find matching method Foo#<init>(). Please check if the declared type is correct and if the method exists.
 @ line 6, column 10.
     return new Foo()
            ^
1 error
> Task :compileTestGroovy FAILED
...
Discussion
- I think this will only be true for classes with no properties. Still a bug obviously but shouldn't affect (as) many classes. Workaround is to use: 
  
 
@groovy.transform.CompileStatic
@groovy.transform.Immutable
 class  Foo {
    static  Foo create(){
       return   new  Foo([:])
   }
}
