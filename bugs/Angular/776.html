Title

PercentPipe maxFractionDigits default values are wrong/missleading

Description
# 📚 Docs or angular.io bug report

### Description

PercentPipe maxFractionDigits default values are wrong/missleading

## 🔬 Minimal Reproduction
  
{{1.12/100|percent}} - {{1.12/100|percent:'1.0-3'}}
  
Output:
1% - 1.12%

### What's the affected URL?**
[URL]

### Reproduction Steps**
Documentation says:
maxFractionDigits: The maximum number of digits after the decimal point. Default is 3.

Actual value seems to be '0'

### Expected vs Actual Behavior**
This may either be an implementation or documentation issue. I *believe* it is a documentation issue, probably a copy-paste issue from DecimalType, whose actual defaults are '1.0-3'
