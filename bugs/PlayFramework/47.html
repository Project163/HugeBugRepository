### Expected Behavior

`request.flash` should contain data passed using such code
`Home.flashing("success" -> "Computer has been created")`

It worked fine with Play 2.5.x in particular in the Anorm example project
[URL]

How to check:
1. Run project and apply database evolution.
2. Click on "ACE" computer name.
3. Click on "Delete this Computer"

Result:
[Image: good]

### Actual Behavior

The same steps with Anorm example project for Play 2.6.0 (https://example.lightbend.com/v1/download/play-scala-anorm-example) produce such result:

[Image: bad]

The issue is also appears in case of creating seed project using `sbt new playframework/play-scala-seed.g8` and in a controller adding something like `Home.flashing("success" -> "Computer has been created")`. In views the code `request.flash.data.size` always returns 0.

### Reproducible Test Case

Test cases for both Play 2.5.x and 2.6.0 pass correctly. The problem only appears when the project is tested manually in browser.
