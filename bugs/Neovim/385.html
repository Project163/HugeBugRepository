Title

Treesitter 0.19.5 unlimited pending matches makes Neovim unusable when active

Description
- `nvim --version`: `NVIM v0.5.0-dev+1434-g24e0c16fd`

### Steps to reproduce

1. Install `nvim-treesitter`
2. Ensure it is the only plugin installed, and is setup something like:
```
vim.cmd('packadd nvim-treesitter')
require('nvim-treesitter.configs').setup {
    ensure_installed = { 'python' },
    highlight = {
        enable = true,
    },
}
```
3. Update to the latest parsers with `:TSUpdate`/`:TSInstall`
4. Open a large _Python_ buffer (find something in the system `site-packages` with `find / -type d -name 'site-packages' 2>/dev/null` or similar).

Note that this is not reproducible before ` `.

### Actual behavior

Especially notable when there are a lot of lines _below_ the cursor, parsing is un-usably slow and can spike CPU usage by _Neovim_ to 100%, bringing everything to a grinding halt.

### Expected behavior

_Treesitter_ highlighting is usable for _Python_ buffers.
