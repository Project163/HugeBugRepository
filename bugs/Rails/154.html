Title

Can't use enum value in `where` key with `joins` for has_one relation query.

Description
### Steps to reproduce

I wrote following code, but it isn't work.

```
ruby
# bundle exec rails -v
class User   "SELECT \"users\".* FROM \"users\" INNER JOIN \"addresses\" ON \"addresses\".\"user_id\" = \"users\".\"id\" WHERE \"addresses\".\"kind\" = 'home'"
```

But, followin code is work.

```
ruby
class User   "SELECT \"users\".* FROM \"users\" INNER JOIN \"items\" ON \"items\".\"user_id\" = \"users\".\"id\" WHERE \"items\".\"state\" = 0"
```
### Expected behavior

``` ruby
User.joins(:address).where(addresses: {kind: 'home'}).to_sql
  #=> "SELECT \"users\".* FROM \"users\" INNER JOIN \"addresses\" ON \"addresses\".\"user_id\" = \"users\".\"id\" WHERE \"addresses\".\"kind\" = 0"
```
### Actual behavior

``` ruby
User.joins(:address).where(addresses: {kind: 'home'}).to_sql
  #=> "SELECT \"users\".* FROM \"users\" INNER JOIN \"addresses\" ON \"addresses\".\"user_id\" = \"users\".\"id\" WHERE \"addresses\".\"kind\" = 'home'"
```
### System configuration

**Rails version**:Rails 5.1.0.alpha
# 

**Ruby version**:ruby 2.3.1p112 (2016-04-26 revision 54768) [x86_64-darwin15]
