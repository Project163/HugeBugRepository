Title

Reset values ignored when keepDefaultValues is true

Description
**Describe the bug**
If `{ keepDefaultValues: true}` is passed to `reset()` the `values` prop will be ignored.

**To Reproduce**
Steps to reproduce the behavior:

1. Go to [URL]
2. Click on 'Reset with new values & keepDefaultValues = true' button
3. The form's values do not change

**Codesandbox link (Required)**
[URL]

**Expected behavior**
The form is reset with the new values and isDirty = true

**Desktop (please complete the following information):**

- OS: Windows
- Browser: Firefox
- Version: 87

**Additional context**
If I am misunderstanding the intended behaviour should the docs be updated to show that the values prop and keepDefaultValues option are mutually exclusive?
Discussion
- Thanks for the issue report, there are couple of things.

- `defaultValues` is what's populate those native inputs, so when you keeping the `defaultValues` the original value remains unchanged. so alternative
- I think you are better of using `setValue` if you just want to change the values of the input. 
- you should be able to use Controller to achieve this (after the fix) because Controller has its own local state for value, so we can update the value without touching the defaultValues.
