Title

TBase class for C++ Library

Description
Unlike Other languages, C++ is missing a TBase class (the majority of other langugaes call it that) that all generated structs always inherit from. This prevents simple utility functions, and forces ugly template use. 

 Something like this: 

   thtift/TBase.h   
  class  TBase {
 public :
  virtual ~TBase();
  virtual uint32_t read(::apache::thrift::protocol::TProtocol* iprot);
  virtual uint32_t write(::apache::thrift::protocol::TProtocol* oprot)  const ;
}
Discussion
- please remember that in C++ lib in thrift there was a lot of effort put to remove virtual methods in exchange for templates. I'm not really sure if efficiency gain justified those actions, but nevertheless we can't just ignore that. IMHO: TBase should not be added when generating C++ code in template mode.
