Title

Recording rawvideo causes SIGSEGV

Description
## Platform
 
 
Operating system and version: Linux 5.3.0-46-generic #38~18.04.1-Ubuntu SMP Tue Mar 31 04:17:56 UTC 2020 x86_64 x86_64 x86_64 GNU/Linux
OBS Studio version: OBS Studio - 25.0.8 (linux)
Installer: DEB from official PPA

## Expected Behavior

When I set obs to record `rawvideo` to my v4l2loopback device `/dev/video0`, I expect it to do so OR display a meaningful error message.

## Current Behavior

    “obs” terminated by signal SIGSEGV (Address boundary error)

## Steps to Reproduce

_Prerequisites:_ Install v4l2loopback and load the kernel module.

1. Set Recording to Custom Output (FFmpeg) > Output to URL, `/dev/video0`, rawvideo
   
   [Image: image]

2. Press "Start Recording"

I can reproduce the crash also without v4l2loopback, selecting Output to File.
