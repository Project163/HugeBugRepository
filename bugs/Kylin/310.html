Title

Support implicit query of split function

Description

    
Discussion

    
- Problem 

 We defined a computed column cc=split(C_PHONE,' [-] ',2) [1]   on the model, with related indexes ready, implicit query can't hit model 

  
 
 select  split(C_PHONE, '[-]' ,2)[1]  from  ssb.customer;
- Design 

 The result of  " split(C_PHONE,' [-] ',2) " are some items in the view of RexNode. The ExpressionConverter cannot resolve this kind of RexNodes, add the following code to cover this case. 
  
 
 case   "item"  =>
  element_at(k_lit(children.head), k_lit(children.apply(1).asInstanceOf[Int] + 1))
