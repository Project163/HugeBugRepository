Title

[web-sys] yew 0.13 fails to compile

Description
**Problem**
 

I want to update my project from std_web to web_sys.
When trying to build an `empty` (or not) project with the new feature `web_sys`, yew 0.13 does not compile.

**Steps To Reproduce**
Steps to reproduce the behavior:
1. `cargo new --lib project`
2. Cargo.toml
```
yml
[package]
name = "project"
version = "0.1.0"
edition = "2018"
... [Log Snipped] ...
[lib]
crate-type = ["cdylib", "rlib"]
```
3. src/lib.rs
```rust
fn main() {
    println!("Hello, world!");
}
```
4. Run `cargo wasm build` or `wasm-pack build` (it will be the same error with both)
5. See error
```
bash
   Compiling yew v0.13.0
error[E0308]: mismatched types
   --> /home/user/.cargo/registry/src/github.com- /yew-0.13.0/src/virtual_dom/vtext.rs:113:9
    |
... [Log Snipped] ...
To learn more, run the command again with --verbose.
Failed to run cargo. Exit code was: 101
```

**Expected behavior**
I was expecting yew to build, but maybe am I doing something wrong ?

**Environment:**
 - Yew v0.13
 - Rust v1.41.1
 - Target wasm32-unknown-unknown
 - web-sys v0.3.36
 - OS: ubuntu
