Title

The navbar width becomes messed up upon clicking on my profile picture

Description
**Describe the bug**
The overlay seems to be cutting into the navbar.

[Image: image]


**To Reproduce**
Steps to reproduce the behavior:

1. Click profile picture

**Expected behavior**
Navbar to be above overlay.

**Desktop (please complete the following information):**

- OS: Solus (Linux)
- Browser Firefox
- Version 63.0.1
Discussion
- `.menubg` starts too high, it has a top of 40px whereas the `.top-bar` has a height of 48px. A change in this block ought to fix it.

[URL]
- Though personally, rather than having to worry about sizes I would put the model effect over the `page-content`

perhaps something like this

```
CSS
div#page-content::after {
  content: "";
  position: fixed;
  top: 0;
... [Log Snipped] ...
  pointer-events: auto;
}
```
This would mean the whole of `.top-bar` is above the modal backdrop, also anything could use that modal style in the future.

**Side note:** 
I'm using `opacity` and `pointer-events` rather than `display:none` to avoid a repaint.
