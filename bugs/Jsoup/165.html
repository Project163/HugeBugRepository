Title

Default proxy is ignored, when HttpClient is used (jsoup.useHttpClient=true or default from 1.21.1 onward)

Description
HttpClient has a mechanism to get/set a global default proxy with java.net.ProxySelector.getDefault/setDefault. This is used, if no proxy configuration is set at the builder (see jdk.internal.net.http.HttpClientImpl.getDefaultProxySelector()).

HttpClientExecutor uses always ProxyWrap for the HttpClient builder, so the JDK HttpClient default is not used. But its implementation does not consider ProxySelector.getDefault.

So the select method of ProxyWrap should look like this:

```
@Override
    public List  select(URI uri) {
        Proxy proxy = perRequestProxy.get();
        if (proxy != null) {
            return Collections.singletonList(proxy);
... [Log Snipped] ...
        return NoProxy;
    }
```

        if (defaultSelector != null) {
            defaultSelector.connectFailed(uri, sa, ioe);
        }
    }
