Title

Docker provisioner doesn't allow provisioning when container name is specified

Description
When I run `vagrant provision` on my Vagrantfile which runs docker provisioner, docker raises an error saying the container name already exists. 

When taking a look at the [Link: source code], it looks like it’s failing on `container_exists?` call - which calls `lookup_container` and tries to create a new one every time.  I tried the bash command that it tries to call - one of the flags is using `-notrunc`, which has changed to `—no-trunc` and I’m suspecting that’s why it’s failing.
