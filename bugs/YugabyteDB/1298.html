Title

[YSQL] INSERT ON CONFLICT batching RETURNING garbage

Description
Jira Link: [Link: DB-15132]
### Description

With INSERT ON CONFLICT read batching enabled and a RETURNING clause that returns non-ptr types such as text, the memory that it's pointing to gets invalidated so that the return output is garbage.  The data inserted is fine at least.

```sql
SET yb_insert_on_conflict_read_batch_size = 1024;
create table texts (i int, t text, unique (t));
insert into texts values (1, 'hello world') on conflict do nothing returning *;
```

causes, for example,

```

---+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
------------------------------------------------------------------------
```
