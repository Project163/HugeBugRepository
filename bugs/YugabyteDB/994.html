Title

[DocDB] IntentsDB debug page not working with packed rows

Description
Jira Link: [Link: DB-6780]
### Description

The tserver admin UI includes a route at localhost:9000/intentsdb which dumps intentsdb contents in debug builds, with flag `enable_intentsdb_page=true`. However, navigating to this route causes a CHECK failure if there are packed rows in intentsdb

```
Fatal failure details written to /Users/rob/yugabyte-data/node-1/disk-1/yb-data/tserver/logs/yb-tserver.FATAL.details.2023-06-01T16_49_49.pid2010.txt
F20230601 16:49:49 ../../src/yb/dockv/schema_packing.cc:219] Check failed: _s.ok() Bad status: Not found (yb/dockv/schema_packing.cc:216): Schema packing not found: 0, a
vailable_versions: []
    @           google::LogDestination::LogToSinks()
    @           google::LogMessage::SendToLog()
... [Log Snipped] ...
    @           yb::Webserver::Impl::RunPathHandler()
    @           yb::Webserver::Impl::BeginRequestCallback()
```

Initializing the cluster with an additional flag `ysql_enable_packed_row=false` resolves the issue
