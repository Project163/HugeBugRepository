Ivy + @Component.host + async pipe binding - Unexpected Node Error (Ivy Only)

# 🐞 bug report

### Affected Package
@angular/compiler

### Is this a regression?

### Description
If I use a @Component.host style binding with an Async pipe, the Ivy compiler gets very very angry with me.  This works just fine in VE mode.

```

import { of } from 'rxjs';

  selector: 'hello',
```
