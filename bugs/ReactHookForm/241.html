Title

V7 - Watch + Controlled Field Array bug: unable to append or copy multiselect (array) values within a watch-controlled field array

Description
**Describe the bug**

Field array multi-select values cannot be appended to or copied effectively.

**Codesandbox link (Required)**
[URL]

**To Reproduce**
Steps to reproduce the behavior:

1. Hit the add button
2. Select "two"
3. Hit "copy"
4. Hit "add"
5. Hit submit

In the alert, notice the actual output:
```
json
{
  "myFieldArray": [
    {
      "mySelect": [
... [Log Snipped] ...
  ]
}
```

Which differs from the expected output:
```
json
{
  "myFieldArray": [
    {
      "mySelect": [
... [Log Snipped] ...
  ]
}
```

**Expected behavior**
Using the array mutators will preserve these multiselect values rather than splitting them up into single-character strings

**Desktop (please complete the following information):**

- OS: Linux Mint
- Browser: Firefox
- Version 87.0b9 (64-bit)
Discussion
- This may be a docs issue -- I followed the controlled field array docs, and I think the `watch` is the root of the problem here
- Confirmed -- switching from `watch` to `useWatch` solves this problem. I'll leave this to the maintainers to close though, since the current docs use `watch` and this is likely a `watch` bug.
