Title

Compaction Stats updater does not collect column stats when hive.stats.autogather is true

Description
To reproduce the issue add a test to  TestCrudCompactorOnTez.java  
  
 
   private   static   String  TABLE1 =  "t1" ;

  @Test
   public  void testMajorCompaction()  throws  Exception {
    executeStatementOnDriver( "create table "  + TABLE1 +  "(a  int , b varchar(128), c  float ) stored as orc TBLPROPERTIES ( 'transactional' = ' true ' )" , driver);
    executeStatementOnDriver( "insert into "  + TABLE1 +  "(a, b, c) values (1,  'one' , 1.1)" , driver);
    executeStatementOnDriver( "insert into "  + TABLE1 +  "(a, b, c) values (2,  'two' , 2.2)" , driver);

    executeStatementOnDriver( "delete from "  + TABLE1 +  " where a = 1" , driver);

    CompactorTestUtil.runCompaction(conf,  " default " ,  TABLE1 , CompactionType.MAJOR,  true );
    CompactorTestUtil.runCleaner(conf);
    verifySuccessfulCompaction(1);

    List< String > result = execSelectAndDumpData( "describe formatted "  + TABLE1, driver, "");
 
  
 In the  results  array the string 
  
 
	COLUMN_STATS_ACCURATE	{\ "BASIC_STATS\" :\ " true \" }
 
  
 shows that only basic stats are accurate. 
The delete operation made the column stats stale and the stats updater running after compactor didn't collected the column stats because  hive.stats.autogather  is true:
