Title

[Quarkus 3.0.0.CR2] [quarkus-mailer] NullPointerException when sending with MailTemplateInstance

Description
### Description
Hello,
when sending an email with:

     @CheckedTemplate
     static class Templates {
         public static native MailTemplate.MailTemplateInstance mailTemplate(String something);
     }

via

`Templates.mailTemplate("This is an email").to("test@email.org").subject("Something happened").send()`

in a Resteasy Reactive resource I get a NullPointerException. It seems that no mailer gets injected.
