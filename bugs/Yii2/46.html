Title

GII crud generator should not allow equal names for model and search model classes

Description
Using the same name for model class and search model class (even in different directories) leads to the following error message calling the generated controller:

Cannot use app\models\search\Kontoplan as Kontoplan because the name is already in use

The use statements are generated properly to point to different directories but the class names are the same.

I suggest to check that the names are not equal or to follow some naming conventions.
