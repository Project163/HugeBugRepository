## Current behavior
Remove item from FormArray, and then submit the form causes the exception:
```
ERROR TypeError: Cannot read property 'updateOn' of null
    at eval (VM1742 forms.umd.js:2519)
    at Array.forEach ( )
    at syncPendingControls (VM1742 forms.umd.js:2517)
    at FormGroupDirective.onSubmit (VM1742 forms.umd.js:6806)
... [Log Snipped] ...
    at ZoneDelegate.invokeTask (VM1692 zone.js:274)
    at Zone.runTask (VM1692 zone.js:151)
```

For removing item I use `removeAt` on FormArray object:
```
  onDelete(index) { 
    this.secretLairs.removeAt(index);
  }
```

Reproduces in Angular 5, but worked in previous release (angular 4)

## Expected behavior
No exception is thrown after removing item, form successfully submitted


## Minimal reproduction of the problem with instructions
The repro example can be found here:
[URL]

Steps to reproduce:
1. Select `Whirlwind` hero 
2. Press `Del` button under the `Address #1`
3. Press `Save`
4. Press `Del` button under the `Address #1` one more time
5. Press `Save`
6. Exception was thrown

## What is the motivation / use case for changing the behavior?
 
It worked in angular 4, and in new 5th version the functionality of removing items from FormArray is broken.
