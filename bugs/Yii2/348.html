Title

Formatter - Date and timezone issue

Description
There is a issue in formatter where returned formatted date has a wrong value.

Prerequisite: current date in UTC and your local timezone should be different.

Code example:
`echo Yii::$app->formatter->asDate('2014-10-09', 'php:Y-m-d');`

Expected result is: `2014-10-09`
Real result is: `2014-10-10`

Problem is in formatter as it assumes the input date was in UTC timezone and then formats it in the local timezone (or whatever you have set in your app). This may be the correct way to handle it in some cases but for example in DatePicker widget it's definitely not.
