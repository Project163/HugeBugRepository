Title

-1: Access to java.lang.Object#myField is forbidden @ line -1, column -1.

Description
Please advise with that problematic code (note it is working on 2.4.15 perfectly but not on 2.5.8): 
  
 
 public   class  MyClass {
   public   boolean  myField
}

MyClass myClass =  new  MyClass()
List list =  new  ArrayList()
list.each {
    myClass.myField = myClass.myField  // BOOM!!!
 }

Discussion
- A casting to the class somehow workarounds the issue: 
  
 
list.each {
    myClass.myField = ((MyClass) myClass).myField
}
- It works with groovy 3.0.0-beta-3. I think some fixes are not merged into 2_5_X branch, because they are very hard to merge...
- ... [Middle Discussions Snipped for Brevity] ...
- Will that be fixed in 2.5.9?
- The following example works in 3.0.0-rc-1 and works on the GROOVY_2_5_X branch so will work in 2.5.9 and above as per the fix versions: 
  
 
 class  MyClass {
   public   boolean  myField
}
@groovy.transform.CompileStatic
def method() {
  MyClass myClass =  new  MyClass()
  [].each {
    myClass.myField = myClass.myField  // BOOM!!!
   }
}
 
  
 We have no exact date scheduled for 2.5.9 but I expect in the next 1-4 weeks.
