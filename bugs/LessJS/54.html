Title

@import adds .less onto parameters and can cause import loops

Description
Noticed while I was integrating that less.js was reimporting the same file over and over. Issue was caused by a jsp sessionId being attached to the end of the original less file's url

example.com/main.less imports sub.less

but its really
example.com/main.less;jsessionid=1234
which less turns into
example.com/main.less;jsessionid=sub.less to import

possibly find a safer replacement mechanism?
Discussion
- But it's supposed to be correct behavior, ? used for query strings, ; - seems like custom routing..
- for browser only, instead of saying endsWith(".less") it should interpret the url and work out the resource name? or like #823 have a flag to import everything as less.

Its a tricky comprimise.
