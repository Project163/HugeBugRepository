Title

[OS X + IPv6]: Unable to communicate with the VM over IPv6 over host-only interfaces

Description
When provisioning an IPv6 host-only interface on OS X, the guest is unable to communicate with the host. This appears to be due to the handling of routes for addresses of the type of `2001:dead:beef::` and that is the address Vagrant chooses for the adapter. The error is `no route to host`, although there appears to be a routing table entry for `2001:dead:beef::/64 dev vboxnetN`. When changing the adapter IP to `2001:dead:beef::1`, the communication proceeds as expected.

I do  not understand the differences between the IPv6 stacks, but on Linux this issues does not manifest.

Given that there is no strong requirement to use ` ::` as the IPv6 address for the adapter, I suggest changing it to ` ::1`, akin to IPv4 configuration.
