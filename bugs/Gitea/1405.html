Title

Invalid output in `batch_reader.go`

Description
`strconv.ParseInt: parsing "number": invalid syntax`

Steps to reproduce:
1. Create a repository with actions enabled
2. Create a file `/.gitea/workflows` with the content `not a number`
3. Create a file `/.github/workflows` with the content `not a number`
4. Open the page `/ / /actions`
5. If no error is shown, refresh the page multiple times until an error occurs

The reason is this code
[URL]

which fails in line 179
[URL]

If the error occurs the code tries to parse `not a number` as output of the batch reader. A normal output looks like `  tree 104`. I don't know how the content of a file can be present here. And even worse is that it does not fail every time. If I create only one `workflows` file it does not fail but that may just be a timing issue.
