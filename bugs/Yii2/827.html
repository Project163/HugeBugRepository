Title

migration generation with prefix

Description
is there a reason why the migration templates (createTableMigration.php, addColumnMigration.php etc.) do not have the table prefix syntax `{{%tablename}}` ?

### What steps will reproduce the problem?
php yii migrate/create add_xxx_column_to_yyy_table --fields="xxx:integer"
### What is the expected result?
```
$this->addColumn('{{%yyy}}', 'xxx', $this->integer());
```
### What do you get instead?
```
$this->addColumn('yyy', 'xxx', $this->integer());
```

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      |  
| PHP version      | 7.2
| Operating system |Windows
Discussion
- There is a switch for enabling prefix in generated migrations.

[URL]

 The question is why it is disabled by default and why we even need it - does adding prefix everywhere has any drawbacks?
- So, can I completely remove $useTablePrefix property from all over the source? And generate table name by next way:
```
protected function generateTableName($tableName)
{
    return '{{%' . $tableName . '}}';
}
```
- I'm for changing default value of `$useTablePrefix` to `true`. We could also mark this property as deprecated, but I'm not sure if it makes any sense.
