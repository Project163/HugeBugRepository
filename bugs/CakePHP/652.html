Title

patchEntities() fails with csrfToken

Description
Hello,

I encounter a persistent error while trying to a apply patchEntities() with request->data containing a csrfToken.

The error is:
errorUnserializable object - InvalidArgumentException. Error: Passed variable is not an array or object, using empty array instead in /home/modulwoo/www/2ndGuideTest/vendor/cakephp/cakephp/src/ORM/Marshaller.php, line 200.

Jose found a workaround adding unset($this->request->data['_csrfToken']); before the call to patchEntities().
