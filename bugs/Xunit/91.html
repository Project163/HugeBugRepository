Title

XunitTestClassRunner - IAsyncLifetime's DisposeAsync and IDisposable's Dispose run in parallel

Description
**Summary:**

When a test class fixture implements both IAsyncLifetime and IDisposable, corresponding Dispose methods are executed in parallel despite the documentation:

```csharp
     ///  
    /// Called when an object is no longer needed. Called just before  
    /// if the class also implements that.
    ///  
    Task DisposeAsync();
```

**Source:**
[URL]

**Workaround**
Just use one or another interface
