Title

Cant specify PluginOne.layout / PluginTwo.layout for emails

Description
I have generic layouts for emails inside Emails plugin.

I have some other plugins that have their own email views so end up with something like

```
SomePlugin.email_view
```

This does not work as it always uses SomePlugin for the layout if there is a plugin defined for the view file [Link: here]

A few lines down it does `$render = $View->render($template, $layout);` which should probably be `$render = $View->render($this->_template, $this->_layout);`

Cake is able to handle rendering views / layouts with Plugin.file syntax, so should do the same for emails. This will allow using layouts from one plugin with the view from another plugin.
