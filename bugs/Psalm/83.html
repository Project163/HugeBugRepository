Title

False positive InvalidArrayAccess in array index with array_rand

Description
Expected: no error
Observed:
```
ERROR: InvalidArrayAccess - src/rand.php:6:17 - Cannot access value on array variable $vars using int offset - expecting 'x' or 'y'
    return [$c, $vars[$c]];  
```

```php
  'a', 'y' => 'b'];
    $c = array_rand($vars);
    return [$c, $vars[$c]];
}
```
Discussion
- After that commit, psalm complains if 2 arguments are provided to array_rand. The second is the number of requested elements.

```
  'a', 'y' => 'b'];
    $c = array_rand($vars);
... [Log Snipped] ...
    return array_rand($vars, $n);  // incorrectly emitted: TooManyArguments: Too many arguments for method array_rand 
}
```
- Those signature discrepancies have been fixed in [URL]

And I maintain that this is one of the worst signatures in heavy usage (though `get_class(null)` gets a special shoutout)
