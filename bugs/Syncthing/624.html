Discussion
- Seems there are multiple bugs here.
One is the staggered expire grouping happens on untagged file name, but version does not include the tagged file name.

Restoration function takes a version timestamp, yet the filenames have modtime of the original file embedded, meaning we potentially need to do multiple globs to find it (old style glob, new style glob, and without a timestamp potentially).
