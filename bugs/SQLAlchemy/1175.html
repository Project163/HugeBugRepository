Title

schema_translate_map ignored when using Enum with ARRAY

Description
While an ``Enum`` type being correctly created with the schema specified, it's impossible to use the type as an ``ARRAY`` element type. A ``CREATE TABLE`` and a subsequent ``CAST`` clauses generated will lack of schema for the ``Enum``.

**To Reproduce**
```
py
from sqlalchemy import create_engine, Table, Column, Integer, MetaData, ARRAY, Enum

metadata = MetaData()

... [Log Snipped] ...
conn.execute(t.insert(), [{"value": ["one"]}, {"value": ["two", "three"]}])
metadata.drop_all(conn)
```
