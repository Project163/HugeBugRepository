Title

Yii 2.0.13 Gii broken for MSSQL

Description
### What steps will reproduce the problem?
Go to gii model generator. Enter name of table in MSSQL database.
Click preview. 

### What is the expected result?
Preview of model is generated.

### What do you get instead?
Error:
SQLSTATE[42S02]: [Microsoft][ODBC Driver 13 for SQL Server][SQL Server]Invalid object name 'pg_namespace'.
The SQL being executed was: SELECT ns.nspname AS schema_name
FROM pg_namespace ns
WHERE ns.nspname != 'information_schema' AND ns.nspname NOT LIKE 'pg_%'
ORDER BY ns.nspname

### Additional info

This appears to be an issue with protected function findSchemaNames(): [URL]

As mssql doesn't doesn't store schemas in pg_namespace. The query should probably be using sys.schemas or INFORMATION_SCHEMA.SCHEMATA
