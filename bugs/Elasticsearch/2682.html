Title

[Licensed Feature Tracking] Searchable Snapshots license level should be Enterprise, not Platinum

Description
In [URL] we started tracking usage of the Searchable Snapshots feature. The usage is returned by the `GET _license/feature_usage` API like so:

```
json
{
  "features" : [
    {
      "family" : null,
... [Log Snipped] ...
  ]
}
```

Notice the `license_level` field in the response. It is set to `platinum`. However, according to [URL] Searchable Snapshots is an Enterprise level feature.
