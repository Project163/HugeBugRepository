Title

(OBS 30.0.0-beta3) QSV crashes OBS

Description
### Operating System Info

Windows 11

### Other OS

_No response_

### OBS Studio Version

Other

### OBS Studio Version (Other)

30.0.0-beta3

### OBS Studio Log URL

[URL]

### OBS Studio Crash Log URL

[URL]

### Expected Behavior

Encoder shouldn't crash obs.

### Current Behavior

OBS crashes when you stop recording while running stream.

### Steps to Reproduce

1.Select qsv as encoder both on streaming and recording tab
2. Start streaming
3. Start recording
4. Stop recording
5. Crash!
...


### Anything else we should know?

This issue started with OBS 30.0 beta-3
**OBS 30.0 beta-2** works without issues no crashes.

- I don't know what the correct fix is, but I can confirm that gating the close/release behind the g_numEncodersOpen solves it.

Introduced in: #9510 

```cpp
if ((m_bUseTexAlloc) && (g_numEncodersOpen <= 0)) {
	g_DX_Handle = NULL;
	Release();
}
MFXVideoENCODE_Close(m_session);
return sts;
```
Works for me. Tested with and without gpu tex.

cpp
if (m_bUseTexAlloc) {
