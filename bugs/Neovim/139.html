Title

crash on exit with shada='100,:0

Description
Likely a multiple-year old issue, as I've been experiencing this crash on exit for a while.
```
fish: “nvim” terminated by signal SIGSEGV (Address boundary error)
```

Caused by the following line:
```
set viminfo='1000,:0,<0,@0,f1,/0
```

Any of the `:0,<0,@0` options in combination with any number of lines (`'100`) are causing the crash. I'm not sure there's an expected behavior with Neovim's shada.
