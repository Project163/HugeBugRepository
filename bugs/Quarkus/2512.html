Title

quarkus-container-image-podman seems to be ignored?

Description
### Describe the bug

I have added the quarkus-container-image-podman extension to my app, however when I issue a container build command (e.g. `quarkus image build`) the extension seems to be somewhat ignored since it says it's using the executable podman within the quarkus-container-image-docker extension:

```
[INFO] [io.quarkus.container.image.docker.common.deployment.CommonProcessor] Starting (local) container image build for jar using docker
[WARNING] [io.quarkus.container.image.docker.deployment.DockerProcessor] Using executable podman within the quarkus-container-image-docker extension. Maybe you should use the quarkus-container-image-podman extension instead?
[INFO] [io.quarkus.container.image.docker.common.deployment.CommonProcessor] Executing the following command to build image: 'podman build -f src/main/docker/Dockerfile.jvm -t quay.io/kevindubois/kubernetes-agent:1.0.0-SNAPSHOT .'
[INFO] [io.quarkus.container.image.docker.deployment.DockerProcessor] Built container image quay.io/kevindubois/kubernetes-agent:1.0.0-SNAPSHOT
```

This becomes problematic when you have an application property like `quarkus.podman.platform=linux/amd64` which is completely ignored.

 

### Expected behavior

when I add the quarkus-container-image-podman extension, I expect the build to use it and pick up my quarkus.podman.* properties.

### Actual behavior

the quarkus-container-image-podman extension appears to be ignored.

### How to Reproduce?

Any Quarkus project should work, but you can try with this one: github.com/kdubois/quarkus-kubernetes-kafka-db .   Make sure to add the quarkus-container-image-podman extension and that you have podman installed on your machine.  also add `quarkus.podman.platform=linux/amd64` to your application.properties

Run:

`quarkus image build`
