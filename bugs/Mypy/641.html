Title

Metaclass doesn't work across import cycle

Description
I have a program with the following files:

`a.py`:

```py
import b
import c
reveal_type(c.A.f())
m: b.M = c.A
```

`b.py`:

```py
import c
class M(type):
    def f(cls) -> int: return 0
```

`c.py`:

```py
from typing import Type
import b
class A(metaclass=b.M): pass
```

If I run `mypy a.py`, I get the following output, which isn't what I'd expect:

```
c.py:3: error: Metaclasses not inheriting from 'type' are not supported
a.py:3: error: Revealed type is 'Any'
a.py:3: error: "A" has no attribute "f"
a.py:4: error: Incompatible types in assignment (expression has type "A", variable has type "M")
```

(The program also doesn't run as such, but by reversing the order of imports in `a.py` it runs, so the cycle is not inherently badly formed.)

Here's also a test case that I wrote (goes to `check-incremental.test` or `check-serialize.test`):

```
[case testSerializeMetaclassInImportCycle2]
import b
import c
reveal_type(c.A.f())
m: b.M = c.A
... [Log Snipped] ...
main:2: error: Revealed type is 'builtins.int'
main:4: error: Revealed type is 'builtins.int'
```
Discussion
- As a quick and dirty fix, we can default for assuming that a class is a valid metaclass if its `mro` is `None`. After all, it is true.
