Title

[Bug]: Next.js Link component causes navigation to a non-existent page in stories

Description
### Describe the bug

When using the `Link` component from Next.js 15 within an `appDirectory` configuration, the component behavior is not properly overridden. This leads to navigating directly to nonexistent pages after clicking the link. 

This behavior does not occur with Next.js 14.

### Reproduction steps

Discussion
- As a workaround, I added the following configuration.

```
  webpackFinal(config) {
      if(!config.resolve?.alias) return config
      config.resolve.alias = {
        ...config.resolve?.alias,
        "next/link": "next/dist/client/app-dir/link",
      }
      return config
  },
```
