Title

Implicit FTPS upload timeout since curl 7.88.1

Description
### I did this

This is possibly related to the report here: [URL]

Implicit FTPS file uploads time out since upgrade of my system to Debian 12.1 with curl 7.88.1. I don't fully understand the logs, but it looks as if the TLS session gets closed and not reopened for the file transfer. This was working fine on Debian 11.
I tried installing the curl 8.2.1 from Debian sid and also the 7.88.1 version for Debian 11 but the same happens. I tried an ubuntu system which worked fine. This one used curl version 7.81.0.

Verbose log of the connection attempt and timeout:
```

... [Log Snipped] ...

curl: (28) FTP response timeout
```

Installed the ubuntu packages onto Debian 12.1 and now it's working again on the Debian12.1 system and marked as hold to prevent updates for the time being:
```
wget [URL]
wget [URL]
wget [URL]
dpkg -i libssh-4_0.9.6-2build1_amd64.deb 
dpkg -i libcurl4_7.81.0-1ubuntu1.13_amd64.deb
dpkg -i curl_7.81.0-1ubuntu1.13_amd64.deb 
apt-mark hold curl libcurl4 libssh-4
```
