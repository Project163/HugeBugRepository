Title

XSS during server side rendering

Description
**Describe the bug**

It is possible to inject a script tag into the HTML during server side rendering. The content of `svelte-data`-scripts aren't escaped.

Also tested it on Sapper and there it is escaped.

**Logs**

--

**To Reproduce**

##### user.json.js
```
js
export async function get() {
  const user = {
    name: "  alert('xss') "
  };
... [Log Snipped] ...
  };
}
```

##### index.svelte
```
html
 
  export async function load({ fetch }) {
    const res = await fetch('/user.json');

... [Log Snipped] ...

 My heading 
```

##### On the rendered page
```html
 {"status":200,"statusText":"","headers":{"content-type":"application/json"},"body":"{\"name\":\"  alert('xss') \"}"} 
```

##### Sapper does something like this (shortened):

```html
 __SAPPER__={preloaded:[void 0,{user:{name:"\u003C\u002Fscript\u003E\u003Cscript\u003Ealert('xss')\u003C\u002Fscript\u003E"}}]}; 
```

**Expected behavior**

The content inside `svelte-data` would be escaped.
