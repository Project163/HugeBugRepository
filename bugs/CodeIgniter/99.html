Title

Image library is broken in 3.1.0

Description
The addition of escapeshellargs on this line breaks image processing: [URL]

It's double quoting the paths: "'...'" instead of '...'

That line should read:

`$cmd .= ' '.escapeshellarg($this->full_src_path).' '.escapeshellarg($this->full_dst_path).' 2>&1';`
Discussion
- What is your system as I know escapeshellarg works a little bit different under Windows .. 
Perhaps a system difference is causing the problem, not the php code as its written..
- I'm on a Mac and encapsulating the parameters in double quotes then again in single quotes doesn't work. We caught this on our staging server which is an AWS ElasticBeanstalk container (Amazon Linux) which also breaks. My dev (Mac) and our staging/production environments (AWS) are all running PHP 5.6.

It may be hard to see in my comment above but its doing this:

[doublequote][singlequote]parmeter[singlequote][doublequote]

The change in 3.1.0 wraps it in double quotes in code then escapeshellarg wraps it again in single quotes. In 3.0.6 it only wrapped it in double quotes in code. I'm assuming escapeshellarg is the preferred method and the old double quotes weren't removed.
