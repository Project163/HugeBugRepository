Title

Bug in XSDDateTime toString

Description
toString() for the class org.apache.jena.datatypes.xsd.XSDDateTime generates incorrect output when year value is between -999 and -1. 

 For example : the representation of date time "-0001-01-01T00:00:00" in XSDDateTime class has data array of (-1,1,1,0,0,0,0,0,0) and mask = 15. however, the toString() method incorrectly outputs "000-1-01-01T00:00:00" 

 proposed fix attached.
