Title

New Table Function type inference fails

Description
For a simple UDTF like  
  
 
 public   class  Split  extends  TableFunction< String > {
		 public  Split(){}
		 public  void eval( String  str,  String  ch) {
			 if  (str ==  null  || str.isEmpty()) {
				 return ;
			}  else  {
				 String [] ss = str.split(ch);
				 for  ( String  s : ss) {
					collect(s);
				}
			}
		}
	}
