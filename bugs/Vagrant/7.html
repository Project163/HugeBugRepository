Title

Ansible provisionner doesn't check SSH key permissions

Description
When declaring a `config.ssh.private_key_path` with wrong permissions, vagrant itself [Link: checks for permissions]

Since the ansible provisionner is called before any vagrant builtin ssh action, if the permissions are wrong, it will fail.

I think we should call the "check permissions" method in the ansible provisionner, the same way it's done in ssh actions.

I'm running vagrant 1.6.5
Discussion
- Thanks @julienvey for reporting this problem (I was not aware that Vagrant tries to fix private key permissions).
