Title

_autobegin() in connection (check Session also) does not guard against reentrant behavior

Description
**Describe the bug**
In 1.3.x, the guidance here [URL] worked perfectly. However, once I upgraded to 1.4 and put future in the engine I am now getting a recursion error. The page still exists in the 14 docs with a minor syntax change so it led me to believe it would still work.

**Expected behavior**
Tests using an in memory sqlite database engine should still work under 1.4 future mode.

**To Reproduce**
Run this in pytest:

```
py
from sqlalchemy import create_engine, event, Column, String
from sqlalchemy.orm import declarative_base
from sqlalchemy.pool import StaticPool

... [Log Snipped] ...
    engine = get_engine()
    Base.metadata.create_all(engine)
```

**Error**

```
def test_example():
        engine = get_engine()

tests/alchemy/test_alchemy.py:43: 
... [Log Snipped] ...
==================================================================================================== short test summary info =====================================================================================================
FAILED tests/alchemy/test_alchemy.py::test_example - RecursionError: maximum recursion depth exceeded while calling a Python object
```

**Versions.**
 - OS: Ubuntu 20.04.1 LTS
 - Python: Python 3.8.5
 - SQLAlchemy: 1.4.0b1
 - Database: sqlite3
 - DBAPI: nominal
