- Seems like we keep having this problem and just need to workaround it in cqlsh with a bit more logic like ignoring anything after the last numeric character.

     JAVA_AGENT= "$JAVA_AGENT -javaagent:$CASSANDRA_HOME/lib/jamm-0.2.5.jar" 
 
  

 to point to the correct version (jamm 0.2.6).
