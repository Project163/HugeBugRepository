Title

[salt] provisioner fails to copy minion config on 1.7.4

Description
Hey all! This is more than just a reproduction #5973 (which you should read for context. I won't duplicate here).

The goal of this issue is to point out problems/solutions with bootstrap script usage introduced in 1.7.3. With a fresh install of vagrant 1.7.4 (host: Trusty64), #5936 does not fix issues seemingly introduced with #5435.
### Problems
1. We need a clear and consistent way of customizing the arguments passed to the bootstrap script. This was the reason why @timoguin created #5435. The [Link: documentation surrounding `install_args` and `bootstrap_options`] should properly reflect the  ~~quirks~~ behaviour of saltstack's bootstrap script.
   - `bootstrap_options` applies to the flagged options passed the the bootstrap script that are required to appear first.
   - `install_args` are for arguments such as branch name and install type (e.g. stable, git)
2. The quickest way back to a _working_ state would be to revert **both** #5936 and #5435. 
3. We need [Link: testing around `install_args` and `bootstrap_options` anyways]

I'm working on all 3. PR soon.

Thoughts? @timoguin @mitchellh @cachedout @thatch45
