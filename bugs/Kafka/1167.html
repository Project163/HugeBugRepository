Title

DumpLogSegments cannot print data from offsets topic

Description
It looks like there's been a regression in the DumpLogSegments tool. I'm marking it a blocker since it appears we can no longer dump offset information from this tool, which makes it really hard to debug anything related to __consumer_offsets. 

 The 0.10.0 branch seems to work fine, but even with offsets log files generated using only old formats (0.10.0 branch), the DumpLogSegments tool from trunk (i.e.  -SNAPSHOT with latest githash   as of reporting this) will cause the exception below. This was found while doing some basic testing of   KAFKA-4062  .
