Title

Compiler doesn't enforce that annotations are only applied to program elements they are intended for

Description
Although @Documented is only meant to be applied to annotation types, I can put it wherever I want, and the compiler won't complain. And neither the JVM! 
It seems the compiler only detects the misuse if the annotation type is defined and used in the same compilation unit. This is a reoccurring pattern. How can we make sure it won't strike again? 

  
 @Documented
 class  AnnTests {
  @Documented
   private  field

  @Documented
  def prop

  @Documented
   public   static  void main( String [] args) {
    println AnnTests.annotations
    println AnnTests.getDeclaredField( "field" ).annotations
    println AnnTests.getDeclaredField( "prop" ).annotations
    println AnnTests.getMethod( "main" ,  String []).annotations
  }
}
