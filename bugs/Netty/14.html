Title

CookieEncoder should refuse to encode more than one cookie if on server mode

Description
The `Set-Cookie` or `Set-Cookie2` header is supposed to set only a single cookie at a time.  If a server wants to set multiple cookies, it has to add multiple `Set-Cookie` headers.  Therefore, encoding multiple cookies into a single header value on the server side makes the client accept only the first cookie set.  #94 illustrates this issue, but we failed to fix the issue at that time.
