Title

before_execute no longer allows modification of the statement

Description
### Describe the bug

Seems like previously the before_execute handling code actually used the statement part of the return value, whereas [Link: now], it doesn't appear to make any use of that value.

So while it may be possible to mutate a statement, for immutable query types like strings (or even `text`, i would imagine one would have to mutate private internals), one can seemingly no longer alter the query

### To Reproduce

```
python
from sqlalchemy import create_engine, event

engine = create_engine("sqlite://")

... [Log Snipped] ...

engine.execute("select 1")
```
