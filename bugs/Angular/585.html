Title

Language Service. Component ... must have a template or templateUrl

Description

[ ] Regression (a behavior that used to work and stopped working in a new release)
[x] Bug report

[ ] Documentation issue or request

I have a simple component with empty template:
```
@Component({
               selector: 'app-home',
               template: ''
           })
export class HomeComponent {
    title = 'Home!';
}
```

## Current behavior
 
Language service shows error that `Component HomeComponent must have a template or templateUrl`.

## Expected behavior
 
It has but empty.

## Minimal reproduction of the problem with instructions
 
Check [Link: the repo].

## What is the motivation / use case for changing the behavior?
 
There are cases when empty template is desirable (e.g. when building DOM with d3) LS shouldn't show error when template is specified as empty.

## Environment

  
Angular version: 4.3.3
