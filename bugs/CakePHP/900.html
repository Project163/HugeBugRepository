Title

ignored exist field when using "EntityRoute"

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

[URL]
in route class
```
php
		$url['lang'] = 'en';
		if (isset($url['_entity'])) {

				$entity = $url['_entity'];
... [Log Snipped] ...
		}
		debug($url);
```
my entity ( ` $url['_entity']` )  does not any field named `'lang'` 
`debug($url); ` returns 
```php
//
'lang`=>null
//
```
so you can not use 
```php
Router::url([ 'lang' => 'en', '_name' => 'articles:view', '_entity' => $article]);
```
Discussion
- I fixed this by a `if` in my app
```php
				foreach($matches[1] as $field) {
						if(!isset($url[$field])){
							$url[$field] = $entity[$field];
						}

				}
```
- but above solution is not true for general usage
- ... [Middle Discussions Snipped for Brevity] ...
- We would need to distinguish between stuff that was passed manually and fields that are present because of the `$this->defaults` property in the Route
- @lorenzo Does the following precedence make sense:

* URL key
* Entity property
* Route defaults
