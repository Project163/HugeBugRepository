Title

Single proto defining 2 or more services will generate invalid Objective-c code

Description
define a proto as:

```
syntax = "proto3";

package TestPackage;

import "google/protobuf/empty.proto";
... [Log Snipped] ...
   rpc Method2(google.protobuf.Empty) returns (google.protobuf.Empty);
}
```

Will generate Services.pbrpc.h that will not compile:

... Redefinition of 'kPackageName'
... Redefinition of 'kServiceName'

Example:

```
#import "Services.pbrpc.h"

#import  
#import  

... [Log Snipped] ...
static NSString *const kPackageName = @"TestPackage";
static NSString *const kServiceName = @"ControlBackend";
```

I would expect I can define as many services as I'd like in a single proto.
