Title

Allow array_filter callable strings to be interpreted as closures

Description
Bringing up the issue of strings being passed as argument 2 to `array_filter()`, psalm at present doesn't parse `array_filter(array , 'is_object')` to resolve to `array `:

* [URL]
```
php
 
*/

```
Discussion
- Smaller reproduction:

```php
/**
 * @param array  $a
 * @return array 
 */
function foo(array $a) : array {
	return array_filter($a, 'is_object');
}
```

[URL]
- This works fine:

```php
/**
 * @param array  $a
 * @return array 
 */
function foo(array $a) : array {
	return array_filter($a, function ($f) { return is_object($f); });
}
```

So it should be a relatively simple fix.
