### Issue Description

I use Frameit with pleasure to frame my screenshots and add a localised keyword and title to it.
The majority of text is aligned correctly:
[Image: iphone5s-03_keyboarddiscovered-589996837d813aace56d9a0cf7b764a0_framed]

Some of the framed screenshots show a vertical offset between the keyword and title. The offset might be a few pixels:
[Image: iphone5s-02_smarttab-589996837d813aace56d9a0cf7b764a0_framed]

Or massive:
[Image: iphone5s-01_remotetab-589996837d813aace56d9a0cf7b764a0_framed]

My Framefile:
```
json
{
    "default": {
        "keyword": {
            "font": "./fonts/SF-UI-Display-Semibold.otf",
... [Log Snipped] ...
             ]
}
```

These are French, but I have got it in other languages too.
The ones with a small offset, have a special character in either the keyword or title. For example in German the "ä", but also the apostrophe (') in a Dutch word.
But I can't explain the massive offset in the example above, where no special character is used. The behaviour seems somehow random.

Here are the *.strings files for the above French screenshots:

_keyword.strings_
```strings

"01" = "Familier";
"02" = "Logos";
"03" = "Pratique";
"04" = "Glisser";
"05" = "Sélection directe";
```

_title.strings_
```strings

"01" = "en apparence";
"02" = "pour changer de chaîne";
"03" = "pour entrer du texte";
"04" = "pour contrôler";
"05" = "des sources";
```

Can you please investigate?
