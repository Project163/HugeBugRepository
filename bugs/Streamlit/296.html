Title

Show warning when calling to_bytes with object-typed NumPy array

Description
Numpy hashes object-typed arrays unexpectedly. Just the memory pointers are processed by `tobytes()`, not the objects that they point to.

This means that we are unable to properly compare two sets of data that are equivalent but have different references, which is not what we want.

[URL]

# Potential solution
Can we detect when we have an object-typed NumPy array and show a warning instead of calling to_bytes?
