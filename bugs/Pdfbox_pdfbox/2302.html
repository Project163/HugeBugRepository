Title

Use PDFontFactory. CreateDefaultFont font to render text, the exported PDF document has a mistake

Description
Using PDFontFactory. CreateDefaultFont font to render a text and save this document. 
  
 
 float  fontSize = 11;
PDFont font = PDFontFactory.createDefaultFont(); 
contentStream.beginText();  
contentStream.newLineAtOffset(100, 100); 
contentStream.setFont(font, fontSize);
contentStream.showText( "¥456,123" ); 
contentStream.endText();
contentStream.close();

doc.save( "sample.pdf" ); 
  
 Open the PDF document with Abode and throw the following error message when editing the document.

   Test.zip
Discussion
- Please try using  PDType1Font.HELVETICA  instead and tell whether that works. I have doubts whether  createDefaultFont  is good for creating PDFs (at the very least, the method has a poor javadoc), it was meant for rendering corrupted PDFs (  PDFBOX-2222  ) and I see that it references a font that may not exist on your machine (Arial). I don't have an error with Adobe Reader, but I have the save problem with Chrome that you have.
- Use the Adobe Acrobat Pro DC, and click on the "Edit PDF" menu, the error box appreaes.   I use the PDType1Font.HELVETICA instead, neither of these situations exists. So is it not recommended to use createDefaultFont to create the default font for pdfbox?
