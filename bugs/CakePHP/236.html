Title

3.0 - Session timeout not working

Description
Hi guys. I'm pretty sure this worked at some point, but setting the timeout in Session config has no (or seems to not have any) effect right now.

In my config:

```
'Session' => [
    'timeout' => 60
]
```

In `Cake\Network\Session::create`, my `$sessionConfig` becomes:

```
Array
(
    [timeout] => 60
    [defaults] => php
    [cookiePath] => /cms/
)
```

When logging in on my cms, the set-cookie is:

```
Set-Cookie:CAKEPHP= ; path=/cms/; HttpOnly
```

The reason I think this is more a bug than my config being wrong is that other keys work, I can do this:

```
'Session' => [
    'ini' => [
            'session.cookie_lifetime' => 60
        ]
]
...
```

And then my cookie is this, which reflects the timeout

```
Set-Cookie:CAKEPHP= ; expires=Wed, 14-Jan-2015 16:36:19 GMT; Max-Age=60; path=/cms/
```
Discussion
- `'timeout'` != `'cookieTimeout'` afaik. Did you try the latter? The first is usually a relative value, the second one an absolute one.
- Yeah I tried that one as well. No permutation of using both/either of these seems to work..

```
'Session' => [
    'timeout' => 62,
    'cookieTimeout' => 61
]
```

Edit.. also the docs say that if `cookieTimeout` isn't there it'll use the value of `timeout` for it.
