Title

Lack of cyrillic charset windows-1251 Google Closure Compiler REST API support for input & output.

Description
What steps will reproduce the problem? 
1. Create *.js file with charset windows-1251 and cyrillic symbols in it (ex. "Да здравствует этот прекрасный мир!");
2. Add it as a source url to google compiler ( REST API ) with request parameter "..&charset=windows-1251&..";
3. Try to compile.

 What is the expected output? What do you see instead? 
JS part'll be compiled with success, except cyrillic symbols, which will be outputs as "\ufffd\ufffd \ufffd\ufffd\ufffd\ufffd\ufffd\ufffd\ufffd\ufffd\ufffd\ufffd\ufffd \ufffd\ufffd\ufffd\ufffd \ufffd\ufffd\ufffd\ufffd\ufffd\ufffd\ufffd\ufffd\ufffd\ufffd \ufffd\ufffd\ufffd!"

 What version of the product are you using? On what operating system? 
The latest version of REST API, using Google Chrome on Windows.

 Please provide any additional information below.
