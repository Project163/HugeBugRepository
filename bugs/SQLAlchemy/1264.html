Title

SET class in lib/sqlalchemy/dialects/mysql/enumerated.py is missing __repr__method

Description
### Describe the bug

As a result, when auto generating migrations with Alembic, allowable SET values are missing.

### Error

```python
# Should look like this:
sa.Column('target', mysql.SET('_blank', '_self'), server_default=sa.text("'_self'"), nullable=False)

# Looks like this:
sa.Column('target', mysql.SET(length=11), server_default=sa.text("'_self'"), nullable=False)
```
