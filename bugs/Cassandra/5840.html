- Workaround:  

 Cassandra is using jna- .jar that has a native dll in it (jnidispatch.dll) that needs msvcr100.dll that is part of Microsoft Visual C++ 2010 Redistributable Package (x64). If you install that then Cassandra will run without crashing. NOTE: It may be hard to find "Microsoft Visual C++ 2010 Redistributable Package (x64)" from Microsoft.
