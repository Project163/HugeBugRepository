Title

The diamond operator does not work when passing a value whose type is a type variable

Description
I have the following program 

   
  
 
 class  A<T> {
  void foo() {
    T z =  null ;
    T x =  new  B<>(z).f  // does not work
 
     String  y = ""
     String  k =  new  B<>(y).f  // works
   }
  
}
 class  B<X> {
  X f;
  B(X f) {
     this .f = f;
  }
}

 Compile successfully
