Title

No tests are run with TestNG 5.0 or 5.0.1

Description
Run the test below with TestNG 5.0 or 5.0.1.  You'll get 0 tests run.  Run with TestNG 5.0.2, 5.1, 5.5, 5.6 or 5.7.  You'll get one passing test.
Discussion

- The 5.0 and 5.0.1 jars on repo are malformed; they don't even run tests from the command line.  Nobody could possibly want to be compatible with them.
