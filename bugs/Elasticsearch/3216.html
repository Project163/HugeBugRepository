Title

knn query on semantic_text field with semantic_text filter fails

Description
### Elasticsearch Version

9.2

### Installed Plugins

_No response_

### Java Version

_bundled_

### OS Version

Darwin

### Problem Description

A `knn` query on a `semantic_text` field fails when it contains filters that are other queries on `semantic_text` fields (e.g. `knn`, `sparse_vector`, `match`).

### Steps to Reproduce

```
PUT example
{
    "settings": {
        "number_of_shards": 1,
        "number_of_replicas": 0
... [Log Snipped] ...
    }
}
```

The first search fails with: 

```
{
  "error": {
    "root_cause": [
      {
        "type": "query_shard_exception",
... [Log Snipped] ...
  "status": 400
}
```

The second fails with:

```
{
  "error": {
    "root_cause": [
      {
        "type": "illegal_state_exception",
... [Log Snipped] ...
  "status": 500
}
```
