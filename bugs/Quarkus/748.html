Title

In tooling, do not install any extension when there are multiple matches

Description
**Describe the bug**
I think that by default we shouldn't install any extension when there are multiple matches:

We only list then and tell the user that they can use a flag to "accept" installing all

Example of case where you may not want all installed in the end:

```
addExtensions(asList("jdbc"));

✅ Extension io.quarkus:quarkus-agroal has been installed
✅ Extension io.quarkus:quarkus-jdbc-db2 has been installed
✅ Extension io.quarkus:quarkus-jdbc-postgresql has been installed
... [Log Snipped] ...
✅ Extension io.quarkus:quarkus-jdbc-derby has been installed
✅ Extension io.quarkus:quarkus-elytron-security-jdbc has been installed
```

**Expected behavior**
Fail and list the matching extensions

**Actual behavior**
They are installed

This new behavior has appeared with the new registry.
