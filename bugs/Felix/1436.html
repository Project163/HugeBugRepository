Title

Disable update counter

Description
Update counter checks have been added to prevent multiple configuration updates with the same configuration in certain race condition situations. 

 With the new R4.3 Configuration Admin (v1.4) it is now allowed that multiple ManagedService or ManagedServiceFactory services are registered with the same PID and that all receive the same configuration. This of course is incompatible with the current simple update counter mechanism. 

 For now we should just disable this check.
Discussion
- This reverts part of   FELIX-1542  . We still keep the counter of modifications to the configuration (for now because it helps with logging the operation)
- Removed the lastUpdateTime field (and all references and uses) and renamed the lastModificationTime field to revision to reflect the intended use as a revision counter rather than a timestamp.
- Close issues after release
