Title

[bug] NSIS updater assets are not created if specify targets to ["msi", "app", "dmg", "updater", "nsis"]

Description
### Describe the bug

if I specify ["msi", "app", "dmg", "updater", "nsis"] in targets, then updater assets(.zip/.sig) are created for msi but no updater assets are created for nsis, if don't specify targets, then updater assets are created for both msi and nsis.

- I can finally reproduce the bug, it is related to the order you define the targets, if `updater` target is not the last one in the list, it will behave weirdly.

Until a proper fix is released, just keep `updater` target at the end of the list and all should be fine.
