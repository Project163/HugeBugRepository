Title

spark.driver.* system properties are outdated if --driver-* options exist

Description
If we set "spark.driver.extraClassPath" AND "--driver-class-path", then the latter correctly overrides the former. However! The value of the system property "spark.driver.extraClassPath" remains the former, which is not actually used. 

 That is just an example. Of course this also affects java options, library path and memory etc.
