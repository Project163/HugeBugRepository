Title

Class property accepts generic instance with unmatching template types

Description
In the code at [URL] a value that is inferred to be an `Collection ` is assigned without warnings to a property accepting a `Collection `. During the executing of the constructor, the property is also inferred to be a `Collection `, as shown by the error.

What may be expected instead:
 - The assignment of a `Collection ` to a property of type `Collection ` shouldn't be allowed
- Ideally, `new ArrayCollection()` should be inferred to be a `Collection ` in this case. It's currently inferred as a `Collection ` because the constructor argument has a default value; however this value is an empty array
