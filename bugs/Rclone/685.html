Title

rclone package linux-arm-v7.deb, v1.58.0-beta.5887 and newer, not installable on raspian (rPi4), architecture missmatch

Description
RaspberryPi 4 has an arm-v7 architecture. Raspian is based on debian. so the right package for installation is linux-arm-v7.deb
when you try to install with
apt install linux-arm-v7.deb
v1.58.0-beta.5887 and newer, the package manager will fail.

the deb-package doesnt contain the information any more that the package is also for armhf.
so the package manager will stop installation:

Error while processing Archiv rclone-beta-latest-linux-arm-v7.deb (--unpack)
Package-Architecture (arm) doesnt match with system (armhf)
sub-process /usr/bin/dpkg returned an error code (1)
