Title

BUG! exception in phase 'class generation' while poping argument from operand stack tracker

Description
The following fails with the above exception: 

  
 @groovy.transform.CompileStatic
 class  Test {
   long [] data
   long  topMask
    
  void doSomething() {
    data[ 0 ] |= 0x7ffffffl
  }
}

 new  Test()

 void doSomething() {
  data[ 0 ] = data[ 0 ] | 0x7ffffffl
}
