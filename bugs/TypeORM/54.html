Title

PrimaryGeneratedColumn does not set isGenerated to true when exists on parent entity

Description
Describing normal Typescript inheritance and not one of single table/class inheritance.

This is happening due to recent changes in the auto-generated functionality made on the 25th of July.
The problem is that the "build" function of EntityMetadataBuilder calls the "findGenerated" function on MetadataArgsStorage and only passes the current entity metadata without the entire inheritance tree.

Didn't know what was the best way to fix this.
