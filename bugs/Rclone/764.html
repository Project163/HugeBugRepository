Discussion
- Unhelpfully some non s3 systems give the same error code `BucketAlreadyExists` if you own the bucket or not.

Rclone tries to make the bucket before doing operations on it, so if the bucket already exists it ignore the `BucketAlreadyExists` error.

The reason rclone does this is probably a design mistake that I haven't removed as I don't want to break backwards compatibility.

However s3 does now (it didn't used to) give back the error BucketAlreadyOwnedByYou and we know we are using s3 because of the provider field, so that suggests a fix - only check  BucketAlreadyOwnedByYou on S3.

I've added a provider quirk and and coded that up - I think this should give an error for you now.
