Title

The metrics data for the number of scanned rows in pushdown queries is lost

Description
Root Cause 

 The operator types for scanning data contained in the generated SparkPlan are not fully covered when calculating `scanRows` and `scanBytes`. In the current case, this is due to the lack of accumulation of metrics for `HiveTableScanExecTransformer`.
Discussion
