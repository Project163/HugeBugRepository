Title

Sync progress can show negative percentages

Description
The files-to-sync can be higher than the files in the global repository:

```
 Globale repository   4922 objecten, ~26.7 GiB
 Lokale repository    0 objecten, ~0 B
 Niet gesynchroniseerd    5027 objecten, ~27.4 GiB
```

When this happens, the sync percentages in the Web UI become negative. Presumably happens when the repo filelist is still being downloaded.
Discussion
- The sync percentage is defined as 

```
var pct = 100 * $scope.model[repo].inSyncBytes / $scope.model[repo].globalBytes;
```

which can only be negative if one of the byte counts are. I don't see how that would happen... Server side, the sizes in question are int64 so wrapping should not be an issue.
