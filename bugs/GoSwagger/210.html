Title

swagger validate fails on responses with description field

Description
## Problem statement

Recent updates to go-swagger dependencies mean that the `description` field of responses is no longer omitted when empty.

The validator needs to be updated to accommodate this change.

## Swagger specification

```
...
"/api/test": {
      "get": {
        "description": "test description",
        "consumes": [
... [Log Snipped] ...
      }
...
```

## Steps to reproduce

```
swagger generate spec -o ./swagger.json --scan-models -x swagger-automation

swagger validate ./swagger.json
```

## Environment
swagger version: master ([Link: d7d6b60])
go version: 1.14
OS:  MacOS 10.15 + Github Actions ubuntu-latest
