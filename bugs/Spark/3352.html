Title

Handle jar conflict issue when uploading to distributed cache

Description
Currently with the introduction of assembly-free deployment of Spark, by default yarn#client will upload all the jars in assembly to HDFS staging folder. If the jars in assembly and specified with --jars have the same name, this will introduce exception while downloading these jars and make the application fail to run.
