Title

Fedora plugin doesn't leave localhost entries in /etc/hosts

Description
For example. If my hostname is `nule3` then this is the sed statement that gets run:

```
sed -ri 's@^(([0-9]{1,3}\.){3}[0-9]{1,3})\s+localhost(\s.*)?$@\1 nule3 nule3@g' /etc/hosts
```

This gets rid of all of the localhost entries on the line. In other words I start with this:

```
     localhost.localdomain localhost4 localhost4.localdomain4
::1         localhost localhost.localdomain localhost6 localhost6.localdomain6
```

and I end up with this:

```
  nule3 nule3
::1         localhost localhost.localdomain localhost6 localhost6.localdomain6
```
Discussion
- I stumbled across this as well while using the [Link: Boxcutter Fedora 22 box]. The default `/etc/hosts` file gets changed from the default:

```
[vagrant@localhost ~]$ cat /etc/hosts
    localhost localhost.localdomain localhost4 localhost4.localdomain4
::1         localhost localhost.localdomain localhost6 localhost6.localdomain6
```

to:

```
[vagrant@hostname-test ~]$ cat /etc/hosts       
  hostname-test hostname-test
::1         localhost localhost.localdomain localhost6 localhost6.localdomain6
```
