Title

Roundrobin failover policy does not reset the cursor position after a successful failover.

Description
The default roundrobin failover policy does not reset the  cursor position after a successful failover. This means that if you failover from A to B you will never failover from B to A anymore (assuming that our list of broker only contains two brokers A and B).
Discussion
- The value of _cycleRetries was 0 as a default hence resulting in the failoverAllowed method returning false once the last broker within the list was reached.
