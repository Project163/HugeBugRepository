Title

InjectMock with package private method

Description
've noticed that when using `@InjectMock` on a class that declares package-private methods, you do get a mocked instance but the methods that are declared package private can't be stubbed.

Given a class like this:

```
java
package example;

import javax.enterprise.context.ApplicationScoped;

... [Log Snipped] ...

}
```

And a test like this:

```
java
package example;

import static org.mockito.Mockito.when;

... [Log Snipped] ...

}
```

The `getPublic()` and `getProtected()` tests will work as expected but `getPackagePrivate()` will throw a null pointer since it's actually invoking `myService.getPackagePrivate()` inside then when clause.

Contrary to this, a "normal" Mockito test will work just fine:

```
java
package example;

import static org.mockito.Mockito.when;
import static org.mockito.MockitoAnnotations.openMocks;
... [Log Snipped] ...

}
```

If it's for some reason not possible to stub package-private methods in Quarkus then at least a helpful error message would be appreciated - it took me a while to figure out why my mock wasn't working 😄

Java version:
```
openjdk version "11.0.10" 2021-01-19 LTS
OpenJDK Runtime Environment Corretto- .1 (build 11.0.10+9-LTS)
OpenJDK 64-Bit Server VM Corretto- .1 (build 11.0.10+9-LTS, mixed mode)
```

Quarkus version: `1.11.0.Final`
