Title

Camel-jbang while running the process in background unable to access log if the process start fails with errors

Description
When I run camel integrations with jbang in background and later fetch log using "camel log" I am able to access the log only when the process has started successfully. But when it fails with some error, the log is empty and I am unable to find the failure reason.
Discussion
- Yes this is how it works - the camel log, only shows running JVM processes. If the process starts to fail for some other reason. We may consider some other way of reporting this.
