Title

LastCommit cache is broken by default on memcached

Description
- Gitea version (or commit ref): 1.14.0+dev-607-g012bf388a

## Description

Default TTL for LastCommit cache is 8760h or 365 days, however when supplying TTL in seconds to memcached, the maximum value is 2592000. Any value of seconds above that is treated as unix timestamp.

Due to this, LastCommit cache is always expired at the time of insertion (unix timestamp 31536000 is 1971-01-01T00:00:00+00:00)
Discussion
- Could you paste your configuration of these sections?
- Broken:
```
[cache]
ENABLED  = true
ADAPTER  = memcache
HOST = gitea-mc:11211
```

Working:
```
[cache]
ENABLED  = true
ADAPTER  = memcache
ITEM_TTL = 36h
HOST = gitea-mc:11211
```
