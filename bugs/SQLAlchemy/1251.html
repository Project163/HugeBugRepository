Title

with_parent example query in docs is incorrect

Description
### Describe the bug

Example query from sqlalchemy [Link: documentation] seem to produce cartesian product.
Models setup:
```
py
from sqlalchemy import ForeignKey, Column, Integer, select
from sqlalchemy.orm import relationship, declarative_base, with_parent

Base = declarative_base()
... [Log Snipped] ...

some_user = User(id=42)
```
Query from documentation:
```py
query = select(Address).where(with_parent(some_user, Address.user))
```
```sql
SELECT addresses.id, addresses.user_id 
FROM addresses, users 
WHERE users.id = :param_1
```
Using `User.addresses` instead of `Address.user` seem to be producing correct query:
```py
query = select(Address).where(with_parent(some_user, User.addresses))
```
```sql
SELECT addresses.id, addresses.user_id 
FROM addresses 
WHERE :param_1 = addresses.user_id
```

### To Reproduce

```
python
from sqlalchemy import ForeignKey, Column, Integer, select
from sqlalchemy.orm import relationship, declarative_base, with_parent

Base = declarative_base()
... [Log Snipped] ...
    correct_query = select(Address).where(with_parent(some_user, User.addresses))
    print(correct_query)
```

There's no error.
