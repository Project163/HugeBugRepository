Title

[Iceberg] Data type info is not correct in Error message for tinyint, smallint

Description
Creating table with smallint and tinyint as datatypes throws error log which reflects wrong data types. 
1. In case of smallint: 'Unsupported Hive type SHORT, use integer instead or enable automatic type conversion, set 'iceberg.mr.schema.auto.conversion' to true' 
2. In case of tinyint: 'Unsupported Hive type BYTE, use integer instead or enable automatic type conversion, set 'iceberg.mr.schema.auto.conversion' to true'
