Title

\yii\web\User has no method to clear access cache

Description
The User class does not seem to offer any way to clean the $this->_access cache.
As $this->_access is defined private there is no way (without overloading) to do it outside of the class.
I can't switch users due to the fact that checkAccess uses cache by default.
There is possibility however to to use checkAccess without allowing cache.

It would be greatly appreciated if any way to clear the $this->_access cache would be created and it automatically removed when switching users.
Discussion
- How and why are you switching users in one request?
- Checked in a fix that resets `$_access` when identity is set. Does this solve your problem?
- for example in a unit test, by using logout and login, might not be the
best approach to reuse the user component.
As there is a function available called switchIdentity I think it's
volatile.

The reset is in Yii1, see
[URL]
In Yii1 $this->_access is set as array() on logout, Yii2 never resets it as
far as I can see.
