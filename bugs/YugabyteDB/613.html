Title

JSON datatype not recognized by the packaged yugabyte db cqlsh

Description
Created a table with the `jsonb` datatype:
```
cqlsh:bookstore> describe table books;

CREATE TABLE bookstore.books (
    id int PRIMARY KEY,
    data jsonb
) WITH default_time_to_live = 0;
```

Tried selecting all the rows, but am hitting the following issue:
```
cqlsh:bookstore> select * from books;
Traceback (most recent call last):
  File "/Users/karthik/yugabyte/yugabyte- /bin/cqlsh.py", line 1039, in perform_simple_statement
    result = future.result()
  File "/Users/karthik/yugabyte/yugabyte- /bin/../lib/cassandra-driver-internal-only-3.7.0.post0-2481531.zip/cassandra-driver-3.7.0.post0-2481531/cassandra/cluster.py", line 3784, in result
    raise self._final_exception
NotSupportedError: Unknown data type code  . Have to skip entire result set.
```

This is in the following version:
```
$ bin/yb-tserver --version
version   build 26 revision   build_type RELEASE built at 19 Apr 2018 16:02:12 PST
```
Discussion
- This was a temporary glitch in our internal release flow. It was fixed soon after and is all good for our next release, confirmed with a manual download of our latest release candidate.
