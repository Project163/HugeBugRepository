Title

DOCKER_HOST-strategy in class isDockerWorking.java excludes expected "unix:"-path where it should include "unix:" - broken.

Description
### Describe the bug

In the file
IsDockerWorking.java.
line 129 -see [URL]

 the check for the DOCKER_HOST-variable is negatated. However, setting the DOCKER_HOST variable to a unix socket usually involves a path like "unix:\\\the\path\to\socket". This is also clearly mentioned and recommened in your documentation -> [URL] The negation should most likely be removed so that the logic it now hides can run correctly (connection to the "unix:" socket in the DOCKER_HOST-env.




### Expected behavior

It should find a DOCKER_HOST-path (according to practices, according to your documentation linked in descrioption starting with unix:\\\the-path-to-the-socket. 

### Actual behavior

It instead excludes DOCKER_HOST paths starting with "unix:" due to starting with neg !.

### How to Reproduce?

Set a DOCKER_HOST starting with "unix:\\" for example as per docu, qurkus will fail finding it and connecting to it . [URL]
