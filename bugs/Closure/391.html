Title

var obj2 = /** @dict */ { x: 321 }; displaying warninging in ADVANCED_OPTIMIZATION mode

Description
What steps will reproduce the problem? 
1. Create a file with the following content

/** @expose */
var obj2 = /** @dict */ { x: 321 };
alert(obj2[x]);

2. Compile the file with the flag "--compilation_level ADVANCED_OPTIMIZATIONS"
3. The compiler will compile the file and output an incorrect warning message

 What is the expected output? What do you see instead? 
I expected zero warnings. Instead I saw one warning, "ERROR - Illegal key, the object literal is a dict".  Based on the document for @dict this should be working without any warnings: [URL]

 What version of the product are you using? On what operating system? 
OS: Ubuntu 10
Closure Compiler: Version: v20130823 Built on: 2013/08/26 10:59

- @expose is only valid on a property (we should probably warn when it is used elsewhere).

Your second example still doesn't have the array index quoted. The corrected sample would be:

/**
 * @expose
 * @dict
 */
var obj2 = { };
/**
 * @type {number}
 */
obj2['x'] = 321;
alert(obj2['x']);

When corrected, both examples produce the same output of:

alert(321);
