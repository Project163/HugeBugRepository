Title

Zip file timestamps contain spurious millisecond values

Description
Running under Java 8, Commons Compress' timestamps from zip files seem to include a random millisecond value. 

 The workaround we're applying is to round down to the nearest multiple of 1000, a workaround which could move into Commons Compress itself.
