Title

[YSQL] Incorrect global catalog version mode set on tserver start

Description
Jira Link: [Link: DB-10751]
### Description

In recent debugging of a catalog version related bug, I noticed the following logs:

```
I0401 18:37:02.763697 353140 tablet_server.cc:897] set pg_yb_catalog_version table in global mode
I0401 18:37:02.763732 353140 tablet_server.cc:887] set pg_yb_catalog_version table in perdb mode
```

These two logs appear back-to-back. However the test uses per-database catalog version mode from the beginning and there is no such moment that we change from global mode to per-db mode. This is a code bug that while we go through the list of db catalog versions retrieved from the tserver-master heartbeat response, we prematurely set to global mode after processing the very first database item.
