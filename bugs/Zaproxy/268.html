Title

Changing look and feel messes with macOS integrations

Description
**Describe the bug**

When you change the Display setting in the ZAP (Weekly) Setting, like choosing MacOS specific UI overrides (like the native menu bar) doesn't appear anymore. Also instead of showing up as ZAP in the Dock it shows up as Java.

**To Reproduce**
Steps to reproduce the behavior:
1. Download ZAP Weekly on MacOS (Catalina, 10.15.5 (19F101))
2. Go to `Preferences -> Display`
3. Change anything (e.g. set theme to Flat Dark)
4. Shut down Zap
5. Restart Zap
6. ZAP now shows the integrated windows and linux style menu bar, shows java logo instead of the zap logo

**Expected behavior**

Menu Bar renders nativly and App Icon shows correctly. (See initial screenshot)
