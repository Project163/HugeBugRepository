Title

Potential memory leak in stageIdToExecutorSummaries in JobProgressTracker

Description
JobProgressTracker continuously cleans up old metadata as per the spark.ui.retainedStages configuration parameter. It seems however that not all metadata maps are being cleaned, in particular stageIdToExecutorSummaries could grow in an unbounded manner in a long running application.
