Title

Win8.1 Store app inherit from Automapper.Profile generates warning CS1684

Description
Hi,

I am building a Win8.1 Store app and have generated a custom profile class by inheriting from the **Automapper.Profile** class.

Compiling the app generates three instances of this warning message:
_.\packages\AutoMapper.3.3.0\lib\windows8\AutoMapper.dll : warning CS1684: Reference to type 'System.Reflection.BindingFlags' claims it is defined in 'c:\Program Files (x86)\Reference Assemblies\Microsoft\Framework.NETCore\v4.5.1\mscorlib.dll', but it could not be found._

I am also employing **Code Contracts** in my app and this problem further results in a **ccrewrite error**  _Rewrite aborted due to metadata errors._

Is it possible to fix this problem in the Win8.1 Automapper implementation or should I simply remove my dependency on Automapper.Profile.
