Title

Gateway: Failure to read full translog from the gateway

Description
When recovering from the gateway, there might be an error where not all translog operations will be read from it (accompanied with a WARN log message). This has very small chances of happening.

Note, the fix will require a full cluster restart with the flush API called before the shutdown.
