Title

Duplicated ZEPPELIN_INTP_JAVA_OPTS in interpreter processes

Description
Because bin/common.sh is read twice by interpreter processes, ZEPPELIN_INTP_JAVA_OPTS is duplicated. This makes some of the configurations (such as remote debug settings) for interpreter failed
