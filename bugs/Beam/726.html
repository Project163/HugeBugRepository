Title

BeamPython data plane streams data

Description
Currently the default implementation is to buffer all data for the bundle.  

 Experiments were made splitting at arbitrary byte boundaries, but it appears that Java requires messages to be split on element boundaries. For now we should implement that in Python (even if this means not being able to split up large elements among multiple messages).
