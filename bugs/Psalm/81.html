Title

switch(bool) to assert nullability/non-nullability

Description
Currently, `switch(get_class($var)) {` can be used to assert `$var` class. It would be useful if psalm could understand the following as well:
```
php
class A {
   /**
    * @var ?string
    */
... [Log Snipped] ...
  }
}
```
Discussion
- Ah, I haven't encountered that pattern before – I'll make sure that there's a less specific treatment of switch statement case assertions.
- The equivalent function in if-statement form also fails in Psalm:

```
php
function f(A $obj): string {
  if (($obj->a !== null) == true) {
    return $obj->a; // definitely not null
  } elseif (!is_null($obj->b) == true) {
... [Log Snipped] ...
  }
}
```

But it works when simplified:

```
php
function f(A $obj): string {
  if ($obj->a !== null) {
    return $obj->a; // definitely not null
  } elseif (!is_null($obj->b)) {
... [Log Snipped] ...
  }
}
```

and in the spirit of not forcing Psalm to ~understand arbitrarily convoluted algebra~*, I'm going to close this, while opening one to address more basic switch statement logic.

**EDIT** *Psalm now understands all of the above
- OTOH PHPStan [Link: supports this]
so maybe Psalm should as well
- Thanks for this – I've done a bunch of work to improve Psalm's assertion finding, and it now treats switch statements identically to their comparable if statements.
