Title

[Gii, PostgreSQL] hasOne() relationship code generated incorrectly

Description
Hello Guys,

First of all thank you for the amount of work you are putting into Yii2, it's absolutely fantastic to see where it goes.

I think I found an issue with how gii generates model relationship. 

I have a very simple scenario with two tables, one called employee and another one called team. An employee can belong to one team and one team can have multiple employees. Here is the migration I'm using:

```
class m131125_221834_create_basic_schema extends \yii\db\Migration
{
    public function up()
    {
        $this->createTable('employee', [
... [Log Snipped] ...
...
}
```

When gii generates the models for both tables, I can see the following hasOne() relation generated in the Employee model:

```
    /**
     * @return \yii\db\ActiveRelation
     */
    public function getId()
    {
        return $this->hasOne(Team::className(), ['team_id' => 'id']);
    }
```

I think there are two problems with the generated code: 
- the name of the function should be getTeam() instead of getId()
- hasOne() has the link parameter specified the other way around. When I attempt to call the function above I get a message: `Undefined column: 7 ERROR: column "team_id" does not exist LINE 1: SELECT * FROM "team" WHERE "team_id"=$1`. When I replace the link with ['id' => 'team_id'] it works just fine.

To sum it up, I believe the generated function above should look like this:

```
    /**
     * @return \yii\db\ActiveRelation
     */
    public function getTeam()
    {
        return $this->hasOne(Team::className(), ['id' => 'team_id']);
    }
```

It might be an important factor that I'm using the Postgres database engine.

Thank you in advance.
