Title

lsp: hover doesn't parse markdown from texlab

Description
After the recent rounds of improvements, it looks like "text markup" (not code blocks) are no longer parsed and concealed. 

On latest master, with [URL] installed and setup using `nvim-lspconfig`. Then save the following as, say, `test.bib`
```
bib
@article{wuffles,
  author = {Ann Author},
  title = {A note of wuffles},
  journal = {Proceedings of the American Piffles Association},
... [Log Snipped] ...
  year = {1974}
  }
```
 and the following as `test.tex`:
```
tex
\documentclass{article}
\begin{document}

See \cite{wuffles}.
... [Log Snipped] ...
\bibliography{test}
\end{document}
```

Now open `test.tex`, put the cursor on the second `wuffles` (inside the `cite` arguments) and trigger `textDocument/hover`. The hover then shows (literally)
```
Author, Ann. (1974). A note of wuffles. *Proceedings of the American Piffles Association*, *1*(2), 52–55.
```
instead of rendering the markup as italics.

The returned result is
```
{
  contents = {
    kind = "markdown",
    value = "Author, Ann. (1974). A note of wuffles. *Proceedings of the American Piffles Association*, *1*(2), 52–55."
  },
... [Log Snipped] ...
  }
}
```
so properly declared as Markdown.
