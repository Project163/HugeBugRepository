Title

Cake\Http\Client\FormData does not allow "@" symbol as value

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.3.6
* Platform and Target: Apache2 

### What you did
```
$data = [
    'type'  => 'A',
    'name' => '@',
    'content' => ' ',
];
$client->post($base . 'zones/:zone_identifier/dns_records', $data);
```

The above is an example usage for cloudflares dns management.
[URL]

Adding @ as a  **value** should be valid.

### What happened
The key value pair is actually submitted with empty value:
```
 'name' => '', <--- empty string
```

### What you expected to happen
The @ symbol should not be stripped out.


I can see this has a deprecation warning in the FormData class, but this was since 2015
Discussion
- We've not done a breaking change release in the intervening years, so there has been no opportunity to remove the old code.
- Confirmed this bug just a few minutes ago.

```bash
2018-04-20 14:01:21 Warning: Warning (2): finfo::file(ngd2b@afdwg!!) [  'username',
    'password' => '@ngd2b@afdwg!!',
];
```

This was a security problem for us with generated lastpass passwords and had to drop usage of `Cake\Http\Client` in favor of `GuzzleHttp\Client` immediately. A crafted password being passed to the `finfo::file()` could be a problem. Just a heads up for you guys.
