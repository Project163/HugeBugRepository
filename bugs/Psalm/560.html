Title

Unable to determine class of property

Description
I have the following PHP code, which generates an error.
```
php
private function createNamespaceStmts(array $stmts, Stmt $stmt): array
    {
        $stmts[] = $stmt;

... [Log Snipped] ...
        // Rest of the function
}
```

```
ERROR: UndefinedPropertyFetch - src/PhpParser/NodeVisitor/ClassAliasStmtAppender.php:108:22 - Instance property PhpParser\Node\Stmt::$name is not defined
        if (null === $stmt->name) {
```

Psalm could not infer that $stmt must be a Class_ or Interface_ at that point.
When i refactor it like so, psalm does understand:
```diff
- if (false === ($stmt instanceof Class_ || $stmt instanceof Interface_)) {
+ if (!$stmt instanceof Class_ && !$stmt instanceof Interface_) {
```
Discussion
- Yeah, you can also refactor to 

```php
if (!($stmt instanceof Class_ || $stmt instanceof Interface_)) { ... }
```

It's an easy fix, but I'm curious - do you consider that code beautiful?
