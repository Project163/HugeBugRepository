Title

Nested Field Array - Deep append error using formState

Description
**Describe the bug**
This one is a bit hard to explain.
When you have a nested field array and you append one field at the top level and immediately you append a nested field it works as expected. But when you are trying to access to `formState` right when you append a first nested field in a second field it throws an error saying `Uncaught TypeError: get is not a function or its return value is not iterable` 

**To Reproduce**
Steps to reproduce the behavior:
1. Go to the sandbox
2. Click on the add array field button
3. Notice it is working (both, array field and nested array field were appended correctly)
4. Uncomment line `34` that prints `formState`
5. Click on the add array field button
6. It fails with the above-mentioned error.

Extra: (Hope this extra gives you a clue of what is going on)
1. Uncomment line `34` that prints `formState`
2. Click on the remove button
3. Click on the add array field button, twice
4. It fails with the above-mentioned error on the second try.

- [URL]

**Expected behavior**
It should not fail.

**Additional context**
Using react-hook-form v6.8.0
