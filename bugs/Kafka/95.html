Title

Replace numerical compression codes in config with something human readable

Description
Currently we have compression codes like 1 or 2, which is pretty unintuitive. What does 1 mean? 

 We should replace these with human-readable codes like "snappy", "gzip", or "none" and change the documentation. We can continue to support the existing integer codes in addition for backwards compatibility with existing configurations.
