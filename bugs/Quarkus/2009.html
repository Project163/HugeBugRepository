Title

`QuarkusTestBeforeClassCallback` Quarkus JUnit 5 callback fires for every test method

Description
### Describe the bug

According to the class contract of `QuarkusTestBeforeClassCallback`:


This should be equivalent to `@BeforeAll` in JUnit 5, IIUC from the code and various discussion threads. 

### Expected behavior

For a given test class, `QuarkusTestBeforeClassCallback.beforeClass` should be called only once.

### Actual behavior

`QuarkusTestBeforeClassCallback.beforeClass` is called before every test method.

Discussion
- I can confirm that it's a bug. The `QuarkusTestBeforeClassCallback` callback is executed during the invocation of `InvocationInterceptor#interceptTestClassConstructor()` and this JUnit callback is invoked for each test method by default, i.e. with `@TestInstance(Lifecycle.PER_TEST)`. It does work correctly if `@TestInstance(Lifecycle.PER_CLASS)` is used.
