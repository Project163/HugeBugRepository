Title

Make Theme::basePath optional

Description
Theme class uses _basePath_ property only once on init, when it build _pathMap_ if it is empty. But we should set _basePath_ property even we have set _pathMap_. So I suggest to rewrite init method as follows:

```
php
public function init()
{
    parent::init();

... [Log Snipped] ...
    }
}
```

Moreover there is only one method (_Theme::getPath()_) that uses _basePath_ property, but is is never called. So I suggest to remove it.
