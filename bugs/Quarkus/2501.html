Title

UnsupportedOperationException with HTTP Response Code 204

Description
### Describe the bug

Since Quarkus 3.28 the response code 204 (NO CONTENT) ends up in an UnsupportedOperationException using quarkus-rest.

Code:
`return Response.status(Response.Status.NO_CONTENT).build();`
`return Response.status(204).build();  // same behavior`

### Expected behavior

The response code works without any exception.

### Actual behavior

see description

### How to Reproduce?

Just implement a REST endpoint with this one code line mentioned in the description and call the endpoint.
