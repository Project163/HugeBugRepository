Title

Hook output is very noisy

Description
### What happened?

I use a custom hook to sign and notarize a MacOS binary:

```yaml
universal_binaries:
  - replace: true
    hooks:
      post:
        - cmd: script/mac-sign-notarize.sh {{ .Path }}
          output: true
```

I'd like to see output, as it prints information I'd like to see in our automated pipeline, like the notarization ID and request logs. But the output format includes all environment vars, making it:

1. Extremely verbose / hard to read
2. Includes some secret credentials, like AWS access key & session token

Example output:

```
    •   "ticketContents": [                          cmd=[script/mac-sign-notarize.sh dist/lsk-db-connect_darwin_all/lsk-db-connect] env=[PATH=...]
    •     {                                          cmd=[script/mac-sign-notarize.sh dist/lsk-db-connect_darwin_all/lsk-db-connect] env=[PATH=...]
    •       "path": "lsk-db-connect.zip/lsk-db-connect", cmd=[script/mac-sign-notarize.sh dist/lsk-db-connect_darwin_all/lsk-db-connect] env=[PATH=...]
    •       "digestAlgorithm": "SHA-256",            cmd=[script/mac-sign-notarize.sh dist/lsk-db-connect_darwin_all/lsk-db-connect] env=[PATH=...]
[...]
```

Is it possible for this output to not include `env` data unless `--debug` is specified?

### How can we reproduce this?

Set a lot of env vars and run a post-hook for `universal_binaries`
