Title

FileEngine throws invalid character exception

Description
### Description

The following query throws a InvalidArgumentException when combined with FileEngine cache.

```
$entity = $this->Statuses->get($id, [
    'cache' => 'default',
]);
```

If `key` attribute is not provided the default key generated by Table.php contains a colon which triggers the exception.

Table.php
```
if ($cacheConfig) {
    if (!$cacheKey) {
        $cacheKey = sprintf(
            'get:%s.%s%s',
            $this->getConnection()->configName(),
... [Log Snipped] ...
    $query->cache($cacheKey, $cacheConfig);
}
```

FileEngine.php
```
protected function _key($key): string
{
    $key = parent::_key($key);

    if (preg_match('/[\/\\<>?:|*"]/', $key)) {
... [Log Snipped] ...
    return $key;
}
```

Possible solution is to remove and/or replace colon with another allowed character or allow colon in regex eval.



### CakePHP Version

4.2.x

### PHP Version

7.4
