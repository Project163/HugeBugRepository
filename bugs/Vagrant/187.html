Title

Windows reboot is unreliable

Description
### Vagrant version
Vagrant 2.2.6

### Host operating system
Ubuntu 18.04 with the libvirt provider.

### Guest operating system
Windows 2019

### Vagrantfile
```ruby
config.vm.provision "shell", path: "ps.ps1", args: "provision.ps1", reboot: true
```

The full file is at [URL]

### Expected behavior
Reboot should work while ignoring transient errors (like `Errno::ECONNREFUSED`) until it can prove the reboot is done.

It crashed with the following stacktrace:

- Hi there! Thanks for opening an issue with Vagrant. We shouldn't be capturing a blanket Exception here (as it would prevent other errors from surfacing not relating to rebooting), but we can catch things like `Errno::ECONNREFUSED` in this case to make sure we're not missing any exceptions related to waiting for the reboot.
- ... [Middle Discussions Snipped for Brevity] ...
- @rgl I agree with you that just catching `StandardError` is acceptable here, especially since the loop is time boxed and it will still propagate up if the error is originating from something unrelated. #11428 will resolve this issue and be in the next release, so from then on you should stop getting these transient or unexpected errors breaking the wait.
