Title

Empty Pragma header in HttpCache

Description
### What steps will reproduce the problem?

Define any callback in `HttpCache` and check for output headers.
### What is the expected result?

No empty `Pragma` header or a `Pragma` header with some value (according to 14.32 of the [Link: spec]). It looks like there should be no `Pragma` at all.
### What do you get instead?

Empty `Pragma` header (see the [Link: source code]).
### Additional info

| Q | A |
| --- | --- |
| Yii version | 2.0.9 |
| PHP version | 5.6.23 |
| Operating system | Debian |
