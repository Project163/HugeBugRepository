Title

yii\i18n\GettextMessageSource fails to work with .po files generated by yii\console\controllers\MessageController

Description
When I'm trying to use .po files generated by `./yii message/extract` command, `yii\i18n\GettextPoFile::load()` method can not find any translation messages.

I assume it because of `yii\console\controllers\MessageController::generateMessageFile()` method generates only `msgid` and `msgstr` tags, while `yii\i18n\GettextPoFile::load()` expects `msgctxt` tag for translation category also (see [Link: GettextPoFile.php#38]).

P.S. `yii\i18n\GettextMoFile` doen't work also. I've compiled generated .po file with `pocompile` linux tool - Yii can't find any messages too ($separatorPosition is always false at [Link: GettextMoFile.php#108])
