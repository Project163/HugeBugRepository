Title

Schema validation failure when null system ID passed to LSResourceResolver.resolveResource()

Description
The re-working of the EndpointReferenceUtils schema caching logic in 2.2.5 can cause schema validation failures. This is triggered by a null system ID being passed to LSResourceResolver.resolveResource(), so that a direct key lookup in the schemas map fails. In order to locate the schema, a scan though the map searching for an endsWith match is required. 

 The problem manifests on the first schema resolution as: 

  
 SAXException  for  newSchema() on
org.xml.sax.SAXParseException: src-resolve: Cannot resolve the name  'ns1:IllustrationSet'  to a(n)  'type definition'  component.
 
  

 and thereafter as: 

  
 org.apache.cxf.interceptor.Fault: Unmarshalling Error: cvc-elt.1: Cannot find the declaration of element  'generateIllustration' .
Discussion
- Fix  committed  on trunk.
