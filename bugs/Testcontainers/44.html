Title

Stop publishing sources after applying Delombok

Description
As I understand, Testcontainers project uses Lombok library:
* The sources are compiled using Lombok annotation-processor
* Source files are passed through Delombok tool before publishing.

It breaks debugging, as the IDE can't match lines in bytecode with line in the source files.

I see two solutions:
1. First delombok the sources and only then run compilations
1. Publish true sources without applying Delombok tool
IMHO the second solution is more preferable, as Delombok tool sometimes produces sources that can't be compiles.
