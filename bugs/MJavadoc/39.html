Title

Plugin does not accept URL to an offlineLink's location

Description
According to  [URL] the location "is the path or URL to the directory containing the package-list file for the external documentation."  The plugin's OfflineLink.java uses a java.io.File for the argument, which munges it if it's a URL.  Easiest fix might be to just use String instead of File.
