Title

wrong comparison of HTTP Messages in queryEquals() method of HttpMessage class

Description
The method queryEquals(HttpMessage), of org.parosproxy.paros.network.HttpMessage class, compares url and body parameter names of two HTTP Messages. 

The comparison is happening in wrong way, that it is comparing the first HTTP Message to itself, hence returns 'true' always.

        **set1 = getParamNameSet(HtmlParameter.Type.url);
	set2 = getParamNameSet(HtmlParameter.Type.url);**
	if (!set1.equals(set2)) {
	        return false;
	}
	if (getRequestHeader().getMethod().equalsIgnoreCase(HttpRequestHeader.POST)) {
	        
	        **set1 = getParamNameSet(HtmlParameter.Type.form);
		set2 = getParamNameSet(HtmlParameter.Type.form);**	        

		if (!set1.equals(set2)) {
		        return false;
		}
	    }

The following is the correct way to compare the two Messages:

        **set1 = getParamNameSet(HtmlParameter.Type.url);
	set2 = msg.getParamNameSet(HtmlParameter.Type.url);**
	if (!set1.equals(set2)) {
	        return false;
	}
	if (getRequestHeader().getMethod().equalsIgnoreCase(HttpRequestHeader.POST)) {
	        
	        **set1 = getParamNameSet(HtmlParameter.Type.form);
		set2 = msg.getParamNameSet(HtmlParameter.Type.form);**	        

		if (!set1.equals(set2)) {
		        return false;
		}
	    }
