Title

misleading class name: Acl should be Ace

Description
The access control part of the  Content-Package to Feature Model Converter  is a bit confusing to read.... one reason for this: class and method names are misleading. 

  ACL  stands for  Access Control List  but the class  org.apache.sling.feature.cpconverter.acl.Acl  actually captures the information that is stored in a singular  Access Control Entry  (aka ACE), which is the type of objects that go into an ACL. 

 btw: i am also not sure the usage of  acl  in the package name is correct.... what was probably intended was  accesscontrol  in general. 

  cziegeler ,  dsuess ,  karlpauls
