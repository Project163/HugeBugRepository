Title

Update commons-compress to 1.18 due to security issues

Description
Currently most Hive version depends on commons-compress 1.9 or 1.4. Those versions have several security issues:  [URL]

 I propose to upgrade all commons-compress dependencies in all Hive (sub-)projects to at least 1.18. This will also make it easier for future extensions to Hive (serde, udfs, etc.) that have dependencies to commons-compress (e.g.  [URL] to integrate into Hive without upgrading the commons-compress library manually in the Hive lib folder.
Discussion
- Should we be making changes on all the versions, or just in the current (4.0)? 

 I can take this up if nobody is working on it.
