Title

FQL does not handle explicit null/tombstones in prepared statements

Description
FQL will throw an NPE if it attempts to record a successful batch operation containing a null bind value, which we obviously interpret as a tombstone. This means it will be missing from any subsequent dump and completely ignored by replay.
