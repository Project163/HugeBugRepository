Title

[YSQL] Follower reads are not using CONSISTENT_PREFIX on index reads

Description
Jira Link: [Link: DB-1192]
### Description

Follower reads for selects that are looking up the index are not using CONSITENT_PREFIX, but instead using STRONG, so they are getting sent to the leader and not the follower.
Discussion
- It looks like the lookup to the index uses CP. But the following read into the main table using ybctid is using STRONG, since it is created through a code path that does not update the consistency level setting for the request.
