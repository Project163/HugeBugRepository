Title

Optional argument in CanvasRenderingContext2D

Description
What steps will reproduce the problem? 
1. Create the following test file "test.js":

/** @param {CanvasRenderingContext2D} ctx */
var f = function (ctx) {
	ctx.arc(1, 2, 3, 4, 5);
};

2. Compile it with

java -jar compiler.jar --warning_level VERBOSE test.js

 What is the expected output? What do you see instead? 

No warning expected (the output itself is correct). Warning displayed:

test.js:3: WARNING - Function CanvasRenderingContext2D.prototype.arc: called with 5 argument(s). Function requires at least 6 argument(s) and no more than 6 argument(s).
	ctx.arc(1, 2, 3, 4, 5);
	^

0 error(s), 1 warning(s), 100,0% typed
var f=function(a){a.arc(1,2,3,4,5)};

 What version of the product are you using? On what operating system? 

Closure Compiler (http://code.google.com/closure/compiler)
Version: exported
Built on: 2013/04/11 11:30

Mac OS 10.6.8

 Please provide any additional information below. 

Reference document for HTML5 canvas, at [URL] , shows that the 6th argument of arc ("anticlockwise") is optional. In closure-compiler file externs/html5.js, line 265 should read "@param {boolean=} anticlockwise" instead of "@param {boolean} anticlockwise".

There are similar issues with other optional arguments, such as with function CanvasRenderingContext2D.prototype.fill; search "optional" in the W3 reference document.
