Title

[Bug] CaptureOutput in bilib (bisync) restores wrong output for logrus

Description
Regarding CaptureOutput in bilib:

[URL]

First in logrusSave the InfoLevel-Writer ist stored:

[URL]

... which is then later restored as the default output destination of the logger:

[URL]

I think what should be stored instead is the Output of the StandardLogger:

logrusSave := logrus.StandardLogger().Out


Currently, if rclone is used as a library and logrus is used after a call to rc "sync/bisync", logging does not work anymore. It leads to writing to a closed pipe. For example, this leads to a write to a closed pipe:


```
go
import (
	logger "github.com/sirupsen/logrus"
)
...
... [Log Snipped] ...
  logger.Fatal(fmt.Sprintf("sync/bisync failed: %d\n%s", status, out))
}
````
