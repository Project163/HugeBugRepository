Title

Bug in no-extra-bind

Description
I found another bug in this rule.

If the `this` keyword only appears as the parameter to `bind`, it doesn't get registered in the right scope because we've already exited the `FunctionExpression`, but not yet from its associated `CallExpression`.

So in code like this:

``` javascript
var a = function() {
  (function() {
    this.b
  }.bind(this))
}.bind(c)
```

the outer `bind(c)` is marked as unnecessary, even though `this` is actually used in the bound function.

The bug gets fixed (and other tests will also pass) if I replace this:

``` javascript
if (top.depth === 0) {
    top.found++;
}
```

with this:

``` javascript
if (top.depth === 0) {
    top.found++;
} else if (top.depth === -1 && scope.length > 1) {
    var parentOfTop = scope[scope.length - 2];
    parentOfTop.found++;
}
```

It feels slightly hacky, but I'm not sure how to solve it in a cleaner way.

I can submit a PR with this fix if needed.
