Title

Some examples are broken on web due to calling `argh::from_env()`

Description
## Bevy version

Bevy main   (haven't tried to bisect it)

## What you did

Build a bevy example that uses `argh::from_env()` (eg. many_foxes, bevymark, or many_cubes) targeting web (either webgl2 or webgpu).

## What went wrong

It panics on the call to `argh::from_env()` and fails to run.
Discussion
- No need for a fancy bisection. Any of the stress tests that make use of `argh` haven't worked on the web since that was added. Oops.

The most barebones/quick fix might be to use `let args = Args::from_args(&[], &[]).unwrap();` instead of `from_env` for wasm builds. The library sort of works on wasm, just not `from_env`.

Full list:
```
bevymark
many_buttons
many_cubes
many_foxes
text_wrap_debug
```
