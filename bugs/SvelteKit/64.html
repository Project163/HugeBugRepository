Title

returning a status 302 & headers.location from an endpoint breaks after upgrading to latest version with adapter-node

Description
### Describe the bug

Returning a redirect object from an endpoint get function redirects as expected using sveltekit-next.291 with adapter-node next.69.

After upgrading to kit 294 & adapter-node 71, all else being equal, this same function seems to always return an empty object and it therefore falls through to the next route.

### Reproduction

```
js
// src/routes/contact/index.js

/** @type {import('@sveltejs/kit').RequestHandler} */
export async function get({ locals }) {
... [Log Snipped] ...
  }
}
```
### Logs


I've console logged, env variables, hooks handle, getSession, endpoints, every step of the way, the event chain just stops when using this type of redirect in the latest version. Worked as expected before, so I'm fairly sure it's a recent issue.
