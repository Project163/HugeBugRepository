Title

[Bug]: Angular + Webpack not picking up styles, assets and stylePreprocessorOptions from browserTarget after update to version 9.

Description
### Describe the bug

After upgrading from version 8 to 9, it is necessary to add stylePreprocessorOptions in the entry for storybook in the `angular.json` to get `stylePreprocessorOptions.includePaths`. In version 8, the `stylePreprocessorOptions` was picked from whatever entry was configured as `browserTarget` in Storybook.

The config should work as in previous versions to avoid duplications.
 

### Reproduction link

[URL]

### Reproduction steps

In the reproduction link I have the config for `stylePreprocessorOptions.includePaths` duplicated under `storybook` and 'angular-latest:build', if you remove the config from `storybook`, the `@use` at the `button.scss` will stop working as intended.
