Title

Upgrading from v1.19.2 to v1.20.x now requires chmod for syncing files

Description
After upgrading from v1.19.2 to v1.20.1 syncing of files fails with `syncing: chmod ...: operation not permitted` when trying to write data changes.

This was working in v1.19.2 with Restricted ACL mode for the data directory. I would rather not remove Restricted mode as it breaks other programs as it's a SMB share location.

Setup:
- Syncthing v1.20.1, Linux (64-bit Intel/AMD)
- Running on TrueNAS-SCALE-22.02.1 as a docker image
- The data directory is a ZFS dataset with Restricted ACL mode enabled
- The syncthing user account has read and write access to the data directory
