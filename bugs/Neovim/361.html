Title

Neovim used as git editor freezes when typing commit message

Description
### Problem

Hi!

I want to preamble this by saying that I did not find anything from the existing issues. I tried to search for specific keywords that rendered me nothing relevant.

I am having a issue where Neovim freezes when I use it as the editor of Git to insert a commit message.
Basically, I have this in my `.gitconfig`:

```gitconfig
[core]
editor = "nvim --clean"
```

When I want to commit something in a project, I just do `git commit` and it starts Neovim so I can type the message.
When I start typing, suddenly Neovim just freezes and I have to use `kill`.

I did a `git bisect` on the Neovim repository and it said that commit ` ` introduced the problem.

### Steps to reproduce

1. Set Neovim as editor of Git, through `.gitconfig` or `export GIT_EDITOR="nvim --clean"`;
2. In any git repository that has staged changed, just type `git commit`;
3. Neovim will open, go to insert mode and start typing;
4. You will verify that Neovim freezes (hopefully?);

### Expected behavior

Neovim shouldn't freeze at all.

NVIM v0.10.0-dev-2197+g89a9745a1
