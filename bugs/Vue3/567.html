Title

v-bind's same-name shorthand fails (causes crash) in in-DOM templates

Description
### Vue version

3.5.22

### Link to minimal reproduction

[URL]

### Steps to reproduce

Open the reproduction example HTML file in a browser, no build process needed.

### What is expected?

A page showing the following text:

```
Fail #1: param is orz

Pass #1: param is orz

Pass #2: param is orz
```

### What is actually happening?

Got a TypeError: can't access property "type", value is undefined

### System Info

```
shell
System:
    OS: Linux 6.16 Arch Linux
    CPU: (8) x64 11th Gen Intel(R) Core(TM) i7-1165G7 @ 2.80GHz
    Memory: 6.68 GB / 15.35 GB
... [Log Snipped] ...
    pnpm: 9.4.0 - ~/.local/bin/pnpm
    bun: 1.2.14 - ~/.bun/bin/bun
```

### Any additional comments?

The problem only occurs in in-DOM templates. SFCs and ` ` is unaffected and work just fine.
Discussion
- This is a regression in 3.5.22.

You can workaround this problem for now by pinning to version 3.5.21.

For anyone who has encountered this in their live application... If you're using a CDN build of Vue then you should always pin the version in production to ensure your live site doesn't get impacted by regressions in new releases of Vue.
