Title

X-Forwarded-Prefix is ignored by Quarkus REST

Description
### Describe the bug

I am trying create a response in an endpoint with a redirect to another path. 

When using `X-Forwarded-*` headers, quarkus uses `X-Forwarded-Port`, `X-Forwarded-Proto` and `X-Forwarded-Host` to construct a response URI but does not use `X-Forwarded-Prefix`. 

### Expected behavior

I expected `X-Forwarded-Prefix` to be a part of the Location URI in a redirect response. 

### Actual behavior

`X-Forwarded-Prefix` is not a part of the Location URI in a redirect response.
