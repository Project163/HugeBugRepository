Title

Animation: Void => State Ignores Initial Style When Delayed

Description
**I'm submitting a ...**

```
[x] bug report
[ ] feature request
```

**Current behavior**

When animating a transition from `void` to a defined state and delaying this animation, the styling set before the animation is only applied once the delay is over.

**Expected/desired behavior**

The styling set before the animation should be applied immediately and be held until the actual animation starts to prevent flashing.

**Reproduction of the problem**

The code below describes a parallel in/out animation. One box moves in, the other moves out at the same time. (A little bit like a traditional airport departure board.) Since the two should not overlap, the in animation (`void => someState`) needs to be delayed. However, the void element (the one animating in) stays visible until the animation starts, is then hidden instantly, only to start animating in again.

```
transition('void => someState', [
            style({
                transform: 'rotateX(90deg)',
            }),
            animate('400ms 400ms ease-out')
... [Log Snipped] ...
            }))
        ]),
```

Trying to style `void` as well does not work.

**Please tell us about your environment:**
- **Angular version: 2.0.0-rc.2**
- **Browser: Chrome 50.0.2661.102**
- **Language: TypeScript 1.8.10**
