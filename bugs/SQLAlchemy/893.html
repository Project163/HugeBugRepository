Title

pool_pre_ping not detecting dead connection for Firebird database

Description
The `is_disconnect()` method for Firebird dialects check for the following in the error message:

`"Unable to complete network request to host"`
`"Invalid connection state"`
`"Invalid cursor state"`
`"connection shutdown"`

However, the actual error I get is: `"Error writing data to the connection"`
