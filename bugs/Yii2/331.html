Title

Grid View "all" checkbox not change status when all rows are slected

Description
See yii.gridView.js
Line: 129

Should be something like this:

``` javascript
 $(document).off('click.yiiGridView', "input[name='" + options.name + "']:enabled")
                        .on('click.yiiGridView', "input[name='" + options.name + "']:enabled", function () {
                var all = $grid.find("input[name='" + options.name + "']").length == $grid.find("input[name='" + options.name + "']:checked").length;
                $grid.find("input[name='" + options.checkAll + "']").prop('checked', all);
            });
```
