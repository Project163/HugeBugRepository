Description
- You are trying to create a 3 dimensional rotation matrix about a 2 dimensional axis. This doesn't really make sense. You are trying to call the following:

`glm::rotate(const glm::mat4&, const float&, const glm::vec2&)`

The rotation function signature looks like this:

`glm::rotate(const glm::mat4&, const float&, const glm::vec3&)`

Note that it takes a 3 dimensional axis in which the rotation is applied. Are you trying to create a first person style camera?
