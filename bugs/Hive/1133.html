Title

Unit test failures due to unspecified order of results in "show grant" command

Description
A number of unit tests (sometimes) using "show grant" fail, when run on windows or previous failures put the database in an unexpected state. 

 The reason is that the output of "show grant" is not specified to be in any particular order, but the golden files expect it to be. 

 The unit test framework should be extended to handled cases like that.
