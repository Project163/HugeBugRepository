Title

prefer-arrow-callback should not be triggered when a function uses the arguments object.

Description
Arrow functions [Link: do not have their own lexical arguments object], instead inheriting it from the enclosing scope.

A simple example:

``` javascript
function getSomeData(callback) {
  callback(1, 2, 3);
}

getSomeData(function() {
  console.log(arguments);
});
```

This triggers the prefer-arrow-callback rule. If the switch to the arrow function is made:

``` javascript
getSomeData(() => {
  console.log(arguments); // Arrow functions have no arguments object.
});
```

the value of `arguments` is not that which was intended, and will even throw an error in the global scope.

tl;dr The prefer-arrow-callback rule should also check for the use of `arguments`.

This behaviour seen in v1.6.0.
