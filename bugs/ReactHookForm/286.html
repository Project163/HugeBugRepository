Title

isValid is true even if the dynamic required fields are empty

Description
**Describe the bug**
isValid is true even if the dynamic required fields are empty.

**To Reproduce**
Steps to reproduce the behavior:

1. Set the marital status to single. The button is enabled.
2. Set the marital status to married. The button is disabled.
3. Set the marital status to single. The button is enabled.
