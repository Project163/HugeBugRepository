PS: I refactored code in the repo and made public MyJob as suggested
- The reason why this works in the console but not the ide is that the default Quartz CL model looks like:
        loadHelpers = new LinkedList ();

        loadHelpers.add(new LoadingLoaderClassLoadHelper());
        loadHelpers.add(new SimpleClassLoadHelper());
        loadHelpers.add(new ThreadContextClassLoadHelper());
        loadHelpers.add(new InitThreadContextClassLoadHelper());

In the IDE all the job classes are on the Class Path, so ThreadContextClassLoadHelper loads the non-quarkus versions of the class, before the correct ones can be loaded from InitThreadContextClassLoadHelper.
