Title

Access to files bundled with Android Applications

Description
**Is your feature request related to a problem? Please describe.**
Android provides a number of filesystems, one of which allows access to open and read raw files that have been bundled with the application 

**Describe the solution you'd like**
An asset IOsystem that implements an APK loader to `Assimp::DefaultIOSystem` 

**Additional context**
The Android AssetManager presents a lower-level API that permits opening and reading raw files that have been bundled with and Android APK.
