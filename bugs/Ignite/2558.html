Title

Default format of the ignite log doesn't contain a date.

Description
Ignite uses the default pattern layout for the log4j loggers with the  ABSOLUTE  date format.  

 May be the  ISO8601  for default is more useful because  ABSOLUTE  doesn't contain date.
Discussion
- +1 for ISO8601. 
It would be particularly useful for long-running evaluation tests when users don't care about changing log settings.
