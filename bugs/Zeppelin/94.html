Title

Wrong PYTHONPATH when SPARK_HOME is defined.

Description
When SPARK_HOME is defined, PYTHONPATH is defined as 
  
 ${SPARK_HOME}/python/lib/pyspark.zip:${SPARK_HOME}/python/lib/py4j- -src.zip"
 
  

 instead of 
  
 ${SPARK_HOME}/python:${SPARK_HOME}/python/lib/py4j- -src.zip"
