Title

make dist fails on clean build

Description
make dist  tries to distribute lib/cpp/test/tests.xml which is test result file generated by Boost. 
So in a clean source tree where we haven't run  make check , make dist fails. 

 While we can tell how to generate the file in lib/cpp/test/Makefile.am, I think we shouldn't distribute test results.
