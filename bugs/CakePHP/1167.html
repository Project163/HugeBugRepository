Title

removeBehavior does not remove functions from methodMap

Description
### Description

We have a few behaviors that are subclassed from a certain base behavior.

When removing one of those and adding another, the BehaviorRegistry does not update the methodMap, and calling a function from the behavior fails, because the former behavior class is still in the method list.

```
$Table->addBehavior('Subclass1');
$Table->baseclassFunction();
$Table->removeBehavior('Subclass1');
$Table->addBehavior('Subclass2');
$Table->baseclassFunction(); // Fails with "Cannot call basecalssFunction it does not belong to any attached behavior
```



An easy (but not 100% correct) fix would be to change this line in _create:

`$this->_methodMap += $methods['methods'];`

to

`$this->_methodMap = array_merge($this->_methodMap, $methods['methods']);`


Or is there any other way?


### CakePHP Version

4.5.5

### PHP Version

8.1
