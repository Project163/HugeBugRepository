Title

solr.DenseVectorField fieldType without a knnAlgorithm parameter results in error

Description
Following the Dense Vector Search documentation at  [URL]

   

 Using a field definition of  

   
  
 
  <fieldType name= "knn_vector"  class= "solr.DenseVectorField"  vectorDimension= "4"  similarityFunction= "euclidean" />
  <field name= "vector"  type= "knn_vector"  multiValued= " false "  stored= " true " /> 
  
 And then trying to index a document results in an error in solr: 

   

   
  
 
2022-12-13 19:10:08.763 ERROR (qtp3540494-54) [ x:fsnn] o.a.s.s.HttpSolrCall org.apache.solr.common.SolrException:  null  KNN algorithm is not supported => org.apache.solr.common.SolrException:  null  KNN algorithm is not supported
