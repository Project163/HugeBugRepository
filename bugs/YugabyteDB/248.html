Title

[YCQL] 'expression not yet supported' error for old-format index update

Description
When upgrading from pre 1.3.1 version to post 1.3.2 (e.g. 2.0.0) version we need to handle the old-index-format case (no colexpr) on the update path.

To replicate download yb version 1.3.1 or earlier as well as latest (2.0.0):

- Start old version cluster.
```
./bin/yb-ctl create
./bin/cqlsh
```
- Set up table with index in `cqlsh`
```
create keyspace test;
use test;
create table test (a int, b int, c int, primary key (a)) WITH transactions = { 'enabled' : true };
create index test_idx on test(b);
insert into test(a,b,c) values (1,1,1);
insert into test(a,b,c) values (2,2,2);
update test set b = 3 where a = 2;
select * from test;
```

```
 a | b | c
---+---+---
 1 | 1 | 1
 2 | 3 | 2

(2 rows)
```
- Upgrade cluster to new version.
```
./bin/yb-ctl stop && ./bin/yb-ctl start && ./bin/cqlsh
```
- Do an update query (after connecting with `cqlsh`)
```
update test.test set b = 4 where a = 2;
```
This will throw an "Indexing expression is not yet supported" error.
For instance:
```
cqlsh:test> update test set b = 4 where a = 2;
InvalidRequest: Error from server: code=2200 [Invalid query] message="Execution Error. Indexing expression is not yet supported
update test set b = 4 where a = 2;
^^^^^^
 (ql error -300)"
... [Log Snipped] ...
 (ql error -300)"
cqlsh:test> select * from test;
```
