Title

Hybrid Property error when using sql.func return introduced in 1.4

Description
**Describe the bug**
So on 1.3 and earlier versions of Sqlalchemy we were using a hybrid_property to return an sql.func.tstzrange return.  On 1.4 it now causes an AttributeError.

**Expected behavior**
I expected it to work correctly as it did in Sqlalchemy 1.3.

**To Reproduce**
```
py
import datetime
from contextlib import contextmanager
from sqlalchemy import Column, Integer, DateTime, Interval
```
