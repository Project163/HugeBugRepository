Title

SQL: CASE WHEN with NULL result yields NULL column type

Description
If there's a `null` in the results of a CASE WHEN query, the column type is incorrectly set to `null`.

Example: 
```
SELECT (CASE WHEN ({fn DAYOFWEEK("employees"."hire_date")} IN (7, 1)) THEN NULL ELSE "employees"."hire_date" END) AS DOW
FROM "employees"
GROUP BY 1
```
returns:
```
{
  "columns" : [
    {
      "name" : "DOW",
      "type" : "null"
... [Log Snipped] ...
    ],
  ...
```
