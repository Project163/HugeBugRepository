Title

ng1 Component Router doesn't work with 1.5 components / restrict E directives

Description
- **Issue**: ngComponentRouter, in the outlet directive will place the component name as an attribute on a div tag, instead of creating an element for it
- Using Angular 1.5
- Building ngComponentRouter from current angular master
- **Motivation/Use Case**: Exploring migration of ui-router to the ngComponentRouter 

Looking at the [Link: ngOutlet]

``` javascript
this.controller.$$template = '  ';
```

If using a `.directive`, restrict needs to be `AE` as a result, if I am using `.component`, then the element won't display at all, assuming that behind the scenes it only works for elements, not attributes. 

Changing the line to something like:

``` javascript
var dashName =  dashCase(componentName)
this.controller.$$template = ' ' + ' ' 
```

seems to work. 

Also a consideration when working with ngUpgrade, as the comments [Link: indicate that restrict must be 'E']
Discussion
- @e-schultz you can override the restrict to work with the component helper. Its just set to E by default

``` js
angular.module('something').component('home', {
    restrict: 'AE'
});
```
- This is a problem when using with ng-forward as the @Component decorator defaults to restrict: 'E' and currently the is no way to override it.
