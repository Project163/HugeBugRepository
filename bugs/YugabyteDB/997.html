- Inside RemoteTablet::GetRemoteTabletServers, to update replicas:

Acquire shared lock
grab all replicas needs to be updated and save the address pointing to the replica to a vector.
release the shared lock
acquire write lock
update the replicas
It's possible that the vector replicas_ is refreshed between step 3 an 4 and leads to container-overflow issue.

To fix this, we can change RemoteReplica pointers to shared_ptr in case updating on the refreshed elements in the replicas_ vector.
- Since the above can lead to memory corruption, we are back-porting it all the way to 2.14.
