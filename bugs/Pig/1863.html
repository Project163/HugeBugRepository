Title

Pig on Tez AM use too much memory on a small cluster

Description
Pig will use 1024M for AM memory even if "tez.am.resource.memory.mb" is smaller. On a small cluster such as sandbox, the total memory is very small (eg, 2g) and this will make the capacity full and not able to run any job.
