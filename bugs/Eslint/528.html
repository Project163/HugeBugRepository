Title

"allman" option of `brace-style` rule does not perform as documented

Description
According to the documentation, these should cause an error:

```
js
/*eslint brace-style: [2, "allman"]*/

if (foo)
{
... [Log Snipped] ...
  handleError();
}
```

Using current master, I get no errors.
Discussion
