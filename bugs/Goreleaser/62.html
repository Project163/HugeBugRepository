Title

Snapshot build doesn't obey `name_template`

Description
**Describe the bug**

Snapshot build doesn't obey `name_template` and use solely latest tag in its name

**To Reproduce**

Steps to reproduce the behavior:

- Run `goreleaser --snapshot --skip-publish --rm-dist`
- Given following `.gorelaeser.yml`

```
yaml
project_name: terraform-provider-assert
builds:
  - binary: "{{ .ProjectName }}_{{ .Tag }}"
    env:
... [Log Snipped] ...
      # the README and LICENSE files to the archive.
      - none*
```
**Expected behavior**

`dist` folder to contain builds with `SNAPSHOT` and short commit in their names. Instead I got just the most recent tag . See output:

```
pchernikov$ goreleaser --snapshot --skip-publish --rm-dist

   • releasing using goreleaser 0.128.0...
   • loading config file       file=.goreleaser.yml
   • RUNNING BEFORE HOOKS
... [Log Snipped] ...
      • pipe skipped              error=publishing is disabled
   • release succeeded after 3.95s
```
**Environment (please complete the following information):**

- OS: `mac`
- OS version: `Darwin bos-pchernikov-mac.local 19.2.0 Darwin Kernel Version 19.2.0: Sat Nov  9 03:47:04 PST 2019; root:xnu-6153.61.1~20/RELEASE_X86_64 x86_64`
- GoReleaser Version `0.128.0`
Discussion
- Its because you are using `{{ .Tag }}` in your templates, should be `{{ .Version }}` to get the snapshot tag.

Will improve docs.
