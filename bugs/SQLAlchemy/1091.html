Title

How do I get a table's OID with the SQLAlchemy 2.0 API?

Description
**Describe your question**
Using the inspector's `get_table_oid` function is giving me a `NotImplementedError: This method is not implemented for SQLAlchemy 2.0.` error. What is the intended way to get a table's oid with the 2.0 API?

**Example - please use the [Link: Minimal, Complete, and Verifiable] guidelines if possible**
```python
from sqlalchemy import create_engine, inspect
engine = create_engine("postgresql://username:password@localhost/database", future=True)
inspector = inspect(engine)
inspector.get_table_oid('table_name', schema="schema_name")
```

If I remove `future=True` from the `create_engine` call, it works fine.

**Complete stack trace, if applicable**

```
---------------------------------------------------------------------------

      2 engine = create_engine("postgresql://mathesar:mathesar@db/mathesar", future=True)

```

**Versions**
 - OS: Debian GNU/Linux 10 (buster)
 - Python: 3.9.2
 - SQLAlchemy: 1.4.2
 - Database: Postgres 13.2
 - DBAPI: psycopg2 2.8.6
Discussion
- workaround, inspect the connection:

```
with eng.connect() as conn:
   insp = inspect(conn)
```
