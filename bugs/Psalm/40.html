Title

Null coalesce should be treated more kindly

Description
Currently Psalm emits an issue if it sees

```php
$a = $b ?? null;
```

and $b is not defined anywhere. Whereas, it doesn't emit an issue for the functionally equivalent

```php
$a = isset($b) ? $b : null;
```

The former should be treated like the latter.
