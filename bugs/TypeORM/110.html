**Steps to reproduce or a small repository showing the problem:**

According to the [Link: changelog], @DiscriminatorValue was removed in 0.2.0, but [Link: the error message for duplicated discriminators] still suggest to use it. The example below shows the issue after forgetting to change the discriminator:

`entities/user.ts`:

```
ts
@Entity('user')
@TableInheritance({column: {type: 'varchar', name: 'type'}})
export class User {

... [Log Snipped] ...

}
```

`entities/admin.ts`:

```ts
@ChildEntity('admin')
export class Administrator extends User {
}
```

`entities/editor.ts`:

```ts
@ChildEntity('admin')
export class Editor extends User {
}
```
