Title

Error in persisting dates in 0.1.0-alpha.35

Description
I've tried to upgrade from typeorm v0.0.11 to v0.1.0-alpha.35, but ran into an issue.

Consider the following 

### model:

    @Entity()
    export class Tournament {
      @PrimaryGeneratedColumn()
      id: number;

      @Column({ unique: true, length: 200 })
      name: string;

      @Column()
      startDate: Date;

      @Column()
      endDate: Date;
    }

### Controller:

    @Service()
    @JsonController('/tournaments')
    export class TournamentController {
        private repository: Repository ;
        private conn: Connection;

        constructor() {
            this.repository = getConnectionManager().get();.getRepository(Tournament);
        }

        @Post()
        create( @Body() tournament: Tournament) {
            return this.repository.persist(tournament);
        }
    }

### POST Payload

    {
      "id": null,
      "name": "Some name",
      "startDate": "2017-08-28T00:00:00.000Z",
      "endDate": "2017-08-31T23:59:59.999Z"
    }

## Generated query

### typeorm v0.0.11

    INSERT INTO `tournament`(
      `name`, 
      `startDate`, 
      `endDate`
    ) VALUES (
      "Some name",
      "2017-08-28 00:00:00",
      "2017-08-31 23:59:59"
    )

### typeorm v0.1.0-alpha.35

    INSERT INTO `tournament`(
      `id`, 
      `name`, 
      `startDate`, 
      `endDate`
    ) VALUES (
      null,
      "Some name",
      "2017-08-28T00:00:00.000Z",
      "2017-08-31T23:59:59.999Z"
    ) 

I don't know if this is a bug in v0.0.11 for reconstructing the date value from a UTC date to a MySQL compliant date value, or if it's a bug in v0.1.0 for not reconstructing it. I'm creating the date values using momentJS, and I'm trying to keep all my dates in UTC only. As it seems MySQL does not care much for zulu marks in dates and will throw if found.
