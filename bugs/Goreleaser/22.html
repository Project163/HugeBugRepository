Title

where Env is accepted, break if the env is empty

Description
Right now there are already some places where the user can inform things like `.Env.FOO` on a template.

Problem is that if that variable is not available, the user might get things like ` ` somewhere but the process itself don't fail.
Discussion
- Took me a bit of head-scratching, so I'm posting here in the hopes that it finds its way in the appropriate corner of the documentation:

If you'd like to print an empty string whenever a variable is not set (for an optional ldflag, for example), use something like:

```
-X github.com/acme/myproject/main.MyOptionalApiKey={{index .Env "MY_OPTIONAL_API_KEY"}}
```
