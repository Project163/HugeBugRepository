Title

NHTTP transport does not allow to write empty string as a SOAPAction header.

Description
Empty String ("") is a valid value for SOAPAction header but NHTTP transport sender does not allow to send empty String as the value of SOAPAction.  This will be a blocker for Synapse once the   AXIS2-5374   get fixed.
