Title

Text() with Group by causes 'TextClause' object has no attribute 'c'

Description
**Migrated issue, originally created by Kuthair Habboush ([Link: @kuthair])**

I get the following error when trying to apply text() to a group_by clause.

`query = query.group_by(text(group_by))`

**Error:** 'TextClause' object has no attribute 'c'

`SAWarning: Can't resolve label reference 'import_first_name, import...'; converting to text() (this warning may be suppressed after 10 occurrences)`
