Title

space-before-function-parentheses false positive

Description
eslint incorrectly reports an error for this code:

```
js
var k = ''
var a = {
  set b (val) {
    k = val
... [Log Snipped] ...
a.b = 'abc'
console.log(k)
```

Line 3: Missing space before function parentheses.

With this config:

``` json
{
  "space-before-function-parentheses": [2, "always"]
}
```
Discussion
- We probably just forgot to include getters/setters in the check.
- This could be also a problem for generator functions.
- @lo1tuma Seems to me space-before-function-parentheses should ignore anonymous generator functions and let generator-star handle that case?
