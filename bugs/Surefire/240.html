Title

java.lang.NoSuchMethodException when trying to run Junit 3 suite class

Description
attached small demo project demonstrates that JUnit 3 suite classes can't be executed due to NoSuchMethodException. 
surefire 1.8 and 2.9 are affected. BTW I also tested with older surefire versions, here the suite class is completely ignored which is also a bug. 

 We found this bug while porting the tycho surefire plugin to surefire 2.9, see
