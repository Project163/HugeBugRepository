Title

SPDLOG_TRACE doesn't compile when given a variable as the `fmt` argument

Description
```
const char* blah = "I am a string";
SPDLOG_TRACE(logger, blah);
```

This fails to compile with the following errors:

```
myfile.cpp: error: expected ‘)’ before ‘blah’
         SPDLOG_TRACE(logger, blah);
                              ^
spdlog/spdlog.h:175:103: note: in definition of macro ‘SPDLOG_TRACE’
   #define SPDLOG_TRACE(logger, ...) logger->trace("[ " __FILE__ ":" SPDLOG_STR_HELPER(__LINE__) " ] " __VA_ARGS__)
                                                                                                       ^~~~~~~~~~~
```

Using the literal explicitly works fine:

```
SPDLOG_TRACE(logger, "I am a string");
```

This compiles without complaint.

Using variables for arguments past the one representing `fmt` also does the job:

```
const char* blah = "I am a string";
SPDLOG_TRACE(logger, "format string {}", blah);
```

This also compiles. It's only when a variable is used as the first argument (besides the logger).
