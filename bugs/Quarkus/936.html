Title

The property quarkus.kubernetes-config.enabled: "true" is ignored in the Kubernetes configuration

Description
**Describe the bug**
Even you enable the possibility to read the configuration from the k8s config maps via environment varible, quarkus ignore the flag.

**Expected behavior**
The config map is read

**Actual behavior**
The flag is ignored and the config map is ignored


**To Reproduce**
Specify the `quarkus.kubernetes-config.enabled: "true"` in the application.yml like this:

```
  kubernetes:
    env:
      configmaps: my-config-map
      vars:
        quarkus.kubernetes-config.enabled: "true"
  kubernetes-config:
    enabled: false
    config-maps: my-config-map
```

**Configuration**
```
  kubernetes:
    env:
      configmaps: my-config-map
      vars:
        quarkus.kubernetes-config.enabled: "true"
  kubernetes-config:
    enabled: false
    config-maps: my-config-map
```
