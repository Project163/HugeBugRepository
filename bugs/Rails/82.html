Title

exists? method is broken in 4.1.rc1

Description
As of rc1, calling `exists?` on a new record association is broken. 

My app has the following data model:

**home.rb**

``` ruby
has_many :home_users, dependent: :destroy
has_many :users, through: :home_users
```

**user.rb**

``` ruby
has_many :home_users
has_many :homes, through: :home_users
```

**home_user.rb**

``` ruby
belongs_to :home
belongs_to :user
```

See the console log below.

```
ruby
2.1.0 :003 > home = FactoryGirl.create(:home)
...
2.1.0 :004 > user = FactoryGirl.create(:user, home_ids: [home.id])
  Home Load (0.6ms)  SELECT  "homes".* FROM "homes"  WHERE "homes"."id" = $1 LIMIT 1  [["id", 5]]
... [Log Snipped] ...
  Home Exists (0.7ms)  SELECT  1 AS one FROM "homes" INNER JOIN "home_users" ON "homes"."id" = "home_users"."home_id" WHERE "home_users"."user_id" = $1 AND "homes"."id" = 5 LIMIT 1  [["user_id", 7]]
true
```

Do you see the weirdness?

**4.1.rc1**

``` ruby
2.1.0 :005 > user.homes.exists?(id: home.id)
  Home Exists (0.6ms)  SELECT  1 AS one FROM "homes" INNER JOIN "home_users" ON "homes"."id" = "home_users"."home_id" WHERE "home_users"."user_id" = $1 AND "homes"."id" = 5 LIMIT 1  [["user_id", nil]]
false
```

The ID of the newly created User record is nil. I have confirmed that reverting to Rails 4.1.beta1 behaves correctly, and passes in the ID of the User record:

**4.1.beta1**

``` ruby
2.1.0 :007 > user.homes.exists?(id: home.id)
  Home Exists (0.9ms)  SELECT  1 AS one FROM "homes" INNER JOIN "home_users" ON "homes"."id" = "home_users"."home_id" WHERE "home_users"."user_id" = $1 AND "homes"."id" = 6 LIMIT 1  [["user_id", 8]]
true
```
