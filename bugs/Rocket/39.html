Title

No way to resolve route collisions between multiple bundles of static files

Description
Rocket Version: 0.4.0
OS: Windows 10
Description of the bug:

When mounting multiple sets of static files, there is no way to resolve route collisions between them. In my case, the route setup looks like:
```
rocket::custom(config)
	.mount("/api", api::get_routes())
	.mount("/swagger", StaticFiles::from("docs/swagger'))
	.mount("/", StaticFiles::from("web"))
```

The output looks like:
```
Rocket failed to launch due to the following routing collisions:
GET /swagger/  [10] collides with GET /  [10]
GET / collides with GET /
Note: Collisions can usually be resolved by ranking routes.
```

The error makes sense, but looking at the documentation, I cannot see a way to specify route ranks when using StaticFiles.

Thank you very much!
Discussion
- Yeah, unfortunately StaticFiles is hardcoded to a rank of 10. It should be made customizable.

In the meantime, you can still do it [Link: the 0.3 way]. You'll gain control over the ranking, but lose the automatic serving of "/path/to/index.html" when "/path/to" is requested.
- Thank you for the quick answer!
This seems like a reasonable trade-off for my use case.
