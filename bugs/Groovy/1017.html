Title

BindingProxy.setModel() disconnects listeners

Description
I use proxy binding, formerly known as model binding with the Groovy SwingBuilder. 

 Today, I noticed that Groovy removes the property change listeners but does not add them again, when I call BindingProxy#setModel(). So, the GUI gets no updates any more after the first setModel() call. 

 After a look into the source code, I found that this is pretty clear (unless I am missing something): 

 setModel() calls unbind() which sets this.bound = false 
setModel() then calls rebind() which checks if(this.bound) and therefor does nothing. 

 From my point of view, setModel should call bind() instead of rebind().

 import groovy.beans.Bindable 
import groovy.swing.SwingBuilder 
import groovy.util.GroovyTestCase 

 class DummyBean { 
	@Bindable String name 
} 

 class SwingBuilderBindingsTest extends GroovyTestCase { 

 	public void testModel()  
{
		SwingBuilder swing = new SwingBuilder()
		
		def bean = new DummyBean()
		
		swing.bindProxy(bean, id:'dummyBean', bind:true)
		
		// test initial binding
		bean.name = 'Jochen'
		swing.textField(id:'textField', text:swing.dummyBean.name)
		assert swing.textField.text == bean.name
		
		// test for update on bean change
		bean = new DummyBean()
		bean.name = 'Alex'
		swing.dummyBean.setModel(bean)
		assert swing.textField.text == bean.name
		
		// now simply one more live update: test fails here because 
		// setModel() has called rebind() instead of bind()!
		bean.name = 'Danno'
		assert swing.textField.text == bean.name
	}
 }
