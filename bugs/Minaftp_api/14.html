Title

Timestamp values returned by various extension commands such as MDTM, MLSD are incorrect

Description
Various extension commands such as MDTM, MLSD, MLST etc return incorrect timestamp values. The RFC indicates that all timestamp values must be in UTC (GMT). The current version returns these values in local timezone.
Discussion
- Fixed in 1.0.x and 1.1.x in rev 818387.
