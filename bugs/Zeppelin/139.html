Title

Keep "Pending" when restarting interpreter

Description
When some paragraphs have "pending" status and the interpreter gets restarted, the paragraphs persist on "pending" even with the restarted interpreter although they aren't really pending for execution.  

 Scenario: 
1. Take an example note where runtime of one of the paragraphs is larger than the time to restart the corresponding interpreter. 
2. Click on "Run all the notes" button to run all the paragraphs.  
3. When the mentioned paragraph with long execution time starts "running", restart the interpreter. It'll take a while. 
4. Then refresh the page for your note. You may see that the paragraphs after the paragraph that was executing still have the pending status without real execution.
Discussion
- This is an example screenshot when we restarted %spark interpreter when second paragraph (taking one minute to execute) was "running". After refreshing the page we can see that 3rd and 4th paragraphs keep pending forever. Currently, the only way to resolve it is to create new paragraph, copy content there, and delete existing one.
