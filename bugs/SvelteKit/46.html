Title

Text selection is kept when switching between svelte routers - should be resetting?

Description
Text selection is kept when switching between svelte routers(If it is in `$layout.svelte`). I don't know if this shouldn't be cleared by the router by default either?

The `router.js` file just executes `document.body.focus();` every time the router is rebooted:
[URL]
And for the scroll position (conditionally):
[URL]
Should text selection be treated the same?

`document.body.focus();` and `scrollTo(0, 0);` is to simulate a full website refresh.
Should `router.js` be run with a line that resets the text selection:
```javascript
window.getSelection().empty();
```

I emphasize: This is NOT needed directly by me, but I noticed this behavior during experiments with sveltekit.
Discussion
- This is intentional — the thinking is that it's better for accessibility if client-side navigation has the same behaviour as a full page refresh. We may make this behaviour customisable in future
- Hang on, I totally misunderstood. Yes, we should be resetting the selection — good catch, thanks
