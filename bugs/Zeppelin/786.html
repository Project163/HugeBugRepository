Title

Spark version specified in Dockerfile doesn't exist anymore

Description
The 3 Dockerfiles for building and configuring the image on the 3 supported types of Spark cluster currently are referencing Spark version 2.1.1 which is not available in the Apache mirror. 

 Thus we should change the version to the current 2.1.2.
