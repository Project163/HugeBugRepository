Title

url(label: 'test') { CDATA(body) }

Description
Groovy Markup with both content data and attribute doesn't work. I have testet both with MarkupBuilder and DOMBuilder. 

 I have tested the following which doesn't work: 
url(label: 'test')  
{ ['some text content'] }
 url(label: 'test')  
{ 'some text content' }
 url(label: 'test')  ['some text content']  

 This work, only attribute: 
url(label: 'test') 

 This work, only content: 
url('some text content') 

 What should the correct syntax be?
Discussion
- Streaming markup has a special element called yield. This causes the text to be added to the document with no tags so: 

 td(width:'30%') { 
    yield getReturnType(meth) 
} 

 emits <td width='30%'>int</td> 

 it is also used to produce mixed content: 

 li { 
    b "returns" 
    yield ": ${returnType}" 
} 

 emits: <li><b>returns</b>: int</li> 

 perhaps MarkupBuilder could use the same mechanism?
- Is it possible in straming markup to override it getting an element named yield? 

 But its ok for me if the builders also gets this special yield element. Just now I need it atleast working with DOMBuilder.
