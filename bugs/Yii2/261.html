Title

mssql (dblib) driver does not support getting attributes

Description
The MSSQL PDO Driver for Linux (dblib) does not support getting attributes. 
When `\yii\db\mssql\QueryBuilder` check for old mssql version, it uses the `PDO::getAttribute(PDO::ATTR_SERVER_VERSION)` method to get the server version, and this causes an exception.
I don't know for windows mssql/sqlsrv driver.

I'm not sure this is the best way to correct this, but this works for me, and can be extended in the future to get more attributes. In `\yii\db\mssql\PDO` added the following method :
