Description
### Describe the bug

Due to recent [Link: change] in `svelte-check` v4.0.3, following type error occurs while importing Svelte 5 component in svelte storybook file. This also ends up causing multiple type errors in the story args definition.

```typescript
Error: Type 'Component ' is not assignable to type 'ComponentType , any>'.
  Type 'Component ' provides no match for the signature 'new (options: ComponentConstructorOptions >): { [x: string]: any; $destroy: () => void; $on:  (type: K, callback: (e: any) => void) => () => void; $set: (props: Partial ) => void; }'. 
```

As per [Link: PR], In svelte 5, components are functions. Hence with this PR only function type is exported in runes mode.

I tried to supply svelte 5 component to `Meta` as `Meta >`. However, it throws following error after that change.

```typescript
Error: Type '{ $on?(type: string, callback: (e: any) => void): () => void; $set?(props: Partial ): void; }' is not assignable to type 'ComponentType  void): () => void; $set?(props: Partial ): void; }, any>'.
  Type '{ $on?(type: string, callback: (e: any) => void): () => void; $set?(props: Partial ): void; }' provides no match for the signature 'new (options: ComponentConstructorOptions  void): () => void; $set?(props: Partial ): void; }>): { ...; }'.
