Title

Syncthing switches off verbose logging after receiving sync event

Description
Hello.

When I run Syncthing in verbose mode using the command `syncthing -verbose`, it logs verbosely as expected until I change some files on my other device and syncing occurs.
So after a sync intiated by the other device, I stop seeing VERBOSE level messages in my terminal.
Only INFO level messages continue to appear.

This is my terminal output with obfuscated device IDs:
[URL]
You can look at timestamps. When verbose mode was working normally, messages were coming very often, few times per second. Then a sync from my other device occured and verbose logging stopped. Only rare INFO messages were coming. "scanning" and "idle" events in web GUI were still observable, so Syncthing apparently hasn't stopped working, it just went into non-verbose output mode in terminal.
