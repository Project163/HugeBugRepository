Title

How to set multiple cookies?

Description
How can I set multiple cookies in one response?
I tried two things:

1. Use one `&Cookies` argument:

```
rust
#[post("/accounts/login", format="application/json", data = " ")]
fn login(db: State ,
         data: JSON ,
         cookies: &Cookies)
... [Log Snipped] ...
    }
}
```

2. Use two `&Cookies` arguments:

```
rust
#[post("/accounts/login", format="application/json", data = " ")]
fn login(db: State ,
         data: JSON ,
         u_cookies: &Cookies,
... [Log Snipped] ...
    }
}
```

It doesn't matter the response only contains one `Set-Cookie` header :(
Discussion
- Just confirmed that this is a bug. Investigating the issue now.
- The issue stems from Hyper in what appears to be a present limitation. In particular, I assumed that calling [Link: set_raw] using the same header name would set multiple versions of the header, but this appears to be incorrect. As a result, only one `Set-Header` header gets sent to the client. It does not appear that there is any way to set multiple headers of the same name in Hyper at the moment.

I've pinged @seanmonstar to try to resolve this.
- so how do i add multiple cookies to a jar? i'm trying to add two named "_ga" and nothing works
- That is not possible, due to HTTP itself - cookie names must be unique, unless they have a different domain+path from each other.
