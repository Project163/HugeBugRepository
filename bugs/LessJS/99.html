Title

Combining Media Query Variables

Description
I have variables set up to manage my breakpoints in responsive stylesheets. Combining variables into one media query with the "and" combiner returns an error, for example: `@media @thinScreen and @shortScreen { .Container { padding: 5px; } }`

You can copy and paste this more detailed example code into [URL] to see the errors on each of the commented out lines.

```
less
////////////////////////////////////////
// This portion compiles just fine
////////////////////////////////////////

... [Log Snipped] ...
//@only: ~"only screen and ";
//@media @only @thinScreen { };
```

Tested in 1.3.3 and 1.4.0 with no luck. Any workarounds other than the combined variable or will this bug just have to be squashed?
Discussion
- Your main issue is that you're not using string interpolation to get variables into the strings using the `@{var}` syntax.

However, I'd recommend the following approach anyways since it's way easier to reference the media queries in the rest of your stylesheet. This should work in 1.3.3 and 1.4

```
@tablet-width: 500px;
@tablet: ~"screen and (max-width: @{tablet-width})";

div {
  @media @tablet {
    color: red;
  }
}
```
- I agree about the approach you suggested as a good route to take for targeting specific devices. Not sure that the string interpolation is really the issue here.

It is still odd that combining statements or specifying "only screen and" requires a new variable for each. Why shouldn't `@media @tablet and @highdensity { }` work? Seems silly to require extra variables to combine statements like that.
