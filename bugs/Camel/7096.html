Title

camel-jbang - Transform route to yaml with CBR cannot load into Karavan

Description
The route dump  
  
 
- route:
    from:
      uri: timer
      parameters:
        timerName: java
        period:  "{{time:1000}}" 
      steps:
        - setBody:
            simple:
              expression:  "Hello Camel from ${routeId}" 
        - choice:
            steps:
              - when:
                  simple:
                    expression:  "${header.foo} ==  'bar' " 
                  steps:
                    - to:
                        uri: direct
                        parameters:
                          name: bar
              - otherwise:
                  steps:
                    - to:
                        uri: direct
                        parameters:
                          name: cheese
                    - log:
                        message:  "${body}"   
  
 Cannot be loaded into Karavan or Kaoto. It may be the predicates that should be in the long form 

 expression 
  simple 
     expression 

 or something.
Discussion
- This is the java test code that dumped the yaml 
  
 
 public   class  Test  extends  RouteBuilder {

    @Override
     public  void configure()  throws  Exception {

         // Write your routes here,  for  example:
         from( "timer:java?period={{time:1000}}" )
            .setBody()
                .simple( "Hello Camel from ${routeId}" )
            .choice()
              .when(simple( "${header.foo} ==  'bar' " ))
                .to( "direct:bar" )
              .otherwise()
                .to( "direct:cheese" )
            .log( "${body}" );
    }
}
- It looks like the culprit is the `steps` under `choice`, rather `when` and `ohterwise` should come right under `choice` without `steps`
