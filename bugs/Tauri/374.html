Title

[bug] Tauri mistakenly handles PNG24 icon

Description
### Describe the bug

When use a 24bit PNG file as icon, the program will panic:
```
 `thread 'main' panicked at 'data.len() must fit the width, height, and row_stride', /gdk-pixbuf-0.15.11/src/pixbuf.rs:52:13`
```

TAURI treats any PNG files as RGBA, and that is incorrect.

[URL]

To fix this problem, we can get the color type of PNG icon by `reader.output_color_type()`, but the `png` crate does not provide an API for transforming other color types to RGBA. We should use crate `image` for the transformation.

Or just simply add a assert here, outputting some friendly information if the icon is not RGBA.
