Title

Bazel does not honor custom CA certificates

Description
### Description of the problem:

When I try to use Bazel in an environment with TLS only working with custom CA certificates, it does not work (e.g. download dependencies).

One of the errors is:

```
ERROR: An error occurred during the fetch of repository 'zlib':
   java.io.IOException: Error downloading [https://zlib.net/zlib-1.2.11.tar.gz] to /home/abergmei/.cache/bazel/_bazel_user/ /external/zlib/zlib-1.2.11.tar.gz: PKIX path building failed: sun.security.provider.certpath.SunCertPathBuilderException: unable to find valid certification path to requested target
```

### Bugs: what's the simplest, easiest way to reproduce this bug? Please provide a minimal example if possible.

Have a non-rooted CA, which intercepts all HTTPS calls in your network.

### What operating system are you running Bazel on?

Ubuntu 18.04

### What's the output of `bazel info release`?

`release 1.2.1`

###  Have you found anything relevant by searching the web?

### Any other information, logs, or outputs that you want to share?

Tried executing via `JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64 bazelisk build --host_javabase '@local_jdk//:jdk' //mytarget` but the error persists. Not sure though, that it really uses my local JDK.

Is there any way of forcing the bundled JDK to use a certs database outside of Bazel?
Discussion
- It does seem to work when using:

```
JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64 bazelisk --host_jvm_args '-Djavax.net.ssl.trustStore=/etc/ssl/certs/java/cacerts' build --host_javabase '@local_jdk//:jdk' //mytarget```
- when add custom cert by keytool `keytool -import -alias ca -keystore /root/.cache/bazel/_bazel_root/install/ /_embedded_binaries/embedded_tools/jdk/lib/security/cacerts -file /root/ca.cer`, it will cause `FATAL: corrupt installation: file '/root/.cache/bazel/_bazel_root/install/ /_embedded_binaries/embedded_tools/jdk/lib/security/cacerts' is missing or modified.  Please remove '/root/.cache/bazel/_bazel_root/install/ ' and try again.` error.
