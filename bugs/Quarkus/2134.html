Title

Hibernate schema validation is flaky and fails due missing tables (while the tables are present)

Description
### Describe the bug

When running integration tests on the project - it fails around 10% of the time locally, and more often on CI. The error shown is `java.lang.RuntimeException: Failed to start quarkus` ... `Caused by: org.hibernate.tool.schema.spi.SchemaManagementException: Schema-validation: missing table [Limits]`. 

I saw there was already an issue created about the same flakiness earlier ([Link]) and it was closed due to the missing reproducible, so I stripped down the project to the minimal setup when the issue still happens and made it available here - [Link]. 

### Expected behavior

No flakiness while executing integration tests

### Actual behavior

flaky around 10% of the time on my local machine, more often on CI. Perhaps can be triggered more often with restrained resources.
