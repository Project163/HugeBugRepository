Title

[bug] Migration tool append unnecessary createUpdaterArtifacts config

Description
### Describe the bug

After building the application, an error occurs: `Error failed to build bundler settings: failed to get updater configuration: plugins > updater doesn't exist`.
When I removed `"createUpdaterArtifacts":  "v1Compatible"` from `tauri.conf.json`, the bundle was created properly.
I guess `"createUpdaterArtifacts":  "v1Compatible"` config is unnecessary unless the updater functionality is used.

### Reproduction

`tauri build -d` after migrating from v1 app without using "Updater" functionality.
