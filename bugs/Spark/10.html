Title

Passing bad master address to SparkContext results in unhelpful Mesos error message

 ```

... [Log Snipped] ...
java: /root/mesos/build/../src/common/try.hpp:77: T Try<T>::get() const  [with T = mesos::internal::MasterDetector*] : Assertion `state == SOME' failed. 
/root/scala-2.9.1.final/bin/scala: line 161:  2801 Aborted                 "${JAVACMD:=java}" $JAVA_OPTS "${java_args [@] }" ${CPSELECT}${TOOL_CLASSPATH} -Dscala.usejavacp=true -Dscala.home="$SCALA_HOME" -Denv.emacs="$EMACS" $CYGWIN_JLINE_TERMINAL scala.tools.nsc.MainGenericRunner "$@" 
```
