Title

RESTEasy Reactive streaming resource methods leads to NoSuchMethodException in native mode

Description
### Describe the bug

[URL] changed `Serialisers.NO_ANNOTATION` to `context.getAllAnnotations()` so now all streamed methods needs to be registered for reflection (or change impl.)

### Expected behavior

I can call RESTEasy Reactive endpoint that returns `Multi` (meaning these that are not already registered for reflection)
