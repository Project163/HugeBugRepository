Title

Profile switches that change audio settings (e.g. sample rate, channels) do not prompt user to restart

Description
You could argue this is a feature request I suppose but here it is

## Platform
Operating system and version: Windows
OBS Studio version: 25.0.8

## Expected Behavior
If you switch to a profile that changes settings requiring OBS to be restarted, the user should be prompted to restart OBS.

## Current Behavior
Nothing happens so the user doesn't know they need to restart

## Steps to Reproduce
1. Create 2 Profiles - call them... say... carrot and parsnip
2. Change the audio channels setting in the parsnip profile to 5.1
3. Restart OBS as prompted
4. Switch to the carrot profile and notice nothing really happens
5. Cry when you stream to Twitch but find out iOS users can only watch on 360p

Would you like a carrot?
