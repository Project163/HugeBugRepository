Title

Fix child operator references after NonBlockingOpDeDupProc

Description
The optimizer proc called 'NonBlockingOpDeDupProc' combines Sel-Sel or Fil-Fil into a single operator.  However, some references to the old (removed) child still remain in the optimizer context, and mess up further optimizer procs.
Discussion
- This patch fixes references in JoinContext.  I discovered the outdated references while trying to run a join optimizer that runs after this one.
