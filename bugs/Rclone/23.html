Title

swift: Timeout sometimes uploading to Rackspace Cloudfiles

Description
I am running about 25 builders on buildbot, and on every build about 2-5 builds fail to upload to cloudfiles with the following timeout:

```
2015/05/07 03:15:43 dists/cloudmonitoring/main/binary-i386/Packages.gz: Failed to copy: Timeout when reading or writing data
```

Usually a subsequent build works fine.
Discussion
