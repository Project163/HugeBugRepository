Title

Intersection of iterables should contain elements that are intersection of iterable type params

Description
[URL]
```
php
 &iterable  $i */
... [Log Snipped] ...
    }
  }
```
Currently psalm complains that `takesB($c)` is invalid (`$c` is treated as being *only* `A`). But `iterable &iterable ` is equivalent to `iterable ` (and that does not complain)
Discussion
- Similarly, psalm currently does not accept the following:
```php
  /** @psalm-var iterable &iterable  $data */
  $data = [];
  takesIterableOfIntersections($data); // defined above
```
- I'm not *entirely* sure this is a bug, but I agree that Psalm should probably rewrite `iterable &iterable ` to `iterable ` as a convenience.
- This should probably apply to other generics as well
