Title

EDT accessed in daemon mode

Description
Issue reported in OWASP ZAP User Group: [URL]

Steps to reproduce the issue:
1. Run ZAP in daemon mode;
2. Open a site while proxy through ZAP;
3. Note that in the threads created there are "AWT-EventQueue-0" and "AWT-Shutdown", threads related to view (Swing).

Remarks:
This might lead to exceptions while passive scanning since the passive scan thread is interrupted when a message is proxied:

```

    java.lang.InterruptedException
        at java.lang.Object.wait(Native Method)
        at java.lang.Object.wait(Object.java:503)
        at sun.awt.AWTAutoShutdown.activateBlockerThread(AWTAutoShutdown.java:349)

        at org.zaproxy.zap.extension.pscan.PassiveScanThread.run(Unknown Source)
```

ZAP Versions:
Versions >= 1.0.0
