Title

Avoid NPE when processing CFF2 based fonts

Description
PDFBOX-5631   adds rendering support for CFF-based fonts. That support is limited to CFF based fonts. The newer CFF2 format isn't supported which may lead to a NPE while loading local fonts when creating the font cache.
