Title

pre_ping settings not propagated when recreating pools

Description
The docs state for `Pool.recreate()`:


but `pre_ping`'s value (and a couple other values) is not passed to the class constructed in all classes inheriting Pool.

So if we chose to set pre_ping to True and disposed the engine, that setting defaults back to False.

engine.dispose()
