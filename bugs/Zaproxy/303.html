Title

Improve add-on update file handling

Description
When ZAP updates add-ons it tries to delete/update old files (the ones bundled in the add-on and the add-on itself) but in Windows that might not always work, it says the files are in use or open (other OSes allow to delete the files anyway).

This is most noticeable with WebDrivers add-ons which provide binaries, that might indeed be in use if the user launched a browser from within ZAP. If that happens the binaries might remain with the old version until the user manually deletes them.

ZAP should not assume that can delete the files. Ideally the update itself should not require to delete any files for the new add-on version to work properly. Any required clean ups should probably be done on a following start to ensure that the old files are no longer in use.
