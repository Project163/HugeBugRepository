Title

CSS XML Namespace selectors

Description
LESS does not appear to support CSS namespace selectors (http://www.w3.org/TR/css3-selectors/#typenmsp), nor does it seem that one can escape it using ~'@namespace ...'. or ~'[namespace|class~="classname"]'. Is there a solution?

It is genuinely handy in some apps to differentiate between, say, core classes and ones that have been added via another source by using namespaces, plus you can avoid conflicts. It doesn't seem to me that HTML5 custom attributes are an equivalent or have the native support that the class and id attribute do.
