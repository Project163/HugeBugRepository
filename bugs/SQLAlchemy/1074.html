Title

[1.4] Correlate and correlate_except calls mapper configure when used in column_property

Description
Running the example below in 1.3 would not configure the mapper when a select with `correlate_except` is used in a `column_property`. In 1.4 it's instead called. 
This causes issues while importing classes, since not all files may be imported before mapper configure is called leading to unknown class errors.

**Describe the bug**
```
py
import sqlalchemy as sa
import sqlalchemy.orm

try:
... [Log Snipped] ...
sa.orm.configure_mappers()
print("done")
```

**Expected behavior**
In 1.3 this gets printed:
```
class loaded. call configure_mappers()
done
```
in 1.4 isntead (ignoring the as_scalar warning)
```
class loaded. call configure_mappers()
done
```

Using the table instead of the class seems to be a viable workaround:
```py
    barNum = sa.orm.column_property(
        sa.select([sa.func.count(Bar.id)])
        .where(Bar.foo_id == id)
        .correlate_except(Bar.__table__)
        .as_scalar()
    )
```

 - OS: -
 - Python: 3.8
 - SQLAlchemy: master/rel_1_3
 - Database: -
 - DBAPI: -
