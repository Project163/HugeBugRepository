Title

TimeHelper i18nFormat gives always UTC

Description
_Ubuntu 14.04, PHP 5.5.9, MySQL 5.5.4, CakePHP 3.0-3.2_

I have dates saved as UTC in my DB. When I call in my template:

`$this->Time->nice($date, 'Europe/Berlin');`

times get correctly converted into GMT+1.

But when I use:

`$this->Time->format($date, 'HH:mm', null, 'Europe/Berlin') ;`

it is still UTC, which is not correct.

I think, the source of this problem lies in View/Helper/TimeHelper.php::i18nFormat:336:

here the Time object is constructed with the target timezone, which is wrong. I think it should be:

`$time = new Time($date);`

Bye

``` php
public function testFormatTimeInstance()

    $this->assertTimeFormat($expected, $result);
}
```
