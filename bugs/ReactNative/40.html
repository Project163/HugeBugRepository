## Description
on android, setting accessibilityRole to "header" for view component does not have any effect when talkback turn on, they will neither be pronounced with heading suffix nor can navigate by heading (when talkback turn on, "navigation by heading" can be turn on by swiping up)

## Reproducible Step:

sample code:
```
 Welcome to React Native! 
 To get started, edit App.js 
 blah,blah 
```
1. turn on talkback in setting -> accessibility -> talkback
2. launch react native app
3. tap on `  `, there is no "heading" suffix pronounced
4. swiping up to switch "navigation mode" to "heading", and the ` ` component can not be found as "heading"
