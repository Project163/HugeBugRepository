Title

Addon-contexts: switching tab causes SB crash

Description
**Describe the bug**
When using `@storybook/addon-contexts@5.2.0-alpha.xx` with addons which use toolbar (e.g. viewport addon) and create tabs (e.g. notes addon), switching to `Canvas` tab causes page crash.

**To Reproduce**
Steps to reproduce the behavior:
1. `yarn add -D @storybook/addon-contexts@5.2.0-alpha.36 @storybook/addon-viewport@5.2.0-alpha.36 @storybook/addon-notes@5.2.0-alpha.36` then configure them
2. Launch SB
3. Click `Notes` tab
