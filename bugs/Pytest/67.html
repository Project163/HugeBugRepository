Title

--fixtures only shows fixtures from first file

Description
If I have two files:

`test_a.py`:

```
python
import pytest

@pytest.fixture
def fix_a():
... [Log Snipped] ...
def test_a(fix_a):
    pass
```

and `test_b.py`:

```
python
import pytest

@pytest.fixture
def fix_b():
... [Log Snipped] ...
```
