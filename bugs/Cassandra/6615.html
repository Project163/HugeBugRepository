Title

Fix Min/Max aggregation function on reversed types

Description
Cassandra version  

 5.0.3 

 docker run --name cassandra -d cassandra:5 

 docker exec -it cassandra cqlsh 

   

  Data schema   
  
 
CREATE KEYSPACE IF NOT EXISTS test WITH replication = {  'class' :  'SimpleStrategy' ,  'replication_factor' : 1 } AND durable_writes =  true ; 

USE test;

CREATE TABLE data(
  sensor_id text,
  time timestamp,
  value  double ,
  PRIMARY KEY (sensor_id, time)
) WITH CLUSTERING ORDER BY (time DESC)
  AND compaction = { 'class' :  'TimeWindowCompactionStrategy'  }; 

INSERT INTO data (sensor_id, time, value) VALUES ( 's1' , 0,    1);
INSERT INTO data (sensor_id, time, value) VALUES ( 's1' , 1000, 2); 
  
   

  Actual result  
  
 
SELECT min(time), max(time) FROM data WHERE sensor_id =  's1' ; 

system.min(time)                | system.max(time)
---------------------------------+---------------------------------
 1970-01-01 00:00:01.000000+0000 | 1970-01-01 00:00:00.000000+0000(1 rows) 
  
   

  Expected result  { } 

 On cassandra 4 (tested with 4.1.8) everything is working fine 
  
 
SELECT min(time), max(time) FROM data WHERE sensor_id =  's1' ; 

system.min(time)                | system.max(time)
---------------------------------+---------------------------------
 1970-01-01 00:00:00.000000+0000 | 1970-01-01 00:00:01.000000+0000(1 rows) 
  
  Note  

 If we'll change clustering order from DESC to ASC then problem disappear
