Title

FTP: Passive transfer fails because curl tries only a single IP address

Description
### I did this

```
./curl -v -x [URL] -p ftp://mirror.switch.ch/doc/standard/rfc/26xx/2616.txt
```

Output:
```
* STATE: INIT => CONNECT handle  ; line 1410 (connection #-5000)
* Added connection 0. The cache now contains 1 members
*   Trying ::1...
* TCP_NODELAY set
* STATE: CONNECT => WAITCONNECT handle  ; line 1462 (connection #0)
... [Log Snipped] ...
* Expire cleared
curl: (8) Failed to connect to localhost port 3128: Connection refused
```

Squid 2.7.STABLE9 runs on localhost:3128. This old version does not support IPv6.


### I expected the following

The download should succeed. After switching to passive mode (EPSV), curl should try all IP addresses for "localhost". Currently it tries ::1, but it should also try  .

### curl/libcurl version

curl 7.54.1-DEV

### operating system

Linux
