Title

use-json-log; uses Error Stream on Windows instead to log to logfile

Description
Hi There!

If I use the following command, the JSON Messages go to the screen but logfile stays empty.
```
rclone.exe copy "C:\temp\Source" "C:\temp\Destination" --use-json-log -v --log-file="C:\temp\Destination\Rclone.log"
``` 
With the help of PowerShell I noticed that all Text was displayed RED

So If I redirect the Error Stream to a file I get the Messages into the file. Like desired
See code here:
```
rclone.exe copy "C:\temp\Source" "C:\temp\Destination" --use-json-log -v > "C:\temp\Destination\Rclone.log" 2>&1
``` 
Attached a full -vv Log (catch with the error Stream 2>&1 )
