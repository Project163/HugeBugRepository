Title

Groovy JDK File.eachFileMatch insufficient documentation to use the method.

Description
The documentation in the File.eachFilematch entry of the Groovy JDK does not give enough information to make use of the method quickly and easily.
Discussion
- I am thinking even just one simple example embedded in the Javadoc would be enough to make this passable.
- The doc now includes the following examples: 
  
  // collect names of files in baseDir matching supplied regex pattern
  import   static  groovy.io.FileType.*
def names = []
baseDir.eachFileMatch FILES, ~/foo\d\.txt/, { names << it.name }
 assert  names == [ 'foo1.txt' ,  'foo2.txt' ]

 // remove all *.bak files in baseDir
 baseDir.eachFileMatch FILES, ~/.*\.bak/, { File bak -> bak.delete() }

 // print out files > 4K in size from baseDir
 baseDir.eachFileMatch FILES, {  new  File(baseDir, it).size() > 4096 }, { println  "$it.name ${it.size()}"  }
