Title

Update Tomcat version used by HttpFS and KMS to latest 6.x version

Description
KMS and HttpFS are using Tomcat 6.0.37, we should move it to 6.0.41 to get bug fixes and security fixes. 

 We should add a property with the tomcat version in the hadoop-project POM and use that property from KMS and HttpFS.
