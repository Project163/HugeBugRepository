Title

Email::getHeaderCharset() doesn't default to regular charset

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.8.6

### What you did
Construct an Email instance with $config['headerCharset'], call `reset()` then call `getHeaderCharset()`.

In 3.8.6, `getHeaderCharset()` does not default to `charset` if `headerCharset` is null despite documentation.  Instead, this default value is only set in the constructor.

```
/**
     * Charset the email header is sent in
     * If null, the $charset property will be used as default
     *
     * @var string|null
... [Log Snipped] ...
    return $this->headerCharset;
}
```

In 4.x, this was refactored into the Message class where the default replacement is only done in `getHeaderCharset()`.

```
public function getHeaderCharset(): string
{
    return $this->headerCharset ?: $this->charset;
}
```

Just something I noticed while reviewing charset encoding with [URL]
