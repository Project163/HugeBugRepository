Discussion
- Both destPath & destFile are serving same purpose. You may want to get rid of one of those to simplify this.
- I worry about the code assuming that the return code of rename() is relevant. It's one of the key bits of API ambiguity, where HDFS sometimes behaves differently from Posix filesystems —nobody knows quite what to do. I'd rely on the filesystems throwing an exception if something serious went wrong, and just logging at warn here.
