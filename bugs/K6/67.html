Title

Http response.request.headers are missing "host" value

Description
If you set a value for "host" in the header of a http.post request, that value gets stripped from the response-objects .request.header property. Minor issue but I was asked to report it.

## Environment
k6 v0.28.0 ((devel), go1.14.9, windows/amd64)

## Steps to Reproduce the Problem
```
import http from "k6/http";

export default function main() {
    let r = http.post("[URL] "body", { headers: { "foo": "bar", "host": "[URL] } });
    console.log(JSON.stringify(r.request.headers));
}

```
Discussion
- Thanks for reporting this! I suspect this issue is caused by this `switch`: [URL]

And maybe a simple `fallthrough` (or rewriting the switch to a simple `if strings.ToLower(key) == "host"` and always setting the header value) would be enough to fix it, but whoever ends up doing that should read up on the Go `net/http` docs and maybe the RFC, as well as test things thoroughly, so we don't mess up something else.
