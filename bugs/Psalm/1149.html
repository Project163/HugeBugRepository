Title

Unable to suppress ParamNameMismatch error.

Description
The `ParamNameMismatch` error cannot be suppressed using the `@psalm-suppress` annotation in a method's docblock.

For e.g. argument names of `format()` method here [URL] don't match the names used in interface [URL]

Adding a `@psalm-suppress ParamNameMismatch` in docblock of `SprintfFormatter::format()` doesn't suppress the error. I have read the [Link: various other ways] to prevent this error from being reported but I only want to prevent reporting for one off cases.

I am unable to provide a standalone example for this since the tool on pslam.dev doesn't seem to report the `ParamNameMismatch` error.
