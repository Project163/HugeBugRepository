Title

Zoom behaviour on SVG with pinch: wrong translation reference

Description
Zoom behaviour always works as expected with scroll and drag events.
If pinch is involved (tested in Safari on iPhone, iPad) it still works fine if zoom behaviour is attached to CANVAS element.
If it's attached to the G element inside the SVG tag, pinch to zoom works as expected only if the SVG element is located at the top of the page.
If SVG element appears around 700px below, zooming with pinch doesn't keep the zoom centre in the location of fingers, but moves the whole G element down.
On the other hand, if SVG element's position style is set to 'fixed' or 'absolute' with any value for 'top', zoom centre stays at the touch point.
