Title

@PostConstruct interceptor method returning Object works only if it's private

Description
InterceptorGenerator incorrectly assumes that return type from a @PostConstruct method is void, but the specification allows Object too (https://docs.oracle.com/javaee/7/api/javax/annotation/PostConstruct.html).

When the method is private, it will work because InterceptorGenerator will use a reflection fallback and find the method to invoke by name and param types only (so the return type doesn't matter): [URL]
