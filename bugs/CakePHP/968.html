Discussion
- Looks like this issue was caused by changes in #11978. The `ExceptionRenderer` is now passed the request instead of it being retrieved from `Router` via `getRequest(true)` as it was in 3.6.

Because your request is using a `.json` extension the request that ends up in `ExceptionRenderer` doesn't have routing applied and the parsed extension is not present. The same problem does not occur if a request is sent with `Accept: application/json` in the headers. I've got an idea on how to fix this and should have a pull request up soon.
- You can use

```php
// in ErrorController
$this->RequestHandler->renderAs($this, 'json');
```

to force it (I use it in 3.6)
