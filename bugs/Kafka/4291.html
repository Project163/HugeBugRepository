Title

Memory leak using range scans

Description
We introduced a regression bug in AK 4.1.0 release, when range scans are use. We are leaking some metrics/sensors. 

 Thanks to  eduwerc  and  hermankj  for reporting this issue. 

 Anybody who is using iterator, ie, any type of all/rang/prefix scan etc is affected. Note that certain DSL operators like session-windows, sliding-windows, stream-stream joins, and FK-join all use range scans internally, so the number of affected users is expected to be quite high.
