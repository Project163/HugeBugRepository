Title

"groovy -help" doesn't mention -cp option (also groovysh, groovyconsole etc.)

Description
"groovy -help" doesn't mention the -cp option for setting the classpath.
Discussion
- Yes I was looking for this option the other day. Did not know it was there actually. 

 I think it's a must that it's added to the usage description.
- Also, -cp and --classpath on windows do not properly allow spaces in the supplied classpath in 1.5.7. 

 C:_sources\src - xxxx yyyy>groovy -cp "C:_deployments\xxxx yyyy\temp_build" groovylink.groovy

groovy, groovyc, groovydoc, groovysh and groovyConsole
