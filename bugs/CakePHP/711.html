Title

commandline disable log output to screen

Description
Hi,

I'm working in command line with cake shell. But I have to disable output to cli. You can do that by calling shell with -q flag. But when you want to log something to file (with $this->log('text', 'debug')). It also appears on the screen. I think this should not be happen when you use the -q flag.

I need it to be quiet because the process is included in an other php process as child. and it only needs to send correct data to the parent and no logs.
