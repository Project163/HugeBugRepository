Title

Misleading/Erroneous signatures in Panache Hibernate Kotlin

Description
**Describe the bug**
Several signatures in the `PanacheCompanion` indicate that the result of function call may be `null`, e.g. `PanacheCompanion .findById(id: Id): Entity?` or `PanacheQuery .singleResult(): Entity?`.

**Expected behavior**
Invoking a function with a nullable result type returns `null` instead of throwing an exception; like e.g. `PanacheQuery .firstResult(): Entity?`.

**Actual behavior**
```
javax.persistence.NoResultException: No entity found for query
	at org.hibernate.query.internal.AbstractProducedQuery.getSingleResult(AbstractProducedQuery.java:1583)
	at io.quarkus.hibernate.orm.panache.common.runtime.CommonPanacheQueryImpl.singleResult(CommonPanacheQueryImpl.java:299)
	at io.quarkus.hibernate.orm.panache.kotlin.runtime.PanacheQueryImpl.singleResult(PanacheQueryImpl.java:171)
```
