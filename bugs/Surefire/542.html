Title

Surefire incorrectly suppresses exceptions when closing resources.

Description
There are various places where exceptions thrown when closing resources are suppressed although they should be handled. Additionally, the  PrintStream  class does not throw exceptions but provides a  checkError  method to be used instead. This method has not been used after writing to the  PrintStream .
