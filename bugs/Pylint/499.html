Title

ModuleNotFound error with pylint-django plugin

Description
### Bug description

Starting with pylint 2.15, running pylint on a Django project with the `pylint_django` plugin enabled results in a `ModuleNotFound` exception.  Bisecting points to commit   as the one that exposes the issue.  The reason the exception occurs is that when `_astroid_module_checker()` opens the the `pylint_django` plugin, `pylint_django` attempts to import the Django settings module.  However, the import path has not been fixed up at this point, so the module cannot be found, thus the exception.  I already have a fix working on my machine and thus hope to have a PR ready shortly.

### Configuration

```ini
[MAIN]
load-plugins = pylint_django
```

### Command used

```shell
DJANGO_SETTINGS_MODULE=demosite.settings pylint polls/models.py
```

### Pylint output

```
shell
Using env: /home/dharding/.virtualenvs/demosite

    sys.exit(run_pylint())
... [Log Snipped] ...
  File " ", line 973, in _find_and_load_unlocked
ModuleNotFoundError: No module named 'demosite'

### Expected behavior

Normal output without crashing, e.g.
```
