Title

Edit credentials.yml.enc will remove the Symbolic Link

Description
### Steps to reproduce
 
create a Symbolic Link for credentials.yml.enc
ln -s /shared/config/credentials.yml.enc  /current/config/credentials.yml.enc
The eidt the current/config/credetnials.yml.enc and save
### Expected behavior
 
credentials.yml.enc -> /shared/config/credentials.yml.enc
### Actual behavior
 
credentials.yml.enc
The symbolic link has been removed

### Releated Code
activesupport/lib/active_support/encrypted_file.rb

def write(contents)
  IO.binwrite "#{content_path}.tmp", encrypt(contents)
  FileUtils.mv "#{content_path}.tmp", content_path
end

That mv make the credentials.yml.enc become a new file, which will remove the symbolic link
Discussion
- What OS are you using?
- I try both macOS High Sierra and amazon AMI
- I have the same issue with Rails `6.0` on the master branch. It is relevant if you use capistrano to deploy your Rails application, you are symlinking the `credentials.yml.enc` and you edit the file using `rails credentials:edit`.

My workaround is to copy the  `current/config/credentials.yml.enc` to `shared/config/credentials.yml.enc` after the changes have been done.
