Title

inference_mode causes segfault

Description
## 🐛 Bug

## To Reproduce

Steps to reproduce the behavior:

1. Create new, empty conda environment
2. Run ```conda install pytorch cpuonly -c pytorch-nightly```

Run
```
import torch
with torch.inference_mode():
    torch.nn.Linear(9, 64)
```
which results in a segmentation fault.

When run outside of inference_mode context the code succeeds

```
import torch
torch.nn.Linear(9, 64)
```

## Expected behavior

Don't segfault.
