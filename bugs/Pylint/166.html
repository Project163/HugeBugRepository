Title

io.StringIO should not be an old-style class

Description
Originally reported by: **Alexey Kotlyarov (BitBucket: [Link: koterpillar], GitHub: @koterpillar?)**

---

The following code:

``` python
import io

class MyIO(io.StringIO):
    def __init__(self, *args, **kwargs):
        super(MyIO, self).__init__(*args, **kwargs)
```

gives a warning:

```
************* Module stringiotype
E:  5, 4: Use of super on an old style class (super-on-old-class)
```

However, `io.StringIO` appears to be a new-style class and `super()` works correctly on it.

Python 2.7.10, Pylint 1.5.1, astroid 1.4.1
