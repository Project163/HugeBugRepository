Title

Entropy key is not resolved if flink-s3-fs-hadoop is added as a plugin

Description
Using flink 1.10 

 I added the flink-s3-fs-hadoop jar in plugins dir but I am seeing the checkpoints paths like  s3://my_app/_ ENTROPY _/app_name-staging/flink/checkpoints/ /chk-3071  which means the entropy injection key is not being resolved. After some debugging I found that in the  EntropyInjector  we check if the given fileSystem is of type  SafetyNetWrapperFileSystem  and if so we check if the delegate is of type  EntropyInjectingFileSystem  but don't check for   ClassLoaderFixingFileSystem    which would be the type if S3 file system dependencies are added as a plugin.
