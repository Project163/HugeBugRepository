- @christianfrank84  I just verified the steps again and can't see a problem. Here is what I did:

1. Checked out ExoPlayer and changed to dev-v2 branch:
```
git clone [URL]
cd ExoPlayer
git checkout dev-v2
```
2. Created a new empty Android Studio project in `../Project`. The directory structure now looks like this (among others):
```
root/ExoPlayer/common_library_config.gradle
root/ExoPlayer/core_settings.gradle
root/Project/setting.gradle
```
3. Modified `setting.gradle` to end with the following lines:
```
gradle.ext.exoplayerRoot = '../ExoPlayer'
gradle.ext.exoplayerModulePrefix = 'exoplayer-'
apply from: new File(gradle.ext.exoplayerRoot, 'core_settings.gradle')
```
4. Ran gradle sync and now have all exoplayer modules as source.
