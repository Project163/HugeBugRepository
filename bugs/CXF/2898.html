Title

Don't register default application if no services discovered

Description
In certain cases, the CXF CDI integration may be included blindly in a framework.  In these cases, if the user does not provide any JAX-RS resources the integration will fail to deploy a server.  This scenario should be handled gracefully by not registering the application.
