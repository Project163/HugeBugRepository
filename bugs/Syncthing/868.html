Title

irreversible Local Additions after re-adding the same folder as Receive Only

Description
This is a long-standing problem that I have experienced multiple times, but only now I have managed to reproduce it.

1. On Device 1, create a new folder called `test1`.
2. In the folder `test1`, create a folder called `1`.
3. In the folder `1`, create a file called `1`.
3. On Device 2, create a new folder called `test2`.
4. In the folder `test2`, create a folder called `2`.
5. In the folder `2`, create a file called `2`.

The first steps are done on the file system level, not in Syncthing.

5. On Device 1, add the `test1` folder to Syncthing, and share it with Device 2.
6. On Device 2, accept the folder as SR, pointing it at the `test2` folder.
7. The contents of the two folders have been merged and synced.

   [Image: image]
   [Image: image]


8. On Device 2, remove the folder from Syncthing.
9. Then, re-add it again, but this time as RO.
10. The folder is now marked as "Local Additions".

    [Image: image]
    [Image: image]
    [Image: image]

11. Reverting local changes doesn't clear all the errors either.

    [Image: image]

    ```
    INFO: Revert: directory has been deleted on a remote device but is not empty; the contents are probably ignored on that remote device, but not locally
    ```
