- Finally got to look at your example in more detail.  ProxyGenerator  is working as expected. It supplies by default method implementations which throw UnsupportedOperationException. There is a setEmptyMethods(boolean) flag which causes it to just have empty implementations. 

 In your case, given that you are using the static method flavor you need to go: 
  
 ProxyGenerator.INSTANCE.emptyMethods =  true 
 
  

 It is debatable whether we should have flipped the default for that flag but at least you have the mechanism to choose. The other thing you might find useful is to turn on the debug flag, i.e.: 
  
 ProxyGenerator.INSTANCE.debug =  true 
 
  

 This will show you what is being generated for you under the covers. Just remember to turn the debug flag off again before you are finished.
