Title

winget: `PackageVersion` should not be prefixed with `v`

Description
### What happened?

For winget, all 3 files are generated with a `PackageVersion` prop prefixed with `v` like:

```yaml
PackageVersion: v1.2.3
```

This is not accepted by winget. It should not include `v`:

```yaml
PackageVersion: 1.2.3
```

### How can we reproduce this?

You can take our repository as an example: [URL]
