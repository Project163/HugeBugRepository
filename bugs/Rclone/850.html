Discussion
- The convention rclone uses is that you don't need an initial `/` in a remote name. Like all conventions there are a couple of backends which care about this (eg `local`, `sftp`, `dropbox`) but by and large you shouldn't start your remote names with `/`.

That said we do go to some effort to strip off un-needed `/` in a lot of the backends, because people love putting them in, so I think we can class this as a bug.
