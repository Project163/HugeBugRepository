Title

Tensor.masked_fill treats DoubleTensor masks as BoolTensor masks of all False

Description
### 🐛 Describe the bug

Tensor.masked_fill treats a DoubleTensor mask as a BoolTensor of all False, which as @ramiro050 pointed out [Link: is inconsistent with masked_select]. Is this expected behavior or should passing a DoubleTensor produce a runtime error like it does for masked_select?
