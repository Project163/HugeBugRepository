Title

HealthCheck is broken for KafkaConsumer

Description
Since Camel 4.x there is no ComponentsHealthCheckRepository class anymore. So 
the code 
  
 
healthCheckRepository = HealthCheckHelper.getHealthCheckRepository(
                 endpoint.getCamelContext(),
                 "components" ,
                WritableHealthCheckRepository.class);

 
  
 can't load the HealthCheckRepository 

 The current KafkaConsumerHealthCheckIT can't catch this error because it use 
  
 
        final  Collection<HealthCheck.Result> res = HealthCheckHelper.invokeReadiness(context);
        final   boolean  down = res.stream().allMatch(r -> r.getState().equals(HealthCheck.State.DOWN));
        Assertions.assertTrue(down,  "readiness check" );
 
  
 However as res is an empty List so res.stream().allMatch() always return true, so actually can't test the HealthCheck status.
