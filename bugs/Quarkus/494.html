Title

Calling long-running JPA operation from non-reactive REST service causes exception

Description
**Describe the bug**
When processing of the REST call takes a long time, it will end with either 

```
java.lang.IllegalStateException: You have attempted to perform a blocking operation on an IO thread.
```

or

```
ARJUNA016029: SynchronizationImple.afterCompletion - failed for io.quarkus.hibernate.orm.runtime.entitymanager.TransactionScopedEntityManager$1@5e290947 with exception: java.util.ConcurrentModificationException
```

**Expected behavior**
Non-reactive API should not complain about blocking operation and just execute it.

**Actual behavior**
Call throws an exception.

**To Reproduce**
Steps to reproduce the behavior:
1. Create REST service and repository
2. Make operation long (for example, do a long-running query repeating a couple of hundred times)
3. Call the REST service
