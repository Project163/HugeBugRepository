Title

sqlalchemy test suite fails when run under a directory called "test"

Description
### Describe the bug

If you put sqlalchemy in a directory called "test", the test suite will fail. It doesn't have to be the direct parent, it can be an ancestor directory.

### To Reproduce

```python
cd /tmp
mkdir test
cd test
git clone [URL]
cd sqlalchemy
tox -e py38-sqlite
# fails
```
