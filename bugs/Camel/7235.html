Title

camel-main: DataFormat auto configuration does not work

Description
Not sure if I miss something obvious, but I don't see data format auto configuration being applied correctly when using camel-main. 

 I attached a reproducer with camel-csv, where application.properties has camel.dataformat.csv.ignore-surrounding-spaces = true. The result from the unmarshal should be: 
  
 
[[One], [Two], [Three]]
 
  
 But it shows as the following, because the ignore-surrounding-spaces is not applied: 
  
 
[[One   ], [Two   ], [Three]]
 
  
 I see the DataFormat get instantiated twice. First here: 

  [URL]

 The property binding is done against that instance. 

 But later the DataFormat ends up being created again here: 

  [URL]

 No property binding is done against this instance, effectively ignoring the auto configuration.
Discussion
- Its a bit because Java DSL creates a new instance which essentially could be configured as well. So the general auto configured properties should then be re-applied here as well.
