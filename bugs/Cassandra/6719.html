Title

Non-serial reads/range reads need to be done through Accord for Accord to support async apply/commit

Description
Currently they haven't been implemented. We have a path forward for it using ephemeral reads.
Discussion
- An important thing to account for in implementing this is that when migrating from Accord to Paxos it's important that non-serial reads perform Accord key barriers just like Paxos otherwise non-serial writes that were done through Accord will not be visible since Accord may have done asynchronous commit.
- Another thing to keep in mind is that `TxnQuery` will need validate that range reads against Accord are against ranges that are managed by Accord in the epoch that the read executes in. 

 `TxnQuery` also currently has a problem with its validation where it doesn't have access to the migration information for the epoch of the transaction and just has whatever the latest information is.
