Title

For comprehensions should create a scope

Description
According to [Link: Starlark spec], this code should print `1`:

```
x = 1
_ = [x for x in [2]]            # new variable x is local to the comprehension
print(x)                        # 1
```

However, when running latest master, it results in error:

```
$ bazel run //src/main/java/com/google/devtools/starlark:Starlark -- `pwd`/compr.sky
...
Traceback (most recent call last):
	File "", line 4
		print(x)
	File "", line 4, in print
		x
global variable 'x' is referenced before assignment.
```

Run from bazel master, revision  , Sep 25 2019.
