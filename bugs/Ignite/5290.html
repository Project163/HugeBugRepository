Title

Assertion on histogram update if currentTimeMillis decreases

Description
Histogram metric classes ( HistogramMetricImpl ,  PeriodicHistogramMetricImpl ) assume that timestamp is always increasing, but in some cases method  U.currentTimeMillis()  can return decreasing values (for example, if time was set manually or on NTP sync). In these cases assertion can be thrown on histogram update: 
  
 java.lang.AssertionError: null
at org.apache.ignite.internal.processors.metric.impl.HistogramMetricImpl.value(HistogramMetricImpl.java:61) ~[classes/:?]
at org.apache.ignite.internal.util.StripedExecutor$Stripe.body(StripedExecutor.java:643) [classes/:?]
at org.apache.ignite.internal.util.worker.GridWorker.run(GridWorker.java:125) [classes/:?]

 We should fix  PeriodicHistogramMetricImpl#add  and  HistogramMetricImpl#value  methods to work correctly with decreasing timestamps.
