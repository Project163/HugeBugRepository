Title

Vault requires extension quarkus-vertx-core in 1.12.0.CR1

Description
**Describe the bug**
If the app uses the vault extension, a dependency on `quarkus-vertx-core` must be explicitly added for the native build to succeed.
This is related to getting the vault extension to use mutiny instead of the ok http client.
The solution is either to add `quarkus-vertx-core` into the vault extension as a dependency (the easiest and more maintainable), or replicate some of the customizations that are done to make vertx run in native mode.
Probably related to [URL]
the [Link: vertx] shows also many graalvm options that need to be added to support a native build.

**Expected behavior**
Adding an explicit dependency on `quarkus-vertx-core` should not be required.
