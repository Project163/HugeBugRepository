**Current behavior**
 
Currently when you have `ContentChild(TemplateRef)` it is not working correctly. Because after init you get different TemplateRef object as you get after another ContentCheck. 

If you have following html
```
html
 
     
         
             ok 
... [Log Snipped] ...
     
 
```

If your `grabber` component have `@ContentChild(TemplateRef)` and in `ngAfterContentInit()` method you will use this template, ` ` element is used.

But if you use this template again, not during `ngAfterContentInit()` method call you get ` bad ` template.

This is pretty awfull bug. 
Thanks for help

**Expected behavior**
 
It should return same template during init phase and also after another check of content. And also there is no explaination why `descendants: true` were set. This means that correct template in this case is div? If so, then during init phase this is not considered.
