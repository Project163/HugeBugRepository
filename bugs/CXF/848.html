Discussion
- Your problem is probably msv. However, this code was designed to fade away silently if anything was missing. I guess that the InstantiationException is more than it bargained for. 

 From parent/pom.xml: 

  
 

            <!--  if  we use the  new  woodstox artifact, we're using the  new  version -->
            <dependency>
                <groupId>org.codehaus.woodstox</groupId>
                <artifactId>woodstox-core-asl</artifactId>
                <version>4.0.8</version>
            </dependency>
            <dependency>
                <groupId>net.java.dev.msv</groupId>
                <artifactId>msv-core</artifactId>
                <version>${cxf.msv.version}</version>
            </dependency>
- Yes, you resolve my problem. 
That's work fine now with all of these lib : 
 
	 woodstox-core-asl-4.0.8.jar 
	 stax2-api-3.0.2.jar 
	 msv.jar (build 20090415) 
 

 I think file WHICH_JARS in lib directory should contain this required lib.
