Title

Model compilation problems when `additionalProperties: true`

Description
## Problem statement
When generating models (client for sure, maybe also for server), and the model has `additionalProperties: true`, the generated MarshalJSON/UnmarshalJSON functions have compilation errors.

Please remove the sections that don't apply

## Swagger specification
```
yaml
---
  swagger: "2.0"
  info:
"This is a sample server Petstore server.  You can find out more about Swagger at [Link: [URL] or on [Link: irc.freenode.net, #swagger].  For this sample, you can use the api key `special-key` to test the authorization filters."
... [Log Snipped] ...
"Find out more about Swagger"
    url: "[URL]
```
## Steps to reproduce
`$ swagger generate client -f ./petstore.yml`

```
$ go build ./...
# ./models
models/pet.go:103: cannot use stage2 (type map[string]interface {}) as type *Pet in assignment
models/pet.go:151: invalid argument m (type Pet) for len
```

If you comment out the `additionalProperties: true` bit, then the generation works properly.
