Title

EnumUtils .ToString() throws for elements not known to the receiving end

Description
If a new enum value gets added, an older client or server that uses the  ToString()  method of the surrounding element throws an exception (invalid ordinal value) if the new value is used in the data.
Discussion
- Had to drop EnumUtils<>.ToString() support for versions below Rio, since the  pType^.TypeData  member is not (officially) supported there. Without MinValue and MaxValue info we cannot guarantee that  value  is inside the legal enum range.
