Discussion
- Sorry to dig this back up but I am seeing this same issue if Note has an `id` that is just a `PrimaryColumn` of type string also. I am trying to store data where the unique id is coming from another service and its a string, so I would like that string to be the primary key for the table.  That table also will have a OneToMany/ManyToOne relationship.

It seems that something is forcing id to be an `int` even though I have specified it to be a `varchar`

```
 @PrimaryColumn()
```
