Title

StringTemplate vsprintf error with %20 (URL encoded space)

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.3.8

### What you did
```php
 add(['test' => '  {{text}}']);
echo $stringTemplate->format('test', ['text' => 'formatted text']);
```

### What happened
`Warning (2): vsprintf(): Too few arguments [CORE/src/View/StringTemplate.php, line 246]`

### What you expected to happen
`  formatted text`

It is caused by `%20`: [URL]
Discussion
- It's not a bug.

You have to escape using two `%%` characters.

```
$stringTemplate->add(['test' => '  {{text}}']);
```
- That said, it should be noted that whitespace in URLs should always be avoided completely.
Use slugs or at least replace those whitespace characters with underscore/dash instead.
- ... [Middle Discussions Snipped for Brevity] ...
- Fixed by not using StringTemplate for this. Perhaps this issue will help others facing this, because it can also happens with something else than HTML containing `%`.
- We could/should be replacing `%` in variables with `%%` where we know it is not a sprintf placeholder in my opinion. Allowing recursive variable replacements sounds like a feature I don't think we want.
