Title

Extra newline generated from 'toyaml' function which is not removed even by an {{- end }}

Description
Created a values.yaml file with the following:
```
labels:
  tier: frontend
  foo: bar
  foo3: bar3
```

and a template with the following:
```
apiVersion: v1
kind: ConfigMap
metadata:
  name: "bug bug"
data:
{{- if .Values.labels }}
{{ toYaml .Values.labels | indent 2 }}{{- end }}
  bug: yes
```

When I run a dry run it returns:
```
[debug] Created tunnel using local port: '41519'

[debug] SERVER: " :41519"

[debug] Original chart version: ""
... [Log Snipped] ...

  bug: yes
```

The empty line above `bug: yes` has the 2 spaces from the indent but the `{{- end }}` should have removed them (or better yet not passed back the extra line from the toyaml function
```
helm version
Client: &version.Version{SemVer:"v2.8.0", GitCommit:" ", GitTreeState:"clean"}
Server: &version.Version{SemVer:"v2.8.0", GitCommit:" ", GitTreeState:"clean"}
```

### Update 1
So why does [Link: Go text/template] not chomp toYaml output? I think it might be because toYaml outputs a newLine followed by indentation whitespace!

### Update 2
Everything that is outputted by evaluating `{{ }}` will be hands off for the `go text/template` whitespace chomping. For example if you would write `{{if true}}{{ print "This ends with new lines\n\n" }}{{- end }}` you still have the new lines.

__Conclusion__
This solution suggestion won't happen, as it would suddenly expect the go text/template whitespace chomping to invade outputs of other `{{ }}`.

- So far I've managed to workaround this issue by calling `trim` on the `toYaml` output.
By doing something like this:
```
{{- range $i, $vol := .Values.volumes }}
        - name: {{ $vol.name }}
{{ toYaml $vol.path | trim | indent 10 }}
{{- end }}
```

I got the following output:
```
volumes:
        - name: log-volume
          hostPath:
            path: /var/log/foo
        - name: process-comm
... [Log Snipped] ...
          configMap:
            name: foo-config
```
- My current practice, that I'm quite happy with, is to write...

```yaml
something:
  {{- .Values.somethingElse | toYaml | trimSuffix "\n" | nindent 2 }}
```

trimSuffix resolves this issue, nindent instead of indent adds a new line before the content and that combined with a whitespace left chomp makes the indentation of the template code look good as well.
