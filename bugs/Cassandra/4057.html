Discussion
- The suspect thing is this line "Received Prepare (0 requests, 0 files}" 

 Why would it be receiving nothing?
- CASSANDRA-6992   made bootstrap to sequentially connect each node after one node is prepared to stream. 
It is done by receiving PREPARED even from StreamSession, but when streaming 0 file like above, the event does not happen(just skip to COMPLETE), and lead to stream hang.
- As  yukim  noticed, the problem was caused by   CASSANDRA-6992   and only happens in case one of the nodes involved in a boostrap stream has no data to stream, so the prepare step is skipped in favor of complete. Created  dtest  to reproduce the issue and trivial 3.3 patch to connect to next node in case a session with the previous node is completed.
