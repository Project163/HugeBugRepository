Title

Cannot install chart on private Artifactory registry with self-signed cert

Description
We are using the Artifactory Helm plugin on Artifactory version `6.13.1`. When installing a chart in a repository via `helm install`, the following error occurs:

```shell
» helm install --generate-name helm-virtual/foo
Error: failed to download "helm-virtual/foo" (hint: running `helm repo update` may help)
```
This repository was added with a specified CA file:

```shell
» helm repo add helm-virtual $ARTIFACTORY_URL/artifactory/helm-virtual --username $USER --password $PASS --ca-file=/tmp/artifactory.crt
"helm-virtual" has been added to your repositories
```

This is confirmed by checking `~/.helm/repository/repositories.yaml`.

By changing the following to be hard coded, I can get past this error:
