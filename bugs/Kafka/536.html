Title

AdminUtils.deleteTopic does not work

Description
the AdminUtils:.deleteTopic method is implemented as 

  
     def deleteTopic(zkClient: ZkClient, topic:  String ) {
        ZkUtils.createPersistentPath(zkClient, ZkUtils.getDeleteTopicPath(topic))
    }
 
  

 but the DeleteTopicCommand actually does 

  
     zkClient =  new  ZkClient(zkConnect, 30000, 30000, ZKStringSerializer)
    zkClient.deleteRecursive(ZkUtils.getTopicPath(topic))
 
  

 so I guess, that the 'createPersistentPath' above should actually be  

  
     def deleteTopic(zkClient: ZkClient, topic:  String ) {
        ZkUtils.deletePathRecursive(zkClient, ZkUtils.getTopicPath(topic))
    }
Discussion
- Delete topic is not supported in  . It is implemented in trunk, but hasn't been fully tested. The way this works is not to delete the topic path directly. Instead, it first indicates in a separate path that we want to delete a topic. Once all data related to the topic is deleted, the controller will then delete the topic path.
