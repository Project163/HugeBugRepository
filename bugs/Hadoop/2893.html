Title

S3A to support HTTPS web proxies

Description
Currently, we cannot set the protocol for a proxy in S3A. The proxy protocol is set to "http" by default and thus we lack the support for HTTPS proxy in S3A.
Discussion
- When we design how to configure this with S3A, it would be good to think about it in the context of AWS SDK V2 (  HADOOP-18073  ) since that changes a bit how the client is setup. cc  ahmarsu   passaro
- In SDK V2, we construct the endpoint URI ourselves. this is different to V1, where for eg: you would do something like  
  
 
awsConf.setProxyHost(proxyHost); 
awsConf.setProxyPort(proxyPort); 
  
 see  S3A's proxy config . 

 In V2, we're doing  
  
 
proxyConfigBuilder.endpoint(buildURI(proxyHost, proxyPort));  
  
   

 where buildURI ( see in WIP PR ) should do  
  
 
 return   new  URIBuilder().setScheme(scheme).setHost(host).setPort(port).build();  
  
 where the scheme will be http or https depending on if secure connections have been enabled or not. I will update the code to set the scheme. think that is all we will need to do for V2?
