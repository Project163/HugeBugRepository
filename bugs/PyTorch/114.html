Title

Segmentation fault in 'flatbuffer_loader.cpp:298'

Description
### 🐛 Describe the bug

Hi! We've been fuzzing PyTorch project with [Link: sydr-fuzz].
We've found a hcrash at `flatbuffer_loader.cpp:298` in jit module.

The crash occurs because of null pointer dereference when accessing some fields of malformed flatbuffers-module.

PyTorch version:  

OS: Ubuntu 20.04

How to reproduce

1. Build docker from [Link: here] and run the container:

        sudo docker build -t oss-sydr-fuzz-pytorch .
        sudo docker run --privileged --rm -v `pwd`:/fuzz -it oss-sydr-fuzz-pytorch /bin/bash

2. Run the target on this input: [Link: crash.txt]

        /load_afl crash.txt

3. You will see the following output:
