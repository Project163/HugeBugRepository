Title

Make ARFF integration generate meta-data in JSON format

Description
Add a command line option to generate meta-data in a JSON format. 

 This ticket supports the larger goal of making RF classifiers consume the meta-data and sequence files generated by the integration components.   

   MAHOUT-1163   makes RF classifiers read JSON meta-data.  This ticket is to get the ARFF integration to generate the same JSON formatted meta-data.
Discussion
- This patch adds a command line option to generate JSON meta-data. 

 The patch also improves the binary meta-data representation to include allowed values for enumerated types.  The improvement should be backwards compatibale as the additional data is tacked on at the end. 

 It's worth considering dropping support for the binary format.  I'm not sure who is using it...
- I factored large string constants out into resource files.  More review pending.
