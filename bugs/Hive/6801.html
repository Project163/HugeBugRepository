Title

Query with outer join filter is failing with dynamic partition join

Description
Reproducer

 select 
  *
 from  alltypesorc  a   left   outer   join  alltypesorc b  on   a .cint = b.cint  and   a .csmallint !=  a .cint
 where 
   a .cint  between  1000000  and  3000000
 order   by   a .cint;

Discussion
- During conversion of Join operator to Dynamic Partitioned hash join new join descriptor is created. To create this existing expressions e.g. column expressions, filter expressions etc are "back-tracked" and converted to refer to appropriate input expressions depending upon if RS operator is to be removed or not . Filter expressions are always being "back-tracked" and converted irrespective of RS removal. This should be done only if RS is removed (for Map-join RS is removed but for dynamic partitioned join it is not)
- -1 overall
