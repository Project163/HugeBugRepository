Title

Bender export / json loader mapNormalFactor bug

Description
When exporting from blender a mesh witch has an normal map applied to material resulting render is evenly black mesh.
Issue is fixed by patching material before mesh is made in loader callback:
``` javascript
function (geometry, materials) {
   ...
   materials[0].normalScale = new THREE.Vector2( 1, 1 );
   ...
```
But this has to be done individually to each material and scaling is not coming from material.
After digging I found that if you change 
``` javascript
case 'mapNormalFactor':
	json.normalScale = [ value, value ];
	break;
``` 
in here [URL]
to:
``` javascript
case 'mapNormalFactor':
	json.normalScale = value;
	break;
``` 
Problem is solved.

Sorry not providing batch, might also be that I have some setting wrong in my Blender model/material/export
