Title

3.0: Configs in behavior's initialize() are incomplete

Description
The doc block for

```
public function initialize(array $config) {
}
```

states:

```
@param array $config The configuration array this behavior is using.
```

But in fact only the new passed configs via behavior constructor are passed along in here - and any other default configs are not. This renders the $config param in initialize() faulty IMO.

Instead of

```
$this->config($config);
$this->initialize($config);
```

the behavior's constructor should pass the full array along:

```
$this->config($config);
$this->initialize($this->_config);
```

The same might be true for Components.

Or this intended behavior to only have direct access to the currently modified/passed configs?
Then the doc block needs adjusting.
Discussion
- The intention across all things that take a `$config` parameter in their `initialize()` method is that you only get the modified configuration. There would be no need for a parameter if you wanted the complete configuration as the `config()` method exists.
- I've tried to clarify the docs.
- Makes sense. The text was just a bit misleading. But I think now it's fine.
