Title

verbose option not recognized in configuration file

Description
In GitLab by @nre-ableton on Jul 6, 2018, 03:16

I would like to put my Flake8 options in a configuration file (like `.flake8` or `setup.cfg`), and this seems to work fine except for the `verbose` option, which doesn't work despite the [Link: documentation claiming that it should]. My example `setup.cfg` file looks like so:

```
[flake8]
max-line-length = 90
verbose = 2
```

When I run `flake8`, no output is produced unless I force a violation.

I installed Flake8 from pip (`pip install flake8`) in a virtualenv. Here is the output of `flake8 --bug-report`:

```
{
  "dependencies": [
    {
      "dependency": "setuptools",
      "version": "38.5.1"
... [Log Snipped] ...
  "version": "3.5.0"
}
```
