Title

Illegal character 0x0 oozie client

Description
Sometimes oozie client query fails with below message: 
Error: HTTP error code: 400 : Illegal character 0x0.
Discussion
- In AuthOozieClient.java, we write authentication token into .oozie-auth-token. But this file is not protected by any lock. For the first time when this file is created and written, if two or more oozie clients are trying to write into this file, the data might get corrupted. 

 We need to protect this file using file lock to enforce mutual exclusion.
- I think an easy and simple fix is to write it to a temporary file and issue move command at end.
