Title

Android: Panic unwrapping None value while getting Native Activity. Native Activity is never not None.

Description
## Bevy version

Bevy 0.8.0 dev, cloned today.

## Operating system & version
Windows 10, targeting android

## What you did

`cargo apk run --example android`

I get this when ran without any modifications
```
rust.example.android I/RustStdoutStderr: thread ' ' panicked at 'called 'Option::unwrap()' on a 'None' value', [...]\ndk-glue-0.6.1\src\lib.rs:60:39
```

which is 
```
    unsafe { NATIVE_ACTIVITY.as_ref().unwrap() }
```

When I modify the unsafe call to 
```
//unsafe { NATIVE_ACTIVITY.as_ref().unwrap() }
    println!("Getting activity");
    unsafe {
```
