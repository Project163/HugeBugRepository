Title

Clerey inspect report leaking beat_dburi password

Description
Celery Inspect report obscures some passwords from the worker report (I.E. broker url, result_backend) but it is not obscuring passwords from "beat_dburi".
As a result this shows in Flower UI under the config section.

[Image: Image]

[Image: Image]

# Proposed solutions
Add "beat_dburi" here [URL]
` elif 'backend' in key.lower() or 'beat_dburi' in key.lower():`
or
Add '|DBURI' or '|BEAT_DBURI' here [URL]
`HIDDEN_SETTINGS = re.compile(
    'API|TOKEN|KEY|SECRET|PASS|PROFANITIES_LIST|SIGNATURE|DATABASE|DBURI',
    re.IGNORECASE,
)`
