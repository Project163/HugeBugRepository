Title

parse of assert fails when newline between 'test' and 'message'

Description
assert statements crashes the parser if a line break appears between the test and the message. i.e: 

 assert test : 
    "message" 

 see attached test case and stack trace.
Discussion
- Java does allow the message to be written in the following line, the question is should Groovy too? 
If the answer is no, this should be closed and a New Feature should be opened targeting a future release.
- Agreed. Besides, there's a cute work-around: 

 assert (test 
       ): "message"; 

 Somehow the presence of a frowning "smiley" is fitting for a failed assertion.
- Hi, 

 I see it's an old issue not fixed yet. Do you have any plans about it?
