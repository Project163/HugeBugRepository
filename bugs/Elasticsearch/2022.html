Title

Date field mapping "epoch_millis" errors on date aggregations with timezones other than UTC

Description
As demonstrated in [URL] having a date field with `"format": "epoch_millis"` can cause
errors when running date histogram aggregations with a time zone other than UTC. I think this problem was introduced as a side effect of [URL] While throwing an error for parsing time values with `"format": "epoch_millis"` and timezones other than UTC looks like the intented behaviour (see [URL] it should be able to overwrite this by specifying `format` in the aggregation. This however doesn't seem to work currently on 6.x.
Discussion
- Pinging @elastic/es-search-aggs
- Specifying `format` like this in the aggregation:

```
DELETE test_epochmilli_1

PUT test_epochmilli_1
{
  "settings" : {
... [Log Snipped] ...
	
}
```

Throws 

```
{
  "error": {
    "root_cause": [
      {
        "type": "parse_exception",
... [Log Snipped] ...

I would have expected it to use the specified format instead.
```
