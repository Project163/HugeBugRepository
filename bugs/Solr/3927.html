Title

More Like This Handler uses only first field in mlt.fl when using stream.body

Description
The documentation at:  [URL] indicates that one can use multiple fields for similarity in mlt.fl: 
 [URL]

 In trying this, only one field is used.  
Looking at the code, it only looks at the first field: 

  public DocListAndSet getMoreLikeThis( Reader reader, int start, int rows, List<Query> filters, List<InterestingTerm> terms, int flags ) throws IOException 
    { 
      // analyzing with the first field: previous (stupid) behavior 
      rawMLTQuery = mlt.like(reader, mlt.getFieldNames() [0] );
Discussion
- the problem to me is not (only) on the Solr side, but I think Lucene's MoreLikeThis should support multiple fields instead of just one, e.g. adding a new method like 
  
 Query like(Reader r,  String ... fieldNames)  throws  IOException
- These two snippets of code seem to work. I will recraft it as a patch soon. However, I wonder if there are more standard ways of rereading a Reader. 

  
      private   class  ResettingReader  extends  Reader {
    	Reader wrapped;
    	 public  ResettingReader(Reader reader) {
    		wrapped = reader;
    	}
    	 public   int  read( char []buf,  int  off,  int  len)  throws  IOException {
    		 return  wrapped.read(buf, off, len);
    	}
    	 public  void close()  throws  IOException {
    		wrapped.reset();
    	}
    	 public  void reallyClose()  throws  IOException {
    		wrapped.close();
    	}
    }
 
  

  
  public  DocListAndSet getMoreLikeThis( Reader reader,  int  start,  int  rows, List<Query> filters, List<InterestingTerm> terms,  int  flags )  throws  IOException
    {
      if  (mlt.getFieldNames().length==1) {
    	rawMLTQuery = mlt.like(reader, mlt.getFieldNames()[0]);
      }  else  {
        BooleanQuery mltQuery =  new  BooleanQuery();
        ResettingReader reader2 =  new  ResettingReader(reader);
         for  ( String  fieldName : mlt.getFieldNames()) {
      	  BooleanQuery singleFieldQuery = (BooleanQuery)mlt.like(reader2, fieldName);

    	  }
        }
        reader2.reallyClose();
        rawMLTQuery = mltQuery;
