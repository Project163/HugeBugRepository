Title

Dead code detection fails to find nested assignments

Description
```php
$a = 5;
$b = $a;

if (rand(0, 1)) {
  $a = $b;
}
```

```php
$a = 5;

if (rand(0, 1)) {
  $a++;
}
```

```php
$a = 5;

if (rand(0, 1)) {
  $a = $a + 5;
}
```

in all cases the assignment to `$a` inside the conditional is of no value
