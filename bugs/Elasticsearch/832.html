Title

Use XNativeFSLockFactory instead of the buggy Lucene 4.8.1 version

Description
There is a pretty nasty [Link: bug] in the lock factory we use that can cause nodes to use the same data dir wiping each others data. Luckily this is unlikely to happen if the nodes are running in different JVM which they do unless they are embedded. We should place the fix for this as an X-Class until the fix is released.

yet this might have other side-effects that we haven't uncovered yet so I mark it critical
