Title

Generate translations fails for sub-categories (like app/error)

Description
If you generate the translations it will fail if you use categories like "app/error". Only after one created manually the sub-folder "app" under the folder "de" (e.g. for a translation in German) the generation is successful. Otherwise it fails and the files are not generated but an exception is thrown.

Seems like the sub-folders are not created correctly. Or sub-folder are not supported that way at all. But then the example in [URL] should be made clearer. Because it seems to work only if one maps the category "app/error" to one single file "error.php" like in the example. 

However, below it say one should not use the filemap but rely on the standard categories!
