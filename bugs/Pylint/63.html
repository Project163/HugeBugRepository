Title

Overly optimistic "lambda may not be necessary"

Description
Originally reported by: **Antony Lee (BitBucket: [Link: anntzer], GitHub: @anntzer?)**

---

Currently `f = lambda: foo().bar()` (or `foo.bar().baz()`) triggers a "lambda may not be necessary warning", probably because pylint belives this may be refactored as `f = foo().bar` (or `foo.bar().baz`).  But this is likely not the case, as the intermediate function call can return a different result each time it is called.
