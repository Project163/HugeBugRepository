Title

ApplicationProtocolNegotiationHandler does not use fallback when with Java 9 and extension ignored

Description
### Expected behavior

The fallback given to the `ApplicationProtocolNegotiationHandler ` is provided in the `configurePipeline` method.

### Actual behavior

The `configurePipeline` method is called with an empty string instead of the given fallback protocol. This is because the engine returns an empty string and the `ApplicationProtocolNegotiationHandler ` checks the nullity of the protocol string, it should also check wether it's empty or not.

### Steps to reproduce

A bootstrap setup with an `SslHandler` and the `ApplicationProtocolNegotiationHandler` using JDK engine. The bootstrap connects to an SSL server that does not support ALPN and ignores the extension.
