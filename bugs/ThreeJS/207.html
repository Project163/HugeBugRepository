Title

Wrong array size in RGBELoader

Description
I think I see another trivial bug, but this time I would like to confirm before I prepare a PR, because I am not quite sure. In `RGBELoader` there is a computation `numElements = image_rgba_data.length / 4 * 3`. The `numElements` obtained this way is a total number of RGB items in the result. Still the iteration is done as:

```
js
numElements = image_rgba_data.length / 4 * 3;
const floatArray = new Float32Array( numElements );

for ( let j = 0; j < numElements; j ++ ) {
... [Log Snipped] ...

}
```

I think the target array is accessed with 3x times larger indices than expected and it should be:

```js
for ( let j = 0; j < numElements / 3; j ++ ) {

	RGBEByteToRGBFloat( image_rgba_data, j * 4, floatArray, j * 3 );

}
```

Can anyone confirm?
Discussion

```
js
numElements = image_rgba_data.length / 4;

const floatArray = new Float32Array( numElements * 3 );

... [Log Snipped] ...

}
```
- That looks even better, easier to understand. I will prepare a PR.
