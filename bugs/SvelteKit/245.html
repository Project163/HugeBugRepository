Title

data-sveltekit-replacestate does not work for #hash links

Description
### Describe the bug

When clicking on a hash link that has the `data-sveltekit-replacestate` attribute, the expected behavior is to update the URL without pushing a new history entry. However, the bug causes the history object to be pushed even when the `data-sveltekit-replacestate` attribute is used, resulting in unexpected navigation history behavior.

### Reproduction

[URL]

Steps to reproduce the behavior:

1. Create a new SvelteKit project or open an existing one
2. Add a hash link with the `data-sveltekit-replacestate` attribute, like the following: ` c `
3. Start the development server and navigate to the page containing the hash link
4. Click on the link with the attribute
5. Observe the URL change and the browser's navigation history

- I think i know why this is happening: 

We have the following options element which contains:

[URL]

It returns an object which contains `replace_state`, which is a `boolean`. It activates whenever we click on  a `div` which contains `data-sveltekit-replacestate`. It will return `options.replace_state` as `true` This is working as expected.

But we have a problem, because whever we click, the logic of only updating the hash will update.That will trigger the `pushHistory` Which is the following

[URL]

Even if `options.replace_state` is `true`, it will always enter this `if` condition and `push` the `store` because of the `stores.page.set`. It will never reach the expected `navigate` function which has the logic of triggering the `replaceHistory`. 


This is the function that is expected to replace the state with replaceState

[URL]

One way of dealing with this is to check in the `if` condition the options.replace_state:
```javascript
if (
      hash !== undefined &&
      nonhash === location.href.split('#')[0] &&
      !options.replace_state
    ) 
``` 

In that way we can assure that if we trigger the `data-sveltekit-replacestate`  the store will never push. It will reach the navigate function which is in charge of the logic of replacing the state.
