Title

Cross-Site Request Forgery (CSRF) prevents JSON-Bodies to be deserialized

Description
### Describe the bug

I want to add CSRF-protection as described in [URL] But my application has some Ajax-endpoints, e.g:
```
@POST
  @Path("/csrfTokenPostBody")
  @Consumes(MediaType.APPLICATION_JSON)
  @Produces(MediaType.TEXT_PLAIN)
  public Uni  postJson(User user) {
    return Uni.createFrom().item(user.name);
  }
```

### Expected behavior

The token is read from the header and verified. If the token is correct, the method can access the body normally.

### Actual behavior

If I send a correct token in the header, I get this exception 
