Title

Global discovery not reconnecting

Description
After i had no connection to the internet syncthing stopped trying to connect to the global discovery server with the error message:

```
9:00:20: Global discovery:  :22025: stopping due to too many errors: write udp: network is unreachable
```

This is probably not a bug, but in my opinion it sould try to reconnect after some time (every 10min for example). After restarting syncthing it immediately connected to the global discovery server.
Discussion
- Agreed, giving up forever is unnecessary.
- This will better handle the case that syncthing starts before the network and dns are up.
