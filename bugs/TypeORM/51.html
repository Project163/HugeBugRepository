BTW instead of 

```ts
  @Column('enum', {
    default: AppointmentStatus.IN_PROGRESS,
    enum: [AppointmentStatus.CANCELLED, AppointmentStatus.COMPLETED, AppointmentStatus.IN_PROGRESS]
  })
```

you can simply do:

```ts 
  @Column('enum', {
    default: AppointmentStatus.IN_PROGRESS,
    enum: AppointmentStatus
  })
```
