	 The check  ensureNoVacuum()  was removed due to a race between ensureNoVacuum() call and grid activation (auto-activation) that makes test flacky. 
 Actually, second node start return control to test-thread and starts a new PME to activate cluster. So, test-thread can see node state 'before' auto-activation as well as 'after' auto-activation. First cache operation or node.cluster().active(true) will wait for activation and it safe to check ensureNoVacuum() after if, but not before.
