Title

po.file generation empties already existing translations

Description
If there is nothing new in the category it should take the translated message from the PO file and use that as the message not an empty string. This essentially erases any existing translations from categories that haven't changed.

Solution would be to `$merged[$category . chr(4) . $message] = $existingMessages[$message];`
