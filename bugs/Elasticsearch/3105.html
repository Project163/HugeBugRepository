Title

GET _cluster/settings with include_defaults doesn't return expected value in case of a setting with fallback

Description
### Elasticsearch Version

8.14

### Installed Plugins

_No response_

### Java Version

_bundled_

### OS Version

Linux 6.9.7-1-ck-generic-v4

### Problem Description

In case a `Setting` is defined with a fallback setting and the fallback setting is defined in `elasticsearch.yml`, the response to `_cluster/settings?include_defaults` doesn't return the value defined in `elasticsearch.yml` for the 1st setting. Instead, it returns whatever default is defined for the fallback.

### Steps to Reproduce

- create a setting `my.setting` which defaults to `1`.
- create a setting `my.setting.with_fallback` which falls back to `my.setting`.
- set a value for `my.setting` in `elasticsearch.yml`, e.g., `42`.
- the response of `_cluster/settings?include_defaults` contains `defaults.my.setting.with_fallback: 1`, although what is expected is to get `defaults.my.setting.with_fallback: 42`
