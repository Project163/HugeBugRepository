Title

[4.3.6] Paginator helper "limitControl()" method does not care about "model" option

Description
### Description

Hello,

The instruction ` Paginator->limitControl([25 => 25, 50 => 50], null, ['model' => 'Mesures']) ?>` does not create a link for the specific model. **It make a link but without the model**:
```php
// [URL]
```

But others method work fine like : 
 ```php
  $this->Paginator->options(['model' => 'Mesures']);
   Paginator->sort('mesured_at', __( 'Mesured At' )) ?>
 // [URL]
```

or this too :
```php
   Paginator->sort('mesured_at', __( 'Mesured At' ), ['model' => 'Mesures']) ?>

```
In the source code of `PaginatorHelper::limitControl()`  the is no use of `$this->params` either `['model']` ...

### CakePHP Version

4.3.6

### PHP Version

7.4
