Title

Start method of components throwing NoClassDefFoundError are not caught

Description
Currently, if the component creation throws NoClassDefFoundError in the constructor is caught and logged. But if it is thrown from start() it is not caught and the component may never start and no logging happens. We need to at least log it till a permanent fix is found.
