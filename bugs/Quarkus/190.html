Title

Regression in list-extensions of quarkus-maven-plugin 0.21.1, case when pom.xml is not present

Description
quarkus-maven-plugin `0.21.1` has regression in `list-extensions` goal.

Getting error when invoking `mvn io.quarkus:quarkus-maven-plugin:0.21.1:list-extensions` command in directory without `pom.xml` .

`mvn io.quarkus:quarkus-maven-plugin:0.20.0:list-extensions` doesn't require pom.xml presence. So from this perspective it's a regression. `list-extensions` shouldn't require presence of pom.xml.

Probably related to [URL] change.

[ERROR] Failed to execute goal io.quarkus:quarkus-maven-plugin:0.21.1:list-extensions (default-cli) on project standalone-pom: Unable to list extensions: null/pom.xml -> [Help 1]
org.apache.maven.lifecycle.LifecycleExecutionException: Failed to execute goal io.quarkus:quarkus-maven-plugin:0.21.1:list-extensions (default-cli) on project standalone-pom: Unable to list extensions
