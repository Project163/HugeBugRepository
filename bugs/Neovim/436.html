Title

completeopt crashes neovim

Description
### Neovim version (nvim -v)

NVIM v0.7.0-dev+1126-gfc7fc14bd2

### Vim (not Nvim) behaves the same?

don't know

### Operating system/version

arch linux 5.16.9-arch1-1

### Terminal name/version

kitty 0.24.2

### $TERM environment variable

xterm-kitty

### Installation

AUR

### How to reproduce the issue

```
nvim -u minimal.lua README.md
```
where `minimal.lua` is
```
lua
vim.cmd [[set runtimepath=$VIMRUNTIME]]
vim.cmd [[set packpath=/tmp/nvim/site]]
local package_root = '/tmp/nvim/site/pack'
local install_path = package_root .. '/packer/start/packer.nvim'
... [Log Snipped] ...
require('packer').sync()
vim.cmd [[autocmd User PackerComplete ++once echo "Ready!" | lua load_config()]]
```
then do `:set completeopt=menu,longest` and type
```
# header

test[test](#
```

### Expected behavior

No crash

### Actual behavior

`nvim` crashes with one of the following errors:
```
free(): invalid next size (fast) 3218481 IOT instruction (core dumped)

corrupted size vs. prev_size 3216727 IOT instruction (core dumped)

munmap_chunk(): invalid pointer 3184780 IOT instruction (core dumped)
```

This might be an issue but `mkdx` but I guess `nvim` shouldn't crash at least.
