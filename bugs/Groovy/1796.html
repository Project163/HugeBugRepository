Title

indy looses safe navigation flag

Description
for the following script: 
  
  class  X {
    def value
}
def m(x) {
    x?.getValue()
}
def x =  new  X(value:1)
m(x)
m( null )
 
  
 Indy fails to keep the safeNavigation flag and causes a NPE for the getValue() call on the m(null) invocation
