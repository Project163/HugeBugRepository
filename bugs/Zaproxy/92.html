Title

Memory leak on session creation/loading

Description
From OWASP ZAP User Group: [URL]

---

Steps to reproduce the issue:
1. Start ZAP;
2. Create a new session several times (>= 5 to be easier to spot the issue);
3. Create a heap dump, analyse it (for example, using Java VisualVM) and note that the instance variable `listenerList` of `ParosDatabase` has many instances of `ClientTable`, `MessageTable` and `TableWebSocket`, one per session opened (the exact types depend on the installed add-ons);
4. The more sessions are created the more items the `listenerList` has (and the more memory is used by `ParosDatabase`).

ZAP:
Versions >= 2.4.0
