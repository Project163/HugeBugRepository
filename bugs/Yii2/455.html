Title

Double formatting in i18n fallback

Description
When intl extension is not available, fallback formatting works wrong for double values:

``` php
echo Yii::t('app', 'Here is a big number: {n, number}', ['n' => 2e+8]);

// Intl: Here is a big number 200,000,000
// No intl: Exception(Message format 'number' is only supported for integer values. You have to install PHP intl extension to use this feature
```

Expected: float should be formatted as with intl
