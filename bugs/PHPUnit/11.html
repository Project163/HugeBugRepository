Title

callback() assert seems to be called incorrectly

Description
There seems to be a bug around the `callback()` assertion. When using code such as the following

```
$mock->expects($this->once())
   ->with($this->callback(function() { })
```

the callback is called multiple times even though the method that is being mocked is only called once.
