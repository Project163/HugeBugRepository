Title

SedolCheckDigit fails to reject invalid (non-numeric) check digits

Description
The SedolCheckDigit class fails to check that the check digit is actually a digit; it currently also allows some alphabetics. 

 As a side effect of this, it treats some letters as being valid checkdigits when they should be rejected.
