Title

Optimized foreach loops should handle "continue" properly

Description
This code shows a regression in the foreach loop optimization (  GROOVY-7349  ) introduced in 2.4.2  
  
 @groovy.transform.CompileStatic
 private   int  foo( String [] arr) {
    int  counter=0
    for  ( String  s in arr) {
       if (counter++ > 100)  break 
      println(s)
       if (s ==  'b' )  continue 
   }
   counter
}

 assert  foo([ 'a' , 'b' , 'c' ] as  String [])==3
