Title

don't load dialect provision.py modules unless tests are running

Description
just noticed that the entire SQLAlchemy library, all of testing and orm, is imported when we load dialects because provision.py relies upon testing, which then relies upon ORM in one spot.

we should try to make it so that testing isn't even imported unless needed.  this will require revising how we call in "provision.py" in each dialect.
