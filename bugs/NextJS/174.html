### Describe the Bug

When `i18n.locales` contains the same value twice, it will trigger an error similar to [URL]
This is because the built file as already been moved from `.next/export/` to `.next/server/pages`.

This can happen if you compute the locales list from regions, for instance `["zh-Hans", "zh-Hant"].map(l => l.slice(0,2)`, you will have `zh` country code twice.

### Expected Behavior

Have a cleaner warning, similar to when we forget to put the defaultLocale into the locales list

### To Reproduce

In `next.config.js` `i18n.locales`, put the same locale twice and try to build an app.
