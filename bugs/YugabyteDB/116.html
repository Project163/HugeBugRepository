Title

[YSQL] Dropping a table created in the same session may cause session to terminate

Description
In a YSQL-enabled YugaByte DB, when a table is created and then dropped within the same session, the session may terminate unexpectedly. For example,

```
postgres=# CREATE TABLE yb_char_in_key (ck CHAR PRIMARY KEY);
CREATE TABLE
postgres=# INSERT INTO yb_char_in_key VALUES ('a');
...
postgres=# DROP TABLE yb_char_in_key;
server closed the connection unexpectedly
	This probably means the server terminated abnormally
	before or while processing the request.
```
