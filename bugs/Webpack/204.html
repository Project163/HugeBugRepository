Title

When using more than one worker, the main thread bundle references them with an undefined hash

Description
# Bug report

 
 
 
 

**What is the current behavior?**

When declaring two bundles (entry points) each one with its own web worker, and using `[contenthash]`, workers are incorrectly referenced with an `undefined` hash, which the browser can't load.

**If the current behavior is a bug, please provide the steps to reproduce.**

I created a github repo with the minimal repro case. Follow the README.md in that repo:
[URL]

 
 
 
 
 
 

**What is the expected behavior?**

Same as when using `[fullhash]`, both workers should be possible to reference from their respective bundles, i.e. the generated URL should have the correct hash instead of `undefined`.
