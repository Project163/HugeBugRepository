Title

When creating s3 repository snapshot, error "Cannot invoke java.lang.Number.longValue() because requestCount is null" occurs

Description
**Elasticsearch version** 7.8.1

**Plugins installed**: analysis-icu, repository-s3

**JVM version** `openjdk version "14.0.1" 2020-04-14 (docker)`

**OS version** `Linux 4.4.0-1072-aws #82-Ubuntu SMP Fri Nov 2 15:00:21 UTC 2018 x86_64 x86_64 x86_64 GNU/Linux (docker)`

I've just upgraded to 7.8.1 and I'm trying to make a snapshot to a s3 repository
`curl -X PUT [URL] -H 'Content-Type: application/json' -d '{"indices": "[snapshot_index]", "include_global_state": false}`

- Hi @maxrem thanks for reporting this. It looks like we throw this error if the S3 SDK completely fails to execute the API request (doesn't even attempt it for some reason) and thus we unexpectedly see this exception.
I looked through a lot of logs on our end and could not find a single instance of this failure. I can and will fix this code to not throw a null pointer exception but I think there is a deeper reason for why this is failing on your end. 

Maybe look into the logs to see if there's any failures logged from the S3 SDK before getting to this line?
