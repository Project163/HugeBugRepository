Title

Computing readable buffer offsets and sizes when including empty buffers fails.

Description
The computation of readable buffer offsets and sizes fails when the range starts or ends with empty buffers. 

 The offsets and sizes of buffers can follow these patterns: 
  
 
{{0,0}, ..., {1,3}, ..., {0,0}, {5,6}, ...}  for  non-broadcast scenarios. 
  
  
 
{{1,2}, ..., {1,2}, ..., {1,2}, ...}  for  broadcast scenarios.  
  
 However, the current logic does not correctly handle situations where the sequence starts or ends with an empty buffer. This needs to be fixed.
