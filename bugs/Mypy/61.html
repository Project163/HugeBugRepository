Title

Type inference problem with map() and function that takes *args

Description
The call to map() below is not accepted ("argument 1 has incompatible type"), even though it should be fine:

```
import typing
def f(*args: str) -> str: return args[0]
map(f, ['x'])
```

The call is accepted if the *args argument is switched to an ordinary argument.
Discussion
- Another repro:

``` python
from typing import typevar, Function
T = typevar('T')
def m(x: Function[[T], None]) -> None: pass
def f(*args: str) -> None: pass
m(f) # Argument 1 to "m" has incompatible type Function[["str"] -> None]; 
     # expected Function[["str"] -> None]

```
- This actually seems to a subtyping issue with `*args`:

``` python
from typing import Function
x = None # type: Function[[int], None]
def f(*x: int) -> None: pass
x = f   # Complains about incompatible types, even though should be valid
```
