Title

ISO8601 for datetime json format, when on Danish locale

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.7, 3.8.
* Platform and Target: LAMP (Ubuntu, with Danish locale).

### What you did
var_dump((new FrozenTime())->jsonSerialize());

### What happened
Output is string(25) "2019-05-14T10.22.48+02:00"

### What you expected to happen
':' should be used for time instead of '.':
string(25) "2019-05-14T10:22:48+02:00"

The similar issue is described by another user here:
[URL]
Discussion
- You can use `FrozenTime::setJsonEncodeFormat()` in your bootstrap to set required format.
- @ADmad Default value for DateFormatTrait::$_jsonEncodeFormat = "yyyy-MM-dd'T'HH:mm:ssxxx" (with ':' for time).
But in DateFormatTrait::jsonSerialize() it uses i18nFormat(), so value is incorrect with Danish locale:
```
public function jsonSerialize()
{
	return $this->i18nFormat(static::$_jsonEncodeFormat);
}
```
- ... [Middle Discussions Snipped for Brevity] ...
- @othercorey 
Code:
```
ini_set('display_errors', 1);
echo datefmt_create('da_DK', 0, 0, 'UTC', null, "yyyy-MM-dd'T'HH:mm:ssxxx")->format(0);
phpinfo(INFO_GENERAL);
```
Output:
```
1970-01-01T00.00.00+00:00
PHP Version 7.0.33-0ubuntu0.16.04.4
```
- Perhaps it's worth submitting a bug report to php?  I looked and didn't find anything related to this.

The . and : characters are not locale-specific. They're considered escaped characters even without the ':' so that seems like a bug?
