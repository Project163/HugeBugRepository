Title

Other registered failing RunListeners cause NullPointerException in ConcurrentReporterManager, falsely report of "No tests were executed!":

Description
A Custom Runner in JUnit can register their own RunListeners on the RunNotifier during execution. When these fail, junit removes them from the Listener chain and fires a 'internal' Failure,  

   RunNotifier.SafeNotifier:44   
 fireTestFailure( new  Failure(Description.TEST_MECHANISM, e));
 
  

 When a unknown Failure is fired with a 'unknown' Description as compared to surefires pre created metadata registry, it fails with a NullPointerException and is removed by JUnit.  

 "No tests are found"
