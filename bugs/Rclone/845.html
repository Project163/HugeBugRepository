Title

`size` does not report size when using `-P` or `-v`

Description
Running `size` on a Google Photos remote like so:
`rclone size --gphotos-read-size --fast-list gp0:media/by-month/2006/2006-02`
returns count & size (as expected):
```
Total objects: 68
Total size: 84.786 MiB (88905066 Byte)
```

But if I add `-P` (and/or `-vv`) then it only returns count, not size:
```
rclone size -P --gphotos-read-size --fast-list gp0:media/by-month/2006/2006-02
Transferred:   	          0 B / 0 B, -, 0 B/s, ETA -
Elapsed time:         8.0sTotal objects: 68
Transferred:   	          0 B / 0 B, -, 0 B/s, ETA -
Elapsed time:         8.3s
```

When using `-vv` I also see this:
`INFO  : Google Photos path "media/by-month/2006/2006-02": Committing uploads - please wait...`
... which I have no idea what this means?
