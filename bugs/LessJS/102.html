Title

ModifyVars does not seem to work with numerical values.

Description
I'm trying to change size of elements with **modifyVars** like this:

```
javascript
   function user_scale_up() {
      USER_SCALE = ((USER_SCALE + (USER_SCALE * 0.1)) * 100) / 100;
      var scale = Math.round(USER_SCALE * 100) / 100;
      less.modifyVars({'@scale': scale});
... [Log Snipped] ...
      less.modifyVars({'@scale': scale});
    }
```

However, this errors if the value I pass is not a string. I get the error:

```
  Uncaught TypeError: Object 1.21 has no method 'slice'
```

I tried passing the number in as a string with **.toString()** which works -- but then LESS errors when the value is multiplied to px sizes like **padding: (2px \* scale)**

What is the correct way to modify numerical variables?
