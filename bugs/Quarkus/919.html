Title

resteasy-reactive: When using own Content-Type for @Produces then quarkus will set 'application/json' as Content-Type header

Description
**Describe the bug**
When. using `@Produces` with non-standard content type with resteasy-reactive  will result in 'application/json' being set as Content-Type header instead of the requested type.

**Expected behavior**
It should set the requested content type that was requested in the Accept header.

**Actual behavior**
'application/json' is always set.

**To Reproduce**

Steps to reproduce the behavior:
1. Checkout [URL]
3. Add `@Produces("application/vnd.quarkus.fruit-v1+json")` to POST method
4. Call `curl -H "Accept: application/vnd.quarkus.fruit-v1+json"  [URL] -d'{"name": "apple"}' -v`
