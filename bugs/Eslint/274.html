Title

False alarm with commas in JSX

Description
Putting a comma in a JSX expression causes a false alarm.

```
var X = React.createClass({

    render: function () {
        var hello = "Hello";
        var world = "World";
... [Log Snipped] ...

});
```

```
{
  "ecmaFeatures": {
    "jsx": true
  }
}
```

```
$ eslint index.js

  ...
  6:28  error  A space is required after ','   comma-spacing
```

See [URL] for the original report. It was found out the issue was upstream.
Discussion
- Confirmed. We should not flag commas in JSX elements.
