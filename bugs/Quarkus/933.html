Title

Setting quarkus properties using the Kubernetes extension results in incorrect env var name

Description
**Describe the bug**
If I try to set a Quarkus config property like `quarkus.kubernetes.env.vars."quarkus.kubernetes-config.enabled"=true` using the Kubernetes extension, an incorrect name is generated in the Kubernetes Deployment.

**Expected behavior**
I expect to see the following in the generated YAML:

```
        - name: QUARKUS_KUBERNETES_CONFIG_ENABLED
          value: "true"
```

**Actual behavior**
The following is added to the genetated YAML:


```
        - name: QUARKUS.KUBERNETES_CONFIG.ENABLED
          value: "true"
```
