Title

useController isValid issue with input ref not registered

Description
I noticed the following and i'm not sure if i'm doing something wrong or it is a bug:

When I use `onChange` and `value` of `field` inside the `render` prop function of the `Controller` component, validation is not executed after I fix a validation error in another field. It is easier to understand with an example:

Steps to reproduce:

1. open [Link: CodeSandbox]
2. remove the value from the first input with the label 'Name'.
3. `formState.isValid` will update to `false`
4. type something in the input again
5. `formState.isValid` doesn't update to `true`

This only happens when I use `onChange` and `value`, if I just spread the `field` object into the `inputProps` prop (as in my case i use Material UI) the validation works and the formState updates itself after input changes.
