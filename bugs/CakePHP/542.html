Title

Assosiated entity nullable depends on contain() parameters.

Description
I have association like:

```
OffersTable -> belongsTo -> Products
ProductsTable -> hasMany -> Files
```

Now, offer doesn't have product, and when I search offer:

``` php
$offer = $this->Offers->find()->contain(['Products']);
```

then $offer->product is null. But if I use contain like:

``` php
$offer = $this->Offers->find()->contain(['Products', 'Products.Files']);
```

then $offer->product is not null like before, but it is an empty Product entity. $offer->product->files is an empty array of course.
I think $offer->product should be always null, if its not found. Contains deeper than 'Products' shouldn't make difference I think.
Also, $offer->product->isNew() returns false although all properties of its entity are null.
