Title

Zerowidth characters not rendering in last column

Description
The following code should show the problem:

```sh
for _ in $(seq $(tput cols)); do
    printf "X̃̂̆"
done
```
Discussion
- This is actually our terminal is writing zerowidth character to a wrong glyph when it reaches the end of the line, the zerowidth vector is empty for the last glyph in the row.

I've logged it from the renderer and it gets the following information for the last 3 chars in the row.

```
char: X, zerowidth: Some(['\u{303}', '\u{302}', '\u{306}'])
char: X, zerowidth: Some(['\u{303}', '\u{302}', '\u{306}', '\u{303}', '\u{302}', '\u{306}'])
char: X, zerowidth: None

```

As you can see one of them has 2 zero width chars.
