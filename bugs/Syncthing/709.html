Title

Incorrect out-of-sync/locally changed status indication on folders

Description
(This is a bug report for IssueA and IssueB described in this forum thread:
[URL]

 - what happened,
I had several receive-only folders with ignore-delete. They were used for unidirectional sync from phones to NAS server. I changed their type from receive-only to send-receive, still with ignore-delete set. At this moment the folders became out-of sync. The total size of the out-of-sync items is displayed as 0B. When I want to display the list of the out-of-sync items, the list contains many pages, but all the pages are empty - the list is corrupted.

 - what you expected to happen instead
At first, the folder should not become out-of-sync.
At second, the list of out-of-sync items should display the problematic items.
At third, if those out-of-sync items are not empty or deleted, their total size should not be displayed as 0B.

Screenshot: [URL]

 - any steps to reproduce the problem.
Much more details are described in the forum link, but I cannot tell which ones are relevant for this issue.

### Version Information

Syncthing Version: v1.4.0
OS Version: Synology NAS DS416play (Linux x64)
