Title

Installed add-on dependencies might not be taken into account when installing add-ons

Description
Steps to reproduce the issue:
1. Run ZAP (2.4.2);
2. Try to install the add-on "DOM XSS Active scanner rule", note that it asks to update the "Selenium" version 3 (a dependency) even if it's already installed;
3. If the installation continues it leads to errors later on, for example:

