Title

[Form] PATCH'ed forms are never valid

Description
While trying out the new form PATCH feature, I ran into a bug:

Say for instance you have a form with two children: firstName, lastName,

and you PATCH with this data: `array('firstName' => 'Hank')`

now the "submit" method is never called on the child "lastName". Now there's a problem, because Form::isValid() only returns `true` if `$this->submitted` is `true`. However, this is `false` for the "lastName" child. A form with children, in turn, will only return `true`, if all of it's children are `true`, which, now, is not the case.
