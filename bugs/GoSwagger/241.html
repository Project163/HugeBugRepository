Title

v0.30.4 panics during flatten

Description
## Problem statement

A OAS2.0 spec that flattens multiple files fine in v0.28.0 and v0.29.0, but panics in v0.30.4.

## Swagger specification

[URL] contains a `management.yml` and `client.yml` that needs to be flattened. Used to generate `management.yml` and `client.yml` in the directory above.

## Steps to reproduce

1) clone [URL]
2) `git checkout  ` (should work on main, but this is the commit I was on when the issue present itself)
3) `cd edge-api/source`
4) `swagger flatten .\client.yml -o ..\client.yml --format yaml`
