Title

Log output Issue

Description
I have the following running:

`/Applications/rclone/./rclone --log-file /Applications/rclone/rclone.log --include-from /Applications/rclone/include-file.txt copy $UserDir GDrive:`

I only get the following in the log file:

```
2016/02/19 12:41:24 Can't redirect stderr to file
2016/02/19 12:41:29 Google drive root '': Building file list
2016/02/19 12:42:13 Google drive root '': Waiting for checks to finish
2016/02/19 12:42:13 Google drive root '': Waiting for transfers to finish
```

This is what shows up in the terminal window:

```
Transferred:            0 Bytes (   0.00 kByte/s)
Errors:                 0
Checks:              1377
Transferred:            0
Elapsed time:       43.5s
```

shouldn't this second snippet also log to the log file?  I must be missing something simple but i can't identify it.

Thanks!
Discussion
- The `Can't redirect stderr to file` is the reason I think.  It shouldn't be saying that!

Which OS are you running on and how many bits? I'm guessing OSX...

In the mean time you can use command line redirection if you want

```
rclone commands  > rclone.log 2>&1
```
