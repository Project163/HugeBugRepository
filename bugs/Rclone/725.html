Discussion
- This is a problem with bucket based backends which don't store directories.

What happens is, in this code

[URL]

The first call to `f.create` returns nothing with `fs.ErrorObjectNotFound`

This then attempts to create them and because the bucket based storages systems can't have empty directories, the second call to `f.create` also returns nothing with `fs.ErrorObjectNotFound`.

To fix this we need an internal version of `Mkdir` which returns a `[]upstreams` so we **don't** need to call `f.create` again.

I had a go at implementing this here - can you give it a test?
