Title

3.x rendering Cells with template from another Cell

Description
What i try to do:
FirstCell already exists and it render Template/Cell/FirstCell/display.ctp
I create SecondCell and try to render Template/Cell/FirstCell/display.ctp because it differ only in cell display method(take different data from database), but render data in same manner(select list)
Problem:
Standard Cell class do not allow to do this 
Cake\View\Cell::render

```
$this->View->subDir = 'Cell' . DS . substr($className, 0, strpos($className, 'Cell'));
```

I think it is a great opportunity to reduce the amount of code and template files if they are the same, if it would be possible to reuse already existing tamplates from another cells.
Discussion
- Why do cells need to share views?
- Maybe i don't undeerstand Cell concept. But...
Example:
FirstCell generates list of Users
SecondCell generate list of Roles
and set for cell view two vars: $fieldName, $options
Both templates contains same code like:

```
echo $this->Form->input($fieldName, $options);
```

At now I need to create two templates for two cell. Why shoudn't reuse existing one?

P.S. This is just an idea. You better know whether to implement it.
