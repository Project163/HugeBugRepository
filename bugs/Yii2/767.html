Title

Optimistic Locking doesn't work if the lock value is not sent

Description
I'm working on a REST API.
If I send an outdated lock value (e. g. `{"some_field":"some new value","version":0}`), I get StaleObjectException, which is expected.
If I do not send the optimistic lock field (e. g. if I send only `{"some_field":"some new value"}`), the record gets updated and everything is fine, which is not expected.
I expect to get StaleObjectException if I do not send the optimistic lock field.
Discussion
- I was able to reproduce this in the webapp part (deleted the input field for version.)

```
    public function rules()

        ];
    }
```
