Title

findOne() doesn't prefix columns with table name

Description
Is it a bug?
I have an ActiveQuery with "default scope" that calls innerJoinsWith another model.

In controller-view when findModel() tries to findOne($id) throws ERROR:  column reference "id" is ambiguous because findOne doesn't put any table before id column in where clause.

I had to replace 

``` php
MyModel::findOne($id)
```

with

``` php
MyModel::find()->where(['{{%table}}.id' => $id])->one()
```
Discussion
- should be fixed. This means we need a different implementation for findOne() and findAll() in SQL and NoSQL dbms. SQL needs table name prefix, while NoSQL does not.
- It's ugly to always prefix the table name when the SQL only selects from one table (which is the case 99% of the time. The issue reported here is very rare.). I think this should be improved.

- No functionality problem. It's just the SQL looks ugly with the unneeded table prefix 99% of the time.
