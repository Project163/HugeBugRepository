Title

Run All Paragraphs stops if there is a disabled paragraph mid-run

Description
Run All Paragraphs runs fine until it reaches a disabled paragraph in the middle of a run. 

 How it should be processed: disabled paragraphs should be just skipped; following paragraphs should be processed normally. 

 What happens: disabled paragraph doesn't run (as expected), but it doesn't run non-disabled paragraphs after that as well (this is the bug).  

 Also it seems make Zeppelin not able to run any paragraphs at all (even manually).. it's in some stuck state (refreshing page fixes this state).
