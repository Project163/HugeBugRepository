Title

Rules off by default in the doc

Description
In the rules doc [1] we state that the rules not enabled by default are marked as being off.

For instance,
`block-scoped-var - treat var statements as if they were block scoped` - wrong
`valid-jsdoc - Ensure JSDoc comments are valid (off by default)` - correct

Giving a look at the default `eslint.json` [2], it seems there is a gap in the doc.
