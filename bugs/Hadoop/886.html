Title

Incremental dist tar build fails

Description
Building a dist tar build when the dist tarball already exists from a previous build fails.
Discussion
- Example output from  mvn install -Pdist -Dtar  after a previous build: 

  
 [INFO] --- maven-antrun-plugin:1.6:run (tar) @ hadoop-dist ---
[INFO] Executing tasks

main:
     [exec] $ tar cf hadoop-3.0.0-SNAPSHOT.tar hadoop-3.0.0-SNAPSHOT
     [exec] gzip: hadoop-3.0.0-SNAPSHOT.tar.gz already exists;	not overwritten
     [exec] $ gzip hadoop-3.0.0-SNAPSHOT.tar
     [exec] 
     [exec] Failed!
- Looks like this was broken by   HADOOP-8562  .  We used to use  tar czf  to build the tarball, but now it uses  tar cf  followed by a separate  gzip  instead.   tar   overwrites the destination file but gzip by default does not.
