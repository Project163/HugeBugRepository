Discussion
- Looks like this actually stems from the fix we put in to stop users who sent records from punctuators from hitting the txn timeout.  We used to skip over the txn commit entirely when no new records had been processed from the input topics, so that fix just added a check for StreamsProducer#transactionInFlight when deciding whether or not to commit.  I guess that API doesn't work as expected when the producer is already closed? 

   

 Anyways, I set the Affects version to 3.4 as this was where the regression from that fix was introduced. Also for anyone who might be worried, IIUC this would only impact EOS (specifically v2) applications
