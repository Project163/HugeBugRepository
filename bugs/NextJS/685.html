### Describe the Bug

The Server Component renders twice in production environment when defining `generateStaticParams`, it is also called twice in the build process.
This is basically the code I used to showcase the behaviour:
```
javascript
export async function generateStaticParams() {
  return [{ id: "1" }, { id: "2" }]
}

... [Log Snipped] ...

export default Day
```

Another thing to notice is that each time the component seems to receive different `params` for the same `id`

### Expected Behavior
