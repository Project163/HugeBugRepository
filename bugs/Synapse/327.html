Title

Can't configure a socket time out for server and client side seperatly.

Description
When we set the Socket timeout in nhttp.properties it will be set for both server and client sides. But we should be able to configure separately.
Discussion
- As a Fix for this  i have introduced new nhttp properties to be defined at nhttp.properties file  

 http.socket.timeout.receiver = Socket timeout for Listner 
http.socket.timeout.sender = Socket timeout for Sender.
- This fix is in the trunk. Hence resolving the issue.
