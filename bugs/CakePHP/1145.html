Title

5.x: Regression with named routes

Description
### Description

A plugin uses
```
php
$builder->setRouteClass(DashedRoute::class);
$builder->connect(
			'/edit/*',
			['controller' => 'Tags', 'action' => 'edit'],
... [Log Snipped] ...

		$request = ['_name' => 'Tags::edit'];
```
and
```php
$routes = Router::getRouteCollection()->named();
$defaults = $routes[$url['_name']]->defaults;
```
It now contains 
```php
[
  'controller' => 'tags',
  'action' => 'edit',
  'plugin' => null
]
```
But this used to be `Tags` and due to this change there is now breaking behavior that is unexpected.

So for some reason the lowercasing is happening where it should not, making comparison impossible.

### CakePHP Version

5.x

### PHP Version

8.1

See now failing tests [URL]
Discussion
- I have narrowed it down to this line being called
```
\Cake\Routing\Router::url(['_name' => 'Tags::edit']);
```
this results in the controller name being changed from uppercase to lowercase.
Digging deeper...
- Its the `$url = $this->_dasherize($url);` call inside the DashedRoute.
```
array (
  'controller' => 'Tags',
  'action' => 'edit',
  'plugin' => NULL,
)
```
will turn into
```
array (
  'controller' => 'tags',
  'action' => 'edit',
  'plugin' => NULL,
)
```
