Title

invalid mat2x3 * mat3x2 operator overload

Description
In glm/detail/type_mat2x3.inl line 435 why is there a second definition of operator*(mat2x3,mat3x2) returning a mat4x3? This doesn't make sense mathematically and conflicts with the corrent definition in line 405 resulting in compile time errors like:

ambiguous overload for 'operator*' (operand types are 'T {aka glm::tmat2x3 }' and 'V {aka glm::tmat3x2 }')
Discussion
- I think it should be mat2x3 \* mat4x2 instead of mat2x3 \* mat3x2 - that one seems to be missing
- (and for mat2x3 \* mat4x2 the function on line 435 seems correct and the return value would match)
- So I suggest this patch: [URL]
- This issue is fixed in branch 0.9.6 for GLM   release.
