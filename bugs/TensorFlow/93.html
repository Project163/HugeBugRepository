Title

Should check whether n_class is zero before calling sample_n() in mixture.py

Description
### Problem Description
Mixture model first use categorical to sample how much samples it need for each mixture components (this is variable `n_class` at [Link: line 308], but it actually means **number of samples per component**), and then it pass `n_class` to `sample_n()`.

The problem is `n_class` could be 0 and you can't pass `shape=0` to `tf.random_gamma(shape, alpha, ...)`, which is used in Beta distribution. (see [Link: line 310] in mixture.py)

### If possible, provide a minimal reproducible example (We usually don't have time to read hundreds of lines of your code)
It's easy to reproduce: just create a mixture of Beta + Uniform with 50/50 probability. Half of the time it'll sample from uniform, and half of the time it'll sample from Beta.
```
python
#!/usr/bin/python
import tensorflow as tf
ds = tf.contrib.distributions

... [Log Snipped] ...
    for i in range(1000):
        print sess.run(x)
```

    Just create a zero tensor with shape 0 when `n_class` is **0** and let the reshape operator at [Link: line 330] to worry about the shape.

2. Support `shape=0` in `random_gamma(shape, alpha, ...)`. Personally I think it's a bad idea. It already caused `InvalidArgumentError` exception, which means the one who implemented this might already considered this problem before.
