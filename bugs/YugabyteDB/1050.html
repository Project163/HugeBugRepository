Title

[xCluster] Add index to the colocated table halts the replication

Description
Jira Link: [Link: DB-7414]
### Description

**Version**: ` -b65`
**Steps**

1. Create colocated DB and table at source
2. Take backup of DB and restore at target
3. Setup replication from source to target
4. Run workload and validate the replication - it works fine

5. Create index at source and wait until index backfill to complete
6. Then Create same index at target and wait until backfill to complete
7. Then check the data at source and target - There will be **data mismatch** and **replication will halt when the index is being created at source**

**Transactional setup**
Same steps as above and run transactional Workload
Here while creating same index at target it got stuck and create index operation didn’t finish at all
