Title

Error: Unknown node type AssignmentPattern

Description
The following code:

``` js
var o = {
    f(c = 2) {}
};
```

breaks ESLint 1.5.1 (i.e. the latest one) completely:

```
/Users/mgol/Documents/projects/bn/cbn/repo/polona-gui/node_modules/estraverse/estraverse.js:517
                        throw new Error('Unknown node type ' + nodeType + '.');
                        ^

Error: Unknown node type AssignmentPattern.
... [Log Snipped] ...
    at Object.cli.execute (/Users/mgol/Documents/projects/bn/cbn/repo/polona-gui/node_modules/eslint/lib/cli.js:159:95)
    at Object.  (/Users/mgol/Documents/projects/bn/cbn/repo/polona-gui/node_modules/eslint/bin/eslint.js:61:20)
```

One issue is that this code is valid ES6 and should be recognized; another one is that a parse error should at least show which file cannot be parsed; it's very hard to find the reason when you have thousands of files and you just know one of them is causing this.
