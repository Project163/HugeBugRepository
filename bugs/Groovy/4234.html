Title

 PostgreSQLContainer (from Tescontainers library) is declared as

- You are using  PostgreSQLContainer  as a raw type, so there is no explicit argument assigned to the  SELF  type parameter.  Looks like the "fully-resolve" code that tries to get a concrete type to work with (aka  StaticTypeCheckingVisitor#inferReturnTypeGenerics ) is getting Object in the current codebase. 

 If each of the "with" methods are returning "this" and not a new instance, your grooviest workaround would be: 
  
 
 def  postgreSqlServer =  new  PostgreSQLContainer().tap {
  withExposedPorts(5432)
  withEnv(TZ:  "Europe/Paris" )
  withDatabaseName( "my_database" )
  withUsername( "user" )
  withPassword( "pass" )
}
