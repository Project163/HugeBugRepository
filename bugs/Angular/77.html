Title

Change `@proxy()` to `@proxy`

Description
[URL] caused a regression in Dart output. `@proxy()` is an incorrect way to use `proxy`. It must be `@proxy` as it is a predefined constant.

/cc @jelbourn
Discussion
- Why didn't any of our tests catch this defect?
- Probably some combination of the following:
- we do not run Dart analyzer on the offending code (or it passes the analyzer check)
- we do not compile our unit tests to JS
- Dart VM doesn't care to eval `@proxy` because this annotation is not used at runtime (it's used for static analysis only) and therefore never fails any of our tests
- Is it because we don't run Dartium in checked mode for our testing? Can you
fix that?
