Title

Producer should handle COORDINATOR_LOADING error in TxnOffsetCommit

Description
The producer should check for the COORDINATOR_LOADING error when handling the TxnOffsetCommit response. We fixed the logic in GroupCoordinator to correctly check for offset loading in  [URL] Prior to this fix, it was not possible to see this error, so we were able to get away with not having the check.
