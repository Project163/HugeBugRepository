Title

[Failed to find Server Action "a944...". This request might be from an older or newer deployment]- Using Server action in parallel routes causing unexpected error

Description
### Link to the code that reproduces this issue

[URL]

### To Reproduce

1. Start application in development mode (next dev)
2. You will see two "div" side by side with headings - "@Left" and "@Right".
3. Click on "Go to LeftPage1" Link.
4. Click on "Go to RightPage1" Link.
5. Click on "Submit" button in the left div.

### Current vs. Expected behavior

Current: 
The server action "getData" doesn't work and an error comes on the dev Terminal: "Error: Failed to find Server Action "a944...". This request might be from an older or newer deployment. Original error: Invariant: Couldn't find action module ID from module map."

Expected:
The server action "getData" should work and response data should show in the left div below the "Go to LeftPage2" Link after clicking the "Submit" button.
