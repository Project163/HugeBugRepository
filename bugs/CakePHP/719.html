Title

Using DateTime in a find does not work when selecting on external tables' fields

Description
Using a DateTime in a condition or a `where()` works fine when the field being selected on is in that same Model/Table:

**EventsTable.php**

```
    public function getUpcoming() {
        return $this->find('all', [
            'conditions' => ['Events.date >' => new \DateTime('now')],
            'order' => 'Events.date ASC'
        ]);
    }
```

However, when using it as a value of a condition on a foreign table's field, it refuses to work.

**OtherTable.php**

```
    public function findUpcoming() {
       return $this->find('all', [
            'contain' => ['Events'],
            'conditions' => ['Events.date > ' => new \DateTime('now')]
       ]);
    }
```

I consistently am notified that:
`Warning (4096): Object of class DateTime could not be converted to string [CORE/src/Database/Type.php, line 261]`

Looking at the query, it does indeed return a blank string and isn't entered into the SQL statement. When I change the value of the condition on Events.date to `date('Y-m-d H:i:s')`, all is well. In addition, when I query on `Other.date` (i.e. a date field within the _OtherTable_), I can use DateTime. 

Is this just me, or what gives?
