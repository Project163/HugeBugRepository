Title

[DocDB][ASH] rpc_request_id is not unique in the same tserver

Description
Jira Link: [Link: DB-13060]
### Description

```
-[ RECORD 1 ]--------+-----------------------------------------
query                | DELETE FROM bankaccounts WHERE id = $1
sample_time          | 2024-09-27 11:47:58.973128+05:30
root_request_id      | 2d87fd76-4668-54e3-b60e-9d5fd2c3314a
rpc_request_id       | 25017
... [Log Snipped] ...
wait_event_type      | WaitOnCondition
ysql_dbid            | 13266
```

The above two samples are exactly same except `wait_event_aux`. If the sample time is same, and we have two different samples, that means there are two different RPCs currently, so the rpc_request_id should be different, but here both these samples have the same rpc_request_id
