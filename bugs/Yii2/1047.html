Title

Language code with digits (e.g. "en-150") triggers Invalid Argument error in yii2/i18n/PhpMessageSource.php

Description
### What steps will reproduce the problem?

set language code to any value containing digits, e.g. "en-150", "en-001", "es-419"

### What is the expected result?

no error


### What do you get instead?

`getMessageFilePath()` in `yiisoft/yii2/i18n/PhpMessageSource.php` returns an InvalidArgumentException.

That is because the `preg_match()` in line 137 returns false – regular expression `^[a-z_-]+$/i` doesn't match digits

It should probably be changed to `^[a-z0-9_-]+$/i`
