Title

Inconsistent isAttribute & getAttribute behavior in Groovy 4 with traits

Description
As a follow-up to   GROOVY-10621  : 

 The following class in groovy 4: 
  
 
 class  Testing {
     boolean  deleted
}  
  
 will generate `getDeleted()` & `isDeleted`, but if a trait adds the property like this code: 
  
 
trait ParentTesting {
  boolean  deleted
}
 class  Testing  implements  ParentTesting {
}  
  
 It will generate only the isDeleted() and not the getDeleted() on the testing class. 

 Also, the behavior change mentioned in   GROOVY-10621   is not mentioned in the Groovy 4 release notes.  Can this behavior either be made consistent or reverted to pre-groovy 4 behavior?
