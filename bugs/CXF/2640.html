Title

Unable to override Content-Type on GET requests

Description
Please consider the following code: 

 ClientBuilder.newClient() 
    .target("[URL]
    .request(MediaType.APPLICATION_JSON) 
    .header(HttpHeaders.CONTENT_TYPE, MediaType.APPLICATION_JSON) 
    .get(); 

 which results in: 

 GET / HTTP/1.1 
Content-Type:  /  
Accept: application/json 
User-Agent: Apache CXF 3.1.2 
Cache-Control: no-cache 
Pragma: no-cache 
Host: localhost 
Connection: keep-alive 

 Expected would be: 
... 
Content-Type: application/json 
... 

 I'm using the following dependency: 
compile 'org.apache.cxf:cxf-rt-rs-client:3.1.2' 

 Is there any way to set the Content-Type on GET requests?
Discussion
- It was fixed yesterday. Though not because we wanted to support GET and Content-Type but to let people override a wildcard Content-Type in case of empty requests. 

 Please try the snapshots
- It is fixed indeed. Thanks.
