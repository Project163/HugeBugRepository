Title

Description
I noticed some new failures with pytest-dev where collection errors are occuring with "duplicate parametrization" messages.

Here's a minimal example:
```
python
import pytest

@pytest.fixture(params=["a", "b"])
... [Log Snipped] ...

    assert str(val) == str(target)
```
