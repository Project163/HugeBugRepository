Title

getEntityClass Regression in 3.6.8

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.6.8
`$alias = Inflector::singularize(substr(array_pop($parts), 0, -5));`
was changed to:
`$alias = Inflector::classify(Inflector::singularize(Inflector::underscore(substr(array_pop($parts), 0, -5))));`
Suddenly my Entity Class "Address" is not found anymore because it is inflected to "Addres"

When I changed those line back to the previous one (in CakePHP 3.6.7), then it works as expected.
Discussion
- The problem is caused due to double singularization since `classify()` already calls `singularize()` internally.
