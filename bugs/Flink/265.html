Title

Flink uberjar does not work with Java 6

Description
Apparently the uberjar created by maven shade does not work with java 6 

  
 /jre1.6.0_45/bin/java -classpath flink-0.9-SNAPSHOT/lib/flink-dist-0.9-SNAPSHOT-yarn-uberjar.jar org.apache.flink.client.CliFrontend

Discussion
- The issue is that Java 6 can not load jar files with more than 65536 files. 

  [URL]
It seems that we've recently surpassed that number for our uberjar. 
It contains 65868 files.
- There are tools like ProGuard which can reduce the number of class files by removing unused code.
