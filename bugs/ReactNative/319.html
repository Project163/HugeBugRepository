Discussion
- Could only reproduce on iOS, Android appears to be fine.
- A temporary workaround would to be extract the `testID` prop and instead assign it to the `View` that wraps the `PlatformActivityIndicator` in [Link: ActivityIndicator.js]. However, I don't think that this behaviour is wanted, because from what I've read [Link: here], is seems that `testID` is also assigned on native views on IOS. While the `testID` would still show up when inspecting the native components, it might break some tests for future versions. It also may be a bit of a hack, because the real bug is likely lying in native code.
