- Hi @satanTime, thanks for reporting the issue.

PR #39235 (changes were released in v11.1.0) introduced additional cleanup logic for form controls and directives. This cleanup logic relies on the fact that `FormControlName` and `FormControl` directives are fully initialized, thus having the `valueAccessor` field defined as an instance of corresponding CVA (Control Value Accessor). There is a logic in [Link: selectValueAccessor function] that makes sure that this is the case and throws an error otherwise. However in your test there is a try-catch (in a form of `expect(...).toThrow(...)`) which ignores that error, thus directive instance ended up being not fully initialized.

This is unlikely to happen in real scenarios (i.e. in an app on a page), but some specific use-cases in tests might cause the error to happen. So I've created a PR #40526 to make the cleanup logic more resilient to this type of scenarios.

Thank you.
