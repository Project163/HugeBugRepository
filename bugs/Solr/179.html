Title

logged "hits" should be num matching docs, not num returned

Description

    
Discussion

    
- Trivial one line patch (also attached) 

 
	 rsp.getToLog().add("hits", rb.getResults().docList.size()); 
+    rsp.getToLog().add("hits", rb.getResults().docList.matches()); 
 

 If there are no objections, this should go in 1.3 and I'll commit shortly.
- Not sure if this should be changed, but I can see both sides.  I think the intent was to report how many were returned, which may differ from rows (albeit, it can only ever be the same as rows or less).  Don't know if that is useful or not.  I would suspect, like you did, Yonik, that most people think it should return the number of matches not just those that are returned. 

 An alternative would be to add a "matches" or "totalMatches" log entry and keep hits.
