Title

Fuzzy query parsing logic allows illegal syntax

Description
A user [Link: ran into an issue] when they passed an array for the "value" property in a fuzzy query:

	{
	  "query": {
		"fuzzy": {
		  "name": {
			"value": [
			  "donald",
			  "trump",
			  "president"
			],
			"boost": 1,
			"fuzziness": 1,
			"prefix_length": 0,
			"max_expansions": 50
		  }
		}
	  }
	}

Rather than failing with a parse error (e.g. "expected string not an array") it runs a query which fails to match anything.
Discussion
- In this case the `FuzzyQueryBuilder` would actually result in `"value": "]"` :  hence the unexpected result.
