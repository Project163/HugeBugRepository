Title

AsyncKafkaConsumer#close does not send heartbeat to leave group

Description
This bug can be reproduced by immediately closing a consumer which is just created. 

 The root cause is that we skip the new heartbeat used to leave group when there is a in-flight heartbeat request ( [URL]

 It seems to me the simple solution is that we create a heartbeat request when meeting above situation and then send it by pollOnClose ( [URL]
