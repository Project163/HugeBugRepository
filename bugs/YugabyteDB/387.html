Title

[YSQL] Wrong results for condition on DESC NULLS LAST column

Description
DocDB-pushdown of inequality conditions for `DESC NULLS LAST` columns do not correctly handle column order when computing the lower/upper bound for the DocDB scan.
Therefore, strict inequality conditions may yield wrong (missing) results, while inclusive inequality 
will behave like equality.
This only affects `DESC NULLS LAST` and only if the condition is pushed down to DocDB. 
The others ( either variant of `ASC` and `DESC NULLS FIRST`) work fine.

```
create table test(h int, r int, v int, primary key (h HASH, r DESC NULLS LAST));
insert into test(h,r,v) values (1,1,1), (1,2,2), (1,3,3), (1,4,4), (1,5,5);
select * from test where h = 1 and r >= 2;
```
```
 h | r | v
---+---+---
 1 | 2 | 2
(1 row)
```
