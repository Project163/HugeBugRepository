## Current behavior
 
Some of the router code executes `Object.freeze` on parts of the UrlTree before using it to create an ActivatedRoute (example: [URL] While this helps avoid incorrect usage of ActivatedRoute, `Object.freeze` actually operates in-place on the queryParams object, and thus affects the UrlTree as well.

## Expected behavior
 
Since the UrlTree can be used/modified to represent a navigation target (and is used in UrlHandlingStrategies), the queryParams should ideally not be frozen.
