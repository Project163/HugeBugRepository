Title

Cannot set property scrollRestoration of [object History] which has only a getter.

Description
# 🐞 bug report

### Affected Package
 
The issue is caused by package @angular/common. There is a method named _setHistoryScrollRestoration_ in the **viewport_scroller.ts**.


### Is this a regression?

 
I don't think so.


### Description
Not much, i only got this error from ErrorHandler from some particular IP adresses.

Discussion
- There is a proposed PR for this at #30630
- It seems from [URL] that this issue is caused by specialised browsers that do not support scroll restoration (e.g. some web crawlers). Given that we already sniff the browser to see if it has the `window.scrollTo` method, I think it would also be reasonable to check whether `window.history.scrollRestoration` is writable too.
