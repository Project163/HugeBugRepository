Title

Java client ignores missing heartbeats

Description
The Java JMS client for AMQP 0.10 doesn't seem to detect missing heartbeats. In the logs it is visible that the client is responding to the heartbeats received from the broker. But when I suspend the broker, the client doesn't mind that no heartbeats are received. I would expect that the client should detect missing heartbeats and timeout the connection after 2 heartbeat intervals.
