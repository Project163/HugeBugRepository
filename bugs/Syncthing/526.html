Title

"kiB" should be "KiB"

Description
Easy one. `kiB` is capitalized incorrectly in device download/upload rates. `MiB`, `GiB`, and `TiB` are fine.

[URL]
Discussion
- Just for future searches:

- [Link: International System of Units (SI)] is a standard which defines the prefix "kilo" (symbol "k") as 1000 (10 3 );
- [Link: ISO 80000, or IEC 80000], is a standard which defines the prefix "kibi" (symbol "Ki") as 1024 (2 10 ).
