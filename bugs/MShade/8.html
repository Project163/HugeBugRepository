Title

Fix case-insensitive string comparisions in resource transformers

Description
String.toLowerCase()   is sensitive to the JVM's default locale and hence platform-dependent, potentially yielding wrong build output. For instance: 
  
 Locale.setDefault(  new  Locale(  "en"  ) );
 System .out.println(  "META-INF/NOTICE" .toLowerCase().equals(  "meta-inf/notice"  ) );
Locale.setDefault(  new  Locale(  "tr"  ) );
 System .out.println(  "META-INF/NOTICE" .toLowerCase().equals(  "meta-inf/notice"  ) );
 
  
 will print 
  
 true
false
 
  
 See also  Common Bugs .
