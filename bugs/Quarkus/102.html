Title

Configuration guide - incorrect description of injecting non-existing properties

Description
The guide: _"If you do not provide a value for the first property, it will have a null value."_ However, injecting a non-existent property results in `DeploymentException` during app startup, i.e. something like `No config value of type [class java.lang.String] exists for: greeting.message`.

This behavior is defined by the MP Config spec.
