Title

[False positive][L7] ?bool comparison in (else)ifs imposes side-effects and drops nullability

Description
Having a method with nullable bool return type and comparing its return value in if + elseifs.
```php
	public function foo(): ?bool
	{
		return false;
	}
```

When comparing null first, then true and false, it works. 
```
php
	public function bar(): int
	{
		if ($this->foo() === null) {
			return 1;
... [Log Snipped] ...
		assert(false);
	}
```
See [URL]

When comparing to true and false first and null at last, an error is produced: `Strict comparison using === between bool and null will always evaluate to false.`:
```
php
	public function bar(): int
	{
		if ($this->foo() === true) {
			return 1;
... [Log Snipped] ...
		assert(false);
	}
```
See [URL]

Looks like a side-effect during comparison, causing nullability flag being dropped.
