Title

Using DbTxnManager with concurrency off results in run time error

Description
Setting 
  
 hive.txn.manager=org.apache.hadoop.hive.ql.lockmgr.DbTxnManager
hive.support.concurrency= false 
 
  

 results in queries failing at runtime with an NPE in DbTxnManager.heartbeat.
Discussion
- This is an invalid configuration and should result in an error, but the error should come at compile time rather than runtime.
- This patch changes DbTxnManager to check that concurrency is set to true when it is handed the config file.
