Title

Replcace `Array.toString` with `Array.mkString`

Description
Some code in Spark as follows: 
  
 
val appDirs = workDir.listFiles()
 if  (appDirs ==  null ) {
   throw   new  IOException( "ERROR: Failed to list files in "  + appDirs)
}  
  
 appDirs is an `Array` and `Array.toString` will print as `className#hashCode`, this result seems meaningless and  Array.mkString should be used.
