Title

[CDCSDK] CDC Data Loss Observed in CDC Master Case After Enhancing test with Index and MV Operations

Description
Jira Link: [Link: DB-16301]
### Description

Data loss is observed in the CDC master test case after extending the test to perform additional operations such as:

- CREATE INDEX
- DROP INDEX
- CREATE MATERIALIZED VIEW
- REFRESH MATERIALIZED VIEW

These operations were introduced to enhance the test coverage, but their inclusion appears to have introduced scenarios where changes are not being captured or retained correctly in the CDC stream. Further investigation is required to identify the root cause and ensure CDC integrity when such operations are present.

Please find slack thread and run details in JIRA.

### Source connector version

quay.io/yugabyte/ybdb-debezium:dz.2.5.2.yb.2024.2.3 (Seen in both gRPC and logical replication connector)
