Title

[DocDB][ASH] query id is 0 in some ASH samples

Description
Jira Link: [Link: DB-16198]
### Description

In some cases, we observe 0 query id in some samples. This is mostly due to
- We sample before updating the metadata
- The RPC is sent by the master (we don't have metadata passing through master yet)
- The RPC is handed off to another thread and we didn't inherit the wait state in the other thread
