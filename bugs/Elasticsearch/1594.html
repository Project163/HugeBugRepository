Title

ingest-attachment adds content-length as string

Description
If you run Elasticsearch with the ingest-attachment plugin:

```
gradle plugins:ingest-attachment:run
```

And then you use it on a document:

```
js
PUT _ingest/pipeline/attachment
{
  "description" : "Extract attachment information",
  "processors" : [
... [Log Snipped] ...
}
GET my_index/my_type/my_id
```

You get this back:

```
js
# PUT _ingest/pipeline/attachment
{
  "acknowledged": true
}
... [Log Snipped] ...
  }
}
```

This part seems wrong

```
      "content_length": "28"
```

`content_length` feels like a number rather than a string. That'd make its dynamic mapping type a number which'd be useful for things like range queries.
