Title

In v0.18.0 reading script from STDIN doesn't work with Insights

Description
When running the v0.18.0 Docker image with results streaming to Insights (`-o cloud`) it stops and prints:
`time="2017-11-23T13:19:39Z" level=error msg="0 Validation error"----]   collector`

The error message comes from the cloud API (https://ingest.loadimpact.com/), but the communication with the cloud works with the pre-built binaries and earlier versions of the Docker image so points to some kind of issue with the Docker image.

- Both the `latest` and `0.18.0` tags are broken in this regard. The most recent version of the Docker image that works is `0.17.2`.
- It seems the problem is with reading the script from stdin via `-<`. Both v0.18.0 binary and Docker image fails when running with `-o cloud` and reading from stdin. They both work when passing the filename as last arg (using a volume for Docker).
