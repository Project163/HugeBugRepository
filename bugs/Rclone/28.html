Title

Windows: Support "\\server\share\folder" as local filesystem.

Description
Currently 

```
c:\GoPath\src\github.com\ncw\rclone>go build && rclone copy c:\HaxLogs.txt \\server\share\dir
2015/09/11 11:54:52 Local file system at /server/share/dir: Building file list
2015/09/11 11:54:52 Local file system at /server/share/dir: Waiting for checks to finish
2015/09/11 11:54:52 Local file system at /server/share/dir: Waiting for transfers to finish

... [Log Snipped] ...
Transferred:            1
Elapsed time:  17.1175ms
```

Files are copied to /server/... on the current drive.

With #129 applied, it fails with an error:

```
c:\GoPath\src\github.com\ncw\rclone>go build && rclone copy c:\HaxLogs.txt \\server\share\dir
2015/09/11 11:58:17 Attempt 1/3 failed with 1 errors and: mkdir //server: Invalid path.
2015/09/11 11:58:17 Attempt 2/3 failed with 1 errors and: mkdir //server: Invalid path.
2015/09/11 11:58:17 Attempt 3/3 failed with 1 errors and: mkdir //server: Invalid path.
2015/09/11 11:58:17 Failed to copy: mkdir //server: Invalid path.
```

This is because the `filepath.ToSlash()` changes the path to "//server/". The obvious solution is to skip `filepath.ToSlash()` if the path starts with "\\". Any objections?
Discussion
- Makes me wonder if that `ToSlash` is needed at all.  Provided Windows is OK with paths with mixed `/` and `\`...
- I am bit worried about file matching, but it should be easy to test by mixing \ and / in paths.
