Discussion
- bisected to #15586
- I have a fix for this, but it's blocked on #15812.

For the context: In #15586, we added feature gates for all the image formats. We also moved all the supported extension stuff to `bevy_image`. This included making a constant array of all the supported formats. Sadly, this list of supported formats is on the `ImageFormat` type, not the `ImageLoader` type. This makes it awkward since we can't remove exr and hdr formats from this list (because then the array doesn't have all the formats like it suggests). We also can't move this list of supported formats to `bevy_render`, since it doesn't have all the image format feature flags. So #15812 moves the `ImageLoader` to `bevy_image`, and my next PR moves the supported format stuff to `ImageLoader` and removes exr and hdr from that list.
