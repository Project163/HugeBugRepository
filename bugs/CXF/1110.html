Title

NPE in wsdl2java if soap:binding tag is omitted

Description
The cxf-codegen-plugin's wsdl2java functionality fails with a NullPointerException if the soap:binding tag is omitted from the WSDL. Reintroducing the soap:binding tag avoids the NPE.
Discussion
- The WSDL which causes an error. If you uncomment the "soap:binding" line on line 38, the error goes away.
- The stack trace which is thrown by the cxf-codegen-plugin.
- The solution appears to be to halt with a user-friendly error message should either no binding or one of the three bindings supported by CXF (SOAP, CORBA, XML) not be given.
