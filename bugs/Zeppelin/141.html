Title

Big Result are shown outside the container

Description
When custom result is too wide (html for example), the result will burst out of the container and create a scrollbar at page level. 

 The result should always be constrained to the paragraph result container
Discussion
- Thanks for filing the issue. 
Should the contents be wrapped within the parent container or should there be a scrollable div holding the results when they are wide enough. Having a scrollable div could also mean we could opt for both vertical and horizontal scrollbars, similar to what Jupyter does for long results.
- There should be a scrollbar on both axis if the result content is bigger than the container. 
We are not really supposed to have that problem with graphs (since they are 100%), but I do see it sometimes when resizing. 
And it's already handled when results are in the table. 
So the main use would be for custom HTML rendering
