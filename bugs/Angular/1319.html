Title

DatePipe treats ISO-8601 YYYY-MM format as a date-time and adds timezone

Description
# 🐞 bug report

### Affected Package
 
  
@angular/common
### Is this a regression?

 
  No

### Description

  
I am trying to use the `DatePipe` with a string input that is in the ISO-8601 Year and Month format `YYYY-MM`. The DatePipe doc states that it supports ISO-8601 strings: [URL]

The `DatePipe` incorrectly assumes the date is in GMT time. Then the resulting output is converted to the user's locale, which can cause off-by-1-day errors depending on your timezone.

E.g. `{{"2019-02" | date:'MMM. yyyy'}}`
Expected:  `Feb. 2019`
Actual: `Jan. 2019`



I don't see the same issue when using the other ISO-8601 format `YYYY-MM-DD`, there is a specific piece of code to handle timezone offsets for it: [URL] I think it should also apply to the `YYYY-MM` format.
