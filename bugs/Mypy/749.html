Title

Python 3 stdlib stubs are sometimes used in Python 2 mode

Description
This generates no errors in Python 2 mode:

```py
from urllib import parse
```

Note that `urllib.parse` is not available in Python 2. It looks like we fall back to the Python 3 stubs for this and some other stdlib modules.

This also affects submodule imports from at least `unittest` and `collections`.

If a stdlib module has stubs under `stdlib/@python2`, we shouldn't look for additional stubs in `stdlib`.

This is a regression from mypy 0.812 introduced with the new typeshed structure.
