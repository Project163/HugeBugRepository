Title

Chef apply provisioner validation

Description
The chef apply provisioner causes validation errors due to the `node_name` attribute being set. This is due to the `node_name` configuration attribute being automatically set in the `Base` chef provisioner when not set. Since it is not a valid configuration attribute for chef apply, validations occur when checked.
