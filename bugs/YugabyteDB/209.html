Title

Assertion error when inserting into temporary table from JDBC

Description
**Test Case:**
```
try (Statement statement = connection.createStatement()) {
  statement.execute("CREATE TEMP TABLE test_table(a int, b int, c int, PRIMARY KEY (a))");
  statement.execute("INSERT INTO test_table(a, b, c) VALUES (1, 2, 3)");
}
```
**Result:** The INSERT statement causes the following assertion to fail:
```
TRAP: FailedAssertion("!(!((allPgXact[proc->pgprocno].xid) != ((TransactionId) 0)))", File: "../../../../../../../src/postgres/src/backend/storage/ipc/procarray.c", Line: 441)
```
Note: This issue does not occur from `ysqlsh`, only when connecting through JDBC.
