Title

Newlines in evaluated JavaScript behavour

Description
Sometimes we need something more complex than a single-line JavaScript expression to be evaluated in our stylesheets, just to provide readability. However, while this works completely nice:

```
.class {
  property: `1 +
  1`; // outputs 2
}
```

More complex thing shows up with an error:

```
.class {
  property: `(function(){var x = 1 + 1;
  return x})()`; // everything crashes
}
```

Single-line equivalent works just fine:

```
.class {
  property: `(function(){var x = 1 + 1; return x})()`; // outputs 2
}
```
