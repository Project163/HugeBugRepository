- I've found a similar issue trying to test a controller action that should returns a file. After a little research I think that the problem is [Link: here]. 
It seems that in this line cakephp is closing buffers that it should not, I'm not sure about that, but if I remove that line, test runs as expected. 

It seems that when raising the exception, PhpUnit checks the value of `ob_get_level()` before run a test and then recheck after run it, and those values doesn't match, due to the call to `ob_end_clean()`.
