Title

yii.js handleAction method not detecting existing form

Description
Found issue on Yii 2.0.0-dev in `assets/yii.js` in method `handleAction()` on line 120.

Apparently there's a mechanism which ought to detect whether the `data-method` event invoking element resides within a form (`var newForm = !$form.length || action;`). 
Looking this line one might suspect that `newForm` is meant to be casted as a boolean. This is not the case, which leads to false negative detection of existing form wrappers. The line should be written as `var newForm = !($form.length || action);`.

Issue can be reproduced with the following code, the value of `input[name="relation"]` is not sent along with the request and the `action` url of the form is not called: 

```
echo Html::beginForm(Url::toRoute(['unlink'])).
Html::hiddenInput("relation", 'replaced').
Html::a(
    '  ',
    '#',
... [Log Snipped] ...
).
Html::endForm();
```
Discussion
- This fix does not function correctly, because `$e.prop('href')` returns the whole url (e.g. [URL] instead of the content of the `href` attribute. Changing this to `$e.attr('href')` solves the issue .
