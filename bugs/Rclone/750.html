Title

Webdav: server side copy or move doesn't overwrite

Description
Hello, I'm using webdav to sync two folders on my webdav server. But the sync always fail with 419 precondition failed.

The two folders have files with the same name and these files are causing the problems. The server is customized golang webdav server and it reproducible using `rclone serve webdav`.

After digging the request log and reading source code. I find it's because rclone specifying the wrong `Overwrite` header [Link: here] and [Link: here].

Golang webdav handles this header [Link: here] and [Link: here].
