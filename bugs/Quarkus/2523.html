Title

Tests report REST Assured timeout has been removed

Description
### Describe the bug

The quarkus configuration documentation states that the configuration parameter: `quarkus.http.test-timeout` can be used to set the timeout for the REST Assured HTTP client [Link: here]
However, if you set this parameter and run tests using `quarkus build` you get the warning:
`2025-11-17 15:30:53,973 WARN  [io.qua.config] (main) Unrecognized configuration key "quarkus.http.test-timeout" was provided; it will be ignored; verify that the dependency extension for this configuration is set or that you did not make a typo`
This bug has been reported before in a much earlier version of quarkus [Link: here]

### Expected behavior

The configuration parameter is accepted and the HTTP timeout configured per the docs

### Actual behavior

A warning is generated (see above) and the timeout is not applied.

### How to Reproduce?

Quickest way to reproduce is to check out the first project from [URL]
In the src/test/resources/application.properties file add:
`quarkus.http.test-timeout=120s` 
Run `quarkus build`
