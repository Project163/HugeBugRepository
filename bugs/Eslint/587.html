Title

Warnings output due to .gitattributes during release

Description
In the last release, this popped up:

```
Generating eslint.org
Note: is not a valid attribute name: docs/rules/.gitattributes:5
[Documentation is not a valid attribute name: docs/rules/.gitattributes:15
Note: is not a valid attribute name: docs/rules/.gitattributes:5
[Documentation is not a valid attribute name: docs/rules/.gitattributes:15
... [Log Snipped] ...
Note: is not a valid attribute name: docs/rules/.gitattributes:5
[Documentation is not a valid attribute name: docs/rules/.gitattributes:15
```
Discussion
- This is happening because we are copying over `.gitattributes` as if it were rule documentation. We need to omit any files beginning with `.`.
