Title

[YSQL] ASAN tests fails due to accessing deleted object

Description
`DocPgsqlScanSpec` class stores `hashed_components` and `range_components` as the pointers. But in the following case both  `hashed_components` and `range_components` will be destroyed after constructor completion. Pointers in the `spec` object will points to destroyed objects.

```
    docdb::DocPgsqlScanSpec spec(
        projection, rocksdb::kDefaultQueryId, {} /* hashed_components */, {} /* range_components */,
        &cond, boost::none /* hash_code */, boost::none /* max_hash_code */, nullptr /* where */);
   RETURN_NOT_OK(doc_iter->Init(spec));
```
