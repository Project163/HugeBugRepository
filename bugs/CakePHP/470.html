Title

3.0: 'empty' not working on $this->Form->input()

Description
It appears that the 'empty' option is not working on the form select in views.  E.g:

```
echo $this->Form->input('parent_id', ['label' => 'Set Parent Page', 'options' => $pages, 'empty' => 'No Parent']);
```

The following error is being thrown:

```
Error: Unsupported operand types
File /home/michael/public_html/bettornet/vendor/cakephp/cakephp/src/View/Widget/SelectBox.php
Line: 167
```

When setting 'empty' => false, it works OK, but it should allow the option to add a string there for the default select option.
