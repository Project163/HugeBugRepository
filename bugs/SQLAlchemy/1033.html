Title

TypeDecorator.with_variant ignored in type compilation

Description
**Describe the bug**
I found out, that `with_variant` has no effect on type compilation, for example in `CREATE TABLE` SQLs.

I discovered bug using `ScalarListType` from sqlalchemy-utils, see [URL] but doesn't seem to be caused by that particular implementation.

**Expected behavior**
Variant type should be used for defined dialect.

**To Reproduce**
```
py
from sqlalchemy import ARRAY, Column, Integer, MetaData, Table, UnicodeText, types
from sqlalchemy.dialects import postgresql, sqlite
from sqlalchemy.schema import CreateTable
# from sqlalchemy_utils import ScalarListType
... [Log Snipped] ...
print("ScalarListType in PostgreSQL:")
print(statement_rev.compile(dialect=postgresql.dialect()))
```

**Output**

```
ARRAY in SQLite:

CREATE TABLE "table" (
	"attach" TEXT
)
... [Log Snipped] ...
	attach TEXT
)
```
In the second case, the `ARRAY` variant for PostgreSQL is ignored and main type `TEXT` is used instead.

**Versions.**
 - OS: Linux queeg-500 5.8.0-2-amd64 #1 SMP Debian 5.8.10-1 (2020-09-19) x86_64 GNU/Linux
 - Python: Python 3.9.1
 - SQLAlchemy: 1.3.20, 1.3.22, 1.4.0b1
 - Database: SQLite & PostgreSQL
