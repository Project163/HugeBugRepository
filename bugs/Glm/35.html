Title

C++11 not activated by default with g++ -std=c++11

Description
This can be achieved by testing for __cplusplus macro in setup.hpp.

from [URL] :
"G++ now sets the predefined macro __cplusplus to the correct value, 199711L for C++98/03, and 201103L for C++11"

The workaround is to define GLM_FORCE_CXX11
Discussion
- This issue is now fixed in GLM 0.9.4 for the upcoming release.
