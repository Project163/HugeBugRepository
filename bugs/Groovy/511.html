Title

Inconsistent compilation behaviour: No exception thrown for javac, but exception for groovyc when doing joint compilation

Description

    
Discussion

    
- looks like the implementation ignores the output of javac completely. I did a bit research on the net and found that besides the compile(String[]) method, there is also a compile(String[],PrintWriter) method. This PrintWriter will then contain the output. So I will do the following, I will test if this method is available and if so and an error happens I will use this output as message text for my groovyc error. I found another web site stating that compile gives the following return values: 

 0: compilation ok. 
1: compilation error 
2: command line usage error 
3: system error (what ever this is) 
4: abnormal javac program termination 

 So I wrote a message that will reflect an information about this codes at last. I ma not sure about side effects yet. I will close this issue as fixed for now.
