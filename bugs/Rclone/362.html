Title

OneDrive and shared folders - listing issue

Description
I just updated to the latest beta of rclone ( v1.43-036-g89be5cad-beta) on what Microsoft Graph code was merged into v 1.43, however on my personal OneDrive doing an rclone lsd on a Shared Folder only works on the first level of directories, example: `rclone lsd myonedrive:sharedfolder1/`.

Trying a `rclone lsd myonedrive:sharedfolder1/sharedfolder2/` delivers this error:
```
2018/09/05 00:32:31 ERROR : : error listing: directory not found
2018/09/05 00:32:31 Failed to lsd: directory not found.
```
I did checked and sharedfolder2 in fact exists in the directory tree (this works well ok on non-shared folders).

The same happens when trying to copy files from `myonedrive:sharedfolder1/sharedfolder2/` to my local instance as it says
```
2018/09/05 00:34:31 ERROR : : error listing: directory not found
2018/09/05 00:34:31 Failed to lsd: directory not found
```

Any ideas on why listing directories is not working properly on shared folders?

This may be related to what is described here [Link] for crypt folders.
