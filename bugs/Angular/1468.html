Title

DOM elements are not removed when the root view is removed if the RendererFactory2 is injected into the root provider

Description
### Which @angular/* package(s) are the source of the bug?

animations

### Is this a regression?

Yes

### Description

All DOM elements remain when calling `NgModuleRef.destroy()`, but actually, all `ngOnDestroy` hooks are invoked, event listeners are removed, basically, all cleanups are done except removing nodes from DOM.

:warning: This happens only when the `BrowserAnimationsModule` is imported and the `RendererFactory2` is inejcted, this doesn't happen with `BrowserModule`.
