Title

Bazel 0.5.2 prints "bit length overflow" messages when building deploy jars

Description
Please provide the following information. The more we know about your system and use case, the more easily and likely we can help.

### Description of the problem / feature request / question:

This command:

```bash
bazel --bazelrc=/dev/null build //src:bazel
```

Prints rather weird warning messages when building deploy jars:

```
bash
INFO: From Building deploy jar src/java_tools/buildjar/JavaBuilder_deploy.jar:

bit length overflow
code 0 bits 6->7
... [Log Snipped] ...
bit length overflow
code 4 bits 6->7
```

The build seems to work fine. The resulting `bazel-bin/src/bazel` binary seems to work fine, too.

### If possible, provide a minimal example to reproduce the problem:

```bash
wget [URL]
bash bazel-0.5.2-installer-darwin-x86_64.sh --user
git clone [URL]
bazel clean --expunge
bazel --bazelrc=/dev/null build //src:bazel
```

The warning messages happen during the last part of the build (starting from action ~960).

### Environment info
* Operating System:
macOS 10.12.5

* Bazel version (output of `bazel info release`):
`release 0.5.2`
