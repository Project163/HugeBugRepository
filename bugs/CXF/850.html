Title

JAXRSClientFactoryBean selects a wrong user resource when the model includes multiple resource descriptions

Description
Reusing the model in a common module between server and client code does not work well in cases where the model describes multiple root resources - currently JAXRSClientFactoryBean assumes only a single ClassResourceInfo can be created. 

 With the model containing multiple resource descriptions it does not work reliably. The fix will insure the correct resource is selected
