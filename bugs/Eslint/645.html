Title

"key-spacing" align colon issue with comma-first

Description
ESLint version: **v1.5.0**

`.eslintrc`:

``` json
{
  "rules": {
    "key-spacing": [2, {"align": "colon", "beforeColon": false, "afterColon": true}]
  }
}
```

Failing source code - `fail.js`:

``` js
var obj = {
    foo : foo
  , bar : bar
  , cats: cats
};
```

Result:

``` bash
$ eslint fail.js 

/path/to/fail.js
  2:5  error  Missing space after key "foo"  key-spacing

✖ 1 problem (1 error, 0 warnings)
```

The error disappears when an extra two spaces are added before the first colon in the object.
e.g.
`no_fail.js`:

``` js
var obj = {
    foo   : foo
  , bar : bar
  , cats: cats
};
```

Am I missing something here? If more information is required, let me know.

Thanks.
