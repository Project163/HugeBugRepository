Title

.NET: CompiledQuery fails with embedded const parameters

Description
This works: 
  
  var  qry = CompiledQuery.Compile(( int  x) => cache.Where(x => x.Key < x));
qry(5).GetAll();
 
  

 And this fails: 
  
  var  qry = CompiledQuery.Compile(() => cache.Where(x => x.Key < 5));
qry().GetAll();
