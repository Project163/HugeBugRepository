Title

Spring Data JPA findFirstBy with Optional throws NullPointerException

Description
### Describe the bug

When using Spring Data JPA with Quarkus I get `NullPointerException` when using repository method with query keyword `findFirstBy` that returns `Optional`.

### Expected behavior

Method returns Optional.of(value) if it's present or Optional.empty if no value is present.

### Actual behavior

Call to `findFirstByOrderByCreatedAtDesc` throws `NullPointerException`:
``` java
public interface ExampleRepository extends JpaRepository  {
    Optional  findFirstByOrderByCreatedAtDesc();
}
```
Exception stacktrace:
```
java

	at java.base/java.util.Objects.requireNonNull(Objects.java:233)
	at java.base/java.util.Optional.of(Optional.java:113)
	at com.andreiyusupau.example.ExampleRepository_68d979ff1b1ad5d6d3707a1ecc50adb481e23c00Impl.findFirstByOrderByCreatedAtDesc(Unknown Source)
... [Log Snipped] ...
	at io.netty.util.concurrent.FastThreadLocalRunnable.run(FastThreadLocalRunnable.java:30)
	at java.base/java.lang.Thread.run(Thread.java:1583)
```

    ExampleEntity findFirstByOrderByCreatedAtDesc();
