Title

PropertiesConfigurationLayout does not preserve comments at bottom of a file

Description
Example: 
helloWorld.properties 

 hello = world 
#this comments would not be preserved
Discussion
- Thanks for the report. 

 The current implementation assigns a comment to the following property. This explains why a comment at the bottom of the file gets lost. We will have to think about a workaround.
- Fixed in revision 1457278. 

  PropertiesConfiguration  now reads a comment at the end of a configuration file and makes it available through the new  getFooter()  method. With  setFooter()  the end comment can be changed.
