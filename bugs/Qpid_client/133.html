Title

Don't close consumer when a drain request times out if the consumer is in a Transaction

Description
If the consumer is awaiting a stop action (draining) then a timeout can be set for the request and currently we close the link even if that consumer has messages that were acknowledged inside a transaction and awaiting completion of the transaction.
