Title

Synchronization on a string literal

Description
String literals are constant and are automatically interned, and hence act as global variables in the JVM. If someone tries to synchronize on the same string literal, a deadlock might occur. More information on the issue of synchronizing on strings:  [URL]

 The affected method is initSessionContext(Object startupObject):  [URL]

 The issue has been discovered as a result of static code analysis
