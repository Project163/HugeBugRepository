Title

Bootstrap Dropdown links do not work

Description
The links within a Dropdown do not work on click. I traced it to this [Link: line in Dropdown.php]. 

``` php
 $this->registerPlugin('dropdown');
```

The `registerPlugin('dropdown')` is not required - you just need to render the markup. If you add this line - the links in the dropdown are not clickable.
