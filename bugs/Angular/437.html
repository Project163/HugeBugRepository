- Ahah! Adding in the animations packages broke it. For ages I couldn't work out why.
But then I realised that there must be an unbalanced triple backtick in those docs.
The JSDOC parser tracks whether it is in a code block or not to decide whether it is supposed to ignore tags. But it was not re-initializing properly on each new run, so the bad docs from animations were putting everything out of sync.
