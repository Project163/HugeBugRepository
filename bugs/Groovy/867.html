Title

groovysh is initializing AWT

Description
Running  groovysh  is initializing AWT.  This is bad on Mac where it causes a generic Java app to launch.
Discussion
- Yea, that shouldn't happen.  Got a stack trace from the crash or a patch in mind?  Running with java.awt.headless=true doesn't throw any exceptions on windows.

 Changed to wait until 'inspect' is invoked to do the headless test and issue the message. 

 The problem with the Java app appearing and not being able to quit from that on Mac remains.  I believe there are Apple extensions that give control over it (like whether it is hidden), but no time for that right now.
