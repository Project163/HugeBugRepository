Title

`operator-assignment` incorrectly treats string concatenation as commutative

Description
The following:

``` js
var a = 'foo';
a = 'bar' + a;
var b = 123;
b = 'baz' + b;
var c = 'qux';
c = 123 + c;
```

results in:

```
  2:0  error  Assignment can be replaced with operator assignment  operator-assignment
  4:0  error  Assignment can be replaced with operator assignment  operator-assignment
  6:0  error  Assignment can be replaced with operator assignment  operator-assignment
```

Unless I've completely forgotten of a way to do this with an assignment operator, it is not possible to do what the rule encourages.
