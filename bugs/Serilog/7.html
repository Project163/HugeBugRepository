Title

JSON formatter output should be delimited when writing to files

Description
We wrote the JSON formatter for sinks like Mongo and Couch, but now that it can be used with regular files as well, we need to provide a way to delimit the JSON documents written to the file.

Newlines work very well for this (JSON well-formedness is hard to achieve, and splitting on newlines is easy when processing events).

My first thought is to add this behaviour by default to the formatter, and allow it to be switched off by the "pure JSON" sinks. This would be a binary breaking change however.

Alternatively we can provide a decorator for text formatters that does the delimiting, or a new encapsulation of the JSON sink that provides this feature.

Via #105
Discussion
- This will now work by default:

``` csharp
  // Or RollingFileSink()
  .WriteTo.Sink(new FileSink("log.jsnl", new JsonFormatter(), null))
```

The delimiter, if none is specified, will be `Environment.NewLine`. Providing the `closingDelimiter` parameter can override this, e.g. to use `""` if the original non-delimited behaviour is needed.

The change is binary-compatible with existing sinks that use `JsonFormatter`, but the old constructor is marked obsolete and on recompilation callers will be forced to use the named-args version.
