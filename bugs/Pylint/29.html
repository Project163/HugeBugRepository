Title

False positive for abstract-method (W0223)

Description
Originally reported by: **Antony Lee (BitBucket: [Link: anntzer], GitHub: @anntzer?)**

---

Pylint does not detect overriding of abstract attributes by non-function objects.  For example, in the following code, the definition of E (but not the one of D) raises the warning "Method 'prop' is abstract in class 'C' but is not overridden (abstract-method)".

```
#!python
import abc

class C(metaclass=abc.ABCMeta):
    @property
... [Log Snipped] ...
class E(C):
    prop = property(lambda self: 1)
```
