Title

Correct truncate token filter docs so it doesn't confuse `keyword` analyzer with the `keyword` field type

Description
relevant link: [URL]

On this page of documentation we say:
```
The truncate token filter can be used to truncate tokens into a specific length. This can come in handy with keyword (single token) based mapped fields that are used for sorting in order to reduce memory usage.
```

This is confusing now that we have `keyword` field types which cannot have an analyzer configured. We should change the wording to be clear we mean this is useful when using the keyword tokenizers on text fields.
