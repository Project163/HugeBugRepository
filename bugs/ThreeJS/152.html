Title

Non-indexed BufferGeometry with MultiMaterial

Description
##### Description of the problem 

The problem is in geometry.fromBufferGeometry method. If BufferGeometry is non-indexed it is impossible to use MultiMaterial. Because material index of group is taken into account only if BufferGeometry has index. 
[URL]
But it is not always the case. For example, BufferGeometry loaded from .OBJ file is non-indexed but has groups.
