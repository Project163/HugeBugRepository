## Issue

- After running `poetry install`, the project package itself is not added to python path.
- Our package is in `src/`, and defined in `pyproject.toml` to be included as `betterproto` (may or may not be related)

## Reproduce:

clone `betterproto`
```bash
git clone git@github.com:danielgtaylor/python-betterproto.git poetry-install-bug
cd poetry-install-bug
git checkout  
```

install poetry
```bash 
poetry run pip install --upgrade pip  # workaround for another bug, probably not essential to reproduce
poetry install
```

run a module that depends on the project package `betterproto`
```bash
poetry run python -m tests.generate
# ModuleNotFoundError: No module named 'betterproto'
```
