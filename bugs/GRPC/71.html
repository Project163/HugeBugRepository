Title

Some false sharing problems in struct grpc_completion_queue.

Description
Seeing some false sharing problems in "struct grpc_completion_queue". 

The following is how I identified the problems:
1. sudo -E ./run_performance_tests.py -l c++ --category scalable -r cpp_protobuf_async_streaming_qps_unconstrained_1cq_secure
2. Run "perf c2c record  -a -u --ldlat 50 -p $PID -F 2000 -- sleep 10" while the command above is running.
3. sudo perf c2c report -NN -g --call-graph --full-symbols -c pid,iaddr --stdio > perf_report.txt

Below is the output of "perf c2c report". There are HITMs (Hit modified cache line) at offset 0x0, 0x8, 0x10 and 0x18 of the same cacheline  . It means that there are some false sharings in "struct grpc_completion_queue". I guess we can see some performance improvement if adding some padding in that struct.
