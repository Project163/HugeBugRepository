Title

postgres crash when creating table whose PRIMARY KEY has a single column in the HASH specifier

Description
When executing the following SQL command in `ysqlsh`:

```
CREATE TABLE public.tbl4 (
    a integer NOT NULL,
    b integer NOT NULL,
    PRIMARY KEY((a) HASH, b)
);
```

The `postgres` process ends up crashing in this manner:

