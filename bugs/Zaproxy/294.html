Title

Path input vector not properly encoding values

Description
**Describe the bug**
Zap able to detect SQL injection from query params but not route params.

**To Reproduce**
I created a simple flask app that has an ```[URL] endpoint with SQL injections on purpose.
```
from flask import Flask, request
import psycopg2

@app.route('/api/user/ ')
