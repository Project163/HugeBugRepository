Title

http.bzl http_archive downloads multiple times if build_file is specified

Description
### Description of the problem:
If you override the native rule for http_archive by loading http.bzl, and provide a build_file argument to http_archive, bazel downloads the file 3 times. If build_file_content is provided as empty or neither build_file_content or build_file are provided, it downloads 1 time as expected.

I was trying to write my own repository rule based on http.bzl and found that my rule was downloading external dependencies multiple times.
