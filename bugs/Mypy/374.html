Title

Crash on reverse arithmetic method definitions with no arguments.

Description
Run mypy (0.550) on the following code:

```python
class A: ...

class B:
    def __rmul__(self) -> A: ...

```

This results in the traceback below.

This seems to occur with the other reverse arithmetic methods as well  (__radd__, __rtruediv__, etc), but  only if no arguments are specified in the method definition.
