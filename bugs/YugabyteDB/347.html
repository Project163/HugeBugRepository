Title

[colocation] handle TabletServerErrorPB::NOT_THE_LEADER

Description
`AsyncAddTableToTablet::HandleResponse` and `AsyncRemoveTableFromTablet::HandleResponse` do not handle the `TabletServerErrorPB::NOT_THE_LEADER` error code.  In the _add_ case, this causes the task state to be set to `MonitoredTaskState::kComplete` when it is not complete: the metadata change never went through.  This issue surfaces in about 2% of runs of `PgLibPqTest.TableColocation` in CentOS, debug build.

Handle the `NOT_THE_LEADER` error code.
