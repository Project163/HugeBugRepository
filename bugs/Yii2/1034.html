Title

beginProfile is lost in data collecting with use events if overfull message data array in logs

Description
Logs are writing in a data array by 1000 (default) message, then uploaded from memory (method flush).

When I use profiling, beginProfile is goes in first thousand array messages and endProfile is goes in next array messages, but there aren't any error messages.

I catch messages and processing them, then I send them in a pinba service.
