Title

Describing a topic with the TopicCommand fails if unauthorised to use ListPartitionReassignments API

Description
Since  [URL] describing topics with the TopicCommand requires privileges to use ListPartitionReassignments or fails to describe the topics with the following error: 

 
 Error while executing topic command : Cluster authorization failed.   

 This is a quite hard restriction has most of the secure clusters do not authorize non admin members to access ListPartitionReassignments.
