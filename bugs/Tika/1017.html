Title

Handle empty cells in tables uniformly

Description
It looks like we output a <td/> for empty cells in xls, and tables in doc, docx and pptx.  However, we don't retain empty cells in xlsx or tables in ppt.  We should make this handling uniform.
Discussion
- I've done a little poking at this; looks like the xslx parser doesn't emit events for empty cells (by design), but they do have some sample code for how to handle the situation. I've attached a proposed patch based on the POI sample code that adapts  XSSFExcelExtractorDecorator  to handle sparse  cell  events.
