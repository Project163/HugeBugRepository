Title

sessions are not returned to the sessionPool in case of an interrupt

Description
While returning a session to the pool, the interrupt status on the thread seems to be set, which causes the pool return to fail. 
The session slot is useless at this point. A HS2 instance configured for a single session will stop running queries.
