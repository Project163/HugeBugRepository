Title

[R0924] for set-like objects

Description
Originally reported by: **BitBucket: [Link: habilain], GitHub: @habilain?**

---

Set-like object have **len** and **iter**, but not any of the random access methods (e.g. **getitem**). Hence:

class Test(set): pass

gives the error 

R:  1,0:test: Badly implemented Container, implements **len** but not **delitem**, **getitem**, **setitem**

Unless there's a good reason not to, it would be nice to detect the set protocol.
- David
