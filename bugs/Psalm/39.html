Title

Function/method calls after is_callable check not properly evaluated

Description
Right now Psalm gives up on checking function parameters match the given function after an `is_callable` check, so this issue isn't currently caught (false negative):

```
php
/**
 * @param callable $callback
 * @return void
 */
... [Log Snipped] ...

function takes_int(int $i) {}
```

Instead of turning off all function parameter checks, Psalm should just stop checking if a function exists (but still proceed normally for functions that do exist).
