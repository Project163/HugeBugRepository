Title

3.0 - Inconsistency when baking views

Description
When baking a view using `cake bake view modelname` the $keyFields variable in the ViewTask is being populated with the BelongsTo associations for the add//edit forms. That is then passed to the views as a variable.

However, the appropriate variables are not being set when a controller is being baked for the add//edit methods.

For instance if you have a users model and it's associated with a groups model. The options index of the group_id field is getting a variable of $groups but the $groups variable is not being set in the add//edit methods of the controller.

On the contrary, when you bake using `cake bake all` this behavior is not happening. The $keyFields variable in the _loadController method is not being set.
