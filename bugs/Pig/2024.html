Title

Null handling of FLATTEN with user defined schema (as clause)

Description
Follow up from   PIG-5201  ,  
  
 
A = load  'input'  as (a1:chararray);
B = FOREACH A GENERATE a1,  null  as a2:tuple(A1:chararray, A2:chararray), a1 as a3;
C = FOREACH B GENERATE a1, FLATTEN(a2), a3;
dump C; 
  
 This produces right number of nulls. 
  
 
(a,,,a)
(b,,,b)
(c,,,c)
(d,,,d)
(f,,,f)  
  
   

 However,  
  
 
A = load  'input.txt'  as (a1:chararray);
B = FOREACH A GENERATE a1,  null  as a2:tuple(), a1 as a3;
C = FOREACH B GENERATE a1, FLATTEN(a2) as (A1:chararray, A2:chararray), a3;
dump C; 
  
 This produces wrong number of null and the output is shifted incorrectly.  
  
 
(a,,a,)
(b,,b,)
(c,,c,)
(d,,d,)
(f,,f,)  
  
 Difference here is, for the latter, a2 in "FLATTEN(a2)" only has schema of tuple() with empty inner fields but with user defined schema of "as (A1:chararray, A2:chararray)".
Discussion
- Instead of relying on innerfield schema, using the output schema which combines schema of data and user-defined schema.
