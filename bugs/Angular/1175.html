Title

routerLink with absolute path and round brackets parsed incorrectly

Description
# 🐞 bug report

### Affected Package
The issue is caused by package @angular/router: ~8.3.23

### Is this a regression?

Don't know

### Description

When using the secondary routes feature, I cannot create an absolute routerLink with it. Parenthesis are encoded.

## 🔬 Minimal Reproduction

Example :

` try me `

Gives the link `"/page%28some:thing%29"` instead of `"/page(some:thing)"`

Same bug if I use `[routerLink]="myLink"` with `this.myLink = '/page(some:thing)'`

I know that Angular try to encode URL following the standards, but parenthesis are special chars needed for secondary routes. They shouldn't be encoded.

I see a lot of issues reported with parenthesis, and I want to re-open #32718
