Title

Unexpected error log though master change config succeeded.

Description
Noticed this output in one of the recent ops:
`$ ~/master/bin/yb-admin -master_addresses   change_master_config REMOVE_SERVER   7100 1
I0108 22:30:54.751463 17854 mem_tracker.cc:240] MemTracker: hard memory limit is 25.722462 GB
I0108 22:30:54.751554 17854 mem_tracker.cc:242] MemTracker: soft memory limit is 21.864092 GB
_E0108 22:30:56.275851 17854 client-internal.cc:1166]
Error: Invalid argument (yb/client/client-internal.cc:1167): Unable to change master config: master addresses cannot be empty_`

The master UI shows master quorum updated correctly to remove the `old_ip`. 

The log seems to be due to some kind of first try printing an error instead of a debug/warning, need to change that to not show up by default.
