Title

Powerline font cut off on 0.13

Description
After updating to 0.13, powerline icons have started rendering incorrectly. On 0.12 it used to render as expected, but now it's cutting off the "points" of the powerline triangles. Here's a screenshot of what it looks like:

[Image: new]

And here's what it used to look like before (downgraded to 0.12 for the screenshot):

[Image: old]

I use the IosevkaTerm font with NerdFont patches (https://www.nerdfonts.com/font-downloads)

Here's my config, after migrating to toml:

```
toml
import = ["/home/pavle/.config/alacritty/gruvbox.toml"]

[font]
size = 8
... [Log Snipped] ...
general = "Alacritty"
instance = "Alacritty"
```

gruvbox.toml just defines some colors and I get the same behaviour with and without that file included.

### System

OS: Linux
Version: alacritty 0.13.0 (78fa4d6f)
Linux: X11, i3, no compositor
