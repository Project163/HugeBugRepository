Title

Description
From the mailing list: 

 When I try to print the pdf available 
here< [URL] there 
are 2 boxes on the second page with text "CV 138" and "D946". both text are 
in black boxes. When this is printed out on windows machine the text in the

Discussion
- I've added a new constructor to PDFPrinter in revision 1586802, which accepts a  dpi  parameter. If set, it will cause the printed output to be rasterized to a bitmap before being sent to the printer driver. This provides an alternative from using Java 2D's Graphics to perform printing via PostScript (or other vector-based platform driver).
- Just for the record, he said that it happened on a Zebra LP2844 (which is a label printer) and on a Citizen.
