Title

SQL: translate API doesn't generate the correct query

Description
The SQL query itself returns results and doesn't throw any exceptions, but the ES query `translate` API is generating for the same SQL query doesn't work.

Example: `select avg("salary"), day("hire_date") from "test_emp" group by day("hire_date") having avg("salary") >50000` works from CLI and returns results:

```
sql> select avg("salary"), day("hire_date") from "test_emp" group by day("hire_date") having avg("salary") >50000;
   AVG(salary)    |DAY_OF_MONTH(hire_date [UTC])
------------------+-----------------------------
56518.5           |3
51396.0           |7
... [Log Snipped] ...
61805.0           |28
62958.333333333336|30
```

But the `translate` API returns the following:

```
{
    "size": 0,
    "_source": false,
    "stored_fields": "_none_",
    "aggregations": {
... [Log Snipped] ...
    }
}
```
