Title

The `zap-x.sh` script should exit with the exit code of `zap.sh`

Description
### Describe the bug

When using `zap-x.sh` in pipelines, it is important to know if there was an error with ZAP itself.

The current script will output the exit code from the `rm -f` command regardless of the status of ZAP.

### Steps to reproduce the behavior

1. Do something that messes up the core ZAP run
2. Check `$?` and see that it is `0`

### Expected behavior

The exit code is that returned by `zap.sh`
