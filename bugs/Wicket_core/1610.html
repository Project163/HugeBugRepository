Title

Removing Metadata from Application not possible

Description
Moving to ConcurrentHashMap as storage for the MetaData made deleting Metadata by passing null-Value when calling Appliction#setMetadata impossible. ConcurrentHashmap does not like null-Values and reacts with Exception. 

 Solution: use ConcurrentHashMap#remove for null-Value.
