Title

StreamParser on HtmlParser may emit the final elements twice, if explicitly closed

Description
Possible bug when using stream()  with StreamParser and Jsoup.parse().  Details can be found at
[URL]

It would be helpful to understand why attributes and elements of a valid Html document gets duplicated on using stream()
Discussion
- Hi there,

The primary issue in that report is that the user effectively has two iterators, the `forEach` and the `element.toString()`, which will output the element plus all it's children, leading to seeming duplicates. As the answer from Jarez notes.

But there an issue seen in this example:

```
java
String html = "   Stream    Link   ";

StreamParser streamParser = new StreamParser(Parser.htmlParser());
StreamParser parse = streamParser.parse(html, "");
... [Log Snipped] ...
    "El:  ; attributes: %s; ownText: %s", el.tagName(), el.attributes(), el.ownText()));
});
```

We get:

```
text
El:  ; attributes: ; ownText: Stream
El:  ; attributes: ; ownText: 
El:  ; attributes:  href="foo"; ownText: Link
El:  ; attributes: ; ownText: 
... [Log Snipped] ...
El:  ; attributes: ; ownText: 
El:  ; attributes: ; ownText:
```

The `a` and the `body` are emitted twice. I guess that we are calling `onNodeRemoved` twice, once when it is actually closed, and once when the document is complete and we pop all the nodes off the final stack. It doesn't happen with the XML parser, only the HTML parser. (The latter keeps the `body` and `html` on the stack even when closed so any content following that can still be added to the body. Will look to suppress emitting those pops).

XML parser version:

```text
El:  ; attributes: ; ownText: Stream
El:  ; attributes: ; ownText: 
El:  ; attributes:  href="foo"; ownText: Link
El:  ; attributes: ; ownText: 
El:  ; attributes: ; ownText: 
El:  ; attributes: ; ownText: 
```

(If the HTML doesn't have the explicit close tags and just implicitly closes, we only see the emits once, correctly.)
- Thanks, fixed!

The sample code above now correctly produces:

```text
El:  ; attributes: ; ownText: Stream
El:  ; attributes: ; ownText: 
El:  ; attributes:  href="foo"; ownText: Link
El:  ; attributes: ; ownText: 
El:  ; attributes: ; ownText: 
El:  ; attributes: ; ownText: 
```
