Title

Tests are not rendered in folders in the desktop-gui on windows

Description
- Operating System: Windows 10
- Cypress Version: 2.0.1
- Browser Version: Chrome 63

### Is this a Feature or Bug?
Bug

### Current behavior:
Tests are incorrectly rendered in groups/folders on windows.
[Image: image]

### Desired behavior:
Tests should be organized by groups

### How to reproduce:
Load a folder with tests organized in sub-folders on a Windows PC.
Discussion
- Fix can be done in specs-store.js in the desktop-gui package:
Line 42:
```js
      const filesByDirectory = _.map(specs, (spec) => {
        // change \\ from Windows to /
        let name = spec.name.replace(/\\/g, '/');
        return name.split('/');
      })
```
- Released in [Link: `2.0.3`].
