Title

[YSQL] Lookup by oid in system catalog tables does not make use of the primary key

Description
Currently, `ybcScan.c` omits the oid column in sys catalog tables when loading the primary key information, thereby causing lookup by oid to be a full-table scan. This causes slowdown in initdb as well as initial table describe in a psql session.
