Title

Bazel mis-interprets errors while executing tests remotely

Description
### Description of the problem / feature request / question:

When test execution fails for unexpected reasons, the error is re-thrown as a SpawnExecException: [URL]

The test strategy catches this and translates it into a test failure:

[URL]

The net effect of this is that all execution failures during the running of tests are reported to the user as test failures instead of as the underlying issue, which in turn masks the underlying issues.
