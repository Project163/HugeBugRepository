Title

Ignite artifacts need to contain "-incubating" tag

Description
Currently, the top-level pom says 
  
     <groupId>org.apache.ignite</groupId>
    <artifactId>ignite</artifactId>
    <version>1.1.0</version>
 
  
 The  -incubating  tag is missed. Let's add it into the version string to avoid renaming all the artifacts in the project. Eg  <version>1.1.0-incubating</version>
Discussion
- Ignite version analizer have some restrictions.  
It's ok to have versions:  
X.X.X-incubating 
X.X.X-incubating-SNAPSHOT 
but not ok to have  
X.X.X-incubating-RC1 
X.X.X-incubating-RC1-SNAPSHOT 

 Is it possible to start vote with version X.X.X-incubatingRC1 or X.X.X-RC1? 
Release version will be X.X.X-incubating.
- In case of RC+ you don't do SNAPSHOTs anymore: these are effectively release versions.
