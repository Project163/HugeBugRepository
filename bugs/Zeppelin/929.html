Title

Can't hide Spark Jobs (Spark UI) button

Description
Hi, 

 In Zeppelin 0.8.0 I can't manage to hide "Spark Jobs" / Spark UI in our Notes after upgrading from 0.7.3. 

 I did a bit of digging and I could see if "spark.ui.enabled" is set to false the button shouldn't be visible. But this seems to be ignored and it's still visible. 

   

 NOTE: Just to be clear, I don't want to disable Spark UI. I need to be able to see the jobs from Spark UI. Since we don't offer this feature to our data scientists at our lab, I want to hide this button entirely. 

   

 Thank you. 

 Maziyar
