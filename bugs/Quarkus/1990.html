Title

gRPC reflection service is gone when dev server hot reloads

Description
### Describe the bug

The gRPC reflection service seems to be removed when the dev server is hot reloading. Stopping `gradle quarkusDev` and re-running would get the reflection service back.

### Expected behavior

_No response_

### Actual behavior

_No response_

### How to Reproduce?

0. Go to [URL] tick `grpc`, download the generated code.
1. `unzip` && `cd` && `gradle quarkusDev`
2. From another terminal:
```
$ ./grpcurl -plaintext localhost:9000 list
grpc.health.v1.Health
hello.HelloGrpc
```
4. `echo >> src/main/java/org/acme/HelloGrpcService.java` to trigger a dev server hot reload.
5. Now:
```
./grpcurl -plaintext localhost:9000 list
Failed to list services: server does not support the reflection API
```
