Title

HttpClient.delete() cannot handle a body in its request

Description
## I'm submitting a...
  
[ ] Regression (a behavior that used to work and stopped working in a new release)

## Current behavior
The [Link: `HttpClient.delete()`] does not accept a body parameter. 

## Expected behavior
The [Link: `HttpClient.delete()`] needs to accept a body or clear guidance on why it has this limitation and how to get around it. It was possible with the original [Link: `Http.delete()`] via the [Link: `RequestOptionsArgs`]

## What is the motivation / use case for changing the behavior?
I work with APIs that have always handled the body of DELETE requests and this is an unexpected change in REST api interaction.
