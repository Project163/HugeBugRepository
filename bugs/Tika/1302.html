Title

Word Document extracted mpga file extension instead of bitmap

Description
When tried to parser the .doc document it is extracted two mpga files which can't be open to play. We are suspecting they should be bitmap image files. The Tika version we are using is 2.4.1. 

   example.DOC
Discussion
- Its  is reading it as FilesYO.RF and while extracting the content itself the embedded file contains two file with .mpga extension.
- The RTFParser runs file type detection on embedded files. That process is identifying these as mpga.  I agree that the files are bitmap, and the RTF file encodes that with:  \bitmap . 

 So, should we turn off file type detection if the RTF alleges that the embedded file is a pict/bitmap?  Or do we need to improve our mpga handling?
