Title

Parsing tags in a custom tag library with a colon

Description
A problem with parsing tags such as  .  Currently, JSoup parses this and splits the tag into-  <abc :door=""></abc> which is invalid and makes the code useless.
Discussion
- I managed to alter the parser to continue reading characters when matching a colon by changing the below method

 public boolean matchesWord() {
        Character peekChar = peek();
        return !isEmpty() && (Character.isLetterOrDigit(peekChar) || peekChar.equals(':'));
    }
 

However, we have a problem since when leaving a tag like    , JSoup splits the tag into 2 seperate tags       (note the extra space/ new line between the tags).  This is breaking all the logic. - Hi,

This is fixed now. Jsoup will handle namespaced tags correctly, and includes support for selectors (i.e. doc.select("fb|name").)

I modified the parser and tag definitions so that when an unknown tag is found that is self closing, it is marked as optionally self closing for output (so that self closed tags will be output as is, but not forced to be empty).

I also modified the html output for empty elements so that there is no newline and indent added to them.
