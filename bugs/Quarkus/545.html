Title

Gradle quarkus-kubernetes error

Description
**Describe the bug**

I have the following dependencies in my build.gradle file and have a local minikube setup.

```groovy
dependencies {
    implementation 'io.quarkus:quarkus-kubernetes'
    implementation 'io.quarkus:quarkus-container-image-jib'
    // ..
}
```

I am re-using the Docker registry inside Minikube via **eval $(minikube docker-env)**.

The build is failing with a UnsupportedOperationException

The code is built and docker image is created and deployed to kubernetes successfully.
