Title

Discard hints based on write time, not timeout time

Description
Hints are created after a write timeout are created with the timeout time as the hint creation time. In the case of slow hint delivery, this can create a window of time where a write is applied after gcgs would have elapsed for tombstones written after the original write, and the tombstone has been purged, causing data resurrection. We should use the time the client request thread started working on the request as the hint creation time.
