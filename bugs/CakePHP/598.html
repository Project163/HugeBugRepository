Title

Raising exceptions from RequestHandlerComponent::addInputType handler results in infinite loop.

Description
If you override 'xml' with a custom input handler and raise an exception, the RequestHandler and ErrorHandler get into a never ending cycle.  The documentation does not mention that raising exceptions is forbidden.
### AppController

```
php
class AppController extends Controller {
    public $components = array(
        'RequestHandler'
    );
... [Log Snipped] ...
    }
}
```
### Request

POST /examples/fail.xml HTTP/1.1
Host:  
Content-Type: text/xml
Cache-Control: no-cache
Postman-Token: cbabd12a-1fb3-e225-fbdb-6a08ab410831

xml that parses but is missing required fields
### Workaround

For now, I just wrapped the code in `beforeFilter` with `if(!($this instanceof CakeErrorController)) {...}`.
