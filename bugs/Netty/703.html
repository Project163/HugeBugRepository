Title

AsciiString contentEqualsIgnoreCase fails when arrayOffset is non-zero

Description
### Expected behavior
AsciiString.contentEqualsIgnoreCase is expected to work.

### Actual behavior
AsciiString.contentEqualsIgnoreCase may return true for non-matching strings of equal length

### Steps to reproduce
Create AsciiString with non-zero offset.

### Minimal yet complete reproducer code (or URL to code)

Example of failure
`   @Test
    public void testContentEqualsIgnoreCase() {
        byte[] bytes = { 32, 'a' };
        AsciiString asciiString = new AsciiString(bytes, 1, 1, false);
        assertFalse(asciiString.contentEqualsIgnoreCase("b"));
        assertFalse(asciiString.contentEqualsIgnoreCase(AsciiString.of("b")));
    }
`
