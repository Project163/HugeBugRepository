Title

Available Material Icons are not updated with new Streamlit releases

Description
### Checklist

- [Link: X] I have searched the [existing issues] for similar issues.
- [X] I added a very descriptive title to this issue.
- [X] I have provided sufficient information below to help reproduce this issue.

### Summary

From this discussion: [URL]

************

There are icons that exist in the Material Symbols docs (for example, [Link: `table_convert`]) but are not recognized by Streamlit:

`StreamlitAPIException: The value “:material/table_convert:” is not a valid Material icon.`

******

The icon name needs to be in [Link: this set in `material_icon_names.py`] to be recognized by Streamlit. That set  is generated by [Link: `scripts/update_material_icon_names.py`],  which reads the material icon names and codepoints from [Link: this other file in the material-fonts] repository.

But the last time `material_icon_names.py` was updated in Streamlit's repo was five months ago, so the available codepoints used to generate that set was [Link: likely this version] which did not include, for example, `table_convert` or `table_edit`.

### Reproducible Code Example

```Python
import streamlit as st

# OK
st.button(label="Table Chart View", icon=":material/table_chart_view:")

# Raises Exception
st.button(label="Table Convert", icon=":material/table_convert:")
```
