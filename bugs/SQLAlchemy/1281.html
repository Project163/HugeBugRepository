Title

lazy relationship with polymorphic is use wrong condition

Description
### Describe the bug

Following commit broke the query condition over lazy relationship with polymorphic.
[URL]

I think maybe use wrong cached query.

### FYI
- working correctly in 1.4.32
- working correctly without [URL]
- working correctly without previous query
- working correctly without polymorphic
