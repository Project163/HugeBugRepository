Title

# type: ignore doesn't fully work

Description
In a code like this:

``` python
logger.info("xxx: %s", pprint.pformat(retval, compact=True))
```

I get this type check error.

```
$ mypy -s -p somepackage
somepackage/somemodule.py: note: In function "foobar":
somepackage/somemodule:438: error: Unexpected keyword argument "compact" for "pformat"
env/lib/mypy/typeshed/stdlib/3/pprint.pyi:7: note: "pformat" defined here
$
```

Yes, I know, a bug in typeshed.

However, even if I want to suppress it, I can't:

``` python
logger.info("xxx: %s", pprint.pformat(retval, compact=True))  # type: ignore
```

then:

```
$ mypy -s -p somepackage
somepackage/somemodule.py: note: In function "foobar":
env/lib/mypy/typeshed/stdlib/3/pprint.pyi:7: note: "pformat" defined here
$
```

So, I still get printed errors and still it returns exit code 1 denoting an error.   I should be able to ignore this "error", but mypy (0.4.4) doesn't let me.
