Title

[BLOCKER] Effect of '# type: ignore' became much more severe after '--warn-unused-ignores'

Description
It seems the introduction of `--warn-unused-ignores` in 4889c0c caused even valid imports to acquire the type `Any`.
Discussion
- It seems like there's some disagreement over the expected behavior of the first test case (testIgnoreImportBadModule) introduced by [URL] -- if a module is marked as `# type: ignore`, it should only ignore errors if that module does not exist, and not if there's any error of any kind from within that module.
