Title

DefaultGroovyMethods#unique now returns null for empty or 1 element input

Description
[URL] changed the behavior of  DefaultGroovyMethods#unique  to return  null  for an empty or one element collection input when  mutate  is  false . This requires a really awkward workaround and breaks compatibility with previous versions, and I personally don't think the behavior makes sense.
