Title

Spark shell prints error when :4040 port already in use

Description
When running two shells on the same machine, I get the below error.  The issue is that the first shell takes port 4040, then the next tries tries 4040 and fails so falls back to 4041, then a third would try 4040 and 4041 before landing on 4042, etc. 

 We should catch the error and instead log as "Unable to use port 4041; already in use.  Attempting port 4042..."
