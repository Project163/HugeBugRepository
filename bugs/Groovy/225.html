Title

protected fields not visible in subclasses

Description
class SuperClass 
{protected String x = 'x'}
 class SubClass{void out(){print x}} 
new SubClass().out() 

 throws a ScopeCheckingException
Discussion
- This issue has been fixed, but is not closed yet, since currently this works only when the subclass and superclass exist in the same groovy file.

- accessing protected attributes of a superclass is one thing, making them practically public another thing. Example: 

  c = new EmptyRange(null) 
 asset c.EMPTY_LIST==[] 

 this  should fail because of an illegal property access. The field EMPTY_LIST is protected in EmptyRange and as the script above is neither a subclass of EmptyRange nor is it in the same package, the attribute should not be accessible.
