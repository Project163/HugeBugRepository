Title

Theory treats null and string.Empty inline data parameters as identical

Description
Running this test results an error: 

```
[Theory]
[InlineData(null)]
[InlineData("")]
public void Test(string input)
{
}
```
Discussion
- Looks like the issue is in `XunitSerializationInfo.Deserialize`:

```
public static object Deserialize(Type type, string serializedValue)
{
    if (serializedValue == "")
        return null;
```

For empty string, it doesn't check the type and returns null even if the type is string that should be deserialized into empty string.
- Seems that this is still broken?
- Please open a new issue with a repro.
