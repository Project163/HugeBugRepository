Title

View not being updated when model changes in animation done callback

Description
**I'm submitting a** 

```
[x] bug report
```

**Current behavior** 

I created a simple animation trigger for changing the text color of a header. Then, I create a variable in the component and then bind it to the template. When I change the value of that variable inside the animation `done` callback, the view is not immediately updated. 

Demo: [URL]

I think this is somehow related to [URL]

**Expected behavior**

The component's template should update any bound data whenever this data is changed inside the animation `done` callback.

**Reproduction of the problem**
See demo: [URL]

**What is the motivation / use case for changing the behavior?**
I need to update some variables once a particular animation has been done and get them reflected in the view immediately.

Discussion
- I know this will be solved in v2.0.1 but I wanted to share a workaround I found to get this working. 

So, when changing variables inside the `done` callback, you'll have to _apply_ this changes to the template by manually _detecting changes_ using the `ChangeDetectorRef`.

```
typescript
import { ChangeDetectorRef } from '@angular/core';
...
export class AppComponent{
changeDetectorRef: ChangeDetectorRef
... [Log Snipped] ...
  }
}
```
