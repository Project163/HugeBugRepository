Discussion
- here's a simpler example

```
In [79]: df = DataFrame({'A' : date_range('20130101',periods=3,tz='US/Eastern'), 'B' : [0, np.nan, 2]})

In [80]: df
Out[80]: 
                          A   B

```

```
Out[86]:

```
