Title

LruList in ServiceWorker not correctly removing url

Description

## Current behavior
 
The LRUList's remove function sometimes throws an error because the node's 'previous' url is not defined in the linked list. Upon further examination, this occurs when a node that has been previously 'removed' is removed again. Since the node is still defined in 'state.map', the code is executed and we see this error.

## Expected behavior
 
There should never be an invalid node in the LRUList's state.map.


## Minimal reproduction of the problem with instructions
 
- Create an LruList
- Populate the list with some urls
- remove a url and observe that the return value is true
- remove the same url again and observe that the return value is still true (it should be false)

## Environment

  
Angular version: 5.2.6
