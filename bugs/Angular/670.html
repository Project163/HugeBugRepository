Title

Literals in css with escapes are not emitted correctly

Description
## I'm submitting a...
 
  
[x] Regression (a behavior that used to work and stopped working in a new release)
  

REF: [Link: b/74538140]

## Current behavior

A style that contains an a value with a string escape such as `'\0025BC'` is emitted as `"\\x0025BC"` instead of the expected "\0025BC".

This is true when using 2.6 or 2.7 of TypeScript but does not reproduce with 2.5.

This is related to [URL] TypeScript, beginning with 2.6, calls `escapeString` for the value of synthetic literals.

[URL]

This produces the incorrect escaping identically had this been an interpolation.

## Expected behavior

The escaped string in css should be emitted correctly.

## Minimal reproduction of the problem with instructions

1. `ng new repro`
2. modify app.component.css to be

```css
span {
  content: '\0025BC';
}
```

`./node_modules/.bin/ngc -p src/tsconfig.app.json`

Inspect `out-tsc/app/src/app/app.component.css.shim.ngstyle.js`

**EXPECTED**


```
["span[_ngcontent-%COMP%] {\n  content: '\\0025BC';\n}"]
```

**RECEIVED**

```
["span[_ngcontent-%COMP%] {\n  content: '\\x00025BC';\n}"]
```
