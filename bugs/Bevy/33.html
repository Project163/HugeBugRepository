Title

Weird limits on tuple parameters

Description
After the new ECSv2 overhaul, the limit for the number of system and query parameters was reduced from the old limit of 16. See here: [URL]

Supposedly, the new limit should be 12 (explained by limitations with the trait impls in the Rust standard library).

However, now I am actually investigating it, and it seems like the actual limit for system parameters in current bevy main is 11, not 12. The actual limit for query parameters is 14.

These numbers seem weird? Is this a bug/oversight? If yes, it should probably be fixed before releasing 0.5.
Discussion
- @cart sanity check on whether this should block 0.5? Also to make sure migration guide advice is correct.
- @cart Will this be addressed before 0.5? It seems like a weird minor oversight?
- Yeah if SystemParams aren't lined up with the Default impls for rust tuples, they should be. WorldQuery impls shouldn't have the same limitations, so we can pick whatever makes sense there.
