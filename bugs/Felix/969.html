Title

The Memory Usage plugin does not support multipart/form-data POST requests

Description
The Memory Usage plugin currently only supports url-encoded parameters to POST requests. It would be useful to also support multipart/form-data encoded parameters. This is made easy by the WebConsoleUtil.getParameter method.
