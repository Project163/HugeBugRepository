Title

Add another HistoryLogLevel to suppress TaskAttempts at specific levels

Description
In LLAP, there are too many TaskAttempts which are preempted by llap. This results in too many log events, add a log level to support configure and suppress these events.

 TASK_ATTEMPT_NON_PREEMPTED: Will suppress externally preempted task events and the container events.
