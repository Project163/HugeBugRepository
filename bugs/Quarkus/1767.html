Title

UniAsserter - assertFailedWith() does not always assert the failure from the supplied Uni

Description
### Describe the bug

I'm not quite sure whether it's a bug or just a confusing behavior. 

If any of the previous `UniAsserter` asserts fails then the `assertFailedWith()` receives the exception that caused the failure, i.e. `AssertionError` and not the the failure from the supplied `Uni` (which is obviously ignored). I think that it would make more sense to ignore the `assertFailedWith()` completely if any of the previous stages fails.
