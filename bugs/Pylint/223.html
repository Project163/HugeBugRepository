Title

singleton-comparison doesn't cover `expr != [None|True|False]`

Description
### Steps to reproduce
```py
def something():
    a = 1
    if a == None:
        print 'is None'
    if a != None:
        print 'is not None'
```

### Current behavior
```
C:  3, 7: Comparison to None should be 'expr is None' (singleton-comparison)
```

### Expected behavior
```
C:  3, 7: Comparison to None should be 'expr is None' (singleton-comparison)
C:  5, 7: Comparison to None should be 'expr is not None' (singleton-comparison)
```
