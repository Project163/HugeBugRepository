Title

`env` override is not applied to build env variables

Description
### What happened?

I am attempting to cross-compile a CGO library, and thus have to set the toolchain for selected targets (through `CC` env variable).

When setting env variables in a build override - despite the arch/os matching - the overridden value is not set when actually performing the build.

I can see the build matching the override rule:
```
• overridden build details for linuxarm64        details={[-s -w] [] [-buildmode=c-shared] [] [] [CC=zig cc -target aarch64-linux]}
```

However, when running 

```
$ goreleaser build --debug
```

In the list of environment variables I do not see the overridden value:

```
[...] CGO_ENABLED=1 CC=zig cc GOOS=linux GOARCH=arm64 GOARM= GOMIPS= GOMIPS64= GOAMD64=
```

`CC` in particular is supposed to appear twice, with the default value, plus the overridden one as `CC=zig cc -target aarch64-linux`.
