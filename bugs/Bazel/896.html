Title

Compilation modes dbg and opt have no effect with compiler mingw-gcc on Windows

Description
### Description of the problem:

The compilation modes dbg and opt don't add any compiler flag (like -g or -g0 -O2 -DNDEBUG) when using compiler mingw-gcc on Windows.

### Bugs: what's the simplest, easiest way to reproduce this bug? Please provide a minimal example if possible.

git clone [URL]
cd examples\cpp-tutorial\stage1
bazel build --compiler=mingw-gcc -s --noshow_progress //main:hello-world
bazel build --compiler=mingw-gcc -c dbg -s --noshow_progress //main:hello-world
bazel build --compiler=mingw-gcc -c opt -s --noshow_progress //main:hello-world
The subcommands are identical except the output paths.

### What operating system are you running Bazel on?

Windows

### What's the output of `bazel info release`?

1.1.0
