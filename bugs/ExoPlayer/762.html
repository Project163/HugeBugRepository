Title

Aspect ratio not properly set at playback start after latest changes to dev-v2

Description
I was using dev-v2 branch and found this

During the buffer stage the player doesn't have the proper aspect ratio, is just a square but the content and view are 16 by 9.

After `Player.STATE_READY` the size is OK.

I initiate the view layout like this.

```
             
```
Then dinamicly change the view layout to be smaller always keeping the 16 by 9 aspect ratio, that is why I can see it changing from a square to a rectangle, as the view is smaller then the device screen and is above a lighter background.

I notice this issue after this change [URL] reverting it will solve.

I made this for testing
[URL]

the result is this

```
updateAspectRatio: setPlayer
updateAspectRatio: width 0 height 0
updateAspectRatio: onVideoSizeChanged
```
