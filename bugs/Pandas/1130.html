Title

BUG: fillna returns frame when inplace=True if fill values are specified as a dict

Description
`fillna` will return the frame in question if passed fill values via a dict, even if `inplace=True`.

```
In [6]: data = pd.DataFrame({'a': [1, None], 'b': [2, None]})

In [7]: data.fillna({'a': 0}, inplace=True)
Out[7]: 
     a    b
... [Log Snipped] ...
0  1.0  2.0
1  0.0  NaN
```
Discussion
- I noticed this because it comes up in [Link: PR#15653], where it causes the following test...

```
python
        def _check_f(base, f):
            result = f(base)
            self.assertTrue(result is None)

... [Log Snipped] ...
        f = lambda x: x.fillna(0, inplace=True)
        _check_f(data.copy(), f)
```

...to fail.

Will fix there. *Should* be a one-liner.
- yep this looks like a bug.
- I'm working on this issue
