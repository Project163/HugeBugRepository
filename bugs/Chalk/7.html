Title

`reset` order inconsistency

Description
This outputs in yellow:

``` js
console.log(chalk.yellow.reset('unicorn'));
```

This without a style:

``` js
console.log(chalk.reset.yellow('unicorn'));
```

Our docs say the styles aren't order dependent, but with reset they clearly are.

@jbnicolai thoughts on how this should be handled?
Discussion
- Perhaps update the docs to say `non-conflicting styles aren't order dependent, otherwise the first is used`?

The same goes for, e.g:

``` javascript
console.log(chalk.blue.red('sharkbear'));
// blue
console.log(chalk.red.blue('sharkbear'));
// red
```
- Ah, ok, so the issue is actually that the styles are applied in the opposite order of what I would have expected.

``` js
console.log(chalk.red.blue('sharkbear'));
```

I would have expected this to be blue, as `blue` is last and should have overridden `red`.

I guess we could just reverse the styles array?
