Title

ijar fails to extract Bazel installation due to its size.

Description
At current head ( ), I get the following error message after I build Bazel and try to use it:

```
Extracting Bazel installation...
Failed to extract Bazel as a zip file: ijar does not support decompressing files larger than 128MB.
```

A possible fix is the increase of the constant `MAX_BUFFER_SIZE` in `third_party/ijar/zip.cc`.
Discussion
- Can confirm that increasing the constant to 256MB fixes the problem. Probably an increase to a smaller value would also fix it.
- But the bazel binary shouldn't be that big... Anyway increasing the constant to 256MB is a good enough solution.
- That's probably because we're bundling a lot of the tools...
