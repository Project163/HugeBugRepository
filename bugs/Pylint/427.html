Discussion
- The issue is caused by #5158.
In particular if a variable is not defined in the current astroid scope. For the example above the scope is `ListComp` whereas the `AnnAssign` is in the `FunctionDef` scope.

A similar error can be created by using `global`.
```py
var: int

def func():
    global var
    print(var)
```
