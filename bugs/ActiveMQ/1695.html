Title

setup writes incorrect jmx port

Description
See  [URL] for the question and request for JIRA issue. 

 Change the line: 
ACTIVEMQ_SUNJMX_START="-Dcom.sun.management.jmxremote.port=11099 " 
to 
ACTIVEMQ_SUNJMX_START="-Dcom.sun.management.jmxremote.port=1099 " 
Then remove the "--jmxurl 
service:jmx:rmi:///jndi/rmi:// :11099/jmxrmi " from the ACTIVEMQ_SUNJMX_CONTROL to make restarts and queries work without erroring.
