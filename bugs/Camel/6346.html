Title

camel-kafka: producer idempotence is not enabled by default

Description
Kafka enables idempotence on the producer by default but camel-kafka does not (see the first bullet point  here ). As far as I can tell, aligning the following props would fix this:

Discussion
- [URL]
Idempotence for the producer is enabled by default if no conflicting configurations are set. In 3.0.0 and 3.1.0, a bug prevented this default from being applied, which meant that idempotence remained disabled unless the user had explicitly set enable.idempotence to true (See   KAFKA-13598  for more details). This issue was fixed and the default is properly applied in 3.0.1, 3.1.1, and 3.2.0.
