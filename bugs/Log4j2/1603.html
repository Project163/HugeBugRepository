- Hi  simonikula , 

 What version of Xerces is your WebSphere using? Recent versions of Xerces fail fast if a feature is not available. 

 The problem you encounter can not easily be fixed, since it is not possible to guess in code, what feature caused the problem.
- I agree that identifying specific error case is difficult. 
How about refactoring error handling so that any exception would trigger attempt without include. Other scenarios could also be added and handled.
