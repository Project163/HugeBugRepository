Title

Add support for BEGIN TRANSACTION to allow mutations that touch multiple partitions

Description
UPDATE and DELETE are both able to update multiple partitions, but these queries would fail when using in BEGIN TRANSACTION as it assumed single partition only.  To better support all CQL operations, need to support multiple partitions within a single mutation.
