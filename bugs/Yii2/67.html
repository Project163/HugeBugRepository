Title

the route with no action but with a closing slash

Description
No additional url management was made.

When I call the page like this:

```
site.com/?r=learn/
```

it could not understand that the action is default. It says that the page is not found. Did you intend this behavior?
Because in the yii1 it works in a - I think it is needed to take into consideration a URL Canonicalization. For seo the URL with trailing slash and URL without trailing slash are different URLs. It is said by Matt Cutts - employee of Google SEO team. You can read what he says about trailing slashes [Link: here]. Also take in consideration traling slashes for Pretty URLs (Permanent URLs). I think Yii must open URLs with trailing and without trailing slash but Canonical URL must be without trailing slash.
- @egorpromo, I have just checked that Controller::getCanonicalUrl() for the route like  'learn/'  or  'learn'  will return  'learn/index'
- @mgrechanik I have checked it now and I see it is ok for seo :)
