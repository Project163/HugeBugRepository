Title

[YSQL] Postgres crash on concurrent INSERT and SELECT

Description

Curiously enough, I wasn't able to reproduce this manually, and changing query `SELECT * FROM test_rr LIMIT 10` by dropping `LIMIT` or adding `ORDER BY` prevents catching this problem.
