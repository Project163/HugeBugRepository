Title

Raise minimum runtime requirement to Jackrabbit 2.20.4 and Jackrabbit API 1.22.14

Description
[URL] states that 
  The OSGi bundles require Oak 1.8+ or Jackrabbit 2.16+  

 This is unfortunately not true as the runtime dependency check is broken and 3.6.9 in fact requires much newer version. As the documented minimum dependencies are pretty outdated I propose to raise the minimum runtime dependencies for the OSGi bundles to 

 
	 Jackrabbit API 1.22.14 and 
	 Jackrabbit Commons, SPI, SPI Commons, WebDAV to 2.20.4 
 

 and restore enforcement of those. These versions are compatible with AEM 6.5.16 and Sling Starter 12 ( [URL]
Discussion
- Just one related note, Oak 1.26.0 is required for Java 14 and newer:  [URL] so testing with the minimum version is not possible on Java 17 and 21.
