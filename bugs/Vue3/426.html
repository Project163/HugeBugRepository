Discussion
- The compiler produces this code:
```js
(_ctx.$emit('myclick', new _unref(TestClass)())
```

which is invalid. This should be fixable with an additional set of paranthesis if we need to unwrap directly after `new`:

```js
(_ctx.$emit('myclick', new (_unref(TestClass))())
```
