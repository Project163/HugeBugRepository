Title

specifying `dest` triggers error in `output.format` even if it is specified

Description
version rollup@0.56.2.  Trying to migrate from the old to the new options style by adding both set of options:

```
js
import resolve from 'rollup-plugin-node-resolve';
import commonjs from 'rollup-plugin-commonjs';
export default {
	input: 'main.js',
... [Log Snipped] ...
	format: 'cjs'
};
```

This triggers the error:

```
[!] Error: You must specify options.format, which can be one of 'amd', 'cjs', 'system', 'es', 'iife' or 'umd'
```

Commenting out the marked line seems to work.

  Repro (click to show) 

**package.json:**

```
js
{
	"dependencies": {
		"rollup-plugin-node-resolve":"",
		"rollup": "",
... [Log Snipped] ...
	}
}
```

**main.js**

```js
import XLSX from 'xlsx';
export default XLSX;
```

**rollup.config.bad.js**

```
js
import resolve from 'rollup-plugin-node-resolve';
import commonjs from 'rollup-plugin-commonjs';
export default {
	input: 'main.js',
... [Log Snipped] ...
	format: 'cjs'
};
```

**rollup.config.good.js**

```
js
import resolve from 'rollup-plugin-node-resolve';
import commonjs from 'rollup-plugin-commonjs';
export default {
	input: 'main.js',
... [Log Snipped] ...
	format: 'cjs'
};
```

Test:

```
$ npm install
$ npm run good

... [Log Snipped] ...
main.js → rollup.node.js...
[!] Error: You must specify options.format, which can be one of 'amd', 'cjs', 'system', 'es', 'iife' or 'umd'
```
Discussion
- this fixed the issue for me on Windows 10
- Hi, thanks for pointing this out! I think the internal migration logic probably accidentally overwrites the output object in case `dest` is provided. Hope to find some time to have a look soon.
