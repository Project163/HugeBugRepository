Title

celery multi - preload options unrecognized

Description
Preload options are not unrecognized anymore since celery v4.4.4

The example at [Link: Preload options] works with celery v4.4.3 but not with >=4.4.4.

```
python3
# app.py
from celery import Celery
from celery import signals
from celery.bin import Option
... [Log Snipped] ...
def on_preload_parsed(options, **kwargs):
    print(options["template"])
```

Here is the output with v4.4.3:

```
bash
$ venv/bin/celery \
... [Log Snipped] ...
loader   -> celery.loaders.app.AppLoader
settings -> transport:amqp results:disabled
```

This is the output with v4.4.7:

```
bash
$ venv/bin/celery \
... [Log Snipped] ...
loader   -> celery.loaders.app.AppLoader
settings -> transport:amqp results:disabled
```
