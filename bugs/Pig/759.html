Title

pig is running validation for a statement at a time batch mode, instead of running it for whole script

Description
In   PIG-2059  , a change was made to run validation for each statement instead of running it once for the whole script. 
This slows down the validation phase, and it ends up taking tens of seconds.
Discussion
- To fix this, the per-statement validation should be enabled only for interactive mode and if the -c option (check) is used.
- Unit test and test-patch passed. Patch committed to trunk and 0.9 branch.
- PigServer.registerQuery() will not trigger validation after the patch, unless PigServer.setValidateEachStatement(true) is called.
