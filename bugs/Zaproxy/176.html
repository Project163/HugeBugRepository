Title

zap.bat should use %USERPROFILE% instead of %HOMEDRIVE%%HOMEPATH%

Description
ZAP Version: 2017-10-30 (weekly release)

## Suggenstion and Reasons

**zap.bat** should use `%USERPROFILE%` instead of `%HOMEDRIVE%%HOMEPATH%` to locate the file ".ZAP_JVM.properties".

There are two reasons:
1. [Link: The user's default ZAP directory] containing ".ZAP_JVM.properties" is [Link: determined by "user.home" Java system property] which usually equals to `%USERPROFILE%`, not `%HOMEDRIVE%%HOMEPATH%`.
2. `%HOMEDRIVE%%HOMEPATH%` can be different to `%USERPROFILE%`. (Actually I experienced it on a Windows machine managed by Active Directory. Of course, it caused an error same as #3211) See [Link: about these variables]


### Detail about reason 1

How "user.home" property is set is rather complicated, please see [Link: stackoverflow answer].

Here is summary:
* In Java 8: It equals to `%USERPROFILE%`
* In Java 7:  It seems to equal to `%USERPROFILE%` by default.

## Impact by adopting suggestion
* Users who have had `%HOMEDRIVE%%HOMEPATH%` different to `%USERPROFILE%` and put ".ZAP_JVM.properties" in only `%HOMEDRIVE%%HOMEPATH%` will get an error same as #3211
Discussion
- Yeah, that looks better, with Java 8 the `user.home` property is set from `FOLDERID_Profile`/`CSIDL_PROFILE`, which defaults to `%USERPROFILE%`.
