Title

Getting invalid object name 'tags/warning' when attempting to release

Description
**Describe the bug**

When attempting to release via Azure DevOps Pipeline I get the following during the changelog generation which breaks the release in the end:
```
• generating changelog     
      • running git               args=[-c log.showSignature=false describe --tags --abbrev=0 tags/v0.3.18^]
      • git result                output=warning: refname 'tags/v0.3.18' is ambiguous.
v0.3.17

... [Log Snipped] ...

   ⨯ release failed after 1.59s error=fatal: invalid object name 'tags/warning'.
```
When disabling changelog generation everything is working as expected.

**To Reproduce**

Steps to reproduce the behavior:
I'm not able to reproduce this issue because it is working locally as expected.

`.goreleaser.yaml`:
```
yaml
dist: ./artifacts/dist
before:
  hooks:
    - go mod download
... [Log Snipped] ...
    - '^style:'
    - '^refactor:'
```

**Expected behavior**

The release should create a changelog without errors.
