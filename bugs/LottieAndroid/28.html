Title

Reusing LottieAnimationView with different animations cause problems

Description
**Describe the bug**
I have a case on my project where I reuse a LottieAnimationView, switching the animation using setAnimation(int rawRes).

On my first playAnimation it works normally, but when I try to switch to a different animation and then play it, the animator stays frozen on the last frame of the previously played animation.

The same problem happens if I try to play the same animation, only changing the min and max frames with setMinAndMaxFrame(final String startMarkerName, final String endMarkerName, final boolean playEndMarkerStartFrame)

**What version of Lottie did you test this on?**
Works on 3.5.0, broken on 3.6.0

**What version of Android did you test this on?**
Android 10

**Steps To Reproduce**
Steps to reproduce the behavior:

1. Use Lottie 3.6.0
2. Assign an animation
2. Play it
3. Wait for it to end
4. Assign a different animation or the same with different min and max frames
5. Play the animation on the same LottieAnimationView
Discussion
