Title

Using a deprecated interface in generics triggers `DeprecatedClass` error

Description
Consider this piece of code:

```php
/** @deprecated */
interface MyInterface {}

/** @extends ArrayObject  */
class MyClass extends ArrayObject {}
```

[URL]

Psalm correctly detects that the interface that is referenced here is deprecated. However, the error reported is of type `DeprecatedClass` and the message reads "Class MyInterface is marked as deprecated".

I would have expected a `DeprecatedInterface` error instead and an error message that refers to `MyInterface` being an interface, not a class.
