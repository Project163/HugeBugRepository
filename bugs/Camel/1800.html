Title

Removing a route with route scoped error handler, should remove the error handler from JMX

Description
A route scoped error handler should be removed if the route is removed from JMX. 
Context scoped error handlers, should be kept.
Discussion
- I post on @dev about removing the error handler mbeans from JMX as it would be easier than trying to keep properly track of which error handler is context vs route scoped. And which may be used by other routes, and whatnot.  

 And all together the error handler mbeans does not bring much value, and people have not talked about them on the @user. So they are most likely not in use as much.
- The route scoped error handlers is now removed from JMX when removing a route.
