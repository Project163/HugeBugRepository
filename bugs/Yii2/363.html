Title

Path alias not translated in yii\twig\Extension::path()

Description
In Twig templates `{{ path('@alias/to/file') }}` returns `@alias/to/file` instead of `/path/to/file`. Same with `url()`.
Discussion
- in code `url` and `path` return always url::to:

``` php
    public function path($path, $args = [])
    {
        return Url::to(array_merge([$path], $args));
    }
```
