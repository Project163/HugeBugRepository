Title

Static type check reports an error when accessing some property

Description
@groovy.transform.CompileStatic
 class  Test {
 
  List getListVar() {
     new  ArrayList()
  }
 
  void someMethod() {
     def t =  new   Object ()
     t =  this 
     
     t.getListVar()      //No error here
      t.listVar           //error is being reported here
   } 
}
 
  

 1 compilation error: 

 Access to java.lang.Object#listVar is forbidden at line: 13, column: 6
Discussion
- In this case, an error is being reported when accessing 
  
 t.listVar
 
  

 If the variable "t" is initialized directly to "this", the issue does not occur.
