Title

Cannot create ORM mapping against view

Description
### Describe the bug

When I follow the recipe to create a View, I get an error stating that ``ORM mappings can only be made against schema-level Table objects, not TableClause``. In the wiki, it says that it should work with SQLAlchemy 2.0
