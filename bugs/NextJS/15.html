Discussion
- Can reproduce the bug, and confirmed it's a problem with Squoosh CLI:

[Image: image]
- With some further investigation I found that it's related to PNG with _grayscale and alpha_. 

```
› file WCcL3Ip.png
WCcL3Ip.png: PNG image data, 36 x 36, 8-bit gray+alpha, non-interlaced
```

Opened an issue for Squoosh (GoogleChromeLabs/squoosh#971). A temporary work around is to avoid using `gray+alpha` PNGs. When it's `8-bit/color RGBA` it will be handled correctly again.
