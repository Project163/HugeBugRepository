This is a new bug since it did not happen a week or two ago. The bug only occures on command line although the cache and database configs are the same for web. I dont know why this works at all since `apc_store` should return `true` or `false` and not an array. [URL]
Discussion
- `apc_store()` returns an array if the input is an array (the 2nd syntax in PHP manual). It seems this is related with your APC because you said it happens to command line only, not Web.
- Even if you've installed APC, at command line it's disabled by default. [URL]
- ... [Middle Discussions Snipped for Brevity] ...
- ```
$ php -d apc.enable_cli=1 test.php 
array(0) {
}
array(1) {
  'a' =>
  string(1) "b"
}
bool(true)
```

```
$ php -d apc.enable_cli=0 test.php 
array(1) {
  'a' =>
  int(-1)
}
bool(false)
NULL
```
- So it works according to docs. I don't know what happened in @thelfensdrfer case. Fixed `yii\caching\ApcCache::getValues()` though to return according to phpdoc.
