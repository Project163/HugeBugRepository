Title

V7 field array, setValue then deleting does not work without explicit defaultValues

Description
**Describe the bug**
Since V7 rc.3 deleting does not work in an field array when its values are not explicitly set in `defaultValues`.

**To Reproduce**
Steps to reproduce the behavior:

1. Go to [URL]
2. Click on `Set array by SetValue`
3. Try to delete a item
4. See error: TypeError: data is not iterable

**Codesandbox links**
[Link: V7.rc-2 **working fine** without explicitly set `defaultValues`] 
[Link: V7.rc-3 **not working** because of not explicitly set `defaultValues`]
[Link: V7.rc-3 **working fine** with explicitly set `defaultValues`]

**Expected behavior**
Should be able to delete the item without an error.
