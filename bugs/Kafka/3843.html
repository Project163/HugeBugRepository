Title

Rename "Mode" to "SslMode"

Description
In the channel builders, the Mode enum is undocumented, so it is unclear that it is used to signify whether the connection is for SSL client or SSL server. 

 I suggest renaming to SslMode (although adding documentation will be ok too, if people object to the rename)
