Title

[bug] `writeTextFile` does not completely overwrite existing file.

Description
### Describe the bug

When using `writeTextFile` to overwrite an existing file, if the new content is shorter than the old content, the file is only partially overwritten.

### Reproduction

```js
import {fs} from "@tauri-apps/api";

await fs.writeTextFile('test.txt', '12345') // file content is now '12345'
await fs.writeTextFile('test.txt', 'abc') // file content is now 'abc45'
```

### Expected behavior

After the second operation, the file content should be 'abc'
