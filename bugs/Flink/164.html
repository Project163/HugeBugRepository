Title

TaskManager and JobManager do not log startup settings any more

Description
In prior versions, the jobmanager and taskmanager logged a lot of startup options: 
 
	 Environment 
	 ports 
	 memory configuration 
	 network configuration 
 

 Currently, they log very little. We should add the logging back in.
Discussion
- I ran into this issue yesterday as well.
- The logger used in the task manager and job manager is the logger of the Akka actor. That's why it's not logged to the old log files as it did previously. 

 We can still enable it by setting "akka.loglevel" in the config, but I'm not sure whether this is a good idea. It is very verbose as it also includes Akka logs like "Starting remoting", which are not important for most users. 

 Should we use the logger of the companion object again (which logs to the default JM log file)?
