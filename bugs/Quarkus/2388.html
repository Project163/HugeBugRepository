Title

Problem with container image build with podman extension

Description
### Describe the bug

Unable to build container image using extension 'io.quarkus:quarkus-container-image-podman'.

### Expected behavior

Using extension 'io.quarkus:quarkus-container-image-podman' should be sufficient to build container images with podman.

### Actual behavior

When I use exrtension for podman (implementation 'io.quarkus:quarkus-container-image-podman') to following build result:
```
Execution failed for task ':quarkusImageExtensionChecks'.
        gradle addExtension --extensions=quarkus-container-image-docker
```

When I use docker (implementation 'io.quarkus:quarkus-container-image-docker') got following result:
```
Using executable podman within the quarkus-container-image-docker extension. Maybe you should use the quarkus-container-image-podman extension instead?
```

My build environment uses podman. It seems to be a loop:
- podman isn't sufficient, requires docker
- docker complains about using podman

### How to Reproduce?

Enable extension for podman images, insert into dependencies in build.gradle:
```
implementation 'io.quarkus:quarkus-container-image-podman') 
```
