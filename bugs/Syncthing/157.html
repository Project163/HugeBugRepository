Title

When Syncthing is already running, trying to start it gets it stuck in a loop

Description
When Syncthing is running, and I try to start it from the terminal, or in a startup script, Syncthing exits, like it should. It then tries to start again, and fails again, ad infinitum.

It makes sense to do this for a lot of other cases in which it fails to start up, but not in this case. It should just stop completely, because there's already a running instance, instead of trying over and over again.

[monitor] 11:12:11 INFO: Starting syncthing

Is your start script restarting further perhaps?
- I let it try for four minutes, by running it manually, but it just kept trying.

After upgrading to v0.10.7, it kept doing this when I tried again.

Could it be a bug in the GNU/Linux version?
- How are you running syncthing?
Can you post the full log?
- It's probably just a slow system.

```
[monitor] 10:27:46 INFO: Starting syncthing
[R2ESS] 10:27:51 INFO: syncthing v0.10.6 (go1.3.3 linux-386 default) jenkins@build.syncthing.net 2014-11-18 12:24:42 UTC
...
[monitor] 10:27:51 INFO: Syncthing exited: exit status 1
```

That's five seconds for a single startup+exit (plus the one second we sleep between retries). The threshold is that if we've attempted five restarts the last fifteen seconds, we give up. That won't happen in this case. It needs to be smarter, or have a higher threshold.
