Title

Drive mount polling missing directories

Description
#### What is the problem you are having with rclone?
Google drive changes polling doesn't work for new directories, when moving with rclone, only if the parent dir is refreshed with `rclone rc vfs/forget dir=/parent`.
If created on the UI, it works.

Using a rclone crypt mount.
`teamdrive -> crypt`

Discussion
- It seems to be the team drive that is the problem.  I tried your test on a normal drive and it worked fine. However trying it on a team drive causes the problem.

Looking at [Link: the api docs] it looks like we need to set the `IncludeTeamDriveItems` flag as well as the `SupportsTeamDrives` flag!

I've added this flag here, and tested it - it seems to work for me :-)
