Title

[DocDB] Fix typo in error message for xcluster_checkpoint_max_staleness_secs flag validation

Description
Jira Link: [Link: DB-12493]
### Description

If the value for  `xcluster_checkpoint_max_staleness_secs` is lesser than the sum of `log_min_seconds_to_retain` and `update_min_cdc_indices_interval_secs` the following error comes up - 
```
E0820 23:04:01.951020 33181 cdc_service.cc:201] Invalid value '300' for flag 'xcluster_checkpoint_max_staleness_secs': Must be less than the sume of log_min_seconds_to_retain and update_min_cdc_indices_interval_secs
F0820 23:04:01.951089 33181 flags.cc:618] Check failed: _s.ok() Bad status: Invalid argument (yb/util/flags/flags.cc:793): ERROR: failed validation of new value '300' for flag 'xcluster_checkpoint_max_staleness_secs'
 : cdc_service.cc:201] Invalid value '300' for flag 'xcluster_checkpoint_max_staleness_secs': Must be less than the sume of log_min_seconds_to_retain and update_min_cdc_indices_interval_secs
```
In this error message "sume" should be corrected to "sum".
