Title

Unable to download ubuntu-rootfs as new_http_archive

Description
Please provide the following information. The more we know about your system and use case, the more easily and likely we can help.

### Description of the problem / feature request / question:

Trying to download ubuntu rootfs ends up with an error:

```
ERROR: no such package '@docker_brew_ubuntu//image': /private/var/tmp/_bazel_dimka/ /external/docker_brew_ubuntu/usr/share/man/man7/pam.7.gz (File exists).
```

My config is:

`WORKSPACE`
```
new_http_archive(
    name = "docker_brew_ubuntu",
    url = "[URL]
    build_file = "docker/ubuntu.BUILD",
    sha256 = " ",
)
```

`docker/ubuntu.BUILD`
```
load("@bazel_tools//tools/build_defs/docker:docker.bzl", "docker_build")
docker_build(
    name = "image",
    tars = ["ubuntu-base-16.04-core-amd64.tar.gz"],
    visibility = ["//visibility:public"],
)

```

### Environment info
* Operating System:
16.5.0 Darwin Kernel Version 16.5.0: Fri Mar  3 16:52:33 PST 2017; root:xnu-3789.51.2~3/RELEASE_X86_64 x86_64

* Bazel version (output of `bazel info release`):
release 0.4.5-homebrew
