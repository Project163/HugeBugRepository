Title

Reinserting a schedule's unchanged `ScheduleBuildSettings` forces sync points insertions despite `*_ignore_deferred` configs

Description
## Bevy version

`0.16.0-rc.3`

## What you did

I ran this test:

```
rs
use bevy::prelude::*;

#[derive(PartialEq, Debug)]
enum Entry {
... [Log Snipped] ...
    assert_eq!(log1, log2);
}
```

## What went wrong

The assertion at the end failed:

```
assertion `left == right` failed
  left: [System(1), System(2), SyncPoint(1), SyncPoint(2)]
 right: [System(1), SyncPoint(1), System(2), SyncPoint(2)]
```

Reading and reinserting the settings unchanged should not result in a different behavior.
