Title

Injector does not respect TypeScript type-only imports

Description
# 🐞 bug report

### Description

TypeScript introduced [Link: type-only imports in version 3.8] which contains the following text in the documentation:


Now consider a new Angular CLI project with the following relevant files:

**foo.ts**:
```ts
console.log('I do not expect this statement to print if the file is imported as type-only.')

export class Foo { }
```

**foo.token.ts**:
```ts
import { InjectionToken } from '@angular/core';

export const FOO = new InjectionToken('Foo', {
    factory: () => { };
});
```

**app.component.ts**:
```
ts
import { Component, Inject } from '@angular/core';
import { FOO } from './foo.token';
import type { Foo } from './foo';

... [Log Snipped] ...
  constructor(@Inject(FOO) foo: Foo) {}
}
```
The key things to note is that the `Foo` class is being imported as a type only. It is also not being imported anywhere else in the project. As the `console.log` message in the `foo.ts` file states, I do not expect that line to print at run time. I do not expect that line to print because TypeScript says that type-only imports "always gets fully erased, so there’s no remnant of it at runtime". The actual behavior does not match my expected behavior because the `console.log` message is being printed at runtime.

Discussion
- Further investigation shows that the type-only import works as expected if the class is being referenced as a type only anywhere else but the component constructor. The following sample `app.component.ts` does not cause the `console.log` message in the `foo.ts` file to print as expected:

```
ts
import { Component, Inject } from '@angular/core';
import type { Foo } from './foo';

@Component({
... [Log Snipped] ...
  private doSomething(foo: Foo) { }
}
```
[Link: StackBlitz]
- Can confirm, the type-only modifier is not respected when emitting decorator metadata.
- I opened #37912 with a fix, an easy workaround would be to introduce a local type alias and use that instead:

```ts
type Foo_ = Foo;
```
