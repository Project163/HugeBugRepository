Discussion
- You can add this to your build.gradle: 
  
 
tasks.withType(GroovyCompile) {
  groovyOptions.fork =  false 
}
 
  

 Then add "-Dorg.gradle.debug=true" to your gradle command line to have it wait for remote debugger on port 5005.  Then you can open a remote debug session from IntelliJ.  Easiest way to get a consistent break on NPE is to add an exception watchpoint.  Otherwise you need to be sure you have the source that matches your java executable so that the line number are aligned.
