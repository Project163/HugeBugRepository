Title

Cannot get saved entity data for multicheckbox form controlls

Description
If I define form controls in view like that:

``` php
$this->Form->input(
   'insurance.type',
   ['type' => 'select', 'multiple' => 'checkbox',
   options => [...]);
```

I can display this view, when I have empty Insurance entity. When I send this form, I get data like:

```
object(Motors\Model\Entity\Insurance) {

    ...
    'properties' => [
        ...
... [Log Snipped] ...

}
```

But now, when I try to display this entity with data like above (with 'type' as array), I get exception: 'Unable to fetch property "insurance.type"'.
Widget MultiCheckbox accepts array values, but problem is in EntityContext::val(), and rather in method _getEntity(), which doesn't accept array values from entity field:

``` php
if (
    !is_array($next) &&
    !($next instanceof Traversable) &&
    !($next instanceof Entity)
) {
    return $entity;
}
```
