Title

Crash when resizing with URL highlight

Description
The URL highlight stores the state of the last URL highlight with the position of the URL start position. However when resizing, it's possible that the indices of this point change which will cause a crash if the old positions are not within the grid anymore.

The best approach to fix this seems to be to clear the URL highlight state when the window is resized.
