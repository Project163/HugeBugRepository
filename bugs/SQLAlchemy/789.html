Title

array_agg ignores keyword type_ hint for postgres dialect, failing for a nested array

Description
**Migrated issue, originally created by Dmitry Nikonov ([Link: @theseer])**

Hello.

This issue is quite similar to the #4107 but about the [Link: postgresql dialect version] of the `array_agg`.  I suppose it should be fixed in the same manner.

Code to reproduce (Python 3.7.0, SQLAlchemy 1.2.11):
```
python
from sqlalchemy import *
from sqlalchemy.dialects import postgresql

col = column('foo', postgresql.ARRAY(Integer))
... [Log Snipped] ...

function = postgresql.array_agg(col, type_=postgresql.ARRAY(Integer))  # Fails with the same trace
```

Stack trace:
```
---------------------------------------------------------------------------
ValueError                                Traceback (most recent call last)
  in  ()
----> 1 function = postgresql.array_agg(col, type_=postgresql.ARRAY(Integer))

... [Log Snipped] ...

ValueError: Do not nest ARRAY types; ARRAY(basetype) handles multi-dimensional arrays of basetype
```
