Title

`quarkus run` no longer works for certain combinations of dependencies

Description
### Describe the bug

After approximately version 3.18, Quarkus projects that have both `hibernate-orm-rest-data-panache` *and* `liquibase` extensions installed can no longer be run using the Quarkus CLI command `quarkus run`, and results in the following stack trace:

```
[ERROR] Failed to execute goal io.quarkus.platform:quarkus-maven-plugin:3.24.3:run (default-cli) on project code-with-quarkus: Execution default-cli of goal io.quarkus.platform:quarkus-maven-plugin:3.24.3:run failed: io.quarkus.builder.BuildException: Build failure: Build failed due to errors
[ERROR]         [error]: Build step io.quarkus.arc.deployment.BeanArchiveProcessor#build threw an exception: java.lang.IllegalStateException: Failed to index: io.quarkus.test.ActivateSessionContext
[ERROR]         at io.quarkus.deployment.index.IndexingUtil.indexClass(IndexingUtil.java:170)
[ERROR]         at io.quarkus.arc.deployment.BeanArchiveProcessor.build(BeanArchiveProcessor.java:94)
[ERROR]         at java.base/java.lang.invoke.MethodHandle.invokeWithArguments(MethodHandle.java:733)
... [Log Snipped] ...
[ERROR]         at io.quarkus.deployment.index.IndexingUtil.indexClass(IndexingUtil.java:165)
[ERROR]         ... 11 more
```

Note that regular invocation of the application via `java -jar target/quarkus-app/quarkus-run.jar` does not have problems; only `quarkus run`.

### Expected behavior

_No response_

### Actual behavior

### How to Reproduce?

Run the following commands:

`quarkus create app`
`cd code-with-quarkus`
`quarkus ext add hibernate-orm-rest-data-panache liquibase`
`mvn package quarkus:run`

and observe the error. With just one of the installed extensions the error won't occur.

Or in the following repo: [URL]
Run `./mvnw package quarkus:run`
