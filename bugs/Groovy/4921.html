Title

DGM flatten return type is often incorrect

Description
The groovy method  flatten  for  Object[] ,  Collection ,  Iterable ,  List ,  Set  and  SortedSet  does not inference to the correct return type except for the case where there were no aggregate elements to flatten. 

 There isn't anything the type checker can do to detect the return type for non-trivial cases, but the  flatten  methods that accept a transform are a reasonable model: 
  
 
     public   static  <T, E> Collection<T> flatten(Iterable<E> self, Closure<?> flattenUsing) {
         // ...
     }
 
  

 This allows the programmer to declare the expected type: 
  
 
 def  list = [1,[2],[[3],[4]]]
Collection< Integer > coll = list.flatten(Closure.IDENTITY)
