Title

v13.5.2 Style jsx can't seem to handle variable declaration using javascript variable name

Description
### Link to the code that reproduces this issue

[URL]

### To Reproduce

1. Start application (npm run dev)
2. Notice background isn't red

### Current vs. Expected behavior

With the following jsx: 

```
tsx
import { AppProps } from "next/app";

const someVar = "--var-1";

... [Log Snipped] ...
  );
}
```

v13.4.19 rendered properly (background was red) vs v13.5.2 where background is not rendered properly.

Looking at the generated css, v13.4 generated the following:

```css
:root {
    --var-1: red;
    background-color: var(--var-1);
}
```

v13.5.2 generates:

```css
:root {
    --var-1: 0: red;
    background-color: var(--var-1);
}
```
