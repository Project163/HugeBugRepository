Title

Goreleaser builds binarys not asked to build / gon example in docs does not work

Description
**Describe the bug**

Goreleaser insist on creating 386 binarys even though not told to do so also it produces double binarys with said invalid platforms

**To Reproduce**

try to use goreleaser

```
yaml
env:
- GO111MODULE=on
- CGO_ENABLED=0
builds:
... [Log Snipped] ...
    - .gon.hcl
    artifacts: all
```


**Expected behavior**

A clear and concise description of what you expected to happen.

*NOT* build 386 binarys, and *NOT* create tjek-cli only *tjek* as defined in the config

```
   • BUILDING BINARIES

      • building                  binary=/Users/asdf/tjek-cli/dist/tjek-cli_linux_amd64/tjek-cli
```
the 386 binarys should never be build and why is it creating double binarys of everything? one named after the folder of the sourcecode and one named what i asked it to name it
