Title

Replace FileUtils.writeStringToFile(File, String) with (File, String, Charset) to fix deprecation warnings

Description
FileUtils.writeStringToFile(File, String) relies on default charset and should be replaced with FileUtils.writeStringToFile(File, String, Charset).
Discussion
- FYI: For Charsets,  StandardCharsets.UTF-8  is better than  Charset.forName("UTF-8")  because we don't need to write a code to catch and ignore UnsupportedCharsetException.
