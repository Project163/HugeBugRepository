Title

update...values expressions are lost due to differences in how insert/update handle these keys

Description
### Describe the bug

I have been trying to perform a bulk update using `connection.execute` and values added as a connection parameter. The update is conditional, some of the values are nullable and can either be null in the update value _or_ in the existing value, in which case I want to choose the non-NULL value, using `func.COALESCE`. Unfortunately, the coalesce statement appears to be dropped when passing the update `stmt` to `connection.execute`.

I am able to work around the issue by passing `text(str(stmt))` instead of `stmt`.

### To Reproduce

```
python
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy import create_engine, insert, update, select, bindparam, func, text
```
