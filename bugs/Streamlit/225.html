Title

`st.Page` does not throw an error when passed an invalid page; infinite run when invalid page passed to `st.navigation`

Description
### Checklist

- [Link: X] I have searched the [existing issues] for similar issues.
- [X] I added a very descriptive title to this issue.
- [X] I have provided sufficient information below to help reproduce this issue.

### Summary

Streamlit allows you to define an invalid page with `st.Page`. Then, if you pass that page to `st.navigation`, Streamlit enters an infinite run condition.

### Reproducible Code Example

```
Python
import streamlit as st

dne = st.Page("not a real file", title="DNE")
real = st.Page("real.py", title="Real page")
... [Log Snipped] ...
st.navigation([real, real2]) # No error
# st.navigation([real, real2, dne]) # Infinite run condition
```


### Steps To Reproduce

1. Create an `app.py` file as above and two other files (`real.py` and `real2.py`) in the same directory, which can be empty.
2. `streamlit run apply`
3. As is, there is no error.
4. Comment out the `st.navigation` line and uncomment the other one (with the dne page).
5. Observe the infinite run condition.

### Expected Behavior

When declaring a page that does not exist, I expect `st.Page` to throw an error.
If `st.navigation` is passed an invalid page, I expect `st.navigation` to throw an error.
