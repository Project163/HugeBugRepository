Title

i18n __() bug when first argument = null

Description
Passing null as the 2nd argument to __() is buggy if more than 1 replacement is needed.

```
$a = array();
$a['key2'] = 'dummy';

echo __('%s, your %s appointment for %s is confirmed!',
    $a['key1'],
... [Log Snipped] ...

//outputs '%s, your %s appointment for %s is confirmed!'
```

ref:
[URL]

This occurs because the __() function tests " if ($args === null) " without checking if  other arguments might be present.

**_Suggested fix**_
CHANGE:
`if ($args === null) {`
TO:
`if ($args === null && func_num_args() < 3) {`
