Title

authentication doesn't work with proactive auth disabled

Description
### Describe the bug

I have a project with form-based authentication and it works fine.
I want to customize authentication exception responses using a custom exception mapper, to this end (as stated in the [Link: documentation]) I want to disable the proactive auth.
If I disable proactive authentication setting `quarkus.http.auth.proactive = false` in application.properties the authentication doesn't work anymore.

### Expected behavior

The authentication phase should work also with proactive-auth disabled.

### Actual behavior

When I submit credentials from the login form the request to `/j_security_check` returns a 404 error.
