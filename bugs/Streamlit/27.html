Title

key argument for number_input does not exist

Description
# Summary
If you have multiple number_inputs with identical parameters passed to them you get an error stating that they all have the same keys automatically generated. To fix this it instructs you to pass a unique "key" argument. However, the "key" argument does not exist for the number_input().

# Steps to reproduce
What are the steps we should take to reproduce the bug:
1. Create a file with:
    
```
import streamlit as st

num1 = st.number_input("Input a number",value=0)
num2 = st.number_input("Input a number",value=0)
st.write("Their sum is " + str(num1+num2))
```

2. Run it with streamlit. You will see the error message:
```
DuplicateWidgetID: There are multiple identical st.number_input widgets with the same generated key. (When a widget is created, it's assigned an internal key based on its structure. Multiple widgets with an identical structure will result in the same internal key, which causes this error.) To fix this, please pass a unique 'key' argument to st.number_input().
```
3. Edit the file to be:
```
import streamlit as st

num1 = st.number_input("Input a number",value=0,key=0)
num2 = st.number_input("Input a number",value=0,key=1)
st.write("Their sum is " + str(num1+num2))

```


## Expected behavior:
Two number input widgets that can be used to enter two numbers that will be added together and displayed.

## Actual behavior:
`TypeError: number_input() got an unexpected keyword argument 'key'`

## Is this a regression?
no

- Python version: 3.7.3
