Title

install_external_dependencies.sh fails to install new statsmodels 0.9.0

Description
install_external_dependencies.sh installs the latest module statsmodels 0.9.0 which came out on May 14, 2018.  Version history is at   [URL]

 This version does not install correctly and gives the error:
