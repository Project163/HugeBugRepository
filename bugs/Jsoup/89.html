Title

Wildcard namespace selector should also select elements without namespace

Description
Hello,

given the following input:

```xml
 
 Incomplete Theft, The 
     Burke, Ralph 
   
 
```

1. `metadata > meta[property=file-as]` will find ` Burke, Ralph `
2. `metadata > *|meta[property=file-as]` will find ` Incomplete Theft, The `

I would expect the 2nd selector to match both nodes.

Is that intended or is it a bug ?

It can be verified using [URL]

Thanks
Discussion
- Hi -- agreed, I think it makes sense to consider this a bug, and make the wildcard support non-namespaced elements.
- Thanks -- fixed in 1.14.2
