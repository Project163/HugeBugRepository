Title

Middleware: response.cookie mutates options argument

Description
### What version of Next.js are you using?

12.0.4

### What version of Node.js are you using?

v14.16.1

### What browser are you using?

Chrome

### What operating system are you using?

macOS

### How are you deploying your application?

Vercel

### Describe the Bug

The `NextResponse` has `response.cookie(name, value, options)` which mutates the `options` argument.

This leads to unexpected behavior.

In my specific case, I had something along the lines of

```
ts
const cookieOptions = { maxAge: 15552000 };


export async function middleware(request: NextRequest) {
... [Log Snipped] ...
  return response;
}
```

This will log 

```js
15552000
15552
```


In my specific case, this has led to the problem that the first request set the cookie as expected, but all further cookies were lost due to `maxAge` slowly graduating towards 0 because of this code which mutates the passed `options`:

[URL]

### Expected Behavior

I would expect `response.cookie` to not mutate the arguments it receives.


### To Reproduce

Use this middleware and check the console log

```
js
const cookieOptions = { maxAge: 15552000 };


export async function middleware(request) {
... [Log Snipped] ...
  return response;
}
```
