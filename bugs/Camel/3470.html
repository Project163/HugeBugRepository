Title

CXFRS "skipFaultLogging" attribute doesn't work in Spring

Description
When defining a camel-cxf cxf:rsClient bean with skipFaultLogging enabled, like this 

  
 <camelcxf:rsClient id= "rsClient"  address= "http: //localhost:9081/CxfRsService/ rest " 
     serviceClass= "org.apache.camel.component.cxf.jaxrs.testbean.CustomerService" 
    skipFaultLogging= " true "  />
 
  

 ... the exception will still be logged. If you add the flag to the endpoint URI instead,  skipFaultLogging  works as expected.
Discussion
- When going through the Spring factory bean, the code was adding the  beanId  to the endpoint properties in one place and the  FaultListener  in another place.  In the normal  CxfEndpoint , we were merging these properties into a single properties map, but that bit of code was missing from the  SpringJAXRSClientFactoryBean  

 Fixed for  master  in  [URL]
