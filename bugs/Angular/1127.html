Title

upgrade-phonecat-2-hybrid docs example fails with APF v10

Description
# 📚 Docs or angular.io bug report

### Description

  A clear and concise description of the problem...

In [URL] we introduced APF v10, but this resulted in odd uglify error in the `upgrade-phonecat-2-hybrid` example.

The error looks like this:

```
(!) uglify plugin: The transformBundle hook used by plugin uglify is deprecated. The renderChunk hook should be used instead.
 
[!] (uglify plugin) SyntaxError: Error transforming bundle with 'uglify' plugin: Unexpected token: punc ())
 
SyntaxError: Error transforming bundle with 'uglify' plugin: Unexpected token: punc ())
... [Log Snipped] ...
 
    at /home/circleci/ng/aio/tools/examples/shared/node_modules/rollup/bin/rollup:1093:9
```

And the most likely root cause is that the uglify version is very old. We tried switching that example over to use terser didn't help for some reason, but it's possible that the switch to terser was not performed correctly.

To unblock #36944 we temporarily disabled the example test. This issues is here to remind us to come back and resolve this minor issue.

For future reference the terser patch looked like this:

```
From   Mon Sep 17 00:00:00 2001
From: Igor Minar  
Date: Wed, 6 May 2020 10:13:21 -0700
Subject: [PATCH] build: update upgrade-phonecat-2-hybrid to use terser instead
 of old uglify
... [Log Snipped] ...
   version "3.1.0"
   resolved "[URL]
```
Discussion
- This error is also typically shown when there is a trailing comma in a function call.

I’ll have a chat with @devversion tomorrow.
- @alan-agius4 I confirmed locally that switching to `terser` worked. It initially didn't work in [URL] because the rollup config change has not been applied to the AIO boilerplate, but rather to the concrete rollup config primarily used for doc regions.

So this change was actually a noop and on CI uglify was still used. I'll double-check tomorrow again.
- The context for the failure is that now uglify runs on ES2015 output, as there is no downleveling step that converts the Angular framework es2015 output to ES5. Previously, rollup would have just included the ES5 output from the Angular framework packages. Now it fails because uglify does not support es2015 syntax.
- @devversion glad to hear it’s fixed.  Feel free to add me as a reviewer.
