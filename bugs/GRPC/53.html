Title

Should install pkgconfig files under gRPC_INSTALL_LIBDIR

Description
### What version of gRPC and what language are you using?

1.36.1, C/C++/Python (packaging for Fedora Linux)

### What operating system (Linux, Windows,...) and version?

Fedora Linux 35/Rawhide and 34

### What runtime / compiler are you using (e.g. python version or version of gcc)

python 3.9.2 and gcc 11.0.0, but it is irrelevant

### What did you do?

Build and install the package using CMake, with `gRPC_INSTALL_LIBDIR` set to something other than the default `lib`; in this case, `-DgRPC_INSTALL_LIBDIR:PATH=/usr/lib64`.

### What did you expect to see?

The `.pc` files should be installed in `/usr/lib64/pkgconfig/` in this example.

### What did you see instead?

The `.pc` files are installed in `/usr/lib/pkgconfig/` in this example.

### Anything else we should know about your project / environment?

I think that, in the `install` command in the `generate_pkgconfig` function in `templates/CMakeLists.txt.template`, the value of `DESTINATION` should be changed from `"lib/pkgconfig/"` to (if I understand the templating system correctly) `" ${gRPC_INSTALL_LIBDIR}/pkgconfig "`.
