Title

XBean has a runtime issue with Spring 2.0M2

Description
Apparently there is an issue with XBean now that Spring 2.0 (starting with M2) is compiled against a Java 5 compiler ( [URL]  It's probably worth investigating how long before XBean releases a fix and postponing the 4.0 release until they do.  If not, at least documenting in a known issues list that ActiveMQ 4.0 can't working with 2.0M2 and later until a later release where they do fix it.
