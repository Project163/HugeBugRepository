Title

Expressions of the form `a[]` cause the metadata collector to throw

Description
## I'm submitting a ...
 
  
[x] Bug report  
  

## Current behavior

[URL]

If an Angular annotation contains an expression like `a[]` it will throw. The source is invalid but, in the context of the language service, the collector will be called on this file regardless of errors.

## Expected behavior

An error message should be reported instead of a throw.

## Minimal reproduction of the problem with instructions

Add an expression such that `[]` is a trail such as:

```ts
import {Component} from '@angular/core';

const value = [];
@Component({
   provider: [{provide: 'some token', useValue: value[]}]
})
export class MyComponent {}
```
