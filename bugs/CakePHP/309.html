Title

Undefined variable: $validates when calling saveMany() with array('validate' => false)

Description
On Cake 2.4.2, if you call the following:

```
$data = array(
    array('id' => 1, 'some_other_field' => 'hi'),
    array('id' => 2,' some_other_field' => 'bye')
);
$this->saveAll($data, array('validate' => false));
```

It throws an error saying 

```
Notice (8): Undefined variable: validates [CORE/Cake/Model/Model.php, line 2249]
```

I looked through the tests for the saveAll() method, and it appears the scenario where array('validate' => false) is passed is not tested, hence why it probably wasn't caught earlier. My fix was to just add $validates = false to line 2204.

Thanks for all your work on Cake! This is the first snag I've hit. Love everything else :)
