Title

ColumnDefault.__repr__ does not cope with tuple in composite types.

Description
**Migrated issue, originally created by Nicolas Caniart**

We defined a composite type that is seen as a tuple on the Python side: a value with a unit.

Some columns are defined with a default value like: `(0, Unit.ton)`. The __repr__ method of the ColumnDefault class cannot cope with such values as the tuple is intrepret as arguments to the format, not the actual value to format. Simple fix is to wrap the format argument with `(` and `, )` to make it safe.
