Title

Switching from a streaming service with linked Account to service with stream key leaves account linked

Description
### Operating System Info

Windows 10 (and probably all other)

### Other OS

_No response_

### OBS Studio Version

27.1.0-rc1

### OBS Studio Version (Other)

_No response_

### OBS Studio Log URL

-

### OBS Studio Crash Log URL

_No response_

### Expected Behavior

The linked account gets unlinked and you can start a stream to the newly selected service with the streamkey.

### Current Behavior

Account stays linked and stream happens to the linked account.

### Steps to Reproduce

1. Connect an account for example YouTube
2. Switch to another service like Twitch for example
3. Click the use stream key option and enter a valid stream key
4. Apply settings and try to start a stream
5. YouTube event creation dialog will open instead of the stream starting on twitch


### Anything else we should know?

Probably happens with all services that have account linking when you switch to another service when using a stream key.

Switch to another service and linking the account will correctly unlink the old account.
