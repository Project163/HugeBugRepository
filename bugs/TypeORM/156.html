- Hey, @rizedr 

Unfortunatelly `typeorm` is very unstable library. Try some old version of the one. As instance workaround was tested with `0.2.30`.
Currently considering `typeorm` uses decorators and `reflect-metadata` it makes sense to use some other ORM, with all respect to developers of `typeorm`
- This is also a real blocker for us.

Our current workaround is to have a script that parse the migration with regex and wrap CREATE/ALTER/DROP statement on enum with `DO $$ BEGIN ${statement} EXCEPTION WHEN dependent_objects_still_exist THEN null; END $$;`
