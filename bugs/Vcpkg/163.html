Title

application built with libebur128 1.2.5 on x64 Windows crashing with exit code

Description
**Describe the bug**
I am working on [Link: getting Mixxx building] with dependencies from vcpkg. We are building dependencies with vcpkg, creating an archive with `vcpkg export`, uploading it to our file server, then downloading that on GitHub Actions. Using [Link: this branch] based on  , Mixxx built and ran fine. But when I tried merging those changes with the latest upstream master branch, [Link: every test started failing] with exit code  . We are using the CMake toolchain file from the vcpkg export archive. The only thing that changed was using a different `vcpkg export` archive; nothing changed in the application code or application build system.
