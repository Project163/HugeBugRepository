Title

camel-plc4j - Cannot load drivers when using poll mode

Description
The drivers cannot be loaded in poll mode, and especially if using route controller as then its another thread that is startup up camel, and plc4j has some service loaded that is based on current class loader. 

 So we need to provide the app context classloader, then this also works with jbang that can download drivers.
