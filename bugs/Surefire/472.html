Title

TestNG parallel options seem to not be honored

Description
I have some simple tests I'm trying to configure to run in parallel using Maven 3.3.3 and the latest versions of TestNG.  I've set my POM file to the following: 

              <plugin> 
                <groupId>org.apache.maven.plugins</groupId> 
                <artifactId>maven-surefire-plugin</artifactId> 
                <version>2.18.1</version> 
                <configuration> 
                    <parallel>methods</parallel> 
                    <threadCount>50</threadCount> 
                </configuration> 
            </plugin> 

 When I run in parallel, I only get 10 threads no matter the setting and I can not change it.  I've tried adding the annotation parameter  to the method as well: 

      @Test(dataProvider = "dataProvider", threadPoolSize = 50) 

 Nothing seems to help.  I have a simple project that illustrates what I'm seeing.
Discussion
- Sample project attempting to illustrate a parallel data provider feeding a method.   Attempting to increase the number of threads handling the method calls.
- See my comment in    SUREFIRE-1177  . I tested TestNG 6.8 and 6.9.6 with surefire configuration of parallel=methods and threadCount=2 and the timestamps of test methods really overlapped. 

 The problem is in your POM 
  
 <parallel>tests</parallel>
 
  
 You mean parallel=methods or classes. 
First of all read the documentation because these values in configuration parameter may differ from TestNG configuration
