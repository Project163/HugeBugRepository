Title

Setting `add-version-to-label-selectors: false` removes the app.kubernetes.io/version label

Description

It seems that setting `add-version-to-label-selectors: false` completely removes the version label.

### Expected behavior

The version should not be used in the selector but still be in the labels.

### Actual behavior
