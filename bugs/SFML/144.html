Title

sf::Text::getLocalBounds() inconsistency

Description
I've recently realized that `sf::Text::getLocalBounds()` is a bit inconsistent.
When the text object has an outline applied then `top` and `left` return correctly compensated negative values, but `width` and `height` still contain the outline. This is a bit problematic to align the text to the right without it being affected by the outline.
