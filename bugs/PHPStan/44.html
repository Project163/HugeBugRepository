Title

array_pop(): Unreachable statement - code above always terminates.

Description
# Bug report (version 0.12.42)

If you have a queue with single item in it, phpstan seems to think that array_pop() returns null.

### Code snippet that reproduces the problem

[URL]

```
php
function foo(): void
{
    $queue = ['asd'];
    $list = [];
... [Log Snipped] ...
    } while ($queue);
}
```

### Output

Line 10: Unreachable statement - code above always terminates.

### Expected output

No error
Discussion
- [URL] should fix this.  However PHPStan will still (correctly) report that the if-condition is always false. The do-while-loop will only ever execute once, thus the comparison will always be `'asd' === null`.
