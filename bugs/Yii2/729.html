Title

OCI Incorrect column length unit

Description
Hello!
Gii generator get wrong max length for string type
Gii returning max value of string from table ALL_TAB_COLUMNS and column DATA_LENGTH.
DATA_LENGTH returning value in bytes, for get correct length we must compare CHAR_USED with symbol 'C' and get value from CHAR_LENGTH.
VARCHAR2 can be installed with a subtype of BYTE and CHAR.

SQL with error
```
SELECT
    A.COLUMN_NAME,
    A.DATA_TYPE,
    A.DATA_PRECISION,
    A.DATA_SCALE,
... [Log Snipped] ...
    AND B.OBJECT_NAME = :tableName
ORDER BY A.COLUMN_ID
```
Correct SQL
```
SELECT
    A.COLUMN_NAME,
    A.DATA_TYPE,
    A.DATA_PRECISION,
    A.DATA_SCALE,
... [Log Snipped] ...
    AND B.OBJECT_NAME = :tableName
ORDER BY A.COLUMN_ID
```
