Title

`space-in-parens` warns multiline with a comment.

Description
When there is a comment after an opening parenthesis, this rule warns spacing which is between the parenthesis and the comment.
This behavior is different from other spacing rules (`block-spacing`, `object-curly-spacing`, `computed-property-spacing`, `array-bracket-spacing`)
Is this intended behavior?

``` js
/* eslint space-in-parens: 2 */
foobar( // some comment
    param,
    args,
    variables
);
```
