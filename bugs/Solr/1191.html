Title

When a core is registering with ZooKeeper, the timeout to find the leader in the cluster state is 30 seconds rather than leaderVoteWait + extra time.

Description
The sub calls to get the leader had a 30 second wait which effectively short circuits the top level timeout with regards to waiting for an initial leader. Not a big deal in smaller clusters, but can end up as problem with larger clusters where a node might timeout and need to be restarted.
