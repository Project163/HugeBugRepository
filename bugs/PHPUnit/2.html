Title

Composer-installed PHPUnit does not show version information

Description
I installed PHPUnit via composer (see [URL] Now I get the following error

```
➜  test  ./vendor/bin/phpunit --version
fatal: Not a git repository (or any parent up to mount point /home)
Stopping at filesystem boundary (GIT_DISCOVERY_ACROSS_FILESYSTEM not set).
PHPUnit  by Sebastian Bergmann.
```

because `vendor/phpunit/phpunit` is not a Git repository.
Discussion
- Composer does not always install packages by cloning them. For released versions (i.e. tags), it will use the github zipball by default
- How can I configure (in PHPUnit's `composer.json` file) that I would like Composer to use a clone instead of the tarball?
- ... [Middle Discussions Snipped for Brevity] ...
- How do I get the name of the tag then?
- We don't support var replacements during install, so if you don't set the version constant before tagging this is not gonna be easy. For users it's fairly easy, they can do `composer show phpunit/phpunit` and see which version they got installed. If you really want to do it, you can hack something up using the composer installed repository:

```
$packages = json_decode(file_get_contents(dirname(__FILE__) . '/../../composer/installed.json'));
```

Then you can check in packages for the version of phpunit/phpunit. Same should be done for installed_dev.json since it's likely to be a dev requirement only.
