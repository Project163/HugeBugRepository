Title

Error reading the file size larger than 2 gb

Description
Error reading bytes from the file sent via servlet when it has a size larger than 2GB, it puts the total file size is negative.
Discussion
- I think it is a very old problem about j2ee. 
commons-upload get total size of upload using ServletRequest#getContentLength() 

 Interface ServletRequest#getContentLength() return a int value. 
on j2ee javadoc: 
  an integer containing the length of the request body or -1 if the length is not known 

 The max value of int is 2147483647, it is less then 2gb(2147483648). 
then it return -1
- No,   FILEUPLOAD-188   states upload is impossible. This issue just states the file size reported is wrong IMHO.
