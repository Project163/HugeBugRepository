Title

New consumer should align close timeout handling with classic consumer

Description
see discussion:  [URL]

 In the classic consumer, the timeout respects  request.timeout.ms.  
However, in the async consumer, this logic is either missing or only applies to individual requests. Unlike the classic consumer, where  request.timeout.ms  works for the entire coordinator closing behavior, the async implementation handles timeouts differently. 

 We should align the close timeout-handling to enable ConsumerBounceTest#testClose
