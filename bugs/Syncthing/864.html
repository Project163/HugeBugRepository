Title

UTF-8 normalization doesn't work on macOS

Description
When Syncthing sees a filename which is well formed UTF-8 but unexpected normalization form for the system it corrects the normalization form on disk. This currently doesn't happen on macOS, instead the file remains unscanned and "invisible" to Syncthing.
Discussion
- I added a test case, and with a normal `basicFs` it works, but when wrapped with a `caseFs` the normalization logic breaks. ~~Probably because the caseFs itself does normalization as part of case conversion.~~ Because our case folding doesn't normalize, so when we look up the file there it generates a `not found` even though the underlying stat succeeds.
- Unfortunately, this fix doesn't fix the original problem. See [Link: Forum] for further details.
