Title

Don't require a `@return` tag for `@interface`

Description
There is already a condition that disables the check for `@return` for `@class` and `@constructor`.  The [Link: `@interface` tag] may be applied to a constructor instead of one of these.

With ESLint @  , the code below doesn't pass the `valid-jsdoc` rule:

``` js
/* eslint valid-jsdoc: 2 */

/**
 * Creates a new thing.
 * @interface
 */
function Thing() {}
```

If `@interface` is changed to `@constructor`, `valid-jsdoc` passes (as it should).
