Title

Batch with multiple conditional updates for the same partition causes AssertionError

Description
Reproduced in 3.0.10 and 3.10. Used to work in 3.0.9 and earlier. Bug was introduced in   CASSANDRA-12060  . 

 The following causes an AssertionError: 
  
 CREATE KEYSPACE test WITH replication = {  'class'  :  'SimpleStrategy' ,  'replication_factor'  : 1 };
create table test.test (id  int  PRIMARY KEY, val text);
BEGIN BATCH INSERT INTO test.test (id, val) VALUES (999,  'aaa' ) IF NOT EXISTS; INSERT INTO test.test (id, val) VALUES (999,  'ccc' ) IF NOT EXISTS; APPLY BATCH ;
