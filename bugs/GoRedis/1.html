Title

v9 (RC4): `rediscensus.TracingHook` (from `github.com/redis/go-redis/extra/rediscensus/v9`) doesn't implement `redis.Hook`

Description
```
go
package main

import (
	"github.com/redis/go-redis/extra/rediscensus/v9"
... [Log Snipped] ...
	client.AddHook(rediscensus.TracingHook{})
}
```

## Expected Behavior

`rediscensus.TracingHook` should implement `redis.Hook`.

## Current Behavior

It does not.

