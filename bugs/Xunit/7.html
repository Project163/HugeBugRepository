Title

VS test runner fails when trying to report a wrapped AssertException

Description
I'm using

 
Visual Studio 2013 Update 1
xunit 1.9.2
xUnit.net runner for Visual Studio 2012 and 2013 0.99.6
 

When I try to run a test that performs an assertion, and the resulting `AssertException`-derived exception is subsequently wrapped in some other exception, the test runner fails with `IndexOutOfRangeException`.
Repro test case is pasted below.
The full test output is pasted below.

One of practical impacts of this bug is that now I can't use the VS test runner when working with [Link: TickSpec] tests, as all assert exceptions reported from there are wrapped in TargetInvocationException.

VS test runner 0.99.5 seem to run those tests and report exceptions properly.
(also, tests are working properly with xunit GUI runner (v.1.9.0)).

I saw a related pull request [Ref: #71] (Xunit1 exception handling...), but I believe that 0.99.6 should already contain those changes.

Repro:

 
        [Fact]
        //xunit VS test runner 0.99.6 fails with IndexOutOfRangeException
        static void WrappedAssertExceptionShouldBeReported()
        {
            try
            {
                Assert.True( false );
            }
            catch ( Exception ex )
            {
                throw new Exception( "failure", ex );
            }
        }

 

This one works fine, though:

 
        [Fact]
        //works fine with xunit VS test runner 0.99.6
        static void WrappedExceptionOfOtherTypesShouldBeReported()
        {
            try
            {
                throw new Exception( "error" );
            }
            catch ( Exception ex )
            {
                throw new Exception( "failure", ex );
            }
        }
 

Test output from VS test runner 0.99.6:

------ Run test started ------
System.Reflection.TargetInvocationException: Exception has been thrown by the target of an invocation. ---> System.IndexOutOfRangeException: Index
