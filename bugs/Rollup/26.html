Title

`delete` statement dropped in the output

Description
``` JS
//main.js
export default function foo(o) {}

foo.bar = 8;

delete foo.bar;
```

`rollup -i main.js > bundle.js`

``` JS
//bundle.js
function foo(o) {}

foo.bar = 8;
// note the conspicuous absence of `delete foo.bar;`.
export default foo;
```

Is this expected?

The test case is available in the [Link: `drops-delete` branch of my rollup playground].
