Title

Context not used by the Spider even if selected

Description
Issue reported in OWASP ZAP User Group: [URL]

Steps to reproduce the issue:
1. Run ZAP;
2. Access the target website;
3. Include the root node of the website in "Default Context" and exclude child nodes, for example:
Include:
\Q[URL]
Exclude:
\Q[URL]
(make sure the root node is in context)
4. Open the spider dialogue, select the "Default Context" as starting point, start the spider and note that child nodes are not spidered (as expected).
5. Reopen the spider dialogue, select the root node as starting point and note that the "Default Context" is selected;
6. Start the spider and note that child nodes, which are excluded from the context, are spidered.

Remarks:
The same problem also happens with API when scanning as a user (which has an associated context).

ZAP Versions:
Versions >= 2.4.0
