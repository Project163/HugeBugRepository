Several tests don't clean resources (connections should be closed)

Description

    
Discussion

    
- The folowing tests don't do a proper resource cleaning:  
client/src/test/java/org/apache/qpid/test/unit/basic/close/CloseTests.java 
client/src/test/java/org/apache/qpid/test/unit/basic/InvalidDestinationTest.java

 Would be good if somebody can double check whether this list is exhaustive.
- I have checked in a patch for the above tests to close resources. I have also changed DurableSubscriptionTest#testDurability to unsubscribe the durable subscriber as the session is created as no ack the test cannot be run twice in a row because messages are redelivered (messages are not acked)
- Rather than closing connections manually in each test case, we could probably modify QpidTestCase to track the connections that it gives out via it's getConnection(..) methods, and automatically close them on teardown. This would at least narrow the problem to only those tests that don't extend QpidTestCase, which should be a diminishing number.
- This is solved but as mentioned QpidTestcase will benefit in closing the connection.
