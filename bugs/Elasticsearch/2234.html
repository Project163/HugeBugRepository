Title

SQL: Sorting by aggregate function produces incorrect results

Description
```
SELECT COUNT(*) count, "geoip.city_name" FROM "logs_server*" GROUP BY "geoip.city_name" ORDER BY "count" DESC LIMIT 100
```

produces different results than terms aggregation:
```
GET logs_server*/_search
{
  "size": 0,
  "aggs": {
    "test": {
... [Log Snipped] ...
  }
}
```

Seems that not all buckets returned by the underlying composite aggregation are processed but instead the sorting process bails out earlier when the PriorityQueue is full.
