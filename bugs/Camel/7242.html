Title

[camel-observation] Observations should not influence metrics

Description
While working on   CAMEL-21869   I realized that the issue raised in   CAMEL-21854   has a different nature. The observation should correctly set the trace with the logged message as it used to do. However, as we are using an Observation object, it seems this one is directly affecting metrics, beside tracing feature. 

 In order to properly fix the issue reported in   CAMEL-21854  , instead of not logging the trace, we should tell the observation framework not to consider the traces for metrics purposes.
