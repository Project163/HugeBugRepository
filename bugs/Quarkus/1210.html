Title

Regression: Continuous testing does not detect new test classes

Description
### Describe the bug

Given having a Quarkus application running in DEV mode and with the continuous testing enabled, 
When we copy a test java class into the sources
Then the test should be detected and executed

Note that the above use case was working fine in 2.0.0.Final.

### How to Reproduce?

1. git clone `[URL]
2. cd quarkus-test-suite
3. git checkout reproducer_18795
4. cd http/http-minimum
5. run it using `mvn quarkus:dev`
6. Enable continuous testing (press r)
7. in another terminal, use: `cp src/test/resources/HelloResourceTest.java.template src/test/java/HelloResourceTest.java`

The new HelloResourceTest should be detected but is not. This was working in previous versions.
