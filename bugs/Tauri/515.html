Another interesting one from ( [URL] )


What wixsharp does is:
```csharp
ProductId = CalculateProductId(guid.Value, Version);
```

Where guid.Value is a static string on their project setup, but Version changes on each build.

So maybe Tauri should do the same and generate the GUID based on ProductName+Version instead of just ProductName?
