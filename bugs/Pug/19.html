Title

Inheritance is recursive only to 3rd level

Description
In order to reproduce, create 4 jade files that inherit from each other
4 extends 3
3 extends 2
2 extends 1

What you will see is that 4.jade file is not rendered at all.
Hera are simple files:

**file 1.jade**

``` jade
!!!
html
    body
        h1 1
        block one
```

**file 2.jade**

``` jade
extends 1

block one
    h2 2
    block two
```

**file 3.jade**

``` jade
extends 2

block two
    h3 3
    block three
```

**file 4.jade**

``` jade
extends 3

block three
    h4 4
```

**compile script**

``` js
var jade = require('jade');
    fs = require('fs'),
    stringOfJade = fs.readFileSync('4.jade', {encoding: 'utf-8'});

var fn = jade.compile(stringOfJade, {filename: '4.jade', pretty: true});
console.log(fn());
```

**Result**

```
html
 
 
   
     1 
... [Log Snipped] ...
   
 
```

**Desired result**

```
html
 
 
   
     1 
... [Log Snipped] ...
   
 
```
