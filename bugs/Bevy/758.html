Title

`DespawnOnEnter`/`DespawnOnExit` no longer working on `Observers`

Description
## Bevy version and features

Version 0.17

## What you did

Since #20204, can no longer be despawned by using the `DespawnOnEnter`/`DespawnOnExit` components. This is due to them being `Internal` entities and thus they are not queried in the systems responsible for despawning entities. 

[URL]

[URL]

Is this intended or should observers be able to be despawned?
Discussion
- Hmm come to think of it, this also ignores `Disabled` entities, which will cause invariants to be violated when the entity is enabled again.

In my opinion, `DespawnOnExit` should be agnostic to any filters, as it is used to uphold invariants. If your invariant is that the observer is despawned, that sounds legitimate to me.
- Yeah, I agree that those systems should ignore default query filters.  Using `Disabled` to make an entity temporarily not exist shouldn't prevent `DespawnOnExit` from making it permanently not exist!  

We probably want to build an `AllowsAll` filter that ignores *all* default query filters, since I imagine the same reasoning applies to *any* of them.
