Title

3.0 - check for new entity even if pk is null

Description
When inserting new entity:

``` php
$entity = $this->Articles->newEntity();
$this->Articles->save($entity);
```

Table::_processSave will try to find if the record is already there:

``` php
SELECT 1 AS `existing` FROM articles AS Articles WHERE Articles.id = NULL LIMIT 1
```

but is this correct? PK should never be null (maybe only in SQLite) so all that "existing" queries for new entity are really needed? Of course ONLY for new entity have no sense, they have A LOT of sense for old entity that should be modified..
