Title

[bug] Relative paths in `version` field of `tauri.config.json` is not correctly parsed by `generate_context!()` since `fa028ebf`

Description
### Describe the bug

The `version` field should accept paths to `package.json`. This works with the default directory layout as is generated by `create-tauri-app`, but may fail in `cli.js>=1.0.3` when the layout is changed.

### Reproduction

1. Clone this repository: [URL]

2. `cd` into it, and 

```
pnpm i -r
pnpm tauri dev
```

It fails with

```
error: `package > version` must be a semver string
 --> src\tauri\src\main.rs:8:10
  |
8 |     .run(tauri::generate_context!())
  |          ^^^^^^^^^^^^^^^^^^^^^^^^^^
... [Log Snipped] ...

error: could not compile `app` due to previous error
```

3. Make these changes:

```
diff
--- a/src/frontend/package.json
+++ b/src/frontend/package.json
@@ -8,6 +8,6 @@
     "@tauri-apps/api": "^1.0.2"
... [Log Snipped] ...
   }
 }
```

And run:

```
pnpm up -r 
pnpm tauri dev
```

It still fails.

4. Make these changes:

```
diff
--- a/src/frontend/package.json
+++ b/src/frontend/package.json
@@ -8,6 +8,6 @@
     "@tauri-apps/api": "^1.0.2"
... [Log Snipped] ...
   }
 }
```

And run: 

```
pnpm up -r 
pnpm tauri dev
```

It now succeeds.

### Expected behavior

Step two and three should succeed.
