Title

Native build will java 17 project fail because using a java 11 image

Description
### Describe the bug

Native build will java 17 project fail because using a java 11 image.

To workaround it: 
```
 quarkus build --native -Dquarkus.native.container-build=true -Dquarkus.native.builder-image=quay.io/quarkus/ubi-quarkus-mandrel:22.0-java17
```

### Expected behavior

it should use `quay.io/quarkus/ubi-quarkus-mandrel:22.0-java17` and build correctly.


### How to Reproduce?

Reproducer:
1. [URL]
2. `quarkus build --native -Dquarkus.native.container-build=true`

It will fail because the image used is: [Link: quay.io/quarkus/ubi-quarkus-native-image:22.0-java11]
