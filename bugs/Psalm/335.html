Title

MissingFile and UnrecognizedStatement errors when trying to run phar

Description
I am trying to run psalm via phar and getting following errors (after successfully running `--init` to create the config):

```
Scanning files...
Analyzing files...

ERROR: MissingFile - C:\server\phar\psalm.phar:12:1 - Cannot find file C:\server\www\local\phar:\box-auto-generated-alias-8ebef225ae92.phar\.box\bin\check-requirements.php to include
... [Log Snipped] ...

Checks took 0.25 seconds and used 37.966MB of memory
```

Win7, PHP 7.2.11

```
Psalm  @ 
```
Discussion
- psalm.phar should be outside of the directory being analyzed, or in a file/directory that's completely excluded from parsing/analysis
- It is. `C:\server\phar\psalm.phar` is phar location and `C:\server\www\local\` is current directory where it’s being called.
- Thanks for this - seems like `Phar::running(false)` uses Unix slashes.
- I've released Psalm 3.0.2 with the fix
