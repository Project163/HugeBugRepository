Title

Initialize Executor.threadPool before ExecutorSource

Description
I recently saw some NPEs from   ExecutorSource:44   in the first couple seconds of my executors' being initialized. 

 I think that  ExecutorSource  was trying to report these metrics before its threadpool was initialized; there are a few LoC between the source being registered ( Executor.scala:82 ) and the threadpool being initialized ( Executor.scala:106 ). 

 We should initialize the threapool before the ExecutorSource is registered.
