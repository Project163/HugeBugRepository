Title

Nested Field Array Not Moving Errors

Description
**Describe the bug**
Nested Field Array Not Moving Errors
[URL]

[URL]

**To reproduce the issue I am seeing:**
- Click 'Append Nested' twice
- Put a value into 'Sub Nested Array'[0] input
- Click in and out of 'Sub Nested Array'[1] input to trigger a blur error (input will have 'ERROR' in red under it)
- Click the 'Move Nested' button (hard coded to move 'Nested Array'[0] to 'Nested Array'[1])

**What happens:**
- 'Sub Nested Array' inputs swap
- 'Sub Nested Array'[1] error stays at 'Sub Nested Array'[1]

**What is expected:**
'Sub Nested Array'[1] error moves to 'Sub Nested Array'[0] as the value does
Any ideas on what I am doing wrong?
Discussion
- This fix works for the presented case. However, if you reverse the actions:
- Click 'Append Nested' twice
- Put a value into 'Sub Nested Array'[1] input
- Click in and out of 'Sub Nested Array'[0] input to trigger a blur error (input will have 'ERROR' in red under it)
- Click the 'Move Nested' button (hard coded to move 'Nested Array'[0] to 'Nested Array'[1])

The error stays on 'Sub Nested Array[Link: 0]'. Updated [codesandbox] to use v6.0.6.
