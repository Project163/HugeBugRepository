Title

Recovery after out of disk space (when space freed up) needs manual intervention

Description
When broker runs out of disk space, the journal excepts and the send fails with an exception as expected. The default IO exception handler ignores the exception. (aside: it is possible to install an exception handler that shuts down the broker:  [URL]

 On restart, the last journal file that failed a write is left with 0 size, this impedes restart recovery as it cannot be parsed.
