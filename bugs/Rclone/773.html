Title

VFS: stale entries in the cache with --vfs-cache-mode full

Description
#### What is the problem you are having with rclone?

Can't install "rclone-beta-latest-linux-amd64.deb"

#### Which OS you are using and how many bits (e.g. Windows 7, 64 bit)

Debian sid
```
$ uname -a
Linux 5.16.0-5-amd64 #1 SMP PREEMPT Debian 5.16.14-1 (2022-03-15) x86_64 GNU/Linux
```
#### The command you were trying to run (e.g. `rclone copy /tmp remote:tmp`)
```
$ sudo apt install /tmp/rclone-beta-latest-linux-amd64.deb
```
#### A log from the command
```
Reading package lists... Error!
E: Invalid archive member header
E: Could not read meta data from rclone-beta-latest-linux-amd64.deb
E: The package lists or status file could not be parsed or opened.
```
#### Other information

When trying to open the .deb package with an archive manager I got the following error when trying to open "data.tar.gz" :
```
An error occurred while extracting files
Truncated ar archive
```
The .deb packages for other platforms don't seem to be impacted (can extract the content of "data.tar.gz")
```
$ sha256sum rclone-beta-latest-linux-amd64.deb
   rclone-beta-latest-linux-amd64.deb
```

So what looks like happened is the cache and the actual file system got out of sync.
