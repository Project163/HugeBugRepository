Title

Aggregations: DateHistogramBuilder uses wrong data type for pre_offset and post_offset

Description
The DateHistogramBuilder stores and builds the DateHistogram [Link: with a `long` value for the `pre_offset` and `post_offset`], which is neither what the [Link: API docs specify] (which specify the format is the data format `1s`, `2d`, etc.) nor what the [Link: DateHistogramParser expect].

This forces the improper construction of DateHistogram requests when using the Java API to construct queries.  Both the `preOffset` and `postOffset` variables should be converted to `Strings`.
