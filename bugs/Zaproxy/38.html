Title

Returned HAR/list does not contain correct redirection messages

Description
Steps to reproduce the issue:
1. Run ZAP with API enabled;
2. Send a HAR request following redirections, using the API (http://zap/OTHER/core/other/sendHarRequest/), for example:

```
{
  "request" : {
    "method" : "GET",
    "url" : "[URL]
    "httpVersion" : "HTTP/1.0",
... [Log Snipped] ...
  }
}
```
1. Check, in "History" tab, that both requests (original and redirection) were correctly sent;
2. Note, in the returned HAR, that both requests/responses have exactly the same content (i.e. first request is the same as the second).

ZAP Version:
Versions >= 2.3.0
Discussion
- This also affects the action "sendRequest", which returns a list of messages.
