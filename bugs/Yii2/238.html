Title

batchInsert() for SQLite

Description
When using SQLite's version `\db\QueryBuilder::batchInsert()`, SQLite will fail when inserting more than 500 rows at a time due to [Link: SQLite's limitation of 500 terms per select statement]. This can be overcome by using the [Link: newer insert syntax for SQLite >= 3.7.11]. 

This issue is related to pull request #3545 
### stack trace

```
*** applying m140521_091550_load_data_table
Exception 'yii\db\Exception' with message 'SQLSTATE[HY000]: General error: 1 too many terms in compound SELECT
Failed to prepare SQL: [...]

in src/basewrd/vendor/yiisoft/yii2/db/Command.php:157
... [Log Snipped] ...
#13 src/basewrd/yii(30): yii\base\Application->run()
#14 {main}
```

note that `helper::_batchInsert()` in the trace is just a wrapper:

```
public static function _batchInsert($table, $columns, $data) {
    Yii::$app
            ->db
            ->createCommand()
            ->batchInsert($table, $columns, $data)
            ->execute();
}
```
Discussion
- I think a proper solution is to use the newer syntax when the version allows.
I don't think it worths the effort or is the right direction trying to overcome the limit that is enforced by DBMS.
- We should detect SQLite version (http://www.php.net/manual/en/sqlite3.version.php) and use the new syntax when we have SQLite >= 3.7.11.
- Newer syntax (http://www.sqlite.org/lang_insert.html) is similar to other SQL flavours:

```
INSERT INTO "foo" ("a", "b", "c") VALUES (1, 2, 3), (4, 5, 6);
```

The `UNION SELECT` version is [Link: a hack].
- Probably the most robust solution is to create a prepared statement and use that, but that would require `batchInsert()` to call `execute()` itself. That's probably not a change you want to make, right? But if `batchInsert()` is just a convenience function, is there any reason not to include a call to `execute()`? What other possible method could be called after `batchInsert()`? Wrapping both `QueryBuilder()->execute()` would make it easier for each DBMS to use the most efficient methods of mass inserts such as prepared statements.
