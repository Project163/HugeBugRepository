Title

[Connect] When joining a new room, user is not taken to the new room

Description
**Describe the bug**

 
Sometimes when joining a new room, the room that gets displayed to the user is actually a previously joined room and not the room that the user has just joined. This feels unintuitive and might lead to confusion.

**To Reproduce**

 

 
 
 
 

**Expected behavior**

 
Upon joining a new room, the user should always be taken to that room.

**Screenshots**

 
[Image: dev_connect_wrong-room-after-accepting-invite]
Here you can see the room the user wants to join is called "show-and-tell", but upon accepting the invite, the room that displays is one that the user previously joined, called "watercooler".

**Desktop (please complete the following information):**

- OS: Mac
- Browser: Chrome
- Version: 83.0.4103.116
