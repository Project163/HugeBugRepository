Title

`array-bracket-spacing` for empty array

Description
When linting this code:

```
[ ]
```

with this config:

```
{
    "eslintConfig": {
        "rules": {
            "array-bracket-spacing": 1
        }
    }
}
```

I would expect to see an error like:

```
1:1  warning  There should be no space after '['   array-bracket-spacing
```

Instead, there is no warning.

(My `eslint -v`: 1.6.0)
Discussion
- I can confirm this behaviour.
- I think need option for this behavior (empty array).

- Can someone describe what you think the bug is here? 

I think we chose to just not enforce anything for empty arrays, so I'm not sure this is a bug.
- The bug is allowing an empty array with spaces `[ ]` when the default `never` option is set.

The doc doesn't say that is expected behaviour, but just for `always`:
`Note that "always" has a special case where`{}`and`[]`are not considered problems.`

If it is expected behaviour the docs should also reflect that.
