Title

DateIntervalType (negative support)

Description
**DateIntervalType does not support negative intervals**
(http://php.net/manual/en/class.dateinterval.php#dateinterval.props.invert) :cry:

Is this an oversight? 
It's not in a stable version, so it can still be changed. 

Happy to work on a PR.

**N.B.** A while ago, @jaroslavtyc created this functionality by using integers, and a DateInterval library. [URL] We could use the same approach.
