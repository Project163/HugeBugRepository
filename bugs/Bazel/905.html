Title

Native rules cannot correctly set useToolchainTransition

Description
Native rules with multiple parents (eg, [Link: `cc_library`]) cannot correctly set the [Link: `RuleClass.Builder.useToolchainTransition` method]. Each parent rule class will override the previous, instead of combining them.

This is not a problem for Starlark rules, as they cannot have parents at all.
