Title

`SseUtil` unexpectedly stores headers in `Serialisers.EMPTY_MULTI_MAP`

Description
### Describe the bug

The `SseUtil` class is using `Serialisers.EMPTY_MULTI_MAP` variable, here:

[URL]

This leads to storing of subsequent headers in this map `Serialisers.EMPTY_MULTI_MAP`. This leads to uncapped memory consumption, use of the whole available heap (possible DDoS). Also, invocations have access to previously set headers, which is a privacy concern.

### Expected behavior

Sending with `SseUtil` should be safe and not lead to data leaks or DDoS.

### Actual behavior

Sending with `SseUtil` will lead to data leaks or DDoS.

### How to Reproduce?

```java
@GET
@RestStreamElementType(MediaType.APPLICATION_JSON)
Multi  events() {
  return Multi.createFrom().iterable(events);
}
```

See also: [URL]
