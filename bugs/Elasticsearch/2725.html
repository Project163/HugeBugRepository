Title

Autoscaling capacity calculation blocks a transport thread

Description
**Elasticsearch version** (`bin/elasticsearch --version`): seen in 7.13.1 but `master` also affected

**Plugins installed**: [Cloud]

**JVM version** (`java -version`): Bundled

**OS version** (`uname -a` if on a Unix-like system): Cloud

**Description of the problem including expected versus actual behavior**:

In a 100-node cluster with ~23k shards we saw the get-autoscaling-capacity API taking 10-20 seconds to complete its calculations. However this API runs on `SAME`, so while the calculation was ongoing it blocked other network activity on the same worker.
