Title

comma-dangle: Not accurate when last array item is wrapped in parentheses

Description
Using ESLint v1.7.1, the `comma-dangle` rule is not accurate when the last array item has (unnecessary) parentheses. It will always warn when the rule option is set to `"always"` and never warn when the rule option is set to `"never"`.

Examples:

```
/* eslint comma-dangle: [2, "always"] */
[(1),]
```

Expected: No errors
Actual: `2:4  error  Missing trailing comma  comma-dangle`

```
/* eslint comma-dangle: [2, "never"] */
[(1),]
```

Expected: `2:4  error  Unexpected trailing comma  comma-dangle`
Actual: No errors
Discussion
- Yeah, that looks like a bug. Probably confused by the parens.
