Title

Bug: DictVectorizer throws exception for empty/unknown feature dict

Description
The DictVectorizer throws a ValueError when no features in the dict are known instead of returning an empty vector.

```
DictVectorizer(dtype= , separator='=', sparse=True)
... [Log Snipped] ...
    indices = np.frombuffer(indices, dtype=np.int32)
ValueError: offset must be non-negative and smaller than buffer lenth (0)
```
Discussion
- ```
a.transform([])
```

should raise an exception, although the message could be friendlier.

The no-features case is actually a bug in older NumPy versions. `CountVectorizer` contains (or contained, prior to the last refactoring) a workaround that can be applied to `DictVectorizer` as well.
- On current master, the second two return empty arrays, which I think is fine.
The first raises an "invalid shape" in the sparse matrix that is created....
- That sounds good, empty array is what you would expect from a dict with unknown/no features. :)
