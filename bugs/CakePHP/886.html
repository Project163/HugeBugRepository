Title

Possible race-condition while checking `is_dir`

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version:  

### What happened
[URL]
```
        if (!is_dir($dir)) {
            mkdir($dir, 0775, true);
        }
```
As you can see, there is a possibility of a race-condition while checking `is_dir`. This nomenclature exists in other places in the core as well.

### What you expected to happen
It would be better to do something like the following:
`if (!@mkdir($dir, 0775, true) && !is_dir($dir)) { throw... }`
Discussion
- If you're in a high-concurrency environment you should avoid using FileCache, and if that's not possible you should create the directories ahead of time. Multiple operations on the file system are very hard to make atomic in PHP.
- I agree with you, I was just going through the code and decided to raise this up. Thanks!
- Wouldn't that change still help?
