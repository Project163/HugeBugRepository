Title

Cannot run dotnet xunit with NetCoreApp2.1 and dotnet core 2.1 preview1 runtime

Description
Hi,

I'm trying to use the dotnet xunit cli on a test project that has NetCoreApp deps.

Using internal diagnostics, I extracted the lines from the tmp file that's created when dotnet xunit cli discovers the Framework info:

```
TargetFrameworkIdentifier: .NETCoreApp
TargetFrameworkVersion: v2.1
RuntimeFrameworkVersion: 2.1.0-preview1-26216-03
```

An Input string format exception is thrown on the line below because the RuntimeFrameworkVersion doesn't adhere to the dotted notation that `System.Runtime's Version` is expecting.

[URL]

Because of the order of this line and the lines below it, I'm unable to override this behaviour using the FxVersion command line switch.
