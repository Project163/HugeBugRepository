Title

goog.abstractMethod prevents cross-module code motion

Description
Create 2 modules:

Module 1:
var nullMethod = function () {}
window.nullMethod = nullMethod

/** @constructor */
var Class = function () {
}
Class.prototype.x = nullMethod

Module 2:
new Class();

expected result:
cross-module code motion should move Class into module 2.

actual result:
Class stays in module 1. If I change nullMethod to a function literal, the issue goes away.

The problem is that the compiler conservatively assumes that the variable may change, and so won't move the class.
