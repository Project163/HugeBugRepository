Title

[YSQL] Regression: Table with Identifier not found: OBJECT_NOT_FOUND error while alter index

Description
Jira Link: [Link: DB-18567]
### Description

**Version -  -b590**
**Steps -**

1. Create some partition tables, load some data into tables and do DMLs concurrently on these tables
2. Start sample app workload, this creates table bankhistory_bankaccounts. Alter add more columns and create triggers that insert data in these columns while sample app is running
3. create indexes on all tables concurrently
4. drop some of these indexes randomly
5. Alter table -> fails here

Error - `ERROR: Table with identifier   not found: OBJECT_NOT_FOUND`

Minimal repro thanks to @myang2021 -
```
yugabyte=# create table foo(id int, id2 int);
CREATE TABLE
yugabyte=# insert into foo values (1, 1), (2, 2);
INSERT 0 2
yugabyte=# insert into foo values (1, 3), (2, 4);
... [Log Snipped] ...
yugabyte=# insert into foo values (5, 5); -- OBJECT_NOT_FOUND error
ERROR:  Table with identifier   not found: OBJECT_NOT_FOUND
```
