Title

Fix handling of HTTP/2 H2 empty frames in Resteasy Reactive

Description
### Describe the bug

The issue fixed in #27772 is still happening when using Resteasy Reactive.

### Expected behavior

The frames indicate that the client does not have anything more to send and should not be considered as part of the body.

### Actual behavior

The frames indicate that the client does not have anything more to send and an additional byte is appended to the last parameter.
