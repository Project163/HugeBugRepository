Title

Webpack 2 treats 'stats' option inconsistently

Description
**Do you want to request a *feature* or report a *bug*?**

A bug

**What is the current behavior?**

If you have a config like this:

```
module.exports = {
    stats: { modules: false },
    ... other config ...
};
```

... then Webpack 2 completely ignores the `modules: false` setting, and displays modules in stats (which it should not).

However, if you change your config to this:

```
module.exports = [{
    stats: { modules: false },
    ... other config ...
}];
```

... then it correctly honours the `modules: false` setting. I don't think this is by design - you shouldn't have to declare your config as a single-element array just to make it work, should you?

 
 
 

**What is the expected behavior?**

Consistency between `module.exports = { ... };` and `module.exports = [{ ... }];` styles.
