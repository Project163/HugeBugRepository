Title

Empty query_string generates SearchParseException

Description
When executing a query with an empty query_string an org.elasticsearch.search.SearchParseException is raised.

How to reproduce:

```
curl -XPUT localhost:9200/test/test/1 -d '{}'

curl -XPOST [URL] -d '{ 
    "query" : {"query_string":{ query: ""}},
}'
```

Tested with 0.90.5.

Discussion
- Not only empty queries; a query containing only whitespace will fail too.

It's pretty annoying from a logical POV -- empty strings are nothing special, really. Littering the application code with checks for query emptiness/whitespace-only-ness is very ugly and unnatural. 

Should be done on ES side (no query restriction = match all). "400 Bad Request" is not an appropriate response.
