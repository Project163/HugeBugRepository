Title

Alert parameter might not be properly loaded

Description
**Describe the bug**
Creating an alert filter doesn't match alerts as expected when the parameter value is present.

**To Reproduce**
Steps to reproduce the behavior:
1. Using ZAP GUI "Quick Start" tab start an attack on "[URL]
2. Once the attack has completed right click on the cross domain javascript source file inclusion alert and choose create alert filter
3. Make sure scope is set to global (it should default to global)
4. Click the test button and the filter will apply to 0 alerts
5. Clearing the parameter value and click the test button again and it will apply to the alert

**Expected behavior**
Step 4 above should have matched the alert

**Software versions**
 - ZAP: 2.8.0
 - Add-on: Alert filters 9.0.0
 - OS: Ubuntu 18.04
 - Java: openjdk-8-jre (8u222-b10-1ubuntu1~18.04.1)
 - Browser: N/A using traditional spider

**Errors from the zap.log file**
N/A

**Additional context**
[URL] is being hosted on a free app service that can only run for 60 minutes a day.
