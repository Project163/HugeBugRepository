Title

DeepPartial simplification breaks the `.create()` and `.save()` method in certain cases.

Description
## Issue Description

After the `DeepPartial` simplication of #8187, TypeScript is no longer able to match certain situations using the `.create()` and `.save()` functions. Specifically, when we are trying to pass a relation that is nested within a deep partial entity instance which is also an array, it will no longer match the `DeepPartial []` type signature and fail. See example code.


### Steps to Reproduce

 

```
typescript
@Entity()
class Item {
  @PrimaryGeneratedColumn()
  id!: number
... [Log Snipped] ...
  await getRepository(Item).save(myThing.items) // Not OK for the same reason as above.
}
```
