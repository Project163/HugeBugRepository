Title

imports of wasm-bindgen file reports : No loader is configured for ".wasm" files.

Description
### Describe the bug

npm package using any *_bg.wasm does not import.
error looks like: 
```
 'ERROR: No loader is configured for ".wasm" files: ...@dqbd/tiktoken/tiktoken_bg.wasm.'
```

```

}
```
