Title

InvalidProgramException with ProjectTo and nullable ints

Description
### Source/destination types

```
csharp
public class SourceParentTest {
    public SourceChildTest? Child { get; set; }
}

... [Log Snipped] ...
    public int? TestNullableInt { get; set; }
}
```

### Mapping configuration

```csharp
CreateMap ()
    .ForMember(
        a => a.TestNullableInt,
        opt => opt.MapFrom(b => b.Child!.TestInt)
    );
```

### Version: x.y.z
AutoMapper 10.1.0
Microsoft.EntityFrameworkCore.SqlServer 5.0.0-rc.2.*

### Expected behavior

With AutoMapper 10.0.0 and using ProjectTo the mapping is successful with TestNullableInt being null when the Child navigation property is null and otherwise being set to the value of TestInt property from the child entity.

### Actual behavior

A "InvalidProgramException: Common Language Runtime detected an invalid program." is thrown when calling ToListAsync() on the ProjectTo query like this:

```csharp
var test = await _autoMapper.ProjectTo (sourceQuery).ToListAsync();
```
