Title

Not detecting mouse release after alt-tab on windows

Description
# Environment
App: egui_demo_app (+ other egui-based apps)
OS: Windows 11
Git: 0bc59f57

# Describe the bug
1. Open the 'input test' demo.
3. Click and hold `Sense::drag`
4. Move cursor off egui window
5. Alt-tab to a different window
6. Release mouse
7. Alt-tab back to egui window
8. Move cursor around
9. Mouse is erroneously considered pressed, even though it was released
10. Click mouse on egui window to fix state

# Expected
Mouse should be detected as released once it is released. Other native windows apps seem to do this correctly, e.g. ms paint.
