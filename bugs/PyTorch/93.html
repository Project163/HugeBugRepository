Title

INTERNAL ASSERT FAILED in `torch.compile` when the input tensor of `torch.clamp` has `requires_grad=True`

Description
### 🐛 Describe the bug

The following program works fine in eager mode but throws INTERNAL ASSERT FAILED in compile mode. The assertion failure can be triggered if tensors with `requires_grad=True` are used as input.
