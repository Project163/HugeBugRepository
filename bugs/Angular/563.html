Title

Angular 5 compiler can't find the `.css` files next to source `.ts` files

Description

## Current behavior
The build doesn't work with Angular 5. It was working with Angular4.
The issue is that we compile our TS files with the `@angular/compiler-cli`, but it ends up throwing an error that it can’t find the `.css` files next to the source `.ts` files.

Discussion
- The following changes need to be added [URL]

The compiler now validates the modules in compile by generating and type-checking the implied factory files. However, this means that we need to be able to find the referenced '.css' files. Since the '.css' files are generated into `dist` it means we need to know where that is. This is what the addition of `rootDirs` does.

We improved the metadata validation as well but it now reports that `styleTag` is invalid. Since `styleTag` is not intended to be used in a decorator, adding `@dynamic` to its comment silences this error.

Making these changes is not a complete fix as this uncovered a bug in `ngc` that #19770  fixes.
