Title

create data stream REST API spec indicates body is supported, but does not on 8.0.0-SNAPSHOT

Description
Relates: [URL]

The `indices.create_data_stream.json` REST API spec indicates that a body is supported:

[URL]

However, Elasticsearch returns an error to indicate that the API does not support having a body on 8.0.0-SNAPSHOT.

### Steps to reproduce

1. Spin up a default distribution 8.0.0-SNAPSHOT Elasticsearch instance
2. Create a composable index template

```
sh
curl -X PUT "[URL] -u elastic:changeme \
-H 'Content-Type: application/json' -k -d'
{
  "index_patterns": [ "logs*" ],
... [Log Snipped] ...
  }
}
```

3. Create a data stream with an empty object body

```sh
curl -X PUT "[URL] -k -u elastic:changeme \
-H 'Content-Type: application/json' -d '{}'
```

4. Observe the following error is returned

```
json
{
  "error" : {
    "root_cause" : [
      {
... [Log Snipped] ...
  "status" : 400
}
```

### Possible solution

Remove the `body` property from the `indices.create_data_stream.json` REST API spec. 

Official language clients use this property to determine whether the generated implementation should expose a way to set a request body for an API, or, if the client models an API request with a type, whether the type should be serialized to the request stream.

Note that 7.9.0-SNAPSHOT does not return an error when sent `{}` in the request body.
