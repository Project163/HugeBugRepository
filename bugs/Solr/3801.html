 The only explanation is that  interrupt()  can not unpark that Jetty thread. A guy in a pub told me that  it might happen . 
So, if I set  @ThreadLeakLingering(linger = 80000)  it keeps  beast  happy thousand times on this test. 

 My proposal is to set  lingering time above 1 min  for all Solr tests and for Lucene ones which hit the same issue. Opinions?
- I also checked  the hint  about StatsHandler for Jetty. I didn't make any significant difference to the beast.
