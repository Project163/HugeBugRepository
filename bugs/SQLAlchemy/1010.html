Title

Cannot query Redshift in 1.4.0b1

Description
**Describe the bug**
When trying to run a simple `SELECT *` against my Redshift database, I receive the following error:

`UndefinedObject: unrecognized configuration parameter "standard_conforming_strings"`

This issue only happens with SQLAlchemy 1.4.0b1. Rolling back to 1.3.20 allows the query to run successfully. 


**Expected behavior**
Expect the query to run successfully and the results to be loaded into a DataFrame.

**To Reproduce**
```py
import os
import pandas as pd
from sqlalchemy import create_engine, pool
connection_string = os.environ['DATA_WAREHOUSE_CONNECTION_STRING']  # this contains my connection secrets in my .env
redshift_connector_obj = create_engine(connection_string, echo=False, poolclass=pool.NullPool)
query_results = pd.read_sql("select * from my_schema.my_table limit 10", redshift_connector_obj)
```
