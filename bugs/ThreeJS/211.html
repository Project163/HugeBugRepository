Your findings made it much easier to finally reproduce this issue in a small test case. The idea is to create two keyframe tracks animating the same property (e.g. `Object3D.position`) and then create for each track a clip. Uncaching a mesh while both animations are playbacked produces the issue. After some debugging, I'm sure this is the same root cause for #22036.

 A missing statement in `AnimationMixer._bindAction()` produces a wrong reference count which potentially breaks `_removeInactiveBindingsForAction()`. It breaks because multiple actions share the same `PropertyMixer` (binding) but the code did not account for this particular use case and thus did not raise the reference count. Your PR fixes the issue.
