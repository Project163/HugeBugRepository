Title

MariaDB default expression on date and time columns

Description
### What steps will reproduce the problem?

Create table in MariaDB 10.2+ with `date` or `time` column set with `DEFAULT current_timestamp()`.

### What is the expected result?

Column's schema recognizes default value as an expression.

### What do you get instead?

Column's schema says default value is a simple string.
