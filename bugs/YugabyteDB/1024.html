Title

[DocDB] TSAN race in PgRangePartitionedTableSplit.* tests

Description
Jira Link: [Link: DB-7822]
### Description

The following tests may fail in tsan build:
```
PgRangePartitionedTableSplitTest.SelectMiddleRangeAfterManualSplit
PgRangePartitionedTableSplitTest.SelectMinMaxAfterSplit
PgRangePartitionedTableSplitTest.SelectRangeAfterManualSplit
PgTabletSplitTest/PgPartitioning.PgGatePartitionsListAfterSplit/kHash
PgTabletSplitTest/PgPartitioning.PgGatePartitionsListAfterSplit/kRange
PgTabletSplitTest/PgPartitioningVersionTest.UniqueIndexRowsPersistenceAfterManualSplit/1
```
They started failing because they were enabled in the context of #18642 and were disabled before that commit. So, they already have some tsan inconsistence that should be fixed.
