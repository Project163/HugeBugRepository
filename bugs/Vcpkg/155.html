Title

How do I turn off the message "Warning: passed --sendmetrics, but metrics are disabled."

Description
- I search through the vcpkg.cpp code.
- I did not see a vcpkg documentation md file updated with the PR/commit
- Prior to commit of this PR [URL] [vcpkg] Use a tag file rather than conditional compilation to permanently disable metrics. (#15470)
   - One could bootstrap vcpkg with option `-disableMetrics` or set the environment variable  `VCPKG_DISABLE_METRICS=true` and all was fine.
   - Now no matter what `vcpkg` command I put in the message: `Warning: passed --sendmetrics, but metrics are disabled.` appears.
  - The only way I can find to stop the message is to add the command line option `--no-sendmetrics` which is unfriendly user experience method as you have to type it in on every command issuance of `vcpkg`.
- I am asking, is there another way to disable the message with every issuance of `vcpkg` on the command line?
- Otherwise there will need to be more customization to comment out these lines in `vcpkg.cpp`:
