Title

Doc: "Usage Scenarios" refers to deprecated methods

Description
The  Usage Scenarios  describe how to add argument options like this: 
  
 
Option logfile   = OptionBuilder.withArgName(  "file"  )
                                .hasArg()
                                .withDescription(   "use given file  for  log"  )
                                .create(  "logfile"  );
 
  
 OptionBuilder has been deprecated. From what I can tell, the new way to do it is this: 
  
 
  Option logfile = Option.builder( "logfile" )
      .argName( "file" )
      .hasArg()
      .desc( "use given file  for  log" )
      .build();
