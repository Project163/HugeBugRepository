Title

Chain with subtask which are not registered raises NotImplementedError: Tasks must define the run method.

Description
See the following example:

celery_app.py:

```
python
from celery import Celery, chain, subtask

celery = Celery('tasks', broker='redis://localhost/0', backend='redis://localhost/0')

... [Log Snipped] ...
g = chain(subtask("worker.add", (2, 2)) | subtask("worker.sub", (1, )))
print g().get()
```

celery_worker.py:

```
python
from celery import Celery

celery = Celery('tasks', broker='redis://localhost/0', backend='redis://localhost/0')

... [Log Snipped] ...
def sub(result, x):
    return result - x
```

Start the worker with:

``` bash
# celery worker -A celery_worker 
```

When the task is called:

```
bash
# python celery_app.py                                                                                                                              
Traceback (most recent call last):
  File "celery_app.py", line 16, in  
    print g().get()
... [Log Snipped] ...
    raise result
NotImplementedError: Tasks must define the run method.
```

Uncommenting these lines on celery_app.py:

``` python
#@celery.task(name="worker.add")
#def add(a, b):
#    pass
#
#@celery.task(name="worker.sub")
#def sub(result):
#    pass
```

Solves the problem. The run method on the task is correctly created and everything works as expected.

This is the same problem as described here:
[URL]

I've tested with celery 3.0.24 and the problem persists.
