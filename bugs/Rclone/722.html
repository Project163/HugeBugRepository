Title

rclone sync creates a directory named ".." when destination path contains /../

Description
**What is the problem you are having with rclone?**

If you launch the command;
`rclone sync    /parentDir/../ 
`
so a synchronisation on a local machine from a local directory to another local directory, it will create a directory named ".." in parentDir instead of going one directory up.

**What is your rclone version (output from rclone version)**

All versions >= 1.50 (it works in 1.49)

**Which OS you are using and how many bits (e.g. Windows 7, 64 bit)**

Windows 11 Pro 21H2  (arch: amd64) and macOS 12.6 (arch: arm64)

**Which cloud storage system are you using? (e.g. Google Drive)**

Local filesystem

**The command you were trying to run (e.g. rclone copy /tmp remote:tmp)**

`rclone sync XXX XXX/../XXX
`
