Title

Rake tasks accidentally removed instead of deprecated (db:structure:load_if_sql & db:schema:load_if_ruby)

Description
In #39470, these two tasks were accidentally removed instead of deprecated. I'm proposing that in the short term, we bring them back with a deprecation. In the long term I would like to preserve them as a consistent interface but possibly make them a "silent" option by not including a task description:

Last release of Rails:

```
$ rails -v
Rails  
$ be rake -P | grep load_if
rake db:schema:load_if_ruby
    db:schema:load_if_ruby
    db:structure:load_if_sql
rake db:structure:load_if_sql
```

Rc release of Rails:

```
$ rails -v
Rails 6.1.0.rc1
$ be rake -P | grep load_if
```
