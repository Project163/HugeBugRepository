Title

[YCQL] ALTER TABLE resets table properties like `is_transactional_`.

Description
```
ycqlsh:a> create table t (h int primary key) with transactions={'enabled':'true'};
ycqlsh:a> desc t;

CREATE TABLE a.t (
    h int PRIMARY KEY
... [Log Snipped] ...
) WITH default_time_to_live = 10
    AND transactions = {'enabled': 'false'};   <<<<<<<<< ERROR! NON-TRANSACTIONAL.
```
Discussion
- Due to the bug any YCQL ALTER TABLE can drop the following table properties into default values:
```
  bool is_transactional_ = false;
  bool retain_delete_markers_ = false;
  YBConsistencyLevel consistency_level_ = YBConsistencyLevel::STRONG;
  bool use_mangled_column_name_ = false;
  bool is_ysql_catalog_table_ = false;
```
The root cause (`src/yb/yql/cql/ql/exec/executor.cc`):
```
Status Executor::ExecPTNode(const PTAlterTable *tnode) {
...
   TableProperties table_properties;      ToTableProperties(&table_properties);    SetTableProperties(table_properties); 
```
