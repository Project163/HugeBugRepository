Title

[YSQL] Prevent concurrent backfill on same table

Description
`MultiStageAlterTable::StartBackfillingData` makes sure that the indexed table is not already backfilling.  YSQL `CatalogManager::BackfillIndex` skips that and directly creates a `BackfillTable` object.  It is then hypothetically possible to have multiple backfills on the same table.  I imagine this can happen by two `CREATE INDEX` requests on the same table getting to the backfill request at the same time, but given that there are issues in starting those two `CREATE INDEX`es (issue #6269), I don't see this being a likely occurrence.
