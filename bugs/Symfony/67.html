Title

[HttpKernel] HInclude FragmentRenderer broken

Description
The change of a the visbility of the property `$templating` from `protected` to `private` in [URL] breaks the subclass `ContainerAwareHIncludeFragmentRenderer` at [URL]

```
if (!$this->templating) {
    $this->setTemplating($this->container->get('templating'));
}
```

The hinclude-fragment-renderer is not useable anymore.
