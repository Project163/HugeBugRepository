Title

Cant't mount text node components

Description
Cant't mount text node components in a child window in **IE11** and **Edge**.

[URL]

```
jsx
const SomeComponent = () => (
   
     This will be displayed 
     
... [Log Snipped] ...
   
), container);
```

It throws the following error: `SCRIPT87: Invalid argument.`

Debugging the stack trace I've noticed that the fragment creation (`ownerDocument.createDocumentFragment()`, line 7923, `react-dom.js`) is resulting in a malformed fragment. Later, when trying to append this "malformed" fragment to the DOM (`parentNode.insertBefore(tree.node, referenceNode)`, line 1623, `react-dom.js`), it fails and throws that error.

I tried to replace the fragment by a span element for this specific case (IE11 and child window) and it worked. Could this be a solution?
Discussion
- Tagging this as a bug although not sure if it's on our side or not. Still needs someone to investigate.
- @gaearon after digging into this a bit more, I found that it is due to Edge / IE does not work with documentFragment append when working with children window. As for the reason for this, I don't know... but if React can provide a workaround for these browsers, it would be nice :)
- I'm working a fix for this...
- Quick update here on this bug: I've found the root cause for React 15 AND 16. I created a PR for master against the unused 15 APIs, so I closed that one. I created a new PR for the 16 fiber reconciler code instead.
