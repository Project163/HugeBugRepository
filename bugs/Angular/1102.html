### Description
ngcc timeout does not stop the execution and the process will run infinitely. I have seen this behavior on our CI, where the build runs since 3 days.
The error occurs if there are multiple ng builds in parallel.

## 🔬 Minimal Reproduction
1. run a long running ngcc process
2. run another ngcc process which would run into the 25 seconds timeout.
