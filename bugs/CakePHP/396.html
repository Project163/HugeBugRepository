Title

Checkbox's hidden field missing form attribute

Description
this code:

```
 Form->input('Model.field', array('form'=>'FormId')); ?>
```

outputs this html

```
 
   
   
   Field 
 
```

form="FormId" is not included as an attribute of the hidden field.  the form attribute is used to associate inputs not included inside the    tags with the form.  because the hidden field does not include the attribute, it is not submitted with the form, and the 0 value is never saved.
