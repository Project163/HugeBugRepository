Title

Illegal return statement

Description
Although not valid in browser land, this is valid in node because the way the require system works.  A module can have 'return' statement to short circuit processing.  This doesn't throw an error in JSHint but does in ESLint.

``` js
if (!module.parent) return
```

Output:

```
1:27  error  Illegal return statement
```
Discussion
- This is the behavior of Esprima, so we would need to get it fixed there.
