Title

Misleading error log message when failing to bind to a port

Description
### Describe the bug

With this setup:
```
application.properties:  quarkus.http.host=macbook
/etc/hosts:   macbook macbook-admin ...
```

and   being unreachable, Quarkus fails to start and logs this message:

`Caused by: io.quarkus.runtime.QuarkusBindException: Port(s) already bound: 8089: Can't assign requested address`

This is misleading, and a serious time waster when you forgot to adjust /etc/hosts after moving from one network to another.

### Expected behavior

The log message should clearly indicate that the interface doesn't exist.

### How to Reproduce?

Set quarkus.http.host to a dns name that resolves to an unreachable network address.

### Quarkus version or git rev

3.19.2

### Build tool (ie. output of `mvnw --version` or `gradlew --version`)

Not relevant
