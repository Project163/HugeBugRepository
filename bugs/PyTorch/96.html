Title

`torch.compile` crash when indexing an empty tensor by using `tensor[[0]]`

Description
### 🐛 Describe the bug

`torch.compile` crash when indexing an empty tensor by using `tensor[[0]]`


```
py
import torch

a = torch.tensor([])

... [Log Snipped] ...
torch.compile(func)(a)
# segmentation fault (core dumped)
```
