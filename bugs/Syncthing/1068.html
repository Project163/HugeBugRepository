Title

assignment copies lock value to igd: IGDService contains Service (with sync.RWMutex)

Description
### What happened?

**What happened**  
The function `discover` returns a slice of `IGDService` structs.  
`IGDService` contains a `nat.Service`, which contains a `sync.RWMutex`.  
Iterating over the slice with `for _, igd := range igds` copies the structure, including the RWMutex.  
Go linters (e.g., `go vet`) report:  
`assignment copies lock value to igd: IGDService contains Service with sync.RWMutex`.  

**What I expected instead**  
To avoid copying the mutex, the function could return `[]*IGDService` instead of `[]IGDService`.

**Environment**  
- Syncthing version: v2.0.10
- OS: Linux x86_64

**Additional info**  
All existing tests pass with the proposed change.
