- I can't repro this issue locally, please provide more repro codes, like `main.cc`.

If you need to change the order of the link library under linux, I changed `crashpadConfig.cmake`
unadorned
```
set(CRASHPAD_LIBRARIES client util base common )
```
After modification
```
set(CRASHPAD_LIBRARIES common client util base),
```
And it compiled successfully
