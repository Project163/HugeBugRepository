Title

sub-tabbedPane in swingbuilder missing title

Description
I found that the sub-tabbedPane can not have a title, the test code is shown as follows: 

  
  import  groovy.swing.*

def swing =  new  SwingBuilder()
def frame = swing.frame() {

    tabbedPane() {
        label(text: 'a' , title: 'ta' )
        tabbedPane() {
            label(text: 'sa' , title: 'sta' )  // the title named sta does not show :(
             label(text: 'sb' , title: 'stb' )  // the title named stb does not show, too :(
         }
    }
}

frame.pack()
frame.show()
Discussion

    tabbedPane() {

        }
    }

frame.pack()

- The attached patch is not a real solution to the problem but may be a hint to what is really going wrong.  I am not sure why the inspectChild method in TabbedPaneFactory is being called twice for each child, but it is.  The second time inspectChild is called, the title attribute is not there.  This patch simply ignores the second call for each child and that makes the symptom go away.   

 Why is inspectChild being called twice for each child?
- Ultimately inspectChild was being called for children that didn't belong to that tab.  So now I am adding a bumper to insure that the particular closure instance is it is only called for children of that node, not for all such nodes.
