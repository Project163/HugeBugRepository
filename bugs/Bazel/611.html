Title

useless "remote" summary information

Description
Since  , Bazel builds end with a line like this:
```
Elapsed time: 636.182s, Critical Path: 162.75s, Remote (0.00% of the time): [queue: 0.00%, setup: 0.00%, process: 0.00%]
```
The "remote" numbers at the end are always zero. AFAICT, `AggregatedCriticalPath` is never instantiated with non-`EMPTY` `SpawnMetrics`.
