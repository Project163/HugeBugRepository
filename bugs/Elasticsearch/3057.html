Title

[Enrich] Improve error returned when data stream targeted as index

Description
### Description

If a datastream is targeted by a enrich policy like the following:

```
PUT /_enrich/policy/my-policy
{
  "match": {
    "indices": ["data_stream"],
    "match_field": "fieldA",
    "enrich_fields": ["fieldB", "fieldC"]
  }
}
```

then an error like the following is returned:

```
json
{
  "error": {
    "root_cause": [
      {
... [Log Snipped] ...
  "status": 404
}
```

Other that decypher the combination of `"reason": "no such index [data_stream]"` and `"excluded_ds": "true"` it's not easy to understand that data streams are not supported. Also the documentation does not mention anything about data streams as well.

It would be nice to have a better error message in this case that explains that the provided `index` is a data stream and is not supported.
