Title

metadata.log.dir failure shouldn't shutdown broker in ZK mode

Description
ReplicaManager::handleLogDirFailure  shuts down the broker if the directory that has failed is the same as  config.metadataLogDir   [0] . If unset, it defaults to the first log directory configured even in ZK mode. 

 The check should be amended to ensure the broker is either in Migration mode or Kraft mode and the broker shouldn't shut down when running in ZK mode.
