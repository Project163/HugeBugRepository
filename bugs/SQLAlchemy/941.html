Title

Tests fail for SQLite file database but not for memory database

Description
Tests against a SQLite memory database (as performed by the current CI setup) pass, but those same tests against a persistent (file-based) SQLite database fail.

## The Big Picture

Memory database:

```
(venv) PS C:\Users\Gord\git\sqla-gerrit> pytest -n4 --dburi=sqlite:///:memory: | tee memory_db.txt

...

=============== 10105 passed, 1283 skipped in 194.22s (0:03:14) ===============
```

Persistent database:

```
(venv) PS C:\Users\Gord\git\sqla-gerrit> pytest -n4 --dburi=sqlite:///C:/Users/Gord/git/sqla-gerrit/sqla_test.sqlite | tee file_db.txt

===== 7 failed, 3318 passed, 206 skipped, 18 errors in 3115.51s (0:51:55) =====
```
