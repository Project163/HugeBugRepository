Title

index back ticks when length is specified.

Description
Create a fixture with the following:

```
'url_slug' => array('column' => array('url_slug(150)', 'website_code'), 'unique' => 1),
```

So the index for `url_slug` only uses 150 chars.

Cake renders it as

```
UNIQUE KEY `url_slug` (url_slug(`150`), `website_code`),
```

The length is quoted with back ticks, this should not happen. it should be quoted as 

```
`url_slug`(150)
```

Quoting it manually does work fine

latest 2.x branch
Discussion
- You should be using the `length` property to define a length on indexes.

``` php
'url_slug' => array('column' => array('url_slug', 'website_code'), 'length' => array('url_slug' => 150), 'unique' => true);
```
