## Current behavior
Binding to `[innerHTML]` causes the server to render the html content in both the `innerHTML` property and in the element body.

```html
  
```

produces

```html
 content 
```

## Expected behavior
The `innerHTML` property in the rendered HTML is not needed as far as I can tell. I added code to my project to remove it after Angular renders the page. Everything seems to work fine, and the HTML payload is much smaller.

## Minimal reproduction of the problem with instructions
See above.

## What is the motivation / use case for changing the behavior?
The rendered HTML payload is bloated with the duplicate content.
