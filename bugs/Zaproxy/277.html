Title

mozilla.net appears in the report even though excluded with globalexcludeurl.url_list.url.regex

Description
**Describe the bug**
Trying to use API scan against and API I get mozilla.net urls in the report, even though it's excluded. Note: Even after running with `-d` I am not able to find anything that leads to mozilla.net, so what I don't understand is why it ends up in the XML report. I also tried a bunch of different regexes and all appear to be ignored.

**To Reproduce**
Steps to reproduce the behavior:
1. Run the owasp/zap2docker-stable image with `-z "-config globalexcludeurl.url_list.url.regex='https?:\/\/.*mozilla\.net\/.*'"`
2. Wait for it to complete
3. Scroll down to logs and cat report file.
4. See mozilla.net included in zap.log section below

**Expected behavior**
The mozilla.net urls should not be included in the report at all.
