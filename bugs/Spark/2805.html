Title

Branch 1.6's hadoop 2.2 tests always fail the entire VersionsSuite

Description
Right now, we hardcoded hadoop 2.4 to download when we need to download hive and hadoop jars for metadata hive. However,   SPARK-9596   makes isoalted client loader share hadoop classes. So, if there is any compatibility issues between the shared hadoop and hadoop 2.4, VersionsSuite will failed. Actually, in spark 1.6's hadoop 2.2 tests, VersionsSuite always fail ( [URL] Because  HftpFileSystem  has been moved to a new location in Hadoop 2.3+. From Hadoop 2.4, we get  org.apache.hadoop.hdfs.web.HftpFileSystem . But, when we look up the class (by looking at hadoop 2.2's jars), it is not in this location.
