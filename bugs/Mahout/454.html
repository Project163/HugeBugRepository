Title

classify-20newsgroups.sh fails during the seqdirectory step

Description
classify-20newsgroups.sh fails during the seqdirectory step as it fails to overwrite the output folder. 

  
 
Exception in thread  "main"  org.apache.hadoop.mapred.FileAlreadyExistsException: Output directory /tmp/mahout-work-jenkins/20news-seq already exists
Discussion
- This issue is only seen when running with Complimentary Naive Bayes or Naive Bayes options. 

 seqdirectory now executes as a MapReduce job (in light of the changes in Mahout-833) unless the sequential option is explicitly specified.   

 classify-20newsgroups.sh creates 20new-seq/ directory on the first run, but subsequent runs fail as the directory already exists from the previous runs. 

 The fix was to specify --overwrite flag when invoking seqdirectory.
