Discussion
- I have also been experiencing this issue.
- The depth bias is only ignored with opaque meshes. It still works with meshes using alpha blending. The reason it doesn't work anymore is because the depth bias is only applied when sorting the mesh based on the distance to the camera but bevy doesn't sort opaque meshes anymore.

A fix for this would probably need to involve passing it to the vertex shader and applying the bias inside the vertex shader.
