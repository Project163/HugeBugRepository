Title

Add jaxb-core, istack, ... for runtimeConfigurationPlugin without broker started

Description
In order to work with any JDK version (JDK8, JDK9, JDK11+), and avoid classloading issue, the runtimeConfigurationPlugin needs jaxb-core and itstack-commons-runtime in the classloader. This is especially required with broker start attribute is false.
