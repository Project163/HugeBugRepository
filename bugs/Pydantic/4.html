Title

Failed to create schema with optional fields

Description
Just tried to use schema creation and it's awesome, but I found, I think, bug with optional fields.

Here is my model:
```
from typing import Optional
from pydantic import BaseModel

class TestModel(BaseModel):
    foo: Optional[int] = None

print(TestModel.schema_json(indent=2))
```

Output:

Same issue with `Union`:
```
from typing import Union
from pydantic import BaseModel

class TestModel(BaseModel):
    foo: Union[str, int]

print(TestModel.schema_json(indent=2))
```

I think `pydantic` should cover cases like this, I don't know what is the best way to solve issue with `Optional`, but in case of `Union` `oneOf` or `anyOf` rule can be used [URL]
