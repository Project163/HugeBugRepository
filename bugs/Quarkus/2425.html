Title

quarkus-grpc provides insufficient reachability metadata for enum

Description
### Describe the bug

When trying to call `toString()` on a generated proto message, a `IllegalStateException` is thrown, if any of these conditions are true
 
- The message contains an enum (locally defined or imported)
- The message contains anything from `protobuf-java` (such as `com.google.protobuf.Timestamp`)

### Expected behavior

Calling `toString` on a generated proto class should not throw exceptions. Implicit calls, such as passing the proto to a logger, should neither throw.

### Actual behavior

Exception, if calling `toString` on generated class containing Enum:
