Title

Ignite doc: Wrong use of setValueFields function in CacheJdbcPojoStore demo

Description
The following page of documentation provides an example of configuring CacheJdbcPojoStore  [URL]
In particular, it suggest to set value fields as follows: 
  
 
...
    personType.setValueFields( new  JdbcTypeField(java.sql.Types.INTEGER,  "id" ,  Integer .class,  "id" ));
    personType.setValueFields( new  JdbcTypeField(java.sql.Types.VARCHAR,  "name" ,  String .class,  "name" ));
...
 
  
 The code above looks incorrect just because the second method call will be taken into account and overrides the previous one. 

 The example should be corrected: 
  
 
...
    personType.setValueFields(
         new  JdbcTypeField(java.sql.Types.INTEGER,  "id" ,  Integer .class,  "id" ), 
         new  JdbcTypeField(java.sql.Types.VARCHAR,  "name" ,  String .class,  "name" ));
...
