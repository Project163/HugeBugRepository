Title

texualselect regressions due to change in how TextualSelect is treated in the compiler

Description
### Describe the bug

When compiling the `sqlalchemy.dialects.postgresql.Insert` statement with a `select_from(text("SELECT ..."))` (_cf._ MVCE below) and the `.on_conflict_do_update()` method to add the , the compilation fails with the error (_cf._ stacktrace below)

```
python
from sqlalchemy import Column, Integer, MetaData, Table, Text, text
from sqlalchemy.dialects.postgresql import dialect as pg_dialect, Insert

meta = MetaData()
```

### Versions

### Additional context

The fix is pretty simple: instead of using `insert_statement.table.c` one has to use `insert_statement.selected_columns`. Though I guess this would require the addition of non-regression test for the future. Hopefully, one can be derived from the above example.
