Title

Possible Regression on 5.0A3 for string to text conversion

Description
**Elasticsearch version**: 
5.0 A3

**JVM version**: 
1.8.0_91

**OS version**:
CentOS 7

**Description of the problem including expected versus actual behavior**:
On 5.0 A2 the automatic upgrade [URL] was working fine for a mapped string using an analyzer (Path Hierarchy Tokenizer), after upgrade to 5.0 A3 it didn't work, so I think we have a regression at that point.

**Steps to reproduce**:
1. Define an analyser for a path_hierarchy

"analyzer": {
        "paths": {
          "tokenizer": "path_hierarchy"
        }
1. Set it for an analyzed string on mapping
