Title

When a SolrCore registers in zk there may be stale leader state in the clusterstate.json.

Description
This can be a problem when stop the whole cluster and then start it - a leader that has not yet showed up in the cluster state may see a stale leader and try to recover from it.
Discussion
- a workaround - on registering, instead of getting the leader from the cluster state, we go right to the ephemeral zk node
- I've committed this work around, but need to consider if there is anything more we should try to do.
- This is good for now - works - any improvement can go to another issue.
