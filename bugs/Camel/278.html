Title

Allow '@' in usernames.

Description
Many servers use 'username'@'servername' as a login name. Camel-mail doesn't allow this.
Discussion
- It does allow it. Try to upgrade to 1.4. 
This works for me: 

 String smtpUri =  
			 "smtp://mail.server.com?username=freeforall@server.com&password=freeforall" + 
			 "&From=freeforall@server.com&To=otheruser@server.com";
- I use camel 1.4 and javax.mail 1.4.1.
