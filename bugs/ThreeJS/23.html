Title

Render-To-Texture Example Renders Upside-Down

Description
The render-to-texture example ( [URL] ) renders upside down. The smaller ring should be on the top, and the 4 colored quads are flipped vertically.
Discussion
- Yup, this is a trouble with render targets, they are flipped compared to image based textures.

Now everything else in the lib is made to look ok with images, which means render targets look wrong (even while these are the ones which are technically correct).

One possible workaround is to flip UVs for objects which use such generated textures.
- Yep, as I mention [Link: here] this is a long standing issue we haven't been able to nail nicely yet.

As far as I understand, the problem is that `UNPACK_FLIP_Y_WEBGL` didn't seem to be well supported back when we were trying to implement this, so sometimes loaded textures weren't being flipped. So the solution was to invert the V in all the geometries.

I don't know how's the support nowadays, but would be good to remove this hack eventually.
