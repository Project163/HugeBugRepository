Title

ContainsConstraint break when used with AndConstraint

Description
3.0 Alpha3

Given a constraint: Does.StartWith ("Could not load").And.Contains (MISSING_FILE)

AndConstraint has the following code:

```
public override ConstraintResult ApplyTo (TActual actual)
    {
        var leftResult = Left.ApplyTo(actual);
        var rightResult = leftResult.IsSuccess
            ? Right.ApplyTo(actual)
... [Log Snipped] ...
        return new AndConstraintResult(this, actual, leftResult, rightResult);
    }
```

if leftResult.IsSuccess is false, then the Right.ApplyTo is never called.  However, ContainsConstraint requires that its ApplyTo method be called to properly initialize its _realConstraint field.  Since it is not being called, the ConstraintResult constructor fails when trying to access Right.Description, which refers to the uninitialized _realConstraint field.
