Title

Error on loading win32-ffi-extensions on Windows

Description
### Vagrant version
2.0.4.dev

### Host operating system
Windows 7 

### Expected behavior
I expected to see the vagrant standard output

### Actual behavior
I got an error saying 
`/vagrant/lib/vagrant.rb:70:in 'require': cannot load such file -- win32-ffi-extensions (LoadError)`

### Steps to reproduce
1. Install vagrant from source on windows
2. run `bundler exec vagrant`

### Fix:
When I edited the `lib/vagrant.rb` and changed `win32-ffi-extensions` to `ffi-win32-extensions` everything worked normally again.
