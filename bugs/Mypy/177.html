```
from typing import Iterator, TypeVar, Callable, Tuple, Any
```

Discussion
- Smaller test case:

``` python
from typing import Iterator, TypeVar, Callable, Any

X = TypeVar('X')

def f(x: Callable[[X], Any]) -> Iterator[X]: pass
def g(x: Iterator[X]) -> X: pass
bax = g(f(lambda x: x))
```
- Even more reduced:

