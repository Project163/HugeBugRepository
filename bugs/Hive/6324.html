Title

Vectorization: Suppress known Q file bugs

Description
There are known bugs recently found and reported that occur when vectorization is turn on in Q files.  Until those bugs are fixed, add SET statements to the top of the Q files that suppress vectorization. 

 Change a few EXPLAIN VECTORIZATION to EXPLAIN where it isn't needed and creates an unnecessary Q file difference during enable by default experiments.
