Title

check-env for aio should not fail if the check-env for the main angular project fails

Description
repro:
- clone repo
- `cd angular/aio`
- `yarn install`
- `yarn start`

expected result:
- dev server starts

actual result:
- dev server fails to start because `yarn check-env` fails

This failure is because we didn't install npm dependencies in the main project - this error is however irrelevant to what we are trying to do and those dependencies are not at all required for the aio build to work, so we should not require them.
