Title

DefaultParser.parse() throws NullPointerException when options parameter is null

Description
The DefaultParser.parse() method throws a NullPointerException when the options parameter is null. 

 Steps to reproduce: 
1. Create a DefaultParser instance 
2. Call parse() with null options parameter: Eg.:  
  
 
defaultParser0.parse((Options)  null , stringArray0, getBooleanJazzer()); 
  
 3. NPE is thrown at line DefaultParser.java:708:  
  
 
expectedOpts =  new  ArrayList<>(options.getRequiredOptions()); 
  
   

   

 Expected behavior: The method should validate input parameters and throw a meaningful IllegalArgumentException with a descriptive message.
Discussion
- Hello  leofernandesmo   

 Thank you for your report. 

 If you use a recent version of Java, you get: 
  
 java.lang.NullPointerException: Cannot invoke "org.apache.commons.cli.Options.getRequiredOptions()" because "options" is null
	at org.apache.commons.cli.DefaultParser.parse(DefaultParser.java:747)
        ...
  
  
 Which is the most precise exception and message you'll receive from Java. 

 Nevertheless, we can make this a touch better using Java's  Objects.requireNonNull()  to fail faster with a message specific to the argument. The exception is still an NPE, the most precise for this case.
