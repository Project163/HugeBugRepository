Title

3.0 - PDOException is thrown when paginating with hasMany or belongsToMany relationships in empty pages.

Description
When paginating a model with `hasMany`or `belongsToMany` relationships, a `PDOException` is thrown when trying to see a non existent page.

If the primary model is not related or has other type of relationships the classic 404 exception is thrown.
