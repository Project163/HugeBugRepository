Title

[DocDB] The yb-tserver crash is due to a segmentation fault caused by an invalid memory access during a hybrid scan.

Description
Jira Link: [Link: DB-19134]
### Description

Starting from  -b40, the INDG12_1_index_scan_hash_skey_point_select workload on colocated tables+PG parity has been failing on master.  The issue appears to be introduced by the change when running on colocated tables with pgparity flags set - [Link: [#28439] DocDB: Use bloom filter when user specified multiple keys]

The yb-tserver crash is due to a segmentation fault caused by an invalid memory access during a hybrid scan. The issue originates in` yb::docdb::HybridScanChoices::UpdateUpperBound()`

Parallel worker was running during the crash
