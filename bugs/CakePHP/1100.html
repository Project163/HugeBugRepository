Title

Handle invalid cookies in Cake\Http\Cookie\CookieCollection::createFromHeader()

Description
### Description

Issue happens with `Cake\Http\Cookie\CookieCollection::createFromHeader()` after adding parameter types in `Cake\Http\Cookie\Cookie::__construct()`.

Following try/catch does not work:
```
try {
--
 $cookies[] = Cookie::createFromHeaderString($value, $defaults);
 } catch (Exception $e) {
 // Don't blow up on invalid cookies
}
```
Because instead of exception, sometimes there is TypeError

Code to reproduce this issue:
```
\Cake\Http\Cookie\CookieCollection::createFromHeader([
  'id= ; Path=/; Expires=Tue, 17 May 2022 22:19:06 GMT; Secure=true; SameSite=none'
])
```
It produces folowing
[`TypeError] Argument 6 passed to Cake\Http\Cookie\Cookie::__construct() must be of the type bool or null, string given`

Please fix this in 4.2/4.3 if possible


### CakePHP Version

4.3

### PHP Version

7
