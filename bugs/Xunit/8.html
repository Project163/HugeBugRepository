Title

MSBuild runner: source line information not always present

Description
If the top of the stack trace doesn't have line number information (f.e., if it's the .NET framework), then the MSBuild runner shows the source/line of the MSBuild file instead of the source file. The stack trace finder should keep search stack frames until it finds one with source information.

Broken example:

```
D:\Dev\xunit\xunit\tools\xunit.tests.msbuild(26,5): error : FixtureAcceptanceTests+ClassFixture.TestClassWithExtraArgumentToConstructorResultsInFailedTest: System.InvalidOperationException : Sequence contains more than one element
D:\Dev\xunit\xunit\tools\xunit.tests.msbuild(26,5): error :    at System.Linq.Enumerable.Single[Link: TSource]
D:\Dev\xunit\xunit\tools\xunit.tests.msbuild(26,5): error :    at FixtureAcceptanceTests.ClassFixture.TestClassWithExtraArgumentToConstructorResultsInFailedTest() in d:\Dev\xunit\xunit\test\test.xunit.execution\Acceptance\FixtureAcceptanceTests.cs:line 76
```

Non-broken example:

```
d:\Dev\xunit\xunit\test\test.xunit.execution\Acceptance\FixtureAcceptanceTests.cs(16): error : FixtureAcceptanceTests+Constructors.TestClassMustHaveSinglePublicConstructor: Assert.Collection() Failure\r\nExpected item count: 20\r\nActual item count:   24 [D:\Dev\xunit\xunit\tools\xunit.tests.msbuild]
d:\Dev\xunit\xunit\test\test.xunit.execution\Acceptance\FixtureAcceptanceTests.cs(16): error :    at FixtureAcceptanceTests.Constructors.TestClassMustHaveSinglePublicConstructor() in d:\Dev\xunit\xunit\test\test.xunit.execution\Acceptance\FixtureAcceptanceTests.cs:line 16 [D:\Dev\xunit\xunit\tools\xunit.tests.msbuild]
```
