Title

Simple scheduler CRON triggers do not work correctly with JDK9+

Description
It seems that since JDK9 the `ZonedDateTime.now()` method works with microsecond precision. This breaks our scheduling logic which expects milliseconds precision (JDK8 behavior). We need to make the extension logic more robust.

NOTE: This bug does not apply to quartz extension which is using a different mechanism to evaluate triggers.
