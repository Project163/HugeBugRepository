Discussion
- Looking into this a bit, I suspect it's a race condition: In the test, we set a cleanup interval of 10ms. This is probably low enough that sporadically, between querying that the result is now available and actually fetching the result, it is lost. According to the docs of the cache being used, elements are automatically removed after the interval. The code contains explicit cleanup calls, though I am not sure what purpose they serve (tests pass without). 

 I experimented locally and can only reproduce this exception when setting the cleanup interval to 1ms, but then it is pretty consistent.
