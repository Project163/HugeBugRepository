Title

Cannot load plugins via command line

Description
Going by the [Link: plugin option docs], any plugins I specify with the `--plugin` option are ignored. On the other hand, if I specify a plugins property in `.eslintrc`, they are loaded.

Digging into the `lib/cli-engine` and `lib/config` modules, it seems that `config.plugins` is undefined [Link: here]:

``` javascript

    loadPlugins(config.plugins);
```

Using v1.1.0
