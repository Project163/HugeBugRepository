Title

incomplete certificate generated by mitmproxy

Description
#### Problem Description
A clear and concise description of what the bug is.

When using mitm proxy to fetch the following resource:


I get the following exception:

```
Caused by: java.security.cert.CertificateParsingException: X.509 Certificate is incomplete: SubjectAlternativeName extension MUST be marked critical when subject field is empty
        at java.base/sun.security.x509.X509CertInfo.verifyCert(X509CertInfo.java:751)
```
 
I don't know why, but the Subject of the certificate generated by mitmproxy does not get set to anything in this case.

Discussion
- Ha, interesting edge case. :)
If mitmproxy's `upstream_cert` setting is false, mitmproxy wants to set `document-storage-production-dot-remarkable-production.appspot.com` as the certificate subject (because that's all we know without looking at the upstream cert). However, that domain is exactly 65 characters long, whereas the CN field is limited to 64 characters. Hence we don't set a subject and only a SubjectAltName. The Java client is right to point out that we need to set this extension as critical then (see [URL]
