Title

Do not fail when given timeout to connectionImpl.isValid() = 0

Description
The ConnectionImpl.isValid() returns false when you pass 0 as the timeout. According to the javadocs ( [URL] a timeout = 0 means no timeout. In the current implementation a timeout = 0 means that the connection is always invalid.
