Title

Config file is not always positioning window

Description
Hey, just found a small bug with window positioning when using config vars.

If i put my code like so, then it centers both axis.
config.x=-1;
config.y=0;
or
config.x=0;
config.y=-1;

But if i put it like so, then window is in top left corner.
config.x=0;
config.y=0;
Discussion
- The way the position works specifically demands that both x and y are set if either is set. It doesn't look like LWJGL itself has this demand so am not sure why we do.
