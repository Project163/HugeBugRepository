Title

Syncing fails with 'A required privilege is not held by the client' on Windows with symlinks

Description
After upgrading to Syncthing v0.14.24 I'm no longer able to finish syncing between two Windows machines (it won't ignore symbolic links anymore which it isn't able to sync.)

Machine A has a 'send only' folder that is synchronized with Machine B. Some files on machine A are symbolic links. Previously I'd turned off symlinks under the advanced configuration options so the symbolic links would be ignored. The option to ignore symbolic links has been removed in v0.14.24 and now it won't ignore them and it can't synchronize them either.

### Version Information

Machine A:
Syncthing Version: v0.14.24
OS Version: Windows 10

Machine B:
Syncthing Version: v0.14.24
OS Version: Windows 10

Probably unrelated but I should note I use tray icon Synctrayzor (at latest, v1.1.14) on both machines which starts Syncthing.
