Title

Missing profile id at usage page

Description
At  [URL] bottom is shown settings.xml file to discover the passphrase via the keyname. It doesn't work because the id property is missing : 

  
     <profiles>
      <profile>
        <activation>
          <activeByDefault>true</activeByDefault>
        </activation>
        [...]
    <profiles>
 
  

 Should be 

  
     <profiles>
      <profile>
        <id>my_profile_id</id>
        <activation>
          <activeByDefault>true</activeByDefault>
        </activation>
        [...]
    <profiles>
