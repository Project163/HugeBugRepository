Title

Metadata for numeric data types does not include number of digits

Description
When fetching metadata from a JDBC data source, numeric values do not include the number of digits that are allowed. This value is necessary for proper support of Oracle's NUMBER type or PostgreSQL's numeric type. 

 In JDBC, this is the "DECIMAL_DIGITS" metadata value:
