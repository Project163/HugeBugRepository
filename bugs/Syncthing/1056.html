Title

'syncthing upgrade' fails if lockfile does not exist

Description
### What happened?

Noticed the following failure in CI:

```
Running Syncthing upgrade...
2025/08/12 15:19:54 INFO: Upgrade available (current "v2.0.0-rc.23" < latest "v2.0.0")
2025/08/12 15:19:54 WARNING: Upgrade: open C:\Users\runneradmin\AppData\Local\Syncthing\syncthing.lock: The system cannot find the path specified.
Syncthing upgrade failed with exit code 1.
```

The CI simply does `syncthing upgrade` without any syncthing being installed, e.g. there is no config, no lockfile, nothing. In this case, it appears that syncthing fails to upgrade, as it expects the lockfile to already exist.

### Syncthing version

v2.0.0-rc.23

### Platform & operating system

Windows amd64
