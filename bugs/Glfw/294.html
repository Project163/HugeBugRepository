Title

Cannot set `GLFW_X11_CLASS_NAME` and `GLFW_X11_INSTANCE_NAME` individually

Description
Hi,

it seems I can't set the hints `GLFW_X11_CLASS_NAME` and `GLFW_X11_INSTANCE_NAME` individually, meaning, if I do alone either:

```C
glfwWindowHintString(GLFW_X11_CLASS_NAME, "my fancy class");
```

or 

```C
glfwWindowHintString(GLFW_X11_INSTANCE_NAME, "my instance");
```

the class and instance parts of the ICCCM `WM_CLASS` are still set by default by the window title.

If, however, I set them both in the same program:

```C
// order is irrelevant
glfwWindowHintString(GLFW_X11_CLASS_NAME, "my fancy class");
glfwWindowHintString(GLFW_X11_INSTANCE_NAME, "my instance");
```

then `xprop` shows that indeed the class and instance parts have been set accordingly.

I am using x11 and my window manager is i3.

Can this have anything to do with:
Discussion
- Oops, I forgot to document that behavior. Both hint strings need to be set to something other than an empty string for them to take effect. I will add a note about this to the documentation. Thank you!
