Title

Discussion
- If you don't use the JsonbConfig which influences the size of the JSON structure then it works.
- It is more linked to the buffers size. You can configure the default strategy to workaround it setting the property org.apache.johnzon.buffer-strategy to BY_INSTANCE
- Thanks for that intermediate workaround until 1.1.7 is released. This seems to work.
