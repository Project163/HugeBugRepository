Title

IO test should use a free port for embedded resource instance

Description
MongoDbIOTest fails  (addr already in use) when a MongoDB service is locally running. I'd say the port should be random in the test suite.
Discussion
- Generally speaking, the same behavior can apply for other IO tests, like JMS for instance which starts an ActiveMQ broker for the test. I already implemented something similar in Apache Karaf (picking up a free port for the test). I do the same here.
