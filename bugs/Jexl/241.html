Title

Parse error with variables declared in a catch clause

Description
A variable defined in a catch clause cannot be reused in the same block. 
The following scripts are not allowed by the parser: 
  
 
 try  {
   //  do  stuff
 }  catch  (let error) {
   // manage error
 }
let error =  'hello error' ; 
  
 Or: 
  
 
 try  {
   //  do  stuff
 }  catch  (let error) {
   // manage error
 }
 try  {
   //  do  stuff
 }  catch  (let error) {
   // manage error
 } 
  

 Both cases end with a parsing error: 
  
 
error: variable is already declared  
  

 A failing test can look like: 
  
 
JexlEngine jexl =  new  JexlBuilder().create();
 final   String  src =  "let x = 0;  try  { x += 19 }  catch  (let error) {  return  169 }  try  { x += 23 }  catch  (let error) {  return  169 }" ;
 final  JexlScript script = jexl.createScript(src);
assertNotNull(script);
 final   Object  result = script.execute( null );
assertEquals(42, result);  
  

 At runtime it works fine. 
A try-with-resources is working fine as well: 
  
 
 try  (let closeable = open()) {
   // IO stuff
 }
 try  (let closeable = open()) {
   // IO stuff
 }
Discussion
- Grammar change to consider a try/catch as a lexical node (so local variables can be declared without clashing with outer scope, same as try-with-resource).
