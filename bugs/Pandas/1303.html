- This exact issue is caused in the above example by not defining a sub classed Series and the ``_constructor_sliced`` property on the CustomDataFrame. For example this code works as expected:

```
python
import numpy
import pandas as pd
```

This exact issue could be solved in ``NDFrame.astype`` but I imagine that a sub classed ``DataFrame`` and sub classed ``Series`` are intertwined in a lot more places than just ``astype``.  My suggestion, and I'd be happy to implement it, would be to note this behavior [Link: in the docs] and that both sub classed types need to be implemented.
