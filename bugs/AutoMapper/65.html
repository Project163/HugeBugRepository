Title

typeof() version of IncludeBase() is not working

Description
### Source/destination types

```
csharp
class Source : SourceBase 
{ }

class Destination : DestinationBase 
... [Log Snipped] ...
	public String Time;
}
```

### Mapping configuration

```
csharp
Mapper.Initialize(
	cfg =>
	{
		// It does not matter if generic type is   or <>, result is the same.
... [Log Snipped] ...
			.IncludeBase(typeof(SourceBase ), typeof(DestinationBase ));
	});
```

### Version: 6.1.1
  

### Expected behavior

`AssertConfigurationValid()` should not fail and `Timestamp` should be mapped to `Time`.

### Actual behavior

`AssertConfigurationValid()` fails with error about `Time` being unmapped.
Skipping Assert leads to essentially the same error when trying to actually map `Source` to `Destination` at runtime.

### Steps to reproduce

```
csharp
// Throws exception about "Time" being unmapped.
Mapper.AssertConfigurationIsValid();

// Throws exception because "Time" is not mapped.
... [Log Snipped] ...
if (destination.Time != source.Timestamp)
	throw new Exception("Not mapped.");
```
Discussion
- Also, using CreateMap () syntax works as expected. It's only the typeof() version that fails.
- It looks like it's the MapFrom combination of using string-based MapFrom
