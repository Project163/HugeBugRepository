Title

Fix hive-exec shaded jar config for opencsv package change

Description
In    HIVE-28248   ,  opencsv  was upgraded to v5.9 and its package changed from  net.sf.opencsv  to  com.opencsv . 
However, the  hive-exec  shaded jar configuration was not updated accordingly, and still references the old package. 
This Jira updates the shading config to relocate  com.opencsv  correctly and remove leftover  net.sf.opencsv  entries.
