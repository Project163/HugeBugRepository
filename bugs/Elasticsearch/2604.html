Title

Reproduction lines are not captured in test output

Description
The test `NodeShutdownIT.testCRUD` failures (see [URL] do not include repro lines with the failures.

Example build scans: [Link: One], [Link: Two]

This appears to happen reliably with this test.

PR [URL] should fix the test failures, which occur because the other test in `NodeShutdownIT`, `testAllocationPreventedForRemoval`, does not remove the node shutdown it registers, which leaks into `testCRUD` and causes assumptions to fail. The failure will occur any time `testAllocationPreventedForRemoval` runs before `testCRUD`. A repro line that appears to reproduce this reliably is:
```
./gradlew ':x-pack:plugin:shutdown:qa:multi-node:javaRestTest' --tests "org.elasticsearch.xpack.shutdown.NodeShutdownIT" -Dtests.seed=  -Dtests.locale=ja -Dtests.timezone=America/Louisville
```

At some point, that repro line came from a `testCRUD` failure (it's been edited to run all of `NodeShutdownIT`), but I think it was a local failure? I've unfortunately lost my terminal history back that far.
