Title

Per topic consumer metrics missing in new consumer's metrics reporter

Description
In version of  , the old consumer will provide the metrics reporter per-topic consumer metrics under group 'ConsumerTopicMetrics'. For example: 

 *.ConsumerTopicMetrics.clientId. [topic name] .BytesPerSec.count 
*.ConsumerTopicMetrics.clientId. [topic name] .MessagesPerSec.count 

 These consumer metrics are useful since it provides consumer rate for each topic. But the new consumer( ) doesn't expose per topic metrics anymore, even though I did find sensor objects in consumer metrics object collecting per-topic metrics.  

 After investigation, I found that these sensors don't register any KafkaMetrics.
