Title

Transaction find-hanging command with --broker-id excludes internal topics

Description
We use the vanilla `Admin.listTopics()` in this command if `--broker-id` is specified. By default, this excludes internal topics.
Discussion
- Note that it is still possible to use it with the --topic option instead. For example:  
  
 
kafka-transaction.sh --bootstrap-server localhost:9092 find-hanging --topic __consumer_offsets
