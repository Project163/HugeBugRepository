Title

Form wrapped around multiple Material UI tabs does not retain state

Description
**Describe the bug**
A RHF form wrapped around Material UI tabs does not retain state when switching between tabs.

**To Reproduce**
Steps to reproduce the behavior:

1. Fill in values under Name tab
2. Click on Identifiers tab
3. Click back to Names tab, TextField values are reset

[URL]

**Expected behavior**
I expected that my changed fields would be retained when I returned to the tab to continue editing
