Title

Pyverse crashes if graphviz is not installed

Description
Originally reported by: **Anonymous**

---

When calling Pyverse with the -o svg options,
it  crashes if graphviz is not installed :

```
#!python
...
  File "/usr/lib/python2.7/subprocess.py", line 679, in __init__
    errread, errwrite)
  File "/usr/lib/python2.7/subprocess.py", line 1259, in _execute_child
    raise child_exception
OSError: [Errno 2] No such file or directory

```

It should probably send a nice warning instead, if we don't want to make
pylint depend on graphviz. Or can we use python-pydot instead of a subprocess?

I'm using debian stable, but the most current pylint / astroid / lgc mercurial versions 
but the crash also occured on the debian stable version of pyreverse.
