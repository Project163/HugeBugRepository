Title

Ansible provisioner no longer gives feedback on a task-by-task basis

Description
When attempting to provision my Vagrant box with Ansible using:

``` ruby
config.vm.provision :ansible do |ansible|
  ansible.playbook = "#{ENV['ORCHESTRATION_HOME']}/foo.yml"
  ansible.inventory_path = "#{ENV['ORCHESTRATION_HOME']}/development/inventory"
end
```

The ansible provisioning no longer gives feedback on each task as it is being run, i.e. it appears to hang on:

```
[default] Running provisioner: ansible...
```

When the provisioning has finished the full output of the `ansible-playbook` invocation is shown (sometimes it is shown part way through cut off at seemingly random points).

This is an issue for us as (a) it's not immediately obvious that the provisioner is still running, and (b) it's hard to identify bottlenecks in our playbooks so we can optimise.

I suppose we could use `ansible.verbose = true` and look at timestamps but ideally we would get feedback on task execution as it was running. We used to get this when using Vagrant 1.2.x and Ansible 1.2.x.

We're now using:
- Vagrant **1.3.1**
- Ansible **1.3**

Thanks :-)
