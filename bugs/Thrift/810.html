Thrift Compiler fails at input files with UTF-8 BOM

Description
On Windows platforms, non-ASCII files are commonly preceded by a BOM. Although the Thrift Compiler supports UTF-8, it fails if the Input file data is preceded by an UTF-8 BOM.
