Thanks for looking into this.  The problem is that "coladd" is larger
than the width of the character.  Thus somewhere "coladd" gets a wrong
value.  This appears to be in do_pending_perator, where start.col is set
to zero, but coladd isn't reset.

And even if we do check, it doesn't verify the value of coladd.

So we need three fixes.  And I'll turn the example into a test.
