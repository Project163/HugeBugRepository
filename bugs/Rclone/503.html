Title

GetPassword limited to 254 characters on Windows

Description
#### Output of `rclone version`
rclone v1.49.2
- os/arch: windows/amd64
- go version: go1.12.3


#### Describe the issue
At least on Windows, the RCLONE_CONFIG_PASS environment variable only uses the first 254 characters of the value. Both Windows environment variables and rclone configuration allow for much longer strings. However, setting the environment variable to a valid password that is more than 254 characters always results in a decryption error.

If this is a language limit then even just a note in the documentation would be appreciated.
