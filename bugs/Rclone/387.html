Title

rclone sync not detecting overlapping remotes

Description
#### Output of `rclone version`
rclone v1.45



#### Describe the issue
I have a job that syncs file from one google drive to another (server side copy). I have added the source drive to the destination drive as a view only folder, so the remotes are "gdrive1:RemoteCopy" and "gdrive1:LocalCopy"

At the end of a rclone sync-job, rclone tries to delete files from the remote copy. The folder is added as "view only", so this of course fails, but why would rclone try to delete from source in the first place:

commandline is:

`rclone -vvv --drive-impersonate user@example.com sync "gdrive1:RemoteCopy" gdrive1:LocalCopy"`

I am using a service account on gdrive to impersonate user@example.com
