Title

Unable to discover 2 methods in the same class

Description
IDEA allows users to run 2 test methods of the same test class. This is done now through `LauncherDiscoveryRequest`, like:

```
java
        List  selectors = new ArrayList<>();
          while ((line = reader.readLine()) != null) {
            selectors.add(createMethodSelector(line));
          }
... [Log Snipped] ...
          }
          return builder.build();
```

Works well in most cases, but if both methods belong to the same class, then only the first one would be executed. After debugging it turns out that `org.junit.jupiter.engine.discovery.JavaElementsResolver#tryToResolveWithResolver` detects that there is already a corresponding class but instead of replacing newly created `ClassTestDescriptor` with old one, newly created descriptors are returned, and second method is added there and this subtree is lost.
