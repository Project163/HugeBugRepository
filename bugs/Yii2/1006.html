Title

PHP Notice 'Uninitialized string offset: 0' in `yii\widgets\Menu`

Description
Get notice`Uninitialized string offset 0 in /vendor/yiisoft/yii2/widgets/Menu.php:309` when using `''` as a url. Since PHP 8 has `E_ALL` turned on by default, it will be a problem.

### What steps will reproduce the problem?
```php
echo Menu::widget([
    'items' => [
        ['label' => 'Some Label', 'url' => ['', '#' => 'someid']]
    ]
]);
```

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      |  
| PHP version      | 7.4, 8.0
| Operating system | Linux, MacOS
Discussion
- How come? This is a valid array syntax with offset 0. And there is the check in line 307 anyway.
- 308: `$route = Yii::getAlias($item['url'][0]);`
309: `$route[0]`

- Yes, it should. And I think we can skip `false !== $route` since with the way `getAlias()` is called it will never be `false`.
