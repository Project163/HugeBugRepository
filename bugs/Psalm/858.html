Title

Bug: JSON report is array or object depending on --report-show-info`

Description
* When creating a JSON report (e.g. `psalm --report=psalm.json`), the resulting report is an `array`.
* When creating a JSON report excluding INFO issues (e.g. `psalm --report=psalm.json --report-show-info=true`), the resulting report is an `object`.

```
[{"severity":"info", ...

{"15":{"severity":"error", ...
```

I guess a solution would be to convert the filtered result using `array_values()`.
