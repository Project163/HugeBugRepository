Title

StandardScaler ignores with_std for sparse matrices

Description
Hi,

Looking at the code for StandardScaler's fit() method in preprocessing.py, I noticed that with_std is ignored when sp.issparse(X) is true. I noticed this when trying to make a dummy transformation in a pipeline where I was trying to decide whether to scale feature values or not.
Discussion
- Not sure what we should do about this. Maybe just raise an error if `with_std` is set to `True`. Centering the data will destroy the sparsity structure and quite likely blow your ram away.
- +1 for raising an exception

To be backward compatible, we can set `with_std` to `auto` by default, which would be True if the scaler is fit with an numpy array and False is fit with a scipy sparse matrix.
