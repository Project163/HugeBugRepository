Title

EmailTarget ignores `mail()` failures

Description
### What steps will reproduce the problem?

Disable `mail()` function in PHP config (or just ensure that it will return `false`). Use default configuration of `yii\swiftmailer\Mailer` and configure `EmailTarget` for errors. Log error.

### What is the expected result?

Warning that email can not be sent.

### What do you get instead?

Nothing. `swiftmailer` [Link: swallows `mail()` errors and returns `false`], but `EmailTarget` [Link: ignores `send()` result]. So failures are just ignored.

| PHP version      |  7.1.4
| Operating system | Linux
