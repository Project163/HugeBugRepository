Title

Dev mode not working anymore when META-INF/resources is generated

Description
**Describe the bug**
Dev mode is not working correctly when using `./mvnw compile quarkus:dev` on a project where the `target/classes/META-INF/resources` is generated.

[Image: image]

**Expected behavior**
Should work without any error

**Actual behavior**
It works once every few page refresh

**To Reproduce**
Steps to reproduce the behavior:

Simulate a Maven step that generate the `target/classes/META-INF/resources`

1. Create a project with Quarkus 1.1.0.Final
2. save the `src/main/resources/META-INF/resources/index.html` somewhere
3. run `rm -rf src/main/resources/META-INF/resources` 
4. run `./mvnw compile quarkus:dev`
5. stop it
6. copy the index.html to `target/classes/META-INF/resources`
7. run `./mvnw compile quarkus:dev`
8. open in browser and refresh multiple times

**Environment (please complete the following information):**
 - Output of `java -version`: reproduced on java 1.8 and java 1.11
 - Quarkus version or git rev: 1.1.0.Final

**Additional context**
This bug was originally met on Code Quarkus using frontend maven plugin to generate the files:
