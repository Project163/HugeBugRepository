Title

Psalm unable to infer generic type when templated class implements a templated interface

Description
I've created a snippet to illustrate the issue: [URL]

The first `foreach` block:
```
/** @var Collection  $foo */
$foo = new FooCollection(['foo']);
foreach ($foo as $bar) {
  $bar + 1;
}
```
results in `Cannot perform a numeric operation with a non-numeric type string`. So Psalm knows that `$bar` is a string. So far so good.

When I use the concrete class in the type hint (or leave the docblock out completely), Psalm is unable to infer that `$bar` is a string instead of `mixed`, even though it knows that it is of type `FooCollection `:
```
/** @var FooCollection  $foo */
$foo = new FooCollection(['foo']);
foreach ($foo as $bar) {
  $bar + 1;
}
```
Running Psalm with the second `foreach` block gives me:
```
INFO: MixedAssignment - 45:18 - Cannot assign $bar to a mixed type

INFO: MixedOperand - 46:3 - Left operand cannot be mixed
```
Discussion
- You can fix this by adding  a return type  to `getIterator`: [URL]

Still not sure if this is a bug, though
