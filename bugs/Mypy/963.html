Description

```
from typing import overload, TypeVar, Sequence
```

- LOL, I just started writing an issue about this as well. It seems to me the root cause is
```
python
from typing import Callable, TypeVar, Union, Sequence

TI = TypeVar("TI", bound=int)
TS = TypeVar("TS", bound=str)
... [Log Snipped] ...
g: Callable[[Union[Sequence[TI], Sequence[TS]]], None]
f = g  # Bogus error: Incompatible types in assignment
```
And IMO a proper fix would be to filter out "trivially unsatisfiable" (because of upper bounds) constraints _and_ then turning `[]` into `None` before comparing constraints in `any_constraints()` (used when handling unions).
