Title

`# fmt: off` directly before `yield` only affects the `yield`

Description
this is on current master:

```python
# fmt: off
yield    "hello"
yield    "world"
# fmt: on
```
formats to:
```python
# fmt: off
yield    "hello"
yield "world"
# fmt: on
```

The bug seems to be avoided by putting any (afaict) statement after the `# fmt: off` declaration, like:
```python
# fmt: off
...
yield    "hello"
yield    "world"
# fmt: on
```
Discussion
- Thanks for reporting, this is definitely a bug, I'll take a look
- Looks like this is since [URL] because we don't generate all the leaves to be ignored properly
