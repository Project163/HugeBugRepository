Title

Can't get 'in' to work under static compilation

Description
Given: 

  
 @groovy.transform.CompileStatic
 boolean  m(  Integer  i ) {
  i in [ 1, 2, 3 ]
}

println m( 1 )
 
  

 We get  false . 

 Comment out the annotation, or change it to: 

  
 @groovy.transform.CompileStatic
 boolean  m(  Integer  i ) {
  [ 1, 2, 3 ].contains( i )
}
 
  

 And we get true again.
