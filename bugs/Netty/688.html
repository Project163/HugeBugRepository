Title

DefaultHeaders does not correctly implement interface

Description
### Expected behavior

One-argument convert-and-get methods (`get{Byte,Double,Float,Int,Long,Short}`) should return `null` when invoked on a header that can't be converted, per the documentation (e.g. [Link: for `getInt(String)`]).

Similarly, two-argument convert-and-get methods should return the default value provided when the header can't be converted.

### Actual behavior

Conversion getter methods throw `NumberFormatException`.

### Steps to reproduce

Set a header to a non-numeric value, then attempt to read it as a number.

### Minimal yet complete reproducer code (or URL to code)

```java
io.netty.handler.codec.http2.DefaultHttp2Headers headers = new io.netty.handler.codec.http2.DefaultHttp2Headers();

headers.set("example", "abc");                                                                  

// Throws NumberFormatException, counter to documentation.    
int value = headers.getInt("example", 123); 
```

### Netty version

4.1
