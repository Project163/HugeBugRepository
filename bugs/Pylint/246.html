Title

Unused import from forward declaration of types

Description
Where adding a type hint would require a cyclic import, PEP484 allows guarded imports and  forward references by embedding the type hint in quotes. Pylint doesn't understand this, and considers any imported types only used in forward references to be unused, giving unused-import

### Steps to reproduce
Assume a.py imports b.py, and b.py contains:

```
import typing

if typing.TYPE_CHECKING:
  import a

def get_foo() -> 'a.Foo':
  ...
```

### Current behavior

unused-import error for the guarded `import a`

### Expected behavior

Pylint detects the forward reference and considers \`a` used.
