Title

adapter-static: infinite loop in the browser on inexistent page fallback

Description
**Describe the bug**
Now that [URL] is closed I found a problem: infinite loop in the browser.

**To Reproduce**
1. If you `npm run build` a simple app with two pages: `/` and `/players`

1. and `npx serve --single build`

1. it amazingly works good.

1. What doesn't work is if you open the browser pointing to `/inexistent` page.

1. Now the browser is in an infinite loop.
