Title

stubtest ignores `strict_bytes = true` in `pyproject.toml` 1.15.0

Description
This causes mypy build errors to be reported when I run `stubtest --mypy-config-file=pyproject.toml numpy` (in [Link: numpy/numtype]), where the `pyproject.toml` contains:

```toml
[tool.mypy]
# [...]
strict_bytes = true
```

The build error is of the `overload-cannot-match` kind, and is caused by a `memoryview` promotion in [URL]

---

The workaround is to use the superseded (and undocumented) flags instead:

```toml
[tool.mypy]
# [...]
disable_bytearray_promotion = true
disable_memoryview_promotion = true
```

Running the command again with this `pyproject.toml` shows no build errors.
