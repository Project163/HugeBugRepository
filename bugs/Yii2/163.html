Title

Parameterizing hostnames is not supported now (UrlRule)

Description
[URL]
Dont work UrlRule as

```
[
    '[URL] => 'user/profile',
] 
```

And looking at the class UrlRule , I do not understand how it can work.

I have not found a simple way to solve this problem.
Discussion
- I think it is not documentation bug, but UrlRule bug
- What exactly doesn't work here?
- ... [Middle Discussions Snipped for Brevity] ...
- It seems server configured properly.
This work:

```
[
    'host'=>'[URL]
    'pattern'=>'/',
    'route'=>'site123/index123'
],
```

This dont work:

```
'[URL]
```

And documentation example dont  work too.

UrlRule->parseRequest have following lines

```
if ($this->host !== null) {
   $pathInfo = strtolower($request->getHostInfo()) . ($pathInfo === '' ? '' : '/' . $pathInfo);
}
```

So  $pathInfo contain $request->getHostInfo() only if set host explicitly.

In other words, parameterizing hostnames not supported now.
