Title

TypeError: 'Uninferable' object is not iterable

Description
### Steps to reproduce
Simplified example. Function needs those two lines (which make more sense in the original code):
```
"""Will crash pylint on python 3.6."""
import asyncio


def crash(futures):
    """Crash pylint."""
    yield from asyncio.wait(futures)
    raise asyncio.TimeoutError()

```
### Current behavior
Pylint 1.8.1 will crash on Python 3.6. This works on Python 3.4 and 3.5.
```
# pylint test.py 
No config file found, using default configuration
Traceback (most recent call last):
  File "/usr/local/bin/pylint", line 11, in  
    sys.exit(run_pylint())
... [Log Snipped] ...
    return any(_class.qname() == stopiteration_qname for _class in exc.mro())
TypeError: 'Uninferable' object is not iterable
```
Reproduced on Ubuntu 17.10 and debian experimental. Works in Ubuntu 14.04, 16.04 and debian jessie.

### Expected behavior
No crash

### pylint --version output
```
# pylint --version
No config file found, using default configuration
pylint 1.8.1, 
astroid 1.6.0
Python 3.6.3 (default, Oct  3 2017, 21:45:48) 
[GCC 7.2.0]
```
