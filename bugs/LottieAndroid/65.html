Title

A double value for layer "w" property causes a JsonDataException

Description
*Lottie is supported and developed on nights and weekends. Issues from [Link: Lottie sponsors] will be prioritized.*

**Checklist**

1. My animation doesn't use any [Link: unsupported features].
2. I know what part of my animation doesn't work.
3. I have created a simplified version of my animation 
4. I have attached the AEP file (as a zip file so it can be attached) that only has the part of the animation that doesn't work.

**Describe the bug**
I have an animation that has base64 images with rounded corners.  Here is what the animation should look like: [URL] It displays fine on LottieFiles and in iOS, but on Android I get a few `JsonDataExceptions` always for the same field.

In `LayerParser.java` on line 239 the parser only accepts an int, but in my animation (json attached) these fields are floating point values.  I was going to attempt a PR, but the `preCompWidth` is eventually used in a `Rect()` which needs an integer, and I am not familiar enough with the Lottie rendering pipeline to think of a good solution...
[Link: problem_animation.json.zip]

When I round these values to integers, the images in my animation appear as below, in the screenshot section.

**What version of Lottie did you test this on?**
 5.2.0 and 5.2.1-SNAPSHOT (lottie-compose)

**What version of Android did you test this on?**
Android 13 Emulator
Compose 1.2.1

**Steps To Reproduce**
Steps to reproduce the behavior:

1. Try to load composition of attached json file
2. Get error `Error is com.airbnb.lottie.parser.moshi.JsonDataException: Expected an int but was 25.7358 at path $.assets[9].layers[0].w`

**Screenshots**
