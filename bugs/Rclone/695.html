Title

`rc mount/mount` mount helper error: fusermount: unknown option 'fsname'

Description
#### What is the problem you are having with rclone?

`rc mount/mount` has started failing in 1.58 with the following command:

````
rclone rc mount/mount fs=media: mountPoint=/data/mount/media
````

Log output (stdout + json)

````
2022/03/19 11:08:26 mount helper error: fusermount: unknown option 'fsname'
2022/03/19 11:08:26 mount FAILED: fusermount: exit status 1
{"level":"error","msg":"rc: \"mount/mount\": error: fusermount: exit status 1","source":"rcserver/rcserver.go:176","time":"2022-03-19T11:08:26.654392+00:00"}
````

#### Workaround

Adding `mountOpt='{ "DeviceName": "blah" }'` seems to workaround the issue (guessed from commit [Link: f4c40bf7])

````
rclone rc mount/mount fs=media: mountPoint=/data/mount/media mountOpt='{ "DeviceName": "rclone-media" }'
````
