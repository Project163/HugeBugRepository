Title

Preview: Improved line breaks with multiple targets

Description
**Describe the bug**

The "Improved line breaks" preview style should break the value before the target according to the preview style documentation. This is true for the first target, but doesn't seem to be the case when using assignments with multiple targets:

**To Reproduce**
```python
a["a"] = b["b"] =  
```

Gets formatted as 

```python
a["a"] = b[
    "b"
] =  

```

[Link: Playground]

**Expected behavior**

Black to parenthesize the value before splitting the targets:

```python
a["a"] = b["b"] = (
     
)
```
