Title

Skewed join creates 3 map reduce jobs

Description
The first job is a load / store job which loads the data from PigStorage and stores it in BinStorage. This hampers performance. The desired behavior is for the sampler to read from PigStorage instead of relying on the first load/store job. Skewed join should thus be 2 M/R jobs and not 3.
