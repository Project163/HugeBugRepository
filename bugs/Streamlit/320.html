Title

The DataFrame demo in `streamlit hello` requires a more recent Pandas version than Streamlit does

Description
# Summary

We watched a user run `streamlit hello` and see it fail in the dataframe example because `Pandas.isna()` wasn't defined.

## Steps to reproduce

1. Install an old version of Pandas. (Sorry, we don't have a record of what it was.)
2. Go to the dataframe demo in `streamlit hello`

# Behavior

## Actual behavior

An exception is thrown because `pd.isna()` wasn't defined.

## Expected behavior

The demo should work beautifully, of course ;) 

# Debug info

This was not recorded unfortunately, although it maybe worth noting that this user had `pip install`ed Streamlit into a Conda environment.

# Possible Solution

We need to figure out the minimum version of Pandas which has `isna()`. Ways to solve this:
1. Look up that function and figure out when it was introduced.
2. **(Safer!)** install progressively earlier versions of Python and run the dataframe demo until we can find the incompatible version.
