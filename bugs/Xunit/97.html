Title

ArgumentFormatter doesn't pretty-print rank-1 variable-bound arrays correctly

Description
## Summary

`ArgumentFormatter` does not pretty-print rank-1 variable-bound arrays correctly. It prints `int[]` when it should instead print `int[*]`.

## Repro

## Discussion

In .NET, there are actually __three__ ways to represent arrays:

* `int[]`, which is a standard single-dimensional, zero-indexed array ("SZ array")
* `int[,,,]`, which is a multi-dimensional array (not necessarily zero-indexed)
* `int[*]`, which is a single-dimensional array (not necessarily zero-indexed)

The last two are also called _variable-bound arrays_, and the rank-1 syntax of `[*]` has an asterisk to disambiguate it from the standard `[]` SZ array syntax.
