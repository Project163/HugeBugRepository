Title

`no-whitespace-before-property` false positive

Description
Using eslint 2.0.0-rc.0.

Code: 

``` js
var arr = [1, 2, 3]
var first = arr[ 0 ]
```

Rules:

``` js
{
  "rules": {
    "no-whitespace-before-property": 2
  }
}
```

Gives the following error:

```
  2:13  error  Unexpected whitespace before property 'undefined'  no-whitespace-before-property
```

The rule shouldn't consider this to be invalid whitespace, since the whitespace occurs _within_ the square brackets. Spacing within square brackets is already covered by another rule.

This should be continue to be considered an error:

``` js
foo [bar]
```

But not this:

``` js
foo[ bar ]
```
