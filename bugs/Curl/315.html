Title

wolfssh: all tests fail

Description
### I did this

Since a wolfSSH job has been added to CI, it fails all tests.
It doesn't support SCP so those are excluded automatically,
and the other half, SFTP, has to be ignored to keep CI green.

Example job (Linux):
[URL]

In most cases it fails with:
curl: (79) wolfssh SFTP connect error -1051 / WS_MATCH_KEY_ALGO_E / cannot match key algo with peer


### I expected the following

wolfSSH builds to pass tests.


### curl/libcurl version

master (and earlier)

### operating system

Linux (possibly others)
Discussion

- It's fine with me.

One guess I had was the wolfSSL build missing some required options. Tried building it with `--enable-wolfssh`, but it made no improvement (I haven't verified if this did add anything over `--enable-all`).
