Title

FileValidator: array keys changed after validation in multiple files case

Description
Hi

I make something like this in my form : 

```
...
 field($model, 'file[custom1]')->dropDownList($items1) ?>
 field($model, 'file[custom2]')->dropDownList($items2) ?>
...
```

After recuperating the UploadedFile instance and before validating the form, my _file_ attribute is like that : 

```
[
    'custom1' => yii\web\UploadedFile ...
    'custom2' => yii\web\UploadedFile ...
]
```

But, for some reason, after validating my model attribute, the keys of my _file_ attribute changed : 

```
[
    0 => yii\web\UploadedFile ...
    1 => yii\web\UploadedFile ...
]
```

I looked in FileValidator.php and the reason is at the [Link: line 183] : 

```
public function validateAttribute($model, $attribute)
{
    ...
    $model->$attribute = array_values($files);
    ...
}
```

Is it normal ? How to pass through ?

Thanks
