Title

New logical plan: Optimized UserFuncExpression.getFieldSchema

Description
Currently every time we invoke UserFuncExpression.getFieldSchema, Pig will instantiate UserFunc. This is not efficient and should change.
Discussion
- Patch is performance improvement, no obvious way to write a unit test.
- +1. This solution is to use caching of the often-used object. It is based on the assumption that once mFuncSpec is set, itself and its contents won't be modified, at least after the getFieldSchema method is called. But this invariant is nowhere to find in code. We may need to comment somehow. Otherwise patch looks ok.
