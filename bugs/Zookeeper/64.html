Title

Zookeeper c client build should not depend on CPPUNIT

Description
One should be able to build Zookeeper C client libs on a machine without CPPUNIT installation. 

 A simple fix is to remove from configure.ac the following line: 
M_PATH_CPPUNIT(1.10.2)
Discussion
- Simply commented out the line and the problem is fixed.
- Unfortunately this patch removes cppunit entirely from ac, we need cppunit for the tests. Rather this patch should make cppunit an option for configure - ie "on" by default, with a commmand line option to configure to turn off. I think there is a std way to do this in ac.
