Title

Description
**Describe the bug**

ZAP UI & API freezes when running automated active scan. Suspect is `alertFilters` addon based on log.

```
java -XX:MetaspaceSize=128M -XX:MaxMetaspaceSize=256M  \
-jar /home/user1/ZAP_2.7.0/zap.7.0.jar \
-port 8081 \
-dir /home/user1/.ZAP \
-installdir /home/user1/ZAP_2.7.0 \
```
