Title

[YSQL] Attempt to create a table with primary key on expression kills the server process

Description
Creating a UNIQUE or the PRIMARY KEY "constraint" on an expression is disallowed in PostgreSQL and other systems such as DB2, Oracle, etc.  (a UNIQUE "index" on an expression is fine.) On YugabyteDB, creation of a UNIQUE constraint on an expression is disallowed but the same with PRIMARY KEY causes a server process crash.

Test case:
```
yugabyte=# CREATE TABLE t1 (c1 int, c2 int, PRIMARY KEY ((c2 * 8)) );
server closed the connection unexpectedly
	This probably means the server terminated abnormally
	before or while processing the request.
The connection to the server was lost. Attempting reset: Failed.
!> 
```

Throws an error if I try to add the primary key using an index:
```
yugabyte=# CREATE TABLE t1 (c1 int, c2 int);
CREATE TABLE
yugabyte=# CREATE UNIQUE INDEX i_t1_c2mul8 ON t1 ((c2 * 8));
CREATE INDEX
yugabyte=# ALTER TABLE t1 ADD PRIMARY KEY USING INDEX i_t1_c2mul8;
... [Log Snipped] ...
DETAIL:  Cannot create a primary key or unique constraint using such an index.
yugabyte=#
```
Also an error when I try to create a UNIQUE constraint on an expression:
```
yugabyte=# CREATE TABLE t1 (c1 int, c2 int, UNIQUE (c2 * 8));
ERROR:  syntax error at or near "*"
LINE 1: CREATE TABLE t1 (c1 int, c2 int, UNIQUE (c2 * 8));
                                                    ^
yugabyte=# CREATE TABLE t1 (c1 int, c2 int, UNIQUE ((c2 * 8)));
... [Log Snipped] ...
                                                 ^
yugabyte=#
```

On PostgreSQL 11.2, an error is thrown against creation of both UNIQUE and PRIMARY KEY constraint on an expression:
```
test=# CREATE TABLE t1 (c1 int, c2 int, PRIMARY KEY ((c2 * 8)));
CREATE TABLE t1 (c1 int, c2 int, PRIMARY KEY ((c2 * 8)));
ERROR:  syntax error at or near "("
LINE 1: CREATE TABLE t1 (c1 int, c2 int, PRIMARY KEY ((c2 * 8)));
                                                      ^
... [Log Snipped] ...
DETAIL:  Cannot create a primary key or unique constraint using such an index.
test=#
```
