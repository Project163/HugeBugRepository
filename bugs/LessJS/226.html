Title

Nested @layer rule lost scope

Description
**To reproduce:**

[URL]

```less
.main{  
  @layer{
    &::before{
      color:#f00;
    }
  }
}
```

**Current behavior:**
Nesting selector `&` lost in `@layer`.
But other @ rules works well, such as `@media`, `@container` etc.
```less
@layer {
  ::before {
    color: #f00;
  }
}
```

**Expected behavior:**
Nesting selector `&` resolved as its scope selector.
```less
@layer {
  .main::before {
    color: #f00;
  }
}
```

**Environment information:**

- `less` version: 4.2.0
Discussion
- Fixed in [URL]
