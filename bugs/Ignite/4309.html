Title

Thin client: Protocol version conflict in master

Description
Two independent tickets (  IGNITE-11043   and   IGNITE-9113  ) introduced two different thin protocol versions - one for Affinity Awareness and another is for the Lazy Memory Allocation. These two different protocol versions were given the same value - 1.3.0. It is proposed to change one of versions to 1.4.0.
Discussion

Why do you want to do it? 

 Thin client version incremented in each release that has uncompatible changes in protocol. 
Changes from   IGNITE-9113   and   IGNITE-11043   should use the same 1.3.0 version.

Lately, if .Net implementation will be included in release, we can always make it one version again.
