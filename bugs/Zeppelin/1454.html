Title

Modal is closed when NOTES_INFO message arrives

Description
On the home page, any open modal(e.g., `Import Note`, `Create New Note`) closes when a  `NOTES_INFO` message is received. 

 This is unexpected and makes running parallel E2E tests that create new notes unreliable. 

 We should fix the modal behavior while still letting `NOTES_INFO` trigger note-list UI updates.
