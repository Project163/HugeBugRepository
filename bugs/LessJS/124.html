Title

Mixin wrongly called

Description
Hi,

I have a bug with this example

```
css
.row(@layout: fixed) { 
    display: table;
    table-layout: @layout;
}
... [Log Snipped] ...
.row { .row() }
.row > *, .col { .col() }
```

output: 

```
css
.row {
  display: table;
  table-layout: fixed;
  display: table-cell;
... [Log Snipped] ...
  display: table-cell;
}
```

If I add the parameter `fixed` as an argument to .row, no problem, if I remove the `.row > *,` code, no problem (but that's not what I want)
Discussion
- I think it is detecting recursion and (incorrectly) excluding both `.row` mixins.
When you add an argument it will exclude the class you are in, meaning it doesn't detect any recursion.
I guess that this might work too

```
._row(@layout: fixed) { 
    display: table;
    table-layout: @layout;
}

... [Log Snipped] ...
.row { ._row() }
.row > *, .col { ._col() }
```
- @lukeapage I think I will be able to fix this, if you are not working on it. I tracked the issue down to `css.match(/[Link: ,&#\.\w-])*/g)` in selector.js, it seems to be just a matter of tweaking the regular expression.
