Title

[Assetic] Requests service of inactive scope

Description
Enabling the Twig extension "twig.extension.assets" causes Assetic to request the service "request" while the request scope has not been entered, yet. The result is an InactiveScopeException. This only happens when the container, and the routing have to be re-built during the same request.

``` yml
# Twig Configuration
twig:
    debug:            %kernel.debug%
    strict_variables: %kernel.debug%
    extensions: [twig.extension.text, twig.extension.assets]
```

```
yml
exception:
  -
    message: 'You cannot create a service ("request") of an inactive scope ("request").'
    class: Symfony\Component\DependencyInjection\Exception\InactiveScopeException
```
