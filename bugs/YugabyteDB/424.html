Title

ldb, rocksdb_dump: type.googleapis.com/yb.docdb.ConsensusFrontierPB not found

Description
`rocksdb_dump` doesn't seem to work on commit  .  Here's a repro:

```sh
./bin/yb-ctl create --num_shards_per_tserver 1
./bin/cqlsh --execute "CREATE KEYSPACE k"
./bin/cqlsh --execute "CREATE TABLE k.t (i int PRIMARY KEY)"
./bin/cqlsh --execute "INSERT INTO k.t (i) VALUES (1)"
./build/latest/bin/yb-admin --master_addresses   flush_table k t
./build/latest/bin/rocksdb_dump --db_path ~/yugabyte-data/node-1/disk-1/yb-data/tserver/data/rocksdb/table- /tablet-  --dump_location /dev/stdout
```
