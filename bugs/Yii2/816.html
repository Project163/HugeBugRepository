Title

AssetManager unnecessarily checks for writable basePath when not configured to publish any assets

Description
### What steps will reproduce the problem?
- Configure AssetManager to use assets already in web accessible folder or external assets from CDN
- Set permission on assets folder to read-only (755) (this is a standard security measure on our production servers)

### What is the expected result?
Use the configured assets without publishing or checking for writable publish path

### What do you get instead?
Invalid Configuration – yii\base\InvalidConfigException
The directory is not writable by the Web process: /var/www/htdocs/admin/assets
1. in /var/www/includes/vendor/yiisoft/yii2/web/AssetManager.php at line 215

### Additional info
My AssetManager config:
```
return [
    // Map file names to external resources
    'assetMap' => [
        'jquery.js'         => "//ajax.googleapis.com/ajax/libs/jquery/2.2.4/jquery.js",
        'bootstrap.css'     => "//maxcdn.bootstrapcdn.com/bootstrap/3.3.7/css/bootstrap.css",
... [Log Snipped] ...
    ],
];
```
My AppAsset class:
```
class AppAsset extends AssetBundle
{
    public $basePath = false;
    public $baseUrl = '@web/assets';

... [Log Snipped] ...
    public $depends = [ ];
}
```

| Q                | A
| ---------------- | ---
| Yii version      |  
| PHP version      | 5.6.31
| Operating system | Linux CentOS 7

The problem is caused by the AssetManager::init() method where the basePath is checked if it's an existing and writable directory regardless of the need for such check. 

Could this check be moved from the init() method to somewhere where it's more relevant and only perform the check when asset publishing is involved?

My workaround for now is to point the basePath to a writable directory, which is currently the yii-runtime, even though nothing gets published there. This satisfies the check in AssetManager::init(). The other workaround would be to override the init() method but I don't want that in case new functionality is added in later versions.
