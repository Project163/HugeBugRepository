Title

Splat operator calls for arrays only, yet an iterable would work just fine

Description
```php
function foo(iterable $args): int {
    return intval(...$args);
}
```
[Link: Errors with:]
```
Psalm output (using commit a887d09): 

ERROR: InvalidArgument - 4:12 - Argument 1 of intval expects array, iterable provided
```
Yet the code is [Link: perfectly valid in PHP 7.1+.]

```php
var_dump(foo(new ArrayIterator(["123"])));
// outputs int(123)
```

[Link: Quoting the docs:]


So there comes another specimen:

```php
function foo(ArrayIterator $args): int {
    return intval(...$args);
}

foo(new ArrayIterator(["123"]));
```

[Link: Fails with]

    ERROR: InvalidArgument - 4:12 - Argument 1 of intval expects array, ArrayIterator provided
