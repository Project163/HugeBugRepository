Title

HTML URL encoding problems (files get skipped)

Description
rclone v1.37-041-g21aca686β
Ubuntu 17.04, 64 bit
HTTP
"rclone ls test:" or "rclone copy test: /tmp"

Filenames containing characters like ":" (encoded as "%3a") or "%" ("Now 100% better.mp3") cause the latest rclone beta to skip these files. (rclone v1.37 crashes as discussed in #1555)

It would be great if rclone could replace these characters with something like underscore.
