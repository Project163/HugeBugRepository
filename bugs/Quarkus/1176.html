Title

Error during build: Unrecognized option: --add-opens

Description
## Describe the bug
I want to add `--add-opens` JVM args to my Quarkus application. To do it I have created `.mvn/jvm.config` file and put `--add-opens` command there. Then when I run `./mvnw clean install` it shows the error.

### Expected behavior
Application should built successfully.

### Actual behavior
The following error is shown:


## Additional context

I tried `--illegal-access=warn` JVM arg instead of `--add-opens` but got the similar error.

- @fabasoad Ok, so for your case there is one thing you can try:
Add `--add-opens java.base/java.util=ALL-UNNAMED` to `maven-surefire-plugin` via [URL] _instead_ of adding it to `jvm.config` (or `MAVEN_OPTS`).

PS: Quarkus will try plain Java serialization before trying xstream, but #16302 was not backported (and most likely won't) so for now this means 2.0 (2.0.0.Alpha2 at the time of writing this).
