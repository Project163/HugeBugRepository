Title

Remote names with spaces are unusable

Description
Being naive and uncreative in my first run with rclone, I named my remote `amazon cloud`. Any attempt to use this remote name results in rclone looking in the current directory on the local filesystem and ending in error. No combination of quotes or backslashes (e.g., `"amazon cloud":`, `amazon\ cloud:`) helped. I am using Bash in OSX. A check/warning at the command line or some note in the documentation would be helpful. Great util, by the way!
