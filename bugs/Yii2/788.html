Title

checkBoxList itemsOptions is ignored

Description
### What steps will reproduce the problem?
In View
// $form is yii\widgets\ActiveForm

```
echo $form->field($model, 'my_attr')
          ->checkBoxList(['1' => 'One', '2' => 'Two'], [
            'itemOptions' => [
              'value' => '0',
              'label' => 'My Label',
          ]]
     );
```

### What is the expected result?
```
 
      My Label
 
 
      My Label
 
```

### What do you get instead?
```
 
      Attribute Label from Model
 
 
      Attribute Label from Model
 
```
value is 0 by default, but it does not change anyway

### Additional info

The solution is change order from `array_merge` in `public static function checkboxList` from `yii\helpers\BaseHtml`
```
Original: 
...
            } else {
                $lines[] = static::checkbox($name, $checked, array_merge($itemOptions, [
                    'value' => $value,
... [Log Snipped] ...
            }
...
```
```
Suggested update: 
...
            } else {
                $lines[] = static::checkbox($name, $checked, array_merge([
                    'value' => $value,
... [Log Snipped] ...
            }
...
```
