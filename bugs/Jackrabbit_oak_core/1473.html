Title

LeaseFailureHandler might be called multiple times/concurrently on a lease failure

Description
Due to the  retry loop in ClusterNodeInfo.performLeaseCheck  the previous mechanism to prevent multiple threads to call the LeaseFailureHandler is broken and you can now have multiple threads hit that retry-loop and all of them will call the LeaseFailureHandler in separate threads. 

 The consequences aren't grave as OSGi can handle concurrent  bundle.stop()  calls just fine. 

 But nevertheless, should we only call the LeaseFailureHandler only once.
