Title

infer_file_schema() does not use offset from with_skip_rows_after_header()

Description
### Polars version checks

- [X] I have checked that this issue has not already been reported.

- [Link: X] I have confirmed this bug exists on the [latest version] of polars.


### Issue Description

I have a csv of floats that has a header, then a row that describes the unit of the column, then all the remaining rows contain floats or ints. I believe that the infer_file_schema function should start looking after the offset I provide in with_skip_rows_after_header() when I generate the LazyCsvReader.
