Title

[YSQL] Java regress test "failed tests: []" empty set

Description
Jira Link: [Link: DB-15456]
### Description

Applying this

```
diff
diff --git i/src/postgres/src/test/regress/sql/yb.orig.tablegroup.sql w/src/postgres/src/test/regress/sql/yb.orig.tablegroup.sql
index 9ffab04bd1..6c7ff3a388 100644
--- i/src/postgres/src/test/regress/sql/yb.orig.tablegroup.sql
+++ w/src/postgres/src/test/regress/sql/yb.orig.tablegroup.sql
... [Log Snipped] ...
 -- Tablegroups
 --
```

and running `./yb_build.sh fastdebug --gcc11 --java-test TestPgRegressTablegroup --sj` gives

```
java.lang.AssertionError: pg_regress exited with error code: 1, failed tests: []
```

Normally, test names are listed in `failed tests: []`.  This is broken because the `failedTestLineRe` doesn't handle `.`.  This issue has existed for a long time (since commit  ), and it only got worse since commit   renamed many tests to have `.`.  But such tests with `.` existed even before  , such as `yb.port.collate.icu.utf8` (previously named `yb_pg_collate.icu.utf8`).
