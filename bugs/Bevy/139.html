Title

WorldQuery derive doesn't respect visibility

Description
## Bevy version

(main)  

## Operating system & version

Windows 10

## What you did

Created a `WorldQuery` derive with a `pub` struct:
```rust
#[derive(Component)]
pub struct Foo;

#[derive(WorldQuery)]
pub struct FooQuery  {
    pub foo: &'w Foo,
}
```

## What you expected to happen

Compile without error.

## What actually happened

```
error[E0446]: private type `FooQueryFetch ` in public interface
  --> server\entity\src\lib.rs:17:10
   |
17 | #[derive(WorldQuery)]
   |          ^^^^^^^^^^
... [Log Snipped] ...
   |
   = note: this error originates in the derive macro `WorldQuery` (in Nightly builds, run with -Z macro-backtrace for more info)
```
and
```
error[E0446]: private type `FooQueryState ` in public interface
  --> server\entity\src\lib.rs:17:10
   |
17 | #[derive(WorldQuery)]
   |          ^^^^^^^^^^
... [Log Snipped] ...
   |
   = note: this error originates in the derive macro `WorldQuery` (in Nightly builds, run with -Z macro-backtrace for more info)
```

## Additional Information

Removing the `pub` from `Foo` and `FooQuery` results in no compile errors.
