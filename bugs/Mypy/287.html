Title

Duck type compatibility with a generic type using implicit type args

Description
If you try to make a class duck type compatible with a generic type using the typing.ducktype decorator, the type checker fails in a subtype check with an unhandled exception if you omit the type arguments:

```
from typing import ducktype, List
@ducktype(list)  # works if List[int] instead
class A: pass
def f(x: List[int]) -> None: pass
f(A())
```
Discussion
- The `ducktype` decorator is not supported any more (it got renamed to `_promote` but it's not officially supported).
