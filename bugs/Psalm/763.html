Title

Type declared by @psalm-type cannot be used in @psalm-var annotation of return statement

Description
I have a type declared by `@psalm-type` annotation:
```php
/**
 * @psalm-type Person = array{name: string, age: int}
 */
```

Then I tried to use it in `@psalm-var` annotation of return statement and it didn't work.
```
php
/**
 * @psalm-return Person
 */
function getPerson(): array {
... [Log Snipped] ...
  return json_decode($json, true);
}
```

If I use `array{name: string, age: int}` instead of `Person`, it works.
```
php
/**
 * @psalm-return Person
 */
function getPerson_ok1(): array {
... [Log Snipped] ...
  return json_decode($json, true);
}
```
It's also possible to assign the value to a varible (with `@psalm-var` annotation) and then return the variable.
```
php
/**
 * @psalm-return Person
 */
function getPerson_ok2(): array {
... [Log Snipped] ...
  return $person;
}
```
