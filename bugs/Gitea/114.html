## Description

I'm using MS SQL Server 2014. Whenever  I try to add a user to an organization team. I get the error "mssql: Incorrect syntax near 'LIMIT'."

[Image: error]

The error is caused because  it's trying to run the following SQL statements:

``` 
SELECT * FROM team_user WHERE org_id=@p1 AND team_id=@p2 AND uid=@p3 LIMIT 1
SELECT * FROM org_user WHERE uid=@p1 AND org_id=@p2 LIMIT 1'
```
I was able to trace it to changes introduced on commit   .  

file: models/org_team.go
```
go
func isTeamMember(e Engine, orgID, teamID, userID int64) (bool, error) {
	return e.
		Where("org_id=?", orgID).
		And("team_id=?", teamID).
... [Log Snipped] ...
		Exist()
}
```
and models/org.go
```
go
func IsOrganizationMember(orgID, uid int64) (bool, error) {
	return x.
		Where("uid=?", uid).
		And("org_id=?", orgID).
... [Log Snipped] ...
		Exist()
}
```
It looks like calling Exist() generate the code with LIMIT 1, which fails on MSSQL because it doesn't support LIMIT 1.  Reverting the changes to use  `Get(new(OrgUser))` fixes it. I'm assuming the error is coming from the ORM.
