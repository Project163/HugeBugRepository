Title

Make d3 compatible with ES5 strict mode

Description
Strict mode disallows function statements inside if() statements:
- [URL]
- [URL]

d3_event_dragSuppress is not compatible with strict mode, because it conditionally defines the off() function:

```
js
function d3_event_dragSuppress() {
  // ...
  return function(suppressClick) {
    // ...
... [Log Snipped] ...
  };
}
```
Discussion
- See #1755 for a previous discussion about strict mode; if you have arguments for strict mode I would add them to that issue.

_However_, I do think putting a function declaration inside a conditional is bad practice, since hoisting behaviour can be inconsistent across JavaScript VMs.  Function declarations should be in the top-level scope according to the specification, hence the inconsistency.  Specifically, Firefox will not hoist a function declaration inside a conditional.  We’re OK in this instance because we do not require any hoisting.

Hence, I would be happy to convert to a function expression for the next release.

(This function declaration issue has been reported previously as #1553.)
- Fixed by #2115 and staged for 3.5 in #2118.
