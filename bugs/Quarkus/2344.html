Title

Nested tests start and stop Quarkus multiple times

Description
### Describe the bug

Due to [URL] i couldn't write nested tests, the profile's config would be shared across tests. After it got fixed via [URL] i tried to write some nested tests but i observed that the nested tests which have defined a profile, makes the app to start/stop 3 times and then the test gets executed. Nested tests without (default) profile does not trigger that start/stop. This [URL] might be related.

If you run the following test:

```
java
@QuarkusTest
class ManifestTest {

    @Nested

}
```
