Title

Use actual first offset of messages when rolling log segment for magic v2

Description
We've implemented a heuristic to avoid overflowing when rolling a log segment to determine the base offset of the next segment without decompressing the message set to find the actual first offset. With the v2 message format, we can find the first offset without needing decompression, so we can set the correct base offset exactly.
