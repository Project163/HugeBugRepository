Title

ant clean-jars should not delete gradle-wrapper.jar

Description
Right now ant clean-jars deletes  gradle/wrapper/gradle-wrapper.jar , so if I execute the following command to recreate the checksums it shows up as as deleted file in git: 
  
 $ ant clean-jars jar-checksums 
...
$ git status -s
 D gradle/wrapper/gradle-wrapper.jar 
  

 I don't think we should delete the gradle-wrapper.jar here
