Title

CheckboxColumn, value у всех 1, если checkboxOptions является замыканием

Description
Использую в GridView yii\grid\CheckboxColumn. Если checkboxOptions является замыканием, и если явно не устанавливать value, то у всех чекбоксов value будет 1:
`'checkboxOptions' => function ($model, $key, $index, $column) {
    return ['checked' => 'true'];
}`
Приходится в замыкании явно указывать value, например 'value' => $model->id.

По аналогии, если checkboxOptions массив, то все работает правильно:
`'checkboxOptions' => [
    'checked' => 'true',
]`

Предпологаю, что ошибка кроется [Link: тут].
