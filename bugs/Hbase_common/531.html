Discussion
- This problem is more related to tag compression than the DBE's themselves. I updated the above test case to call  .setCompressTags(false)  on the ColumnFamilyDescriptor, and none of the DBE's throw an exception in that case. 

 So just pointing out that if anyone stumbles across it they can work around by using  .setCompressTags(false)  in code or  COMPRESS_TAGS => false  in the shell.
- Found the bug, relating to resetting uncompressTags state when rewinding. Patch available.
