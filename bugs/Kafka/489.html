Title

zookeeper.connection.timeout.ms is set to 10000000 in configuration file in Kafka tarball

Description
I've noticed that Kafka tarball comes with zookeeper.connection.timeout.ms=1000000 in server.properties while  [URL] says the default is 6000. This setting was introduced in configuration file in 46b6144a, so quite a long time ago (3 years), which makes it look intentional, but as per Jun Rao's comment on IRC, 6000 sounds more reasonable, so that entry should probably be changed or removed from config at all.
