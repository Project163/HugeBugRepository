Title

Excel parser cannot change *keep_default_na* value

Description
The parse method in the ExcelFile class does not pass the argument _keep_default_na_ to the TextParser from pandas.io.parsers.  There is no clean way to override the default na values when parsing excel files with the current code.

My specific problem involves "NA" as a typical value for "North America" in excel files.
