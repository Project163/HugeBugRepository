Title

CI_Input::request_headers(): Improper handling of $xss_clean parameter.

Description
A current code snapshot: [URL]

When this method is called for the first time, $xss_clean will be taken into account when the result is created. But once the result is cached within the property $this->headers, the parameter will not make further influence on the result on next method calls.

A possible solution I can imagine is caching both the escaped and the unescaped versions of the headers.
