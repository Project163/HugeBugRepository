Title

phpunit and debugkit together creates misleading error messages and exceptions

Description
At the AppController.php I have DebugKit.Toolbar in the $components array.

At my controller test case I have the setUp() function.

```
    public function setUp() {
      parent::setUp();
      $this->Bizonylatok = $this->generate('Bizonylatok', 
        array('components' => array('Session','DebugKit.Toolbar')));
    }
```

The test throws an exception. PHPUnit_Framework_Error_Warning. Invalid argument supplied for foreach(). It fails at the line where DebugKit is moked in the setUp method.
