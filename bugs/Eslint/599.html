Title

space-before-keyword matches getters

Description
After updating from ESLint 1.4.3 to 1.5.0 I noticed the `space-before-keywords` rule with configuration `always` matches getters and setters.

``` js
return {
  get prop() {  <-- reports: Missing space before keyword "(".
    return prop;
  }
};
```

This conflicts with `space-before-function-paren` set to `never`.
