Title

Indent rule with object and array elements

Description
Version 1.0.0

Rule:

``` yml
indent: [2, 2, {"SwitchCase": 1, "VariableDeclarator": 2}]
```

Code:

```
js
var data = {
    x: 0,
    y: 0
};
... [Log Snipped] ...
    1
];
```

Error:

```
test3.js
  4:2  error  Expected indentation of 2 characters but found 0  indent
  9:2  error  Expected indentation of 2 characters but found 0  indent
```

I expect the rule to warn about the indentation of array and object elements (should be 2 instead of 4), but it is flagging the last line of the literal instead.
Note: when indentation of the elements is correct, there is no problem.

B:

Based on above examples, which is correct `A` or `B`?
