Title

rclone removing excluded files when 'pulling' the sync

Description
I set up rclone on my main computer to sync a folder to Amazon Cloud Drive:

```
rclone sync --checksum --bwlimit=400k --filter-from="rclone-filters.txt" ~/sites acd:sites
```

And another on my laptop to 'pull' the folder:

```
rclone sync --checksum --bwlimit=1M --filter-from="rclone-filters.txt" acd:sites ~/sites
```

rclone-filters.txt excludes .gir directories, node_modules, etc so the version on ACD doesn't have these folders.

When syncing to the laptop, rclone deletes these directories on the laptop if they already existed. (Or tries to in the case of .git directories which just spams the terminal with operation not permitted errors) Shouldn't using --filter-from on the 'pull' command prevent that?
Discussion
