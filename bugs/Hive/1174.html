Title

NonBlockingOpDeDup does not merge SEL operators correctly

Description
The input columns list for SEL operations isn't merged properly in the optimization. The best way to see this is running union_remove_22.q with -Dhadoop.mr.rev=23. The plan shows lost UDFs and a broken lineage for one column. 

 Note: union_remove tests do not run on hadoop 1 or 0.20.
