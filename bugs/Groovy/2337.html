Title

Groovyc doesn't check annotations for missing attributes if variable is annotated

Description
Groovyc should fail on '@X' annotation because attribute 'foo' is missed 
  
 @ interface  X {
     int  foo()
}

@X   //I expect an error here 
  int  g = 5

print g

 
  

 if I declare a type definition with @X Groovyc fails: 

  
 @ interface  X {
     int  foo()
}

@X   //An error is here
  class  Bar {}
Discussion
- BTW Groovyc doesn't check aliased annotations used on vars as well. 

  
 @ interface  X {
     int  foo()
}

@ interface  Y {
     String  foo()
}

@X
@Y
@AnnotationCollector
@ interface  Alias {}

@Alias(foo =  'a' )  //error is expected here
  int  abc
- aliased annotation are not really different from those not annotated when it comes to these checks. So it is unrelated to aliased annotations
