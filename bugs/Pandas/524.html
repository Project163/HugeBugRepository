Title

Constructing a Series with a set returns a set and not a Series

Description
With latest master:

``` python

In [1]: import pandas

In [2]: data = set([1,2,3,4])

In [3]: pandas.Series(data)
Out[3]: set([1, 2, 3, 4])
```
Discussion
- I'm not sure what would be the correct behavior, IMO (return a Series or raise an exception).
- It should probably raise an exception because sets are unordered and, unlike dicts, are not a mapping
- Where is the check made? I might take a stab at it if time permits.
- Added a simple check / TypeError
