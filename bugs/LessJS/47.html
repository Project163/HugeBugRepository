Title

Compilation should fail on any error.

Description
Currently the compilation happily outputs css up to the point of parsing error and lessc returns exit code 0. Wouldn't it be better to be more strict and fail early?
Discussion
- Can you give an example and your usage? I haven't seen this....
- Upon further investigation it has something to do with imports. Minimal test case:

style.less:

```
less
@import 'imported.less';

body
{
... [Log Snipped] ...
    cursor: pointer;
}
```

imported.less:

``` less
.someclass
{
    font-weight: bold;
}
```

compile:

```
lessc style.less
```

output:

```
css
.someclass {
  font-weight: bold;
}
body {
... [Log Snipped] ...
  font-style: normal;
}
```

Rest of the style.less is ignored. No error.
- thanks, reproduced and fixed.
