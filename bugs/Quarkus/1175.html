Title

Empty REST Client @Path leads to exception with OpenTelemetry

Description
## Describe the bug
Reported in [URL]

When a REST Client interface is defined as:

```
    @RegisterRestClient(configKey = "simple")
    public interface SimpleClient {
        @Path("")
        @GET
        TraceData noPath();
    }
```

When the OpenTelemetry client filter is setting the span name, it results in the following exception:
```
Caused by: java.lang.StringIndexOutOfBoundsException: String index out of range: -1
at java.base/java.lang.String.substring(String.java:1841)
at io.quarkus.opentelemetry.tracing.client.ClientTracingFilter.filter(ClientTracingFilter.java:41)
at org.jboss.resteasy.client.jaxrs.internal.ClientInvocation.filterRequest(ClientInvocation.java:686)
... 118 more
```

### Expected behavior
No exception and a reasonable client span name is set

### Actual behavior
An exception is thrown, preventing the trace from being recorded properly
