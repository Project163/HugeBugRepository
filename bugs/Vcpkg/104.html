Title

[qt5-base 5.12.5-3] build failure in linux in feature openssl-linked

Description
**Host Environment**
- OS: Ubuntu 19.10 64 bit
- Compiler: gcc (Ubuntu 9.2.1-9ubuntu2) 9.2.1 20191008

**To Reproduce**
Steps to reproduce the behavior:

- Install a new Ubuntu 19.10 installation
- Install `build-essential`, `curl`, `unzip`, `tar`, `libgl1-mesa-dev`, `libglu1-mesa-dev`, `git`, `cmake`
- Clone `vcpkg`
- Enter the vcpkg folder
- `./bootstrap-vcpkg.sh`
- `./vcpkg install qt5`

After some point, the build fails during the configuration.



**Failure logs** 

The error message that I obtain is the following one:
```
ERROR: Feature 'openssl-linked' was enabled, but the pre-condition '!features.securetransport && libs.openssl' failed.
```

**Additional context**
I've tried to install those packages from vcpkg:

- openssl
- openssl-linux
- libssh2

I've also tried to build libssh but I've another error, so I've installed the system ones with
```
sudo apt-get install libssl-dev
```

The error persists.

`"OPENSSL_LIBS=${SSL_RELEASE} ${EAY_RELEASE} -ldl -lpthread"`
and do the same for the debug case a few lines below that
