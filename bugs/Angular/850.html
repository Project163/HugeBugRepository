- Thanks for reporting! It looks like this happens because syntax of the form `object.property` is being statically analyzed with `object` being resolved to `undefined`. The interpreter doesn't currently handle that nicely and we should look into improving the situation.

Would you be able to share a reproduction? I could understand there's no way for you to find the culprit, but if it were possible to share some code that shows the problem would help in establishing the next steps.

}
