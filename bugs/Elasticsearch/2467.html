Title

DateFieldMapper `ignore_malformed` misses java.lang.ArithmeticException

Description
It seems when parsing dates as longs, we can have arithmetic exceptions. Steps to reproduce:

```
PUT test01
{
  "mappings": {
    "properties": {
      "dadate": {
... [Log Snipped] ...
  "dadate": "-522000000"
}
```

The error in the logs looks like:

