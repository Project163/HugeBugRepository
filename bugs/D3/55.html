Title

d3.geo.interpolate sometimes generates NaNs when interpolating between two identical points.

Description
There are some strange corner cases.

Interpolating between the same point works fine for some points:

```
[4, 4]
```

But this ends up returning [NaN, NaN] for all values of `t` for other pairs of points, like this one:

```
[NaN, NaN]
```
Discussion
- The problem is that with enough precision, the value `d` in d3_geo_interpolate ends up being equal to 1, which leads `k` to equal to `Infinity`.

Two solutions are:
1. Check for `x0 == x1 && y0 == y1` and return a function that always returns `[x0, x1]` in that case.
2. Subtract a tiny offset to `d` if it equals to 1

Interpolating between the same point obviously isn't a "normal" use of interpolate but can happen in practice -- and should work properly in that case.
