Title

"select * from table ..." using secondary index returns selected columns in different order

Description
When executing "select * from table ..." using a secondary index, the selected columns are returned in a different order from the table columns.

```sql
cqlsh> create table t (k int primary key, v1 int, v2 int) with transactions = { 'enabled' : true };
cqlsh> create index i on t (v1) include (v2);
cqlsh> insert into t (k, v1, v2) values (1, 2, 3);

cqlsh> select * from t ;
 k | v1 | v2
---+----+----
 1 |  2 |  3

cqlsh> select * from t where v1 = 2;
 v1 | k | v2
----+---+----
  2 | 1 |  3
