Title

Theme setting priority between embed_options and the config file

Description
### Checklist

- [Link: X] I have searched the [existing issues] for similar feature requests.
- [X] I added a descriptive title and summary to this issue.

### Summary

When you have a Streamlit app with a custom theme (setting the `theme` in `streamlit/config.toml`) and embed the app somewhere with `embed_options=light_theme` or `embed_options=dark_theme`,
`embed_options` have priority to select the initial theme so that the app is displayed with the light or dark, but not the custom theme first.

Sometimes it is confusing, as you expect the custom theme to be applied first.
