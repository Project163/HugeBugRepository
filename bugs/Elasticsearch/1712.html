Title

Include in term aggregation not working on integer field

Description
**Elasticsearch version**:5.1.1

Below are two documents of type 'book' which have the fields title, year and yearint. 

```
PUT filteryear
{
  "settings": {
    "number_of_shards": 1
  },
... [Log Snipped] ...
  }
}
```
Documents:

```
PUT filteryear/book/1
{
"title": "Banana",
"year": "2007",
"yearint": 2007
... [Log Snipped] ...
"yearint": 2008
}
```

The following is a term aggregation on the field "year" (mapped as String).

```
POST filteryear/book/_search
{
  "from" : 0,
  "size" : 0,
  "query" : {
... [Log Snipped] ...
  "ext" : { }
}
```

Result:

```
{
  "took": 1,
  "timed_out": false,
  "_shards": {
    "total": 1,
... [Log Snipped] ...
  }
}
```
As you can see the "YearsSelected" aggregation contains only the bucket, which was specified in the include ("2007"). "YearsNonSelected" aggregation contains all years except of "2007".


Now the same aggregation, but on the field "yearint" (mapped as integer).

```
POST filteryear/book/_search
{
  "from" : 0,
  "size" : 0,
  "query" : {
... [Log Snipped] ...
  "ext" : { }
}
```

Result: 

```
{
  "took": 1,
  "timed_out": false,
  "_shards": {
    "total": 1,
... [Log Snipped] ...
  }
}
```

The "YearsSelected" aggregation now contains two buckets "2007"and "2008", although it should only contain the included term "2007".

The only difference is the type of the field I use for the aggregation, shouldn't  the result be the same? 

Btw, it doesn't  make any difference if we specify 2007 or "2007" in the include.

My current fix is to use min_doc_count = 1, so that all buckets with docCount=0 are excluded.
