Discussion
- The statement `zap.xml_report` should be called before shutting down ZAP, otherwise it might not complete successfully.
You also need to do something with the returned report (e.g. print, save to file).
- As per your suggestion I genrated the report before shutdown

#using owasp gem
require 'owasp_zap'
include OwaspZap

zap = Zap.new :base=>'[URL] :target=>'[URL] :zap=>'/root/ZAP/ZAP_2.4.1/zap.sh', :output=>'logfile.txt'
zap.start :daemon=>true

p 'Starting ZAP'

# Wait for ZAP to start

until zap.running?
    sleep(2)
end

#To set format of the alerts
zap.alerts.view

# Wait for the spider to finish

while spider.running?
    sleep(2)
end

p 'Starting Active Scan...'
scan = zap.ascan # Obtaining the Attack from zap instance
scan.start

# Wait for the active scan to finish

while scan.running?
    sleep(2)
end

# do something with results

p 'Generating Alerts'
alert = zap.alerts
alert.view
sleep(2)

content = zap.xml_report
file = File.open("report.xml", 'w')
file.write(content)

zap.shutdown

exit
