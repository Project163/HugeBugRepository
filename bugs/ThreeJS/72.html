Title

Editor: Orbit controls stop working when drag events terminate outside of the expected region

Description
**Steps**
1. Open the Editor app on a the latest version of the dev branch
2. If needed, add an object to the scene
3. Select the object 
4. If needed, click the translate button to ensure the translate controls are displayed
5. Click and drag one of the axis helper arrows
6. Move the mouse in a direction perpendicular to the axis so that it moves outside of the selected objects bounding box and move a resonable distance from the objects bounding box
7. Release the mouse button
8. Attempt to orbit the scene
9. In some cases it behaves as expected; repeat steps 3-6 to reattempt.

**Expected**
Terminating the drag event as described should produce the same results in all cases. One expected observable aspect is the yellow color that is used to highlight the axis during the drag should revert to the original color when the mouse is released. Note the switch from yellow back in the original color in the following example: [URL]

**Actual**
After releasing the mouse outside of the general proximity of the selected object, the ability to orbit the scene is lost and the camera view remains fixed. In addition, the color of the axis arrow remains yellow as can be noted in the following example: [URL]

**Workarounds**
- Reselect or select a new object. In some cases this may require multiple attempts
- Refresh the page

**Additional Info**
- Verified on Windows with the latest version of Chrome and a nightly build of FF
- Possibly regressed around   and
