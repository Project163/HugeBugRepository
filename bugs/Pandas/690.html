Title

read_csv, compression, and bad column names.

Description
Hi.  I've got a data set that I'm working with from [Link: here], the `bop_its_det.tsv.gz` file.  [Link: Direct Link]. It's about 80 MB unzipped.  I tried to create a csv of just the first 10 rows [Link: here] but I think I messed up some of the newlines.  [Link: Here's] a gist of the plain text.

I want to say up front that I'm using pandas version `0.10.0.dev-16774b3`, which I think is from a couple days before the official 10.0 beta was released, so maybe this isn't an issue anymore.

Someone in the EU's stats department decided it would be a good idea to separate some column names by columns and others by tabs so the first line looks like

```
In [332]: f = open('BulkDownloadListing.tsv', 'r')

In [333]: f.readline()
Out[333]: 'currency,post,flow,partner,geo\\time\t2011 \t2010 \t2009 \t2008 \t2007 \t2006 \t2005 \t2004 \n'
```

read_csv can handle this fine with:

```
df = pd.read_csv('BulkDownloadListing.tsv', sep=',|s*\t', na_values=[':', ' :', ': '], nrows=10)
```

when I try with the compressed file `BulkDownloadListing.gz`:

```
df = pd.read_csv('BulkDownloadListing.gz', compression='gzip', sep=',|s*\t', na_values=[':', ' :', ': '], nrows=10)
```

I get 

```
