Title

Add entryPoints option to ant compile task

Description
Ant task has manageClosureDependencies option.  

The next logical addition to make this functionality really helpful would be to able to specify entry point(s) as is possible from the command line. 

This would make ant output smaller and inputs easier to specify.

NOTE:
The AbstractCommandLineRunner uses setDependencyOptions, but the ant CompileTask uses setManageClosureDependencies.  Consider converting the ant task to use setDependencyOptions as part of this change, maybe making the createDependencyOption method part of the Compiler options so that logic is more widely available.
