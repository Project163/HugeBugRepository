Title

[ES|QL] `values` function does not return _all_ values as it dedupes them

Description
### Elasticsearch Version

8.18.1

### Installed Plugins

_No response_

### Java Version

_bundled_

### OS Version

Container

### Problem Description

The [Link: `values`] aggregation states that it returns _all_ values as a multi-valued field:

However, if 2 or more values are the same, the returned result will only include the value once, instead of having _all_ values.

### Steps to Reproduce

1. Create an index
2. Index some docs, and have a field that you want to use `values` against

```
json
POST example-index/_doc
{
  "vc": "vc0001",
  "share": 1
... [Log Snipped] ...
  "share": 3,
}
```

3. Run an ES|QL query like:

```
FROM example-index
| STATS shares = VALUES(share)
```

4. Get the response

`shares = [1, 3]`

5. Expected (based on the wording of the docs) to get

`shares = [1, 1, 3]`
