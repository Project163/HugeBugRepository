Title

@next/third-parties peerDependencies does not support Next 15 or React 19 RC

Description
### Link to the code that reproduces this issue

[URL]

### To Reproduce

On the canary branch (https://github.com/vercel/next.js/blob/canary/packages/third-parties/package.json), we see:

```
"peerDependencies": {
  "next": "^13.0.0 || ^14.0.0",
  "react": "^18.2.0"
}
```

When using this package in a canary build using Next 15 and the appropriate React 19 RC, we get warnings in various package managers.

Reproduction steps:
* Have `"@next/third-parties": "15.0.0-canary.186",` in `packages.json`
* Run `yarn install`
