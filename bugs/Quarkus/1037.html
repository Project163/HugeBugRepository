Title

Quarkus 1.13.0.CR1 dev mode fails with build exception on Apple Silicon machine

Description
## Describe the bug
Quarkus dev mode fails with 1.13.0.CR1 on arm64 and x86_64 Java when using MacBook with M1 processor. 

I verified it works on my Intel machine (although using java 15 not java 11). On the M1 machine package jar and native build also run fine. 

Quarkus dev mode running 1.12.x works fine on M1 Mac.

## To Reproduce

Download quarkus-quickstarts. Go to getting started and adjust pom file to use 1.13.0.CR1. 

Steps to reproduce the behavior:
1. Download quarkus-quickstarts
2. In getting-started adjust pom to use `1.13.0.CR1`
3. run `mvn compile quarkus:dev`
