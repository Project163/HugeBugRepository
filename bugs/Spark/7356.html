Title

AQE doesn't adequately allow for Columnar Processing extension

Description
In   SPARK-27396   we added support to extended Columnar Processing. We did the initial work as to what we thought was sufficient but adaptive query execution was being developed at the same time. 

 We have discovered that the changes made to AQE are not sufficient for users to properly extend it for columnar processing because AQE hardcodes to look for specific classes/execs.
