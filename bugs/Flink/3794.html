- AFAIK Netty uses Direct Memory in Java 11, but not in Java 8. In Java 8 it uses some unsafe memory allocation, similar as Flink does in 1.10, but drops that from Java 9 onwards due to the more restrictive access control (Jigsaw modules) to avoid the "illegal reflective access" warnings that we also currently see in Flink.
