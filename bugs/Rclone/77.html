Title

Starting bandwidth limiter at xxBytes/s prints to stdout regardless of --log-file switch

Description
Version: rclone v1.29
OS: ubuntu 16.04
Cloud Storage: ACD
Command: rclone --log-file tmp.txt move src dst (same behavior with copy)

When using the --log-file switch just about everything goes to the log file except the "Starting bandwidth limiter at xxBytes/s"  which goes to stdout regardless of the switch

Should be a pretty easy fix to just switch that message output to log.printf from the current Log implementation in fs/accounting.go
