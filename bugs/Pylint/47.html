Title

broad-except suppressed when catching several exception types

Description
Originally reported by: **BitBucket: [Link: moxian], GitHub: @moxian?**

---

The code

```
#!python
def main():
  try:
    pass
  except Exception:
... [Log Snipped] ...
if __name__ == '__main__':
  main()
```

promptly issues a warning:

```
W:  4, 9: Catching too general exception Exception (broad-except)
```

While a similar one, which is just as bad

```
#!python
def main():
  try:
    pass
  except Exception:
... [Log Snipped] ...
if __name__ == '__main__':
  main()
```

does not.
