Title

HttpClientCodec may produce empty ByteBufs when CONNECT is used

Description
At the moment once CONNECT is received in  HttpClientCodec we use :

``` java
                return buffer.readBytes(actualReadableBytes());
```

This may produce an empty ByteBuf if decode(..) is called because of decodeLast(..). We need to check if the actual readable bytes are 0 and if so return null
