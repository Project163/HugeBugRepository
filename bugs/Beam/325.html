Title

Build beam-sdks-java-maven-archetypes-examples Failed If Dir Contains Space

Description
Error log from  Jenkins console log : 
  
 rsync: change_dir  "/home/jenkins/jenkins-slave/workspace/beam_PostCommit_Java_JDK_Versions_Test/jdk\#012.\#012(latest)/label/beam/sdks/java/maven-archetypes/examples/../../../../examples/java/src/main/java/org/apache/beam/examples"  failed: No such file or directory (2)
rsync error: some files/attrs were not transferred (see previous errors) (code 23) at main.c(1183) [sender=3.1.0]
2017-05-03\T\19:20:56.905 [ERROR] Command execution failed.
 
  

 beam-sdks-java-maven-archetypes-examples execute a  bash script  through  exec-maven-plugin . Looks like it fails to create a directory which contains space in  previous step . The root directory of above build is "/home/jenkins/jenkins-slave/workspace/beam_PostCommit_Java_JDK_Versions_Test/jdk/JDK 1.8 (latest)/label/beam/...". 

 Similar error also happens in  JDK1.7  and  OpenJDK7 . 

 I simply run  generate-sources.sh  from my Linux machine in JDK1.8 under contain-space directory and it works perfectly. I guess exec-maven-plugin works differently when handling bash commands that contains space, but I failed to solve this problem by modifying commands in script.
Discussion
- I replaced "$(dirname $0)" with "$( cd "$( dirname '$0' )" && pwd )" in  generate-sources.sh  and solve the problem.  

 Test is done on the Jenkins. Will send out a PR soon.
