Title

DataFrame.write.format("text") requires the column name to be called value

Description
We should support writing any DataFrame that has a single string column, independent of the name. 

  
 wiki.select( "text" )
  .limit(10000)
  .write
  .format( "text" )
  .mode( "overwrite" )
  .save( "/home/michael/wiki.txt" )
