RESTEasy Reactive: Customised Jackson ObjectMapper not used

Description

If the ObjectMapper is customised then it should be used when serialising JSON as it does with normal RestEASY.

Actual behavior
Some other ObjectMapper is being used, causing customised mapping to be ignored.
