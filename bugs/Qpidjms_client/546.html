Title

[Java Client] The client does not fail with a sensible error message if it tries to send a message header that is larger than the max frame size

Description
If the message headers for an 0-9 message are large enough that they cannot fit inside the agreed max frame size, then the client should fail before sending (and if such an oversized frame arrives at the broker then the failure message should be more helpful).
