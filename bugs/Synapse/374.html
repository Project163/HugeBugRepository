Title

Fail Safe mode does not work when artifact configurations contain xml syntax errors

Description
Even though we enable fail safe mode for artifacts, If at least one artifact configuration contains a xml error server get hanged during the startup.  
Ideally when fail safe mode is enabled, server should start skipping the faulty artifact deployment.
Discussion
- Please find the patch to fix this issue from the attachment. 

 After applying this patch, If fail safe mode is enabled, instead of hanging the server start up, it will start giving a proper error message for faulty artifact configurations.
- Applied the patch with some changes. Changes done were mainly to prevent the unnecessary wrapping of the exceptions. Thanks Isuru for the contribution.
