Title

Mixed is inserted when summing arrays

Description
```
php
$arr = [1, 1, 1, 1, 2, 5, 3, 2];
$cumulative = [];

foreach ($arr as $val) {
... [Log Snipped] ...
    }
}
```

Expected: no issues
Actual: Psalm complains about `MixedAssignment` (in `totallyTyped` mode)

Can be avoided by doing something like 

```php
foreach ($arr as $val) {
    if (!isset($cumulative[$val])) {
        $cumulative[$val] = 0;
    }
    $cumulative[$val] = $cumulative[$val] + 1;
}
```

or by adding a docblock to `$cumulative = []` suggesting that it will only contains ints
Discussion
- One solution would be to have an `unknown` flag on a `mixed` type to allow it to be combined with the first available type
