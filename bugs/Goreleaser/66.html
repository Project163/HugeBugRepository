Title

Doc: 404 errors on .gorelease.yml customization sub-categories pages

Description
**Describe the bug**

Sometimes customization sub-categories links are broken.

**To Reproduce**

When you are on the [Link: Quick Start Page] and you click on the `Customize` link after the `gorelease init` code block, the redirection works but every sub-categories (Archives, Blobs, ...) links are broken.

Only a `404 Not Found` title is shown

[Image: image]

The links seems to be wrong

For example:

```text
[URL]
```

**Expected behavior**

Pages should work and show the expected documentation.

**Additional context**

Tested on Firefox `79.0b2`
Discussion
- I think it doesn't work because the generated nav items are relative URLs and the link to Customization in the page you mentioned is `[URL] which misses the final `/`. The browser will try to bring you to a non-existent page since it will take you to the wrong location (looking for Blobs inside root dir instead of customization).

I think this could be due to the way docs are being served. If you serve the docs locally with `mkdocs serve` then everything works as expected. I guess mkdocs knows automatically append the final `/` in the case it's missing. The fix could be to make sure all references in the docs end with a `/`, or look into how the docs are being served and make sure it's basically equivalant to `mkdocs serve`.
