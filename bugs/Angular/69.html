Title

Bootstrap throws errors in safari

Description
To repro: Load the hello world example in safari.
Stack trace: [URL]
Discussion

- Found the root cause of the issue.

In Safari, `MapIterator` doesn't implement `next()`,
which is used in the traceur-runtime's polyfill of `Array.from`,
which is used in `MapWrapper.keys()` and `MapWrapper.values()` in Angular2's facade.
This makes about 860 unit tests to fail.

Not sure if we should try to fix Traceur knowing that it should go away, or if we should work around this bug. Any thoughts please?
- It appears the issue has been addressed in latest version of traceur-runtime/0.0.91 (was previously using version 0.0.89 and experienced the same issue when running under Safari - runs fine with latest traceur).
