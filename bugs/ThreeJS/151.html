Title

Warnings upon selecting Camera on empty Editor

Description
##### Description of the problem 

1. Open the THREE.js Editor
2. Click: File > New
3. On the right hand side under the 'SCENE' tab, select the 'Camera' from the list of children
4. Just move the mouse pointer on the canvas area.
This triggers the warning (open console to see it): "THREE.Matrix4.getInverse(): can't invert matrix, determinant is 0" which keeps appearing until 'Camera' is unselected.
