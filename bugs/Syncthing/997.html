- So I don't think we support junctions, though we do (or try to) support symlinks.

If you run Syncthing as administrator on Windows, the symlink should get synced properly.

The reason it gets ignored is most likely because of not having permissions to create one.
The fact that you cannot create one is probably the reason you get these issues.
