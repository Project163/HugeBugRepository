Title

yii2-composer can't make extensions.php file

Description
Well we have code in Installer::loadExtensions()
$extensions = require($file);

If we want to have more then one extension (yii2-debug, yii2-gii for instance), we got only one - the last one in extensions.php file.

It is only true if opcode cache is enabled for cli. (that was my case)
I added line with opcache_reset(), to flush cache of the $file.

So i see 3 options to fix it.
1) Add information in manual to disable opcache in cli. (or any other cacher)
2) Flush cache before require (separte method with few function_exits())
3) Change require in favor of stream functions + parsing;
