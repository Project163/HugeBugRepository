Title

An empty integer collection doesn't map over a collection with values.

Description
```
void Main()
{
    Mapper.CreateMap ();
    var target = Mapper.Map(new SourceObj(), new TargetObj());
}
... [Log Snipped] ...
    public IEnumerable  IntCollection { get; set; } = new[] {1,2,3,4,5};
}
```

The expectation is that `TargetObj` will have an empty array after mapping. Instead it has an array of the original length, but all items are set to the default.

[Image: automapper_output]
Discussion
- As a workaround you can use int[] in the destination.
- This seems to work on develop.
