Title

Avoid logging Warning when packet could fit into read buffer

Description
When memory limit happens we are not allowed to allocate extra buffer for reading packets, and the following message could appear in logs:
```
W0404 04:12:26.048256 17327 binary_call_parser.cc:67] Unable to allocate read buffer because of limit, required: 41153
```

But such small messages could be fully read into read buffer, so they will be processed anyway.

We should avoid logging of such Warning in this case.
