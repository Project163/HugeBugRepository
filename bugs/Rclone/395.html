Description

- Try `--s3-upload-cutoff 0`

Does that fix it?

Which version of CEPH are you using?

I use ceph luminous in the integration tests which are working fine.
- That works. So there is only an issue with single part uploads?


It's an older version, 10.2.x jewel.
- Previous to 1.46 the s3 library used multipart uploads for all files bigger than 5MB.  I decided to upload smaller files using a single part upload, but the library lacked the abstraction I needed so I worked around it by using signed URLs.  This was 100% successful in my testing, but alas I didn't test CEPH jewel.

Putting `--s3-upload-cutoff 0` will revert to the old behaviour, and you can put `upload_cutoff 0` in the config file too if you want.

Is that an acceptable work-around?

So I'd say this is a compatibility issue with CEPH jewel
