Title

NoSuchMethodError: org.apache.spark.ui.SparkUI.appUIAddress() for the spark master

Description
This happens on the latest spark master. Because spark remove the method SparkUI.appUIAddress(), and this is private method, we should try to use private method as less as possible. Instead we should use SparkContext.uiWebUrl

			 What is this PR for? 
    `SparkUI.addUIAddress` is removed in spark master which cause this error. Actually spark 2.0 introduce new api `SparkContext.uiWebUrl` (  SPARK-14576  ) which is public in contrast `SparkUI.addUIAddress` is private. This PR would use `SparkUI.addUIAddress` for spark 1 and `SparkContext.uiWebUrl`  for spark 2.
