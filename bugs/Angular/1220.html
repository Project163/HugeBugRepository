- @vraddy we are confusing the conversation here a bit by discussing 2 separate issues, I'm afraid. So, the problem that you are raising here is that Angular will create a HTML element corresponding to a component (` ` in your example) that we call host element. The issue is that ` ` is not a valid element that can be used with SVGs hence a browser doesn't render it. This is a well known issue with SVG support in Angular. It can be worked around by using an attribute selector for a component:
[URL]

To sum, we've got 2 problems here:
* Angular creating host element that doesn't play nice with SVG use-cases
* Angular template parser bug when ones put a ` ` inside ` `. Reproduction:  [URL]
