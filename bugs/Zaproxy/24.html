Title

Forced Browse/AJAX Spider messages not restored to Sites tab

Description
From #1627

Steps to reproduce the issue:
1. Run ZAP;
2. Persist the session;
3. Run the Forced Browse and AJAX Spider;
4. Note the Forced Browse and AJAX Spider messages in "Sites" tab;
5. Create a new session and reopen the previously saved session;
6. Note that the Forced Browse and AJAX Spider messages are no longer shown.

Remarks:
The messages are properly restored if an alert is raised on them (either by passive/active scans or manually).

ZAP Versions:
Versions >= 2.0.0 (for Forced Browse, AJAX Spider since it was added)
