Title

Too easy to `cancel` inactive Tasks

Description
**Problem**
The `Task` interface has a method called `cancel` which is intended to allow devs to cancel long running tasks. However, this API is easy to misuse accidentally. For example, our examples encourage risky usage [Link: here] and [Link: here]. These are risky because the task should first be check using `is_active()` before canceling.

Related to [URL]
 

**Proposed behavior**
We should rely on `Drop` to cancel the task and remove the `cancel` method from the `Task` interface.
