Title

@import css bug

Description
Given this main.less stylesheet:

```
@import "reset.less"
@import "base.css"
```

and a directory structure that looks like this:

```
project
---styles
------main.less
------reset.less
------base.css
```

When I use LESS in Node everything is fine - main.less can import base.css. But when I use less.js in the browser, it can't find it because it's no longer looking relative to the main.less file, but relative to the index.html where less.js is used.
