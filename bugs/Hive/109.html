Title

metastore should not use HADOOPFS variable value directly

Description
hadoop uses a uri for the file system that first does a reverse resolution of the fs.default.name ip address section (in case ip address is used). hive uses the un-resolved one. this causes url mismatch exceptions in load command (for example - localhost.localdomain does not match  ). 

 fix is to use the uri given back by the filesystem object.
