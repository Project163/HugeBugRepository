Title

Domain should added separately for SMB mount(Not in username)

Description
I'm running hyper-v on windows8.1 pro. I have problem with /vargrant folder mount using SMB.

On command prompt it says

```
Batchfile
Failed to mount folders in Linux guest. This is usually because
the "vboxsf" file system is not available. Please verify that
the guest additions are properly installed in the guest and
can work properly. The command attempted was:
... [Log Snipped] ...

mount -t cifs -o uid=`id -u vagrant`,gid=`id -g vagrant`,sec=ntlm,username=babple/spoon,pass='PASSWORDHIDDEN' // /  /vagrant
```

So I tried those commands on ssh, but it fails with Permmision denied.
However when I tried below comman it success.

``` bash
sudo mount -t cifs -o uid=`id -u vagrant`,gid=`getent group vagrant | cut -d: -f3`,sec=ntlm,username=spoon,pass='MYPASSWORD',domain=babple // /  /vagrant
```

I think domain parameter should use separately for domain not in username.
