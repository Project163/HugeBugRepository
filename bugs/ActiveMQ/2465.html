Title

The DiskBenchmark util doesn't sync (fsync) to disk for sync writes

Description
We added a JVM flag, org.apache.activemq.file.skipMetadataUpdate, to control whether to force metadata syncs or not when sync'ing to disk. Unfortunately, that flag was not applied to the section of code that does the sync writes.
