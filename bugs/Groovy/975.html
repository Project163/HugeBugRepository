Title

@Delegate not working when it refers to a Map

Description
If you use the @Delegate to mark a Map as a Delegate you'll get an error: 

 java.lang.NullPointerException: Cannot invoke method put() on null object 

 It can be illustrated with this example: 

 class Test { 
    @Delegate Map mp 
} 

 def t = new Test(mp: new HashMap()) 

 println t.keySet() 

 I originally noticed it when trying it with a GroovyRowResult (same error as above): 

 import groovy.sql.GroovyRowResult 

 class DelegateRowResult { 
	@Delegate GroovyRowResult row 
	String foo 
} 

 DelegateRowResult d = new DelegateRowResult( foo: "Boo") 
println "$d.foo"
Discussion
- As a workaround, if these Map interface based delegates are defined as @Delegate(interfaces=false), then it works. 

 The reason for the failure reported is that MetaClassImpl handle class implementing Map interface differently to support map.x = "y" kind of calls.  

 If we don't want to change that special handling in MetaClassImpl for Map, then one way of solving the issue reported is that in a class like  

 class Test { 
 @Delegate MyType mp // MyType implements interfaces Map, A, B 
} 

 then class Test generated should implement only A, B and exclude Map. It will be like antidote for Map's special handling in MetaClassImpl
- Not sure about the solution - whether to make changes around the special map handling in MetaClassImpl or to not make the class owning the Map delegate implement the Map interface. If someone has a suggestion, I can give that a try.
