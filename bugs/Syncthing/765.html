Title

Local Additions when deleting file after changing folder type from SR to RO

Description
Now, if this is really intended, please close the issue, but I think that it is a little bit unexpected that unshared Receive Only folders can even have local additions.

Case 1:

1. Create a new Receive Only folder and keep it unshared.
2. Add some files/folders to it.
3. The folder is now marked Local Additions.

Case 2:

1. Create a new Send & Receive folder and keep it unshared.
2. Add some files/folders to it.
3. Change the folder type to Receive Only.
4. Delete the previously added files.
5. The folder is now marked Local Additions, but the revert button does nothing (as the folder is unshared, and thus cannot "undelete" the removed files).
Discussion
- Case 1 is expected.

Case 2 is indeed a not covered corner case that needs fixing.
