Title

camel-elsql - Does not read named parameter from header properties

Description
Camel-elsql could not lookup for parameters from message headers. Problem is here  [URL]

 Sample route: 
  
 from( "direct:projects" )
  .setHeader( "lic" , constant( "ASF" ))
  .setHeader( "min" , constant(123))
  .to( "elsql:projects:com/foo/projects.elsql" )
 
  

 ElSql: 
  
 @NAME(projects)
  SELECT *
  FROM projects
  WHERE license = :lic AND id > :min
  ORDER BY id
