Discussion
- Data query permission refers to whether the user has the permission to view the data in the table. Belongs to data permissions. Restrictions are required. 

   

 Sampling and reloading tables are operations on tables. Belongs to administrative permissions. There are no restrictions. 

   

 When the user does not have data query permission in the project, the actual sampled data will not be returned in the following interface
