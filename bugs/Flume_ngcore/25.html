- This is a one-line patch to include log4j in the runtime distribution. In trunk, due to the single line which is removed in the patch, log4j is only included during the test phase, which means that the flume-ng script is broken when run from the distribution. See the stack trace above for the error you get when you try to run the flume-ng script.
