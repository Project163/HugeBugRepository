Even if we don't want to bring it back, there are a few other problems:

1. The argument was (and still is) [Link: publicly documented]. It probably should have had a deprecation cycle before it was removed.
2. @rafaelfranca [Link: said] that backends which need the argument can define it, but that won't work with the local cache strategy since [Link: it overrides the method and forces it to be 0-arity].  
3. The [Link: MemCacheStore] and [Link: MemoryStore] backends still declare the argument, even though they don't use it.
