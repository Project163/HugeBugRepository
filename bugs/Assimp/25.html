Title

Segfault when importing GLTF1/2 with triangle strip or triangle fan

Description
gltf1 and gltf2 with Triangle Strip and Triangle Fan primitive generates a segfault.

You can reproduce this issue using models here:
[URL]

Indeed, we access faces[2].mIndices[2] on the first iteration, which is undefined.
```
                    case PrimitiveMode_TRIANGLE_FAN:
                        nFaces = count - 2;
                        faces = new aiFace[nFaces];
                        SetFace(faces[0], data.GetUInt(0), data.GetUInt(1), data.GetUInt(2));
                        for (unsigned int i = 3; i < count; ++i) {
                            SetFace(faces[i - 2], faces[0].mIndices[0], faces[i - 1].mIndices[2], data.GetUInt(i));
                        }
                        break;
```
