Title

phpunit/phpunit-selenium does not work with PHPUnit 8.5.9

Description
#### Summary

After update from 8.5.8 to 8.5.9 phpunit seems to be "testing" all the internal methods of the Selenium2TestCase.

#### Current behaviour

A simple Selenium2TestCase test fails, with hundreds of failed tests.

```
PHPUnit 8.5.9 by Sebastian Bergmann and contributors.

Runtime:       PHP 7.3.19-1~deb10u1

Unnamed Tests (App\Tests\UnnamedTests)
... [Log Snipped] ...
   │
^C
```

#### How to reproduce

Clone my simple test case
```
git clone [URL]
cd phpunit_selenium_test
composer install
vendor/bin/phpunit -v test.php --testdox
```
See here one test is ran, as expected. Now update phpunit and try again:
```
composer require phpunit/phpunit:8.5.9 --update-with-dependencies
vendor/bin/phpunit -v test.php --testdox
```
Now there are hundreds of tests being executed that aren't even defined in test.php.

#### Expected behaviour

The single test defined in test.php is executed.

More details at: [URL]

Discussion
- I've done a git bisect:

```
  is the first bad commit
commit  
Author: Sebastian Bergmann  
Date:   Sun Sep 27 17:14:46 2020 +0200

... [Log Snipped] ...
:040000 040000     M	src
:040000 040000     M	tests
```
- `phpunit/phpunit-selenium` uses `PHPUnit\Framework\TestSuite` although this class is marked as `@internal` and therefore must not be used outside of PHPUnit itself.

The correct fix would be for `phpunit/phpunit-selenium` to no longer unconditionally call `addTestMethod()` and instead ensure it only calls this method with a valid method.

That being said, I will revert the change in the `8.5` branch. However, I will not revert this change in the `9.4` and `master` branches.
