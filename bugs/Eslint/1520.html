Title

Bug: comma-spacing is conflicting with array-bracket-spacing

Description
### Environment

Node version: v16.15.1
npm version: v8.11.0
Local ESLint version: v8.18.0 (Currently used)
Global ESLint version: Not found
Operating System: darwin 21.4.0

### What parser are you using?

@typescript-eslint/parser

### What did you do?

You can see an ESLint demo [Link: here]

 
 Configuration 

```
json
{
    "env": {
        "browser": true,
        "es2020": true
... [Log Snipped] ...
    }
}
```
 

```js
tsts = [1, 2, 3, 4,];  // A space is required after ','. eslint(comma-spacing)
tsts = [1, 2, 3, 4, ];  // There should be no space before ']'. eslint(array-bracket-spacing)
```

### What did you expect to happen?

I was expecting the `array-bracket-spacing` rule to take over the `comma-spacing` rule and allow the first line as linted

### What actually happened?

- `array-bracket-spacing` requires there to be no space before the close bracket
- `comma-spacing` requires there to be a space after the final comma

Therefore, we have a conflict.
