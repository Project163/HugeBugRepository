Title

Util.getSchemaFromString fails with java.lang.NullPointerException when a tuple in a bag has no name (as when used in MongoStorage UDF)

Description
The MongoStorage UDF (  [URL] ) fails on its call to Util.getSchemaFromString when a tuple is not named.  The call succeeds when the tuple is explicitly named.  As tuple naming is optional, this is a bug.
