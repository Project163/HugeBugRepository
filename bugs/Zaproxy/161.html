Title

Add-on files not updated when running newer ZAP/core version

Description
Reported in IRC channel.

Steps to reproduce the issue:
1. Run ZAP 2.5.0 with custom home directory (easier to reproduce the issue, same behaviour with default directory);
2. Check Scripts > Templates > Fuzzer HTTP Processor > Fuzzer HTTP Processor default template.js;
3. Quit ZAP 2.5.0 and run ZAP 2.6.0 (with same custom home directory);
4. Note that the template is the same;
5. Run ZAP 2.6.0 with another custom home directory;
6. Note that the template is now different, as expected, version 2.6.0 contains a newer version of the Fuzzer add-on with updated templates.

Remarks:
The files are properly updated when the newer version of the add-on is (explicitly) installed (e.g. updated through the marketplace).

ZAP version:
Version 2.6.0 (same happens with older versions).
