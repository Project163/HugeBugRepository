Title

In Default ErrorView render by `yii\web\ErrorAction` ，the `Yii::$app->response->statusCode` is not correct

Description
### What steps will reproduce the problem?
use  `Composer` to initialize  a clean Yii2 advanced app template
in `frontend/views/site/error.php`   add the following line
```php
 response->statusCode?>
```
then, navigate to `a none-existing Url Location` in Browser,such as `[URL]


### What is the expected result?

the above PHP code added to   `frontend/views/site/error.php`    should output `404`

### What do you get instead?
the  above PHP code added to   `frontend/views/site/error.php`    just output `200`  in page content
 **_this is not correct_**

**Note:** HTTP code in Browser is 404, **_this is correct_**.
