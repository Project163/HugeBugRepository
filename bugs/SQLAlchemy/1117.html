Title

syntax error from sqlite when executing an insert with multiple rows but no non-default columns

Description
**Describe the bug**
Executing an insert of multiple rows into a sqlite table with a single autoincrement column works in sqlalchemy 1.3.24, but raises an OperationalError in sqlalchemy 1.4.7.

**Expected behavior**
Expected the insert to succeed.

**To Reproduce**

```
py
from sqlalchemy import Column, Integer, MetaData, Table, create_engine

engine = create_engine("sqlite:///test.db")
with engine.connect() as conn:
... [Log Snipped] ...

    conn.execute(table.insert(), ({}, {}))
```
