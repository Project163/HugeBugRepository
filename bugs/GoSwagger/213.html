Title

Required object value without type produces broken validator "Another bug" ... [Log Snipped] ... 200:

Description
## Problem statement

Required object value without type produces broken validator.

## Swagger specification

```
yaml
swagger: "2.0"
info:
  version: "1.0.0"
"OK"
```

## Steps to reproduce

Generate models or entire server from this specification.

Models validator will be like this:
```
go
type Object struct {
	// Value of the tag
	// Required: true
	Value interface{} `json:"value"`
... [Log Snipped] ...
	return nil
}
```

Function `validateValue` calls `openapi.validate.Required` function [URL] with given value type of `interface`.

Since given value is not pointer  `openapi.validate.Required` will return error on any incomming default value, for example, `false` for `boolean` type or `0` for `integer`.

If we add type to our field then `openapi.validate.Required` will recieve pointer and validation will successed.

Simple example [URL]

## Environment
swagger version: latest master  
go version: 1.12.7
OS: darwin/amd64

## Possible sollution

Codegen should produce required fields without type as `*interface{}` instead of `interface{}`.
