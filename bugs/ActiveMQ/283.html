Title

Incorrect value for QueueCount attribute after broker restart

Description
When using a persistent broker with AMQ message store, the QueueCount attribute on those queues which have messages in them has incorrect value after the broker is restarted. Although the messages can be viewed by browsing the queue, the web console as well as the JMX console display a value of zero for the queue once the broker is restarted. 

 Both consoles should display the count of the number of messages in the queue accurately in the QueueCount attribute after the broker restarts.
