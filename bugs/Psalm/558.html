Title

SimpleXMLElement can be passed to count()

Description
SimpleXMLElement objects are a bit weird, they do not implement \Countable but can be passed to count() without issue.

Following snippet should probably not yield an InvalidArgument issue on count():
```php
       ');
echo count($xml); // InvalidArgument - Argument 1 of count expects array |Countable, SimpleXMLElement provided
```
