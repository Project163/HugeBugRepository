Discussion
- `ClippingMediaSource` doesn't support clipping unseekable media files to a non-zero start position. If you just play the file without clipping you can observe that `Player.isCurrentWindowSeekable()` is false, meaning the clipping start of 1 second won't work.

The problem is that the nicely readable `IllegalClippingException` isn't thrown, making it hard to understand the error. I'll mark this as a bug to fix this particular problem.
- but why the second way works fine?
- I used the second way (with `MediaItem`) when testing the file and it didn't work. So I think the problem occurs in both cases.
