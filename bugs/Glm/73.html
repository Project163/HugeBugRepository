Title

GLM requires CUDA 3.0 or higher - error when compiling using nvcc

Description
When I compile a .cu-file using nvcc and cuda.h is _not_ included, compilation fails.
A very simple example:

 test.cu: 

``` cpp
#include  

int main (void)
{
        return 0;
}
```

 
$ nvcc test.cu -I/opt/glm-0.9.5
In file included from /opt/glm-0.9.5/glm/detail/type_int.hpp:32:0,
                 from /opt/glm-0.9.5/glm/fwd.hpp:32,
                 from /opt/glm-0.9.5/glm/glm.hpp:88,
                 from test.cu:1:
/opt/glm-0.9.5/glm/detail/setup.hpp:215:4: error: #error "GLM requires CUDA 3.0 or higher"
/opt/glm-0.9.5/glm/detail/setup.hpp:317:2: error: #error "GLM_COMPILER undefined, your compiler may not be supported by GLM. Add #define GLM_COMPILER 0 to ignore this message."

 

The reason for this error is that nvcc does not define  CUDA_VERSION , it is only defined if cuda.h is included.

 cuda.h 

``` cpp
...
#define CUDA_VERSION 5050
...
```

A solution could be to include cuda.h from setup.hpp:
 setup.hpp 

```
cpp
...
// CUDA
#elif defined(__CUDACC__)
#       include   // make sure this file is included, otherwise CUDA_VERSION will not be defined
... [Log Snipped] ...
#       endif
...
```

My setup: CUDA 5.5, glm 0.9.5
