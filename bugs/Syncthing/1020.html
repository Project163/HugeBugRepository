Title

Junctions as dirs doesn't work anymore

Description
### What happened?

I used to be able to sync the contents of NTFS junction directories. I recently noticed that it doesn't seem to work anymore.

I tried on 2 different machines, one with admin/systemwide install, the other with user install. On the systemwide install I added SyncthingServiceAcct to the perms on the sync'ed folder. The _Junctions as dirs_ option is set.
