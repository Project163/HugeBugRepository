Title

TransformOutInterceptor may lose namespace declarations in some elements

Description
When TransformOutputInterceptor is used to process a list of elements with the same namespace that is declared locally, some namespace declarations may not be correctly seriazlied. 

 Given the input message 
<soap:Envelope xmlns:soap="[URL]
  <soap:Header> 
    <Action xmlns="[URL] href="[URL] class="external-link" target="_blank" rel="nofollow noopener">[URL]
    <MessageID xmlns="[URL]
    ... 

 and transforming the namespace from "[URL] to "[URL] may lose the namespace declaration in the second element as in: 

 <soap:Envelope xmlns:soap="[URL]
  <soap:Header> 
    <Action xmlns="[URL] href="[URL] class="external-link" target="_blank" rel="nofollow noopener">[URL]
    <MessageID>urn:uuid:fac787f8-db6e-4606-a76c-c45ed3bbba4d</MessageID> 
    ... 

 The correct output message should carry the namespace declaration as in 

 <soap:Envelope xmlns:soap="[URL]
  <soap:Header> 
    <Action xmlns="[URL] href="[URL] class="external-link" target="_blank" rel="nofollow noopener">[URL]
    <MessageID xmlns="[URL]
    ...
