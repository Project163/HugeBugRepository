Title

quotes does not catch errors in strings wrapped in {...} within jsx

Description
**What version are you using?**
3.4.0

**What did you do?**
Run lint with `quotes` rule turned on (prefer single quotes) over jsx code that looks like:
` `

**What happened?**
The linter passed, when it should have errored on the double quotes. This is not covered by jsx-quotes because the string is wrapped in `{...}`, which makes it a JS string and not a jsx string.

**What did you expect to happen?**
Error for violating the `quotes` rule
Discussion
- Verified with the following code:

``` js
/*eslint quotes: ["error", "single"] */
/*eslint jsx-quotes: ["error", "prefer-single"]*/

function a() {
    return  ;
}
```
