Discussion
- This also affects earlier Groovy releases when "indy" compiler option is enabled.
- Another example involves grab and use: 
  
 
 import  groovy.transform.stc.*
@Grab( 'io.vavr:vavr:0.10.4' )
 import  io.vavr.control.Try

@groovy.transform.ToString
 class  Id {
}
Id resolveId() {
   new  Id()
}

 class  Cat10714 {
  static <V> Try<V> andThen(Try<V> t, @ClosureParams(value=FromString,options= "V" ) Closure c) {
     if  (!t.isFailure()) {
       try  {
        c.call(t.get())
      }  catch  (Throwable e) {
         return  Try.failure(e)
      }
    }
     return  t
  }
}

 def  test2() {
  use (Cat10714) {
    Try.of( this ::resolveId).andThen { id -> id.toString() }
  }
}

print(test2())
 
  
 This may be further reduced by commenting out "use ..." as well as ".andThen ...". 

  Try.ofCallable(this::resolveId)  works fine.
