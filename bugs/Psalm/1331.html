Title

@no-named-arguments may violate implements/extends contract

Description
In this situation usage of `no-named-arguments` violates contract of `Foo::foo`.
It requires `array `. But `Bar::foo` requires more concrete type `list `.
This snippet should trigger `MethodSignatureMismatch`. Actually no issues.

```
php
 foo(name: ''); // may cause runtime error
```
