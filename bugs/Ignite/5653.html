Title

Add authorization of Compute Task Job cancellation

Description
We need to add authorization to cancel a Compute Task. Compute Tasks can be canceled explicitly using ComputeTaskFuture#getTaskSession()#getJobSiblings(), but unlike ComputeTaskFuture#cancel(), this operation is performed without permission checks. 

 This also affects the control.sh --kill compute command. Even if the user doesn't have the TASK_CANCEL permission, all tasks will be terminated after this command is run.
