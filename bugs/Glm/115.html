Title

gtc_packing signed to unsigned conversion warnings

Description
The functions `floatTo11bit` and `floatTo10bit` used by GLM_GTC_packing both return unsigned integers, and they both contain the statement `return ~0;`.

This should use an unsigned literal zero to avoid warnings about conversion from `int` to `unsigned int`:

```
return ~0u;
```
Discussion
- This issue should be fixed in GLM 0.9.6 for GLM   release.
