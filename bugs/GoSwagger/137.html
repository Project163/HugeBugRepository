Title

mixin removes securityDefinitions

Description
## Problem statement
when mixing 2 specs with OAuth2 securityDefinitions, the resulting merged spec keeps the security specifications at the operation level but omits the top level securityDefinition, resulting in an invalid spec.

## Environment
swagger version: current master
go version: 1.9.1
OS:   ubuntu
Discussion
- Workaround: manually inserted the same securityDefinitions in both specs and it works
