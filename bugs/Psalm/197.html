Title

Unset on objectlike array should reset it to empty array

Description
```php
function takesInt(int $i) : void {}
$x = ['a' => 'value'];
unset($x['a']);
$x []= 5;
takesInt($x[0]); //Erroneous PossiblyInvalidArgument here
```
Discussion
- And from @TysonAndre, this *should* be a failure

```php
$x = ['a' => 'value', 'b' => 'value'];
unset($x['a']);
echo $x['a'];  // type for $x is still array{a:string, b:string}
```
