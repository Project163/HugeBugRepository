Title

@media import fails

Description
```
@media print{
  @import "@{libPath}/_print.less";
}
```

Throws exception in 1.5.0 but worked in 1.4.2
 non_object_property_callError: Cannot call method 'variable'

Moving the "@media print" block inside the import file and just importing the file works fine in 1.5.0

```
@import "@{libPath}/_print.less";
```
Discussion
- You can fix this by putting the media path on the import statement (just
print after the filename) however, we should fix this.
- This change in the syntax was not obvious as a breaking change. 

Also if more than one file to be imported for print then final output has multiple media print queries, bloating the final css file. Wouldn't be and issue if all similar media queries were combined :)

+1 for fixing and flagging as bug.
- Merged to master, will be in the next release
