Title

relation "typeorm_metadata" does not exist while creating a view in migration

Description
## Issue Description

This issue is probably related to [Link: 4923], pull request [Link: 4956] doesn't seem to work here.

### Expected Behavior

I try to implement a migration that creates views for postgres. Before that migration another migration installs all tables successfully (fresh installation). I'm running the migrations manually using the typeorm-cli.

I'm using the following code to create a view (just for testing before implementing the real query):

```
`typescript
 console.log(`Create view...`);
    await queryRunner.createView(new View({
      name: 'tool_view',
      materialized: false,
... [Log Snipped] ...
      }
    }));
````

It should create a view that just represents the same table as "tool".

### Actual Behavior

I get the following error message:

```
`
QueryFailedError: relation "typeorm_metadata" does not exist
    at PostgresQueryRunner.query (/snapshot/project/node_modules/typeorm/driver/postgres/PostgresQueryRunner.js:211:19)
    at processTicksAndRejections (node:internal/process/task_queues:96:5)
    at async PostgresQueryRunner.executeQueries (/snapshot/project/node_modules/typeorm/query-runner/BaseQueryRunner.js:421:13)
... [Log Snipped] ...
  routine: 'parserOpenTable'
}
````


### Steps to Reproduce

1. Create a Datasource connection for PostgreSQL
2. Create a migration and implement code that creates any view.
3. Run the migration using the typeorm -cli.

### Possible solution

Create "typeorm_metadata" automatically next to "typeorm_migrations" table. That would ensure that the typeorm_metadata table exists.

Discussion
- got the same with typeorm version 0.3.15.
How to fix that?
- Okay, here we go: [URL]
- I first had the same problem with `0.3.20` but it was a wrong configuration on the server. Be sure to configure your `TYPEORM_ENTITIES` or `entities` in `ormconfig.ts` accordingly. I wasn't including the views, only the entities, which I already had changed locally for migration generation. Proper value for my case on the server:

```
TYPEORM_ENTITIES=dist/**/*.{entity,view}.js
```
Locally during development:
```
TYPEORM_ENTITIES=src/**/*.{entity,view}.ts
```
