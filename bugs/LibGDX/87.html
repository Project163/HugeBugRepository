Title

Delta time doesn't change when resizing the window (resizing window speeds up the game)

Description
#### Issue details
I have movement tied to the delta time in the render method but while I am resizing the window everything speeds up a bit. It seems that the delta time doesnt change when it should be affected by the window being resized. I used the method to make my own delta time for testing and that one was different to what the methods delta was giving me and it fixed the speeding up issue if I used my own one instead.
I have only tested this on linux

#### Reproduction steps/code
Create a screen that uses an ExtendViewport (just what I use, should make it easier to see) and make a sprite move around the screen, make sure it uses delta to keep it tied to the frame rate. As you are resizing the screen it will speed up the movement of the sprite.

#### Version of libGDX and/or relevant dependencies
I tested it on gdx 1.10.0. 1.11.0 and 1.12.0 and it happens on them all
