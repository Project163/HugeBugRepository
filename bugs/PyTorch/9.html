Title

torch.norm does not work when p="nuc"

Description
## 🐛 Bug

 
torch.norm does not work as expected when p="nuc" , x is a 4 dimensional tensor, dim=(2,3)
## To Reproduce

Steps to reproduce the behavior:
`
import torch

w = torch.randn(2, 1024, 3, 3)

torch.norm(w, p="fro", dim=(2,3)) ## this works fine

torch.norm(w, p="nuc", dim=(2,3)) ## this produce an error message
`

Discussion
- good find, this is a bug. We need to compute it on the last two dimensions.
- I have two thoughts:

1. this is not a bug, but rather a limitation of the linear algebra backend. I believe ‘nuc’ uses the SVD internally, which is only implemented for 2D tensors.
2. this is a bug considering dims is not passed to the nuclear norm implementation as indicated by the traceback. We should consider erroring out for the case when dims is not None and p=‘nuc’.

- When `torch.norm()` is used with `dim=(2,3)` and `p='nuc'` the gradient cannot be computed because U and V  in SVD are not computed.
