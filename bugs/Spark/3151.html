Title

Driver should tell Executor to stop itself when cleaning executor's state

Description
When the driver removes an executor's state, the connection between the driver and the executor may be still alive so that the executor cannot exit automatically (E.g., Master will send RemoveExecutor when a work is lost but the executor is still alive), so the driver try to tell the executor to stop itself. Otherwise, we will leak an executor.
