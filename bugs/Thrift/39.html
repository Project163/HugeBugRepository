Title

Isset values do not account for null values in constructor

Description
Say you have: 

  
 
struct Foo {
  1: string blah
}

 
  

 If you generate the Java classes for this and then do something like:  

  
 Foo foo =  new  Foo( null );
 
  

 Then foo.__isset.blah will be true, even though the value is actually null (unset).
