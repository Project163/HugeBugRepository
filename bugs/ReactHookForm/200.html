Title

form.setError() from within useEffect() prevents form.formState.isSubmitting changing to false after onSubmit() completes

Description
**Describe the bug**
`form.formState.isSubmitting` doesn't return to `false` when calling `form.setError()` from a `useEffect()` hook.

**To Reproduce**
Steps to reproduce the behavior:

1. Create some state with the `useState()` hook.
2. Change the state within the `onSubmit()` callback passed to the form.
3. In a `useEffect()` hook, react to this state change and call `form.setError()`.

The `form.formState.isSubmitting` value never changes back to `false`, even after the `onSubmit()` callback completes.

**Codesandbox link (Required)**
[URL]

**Expected behavior**
`form.formState.isSubmitting` should turn to `false` after the `onSubmit` callback is executed.

**Desktop (please complete the following information):**

- OS: macOS 10.15.6
- Browser: Chrome 86.0.4240.193

**Additional context**
If `form.setError()` is called within the `onSubmit()` callback, `form.formState.isSubmitting` does return to `false` once the callback completes, as expected.
