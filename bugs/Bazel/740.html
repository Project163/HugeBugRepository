Title

exec_compatible_with not working with 0.26.0 (rc15)

Description
### Description of the problem / feature request:

`exec_compatible_with` is in [Link: bazel common definition],
working great with rules_scala's [Link: `scala_junit_test`]

It helps us define different execution env constraints.

### Bugs: what's the simplest, easiest way to reproduce this bug? Please provide a minimal example if possible.
For some reason with bazel0.26.0 (rc15) it fails the build:
```
ERROR: /Users/ors/workspace/rules_scala/test/BUILD:346:1: //test:JunitTestWithDeps: no such attribute 'exec_compatible_with' in 'scala_junit_test' rule 
```

Please kindly check out my repro on [Link: Wix's rules_scala fork] - try to build `//test/...`
(in `bazel 0.25.2` it still worked)

### What operating system are you running Bazel on?

Tested on both macos and linux

### What's the output of `bazel info release`?

```
release 0.26.0rc15
```
linked to #7499

- This is a regression, caused by a0f88c0. I have a workaround, and will send an actual fix shortly.

The workaround: add the flag `--incompatible_disallow_rule_execution_platform_constraints_allowed` to your build. I am in the process of making every target allow the `exec_compatible_with` attribute, and this flag will opt you into that behavior.

The fix will be to just change the default assumption in the `rule()` function.
