Title

3.0 Form with 2 or more query params always is black-holed

Description
I have a form in the following url

/admin/commissions/rules/add?dealer=1&type=Residual

The url vary according to some filters and can be

/admin/commissions/rules/add
/admin/commissions/rules/add?dealer=1
/admin/commissions/rules/add?dealer=1&type=Residual

the problem is in third url, the submit always is black-holed, debugging in to this, I found the following bug.

The form helper create the hash using the url

```
/admin/commissions/rules/add?dealer=1&type=Residual
```

and the component

```
/admin/commissions/rules/add?dealer=1&type=Residual
```

see the  ampersand , this causes that any form with two or more query params will be black-holed
