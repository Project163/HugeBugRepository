Title

Hive temporal join should allow monitor interval smaller than 1 hour

Description
Currently hive temporal join requires the monitor interval to be at least 1h, which may not fit everyone's needs. Although we recommend a relatively large monitor interval, we shouldn't make such decision for users. A warning log is a better option for a small interval.
