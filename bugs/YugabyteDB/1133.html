### Description

Problem
----
* Wrong results from a Bitmap Scan plan. The row: `(25,,x)` is returned in the result set despite the conditions: `table1.col_varchar_key  = 8) OR ((col_varchar_key)::text  = 8) OR ((col_varchar_key)::text < 'w'::text) OR (((col_varchar_key)::text < 'h'::text) AND ((col_varchar_key)::text = ANY ('{j,x}'::text[]))))
(2 rows)
