Title

LeakCanary RuntimeException when there is no label set in AndroidManifest

Description
### Description

When there is no label attribute set in AndroidManifest   tag, LeakCanary crashes on application startup.

### Steps to Reproduce

Any project without label attribute in   AndroidManifest

1. Make sure you don't have label attribute set
2. First install of the app without the label attribute
3. start the app 
4. RuntimeException 

**Expected behavior:** Expect LeakCanary to not crash

### Version Information

* LeakCanary version: issue first happened on beta-1, issue not happening on alpha-3 version
* Android OS version: 8.0.0
* Gradle version: gradle-5.4.1
