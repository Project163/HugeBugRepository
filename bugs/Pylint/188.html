Title

allow `type(self)._private_attribute`

Description
### Steps to reproduce

pylint the following

```
class C:
    _attr = 1

    def foo(self):
        return type(self)._attr
```
### Current behavior

A warning is raised: `W:  5,15: Access to a protected member _attr of a client class (protected-access)`
### Expected behavior

No warning raised.  After all, I can already access `_attr` as `self._attr`, and `type(self)._attr` simply allows me to clarify that I am indeed accessing a class attribute, not an instance attribute.
