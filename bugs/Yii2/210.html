Title

Escape jQuery id selectors

Description
When using JUI in combination with a GridView filter, selectors with a dot (.) in it should be escaped so the JUI widgets can properly attach. For example;

GridView with a searchModel which has some relations in it (e.g. network.value). When attaching a AutoComplete widget to the filter of the dataColumn the id of the filter input becomes #searchmodel-network.value  so the selector is written like jQuery('#searchmodel-network.value').autocomplete(); jQuery can not attach that selector because the dot needs to be escaped; jQuery('#searchModel-network\\.value').autocomplete();

The fix for this problem is in \yii\jui\Widget on line 96 add:

```
if(strpos($id, '.') !== false) {
$id = str_replace('.', '\\\.', $id);
}
```

This also needs to happen on line 119.
Discussion
- The change should rather be made to the id generation of the input field so that the `.` will be replaced with a non-conflicting character.
- Yeah, that would probably be a cleaner solution indeed
- fixed, thanks for reporting.
