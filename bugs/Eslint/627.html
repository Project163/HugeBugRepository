Title

array-bracket-spacing false-positive when accessing array index in array.

Description
I have the following in my .eslintrc file:

``` json
"array-bracket-spacing" : [ 1, "always", {
  "objectsInArrays": false,
  "arraysInArrays": false
}]
```

...and the following code:

``` js
var theBestApples = [ apples[i], apples[j] ]
```

... and the following `array-bracket-spacing` warning from eslint: `There should be no space before ']' at line...`

My guess is that eslint is seeing `[j]` and incorrectly recognizing it as an array literal rather than reference of index `j` on the `apples` array. The warning only gets triggered when the array reference is the last element in the array. Eliminating the space before the final `]` removes the warning.

I am using eslint version `1.1.0`.
Discussion
- Can you try the latest version of ESLint?
- Updated to v1.6.0. No change. Still warns incorrectly.
- It also fails for other cases:
- nested array patterns

```
{ code: "var [ x, [ y, z ]] = arr;", ecmaFeatures: { destructuring: true }, options: ["always", {"arraysInArrays": false}] },
```
- function definitions

```
{ code: "var foo = [ function(){} ];", options: ["always", {objectsInArrays: false}] },
```

Maybe the issue should be renamed to reflect that.
