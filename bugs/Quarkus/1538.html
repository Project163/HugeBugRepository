Title

Dependency order in pom.xml - NPE during headers writing

Description
### Describe the bug

Declaring `dependencies` in this order
```
 
   io.quarkus 
   quarkus-rest-client-jackson 
 
 
... [Log Snipped] ...
   quarkus-resteasy-reactive 
 
```
will make this code
```
@GET
@Path("")
@Produces(MediaType.TEXT_PLAIN)
public Response test(@QueryParam("value") @DefaultValue("0") Number headerValue) {
  return Response.ok().entity("ok").header("numeric-header", headerValue).build();
}
```
to fail with this stacktrace
```
ERROR: Request failed
java.lang.NullPointerException
	at org.jboss.resteasy.reactive.common.headers.HeaderUtil.headerToString(HeaderUtil.java:44)
	at org.jboss.resteasy.reactive.server.core.ServerSerialisers.encodeResponseHeaders(ServerSerialisers.java:493)

```

### Expected behavior

Everything should works fine regardless dependencies order

### Actual behavior

```
ERROR: Request failed
java.lang.NullPointerException
	at org.jboss.resteasy.reactive.common.headers.HeaderUtil.headerToString(HeaderUtil.java:44)
	at org.jboss.resteasy.reactive.server.core.ServerSerialisers.encodeResponseHeaders(ServerSerialisers.java:493)

```

### How to Reproduce?

Link to reproducer: [URL]
`mvn test` to run test

### Output of `uname -a` or `ver`

Microsoft Windows [Versione 10.0.19044.1469]

### Output of `java -version`

openjdk version "11.0.6" 2020-01-14 LTS

### GraalVM version (if different from Java)

_No response_

### Quarkus version or git rev

2.7.3.Final

### Build tool (ie. output of `mvnw --version` or `gradlew --version`)

Apache Maven 3.8.4 ( )

### Additional information

Non-reactive version works fine.
Moving
```
 
   io.quarkus 
   quarkus-rest-client-jackson 
 
```
after ALL reactive dependencies solve the problem.
Discussion
- This issue started to happen on 3.9.1 with using new quarkus-rest dependencies instead of quarkus-resteasy dependency.
- Given how old this issue is, it's probably not exactly the same problem.

Please open a new issue with a small reproducer.
