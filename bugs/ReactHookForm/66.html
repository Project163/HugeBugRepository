Title

With validateCriteriaMode: 'all' and mode: 'onChange' errors is not being updated on validation pass

Description
**Describe the bug**
Return of functions in validate object is not being properly updated in errors object.

**To Reproduce**
Steps to reproduce the behavior:
1. Go to [URL]
2. Click on input field in browser
3. Type "1" into input
4. Notice following errors listed "minLength 10", "lowerCase", "upperCase"
5. Append input with "a"
6. Notice errors object not updating despite validation function returning true
5. Append input with "A"
6. Notice errors object not updating despite validation function returning true
5. Append input with "4567890"
6. Notice errors object updating only after reaching 10 length.

**Codesandbox link**
[Link: CodeSandbox] modified example from [URL] for validateCriteriaMode parameter

**Expected behavior**
Errors object should be updated when return of any validation function changes.

**Desktop (please complete the following information):**
 - OS: OS X
 - Browser: Chrome
 - Version: 79

**Additional context**
I want to create form that dynamically shows which criteria user passes and fails so I need a valid errors object.

**Side Effects**
If you place watch(); in functional component body validation works correctly though with unnecesary rerenders.
