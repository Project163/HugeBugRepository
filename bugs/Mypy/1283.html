Title

[1.11 Regression] `partial` plugin doesn't respect TypeVar bounds when deciding if something can be passed to `partial`

Description
**Bug Report**

```
py
from typing import Callable, TypeVar
import functools

T = TypeVar("T", bound=Callable[[str, int], str])
... [Log Snipped] ...
    g = functools.partial(f, "foo")  # error: "S" not callable  [misc]
    return f
```

[URL]

Mypy should understand both `T` and `S` to be callable due to the fact that the TypeVars have `Callable` and `type` as their respective upper bounds. We're hitting this in our attempt to upgrade mypy to 1.11.1 for Argument Clinic over at CPython in [URL]

Cc. @hauntsaninja 

**Your Environment**

 

- Mypy version used: 1.12.0+dev.  (compiled: no)
