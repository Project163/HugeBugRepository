Title

Description
The async pattern is available in C# 5 on .NET 4.5. Thus, it shouldn't only be for Silverlight.

- Thanks for the feedback. 

 The async keyword is optionally defined by the thrift compiler. Users can select to include these async functions, but by default, these will not be generated; thus preserving the backward compatibility. 

 Also, the async keyword in C# is now a part of the base language (in C# 5); before that it was only in technology preview. I don't think the thrift compiler was changed after that, but it seems a reasonable change to support async for all of C# now that it is no longer in preview.
