**Current behavior**
When passing a class instance as the context for ngOutletTemplate, I get a run-time error "_Cannot read property 'index' of null_". Passing a regular plain object seems to be OK.

**Expected behavior**
I should be able to use a class instance as context for ngOutletTemplate (it worked up until  4.0.0-beta.8)

**Minimal reproduction of the problem with instructions**
rc.1 - does not work

**What is the motivation / use case for changing the behavior?**
For templates that are internal using and not for public API, it's advantageous to be able to pass the entire class instance to the templates and let the templates decide what it needs from the instance. We still define what the templates access via the "let-" declarations.
