Title

`render_to_string` no longer works outside of real requests in 4.1.rc1

Description
In the project I am working on this code is being called in a model:

``` ruby
ApplicationController.new.render_to_string( [...] )
```

... not the prettiest thing, but it used to work in older versions of rails. However, on rails 4.1.rc1 this error is raised - `undefined method 'variant' for nil:NilClass`.

This is the relevant part of the stack trace:

```
lib/abstract_controller/rendering.rb:109:in `_normalize_render'
lib/abstract_controller/rendering.rb:42:in `render_to_string'
lib/action_controller/metal/rendering.rb:21:in `render_to_string'
```

This is the line that causes the error:

``` ruby
options[:variant] = request.variant if defined?(request) && request.variant.present?
```

It seems that the `request` variable is defined, but is `nil`. Changing the code to:

``` ruby
options[:variant] = request.variant if defined?(request) && request && request.variant.present?
```

... should fix the problem.

I am not opening a pull request, because I am not sure if this is not some deeper problem (e.g. `request` being defined and `nil` at the same time could be an invalid state for a controller to begin with)
