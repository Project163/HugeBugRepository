Title

Static type checker complains on assignment on generics fields

Description
The static type checker complains on the following class: 
  
 @groovy.transform.TypeChecked
 class  Container<T> {
     private  T initialValue
    Container(T initialValue) {  this .initialValue = initialValue }
    T get() { initialValue }
}
 
  
 With the message: 
  
 [Static type checking] - Incompatible  generic  argument types. Cannot assign java.lang. Object  <T> to: java.lang. Object  <T>
 at line: 4, column: 33
Discussion
- see also lines 85-88 of  org.codehaus.groovy.ast.GenericsType  which might be fixed by a solution to this problem - running stub generator tests should verify whether fixed after removing lines 85-88
- Resolution is not related to the lines GenericsType#85-88 though.
