Title

`goreleaser check` does not report usage of deprecated config options

Description
### What happened?

I ran `goreleaser check` as noted on: [URL]

I expected it to report line numbers of my usage of `empty_folders` as I was seeing from my build commands:
```
      • DEPRECATED: 'empty_folders' is deprecated and will be removed in a future version, create content with type 'dir' and directory name as 'dst' instead
```

Actual:
```
$ goreleaser check -f .goreleaser.yml

   • loading config file       file=.goreleaser.yml
   • checking config:
   • config is valid
```

### How can we reproduce this?

Add a config with:
```
nfpms:
- empty_folders:
  - /foo/bar
```

Run `goreleaser check`
