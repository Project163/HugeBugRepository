Title

Test case serialization fails for Type[] containing open generic types

Description
Serializing/deserializing `Type[]` works fine normally. But if one of the elements of the array is an open generic type (e.g. `IEnumerable<>`), Xunit deserializes a `null` element to the array instead of the original value. This is blocking my conversion of my xunit1 extensions to xunit2.

```
[FactWithTypes(typeof(IEnumerable ))]
    public void ThisWorks(string t1)
    {
    }

... [Log Snipped] ...
    }
}
```
Discussion
- One possible workaround I've found. Serialize string[] instead of Type[] and do my own type-string serialization:

```
data.AddValue("arguments", this.arguments?.Select(t => t.AssemblyQualifiedName).ToArray());

this.arguments = data?.GetValue ("arguments").Select(n => Type.GetType(n)).ToArray();
```
- I confirm that the rc4 release fixes this. I have removed my workaround. Thanks again.
