Title

Lambda evaluation

Description
The following script returns correct lambda  function(s,v){42; } 
  
 
 var  x = (s, v)->{42} 
  
 While the following script returns  42  
  
 
(s, v)->{42} 
  
 The expected result is the same lambda as in the first example
Discussion
- This behavior is what is expected and has been implemented since 3.0; the actual commit happened in 2013 (  [URL] ). 

 The second form allows creating a script with parameters without having to use the explicit API.
