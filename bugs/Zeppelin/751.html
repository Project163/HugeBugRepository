Title

If execution of paragrah is aborted then the previous results are cleared

Description
If we abort the execution of paragrah then the previous results are cleared but this was not the case with 0.6 version .The results were kept till the new results are produced. 
Following are the steps to reproduce this issue: 
1) Run a paragraph 
2) Rerun the paragraph and abort it in between the paragraph is cleared.
