Title

Animation doesn't render correctly using Lottie-Compose

Description
**Describe the bug**
With Lottie-Compose, the animation doesn't render correctly, some parts are missing. The same animation works with `LottieAnimationView`. Am I misusing `LottieAnimation`?

**What version of Lottie did you test this on?**
Lottie-Compose Alpha 05, 06-SNAPSHOT
Jetpack Compose Alpha 10, 11

I didn't test this with the latest snapshot yet because I didn't find the docs for that :D Will test that as soon as I figure out how to include the snapshot :) I don't expect it to change though

**What version of Android did you test this on?**
Pixel 4XL, Android 11

Steps to reproduce the behavior:

1. Use the attached `lightbulb.json` file in the zip (this is from [URL]

```
kotlin

    autoPlay = true,
    repeatCount = Int.MAX_VALUE
```
