Title

Undefined behavior when using `diesel::sql_query` with an empty string for Sqlite

Description
## Setup

### Versions

- **Rust:** rustc 1.80.1
- **Diesel:** v2.2.3
- **Database:** sqlite 3.44.1
- **Operating System** Linux

### Feature Flags

- **diesel:** sqlite

## Problem Description

This code has UB:
```rust
use diesel::{Connection, RunQueryDsl, SqliteConnection};

fn main() {
    let mut conn = SqliteConnection::establish("tmp.sqlite").unwrap();
    diesel::sql_query("").execute(&mut conn).unwrap();
}
```

Output with `cargo run`:
```
thread 'main' panicked at library/core/src/panicking.rs:219:5:
unsafe precondition(s) violated: NonNull::new_unchecked requires that the pointer is non-null
stack backtrace:
   0: rust_begin_unwind
             at /rustc/ /library/std/src/panicking.rs:652:5
... [Log Snipped] ...
thread caused non-unwinding panic. aborting.
[1]    6997 abort (core dumped)
```
