Title

Alias generator not working on inherited attributes

Description
# Alias generator not working on inherited attributes
* OS: **Debian GNU/Linux 9 (stretch)**
* Python version `import sys; print(sys.version)`: **3.7.3**
* Pydantic version `import pydantic; print(pydantic.VERSION)`: **0.32.2**

On inherited attributes, the alias generators do not work, if the base class also has an alias generator set. Minimal example:

```
py
from pydantic import BaseModel

def alias_generator_1(field_name: str) -> str:
    return field_name + '1'
... [Log Snipped] ...
# actual: {'x1': 1, 'y2': 2}
print(i.dict(by_alias=True))
```


A simple fix is to just define the attribute again on the child like so:
```
class Impl(Base):
    x: int
    y: int

    class Config(Base.Config):
        alias_generator = alias_generator_2
```

But i would expect the `alias_generator` to be overridden for all attributes, when defined in subclasses.
