Title

XML Escape mode should escape < in attributes

Description
We are extensively using Jsoup version1.7.2 from sometime. Thanks for the library ,it has been wonderful.

But upgrading seems to be bit difficult with one particular issue we faced.
test case:

```
    public static void main(String[] args) {
        final Document doc = Jsoup.parse(" ");
        doc.outputSettings().escapeMode(org.jsoup.nodes.Entities.EscapeMode.xhtml);
        System.out.println("Output: " + doc.select("input.text").get(0));
    }
```
output is

Jsoup 1.7.2
`Output:  `


Jsoup 1.8.2
`Output:   data   
`
Jsoup 1.11.3
`Output:   data  < ">`


This is similar to the issue [URL]  but point to note here, this works fine in 1.7.2
Could you please help me over here if there is a workaround or better way to parse this
