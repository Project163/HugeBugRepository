Title

Description

- Vim (version: ) behaves differently?
see [URL]
- Operating system/version: MacOS 10.14
- Terminal name/version: MacOS's builtin Terminal 2.9 (421)
- `$TERM`: xterm-256color

### Steps to reproduce using `nvim -u NORC`

```
nvim -u NORC
set selection=exclusive
```

1. assume we have text: `'ab|c'`, and `|` is the cursor position
2. stay in `normal mode`, use `vi"` or vi` to select (double quote or back quote, that does not match)
    * `vi]` or `vi}` won't cause the issue

### Actual behaviour

cursor moved left, result to `'a|bc'`

### Expected behaviour

no match, the cursor stays at old position
