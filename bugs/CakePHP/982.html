Title

FormContext removes error name keys

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.7.7

### What you did

I have  a modelless form with custom validation.

```
php
class RegisterForm extends Form
{
    public function validationDefault(Validator $validator)
    {
... [Log Snipped] ...
    }
}
```

I wanted to overwrite error messages using form helper.

```php
 $this->Form->control('email', [
    'label' => false,
    'placeholder' => __('E-mail address'),
    'error' => [
        'email' => __('Please provide a valid e-mail address.'),
    ]
]) 
```


### What happened

Error messages set with a helper are not displayed.

### How to fix it

`FormContext` returns only array values in `errors()`:

[URL]

This should be easy to fix by removing `array_values()` but is it BC safe enough?
