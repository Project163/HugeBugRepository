Title

No log in dev mode

Description
I'm unable to configure the log in dev mode despite having configured the logging in the configuration.
Everything works in JVM mode.
Discussion
- I was able to get logs after using build, something like that:
`mvn compile shamrock:build shamrock:dev`
yet still `mvn clean compile shamrock:dev` produce no logs , used master head (shamrock-maven-plugin:1.0.0.Alpha1-SNAPSHOT:dev)
- This appears to be racey, I have seen it both work and fail to work with 'mvn compile shamrock:dev'
- When the config PR came in `org.jboss.shamrock.runner.RuntimeLoggingConfigurator` was deleted, which means there is no longer a runtime based logging configurator. This means in most cases there is simply no logging config.

The reason why this works sometimes is that for some reason the wiring-classes dir is being added to the dev mode class path, which I think is a mistake. If shamrock:build has already been run the generated logging config will be present, and this will be used so logging appears to work normally.

Unfortunately the fix for this is not as simple as just adding back RuntimeLoggingConfigurator. The config PR also updated to SmallRye config 1.3.5, which is now doing logging as part of the config property loading. This results in a nasty circular dependency.
