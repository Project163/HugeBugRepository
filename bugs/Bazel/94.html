Title

repository_ctx.download should create necessary directories

Description
Much like `repository_ctx.file` does. Right now I have a rule that does 

```
repository_ctx.download(…)
repository_ctx.file("BUILD", build_file_contents)
```

But it doesn't work unless I reverse the order of the calls, because the second line implicitly creates the output directory, but the first doesn't, which seems unnecessarily confusing and fraught.
