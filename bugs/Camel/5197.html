Title

NullPointerException with @BeanInject

Description
When testing if I can use Camel 3, I’m getting a NullPointerException when trying to start Camel.

Discussion
- I added a test-case showing the error. Just execute "./gradlew run" to run it.
- I added a null-check in the method getInjectionBeanValue of the CamelPostProcessorHelper and that seemed to solve it: 

 if (camelContext != null && type.isAssignableFrom(camelContext.getClass()))  
{
   return camelContext;
}
- Thanks I have reproduced and have a fix
