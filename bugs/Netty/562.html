Title

HTTP/2: SETTINGS_HEADER_TABLE_SIZE should be an unsigned int

Description
The HTTP/2 spec demands that the max value for `SETTINGS_HEADER_TABLE_SIZE` should be an unsigned 32-bit integer. However, it seems that some [Link: limitations in HPACK] prevent us from supporting that.

h2spec test suite 6.5 fails due to this limitation. The exception is `Setting HEADER_TABLE_SIZE is invalid: 4294967295`.

```
        × Sends a SETTINGS frame
          - The endpoint MUST sends a SETTINGS frame with ACK.
            Expected: SETTINGS frame (Flags: 1)
              Actual: GOAWAY frame (Length: 56, Flags: 0, ErrorCode: PROTOCOL_ERROR)
```
