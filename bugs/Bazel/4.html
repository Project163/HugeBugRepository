Title

select() + list fails in common cases

Description
I've found a couple cases where adding a list to a select() doesn't work. Both of these fail with the error "'+' operator applied to incompatible types".

Can't add an empty list:
  s = select({
      "foo": ["FOO"],
      "bar": ["BAR"],
  }) + []

Can't add sums of lists:
  s = select({
      "foo": ["FOO"],
      "bar": ["BAR"],
  }) + (["A"] + ["B"])
This also doesn't work if the sum is stored in a variable:
  L = (["A"] + ["B"])
  s = select({
      "foo": ["FOO"],
      "bar": ["BAR"],
  }) + L
But it does work if you add a copy of L (via L[:], list(L), etc.).
Discussion
- Also: performing select() addition in a BUILD with selectors generated in .bzl file is buggy. For example, this works:
    s = select({"//conditions:default": ["foo"]}) + ["bar"]
But if I define
   def make_select():
       return select({"//conditions:default": ["foo"]})
in a .bzl file, and then
    s = make_select() + ["bar"]
in a BUILD file, I get an incompatible types error.
