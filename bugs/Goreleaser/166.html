Title

Scoop pipeline doesn't substitute variables

Description
### What happened?

The Scoop pipeline does not replace custom variables defined in the YAML.

### How can we reproduce this?

```
yaml
variables:
  owner: foo
  author: My Name
  email: email@example.com
... [Log Snipped] ...
    email: '{{ .Var.email }}'
  license: MIT
```

This results in 
```
    • scoop manifests
      • error checking for default branch            err=GET [URL] 404 Not Found [] projectID={{ .Var.owner }}/scoop-bucket statusCode=404
      • error checking for default branch, using master err=GET [URL] 404 Not Found [] fileName=vhs.json projectID={{ .Var.owner }}/scoop-bucket requestedBranch=
```

### goreleaser version

```bash
goreleaser v1.12.3-pro
```
