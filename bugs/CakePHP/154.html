Title

3.0 - It should be possible to pass extra arguments to a named route

Description
When using this code:

``` php
Router::scope('/articles', ['controller' => 'Articles'], function($routes) {
    $routes->connect('/', ['action' => 'index']);
    $routes->connect('/view/*', ['action' => 'view', ['_name' => 'Articles::view']]);
});
```

There is no way to build a link for `/articles/view/1`. I tried several variants:

` Html->link('View', ['_name' => 'Articles::view', $article->id]); ?>`

` Html->link('View', ['Articles::view', $article->id]); ?>`

` Html->link('View', 'Articles::view'); ?>`

` Html->link('View', Router::url('Articles::view')); ?>`
Discussion
- Shouldn't

``` php
$routes->connect('/view/*', ['action' => 'view', ['_name' => 'Articles::view']]);
```

be

``` php
$routes->connect('/view/*', ['action' => 'view'], ['_name' => 'Articles::view']);
```
