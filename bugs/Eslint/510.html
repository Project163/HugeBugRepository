Title

Keyword "else" must not be followed by a newline

Description
The fix for #3198 has created a quirk in the way the `else` keyword is handled.

`"space-after-keywords": [2, "always"]` with the following code:

``` js
if (a == null)
  doThing()
else
  doOtherThing()
```

Results in the error: `Keyword "else" must not be followed by a newline`

I believe this rule of strictly being a space is really intended to be applied to keywords where the next token is `(` or `{` – as in `if(something)` or `else{ whatever() }`
