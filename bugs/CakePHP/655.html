Title

Stubbed Response objects in controller unit tests do not set their magic headers

Description
Because [Link: TestSuite/Stub/Response] overwrites the send(), methods like _setContentType never get executed.

This affects controller unit tests with false data. Content-Type for example never gets set if it got configured with Response->type().
