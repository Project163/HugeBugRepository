Title

vars-on-top conflicts with 'use strict'

Description
There is a failing test-case for `vars-on-top` which I think should be valid:

``` js
"use strict";
var first = 0;
function foo() {
    first = 2;
}
```
Discussion
- Also the following test-case fails:

``` js
function foo() {
    "use strict";
    var first = 0;
}
```
