Title

symlink(): File exists

Description
Hi,
I got that error sometimes after I've deleted symlinks from `web/assets` manual or in the code. I can run `clearstatcache( true )` but it worked per thread, so other theads will produce the error until `realpath_cache` will be reloaded. How to fix it? I'm talking about `\yii\web\AssetManager::publishFile` and `\yii\web\AssetManager::publishDirectory`. Maybe try to catch that error and make `clearstatcache( true )`, then try again? I've googled that problem, and it's common problem for PHP.
Discussion
- How to reproduce it reliably?
- Set php.ini options (by default realpath_cache_size=16K, so will be full each time and you'll can't reproduce the error)

```
realpath_cache_size => 1M
realpath_cache_ttl => 120
```

Then just remove web/assets/\* symlinks and will try to reload the page (in 120 secs).
For reliably reproduce try to set `realpath_cache_ttl = 600`.
