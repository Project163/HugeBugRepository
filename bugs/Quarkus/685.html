Title

Qute throws very sparse exceptions

Description
Running Quarkus 1.6.0.CR1 with Gradle

I was recently tripped up by assuming that I could do the following to have a 'default' value for a parameter:

`{redirectTo} {/}`

I was, of course, was mistaken and needed: `{#insert redirectTo}/{/}`

But the error I got was just a simple null pointer exception, extremely unhelpful when trying to debug and find out what is causing issues. Currently it is hard to even know which template is failing.

TL:DR; the error reporting for Qute- related errors are usually very unhelpful. Would be nice to see more helpful and explanative error messages
Discussion
- That is a bug. Our parser does not handle the case where a section end tag `{/}` has no relevant section start tag and is not placed inside another section.


Could you be more specific? We do try to produce helpful messages where possible. See for example our [Link: ParserTest]. Of course, not all error use cases are covered. Feel free to create issues for specific use cases. That would be helpful and appreciated ;-).
