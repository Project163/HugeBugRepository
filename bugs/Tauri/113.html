Title

Systray icon not showing in newest releases

Description
### **Describe the bug**

The systray icon is not shown in cli.js `v1.0.0-beta.8` and `v1.0.0-beta.9`, although it works perfectly fine. I have also been able to reproduce the issue with the `example/api` from the core tauri repo.

With the same setup, the icon *is* shown in cli.js `v1.0.0-beta.6`

### **To Reproduce**
Steps to reproduce the behavior:
1. Add a systray icon in `tauri.conf.json`.
2. Update to cli.js `v1.0.0-beta.8`.
3. Run `npm run tauri build`
4. Execute the resulting `.AppImage`

### **Expected behavior**

The icon has to show without issues.

Discussion
- The issue also exists in Ubuntu 18.04 with gnome.
- Was able to track down the issue to [Link: this commit]. I went down and executed the `examples/api` example in the commits between the two cli.js versions, and in commit 8b2cc26 it does work, and in commit 3f039cb the icon doesn't work.

I would assume that some renaming of the folders is confusing the building process and not processing the systray icon correctly? The normal app icon displays correctly.
