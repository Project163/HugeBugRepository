Title

Avoid handling duplicate LeaderAndISR requests

Description
Upon controller migration, the new controller will try to resend all the LeaderAndISR requests for any on-going partition reassignments. This can then lead to duplicate such requests sent to the same broker. 

 Upon receiving such requests, today brokers do not detect if, for example, it is already the leader for the requested becoming-leader-partition, and does the logic such as 1) stop fetching 2) coordinator migration, etc which is not necessary.
