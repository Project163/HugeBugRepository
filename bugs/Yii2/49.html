Title

GII crud generator generates invalid comments in view _search.php

Description
The generated _search.php form file includes echo tags for each field. Only the first ones are activated while the later ones are commented.
It seems that php offers no valid comment for the new echo tag.
Example:
 field($model, 'abcfield') ?>            --> invalid
Possible solutions might be:
 field($model, 'abcfield') ?>
Echo an empty string and then comment the rest or
use the old way to echo data.
 field($model, 'abcfield') ?>
