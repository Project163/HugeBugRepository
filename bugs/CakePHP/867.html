### What you did

I make a Query who is cached, this is my query

```
self::$__pagebuilder = $Pagebuilders
            ->getAllPagebuildersActivated()
            ->matching('Templates', function($q) {
                return $q
                    ->where([
... [Log Snipped] ...
                    ->limit(1);
            });
```

Into my Table i manage the Query and the cache

```
public function getAllPagebuildersActivated($type = 'all')
    {
        return $this
            ->find($type, [
                'conditions' => [
... [Log Snipped] ...
            }, 'infinite');
    }
```

### What happened
`Notice (8): Undefined index: matching [CORE/src/Database/Query.php, line 1701]`

### What you expected to happen
The clause method of Query class should check if the key exist before return parts data.

Query.php method clause should be rework from

```
public function clause($name)
{
        return $this->_parts[$name];
}
```

to

```
public function clause($name)
{
        if (array_key_exists($name, $this->_parts)) {
            return $this->_parts[$name];
        }
        return null;
}
```
Discussion
- Just a heads up that `matching()` never makes a clause. But I agree that we should null guard the key.
