Title

In a tag, the selector greater than ">" is escaped into the entity >

Description
**Problem**
 

**Steps To Reproduce**

Create a simple yew app, add this lines :

```rs
 {"body > a {color: #cc0;}"} 
 {"This is a test : > it works ?"} 
```

**Expected behavior**

We should get this HTML

```html
 body > a {color: #cc0;} 
 This is a test : > it works ? 
```

**Result**

We get this HTML

```html
 body > a {color: #cc0;} 
 This is a test : > it works ? 
```

The selctor does not work.
