Title

Unused Parameters in Ng Factory code

Description
I'm submitting a Bug Report.

## Current Behaviour

Running `ngc` generates a `View_AppComponent_0()` function that takes the logger as argument. If the component template does not declare any element or text that function is basically empty. The `l` parameter is not used, which can lead to errors when typescript builds it with `noUnusedParameters`.

## Expected Behaviour

The factory code should not take an argument, or should always use that argument so that typescript doesn't show an error.
