Title

Public IPs of Azure virtual machines in scale sets are not exposed by the `__meta_azure_machine_public_ip` label in `azure_sd_config`

Description
**What did you do?**

We have Azure virtual machines that are part of a virtual machine scale set.  We attempted to scrape metrics from them using the following `azure_sd_configs` block:
```
azure_sd_configs:
  - environment: AzurePublicCloud
    port: 9182
    subscription_id: ***
    tenant_id: ***
... [Log Snipped] ...
    replacement: $1
    action: replace
```

**What did you expect to see?**

We expected that the public IP addresses of the virtual machines would be visible in Prometheus under the `__meta_azure_machine_public_ip` label.

**What did you see instead? Under which circumstances?**

The private IP addresses of the virtual machines are visible under the `__meta_azure_machine_private_ip` tag, but the public IP addresses are not visible:
