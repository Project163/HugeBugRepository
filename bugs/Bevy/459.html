Title

`ui_focus_system` ignores clipping

Description
## Bevy version

  

## Problems

* `ui_focus_system` ignores clipping and the clipped areas of UI nodes respond to mouse interactions.
* `RelativeCursorPosition` for clipped nodes returns a nonsensical value for clipped nodes. The cursor position's coordinates are normalized relative to a rect with its position taken from the intersection of the node rect and clipping rect and its size taken from the full unintersected node rect.
* The `RelativeCursorPosition::mouse_over` method returns true when the mouse is over a clipped part of the UI node.
