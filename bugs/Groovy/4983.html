Title

Return statement throws a compile error inside a closure

Description
I am not sure what's going on here, the first call to myOther() succeeds during compilation, but the call to the submit method shows this error (after static compile was applied, during class gen) 
  
 

 import  java.util.concurrent.Callable;
 import  java.util.concurrent.Executors;

 public   class  RecordTesting {

     public  <T> T myOther(Callable<T> callable) {
    }

     public  void myFunction() {
        myOther(() -> {
             return   "blah" ;
        })

        Executors.newSingleThreadExecutor().submit(() -> {
             return   "blah" ;
        });
    }
}
