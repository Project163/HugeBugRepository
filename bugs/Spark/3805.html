Title

Cannot use "SparkR::sql"

Description
When call "SparkR::sql", an error pops up. For instance 

  
 SparkR::sql("")

Error in get(paste0(funcName,  ". default " )) :
 object  '::. default '  not found
 
  

  [URL]
Discussion
- This also affects other functions like `SparkR::createDataFrame` – The problem seems to be that the `funcName` we extract in `dispatchFunc` is `.` instead of being `sql` or `createDataFrame`. The line of code is 
  
 funcName <- as.character(sys.call(sys.parent())[[1]])
 
  

 Not sure what is the fix though
- So it looks like what is going on is that the `funcName` we get in the case of `SparkR::createDataFrame` is a list and not a single element. Further the list contents are  [::, SparkR, createDataFrame]  - So a change which looks like  

  
   funcName <- as.character(sys.call(sys.parent())[[1]])
   if  (length(funcName) > 1) {
    funcName <- funcName[length(funcName)]
  }
 
  

 seems to work.  felixcheung  is there a better way to fix this ?
