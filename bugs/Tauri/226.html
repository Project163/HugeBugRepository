Title

[bug] Signed Windows installer shows program name as autogenerated hash value

Description
### Describe the bug

After building an MSI installer for Windows, and signing it, the installer shows a dialog with the app name set to a random-looking value that looks like a hash of some sort.

This SO question matches the problem: [URL] (/ht @FabianLars in Discord for that link)

[Image: tauri-installer]

### Reproduction

1. Create a Tauri project
2. Set up code signing and build an installer
3. Run the installer.

### Expected behavior

The "Product name" should probably match `package.productName` from `tauri.conf.json`.
