Title

Return 401 instead of 500 on use of invalid access tokens

Description
Token Service will throw an InvalidStateException if a wrong access token is used as a Bearer token for authentication and this gets translated to a 500 error response. We should be handling this correctly and return a 401 Unauthorized instead. 

Relates : [URL]
Discussion

- This has been resolved as part of the awesome work that @albertzaharovits did on refactoring the TokenService. I added a small test to catch any regressions in [URL]
- Re-opening this as it was prematurely closed. There is one case still that we throw a 500 - when the access token is valid but expired _and_ deleted from the tokens index. This needs to be handled before we resolve this issue
