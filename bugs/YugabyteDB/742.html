Title

[yb-admin] Incorrect error message for list_tablets command

Description
Jira Link: [Link: DB-1289]
list_tablets (yb-admin) command returns incorrect message if user tries incorrect command

```
bin/yb-admin --master_addresses   list_tablets  demo_2 
Error running list_tablets: Invalid argument (yb/util/stol_utils.cc:28): demo_2 is not a valid number
```
**Expected**: table name is missing

AND
help section of yb-admin command shows as below,
`6. list_tablets   [max_tablets] (default 10, set 0 for max) [JSON]`

here, database/keyspace entry is missing.
**Expected**:` list_tablets     [max_tablets]`
Discussion
- In master branch, I get:
```
./build/debug-gcc-dynamic-ninja/bin/yb-admin list_tablets  demo_2
Error running list_tablets: Invalid argument (yb/tools/yb-admin_client.cc:356): Namespace 'demo_2' of type 'ycql' not found
```
- @tedyu Please create keyspace(demo_2) and try the same command
- ... [Middle Discussions Snipped for Brevity] ...
- By default, command takes YCQL type, so it is required to specify the type as well
if user tries with
`bin/yb-admin --master_addresses   list_tablets test1`

It gives
`Error running list_tablets: Invalid argument (yb/tools/yb-admin_client.cc:363): Namespace 'test1' of type 'ycql' not found`

cmd should be 
`bin/yb-admin --master_addresses   list_tablets type.dbname table/index name`

mentioning **type** in [URL] helps to the end user.

And 
`6. list_tablets   [max_tablets] (default 10, set 0 for max) [JSON]`
here it is not taking 10 as default, it lists all tablets
- Resolved issues regarding default 10 tablets, missing table name error message, and add keyspace to the error message. Also added a follow up issue: [URL]
