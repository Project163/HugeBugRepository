Title

Window title is lost when toggling from windowed to fullscreen and back

Description
OS: **MacOS 10.13 High Sierra**
GLFW Version: **GLFW 3.3.0 Cocoa NSGL** @ 32e78ae

You can see this happening in the example `boing`.

1) Run the `boing` test app, verify that the window title is `Boing (classic Amiga demo)`
2) Press  alt-enter  to trigger fullscreen
3) Press  alt-enter  again to exit fullscreen
4) Window title is lost

In my own app I was just going to implement a quick fix by grabbing the current title before going fullscreen and setting it back when exiting, but then noticed that there wasn't a counterpart for getting the title as there is for setting it; i.e. there is a `glfwSetWindowTitle`, but there's not a `glfwGetWindowTitle` (which may be a separate issue in its own).
