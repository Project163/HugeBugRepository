Title

3.0 Fatal error with BelongsToMany on $Table->get()

Description
So I'm trying to pass the `contain` key to a `$table->get()` call which results in a fatal error. Here is the set up I'm using:

```
php
// Manufacturers Table
class ManufacturersTable extends ProductsAppTable {

    public function initialize(array $config) {
... [Log Snipped] ...
    }
}
```

The fatal error that I am getting is from `Cake\ORM\Association\BelongsToMany` on line [Link: 918]. It's trying to call `foreignKey()` on the target table and that method does not exist. In other parts of my application I have contained BTM data successfully so I believe this is probably something to do with the `through` key.

I thought this was something in my configuration but I haven't done anything out of the ordinary on this plugin and it still manages to call a method that does not exist. Running a `debug()` on that `$association` variable in the controller produces this:

- ... [Middle Discussions Snipped for Brevity] ...
- Looks like you are re-using an association alias, which won't work well.
- Hmm... it does seem that it is the association alias.

The BTM association class looks for the association by alias and uses it regardless if it is configured for BTM. That's tricky since I'm not too excited about creating a new alias just for this association to work correctly.

It feels like a bug given my set up seems pretty standard. I think the only thing messing it up is that [Link: `targetTable`] instance that it passes when it sets up the `hasMany` association. Maybe something like this...

``` php
$hasManyJunction = $target->association($junctionAlias);
$target->hasMany($junctionAlias, [
    'targetTable' => $hasManyJunction ? $hasManyJunction->target() : $table,
    'foreignKey' => $hasManyJunction ? $hasManyJunction->foreignKey() : $this->targetForeignKey(),
]);
```
