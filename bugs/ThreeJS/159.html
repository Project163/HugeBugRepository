Title

ExtrudeGeometry: Used options.arrays in spite of being undefined

Description
Inside of `if ( ! options.arrays )` the undefined value is used:

[URL]

Should be:

		this.addAttribute( 'uv', new Float32BufferAttribute( uvArrays, 2 ) );

The code path is probably not taken usually, as this makes the function to fail?
Discussion
- Good find! This wasn't noticed because `.addShape()` is normally only used by `ExtrudeBufferGeometry`. In this case `options.arrays` is never `undefined`. 

It is actually questionable if methods like `.getArrays()`, `.addShapeList()` and `.addShape()` needs to be public. The mentioned if-statement only exists because `.addShape()` could be used on an "empty" geometry object.  Not sure such an API is preferable...
- But the correct name of the variable is `uvArray` 😉
