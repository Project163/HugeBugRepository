Title

CLI wrapper does not respond to SIGINT or SIGTERM

Description
### Expected behavior

`SIGINT` / `SIGTERM` kill signals should exit the `electron` child process

### Actual behavior

They don't 😆 

### How to reproduce

```js
// From a node.js script
const child = childProcess.spawn(process.execPath, ['./node_modules/electron/cli.js']);
setTimeout(() => {
  child.kill('SIGTERM');
}, 2000);
```
