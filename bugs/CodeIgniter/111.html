@gigkokman 
I read your code and find your wrongly use.

your code 
```
$this->db->set_update_batch($update, 'ITEM_ID', FALSE);
$this->db->update_batch('ITEM', NULL, 'ITEM_ID');
```

should change to 

```
$this->db->set_update_batch($update, 'ITEM_ID');
$this->db->update_batch('ITEM', NULL, 'ITEM_ID');
```

In `update_batch()`,  it uses `$this->_protect_identifiers`,which default to be `TRUE`, to determine whether to do the escaping work .	, .

And your code, with the `FALSE` param,  force it not escaping. So if your `$this->_protect_identifiers` is `TRUE`, they come into conflict.

My suggestion is just using

`$this->db->update_batch('ITEM', $update, 'ITEM_ID');`

**AND DO NOT USE `$this->db->set_update_batch(XXX)`**
