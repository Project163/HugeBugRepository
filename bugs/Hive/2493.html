Title

Cleanup hbase-handler/pom.xml dependency list

Description
Noticed an extra dependency  hive-service  when changing dependency version of  hive-hbase-handler  from 0.12.0 to 0.13.0 in a third party application. Tracing the log of hbase-handler/pom.xml file, it is added as part of ant to maven migration and not because of any specific functionality requirement. Dependency  hive-service  is not needed in  hive-hbase-handler  and can be removed.
