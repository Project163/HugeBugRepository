Title

result highlighting has problems with multi-byte runes

Description
When building the highlight there is deteremined to be a fixed size.  Right now this incorrectly operates on bytes.  The size should instead refer to number of runes.

For example we see:

…[[पानी का स्वाद]] [[नीलेश रघुवंशी]] का कविता संग्रह हैं। इस कृति के लिए उन्हें २०�…
1.  This snippet is quite short.  Again, most likely because its 100 bytes, not 100 runes.  With each rune visible here taking 2-3 bytes, it ends up quite short.
2.  The presence of � indicates that we probably stopped the snippet in the middle of a utf-8 sequence.  This results in the browser not knowing how to display the character.
