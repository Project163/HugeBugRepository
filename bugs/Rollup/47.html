Title

Object properties that use ES6 shorthand are renamed.

Description
If Rollup renames a variable that's used in an object literal as a shorthand property, the name of the property will be changed, too.

For instance, this:

``` js
const something = 5;
return { something };
```

May be changed to this:

``` js
const something$$ = 5;
return { something$$ };
```

I would expect it to become this instead:

``` js
const something$$ = 5;
return { something: something$$ };
```

This behavior breaks the API of a module I'm working on. The transpiled version of [Link: this] after being run through Rollup and Babel looks like this:

``` js
self = {
  name: name, set: set, remove$$: remove$$, has: has, get: get, nodes: nodes, getNodes: getNodes
};
```

As you can see, Rollup has changed the name of the `remove` method to `remove$$`.
