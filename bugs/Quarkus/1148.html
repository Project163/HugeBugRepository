Title

injecting Instance results in NPE at io.quarkus.amazon.s3.runtime.S3ClientProducer.client()

Description
**Describe the bug**
Attempt to call any S3Client method on instance injected as
```
  @Inject
  Instance  s3ClientInstance;
```

