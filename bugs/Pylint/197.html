Title

False positive `len-as-condition` in ternary condition

Description
### Steps to reproduce
Use pylint on the following minimal code snippet:
```python
l = [1, 2, 3]
len(l) if l else 0
```

### Current behavior

Pylint issues the warning `len-as-condition` on the second line of the above code.

### Expected behavior

Since `len` is not used as a condition in the above code I would not expect pylint to issue the `len-as-condition` warning.
