- Adding a similar case:

```
drop table test;
create table test (
    id   uuid NOT NULL,
    num  int4 NOT NULL,
    PRIMARY KEY ((id)HASH, num DESC)
);
insert into test(id, num) VALUES 
('774cee8f-f0e9-4c46-8f3d-3b5e7db8b836'::uuid, 1);

explain
/*+ Set(yb_bnl_batch_size 2) */

	'774cee8f-f0e9-4c46-8f3d-3b5e7db8b836'::uuid, 
	'884cee8f-f0e9-4c46-8f3d-3b5e7db8b847'::uuid);

ERROR:  Attribute value type does not match column type: 3 vs 10
- This issue seemed to have happened ONLY when the BNL join condition involves a binary column such as UUID and a non-binary column. A join condition with only a binary column worked fine.
