Title

Each interpreter should have a seperate log file

Description
In the current implementation both spark and spark2 uses spark interpreter,  both phoenix and hive uses jdbc interpreter log file.  

 Each interpreter should have seperate log file.  The same log file for multiple interpreter confuses user and complicated debugging.
