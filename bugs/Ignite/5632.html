Title

Fix node stop hang during snapshot creation.

Description
The "Snapshots 1" suite hangs every 10th run. This issue can be reproduced locally by running the `testCrdChangeDuringHandlerCompleteOnSnapshotCreate` test (failure rate of about 1 in 5-15 runs). The cause is a deadlock between the starting snapshot task and node shutdown process. Stack traces are provided below:
