Title

Non-synthetic ConfigureNotify positions not discarded

Description
Certain window managers reparent windows (for example when resizing) so the xconfigure.x and xconfigure.y will be the position relative to the parent, not what the user wants. XtranslateCoordinates could be used to get the position of the window in the root window, that is the position of the window in the screen.
