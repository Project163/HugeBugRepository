Title

Extended bounds create misaligned empty buckets in date histogram aggregation.

Description
Using a timezone in combination with 'pre_zone_adjust_large_interval' set to true leads to the creation of buckets which are not correctly aligned. 

Example:
Timezone set to CET, interval set to month (march and april are off here):

```
"aggregations" : {
    "histo" : {
      "buckets" : [ {
        "key_as_string" : "2013-12-31T23:00:00.000Z",
        "key" : 1388530800000,
... [Log Snipped] ...
    }
  }
```
