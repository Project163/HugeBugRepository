Title

Quarkus CLI issues WARNINGs for unrecognized .env values in dev mode

Description
### Describe the bug

I have a `.env` file in a directory, which I use to hold sensitive data (e.g. API credentials) and which is read by Quarkus when my application runs.

When I run dev mode via `mvn quarkus:dev` I only see expected output from the app. When I run dev mode via `quarkus dev` I immediately get a screenful of WARNINGs about `Unrecognized configuration key "quarkus.[x.y.z]" was provided; it will be ignored; verify that the dependency extension for this configuration is set or that you did not make a typo" for each of my configuration keys/values for my sensitive credentials.

I am _assuming_ it's because the Quarkus CLI and Quarkus itself share some common configuraton resolver libraries and they both look at `.env` but only one of them is expecting the keys found therein.

### Expected behavior

No WARNINGs for valid configuration values for my application

### Actual behavior

WARNINGs for valid configuration values for my application

### How to Reproduce?

1. Create an app that consumes a configuration property
2. Put that config property in a `.env` in the same directory in which the app will be run
3. Run with `mvn quarkus:dev` and observe no WARNING
4. Run with `quarkus dev` and observe WARNINGs. 
5. Get nervous because of WARNINGs
