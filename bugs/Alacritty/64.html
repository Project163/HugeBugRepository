Title

Index out of bounds when selecting during `yes`

Description
When creating a selection while running the `yes` command, Alacritty will crash with an index out of bounds exception.
Discussion
- For further info: I can reproduce this using `while true; do echo no; done` and selecting. Theoretically, any high-output command that induces fast scrolling would cause this.
- Another interesting detail might be that I *think* I've specifically tested this in the past, so it's possible that there has been a regression and it might be worth bisecting this issue.
- ... [Middle Discussions Snipped for Brevity] ...
- Most definitely. I'd assume that the selection is stored at a specific position and then rotated (moved up) until it leaves the grid. So trying to access it then will lead to an access outside of the grid, leading to an IOOB.

Though I haven't had the time to look at this yet, so this is only a guess.
- I did some testing and this seems to be exactly what the issue is. If I prevent span.{start,end}.line from going larger than the number of lines in the grid then no IOOB will occur.
