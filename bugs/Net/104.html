Title

SubnetUtils does not handle /31 and /32 CIDRs well

Description
SubnetUtils does not handle /31 and /32 CIDRs well. 

 This should be documented and/or fixed. 

  /32 causes an IllegalArgumentException to be thrown (by the way, that should show the upper and lower bounds) 

  /31 gives  
addressCount=0,  
low =   
high=  
and   is rejected as not in range
Discussion
- Also does not handle /0 properly - getAddressCount() returns a negative number, as the number is higher than Integer.MAXINT. 

 /0 should perhaps be rejected as Illegal?
- I should be more explicit about the bounds - I'll fix up the docs.  

 The  /31 addresses=0 example is actually correct with the assumed bounds - it doesnt count the network and broadcast address as usable. I'll look at the range check -I'm not sure that the current impl is 100% correct.
