Title

References to a local repository subdirectory should only be allowed through @repo syntax

Description
That is, if you have:

```
foo/
  WORKSPACE
  BUILD
  bar/
    WORKSPACE
    BUILD
```

and foo/WORKSPACE contains `local_repository(name = "bar", path = "bar")`, then foo/BUILD should not be able to depend on `//bar:whatever`.  Similarly, `bazel build //...` should not include targets in `@bar`.
