Title

d3.scale.log(), 0 in domain

Description
My first bug-report ever so bear with me!

This concerns d3.scale.log() with a value of zero in the domain.

When the input domain contain 0 the javascipt-engine will crash, due to calling log(0). Since log(0) is mathematically undefined, it would be nice if d3 handled this special case instead of causing a total crash.

Using: Version 3.2.7

You can always do a wrapper function. The details will depend on what you want, but for example:

``` js
function myScale(x){
  if (x === 0){
    return 0;
  }else{
    return myRealScale(Math.abs(x))
  }
}
```
