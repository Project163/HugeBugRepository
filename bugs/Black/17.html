Discussion
- Thanks for reporting, I noticed this too, hence no release yet. There are three problems:

1. Trailing comma gets put in a wrong place if there's a trailing comment. Example:
```
    assert scenario.connect_times == {
        " ": 0,
        " ": 0.300,
        #   was never even started
        ,
    }
```
2. When `# yapf: disable` was found in trio/_core/tests/test_run.py, Black decided to discard that content entirely. 🤣

3. Or should I say, 18. This is again a `# yapf: disable`-related bug. This time it's when you disable twice in a row. Black doesn't support statement-level format disabling and it gets confused by this.
```
async def test_getaddrinfo(monkeygai):
    check(res, [
        (tsocket.AF_INET,  #   is ipv4
         tsocket.SOCK_STREAM,
         tsocket.IPPROTO_TCP,
... [Log Snipped] ...
         ("::1", 12345, 0, 0)),
    ])  # yapf: disable
```

I'll fix all three this weekend.
- Thanks for reporting, all this is fixed in 18.4a0!
