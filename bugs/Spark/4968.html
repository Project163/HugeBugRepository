Title

Add task metric to report spill time

Description
The  ExternalSorter  passes its own  ShuffleWriteMetrics  into  ExternalSorter .  The write time recorded in those metrics is never used.  We should probably add task metrics to report this spill time, since for shuffles, this would have previously been reported as part of shuffle write time (with the original hash-based sorter).
Discussion
- Have you noticed the incorrect metrics reported or is this just something you noticed in the code?  My understanding is that my patch maintained the existing behavior of not including the time it spent spilling bytes for ExternalSorter in the shuffle write time.  Are you saying we should in fact include the time we spent spilling in the shuffle write time?
