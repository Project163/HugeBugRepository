Title

set_with_columns_kwargs() does not exist, but recommended

Description
### Polars version checks

- [X] I have checked that this issue has not already been reported.

- [Link: X] I have confirmed this bug exists on the [latest version] of polars.


### Issue Description

`.with_columns(**named_kwargs)` throws an error 

```
RuntimeError: **kwargs support is experimental; requires opt-in via `pl.Config.set_with_columns_kwargs(True)`
```

But the above function does not exist

### Reproducible Example

```
python
import polars as pl
df = pl.DataFrame({"a": [1,2,3]})
ab = df.with_columns([df.get_column("a").alias("b")])
ab2 = df.with_columns(b=df.get_column("a").alias("b"))
... [Log Snipped] ...
Out [53]:
True
```


### Expected Behavior

The function should exist.

Workaround is `pl.Config.with_columns_kwargs = True`
