Title

ActiveRecord::ConfigurationError on has many through with conditions

Description
Hi there,

Hope this is not user error and an actual issue! We're testing out edge and I believe the `ActiveRecord::ConfigurationError` is being raised unnecessarily on a `has_many through` with a clause. `project.contacts` works as expected. Also, version Rails   does not raise.

I can get the test below to pass if I change the `ordered` scope from:

```ruby
order(Arel.sql("users.first_name || ' ' || users.last_name ASC"))
```

to

```ruby
order(Arel.sql("first_name || ' ' || last_name ASC"))
```

We usually try to reference the table name when writing SQL to avoid ambiguous column references. Should we avoid doing that in the future?

Thanks for your time!
