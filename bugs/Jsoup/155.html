Title

Printer is over eager to remove white space in 1.20.1

Description
Given this HTML fragment:
```html
 in span 
Text after span
```

parsing in 1.20.1 removes *all* of the whitespace between the end of the `span` tag and `Text after span`, leaving this:
```html
 in span Text after span
```

It should leave in at least one white space to be the same HTML:
```html
 in span  Text after span
```

Failing test:
```
java
package foo;

import static org.jsoup.Jsoup.parse;

... [Log Snipped] ...
    }
}
```
Discussion
- Thanks for the find. Specifically, it's not the parser, but the printer. Looks like the issue is a textnode following an inline element when in block mode.

You could work around for now by setting the pretty-printer to off.

I'd be happy to review a PR for this if anyone would like to contribute.
