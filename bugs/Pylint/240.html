Title

Spurious messages for loop variables

Description
### Steps to reproduce

```
def call(f):
    print(f())

def test():
    for a in [1,2,3]:
... [Log Snipped] ...

test()
```
prints `2 3 4` as expected but produces
```
z.py:7: error (E0602, undefined-variable, test. ) Undefined variable 'x'
z.py:6: warning (W0612, unused-variable, test) Unused variable 'x'
```

PS: This is an attempt to avoid `cell-var-from-loop` in
```
def test():
    for x in [1,2,3]:
        call(lambda: x+1)
```

### Current behavior

2 incorrect messages (a warning and an error!) are produced for valid code.

### Expected behavior

no messages
