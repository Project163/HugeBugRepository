Title

UriInfo can not be injected in presence of quarkus-rest-client dependency

Description
### Describe the bug

I has an application, which uses a filter (derived from `ContainerRequestFilter`) and adds UriInfo into it via `@Inject` annotation. When I add `quarkus-rest-client` into that application, it fails with `UnsatisfiedResolutionException` during build.

This behavior can only be observed while using the latest Quarkus, classic resteasy and rest-client extensions and `@Inject` annotation. It can not be observed with released version, reactive extensions and when UriInfo injected via `@Context` annotation.

### Expected behavior

Application should build and start properly.
