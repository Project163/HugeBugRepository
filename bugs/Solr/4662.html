- Hmmm, what's the use case? Should the same documents appear at the top of every page as you're paging? 

 CursorMark is intended to handle the "deep paging" issue where "start" is at least in the hundreds. If this combination is intended to keep the elevated documents at the top of successive pages while a user pages, cursorMark is overkill and a workaround would be to just use start without cursormark.
