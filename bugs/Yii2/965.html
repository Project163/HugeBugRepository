Title

Can't get table metadata for tables with '(' in their names

Description
Disclaimer: I know it is a horrible idea to have table names like this, but I have to work with a DB that already contains some and I'd like for my code to work nonetheless.

### What steps will reproduce the problem?
Create a table in the database of the app with parenthesis in the table name, so like:
``CREATE TABLE `example_table(0)` (
 `ID` int(11) NOT NULL AUTO_INCREMENT,
 PRIMARY KEY (`ID`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8``
Try to run this line or any code that involves querying the tables schema.
`Yii::$app->db->getTableSchema("example_table(0)", true);`
### What is the expected result?
I expect to get the table metadata returned, as it is with any other tables without the parenthesis.

### What do you get instead?
`SQLSTATE[42000]: Syntax error or access violation: 1064 You have an error in your SQL syntax; check the manual that corresponds to your MariaDB server version for the right syntax to use near '(0)' at line 1
The SQL being executed was: SHOW FULL COLUMNS FROM example_table(0)`
As you can see, the table name isn't quoted correctly. Looking at the code makes me believe that this issue is present independent of the DB driver.
[URL]
Moreover, it doesn't help if I quote the table name myself, because the quoting characters are removed when building the query. I _think_ this only happens when the MySQL driver is used.

- To fix this issue we can check if the bracket `(` exists and if it is the first letter in table name, then return it without quote. It will not quote the expressions witch starts with `(` but quote table names with brackets like `table_name(1)` etc. 

To do this trick we just need to replace `false` to `0` like this:
```php
if (strpos($name, '(') !== 0 || strpos($name, '{{') !== false) {
```

Or we can add additional check to latest bracket and separate it from `{{` checking like this:

```php
if (strpos($name, '(') === 0 && strpos($name, ')') === strlen($name) - 1) {
    return $name;
}
if (strpos($name, '{{') !== false) {
    return $name;
}
```
