Discussion
- Try with: 

  mvn clean install -Pscala-2.12    -Dscala-2.12   -Pinclude-kinesis -DskipTests
- You have to use  -Dscala-2.12 ; activating the profile directly is not sufficient. If you use the property you can omit the profile activation.

 Maybe it would be useful to specify this in  the relevant doc page .
