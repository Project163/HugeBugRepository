Title

When a table attempts to clean up metrics, it was cleaning up all global table metrics

Description
when i use 
  
 
bin/nodetool tablestats xxxx 
  
 i get this error 
  
 
error: org.apache.cassandra.metrics:type=Table,keyspace=xxxx,scope=feed,name=WriteLatency
-- StackTrace --
javax.management.InstanceNotFoundException: org.apache.cassandra.metrics:type=Table,keyspace=xxxx,scope=feed,name=WriteLatency
 
  
 if i restart the node and check it works but if i write something then i get the error again 
 
	 Cassandra 4.0-beta1 
	 Ubuntu 20
Discussion
- My bad, server is using JVM 11 and nodetool client using JVM 8 that is the reason.
- I have seen this as well with server running JVM 11 and nodetool JVM 11, the issue went away on restart. 

 I took a dump of the metrics and saw that the tables had the MBeans registered, but not TableMetrics (though some tables had both). 

 I am trying to figure out how this happened and will reopen if I make any progress.
