Discussion
- `readable_to_offset_` is updated in `UpdateSegmentReadableOffset` when doing `Log::Sync`.

`UpdateIndexForBatch` is done in `Log::DoAppend` which happens earlier.

There is a gap between setting op index and update the readable offset, which seems cause the issue.
