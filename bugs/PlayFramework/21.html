Title

sbt mysubproject/run doesn't work

Description
If trying to run Play dev mode on a sub project using `sbt mysubproject/run`, it fails with the following exception when you try to use the app:

```
[ERROR] [2014-10-07 13:40:03,019] [application] [New I/O worker #1] -

! Internal server error, for (GET) [/login] ->

java.util.NoSuchElementException: None.get
... [Log Snipped] ...
[WARN] [2014-10-07 13:40:03,097] [play] [New I/O worker #1] - No application found at invoker init
[INFO] [2014-10-07 13:40:03,352] [akka.event.slf4j.Slf4jLogger] [play-akka.actor.default-dispatcher-2] - Slf4jLogger started
```

It seems that we're not executing the `playReload` task for the right project, it's probably being run for the root project, not the selected sub project.
