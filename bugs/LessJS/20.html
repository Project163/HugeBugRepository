Title

Wrong include order of CSS/LESS files

Description
It I have something like:
 link rel="stylesheet" type="text/css" href="ccss/layout.css" 
 link rel="stylesheet/less" type="text/css" href="css/bootstrap.less" 
 link rel="stylesheet" type="text/css" href="ccss/other.css" 
 link rel="stylesheet/less" type="text/css" href="ccss/page.less" 
 script src="/FL_NT/html/js/less-1.1.3.min.js" TYPE="text/javascript" language="javascript"

The less compiled add the compiled .less css appending the css after the last style/link tag. That change the order of the CSS rules and you may end up with something unexpected if an element has class="c1 c2", c1 is defined in other.css and c2 is defined in bootstrap.less.

Less.js should attach the compiled css just after the stylesheet/less that generated it.
