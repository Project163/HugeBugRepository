Title

[Bug]: Using Controller gives incorrect value for isValid

Description
### Version Number

7.13.0

### Codesandbox/Expo snack

[URL]

### Steps to reproduce

1. Go to [URL]
2. Open Console
3. See output from line 24 of App.tsx - isValid (initially false), errors (initially empty)
4. Put any text into the Text1 field
5. See the final line in the console: showing isValid as true, even though both fields are required and Text2 is empty
6. Now type a character into Text2 field, and delete it
7. See the final line in the console: isValid is still true despite Text2 being empty, even though there's an error

### Expected behaviour

The value of `isValid` should reflect all validity constraints set.

My tests suggest the problem does not occur with v7.8.4, and does occur with v7.8.5 and above.

If you comment out lines 29-34 (ie the Controller) and uncomment line 36 (a simple text input), the problem does not occur.


### What browsers are you seeing the problem on?

Chrome
