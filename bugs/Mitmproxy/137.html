Title

Unable to scroll mitmweb details in Firefox

Description
##### Steps to reproduce the problem:

1. Install Firefox ESR 45.7.0 on Linux
2. Capture with mitmweb
3. Find a message that requires scrolling on the right pane, and attempt to view all content. 


##### Any other comments? What have you tried so far?

This seems very similar to issue #615
Chromium scrolls fine.

Discussion
- I tried this out and found that in `.flow-detail section`, if we change the css code like this:
```css
section {
    /* display: flex;
     flex-direction: column;*/
    overflow-y: scroll;
}
```
That works for me on Ubuntu with Firefox 51.0.1 and Chrome 52.0.2743.116, don't know if this works on other browsers.
- @MatthewShao: We only care about Chrome/Firefox for now, so if that fixes things, please submit a PR! 😃
