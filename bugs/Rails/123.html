Title

Serialized attribute is rendered as yaml in form helpers

Description
When you set the value of an input field to a serialized attribute of a model it is rendered as yaml.

To reproduce:
- create a new project and set up a scaffold: `rails g scaffold Post content`
- add `serialize :content` to the post model

When you start the server, create a new post and edit it, the content attribute is displayed in yaml, like `--- test...`.

This seems to be introduced in rails 4.2. Rails 4.1 and 4.0 render the attribute as a string. Tested with both postgres and sqlite.

A workaround is to set the value of the input field explicitly.
