Title

Auto-Config Wizard doesn't save YouTube stream key

Description

### OBS Studio Crash Log URL

### Expected Behavior

Stream keys are retained.

### Current Behavior

Stream keys are not saved.

### Steps to Reproduce

1. Tools -> Auto-Configuration Wizard
2. Select "Optimize for streaming, recording is secondary"
3. Video Settings (Next)
4. Select the service "YouTube - RTMPS” or "YouTube - HLS”
5. Select "Use Stream Key (advanced)"
6. Enter stream key
7. Wait for it to end.
8. Apply Settings
9. Start Streaming
10. "Missing Stream Setup" is displayed.
11. Open Setting -> Stream
12. Stream key is not saved. (The screen is not set to the stream key screen in the first place.)
