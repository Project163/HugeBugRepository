Title

Iceberg's Minor Compaction replicates records

Description
I observed that some records in the current snapshot were replicated after running a minor compaction. I reproduced the issue when I combined a minor compaction, bucket transform, and partition evolutions. I've not identified which factor caused the issue. 

 This is a reproduction. The result set of `SELECT * FROM default.srcbucket_big ORDER BY id` changes after the compaction.
