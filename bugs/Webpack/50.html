Title

syntax error with harmony exports

Description
If an export statement doesn't end with a semicolon the resulting bundle ends up with a syntax error. This appears to be due to the export code being dumped on the same line, rather than the next (as seems to be the case elsewhere).

You can reproduce this pretty simply without any config with webpack 2: `webpack entry.js bundle.js`

**entry.js**

``` javascript
export var foo = "bar"
```

**bundle.js**

``` javascript
// Syntax error
var foo = "bar"/* harmony export */ Object.defineProperty(exports, "foo", {configurable: false, enumerable: true, get: function() { return foo; }});
```

A work around of course is to add a semicolon after the export statement.
However, some code bases already have established (auto-)formatting (e.g. standardjs) so it wouldn't be a long-term solution.
