Title

BUG Tree allows segfault / arbitrary memory access

Description
The properties for accessing attributes on `Tree` return arrays which don't own their data, and which are malloced and freed by the tree. Therefore:

``` python
from sklearn.tree import DecisionTreeClassifier
c = DecisionTreeClassifier().fit([[1,2]], [1])
cl = c.tree_.children_left
print(cl)
del c
print(cl)
cl[0] = 1
```

outputs

```
[-1]
[-849416680]
Segmentation fault (core dumped)
```
Discussion
- Yes, this is meant to avoid copies and to allow to modify the structure of the tree.
- hmm... I guess if we make defensive copies that will hurt performance and disallow to modify the structure
can we fiddle with garbage collection and only allow to remove the object if the refcount on the attributes is one?

- Yes this is fixed. We even added a non-regression test for the bug identified in this issue.
