Title

Rendering maps values omits following '!important' statement

Description
An `!important` statement following maps value retrieval is rendering the values without `!important`

Reproducible on [URL]

**LESS:**
```
less
@colors : {
  primary: blue;
  secondary: green;
}
... [Log Snipped] ...
  color: @colors[primary] !important;
}
```

**Current Result:**
```css
.foo {
  color: blue;
}
```

**Expected Result:**
```css
.foo {
  color: blue !important;
}
```

**Workaround**:
```less
.bar {
  color: @colors[primary] ~"!important";
}
```
