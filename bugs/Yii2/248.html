Title

No log file rotation [FileTarget]

Description
I'm running Yii2 beta, log component is set to all defaults, so all messages are filed to app.log under frontend/runtime. The default settings for FileTarget suggest that the log file will be rotated at 10 MB, however, app.log is 25MB now and no rotation occurs.

I actually sorted this out by doing these changes to `FileTarget`:
- Passed a log file handler `$fp` to `rotateFiles()` in `export()`
- Added `@fclose($fp);` before last `@rename()` in `rotateFiles()`

This way it seems to be working and the log file is rotated. Not very elegant but I'm fine with that while you look for the permanent solution. This solution was mentioned at [URL] at the very first comment.
- @dryu you have to use rotateByCopy in your case because rename does not work. the locking is needed otherwise you get conflicts when mulitple processes try to rotate the logs.
