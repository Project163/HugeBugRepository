Title

Log exception causes no logging at all

Description
When I call Yii::error(new Exception('asdf')); nothing gets logged. Even other loggings are then ignored for the current request.

Is this a bug? Or not? At least it would be nice if I could easily log an exception. Like described [Link: here] I'd like to log it easily if possible.

Using Yii2 2.0.2.
Discussion
- Message parameter accepts string, not an instance of Exception.
- Documentation says: 

[URL]
- the problem in this case seems to be that the exception includes a stack trace of the point where it was created. This stack trace also contains pointers to all the object references of functions being called and also their arguments. If this contains a closure at some point (which it does), the var_export here is going to fail: [URL]
The fallback then fails because of a circular reference.
