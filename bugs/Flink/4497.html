Discussion
- I managed to reproduce the issue and did some debugging. In Hive 2.3.4, the in-progress file is created when Hive creates the Orc writer. In Hive 1.1.0, it seems the file is not created even after the first record is written. When a  Bucket  receives the first record, it creates the writer and writes this record with the writer. And on the 2nd record, the  Bucket  checks the underlying file size to see if rolling is needed and this is when we hit the exception because the file is not yet created.
- Also need fix flink native orc writer for Hive 1.x (orc-nohive).
