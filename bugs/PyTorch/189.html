Title

`torch.cross`'s behavior is different on cpu and gpu on torch 2.5.0.dev20240708+cu121

Description
### 🐛 Describe the bug

on cpu:
```
python
import torch
torch.manual_seed(0)
torch.cuda.manual_seed(0)
a = torch.randn(3, 4)
... [Log Snipped] ...
#         [ 0.9158,  2.3039,  0.7830, -0.6937],
#         [ 1.2427, -3.2395,  0.9753, -1.3094]])
```

on gpu
```
python
import torch
torch.manual_seed(0)
torch.cuda.manual_seed(0)
a_cuda = torch.randn(3, 4).cuda()
... [Log Snipped] ...
#         [ 0.0454, -0.0165,  2.6868, -0.4181],
#         [-1.8018,  1.4298,  2.3755, -0.9607]], device='cuda:0')
```

`a` and `a_cuda` are not equal.
