Title

Remove duplicate code in generated code for map get

Description
There is a bug when we get values from a map with a complex expression key. 

 The reason is the `key.code` in ScalarOperatorGens#generateMapGet will be called twice. 

   

 This is a test case: 
  
 
CREATE TABLE T (
     `name` VARCHAR,
     `map` MAP<VARCHAR, INT>
 ) WITH (
     ...
 );
SELECT `map`[coalesce(name, '')] FROM T;
