Title

View options menu doesn't display overflowed part

Description
#### Problem Description
[Image: Screenshot]

As shown in the screenshot above, the overflowed part of the view options menu doesn't get displayed if the flow detail section is too short.

Removing the `overflow` property on `.flow-detail` and the `overflow-y` property on `.flow-detail section` fixes the issue, but will conflict with the fix of issue #2083. Maybe find a different solution for that issue, or set the `overflow` property of `dropdown-menu` to `auto` and limit the height of it by set its `top` property to a fixed value, like `-300px`.

#### Steps to reproduce the behavior:
1. Open a flow detail that is short enough
2. Open the view options menu
3. The menu get displayed as shown in the screenshot above

#### System Information
Mitmproxy: 6.0.2
Python: 3.9.1
OpenSSL: OpenSSL 1.1.1i  8 Dec 2020
Platform: Windows-10-10.0.16299-SP0
Firefox: 86.0b9
