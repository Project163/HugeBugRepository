Title

TypeError: Cannot read properties of null (reading 'status') in the GUI after killing Syncthing

Description
I keep getting these errors while accessing the Web GUI remotely. This usually happens after Syncthing has been killed on the remote device, e.g. when restarting the computer there. The problem can be reproduced locally, e.g. by killing the Syncthing process (instead of shutting it down gracefully using the GUI, etc.)

To reproduce:

1. Open the Web GUI in a browser.
2. Kill the Syncthing process (e.g. using the Task Manager in Windows).
3. Wait a few seconds.
4. The GUI now displays the following error message:

   [Image: image]

   ```
TypeError: Cannot read properties of null (reading 'status')
       at syncthingController.js:182:25
       at Scope.$emit (angular.js:14835:33)
       at $scope.emitHTTPError (syncthingController.js:425:20)
       at angular.js:9461:11
... [Log Snipped] ...
       at Scope.$apply (angular.js:14694:24)
       at angular.js:14984:22
```
Discussion
- I'd like to add that this problem isn't limited to what I originally wrote. If you try to enable/disable HTTPS in the GUI, it also displays the same error, which is actually more serious then, because it seems to prevent the GUI from triggering a refresh. The error is present when changing themes too, but there the GUI does refresh successfully, so it's only visible for a brief moment.
