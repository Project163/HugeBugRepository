Title

quickfix: ml_get error when updating quickfix list after RPC nvim_buf_attach

Description
### Problem

An ml_get error may happen when updating the quickfix list when an RPC client has called `nvim_buf_attach`.
This is a regression from #31105.

### Steps to reproduce

Run the following test case:
```
diff
diff --git a/test/functional/api/buffer_updates_spec.lua b/test/functional/api/buffer_updates_spec.lua
index 489f601d31..36bbbc8495 100644
--- a/test/functional/api/buffer_updates_spec.lua
+++ b/test/functional/api/buffer_updates_spec.lua
... [Log Snipped] ...
+  end)
 end)
```
It fails with `Vim(caddexpr):E315: ml_get: Invalid lnum: 4`

### Expected behavior

No ml_get error

### Nvim version (nvim -v)

v0.12.0-dev-656+g462f7aaa8e

### Vim (not Nvim) behaves the same?

N/A (codepath requires nvim_buf_attach callbacks to be active)

### Operating system/version

Arch Linux

### Terminal name/version

kitty 0.42.1

xterm-kitty

build from repo
