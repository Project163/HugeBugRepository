Title

File injection in private/unshared repository

Description
Install syncthing (v0.8.13) instances on different machines: A, B. 

Create a repository named "documents" on A, restart syncthing on A. 
Create a repository named "documents" on B, restart syncthing on B. 

Add node of B to syncthing on A. Restart syncthing on A.
Add node of A (NodeA) to syncthing on B. Restart syncthing on B. Enable syncing of repository "documents" on B with NodeA. Restart syncthing on B. 

Create a file in repository "documents" on B. Give it time to sync. The file is synced with repository "documents" on A. 

The repository "documents" is not shared at this point with any node, still files appear in it. So by "guessing" share names one could push files to other (users') private/unshared repositiories.

According to @calmh this bug is a side effect caused by relaxing the security for issue #223
