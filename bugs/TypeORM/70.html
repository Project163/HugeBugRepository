Title

update() not skipping null properties.

Description
Hello, I have this entity defined:

```
typescript
@Entity('users')
export class UserEntity {

  @PrimaryColumn('nvarchar', {unique: true, nullable: false})
... [Log Snipped] ...
  role: UserRole
}
```

And then I have this method (simplified for clarity):
```
typescript
async modifyUser (user: UserEntity): Promise  {
    if (user.email) {// This does not work.
          return this.connection.getRepository(UserEntity)
            .update({email: user.email}, user)
... [Log Snipped] ...
        }
  }
```

It allows to search for an user using either it's username (the primary key) or the email (which is unique).
If I pass in the username it works fine, but if I pass the email I get this error:

```
RequestCannot insert the value NULL into column 'role', table 'testdb.dbo.users'; column does not allow nulls. INSERT fails.
```

Isn't `update()` supposed to do partial updates? Why it's the query an `INSERT` instead of an `UPDATE`?
Discussion
- Yes. It actually (right now) calls `save` method which performs same - makes partial updates. Strange that you have `INSERT` query. I can only assume that you don't have a user with `{ email: user.email }` in the database. Please log what you send to `modifyUser` and check if you really have user with same email in the database.
