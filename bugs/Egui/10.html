Title

Cursor icon flickers at frame boundary (Windows)

Description
**Describe the bug**
The cursor icon flickers between default&resize when hovering over the frame boundary.

**To Reproduce**
1. On desktop / Windows OS
2. Run egui_demo_app
3. Hover over frame boundary to attempt resizing the entire app window
4. Observe that cursor briefly flicker to the Resize icon, then immediately back to Default

**Expected behavior**
The cursor should indicate that resizing is possible
A clear and concise description of what you expected to happen.

**Desktop (please complete the following information):**
 - OS: Windows 10

**Additional context**
Experiment shows that the OS takes control over the cursor for frame resizing. When the call to set_cursor_icon is commented out, the indication of the frame resize area works as expected. The flickering arises because egui_glium forces the cursor icon to its internal setting in every frame.
