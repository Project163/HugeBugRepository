Title

AbstractIntegerDistribution cumulativeProbablitity(int, int) implementation does not match API documentation

Description
The documentation for this method says it computes p(x0 < X < x1), but the parameter documentation inconsistently states that the bounds are "inclusive" and what it actually returns is 
  
 cumulativeProbability(x1) - cumulativeProbability(x0 - 1);
 
  
 which is p(x0-1 <= X < x1). 
In the code above, x0 - 1 should be replaced by x0 + 1.
Discussion
- Once the javadoc API descriptions were reverted to last release versions, the documentation matches the implementation.  Sorry I was confused by the javadoc.  I added a standalone test class confirming that the API contracts match the default impls.
