Title

KRaft servers require valid static socketserver configuration to start

Description
KRaft servers require a valid static socketserver configuration to start. However, it would be better if we could support invalid static configurations, as long as there were dynamically set changes that made them valid. This will require reworking startup somewhat so that we start the socket server later.
