Title

Packaged Prometheus config ignores REPLICATION metrics

Description
The solr-exporter-config.xml provided with Solr does not pick up REPLICATION metrics. This is probably unintentional, as it has configuration for `REPLICATION.replication` metrics, however actual metric names starts with `REPLICATION./replication` (notice the slash).
