Title

HelpFormatter infinite loop with 0 width input

Description
I am writing to report an infinite loop bug in the HelpFormatter class when the width parameter is set to 0. Despite existing protective code meant to prevent this issue, the infinite loop still occurs under certain conditions. 
  
 Problem Description:  
When calling HelpFormatter.printOptions() or any method that uses appendWrappedText() with width=0, the application enters an infinite loop, eventually causing heap space exhaustion.
