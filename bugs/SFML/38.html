Title

Prevent TCP sockets from sending a SIGPIPE signal when disconnected

Description
On Unix, sockets send a SIGPIPE signal on disconnection instead of setting errno. This must be avoided since SFML uses errno to find out the result.

Code for OS X:

```
setsockopt(sd, SOL_SOCKET, SO_NOSIGPIPE, ...)
```

Code for Linux (2.2+):

```
send(..., MSG_NOSIGNAL)
```
