Title

Tag changes in Search tab not reflected in History tab

Description
**Describe the bug**
Managing message tags with the "Manage Tags..." dialog in Search view does not affect message tags in History view. This might not be a bug, but actually just a missing feature, not sure though.

**To Reproduce**
1. find message in "Search" tab
2. got to "Manage Tags"
3. add a new tag and finish the dialogue
4. there is no new tag in the tag column of search view. This will appear if the search is repeated. The tag does not appear in the history view at all

**Expected behavior**
It is expected for a tag added in Search to affect the History view and be persisted in history and the ZAP session.

**Software versions**
 - ZAP: w2018-05-14
 - Add-on: Search is part of the core, right?
 - OS: OSX 10.13.4
 - Java: 1.8.0_152
Discussion
- Yes it's part of the core [URL]
- The update of the history table is probably just a missing call to:
`notifyHistoryItemChanged(historyReference);` like [URL]
- Note that the History tab is now using events to update its state.
