Title

Problem With CompileStatic And Interface Methods In Abstract Subclass

Description
The attached abstractcompilestatic.zip contains the following: 

   src/main/groovy/demo/SomeInterface.groovy   
  package  demo

 interface  SomeInterface {
    void someInterfaceMethod()
}
 
  

   src/main/groovy/demo/AbstractSuperClass.groovy   
  package  demo

 abstract   class  AbstractSuperClass  implements  SomeInterface {}
 
  

   src/main/groovy/demo/AbstractSubClass.groovy   
  package  demo

 import  groovy.transform.CompileStatic

@CompileStatic
 abstract   class  AbstractSubClass  extends  AbstractSuperClass {

    void someMethod() {
        someInterfaceMethod()
    }
}

Discussion
- This was reported as a Grails issue at  [URL]
- This seems to be caused by the static type checker not considering methods of interfaces declared but not implemented by the super class when attempting to find a given method. Specifically,  findMethod(ClassNode, String, ClassNode...)  in StaticTypeCheckingVisitor looks for unimplemented interface methods by calling  collectAllInterfaceMethodsByName(ClassNode, String, List<MethodNode>)  which only collects methods from interfaces declared by the given class.
