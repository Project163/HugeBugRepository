Title

Naming a closure __getattr__ triggers `Invalid signature`

Description
Mypy won't let me name a closure `__getattr__`. Since it's not a method I'm not sure why mypy would care what the signature is. This is somewhat important, though, as Pytho 3.7 supports `__getattr__` functions in modules.

* Are you reporting a bug, or opening a feature request? bug
* Please insert below the code you are checking with mypy,
  or a mock-up repro if the source is private. We would appreciate
  if you try to simplify your case to a minimal repro.
```python
def foo():
    def __getattr__():
        pass
    return __getattr__
```
* What is the actual behavior/output? `tester.py:2: error: Invalid signature "def () -> Any"`
* What is the behavior/output you expect? No error
* What are the versions of mypy and Python you are using? CPython master, mypy 0.59
  Do you see the same issue after installing mypy from Git master? yes
* What are the mypy flags you are using? (For example --strict-optional) None
