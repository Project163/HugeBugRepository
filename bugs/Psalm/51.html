Title

Psalm thinks types are mixed when you cast to arrays

Description
Casting a string to an array returns an array containing the string. But paste this in getpsalm.org:

```
php
  $bar
... [Log Snipped] ...
    return (array) $bar;
}
```

You'll see errors where Psalm has decided the type of `(array) $baz` is `array ` instead of `array `
