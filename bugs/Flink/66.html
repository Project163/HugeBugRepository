Title

FilterNode set estimated data size to unknown

Description
The default selectivity estimate of a Filter is 0.5. 
During optimization, the FilterNode correctly adapts the estimated cardinality but sets the estimated data size to unknown.

       FLINK-1150   Fix output size estimate of FilterNode. 

     FilterNode implicitly sets the estimated output size to unknown (-1) while adjusting the cardinality by a factor of 0.5.
