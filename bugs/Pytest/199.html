Title

Description
Origin: [Link: question on SO]

Prep for reproducing:

```
sh
$ mkdir issue
$ printf 'def test_spam():\n    assert True\n' > issue/test_eggs.py
$ pytest issue/test_eggs.py::test_spam

... [Log Snipped] ...
```
