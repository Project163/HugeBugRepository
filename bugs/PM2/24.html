Title

--no-daemon gets parsed by pm2 even when passed as argument to started script

Description
When running, for example the following command:

```
 pm2 start loader.js -- --no-silent --no-daemon --production
```
#### Expected behavior

Arguments after `--` are passed to loader.js rather than used by pm2
#### Actual behavior

`--no-daemon` is used as both an argument to loader.js **and** an argument to pm2 resulting pm2 being run with `--no-daemon` which is not the desired behavior
#### Steps to reproduce

Run a script that takes --no-daemon as an argument.
#### Software versions used

```
OS         : Ubuntu Server 16.04
node.js    : v6.3.0
PM2        : 1.1.3
```
#### PM2 Log output

```

--no-daemon option enabled = do not exit pm2 CLI
PM2 daemon PID = 3744
[PM2] Streaming realtime logs for [all] processes
...
```
