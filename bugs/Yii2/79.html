Title

[Bug] Alias for authFile in rbac/PhpManager not resolved

Description
If I use a proper alias the file will not be loaded! I need to resolve the alias myself. 

```
'components.auth' => [
    'class' => 'common\components\PhpManager',
    'authFile' => '@common/data/rbac.php',
    //'authFile' => realpath(__DIR__ . '/../').'/data/rbac.php',
    'defaultRoles' => ['guest'],
],
```

Debugging shows that the alias is never resolved and therefore the file is not loaded.

BTW, I think Yii should raise an exception if the file cannot be found and not simply skip the loading.
