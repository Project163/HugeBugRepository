Title

CSS3 Properties Being Renamed

Description
What steps will reproduce the problem? 
1. Compile the following code using advanced optimizations.

    document.getElementById("id").style.appearance = "button";
    document.getElementById("id").style.resize = "both";

 What is the expected output? What do you see instead? 

Output expected : as same as the input
Output seen instead: (formatted)

    document.getElementById("id").style.a = "button";
    document.getElementById("id").style.b = "both";


 What version of the product are you using? On what operating system? 

This error is with the live version at [URL]
Discussion
- appearance is not standardised yet. webkitAppearance works as expected. [URL]

resize does appear to be missing (although it is still technically working draft). If you want to add it to your own version, add this to externs/w3c_css.js:

/**
 * @type {string}
 * @see [URL]
 */
CSSProperties.prototype.resize;

maybe somebody will add it to the main code.
