Title

Commit diff count is off for repos migrated from GitHub

Description
### Description

For releases that got migrated from GitHub, the commit diff between the tag and `refs/heads/main` is off for some releases. Compared to the actual diff, the count on Gitea is in short of 1. Also, the diff on specific release page is showing `0` instead of the correct value.

The issue seemly only happens when a release is tagged against `refs/heads/main` instead of `main` on GitHub, and then get migrated. It's also unclear if the existence of a draft release is linked to it. It needs further investigations.
