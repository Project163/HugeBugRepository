Title

TensorFlow Lite Micro fully connected int8 test passes illegal filter offset

Description
An external developer pointed out that the test for the quantized fully connected operation passes in a non-zero weight offset to the kernel for int8 tests:
[URL]

The quantization specification promises that int8 kernels will always receive zero weight offsets:
[URL]

This failing test is preventing an optimized kernel for a hardware platform from being accepted.
Discussion
