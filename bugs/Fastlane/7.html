Title

Download of crashlytics-devtools.jar fails behind proxy

Description
### New Issue Checklist
- [x] Updated fastlane to the latest version
- [Link: x] I have read the [Contribution Guidelines]
### Issue Description

When using the crashlytics action without specify the crashlytics_path path, crashlytics_helper.rb attempts to download the jar, but fails when running behind a proxy. It appears 'Net::HTTP.get(URI(url))', does not use the ENV['http_proxy'] setting as opposed to when using 'Net::HTTP.new(host, port)'.

Replacing lines 75/76 or crashlytics_helper.rb with the following block solves the issue:

```
        uri = URI(url)
        httpConn = Net::HTTP.new(uri.host, uri.port)
        httpConn.use_ssl=true
        result = httpConn.request_get(uri.path)
        raise "#{result.message} (#{result.code})" unless result.kind_of? Net::HTTPSuccess
        File.write(zip_path, result.body)
```
