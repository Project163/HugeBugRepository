Title

EmailValidator won't validate domain in the email address with name with checkDNS=true

Description
Imagine email: `Ivan Petrov  `
Try to validate with `checkDSN = true`. On my Fedora20 linux server it fails, 
because preg_match() by default is greedy and will not correctly parse the domain out of the 
email address with name. Domain name will be like `gmail.com>`.
Need to change regex to  `/^(.*? ?)$/` 
in `\yii\validators\EmailValidator::validateValue($value)`
I had to add additional `?` after quantifiers `*` before ` ` in order to make it non-greedy. Then it worked for both email types with and without name.
