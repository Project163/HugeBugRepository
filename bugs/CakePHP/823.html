Title

Redirecting outside subdirectory after upgrading to 3.3.3

Description
This is a (multiple allowed):
- [x] bug
- [ ] enhancement
- [ ] feature-discussion (RFC)
- CakePHP Version: 3.3.3.
- Platform and Target: PHP5.5.12, MySQL 5.6.17, Apache/2.4.9.
### What you did

My app was running on CakePHP 3.2.13 in a subdirectory called cake, I have put a condition on routes.php file to check if the app installed or not and if not installed redirect to installation wizard using this code
`Router::redirect('/**', ['controller' => 'Install', 'action' => 'index'], ['status' => 307])`
and it was redircting to [URL] but after upgrading to CakePHP 3.3.3 it is redirecting outside the subdirectory like this [URL]
### Expected Behavior

It should redirect within the subdirectory like this [URL]
Discussion
- Is that redirect route all that someone would need to reproduce this issue?
- To reproduce this issue, add the below code after `Router::defaultRouteClass(DashedRoute::class);` line into your app `routes.php` file

``` php
if (!file_exists(CONFIG.'configuration.php')) {
    Router::connect('/install/:action', ['controller' => 'Install']);
    if (strpos(env('REQUEST_URI'), 'install') === false) {
        return Router::redirect('/**', ['controller' => 'Install', 'action' => 'index'], ['status' => 307]);
    }
}
```

The above code will check if `configuration.php` is not exsiting then redirect to install controller.
