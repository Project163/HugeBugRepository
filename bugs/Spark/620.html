Title

Utils.getLocalDir() may return non-existent spark.local.dir directory

Description
The patch for   SPARK-2324   modified Spark to ignore a certain number of invalid local directories.  Unfortunately, the  Utils.getLocalDir()  method returns the  first  local directory from  spark.local.dir , which might not exist.  This can lead to confusing FileNotFound errors when executors attempt to fetch files.
