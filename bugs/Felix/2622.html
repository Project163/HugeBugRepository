Title

BundleNamespace on Req/Cap is not translated correctly

Description
When translating Requirements and Capabilities with namespace 'osgi.wiring.bundle' some attributes are not translated correctly. 

 Currently 'osgi.wiring.bundle:osgi.wiring.bundle' is translated to 'bundle:bundle' but it should be translated to 'bundle:symbolicname'. 

 Also 'bundle-version' should be translated to 'version'
