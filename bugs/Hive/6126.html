Title

hive-exec.jar leaks contents fb303.jar into classpath

Description
thrift classes are now in the hive classpath in the hive-exec.jar (  HIVE-11553  ). This makes it hard to test with other versions of this library. This library is already a declared dependency and is not required to be included in the hive-exec.jar. 

 I am proposing that we not include these classes like we have done in the past releases.
