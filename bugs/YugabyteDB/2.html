Title

tserver crash when copying data

Description
Encountered a tserver crash today when I tried to use copy command. In this particular case the data was aggregate counters. So, effectively in the same batch we had multiple records which had the same primary key, and non-primary key columns in the table were all counters.

Error from tserver logs:

```
E0305 18:37:00.424288  6387 process_context.cc:180] SQL Error: Execution Error. Reading from a row modified in the same batch request is not supported yet
```
