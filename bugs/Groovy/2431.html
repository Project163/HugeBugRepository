Title

Compiler reporting bug when calling extension module method in Groovy 2.2

Description
The Groovy compiler reports a bug when calling a method added by an extension module to a class using Groovy 2.2.  The error message is:  

 "Declaring class for method call to 'fj.data.Stream to(java.lang.Integer, java.lang.Integer)' declared in java.lang.Integer was not matched with found receiver int. This should not have happened!." 

 I have created a Github repository demonstrating the error at  [URL]

 The to method here is added to a Java class called Stream using a Groovy extension module.
