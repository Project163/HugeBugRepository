Title

GzCompressAction leaves files open until GC when an IO error takes place

Description
The class  org.apache.logging.log4j.core.appender.rolling.action.GzCompressAction  leaves files open when an IO error takes place. Since  FileInputStream  and  FileOutputStream  have  finalize()  methods, the JVM should  eventually  close the appropriate resources though, but perhaps not before the files left open cause other problems.
