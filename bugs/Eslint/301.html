Title

yoda range fails on 'this' reference

Description
Using a rule

```
"yoda": [ 2, "never", { "exceptRange": true } ]
```

and given the code

```
if (1<=this.prop && this.prop<=10) console.log('ok');
```

ESLint (v0.17.0) fails with _Expected literal to be on the right side of <=_ (it should pass).

I suspect this might be in `lib/rules/yoda.js: function same(a, b)`: for the above example, `a.type` comes through with `ThisExpression` which is not covered in the switch expression.
