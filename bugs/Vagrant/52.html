So far, I ran some tests with a `Vagranfile` like this:

```
ruby
Vagrant.configure(2) do |config|

  config.winrm.transport = :ssl
  config.winrm.ssl_peer_verification = false
... [Log Snipped] ...

end
```

And the generated ansible inventory looks something like:

```
# Generated by Vagrant

win8 ansible_connection=winrm ansible_ssh_host=  ansible_ssh_port=55986 \
ansible_ssh_user='vagrant' ansible_ssh_pass='vagrant'
trusty ansible_ssh_host=  ansible_ssh_port=2222 ansible_ssh_user='vagrant' \
... [Log Snipped] ...
[linux]
trusty
```

By forcing the `ansible_connection` mode in the inventory, there is no need to change anything in the `ansible-playbook` arguments.
If you want to use a static custom inventory, then you'll have either to set `ansible_connection=winrm` in your inventory, or as via the `raw_arguments` array.

:warning: :question: Please tell me if this is enough for your desired usages...

Notes: 

Ansible 1.9 does not seem to support WinRM in `:plaintext` mode (but it's coming in Ansible 2). For a basic/unsafe `winrm-ssl` environment, I had to monkey patch my ansible installation with a custom `callback_plugins` to skip the SSL certificate validation (see ansible/ansible#10294).
