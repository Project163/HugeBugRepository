Title

Full page reload when using redirect in getServerSideProps on a rewriten URL

Description
### What version of Next.js are you using?

10.2.3

### What version of Node.js are you using?

v14.15.5

### What browser are you using?

Firefox

### What operating system are you using?

macOS

### How are you deploying your application?

next start (locally or in Docker)

### Describe the Bug

A full reproduction is available in [Link: this repository].

**When using `redirect` in `getServerSideProps` and using a `destination` which is rewriten in `next.config.js`, then Next reload the full page in the browser instead of doing a client-side navigation**

Example :

- The `/` URL is rewriten to `/some-page`
- When navigating to `/some-other-page`, we may want to redirect to `/`
- Doing so performs a full reload

```
javascript
// next.config.js
module.exports = {
    async rewrites() {
        return [{
... [Log Snipped] ...
    }
}
```

```
javascript
// some-other-page.js
export default function SomeOtherPage() {
    return  Some other page 
}
... [Log Snipped] ...
    return { props: {} }
}
```



### Expected Behavior

A client-side navigation should be performed, and Next should fetch `some-page.json` as it does when using `/some-page` as a redirection destination.
