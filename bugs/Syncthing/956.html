Test cleanup fails all model tests on Windows on Go 1.20

Description
Pretty much all the tests fail at cleaning up the temp dir:

```
...

```
Discussion
- Looks exactly like this, which is fixed in go1.19, and the code hasn't been changed since that fix:     
[URL]
- Yes though apparently it has. Our model test are quite convoluted though, especially in terms of setup and tear down, and creates
a bucketload of temporary files and directories often inside the repo. I started cleaning it up to consistently use the fakefs where possible which removes this issue.
- For what it's worth, I was on one of the [Link: original threads] where a similar bug was reported and the fix from that thread didn't resolve the issue for me. While investigating, the most likely conclusion I reached was that a file handle not being closed in the Windows file handling code related to temp directories and tests, however I ran out of time before I could pinpoint the exact line of code where the file was being left open when the temp dir cleanup was occurring. For our tests, we worked around the issue by avoiding temp dir creation at all. Based on my findings, no amount of delay or retry is going to resolve this specific Windows issue. 

Caveat, although I've been programming for decades, I'm a newbie with Go. Everything I said above could be completely wrong and/or misleading.
