### Current behavior?

C++ API `MatrixDiagV3` aborts with tensor type of `k`.
Usually `k` would be given as an array of integers. But it can also accept a tensor, and it can lead to crash.
Suspected code location is [Link: here],
But I have no idea why it is not triggered when it runs with an integer array `k`.
