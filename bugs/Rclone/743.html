Title

null response for /operations/stat api when directory has trailing slash

Description
Hello Team,

First of all thanks for the wonderful tool.

I am using rclone in rc mode from few months and having great experience.

While using recently it recently found one use case where the behavior of api could have been better I felt , so raising this to provide more info.

When I am using  "/operations/stat" api with cloud remote (adls/aws) found that trailing slash(/) in directory path gives below response :

Request -
```
{
	"fs": "appsettingchanges_6019_ADLS_82c880d2_bb71_45d1_96be_08db1bc37687:",
	"remote": "o9datalake/Folder1/"
}
```
Response - 200
Response body -
```
{
	"item": null
}
```

The response could be something other than null and also when I use trailing slash with data copy api (/sync/copy) it works witout any error and able to copy/sync data.


Same above issue discussed here in this in details-

Thanks,
Mahendra
