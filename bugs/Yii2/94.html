Title

yii\widgets\LinkSorter - ul options problem

Description
Options of ul tag are hardcoded in yii\widgets\LinkSorter.php on line 71: 

return Html::ul($links, ['encode' => false]);

So that it is impossible to set css class of sorter the following way:

  $dataProvider,
        'sorter' => [
            'options' => ['class'=>'sorter some-class'],
        ]...

Default value is also not used due to the same reason -

line 38: public $options = ['class' => 'sorter'];

It would be great to leave the opportunity to set options dynamically, something like that:

return Html::ul($links, $this->options);
