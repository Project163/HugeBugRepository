Title

[DocDB][DDL replication] ALTER DEFAULT PRIVILEGES fails with DDL replication

Description
Jira Link: [Link: DB-16525]
### Description

Version: `2025.1.0.0-b33`

Steps:
1. Create database and tables at both sides
2. Setup DDL replication
3. Create role at both sides
4. set created role and run
`ALTER DEFAULT PRIVILEGES REVOKE select on tables from role_name`
5. Reset role and run
`ALTER DEFAULT PRIVILEGES REVOKE select on tables from role_name`

Noticed:
Both fails with
`ERROR:  Found NULL value when parsing oid (column 1)`

it is working for Databases which are not part of DDL replication.
