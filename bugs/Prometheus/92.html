Title

[Promtool] `promtool check config` doesn't properly check `bearer_token_file` file existence

Description
**What did you do?**

While working on #5222, I was trying to reproduce the error with `bearer_token_file`. I ran `promtool check config $my_config` against a config file that has `bearer_token_file` set to a path to a file that doesn't exist.

**What did you expect to see?**

Promtool should fail, as it explicitly checks if a file exists for the `bearer_token_file` path.

**What did you see instead? Under which circumstances?**

Promtool check succeeded. During unmarshalling of configs, they'll call `c.HTTPClientConfig.Validate()`. This [Link: validate function moves] the `bearer_token_file` info to `Authorization.CredentialsFile` and sets `bearer_token_file` to `""`. So when promtool goes to check the config struct, it [Link: only checks the `bearer_token_file`] which is set to empty string.

If we want to keep the same functionality, we need to update this check to look at `config.HTTPClientConfig.Authorization.CredentialsFile` instead.
