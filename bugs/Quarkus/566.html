Title

A project with both docker and jib extension - no warning about this situation and image gets build twice under the same name

Description
A project with both docker and jib extension  - no warning about this situation and the image gets build twice under the same name.

Expectation:
 - warning about the situation
 - optionally: only one build, but who should win?

I did some experiments with docker build and wanted to see the differences in jib image so I added the jib extension. But the docker image produced by the new run had the same image size as the previous one. So that made me a bit worried before I realized two builds happened during the mvn command execution.

Reproducer:
```bash
mvn io.quarkus:quarkus-maven-plugin:1.3.2.Final:create \
    -DprojectGroupId=org.acme \
    -DprojectArtifactId=getting-started \
    -DclassName="org.acme.getting.started.GreetingResource" \
    -Dpath="/hello" -Dextensions="docker,jib"
cd getting-started
mvn clean package -Dquarkus.container-image.build=true
```
Discussion
- Having more than 1 `container-image-*` extension is probably a bad idea indeed. Hmm, not sure if `container-image-s2i` also collides...

IMHO detecting `container-image-docker` and `container-image-jib` should be easy, and should lead to a build time error.
- Indeed, I'll take care of it (just need to think of the best way to do it).
