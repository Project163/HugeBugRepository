Title

[Regression] `Module not found` to `url()` function (sass) when compiling

Description
### What version of Next.js are you using?

12.0.3

### What version of Node.js are you using?

14.17.0

### What browser are you using?

Chrome

### What operating system are you using?

Windows

### How are you deploying your application?

Vercel

### Describe the Bug

From `next` [Link: v12.0.3-canary.2], [Link: special functions] of `sass` , like _url_, aren't compiled correctly.

### Actual Behavior
```
console
ready - started server on  :3000, url: [URL]
error - ./pages/style.scss:4:0
Module not found: Can't resolve './data:application/font-woff;charset=utf-8;base64'

... [Log Snipped] ...

[URL]
```

### Expected Behavior

Compiling done.

### To Reproduce

1. `yarn init -y`
2. `yarn set version berry`
3. `yarn add next@canary react react-dom sass`
4. Create `pages/_app.js` file:
```js
import './style.scss'
```
5. Create `pages/style.scss` file:
```scss
@font-face {
  src: url(data:application/font-woff;charset=utf-8;base64) format('woff');
}
```
6. `yarn next`

OR (my use case)

1. Clone [Link: material-ui + next] example
2. `yarn set version berry`
3. `yarn add @mui/material@5.0.4 next@canary sass videojs-font`
4. Create `pages/style.scss` file:
```scss
@import 'videojs-font/scss/icons';
```
5. Add in `pages/_app.js` file on first line:
```js
import './style.scss'
```
6. `yarn next`
