Title

Calcite engine. Query planning failed when cache size is too big

Description
We use cache size as estimation for row count while planning, but use  cache.size()  method, that returns int value. But if cache size is more than  Integer.MAX_VALUE  we get an wrong size or even negative sometimes, which cause assertion errors during planning. 
We should fix it to  cache.sizeLong() .
