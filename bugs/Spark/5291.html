Title

Description
This is actually a followup for   SPARK-22033  , which set the `ARRAY_MAX` to `Int.MaxValue - 8`. It is not a valid number because it will cause the following line fail when such a large byte array is allocated:  [URL] We need to make sure the new length is a multiple of 8.
