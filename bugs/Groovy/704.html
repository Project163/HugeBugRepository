Title

Concatenating GStrings produces gaps for GSQL

Description
Concatenating Gstring produces "gaps" in the values/strings lists. Thias is a problem when used as GSQL blocks 

                 def x = "dog" 
                def y = "woof-woof" 
                def gs1 = "the ${x} says " 
                gs1 = gs1.plus(" ${y} "); 
                gs1 = gs1.plus(" not the cat"); 
                print gs1   // works fine 
                print gs1.getProperties().inspect()  // now you see the empty values 

 This GString would result in a sql Block with 4 Parameters, but only should have 2 (sorry I did'nt use real sql as example) ,
