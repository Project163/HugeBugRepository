Title

Do not collapse projects in CombineUnions if it hasCorrelatedSubquery

Description

 Here is a simple example to reproduce this issue 
  
 
SELECT (SELECT IF(x, 1, 0)) AS a
FROM (SELECT  true ) t(x)
UNION 
SELECT 1 AS a
