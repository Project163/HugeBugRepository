Title

Dev mode stops without reason instead of restart when fired by code Changed (worked with 1.4.2.Final)

Description
**Describe the bug**
Problem can be simulated on the example from camel-quarkus: [URL]

Problem doesn't happen with quarkus **1.4.2.Final**. (but happens with 1.5.0.cr1, 1.5.0.Final and master)

**Expected behavior**
App is reloaded with custom code change.

**Actual behavior**
App stops.


**To Reproduce**
Steps to reproduce the behavior:
1. Download [URL] (version of quarkus could be chaged in [URL]
