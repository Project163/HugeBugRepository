Title

Reinstate locale mapping

Description
From zaproxy/zap-extensions#1358.

ZAP is not picking up translations from several languages (e.g. Indonesian). This is caused by an "incompatibility" in the language codes (more details in [Link: JDK-4778440]). In previous ZAP versions the locale/language code mapping was being done after downloading the translations files from Crowdin, but that was removed as it didn't seem to be necessary anymore... :/
