Title

pylint #9223 __future__ module does not contain real symbols

Description
Originally reported by: **Claudiu Popa (BitBucket: [Link: PCManticore], GitHub: @PCManticore)**

---

```
#!python

from __future__ import division

def some_func():
    division = 2
```

Pylint warns that `division` is redefined from outer scope. This is not the case, since the `division` imported from **future** is not a symbol. Original ticket: [URL]
