Title

Visits with a hash (#) where you are visiting the same base url will not navigate.

Description
Back to back `cy.visit` where the url contains a hash (#) and you are visiting the same base url (before the hash) does not navigate to the 2nd url.

This is a regression introduced in [Link: `0.17.2`], specifically the commits relating to "No longer forcing `cy.visit` to navigate to `about:blank` prior to navigating to the real url." to fix Issue #208.

**Example Code**

```
javascript
describe("user", function() {
  it("visits user page", function() {
    cy.visit("[URL]
  });
... [Log Snipped] ...
  })
})
```
