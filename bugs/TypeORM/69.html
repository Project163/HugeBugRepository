Title

Sqlite: composite primary key ignored on synchronization

Description
When using two columns as primary key in sqlite like this:
```
typescript
import { Entity, PrimaryColumn, Column } from 'typeorm';

@Entity()
export class ExampleEntity {
... [Log Snipped] ...
  otherColumn: boolean;
}
```
When making a change a creation sql like this is generated:
```sql
CREATE TABLE "temporary_example_entity"
("id1" varchar NOT NULL, "id2" varchar NOT NULL, "otherColumn" boolean, PRIMARY KEY(id1))
```
But is should be
```sql
CREATE TABLE "temporary_example_entity"
("id1" varchar NOT NULL, "id2" varchar NOT NULL, "otherColumn" boolean, PRIMARY KEY(id1,id2))
```

This issue only exists when syncing. The initial creation is correct.
