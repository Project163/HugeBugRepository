Description

### Description

While running the select queries etc from the cassandra driver version: '3.8.0-yb-7' on YB DB version 2.14.x it throws an error below. 

```
Exception in thread "main" com.datastax.driver.core.exceptions.InvalidQueryException: Wrong Metadata Version: Table has been altered. Execute the query again. Requested schema version 0, got 20. (ql error -303)
```

This issue is not happening in older YB versions i.e 2.6.x.
