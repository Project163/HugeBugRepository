Title

Cannot make a nullable object typedef non-nullable

Description
What steps will reproduce the problem? 

I'd like to use nullable object @typedefs, so that they match default nullability behavior of the @constructor type names.

So, I define a type like this:

/** @typedef {{foo:number}|null} */
Types.MyClass;

But this way, it can be no longer made non-null (unlike @constructor types). i.e.

/**
 * @param {!Types.MyClass} a
 */
function dontWantNulls(a) {
}
dontWantNulls(null); // No compiler warnings!


 What is the expected output? What do you see instead? 

The /** @type {!Types.MyClass} */ should describe a non-null Object.


 What version of the product are you using? On what operating system? 
Build at r2388. Linux OS.
Discussion
- Try this:

/** @typedef {?{foo:number}} */
Types.MyClass;
- It is the same thing. And I do expect this to be the same.
- This is interesting.  It works for variable declarations:

/** @const */
var Types = {};
/** @typedef {{foo:number}|null} */
Types.MyClass;

/** @type {!Types.MyClass} */
var x = null;   // warning

/** @type {Types.MyClass} */
var y = null;   // no warning

/**
 * @param {!Types.MyClass} a
 */
function dontWantNulls(a) {}
dontWantNulls(null); // no warning
