Title

webpack@2.1.0-beta.8 SyntaxError because of extra paren

Description
Code in question:

```
js

    import cls from 'classnames';

    // ...
... [Log Snipped] ...
      [`${baseClassName}_is-filled`]: Boolean(this.getValue()),
    });
```

After `beta.8` there is `SyntaxError: Unexpected )` (note 1 opening paren and 2 closing ones):

```
js
var dropdownClassName = /* harmony import */ __WEBPACK_IMPORTED_MODULE_2_classnames___default.a.call(
  undefined,
  _cls = {},
  _cls[baseClassName] = true,
... [Log Snipped] ...
  _cls
));
```

After `beta.7` everything is fine (2 opening and 2 closing parens):

```
js

  _cls = {},
  _cls[baseClassName] = true,
  _cls[baseClassName + '_is-open'] = uiState.isOpen,
... [Log Snipped] ...
  _cls
));
```

Code was run through `babel` with this `.babelrc`

```
json

    "transform-decorators-legacy",
    "transform-class-properties",
... [Log Snipped] ...
  ]
```
