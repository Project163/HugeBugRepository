Title

Description

UPDATE validation_cf_counter SET test=test + 1 WHERE id='test_key' => Success 
UPDATE validation_cf_counter SET test=test - 1 WHERE id='test_key' => Success 
UPDATE validation_cf_counter SET test=test-1 WHERE id='test_key' => Failure (line 1:38 no viable alternative at input 'test')
