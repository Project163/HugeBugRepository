Title

(Nix) `grammarOverlays` not applied in flake package

Description
### Summary

The `grammarOverlay` argument is not passed anymore to the Helix package in the flake which prevents users for adding their own grammar overlays.

The fix seems pretty straight-forward, as far as I can tell. Since the `grammarOverlays` still exists in `grammars.nix`, we just need to update `default.nix` to take as another argument the `grammarOverlays` again, like so:

```
nix
{
  lib,
  rustPlatform,
  callPackage,
... [Log Snipped] ...
  grammars = callPackage ./grammars.nix { inherit grammarOverlays; };
  # ...
```

### Reproduction Steps

  

Here are the reproduction steps:

1. Import the Helix flake in your flake
2. Use the provided package
3. Override the package with `.override { grammarOverlays = []; }`

I expected this to happen:

Being able to pass a grammar overlay to the derivation.

Instead, this happened:

The package fails to build with a grammar overlay provided with `.override`.
