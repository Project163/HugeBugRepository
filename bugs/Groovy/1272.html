Title

Class ReleaseInfo isn't thread-safe

Description
Current implementation of class ReleaseInfo doesn't look like it's thread-safe.
Discussion
- Since we don't use the class in the runtime itself and it is only for the purpose of others reading that information I suggest to make all initialization in the static initlizer. The boolean can be removed then and the read access to the properties should then be safe enough. Of course a write operation may still cause problems. 

 Another way of "fixing" would be by documenting that this class is not thread safe and requires external synchronization.

- unless Peter thinks different I would say it should be good to go
