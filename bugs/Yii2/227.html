Title

Compressed assets result in file paths in the HTML tags

Description
When I use the asset compressor, the resulting minified CSS and JS files have their file paths registered in the ` ` and ` ` tags instead of their URLs.
### Details

The converter/compressor will set the keys `js` and `css` with file paths:

[URL]

``` php
$outputFile = $target->basePath . '/' . strtr($target->$type, ['{hash}' => md5_file($tempFile)]);
rename($tempFile, $outputFile);
$target->$type = [$outputFile];
// i.e., 'css' => array('/var/www/myapp/public/css/all-xxx-css')
```

The asset bundle object will register those file paths as URLs:

[URL]

```
php

foreach ($this->css as $css) {
    if ($css[0] !== '/' && $css[0] !== '.' && strpos($css, '://') === false) {
        $view->registerCssFile($this->baseUrl . '/' . $css, [], $this->cssOptions);
... [Log Snipped] ...
    }
}
```

So in the HTML we will have this:

``` html
 .css" rel="stylesheet">
 .js"> 
```
