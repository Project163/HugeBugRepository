Title

Cannot create property '__anonymousType' on symbol

Description

[x] bug report

**Current behavior**
Within a TS file I create a very simple `symbol` and an injectable class. When this symbol is used as an injection reference it breaks:

```ts
  const MyGlobalService = Symbol('MyGlobalService');

  // ...
  constructor(
    @Inject(MyGlobalService) private _service: any
  ){}
  //...
```

Discussion
- Why do u think angular supports injection by `Symbol`?

See [URL]
- It is indeed a bug (you should be able to use anything as a DI token).

The fix is probably to use a `WeakMap` instead of adding hidden properties.
- For anyone else reading this in the future - this has been reverted in #15319, so Symbols again can't be used. Note that you can use an `InjectionToken` instead (which even accepts a type parameter).
