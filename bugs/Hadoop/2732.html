Title

Upgrade JUnit to 4.13.1

Description
A reported vulnerability reported in JUnit4.7-4.13. 
The JUnit4 test rule  TemporaryFolder on unix-like systems does not limit access to created files
Discussion
- There's about 40 uses of TemporaryFolder in the project test suites, so yes, we should upgrade. 

 it's only a security issue if 
 
	 test writes sensitive data 
	 host is multiuser 
	 tests run with java.io.tmpdir set to the default of /tmp. Doesn't look like our builds change this value. 
 

 So: enough risk the update is justified, especially as this is a test JAR update only
