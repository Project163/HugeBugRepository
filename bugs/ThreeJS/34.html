Title

SkinnedMesh: Animations on shadow when material.skinning = false

Description
I tried to get animations working on a SkinnedMesh yesterday, and found this a bit strange: When shadows are enabled, and the skinning attribute on the mesh's material isn't set to true, the animation still shows on the shadow, while the model remains static.

Here's an example using the buffalo from the examples: [URL]
Example with my model: [URL]

I would expect material.skinning to enable animation on both shadow and model, not just one of them.
Discussion
- @oal Basically, the code responsible for this behavior can be found [Link: here]:

```
if ( object.customDepthMaterial ) {

    material = object.customDepthMaterial;

} else if ( object instanceof THREE.SkinnedMesh ) {
... [Log Snipped] ...

}
```

So as you can see, the decision about shader parameters is being made based on your model attributes rather than on the current object's `material`. Maybe @mrdoob, or @alteredq could explain to you why it works this way :)

However, If you want to change this behavior you can provide `object.customDepthMaterial` (as you can see in the code above). Before creating one, just look at these [Link: examples]:

```
_depthMaterial = new THREE.ShaderMaterial( { fragmentShader: depthShader.fragmentShader, vertexShader: depthShader.vertexShader, uniforms: depthUniforms } );
_depthMaterialMorph = new THREE.ShaderMaterial( { fragmentShader: depthShader.fragmentShader, vertexShader: depthShader.vertexShader, uniforms: depthUniforms, morphTargets: true } );
_depthMaterialSkin = new THREE.ShaderMaterial( { fragmentShader: depthShader.fragmentShader, vertexShader: depthShader.vertexShader, uniforms: depthUniforms, skinning: true } );
_depthMaterialMorphSkin = new THREE.ShaderMaterial( { fragmentShader: depthShader.fragmentShader, vertexShader: depthShader.vertexShader, uniforms: depthUniforms, morphTargets: true, skinning: true } );
```
