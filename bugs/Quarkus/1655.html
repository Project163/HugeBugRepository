Title

Remote servers that require a trailing slash can no longer be called with Quarkus 2.11

Description
### Describe the bug

As [Link: discussed on Zulip], Quarkus 2.11 introduces a change in `quarkus-rest-client-reactive`: trailing slashes are removed from REST paths. This makes it impossible to call a remote server that requires a trailing slash.

### Expected behavior

Trailing slashes should be preserved.

### Actual behavior

Trailing slashes are removed. The calls fail with a 404 status when the remote server does not accept requests without a trailing slash.

### How to Reproduce?

_No response_

### Quarkus version or git rev

2.11.0.Final
