Title

[DocDB] Copy to a range-organized table is very slow with large rows_per_transaction

Description
Jira Link: [Link: DB-4496]
### Description

Copying to colocated table (without packed rows enabled) is very slow on a large rows_per_transaction. Specifically, when large rows per transaction is used by copy command, the average write latency increases substantially.
The increasing write latencies at the tablet server indicate that the latency is coming from docdb. See image below.
