[upgrade/static] ChangeDetectionStrategy.OnPush - input change doesn't induce change check

**Current behavior**
 

A downgraded component with OnPush change detection strategy is used in an ng1 component. Changes to the component inputs are completely ignored.

This occurs only in upgrade mode. Workarounds:
* disable OnPush,
* use setter method and call changeDetectorRef.markForCheck() in the setter

**Expected behavior**
 

Change to input property should induce a change detection check.
