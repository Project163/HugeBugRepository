Title

Import Notebook has 1MB limit but there is no error when save large size Notebook

Description
1.Save/Download a notebook that is larger than 1MB,  there is no warning/error. 
2. When import the saved notebook, there is 1MB limitation. 

 Suggestion: Saving a notebook that is larger than 1MB should show warning/error messages.
Discussion
- Hi, Could you attach a sample notebook which exceeds 1MB? 

 And This occurs even in 0.7.1, we can add this issue for 0.7.2 release.
- My experience has been that the serialized notebook includes not only the paragraph texts and config information but also the displayed data (paragraphs with  %sql select ... ,  z.show(...) , or equivalent. 

 So in some cases (particularly for highly interactive educational or analytical notebooks with large amounts of data displays), the size limit can be silently exceeded, and a rude shock is delivered when someone tries to import that notebook again. 

 For these cases it would be very useful to have the size check, and a popup to warn the user of the situation. The user can then clear the output before trying to save again.
