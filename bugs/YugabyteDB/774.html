Title

[DocDB] Fix strongly typed bool to generate compile time constants

Description
Jira Link: [Link: DB-4011]
### Description

Currently we define StronglyTypedBool::kTrue and kFalse externally to the class.
As result they are established as runtime variables that requires initialisation.
It is possible to redefine them to achieve compile time initialisation.
I.e. kTrue will be replaced with 1 and kFalse will be replaced by 0 by compiler.
