Title

Regression in pack200's Archive class -- underlying InputStream is now closed

Description
On   TIKA-4221  , on our recent regression tests, we noticed a change in the behavior of Pack200's Archive class. In 1.26.0, the unwrapping of the FilterInputStreams ( [URL] effectively disables CloseShieldInputStreams, which means that the underlying stream is closed after the parse. 

 This causes problems when a Pack200 file is inside of an ArchiveInputStream. 

 Not sure of the best solution. There's a triggering file on the Tika issue. We can implement a crude workaround until this is fixed in commons-compress. 

 Thank you!
