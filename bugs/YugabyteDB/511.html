Title

[YSQL] Crash on usage of TEMP table in procedure

Description
`debug` build crashes on attempt to use `TEMP` table in procedure.
`release` build provides unexpected results.

Example:

```
CREATE TEMP TABLE test(k int, v int);
CREATE PROCEDURE test_temp_table(kv int) AS $$
BEGIN
  INSERT INTO test VALUES(kv, kv);
END; $$ LANGUAGE 'plpgsql';
... [Log Snipped] ...
CALL test_temp_table(3);
SELECT * FROM test;
```
