Title

3.0 $entity->id returns a new uuid instead of the entity id

Description
Tested in a behavior (3.0 dev3)

``` php
$entity = $this->newEntity($data);
$this->save($entity);
return $entity->id;
```

Database settings : id is primary and set to CHAR(36)
It returns a new uuid and breaks relationships.

In the other case :
Database settings : id is primary and set to INT(11).
It works, it returns the entity id.
Discussion
- Not sure I understand the issue here.
- Did an id exist in the data passed to newEntity()?
- He might be confusing the entity that goes in and the one that comes out.
Wouldnt it usually be this way?

``` php
$entity = $this->newEntity($data);
$result = $this->save($entity);
$id = $result->id;
```
