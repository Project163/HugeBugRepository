Title

Synchronizing iteration of Configuration properties object

Description
It is possible to encounter a ConcurrentModificationException while trying to iterate a Configuration object.  The iterator method tries to walk the underlying Property object without proper synchronization, so another thread simultaneously calling the set method can trigger it.
Discussion
- See   TEZ-3413   for a sample backtrace.  I believe the fix is to simply lock the Property object while iterating it within the Configuration#iterator method, but I haven't thought through all of the potential interactions to see if we don't also have to lock the Configuration object itself as well or do something even more complicated.
