Title

vim.cmd.delete and undo can cause segmentation fault

Description
### Neovim version (nvim -v)

0.8.0-dev-752-gbcb4186cf

### Vim (not Nvim) behaves the same?

N/A (nvim_cmd)

### Operating system/version

Ubuntu 20.04

### Terminal name/version

wsltty

### $TERM environment variable

xterm-256color

### Installation

build from repo

### How to reproduce the issue

minimal.lua
```lua
vim.api.nvim_buf_set_lines(0, 0, -1, false, { "aa" })
vim.cmd.delete({ range = { 0 } })
vim.cmd("undo")
```

```
build/bin/nvim --clean +'luafile minimal.lua'
zsh: segmentation fault (core dumped)
```


### Expected behavior

No crash.

### Actual behavior

Crash.

📝 use `vim.cmd("0delete")` or `range = { 1 }` to avoid crash.


```
build/bin/nvim --clean --headless +'luafile minimal.lua'
```
