Title

AttributeError: 'list' object has no attribute '_reset_empty'

Description
**Describe the bug**
Using `noload('*')` and then `contains_eager` for another relationship breaks if that relationship has a backref with `lazy='dynamic'`.

**Expected behavior**
No error, this worked fine in 1.3

**To Reproduce**

```
py
from sqlalchemy import *
from sqlalchemy.orm import *


... [Log Snipped] ...

print(s.query(Foo).join(Foo.bar).options(noload('*'), contains_eager(Foo.bar)).all())
```
