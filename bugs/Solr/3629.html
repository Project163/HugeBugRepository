Title

Ref Guide: Update for *PointFields & deprecated Trie*Fields

Description
The Ref Guide doesn't have much about Point fields, so needs to be updated since they are now default numeric types. 

 A few things to do: 

 
	 Note that all Trie*Fields are deprecated. 
	 Update the field type descriptions (in  field-types-included-with-solr.adoc  so they don't refer to TrieFields to describe how they function (like, "This works just like a Trie* field..."), since that will be less & less relevant to users as time goes on. 
	 Review all the mentions of Trie fields and replace them with new configurations or descriptions that use PointFields instead.
Discussion
- I've got all of item 1 and about half of item 3 on the above list done - a few remaining references are over my head because I'm not entirely sure where Point fields don't work yet.  

 I don't think the remaining change  have  to be done for 7.0 - they could wait. So, I'll commit what I have so far and someone else could do a review to see if they could fix the rest. 

 I found these pages that discuss Trie* fields in a way that needs to be updated for Points: 

 
	 docvalues.adoc 
	 function-queries.adoc 
	 spatial-search.adoc 
	 the-extended-dismax-query-parser.adoc 
	 the-standard-query-parser.adoc 
	 working-with-dates.adoc
