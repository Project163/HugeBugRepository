Title

Config comments sometimes ignore incorrect options

Description
Credit goes to @gyandeeps for catching this one:

``` js
/* eslint vars-on-top:"aaalways", semi:true */
function foo() {
    foo()
    var bar = 42
}
```

``` sh
$ eslint --reset --no-eslintrc test.js
# No errors reported
```

[Link: `eslint.js` line 290] was causing the incorrect configuration to be ignored because `semi:true` failed the filter.

This will be fixed by removing that line entirely and letting the validator catch any errors.

Working on this.
