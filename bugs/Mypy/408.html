Title

attr plugin should make attributes instance only

Description
This is somewhat related to #708. If you use Callables as attrs then mypy will assume they are methods and not instance variables.

For example, the following gives type errors on the call. 

```
import attr
from typing import Callable
@attr.s
class G:
   _cb: Callable[[int, int], bool] = attr.ib()
... [Log Snipped] ...
    def foo(self) -> bool:
        return self._cb(5, 6)
```

```
foo.py:9: error: Invalid self argument "G" to attribute function "_cb" with type "Callable[[int, int], bool]"
foo.py:9: error: Too many arguments
foo.py:16: error: Invalid self argument "F" to attribute function "_cb" with type "Callable[[int, int], bool]"
foo.py:16: error: Too many arguments
```

I'm working on a fix. Just wanted to file this in case anybody else notices.
