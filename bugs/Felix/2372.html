Title

Metatype information might contain wrong default values

Description
The metatype information for the JettyService does not consider values from the bundle context properties. Therefore it can happen that it for example contains the port 8080 while the actual port is something different. If a tool now uses the metatype information to create a configuration form it displays the wrong value and once such a configuration is saved, unexpected changes might occur. 
This can be easily reproduced by using the property to change the port when starting an instance, going to the web console and saving the configuration. The port will change to 8080 without any further action. 
The same happens to all properties that have been changed through bundle context properties.
