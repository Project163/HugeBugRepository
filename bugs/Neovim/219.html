- The problem here appears to be that for a valid CDPATH entry (`~user`) `os_get_user_directory` gets used directly, but for a non-existing one it falls back to using the shell for expansion, which looks like being done too early (before the event queue is setup).

It works after Nvim has started up (although it seems unnecessary to call a shell twice here (another issue; [URL]
