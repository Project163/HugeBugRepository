Fatal error when analyzing an incorrectly structured docblock

Description
I cannot extract the code required for reproducing this from a proprietary codebase. The stack trace during the error looks like the following:
```

 22. Psalm\Type::scrapeTypeProperties($type = *uninitialized*, $combination = *uninitialized*) vendor/vimeo/psalm/src/Psalm/Type.php:520
```

The value of `$this->value` during the `__toString()` function call is `(int) 1`. It looks like it comes from a definition like this:
```php
/**
 * @return 1 if supported, -1 if unsupported
 */
function test() {}
```
The numeric values of the type names are implicitly cast to `int` because they are used as array keys in `TypeCombination::$value_types` and then are iterated over:
```php
$combination->value_types[$type_key] = [];

// ...

foreach ($combination->value_types as $generic_type => $value_type) { }
```
