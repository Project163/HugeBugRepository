Title

Jottacloud rclone copy using server-side copy crashed with SEGV.

Description
#### What is the problem you are having with rclone?

I was running two of these copies (different destination directories) at the same time on the same machine, and both of them seemed to crash at about the same time, so I'm going to guess that they got back an unexpected response which caused that (the machine itself isn't low on memory and shouldn't have otherwise failed).
