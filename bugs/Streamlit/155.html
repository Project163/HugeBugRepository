Title

setIn Error with `st.empty`

Description
### Summary

Streamlit produces a `setIn` error when using `st.empty`

### Steps to reproduce

From: [URL]

Code snippet:

```python
import streamlit as st

placeholder = st.empty()
column, = placeholder.columns(1)

if column.button("Click me"):
    placeholder.empty()
```

Or even more succinctly:

```python
import streamlit as st

placeholder = st.empty()
placeholder.columns(1)
placeholder.empty()
```

1. Run script
2. Press the button

**Expected behavior:**

The button should disappear, and there shouldn't be an error.

**Actual behavior:**

The button disappears, but there's an error.

### Is this a regression?

No

### Debug info

- Streamlit version: 0.85.0
- Python version: 3.8.6
- Using Conda? PipEnv? PyEnv? Pex? None
- OS version: Mac OS X
- Browser version: Brave Browser
