Title

`no-useless-call` rule false positive

Description
Using `1.0.0-rc1`, the unnecessary `apply` (`no-useless-call`) rule fails on common case of using `concat` to flatten an array one level deep. Consider:

``` js
var arr = [].concat.apply([], [[1], [2], [3]])
console.dir(arr)
```

With config:

```
"no-useless-call": 2
```

Giving this error:

```
t.js:1:11: unnecessary ".apply()".
```

But it works if you add a space to one of the arrays:

``` js
var arr = [].concat.apply([ ], [[1], [2], [3]])
console.dir(arr)
```

This looks like a bug. These are different array instances, so the rule should never report any errors here.
Discussion
- ``` js
var arr = [].concat.apply([], [[1], [2], [3]])
```

Its result is same as

``` js
var arr = [].concat([1], [2], [3])
```

So the `apply()` is extra.  You can remove the `apply()` safely.
