Title

one-var rule doesn’t have default options

Description
# Problem description

In my `.eslintrc` I’ve configured the `one-var` rule as `"one-var": 2`, according to the [Link: rule documentation] the default option should be `"one-var": [2, "always"]`.

If I try to lint the following code with `"one-var":  2`

``` js
var foo = 'a';
var bar = 'b';
```

I get no error. When I set the configuration to `"one-var": [2, "always"]` in my `.eslintrc` then I get the expected errors.

---
## Reproducible in the online demo

No error:

``` js
/*eslint "one-var": 2 */
var foo = 'a';
var bar = 'b';
```

Works as expected:

``` js
/*eslint "one-var": [2, "always"] */
var foo = 'a';
var bar = 'b';
```

---

Seems like the default options were removed in commit  .
Discussion
- What is wrong here code or docs?
- I would say the code, because the rule does nothing although the rule is explicitly enabled.
- With that being said, `always` should be applied to `var` , `let` and `const` when the config is like this
`/*eslint "one-var": 2 */`
- @gyandeeps yes, `"one-var": 2` should have the same behavior as `"one-var": [2 "always"]`.
