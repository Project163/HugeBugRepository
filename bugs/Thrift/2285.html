Title

Add AIX support

Description
Building the Go library on AIX results in the following error: 
  
 -bash-5.2$ go build ./lib/go/thrift 
# github.com/apache/thrift/lib/go/thrift 
lib/go/thrift/socket_unix_conn.go:61:80: undefined: syscall.MSG_DONTWAIT 
  
 Unlike most other POSIX platforms, AIX does not have a MSG_DONTWAIT. On AIX matching behavior can be achieved with the MSG_NONBLOCK flag instead. I will open a PR on github with a suggested patch.
