Title

Client node may not stop

Description
There is possible case when client node is not stopped and blocked on waiting when SocketReader will be completed. Looks like interruption was lost, and the only place where it could happen is in unmarshaling message from input stream. 

 The way to overcome/fix it is to check if InterruptedException was in cause of IgniteCheckedException and repeatedly interrupt reader on stop.
