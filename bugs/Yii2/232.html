Title

Any way for Flash messages to persist during redirects?

Description
Is any way to change this behavior or you'll have to handle redirects individually each time?

Example: access rules in SiteController by design are configured so that guest has access to login and password reset.

Requests:

```
GET     [URL]      200     (display password reset form)
POST    [URL]      302     (submit form successful, user is redirected by `goHome()`)
GET     [URL]                                 302     (user is redirected due to access rules)
GET     [URL]                            200     (flash message about successfull reset is lost)
```

So, finally when view is rendered after all redirects flash message that reset token was succesfully sent is lost.
Discussion
- Its strange. Flash message should remove only when you access it. This should work by design.
- Each time `Session` is started, it will increment the counter of each flash message by 1 (the counter starts at 0). If a counter is more than 1 the message will be removed. This is by design.
