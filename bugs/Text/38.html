Title

JaroWinklerDistance: Wrong results due to precision of transpositions

Description
The method  JaroWinklerDistance#matches  returns  transpositions / 2  as integer. However, it is not granted for  transpositions  to be even. E.g. comparing "aaabcd" and "aaacdb" will result in  transpositions  = 3. Therefore the method must return 1.5, not 1. Otherwise the similarity is 0.  instead of 0. . 

 I recommend to return  halfTranspositions  instead of  transpositions  and doing the cast and division ( (double) mtp [1]  / 2 ) in  JaroWinklerDistance#apply .
