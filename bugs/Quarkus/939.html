Title

Liquibase hot reload - This pool is closed and does not handle any more connections!

Description
**Describe the bug**
I am starting a new quarkus project which uses the quarkus-liquibase extension.

On normal quarkus start (mvn quarkus;dev), the liquibase changesets are run fine.

On hot reload, I get the exception from below.

**Expected behavior**
Liquibase migrations are executed succefully on hot reload.

**Actual behavior**

**To Reproduce**

Link to a small reproducer (preferably a Maven project if the issue is not Gradle-specific).

Or attach an archive containing the reproducer to the issue.

2. Start the database: docker compose up -d
3. Start quarkus: mvn clean compile quarkus:dev. Notice that it just starts.
