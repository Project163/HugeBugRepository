Description
### Discussed in [URL]

### Summary

We started to use [Link: react-aria-components] in our NextJS project and we encountered something strange: when using just a simple ` ` from **_react-aria-components_**, the entire  140kb+ **_react-aria-components_** package is imported in the app as seen in the [Link: next-bundle-analyzer] report below:

[Image: image]


At first, I thought this is a problem with how the files are exported from **_react-aria-components_**. 

I don't think this is the case, because a [Link: Vite] React project shows it only imports under 40kb of react-aria-components packages as seen in the [Link: vite-bundle-visualizer] report below:

[Image: image]

Is [Link: next-bundle-analyzer] outputting wrong data or is there a problem with the NextJS builder?

Following this issue, I came across other two opened issues:
- [URL]
- which points to [URL]

Reading these I noticed that using 'use client' in every page does bring the react-aria-components package size down to ~40kb:
[Image: image]

[Image: image]

You might thing the issue is solved, but nooo. 

As you will notice in the NextJS repos I created to replicate the issue and I listed below, the "/" page is using a simple ` ` and the "/other-page" is using a more complex ` ` component. Still, the "/" page that is using only a ` ` contains all of the modules for the ` ` component EVEN IF the "/" page is not using the ` ` component at all. 🤯
