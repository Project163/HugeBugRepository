Title

Persistent growing high CPU usage with proxy

Description
**Describe the bug**
High CPU usage 25% (1 full core) is observed after ZAP starts and proxies a WebSocket request from Firefox.
With passive scan configured to scan only in-scope objects, and none domains added to scope, after fuzzer scan finishes, 50% constant CPU usage is observed.
After a while, CPU utilization rises to 75% (3 full cores out of 4)

**To Reproduce**
Steps to reproduce the behavior:
1. Start ZAP 
2. Configure Passive scanner to scan only in-scope objects
3. Close ZAP
4. Restart ZAP
5. Open Firefox
6. Observe Firefox calls a WebSocket and gets response
7. Check ZAP CPU utilization
8. Fuzz some site with 2000 payloads
9. After fuzzing finishes, check CPU utilization
10. Wait 10 minutes.
11. Check CPU utilization

**Expected behavior**
ZAP when there is no active|passive jobs to do shouldn't utilize full cores of CPU.
