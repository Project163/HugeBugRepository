Title

AttributeError: 'Attribute' object has not attribute 'name'

Description
Seems to be an issued directly related to PR [URL] and issue [URL] When using a metaclass from a subpackage that can't be imported, and then referencing another variable from said subpackage within the same scope, an ``AttributeError`` is raised. Removing the ``assert`` line in the given file below prevents the error. Came across this while writing unit tests, hence the ``assert`` statement.

### Steps to reproduce

Given a file `lintme.py`:
```python
# pylint: disable=C0304,C0114,C0116,C0115,R0903
import pkg.sub

class Failed(metaclass=pkg.sub.Metaclass):
    pass
assert pkg.sub.value is None
```

### Current behavior

Result of `pylint lintme.py`:
```
(pylint-bug) [rydrew@redhat-worklp pylint-error]$  pylint lintme.py
************* Module lintme
lintme.py:2:0: E0401: Unable to import 'pkg.sub' (import-error)
Exception on node  > in file '/home/rydrew/Documents/pylint-error/lintme.py'
Traceback (most recent call last):
... [Log Snipped] ...
    name = klass._metaclass.expr.name
AttributeError: 'Attribute' object has no attribute 'name'
```

### Expected behavior

Only the import error is shown

```
(pylint-bug) [rydrew@redhat-worklp pylint-error]$  pylint lintme.py
************* Module lintme
lintme.py:2:0: E0401: Unable to import 'pkg.sub' (import-error)
```
