Title

Icon for Windows apps is not working

Description
**Describe the bug**
When Building  windows the windows exe does not get the window icon

**To Reproduce**
Steps to reproduce the behavior:
build any app from tauri cli

**Expected behavior**
When building the app the icon in the app icon (left top corner) should be visible, but defaults to the standard no icon.
However the icon is there for the actual exe as shown below

Discussion
- Found the issue. The default ID used by `winres` is wrong. To fix it, change your `src-tauri/src/build.rs`:

Old:
`res.set_icon("icons/icon.ico");`
New:
`res.set_icon_with_id("icons/icon.ico", "32512");`
- I'll change the default tauri template to include this. Thank you for the report :)
