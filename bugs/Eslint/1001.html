Title

Master unit tests are failing after Espree upgrade

Description
**Tell us about your environment**
- **ESLint Version:** Master branch
- **Node Version:** n/a
- **npm Version:** n/a

**What parser (default, Babel-ESLint, etc.) are you using?** Espree 3.2.0

After release of Espree 3.2.0 our unit tests started failing in master: See [URL] for example. This is not good, since we haven't enabled ES2017 anywhere yet, and all of the tests should continue to pass.
Discussion
- The Acorn change consumed by espree was semver-major. Maybe they introduced a general breaking change?
- The tests are failing due to a bugfix in Acorn. For example, this was previously parsed correctly by Acorn, but is actually invalid according to the ES2015 spec:

``` js
function foo(bar, bar = 5) {
}
```

I think the test failures that we're seeing are cases where our tests used syntax that is invalid according to the spec. (See the note on `no-dupe-args` and `no-redeclare` in #7101)
