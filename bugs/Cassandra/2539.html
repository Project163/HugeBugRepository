- Totally baffled, these logs show the same thing: everything's working normally.
- What I'm seeing is that on the first boot of 2.0, ring/status show the other nodes as down, even though the logs indicate everything is fine.  And indeed, it is, reads and writes work normally.  The other nodes on 1.2 see the 2.0 node as up.  If you restart the 2.0 node at this point, the cosmetic problem goes away and everything appears normal.  This appears to stem from   CASSANDRA-3533   unconditionally sending echo commands and only adding the node to liveMembers if it responds, which cannot happen with nodes < 2.0.  Patch to conditionally mark anything < 2.0 up without the echo.
