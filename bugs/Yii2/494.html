Title

Migration bug Timestamp

Description
There's a related bug that someone has already closed (https://github.com/yiisoft/yii2/issues/8080) but I think it's a yii bug.

I've the following migration:

```
    $this->createTable('sector', [
        'id' => Schema::TYPE_PK,
        'name_i18' => Schema::TYPE_INTEGER. ' NOT NULL',
        'created_at' => Schema::TYPE_TIMESTAMP,
        'updated_at' => Schema::TYPE_TIMESTAMP
    ], $tableOptions);
```
