Title

cross-module extends doesn't work

Description
// Module 1
/** @constructor */ function Foo() {}
module.exports = Foo

// Module 2
/** @const */
var Foo = require('./foo')
var util = require('util')

/**
 * @constructor
 * @extends {Foo}
 */
var SubFoo = function () {}
util.inherits(SubFoo, Foo)

Emits a warning like:
    [junit] JSC_TYPE_MISMATCH. mismatch in declaration of superclass type
    [junit] found   : Foo$$module$foo
    [junit] required: Foo$$module$subfoo

The @const requirement is also a bit weird, but for this bug i'm focusing on the mismatch. There's a problem where it doesn't recognize that the alias is equivalent to the original type.
Discussion
- (or perhaps more precisely, it resolves the Foo symbol in the type annotation differently than the Foo symbol in the inherits expression, and doesn't treat the 2 symbols equal. We could either fix this by fixing the equality relation, or fixing the symbol resolution.
