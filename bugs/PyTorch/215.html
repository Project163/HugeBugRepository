Title

`torch.stack` fails with `CUDA error: an illegal memory access was encountered` after a `permute`

Description
### 🐛 Describe the bug

Hi,

Stacking more than 128 tensors whose dimensions have been permuted on cuda may lead to corrupted results.

The following code should print twice "True" but fails with the output:
```
RuntimeError: CUDA error: an illegal memory access was encountered
CUDA kernel errors might be asynchronously reported at some other API call, so the stacktrace below might be incorrect.
For debugging consider passing CUDA_LAUNCH_BLOCKING=1
Compile with `TORCH_USE_CUDA_DSA` to enable device-side assertions.
```

The code:
```
import torch

if __name__ == "__main__":

    def test_stack(imgs):
... [Log Snipped] ...
    print(test_stack([t for _ in range(128)])) # True
    print(test_stack([t for _ in range(129)])) # False or RuntimeError: CUDA error: an illegal memory access was encountered
```

I hope this description is enough to reproduce and obliterate this bug!
