Title

Stax2Validation doesn't support schema imports.

Description
Using the Stax2Validation for validating a wsdl, a NPE is being thown. 
After some analysis I could find that the targetNamespace is being used as key to save schemas to process (please see  this code line ) 

 However, a WSDL can have the following format in the <wsdl:types> element: 

  
  <wsdl:types> 
     <xsd:schema> 
             <xsd:import namespace= "[URL] schemaLocation= "foo.xsd" /> 
             <xsd:import namespace= "[URL] schemaLocation= "bar.xsd" /> 
     </xsd:schema> 
 </wsdl:types> 
 
  

 As you can see in these cases, the targetNamespace is not present in the schema element that is only used for importing external schemas.
