Title

MetaClassImpl calling method twice

Description
When calling a closure as a local method the MetaClassImpl doesn't check the method name on the MissingMethodException to make sure it was the missing method we are calling and as a result can re-call the closure and call the method twice, attempting the delegate (which is the owner unless overridden).  The problem is if some other mme gets thrown that is not the expected MME. 

 This fails, foo() gets called twice. 
  
  int  count = 0
foo = {
  println  "foo Closure" 
  count++
  bar()
}
closure1 = { println  "Closure1" ; foo() }

 try  {
    closure1()
    fail()
}  catch  (MissingMethodException mme) {
     assert  mme.method ==  'bar' 
     assert  count == 1
} 
  

 The solution is to assert the method name on the MME before putting it aside and trying again on the delegate.   

 Patch forthcoming.
