Title

Web UI does not cleanup temporary files

Description
The web UI creates two directories in  java.io.tmp , namely  flink-web-<uuid>  and  flink-web-upload-<uuid>  and both are not cleaned up (running  start-cluster.sh  and  stop-cluster.sh .
