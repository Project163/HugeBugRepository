Title

EventBridge providers should be bound without scope

Description
Currently all event bridge providers (JMS, XMPP, JGroups) are bound in default scope (i.e. as singletons). And that brakes things in case of shared  DataRowStore  is disabled. 
So they should be bound without scope and provide new instances for every request to provider.
