Title

xunit.runner.msbuild 2.3 doesn't detect it is running in TeamCity

Description
Reproduction of error here: [URL]

This contains two identical projects, the only difference between the two is the version of `xunit.runner.msbuild` (2.2, which works, and 2.3, which doesn't).  Both projects are targeting .NET framework 4.7.

The batch file which runs each program first sets the `TEAMCITY_PROJECT_NAME` env variable to simulate running under TeamCity.

- Build solution with VS2017
- Set startup project to Test-2.2 and run with F5
- Note that the output contains
```
  ##teamcity[testSuiteStarted name='Test collection for Test.Test (1)' flowId=' ']
  ##teamcity[testStarted name='Test.Test.test' flowId=' ']
  ##teamcity[testFinished name='Test.Test.test' duration='11' flowId=' ']
  ##teamcity[testSuiteFinished name='Test collection for Test.Test (1)' flowId=' ']
```

- Now set startup project to Test-2.3 and run with F5
- Note that the output is missing the lines starting with `##teamcity` as above.
Discussion
- That's... weird. That code did not change, unless the TeamCity reporter isn't available for some reason...
- Yeah, that is exactly what's going on:

```
C:\Dev\xunit\xunit.integration\msbuild\v2x_net452\v2x_net452.csproj(56,5): error : Reporter value 'TeamCity' is invalid. There are no available reporters.
```

Doh!
