Title

Imported variable used in dynamic property name are not replaced

Description
**Do you want to request a *feature* or report a *bug*?**
Report a bug
 
 

**What is the current behavior?**
When importing a variable and using it as a dynamic property name, it is not replaced in the bundle.
```js
import var1 from './export';
const { [var1]: value } = {};

```
```
js
/* 1 */
/***/ (function(module, __webpack_exports__, __webpack_require__) {

"use strict";
... [Log Snipped] ...

/***/ })
```
**How to reproduce**
See [Link]
**What is the expected behavior?**
Expected to replace the dynamic propery name with the imported variable. Something like : 
```
js
/* 1 */
/***/ (function(module, __webpack_exports__, __webpack_require__) {

"use strict";
... [Log Snipped] ...

/***/ })
```

Node 7.6.0
