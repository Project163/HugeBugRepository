Title

"DropboxHash" is now just "Dropbox"

Description
#### What is the problem you are having with rclone?

Not a problem per-se but there is a missing change in the changelog that should be noted:

The hash from Drobox used to be called `DropboxHash` and now returns as `Dropbox`. This is a better name but should have been noted in the changelog!
