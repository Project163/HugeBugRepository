- The AppLocalFromInstalled target is added by Vcpkg, which indicates this is a problem on our side, not protobuf's.

The powershell call stack error indicates it is very likely to be an issue in the `scripts\buildsystems\msbuild\applocal.ps1` file. I think the problem is if the DLL in question has no dependencies then the script will enter an infinite loop of "Does this directory have any DLL dependencies? Empty string? Ok, let's see if the directory's parent has any dependencies!".
- I believe I've fixed this issue, however I was unable to reproduce it locally since it seems to require a very old version of powershell. Please let us know if the problem persists.
