Title

JDBC - Use Statement.executeUpdate instead of PreparedStatement.executeUpdate for DDLs

Description
Certain DataFrame APIs invoke DDLs such as CREATE TABLE and DROP TABLE under the covers. Current code in DataFrameWriter and JDBCUtils uses PreparedStatement.executeUpdate to issue the DDLs to the DBs. This causes the DDLs to fail against couple of databases that do not support prepares of DDLs. 

 Can we use Statement.executeUpdate instead of PreparedStatement.executeUpdate? DDL is not a repetitive activity, so there shouldn't be a performance impact. 

 I can submit a PULL request if no one has objections. 

 Thanks.
