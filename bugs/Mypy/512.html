Title

error: Item "None" has no attribute "__bool__"

Description
```python
thing = None
assert not thing.__bool__()
print(thing.__bool__())
```

As expected:
```
False
```

Not expected:
```
test:2: error: Item "None" has no attribute "__bool__"
test:3: error: Item "None" has no attribute "__bool__"
```

cf. python/typeshed#2432
Discussion
- This should be easy to fix by adding a special case for things that are defined on `None`, but not on `object`, which is apparently only `__bool__` on Python 3:
```
{'__bool__'}
```
Look at `checkmember.analyze_member_access` under this comment :-)
```
# The only attribute NoneType has are those it inherits from object
```
