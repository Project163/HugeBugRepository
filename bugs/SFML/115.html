Title

iOS autocomplete window overlaps keyboard

Description
## Subject of the issue

The autocomplete window overlaps the keyboard, looking terrible and making typing difficult, see [Link: here]

## Your environment

* macOS 10.13, Xcode 10.13, iOS 11.3

## Steps to reproduce

Set the virtual keyboard visible with `sf::Keyboard::setVirtualKeyboardVisible(true);`

## Expected behavior

Autocomplete window should appear on top of the keyboard, as per usual

## Actual behavior

Autocomplete overlaps keyboard

## Details

I haven't worked out why this is happening, but I have worked out how to hide the autocomplete window, which technically fixes the issue, at the expense of losing some functionality (But to be fair in my tests the autocomplete didn't fill correctly anyway, so that's an issue for another day).

If I don't get any other feedback in the next week or so about this I'll put together a PR to hide the autocomplete.
