Title

Web Console assets fail to load when not using HTTPS

Description
As part of the changes in  [URL] I added "upgrade-insecure-requests" to the Content-Security-Policy header. This policy caused CSS and images to fail to load when not running the Web Console over HTTPS. 

   

 When using the Safari browser, the console shows the errors: 

 " [Error]  Failed to load resource: An SSL error has occurred and a secure connection to the server cannot be made. (head.css, line 0) 
 [Error]  Failed to load resource: An SSL error has occurred and a secure connection to the server cannot be made. (common.js, line 0) 
 [Error]  Failed to load resource: An SSL error has occurred and a secure connection to the server cannot be made. (css.js, line 0) 
 [Error]  Failed to load resource: An SSL error has occurred and a secure connection to the server cannot be made. (standardista-table-sorting.js, line 0) 
 [Error]  Failed to load resource: An SSL error has occurred and a secure connection to the server cannot be made. (prettify.js, line 0) 
 [Error]  Failed to load resource: An SSL error has occurred and a secure connection to the server cannot be made. (head.js, line 0)" 

   

 Apparently Chrome is able to handle it correcly.
