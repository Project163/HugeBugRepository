Title

NFSClient plugin fails for Redhat / Centos 7 Guests

Description
I will submit a PR if this sounds like the right approach:

The [Link: NFSClient plugin] will always try to call:

```
/etc/init.d/rpcbind restart; /etc/init.d/nfs restart
```

Which results in:

```
bash: line 2: /etc/init.d/rpcbind: No such file or directory
bash: line 2: /etc/init.d/nfs: No such file or directory
```

I believe NFSClient needs to detect the `rhel_7` flavor, similar to the [Link: ConfigureNetworks plugin] and do:

```
systemctl restart rpcbind; systemctl restart nfs
```
