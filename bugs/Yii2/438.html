Title

Not working - UrlManager rule having parameter with dash

Description
I use Yii2 advanced template, Linux OS, Google Chrome browser.

On my page I'm using [Link: yii\data\Pagination] object for pagination.

It is necessary to set pageSize, so:

``` php
        $pagination = new Pagination(['totalCount' => $vuz->count(), 'pageSize' => 9,]);
```

View code:

``` php
        echo LinkPager::widget([
            'pagination' => $pagination,
        ]);
```

Config part related to `UrlManager` is such:

```
php
        'urlManager' => [
            'class' => 'yii\web\UrlManager',
            'showScriptName' => false,
            'enablePrettyUrl' => true,
... [Log Snipped] ...
            ),
        ],
```

When I click on pagination links an end of  URL looks like this: `/frontend/web/search-vuz?page=2&per-page=9`

It is necessary to have a such URL end: `/frontend/web/search-vuz/2/9`

So I add additional rules:

```
php
            'rules' => array(
                 'search-vuz/ / ' => 'site/search-vuz', // added
                 'search-vuz/ ' => 'site/search-vuz', //added
                'search-vuz' => 'site/search-vuz',
... [Log Snipped] ...
                ' / ' => ' / ',
            ),
```

Again I try pagination links and get such URL `/frontend/web/search-vuz/1?per-page=9`
`per-page` is still here.
Everything is working If I change `pageSize` parameter name like this:

``` php
        $pagination = new Pagination(['totalCount' => $vuz->count(), 'pageSize' => 9,
            'pageSizeParam' => 'n'
        ]);
```

And rule like this:

``` php
'search-vuz/ / ' => 'site/search-vuz', 
```

So the question is - how to use parameters with dashed name in urlManager rule.

Doesn't work:

``` php
'search-vuz/ / ' => 'site/search-vuz',
```
