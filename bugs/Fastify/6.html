- Hi and thank you for this report! 

Nice catch!

For the time being, PROFIND and PROPATCH http methods are not supported. That produces an "internal" error. During the handling of that error, fastify crashes.

Anyway, the only supported http methods are listed in the above output

So, this is a fastify bug definitely! But, I suggest you to don't inject custom http methods!
