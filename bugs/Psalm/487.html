Title

Cannot assign to a mixed type

Description
I guess something is not quite right here.

When Psalm reports `MixedAssignment` violations, sometimes it couldn't name variables properly, but omits them (please note the two whitespaces between assign and to):

```
Cannot assign  to a mixed type
```

Example code where this can happen:

```
$maxRule[$rule[1]] = $rule[2];
```

As far as I can see, this can only happen when populating `array`s.
