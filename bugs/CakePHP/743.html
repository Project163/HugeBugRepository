Title

Windows: File utility reads wrong files

Description
Both 2.x and 3.x.

On *nix:

``` php
var_dump( (new File('/path/to/foo.txt'))->exists() );
//true
var_dump( (new File('file:///path/to/foo.txt'))->exists() );
//true
```

On Windows:

```
php
var_dump( (new File('\path\to\foo.txt'))->exists() );
//true

var_dump( (new File('/path/to/foo.txt'))->exists() );
... [Log Snipped] ...
var_dump( (new File('file:///path/to/foo.txt'))->exists() );
//false, as reading \file:\\\path\to\foo.txt
```

`file_exists()` would return `true` against every notation but `File::exists()`.
Especially, `\\path\to\foo.txt` means `FOO.TXT` in the shared folder `TO` on the remote computer `PATH`. That is a totally wrong file.
