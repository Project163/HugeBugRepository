Title

promtool backfill does not delete labels in generated data

Description
I have a recording rule which deletes a label:

```yaml
      - record: 'weather:temperature:avg5m'
        expr: 'avg_over_time(sensor_temperature_degreesC{chip="BME280"}[5m])'
        labels:
          chip: ""
```

The generated data created "live" deletes the chip label here, e.g.:

```
weather:temperature:avg5m{instance="ina.leo:9098", job="sensors"} | 15.646500000000001
```

I have followed the steps [Link] to backfill this. It has created data, but it hasn't deleted the chip label; e.g. providing:

```
weather:temperature:avg5m{chip="BME280", instance="ina.leo:9098", job="sensors"} | 8.818000000000001
```

```
$ /opt/prometheus/releases/prometheus-2.30.0.linux-amd64/promtool --version
promtool, version 2.30.0 (branch: HEAD, revision:  )
  build user:       root@e913c65aa170
  build date:       20210914-09:49:24
  go version:       go1.17.1
  platform:         linux/amd64
```
Discussion
- A fairly easy workaround is to adjust the recording rule to be

```
sum without (chip) (EXPR...)
```

which seems to work for my backfill.
