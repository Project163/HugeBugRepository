［Steps to reproduce］

1. Make these three php files, and put it on webserver.

[index.php]
```
 
```
[index2.php]
```
 
```

2. Run ZAP 2.5.0 and access index.php

3. the URL history on ZAP history window is below:
```
GET index.php / 302 Found / 0kb
GET index2.php / 302 Found / 0kb
GET index3.php / 200 OK / 97.96KiB
(* 3 lines)
```
4. Do resend request to index.php by select "Resend.." in contextmenu of ZAP history window.

5. The URL history displayed on ZAP history window is below:
```

```
