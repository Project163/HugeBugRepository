Title

[YSQL] Connections hitting max limit after OOM kills

Description
Jira Link: [Link: DB-7029]
### Description

Connections to the database fail with the error message
`FATAL:  remaining connection slots are reserved for non-replication superuser connections`
even though the number of current connections is nowhere close to the limit prescribed by ysql_max_connections.

This is observed after the oom-killer kills processes (presumably PG backends) in a memory constrained system.
System details:
`Read Replica with 2 vCPUs, 8 GB memory, ysql_max_connections: 503, actual connections: ~100`

Other issues seen in this cluster include:
`[pg_client.cc:188] S [number]: Heartbeat failed: Invalid argument (yb Unknown session: [number]`
`postgres invoked oom-killer: gfp_mask=, order=0, oom_score_adj=[score]`
