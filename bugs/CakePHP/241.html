Title

Custom path to Plugin without trailing slash

Description
Just recently I found something annoying: I had to specify a custom path to a Plugin: [URL]

The problem was that I did not add a trailing slash to the path specified to the `CakePlugin::load()` function. This causes the plugin to load fine, but a call to:

``` php
App::uses('AirbrakeError', 'AirbrakeCake.Lib');
```

failed.

The path CakePHP constructed was something like: `/path/to/CakephpAirbrakeLib/AirbrakeError`.

Fix: Automatically add a trailing slash, if not already present.
