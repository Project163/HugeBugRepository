Title

Duplicate fields in Enum must raise an error

Description
I have this example:

```python
from enum import Enum

class A(Enum):
   x = 1
   x = 2

reveal_type(A.x)
```

Mypy is happy with it:

```python
» mypy ex.py
ex.py:8: note: Revealed type is "Literal[ex.A.x]?"
```

But, it raises in runtime:

```
python
» python ex.py
Traceback (most recent call last):
  File "/Users/sobolev/Desktop/mypy/ex.py", line 4, in  
    class A(Enum):
... [Log Snipped] ...
    raise TypeError('Attempted to reuse key: %r' % key)
TypeError: Attempted to reuse key: 'x'
```
