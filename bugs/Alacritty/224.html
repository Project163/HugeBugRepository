Title

Selection not copied after tab character

Description
This morning, I had to come to the disappointing realization that... ehh.. that somebody is watching me. And it is not God. They are already knocking at my door, so I can only say that censorship has reached terminals too. Be careful!

```
sh
$ printf 'I do not\rI\t like '$TERM
I do not like alacritty

$ # Selecting previous text, for example to send it to a friend...
... [Log Snipped] ...
$ # Do     panic.
$ rrn -rf /
```

---

Jokes aside, here is a minimal, reproducible example:
```sh
$ printf 'x X\r[\t]'
[ X     ]

$ # Selecting whole line using mouse/Vi-mode.
$ xclip -o|od -c
0000000   [  \t   ]
```

### System

OS: Arch Linux
Version: `alacritty 0.7.2 (5ac8060b)`
Linux/BSD: X11
