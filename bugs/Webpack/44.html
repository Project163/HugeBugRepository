Title

Broken loader and context upgrading from 2.0.2 to 2.0.4 (persists in 2.0.5)

Description
Everything working great in 2.0.2.
Starting in 2.0.4, `modules.loaders[].include` no longer accepts an array.

Additionally, calling `import` on filepaths that treat the context as the resource root are now broken.

Reproduction case here (just upgrade to 2.0.4+ to make it break): [URL]

Not sure if the 2 are related, but given the very few changes that took place between the 2 commits I'd guess so.
Discussion
- The configuration changed a bit: `resolve.root` `resolve.moduleDirectories` and `resolve.fallback` => `resolve.modules`.

So your config need to be changed:

``` diff
   resolve: {
-    extensions: ['', '.js'],
-    root: path.join(root, 'src')
+    extensions: ['.js'],
+    modules: [path.join(root, 'src'), "node_modules"]
   },
```
