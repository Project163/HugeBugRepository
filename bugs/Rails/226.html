Title

ActiveRecord: enum where clause does not work anymore in Rails 6.1 when providing array of strings

Description
### Steps to reproduce
 

When upgrading to Rails 6.1 I encountered a strange bug. In the application, the values to filter by enum property are passed not as an array of integers, but of strings, and that works correctly before. Now, instead of string array passed into `IN` clause, like `enum IN ('0', '1')`, there is `NULL` (`enum IN (NULL)`). I found that [Link: this PR] fixes the issue.

Here is a simplified script to reproduce this error.

```
require "bundler/inline"

gemfile(true) do
  source "[URL]
  gem "activerecord", " "
... [Log Snipped] ...

puts User.where(role: ["0", "1"]).to_sql
```

### Expected behavior

 

`User.where(role: ["0", "1"]).to_sql` should return `SELECT "users".* FROM "users" WHERE "users"."role" IN ('0', '1')`

### Actual behavior

 

`User.where(role: ["0", "1"]).to_sql` returns `SELECT "users".* FROM "users" WHERE "users"."role" IN (NULL)`
