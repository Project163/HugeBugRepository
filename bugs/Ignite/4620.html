- The root cause of this issue is that the  ValidationOnNodeJoinUtils.validate()  method is called on the recovery phase and at this moment  DiscoverySpi  is not started yet, therefore  localNode()  returns  null  and so it cannot be used for validation. 
It seems that we should use  DetachedClusterNode  in this case.
