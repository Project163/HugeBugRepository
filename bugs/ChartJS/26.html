Title

chart does not render if data contains value of 0 when using logarithmic scale

Description
Here we have one red vote, renders correctly:

``` javascript
data: {
        labels: ["Red", "Blue", "Yellow", "Green", "Purple", "Orange"],
        datasets: [{
            label: '# of Votes',
            data: [1, 2, 3, 5, 2, 3]
        }]
    }
```
