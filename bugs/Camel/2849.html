Title

Property Trigger.timerZone is declared as constant but not implemented

Description
Seems that we have a problem with Quartz/Quartz2 components. The doc claims that we can setup this property in the URI "trigger.timeZone" ( [URL] - see specifying timezone ) but quartz don't use it even if a constant is defined : [URL]

 We have the same issue too with quartz2 -->  [URL]
