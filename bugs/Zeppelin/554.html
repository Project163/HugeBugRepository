Title

Can not switch visualization package version

Description
In case of there're multiple versions of a visualization package in npm repository, Zeppelin helium menu allows user select specific version. 

 However, switching version sometimes result 'npm install' command failure (internally). And visualization bundle can not be rebuilt.
