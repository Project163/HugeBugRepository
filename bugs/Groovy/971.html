Title

GroovyRuntimeException thrown Ambiguous method overloading when accessing metaClas of java.lang.String

Description

methodName = 'toUpperCase'

println methodOfInterest.invoke(str)

Discussion
- it is not the invocation of the selected method, that is causing the problem, it is the invocation of getMetaMethod itself that is failing. Now MetaClassImpl, which is used in 1.5.7 directly, has not getMetaMethod(String,Class[]), so there cannot be a problem. I think the solution would be to remove getMetaMethod(String name, Class[] argTypes) from DelegatingMetaClass (super class of HandleMetaClass). This method directs to the Object[] version anyway.  

 As a work around you can use "str.metaClass.getMetaMethod(methodName, [] as Object[])" for now
- fixed by removign the method
