Title

Some negative float numbers are returned incorrectly

Description
I use **Doctrine/DBAL 2.5.2** for accessing an **Oracle** database containing latitudes and longitudes.

The values are stored as floats in columns of type `NUMBER`.

Most values are being returned correctly but some are retrieved in a "corrupted form" e.g.:
- If the column contains `-0.123`, then I get the value as `-.123`
- If the column contains `-0.987`, then I get the value as `-.987`.

This happens only for numbers of the form `-0.xxx`.

I'm not 100% sure that the issue is generated by `doctrine/dbal` since we use a custom implementations of the `Doctrine\DBAL\Driver` and `Doctrine\DBAL\Driver\Statement` interfaces and I'm not very familiar with that code. I scanned it from top to bottom and it doesn't seem to contain any pieces of code that change the data after retrieval.

Since those custom implementations are needed in our codebase, it is kind of hard for me to reproduce the issue by using a "naked" instance of `doctrine/dbal`.

If there's any additional information needed, I will do my best to provide it :) .
