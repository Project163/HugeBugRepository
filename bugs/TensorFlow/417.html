Title

[MLIR] TFlite contains unused file

Description
**tensorflow/compiler/mlir/lite/transforms/load_quantization_recipe.cc** is called via 
`tf-opt -allow-unregistered-dialect -tfl-load-recipe %s | FileCheck %s`

However, according to [Link: this commit], "-allow-unregistered-dialect" is disabled (the only way to call the file is deprecated).
Hence, in **tensorflow/compiler/mlir/lite/transforms/load_quantization_recipe.cc** can be removed as it is not involved in any mlir::tfl passes.
