Title

provider 接口级注册+consumer APPLICATION_FIRST类型的服务发现无法正常RPC调用

Description
### Environment

* Dubbo version: 3.0.8
* Operating System version: mac
* Java version: 1.8

### Steps to reproduce this issue

1. provider 接口级注册方式启动
2. consumer 服务发现方式设置为APPLICATION_FIRST, 关闭推空保护(enable-empty-protection=false)
3. consumer调用provider暴露的dubbo service接口

Pls. provide [GitHub address] to reproduce this issue.

### Expected Behavior

正常调用成功

### Actual Behavior

首次报java.lang.UnsupportedOperationException， 之后都报java.lang.NullPointerException

原因是在APPLICATION_FIRST方式下会先尝试以实例级方式去发现服务，在实例级服务发现过程中会调用到ServiceInstancesChangedListener.doOnEvent()方法，但是根本找不到，在ServiceInstancesChangedListener.java 359行 this.getAddresses(protocolServiceKey, notifyListenerx.getConsumerUrl()) 方法会返回null， toUrlsWithEmpty(urls)方法中会判断入参为null时，urls=Collections.emptyList(); 由于关闭了推空保护，在429行又执行urls.add(empty); 此时就抛java.lang.UnsupportedOperationException
