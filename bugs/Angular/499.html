Title

`NgModule` not detected when module is re-exported from a different package

Description
#### Reproduction
1. Clone [URL]
2. `npm i`
3. `npm run start`

#### Error
```
ERROR in Unexpected value 'PortalModule in /usr/local/google/home/jelbourn/material.angular.io/node_modules/@angular/material/material.d.ts' imported by the module 'DocViewerModule in /usr/local/google/home/jelbourn/material.angular.io/src/app/shared/doc-viewer/doc-viewer-module.ts'. Please add a @NgModule annotation.
```

We moved `PortalModule` from `@angular/material` to `@angular/cdk`, along with a re-export in in the original location:
```ts
export {TemplatePortalDirective, PortalHostDirective, PortalModule} from '@angular/cdk';
```

It seems that the metadata isn't being seen through the re-export. I've tried adding both `"flatModuleIndexRedirect": true` and an `"importAs"` to the metadata.json in both packages, but this has no effect.

Using `4.2.5` for all angular/angular dependencies
