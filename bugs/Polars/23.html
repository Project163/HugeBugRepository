### Issue description

The error occurs when creating a DataFrame where a cell is a numpy array (eg pl.List dtype).
This is required for instance if you create a DataFrame were you split a column with `pl.col("name").str.split(", ")`, and you export the data with to_numpy, operate on it and create a new DatFrame with from_numpy`.
This worked on 0.20.5, but was broken by commit   where the `v == v ` fails for np.arrays
```
            first_non_nan = next((v for v in values if v == v), None)
```

### Expected behavior

A DataFrame with an object columns is created. See asserts in "reproducible example"
