Title

try-catch in constructor that calls super() causes VerifyError, Inconsistent stack height 0 != 1

Description
The following code produces VerifyError, this can be avoided by either removing try-catch or the call to super() 

 class A {} 

 class B extends A { 
    B() { 
        super() 
        try 
{
            compute()
        }
  catch(RuntimeException e) { 
        } 
    } 

     def compute() {} 
} 

 println B.class
