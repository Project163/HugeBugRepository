Title

RBAC DbManager does not play well with PDO::NULL_TO_STRING

Description
### What steps will reproduce the problem?

Configuration:
```
'components' => [
        'db' => [
            'attributes' => [
                PDO::ATTR_ORACLE_NULLS => PDO::NULL_TO_STRING,
            ],
... [Log Snipped] ...
        ],
    ],
```

Code:

```php
$auth = \Yii::$app->getAuthManager();
$roleName = 'foo';
$role = $auth->getRole($roleName);
$role->name = 'bar';
$auth->update($roleName, $role);
```

This seems that the `ruleName` was set as **empty string** since `PDO::NULL_TO_STRING`,
and then occurs error when update.

### What is the expected result?

No error
