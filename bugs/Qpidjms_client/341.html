Title

When creating the subscription queue the durable property specified in link props is not picked up

Description
When creating the subscription queue the durable property specified in link props is not picked up 
For example, the subscription queue created off the following should set the durable property to true. 

 "amq.topic/topic1; {link:{durable: true}}" 

 Currently due to a bug this property is not picked up.
Discussion
- Updating 'Fix For'  to Unknown on issues not targeted for 0.8
- This issue has been fixed and verified using Drain utility. 
We probably need to find a easy way to write automated tools for verifying queue durability - perhaps using QMFv2.
