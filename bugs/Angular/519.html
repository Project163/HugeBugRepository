**Current behavior**
 
When using nested groups as `AnimationMetadata` AOT compiler throws the following error:
`ERROR in Recursion not supported, resolving symbol MyComponent`

**Expected behavior**
 
Nested groups pass AOT compilation process

**Minimal reproduction of the problem with instructions**
 
```
transition('home => about',
        group([
          query(':enter', group([
            useAnimation(slideFromRight),
            animateChild()

**Workaround**
```

        group([
