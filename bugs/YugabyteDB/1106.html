Discussion
- The STANDBY role is currently needed for Planned DR.

YBA sets the source to STANDBY, even though it has no inbound replication groups inorder to put the DB in a read only mode before performing the failover.
We would have to provide YBA a new API that will allows them to selectively block certain DBs independent of xCluster in order to achieve a combination of both behaviors
