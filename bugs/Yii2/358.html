Discussion

- I disaggre. My suggestion, we declare backend and frontend as module

```
php
'modules' => [
    'frontend' => [
        'basePath' => '@frontend',
        'controllerNamespace' => 'frontend\\controllers',

```

As my suggestion, we use controllerID instead of controller className (like as gii/controller). When we want to generate crud for backend, we execute

```
./yii gii/crud --modelClass=common\\models\\User --controllerID=user --moduleID=backend
```
