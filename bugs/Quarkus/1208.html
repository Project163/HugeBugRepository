Title

Build fails when defining property quarkus.kubernetes.pvc-volumes

Description
## Describe the bug
Build fails when application.properties contains the property _quarkus.kubernetes.pvc-volumes_ 

### Expected behavior
build task should add the persistent volume claim info inside the kubernetes deploy script.

`java.lang.NoSuchMethodError: 'io.fabric8.kubernetes.api.model.PersistentVolumeClaimVolumeSourceFluent io.fabric8.kubernetes.api.model.VolumeFluent$PersistentVolumeClaimNested.withNewReadOnly(boolean)'`
