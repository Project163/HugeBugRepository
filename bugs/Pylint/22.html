Title

False positive W0141: built-in 'input' function should not be considered blacklisted in Python 3.

Description
Originally reported by: **Jace Browning (BitBucket: [Link: jacebrowning], GitHub: @jacebrowning?)**

---

In Python 2, `input()` can be dangerous because it evaluates Python code, thus should be blacklisted for production code.

In Python 3, `input()` behaves like Python 2's `raw_input()` which can only return a string. This should not be considered blacklisted by W0141.
