Title

Fully-qualified @method param types aren’t respected

Description
```
`INFO: InvalidArgument -   - Argument 1 of transaction expects Illuminate\Support\Facades\Closure, Closure():mixed provided`
            DB::transaction(function () {
```

DB refers to one of Laravel's facades: [URL]

Specifically the line: `@method static mixed transaction(\Closure $callback, int $attempts = 1)`

I'm not sure \Closure should be interpreted as Illuminate\Support\Facades\Closure (which does not exist), but more like PHP's internal Closure class. 

I can work around the error by adding `use Closure;` at the top. But it's strictly not needed for PHP, even if the class had method explicitly defined using \Closure as a type in the arguments.

Example workaround pull-request for Laravel: [URL]
