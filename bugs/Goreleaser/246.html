Title

Snapcraft build failures when using completers

Description
**Describe the bug**

When creating a snap package with multiple builds and multiple apps, setting a completer on the application fails.

**To Reproduce**
```
yaml
snap:
  builds:
  - build1
  - build2
... [Log Snipped] ...
    app2:
      completer: app2.completer
```


**Expected behavior**

The snap to build successfully

**Environment (please complete the following information):**

- OS: all
- OS version: all
- GoReleaser 0.140.0
- GitLab version n/a

**Additional context**

This occurs because [URL] is executed per application per binary, so `os.Link` fails the second time around with a `File Exists` error.
