Title

SqlDataProvider not replace my `ORDER BY` in `sql` property after sorting

Description
### What steps will reproduce the problem?
1. Create SqlDataProvider in SearchModel with query `SELECT "f"."rid" AS "id", "f"."ris_deleted" AS "is_deleted", "f"."ris_ready" AS "is_ready", "f"."ris_org" AS "is_org", "f"."rname" AS "name", "f"."rown_square" AS "own_square", "f"."rownerdoc_id" AS "ownerdoc_id", "f"."rownershipdoc_id", "f"."rown_percent" AS "own_percent", "f"."rown_fraction" AS "own_fraction", "f"."rattrs_list" AS "attrs_list", "f"."rstreet_id" AS "street_id", "f"."rbuilding_id" AS "building_id", "f"."rappart_id" AS "appart_id", "f"."rstreet" AS "street", "f"."rhouse" AS "house", "f"."raddress" AS "address", "f"."rappart" AS "appart", "f"."rdoc_no" AS "doc_no", "f"."rdoc_date" AS "doc_date", "f"."rdoc_org" AS "doc_org", "f"."rappart_square" AS "appart_square", "f"."rappart_num" AS "appart_num", "f"."rappart_letter" AS "appart_letter", "f"."rmeeting_name" AS "meeting_name", "f"."rmeeting_num" AS "meeting_num" FROM sh_sosedi.f_owners_list('{"user_id":4,"meeting_id":160}') f ORDER BY "f"."rappart"`
2. Use this SqlDataProvider in GridView
3. Click on column is_deleted

### What is the expected result?
1. Error in sql-query with TWO `ORDER BY` instructions - `ORDER BY "f"."rappart" ORDER BY "f"."ris_deleted" DESC LIMIT 25`

### Research
1. Error in `SqlDataProvider->prepareModels()` method
2. Do not understand why pattern `/\s+order\s+by\s+([\w\s,\.]+)$/i` not work correctly
3. When i'm add `preg_match_all($pattern, $sql, $matches); var_dump($matches); die();` after `$pattern = '/\s+order\s+by\s+([\w\s,\.]+)$/i';` line and refresh page i see empty `$matches` array
