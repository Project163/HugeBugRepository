Title

Semicolon in password doesn't seem to work.

Description
**Describe the bug**
I'm using url encoding on passwords, but when the password contains a semicolon it seems to have login failure errors. Once I remove the semicolon from the password, it succeeds.

**Expected behavior**
Password with a semicolon should work.

**To Reproduce**
The following code shows the url being passed to create_engine has escaped everything, including the semicolon. The output of the url from the engine shows only colons are escaped. Other special characters are not, though it seems semicolons are the only ones causing me problems. If you then try to use that engine, it fails with a login failed. But if you remove the semicolon from the password it works.

```
py
from sqlalchemy import create_engine
from urllib.parse import quote_plus as urlquote

password = '_]REOYGR:Q>c4[R:6X;Q'
... [Log Snipped] ...
connection = create_engine(url)
print(connection.url)
```
