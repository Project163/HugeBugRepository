Discussion
- Be prepared to throw up a little. 

 This approach puts a lock around CompactionManager. Migrations have to acquire it and Table.flushLock before proceeding.  Special care had to be taking when reloading a CFS since it places blocking jobs on the compaction manager.  This patch should handle the streaming race as well (when the directory specified in a Descriptor is no longer valid).
