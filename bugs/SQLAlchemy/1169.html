Title

PG / Oracle - 'INTERVAL' object has no attribute 'impl'

Description
**Describe the bug**
 

Filtering a `query` (with eg. `filter_by()`) on an `interval` column in Postgres raises `AttributeError: 'INTERVAL' object has no attribute 'impl'`.

**To Reproduce**

```sql
CREATE TABLE "test" (
    "uid" SERIAL PRIMARY KEY NOT NULL,
    "interval_col" interval 
);

INSERT INTO test (interval_col) VALUES (interval '1 day');
```

```
py
from datetime import timedelta

from sqlalchemy import MetaData, create_engine
from sqlalchemy.ext.declarative import declarative_base
... [Log Snipped] ...
if __name__ == "__main__":
    t = session.query(Test).filter_by(interval_col=timedelta(days=1)).all()
```

**Error**

```
---------------------------------------------------------------------------
AttributeError                            Traceback (most recent call last)
  in  
----> 1 t = session.query(Test).filter_by(interval_col=timedelta(days=1)).all()

... [Log Snipped] ...

AttributeError: 'INTERVAL' object has no attribute 'impl'
```

**Versions**
 - OS: Debian 10
 - Python: 3.8
 - SQLAlchemy: Found on 1.3.17, confirmed present on 1.3.24 through direct testing, and found the code path is identical in 1.4.18 and master.
 - Database: Postgresql 12
 - DBAPI: psycopg2
