Title

annotated declarative mis-interprets Literal within Mapped[]

Description
### Describe the bug

I get an `sqlalchemy.exc.ArgumentError: Could not resolve all types within mapped annotation: "Mapped[Status]"` error when I use `from __future__ import annotations` together with a `Mapped` column of type `typing.Literal`.

When I remove `from __future__ import annotations`, everything works as expected.

I'm aware that sqlalchemy already includes built-in support for `enum.Enum`. I'm aware that this is another workaround.

### To Reproduce

```
python
# NOTE: Code works if we remove the following line
from __future__ import annotations

from typing import Any, Literal, Optional, get_args

    id: Mapped[int] = mapped_column(primary_key=True)
```
