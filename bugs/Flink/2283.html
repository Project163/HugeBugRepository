Title

Fix Java 64K method compiling limitation for CommonCalc

Description
For complex SQL Queries, the generated code for  
  
 DataStreamCalc 
  
 ,  
  
 DataSetCalc 
  
  may exceed Java's method length limitation 64kb. 

 This issue will split long method to several sub method calls.
