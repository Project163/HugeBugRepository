Discussion
- Root Cause 

 In the build code, the following content causes the issue: even though the global `gluten.enable` is set, the `NativeScan hive xxx.xxx` is not generated during the snapshot build step, leading to subsequent execution failure. 

     

 When setting `gluten.enable=false` globally, the same exception still occurs because `spark.plugins=org.apache.gluten.GlutenPlugin` is configured, causing the execution to enter the Gluten logic and throw an exception.
- Dev Design 
 
	 Enable Gluten only for internal table tasks.   
	 Disable Gluten for non-internal table tasks.  
	 
		 Exclude Gluten-related parameters when generating `spark-submit`.   
		 Exclude Gluten-related parameters when retrieving Spark parameters in `exchangeSparkConf`.
