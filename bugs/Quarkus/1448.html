- @rsvoboda this is intentional and related to #20088. These logs are just a side effect.
- I disagree that it's intentional. Why do we pass this property to SmallRye Reactive Messaging if not supported? Can't we filter it?

If we can't, you can use `LogCleanupFilterBuildItem` to avoid logging them.
- Yes that's an unfortunate effect of how kafka handles configuration. We have to pass the property to avoid a SASL issue when elytron is used, but kafka does not know that property only the underlying SASL implementation. 

We could try to filter out that message, but we must not disable that log category, and only filter out this property. 

WDYT @ozangunalp ?

Note that it would be purely cosmetic.
