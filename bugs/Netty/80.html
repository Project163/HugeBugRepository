Title

HttpContentDecoder and HttpContentEncoder free up messages even if they are just pass them through

Description
In HttpContentDecoder and HttpContentEncoder we pass through the original message if no decoder/encoder is used for the message. Unfortunally we miss to handle this special case in our free*Message code. 

This will then cause an IllegalBufferAccessException later, like this one:

