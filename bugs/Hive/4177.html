Title

subquery with NOT IN failing due to ClassCastException

Description
create table student(
            name string,
            age  int ,
            gpa  double )

create table voter(
            name string,
            age  int ,
            registration string,
            contributions  float )

select * 
from student 
where not student.age in
(select age from voter) 
order by age;
 
  

 Fails in Tez – Vectorized Reduce.
