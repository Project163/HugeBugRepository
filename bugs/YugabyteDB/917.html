Title

[DocDB] Ensure that inbound_call::trace_ is synchronized across threads

Description
Jira Link: [Link: DB-5973]
### Description
`ybd asan --cxx-test tools_yb-admin-test --gtest_filter AdminCliTest.TestCreateTransactionStatusTablesWithPlacements -n 200 --tp 1` fails intermittently with sampled tracing. Upon investigation we find that: 

With Sampled Tracing, we may be creating inbound_call::trace_ after the call object has been constructed.

As the inbound_call may be used across different threads, we should ensure that ::trace_ is guarded properly.
