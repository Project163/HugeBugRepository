Title

Unable to map exceptions other than `Exception` and `ApplicationException`

Description
**Describe the bug**
I am trying to adjust the response for errors provided by quarkus extensions but it does not seem to be possible to capture those in ExceptionMappers.
Also, this issue (https://github.com/quarkusio/quarkus/issues/3253) mentions that `WebApplicationExceptions` works, but that's not the case for me. So I cannot easily capture javax.ws.rs.core.Response exceptions easily.

**Expected behavior**
For example, I would expect to be able to capture hibernate exceptions with either a `ExceptionMapper ` or `ExceptionMapper `.

**Actual behavior**

For example, violating a database constraint produces the stacktrace:
```
RuntimeException 
-> javax.transaction.RollBackException 
-> javax.persistence.PersistenceException 
-> org.hibernate.exception.ConstraintViolationException
```
But I am only able to capture it with a `ExceptionMapper `.

**To Reproduce**
1. Build a project with `hibernate-orm`
2. Create a service to insert the following entity twice.

```
@Entity
@Table(name = "DEMO")
@Data
public class Demo {
	@Id
... [Log Snipped] ...
    private String name;
}
```

3. Add the following ExceptionMappers to the project

```
java
@Slf4j
@Provider
public class PersistenceExceptionMapper implements ExceptionMapper  {

... [Log Snipped] ...

}
```

```
java
@Slf4j
@Provider
public class RollbackExceptionMapper implements ExceptionMapper  {

... [Log Snipped] ...

}
```

You will see none of them triggers and the response is a HTML, if in DEV mode.
