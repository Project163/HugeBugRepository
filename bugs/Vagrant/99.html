Title

dockerfile build failing when dockerfile parameter of the docker provider is set

Description
Please note that the Vagrant issue tracker is reserved for bug reports and
enhancements. For general usage questions, please use the Vagrant mailing list:
[URL] Thank you!
### Vagrant version

both 1.8.1 and 1.8.6
### Host operating system

Linux Mint 18
### Guest operating system

Centos 6.8 but irrelevant in this case
### Vagrantfile
# -_\- mode: ruby -_-
# vi: set ft=ruby :

Vagrant.configure(2) do |config|
    config.vm.define "A" do |a|
        ENV['VAGRANT_DEFAULT_PROVIDER'] = 'docker'
        a.vm.provider "docker" do |d|
            d.build_dir = "."
            d.dockerfile = "Dockerfile"
        end
    end
end
### Debug output

[URL]

key output

A Docker command executed by Vagrant didn't complete successfully!
The command run along with the output from the command is shown
below.

Command: ["docker", "build", "--file=\"/home/jdwagner/eraser_board/vagrant_issue/Dockerfile\"", "/home/jdwagner/eraser_board/vagrant_issue", {:notify=>[:stdout, :stderr]}]

Stderr: unable to prepare context: unable to evaluate symlinks in Dockerfile path: lstat /home/jdwagner/eraser_board/vagrant_issue/": no such file or directory
### Expected behavior

expected a centos docker to be launched
### Actual behavior

docker build command fails due to being unable to parse the dockerfile path

while unconfirmed may be caused by a parsing issue which is letting a single quote through at the end of the line. this is based on the Stderr output from the docker build command having a single trailing quote
### Steps to reproduce
1. create a docker file
2. create a vagrant file using a docker provider
3. set the build dir to the dir where the dockerfile is located
4. set the dockerfile to the name of the dockerfile
5. run vagrant up

`args.push("--file=#{dockerfile_path}")`
