Title

Broken quaternion version of glm::rotateNormalizedAxis

Description
Current code:

```
    template  
    GLM_FUNC_QUALIFIER detail::tquat  rotateNormalizedAxis
    (
        detail::tquat  const & q, 
        typename detail::tquat ::T const & angle,
        detail::tvec3  const & v
    )
```

Should be:

```
    template  
    GLM_FUNC_QUALIFIER detail::tquat  rotateNormalizedAxis
    (
        detail::tquat  const & q, 
        T const & angle,
        detail::tvec3  const & v
    )
```

This bug breaks compilation and can be reproduced with following code:

```
glm::rotateNormalizedAxis(glm::quat(), 0.0f, glm::vec3());
```

(it might be a good idea to add something as simple as that to test/gtx/gtx_rotate_normalized_axis.cpp)

Matrix version seems to be ok but I haven't checked that.
Discussion
