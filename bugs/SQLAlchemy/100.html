Title

support self-referential auto-joins when the foreign key joins to itself

Description
**Migrated issue, originally created by Anonymous**

See attached test case. Basically, we have a class called Item with a relation on itself called group and we try to do:
session.query(Item).filter(~Item.group.any(id = 2))

The generated sql is:

SELECT item.id AS item_id, item.group_id AS item_group_id 
FROM item 
WHERE NOT (EXISTS (SELECT 1 
FROM item AS item_1 
WHERE item.group_id = item.group_id AND item_1.id = :id_1))

Note that it has the tautological
WHERE item.group_id = item.group_id

This should be
WHERE item_1.group_id = item.group_id
