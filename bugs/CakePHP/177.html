Title

Should not overwrite files when Folder::SKIP is set

Description
According to the documentation for Folder::copy() found here [URL] it says : 

`Folder::SKIP  -- skip copying/moving files & directories that exist in the destination directory.`

However, [URL] does not check for `$options['scheme'] != Folder::SKIP`. Thus, given the following directory structure:

```
animals/
    dog
    bird
pets/
    dog
```

and I do the following:

```
$folder = new Folder('animals');
$folder->copy(array(
    'to' => 'pets',
    'from' => 'animals',
    'mode' => 0755,
    'scheme' => Folder::SKIP
));
```

what I would expect is the dog file to **NOT** be overwritten but it does.

I have a fix in a branch I created but require input on whether my expectation of the usage of the `scheme` option to be correct. Would we want to add a new scheme option to skip overwriting of files  not just skip directories? Or is it safe to simply add the  `$options['scheme'] != Folder::SKIP` check on  [URL]
