Title

Health UI access wrong health endpoint with management interface

Description
### Describe the bug

Hello,

I was trying to use the health-ui with management interface.
When opening the page, a request to the health endpoint is made but with the wrong host " :9000".

### Expected behavior

Health UI request to `localhost:9000`

### Actual behavior

Health UI request to ` :9000`

### How to Reproduce?

1. Create a project with
```
mvn io.quarkus.platform:quarkus-maven-plugin:3.3.3:create \
    -DprojectGroupId=org.acme \
    -DprojectArtifactId=microprofile-health-quickstart \
    -Dextensions='smallrye-health' \
    -DnoCode
```
2. Add `quarkus.management.enabled=true` to application.properties
3. Open [URL]
4. Check request console
