As this is a higher google result I just want to note some of the pitfalls I've run into.

Make sure
```
nixpkgs.url = "github:nixos/nixpkgs/nixpkgs-unstable";
```
is set to nixpks and not nixos. (this burnt an hour)

If you want cargo r to work in the dev environment make sure you set shellInputs.
```rust
devShells.default = pkgs.mkShell {
  shellInputs = buildInputs;
  shellHook = ''
    export LD_LIBRARY_PATH="$LD_LIBRARY_PATH:${pkgs.lib.makeLibraryPath buildInputs}"
  '';
};
```
