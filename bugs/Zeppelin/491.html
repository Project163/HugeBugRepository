Discussion
- I've tested 0.7.0 branch and it's broken the same way there too.
- Hi, this is expected result when you create HiveContext multiple times. 
If HiveContext is configured to use embedded derby data base for the metastore(default configuartion), this error will occur when multiple HiveContext is created. 
You can reproduce it in SPARK_HOME/bin/pyspark. 

 So you'll need to configure your conf/hive-site.xml to use something else for it's metastore. not derby. 

 Workaround is use HiveContext.getOrCreate() 

  
 hc = HiveContext.getOrCreate(sc)
