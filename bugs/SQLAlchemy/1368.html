Title

HasTableTest assumes support for SELECT * in CREATE VIEW

Description
### Describe the bug

`HasTableTest` currently creates views as

```sql
CREATE VIEW vv AS SELECT * FROM test_table
```

and not all databases support that (e.g., CockroachDB, see "To Reproduce") resulting in test suite errors.

### To Reproduce

```
python
gord@gord-dv7:~$ ./crdb_sql.sh 
#
# Welcome to the CockroachDB SQL shell.
# All statements must be terminated by a semicolon.
... [Log Snipped] ...
HINT: You have attempted to use a feature that is not yet implemented.
See: [URL]
```

### Error

```
ERROR: unimplemented: views do not currently support * expressions
``` 

### Versions

- OS: (any)
- Python: (any)
- SQLAlchemy: 2.0.0b4
- Database: CockroachDB
- DBAPI (eg: psycopg, cx_oracle, mysqlclient): sqlalchemy-cockroachdb
