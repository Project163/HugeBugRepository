Title

Glyphs overlapping in rendering

Description
See attachment, this is reduced (but uncompressed) from the original pdf. All the glyphs render at about the same position. I did some tracing, the widths of the glyphs are about the same as the values within TJ.
Discussion
- The problem are wrong values for the glyph widths. PDCIDFont#getWidth doesn't provide the DW value of the font descriptor but delegates the calculation to the embedded font itself. IMHO that isn't in line with the spec (see "Glyph Metrics in CIDFonts"), but maybe I'm missing something. However if we use the DW value 1000 everything looks fine.
