Title

3.0 View cells render() does not respect plugin dot syntax

Description
If I have a view cell `PageHeader` and I am rendering a template from a plugin a missing template exception will be thrown. When it lists all of the template locations it looked in the template I am trying to render is listed but the exception is still thrown.

```
php

... [Log Snipped] ...

```
