Title

Key bindings broken after migration

Description
Before the migration I was using key_bindings to remap `shift+enter` to `ctrl+J`
I had this in my yml:
```

  - { key: Return,   mods: Shift,    chars: "\x0a" }
```
After migration, I have ended up with:

```

"""

mods = "Shift"
```
