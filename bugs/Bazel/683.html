Title

Toolchain targets don't properly report overlapping constraints

Description
Sample BUILD file showing the problem:
```
constraint_setting(name = 'foo')
constraint_value(name = 'val1', constraint_setting = ':foo')
constraint_value(name = 'val2', constraint_setting = ':foo')

toolchain(
... [Log Snipped] ...
    ],
    toolchain = ':toolchain_impl')
```

Currently, attempting to use this toolchain will give an IllegalArgumentException from DeclaredToolchainInfo, because the constraints are not being checked for duplicate settings.
