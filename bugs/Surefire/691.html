Title

Why sudo docker?

Description
The page 
 [URL]
says 
"$ sudo docker build --no-cache -t my-image:1 -f ./Dockerfile ." 

 Is sudo really needed here? 
If so, the reason should be explained and any limitations noted.
Discussion
- Yes, from what I've seen, it is required. 

 I would expect that this is because the docker daemon generally requires root level privileges for most of its core functionality. 

 For more information (~5 years old, but still applies): 

  [URL]

 Using docker without sudo/ root level access is currently experimental. 

  [URL]  

 A limitation that is undeniable is that root level privileges are being given, which means that if that are any vulnerabilities with the docker system, there is the possibility of providing root access to unwanted entities, which has potential to incredibly harm on the system that is using docker.
