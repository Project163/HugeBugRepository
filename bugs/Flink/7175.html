Discussion
- I can reproduce this problem locally with `cluster.evenly-spread-out-slots: true`, and found the root cause is the wrong usage of  MiniClusterExtension . Each test in  FileSourceTextLinesITCase  needs a new minicluster instance (as some tests kill the TM), but  MiniClusterExtension  creates only one  MiniCluster  instance for each test class, all tests in the test class share one minicluster instance. 

 I can easily fix this problem by manully creating a minicluster instance in each test, but I think it's worth discussing whether to enrich  MiniClusterExtension  to support this functionality, just like the  @Rule  in Junit4.
