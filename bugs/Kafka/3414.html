Title

Off by one error in generated snapshot IDs causes misaligned fetching

Description
We implemented new snapshot generation logic here:  [URL] A few days prior to this patch getting merged, we had changed the `RaftClient` API to pass the  exclusive  offset when generating snapshots instead of the inclusive offset:  [URL] Unfortunately, the new snapshot generation logic was not updated accordingly. The consequence of this is that the state on replicas can get out of sync. In the best case, the followers fail replication because the offset after loading a snapshot is no longer aligned on a batch boundary.
