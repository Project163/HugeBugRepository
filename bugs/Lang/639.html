Title

when ArrayUtils.removeAll meeting 'null' array

Description
it just throw java.lang.NullPointerException: Cannot invoke "Object.getClass()" because "array" is null, hope a more propel way to handle this situation, for example just return null, or raise the illeagleargument exception (the array must not be null) 

 the test code is : 
 @Test  public void   testRemoveAll_NullArray () { 
 // Preparation of the test case     char [] array =  null;       // Invocation of the API     char [] result = ArrayUtils.removeAll(array) ;       // Final assertion    assertArrayEquals( "Removing elements from a null array should return null"  , null,  result) ; }
Discussion
- We could use  Objects.requireNonNull()  but you'd still get an NPE. 

 It seems to me that  NullPointerException  is the most precise exception and tells a developer  exactly  where to look. Throwing IAE is more general and therefore less useful. 

 What do others think?
