Title

[Java Broker] Restore building of zip distribution bundle for Qpid Java Broker

Description
Currently only tar.gz distribution bundle is created for Java Broker. We used to have zip bundle in previous version. There is no embedded support for tar.gz in Windows OSs. Thus, without installing of 3rd party software users of Windows will not be able to extract Qpid Java Broker tar.gz bundle. 
We nee to restore builing of zip bundle ditribution for Qpid Java Broker in order to simplify use of Qpid Java Broker in Windows environment
