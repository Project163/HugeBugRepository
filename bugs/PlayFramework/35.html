Title

Ok.sendFile logs exception java.util.NoSuchElementException: http-handler-body-subscriber

Description
### Play Version

2.5.0
### API

Scala and Java.
### JDK

```
java version "1.8.0_65"
Java(TM) SE Runtime Environment (build 1.8.0_65-b17)
Java HotSpot(TM) 64-Bit Server VM (build 25.65-b01, mixed mode)
```
### Expected Behavior

The following code should delivery an existent file without exceptions being logged.
#### Scala:

``` scala
def streaming = Action {
  Ok.sendFile(
    content = new java.io.File("/Volumes/Share/Book/AkkaScala2.3.14.pdf"),
    fileName = _ => "termsOfService.pdf",
    inline = true
  )
}
```
#### Java:

``` java
public Result streaming() {
    File file = new File("/Volumes/Share/Book/AkkaScala2.3.14.pdf");
    return ok(file, "termsOfService.pdf");
}
```
### Actual Behavior

The file is delivered but the following exception appears at the logs:


For anyone looking at this issue, this is the `sendFile` method right now:

``` scala
import akka.stream.scaladsl.FileIO

def sendFile(content: java.io.File, inline: Boolean = false, fileName: java.io.File => String = _.getName, onClose: () => Unit = () => ()): Result = {
  streamFile(FileIO.fromFile(content), fileName(content), content.length, inline)
}
```

`FileIO.fromFile` creates a `akka.stream.impl.io.FileSource` which is an internal API of Akka Streams. Looks like have the following version of `sendFile` fixes the issue:

``` scala
import akka.stream.scaladsl.StreamConverters

def sendFile(content: java.io.File, inline: Boolean = false, fileName: java.io.File => String = _.getName, onClose: () => Unit = () => ()): Result = {
  streamFile(StreamConverters.fromInputStream(() => Files.newInputStream(content.toPath)), fileName(content), content.length, inline)
}
```

`StreamConverters.fromInputStream` creates an `akka.stream.impl.io.InputStreamSource` which is slightly different from `akka.stream.impl.io.FileSource`.

I'm still trying to figure out exactly why `FileIO.fromFile` is not doing the magic without the exception.
