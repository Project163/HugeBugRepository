Title

Output of sort merge join is no longer bucketed

Description
I don't know if this was a feature or a happy coincidence, but before   HIVE-3230  , the output of a sort merge join on two partitions would be bucketed, even if hive.enforce.bucketing was set to false.  This could potentially save a reduce phase when inserting into a bucketed table. 

 This would be good to have back.
