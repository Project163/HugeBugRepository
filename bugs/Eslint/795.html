Title

Feature Request: Add option to newline-per-chained-call for func calls only

Description
Personally , I want to ask if its possible to have an option to chain function calls only and not object access as well?

Example:

```
// valid with option on, invalid with off
db.user
            .query()
            .then()
            .catch();
```

I'm not sure what to name the option, perhaps `funcCallOnly` ? e.g 

```
  'newline-per-chained-call': [2, {funcCallOnly: true}]
```
Discussion
- I'd prefer `onlyMethods` or `memberAccess` or `propertyAccess`. That said the initial explanation of the rule just mentions method calls so may be we should exclude member access completely. That would be a breaking change though.
- I'm pretty sure this is a bug, the rule even says "chainable call".
- This code causes error by me

```
javascript
// error, but no chained function call, wtf?
const debug = window.location.search.indexOf('debug=1') !== -1;

// no error
```
