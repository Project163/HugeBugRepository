Title

Kinesis receiver does not checkpoint to DynamoDB if there is no new data.

Description
Current implementation of KinesisRecordProcessor checkpoints to DynamoDB only when there is a new record received. So if there is no new data for a while, the latest received sequence numbers are not checkpointed. This is not intuitive behavior and should be fixed using  timer task.
