Title

Cannot use argument_for on DialectKWArgs not explicitly in construct_arguments

Description
**Migrated issue, originally created by Dennis Hennen ([Link: @dhennen])**

Using 0.9.4

    from sqlalchemy.sql.expression import Insert
    Insert.argument_for('mysql', 'foo', False)

returns

    Traceback (most recent call last):
      File "test.py", line 2, in  
        Insert.argument_for('mysql', 'foo', False)
      File "/usr/local/lib/python2.7/site-packages/sqlalchemy/sql/base.py", line 184, in argument_for
        construct_arg_dictionary[cls][argument_name] = default
    KeyError:  

Because mysql doesn't have Insert explicitly in it's construct_arguments we get the KeyError.
Discussion
- **Michael Bayer ([Link: @zzzeek]) wrote:**

- Fixed bug in new :meth:`.DialectKWArgs.argument_for` method where
adding an argument for a construct not previously included for any
special arguments would fail. fixes #3024
