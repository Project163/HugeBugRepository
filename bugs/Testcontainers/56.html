### What happened?

The official mongodb 6.0 docker image was released yesterday: [URL]
The image can not be used with testcontainers, as there is mongo-executable within the PATH anymore: 
```
➜  ~ docker run mongo:6.0 mongo
/usr/local/bin/docker-entrypoint.sh: line 421: exec: mongo: not found
```
Testcontainers startup fails accordingly.
