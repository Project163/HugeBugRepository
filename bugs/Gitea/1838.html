Title

bracket syntax `\(\)\[\]` for math problematic

Description
### Description

Here's another issue with the bracket syntax: `\[Link: ` and `\]` are actually valid Markdown characters (see Markdown definition [here]), rendering to `[Link: ` and `]`, respectively. The escaping is to set brackets apart from Markdown links à la `[abc]`. Markdown formatters like [Link: prettier] or [Link: mdformat] escape brackets in various places, accidentally producing Gitea math. (See [Link: here] for the corresponding mdformat bug.)

Related to [URL]

_Edit:_ [Link: I've surveyed math syntaxes and performance on GitHub, Gitea, GitLab.]. Gitea's bracket-syntax is unique and hence not compatible. The backticked syntax is sorely missing from Gitea, especially given its great performance on the other platforms.
