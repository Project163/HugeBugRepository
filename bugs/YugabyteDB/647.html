Title

[xCluster] Removing table with alter_universe_replication blocks dropping table

Description
Jira Link: [Link: DB-2725]
### Description

When using remove_table with alter_universe_replication, this doesn't remove the table from the in-memory `xcluster_consumer_tables_to_stream_map_` map. Then when the table is trying to be deleted, then the table gets blocked on the `IsCDCEnabled` check as it still thinks its a consumer table.
