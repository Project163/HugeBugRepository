Title

test_reflection fails when running against MariaDB 10.6

Description
### Describe the bug

test_reflection fails when running with mariadb connector or against MariaDB server > 10.6.0:

- Default character set for mariadb dialect is utf8mb4 - it cannot be changed.
- Since MariaDB 10.6.1 utf8 character set is mapped to utf8mb3 (and will be mapped to utf8mb4 in 10.7). See [URL]

Proposed solution: when testing against a MariaDB server or with mariadb dialect, use character set utf8mb4 instead of utf8.

### To Reproduce

```python
pytest  --dburi=mariadb+mariadbconnector://foobar:foobar@ :3306/test test/dialect/mysql/test_reflection.py
```

### Error

```
_______________________ ReflectionTest_mariadb+mariadbconnector_10_6_4.test_reflection_with_table_options ________________________
Traceback (most recent call last):
  File "/home/georg/work/python/sqlalchemy/test/dialect/mysql/test_reflection.py", line 341, in test_reflection_with_table_options
    assert def_table.kwargs["mariadb_default_charset"] == "utf8"
AssertionError: assert 'utf8mb4' == 'utf8'
  - utf8
  + utf8mb4
```

### Versions

- OS: Linux
- Python: 3.9.6
- SQLAlchemy: master branch, latest version
- Database: MariaDB 10.6
- DBAPI (eg: psycopg, cx_oracle, mysqlclient): mariadbconnector
