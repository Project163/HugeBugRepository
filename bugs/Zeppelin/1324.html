Title

Zeppelin does not support JDBC interpreter for trino v358 and above

Description
1. prestosql has been renamed to trino since 2020.12 
 
	  [URL]
 

  2. jdbc interpreter supports only `com.facebook.presto.jdbc.PrestoDriver` and `io.prestosql.jdbc.PrestoDriver` after bug (check issue below) 
 
	  [URL]
 

 
	  [URL]
 

   

 3. trino no longer supports the name `io.prestosql.jdbc.PrestoDriver` and has been removed in v358.  

  - [URL]

 4. For backward compatible, need to add trino driver name to support v358 and above

- This is what I did to apply the fix on a my container: 
1. Start a new container to build the jdbc jar - used maven image with open-jdk java 1.8: 
  
 
docker run -it --rm --name my-java --mount type=bind,source= "$(pwd)" /output,target=/output maven:3-openjdk-8 /bin/bash  
  
 2. Inside the container build the jdbc jar, the new jar - which will be placed in the current dir of the host: 
  
 
git clone https: //github.com/apache/zeppelin.git
 cd zeppelin
mvn --projects zeppelin-common,zeppelin-interpreter,zeppelin-interpreter-shaded,jdbc clean  package  -DskipTestscp 
cp interpreter/jdbc/zeppelin-jdbc-0.11.0-SNAPSHOT.jar /output/  
  
 3. Replace the jar in the zeppelin container. The target name is for the latest docker image: 
  
 
docker cp zeppelin-jdbc-0.11.0-SNAPSHOT.jar your-container-name:/opt/zeppelin/interpreter/jdbc/zeppelin-jdbc-0.10.0.jar
