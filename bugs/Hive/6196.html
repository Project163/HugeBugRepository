Title

Vectorization acid/inputformat check should allow NullRowsInputFormat/OneNullRowInputFormat

Description
Vectorizer.verifyAndSetVectorPartDesc() has a Preconditions check to ensure the InputFormat is ORC only. However there can be metadataonly or empty result optimizations on Acid tables, which change the input format to NullRows/OneNullRowInputFormat, which gets tripped up on this check. 
Relaxing this check to allow nullrows and onenullrow input formats.
