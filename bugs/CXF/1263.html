Title

Codegen plugin requires WSDL artifact to be listed in dependency tree

Description
The maven-codegen-plugin is only capable of resolving WSDL artifacts that are listed in the dependency tree. This had the unintended consequence of re-scoping transitive dependencies in to the current project. 

 Since the maven-artifact-resolver is arguably flawed (see   CXF-3964  ), a more robust approach is necessary to handle both possible scenarios (WSDL as a dependency, WSDL not as a dependency).
