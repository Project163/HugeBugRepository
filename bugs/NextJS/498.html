### To Reproduce

Send a POST request to [URL] which includes the [Link: Expect] header (`Expect: 100-continue`).

### Describe the Bug

Starting from next@13.4.13 POST requests to (Pages-based) API routes with an Expect header fail with an error:
[Image: image]

Using next@13.4.12 the issue is not reproducible.

The Expect header is apparently [Link: automatically sent by .NET]. We are simultaneously looking into disabling this in the .NET client making these particular requests.

**Here are notes from a colleague's investigation into this...**
You have an internal invoke-request file that executes internal server side fetch call when API route is triggered by POST request

Before  <13.4.13 you used node fetch: [URL]

In scope of 13.4.13 you removed node fetch and started to use [Link: undici]: [URL]

undici doesn't support this header, so it's a breaking change for us, see: [URL]

Here is a PR where you made these changes: [Link]

Here is a PR where you mentioned migration to undici: [URL]

### Expected Behavior

Expect header is supported.
