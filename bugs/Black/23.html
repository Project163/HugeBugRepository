Title

Black does not follow line length rule with ternary expression

Description
Operating system: MacOS
Python version: 3.6.4
Black version: 18.4a2
Does also happen on master: yes

Code: 
```
x = {
    'a': (
        some_very_long_value 
        if some_condition_smsmms 
        else another_long_value_smsmsms
    )
}
```

is being formatted to 

```
x = {
    "a": (
        some_very_long_value if some_condition else another_very_very_very_long_value
    )
}
```
by **black** despite line length settings.
Discussion
- So your line length is 86 here:

```
$ echo "        some_very_long_value if some_condition else another_very_very_very_long_value" | wc -c
      86
```

And I see the default max line length is set to 88: [URL]

You can change it follow the docs.
- What's more, your variable name is so long and can't be break beautifully, I have tried this:

```
x = {
    "a": (
        some_very_long_value if some_condition else another_very_very_very_long_valueaaaaaaaaaaaaaaaa
    )
}
```

It will still in one line. But when I change to this, it works good.


```
x = {
    "a": (
        some_very_long_value if some_condition_smsmms else [
            x for x in asdfasdfasdfasdfasdfasdfasdf
        ]
    )
}
```
- @laixintao 1) My bad I haven't specified used line length in the example. Idea was that despite line length setting (like, if you manually set it to e.g. 80 in the example above) black will break line length setting and will put shown expression in 1 line, even if it breaks line length setting

2) yes, there is a workaround - if you wrap any of if or else expression into parentheses, black will use them to break lines.
- So I think the line length is not a constraint? Leaving them in one line is better than break them into ugly lines.
