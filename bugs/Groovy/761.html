Title

Bindable transformation causes verification errors with static properties

Description
If you add the Bindable transformation to a class with static properties, then a VerifyError will be generated at runtime. In my mildly abused version of the transformation, I added a check for isStatic() to createListenerSetter, and that solved the problem.
Discussion
- Yep, I should be failing on annotating static properties and skipping them for class annotations.  Tests included
