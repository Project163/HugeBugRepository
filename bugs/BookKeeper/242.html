Title

Add flag to output test logs to stdout

Description
Logs are currently piped to a file. However, if a test is hanging, its useful to get the logs sent to stdout in as they happen, to see where the test is hanging. We should enable this with a mvn profile, instead of requiring the person to edit out the <redirectOutputToFile> flag.
Discussion
- With the attached patch, test output can be sent to stdout by adding -PconsoleTestOutput to the maven command.
- Patch looks good to me, and test is ok in my dev box.
