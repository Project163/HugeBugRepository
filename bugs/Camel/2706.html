Title

CXFRS does not check JAX-RS Exception mappers

Description

    
Discussion

    
- If calling CXF JaxrsUtils.convertFaultToResponse(throwable, currentCxfMessage) returns non-null Response then the exception has been mapped
- Current CxfRsInvoker just hijack the exception and turn it into WebApplicationException, which disables the CXF default feature of exception mapping.  
I'm working on the patch now.
- Applied the patch into camel master, camel-2.13.x and camel-2.12.x branches.
