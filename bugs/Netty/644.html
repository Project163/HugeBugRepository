Title

Netty Epoll.isAvailable() check doesn't handle lib loading issue on 32bit JVM

Description
### Expected behavior
Method should check os and jvm variables if it can safely load the libs expected and return false and not cause JVM warning by loading incompatible libs

[URL]

### Actual behavior
using a 32 bit JVM:
Java HotSpot(TM) Server VM warning: You have loaded library /tmp/libnetty-transport-native-epoll7550636318037030956.so which might have disabled stack guard. The VM will try to fix the stack guard now.
It's highly recommended that you fix the library with 'execstack -c  ', or link it with '-z noexecstack'.

### Steps to reproduce
Run netty native epoll on 32bit jvm
