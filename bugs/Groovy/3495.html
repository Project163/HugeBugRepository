Title

Specifying initial heap size results in an error

Description
On Windows, setting initial heap size greater than 128MB without setting maximum heap size, e.g. JAVA_OPTS=-Xms1G, results in the following error: 
  Error occurred during initialization of VM 
Initial heap size set to a larger value than the maximum heap size  
 This works fine on Linux. And it is a valid JVM parameter, since JVM will set its maximum heap to be the greater of its default value and initial heap size.
Discussion
- Is it a Groovy or Java issue? Do you have a stacktrace?
- The problem is with the way Groovy initializes JVM. There is no stacktrace, the error is the only output.
- Okay, understood. Looks like we hard code a value for -Xmx: 

  [URL]

 Obviously we should not do that if a user supplies their own -Xmx and/or the value should be at least as big as any -Xms setting.
- I have removed our explicit setting. Reading up on the default value for that setting on current JVMs, I suspect it will be set to a higher value on most folks systems.
