Title

Distinguish between class-level and instance-level function objects

Description
A recent change (#104) fixed some issues related to function objects as data attributes, but it broke other cases.

There are two different ways of associating data attributes with callable values:
1. class-level: when accessing via instance, create bound method (implicit self)
2. instance-level: when accessing via instance, return value as such

The fix to #104 fixed 1 but broke 2. 

Here is a simple idea for fixing also 2 (but we may eventually need a better long-term solution):
- callable data attributes have a flag determining whether they are instance or class level
- if a data attribute with a callable type has an initializer in the class body, it is 
  automatically
  class-level; otherwise, the data attribute is instance-level
- perform implicit self processing only for class-level attributes (and methods; they are
  always class-level)
