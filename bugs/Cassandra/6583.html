Title

Remove `REPEATED_TESTS` env var from repeated tests script

Description
Quick follow-on from   CASSANDRA-18942   

 The use of REPEATED_TESTS doesn't work with the dockerised scripts (see this  comment ), and duplicates the `-t` functionality. 

 Easiest solution is to just remove it.
