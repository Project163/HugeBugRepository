Title

torch.nn.functional.pad throw 'Dimension out of range' on Apple Silicon M1 MPS

Description
### 🐛 Describe the bug

If I try to use torch.nn.functional.pad on a tensor on an MPS device, I get this error
```IndexError: Dimension out of range (expected to be in range of [-1, 0], but got 1)```
It doesn't happen when the device is set on 'cpu'

```
import torch
import torch.nn.functional as F

test = torch.ones((64), device='mps')
testPadded = F.pad(test,(0,1),value=0.)
```
