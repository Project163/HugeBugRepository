There's a remaining issue: if the column type is integer, and you are binding a boolean value (PDO:TYPE_BOOLEAN), it will cause an error for pgsql. The same error doesn't occur to other DBMS. 

Note that when you are inserting/updating records, the issue won't occur because Yii can correctly typecast the values based on the column types. However, if you are providing values to query conditions, all Yii can do are to use corresponding PDO type based on PHP type.
