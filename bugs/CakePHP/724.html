Title

_ext='json' Url generation does not allow for passed parameters.

Description
If I generate a Url with parameters, the Router does not detect the .json in the url as the Router.php file expects .json to be the end of the URL.

For example:

```
url = " Url->build(['controller' => 'Purchases', 'action' => 'getDealerDefaultState','id'=> 47,'_ext'=>'json']) ?>";
        targeturl = url;
        $.ajax({
            type: 'get',
            url: targeturl,
            beforeSend: function(xhr) {
                xhr.setRequestHeader('Content-type', 'application/x-www-form-urlencoded');
            }
```

Generates a url such as:
Controller/getDealerDefaultState.json/id=47

I modified my Cakephp/src/Routing/Route/Route.php file as follows

```
preg_match('/\.([0-9a-z]*)/', $url, $match); // modified the RegExp  to search for an '_ext' globally in the URL

    if (empty($match[1])) {
        return [$url, null];
    }
... [Log Snipped] ...
    $url = str_replace($ext, '', $url);  //remove the found ext (e.g. '.json' )from the URL
    return [$url, null];
```

This solved my problem and allows multiple parameters to be sent via the URL.
