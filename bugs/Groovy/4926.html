Title

Static compiler should treat inner records as static

Description
should work   
 
@groovy.transform.CompileStatic
 class  Reproducer { 
  def foo() {
     new  MyRecord(42)
  } 

 record MyRecord( int  i) {}
}
 
  

 But fails with   [Static type checking]  - Cannot find matching constructor Reproducer$MyRecord(Reproducer, int)  

 These work 

   static record   
 
@groovy.transform.CompileStatic
 class  Reproducer { 
  def foo() {
     new  MyRecord(42)
  } 

   static  record MyRecord( int  i) {}
}
 
  

   static method   
 
@groovy.transform.CompileStatic
 class  Reproducer { 
   static  def foo() {
     new  MyRecord(42)
  } 

  record MyRecord( int  i) {}
}
