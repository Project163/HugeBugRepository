Title

GenericContainer runs in endless loop, when image does not exist

Description
When using GenericContainer with an image, that does not exist on dockerhup (which happened to me because of a typo), then there is a endless loop in `GenericContainer.java:244`. It would be better to print a clear error message in this case.

To workaround [URL] one could retry N times before printing an error.
