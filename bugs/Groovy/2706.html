Title

GeneratedMetaMethod.Proxy#proxy() can cause massive waiting times

Description
The method is synchronized, so if multiple threads want to read, they all have to go through the full synchronization procedure. The variable is already volatile, so it would be enough to make the writing process synchronized. This can still cause massive waiting times, if for example the class loader is very slow and the proxy has not been generated yet. Unfortunately there is no solution for that
Discussion
- now only the writing of proxy is synchronized, reading is done by volatile
