Title

Autogeneration of the migration code breaks MongoDB migration

Description
Originally reported at:
[URL]

Latest addition:
[URL]

was made in the wrong way: `BaseMigrateController` was affected by relational DB related logic.

Thus, MongoDb migration now fails with error "The view file does not exist: "
Discussion
- Before i have same issue but I fixed it with this solution:

``` php
    'controllerMap' => [
        'mongodb-migrate' => [
            'class' => 'yii\mongodb\console\controllers\MigrateController',
            'migrationPath' => '@app/migrations/mongodb'
        ]
    ],
```

and for generate migration:

```
php yii mongodb-migrate/create user_collection
```

MongoDB migration going to mongodb folder under migrations folder.
