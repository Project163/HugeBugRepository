Title

Async root logger config is defaulting includeLocation to true without use of Log4jContextSelector system property

Description
I'm using the approach detailed here -  [URL] - under "Mixing Synchronous and Asynchronous Loggers" where we have the <asyncRoot> logger defined. I noticed this was slow so looked into it and noticed the location was being captured but I thought this should default to false for async loggers. Looking into this, the line here -  [URL] - the call to includeLocation() is actually calling LoggerConfig.includeLocation() which checks for the existence of the system property (which we don't have set), therefore include location defaults to true. I think instead it should be calling the includeLocation() static method inside of AsyncLoggerConfig here -  [URL] - which would end up defaulting this to false correctly as the includeLocation value is actually null since I didn't explicitly configured it.
