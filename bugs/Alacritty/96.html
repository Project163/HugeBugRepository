Title

focused terminal turns invisible with chunkwm when opening another application

Description
Which operating system does the issue occur on? MacOS 10.13.3
Alacritty version:  

A focused alacritty terminal turns invisible when another app is opened. I'm using [Link: chunkwm] (a tiling window manager) so the alacritty terminal gets resized when I open another app. The contents of the alacritty terminal become visible when I focus the window again. I attached a gif showing this in action, the red outline shows which window has focus.

If I had to guess, this weird combination of a window being resized but losing focus that causes the terminal to stay invisible.

This is really just an annoyance :)
