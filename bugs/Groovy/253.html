- blackdrag solved the issue with ''' 
in fact the error was a little bit different. Initializing a Closure  
means always to use Reference instances. In the case above the Reference  
  instances were prepared, but then overwritten by a careless astore  
which sotred the Throwable there instead of using the reference. Of  
course this means that a later access to this register gets no reference  
but the Throwable and so the initialization of the closure inside the  
catch block failed. 

 But this should be fixed now... and btw, this strange workaround with  
"def local = t" should also not any longer be used. It is not needed in  
the new scoping. 

 bye blackdrag
