Title

Numpy `ufunc` type-inference (for Expr) can't distinguish between Float32 / Float64 (raising SchemaError)

Description
### Polars version checks

- [X] I have checked that this issue has not already been reported.

- [Link: X] I have confirmed this bug exists on the [latest version] of polars.


### Issue Description

Applying numpy `ufunc` against Float32 columns fails, as the type inference inside `Expr.__array_ufunc__` forces `return_dtype` to Float64. 

Setting `return_dtype` to None or Float32 (while debugging the issue) causes the calculation to succeed, so it's just the forcing to Float64 at issue, rather than Float32 ops not working.

### Reproducible Example

```
python
import numpy as np
import polars as pl

# create some 32bit test data
... [Log Snipped] ...
# SchemaError: Expected output type: 'Float64', but got 'Float32'.
#  Set 'return_dtype' to the proper datatype.
```


### Expected Behavior

Numpy `ufunc` calculations should succeed against Float64 _and_ Float32 columns.
