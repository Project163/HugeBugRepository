     Make setting of working directory to user-home optional for shell interpreter
- Allow me to suggest that this may not be necessary. 

 Since the purpose of the shell interpreter is to run a shell script (the lines of the command provided to it), the interpreter's behavior should be as close to that of a real shell as possible. 

 So if the author of a script desires to run it in the home directory, the simple addition of a "cd" command at the top of the script should achieve that result. This would be completely transparent and natural to those reading the script later. 

 The need to correct the problem caused by Docker-hosting is IMHO a separate issue, and should not be mixed with configuration mechanisms. 

 Submitted for your consideration.
