Discussion
- So here is what I think is happening: 
1. AcidUtils.getAcidState() retrieved a list of files from the partition directory  
2. The transactional file Cleaner deleted some of the files from this same partition directory 
3. AcidUtils.getChildState tried to perform some file operations on the files listed in step (1), and hit the FileNotFoundException encountered by the customer. 

 Basically AcidUtils.getAcidState() is not safe in the event that files are being deleted at the same time that this method is called.
- Looks like   HIVE-21225   did not include fixes for this issue after all.
