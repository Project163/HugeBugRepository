Title

Using config globals with quotes throws error, but using globals without quotes still continues.

Description
In the `.eslintrc` config JSON, using globals with quotes (valid JSON) fails:

``` json
{
    "globals": {
        "foo": false
    }
}
```

But this invalid JSON without quotes doesn't throw the error (although the globals still aren't acknowledged):

``` json
{
    globals: {
        "foo": false
    }
}
```
