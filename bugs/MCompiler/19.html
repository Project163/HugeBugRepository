Title

-Xlint -Xlint:-path argument quoting problem

Description
<compilerArgument>-Xlint -Xlint:-path</compilerArgument> gives the following error: 

 javac: invalid flag: -Xlint -Xlint:-path 

 The workaround/hack illustrates the quoting problem: 

 <compilerArgument>-Xlint" "-Xlint:-path</compilerArgument> 

 And now to quote the docs at  [URL]

 Sets the unformatted argument string to be passed to the compiler if fork is set to true. This is because the list of valid arguments passed to a Java compiler varies based on the compiler version.
