Title

[HttpKernel] #[MapQueryString] does not handle string and arrays properly, returning an empty / invalid dto

Description
### Symfony version(s) affected

6.3

### Description

`RequestPayloadValueResolver` does not handle string and arrays properly, returning an empty / invalid dto even with all default values set.

```
php
class SearchDTO
{
    public function __construct(
        #[Assert\All([

    }
}
```

- The problem is caused by the `RequestPayloadValueResolver` passing the `disable_type_enforcement` option to the `denormalize()` method. Without that option an exception is thrown.

Updated code

```
#[Route(path: '/', name: 'homepage')]
public function homepage(
    #[MapQueryString(
        serializationContext: ['disable_type_enforcement' => false]
    )] SearchDTO $searchDTO = new SearchDTO()
): Response {
    dd($searchDTO);
}
```
