Title

[YSQL] Create a shared relation during YSQL upgrade should have global impact

Description
Jira Link: [Link: DB-11729]
### Description

During YSQL upgrade, we can create a new shared relation. Currently in per-database catalog version mode we only increment the catalog version of database template1 because this create shared relation DDL statement does not modify any shared relations. It only updates system tables such as pg_class, which isn't a shared relation by itself. Creating a shared relation during YSQL upgrade should be considered as having global impact and should increment the catalog version of every database. Otherwise, except for template1, any other database may continue to have stale catalog cache stored in tserver cache, and a new connection that loads this stale catalog cache will not be able to see the newly created shared relation during the initial catalog preloading phase.
