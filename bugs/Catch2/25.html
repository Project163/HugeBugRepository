Title

ApprovalTests fail when using out-of-source build

Description
## Description
I tried running the tests for Catch2 after building it with CMake + Ninja. The ApprovalTests failed. The only difference I could see is that all the `filename`s were `../project/...` rather than `project/...`.

### Steps to reproduce

```
$ git clone [URL]
$ cd Catch2 && mkdir build && cd build
$ cmake -G Ninja ..
$ ninja
$ ctest
```

This did not show up with the default `make` generator.

* Catch version: [Link: 7b6e49d]
