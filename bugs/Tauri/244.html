Title

[bug] `UpdateBuilder::target` weird behavior when specifying target

Description
### Describe the bug

These are the lines in question:
[URL]

Aside from being weird and hard to understand the section has a logic issue, that would potentially prevent the updater from finding the correct platform entry.

### Reproduction

Let's make an example to illustrate this:

I'm setting `UpdateBuilder::target` to `darwin-x86_64` even though my machines arch is `aarch64`.
This will cause the updater to fill out the url `[URL] like so `[URL] which is absolutely not what I intended. 

It gets weirder though:
Let's also say I'm using the url parameters only for statistics and always return the `static JSON format`. 
In this situation the updater would download the `x86_64` artifact (like intended) **even though** it clearly announced to the update server that it's arch is `aarch64`.

### Expected behavior

given the target `darwin-x86_64`
`{{target}}` would get replaced with `darwin` and `{{arch}}` would be replaced by `x86_64`.
