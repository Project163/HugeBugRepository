Title

[5.0.2] Importing a FBX model exported from MAYA cause assertion

Description
I have a FBX model with animation which is exported by MAYA, Importing it in Assimp 5.0.2 will cause assertion in FBXConverter.cpp, line 806:
```
            // is_complex needs to be consistent with NeedsComplexTransformationChain()
            // or the interplay between this code and the animation converter would
            // not be guaranteed.
            ai_assert(NeedsComplexTransformationChain(model) == ((chainBits & chainMaskComplex) != 0));

```

    If I ignore the assertion and continue, the animation look weird, the arm rotation is obviously incorrect.
    You can download the FBX model from the following link:
    [URL]
Discussion
- I have found the cause of the problem. That is because in FBXConverter.cpp: FBXConverter::NeedsComplexTransformationChain() and FBXConverter::GenerateTransformationNodeChain() use different epsilon value to detect transformation. Once I change epsilon used in FBXConverter::NeedsComplexTransformationChain() to the following

const float zero_epsilon = Math::getEpsilon ();

    The problem is solved.
