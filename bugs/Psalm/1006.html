Title

Classes loaded before manual autoloader registration

Description
Hi,

Our project have a manual auto loader which we registered via autoloader attribute in xml file.

However, we still get errors for UndefinedClasses. After investigation, I believe it happens because our autoloader need some dependancies that are loaded manually before the autoloader is registered. Those dependancies have some reference to other classes that, at this time, can't be loaded. They are registered in ClassLoader::missingClasses and even if they can be loaded after, they're still considered missing

I tried some solutions:
1) try to require those file before registering the autoloader: it doesn't work
2) Run psalm with cache: the first run fails, but it succeed after using cache. However, we can't do that due to high memory usage when loading cache on complete analysis (8GB +)

Is there a solution to help psalm detect those classes? (no matter how dirty for now, I already have to tweak Psalm's code to run our project...)

Thanks a lot!
