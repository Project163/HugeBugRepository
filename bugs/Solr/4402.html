Title

@LogLevel annotation not properly reseting after end of test (causes LoggingHandlerTest.testLogLevelHandlerOutput failures)

Description
We've seen a recent uptick in jenkins failures from  LoggingHandlerTest.testLogLevelHandlerOutput  that indicate the @LogLevel usage in other tests that have run earlier in the same JVM are  NOT  properly being reset when those tests complete.
Discussion
