Title

Exclude relocation of org.apache.hadoop.security.* in the JDBC standalone jar

Description
There has been a use case that core-site.xml file is used along with the JDBC jar, which sets "hadoop.security.group.mapping" using the class names such as "org.apache.hadoop.security.JniBasedUnixGroupsMappingWithFallback". This will cause CNF errors due to the renaming. So we need to exclude those security related classes in the relocation part.
