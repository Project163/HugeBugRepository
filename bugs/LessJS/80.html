Title

Allow [class*="@{grid_col_class}"] selector interpolation in 1.4

Description
In most cases this `.myclass_@{index}` is a perfectly fine alternative to using the `(~".myclass_@{index}")` selector interpolation. The problem is when you need to use a variable but keep the quotes as well. Here's an example that I currently am using in my grid system:

```
@grid_col_class: col-;

(~'[class*="@{grid_col_class}"]') {
    .column-base();
}
```

This currently outputs:

```
[class*="col-"] { 
    ...my column styles...
}
```

If the `(~".myclass_@{index}")` selector interpolation becomes deprecated, I can't think of another way to allow users to use a variable class name within that CSS class selector.
Discussion
- Try this:

```
@grid_col_class: col-;
@new_syntax: ~'[class*="@{grid_col_class}"]'; //escaped value interpolation
@{new_syntax} {
    define: something;
}
```

I tried it with beta-1 less-1.4.0-b1.js and it seems to work:

```
[class*="col-"] {
  define: something;
}
```
- It would be good to be able to write

```
[class*="@{grid_col_class}"] {
    .column-base();
}
```

I am assigning this as a 1.4.0 bug
