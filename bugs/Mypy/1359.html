Title

Multiple inheritance with Generic leads to [misc] error

Description
**Bug Report**

If we creates multiple generic parents with the same generic attribute, mypy raises an error about incompatible definition

**To Reproduce**

```
python
from typing import Generic, TypeVar

T = TypeVar("T")

... [Log Snipped] ...
class C(A[str], B[str]):
    pass
```

Raises `error: Definition of "x" in base class "A" is incompatible with definition in base class "B"  [misc]`

**Expected Behavior**

The example should has no error, like in the final types case

```
python
class A:
    x: str

class B:
... [Log Snipped] ...
class C(A, B):
    pass
```

**Actual Behavior**

Raises an error

**Your Environment**

`mypy==1.14.0`

It validates two `TypeVarTypes`, that  contains `TypeVarId` differs by [Link: `namespace`]. They has `A` and `B` classes values, but seems like the correct one is `C` or `str`
