Title

camel-vertx-http duplicates path

Description
The following code 
  
 
from( "timer:test?repeatCount=1" )
    .setHeader(Exchange.HTTP_URI, simple( "https: //gorest.co.in/ public /v1/users/123/posts" ))
     .toD( "vertx-http:${header.CamelHttpUri}" );
 
  
 throws exception: 
  
 Error processing exchange. Exchange[AB574B09C060549- ]. Caused by: [org.apache.camel.http.base.HttpOperationFailedException - HTTP operation failed invoking [URL] with statusCode: 404]: org.apache.camel.http.base.HttpOperationFailedException: HTTP operation failed invoking [URL] with statusCode: 404
 
  

 Because it duplicates path  public/v1/users/123/posts/public/v1/users/123/posts  

 Same code with camel-http work fine 
  
 
.toD( "${header.CamelHttpUri}" )
Discussion
- That is because you use toD and "abuse" the Exchange.HTTP_URI header. 
You can use to then it should work
- 1.  to  works for camel-vertx-http 
  
 
.to( "vertx-http:${header.CamelHttpUri}" )
 
  

 2. However  toD  works for camel-http 
  
 
.toD( "${header.CamelHttpUri}" )
 
  

 3. But  to   does not work  for camel-http 
  
 
.to( "${header.CamelHttpUri}" )
 
  

 This is kind of confusing
- Ad 2) 
This only works because the http uri is with https that is the http component name also (http/https) 

 So if you do it as 

  
 
.toD( "http:${header.CamelHttpUri}" )
 
  

 Then it fails just like vertx-http does
- There was a bug in toD when using vertx-http when compared to camel-http.
