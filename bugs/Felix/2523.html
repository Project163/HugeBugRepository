Title

Race condition between getService and stopping the http service

Description
It might happen that getService() is called on the HttpServiceFactory while stop() is called and the context is set to null. This results in an IAE. 
We should first unregister the factory and then set the context to null. In addition if the context is null, getService should just return null and not throw
