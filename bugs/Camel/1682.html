Title

camel-netty component requires a URI parameter to set receiveBufferSizePredictorFactory for UDP consumers

Description
The Netty UDP consumer truncates received messages that are larger than 768 bytes. A number of higher level protocols and data-formatters have message sizes larger than 768. E.g. Syslog 1024 bytes
