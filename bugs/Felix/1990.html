Title

DeploymentAdmin tries to start/stop fragment bundles

Description
Deployment Admin currently tries to start all bundles in a deployment package, including fragment bundles. Although this fails, the installation of the deployment package still succeeds. Nevertheless, it is sloppy to do this.
