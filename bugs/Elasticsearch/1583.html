Title

_cat/shards should support index pattern wildcards

Description
**Elasticsearch version**: 2.3.3 & 2.3.4

**JVM version**: what is running in Cloud now

**OS version**: what is running in Cloud now

**Description of the problem including expected versus actual behavior**:
I’m trying to do some cat queries and I run into an issue that I can’t see any results when I try to use a wildcard in _cat/shards

**Steps to reproduce**:
0. Make sure you have some indices named topbeat*
1. GET _cat/indices/topbeat\* <-- as expected
2. GET _cat/segments/topbeat\* <-- as expected
3. GET _cat/shards/topbeat\* <-- empty response

But if I point to a single index with its full name, it does work.

Not sure if this is a bug or an enhancement, the docs actually speak of "[Link: index pattern]", so I'm leaning towards bug.
