Title

Check first if an add-on can be uninstalled before uninstalling dependents

Description
If an add-on can't be unloaded its dependents should not be uninstalled, otherwise the functionality provided by those add-ons is unavailable while the add-on that was meant to be uninstalled remains available (thus still usable).
