Title

IllegalAccessError: trait property and protected/package-private super access method

Description
Consider the following: 
  
 
 trait  A {
  final  long  id = 123L
}
 class  B {
  protected final  long  getId() { 456L }
}
 class  C  extends  B  implements  A {
}

 def  c =  new  C()
 assert  c.id ==  '456L' 
 assert  c.getId() ==  '456L' 
 
  

 The property expression "c.id" throws an IllegalAccessError at run time.
