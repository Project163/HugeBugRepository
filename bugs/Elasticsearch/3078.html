Title

Null pointer exception in /_scripts/painless/_execute endpoint using score context if no document match

Description
**Elasticsearch version** 

7.0.1

**Plugins installed**: []

**JVM version** 

9

**OS version**

Linux 4.18.0-22

**Description of the problem including expected versus actual behavior**:

The endpoint `/_scripts/painless/_execute` throws a null pointer exception when the context parameter is set to `score` and the document in the context does not match the query.

**Steps to reproduce**:

Set up a simple mapping

```
curl -X PUT "localhost:9200/test" -H 'Content-Type: application/json' -d'
{
    "mappings" : {
        "properties" : {
            "field": {"type": "keyword"}
        }
    }
}
```
The following call return a valid result

```
curl -X POST "localhost:9200/_scripts/painless/_execute" -H 'Content-Type: application/json' -d'
{
  "script": {
    "source": "_score"
  },
... [Log Snipped] ...
  "context": "score"
}
```
If the query is modified and does not match the document a null_pointer_exception is sent.
```
curl -X POST "localhost:9200/_scripts/painless/_execute" -H 'Content-Type: application/json' -d'
{
  "script": {
    "source": "_score"
  },
... [Log Snipped] ...
  "context": "score"
}
```

**Possible bugfix**

In `PainlessExecuteAction.java` file, in the method `innerShardOperation` the call `weight.scorer(indexSearcher.getIndexReader().leaves().get(0))` can return a null value but is not checked.
