Title

Panache repository breaks when narrowing the generic of a subclass

Description
### Describe the bug

I am not 100% sure what is going on here. I suspect it is a bug in Quarkus but I can't be 100% sure (the error message is definitely not correct though).

We use a setup where we have our own generic panache base repository, which inherits/extends the Quarkus provided panache base repository, and is then implemented by concrete repositories. A logical implementation of the intermediate layer is:
```kotlin
abstract class BaseRepository  : PanacheRepositoryBase 
```

Which indeed works perfectly fine. However, we now need something like this:
```kotlin
abstract class BaseRepository  : PanacheRepositoryBase 
```

And this suddenly breaks, with:
```
Caused by: java.lang.IllegalStateException: This method is normally automatically overridden in subclasses: did you forget to annotate your entity with @Entity?
	at io.quarkus.hibernate.orm.panache.common.runtime.AbstractJpaOperations.implementationInjectionMissing(AbstractJpaOperations.java:452)
	at io.quarkus.hibernate.orm.panache.kotlin.PanacheRepositoryBase.findById(PanacheRepositoryBase.kt:95)
	at nl.rug.digitallab.BrokenBaseRepository.findById(Reproducer.kt:36)
	at nl.rug.digitallab.BrokenBaseRepository.findById(Reproducer.kt:36)
... [Log Snipped] ...
	at nl.rug.digitallab.BrokenAssignmentRepository_ClientProxy.findByIdOrThrow(Unknown Source)
	at Reproducer.This breaks for some reason(Reproducer.kt:32)
```

Even though we did not change the entity at all.

I tried to make a toy reproducer that has the minimal number of changes with the two to see where it breaks, and taking the exact same implementation, but changing
```kotlin
abstract class BaseRepository  : PanacheRepositoryBase 
```

by this (with making no other changes):

```kotlin
abstract class BaseRepository  : PanacheRepositoryBase 
```

Suddenly makes this issue appear.

### Expected behavior

I should be able to narrow down the generic from Any to UUID without causing an issue with the generated entity method
