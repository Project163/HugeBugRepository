Title

Runtime.getRuntime().availableProcessors() is assumed to be constant

Description
`Runtime.getRuntime().availableProcessors()` is not constant, and may decrease while a node is running. If it does so, the default value of `node.processors` may become invalid, leading to APIs like `GET _cluster/settings?include_defaults` returning an IAE: `Failed to parse value [8.0] for setting [node.processors] must be <= 1`.

I think we should capture the value of `Runtime.getRuntime().availableProcessors()` when starting up and use this immutable value for the validation.
