Title

TIFF JPEG reader encounters array bounds exception on edge cases.

Description
The changes recently introduced for Imaging-194 permit the processing of TIFF files that use JPEG compression internally (these are TIFF files, not JPEG files).  However, there is an edge case where they can fail and throw an array-bounds exception.  This Issue proposes to fix the bug and contribute an additional test file that exercises the section of code that has the problem.
