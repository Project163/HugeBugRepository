Title

[DocDB] Tablet bootstrap unable to decode SELECT FOR UPDATE/KEY SHARE provisional records.

Description
Jira Link: [Link: DB-7542]
### Description

Originally found during testing with dynamic tablet splitting but turned out to be reproducible even with single tablet without splitting with the following test:
```
TEST_F(PgRowLockTest, SelectForKeyShareWithRestart) {
  auto conn = ASSERT_RESULT(Connect());
  ASSERT_OK(conn.Execute("CREATE TABLE t(k INT, v INT) SPLIT INTO 1 TABLETS;"));
  ASSERT_OK(conn.Execute(
      "INSERT INTO t SELECT i, 1 FROM (SELECT generate_series(1, 10000) i) t2;"));
... [Log Snipped] ...
  ASSERT_OK(conn.CommitTransaction());
}
```

Intent value decoding fails during loading transactions (`TransactionLoader::Executor::Execute`) that is happening on opening tablet. Also fails for `SELECT ... FOR UPDATE`. It fails with the following error: 

`Expecting hybrid time with ValueType kHybridTime, found  `
