Title

Document IDs need to be URL decoded when indexed

Description
Here is a simple test to reproduce:

curl -XPUT '[URL] -d '
{ name: "Shay Banon" }
'

This should result in:
"_id":"ki mchy"

Instead, we end up with the literal text and not the url decoded form:
"_id":"ki%20mchy"
