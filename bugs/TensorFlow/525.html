- Triage Notes: The maximum value that float16 can represent is `65504`. The values in this example are large enough that it is a reasonable guess that overflow is occurring. This appears to be a testing only case to find numeric bounds, the box coordinates do not look like either typical absolute pixel coordinates in an image or [0,1] normalized coordinates. Using `float32` avoids this bug. While the `NonMaxSuppressionV3` currently does not support `bfloat16`, using `bfloat16` instead of `float16` might solve this problem.
