Title

no field content after PDAcroForm.refreshAppearances() call if BBox empty

Description
Calling  refreshAppearances()  for the attached file (which is an "improved" version of the file from the linked issue, I included a font in the acroform default resources) shows nothing. The reason is that all BBoxes of the text fields are empty. Adobe has no problem displaying the file, thus we should treat an empty BBox like a non existent BBox, see   PDFBOX-4615  .
