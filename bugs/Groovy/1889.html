Title

strange behavior with lists involving generics

Description
this works fine: 
  
 @groovy.transform.TypeChecked
def test() {
    List<GString> dates = [ "${ new  Date()-1}" ,  "${ new  Date()}" ,  "${ new  Date()+1}" ]
    List< String > upper = dates*.toUpperCase()
}
test()
 
  
 but this fails: 
  
 @groovy.transform.TypeChecked
def test() {
    List<GString> dates = [ "${ new  Date()-1}" ,  "${ new  Date()}" ,  "${ new  Date()+1}" ]
    List<GString> copied = []
    copied.addAll(dates)
    List< String > upper = copied*.toUpperCase()
}
test()
