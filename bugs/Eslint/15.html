Title

increment and decrement operators not recognized

Description
Even with no-plusplus: 0, the -- and ++ operators trigger a: "Expected an assignment or function call and instead saw an expression."
Discussion
- I think only prefix increments/decrements should be allowed in statement position. Postfix increments/decrements have more complex semantics, and their results should always be used.
- I disagree. When used in this manner, the result is functionally the same.
- Yes, they are functionally identical when used in statement position, but I was saying that it's a good practice to use prefix increment/decrement unless the more complex additional semantics of postfix increment/decrement are desired. In statement position, they're ignored, so this rule should point that out.
- That sounds like a separate rule to me.
