Title

qpid-client.properties not loaded by client

Description
The client is supposed to load a qpid-client.properties from the classpath.  It does this within a static initialiser block within the ClientProperties class.  However, since the remainder of class ClientProperties contains only final member variables these can be legitimately inlined at compile time into referring classes, therefore the static initialiser may never be called and the properties file never loaded.
