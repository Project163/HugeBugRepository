Discussion
- Thanks. This was a little broken.

Mitigating factors: the `vendor` directory is ignored by default (for over a year), so most people won't have noticed the discrepancy.

`hideExternalErrors` actually defaulted `true` in Config.php – the documentation was incorrect, but I've since fixed the `Config.php` default to `false`.

_Actually_ setting the default to `true` now works as expected (you don't have to explicitly ignore the `vendor` directory).
