Title

[bug] [v2] `npm run tauri migrate` grants incorrect permissions.

Description
### Describe the bug

I ran `npm run tauri migrate` and `npm run tauri dev`.

I got this error.

```sh
  Permission clipboard-manager:allow-read not found, expected one of ...(snip)... clipboard-manager:allow-clear, clipboard-manager:allow-read-image, clipboard-manager:allow-read-text, clipboard-manager:allow-write-html, clipboard-manager:allow-write-image, clipboard-manager:allow-write-text, clipboard-manager:deny-clear, clipboard-manager:deny-read-image, clipboard-manager:deny-read-text, clipboard-manager:deny-write-html, clipboard-manager:deny-write-image, clipboard-manager:deny-write-text, ...(snip)...
```

`migrate` subcommand is generate permission `clipboard-manager:allow-read` and `clipboard-manager:allow-write` but available permission is those.

- `clipboard-manager:allow-read-image`
- `clipboard-manager:allow-read-text`
- `clipboard-manager:allow-write-html`
- `clipboard-manager:allow-write-image`
- `clipboard-manager:allow-write-text`

Maybe we need fix this.

[URL]

### Reproduction

```sh
git clone [URL]
cd scab-player
npm i @tauri-apps/cli@next @tauri-apps/api@next
npm run tauri migrate
npm run tauri dev
```

### Expected behavior

This error should not occur.
