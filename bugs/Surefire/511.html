Title

Description
Preconditions: 
 There is a simple TestNG class with two methods so that 1st method has group "group" and 2nd has group "apigroup". 

   Steps to reproduce: 
 Run tests with command: 
  
 mvn clean test -Dgroups=group

Both tests are run. 

  h4.Expected:  
Only method with group "group" is run.
