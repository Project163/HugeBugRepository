Title

OSX resize issue

Description
**Issue:**

In /src/SFML/Window/OSX/SFViewController.mm, the SFOpenglView doesn't resize when it's parent view resizes.

**Possibe solution:**

Add the following at Line 75:

``` Objective-C
// Make the opengl view resize to parent view
[m_view setAutoresizesSubviews:YES];
[m_oglView setAutoresizingMask:NSViewWidthSizable | NSViewHeightSizable];
```
