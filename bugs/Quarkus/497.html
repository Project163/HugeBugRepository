Title

Unable to build Hibernate SessionFactory due NPE

Description
**Describe the bug**

Failed to start Quarkus:
Unable to build Hibernate SessionFactory due NPE  for a simple entity with a set(ter) method and a declaration level initialization of the member var.


    @OneToMany(fetch = FetchType.EAGER, cascade = CascadeType.ALL, orphanRemoval = true)
    @JoinColumn(name = "customer", unique = false, nullable = true)
    public Set  products = new HashSet<>();
    public void setProducts(Set  references) {
        this.products.clear();
        if (references == null || references.size() == 0) {
            return;
        } else {
            for (Product reference : references) {
                reference.customer = this;
                this.products.add(reference);
            }
        }

    }

Quarkus version is 1.3.0.CR2
