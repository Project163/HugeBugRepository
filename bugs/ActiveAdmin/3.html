Title

ActiveAdmin.default_sort_order "id_desc" prevents use of scopes with joins

Description
Hi,

I'm using a model with some scopes involving joins. For example:

```
class User   10 ORDER BY id desc
```

This appears to be because in [Link:  lib/active_admin.rb ] the default sort order is set to "id_desc", which doesn't then get scoped with the appropriate table name - hence the ambiguous query error.

There's a gist [Link: here] with the full stack trace in case it's useful...
