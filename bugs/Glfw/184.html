Title

IsWindows8Point1OrGreater fails on Windows 10

Description
Both `IsWindows8Point1OrGreater` and `IsWindows10OrGreater` fail on Windows 10. This is because Windows 10 deprecates `VerifyVersionInfo`.

[URL]

Among other things, this leads to per-monitor DPI not behaving correctly on Windows 10.
```
if (IsWindows8Point1OrGreater())
    SetProcessDpiAwareness(PROCESS_PER_MONITOR_DPI_AWARE);
else if (IsWindowsVistaOrGreater())
    SetProcessDPIAware();
```
This requires application to provide app manifest.
Internet suggests 2 solutions to this problem, if you want to avoid including app manifest:
1. Use `RtlGetVersion`
[URL]
2. Query version of `kernel32.dll` (this will not work well with compatibility options).

Now, while I could mess around with app manifest myself, GLFW tests and examples will still behave incorrectly.
