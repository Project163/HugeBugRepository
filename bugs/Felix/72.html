Title

Configuration Admin should not send a CM_UPDATED event after first registration of a ManagedService

Description
As per section 104.5.3 of the Configuration Admin Specification a CM_UPDATED event is created when a ManagedService is first registered. According to BJ Hargrave (see  [1] ) this is a bug and is now listed as an errata of the R4 Spec (see  [2] ). 

 Therefore, the ConfigurationManager sending the event must be fixed.
