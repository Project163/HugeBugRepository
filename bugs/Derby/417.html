Title

Resolve test failures with JCC2.8

Description
The following tests fail when run with JCC 2.8 driver: 

 derbynetmats/derbynetmats.fail:jdbcapi/resultset.java 
derbynetmats/derbynetmats.fail:jdbcapi/LOBTest.java 
derbynetmats/derbynetmats.fail:jdbcapi/parameterMapping.java 
derbynetmats/derbynetmats.fail:derbynet/testSecMec.java (fails with Sun JDKs only)
Discussion
- Attaching a patch 'jcc2.8_masters.diff' which adds master files for jcc 2.8. The new masters are needed to account for the differences in JCC 2.8 which allows getBytes on character types and does not default to IBMJCE driver for encryption. With this patch, I ran derbynetmats with JCC2.8 driver with Sun jdk 1.4. I also ran the four changed tests using JCC2.8 with IBM jdk1.4 and Sun jdk 1.5. 

 This patch only adds new masters. I would appreciate if someone can take a look at it and commit if okay.
- Committed to trunk with revision 399909.
- Verified tests pass with JCC 2.8 (46)
