Title

Remove all 2.x version constants from Version.java

Description
We should remove the 2.x version constants from Version.java since master (a.k.a. 6.0) does not need to know about those versions.
Discussion
- We might need to change re-index slightly to allow this change. 

The reindex from remote determines the version of the remote cluster and changes its behaviour based on whether `version  = 2.1.0` (e.g. [1]). It does this by parsing the string version from a call to `GET /` into an instance of `Version`[2]. 

Maybe we should have re-index (and maybe the REST client) use their own version of the `Version` class that does not store the Lucene version (since they shouldn't need it), so that the versions that they are compatible with can be independent of the versions which are compatible internally?
