Title

new types to StringType mapping is missing

Description
### Description

The doc claims it was added support for geospatial DB columns of type **linestring**, **polygon** and **geometry**.

The problem is that those column types are actually mapped somehow in the code BUT the respective classes are not present in folder `“src/Database/Type”`.

That means that a DB table, in which you have a GEOMETRY type field, worked fine in CakePHP 5.0.8 and now throws an error “unknown type “geometry” when marshaller is trying to build the respective type.

### CakePHP Version

5.1.1

### PHP Version

8.3.7
