Title

DB race condition causes cakephp to generate a query with WHERE 1 = 1

Description
I believe this is related to this issue.
[URL]
We just had this happen on a production issue and while I can't write a test to replicate it because it's a really fine timing issue. I have located the code where it happens.
This is for the 1.3 branch. Not sure if it affects the other branches but I took a quick peek at the 2.5 branch and it looks like it might also have this issue.
Assuming we're using dbo_mysql.

When calling a model save like this..
$this->Model->id = 65;
$this->Model->save($save_data);

What happens is that in the model.php, it first does a check to make sure that the record exists. So something like

```
SELECT COUNT(*) AS `count` FROM `models` AS `Model`   WHERE `Model`.`id` = 65 
```

If the record exists, it goes on to do an update, if it doesn't exist, it does an insert.
Assuming the record exists, we move on to the update section of the code.

When we do the update, the dbo_mysql does a check for default conditions which does another check to make sure the record exists. So it runs the previous query again. 

```
SELECT COUNT(*) AS `count` FROM `models` AS `Model`   WHERE `Model`.`id` = 65 
```

If the record is there, it's all good and we return back the correct condition which is 

```
WHERE `Model`.`id` = 65.
```

Here's the issue, if the record got deleted in between the two count statements, the default conditions will instead return 

```
WHERE 1 = 1
```

This causes all kinds of issues as you can imagine.
