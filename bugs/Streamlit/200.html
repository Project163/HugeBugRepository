- I was able to investigate this using your `streamlit-gh-action-test` repo and a Streamlit wheel with more detailed error messages. I believe the problem during the smoke test is because it tries to run each page independently as an app test. If you run `streamlit run pages/page_1.py` in that repo the same error will occur, because it sees `pages` as the main directory.

This doesn't seem like a bug with `AppTest` exactly, but we could potentially support switching pages in AppTest better so the smoke test could use that instead of the current approach.
