Title

Live split can lose data

Description
This issue is to investigate potential data loss during a "live" split (i.e. split happens while updates are flowing) 

 This was discovered during the shared storage work which was based on a non-release branch_8x sometime before 8.3, hence the first steps are to try and reproduce on the master branch without any shared storage changes.
Discussion
