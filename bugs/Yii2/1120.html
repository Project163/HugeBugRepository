Title

Improve MySQL/MariaDB master load balancing on error condition

Description
### What steps will reproduce the problem?

I think this has been brought up in #11306 already but it was not described clearly.

Setup:
- MySQL or MariaDB cluster with multiple masters
- or a single master with one or more slaves setup

Problem:
The connection may take too long to recover after a failure.

Current behavior of Yii is to cache the status of unavailable master servers. In case all masters are unavailable this is cached too and no attept is made to try connecting.

It will take `serverRetryInterval` seconds (which is default to 10min) to get a connection back.

During that time the exception message `None of the master DB servers is available.` is shown without any attempt to connect.

### What is the expected result?

When no master is available, Yii should ignore unavailable server cache and try to connect anyway, ideally updating the cache status marking a server as available again after successful connection.
