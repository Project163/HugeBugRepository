Title

Cache [Drive]: new subfolders are not detected

Description
### rclone version

```
rclone v1.40-082-gdc247d21β
- os/arch: linux/amd64
- go version: go1.10.1
```

### backend 

Drive -> cache -> crypt

### mount command

```
/usr/bin/rclone mount crypt-cache: /mnt/media \
   --allow-other \
   --allow-non-empty \
   --dir-cache-time=1m \
   --cache-db-purge \
... [Log Snipped] ...
   --rc \
   --log-level INFO
```

### How to recreate

This requires the cache remote be mounted on **two** hosts:

**on host 1**

`mkdir /mnt/media/111`
`touch /mnt/media/111/file.txt`

**on host 2** (after the 1 minute dir cache time)

`ls /mnt/media/111`

**result on host 2**
`ls: cannot access '/mnt/media/111': No such file or directory`

### Why this is a major problem

If any new folder is created within a folder that is already in the cache, rclone will not detect that folder. 

The impact is that if you're adding a new movie folder, new tv show, new tv show season, these will **never** be picked up by the 2nd host until the cache expires on its own. 

Yes you can manually evict the cache but that shouldn't be necessary. 

Needless to say this is a pretty serious bug. This should never happen.
