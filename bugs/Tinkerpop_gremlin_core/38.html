Title

Profile step and iterate do not play nicely with each other

Description
Profile step doesn't like it if there are any other steps after it. However if someone calls profile().iterate() they will get an error as iterate appends a NoneStep to the end of the traversal. 
Even though this means that the results of the profile would never be returned I think that profile step should allow None step to follow it.
