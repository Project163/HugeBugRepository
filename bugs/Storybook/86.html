Title

Failed to construct 'URL': Invalid URL [6.0.0-alpha.29]

Description
**Describe the bug**
After updating from`6.0.0-alpha.6` to `6.0.0-alpha.29` Storybook freezes with spinning loader and shows an error message.

```
TypeError: Failed to construct 'URL': Invalid URL
    at getEventSourceUrl (vendors~main. .bundle.js:9519)
    at PostmsgTransport.handleEvent (vendors~main. .bundle.js:9467)
```

**Expected behavior**
Storybook should load stories as usual.

**Screenshots**
  6.0.0-alpha.29 
    @storybook/source-loader: v6.0.0-alpha.29 => 6.0.0-alpha.29
```
Discussion
- After some debugging I've found the issue. It's related to the way `src` attribute is obtained from `iframe` and after altering the returned value `'iframe.html?id=*&viewMode=story'` to `[URL] Storybook started to work as normal.

#### Root problem

`var src = frame.getAttribute('src')` returns source but it's stripped from base url and that's why `new URL(src)` throws an error.

```js
var src = frame.getAttribute('src') // 'iframe.html?id=*&viewMode=story'
new URL(src) // TypeError: Failed to construct 'URL': Invalid URL
```

#### Possible solution:

A. switch from `frame.getAttribute('src')` to just `frame.src`
```js
var src = frame.src // '[URL]
```

B. pass additional base to URL constructor like `new URL(src, base)`
```js
var base = '[URL]
var src = frame.getAttribute('src') // 'iframe.html?id=*&viewMode=story'
new URL(src, base)
```
