Title

Zone.js cancelTask throws an error when trying to cancel a previously cancelled task

Description

Don't known / other

### Is this a regression?

### Description

We have code running a Knexjs migration which is wrapped in some code that we use Zonejs for tracing execution. It appears that by the time Zonejs tries to cancel a task, it is already in a `notScheduled` state. 

A similar circumstance was fixed awhile back in the context of `runTask`, see [URL]

It may be a simple fix to add a similar guard in `cancelTask` at [URL]
