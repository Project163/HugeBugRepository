Title

readme.html under frameworks does not mention about Derby client and some minor typos in example.html

Description
The readme.html file under frameworks mentions about the JCC driver but nothing about the Derbyclient. 

 Also under the demo/programs/simple/example.html some minor issues/typos: 

 Under the section 'Next run the SimpleApp demo in Derby client mode:'  step 5 on classpath mentions: 

 NOT FOUND IN CLASS PATH: 

     Derby Client libraries (db2jcc.jar) 
    (com.ibm.db2.jcc.DB2Driver not found.) 

 The above show JCC info instead of Derby Client
Discussion
