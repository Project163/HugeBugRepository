Title

Pig is returning too many blocks in the InputSplit

Description
When SlicerWrapper builds a slice, it currently returns the 3 locations for every block in the file it is slicing, instead of the 3 locations for the block covered by that slice.  This means Pig's odds of having its maps placed on nodes local to the data goes way down.
