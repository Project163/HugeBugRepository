Title

aiGetImporterDesc: wrong name mangling in libassimp.so [Linux]

Description
I expected the symbol name in libassimp.so to be "aiGetImporterDesc", but it is "_Z17aiGetImporterDescPKc".
All other symbol names are the same as their corresponding function names, this is the only exception.
This causes a symbol loading error.

This is the case in the current 5.0.1 Manjaro and ArchLinux packages.

You can see this from the output of the command

nm -D /usr/lib/libassimp.so | grep aiGetImporterDesc

Possible cause of the error:
All exported functions are declared with the ASSIMP_API prefix, and aiGetImporterDesc is the only function
that also uses the C_STRUCT macro on the return type, so I expect this macro to cause the error.
See code/Common/Assimp.cpp for this.
