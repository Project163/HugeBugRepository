Title

document --msg-template as replacement for deprecated --include-ids and --symbols

Description
Originally reported by: **Anonymous**

---

`--include-ids` and `--symbols` are deprecated since version 1.0.0. the documentation for version 1.2.0 in [URL] only says DEPRECATED. this does not help users upgrading from version 0.28 or older who are now puzzled what the old options did and what to use now instead.

the documentation should explain what the options did (at least one short sentence) and then point the user to the new `--msg-template` as a replacement.
