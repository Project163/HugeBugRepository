Title

UriInfo.resolve always returns null with resteasy-reactive

Description
### Describe the bug

After switching from RESTeasy Classic to the reactive counterpart, `UriInfo.resolve` does not work anymore and always returns `null`. `UriInfo.getBaseUri().resolve` still works, though.

### Expected behavior

`UriInfo.resolve` does not return `null`, similar to the behavior of RESTeasy classic.

### Actual behavior

`UriInfo.resolve` always returns `null`.
