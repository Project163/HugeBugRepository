Title

hbase-default.xml hbase.status.multicast.address.port does not match code

Description

 +  <property>
+    <name>hbase.status.multicast.address.port</name>
+    <value>6100</value>
+    <description>
+      Multicast port to use  for  the status publication by multicast.
+    </description>
+  </property>
