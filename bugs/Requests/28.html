Title

allow_redirects=True for one get affects the next one

Description
Here is an example with 3 similar `get` calls with all allow_redirects=False:

```
$> PYTHONPATH=$PWD python -c "import requests; url = '[URL] sess = requests.Session(); print sess.get(url, allow_redirects=False); print sess.get(url, allow_redirects=False); print sess.get(url, allow_redirects=False)"                                                                  
 
 
 
```

all of them logically 301.  If 2nd one says to allow redirects, then 3rd would also succeed even if I disallow redirects for that invocation

```
$> PYTHONPATH=$PWD python -c "import requests; url = '[URL] sess = requests.Session(); print sess.get(url, allow_redirects=False); print sess.get(url, allow_redirects=True); print sess.get(url, allow_redirects=False)"
 
 
 
```
