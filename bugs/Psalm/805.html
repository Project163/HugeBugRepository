Title

is_null($value) not treated same as null === $value

Description
It seems that `is_null($value)` is not being treated in the same way as `null === $value` when used in an assertion method. 

I would expect these methods to be treated the same by Psalm. 

```
function assertNotNull($value): void
{
  if (is_null($value)) throw new Exception();
}
```

and

```
function assertNotNull($value): void
{
  if (null === $value) throw new Exception();
}
```


It seems that Psalm understand them differently. Two code snippets are identical apart from line 15. 

Using [Link: is_null] the assertion method works. 

Using [Link: ===] the assertion does not work.
