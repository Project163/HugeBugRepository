DBFORGE error using reserved names

Description
I think this is an issue with the library and not personal support, so I'm writing here.
Execute:
`$this->dbforge->create_database("default")`
Result:

Reason:
`CREATE DATABASE default CHARACTER SET utf8 COLLATE utf8_unicode_ci` is not valid

Fix:
`CREATE DATABASE `default` CHARACTER SET utf8 COLLATE utf8_unicode_ci`
