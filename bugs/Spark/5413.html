Title

Duplicated secret volumes in Spark pods when init-containers are used

Description
User-specified secrets are mounted into both the main container and init-container (when it is used) in a Spark driver/executor pod, using the  MountSecretsBootstrap . Because  MountSecretsBootstrap  always adds the secret volumes to the pod, the same secret volumes get added twice, one when mounting the secrets to the main container, and the other when mounting the secrets to the init-container.
