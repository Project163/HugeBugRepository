Title

`TEMPLATE_TEST_CASE_SIG` multiple `typename` parameters in a row

Description
Why is it not possible to declare `TEMPLATE_TEST_CASE_SIG` with two `typename` parameters, as presented in the example below?
```cpp
TEMPLATE_TEST_CASE_SIG("TemplateTestSig: arrays can be created from NTTP arguments", "[vector][template][nttp]",
    ((typename T, typename V), T, V), (int, double))
{
}
```
The error follows:
```
error: call of overloaded 'get_wrapper ()' is ambiguous
159 | TEMPLATE_TEST_CASE_SIG("TemplateTestSig: arrays can be created from NTTP arguments", "[vector][template][nttp]",
       | ^~~~~~~~~~~~~~~~~~~~~~
```
Discussion
- I believe this is a catch2 bug.

With a trivial example:
```CPP
TEMPLATE_TEST_CASE_SIG("min","[]",((typename T1), T1),( int ))
{
}
```

These two lines from `INTERNAL_CATCH_TEMPLATE_PRODUCT_TEST_CASE2` create functions that only differ by return type.
```CPP
        namespace INTERNAL_CATCH_MAKE_NAMESPACE(TestName) {                                     \
            INTERNAL_CATCH_TYPE_GEN                                                  \
            INTERNAL_CATCH_NTTP_GEN(INTERNAL_CATCH_REMOVE_PARENS(Signature))         \
```
So, this is called like this:
```CPP
INTERNAL_CATCH_NTTP_GEN(INTERNAL_CATCH_REMOVE_PARENS(Signature))
```
With the trivial example it ends up:
```CPP
INTERNAL_CATCH_NTTP_GEN((typename T1), T1)
```
Which ends up:
```CPP
#define INTERNAL_CATCH_NTTP_1(signature, ...)\ 
    // with (signature == typename T1) VA_ARGS == T1
    template  struct Nttp{};\
    template \
    constexpr auto get_wrapper() noexcept -> Nttp  { return {}; } \
```
Then:
```CPP
template  struct Nttp{};
template 
//       ^^^^^^^^^^^ THE CAUSE OF YOUR ISSUE.
constexpr auto get_wrapper() noexcept -> Nttp  { return {}; }
```
