Title

FromElements ignores returns()

Description
StreamExEnv#fromElements eagerly serializes data with the automatically determined serializer. This can result in errors for example when generic avro records are used, because it will default to Kryo. 

 Subsequent calls to returns() have no effect because the typeinformation is never forwarded to the function. 

 Annoyingly the fact that it serializes data isn't logged anywhere. and there doesn't seem to be a way to change the serializer except by using fromCollection() instead.
Discussion
- I think implementing  OutputTypeConfigurable  for  FromElementsFunction  could solve this.  AbstractUdfStreamOperator  will redirect  OutputTypeConfigurable  to user defined function. Here is my proposed steps: 
 
	 Store a  transient   elements  field for original elements. 
	 Keep eagerly serialization but re-serialize if serializer from  setOutputType  differs from existing one.
