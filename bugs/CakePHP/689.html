Title

Inconsistent accessibility of _joinData

Description
I'm using `_joinData` to save some data along with relations. When creating a new item, a new record is created in the join table and the join data is saved correctly as well. When updating an item, I'm able to update the join data for existing relations as well. But when creating new relations for an existing item, the relation is created with no join data.

I checked the entity in the `beforeSave` all situations, and the problem seems to be the accessibility of `_joinData`. It's accessible when:
- Adding new relation to new item
- Updating relation to existing item

But not when:
- Adding a new relation to an existing item

It can be solved by marking `_joinData` as accessible. But it could be something to look at, since it's fairly inconsistent in my opinion.
