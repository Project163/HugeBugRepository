Title

NPE in StreamTransferTask.createMessageForRetry

Description
seeing this NPE during repair: 
at org.apache.cassandra.streaming.StreamTransferTask.createMessageForRetry(StreamTransferTask.java:106) 
at org.apache.cassandra.streaming.StreamSession.retry(StreamSession.java:525) 
at org.apache.cassandra.streaming.StreamSession.messageReceived(StreamSession.java:401) 
at org.apache.cassandra.streaming.ConnectionHandler$IncomingMessageHandler.run(ConnectionHandler.java:289) 
at java.lang.Thread.run(Thread.java:744)
Discussion
- We don't protect against a timeout task having timed out, completion being in-process, or timeoutExecutor being in a shutdown state / shutting down from complete / abort during the window we get this RETRY message. 

   StreamTransferTask.createMessageForRetry   
  // remove previous time out task to be rescheduled later
 ScheduledFuture  future  = timeoutTasks.get(sequenceNumber);
 future .cancel( false );
 return  files.get(sequenceNumber);
- v1 attached - synchronize to prevent null file return, check against future existing before attempting to cancel to prevent NPE.
