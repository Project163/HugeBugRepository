Title

Formatter invalid to integer

Description
When i configure: 

``` php
'formatter' => [          
    'numberFormatterOptions' => [
        NumberFormatter::MIN_FRACTION_DIGITS => 2,
    ]
],
```

than

``` php
 formatter->asInteger(1); ?> //results in 1,00 instead of 1
```
Discussion
- With intl enabled? Isn't this a bug of ICU then?
- I think not. 
I believe that as the framework use: 

[URL]

``` php
$f = $this->createNumberFormatter(NumberFormatter::DECIMAL, null, $options, $textOptions);`
```

this function set the attributes: 

[URL]

``` php
foreach ($this->numberFormatterOptions as $name => $value) {
    $formatter->setAttribute($name, $value);
}
```

But, in case of integer this not is valid
- The next line specifies `NumberFormatter::TYPE_INT64` so the result has to be an integer. Need further investigation on this...
