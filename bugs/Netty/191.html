Title

IndexOutOfBoundsException in DefaultCompositeByteBuf.removeComponents

Description
FYI

When I remove all components from a DefaultCompositeByeBuf, I've got an IndexOutOfBoundsException exception (tested with 4.0 CR5);

Sample code:
            int nbChunck = completedMsg.numComponents();
            completedMsg.removeComponents(0,nbChunck);

Dump stack:

10:05:23.250 [nioEventLoopGroup-2-1] WARN  i.n.util.concurrent.DefaultPromise - An exception was thrown by org.msrpenabler.server.net.TransactionHandler$7.operationComplete()
java.lang.IndexOutOfBoundsException: Index: 0, Size: 0
    at java.util.ArrayList.rangeCheck(ArrayList.java:604) ~[na:1.7.0_21]
    at java.util.ArrayList.get(ArrayList.java:382) ~[na:1.7.0_21]
    at io.netty.buffer.DefaultCompositeByteBuf.updateComponentOffsets(DefaultCompositeByteBuf.java:281) ~[netty-all-4.0.0.CR5.jar:na]
    at io.netty.buffer.DefaultCompositeByteBuf.removeComponents(DefaultCompositeByteBuf.java:314) ~[netty-all-4.0.0.CR5.jar:na]

It seems that DefaultCompositeByteBuf.updateComponentOffsets doesn't test if array is empty.
