Title

Improve the accuracy of MutableStat mean

Description
The current MutableStat mean calculation method is more prone to loss accuracy because the sum of samples is too large.  
Storing large integers in the double type results in a loss of accuracy. For example,   and   are both stored as doubles as  . Therefore, we should try to avoid using the cumulative total sum method to calculate the average, but update the average every time we sample. All in all, we can process each sample on its own to improve mean accuracy.
