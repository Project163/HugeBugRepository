Title

Remove Windows-specific code

Description
I know a lot of work has gone initially into supporting UT, runtime, etc on Windows, but this code seems to have been rotting.  

 There have been no updates to the windows specific test files, or any new code to keep the new features compatible. 

 We're also not running the tests or builds on windows. That is really an impediment to keepting that code healthy. 

 The code is sprinkled all over the codebase. Makes it hard to maintain. I think we're better off removing it.
