Title

quantile throws error if not convertible to float

Description
If we try and `quantile` a DataFrame with string entries which are not convertible, there is a ValueError. Should this behave like mean (and ignore these entries)? (taken from [Link: this StackOverflow question]).

```
In [1]: df = DataFrame({'col1':['A','A','B','B'], 'col2':[1,2,3,4]})

In [2]: df
Out[2]:
  col1  col2
... [Log Snipped] ...

ValueError: ('could not convert string to float: A', u'occurred at index col1')
```
Discussion
- Agreed. This should select only the numeric data and compute the quantiles on that
