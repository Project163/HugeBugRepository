Title

Getting "Missing semicolon" when using a for-of loop

Description
Hi,
The following code:

```
'use strict';

let definition = {};
let store = {};

for (let prop of definition) {
  store[prop] = prop;
}
```

Produces the error "Missing semicolon (semi)".

My guess by looking at the semi-rule is that it needs to check for `ForOfStatement` and not just `ForStatement` and `ForInStatement`.

I'm using version 0.14.1.

My .eslintrc contains this:

```
{
  "ecmaFeatures": {
    "blockBindings": true,
    "forOf": true,
    "jsx": true,
... [Log Snipped] ...
  }
}
```
Discussion
- Just to cover our bases, can you paste the full error message in? I'd like to see the line and column numbers.
- I'm not on the computer where I have it all set up, so I can't give it to
you right now. But I did manage to resolve it by modifying the semi rule to
make a check for "ForOfStatement" in the same way it does with
"ForInStatement", which made the reported error go away.
