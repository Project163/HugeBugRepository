Title

'one-var' doesn't respect 'separateRequires' option with 'always' or 'consecutive'

Description
**Tell us about your environment**

* **ESLint Version:** 4.19.1
* **Node Version:** 8.11.1
* **npm Version:** 5.8.0

**What parser (default, Babel-ESLint, etc.) are you using?**
default

**Please show your full configuration:**

 
 Configuration 

 
```
js
module.exports = {
	'root': true,
	'extends': [],
	'parserOptions': {
... [Log Snipped] ...
	}
};
```

 

**What did you do? Please include the actual source code causing the issue, as well as the command that you used to run ESLint.**
Took code from [URL] under the `separateRequires` block.
 
```js
var foo = require('foo');
var bar = 'bar';

var foo = require('foo'),
	bar = require('bar');
```

 
Ran through Webstorm, which I presume just runs the configured package (which is the correct path) against the current file.

**What did you expect to happen?**
No errors are flagged.

**What actually happened? Please include the actual, raw output from ESLint.**
2 errors are flagged: The first `bar` variable wants to be joined with the first `foo`. The second foo/bar block wants to be joined with the first block. Interestingly if you make the `consecutive` option an `always`, the first error goes away.
Discussion
- Even paring it down further to just the following, it still doesn't seem to validate for the "correct" example.

**.eslintrc.js**
```js
module.exports = {
	'root': true,
	'extends': [],
	'rules': {
		'one-var': [2, { separateRequires: true, var: "always" }],
	}
};
```

**eslint.js**
```js
var foo = require('foo');
var bar = 'bar';

var foo = require('foo'),
	bar = require('bar');
```
