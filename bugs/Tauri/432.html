Title

[bug] [macOS] Tauri drag handler should wait for mouse up after double-click-to-maximize

Description
### Describe the bug

After a drag area (titlebar) is double clicked on macOS, Tauri does not wait for the user to release their mouse before maximizing.

[URL]


### Reproduction

With Tailwind:
```html
  
```

### Expected behavior

After double clicking, maximization is delayed until the mouse button is released. If the mouse button is moved before being released, the maximization is aborted.
