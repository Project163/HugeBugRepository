Title

inconsistent error message for file names with/without spaces

Description
Non-existent script files containing " " (space) character in the name are handled differently from non-existent files without spaces. :man_shrugging: This is easier to understand by looking at the screenshot.

[Image: 2021-04-16_13-31]

Script files with spaces that exist work as expected. 

## Environment
 
- k6 version: `k6 v0.31.1 (2021-03-17T13:23:23+0000/e9d8349, go1.15.8, linux/amd64)`
- OS and version: Linux / debian testing (5.10.0-3-amd64)

## Expected Behavior
I expected the same error message to be printed in both cases.

## Actual Behavior
See screenshot above.


## Steps to Reproduce the Problem
`k6 run file\ that\ doesnt\ exist\ and\ has\ spaces.js`
