Title

RSS sync silently ignores feed entries with long titles (I think)

Description
**Describe the bug**

I have noticed that some of my posts to our (OpenNMS's) blog don't show up in my dashboard as draft posts.  Up until now I've just ignored it and let an entry go missing here or there.  Today I tried adding the entry manually, and found that it wouldn't let me save because my title was too long.

I suspect these entries are getting missed because the title is too long so it can't get auto-saved into my dashboard.

**To Reproduce**

1. Create an RSS feed with an entry with a very long title.
2. refresh RSS

**Expected behavior**

All RSS feed entries get draft posts.

**Desktop (please complete the following information):**

- OS, version: Mac OS X Catalina
- Browser, version: Firefox 89

**Additional context**

Our RSS feed is [URL]

The June 7th entry _("OpenNMS On the Horizon - Documentation, Flows and Nephron, Docker Container Trust, Thresholding, Metadata, Time-Series API, Minion Health Checks")_ did not auto-import.
Discussion
- Hi @RangerRick, I can confirm this is happening, and for the reason you suspected.

When I fetched the rss feed, it contained 10 items. I only saw 7 articles created from those 10 entries, items with title lengths of up to 122 were permitted/created and entries with title lengths of 132, 143, and 144 were omitted/skipped.

## Technical investigation (skip ahead if not interested)

[Link: Feeds::Import] handles errors in article creation by logging 

`result` here is the set of articles successfully created, `entries` is the parsed xml from the rss feed (I think there's some reverse chronological sorting between the two, one reads right to left and the other left to right, that's unimportant):

```ruby
[38] pry(  ):2> result.map { |a| a.title.size }
=> [122, 114, 22, 90, 96, 114, 87]                           
[39] pry(  ):2> entries.map {|e| e.title.size }
=> [144, 87, 114, 96, 143, 90, 22, 114, 122, 132]     
```

Checking the logs after I called `create_articles_from_user_feed`, I see the error message is as you suspected  (article title is too long):

```
feeds::import::error::ActiveRecord::RecordInvalid::{:feeds_import_info=>{:username=>"admin_mcadmin", :feed_url=>"[URL] :item_count=>10, :error=>"Feeds::Import::CreateArticleError:[URL] :error_message=>"Validation failed: Title is too long (maximum is 128 characters)"}
```

There's a validation in the article code to ensure title is kept 128 characters or less.
