**Current behavior**
i18n attributes using the syntax `i18n- ="@@ "` are correctly extracted, but not translated.

**Expected behavior**
The attributes should be translated

I have the following template:

```
 Welcome to Ponyracer {{ user.firstName }} {{ user.lastName }}! 
 
```

Using Angular CLI, I extract the messages file using `ng xi18n --output-path src/locale`:

```

```
