Title

EVENT_BEFORE_ACTION does not handle Exceptions

Description
I have a bootstrap-class, which triggers on `Application::EVENT_BEFORE_ACTION` and throws `NotFoundHttpException`.

``` php
public function bootstrap($app)
{
    $app->on(Application::EVENT_BEFORE_ACTION, [$this, 'initLanguage']);
}
```

The problem is, that it does not show the normal 404 error page.

If I change the trigger event to `Application::EVENT_BEFORE_REQUEST` it shows the normal error page.
Discussion
- This is expected as "normal 404 error page" is rendered by controller action, which also trigger the same event and throws the same exception.
