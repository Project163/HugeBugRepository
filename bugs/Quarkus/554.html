Title

Liquibase in dev mode detects duplicate changeLog file

Description
**Describe the bug**
During startup of quarkus dev mode, Liquibase tries to parse the configured (yaml) file containing the changeLog, this fails due to 2 such files being found in the classpath.  This error does not occur in normal mode (running the runner jar).

**Expected behavior**
Liquibase only finds one changeLog file and parses it.

**Actual behavior**
The following exception is thrown, blocking further startup
```
2020-04-05 19:09:25,554 ERROR [io.qua.application] (main) Failed to start application: java.lang.IllegalStateException: liquibase.exception.ChangeLogParseException: Error parsing db/changeLog.yaml
        at io.quarkus.liquibase.runtime.LiquibaseRecorder.doStartActions(LiquibaseRecorder.java:75)
        at io.quarkus.deployment.steps.LiquibaseProcessor$configureRuntimeProperties41.deploy_0(LiquibaseProcessor$configureRuntimeProperties41.zig:98)
        at io.quarkus.deployment.steps.LiquibaseProcessor$configureRuntimeProperties41.deploy(LiquibaseProcessor$configureRuntimeProperties41.zig:36)
        at io.quarkus.runner.ApplicationImpl.doStart(ApplicationImpl.zig:231)
... [Log Snipped] ...
        at liquibase.parser.core.yaml.YamlChangeLogParser.parse(YamlChangeLogParser.java:26)
        ... 20 more
```

**To Reproduce**
Steps to reproduce the behavior:
1. Add the liquibase extension to your Quarkus project
2. Add a changeLog file to your resources
3. Startup in dev mode

**Configuration**
Relevant properties are:
```yaml
quarkus:
  liquibase:
    change-log: db/changeLog.yaml
    migrate-at-start: true
    validate-on-migrate: true
```
The change log file is custom, but it seems to be failing when I convert to db/changeLog.xml (the default) as well.
