Title

NUnit3's nunit2-compatible XML is different for [Explicit] tests

Description
Using the following test case:

```
using NUnit.Framework;

namespace NUnitSkippedTests
{
    class Program
... [Log Snipped] ...
    }
}
```

When compiled against NUnit2 and run with NUnit2's `nunit-console`, the XML output resembles the following:

```
 
 
 
   
   
... [Log Snipped] ...
   
 
```

Note that the test marked with `[Explicit]` does not appear in the output at all, only the test marked with `[Ignore`].

When compiled against NUnit 3 and run with NUnit 3's `nunit-3-console` with as follows:

```
"C:\Program Files (x86)\NUnit.org\nunit-console\nunit3-console.exe" C:\temp\NUnitSkippedTests\NUnitSkippedTests\bin\Debug\NUnitSkippedTests.exe --inprocess --result=skipped3.xml;format=nunit2
```

The XML output resembles the following:

```
 
 
 
   " clr-version="4.0.30319.42000" os-version="Microsoft Windows NT 10.0.10240.0" platform="Win32NT" cwd="C:\Temp\nunit3" machine-name="REDACTED" user="REDACTED" user-domain="REDACTED" />
   
... [Log Snipped] ...
   
 
```

There are three deviations here which do not remain 100% compatible with Nunit 2:
1. The `[Explciit]` test now appears
2. The `[Explicit]` test is given a `result` of `Ignored`, whereas the `[Ignore]`'d test is given a result of `Skipped`.
3. The `Skipped` value seem to be new to NUnit 3 - my code for handling NUnit 2 output never saw this value on NUnit 2.
Discussion
- Congratulations on being the first to notice this stuff. So much for betas. :-{
1. This is an intentional change. It remains true to the format but obviously it is a semantic difference. I don't think it should hurt anything, provided we fix #2.
2. These are both errors. The Explicit item should be Skipped, while the Ignored item should be Ignored.
3. Skipped is not new. It's used for tests skipped in a way that has penalty for the overall result. Examples are tests skipped due to a PlatformAttribute or a CultureAttribute.
- I wish I could have tried the betas earlier but it's been challenging converting a large codebase from NUnit 2 to NUnit 3.

1: Makes sense.

3: Interesting - I've never used those, so that would explain why I've never seen `Skipped` before.
