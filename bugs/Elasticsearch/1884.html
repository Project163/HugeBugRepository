Title

_update_by_query's default size accidentally changed to 1000

Description
**Describe the feature**:  `scroll_size` seems to be ignored in my request

 

**Elasticsearch version** (`bin/elasticsearch --version`):  6.0.0-beta2

**Plugins installed**: []

**JVM version** (`java -version`): JDK 8

**OS version** (`uname -a` if on a Unix-like system): Ubuntu

**Description of the problem including expected versus actual behavior**:

**Steps to reproduce**:

No matter what value I set for `scroll_size`, the following request only updates 1,000 documents:
