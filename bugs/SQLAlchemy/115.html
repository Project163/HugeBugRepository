Title

Event removal not working

Description
**Migrated issue, originally created by Konsta Vesterinen ([Link: @kvesteri])**

Very simple test scenario:

```
import sqlalchemy as sa

@sa.event.listens_for(sa.orm.mapper, 'instrument_class')
def my_listener(mapper, cls):
... [Log Snipped] ...
    sa.orm.mapper, 'instrument_class', my_listener
)
```

This throws a ValueError:

```
def remove(self, event_key):
        target = event_key.dispatch_target
        stack = [target]
        while stack:
            cls = stack.pop(0)
... [Log Snipped] ...
E               ValueError: list.remove(x): x not in list
```

Maybe the `event_key.fn` should be `event_key.fn_wrap` instead?
Discussion
- **Michael Bayer ([Link: @zzzeek]) wrote:**

- Fixed bug where events set to listen at the class
level (e.g. on the :class:`.Mapper` or :class:`.ClassManager`
level, as opposed to on an individual mapped class, and also on
:class:`.Connection`) that also made use of internal argument conversion
(which is most within those categories) would fail to be removable.
