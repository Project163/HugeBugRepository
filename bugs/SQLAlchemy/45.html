Title

Bug in firebird.FBDialect.reflecttable()

Description
**Migrated issue, originally created by Anonymous**

A reflection of my database fails in reflecttable() at `row[Link: 'fdefault'].startswith('DEFAULT ')` because the value is "Default 0", not "DEFAULT 0". The small patch fixes the assertion and increases debugging.

                 if row[Link: 'fdefault'] is not None:
                     # the value comes down as "DEFAULT 'value'"
    -                assert row[Link: 'fdefault'].startswith('DEFAULT ')
    +                assert row[Link: 'fdefault'].upper().startswith('DEFAULT '), row
                     defvalue = row[Link: 'fdefault'][Link: 8:]
