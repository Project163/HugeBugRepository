With that said, Plotly v4 changed its main package and is accessed differently than in v3.

With v4

```import chart_studio.plotly as ply```

With v3

```import plotly.plotly as ply```

Please verify the version you're using and access the Plotly object accordingly. Streamlit apps should work with both versions.

Check version
```
import plotly
plotly.__version__
```

To install v4
```
pip install chart-studio
pip install plotly==4
```

To install v3
```
pip install plotly==3
```

Also, looks like you're on version `0.45.0` of Streamlit, feel free to update to `0.46.0` with `pip install --upgrade streamlit` if there's no blockers on your end.

Let us know if you're still having issues afterwards.
