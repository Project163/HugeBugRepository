Title

Description
Created by **alexsmonte**, 14th Feb 2011. _(originally [Link: Lighthouse ticket #1536])_:

---

dbo_oracle where in the connection string is used $ config ['database'] to change $ config ['host'].

Thus:
$ this-> connection = @ oci_connect ($ config ['login'], $ config ['password'], $ config ['database'], $ config ['charset']);
should look like
$ this-> connection = @ oci_connect ($ config ['login'], $ config ['password'], $ config ['host'], $ config ['charset']);
