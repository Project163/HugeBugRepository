Title

Allow assertrepr_compare hook to apply only to a subset of tests

Description
Originally reported by: **Jason R. Coombs (BitBucket: [Link: jaraco], GitHub: [Link: jaraco])**

---

Currently, if one defines `pytest_assertrepr_compare` and it is found on test discovery, it is applied to the entire test suite.

I want the hook to apply to only a subset of tests (`tests/unit/**`), so I defined `tests/unit/conftest.py` and defined my `pytest_assertrepr_compare` there, but still tests under `tests/other/**` get that behavior (when I run py.test on `tests/`).

pytest should configure the hook such that it is only loaded for `tests/unit/**`.
