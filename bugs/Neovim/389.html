charidx fails at the last character of the line

Description

NVIM v0.5.0 Build type: RelWithDebInfo LuaJIT 2.1.0-beta3

### Operating system/version:

Arch Linux 5.10.55-1-lts x86_64

### Terminal name/version:

rxvt-unicode (urxvt) v9.26 - released: 2021-05-14 (From pacman Arch Linux)

### Installation

appimage (https://github.com/neovim/neovim/releases/download/v0.5.0/nvim.appimage)

### Steps to reproduce

`		let l:cc = charidx(getline('.'), col('.'))`
Note the cursor position.
Go to command-line mode.
type:
`:echo charidx(getline('.'), col('.'))`
Should give -1 as shown in the image below.

However if I type:
`:echo col('.')`

I think I should get 44 here. But charidx don't give 44. :(

I expect to get 44 not -1
