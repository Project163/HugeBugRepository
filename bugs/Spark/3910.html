Title

Infinite recursion loop in org.apache.spark.sql.catalyst.trees.TreeNode when table name collides.

Description
How to reproduce:  

 In spark-sql on Hive 

  
 DROP TABLE IF EXISTS t1 ;
CREATE TABLE test.t1(col1 string) ;

WITH t1 AS (
  SELECT  col1
  FROM t1 
)
SELECT col1
FROM t1
LIMIT 2
;
