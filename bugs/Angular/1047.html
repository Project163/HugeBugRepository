Title

[IVY]: Fail to get `componentFactoryResolver` from a child NgModuleRef

Description
# 🐞 bug report

### Affected Package
The issue is caused by package @angular/core

### Is this a regression?

Worked in 8 and below

### Description

When trying to access `componentFactoryResolver` on an instance of `NgModuleRef` that
is not the root module there is an exception thrown:

 
 TypeError: Cannot read property 'get' of undefined 
 
   at NgModuleRef$1.get (core.umd.js:24253)
    at NgModuleRef$1.get [as componentFactoryResolver] (core.umd.js:24257)
    at new FeatModule (feat-module.ts:8)
    at Object.FeatModule_Factory [as factory] (feat-module.ts:12)
    at R3Injector.hydrate (core.umd.js:11505)
    at R3Injector.get (core.umd.js:11328)
    at eval (core.umd.js:11268)
    at Set.forEach ( )
    at new R3Injector (core.umd.js:11268)
    at createInjector (core.umd.js:11233)
 
 

The issue is that there is no value in the `_r3Injector` property... it exists only in the root module.

Discussion
- FYI, unless `_r3Injector` exist, the component factory resolver is useless because it will pass the module ref (that is missing the R3Injector) into the component factory which will then fail when creating the component and it's child components because the injector is missing.

I've managed to workaround this with an ugly hack:

```ts
    try {
      if (ngRef.componentFactoryResolver) {
      }
    } catch (err) {
      const parent = (ngRef as any)._parent;
      (ngRef as any)._r3Injector = parent;
    }
```

With this, i'm assuming that the parent is indeed an `R3Injector` instance because this is the case for me right now, in other cases a more clever approach might br requried.

Also, if found that some modules get a module ref from `NgModuleRef$1` which does assign an `R3Injector` and some are not, couldn't figure out why and what is the module ref class used for them. They do have the same `NgModuleRef$1` constructor but it is not used (in the ngcc transformed code). I guess it is manually constructed somehow.
