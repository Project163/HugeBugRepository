Title

.contains fails with "chained" association proxies in 1.2

Description
**Migrated issue, originally created by Jeff Dairiki ([Link: @dairiki])**

The attached script fails with `sqlalchemy.exc.InvalidRequestError`: `contains() doesn't apply to a scalar endpoint; use ==` in SQLAlchemy==1.2.  It works with SQLAlchemy==1.1.15 (and before).

The crux here is:

```
Team.events = association_proxy('eventteams', 'event')
```

where the proxied attribute is itself an association proxy:

```
EventTeam.event = association_proxy('division', 'event')
```

In this case the expression `Team.events.contains(some_event)` is what elicits the exception.
