Title

Resizing window repositions it on MacOS

Description
If we resize a window on MacOS using `glfwSetWindowSize()` - window visually move down. Bottom of the window remains stationary. This is because MacOS positions windows from the bottom-left corner while glfw positions windows from the top-left corner. A workaround to this issue is to move window upwards by the difference of current and new window size. glfw does not do that when window is resized.

Here is workaround code:
```
cpp
static void ImGui_ImplGlfw_SetWindowSize(ImGuiViewport* viewport, ImVec2 size)
{
    ImGuiViewportDataGlfw* data = (ImGuiViewportDataGlfw*)viewport->PlatformUserData;
#if __APPLE__

}
```
