Title

Spark UI Should Not Try to Bind to SPARK_PUBLIC_DNS

Description
Right now the Spark UI will try to bind to the SPARK_PUBLIC_DNS. This is not correct - the SPARK_PUBLIC_DNS name denotes how Spark components should advertise to other services/components, not the actual bind address.
