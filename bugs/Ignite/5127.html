Title

C++ thin and ODBC: SSL keystore shouldn't be a mandatory parameter

Description
Currently, SSL in C++ thin client and ODBC can't be configured without specifying client-side certificates. This shouldn't be the case - SSL can be used without any corticates or custom trust stores on the client. 

 Need to add a way to do this out of the box.
