Title

The API method KafkaStreams#cleanUp() is not applicable when use @Produces to build the topology

Description
### Describe the bug

To delete the Kafka streams application’s local state directory on any machines where the Kafka streams application instance was run. You must do this before restarting an application instance on the same machine. 

You can use this method:The API method KafkaStreams#cleanUp() in your application code.

The is issue is that the clean up process is not applicable when we use @Produces to build the topology as below:

`@Produces
    public Topology buildTopology() {
        StreamsBuilder builder = new StreamsBuilder();
 return builder.build();
    }`

The Kafka streams is created by quarkus internally and there is no any control to clean up the streams before start up.

Kafka reference: [Link]


### Expected behavior

Have a separate function that can clean up the streams before start.

### Actual behavior

there is no way to clean up the kafka streams
