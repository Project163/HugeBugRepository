Title

Reactive REST client does not encode request path properly

Description
### Describe the bug

If I create a REST client using _quarkus-rest-client-reactive_ spaces in the request path (and other special characters) are not encoded correctly when the final HTTP request is built:

```
javax.ws.rs.client.ClientBuilder.newClient().target("[URL] space").request().get()
javax.ws.rs.client.ClientBuilder.newClient().target("[URL]
```

In both cases the HTTP request contains `GET /with space HTTP/1.1` when it should be `GET /with%20space HTTP/1.1`.
This problem does not exist in the classic RESTEasy client.

### Expected behavior

Paths for HTTP requests should be encoded correctly.

### Actual behavior

Special characters are not encoded for the HTTP request.

### How to Reproduce?

Run `quarkus.bugs.RequestUriNotEncoded` from [URL]
