Title

Qute: generation of qute-i18n-examples doesn't handle localized enums

Description
### Describe the bug

When I have message accepting a single enum parameter as part of my message bundle, a maven quarkus application fails while doing `mvn install` with the following message 

    Cannot invoke "org.jboss.jandex.MethodInfo.name()" because the return value of "io.quarkus.qute.deployment.MessageBundleMethodBuildItem.getMethod()" is null.

This is probably because `MessageBundleProcessor#generateExamplePropertiesFiles()` is trying to generate example properties keys by using the build item method names, and build items generated by `generateEnumConstantMessageMethod()` creates build items without methods.

### Expected behavior

Message bundle processor correctly generates example properties file even when auto-generated message keys for enums are present.

### Actual behavior

Message bundle processor crashes when encountering auto-generated enum messages.

### How to Reproduce?

Create a qute project with the following files:
`FooMessages.java`
```java
@MessageBundle("foo")
public interface FooMessages {
    @Message
    String enum_message(MyEnum period);
}
``` 

`MyEnum.java`

```java
public enum MyEnum {
    A,
}
``` 

`/resources/messages/foo_en_US.properties`

```
enum_message_A=A
```

Run `mvn install` to build and package. Crashes with the above mentioned error message.
