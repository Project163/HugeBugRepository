Title

Support for jsdoc comments in spaced-comment rule

Description
The common usage for jsdoc is to start it with `/**`, here is an example:

```
/**
 * Window
 */
export default class Window extends eventEmitter { 
```

Result for lint with `"spaced-comment": 2`:

```
1:0  error  Expected space or tab after /* in comment  spaced-comment
```

It will be great no to trigger the error in this case. /cc @gyandeeps
