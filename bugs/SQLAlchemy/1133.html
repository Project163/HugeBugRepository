Title

Strange insert statement

Description
**Describe the bug**
I'm trying to insert multiple values into a table, but SQLAlchemy generates a strange SQL statement:
```sql
INSERT INTO foo (id) VALUES (nextval('foo_id_seq')), (%(id_m1)s), (%(id_m2)s)
```
in the log I see prefetch queries:
```sql
select nextval('foo_id_seq')                                                          
select nextval('foo_id_seq')
```
the question is why it prefetches nexval only for 2nd and 3rd values and 1st uses inline?

The result of this query affects the id order that Postgres generates for rows. The first row will have a larger id than the second.

**Expected behavior**
SQLAlchemy should prefetch all values or it should use inline for each value.

**To Reproduce**
Run insert query with multiple values
```py
insert_query = insert(foo_table).values(foo_dicts).returning(literal_column("*"))
objects = conn.execute(insert_query).fetchall()
```

**Versions.**
 - OS: linux
 - Python: 3.8
 - SQLAlchemy: 1.3
 - Database: postgresql
 - DBAPI: postgresql+psycopg2
