Title

PIL does not pack 2-bit palette images correctly

Description
```Python
from PIL import Image

rgb = '\x00' * 2 + '\x01' * 2 + '\x02' * 2
img = Image.frombytes('P', (6, 1), rgb)
img.putpalette('\xFF\x00\x00' '\x00\xFF\x00' '\x00\x00\xFF') # RGB
img.save('file.png')
```
Expected is an image with 6 pixels: `RRGGBB`. Instead it makes image `RRGGBR`.

The first clue is in the raw (uncompressed) `IDAT` bytes written: `0x00 0x05 0x80`.

Now the first byte is the filter byte, and the bit representation of the other two bytes is as follows.
```
0x05: 00 00 01 01
0x80: 10 00 00 00
```
Whereas it should be.
```
0x05: 00 00 01 01
0xA0: 10 10 00 00
```
So `10` is `00`, hence `R` instead of `B`.

The packing is handled by function `packP2`.

