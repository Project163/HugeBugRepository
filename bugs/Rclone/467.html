Title

Environment variables not setting command line flags

Description
#### What is the problem you are having with rclone?

The man page says:

     Rclone  can  be configured entirely using environment variables.  These can be used to set defaults for options or config file entries.

But that isn't true. For example:

    $ RCLONE_VFS_CACHE_MODE=writes rclone mount onedrive: /onedrive
    2019/10/10 21:09:37 Couldn't find flag "vfs-cache-mode"

If I understand it correctly, setDefaultFromEnv() only looks for flag in top-level options:

    setDefaultFromEnv()
    -> pflag.Lookup()
        -> CommandLine.Lookup()

So I think command specific options can't be configured using environment variables? If so, the man page should be fixed.
