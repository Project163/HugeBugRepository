Title

Mixed or Invalid argument reported with variadic when argument with default value is not provided

Description
We've been running into an issue which I'm trying to simplify with the examples here:

We're using a variadic which expands an array with two elements in it, but Psalm reports an error for the 3rd parameter of the function, even though it has a default value.

`    protected function __construct(
        string $p1,
        array $p2 = null,
        int $p3 = 10
    ) `

[Link: Simpler example]:
`INFO: MixedArgument - 13:37 - Argument 3 of Hello::__construct cannot be mixed, expecting int
`

[Example referencing a class constant and array_values](https://psalm.dev/r/9372f051a1
):
`ERROR: InvalidArgument - 18:37 - Argument 3 of Hello::__construct expects int, array |string(aaaaa) provided
`
