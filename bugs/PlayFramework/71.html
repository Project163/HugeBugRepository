Title

RequestBuilder.bodyMultipart(...) creates wrong body type

Description
Create a request via `new RequestBuilder().bodyMultipart(...).build()`. Now try to retrieve the multipart form data from this request via `request.body().asMultipartFormData()`.

It will not work :sob:

Why? Because the body created by the `RequestBuilder` is an instance of `play.mvc.Http.RawBuffer`:
[URL]

[URL]

`body().asMultipartFormData()` however returns the data by casting the body to `MultipartFormData` but of course only *if the body is an instance of this type* (which `RawBuffer` obviously isn't):
[URL]

[URL]
