Title

OBS doesnt let you use certain keys as hotkeys

Description
### Operating System Info

Other

### Other OS

Arch Linux

### OBS Studio Version

28.0.3

### OBS Studio Version (Other)

_No response_

### OBS Studio Log URL

[URL]

### OBS Studio Crash Log URL

_No response_

### Expected Behavior

The keys I push should show up as part of the hotkey

### Current Behavior

Pushing certain keys, such as print screen, or any of the "media control" keys like SKIP TRACK, does nothing.

### Steps to Reproduce

1. Open OBS
2. Open settings
3. Open hotkeys
4. Try to use print screen or a "media control" key as a hotkey

### Anything else we should know?

Other applications, such as Discord, properly recognize the keys you push. For example, I have Discord's push-to-talk set to SKIP TRACK, since I have that globally unbound on my desktop, and its in a convenient location on my keyboard. It's a convenient single key that nothing else uses, which will never conflict with anything else, to which theres no replacement on my keyboard, and OBS for some reason doesn't recognize.

This issue means that I cannot have both Discord and OBS set to the same push-to-talk hotkey, and have to come up with a difficult to use contrived hotkey thats acceptable to OBS and doesnt conflict with anything else.
