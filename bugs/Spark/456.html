Discussion
- The error was due to small number of points and large k. The k-means|| initialization doesn't collect more than k candidates. This is very unlikely to appear in practice because k is much smaller than number of points. I will re-visit this issue once we implement better weighted sampling algorithms.
- I don't think that the problem is about size of dataset. I've faced with similar issue on dataset  with about 900 items. As a workaround we've decided to fallback with random init mode.
