Title

[Form] ChoiceType should not use json_encode to generate hash

Description
In Symfony\Component\Form\Extension\Core\Type\ChoiceType::setDefaultOptions() a hash is generated. Unfortunately this is done using json_encode and may generate php errors when not using UTF-8 as character encoding. According to the json_encode documentation, json_encode should fail if used with anything other than UTF-8 encoded data.

We fixed this by using serialize() instead, but it would be great to see this bug fixed in the symfony code.
