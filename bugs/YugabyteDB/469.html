Title

[YSQL] Connection backend process hangs after exit on linux

Description
Confirmed on centos, to replicate:

```
./bin/yb-ctl create
./bin/ysqlsh
```
Then ` ` to exit.
The connection's backend process will remain idle, and it will also cause `yb-ctl destroy` to hang if called.
Creating an object (in this case table) is required to replicate.

This also likely is the cause for some recent Jenkins test failures with the error:
```
Cluster failed to gracefully terminate within 180000 ms, had to forcibly kill some processes (see logs above).
```
