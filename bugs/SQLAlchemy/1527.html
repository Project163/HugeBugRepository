Title

Legacy class names are not fully imported by sqlalchemy.orm.collections.*

Description
### Describe the bug

Classes in `sqlalchemy.orm.collections` module were renamed in SQLAlchemy 2.0, but some of the legacy names are not imported by `sqlalchemy.orm.collections.*` while the others are.
It's ideal that the behavior is consistent for all legacy class names.
