Title

Bundle Adapter auto configures class fields even if callbacks are used

Description
When a bundle adapter is used with some callbacks (with or without a callback instance), then any fields in the adapter class with type=Bundle are auto-injected. 

 Normally, auto-configuration should be turned off when callbacks are used, exactly in the same manner it is done with regular service dependencies, or with service adapters.
