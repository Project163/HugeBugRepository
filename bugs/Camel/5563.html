Title

HazelcastQueueConsumer : when using mode POLL, the consumer sends NULL

Description
While running some integration test on HazelcastQueueConsumer, using mode POLL. Sometimes the consumer sends and additional NULL as first element. 

 This does not happen at every time I run the tests. It seems that if it polls before having any element, it can gets a NULL, and it send it anyway. 

 I'll try to find a way, to reproduce easily
Discussion
- If the polling timeout is exceeded with  nothing to poll from the queue, the queue.poll() method return NULL. the consumer shouldn't send this NULL
- I've reproduced it by waiting more than the pollingTimeout, and it gets that NULL
