Title

`no-unused-vars` is incorrectly raised when function name matches parameter name

Description
The code snippet:

``` js
function a(a) { return a; }
a();
```

incorrectly complain about the parameter `a` being unused. It seem to prefer the reference to the funcion name instead of the parameter.

Propably caused by the order [Link: in `block-scoped-var.js`].
