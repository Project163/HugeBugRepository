Title

Animated.modulo can be negative when `useNativeDriver: true`

Description
## 🐛 Bug Report
`Animated.modulo` always returns positive value when animation is used without `useNativeDriver`.
If animation uses `useNativeDriver` then output of `Animated.modulo` can be negative

[Image: gif]

## To Reproduce
[Link: TL;DR - sample code]

1. create animated value
2. initialize animated to negative value
3. create `timing` animation to positive value
4. create view using `Animated.modulo`
5. observe when animation is launched with `useNativeDriver` the result of `.modulo` is negative.


## Expected Behavior
I am not 100% sure understand what is the reason of keeping `modulo` always positive but it should at least work according to docs: [URL]
