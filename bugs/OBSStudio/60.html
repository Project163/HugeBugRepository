Title

Stinger transitions linger on last frame.

Description
### Operating System Info

### Other OS

### Expected Behavior

The last frame of a stinger transition should be shown for exactly as long as it's supposed to last.

### Current Behavior

The last frame instead lingers for much longer than it should. 
Recording at 60 fps a stinger at 60fps itself lasting for 1 second results in the last frame of the stinger lasting for 15 frames of the resulting video.
For an example :
[Link: stinger used]
[Link: resulting video]

### Steps to Reproduce

1. Add a stinger transition whose last frame isn't fully transparent
2. Record a scene transition with it
3. Check the recording for lingering frames
