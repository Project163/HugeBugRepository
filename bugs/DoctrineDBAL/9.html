Title

Compatibility mis-match? PGSQL_ATTR_DISABLE_PREPARES in v2.5.2 (in a PHP 5.6.16 envt)

Description
Greetings,

I'm coming up empty on the following observation. I'm not sure if it's an issue or not, and perhaps someone here could advise.

I went ahead and installed doctrine/dbal 2.5.2 (via composer) into a project running atop of PHP 5.6.16, and I'm using pgsql as my backend database. I was previously running 2.5.1 on a PHP 5.3.\* without issue. 

In connecting via dbal to the database, I am seeing this now:
`Fatal error: Undefined class constant 'PGSQL_ATTR_DISABLE_PREPARES' in /path-to-files/vendor/doctrine/dbal/lib/Doctrine/DBAL/Driver/PDOPgSql/Driver.php on line 49`

That block is shown:

``` php
if (PHP_VERSION_ID >= 50600
                && (! isset($driverOptions[PDO::PGSQL_ATTR_DISABLE_PREPARES])
                    || true === $driverOptions[PDO::PGSQL_ATTR_DISABLE_PREPARES]
                )
            ) {
                $pdo->setAttribute(PDO::PGSQL_ATTR_DISABLE_PREPARES, true);
            }
```

If I comment out this entire block, the fatal error goes away and things _seem_ to work normally. I'm not comfortable just commenting this out, since I don't know the full ramifications of such an action.

Any advice is much appreciated and I hope I'm not breaking any conventions by reporting this here. Thanks!

JP
