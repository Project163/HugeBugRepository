Title

Hive skips the creation of ColumnAccessInfo when creating a view

Description
When creating a view, Hive skips the creation of ColumnAccessInfo that should be created at  step 8 . This causes Authorization error.  

 Currently, this issue is "hidden" when CBO is enabled. By introducing   HIVE-14496  , CalcitePlanner creates this ColumnAccessInfo at  step 2 . But after turning off CBO, the issue is still there.  

 I think the return statement in  step 5  is not necessary.
