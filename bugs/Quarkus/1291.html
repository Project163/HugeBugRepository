### Describe the bug


My source code like this:

```java
@Path("/hello")
public interface IReactiveGreetingResource {
    @GET
    @Produces(MediaType.TEXT_PLAIN)
    String hello();
}
```

```java
@RolesAllowed("user")
public class ReactiveGreetingService{
    public String hello() {
        return "Hello RESTEasy Reactive";
    }
}
```

```java
public class ReactiveGreetingResource extends ReactiveGreetingService implements IReactiveGreetingResource{
}
```

when I  remove annotation  'RolesAllowed', it works in natvie mode .
