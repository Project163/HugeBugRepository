Title

Maven Failsafe plugin may report SUCCESS on failed tests

Description
The following build completed successfully on Travis but there are actually test failures:  [URL]
Discussion
- Would be interesting to see if this is an issue of the maven version or the failsafe plugin version
- Failing tests are not supposed to fail the entire build in the  integration-test  phase: 

 
 The Failsafe Plugin is used during the integration-test and verify phases of the build lifecycle to execute the integration tests of an application. The Failsafe Plugin will not fail the build during the integration-test phase, thus enabling the post-integration-test phase to execute.  
  [URL]

 The verify phase also runs afterwards but doesn't receive the failed tests from the previous phase. It appears the test failures are read from the  failsafe-reports  file in the verify phase. 

 I verified on my machine that Exceptions thrown in the integration-tests phase let maven fail the build on  mvn verify . 
  
 [INFO] --- maven-failsafe-plugin:2.18.1:verify (default) @ flink-tests_2.10 ---
[INFO] Failsafe report directory: /Users/max/Dev/flink/flink-tests/target/failsafe-reports
[ERROR] Failed to execute goal org.apache.maven.plugins:maven-failsafe-plugin:2.18.1:verify (default) on project flink-tests_2.10: There are test failures.
 
  

 On Travis, all we get is  
  
 [INFO] --- maven-failsafe-plugin:2.18.1:verify (default) @ flink-tests_2.10 ---
[INFO] Failsafe report directory: /home/travis/build/apache/flink/flink-tests/target/failsafe-reports
 
  

 The  executions  are set up correctly in the parent pom. I'll try to reproduce the error on Travis with activated debug logging.
