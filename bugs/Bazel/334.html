- So I spoke a bit too soon. HardlinkedExecRoot does handle directory inputs, however the way it handles them is by hard linking each of the directory entries:

[URL]

Then, in the process of creating the hardlinks for the children, it creates the parent directory. However, in the case of an empty tree artifact (_aar/unzipped/resources/support-compat-25.2.0), this means that the directory never gets created.

So it seems a simple fix is to call `FileSystemUtils.createDirectoryAndParents(source);` at [URL]
