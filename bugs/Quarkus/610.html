Title

QuarkusTest throws exceptions when having parameters in test function

Description
**Describe the bug**
When having a test function with parameters injected, QuarkusTest throws `java.lang.IllegalArgumentException: argument type mismatch` exception

**Expected behavior**
Maybe it should work with parameters injected.

**Actual behavior**
```
argument type mismatch
java.lang.IllegalArgumentException: argument type mismatch
	at java.base/jdk.internal.reflect.NativeMethodAccessorImpl.invoke0(Native Method)
	at java.base/jdk.internal.reflect.NativeMethodAccessorImpl.invoke(NativeMethodAccessorImpl.java:62)
	at java.base/jdk.internal.reflect.DelegatingMethodAccessorImpl.invoke(DelegatingMethodAccessorImpl.java:43)
... [Log Snipped] ...
	at org.junit.jupiter.engine.descriptor.TestMethodTestDescriptor.invokeTestMethod(TestMethodTestDescriptor.java:201)
	at org.junit.jupiter.engine.descriptor.TestMethodTestDescriptor.execute(TestMethodTestDescriptor.java:137)
```


**To Reproduce**
Steps to reproduce the behavior, simple reproduce test below:
In order to use [Link: `VertxExtension`], I need to inject `VertxTestContext` in my test function:
```
@ExtendWith(VertxExtension::class)
@QuarkusTest
class simpleTest {
    @Test
    fun myTest(vertxTestContext: VertxTestContext) {
           testContext.verify { }
     }
}
```
I can create a new instance of `VertxTestContext` in the test, but will lost the benefit of its context and need to do some workaround to verify the test etc.

**Environment (please complete the following information):**
 - Output of `uname -a` or `ver`:  `Darwin Kernel Version 19.4.0`
 - Output of `java -version`: `openjdk version "11.0.6" 2020-01-14`
 - GraalVM version (if different from Java): 
 - Quarkus version or git rev: `io.quarkus:quarkus-bom:1.3.2.Final`
 - Build tool (ie. output of `mvnw --version` or `gradlew --version`):  `6.0.1`
 - Vertx-junit5 version: `3.8.5`
