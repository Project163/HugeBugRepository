Title

Incompatible SCR API

Description
Current trunk contains version 2.0.0 of the org.apache.felix.scr API package. While this is a logical step, this makes the new implementation unusable as a drop-in replacement into existing installations which might use the 1.x version of that API. 

 I think we should go a more moderate way, leave the 1.x version in but deprecate it and also provide the replacement API (if any). Then in one of the further versions along the road, we can remove the API. This gives our users a chance to migrate slowly
