Title

Callable arrays aren't interpreted correctly

Description
```
php
 ' for AAA::b is more specific than the inferred return type 'array '
    /**
     * @return stdClass[]
     */
    public function b(): array
    {
        return array_map([$this, 'a'], []);
    }
```
It appears the only way to get array_map to type-check is to provide it with typed lambda.
