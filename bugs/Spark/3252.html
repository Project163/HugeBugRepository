Title

Cannot create encoders for case classes defined in Spark shell after upgrading to Scala 2.11

Description
Spark 2.0 started to use Scala 2.11 by default since  PR #10608 .  Unfortunately, after this upgrade, Spark fails to create encoders for case classes defined in REPL: 
  
  import  sqlContext.implicits._
 case   class  T(a: Int, b:  Double )
val ds = Seq(1 -> T(1, 1D), 2 -> T(2, 2D)).toDS()

Discussion
- We need to inject OuterScopes registration like we do in 2.10:  [URL]
- spark shell of scala 2.11 is very different from the scala 2.10 one, we just use the standard shell instead of rewriting a lof of related stuff. 
The trick we used in the scala 2.10 shell is not easy(or impossible) to port to scala 2.11, because we wanna overwrite something in class `Request`, which is an inner class of `ILoop#ILoopInterpreter`. However, there is no virtual inner class in scala, if we wanna overwrite an inner class, we have to overwrite its factory method too. Unluckily, the factory method of `Request` is private, we can't overwrite. 

 I'm going to try another approach, to make `OutScope` smarter that can detect classes defined in shell and load shell wrapper class automatically.
