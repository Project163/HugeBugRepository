Title

A custom input widget won't be validated if you change the ID

Description
Validation of custom widget will not happen if you change it's auto-generated id.
But all works fine when changing the id of 'standard' inputs.

This happens because all input-setting methods (like `ActiveField::textInput()` or `ActiveField::checkboxList()`) call the protected `ActiveField::adjustLabelFor()` function which sets the internal `$_inputId` variable eigther. But the `ActiveField::widget()` method doesn't do this (BTW it also causes incorrect label's `for` value).

I suppose the issue can be solved by adding call of `adjustLabelFor()` in `widget()` method.

Now I'm using the following weird-looking workaround:

```
php
echo $form->field($tag, 'category_id')
    // A hack to set internal input id
    ->textInput([
        'id' => $form->id . '-category_id'
... [Log Snipped] ...
        ]
    ]);
```
