Title

No '--' option for terminating options processing

Description
It appears that neither 1.0 not 1.1 have a '- ' option as the 'end processing options' option.  This is immensely useful to allow parameter that are not options that start with a hyphen.  grep for example does this.  I think it is a bug rather than an enhancement request, I think Commons CLI should support ' -' option.
Discussion
