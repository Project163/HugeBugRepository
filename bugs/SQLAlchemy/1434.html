Title

with_polymorphic returns AliasedClass[Type[Model]] instead of AliasedClass[Model]

Description
### Ensure stubs packages are not installed

- [X] No sqlalchemy stub packages is installed (both `sqlalchemy-stubs` and `sqlalchemy2-stubs` are not compatible with v2)

### Verify if the api is typed

- [Link: X] The api is not in a module listed in [#6810] so it should pass type checking

### Describe the typing issue

If you use `with_polymorphic`, the created object gets the type `AliasedClass[Type[ORMModel]]`. This propagates to the objects retrieved from the database. They should have the type `Sequence[ORMModel]`. Instead they have the type `Sequence[Type[ORMModel]]`.

```
python
from typing import Sequence

from sqlalchemy import create_engine, select
```
