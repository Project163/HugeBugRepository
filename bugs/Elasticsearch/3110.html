Title

XContentGenerator#copyCurrentEvent does not handle BigInteger and BigDecimal

Description
### Elasticsearch Version

8.15

### Installed Plugins

_No response_

### Java Version

_bundled_

### OS Version

x

### Problem Description

`XContentGenerator#copyCurrentEvent` does not handle `BigInteger` and `BigDecimal` numbers. It is just not handled [URL] As a result `copyCurrentEvent` on documents that contain such types produces invalid documents.
