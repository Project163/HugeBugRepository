Title

$ref '/$defs/FileInfo' can not be resolved

Description
### What happened?

In VS Code using the Red Hat YAML Extension, .goreleaser.yml fails to provide any intellisense due to the following error:

```
$ref '/$defs/FileInfo' in '[URL] can not be resolved. YAML(768)
```

I believe this is an issue with the schema provided by Goreleaser itself and not with the YAML extension, since I also noticed that this ref was missing.

### How can we reproduce this?

1. Download The Red Hat YAML Extension in VSCode
1. Create or open a project in VSCode
1. Create a .goreleaser.yml file in the project root
1. Notice the error and lack of auto complete and validation in the editor for that file
