Title

Context's in scope change might not be applied

Description
Reported in IRC channel.

Steps to reproduce the issue:
1. Run ZAP;
2. Create a new context (called A);
3. Click twice in the newly created context (to edit it);
4. Deselect the "In Scope" check box;
5. Close the dialogue (OK button);
6. Note, in the Contexts tree, that the context is still in scope.

Remarks:
The issue does not happen always (e.g. if another context is created) as it depends on the internal ordering of the context panels (not the actual issue, though).

ZAP
Version 2.5.0 (older versions might be affected).
