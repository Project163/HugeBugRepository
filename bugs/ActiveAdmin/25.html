Title

NoMethodError - undefined method `build' for # >

Description
I'm using latest master with Rails 3.2.19 and got this exception when trying to access /new action for nested resource. 

```
ActiveAdmin.register IssueType do
  belongs_to :issue
end
```

Here is beginning of stack trace:

```
activerecord (3.2.19) lib/active_record/associations/collection_proxy.rb:91:in `method_missing'
() .../bundler/gems/active_admin-2ae0a9e09bf9/lib/active_admin/resource_controller/data_access.rb:134:in `build_new_resource'
() .../bundler/gems/active_admin-2ae0a9e09bf9/lib/active_admin/resource_controller/data_access.rb:120:in `build_resource'
```

The problem to my think in #build_new_resource method. It uses #public_send on collection proxy to call [Ref: #build] method, which was introduced in rails 4.0. It was before, but triggered somehow tricky with method_missing.
Here is example in rails 3.2.19 console:

```
Issue.first.issue_types.send(:build) 
=> # >
```

Replacing #public_send to #send could fix this.
Can it be fixed or AA won't support Rails 3.2.x anymore?
