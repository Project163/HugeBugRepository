Title

Missing input/output values in camel-catalog for several eips

Description
In camel-catalog jar in org.apache.camel.catalog.models/*.json, 
some of the files does not define the input/output values 

 list of elements for which it is missing: 
beanPostProcessor, errorHandler, endpoint, streamCaching, propertiesFunction, export, restContext, propertyPlaceholder, fluentTemplate, template, consumerTemplate, camelContext, routeContext, jmxAgent, redeliveryPolicyProfile, threadPool, proxy
Discussion
- They are not part of <route> and EIPs. And they do not have input and ouputs. 

 They are the other kind of configuration you can do.
- if they have no input or output, shouldn't the value of input and output set to "false" instead of not setting any value?
- We could add them and hardcode them to false, so all the model files have those attributes. 

 But this change may slip 2.18.0.  

 If you think this makes sense to add them as false, then you are welcome to reopen the ticket.
- I found some time to fix this.
