Title

NoSuchColumnError stack trace for a function column in a Query

Description
**Describe the bug**
 
I am converting my code from using 1.3.x to 1.4.1 and one of my existing queries is now stack tracing with a NoSuchColumnError, where the Query is returning a `func` column along with other data from a Query.

**Expected behavior**
 
I've tried to investigate in the debugger and I can boil it down to a simple statement:
`session.query(models.Image, func.count(models.Image.id)).group_by(models.Image)`
(not the actual one I am using but it reproduces the error)
Normally I would expect to get a result back, but in this case it stack traces.

I am really struggling to provide a reproducible test case for you because this error **only** happens with **one** of my model classes! If I swap out my `models.Image` with a different, but equally complex model, it works as expected. I cannot work out what is different about it that causes this error. It is not particularly an unusual model, it has a few relationships and a couple of them are `joinedload`ed.

I might be able to privately send the model definition to someone but I cannot post it publicly.

Discussion
- no worries, the query you describe plus the joinedload is sufficinet to reproduce:

```
python
from sqlalchemy import Column
from sqlalchemy import create_engine
from sqlalchemy import ForeignKey
from sqlalchemy import func
... [Log Snipped] ...

s.query(A, func.count(A.id)).group_by(A).all()
```
- fortunately this can be worked around by applying a label to your func.count():

    s.query(A, func.count(A.id).label('count')).group_by(A).all()

if you can verify that fixes the problem for you now, I can get to this issue after i do some others
