Title

FrameworkStartCheck does not work by default on bndtools

Description
Bndtools uses only one framework start level "1" and default bundle start level "1". 

 The current code in FrameworkStartCheck checks for default bundle level +1. So this check never succeeds.  

 I propose to fix this by expecting the framework start level to be default bundle start level by default.
