Title

Router outlet mounts wrong component if using a route reuse strategy and if the router outlet was not instantiated at the time the route got activated

## Current behavior
If using a custom route reuse strategy `RouteReuseStrategy` and if the router outlet was not instantiated at the time the route got activated (ie inside a NgIf), the previous activated component is mounted.

## Expected behavior
The component of the currently activated route is mounted.

## Minimal reproduction of the problem with instructions
Editor URL: [URL]
App URL: [URL]

## What is the motivation / use case for changing the behavior?
We have a toolbar and a tool detail panel to display the currently activated tool component in a named router outlet.
When clicking a tool, we show the tool detail component by navigating to the tool's auxiliary route.
Because we do not want the tool component to be destroyed when switching between tools, we use a custom route reuse strategy.
Also, if toggling an already activated tool, this removes the the router outlet from the DOM.

## Environment
  
Angular version: 6.1.0
