Title

Change ReadToEndLoader.setLocation not throw UnsupportedOperationException

Description
After   PIG-1680  , we will call LoadFunc.setLocation() before launching hadoop job. This change cause TestExampleGenerator fail. The reason is ReadToEndLoader.setLocation() will throw UnsupportedOperationException. We never get to this point before   PIG-1680  .
Discussion
- In general, I think calling LoadFunc.setLocation before launching hadoop job is beneficial. This gives user a hook to setup UDFContext properly. There could be some minor backward compatibility issues, but our document clearly state it will be called multiple times in both frontend and backend. So I think it is Ok. 

 To fix this issue, we can simply remove "throw UnsupportedOperationException" in ReadToEndLoader, which seems unnecessary.
