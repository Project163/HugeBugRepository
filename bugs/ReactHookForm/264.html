Title

Deeply nested fields remain empty when submitting or watching a form.

Description
**Describe the bug**
Since version `7.6.7` deeply nested fields remain empty when submitting or watching a form when combined with `useFieldArray` and appending additional fields. The value is still updated on the actual field.

**To Reproduce**
Steps to reproduce the behavior:

1. Add a new field to the form. 
2. Fill out the username and company name. The value will update alongside it.
3. Submit the form or check the form state at the bottom. The `company.name` property will remain empty.

**Codesandbox link (Required)**

- [Link: v7.6.7]
- [Link: v7.6.6]. 

**Expected behavior**
It should remain possible to deeply nest form fields like on the 7.6.6 release.
