The instructions in the README.md under "angular/aio" to get a general setup doesn't work anymore. After executing "yarn setup" an error occurs (see screenshot).
  

## Current behavior
After executing the "yarn setup" an error occurs and general setup can't be completed. That's why it's impossible to generate documentation or local builds.
The errors seems to be related to the generation process of the documentation files. 

Also tested:
- yarn cache clean - No Improvement
- Executing "yarn" before "yarn setup" - No Improvement
- Cloning the repository again - No Improvement

[Image: error]
 


## Expected behavior
General setup should run through without any errors.
 


## Minimal reproduction of the problem with instructions
Steps to reproduce:
- Install the latest Yarn version
- Fork and clone the Angular Repo
- Open a terminal (administration rights required) and navigate into the folder "angular/aio"
- Execute "yarn setup"
 

## What is the motivation / use case for changing the behavior?
Generating docs is essential for contributing to angular.

- I have the same problem on Windows 10 Enterprise Version 1709 (Build 16299.431).
- Oh, it's because `packages/upgrade/static/src` is a linux-style symlink to `packages/upgrade/src`. Windows doesn't recognize it and can't find `downgrade_module.ts`.

There are some scripts in `scripts/windows/` which you can use to update/restore those symlinks (require admin rights, if you haven't enabled Windows dev mode).
