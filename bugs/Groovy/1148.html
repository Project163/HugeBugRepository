Title

Static import with missed package qualifer

Description
Assume you have a class Class in package p1: 
  
  package  p1
 class   Class  {
   static  foo(){}
}
 
  

 Consider two scripts: 
  
  package  p2
 import  p1. Class 
 import   static   Class .foo

foo()
 
  
 and  
  
  package  p2
 import  p1. Class 
 import   static   Class .*

foo()
 
  
 IMHO these scripts are equivalent but the first one is compiled fine while another one is not. 
I am not sure that they are correct but the script  
  
  package  p1
 import   static   Class .* (or  import   static   Class .foo)

foo()
 
  
 works well.
