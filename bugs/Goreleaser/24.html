Title

goreleaser init produces an empty file

Description
### Prerequisites

* [x] Are you running the latest version?
* [x] Did you perform a search to see if this problem was already reported?

### Description

Since #577 was merged, `goreleaser init` produces an empty `.goreleaser.yml` file.

### Environment

Please paste the output of:

* `go version`
```
go version go1.10 darwin/amd64
```
* `uname -a`
```
Darwin WF001331.local 17.4.0 Darwin Kernel Version 17.4.0: Sun Dec 17 09:19:54 PST 2017; root:xnu-4570.41.2~1/RELEASE_X86_64 x86_64
```
* ~`goreleaser --debug`~ (not relevant)

### Steps to Reproduce

1.  Run `goreleaser init`.
2.  Look at `.goreleaser.yml`.
3.  There isn't really a third step.

**Expected behavior:**
The contents of `example.goreleaser.yml` should be in the generated `.goreleaser.yml`.

**Old behavior:**
```
shellsession
oops:az-dns elyscape$ rm .goreleaser.yml
oops:az-dns elyscape$ ./goreleaser -v

goreleaser version 0.55.1, commit  , built at 2018-02-25T21:02:43Z
... [Log Snipped] ...
oops:az-dns elyscape$ ls -l .goreleaser.yml
-rw-r--r--  1 eliyoung  staff  1636 Mar  1 16:16 .goreleaser.yml
```

**Actual behavior:**
```
shellsession
oops:az-dns elyscape$ rm .goreleaser.yml 
oops:az-dns elyscape$ goreleaser -v

goreleaser version 0.58.1, commit  , built at 2018-03-01T23:53:33Z
... [Log Snipped] ...
oops:az-dns elyscape$ ls -l .goreleaser.yml
-rw-r--r--  1 eliyoung  staff  0 Mar  1 16:16 .goreleaser.yml
```
