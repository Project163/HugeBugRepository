Title

Support non-standard HTTP methods

Description
There have been reports that Play's Akka HTTP backend doesn't handle custom methods beyond GET, POST, etc. We should provide support for this. This can be done by hooking into [Link: Akka HTTP's `customMethods` setting] when we [Link: initialise a server]. We should support any method that is valid. This will require changes to Akka HTTP's `ParserSettings` so it accepts a function to create `HttpMethod`s, not just a list of known `HttpMethod`s.

While we're at it, we may want to use the `customStatusCodes` setting too. A related setting is `customMediaTypes`; this setting will be handled in #8239.
