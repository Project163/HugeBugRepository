Title

Invalid code generation with AdditionalProperties

Description
## Problem statement

The generated validation code in model for the following JSON schema constructs is invalid.

This testcase is part of the cloudbreak.json spec (see also #910): [Link: here]

Given the following definition:
```
json
"PlatformGatewaysResponse" : {
      "type" : "object",
      "properties" : {
        "gateways" : {
... [Log Snipped] ...
      }
    }
```

The model generation yields:
```
golang
// PlatformGatewaysResponseGateways platform gateways response gateways
// swagger:model platformGatewaysResponseGateways
type PlatformGatewaysResponseGateways map[string][]CloudGatewayJSON

... [Log Snipped] ...
	return nil
}
``` 

The `m[k][i] != nil`  is invalid.

With type:
```
golang
// CloudGatewayJSON cloud gateway Json
// swagger:model CloudGatewayJson
type CloudGatewayJSON struct {

... [Log Snipped] ...

	// properties
```
## Swagger specification
[Link: cloudbreak.json]

## Steps to reproduce
```bash
swagger generate server --spec [URL]
cd models
go build
``` 
## Environment
swagger version: current master  
go version: 1.9.1
OS:   linux ubuntu 14..04
