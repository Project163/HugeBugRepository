Title

CharsetDetector.getReader returns null when an exception documented

Description
The CharsetDetector.getReader() javadoc states that it will "Raise an exception if no charsets appear to match the input data." 

 However, if CharsetDetector.detect() returns null, null is returned from the method. 

 In addition, if an IOException occurs it is caught and null is returned from the method. 

 The documentation does not reference null as a possible return value. 

 This is the underlying cause of an issue in RAT.
