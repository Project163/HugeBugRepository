- @deki Interesting, the only option I see is that `request.getRequestContext().getHttp()` returned null. Because `request.getRequestContext()` was already called few lines above. How did you get such state? Because it's not really clear what to do in that case. There is no "default" method in HTTP protocol.
- Maybe you are using the wrong extension?  Are you doing a normal lambda or are you using vertxweb, servlet, or jax-rs with lambda?

A regular lambda is quarkus-amazon-lambda
If you are using one of our HTTP apis its quarkus-amazon-lambda-http (or -rest depending on which AWS http api you are using)
- Yes if you trigger the Lambda function directly without involving API-Gateway (e.g. using the Test button in the AWS Lambda console) there is obviously no HTTP involved. So not much we can do apart from providing a proper error message.
