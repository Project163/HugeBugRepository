Title

PubSub example has a minor error in the closing logic

Description
The Listener class has the following check  - "while (_finished < 3 && !_failed)" 
However there are 4 topics and this loop condition causes the Listener to close after receiving 3 "termination messages" instead of 4. 
Due to the volume of messages this is mostly unnoticable when run manually. 
But this causes an intermittent failure when run with the verify scripts as due to a race condtion sometimes all messages from all 4 topics are received before close.
Discussion
- This contains a trivial fix in r639078 in trunk. 
I also took the oportunity to organize the  Listener code a bit more. 
Also removed the temp hack we used to bind a Topic to more than one routingkey to interop with the c++/python examples. 
The topics can now be bound to more than one routingkey in the jndi properties file.
- This has been fixed and verified. 
Closing issue.
