Title

Make `mapping.single_type` only settable if the index is a 5.x index

Description
`mapping.single_type` allows to add multiple types which is something that 6.x indices must not allow. Yet, today this setting is still modifiable while it defaults to `true` In order to move make it only settable on 5.x indices and read-only in 6.0 we need to fix several things like:

- [x] Fix `PercolatorFieldMapperTests` to use a single type #24958 / #24963
- [x] Move Rest tests that use multiple types into a mixed cluster scenario such that indices that are tested against are created with a 5.x version. #24965
- [x] Remove this setting from `AbstractQueryTestCase`
- [x] disallow setting `index.mapper.single_type` on 6.x indices #25375
- [x] Fix Parent/Child to work without multiple types #20257
- [x] Fix Documentation do not use multiple types #25401
Discussion
- The `qa:full-cluster-restart` project might be useful here.
- I don't think it needs to be that complicated we can just use the `qa:mixed-cluster` project
