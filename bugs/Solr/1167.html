- I said it'd be difficult to make anything sensible under low-memory conditions, didn't I? Even hotspot goes wild. Try it: 

  
  import  java.util.LinkedList;

 public   class  CodeOom {
   static  LinkedList< byte []> ohMy =  new  LinkedList< byte []>(); 

   public  void oomInCode() {
     int  stringLength = 1024 * 1024 * 5;
     while  ( true ) {
       try  {
          ohMy.add( new   byte  [stringLength]);
      }  catch  (OutOfMemoryError e) {
         if  (stringLength < 100) {
           throw  e;
        }  else  {
          stringLength /= 2;
        }
      }
    }
  }
  
   public   static  void main( String [] args) {
     try  {
       new  CodeOom().oomInCode();
    }  catch  (Throwable t) {
       Runtime .getRuntime().halt( /* anything != 0, 1, etc. */  5);
    }
  }
}
 
  

 This should terminate with exit code 5. So it does, normally. But not when there's no memory. See for yourself: 

  
 dweiss@ophelia:~/tmp$ java -cp . CodeOom; echo $?
