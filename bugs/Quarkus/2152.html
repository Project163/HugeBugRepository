Title

Description

Discussion
- Thanks for reporting. 

This is a more general issue, i.e. that `@MockitoConfig(convertScopes = true)` does not work with synthetic beans. 
I am not sure what we could do about that @mkouba.

In this specific case we could easily make the `GitInfo` bean an `@ApplicationScoped` bean instead of a `@Singleton`.
- Indeed, `@MockitoConfig(convertScopes = true)` makes use of the `AnnotationsTransformer` API which does not work for synthetic beans, i.e. beans whose metadata are created programmatically in a Quarkus extension. We would need a new API to transform the bean metadata to fix this problem :shrug:.

I'm not quite sure it's worth the effort.
