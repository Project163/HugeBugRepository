Title

`no-magic-numbers` doesn't catch assignment operators

Description
Using ESLint 1.9.0:

Input:

``` js
/*eslint no-magic-numbers: 2*/
var a = 5;
a += 5;
a = a + 5;
```

Result:

```
  4:13  error  No magic number: 5  no-magic-numbers

✖ 1 problem (1 error, 0 warnings)
```

I'd expect to also get an error for line 3.
