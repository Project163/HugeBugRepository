Title

Problems with the 'as' operator

Description
The following code reproduce the error: 

 class Foo {} 

 Foo.metaClass.invokeMethod = { String name, args -> 
    for (arg in args)  
{
        arg.getClass()
    }
 } 

 def f = new Foo() 

 f.echo(f as Foo)
Discussion
