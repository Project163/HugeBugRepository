Title

Hive Test Commands failure should be printed in hive.log in addition to stderr

Description
When the  QTestUtil.executeTestCommand  runs a test only command, and the command fails, the exception info is printed to stdout rather than the log file. Printing out to the logs file will better help debuggability of these failures.
