### Additional context

The problem is that Turbopack, for example, when using `@media screen and (max-width: 768px)` converts this to `@media screen and (width <= 768px)`. Because of this, Chrome doesn't show media breakpoints
Discussion
- Turns out the problem is that Lightingcss (in Turbopack) minifies @media, but if you set `experimental: { turbo: { useSwcCss: true } }` in the config to disable it, everything displays.
- That flag is legacy and will be removed in an upcoming patch release. We'll want to figure out why LightningCSS is causing problems for this case 🙂
- ... [Middle Discussions Snipped for Brevity] ...
- Starting with Next.js 15.1 they removed `experimental: { turbo: { useSwcCss: true } }`
- Opened [Ref: #85086] to fix this
