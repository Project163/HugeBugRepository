Title

Timeout async guard inappropriately triggers with F#

Description
Reported here: [URL]

Sample code that fails to run with 2.7.0:

```
fsharp
module Tests

open System.Threading.Tasks
open Xunit
... [Log Snipped] ...
        Assert.Fail("Make sure things waited")
    }
```

Adding `:> Task` cast to the end of the task lambda is a temporary workaround:

```
fsharp
module Tests

open System.Threading.Tasks
open Xunit
... [Log Snipped] ...
        Assert.Fail("Make sure things waited")
    } :> Task
```
Discussion
- The "culprit" here is the new `task` keyword, which I wasn't familiar with. Instead of returning an [Link: `FSharpAsync `], it returns [Link: `Task `], presumably for better cross-language interop.
- Available in v2 `2.7.1-pre.7`
Available in v3 `0.1.1-pre.378`
