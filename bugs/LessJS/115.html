Title

unit() Broken for Percentages?

Description
The docs don't explicitly mention using unit with "%", but I would assume that this should work:

```
@v: unit(100, %);
s { p: @v;}
```

However the output is:

``` css
s {
  p: %);
}
```

`unit(100, ~'%')` does work, however.

 (I originally posted this by mistake on less/less#217)
Discussion
- I think this is a straight forward bug that needs fixing.
- is this a limitation of JS as % is an operator so it has to be quoted to be passed to unit()?
- No, its the parser. It doesn't understand % on its own.
- see #1571 for proposed fix. #1566 is not a valid pull request.
