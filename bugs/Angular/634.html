Title

[Regression] HttpClient converts null -> 'null' in unit tests: "Expected 'null' to be null."

## Current behavior
 
In version 5.0.4 and 5.0.5, during unit tests, flushing http requests with a `null` value converts the result into `'null'` (string)

In the test this causes the error: `ApiService should return null FAILED  Expected 'null' to be null.`

## Expected behavior
 
In version 5.0.3 flushing http requests from http requests with a `null` value returned a `null` value. This is a regression.
