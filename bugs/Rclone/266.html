Title

Entry doesn't belong in directory.. errors when using rclone sync with s3

Description
Hi,

I installed rclone on my Ubuntu 16.04 LTS server and I want to sync a remote s3 bucket to a local directory. When using rclone sync I got a couple of directory related errors.

This is my config file:

```
[test-s3]
type = s3
env_auth = false
access_key_id =  
secret_access_key =  
... [Log Snipped] ...
server_side_encryption =
storage_class =
```

This is the output of rclone:

```

```
├── folder 1

Do I miss something? Or do we have a bug here?
Discussion
- How did those `folder 1` and `folder 2` get created?  s3 doesn't have a concept of empty folders, so I suspect they are actually 0 size objects with a trailing /.  Rclone doesn't deal brilliantly with these...  The ERROR messages are rclone ignoring those objects and it looks like the sync worked properly.
- All of the bucket based remotes potentially have this problem - objects with names ending in `/` which have been uploaded by other storage systems (cyberduck for instance).
