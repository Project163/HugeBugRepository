Title

`Checker.is_final_enum_value` duplicates `TypoInfo.enum_members` logic

Description
After merging [URL] I think it would make sense to change how we check for `@final` enums here: [URL]

There's no need to duplicate the `.enum_member` logic here once again. I will refactor this piece.
Discussion
- This cause a problem: now `member` and `nonmember` types are supported in `.enum_members`, but not in `is_final_enum_value`. As the result, this code does not work properly:

```python
from enum import Enum, nonmember

class My(Enum):
    x = nonmember(1)
    
class Other(My):  # E: Cannot extend enum with existing members: "My"
    y = 2
```

While in runtime it works just fine.

Solving it!
