Title

3.x Can't use dot in a cache config

Description
**What I did**

``` php
\Cake\Cache\Cache::config('CurrencyExchange.ratesCache', [
    'className' => 'File',
    'path' => CACHE,
    'duration' => '+1 year',
    'prefix' => 'currency_exchange_'
]);
```

**What happened?**
I got a PHP Fatal for trying to use `write()` on a non-object.

**What's going on?**
The Cache class `write()` method calls `engine()` to build the cache engine, which calls `_buildEngine()`, which in turn calls [Link: `static::$_registry->load($name, $config);`]`.

In the [Link: `ObjectRegistry` class, the `$objectName` is parsed using `pluginSplit()`] which removes the first part of the cache config name. This means that the loaded object never matches with the config in the cache class. `CurrencyExchange.ratesCache != ratesCache`

**How I got around it**
I updated my cache config from `CurrencyExchange.ratesCache` to `CurrencyExchange_ratesCache`
