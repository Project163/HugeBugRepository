Title

NumFieldLimiting URP "warnOnly" mode broken

Description
NumFieldLimitingUpdateProcessorFactory (introduced in   SOLR-17192  ) aims to offer a "warnOnly" mode that logs a warning when the maximum number of fields is exceeded. 

 But the "warnOnly" code path doesn't trigger any subsequent processors in the chain.  So in effect, both modes will prevent new documents from being added once the limit has been exceeded. 

 We should rework this logic so that the warnOnly=true codepath allows documents to be indexed as expected.
