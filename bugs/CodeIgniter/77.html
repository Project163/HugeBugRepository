Title

DB query builder adds space after right bracket in the function where_in

Description
Today I get a strange bug with Codeigniter 3.0.4 and php7:

``` php
 $this->db->select('*')->from('file');
 $this->db->where_in('name', ['hello).txt', 'world']);

var_dump($this->db->get_compiled_select());
```

 **'SELECT *
 FROM `file`
 WHERE `name` IN('hello) .txt', 'world')' (length=60)**

DB Query Builder adds space after ")" and I can't find a file with the name "hello).txt" at my database.
The problem is at file DB_query_builder.php line 2370.
