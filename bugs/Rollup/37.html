Title

Computed property keys are mistakenly tree-shaken away

Description
In the following code snippet, rollup drops `_x`:

``` js
const _x = Symbol('x');
export class Foo {
  [Link: _x] {}
}
```

([Link: see live here])
Discussion
- As (probably) part of the same issue, even if the symbol used in the computed property is otherwise retained and renamed, the resulting code does not track the new renamed name of the symbol.

([Link: see example])
- Note that this is almost like #434, except for class syntax (was fixed for object literals).
