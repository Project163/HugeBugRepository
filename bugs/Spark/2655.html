Title

Partition discovery does not throw an exception if the dir structure is invalid

Description
I have a dir structure like  /path/table1/partition_column=1/ . When I try to use  load("/path/") , it works and I get a DF. When I query this DF, if it is stored as ORC, there will be the following NPE. But, if it is Parquet, we even can return rows. We should complain to users about the dir struct because  table1  does not meet our format.
