Title

Ivy resolve force mode should be turned off by default

Description
The problem is introduced by    HADOOP-6486  . Which have caused a lot of mysterious artifact issues (unable to downgrade or do parallel dev, without wiping out both m2 and ivy caches etc.) wasting countless hours of dev (many people's) time to track down the issue.
Discussion
- The patch introduced a "force-mode" property which is off by default. Can be turned on with -Dforce-mode=true.
- force-mode may not be the best name for the option as it doesn't say anything about ivy.  How about something like force-ivy-resolution.  More descriptive names are better, even if they are longer.
