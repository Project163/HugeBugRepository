Title

What does the uninstall target do / how can we not create it

Description
Hi,

I asked the same question [Link: on stack overflow] but apparently nobody there knows.

What does the `uninstall` target do that is generated in Visual Studio when using this with CMAKE?

How do we disable it?

It is not mentioned in the documentation, nor any of the code within the "install" target CMakelists itself.

If it must exist can it be automatically added inside the `GLFW3` folder instead of outside it?
Discussion
- It uninstalls the GLFW library, headers and package files from where the `install` target placed them (or will place them).


It's disabled along with the `install` target. Use the `GLFW_INSTALL` CMake option to disable them.


True, and it really should be included. There isn't really a section on installation at all and the rest of the compilation guide isn't all that great either.
