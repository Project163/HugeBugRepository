Title

Incomplete API `POST` reponse for `scopes` in `/api/v1/users/ /tokens`

Description
### Description

When creating a token via the API and supplying scopes, eg...
```sh
curl -k -H "Content-Type: application/json" -d '{"name":"test2", "scopes":["write:package", "read:notification"]}' -u user:pass [URL]
```
the response for `scopes` is always `null`, eg.
```json
{"id":13,"name":"test2","sha1":"6xxxxxxxxxxxxxx87c","token_last_eight":"bd4e087c","scopes":null}
```
even though the permissions are actually there:
```sh
curl -k -H "Content-Type: application/json" -u user:pass [URL]
```
```json
[{"id":13,"name":"test2","sha1":"","token_last_eight":"bd4e087c","scopes":["read:notification","write:package"]}]
```
This issue was found when updating the documentation in pull request [URL]
