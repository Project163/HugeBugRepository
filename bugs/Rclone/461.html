Title

Description
During copies for very large objects (10's of GB) Rclone may time out, and then retry incessantly causing backend storage system resource issue, due to the tens of thousands of requests (even though the copy eventually succeeds). Is it possible to implement better handling of checking so that before a copy starts, ensure the original request was properly completed?
