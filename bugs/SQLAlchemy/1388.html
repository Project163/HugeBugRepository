Title

Docs error: MySQL SSL Connections connect_args example is wrong

Description
### Describe the bug

[URL]

First example here shows how to using the [Link: create_engine.connect_args] dictionary. It has error: items in "ssl" subdictionary must not have "ssl_" prefix.

Using your example I can't establish SSL connection to my MySQL server.
But using second example with encoding parameters to DB URL does work.

So, I've checked with debug print what parameters arrived to the pymysql Connect() object and found out they are in "ssl" dict and all keys without "ssl_" prefix. After fixing my connect_args to be without "ssl_" prefix - the code works as expected.

### To Reproduce

```
python
Our admin created special user_ssl in MySQL which requires using only SSL connections to database. 

        url = "mysql+pymysql://user_ssl:password@ :3306/base?charset=utf8mb4"
        connect_args = {
... [Log Snipped] ...

Then do any SQL select and get error.
```

```
sqlalchemy.exc.OperationalError: (pymysql.err.OperationalError) (1045, "Access denied for user 'user_ssl'@' ' (using password: YES)")

```
