Title

Fix KRPC files with missing flexibleVersions annotation

Description
Some KRPC files do not specify their flexibleVersions. Unfortunately, in this case, we default to not supporting any flexible versions. This is a poor default, since the flexible format is both more efficient (usually) and flexible. 

 Make flexibleVersions explicit and disallow setting anything except "0+" on new RPC and metadata records.
