Title

Bug in Hybrid Hash Join: Request to spill a partition with less than two buffers.

Description

Discussion
- If the join tries to spill a partition with only one buffer, then all partitions have only one buffer. All other buffers must be already used in the hash table and overflow segments. 

 I initially assumed that such a situation could never occur (the way segments are distributed), but I think I may have been mistaken there. If this situation occurs (all partitions have one buffer), then the only space to free is overflow buffers. 

 So we should actually look for partitions to spill by counting partition buffers and overflow buffers. In that case, there should be no lack of buffers before one partition has accumulated two buffers.
