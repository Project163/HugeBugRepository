Title

Pseudo scope doesn't use the context class object

Description
### Describe the bug

Custom pseudo scope beans are not managed.
The scope configuration doesn't make the registered scope context class involved in bean lifecycle.

The same scope which is registered as a normal works fine.

The problem is: normal scope create and uses proxies instead of actual bean classes and this makes impossible to use normal scope in some cases.

### Expected behavior

Pseudo scope bean is managed, i.e. it's `CustomContext` class is used to create and store a bean instance during the context lifecycle.

### Actual behavior

`CustomContext` is never used for pseudo scope.
The instance is created for every injection point and the context of the scope is disregarded.
As a result the instance is not reused within the context.

### How to Reproduce?

I have a pseudo scope:

```
@Scope
@Inherited
@Target({ ANNOTATION_TYPE, TYPE, FIELD, METHOD, CONSTRUCTOR })
@Retention(RetentionPolicy.RUNTIME)
public @interface CustomScope {
}
```
**Note: It's not a normal.**
I have an  `InjectableContext` implementation class. Let's say it's `CustomContext`.

I register a `CustomScope` via `@BuildStep`s:

```
@BuildStep
    ContextConfiguratorBuildItem registerCustomContext(
            ContextRegistrationPhaseBuildItem phase) {
        return new ContextConfiguratorBuildItem(
                phase.getContext().configure(CustomScope.class)
... [Log Snipped] ...
        return new CustomScopeBuildItem(CustomScope.class);
    }
```

When the `CustomScope` beans are used they are injected but `CustomContext` class methods are never used.
So neither `CustomContext::get(Contextual)`  nor `Contextual::get(Contextual, CreationalContext)` are ever called.

The same scope which is registered as a normal (i.e. with `@NormalScope` and `configure(CustomScope.class).normal()` in the proper places) works fine.
