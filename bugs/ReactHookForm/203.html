Title

"Maximum call stack size exceeded" when using react element in required

Description
**Describe the bug**
If I use react element inside register for required property, then I am getting the error "Maximum call stack size exceeded". 

**To Reproduce**
Steps to reproduce the behavior:

1. Go to the sandbox
2. Click on the email input to make it focused.
3. Click outside of the email input to make it unfocused.
4. Click on the email input again to make it focused.
5. Click outside of the email input to make it unfocused.
6. It throws the error "Maximum call stack size exceeded".
