Title

[YSQL] PgLibPqTest.TestWebserverKill failing on mac

Description
Jira Link: [Link: DB-9226]
### Description

There seems to be a bug in the mac implementation of pgrep:

`pgrep -f 'YSQL webserver' -P  ` command on mac returns all items with PPID  . 
`pgrep -P   -f 'YSQL webserver' ` command on mac returns all items with PPID   and matching YSQL webserver. 

For example:
```
❯ pgrep -P 24430 -f "webserver"
24433
❯ pgrep -f "webserver" -P 24430
12932
12935
24430
24433
```

On linux they both behave the same, as expected. 
```
$ pgrep -P 116838 -f "webserver"
116889
$ pgrep -f "webserver" -P 116838
116889
```
