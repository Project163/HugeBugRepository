Title

Subtracting two data time series with NaT yields Overflow error

Description
#### Problem description

If I have a series of DateTime values and I want to subtract another series with DateTime value which contains NaT, in some case I get OverflowError. 

#### Code Sample, a copy-pastable example if possible

```python
s1 = pd.Series([pd.to_datetime('1969-12-31')])
s2 = pd.Series([pd.to_datetime('NaT')])
s1 - s2
```
#### Expected Output

```
0   NaT
dtype: timedelta64[ns]
```
