Title

duplicate declarations on a naming colision

Description
given the following spec, swagger will produce two top level package variables named the same thing, which prevents the server from running:

```
json
{
    "host": "localhost",
    "schemes": ["https"],
    "swagger": "2.0",
... [Log Snipped] ...
    }
}
```

produces in soda.go:

``` go
var sodaBrandEnum []interface{}

func (m *Soda) validateBrandEnum(path, location string, value string) error {
    if sodaBrandEnum == nil {
```

and in soda_brand.go:

``` go
type SodaBrand string

// for schema
var sodaBrandEnum []interface{}

func (m SodaBrand) validateSodaBrandEnum(path, location string, value SodaBrand) error {
    if sodaBrandEnum == nil {
```

which causes go to complain about the duplicate declaration of sodaBrandEnum.
