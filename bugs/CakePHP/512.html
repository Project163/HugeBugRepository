Title

Join throws Notice if `conditions` key not set.

Description
My code example. Note that `conditions` key is not set in the join array:

```
$rows = $this->find('all', array(
        'joins' => array(
            array(
                'table' => 'kitchens_restaurants',
                'alias' => 'KitchenRestaurants',
... [Log Snipped] ...
    )
);
```

The error:

[Link: Code Ref]

The reason this occurs is because the default setting of `conditions` is an empty array. You can see that here in the [Link: buildJoinStatement function]. This function sometimes calls `$this->conditions` to convert the conditions into a string but not always (and not in the default case).

If Cake wants to make all 4 keys necessary should an exception be thrown if they are empty? If `conditions` is empty should the `type` be changed to 'CROSS'? I've fixed my own code by including a condition.
Discussion
- Why do you not have conditions for the join? Without them a cross join will be generated and that's probably not what you want.
- I guess what I'm saying is this logic makes sense to:

A) Require all 4 parameters. Throw exception (??) if one is missing
or
B) Try to handle cases where a parameter is missing correctly. For instance, maybe the default settings should be

```
array(
    'type' => 'CROSS',
    'alias' => null,
    'table' => 'join_table',
    'conditions' => array()
)
```

and then modify [Link: this check]:

```
if (strtoupper($data['type']) === 'CROSS') {
    return "{$data['type']} JOIN {$data['table']} {$data['alias']}";
}
```

to 

```
if (strtoupper($data['type']) === 'CROSS' || empty($data['conditions']) {
    return "{$data['type']} JOIN {$data['table']} {$data['alias']}";
}
```

It just seems kind of odd that there isn't better checking here.
- Fair enough, getting warnings isn't super helpful.
