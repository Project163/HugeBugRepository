Title

InternalHashError: 'method_descriptor' object has no attribute 'module'

Description
### Summary

Some functions seem to not be able to be cached (but they are pretty commonly used).

I've checked [URL] but it tells to use another package other than `pickle` (in their case, `dill`) which is beyond my control.

from datetime import datetime as dt

Discussion
- On my own code, replacing the `date_to_timestamp` function by:

```
import time

def date_to_timestamp(date):
    return str(int(time.mktime(date.timetuple())))
```

solves the problem.

But it may not be possible for everyone to just "switch functions" in order to get the cache to work.
- Thanks for reporting this @vinzeebreak!

I'm going to close this as we hope to replace `st.cache` entirely with a new caching primitive [Link: st.experimental_memo] (and it seems like the code snipped you provided works if `st.cache` is replaced with `st.experimental_memo`) in the coming months (if all goes according to plan), so it's unlikely that a fix for this will be prioritized with `st.cache`'s deprecation in sight.
