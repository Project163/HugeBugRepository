Title

Linting with auto-fix with rule 'object-shorthand' breaks properties with async/await functions

Description
**Configuration**
```
node 6.9.1
npm 3.10.8
dependencies: {
    "eslint": "^3.8.0",
    "eslint-loader": "^1.6.1",
... [Log Snipped] ...
    "eslint-plugin-react": "^6.6.0"
  }
```

**Have**
You have `index.js`:
```js
function MyObj() {}

MyObj.prototype = {
    someMethod: async function () {}
};
```

You have `.eslintrc`
```
json
{
    "parserOptions": {
        "ecmaVersion": 2017
    },
... [Log Snipped] ...
    }
}
```

You run:
```bash
./node_modules/.bin/eslint --fix ./index.js 
```

You get in `index.js`:
```js
export default {};

function MyObj() {}

MyObj.prototype = {
    someMethodnction() {} // wrong auto-fix
};
```

**Expects & caused by**
I've investigated that it caused by `object-shorthand` rule. 
```json
{
    "object-shorthand": ["error", "properties"]
}
```
If i set up it like that everything is ok. But I think with rule `["error", "always"]` also everything should be linted great.
