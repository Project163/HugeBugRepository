Title

Calling `vim.wait` within fast events results in crash

Description
### Problem

Calling `vim.system` within `vim.loop` results in failure, causing Neovim to exit with a 134 status code.

### Steps to reproduce

- Create following `repro.lua`
```lua
vim.loop.timer_start(vim.loop.new_timer(), 0, 100, function()
  vim.system({ 'echo' }):wait()
end)
```
- Open `nvim` with `nvim -u NORC -u repro.lua`.


### Expected behavior

Successfully opened neovim.

### Neovim version (nvim -v)

v0.10.0-dev-1453+ge0d97d264-Homebrew

### Operating system/version

macOS 14.1.1

### Terminal name/version

wezterm

### $TERM environment variable

wezterm

### Installation

homebrew
