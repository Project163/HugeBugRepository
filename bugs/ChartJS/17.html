Title

Error in logarithmic scale online documentation

Description
Hi,

I think that in Logarithmic Scale documentation [Link], Example Configuration is missing 'scales' in 'options'.

`options: {
        xAxes: [{
            type: 'logarithmic',
            position: 'bottom',
            ticks: {
                min: 1,
                max: 1000
            }
        }]
    }`

should be:

`options: {
     scales: {
        xAxes: [{
            type: 'logarithmic',
            position: 'bottom',
            ticks: {
                min: 1,
                max: 1000
            }
        }]
      }
    }`
