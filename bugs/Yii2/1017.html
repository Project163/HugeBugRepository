Title

Yii2 does not properly handle name quoting character when MySQL is run in ANSI mode

Description
How to reproduce the problem: configure MySQL to run in ANSI or ANSI_QUOTES mode. Run gii and try to create a model for any table with foreign key to another table.

When MySQL is run in ANSI or ANSI_QOUTES mode the character to escape database names is double quote as in standard ANSI SQL. And while in these modes backtick (`) character still works for quoting MySQL names, when executing SQLs such as "SHOW CREATE TABLE" MySQl will return the result with names quoted with double quote character but Yii2 expects it to contain backtick character.

Some references:
[URL]
[URL]

Alot of code in yiisoft\yii2\db\mysql\Schema.php is affected by this bug. For example, in function findConstraints($table):

```
$fks = array_map('trim', explode(',', str_replace('`', '', $match[1])));
$pks = array_map('trim', explode(',', str_replace('`', '', $match[3])));
```

etc. The lines above remove backtick while the string returned by MySQL contains double quote instead of backtick.
Discussion
- whats the benefit of turning that mode on?
- The benefit is a compliance with the ISO/IEC 9075 SQL standard which is always a good thing - makes it easier to switch to another database, etc.
- Maybe the relevant code could check for the current mode? I've added a similar check for Oracle when using `PDO::CASE_UPPER`.
