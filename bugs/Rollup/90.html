Title

Importing external package as namespace creates duplicate imports

Description
I'm trying to upgrade to the latest release (v0.56.4) from v0.52.0 but getting this issue when importing external namespaces. When I try to use this output with Rollup, CommonJS plugin complains and fails `[!] (commonjs plugin) SyntaxError: Identifier 'externalPackage' has already been declared`

input:
```js
import * as ext from 'external-package';
export { ext };
```

output:
```js
import * as externalPackage from 'external-package';
import * as externalPackage from 'external-package';
export { externalPackage as ext };
```
