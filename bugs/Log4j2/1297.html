Discussion
- Actually, the stack trace above proves the   LOG4J2-1964   is fixed. You are successfully creating a configuration with a RollingFileAppender that only uses the SizeBasedTriggeringPolicy. You then attempt to create a RollingFileAppender with a TimeBasedTriggeringPolicy - but you didn't change the file name pattern to include a date. This caused an exception because a date is required in the pattern for TimeBasedTriggeringPolicy. In   LOG4J2-1964   the complaint was that the file name was not being changed, not that an exception was being thrown. 

 Resolving this as invalid.
