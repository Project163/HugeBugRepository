Title

In the torch.Tensor.scatter_ documentation, self, index, and src (if it is a tensor) should have the same number of dimensions, but in practice, the CPU、Gpu does not add a check. Validation needs to be added.

Description
### 🐛 Describe the bug

In the torch.Tensor.scatter_ documentation, self, index, and src (if it is a tensor) should have the same number of dimensions, but in practice, the CPU、Gpu does not add a check. Validation needs to be added. 

cpu：
import torch
index = torch.tensor(0)
tensor_input = torch.arange(0, 10)
result = tensor_input.scatter_(0, index, 100)
print(tensor_input)
print(result)

gpu：
import time
import math
import numpy as np
import torch
import torch
index = torch.tensor(0)
if 'torch.Tensor' in str(type(index)) or 'torch.nn.modules' in str(type(index)):
    index = index.cuda()
tensor_input = torch.arange(0, 10)
if 'torch.Tensor' in str(type(tensor_input)) or 'torch.nn.modules' in str(type(tensor_input)):
    tensor_input = tensor_input.cuda()
result = tensor_input.scatter_(0, index, 100)
if 'torch.Tensor' in str(type(result)) or 'torch.nn.modules' in str(type(result)):
    result = result.cuda()
npu：
import time
import math
import numpy as np
import torch
import torch_npu
import torch
index = torch.tensor(0)
if 'torch.Tensor' in str(type(index)) or 'torch.nn.modules' in str(type(index)):
    index = index.npu()
tensor_input = torch.arange(0, 10)
if 'torch.Tensor' in str(type(tensor_input)) or 'torch.nn.modules' in str(type(tensor_input)):
    tensor_input = tensor_input.npu()
result = tensor_input.scatter_(0, index, 100)
if 'torch.Tensor' in str(type(result)) or 'torch.nn.modules' in str(type(result)):
    result = result.npu()
