Title

Reject JoinGroup request from first member with empty protocol type/protocol list

Description
Currently, if the first group member joins with empty partition.assignment.strategy, then the group won't allow any other members with valid protocols.  This JIRA is to add validation to reject JoinGroup requests from the first member with empty protocol type or empty protocol list 

 Also, add consumer-side validations to check at least one partition assigner class name is configured while using subscribe APIs.
