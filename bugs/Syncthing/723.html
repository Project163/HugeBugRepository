1. The Scan() issued by recheck during a request can hang until the pull is finished if request comes in during a pull
2. A pull can hang as long as the other side has not responded to a request
3. The other side can not respond to a request because it's trying to do a recheck which is blocked by a scan.

Goto 1.

Seems that all you need is device A to pull some file which hits the recheck condition on device B
and device B to pull some file that hits the recheck condition on device A at the same time.
Discussion
- Very nice find!  
Making the scan async and returning an error on the rechecked request should deal with this.
