Title

Regression: --version requires configuration password

Description
In v1.50.2, running `rclone --version` with an encrypted config file would output the version.

In v1.55.0, the same command asks for the configuration password first. This should not be necessary, as none of the information output by `--version` seems related to the configuration.

```
$ rclone --version
Enter configuration password:
password:
rclone v1.55.0
- os/type: linux
... [Log Snipped] ...
- go/linking: static
- go/tags: cmount
```

(Also, the password prompt is doubled, but that's a separate issue.)
Discussion
- @ncw I guess it was caused by recent config patches.  Is it fixed by 1.55.1?
- For info: v1.54.1 also does not ask for password, so its introduced with v1.55.

Workaround is to run with option for memory-only config, although it has its own [Link: issue]. But is there a plan for a better solution to this, avoiding the need for such option, for --version or even more generic?
