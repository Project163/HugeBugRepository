Title

[YSQL] Crash in CBO when estimating cost of index scan with no filter on hash keys

Description
Jira Link: [Link: DB-11675]
### Description

A bug in cost estimation for index scan can cause a crash. 

This occurs when estimating the cost of an index. The index must have hash and range keys and included columns. The query must have no filter on at least on of the hash keys and no range filters on any hash keys.

This issue can be reproduced with following test,

```
SET yb_enable_base_scans_cost_model = ON;
CREATE TABLE test (v1 INT, v2 INT, v3 INT); 
CREATE INDEX test_index ON test ((v1) HASH, v2 ASC) INCLUDE (v3);
SELECT * FROM test WHERE v2 > 100;
```
