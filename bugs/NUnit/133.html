Title

NUnitLite incorrectly reports Win 10 OS name

Description
NUnitLite incorrectly reports `Environment.OSVersion` as Windows 8, when running on Windows 10. The property has been [Link: deprecated].aspx). This is shown in the main console output, xml, and a couple of other places.

The simple workaround is to add an [Link: app.manifest], as the console runner has. (The Console runner reports correctly.)

Alternatively, looks like the existing `OSPlatform` class might already work around this situation.
