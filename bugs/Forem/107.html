Title

Likes button opacity and tooltip glitch after replying to a comment on own post

Description
When replying to a comment on your own post, the "Likes" button becomes semi-transparent (opacity reduced) and its tooltip ("Likes") is rendered behind the newly added reply. This visual issue persists until the page is reloaded, after which the button and tooltip appear normal again.

**To Reproduce**

1. Go to your own post.
2. Add a new comment if not already present.
3. Reply to that comment.
4. Observe that the "Likes" button becomes faded, and its tooltip is hidden behind the reply section.
5. Reload the page — the issue disappears.

**Expected behavior**
The "Likes" button should maintain normal opacity, and the tooltip should remain visible and properly layered above any replies without requiring a page reload.

**Screenshots**

 

**Desktop (please complete the following information):**

* OS, version: macOS Sequoia version 15.6.1
* Browser: Version 141.0.7390.108 (Official Build) (x86_64)

**Additional context**
This seems related to the DOM re-render or z-index layering after posting a reply. The styles for the like button and tooltip may not be re-applied or updated correctly after the comment section refreshes dynamically.
