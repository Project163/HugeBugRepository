Title

gui: Warning "path is a subdirectory of other folder" persists between dialogs

Description
Seen in ubuntu firefox
Starting to create a new share, then giving a path through a yet shared one the warning (string 139) triggers OK. Then cancelling the creation and immediately starting a new creation, the warning still shows even though the path is empty. The warning definitively disappears OK when typing / ~ or double-clic the path field... until we type again a path through an existing share path, which is OK.

Seems to be some variable not reset by Close button. Same issue when validating with Save.
