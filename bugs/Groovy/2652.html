Title

CLONE -JavaStubGenerator doesn't generate annotations available in Groovy code - More Tests required

Description
We made some progress on the original issue   GROOVY-4118   and so we closed it for the 1.7.3 release. This issue captures remaining work, primarily some additional test cases. 
 
 Looking at org.codehaus.groovy.tools.javac.JavaStubGenerator ( [URL] I see it doesn't generate annotations that are originally available in Groovy sources. 

 I think it causes those issues later: 
 
	  [URL] - "GMaven: generateStubs generates stubs without original Javadocs or annotations" 
	  [URL]  - "GMaven: Stub generation should generate annotations" 
 

 I'm trying to use AnnoMojo annotations ( [URL] when developing my MOJOs in Groovy. 
GMaven's "generateStubs" goal doesn't produce Java sources with original AnnoMojo annotations
Discussion
- What is the status of parameter annotations? This has implications for some of the JAX-RS tooling which I work with daily. 

 A simple example for clarity's sake: 
  
 @Path("/myURL/{pathVariable}")
public Response getView(@PathParam("pathVariable") String pathVariable) {
    // ...
}
 
  

 Here the  @Path  annotation makes it to the stub just fine, but not the  @PathParam .
- OK, I added support for keeping Parameter annotations in stubs. I think that covers all of the use cases discussed in this issue. If any more use cases are found, please open a new issue with details.
