Discussion
- Quick update on this. I debugged into the ngcc processing and found that the problem is when the `TypeScriptReflectionHost` tries to find the declaration of `Observable` which is exported from the `@apollo/client/core` package.

And this `Observable` being exported is actually declared as a global:

```
ts
import Observable from 'zen-observable';
import 'symbol-observable';
export declare type Subscription = ZenObservable.Subscription;
export declare type Observer  = ZenObservable.Observer ;
... [Log Snipped] ...
}
export { Observable };
```

The result if this is that instead of a valid declaration being returned, we get an `unknown` symbol.

I guess that ngcc should handle this somehow...
