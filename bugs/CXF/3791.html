Title

ClientRequestContext#getConfiguration always return null in the MicroProfile RestClient

Description
Calling ClientRequestContext#getConfiguration inside of a Filter when using the MicroProfile RestClient always return null, making it impossible to access properties set on the RestClientBuilder inside ClientRequest/ResponseFilters. 

  To reproduce:  
  
 
@Path("")
 public   interface  GreetingClient {
    @GET
    Response greet();
}

 public   static   class  Filter  implements  ClientRequestFilter {
    @Override
     public  void filter(ClientRequestContext requestContext) {
         System .out.println(requestContext.getConfiguration().getProperty( "foo" ));
    }
}

RestClientBuilder.newBuilder()
        .baseUri(URI.create( "http: //localhost:8080" ))
         .property( "foo" ,  "bar" )
        .register(Filter.class)
        .build(GreetingClient.class)
        .greet();
