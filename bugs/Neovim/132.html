- @teto I think the easiest way to reproduce this phenomenon is to `:call nvim_input(' ')`. If xterm is installed, I think it can be reproduced by typing `alt+р (U+440)`  in nvim on xterm started with `xterm -xrm 'xterm*VT100.metaSendsEscape: true'`. I think the input for `alt+р (U+440)` is Russian keyboard layout and the actual keys are `alt+r` or `alt+h`. I couldn't find a setting in kitty that would send an alt key to the application. However, if you set `map alt+h send_text all \x1b\u0440` in kitty.conf, you can reproduce the phenomenon with `alt+h` input regardless of the keyboard layout.
