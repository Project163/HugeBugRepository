Title

Wrong position of fullscreen window on secondary monitor

Description
Under OS X 10.10.5, with the current (master) version as well as 3.1.2, fullscreen windows created on secondary screens are placed at an incorrect vertical location.
Depending on how the secondary monitor is placed relative to the primary in the extended desktop settings from the monitor system preferences, the fullscreen window is placed either too high or too low (and the desktop is below or above). This is probably a mistake due to the way OS X reports screen locations (top-left corner relative to the top-left corner of the primary screen).
