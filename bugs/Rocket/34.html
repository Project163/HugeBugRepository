Title

Display of a uri::Origin does not have "=" in query values escaped

Description
I am using something like the following code to compute URIs in my application:
```
rust
let page = uri!(run_action: signed_action = &signed_action);
let absolute_uri = format!("{}{}", config.root_uri, page);

// Further down
... [Log Snipped] ...
    config: State 
) -> Result 
```
In this case, `signed_action` is a string ending in `=` (it is base64 encoded).  `=` needs to be escaped in queries, but it is not: The result of `absolute_uri` above is
```
[URL]
```
Notice the unescaped `=` at the end.  Clicking that link ends up not working, rocket says `Missing required query parameter 'signed_action'.`.

I am using Rocket 0.4.0 on Debian testing.
