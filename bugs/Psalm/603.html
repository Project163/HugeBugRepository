Title

Annotation doesn't work on throw-statements

Description
Consider the variable `$lastException` of type `\Exception|null`..
I'm sure that the variable at a certain point can only contain an `\Exception`, so I want to use annotation:

``/** @var \Exception $lastException */``
``throw $lastException;``

This appears to be doing nothing at all (tested on versions 1.1.9 & 3.4.7):

The only way around this I could think of was to either use `/** @psalm-suppress InvalidThrow */` to suppress the false-positive or to insert another assignment like this:

``/** @var \Exception $lastException */``
``$lastException = $lastException;``
``throw $lastException;``

Both do the trick, but neither is really a solution if you ask me..
