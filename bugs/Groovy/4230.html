Discussion
- When processing this line within  CompileStack#clear : 
  
 
mv.visitLocalVariable( " this " , className,  null , thisStartLabel, thisEndLabel, 0);
- You can debug your gradle build by adding this to your build.gradle: 
  
 
tasks.withType(GroovyCompile) {
  groovyOptions.fork =  false 
}
 
  

 Then run gradle with additional command line arguments: 
  
 
-Dorg.gradle.debug= true  --no-daemon
 
  

 You can attach a remote debugger on port 5005.  You want to set a breakpoint within  CompileStack#clear  at the line mentioned above.  Best to make it a conditional breakpoint looking for  className ,  thisStartLabel  or  thisEndLabel  null.
