Title

build.gradle should be x86_64 instead of x86-64

Description
## 🐛 Bug Report
A typo in build.gradle under android/app/ folder causing x86_64 apk not being build.

## To Reproduce
```
abi {
    ...
    include "armeabi-v7a", "x86", "arm64-v8a", "x86-64"
}
```

## Expected Behavior
```
abi {
    ...
    include "armeabi-v7a", "x86", "arm64-v8a", "x86_64"
}
```
