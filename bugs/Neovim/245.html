### How to reproduce the issue

* have a nvim nightly from release page
* prepare ~/.local/share/nvim/treesitter/{query,query-info} -> {lua.so, lua.reversion}
* echo 'set rtp+=~/.local/share/nvim/treesitter' > ~/.config/nvim/init.vim
* create custom highlights.scm
* open a lua file
* `:lua vim.treesitter.start()`
* move arround

the highlights.cm i used `~/.config/nvim/after/queries/lua/highlights.scm`
```
;; inherits: lua

[
 "goto"
 "in"
... [Log Snipped] ...
 "local"
] @type.qualifier
```

### Expected behavior

if there are errors in my custom highlights.scm, nvim can give reasonable errors.

nvim will pour errors in the current buffer, seems like virtual texts; sometime nvim coredumps
