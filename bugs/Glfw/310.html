Title

glfwGetVideoMode documentation is incorrect

Description
However, if I disconnect monitor before calling this function, the returned mode is not NULL but is all zeroes. That is on Windows 10.
Discussion
- I just confirmed this bug on `Windows 10 Version 2004 (OS Build 19041.572)`. Though I'm not sure how `GLFW` should handle this, the bug can be found here:

[URL]

**Return value is not checked**, and it's just happens to be that it returns `FALSE` just after the monitor has been disconnected. I verified this with device name `"\\\\.\\DISPLAY1"`.
```
EnumDisplaySettingsW(monitor->win32.adapterName, ENUM_CURRENT_SETTINGS, &dm);

mode->width  = dm.dmPelsWidth; // Will be zero
mode->height = dm.dmPelsHeight; // Will be zero
```
