Title

Unquoted relative URLs are broken if absolute path contains parens

Description
1. Grab this Gist: [URL]
2. Place in a folder whose name contains ()s -- e.g. "test(2)"
3. Place LESS .js file in the same folder
4. Open index.html

**Expected:**
Both divs have a green border.  One style comes from the LESS file, the other comes from the CSS file which is imported by the LESS file.

**Actual result:**
Only the first div has a green border.  The imported CSS file is never loaded, so only the styles in the LESS file are applied.

The problem is apparent if you look at the generated CSS output:

``` css
@import url(file:///C:/code/test(2)/included.css);
```

The relative -> absolute URL conversion added text containing the parens, which are not allowed unless they're escaped or the whole URL is wrapped in quotes.  From [URL]

**Workaround:**
In the original LESS source, wrap the relative URL in quotes: `@import url("included.css");`.  This will cause the generated CSS code to also use quotes.
