Title

NPE in SnapshotsService in 1.4.2

Description
I keep getting the same NPE when performing snapshots in 1.4.2:

```
java.lang.NullPointerException
    at org.elasticsearch.snapshots.SnapshotsService.shards(SnapshotsService.java:1195)
    at org.elasticsearch.snapshots.SnapshotsService.access$800(SnapshotsService.java:88)
    at org.elasticsearch.snapshots.SnapshotsService$2.execute(SnapshotsService.java:300)
    at org.elasticsearch.cluster.service.InternalClusterService$UpdateTask.run(InternalClusterService.java:329)
... [Log Snipped] ...
    at java.util.concurrent.ThreadPoolExecutor$Worker.run(ThreadPoolExecutor.java:617)
    at java.lang.Thread.run(Thread.java:744)
```

The line in question is:

`IndexRoutingTable indexRoutingTable = clusterState.getRoutingTable().index(index);`

clusterState isn't null because it's successfully dererenced above.  So that leaves getRoutingTable().  Any ideas as to why that would return null?
