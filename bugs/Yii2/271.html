Title

message/extract command works incorrect with .po files

Description
Hi. I've discovered two issues with `message/extract` command when working with `.po` files in `MessageController::saveMessagesToPO()` method.
##### Translation files are not updated when translation messages are updated (without adding or deleting new entries)

For example. Lets assume we have a `Yii:t()` call: `Yii:t('category', 'some message')`.
We generate initial translation files with `message/extract` command. After that we want to change `Yii:t('category', 'some message')` to `Yii:t('category', 'some new message')`. After change we run `message/extract` command again, but translation files will not be updated.

I think the reason is here ([Link: MessageController.php#L422-L425]):

``` php
if (array_keys($existingMessages) == $msgs) {
    echo "Nothing new... skipped.\n";
    return self::EXIT_CODE_NORMAL;
}
```

While this is able to find difference between arrays:

``` php
if (!array_diff(array_values($msgs), array_keys($existingMessages))) {
    echo "Nothing new... skipped.\n";
    return self::EXIT_CODE_NORMAL;
}
```
##### Incorrect handling of multiple messages categories

The same code snippet  ([Link: MessageController.php#L422-L425]):

``` php
if (array_keys($existingMessages) == $msgs) {
    echo "Nothing new... skipped.\n";
    return self::EXIT_CODE_NORMAL;
}
```

has another bug in `return self::EXIT_CODE_NORMAL;`. It should not do this because it breaks work with multiple messages categories.
For example, we have three categories: `messages`, `attributes` and `general`. Lets say we updated our code and have changed `Yii:t()` calls with `messages` and `attributes` categories. Now let's see what `MessageController::saveMessagesToPO()` method will do (as there are a `foreach` at [Link: MessageController.php#L414]):
1. It will find changed messages in `messages` category and print `Translation merged`.
2. It will find changed messages in `attributes` category and print `Translation merged`.
3. It will not find changed messages in `general` category
