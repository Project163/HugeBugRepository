Title

Wrong data type for date fields in entities returned in _matchingData array (CakePHP v3.2.*)

Description
Rows/entities returned in _matchingArray() have date fields in correct type in CakePHP v3.1.10 but in v3.2.x not. See example below.

I am using PHP v5.5.11

Example (read the comments):

```
php
// Executed query:

$subquery = $this->pdfDocumentsPubTable
  ->find()
... [Log Snipped] ...
      }
  );
```

```

... [Log Snipped] ...
    }
]
```

```
php
// Results (for CakePHP v3.1.10):

[
    (int) 0 => object(App\Model\Entity\PdfPlace) {
... [Log Snipped] ...
    }
]
```
