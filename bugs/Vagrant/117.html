Title

`vagrant validate` fails when not in Vagrant environment

Description
When `vagrant validate` is run in a directory that doesn't contain a `Vagrantfile`, a cryptic stack trace is displayed instead of a helpful error message (e.g. "A Vagrantfile couldn't be found in the current directory")

Perhaps, [Link: `vagrant validate`] should check for a `Vagrantfile` before running validation.

### Vagrant version
1.9.6

### Host operating system
Issue found on CentOS 7 or Windows 10

### Debug output
[URL]

### Expected behavior
The `NoEnvironmentError` should have been raised or a helpful error message should be printed.
