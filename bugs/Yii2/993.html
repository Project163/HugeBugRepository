Title

\yii\base\Model::getErrorSummary reverse order

Description
### What steps will reproduce the problem?
```php
echo Html::errorSummary($model, [
	'showAllErrors' => true,
]);
```
### What is the expected result?
errors in order as in validators
### What do you get instead?
reverse order

### Additional info
getErrorSummary merge old to new, not new to old
```php
$lines = array_merge((array)$es, $lines);
```
