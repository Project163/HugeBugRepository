- This still seems broken for me as well, though I'm having a difficult time determining what commit I'm on since I am using the Ubuntu repo and `nvim --version` just returns `NVIM v0.2.1-dev` for me.
- Same here, ~adding `TERM=xterm-256color neovim` "fix" it.~

- Older tmux releases didn't have their own terminfo entry, so you _did_ have to use a variant of `TERM=screen`, of which `TERM=screen-256color` is the one to use to indicate support for more colors.  With contemporary tmux/terminfo, you should use `TERM=tmux-256color`, but `TERM=screen-256color` is still viable.
- The only thing that worked for me was `tmux set-option -ga terminal-overrides ",xterm-256color:Tc"`. I use alacritty and `$TERM` is set to `xterm-256color`, tmux version is 2.6, neovim version 0.2.0 from pacman. None of the other proposed solutions worked for me. I could use `tmux` or `tmux -2`, set different `$TERM` values in alacritty and/or tmux, only the above mentioned line fixed the color issue *for me*
