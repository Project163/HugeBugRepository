Title

create table + reflection for parenthesis around server defaults that contain spaces, all DBs

Description
### Describe the bug

When using `metadata.reflect` on a sqlite3 table with a "_timestamp_" column defined as:
`timestamp DATETIME NOT NULL DEFAULT (datetime(CURRENT_TIMESTAMP, 'localtime'))`
the resulting metadata is:
`datetime(CURRENT_TIMESTAMP, 'localtime')`
without the surrounding parentheses and 
`metadata.create_all(engine)`
will fail.

Discussion
- defaults of this form, e.g. with spaces, seem to have problems at different points with different dialects and I would like to ensure that normalization of parenthesis occurs only one side (where "sides" means, rendering of DDL vs. reflection side) consistently for all built in backends.    so I've assembled a suite to illustrate where we are at at this moment and it looks like both Sqlite and MySQL can use improvements cc @CaselIT

so we can see here mysql has the biggest problem since the regex isn't even getting the whole default.  the sqlite dialect does seem to have an "add parenthesis to the default during DDL rendering" feature at least when a non-text default is sent, so we probably want to extend that for a textual default as well.  same idea should be applied to mysql and we need to have a dialect suite test for this.
