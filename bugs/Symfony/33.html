I did today the investigation and found the reason.

The segmentation fault causes one line in file:
vendor/symfony/src/Symfony/Component/HttpKernel/Controller/ControllerResolver.php
Line number: 63
The code which causes the segmentation fault: method_exists($controller, '__invoke')
The $controller is: Acme\DemoBundle\Controller\WelcomeController::indexAction

The problem doesn't occur, when I change the code to:  method_exists(substr($controller, 0, strpos($controller, '::')), '__invoke')

The added code drops the ::indexAction from $controller.
