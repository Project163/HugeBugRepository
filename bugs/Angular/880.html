Title

Problem in Angular "my-app" instructions in Windows, try #2

Description
# 📚 Docs or angular.io bug report

### Description

On web page [URL] there are instructions

```
Open ./src/app/app.component.ts. 
Change the title property from 'my-app' to 'My First Angular App'.
```

On Windows this fails because the example was created by default (following instructions) in folder C:\Windows\System32\my-app, which cannot be written because it is in the protected Windows directory tree.

Discussion
- When a command line dialog box is created in Windows, the initial folder is set to C:\Windows\System32, a protected system folder. There were no instructions to change to a different folder. In fact, the instructions **actually created the Angular example in C:\Windows\System32**, which is a very bad practice.
- AFAIK this is only the default cwd if you start the terminal with administrator rights — which definitely is a bad idea (and not suggested by the docs).

Nonetheless, it probably wouldn't hurt to add a hint that the command will create a folder in the cwd and that the user should first cd to whichever location they prefer first.
