Title

Bazel runs tests in a sandbox even with "local = 1"

Description
In our documentation, we say that when you set the "local = 1" attribute on a test, the test will run without sandboxing. This is supposed to be equivalent to setting the "tags = ['local']" attribute on a test: [URL]

However, when I run this test, it actually executes in a sandbox, as seen in "ps axuf":

```
sh_test(
    name = "example_test",
    srcs = ["example_test.sh"],
    local = 1,
)
```

This test however runs without a sandbox:

```
sh_test(
    name = "example_test",
    srcs = ["example_test.sh"],
    tags = ["local"],
)
```

So, it looks like the "local = 1" logic is somehow broken. We should write a test for this behavior and then fix the bug.
