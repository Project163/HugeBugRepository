Title

no-redeclare broken when node environment is set

Description
Using ESLint v0.17.0:

```
js
// .eslintrc
{
    "env": {
        "node": false
... [Log Snipped] ...
    }
}
```

``` js
// test.js
var x = 42,
    x = 17;
```

```
$ node_modules/eslint/bin/eslint.js test.js

test.js
  2:4  error  x is already defined  no-redeclare

✖ 1 problem (1 error, 0 warnings)
```

Now when the `node` setting in `env` is changed to `true`, no error is reported. Happens in the online demo as well.
Discussion
- I just pasted this on online demo

``` .js
/* eslint-env node */
var x = 42,
    x = 17;
```

It showed the error.
- Interestingly, I was only able to repro by setting the environment in a config file, not inline.
- @btmills that might be a bug - they should work the same.
