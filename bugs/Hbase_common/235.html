Title

Deprecate Chore; its a thread per task when we should have one thread to do all tasks

Description
Should use something like ScheduledThreadPoolExecutor instead (Elliott said this first I think; J-D said something similar just now).
Discussion
- Last time I counted we have ~150 threads on a totally un-loaded region server. The number of context switches that represents is a pretty serious perf impact.
- I was thinking along the same lines when I first encountered Chore. +1
