Title

Ambiguous syntax between namespace function call and map object definition.

Description
function test() {
   return   'x' ;
}

let var1 =  'var1' ;
let x = {
  var1: test(),
   'var2' : 1
}  
  
 this code caused a parse error. 

 Looks like the reason is the parser consider `var1: test()` as a namespace function call but here I just want define a map keyed by variable. 

 Is it possible to disable 'namespace' feature to avoid this ambiguous syntax? 

 Thanks!
Discussion
- I'll look into it. As a workaround, there is a 'syntactic hint' for this case, add a space before the ':' as in '{ var1 : test() }'.
- Some people experience regressions; modules in particular declare namespaces.
- Kinda restored previous behavior by looking at the whole ns:func sequence and adding a grammar disambiguation for map entries.
