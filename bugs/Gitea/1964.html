Title

Can't overwrite package tags

Description
### Description

When uploading/publishing a container package existing tags won't be overwritten.
In my environment I have containers that build a unique and `latest` tag about every day.
Since we upgraded from `1.24.7` to `1.25.0` the date of the `latest` tag doesn't get updated anymore when we push to it.
Docker build tells it was successful.

The `latest` tag shows multiple digests instead of one:
```
sha256: 
sha256: 
sha256:
```
