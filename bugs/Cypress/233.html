Title

Cypress fails silently (no error message) after FATAL error

Description
### Current behavior

The fatal system error described in [URL] "FATAL:setuid_sandbox_host" is no longer output and Cypress fails silently.

This is a regression from Cypress `14.5.4`  

### Desired behavior

If Cypress has a fatal error causing it to exit, then Cypress should at least report that it has failed, and it should preferably also give the reason for the failure in the logs without requiring setting the environment variable `DEBUG=cypress:*`.

### Test code to reproduce

```
shell
sudo rm -rf /etc/sysctl.d/60-apparmor-namespace.conf # remove any workaround for "Unprivileged user namespace restrictions"
sudo sysctl --system
git clone [URL]
cd cypress
... [Log Snipped] ...
sudo sysctl --system
yarn start # Cypress starts
```

Now revert to last v14.x version

```
shell
git checkout v14.5.4
sudo rm -rf /etc/sysctl.d/60-apparmor-namespace.conf # remove any workaround for "Unprivileged user namespace restrictions"
sudo sysctl --system
n auto
... [Log Snipped] ...
sudo sysctl --system
yarn start # Cypress starts (with "ERROR:atom_cache.cc")
```

### Cypress Version

First reported on version: `15.0.0`  
Continues to be reproducible on: `15.1.0` b4ba15e4e9

### Node version

`v22.15.1` LTS

### Operating System

Ubuntu `24.04.3` LTS
