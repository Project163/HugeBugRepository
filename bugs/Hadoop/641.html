Title

some common testcases create core-site.xml in test-classes making other testcases to fail

Description
Some of the testcases (  HADOOP-8581  ,   MAPREDUCE-4417  ) create core-site.xml files on the fly in test-classes, overriding the core-site.xml that is part of the test/resources. 

 Things fail/pass depending on the order testcases are run (which seems dependent on the platform/jvm you are using).
