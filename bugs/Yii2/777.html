Title

Incorrect SQL query generated by dropIndex in migration

Description
### What steps will reproduce the problem?

1) In database PortgreSQL create schema myproject
2) In schema create table mytable
3) In table create fields id:PKint and category_id:int
4) create index on field category_id with name myproject_categoryid_index

5) Write migration with next code

`$this->dropIndex(‘myproject_categoryid_index’, 'myproject.mytable');`

6) run php yii migrate

### What is the expected result?

must be generated SQL with schema
so it must be like this
`DROP INDEX myproject.myproject_categoryid_index RESTRICT`

and migration executed succesful

### What do you get instead?

`$this->dropIndex(‘myproject_categoryid_index’, 'myproject.mytable');`
this line of code generate SQL:
`DROP INDEX myproject_categoryid_index`

without schema!

and when executed get error:
` > drop index myproject_categoryid_index on myproject.mytable ...Exception: SQLSTATE[42704]: Undefined object: 7 ОШИБКА:  индекс "myproject_categoryid_index" не существует`
