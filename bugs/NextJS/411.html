Basically, the problem is caused by the path separator, which is `\` in Windows and `/` in non-Windows machines. The function `fillMetadataSegment` in [Link: get-metadata-route.ts] expects the variable `segment` to be forward-slash-separated, but the case is not true on Windows machine.

I isolated the problem by directly calling the `fillMetadataSegment` function.
