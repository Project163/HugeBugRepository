Title

timeout option is not being passed through to cy.wait() command

Description
The `cy.wait()` command is intended to accept a `timeout` option that would update both the `requestTimeout` and `responseTimeout` of the xhr being waiting on, but the timeout option is never passed through the code, so never overwrites any timeout options previously set. 

**Example Code**

```
cy
  .server()
  .route(/comments\/1/).as('getComment')
  .wait('@getComment', {timeout: 2000000})
```

**Example Error still shows requestTimeout as 5000ms**
- This actually requires more thought than originally expected. Since `cy.wait` actually has a `requestTimeout` and a `responseTimeout`, it would be ideal to allow both of those options to be passed to `cy.wait`.
- `timeout` option is passed to both `requestTimeout` and `responseTimeout` since `0.17`
