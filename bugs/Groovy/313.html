Title

Resource leak in ResolveVisitor.isSourceNewer()

Description
at org.codehaus.groovy.control.ResolveVisitor.isSourceNewer(ResolveVisitor.java:296) is a resource leak: 

  
 lastMod = source.openConnection().getLastModified();
 
  

 The connection returned by openConnection() is never closed. 

 I think the solution is: 

  
 URLConnection conn = source.openConnection();
lastMod = conn.getLastModified();
conn.getInputStream.close();
Discussion
- Jochen, perhaps we could have a look at this issue to see whether we can put the fix in beta-1?
- I applied the patch to ResolveVisitor and GroovyClassLoader
