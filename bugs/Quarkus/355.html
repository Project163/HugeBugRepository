Title

ENV Variable not substituted

Description
**Describe the bug**
When I build in local with `mvn package` and run the following command:
`export MP_OPENAPI_SERVERS=[URL] java -jar target/app-1.0.0-SNAPSHOT-runner.jar`
My variable `mp.openapi.servers` is replaced.

When I do the same in a docker container from `maven:3.6.1-jdk-11-slim`
The variable in the Swagger is not replaced.

**To Reproduce**
Steps to reproduce the behavior:
```
mvn io.quarkus:quarkus-maven-plugin:0.22.0:create \
    -DprojectGroupId=org.acme \
    -DprojectArtifactId=using-openapi-swaggerui \
    -DclassName="org.acme.openapi.swaggerui.FruitResource" \
    -Dpath="/fruits" \

curl [URL] | grep servers -A1
```

... [Log Snipped] ...
