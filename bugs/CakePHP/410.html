Title

3.0 Error posting form with file

Description
Trying to upload some file in a form, I got the following problem

Form:

``` php
echo $this->Form->create(null, ['type' => 'file']);
echo $this->Form->file('file_to_upload');
echo $this->Form->input('comments');
echo $this->Form->submit('Upload');
echo $this->Form->end();
```

The request data array contain

```
[
    'comments' => 'testing',
    'name' => [
        'file_to_upload' => 'test.xlsx'
    ],
... [Log Snipped] ...
    ]
]
```

As you see, the input file does not appear in the array, instead appear name, type, file etc. the expected result should be something like

```
[
    'comments' => 'testing',
    'file_to_upload' => [
        'name' => [
            'file_to_upload' => 'test.xlsx'
... [Log Snipped] ...
    ]
]
```
