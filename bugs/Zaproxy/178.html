Title

Issue when attempting to ignore all rules for a URL

Description
I have created a config_file and can successfully ignore explicit rules for a url:

    #####  OUTOFSCOPE  [URL]

But WARNs are not being ignored when I use the asterisk wildcard in place of an explicit rule number:

    *  OUTOFSCOPE [URL]

Any ideas on what I might be doing wrong? Here is how I am running the scan:

    docker run -v ${PWD}:/zap/wrk --net=host -i owasp/zap2docker-weekly:latest zap-baseline.py -t [URL] -c zap_config
Discussion
- Can you provide the contents of your config file for the problem scenario?

Ref: [URL]
- ```
# zap-baseline rule configuration file
# Change WARN to IGNORE to ignore rule or FAIL to fail if rule matches
# Only the rule identifiers are used - the names are just for info
# You can add your own messages to each rule by appending them after a tab on each line.
10010	WARN	(Cookie No HttpOnly Flag)
... [Log Snipped] ...
*	OUTOFSCOPE	[URL]  
#10202	OUTOFSCOPE	[URL]
```
When I uncomment the the line with the rule number, the rule is successfully ignored for the url.
But when running the config file as shown above (with the asterisk) the rule is not ignored for the url.
