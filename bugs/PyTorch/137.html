Title

Segmentation fault (core dumped) in `torch.bincount`

Description
### 🐛 Describe the bug

A crash will be triggered when torch.bincount handles a large tensor.

minimal example:
```
import torch

input = torch.tensor([2 ** 63 - 1], dtype=torch.int64)  
result = torch.bincount(input)
```

output:
```
Segmentation fault (core dumped)
```
