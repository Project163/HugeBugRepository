Title

A Segmentation Fault can be trigerred in torch.nn.utils.rnn.pack_padded_sequence

Description
### 🐛 Describe the bug

A **Segmentation Fault** can be trigerred in `torch.nn.utils.rnn.pack_padded_sequence` with the following code:

````python
import torch
input = torch.rand([0, 14,  ], dtype=torch.float32)
lengths = torch.rand([11, 14, 14, 2], dtype=torch.float32)
batch_first = True
torch.nn.utils.rnn.pack_padded_sequence(input, lengths, batch_first)
````

Output:
````
Segmentation fault (core dumped)
````
