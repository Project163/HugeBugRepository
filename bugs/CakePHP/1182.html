Title

Using BehaviorRegistry::set() does not populate _methodMap and _finderMap

Description
### Description

I may be missing something but while working on a test case that requires to mock a behavior, I am doing:

```
$behaviorMock = ....
$behaviorMock->expects(...
$MyModel->behaviors()->set('BehaviorName', $behaviorMock);
```

The thing is that `load` method populates _methodMap and _finderMap but set does not so when trying to call a behavior method through the model:

```
$MyModel->behaviorMethod()
```

I get `Unknown method error`.

I have no problem working on this but I would like to confirm if it is actually an issue or if I am doing something wrong.

I have not confirmed if the issue is present on CakePHP 5 but according to a quick look at the code it should be the same.
