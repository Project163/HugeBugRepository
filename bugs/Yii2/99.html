Title

Not working debug module

Description
I have problem, after setupe bace application, I turn debug module, but it is not works. I have error massage: "Not Found (#404): Unable to find debug data tagged with '52aade643146f'."
Discussion
- Make sure PHP can write to `runtime` directory of your application.
- PHP can write to runtime folder, I create screenshot with explanation -  [URL]
- ... [Middle Discussions Snipped for Brevity] ...
- I've just encountered this issue on a vagrant setup with xdebug with the latest release. The debug/default/toolbar request was responding with a 404. After a bit of a dig it appears that if you have xdebug.scream turned on no .data files are written to the debug directory. I turned off scream and it works perfect. Just a heads up in case someone else has this issue. 

Here's my working xdebug.ini:

```
[xdebug]
zend_extension=xdebug.so
xdebug.remote_enable = 1
xdebug.remote_connect_back = 1
;xdebug.scream=1
xdebug.remote_port = 9000
```
