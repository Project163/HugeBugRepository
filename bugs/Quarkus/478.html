Title

Constructor Injection in secured JAX-RS resources leads to exception

Description
**Describe the bug**
Constructor Injection in secured (`@Authenticated`) JAX-RS resources leads to exception.

**Expected behavior**
Constructor Injection should also work for secured JAX-RS Resources. 

**Actual behavior**
```
java.lang.RuntimeException: RESTEASY003190: Could not find constructor for class: bar.foo.AuthorizedMyResource
```

**To Reproduce**

```
java
@Authenticated
@Path("/secured")
public class AuthorizedMyResource {

... [Log Snipped] ...
  }
}
```

```
java.lang.RuntimeException: RESTEASY003190: Could not find constructor for class: de.volkswagen.trackandtrace.scanning.web.rest.AuthorizedScanningResource
        at org.jboss.resteasy.spi.metadata.ResourceBuilder.getConstructor(ResourceBuilder.java:852)
        at org.jboss.resteasy.plugins.server.resourcefactory.POJOResourceFactory.registered(POJOResourceFactory.java:58)
        at org.jboss.resteasy.core.ResourceMethodRegistry.addResourceFactory(ResourceMethodRegistry.java:247)
        at org.jboss.resteasy.core.ResourceMethodRegistry.addResourceFactory(ResourceMethodRegistry.java:228)
... [Log Snipped] ...
        at io.netty.util.concurrent.FastThreadLocalRunnable.run(FastThreadLocalRunnable.java:30)
        at java.base/java.lang.Thread.run(Thread.java:834)
```

But Field Injection works as expected for secured resources:

```java
@Authenticated
@Path("/secured")
public class AuthorizedMyResource {

  @Inject
  myService service;
}
```

**And Constructor Injection even works as expected for unsecured resources:**

```
java
@Path("/unsecured")
public class MyResource {

    private final MyService service;
... [Log Snipped] ...
      this.service = service;
    }
```

**Environment:**
- Quarkus Framework 1.2.1.Final
- GraalVM CE 19.3.1
