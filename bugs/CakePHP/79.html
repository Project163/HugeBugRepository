Title

3.0 Error in Paginator counters (format:range)

Description
I'm using the following statement in the view

``` php
  Paginator->counter(['format' => 'range']); ?>
```

and the result is:

```
1 - 0 of 43
```

when expect something like

```
1 - 20 of 43
```

the paging works fine, but the counter is always the same.

In the controller

``` php
$entities = $this->Paginate();
```

using default pagination settings

Debuging the request I can see the param limit is always null, however the pagination works fine.
