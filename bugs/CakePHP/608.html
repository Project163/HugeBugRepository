Title

3.0 RC1 - Invalid dates changed

Description
If a user enters an invalid date in a date field (eg 31 Feb), it correctly fails validation with rule:
      ->add('date_of_birth', 'valid', ['rule' => 'date'])

However, when the form is displayed again with the error, it has changed it to 3 March (or 2nd if it's a leap year). The object should contain the original, invalid date.
