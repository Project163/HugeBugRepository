Title

Mongo client config host list should have explicit default

Description
**Describe the bug**
In order to get #5387 to pass, I had to change `MongoClientConfig#hosts` to be optional.  It would be better to give it an explicit default value so that it appears in documentation, and it should not be optional, so that if no host value is given (i.e. if the default value is overridden with an explicitly empty value), a validation error is automatically raised.
