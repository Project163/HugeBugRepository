Title

Error in the Console when running a GroovyTestCase 2 times.

Description
I do not know if we should run twice a test in GroovyConsole, but when we do it the interrupt msgbox stays there and it is not possible to close it. 

 To reproduce the error. Open the console in Ubuntu 8.10 (I have no idea if this happens in other environments)  

 Execute the following test case: 
  
  import  groovy.util.GroovyTestCase

 class  AnyTest  extends  GroovyTestCase {

    void testAssertAnyStuff() {
        assertEquals  "1" ,  '1' 
    }
}
 
  

 It runs ok. 

 Then run again, the window to interrupt the script does not close, even if we press "Interrupt"
