Title

intermittent failures of the failover related QueueBrowser* tests

Description
The failover related tests sometimes fail because the java 0-10 client is acknowledging messages received from a prior session, and these sometimes fall outside the range of messages that have been sent on the new session. When this happens an assertion failure is triggered on the C++ broker. The java client needs to be fixed to pause failover until all the messages from old sessions have been processed.
