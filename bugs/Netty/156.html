Title

register0 sets ChannelPromise to success too early

Description
I had an error where fireChannelRegistered throws an exception (initHeadHandler failed) but then I got this exception:

java.lang.IllegalStateException: complete already
        at io.netty.util.concurrent.DefaultPromise.setFailure(DefaultPromise.java:385)
        at io.netty.channel.DefaultChannelPromise.setFailure(DefaultChannelPromise.java:86)
        at io.netty.channel.AbstractChannel$AbstractUnsafe.register0(AbstractChannel.java:623)

I think promise.setSuccess should be moved until after fireChannelActive()
Discussion
- BTW, this causes a memory leak as promise.setFailure(t) throws an exception so closeFuture.setClosed() is never called. Since this isn't called, the channel is not removed from the allChannels map in AbstractChannel.
- Also do we need a fireChannelInactive if fireChannelActive throws an exception?
- ... [Middle Discussions Snipped for Brevity] ...
- So maybe we need to break up the try-catch into multiple blocks.
