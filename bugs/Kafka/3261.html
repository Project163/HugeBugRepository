Title

Memory Leak When Logging Is Disabled In InMemoryTimeOrderedKeyValueBuffer

Description
If `loggingEnabled` is false, the `dirtyKeys` Set is not cleared within `flush()`, see  [URL] However, dirtyKeys is still written to in the loop within `evictWhile`. This causes dirtyKeys to continuously grow for the life of the buffer.
