Title

picocli does not register defaultValueProvider references thus breaks in native

Description
### Describe the bug

Have something like:

```
@CommandLine.Command(name = "starfix", mixinStandardHelpOptions = true, defaultValueProvider = YAMLDefaultProvider.class)
```
