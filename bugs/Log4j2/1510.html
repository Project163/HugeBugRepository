Title

wrong documentation for logging with Level.OFF

Description
The documentation states that log events of level OFF should never be logged, whereas level ALL should always be logged.  
See the last table in section "LoggerConfig" here:  [URL]

 In fact the opposite is the case.  
The following statement in combination with the default configuration leads to a log entry. 
  
 
LogManager.getLogger().log(Level.OFF,  "test" );
Discussion
- This is logically equivalent to the behavior described in   LOG4J2-3151   and  LOG4J2-2174 .  
 Thus, I am aware of the logic in the internal filter method. The documentation, on the other hand, put me on the wrong track of how to use the levels.
- As stated in   LOG4J2-3151  , we are aware of this shortcoming of the documentation and PRs improving this state are more than welcome.
