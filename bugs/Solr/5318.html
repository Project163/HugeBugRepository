Title

BALANCESHARDUNIQUE with `preferredLeader` sets property for PULL nodes

Description
The `preferredLeader` property can be set using the collection admin BALANCESHARDUNIQUE action. However if you run this on a cloud in a TLOG/PULL configuration, PULL nodes are also included in the balancing distribution. This seems to be an incorrect behavior as PULL nodes can never be elected leader. 

 For `preferredLeader` property, only NRT/TLOG nodes should be considered
