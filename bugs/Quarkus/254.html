Title

Some integration tests don't run by default, but have no docs to explain how to run them

Description
I had a hard time finding how to run the `reactive-pg-client` integration test, because tests are skipped by default. Turns out I needed the `-Dtest-postgresql` flag. Some tests have a `README.md` but not most:

```
integration-tests/amazon-dynamodb/README.md
  integration-tests/jpa-mariadb/README.md
  integration-tests/jpa-mssql/README.md
  integration-tests/jpa-postgresql/README.md
  integration-tests/jpa/README.adoc
  integration-tests/keycloak/README.md
  integration-tests/neo4j/README.md
```

The following seem to have ` true` in their build, so might be disabled by default too (need to check) and have no `README`:

- integration-tests/hibernate-search-elasticsearch
- integration-tests/infinispan-client
- integration-tests/mongodb-client
- integration-tests/reactive-mysql-client
- integration-tests/reactive-pg-client
