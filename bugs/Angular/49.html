Title

Definition of Query does not work in d.ts file (alpha 30)

Description
Using Query from the d.ts file results in this error:

```
Error   TS2348  Value of type 'typeof Query' is not callable. Did you mean to include 'new'?
```

The file currently contains these (seemingly dupllicate) definitions:

```
typescript
class QueryAnnotation extends DependencyAnnotation {
        descendants: boolean;
        selector: void;
        isVarBindingQuery: boolean;
... [Log Snipped] ...
        toString(): string;
}
```

After adapting the d.ts file to have:

``` typescript
var Query: any;
```

and removing the above Query class the annotation works as expected...

Another issue can be seen here:

```
typescript
class BaseQueryList  {
        reset(newList: any): void;
        add(obj: any): void;
        fireCallbacks(): void;
... [Log Snipped] ...
        last: void;
}
```

The length, first and last properties are declared as void, I also constantly need to adapt these to have working code :)
