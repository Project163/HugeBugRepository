Title

Sets are not sequence_like

Description
# Bug

Output of `python -c "import pydantic.utils; print(pydantic.utils.version_info())"`:
```
             pydantic version: 1.4
            pydantic compiled: True
               python version: 3.7.1 (default, Dec 14 2018, 19:46:24)  [GCC 7.3.0]
                     platform: Linux-4.4.0-173-generic-i686-with-debian-stretch-sid
     optional deps. installed: ['typing-extensions']
```

```
py
# model.py
from pydantic.dataclasses import dataclass
from typing import Sequence

... [Log Snipped] ...
print(Model({1, 2}))
print(Model(frozenset({1, 2})))
```
Running mypy on `model.py` correctly reports 2 errors:
```
model.py:8: error: Argument 1 to "Model" has incompatible type "Set[int]"; expected "Sequence[int]"  [arg-type]
model.py:9: error: Argument 1 to "Model" has incompatible type "FrozenSet[int]"; expected "Sequence[int]"  [arg-type]
Found 2 errors in 1 file (checked 1 source file)
```
Pydantic however doesn't; additionally it converts the frozenset to list while it preserves the set:
```
Model(list_of_ints={1, 2})
Model(list_of_ints=[1, 2])
```

- This is resolved in V2:

```
from typing import Sequence

from pydantic.dataclasses import dataclass


... [Log Snipped] ...

```

They'll be a conversion table for V2 that details this.
