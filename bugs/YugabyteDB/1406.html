Title

[YSQL] create temp table with ON COMMIT DROP fails with ERROR: Transaction for catalog table write operation 'pg_type' not found

Description
Jira Link: [Link: DB-16848]
### Description

I tried to run the following create temp table query with ON COMMIT DROP  , Failed with 

`ERROR:  Transaction for catalog table write operation 'pg_type' not found`

```
rr=# CREATE TEMP TABLE t3 (
    id INT
) ON COMMIT DROP;
CREATE TABLE
ERROR:  Transaction for catalog table write operation 'pg_type' not found
rr=# \d t3;
Did not find any relation named "t3".
```

One more observation ->  the temp table gets created even when we get an error, but only if a other temporary table has already been created/present  in the session . In the above case it is not created since there is no other temp table in the session.

```
yugabyte=# create temp table temp_table (i int);
CREATE TABLE

yugabyte=# 
yugabyte=# CREATE TEMP TABLE t3 (
... [Log Snipped] ...
yugabyte=# insert into t3 (id) values (100);
ERROR:  could not open file "base/13263/t1_16407": No such file or directory
```
