Title

PluginUnloadCommand removing extra non empty line

Description
This is a (multiple allowed):

* [x] bug

* CakePHP Version: dabb56c latest master
* Platform and Target: n/a.

### What you did
use `bin/cake plugin load PluginName` (refers to PluginLoadCommand from core)
Manually add `$this->addPlugin('OtherPlugin');` in very next line after added by `plugin load` `$this->addPlugin('PluginName');`
use `bin/cake plugin unload PluginName` (refers to PluginLoadCommand from core)

### What happened
both lines were removed

### What you expected to happen
removed `$this->addPlugin('PluginName');` only
