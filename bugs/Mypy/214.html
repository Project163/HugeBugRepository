Title

Invalid type comment in Python 2 may crash with fast parser

Description
This crashes when checked in Python 2 mode with the fast parser:

```
from typing import Sequence

def f(a):
  # type: (Sequence(int)) -> int
  pass
```

(The error is that it uses `()` instead of `[]` for the generic type.)

I also have a fix ready.
