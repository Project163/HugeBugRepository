Title

Java client 0-8..0-91 sends queue.delete with nowait true but then awaits a reply

Description
The Java Client sends AMQP queue.delete with  nowait  hard-coded true, but then awaits a queue.delete-ok reply anyway.  This defect is transparent with the Java Broker since the Broker sends the queue.delete-ok regardless of the setting of the nowait flag. 

 This defect shows up when inter-operating against the RabbitMQ, which respects the  nowait  flag. 

 This behaviour is longstanding.
