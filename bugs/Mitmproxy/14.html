- Thanks for the feedback.
I just took quick a look at the BDFProxy code - neat stuff! I think the inline script approach would work pretty well for you, but that alone is of course no reason to rewrite your code. However, keep in mind that the master is single-threaded, so when handle_response blocks because it patches a binary, all traffic through the proxy is paused. I don't know how fast your patching method is, but if speed tends to become an issue, you should reconsider using inline scripts (with `@concurrent`) again. :-)
