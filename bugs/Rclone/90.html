Title

Moving a remote file deletes it

Description
This command with rclone 1.30 on Windows XP with Google Drive:

  `rclone move remote:/test/file1.txt remote:/test/file2.txt`

will delete `file1.txt` and replace it with a folder named `file2.txt`.  `file1.txt` is nowhere to be found after this operation.

It would appear that the move command was never meant to be used on files.  But such an outcome is really not desirable. A warning would be better.
