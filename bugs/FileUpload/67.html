Description

Discussion
- In r1638215 I have added a unit test based on the example in  [URL] section 6, Examples, which shows that fileupload already supports this. 

 I close this ticket as invalid, as the referenced rfc clearly states that any part of a multipart/form-data is expected to have a content-disposition set to "form-data" (section 7). If multiple files are uploaded, a multipart/mixed part can be used to group them together, in which case other dispositions can be used, as outlined in the example.
