Title

Having a custom relation and a parent/child relation at the same time causes panics on despawn

Description
## Bevy version

0.16-rc5

## What you did

I tried to add a relation between entities that are also parent / child of each other. My goal was to remove the need of iterating children looking for marker components.

```
rust
// The relationship declaration
#[derive(Component)]
#[relationship(relationship_target = HairOf)]
pub struct HasHair(Entity);
... [Log Snipped] ...
// later in a system
commands.despawn(character_entity);
```

## What went wrong

It panicked with the following:

```
Encountered an error in command ` ::on_replace::{{closure}} as bevy_ecs::error::command_handling::CommandWithEntity >>::with_entity::{{closure}}`: The entity with ID 97670v1 was despawned by .cargo\registry\src\index.crates.io- \bevy_ecs-0.16.0-rc.5\src\relationship\mod.rs:255:21
```
Discussion
- Added it to 0.16.1 since this seems like a very common use-case
