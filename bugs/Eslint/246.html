Title

computed key marked duplicate

Description
``` js
var x = "y";
var z = {
  x: x,
  [x]: x
};
```

```
  2:8  error  Duplicate key 'x'  no-dupe-keys

✖ 1 problem
```

is this by design?
Discussion
- In this context it's a bug, because you're creating a property called "y", so it's not a duplicate. If you did this it would be a valid error:

``` js
var z = {
    x: x,
   ["x"]: x
}
```
