Title

Remove git requirement for gradle build

Description
Currently the source release cannot be built with  gradle assemble  or checked with  gradle check  since the ref-guide tasks require the solr directory to be a git repository. 

 The easy way to fix this is to not include the ref-guide tasks if the root directory doesn't contain the  .git/  directory.
