Title

[ERROR] Error fetching link: %{project.basedir}/target/javadoc-bundle-options. Ignored it.

Description
Not sure whether this is a bug or a something missing my side. 

 Using the javadoc plugin with maven 3.6.2 and JDK 13 and a minimal configuration: 

   
  
 
 <plugin> 
  <groupId> org.apache.maven.plugins </groupId> 
  <artifactId> maven-javadoc-plugin </artifactId> 
  <version> 3.1.1 </version> 
  <executions> 
    <execution> 
    <id> attach-javadocs </id> 
    <goals> 
     <goal> jar </goal> 
    </goals> 
   </execution>  
  </executions>  
 </plugin> 
 
  

 I get this error: 
 [ERROR]  Error fetching link: ${project.basedir}/target/javadoc-bundle-options. Ignored it. 
(with the ${project.basedir} being the absolute path for the project). 

 If this error can be ignored it shouldn't be logged at Error level (debug or info would be preferable).
