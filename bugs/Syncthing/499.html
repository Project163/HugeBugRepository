Title

Unclear error message about failed watcher when running out of inotify watches

Description
Syncthing shows the following notice after a short time after starting the web interface:

2018-03-22 15:12:10: Failed to start filesystem watcher for folder "Myfolder" (MyfolderID): error while traversing /home/username/documents/folder: no space left on device 

The file or folder which is mentioned by the message is changing from time to time/reboot to reboot.
There are >200GB space left on my device.

System: Manjaro XFCE 17.1.6
Syncthing V0.14.45, Linux (64 bit)

I have searched for the problem with google and in the github issue tracker but couldn'd find anything similar.
Discussion
- This is because you run out of inotify watches, see [URL] for how to fix this.

However it is intended that there is a more helpful error message, but that's broken. I did fix it upstream (https://github.com/rjeczalik/notify/pull/134) but forgot to adjust our own code accordingly...
