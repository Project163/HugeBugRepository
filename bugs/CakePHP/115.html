Title

resetSequence in the PostgreSQL Datasource uses a fixed column name for counting the next sequence value.

Description
In the resetSequence function of the PostgreSQL Datasource, it accepts both a table name, and a column name, but doesn't use the column name when calculating the next sequence number.

It currently uses "id" which isn't always the sequence column name.
