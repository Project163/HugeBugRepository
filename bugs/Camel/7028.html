Title

camel-smb - DFS doesn't work because SmbConfig cannot be set for smbclient

Description
When trying to connect to a server with DFS mode enabled, a connection error appears. 
To set DFS mode to true, an  SmbConfig  object must be created with the  withDFSEnable  parameter set to  true . 
This object allows for advanced client configuration. 

 Here is an example with Camel Spring Boot: 
  
 
@Configuration
 public   class  SmbConfigBean {

    @Bean
     public  SmbConfig smbConfig() {
         return  SmbConfig.builder()
                .withDfsEnabled( true )  // Active le DFS
                 .withMultiProtocolNegotiate( true )
                .build();
    }
}  
  
   

 However, the configuration is not applied during the client connection. The configuration is not passed this constructor. 
  
 
 public  SmbOperations(SmbConfiguration configuration) {
     this .configuration = configuration;
     this .smbClient =  new  SMBClient();
}
