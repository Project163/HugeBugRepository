Title

CombinedConfiguration does not reload when enclosed configuration files are modified.

Description
When getProperty() is called on a CombinedConfiguration object the reloadingRequired() method is not called.
Discussion
- IMHO this seems to be rather a design flaw in the way reloading is implemented ATM than a bug. But I will see what I can do about it.
- Should be fixed now in subversion and the next nightly build. 

 CombinedConfiguration now provides a property called "forceReloadCheck". If you set it to true, each property access will trigger the contained configurations, which will cause a reload if necessary.
