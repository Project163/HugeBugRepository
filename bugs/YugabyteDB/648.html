Title

[YSQL] Incorrect function parameter handling with expression pushdown enabled

Description
Jira Link: [Link: DB-2748]
### Description

If UPDATE statement inside of a SQL procedure sets bare parameter of matching type, it is not getting replaced by a constant when pushing expression down to DocDB:
```
yugabyte=# SET yb_enable_expression_pushdown to on;
SET
yugabyte=# create table foo (k int primary key, v int);
CREATE TABLE
yugabyte=# insert into foo values (1, 1);
... [Log Snipped] ...
yugabyte=# CALL update_foo(1, 2);
ERROR:  Query error: Unsupported YSQL expression received by DocDB
```
