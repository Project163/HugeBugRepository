Title

Yii message translation

Description
I've got some problems with the yii message/extract command. 
With following code yii dont read correctly:

```
$detailName = Yii::t('app', HtmlExt::strToCamelCase($detail->name));
$field = $form->field($detail, 'value', [
...
```

It comes with the Exception 'mkdir(): File name too long'.
I find out that yii dont parse `Yii::t('app', HtmlExt::strToCamelCase($detail->name))` into `app` and `HtmlExt::strToCamelCase($detail->name)` instead of the second parameter stop at `);` it will get with all following code.
The second parameter looks like this 

```
HtmlExt::strToCamelCase($detail->name));
$field = $form->field($detail, 'value', [
...
```
Discussion
- Translation is for static string. You can use placeholders for variables. From the documentation: `echo \Yii::t('app', 'Hello, {username}!', ['username' => $username]);`
- @arisk is correct.

I'll adjust either regular expression not to match in such cases or the error message.
