A bit of git bisect shows that this is the problem commit

 

This commit causes the `copy` to run through a different part of the drive backend exposing this bug which has been there all along.

What needs to be done is that the code which mangles the google drive file names needs to be pushed into a lower level, so the code in `List` needs to be pushed into `list` so all callers of `list` get to know about google docs.

(Note also that if `NewFs` returned `Fs, Object, error` instead of `ErrorIsFile` then the code in `CopyFile` could use it directly instead of having to look it up again).
