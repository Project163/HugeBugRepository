Title

quarkus-jgit: Cannot save config file 'FileBasedConfig[/project/?/.gitconfig]': java.io.IOException: Creating directories for /project/? failed

Description
**Describe the bug**
When a directory is cloned to a directory that does not exist using the JGit API, the following error is shown in the logs when the application runs in native mode: 

```
java
2019-09-26 02:12:40,738 ERROR [org.ecl.jgi.uti.FS] (ForkJoinPool.commonPool-worker-1) Cannot save config file 'FileBasedConfig[/project/?/.gitconfig]': java.io.IOException: Creating directories for /project/? failed
	at org.eclipse.jgit.util.FileUtils.mkdirs(FileUtils.java:425)
	at org.eclipse.jgit.internal.storage.file.LockFile.lock(LockFile.java:163)
	at org.eclipse.jgit.storage.file.FileBasedConfig.save(FileBasedConfig.java:252)
... [Log Snipped] ...
	at com.oracle.svm.core.thread.JavaThreads.threadStartRoutine(JavaThreads.java:460)
	at com.oracle.svm.core.posix.thread.PosixJavaThreads.pthreadStartRoutine(PosixJavaThreads.java:193)
```

The warning seems harmless, because the directory is cloned successfully.

**Expected behavior**
No stacktrace

**Actual behavior**
Stacktrace is shown in the logs. Invocation still works
