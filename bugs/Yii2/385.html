Title

yii2-composer error when using an array for psr-4 autoloading

Description
Hi guys,

We've run into a problem with composer when trying to use an array of strings for namespace location, as per [URL] We'd like to use this mechanics to overwrite models defined in a yii2-extension inside of an app application. The relevant section of our composer.json looks like this: 

``` json

 "autoload": {
        "psr-4": {
            "matacms\\post\\": ["frontend/models/overwrites/post/", ""]
        }
    }

```

and the error when doing composer update: 

```
[ErrorException]                                        
  substr() expects parameter 1 to be string, array given  

Exception trace:
 () at phar:///usr/local/bin/composer/src/Composer/Util/Filesystem.php:392
... [Log Snipped] ...
 Composer\Console\Application->run() at phar:///usr/local/bin/composer/bin/composer:43
 require() at /usr/local/bin/composer:25
```

Could you please advise if this is a bug? I feel yii2-composer should be a transparent layer on top of composer, but perhaps the design is different? 

Thanks,
Marcin
Discussion
- The problem with this is that the yii autoloader is based on path aliases and does not support one alias to point to multiple paths. It should however just ignore this case then and leave it up to the composer autoloader.
- Should be fixed by fecdf1a. @wichura can you try installing it by using `"yiisoft/yii2-composer": "*@dev",` in your composer.json?
- Hi @cebe,

Thanks for the prompt fix, and sorry for the radio silence in the past days - I was away from my computer.
