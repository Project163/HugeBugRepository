Title

[YCQL] - Wrong results when querying multiple map fields

Description
Jira Link: [Link: DB-3166]

Hello,

We have a bug where every time a select query is run with type MAP, it queries out only the last value of the key that is in the query.

```
ycqlsh> CREATE TABLE data.users(username TEXT PRIMARY KEY,emails SET ,phones MAP ,top_cities LIST );

ycqlsh> INSERT INTO data.users(username, emails, phones, top_cities) VALUES ('foo',{'c@example.com', 'a@example.com'}, {'home' : '999-9999', 'mobile' : '000-0000', 'work':'222-222'},['New York', 'Paris']);

ycqlsh> SELECT phones FROM data.users ;
... [Log Snipped] ...

(1 rows)
```

**Workaround:**

As a workaround, you can use `AS` clause in the query to get the correct output.

```
ycqlsh> SELECT username, phones['work'] AS work ,phones['home'] AS home from data.users WHERE username = 'foo';

 username | work     | home
----------+----------+----------
      foo | 222-222 | 999-9999   ---> works as expected.
```
