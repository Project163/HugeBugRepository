Title

Locale is not handled properly in kafka-consumer

Description
If the JVM local language is Turkish, which has different upper case for the lower case letter i, the result is a runtime error caused by org.apache.kafka.clients.consumer.OffsetResetStrategy. More specifically an enum constant  EARLİEST  is generated which does not match  EARLIEST  (note the  dotted capital i ). 

 If the locale for the JVM is explicitly set to en_US, the example runs as expected.
