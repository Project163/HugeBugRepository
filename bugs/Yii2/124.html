Title

Property $actionParams conflicts with a defined getter getActionParams in yii\web\Controller.

Description
property is defined in web\Controller, getter is in base\Controller.
Discussion
- `getActionParams()` is not used anywhere. I think we can remove it.
- getActionParams was useful in Yii 1.1, I could use it to override where my actions got their params from in a REST API, which allowed explicit actions like `public function actionApiMethod1($param1,$param2,$pram3)`, making it easier to document using phpdoc and it worked simply by returning $_POST in getActionParams in my controller class, I also automatically got HTTP 400 if a parameter was missing.

This doesn't look possible in yii 2 since bindActionParams only looks in the 'get' parameters for action params.

Perhaps this use was missed when yii 2 was created which is why the function no longer looks useful?

Now I have to remove the parameters from the actions and manually get each one from Yii::$app->request (if doing it properly) or $_POST and then manually return HTTP 400 if one of them is missing. This is much more code.
- Ability to get $_POST via method signature was remove on purpose for security reasons.
