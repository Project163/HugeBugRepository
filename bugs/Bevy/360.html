Title

Bevy does not center window properly when system interface is scaled

Description
## Bevy version
0.10.1

## \[Optional\] Relevant system information
Windows 10 with interface scaling 125%

## What you did
I have set the position of the window at creation with
```
rust
App::new()
    .add_plugins(DefaultPlugins.set(WindowPlugin {
        primary_window: Some(Window {
            position: WindowPosition::Centered(MonitorSelection::Primary),
... [Log Snipped] ...
    }))
    .run();
```

## What went wrong
The center appears centered when the interface scaling is set to 100%, however it is not centered properly when the scaling is something other than 100% (see screenshots)
