Title

BelongsToMany mishandles object data type foreign keys

Description
### Description

## Description

When `Articles BelongsToMany Tags`, and `Articles` has a composite foreign key including a field of object data type such as `date`, saving an article with associated tags deletes existing tags associations for this article.

## Faulty code

1. Open the `/articles/` page and click on the article body.
2. Check the first tag and submit ; the first tag link is saved successfully, as you can see in database.
3. Check the second tag (without unchecking the first one) and submit again.
4. Look at SQL logs and at the join table in database : the first tag was unintentionally removed from the article.
5. Re-submit the same query : the second tag was removed and the first tag re-added.
