Title

ZAP hsqldb OutOfMemoryError when deleting records on cleanup

Description
How to reproduce, create a new session and one context, run one scan on a large site/app. The session file should be roughly 10.5GB and there will be around 200,000 records in the `HISTORY` table.

When closing ZAP, it will run a delete to try to delete all records of a certain HISTTYPE at once, this will result in a 

`org.hsqldb.HsqlException: java.lang.OutOfMemoryError: Java heap space`

ZAP will fail to close, the session has a chance of getting corrupted but the regardless of a corrupted session, zap ends in an unclean state.
