#### What is the problem you are having with rclone?
the onedrive headless token, generated by the authorize command (generated by rclone 1.57) is much longer than previous versions causing unable to input it back to remote rclone as the remote rclone doesn't accept this length of token

token length is decided by the authorize code provided by remote rclone. 

remote rclone 1.55 will cause local rclone generate token length about 3300 character
remote rclone 1.57 will cause local rclone generate token length about 4500 character

rclone will not accecpt token longer than 4096 chars
