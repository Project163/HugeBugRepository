Title

Problem calling _setInstanceManager on guice enhanced classe

Description
If a pojo is created by some class enhancer, for example a method interceptor enhanced object returned by guice, the call to _setInstanceManager in InstanceManager fails. The reason is that the enhanced class is a subclass of the original pojo and that class only has the methods it chose to override.  
One solution to this is to travel up the class hierarchy until the _setInstanceManager method is found or Class.getSubclass() returns null (in which case we throw the usual error.
