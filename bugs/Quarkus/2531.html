Discussion
- Adding these configurations makes it working again:

```
--initialize-at-build-time=sun.awt.datatransfer.DesktopDatatransferServiceImpl
--initialize-at-build-time=javax.swing.plaf.ColorUIResource
--initialize-at-build-time=java.awt.font.FontRenderContext
--initialize-at-build-time=sun.awt.SunHints$Value
--initialize-at-build-time=sun.awt.SunHints$Key
--initialize-at-build-time=sun.awt.SunHints$LCDContrastKey
```

Alternativley:

```
--initialize-at-run-time=sun.datatransfer.DataFlavorUtil$DefaultDesktopDatatransferService
--initialize-at-run-time=sun.swing.SwingUtilities2
--initialize-at-run-time=javax.swing.plaf.metal.DefaultMetalTheme
--initialize-at-run-time=javax.swing.plaf.metal.MetalTheme
--initialize-at-run-time=javax.swing.plaf.metal.MetalBumps
```
- This is another case where passing `--future-defaults=complete-reflection-types` fixes the Graal master based native image generation.
