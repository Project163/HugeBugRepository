Title

Improve JDBC interpreter documentation

Description
After  [URL] merged, Zeppelin doesn't support "mapping from %jdbc(prefix) to %prefix" after 0.7.0 version. Instead, we can use  %interpreter_alias  as a JDBC interpreter prefix. You can find this information in  [URL]

 Actually  %jdbc(prefix)  itself works at the moment as  [URL] describes. But auto-prefix for  %jdbc(prefix)  doesn't work. After running the paragraph with  %jdbc(prefix , newly appended paragraph is not including  %jdbc(prefix) . It’s quite uncomfortable to type  %jdbc(prefix)  to every paragraphs’ header. To avoid this inconvenience, we need to use  %interpreter_alias  for JDBC interpreter prefix. Please see the attached gif image files.  

 For example, if a user wants to use  %hive , he needs to create a new JDBC interpreter(the interpreter name should be “hive” not “jdbc") then set  default.driver  with hive driver. Currently there is no guide for this in  [URL] page. Moreover the user wants to connect multiple jdbc drivers(let’s say he needs to connect “mysql” at the same time), he needs to create another JDBC interpreter for Mysql connection. Then he can use  %mysql . 
So  [URL] this page needs to be updated as well.
