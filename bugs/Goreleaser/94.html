Title

[Bug]: Twitter announce incorrect URL

Description
### What happened?

I use twitter announce (which works fine), but it posted the incorrect URL. 

### How can we reproduce this?

This is most likely not a bug in Goreleaser and probably not released to Twitter announce, but to the value of `.GitURL`.

When importing a new repsitory on Github, it suggest to add a remote like: 

    git remote add origin [URL]

(notice the `.git` suffix)

Now I set up Twitter announce with the following setting:

```
announce:
  twitter:
    # Whether its enabled or not.
    # Defaults to false.
    enabled: true
```

and on `goreleaser release --rm-dist` it publishes a twitter message with an incorrect link. I don't have it anymore but I strongly believe it was `[URL] including the `.git` suffix. This link gives a 404.

Perhaps it is possible to strip the `.git` suffix from the `.GitURL` or to override this in the yaml file? The `github_urls:` are documented to be for Github enterprise only, so I didn't try them.

Sorry that I have deleted the link too quickly.
