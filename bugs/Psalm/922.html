- @nikic I'm curious whether this behaviour is intended. It seems this is a special case – passing a nullable property by reference before it's initialised
- Relates to #3000. The error message if it's not nullable explicitly says `Cannot access uninitialized non-nullable property`, so I guess this is by design.
- @muglug Passing by reference (or acquiring a reference in any other way) performs an implicit null initialization. Same reason why you can write `preg_match(..., $matches)` without initializing `$matches` first.
