Title

Chunked Stream is closed regularly when Exception is thrown

Description
In response to SOAP requests served by Apache CXF we send large datasets streamed directly from a database. Because of the size of the data, chunked encoding is used. Unfortunately when a database error occurs and an exception is thrown while data is sent, the client will receive a regular ending to the chunked data stream. That means he has no way to recognise that an error occurred and that he has only received a partial file.

 To actually use chunked encoding, I replaced: 
  
 
                 if  (ThreadLocalRandom.current().nextBoolean()) {
                     throw   new  IllegalArgumentException( "simulated error during stream processing" );
                }
 
  

 With: 
  
 
                 if  (ThreadLocalRandom.current().nextDouble() < 0.01) {
                     throw   new  IllegalArgumentException( "simulated error during stream processing" );
                }
