Title

Docker manifests does not work well when pushing tag like "latest"

Description
**Describe the bug**

Currently new images are amended (--amend) to the manifests. For manifests like "latest " this means both old and new versions end up in the latest manifest.

**To Reproduce**

Steps to reproduce the behavior:

a docker_manifests config like

```
docker_manifests:
- name_template: 'timescale/promscale:{{ .Tag }}'
  image_templates:
  - 'timescale/promscale:{{ .Tag }}-amd64'
  - 'timescale/promscale:{{ .Tag }}-arm64'
... [Log Snipped] ...
  - 'timescale/promscale:{{ .Tag }}-amd64'
  - 'timescale/promscale:{{ .Tag }}-arm64
```

**Expected behavior**

Expect latest manifest to have only 2 images, but has 4 (2 from previous version)


**Possible solution**
- run `docker manifest rm`
- don't amend but set (not sure it's possible)
