Title

Only a single Data Driven Node can be saved in a context

Description
OWASP ZAP 2.4.3 running on a Kali Linux VM.

The UI lets you define multiple data driven nodes for a context, but only one (I think the last one edited) is saved in the context when you export it. I first noticed this when importing a context into a new session, at which point I examined the contents of the .context file, where I confirmed that only one node was saved.
