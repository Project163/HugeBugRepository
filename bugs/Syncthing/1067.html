Title

CLI showing wrong usage for config subcommands

Description
### What happened?

Looks like help info for the `syncthing cli config` subcommand is not initialized correctly:

```
$ syncthing cli config --help
Incorrect Usage. flag: help requested

NAME:
   syncthing - A new cli application
... [Log Snipped] ...
   syncthing  command [command options] [arguments...]
[...]
```

Note the strange application description and the missing `cli config` part after the `syncthing` main command.  For comparison:

```
$ syncthing cli show --help
Usage: syncthing cli show   [flags]

Show command group

Flags:
  -h, --help                  Show context-sensitive help.
[...]
```

The CLI is already a bit hard to maneuver without auto-completions, but this is misleading even for help-based usage.  Since there are no further detailed docs about the CLI either, this is the only authoritative place to see what's available, and it's incorrect.
