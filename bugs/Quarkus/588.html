Title

Uppercase quarkus.container-image.group causes docker error

Description
**Describe the bug**
Quarkus extension **quarkus-container-image-docker** fails with uppercase repository name.

```
[INFO] --- quarkus-maven-plugin:1.3.2.Final:build (default) @ simple ---
[INFO] [io.quarkus.container.image.docker.deployment.DockerBuild] Docker daemon found! Version:'19.03.8'
[INFO] [org.jboss.threads] JBoss Threads version 3.0.1.Final
[INFO] [io.quarkus.deployment.pkg.steps.JarResultBuildStep] Building thin jar: C:\git\Back2Code.CampusStudents\__temp\simple\target\simple-1.0.0-SNAPSHOT-runner.jar
[INFO] [io.quarkus.container.image.docker.deployment.DockerProcessor] Building docker image for jar.
... [Log Snipped] ...
[INFO] BUILD FAILURE
[INFO] ------------------------------------------------------------------------
```

**Expected behavior**
Docker image gets built.

**Actual behavior**
Docker error because of uppercase repository name.
Without setting the container-image.group my windows username is used instead,
which is uppercase too and causes the same error.

**To Reproduce**
Steps to reproduce the behavior:
1. Use quarkus-container-image-docker extension
2. In ``application.properties`` set ``quarkus.container-image.group=ABC``
3. Call maven package: ``mvn clean package -Dquarkus.container-image.build=true``
