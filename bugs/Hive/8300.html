Title

TestOperatorCmp/TestReOptimization fail silently due to incompatible configuration

Description
Running TestOperatorCmp, TestReOptimization currently in master ( [URL] shows BUILD SUCCESS although the tests are actually failing when executing the  @BeforeClass  logic.  

 Since the error appears inside  @BeforeClass  the failure remains unnoticed and the only  indication that something is wrong is given by the INFO line below: 

  
 [INFO] Tests run: 0, Failures: 0, Errors: 0, Skipped: 0
 
  

  Steps to reproduce:  
  
 
mvn test -Dtest=TestOperatorCmp
mvn test -Dtest=TestReOptimization

- Looking into the test output under target/surefire-report it turns out that the error causing the failures is the following:

 Most likely the cause of the failure is the changes introduced by   HIVE-25792  .
