Title

[docs] Using Log4j 2 in Web Applications: Update example (Log4jWebLifeCycle is not visible)

Description
On the  [URL] page you mention following code snippet: 
  
      final  Log4jWebLifeCycle webLifeCycle =     WebLoggerContextUtils.getWebLifeCycle(TestAsyncServlet. this .getServletContext());
 
  
 The problem is, Log4jWebLifeCycle is package-private and you can't use it.
Discussion
- The docs are wrong, it was not updated to the latest version of  org.apache.logging.log4j.web.TestAsyncServlet  (see git). 

 Just change  Log4jWebLifeCycle  to  Log4jWebSupport : 

  
   final  Log4jWebSupport webLifeCycle =     WebLoggerContextUtils.getWebLifeCycle(TestAsyncServlet. this .getServletContext());
 
  

 Gary
- Fixed docs in git master. Please verify that the new example works for you.
