Title

Add clean bounce system test for distributed Copycat

Description
Using sources and sinks for system tests that are similar to VerifiableProducer and VerifiableConsumer, the test should run a copycat cluster, create source and sink jobs, perform rolling bounces of the Copycat nodes, and then validate the delivery semantics. In particular, with clean bounces, we should see exactly once delivery of messages all the way to the sink.
