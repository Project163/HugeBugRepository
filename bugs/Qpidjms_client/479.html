Title

JMS client doesn't distinguish between node and link bindings

Description
The x-bindings specified in node properties should be created/deleted at the time the node is created/deleted. 

 The x-bindings specified in link properties should be created/deleted at the time a link is established to a node. 
Ex creating producer or consumer.
