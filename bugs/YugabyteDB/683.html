Title

[YSQL][Upgrade] Upgrade doesn't work if YSQL was initialized by a manual initdb run

Description
Jira Link: [Link: DB-3116]
### Description

If you create a cluster on, say YB v2.6 via something like `./bin/yb-ctl create --disable_ysql` and run initdb manually [Link: as per our v1.x docs], you'll get working YSQL.
But after upgrading to 2.8+, YSQL upgrade won't actually work because it won't recognize initdb was done:
```
./bin/yb-admin upgrade_ysql
Upgrade is not needed since YSQL is disabled
```
(this check was added in #11206)
