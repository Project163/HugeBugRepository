Title

Bug with measure tool: measure is shown under elements with really high z-index

Description
**Describe the bug**
As you can see radix-ui sets really high z-index, that causes the ruler to be show under the drawer
[Image: image]

**To Reproduce**
Just try the measure tool with a high index component
Discussion
- I don't think it's a good idea to max out the z-index. Most browsers limit the maximum value for `z-index` to `2147483647`. You can see the element in your screenshot has maxed it out. That said, this might be our only option here. 

@winkerVSbecks do you have any other ideas? Outside of moving the canvas overlay outside of the iframe, I don't know that we have an alternative option.
- z-index seems like a reasonable compromise for now. 
I'm not sure what else we can do. It's in the iframe because it has to measure the DOM nodes, etc. We could potentially move rendering out of the iframe but, that'll require a lot more work. Potential v2 option.

```
npx sb upgrade --prerelease
```

Closing this issue. Please re-open if you think there's still more to do.
