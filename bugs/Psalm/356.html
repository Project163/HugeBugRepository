Title

Unexpected "RedundantCondition" reported when doing empty() check for iterable.

Description
Since an argument type hinted as `iterable` can be an array, doing a `empty()` check for that variable should not generate `RedundantCondition` error.
Discussion
- Got a sample code? I can imagine this error to be quite handy to remind me generators/iterators shouldn't be checked with `empty()`. And `is_array($iterable) && empty($iterable)` does not produce any issues.
- Reproduced with [URL]

```php

    if (empty($i)) {}
}
```
