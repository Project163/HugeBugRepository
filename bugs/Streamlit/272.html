Title

Blank page on Streamlit 1.41.1 (incorrect ContentType on javascript)

Description
### Checklist

### Summary

I have an application working OK on version 1.41.0, but i get a blank page if I upgrade it to 1.41.1.

The error is the javascript resource, the browser (chrome/edge) rejects it because its ContentType is "text/plain":

`Failed to load module script: Expected a JavaScript module script but the server responded with a MIME type of "text/plain". Strict MIME type checking is enforced for module scripts per HTML spec.`

The applications works again after downgrade to 1.41.0

2. Check the application on Chrome or Edge

### Expected Behavior

### Current Behavior

Blank PAge, as Browser rejects to load Javascript.
