Title

[YSQL] ANALYZE command doesn't populate parent-level stats for partitioned tables

Description
Jira Link: [Link: DB-12511]
### Description

Problem
---
* The ANALYZE command doesn't populate the stats for partitioned tables at the top-level.
* Missing parent-level stats leads to poor row count estimates.
* Vanilla PG (even 11) populates the stats with the rows sampled from each partition. **NOTE: vanilla PG populates columns stats but NOT relation stats (`reltuples`, etc.) at the parent-level until upstream commit: pg  ).  PG15 has this change but not PG11.**
