Title

Description
Environment 
 
	 OS: CentOS Linux release 7.6 
	 Kafka version: 2.4.1 
 

 
	 
	 
		 But as far as I checked the code, I think same phenomenon could happen even on trunk 
	 
	 
	 Kafka log directory: RAID1+0 (i.e. not using JBOD so only single log.dirs is set)
