- Why do you consider this a bug? Throwing an NPE, if either parameter is null, makes perfect sense to me. What else should the method do?

- Hi  jochen@apache.org  

 I expect the API to behave reasonably, like  java.util.Objects.equals(Object, Object) , and not blow up miserably. The value of an "equals" API is tremendously devalued if the most basic boundary conditions cannot be handled IMO. In this case, the NPE is just a lazy or incomplete implementation.
