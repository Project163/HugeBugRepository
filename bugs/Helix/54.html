Title

Blank screen after SIGCONT

Description
### Summary

After  , `hx` stops redrawing screen after SIGCONT. The current `Application::handle_signals` calls `Terminal::autoresize` indirectly instead of `Compositer::resize`. But `autoresize` does nothing if the actual size is equal to the stored one. So redrawing is skipped.
I think we need to call `Terminal::resize` after all or to call `Terminal::clear` directly.

### Reproduction Steps

  

I tried this:

1. `hx`
1. C-z (suspend)
1. `fg`

I expected the screen was resumed.
Instead, it got blank.
