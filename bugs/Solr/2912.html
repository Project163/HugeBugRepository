Title

ZkStateWriter.writePendingUpdates() can return null clusterState; NPE in Overseer

Description
While trying to get the test in Varun's patch in   SOLR-5750   (SolrCloud collection backup & restore) to succeed, I kept hitting an NPE in Overseer in which clusterState was null.
