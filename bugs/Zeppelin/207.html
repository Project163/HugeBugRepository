Title

Update cassandra-spark-1.5 profile to use Guava 16.0.1 and connector 1.5.0-RC1

Description
Right now, the Maven profile  cassandra-spark-1.5  is broken because an older version of Guava is used ( 15.0  to be exact). This PR addresses this issue and also update the version of the Spark/Cassandra connector: 

 
	 Guava version set to  16.0.1  because the spark-cassandra connector is pulling the Java driver  3.0.0-rc1  which requires Guava 16.0.1 
	 spark-cassandra connector set to  1.5.0-RC1
