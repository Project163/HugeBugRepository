Title

libsodium assertion failure

Description
**Describe the bug**
libsodium is missing a #define when built on macos.  The #define HAVE_SYSCONF controls how libsodium determines the page_size used in memory allocations.  This is in src/libsodium/sodium/utils.c, in the _alloc_aligned function.  When it is missing, the incorrect page_size is used.  This causes an assertion failure in src/libsodium/sodium/utils.c, in the _sodium_malloc function.

**Environment**
- OS: MacOS
- Compiler: clang

**To Reproduce**
Steps to reproduce the behavior:
Build and use libsodium in an application.  The assert is triggered the first time the application attempts to allocate memory with libsodium.

**Expected behavior**
No assertion when allocating memory.

**Failure logs**
Assertion failed: (_unprotected_ptr_from_user_ptr(user_ptr) == unprotected_ptr), function _sodium_malloc, file utils.c, line 629.

**Additional context**
This can be fixed by adding
sodium_check_func(sysconf HAVE_SYSCONF)
to CMakeLists.txt in the port
