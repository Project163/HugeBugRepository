Title

Problems with moveto/copyto commands

Description
Using the latest (updated as of earlier this morning) rclone on Linux, I'm getting unexpected behavior with the `moveto` command on local files.

`rclone -v moveto testfile somepath/`

fails with

```
2017/01/30 16:48:13 rclone: Version "v1.35-DEV" starting with parameters ["rclone" "-v" "moveto" "testfile" "somepath/"]
2017/01/30 16:48:13 Can't find parent directory for "somepath/"
```

Attempting the same command without the trailing slash and an empty `somepath` clobbers the destination directory and just renames the file in the same directory.

Attempting the same command without the trailing slash but a non-empty destination gives:

```
2017/01/30 16:49:26 rclone: Version "v1.35-DEV" starting with parameters ["rclone" "-v" "moveto" "testfile" "somepath"]
2017/01/30 16:49:26 Local file system at /home/eharris/rclone: Modify window is 1ns
2017/01/30 16:49:26 testfile: Sizes differ
2017/01/30 16:49:26 somepath: Couldn't delete: remove /home/eharris/rclone/somepath: directory not empty
2017/01/30 16:49:26 Attempt 1/3 failed with 1 errors and: remove /home/eharris/rclone/somepath: directory not empty
... [Log Snipped] ...
2017/01/30 16:49:26 Attempt 3/3 failed with 1 errors and: remove /home/eharris/rclone/somepath: directory not empty
2017/01/30 16:49:26 Failed to moveto: remove /home/eharris/rclone/somepath: directory not empty
```
