Check if "Deprecating positional selectors and the sunset of Sizzle" causes BC breaks.
- Do you mean the 3.4 breaks the current bootstrap version?
- Should not but should be checked.
- From the same blog post:
Specifically, jQuery 3.4.0 is deprecating :first, :last, :eq, :even, :odd, :lt, :gt, and :nth. When we remove Sizzle, we’ll replace it with a small wrapper around querySelectorAll, and it would be almost impossible to reimplement these selectors without a larger selector engine.
**Upgrading**
There should be no compatibility issues if upgrading from jQuery 3.0+.

3.4.x works fine for me. JQuery roadmap for 4.x is something like Yii roadmap for version 3 - "when is done" :).
