Title

Parser requires config options object

Description
As of 1.4.0 this creates a type error:

```
var less = require('less')
    , parser = new(less.Parser);

// Results in this exception: 'TypeError: Cannot read property 'filename' of undefined'

```

A blank object is required, like so:

```
var less = require('less')
    , parser = new(less.Parser)({});
```

This is not documented in the documentation or changelog.
