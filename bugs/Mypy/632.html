Title

__class_getitem__ is not assumed to be a classmethod

Description
mypy (version 0.720) gives confusing errors like this:

    error: The erased type of self "Type[_Type]" is not a supertype of its class "_Type"

for the following method:

```python
_TypeT = TypeVar("_TypeT", bound="_Type")
class _Type:
    def __class_getitem__(cls: Type[_TypeT], item: Any) -> _TypeT:
        raise NotImplementedError
```

even though this is [Link: apparently the correct way] to type-hint factory functions.

Adding the `@classmethod` decorator makes the error go away, but [Link: according to PEP 560], `__class_getitem__` is automatically a class method, so the decorator shouln't be required.
Discussion
- Yes, we should recognise it as a class method automatically, this is however quite low priority IMO, because it is a rarely used method.
