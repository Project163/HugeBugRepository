Discussion
- In the 2.0 version, the fotos come out green, and so is the rendering of the 2nd page. There is a warning "Inconsistent metadata read from JPEG stream". A source comment tells that this may indicate a YCCK image but that this isn't sure.
- I get correctly extracted JPEG images if I extract the unmodified JPEG stream. According to IrfanView, the images are CMYK. 

 So the current situation is: 
 
	 The colorspace in the PDF is CMYK 
	 The JPEG streams are CMYK 
	 But we can't know that the JPEG is CMYK because of the "Inconsistent metadata read from JPEG stream" exception 
 

 I could post the source code needed to do a 1:1 extraction, but I don't know if this will really help you, it will show weird images in other cases.
