Title

[bug] IOS log are too verbose

Description
### Describe the bug

On IOS when using `tauri_plugin_log`  logs are too verbose and it's not possible to see usefull logs because of it.
According to @FabianLars it is not the expected behaviour

 

One workaround is this add `.level(log::LevelFilter::Info)`

Discussion
- the problem here is that tauri-plugin-log defaults to [Link: trace level] I think that's a bit too much, but we can't really change it without making it annoying for people already relying on it

our template comes with the `.level(log::LevelFilter::Info)` by default too
- note that you can also pick the crates that you want logs to be enabled:

```rust
tauri_plugin_log::Builder::default()
                .level(log::LevelFilter::Off)
                .level_for("tauri", log::LevelFilter::Info)
                .level_for("app_lib", log::LevelFilter::Debug)
```
make sure app_lib matches whatever you have in your `Cargo.toml > lib > name`
- i'll close this since there's not much else we can do - make sure you set a level filter!
