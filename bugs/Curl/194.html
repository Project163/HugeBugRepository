Title

http/3: transfer closed with n bytes remaining to read

Description
### I did this

I'm using curl to call http/3 server provided by [Link: jetty]. I'm getting error like `curl: (18) transfer closed with 8 bytes remaining to read`:

```
curl3 --http3 -vv -k [URL]
*   Trying  :5443...
* Connect socket 5 over QUIC to  :5443
* Sent QUIC client Initial, ALPN: h3,h3-29,h3-28,h3-27
* Connected to localhost () port 5443 (#0)
... [Log Snipped] ...
* Connection #0 to host localhost left intact
curl: (18) transfer closed with 8 bytes remaining to read
```

### I expected the following

When I switch to the client provided by quiche code base, it received the whole body without error.
