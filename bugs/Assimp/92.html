Title

Bug: Memory hog when running assimp info on fbx files in s390x

Description
Hi,

There was an error reported in Debian saying that while running the test suites for assimp it is taking an extremely high memory on s390x machines ([Link])
Logs: [Link]

So, isolating from the test bed, this issue is produced when running `assimp info` on any `.fbx` files.
Eg: `assimp info /home/pranav/github/assimp/test/models/FBX/animation_with_skeleton.fbx`

When I tested this out personally, it was filling up 64 GB of RAM and an additional swap space of 20 GB (afterwards the process was killed by the OOM reaper).
