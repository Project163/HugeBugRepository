Title

OpenSslServerContext reinitializes the provided TrustManagerFactory with the key cert chain.

Description
AFAICT, this is incorrect behavior, as the provided trust manager factory should already be initialized.
Discussion
- @freels hmmm... s you would argue that either the user provides a full initialised TrustManagerFactory and not certs or none and the certs ?
- Yes. This would match the behavior of JdkSslServerContext as well.

In my case, I am trying to provide a trust manager initialized with a root CA cert that a server context will use to validate client certs. However, because OpenSslServerContext reinitializes the provided trust manager w/ the server's cert, it drops the root cert and trusts only its own server cert.
