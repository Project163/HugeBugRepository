Title

DateFormat is in US format by default on a UK culture server

Description
I've just started looking at using Serilog (version 1.3.24) in a new project and noticed that the dates are US culture by default. With the following code:

``` csharp
    var logger = new LoggerConfiguration()
        .WriteTo.ColoredConsole()
        .CreateLogger();

    logger.Information("Begin");
    Console.WriteLine(DateTime.Now.ToString());
```

The output is as follows:

```
05/27/2014 12:14:31 [Information] Begin
27/05/2014 12:14:31
```

If I change `ColoredConsole()` to `ColoredConsole(formatProvider: CultureInfo.CurrentCulture)` then it renders correctly:

```
27/05/2014 12:15:29 [Information] Begin
27/05/2014 12:15:29
```

Is there a reason that you don't use `CultureInfo.CurrentCulture` by default?
Discussion
- No, thanks for the heads-up. We generally use `InvariantCulture` for machine-readable data, but in the case of the console sink (where we use a locale-dependent format) `CurrentCulture` seems like the correct default.
