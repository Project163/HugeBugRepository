Title

setOutputSurface bug Lenovo TAB 2 A10-70L

Description
### [REQUIRED] Issue description
I noticed that one of my testing devices (Lenovo TAB 2 A10-70L) is crashing with ExoPlaybackException when we attach new PlayerView to Player. I think it is related to setOutputSurface workaround #4468. 
I was able to get rid of the crash when i changed `deviceNeedsSetOutputSurfaceWorkaround` flag to true during debug. I'm attaching stacktrace with the crash, let me know if full bug report is necessary.

DEVICE: 
**Build.DEVICE:** A10-70L
**Build.MANUFACTURER:** Lenovo 
**VideoDecoderName:** OMX.MTK.VIDEO.DECODER.AVC

As far as i can see `codecNeedsSetOutputSurfaceWorkaround` method from `MediaCodecVideoRenderer` class already has device with simmilar name A10-70F for a workaround to kick in. So i think it's same device but slightly different variant?
