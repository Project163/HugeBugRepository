Title

Reusable events drop the original format string

Description
MutableLogEvent and RingBufferLogEvent hold references to state from original messages, but they currently exclude the value of Message.getFormat(). 

 I would like to write a custom Layout implementation which is aware of the format string and parameters, which doesn't necessarily use the formatted message value.
