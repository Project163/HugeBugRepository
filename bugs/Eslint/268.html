- Can you use some debug flags to narrow down where the problem is occurring? (Ideally with some sample code.)

You can use debug flags like this:

``` js
$ DEBUG=eslint:* eslint .
```

Where `eslint .` is your command for running ESLint. You should be able to see which file the error occurred in and then be able to narrow down to which `return` statement is causing the problem.
