Title

Incorrectly merging built-in and user config `languages.toml` files for typescript lsp

Description
### Reproduction steps

You need to have [Link: `deno`] installed to be able to reproduce and consult wiki for helix config/log directories.

1. Create an empty `languages.toml` in the Helix config directory.
2. Copy in the text from [Link: `helix/languages.toml`]
3. Navigate to the `language` entry that has a name of `typescript`
4. Change the `language-server` value to be of `{ command = "deno", args = ["lsp"] }` and save
5. Create a dummy file with a `ts` file extension
6. Insert the following code:

```ts
console.log("Hello, world!");
```

7. Close helix
8. Open the file in helix again with the `-v` flag
9. Open the helix log file and see the errors listed below.

- Platform: Windows
- Helix version: 0.5
