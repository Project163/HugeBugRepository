- I am using default nodejs runtime, it works when I just run `npm run dev` in my local, but after I changing something inside the server action (even just add some spaces), it throws this error, then if I stop and rerun the project, it works again.. is it a bug?
- This bug can be easily repeated. I have the following fixture:

[URL]

The following access to `cookies()` simply doesn't work if `runtime = "edge"`

```js
'use server';

import { cookies } from "next/headers";

export async function act() {
  return cookies().get('token').value;
}

```

Clicking the button the repro throws the error:

```
- error Error: Invariant: Method expects to have requestAsyncStorage, none available
    at act (./src/app/_actions.js:13:65)
```

After reading the compile result, I find this is because the `requestAsyncStorage` accessed by `cookies` is not the one used in `handleAction()`. This only happens in edge runtime, but works well in node. I suspect there's some wrong webpack config that leads to double instantiation of the singleton `requestAsyncStorage`.
