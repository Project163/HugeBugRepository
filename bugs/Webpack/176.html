Title

[5.0.0] require() of a non-existing package in a try-catch block is broken

Description
# Bug report

**What is the current behavior?**
require() of a non-existing package in a try-catch block doesn't behave like in Webpack 4.
```
try
{
	require('preact').cloneElement; // when preact not available emits an error
	require('preact'); // when preact not available emits a warning
}
catch(e) {}
```
**What is the expected behavior?**
Webpack should always emit a warning. This worked fine in Webpack 4.

**Other relevant information:**
webpack version: 5.0.0
Node.js version: 12.18.4
Operating System: Linux
