Title

[cpuinfo] warnings: The following EXEs were found in.... then errors: but seems to install

Description
**Describe the bug**
On windows, maybe others also, vcpkg needs to check when a `statically linked only` port is compiled/linked under dynamic triplets (in this case `x64-windows`) to see if a `tools` feature is selected and therefor may contain the tool executables (in this case `cpuid-dump.exe`) and not produce warnings/errors about statically linked ports have EXEs in .\bin and .\debug\bin directories.

**Environment**
- OS: [Windows 11 22H2 Version [10.0.22621.963]]
- Compiler: VS 2022
   - Visual Studio Community 2022 Version: [17.4.3]  VS Tools Version: [14.34.31933] 
   - Microsoft (R) C/C++ Optimizing Compiler Version [19.34.31937] for x64 
- Vcpkg-Tool Version [2022-12-18- ]  (latest as of 21:00 EST 2022-12-19)

**To Reproduce**
Steps to reproduce the behavior: 

`triplet = x64-windows`
1. .\vcpkg.exe install --recurse --keep-going --clean-buildtrees-after-build --clean-packages-after-build --no-print-usage cpuinfo[core,tools]
2. See error:

**Expected behavior**
No Warning or Error message produced when a statically linked port is compiled under a dynamic triplet and the port contains a `tools` feature.
