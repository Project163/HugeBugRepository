Discussion
- Hi, please do try using a `string[]` type for `emails`. Also, please note that using implicit types from next/dist is not recommended.

```tsx
emails: ['test']
```

EDIT: I'd recommend using it like:

```tsx
type OpenGraph = Metadata['openGraph'];
```
