Title

Cake Bake adds ->validatePresence for datetime fields by default

Description
While testing CakePHP Dev Preview 3 I came across an issue where the default Cake Bake validation does not work for the datetime fields Created & Modified. Some trial & error shows that ->validatePresence is the culprit. 

New records can't be saved if this line is in the $validator. Not sure what goes wrong here, debug shows no errors. 

->validatePresence('created', 'create')
->validatePresence('modified', 'create')
Discussion
- Are you using the TimestampBehavior? The reason is that the fields are not present until the are saved, so there is no point in validating those fields
- Yes, I do use TimestampBehavior as it was initialized as default, I just used the plain vanilla CRUD code after Cake Bake to see if it works. 

If it does not make sense to validate them, would it be an idea to remove this validation as default cake bake output? I am speaking for the noobs here
