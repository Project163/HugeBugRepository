Title

jQuery deferred.then allows null but is marked as non-null

Description
What steps will reproduce the problem? 

1. Visit [URL]

2. Select Advanced.

3. Paste the following:

// ==ClosureCompiler==
// @compilation_level ADVANCED_OPTIMIZATIONS
// @output_file_name default.js
// @externs_url [URL]
// ==/ClosureCompiler==

$("foo").animate({}).promise().then(function(){}, null);

4. Click Compile.

5. Click Warnings.

EXPECTING: no warnings.

ACTUAL: 

JSC_TYPE_MISMATCH: actual parameter 2 of jQuery.Promise.then does not match formal parameter
found   : null
required: function (): ? at line 1 character 50
$("foo").animate({}).promise().then(function(){}, null);
Discussion
- See [URL]

"All three arguments (including progressCallbacks, as of jQuery 1.7) can be either a single function or an array of functions. The arguments can also be null if no callback of that type is desired."
