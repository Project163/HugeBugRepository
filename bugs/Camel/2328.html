Title

baseResource of Jetty ServletContextHandler does not work when project deployed as a bundle

Description
If we package a camel websocket route ("websocket:// :9090/newsTopic?sendToAll=true&staticResources=classpath:webapp") as a bundle and set the staticResources as parameter (classpath:webapp), then the pages cannot be accessed from the browser 

 Code should be  

  
              if  (resources[0].equals( "classpath" )) {
                URL url =  this .getCamelContext().getClassResolver().loadResourceAsURL(resources[1]);
                context.setBaseResource(Resource.newResource(url));
            }  else   if  (resources[0].equals( "file" )) {
                context.setBaseResource(Resource.newResource(resources[1]));
            }
