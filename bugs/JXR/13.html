Title

Javadoc link broken for site:stage

Description
When I use site:stage in a multi-project environment the generated JXR Pages contain invalid links to the javadocs. 
The href looks like this: 
./../../../../../../../../../../../SVN_ROOT/SVN_FOLDER/MODULE1/target/site/apidocs/org/foo/... 

 But for site:stage there is no target and no site folder.  
Your way to determine the URL to the javadocs seems to be wrong.
Discussion
- Can you please try the 2.1 release. I think that this issue has been solved in the new version.
- I tried the official 2.1. The bug still remains. Simply try "mvn site:stage -DstagingDirectory=/absolute/path/..." on a project with javadoc and jxr.
- Handle the stagingDirectory for the site:stage in getJavadocLocation()
- This project has moved from Jira to GitHub Issues. This issue was migrated to  apache/maven-jxr#152 .
