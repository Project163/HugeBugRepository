Title

no-unused-vars missing require that isn't used

Description
I have this code at the beginning of a file:

``` js
var fs = require('fs'),
    path = require('path'),
    properties = require('properties'),
    assign = require('object-assign');
```

The `assign` variable is never used but isn't flagged (I found it through JSHint integration with my editor). Seems like we're missing the easiest case.
Discussion
- Okay, this is because we don't check globals by default. I'm wondering if that's the correct default given that jshint checks globals by default. At the moment, i'm leaning towards turning on checking global variables by default and letting people opt out. I'm open to hearing opinions on this.
- I'm okay with that. I like forcing explicit exports. People should not be working in the global scope. Wrap your program in an IIFE and export via `global.x =`, `window.x =`, `exports`/`module.exports`, some AMD `defined` function, or some other method. Also note that nodejs top-level scope is not global, so it's even more appropriate in that environment.
