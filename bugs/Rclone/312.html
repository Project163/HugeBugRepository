- Seems to be related to --fast-check
if i disabled fast-check if seems to work:

export RCLONE_FAST_LIST=false;
export RCLONE_BUFFER_SIZE=10M;
export RCLONE_CHECKERS=50;
export RCLONE_TRANSFERS=50;
export RCLONE_TPSLIMIT_BURST=80;
export RCLONE_TIMEOUT=30s;
export RCLONE_STATS=1m;
export RCLONE_STATS_UNIT=bits;
export RCLONE_STATS_LOG_LEVEL="INFO";
export RCLONE_LOG_LEVEL="INFO";
- I think this should fix it.  I don't know how no-one noticed this before!
