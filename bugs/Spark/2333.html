Title

SBT build: com.twitter:parquet-hadoop-bundle:1.6.0 is not packaged into the assembly jar

Description
One of the consequence of this issue is that Parquet tables created in Hive are not accessible from Spark SQL built with SBT. Maven build is OK. This issue can be worked around by adding  lib_managed/jars/parquet-hadoop-bundle-1.6.0.jar  to  --driver-class-path . 

 Git commit:     

 Build with SBT and check the assembly jar for classes in package  parquet.hadoop.api : 
  
 $ ./build/sbt -Phive -Phive-thriftserver -Phadoop-1 -Dhadoop.version=1.2.1 clean assembly/assembly
...
