Title

"sealed" not usable as a restricted identifier

Description
The restricted identifier "sealed" is not usable for a variable or member name any longer. 
  
 
 def  sealed =  false   // fails to parse
  def  record =  false   // okay
  def  permits =  false   // okay
 
 class  C {
   def  sealed =  false   // fails to parse
    def  record =  false   // okay
    def  permits =  false   // okay
 }
 
  

 And this should still work as minus: "{ non, sealed -> return non-sealed }"
Discussion
- I am still pondering options here but just to add some additional info. 

 The following two examples work in 3.0.9 but not 4.0.0-rc-2: 
  
  
 
def sealed() {  false  }
sealed()
 
  
 and: 
  
 
def sealed = { ->  false  }
sealed()
 
  

 The following examples fail in both: 
  
 
def  private  = { ->  false  }
 private ()
 
  
 and: 
  
 
def  protected () {  false  }
 protected ()
 
  
 and: 
  
 
def  public  =  false 
def class =  false 
def  interface  =  false 
def def =  false 
 
  

 The following example runs fine in both: 
  
 
def  "non-sealed" () {  false  }
def  "sealed" () {  false }
def  " private " () {  false  }
 var   var  =  false 

 this . private ()
 this .sealed()
 this . "non-sealed" ()
- I wouldn't expect "def private = ..." to work.  It has been a keyword / reserved word from the very start of Java (and Groovy).  I think only "var", "record", "sealed", "permits" and soon "_" are so-called restricted identifiers.  They can be used as identifiers but serve as keywords in specific circumstances.
