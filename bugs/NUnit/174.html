- @savornicesei This is not the same error as in the original post. I tried to run the code, but I'm unsure what "empty unicode character" is, so I cannot answer this part.

The failing testcases, however, is since the test method expects the last argument to be an integer, and you pass doubles. So changing the signature from `public void ToInt_FromObject_WithGivenCultureInfo(object value, CultureInfo cultureInfo, int expected)` to `public void ToInt_FromObject_WithGivenCultureInfo(object value, CultureInfo cultureInfo, double expected)` should solve the problem.

EDIT: I was actually a bit surprised that XUnit rounds passed doubles to nearest integer (if the test methods expects an integer). So the first two cases pass and the last two fail with `Expected: 2 ... Actual:   1`.
