Title

renaming static imports

Description
The Groovy  style guide  introduces the renaming  import... as  statement and discusses  import static . It should not leave as an exercise that  import static... as  works as well, but simply introduce it by a simple example, as in 
  
 import static java.lang.Math.abs as mabs
println mabs(-4)
