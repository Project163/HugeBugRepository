Title

[scr.compat] ScrServiceImpl.getComponents() returns no components

Description
In the scr.compat version of ScrServceImpl, the getComponents() method which should return all components in the system, always returns null.
Discussion
- The reason is that it passes  null  to a variable arguments list, which is interpreted as an array of size one, with a null value, rather than an empty list. 

 As a result in the second clause of the if statement below gets called (from  ServiceComponentRuntimeImpl ) 

  
  	 public  Collection<ComponentDescriptionDTO> getComponentDescriptionDTOs(Bundle... bundles)
	{
		List<ComponentHolder<?>> holders;
		 if  (bundles ==  null  || bundles.length == 0)
		{
			holders = componentRegistry.getComponentHolders();
		}
		 else 
		{
			holders = componentRegistry.getComponentHolders(bundles);
		}
- Thanks for reporting, I've fixed this in master
