Title

Helm3 upgrade --install does not respect the --version flag

Description
I used the 
```
helm upgrade --install $AppName $AppChartLocation --namespace=$AppNamespace --version=$AppChartVersion
```
to upgrade/install the chart. And 
`AppChartVersion=0.0.0-${CI_COMMIT_REF_SLUG}+${CI_COMMIT_SHORT_SHA}`

e.g. `0.0.0-7-featureA+47f46c46`, `0.0.0-7-featureA+959728d8`

In my chart repo, the `0.0.0-7-featureA+959728d8` is uploaded first and then `0.0.0-7-featureA+47f46c46`.

When I ran `helm upgrade --version=$AppChartVersion`(abbreviated for brevity) with `AppChartVersion=0.0.0-7-featureA+47f46c46`, helm installed the chart `0.0.0-7-featureA+959728d8`. I expected helm to respect the version that I provided which is `0.0.0-7-featureA+47f46c46` instead. 

Output of `helm version`:
`version.BuildInfo{Version:"v3.0.0-beta.5", GitCommit:" ", GitTreeState:"clean", GoVersion:"go1.13.3"}`

Output of `kubectl version`:
```

```
