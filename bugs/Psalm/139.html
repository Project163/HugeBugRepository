Title

Function existence not checked or leads to fatal error after unrelated function_exists call.

Description
Hi there, loving this tool.

I believe I've found a similar issue to #97—this time instead related to `function_exists()` checks.  Specifically, existence of other functions is not checked correctly following a `function_exists()` call.  

- In most scenarios, this means the `UndefinedFunction` issue is simply unreported.
- Referencing (without the preceding `\`) a global function declared in a stubs file from a non-global namespace causes a fatal error.  (Sorry that's a mouthful, see the example below).

I've tried to enumerate the working and failing cases here.

**Directory structure:**
```
- psalm.xml
- stubs.php (when specified)
- src
    - main.php
```
