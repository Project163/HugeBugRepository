Title

Error (HTTP 404) When Assigning Teams to Repos

Description
### Description

Since Gitea 1.17.0, normal users cannot assign organization teams to organization repositories. This task can currently only be done by administrators.

Instead of search results, the search box shows the error message "There was an issue querying the server" (see attached screenshot). The web developer console shows that the query to `/org/ /teams/-/search?q=test` returns HTTP 404.

I would expect to at least see all groups that I'm assigned to.
