Title

Previous path traversal fix incomplete (CVE-2024-31860)

Description
A similar path traversal issue to CVE-2024-31860 can still be reproduced by double-encoding `..` (e.g., %252e%252e). This bypasses the existing validation and allows unintended file access. The issue may be resolved by decoding the path multiple times before validation.
