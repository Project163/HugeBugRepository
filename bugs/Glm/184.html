Title

Wrap functions using non existant members

Description
The function [Link: `repeat`, `mirrorRepeat` and `clamp`] use API calls - `tvecX ::size_type` and `tvecX ::value_size()` - that do not exist:

```
...
for(typename tvec2 ::size_type i = 0; i  ::value_size(); ++i)
...
```
Discussion
- This issue is fixed in GLM 0.9.8 and master branches.
