Title

Allow sstableloader to work with 3rd party authentication providers

Description
When sstableloader was changed to use native protocol instead of thrift there was a regression in that now sstableloader (BulkLoader) only takes  username  and  password  as credentials so only works with the  PlainTextAuthProvider  provided by the java driver. 

 Previously it allowed 3rd party auth providers to be used, we need to add back that ability by allowing the full classname of the auth provider to be passed as a parameter.
