Title

[useFieldArray] Appended but removed fields reappear in dirtyFields after an other append

Description
**Describe the bug**
When I append (or prepend or insert) a row to a fieldArray, the dirtyFields are also populated with it. When I reset the form, the dirtyFields become empty again. So far so good.
But when I append (or prepend or insert) a new row to the fieldArray, **two rows** are added to dirtyFields. If I repeat reset and append, more and more rows appear in dirtyFields.

**To Reproduce**
Steps to reproduce the behavior:

1. Go to [Link: forked CodeSandbox example]
2. Click on Append (or prepend or insert at)
3. Click on Reset
4. Click on Append (or prepend or insert at)
5. Optionally repeat as many times as you like
6. Scroll down to the last paragraph about the formState.dirtyFields
4. See the always growing array in it

**Codesandbox link (Required)**
[URL]

**Expected behavior**
reset **permanently** resets form state, dirtyFields only contains the current fields' dirtiness state

**Desktop (please complete the following information):**

- OS: Win 10
- Browser: Chrome
- Version 85

**Additional context**
react-hook-form version 6.9.2
