Title

Zeppelin Quartz scheduler checks for updates against external endpoint

Description
Zeppelin uses the Quartz scheduler which has a built in update checker. This reaches out to a Terracotta server to check for updates. This should be disabled since it isn't useful and leaks information to a remote server.
