Title

Line number is not proper at EOF

Description
CSVParser.getCurrentLineNumber() is returning wrong line number (actual line number - 1) when EOF file is reached without record delimiter (\r\n).
Discussion
- Can you provide a unit test to reproduce the problem please?
- Please find the code and output below 

 Code 
======= 
public class TestCsv 
{ 
	public static void main(String[] args) throws Exception 
	{ 
		String records = "A,B,C,D\r\n" 
				+ "a1,b1,c1,d1\r\n" 
				+ "a2,b2,c2,d2"; 

 		CSVParser parser = new CSVParser(new StringReader(records), CSVFormat.EXCEL.withHeader()); 
		Iterator<CSVRecord> recordIt = parser.iterator(); 

 		while(recordIt.hasNext()) 
		{
			System.out.println(parser.getCurrentLineNumber() + " ==> " + recordIt.next());
		}

 		parser.close(); 
	} 
}
