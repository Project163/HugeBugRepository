Title

prefix "classpath:" does not work for "quarkus.flyway.locations " in native mode

Description
Flyway does not use locations configured with the prefix "classpath:" in native mode.
The configuration entry (application.properties)
- `quarkus.flyway.locations=db/custom` works (native and substrate)
- `quarkus.flyway.locations=classpath:db/custom` doesn't (substrate only)

I suggest to simply delete the "classpath:" hint inside the JavaDoc and the description.
Since it may be, that "classpath:" is not only used here, it may be interesting, if there are similar problems in other places.

Steps to reproduce the behavior:
1. Setup using "mvn io.quarkus:quarkus-maven-plugin:0.26.1:create"
2. Adding flyway as described in [Link: flyway guide]
3. Renaming "META_INF/db/migration" to "META_INF/db/custom"
4. `application.properties` entry `quarkus.flyway.locations=classpath:db/custom`
