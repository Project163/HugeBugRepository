Title

[YSQL] Index scan return in correct results for count(1/*)

Description
Jira Link: [Link: DB-5983]
### Description

 Index scan return in correct results for count(1/*) .

**Example:** 

```
create table test(k int primary key, v int);
insert into test select i, i from generate_series(1,1000) as i;
```

**Output using the seq_scan.**

```
yugabyte=#  select count(1) from test;
 count
-------
  1000
(1 row)
```

**Turn of the seq_scan and count(1)/count(*) returns 0 rows **

```
yugabyte=# set enable_seqscan to off ;
SET
yugabyte=#  select count(1) from test;                                                                  
 count
-------
... [Log Snipped] ...
 Peak Memory Usage: 8 kB
(11 rows)
```

The problem might be on the pushdown part.
- Even for a simple scan, it won't return the rows
```
yugabyte=# explain analyze select from test;
```

- ~When there is not column ref in the doc_db request, the returned is_nulls are true, while when col refs exist, the is_nulls are false. This is why PG layer stops and regards it to be empty results.~
