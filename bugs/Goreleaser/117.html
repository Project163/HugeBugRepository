Title

Some custom git engines are not supported

Description
### What happened?

We are using [Link: gerrit] in our team (in legacy terms, but this is not main point), and gerrit allows to create repository links with single path item (e.g. `ssh://quenbyako@git.example.com/myapp`, and it's a valid git repo url). But goreleaser requires (for some reason, why?) **just** building task requires a valid git repo with valid remote url. Why? Who knows. But it interferes with setting up the environment with goreleaser.

### How can we reproduce this?

* setup gerrit repo (or, easier, use proxy tool like kong, traefik, etc)
* init git repository with origin of single path item
* boom... or not boom, but there is an error.
