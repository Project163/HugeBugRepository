Title

Output Buffer Level consumption prevents custom output buffers from working

Description
Hi,

I noticed a weird behaviour as I wanted to wrap the output of a test run in an output buffer. It seems like the phpunit code closes all existing output buffers in the process. Even those opened by me.

Here is my test code:

```
php
ob_start();
include('/home/johann/development/toolbox/lib/vendor/phpunit/phpunit.phar');
ob_end_clean();

... [Log Snipped] ...
$content = ob_get_contents();
ob_end_clean();
```

The last `ob_end_clean()` call fails because all output buffers were already closed by phpunit.

The code responsible for closing ALL open output buffers is in the `phpunit.phar/phpunit/Framework/TestCase.php` file and in the `startOutputBuffering` method:

```
php
private function startOutputBuffering()
{
    while (!defined('PHPUNIT_TESTSUITE') && ob_get_level() > 0) {
        ob_end_clean();
... [Log Snipped] ...
    $this->outputBufferingLevel  = ob_get_level();
}
```

So what it does is close output buffers till the level reaches 0. That's bad if you want use your own output buffer outside. Maybe the current level should be taken into consideration.
