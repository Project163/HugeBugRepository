Title

0.20.0 - invalid enum constants for "+" and "-" values

Description
## Problem statement

* In version 0.20.0 invalid code is generated using enum values like "+" or "-". 
* The generator does not add postfixes to the generated constants, thus the variable names are not distinct anymore. 
* In v.0.19.0 an enum value like "+" added "Plus" and "-" added "Minus" to the constant name, but in 0.20.0 they add nothing, resulting in two constants with the same name.


## Swagger specification

```
kennzeichenZuAbschlag:
    type: "string"
    example: "+"
    enum:
    - "+"
    - "-"
```

## Generated golang code

```
// v0.19.0
const (

	// BestellungKonditionKennzeichenZuAbschlagPlus captures enum value "+"
	BestellungKonditionKennzeichenZuAbschlagPlus string = "+"
... [Log Snipped] ...
	BestellungKonditionKennzeichenZuAbschlagMinus string = "-"
)
```

```
// v0.20.0
const (

	// BestellungKonditionKennzeichenZuAbschlag captures enum value "+"
	BestellungKonditionKennzeichenZuAbschlag string = "+"
... [Log Snipped] ...
	BestellungKonditionKennzeichenZuAbschlag string = "-"
)
```

## Environment
go-swagger: 0.20.0
OS:  Docker  quay.io/goswagger/swagger
