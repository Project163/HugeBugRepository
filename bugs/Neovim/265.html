Title

preserve cursor position more reliably

Description
- `nvim --version`: 0.3.1
- Vim (version: 8.0) behaves differently? No
- Operating system/version: macOS 10.13.6
- Terminal name/version: 4.4.23(1)-release
- `$TERM`: xterm-256color

### Steps to reproduce using `nvim -u NORC`

```
nvim -u NORC file1 file2
M
ww
:2b
:1b
```

### Actual behaviour
When switching back to file1 from file2, the line position of the cursor was restored, but the column position of the cursor was reset to the first column.

### Expected behaviour
When switching back to a buffer, the column and line position of a cursor are restored.
Discussion
- Try this:

    :set nostartofline

However I wish this behavior was more comprehensive, for example it drives me crazy that `:edit` screws up other windows showing the same buffer. I messed around with this in [URL] but the interactions are nightmarish and I haven't cracked the nut yet.
