Title

The globber will sometimes erroneously return a permission denied exception when there is a non-terminal wildcard

Description
The globber will sometimes erroneously return a permission denied exception when there is a non-terminal wildcard.  The existing unit tests don't catch this, because it doesn't happen for superusers.
