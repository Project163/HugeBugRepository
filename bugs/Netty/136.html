Title

Infinity-loop if write in AioSocketChannel fails

Description
There is a high CPU usage potential issue in Netty when SSL is used. I was able to reproduce it only in NetBeans (I'm using v7.3) in both debug and run mode. The issue does not occurs when the program is run from the command prompt. However, this may be due the different speed in the execution.

The issue occurs when the client uploads binary data to the server and terminates the connection before the server can send all text responses back (it can probably happen in other configurations as well). At that point the server starts to use 100% of a CPU core probably due an infinite loop.

Although this may not be an actual bug since it is only reproducible in NetBeans I'm submitting it just in case. It is possible that the different speed in execution causes the problem to manifest. In addition it may not occur on each run. The program may have to be run a few times (usually two is enough).
