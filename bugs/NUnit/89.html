Title

NUnitLite XML output is not consistent with the engine's

Description
There are four key differences:
1. The engine now has two added attributes in the test-run element. NunitLite does not.
   
   **Update:** Neither of these is needed in the nunitlite output
   - `engine-version` - because no engine is involved
   - `clr-version` - because nunitlite is running in process with the tests, so it's the same version
2. The engine no longer has an environment element under test-run, it's under test-suite.
3. The engine creates a test-filter element under test-run. NUnitLite does not.
4. The engine creates a settings element under the test-suite for each assembly. NUnitLite does not.

This is an easy fix only if we don't mind adding code in NUnitLite that duplicates the engine and framework. It's possible that only some of the above items will get fixed for the RC.
