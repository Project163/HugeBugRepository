Title

stubtest: incorrect runtime signature of cython `__cinit__` methods

Description
Originally posted in [URL] (slightly edited):

---

I'm seeing a bunch of new errors pop up when running stubtest on [Link: scipy-stubs] using mypy master ([Link: `ffe2db8`]).

All errors are seem to be related to `__cinit__` Cython methods:

- `scipy.io.matlab._mio5_utils.VarReader5` (not public api)
  - scipy: [URL]
  - scipy-stubs: [URL]

- `scipy.stats._unuran.unuran_wrapper.NumericalInversePolynomial`, re-exported as `scipy.stats.sampling.NumericalInversePolynomial`
  - scipy: [URL]
  - scipy-stubs: [URL]
- `scipy.stats._unuran.unuran_wrapper.NumericalInverseHermite`, re-exported as `scipy.stats.sampling.NumericalInverseHermite`
  - scipy: [URL]
