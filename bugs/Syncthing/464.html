Title

Fd leak when temp file cannot be truncated

Description
If the truncate call fails after we've opened a temp file we will return with an error, leaving the temp file fd open.
Discussion
- Don't we do that for all kind of errors in the shared puller state? That state then gets sent to the finisherChan and thus the fd is closed in `finalClose`.
- Nope, because in this specific case we error before we store the fd on the puller state, thus there is nothing to close later. It's the only case this happens.
