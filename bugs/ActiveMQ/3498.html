Title

Control if the queue exists before browsing in the WebConsole

Description
By default, the WebConsole has an admin user. This admin user can create queues (using the corresponding text field and button). 

 If a non-admin group/user is added, obviously this non-admin user can't create queue. However, via the browse URL ( [URL] , it's possible to create a new queue (implicitly) without being an admin. 

 It's an expected behavior from a broker standpoint, but, it could be confusing for WebConsole users. We should do a small improvement in the WebConsole, which is basically checking the queue exists (previously created by a WebConsole admin user) before being able to browse it.
