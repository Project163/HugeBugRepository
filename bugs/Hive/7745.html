Title

ObjectStore.cleanWriteNotificationEvents and ObjectStore.cleanupEvents OutOfMemory on large number of pending events

Description
As in  [URL] if there are large number of events that haven't been cleaned up for some reason, then ObjectStore.cleanWriteNotificationEvents() and ObjectStore.cleanupEvents can run out of memory while it loads all the events to be deleted. 
It should fetch events in batches.
