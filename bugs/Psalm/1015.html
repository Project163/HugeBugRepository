Title

False positive with amphp

Description
I created a simple reproducer here: [URL]

Just clone, run composer install and vendor/bin/psalm. You'll get these errors:

```
ERROR: MixedReturnTypeCoercion - src/index.php:3:13 - The declared return type 'Amp\Promise ' for test is more specific than the inferred return type 'Amp\Promise ' (see [URL]
/** @return \Amp\Promise  */


ERROR: MixedReturnTypeCoercion - src/index.php:6:12 - The type 'Amp\Promise ' is more general than the declared return type 'Amp\Promise ' for test (see [URL]
    return \Amp\call(function (): Generator {
        yield from [];
    });
```

The [Link: Generator] however has no `return` statement which means the Promise is resolved to nothing. As such `Promise ` is correct here.
