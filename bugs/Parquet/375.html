Title

Apparent race condition in CharsetValidator

Description
The  CharsetValidator  has a static singleton instance at  BinaryTruncator.DEFAULT_UTF8_TRUNCATOR.validator , so it can be accessed from multiple threads. All threads operate on a shared "dummy buffer" for decoding.
