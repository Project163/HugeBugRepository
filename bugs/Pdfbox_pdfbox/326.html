- After a first look at your documents I came to the following conclusions: 

 test_openoffice301.pdf: 

 
	 it uses ArialNarrow as font not DejaVu as mentioned 
	 the problem seems to be an (unicode-)encoding issue. There are some other jira-issues with similar problems 
 

 test_word+pdfcreator.pdf: 

 
	 in some way pdfbox can't read the embedded font and consequently it throws an exception 
	 finally the font isn't found and the fallback (Arial) is used
- I just verified that the text is properly extracted from both files.
