Regarding the [Link: previous PR], there are 3 changes.

- path

### path

`page.path` is already sanitized without this change.
(Maybe already sanitized at browser level.)
Therefore test for sanitizing `page.path` should not fail without this change.
But I think we should add sanitizing process and tests because preventing XSS is very important and I'm not sure 100% ALL browser has such sanitizing process.

### query

The type of `page.query` is `URLSearchParams`.
And `URLSearchParams#toString` has sanitizing function.
Therefore this test case also should not fail without this change.
But again I think we should add this test also.

e.g.
```js
new URLSearchParams("key=  alert(3) ").toString()
-> 'key=%3C%2Fscript%3E%3Cscript%3Ealert%283%29%3C%2Fscript%3E'
```
