Title

Wasabi: Only the first 1001 items per folder seem to be listed

Description
Hi there,

I'm trying to sync a borg backup archive to Wasabi. I'm using Ubuntu 16.04 64-bit and tried rclone 1.36, 1.37 and also the latest beta 1.37-117, with similar results.

The archive consists of about 4000 5 MB files in a single directory, together with a few other files one level up. rclone uploads them all without a problem, and I can see them in the Wasabi web interface.

When I sync again, rclone wants to re-upload all files beyond the first 1000 in the archive folder. It seems that the list returned from Wasabi only shows the first 1000 items.

A `rclone ls` also only lists about 1000 items:

          26 borg-backup/README
         635 borg-backup/config
       19431 borg-backup/hints.4787
    51516698 borg-backup/index.4787
         190 borg-backup/integrity.4787
          16 borg-backup/nonce
     5253087 borg-backup/data/0/100
     5383536 borg-backup/data/0/1000
     5272999 borg-backup/data/0/1001
     5420980 borg-backup/data/0/1002
     [...]
     5412105 borg-backup/data/0/1929
     5253476 borg-backup/data/0/193
     5289456 borg-backup/data/0/1930
     5274946 borg-backup/data/0/1931

`--fast-list` doesn't make a difference, either.

Wasabi was configured according to their documentation (https://wasabi.com/wp-content/uploads/2017/08/Wasabi_AppNote_Rclone.pdf?x55444).

I'm new to S3-compatible storage. Maybe I'm missing some configuration on the backend? Or is Wasabi simply not behaving correctly?

Thanks
Jochen
