Title

Documentation error in Mesh material property

Description
##### Three.js version

- [x] Dev

##### Browser

- [x] All of them

##### OS

- [x] All of them



The documentation of the `Mesh` class states:

.material

An instance of material derived from the Material base class, defining the object's appearance. Default is a MeshBasicMaterial with a random colour.


But I just saw in my Collada loader that the `material` property contains an array.
Discussion
- Yes, `.material` might represent an array of material objects. Looks like the documentation is not 100% precise in this context.
