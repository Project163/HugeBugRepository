Title

ESQL: Load non-stored text sub field

### Problem Description

If you make a mapping like this:
```
"properties": {
  "foo": {
    "type": "keyword",
    "fields": {
      "text": { "type": "text" }
    }
  }
}
```

Then you can enable synthetic _source on it because the top level field is enough to store the value. But the sub-field will fail to load. In fact, ESQL will give up because it doesn't think it should be possible to get a text field in synthetic source mode without either storing the field or using a synthetic _source storage delegate. Well, in this case there is a delegate - but we don't find it.
