Title

Async tests not working on Windows 10 Universal

Description
Copied from nunit/nunit.xamarin#35 reported by @tofutim. I have confirmed that this is an issue with the portable framework, so may be an issue with other platforms.

From the other issue

Is this a UWP, nunit, nunit.runners issue? I added this to the tests in this solution after seeing it in mine. This is a result from the UWP emulator (Windows 10 mobile) in VS2015 on Server 2012 R2.

```
[Test]
    public async Task AsyncTest()
    {
        var result = await anInt();
        Assert.AreEqual(42, result);
... [Log Snipped] ...
        return 42;
    }
```

[Image: image]
Discussion
- The offending code is in `AsyncInvocationRegion.cs`

```
C#
        private class AsyncTaskInvocationRegion : AsyncInvocationRegion
        {
            private const string TaskWaitMethod = "Wait";
            private const string TaskResultProperty = "Result";
... [Log Snipped] ...
            }
        }
```

Notice, we reference methods and properties by name, then use reflection to access them. This is dangerous on multiple platforms where they may not be available. In this case, the Result property is not available when we try to get the `taskResultProperty`

I think this is pretty serious, possibly a candidate for a 3.0.1 release?
- should async tests work in UWP?
