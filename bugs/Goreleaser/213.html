Title

do not link files on docker pipe

Description
some docker pipe tests are failing with things like:

```

```

seems to be related to some change in github actions, as goreleaser's code didn't change anything related to this lately.

PS: the docker pipe do some hard links indeed, maybe we should change that to copy instead as it already caused other problems in the past?
