### What happened?

When using a custom VPN like `new SolaceContainer("solace/solace-pubsub-standard: ").withVpn("myVpn")` some permissions (capabilities?) seem to be missing, as one can no longer
- [Link: provision queues]
- [Link: create flows]
_(and maybe more)_

Running the same code omitting `.withVpn("myVpn")` works just fine.
