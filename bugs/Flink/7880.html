Title

Array OOB error when trying to get a binary from a non-zero offset from a vector

Description
We have noticed that an OOB error is being thrown when trying to invoke getBinary when the following conditions are met: 
 
	 There are multiple elements in a HeapArrayVector 
	 When trying to get an element from a non-zero offset of the array
