Title

[?] Explicit mixed in totallyTyped mode

Description
I'm not sure if this is a bug, or if Psalm is expected to complain on any mixed assignment, even when both LHS and RHS are explicitly typed as mixed. But using pretty much equivalent union type instead of `mixed` gets rid of error, and at the very least emitted issue misses the RHS type:
```
php
 itemsMixed[$key]` assignment:
```
ERROR: MixedAssignment - q.php:28:9 - Cannot assign  to a mixed type
        $this->itemsMixed[$key] = $value;
```
and the error message fails to specify *what* cannot be assigned to a mixed type (and I wonder why wouldn't it be possible to assign `mixed` to `mixed`).
Discussion
- That's a definite bug
- The message, or the issue emitted?
