Title

Bundled AppImage does not execute

Description
**Describe the bug**
The AppImage generated by the bundler does not run. In particular, it yields the error "cannot execute binary file: Exec format error".

I have managed to fix this by changing the `build_appimage` script in `src-tauri/target/release/bundle/appimage` to download an AppImage runtime and appending it to the image. In this case, the AppImage bundle successfully executes, but in the next execution of 
`yarn tauri:build ` the script `build_appimage` is overwritten.

**To Reproduce**
(This is based on a project created using `vue-cli-plugin-tauri`)
Steps to reproduce the behaviour:
1. Create new project using
```
vue create my-tauri-app
cd my-tauri-app
vue add tauri
```
2. Run `yarn tauri:build`
3. Go to `src-tauri/target/release/bundle/appimage`
4. Run `./app.AppImage

**Expected behavior**
Running the AppImage should create a window with the default vue application.

OS:Linux(5.6.12-1-MANJARO) - linux/x64
Node:14.1.0
NPM:6.14.4
Yarn:1.22.4
Rustc:1.43.1

- Hi. There were a few more problems in the script `build_appimage` that I had forgotten to mention in my post. I fixed them first and then started focusing on the AppImage runtime, so I forgot about the other problems. Apologies for the omission. Here's a rundown of the issue I have found and a version of the script that works for me. I hope this helps.

1) The script is in the `appimage` folder, so the `deb` folder is below `appimage`, not inside `bundle`.
2) Before copying `app` and the icon to `app.AppDir`, we need to `cd` into `app.AppDir` as the folder `usr` has already been copied.
3) The path to the icon has a type in `256x265`, it should be `256x256`.
4) We need to `cd` back to `appimage` before creating and copying the `.desktop` file to created it in appimage. 
5) The appimage should not be redirected into `app.AppImage` not appended. Appending it only works if the file was empty or did not exist before.

With this changes (including the download of the runtime), the script builds an AppImage that works for me. Note that if you run `yarn tauri:build`, the script is reverted back. 

Here's the full script that worked for me:

```
#!/bin/bash

mkdir -p app.AppDir
cp -r ../deb/app_0.1.0_amd64/data/usr app.AppDir

... [Log Snipped] ...
cat app.squashfs >> app.AppImage
chmod a+x app.AppImage
```
