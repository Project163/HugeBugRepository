Extraneous whitespace in expression ASTs

# 🐞 bug report

### Affected Package

@angular/compiler


### Is this a regression?

### Description

The expression parser leaves trailing whitespace when generating some expressions ASTs. This is already a known issue:

[URL]

This extra whitespace should probably be stripped so that e.g. diagnostic messages do not have trailing whitespace. See [URL] for an example of this affecting the language service.

This is unrelated to #31898.
