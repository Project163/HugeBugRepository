Title

DELETE operation with no body and Accept: */* does not reach handler

Description
A DELETE operation that is sent no body and has Accept: _/_ in the header never reaches our handler.
# 

Request:

```
curl -i -X DELETE -H 'Accept: */*' [URL]
```
# 

Result:

HTTP/1.1 415 Unsupported Media Type
Content-Type: application/json
Date: Sat, 05 Mar 2016 00:07:52 GMT
Content-Length: 100

{"code":415,"message":"unsupported media type \"\", only [application/json text/plain] are allowed"}
