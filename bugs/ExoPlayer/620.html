Title

Stream with Invalid PMTs?

Description
### [REQUIRED] Issue description
Mpeg-ts stream coming from DVB-S broadcast contain PMTs that contain invalid "program_info_length" that cannot be handled by Exoplayer.

This issue also had issues with "program_info_length": [URL]

It also mentined a workaround that also works in my case:
```
if (programInfoLength > sectionData.bytesLeft()) {
  Log.w(TAG, "Invalid programInfoLength: " + programInfoLength);
  return;
}
```

Comments for the above issue states that errors in streams should not be handled with workarounds in Exoplayer which I totally buy, but in this case the stream comes from a network broadcast company in europe that obviously uses this technique for some reason which makes me unsure of how to handle the situation.

If this is a "won't fix" please give me some guidelines of how to proceed. To I need to maintain this workaround in a fork or is there a better solution?


### [REQUIRED] Reproduction steps
