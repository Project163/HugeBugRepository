Title

Proxy excluded URLs still processed by ZAP

Description
Steps to reproduce the issue:
1. Run ZAP;
2. Exclude everything from the proxy (e.g. .*);
3. While proxying through ZAP access The BodgeIt Store login page (to set some cookies);
4. Note that in HTTP Sessions tab there's a cookie from The BodgeIt Store, proxy excluded requests should pass through ZAP.

ZAP Version:
2.5.0 although previous versions should also be affected.
