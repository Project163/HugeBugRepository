Title

Documentation (--docs) mode not running in local development

Description
**Describe the bug**
According to [Link: Storybook Docs] running `start-storybook --docs` should run a local instance in documentation mode, where the navigation is flattened and the toolbar is removed... similarly to how a public docs would be distributed. However running `start-storybook --docs` appears to run a local instance of Storybook in a normal mode where the navigation is not flattened, and the toolbar is present.

**To Reproduce**

1. In Terminal, run `yarn start-storybook --docs`
2. When everything is compiled, open storybook instance in browser
3. Be sad because its not in docs mode ☹️ 

I've also tried this with a fresh, unedited storybook install, and the results are the same.

**Expected behavior**
I expect that running `start-storybook --docs` to run a local instance of storybook in documentation mode [Link: as described] (flattened navigation and no toolbar).
