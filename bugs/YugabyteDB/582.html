Title

[DocDB] Split child tablet replicas Raft config inconsistency

Description
### Description

In the first version, on applying `SPLIT_OP` in the parent tablet we were copying the current parent tablet’s Raft state (committed config + Raft log + Raft metadata) into child tablets.
That could lead to child tablet replicas Raft state inconsistency if we allow copying the current parent tablet’s Raft state into child tablet on an outdated node after parent tablet Raft config or term change.
