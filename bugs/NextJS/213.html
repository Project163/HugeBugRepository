### Describe the Bug

Running `npm run build` outputs this warning:

```
warn  - Invalid next.config.js options detected: 
  - The value at .experimental.esmExternals must be a boolean but it was a string.
```

But:
* `esmExternals` has long been allowed to be `'loose'` instead of a boolean
* [Link: that setting is still checked for]
* [Link: an integration test still has such a configuration].

So I think the warning is erroneous. Or else some documentation of a change is missing.

### Expected Behavior

No warning.

[URL]

### To Reproduce

Put this in your `next.config.js` exports:

```js
  experimental: {
    esmExternals: 'loose',
  }
```
