Title

Surefire swallows redirected test output if uncaught exceptions occur in forked SurefireBooter

Description

	 forks a test and 
	 is configured to redirect test output to a file and 
	 encounters an uncaught exception in its internals 
 

 the tests fail (as expected) but the user does not get any information about the error, i.e. the txt files under target/surefire-reports are of zero length. This can be quite fustrating.
