Title

Reset function doesn't trigger Yup validation

Description
First of all, thank you for the great library!
I wasn't able to find something related to my issue that's why I've created new one.

**Describe the bug**
Starting from version 6.9.1 I see incorrect behavior of the `reset` function. If I set valid async form values using `reset` I get `formState.isValid = false` and at the same time `errors` object is empty.
All form fields are filled correctly.
Yup resolver is used. The bug is not reproducible without yup schema.
In order to trigger validation and make form valid you need to change an input field.

**To Reproduce**
1. Go to [Link: sandbox];
2. Notice that validation works (submit button is enabled);
3. Switch `react-hook-form` version from `6.9.0` to `6.9.1` or higher
4. Check browser console. Submit button is disabled. All fields are filled.

**Codesandbox link (Required)**
I've forked your `Async Set Form Values` example and set up yup resolver.
[URL]

**Expected behavior**
When form fields are filled asynchronous validation should work.
