Title

isunit is case sensitive

Description
It is just a small thing. According to [Link: css spec] unit identifiers should be case-insensitive within the ASCII range.

Isunit function is case sensitive:

```
a { unit-casing: isunit(32PX, px); }
```

compiles into 

```
a {
  unit-casing: false;
}
```

It probably should return:

```
a {
  unit-casing: true;
}
```
