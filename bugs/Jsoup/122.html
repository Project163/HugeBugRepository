Title

Improperly formatting text within a tag

Description
Hi,
apparently Jsoup formats the content inside a ` ` tag, resulting in a non-equivalent rendering.
Given the following HTML:

```
html
 
 
  Test  
 
... [Log Snipped] ...
 
 
```

And running the following Java code

```
java
final String html =
        " \n"
        + " \n"
        + "  Test  \n"
... [Log Snipped] ...
final String parsed = Jsoup.parse(html).toString();
System.out.println(parsed);
```

the result is

```
html
  
  
 
  Test 
... [Log Snipped] ...
 
 
```

I'm using latest 1.15.3 version
Discussion
- I'm not able to repro this in 1.15.4. See [Link: this example], returns:

```html
   
        TEST     
   
```

jsoup does test if an element is in a ` ` (in `Element#preserveWhitespace()`) and will preserve textnode formatting; and should not be otherwise formatting elements. There is a limit (6 up levels) of stack depth as an optimization for serialization time, but that wouldn't be impacting in this instance. I guess this issue was resolved in one of the pretty-print fixes in 1.15.4 but haven't checked yet.

Can you review with 1.15.4? If you find other cases where's it's not working as desired, happy to take a look.
- Hi, thank you for your answer, you are right about the minimum example, it seems to be fixed.

Sadly, I'm still experiencing the problem when moving to my acutal document; I cannot provide the full document, but I can provide another example:

```html
 
         TEST     
 
```

The following code under Jsoup 1.15.4 will be formatted as:

```
html
 
   
  
   
... [Log Snipped] ...
  
 
```

Note that I replaced the ` ` tag to an Office-namespaced paragraph tag ` `.

HTML documents with these tags are usually produced by tools like Microsoft Word and Microsoft Outlook.
