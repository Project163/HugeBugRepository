Title

Artifactory throws EOF during upload

Description
**Describe the bug**

Hi, 

I am using artifactory extension to upload my build artifacts. While uploading the artifacts, goreleaser fails with following exception

` ⨯ artifactory: upload failed error=EOF instance=production username=debtest`

Note that I am trying to upload a debian package generated using `nfpm` to artifactory. I have setup debian repository on my artifactory instance

**To Reproduce**

Just build any package and try to upload to artifactory. 

```
yaml
# .goreleaser.yml

project_name: package

... [Log Snipped] ...
        empty_folders:
          - /var/log/package
```

**Expected behavior**

Package should be uploaded without any issue

**Environment (please complete the following information):**

- OS: Mac
- OS version: 10.15.4
- GoReleaser Version: 0.138.0
- Artifactory version: 2.14.17

**Additional context**
Going through goreleaser codebase, I figured that after successful upload (status code between 200 and 299), it tries to unmarshal response into `artifactoryResponse` struct. 

Artifactory version I am using is 2.14 which is not the latest one (3.x). 
Not aware of API responses of 3.x PUT API but 2.xx PUT API returns 201 status code with no response body which I suspect is causing EOF since there is nothing to unmarshal. Is there any plan to support artifactory 2.x or is my debugging incorrect ?


Also noticed that output of API response is actually discarded in `artifactory.go`. Following is the code snippet - 
```go
		var r artifactoryResponse
		err := json.NewDecoder(res.Body).Decode(&r)
		return err
```

Is there any reason of parsing the response if it just going to be discarded ? This looks redundant since status code is anyway checked for proper range (between 200 & 299)
Discussion
- we should probably ignore the EOF error there... 🤔

thanks for the issue :)
