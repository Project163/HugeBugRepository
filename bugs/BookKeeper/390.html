Title

Fix findbugs warnings after bumping to java 8

Description
after bumping to java 8, the ci jobs fail with findbugs warnings. we'd need to fix all the findbugs warnings.
Discussion
- I can take a look, can I assign the issue to myself ?
- The fix is quite simple, but I have only one doubt, in BookKeeperAdmin:LedgerEntriesIterator 
old code is 
  
 @Override
         public  LedgerEntry next() {            
            ++nextEntryId;
            LedgerEntry entry = currentEntry;
            currentEntry =  null ;
             return  entry;
        }
 
  

 my proposal is 

  
 @Override
         public  LedgerEntry next() {
             if  (lastEntryId > -1 && nextEntryId > lastEntryId) {
                 throw   new  NoSuchElementException();
            }
            ++nextEntryId;
            LedgerEntry entry = currentEntry;
            currentEntry =  null ;
             return  entry;
        }
 
  

 FindBugs complaints that a call to "next()" will never throw NoSuchElementException. 
The logic of this iterator is not very clear to me in case of lastEntryId = -1 

 The proposed fix adds the throw statement for a sure NoSuchElementException case, but leaves uncovered the lastEntryId = -1 case.
