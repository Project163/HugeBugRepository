Title

Quarkus DEV mode requires 3.9.6 Maven

Description
### Describe the bug

After [URL] Quarkus now requires Maven 3.9.6 in DEV mode. I don't see this documented in migration guide and from what I understand from PR title, it is Quarkus that requires 3.9.6, not the Quarkus application.

### Expected behavior

Fix requirement or document the situation.

### Actual behavior

Exception is raised: 

```
[mvavrik@apc-ap8641-3a-d11d code-with-quarkus]$ mvn quarkus:dev
[INFO] Scanning for projects...
[INFO] 
[INFO] --------------------- ---------------------
[INFO] Building code-with-quarkus 1.0.0-SNAPSHOT
... [Log Snipped] ...
[ERROR] For more information about the errors and possible solutions, please read the following articles:
[ERROR] [Help 1] [URL]
```

### How to Reproduce?

Steps to reproduce the problem:

```
quarkus create app
cd code-with-quarkus/
sed -i -e "s| io.quarkus.platform | io.quarkus |" pom.xml
sed -i -e "s| 3.13.2 | 999-SNAPSHOT |" pom.xml
mvn -DskipTests -DskipITs clean install
mvn quarkus:dev
```
