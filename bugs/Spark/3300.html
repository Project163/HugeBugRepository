Title

Improve LIKE pattern in "SHOW TABLES / FUNCTIONS LIKE " DDL

Description
LIKE <pattern> is commonly used in  
  
   SHOW   TABLES  / FUNCTIONS  
  
  etc DDL. In the pattern, user can use `|` or `*` as wildcards. 

 I'd like to address a few issues in this JIRA: 
 
	 Currently, we used `replaceAll()` to replace `*` with `.*`, but the replacement was scattered in several places; it is good to have one place to do the same thing; 
	 Consistency with Hive: the pattern is case insensitive in Hive and white spaces will be trimmed, but current pattern matching does not do that. For example, suppose we have tables t1, t2, t3, 
  
  SHOW   TABLES   LIKE   '  T*  ' ;  
  
  will list all the t-tables.  
	 Sort the result. 
Please use Hive to verify it.
