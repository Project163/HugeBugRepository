Title

relaysrv crash after some weeks of operation

Description
strelaysrv v1.22.1 "Fermium Flea" (go1.19.2 linux-amd64) deb@build.syncthing.net 2022-11-02 06:27:53 UTC [noupgrade]

After some weeks of operation syncthing relayserver crashes with (from the debug log):
```
syncthing-relaysrv: panic: runtime error: invalid memory address or nil pointer dereference
syncthing-relaysrv: [signal SIGSEGV: segmentation violation code=0x1 addr=0x30 pc= ]
syncthing-relaysrv: 
syncthing-relaysrv: goroutine 14 [running]:

syncthing-relaysrv: #011github.com/syncthing/syncthing/cmd/strelaysrv/main.go:280 +
```

There were around 7000 session handled on the day of the crash. 
The crash happened already several times. I've never experienced such a crash with versions before 1.22.1.
