Title

`AlterConsumerGroupOffsetsHandler` does not handle partition errors correctly.

Description
While reviewing  [URL] we have noticed that `AlterConsumerGroupOffsetsHandler` does not handle the partition errors correctly. The issue is that any partition error fails the entire future returned in the results instead of failing only the future of the corresponding partition. This is a regression that was introduced by KIP-699.
