Title

Remove unused MR Temp file localization from Tasks

Description
HIVE-1408   introduced code that is currently commented out (i.e.: dead code), with a comment saying needs further development ( HIVE-1484 ). It's been like this for close to 3 years.  

 I suggest removing the code until such time that someone picks up that work. At that time they can decide if they want to use this code or pursue another route (FS shim?).
Discussion
- I think it makes sense to remove this piece of code. Executing query locally (instead of on cluster) isn't the common use case for Hive. So, unless anyone really is interested in optimizing that code path, its better to get rid of it to lessen our technical debt.
