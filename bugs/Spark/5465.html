Title

BigDecimal multiplication sometimes returns null

Description
The multiplication of two BigDecimal numbers sometimes returns null. Here is a minimal reproduction: 

  
 object Main  extends  App {
   import  org.apache.spark.{SparkConf, SparkContext}
   import  org.apache.spark.sql.SparkSession
   import  spark.implicits._
  val conf =  new  SparkConf().setMaster( "local[*]" ).setAppName( "REPL" ).set( "spark.ui.enabled" ,  " false " )
  val spark = SparkSession.builder().config(conf).appName( "REPL" ).getOrCreate()
  implicit val sqlContext = spark.sqlContext

   case   class  X2(a: BigDecimal, b: BigDecimal)
  val ds = sqlContext.createDataset(List(X2(BigDecimal(-0.1267333984375), BigDecimal(-1000.1))))
  val result = ds.select(ds( "a" ) * ds( "b" )).collect.head
  println(result)  // [ null ]
 }
Discussion
- This happens because there is an overflow in the operation. I am not sure of what should be done in this case. The current implementation returns null when an operation cause a loss of precision.
- It's surprising because in this case the resulting value seems to fit within the range of representable values: 

  
 scala> val result = BigDecimal(-0.1267333984375) * BigDecimal(-1000.1)
result: scala.math.BigDecimal = 126.74607177734375

scala> sqlContenxt.createDataset(List(result)).head == result
res10:  Boolean  =  true 
 
  

 Also Spark will silently loses BigDecimal precision in other circumstances: 

  
 scala> val tooPrecise = BigDecimal( "126. " )
tooPrecise: scala.math.BigDecimal = 126. 

scala> val ds = sqlContenxt.createDataset(List(tooPrecise))
ds: org.apache.spark.sql.Dataset[scala.math.BigDecimal] = [value: decimal(38,18)]

scala> ds.head
res14: scala.math.BigDecimal = 126. 

scala> ds.select(ds( "value" ) * BigDecimal(1)).head
res15: org.apache.spark.sql.Row = [126. ]
 
  

 > I am not sure of what should be done in this case 

 Given that Sparks' BigDecimal have bounded precision I would consider following what is done for other numeric representations and return the closest representable value in case of overflow.
