Title

elasticsearch-plugin spits out the usage information if you ask it to remove a plugin that isn't installed

Description
`elasticsearch-plugin` spits out the usage information if you ask it to remove a plugin that isn't installed. It really shouldn't do that. Example

```
manyair:x-plugins manybubbles$ backwards/elasticsearch-5.0.0/bin/elasticsearch-plugin remove x-pack
-> Removing x-pack...
A tool for managing installed elasticsearch plugins

Commands
... [Log Snipped] ...
-v, --verbose  show verbose output
ERROR: plugin x-pack not found; run 'elasticsearch-plugin list' to get list of installed plugins
```

I couldn't see the error because of all the usage information....
