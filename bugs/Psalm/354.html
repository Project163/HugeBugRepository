Title

Potential false positive "RedundantCondition".

Description
For the following block of code

[URL]

after changing the string `Cake\ORM\Entity` to `\Cake\ORM\Entity::class` psalm reports error

```
ERROR: RedundantCondition - src/Datasource/EntityTrait.php:626:13 - Found a redundant condition when evaluating $class and trying to reconcile type 'class-string(Cake\ORM\Entity)' to class-string(Cake\ORM\Entity)
```

Since `Cake\Datasource\EntityTrait` is used by `Cake\ORM\Entity` this error is understandable but the trait could be unused in some other class too, hence checking that `$class` does not evaluate to `Cake\ORM\Entity::class` is necessary, so check like `$class === \Cake\ORM\Entity::class` should not throw an error.
