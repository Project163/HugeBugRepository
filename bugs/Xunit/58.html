Title

All runner packages should set developmentDependency=true

Description
When installing the xunit.runner.console package to a project, the `developmentDependency=true` attribute should be set on that package in the packages.config file so that the dependency does not propagate to other projects that will interpret it as a package dependency (e.g. NuProj).

This can be fixed by setting adding this tag to the .nuspec file for the xunit.runner.console package:

``` xml
 true 
```
