Title

Scanning plugin.path needs to support relative symlinks

Description
Discovery of Kafka Connect plugins supports symbolic links from within the  plugin.path  locations, but this ability is restricted to absolute symbolic links. 

 It's essential to support relative symbolic links, as this is the most common use case from within the plugin locations.
