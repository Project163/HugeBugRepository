- Ok, I've figured it out, the behaviour of the "Interpolate" flag isn't strictly specified and is left to the "conforming reader" to choose. Page 2 of mori-cvpr01.pdf from   PDFBOX-2302   shows that Acrobat uses nearest-neighbour when scaling up small images on the page. However, the file from   PDFBOX-2338   which this issue is about, renders smoothly in Acrobat. In both cases, the "Interpolate" flag is not set, the difference is that the second PDF has images which are being scaled  down . 

 It seems that Acrobat honours the Interpolate flag when scaling up, but not scaling down, which makes some sense.
