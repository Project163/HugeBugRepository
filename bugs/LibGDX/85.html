Title

HTTP request cancel does not cancel the request

Description
#### Issue details
Cancelling of HTTP request using `cancelHttpRequest` method in `Net` only cancels invoking of listeners, but the actual request is still performed.

#### Reproduction steps/code
```java
HttpRequest httpRequest = /* ... */;
Gdx.net.sendHttpRequest(httpRequest, null);
Gdx.net.cancelHttpRequest(httpRequest);
```
This code will not cancel the downloading that was not yet performed.

#### Version of libGDX and/or relevant dependencies
1.10.0
