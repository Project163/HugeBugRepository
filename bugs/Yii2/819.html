Title

Illegal offset type in isset or empty in InConditionBuilder

Description
### What steps will reproduce the problem?
Set one column as array to in condition:
```
MyModel::find()
->andWhere(['in', ['id'], [['id' => 1, 'name' => 'Name1'], ['id' => 2, 'name' => 'Name2']]])
->all();
```
### What is the expected result?
Return my models where id in (1, 2)

### What do you get instead?
Exception: Illegal offset type in isset or empty
```
yiisoft/yii2/db/conditions/InConditionBuilder.php  93
 $value = isset($value[$column]) ? $value[$column] : null;
```

### Some researches
In InConditionBuilder build function check count($column), normalize it by reset($column) and call buildValues.
```
public function build(ExpressionInterface $expression, array &$params = [])
...
if ($column instanceof \Traversable || ((is_array($column) || $column instanceof \Countable) && count($column) > 1)) {
    return $this->buildCompositeInCondition($operator, $column, $values, $params);
}
... [Log Snipped] ...

$sqlValues = $this->buildValues($expression, $values, $params);
```
But in function buildValues $column is not normalized and equals to  `[ 0 => 'id']`
```
protected function buildValues(ConditionInterface $condition, $values, &$params)
{
    $sqlValues = [];
    $column = $condition->getColumn();
```

Discussion
- According to the code a composite in condition needs more than 1 column name.
I don't know if it's a requirement so it's either a bug or you need to do something like,
```php
$data = array_column([['id' => 1, 'name' => 'Name1'], ['id' => 2, 'name' => 'Name2']], 'id');
MyModel::find()
  ->andWhere(['id' => $data])
  ->all();
```
- It worked until 2.0.14 because `$column = reset($column);`  was used. After extraction InCondition 'reset' was lost in buildValues.
