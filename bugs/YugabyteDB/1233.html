Title

[YSQL] pg_node_tree broken in ysql_upgrade

Description
Jira Link: [Link: DB-13864]
### Description

Commit   modified pg_node_tree_in to support ysql_upgrade. 

The pg15 merge changed the pg_node_tree handler to use a default function:
```
PSEUDOTYPE_DUMMY_INPUT_FUNC(pg_node_tree);

/*
 * These macros generate input and output functions for a pseudo-type that
 * will reject all input and output attempts.  (But for some types, only
... [Log Snipped] ...
	PG_RETURN_VOID();			/* keep compiler quiet */ \
} \
```

So the special handling added by the ysql_upgrade diff is missing. 

Test case:
```
SET ysql_upgrade_mode = true;
SET yb_non_ddl_txn_for_sys_tables_allowed TO true;
UPDATE pg_catalog.pg_proc SET
  pronargs = 1,
  pronargdefaults = 1,
... [Log Snipped] ...
  proargdefaults = '({CONST :consttype 16 :consttypmod -1 :constcollid 0 :constlen 1 :constbyval true :constisnull false :location 83 :constvalue 1 [ 0 0 0 0 0 0 0 0 ]})'
WHERE proname = 'yb_is_database_colocated' AND proargtypes = '' AND pronamespace = 'pg_catalog'::regnamespace;
```

Errors with `ERROR:  cannot accept a value of type pg_node_tree`
