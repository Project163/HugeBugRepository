Title

failed to wrap query with labels with .exists()

Description
**Describe the bug**
In version 1.4.0 I have following error:

ArgumentError FROM expression, such as a Table or alias() object expected, got Column('col1', Text(), table= ).

trying to make `query.exists()` where `query` has labeled field in select part of statement.

**Expected behavior**
In version 1.3.23 that behaviour worked.

**To Reproduce**
```python
x = self.session.query(T1.col1.label('dfd'))
x = x.exists()
```
