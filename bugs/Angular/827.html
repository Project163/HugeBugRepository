Discussion
- Thank you for trying out Ivy! This seems to be related to #29939, I'll try to have a look at it over the weekend.
- @JoostK I dug a little deeper and it seems that if you have `"target": "es2015"` in your `tsconfig.app.json`, the command `ng build --prod` will overwrite `.d.ts` files in `./node_modules` in a weird way, essentially removing `BrowserAnimationsModule` from `./node_modules/@angular/platform-browser/animations/animations.d.ts`.

Recovering from that is impossible. You will need to delete the `node_modules` folder and run `npm install` again to fix it.

If you set `"target": "es5"` in your `tsconfig.app.json`, then this bug does not happen.

My Setup:
- Windows 10
- Node 11.14.0
- Using the same angular versions as OP
- @HitomiTenshi thanks for your insights! It took me quite a while to find where the overwrite action originated from, eventually finding that it was actually ngcc at fault. PR available in #30020
