Title

no-duplicate-case false positives with CallExpressions

Description
The `getHash` function of the `no-duplicate-case` rule does not include CallExpressions so the rule will report false positives when using function calls in case statements.

Some examples:

```
var a = 1,
    f = function(b) {
        return b ? {
            p1: 1
        } : {
... [Log Snipped] ...
        break;
}
```

```
var a = 1,
    f1 = function() {
        return {
            p1: 1
        }
... [Log Snipped] ...
        break;
}
```

```
var a = 1,
    f = function(s) {
        return {
            p1: s
        }
... [Log Snipped] ...
        break;
}
```
