- This issue is related to  [URL]

 When add splits to  KafkaPartitionSplitReader , the split reader will delete the completed partitions whose offset is over the stopping offset in the  removeEmptySplits  method.  All assigned partitions are deleted here in the test case. 

 The reason is that the timestamp of the test data is more than 7 days earlier than the test time. These messages are deleted ,and the beginning offset of the partition is set to the end, which causes  the split reader judge the partition as a completed partition and delete it. 

 We should change the timestamp of the test data to null or a recent timestamp.
