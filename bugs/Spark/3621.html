Title

Spark executor OOM during TimSort

Description
While running a query, we are seeing a lot of executor OOM while doing TimSort.

 Out of total 32g available to the executors, we are allocating 24g onheap and 8g onheap memory. Looking at the code ( [URL] we see that during TimSort we are allocating the memory buffer onheap irrespective of memory mode that is reason of executor OOM.
