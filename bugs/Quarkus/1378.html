Title

Panache entities not found when using multiple datasources in Quarkus 2.x versions

Description
### Describe the bug

I'm using the package quarkus-hibernate-orm-panache-kotlin to define multiple entities that should belong to different datasources. The classes are annotated with javax.persistence @Entity and @Column and extend the PanacheEntity class. I'm using the repository pattern to retrieve these entities. The application properties file defines multiple datasources and each one is mapped by a different peristence unit. Via rest calls these entities will then be queried. A complete example set up can be seen at [URL]

The code worked on the latests 1.x version (1.13.7.Final) of quarkus but after upgrading to any quarkus 2.x (e.g. 2.3.0.Final or 2.2.1.Final) version I receive the Error `2021-10-19 21:45:01,952 [io.qua.ver.htt.run.QuarkusErrorHandler] (executor-thread-0) HTTP Request to /user failed, error id: c1b859cc-c60c-45cd-8c92-a3e27b34a1ae-8: org.jboss.resteasy.spi.UnhandledException: java.lang.IllegalStateException: No entities were found. Did you forget to annotate your Panache Entity classes with '@Entity'?`
