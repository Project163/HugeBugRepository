Title

Pylint still doesn't like namedtuple subclasses

Description
Originally reported by: **Antony Lee (BitBucket: [Link: anntzer], GitHub: @anntzer?)**

---

This crashes pylint 1.3.1:

```
#!python
from collections import namedtuple
class C(namedtuple("C", "foo bar")):
    def __str__(self):
        return "{0.foo}: {0.bar}".format(self)
```
