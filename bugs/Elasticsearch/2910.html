- Pinging @elastic/ml-core (Team:ML)
- From you config:

```
"sync": {
  "time": {
    "field": "es_timestamp",
    "delay": "0s"
}
```

`delay` can never be `0s`. Your created index uses defaults, Lucene's default refresh interval is `1s`.

Please try again with a reasonable value for `delay`, e.g. `2s`.

(It is still a bug that we allow setting `delay` to `0s`, if the above fixes your problem, feel free to change the bug report accordingly)
