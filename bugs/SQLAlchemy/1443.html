Title

because we use PG casts aggressively in drivers now, cannot transfer varchar length to compared types

Description
### Discussed in [URL]

```py
from sqlalchemy import column, String

from sqlalchemy.dialects.postgresql import asyncpg


expr = column('x', String(2)).like('%ab%')
print(expr.compile(dialect=asyncpg.dialect()))
```

produces:

```
x LIKE $1::VARCHAR(2)
```
which is the wrong cast, the compared string is four chars.

patch as follows:

```
diff
diff --git a/lib/sqlalchemy/sql/sqltypes.py b/lib/sqlalchemy/sql/sqltypes.py
index 4583948704..ae90f74c95 100644
--- a/lib/sqlalchemy/sql/sqltypes.py
+++ b/lib/sqlalchemy/sql/sqltypes.py
... [Log Snipped] ...
 
 class Text(String):
```
