Title

Invalid compiler error for class which overrides a method having duplicate default definitions from interfaces

Description
This is a clone of   GROOVY-10381   which solved the following: 
  
 
 package  p;
 public   interface  A {
   default  void m() {}
}
 public   interface  B {
   default  void m() {}
}
 
  
  
 
 class  C  implements  p.A, p.B {
  void test() {
    m()
  }
}
 
  

  groovyc  does not detect that  m()  must be overridden to resolve the conflict.   javac  does produce an error, but it is still possible to import the interfaces from libraries and not trigger joint compilation. 

 As noted in that issue, the following case isn't covered: 
  
 
 import   package  p.*
 class  C  implements  A, B {
  @Override
  void m() {
    A. super .m()
  }
  void test() {
    m()
  }
}
 
  
 The intention of this issue is to cover that missing case.
