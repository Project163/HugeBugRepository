Title

"key-spacing" crashes eslint on object literal shorthand properties

Description
Hi, I'm using shorthand properties for object literals in my code, and after I've added `key-spacing` rule to `.eslintrc`, `eslint` (version 1.2.0) throws an unhandled exception:

`index.js`:

``` javascript
var a = 'a';
var b = 'b';

export default {
    a,
    b
};
```

`.eslintrc`:

```
json
{
    "rules": {
        "indent": [
            2,
... [Log Snipped] ...
    "extends": "eslint:recommended"
}
```

eslint output:

```
PS G:\test> eslint .\index.js
C:\Users\belym.andrey\AppData\Roaming\npm\node_modules\eslint\lib\rules\key-spacing.js:127
        while (node.type !== "Punctuator" || node.value !== ":") {
                                          ^
TypeError: Cannot read property 'type' of undefined
... [Log Snipped] ...
    at emitOne (events.js:82:20)
    at EventEmitter.emit (events.js:169:7)
```

Exception gone after removing `key-spacing` rule from `.eslintrc`.
