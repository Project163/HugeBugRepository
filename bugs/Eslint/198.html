Title

quote-props message is messed up when the property is a number

Description
Run eslint with the quote-props rule against the following file:

``` js
(function(){
    'use strict';
    var a = {
        0: '0',
        1: '1',
    };
}());
```

The messages will say:

```
  4:2   error  Unquoted property `{{name}}` found  quote-props
  5:2   error  Unquoted property `{{name}}` found  quote-props
```

Notice how it says {{name}} instead of 0 and 1.
Discussion
- Yup, message format is definitely messed up there.
- Looks like quote-props has inadequate test coverage in general. Working on this.
