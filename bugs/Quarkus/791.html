Title

FormAuthenticationMechanism needs to handle exceptions to avoid requests without response.

Description
Exceptions in `io.quarkus.vertx.http.runtime.security.PersistentLoginManager.save()` are not being handled correctly by the caller. This means that if an exception happens, the request will never be fulfilled. You can see this in action in #11768.

`subscribe().with()` callback in `FormAuthenticationMechanism.runFormAuth` needs to check if any exceptions happen and fail the uni if so.

I've got a patch for this already that I'll be sending shortly.
