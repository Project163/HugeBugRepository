Title

build: fix git show --no-patch error

Description
Recent commit   breaks docker build because the `git` version is too old to recognize `show --no-patch`, according to @mbautin.  This can probably be fixed by using the short form `-s`, which seems to have been around longer (at least since 2010, git repo commit  ).
Discussion
- - `--no-patch` was introduced in git repo commit   (2013 July)
- `-s` was introduced in git repo commit   (2005 May)

Therefore, `-s` looks very safe.
