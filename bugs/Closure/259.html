Title

closure compiler crash in simple mode, invalid code removal in whitespace mode.

Description
I passed the content of the attached file into the closure compiler [URL] and it crashed.

In whitespace only mode, it doesn't show that it crashed, but it doesn't give any script back as a result (which is wrong, because my code should give an alert).

By the way, to generate the javascript that causes the crash, I used this script (you can use max to vary the nesting depth):
max=250;depth=0;func="{alert(depth);}";for(i=0;i<max;i++)func="{depth++;return function()"+func+"();}";exec="("+new Function(func)+")()";

- Hehe. Interesting. Seems like this is hitting more than one bug.

Just looking at tryOptimizeBlock

      case Token.SCRIPT:
      case Token.BLOCK:
        return tryOptimizeBlock(subtree);

Which would cause it to crash because the subtree can be a script.

The web service probably creates the whole AST with script nodes a bit different than the commandline compiler.
