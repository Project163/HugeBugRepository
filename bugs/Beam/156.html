- The issue here is that TypeDescriptor (which relies on TypeToken) is not serializable when a variable type is specified (the <OutputT, CheckpointMarkT> part). 

 The simplest path is to drop the variable type part: 

 Coder<? extends UnboundedSource<OutputT, CheckpointMarkT>> sourceCoder = 
    (Coder<? extends UnboundedSource<OutputT, CheckpointMarkT>>) 
      SerializableCoder.of(new TypeDescriptor<UnboundedSource>() {}); 

 You're losing some information at the TypeDescriptor level about the type parameters but you still get the fact that you are encoding an UnboundedSource.
