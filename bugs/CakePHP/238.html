Title

3.0 - Plugins can't be loaded when using namespaces

Description
Since the new plugins-being-in-vendor mechanism was set in place, `Plugin::load` fails to respect namespaces.

This stopped working and needs to work again:

```
Plugin::load('Company/Plugin', ['bootstrap' => true]);
```

It works if you make the namespace separator a backslash:

```
Plugin::load('Company\Plugin', ['bootstrap' => true]);
```
