Title

Controller doesn't load default model in plugins

Description
In normal case controller automatically load default model, i.e. $this->Articles is accessible in ArticlesController. However if ArticlesController and his model ArticlesTable are located in Plugin directory, the model Articles is not automatically loaded.
Discussion
- Sounds like duplicate of #3665. Can you check against 3.0 branch head, a fix #3679 was done recently for it.
- I think that latest update may broke model loading. For example, in plugin "Course" in controller "Courses" value of $this->modelClass is "Course.Courses". Its fine for custom model loading, but in \Cake\Controller\Controller in method __get($name) is comparation "if ($name === $this->modelClass)" which is never true for accessing model via $this->Course.
If I enforce value of $this->modelClass to "Courses" in beforeFilter, everything works fine.
