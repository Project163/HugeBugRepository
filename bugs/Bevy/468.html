Title

Inconsistent implementations for calculating aspect ratios

Description
## Bevy version
- 0.11.3
- the main branch as of `b22db47`

## What went wrong
Aspect ratios should be calculated as `width / height`, not `height / width`.

In the code base of the version 0.11.3 and the main branch (`b22db47`), I found that `bevy_render/src/texture/image.rs` wrongly uses `height / width` while other files correctly use `width / height`.
