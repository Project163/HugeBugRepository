Title

[1.16 regression] Crashes on a combination of dataclass inheritance, InitVar, and properties.

Description
**Crash Report**

mypy started crashing on the code below starting with version 1.16.0 — it was still working fine in 1.15.0.

**Traceback**

```
# mypy mypy-internal-error.py --show-traceback
mypy-internal-error.py:27: error: Name "value" already defined on line 22  [no-redef]
mypy-internal-error.py:27: error: INTERNAL ERROR -- Please try using mypy master on GitHub:
[URL]
Please report a bug at [URL]
... [Log Snipped] ...
AssertionError:
mypy-internal-error.py:27: : note: use --pdb to drop into pdb
```

**To Reproduce**

```
from dataclasses import InitVar, dataclass, field
from typing import Callable

@dataclass
... [Log Snipped] ...
    def value(self, value: int):
        self.setter(value)
```

**Your Environment**

 

- Mypy version used: >=1.16.0
- Mypy command-line flags: mypy mypy-internal-error.py --show-traceback
- Mypy configuration options from `mypy.ini` (and other config files): none
- Python version used: 3.10
- Operating system and version: macOS 15.5
Discussion
- Mypy probably won't support this use case (from the type checker perspective `value` is indeed redefined), but crashing is too bad. 

The node is deleted here:

[URL]

I think such redefinitions are too rare to support correctly, so just bailing out early with "not supported" and *not crashing* looks like a good compromise to me.
