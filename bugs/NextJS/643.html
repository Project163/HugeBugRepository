Title

Issues with intercepting routes in dev mode

Description
### Link to the code that reproduces this issue

[URL]

### To Reproduce

Note that there's no styling in order to simplify the example, so calling it a "modal" is a bit of a stretch. This is a simplification of [URL] where I also experience the issue.

1. Start application: `next dev`
[Image: image]

2. Click "Open Modal" to open the "photos modal". Works as expected.
[Image: image]

3. Refresh the page to see the photos page (no modal). Works as expected.
[Image: image]

4. Edit any page, ex: in `app/page.tsx` add "!" to the "Open Modal" text.
[Image: image]

6. Allow the photos page to reload automatically. The photos page now shows the modal rendering with the photos page as the "background"
[Image: image]


### Current vs. Expected behavior

I would expect the hotreload to have no visible effect, but instead it seems to cause the route to be suddenly intercepted. I'm not sure if this is a bug in the implementation (this repros on [URL] as well) or in the route interception logic during dev mode.
