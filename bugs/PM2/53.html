Title

cli-table is unmaintained and don't handle null values

Description
**What's going wrong?**

Setting a value to *null* in `package.json` "config" crash the install while rendering the cli-table, due to a [Link: two year old bug in cli-table].

**How could we reproduce this issue?**

Create a module, set `config: {"foo": null}` in package.json and try to install it.
