By the way, to make a fair one-to-one comparison between the LassoLars implementation available in R (library lars) and the one available in sklearn, you need to call the corresponding methods in the following way:

---

Scenario 1: Let's compare R vs sklearn when fit_intercept=False and normalize=False

R:

``` R
library(lars)
model_lasso_lars = lars(X, t(y), type="lasso", intercept=FALSE, trace=TRUE, normalize=FALSE) 
r = t(model_lasso_lars$beta)
```

sklearn:

``` python
model_lasso_lars = linear_model.LassoLars(alpha=0, fit_intercept=False, normalize=False)
model_lasso_lars.fit(X, y)
skl_betas = model_lasso_lars.coef_path_
```

---

Scenario 2: Let's compare R vs sklearn when fit_intercept=True and normalize=True
Note: When normalize is equal to True, R returns the coefficients in their original units, that is, they are rescaled back, whereas sklearn does not do that, therefore, we need to do this step before comparing their results.

R code:

``` R
library(lars)
model_lasso_lars2 = lars(X, t(y), type="lasso", intercept=TRUE, trace=TRUE, normalize=TRUE)
r2 = t(model_lasso_lars2$beta)
```

sklearn:

```
python
model_lasso_lars2 = linear_model.LassoLars(alpha=0, fit_intercept=True, normalize=True)
model_lasso_lars2.fit(X, y)
skl_betas2 = model_lasso_lars2.coef_path_
```
