Title

_namePrefix not working in \Cake\Routing\RouteBuilder::plugin

Description
This is a (multiple allowed):
* [x] bug

* CakePHP Version: 4.2.4.
* Platform and Target: Ubuntu Linux 18.04, PHP 7.2.

### What you did
I've set up a plugin with a namePrefix for its routes.

```
php
// my Plugin class
class Plugin extends BasePlugin
{
    public function routes(RouteBuilder $routes): void
... [Log Snipped] ...
    }
}
```


### What happened
The route is registered with the _name "home" without the prefix.

### What you expected to happen
The route should be named as "sadmin.home"

I've been looking into the code and I think the issue is on the `\Cake\Routing\RouteBuilder::plugin()` method, as it's ignoring any options key other than `"path"`:

```
php
// \Cake\Routing\RouteBuilder class
    public function plugin(string $name, $options = [], $callback = null)
    {
        if (!is_array($options)) {
... [Log Snipped] ...
        return $this;
    }
```
As you can see, `$options` is not passed nor merged into `scope()` method, instead only the `"path"` key is taken.
I found this bug some time ago, in cakephp 3.x, I was almost sure I'd reported it then, but it turns out that I didn't, I'd just used the scope method directly, avoiding the use of `plugin()`.
