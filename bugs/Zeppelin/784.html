Title

The "Default Interpreter" select box on the "Create new note" modal dialog has no contents when it is opened via the "Create new note" link on ${ZEPPELIN_HOME}/webapps/webapp/app/home/notebook.html

Description
Abstract  
The "Default Interpreter" select box on the "Create new note" modal dialog has no contents when it is opened via the "Create new note" link on ${ZEPPELIN_HOME}/webapps/webapp/app/home/notebook.html (*1) 

 The screen shot is attached to this issue as   ZEPPELIN-3022.png     . 

  Cause  
NoteCreateCtrl.getInterpreterSettings() is not invoked when the "Create new note" link on ${ZEPPELIN_HOME}/webapps/webapp/app/home/notebook.html is clicked:  [URL]

  Solution  
Fix ${ZEPPELIN_HOME}/webapps/webapp/app/home/notebook.html so that NoteCreateCtrl.getInterpreterSettings() is invoked when the "Create new note" link is clicked. 

  Appendix  
*1. It is encouraged to include /${ZEPPELIN_HOME}/webapps/webapp/app/home/notebook.html for showing the list of notes on the custom Apache Zeppelin homepage. See  [URL] for the details.
