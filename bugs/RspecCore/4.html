Title

Backtrace detection is broken on JRuby 9000

Description
JRubys 9000's (specifically  ) backtraces are no longer being detected properly resulting in "unable to find backtrace line" for several of our specs and two features in our build.

It would seem these are all related to detecting backtraces from outside a users project code (external libraries and our pending exceptions).
