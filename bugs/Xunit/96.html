Title

Paths in *.runtimeconfig.dev.json aren't searched

Description

X unit cannot find the dll for System.Text.Encoding.CodePages please note that mimekit is depended on 4.3.0 however for some reason an exception is thrown because version 4.0.2 is not found when running tests using xunit (dotnet xunit from CLI).

Discussion
- This is (somewhat) related to the MVC testing bug, which is: the "root" folder of the execution is not the unit test assembly folder, but rather the folder containing `dotnet-xunit.dll`, which means the unit test assembly's `.runtimeconfig.dev.json` file isn't being read, and the probing paths do not include the locally cached assemblies in `%ProgramFiles%\dotnet\sdk\NuGetFallbackFolder`.
- Verified with 2.4 beta 1 build 3896.
