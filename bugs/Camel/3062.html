Title

CXFRS endpoint ignores model references

Description
CXF JAX-RS implementation offers an extension where an external model description is bound to an interface or concrete class with no JAX-RS annotations. 
The cxfrs component schema supports a modelRef attribute however CxfRsEndpoint does not propagate it to CXF JAX-RS factory beans
