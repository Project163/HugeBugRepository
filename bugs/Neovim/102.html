Title

Quickfix list size increases when splitting

Description
This only happens if vertical splits are used.

Steps to reproduce:
- `start nvim`
- `:vsp`
- `:copen`
-  `execute 'bot split'`
-  `:q`
- `execute 'bot split'`
- `:q`

Everytime you split the quickfix list gets bigger.
Discussion
- For what it's worth, the behaviour is the same with Vim. The problem seems to be how `:copen` is handled, because just using `:split` works as expected.
- The quickfix _window_ "stays" bigger after the first `:q`, but thereafter alternating `:bot split` and `:q` don't seem to change the window. (**Edit:** it's related to `winfixheight`, see [Link: below]).

The layout behavior that I observe is just Vim's standard window layout logic (cursor placement affects it as well).
