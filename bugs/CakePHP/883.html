Title

Cannot use object of type Cake\Http\Cookie\Cookie as array

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.5.0
* Platform and Target: Apache 2.4, MySQL, OS: Ubuntu
* AuthComponent and CsrfComponent  activated

### What you did
- migrated from latest 3.4. to 3.5.0 via composer
Just tried to start my cake app

### What happened
Cake fails with exception:
Error: Cannot use object of type Cake\Http\Cookie\Cookie as array
Error in: ROOT/vendor/cakephp/cakephp/src/Http/Response.php, line 546
Cake tries to set the csrf token and fails with the above message

### What you expected to happen
Just simply the app to start
Discussion
- Reopen, as this issue looks like a bug. I could reproduce this issue by using the old Dispatcher, or just calling `Response::send()` in a controller:
```php
$this->Cookie->write('foo', 'bar');
$this->response->send();
$this->response->stop();
```
