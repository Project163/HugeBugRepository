Title

Not work redirect (if header location with plus symbol '+')

Description
For example:

```
App::uses('HttpSocket', 'Network/Http');
$HttpSocket = new HttpSocket();
$image = '[URL]
$res_img = $HttpSocket->get($image, array(), array('redirect'=>true));
debug($res_img->code); // code = 0 
```

Not work redirect to '[URL]

Because in [URL] on line 419 decoded header location (plus symbol(+) are decoded to space character): 

```
$request['uri'] = trim(urldecode($this->response->getHeader('Location')), '='); // '[URL] BT_P-2668820b-acee-4ff4-b109-32bb5dcb0d49_I1.jpg'
```
Discussion
- This issue was caused by fixing issue 3310 in lighthouse. The issue description was

---

#### What I did

```
App::uses('HttpSocket', 'Network/Http');
$url = '[URL]
$HttpSocket = new HttpSocket();
$HttpSocket->get($url, array(), array('redirect' => 5));
```

#### What happened

First outgoing request is URL encoded to:
    [URL]

Response is:
    Location: [URL]

Following that the request is:
    [URL]

Response is:
    Location: [URL]

_This is where the issue gets tricky_
The next request does not url decode the Location header so the raw request is:

```
'GET / HTTP/1.1
Host: i.cmpnet.com%2Ftechonline%2Fpdf%2Fpavillions%2Fti%2Fsprt537a.pdf=
Connection: close
User-Agent: CakePHP
```

which fails.

This may be an issue with doubleclick but I am able to follow the redirect properly in the browser and using curl. 

I am not sure how to address this issue or I would submit a patch. Should the url be decoded before being sent to redirect? Should the url not have been encoded in the first place?
