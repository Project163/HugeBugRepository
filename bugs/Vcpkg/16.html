Title

glbinding fails to install

Description
I get the following error message when I try to install glbinding:

```
-- Performing post-build validation
The following files are placed in
C:/vcpkg/packages/glbinding_x64-windows and
C:/vcpkg/packages/glbinding_x64-windows/debug:

... [Log Snipped] ...
Found 1 error(s). Please correct the portfile:
    C:\vcpkg\ports\glbinding\portfile.cmake
```

Am I the only one experiencing this?
Discussion
- This works for me. Just to be sure, can you (re)try with the following steps:
1) `git pull` to get the latest version
2) Run `scripts\bootstrap.ps1` again. 
3) Use `vcpkg version` to verify that you have at least version v0.0.67. 
4) `vcpkg remove --purge glbinding:x64-windows`
5) `vcpkg install glbinding:x64-windows`

These executables never get built for me, so this is somewhat odd (as opposed to having them build, and then the portfile removes them afterwards, which is prone to race issues if the build does something weird).
- Same result after performing the steps you listed. I'll try to investigate further...
- I figured out what's happening. Those executables are only built if GLFW is found by CMake (see source/tools/*/CMakeLists.txt). GLFW is not listed as a dependency for glbinding, so it will only break on systems where package glfw3 is present (that's my case).

glbinding's cmake files don't offer the choice to exclude those tools from the build process, so deleting the executables at the end (if they were generated) is probably the only way to solve this issue.
