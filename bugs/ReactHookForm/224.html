Title

V7: formState.isDirty is not set to true onChange if value is watched

Description
**Describe the bug**
In v7 in a form with only one input the formState.isDirty will not be true when the input is changed if you are watching the form value.  It will become true once the input is blurred, however this is not good if the save button is disabled when !form.isDirty as it prevents the user from submitting the form unless they have blurred the input.

If you remove the watch on the form value it works as expected

**To Reproduce**
Create a form with a single input and set the submit button to be disabled if !formState.isDirty

1.  Watch a field with something similar to what is below or in the codeSandbox
```
function Form(){
  const { register, formState, watch } = useForm()
  const { isDirty } = formState

  const name = watch('name')
... [Log Snipped] ...
   
}
```
2.  Change the field value
3. The submit button will be disabled when it should be enabled
