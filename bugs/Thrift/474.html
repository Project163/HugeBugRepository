Title

C# JSON Protocol uses culture-dependant decimal separator for double

Description
C# JSON protocol uses the current culture to read and write doubles, so the decimal separator is not always a dot. For instance, if the the current culture is fr-FR, a comma is used as decimal separator thus resulting in invalid JSON.
