Title

@Memoized failed to apply for method with variable args

Description
import  groovy.transform.Memoized

 class  Test{
    @Memoized
     String  some( Integer  inp, ...params){
        sleep(3000)
    }
}
 
  

  
 1 compilation error:

Invalid field name. Invalid character at position: 40 of value:  ; in name: memoizedMethodClosure$someIntegerObject;
. At [-1:-1]  at line: -1, column: -1
Discussion
- Actually class/interface array java type name generated using following encoding: 'Lclassname;', now for arrays using componentType.class + 'Array' to avoid  ';' invalid character 

 I sent pull request  [URL]
- but note that actual memoization will not work because in java  

  
 ( new   String []{ "X" ,  "B" }).equals( new   String []{ "X" ,  "B" }) 
 
  

 is false, I think developer should aware that method can be memoized only for objects with correct equals() and hashCode()
- Yes the situation could be improved by leveraging a different Map than LinkedHashMap as the backing cache structure, to use  Arrays.equals  for example.
