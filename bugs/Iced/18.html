Text centering not working properly

### What happened?

In iced version 0.13.1 (currently on crates.io), `Text.align_x()` doesn't work, it just does nothing.
After having learned this, I switched to the git version of iced, where `align_x()` does work, sometimes.

It does work when the application first starts up. But during the application usage, the centering can quickly break for following reasons (and maybe more):

- if the text to center contains a newline character, any resizing of the immediate container shifts the text right. So the text is still centered, but it's all the way on the right side of the container, even if the container was also set to center its contents.
- if the text doesn't contain a newline character, then it sometimes behaves as if it was aligned left instead of centered. This seems to happen only in certain circumstances and I'm not sure when it works fine and when not, but I certainly experienced it not working.

### What is the expected behavior?

Text that has the function `.align_x(Alignment::Center)` applied to it, should always have each individual line centered within its parent.

When the text contains newlines, resizing the parent or adding other children to the parent should keep the text centered and in the middle of the centered parent instead of moving the text to the right.
