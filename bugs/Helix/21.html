Title

Horizontal split shifts view up and down when inserting text

Description
While testing #322 I noticed that something about the views does not seem right when typing. It only affects the views in between the first and the last.

### Reproduction steps
1. Run helix with `cargo r --release` in the repository
2. Open `helix-term/src/application.rs` with file picker
3. Open at least 5 horizontal splits
4. Wait for rust-analyzer to initialize
5. Add `use std::` after first 3 imports
6. Navigate to the split below middle and above the last one
7. Start typing below the import (so that server reports an error)
  

### Environment

- Platform: Linux
- Helix version: v0.2.1-63-g4b7276d
