Discussion
- This is an error on the mail server (not in Camel). So why it works after restart is likely because a new clean session is created and logged in to the mail server.
- Maybe camel-mail, can in the poll method, detect some severe errors when attempting to open the mail folder, and then invalidate the mail session, so a new fresh session is created on the next poll. And that can mitigate the problem.
- Made the mail consumer re-connect if error opening the mail folder
