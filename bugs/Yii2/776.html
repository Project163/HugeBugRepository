Title

`resolveCallableDependencies` is not supported callable object.

Description
### What steps will reproduce the problem?

1. Create an invokable class:

```php
class Foo
{
    public function __invoke()
    {
        return new \stdClass();
    }
}
```

2. Call `Yii::createObject`:

```php
$stdClassInstance = \Yii::createObject(new Foo());
```

3.  An error shows: `ReflectionFunction::__construct() expects parameter 1 to be string, object given`.

### What is the expected result?

`$stdClassInstance` is an instance of `stdClass`.

### What do you get instead?

Yii use `is_callable` to check if a param is a `callable` or not, but in `yii\di\Container::resolveCallableDependencies` function, simply use `is_array` to check the `callable` is a method or function.

In PHP Documentation, a [Link: callable] was defined as 6 types.

So, if there was an object which has `__invoke` method, that will be a `callable` in PHP, but it's not an array.

It should be easy to fix. In my environment, I just add 2 lines in `resolveCallableDependencies` (See commented lines):

```php
        if (is_array($callback)) {
            $reflection = new \ReflectionMethod($callback[0], $callback[1]);
        // } elseif (is_object($callback)) {
        //     $reflection = new \ReflectionMethod($callback, '__invoke');
        } else {
            $reflection = new \ReflectionFunction($callback);
        }
```

That's works for me.

| ---------------- | ---
| Yii version      | >=2.0.7
| PHP version      | 7.0
| Operating system | macOS
