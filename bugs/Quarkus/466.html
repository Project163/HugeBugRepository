Title

@PreAuthorize() does not support space before string expression

Description
**Description**
If you include the spring-security extension and use the functionality with a PreAuthorize annotation for calling a method on a bean, startup fails if a string in the expression has space before an Apostrophe defining a string argument.
The problem is in this line where _argumentExpression_ is used rather than _trimmedArgumentExpression_ when evaluating:
[URL]

**Expected behavior**
Spaces should be trimmed before evaluating the expression

**Actual behavior**
The string is trimmed, but it is the untrimmed string that is used for evaluation.
Startup fails with the following:
```
Build step io.quarkus.spring.security.deployment.SpringSecurityProcessor#addSpringPreAuthorizeSecurityCheck threw an exception: java.lang.IllegalArgumentException: Expression: '@roleChecker.check('tenant', 'READ')' in the @PreAuthorize annotation on method 'role' of class 'com.acme.SecuredResource' is malformed
        at io.quarkus.spring.security.deployment.SpringSecurityProcessorUtil.createGenericMalformedException(SpringSecurityProcessorUtil.java:22)
        at io.quarkus.spring.security.deployment.BeanMethodInvocationGenerator.generateSecurityCheck(BeanMethodInvocationGenerator.java:194)
        at io.quarkus.spring.security.deployment.SpringSecurityProcessor.addSpringPreAuthorizeSecurityCheck(SpringSecurityProcessor.java:478)
        at java.base/jdk.internal.reflect.NativeMethodAccessorImpl.invoke0(Native Method)
... [Log Snipped] ...
        at java.base/java.lang.Thread.run(Thread.java:834)
        at org.jboss.threads.JBossThread.run(JBossThread.java:479)
```

**To Reproduce**
Steps to reproduce the behavior:
1. include spring-security
2. Annotate a resource with PreAuthorize like 
`@PreAuthorize("@roleChecker.check('tenant', 'READ')")`
3. create a bean for evaluating this like:
```
@Component()
public class RoleChecker {
    public boolean check(String tenant, String role) {
        return true;
    }
}
```
4. Start the application
