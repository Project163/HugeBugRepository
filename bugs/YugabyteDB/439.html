Title

Old WAL entries might not contain restart-safe monotonic time

Description
In   a "restart-safe monotonic timestamp" was introduced into WAL records to help with making sure that we retain enough logs to detect and reject retries that have already been processed. This timestamp might not be present in old WAL entries. In   a DCHECK checking for this was replaced with an SCHECK, leading to tablet bootstrap failures on old clusters that still have very old entries in master WALs.
(BTW we should ensure we flush sstables at least once in a while to avoid these kind of very old WAL entries from showing up in the future.)
