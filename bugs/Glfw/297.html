Title

Fullscreen window minimizes when clicked on 10.15 Catalina

Description
OS and version: MacOS Catalina 10.15.7
Commit ID:  
Error Messages: None

(NOTE: This also happens on 3.3 stable) 

In my game engine, when it creates a GLFW window, it does so in windowed mode to start with in case loading the main resource archive takes a long time. I then set the window fullscreen later if configured to do so, otherwise it stays windowed.

On MacOS Catalina however, even with GLFW_MOUSE_PASSTHROUGH set to false, (I don't set the hint in the first place but I tested this to check) the mouse "clicks-through" the window and minimizes it if the engine starts in fullscreen. This state remains even if I then bring the window up again from the dock. Sometimes if I use my game engine's fullscreen toggle a couple of times it correctly focuses the window.

Zooming the window with the green button instead of using glfwSetWindowMonitor is not affected. Windowed mode is not affected. 

Big Sur and Monterey to my knowledge are not affected by this bug.
Discussion
- Hello! We have been investigating this issue due to this report on the Minecraft bug tracker: [Link: MC-265519]. Not totally sure what has gone wrong here, but wanted to share our findings 🙂 
* It does not seem to be specifically related to the version of MacOS, but rather based on monitor configuration / screen resolution - it is possible to reproduce or not reproduce the issue on the same device with different screen or resolution setups
* The issue was introduced at some point between version 3.3.6 and 3.3.8 (suspicion is [Link: this commit], but have not confirmed this)
* The [Link: NSWindowStyleMaskResizable] style flag seems to be related - explicitly removing it when in fullscreen mode seems to restore to previous behaviour
  * The resizable flag does actually allow the window to be resized even when in fullscreen mode, which is a bit of a fun experience 😄
- Wow, good catch; I'll test this in my own engine codebase and report if it fixes it with my code.

If it does I'll see if I can author a patch for GLFW.

UPDATE: Can confirm masking out NSWindowStyleMaskResizable on GLFW's native Cocoa handle works and gets rid of the minimise bug. I'll author a patch to address this properly but for now my game engine has a workaround for when fullscreen mode is entered.

UPDATE 2: Pull request opened; the fix was surprisingly simple.
