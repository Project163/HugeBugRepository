Title

mvn quarkus:dev freezes in a project with bidirectional JPA relationships

Description
**Describe the bug**
Having the following entities in a Quarkus app makes `mvn compile quarkus:dev` freeze: 

```
java
@Entity
@Table(name = "owners")
public class Owner {

... [Log Snipped] ...
    }
}
```

And 
```
java
@Entity
@Table(name = "pets")
public class Pet {

... [Log Snipped] ...
    }
}
```

**Expected behavior**
Application should run
