Title

Keybindings don't work on Linux after migration to TOML

Description
I recently built version 13-dev and as suggested at the first start I did the migration of my config from YML to TOML.
I don't see regressions on Mac so far, but on Linux all of my keybindings stopped working.
To reproduce, I simplified my bindings to this:
```
[[keyboard.bindings]]
chars = "\u001B"
key = "Left"
mods = "None"
```

But, it doesn't work.

### System

OS: Linux
Version: alacritty 0.13.0-dev (4ad1aa32)
Linux/BSD: Wayland, Gnome, Fedora
