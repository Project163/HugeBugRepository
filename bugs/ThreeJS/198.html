Title

CatmullRom3 Sets tension=0.5 if initialized with tension=0

Description
##### Description of the problem

If I generate a [Link: `CatmullRomCurve3`] with `tension=0`, the curve will actually initialize with a `tension=0.5`

```javascript
        const curve = new THREE.CatmullRomCurve3(
          points,  // Tension
          true,  // Closed
          "catmullrom",  // Type
          0  // Tension
        )
```

**Bug**: `Tension = 0.0` looks like `Tension = 0.5`

[Image: image]

**Expected**: Tension = 0.0

[Image: image]

_I'm achieving this look for the screenshot by setting `tension=0.001`_

I believe this is caused by this code in the initializer:

`this.tension = tension || 0.5;`

Which should be something like:

```
const defaultTension = 0.5;
// Handle `0` as a valid input
this.tension = (tension === 0 || tension) ? tension : defaultTension;
```

##### Three.js version

- `0.109.0`

##### Browser

- [x] All of them

##### OS

- [x] All of them
Discussion
- Nice find. We use this pattern to fix that:
```js
this.tension = ( tension !== undefined ) ? tension : 0.5;
```
