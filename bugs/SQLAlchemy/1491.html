Title

`DeclarativeBase` doesn't forward keyword arguments in `__init_subclass__`

Description
### Describe the bug

`DeclarativeBase.__init_subclass__` doesn't forward unknown keyword arguments meaning `Base` **MUST** come last when using a Mixin that uses `__init_subclass__` with keyword arguments.

The docs don't reflect this:



This should be a simple fix for `DeclarativeBase` but opens a wider discussion to do this for other or all classes that use `__init_subclass__` e.g. `MappedAsDataclass`?


Happy to open a PR for this, draft without tests here [URL]
If accepted where should a test for this live?
