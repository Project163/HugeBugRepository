Title

[doc] [quarkus-test-amazon-lambda] Example missing required property

Description
**Describe the bug**
The example at [URL] does not work when applied to an existing project.

**Expected behavior**
The test should run and complete.

**Actual behavior**
The test hangs.


**To Reproduce**
Steps to reproduce the behavior:
1. Create a simple Quarkus application
2. Add amazon-lambda dependencies, and add a unit test to exercise it
3. Run the test, it hangs.

I will skip ahead to the solution which is to include in the `source/test/resources/application.properties` version the following line (as found within the Quarkus own integration test):

`quarkus.lambda.enable-polling-jvm-mode=true`
