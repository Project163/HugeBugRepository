Title

JAXRS 2 Feature not supported on server side?

Description
Hi 

 maybe I missed something but seems DynamicFeatures are supported on server side through @Provider but Features (JAXRS2 ones, not CXF ones) are not. This prevents to reuse some logic like Moxy JAXRS integration for instance which provides a hidden (for end user) ContextProvider<JAXBContext> through a Feature.
Discussion
- Yes, Feature was introduced while we were working on the client API, so I was not really focusing on adding it to the server, except for DynamicFeature so as a workaround, you can register Feature from within DynamicFeature. Not sure though about registering providers like ContextProvider from Feature(Context), many of those methods have priorities accepted and it only makes sense for the 2.0 filters/interceptors, it is confusing...
