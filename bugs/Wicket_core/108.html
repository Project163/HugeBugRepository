Title

Inline Javascript evaluated is executed before head contributions are loaded

Description
When a script added to the head loads an external script firefox postpones processing of the following script added to the head. This is a problem, because wicket assumes that head contributions are loaded immediately. So if for example a library is used as a head contribution it will not be loaded for it's actual usage.

- Append post call handler and notify function from FunctionExecuter to after javascript to be add in header is not working in 1.5.
