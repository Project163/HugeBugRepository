Title

live reloading error with Kotlin

Description
### Describe the bug

I'm using quarkus version `2.6.1.Final` and kotlin version `1.6.10` and running in dev mode with command `mvn quarkus:dev`. The service started normally and i can run curl -v `[URL] and returns "Hello RESTEasy". If i change the code to return "Hello World", live reloading fails when i run curl again.

### Expected behavior

Return Hello world

### Actual behavior

Show this error in request with http status 500:

Invalid argument: -parameters

1. visit code.quarkus.io, select `Kotlin` and `RESTEasy JAX-RS` extensions and download zip file
2. extract zip file and go to folder
3. run `mvn quarkus:dev`
