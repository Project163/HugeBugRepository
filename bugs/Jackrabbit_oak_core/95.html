Title

Basic reindex support in the lucene index

Description
Currently there is no reindex support.  
This also affects the initial index state, where the lucene index doesn't contain nodes that have been added before the index was setup.
Discussion
- fixed with rev 1389824 and rev 1390995
- I still wan't happy with the initial index state and added a few more tricks in rev 1391071. 

 Basically now we have the 'indexUpdate' which contains the last index update timestamp. If this doesn't exist it will trigger a full reindex. This also means that removing this property also triggers a full reindex.
- In revision 1393639 I moved the 'indexUpdate' property to the :data node, as it was breaking the observation tests on oak-jcr.
