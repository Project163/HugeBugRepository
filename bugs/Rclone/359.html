Title

B2 backend uploads to wrong bucket if application key does not allow uploading to the right one

Description
#### What is the problem you are having with rclone?
B2 backend uploads to wrong bucket if application key does not allow uploading to the right one.

Steps to repoduce:

 * In B2 web UI, create two buckets, `bucket1` and `bucket2`
 * Create an application key with R+W access to `bucket1` only
 * Configure it in rclone
 * Try uploading to `bucket2` using rclone (`rclone sync dir b2:bucket2`)

Expected output:
rclone fails with a permission error (`can't write to bucket2`)

Actual output:
rclone uploads everything and overwrites `bucket1`.
