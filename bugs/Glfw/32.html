Title

glfwWaitEvents spinning on cursor rect updates

Description
Hello, 

I'm trying the GLFW 3.1 in OS X and Linux, and found that: with the latest code from git repository, the glfwWaitEvent() takes too much CPU consumption in OS X 10.10 when the mouse cursor is hovering on the glfw window.
[Image: activity_monitor_screenshot]

It's very easy to reproduce this issue:
1. just use the example code on [URL] to create a glfw window.
but replace the "glfwPollEvents();" with "glfwWaitEvents();"
2. Build and run your program, check the activity monitor in OS X.
3. Move your cursor and you'll find that when the cursor hovers on the window, the CPU consumption will increase (more than 50% on my iMac: i7 3.5GHz) immediately.

The Xcode/Instruments/Time Profiler may help to find the root cause:
[Image: time_profiler_screenshot]
