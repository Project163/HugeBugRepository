Title

[DocDB] Remove protransform column of pg_proc from ysql migration script in pg 15

Description
Jira Link: [Link: DB-13631]
### Description

As Yugabyte codebase now uses Postgres 15, writing ysql migration scripts in pg15 has some differences to take into consideration the new pg_catalog schema as of pg version 15. One such pg_catalog table is `pg_proc`. For this table, the column `protransform` has been removed and a new row 'prosupport' has been added in pg 15.

`yb_database_clones` is the first internal function we added after the new upgrade to pg 15. However, the ysql migration script didn't take that into consideration. This should be fixed.
