Title

sqlalchemy 1.4 sqlite regexp_match(): re.match() vs. re.search()

Description
I think I might be missing something but from comparing with [Link: postgresql]:

```
'abc' ~ 'abc'    true
'abc' ~ '^a'     true
'abc' ~ '(b|d)'  true
'abc' ~ '^(b|c)' false
```

I think this should use `re.search()` instead of `re.match()` (which is left-anchored):

[URL]

IIUC what is called regex matching by many tools is `re.search()`, while `re.match()` is more like a short-cut for `re.search('^...')` (maybe `letmatch` or `prefix_match` would be a better name, any way `re.fullmatch()` seems less confusing and more useful).

I took a quick look at the tests but only saw test examples for initial matches. Hope this helps.
