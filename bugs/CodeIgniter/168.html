Title

postgresql drivers: table_schema missing in column select

Description
selects for columns not work correct if the postgres database has a second schema with same table_names.

affected files: 
CodeIgniter/system/database/drivers/pdo/subdrivers/pdo_pgsql_driver.php
CodeIgniter/system/database/drivers/postgre/postgre_driver.php

affected functions:
protected function _list_columns($table = '')
public function field_data($table)

WHERE clause should be changed to
			WHERE "table_schema" = \''.$this->schema."'".' AND LOWER("table_name") = '.$this->escape(strtolower($table));

This problem is incompletly handled in 96f81d2
