Title

Yii is returning 404 for two words actions and making dashes fail

Description
Yii is refusing dash character (`-`) in action ids, but it is accepting backslashes (`\`) on the other hand.

I think this is due to a possible mistake in the pattern to validate an id in method `Controller::createAction()`, line 228, as follows:

[URL]

The double backslashes in the pattern are matching characters in the range from `\` (93) to `_` (95), which includes `\`, `]`, `^` and `_` instead of only `-` and `_`, which I suppose was the initial intention. 

Can someone please confirm me if that is a bug or am I lacking any information?

- I think `preg_match('/^[a-z0-9\\-_]+$/', $id)` should not contain double backslash at all - because:

* double backslash = explicit character `\`, means URL like `my\url` would be accepted (wrong).
* single backslash = escaping, would allow following character translated as REGEX modifier, e.g. `\-` would allow characters range up to the `-` character (wrong)

My guess is that by removing it would not break anything for first option because writing action name like `function actionMy\Action(){...}` is not possible and for the second option it would only fix unwanted buggy behaviour.
- The regex as it is really makes no sense:
This is valid: 
`asd\]^_asd`
This is not :
`asd\]^_-asd`
