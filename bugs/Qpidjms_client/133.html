Title

QpidTestCase clashes with maven

Description
QpidTestCase should be renamed as maven tries to run (everything that starts with test or contains testcase) it and fails.
Discussion
- IMHO this is a bug in maven. It is the standard junit convention to name things like this FooTestCase. Perhaps a better workaround would be to move the class from the test src tree into the main src tree. IMHO this would make more sense anyways, since it's not actually a test.
- Alternatively I believe it would also be fairly trivial to add to the list of excludes in the surefire plugin configuration in the top level pom.xml.
- This test has been added to the exclude list.
