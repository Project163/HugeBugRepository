Title

Path --ansi does not exist

Description
PHPStan - PHP Static Analysis Tool 0.10.2

### Summary of a problem or a feature request

 

When running `phpstan` without either the `--ansi` or `--no-ansi` flags, the output returns an error about the file `/path/to/project/--ansi` not existing. This appears to happen regardless of whether or not the path given to `phpstan` is a file or a directory.

FWIW, I found that if I pass either `--ansi` or `--no-ansi` on the command line, the `--ansi` error goes away. I presume this has to do with how `XdebugHandler` parses the command line when restarting `phpstan` (I do have xdebug installed). 

### Code snippet that reproduces the problem

 

`phpstan analyse --level=0 -- /path/to/single/file`

```
$ phpstan analyse --level=0 -- public/index.php

... [Log Snipped] ...

 [ERROR] Found 1 error
```
