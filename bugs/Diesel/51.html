Title

Regression in distinct_on: cannot use .nullable() on column

Description
## Setup

### Versions

- **Rust:** rustc 1.71.1
- **Diesel:** 2.1.1
- **Database:** Postgres
- **Operating System** Linux

## Problem Description

Code using `fn distinct_on` works in Diesel `v2.0.1` but not in `v2.1.1`.

Minimal reproducible example: [URL]
`Cargo.toml`: `diesel = { version = "=2.0.1", features = ["postgres", "r2d2"] }`

It compiles in `v2.0.1` but in `v2.1.1` there is the compiler error:
```
error[E0277]: the trait bound `NullableExpression : Column` is not satisfied
  --> src/main.rs:74:10
   |
74 |         .distinct_on(m::id.nullable())
   |          ^^^^^^^^^^^ the trait `Column` is not implemented for `NullableExpression `
   |
```

So I tried to remove the `nullable()` so the two lines become:
```rust
        .order_by((m::id, wj::submit_date.nullable().desc()))
        .distinct_on(m::id)
```
But then I get the error:
```
error[E0271]: type mismatch resolving `  as AppearsInFromClause >::Count == Never`
  --> src/main.rs:74:10
   |
74 |         .distinct_on(m::id)
   |          ^^^^^^^^^^^ expected `Once`, found `Never`
   |
```
Which makes sense I guess, because the `measurement` table is left-joined so `m::id` is not always present.
