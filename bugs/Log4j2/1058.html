Title

RFC5424 Layout ignores event prefix

Description
In RFC5424Layout the mdcPrefix should add a prefix value to ThreadContext values only. Instead it adds the prefix to all attributes. The eventPrefix should be added to attributes that are not ThreadContext attributes.
