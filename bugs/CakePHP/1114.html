Title

Radio and Multiple Checkbox Hidden Input id is missing in 3.x and 4.x

Description
### Description

When we generate radio and multiple checkbox input using form helper, it generates hidden input without id attribute.
Due to this issue I am not able to show error on ajax/javascript validations.

syntax
```
 Form->control('Users.gender', ['type'=>'radio', 'label'=>false, 'options'=>['Male'=>'Male', 'Female'=>'Female']]);?>
 Form->control('Users.hobbies', ['type'=>'select', 'label'=>false, 'multiple'=>'checkbox', 'options'=>['Cricket'=>'Cricket', 'Tennis'=>'Tennis', 'Football'=>'Football']]);?>
```

Solution
root\vendor\cakephp\cakephp\src\View\Helper\FormHelper.php

```
function multiCheckbox()
add id in $hiddenAttributes
'id' => $attributes['id'].'-',

function radio()
add id in $this->hidden( function call
'id' => $attributes['id'].'-',
```

It is working fine in Cakephp 2.x

### CakePHP Version

3.x and 4.x
