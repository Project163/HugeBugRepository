Title

Null value for HttpServletRequest after http call

Description
I am trying to generate an audit message after a HTTP call, the audit message needs to contain the body of the original request.  

   

 I have the following route snippet: 

   
 from("direct:myqueue")  .setHeader(Exchange.HTTP_METHOD, constant(org.apache.camel.component.http.HttpMethods.POST))  .setHeader(Exchange.CONTENT_TYPE, simple("application/json"))  .to("[URL]
  
The  AuditProcessor class contains the fragment:  
 public void process(Exchange exchange) throws Exception {  
 HttpServletRequest request = exchange.getIn().getBody(HttpServletRequest.class);  
 String httpRequestBody = request.getReader().lines().collect(Collectors.joining(System.lineSeparator()));  
  
however, request is always being evaluated as null.  
  
The documentation  [URL] suggests I should be able to access the request object after the http request in the pipeline. 
  
Thanks
Discussion
- HttpServletRequest is for a  servlet  when you use camel-servlet - not when you use camel-http that is NOT a servlet.
- That doc page is wrong I am removing that section.
- Can you recommend a way I can get hold of the request body after the http call has been made?
- That is not possible with camel-http - you cant get access to the HttpResponse instance that the http client returns
