Title

Indent rule errors if nested callbacks end on the same line

Description
Rule:

``` yml
indent: [2, 2, {"SwitchCase": 1, "VariableDeclarator": 2}]
```

Code:

``` js
var arr = [[[0]]];
arr.forEach(function(data) {
  data.forEach(function(otherdata) {
    otherdata.forEach(function(zero) {
      console.log(zero);
    }) }) });

```

Error:

```
  6:9   error  Expected indentation of 2 characters but found 4  indent
  6:12  error  Expected indentation of 0 characters but found 4  indent
```
