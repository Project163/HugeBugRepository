Title

Block usage of collations for maps' key

Description
Now it is possible to set collations on keys of map type. But it could lead to unexpected bugs related to uniqueness of keys, so after collation change existing data may become unreadable. For example, it happens when table is created with 
  
 
map( 'A'  -> 1,  'a'  -> 2) 
  
 and then collation switched to UTF8_LCASE. 

 I propose to block collations on keys for now. Other systems rejects such changes as well. 
Probably int he future we could discuss about blocking changing collation but not blocking creation tables with collated keys.
