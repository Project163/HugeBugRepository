Title

union and pipe types not handled the same, unions are deconstructed into the type map

Description
```
py
from __future__ import annotations

from decimal import Decimal
import typing
... [Log Snipped] ...

print(CreateTable(A.__table__))
```

output:

```
CREATE TABLE a (
	id INTEGER NOT NULL, 
	d1 NUMERIC(11, 3) NOT NULL, 
	d2 NUMERIC(11, 3) NOT NULL, 
	d3 NUMERIC(11, 3) NOT NULL, 
	d4 NUMERIC(11, 3) NOT NULL, 
	PRIMARY KEY (id)
)
```

using pipe, then it works:

```
py
from __future__ import annotations

from decimal import Decimal
import typing
... [Log Snipped] ...

print(CreateTable(A.__table__))
```

output:

```
CREATE TABLE a (
	id INTEGER NOT NULL, 
	d1 FLOAT NOT NULL, 
	d2 NUMERIC NOT NULL, 
	d3 NUMERIC(11, 3) NOT NULL, 
	d4 NUMERIC(11, 3) NOT NULL, 
	PRIMARY KEY (id)
)


```


note this change is backwards incompatible as we have some test cases that are assuming the first behavior, erroneously.

this issue is related to #11370 and may end up including #11370
