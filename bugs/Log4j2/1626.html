Title

Concurrent individual LoggerContext initializations cause severe LogEvent drop or incorrect delivery

Description
When multiple  LoggerContext 's get initialized concurrently, they affect each other causing severe  LogEvent  drop and incorrect delivery. Consider the following test:

                .newConfigurationBuilder()

                .setConfigurationName( "Letter-"  + letter);

         final   String  appenderFilepath = Paths

Discussion
- Configurator.initialize(Configuration)  sets the global configuration, hence the corrupt state while run concurrently. Creating an individual  LoggerContext  fixes the problem: 

  
 
 final   String  loggerContextName =  "LC"  + letter;
 try  ( final  LoggerContext loggerContext =  new  LoggerContext(loggerContextName)) {
    loggerContext.reconfigure(config);
    loggerContextConsumer.accept(loggerContext);
}
 
  

 Hence, this is not really a  problem .
