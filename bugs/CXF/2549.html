- Sergey, 

 If resume() and isSuspened() are called in a single request, the code works well, since initialSuspend is false. But in this test code, resume() and isSuspened() are called in two requests. In the second request (isSuspended()), asyncImpl.prepareContinuation()>asyncImpl.initContinuation() was called, and initialSuspened is set to true again, so the isSuspened() method will return true regardless of the return value of cont.isPending().
