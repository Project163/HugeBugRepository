Title

Transaction Class Rollback Problem

Description
Hello guys,

So by inspecting your [Link: Transaction] in the methods begin and rollback, im not sure if what you have is a bug or by design of the framework.
But in this piece of code from the method [Link: begin]
```php
$schema = $this->db->getSchema();
if ($schema->supportsSavepoint()) {
            Yii::debug('Set savepoint ' . $this->_level, __METHOD__);
            $schema->createSavepoint('LEVEL' . $this->_level);
        } else {
            Yii::info('Transaction not started: nested transaction not supported', __METHOD__);
        }
```
you don't throw an Exception, but in the piece of code from [Link: rollback]
```
php
$schema = $this->db->getSchema();
        if ($schema->supportsSavepoint()) {
            Yii::debug('Roll back to savepoint ' . $this->_level, __METHOD__);
            $schema->rollBackSavepoint('LEVEL' . $this->_level);
... [Log Snipped] ...
            throw new Exception('Roll back failed: nested transaction not supported.');
        }
```
you throw an Exception if the schema doesn't support save point.
The first Question is:
Shouldn't the begin method throw the exception if SavePoint is not enabled?

Well because this leads to unexpected behavior by the IDE when i try to catch the exceptions that are thrown by the transaction like this 
[Image: screenshot_1]

To me this feels really weird because we caught  an exception we should rollback but we need to have another try catch to catch the exception that the rollback might throw.

The solution would be to throw that exception in the method [Link: begin] because we should not start a transaction that doesn't support SavePoint, at least by following your logic.

Any help you need just say.
Cheers Pedro Rosa

- Yes. It should throw as well, I think.
- If you throw it in the begin method, you should not need to throw it in rollback, since it will never start the transaction.
Because if you just add it to the begin method, we would still need to put the try catch inside the catch method.
