Title

Partial PathParam doesn't work in RESTEasy Reactive

Description
### Describe the bug

Having an endpoint defined as: 

```
java
@Path("/hello")
public class ReactiveGreetingResource {

    @GET
... [Log Snipped] ...
    }
}
```

And if a request is done to [URL] a 404 is returned

### Expected behavior

The following should be returned: 

```http
HTTP/1.1 200 OK
Content-Type: text/plain;charset=UTF-8
content-length: 7

->hoy<-
```

### Actual behavior

It returns: 

```http
HTTP/1.1 404 Not Found
Content-Type: application/json
content-length: 0
```

### How to Reproduce?

1. Generate a project with RestEasy Reactive: [URL]
2. Add `@Path("/a-{extension}")` and add a `@PathParam`  to the `ReactiveGreetingResource` there
3. Run `mvn clean compile quarkus:dev`
4. Go to [URL]
