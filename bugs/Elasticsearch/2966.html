Title

Dense Vector without dims property causes NullPointerException when calling _cluster/stats

Description
### Elasticsearch Version

8.11.1

### Installed Plugins

_No response_

### Java Version

_bundled_

### OS Version

N/A (Elastic Cloud)

### Problem Description

`_cluster/stats` returns a NullPointerException when there is an index with a dense_vector without dims, which is allowed as reported in the [Link: documentation of the dense_vector type]. 
This endpoint is also used by Elastic-Agent/Metricbeat to gather cluster statistics and this bug can cause them not to work.

### Steps to Reproduce

Create a new index with the following mapping:
```
PUT breaking-cluster-stats
{
  "mappings": {
    "properties": {
      "foo": {
... [Log Snipped] ...
  }
}
```

Execute `_cluster/stats`. It will return:

```
{
  "error": {
    "root_cause": [
      {
        "type": "null_pointer_exception",
... [Log Snipped] ...
  "status": 500
}
```

### Workaround

Create mapping with dims property or index a vector with the number of dimensions needed, e.g.: 
```
PUT breaking-cluster-stats/_doc/1 
{
  "foo": [1,1,1,1,...,1]
}
```
