Title

reduce _is_clone_of depth for memory savings

Description
everytime we clone an expression it keeps around `_is_clone_of` as an intermediary, so that we have chains of expressions and columns that are all wasteful.  _is_clone_of and _cloned_set are not consulted in too many places and it's very likely we only need it maintained for the root item, so we can at least flatten these.


```
py
import gc

from sqlalchemy import Column
from sqlalchemy import ForeignKey
... [Log Snipped] ...
print("binaries: %s" % be)
print("binaries: %s" % [str(x) for x in be])
```
Discussion
- reduction is not that impressive but certainly worth doing anyway, seems to be about 30%.   program to create 400 mappings of two classes each, the reduction in total ClauseElement objects goes from 17603 to 11603 if intermediary clones are removed, 11203 if clones are removed entirely.

py
