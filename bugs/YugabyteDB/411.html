Title

[YCQL] With index created on column which is a prefix of another column, Select queries fail with 'Column doesn't exist'.

Description
When we create table with indexes where one column is a prefix of the other column, the select queries that use both the column fail with "Column doesn't exist" error.

Steps to reproduce:
```
ycqlsh:ybdemo_keyspace> create table benchmark_table_0405 (k text, v text, v1 text, primary key(k)) WITH transactions = { 'enabled' : true };
ycqlsh:ybdemo_keyspace> create index idx on benchmark_table_0405 (v);
ycqlsh:ybdemo_keyspace>  create index idx1 on benchmark_table_0405 (v1);
ycqlsh:ybdemo_keyspace>
ycqlsh:ybdemo_keyspace> select * from benchmark_table_0405 where v = 'def' and v1 = 'efg';
... [Log Snipped] ...
                                                       ^^
 (ql error -203)"
```

Note that without indexes the problem doesn't exist.
```
ycqlsh:ybdemo_keyspace> create table benchmark_table_0405 (k text, v text, v1 text, primary key(k)) WITH transactions = { 'enabled' : true };
ycqlsh:ybdemo_keyspace> insert into benchmark_table_0405 (k,v,v1) values ('abc', 'def', 'efg');
ycqlsh:ybdemo_keyspace> select * from benchmark_table_0405 where v = 'def' and v1 = 'efg';
 k   | v   | v1
-----+-----+-----
 abc | def | efg

```

Also this is a problem only when one column is a prefix of the other:
```
ycqlsh:ybdemo_keyspace> create table benchmark_table_0405 (k text, v2 text, v1 text, primary key(k)) WITH transactions = { 'enabled' : true };
ycqlsh:ybdemo_keyspace> create index idx1 on benchmark_table_0405 (v1);
ycqlsh:ybdemo_keyspace> create index idx2 on benchmark_table_0405 (v2);
ycqlsh:ybdemo_keyspace>  insert into benchmark_table_0405 (k,v1,v2) values ('abc', 'def', 'efg');
ycqlsh:ybdemo_keyspace> select * from benchmark_table_0405 where v1 = 'def' and v2 = 'efg';
 k   | v2  | v1
-----+-----+-----
 abc | efg | def
```
