Title

3.0 paginate conditions applied twice

Description
I have the following 3.0 method:

```
public function index() {
    $this->paginate = [
        'conditions' => [
            'Visits.domain' => $this->Auth->user('domain')
        ],
... [Log Snipped] ...
    $this->set(compact('visits'));
}
```

just noticed in debugkit that the sql conditions applied twice:

```
 ..... WHERE (Visits.domain = 'a.com' AND Visits.domain = 'a.com') ....

SELECT (COUNT(*)) AS `count` FROM visits Visits WHERE (Visits.domain = 'a.com' AND Visits.domain = 'a.com')
```

this works fine though:

```
public function index() {
    $query = $this->Visits->find()->where(['domain' => $this->Auth->user('domain')]);
    $visits = $this->paginate($query);
    $this->set(compact('visits'));
}
... [Log Snipped] ...

SELECT (COUNT(*)) AS `count` FROM visits Visits WHERE domain = 'a.com'
```

Thank you,

Andras
