Title

ubuntu init script not working

Description
Hi

I tried to make my node application resurrect on boot, but using regular way is not working.
I'm on a debian 7, node v0.10.29, pm2 v0.9.1

I create a specific user for my node applications (called node)
I just runned as specified in the documentation:
`pm2 startup ubuntu -u node`

After that, with my sudo user, when I call the following command I obtain the error:

```
$ sudo service pm2-init.sh start
Starting pm2
/home/node/programs/node-v0.10.29-linux-x64/lib/node_modules/pm2/bin/pm2: 4: exec: : Permission denied
```

(the rights are ok, and running `pm2 resurrect` directly logged as `node` run fine)

After debugging, it appears that `$PATH` is not correctly setted, so in the file `/home/node/programs/node-v0.10.29-linux-x64/lib/node_modules/pm2/bin/pm2` at line 4:

```
':' //; [ -f ~/.pm2/custom_options.sh ] && . ~/.pm2/custom_options.sh || : ; exec "`command -v node || command -v nodejs`" $PM2_NODE_OPTIONS "$0" "$@"
```

The part `command -v node || command -v nodejs` just give an empty string.

So why ? 
In the file `pm2/lib/scripts/pm2-init.sh` at line 27:
`sudo -Ei -u $USER PATH=$PATH $*`
There is the  `-i` option, which from the sudo manual:
`The security policy shall initialize the environment to a minimal set of variables`

Maybe I'm wrong, but removing the `-i` flag resolved my problem.
Discussion
- To me, [URL] `update-rc.d` has no root permissions and so command isn' t found.

The `sudo -Ei` is not working to me, I had to do `sudo -u $USER PATH=$PATH $*`
