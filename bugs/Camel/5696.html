Title

camel-zipkin - Incorrect spans created when using parallelProcessing with recipientList or multicast

Description
Incorrect spans (with incorrect parentId) are created by camel-zipkin when using  parallelProcessing  with recipientList or multicast e.g. consider the below route 

 public void configure() throws Exception  
{

restConfiguration()
 .component("netty-http")
 .host(" ")
 .port(8081)
 .bindingMode(RestBindingMode.json);

rest().get("/demo").produces("text/plain")
 .route().recipientList().method(CamelRoute.class).parallelProcessing();

 from("direct:a")
 .to("mock:c");

from("direct:b")
 .to("mock:d");

 }

   

 The spans created for this are as follows. mock:c is supposed to have direct:a as the parent. But according to span information both mock:d and mock:c has parent "direct:b"
