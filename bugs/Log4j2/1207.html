Title

Custom Async ContextSelectors should disable location by default

Description
When AsyncLoggerContextSelector is selected, we modify the default value of LoggerConfig.includeLocation from true to false. 
Custom asynchronous ContextSelector implementations should also trigger this logic to avoid unnecessarily work.
