Title

Segmentation fault in col2im

Description
### 🐛 Describe the bug

Segmentation fault in `col2im` when containing large arguments.

### Example to reproduce

```
python
import torch

self = torch.full((2, 16, 4,), 0.5, dtype=torch.float64, requires_grad=False)
output_size = [536870912, 536870912]
... [Log Snipped] ...
stride = [1250999896764, 1250999896764]
torch._C._nn.col2im(self, output_size, kernel_size, dilation, padding, stride)
```

### Result
```segmentation fault```

### Expected behavior
Graceful termination or a RuntimeError to be thrown.

### Note
This bug was discovered using fuzz testing.
