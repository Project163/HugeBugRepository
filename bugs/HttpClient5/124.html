Title

Error "Chunked transfer encoding not allowed for HTTP/1.0" with proxy and HttpClient 5.4

Description
Exception org.apache.hc.core5.http.ProtocolException: "Chunked transfer encoding not allowed for HTTP/1.0" is thrown when sending request through corporate proxy (using Spring's RestClient). That did not occur with HttpClient 5.3. 

 Wire protocol (see below) shows proxy replies to CONNECT request with "HTTP/1. 0  200 Connection Established". Since 5.4., this protocol version seems to be  interpreted and set on the HTTP connection that is made after establishing the TLS connection through the TCP tunnel set up by the proxy. 

 The corporate proxies are very hard to change to e.g. return "HTTP/1. 1  200 ..." instead.
