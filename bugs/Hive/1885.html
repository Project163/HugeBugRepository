Title

TestCliDriverMethods test can cause entire build to fail

Description
TestCliDriverMethods has some tests which uses a custom SecurityManager  to intercept System.exit().  If the test fails early the security manager may not be unregistered and the process is unable to exit cleanly, which can cause the entire test run to fail with:
