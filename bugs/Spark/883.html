Title

Sort-based shuffle can lead to assorted stream-corruption exceptions

Description
Several exceptions occurred when running TPC-DS queries against latest master branch with sort-based shuffle enable, like PARSING_ERROR(2) in snappy, deserializing error in Kryo and offset out-range in FileManagedBuffer, all these exceptions are gone when we changed to hash-based shuffle. 

 With deep investigation, we found that some shuffle output file is unexpectedly smaller than the others, as the log shows:
