Discussion
- Attached patch with unit test. The change was to use canonical name of FieldSchema as the key in the mFieldSchemas multimap. Earlier the FieldSchema object was the key and this caused problems when the the FieldSchema object was changed (say the schema or some other member was changed) while in the multimap. This caused the hashcode of the FieldSchema object to change and hence corrupt the multimap.
- patch comitted; thanks pradeep
