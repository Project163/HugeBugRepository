Title

Cdcr Bootstrapping does not cause "index copying" to follower nodes on Target

Description
Please find the discussion on: 
 [URL]

 If we index significant documents in to Source, stop indexing and then start CDCR; bootstrapping only copies the index to leader node of shards of the collection, and followers never receive the documents / index until and unless atleast one document is inserted again on source; which propels to target and target collection trigger index replication to followers. 

 This behavior needs to be addressed in proper manner, either at target collection or while bootstrapping.
