Title

CIE LAB item missing in rendering

Description
The file from   PDFBOX-1681   is missing the "CIELAB" output, it was there a few weeks ago.
Discussion
- It happened around the 20th of February, between 1569060 (does display) and 1570806 (does not display).
- The difference is that for the attached pdf, it is this pdf segment that results in a call of toRGB(): 

 /CS0 cs 74 0 0 sc 

 So it would be enough to remove the code that isn't mentioned in the PDF spec (I tried this). But....  for the file   PDFBOX-1870  -technical_v2_p9.pdf , toRGB() is called from PDCIEBasedColorSpace.toRGBImage() and there is a different scale than when called from within PDColorSpace.toPaint(), so my solution doesn't work.
- I realize that my text here didn't make much sense, I had to debug again to understand what I meant. My observation was the same as  pslabycz  from   PDFBOX-2180  , but I also had a solution for rasters that I did at that time and then forgot about. Petr, please test it with all your files. 

 The solution is that the raster conversion does a scaling and the single conversion doesn't. I am using a modified toRGBImage() method copied from the parent class (PDCIEBasedColorSpace). 

 Fixed in rev 1607674 for the trunk.
- Works fine for me, thanks. But I found just a single file using LAB color space, so that is no proof
