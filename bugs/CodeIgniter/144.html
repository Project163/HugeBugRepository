Title

Backup content is not enclosed

Description
Hello,

While making a backup form the database the content is not enclosed by '.
Example:
INSERT INTO `tr_acties` (`id`, `naamKort`, `naamLang`, `kleur`, `afb`) VALUES (1, bellen, Bellen, #6BBE23, telefoon.png);
Instead of 
INSERT INTO `tr_acties` (`id`, `naamKort`, `naamLang`, `kleur`, `afb`) VALUES ('1', 'bellen', 'Bellen', '#6BBE23', 'telefoon.png');

This is seen in version 3.1.6 as in the development version of 27-09-2017.
