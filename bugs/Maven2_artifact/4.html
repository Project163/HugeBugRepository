Title

Inherited version gets the resolved version, not the asked for version

Description
eg: wagon-provider-api will get the last deployed SNAPSHOT version as that's what the parent is. 

 This does mean that when the version is inherited it is always consistent, but probably not what is expected. 

 In addition, deploy and install do not resolve it back to the base version.
