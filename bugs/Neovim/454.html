Title

Description

I don't think vim supports treesitter.nvim

### Operating system/version

Linux 5.16.16-artix1-1

### Terminal name/version

Artix repos

### How to reproduce the issue

1. Open a C file with treesitter.nvim.
2. Write into it :
