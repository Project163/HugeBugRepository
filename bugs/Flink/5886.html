Title

Bash scripts do not respect dynamic configurations when calculating memory sizes

Description
Dynamic configurations (the '-D' arguments) are lost due to changes in   FLINK-21128  . 

 Consequently, dynamic configurations like the following commands will not take effect. 
  
 
./bin/taskmanager.sh start -D taskmanager.memory.task.off-heap.size=128m
Discussion
- Shouldn't it be  ./bin/taskmanager.sh start -Dtaskmanager.memory.task.off-heap.size=128m ?
- I think both ` -Dkey=value ` and ` -D key=value ` are expected to work. 

 I tried this on  taskmanager.numberOfTaskSlots  and both ways work. 

 However, for memory options,  only ` -Dkey=value ` works but not ` -D key=value `  neither way works.
