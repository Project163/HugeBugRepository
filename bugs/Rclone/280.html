Title

Specifying --config doesn't disable the error message

Description
Eg

```
$ CGO_ENABLED=0 go install
$ rclone --config ~/.rclone.conf about .
2018/04/21 22:28:59 ERROR : Couldn't find home directory or read HOME or XDG_CONFIG_HOME environment variables.
2018/04/21 22:28:59 ERROR : Defaulting to storing config in current directory.
2018/04/21 22:28:59 ERROR : Use --config flag to workaround.
2018/04/21 22:28:59 ERROR : Error was: user: Current not implemented on linux/amd64
```

**NB** the error message has a missing `-` in `-config`!
Discussion
