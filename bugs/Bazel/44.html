Title

Docker Build rule with directory attribute and tar sources has extra '.'

Description
Example build rule

```
docker_build(
  name = "minimal_racket",
  base = "//:minimal_deb",
  tars = [":racket-src.tar.gz"],
  directory = "racket"
)
```

produces output (tar tvf of the .layer file)

```
$ bazel build -s test:minimal_racket.tar && tar tvf bazel-bin/test/minimal_racket.layer
...
-rw-r--r--  0 0      0           0 Dec 31  1969 .racket/share/pkgs/.LOCKpkgs.rktd
-rw-r--r--  0 0      0         106 Dec 31  1969 .racket/share/pkgs/pkgs.rktd
drwxr-xr-x  0 0      0           0 Dec 31  1969 .racket/share/pkgs/racket-lib/
-rw-r--r--  0 0      0         539 Dec 31  1969 .racket/share/pkgs/racket-lib/LICENSE.txt
-rw-r--r--  0 0      0         783 Dec 31  1969 .racket/share/pkgs/racket-lib/info.rkt
```

The buggy line is [URL]

Currently

```
 if root is not None:
          if name.startswith('.'):
            name = '.' + root + name.lstrip('.')
            # Add root dir with same permissions if missing. Note that
            # add_file deduplicates directories and is safe to call here.
```

I think it should be

```
 if root is not None:
          if name.startswith('.'):
            name = './' + root + name.lstrip('.')
            # Add root dir with same permissions if missing. Note that
            # add_file deduplicates directories and is safe to call here.
```
