Title

ORC : Is null SARG filters out all row groups written in old ORC format

Description
Queries are returning wrong results as all row groups gets filtered out and no rows get scanned. 

  
 SELECT 
  count(*)
    FROM
        store_sales
    WHERE
        ss_addr_sk IS NULL
 
  

 With hive.optimize.index.filter disabled we get the correct results 

 In pickRowGroups stats show that hasNull_ is fales, while the rowgroup actually has null. 
Same query runs fine for newly loaded ORC tables.
