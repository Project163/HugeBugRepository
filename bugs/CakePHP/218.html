Title

3.0 Nested router prefixes don't generate correctly

Description
In `routes.php` I added a route similar to the following...

``` php
Router::plugin('Inventory', function ($routes) {
    $routes->prefix('Browse', function ($routes) {
        $routes->prefix('Assets', function ($routes) {
            $routes->fallbacks();
        });
    });
});
```

Then I try to access the route like this: `/inventory/browse/assets/categories` which produces the a missing controller exception telling me to create the controller: `/plugins/Inventory/src/Controller/Browse/assets/CategoriesController.php`
