Title

[DocDB] Multiple txns might acquire FOR UPDATE explicit row-locks simultaneously

Description
Jira Link: [Link: DB-1226]
### Description

In the below example, if both txns issue the `FOR UPDATE` queries simultaneously, it is possible that both get the lock successfully.

`create table test (k int primary key, v int);
insert into test values (1, 1);

Session 1 -
begin;
select * from test where k=1 for update;
commit;

Session 2 -
begin;
select * from test where k=1 for update;
commit;
`
