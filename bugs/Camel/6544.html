Title

camel-aws - SNS component subscription to SQS error

Description
The parameter  queueUrl  says that we need to provide queue URL but it seems that we need to provide ARN endpoint instead. 

 example: 
  
 
aws2-sns: //xxxxx?subject=subj&autoCreateTopic= true &subscribeSNStoSQS= true &queueUrl=[URL]
  
 when the subscription to SQS queue will be created, an error is thrown 
  
 
Invalid parameter: SQS endpoint ARN (Service: Sns, Status Code: 400, Request ID: xxxx) 
  
 providing the same SQS URL in  ARN  format, the subscription will be created as expected
Discussion
- when fixed the test  SnsTopicProducerWithSubscriptionTest  can be enabled
