Title

Hide large IntegrationTests with Selenium for ZeppelinServer under a profile

Description
Right now on every  mvn package  large Selenium based tests in Scala are run (and fail on most local machines, but pass on CI). 

 It is good that we have them but there should be explicit way to run them when needed and skip those in favor of development productivity 

 I.e they can be hidden under  mvn verify   instead, so users become less in a habit of just adding  -DskipTests  all the time and CI who is doing  mvn verify  will still run them.
Discussion
- Actually Zeppelin already uses failsafe plugin to run large integration tests which adds  mvn integration-test  goal and is bind to  mvn verify  

 So  mvn package  does not run those tests,  mvn install  does wich looks good and is used by CI 

  Actual issue that need to be addressed here is just UnitTests in zeppelin-server failing:
