Title

Unexpected valid-jsdoc duplicate JSDoc parameter

Description
```
js
/**
 * Finds all different day times across a range of timestamps.
 * Sorts day times in an ascending order.
 *
... [Log Snipped] ...
 * @return {Array}
 */
```

This is a common syntax to define member properties of the object. JSDoc validator is raising an error: "Duplicate JSDoc parameter 'screenings'".

```
curiosity:foo gajus$ eslint -v
v1.2.1
```

```
/foo/index.js
  14:5   error  Duplicate JSDoc parameter 'screenings'                                  valid-jsdoc
```
Discussion
- According to [URL] your code looked valid and I was about to accept it :D
- I was not aware of the `@typedef` at the time of raising this issue. I consider the following syntax a lot more eloquent:

```
js
/**
 * @typedef {Object} screening
 * @property {Number} timestamp UNIX timestamp.
 * @property {String} url Booking URL.
... [Log Snipped] ...
 */
function positionTimes (screenings) {}
```
