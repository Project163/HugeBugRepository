Title

pig wrapper script tends to fail if pig is in the path and PIG_HOME isn't set

Description
If PIG_HOME isn't set and pig is in the path, the pig wrapper script can't find its home.  Setting PIG_HOME makes it hard to support multiple versions of pig.
Discussion
- Since we require bash, we can cheat a bit.  BASH_SOURCE should contain the full path to the script that we are executing.  This means we can ... piggyback... off of that variable to figure out where our real PIG_HOME is at.
