Title

Possible errors when sending a notification when user follows a tag

Description
**Describe the bug**
Here is an attempt to send a new follower notification no matter what the `followable_type` is.

[URL]

When `followable_type` is a tag, an incorrect notification could be updated or attempted to be created, cause the `notification_params` on this line will be `{ action: "Follow" }`
[URL]

**To Reproduce**
I modified the `create_follow` spec to run delayed jobs so that it would be clear that it's failing.
[URL]

**Expected behavior**
Only try to send a notification when a followable is a User or an Organization. At least add checks to the controller.

**Additional context**
I've started to refactor `send_new_follower_notification` in this pr #2030, but it makes sense to fix the described issue first. I'll add more checks for the valid arguments there.
