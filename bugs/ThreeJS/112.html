Title

ColladaLoader TypeError: surface is undefined

Description
When I'm trying to import some of my files in the three.js editor this error message appears:
TypeError: surface is undefined ColladaLoader.js:3430.
Unfortunately I can't load the file in this message, because it is to large.
I fixed the issue myself with this if-clause:

if (surface) {
    var image = images[surface.init_from];
...
}

Then the export worked.
