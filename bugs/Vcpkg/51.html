Title

VsCode cmake-tools plugin hangs when using the vcpkg toolchain file

Description
The configure step (of cmake) hangs when using the cmake-tools pluging for VsCode.

I have setup vcpkg and installed it. The following lines were added to my vscode user settings in order for the cmake tool to find my toolchain file.
```
"cmake.configureSettings": {
    "CMAKE_TOOLCHAIN_FILE" : "D:/Code/vcpkg/scripts/buildsystems/vcpkg.cmake"
},
```

After running cmake with some extra flags for verbosity i could see that it hanging on the getWindowsSdk.ps1 script. More details can be found [Link: here]

I got everything working by modifying the powershell call [Link: here] adding ```INPUT_FILE NUL``` like so:

```
execute_process(
    COMMAND powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "& {& '${VCPKG_ROOT_DIR}/scripts/getWindowsSDK.ps1'}" 2>&1
    INPUT_FILE NUL
    OUTPUT_VARIABLE WINDOWS_SDK
    RESULT_VARIABLE error_code)
```

I'll open a pull request if theres no objections here.
