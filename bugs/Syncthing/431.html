Title

Erroneously inherited ignore patterns

Description
Syncthing Version: v0.14.29
OS Version: Windows 7 x64
Browser Version: Firefox 53.0.3 / SyncTrazyzor 1.1.16
(Tested with and without SyncTrayzor)

If ignore patterns are added to a share, then a new share comes in from a remote device, the previously-used ignore patterns are added to the new share when it is saved.

Steps to reproduce:
On local machine: Add a new shared folder (1) and apply an ignore pattern. No need to share folder with other devices.
On remote machine: Add a second new shared folder (2), which is shared to local machine.

On local machine: Once request to add new shared folder (2) comes in, enter a path and save it.
Observe that .stignore is created with the data from set-up of shared folder (1).

Expected behaviour: .stignore on shared folder (2) should not be created.
