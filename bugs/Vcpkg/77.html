Title

vcpkg_fixup_cmake_targets does not correctly handle generator expressions

Description
### Short summary

The [Link: `vcpkg_fixup_cmake_targets()` function] does not handle generator expressions. You do not need to use generators explicitly for this to come up, because they are used internally by `target_link_libraries` if you specify the `debug` or `optimized` qualifier. This results in a very confusing error when you come to link against a library affected by this.


### More detail

I am using the following chain of dependencies:

 * An internal application, which I am building with CMake. This depends on ...
 * ... an internal library, let's call it XYZ, which I have written a vcpkg port for. This depends on ...
 * ... the Windows pthreads library. This already has a vcpkg port.

However, pthreads does not have a CMake config, so I have to find it manually in the `CMakeLists.txt` for XYZ:

    find_library(PTHREADS_LIB pthreadsVC2)
    find_library(PTHREADS_LIBD pthreadsVC2d PATH_SUFFIXES debug/lib)
    find_path(PTHREADS_INCLUDE "pthread.h")
    target_link_libraries(xyz PUBLIC debug ${PTHREADS_LIBD} optimized ${PTHREADS_LIB})
    target_include_directories(xyz PUBLIC ${PTHREADS_INCLUDE})

On the other hand, I *do* export targets for XYZ and include that from a CMake config file, so the application can just use `find_package()`:

    find_package(xyz)
    target_link_libraries(my_application PUBLIC xyz)

However, attempting to build and link causes the following bewildering error:

    LINK : fatal error LNK1104: cannot open file '$ :C:/src/vcpkg/installed/x64-windows-static/debug/lib/pthreadsVC2d.lib>;\$ >:C:/src/vcpkg/installed/x64-windows-static/lib/pthreadsVC2.lib>"
    )
