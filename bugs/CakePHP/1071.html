Title

Cake\Validation\Validation::imageWidth() should expect an UploadedFile object instead of an array

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 4.1.7
* Platform and Target: OpenSuse 15.2, MySQL

### What you did
I tried to patch an entity with form data that contained an UploadedImage object.
I also have the following validation rule:

```php
$validator->add('image', 'largeurImageInvalide', [
    'rule' => ['imageWidth', '==', 640],
    'message' => __('The image width must be 640 pixels.'),
]);
```

### What happened
`'Argument 1 passed to Cake\Validation\Validation::imageWidth() must be of the type array, object given'.`

### What you expected to happen
Validation should not throw an error.
