Title

Redirect of HttpsEnforcerMiddleware loses base path

Description
### Description

When I install a fresh copy of CakePHP and add the following line to `src/Application.php`'s `middleware()` method ...

```
->add(new HttpsEnforcerMiddleware(['disableOnDebug' => false]))
```

... I notice that the resulting redirect from http to https loses the base path of my installation.

For example, if my app is running at [URL] the forward actually takes me to [URL] (i.e. it loses "cakephp-test"). Also if I go to [URL] it redirects me to [URL] (also losing "cakephp-test").

So as soon as CakePHP is not running on the root of a domain, the HttpsEnforcer redirect breaks. Also verified by uploading it to a proper webserver.

### CakePHP Version

4.3.0

### PHP Version

7.4
