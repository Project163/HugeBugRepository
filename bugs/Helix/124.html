Title

Disabling smart-tab in config does not work

Description
### Summary

I've disabled smart-tab in my config, but helix behaves as if smart-tab is enabled.
If I run `:set smart-tab false` in the editor, now helix behaves as if smart-tab is disabled.

### Reproduction Steps

  

Where `example.json` is: 
```
{"one": 1, "two": 2}
```

Where `hx.toml` is:

```
[editor.smart-tab]
enabled = false
```

I tried this:

1. `hx example.json -c /tmp/hx.toml`
2. Place the cursor on 1
3. Press `i` to enter insert mode
4. Press tab 

I expected this to happen:

Nothing, smart-tab is disabled

Instead, this happened:

The cursor jumps through elements
