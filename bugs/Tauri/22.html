- I went through all dependencies, checked how they were used, checked the respective documentation, updated the dependency and fixed any errors coming up. See the respective PR for the fixes.

- winit:  It's not used -> remove
- ar: Seems fine, usage in the bundler complies with the crates's documentation
- cab: Is not used anywhere -> remove
- dirs: Only used to osx_bundle.rs to obtain home dir. Major version update should be fine.
- glob: Seems fine, usage in the bundler complies with the crates's documentation
- images: Here a few minor changes are necessary to update to the latest version.
  1. PNGDecoder::new now returns a PNGDecoder wrapped in a Result
  2. ImageDecoder::dimensions returns a u64 instead of a u32 tuple. As icon files won't be so large as to warrant dimensions of type u64 I propose to cast them down.
- md5: Seems fine, usage in the bundler complies with the crates's documentation
- strsim: Seems fine, usage in the bundler complies with the crates's documentation
- term: Seems fine, usage in the bundler complies with the crates's documentation
- toml: Seems fine, usage in the bundler complies with the crates's documentation
- uuid: Some changes are necessary:
   1. from_bytes does not take a reference anymore and returns a Uuid instead of a Result
   2. Uuid::new_v5 expects a u8 array instead of a str as its second parameter
- lazy_static: Seems fine, usage in the bundler complies with the crates's documentation
- handlebars: Major version upgrade seems fine. The way it is used still complies to the crate's documentation
- hex: Seems fine, usage in the bundler complies with the crates's documentation
- looks good to me, @kastenbutt
