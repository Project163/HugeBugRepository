- I think you're basically just asking to suppress all `MixedAssignment` warnings, right? That can be done via the config.

Otherwise, this is a wontfix – it would require far too much extra work.
- The idea is to have the same rules of `/** @var Foo $foo */` apply also to `assert($foo instanceof Foo);` when the assertion is immediately following the first declaration of the variable.

Alternatively, the rule could be "variable never used before assertion".

This would make the strictly typed mode of psalm usable with layers such as json decoding (and upcasting), which are currently in direct conflict with assertions and `/* @var */` (the consider each other redundant):

```php
/** @var list  $a */ // can't remove this due to mixed assignment rule
$a = json_decode($b);

Assert::isList($a); // detected as redundant, but strictly required by runtime invariants
```

In the code above, the correct modus operandi is to only have the assertion, since removing that is leading to a Security issue.
