Title

Methods in ErrorHandler should set 'title_for_layout' and not 'title'

Description
Created by **RabidFire**, 9th Jan 2011. _(originally [Link: Lighthouse ticket #1439])_:

---

A very minor issue: The title for error pages is always fixed at "Errors".

I came across this when I was trying to create custom maintenance pages as described on [Link: Mark Story's Blog], and the value passed into the 'title' parameter would not work.

Attached a patch for `/cake/libs/error.php`. It's my first time contributing a patch. Hope this is the right way to do it.

Cheers!
Discussion
- 10th Jan 2011, **[Link: Mark Story]** said:

---

My only concern with changing this in 1.x is breaking all the existing applications that are using `$title`.  I think it would be better to set both `$title_for_layout` and `$title`.  We could remove title in a future version of course.
