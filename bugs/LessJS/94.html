Title

Remove warning for IE8 size limit if I've turned off compatibility?

Description
The first time I used data-uri, I thought I must have missed turning off IE compatibility because there were a bunch of giant scary warnings about exceeding the size limit.

Since a developer must opt into turning on that flag, and since the flag is explicitly for data-uri, should we be issuing warnings? A developer has already heeded the warnings and decided to ignore them for his/her particular project. And, since you might use data-uri on many many images, it fills the console with a bunch of warnings you don't need.

Can/should we turn these off? For me, they don't make sense.
