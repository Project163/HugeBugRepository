Title

serve(aot): with Ivy, does not detect changes to files

Description
# 🐞 Bug report

### Command
```
- [x] serve
```

### Is this a regression?
Yes? I didn't use AOT for dev mode serving previously because it wasn't as performant as it is now in Ivy.

### Description
The [Link: Ivy Guide] suggests enabling `"aot": true` for dev mode builds.

What I’m finding during that experience is that while the rebuilds are super fast in Dev mode (`aot: true`), the Angular CLI often doesn’t pick up changes to SCSS and HTML. I need to constantly re-run `ng serve` over and over again to see my changes. It’s not the kind of DX that we’re looking for. 

Changing back to `aot: false` works around this issue.
