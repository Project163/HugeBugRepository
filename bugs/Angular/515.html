Title

NgZone: Emit onError event outside the zone

Description
Currently we emit the onError event from NgZone within the zone itself.

This causes a problem when there is an exception in the error handler itself and that exceptions tries to trigger the onError event again. In Dart this would result in an unhelpful exception message like 

"Caught Bad state: Cannot fire new event. Controller is already firing an event"

instead of surfacing the exception in the error handler.

The fix is to just emit the onError even outside of the NgZone.
