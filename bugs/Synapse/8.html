Title

Synapse Send mediator should not stop mediation

Description
It should be possible to perform a <send/> and continue mediation.  

 If a response message has already been sent over a transport such as http, and another is being attempted, this is a user error and the second should fail. However, is using a transport such as JMS/mail, it should be possible to send the same message out multiple times, as well as continue processing after a send operation. e.g. in the case of a one-way message
Discussion
- Done 

 Now by default <send/> will not stop - hence the uses must be careful to avoid multiple sends or use a drop to stop processing, unless it is the actual functionality they want
