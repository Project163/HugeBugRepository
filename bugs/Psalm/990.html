Title

Can't surpress MissingDependency error

Description
I might be using this wrong but I'm trying to supress this error:

```
ERROR: MissingDependency - tests/Unit/Social/GithubUserTest.php:22:49 - Carbon\Carbon depends on class or interface cake\chronos\chronosinterface that does not exist (see [URL]
        $user = new GithubUser(['created_at' => Carbon::now()->subWeek()]);
```

It's thrown when I run psalm on the [Link: Laravel.io codebase] with the following config:

```
cml
 
 
 
```

Notice that I'm trying to surpress in the `issueHandlers` part. The error itself is thrown because Chronos loads [Link: this file] which aliases a class and interface (which I don't want). Unfortunately there's no way around it.

Any idea why I can't surpress the error from above?
Discussion
- I can't since it's such a large codebase with lots of dependencies.
- The interface Psalm complains about actually exists and is autoloadable:
```console
$ php -r 'require "vendor/autoload.php"; var_dump(interface_exists("Cake\\Chronos\\ChronosInterface"));'
Command line code:1:
bool(true)
```
- ... [Middle Discussions Snipped for Brevity] ...
- It works if I change

```
if (!\class_exists('Carbon\Carbon') && !\interface_exists('Carbon\CarbonInterface', false)) {
```
to 
```
if (!\interface_exists('Carbon\CarbonInterface', false)) {
```
