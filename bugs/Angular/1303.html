Title

docs: No Id's in products.ts in the getting started guide

Description
# 📚 Docs or angular.io bug report

### Description

 
The repo you should fork for the getting started [URL] has no property for id in the arry products


## 🔬 Minimal Reproduction

### What's the affected URL?**
 
[URL]

### Reproduction Steps**
 
 
If you followed the steps of the first tutorial and this tutorial [URL] the products in the array product have **no Id**

### Expected vs Actual Behavior**
 
 
The url should show: `../products/{id}` but as there is no id it shows `../products/undefined` and also the product details are not shown, because of that.
