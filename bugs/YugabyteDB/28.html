Title

NoHostAvailable error when creating index with unsupported index column datatype

Description
When creating creating an index with unsupported index column datatype, NoHostAvailable error is hit:

```
cqlsh:k> create table t (k int primary key, b boolean) with transactions = {'enabled' : true};
cqlsh:k> create index t_by_b on t (b);
NoHostAvailable:
```
