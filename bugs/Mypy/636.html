Title

False positive with --warn-unreachable: TypedDict may be empty

Description
Hi,

I believe there is a false positive related to empty `TypedDict`s with `total=False`.

Using `--warn-unreachable`:

```
python
from typing_extensions import TypedDict

class A(TypedDict, total=False):
    ...
... [Log Snipped] ...
if not b:
    print('b is empty')  # error: Statement is unreachable
```

Using Python 3.7.4, tested with both mypy 0.740 and mypy master.
Discussion
- Thanks for reporting! This looks like something easy to fix. In the `TypedDictType` constructor in `mypy/types.py` one just needs to use `required_keys` instead of `items` to determine value of `self.can_be_false`.
