Title

After upgrade to Quarkus 1.5.1 @Transactional not save changes

Description
After upgrade to Quarkus 1.5.0 (and 1.5.1 also) @Transactional not save changes to database

In version 1.4.2 all changes commited to Oracle db
with version 1.5.1 I expect same bahaviour

but changes not saved

**Query in FPJob PanacheEntity**

```java
public static List  loadAllPendings() {
    var startDT = LocalDateTime.now().minus(10, ChronoUnit.MINUTES);
    var startDate = Date.from(startDT.atZone(ZoneId.systemDefault()).toInstant());

    return find("#load-all-pending-jobs", startDate).withLock(LockModeType.PESSIMISTIC_WRITE).list();
}
```

**but this code is working**
```java
@Transactional
public void removeOldJobs() {
    var startDT = LocalDateTime.now().truncatedTo(ChronoUnit.DAYS).minus(6, ChronoUnit.DAYS);
    var startDate = java.util.Date.from(startDT.atZone(ZoneId.systemDefault()).toInstant());
    FPJob.delete("sysdateReq < ?1", startDate);
}
```
