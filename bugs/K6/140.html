Title

Paths containing spaces cause a panic

Description
### Brief summary

k6 panics when trying to archive or run a script that's located in a path that contains a space.

### k6 version

1.4.0

### OS

macOS Tahoe 26.1

### Docker version and image (if applicable)

_No response_

### Steps to reproduce the problem

1. Create a directory with a space in its name
2. `cd` into the directory
3. Create a k6 script
4. Run the script

### Expected behaviour

The script should run normally

### Actual behaviour

A panic is logged to the console:

```
ERRO[0000] unexpected k6 panic: stat /Users/ /path%20to%20script/temp.js: no such file or directory
goroutine 1 [running]:
runtime/debug.Stack()
        runtime/debug/stack.go:26 +0x64
go.k6.io/k6/internal/cmd.(*rootCommand).execute.func2()
... [Log Snipped] ...
main.main()
        go.k6.io/k6/main.go:9 +0x1c
```

As you can see, the path is URL encoded. It's also notable that it works if you run the script from outside the directory:

```sh
# works
k6 run path\ to\ script/temp.js

# does not work
cd path\ to\ script
k6 run temp.js
```
