Title

WS-RM Sequence header should have mustUnderstand attribute

Description
per the WS-RM spec 2005 Feb 

 <wsrm:Sequence> element MUST have a mustUnderstand attribute from the namespace corresponding to the version of SOAP to which the <wsrm:Sequence> SOAP header block is bound. 

 Currently CXF WS-RM implementation don't have this mustUnderstand attribute for Sequence, hence can cause issues when talk to other WS-RM implementations which has strict check
