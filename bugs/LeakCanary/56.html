Discussion
- The crashing line is:

```
    val latest = backstack.removeAt(backstack.size - 1)
```

The error has: `ArrayIndexOutOfBoundsException: length=5; index=-1`

So it looks `backstack.size` returned 0 (=> index=-1) however how in that case is the length 5?
- The length is 5 because that's the size of the ArrayList backing array, however the list itself had a size of 0.

This error happened because we go back async after the deletion is done executing, and in the meantime the monkey moved us elsewhere.
- ... [Middle Discussions Snipped for Brevity] ...
- I tried slowing down the DB write and wasn't able to repro. updateUI() is ignored if the view has been detached. So I'm not sure I understand exactly how we triggered this.

Edit: unless it ran it while transitioning out, at which point the view is still detached.
- Reproduced by adding a sleep 5s to the background deletion and changing the back animation time to 10s. Then I click delete from a heap dump screen and then back
