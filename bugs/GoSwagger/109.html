Discussion
- It seems like that client and server never use functions MarshalJSON and UnmarshalJSON from go-openapi/strfmt/time.go.
- I think, I found the reason of bug.
When we call ProducerFunc from /go-openapi/runtime/json.go ,then  data interface{} has type Model.Datetime ( type, that is generated by goswagger). But this type has not methods like MarshalJSON. So it can not make right JSON.
But Model.Datetime is just redefinition of type strfmt.DateTime, that has such methods. 
So we have two possible ways of solution of problem:
1)Add automatic generation of methods like MarshalJSON for generated types 
```
func (t Datetime) MarshalJSON() ([]byte, error) {
	return strfmt.DateTime(t).MarshalJSON()
}
```
2) Convert type Model.Datetime to strfmt.DateTime before it falls into ProducerFunc
