Title

`TypeError: issubclass() arg 1 must be a class` when using `Mapper[Optional[X]]`

Description
### Describe the bug

When trying to configure a relationship like this:
```
    some_prop: Mapped[Optional[XYZ]] = relationship(
        back_populates="other", default=None
    )
```

Is this not the right way to configure a zero to many relationship? 

I get a runtime error.
Printing the type name before the error gives `typing.Optional[ForwardRef('XYZ')]`

### To Reproduce

```python
some_prop: Mapped[Optional[XYZ]] = relationship(
        back_populates="other", default=None
    )
```
