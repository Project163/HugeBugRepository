Title

Blank soap address location is appended for mail and vfs ports of the proxy service wsdl

Description
1. Start the Synapse configuration numbered 150: i.e. synapse -sample 150 
2. Go to  [URL] and view the WSDL 

 You will notice that the endpoint address location is blank in vfs and mail endpoints.  

 <wsdl:port name="StockQuoteProxyVfsSoap11Endpoint" binding="axis2:StockQuoteProxySoap11Binding"> 
<soap:address location=""/> 
</wsdl:port> 

 <wsdl:port name="StockQuoteProxyMailtoSoap11Endpoint" binding="axis2:StockQuoteProxySoap11Binding"> 
<soap:address location=""/> 
</wsdl:port>
Discussion
- This is because these transports are not properly configured for this particular service, for example you have not provided the email address to listen for the mail transport and so on. 

 Any way we should disable the not configured transports at the service deployment time after a warning.
- Fixed on the SVN trunk, check for the verification
- The endpoint address locations are properly displayed. Tested on 1.2_SNAPSHOT. The issue can be closed
