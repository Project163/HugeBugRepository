Title

Concurrent access to Graal.js Proxy scripts with latest ZAP versions

Description
### Describe the bug

Scripts (especially Proxy scripts) do not work any more on recent Java versions (21). They are terminated and disabled with the following error message in the console:
```
proxyRequest called for url=[URL]
proxyResponse called for url=[URL]
proxyRequest called for url=[URL]
proxyRequest called for url=[URL]
proxyResponse called for url=[URL]
java.lang.IllegalStateException: Multi threaded access requested by thread Thread[#237,ZAP-IO-Server-1-6,10,main] but is not allowed for language(s) js.proxyRequest called for url=[URL]
java.lang.IllegalStateException: Multi threaded access requested by thread Thread[#237,ZAP-IO-Server-1-6,10,main] but is not allowed for language(s) js.
```

### Steps to reproduce the behavior

1. In the top left box click `+`, then add the `Scripts` tab
2. Right-click on "Proxy" -> "New Script"
3. Give the script a name, e.g. "test"
4. Choose "Script Engine" "ECMAScript : Graal.js", Template is auto-filled with the "Proxy default template"
5. Click "Save"
6. In the "Scripts" tab on the left, right-click on the script and select "Enable"
7. Access a non-trivial website which does a few requests
8. Observe that the script has been disabled an the console below the script contains the error mentioned above

### Expected behavior

I expect Proxy scripts to be called and not be terminated.
