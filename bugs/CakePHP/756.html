Title

Traversing collection more than once causes emptying translations

Description
Hello,

I traversed and formatted (using formatResults) my result two times (two finders) - causing `TranslateBehavior::groupTranslations()` is called twice. This behavior empties `_translations` property in entity, because `_i18n` property is no longer available. 

I fixed it with condition.

``` php
if(empty($translations)){
    return $row;
}
```

added on line 460 behind

``` php
$translations = (array)$row->get('_i18n');
```

edit:
Please let me know, if the problem is in my code. 
I have my own finder which inserts formatter via `$query->formatResults();`
my format function is traversing `$results` collection in foreach loop 2 times. After the first foreach loop entity looks good but after second foreach (or `Collection::first()` call) `_translations` property becomes empty. Maybe I should eliminate formatter when traversing collection somehow.

I use my finder in combination with findTranslations

``` php
//contoller
$this->Pages->find('myFinder')->find('translations');
```

Thanks.
