Title

panic: interface conversion: interface {} is *mypackage.PostActionsDefault, not *mypackage.PostActionsCreated

Description
## Problem statement

I have a spec file which has a default response to catch unexpected codes from the server
```
responses:
        201:
ok
          schema: {$ref: '#/definitions/action'}
        400:
... [Log Snipped] ...
unexpectederror
          schema: {type: text}
```

when the server does respond with either a non 201, 2XX reply like 204, the generated client panics because the code flows through the success case and tries to map it to the action object.


Please remove the sections that don't apply

## Swagger specification
2.0

## Steps to reproduce
use default response and only declare 201 as expected output. But make server misbehave and send a 204 instead.
