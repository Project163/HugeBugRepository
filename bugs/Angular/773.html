## Current behavior
 
When I click anywhere on angular.io, the website always fetches all favicons (total of 19.3 KB).

## Expected behavior
 
The site gets them only once.

## Minimal reproduction of the problem with instructions
 
Go to [URL] open the Network tab in the DevTools and click on the page. Only happens on Google Chrome.
## What is the motivation / use case for changing the behavior?
 
The website downloads way more content than it needs to.

- For what it's worth, this doesn't happen if the user specifically clicks inside `aio-search-box`, presumably because it stops propagation. If you set up a click listener on every child of `aio-shell` that does the same, the issue goes away, leading to the conclusion that `aio-shell` should be the culprit. How or why, I have no idea just yet.
- A click on `aio-shell` closes the search box and calls `setSearch`, which in turn uses the native history API to `replaceState`, which triggers the behavior. Perhaps something is subscribed to the location change, that triggers this behavior.
