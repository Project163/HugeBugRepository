Title

The OsgiServiceRegistry class caches service references

Description
As discussed in  [URL] the OsgiServiceRegistry class caches service references hence limits the ability to dynamically install and use a new version of the same service
Discussion
- Camel patch attached is an integrated test for camel-scr highlighting the issue raised in the Description of the Jira. The test currently fails but should pass when the issue is fixed. 

 The patch does not provide a solution, however I think the caching should be removed from the org.apache.camel.core.osgi.OsgiServiceRegistry (camel-core-osgi) class.
