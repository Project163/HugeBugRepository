Title

Xcode Templates need update and testing

Description
With the release of Xcode 4.5 by Apple the current version of the SFML template for Xcode 4 needs to be reverified.

These templates should also take into account C++03/11 more correctly for compatibility with SFML binaries.

Also their is currently a mistake : the search path should not contains double star (`**`) because this can lead to very _interesting_ inclusion bugs (e.g. if you have wx or boost installed and you include ` ` you can end up looking at incomprehensible error message.) Actually, it looks like no `*` is required.
