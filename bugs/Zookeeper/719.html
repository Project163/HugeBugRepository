Title

stmk four-letter word fails execution at server while reading trace mask argument.

Description
When the server handles the  stmk  four-letter word, it attempts to read an 8-byte Java  long  from the request as the trace mask argument.  The read fails, because the destination buffer's capacity is only 4 bytes.
Discussion
- See below for sample stack traces from both the NIO connection and the Netty connection.  I believe this has been broken since release 3.3.0 by the   ZOOKEEPER-572   patch.  Prior to that patch, the code had been allocating an 8-byte buffer for reading the trace mask argument.
