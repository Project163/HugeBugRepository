Title

[DocDB] Table locks: Fix failing DeadlockDetectionWithTxnPromotionTest suite

Description
Jira Link: [Link: DB-18271]
### Description

The test disables `FLAGS_refresh_waiter_timeout_ms` as an extra measure to ensure deadlocks (with row locks alone) are detected even without periodically timing waiters out of the wait-queue.

With table locks enabed, we take a dependency on periodicially timing out waiters to detect certain deadlocks spanning object locks, row locks and other kinds of locks (Refer [Link: commit]). Hence, we shouldn't disable the periodic timing out of waiters from the wait queue when table locking is enabled.
