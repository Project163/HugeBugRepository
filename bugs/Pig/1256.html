Discussion
- Use report.getCurrentStatus() instead of report.getProgress() to get job status. I haven't check if report.getCurrentStatus() is supported by old Hadoop yet. So please hold on.
- The new patch put the logic in shims layer. The API TaskReport.getCurrentStatus is introduced in 0.21. However, we only see issues with the getProgress trick in Hadoop 2. So putting in the shims should be fine and avoid reflection which makes code ugly.
- Patch committed to both 0.12 branch and trunk.
