Title

Description
### Neovim Version

v0.5.0

### Operating system/version:

Ubuntu 20.04

### Terminal name/version:

xfce4-terminal

### TERM environment variable

xterm-256color

### Installation

appimage

### Steps to reproduce

I am starting from a simple HTML `index.html` file containing only a pair of ` ` tags.

```html
 
 
```

I am using neovim v0.5.0, downloaded from the appimage, and I am opening the above HTML file with:

```
nvim.appimage -u NORC index.html
```

Then, I put my cursor on the opening tag ` ` and go to insert mode at the next line using `o`. Then I start to type ` `, the tag gets pushed one level of indentation to the right.

To me, this is not supposed to happen. And if I repeat the exact same steps with neovim v0.4.4, I don’t have the problem. The ` ` stays where it is.
