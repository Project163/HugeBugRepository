Title

Invalid time unit conversion causing write timeouts

Description
We've been debugging a write timeout that we saw after upgrading from the 2.0.x release line, with our particular workload. Details of that process can be found in this thread: 

  [URL]

 After bisecting various patch release versions, and then commits, on the 2.1.x release line we've identified version 2.1.5 and this commit as the point where the timeouts first start appearing: 

  [URL]

 After examining the commit we believe this line was a typo: 

  [URL]

 as it doesn't properly convert the timeout value from milliseconds to nanoseconds. 

 After testing with the attached patch applied, we do not see timeouts on version 2.1.5 nor against 2.2.5 when we bring the patch forward. While we've tested our workload against this and we are fairly confident in the patch, we are not experts with the code base so we would prefer additional review.
