Title

Adding a new partition specified by location (which is empty) leads to Exceptions

Description
create table supply (id  int , part string, quantity  int ) partitioned by (day  int )
       stored as orc
       location  'hdfs: ///tmp/a1' 
        TBLPROPERTIES ( 'transactional' = ' true ' )
;

alter table supply add partition (day=20110103) location 
        'hdfs: ///tmp/a3' ; 
 
  

 check exception: 
  
 
org.apache.hadoop.hive.ql.metadata.HiveException: Wrong file format. Please check the file's format.
	at org.apache.hadoop.hive.ql.exec.MoveTask.checkFileFormats(MoveTask.java:696)
	at org.apache.hadoop.hive.ql.exec.MoveTask.execute(MoveTask.java:370)
	at org.apache.hadoop.hive.ql.exec.Task.executeTask(Task.java:210)
	at org.apache.hadoop.hive.ql.exec.TaskRunner.runSequential(TaskRunner.java:97)
 
  

 If the format check is disabled; an exception happens from AcidUtils; because during checking it doesn't expect it to be empty.
