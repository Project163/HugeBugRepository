Discussion
- The file is opened by Chrome and icepdf
- The ArrayIndexOutOfBoundsException is occurring on the following line: 

  
  // fallback to the first cmap (may not be Unicode, so may produce poor results)
 cmap = cmapTable.getCmaps()[0];
 
  

 Which would suggest that something is wrong with the "cmap" table in the font file. Presumably the table is present, but doesn't contain any actual cmaps. So getCmaps() is an empty array. 

 As you can't share the PDF, please build PDFBox from source and make the following change to TrueTypeFont.java, in getUnicodeCmap. Change this code: 

  
  if  (isStrict)
{
      throw   new  IOException( "The TrueType font does not contain a Unicode cmap" );
}
 else  {
    ...
 
  

 To this: 

  
  if  (isStrict)
{
      throw   new  IOException( "The TrueType font does not contain a Unicode cmap" );
}
 else   if  (cmapTable.getCmaps().length == 0)
{
      throw   new  IOException( "The TrueType font does not contain any cmaps" );
}
 else  {
    ...
 
  

 And let me know what happens. Does the file render as expected?
