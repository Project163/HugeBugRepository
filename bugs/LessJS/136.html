Title

Guards on pseudo-classes produce syntax error

Description
Source:

``` css
a:hover when (1=1) {
    color: red;
}
```

Error:

```
expected ')' got '='
```
Discussion
- Confirmed. To be more specific the parser does not like a number (and some other entities e.g. `@var`) followed by comparison operator for some reason, e.g.:

```
a:hover when (true)         {1:-} // OK
a:hover when (true = true)  {2:-} // OK
a:hover when not (true = 2) {3:-} // OK
a:hover when not (2)        {4:-} // OK
a:hover when not (2 = true) {5:-} // Err.
```
- It also fails on variables:

``` css

@a: red;
a:hover when (@a = red) {
    color: red;
}
```
