Title

Log history V2 API doesn't serialize properly

Description
Introduced in v9.5.0 by   SOLR-17063  , we have SolrDocuments that are backed by unmodifiable maps that don't support  entrySet() , and thus fail for certain serialization techniques (including the one used by the V2 API). 

 This failed quietly, just writing an empty list – no exception thrown, but useless (empty) results, where there should be content.
