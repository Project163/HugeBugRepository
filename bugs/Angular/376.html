Title

Pass an array to the Router using queryParams

Description
**I'm submitting a ...**

[x] bug report => search github for a similar issue or PR before submitting
[ ] feature request
[ ] support request => Please do not submit support request here, instead see [URL]

**Current behavior**
Currently when we need to pass some query parameter with an array of values, we should do something like this:
```
const queryParams = { ids: [1, 2, 3] };
this.router.navigate(['/some-route'], { queryParams: queryParams });
```
And resulting URL is: `/some-route?ids=1%2C2%2C3`

When we will try to get query parameters via `this.route.queryParams.subscribe((queryParams: Params) =>{...})`, queryParams['ids'] will return string '1,2,3', but not an array with desired values.

**Expected behavior**
Router should serialize queryParams with arrays of values to multiple query parameters with the same name: `/some-route?ids=1&ids=2&ids=3`
