#### What is the problem you are having with rclone?
Similar to [Link: Percentages Exceeding 100%] all my files exceed the 100% progress per file up to 200%. Furthermore, it uses double the amount transferred, so for 3 TiB of files it SHOWS 6 TiB of transferred. Real traffic seems to be half of that so the correct amount (not 100% sure on that) This happens on azureblob with the default block size of 4MiB and files of about 64MiB. This stops happening if I set chunk size to 128Mi. Also, setting chunk size to 128Mi (larger than any file in repo) significantly reduces transactions.
