Title

Installation script incorrectly believes starship is not on PATH

Description
### Discussed in [URL]

 

 Originally posted by **thecesrom** January 21, 2022 
I have installed starship on Git Bash for Windows (not WSL) by overriding the bin installation directory, and even though I have added the custom location to my `$PATH` whenever I upgrade starship it still complains the directory is no in my `$PATH`.

### Installation

```bash
sh -c "$(curl -fsSL [URL] -- --bin-dir="$HOME/.starship/bin/"
```

### `$PATH`

Method 1:
Adding the custom path through the GUI.

Method 2:
Adding the following line to my `.bashrc`

```bash
export PATH="$PATH:$HOME/.starship/bin"
```
