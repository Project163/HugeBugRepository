Title

About the coding styles of python codes in the ./app/ folder

Description
It seems that the ./app/ folder does not keep the soft limit (78) and hard limit(79) guideline. 

* [URL]
```bash
Lines shouldn't exceed 78 columns.
You can enforce this in :command:`vim` by setting the textwidth option:
set textwidth=78
If adhering to this limit makes the code less readable, you have one more character to go on. This means 78 is a soft limit, and 79 is the hard limit :)
```
