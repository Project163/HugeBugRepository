Title

Coordinator node role fails to create synthetic cores for multiple coordinator nodes

Description
Currently the coordinator node role has a bug where multiple coordinator nodes that receive calls for the same configuration can hit a recursive loop and fail to create the necessary synthetic cores used to proxy calls. 

 This only occurs when there is >1 coordinator nodes.
