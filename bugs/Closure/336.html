Title

Advanced optimizations removes instanceof check

Description
Given the following input:

if (propEvt instanceof window.MouseEvent) propEvt.preventDefault();
if (globalEvt instanceof MouseEvent) globalEvt.preventDefault();

$ closure --compilation_level ADVANCED_OPTIMIZATIONS mouseeventtest.js
globalEvt instanceof MouseEvent&&globalEvt.preventDefault();

The same happens with any property on window, unless it has been accessed or set before. So a simple if (window.MouseEvent) ... in the beginning of the file will prevent the propEvt line from being optimized away.

I'm not sure if this is a feature, but in that case it is an unexpected one.
Discussion
- I'm not sure what pass is doing this but without a definition for window.MouseEvent, something is assuming the expression is false.  Adding a definition for "window.MouseEvent" in the externs should be sufficient to fix this, if this is the case.
