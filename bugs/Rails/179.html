Title

Eager loading on empty?

Description
Since Rails 5.1, this followed line make an eager loading for empty?.
`
comments = SupplierComment.where("DATE(created_at) = ?", Date.yesterday).includes(:supplier)
comments.empty?
`

For the first line, the SQL generated is : 
`SELECT  `supplier_comments`.* FROM `supplier_comments` WHERE (DATE(created_at) = '2017-05-09') ORDER BY supplier_comments.created_at DESC LIMIT 11
`

For the second the SQL is : 


` SELECT  `supplier_comments`.* FROM `supplier_comments` LEFT OUTER JOIN `suppliers` ON `suppliers`.`id` = `supplier_comments`.`supplier_id` WHERE (DATE(created_at) = '2017-05-09') ORDER BY supplier_comments.created_at DESC`

In my code this cause an ambiguous request because of created_at on the two table.
In Rails 5.0, not LEFT OUTER JOIN was made.

I suspect this commit [URL]

The empty? method was redefine, with support of no eager loading, but seems to not work fine ?

I use Rails 5.1.0 and Ruby 2.4.0
