Title

Fix wrong help messages of parquet-cli subcommands

Description
There are some minor mistakes in the help messages of parquet-cli, as follows: 

  
 
$ java -cp  'target/parquet-cli-1.14.0-SNAPSHOT.jar:target/dependency/*'  org.apache.parquet.cli.Main help rewrite

...

    --prune-columns
	<columns to be replaced with masked value>
 
  

 It is the description about the  --mask-columns  option, not for  --prune-columns . 

  
 
$ java -cp  'target/parquet-cli-1.14.0-SNAPSHOT.jar:target/dependency/*'  org.apache.parquet.cli.Main help convert-csv

...

  Examples:

    # Create a Parquet file from a CSV file
    parquet convert-csv sample.csv sample.parquet --schema schema.avsc

    # Create a Parquet file in HDFS from local CSV
    parquet convert-csv path/to/sample.csv hdfs:/user/me/sample.parquet --schema schema.avsc

    # Create an Avro file from CSV data in S3
    parquet convert-csv s3:/data/path/sample.csv sample.avro --format avro --schema s3:/schemas/schema.avsc
 
  

 Output paths in these examples should be specified using the  -o / --output  option. In addition, that subcommand doesn't have the  --format  option.
