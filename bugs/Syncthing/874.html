Title

Changing folder type from receive encrypted to a different type corrupts the database

Description
I know that this should not be done, but it is technically possible to do, so I'm reporting anyway, just in case.

1. On Device 1, create a new folder with some files.
2. On Device 1, share the new folder with Device 2 as RE.
3. On Device 2, accept the new folder as RE and let it sync.
4. On Device 2, change the folder type to SR in the Adv. Configuration.
5. On Device 1, remove the folder password.
6. Both devices now mark the folder as "Up to Date".

[Image: image]
[Image: image]

It would be cool if changing the folder type for RE folders could be prevented completely, but I'm not sure if this is even possible.
