Title

Fsync errors should not be reported to the console

Description
Since samba does not support fsync on directories the syncthing daemon gives a lot of "invalid argument" error. It would be great if fsync could be disabled/ignored for directories. 
I think this behaviour is already the default case for windows (5ec1490), but I would like to use it on Linux.

Syncthing Version: v0.14.39
OS Version: Linux / Ubuntu 17.04
