- Ok, the problem is this line: [URL]

Due to Angular's `ZoneAwarePromise` malarky, that line evaluates to false, even though it `moduleExportsOrPromise` is a promise.

We are just doing check there to make sure people aren't returning promises when they shouldn't be. I think maybe we can reverse this check and just not have the check work in Angular. Unless there is a better way to reliably tell if an object is a promise.
