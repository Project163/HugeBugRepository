Title

AssertFailure: ByteCode Conditional then/else stack mismatch

Description

 CREATE TABLE table1 ( 
   s VARCHAR(10)); 

 SELECT 1 
   FROM table1 a 
      INNER JOIN table1 b ON 
         a.s = 
            CASE 
               WHEN 1=1 THEN '0' 
               ELSE SUBSTR(b.s,1,1) END;
