Title

Allow HookContext to access SQLOperationDisplay

Description
There is a lot of useful information in  SQLOperationDisplay  that users of Hive Hooks may be interested in. 

 We should allow Hive Hooks to access this info by adding the  SQLOperationDisplay  to  HookContext . 

 This will allow hooks to have access to all information available in the HS2 Web UI.
