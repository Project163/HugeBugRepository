Title

Deferred building regression due to pass through handling

Description
The implementation of the pass through transport (  SYNAPSE-913  ) prevents using the deferred building feature of Axiom while using content aware mediators. 

 Due to the code in RelayUtils the complete Axiom model is build when the pass through transport (or the BinaryRelayBuilder) isn't used.
Discussion
- This patch fixes the issue by only reading the qualified name of the first element in the SOAP Body instead of reading all elements in an attempt to find the binary payload element.
- There is some interference with logging instrumentation that causes the test case to fail during the Maven build. This will require a fix in Axis2.
