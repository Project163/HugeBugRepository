Title

Table API expressions with several built-in functions are not correctly serialized to SQL

Description
There are several built-in functions in Table API that are not correctly translated into SQL expressions: 
  toTimestamp($("fld"), "yyyy-MM-dd hh:mm:ss")  
translates to 
  TOTIMESTAMP(fld, 'yyyy-MM-dd hh:mm:ss')  
however, the SQL function is called  TO_TIMESTAMP . 
There are several functions for which the SQL translation misses the  _  character. 

 Incomplete list: 
 
	  dateFormat()  →  DATE_FORMAT()  
 

 
	  convertTz()  →  CONVERT_TZ()  
 

 
	  fromUnixtime()  →  FROM_UNIXTIME()  
 

 
	  unixTimestamp()  →  UNIX_TIMESTAMP()  
 

 
	  toTimestampLtz()  →  TO_TIMESTAMP_LTZ()  
 

 
	  toTimestamp()  →  TO_TIMESTAMP()  
 

 
	  toDate()  →  TO_DATE()  
 

 
	  charLength()  →  CHAR_LENGTH()
