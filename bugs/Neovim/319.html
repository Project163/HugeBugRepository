Title

tabline crash on resize

Description
- `nvim --version`: NVIM v0.5.0-593-g1ca67a73c
- `vim -u DEFAULTS` (version: ) behaves differently? Yes
- Operating system/version: Debian Testing
- Terminal name/version: alacritty 0.4.3
- `$TERM`: alacritty

### Steps to reproduce using `nvim -u NORC`
  1. 
```bash
nvim -u NORC
```
  2.
```vim
:source vimrc
:tabe vimrc
```
  3. Then resize your window.

Where **vimrc** is:
```
vim
call plug#begin('~/.vim/plugins')
Plug 'itchyny/lightline.vim'
call plug#end()

... [Log Snipped] ...
  return ""
endfunction
```

### Actual behaviour

Crashes with the following error: ```double free or corruption (!prev)```

Here is **gdb** acktrace:
```
sh
```

### Expected behaviour

No crash, like **vim**.
Note that this bug only happens when using **empty tab names** and **exotic separators**.
