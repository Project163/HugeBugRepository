Title

Usage of async before-each is wrong or at not described sufficiently

Description
# 📚 Docs or angular.io bug report

### Description

On the Testing Guide, in section 'Component Test Basics/Component DOM testing/CLI generated tests' there is an example that shows an initial spec file for the banner-external component.
This test contains two before-each() declarations, one of them being async. However, there is nothing inside that is being awaited, thus it is very confusing why the async version of before-each() is used or needed. 
The describing text doesn't mention anything either.
