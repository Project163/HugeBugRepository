Title

Description
There's a problem with context reloading triggered from k8s secrets when using an autowired KubernetesClient. 

 Both SecretsReloadTriggerTask and AbstractKubernetesEndpoint close the KubernetesClient. When routes get refreshed, the closed client is wired back in an unusable state.
