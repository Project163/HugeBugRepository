The main is in Windows : selecting Default theme from another being yet set will switch to Dark theme (auto reload on "Save"  works OK)

- The default theme supports auto switching between light and dark depending on the current OS mode. Windows and macOS supports this when configured appropriately, typically switching to dark themes after sundown and switching back to light at sunrise. At least that's what my systems do. Perhaps this is not supported in your Linux setup. I don't think this is a bug.
- It's effectively down to the browser caching behaviour, some require a refresh, some don't.
