Title

BaseActiveRecord::__isset and php 7.x

Description
### What steps will reproduce the problem?
Suppose my magic getter throws an error that is not an exception.

### What is the expected result?
Calling `isset($obj->throwError)` should return `false`. 

### What do you get instead?
Due to this code:
```
php
public function __isset($name)
    {
        try {
            return $this->__get($name) !== null;
... [Log Snipped] ...
        }
    }
```
Exceptions are caught but errors are not.

I think it makes sense to not use a typehint here.
