Title

SCR plugin shows misleading message

Description
If Declarative Services are not installed the corresponding Tab shows the message "Apache Felix Declarative Service not installed " which is misleading because Felix SCR API are recommended by OSGi and other vendors (like Eclipse) might also implement it. 

 So ""Apache Felix compatible Declarative Service not installed " or just "Declarative Service not installed" would be better.
