Title

Remove legacy alias feature for JDBC

Description
ZEPPELIN-999   enables users to use JDBC with it's own prefix. But   ZEPPELIN-1012   finished, it makes Zeppelin support general way to use aliases for all interpreters. Thus JDBC sugar is not useful anymore and it also contains a small bug. It should be removed.
