Title

Lazy relations and Query Builder join

Description
When using the query builder's `leftJoinAndSelect` with lazy relations (defined with `Promise `), the relation does not get added to the result as a "regular" property. The actual data can be found at the double-underscore key (ex. `__room__` instead of `room`). The async accessor is still attached.

This means that accessing a lazy relation that was fetched eagerly using `leftJoinAndSelect` will actually fetch the data twice. This leads to a lot of unnecessary queries when the result list is already long.

```
ts
const x = await getRepository(Share)
    .createQueryBuilder("share")
    .leftJoinAndSelect("share.room", "room")
    .getMany()
... [Log Snipped] ...
console.log(await x[0].room)
// → SELECT [...etc.] FROM "room" "room" INNER JOIN "share" "Share" ON "Share"."roomId" = "room"."id" WHERE "room"."id" = $1
```

**Expected behaviour:**
When a relation is defined as lazy and is fetched eagerly using the query builder, existing data should be used and no additional SQL query should be made.

**Typeorm version:** 0.1.0-alpha.50
