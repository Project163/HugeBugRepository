Title

Globally override return type for a method based on argument value

Description
### Problem
```
UndefinedInterfaceMethod
Symfony\Component\Console\Helper\HelperInterface::ask does not exist (see [URL]
$answer= $this->getHelper('question')->ask($input, $output, $question);
```
### Workaround
I know, it can be handled like follows, but it is a bit annoying and makes the code too verbose.
```php
/** @var \Symfony\Component\Console\Helper\QuestionHelper $helper */
$helper = $this->getHelper('question');
$answer = $helper->ask($input, $output, $question);
```
