Title

Set CXF SoapAction header correctly

Description
As of  CXF-6732 , CXF will by default always  set  the SoapAction header with the value found at key SoapBindingConstants.SOAP_ACTION. See  comment  for more details. Workaround can be either adding a custom CXF OutInterceptor or use a different Camel/CXF binding.
