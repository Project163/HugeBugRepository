Title

[YSQL][Upgrade] Replacing system view is not filtering out upgrade-specific options

Description
### Description

View reloption `use_initdb_acl` exists as a YSQL upgrade helper for views, it should be removed from the reloptions before persisting.
However, when doing `CREATE OR REPLACE VIEW`, only the `CREATE` part does the filtering.
Example:
```
sql
SET ysql_upgrade_mode TO true;
SET yb_test_system_catalogs_creation TO true;
CREATE OR REPLACE VIEW pg_catalog.test_view WITH (use_initdb_acl = true) AS SELECT 1;
SELECT oid, relname, reloptions FROM pg_class WHERE relname = 'test_view';
... [Log Snipped] ...
--  13283 | test_view | {use_initdb_acl=true}
-- (1 row)
```
