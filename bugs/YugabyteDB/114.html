Title

[YSQL] TEXT, VARCHAR, and CHAR Types Not Serialized Properly

Description
Test case:
```
CREATE TABLE tab(char_col CHAR[10] PRIMARY KEY, int_col INTEGER);
INSERT INTO tab VALUES('one', 1);
INSERT INTO tab VALUES('two', 2);
INSERT INTO tab VALUES('three', 3);
## Insert as many rows as needed
SELECT * FROM tab WHERE char_col = 'two';
```

When passing data to PostgreSQL engine to process, YugaByte doesn't serialize the values properly for character-based datatypes. Currently, we use BINARY FunctionOID for these types while each of these types actually has its own FuncOID for this task.

To fix this bug, when preparing fields to read from YugaByte, we need to setup the appropriate function pointer (FuncOID) to do the serialization as it is not one FuncOID fits all character types.
