Title

has_many-through-join-model record is incomplete in `after_add` and `before_add` callbacks

Description
With a `has_many` association defined with a `through` option, the callbacks `before_add` and `after_add` of the join model are called with incomplete data. The second argument is missing the target reference.

This is a problem when one of these callbacks causes the owner object to be saved - the DB raises a not-null constraint violation. I was able to work around this in our code by defining my callbacks on the `has_many` association, but I still think the behavior is confusing.

From a quick debug session, the culprit seems to be 
[Link: `ActiveRecord::Associations::HasManyThroughAssociation#build_through_record`]. Here, `through_association.build` triggers the callback, but only after that the source record is set. Not sure if including it in `options_for_through_record` would be a possible fix?

### Steps to reproduce

```
ruby
# frozen_string_literal: true

begin
  require "bundler/inline"
... [Log Snipped] ...
# This produces the expected output:
# consultant.consultants_purposes.create(purpose: Purpose.create!)
```

### Expected behavior
The output should include both a valid `consultant_id` and `purpose_id`, for example:
```
--------------------------------------------------------------------------------
{"consultant_id"=>1, "purpose_id"=>1}
--------------------------------------------------------------------------------
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
{"consultant_id"=>1, "purpose_id"=>1}
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
```

### Actual behavior
The `purpose_id` in the output is `nil`:
```
--------------------------------------------------------------------------------
{"consultant_id"=>1, "purpose_id"=>nil}
--------------------------------------------------------------------------------
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
{"consultant_id"=>1, "purpose_id"=>nil}
+++++++++++++++++++
