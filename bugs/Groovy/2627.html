Title

The type checker disallows the Outer.this notation

Description
This code fails compilation because the type checker disallows the  Outer.this  notation inside a non-static inner class: 

  
  class  Outer {
     int  x
     class  Inner {
         int  foo() { 2*Outer. this .x }
    }
     int  bar() {
         new  Inner().foo()
    }
}
