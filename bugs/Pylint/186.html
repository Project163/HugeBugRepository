Title

logging-format-interpolation: too aggressive

Description
Originally reported by: **BitBucket: [Link: sam-s], GitHub: @sam-s?**

---

I get this warning:

```
(W1202, logging-format-interpolation, my_func) Use % formatting in logging functions but pass the % parameters as arguments
```

when `my_func` does something like

```
logger.info("Read {l:,d} rows".format(l=n))
```

note that this is _not_ equivalent to 

```
logger.info("Read %d rows",n)
```

because `%d` does not insert commas as in `123,456,789`.
I suggest that this warning is only retained for `%` conversions, e.g.:

```
logger.info("Read %d rows" % (n))
```

but _not_ for `"...".format()`.
