Title

Ignoring value changed in loop

Description
### Problem summary

When defining a variable using a ternary (i.e. value is not known certainly) PhpStan does not take into account later modification of the variable value (like increment or decrement) in a loop.

So when we check for the value of the variable with a `if` PhpStan throws a
`Strict comparison using === between 0 and 2|3 will always evaluate to false.`
