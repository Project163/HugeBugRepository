Title

Catch System.import()

Description
Hi! I'm trying to import a dynamic module with `Sytem.import` and it works nicely, but when I'm passing a wrong path it does not trigger `catch`.
Code example:

```
System.import(`locales/${lang}/translation.json`)
    .then(data => {
        console.log(data);
    })
    .catch(err => {
        console.error(err); // this line is never executed
    });
```

Am I doing something wrong?

Thanks.
