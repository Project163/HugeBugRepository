Title

Unit test always succeeds in combination with hibernate-reactive & panache

Description
### Describe the bug

I experience an unwanted behaviour in unit testing with assertions.
I've set up a fresh app via [URL]
and followed the guide on [URL]
My written unit test should/must fail but succeeds nevertheless.

The following dependencies are installed for the app:
```
// Quarkus
implementation(enforcedPlatform("${quarkusPlatformGroupId}:${quarkusPlatformArtifactId}:${quarkusPlatformVersion}"))
implementation("io.quarkus:quarkus-arc")
testImplementation("io.quarkus:quarkus-junit5")
// Flyway
... [Log Snipped] ...
implementation("io.quarkus:quarkus-reactive-pg-client")
testImplementation("io.quarkus:quarkus-test-hibernate-reactive-panache")
```

### Expected behavior

final Animal animal = new Animal();
animal.name = "danger noodle";
asserter.execute(() -> animal.persist());
asserter.assertEquals(() -> Animal.count(), 2L); // Should already fail here!
asserter.execute(() -> Animal.deleteAll());
asserter.fail(); // Must definitely fail here!

### Actual behavior

Unit test always succeeds, even if I intentionally write a broken test.

Discussion
- I'm not sure I can fix it, but I will have a look and see if I can pinpoint the issue
- Thank you for your fast reply! I figured out a work around by implementing an `UniAsserterInterceptor` and assign the interceptor in the beginning of each test method: `asserter = new PanacheTransactionalAsserter(asserter);`

```
public final class PanacheTransactionalAsserter extends UniAsserterInterceptor {

  public PanacheTransactionalAsserter(UniAsserter asserter) {
    super(asserter);
  }
... [Log Snipped] ...
  }
}
```

This way, the intentionally broken tests are failing as expected.
What makes me wonder is that my own implementation does the same as `io.quarkus.test.hibernate.reactive.panache.TransactionalUniAsserter`.

My best guess is that it has to do with when the interceptor gets created (build/run time)?

Thanks for looking into this!
- I think I've found the bug, I will try to fix it
