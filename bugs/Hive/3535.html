Title

desc database and show tables commands don't pass db to HiveAuthorizer check

Description
'show tables' and 'describe database' command should pass the database information for the command to HiveAuthorizer . This is needed for any auditing the hive authorizer might implement, or any authorization check it might decide to do based on the given database name.
