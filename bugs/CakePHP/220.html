Title

Model::bindModel removes associations

Description
If you bind a model on-the-fly and execute a query then the related model losses its associations. 

Below is an unit test failing because of this issue. You should use two models with the following requirements:
- Comment belongs to Post
- Post has 1+ belongsTo relationship(s)

Running on Cake 2.5.6

```
php
public function testBindModel()
{
    // Model 1 belongs to Model2
    $model_alias = 'Comment';

}
```

Is it the intended behavior?
Discussion
- This is expected behavior. By default association bound on the fly are reset after a find call. Set the second param to `bindModel()` to false if you want to prevent that.
- You mean the expected behavior is that the association of both models are reset after the find call?

- The issue is that temporary bindings and contain do not work well together. They both manipulate the same keys and the 'temporary' bindings that you set, are then made permanent by 'containable' as it too modifies the associations temporarily. I don't think there is a reasonable way to fix this as containable is just an abstraction around bindModel().
