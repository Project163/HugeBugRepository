Title

Add getOrStart method to ignition

Description
Currently there is no way to atomically check if an Ignite instance with the given name is started and start it, if it was not started.
Discussion
- Probably we should add boolean parameter like  failIfStarted  to  IgnitionEx.start0() . If the flag is true (default) then everything will work as presently. Otherwise an existed (old) instance should be returned. 

 Tests has to be added as well to validate the functionality.
