Title

[YCQL] Binding value to UNSET(-2) should not cause an error

Description
Jira Link: [Link: DB-1882]
Please refer to [URL]

Binding a value to unset is a valid way to bind when you dont want to change a column's value while using a single prepared statement to bulk load several rows of sparse data according to the  CQL spec (https://git-wip-us.apache.org/repos/asf?p=cassandra.git;a=blob_plain;f=doc/native_protocol_v4.spec)

```   
 [value]        A [int] n, followed by n bytes if n >= 0.
                   If n == -1 no byte should follow and the value represented is `null`.
                   If n == -2 no byte should follow and the value represented is
                   `not set` not resulting in any change to the existing value.
                   n < -2 is an invalid value and results in an error.
```

The current implementation returns an error

```
com.datastax.ycql3.shaded.driver.core.exceptions.InvalidQueryException: Invalid Request. Bind variable was not set
```
