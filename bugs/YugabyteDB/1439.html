Title

[DocDB] The check in RBS should have been a warn instead of a fatal

Description
Jira Link: [Link: DB-18540]
### Description

The check in RBS should  have been a warn instead of a fatal, as it is a result of network issue between nodes. RBS failures are retried, there is no need to crash the TServer for these types of issues.

```
The FATAL looks like it's coming from the CHECK here:
  for (const string& session_id : expired_session_ids) {
    LOG(INFO) << "Remote Bootstrap Log Anchor session " << session_id
              << " has expired. Terminating session.";
    RemoteBootstrapErrorPB::Code app_error;
    CHECK_OK(DoEndLogAnchorSession(session_id, &app_error));
    RemoveLogAnchorSession(session_id);
  }
```
