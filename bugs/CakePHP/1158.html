Title

Time validation fails with Time object

Description
### Description

# How to reproduce
```php
use Cake\I18n\Time;
use Cake\Validation\Validator;
...
$v = new Validator();
$v->time('start_time');
$ret = $v->validate(['start_time' => new Time()]);
debug($ret);
```

outputs
```
[
  'start_time' => [
    'time' => 'The provided value must be a time'
  ]
]
```

# Expected behavior
No validation errors, i.e. `debug($ret)` to output an empty array.

# Notes
No validation errors would be symmetric to how `->date()` and `->dateTime()` validations work.
```php
$v = new Validator();

$v->date('start_time');
$ret = $v->validate(['start_time' => new Date()]); // empty array

$v->dateTime('start_time');
$ret = $v->validate(['start_time' => new DateTime()]); // empty array
```

### CakePHP Version

5.0.5

### PHP Version

8.1.17
Discussion

In CakePHP 4.4.17, `FrozenTime` inherits/implements I18nDateTimeInterface -> ChronosInterface -> DateTimeInterface .

In CakePHP 5.0.5, `Time` inherits/implements ChronosTime .
