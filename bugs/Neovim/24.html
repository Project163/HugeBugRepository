Title

Double click on quickfix item sets `":` register.

Description
- `nvim --version`:
0.1.7
- Vim (version: ) behaves differently?
8.0 NO, same problem

### Actual behaviour
Double clicking on a quickfix or location list item with the mouse moves to that position as expected, but also sets the command register to `.cc` or `.ll` respectively.

### Expected behaviour
The command register `":` should not be changed

### Steps to reproduce using `nvim -u NONE`

```
nvim -u NONE src/nvim/undo.c
:vimgrep ls %
:copen
 
:registers
```

Observe that the ": register is currently `.cc`.

# Cause
This is because of how the double click action is implemented.
In `normal.c:2983` you see that it's implemented by stuffing `readbuf1` with an ex command, this is treated as user input and hence the ex command is stored in the `":` register.
