Title

AMD require with three arguments (3rd is errback) is not parsed in webpack 2

Description
**Issue type:**
- [x] bug report

**Webpack version:**
2.1.0-beta.13

**Please tell us about your environment:**
OSX 10.11.4

**Current behavior:**

AMD require with three arguments, where the third is an errback fails with a `require function is used in a way in which dependencies cannot be statically extracted` message. `System.import` supports this behavior.

**Expected/desired behavior:**

AMD require errback function is supported.

**Repro:**

``` js
define(function() {
  require(['remote'], function() {
    console.log('loaded');
  }, function(err) {
    console.error('error handled');
  });
});
```

will return:

```
require function is used in a way in which dependencies cannot be statically extracted
```

``` js
define(function() {
  System.import('remote').then(function() {
    console.log('loaded');
  }, function(err) {
    console.error('error handled');
  });
});
```

will work as expected.
- **Browser:** [all] 
- **Language:** [all]
