Title

Cleanup on live reload also removes generated classes

Description
**Describe the bug**
Generated classes are removed during live reload.

**Expected behavior**
Generated classes are not deleted.

**To Reproduce**
Steps to reproduce the behavior:
1. `git clone [URL]
2. `mvn install`
3. `ll target/classes/views` ->  `HostingPage.class`
4. `mvn quarkus:dev` (+ `mvn install` + F5 on `[URL]
5. `ll target/classes/views` ->  `HostingPage.class` deleted

**Environment:**
 - Output of `java -version`: 1.8
 - Quarkus version or git rev: 0.20.0
Discussion
- Hi, we are using Rocker as a compile time replacement for some old JSPs, with this issue all generated Rocker classes are deleted during development.

As a quick fix we copy/pasted them, does exist a switch to disable this feature until is fixed ?
- An additional workaround is to launch “mvn compile quarkus:dev” instead of “quarkus:dev” only, after configuring pom.xml with build helper plugin:

