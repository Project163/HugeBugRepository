Title

aggregate_order_by() returns list of characters rather than list of ENUM fields

Description
**Describe the bug**
I am using `array_agg` to return a list of ENUM types, in the example below a list of actions.  To order that list I then add `postgresql.aggregate_order_by`.  However this change results in unexpected and bad behaviour, that I think is a bug.  Instead of returning a list of ENUM actions it returns a list of characters

**Expected behavior**
Both methods below should return the same format (maybe not the same order)

py
from enum import Enum
from sqlalchemy.ext.declarative import declarative_base
