Title

"@const @private" works, but "@private @const" does not

Description
What steps will reproduce the problem? 
Compile e.g:
goog.provide('foo.MyClass');

/** @constructor */
foo.MyClass = function() {
  /** @private @const {number} */
  this.foo_ = 42;

  this.foo_ = 36;
};


 What is the expected output? What do you see instead? 
Expected: Warning about constant foo_ being assigned a value twice.
Actual: No warning.


 What version of the product are you using? On what operating system? 
jscomp-debug


 Please provide any additional information below. 
It does work when the order of the two annotations is switched (i.e. "@const @private {number}").
Discussion
- Looking into this a little bit, after the parser consumes the '@private' it calls recordDescription, so the entire string "@const {number}" is being parsed as a description for the "@private" annotation, rather than as a @const annotation with a type. The logic in extractMultilineTextualBlock knows to stop when it sees an annotation (like @const) but it consumes an entire line before that logic kicks in: [URL]

I guess that's left over from when annotations were not stackable (each one had to be on its own line)?
