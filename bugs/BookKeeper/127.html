Title

We run with preferIPv4Stack in the scripts but not in the tests

Description
Bookkeeper doesn't work with IPv6, but if it's enabled, java will try to use it. We get around this by setting the java.net.preferIPv4Stack in the startup scripts but we don't set it for the tests.
