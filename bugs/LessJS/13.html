Title

Less 1.3.0 compiling removes "0/0"

Description
HTML5 boilerplate's [Link: image replacement] technique uses the following declaration:

``` css
font: 0/0 a;
```

Since I upgraded to Codekit 1.2.3 Less compiles this into

``` css
font: a;
```

resulting into elements with width and height, which is obviously unwanted behaviour. As a workaround I 'escaped' the value by adding ~"". 

Although it seems Less v1.3.0 is used, the developer from Codekit told me that there was a newer build of Less v1.3.0 released and included.

See [Link: my bugreport] for more details.
