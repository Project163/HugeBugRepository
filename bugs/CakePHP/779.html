Title

Pagination count() fails when using group (and is wrong for distinct)

Description
This is a (multiple allowed):
- [x] bug
- [ ] enhancement
- [ ] feature-discussion (RFC)
- CakePHP Version: 3.2.5
- Platform and Target: WAMP - PHP 5.5.12
### What you did

Using pagination with leftJoinWith() and bind() where the conditions affect both tables. If using DISTINCT the pagination count() returns the non-distinct value (i.e. count(*)) which is incorrect for the actual non-count query performed, but switching to using `paginate['group']` causes a Fatal error. 

When debug is enabled it reports:

Code when using paginate and group:

```
$query = $this  ->Products
    ->find("all")
    ->leftJoinWith('Pim1')
    ->select($this->Products);
$this->paginate['group'] = "Products.id";
... [Log Snipped] ...
$products = $this->paginate($query);
$this->set(compact('products'));
```

`debug($query)` outputs:

```
object(Cake\ORM\Query) {

    '(help)' => 'This is a Query object, to get the results execute or iterate it.',
    'sql' => 'SELECT Products.id AS `Products__id`, Products.code AS `Products__code`, Products.title AS `Products__title`, Products.uom AS `Products__uom`, Products.lev1 AS `Products__lev1`, Products.lev2 AS `Products__lev2`, Products.lev3 AS `Products__lev3`, Products.lev1a AS `Products__lev1a`, Products.lev2a AS `Products__lev2a`, Products.lev3a AS `Products__lev3a`, MATCH(Products.code, Products.title) AGAINST(:search IN BOOLEAN MODE) AS `relevance` FROM products Products LEFT JOIN pim1 Pim1 ON Products.id = (Pim1.product_id) WHERE (MATCH(Pim1.value) AGAINST(:search IN BOOLEAN MODE) OR MATCH(Products.code, Products.title) AGAINST(:search IN BOOLEAN MODE))',
    'params' => [
... [Log Snipped] ...

}
```
### Expected Behavior

Not to get a fatal error.
For the query to be considered 'complex' and the values bound and counted as per the original query, much like the non-group query is, except that one doesn't do a distinct count.
### Actual Behavior

Fatal error in debug mode
Friendly fatal error when not in debug mode
