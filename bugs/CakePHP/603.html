Title

3.0 - Schema defaultValues() ignores null default

Description
In [Link: Cake\Database\Schema\Table] when calling `defaultValues()` it runs an `isset()` check for the default key. If the schema default is `null` this will not add it to the returned array. I'm not sure if this was intended or if it will mess with other database schemas. It's just something I noticed when trying to get a list of the field defaults. This is what I used in my behavior to work around it.

```
php
public function defaultValues() {
    $defaults = [];
    foreach ($this->_columns as $name => $data) {
        $defaultIsNull = ($data['default'] === null && $data['null'] === true);
... [Log Snipped] ...
    return $defaults;
}
```
