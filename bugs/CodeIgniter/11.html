Title

join trim '[' in the on clause

Description
{{{
# !php

$querry = $this->db
    ->select( '[a]' )
    ->from( '[A]' )
    ->join( '[B]', '[A].[a] = [B].[b]' );

die($this->db->_compile_select());
}}}

Result: 
{{{
# !sql

SELECT [a] FROM [A] JOIN [B] ON A].[a] = [B].[b]
}}}

Expected:
{{{
# !sql

SELECT [a] FROM [A] JOIN [B] ON [A].[a] = [B].[b]
}}}

Thanks,
Guillaume
