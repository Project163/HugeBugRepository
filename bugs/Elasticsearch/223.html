Title

Script sorting doesn't accept parameters

Description
Hiya

There is a bug when providing params to a script sort.  Depending on the position of the `params` parameter in the JSON, you get 2 different error messages:

```
curl -XPUT '[URL] 
curl -XPOST '[URL]  -d '
{
   "text" : "foo"
}
'
```
