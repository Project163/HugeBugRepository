Title

Marshalling Chronos Date into Datetime Field leads to Deprecation

Description
### Description

CakePHP 4.4.12
CakePHP Chronos 2.4.4

Because `ChronosDate` implements the `DateTimeInterfacce` because it extends `DateTimeImmutable` [URL] and `DateTimeImmutable` implements `DateTimeInterface` [URL]

It also uses the `FrozenTimeTrait` [URL]

When one tries to marshall a `ChronosDate` (or Chronos previous `Date`) into a Datetime field, the `DateTimeType` tries to set the timezone on it [URL] which leads to a  `2.5 setTimezone() will be removed in 3.x.` deprecation message in the aforementioned `FrozenTimeTrait` [URL]

The related workaround [URL] from @markstory does not apply here, as it is neither a PHPUnit `Assertion` nor an `IsEqual` comparison.

If possible, I think it would be best not to set the timezone on the `$value` in `DateTimeType::marshall()` when it is a `ChronosDaate`.

### CakePHP Version

4.4.12
