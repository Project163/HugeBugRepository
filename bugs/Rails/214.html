Title

preventing_writes? doesn't work in test environment

Description
### Steps to reproduce

1. Turn off `ActiveRecord::Base.legacy_connection_handling`
2. Use `ApplicationRecord.connects_to()`
3. include `ActiveRecord::TestFixtures`
4. Create record from inside `ApplicationRecord.connected_to(role: :reading)` block. 

[URL]

### Expected behavior

raise `ActiveRecord::ReadOnlyError`.

### Actual behavior

Nothing was raised.

### System configuration
**Rails version**: 6.1.0.rc1

**Ruby version**: 2.7.1

---

I think that the cause is  that `#replica?` now returns false because of `ActiveRecord::TestFixtures` overwritten the pool config for reading.

`preventing_writes?` checks `replica?` at the first.
[URL]

`ActiveRecord::TestFixtures` removes `replica: true` option by overwriting pool config.
