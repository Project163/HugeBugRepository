Title

3.2: FrozenTime + toRss()

Description
After updating to 3.2, I have this problem with the rss.

This is my code:

```
echo $this->Rss->item([], [
    'description'   => $text,
    'guid'          => ['url' => $link, 'isPermaLink' => 'true'],
    'link'          => $link,
    'pubDate'       => $post->created,
    'title'         => $post->title
]);
```

And `post->created` contains this:

```
object(Cake\I18n\FrozenTime) {
    'time' => '2016-01-30T11:01:00+00:00',
    'timezone' => 'UTC',
    'fixedNowTime' => false
}
```

As you know, CakePHP will automatically call the `TimeHelper::toRss()` method to generate the RSS feed. And I have this exception:

Can you help me understand what is the problem?

This code works fine:

```
    $frozen = new \Cake\I18n\FrozenTime();
    debug($frozen);
    debug($this->Time->toRss($frozen));
```
Discussion
- This works:

`$post->created->toUnixString()`

So:

```
echo $this->Rss->item([], [
    'description'   => $text,
    'guid'          => ['url' => $link, 'isPermaLink' => 'true'],
    'link'          => $link,
    'pubDate'       => $post->created->toUnixString(),
    'title'         => $post->title
]);
```
