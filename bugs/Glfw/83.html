Title

glfwSwapBuffers requires current EGLContext

Description
Documentation says that only these functions need active context:
- glfwSwapInterval
- glfwExtensionSupported
- glfwGetProcAddress

But both EGL 1.4 (3.9.3. Posting Semantics) and EGL 1.5 (3.10.3. Posting Semantics) say:

```
surface must be bound to the calling thread’s current context, for the current rendering
API
```

Without active context, we see black screen.

`eglSwapBuffers` returns `EGL_FALSE` in this case.
