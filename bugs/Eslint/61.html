Title

Semicolon rule misses return statements

Description
The following will not be flagged by the `semi` rule:

``` js
function foo() { 
    return []
}
```

JSHint and JSLint both flag the `return` statement as missing a semicolon, so should we.
Discussion
- How about `break`, `continue`, `debugger`, and `let`?
- Good call. `let` is already covered by `VariableDeclaration`. I'll add the others.
