Title

Node version sometimes empty in _cat/nodes

Description
Sometimes a node will not list its version in `_cat/nodes`.

```
drewr@client-002 Thu 20 17:04:28 30 0 ~()% curl localhost:9200/_cat/nodes\?h=host,ip,name,version,jvm
data-001     Nick Fury      1.0.1
client-001   Melody Guthrie
client-002    Nightwind      1.0.1
```

`client-001` has the same version of ES:

```
drewr@client-002 Thu 20 17:04:31 31 0 ~()% curl -s client-001:9200
{
  "status" : 200,
  "name" : "Melody Guthrie",
  "version" : {
... [Log Snipped] ...
  "tagline" : "You Know, for Search"
}
```
Discussion
- I can't reproduce this - version always comes back. What I never get back is a value for "jvm" though. EDIT: which is apparently because there's no such value..
- @drewr  do you have a fix for this?
- this can happen if the node is in the cluster state, but not yet visible across the cluster, @drewr did it happen on startup, or shutdown of a node?
- ok, this might happen, but we can still get the version from the `DiscoveryNode` instead from the nodes info response, I will push a fix
