Title

canvas_camera_orthographic2 example typo?

Description
In the repo, the constructor in CombinedCamera.js takes 7 parameters:

``` javascript
THREE.CombinedCamera = function ( width, height, fov, near, far, orthoNear, orthoFar ) {  // 7
//stuff
}
```

But in the canvas_camera_orthographic2 example it's used like this (though it works for me):

``` javascript
camera = new THREE.CombinedCamera( window.innerWidth /2, window.innerHeight/2, 70, 1, 1000, -1000, 1000, 1000 ); //8
```

The 8th parameter is a typo, right?
Discussion
- Seems like, yes. Though I've yet to use this method (or see someone using it), chances are I'll be moving it out of the lib this cycle...
- Ok, I decided to just use a regular orthographic camera for what I want to do.

I think a combined camera class can be convenient. Such as in a model viewer. Or similar to Blender, where you can hit Numpad 5 to switch between orthographic and perspective views.
