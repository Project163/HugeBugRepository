Title

curl hangs on SMB upload over stdin

Description
### I did this
```sh
 cat test.txt | curl -T . smb://user:password@localhost/share/test.txt
```
This creates empty test.txt file on smb share and then curl hangs
Tried both Windows and Linux smb shares. Tried several curl versions on alpine, centos, ubuntu, but getting same issue.
### I expected the following
test.txt copied to smb share
Issue occurs only if piping file from stdin. Command like below works as expected
 ```sh
curl -T test.txt smb://user:password@localhost/share/test.txt
```

- My guess would be that curl needs to know the final file size before creating the file via SMB, therefore dynamic input from `stdin` may not be supported.
