Title

cargo registry - Renamed dependencies does not get renamed

Description
### Description

When publishing a crate with a renamed dependency
```
toml
# Cargo.toml

[package]
name = "rename_deps"
... [Log Snipped] ...
[dependencies]
embedded-hal-0-2 = { package = "embedded-hal", version = "0.2.7" } # <-- embedded-hal renamed to embedded-hal-0-2
```

The registry does not reflect the fact that the dependency is renamed `[URL]

```json
{"name":"rename_deps","vers":"0.1.2","deps":[{"name":"embedded-hal","req":"^0.2.7","features":[],"optional":false,"default_features":true,"target":null,"kind":"normal","registry":"[URL]
```

Same thing formatted:
```
json
{
    "name": "rename_deps",
    "vers": "0.1.2",
    "deps": [
... [Log Snipped] ...
    "yanked": false
}
```

I posted the same issue in rust-lang/cargo#14148 leading me here. I have not tried this on demo.gitea.com
