Title

SDK Harness should populate worker id in RPC headers

Description
The SDK harness currently does nothing to populate control plane headers with the harness worker id. This id is necessary in order to identify harnesses when multiple are run from the same runner server. 

 Note that this affects the  SDK  harness specifically (e.g., when running a local process or in-memory harness).
