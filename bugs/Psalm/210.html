Title

Variables from fallthrough case statements are not treated as possibly defined

Description
It's possibly undefined here, and isset is used

Aside: Is there a way to force psalm to create the variable if `isset` is true?

```

    
Discussion

    
- This is a hard one to fix currently, aside from just disabling the new feature (`isset` impossible vars in function scopes).

Switch case statements are currently evaluated bottom up, which simplifies most logic. I could  evaluate them top down, wrapping each unbroken case in a fake `if`.
- So we should transform

```
php
switch(rand() % 4) {
    case 0:
        echo "here";
        break;
... [Log Snipped] ...
        break;
}
```
to
```
php
switch(rand() % 4) {
    case 0:
        echo "here";
        break;
... [Log Snipped] ...
        break;
}
```
