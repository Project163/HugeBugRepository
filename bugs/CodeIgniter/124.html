Title

Image library

Description
Have these issues when upgraded from 2.2.4 to 3.1.2
image_lib.php has issues. 
line 889
$cmd .= escapeshellarg($this->full_src_path).' '.escapeshellarg($this->full_dst_path).' 2>&1';
need to add space in front of it otherwise compiled command is wrong
as such 
$cmd .= ' '.escapeshellarg($this->full_src_path).' '.escapeshellarg($this->full_dst_path).' 2>&1';

also this library in general has problem
when used config for image processing 
i.e.
$config['source_image']	= './folder/path/'.$upload_info['file_name'];
$config['new_image'] ='./folder/path/'.$upload_info['file_name'];
compiles the $this->full_scr_path & $this->full_dst_path in the image_lib.php in initialise correctly in earlier version
but in latest version for above conf the path compile as 

$this->full_scr_path = correct absolute path converted and set here
$this->full_dst_path = incorrect absolute path i.e exact value of './folder/path/'.$upload_info['file_name']; which no good thus resulting in wrong commands

so had to modify them to 
$config['source_image']	='./folder/path/'.$upload_info['file_name'];
$config['new_image'] = FCPATH.'./folder/path/'.$upload_info['file_name']; which is inconsistent with the docs

**so two problems namely,**
1. space issue
2. relative directory not set properly in full_dst_path when used new_image config varible
