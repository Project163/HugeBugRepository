Title

Binding data to the document causes d3.select to bind data.

Description
Binding data to the document directly subsequently causes that data to be bound to any element selected with d3.select:

``` js
document.__data__ = 42;
d3.select("body").datum(); // 42
```

Data propagation should be limited to selection.select and not apply to d3.select.
Discussion
- Fixed in 3.1.6.
