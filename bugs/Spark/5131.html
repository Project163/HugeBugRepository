Title

Incorrect executor request in case of dynamic allocation

Description
killExecutor api currently does not allow killing an executor without updating the total number of executors needed. In case of dynamic allocation is turned on and the allocator tries to kill an executor, the scheduler reduces the total number of executors needed ( see  [URL] which is incorrect because the allocator already takes care of setting the required number of executors itself.
