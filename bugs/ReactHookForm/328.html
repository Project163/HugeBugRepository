Title

issue: Uncontrolled disabled checkbox assigned the wrong defaultChecked

Description
### Version Number

7.28.0

### Codesandbox/Expo snack

[URL]

### Steps to reproduce

1. Go to [Link: CSB]
2. See the second checkbox looks unchecked despite `defaultChecked: true`

There seems to be a particular combination of conditions that cause the issue:
- The "problematic" checkbox **has to have sibling checkboxes** in a group and **has to be disabled**
- The first checkbox **can have `defaultChecked` `true` or `false`** but **has to be not disabled**
- The last checkbox **has to have `defaultChecked: false`** and **can be either enabled or disabled**

For more context see #8049

### Expected behaviour

Disabled checkbox with `defaultChecked: true` is checked

### What browsers are you seeing the problem on?

Firefox, Chrome
