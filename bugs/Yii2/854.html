Title

Validator attribute problem since version 2.0.17

Description
[Image: image]

### What steps will reproduce the problem?

We are creating a dynamic model and use the ActiveForm widget afterwards to render the model, this seems to throw the above error since version 2.0.17, with version 2.0.16 it works.

```php
$model = new DynamicModel();
foreach ($organisation->properties as $prop) {
            $model->defineAttribute($prop->id);
            $model->addRule([$prop->id], SafeValidator::class);
            $model->{$prop->id} = ApiOrganisationPropertyValue::getValue($prop, $this->attachedContext);
}
```

Now using ActiveForm for the generate dynamic model throws the warning above (screenshot).

```php
 field($model, $vp->id);
```

(i made a check on the `$model` to see if the attribute exists - yes it does. via `$model->hasAttribute($vp->id)`)

### What is the expected result?
