Title

testdox="true" configuration setting not honored

Description
| Q                   | A
| --------------------| ---------------
| PHPUnit version     | 10.0-dev
| PHP version         | 8.1.14 and 8.2.1
| Installation Method | Composer v2.5.1 (2022-12-22)

#### Summary

When `testdox="true"` is set in the `phpunit.xml`, PHPUnit does not honor it and instead shows the dot output.

This happens *after* running `phpunit --migrate-configuration`.

```
xml
 
 
```

#### Current behavior

```
PHPUnit 10.0-dev by Sebastian Bergmann and contributors.

Runtime:       PHP 8.2.1
Configuration: /workdir/phpunit.xml

...........................                                       27 / 27 (100%)

Time: 00:00.028, Memory: 8.00 MB
```
#### How to reproduce

Add `testdox="true"` to the `phpunit.xml` in the ` ` tag.

#### Expected behavior

The same as PHPUnit 9.*:

```
PHPUnit 9.6-dev by Sebastian Bergmann and contributors.

HTTPSpeaker (PHPExperts\RESTSpeaker\Tests\HTTPSpeaker)
 ✔ Works as a Guzzle proxy
 ✔ Identifies as its own user agent
... [Log Snipped] ...

Time: 00:00.008, Memory: 6.00 MB
```

```
git clone [URL]
cd RESTSpeaker

```
