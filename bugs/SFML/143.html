Title

Unicode Support within SFML

Description
Every C++ dev will agree that unicode support for C++ is a pain, inconsistent across platforms and non-trivial to get right.

SFML has places where proper unicode support is lacking. This issue serves as a catch-all for this topic, so we can more easily see what has been fixed and what remains open.
