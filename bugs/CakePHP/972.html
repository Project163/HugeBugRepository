Title

Description

### What you did
I'm trying to make usage of the standalone Cakephp packages such as utility, core, etc. to be able to start migrating an application to latest version of cake. I just notice Cake\Core uses Cake\Cache but it's composer.json doesn't require it.
Discussion
- if you only use `Cake\Core\Configure`  , yes it require it.
- We could add `cakephp/cache` to the suggest list for if/when someone wants to use cached configuration files.
- Pull request up to add the suggest and more helpful runtime errors for if/when the dependency is missing.
