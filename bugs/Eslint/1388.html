Title

[6.7] running eslint through npm script throws error.

Description
I don't experience the issue when using eslint v6.6.x.

I have the following script in my package.json:

```javascript
  "scripts": {
    "lint": "eslint ."
  },
```

If I run `eslint .` directly in the console it works correctly, but when I run `npm run lint`, it throws an error. It seems like it's using the wrong config?

```
ESLint: 6.7.1.

ESLint couldn't find the config "adpyke-es6" to extend from. Please check that the name of the config is correct.

The config "adpyke-es6" was referenced from the config file in "C:\Users\pykea\.eslintrc".

If you still have problems, please stop by [URL] to chat with the team.
```

- **Side note:** As you may know, [Link: we have deprecated the config files in HOME directory]. The error of this issue looks like thrown from unused config files in HOME directory (because it should not work since ESLint 6.0.0, I guess that you have not used it while a time), therefore I'd like to recommend to remove it.
- You can replace
```json
  "scripts": {
    "lint": "eslint ."
  }
```

by
```json
  "scripts": {
    "lint": "eslint $(pwd)/."
  }
```
