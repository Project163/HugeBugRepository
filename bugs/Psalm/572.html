Title

False Positive UndefinedInterfaceMethod

Description
Why would calling an interface method called in a constructor be marked as `ERROR: UndefinedInterfaceMethod - 37:23 - Method ShapeInterface::something does not exist`

[URL]

Calling the same interface method from a method does not error.
Discussion
- Short answer: it's a bug. Slightly longer answer: Psalm calls the parent constructor when checking that `$this->shape` is set before it's used, and it seems to forget the type of the passed-in interface, using instead the parent param type.
- We all forget stuff sometimes... cheers
- The solution was just to suppress the error during the property initialisation checks (it'd still be caught on the first run).
