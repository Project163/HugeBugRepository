Title

Build fails for java 1.7 after adding java.math.BigInteger support [SPARK-11827][SQL]

Description
Hi, 
I am building branch-2.0. The build fails with this message: 
  
 [error] spark/sql/catalyst/src/main/scala/org/apache/spark/sql/types/Decimal.scala:137: value longValueExact is not a member of java.math.BigInteger
[error]        this .longVal = bigintval.longValueExact()
[error]                                ^
[error] one error found
 
  
 This seems to be a problem with java versions. In java 1.7 there is no method java.math.BigInteger.longValueExact(). 

 A quick fix is changing longValueExact() to longValue()
