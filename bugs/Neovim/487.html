Title

Cursorline position jumps between two positions when scrolling down when scrolloff is half the window height

Description
### Neovim version (nvim -v)

NVIM v0.7.0
NVIM v0.8.0-dev+78-g7df25a137

### Vim (not Nvim) behaves the same?

Yes

### Operating system/version

Windows 10

### Terminal name/version

Cmder 1.3.18.1106

### $TERM environment variable

N/A

### Installation

Scoop

### How to reproduce the issue

```
nvim --clean
:help (or open any other file, that is big enough to experience the problem)
:set relativenumber number (optional, useful for diagnose)
:set scrolloff=3
:resize 6
jjjjjjj (hold j or press it several times)
```

### Expected behavior

Cursorline position should be static and not flicker between two positions when scrolling down.

### Actual behavior

When scrolling down and if `scrolloff` is set to exactly half the amount of lines visible in the window then the number of lines before cursorline alternates between number of lines set by `scrolloff` and `scrolloff - 1`.
