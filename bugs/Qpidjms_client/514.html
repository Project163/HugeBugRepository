Title

Java Examples Drain/Spout assume virtualhost named test

Description
The Java version of Drain and Spout assume that the Broker has virtualhost named 'test'. 

 Since   QPID-4743  , the Java Broker no longer ships with a virtualhost named 'test', so any attempts to use Drain/Spout against a Broker in as-shipped state fails. 

 Drain/Spout should be changed to pass no virtualhost in the connection url, thus connecting to the virtualhost that has been defined as default within the Broker.
