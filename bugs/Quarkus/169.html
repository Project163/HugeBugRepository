Title

Description
**Describe the bug**
The rest client beans use the `Singleton` scope by default, which seems to be at odds with the spec and leads to some TCK tests failing (for example `org.eclipse.microprofile.rest.client.tck.cditests.CDIInvokeSimpleGetOperationTest`).
