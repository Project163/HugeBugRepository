Title

Move classloader from QueryParserDriver to PigContext

Description
After   PIG-1775  , mapreduce mode fail. The reason is we move classloader from LogicalPlanBuilder to QueryParserDriver, which will need antlr.jar, however, we don't ship antlr.jar to backend. It is better to move classloader to PigContext.
Discussion
- I remember a user trying to parse schemas using the Util.parseFromString() method in an UDF. This might require shipping the antlr binaries to the back-end. Will this patch address this issue too?
