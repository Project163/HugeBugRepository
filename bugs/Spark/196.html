Title

Fix the HistoryServer view acls

Description
If you are running the historyServer with view acls enabled (and a filter added to do auth), the application acls don't work properly.  It is looking at the user running the history server and not the user who ran the actual application, so basically no one other then the user running the history server can see anything. 

 We also need a way to allow all users to see the front page of the history server and only do authorization on the particular applications.
