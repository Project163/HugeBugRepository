Title

Windows build doesn't work with custom dist dir

Description
**Describe the bug**
The Wix build script will look for the `src-tauri/icons` folder relative to the set cargo target dir. This means it won't find them if the target dir is changed, like what the vue cli plugin does.

**To Reproduce** (not tested, but I'm pretty sure this will fail it)
Steps to reproduce the behavior:
1. Create tauri project
2. On windows, run `$env:CARGO_TARGET_DIR = 'other_dist'` and `yarn tauri build`

Or use the [Link: vue cli plugin] to build an app.

**Expected behavior**
Build works
