Title

Floating Point Exception on Empty Input Tensor with `torch.batch_norm_update_stats`

Description
### 🐛 Describe the bug

## Describe the bug
When attempting to update batch normalization statistics using `torch.batch_norm_update_stats` with an input tensor of shape `[0,0]`, a floating point exception (core dumped) error occurs. 

## Error log
```bash
Floating point exception (core dumped)
```

## Minified repro
```python
import torch
inp = torch.rand([0,0])
running_mean = torch.rand([1])
running_var = torch.rand([1])
torch.batch_norm_update_stats(input=inp, momentum=0.0, running_mean=running_mean, running_var = running_var)
```
