Title

StaticImportVisitor converts method calls to static ones too aggressively

Description
SIV is incorrectly promoting closure calls to static calls if a class has a static "call" method, e.g.: 
  
  class  X {
   static  call(x) { "wrong call" }
   static  m(closure) {
    closure( "1234" )
  }
}
 
X.m {  "$it 123"  }
