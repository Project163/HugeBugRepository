- Found the issue - the creation of the empty base file needs the directory "tmp" to exist, but we don't create it when we run the namespace-sandbox binary from the tests.

This only broke the tests, not the build, because "createImportantDirs" in LinuxSandboxedStrategy specifies the -d flag that triggers creation of the tmp directory.

Unfortunately our test suite didn't catch this before I submitted it, because it ran on a machine that didn't support sandboxing (in which case the test does nothing but still passes...).
