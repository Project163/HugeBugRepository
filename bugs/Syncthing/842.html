Title

.stignore should be ignored in Receive Encrypted folders

Description
Right now, if we create a new Receive Encrypted folder and try to edit it later, the Ignore Patterns tab is disabled.

However, if we do instead

1. Click "Add Folder".
2. Go to "Ignore Patterns" and set them to `*`.
3. Go to "Advanced" and set the "Folder Type" to "Receive Encrypted".
4. Click "Save".

then we end up with

[Image: 1]

which can only be fixed by deleting `.stignore` manually.

I'm not sure what the best way to fix this is, but I would personally propose to have Syncthing completely ignore the `.stignore` file when the folder type is set to "Receive Encrypted". This would likely require changes in the actual Go code though, and not just the GUI.
