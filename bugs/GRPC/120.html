### What did you do?

The current code is not correct. (Same as `v1.71.0` and current master head)

[URL]

The JSON minification logic in gRPC removes all whitespace, which unintentionally strips spaces inside string values.  
#### Steps to Reproduce
1. Create a JSON file (`test.json`) with valid spaces inside string values:
   ```json
   {
       "name": "John Doe",
       "bio": "Loves programming  and AI"
   }
   ```
2. Load the JSON file and apply the existing minification logic (`std::remove_if(db_.begin(), db_.end(), isspace);`).
3. Print the processed output.


### What did you expect to see? **Expected Output**

```json
{"name":"John Doe","bio":"Loves programming  and AI"}
```

### What did you see instead? **Actual Output (Incorrect)**

```json
{"name":"JohnDoe","bio":"LovesprogrammingandAI"}
```
The spaces inside JSON string values were mistakenly removed.
