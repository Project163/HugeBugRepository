Title

Redis breaks on live reload

Description
### Describe the bug

**Using Quarkus 1.13.4.Final**
1. App uses a Redis connection (ReactiveRedisClient)
2. Perform a postman call to an endpoint that calls Redis in some way
3. Successful response
4. Make any change such that performing another call triggers live reload
5. Successful response

**Using Quarkus 2.0.1.Final or 2.0.2.Final**
1. App uses a Redis connection (ReactiveRedisClient)
2. Perform a postman call to an endpoint that calls Redis in some way
3. Successful response
4. Make any change such that performing another call triggers live reload
5. Request failed : java.lang.IllegalStateException: Client is closed

Somewhere between 1.13.4.Final and 2.0.1.Final, live reload breaks Redis. I've confirmed this by switching the versions in the pom.xml several times and 1.13.4.Final works great, but 2.0.1.Final+ breaks with absolutely no other changes (same local computer, same remote redis host, same application.properties, etc.)

### Expected behavior

Would expect live reload to not cause a fatal error in Redis.
