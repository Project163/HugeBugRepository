Title

Detection od duplicated routeIDs might cause an issue with the inlined routes

Description
I see the weird behavior in Camel Quarkus with fix   CAMEL-22141   

   

 The issue can be easily simulated by running  CoreMainXmlIoTest  from  camel-main  branch of Camel Quarkus. (here is the CI  failure ) 

   

 There is a rest-dsl configuration: 
  
 
< rest  id= "greet"  path= "/greeting" >
    <get path= "/hello" >
        <to uri= "direct:greet" />
    </get>
</ rest >  
  
 and a route in xml-dsl: 
  
 
<route id= " rest -route" >
    <from uri= "direct:greet" />
    <setBody>
        <constant>Hello World!</constant>
    </setBody>
</route>  
  
 I see in debug, that the route  from direct:greet  is configured as the first route with id  rest-route .  

 Then the  rest:greeting  is added as a second one. Route is marked as inlined and the id of the route is set to  rest-route   (see  code ) because route is marked to be inlined. 

   

 The fix of   CAMEL-22141   detects the duplicated ids and fails camel to start. 

   

 From my POV, this looks like a bug. WDYT  davsclaus  ?
