Title

kafka_version label is unkown in native mode

Description
### Describe the bug

Verifying backport for 3.8.6 [URL] (_Add kafka-version.properties as a native image resource _ ), and attempting to do a test coverage for our Quarkus test suite.

I've noticed that the kafka_version="unknown" label still appears during native mode execution


### Expected behavior

``kafka_consumer_request_total{client_id="kafka-consumer-words-in",kafka_version="3.7.1}`"`

### Actual behavior

`kafka_consumer_request_total{client_id="kafka-consumer-words-in",kafka_version="unknown"}`

1. Clone my reproducer:

`    git clone -b kafkaversion-unknown-native [URL] `

2.  Execute maven command:

`mvn clean verify -Pnative`
