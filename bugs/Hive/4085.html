Title

Hive might produce wrong results when (outer) joins are merged

Description
Consider the following query: 

  
 select * from
  (select * from tab where tab.key = 0)a
full outer join
  (select * from tab_part where tab_part.key = 98)b
join
  tab_part c
on a.key = b.key and b.key = c.key;
