Title

`IntoSystemSetConfigs::chain_ignore_deferred` has wrong return type

Description
## Bevy version

  (Bevy 0.13.2)

## What you did

```
rust
#[derive(SystemSet, Debug, Hash, PartialEq, Eq, Clone)]
struct SetA;

#[derive(SystemSet, Debug, Hash, PartialEq, Eq, Clone)]
... [Log Snipped] ...
        .configure_sets(Update, (SetA, SetB).chain_ignore_deferred());
}
```

## What went wrong

`IntoSystemSetConfigs::chain_ignore_deferred`'s return type is not the same as `IntoSystemSetConfigs::chain`. Because of that you can't use `chain_ignore_deferred` with system sets

Compile error:
```
error[E0277]: the trait bound `NodeConfigs >>: IntoSystemSetConfigs` is not satisfied
   --> src/main.rs:30:33
    |
30  |         .configure_sets(Update, (SetA, SetB).chain_ignore_deferred())
    |          --------------         ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ the trait `SystemSet` is not implemented for `NodeConfigs >>`, which is required by `NodeConfigs >>: IntoSystemSetConfigs`
    |          |
    |          required by a bound introduced by this call
    |
```
