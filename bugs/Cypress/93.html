Title

JSON fixtures with unicode escape sequences are not parsed correctly

Description
See the "Current behavior" for bug details.

I already boiled the problem down to an error in the jsonlint module that is used for parsing the JSON data in [URL] and filed and issue there (zaach/jsonlint#102), but because that last commit is 3 years ago I don't know if it's still maintained.

Returning the result of `JSON.parse()` if no jsonlint error happened will fix the error while still keeping jsonlint as validator.

- Operating System: MacOS 10.13.1
- Cypress Version: 1.1.2
- Browser Version: not relevant

### Is this a Feature or Bug?

This is a bug.

### Current behavior:

A JSON file that contains unicode escape sequences (\uXXXX) in string values is not parsed correctly ("\uXXXX" results in "\\uXXXX"). 

### Desired behavior:

JSON fixture is parsed correctly.

### How to reproduce:

See [URL] for an example
