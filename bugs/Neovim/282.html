Title

regression: winhl=xx:yy ignored when yy was cleared

Description
### Problem

When setting `Normal` highlights for a floating window, the window shows `Pmenu` highlight. I used `git bisect` to see that this started at d879331 (cc @bfredl).

### Steps to reproduce

```
nvim --clean example.vim
```

Add the following code, which opens a floating window and sets its highlighting to `Normal`:

```
vim
let buf = nvim_create_buf(v:false, v:true)
let popup = nvim_open_win(buf, 0, {
      \   'relative':  'editor',
      \   'row':       15,
... [Log Snipped] ...
      \ })
call setwinvar(popup, '&winhighlight', 'Normal:Normal')
```

Source the code.

```
:source %
```

A floating window with `Pmenu` highlighting appears.

[Image: actual]


### Expected behavior

A floating window with `Normal` highlighting would appear. Here's an example using an earlier version of Neovim, 0.7.2.

[Image: expected]

0.8.0
