Title

BeanJsonConverter converting getters from the interface and not the underlying injected class

Description
A bug cropped in since  SHINDIG-912  commit (revision 755421) because it's only converting getters from the interface and not the underlying injected class (e.g. Activity instead of ActivityDb). 

 Here's the current code: 
    for (Map.Entry<String, Method> entry : getSetters(type).entrySet()) { 

 Which imho should be: 
    for (Map.Entry<String, Method> entry : getSetters(out.getClass()).entrySet()) {
Discussion
- Fixed BeanJsonConverter to use underlying injected class instead of type interface (e.g. ActivityDb instead of Activity)
- Updating patch to include unit test which reproduces the bug.
