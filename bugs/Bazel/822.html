Title

java_stub_template hard-codes local_jdk

Description
In [Link: java_stub_template.txt], when executing the actual java binary, if the classpath is too long a fake JAR is created and executed. However, the stub currently harcodes the use of local_jdk.

An upcoming change to split the build-base target greatly inflates the number of targets, and thus classpath entries, which triggers this issue in several Bazel builds and tests.
