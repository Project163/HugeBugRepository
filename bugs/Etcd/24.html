Title

Lease: Retrieving lease info using lease client LeaseTimeToLive() causes etcd node panic and die

Description
I observe that when lease client is retrieving a lease using LeaseTimeToLive() at the moment after the lease just has expired causes one of three etcd nodes to panic and die.

Setup:
OS: OS X El Captitan 10.11.6
etcd Version: 3.1.0-alpha.0+gi
Go Version: go1.7
Go OS/Arch: darwin/amd64

1. Download ectd code in your working directory.
2. CD into `../github.com/coreos/etcd`, start a three node etcd quorum via `goreman start`
