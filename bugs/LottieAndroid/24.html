Title

Strange behaviour when mixing LottieCompositionFactory and static drawable

**Describe the bug**
I found strange behaviour when using LottieAnimationView with static image and LottieCompositionFactory.
Lottie version: 3.5.0

**Steps To Reproduce**
Steps to reproduce the behavior:

1. Load animation to LAV with LCF - works perfectly.
2. Load static image to LAV with Glide (or .setImageDrawable - same result) - no problem
3. Load the same animation object from p. 1 with the same cache key - oops, no animation, static image will stay in LAV.
I can change static image and repeat p. 3 many times, but animation from p.1 will not work anymore.

There is a bad temp solution I found: If I change cache key of p.1 animation or load other animation after static image, I can successfully play animation number 1 again. 
Also transitions "static-static" and "animation-animation" always have no problem.
