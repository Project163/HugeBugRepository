Title

Incorrect key name documented for AffinityPlacementConfig.collectionNodeType

Description
The documentation for the  AffinityPlacementFactory  states that the `nodeType` configuration key limits the nodes eligible for placement to only those that match one or more of the specified node types. 

 The code for the  AffinityPlacementConfig  defines the key as `collectionNodeType` instead.
