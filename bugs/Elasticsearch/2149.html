Title

[ML] GetJobStatsAction does not match open jobs correctly

Description
The endpoint accepts a comma separated list of job Ids, group Ids, wildcarded Ids or `_all` which is then [Link: expanded] into individual job Ids. But the [Link: task match function] works on the unexpanded job id in the request rather than each of the expanded Ids. `_all` is handled correctly.

There are test cases covering getting the job stats for multiple jobs but the tests pass because the code assumes the job is closed then goes and gets the job stats for the job as if it was closed.
