Title

Warn about covariant return type declarations

Description
This is a fatal error in PHP7, but not in Psalm:

```
php
class A {
    function foo(): B {
        return new B();
    }
... [Log Snipped] ...
}
class C extends B {}
```

whereas this is fine in both:

```
php
class A {
    function foo(): B {
        return new B();
    }
... [Log Snipped] ...
}
class C extends B {}
```
