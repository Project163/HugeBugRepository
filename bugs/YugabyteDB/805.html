Title

[DocDB] Reduce level of tablet splitting log for deleted tablet

Description
Jira Link: [Link: DB-4401]
### Description

The log `No replicas found for tablet.` in tablet_split_manager will trigger if a tablet has no replicas. This can legitimately happen if the tablet parent was deleted and we restart the server, since the parent tablet will no longer be loaded in the tablet info map.
