Title

GLFW_MAXIMIZED hint not working correctly

Description
On Windows the GLFW_MAXIMIZED hint does not always work - whilst it works reliably when the app is launched from a console or via an IDE double clicking the exe in Explorer results in a normal sized window. However, calling glfwMaximizeWindow(window) after window creation works correctly.

This has been tested on the example boing as well as other code, issue first reported [Link: on the glfw forum] by user luis.
Discussion
- Successfully reproduced on Windows 7.
- So the easiest fix I can think of is to do

``` c
ShowWindow(_glfw.win32.helperWindowHandle, SW_HIDE);
```

at init to make subsequent calls ignore the `STARTUPINFO` without workarounds.
