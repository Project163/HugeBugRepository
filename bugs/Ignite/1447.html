Discussion
- UnswapIterator  may be created concurrently from multiple threads. As a result, the partition may become evicted while the other thread is iterating. We need to handle  InvalidPartitionException  in iterator and stop iteration when this exception is encountered.
- In the provided patch  next()  method does not call  advance  which creates infinite result set.
- I think I already fixed this error (commit 8a4b7541): GridDhtInvalidPartitionException is handled in clearAll(), if this exception is thrown then partition is already cleared and we can stop iteration.
