Title

null type ignored

Description
if a method or function specifies two or more types, one of which is null, null is ignored.

[URL]

```
php
/**
* @param scalar|null|array|object $b
*/
function Foo1(string $a, $b) : array
... [Log Snipped] ...

Foo1('a', null);
```
Discussion
- That's three or more. `null|string`,`null|object` etc work fine.
- I think it’s more about the union of those _particular_ types (as this works fine: [URL]
- Null is ignored in `null|object|*`
