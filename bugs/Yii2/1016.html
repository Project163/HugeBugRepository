Title

AssetManager::appendTimestamp not working with non-relative web path

Description
### What steps will reproduce the problem?

1. Ensure that `AssetManager::$appendTimestamp` is `true`.
2. Register an asset bundle whose `$baseUrl` is set to an absolute URL (starting with `http`/`https`) or an alias that will result in an absolute URL. (It’s important that the URL is not root-relative (starting with `/`).)

### What is the expected result?

Resulting JS/CSS URLs get timestamps appended (`?v=XXXXXX`).

### What do you get instead?

No timestamp.

### Additional info

Looks like this bug was introduced by  .

AssetBundle::registerAssetFiles() now calls `$manager->getActualAssetUrl()` instead of `getAssetUrl()`, but the timestamp was being appended from `getAssetUrl()`.
