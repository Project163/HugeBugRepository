Title

nodejs - Error with enum generation

Description
the issue is on node.js, an enum is generated like this: 
ttypes.TPolicy = { 
 '1' : 'NO_SYNC', 
 'NO_SYNC' : 1, 
 '2' : 'SYNC', 
 'SYNC' : 2, 
 '3' : 'WRITE_NO_SYNC', 
 'WRITE_NO_SYNC' : 3 
}; 

 correct is: 
ttypes.TPolicy = { 
 'NO_SYNC' : 1, 
 'SYNC' : 2, 
 'WRITE_NO_SYNC' : 3 
}; 

 from the .thrift file: 
enum TPolicy 
{ 
    NO_SYNC       = 1, 
    SYNC          = 2, 
    WRITE_NO_SYNC = 3 
}
