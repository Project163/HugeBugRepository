Title

Terms_Enum API Nullpointers when search string is missing

Description
A missing search string causes a NullPointerException.
I suggest in this scenario we make the API default to the behaviour of passing a blank string i.e. it's a match-all type search rather than return an error.
Discussion
- Pinging @elastic/es-search (Team:Search)
- +1, a blank search should be considered valid and would return the first N values of the field.
