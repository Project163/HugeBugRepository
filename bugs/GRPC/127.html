Title

Grpc.Tools can't process file Suffix name with Upper character.

Description
### What version of gRPC and what language are you using?
Grpc.Tool  2.71.0 
Grpc.Core 2.46.6 
C#

### What operating system (Linux, Windows,...) and version?
Windows 11

### What runtime / compiler are you using (e.g. python version or version of gcc)
C# with .net 8

### What did you do?
When my proto file with a suffix name as "xxx.Proto"， Grpc.Tools can't generate xxxGrpc.cs， but a xxx.ProtoGrpc.cs file， I check the source code ,
In protoc, src\compiler\generator_helpers.h, the StripSuffix() function just compare the suffix name with ".proto"， don't care the upper characters. I think, in Grpc.Tools, should convert the file name to lower charaters in windows platform when  generate parameters for call protoc.exe to generate files. I spend several days to solve this problem.  

### What did you expect to see?
In Windows platform, the proto file name can use upper characters.
