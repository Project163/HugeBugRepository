Title

Crash on :helptags

Description
- `nvim --version`: 0.2.2
- Vim (version: 8) behaves differently? Prints `E151: No match: /tmp/doc/**`
- Operating system/version: macOS 10.12.6
- Terminal name/version: Zsh 5.4.2
- `$TERM`: xterm-256color

### Steps to reproduce using `nvim -u NORC`

Create an empty directory. Call helptags on it.

```
mkdir /tmp/doc
nvim -u NORC
:helptags /tmp/doc
```

### Actual behaviour

Neovim crashes with a message like
```
nvim(73815, ) malloc: *** error for object  : pointer being freed was not allocated
```
The terminal is unusable afterwards.

### Expected behaviour

Error message pointing out that the directory is empty.
