Title

no-redeclare should support ES6 block scope

Description
```
js
// test.js
switch (foo) {
    case true:
        let bar = 42;
... [Log Snipped] ...
        const bar = foo;
}
```

```
js
{
    "ecmaFeatures": {
        "blockBindings": true
    },
... [Log Snipped] ...
    }
}
```

``` sh
$ eslint --reset --no-eslintrc -c config.json test.js

# No output
```

Since the `case` block of `switch` statements is a single lexical environment, `let` and `const` as in the above test should trigger warnings. (Running the test code in Firefox triggers a TypeError.)
Discussion
- TypeError is explained here: [URL]

Even Chrome is not happy. Its an error there too.
- Looks like `no-redeclare` just hasn't been updated for ES6 block scoping yet. I'll rename the issue accordingly.
