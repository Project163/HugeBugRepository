Title

Signatures not accepted for Python 2 static methods

Description
Valid static method signatures are not accepted in Python 2 mode. Consider this code:

```
class Foo:
    @staticmethod
    def f(x): # type: (str) -> int
        return 1
```

The type checker gives the error "Type signature has too many arguments".

- Hmm, this has the problem that if a program redefines `staticmethod`, it is still recognized as a static method. It's a pretty weird corner case, I know... However, `visit_decorator` in `mypy/semanal.py` detects `staticmethod` decorators, and it can deal with weird things like this:

```
def staticmethod(f):
    return f

class A:
    @staticmethod   # not actually a static method
    def m(self): ...
```

and this:

```
from builtins import staticmethod as foo

class A:
    @foo   # this actually is a static method
    def m(self): ...
```

The signature of static methods should probably be tweaked in the semantic analyzer to remain consistent with the rest of the implementation. Let me know if you'd like to have more pointers.
