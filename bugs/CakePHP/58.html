Title

cafile not set in HttpSocket

Description
From the documentation about SSL certificates (http://book.cakephp.org/2.0/en/core-utility-libraries/httpsocket.html#handling-ssl-certificates) you can give your own CAfile 

``` php
$socket = new HttpSocket(array(
    'ssl_cafile' => '/path/to/the/cafile.pem'
));
```

However this is not applied in the HttpSocket['context']['ssl']['cafile']. It seems that a typo in HttpSocket (line 687) is causing the default cacert.pem file to be set all the time.

```
-       if (empty($this->_context['ssl']['cafile'])) {
+       if (empty($this->config['context']['ssl']['cafile'])) {
```
