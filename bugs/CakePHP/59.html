Title

Checkbox doesn't allow value of 0

Description
The checkbox defaults to 1 if you try to set the value to 0.

```
echo $this->Form->checkbox('published', array(
 'value' => '0',
 'hiddenField' => 'anything',
));
```
Discussion
- `value` is usually the wrong option. What you probably want is `default` (in order to preserve posted data upon POST if the form invalidates). It is also possible (and IMO better) to set default values from the controller.

```
if ($this->request->is('post')) {
   // process
} else {
    $this->request->data['ModelName']['published'] = false;
}
```
