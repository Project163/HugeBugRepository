Title

Ambiguous column reference is not detected in GROUP BY query.

Description
Repro: 
  
 
create table t1 (a  int );

select s.a from
  (select a, a from t1) s
group by s.a;
 
  
 This should throw  SemanticException  with the message "Ambiguous column reference: a"
