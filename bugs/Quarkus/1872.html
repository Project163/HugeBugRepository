Title

Hibernate ORM and Search extensions now requires dev build profile

Description
### Describe the bug

I realize that opinions whether this is bug may differs heavily, but I want to create this issue (and  PR that proposes fix) as it seems unnecessary. Our CI is failing because of this [URL]

[URL] introduced `@IfBuildProfile("dev")` for `HibernateOrmDevJsonRpcService` and `HibernateSearchElasticsearchDevJsonRpcService`. That means that in terms of Hibernate ORM extension, DEV profile is same now as DEV launch mode. Previously it wasn't true.

We curate Quarkus application and launch it in DEV mode without setting "dev" profile. 

### Expected behavior

There is easy fix possible on both Quarkus side or our side, however I would prefer if Hibernate ORM worked in DEV mode as previously.
