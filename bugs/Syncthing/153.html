Title

File renamed to a directory name causes sync to fail

Description
### Test case:
1. Create a file 'test' in a repository and allow it to sync to another connected node.
2. Now rename 'test' to 'test_' and then create a new directory 'test/' before the repository scans again.
3. Move 'test_' into 'test/' and rename to 'test'. 
4. The remote repository will stop syncing (red) with the error:
   
   [KVZJP] 18:48:47 WARNING: All remaining files failed to sync. Stopping repo "shared".
   [KVZJP] 18:48:47 INFO: create: error: "shared" / "test/test": open /home/firecat53/shared/test/.syncthing.test: not a directory

This happened when I was moving Ansible group_vars files into their own directories.
