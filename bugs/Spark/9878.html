Title

Correct handling of SPARK_USER env variable override in app master

Description
The default  SPARK_USER  is set to the Hadoop user in the app master container. If a user supplies a configuration value for  spark.yarn.appMasterEnv.SPARK_USER , then the result gets appended to this default value like a classpath entry instead of replacing it.
