- Ah I see now that the problem is about the manual TOC links

```md
[Link: Review]
[Link: Staging]
[Link: Development]
[Link: Testing]
[Link: Unit-tests]
```

Renders as 

```md
  Review  
  Staging  
  Development  
  Testing  
  Unit-tests  
```

So we need to handle the `user-content-` in user-generated links in JS. Should check how GitHub does it.
