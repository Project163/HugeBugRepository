Title

standalone migration's `prune-ng-modules` mode doesn't update standalone imports

Description
### Which @angular/* package(s) are the source of the bug?

core

### Is this a regression?

No

### Description

Standalone migration's `prune-ng-modules` doesn't update imports properly when the pruned NgModule is referenced by a standalone component.

The following code:
```
ts
@Component({
  standalone: true,
  template: ` `,
  imports: [ChildModule]
... [Log Snipped] ...
})
class ChildModule {}
```

produces:

```
ts
@Component({
  standalone: true,
  template: ` `,
  imports: []
... [Log Snipped] ...
class Child {
}
```

and breaks the app, while it should produce:


```
ts
@Component({
  standalone: true,
  template: ` `,
  imports: [Child]
... [Log Snipped] ...
class Child {
}
```
