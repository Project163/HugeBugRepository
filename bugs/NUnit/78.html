Title

OSPlatform.IsMacOSX doesn't work

Description
The implementation of OSPlatform.IsMacOSX depends on Environment.OSVersion.Platform == 6 on MacOSX.  As of Mono 2.2, the implementation changed to NOT return this value:

[URL]

"Notice that as of Mono 2.2 the version returned on MacOS X is still 4 for legacy reasons, too much code was written between the time that the MacOSX value was introduced and the time that we wrote this text which has lead to a lot of user code in the wild to not cope with the newly introduced value."

Here is a discussion about this issue and a solution to call uname libc function to determine Mac vs. Linux.
