Title

[Scene2D] Scaled Font with markup wrapping issue on 1.9.12

Description
I've noticed an issue with Label wrapping when upgrading one of my projects to from 1.9.11 to 1.9.12. The issue seems to happen on Labels that use a scaled font with markup enabled and wrapping enabled as well. In some cases the Label wraps an extra line and doesn't update it's own size causing layouts that are dynamic depending on the size of the Label not to adapt correctly. This issue was not occuring on 1.9.11.
