from typing import Generic, ParamSpec

def checker(foo1: Foo[[int]], foo2: Foo[[str]]) -> None:

Note that, interestingly, this only crashes if you run mypy with `--strict-equality` (which is enabled by default if you run mypy with `--strict`, as you're doing). That's because this crash is caused by an interaction between mypy's logic for the `--strict-equality` check and its logic for `ParamSpec`s.
