# 📚 Docs or angular.io bug report

### Description

Currently, we have some docs that use code samples from the aio example apps, but there's no way for a reader to get to the actual example to see it in action, that is a stackblitz or download link. As a developer, I need to see a feature working in order to process, understand, and build on what I've just read.
