Title

onedrive: improve upgrade to graph procedure

Description
I think the upgrade procedure could work slightly better - if you start with an old remote like this

```
[onedrive]
type = onedrive
client_id = 
client_secret = 
token = {"access_token":"..."}
```

Then run `rclone config` then `e` to edit the remote, you get

```
$ rclone config 
Current remotes:

Name                 Type
====                 ====
... [Log Snipped] ...
q) Quit config
e/n/d/r/c/s/q> q
```

```
$ rclone lsd onedrive:
2018/09/02 16:32:12 Unable to get drive_id and drive_type. If you are upgrading from older versions of rclone, please run `rclone config` and re-configure this backend.
```

```
$ rclone config show onedrive
--------------------
[onedrive]
type = onedrive
client_id = 
client_secret = 
token = {"access_token":"..."}
--------------------
```

So the `drive_id` and the `drive_type` don't save for some reason.

Can you have a look at this please @Cnly ?  It probably isn't the onedrive backend's fault!
