Groovy 5 Elvis operator VerifyError

Description
When upgrading from Groovy 4.0.28 to 5.0.0, I notice that compiling the following code started throwing VerifyError: 

   
  
 
 static  def test( long  x,  Long  other) { return  x ?: other}

java.lang.VerifyError: Inconsistent stackmap frames at branch target 23
Exception Details:
  Location:
    Script1.test(JLjava/lang/ Long ;)Ljava/lang/ Object ; @18:  goto 
  Reason:
    Current frame 's stack size doesn' t match stackmap. 
  
   

   

 Of course, that code does not make much sense, but a bad refactoring left it like that in my codebase, and after the version upgrade, it broke.
