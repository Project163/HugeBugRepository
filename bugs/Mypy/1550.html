Title

Crash on jsonesque recursive type alias (regression 1.17.1 ⟹ 1.18.1)

Description
The following example passes on `1.17.1`, but crashes on `1.18.1`, `1.18.2` and `main` (`1.19.0+dev. `) with message `AssertionError: Must not defer during final iteration`

```python
type JSON_SCALAR = None | bool | int | float | str
type JSON_ARRAY[T: JSON] = list[T]
type JSON = JSON_SCALAR | JSON_ARRAY[JSON]
```
