Title

Empty response in AJAX actions if error after $application->run()

Description
If notice is triggered after `$application->run();`, AJAX actions return empty response.

Steps to reproduce: 
install fresh basic app,
set `cookieValidationKey` in `config/web.php`,
apply diff,
go to `index.php?r=site%2Fajax-hello` - empty response
comment out notice maker in index.php
go to `index.php?r=site%2Fajax-hello`, make sure it works
