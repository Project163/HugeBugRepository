Title

NullPointerException when run notebook previously generated before ZEPPELIN-387

Description
ZEPPELIN-387   introduces a new field "enabled" in paragraph config. 
This value is persisted into note.json. 

 However, note.json that exists before   ZEPPELIN-387   does not have "enabled" field and that cause NullPointerException
