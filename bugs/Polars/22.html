Title

Unable to vstack null typed column with typed column

Description
### Checks

- [X] I have checked that this issue has not already been reported.

- [Link: X] I have confirmed this bug exists on the [latest version] of Polars.


### Reproducible example

```python
import polars as pl
a = pl.DataFrame({"x": [3.5]}, schema={"x": pl.Float64})
b = pl.DataFrame({"x": [None]}, schema={"x": pl.Null})
print(a.vstack(b))
```


### Log output

```
shell
Traceback (most recent call last):
  File " ", line 1, in  
  File "/Users/orlp/.localpython/lib/python3.11/site-packages/polars/utils/deprecation.py", line 96, in wrapper
    return function(*args, **kwargs)
... [Log Snipped] ...
                           ^^^^^^^^^^^^^^^^^^^^^^^^^^
polars.exceptions.ShapeError: unable to vstack, dtypes for column "x" don't match: `f64` and `null`
```


### Issue description

While `null` might be a distinct type, it is compatible with concatenation with any other type. A lack of this support also breaks things such as inference in the JSON parser.

### Expected behavior

```
python
shape: (2, 1)
┌──────┐
│ x    │
... [Log Snipped] ...
│ null │
└──────┘
```

### Installed versions

0.19.9
