Title

using $ref about string type with format, strfmt's UnmarshallText method is not called correctly.

Description
## Problem statement

$ref about string type with format, loading feature is broken.
For example, define `mydate` in swagger (this is `type=string, format=date`),  and passing correct input (e.g. `2017-01-01`),  on deseriazeation is failed.

Maybe, generated code defines new type (type alias of strfmt.Date) but UnmarshalText method is not defined. so swag.ReadJSON is failed.

## Steps to reproduce

swagger.yml

```yaml
definitions:
  mydate:

    format: date
```
