RC6 Forms: when value is null, control is not disabled

Description

**Current behavior**

```
form = new FormGroup({
   'first': new FormControl({value: null, disabled: true}, Validators.required),
   'last': new FormControl('Drew', Validators.required)
})
```

the control `first` will not be disabled

**Expected/desired behavior**
`first` shall be disabled because `disabled` is true, even so the input is null. If the value is empty (''), it will not be disabled either. In other words, the input seems disabled only, and only if the input has a `value` defined
