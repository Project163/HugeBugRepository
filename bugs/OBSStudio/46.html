Title

Python scripting fails to load binary modules

Description
When using a Python script in obs, loading a binary module fails due to non-exported CPython 
symbols.

I am using obs on a Linux Debian Buster.  Tested with obs compiled from current git master (ccb7d897) as well as the debian package provided in testing, aka  `obs-studio 24.0.3+dfsg1-2`.

Given the following example which tries to load the `termios` python package (a cython package):

```python
import termios
```
## Expected Behavior

I would expect this python snippet to load properly (and do nothing).

## Current Behavior

I fails with the following traceback:

```
Traceback (most recent call last):
File "/home/david/perso/elec/obs-tally/obsFirmataTally.py", line 9, in  
  import termios
ImportError: /usr/lib/python3.7/lib-dynload/termios.cpython-37m-x86_64-linux-gnu.so: undefined symbol: PyExc_TypeError
```

## Steps to Reproduce
1. create a `test_import.py` script with the content being just `import termios`
2. load the script in the Tools->Scripts dialog 
3. open the Script Log dialog to see the described  traceback

## Additional information 

Using Python 3.7 from the system (3.7.3-1).

It also fails to load numpy for example.
