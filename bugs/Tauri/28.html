Title

`tauri build` hangs at wget request

Description
**Describe the bug**
A clear and concise description of what the bug is.
On `tauri build`, it hangs on `wget -q -O AppRun [URL] every time.

I tried it without `-q` as a separate commands and it showed this
```
--2020-09-12 13:18:54--  [URL]
```

**To Reproduce**
