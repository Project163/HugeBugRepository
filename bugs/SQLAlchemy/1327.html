Title

Event listeners at the class level don't organize well for subclasses

Description
### Discussed in [URL]
"SessionEvent listener not called if registered before `sessionmaker`"

the patch below shows where it goes wrong for this particular case:

```
diff
diff --git a/lib/sqlalchemy/event/attr.py b/lib/sqlalchemy/event/attr.py
index f8d70a06a6..cf4c38cb52 100644
--- a/lib/sqlalchemy/event/attr.py
+++ b/lib/sqlalchemy/event/attr.py
... [Log Snipped] ...
         if getattr(target, "_sa_propagate_class_events", True):
             self._clslevel[target] = collections.deque()
```

test case below illustrates two combinations.  Note that sessionmaker() makes a subclass of Session, so this test simulates that.

```
py
from sqlalchemy import event
from unittest import mock
```
