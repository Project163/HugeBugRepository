Title

DefaultLauncher should require a non-empty list of engines

Description
## Status Quo

If you fail to put a `TestEngine` JAR in the classpath, JUnit 5 will silently run _nothing_.

This fact recently caused a new user of JUnit 5 quite a headache since his tests were executed via the Maven Surefire plugin but not within the IDE.
