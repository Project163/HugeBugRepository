Title

Default values are not used when register is called before watch

Description
**Describe the bug**

The default value of a watched field is not used if I register a custom field before.

**To Reproduce**

If I use:

1. `useForm` with `defaultValues`
2. `register` a custom field (in my case, not an actual form field, just to compute something)
3. `watch` a real form field

In that specific order, the default value of the watched field is not used, but if I switch 2 and 3, it is working fine.

It seems that the bug comes from the first line of the `watch` function:

[URL]

`fieldsRef.current` is not empty because I used `register` before.

**Expected behavior**

Always use the default values, without having to specify them in the `watch` calls (as second argument).

**Desktop (please complete the following information):**
 - OS: Linux
 - Browser: Firefox
 - Version: 68
