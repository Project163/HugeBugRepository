Title

Stripping obstructive code is missed on triple equality check

Description
### Current behavior:

The following is not stripped correctly:

```js
if (self !== top)
```

### Desired behavior:

```js
if (self !== self)
```

This is because of the `!==`. We strip `!=` and a ton of other scenarios but somehow I missed the regexp on this one, which is a large oversight.
