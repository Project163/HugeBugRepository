Title

[Platform]No regions configured for AWS Provider

Description
When creating a Provider in Platform GUI, the create process fails almost immediately, but a big green indication appears saying "Successfully created AWS provider!". The provider exists in the config, but no regions get configured, and the provider does not function (cannot build universes with it, as there are no regions). Therefore the green "Success" banner is incorrect and misleading.

The issue is most likely in the way in which the regions are configured is incorrect, so the provider creation should fail.
