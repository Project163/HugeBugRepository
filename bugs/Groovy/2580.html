Title

inner and first-level classes with the same names

Description
Assume you have a class Bar in a package foo, so it's qualified name is foo.Bar. Add static method xyz to it. 
  
  package  foo;

 public   class  Bar
     public   static  void xyz(){}       // first-level method
 }
 
  
 Now create a class foo with the following text: 
  
  import   static  foo.Bar.xyz

 class  foo {

   static   class  Bar {
     static  xyz(){}         //  inner   class  method
   }
}
 
  

 The 'import static foo.Bar.xyz' imports the inner class's method if the first-level foo.Bar is a java class. But if the first-level foo.Bar is a Groovy class the import points to the first-level class's method. 

 I think it should be resolved to the first-level class's method in both cases.
