Title

Specifying log4jConfiguration in web.xml fails on Windows when the file's path contains spaces

Description
When specifying the context parameter log4jConfiguration in the web.xml of a web application and the resulting string contains spaces, e.g. 

  
      <context-param> 
         <param-name> log4jConfiguration </param-name> 
         <param-value> file:///${sys:catalina.base}/conf/logtestapp-log4j.xml </param-value> 
     </context-param>

Discussion
- It sounds like we need to encode some characters with % before giving them to the URI ctor.
- The same issue also crops up if you specify a filename with a space in the config file, like 

 <RollingFile name="RFA" fileName="C:/Logs/My Log.log" append="true" ...> 

 Arguably, a URI with spaces (like the param-value definition above) is a bug in the program but non-URI file names need to be encoded by Log4J.
