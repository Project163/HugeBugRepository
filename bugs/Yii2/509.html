Title

Postgresql negative default values support for integer/float/decimal columns

Description
Hello!
Currently yii doesn't handle negative default values and converts them to zero, because postgresql returns them in parenthesis, e.g. `(-1.234)`.
Discussion
- How to reproduce the issue?
- Test:

``` php
$connection = new \yii\db\Connection([...]);
$connection->createCommand('CREATE TABLE issue11912 (col INTEGER DEFAULT -1)')->execute();
$schema = new \yii\db\pgsql\Schema(['db' => $connection]);
$tableSchema = $schema->loadTableSchema('issue11912');
$connection->createCommand('DROP TABLE issue11912')->execute();

$this->assertEquals(-1, $tableSchema->getColumn('col')->defaultValue);
```

Output:

```
Failed asserting that 0 matches expected -1.
Expected :-1
Actual   :0
```
