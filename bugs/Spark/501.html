Title

Set SBT_MAVEN_PROFILES only when it is not set explicitly by the user

Description
dev/run-tests always sets SBT_MAVEN_PROFILES, which is not desired. As a matter of fact, Jenkins is failing for older Hadoop versions because the YARN profile is always on. 

  
   export SBT_MAVEN_PROFILES= "-Pyarn -Phadoop-2.3 -Dhadoop.version=2.3.0"
