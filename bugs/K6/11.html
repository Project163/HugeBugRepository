Title

Got an error that it can not write to the file:

Discussion
- I think it is the deferred shutdown function in engine.Run() that causes this:
```
   // Process any leftover samples.
   e.processSamples(e.collect()...)
   collectorcancel()
   <-collectorch

   // Emit final metrics.
   e.emitMetrics()
```

I swapped the order to:
```
// Process any leftover samples.
   e.processSamples(e.collect()...)

   // Emit final metrics.
   e.emitMetrics()
... [Log Snipped] ...
   collectorcancel()
   <-collectorch
```

Which seemed to fix the problem. Not sure how all these moving parts work however, so I will not check in anything until I know it's a viable solution. (i.e. until @uppfinnarn tells me so :)
