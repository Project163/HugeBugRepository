Title

Patch to Ruby HTTPClient to support SSL and to send correct Thrift Content-Type header

Description
The Ruby HTTPClient class fails if you provide an https: URL, and it does not set the same HTTP Content-Type header as the other language libraries. 

 This small patch addresses these two issues: 

 Index: lib/rb/lib/thrift/transport/httpclient.rb

 require 'uri' 
 require 'stringio'

     def write(buf); @outbuf << buf end 
     def flush 
       http = Net::HTTP.new @url.host, @url.port 
 
	 resp, data = http.post(@url.path, @outbuf)

{ 'Content-Type' => 'application/x-thrift' }
 +      resp, data = http.post(@url.path, @outbuf, headers) 
       @inbuf = StringIO.new data 
       @outbuf = "" 
     end
