Title

Release candidate versions in Debian packages should be like 0.1.2~rc2

Description
I installed the 0.1.2 release from the deb over the previously installed 0.1.2rc2, and got this:

```
$ sudo dpkg -i bazel_0.1.2-linux-x86_64.deb 
[sudo] password for kamal: 
dpkg: warning: downgrading bazel from 0.1.2rc2 to 0.1.2
(Reading database ... 277052 files and directories currently installed.)
Preparing to unpack bazel_0.1.2-linux-x86_64.deb ...
Unpacking bazel (0.1.2) over (0.1.2rc2) ...
Setting up bazel (0.1.2) ...
```

The downgrade warning could be avoided by using a `~` in the version as these compare less than any string including the empty string.

```
$ perl -le 'use Dpkg::Version; print join "\n", sort version_compare qw(0.1.2 0.1.2rc2 0.1.2-rc2 0.1.2~rc2)'
0.1.2~rc2
0.1.2
0.1.2-rc2
0.1.2rc2
```
