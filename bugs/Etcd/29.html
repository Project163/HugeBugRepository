Title

can be the TTL expire time calculation based on relative time?

Description
Now looks etcd TTL expires based on system real time, which may not be reliable as system NTP service will do synchronization from server. 
yes, normally it shall not be big jump for system time, but it is really very good to know if it can be configured with relative time like MONOTONIC.
Discussion
- Yes, TTLs for v3 leases use a relative clock, they don't rely on system time.
- I used the etcd 3.0.12 version, but I found when the system time changes manually, the expire time will be changed also. shall I do some configuration to have this relative clock?
