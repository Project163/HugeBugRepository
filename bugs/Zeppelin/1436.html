Title

Fix resource leaks in SparkInterpreterLauncher.detectSparkScalaVersion

Description
Description 
The `detectSparkScalaVersion` method in `SparkInterpreterLauncher.java` contains resource leaks that can lead to file descriptor exhaustion and temporary file accumulation. 

 Bug Details 

 Current Implementation Issues: 
1. Unclosed FileInputStream: Line 277 creates a FileInputStream that is never closed 
2. Undeleted Temporary File: Line 273 creates a temporary file that is never deleted 

   

   

   Impact 
 
	 Resource Exhaustion: Repeated interpreter restarts can exhaust file descriptors 
	 Disk Space: Temporary files accumulate in the system temp directory 
	 System Stability: Can destabilize Zeppelin if interpreters are frequently restarted 
 

   Root Cause 

 The method uses IOUtils.toString(InputStream, Charset) which does not close the provided stream, and there's no cleanup logic for the temporary file.
