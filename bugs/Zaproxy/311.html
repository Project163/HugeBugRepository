Title

Raw HTML displayed in options panels for search matches

Description
### Describe the bug

After a user has searched within ZAP's options, the title border(s) within some of the Network options panels display raw HTML instead of properly highlighting.

### Steps to reproduce the behavior

1. Open ZAP.
2. Go into the Option panel.
3. Type "prox" in the search area and hit the magnifying glass button.
4. Goto: Network > Local Servers/Proxies note both the border titles now include raw HTML.

### Expected behavior

The border titles should properly render the text and highlight without raw HTML.

### Software versions

Tested in both current dev and 2.13.0.

Network add-on 0.11.2.
