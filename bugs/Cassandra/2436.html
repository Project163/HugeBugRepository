Discussion
- File#getCannonicalPath returns path after resolving symlinks. Patch instead uses getAbsolutePath so symlinks under data dir works as expected.
- If we cannonicalize both sizes of what we're comparing, shouldn't it work either way?
- For example, if you have data dir of "/var/lib/cassandra/data" and you symlinked system keyspace under that data dir to "/var/lib/cassandra2/system" as above, cannonicalized paths are  

  
 /var/lib/cassandra/data -> /var/lib/cassandra/data
/var/lib/cassandra/data/system -> /var/lib/cassandra2/system
 
  

 thus current comparison doesn't work.
