Title

Incorrect indent when else statement has no curly braces

Description
**The `indent` error is incorrectly raised when an `if` statement uses curly braces, but its `else` counterpart does not.**

The following example has proper indentation:

```
JavaScript
/*eslint "indent": 2*/
/*eslint "curly": 0*/
(function () {
    "use strict";
... [Log Snipped] ...
    }
})();
```

but results in

```
12:8  error  Expected indentation of 8 characters  indent
```

The following example has improper indentation:

```
JavaScript
/*eslint "indent": 2*/
/*eslint "curly": 0*/
(function () {
    "use strict";
... [Log Snipped] ...
    }
})();
```

but does not trigger any error.

Even when curly braces are used, the error is off. This examples has proper indentation:

```
JavaScript
/*eslint "indent": 2*/
(function () {
    "use strict";
    switch (this.a) {
... [Log Snipped] ...
    }
})();
```

triggers:

```
10:8   error  Expected indentation of 8 characters   indent
11:12  error  Expected indentation of 12 characters  indent
12:8   error  Expected indentation of 8 characters   indent
```

- Likely related to #2248.
