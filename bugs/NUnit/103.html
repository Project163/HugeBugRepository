Title

ArgumentException when 2.x version of NUnit Framework is in the bin directory

Description
When testing an assembly with a target framework version which has only 2 fields (say, major = 4 and minor = 5, which is what I am testing now, compiled with mono 4.0.4) the code in NUnit.Engine.Services.TestAgency.LaunchAgentProcess() fails while calling System.Version.ToString(), raising an ArgumentException with message "Argument must be between 0 and 2. Parameter name: fieldCount".

I believe the problem to be around lines 204 and 204 of file  nunit/src/NUnitEngine/nunit.engine/Services/TestAgency.cs as of commit 272eadd. There the version is supposed to have at least 3 components, when there may not be that many.
