Title

Missing overload Assert.That(TestDelegate, IResolveConstraint, string, params object[])

Description
The Assert.That(TestDelegate, ...) overload allows to pass in a delegate as follows:
`Assert.That(() => { Console.Write(null, null); }, Throws.TypeOf ());`
However writing the assertion statement with a message
`Assert.That(() => { Console.Write(null, null); }, Throws.TypeOf (), "A message");`
yields the compiler errors:
(NUnit 3.0.0 beta 2)
error CS1643: Not all code paths return a value in lambda expression of type 'System.Func '
error CS1660: Cannot convert lambda expression to type 'bool' because it is not a delegate type
(NUnit 2.6.4)
error CS1660: Cannot convert lambda expression to type 'object' because it is not a delegate type.

This is due to the missing Assert.That(TestDelegate, IResolveConstraint, string, params object[]) overload.

The workaround is to wrap the anonymous method into a TestDelegate:
`Assert.That(new TestDelegate(() => { Console.Write(null, null); }), Throws.TypeOf (), "A message");`

The cast adds unnecessary "noise" to the statement and the compiler errors are unexpected and confusing when encountered the first time.
