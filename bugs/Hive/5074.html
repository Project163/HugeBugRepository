Title

INSERT dynamic partition on S3 fails with a MoveTask failure

Description
The following failure is due to the patch that merges two MoveTask found on the ConditionalTask (See   HIVE-15114  ) 

   Repro steps   
 CREATE EXTERNAL TABLE external_1k0jU (name STRING, age INT)  PARTITIONED BY (country STRING, state STRING); 
ALTER TABLE external_1k0jU ADD PARTITION (COUNTRY='USA', STATE='CA'); 
INSERT INTO external_1k0jU PARTITION (country='USA', state='CA') values ('John Doe', 23), ('Jane Doe', 22); 
CREATE EXTERNAL TABLE external_P3kiT (name STRING, age INT)  PARTITIONED BY (country STRING, state STRING) location 's3a://hive-on-s3/foo/bar/'; 
set hive.exec.dynamic.partition.mode=nonstrict; 
INSERT INTO TABLE external_P3kiT PARTITION (country, state) SELECT * FROM external_1k0jU;
