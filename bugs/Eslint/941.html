Title

Cache is deleted when linting text

Description
**What version of ESLint are you using?**
Master

**What parser (default, Babel-ESLint, etc.) are you using?**
default

**Please show your full configuration:**
N/A

**What did you do? Please include the actual source code causing the issue.**

Given a directory with a file and an `.eslintcache`:

```
.
├── .eslintcache
└── foo.js
```

Running eslint on text with `--stdin` causes the `.eslintcache` file to be deleted:

```
.
└── foo.js
```

**What did you expect to happen?**

Since the cache is only used when executing on files, I would not expect the `.eslintcache` file to be deleted.  This causes problems when using eslint in a text editor like Atom, because it means as soon as a file is opened (and therefore linted), the cache file is deleted (see [URL]  

I believe this is because the code which deletes the cache is too high in the CLIEngine execution [Link: right after instantiation].  It could likely be moved into `executeOnFiles` as an `else` to [Link: this check].
