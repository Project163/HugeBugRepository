Title

Flink Runner prepares to-be-staged file too late

Description
Before execution, the Flink Runner prepares all necessary files, in order for them to be shipped to the remote cluster. 

 Due to a recent regression via   BEAM-2873  , the preparation is performed after the execution environment has been initialized. This skips the preparation phase and results in invalid files being shipped.
Discussion
- This does not affect execution through the  bin/flink  utility where one provides a packaged jar, but native execution via Beam directly.
