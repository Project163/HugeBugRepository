Title

instanceof with || inserts wrong cast

Description
@groovy.transform.CompileStatic
def foo(a) {
     if  (a  instanceof   Integer  || a  instanceof   Double ) {
        a.floatValue()  // expected:  cast  to  Number ; actual:  cast  to  Integer 
     }
}

println foo(1d).class  // CCE: java.lang. Double  cannot be  cast  to java.lang. Integer
Discussion
- I have a solution that supports the case where the method ("floatValue" here, "toString" in 10668) is available via the LUB.  The duck-typing case (example below) needs handling in method selection and probably dynamic handling in classgen. 
  
 
@groovy.transform.CompileStatic
 int  cardinality(obj) {
  (obj  instanceof  List || obj  instanceof  Map) ? obj.size() : 1
}
- I think the general idea for the "full" solution was that even when we fully supported Union/Intersection types, that if the LUB was available, we could happily use that as an efficiency shortcut. However, if there was no LUB or the LUB was inaccessible, e.g. the LUB for StringBuilder || StringBuffer is package private, then we'd retain that knowledge and use Union/Intersection types. You are right - that needs handling further down the line. If your solution to handle the simple case, leaves open the extension to handle the more complex case later, then it seems reasonable to at least move ourselves forward on that part.
