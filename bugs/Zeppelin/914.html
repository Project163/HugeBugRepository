Title

User search is not working in zeppelin with LdapRealm

Description
User search is not working in zeppelin with LdapRealm. 

 Steps to reproduce : 
1) Configure shiro.ini as below : 
  
 
[main]
ldapRealm = org.apache.zeppelin.realm.LdapRealm
ldapRealm.userDnTemplate = cn={0},ou=Users,dc=company,dc=com
ldapRealm.contextFactory.url = ldap: //<ldap-server-host>:389
 ldapRealm.contextFactory.authenticationMechanism = SIMPLE
ldapRealm.contextFactory.systemUsername = cn=hrt_1,ou=Users,dc=company,dc=com
ldapRealm.hadoopSecurityCredentialPath = jceks: //hdfs/user/zeppelin/conf/zeppelin.jceks
 ldapRealm.searchBase = dc=company,dc=com
ldapRealm.userSearchBase = dc=company,dc=com
ldapRealm.groupSearchBase = dc=company,dc=com
ldapRealm.userSearchAttributeName = uid

sessionManager = org.apache.shiro.web.session.mgt.DefaultWebSessionManager
securityManager.sessionManager = $sessionManager
securityManager.sessionManager.globalSessionTimeout = 86400000
shiro.loginUrl = /api/login
[urls]
/api/version = anon
/** = authc
 
  
 2) Now login to zeppelin and try to assign user for a notebook. Here while searching for user, partial search is not working
