Title

[DocDB] For the same write, OperationDriver::SpaceUsed of the write at bootstrap is more than that at runtime

Description
Jira Link: [Link: DB-10174]
### Description

OperationTracker has a limit for memory consumed by pending operations, and should reject new writes if `current consumed memory` + `new writes's memory` > `limit`.
For the same write, the estimate used memory at bootstrap is more than that at runtime.
This can lead to failure of loading the pending operations at bootstrap due to exceeding memory limit.

  if (!operation_) {
    return 0;
