Title

isfinite(x) enters infinite loop

Description
The function glm::infinite(x) from compatibility.inl calls itself, resulting in an infinite loop when using gcc (non-android / no c++11).
Discussion
- This issue is now fixed in GLM 0.9.5 branch for GLM   release.

Thanks for contributing,
Christophe
- This implementation of `isfinite` should report any floating point value  ::min()` is actually the smallest representable positive value (i.e. `> 0`) of the type instead of the smallest representable value overall.
In this case `-std::numeric_limits ::max()` should be used (`std::numeric_limits ::lower()` for C++11).
