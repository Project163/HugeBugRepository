Title

INTERNAL ERROR when using `:=` assignment expression

Description
To reproduce the bug, run `mypy` with the following command:
```bash
mypy --show-traceback test.py
```

Where the contents of `test.py` are:

```
python
def func() -> None:
    obj = MyClass()
    if result := obj.var_name:
        pass

    def __init__(self):
```
