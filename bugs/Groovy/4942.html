Title

Calls to the outer class's super from an inner class does not work

Description
This example fails with a compile error "no such property super in java.lang.Class" on the line MyImplementation.super.myValue() 

 I am running static compilation 
  
 
 public   class  Wrapper {
     public   class  MyInterface {
         String  myValue() {
             return   "BLAHBLAH" ;
        }        

         public   static   class  MyImplementation  extends  MyInterface {            
             private   String  myValueFunction() {
                 return   super .myValue();
            }

             private   final   class  Builder {
                void init() {
                     // Error with no such property  super  in java.lang. Class 
                      // maybe because MyImplementation makes a  Class  reference in groovy
                     MyImplementation. super .myValue()
                }
            }
        }
    }
}
