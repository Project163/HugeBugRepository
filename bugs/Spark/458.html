Title

Shuffle read bytes are reported incorrectly for stages with multiple shuffle dependencies

Description
In BlockStoreShuffleFetcher, we set the shuffle metrics for a task to include information about data fetched from one BlockFetcherIterator.  When tasks have multiple shuffle dependencies (e.g., a stage that joins two datasets together), the metrics will get set based on data fetched from the last BlockFetcherIterator to complete, rather than the sum of all data fetched from all BlockFetcherIterators.  This can lead to dramatically underreporting the shuffle read bytes. 

 Thanks  andrewor14  and  rxin  for helping to diagnose this issue.
