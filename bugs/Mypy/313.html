Title

Generic constraint inference problem with TypedDict

Description
Mypy doesn't seem to infer constraints correctly for TypedDicts. Example:

```
py
from typing import TypeVar, Iterable
from mypy_extensions import TypedDict

T = TypeVar('T')
... [Log Snipped] ...
a: A
reveal_type(f(a)) # Argument 1 to "f" has incompatible type "A"; expected Iterable[ ]
```

The `f(a)` call should be okay and the revealed type should be `str`. This affects `iter()` at least.
