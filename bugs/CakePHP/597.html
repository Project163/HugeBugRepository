Title

3.0 - Problem with belongsToMany finder = list

Description
There is a little problem when we use a finder list on a belongsToMany association.
In Cake\ORM\Association\BelongsToMany in the _buildResultMap method, there is those lines:

```
foreach ($fetchQuery->all() as $result) {
            $result[$this->_junctionProperty] = $result[$property];
            unset($result[$property]);
```

When using a finder = list, the finder will return a key => value response and not an object like the foreach expect it to be.
Discussion
- Is there a reason you are using 'list' instead of finder that will allow associated records to be created?
- You are right, there is no point I can see for using 'list' as a finder. I do not know why we had something like that, but I think the error should be catched and a relevant error message should be thrown to the user.
- Ok, I can try making an exception when the keys are missing, as a notice error is not helpful.
- Closing as there is a pull request up. @mchiron If you have a chance would the error message being added in #5315 make sense to you?
