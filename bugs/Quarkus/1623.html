Title

Unable to set custom app.openshift.io/runtime label when deploying with OpenShift extension

Description
### Describe the bug

I'm deploying quarkus app to OpenShift using openshift extension
I have set in application.properties the following property:
```
quarkus.openshift.labels."app.openshift.io/runtime"=camel
```

### Expected behavior

Label in Openshift
```
app.openshift.io/runtime=camel
```

### Actual behavior

Label in Openshift
```
app.openshift.io/runtime=quarkus
```
