Title

bazel uses invalid options when building with gcc on OS X

Description
### Description of the problem / feature request:

If you instruct bazel to build with gcc instead of clang on OSX, it uses incorrect options and fails.



### Feature requests: what underlying problem are you trying to solve with this feature?

Building with gcc on OSX.

### Bugs: what's the simplest, easiest way to reproduce this bug? Please provide a minimal example if possible.

Do the following:

```
 
touch WORKSPACE
echo "int main() {return 0;}" > main.cpp
echo "cc_binary(name='t', srcs=['main.cpp'])" > BUILD
BAZEL_USE_CPP_ONLY_TOOLCHAIN=1 bazel build -s --action_env CC=/usr/local/bin/g++-7 //...
```
this gives the error
