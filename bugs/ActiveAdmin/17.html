Title

Add buffer override input

Description
I ran into an instance where I want to ignore the form buffer inside an `inputs` block. The resulting code looked something like this:

``` RUBY
f.inputs "Preferences" do 
  Customer::PREFERENCES.map{ |pref| f.input pref, as: :boolean }
end
```

Because of the `@inputs_with_block` instance variable, I can't do this without having the content repeat itself `Customer::PREFERENCES.length` times. As a work-around, I thought to implement something like the following method inside ActiveAdmin::FormBuilder:

``` RUBY
# If this `input` call is inside a `inputs` block, return it directly.
def input!(method, *args)
  # Temporarily set @inputs_with_block false and call `input` method
end
```

This allows the initial code to be written like this:

``` RUBY
f.inputs "Preferences" do 
  Customer::PREFERENCES.map{ |pref| f.input! pref, as: :boolean }
end
```

I feel that this is non-invasive and allows some flexibility in how AA forms are defined.

If this is something welcome / desired, I'll open up a pull-request.
Discussion
- After digging into the code a bit, it looks like this won't be possible with my proposed implementation.
- Instead of `map`, why not just do `each`? Wouldn't that work?

``` ruby
f.inputs "Preferences" do 
  Customer::PREFERENCES.each{ |pref| f.input pref, as: :boolean }
end
```
