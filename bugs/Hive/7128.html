Title

Using triggers in non-LLAP mode should not require wm queue

Description
Resource plan triggers are supported in non-LLAP (tez container) mode. But fetching of resource plan happens only when hive.server2.tez.interactive.queue is set. For tez container mode, only triggers are applicable, so this queue dependency can be removed.
