Title

LibGDX app renders incorrectly on iOS after device rotation

Description
Please ensure you have given all the following requested information in your report.

#### Issue details
LibGDX app renders incorrectly on iOS after device rotation

#### Reproduction steps
Create a boilerplate LibGDX app, ensure that the Info.plist.xml file permits all device orientations.

Capture screen size in `resize()`. Do some drawing in `render()` that is dependent on the aspect ratio of the screen. Check that the result is the same if the app is started in portrait vs starting in landscape then rotating to portrait.

#### Code
```
`
public class MyGdxGame extends ApplicationAdapter {
    int width = 0, height = 0;
    ShapeRenderer sr;

... [Log Snipped] ...
    }
}
````
#### Version of LibGDX and/or relevant dependencies
Tested with 1.9.5 and 1.10.0 - same results

#### Expected result

There should be no difference in the display whether the app starts in one orientation then rotates, vs starting in the final orientation.

#### Actual result

As expected on Android. Not as expected on iOS. Although `resize()` is called correctly with the new screen size, the image drawn is wrong, as though the backend is unaware of the rotation.

Discussion
- I'm not at all knowledgeable about iOS, but your example doesn't use a Viewport (unless ShapeRenderer uses one internally). There have been some issues noted about iOS apps without a viewport, that are hard to reproduce in actual games because almost all games wind up using a Viewport. I think the default behavior is to stretch a fixed-size region of the screen to fit the window or rotated-screen size. This does look like a bug, but it may just be a bug in the default iOS Launcher, or it may be fixed as soon as a Viewport is introduced.
- Yeah, @tommyettinger is right,`glViewport()` is not being called on device rotation which is not necessary when using a Viewport, that's a bug. You can workaround calling it on `resize()` (use `HdpiUtils.glViewport(0, 0, width, height)`). 

Independently from that, if you want the rectangle to have the same shape on both orientations you need to update the projection matrix of the `ShapeRenderer`:

```
matrix.setToOrtho2D(0, 0, width, height);				
sr.setProjectionMatrix(matrix);
```
