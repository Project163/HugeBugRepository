Title

fielddata_fields query string parameter ignored

Description
Specifying `fielddata_fields` on the query string seems to be ignored, although the [Link: rest spec] lists it as a valid query parameter.

```
PUT /twitter/tweet/1
{
  "user": "gregmarzouka"
}
```

```
GET /twitter/_search?fielddata_fields=user
```

```
json
"hits": {
  "total": 1,
  "max_score": 1,
  "hits": [
... [Log Snipped] ...
  ]
}
```

Specifying it as part of the request body works as expected:

```
GET /twitter/_search
{
  "fielddata_fields": ["user"]
}
```

```
json
"hits": {
  "total": 1,
  "max_score": 1,
  "hits": [
... [Log Snipped] ...
  ]
}
```
