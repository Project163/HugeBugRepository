Title

HttpObjectAggregator does not send 100 Continue when using HttpServerCodec

Description
In Netty 4.0.7, `HttpObjectAggregator.decode` sends a `100 Continue` in response to  `Expect: 100-continue`. Using `HttpServerCodec` interferes with this behavior:

``` scala
pipeline.addLast(new HttpServerCodec,
                 new HttpObjectAggregator(maxRequestSize))
                 new MyHandler)
```

A workaround is to use a separate encoder and decoder, with the aggregator immediately following the decoder:

``` scala
pipeline.addLast(new HttpRequestDecoder)
                 new HttpObjectAggregator(maxRequestSize))
                 new HttpResponseEncoder)
                 new MyHandler)
```
Discussion

- We have a separate handler that deals with connection management: keep-alive for 1.0 and 1.1, the connection header, the expect header, and other hop-by-hop headers.
