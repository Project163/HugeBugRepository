Title

Object.assign used when importing json in development mode.

Description
**Do you want to request a *feature* or report a *bug*?**

Bug

 
 

**What is the current behavior?**

In 'development' mode, importing JSON files generate `Object.assign` in the resulting bundle.

An example of this looks like: `Object.assign({}, _test__WEBPACK_IMPORTED_MODULE_1__, {\"default\": _test__WEBPACK_IMPORTED_MODULE_1__})`

This means that in development mode the resulting bundle does not work with IE (https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/assign#Browser_compatibility)

**If the current behavior is a bug, please provide the steps to reproduce.**

Here's a sample repo to reproduce the issue: [URL]

You can check for the use of `Object.assign` in the resulting dev build bundle. Note that production mode does not use `Object.assign`

 
 
 

**What is the expected behavior?**

Don't use `Object.assign`, not sure what is the reasoning behind using it in the first place.

**Please mention other relevant information such as the browser version, Node.js version, webpack version, and Operating System.**

Webpack version is 4.6.0
