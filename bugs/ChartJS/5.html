Title

Span tag in Legend

Description
In Chart,js file there are several places where the legend template string have a span that is immediately closed with its end tag and subsequently the span does not apply any styling to the legends.

``` javascript
legendTemplate : " -legend\">   \">       "
```

The occurrences seems to be at lines : 2045 , 2342 , 2544 , 2916 , 3179 of the Chart.js file.
Discussion
- I believe the intent was to let the user style the span (for example with inline-block display and 10px width/height) so you get a nice color box next to the text.
Now, the "fix" that was merged shows text on a colored background. This is not how legends are normally displayed.
