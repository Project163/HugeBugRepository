Title

Failed compaction is not captured

Description

Discussion
- Attached the patch to change  submit()  to  execute() , as we already created the  FutureTask  for  Runnable ,  submit()  will create one more  FutureTask , which causes nested  FutureTask : 
  
      public  Future<?> submit( Runnable  task) {
         if  (task ==  null )  throw   new  NullPointerException();
        RunnableFuture< Void > ftask = newTaskFor(task,  null );
        execute(ftask);
         return  ftask;
    }
