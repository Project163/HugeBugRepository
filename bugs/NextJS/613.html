### To Reproduce

1. npx create-next-app@latest
2. Add a file structure for dynamic routes
3. Add a loading.tsx page
4. import the same css module to both page.tsx and loading.tsx
5. Deploy or build the project

Error was introduce with next@13.3.0, working as expected on next@13.2.4.

Live demo: [URL]

### Describe the Bug

NextJS let you add a loading.tsx page to render while fetching, if we import the same css module to this loading.tsx file and into page.tsx file, the style is not apply until refresh.

The reason to import from the same css module into this two files is to have the same styling while the data is fetching.

Works fine on dev, this bug its visible once deployed to Vercel/Amplify-Hosting or after building while using yarn start/npm run start.

### Expected Behavior

Style should be applied to the page file after loading without need to refresh the page. Working as expected while development. Workaround so far its pretty easy, just import style from different css modules.
