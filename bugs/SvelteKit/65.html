Title

build list from $service-worker is incomplete

Description
The `$service-worker` provides the `build` and `files` members that allow the service worker to precache the app on install. My expectation is that if I cache all of these files, the app is fully cached, and no live HTTP requests will be done on the window reload. 

Unfortunately, it seems that `build` isn't picking the imported assets. In the example below, it is the `logo` import that is used in the `src` attribute. 

```
 
	import { page } from '$app/stores';
	import logo from './svelte-logo.svg';
 

... [Log Snipped] ...
	 
....
```

To reproduce:
- simply install the demo app (I use the Typescript option).
```
npm init svelte@next sw-test
cd sw-test
npm install
```
- add src/service-worker.ts
```
import { build, files, timestamp } from '$service-worker';

console.log('build', build);
console.log('files', files);
```
- run with 
```
npm run build
npm run preview -- --open
```
- open the dev tools and observe that the logged values don't include the `svelte-logo-....svg` file.
