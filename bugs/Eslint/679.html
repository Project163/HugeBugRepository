Title

Bug: Handle comments in block-spacing

Description
`block-spacing` should handle comments the same way `space-in-parens` does, as discussed in #4302.

Here is an example of a valid case:

``` js
{
  code: "if (a) {/* comment */ foo(); /* comment */}", 
  options: ["never"]
}
```
