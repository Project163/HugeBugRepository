Title

Remove dependency on flatmap-stream 0.1.1

Description
copy-pasting  derektapley 's report in   ZEPPELIN-3881   

  [URL]

   
  
 I see that the error is do to flatmap-stream 0.1.1 not being found, which is a dependency of the event-stream library.  It turns out this might actually be due to being a "poisoned' library, as some news articles recently indicate that event-stream was [backdoored to exploit a popular cryptocurrency wallet| [URL]  As such, npmjs.com has removed the dependency and the event-stream version needs to be updated to the latest, 4.0.1. 
  
   

  It seems that zeppelin master build is broken due to this. 

 Would it be possible to remove dependency of either `flatmap-stream` or `event-stream` or find a secure equivalent ?
Discussion
- Here's a very interesting thread how a very popular `event-stream` npm package got hacked  

  [URL]
- I was able to successfully build again, here are the steps I took: 
 
	 Navigate to ./zeppelin-web 
	 Open package-lock.json in the editor of your choice 
	 Navigate down to the event-stream dependency (as of commit  d1606c2 , this is on line 4523) 
	 Bump version to 4.0.1 
	 In the requires section, remove "flatmap-stream": "^0.1.0", 
	 Save package-lock.json 
	 Verify fix with npm install --no-lock 
 

 This should fix the problem with flatmap-stream being removed from npmjs.
