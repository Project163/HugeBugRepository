Title

Benchpress does not work in Chrome 45 as the events changed

Description
Benchpress does not report script time or gc in the upcoming Chrome 45. Changes to their tracing events:

script time:
Is reported with category `devtools.timeline,v8` and name `FunctionCall` (used to be other category).

gc time:
Is reported via category `devtools.timeline,v8` and name `MinorGC` / `MajorGC` (used to be other category and different name). Also, the name `majorGC` is not reported for category `v8` any more.
Discussion
- Maybe change the parsing of categories to detect multiple categories in the `cat` property of an event...

How can we keep track of these changes, without us debugging the tracing events manually?
- find the right source file in chrome dev tools and firefox dev tools that consumes the protocol as well...
- (per IRL conversation with @tbosch)

Since the names don't change that often (I think they've been stable for over 6 months), and since the devtools are likely to change file locations and structures, it's probably a better solution to just add some logic to examine the structure of data returned from Chrome to figure out if it's named the old names or new names. According to Tobias, we're still getting all the data back with the current implementation, we're just not parsing it correctly because of the name mismatch. Right, Tobias?

Identified changes so far:
- `("disabled-by-default-devtools.timeline", "GCEvent")` has been removed, instead use `("devtools.timeline,v8", "MinorGC")` and `("devtools.timeline,v8", "MajorGC")`
- `("v8", "minorGC")` is now `("devtools.timeline,v8", "MinorGC")`
- `("v8", "majorGC")` is now `("devtools.timeline,v8", "MajorGC")`
- `("disabled-by-default-devtools.timeline", "FunctionCall")` is now `("devtools.timeline,v8", "FunctionCall")`
- `("disabled-by-default-devtools.timeline", "Layout")` is now `("devtools.timeline", "Layout")`
- `("disabled-by-default-devtools.timeline", "UpdateLayerTree")` is now `("devtools.timeline", "UpdateLayerTree")`
- `("disabled-by-default-devtools.timeline", "Paint")` is now `("devtools.timeline", "Paint")`
- `("disabled-by-default-devtools.timeline", "RecalculateStyle")` is now `("blink,devtools.timeline", "UpdateLayoutTree")`

I am working on a PR to incorporate change into Benchpress.
