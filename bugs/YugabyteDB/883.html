Title

[YSQL] Colocation GA: Alter table add primary key(column), drop constraint(PK) not working on colocated tables(new implementation)

Description
Jira Link: [Link: DB-5413]
### Description

- Create a colocated database
- Create a colocated table in this database without a primary key
- Alter the above table and add primary key
**Issue:**
With the new implementation, Colocated tables cannot be altered to add primary key
```
cl_new_implementation=# alter table new_colocated_table_02_alter_pk  add primary key(id);
ERROR:  cannot use 'colocation=true/false' with tablegroup
```

Note: This alter clause works with the old CL implementation.
