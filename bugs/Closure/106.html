Title

JSDoc Type Info Assigned to Wrong Node

Description
[URL]

 What steps will reproduce the problem? 
Compiling a file named type_check.js with the contents:

var list = /** @type {!Array.<string>} */ ['Hello, ', 'how ', 'are ', 'you'];
list.push('?');

document.getElementById('node').innerHTML = list.toString();

using the command:

java -jar compiler.jar --compilation_level=ADVANCED_OPTIMIZATIONS --warning_level=VERBOSE --jscomp_error=checkTypes  --js=type_check.js

Results in:

type_check.js:4: ERROR - assignment to property innerHTML of HTMLElement
found   : string
required: Array

 What is the expected output? What do you see instead? 

I would expect a warning or error that I have a mal-formed type-cast (missing parentheses) or for the compiler to apply the type info to an adjacent node.

Instead, it picks the next assignment in the code (at least, I'm guessing that's what is happening).


 What version of the product are you using? On what operating system? 
Head on Mac OS X, Java 1.6_22
