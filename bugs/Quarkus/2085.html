Title

Incorrect web links Quarkus Hibernate Reactive Rest Data Panache

Description
### Describe the bug

Quarkus Hibernate Reactive Rest Data Panache is providing the incorrect web link self relation urls. 

The following snippets taken from the example entities of the reproducer project [Link: quarkus-issue-38247] produce incorrect rel=self web links.
```
@Entity
@Table(name="double_ids")
public class TestRecordOne extends PanacheEntityBase {

    // marked tid as the pk for this object and not the id field to show
... [Log Snipped] ...
    private String name;    
    ...
```

```
@Entity
@Table(name="annotation_only")
public class TestRecordTwo extends PanacheEntityBase {

    // field not named 'id' to force LinkProcessor to use the @Id annotation
... [Log Snipped] ...
    ....
}
```

### Expected behavior

When running the ReproducerTest cases the following is expected for each test case:

* shouldGetCorrectSelfLinkForRecordOne is expected to render the link [URL]
* shouldGetCorrectSelfLinkForRecordTwo is expected to render the link [URL]
 

### Actual behavior

When running the ReproducerTest cases the following is actually happening for each test case:

* shouldGetCorrectSelfLinkForRecordOne is rendering the link [URL]
* shouldGetCorrectSelfLinkForRecordTwo is rendering the link [URL]

### How to Reproduce?

To reproduce this clone [URL] and run `./mvnw clean verify` and see the failing testcases.
