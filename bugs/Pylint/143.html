Title

[easy] Show deprecated-module even if the module is not installed

Description
Originally reported by: **BitBucket: [Link: moylop260], GitHub: @moylop260?**

---
1. Steps to reproduce bug:
2. Make a pylint_w0402_test.py
3.  Add "import pudb"
4. Uninstall module pudb on your local machine
5. Run pylint
   pylint -d all -e W0402 --deprecated-modules='pudb' pylint_w0402_test.py
6. Check missing message
7. install pudb package (pip install pudb)
8. Run pylint again
   pylint -d all -e W0402 --deprecated-modules='pudb' pylint_w0402_test.py
9. Now you can see the error.
