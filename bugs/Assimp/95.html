Title

Bug: Out-of-bounds Read in Assimp::CSMImporter::InternReadFile

Description
### Summary

Out-of-bounds Read in `Assimp::CSMImporter::InternReadFile`. An attacker could potentially exploit the vulnerability to cause a remote code execution, if they can trick the victim into running assimp on a malformed CSM file.

### Affected

assimp>=5.4.3

### Details

In `code/AssetLib/CSM/CSMLoader.cpp:272`, user can arbitrary read memory using `na` which lead to OOB read.

```cpp
aiMatrix4x4::Translation(na->mPositionKeys[0].mValue, nd->mTransformation);
```

Using `aiMatrix4x4t & aiMatrix4x4t ::Translation`, attacker can leak arbitrary memory value.

```
cpp
template  
AI_FORCE_INLINE aiMatrix4x4t & aiMatrix4x4t ::Translation( const aiVector3t & v, aiMatrix4x4t & out) {
    out = aiMatrix4x4t ();
    out.a4 = v.x;
... [Log Snipped] ...
    return out;
}
```

For PoC, it got crash reading null pointer.

```bash
gdb-peda$ p na->mPositionKeys[0]
Cannot access memory at address 0x0
gdb-peda$ p na->mPositionKeys[0].mValue
Cannot access memory at address 0x8
```
