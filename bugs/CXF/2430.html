Title

JAX-RS proxy client with @QueryParam is not encoding the parameter value

Description
If I create a JAX-RS client with the proxy pattern outlined at  [URL] and the proxy interface looks like this 
  
 @PUT
	@Path( "/admin/user/{id}.json" )
	@Produces(value = {  "application/json"  })
	 public  User updateUser(@PathParam( "id" )  String  userId, @QueryParam( "country" )  String  country, @QueryParam( "description" )  String  role, @QueryParam( "telephone" )  String  phone);
 
  
 all URL parameters are not correctly encoded. 
E.g. if phone contains a "+" this will not be converted to %2B or if the role contains an umlaut this will not be encoded either. 

 Another related question is: Which character set will be used here (I guess UTF-8 makes sense) once that bug is fixed? Also how would it be possible to override the character set?

 /admin/user/123.json?country=<URL Encoded country name>&description=<URL encoded description name>&telephone=<URL encoded telephone number>

- FYI, apparently if you pass URI.getQuery() (the decoded value) to UriBuilder.replaceQuery then the space will be encoded to %20 and it will be a portable JAXRS code
- The fix has been applied to ensure the plus contained in the original query component is not percent-encoded so the code like 
  
 UriBuilder builder = UriBuilder.fromUri( "http: //localhost:8080/a" );
         URI uri = builder.queryParam( "phone" ,  "+44 123" ).buildFromEncoded();
        URI newUri = UriBuilder.fromUri(uri).replacePath( "b" ).buildFromEncoded();
