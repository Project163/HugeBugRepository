Title

DefaultSecurityContext Principal is incorrectly set from Subject

Description
In   CXF-4931  , the SecurityContext was populated from a JAAS Subject if one was available in the WSS4J results. However, the User principal was incorrectly set from the Subject as well. Instead it should be set from the principal returned from the WSS4J results.
