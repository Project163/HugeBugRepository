Title

Shadowed exported variables

Description
Given a situation like this...

```
js
var foo;

foo = (function () {
  return function foo () {

export { foo };
```

...we end up with this, which is a syntax error:

``` js
exports.foo = (function () {
  return function exports.foo () {
    return 42;
  };
})();
```
