Title

render app: Added stages get ignored

Description
## Bevy version

0.9.1

## What you did

The use case (same as [URL] I want to have a uniform which is created based on 2 separate sets of extracted data. I'm bound on one side by the Extract stage where the extraction takes place, and the Prepare stage, where the instantiated uniform is written to the buffer via UniformComponentPlugin.

There is no stage between them. Adding a stage results in the system not running:

```
use bevy::prelude::*;
use bevy::render::{RenderApp, RenderStage};

fn main() {
    let mut app = App::new();
... [Log Snipped] ...
    println!("I want to break free");
}
```

## What went wrong

Expected: the system runs.

Actual: nothing gets printed.
Discussion
- The render app runs all of it's stages by hand, so you can't really add a stage currently. [URL]

This will be fixed in the pipelined rendering pr.
