Title

`override_repo` does not support all labels

Description
### Description of the bug:

When using `override_repo` for a label with `.` in the name like: `swiftpkg_apple.swift_collections` which is a valid label, the `override_repo` usage fails as `.` is not a valid character for a key.

Root issue is:

```starlark
override_repo(
    swift_deps,
    swiftpkg_apple.swift_collections = "SwiftCollections",
)
```

Because `swiftpkg_apple.swift_collections` is a key name with a `.` it's invalid syntax and fails to build.
