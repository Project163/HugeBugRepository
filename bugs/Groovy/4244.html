Title

Statically imported closure field is not resolved

Description
create a class with code: 
  
  class  A {
  def x = {print  'x is called' }
} 
 
  

 and a script: 
  
  import   static  A.x

x()
 
  

 This script fails with MethodMissingException. 

 But script: 
  
  import   static  A.x

def a = x;
a()
 
  
 works well.
Discussion
- I think closure "x" should be static in class A 
  
  class  A {
   static  x = {print  'x is called' }
}
 
  

 Then, the issue is still there that following doesn't work 
  
  import   static  A.x

x()
- Attaching the patch for review. If it doesn't find a statically imported method but finds a static field  of the same name (in Klass), it transforms x(args) to Klass.x.call(args) then.
- Any comments on the fix? I was now planning to go ahead and apply it otherwise. It's a relatively straightforward fix actually.
