Title

Using '-' as separator between GroupID and ArtifactID (Maven) is a poor choice - not unique.

Description
### Description

Copied from discussion in [Link: [30568]] - originally  for a different issue and now closed with pending PR.

Gitea made a poor descision (IMHO) to use the separator '-' between groupID and artifactID.

Consider the following:

```
 foo 
 bar-jdbc 
 1-SNAPSHOT 

 foo-bar 
 jdbc 
 1-SNAPSHOT 
```

Both result in the same URL:
packages/maven/foo-bar-jdbc/1-SNAPSHOT

Although a '-' in a groupID is not "good-practice", it is not forbidden and perfectly valid and in common use.

For example:

```
 
     commons-lang.wso2 
     commons-lang 
     2.6.0.wso2v1 
 
```
