Title

Global Excludes Modify Description Doesn't Work

Description
**Describe the bug**
If you modify an existing Global Exclude to update the description the changes are not accepted. There's no error but they just don't stick.

**To Reproduce**
Steps to reproduce the behavior:
1. Launch ZAP. (2.7.0 or latest Dev build)
2. Go into Options and "Global Exclude URL" [With or without [Beta] tag depending on build]
3. Select an existing entry, click the Modify... button.
4. Add some text to the "Description" and click the Modify button.
5. Back in the Options panel note that no update occurred. (Repeat step 3 with the same entry, note the description wasn't change... so not just a table update issue, the change was seemingly discarded.)

Note: Modifying the regex _does_ seem to behave as expected.
Note2: When you Add... a new entry you can create it with no description, however when modifying the Modify button is disabled when the description field is cleared.

**Expected behavior**
Modifying a Global Exclude to update the description should work :+1: 

**Software versions**
 - ZAP: 2.7.0 & Dev
 - OS: Kali/Win7
