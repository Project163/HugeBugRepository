Title

NPE and 404 error when having a @RestQuery field of type Period

Description
### Describe the bug

I have a GET /api REST API that allows to provide a query parameter which is of type 'java.time.Period'

```
    @Schema(description = "Filter by GDPR retention period", nullable = true)
    @RestQuery
    private Period gdprRetentionPeriod;
```

When I call [URL] I get an 404 Not Found Error and a NPE in the logs with a  very cryptic log message : 

**_Caused by: java.lang.NullPointerException: Cannot invoke "org.jboss.resteasy.reactive.server.core.parameters.converters.ParameterConverter.convert(Object)" because "this.quarkusConverter" is null_**

P10Y is a valid string representation of a Period.

Note that this works perfectly when providing a Period in a JSON body of a  POST query (jackson correctly maps the provided string to a Period).

### Expected behavior

The string representing the Period is correctly converted to the period parameter annotation with @RestQuery

### Actual behavior

Getting a NPE when having a  @RestQuery parameter of type Period.
