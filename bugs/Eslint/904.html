Discussion
- This seems to be related to [URL] In both cases, changing the first character of the tag from lowercase to uppercase results in missing properties that the valid-jsdoc rule is expecting. Changing the characters back to lowercase fixes the issue. 

I'm unsure if capitalized tag names are valid JSDoc or not. If we don't want to allow capitalized tag names, then the fix is in valid-jsdoc itself and should be pretty straightforward (should warn when it comes across a capitalized name). If do want to allow capitalized tag names, I think the change might have to happen in Doctrine itself.
