Title

MacOS stack overflow on f99220f

Description
Running alacritty build from master at ref f99220f causes a runtime error immediately when starting up.

The following PR caused this: [URL]

Using the commit before works fine

### System

OS: macOS
Version: alacritty 0.5.0-dev (f99220f)

### Logs
```bash
./target/release/alacritty

thread 'main' has overflowed its stack
fatal runtime error: stack overflow
fish: './target/release/alacritty' terminated by signal SIGABRT (Abort)
```
Discussion
- seems like something in my config is causing the crash. I'll try to narrow down what that might be
- turns out I had the following enabled:

```yaml
window:
# Window class (Linux only):
  class:
    # Application instance name
    instance: Alacritty
    # General application class
    general: Alacritty
```
- This change seems related? [URL]
- The crash also happens on Windows 10 with ConPTY: `thread 'main' has overflowed its stack`.
Commenting out the `# Window class (Linux only):` section of the config fixes it for me as well.
