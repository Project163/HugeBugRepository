Title

Java doc is broken: "LUDecomposition.java:40: warning - Tag @see: missing final '>'"

Description
Java doc is broken in the build 

  
 [WARNING] Javadoc Warnings
[WARNING] /var/lib/teamcity/data/work/ /incubator-ignite/modules/ml/src/main/java/org/apache/ignite/ml/math/decompositions/LUDecomposition.java:40: warning - Tag @see: missing final '>': "<a href="[URL]
[WARNING] TODO: Maybe we should make this class (and other decompositions) Externalizable."
Discussion
- reproduced the issue in local build. Formal syntax of complained tag looks compliant with  javadoc specification . Experimentally it looks like some sort of side effect of the next line (with "TODO blah blah"). Wrapping that next line in html  <p>  tag did the trick and javadoc stopped complaining: 

  
 <p>TODO: Maybe we should make  this  class (and other decompositions) Externalizable.</p>
- Thank you for your contribution! I've merged the changes to master.
