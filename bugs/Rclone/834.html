Title

SIGUSR2 notification in log always says bandwidht limit is "disabled" even when toggling back on

Description
Sending SIGUSR2 to toggle the bandwidth limiter always shows "disabled" in the log, regardless of it being toggled off or back on:

```
2024/09/25 14:38:50 NOTICE: Bandwidth limit disabled by user
```

I believe this is just a reporting issue in the log.  The bandwidth limiter DOES seem to be toggled back on correctly.

According to the source, it looks like it should say "enabled" when toggling the bandwidth limiter back on (with a subsequent SIGUSR2):
[URL]

```
				tb.toggledOff = !tb.toggledOff
				tb.curr, tb.prev = tb.prev, tb.curr
				s := "disabled"
				if !tb.curr._isOff() {
					s = "enabled"
				}

				fs.Logf(nil, "Bandwidth limit %s by user", s)
```
