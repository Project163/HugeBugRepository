Title

Teamcity does not capture test output that is produced through ITestOutputHelper

Description
Teamcity "Overview" tab that displays failed tests details does not contain test output produced using ITestOutputHelper,
Example test:

```
public class ExperimentLogging1
    {
        private readonly ITestOutputHelper _testOutputHelper;

        public ExperimentLogging1(ITestOutputHelper testOutputHelper)
... [Log Snipped] ...
        }
    }
```

I run tests using xunit.console.exe with -teamcity flag.
Teacity version is: TeamCity Professional 8.1.2 (build 29993) 

Actual output in Teamcity 'Overview' tab is:

```
Assert.False() Failure
Expected: False
Actual:   True
   at SeleniumProject.Tests.ExperimentLogging1.should_1() in c:\BuildAgent\work\ \SeleniumProject\SeleniumProject\Tests\ExperimentLogging.cs
```

NOTE: The 'Build Log' tab does not contain output either. 
NOTE: Resharper runner works correctly and produces the following output:

```
Custom test output

Xunit.Sdk.FalseExceptionAssert.False() Failure

Expected: False

Actual:   True
   at SeleniumProject.Tests.ExperimentLogging1.should_1() in ExperimentLogging.cs
```

The expected behavior is that Teamcity 'Overview' tab contains test output
