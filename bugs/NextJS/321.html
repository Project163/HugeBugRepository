Discussion
- So I took a look @juliusmarminge, this was a pretty funny one :) so the reason why it specifically caused an error on your project was that your next.config only allows for tsx or mdx files with the pageExtensions config, so it would not resolve the default.js file provided by Next.js.

Fix incoming.

Note: in your example, you'd still need a default for the @modal slot.
- Interesting... Allowing `mdx` pages has now shot me in the foot twice 😇 


Why is that? Shouldn't the default provided by you take care of that?
- @juliusmarminge the default.js provided returns a 404 by design.

 The reason is because of things like this:
```/app/[slug]/layout.js
/app/[slug]/@user/profile/page.js
/app/[slug]/@team/members/page.js
function Layout({ params: { slug }, user, team }) {
  return isTeam(slug) ? team : user;
}
```

If I visit `/feedthejim/members` that should be a 404 because there's no "members" page of a user.

The doc should be updated soon to include all of those complicated nuances.
