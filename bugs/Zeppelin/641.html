Title

Provide ability to create charts through REST API

Description
Provide the ability to create charts through REST API.  

 Users should be able to provide chart information (e.g., barchart, piechart, etc) while creating a paragraph through the REST API. When user opens the notebook, this paragraph should show up with the newly created chart.
