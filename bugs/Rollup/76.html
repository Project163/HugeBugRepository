Title

Unused imports when using Import As statement

Description
When I choose output format to `es`, I am getting an unused import when ever I use the `* as` in my import statement.

example
```js
import * as _ from 'lodash';

_.isEmpty([]);
```

will output to 
```js
import { isEmpty } from 'lodash';
import * as _ from 'lodash';

isEmpty([]);

```
