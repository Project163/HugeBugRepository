Title

Improve how snapshots handle CSS

Description
Currently, a snapshot holds a copy of the `body` with any stylesheet ` ` tags removed (so that no further requests are made when the snapshot is restored). When tests are finished, the iframe points to and contains the contents of the last page visited (**a**). When a snapshot (**b**) is restored (by hovering over a command in the command log), it replaces the body of the iframe with the copied, stylesheet-less body of the snapshot. 

There are a few problems with this:
- The CSS from the head of **a** is still there, so **b** will end up using those styles
- **b** is lacking any ` `ed styles that were in its ` `, so those styles are missing
- **b** is lacking any classes that were on its ` ` tag

Solution:

When creating a snapshot:
- Grab any styles from ` `s or ` ` tags, in order, and preserve them
- Remove all styles (` ` or ` ` tags) from the copied body
- Grab any classes from the ` ` tag and preserve them

When restoring a snapshot:
- Remove any styles in the ` ` of the iframe (and preserve them for reverting), and restore the ` ` of the snapshot, inserting the preserved styles
- Replace any classes on the ` ` tag with those from the snapshot

When reverting to the last page visited:
- Put back any styles preserved from the ` ` of the last page visited
- Replace any classes on the ` ` tag with those from the last page visited
