Title

[DS] Removing required dependency before component is created leaves service registered

Description
Scenario: delayed component with a required service.  Start with the required service registered, and enable the component.  It will move to registered state, and create a service registration.  Now remove the dependency before obtaining the service from the service registration.  The component remains in the Registered state and the service remains registered even though the component is in fact now unsatisfied. 

 I think this is a problem with all mandatory dependencies (1..1, 1..n, static, dynamic).
