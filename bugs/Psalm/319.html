Title

Add support for filter_var

Description
```php
function filter(string $s) : int {
  $filtered = filter_var($s, FILTER_VALIDATE_INT);
  if ($filtered === false) {
    return 0;
  }
  return $filtered;
}
```
Expected: no issue
Actual: `Cannot assign $filtered to a mixed type`

[URL]

- Will `FILTER_NULL_ON_FAILURE` need special attention?

```
php
/**

*/

... [Log Snipped] ...
*/
$b = filter_var("foo", FILTER_VALIDATE_BOOLEAN, FILTER_NULL_ON_FAILURE); // null
```
