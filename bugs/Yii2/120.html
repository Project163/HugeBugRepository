Title

Response::send() called twice

Description
Not sure if I'm doing it right, but here's the thing:

I'm trying to send content as attachment using Response::sendContentAsFile().
As you can see, there's a call to $this->send(); at the end of the function (actually, in all send*File functions).

And we have another one at yii\base\Application::run().

This causes headers to be set twice and other bad things.

PS. Sorry if sendContentAsFile is not supposed to be called this way, there's no doc about right usage.
Discussion
- Btw simple removal of $this->send() at the end of sendContentAsFile() solves the problem.

Now I have

``` php
public function actionExport()
{
    $result = 'some data';
    \Yii::$app->response->sendContentAsFile($result, 'export.txt');
    return;
}
```

and it works perfectly.

Probably it would be more logical to do

``` php
public function actionExport()
{
    $result = 'some data';
    // as for now, this line renders the content twice:
    return \Yii::$app->response->sendContentAsFile($result, 'export.txt');
}
```

as we do with redirect()?
