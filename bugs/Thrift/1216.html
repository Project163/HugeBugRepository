- Root cause appears to be: 

 commit   
Author: Roger Meier <roger@apache.org> 
Date:   Sun Apr 12 16:10:35 2015 +0200 

      THRIFT-2850  CMake for Apache Thrift 
    add test/cpp and lib/py 

 This change added test/cpp at the top level of the CMakeLists.txt chain and the definition for -DUSE_BOOST_THREAD=1 is set inside the CMakeLists.txt inside lib/cpp.  It looks like those thread type definitions need to come up to the top level CMakeLists.txt so that everything built will share it.
