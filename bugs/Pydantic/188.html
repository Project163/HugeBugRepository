Title

Overriding default value makes alias go away

Description
# Bug

When overriding a default of in a child model, the alias defined in the parent is lost for the child.

Output of `python -c "import pydantic.utils; print(pydantic.utils.version_info())"`:
```
pydantic version: 1.6.1
            pydantic compiled: True
                 install path: /Users/powerjo/dev/juice/juiceutils/.venv/lib/python3.8/site-packages/pydantic
               python version: 3.8.2 (default, Apr 14 2020, 11:26:53)  [Clang 10.0.1 (clang-1001.0.46.4)]
                     platform: macOS-10.14.6-x86_64-i386-64bit
     optional deps. installed: ['email-validator']
```

Example:

```
py
from pydantic import BaseModel, Field


class Parent(BaseModel):
... [Log Snipped] ...
    assert parent.dict(by_alias=True).get('version_a') == parent.a
    assert child.dict(by_alias=True).get('version_a') == child.a
```

Result:

```
py
def test_override_default():
        p = Parent()
        c = Child()
        assert p.dict(by_alias=True).get('version_a') == p.a
... [Log Snipped] ...

test_ov.py:16: AssertionError
```
