Title

Incorrect line number reporting

Description
What steps will reproduce the problem? 
---- compile this ------------------------------------------------
// ==ClosureCompiler==
// @compilation_level ADVANCED_OPTIMIZATIONS
// @output_file_name default.js
// ==/ClosureCompiler==
/*
line 1
line 2
..
This comment seems to disturb line nr reporting
*/

/**
* provoke error in annotation
* @param {UNKNOWN_TYPE} name <- error this is not line 5, it is line 9
*/
function hello(name) {
    SYNTAX-ERROR-ON-LINE-13-OK
}

hello('New user');
----- end code ----------------------------------------------

 What is the expected output? What do you see instead? 
Should get two error/warnings. One on line 9 and one on line 13.
Both errors are found but first annotation error is reported to be on line 5 instead of line 9. 

-----compiler output -----
Number of warnings: 2

JSC_PARSE_ERROR: Parse error. Unknown type UNKNOWN_TYPE at line 5 character 10
This comment seems to disturb line nr reporting
          ^
JSC_USELESS_CODE: Suspicious code. This code lacks side-effects. Is there a bug? at line 13 character 19
SYNTAX-ERROR-ON-LINE-13-OK
----------------------------

 What version of the product are you using? On what operating system? 
Both the 20100514 release and online compiler.

 Please provide any additional information below. 

The annotation error reporter seems to treat any preceding comment
as single-line when it calculates line numbers. 
(Same in both SIMPLE and ADVANCED mode, just depending what errors are triggered).

Regards
// Fredrik Blomqvist
