Title

IntelliJ sync fails when sandboxing is enabled

Description
I've just tried creating an IntelliJ project (using our new plug-in from [URL] for Bazel itself and the initial sync fails with the following error:

```

... [Log Snipped] ...

        ExecuteBlazeCommand: 5.6s
```

Here's just the error formatted for easier reading:

```
ERROR: /Users/philwo/bazel/src/java_tools/junitrunner/java/com/google/testing/junit/runner/BUILD:28:1:
Writing file for rule '//src/java_tools/junitrunner/java/com/google/testing/junit/runner:Runner' failed:
