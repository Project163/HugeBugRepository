Title

static class constants inside final are always mixed

Description
In cases like [URL] or [URL] Psalm correctly flags `static::STRING` as a mixed type, because it could be defined with any type in a child class (see #505).

However, Psalm will also complain about [URL] where the class is final and there is no way for a child class to change the constant's type.

I think if a constant is both defined and used in a final class, the type should be obvious and Psalm should be able to take it into account.
