Title

Events can only be enabled via CLI, `worker_send_task_events` is ignored

Description
Template filled out below but this is pretty clear.

This line populates Worker.task_events using `either`:
[URL]

However, as of version 5, the `task_events` arg is `False` here when the argument is omitted from the command line, not `None`. So `either`, which looks for the first non-`None` value, always returns `False` and ignores the value from `app.conf`.

Works as expected in 4.4.7.
