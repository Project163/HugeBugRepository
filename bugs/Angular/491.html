Title

NgClass removes existing class when applying array that contains with 2 empty slots

Description
## I'm submitting a ...
 
  
[ ] Regression (behavior that used to work and stopped working in a new release)

**Construct a class array with 4 strings. The middle classes are an empty string. Then change the 2nd class, leaving the other classes unchanged.**

## Current behavior
 

NgClass does not apply correct classes. It removes the last class from the array. Internally the last class is added to the add and remove list, and since the add class code does nothing since it's already in the list and does not error, the remove list removes the class.

## Expected behavior
 

NgClass apply correct classes. The action should be to do nothing for the other existing classes and only add the 2nd class.

The following code tries to add the existing class in `changes.forEachAddedItem`, then removes it in `changes.forEachRemovedItem`. I would suggest not only fixing the bug, but reverse the order to first remove, then add, in case there are more bugs in the future.

[URL]
