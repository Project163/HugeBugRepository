Discussion
- I think that the way the [Link: ConfigMappingCreator] obtains the `InjectionPoint` metadata does not work well together with observer injection points.

It should help if the synthetic bean defines a synthetic injection point for `InjectionPoint` metadata. It also seems that we handle the current IP metadata differently for regular injection points of a `@Dependent` synthetic bean.

In any case, it's a bug.
