Title

solr.cmd wrongly assumes Jetty will always listen on

Description
The Windows solr.cmd script makes the (incorrect) assumption that Solr will always be listening on   (all interfaces). When you change the interface 
address, say to  , then the status and stop commands will fail. 

 This patch adds a property in solr.in.cmd, which is passed to SOLR_OPTS as -Djetty.host, and replaces the instances of   in solr.cmd. 

 The patch includes some changes in the netstat logic used in solr.cmd to find the correct Solr process(es).  

 Tested on Solr 5.5 on Windows 7 and 10.  

 Note: Untested on Solr 6. Currently using Solr 5.5
