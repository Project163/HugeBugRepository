Title

[YSQL] Increase default value of ysql_output_buffer_size

Description
Jira Link: [Link: DB-11163]
### Description

Increasing the default value of ysql_output_buffer_size will reduce the number of situations where query layer retries aren't performed on kReadRestart errors because a filled buffer was already sent to the external client.

On the flip side, increasing the buffer size might lead to less pipelining of data to the external client for large response sizes, which might increase latency. Run some microbenchmark to find a sweet spot.
