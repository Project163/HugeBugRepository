Title

flask addon can't get post data

Description
#### Problem Description
flask addon can't get post data

#### Steps to reproduce the behavior:
```
# test.py

from flask import Flask, request
from mitmproxy.addons import asgiapp

... [Log Snipped] ...
    asgiapp.WSGIApp(app, "example.com", 80)
]
```

mitmproxy -s test.py   --listen-host   -p 8002

and I can't get the post data.

#### System Information
Mitmproxy: 7.0.0
Python:    3.9.6
OpenSSL:   OpenSSL 1.1.1k  25 Mar 2021
Platform:  macOS-10.14.6-x86_64-i386-64bit
Discussion
- Thanks for the excellent report! I discovered two issues here:

- `curl -x localhost:8080 -X POST -F "foo=bar" [URL] -vvv` failing: We incorrectly did not lowercase headers, this will be fixed with #4722
- `curl -x localhost:8080 -X POST -F "foo=bar" [URL] -vvv -H "transfer-encoding: chunked"` failing: This is an upstream issue with asgiref, I'll submit a PR there shortly and will link here. 😃
- If you upgrade to 7.0.1 or above, the issue you were seeing should go away. 😃 I'm still keeping this open to track the upstream issue with asgiref. That only affects chunked tranfers, which usually shouldn't be the case for your example. :)
