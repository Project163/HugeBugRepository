Title

Mitmproxy crashes, when trying to export the flow in the folder with incorrect path

Description
##### Steps to reproduce the problem:

1. Run mitmproxy without root privileges.
2. Start intercepting something.
3. Choose any flow.
4. Press `e`. Choose a part of the flow - `cookies` for example. 
5. Press `w` to save `cookies`.
6. Try to save `cookies` to the directory which requires only root permissions.

I am getting:
