 I initially thought it is a malformed PDF but it isn't. Because the filter is in a 1-element array, the decodeparms dictionaries are also to be in an array. There's a method to get the correct item but it wasn't used in the JBIG2Filter for some reason. This wasn't discovered earlier because usually PDF creators don't use an array if there is only one filter.
