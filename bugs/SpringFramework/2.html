Title

ServerSentEventHttpMessageReader leaves a leading space on field decoding [SPR-17511]

Description
**[Link: Boris Morris]** opened **[Link: SPR-17511]** and commented

When decoding fields, the following code is used

```java
data.append(line.substring(5))
```

When the field is formatted as

```
name:  
```

Then the leading space is left on field.
