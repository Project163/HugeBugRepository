Title

Error reporting: import ends up silently instead of reporting an error

Description
I have three files: main.less, import\chained-import-1.less and import\chained-import-2.less. This is how main.less looks like:

```
@import-once "import\chained-import-1.less";
h1 {
  color: green;
}
@import-once "import\chained-import-2.less";
```

This is how import\chained-import-1.less looks like:

```
chained-import-1 { content: ~"chained-import-1"; }
//This import is wrong. It should be @import-once "chained-import-2.less";
@import-once "import\chained-import-2.less";
```

This is how import\chained-import-2.less looks like:

```
chained-import-2 { content: ~"chained-import-2"; }
```

Important part is in the chained-import-1 file. It attempts to import chained-import-2, but the link is bad and file is not found. 

Expected output:

```
ERR:
 type: Syntax
  message: Couldn't load import\chained-import-2.less (404)
  filename: import\chained-import-1.less
  column: 3
  extract: ,,
```

Actual output:

```
nothing, empty console
```

Tested on lessc less.js-1.3.3, .
Discussion
- The same thing happen if I replace `@import-once` with  `@import`.
