Title

segfault on recursive type

Description
I'm running mypy 0.701 on Python 3.7.2 on Linux, with the following input:
```
py
from typing import Any, Generic, Iterable, TypeVar, Union

ValueT = TypeVar('ValueT')

... [Log Snipped] ...
x: Iterable[str]
print(Sub(x))
```
I ran mypy under gdb to get a stack trace, but the stack trace is over 70,000 frames long (the point at which I aborted its listing), so I don't think including the full thing would be feasible or useful.

It looks like the following pattern is repeated over and over:
```
#70084   in CPyDef_types_accept_Instance (cpy_r_self=0x0, cpy_r_visitor= ) at build/__native.c:1601677
#70085   in CPyDef_subtypes_is_proper_subtype (cpy_r_left= , cpy_r_right= , cpy_r_ignore_promotions= ) at build/__native.c:1474319
#70086   in CPyDef_types_make_simplified_union_UnionType (cpy_r_items= , cpy_r_line= , cpy_r_column= ) at build/__native.c:1626562
#70087   in CPyDef_expandtype_visit_union_type_ExpandTypeVisitor (cpy_r_self= , cpy_r_t= ) at build/__native.c:388697
#70088   in CPyDef_expandtype_visit_union_type__TypeVisitor_glue_ExpandTypeVisitor (cpy_r_self=   , cpy_r_t= ) at build/__native.c:388750
... [Log Snipped] ...
#70098   in CPyDef_subtypes_visit_instance_ProperSubtypeVisitor (cpy_r_self= , cpy_r_left= ) at build/__native.c:1475884
```

I guess the compiled part of mypy got into an infinite recursion trying to figure out the recursive type definition and eventually hit a system limit on the native stack size.
