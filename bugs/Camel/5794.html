Title

AWS2 S3 Documentation contains references to obsolete AWS 1 API

Description
The documentation page for the AWS2 S3 component ( here ) refers to the `com.amazonaws.services.s3` package in several places. However, that package is not in the AWS2 API. 

 As a result, it is not clear what type of object is expected for headers such as `CamelAwsS3Acl` and URI arguments such as `amazonS3Client`.
