Title

Make --new-consumer option as deprecated in all tools

Description
Hi, 
as already described by the  KAFKA-5599 , it's usefull to mark as deprecated the new-consumer option for all the other tools which use it (ConsumerPerformance and ConsumerGroupCommand). It will be available for the next major release for then moving to remove the option in the subsequent release cycle. 

 There is also the following  KIP-176  proposed for removing them in a new release after the depracation. 

 Thanks, 
Paolo.
