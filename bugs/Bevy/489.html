Title

Touch input does not report window

Description
## Bevy version

0.8

## What you did

Read touch input from `Touches`.

## What went wrong

None of the touch inputs report what window is being interacted with. When registering a touch input on a windowing OS, bevy doesn't distinguish between touches on a primary or secondary window. A potential workaround is to query all windows to find the active one, but this can cause bugs when using multitouch.

## Additional information

Running on Windows 11, though this bug is caused by design, not OS-specific.
