Title

potential regression in reconciliation of same-named cols in inheritance

Description
found during the history_meta work

```
py
from sqlalchemy import Column
from sqlalchemy import ForeignKey
from sqlalchemy import Integer
from sqlalchemy import String
... [Log Snipped] ...

    __mapper_args__ = {"polymorphic_identity": "subsub"}
```

as a result of   #8705, the above script now warns for the subsub mapper

```
Implicitly combining column basetable.id with column subtable.id under attribute 'id'.  Please configure one or more attributes for these same-named columns explicitly.
```

didn't do that before.  you can map it by doing the subclass like this:

```py
class SubSubClass(SubClass):
    __tablename__ = "subsubtable"

    id = Column(Integer, ForeignKey("subtable.id"), primary_key=True)
    subdata2 = Column(String(50))

    __mapper_args__ = {"polymorphic_identity": "subsub"}


```

but this is an unexpected change
