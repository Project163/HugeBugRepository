Title

cqlsh failed to format value bytearray

Description
Execute the following in cqlsh (5.0.1): 

  
 > create table test(column blob, primary key(column));
> insert into test (column) VALUES(0x00);
> select * from test;

 column
--------------------
 bytearray(b'\x00')

(1 rows)
Failed to format value bytearray(b'\x00') : b2a_hex() argument 1 must be string or read-only buffer, not bytearray
Discussion
- can not reproduce on cqlsh 5.0.1, cassandra 3.2 (trunk)
- Can reproduce using cassandra 2.1.12 and python 2.6.6 

 Cannot reproduce using: 
 
	 cassandra 2.1.12 and python 2.7.11 
	 cassandra 2.1.11 and python 2.6.6 
	 cassandra 2.1.11 and python 2.7.11 
 

 The likely cause is  commit 1b629c10 , see (new) line 127 in formatting.py 

 I suspect you are running python 2.6; cassandra requires 2.7 – please check your python version
