Title

Different format of $results in afterFind when using ContainableBehavior and limit

Description
Consider this query

```
// Model1 hasMany Model2
$this->Model1->find('first', [
    'contain' => [
        'Model2' => [
            'limit' => 1, // try with and without this line
        ],
    ],
]);
```

If you take a look at `$results` from `Model2::afterFind()` with

```
public function afterFind($results, $primary = false) {
    debug($results);
}
```

you will notice a different in output with and without the `limit` line

```
// with array key `limit`
array(
    (int) 0 => array(
        'field => '...'
    )
... [Log Snipped] ...
    )
)
```

It would be great if `$results` always has the same format since using afterFind makes it hard to use.

I am using CakePHP v2.4.3
Discussion
- Can you confirm that `Model1` `hasMany` `Model2`?
- It would be great, but this is unlikely to change. Changing it could/would cause existing applications to misbehave. I'd rather not break code twice (once for this and then again in 3.0)
- ... [Middle Discussions Snipped for Brevity] ...
- What about building a consistent output but only use it if you pass an extra option in the model's find method ? This provides backwards compatibility and giving developers the option to use the consistent output...

Something like:

```
$this->Model->find('first', array('afterFind' => 'consistent'));
```
