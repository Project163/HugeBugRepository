Title

pkg_deb(built_using)'s documentation is wrong

Description
The documentation says this about pkg_deb's built_using:

This is not what Built-Using is for in Debian. Please read §7.8 on [https://www.debian.org/doc/debian-policy/ch-relationships.html]:

Something like "Bazel" should certainly not be stored there, as it's not a package name. (Although I did not actually find the default in the code, maybe I'm blind.) "bazel (0.1.1)" as suggested in the overview would be technically ok (and should not cause the package to be rejected if bazel exists) but is not really the thing we'd need to list there. `make` would not need to be listed there either.

It's nice to have the field available, but it should never be set automatically. Thanks.
