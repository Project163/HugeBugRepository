Title

Timer coder contains a faulty key coder leading to a corrupted encoding

Description
The coder for timers contains a key coder which may have to be length-prefixed in case of a non-standard coders. We noticed that this was not reflected in the  ProcessBundleDescriptor  leading to errors like this one for non-standard coders, e.g. Python's  FastPrimitivesCoder :
