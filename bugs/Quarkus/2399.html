Title

Instance does not find implementations having a @Context annotated field

Description
### Describe the bug

When iterating over a `Instance `, no implementations of `T` having a `@Context` annotated field are returned.

```
    @Inject
    Instance  generators;
```
```
for (GreetingGenerator generator : generators) {
            if (generator.handlesLanguage("de")) {
                return generator.generateGreeting();
            }
        }
```

And: 

```
@ApplicationScoped
public class GermanGreetingGenerator extends GreetingGenerator {

    @Context
    HttpHeaders headers;
```

The GermanGreetingGenerator  is never found by the for loop.

Directly injecting and using the GermanGreetingGenerator works as expected,

### Expected behavior

Either a log message about this circumstance. or find the GermanGreetingGenerator.

### Actual behavior

GermanGreetingGenerator is not returned with Instance 

### How to Reproduce?

Download reproducer: 

[Link: instance-unremovable.zip]

mvn quarkus:dev
Open localhost:8080/hello.
Should display "Servus", but instead displays "Hello".
In GermanGreetingGenerator.java, remove     @Context HttpHeaders headers;
Open localhost:8080/hello.
Correctly displays now "Servus"
