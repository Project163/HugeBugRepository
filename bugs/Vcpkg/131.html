Title

[sdl2-mixer] build failure on pre-Catalina macOS

Description
**Host Environment**
- OS: macOS 10.14.6
- Compiler: Apple clang version 11.0.0 (clang-1100.0.33.17)

**To Reproduce**
Steps to reproduce the behavior:
`./vcpkg install sdl2-mixer[libflac,libogg,mpg123]`

**Failure logs** 
The key issue seems to be that `os/availability.h` either does not exist or is marked with `API_UNAVAILABLE` in older Xcode SDKs.

**Additional context**
Regression appears to be introduced by #10201
Discussion
- Can you use another compiler or do you _have_ to use AppleClang?
- I don't see the relevance, but in general you can change the compiler by setting the `CC` and `CXX` environment variables. However, Apple Clang is the platform compiler for macOS.
- ... [Middle Discussions Snipped for Brevity] ...
- Apple generally supports the last three released major versions. As of writing, 10.13 High Sierra has extended support until September. Thus, Homebrew tests the most recent three versions and ships bottles for those. I can look more in-depth into how this can be patched but in the meantime I've locally reverted the PR that introduced the regression for my uses.
