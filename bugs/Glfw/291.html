Title

Toggling fullscreen off minimizes window

Description
Operating system: arch linux
GLFW commit fb0f2f92, built with GLFW_BUILD_WAYLAND and GLFW_USE_WAYLAND

Reproduction steps:
Open any GLFW window as a native wayland client, such as `examples/gears` or `tests/events` in the repo. 
Toggle fullscreen on using compositor shortcuts.
Toggle fullscreen off using the same shortcut. (edit: actually just switching focus, for example via alt+tab works as well)
The window is now minimized, instead of its size being restored.

This can be reproduced in GNOME, KDE as well as wlroots-based compositors such as wayfire.

Output of `tests/events`:
```
Library initialized
Creating windowed mode window 1 (640x480)
Error: Wayland: The platform does not support setting the input focus
Main loop starting
00000000 to 1 at 0.028: Window focused
... [Log Snipped] ...
00000016 to 1 at 1.478: Window refresh
00000017 to 1 at 1.512: Window defocused
```
