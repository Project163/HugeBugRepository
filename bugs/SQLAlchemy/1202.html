Title

Insert from_select with independent CTE that is also an insert from_select is selecting from wrong columns

Description
### Describe the bug

If I have two INSERT from_select statements and add one to the other as an independent CTE, the main statement's SELECT selects the columns from the CTE's SELECT.

### To Reproduce

```
python
from sqlalchemy import select, text, Column, Integer, MetaData, String, Table

metadata = MetaData()

... [Log Snipped] ...

print(ins2.add_cte(cte1))
```

### Error

This outputs:
```sql
WITH cte1 AS 
(INSERT INTO table1 (id1, a) SELECT 1, 'a')
 INSERT INTO table2 (id2, b) SELECT 1, 'a'
```

but I'd expect:
```sql
WITH cte1 AS 
(INSERT INTO table1 (id1, a) SELECT 1, 'a')
 INSERT INTO table2 (id2, b) SELECT 2, 'b'
```

### Versions

- OS: MacOS 11.5.2
- Python: 3.9
- SQLAlchemy: 1.4.23
- Database: postgres
- DBAPI: psycopg2

### Additional context

Thanks! (And apologies if this should be an enhancement request rather than a bug report, since `add_cte()` is a recent addition and I'm not sure if this use is supposed to be supported.)
