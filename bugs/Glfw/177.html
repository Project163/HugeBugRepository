Title

Joystick connections/disconnections not detected

Description
This is on the latest Sierra and High Sierra, with an Xbox 360 controller connected to a USB-C port (using a USB-A to USB-C adapter) on a MacBook Pro 2017 model.

The controller must be connected on application startup (found using _glfwJoystickPresent_). Any controllers connected after startup are not detected (the callback is not triggered), and neither are disconnections of controllers detected initially (e.g., the joystick callback does not appear to function on MacOS).

It seems that a controller must be connected before _glfwInit_ is called for it to be detected. I was able to work around this error by re-initializing GLFW in an update loop every second (this application is solely for gamepad input). Using this method, I can successfully detect connections and disconnections (though I must manually call _glfwJoystickPresent_ during this phase for known controllers to decide if they have been disconnected.
Discussion
- For joystick connection events to be delivered on macOS (and Windows), the main thread message queue must be polled. Try calling `glfwPollEvents` at regular intervals instead of reinitializing the whole library.
- `glfwPollEvents` is already being called in the update loop. I still have to re-initialize the library for the connected state of joysticks to change.
