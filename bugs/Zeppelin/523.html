Title

LazyOpenInterpreter would open interpreter multiple times when open fails

Description
I see this issue when livy interpreter fails to open (throw exception). In that case LazyOpenInterpreter would call open again to create another livy session.  
This is due to we call open method in getProgress() 

  
     public   int  getProgress(InterpreterContext context) {
    open();
     return  intp.getProgress(context);
