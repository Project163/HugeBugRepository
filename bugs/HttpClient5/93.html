Title

Credentials not sent when using preemptive auth

Description
After version 5.0.3, preemptive auth appears to be broken, with the  Authorization  header missing from requests sent. I wonder if this may be related to the fix for   HTTPCLIENT-2147  . 

 I was able to reproduce this problem using the  Preemptive Authentication example  provided in the  httpcomponents-client  GitHub repo. Below I outline the differences between the behaviour of HttpClient 5.0.3 and 5.1.1+ (using the Preemptive Authentication example, and Java 15.0.1). Nothing besides the HttpClient version was altered between the two cases. 
    HttpClient 5.0.3  

 Preemptive Authentication example works as expected.
