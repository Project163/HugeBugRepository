Title

PatternSyntaxException on @Path definition with regexp

Description
## Describe the bug
`@Path("/{pin: [A-Z][A-Z][A-Z0-9]{9}[0-9]}")` is not parsed correctly

### Expected behavior
regexp should work

### Actual behavior

create project with quarkus-resteasy-reactive and resource:
```
java
@Path("")
```
