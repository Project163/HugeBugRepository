Title

Description
This bug was found when doing soft upgrade testing from Derby version   to   (RC1) 

 Steps followed are as follows. 

 1. Run setEmbeddedCP.bat from version  's bin folder 
2. In a test folder run ij 
3. create system/wombat database. 
    ij> connect 'jdbc:derby:system/wombat;create=true'; 
4. exit ij 
5. Copy the   derby jars (from lib folder) and the derbyTesting.jar from   to the test folder and set classpath with them (including junit and ORO) 
6. Run suites.All  
     java -Xmx512M -Xms512M -Dderby.tests.trace=true junit.textui.TestRunner org.apache.derbyTesting.functionTests.suites.All
