Title

_csrf cookie sometimes generates invalid values which triggers ModSecurity

Description
### What steps will reproduce the problem?
activate ModSecurity (always active on shared hostings providers like OVH)
include this in the controller:

public function beforeAction($action) {
        if($action->id == 'index'){
            $this->enableCsrfValidation = false;
            $cookies = Yii::$app->response->cookies;
            $cookies->remove('_csrf');
            unset($cookies['_csrf']);
        }
        return parent::beforeAction($action);
    }

and refresh the index action a few times to generate new _csrf cookies

after some refreshes (randomly) it creates a "bad cookie"

### What is the expected result?

standard index page

### What do you get instead?

403 Forbidden
You don't have permission to access / on this server. 

nor any other page, ModSecurity stops it before reaching the actual index.php file

(you get the bad cookie about once every 10 refreshes, and need to delete the cookie to start it behave normally again)

example of "bad" cookie content: " %3A2%3A%7Bi%3A0%3Bs%3A5%3A%22_csrf%22%3Bi%3A1%3Bs%3A32%3A%22%EE3%3C%0B%02%9D%5C%91%5D%E4_Z%96%F9%BB%3F%CE%00%EB%B8%A5n%D6%DE%9D%98%8F%9A%1FJ%E5%60%22%3B%7D"
