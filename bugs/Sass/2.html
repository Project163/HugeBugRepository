Title

3.1.0.alpha.50: Sass::Plugin.options[:always_check] = false doesn't work in Rails 2.3.10

Description
`Sass::Plugin.options[:always_check] = false` doesn't work but `Sass::Plugin.options[:never_update] = true` seems to do the trick... all my production servers were running almost 10x slower since I launched them with Sass 3.1.0.alpha.50. Added `:never_update` and things went back to normal.
Discussion
- #35 confirms this on Rails 3 as well. It's also worth noting that this dramatically affects test times.
- I'm having trouble reproducing this in either production or test. You're not spinning up a new server or otherwise causing global state to get reset for each request, are you? Can you provide me a sample rails app in which running a production server or tests locally demonstrates the issue?

To make it clear whether or not it's happening, include this snippet somewhere in your app:

```
module Sass::Plugin
  def update_stylesheets_with_instrumentation(*args)
    puts "Updating stylesheets"
    update_stylesheets_without_instrumentation(*args)
  end
  alias_method_chain :update_stylesheets, :instrumentation
end
```

This will print "Updating stylesheets" whenever Sass is going to touch the filesystem.
