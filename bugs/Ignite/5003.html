Title

Incorrect values of cache, cache group, data region metrics after cluster re-activation

Description
Cache, cache group, data region metrics values are incorrect after the cluster re-activation.  
It happens because they are not registered with the new cache* context and still point to the previous one. Data region metrics are not reset/remove after deactivation.
