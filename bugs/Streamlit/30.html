Title

Error getting Streamlit credentials

Description
i deploy streamlit on companny server ,which not permmited to connect to internrt ,so how to skip this credentials?
Discussion
- Hi @zdxpan,
thanks for your question!! You can just leave the credential blanks or add empty credential to the `.streamlit/credentials.toml`.

This is an example:
```
[general]
email = ""
```
- This PR is also relevant: #328 

Once that PR lands, when Streamlit runs on a headless server it will skip the credentials step.

We try to detect whether something is headless automatically based on the DISPLAY environment variable, but you can also set it yourself in your config file:

```
[server]
headless = true
```
- Relevant changes have been merged, so closing this.
