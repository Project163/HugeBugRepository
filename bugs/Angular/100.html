bug(compiler): Token#toString returns `null` for TokenType.OPERATOR

Description
[Link: Token#toString] is missing a case for `TokenType.OPERATOR`, so it returns `null` when called for a token of that type. This causes Dart string interpolation to fail, for example [Link: here] if it attempts to report an unexpected `OPERATOR` token.
