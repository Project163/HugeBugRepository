- Try using beta.20, it might have been fixed already as there were changes to import behaviour since beta.15.

The `__webpack_require__.i` is supposed to ensure imported modules behave like ES6 modules, which includes adding a `default` key pointing to the module's contents if it's not flagged with `__esModule`. It could possibly be omitted if webpack knows the module is an ES6 module, though.
