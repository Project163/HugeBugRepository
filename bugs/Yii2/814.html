Title

strtolower function in BaseHtml corrupt UTF-8 strings

Description
### What steps will reproduce the problem?
use yii\helpers\Html;
//Get a Model
$model = Bild::find()->one();
$field= 'bild_groß_dateiname';
echo Html::getInputId($model, $field);

A solution would be the function mb_strtolower

### What is the expected result?
bild-bild_groß _dateiname
### What do you get instead?
