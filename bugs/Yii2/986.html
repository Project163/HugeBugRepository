Title

Validation error classes not applying to checkbox and radio when ActiveForm::$validationStateOn = self::VALIDATION_STATE_ON_INPUT

Description
### What steps will reproduce the problem?

In yii\widgets\ActiveForm::radio() and yii\widgets\ActiveForm::checkbox() methods, code: 

```php
if ($this->form->validationStateOn === ActiveForm::VALIDATION_STATE_ON_INPUT) {
	$this->addErrorClassIfNeeded($options);
}

$this->addAriaAttributes($options);
$this->adjustLabelFor($options);
```

should be at the beginning of those methods an not at the end. Otherwise input and label code is generated without particular css classes (ex. indicating error on those fields when 
ActiveForm::VALIDATION_STATE_ON_INPUT which is used on yii2-bootstrap4/ActiveForm).

### What is the expected result?

Validation flags to be applied to inputs.

### What do you get instead?

When using yii2-bootstrap4/ActiveForm we have no validation state for checkbox and radio inputs 

in yii2-bootstrap4/ActiveForm:
public $validationStateOn = self::VALIDATION_STATE_ON_INPUT 

but the yii\widgets\ActiveForm::radio() and yii\widgets\ActiveForm::checkbox() methods that are used generates the inputs code before setting particular flags and classes with the following code: 

```php
if ($this->form->validationStateOn === ActiveForm::VALIDATION_STATE_ON_INPUT) {
	$this->addErrorClassIfNeeded($options);
}

$this->addAriaAttributes($options);
$this->adjustLabelFor($options);
```
which is called after the input is generated
