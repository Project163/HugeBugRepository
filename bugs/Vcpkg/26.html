Title

MPG123 x64 port issue

Description

Opening the solution in VS(2015) and adding a x64 target, then building in VS works fine, but vcpkg does not perform this. Bulding on Windows 7 x64, en-US locale, VS2015 Update 3.

```
cl /I "..\.." /EP /TC "$(ProjectDir)..\..\..\..\src\libmpg123\synth_stereo_sse_s32.S" /nologo > "$(ProjectDir)..\libmpg123\Release\synth_stereo_sse_s32.asm"

```
that _sound_ x86 specific.
