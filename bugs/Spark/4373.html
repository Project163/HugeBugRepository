Title

CheckAnalysis rejects TPCDS query 32

Description
It seems the CheckAnalysis rule introduced by   SPARK-18504   is incorrect rejecting this TPCDS query, which ran fine in Spark 2.0. There doesn't seem to be any obvious error in the query or the check rule though: in the plan below, the scalar subquery's condition field is "scalar-subquery#24  (cs_item_sk#39#111 = i_item_sk#59)  ", which should reference cs_item_sk#39. Nonetheless CheckAnalysis complains that cs_item_sk#39 is not referenced by the scalar subquery predicates.
