Title

Docker provision not working correctly?

Description
When provisioning a box (using VB for provider) with Docker using this code: 

```
config.vm.provision "docker",
    images: ["debian:7.8"]
```

and running `vagrant up`, I'm getting this error: 

```
==> default: Running provisioner: docker...
    default: Installing Docker (latest) onto machine...
    default: Configuring Docker to autostart containers...
The following SSH command responded with a non-zero exit status.
Vagrant assumes that this means the command failed!
... [Log Snipped] ...
stdin: is not a tty
bash: line 2: stop: command not found
```

Running `vagrant reload --provision` then fixes the issue, but not sure why it doesn't work the first time.
Discussion
- Same problem here.
Did you find any solution?
- Which config.vm.box are you guys running?  I ran into this as well but switching from "puphpet/debian75-x64" to "ubuntu/trusty64" got rid of the issue. 
I haven't yet tried it with other images but Debian could be the issue here.

```
Vagrant.configure(2) do |config|
  # config.vm.box = "puphpet/debian75-x64" <--- stop docker error
  config.vm.box = "ubuntu/trusty64" # <--- no stop docker error

  config.vm.synced_folder "./", "/workspace"
... [Log Snipped] ...

end
```
