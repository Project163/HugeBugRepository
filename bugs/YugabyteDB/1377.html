Title

[DocDB] Table rewrite for DDL replication does not properly handle partitioned tables

Description
Jira Link: [Link: DB-15815]
### Description

Currently, the event trigger captures only the parent table, excluding subtables. As a result, replication is not properly reestablished for subtables and their dependent index tables.

To resolve this, we can use the parent table to retrieve the OIDs of its subtables and their index tables, ensuring proper replication setup.
