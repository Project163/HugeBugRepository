Title

Pundit 2.5.1 distribution missing file config/rubocop-rspec.yml

Description
**Describe the bug**
The 2.5.1 distribution does not include file `config/rubocop-rspec.yml`

**To Reproduce**
- `gem fetch pundit --version 2.5.1`
- `gem unpack pundit-2.5.1.gem`

Observe that `pundit-2.5.1/config/rubocop-rspec.yml` does not exist.

**Expected behavior**
The file should be present in the distribution as it is in previous versions.
