Title

v3: Fixture is created and initialized even if all tests using it are skipped

Description
In xUnit 2, when all tests are skipped (via `[Fact(Skip="Because...")]` or similar) a fixture that is used only by the skipped tests is not created or `IAsyncLifetime.InitializeAsync()`ed.

In xUnit 3 using MTP mode, when all tests are statically skipped in the same way (so not using `SkipUnless` or `SkipWhen`), the fixture used only by skipped tests is always created and `IAsyncLifetime.InitializeAsync()`ed.

I can collect more info and provide repro cases, but I thought I'd post the issue first in case it's by design. It's plausible that it's by design (certainly it makes sense that using `SkipUnless` or `SkipWhen` may always create+initialize the fixture).
