Title

Casting down iterable doesn't give the expected type

Description
`iterable` can't be cast to `array`, which should be valid:
[URL]

When `iterable` is cast to `Traversable`, it loses template types.

Example (https://psalm.dev/r/426c998c6e):
```
php
  $x
 * @psalm-suppress UnusedParam
... [Log Snipped] ...
assert($x instanceof Traversable);
takesTraversable($x);
```

Example output:
```
Psalm output (using commit 3f78082):

ERROR: InvalidArgument - 11:12 - Argument 1 of takesArray expects array , iterable  provided

ERROR: DocblockTypeContradiction - 12:5 - Cannot resolve types for $x - docblock-defined type iterable  does not contain array 
... [Log Snipped] ...

ERROR: MixedArgumentTypeCoercion - 25:18 - Argument 1 of takesTraversable expects Traversable , parent type Traversable provided
```
