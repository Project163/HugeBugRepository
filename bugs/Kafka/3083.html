Title

Consumer should not reset group state after disconnect

Description
When the consumer disconnects from the coordinator while a rebalance is in progress, we currently reset the memberId and generation. The coordinator then must await the session timeout in order to expire the old memberId. This was apparently a regression from  [URL] It would be better to keep the memberId/generation.
