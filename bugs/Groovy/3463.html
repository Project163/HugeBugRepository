Title

@WithReadLock in inner class of @CompileStatic class causes java.lang.VerifyError

Description
Minimal reproduction: 
  
 
 import  groovy.transform.CompileStatic
 import  groovy.transform.WithReadLock

@CompileStatic
 class  A {
     private   class  B {
        @WithReadLock
         int  getFoo() {
            0
        }
    }

     private  B b

    A() {
        b =  new  B()
    }
}

def a =  new  A()
