Title

`torch.cum{min,max}, torch.sort, argsort` do not check the `dim` when the input is 0-d tensor

Description
### 🐛 Describe the bug

`torch.cummin`, `torch.cummax`, `torch.sort` and `torch.argsort` do not check the `dim` when the input is 0-d tensor

```python
import torch
input = torch.rand([], dtype=torch.float64)
dim = 100
torch.cummin(input, dim)
# torch.return_types.cummin(
# values=tensor(0.8172, dtype=torch.float64),
# indices=tensor(0))
```

```python
import torch
input = torch.rand([1], dtype=torch.float64)
dim = 100
torch.cummin(input, dim)
# IndexError: Dimension out of range (expected to be in range of [-1, 0], but got 100)
```

### Versions

pytorch: 1.10.1
Discussion
- `torch.sort` also does not check `dim` when the input is 0-d tensor.
- This seems like a bug; we'd accept a PR fixing it.
- `sort` and `argsort` are already fixed. #143920 takes care of `cummin` and `cummax`
