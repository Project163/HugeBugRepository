**Reason**: packager.js will be started from wrong path.

- This issue occurs since Metro [Link: v0.47].

It happens when the the start command of the local-cli is not executed in the projectRoot directory e.g when you let Xcode start the packager for you. In this case, the cwd will be `${projectRoot}/node_modules/react-native`.

Some babel plugins such as [Link: babel-plugin-module-resolver] or [Link: babel-plugin-import-graphql] fail to resolve files because of it. They receive wrong filenames from Babel such as `${projectRoot}/node_modules/react-native/src/index.js` instead of `${projectRoot}/src/index.js`.

This issue doesn't occur if you start the packager yourself using `node node_modules/react-native/local-cli/cli.js start` from your projectRoot.

It comes from this [Link: line]. This script change the working directory to `${projectRoot}/node_modules/react-native` and start Metro from there. I think that it should cd into the projectRoot instead.
