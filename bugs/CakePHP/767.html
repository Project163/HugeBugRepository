## Fixture could not be created in SQL Server when using schema

CakePHP Version: 3.2.3
Platform and Target: IIS 7.5, SQL Server 2014, PHP 5.6
### What you did

I wrote a fixture with a different schema than 'dbo':

``` php
 public $table = 'factories.assign_components';
```

The table fixture could not be created, due to schema. Writing a fixture, without schema works as expected. The bug seems to be in `Cake\Database\Schema\SqlserverSchema::truncateTableSql`
### Expected Behavior

The method should generate a SQL like

``` sql
DBCC CHECKIDENT('factories.assign_components', RESEED, 0)
```

There sould be a single quote around the table name
### Actual Behavior

the generated query look like this:

``` sql
DBCC CHECKIDENT(factories.assign_components, RESEED, 0)
```

So the single quotes are missing around the table name. In SQL Server documentation (https://msdn.microsoft.com/de-de/library/ms176057%28v=sql.120%29.aspx) the single quotes for the table name are also used.
### Fix

Add single quotes to the query:

```
php

    /**
     * {@inheritDoc}
     */

    }
```
