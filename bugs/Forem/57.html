Title

Cannot remove a `cover_image` from a post

Description
**Describe the bug**

When editing a post, a user is able to upload an image and use the URL provided by the image uploader to add a cover image (by including `cover_image` in the post's front matter. However, if the user decides that they don't want that cover image anymore and wishes to remove it, removing the `cover_image` option from the front matter does not remove the cover image from the post or its preview.

**To Reproduce**

1. Create a post.
2. Upload an image, and copy the provided URL.
3. Go to the post's editor. In the front matter for the post, add a `cover_url:` option, and set the value as the copied link.
4. Save the post. You should see the cover image that you just added in the post's preview.
5. Now, go back to the post's editor, and remove the `cover_url:` option entirely, including the URL you pasted earlier.
6. Click on "preview" and look at the post; it will _still_ contain the cover image, even though you removed the option.
7. You can also test that the cover image was not removed by closing the tab and navigating back to the post (the cover image will still be there, even though the front matter will not contain a `cover_url` option).

**Expected behavior**

I would expect that once the `cover_url:` option is removed from the frontmatter, the post should no longer have a cover image.

**Screenshots**

As you can see from the screenshots, once you remove the `cover_url` option from the frontmatter, the image still remains on the post, but interestingly, its resolution/size seems to change... 🤔
