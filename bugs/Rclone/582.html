Title

arm-v7 is not a valid architecture for a debian package

Description
#### What is the problem you are having with rclone?

I am mirroring the deb files from the release to a local reprepro instance. I have almost all arches activated but in the latest release a file named [Link: rclone-v1.53.0-linux-arm-v7.deb] with the architecture of ``arm-v7`` got introduced. When I try to import the file I get the following error:
```
Error looking at 'timestamp/rclone-v1.53.0-linux-arm-v7.deb': 'arm-v7' is not one of the valid architectures: 'amd64 arm64 armhf i386 mips mipsel ppc64el s390x'
```

This error is easy for me to fix the in mirror script but it does not solve the underlying issue that debian has no arch which is named ``arm-v7``. Debian only has the following arm related arches: ``arm64``, ``armel`` and ``armhf``.

I am not sure if the rpm has the same problem but I assume it.
