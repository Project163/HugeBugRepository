Title

keyValueDiffer is sensitive to key order

Description
- **I'm submitting a ...**
- [x ] bug report

**Current behavior**
When you re-create the object used by ngStyle, depending on the properties order, changes may not be detected.

for example with a ngStyle set as follow : 

```
javascript
@Component({
    template: '  '
    ...
})
... [Log Snipped] ...
    style: { ... }
}
```

Doing this may work : 

``` javascript
update(){
   this.style = {
       height: '10px',
       width: '10px'
    }
}
```

while doing it like this may not : 

``` javascript
update(){
   this.style = {
      width: '10px',
      height: '10px'
   }
}
```

This exact example will probably work, this is just a quick representation of the problem.
You can find a (non) working minimal example [Link: here], file of interest is `src/layout.ts`.

**Expected/desired behavior**
The order should not matter and ngStyle should always update all keys (if different).
- **What is the motivation / use case for changing the behavior?**
  In my case the style object is returned by an external function that's why I'm re-affecting it instead of updating each properties.
- **Please tell us about your environment:**
- **Angular version:** 2.0.0-rc.1
- **Browser:** Probably all but at least  Chrome & Firefox
- **Language:** [TypeScript 1.8]
