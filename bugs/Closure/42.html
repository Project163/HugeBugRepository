Title

function call mis-optimized to method call

Description
Given
    (0, foo[i])('bar')
closure compiler optimizes this to
    foo[Link: i]

This is semantics breaking because now foo[i] is called with "this" being foo instead of the global object.

Consider the listener code below
  function EventDispatcher() {
    var listeners = [];
    this.addListener = function (listener) {
      listeners[listeners.length] = listener;
    };
    this.fire = function (event) {
      for (var i = 0, n = listeners.length; i < n; ++i) {
        (0, listeners[i])(event);
      }
    };
  }

Each listener now has access to all the other listeners violating EventDispatcher's ability to keep its privates private.
Discussion
- There is another instance of this problem.

Given
(function () {
    var x = foo[i];
    x('bar')
})()
closure compiler optimizes this to
    (function(){foo[Link: i]})();

This is semantics breaking in the same way as the latter if fire is rewritten to:

    this.fire = function (event) {
      for (var i = 0, n = listeners.length; i < n; ++i) {
        var listener = listeners[i];
        listener(event);
      }
    };
