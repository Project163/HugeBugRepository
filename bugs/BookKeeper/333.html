Title

Ledger fence state is lost when the ledger file is evicted

Description
we observed in our use case that when a ledger file is evicted before flushing. the fence state isn't persisted to disk, which would cause fencing doesn't work correctly.
Discussion
- The problem is when a file info is evicted from ledger cache, the bookie forgets to flush header of the file info which cause the fence bit lost. 

 The fix is pretty easy. Added a test case to reproduce this behavior.
