Title

Description
####  Feature request

Switch for turn off tools check

For example, lets say I want to do multiple replacements like so:

```
rg --passthru "!RE1!" "!file!" -or "!RP1!" |^
rg  --passthru "!RE2!" -or "!RP2!"  |^
...
rg  --passthru "!RE6!" -or "!RP6!"  |^
rg  --passthru "!RE7!" -or "!RP7!"
```
