Title

Should "x.root" validate as a domain name?

Description
The string "root" is currently included in INFRASTRUCTURE_TLDS with the comment: // diagnostic marker for non-truncated root zone 

 This means that domains such as "x.root" are allowed. 

 Is this correct?
Discussion
- If it's not in the IANA list of TLDs, than it is not correct IMHO.
- In that case, we should also remove "um" and "yu". 

 They are not in the file  [URL]

 However they are listed in  [URL] as "Not assigned" 

 There are lots of other such country codes which are in the HTML version but not the text version. 

 "root" is not in either of the above, though AFAIK it does have a single DNS entry, viz. vrsn-end-of-zone-marker-dummy-record.root
