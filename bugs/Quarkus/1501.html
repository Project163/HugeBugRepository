Title

resteasy-reactive: Wrong http status if return type is `Unit`

Description
### Describe the bug

A rest endpoint with return type `Unit` (Kotlin) results in http status 200 with an empty json object (application/json) instead of http status 204 if kotlin coroutines are used.

`Unit` should be treated like `void`

### Expected behavior

HTTP-Status 204

### Actual behavior

HTTP-Status 200

### How to Reproduce?

```
    @GET
    @Produces(MediaType.APPLICATION_JSON)
    suspend fun xyz() {
    }
```
