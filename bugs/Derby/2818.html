- The real error is hidden by the ClassCastException, which happens in an error handler in FormatIdInputStream.readObject(): 

 				ObjectInputStream ois = getObjectStream(); 
				try  
{
					Object result = ois.readObject();
					return result;
				}
  catch (IOException ioe)  
{
					setErrorInfo((ErrorInfo) ois);
					throw ioe;
				}

 The stream returned by getObjectStream() doesn't necessarily implement ErrorInfo. It doesn't in this case, and a ClassCastException is thrown. We're more interested in the IOException. 

 I changed the error handler to check the type of the ObjectInputStream before attempting to cast it, and then I got this exception instead:
