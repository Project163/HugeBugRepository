Title

Extension's errors during shutdown prevent ZAP to exit

Description
**Describe the bug**
ZAP does not terminate. I think it's a problem after installation of automation framework.

**To Reproduce**
1. Run ZAP (Installed automation framework / 0.4.1)
2. Click window close button or `Menu` > `File` > `Exit`. but not terminated.
3. See logs below.

**Expected behavior**
Terminated ZAP

 - Add-on: Automation framework 0.4.1

## Workaround if 0.4.0 is installed
1) Find your ZAP working dir (https://www.zaproxy.org/faq/what-is-the-default-directory-that-zap-uses/)
2) Remove automation framework 0.4.0 
```
$ rm -rf ~/.ZAP/plugin/automation-alpha-0.4.0.zap
```
3) Reboot ZAP, and install automation framework version 0.4.1
