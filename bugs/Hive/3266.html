Title

Support overriding memory configuration for AM launched for TempletonControllerJob

Description
The MR AM launched for the TempletonControllerJob does not do any heavy lifting and therefore can be configured to use a small memory footprint ( as compared to potentially using the default footprint for most MR jobs on a cluster ).
