Title

3.0 serialize paginated results to Xml

Description
I'm not sure if I'm actually doing pagination and serialization to Xml in CakePHP 3.0 right, but it's the way I would have done it in CakePHP 2.x, and I haven't seen any doco that says otherwise.

I'm trying to serialize paginated results using the XmlView.

My AuthorsController has 

```
public function index() {
    $authors = $this->paginate($this->Authors);
    $this->set(array(
        'authors' => $authors,
        '_serialize' => array('authors')
    ));
}
```

My AppController has 

```
public $components = array('RequestHandler');
```

my routes.php has

```
Router::mapResources('authors');
Router::parseExtensions(['xml']);
```

My calling URL has 

/authors.xml

The error and stack trace is


It looks like passing a ResultSet to be serialized via Xml doesn't work, however, doing JSON serialization does.

Maybe something needs to be done in XmlView::_serialize() to recognise that the referenced viewVar item is an object, and perhaps convert to an array, before passing to Xml::fromArray()
