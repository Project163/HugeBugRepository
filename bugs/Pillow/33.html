Title

ImageDraw.textsize zero length error

Description
### What did you do?
Attempted to get the `textsize` of an empty string ("")
### What did you expect to happen?
Returns a tuple which is the size of the text
### What actually happened?
Produced this error
```py
Traceback (most recent call last):
  File " ", line 1, in  
  File "/usr/local/lib/python3.6/site-packages/PIL/ImageDraw.py", line 263, in textsize
    return font.getsize(text, direction, features)
  File "/usr/local/lib/python3.6/site-packages/PIL/ImageFont.py", line 111, in getsize
    return self.font.getsize(text)
SystemError:  > returned NULL without setting an error
```
### What versions of Pillow and Python are you using?
Pillow 4.30
Python 3.6

I believe this can be traced to the latest 4.3 release and this commit: [URL]

The following code is producing the error: [URL]

In previous versions, the function would not error. If it's not intended to get the size of an empty string, maybe changing the behavior of [Link: `ImageDraw._multiline_split`] would fix the issue.

**Code**
```py
import PIL.Image, PIL.ImageDraw
i = PIL.Image.new('RGB', (2000, 1000))
d = PIL.ImageDraw.Draw(i)
d.textsize("")
```
