Title

flink-end-to-end-tests can fail silently

Description
Because they are written in bash and they are not setting 

  
 
set -e
 
  

 at the beginning, errors can be swallowed silently.
Discussion
- If we really must write those tests in bash, we should by default start all of the scripts with `set -e`.
- How about start scripts with `set -eo pipefail`. Errors can also be swallowed if `set -e` with pipeline, such as `a=$ [1/0] |b=2`.
