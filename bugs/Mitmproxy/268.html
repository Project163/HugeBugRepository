Title

Script in mitm-web won't unload

Description
#### Problem Description
We can't remove a loaded script in running mitm-web.
The scripts option for executing a script with mitm-web seems to have a bug.

Note: If we specify multiple scripts to be executed, then if we intend to remove them, one script remains present and cant be unloaded

#### Steps to reproduce the behavior:
1. In a running mitm-web instance, go to Options > Scripts > add path to script.
2. Try removing, the script, it won't remove. It simply says "no such script" even when removing.
3. Add more scripts. All can be removed except one.
