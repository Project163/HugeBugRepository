Title

QuarkusComponentTest in Gradle

Description
### Describe the bug

When creating an @QuarkusComponentTest within a Quarkus project that you build with Gradle you get an `IllegalStateException: Invalid test path`. 

```
java.lang.IllegalStateException: Invalid test path: /Users/peter/Development/heating-service/valve/build/classes/java/test/com/peterfortuin/heating/valveservice/pipelines/valveupdates/TemperatureRequestSenderTest.class
	at io.quarkus.test.component.QuarkusComponentTestExtension.initArcContainer(QuarkusComponentTestExtension.java:554)
	at io.quarkus.test.component.QuarkusComponentTestExtension.beforeAll(QuarkusComponentTestExtension.java:292)
	at org.junit.jupiter.engine.descriptor.ClassBasedTestDescriptor.lambda$invokeBeforeAllCallbacks$12(ClassBasedTestDescriptor.java:395)
	at org.junit.platform.engine.support.hierarchical.ThrowableCollector.execute(ThrowableCollector.java:73)
... [Log Snipped] ...
		at org.junit.platform.engine.support.hierarchical.NodeTestTask.lambda$executeRecursively$8(NodeTestTask.java:161)
		... 49 more
```

The problem is in QuarkusComponentTestExtension.java. The problem is with this part of the code:

```java
int targetClassesIndex = testPath.indexOf(TARGET_TEST_CLASSES);
// NOTE: continuous testing is not supported at the moment
if (targetClassesIndex == -1) {
    throw new IllegalStateException("Invalid test path: " + testPath);
}
```

Together with

```java
private static final String TARGET_TEST_CLASSES = "target/test-classes";
```

The code is looking if the path to the class with the testcode contains `target/test-classes`. This is true for Maven builds but not for Gradle builds. 

### Expected behavior

I expect to be able to use @QuarkusComponentTest to write component tests with Gradle als build tool and able to run them without the `IllegalStateException: Invalid test path`.
