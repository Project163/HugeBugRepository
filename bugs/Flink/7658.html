Title

IllegalStateException Causes Collect Sink to Fail to Collect Result

Description
When Flink jobs use the collect sink, the JobManager logs the following exception: 

   
  
 
ERROR org.apache.flink.runtime. rest .handler.job.coordination.ClientCoordinationHandler [] - Unhandled exception.
java.lang.IllegalStateException: No parameter could be found  for  the given class.  
  
 The root cause is that the HTTP URL for the ClientCoordinationHandler is incorrect.
