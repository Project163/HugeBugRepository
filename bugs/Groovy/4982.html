Title

Inherting the same Generic Interface at different levels in an inheritance hierachy causes error

Description
public   class  Testing {

     interface  TopLevel  extends  Comparable {
        void blah();
    }

     interface  NextLevel  extends  TopLevel, Comparable {

    }
}  
  
 Compiling this with @CompileStatic enabled results in this error 

  
 
org.codehaus.groovy.control.MultipleCompilationErrorsException: startup failed:
testdata/plugins/records/RecordTesting.java: 10: The  interface  Comparable cannot be implemented more than once with different arguments: java.lang.Comparable<java.lang. Object > and java.lang.Comparable
. At [10:5]  @ line 10, column 5.
        interface  NextLevel  extends  TopLevel, Comparable {
       ^  
  
 Not sure if this is expected behaviour. The error goes away if I extend Comparable<Object>
