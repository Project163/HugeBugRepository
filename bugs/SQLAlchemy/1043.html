Title

catch for str() in column proxy is not catching unsupported custom SQL constructs

Description
**Describe the bug**
We have update to sqlalchemy version 1.3.22 but now a custom compile function doesn't work anymore. Before it worked fine in 1.2.14.

I already debugged the issue and it seems while compiling the custom function, the dialect and/or bind get's lost and therefore sqlalchemy falls back to the default SQL string compiler which cannot compile the function (by purpose on my side).

**Expected behavior**
The custom compile function should work again.

```sql
SELECT anon_1."TableA_create_date" AS "anon_1_TableA_create_date", anon_1."TableA_create_time" AS "anon_1_TableA_create_time", anon_1."TableA_id" AS "anon_1_TableA_id", anon_1.create_timestamp AS anon_1_create_timestamp, "MappingTable_1".id AS "MappingTable_1_id", "MappingTable_1".value_a AS "MappingTable_1_value_a", "MappingTable_1".value_b AS "MappingTable_1_value_b" 
FROM (SELECT "TableA".create_date AS "TableA_create_date", "TableA".create_time AS "TableA_create_time", "TableA".id AS "TableA_id", datetime("TableA".create_date, "TableA".create_time) AS create_timestamp 
FROM "TableA" JOIN "MappingTable" ON "TableA".id = "MappingTable".value_a JOIN "TableB" ON "TableB".id = "MappingTable".value_b 
WHERE "TableB".base_value = ? AND "MappingTable".value_b = ? ORDER BY create_timestamp DESC
 LIMIT ? OFFSET ?) AS anon_1 LEFT OUTER JOIN "MappingTable" AS "MappingTable_1" ON anon_1."TableA_id" = "MappingTable_1".value_a ORDER BY anon_1.create_timestamp DESC
```
