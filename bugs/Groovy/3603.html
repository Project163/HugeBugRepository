Title

Anonymous inner class count is not local to enclosing type

Description
Consider the following: 
  
 
 class  C {
  def meth() {
     new   Object () {}  // C$1
      new   Object () {}  // C$2
      new   Object () {   // C$3
        String  toString() {
         new   Object () {}  // C$3$4 but expect C$3$1
       }
    }
     //  new   Object () {} here would be C$5 but expect C$4
   }
}
println  new  C().meth()
