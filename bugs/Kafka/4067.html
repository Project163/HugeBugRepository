Test failure: DefaultStateUpdaterTest.shouldGetTasksFromRestoredActiveTasks expected: but was:

 To reproduce the failure, you may clone this fork  [URL] and run `./gradlew :streams:test --tests DefaultStateUpdaterTest.shouldGetTasksFromRestoredActiveTasks` 

 The root cause of the issue is that function `DefaultStateUpdater::maybeCompleteRestoration` is not atomic.  

  
 
                 // This code will unblock the `verifyRestoredActiveTasks` in the test
                 addToRestoredTasks(task);

                 //If the test method resumes before the task is removed from `updatingTasks`, the test will fail.
                 updatingTasks.remove(task.id());
