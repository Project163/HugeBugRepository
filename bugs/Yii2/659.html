Title

MySqlMutex should apply useMaster() else it will not work as expected

Description
### What steps will reproduce the problem?
When in many db slaves environment, the MySqlMutex using "SELECT" which causing lock not applied

### What is the expected result?
Mutex not working as expected

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.x
| PHP version      | any
| Operating system | any
Discussion
- ```php
return (bool) $this->db->useMaster(function ($db) {
    return $this->db->createCommand('SELECT GET_LOCK(:name, :timeout)', [':name' => $name, ':timeout' => $timeout])
            ->queryScalar();
});
```
