Discussion
- This looks like Go has freed the memory but it hasn't been returned to the OS.

This can happen if the memory gets fragmented.

Things to try

`export GOGC=20` that will make the garbage collector work harder at the cost of more CPU.

`--use-mmap` causes rclone to allocate buffers directly from the os which it can completely free. 

`export GODEBUG=madvdontneed=1` this tells go to release memory to the OS more aggressively 

I'm not at my computer now so can't look at your trace but hopefully that will give you something to try
- Just FYI, the change requiring this was reverted in 1.16: [URL]

---

The only other relevant & relatively recent memory change in Golang is the THP handling: [URL]

You can try adding `GODEBUG=disablethp=1` to the runtime environment to revert that change and see if that improves things.
