- The patch! 

 This is due to the fact that LOCOGroup also maintains internal plan relations. The optimizer also has to fix up the downstream operator's internal.
- The similar issue can happen in type checker and plan optimizer (future) as well. In the meantime, this patch should work but we will have to come up with a guaranteed safe way to alter the plan. 

 For example, we may have utility methods for removing/inserting nodes in linear subgraph to start with:- 

 RemoveNode (a -> b -> c,  b)   -->  (a -> c)  

 InsertNode(a -> c, b)   -->   a -> b -> c
