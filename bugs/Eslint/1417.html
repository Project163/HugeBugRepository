### Extra information / motivation:

The `no-restricted-modules` works well when using regular single or double quoted strings as argument for `require` calls - it results in expected linting error then.

However `gatsbyjs/gatsby` repository uses `quotes` rule with `backticks` ( [URL] ) which automatically will turn all `require` call arguments to use backticks, which makes it so the `no-restricted-modules` rule is ineffective.
