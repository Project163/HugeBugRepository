Title

Lack of Spring `org.springframework.web.server.ResponseStatusException`

Description
**Describe the bug**
Spring proposes the `ResponseStatusException` to handle java exception in an HTTP-friendly manner.

When migrating to Quarkus, this class is not provided by the `quarkus-spring-web` compatibility extension.

**Expected behavior**
Being able to reuse a spring controller with the minimum of change 

**Actual behavior**
The code does not compile until replacing Spring `ResponseStatusException` by JAX-RS`WebApplicationException`
