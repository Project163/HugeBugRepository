Title

Disabling the cursor kills screen recorders

Description
I lock the mouse in my game:

`glfwSetInputMode(window, GLFW_CURSOR, GLFW_CURSOR_DISABLED);`

If I do this, I am unable to record the screen with QuickTime or iShowU HD.

If I don't lock the mouse, everything works fine.

Any ideas what might be the issue or any workarounds?
Discussion
- `GLFW_CURSOR_HIDDEN` appears to break it as well.
- This seems to be the culprit:

`[(NSCursor*) _glfw.ns.cursor set];`
- Aha. Here's the problem:

```
NSImage* data = [[NSImage alloc] initWithSize:NSMakeSize(1, 1)];
_glfw.ns.cursor = [[NSCursor alloc] initWithImage:data
                                          hotSpot:NSZeroPoint];
[data release];
```

If the size is changed to 16x16, it works.
