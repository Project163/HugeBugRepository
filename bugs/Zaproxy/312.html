Title

Exceptions during update of add-ons with dependents with optional Extensions

Description
### Describe the bug

This morning at 10:40 GMT we were using the zap2docker-stable image to successfully run zap scans, since about 12pm today ZAP has started to fail to find any urls in a file that hasn't changed since the previous successful run.

```
2023-03-03 12:52:08,736 Number of Imported URLs: 0
2023-03-03 12:52:08,736 Failed to import any URLs
Traceback (most recent call last):
  File "/zap/zap-api-scan.py", line 456, in main
    raise NoUrlsException()
NoUrlsException
```

### Steps to reproduce the behavior

1. Run a zap scan using the latest zap2docker image with an openapi spec with the following command:
`zap-api-scan.py -t ./api-spec.json -f 'openapi' -T 10 -c './config/zap.conf' -I -r 'zap_report.html'`
2. Observe the error above

### Expected behavior

The zap scan to complete successfully

`owasp/zap2docker-stable:latest`
