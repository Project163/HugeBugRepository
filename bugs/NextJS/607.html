Title

Catch-all Segment works as Optional Catch-all Segments inside the Parallel Route

Description
### Link to the code that reproduces this issue

[URL]

### To Reproduce

1. Create a Catch-all Segment inside a Parallel Route.
2. Render the parallel route without adding any additional parameters.

### Current vs. Expected behavior

Current behavior:
The content of the Catch-all Segment is not rendered because it should not match empty parameters.

Expected behavior:
The content of the Catch-all Segment is rendered, and the type of the catch-all parameter is `undefined`.
