Title

Kafka Acl documentation bug for wildcard '*'

Description
There is a Kafka Acl documentation bug for wildcard '*' in the  Examples . 

 The bug is when we run the below script in one folder which is not empty, we can not set ACL correctly. However, it works only the folder is empty. 

 We can find the scripts with wildcard '*' from the Kafka documentation. 

   
  
 
 // Adding Acls
 > bin/kafka-acls.sh --authorizer-properties zookeeper.connect=localhost:2181 --add --allow-principal User:Peter --allow-host   --producer --topic * 

 // List Acls
 > bin/kafka-acls.sh --authorizer-properties zookeeper.connect=localhost:2181 --list --topic * 
  
   

 Reproduce the issue: 
 
	 Create a file foo.txt under an empty folder 
	 Run the script to add an acl by using the wildcard resource '*' 
	 We can find the resource name is 'foo.txt'. Not wildcard '*'
