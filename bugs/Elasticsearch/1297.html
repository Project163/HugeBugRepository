Title

can't bind to all interfaces with some docker configurations?

Description
At least in one of our jenkins servers we have:

```
docker0
        inet   netmask:  broadcast:  scope:site
        hardware 56:84:7A:FE:97:99
        MULTICAST mtu:1500 index:3
```

Is this normal? The fact it has a broadcast address like that (which looks totally bogus), means that if the user configures  , we will fail. I can fix the logic to deal with it in several ways (the interface is not marked up, we can not do the check explicitly for a wildcard address) but if anyone understands this I'd love to know why this docker interface looks like that.
