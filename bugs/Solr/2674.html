Title

Dead link to replicas in AngularUI

Description
Dead link to shard replica admin UI - missing # in URL. 

 Reproduce: 
 
	 Start Solr in cloud mode  bin/solr start -e cloud -noprompt  
	 Go to Angular UI, collection overview: 
    [URL]
	 For one of the shards, expand one of its replicas 
	 Click the core name, e.g. 
    [URL]
 

 This link is not valid. It should have had a  #  after  solr/  

 Another issue is that it points to the OLD UI, perhaps it should stay in the new?
Discussion
- Good observations. 

 I've hit that issue a couple of times - where the UI is not "self-aware" and thus redirects to the old one when jumping between nodes. The cloud tab suffers from the same issue. What we could do is centralise the config for the root UI path (/index.html) such that we can easily change it when we change URLs. 

 We should, of course, add the # as you mention, too!
- The patch is simple in  collection_overview.html  
  
 <dt>Core: </dt><dd><a href= "{{replica.base_url}}/index.html#/{{replica.core}}" >{{replica.core}}</a></dd>
 
  
 But probably worth it to centralize the full root path!
