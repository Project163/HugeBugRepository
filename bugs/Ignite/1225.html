Title

Support node restarts in new SQL (IgniteCacheQueryNodeRestartSelfTest)

Description

    
Discussion

    
- Uncomment IgniteCacheQueryNodeRestartSelfTest when fixed
- Implemented retry loop with the following logic: 
If topology is unstable then try to find all the needed partitions in OWNING state at any nodes and send explicit list of partitions to remote nodes. Otherwise assume that we can send only a topology version and remote nodes will reserve only primary partitions. If some partition can't be reserved retry message is sent back. Retry also happens when data node leaves topology. 

 Because reserving many partitions for each query slows things down pretty much, was implemented grouped reservation mechanism allowing to reserve all the primary partitions for topology version in one operation.
- Reviewed with Yakov, merged.
