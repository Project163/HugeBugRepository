Title

Allow to generate code for files outside of `rootDir` (e.g. in node_modules)

Description
With current ng5 we don't generate code for libraries outside of `rootDir`.

We should implement this properly (e.g. so that this also work in watch mode, ...).

Algorithm for mapping path to rootDir:
- take common prefix from path and rootDir
- count all `..`
- produce path `rootDir/dotDotCount/suffix`

It is important that the generated path can be mapped back to the original file without extra caches, ... as TS might ask for generated files directly when passing an oldProgram, without looking at the base file first.
Discussion
- Note that this is non trivial, as we drive the generated path of a file from the path of the file in several places in Angular.
- We determined that it's works as intended that we don't generate code for files outside of `rootDir`.
