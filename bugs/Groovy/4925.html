Title

STC: element type of enum class

Description
Consider the following: 
  
 
@TypeChecked test() {
   for  (ts  in   Thread .State) {
    println  "${ts.ordinal()}: ${ts.name()}" 
  }
}
 
  

 Without STC, this runs and prints out the enum values of  Thread.State .  With STC, it errors on "ts.name()" and "ts.ordinal()".
