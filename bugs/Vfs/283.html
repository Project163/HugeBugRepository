Discussion
- I wonder whether it should derive the username from the system or throw an appropriate exception. I wonder also why the username is a char array at all.
- One can/should use char[] for credentials instead of String to avoid problems like String's being interned dumped/captured, you can't intern a char[]. char[] toString() also removes the chance of credentials being revealed in logs as opposed to String.toString().
- ... [Middle Discussions Snipped for Brevity] ...
- It would be nice to have some explanation, how to specify username for SFTP connection. I think this explanation can be added to exception message text.
- I do not think exception messages should become programming guides, that's a job for Javadoc comments IMO.
