Title

Add symlink support to LocalFileSystem on Windows

Description
Multiple test cases are broken. I didn't look at each failure in detail. 

 The main cause of the failures appears to be that RawLocalFS.readLink() does not work on Windows. We need "winutils readlink" to fix the test.
Discussion
- This test is exposing a Java 1.6 bug on Windows when trying to rename a symlink. Attached a minimal repro to demonstrate the JVM bug.
