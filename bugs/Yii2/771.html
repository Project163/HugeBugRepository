Title

DynamicModel should support check dynamic property.

Description
### What steps will reproduce the problem?

Create an object of DynamicModel with dynamic attributes. Need to check attribute exist because it is `dynamic`, i use method `hasProperty` to check but currently it is not support.

### What is the expected result?

`hasProperty`, `canGetProperty`, `canSetProperty` methods should be return `TRUE` when check.

### What do you get instead?

`hasProperty`, `canGetProperty`, `canSetProperty` methods return `FALSE` when check.

### Additional info

Should we override  `canGetProperty`, `canSetProperty` to check an attribute dynamic exist?
