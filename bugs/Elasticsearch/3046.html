Title

`pre_tags` and `post_tags` params not validated for empty values

Description
`pre_tags` and `post_tags` query parameters for highlighting are not validated of empty values.
As a result if a query sets them to an empty array we get an ArrayOutOfBoundsException:

```
{
  "query" : {
    "match" : {
      "field1" : "fox"}
    }, 
... [Log Snipped] ...
    }
}
