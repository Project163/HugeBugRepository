Title

[YSQL] [Transactional DDL] ERROR: Transaction is already in progress - with temporary table and ON COMMIT DELETE ROWS

Description
Jira Link: [Link: DB-16810]
### Description

Steps to reproduce:

```
CREATE TEMPORARY TABLE p (
    a INT PRIMARY KEY
) ON COMMIT DELETE ROWS;

INSERT INTO p VALUES (1);
 -- Fails with ERROR: Transaction is already in progress
```
