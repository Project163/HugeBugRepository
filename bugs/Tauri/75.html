Title

API example doesn't open new window when button clicked (crashes on `--release`)

Description
**Describe the bug**
API example crashes when clicking "New Window" in a release build. Debug builds generate the same error, but does not crash the window.

**To Reproduce**
1. Check out latest dev (  at the time of writing)
2. Run `cargo run --bin api` (release and backtrace optional)
3. Click the "Window" tab on the left side
4. Click "New window" button
5. See backtrace and no new window (or crash if running release).

**Expected behavior**
A new window to open.

**Platform and Versions (please complete the following information):**
OS: `5.12.10-arch1-1 x86_64 GNU/Linux`
Rustc: `rustc 1.52.1 (9bc8c42bb 2021-05-09)`
