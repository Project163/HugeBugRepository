Title

Improve Global Changes's "Time" column formatting

Description
Right now the "time" column of "global changes" report is of (very narrow) fixed length, resulting in date being split into 4 lines, regardless of the window's width.
[Image: image]

Expected behavior:
"Time" info spans into a single line (or at least 2 lines: date and time) if enough window width is available.
### Version Information

Syncthing Version: v0.14.19
OS Version: Windows 10 x64
Discussion
- Where did you get the info, that this column has a fixed width. There is no fixed width in the code.
You probably have a path with to many unbreakable characters, so the path column get wider and the time column shrinks to make space.
The path cell should be set to even break within words. (CSS `word-break: break-all;`). But in my experience browser than prefer to break within words, even if there are breakable characters and even if the resulting line count would be the same. That would mean ugly breaks for all of us, even if we don't need them.
