- I'm using tauri 1.x and could not get the close request event to fire using any of the tauri api, so I found a work around:

Add this to your javascript side (mac):

```js
 window.addEventListener('keydown', (e) => {
    if (e.key === 'q' && e.metaKey) {
      e.preventDefault();
      // do some pre-closing stuff...
    }
  });
```

Works on the main window, should work on dynamically created ones too. The browser is good at interrupting keys if you let it.
- **Tauri 2.0**
for those who encounter the similar problem:
1. check your permission, make sure you can destroy and close
```
{
  "$schema": "../gen/schemas/desktop-schema.json",
```

2. import the right function, all AI helper such as chagpt, deepseek or gemini are wrong.
```
import { Window } from '@tauri-apps/api/window';//attention captital W
const appWindow = new Window('main'); // you can specify the window by label , setting in tauri.conf.json
appWindow.onCloseRequested((event) => {
   //do your stuff such as clear data before close window or destroy window
});
```
