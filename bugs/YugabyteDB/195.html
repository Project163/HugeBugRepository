Title

remote bootstrap stuck for a table with "Command is greater than read buffer" error

Description
With the recent change to allow a rate limit on remote bootstraps (https://github.com/YugaByte/yugabyte-db/issues/428), seeing this error on remote bootstrap on a cluster with large tablets, and one tablet was stuck in TABLET_DATA_COPYING mode.

{code}
W0909 06:36:08.415642 105404 tcp_stream.cc:91] { local:  :36173 remote:  :9100 }: Shutting down with pending inbound data (size: 267133381, limit: 267386880, status = Invalid argument (yb/rpc/connection.cc:242): Command is greater than read buffer)
{code}

Increasing the `--rpc_max_message_size` flag on the TServer receiving the tablet helped as a temporary workaround.
