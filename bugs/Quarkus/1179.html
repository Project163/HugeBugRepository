Title

Resteasy Reactive ExceptionMapper for, e.g., ClientErrorException has no active request scope

Description
When using a ExceptionMapper  which is RequestScoped or uses other RequestScoped beans,
following error occurs:

ERROR [org.jbo.res.rea.com.cor.AbstractResteasyReactiveContext] <> (vert.x-eventloop-thread-2) Request failed: javax.enterprise.context.ContextNotActiveException

This is easily reproduced with provoking a 405 on a jaxrs endpoint.

This happens with quarkus-resteasy-reactive and quarkus 2.0.0.Final.

This seems to also happen for WebApplicationException.

This used to work with Quarkus 1.12.0 and normal resteasy.
