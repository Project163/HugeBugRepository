Title

When performing variable substitution, fileinstall throws an exception if there is a start or stop delimiter without the other one

Description
This is a real problem as there is no way to escape the delimiters currently. 
I think silently discard any malformed substitution would be much better, else any value containing a '}' will cause the config to not be loaded at all.
