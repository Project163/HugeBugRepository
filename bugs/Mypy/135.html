Title

Ordering issue with processing class definitions

Description
This is I think another variant of #1151 but reporting since the fix may be different.

```
$ mypy --py2 --silent --implicit-any ~/foo.py
/home/tabbott/foo.py: note: In member "foo" of class "S":
/home/tabbott/foo.py:5: error: Cannot determine type of 'X'
```

For this code:

```
class S(object):
    def foo(self):
        return R.X

class R(object):
    X = 2
```
