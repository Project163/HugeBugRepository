Title

Precision error in interpolateZoom

Description
Hello,

For some input, `interpolateZoom` gives `NaN`s, because of precision problems.

[URL]

As far as I understand, the root of the problem is that the corner-case formula is only used when the xy coordinates of the inputs are exactly the same, but there occurs a rounding problem in `Math.log(Math.sqrt(b0 * b0 + 1) - b0)` when they are nearly the same.
Discussion
- I use a workaround now:

```
  if (d1 < 0.00001) {
    dr = NaN;
  }
```

Like this:

```
d3.interpolateZoom = function(p0, p1) {
  var ux0 = p0[0], uy0 = p0[1], w0 = p0[2], ux1 = p1[0], uy1 = p1[1], w1 = p1[2];
  var dx = ux1 - ux0, dy = uy1 - uy0, d2 = dx * dx + dy * dy, d1 = Math.sqrt(d2), b0 = (w1 * w1 - w0 * w0 + ρ4 * d2) / (2 * w0 * ρ2 * d1), b1 = (w1 * w1 - w0 * w0 - ρ4 * d2) / (2 * w1 * ρ2 * d1), r0 = Math.log(Math.sqrt(b0 * b0 + 1) - b0), r1 = Math.log(Math.sqrt(b1 * b1 + 1) - b1), dr = r1 - r0;
  if (d1 < 0.00001) {
    dr = NaN;

  return interpolate;
}
```

With this I couldn't reproduce the NaN's. However, I don't know whether this will disturb the normal zoom-and-pan behaviour.
- Probably it would be sufficient to change the `if (dr) {` in the interpolate function to `if (dr > ε) {`.
