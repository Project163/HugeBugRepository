Title

enableObjectReuse fails when an operator chains to multiple downstream operators

Description
Given a topology that looks like this: 

  
 DataStream<A> input = ...
input
    .map(MapFunction<A,B>...)
    .addSink(...);

input
    .map(MapFunction<A,C>...)
    ​.addSink(...);
 
  

 enableObjectReuse() will cause an exception in the form of  "java.lang.ClassCastException: B cannot be cast to A"  to be thrown. 

 It looks like the input operator calls  Output<StreamRecord<A>>.collect  which attempts to loop over the downstream operators and process them. 

 However, the first map operation will call  StreamRecord<>.replace  which mutates the value stored in the StreamRecord<>.   

 As a result, when the  Output<StreamRecord<A>>.collect  call passes the  StreamRecord<A>  to the second map operation it is actually a  StreamRecord<B>  and behaves as if the two map operations were serial instead of parallel.
Discussion
- After attempting to produce a minimal repro, I realized that there needs to be an operation between the source and the parallel maps: 

  
 DataStream<A> input = ...

input = input
    .map(MapFunction<A,A>...);

input
    .map(MapFunction<A,B>...)
    .addSink(...);

input
    .map(MapFunction<A,C>...)
    ​.addSink(...);
 
  

 see attached repro case
- I was able to fix this for my topology and the test case by making a very small change to  ChainingOutput<T>.collect()  in OperatorChain.java. 

 When object reuse is disabled  CopyingChainingOutput<T>.collect()  is used to make a full copy of the  StreamRecord<T> : 
  
 StreamRecord<T> copy = record.copy(serializer.copy(record.getValue()));
 
  

 If object reuse is enabled,  ChainingOutput<T>.collect()  is used instead.  As the internal code will mutate  StreamRecord<>  downstream, I thought the best "good-faith" effort to support object reuse was to copy the  StreamRecord<>  without copying the value sending this lighter copy downstream instead of the original  StreamRecord<> : 
  
 StreamRecord<T> shallowCopy = record.copy(record.getValue());
