Title

Attributes equals now is order sensitive

Description
Hi,

while updating to latest JSoup version I got unit test failing because `Attributes` equals implementation changed.
I believe it is a bug as the javadoc says:

As a simple test:
```java
final Attributes attributesBarFoo = Jsoup.parseBodyFragment(" ").select("a").first().attributes();
final Attributes attributesFooBar = Jsoup.parseBodyFragment(" ").select("a").first().attributes();
assertEquals(attributesBarFoo, attributesFooBar);
```
results in
```
org.opentest4j.AssertionFailedError: 
Expected : style="bar" class="foo"
Actual   : class="foo" style="bar"
```
