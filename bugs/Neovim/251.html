Title

view unexpectedly altered when 'winminheight' is 0

Description
- `nvim --version`: NVIM v0.5.0-116-g4f4f5ef4f
 - `vim -u DEFAULTS` (version:  8.1 Included patches: 1-2231) behaves differently? Yes
 - Operating system/version: Ubuntu 16.04.6 LTS
 - Terminal name/version: XTerm(322)
 - `$TERM`: xterm-256color

### Steps to reproduce

Run this shell command:

    nvim -Nu NONE +'set wmh=0 | au WinEnter * wincmd _' +'sp|$' <(curl -Ls [URL]

Then, press `C-w w` twice.

### Actual behaviour

The view of the top window has changed. Before pressing `C-w w` twice, the topline was `252` (output of `:echo getwininfo()[0].topline`); now it's `281`.

[Image: gif]

### Expected behaviour

The view is preserved; i.e. the topline stays the same.

### Additional information

In Vim, the view is preserved:

[Image: gif]

---

If `'winminheight'` is set to a value different than 0, the view is preserved.

- Ah no, I was wrong, `-Nu NORC` does not fix the issue; it only fixes it for the top window.

If you run the same command as in the OP, and only replace `-Nu NONE` with `-Nu NORC`:

    $ nvim -Nu NORC +'set wmh=0 | au WinEnter * wincmd _' +'sp|$' <(curl -Ls [URL]

Then, if you press `C-w w` to focus the bottom window, `G` to move on the last line, and finally press `C-w w` twice to focus the top window and come back to the bottom window, the view has – again – been altered.

@bfredl I can't fix the issue because I don't know C/lua, but if you need someone to test a patch which tries to fix it, let me know.
- For anyone having the same issue, this is how I handle it at the moment:

    augroup fix_winline
        au!
        au WinLeave * if !get(g:, 'SessionLoad', 0)
            \ | let w:fix_winline = {'winline': winline(), 'pos': getcurpos()}
            \ | endif
        au WinEnter * au CursorMoved * ++once call s:fix_winline()
    augroup END
    fu s:fix_winline() abort
        if !exists('w:fix_winline') | return | endif
        if getcurpos() != w:fix_winline.pos
            call setpos('.', w:fix_winline.pos)
        endif
        let offset = w:fix_winline.winline - winline()
        if offset == 0 | return | endif
        exe 'norm! '..abs(offset)..(offset > 0 ? "\ " : "\ ")
    endfu

If I find issues in the code, I'll update it [Link: here].
