Title

TimeLimitingBulkScorer not used anymore for queries with limits

Description
After Lucene 10 upgrade (  SOLR-17631  ) it's very likely that query limits are not enforced in this collector, due to the Lucene API change and the commented-out method in  SolrIndexSearcher.search(List<LeafReaderContext> leaves, Weight weight, Collector collector) . 

 Unfortunately there were no unit tests in Solr to specifically target this code execution path - the existing tests related to  QueryLimits  are either too synthetic or simulate timeouts in other components.
