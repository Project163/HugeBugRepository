Title

FaultmediatorFactory does not recognize the the output generated by fault mediator serializer

Description
Following issue was observed when serializing fault mediator. 

 I inserted following element in to makefault mediator of the synapse configuration. 

  <code value="tns:Receiver" xmlns:tns="[URL]

 When serializing it, the following was generated. 

 <code value=" 
{[URL]
 Receiver"/> 

 This  serialized output does not pick up by the fault mediator factory.
Discussion
- FaultMediatorSerializer was just calling the toString method of the value attribute of the code element, which is a QName. Now it is changed to serialize this with the  
{prefix}
 : 
{localPart}
  and declare the namespace with the prefix. To do this I had to modify the Factor to take build the QName with the specified prefix.
