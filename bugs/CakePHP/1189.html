Title

MissingActionException results in multiple warnings "Undefined variable ..." in the default error template `Error/missing_action.php`

Description
### Description

When a `MissingActionException` is thrown, the default error template `Error/missing_action.php` (which is used in debug mode) results in multiple warnings `Undefined variable`:

``` 
Warning (2): Undefined variable $class [in /myapp/vendor/cakephp/cakephp/templates/Error/missing_action.php, line 67]
Warning (2): Undefined variable $action [in /myapp/vendor/cakephp/cakephp/templates/Error/missing_action.php, line 67]
Warning (2): Undefined variable $type [in /myapp/vendor/cakephp/cakephp/templates/Error/missing_action.php, line 73]
Warning (2): Undefined variable $baseClass [in /myapp/vendor/cakephp/cakephp/templates/Error/missing_action.php, line 75]
Warning (2): Undefined variable $class [in /myapp/vendor/cakephp/cakephp/templates/Error/missing_action.php, line 77]
Warning (2): Undefined variable $extends [in /myapp/vendor/cakephp/cakephp/templates/Error/missing_action.php, line 77]
Warning (2): Undefined variable $action [in /myapp/vendor/cakephp/cakephp/templates/Error/missing_action.php, line 80]
```

Because of the undefined variables, the view does not show any details about the exception.

I was able to reproduce this behaviour in a completely new app by using:

```
composer create-project --prefer-dist cakephp/app:5 myapp
bin/cake bake controller Test
```
