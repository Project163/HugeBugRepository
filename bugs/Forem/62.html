Title

Project setup: Database seeding fails

Description
**Describe the bug**

I was trying to setup my development environment and ran into an issue while executing `rails db:setup`. The issue appears to be in the seeding code, one of the methods is being called on a `nil` class, which is causing the seeding process to fail.

Facing the same issue on GitPod as well.

 

**To Reproduce**

1. Clone the project and perform initial config setup
2. Run `bin/setup`

OR

1. Drop the database by running `rails db:drop`
2. Recreate database by running `rails db:setup`

By following any of the above approaches, you should see an error message as stated below.

