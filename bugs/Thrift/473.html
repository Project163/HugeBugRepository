Title

using 'using' to disambiguate between functions in different bases does not conform to C++ standard and will not compile on certain compilers

Description
Currently in transport/TBufferTransports.h three classes have code of the form 

  using TBufferBase::readAll;  

 This code is attempting to disambiguate between the readAll function provided by TBufferBase and TVirtualTransport < T, TBufferBase >. This compile and works under GCC. However, this does not conform to the C++ standard. Other compilers(such as Comeau) will report compilation errors because of this code. Here is a related bug filed with gcc:  [URL]

 I am attaching a patch that explicitly declares readAll and implements it by calling TBufferBase::readAll.
