Title

ArrayHelper::toArray() not passing $recursive to Arrayable::toArray()

Description
If you pass an Arrayable object into yii\helpers\ArrayHelper::toArray(), the $recursive argument should be passed on to the object’s toArray() method, but it’s not.

Example:

```
php
class Foo extends \yii\base\Model
{
    public $date;
}
... [Log Snipped] ...
$fooArray = \yii\helpers\ArrayHelper::toArray($foo, [], false);
\yii\helpers\VarDumper::dump($fooArray, 10, true);
```

Expected result (and what `$foo->toArray([], [], false)` will give you):

```
[
    'date' => DateTime( ... )
]
```

Actual result:

```
[
    'date' => [
        'date' => '2015-03-17 10:45:58.000000'
        'timezone_type' => 3
        'timezone' => 'America/Los_Angeles'
    ]
]
```
Discussion
- it's expected behavior - toArray prepare data `to array` - why u expect 'data' => $object?
recursice work with inner objects
- @lynicidn Are you saying you don’t think that this should be true for Arrayable objects?

``` php
$object->toArray([], [], $recursive) === ArrayHelper::toArray($object, [], $recursive)
```

(That test is true when $recursive = true, but not when $recursive = false.)

Maybe I’m missing something, but considering ArrayHelper::toArray() actually calls the Arrayable object’s toArray() method internally (if it is one), and considering that they both have “$recursive” arguments, expected behavior for me was that they would both behave the same when $recursive = false.

Currently I’m doing the following workaround (until my patch makes it in):

``` php
if ($object instanceof Arrayable) {
    $arr = $object->toArray([], [], false);
} else {
    $arr = ArrayHelper::toArray($object, [], false);
}
```

I certainly hope I can simplify that to this line when Yii 2.0.4 comes out:

``` php
$arr = ArrayHelper::toArray($object, [], false);
```
