Title

Tests fail after 2024-06-07

Description
Output of `helm version`: 3.14.2

While working on [Link: reproducible builds] for [Link: openSUSE], I found that our `helm-3.14.2` package stops building soon, because tests fail after 2024-06-07.

Background:
As part of my work on reproducible builds for openSUSE, I check that software still gives identical build results in the future.
The usual offset is +16 years, because that is how long I expect some software will be used in some places.
This showed up failing tests in our package build.
See [URL] for why this matters.

In this case, [URL] contains expiring .crt files.
There is also `testdata/crt.pem` that will expire in 2032.

There are at least two possible approaches to solve this:
* generate test .crt files at time of test, so they are always fresh
* use static test .crt files that expire in the far future, e.g. in 2999.
