Title

Sometimes indexes for some folders aren't sent after starting Syncthing

Description
There's a race between receiving the cluster config from the remote, which should start sending indexes, and the folder being started: If the CC arrives before the folder is started, we abort processing the CC and no indexes are sent until a new CC arrives (usually until a reconnect).
