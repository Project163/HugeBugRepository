Title

Runtime error when using `bevy_winit` feature without explicitly adding `bevy_window`

Description
## Bevy version

`0.15`. This issue appeared at some point during the RC process. LIkely [URL]

## What you did

```
toml
[dev-dependencies.bevy]
version = "0.15"
default-features = false
features = [
... [Log Snipped] ...
    "x11",
]
```

And start an app using `DefaultPlugins` that creates a window.

## What went wrong

App immediately crashes with this error, which is produced by a system outside of my app / inside of Bevy.

`
Resource requested by (bevy_ecs::system::commands::Commands, bevy_ecs::system::query::Query ), bevy_ecs::query::filter::Added >, bevy_ecs::event::writer::EventWriter , bevy_ecs::change_detection::NonSendMut , bevy_ecs::change_detection::NonSendMut , bevy_ecs::change_detection::ResMut , bevy_ecs::change_detection::Res , bevy_ecs::change_detection::Res ) does not exist: bevy_ecs::event::collections::Events 
`
Discussion
- `bevy_winit` should have a required dependency on `bevy_window`.

For users hitting this now, add `bevy_window` to your features list for `bevy` to fix the error.
