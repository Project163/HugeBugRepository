Title

issue: validatingFields includes "undefined" as field name

Description
### Version Number

7.51.0

### Codesandbox/Expo snack

[URL]

### Steps to reproduce

1. Load sandbox and watch state output above the form
1. validatingFields includes "undefined" as a validating field name
1. this is caused by the `trigger()` call inside the `useEffect` callback

### Expected behaviour

Not sure if this is intentional or if I am doing something wrong here. But I came across this in my current application after updating to the newest version 7.51.0 which introduced this field. 

The issue in my code was that `isValidating` has never been reset to false. I solved it in my app but might lead to other bugs elsewhere if the `"undefined": true` bit is added unintentionally.
