Title

Cooperative spilling should check consumer memory mode

Description
In TaskMemoryManager.java: 
  
  for  (MemoryConsumer c: consumers) {
   if  (c != consumer && c.getUsed() > 0) {
     try  {
       long  released = c.spill(required - got, consumer);
         if  (released > 0 && mode == tungstenMemoryMode) {
          got += memoryManager.acquireExecutionMemory(required - got, taskAttemptId, mode);
           if  (got >= required) {
             break ;
          }
        }
      }  catch (...) { ... }
    }
  }
}
 
  
 Currently, when non-tungsten consumers acquire execution memory, they may force other tungsten consumers to spill and then NOT use the freed memory. A better way to do this is to incorporate the memory mode in the consumer itself and spill only those with matching memory modes.
