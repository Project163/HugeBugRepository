Title

Discover doesn't work on Windows

Description
The whole discover package doesn't work on Windows.
There are at least two problems:
- It isn't currently possible to get the netmask or the broadcast, because it is not possible to make a type assertion from `type Addr` to `*net.IPNet` in Windows. `*net.IPAddr` can be used but doesn't provide enough information.
- `*UDPConn.WriteMsgUDP` returns `0, 0, address family not supported`. It seem that this function is not implemented on Windows. See [URL] (line 145) and [URL] (end of file), but I might be missing something.
