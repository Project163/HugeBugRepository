Title

Create parent directory of specified cacheResultFile when it doesn't exist

Description
| Q                   | A
| --------------------| ---------------
| PHPUnit version     | 7.4.3
| PHP version         | 7.1.22
| Installation Method | Composer

Not sure if this is a problem we want to have, but when specifying a cache result file which is located in a subdirectory, can we by any chance create the subdirectory when it doesn't exist?

I'm running into this issue in combination with `infection/infection`. That is, while I create the directory containing the result cache myself before running tests, there is no problem. The problem arises when running `infection`, as it creates a configuration in temporary directories, and there the subdirectory does not exist. 

This seems like it could be handled either in `infection/infection`

The creation of that subdirectory could be both handled by `infection/infection` and `phpunit/phpunit`, but maybe it's better handled `phpunit`, what do you think?
