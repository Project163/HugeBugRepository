Title

Tag interpolation inside filter text?

Description
I am having tag interpolation being parsed inside filter text? Is this supposed to be happening?

For example, the following pug:

```pug
:test
    | test #[span this].
```

results in the test filter receiving `| test .` and the rendered output being the same (if the filter is just a pass through function. Ex: `function testFilter(value){ return value; }`).

Would this be a bug?
Discussion
- Normal interpolation is handled the way I would expect:

```pug
:test
    | test #{test}.
```

The filter received `| test #{test}.`.

And this is with pug@2.0.0-beta6.
- Yes, I think this is a bug.  `#[...]` style interpolation should probably just be ignored inside filters.
- ... [Middle Discussions Snipped for Brevity] ...
- I agree, we should just consider this a breaking change.

Currently I can't think of any cases where we'd want to enable one but not the other.
- should be fixed in pug@2.0.0-beta11
