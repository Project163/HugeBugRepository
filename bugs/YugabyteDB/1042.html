Title

[DocDB] Under-replicated tablets endpoint does not take into account placement info or tablet state

Description
Jira Link: [Link: DB-6951]
### Description

The under-replicated tablets endpoint (`/tablet-replication`) does not currently take into account placement info for tables (i.e. how many replicas they should have in each zone, whether the tablet is in a read replica or a live cluster), or the state of the tablets (e.g. RUNNING vs BOOTSTRAPPING).
