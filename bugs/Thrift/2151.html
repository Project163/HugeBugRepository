Title

Incorrect namespaces for included types

Description
Fully qualified references to imported types are not treated corectly if a namespace part starts with uppercase letters. This is illegal in Haxe. The attached test case shows this at the "Broken" service method, which is not compileable. 

 Expected behaviour is, that the name gets converted in the exact similar way as the "package" statement at the top of the file.
