Title

Index(postgresql_using='TYPE') wraps index type in extra quotes if it's uppercase

Description
For the PostgreSQL dialect, `Index()` takes a `postgresql_using=` parameter to specify the index type. However, the generated SQL is wrong if the parameter value is uppercase:
```
from sqlalchemy import create_engine
from sqlalchemy.ext import declarative
from sqlalchemy.schema import CreateTable, CreateIndex
from sqlalchemy.sql import schema, sqltypes

... [Log Snipped] ...
for index in MyTable.__table__.indexes:
    print(CreateIndex(index).compile(engine))
```

This produces the SQL:
`CREATE INDEX my_index ON my_table USING "BTREE" (some_column)`
which is invalid because `"BTREE"` is quoted.

However, if we change it to lowercase: `postgresql_using='btree'`, then it produces valid SQL.

Is the `postgresql_using` argument supposed to be case-sensitive like that?
