Title

Combine+crypt storage broken

Description
#### What is the problem you are having with rclone?
Combining crypt storage is broken in version 1.70.1
It works in 1.69.3

**What works (in version 1.70.1):**
crypt storage
combine with "standard" storage like dropbox (unencrypted)

**What doesn't work (in version 1.70.1):**
combine storage with crypt storage inside
