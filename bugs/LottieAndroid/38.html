Title

Unnecessary allocations in ColorKeyframeAnimation.getIntValue()

Description
**Link to fork with a repro in the issue-repro module**
[URL]

**Describe the bug**
Several Integer allocations are being made for every frame of an animation that changes its color using a ValueCallback. This is making the GC to execute really often, having impact in app performance.

**Steps To Reproduce**
Steps to reproduce the behavior:

1. Start the issue-repro app
2. Go to Profiler
3. Select the Memory profiler
4. Start Java/Kotlin allocation recording
5. After a few seconds you will see a huge amount of Integer allocations.
