Title

Code used inside ICU expressions is not fully type safe/checked.

Description
# 🐞 bug report


### Is this a regression?

Not sure.

### Description
Component:
```
typescript
@Component({
  selector: 'my-app',
  templateUrl: './app.component.html',
  styleUrls: [ './app.component.css' ]
... [Log Snipped] ...
  value: {a?: {v: number}, b?: {v: number}} = {b: {v: 123}};
}
```

Code
```html
 
 {{value.a.v}} 

 
 
  {value.a.v, plural, other {...}}.
 
```

### Expected behavior:

Both examples must fail with the message "Object is possibly 'undefined'".


### Actual behavior:

No errors for `{value.a.v, plural, other {...}}`.
