Title

Can't assign some field types a default values

Description
If you have a struct like 

  
 struct myStruct {
   byte  x = 200;
}
 
  

 then the generated code for that default value lacks the necessary (byte) cast to avoid a "loss of precision" compiler warning. The same is true for i64 values that are larger than an i32, since java assumes all numeric literals are i32s unless they're explicitly longs.
Discussion
- Turns out that there are more problems: 
 
	 i16 is affected by the same issue as byte - need a (short) cast 
	 byte, i16, and i64 list types need casts when there are default values
- This patch seems to fix the problem pretty nicely. Review, please?
- I had to fix it for C++ too because the test case was failing to compile.
