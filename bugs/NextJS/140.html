### Describe the Bug

If I add a fallback/default value to one of my dotenv variable expansions the operation doesn't succeed.

```
NEXT_PUBLIC_TEST=${KEY:-default}
```

Results in:

```
< ":-default}"
```

### Expected Behavior


```
< "default"
```

[URL]
