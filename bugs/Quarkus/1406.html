Title

quarkus.rest-config instead of quarkus.rest-client

Description
### Describe the bug

When using REST Client, when you forget to configure the uri of an external microservice, Quarkus displays an error message as follow:

```
Caused by: java.lang.IllegalArgumentException: Unable to determine the proper baseUrl/baseUri. 
Consider registering using @RegisterRestClient(baseUri="someuri"), @RegisterRestClient(configKey="orkey"), or by adding

'quarkus.rest-config."org.agoncal.fascicle.quarkus.book.client.NumberProxy".url' or 
'quarkus.rest-config."org.agoncal.fascicle.quarkus.book.client.NumberProxy".uri' to your Quarkus configuration
```

There is no such `quarkus.rest-config` property, but instead, `quarkus.rest-client`

### Expected behavior

The message should display the right properties

```
...
'quarkus.rest-client."org.agoncal.fascicle.quarkus.book.client.NumberProxy".url' or 
'quarkus.rest-client."org.agoncal.fascicle.quarkus.book.client.NumberProxy".uri' to your Quarkus configuration
```
