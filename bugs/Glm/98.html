Title

Compile problems with glm::max( vec, int )

Description
The following code seems to be a ambigious when using VS2013 (vc120), yet compiles and works as expected with clang:

``` cpp
glm::ivec2 a = glm::ivec2( 0, 2 );
glm::ivec2 b = glm::max( a, 1 );
```

The vc error diagnostic is as follows:

```
1>------ Build started: Project: glm_test, Configuration: Debug Win32 ------
1>  glm_test.cpp
1>d:\code\test\glm_test\glm_test\glm_test.cpp(8): error C2668: 'glm::max' : ambiguous call to overloaded function
1>          d:\code\graphics\glm\glm-git\glm\detail\func_common.inl(398): could be 'glm::detail::tvec2  glm::max (const glm::detail::tvec2  &,const T &)'
1>          with
... [Log Snipped] ...
1>          while trying to match the argument list '(glm::detail::tvec2 , int)'
========== Build: 0 succeeded, 1 failed, 0 up-to-date, 0 skipped ==========
```

Trying to specify the genType param with `glm::max ( a, 1 )` doesn't seem to help, as then I get the following linker error:

```
1>glm_test.obj : error LNK2019: unresolved external symbol "struct glm::detail::tvec2  __cdecl glm::max  >(struct glm::detail::tvec2  const &,int const &)" (??$max@U?$tvec2@H$0A@@detail@glm@@@glm@@YA?AU?$tvec2@H$0A@@detail@0@ABU120@ABH@Z) referenced in function _main
```
