Title

Netty 4.1.0.CR1: DNS resolver do not treat non-ASCII characters correctly

Description
When resolving a domain name containing non-ASCII characters, Netty would send out DNS query but reject the response because the DnsQuestion doesn't match.

For example, when resolving www.äüöß.com, I'm getting:

```
04 Mar 2016 15:33:39,309 [WARN] (dns-response-handler-0) io.netty.resolver.dns.DnsQueryContext: Received a mismatching DNS response: DatagramDnsResponse(from: /x.x.x.x:53, to: /0:0:0:0:0:0:0:0:59756, 1499, QUERY(0), ServFail(2), RD RA)
    DefaultDnsQuestion(www.����.com IN A)
    DefaultDnsRawRecord(OPT flags:0 udp:4000 0B)
```

Looks like it's caused by a difference in encoding. I think the resolver should either validate the input domain name based on [URL] or just fix the encoding.
