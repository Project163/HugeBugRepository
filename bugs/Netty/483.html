Title

Problem with building on Ubuntu 14.04 LTS 32-Bit

Description
Hi!

I would like to use netty for communication with a native application via Unix Domain Sockets and I tried to use transport-native-epoll module but only artifacts for 64-Bit systems are officially provided at the moment. 

So I tried to build netty-tcnative and transport-epoll-module on my own, but I got an error while building tcnative c sources:

How to fix this error correctly? I added an additional cast to `intptr_t` before casting to `jlong`:

``` c
return (jlong)(intptr_t) NULL
```

After this change I was able to execute `mvn clean install` without any problems for _tcnative_ (but I'm not sure if this fix is correct because I'm not familiar with JNI). 

Then I tried to build transport-native-epoll. I got similar errors (in several files) to the one listed above. For example, the errors for io_netty_channel_unix_Socket.c are:

I fixed these errors in the same way (as mentioned for tcnative) by adding an additional cast to `intptr_t`:

``` c
return _sendTo(env, fd, (void*)(intptr_t) memoryAddress, pos, limit, address, scopeId, port);
```

After fixing all errors in this way I was able to build transport-native-epoll, but the unit tests that relate to SSL failed. Perhaps because my fix (of ssl.c of tcnative) was not correct?

Is there a chance to get transport-native-epoll running on 32-Bit systems? If so, how do I have to fix the problems mentioned above correctly? 

Thank you very much!
