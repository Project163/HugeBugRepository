Title

Setting $this->Cookie->time not functional

Description
I'm trying to set the length of the cookie using 
`$this->Cookie->time = 3600;  // or '1 hour'`
according to [URL] That option doesn't appear to actually set the length of the cookie. The only way to set the cookie length is with 
`$this->Cookie->write("name", "value", true, $timeInSeconds);`

We should either make this work in the code, or just change the documentation.

I'm using CakePHP 2.4.4.
Discussion
- Where are you setting the time property? It _only_ works when set in a controller's beforeFilter method. I don't think there is a way to always make it work though.
- Inside of AppController beforeFilter, exactly as in the book. I'm happy to just set it explicitly everytime I write a cookie. It was mainly confusing that setting the time prior didn't affect the output. I'm happy to submit a PR for the book that removes that line.
- Interesting, from quickly reading the cookie component that _should_ work. I could be misreading the code though.

```

```
