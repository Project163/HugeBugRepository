Title

[re2] re2 port doesn't work with cmake 3.29.1

Description
**Describe the bug**

After GitHub actions runners were updated to use cmake 3.29.1 (https://github.com/actions/runner-images/releases/tag/ubuntu20%2F20240407.1), our builds of ParquetSharp, which depends on re2, have started failing due to this issue in re2: [URL]

This is caused by this change in cmake: [URL]

**Environment**

I've reproduced this in my local dev environment:
- OS: Fedora Linux 39
- Compiler: gcc 13.2.1
- Cmake: 3.29.1

**To Reproduce**

Build a project that uses re2:

vcpkg.json:
```
{
  "$schema": "[URL]
  "name": "re2-build-test",
  "version-string": "undefined",
  "builtin-baseline": " ",
... [Log Snipped] ...
  ]
}
```

CMakeLists.txt:
```
cmake_minimum_required(VERSION 3.16)

project(re2-build-test VERSION 0.1 LANGUAGES CXX)

find_package(re2 CONFIG REQUIRED)

add_executable(program src/main.cc)
target_link_libraries(program PRIVATE re2::re2)
```

src/main.cc:
```
int main() {
  return 0;
}
```

Build with vcpkg:
```
cmake -B build -S . -D CMAKE_TOOLCHAIN_FILE=$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake
cmake --build build
```

**Expected behavior**

The program should build successfully.
