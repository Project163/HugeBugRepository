Title

Message Context Menu in Connect is Not Accessible

Description
**Describe the bug**

Connect has a contextual menu on a message that lets you edit or delete a menu. It appears when you hover over a message and when you hover over the three dots icon of the menu, it provides options. It cannot be accessed via the keyboard.

[Image: image]


**To Reproduce**

1. Tab through Connect. You'll be able to tab to focusable elements on a message like the user avatar or a link to the user, but that's it.
2. The menu never appears because the element is hidden until a message is hovered over with a mouse.

**Expected behavior**

A user should be able to access the contextual message menu and it's contents via keyboard or mouse.
