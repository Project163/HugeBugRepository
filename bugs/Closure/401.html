Title

Math.random() fails with --use_only_custom_externs

Description
What version of the product are you using? On what operating system? 
Closure Compiler (http://code.google.com/closure/compiler)
Version: v20140110
Built on: 2014/01/14 16:25

Debian GNU/Linux Xfce

 Please provide any additional information below. 
Compile a program with these options:

  --compilation_level=ADVANCED_OPTIMIZATIONS
  --use_only_custom_externs
  --debug

It should look like this:

  Math.$random$();
  ...rest of code here...

Notice that it's called Math.$random$ rather than Math.random. Which means if you remove --debug, it'll get renamed to something short like Math.K, which obviously fails.

The problem is line 1006 in the base.js file of the Closure Library:

  goog.UID_PROPERTY_ = 'closure_uid_' + ((Math.random() * 1e9) >>> 0);

Normally this isn't a problem because of "externs/es3.js".

But because the call to Math.random is at the top level (and not inside a function), it doesn't get stripped out when using --use_only_custom_externs.

This means that if a user wants to use --use_only_custom_externs they *must* provide their own extern for Math.random, even if they never call Math.random themself.

A quick fix would be to change the line in base.js to this:

  goog.UID_PROPERTY_ = 'closure_uid_' + ((Math[Link: 'random'] * 1e9) >>> 0);

At least then it won't fail with an error, though you'll still have a useless Math.random call in the output.

A better fix would be to make the compiler smart enough to strip out the Math.random even without an extern (perhaps treating the base.js file as special). Alternatively, the line could be moved into a function.
Discussion
- This is expected behavior. The externs for the built-in ecmascript objects MUST be provided. 

See comment #2 on issue 755
- My point is that this makes --use_only_custom_externs significantly less useful, because you must provide an extern for Math.random *even if you never use Math.random*, because base.js uses it at the top-level.
- --use_only_custom_externs is for a very slim set of users. If you're using base.js, then it isn't meant for you.
