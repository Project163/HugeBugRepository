Title

Data-uri function generates incorrect urls from single quoted texts

Description
Data-uri function uses single quote `'` around generated url, but does not encode it in generated string. 

Imagine following css.css file

```
.incorrect:after { 
  color: blue; 
  content: 'Unusual way of doing things. Double quote: "'; 
}
```

Next less uses data-uri function to include it into css:

```
@variable: data-uri('text/css', '../data/css.css');
@import (css) ~"@{variable}";
```

Less.js generates an incorrect css::

```
//single quote right after the word "content"
@import url('data:text/css,.incorrect%3Aafter%20%7B%20color%3A%20blue%3B%20content%3A%20'Unusual%20way%20of%20doing%20things.%20Double%20quote%3A%20%22'%3B%20%7D%0D%0A');
```

Since data-uri function encodes double quote into its utf-8 value `%3A`, the problem would be fixed by swithing to double quotes. 

Exptected css:

```
@import url("data:text/css,.working%3Aafter%20%7B%20color%3A%20blue%3B%20content%3A%20'Unusual%20way%20of%20doing%20things.%20Double%20quote%3A%20%22'%3B%20%7D%0D%0A");
```
