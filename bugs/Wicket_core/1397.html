- hi  kbachl  

 Wicket 8 is stricter about component hierarchy consistency, that's why you get the exception. Please note that even with Wicket 7 you get the following warning message: 

  WARN  org.apache.wicket.page.XmlPartialPageUpdate - Component ' [Component id = history] ' with markupid: 'history3' not rendered because it was already removed from page  

 if you invoke "form.addOrReplace(component);" before "target.add(component);" in both the handlers you will avoid the exception with Wicket 8
