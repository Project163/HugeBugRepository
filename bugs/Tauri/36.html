Title

Icon generation does not accept `--icon` - only `--i`

Description
If I run the command `yarn tauri --icon /mnt/c/Users/googlemac/Downloads/icon.png --compression optipng`, I get the error `Source image for tauricon not found`. I'm guessing this is because it's not recognizing that I'm specifying the path.

I then changed it to the shorthand and it worked: `yarn tauri icon --i /mnt/c/Users/googlemac/Downloads/icon.png --c optipng`
