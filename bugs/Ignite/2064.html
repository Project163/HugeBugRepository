Title

JDBC POJO store should support escaping for database schema, table and field names

Description
Sometimes database names could be very  strange  and this could be handled only via escaping. We need to support this. 
Adding  
  
  String  JdbcDialect.escape(name) 
  
  method looks like a good solution.
