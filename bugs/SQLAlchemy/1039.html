Title

connection pool can lose connections under pypy

Description
this is a long standing issue for pypy that we've actually had for at least ten years and suddenly it's apparent what the problem is.  pypy does not call weakref finalizers if the thing pointing to the weakref is also being GCed.  that's it!  here's a demo, works in cpython, fails in pypy with pool timeout:

```
python
from sqlalchemy import create_engine


e = create_engine(
... [Log Snipped] ...

e.connect()
```
Discussion
