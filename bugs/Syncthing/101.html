Title

sync breaks when there is "no space left on device"

Description
steps to reproduce:
1. setup 2 nodes that syncs
2. one node has "no space left on device"
3. sync stops (in my case by 59%) and stay so forever (even if there is free space again)

i had to restart that node.

it should stop that sync cycle and display a message; check if there is free space again and restart syncing.
Discussion
- It's a very important bug in Syncthing backup/sync utility - "no space on device" problem is very often, so, Syncthing should behave correctly in such situation
- Resolved, but not in the direction you guys wanted. When syncing a repo fails catastrophically (all files it tried to sync in a batch failed due to errors), the repo is stopped. Full disk, or other error condition that suddenly causes all writes to fail, is a bad _bad_ thing and _needs_ human attention.
