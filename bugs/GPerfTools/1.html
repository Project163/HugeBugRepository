Title

Description

get working in a stable manner.

I tried all the libunwind, the -Wl,-fno-omit-frame-pointer,-leh_gcc, etc.

This dead lock is a bug in nssldap. It registers a function with atfork() that calls free() internally. All functions registered with atfork() must be async-signal-safe,
