Title

Broker crashes on startup when trying to parse empty snapshot files

Description
A broker server crash can sometime result in empty snapshot files on disk (depending on FS, barrier setting etc), when Kafka tries to parse such files it crashes, gets restarted and crashes again, this happens until you remove empty snapshot files with: 

  
 find /logs/dir -name \*.snapshot -size 0 -delete
