Title

nvim crashes when `visualbell` is enabled

Description

Discussion
- This used to work ~1 month ago. Could it be a regression caused by the recent tui rework for #18375? @bfredl
- The crash happens because we re-enter `loop_uv_run()` a second time.
I don't understand why does it happens with flash_screen but not with bell.
- likely because ordinary bell has no padding (just a single ^G). Need to reconsider how to handle this. On a modern terminal I suppose "pad" is only used for time sensitive effects (like flashing the screen), so we can replace it with a bare usleep() without losing perf.
