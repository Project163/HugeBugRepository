Title

Build breaks when including Multi-release Jars

Description
As part of   BEAM-5891   there is a reported problem in the build system with jars that contain multiple versions of the classes (this is a feature introduced in Java 9). This should not be a problem when the main classes are still Java 8 compatible as it is the case for byte buddy.
Discussion
- The error is because after shading we check that all class files are within org/apache/beam and Java 9 is adding a module-info.class in META-INF/ which is outside of org/apache/beam and hence fails. 

 Trivial fix is to update the build files to exclude META-INF as well.
