Title

Column named 'row_number' gives error in MariaDB 10.11

Description
### Discussed in [URL]

 

 Originally posted by **BackSeat** April  1, 2023 
This does not produce an error with MariaDB 10.5; it does with 10.11:

```
CREATE DATABASE test;

USE test;

CREATE TABLE `kae` (
... [Log Snipped] ...
that corresponds to your MariaDB server version for the right syntax to
use near 'row_number=12 WHERE id=1' at line 1
```

I believe SQLAlchemy should wrap the column name in backticks (I actually believe this is  regression from MariaDB 10.5 → 10.11, but 'row_number' is a function name in MariaDB).
