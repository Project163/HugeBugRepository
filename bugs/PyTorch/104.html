Title

torch.nn.functional.linear throws different exception information on different devices

Description
### 🐛 Describe the bug

torch.nn.functional.linear throws different exception information on different devices

Test on the CPU:

    import torch
    in_features = 128
    out_features = 1
    weight = torch.rand(out_features, in_features)
    bias = torch.rand(out_features)
    input = torch.rand([302], dtype=torch.float32)
    output = torch.nn.functional.linear(input, weight, bias)
    print(output)

result: RuntimeError: mat1 and mat2 shapes cannot be multiplied (1x302 and 128x1)

Test on the GPU:

    import torch
    in_features = 128
    out_features = 1
    weight = torch.rand(out_features, in_features).cuda()
    bias = torch.rand(out_features).cuda()
    input = torch.rand([302], dtype=torch.float32).cuda()
    output = torch.nn.functional.linear(input, weight, bias)
    print(output)

result: RuntimeError: mat1 dim 1 must match mat2 dim 0

### Versions

pytorch: 1.8.0
Python version: 3.8
CUDA/cuDNN version: cuDNN 11.1
GPU models and configuration: RTX3060
Operating System：Windows

- The same problem exists with torch.nn.Linear

Test on the CPU:

    import torch
    m = torch.nn.Linear(in_features=128, out_features=1)
    input = torch.rand([302], dtype=torch.float32)
    print(m(input))

result: RuntimeError: mat1 and mat2 shapes cannot be multiplied (1x302 and 128x1)

Test on the GPU:

    import torch
    m = torch.nn.Linear(in_features=128, out_features=1).cuda()
    input = torch.rand([302], dtype=torch.float32).cuda()
    print(m(input))

result: RuntimeError: mat1 dim 1 must match mat2 dim 0
- The difference in the error messages on CPU and GPU might be due to different implementations of matrix multiplication on these devices. However, the root cause of the error is the same. You can try to transpose the weight tensor to match the shapes of the input and weight tensors.
Here is the code which is throwing same error on different version(CPU, GPU) : 
```
import torch
in_features = 128
out_features = 1
weight = torch.rand(in_features, out_features) # Transpose the weight tensor
bias = torch.rand(out_features)
input = torch.rand([302], dtype=torch.float32)
output = torch.nn.functional.linear(input, weight, bias)
print(output)
```

Here is the correct code: 
```
import torch

in_features = 128
out_features = 1
weight = torch.rand(out_features, in_features)
```
