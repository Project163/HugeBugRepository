Title

Anchor function in v3 throws an error if uri is an array

Description
The v3 docs of the _anchor_ function says that 

This does not work in v3 but it worked in v2. 

To fix this problem I changed url_helper.php (around line 160) by adding brackets around the preg_match expression like this:

``` php
$site_url = is_array($uri)
           ? site_url($uri)
           : ( preg_match('#^(\w+:)?//#i', $uri) ? $uri : site_url($uri) );
```
