Title

groovyConsole resolves static methods incorrectly

Description
class  A {
    static  void dangerous() { println  "I'm an A"  }
}
 class  B  extends  A  {
    static  void dangerous() { println  "I'm a B"  }
}
A object1 =  new  A()
object1.dangerous()   // outputs  "I'm an A" 
 B object2 =  new  B()
object2.dangerous()   // outputs  "I'm an A"  OOOPS
Discussion

groovy>     static  void dangerous() { println  "I'm a B"  }
groovy> }
groovy> A object1 =  new  A()
groovy> object1.dangerous() 
groovy> B object2 =  new  B()
