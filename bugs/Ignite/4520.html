Title

Partition desync if a partition is evicted then owned again and historically rebalanced

Description
Where is a possibility of partition desync in the following scenario: 

 1. Some partition is evicted with non zero counters. 
2. It is owned again and are going to be rebalanced. 
3. Some node in a grid has history for the partition defined by it's (initial, current) counters pair. 

 In this scenario the partition will be historically rebalanced having only partial data.
