Title

Throwing the same exception twice causes dev mode to fail build

Description
### Describe the bug

When throwing the same exception twice in a method prototype the dev mode fails the build even if the prod build passes

### Expected behavior

The dev build passes as expected

Or

The dev build fails and tells us where wed did wrong

### Actual behavior

We have a an exception during build

```
Caused by: io.quarkus.builder.BuildException: Build failure: Build failed due to errors
        [error]: Build step io.quarkus.arc.deployment.ArcProcessor#generateResources threw an exception: java.lang.IllegalStateException: Catch block for java/io/IOException already exists
```


But we don't know where the problem is

### How to Reproduce?

Create a quarkus project

Create a method such a 

```
public void foo() throws IOException, IOException {
   /// stuff 
}
```
