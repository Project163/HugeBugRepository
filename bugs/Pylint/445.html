- @DanielNoord those symlinks are emacs lock files, basically guaranteed to be dangling and always prefixed with ``.#``, see [URL] for more information.
- This can be fixed in past pylint version by defining ``ignore-patterns=^\.#`` in the configuration. This will become the default in pylint 2.13.
```ini
[MASTER]
ignore-patterns=^\.#
```
