Title

Headers are not set when ssr = false

Description
### Describe the bug

In production build, the headers are not set if `ssr = false` in `+layout.server.ts`

### Reproduction

1. Create SvelteKit skeleton project

2. Set headers in `hooks.server.ts`
```ts
export const handle: Handle = async ({ event, resolve }) => {
  event.setHeaders({
    'x-foo': 'bar',
    'cache-control': 'no-store',
  })
  return resolve(event)
}
```
3. Disable SSR in `+layout.server.ts`:
```ts
export const ssr = false
```

4. `pnpm build`
5. `pnpm preview`
6. Get headers (`https -h [URL]
7. Note the missing headers
