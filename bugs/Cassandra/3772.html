Title

DC Local repair or -hosts should only be allowed with -full repair

Description
We should not let users mix incremental repair with dc local repair or -host or any repair which does not include all replicas.  

 This will currently cause stables on some replicas to be marked as repaired. The next incremental repair will not work on same set of data.
Discussion
- good point, but on trunk we anticompact and mark sstables as repaired even after -full repairs - we always send the AnticompactionRequest and we need to do that to make sure the neighbors remove the parent repair sessions 

 We should probably add a "dont anticompact"-flag to AnticompactionRequest or send empty successfulRanges which will have the same effect. 

 On 2.1 it should be enough to just disallow invoking nodetool with -inc with any of the local params
