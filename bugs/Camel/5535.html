Title

camel-cxfrs - CxfRsProducer leaks Header when Exchange.HTTP_METHOD is set

Description
If you send a message to a CxfRsProducer that has the header Exchange.HTTP_METHOD set, the HTTP message sent will contain the header 

  
 org.apache.cxf.request.method=GET 
  

 for example. 

 This header should not be present in the message since it is internal to the endpoint.
Discussion
- This is standard as part of cxf and camel header mappings
- Ah yeah if you send to some external REST server then we should not have camel cxfrs to leak headers with org.apache.cxf as prefix
