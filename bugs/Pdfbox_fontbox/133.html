Discussion
- The exception is being logged rather than thrown, it initially does not appear to affect rending. On close inspection, the broken font is actually being substituted. Examining the font with Acrobat Preflight causes it to crash. 

 Two Type 1 fonts in the file begin with invalid data: 

  
 ���
%!PS-AdobeFont-1.0: StempelGaramond-Roman 001.002
 
  

 That first line in hex is  80 01 BD 0A 00 00 , which is a PFB header.
- This file is not a valid PDF, because instead of embedding the relevant sections from the PFB file, the entire PFB file (headers and all) has been embedded. Acrobat handles this, so we will too, by detecting the header and unpacking the PFB before processing.
