Title

CacheController "No cache components" when cache component is CacheInterface itself

Description
### What steps will reproduce the problem?
I've got the following configuration of cache driver:
```
return [
    'components' => [
        'cache' => yii\caching\CacheInterface::class,
        // other components
    ],
... [Log Snipped] ...
    ]
];
```

run command `yii cache`
### What is the expected result?
```
The following caches were found in the system:

	* cache (yii\caching\CacheInterface)
```
### What do you get instead?
```
No cache components were found in the system.
```

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      |  
| PHP version      | 7.2
| Operating system | Any
Discussion
- Yii 2.0 can't be configured like that. For 3.0.0 it could be done.
- @samdark. Hi, it seems such a configuration works fine at container/components level, and we are using it in production with no other problems so far. The problem is in `console/controllers/CacheController.php`:
[URL]
It may be patched only there somehow. Naive patch is:
```php
return is_subclass_of($className, 'yii\caching\CacheInterface') || $className == CacheInterface::class
```
- Ah. If that's so then feel free to do a pull request. I'll merge it.
