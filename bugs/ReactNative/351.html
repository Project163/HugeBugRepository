Title

Timers in the new architecture are not spec compliant

Description
### Description

`setTimeout`, `clearTimeout`, `setInterval` and `clearInterval` all have a different behavior regarding error handling compared to Web.

On Web, `setTimeout` and `clearTimeout` only throw when the callback argument isn't provided. They don't even throw when the callback isn't a function. `clearTimeout` and `clearInterval` never throw.

RN (in the new architecture) throws in many more cases:
* `setTimeout` and `setInterval` throw is any of the arguments is missing, or has the wrong type.
* `clearTimeout` and `clearInterval` throw if the argument is missing, isn't a number or isn't a registered timer.

We should align these behaviors with the Web (more details in [URL]
