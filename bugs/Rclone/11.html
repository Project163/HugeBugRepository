Title

local: subdirectories not working under windows

Description
From Kim via email:

For example, I have a file under`C:\Temp\Folder1\sample1.jpg`. when I used

```
rclone copy /Temp remote:backup
```

on GoogleDrive, it does not create a folder called `\Folder1`, it creates a file with a
name called `Folder1\sample1.jpg`.

I tried creating a folder called `Folder1` on Google drive before syncing
but  it  still creates a file with a name called `Folder1\sample1.jpg`
ignoring the directory `Folder1`.
Discussion
- I have confirmed this win Win 7.  This is actually a problem with the local filesystem.  A simple `rclone ls .` under windows shows that`List` (and maybe `ListDir`) are emitting paths with `\` in instead of `/`.

This is caused by `filepath.Rel` most likely.  Everything is filepath uses native directory separators so this needs fixing.

`filepath.ToSlash` and `filepath.FromSlash` look like the way to do this.
