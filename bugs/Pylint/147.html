Title

Assigning-non-slot error with descriptors and slots

Description
Originally reported by: **Dylan Baker (BitBucket: [Link: dylan_baker])**

---

When using a descriptor on a class with slots, pylint will flag assignment to the descriptor as assigning to a non-slot, even though the descriptor is assigning to a slot and works fine.

```
python
class Descriptor(object):
    def __init__(self, name, default=''):                                                                                                                                                                                                                                
        self.__name = name                                                                                                                                                                                                                                               
        self.__default = default                                                                                                                                                                                                                                         
... [Log Snipped] ...
inst = SlotsWithDescriptor()                                                                                                                                                                                                                                             
inst.attr = 'foo'
```

Will result in the assignment `python inst.attr = 'foo'` to be flagged as a 'assigning-non-slot' error.
