Title

Position of dynamically rendered component has changed in DOM from "next sibling" to "last sibling"

Description
# 🐞 bug report

### Affected Package
@angular/core


### Is this a regression?
Yes, the previous version in which this bug was not present was: 8.1.2


### Description

In the template of my AppComponent, I have a placeholder for a dynamic component an some other components:
```
    
    
 ...
    
``` 

The dynamic component is rendered like this (Ivy is on):
```
 @ViewChild('placeholder', { read: ViewContainerRef, static: true })
  container: ViewContainerRef;
...
this.container.createComponent(componentFactory, 0, moduleRef.injector); 
```

Up to Angular 8.1.2, the dynamic component has been rendered right next to the placeholder (or: it "replaced" it, since ng-container is not rendered):

```
    
!!!HERE!!!
    
 ...
    
```  

Starting with Angular 8.2.0, the dynamci component is rendered as the last one after all the other components:

```
    
    
 ...
    
!!!HERE!!!
```

- Thnx for reporting. Yes, we've changed slightly the DOM insertion order in respect to view marker comment node but didn't expect this to cause issues in practice. Will have a closer look at your case.
- @stefanocke it turned out that this is _not_ a breaking change in ivy but rather a bug that we've fixed recently in #33816. The fix is already in master, will be part of the next release (v9 RC.3).

I've opened a PR with an additional test (#33939) "just to be safe"
