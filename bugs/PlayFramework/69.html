Title

Play 2.7.0-M3 doesn't run annotation processors

Description
### Play Version (2.5.x / etc)
2.7-M3

### API (Scala / Java / Neither / Both)
Both

### Operating System (Ubuntu 15.10 / MacOS 10.10 / Windows 10)
Windows 7

### JDK (Oracle 1.8.0_72, OpenJDK 1.8.x, Azul Zing)
```
java version "9.0.4"
Java(TM) SE Runtime Environment (build 9.0.4+11)
Java HotSpot(TM) 64-Bit Server VM (build 9.0.4+11, mixed mode)
```

### Library Dependencies
N/A

### Expected Behavior
Annotation processors are fired

### Actual Behavior
When I change verion of Play in plugins.sbt and run `sbt clean compile` with `2.6.18` everything compiles. When I change version to `2.7.0-M3` and run `sbt clean compile` compilation fails with:
```
[error] C:\workspaces\project\repository\CompanyRepository.java:11:1: cannot find symbol
[error]   symbol:   class Company_
[error]   location: package domain
[error] import domain.Company_;
[error] C:\workspaces\project\repository\CompanyRepository.java:12:1: cannot find symbol
[error]   symbol:   class User_
[error]   location: package domain
[error] import domain.User_;
```
which are normally generated by Hibernate Metamodel Generator.
Moreover, there are errors:
```
[error] C:\workspaces\project\forms\MyForm.java:20:1: cannot find symbol
[error]   symbol:   variable FIELD_EMAIL
[error]   location: class project.forms.MyForm
```
So Lombok's `@FieldNameConstants` is also not fired

When I get bact to `2.6.18` everything compiles again.

`SBT` version in both configurations is `1.1.6`
