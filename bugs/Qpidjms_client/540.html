Title

fix up Javadoc to resolve errors during use of the apache-release profile on Java8

Description
Using the apache-release profile when deploying the java components fails using Java8 due to lots of errors (and warnings) occurring when running the maven-javadoc-plugin. This is because Java8 is far stricter in what Javadoc it will allow through by default, erroring in many siutations that previous versions allowed. 

 The errors should be resolved to ensure people using Java8 can build the Javadoc explicitly or as pert of running the release profile.
