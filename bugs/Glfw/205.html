Title

Mouse y coordinate is off-by-one in callback and disagrees with (correct) value returned by glfwGetCursorPos.

Description
In cocoa_window.m:mouseMoved, glfw's mouse cursor position is updated incorrectly by the line:

`_glfwInputCursorPos(window, pos.x, contentRect.size.height - pos.y);`

whereas cocoa_window.m:_glfwPlatformGetCursorPos does it correctly:

`*ypos = contentRect.size.height - pos.y - 1;`
