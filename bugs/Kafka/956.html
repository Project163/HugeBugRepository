Title

"Add Partition" log message doesn't actually indicate adding a partition

Description
We log: 
"Add Partition triggered " ... " for path "... 
on every trigger of addPartitionListener 

 The listener is triggered not just when partition is added but on any modification of the partition assignment in ZK. So this is a bit misleading. 

 Calling the listener updatePartitionListener and logging something more meaningful will be nice.
