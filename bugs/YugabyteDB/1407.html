Title

[YSQL] Crash during row lock on a temp table

Description
Jira Link: [Link: DB-16633]
### Description

Seems like [URL] happens again after the PG15 merge.

```
CREATE TEMP TABLE uctest(f1 int, f2 text);
INSERT INTO uctest VALUES (1, 'one'), (2, 'two'), (3, 'three');
SELECT * FROM uctest FOR UPDATE;
```

causes a crash on master (but not on 2024.2.2.3). This is a modified form of the regress test case in [URL]

The call stack below is not accurate, most likely, but it is what the core dump showed from a fastdebug build.
