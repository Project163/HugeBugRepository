Title

Black removes leading and trailing spaces in multiline docstrings but fails to remove them from one-line docstrings

Description
With the file `test.py` containing
```
def foo(a):
    """ This is fine. """

    return a + 1

... [Log Snipped] ...

    return a + 1
```
Running `black --diff test.py` results in a diff of:
```
@@ -9,10 +9,10 @@
 
     return a + 1
 
 
... [Log Snipped] ...
 
     return a + 1
```

**Expected behavior**

Black should also complain that the docstring of foo contains a leading / trailing space and remove these. Note that all one-line examples in PEP 257 [URL] have no leading / trailing spaces.

**Environment (please complete the following information):**

- Version: master
- OS: Linux (Ubuntu 20.04)
- Python Version: Python 3.8.2

**Does this bug also happen on master?**

This also happens on master.
