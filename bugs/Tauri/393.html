Title

Error: 'The system cannot find the file specified' when upload file to backend by Tauti http lib

Description
### Describe the bug

Hi, 

I'm trying to send a form request to my backend and I want to transfer a zip file with that request.
I'm using @tauri-apps/api/http + FormData in the body.
the form data contains zip file , in this way:
`const zip = new JSZip();
const logsFolder = zip.folder('logs');
const content = await zip.generateAsync({ type: 'blob' });
const formData = new FormData();
formData.append('file', content, 'info.zip');`

but when I send the request , I get this error each time:
Error: 'The system cannot find the file specified' 

What could be the issue?
