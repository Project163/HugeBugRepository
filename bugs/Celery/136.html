# Description
The [Link: user guide for tasks] states:  "Results can be enabled/disabled on a per-execution basis, by passing the `ignore_result` boolean parameter, when calling `apply_async` _or `delay`_" (emphasis mine)

To me, this seems to suggest that you could so something like `mytask.delay(ignore_result=True)`. However, that will just cause the kwarg to be passed through to the task itself, or rather, it causes an exception:

    TypeError: mytask() got an unexpected keyword argument 'ignore_result'

Looking at the [Link: user guide on calling tasks], it becomes clear that `delay` is just a "Shortcut to send a task message, _but doesn’t support execution options_" (emphasis mine) and hence `apply_async` must be used instead.

# Suggestions
Unless I'm completely misunderstanding something here, I suggest that it is made more clear in the user guide for tasks that usage of `apply_async` rather than `delay` is required to use the `ignore_result` kwarg.
