Title

Alter Table Add Partition operation fails if the DEFAULT_PARTITION_NAME property is a substring of partition value to be added

Description
Scenario to reproduce this issue: 

 create table test_part(a int) partitioned by (b string); 

 set hive.exec.default.partition.name=2025; 

  alter table test_part add partition(b='2025-01-01'); 

 Error: Error while compiling statement: FAILED: SemanticException  [Error 10111] : Partition value contains a reserved substring (User value: 2025-01-01 Reserved substring: 2025) (state=42000,code=10111)
