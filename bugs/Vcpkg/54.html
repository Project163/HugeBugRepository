Title

[boost] Make #define BOOST_ALL_NO_LIB conditional

Description
If I have a project with ```add_definitions(-DBOOST_ALL_NO_LIB)``` then [Link: portfile.cmake:261] will result in a ```warning C4005: 'BOOST_ALL_NO_LIB': macro redefinition```

I believe that BOOST_ALL_NO_LIB should be defined like:

```C++
#ifndef BOOST_ALL_NO_LIB
#define BOOST_ALL_NO_LIB
#endif
```
