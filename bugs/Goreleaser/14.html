Title

FPM should use gnu-tar on macOS

Description
### Prerequisites

* [x] Are you running the latest version?
* [x] Did you perform a search to see if this problem was already reported?

For more information, see the `CONTRIBUTING` guide.

### Description

FPM wouldn't work as expected with the bsd tar that comes within macOS. We should detect that
and error it as well fix the PATH in the fpm execution so it would use the gnu-tar.

```
PATH="/usr/local/opt/gnu-tar/libexec/gnubin:$PATH"
```
