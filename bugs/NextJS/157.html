### Describe the Bug

Every Page component renders twice on server. For, example the following code prints `TempPage Render` twice on server   in production mode (executed using npm run build; npm start)

In fact the root component defined in `_app.js` also renders twice on server.

BTW: the components render only once on client (browser) which is expected.

```
import { GetServerSideProps, NextPage } from 'next';
import React, { useEffect } from 'react';

const TempPage: NextPage  = ({username}) => {
  console.log("TempPage Render");
... [Log Snipped] ...
  }
};
```
Following is the output on the command line where npm run build; npm start is run:

```
getServerSideProps
TempPage Render
TempPage Render
```

### Expected Behavior

Every Page should render only once on the Server.

### To Reproduce

Create a new next app using `npx create-next-app   --ts` and then create a sample temp page using the above code.
