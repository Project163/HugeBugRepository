Title

What purpose does the Properties instance serve?

Description
The CrytoCipher implementations currently store a reference to a Properties instance. 

 However it does not appear to be used by the class except to create a new instance of the class. 

 It looks like the field could be dropped entirely.
Discussion
- Properties instance was used only in PositionedCryptoInputStream.getCipherState(). 
  
                 cipher = CryptoCipherFactory.getInstance(getCipher()
                        .getTransformation(), getCipher().getProperties());
 
  
 agree with  sebb@apache.org . Since PositionedCryptoInputStream itself has Properties parameters, there is no need to hold the Properties reference in CryptoCipher. 

 GitHub PR:  [URL]
- Also I wonder whether a Properties instance is the best way to pass in the configuration parameters. 

 It's awkward to use compared with separate parameters which can use the natural type: String, boolean, enum as appropriate. 

 Or perhaps a config class that contains the settings?
- Add  commit message. 
  CRYPTO-86   remove the Properties field in CryptoCipher
