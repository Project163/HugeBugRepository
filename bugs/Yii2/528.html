Title

Recent change in View::registerCssFile and View::registerJsFile is breaking asset urls

Description
Most of the logic in both functions has been refactored but is mostly the same. 
However the following line was added to the logic and it's removing @web alias result from urls.

`$url = str_replace(Yii::getAlias('@web'), '', $url);`

I'm not sure why this was done however I don't think it should be done this way.
