Title

Thers is a xss issue in schema-browser page of Admin Web UI.

Description
Open Solr Admin Web UI, select a core(such as collection1) and then click "schema-browse",and input a url like "[URL] src=1 onerror=alert(1);>" to the browser address, you will get alert box with "1". 

 I changed follow code to void this problem: 
Original code: 
 $( 'option [value="' + params.route_params.path + '"] ', related_select_element ) 
        .attr( 'selected', 'selected' ); 

 Changed code: 
 $( 'option [value="' + params.route_params.path.esc() + '"] ', related_select_element ) 
        .attr( 'selected', 'selected' );
