Title

release not possible on private gitea instance

Description
### What happened?

When running `goreleaser release --rm-dist` the output is:
```
  ⨯ release failed after 2s                  error=scm releases: failed to publish artifacts: token is required
```
I checked `dist/config.yaml` and it shows the following:

```yaml
env_files:
  github_token: ~/.config/goreleaser/github_token
  gitlab_token: ~/.config/goreleaser/gitlab_token
  gitea_token: ~/.config/goreleaser/gitea_token
```

Running `cat ~/.config/goreleaser/gitea_token` prints out the token.

### How can we reproduce this?

Probably reproducible on another gitea instance. As I only have this private one, I cannot share anything for this.
