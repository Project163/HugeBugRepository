Title

`scene_viewer` crashes when running a gltf that includes a camera.

Description
## Bevy version

Bevy main  

## What you did

Run the `scene_viewer` example with a gltf that includes a camera (exporting the default blender scene and make sure to check Include->Cameras when exporting works)

## What went wrong

It crashes.

Discussion
- I would have bet it was related to my changes with the prepass shader for shadows thing, but a git bisect led to this commit being the cause:  . I will look into it.
- Ok, found the issue: The problem is that the gltf loader does not create a `Camera3dBundle` which would have included the new `Tonemapping` component. Because it is missing the view query in `queue_mesh_view_bind_groups` does not include the camera and does not insert the required `MeshViewBindGroup` component which later results in the `QueryDoesNotMatch` error inside `draw`.

I will open a PR fixing this.
