Title

Translation fallback to msgid_plural not working

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.4.13

### What you did

Ran tests of a helper that uses translations.

The code uses this line for translations `'name' => __d('wa', 'Projects'),` Please note that we're using the *singular* translation here and pay attention to the paste of our po file.

### What happened

`'name' => __d('wa', 'Projects'),` doesn't return a non empty string.

### What you expected to happen

Having plural translations falling back to the msgstr. I think this is somehow related to the order in the po file or something. Because we have `msgid "Projects"` and the plural `msgid "Project"`. See the pasted part of our po file below.

I *guess* this is probably related to the way the translated strings are cached inside the translator object.

Doesn't work, empty output.

```
msgid "Projects"
msgstr ""

#: Model/Search.php:95
msgid "Daily News"
... [Log Snipped] ...
msgstr[0] ""
msgstr[1] ""
```

Works:

```
msgid "Projects"
msgstr ""

#: Model/Search.php:95
msgid "Daily News"
... [Log Snipped] ...
msgstr[0] "Projects"
msgstr[1] "Project"
```
