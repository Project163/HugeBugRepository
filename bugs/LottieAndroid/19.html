Title

Option to disable cache composition doesn't work

Description
**Describe the bug**
The Composition still gets cache in `LottieCompositonCache`, regardless of the setting. This is because the custom/null cache key is ignored here: [URL] It should be calling `fromRawResSync(context, rawRes, cacheKey);` instead.

It looks like this was missed in [URL]

**Steps To Reproduce**
Steps to reproduce the behavior:

1. Set `cacheComposition` to `false` on `LottieAnimationView`
2. Attach a debugger and set a breakpoint in `LottieCompositionCache.put`
3. Load an animation from a raw res
4. See that `cacheKey` is non-null, even though it should be null.
