Title

Not all test-related events are emitted when a test fails or errors

Description
| Q                   | A
| --------------------| ---------------
| PHPUnit version     | 10.1.1
| PHP version         | 8.1.14
| Installation Method | Composer

#### Summary

I have a breaking test case for debug output now!  The issue is test failure, not mocking, as I previously thought.  (Of course, failing tests is when I'd want debug output!)

Given this test class:

```
php
class SampleTest extends TestCase
{
    public function testPass(): void
    {
... [Log Snipped] ...
    }
}
```

#### Current behavior

I get this output:

```
PHPUnit 10.1.1 by Sebastian Bergmann and contributors.

Runtime:       PHP 8.1.14
Configuration: /app/phpunit.xml.dist

... [Log Snipped] ...
FAILURES!
Tests: 2, Assertions: 2, Failures: 1.
```

The debug message from the passing test is shown.  But the output from the failing test is missing.

#### How to reproduce

See above sample code.

#### Expected behavior

Both print statements should be written to stdout.
