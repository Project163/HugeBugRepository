Title

`profile: true` in webpack.config.js has no effect

Description
**Do you want to request a *feature* or report a *bug*?**
Report a bug

 
 

**What is the current behavior?**
Adding `profile: true` to my Webpack config doesn't actually result in profiling data being output (as `webpack --profile` would):

```
bash
$ webpack
Hash:  
Version: webpack 3.0.0
Time: 64ms
... [Log Snipped] ...
   [1] ./foo.js 39 bytes {0} {1} [built]
   [2] ./bar.js 20 bytes {0} {1} [built]
```

**If the current behavior is a bug, please provide the steps to reproduce.**
See a minimal reproduction [Link: here].
 
 
 

**What is the expected behavior?**
The profiling info should be output:

```
bash
$ webpack --profile
Hash:  
Version: webpack 3.0.0
Time: 93ms
... [Log Snipped] ...
   [2] ./bar.js 20 bytes {0} {1} [built]
       [] -> factory:1ms building:1ms = 2ms                       <-- profiling
```
