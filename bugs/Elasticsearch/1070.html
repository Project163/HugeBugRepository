Title

Aggregations: Prevent negative intervals in date_histogram

Description
Using a negative numeric `interval` setting in `date_histogram` can lead to OOM erros on 1.4.2:

```
DELETE /_all

PUT /index/doc/1
{
  "date":  "2014/01/01"
... [Log Snipped] ...
   "status": 503
}
```
