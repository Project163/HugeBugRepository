Title

Improvement / bug in FormHelper::select

Description
Hello

Sorry for my very poor engllish.

In FormHelper::select, if using a checkbox, you can unselect one or more elements using the "$attributes['disabled']". I have try to do the same thing with a select and it work except if the value of my array is 1. In this case, the helper disables the correct option AND the select.

I'm not sure if this is a bug or an improvement bug but it will be a good think if we can disabled elements in select as easily as a checkboxe.

Code :

``` php
    echo $this->Form->select('PostLink.link_id', array(
        'value'=>$selected_posts,
        'options'=>$all_posts,
        'multiple'=>true,
        'disabled'=>array($post['Post']['id']),
    ));
```

Discussion
- Yeah this is probably not correct, as the 1 is being treated as boolean true.
- it's possible to hack the disabled attribute by write this :

``` php
'disabled'=>array(0, $post['Post']['id']),
```

and it works like a charm but it's not really a solution.
