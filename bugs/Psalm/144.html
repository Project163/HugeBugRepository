Title

Fails when Turkish locale is in effect

Description
Just so this doesn't get lost.

```php
class SomeIterator {}
needs(new SomeIterator);
/** @psalm-suppress InvalidClass **/
function needs(someiterator $x) : void {}
```
```
$ for locale in C tr_TR.UTF-8 tr_TR.iso88599; do echo "$locale:"; LC_ALL=$locale psalm qq.php; done
C:
Checks took 0.071636199951172 and used 16.211MB
tr_TR.UTF-8:
ERROR: InvalidArgument - qq.php:4:7 - Argument 1 of needs expects someiterator, SomeIterator provided
... [Log Snipped] ...

Checks took 0.048002004623413 and used 14.227MB
```
The reason for this bug (and similar) is pervasive usage of `strtolower()` across the codebase, where other approaches like `strcasecmp()` could have been used.

Also see discussion in this commit:
Discussion
- `setlocale(LC_CTYPE, 'C')` in startup should help (http://php.net/manual/en/function.setlocale.php#refsect1-function.setlocale-parameters)
