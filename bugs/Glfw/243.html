Title

Fix clang cl issue

Description
GLFW doesn't compile with clang-cl.
Discussion
- Here is how I fixed the issue locally.

Here is the clang-cl user manual:
[URL]

```
cmake
if ("${CMAKE_C_COMPILER_ID}" STREQUAL "Clang") 
    if ("${CMAKE_C_SIMULATE_ID}" STREQUAL "MSVC")
        set(glfw_clang_cl ON)
    else()
... [Log Snipped] ...
    endif()
endif()
```

Basically without this change clang-cl essentially will compile with -Weverthing. Because -Wall becomes -Weverthing in clang-cl. That's because clang-cl tries to emulate MSVC. And -Wall is also a flag in MSVC. Which results in this unfortunate problem...
- Here are the instructions for generating the necessary visual studio solution:
```
cmake -G"Visual Studio 2019" -T ClangCL ..
```
- What was the actual compiler error here before you fixed it? If it's regarding intrinsic.h, it (and some other clang errors) will be fixed in next month's Visual Studio 2019 preview version 16.9 Preview 2.
- @Perksey No errors, just tons of not very useful warnings like `-Wdocumentation`. They seem to have been fixed with 16.8.0, but it would be nice to have this work on earlier versions too.
