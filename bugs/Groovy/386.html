Title

Reader.readLine() consumes too many characters.

Description
Example: 
import java.io.FileReader 

 f=new FileReader(inputFile) 
header=f.readLine() 
println "==${header}==" 
f.readLines().each { 
  println "###" it "###" 
} 

 only works if "f" is decorated with a BufferedReader 
 f=new BufferedReader(new FileReader(inputFile)) 
otherwise "f" misses some lines. 

 Cause: 
DefaultGroovyMethods.readLine constructs BufferedReader of "self", if "self"  is not an instance of BufferedReader. 
BufferedReader does some readahead which "destroys" the FileReader contents.
Discussion
- This is because we can't wrap reader with BufferedReader more than one time.  

 So, I suggest, we should not support readLine(Reader) default method, and we should only support default method readLine(BufferedRead).  
If so, we can let user make sure only decorate reader with BufferedRead only one time  

 The same thing exists in readLine(InputStream stream) which method should not be supported  

 Below is my java code  

 public class ReaderTest {  

 public static void main(String[] args) throws IOException {  
FileReader r = new FileReader("E:/groovy/demo.txt");  
BufferedReader br = new BufferedReader(r);  
String line = br.readLine();  
System.out.println(line);  

 line = br.readLine();  
System.out.println(line);  

 BufferedReader br2 = new BufferedReader(r);  
line = br2.readLine();  
System.out.println(line);  
}  
}  

 From the output, we can see, the third line also is "null".  

 below it the current code for readLine(Read):  
    public static String readLine(Reader self) throws IOException {  
        BufferedReader br = null;  

         if (self instanceof BufferedReader)  
{ 
            br = (BufferedReader) self; 
        }
  else  
{ 
            br = new BufferedReader(self); 
        }
   
        return br.readLine();  
    }
- rather than removing the readline method we could try to do some magic with mark/reset, or implement a readline method of our own. But doing a readline method basing on read() may be slow.
