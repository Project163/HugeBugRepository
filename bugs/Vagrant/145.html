* When the local box filename is missing, publish.rb reveals an internal nil error. The CLI usage description and validation code should perhaps be updated to require the provider filename.

- Hi @mcandre - A provider/box file is required when running the `vagrant cloud publish` command. Your original command seems to have left that off from the command, which results in the error. The CLI should at least be smart and make sure a file is provided rather than showing that error.

As for the description issue, it could be an issue with your shell. This works for me:

```
ruby
brian@localghost:vagrant-sandbox % be vagrant cloud publish briancain/test123 \                             ±[master]
```

- @briancain Thank you for taking a look!
