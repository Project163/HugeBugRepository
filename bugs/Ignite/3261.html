Title

Rebalancing sometimes is not triggered when a node is added to the baseline topology

Description
When a cluster already has baseline topology set and activated adding a new node to the baseline should lead to rebalancing. However, in some cases the new node will not receive any data when joined and added to the baseline; if a cluster is later deactivated and activated again, the rebalancing happens properly and partitions are assigned and transferred to the new node.
