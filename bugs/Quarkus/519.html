Title

Regression: @Inject mock service in QuarkusTest is null during JUnit @TestFactory execution in Quarkus 1.3.0.Final

Description
**Description**
When a JUnit test includes an `@Inject` mock service bean initialisation works properly for normal `@BeforeEach` and `@Test` annotated methods, but tests executed with `@TestFactory` have the mock service uninitialised.

In the attached sample project, look at ExampleResourceTest.`tests` for an example of the problem, these tests work properly in Quarkus 1.2.1.Final.

**Expected behavior**
The `@Inject` mock bean is initialised correctly during `@TestFactory` execution.

**Actual behavior**
The `@Inject` mock bean fails to be initialised.
