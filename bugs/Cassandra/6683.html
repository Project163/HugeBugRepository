Title

(Accord) Cassandra bootstrap no longer using the range txn and instead uses the sync point empty txn for reads

Description
Ephemeral reads made a change to ReadData which caused Bootstrap to no longer use the range txn it generates and instead uses the empty txn from the sync point.  This was not detected in Accord due to ListRead supporting ranges, and failed in Cassandra as we don’t support range reads.
