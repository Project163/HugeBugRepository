Title

ClassData and IClassFixture

Description
Hi all;
I have a problem with `IClassFixture`.  
After several tests, it seems that `IClassFixture` is not shared as a context beetween each test, when using a `Theory` and `ClassData(T)` in any test. 

* I'm targetting  `.Net Framework 4.6.1`
* I use the last XUnit assemblies : `xunit 2.3.0`

**Edit : I made a test with xunit 2.2.0 and it seems to work correctly with this version**

Here is a quick repro, available here  (you will find the project zip as well in attachment : [Link: XUnitTests.zip] )

```
public class ClassConf
    {
        public int Id { get; set; }
        public string Title { get; set; }

... [Log Snipped] ...

    }
```
If I use **only** `[Fact]`, the Fixture is correctly used and shared :

```
Constructor Fixture called
Constructor Class Test called
Test 1 called
Constructor Class Test called
Test 2 called
Dispose Fixture called
```
If I try with a `[Theory]` and `[ClassData]` (with 3 object availables), the fixture class is called twice.  
Here is the output :

```
Constructor Fixture called
Constructor Fixture called
Constructor Class Test called
Constructor Class Test called
Test 1 called
... [Log Snipped] ...
Dispose Fixture called
Dispose Fixture called
```
Discussion
- I have the same issue. However, I don't use ClassData. I use [Fact] with [Theory] and [MemberData].
I noticed that the fixtures get created once for all tests that have the [Fact] tag and once for all tests that have the [Theory] tag. Yet, one of them gets ignored and the second is received by all tests.
- This has something to do with run selected vs. run all.

I've updated the tests like this:

```
csharp
public class ClassFixtureTests
{
    public static long StaticConstructorCount = 0L;
    public readonly long ConstructorIteration;
... [Log Snipped] ...
    }
}
```

When I use Run All, everything passes. When I use Run Selected (or Debug Selected), then I get the failure. There are two fixtures created, and the theories share one, while the facts share the other.

Still looking around to see if I can figure out why...
