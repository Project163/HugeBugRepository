Title

Unable to use statically imported const string in annotation

Description
I have a java class defined (pulled in as byte code from a jar dependency) 
  
  
 
 package  com.org.nativecompiler.cli;
 public   final   class  MyDefinitionInJava {
     public   static   final   String  MYTEXTINJAVA =  "asdsad" ;
}
 
  

 I am using this in my Groovy class. When I compile my groovy class with the java jar in the dependency path, 
  
  
 

 import  static com.org.nativecompiler.cli.MyDefinitionInJava.MYTEXTINJAVA;
public  interface  Interfaces {
     String  OTHERTEXT = MYTEXTINJAVA +  "1234" ;
    @Deprecated(since = OTHERTEXT)
    public  interface  InnerClass {
    }
}
 
  
 I get a compile error (in comple static mode) in the use of OTHERTEXT 
    Expected 'com.org.nativecompiler.cli.MyDefinitionInJava.MYTEXTINJAVA.plus(1234)' to be an inline constant of type java.lang.String in @java.lang.Deprecated 

 This seems to be an issue only if I static import it. This works if I use MyDefintionInJava.MYTEXTINJAVA directly
Discussion
- This standard Groovy also fails with a similar error (it seems to fail only when I do PART1 + PART2 

   Expected 'com.org.interfaces.Blah$Inner.MYSTRING' to be an inline constant of type java.lang.String not a property expression in @java.lang.Deprecated 
  Attribute 'since' should have type 'java.lang.String'; but found type 'java.lang.Object' in @java.lang.Deprecated 

  
 
 class  Blah {
    @Deprecated(since = Inner.MYSTRING)
    void myMethod() {
    }
    public static  class  Inner {
        public static final  String  PART1 =  "my" ;
        public static final  String  PART2 =  "string" ;
        public static final  String  MYSTRING = PART1 + PART2;
    }
}
- There are a few things going on here.  In your original example, part of the string constant comes from a Java source.  Strings are concatenated into an interface field initializer.  And lastly, that static final field is used on an annotation of an inner class. 

 I think order of operations is your greatest hurdle here.
