Title

event attribute of is not evaluated

Description
The "event"-Attribute of <send> is not evaluated. This is not in line with the SCXML WD.
Discussion
- This will be a breaking change, but given that the previous behavior is incorrect, I think it makes sense to change for v0.9 with a prominent remark about this in the release notes.
- This has been fixed in SVN trunk. If possible, please build trunk and verify.
- ... [Middle Discussions Snipped for Brevity] ...
- You may have misread the change. An empty or absent event attribute will not generate any warning. 

 A warning will be generated if and only if: 
 
	 The event attribute has a value (that is not an empty string) 
	 On evaluating the said value as an expression, the evaluator returns null or an empty string 
 

 This is useful because we have changed behavior here (from a string to expression), and if people update to the next release and do not correct their SCXML documents to match, they will get these warnings. 

 Finally, your HTTP example above should not generate a warning if you try it.
- Closing since 0.9 is released.
