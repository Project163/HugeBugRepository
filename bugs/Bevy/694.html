Title

AsBindGroup derive compile error with storage_texture

Description
## Bevy version

0.16.0-rc.2

## What you did

I wanted to use a storage texture in my project and used the `AsBindGroup` derive macro to create it.

Minimal example:
```
rs
use bevy::prelude::*;
use bevy::render::render_resource::AsBindGroup;

#[derive(AsBindGroup)]
... [Log Snipped] ...
    App::new().add_plugins(DefaultPlugins).run();
}
```

## What went wrong

The code fails to compile with the following error message

```
error[E0433]: failed to resolve: use of undeclared type `TextureViewDimension`
 --> src/main.rs:4:10
  |
4 | #[derive(AsBindGroup)]
  |          ^^^^^^^^^^^ use of undeclared type `TextureViewDimension`
  |
  = note: this error originates in the derive macro `AsBindGroup` (in Nightly builds, run with -Z macro-backtrace for more info)
```
