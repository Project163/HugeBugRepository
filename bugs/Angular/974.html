# 📚 Docs or angular.io bug report

### Description

Hello there. On the page [URL] there is one missing import in app.module.ts file available among all changed files for step 3. 

For making included files to be working as a whole example, app.module.ts should have:
```

```
as well as below one:
```
imports: [
   /* ... */
    BrowserAnimationsModule,
   /* ... */
],
```
