Title

Cannot deduce generic type of bound TypeVar through Type of Union

Description
**Bug Report**

Inspired as a follow-up to [Link: this StackOverflow question], I believe that mypy cannot deduce a generic type of a bound `TypeVar` through `Type` of a `Union` - it seems to deduce `object` in all cases and I'm not sure why.

```
python3
from typing import TypeVar, Type, Callable, Union, Any

# t1 is a non-union type
t1: Type[bool] = bool
... [Log Snipped] ...
foo5(t1)  # pass
foo5(t2)  # pass
```

**To Reproduce**

[URL]

**Expected Behavior**

This is not rigorous, but I would expect that mypy could "figure out" that a value of `Union[Type[bool], Type[str]]` can satisfy the bound of `Union[bool, str]` for `T` in the expression `Type[T]`.

Am I misunderstanding something about the relationships between these types? Should this work?

Thanks for any insight.
