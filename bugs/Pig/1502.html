 Problem is with protected DataBag[] bags; in Packager.java. While POCombinerPackage in older version iterated through the tuple, current code in POPackage iterates through the tuple and puts in a bag (in BigData_4 that becomes 600+MB) and passes the bag to POCombinerPackage which causes OOM when trying to add to the bag there as memory is already occupied by the other bag. We need to do some rework on POPackage and Packager.
