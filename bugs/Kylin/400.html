Title

MYSQL Single-Node Use Case with New Database: Error Occurs When Importing Models

Description
In the use case, when exporting a model from one project and importing it into another project, an error occurs during model file parsing.
Discussion
- Root Cause 

 When importing model metadata, the project name of the metadata needs to be obtained first. The current logic for obtaining the project name may use the global metadata's project name, causing the logic for replacing the metadata project to fail. 
   Dev Design 

 The logic for obtaining the project name from the metadata will be changed to retrieve it directly from the model metadata.
