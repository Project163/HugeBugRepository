Title

Default value for csv parameter []interface{} instead of []string MyAPI ... [Log Snipped] ... 200:

Description
## Problem statement
Default values for a csv parameter are translated to a `[]interface{}` instead of a `[]string`, which fails to compile.

## Swagger Version


## Steps to reproduce
### Swagger File
```
yaml
swagger: '2.0'
info:
  version: '1.0.0'
OK
```

Then generate the Go client: `swagger generate client --spec api.yml`

Then save this Go file and run it (`go run .`)

```
go
package main

import (
	"fmt"
... [Log Snipped] ...
	fmt.Println(*params)
}

You get the following error:

```
