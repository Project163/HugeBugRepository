Title

LLAP cache: address some issues in 2.2/2.3

Description
We've run into   HIVE-16233   and   HIVE-15665   and given that 2.2 and 2.3 releases are approaching we are going to add workarounds for them, and then commit the above patches and revert the workarounds as soon as we can. 
Unfortunately this will result in cache wasting some memory on some datasets, but the alternatives, when they are encountered (usually only on large datasets), are worse.
