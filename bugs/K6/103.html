Title

Async/Await update affected k6-browser JS scripts

Description
### Brief summary

As an experiment, we tried updating k6-browser to the latest async/await update in 8418147.

However, we can no longer run our [Link: example JS tests]. Note that our examples were working with k6 v0.42.

You can see the CI output [Link: here].

Also see for more context: [URL]

### k6 version

8418147

### OS

macOS 13.1 and Github CI

### Docker version and image (if applicable)

_No response_

### Steps to reproduce the problem

1. Clone the xk6-browser repository and switch to the folder
3. Run: `xk6 build master --with github.com/grafana/xk6-browser=.`
4. Run: `./k6 run examples/launch_naked.js`

### Expected behaviour

To see the expected behavior, try running a browser script (i.e., `examples/launch_naked.js`) using k6 v0.42. We were not getting a "Not a function" error (which you can see in the actual behavior heading below) while running our example scripts with k6 v0.42.

### Actual behaviour

The following error happens when we use the k6 commit 8418147 in [URL]

```bash
ERRO[0000] test aborted: TypeError: Not a function: [object Object] at file:///Users/inanc/grafana/k6browser/feature/async-await-k6/examples/launch_naked.js:13:20(21)
```

Here's the full output:

```
bash
$ xk6 build master --with github.com/grafana/xk6-browser=.
...
$ ./k6 run examples/launch_naked.js
running (00m00.2s), 0/1 VUs, 0 complete and 1 interrupted iterations
... [Log Snipped] ...

ERRO[0000] test aborted: TypeError: Not a function: [object Object] at file:///Users/inanc/grafana/k6browser/feature/async-await-k6/examples/launch_naked.js:13:20(21)
```

---

### Update

It seems [Link: the xk6-browser mappings] no longer work with the latest k6 update (8418147). It was working with k6 v0.42.0. I can run the scripts when I remove the mappings. However, this still indicates a problem somewhere that we need to figure out. What might have changed on the Goja or k6-core side? 🤔
