Title

Normalize `req.query` within `preload` function

Description
Within the server context (tested w/ `adapter-node`, if it makes a difference), `req.query` is a `URLSearchParams` instance.

Within the client context, `req.query` is a plain object.

```js
// Current workaround:
export async function preload({ query }) {
  const isUSP = query instanceof URLSearchParams;

  const foo = isUSP && query.get('foo') || query.foo || 'default foo';
  const bar = isUSP && query.get('bar') || query.bar || 'default bar';
}
```
Discussion
- This seems like something that Typescript should catch for us
- Ah yep, it should always be an instance of `URLSearchParams`
