Title

Query: log file analyzer tool

Description
Slow queries are logged as a warning. Those log messages can be used to analyze, for example, what indexes (if any) are missing. 

 I will create a simple log analyzer tool that is able to process log files, and list the slow queries. 

 The advantage over JMX statistics is that old log files can be analyzed as well. 

 For now, I will just add the tool to the "test" section. If it proves useful, we can add it to oak-run or so.
