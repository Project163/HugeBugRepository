Title

vcpkg is inconsistent in how it accepts path parameters in its command line interface

Description
**Is your feature request related to a problem? Please describe.**

Consider:

* `--vcpkg-root  `
* `--x-scripts-root= `

where a user probably expects one of:

* `--vcpkg-root= `
* `--x-scripts-root= `

or

* `--vcpkg-root  `
* `--x-scripts-root  `

**Proposed solution**
We already shipped this inconsistency, so just picking one and sticking with it isn't an option. However, we can:

* change parameter parsing to accept either form for all such parameters
* choose the = or separate argument form as the canonical one, and update help text to be consistent
