Title

Spurious "Cannot determine type of 'x'" in fine-grained incremental mode

Description
The following test case fails in fine-grained incremental mode though it should pass:

```
[case testInferAttributeTypeAndMultipleStaleTargets]
import a

class A:
    def g(self) -> None:
... [Log Snipped] ...
[out]
==
```

Here's the actual output:

```
==
main:10: error: Cannot determine type of 'x'
```

Switching the names of the methods (`g`   `f`) works around the failure. The apparent reason for the failure is that we sort targets to process within a file by string value when propagating changes, so `f` gets processed before `g`. The correct way to sort targets is by line number.
