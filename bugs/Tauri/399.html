Title

[bug] windows NSIS uninstall.exe is not code signed

Description
### Describe the bug

the uninstall.exe file created by NSIS installer is not code signed in building process, so when uninstall an app, warning of UAC is still shown.
The bundle process should also code sign the uninstall.exe file when using NSIS installer.
