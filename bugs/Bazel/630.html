- @katre unfortunately, there is not, these tests depend on downloading an installer, you can repro the error easily though, just try to run a build form an environment in which the same env variables as those set in the docker autoconfig target are set. Specifically, you should be able to repro this by simply adding the env variable:
"CC_TOOLCHAIN_NAME": "linux_gnu_x86"
and then trying to run a build of any target that requires the cc toolchain.
With 0.19.0 the build will succeed, with 0.19.1 the build will fail unless you set
"CC_TOOLCHAIN_NAME": "local" (or remove the env variable)
