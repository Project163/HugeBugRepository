Title

Trying to get property 'driverName' of non-object

Description
### What steps will reproduce the problem?
```php
$query = MssqlModel::findBySql($sql);
foreach ($query->batch()) {
// some code...
}
```

### What is the expected result?
Iterate all MssqlModel objects.

### What do you get instead?
Exception after first iteration:

```
PHP Notice 'yii\base\ErrorException' with message 'Trying to get property 'driverName' of non-object'

in /app/vendor/yiisoft/yii2/db/BatchQueryResult.php:168
```

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.24
| PHP version      | 7.4
| Operating system | Debian GNU/Linux

### Additional information
In `/vendor/yiisoft/yii2/db/Query.php:187`: `$db` is null by default and `Query` has no `$db` param to set correct value.
```
php
    public function batch($batchSize = 100, $db = null)
    {
        return Yii::createObject([
            'class' => BatchQueryResult::className(),
... [Log Snipped] ...
        ]);
    }
```

This is workaround:
```php
foreach ($query->batch(100, MssqlModel::getDb()) {
// some code
}
 ```
