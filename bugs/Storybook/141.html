- I believe this was supposed to look up the [Link: `element` parameter value], if it is provided. I just specified the `element` parameter on Storybook 6.3.12 and I get "The scan encountered an error: {}" in the panel. When I dropped the `element` parameter, the addon works fine. So, I explored the source code to see the control flow:

1. [Link: `axe` is run on the `element` identifier]
1. [Link: the `element` identifier refers to the element specified in input or the return of `getElement` if it isn't provided]
1. [Link: `getElement`] refers to an HTML element, either `#root`, the top-level div that contains a story by default when no decorators are used, or `#story-root`, a mysterious value.
1. [Link: `input` is the value returned by `getParams`]
1. [Link: `getParams`] either returns the `element` parameter if specified or null.

So, your real problem is that the `element` parameter's docs are incorrect. That parameter currently seems to do nothing.
