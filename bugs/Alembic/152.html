DeprecationWarning: generator 'RevisionMap._iterate_revisions' raised StopIteration (PEP 479)

Description
**Migrated issue, originally created by Christopher Sang ([Link: @csang])**

Run a downgrade on an initially empty db, using a command like:
```
python -Wall `which alembic` downgrade base
```

```

```

Environment:

- alembic 0.9.5 
- python 3.6.2
- postgresql 9.6.5 (probably does not make a difference)
- psycopg2
