Title

Description
**Describe the bug**

`watch('useFieldArrayName')` returns default values instead of the ones in the input fields under certain conditions.

**To Reproduce**

Steps to reproduce the behavior:

1. Go to [URL]
2. Click on 'append'.
3. Modify input field values in the 2nd row.
4. `watch('test')` returns values correctly.
5. Click on 'append' again.
6. `watch('test')` returns default values instead of current value.
    - Note: The values in the input fields are not changed.
