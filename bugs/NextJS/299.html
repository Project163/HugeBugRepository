### To Reproduce

The page is explicitly set as dynamic so it can fetch data on server side

When running the app, the following error is thrown
```
Error: Page changed from static to dynamic at runtime /test/p
see more here [URL]
```
This page shouldn't be marked as static since 
```
export const dynamic = 'force-dynamic';
```
Dynamic params is also not respected, giving 404 on random routes /test/p/random
```
export const dynamicParams = true;
```
The problem happens even without the `[variant]` segment in the repro, but kept it there to make sure it matches our current working environment

### Describe the Bug

Nextjs incorrectly marks a `force-dynamic` page as `static` causing runtime error
This seems to have been introduced in `13.1.3`

### Expected Behavior

The page should be dynamic, fetch should work

Probably related to #45068 #44860

FIX:
Adding `cache: 'force-cache',` to the fetch() request seems to sort it out. This however does seem to contradict the beta fetch() docs which state that `cache: 'force-cache',` is the default behaviour.
