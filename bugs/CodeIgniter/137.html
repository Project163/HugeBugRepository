- Thanks for reporting this.

However, please note that you should describe the problem, not the solution ... and linking SO questions isn't appropriate for that (e.g. what if the question gets deleted? This bug report becomes meaningless).

Also, the suggested fix isn't correct as we're dealing with a bitflag field; you cannot just compare against a set of values.
For example, an `int auto_increment` field wouldn't have a type value of 3 (as suggested by you). It would contain *at least* the `MYSQLI_TYPE_LONG` (int) and `MYSQLI_AUTO_INCREMENT_FLAG`, and thus will equal at least 515.

Please use the linked commit and see if it works for you if possible.

P.S.: While in this case the OP on that StackOverflow question has no other choice, it is otherwise very inappropriate to suggest modifying core framework files.
