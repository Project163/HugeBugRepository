Title

Set progress to 1.0f do not set last frame of the animation into the LottieAnimationView

Description
**Link to fork with a repro in the issue-repro module**
[URL]
[URL]

**Describe the bug**
Setting progress to the 1.0f do not set last frame of the animation into the LottieAnimationView.

**Side effect**
If I call setMaxProgress(1.0f) before the progress, in that case setProgress(1.0f) works correctly :shrug:.

**Steps To Reproduce**
1. Run PR [URL]
2. In onCreate() setProgress to the 1.0f
3. Wait some time (5s) for progress to take effect
4. Observe progress on the view
Actual: Progress of the view(getProgress) is `0.9914648`, last frame not rendered.
Expected: Progress of the view(getProgress) is `1.0f` last frame is rendered.

**Important note**
The progress is not working correctly with any animation, however it became visible only with animations that has difference between last and preLast frame, see: [URL]
