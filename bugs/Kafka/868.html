Title

System tests: log level is no longer propagating from service classes

Description
Many system test service classes specify a log level which should be reflected in the log4j output of the corresponding kafka tools etc. 

 However, at least some these log levels are no longer propagating, which makes tests much harder to debug after they have run. 

 E.g. KafkaService specifies a DEBUG log level, but all collected log output from brokers is at INFO level or above.
