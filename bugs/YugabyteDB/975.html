Title

[DocDB] Fix GC of schema packings of colocated table

Description
Jira Link: [Link: DB-6755]
### Description

In [Link: rocksdb_writer.cc] when updating the frontiers on the apply path, we seem to be using a table_id of Uuid::Nil(); which updates the parent table schema version and not the colocated/cotables’s schema versions. As a result, GC of schema packings might wipe out schema packings of colocated tables aggressively.
