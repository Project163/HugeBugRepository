Title

Race condition deleting clusterstate.json can prevent Solr from starting

Description
ZkController attempts to delete the deprecated  clusterstate.json  file from ZooKeeper if empty on startup. If multiple instances attempt to delete it at the same time one of them will succeed and the others will fail with `NoNodeException`, which bubbles up and causes the instance to fail startup, requiring another restart
