Title

Resteasy-reactive routing does not work when paths are shared across classes.

Description
## Describe the bug
Having 1 route handled by 2 classes doesn't work (It does in plain resteasy).  For example, 

- GET /hello/{id} in class A
- GET /hello/{id}/foo in class B

Attempting class A's route results in a 404.

### Expected behavior
Routing to Class A's route

### Actual behavior
404


## To Reproduce

[Link: route-bug.zip]

Steps to reproduce the behavior:
1. Start quarkus
2. Visit /hello/123 observe 404
3. Visit /hello/123/bar receive nice message
