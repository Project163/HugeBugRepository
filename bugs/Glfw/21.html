Title

Non-standard libGL sonames

Description
On linux libGL should be loaded by dlopening libGL.so.1. This is what SDL does as seen here: [URL]

It's defined in the abi over here: [URL]

If you still want to fall back to the other names I would suggest this in glx_context.c:

```
    char* libGL_names[ ] =
    {
        "libGL.so.1",
        "libGL.so",
        "/usr/lib/libGL.so.1",
        "/usr/lib/libGL.so",
        NULL
    };
```
