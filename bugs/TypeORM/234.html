Title

0.3 generic findOneBy typescript error

Description
## Issue Description

With the upgrade to the new syntax in 0.3 there is a typescript issue with using `findOneBy` on a generic repro.

```
typescript
export abstract class BaseEntity {
  abstract readonly id: string
}

... [Log Snipped] ...
  if (repo) {
    existingEntity = await repo.findOneBy({ id: entity.id })
```
### Expected Behavior
The code above should compile fine, no issues


### Actual Behavior
I get the following typescript error.

```
TS2345: Argument of type '{ id: string; }' is not assignable to parameter of type 'FindOptionsWhere  | FindOptionsWhere []'.   Types of property 'id' are incompatible.     Type 'string' is not assignable to type 'FindOptionsWhereProperty > | undefined'.
```
