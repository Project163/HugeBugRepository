Title

ITK build failed by broken VTK dependency

Description
The commit   override ed9357a "-DModule_ITKVtkGlue=${ITKVtkGlue}".
As mentioned in @Rastaban, it breaks the dependency to VTK.

Therefore, It cause build failure as reported by @JackBoosY when install itk first. 

NG: vcpkg install itk:x86-windows
OK: vcpkg install itk[vtk]:x86-windows
OK: install vtk:x86-windows then install itk:x86-windows
