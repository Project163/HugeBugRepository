Title

querying uncovered index column on a non-existent row causes crash in yb::ql::RowsResult::SetPagingState()

Description
Test Setup:

```
CREATE TABLE IF NOT EXISTS kv (k int PRIMARY KEY, v int, c text) WITH TRANSACTIONS = { 'enabled' : true };

CREATE INDEX by_v ON kv(v);

INSERT INTO kv(k, v, c) VALUES (1, 11, 'a');
INSERT INTO kv(k, v, c) VALUES (2, 22, 'b');
```

Querying for columns covered by the index (such as k which is automatically in the index) on a non-existent row works fine and returns 0 rows as expected.
```
cqlsh:demo> SELECT k FROM kv WHERE v=33;

 k
---

(0 rows)
```

But querying for a column which is not covered by the index for a non-existent row results in the following crash, instead of an empty result set.
```
cqlsh:demo> SELECT c FROM kv WHERE v=33;
OperationTimedOut: errors={' ': 'Client request timeout. See Session.execute[Link: _async]'}, last_host= 
```
