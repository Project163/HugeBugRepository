Title

The concurrent build model is interlocked abnormally, causing the build to fail

Description
The concurrent build model is interlocked abnormally, causing the build to fail 

   

 e.q. 

 Job ID：470233e2-3dff-e3ba-d947-751dd45a7cba 
Model :  model_64 

 Job ID：cc29d2c3-1352-63d0-e457-5adead341722 
Model :  model_30 

 appearance： 

 model_64 has obtained the lock of the global dictionary, but model_64 has not been built because model_30 has obtained all the resources, and the model_30 building job has not obtained the lock, and all resources are still unable to be build, forming a deadlock.
Discussion
- Design  

 Before building the dictionary column lock, check whether the current spark application has been successfully registered to the worker, 

 if not, wait until the worker is registered and then lock the dictionary column.
