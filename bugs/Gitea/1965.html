Title

go mail to 0.7.2 adding 8BITMIME to MAIL FROM causing SMTP failtures.

Description
### Description

When testing with the following config:

```
[mailer]
ENABLED = true
FROM = example@example.com
PROTOCOL = smtp+starttls
SMTP_ADDR = smtp.zeptomail.eu
SMTP_PORT = 587
USER = emailappsmtp.XXXXXXXXXXXXX
PASSWD = XXXXXXXXXXXXXXX
```

The SMTP Log Shows

`MAIL FROM:example@example.com BODY=8BITMIME SMTPUTF8`

The extra information (from what I understand is rfc6152, SMTP extensions) is causing a MAIL FROM 501 validation issue with the provider. This is because they require strict sending from.

I have tried to override it `[mailer.override_header]` while these are overserved, not when issuing the MAIL FROM.

I have also tried setting ENVELOPE_FROM which removes the "<>" surrounding the email address in the MAIL FROM, however the 8BITMIME is still being used.

How can we disable SMTP Extensions Please, or have them off as default?

1.25.2
