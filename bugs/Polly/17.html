[Bug]: Not able to retrieve Context Information inside OnRetry

Description
### Describe the bug

I am trying to retrieve Context information inside the OnRetry callback, but I am not able to get it.

In the Console we are expected to see the Logs like

```

```

```
On Retry: 0 Content: 
```

### Contents of SharedPool
- The issue here is in your usage.

In the call here:

```csharp
await pipeline.ExecuteAsync((context, token) => throw new Exception(), resilienceContext);
```

The `ResilienceContext` isn't being treated directly as the `ResilienceContext` for the execution, but as the _state_ for the execution (which happens to be of type `ResilienceContext`) as it resolves to this overload:

[URL]

This means that Polly internally retrieves a different `ResilienceContext` from the pool and passes it to your delegate, and because of this it doesn't contain your custom properties.

You should change your code as shown below:

```diff
- await pipeline.ExecuteAsync((context, token) => throw new Exception(), resilienceContext);
+ await pipeline.ExecuteAsync((context) => throw new Exception(), resilienceContext);
```

This will invoke this different overload, which gives the desired result as the `resilienceContext` will be used as the `ResilienceContext`, rather than the `state`:

[URL]

I'll see if there's a note we can add to the docs to help people avoid making this sort of mistake.
