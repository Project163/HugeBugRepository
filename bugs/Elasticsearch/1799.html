Title

Add `max_concurrent_searches` to msearch-template

Description
Multi-search supports the `max_concurrent_searches` QS parameter, but this is missing from the `/_msearch/template` endpoint:

```
PUT test/foo/1
{"user":"john"}

GET _msearch/template?max_concurrent_searches=1
{"index": "test"}
{"inline": {"query": {"match":  {"user" : "{{username}}" }}}, "params": {"username": "john"}} 

```

throws:

```
"request [/_msearch/template] contains unrecognized parameter: [max_concurrent_searches]"
```
