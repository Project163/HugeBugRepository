Title

Invalid hash key "serialVersionUID"

Description
Using "serialVersionUID" as a hash key with bracket notation throws exception
Discussion
- I think the reason is that Groovy tries to access the serialVersionUID field of the class that implements the map. 

 That would make this a MOP2 issue... interesting catch
- def map = [serialVersionUID:123]
 assert  map[ "serialVersionUID" ] == 123
 assert  map.serialVersionUID == 123

map.put( "serialVersionUID" , 789)
 assert  map[ "serialVersionUID" ] == 789
 assert  map.serialVersionUID == 789
 // the above codes work well.
 
 // but using  'putAt'   throws  ReadOnlyPropertyExcetption
 map.putAt( "serialVersionUID" , 333)
