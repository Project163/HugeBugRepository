Title

[MPS] nn.MaxUnpool{1,2,3}d fails to check shape consistency between input and indices (Silent Failure)

Description
### 🐛 Describe the bug

I discovered a behavioral inconsistency between the CPU and MPS backends regarding `nn.MaxUnpool1d`,`nn.MaxUnpool2d`,`nn.MaxUnpool3d`.

### 1. nn.MaxUnpool1d

```
python
import torch
import torch.nn as nn

layer = nn.MaxUnpool1d(kernel_size=3, stride=2)
... [Log Snipped] ...
except Exception as e:
    print(f"MPS Error: {e}")
```
output
```bash
--- CPU Behavior ---
CPU correctly caught the error:
Expected shape of indices to be same as that of the input tensor ([8, 8, 1]) but got indices tensor with shape: [8, 7, 1]
--- MPS Behavior ---
MPS failed to catch the error. Output shape: torch.Size([8, 17])
```

### 2. nn.MaxUnpool2d
```
python
import torch
import torch.nn as nn

layer = nn.MaxUnpool2d(kernel_size=3, stride=2)
... [Log Snipped] ...
except Exception as e:
    print(f"MPS correctly caught the error:\n{e}")
```
output

```bash
--- CPU Behavior (2D) ---
CPU correctly caught the error:
Expected shape of indices to be same as that of the input tensor ([1, 1, 4, 4]) but got indices tensor with shape: [1, 1, 4, 1]

MPS failed to catch the error. Output shape: torch.Size([1, 1, 9, 9])
```
### 3. nn.MaxUnpool3d
