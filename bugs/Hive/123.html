Description

Discussion
- The fix turns out to be simple: 

 The following code in Hive.g: 
  
 queryStatementExpression
    : queryStatement (queryOperator^ queryStatementExpression)*
    ;
 
  

 should be changed to: 
  
 queryStatementExpression
    : queryStatement (queryOperator^ queryStatementExpression)?
    ;
