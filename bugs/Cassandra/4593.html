Title

Avoid byte-array copy when key cache is disabled

Description
While profiling a cluster with the key cache disabled some unnecessary heap pressure was observed. It seems that even though the key cache is disabled we still create the  KeyCacheKey  object which uses  ByteBufferUtil.getArray()  to copy the keys byte array. 

 I don't believe it's a big issue but it's still unnecessary when not using the key cache.
