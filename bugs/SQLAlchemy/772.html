Title

Fix references to utf8 in mysql documentation to utf8mb4 instead

Description
**Migrated issue, originally created by MartinH ([Link: @dwt])**

Hi there,

it is a sadly not so well known shortcoming that mysql utf8 is actually just a subset of utf8 (they also call it utf8mb3) that can only encode up to 3 bytes of utf8 into the database. (Supposedly this was added for performance reasons at some point in the past).

Well, we are stuck with it now, and as a user you will definitely _not_ want to use utf8 as an encoding in mysql.

So here is the bug report: in the documentation, for example here: [URL] utf8 is casually used as an example, and I think you should use utf8mb4 instead. Perhaps even with a note as to why utf8 is bad. I haven't prepped through the documentation, but I suspect this is used in more places.
