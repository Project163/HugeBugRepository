Title

CTMLoader : DEPRECATED: BufferGeometry's addAttribute() now expects ( name, attribute ).

Description
Both CTM Loaders examples generates these warning messages:

```
DEPRECATED: BufferGeometry's addAttribute() now expects ( name, attribute ). 
```

the funny thing is that the only places where this method is called are in CTMLoader : 

```
this.addAttribute( 'index', vertexIndexArray, 1 );
this.addAttribute( 'position', vertexPositionArray, 3 );

if ( vertexNormalArray !== undefined ) 
    this.addAttribute( 'normal', vertexNormalArray, 3 );
... [Log Snipped] ...
if ( vertexColorArray !== undefined ) 
    this.addAttribute( 'color', vertexColorArray, 4 );
```

but the calling convention seems respected, isn't it?
Discussion
- OK, it seems the problem is caused by the worker which cannot really create THREE.BufferAttribute as it has no access to THREE i.e. the following code fails : 

```
CTM.FileBody = function(header){
  var i = header.triangleCount * 3,
      v = header.vertexCount * 3,
      n = header.hasNormals()? header.vertexCount * 3: 0,
      u = header.vertexCount * 2,
... [Log Snipped] ...
  }
};
```
- Should be now fixed in the `dev` branch. Changed the pattern a bit.
Thanks for the pointer!
