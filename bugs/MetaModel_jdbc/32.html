Title

Drop table doesn't work for views with JDBC Tables

Description
A JdbcTable is a MutableTable. A MutableTable can have different TableType including TABLE and VIEW. 

 The JdbcDropTableBuilder (line 69) builds a SQL Statement to drop tables: 
  
 
 "DROP TABLE "  + tableLabel
 
  
 This doesn't work if the MutableTable has TableType VIEW. Then it should be: 
  
 
 "DROP VIEW "  + tableLabel
 
  
 I haven't investigated this issue for other types of datastores. Only for JDBC.
Discussion
- This seems correct and should be pretty easy to fix. To my knowledge the JDBC connector is the only one that even uses TableType.VIEW.
- The PR has been merged, the issue can be set to done?
