Title

Ivy: ChangeDetection not running on transplanted views

Description
# 🐞 bug report

### Affected Package
ivy in 9.0.x

### Is this a regression?
Yes, it fails to update templateRef in ivy, but works in VE.

### Description
TemplateRef doesn't update in a dynamic Component created by an external js lib (ag-grid, using appendChild) in Ivy. (exemple 1)

TemplateRef doesn't update in a child Component of an OnPush Component in Ivy. (exemple 2)

exemple 3 & 4 work fine

1. TemplateRef -> Component OnPush -> Component -> dynamic Component with ngTemplateOutlet **(fails)**
2. TemplateRef -> Component OnPush -> Component with ngTemplateOutlet **(fails)**
3. TemplateRef -> Component -> Component OnPush with ngTemplateOutlet **(works)**
4. TemplateRef -> Component OnPush -> dynamic Component with ngTemplateOutlet **(works)**
