Title

BaseActiveRecord::setAttribute() produces an "Undefined index" error

Description
BaseActiveRecord::setAttribute() produces an "Undefined index" error when setting values of some attributes of new active records.
This causes the program to terminate when error reporting is set to E_ALL.
Discussion
- I've made a little research and I've come to a conclusion that the code which produces an error is a part of the `BaseActiveRecord::updateInternal()` function:

```
php
    protected function updateInternal($attributes = null)
    {
        ...
        $changedAttributes = [];
... [Log Snipped] ...
        ...
    }
```
- I was able to temporarily fix this issue by adding this line to my column's validation rules:

``` php
['token', 'default', 'value' => null],
```
- I can confirm, I hope this will be fixed asap!
- I think this is a pretty grave bug; I hope it can be fixed soon!
