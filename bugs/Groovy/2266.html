Title

Type checker confuses method calls on closure expressions with closure.call

Description
The following code does not compile because the type checker confuses  curry  with  call : 

  
 @TypeChecked
void test() {
    def cl = { it }.curry(42)
    def val = cl.call()
     assert  val == 42
}
