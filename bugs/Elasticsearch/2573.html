Title

Retrieving a field with null value triggers a NPE

Description
Indexing the following document:
```
{
    "a": {"b": 0},
    "a.b": null
}
```
and retrieving it with:
```
{
    "fields": [
        {
            "field": "a.b"
        }
    ]
}
```
will fail due to:
```
Caused by: java.lang.NullPointerException
        at java.util.ArrayDeque.addLast(ArrayDeque.java:303) ~[?:?]
        at java.util.ArrayList.forEach(ArrayList.java:1511) ~[?:?]
        at java.util.ArrayDeque.copyElements(ArrayDeque.java:329) ~[?:?]
        at java.util.ArrayDeque.addAll(ArrayDeque.java:324) ~[?:?]
... [Log Snipped] ...
        at org.elasticsearch.common.util.concurrent.AbstractRunnable.run(AbstractRunnable.java:26) ~[elasticsearch-8.0.0-SNAPSHOT.jar:8.0.0-SNAPSHOT]
        ... 6 more
```

(Simply stripping the `null`s [Link: before enqueuing] the values seems to fix it.)
