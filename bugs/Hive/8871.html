Title

MergeFileTask.execute() need to close jobclient

Description
So when YARN use Https, MergeFileTask causes more and more Threads named “ReloadingX509TrustManager” in HiveServer2。The threads named “ReloadingX509TrustManager” does not interrupt，and HS2 becomes abnormal。 

 In MergeFileTask.execute(DriverContext driverContext) ,a Jobclient created but not closed。The issue cause above。
