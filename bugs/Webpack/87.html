Title

How to trigger a throw on import / require

Description
I'm a big fan of webpack and have stumbled on an interesting pattern for electron where I can shim browser stubs or versions like this so I don't need to modify the node code directly:

// electron

```
config.externals = {
  'fs': require.resolve('fs')
}
```

// browser

```
config.alias = {
  'fs': require.resolve('fs-memory/singleton')
}
```

Really amazing! 

I have a case that I'm trying to solve....I want to throw in the browser like this since the module import is being wrapped by a try / catch already to fallback to a less efficient implementation...

// electron

```
config.externals = {
  'fsevents': require.resolve('fsevents'),
}
```

// browser

```
config.alias = {
  'fsevents': THROW AN ERROR!
}
```

I originally, naively implemented it like:

// browser

```
config.alias = {
  'fsevents': require.resolve('stubs/throw')
}
```

but when I have multiple throwing shims or the module is loaded in multiple places, it only throws the first time as you would expect since the second time the module is in cache.

How can I throw each and every time for multiple modules and multiple import / require call?

```
config.alias = {
  'fsevents': THROW AN ERROR!,
  'somethingelse': THROW AN ERROR!
}
```
