Title

d3.layout.tree children not update

Description
When updating my model the d3 children attribute is not updated if I remove all children from the model.
I have a hierarchy model, which works great initially. If I remove all the child nodes/branches, the d3 children attribute is not updated on the node. This then causes (dead) links to get created, because the links function is looking at the node' s children. 

I'm using release 3.3.3 and making the following calls:

```
nodes = tree.nodes(hierarchy)
links = tree.links(nodes)
```
