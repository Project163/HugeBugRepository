Title

Port number must be set on quarkus.spring-cloud-config.url to pass the test

Description
## Describe the bug
My Quarkus project reads its configuration from a central Spring Cloud Config Server. I've set the corresponding properties, so it works when running `mvn quarkus:dev` but fails when running the tests `mvn clean package`

### Expected behavior
Such command should work. It runs the test using the  quarkus.spring-cloud-config.url property without the need to add a special port.
quarkus.spring-cloud-config.url=[URL]

### Actual behavior
Got an exception:
`Caused by: java.lang.RuntimeException: Failed to start quarkus
Caused by: java.lang.RuntimeException: Unable to obtain configuration from Spring Cloud Config Server at [URL]
Caused by: java.lang.IllegalArgumentException: port p must be in range 0  )
