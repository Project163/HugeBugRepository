Title

Strange "Returning Any" warning

Description
`mypy --warn-return-any` (ver. 0.550) gives a strange "Returning Any from function ..." warning for the following code:
```
def f(a: 'A') -> int:
    if a._x == 2:
        return 2
    n = 1
    return n
... [Log Snipped] ...
    def __init__(self) -> None:
        self._x = 2
```
```
foo.py:5: warning: Returning Any from function declared to return "int"
```
Combining `n = 1` `return n` into one statement `return 1` or putting the definition of `A` before `f` makes the warning disappear.
