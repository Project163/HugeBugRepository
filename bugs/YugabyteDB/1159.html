Title

[YSQL][randgen] Bitmap Scan ERROR: variable not found in subplan target list

Description
Jira Link: [Link: DB-10984]
### Description

Problem
---
* The query returns "ERROR: variable not found in subplan target list". 
* The EXPLAIN command doesn't work, either, with the same error.
* Reproducible on a recent master (42add04f18).

```sql
create table t (pk int primary key, k int);
create index on t (k ASC);
explain /*+ bitmapscan(t2) */ select * from t as t1 join t as t2 on t1.k = t2.pk or (t1.pk = t2.k and t1.k = 1);
ERROR:  variable not found in subplan target list
\errverbose
ERROR:  XX000: variable not found in subplan target list
LOCATION:  fix_upper_expr_mutator, setrefs.c:2590
```
