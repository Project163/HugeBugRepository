Title

Setting datetime64 array as DataFrame column does not convert unit to nanoseconds

Description
Using pandas 0.8 and numpy 1.7,  I get errors when I add columns that are of type datetime64 for everything but very short columns:

```
In [105]: t = np.arange(start='2012-01-01 00:00', stop='2012-01-02 00:00', dtype='datetime64[h]')

In [106]: df = pandas.DataFrame(np.arange(len(t)))

In [107]: df['t'] = t
... [Log Snipped] ...

TypeError: ("ufunc 'isfinite' not supported for the input types, and the inputs could not be safely coerced to any supported types according to the casting rule ''safe''", 'occurred at index t')
```
Discussion
- This is a bug in `isnull` on the datetime64 dtype. I'll get it fixed over the weekend.
- I updated the issue description and will see about fixing. This is really a pain-- the NumPy datetime64 API has been nothing but trouble.
- DataFrame now casts other datetime64 units to nanoseconds behind the scenes-- there's some possibility of supporting the other units at some point in the future, but too much work for me right now.
