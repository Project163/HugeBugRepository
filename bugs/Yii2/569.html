Title

count() on Query with orderBy()

Description
I have relation defined like

``` php
class Company {
    public function getAddresses()
    {
        return $this->hasMany(Address::class, ['company_id' => 'id'])->orderBy('address_id');
    }
}
```

as i always want addresses of companies ordered in the same way

Unfortunately I can't do `$company->getAddresses()->count()` because psql is complaining `[42803] ERROR: column "address.address_id" must appear in the GROUP BY clause or be used in an aggregate function`

Check for orderBy presence could be added here [URL]
Discussion
- Do you have the debug toolbar enabled?
Could you show what SQL gets generated?
- sure, its:

``` sql
SELECT COUNT(*) FROM "address" WHERE "company_id"='17e49540-d3e7-11e4-b3ef-53b449010d08' ORDER BY "address_id";
```
- You can not use order by with `count()`.

``` php
$company->getAddresses()->orderBy([])->count();
```
