Title

False positive with \Ds\Vector::toArray()

Description
```
php
 vector->toArray()` returns `list `. Unfortunately it doesn't understand that and reports this error:

```
ERROR: PossiblyInvalidArgument - src/Z.php:17:18 - Argument 1 of App\Z::process expects iterable , possibly different type array  provided (see [URL]
                $this->process($this->vector->toArray());

Discussion
