Title

[gym] Incorrect Message About Stored Archive

Description
### New Issue Checklist
- [x] Updated fastlane to the latest version
- [Link: x] I have read the [Contribution Guidelines]
### Issue Description

When a user specifies their own archive path like: 

``` ruby
gym(scheme: "Acme", configuration: "Debug", include_symbols: true, clean: true, archive_path: "ios-build-dev/", output_directory: "ios-build-dev/")
```

The output displays:

``` sh
[12:28:03]: Successfully stored the archive. You can find it in the Xcode Organizer.
```

However the archive is actually not stored in the Xcode Organizer because I specified an archive path parameter.

The solution would be to either:
1. Also store the archive in the Organizer
2. Add a flag that allows the user to set to also store the archive in the organizer
3. Remove the message when the archive path is specified.
