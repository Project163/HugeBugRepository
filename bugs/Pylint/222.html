Title

too-few-public-methods (R0903) on Enum subclasses

Description
Originally reported by: **Anonymous**

---

Given the following code:

```
#!python

"""Sample code for a bug report."""

from enum import Enum
... [Log Snipped] ...
    megashark = 1
    octopus = 2
```

`pylint` will output the following:

```
% pylint -d no-init -r n bugreport.py
No config file found, using default configuration
************* Module bugreport
R:  5, 0: Too few public methods (0/2) (too-few-public-methods)
```

Would it make sense to suppress `too-few-public-methods` on subclasses of Enum?
