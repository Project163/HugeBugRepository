Discussion
- Changed in WSDL2JavaMojo.java line 306/307 from 

         doneFileName = doneFileName.replace('?', '_') 
            .replace('&', ' ').replace('/', ' ').replace(' ', '_'); 

 to 

         doneFileName = doneFileName.replace('?', '_') 
            .replace('&', ' ').replace('/', ' ').replace(' ', ' ').replace(':', ' '); 

 And then it works, the .DONE marker files get created
