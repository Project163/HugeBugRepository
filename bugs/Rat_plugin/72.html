- I think I have 2 solutions.  Both of which should be implemented. 

   
 
	 Add back the SimplePatternBasedMatcher class but deprecated and logging a warning about deprecation.  In addition modify the AbstractRatMojo to accept it.  Then during the create Configuratoin processing add the SmplePatternBasedMatcher info to the final configuration.  This means that the old configuraiton drives the new model, and we give time to switch over.  This would be removed in v1.0
