Title

RestEasy reactive InputStream response using wrong writer

Description
### Describe the bug

I tried to optimize a reactive endpoint streaming input of an audio file based on Quarkus REST Score Console. I replaced generic Response with Reactive RestResponse. It increased the score to 100 but it is using wrong message handler. Tried both ByteArray and InputStream as entity - same result

### Expected behavior

ServerInputStreamMessageBodyHandler should be used write to response

### Actual behavior

Using ServerStringMessageBodyHandler
