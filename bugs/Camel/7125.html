Title

camel-jbang - Dependency command does not handle version

Description
according to the  documentation  the command  camel dependency list  should show the version but does not 

  
 
$ camel dependency list
org.apache.camel:camel-main
org.apache.camel:camel-observability-services
 
  

 moreover using the maven output the version is  null  
  
 
$ camel dependency list --output=maven
<dependency>
    <groupId>org.apache.camel</groupId>
    <artifactId>camel-main</artifactId>
    <version>null</version>
</dependency>
<dependency>
    <groupId>org.apache.camel</groupId>
    <artifactId>camel-observability-services</artifactId>
    <version>null</version>
</dependency>
