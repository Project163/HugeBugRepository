Title

VectorExpressionWriterDecimal is missing null check in setValue()

Description
The VectorExpressionWriterDecimal class created by VectorExpressionWriterFactory.genVectorExpressionWritableDecimal() does not check for null field in setValue, while all the other data types check for null. 

 This can result in NPE when inserting to/from Orc tables:
