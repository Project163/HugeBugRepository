Title

Wrong value of RebalancingStartTime cache metric

Description
If "rebalance delay" property is set in the cache configuration and more then one nodes are joined cluster in a period of rebalance delay then cache metric RebalancingStartTime has wrong value (for example, metric value is 4534024989722 when currentTimeMillis is 1511341657692 and rebalance delay is 5000).
