Title

`pm2 deploy` does not support yaml?

Description
I have an `app.yml` like this:

``` yaml
apps:
  name: app
  script: ./index.js

deploy:
  production:
    ...
```

It works with commands below:

``` sh
$ pm2 start app.yml
$ pm2 restart app.yml
...
```

But deploy goes error:

``` sh
$ pm2 deploy app.yml production
```

Got this:

After transforming app.yml to app.json, it works.

```
OS         : Mac OS X
node.js    : 5.10.1
PM2        : 1.1.1
```
Discussion
- fixed, to get the fix:

```
$ npm install Unitech/pm2#development -g
$ pm2 update
```
- did not solved the problem

getting this : `deploy.yml environment is not defined in ecosystem.json file`

I had kept the very same ecosystem.json file. Don't why it could be involved; removed it, got the message is reporting above ("is not defined in package.json file")

How should yml file be used ?
- A similar problem but with the ".js" file.
```ecosystem.develop.js environment is not defined in package.json file```
- you need to use only *.json file
