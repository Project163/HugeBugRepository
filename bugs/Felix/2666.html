Title

SERVICE_PID property should not be created

Description
The @Component annotation has a boolean flag for creating the SERVICE_PID property which defaults to true. However, the SERVICE_PID property is handled by the DS Implementation and should automatically be set to the configuration PIDs used by the component. 
Therefore this property should never be created.
Discussion
- Deprecated the createPid attribute and always set it to false in the scr annotations
- Removed the pid handling from the scr generator
