Title

[bug] onResized sends { width, height } instead of PhysicalSize

Description
### Describe the bug

Similar to [URL] .. The [onResized][0] payload is written `PhysicalSize`, but only the width and height properties are being received by my handler.

```ts
  async onResized(handler: EventCallback ): Promise  {
    return this.listen (TauriEvent.WINDOW_RESIZED, handler)
  }
```

If I'm following right, [rust sends back][1] a struct with just the width and height, and then the window.ts function above should be constructing a PhysicalSize object before passing it to the handler.

[1]: [URL]
