Title

Undefined offset: 0 at vendor/vimeo/psalm/src/Psalm/Internal/Analyzer/CommentAnalyzer.php

Description
There is an issue when a `@method` tag has an invalid function name for example:
`* @method ClientInterface exchange-connect(array $options = [])`
That method name has a dash, which is invalid for a function name.

The fix to this would be to add a check for `empty($statements)` at [URL] so it looks like so:
```
if (empty($statements) || !$statements[0] instanceof \PhpParser\Node\Stmt\Class_
```
