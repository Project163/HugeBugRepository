Title

.NET: Decimal value scale overflow on representable values

Description
BigDecimal values like "7.3770697413E+11" or "1E+1", when inserted from Java and read from .NET, result in an exception: 

  
 
Decimal value scale overflow (must be between 0 and 28): -1
 
  

 There is even a test for that in  TestEchoDecimal . 

 Those values can be represented in .NET (as 737706974130 and 10, respectively), we should not throw exceptions.
