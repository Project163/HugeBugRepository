Title

Nio UDP dropping bytes

Description
On netflow.io we noticed that when using Nio for UDP, it drops almost half of the bytes per Datagram.

I have written an example:

```
package io.netflow

import io.netty.buffer._
import io.netty.bootstrap._
import io.netty.channel._
... [Log Snipped] ...
  }
}
```

This code produces the following output:

```
[info] Running io.netflow.Server
Starting up
Listening on  :2055
Ready
1392
... [Log Snipped] ...
1416
1416
```

This is the correct length as reported by tcpdump.

As soon as you switch over to Nio: (just replaced Oio with Nio and oio with nio)

```
package io.netflow

import io.netty.buffer._
import io.netty.bootstrap._
import io.netty.channel._
... [Log Snipped] ...
  }
}
```

The output becomes:

```
[info] Running io.netflow.Server
Starting up
Listening on  :2055
Ready
656
... [Log Snipped] ...
632
632
```
