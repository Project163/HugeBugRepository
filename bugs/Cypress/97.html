Title

Latest Mochawesome version do not generate files

Description
### What versions are am I running?
- Operating System: Mac
- Cypress Version: 0.19.4
- Browser Version: 59.0.3071.115

### Is this a Feature or Bug?
There is a bug with latest Mochawesome.

### Current behavior:
The Mochawesome files are not generated.

### Desired behavior:
The Mochawesome files are generated.

### How to reproduce:
Install latest version of Mochawesome and run a cypress test suite.
Discussion
- Our tests are checking against version `1.5.3` of mochawesome, which IS working properly. They seem to have updated how the reports are generated since then and the reports are not generating properly in their latest version (`2.3.0`). 

**Workaround:** For now, you could set your mochawesome package version to `1.5.3` and get the generated reports.
