Title

Quarkus fails to startup if resource is annotated with @Deprecated annotation

Description
**Describe the bug**
When a resource class in Quarkus is annotated with a `@Deprecated` annotation, the application fails to start. I haven't tested if other annotations are also affected.

Example:
```
@Deprecated
@Path("/hello")
public class ExampleResource {

    private final ExampleRepository repository;
... [Log Snipped] ...
    }
}
```

**Expected behavior**
I don't see why this should not work.
And if this is some edge-case that is not allowed by the framework, the error message is misleading and should be improved.

**Actual behavior**
```

	... 17 more
```
