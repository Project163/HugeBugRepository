Title

SQL: COUNT(DISTINCT(field)) returns with decimal instead of long

Description
**Elasticsearch version** (`bin/elasticsearch --version`):
7.4.0

**Description of the problem including expected versus actual behavior**:
using count + distinct together, a decimal number is returned.

**Steps to reproduce**:
```
POST _sql?format=txt
{
  "query": "select event_type, count(*), count(distinct(stock_code))  from table_name group by event_type order by event_type"
}
event_type   |   count(*)    |count(distinct(stock_code))
... [Log Snipped] ...
test4        |65             |2.0
test5        |7              |5.0
```
Discussion
- Pinging @elastic/es-ql (:Query Languages/SQL)
- Indeed, this is issue exists in all branches up to current master.
Even though we return LONG as the type of the column, the `count(distinct  )` is extracted from the result of the HyperLogLog used under the hood for the distinct counts which is a Double.
