Title

range delete by some partition keys deletes more rows than expected

Description
User reported issue.

Setup:
```
./bin/yb-ctl --rf 1 --num_shards_per_tserver 1 --data_dir $HOME/yb-data start
```
Test:
```
CREATE KEYSPACE IF NOT EXISTS test;
use test;

DROP TABLE IF EXISTS security;

... [Log Snipped] ...
insert into security (symbol, field, val1, val2) VALUES ('C', 'f3', 3, '1');
insert into security (symbol, field, val1, val2) VALUES ('C', 'f4', 3, '1');
```

This works fine.
```
DELETE FROM security where symbol='B';

SELECT *
FROM security;
```

The above works fine:
```
symbol | field | val1 | val2
--------+-------+------+------
      A |    f1 |    1 |    1
      A |    f2 |    1 |    1
      A |    f3 |    1 |    1
... [Log Snipped] ...
      C |    f3 |    3 |    1
      C |    f4 |    3 |    1
```

But 
```
DELETE FROM security where symbol='A';
```
ends up deleting 'B' & 'C' as well
