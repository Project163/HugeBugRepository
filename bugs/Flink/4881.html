- zhuzh   dian.fu   Thanks a lot for reporting this issue. 

 This error will not affect the correctness of the result. This is caused by not releasing the EventLoopGroup resource of the netty server correctly. 

 This problem has been reported by users since Beam release 2.8.0  [URL] but it has not been resolved. After investigation, I found that the reason for the problem is that Grpc releases the related resources of Netty Server by schedule tasks started by 1s.  [URL] After 1s, when the schedule Task starts to reclaim resources, the related classes have been unloaded by the UserClassLoader, so ClassNotFoundError is thrown.
