Title

yii\db\Schema:refresh() does not clear all cache

Description
The problem already exists in yii 1.1. has been reported in yiisoft/yii#771.

In short:
`Schema::refresh()` only deletes cache entry for tables that have already been loaded.
It should clear cache for all tables using `getTableNames()` imo.
Discussion
- I don't understand what the problem is. The following code in the original issue in `down()` doesn't look correct to me since the `if` condition will be false:

``` php
if (isset(Yii::app()->db->schema->tables['myTable']->columns['myColumn'])) {
$this->dropColumn("myTable", "myColumn");
}
```
- Let me describe the problem in general, not related to the originally reported issue.

Lets assume we have all schema data already stored in the cache from previous requests.
We also made some changes to the DB so cache data is not up to date.
Now run the following code:

```
php
$db = new \yii\db\Connection(array(/* config here */));

$db->db->schema->refresh();
// no table data will be deleted from cache as reset() only iterates over $this->_tables which is empty at this point.
... [Log Snipped] ...
// Only forcing reload here will give me up to date data
$table = $db->schema->getTableSchema('myTable', true);
```
