Title

DynamicTest.stream does not support checked exceptions

Description
Currently `DynamicTest.stream` uses `java.util.function.Consumer` for the parameter to execute tests. This interface does not allow throwing checked exceptions. Thus, e.g., the following code will not compile:

```
java
    @TestFactory
    Stream  myCodeShouldDoSomethingUseful() {
        return DynamicTest.stream(
                ImmutableList.of(
... [Log Snipped] ...
        public IndividualTestCase(String data) {}
    }
```

In analogy with `Executable`, it would be helpful to use a different functional interface for the test executor whose method throws `Throwable`. Thanks!
