Title

tools/bin/cassandra.in.sh is not preparing CLASSPATH correctly

Description
Compare what is in tools/bin/cassandra.in.sh 

  [URL]

 with what is in bin/cassandra.in.sh 

  [URL]

 For tools, it means that I am not able to execute e.g. " ./tools/bin/sstablemetadata " when developing, e.g. from IDEA, because it will prepare CLASSPATH wrongly. The output of `ls -1 ...` are two files (jar itself and sources.jar) which are separated by "new line" and when fed to CLASSPATH, it will construct it wrongly, having space between, which fails the whole thing. 

 We need to make tools/bin/cassandra.in.sh the same way as it is done in bin/cassandra.in.sh.
