Title

Problem with using .class in an interface def in Groovy 1.6

Description

}

println A.type

 interface  B {

}

println B.type

Discussion
- I've tried to groovyc the following B.groovy (same as the testcase): 

  
  interface  B {
    Class  type = B.class
}
 
  

 The result are 2 classes, B.class and another B$1.class, which seems to be an inner class of B caused by the above declaration.
- Class expressions used in interface(ClassNode) were being stored in its helper inner class (InnerClassNode) as synthetic fields but were being accessed as synthetic getters. Resolved by accessing them as fields instead. 

 Fixed on 1.6.1 and trunk.
