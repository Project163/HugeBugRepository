Title

SnappyIntegrationTest intermittently errors

Description
The test below occasionally fails in my continuous build of Netty's trunk, but does not do so on my laptop.  It appears to be trying to read a 4-byte number from a 32768 byte buffer, from position 32766 in it, which is not going to work.

The fact that it occurs intermittently suggests something is expecting the buffer always to be positioned on a multiple of 4, while there is a race-condition with whatever actually changes its position - ?
