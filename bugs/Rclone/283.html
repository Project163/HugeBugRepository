Title

rc-addr not adhered to for rc commands

Description
Hi,

Trying out the rc flag I noticed it works as expected for a mount:

```
user@mybox:~/tmp$ ps auxww | grep rclone
user    5843 16.0 10.1 1033124 826204 ?      Sl   Mar26 160:42 rclone --config /home/user/.rclone-gdrive.conf mount --allow-other --dir-cache-time=1m --cache-tmp-upload-path=/home/user/.cache/rclone-gdrive-cache-upload --cache-db-path=/home/user/.cache/rclone-gdrive-cache-upload --cache-chunk-size=8M --cache-info-age=6h --cache-tmp-wait-time=10m --cache-workers=2 --buffer-size=16M --attr-timeout=1s --cache-writes --rc --rc-addr= :5572  gdrive-data-cache-crypt: /mnt/rclone-gdrive

user@mybox:~/tmp$ netstat -an | grep 5572
tcp        0      0  :5572       :*               LISTEN
```

However notice that when using the 'rc' flag with '--rc-addr' spesified it stlil tries to connect to localhost:

```
user@mybox:~/tmp$ rclone rc --rc-addr= :5572 cache/expire remote=gdrive-data-cache-crypt:.removemefromcache/
2018/03/27 08:58:09 Failed to rc: connection failed: Post [URL] dial tcp  :5572: connect: connection refused
```

Should 'rc' not honour 'rc-addr' ?

Tried this up to v1.40-025-g1ba3ffdc / 26 March nightly

Thanks!
