Title

Using require('jQuery') and require('jquery') in one webpack project leads to duplicate integration of jQuery

Description
This is basically the same problem as [Link: this requireJS issue]: "require() loads same module multiple times if case is different". I might even have the same origin.

Here's my two cents: I have to js files, both requiring jQuery but using different casing. This results in an increased webpack size. Chrome DevTools show jQuery.js twice in the Source tab:

[Image: image]

When I fix the casing, the size is about 90KB smaller and the second entry in DevTools disappear.

Is this a "works as designed" thing due to javascript being case sensitive or is it a bug?
Discussion
- This is a problem with a case-insensitive filesystem. On a case-sensitive filesystem this would lead to an error because you `require("jQuery")` and `require("jquery")` and only one of this exists. Fix your require or `alias: { jQuery: "jquery" }`. By convention module names should be lowercase.
- MacOS and Windows are case-insensitive and Linux is case-sensitive, so these directories will be trouble not only with webpack :wink:

But shouldn't webpack be case-insensitive nevertheless?
