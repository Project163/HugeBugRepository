### Problem Description

Lucene 10.1.0 on ES 9.0.x exhibits EOF for certain queries.

In particular, it must be a boolean query with a multi-claused `must_not` disjunction.

Discussion
- Pinging @elastic/es-search (Team:Search)
- Reading the code paths:

- `ReqExclBulkScorer#score(LeafCollector, Bits, int, int)` its possible that `max == NO_MORE_DOCS` if that leaf slice is the entire leaf. In this case, I expect that it is as it threw on a cfs file.
- It seems possible that within `MaxScoreBulkScorer#score(LeafCollector, Bits, int, int)` that we actually iterate and force `outerWindowMax` to be NO_MORE_DOCS, just like the passed in `max`
- Then we come to `MaxScoreBulkScorer#scoreInnerWindowWithFilter(LeafCollector, Bits, int, DisiWrapper)` with the `max==NO_MORE_DOCS`.
