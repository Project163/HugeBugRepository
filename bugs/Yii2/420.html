Title

Mkdir errors parallel testing

Description
In my parallel testing scenario (which could also potentially occur in production mode) 

``` php
yii\base\Exception: Failed to create directory 'T:\wc6dev_test\assets\e87a0c9b\css': mkdir(): File exists
```

FileHelper::createDirectory can throw an error when it tries to create a folder which already exists.

[URL]

What happens:
- it checks for a directory
- if not exist, it will try to create
- but when it is created in parallel already, it would throw an error.

The solution for this, is to re-check folder existance when an exception has occurred. If the folder is already created, throwing an error is not required anymore.
