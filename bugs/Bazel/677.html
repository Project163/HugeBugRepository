Title

Misleading error message "file must have a corresponding package"

Description
Repro:
```
mkdir tmp && cd tmp
touch WORKSPACE
echo 'load("@repository//dir:file.bzl", "foo")' > BUILD
bazel build //... --incompatible_disallow_load_labels_to_cross_package_boundaries
```

Output:
```
Starting local Bazel server and connecting to it...
INFO: Invocation ID: 548ced79-efbd-4f49-be0f-03c8e096fb86
ERROR: error loading package '': Every .bzl file must have a corresponding package, but 'dir/file.bzl' does not have one. Please create a BUILD file in the same or any parent directory. Note that this BUILD file does not need to do anything except exist.
INFO: Elapsed time: 1.822s
INFO: 0 processes.
FAILED: Build did NOT complete successfully (0 packages loaded)
```

Error message should report that the repository doesn't exist, instead of complaining about the missing BUILD file.
