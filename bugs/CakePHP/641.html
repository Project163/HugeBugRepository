Title

3.0 "'id' in where clause is ambiguous" error when using findById()

Description
Let's say Posts belongs to Users and that both tables have an id column.

`$postsTable->findById('some id')->contain('Users')->first()` will throw the following error:
`Integrity constraint violation: 1052 Column 'id' in where clause is ambiguous`

I guess this is because `findById('some id')` acts like `where(['id' => 'some id'])` and not like `where(['Posts.id' => 'some id'])`
