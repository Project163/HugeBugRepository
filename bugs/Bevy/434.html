Discussion
- @MrGVSV I don't follow exactly what's going on / broke here, but this looks like a regression.
- Yeah this seems to be an issue with the recent changes to how `TypePath` is used in the reflection serializer. I'll make a PR!
- I should make a note, though, that this only applies to top-level dynamic types. Attempting to serialize a field that is a dynamic type is currently not allowed (or should be if it isn't). 

This is because of the fact that the top-level type is always serialized as a map of its type path to its value. Whereas fields do not contain any self-describing type information. Because of this, we couldn't possibly deserialize a value accurately (i.e. is `123` an `i32` or a `u32`?).

This is also why dynamic types need to be proxied in order to be serialized— they need a type to describe themselves as representing!
