'kwargs': kwargs seems to cause nesting time and time again. It seems to be fixed with:

```
def __init__(self, header, body=None, task='celery.chord',
                 args=None, kwargs=None, app=None, **options):
        args = args if args else ()
        kwargs = kwargs if kwargs else {'kwargs': kwargs}
        Signature.__init__(
... [Log Snipped] ...
        )
        self.subtask_type = 'chord
```

Changing the initial kwargs from {} to {'kwargs':} otherwise apply_async has a problem and then merging the dicts rather than what was there before.

Given that I am unfamiliar with the code base, can someone please check if my reasoning is sound? As the code is right now, it always leads to:
{'kwargs': {'kwargs': {'kwargs': {'kwargs': {'kwargs': {'kwargs': {'kwargs': {'kwargs': {'kwargs': {'kwargs': {'kwargs': {}}}}}}}}}}}}
and further till it reaches recursion depth 1000.
