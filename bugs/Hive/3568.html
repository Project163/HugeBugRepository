Discussion
- ACCUMULO-2815   in Accumulo-1.7.0 added some support for client authentication with Kerberos-enabled in Accumulo. As such, some assumptions like sending a PasswordToken to authenticate with Accumulo isn't valid anymore. 

 Need to try to add enough options to make this work while trying to maintain backwards compatibility with Accumulo-1.6.x which lacks the feature.
- Fixes the AccumuloStorageHandler to work with Kerberos. Lots of reflection to make sure that older versions of Accumulo continue to work with the storage handler as the Kerberos support is only in the most recent version. 

 Some basic unit testing, lots of testing on a secured cluster.
