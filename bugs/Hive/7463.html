Title

AM caching connections to LLAP based on hostname and port does not work in kubernetes

Description
AM is caching all connections to LLAP services using combination of hostname and port which does not work in kubernetes environment where hostname of pod and port can be same with statefulset. This causes AM to talk to old LLAP which could have died or OOM/Pod kill etc.
