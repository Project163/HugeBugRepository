Title

post_update UPDATE statement will bump version_id a second time, but also not get the correct value if a committed_state is present

Description
### Discussed in [URL]

```
py
from sqlalchemy import Column
from sqlalchemy import create_engine
from sqlalchemy import ForeignKey
from sqlalchemy import Integer

    p1.updated_by_id = u2id
    session.commit()
```

```
FROM parent
```
