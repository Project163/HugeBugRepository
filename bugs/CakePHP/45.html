Title

Hash::numeric return false if passed array contains negative number

Description
As title, Hash::numeric() should return true.

Replace

``` php
$values = array_values($data);
$str = implode('', $values);
return (bool)ctype_digit($str);
```

with

``` php
return $data === array_filter($data, 'is_numeric')
```

to fix it
