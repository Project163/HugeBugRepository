**Current behavior**
When I use the method navigate of the router in the ngOnInit method of the root component, nothing happens. Same code is working fine in a child component.

**Expected behavior**
Should work on both root and child component.

**Minimal reproduction of the problem with instructions**

```
export class AppComponent implements OnInit {

  displayComponent: string;

  constructor(private router: Router, private elm: ElementRef) {
... [Log Snipped] ...
  }
}
```

**What is the motivation / use case for changing the behavior?**
Display dynamically a component by using the router on the root component

- Can reproduce [URL]

App component is initialized before the initial navigation.
- Workaround is to use `setTimeout(() => this.router.navigate(['comp2']));` to delay navigation
- @maxime-menard there's an option to disable initial navigation
```
RouterModule.forRoot([], {useHash: true, initialNavigation: false})
```
Then it will work as expected
