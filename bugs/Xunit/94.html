Title

Test class or name with colons doesn't deserialize correctly

Description
I just upgrade xunit from 2.20 to 2.3.1 and some of my tests don't run anymore.

The following message appears in the output console of Visual Studio 2017 : 
~~~
[30.11.2017 10:11:06 Error] [xUnit.net 00:00:00.3681911] TESTS: Test case TESTS.TESTS.a:b failed to deserialize: System.FormatException: Guid should contain 32 digits with 4 dashes (xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx).
   at System.Guid.TryParseGuidWithNoStyle(String guidString, GuidResult& result)
   at System.Guid.TryParseGuid(String g, GuidStyles flags, GuidResult& result)
   at System.Guid.Parse(String input)
   at Xunit.Sdk.XunitTestFrameworkExecutor.Deserialize(String value)
   at Xunit.Sdk.TestCaseBulkDeserializer.Deserialize(ITestFrameworkDiscoverer discoverer, ITestFrameworkExecutor executor, String serialization)
~~~

After some investigation I found out that the character ':' in my test was causing this issue. Here is a sample test that cause problems.
~~~F#
namespace TESTS

open Xunit

type TESTS () =
    [ ]
    let ``a:b`` () =
        ()
~~~

I decided to roll back to the 2.20 version of xunit for all my projects and wait this issue to be fixed.
