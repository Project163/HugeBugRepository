Discussion
- I meet the same problem. Compare to the final code, the tutorial need to add 2 steps: modify the  "/angular.json" file and the create the file "/src/main.server.ts".
- @brandonroberts - Can you take a look?
- @BrendanHenryGithub is right, I was able to fix the build by:

1. creating a `/src/main.server.ts` file with:
```typescript
export { AppServerModule } from './app/app.server.module';
```

2. adding a server target to `/angular.json` right under lint:
```
json
        "server": {
          "builder": "@angular-devkit/build-angular:server",
          "options": {
            "outputPath": "dist/server",
... [Log Snipped] ...
          }
        }
```
Should end up looking kinda like this:
```
json
...
       "lint": {
          "builder": "@angular-devkit/build-angular:tslint",
          "options": {
... [Log Snipped] ...
        }
...
```

3. In `/angular.json` change:
```json
"options": {
            "outputPath": "dist",
```
to:
```json
"options": {
            "outputPath": "dist/browser",
```
This is where the server expects to look for resources
```javascript
// server.ts
app.get('*.*', express.static(join(DIST_FOLDER, 'browser')));
```
