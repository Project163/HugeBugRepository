Title

getOriginal() does not return original null values when they changed

Description
**Expected behavior:** When using an entity's method `getOriginal()` (defined in \Cake\Datasource\EntityTrait), one would expect, as the API says, to get the original value of a property.

I think even some other parts of the code in EntityTrait expect `getOriginal()` to return `null` even if the value has changed. See especially these lines in `extractOriginalChanged()`:

```
        $original = $this->getOriginal($property);
        if ($original !== null && $original !== $this->get($property)) {
            $result[$property] = $original;
        }
```

**Observed behavior:** However, if the original value was `null`, and the property has changed, `getOriginal()` will return the new value instead of `null`.
Discussion
- The problem comes from using `isset()` which will return `false` whether the property is `null` or hasn't been defined.

Proposed fix: use `array_key_exists` instead:

In `getOriginal()`:

``` diff
-        if (isset($this->_original[$property])) {
+        if (array_key_exists($property, $this->_original)) {
             return $this->_original[$property];
         }
```

In `set()`:

```
diff
-            if (!isset($this->_original[$p]) &&
-                isset($this->_properties[$p]) &&
+            if (!array_key_exists($p, $this->_original) &&
+                array_key_exists($p, $this->_properties) &&
... [Log Snipped] ...
                 $this->_original[$p] = $this->_properties[$p];
             }
```
