Title

pm2-docker $HOME variable

Description
There is a problem with running pm2 inside a docker with non-root.

#### Expected behaviour

I want to use environment variable $PM2_HOME (http://pm2.keymetrics.io/docs/usage/specifics/#multiple-pm2-on-the-same-server) for specify where pm2 will keep their system file. It works for pm2 as described in the website.

#### Actual behaviour

Instead of that ```pm2-docker``` ignore $PM2_HOME variable and [Link: use only $HOME variable].

#### Steps to reproduce

Just try to run pm2-docker and pm2 with PM2_HOME=/pm2
