Title

java.time.Instant and java.time.LocalDate not handled in org.apache.spark.sql.jdbc.JdbcDialect#compileValue

Description
When using the new java time API (spark.sql.datetime.java8API.enabled=true) LocalDate and Instant aren't handled in org.apache.spark.sql.jdbc.JdbcDialect#compileValue so exceptions are thrown when they are used in filters since a filter condition would be translated to something like this: "valid_from" > 2020-12-21T11:40:24.413681Z. 

 To reproduce you can write a simple filter like where dataset is backed by a DB table (in my case PostgreSQL):  

 dataset.filter(current_timestamp().gt(col(VALID_FROM)))
