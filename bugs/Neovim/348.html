### Steps to reproduce using `nvim -u NORC`
`:h toupper()` reads that function works `just like applying gU to the string`. I was recently working with some German strings, and noticed that `toupper` (and `~` key) does not uppercase German sharp S character `ß`, while `gU` does (it turns `ß` into `SS` which is still accepted as valid, but [Link: capital ẞ letter] was introduced some time ago to replace it, according to linked Wiki article). 

```
nvim -u NORC
:echo toupper('uppercase ß')
UPPERCASE ß
# applying gU to above string yields
UPPERCASE SS
# title key behaviour is the same as `tolower()` call, ß is untouched
```
For reference, nvim works correctly with new capital letter `ẞ`.

```
nvim -u NORC
:echo tolower('lowercase ẞ')
lowercase ß
# tilde key works as well
```

### Actual behaviour
gU on `ß` gives `SS`, while `echo toupper('ß')` returns `ß`.
