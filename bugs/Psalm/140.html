Title

MissingParamType shouldn't be reported when implementing an interface or overriding a parent class method

Description
I have a class implementing the `\Serializable` interface:

```
php
class User implements \Serializable
{
    private $id;
    private $email;
... [Log Snipped] ...
    }
}
```

However I get this error reported:

The function definition must be compatible with the one defined in the `\Serializable` interface, so this cannot be fixed.
Discussion
- You can always add `/** @param mixed $serialized */`, but I'll fix this.
