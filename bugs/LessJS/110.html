Title

Gate conditions not working as expected.

Description
Hi, 

We are using a server side less 1.6.2 rhino compiler. We have a form that generates variables based on user input and defines the variables. The variable in question is either blank or a hex value. I have something similar to the following in the .less file:

```
& when (iscolor(VARIABLE)) {

.class .class:selected {
     background: VARIABLE;
     }
... [Log Snipped] ...
     }
}
```

When the code runs to compile the file when a color is not specified (and the variable is blank), it throws an error that it can't evaluate the tohsl() function because the variable is not a color.

I would have thought that the is color guard would skip the contents of the brackets since the variable isn't a color. Am I mistaken? What could I be doing wrong? Thanks for anything you can suggest.
Discussion
- Please use [Link: backticks] to format your code.

I think it's a bug (i.e. the content of the ruleset is evaluated regardless of its actual expansion). Meanwhile you can use the oldschool method to achieve the same, e.g.:

```
@var: ;

.-;.-() when (iscolor(@var)) {

    .class .class:selected {
... [Log Snipped] ...
    }
}
```
