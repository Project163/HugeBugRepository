Title

Can't find .ZAP_JVM.properties with %HOMEPATH% when using zap.bat in windows

Description
OS: Windows 7 professional Edition 32 - bit
ZAP_VERSION: ZAP_2.5.0_Cross_Platform
The .ZAP_JVM.properties exists.

When I start zap using zap.bat in windows command line, the shell can't find .ZAP_JVM.properties correctly. The "if exist" statement which use %HOMEPATH% variable is False. I found the value of %HOMEPATH% is something like \Users\username which has not contain the drive letter, and the "if exist" statement need a complete path like C:\Users\username to use. I think the shell should use %USERPROFILE% or %HOMEDRIVE%%HOMEPATH% instead of %HOMEPATH% to find .ZAP_JVM.properties. When I do like this, the shell start zap with the given jvm options in property file correctly.
