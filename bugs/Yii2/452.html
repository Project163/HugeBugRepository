Title

Flash messages not showing after logging out a user.

Description
With a clean install of advanced app.  Open frontend (and backend) siteController.
Add 
Yii::$app->session->setFlash('success', 'You have been successfully logged out!');
to line 107 of frontend/siteController
and Add
Yii::$app->session->setFlash('success', 'You have been successfully logged in!');
to line 91 before the return $this->goBack(); call.

Login and see the successfully logged in message.
Logout and notice there is no successfully logged out message.

Happens the same in the backend as well.

I have a working version I downloaded / updated at:-
"time": "2015-09-24 23:06:03".
(working) meaning I get my flash messages displayed as expected.
Just for some reason my new apps don't display them.

I can see from the logs that the flash messages are being set in the POST logout.
Just not being displayed in the GET index page.

I tried using $this->redirect(['site/login']); as well with the same results.
Discussion
- Sessio is destroyed after calling logout method tahts why you dont see any flash messages after redirect

You can call `Yii::$app->user->logout(false);` if you dont want to session will be destroyed
But i am unsure is it right way or not
- I thought that as soon as you call:-
Yii::$app->session->setFlash(...
It automatically creates a new session?
So logout kills the 'user' session, but setting flash message immediately afterwards will create a new session for basic application functionality.

If I use Yii::$app->user->logout(false);. Does it still retain private information about the user (like username, email etc.)?  Or just their publically available info (like ip, browser etc.)?

I don't want the users info to remain in the session (delete it all when they logout), I just want to be able to display flash messages after they have done so (logout).
Is this doable?
