## Description

When I set-up a **mirror** project on Gitea, I expect to retrieve the _origin_ repository URL somewhere in the payload, But it seems there is **no** API routes that provides this information at this time !

I searched for hours in API, and IMHO the best suited route would be for `GET /repos/{owner}/{repo}` which already provides extensive project information :

```
json
{
  "name": "input-event-daemon",
  "full_name": "ricobelo/input-event-daemon",
  "description": "",
... [Log Snipped] ...
  "website": ""
}
```
I have the information that the project is a **mirror**, but I expect that `original_url` or `website` keys would contain à reference to the _Github_ repository URL which this was cloned from, but they are empty howbeit the information **must** be stored somewhere as it is displayed in "mirror settings" pane  in Gitea Web Interface.

May I missed something ?
