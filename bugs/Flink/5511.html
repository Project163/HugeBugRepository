Title

SystemResourcesCounterTest may caused endless loop when some error occured

Description
When the function run() in  class SystemResourcesCounter  come across Throwable exception, the loop in the function run() of the SystemResourcesCounter class will break, the SystemResourcesCounter thread will finish and the loop in the class SystemResourcesCounterTest will continue because of the condition is still true, the test will in a endless loop.
