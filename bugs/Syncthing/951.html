Title

Mutual encrypted sharing doesn't work (both sides with password)

Description
Please forgive me if I'm wrong here, but I remember this being mentioned on the forum as untested, but as something that "should still work". However, in my testing, it seems to always fail with a "generic error".

1. On Device 1, add a new folder filled with some files to Syncthing.
2. Share the folder with Device 2, setting a password on it.
3. On Device 2, accept the folder, but change the type to "Send & Receive", while also inputting the same password.
4. The two devices connect and try to sync the files, but the process fails with a "generic error".
