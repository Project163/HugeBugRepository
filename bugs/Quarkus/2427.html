Title

NPE when ValueExpressionResolver returns null

Description
### Describe the bug

`ValueExpressionResolver.resolve()` has been explicitly annotated with `@Nullable` in Micrometer 1.11.8:

[URL]

But in Quarkus, this doesn't work as it would throw a NPE here:

[URL]

I was wondering if we could instead skip creating a `Tag` when the resolver returns null.

### Expected behavior

NPE is thrown when the resolver gets invoked.

### Actual behavior

Application should behave normally, metric tag should not be included if the resolver returns null.

### How to Reproduce?

```java
@ApplicationScoped
public class MyValueExpressionResolver implements ValueExpressionResolver {
  @Override
  public String resolve(@Nonnull String expression, @Nullable Object parameter) {
    return null;
  }
}
```
