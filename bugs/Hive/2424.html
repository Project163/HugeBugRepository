Title

Query having same aggregate functions but different case throws IndexOutOfBoundsException

Description
A query having same aggregate functions (e.g. count) but in different case  does not work and throws IndexOutOfBoundsException. 
  
 Query:
SELECT key, COUNT(value) FROM src GROUP BY key HAVING count(value) >= 4
