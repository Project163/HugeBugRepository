Title

YouTube Video Not Embedding with Query Parameters in Embed Component

Description
When embedding a YouTube link using the Embed component, videos do not render properly if the URL contains query parameters (e.g., ?si=...).

**Expected Behavior:**
The YouTube video should embed correctly regardless of query parameters in the URL.

**Actual Behavior:**
Links containing query parameters do not embed, but clean URLs do.

[Image: Image]

[Image: Image]

**Possible Fix:**
The Embed component should strip unnecessary query parameters or handle them correctly when rendering the video.
