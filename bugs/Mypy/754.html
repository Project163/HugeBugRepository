Title

Ignoring "from m import *" should still try to import module

Description
It seems that currently if you do `from m import *  # type: ignore` this actually doesn't introduce any names in the module namespace. Instead, we should still try to import `m` and add any names that don't conflict to the namespace of the module that does the import.
