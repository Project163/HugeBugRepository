Title

First time interaction not working with Object / Array as field default values with Controller

Description
**Describe the bug**
When **useForm** initialized with **defaultValues** ( consists field value as Array or Object ) and **Controller** is used for rendering the input / Custom input field then first time interaction is not working as expected. But from the second time interaction onwards it works fine.  codesanboxlink added for to reproduce the scenario. 

**Version**: (react-hook-form # 7.6.5)

**To Reproduce**

1. Go to '[URL]
2. With in 'Component with react-hook-form' under section1 try to check / uncheck the checkboxes (observe first interaction is not working)
3. With in 'Component with react-hook-form' section2 try to uncheck checkboxes[Surfing, Reading] (observe first interaction is not working) (but Try to check 'Playing' will work fine in the first time interaction) 
4. Same component is working fine with similar data working fine in 'section3' and 'section4'
5. Please reload the page to reproduce every time

*Observations*
- Addition of the fields in to array or object (addition of new key fields in the object) working fine in the first interaction

**Expected behavior**
It should be able to work on the first interaction with give scenario

- Browser [chrome, Firefox, Edge] (hope this is in all browsers)
