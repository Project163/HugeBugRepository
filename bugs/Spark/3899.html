Title

file scheme should be used correctly

Description
A RFC  defines file scheme as   file://host/   or   file:///  .  Wikipedia  
 Some code stuffs  use different prefix such as  file: . 

 It would be good to prepare a utility method to correctly add   file://host   or {{ file:// } prefix.
Discussion
- I think the code is actually using the form   file:/path   which I agree isn't quite right though usually is understood. It's OK to add the two extra slashes, yes. I don't think this needs a utility method.
- Thank you for your comments. 

 It is a little bit complicated since there is a difference among platforms as described  here . On Linux, we have to make a prefix   file://   (add the two extra slashes) to  file:  since a file path that we get is  /path/to . On Windows, we have to make a prefix   file:///   (add the three extra slashes) to  file:  since a file path that we get is  c:/windows .
