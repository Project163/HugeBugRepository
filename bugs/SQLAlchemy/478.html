Title

Error in Directed Graph Documentation

Description
**Migrated issue, originally created by John Mercouris ([Link: @jmercouris])**

If you look in the examples, the documentation mentions that you may setup directed graphs:
[URL]

The code for the directed graph can be found here:
[URL]

Unfortunately the code for the directed graph is actually for an undirected graph
(directed vs undirected graph) [URL]

The reason it is a directed graph is because you may not add a relationship from n1->n2 as well as from n2->n1. The program will crash and complain that there is a duplicate entry. 

For your convenience I have modified the program to show an example of a directed graph:
(http://pastebin.com/xJDPdvYJ) - also attached to this issue. Also attached is the database generated from running the file.

You can run the program to demonstrate it for yourself, thank you for your time.
