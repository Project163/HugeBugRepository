**Description of the problem including expected versus actual behavior**:
When attempting to create a match-all index template, i.e. `index_patterns = ["*"]`, without explicitcly defining a settings object then a NullPointerException is thrown during validation as, it seems, the validation does not take any component templates into account that the index template consists of.
It seems to be in the [Link: PutComposableIndexTemplateAction] class that the NPE is thrown as it assumes the index template has a settings object included and isn't hidden away in one of the component templates used to compose the index template.

The error is still present when testing with version 7.10.1 using the official Docker image from Docker Hub, but the error message is slightly clearer (see below)
