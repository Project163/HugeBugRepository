Title

Problem to sync file's attributes

Description
St v0.8.7, Windows (7 and 8), 2 Nodes, 1 repository.
- on a repository I have a file which Read-Only attribute is True on both nodes;
- I change the attribute on node1 to False;
- after the next sync, the attribute of the file in node2 is always True, so the files are different.

It is the same behaviour with then Hidden attribute and surely others.
Discussion
- "Read only" should be supported and synced correctly. Hidden, archive and system bits (are there others?) as well as complex ACL:s are not synced.
- Original DOS's attributes are 'Archive', 'Hidden', 'System' and 'Read-only'

NTFS added 'Compressed', 'Encrypted' and 'Indexed'.
- Right. "Read only" is the only one of those that is supported and synced, the others are ignored. The bug you ran into is that when _only_ the read-only attribute (or other supported permission bits) are changed, syncthing doesn't pick up on it. This will be fixed shortly.
- I perfectly admit your explanation and I confirm it: I only tried to change attributes of the files, which doesn't affect the modification date of the file under Windows.
