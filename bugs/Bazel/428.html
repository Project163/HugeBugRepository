Title

Remote execution: ALREADY_EXISTS status should be ignored

Description
The remote execution API spec allows for the server to throw back an ALREADY_EXISTS status when the item already exists in remote cache. This is there to save upload time for the client. Bazel should handle this status code properly (succeeding) rather than failing.
