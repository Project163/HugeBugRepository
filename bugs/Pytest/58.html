Title

monkeypatch.setattr('foo.bar', raising=False) raises when foo.bar doesn't exist

Description
Originally reported by: **Florian Bruhin (BitBucket: [Link: The-Compiler], GitHub: [Link: The-Compiler])**

---

I'm trying to patch `sys.frozen` to set it to `True`, but `sys.frozen` doesn't exist yet.

This works:

``` python
monkeypatch.setattr(sys, 'frozen', True, raising=False)
```

This however raises:

``` python
monkeypatch.setattr('sys.frozen', True, raising=False)
```

```
E       Failed: object   has no attribute 'frozen'
```
