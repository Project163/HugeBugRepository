Title

[YSQL] The FetchRow/FetchRows/GetValue template function in libpq_utils file doesn't check actual column type

Description
Jira Link: [Link: DB-9683]
### Description

The `FetchRow/FetchRows/GetValue` template function in `libpq_utils` file doesn't check actual column type. Only value size is checked. As a result it is possible for example to fetch int column as string. No issue will raised in this case but return value will contain unusable data (in-memory representation of int interpreted as a string).

```
auto conn = ASSERT_RESULT(Connect());
ASSERT_OK(conn.Execute("CREATE TABLE t(k INT PRIMARY KEY, v INT, s TEXT)"));
ASSERT_OK(conn.Execute("INSERT INTO t VALUES(1, NULL, 'one'), (2, NULL, 'two')"));
auto rows = ASSERT_RESULT((conn.FetchRows , std::string>("SELECT * FROM t")));
```

Last statement should fail at runtime because it tires to read second column (`v`) as `std::string` while its actual type is `int`.
