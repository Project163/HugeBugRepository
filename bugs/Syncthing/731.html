- The panic/crash is a debug feature caused by the debug tracing you've enabled. Without that it would try to just heal the inconsistency. That said, there is an inconsistency and there shouldn't be...
- Wow. Thank you!

I don't yet have a clue why it's happening, but what is happening is that in a single batch of local file updates, we get the same file twice. We then twice remove the original file from before the update, and add the first and second file.

I do believe it's a bug that we get the same file twice in one batch, but I also think we should handle that case. Because for remote devices I think that can happen legitimately, so we should be able handle it in db. Lots of "I think"s in there, need to investigate :)
