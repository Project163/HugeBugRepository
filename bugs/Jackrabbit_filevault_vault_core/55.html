Title

Importing an user and children with UPDATE mode causes unnecessary warnings

Description
Importing an user and children with UPDATE mode causes unnecessary warnings. 

 Assume a package with a  testuser  and a child node  profile . Installing the package twice with  UPDATE  mode will trigger some warnings at the second install. 

  
 org.apache.jackrabbit.vault.fs.impl.io.JcrSysViewTransformer Unable to move child back to new location
 
  

 That happens because the profile node is saved in a temporary location but when it needs to be restored  [1]  (or  [2]  in trunk) the move fails because profile node already exists under the newly recreated user. We could mitigate the unnecessary warning by first checking if the child node already exists before trying a move.
