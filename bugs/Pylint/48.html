Title

Django, self.object and wrong module referencing

Description
Originally reported by: **Anonymous**

---

I can see rather often wrong module references for messages generated by pylint for programs using Django. Today I managed to make a very short program which demonstrates the problem.

```
#!sh

$ pylint --version ; pylint t.py -r n
No config file found, using default configuration
pylint 1.2.0, 
... [Log Snipped] ...
-rwxrwxr-x   1 chu  chu  142 13 Jun 14:40 t.py
$ cat t.py
```

```
#!python

from django.views.generic import CreateView, UpdateView

class BaseCreateView(CreateView):
    def form_valid(self):
        self.object = ''

```

Why module django.views.generic.edit is mentioned at all? There might be errors in Django, of course, but they should not be able to confuse pylint to that extend...

Vladimir Chukharev

PS. py27-django-1.6.5 on FreeBSD 9.2-STABLE
