Title

ByteBridge.flush() does not flush anything if the target buffer is not writable but expandable

Description
`ByteBridge.flush()` checks if the target buffer is writable using `isWritable()`.  This is incorrect because the buffer's capacity can be increased up to its `maxCapacity`.  Instead, `flush()` should check if the buffer's `writerIndex` has reached at the `maxCapacity`.
