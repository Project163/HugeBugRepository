Title

Make the `{provide:}` syntax more idiot (me) proof

Description
```
  {
    provide: HtmlParser,
    useFactory: (translations: string) => new HtmlParserDecorator(new HtmlParser(), translations),
    deps: [[new OptionalMetadata(), TRANSLATIONS]]
  },
```

->

`Error: Cannot resolve all parameters for 'function (translations) { return new html_parser_2.HtmlParserDecorator(new html_parser_1.HtmlParser(), translations); }'(@Optional(),Token Translations). Make sure that all the parameters are decorated with Inject or have valid type annotations and that 'function (translations) { return new html_parser_2.HtmlParserDecorator(new html_parser_1.HtmlParser(), translations); }' is decorated with Injectable.`
Discussion
- The solution is

```
  {
    provide: HtmlParser,
    useFactory: (translations: string) => new HtmlParserDecorator(new HtmlParser(), translations),
    deps: [[new OptionalMetadata(), new **Inject**(TRANSLATIONS)]]
  },
```

we could make the API much more user friendly by:
- at least throwing a meaningful error,
- auto-magically wraps anything that is not a metadata in an `InjectMetadata` (assert there is only one such thing)
