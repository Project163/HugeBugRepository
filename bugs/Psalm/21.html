Title

Constants inside functions are not recognised

Description
Test case:

```
php
/**
 * @return void
 */
function defineConstant()
... [Log Snipped] ...

echo CONSTANT;
```
Output:


Constants are always global, so there is no error in the above script.
Discussion
- Also fails in the opposite example:


	define('TEST', 2);

	/**
	 * @return int
	 */
	function useTest()
	{
		return TEST;
	}

Output:
- Thanks for this – non-trivial to fix the initial version, as it means storing the constants declared by a function. Even then, there'll be a little fudging – I think it should still fail in this scenario:

```
php
/**
 * @return void
 */
function defineConstant()
... [Log Snipped] ...

echo CONSTANT;
```

i.e. when the constant is not defined on the function in the main block.
- In both cases I think the solution is to tend towards false negatives.
- The latter is now fixed
