Title

Add an overflow_wrap field to the Style type ?

Description
## What problem does this solve or what need does it fill?

When we use a Text component and the value doesn't have a whitespace character near the max size (horizontally) it overflows the max size, the overflow also happens when we exceed the max size vertically (with or without whitespace character)

## What solution would you like?

A field in the Style type like "flex_wrap" that can prevent this behavior

## Additional context

Code with the problem on the y axis : 

```
rust

    });
```

- I'm not sure I follow the issue.

What's the intended behavior here? Do you want the text to be clipped (in which case set the `Style::overflow` field) Or do you want another behavior. Which one?
- This is an old issue, at the time there wasn't an overflow field on the Style type (and i misunderstood the purpose of flex_wrap property in CSS, it's not the solution to my problem, sorry about that and thank you for pointing me to the overflow property instead)

The overflow field with the Clip value is a _valid_ way of fixing the problem of this issue, but that's not what i had in mind when i created it

I don't want the text to just be _hidden_ on overflow, i want it to be wrapped, on the horizontal axis when overflowing it goes to next line and on vertical axis, have a way to "scroll" the text in order to see the rest of it (maybe with a scroll bar, maybe with an input) like we can do in CSS with the overflow: auto, or overflow: scroll property

i just tried it with bevy 0.11 and it seems to work on the horizontal axis with the linebreak_behavior field on the Text type, on the vertical axis though, i don't know how to make it works, i can clip it yes, but how to retrieve the rest of the text then ? Is there currently a way to know wich part of the text is not visible ? Or to "scroll" it ?

Should i close this issue ? Even if it's not quite what i wanted, there is now a fix to the overflowing problem
