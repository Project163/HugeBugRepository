Title

SSH Action does not properly handle arguments that have spaces

Description
The SSH action treats arguments that have a space as separate arguments instead of as a single argument, even if you put quotes or do similar tricks.   

 e.g. 
  
  <command> svn </command> 
 <args> commit </args> 
 <args> -m </args> 
 <args> hello world </args> 
 
  
 This will actually send  svn commit -m "hello" "world"  instead of  svn commit -m "hello world"
Discussion
- There were two issues: 
1. The Java code was merging all of the arguments together with the command and then splitting on whitespace when passing it to the ProcessBuilder 
2. The shell scripts were "flattening" the arguments into a single string and then executing that string 

 The patch reworks both areas to keep the arguments intact.   

 I also added a test to verify that it handles spaces properly now; though its disabled in test-patch but I verified it locally and also ran the ssh example.
- Was accidentally using some other  Arrays  package instead of  java.util.Arrays ; now fixed.
