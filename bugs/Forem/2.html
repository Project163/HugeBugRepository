Title

HTML tag in article title not escaped on front page

Description
# HTML tags not escaped on front page
### Current Behavior
An empty HTML \  tag in an article title is not escaped on the front page page: 
[Image: screenshot-1].

The   tag is evaluated as HTML, as seen in the page source:
```html
 
     The strange   gap in HTML 
 
```

### Expected Behavior
The empty \  tag should be printed as text and not be evaluated as HTML. This is done correctly on the article page and also when searching for articles by tag (https://dev.to/t/html):  
[Image: screenshot-2]
[Image: screenshot-3]


### Additional Info
**Steps to replicate:** 
1. Write an article with an HTML \  tag in the title (Other tags not tested).
2. Publish the article
3. Open the front page (https://dev.to/) and find the link to the article

**Device/Browser:**
macOS 10.12.6 (16G29)  
Safari 11.0 (12604. )  
Google Chrome 61.0.3163.100

iOS 11.0 (15A372)

**Notes:**
I did not test other tags. If this applies to   tags as well, this could potentially be exploited in a cross site scripting attack.
