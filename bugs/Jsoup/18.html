Title

uppercase umlauts get replaced by lowercase umlaut entities

Description
The line

```
System.out.println(Jsoup.clean(" Überschrift ", Whitelist.none()));
```

should print

```
Überschrift
```

but prints

```
überschrift
```

This used to work correctly in v0.3.1, but fails in v1.2.3.

While _baseArray_ in _Entities.java_ distinguishes between lowercase and uppercase umlauts, the above call yields the wrong result.
Discussion
- Thanks for reporting this -- I'll fix it for the next release.
- Fixed support for case-sensitive HTML escape entities.
