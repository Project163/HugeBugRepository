### Describe the Bug

on dynamic pages with `getStaticPaths`, `next/link` will construct incorrect links when used for linking to fragment identifiers like this:

```jsx
  Go  
/* or */
  Go  
```

the links will assume `router.pathname`, e.g. `/posts/[id]#somewhere`, which will throw:

[Image: Screenshot_20210414_210420]

`next/link` should behave like a native anchor, i.e. ` Go `.

(why not simply use native anchors instead of `next/link`? because of correct scroll restoration, see [Link: here])
