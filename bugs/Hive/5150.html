Title

Hive/Druid integration: Exception when time filter is not in datasource range

Description
When  metadataList.isEmpty()  (L222 in DruidQueryBasedInputFormat) returns true, we throw an Exception. However, this is true if query filters on range that is not within datasource timestamp ranges. Thus, we should only throw the Exception if  metadataList  is null. 

 Issue can be reproduced with the following query if timestamp values are all greater or equal than '1999-11-01 00:00:00': 

  
  SELECT   COUNT (`__time`)
 FROM  store_sales_sold_time_subset
 WHERE  `__time` <  '1999-11-01 00:00:00' ;
