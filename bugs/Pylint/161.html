Title

[regression] wrong-import-position false positives in 1.5.0

Description
Originally reported by: **BitBucket: [Link: bossylobster]**

---

```
python
"""Small import example."""

try:
    from collections import OrderedDict
... [Log Snipped] ...
    print OrderedDict
    print six
```

causes a failure:

```
************* Module import_example
R:  7, 4: Too few public methods (0/2) (too-few-public-methods)
C: 10, 0: Import "import six" should be placed at the top of the module (wrong-import-position)
```

---

FWIW if the `except` block is 100% imports, there is no lint error:

```
python
"""Small import example."""

try:
    from collections import OrderedDict
... [Log Snipped] ...
    print OrderedDict
    print six
```
