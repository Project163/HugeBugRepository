Title

Wrong result if filter on fill_null in lazy

Description
### Checks

- [X] I have checked that this issue has not already been reported.

- [Link: X] I have confirmed this bug exists on the [latest version] of Polars.

### Reproducible example

```
python

import polars as pl

ids = pl.LazyFrame({"id": [0,1,2]})
... [Log Snipped] ...
    .to_dict(False)['id']
) == [0,2]
```

### Issue description

The snippet above shoud pass. It passes if we do the collect before the filter

### Expected behavior

No AssertionError

Discussion
- If it helps for debugging, the issue is resolved if I had `pl.all_horizontal`
```
(
    ids
    .join(filters, how='left', on = 'id')
    .filter(pl.all_horizontal(pl.col('filter').fill_null(True)))
    .collect()
    .to_dict(False)['id']
)
```
- You can use `LazyFrame.explain()` for more detail.
```python
ids = pl.LazyFrame({"id": [0,1,2]})
filters = pl.LazyFrame({"id": [0,1], "filter": [True, False]})
ids = ids.join(filters, how='left', on = 'id').filter(pl.col('filter').fill_null(True))
print(ids.explain())
```
output:
```text
FILTER col("filter").fill_null([true]) FROM
LEFT JOIN:
LEFT PLAN ON: [col("id")]
  DF ["id"]; PROJECT */1 COLUMNS; SELECTION: "None"
RIGHT PLAN ON: [col("id")]
  DF ["id", "filter"]; PROJECT */2 COLUMNS; SELECTION: "col(\"filter\").fill_null([true])"
END LEFT JOIN
```
Here `col("filter").fill_null([true])` is performed before join as the LazyFrame reorganized the work and leads to different results.

If we collect before filter:
```python
ids = pl.LazyFrame({"id": [0,1,2]})
filters = pl.LazyFrame({"id": [0,1], "filter": [True, False]})
ids = ids.join(filters, how='left', on = 'id')
print(ids.explain())
ids = ids.collect().lazy().filter(pl.col('filter').fill_null(True))
print(ids.explain())
```
output:
```text
LEFT JOIN:
LEFT PLAN ON: [col("id")]
  DF ["id"]; PROJECT */1 COLUMNS; SELECTION: "None"
RIGHT PLAN ON: [col("id")]
  DF ["id", "filter"]; PROJECT */2 COLUMNS; SELECTION: "None"
END LEFT JOIN
DF ["id", "filter"]; PROJECT */2 COLUMNS; SELECTION: "col(\"filter\").fill_null([true])"
```
- Right, then for left and outer joins the fill_full operator should not be done before the join
