Title

z.getInterpreterContext().out().clear() broken in Python interpreter

Description
Zeppelin 0.7.x, %spark and %python interpreter able to clear output using z.getInterpreterContext().out().clear() 

     

   

 However, master branch and branch-0.8, PythonInterpreter does not provide the same capability.
