Title

Cannot vendor dependencies in master branch (multiple `state` revisions)

Description
It turns out that in `master` branch, in the `rocket_http` crate, the `state` crate is pinned to the `7576652` revision:

```toml
[dependencies.state]
git = "[URL]
rev = "7576652"
```

But in the `rocket` crate, it's pinned to the `0a7457d2` revision:

```toml
[dependencies.state]
git = "[URL]
rev = "0a7457d2"
```

When running `cargo vendor` on a project using Rocket in the `master` branch, this causes the following error:

```
error: failed to sync

Caused by:
  found duplicate version of package `state v0.4.2` vendored from two sources:

  	source 1: [URL]
  	source 2: [URL]
```
