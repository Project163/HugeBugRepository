Title

property decorators break at runtime with ES2015 and circular deps

Description
# 🐞 bug report

### Affected Package
 
  The issue is caused by package @angular/core


### Is this a regression?

 
  No


### Description

  Using the `@Input()` property decorator (or any other property decorators I imagine) targetting ES2015 with a circular dependency on a type will cause a `Uncaught ReferenceError` at runtime.


## 🔬 Minimal Reproduction
```
git clone [URL]
cd istiti-circular-deps-es2015
ng serve
# src/app/autocomplete.directive.ts contains the problematic decorator and circular dep
```

Discussion
- Fundamentally, this feature of TypeScript (`emitDecoratorMetadata`) is broken in ES2015. There's not much we can do other than not rely on it. Unfortunately, it's central to how JIT works.
- I am also facing this issue. It is a shame, since the whole purpose of decorators are adding metadata, and this having this issue kinda breaks it. I am using some custom decorators, so I can workaround the issue, but still... :(
