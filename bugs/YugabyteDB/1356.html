Title

[DocDB] ExternalMiniClusterSecureTest.ReloadCertificates fails in TSAN

Description
Jira Link: [Link: DB-16327]
### Description

This test copies certs dir w/o respecting existing permissions. As result postgres could crash after reloading certificates.
```
FATAL:  private key file "/tmp/yb_tests__2025-04-22T06_45_50__26299.13395.23875/external_mini_cluster_secure_test.ExternalMiniClusterSecureTest.ReloadCertificates. -246362/certs/node. .key" has group or world access
DETAIL:  File must have permissions u=rw (0600) or less if owned by the database user, or permissions u=rw,g=r (0640) or less if owned by root.
LOG:  database system is shut down
```
