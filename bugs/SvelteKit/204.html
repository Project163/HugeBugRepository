Title

`data-sveltekit-preload-code` not working with static adapter and custom base path

Description
### Describe the bug

The `data-sveltekit-preload-code` attribute doesn't work on links when built with the static adapter and a custom base path.

### Reproduction

Start from a fresh `npm create svelte@latest`, configured for static output on GitHub Pages per the docs.

Given a link with a custom base path and `data-sveltekit-preload-code`:

```html
 Hello 
```

When ran locally via `dev`, the code will preload on hover as intended. With `build && preview`, it will not.
