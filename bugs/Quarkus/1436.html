Title

RESTEasy Reactive client: add User-Agent

Description
### Describe the bug

Most websites straight-up refuse REST calls without a `User-Agent`. GitHub's API does. We should probably set one by default, otherwise users have to do:

```java
@ClientHeaderParam(name = "User-Agent", value = "MP REST") 
@RegisterRestClient
@Path("/")
public interface GithubClient {
}
```

And the problem is that if this value is missing, all calls will fail with an exception which does not log the GitHub response, so it takes quite a while to figure out why it fails (see [URL]
