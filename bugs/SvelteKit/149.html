Title

Automatically reset form with use:enhance

Description
### Describe the bug


Native browser behaviour clears form inputs after submit (or rather the associated page reload does that).

The progressively enhanced forms do not. This would require resetting the form in the enhance callback. This works:

Discussion
- I'm assuming we'd only want this to reset for _successful_ submits, and not ones that did `throw invalid(400, whatever)`?

Separately, I'm not really comfortable calling this an "enhancement". It's a user-noticeable change in default behavior without (I'm assuming) them needing to specify any other options. If we want the default behavior to change, then either we need to consider the current behavior a bug, or this change would be a breaking change.
- I would consider it more of a bug than a missing feature. I find myself adding the `({form})=>form.reset()` all over the place to make it feel more like the enhance really just enhanced the experience rather than alter it.

I’d argue that if users want a different behavior with javascript enabled, maybe they could write something like `({form})=>form.save()`
- @williamviktorsson Agreed ! Was surprised when I first tried using form actions that it didn't reset after submit.
