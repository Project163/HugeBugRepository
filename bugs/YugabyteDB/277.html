Title

[YCQL] Server crashes on WHERE condition for key_column and collection_column

Description
In the following test case, we use LIST datatype to demonstrate, but the same issue also occurs when referencing column of type SET, MAP, TUPLE, or JSONB in the WHERE clause.

```
cqlsh:test> CREATE TABLE tab(h INT, r INT, v INT, j JSONB, l list , PRIMARY KEY (h, r)) WITH TRANSACTIONS = { 'enabled' : true};
cqlsh:test> CREATE INDEX vidx ON tab(v);
# Crash - DEREF a collection in WHERE condition for INDEX AND LIST.
cqlsh:test> SELECT * FROM tab WHERE v = 1 AND l[1] = 1;
NoHostAvailable: 
cqlsh:test> 
```
