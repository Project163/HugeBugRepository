- I have been able to reproduce this problem on my Mac OS X laptop. At least, I can trigger one instance of the problem. The tinderbox tests show that the problem occurs there in both the embedded and network cases. A comment in the test says that the problem may occur in the network case and speculates that that may be the only place it occurs. In any event, I ran UpdateStatisticsTest 100 times and saw the problem in 20 of the test runs.
- Attaching derby-5025-aa-disableAutoStatsCalc.diff. This is an attempt to fix this test bug. Committed at subversion revision 1069890. 

 According to a TODO comment in the test, we should disable the automatic calculation of statistics when this test is run. That's what this patch does. I have run the test for 100 iterations on my machine and not seen the problem. So I am reasonably hopeful that this fixes it.
