Title

Unclear error message in spaced-comment rule

Description
The error message of spaced-comment rule in ESLint @   does not account for markers:

``` javascript
/* eslint spaced-comment: [2, "always"] */

/**This is a comment with a marker but without whitespace  
/*error Expected space or tab after /* in comment.*/
```

The error message leads to believe that there should be a space after `/*` where in reality the marker `*` is used in the example and placing the space after `/**` is equally right and should be preferred.
