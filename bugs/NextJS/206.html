### Describe the Bug

Running this example with no changes produces a warning `Warning: Each child in a list should have a unique "key" prop`

```
bash
fizzog:~$yarn dev
yarn run v1.22.15
warning ../package.json: No license field
$ next
... [Log Snipped] ...
event - compiled client and server successfully in 62 ms (189 modules)
warn  - Fast Refresh had to perform a full reload. Read more: [URL]
```

The warning is generated because of the return block in `_document.tsx`

```
tsx
return {
  ...initialProps,
  styles: [
    <>
... [Log Snipped] ...
  ],
}
```

### Expected Behavior

No warning is expected with a fresh install of this example. The fix is rather simple. Remove the array brackets and let the fragment return alone.

```
tsx
return {
  ...initialProps,
  styles: (
    <>
... [Log Snipped] ...
  ),
}
```

### To Reproduce

1) Install the example
1) Start the dev server
1) Navigate to localhost:3000
1) See warning in dev console
