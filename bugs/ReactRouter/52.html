Title

[Bug]: Error: useNavigate() may be used only in the context of a component.

Description
### What version of React Router are you using?

^6.0.2

### Steps to Reproduce

"mobx-react": "^7.2.1";
When I use mobx-react to wrap the function component, and then I can't use usenavigate for route hops

```
ts
const App: React.FC = observer(() => {
  const navigate = useNavigate();
  console.log(navigate);
  return (
... [Log Snipped] ...
  );
})
```
It is normal for me to use useNavigate in components that do not use Mobx
```
tsx
const LoginPage: React.FC = () => {
  const navigate = useNavigate();
  console.log(navigate);
  return (
... [Log Snipped] ...
}
export default LoginPage;
```

### Expected Behavior

I can use the useNavigatemethod normally after using mobx

### Actual Behavior

The console then reports an error

```ts
index.tsx:19 Uncaught Error: useNavigate() may be used only in the context of a   component.
    at invariant (index.tsx:19)
    at useNavigate (index.tsx:457)
```
Discussion
- This doesn't have anything to do with mobx-react. You're using `useNavigate` outside of your ` ` context. You need to put that component somewhere outside and above the App component for you to make use of it there.
- OK，thankful。So I can't use some  funtions of react-route  when the router aren't be created.
