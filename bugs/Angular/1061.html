### Description

Angular CLI no longer respects Ctrl-C


## 🔬 Minimal Reproduction

In any angular project, run `ng serve` and then `Ctrl-C` when you see "Compiling   : es2015 as esm2015". The command keeps running in the background, and echoes to the console continue.
