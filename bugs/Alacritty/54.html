Title

Keybinding open -n -a /Application/Alacritty.app not working

Description
We've had a hack for a while on macOS to open multiple windows as a workaround to #607. I dusted of my MBP this morning and found that it's not working. Running the command from a shell in Alacritty works just fine, but the keybinding version causes Alacritty to exit immediately. Seems that this may be a problem with how we create child processes.

If this is a dupe, I blame GitHub search
