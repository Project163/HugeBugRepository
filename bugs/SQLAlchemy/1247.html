Title

Copied __class_getitem__ in declarative Base class forgets attributes

Description
### Describe the bug

I guess this is caused by [URL] When using it, all other attributes, e.g. `__table__` are forgotten by the table.

### To Reproduce

```
python
T = TypeVar("T", bound="CommonBase")  # noqa

class CommonBase(Generic[T]):
	@classmethod
... [Log Snipped] ...

assert Tab.__table__
```


### Error

AttributeError: type object 'CommonBase' has no attribute '__table__'

### Versions

OS: Linux
Python: 3.7.1
SQLAlchemy: 1.4.28
