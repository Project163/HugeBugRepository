Title

Blender exporter fails when scene contains empty objects when custom props export is selected

Description
##### Description of the problem

When trying to export a Blender scene which contains objects of type "Empty", the export fails when the 'Custom props' checkbox is selected. This happens whether or not the Empty object contains any custom properties. 

If the 'Export' checkbox for the empty object is unchecked, the export completes correctly, even when the empty object does contain custom properties. The empty object is of course not exported in this case.
