Title

GroovyConsole cosmetic annoyances

Description
GroovyConsole has some issues with linespacing in the output window. This is particularly noticeable when usign large fonts as per the attached screenshot.
Discussion
- I couldn't work out the root cause but put in place a "hack" which seems to dramatically improve the problem. The problem seems to be due to having troubles sizing a line if no newline has been output and the style has recently changed. The hack is to output a newline in a few choice spots and then remove it. This seems to settle down the sizing algorithm but possibly may still have problems in highly concurrent scenarios. If any anomalies are noticed please add comments here or raise a separate jira.
