Title

ApplicationScoped bean observing start/stop still observing even when mocked

Description
**Describe the bug**
I have an application scoped bean observing start:

```
@ApplicationScoped
public class SomeBean {
  protected void onStart(@Observes StartupEvent ev) {
    System.out.println("I'm here");
  }
}
```
I can of course see this hit the start method when the application starts.

In my QuarkusTests, I don't actually need/want the start to be hit.

If I use `@InjectMock SomeBean`, or create a `@Mock` replacement that overrides the start, I still see the original `onStart` being called.

**Expected behavior**
If you use `@InjectMock` or an alternative bean with `@Mock`, the original observes should not be called.
