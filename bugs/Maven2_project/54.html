Title

circular dependency failure in the reactor with activated plugins

Description
was unable to include configuration for the release plugin and source plugin (used in the super pom via a profile) to build the release/source plugins as it caused a circular dependency.
Discussion
- I can't find any commits on this, and it's still a problem when you run 
  mvn eclipse:eclipse -r -Dmaven.reactor.includes=components/pom.xml,plugins/pom.xml; 
in this case you first get the assembly plugin to error out due to a circular ref on maven-core. 
Quick solution was to exclude plugins in the DAG (not committed). Is it necessary to have 
the plugins in the DAG?
