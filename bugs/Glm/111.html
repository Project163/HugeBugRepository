Title

glm::faceforward specialization missing.

Description
In  , when `faceforward` is used with a vector type, it results in the following error under Visual Studio 2015:

```
error C2677: binary ' ' (or there is no acceptable conversion)
```

This seems to be because `dot` returns a scalar, which is then compared to a vector.  For example, the instantiation of `faceforward ` is equivalent to:

```
vec2 faceforward(vec2 const & N, vec2 const & I, vec2 const & Nref) {
    return dot(Nref, I)  (0) ? N : -N;
}
```

Adding a `faceforward` specialization for vector types in `func_geometric.inl` fixes this error.  The key difference being, we need to cast `0` to `T` instead of `genType`:

```
template   class vecType>
GLM_FUNC_QUALIFIER vecType  faceforward(vecType  const & N, vecType  const & I, vecType  const & Nref)
{
    return dot(Nref, I)  (0) ? N : -N;
}
```

Perhaps there may be a more succinct solution if there is something like the following already implemented (I don't know GLM internals well enough to know)

```
template  
struct GetValueType {
    typedef genType value_type;
};
template   class vecType>
struct GetValueType > {
    typedef T value_type;
};
```

In which case the existing `faceforward` implementation can simply be changed to use `static_cast ::value_type>(0)`.
Discussion
