Title

Vagrant can't find the private_key file if the working directory path contains spaces on Windows.

Description
### Vagrant version
Vagrant 2.1.1

### Host operating system
Windows 7 Enterprise 64-bit 

### Guest operating system
Ubuntu 16.04

### Relevant parts of the Vagrantfile
```
ruby
Vagrant.configure("2") do |config|
  config.vm.define "x", primary: true do |x|
    x.vm.box = "x"
    x.vm.box_url = " "
... [Log Snipped] ...
  end
end
```
### Relevant parts of the run script (batch-file)
```cmd
set VAGRANT_CWD=C:\Path\With a\Space\
vagrant up
```

### Expected behavior
Vagrant box boots normally using the default insecure vagrant key

### Actual behavior
Vagrant can't find the key and asks for password
```cmd
vagrant@ 's password:
bash: a/Space/.vagrant/machines/x/virtualbox/private_key: No such file or directory
```
