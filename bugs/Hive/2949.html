Title

increase retry attempt, interval on metastore database errors

Description
The current defaults of hive.hmshandler.retry.attempts=1 and hive.hmshandler.retry.interval=1s are very small. In some cases one retry is not sufficient for successful command execution. 

 I have seen cases, specially after metastore being idle for sometime, when it takes 2 attempts for the db action to succeed. In this case, it as a Communications link failure/connection lost error.
