Title

Import of authorizable nodes appears not to process "{BinaryRef}" property values

Description
It appears that import of authorizable nodes will not process binary properties using the '{BinaryRef}' format. Instead, their values are passed to the JCR's XML import handler, which then complains about the value not being base64-encoded.
