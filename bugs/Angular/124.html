Title

Query string parameters are not available via the RouteParams instance.

Description
When user visits URL like the [URL] there is no access to the "queryParam" via RouteParams in the component that is configured to match the "/path/part" route.

When the RootRouter class calls to the navigate method in its constructor, it passes in as a parameter only the path part of a URL discarding all query string parameters.
Discussion
- You can get ahold of `queryParam` with ` params.get('queryParam')`.

If this isn't working, please open a new issue that includes a reproduction showing the expected vs. actual behavior. Thanks!
- It doesn't work after page refresh. This is part of the RootRouter::constructor()

```
this.navigate(location.path());
```
