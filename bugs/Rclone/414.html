Title

rclone mount leads to DELETE when appending to a remotely locked file

Description
#### What is the problem you are having with rclone?
I've noticed that when I write (append) to a file over rclone mount in quick succession, sometimes ownCloud returns a 423 (file locked). This results in rclone giving a DELETE on the file.

- os/arch: linux/amd64
- go version: go1.11.5

CentOS Linux release 7.6 (64 bit)

####  Which cloud storage system are you using? (eg Google Drive)
ownCloud (10.0.10 and 10.1)

```

Discussion
- What is happening here I think is
- the upload fails with a 423 error - this is when the webdav backend deletes the file
```
2019/06/14 12:06:50 DEBUG : rclone_appending.txt: Sizes differ (src 110 vs dst 103)
2019/06/14 12:06:53 ERROR : rclone_appending.txt: Failed to copy: "rclone_appending.txt" is locked: OCA\DAV\Connector\Sabre\Exception\FileLocked: 423 Locked
```
- the next append rclone notices that the nextcloud file is a different length
```
2019/06/14 12:06:53 DEBUG : rclone_appending.txt: Sizes differ (src 103 vs dst 110)
```
- however it can't find the file when trying to read it from next cloud back to the cache
```
2019/06/14 12:06:53 ERROR : rclone_appending.txt: Failed to copy: failed to open source object: File with name rclone_appending.txt could not be located: Sabre\DAV\Exception\NotFound: 404 Not Found
```
