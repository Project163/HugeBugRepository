Discussion
- This appears to be a framework problem, if you call context.getService(ServiceReference) on a service reference that has been unregistered.  The code in Felix is 

     <S> S getService(Bundle bundle, ServiceReference<S> ref) 
    { 
        try 
        {
            return (S) m_registry.getService(bundle, ref);
        }
         catch (ServiceException ex) 
        {
            fireFrameworkEvent(FrameworkEvent.ERROR, ref.getBundle(), ex);
        }

         return null; 
    } 
and if ref is unregistered then ref.getBundle() must return null.  Could we use the ref as the source instead of the missing bundle in this case?
