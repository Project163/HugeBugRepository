Title

Client retry perAttemptRecvTimeout crash

Description
### What version of gRPC and what language are you using?
C++ 1.54.3

### What operating system (Linux, Windows,...) and version?
Ubuntu 22.04

### What runtime / compiler are you using (e.g. python version or version of gcc)
clang 18

### What did you do?

In our project we want to use the `MethodConfig['retryPolicy'][‘perAttemptRecvTimeout’]` parameter from `ServiceConfig`.
It fits our requirements well.

Our result `retryPolicy` looks like:
```
json
    "retryPolicy": {
      "maxAttempts": 4,
      "initialBackoff": "0.001s",
      "maxBackoff": "0.01s",
... [Log Snipped] ...
      "retryableStatusCodes": ["UNAVAILABLE"]
    }
```

### What did you expect to see?

We want `perAttemptRecvTimeout` param to work as expected.
We want to start new attempt in `perAttemptRecvTimeout` if no successful result has been received.

### What did you see instead?

Periodically we get crashes with backtrace:
