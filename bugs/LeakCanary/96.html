Title

Inconsistent version of Kotlin dependencies.

Description
### Description

[Description of the issue]

### Steps to Reproduce

1. Check version number declared in project:
[URL]

2. Check version number published in Maven:
 * [URL] -> Kotlin 1.3.72
 * [URL] -> Kotlin 1.4.21



**Expected behavior:**
Same version from all modules published as transitive dep.

### Version Information

* LeakCanary version: at least 2.8.1 and 2.9.1

### Additional Information

Reason:
core has an explicit dependency:
[URL]

main artifact doesn't:
[URL]
which means it "inherits" the version number from the KGP (`plugins { id("org.jetbrains.kotlin.android")`) applied to the project.

### Recommended fix:
```
# See [URL]
kotlin.stdlib.default.dependency=false
```
+ re-add missing dependencies explicitly if necessary.
