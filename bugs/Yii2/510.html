Title

Description
### What steps will reproduce the problem?

After fix issue #10681, event `beforeValidate` will called after blur on any field with enabled client validation. But `afterValidate` will not called. For example, this code does not work now:

javascript

        console.log('beforeValidate');
        $(this).find('[type=submit]').attr('disabled','disabled');
