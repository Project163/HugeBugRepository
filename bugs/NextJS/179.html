Title

Unable to disable prefetch on `Router.push()`

Description
### What version of Next.js are you using?

12.0.4

### What version of Node.js are you using?

16

Chrome

### Describe the Bug

Calling `Router.push()` is triggering a prefetch request but the downstream service does not allow HEAD requests and is returning 405.

Similar to the `prefetch={false}` prop on the ` ` component, would it be possible to disable prefetching when using `Router.push()`?

I can disable prefetching on `push()`
