Title

SparkPipelineResult waitUntilFinish duration not consistent with PipelineResult

Description
`DataflowPipelineJob` default duration on `waitUntilFinish` is `Duration.millis(-1)` which is inline with `PipelineResult#waitUntilFinish` doc <= 1ms results in infinite wait.  

 However, `SparkPipelineResult#waitUntilFinish` uses `Duration.millis(Long.MAX_VALUE)` hence not being consistent with `PipelineResult#waitUntilFinish`
