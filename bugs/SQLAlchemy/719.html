Title

Chained contains_eager for inherited relationships

Description
**Migrated issue, originally created by Dmytro Starosud ([Link: @dima-starosud])**

This is using sqlalchemy 1.2.0b3.

Please consider following code snippet. Sorry it's a bit long.

It basically defines polymorphic models `_A`, `_B`, `_C`, `A1`, `B1`, `C1` and relationships between them `_A   _B`, `B1   C1`.

Then it `contains_eager` them in different ways `A1 * B1`, `B1 * C1`, `A1 * B1 * C1`, .

Since it works for query`ab` and `bc`, I would expect it to also work for `abc`. Or give some warning/error.

```
class Common:
            @declared_attr
            def id(cls):
                return Column(Integer, primary_key=True)

        #   FROM ...

```
B1.a = relationship(A1, back_populates='b')
        A1.b = relationship(B1, back_populates='a')
        configure_mappers()
