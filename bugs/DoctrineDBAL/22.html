Title

ORA-01427 when listing table columns

Description
Example:
`[SchemaManager]->listTableColumns('TABLE01', 'SCHEMA01')`

Under the following criteria a ORA-01427 is thrown:
- $database parameter != null
- Table exists in another schema with the same name
- Both tables have at least one column with the same name
