Title

Dev mode console handler does not get installed if there are no tests (picocli app)

Description
## Describe the bug
When running my (Pico)CLI app (https://github.com/gunnarmorling/kc-cli) in Dev mode, it doesn't show me the options for restarting that CLI app, editing the passed parameters, etc. It just hangs there:

```
mvn compile quarkus:dev  -Dquarkus.args='info'

...

Quarkus application exited with code 0
```

### Expected behavior
There should be the line telling me about the dev mode options like restarting, etc.

### Actual behavior
That line isn't displayed.

## To Reproduce

Clone the project and run it in dev mode.
