Title

DAO layer is broken

Description
``` php
$db = Yii::$app->db;
$db->createCommand()->createTable('foo', ['id' => Schema::TYPE_PK, 'bar' => Schema::TYPE_INTEGER])->execute();
$db->createCommand()->insert('foo', ['bar' => 1])->execute();
$db->createCommand()->alterColumn('foo', 'bar', Schema::TYPE_STRING)->execute();
$db->createCommand()->insert('foo', ['bar' => 'hello'])->execute();
```

Result:

```
id | bar
 1 | 1
 2 | 0
```

Should be:

```
id | bar
 1 | 1
 2 | hello
```

Same thing using pure PDO show that everything is fine. So this is fw DAO layer bug.
