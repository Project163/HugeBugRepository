Title

SQL: Resolution of aliased field in ORDER BY fails even if declared in projection

Description
The following query:
`SELECT foo f FROM x GROUP BY foo ORDER BY f`
fails with:
`Cannot order by non-grouped column [f], expected (foo)`

The analyzer should be improved to read the aliases inside an `Aggregate` projections not just grouping.
