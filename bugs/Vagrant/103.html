Title

Vagrant snapshot restore exit code is zero when snapshot does not exist

Description
### Vagrant version

```
# vagrant -v
Vagrant 1.8.1
```
### Host operating system

Ubuntu 14.04.3 LTS
### Guest operating system

N/A
### Vagrantfile

Vanilla
### Debug output

N/A, as I believe this is functioning as designed.
### Expected behavior

Exit code of `vagrant snapshot restore foo` should be nonzero when the `foo` snapshot does not exist.
### Actual behavior

Exit code of `vagrant snapshot restore test` is zero when the `foo` snapshot does not exist. 
### Steps to reproduce
1. Create a vanilla vagrant configuration: `vagrant init hashicorp/precise64`
2. Attempt to restore a snapshot that does not exist: `vagrant snapshot restore test`
3. Retrieve the exit code: `echo $?`

For example:

```
# vagrant init hashicorp/precise64
A `Vagrantfile` has been placed in this directory. You are now
ready to `vagrant up` your first virtual environment! Please read
the comments in the Vagrantfile as well as documentation on
`vagrantup.com` for more information on using Vagrant.
... [Log Snipped] ...
# echo $?
0
```

Original discovery occurred when attempting something like this:

```
vagrant snapshot restore test || vagrant up && vagrant snapshot save test
```
