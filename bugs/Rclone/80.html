Title

--retries 1 --low-level-retries 1, Sends the file twice on failure. Expected behavior would be send only once.

Description
1.28 Linux 64bit
Amazon Cloud drive using command
rclone upload --retries 1 --low-level-retries 1 source dest 
I am receiving lots of known errors(408) because of the delays of ACD. The files make it there after a delay so i only want to send the file once to save bandwidth. Even with those retries set to 1, it receives the error and sends the file a second time.
