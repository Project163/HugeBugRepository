Title

indices_boost ignore aliasing

Description
It looks that the top level boosting based on the indices (_indices_boost_) requires that we specify the exact index name.  We cannot substitue an alias pointing to a given index.  This is very inconvenient since it defeats the purpose of having aliases to hide internal organization of the indices.
