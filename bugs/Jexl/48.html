- Note: it was probably not spotted because System.getProperty("java.io.tmpdir") returns a string ending with "/"  - i.e. the separator char - (at least on my system) and pathSeparator (:) is valid as a leading filename character on many systems. 

 I think it's safer to use the appropriate File class ctor rather than making assumptions about how OS file path names are constructed.
