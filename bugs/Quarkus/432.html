Title

-H:+AddAllCharsets passed to native-image even though no extension requested it

Description
-H:+AddAllCharsets passed to native-image even though neither any extension nor user config requests it.

Thanks @lburgazzoli for spotting the symptoms. 

Steps to reproduce: run any itest where `-H:+AddAllCharsets` is not expected in the native mode. quarkus-integration-test-jackson is a good example.

Expected: Either `AddAllCharsets` does not occur at all or `-H:-AddAllCharsets` occurs in the output.

Actual: `-H:+AddAllCharsets` occurs in the output

## Explanation

The implementation of `DeprecatedBuildItemProcessor.enableAllCharsets(List )` is broken:

```
    @BuildStep
    NativeImageEnableAllCharsetsBuildItem enableAllCharsets(List  oldProps) {
        return new NativeImageEnableAllCharsetsBuildItem();
    }
```

It returns a NativeImageEnableAllCharsetsBuildItem regardless if there are any oldProps.

A PR follows
