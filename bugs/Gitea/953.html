Title

Cross-repo commit reference gobbles up whitespace

Description
### Description

#22645 introduced cross-repository commit links. However, it has a bug in that whitespace around the reference is not rendered.

This input:
```markdown
This issue was referenced by archive/flamenco-manager@  at some point
```
Produces this output:
```html
 This issue was referenced by " rel="nofollow">archive/flamenco-manager@a6e5900f09 at some point 
```

As you can see, there should be a space between `by at`.
