Title

Typo in BloomPass.js

Description
in bloompass.js, you can read the following - [Link: code here]

```
this.convolutionUniforms[ "uImageIncrement" ].value = THREE.BloomPass.blurx;
```

Notice the lower case 'x' at the end of the line... I think it is a typo and should be `.blurX`. 

Because later on in the code, you can read the following which is likely the variable referenced above... but with a capitale X - [Link: code here]

```
THREE.BloomPass.blurX = new THREE.Vector2( 0.001953125, 0.0 );
```

What do you think ?
Discussion
- Nice find! Thanks.

The value gets overwritten inside the render loop, which is why this typo was never an issue.
