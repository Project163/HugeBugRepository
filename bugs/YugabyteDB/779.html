Title

[DocDB] Fix DoSplitTablet deadlock

Description
Jira Link: [Link: DB-2812]
### Description

We have a deadlock when registering new tablets. We should be locking in the following order:
 1. Catalog manager
 2. Any tables (ordered by id)
 3. Any tablets (ordered by id)

But we are currently locking the table and tablet first in `RegisterNewTabletForSplit`, then locking the catalog manager mutex.

This is causing `AutomaticTabletSplitITest.PrioritizeLargeTablets` and `CqlTabletSplitTest.SecondaryIndex` to fail occasionally.
