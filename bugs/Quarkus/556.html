Title

QuarkusTestExtension doesn't work with @ExtendWith or @RegisterExtension

Description
**Describe the bug**
Using the getting-started quickstart, the test is generated as follows with the `@QuarkusTest` annotation.

```
java
@QuarkusTest
public class GreetingResourceTest {
    @Test
    public void testHelloEndpoint() {
... [Log Snipped] ...
    }
}
```

Junit offers two more ways to integrate an extension: `@ExtendWith` and `@RegisterExtension` . Both ways allows to order extensions between them so it's usefull when using multiple extensions.

Using any of these two annotations leads to the following error:
```
org.junit.jupiter.api.extension.TestInstantiationException: TestInstanceFactory [io.quarkus.test.junit.QuarkusTestExtension] failed to instantiate test class [org.acme.quickstart.GreetingResourceTest]: Bean is null
Caused by: java.lang.NullPointerException: Bean is null
```


**Expected behavior**
We can use any of the existing way to integrate an extension with QuarkusTestExtension.

**Actual behavior**
Using any of this two extension declaration forms didn't works

```
java
public class GreetingResourceTest {
  @ExtendWith(QuarkusTestExtension.class)
  public class GreetingResourceTest {
      @Test
... [Log Snipped] ...
    }
}
```

Or

```
java
public class GreetingResourceTest {
    @RegisterExtension
    static QuarkusTestExtension quarkusTestExtension = new QuarkusTestExtension();

... [Log Snipped] ...
    }
}
```

Leads to 
```
org.junit.jupiter.api.extension.TestInstantiationException: TestInstanceFactory [io.quarkus.test.junit.QuarkusTestExtension] failed to instantiate test class [org.acme.quickstart.GreetingResourceTest]: Bean is null
Caused by: java.lang.NullPointerException: Bean is null
```


**To Reproduce**
Steps to reproduce the behavior:
1. Follow the getting sarted guide
2. Change the `GreetingResourceTest` to one of the two forms described here
3. `mvn clean test`
