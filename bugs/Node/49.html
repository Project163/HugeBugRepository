Title

Array and Object have different values in REPL and in files

Description
- **Version**: `v6.3.0`
- **Platform**: `4.4.0-31-generic #50-Ubuntu SMP Wed Jul 13 00:07:12 UTC 2016 x86_64 x86_64 x86_64 GNU/Linux`

I have one file, say `is.js`, that contains the following:

``` javascript
exports.isObject = (obj) => obj.constructor === Object
exports.isNumber = (obj) => obj.constructor === Number
```

In the console, `require('./is.js').isObject({})` returns `false`. However, `({}).constructor === Object` returns `true`. Strangely, `isNumber(2)` works as expected. When `require`d from another file, everything works as expected.

Affected classes:
- `Object`
- `Array`
- `Date`
- `Error`
- `RegExp`

Unaffected classes:
- `Number`
- `String`
- `Boolean`
- `Map`
- `Set`
- `Symbol`
- Typed arrays
