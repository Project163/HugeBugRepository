Title

1.5 equivalant of protected void WebRequestCycle.onRequestTargetSet(IRequestTarget requestTarget) is mising from AbstractRequestCycleListener

Description
There is not method equivalent to WebRequestCycle.onRequestTargetSet(IRequestTarget requestTarget) in AbstractRequestCycleListener.
Discussion
- Request cycle on 1.5 maintain an stack of executions of request handlers, that is managed by RequestHandlerStack. 
the patch: 
 
	 add those callback to IRequestCycleListener: 
onRequestHandlerResolved 
onExceptionRequestHandlerResolved 
onRequestHandlerScheduled 
	 removes RequestHandlerStack from the RequestCycle hierarchy, since is it an object rather used by the RequestCycle than a parent of 
	 pulling executor API from RequestHandlerStack to IRequestHandlerExecutor interface 
	 add asserting lines in RequestCycleListenerTest to cover the new callbacks
- +1 for the patch.
- patch applied
