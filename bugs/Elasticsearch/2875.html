Eclipse version 2021.12, using eclipse-jdt 4.22 works as intended. That said, we need both IDE and CLI to match otherwise folks will reformat in IntelliJ and spotless with complain or vice versa.

We can open a PR for spotless for this but the [Link: IntelliJ plugin] doesn't seem to use any kind of dependency management. I suspect the author has to download the updated libraries locally and rebuild.
