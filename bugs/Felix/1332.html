Title

DependencyManager ConfigurationDependency update isn't propagated to super classes

Description
When using the latest release of the dependency manager (3.0.0), configuration dependencies aren't propagated towards parent classes. For previous releases this used to work (2.0.1). 
To reproduce: 
 
	 Have an abstract class which implements the ManagedService interface and has the updated() method 
	 Create a class which extends the previous abstract class 
	 Create a new DependencyManager component with the created class as component 
	 Add a configuration dependency to the component
