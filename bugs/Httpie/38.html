Title

Regression: unreadable output in httpie 0.9.3

Description

[Image: ekrano nuotrauka is 2016-02-15 12-37-21]

At this point I decide to see if I'm running the latest version and run `pip install -U httpie`.  I wasn't.

This is httpie 0.9.3:
[Image: ekrano nuotrauka is 2016-02-15 12-37-42]

I cannot read very-light-grey text on a white background.
Discussion
- There's a workaround: edit `~/.httpie/config.json` and change

```
    "default_options": [],
```

to

```
    "default_options": ["--style=solarized"],
```
- I see, `monokai` doesn't play well with light background colors. It looks like `solarized` was a better  default color scheme choice.
- I believe [Link: one of the selling features of solarize] is that it works well with both light and dark backgrounds.
