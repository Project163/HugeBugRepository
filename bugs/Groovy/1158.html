Title

No stack trace printed in the Groovy console

Description
The following code can not print the stack trace. 

  
  try  {
    1 / 0
}  catch  (Exception e) {
    e.printStackTrace()   // but e.printStackTrace( System .out)   works!
 }
Discussion
- It's only System.out output that is directed to the output pane of groovyconsole and not System.err. Since e.printStackTrace() sends the output to System.err by default, you don't see it in the output pane. 

 Should groovyconsole intercept even System.err output and show it in output pane?
