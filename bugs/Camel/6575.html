Title

camel-kafka - When Kafka pausable consumer is resumed, it reads all the messages from the earliest offset

Description
Hi, 

 I'm trying to add the circuit breaker pattern to a Kafka consumer. In short, I want to suspend the consumer when an exception happens due to an outage in downstream systems and resume the consumer when downstream systems are up again. As a reference I used this example from the Camel documentation:  [URL] (coming from this test:  [URL]
