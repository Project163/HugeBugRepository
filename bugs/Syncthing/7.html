Title

Preserve mode of files

Description
The octal mode of files and directories is currently not preserved.

For example:

```
$ touch file1 file2
$ chmod 600 file1
$ chmod 400 file2
```

These files will not have the modes specified above on the other nodes in the cluster.

(I'm not going to request that user and group ownership be preserved, I don't think that's useful at the moment.)
Discussion
- Yes, this should be supported for sure.
- (#11 for directories)
- Modes are now synchronized when files are updated. However, _just_ updating the mode of a file ("chmod 755 foo") does not update the modified time and will not result in the mode being replicated. If the file contents are changed (or the file touched to update the modtime) the new mode will be synced over.
