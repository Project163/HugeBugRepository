Title

Use user agent parse in cli

Description
When I use user_agent::parse() to parse data, like 

```
    $this->agent->parse($value->http_user_agent);
    echo $this->agent->browser();
```

$value->http_user_agent is not empty, but the result is empty.

I found only when have $_SERVER['HTTP_USER_AGENT'] will the construct load config/user_agent.php

```
    if (isset($_SERVER['HTTP_USER_AGENT']))
    {
        $this->agent = trim($_SERVER['HTTP_USER_AGENT']);
    }
    if ($this->agent !== NULL && $this->_load_agent_file())
    {
        $this->_compile_data();
    }
```

Is need to limit load agent file when get $_SERVER['HTTP_USER_AGENT']?
or use parse() can load agent file?
