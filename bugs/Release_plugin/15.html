Title

[release-plugin] stage-distributions mojo assumes site directory has basename 'site'

Description
A multimodule component should have the whole site staged for review, thus from a fully assembled site tree whose default location as produced by  site:stage  is  ${project.build.directory}/staging  . When such a location is set as the  siteDirectory  configuration property of the specified plugin goal, the site copy fails to find the resulting files because it assumes the  staging  directory was copied to  site .
