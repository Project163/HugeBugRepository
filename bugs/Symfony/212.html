Title

AbstractFormLoginAuthenticator::start return type is too restrictive

Description
### Symfony version(s) affected

5.4

### Description

When a user is not logged in I want to respond with a 401 response rather than redirecting to the login page for certain AJAX endpoints, but the docblock for `AbstractFormLoginAuthenticator::start` specifies that it must return a `RedirectResponse`. This causes false-positives for static analysis tools.

### How to reproduce

 1. Create a class extending `AbstractFormLoginAuthenticator`, implement `start`, return `new Response("Test", 401)`;
 2. Run Psalm
 3. Psalm reports `MoreSpecificReturnType - src/Security/FormLoginAuthenticator.php:148:94 - The declared return type 'Symfony\Component\HttpFoundation\RedirectResponse' for App\Security\FormLoginAuthenticator::start is more specific than the inferred return type 'Symfony\Component\HttpFoundation\Response'`

### Possible Solution

Update the signature on `AbstractFormLoginAuthenticator::start` to indicate that the return type is `Response` rather than `RedirectResponse`.
