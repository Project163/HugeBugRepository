Title

max_over_time treats NaN as the max

Description
## Bug Report
**What did you do?**
a simple query like `max_over_time(foo[30m])`

**What did you expect to see?**
I expected to see the largest value

**What did you see instead? Under which circumstances?**
If there was a single `NaN` in the time range then the value returned is NaN. I made an example test case (which fails) to showcase the issue: [URL]

**Environment**

* Prometheus version:

	verified on 2.2, 2.3, and master
