Title

When it cannot be serialized, it should give a friendly prompt instead of reporting an error

Description
### Environment

* Dubbo version: provider=3.2.0-beta.4-SNAPSHOT   consumer=2.7.18
* Operating System version: mac m1
* Java version: 1.8

Discussion
- The troubleshooting found that the default serialization method was modified in 3.2, hession2->fastjson2, and the consumer of 2.7.18 could not find the corresponding serialization method for the returned heartbeat request. Finally, it can be solved by modifying the provider-side serialization method, as follows:

```
yaml
dubbo:
  application:
    name: sp-provider
  registry:
... [Log Snipped] ...
  provider:
    serialization: hessian2
```
