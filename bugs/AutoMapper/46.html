Discussion
- Can you give the type of the predicate and the type it's mapping too?  Preferably in a gist that can replicate the problem.

Also there's UseAsDataSource that does the predicate translation and apply it to source.
- Yes of course, so the predicate is:
`Expression > _predicate = x => x.Name == "aa" && x.Id == 10 && x.AA == "bb" && x.BUId == 1 && x.BU.Id == 1 && x.BU.Name == "bb";`
and the exception is generate by this line:
`var newPredicate = _mapper.Map >>(_predicate);`

In my project I have a Service Layer that converts predicates from VM to DTO and passes the predicates to the Data Layer using repository pattern which doesn't know anything about the VMs so the UseAsDataSource is not a good option.
- Issue stems from both classes having the same property name.

Workaround might be 

```
public abstract class AuditableEntity  
    {
        public virtual T Id { get; set; }
        public string Name { get; set; }
    }
```

or changing name so it isn't the same name on both classes.

Looking at trying to resolve the issue right now.
