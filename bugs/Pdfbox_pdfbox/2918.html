Discussion
- This change may have to be limited to WingDings (and maybe Symbol) because it would mean that other fonts won't be replaced with a bold font where it makes sense. I got several rendering changes that I'll analyse later.
- The cut of anything after a "," is after all other variants have been tried. At least now only adding "-Regular" is tried currently. 

 I thought removing any ",Bold", ",Italic" etc. should be reasonable, as I don't think ",Bold-Regular" should exist on any system. 

 Is it possible there are fonts, which include a comma within the name, that is not a separator for the font style?
