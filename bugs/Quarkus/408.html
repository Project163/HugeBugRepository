Title

url-pattern not configured properly in Vertx

Description
Quarkus is not handling some contents of a web.xml file properly.
Specifically the url-pattern on a servlet-mapping does not appear
to get set properly in Vertx.

     
         javax.ws.rs.core.Application 
     
     
         javax.ws.rs.core.Application 
         /myresources/* 
     

The request uri passed to resteasy from Vertx is "/myresources/hello"
but is should be "/hello".

This testcase demonstrates the issue
[URL]

--
In order to run the test you need to install this archive in your local repo

mvn install:install-file \
   -Dfile=___FIX_THIS___/lib/utils-arquillian-utils-4.5.0-SNAPSHOT.jar \
   -DgroupId=org.jboss.resteasy \
   -DartifactId=utils-arquillian-utils \
   -Dversion=4.5.0-SNAPSHOT \
   -Dpackaging=jar 

---
Set a breakpoint at following to see the issue
  RootClassNode line 67   ;; here you will see the resource path "/hello" is
                          ;; being registered

  SynchronousDispatcher line 323  ;; here you will see request is of type
                          ;; VertexHttpRequest.  In this obj the value of
                          ;; uri.path is "/myresources/hello" but it should be
                          ;; "/hello"
