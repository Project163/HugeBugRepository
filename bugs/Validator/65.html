Title

Local part of the email address should not be longer than 64 bytes

Description
From RFC 5321: 
 
  .1.  Local-part 
   The maximum total length of a user name or other local-part is 64 
   octets.  

 Example: 
Currently this email address is considered valid although the local part is 65 bytes long: 
john56789.john56789.john56789.john56789.john56789.john56789.john5@example.com
