Title

Multiple +layout/+page.svelte with layout reset should be forbidden

Description
### Describe the problem

Because of the layout reset syntax, it is currently possible to create multiple +page.svelte (or +layout.svelte)

Exemple :
```
routes/path/page/
           +page.svelte
           +page@.svelte
           +page@path.svelte
```

Sveltekit seems to accept that, and choose the most complete file (`+page@my-path.svelte` in this example).

I think this should be incorrect and generate an error.

### Describe the proposed solution

Create a page with multiples +page.svelte file using layout-reset.
