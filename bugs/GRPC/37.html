Title

Why HTTP 401 is not mapped correctly?

Description
Currently the 401 code is mapped to CANCELLED instead of UNAUTHENTICATED.

The implementation in the [Link: status_conversion.cc]

```cpp
case 401:
      return GRPC_STATUS_UNAUTHENTICATED;
```

aligns with documentation: [URL]

However, it seems to me that `grpc_http2_status_to_grpc_status()` function is not getting called anywhere in the code base. 

In [Link], the function checks for grpc status, if it doesn't exist, it defaults to `GRPC_STATUS_CANCELLED` instead of `GRPC_STATUS_UNAUTHENTICATED`
