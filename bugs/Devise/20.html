Title

database authentication failure does not support i18n

Description
Unless I'm mistaken, when a user enter the wrong username/password combo, the database_authentication strategy calls

``` fail(:invalid)```
this is bubbled up to the view through the flash[:alert]. :invalid is converted to string and this is what is returned: "invalid"

However, everywhere else in devise, the translation is done _BEFORE_ being assigned to flash[:alert|:notice].

I would like invalid to have the same behavior
