Title

3.0 - Sorting by id column in Pagination

Description
When Pagination in CakePHP 3.0, I have the following in my view:

```
  Paginator->sort('id', 'PO#') ?> 
```

In the Controller I have:

```
$this->paginate['contain'] = ['Clients', 'Types'];
$this->set('campaigns', $this->paginate($this->Campaigns));
```

Because I am using contain with my Pagination, when I try to sort by the "id" field, I get the following error message:

```
Error: SQLSTATE[23000]: Integrity constraint violation: 1052 Column 'id' in order clause is ambiguous 
```

With CakePHP 2, the Pagination would assume I am filtering by the current model, however, in CakePHP 3, it doesn't seem to be doing this.

Expected outcome: It should sort by Campaigns.id by default, not through an error.

- Hey @dereuromark - found the issue.

I have my sorWhiteList as:

```
public $paginate = [
    'sortWhitelist' => [
        'id', 'title', 'Clients.organization', 'created', 'Vendors.name', 'Designers.name', 'Users.username'
    ]
];
```

If I set it as the following:

```
public $paginate = [
    'sortWhitelist' => [
        'Campaigns.id', 'title', 'Clients.organization', 'created', 'Vendors.name', 'Designers.name', 'Users.username'
    ]
];
```

Then it works.

But if I do NOT prefix the 'id' in the sortWhitelist, then it throws that error.

Does this help at all?
