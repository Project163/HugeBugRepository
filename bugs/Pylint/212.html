Title

ignore-patterns does not skip top-level files

Description
### Steps to reproduce
1. Create repository with README.md file
2. Run pylint: pylint --ignore-patterns='\s+\.md|\w+\.sh' ./*
3. Run pylint with other parameters:
pylint --ignore-patterns='\S+\.md|\S+\.sh' ./* 

### Current behavior
Pylint will print all errors in README.md and *.sh scripts in the repository.
And there is no way to ignore these files.

### Expected behavior
Pylint will ignore all files which contain string "README" in names of file of directory.
Probably it is a good idea to add the option which will force pylint check only Python files.

Discussion
- Hello, thanks for submitting an issue, I renamed issue to make it closer to actual behavior.

Right now list of files to check is built in [Link: `pylint.lint.PyLinter.expand_files`]. It calls [Link: `pylint.utils.expand_modules`]. In this file check [Link: `_basename_in_blacklist_re`]  is run only for subfiles and subdirectories and is not run for top-level files.

I'm not sure whether this was intended behaviour, but IMHO it's viable improvement suggestion.
