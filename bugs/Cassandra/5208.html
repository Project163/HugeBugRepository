Title

Selecting Index by Lowest Mean Column Count Selects Random Index

Description
CassandraIndex  uses   ColumnFamilyStore#getMeanColumns  , average columns per partition, which always returns the same answer for index CFs because they contain no regular columns and clustering columns aren't included in the count in Cassandra 3.0+.
