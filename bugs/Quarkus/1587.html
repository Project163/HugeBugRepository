Title

NullPointerException in RestEasy Reactive with 2.9.0.CR1

Description
### Describe the bug

I just upgrade our service to Quarkus 2.9.0.CR1 and made a call to the Rest API. I now always get the following NullPointerException:

```
2022-04-29 10:43:28,929 SEVERE [com.adi.ret.err.ApplicationExceptionMapper] (vert.x-eventloop-thread-3) Error: java.lang.NullPointerException
	at io.quarkus.resteasy.reactive.server.runtime.ResteasyReactiveCompressionHandler.handle(ResteasyReactiveCompressionHandler.java:52)
	at io.quarkus.resteasy.reactive.server.runtime.ResteasyReactiveCompressionHandler.handle(ResteasyReactiveCompressionHandler.java:14)
```

When I debug into that location, I see that `requestContext.getResponseContentType()` returns null. The reason seems to be that the `headers` field in the `response` only contains a single `Cache-Control` header. We have defined the content type of the response with the `@Produces(MediaType.APPLICATION_JSON)` annotation. Maybe the compression handler is applied before the headers are added?

Our resteasy reactive endpoint is a simple @GET as a kotlin suspend function.
