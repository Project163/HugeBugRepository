Title

Shutdown fails with native epoll

Description
I have this shutdown code that used to work with the nio transport:

  @Override protected void shutDown() throws Exception {
    bossGroup.shutdownGracefully();
    workerGroup.shutdownGracefully();
    channel.closeFuture().sync();
  }

Now this doesn't work anymore; calling the EventLoopGroup's shutdown methods will not close their associated channels, I have confirmed that by debugging—the channel just stays open. I can invoke channel.close() instead, this causes no problem as the close() call is a no-op on already-closed channels, so no big deal except that I thought the code above was more recommended, and the fact that it fails only with the native epoll is at least an inconsistency and maybe points to some bug.
