Title

--s3-profile does not work when AWS_PROFILE does

Description
#### What is the problem you are having with rclone?

I believe there's a bug somewhere in between `--s3-profile` and `AWS_PROFILE`. The latter works, the former doesn't.

I'm using AWS s3 with MFA and a corresponding profile declared in `~/.aws/credentials`.

`~/.rclone.conf`:

```
[mys3]
type = s3
provider = AWS
env_auth = true
region = us-east-1
acl = private
```

`~/.aws/credentials`:

```ini
[my-aws-profile-mfa]
aws_access_key_id =  
aws_secret_access_key =  
aws_session_token = sssssssssssssssssssssssssssssssssssssssssssssssssssssssssssssss
```

This works:

```sh
AWS_PROFILE=my-aws-profile-mfa rclone lsd 'mys3:'
```

This fails:

```sh
rclone --s3-profile my-aws-profile-mfa lsd 'mys3:'
```

with `AccessDenied`:

```
2020/11/10 15:49:49 ERROR : : error listing: AccessDenied: Access Denied
  status code: 403, request id:  , host id:  
2020/11/10 15:49:49 Failed to lsd with 2 errors: last error was: AccessDenied: Access Denied
  status code: 403, request id:  , host id:  
```

I used `strace` to determine that either invocation reads `~/.aws/credentials` 4 times, so the problem must be something else.
