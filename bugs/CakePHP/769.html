Title

Multiple Select Check Boxes with Grouped Options

Description
This is a (multiple allowed):
- [x] bug
- [ ] enhancement
- [ ] feature-discussion (RFC)
- CakePHP Version: 3.1.10
- Platform and Target: PHP 5.4.28/MySQL 5.5.48.
### What you did

First, I've successfully implemented a Multiple Select box with option groups based on providing an providing a group of options structured like this:

```
$options = [
       'Group 1' => [
          'Value 1' => 'Label 1',
          'Value 2' => 'Label 2'
       ],
... [Log Snipped] ...
    ];
    echo $this->Form->select('field', $options);
```

This is straight from the Cookbook at: [URL]

It works great, and makes a select box exactly as it should.  My issue is that I would like to change the display to be multiple checkboxes.  In order to do that, I've switched the code to:

```
    echo $this->Form->input('field', [
            'multiple' => 'checkbox',
            'options' => $options
        ]);
```
### Expected Behavior

As indicated in the book, I would expect this code to create multiple checkboxes grouped by the group level in the $options array.  
### Actual Behavior

When I do this, the display ends up being a single checkbox, with all the options listed out next to it. 

I've found a thread on SO about this topic, and I've posted my own question.  Responses seem to indicate that this functionality is not currently built into the core.  I'm submitting this ticket as the functionality is written in the cookbook as part of the core, but does not work as outlined in the cookbook.

Thanks for your response to this issue.
