Title

Negative number results in no formatting when using asSize or asShortSize

Description
When using formatter to format byte values on a negative value, it does not provide a value with the correct suffix. Instead it returns the full number in bytes - without the suffix.

I believe it has to do with this call in **yii\i18n\Formatter @ line 1137**:

``` php
            if ($value  sizeFormatBase) {
                break;
            }
```

Maybe throwing an `abs()` call on the `$value` variable to satisfy this check can solve the issue?
