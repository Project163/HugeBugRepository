Title

[gogo][runtime] Avoid unnecessary conversions from strings to booleans/integers

Description
This can be problematic when calling methods and loosing the string if it looks like a number, for example: 
  
 > delete-version 1.10
 
  

 During this call, the parameter is transformed to an integer and then back to a string, so the method is called with "1.1" instead of "1.10" which can be  really  problematic.
