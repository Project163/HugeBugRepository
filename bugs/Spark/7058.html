Title

Empty string values cause schema_of_json() to return a schema not usable by from_json()

Description
Here's a reproduction: 
   
  
 
 from  pyspark.sql.functions  import  from_json, schema_of_json
json =  '{ "a" : ""}' 

df = spark.createDataFrame([(json,)], schema=[ 'json' ])
df.show()

 # chokes  with  org.apache.spark.sql.catalyst.parser.ParseException
 json_schema = schema_of_json(json)
df.select(from_json( 'json' , json_schema))

 # works fine
 json_schema = spark.read.json(df.rdd. map ( lambda  x: x[0])).schema
df.select(from_json( 'json' , json_schema))

- Confirmed this issue is also present on  branch-3.0  as of commit    .
- There seems two issues. The first is in the JSON schema inference ( [URL] Seems it treats empty strings as nulls. We might need an option to treat this as StringType. 

 Another issue is that  null  type is not properly being supported in SQL parser (which is used to parse the DDL type string from  schema_of_json ). Hive supports  null  type as  void  keyword so we might need to support this as a proper string to parse as a  null  type.
