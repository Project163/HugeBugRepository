Title

Conditionally initialized `final` variables considered maybe uninitialized

Description
Running the following in `groovyConsole`: 
  
 
final  int  i
final  boolean  a =  true 
 if  (a) {
    i = 1
}  else  {
     throw   new  IllegalStateException( 'a is  false ' )
}
println  "i = $i" 
 
  

 would give me: 

  
 1 compilation error:
The variable [i] may be uninitialized
. At [9:15] at line: 9, column: 15
 
  

 It seems groovyc does not take throwing an exception as a non-reachable branch. 

 This code is almost a verbatim copy from a java code that is working. 

 This looks similar to   GROOVY-8472  , and a few others.
Discussion
- Added code tags. Plus here is a JavaShell snippet to confirm the Java behaviour: 
  
 
 def  js =  new  org.apache.groovy.util.JavaShell()
js.run( 'Main' , '''
public  class  Main {
  public static void main( String [] args) {
    final  int  i;
    final  boolean  a =  true ;
     if  (a) {
        i = 1;
    }  else  {
         throw   new  IllegalStateException( "a is  false " );
    }
     System .out.println( "i = "  + i);
  }
}
''')
- The same behavior is observed with the branches reversed or with returns instead of throws: 
  
 
 if  (a) {
     throw   new  IllegalStateException( 'a is  false ' )
}  else  {
    i = 1
}
 
  
 Looking at the codebase, it appears we are only looking for returns/throws for try/catch and switch.
