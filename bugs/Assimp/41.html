Title

Incorrectly named Assimp .dll in UpdateAssimpLibsDebugSymbolsAndDLLs.

Description
In the main CMakeLists.txt, at the root project, a variable named `ASSIMP_MSVC_VERSION` is used for the project UpdateAssimpLibsDebugSymbolsAndDLLs. This variable specifies the visual studio version e.g. **vc140**, **vc141**, **vc142** to use in the .dll file name.  To give an example, here is what building under a certain VC++ compiler would produce:

`Visual Studio 2015 => assimp-vc140-mtd.dll`
`Visual Studio 2017 => assimp-vc141-mtd.dll`
`Visual Studio 2019 => assimp-vc142-mtd.dll`

The following code in CMakeLists.txt shows that `ASSIMP_MSVC_VERSION` is never assigned in a value when  `MSVC_TOOLSET_VERSION` is defined. It seems that the variable `MSVC_PREFIX` was rather meant to be `ASSIMP_MSVC_VERSION`.
