Title

Please consider disabling fsnotify in certain architectures

Description
Hi,

As noted in bug fsnotify/fsnotify#130, fsnotify fails to work correctly (or at all) in arm64, ppc64 and ppc64el.

This was preventing prometheus to be accepted in Debian testing, so while this is solved upstream, I hacked together a [Link: patch] to disable fsnotify and rely only on refresh intervals in those architectures. You might want to consider applying something similar, so prom keeps working.
