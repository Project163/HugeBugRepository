Title

rocket_contrib::uuid::Uuid wrong error return type

Description
Hello everybody !

This morning I tried to switch from rocket `0.4.7` to the master `0.5.0-dev` and ended up on an issue related to `rocket_contrib::uuid::Uuid`.

## Bug Reports

bug happens on `cargo build` for this version :

- rustup version : `rustup 1.23.1 (3df2264a9 2020-11-30)`
- rustc version : tested on both `rustc 1.52.0-nightly (234781afe 2021-03-07)` and `rustc 1.50.0 (cb75ad5db 2021-02-10)`
- rocket version : master [Ref: #f4548950]

- As additional context, here's a sample from my `Cargo.toml` :
```
toml
[dependencies]
# ...
rocket = { git = "[URL] }
# ...
... [Log Snipped] ...
default-features = false
features = ["json", "uuid", "diesel_postgres_pool"]
```
- Well, in the meantime I ran a `rustup update` and set `rustup override set stable`.

After a `cargo clean` and a few changes to be compatible with `0.5.0-dev`,
I got it working mainly by sticking (at least for now) to bare [Link: `uuid::Uuid`].

Here's my updated `Cargo.toml` :
```
toml
[dependencies]
rocket = { git = "[URL] }
# ...
uuid = { version = "0.8", features = ["serde", "v4"] }
... [Log Snipped] ...
default-features = false
features = ["json", "diesel_postgres_pool"]
```

I made an attempt at switching to `rocket_contrib::uuid::Uuid` afterwards and it seems possible but in my case with quite a lot of refactoring.

Feel free to close this issue if nobody runs into it.
- Indeed, this will only work on the latest version of `uuid`, contrary to what the `cargo.toml` says.

Fix is incoming.
