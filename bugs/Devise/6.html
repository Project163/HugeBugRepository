Title

Omniauth path generation not respecting env["SCRIPT_NAME"]

Description
Given a Rails 3 app mounted at sub-uri /q in passenger (using RackBaseURI /q) with this devise_for:
      devise_for :users, :controllers => { :omniauth_callbacks => "users/omniauth_callbacks" }, :omniauth_providers => [:blah]

Devise returns /users/auth instead of /q/users/auth when user_omniauth_authorize_path(:blah) is called.
Discussion
- Consider SCRIPT_NAME on omniauth url helper. Closed by
- This breaks using user_omniauth_authorize_path(:blah) in a mailer because there is no request in a mailer.
