Title

Deploying static site to subfolder leads to 404s for most assets in SvelteKit v1.22.1

Description
### Describe the bug

Starting with SvelteKit 1.22.1, using `adapter-static` to deploy to a subfolder no longer works. It seems likely that the change from [URL] is responsible:


I noticed probably relevant changes in `build/_app/immutable/entry/app.*.js`:

- In 1.22.0, it loads additional JS chunks from a relative path, like `../chunks/...`
- In 1.22.1, it loads them from `_app/immutable/chunks/...`, which does not work.

[Link: @benmccann suggested] that `paths.relative` may fix it, but it doesn't seem like that to me.
