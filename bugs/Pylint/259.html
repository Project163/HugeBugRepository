Title

`not-an-iterable` error for perfectly valid asyncio.couroutine decorated code

Description
### Steps to reproduce

```
python
import asyncio

@asyncio.coroutine
def coroutine_function_return_none():
... [Log Snipped] ...
    yield from coroutine_function_pass()
    yield from coroutine_generator()
```
### Current behavior

```
async_testcase.py:27: [E1133(not-an-iterable), main] Non-iterable value coroutine_function_return_none() is used in an iterating context
async_testcase.py:28: [E1133(not-an-iterable), main] Non-iterable value coroutine_function_return_object() is used in an iterating context
```

A couple of notes:
- I can't explain why `pass` actually works and a plain `return` doesn't…
- Looking at `checkers.typecheck.IterableChecker` and `checkers.utils.is_iterable`, I see there's no support for `asyncio.coroutine`, just for `yield from`, is that correct ?
### Expected behavior

A global evaluation of 10.0/10. No less ;)
