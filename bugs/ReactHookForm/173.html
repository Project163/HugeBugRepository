Title

Hidden inputs reset to initial value on submit

Description
**Describe the bug**
When registering a hidden input via `ref={register}` and setting its value via `setValue`, the field is reset to its initial value `onSubmit`. However, when using ` } type="hidden" control={control} />`, the input's value persists.

Somewhat related thread: [URL]

**To Reproduce**
Steps to reproduce the behavior:

1. Go to demo page and see console logs for the current values
2. Click submit
3. See the 1st "brokenInput" value reset to the default

**Codesandbox link (Required)**
[URL]

**Expected behavior**
Registered hidden inputs should persist their value on submit

**Desktop (please complete the following information):**

- OS: macOS
- Browser: Chrome
- Version: `6.8.2`
Discussion
- looks like this is not a bug with hook form, react cache the default value for hidden input for some reason:

[URL]

so looks like you need to skip the defaultValue at hidden input.
- when there is a `defaultValue` for hidden input, the value persists even after updating.
