### Which area(s) of Next.js are affected? (leave empty if unsure)

App directory (appDir: true), Routing (next/router, next/navigation, next/link)

### Link to the code that reproduces this issue

[URL]

### To Reproduce

1. Create a new project 
2. enable the `app` directory
3. enable `basePath` in `next.config.js` (e.g. `basePath: "/foo",`)
4. create a 'client' page in the app directory (that uses `'use client'`)
5. use the `usePathname()` hook
6. display the value on the page

### Describe the Bug

- When rendered on the server, the value of pathname will be `/`. this seems alright.
- In the browser, the pathname is replaced by `/foo`.

This leads to a 'React Hydration Error'
