Title

Stubtest thinks a property alias isn't read-only in stubs

Description
**Bug Report**

 

I was using [URL] to track support for aliasing property. But even after [URL] (I just tested against mypy on master), stubtest gives the following error (example using pika):
```
error: pika.adapters.blocking_connection.BlockingConnection.exchange_exchange_bindings is read-only at runtime but not in the stub
Stub: in file E:\Users\Avasam\Documents\Git\typeshed\stubs\pika\pika\adapters\blocking_connection.pyi:88      
def (self: pika.adapters.blocking_connection.BlockingConnection) -> builtins.bool
Runtime:
 >
```

**To Reproduce**

```
python
# Runtime
class BlockingConnection:
    @property
    def exchange_exchange_bindings_supported(self):
... [Log Snipped] ...
    # error: exchange_exchange_bindings is read-only at runtime but not in the stub
    exchange_exchange_bindings = exchange_exchange_bindings_supported
```

**Expected Behavior**

 

There should be no stubtest error for valid property aliases.

**Actual Behavior**

(see error above)

**Your Environment**

 

- Mypy version used: `1.18.0+dev. `
- Mypy command-line flags: (copied from the stubtest run) `python.exe -m mypy.stubtest --mypy-config-file C:\Users\Avasam\AppData\Local\Temp\tmp5lugkyw4 --custom-typeshed-dir . pika --allowlist stubs\pika\@tests\stubtest_allowlist.txt`
- Mypy configuration options from `mypy.ini` (and other config files):
- Python version used: `Python 3.13.1`
