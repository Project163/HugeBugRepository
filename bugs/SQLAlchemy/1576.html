Title

Code hanging when exception raised during commit in async code

Description
### Discussed in [URL]

 

 Originally posted by **coby-astsec** July 10, 2025 
# Summary
Hi,
Opening a discussion as per the instructions when creating an issue.

When running multiple async INSERTS at the same time, if an `asyncio.CancelledError` is raised, some(?) commits in progress are not cancelled.

This happened when we had code in the form of:
```python
task1 = insert_many_to_table_a()
task2 = insert_many_to_table_b()
task3 = insert_many_to_table_c()
await asyncio.gather(task1, task2, task3)
```
If task3 would raise an exception while a commit in task1 or task2 is in progress (for any reason, but for us here it was a constraint issue), then the code hangs forever.

# Reproducible example:
The example reproduces 9/10 times for me.

Create a table:
```sql
CREATE TABLE delayed_commit (id uuid PRIMARY KEY, magic INT);
```

