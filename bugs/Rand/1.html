Title

Missing `impl Distribution > for StandardUniform where StandardUniform: Distribution ` in 0.9

Description
## Summary

[Link: `StandardUniform`] is missing the implementation for `Option ` that was previously present in 0.8 with [Link: `impl  Distribution > for Standard where Standard: Distribution `].

This means when defining:
```rust
impl Distribution  for StandardUniform {
    // ...
}
```
Then attempting:
```rust
let x: Option  = rng.random();
```
You will receive the error:
```
the trait bound `StandardUniform: rand::distr::Distribution >` is not satisfied
```

This seems like a big breaking change to miss, was this intentional?
Discussion
- Yes. This was part of the transition from `Standard` to `StandardUniform`. See #1573.
- I expect quite a few more people might encounter this as they update, it might be worth making this explanation more visible.
