Title

"Could not find handler for bind rule" error

Description
[URL] shows the following error:
`ERROR: no such package '@protobuf//src/google/protobuf': Could not find handler for bind rule //external:protobuf.`

The workspace file contain the correct definition:

```python

bind(
    name = "protobuf",
    actual = "@protobuf_archive//:protobuf",
)
```

- @damienmg , I don't have your saved output base, but the problem seems to be that when Bazel sees a reference to the `@protobuf` repository, it looks for a rule called `:protobuf` in the WORKSPACE file and find its handler.

Since the rule that is found is not a repository rule but a `bind` one, the handler is not found.

Easy repro:
```
mkdir t
cd t
echo 'bind(name="a", actual="@//:ar")' > WORKSPACE
echo 'filegroup(name="fg", srcs=["@a//:x"])' > BUILD
bazel build //:fg
```

Then enjoy the error message with the release or crash at HEAD.
