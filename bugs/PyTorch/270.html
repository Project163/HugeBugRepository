Title

PyTorch `torch.ao.nn.quantized.ConvTranspose3d` crashes with floating point exception when `out_channels=0`

Description
### 🐛 Describe the bug

I encountered a crash in PyTorch when using the quantized API `torch.ao.nn.quantized.ConvTranspose3d`. The code is as follows:

```
python
import torch
import torch.ao.nn.quantized as nnq

# Create a quantized ConvTranspose3d layer
... [Log Snipped] ...
output = conv_transpose(input_tensor)
print(output)
```

When running the above code, the Python process aborts with a floating point exception. 

```
floating point exception (core dumped)
```

Similar crashes can also be reproduced on `torch.ao.nn.quantized.ConvTranspose1d` and `ConvTranspose2d` when `out_channels=0`. This indicates that additional argument validation is required to ensure `out_channels` is greater than zero in quantized `ConvTranspose*` modules.

This issue is reproducible on PyTorch 2.9. Here is the [Link: gist].
