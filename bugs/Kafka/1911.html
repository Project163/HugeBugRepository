Title

Processors created after acceptor started which can cause in a brief refusal to accept connections

Description
The acceptor starts before the the processor threads are actually created which creates a very small window in which connections to the broker will fail. When the acceptor takes on a new connection an illegal arithmetic exception is thrown as shown below.
