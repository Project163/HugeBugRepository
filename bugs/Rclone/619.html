Title

webgui location unchanged when using --cache-dir flag

Description
#### What is the problem you are having with rclone?
rclone mount --cache-dir string  will change the vfs cache directory location and the vfsMeta directory location but .cache/rclone/webgui will still be created in the same default location. When I used the command earlier I thought it was extremely unexpected behavior as I had expected the command to create a .cache directory containing all of those items in the specified location, instead I ended up with the webgui in the default .cache location and the vfs & vfsMeta directories created as two top-level independent directories in the location I had specified.
