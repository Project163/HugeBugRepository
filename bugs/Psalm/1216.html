Title

Incorrect UninitializedProperty / PossiblyNullReference error due to buggy parent constructor detection

Description
In the following example, I have three classes which extend from each other (`C` extends `B` extends `A`): [URL] The middle class does not have a constructor but the other two do.

Psalm doesn't seem to realize that when `C`'s constructor calls `parent::__construct()` it results in `A`'s constructor being called.  As a result, Psalm thinks the property is never set, although it definitely is: [URL]
Discussion
- One workaround is to specify the constructor explicitly: [URL]
- It's would be very unusual to see the code like that. `parent::__construct()` is idiomatic in PHP, it's not something that's going to change.
