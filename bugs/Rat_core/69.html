Title

Rat report contains multiple output runs instead of only one

Description
Comparing projects that use RAT in v0.15 and v0.16 I realized that in v0.16 target/rat.txt contains multiple outputs. 

 In RAT 0.15 only one output was generated, while in 0.16 it seems as if multiple RAT runs are written in one file each after the other. 

 How2reproduce: 
 
	 Compare target/rat.txt in a project running v0.15 and apply v0.16 in the same project 
	 Executed maven goal: mvn apache-rat:check
