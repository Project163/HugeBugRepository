Discussion
- The root cause was a convoluted TCCL issue. In general, when you work with TCCL, you SHOULD reset it to its original value, like so ... 

  
 
         var  tccLoader =  Thread .currentThread().getContextClassLoader();
         try  {
             ClassLoader  cl = createClassLoader();
             Thread .currentThread().setContextClassLoader(cl);

             //  do  stuff
 
        }  finally  {
             Thread .currentThread().setContextClassLoader(tccLoader);
        }
