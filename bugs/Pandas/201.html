Title

np.diff fails when called on a Series

Description
```
In [13]: s = Series(np.arange(10))

In [14]: np.diff(s)
---------------------------------------------------------------------------
ValueError                                Traceback (most recent call last)
... [Log Snipped] ...

ValueError: Can only tuple-index with a MultiIndex
```
Discussion
- On Dec 3, 2012, at 1:31 PM, Dan Allan notifications@github.com wrote:

Hi Dan, you should be using s.diff() instead.
np.diff treats the input argument as index unaware so it does not do the right thing for a Series. 
If you want to duplicate np.diff results, you can do np.diff(s.values)
- I'm reopening and moving this to at minimum 0.11. The solution here is to make Series _not_ an ndarray, once and for all. The issue is the `numpy.diff` uses `asanyarray` instead of `asarray`, and Series has different array behavior than `diff`
