Title

TestTezTPCDS30TBPerfCliDriver leaks Postgres container causing intermittent failures elsewhere

Description
Running TestTezTPCDS30TBPerfCliDriver does not stop the underlying Postgres container causing flakiness  and intermittent failures in other tests using a dockerized Postgres database. 

  
 
mvn test -Dtest=TestTezTPCDS30TBPerfCliDriver -Dqfile=cbo_query1.q
 
  
 Even though the test finishes successfully the underlying container is not stopped (verified using  docker ps ). Any attempt to run another Postgres dockerized test after that (e.g., qt_database_postgres.q) results into failures with the following stacktrace.
