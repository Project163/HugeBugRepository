Title

Filenames containing dots lead to a "The system cannot find the file specified" sync error

Description
v1.9.0 Linux syncing to v1.9.0 Windows

Any files containing dots in the path or filename causes a "the system cannot find the file specified" sync error on the Windows client.

See attached:
[Image: Screenshot from 2020-09-26 16-13-11]
Discussion
- File or directory names on Windows cannot end with a trailing dot. Probably we should reject them with an "invalid filename" error at an earlier stage.

```
md \\?\C:\testfolder.
echo>\\?\C:\testfile.
```

or even

```
echo>\\?\C:\NUL
```

Although more of a hack than anything else, all of them are happily synced.
