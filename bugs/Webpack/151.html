Title

serve property in webpack.config.js is treated as invalid

Description
# Bug report

 
 
 
 

**What is the current behavior?**
A _webpack.config.js_ containing a `serve` property (to configure [URL] is treated as invalid.


**If the current behavior is a bug, please provide the steps to reproduce.**
Use a _webpack.config.js_ which contains the `serve` property and start webpack.

 
 
 
 
 
 

**What is the expected behavior?**
A _webpack.config.js_ containing a `serve` property should not be treated as invalid. The `devServer` property is also not treated as invalid.

 
 

**Other relevant information:**
webpack version:  4.8.3
Node.js version: v10.1.0
Operating System: Linux 4.16.8
Additional tools: webpack-serve 1.0.2
