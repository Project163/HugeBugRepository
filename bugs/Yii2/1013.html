Title

Transactions are not committed using the dblib driver

Description
### What steps will reproduce the problem?
Create database handle by using de dblib driver, using the following parameters:
```
[
    'class'               => 'yii\db\Connection',
    'dsn'                 => 'dblib:version=7.2;host=myHost;dbname=myDB',
    'username'            => 'myUsername',
    'password'            => 'myPassw0rd',
];
```

excute the following code:
```
$transaction = Yii::$app->db->beginTransaction();;
var_dump(Yii::$app->db->pdo->inTransaction());
$transaction->rollback();
```

### What is the expected result?
`true`

### What do you get instead?
`false`

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.40
| PHP version      | 7.4
| Operating system | CentOS

Fix [URL] broke transactions completely for database connections using the dblib driver.
There is a check for an active transaction now:[URL]
But since `inTransaction` returns false for dblib connections, no commit will be done, resulting in an automated rollback.

The reason for `inTransaction` to return false is that the transaction is not started with `beginTransaction` but with the SQL command 'START TRANSACTION` (see [URL]

I've tested this by commenting out the `beginTransaction` method in de mssql pdo component: 
[URL]
With this method commented out (thus using the native pdo beginTransaction), `inTransaction` correctly returns true now.
The comment at this method states "_It is necessary to override PDO's method as MSSQL PDO driver does not natively support transactions._" 
I wonder if this is still true, because the native pdo beginTransaction just seems to work fine.
Discussion
- Is the case only with dblib (regarding MSSQL) or are other drivers affected as well? Do you have maybe a solution for this?
- The sqlsrv driver doesn't seem to have this problem.
But I don't want to use that driver because that driver doesn't support multiple uses of bind parameters with the same name in a query.
Maybe I can create an altered PDO driver for dblib.
