Title

UnknownTopicOrPartitionException should be an instance of InvalidMetadataException

Description
In new producer, if a message send failed, we only refresh metadata when the exception is an instance of InvalidMetadataException. UnknownTopicOrPartitionException should be a sub class of it instead of just RetriableException. The scenario we saw is that when a topic get deleted from broker, UnkownTopicOrPartitionException will be thrown. Assuming auto topic creation is turned on, supposedly the producer will be able to produce with retries after the topic get recreated. But because UnknownTopicOrPartitionException is not an instance of InvalidMetadataException, producer will not refresh metadata and retries are exhausted.
