Title

CQL client timeout when inserting data after creating index

Description

create index idx_cn on myapp(cn);

Discussion
- For information secondary indexes are not supported on composite primary keys. We have a ticket for that (  CASSANDRA-3680  ) but this won't be before Cassandra 1.2. 

 That being said, there is a clear lack of validation here and we will fix that (in other words, the 'create index' should return an meaningful error message).
- Attaching patch to reject index creation on table with composite primary keys.
