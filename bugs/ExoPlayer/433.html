Title

Frame drops and stalled video while playing MPEG-TS/AVC on Sony Bravia 4K GB

Description
* checked with demo player based on v1 and v2 ( )
* video is mpeg-ts/AVC High@L4/mpeg-L2 48kHz (https://drive.google.com/file/d/0Bww3WxdHUiM1WmlZVGZYelB5QjQ/view?usp=drivesdk)
* checked without extensions (logcat: [Link: exoplayer_demo_log-noext.txt])
* checked with ffmpeg ([Link: exoplayer_demo_log-ext-ffmpeg.txt])
* video is stalled
* there're _droppedFrames_ in the log
```
02-17 16:24:18.641 24114 24114 D EventLogger: droppedFrames [11.58, 50]
02-17 16:24:20.979 24114 24114 D EventLogger: droppedFrames [13.91, 50]
02-17 16:24:23.262 24114 24114 D EventLogger: droppedFrames [16.20, 50]
02-17 16:24:25.595 24114 24114 D EventLogger: droppedFrames [18.53, 50]
02-17 16:24:27.825 24114 24114 D EventLogger: droppedFrames [20.76, 50]
```
* same video is played well using system player and MXPlayer (log from MXPlayer: [Link: report_2017-02-17_162940.zip])
* no issues in demo player on NVidia Shield

It could be device's performance, but same video using same decoder (OMX.MTK.VIDEO.DECODER.AVC) in 2 other apps is played well.
