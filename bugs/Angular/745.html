Angular Upgrade - `$destroy` event is not fired on angularjs `$element`

## Current behavior
 
When upgraded directive was hidden by `*ngIf` directive, `$element` doesn't receive `$destroy` event.

## Expected behavior
 
In case of angularjs, when condition for `ng-if` is changed from `true` to `false` event is triggered.

## Minimal reproduction of the problem with instructions
1. Add angularjs component with injected `$element`
2. Subscribe to `$destroy` event
3. Make ng6-version using `UpgradeComponent`
4. Put `*ngIf` condition which is initially `true`
5. Trigger some handler that will change it to `false` to hide upgraded component
 

## What is the motivation / use case for changing the behavior?
 
Some plugins, like angular-ui-bootstrap components, use these events to dispose component, so these components don't work properly when event is not fired. In particular, angular-ui-bootstrap dropdown has an option to append dropdown to body. In angularjs, if container was hidden, component is disposed properly. In hybrid mode node that is attached to body is not disposed because component doesn't receive `$destroy` event

Discussion
- Normally, the `$destroy` event is triggered by jqLite/jQuery, which is not used in Angular for removing the element.

I don't see a reason not to trigger the event from `ngUpgrade` ([here][1] and [there][2]).

In the meantime, you can augment `UpgradeComponent` to trigger the event (and then use your class instead of `UpgradeComponent` for you upgraded components):

```
ts
```
