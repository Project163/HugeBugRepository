Title

Bitwise OR and AND operators with left operand inverted (!) cause VerifyError

Description
100% reproducible test case with Groovy 1.0.1: 

 def y = !true | false 

 That's all you need. It happens with AND too: 

 def y = !true & false 

 But not with && or ||. The NOT operator is required on the first operand. 

  Please  add a unit test for this before fixing it.
