Title

Hive should use scratchDir instead of system temporary directory for storing plans

Description
Otherwise these plan files never get deleted.
Discussion
- Currently there are other places using File.createTempFile in the persistent data structures (HashMapWrapper and RowContainer). We have the File.deleteOnExit(true) set to ensure the temp file got deleted when the job is killed or normal exit. Is there any issue there as well? Should we also convert that to using ScratchDir?

 I guess HashMapWrapper runs in mapper or reducer. 
It should be OK because in mapper/reducer, Hadoop automatically sets java.io.tmpdir according to  [URL]
And java.io.tmpdir is used in File.getTempDir.
