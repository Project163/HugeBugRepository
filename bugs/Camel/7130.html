Title

Camel-bindy does not treat escaped double quotes in CSV data

Description
Refer to  [URL]

 
 If double-quotes are used to enclose fields, then a double-quote 
appearing inside a field must be escaped by preceding it with another double quote.  

 The input data like  
  
  "a,"  "b"  ",c,d" ,e,f 
  

  [Expected Result]  

  
 
{columnA= 'a, "b" ,c,d' , columnB= 'e' , columnC= 'f' , columnD= ' null ' , columnE= ' null ' , columnF= ' null ' }
