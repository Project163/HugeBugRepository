Title

Calcite. TPC-H query #19: too long execTime and high heap memory usage on client

Description
Works for s = 0.01 but do not complete in 5 minutes for s=0.1 and s=1.0 

 Use a lot of heap on client side (look similar to the query #16 case at   IGNITE-24753  ) 

 ***
