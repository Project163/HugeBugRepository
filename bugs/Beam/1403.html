- This is due to an Executable Stage receiving metrics from multiple fused transforms. The current "legacy" metrics model assumes that we have an operator with a unique metrics namespace for each transform. I would suggest to use Flink's metric groups to add a sub group for every transform. Alternatively, we could include the transform name in the metric name.
