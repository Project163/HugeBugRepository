App Router, Metadata (metadata, generateMetadata, next/head)

### To Reproduce

I'd like to have a canonical url for the base URL which does not have a trailing slash, but it's not possible to do it when using metadatabase.  

1. Clone the repository. (https://github.com/lucashfreitas/nextjs-canonical-url-trailing-slash)

2. Run `next dev`

3. Note that the head ` ` to the head.

### Describe the Bug

When using metadatabase and canonical URL is not possible to remove the trailing slash from the base URL. According to the documentation and example available here [URL] if we set the canonical URL to `/` , nextjs would render only the metadataBase, but it's actually adding a trailing slash to the end. 

- when canonical is `/`: nextjs adds the trailing slash
- when canonical is null or '': nextjs does not add a canonical link to the head.
- when canonical URL is the base URL e.g `[URL] nextjs renders the baseUrl followed by a trailing slash.
