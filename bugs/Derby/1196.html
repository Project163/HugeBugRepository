Title

Trying to reconnect with derby client after bringing server down throws SQL Exception 58009 rather than 08XXX exception

Description
This issue was discussed in   DERBY-401  , because the case where the server is brought down and an application tries to reconnect does not throw a SQLNonTransientException.  Discussion is still underway about whether 58XXX exceptions should be SQLNonTransientExceptions, but at least for this case changing the exception to 08006 per Knut's suggestion should correct the problem for this case.
