Title

Fix tail inside repeat

Description
tail() step inside repeat() is not properly resetting per iteration. 

 Consider the following queries on the modern graph on 3.7.x 

  
 
gremlin> g.withoutStrategies(RepeatUnrollStrategy).V(1).repeat(__.both().order().tail(2)).times(2)
==>v[4]
==>v[6]
 
  

  
 
gremlin> g.V(1).both().order().tail(2).both().order().tail(2)
==>v[5]
==>v[6]
 
  

 The unrolled version doesn't match the repeat() version because tail() is recalculated on each call to processNextStart(). The tail() is being calculated too frequently even though there are still output traversers remaining from the previous calculation.
