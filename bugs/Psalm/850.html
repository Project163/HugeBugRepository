Title

`array_map((a, b) => c), a, b)` fails to infer the type of `b` in the closure

Description
Typically, `array_map()` is used with two parameters, one is the closure mapping the values, and one is the foldable passed to that closure.

When `array_map(function ($a, $b) { return $c; }, $as, $bs)` is used, then the type of `$b` fails to be inferred as the type of `$bs` items: [URL]

When declaring the type of `$b` explicitly, the errors obviously go away: [URL]

The code is obviously over-simplified: the reason why this issue exists, is because `$b` is often a complex nested structure.
