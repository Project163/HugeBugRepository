Title

Adding dimensions does not recognize Spaces

Description
建两张相同的表，其中某一列末尾带空格，然后构建模型，将带空格的列添加到维度中， 

 保存模型时，报的错误信息：“KE-010010001(重复的维度名)：维度名称 “LO_ORDERKEY” 已存在。请重新命名。” 

 但接口展示的维度，其中的一个是带空格的，并没有重复，所以无法识别维度末尾带空格的情况 

   

 复现步骤： 

 1、建表： 

 表1：正常构建 

 create TABLE FOX.LINEORDER_kg1 ( 
 LO_ORDERKEY  BIGINT, 
 LO_LINENUMBER  BIGINT, 
 LO_PARTKEY  INT) 

 表2：维度LO_ORDERKEY末尾带空格（”LO_ORDERKEY “） 

 create TABLE FOX.LINEORDER_kg2( 
 `LO_ORDERKEY `  BIGINT, 
 LO_LINENUMBER  BIGINT, 
 LO_PARTKEY  INT) 

   

 2、构建模型：表1 join 表2，添加维度：表1的“LO_ORDERKEY”、表2的”LO_ORDERKEY “ 

 3、报错模型：报错误的信息
