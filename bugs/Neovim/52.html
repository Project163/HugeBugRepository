Title

Crash: assertion failed

Description
While doing some regular editing, Neovim crashed with the following output:

```
[200~ plines_win_nofold: Assertion `col <= 2147483647 && (int)col < 2147483647 - (width -1)' failed. execute 'keepjumps keeppatterns [201~
```

It looks like this is an overflow check that should only fail when dealing with extremely long lines; but at the time the crash occured, I was editing a file wrapped at 80 columns. I’m currently trying to reproduce the issue with little success.
Discussion
- any chance you saved a core dump from the crash?
- I found a reproduction:

```
printf "\t" | nvim -u NONE +'set ts=3000000000' -
```

consistently crashes with:

```
nvim: /home/grimy/.nvim/src/src/nvim/misc1.c:1299: plines_win_nofold: Assertion `col <= 2147483647 && (int)col < 2147483647 - (width -1)' failed.
```

On the other hand,

```
printf "\t" | nvim -u NONE +'set ts=2000000000' -
```

just hangs for ever with 100% CPU usage, which is even worse imo.

This still doesn’t explain the original problem, though; I was definitely not playing with ts or very long lines when the crash occured. In the meantime, I think limiting ts to something like 32 would be reasonnable.
