Title

comparison with NaN

Description
I recently stumbled upon code like this:
-----------------
var x = parseInt(str, 10);
if (x == NaN) {
   alert('invalid input');
}
-------------
The programmer had obviously mistaken isNaN check for a comparison with NaN. Any comparison with NaN (even NaN == NaN) will result in false.

Though this might not be a very common mistake I still think the compiler could issue a warning in this case.
You already have the "WARNING - condition always evaluates to false" message for example.

Secondly, the compiler could optimize here, not even in advanced mode the code is short-circuited:
------
NaN==parseInt("asdf",10)&&alert("error");
------

Regards
/ Fredrik
