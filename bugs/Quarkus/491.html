Title

Enforce dependencyConvergence in quarkus-bootstrap-core

Description
The dependency tree of `quarkus-bootstrap-core` contains several versions of `wagon-provider-api` which pops us in Camel Quarkus because we enforce dependencyConvergence:

```
[INFO] --- maven-enforcer-plugin:1.4.1:enforce (camel-quarkus-enforcer-rules) @ camel-quarkus-support-common-deployment ---
[WARNING] 
Dependency convergence error for org.apache.maven.wagon:wagon-provider-api:3.0.0 paths to dependency are:
+-org.apache.camel.quarkus:camel-quarkus-support-common-deployment:1.1.0-SNAPSHOT
  +-io.quarkus:quarkus-core-deployment:999-SNAPSHOT
... [Log Snipped] ...
        +-org.apache.maven.wagon:wagon-provider-api:3.3.4
]
```

The simplest fix that solves our problem is to replace

```
         
             org.apache.maven.resolver 
             maven-resolver-transport-wagon 
         
```

with

```
 
             org.apache.maven.resolver 
             maven-resolver-transport-wagon 
             
                  
... [Log Snipped] ...
             
         
```

in `independent-projects/bootstrap/core/pom.xml` see [URL] .

Should we not introduce `dependencyConvergence` enforcement in `quarkus-bootstrap` so that similar issues do not occur again? WDYT @aloubyansky ?
