Title

Exclude compaction queries from ranger policies

Description
Applying masking or filtering Ranger policies on the compaction users cause data loss, as the policies will be applied to the compaction queries also. 

 While this is a kind of misconfiguration, the result is so bad, that the users should be protected from it by automatically excluding compaction queries from ALL ranger policies.
