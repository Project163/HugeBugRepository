Title

Quick mode crash when class is deleted

Description
On first run, type check `a.py`:
```py
import b
def f() -> b.C: pass
```

`b.py`:

```py
import a
class C: pass
```

Updated contents of `b.py` on the second run (note `C` was deleted, but there still is a reference to it in `a`):

```py
import a
a.f().x
```

Now mypy crashes:

