Title

Modify Alter_numbuckets* test to reflect hadoop2 changes

Description
Hadoop2 now honors number of reducers config while running in local mode. This affects bucketing tests as the data gets properly bucketed in Hadoop2 (In hadoop1 all data ended up in same bucket while in local mode).
