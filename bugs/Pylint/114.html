Title

E1306 too-few-format-args false positive with __class__

Description
Originally reported by: **Chris Rebert (BitBucket: [Link: cvrebert], GitHub: @cvrebert?)**

---

```
#!python

# foobar.py
"""Dummy module docstring"""

print("{0.__class__.__name__}: {0}".format(42))
```
