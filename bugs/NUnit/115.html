Title

Remoting exceptions during test execution

Description
In the process of migrating from NUnit 2.6 to 3.2.1 I repeatedly run into errors with tests that fail to report the result during the execution, and the internal trace files of the test run fills up with remoting exceptions similar to this on:

After the first such exception no further similar exceptions are reported. It seems to occur whenever a test takes "long" time to report progress, which usually happens for us when there is some errors in the test. However finding the errors is challenging when the result is not reported. Any tests that has not completed before the first error fails to report status to TeamCity, so it looks as if the that is missing rather than not executed at all/executed with failure.
