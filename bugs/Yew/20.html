Title

./build.sh: line 43: wasm-bindgen: command not found

Description
**Problem**

We can't compile the `Yew` examples by `./build.sh minimal` as showed in instructions [Link: /examples].

**Steps To Reproduce**

1. `cargo install wasm-pack` ``
2. `git clone [URL]
3. `cd yew/examples`
4. `./build.sh minimal`

It returns the following error:

```
bash
$ ./build.sh minimal
[ Building: minimal using wasm-bindgen ]
    Updating crates.io index
   Compiling proc-macro2 v1.0.18
... [Log Snipped] ...
./build.sh: line 43: wasm-bindgen: command not found
[FAIL] Command: "wasm-bindgen --target web --no-typescript --out-dir $SRCDIR/static/ --out-name wasm $TARGET_DIR/$EXAMPLE.wasm" exited with exit code: 127
```

**Environment:**

 - Yew version: `master`
 - Rust version: `1.44.0`
 - OS: `Fedora32`
Discussion
- Looks like the build script needs the cli tool:
`cargo install wasm-bindgen-cli`
- It fixed the problem (PR sent [URL] Thank you very much! :+1:
