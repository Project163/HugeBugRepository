Title

Exporter bug: Vertex Colors + Blender 2.63

Description
Tested just today on several models in Blender 2.63 and Blender 2.62. The exporter for 2.63 does not work for any models that include vertex colors, while 2.62 does. The last bit of the error is:

...export_threejs.py, line 615, in extract_vertex_colors
face_colors = face_colors.color1, face_colors.color2, face_colors.color3, face_colors.color4
AttributeError: 'MeshLoopColor' object has no attribute 'color1'"

Easy to reproduce:

1) Make a new cube
2) Go into Vertex Paint mode (key is 'v' on my install)
3) Paint!
4) Use Blender 2.63 exporter with Colors checked
Discussion
- I can replicate this. Seems like another victim of Blender's change to n-gons (see #1866, #1940). I'll look into this.
- If you examine another exporter there is some 'tesselate' string in the vertex colors stuff.  I think I looked at the XCD exporter and searched for 'color1'.   Not at home so don't have the actual source in front of me.
- Should be fixed now.
- Tested on my end, works great. Thanks for the fix!

( may have found another possible issue with exporting meshes from Blender that have subsurf modifiers, but will test and create another issue if I find anything )
