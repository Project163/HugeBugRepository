Title

SolrInfoMBeanTest fails when the project root path contains a plus sign

Description
The SolrInfoMBeanTest fails when the project path contains a plus sign (such as /home/me/src/solr-1.3.0+ds1), or other characters that have a special meaning in URL encoding.
Discussion
- This patch removes the URL decoding done to class path elements in the SolrInfoMBeanTest. This decoding seems unneccessary, it's not documented in the ClassLoader javadocs that it would be needed. Applying the patch makes the test succeed.
- Bulk close for Solr 1.4
