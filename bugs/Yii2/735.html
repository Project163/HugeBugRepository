Title

ExistValidator with targetRelation param ignore filter param

Description
### What steps will reproduce the problem?
Add model validation rule:
```
php
[['template_id'], 'exist', 'targetClass' => Template::class, 'targetAttribute' => ['template_id' => 'id'], 'filter' => function (ActiveQuery $query) {
    $query->andWhere(['type' => Template::TYPE_DEDICATED]);
}],

... [Log Snipped] ...
    return $this->hasOne(Template::class, ['id' => 'template_id'])->inverseOf('dedicated');
}
```
works, but:
```php
[['template_id'], 'exist', 'targetRelation' => 'template', 'filter' => function (ActiveQuery $query) {
    $query->andWhere(['type' => Template::TYPE_DEDICATED]);
}],

// ...
// ...
```
not works.

### What is the expected result?

"filter" is respected.

### What do you get instead?

"filter is ignored.
