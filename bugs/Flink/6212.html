Title

The judgment of chainable ignores StreamExchangeMode when partitioner is ForwardForConsecutiveHashPartitioner

Description
After   FLINK-26167  , if the exchange mode is set as  ALL_EDGES_BLOCKING  through  table.exec.shuffle-mode , the shuffle mode of   ForwardForConsecutiveHashPartitioner  will be set as  BATCH  (becase it may be converted to hash shuffle). But it should not affect the chain creation, so we need chang the chain logic and let the judgment of chainable ignores StreamExchangeMode when partitioner is ForwardForConsecutiveHashPartitioner.
