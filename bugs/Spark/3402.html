Title

Fix a potential data race in TaskMemoryManager

Description
SPARK-13210   introduced an `acquiredButNotUsed` field, but it might not be correctly synchronized:

	 the read `memoryManager.releaseExecutionMemory(acquiredButNotUsed, taskAttemptId, tungstenMemoryMode)` (see  here ) might not be correctly synchronized, and might not see `acquiredButNotUsed`'s new written value.
