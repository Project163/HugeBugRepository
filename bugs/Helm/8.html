Title

Helm 3: issue with registries and nested templates

Description
To reproduce, first fetch a chart with Helm 2 containing chart depends (wordpress->mariadb):
```
$ helm repo add bitnami [URL]
"bitnami" has been added to your repositories
$ helm fetch bitnami/wordpress --untar
```

Save the chart with Helm 3, remove original dir
```
$ helm chart save wordpress/ bundle.bar/helm/hub/bitnami/wordpress:5.9.4-alpha1
Name: wordpress
Version: 5.9.4
Meta: sha256: 
Content: sha256: 
5.9.4-alpha1: saved
$ rm -rf wordpress/
```

Exporting is met with an error:
```
$ helm chart export bundle.bar/helm/hub/bitnami/wordpress:5.9.4-alpha1
Name: wordpress
Version: 5.9.4
Meta: sha256: 
Content: sha256: 
Error: open wordpress/templates/tests/test-mariadb-connection.yaml: no such file or directory
```
Discussion
- Note: this issue is actually due to nested directories under `templates/` and nothing to due with dependencies
- Upon removing the `wordpress/templates/tests/`, everything works as expected and mariadb chart .tgz is present on export
