Title

dropDownList without "strict" has new behavior in 2.0.46

Description
Correction for issue [URL] causes new issue for dropDownList()

We have some dropDownList in search forms with both "empty string value" and "zero value", like this
```
 
 
 - select - 
 House handed over 
 2022 Year 
...
 
 
```

**Strict** parameter is not set for dropDownList().

First render of form we get no one option with "selected" attribute.

In Yii 2.0.46 after form submit and page reload **without choosing any option** in this ` ` we get "zero value" option selected ` `


Before Yii 2.0.46 we get no one option selected, without strict => true
In Yii 2.0.46 we have to set strict => true to reproduce previous behavior. 

Is this a bug or a feature?
Now we need to fix a lot of fields in many forms to fix the problem.

| Yii version | 2.0.46
| PHP version | 7.4
| Operating system | Ubuntu
