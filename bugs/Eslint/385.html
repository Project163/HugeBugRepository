Title

`--init` generates incorrect indent "tabs" rule

Description
It seems that with ESLint 0.21.0, the tabs indent rule got broken.
With the default `eslint --init` (which generates an indent: tabs), the following:

```
function x() {
 var y = 3;
}
```

gives an:

```
2:4 error Expected indentation of 4 characters  (indent)
```
Discussion
- Figured out the problem, `eslint --init` generates

```
{
    "rules": {
        "indent": [ 2, "tabs" ]
    }
}
```

That should be `tab` instead of `tabs` it seems.
Changed the title accordingly. 

PS: It would have been handy if `eslint` would have warned about an incorrect indent setting.
- Thanks. We'll fix it. We have a pull request in progress to validate incorrect config settings.
