Title

overwriting None from Tuple[AnyStr]'s only item causes PartialType-related crash

Description
``` python
import os.path

x = None
if 0:
    _, x = os.path.split("blah")
```

results in:

```
Traceback (most recent call last):
  File "/usr/local/bin/mypy", line 6, in  
    main(__file__)
  File "/usr/local/lib/python3.5/site-packages/mypy/main.py", line 54, in main
    res = type_check_only(sources, bin_dir, options)
... [Log Snipped] ...

NOTE: you can use "mypy --pdb ..." to drop into the debugger when this happens.
```

We might want to fix this before releasing.
Discussion
- Here's a simpler repro which produces a similar error:

``` python
from typing import AnyStr, Tuple

def split() -> Tuple[int, AnyStr]: ...
x = None
_, x = split()
```
- What is it supposed to mean? That x becomes an optional AnyStr? Maybe it's
crashing trying to report the problem?
