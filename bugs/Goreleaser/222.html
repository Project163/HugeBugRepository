Title

Windows runner: Deb and RPM archives invalid after updating from 1.16.2 to 1.17+

Description
### What happened?

We are using goreleaser to build and package a binary in Github Actions. We use a `windows-latest` runner. After updating from goreleaser to 1.16.2 to 1.17+, the .deb and .rpm archives produced started becoming invalid as the files contain backslashes.
 When examining the .deb archive for example, the `control.tar.gz` subarchive includes files like:
 `.\\control
.\\md5sums
.\\conffiles`
Same for the .rpm archive when listing the content:
`\\usr\\bin\\globalping`
