Title

iPOJO Provides 'interface' attribute should be 'specifications'

Description
iPOJO Provides element use the 'interface' word. However, to be consistent with iPOJO terminology, it should be 'specifications' 
This attribute has the same semantic as 'interface'.
Discussion
- Fixed at revision 729971 
The 'interface attribute of the 'provides' element becomes 'specifications' The semantic doesn't change. 
When using 'interface' a warning message is logged or printed.
