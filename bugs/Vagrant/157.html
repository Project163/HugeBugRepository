Title

Vagrant up fails due to VBoxManage failing with [\"showvminfo\", \"\x00\\x00\\x00...]

Description
Windows 7, Vagrant 2.2.4, VBoxManage 6.0.4r128413, VirtualBox 6.0.4.28413.

[Link: vagrantup_error.log]

[Link: Vagrantfile.txt]

```
P:\GitHub\...\2019-team-07f>vagrant up
There was an error while executing `VBoxManage`, a CLI used by Vagrant
for controlling VirtualBox. The command and stderr is shown below.

Command: ["showvminfo", "\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x00\x0

Stderr:
```

Vagrantfile is attached, as well as an error log.

I've tried:
- Deleting all VMs
- Deleting ~/.vagrant.d/
- Deleting ~/.VirtualBox/
- Installing VirtualBox 5.2.2
- Reinstalling VirtualBox 6.0.4

EDIT: I just got this to fix. Posting this for the sake of documentation. I fixed it by deleting `P:\GitHub\...\2019-team-07f\.vagrant\`!

The `.vagrant/` folder was CORRUPTED. Consider adding something to catch this, as the error was totally cryptic!
