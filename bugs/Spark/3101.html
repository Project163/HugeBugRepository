Title

PowerIterationClustering test case failed if we deprecated KMeans.setRuns

Description
We plan to deprecated `runs` of KMeans, PowerIterationClustering will leverage KMeans to train model. 
I removed `setRuns` used in PowerIterationClustering, but one of the test cases failed.
Discussion
- This bug is very easy to reproduce. After I removed  this line , one of the test cases failed. 
I pasted the test cases here. It's very strange that the following two cases are based on the same dataset, but one success and the other failed. 
Another clue is that when use `setInitializationMode("degree")` to train the PIC model, both the following two cases can pass. But if we use `setInitializationMode("random")`, the second test case will failed.
