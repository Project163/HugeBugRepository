The file was opened for `O_RDWR|O_CREATE|O_EXCL` which means that the open should have created the file anew if it didn't exist.  However it didn't work, so I think an intermediate directory must be missing.

I wonder if the cache got cleaned and the intermediate directory got removed between the open (which I don't see in your log).

Can you check to see if the intermediate directories are missing?

Commenting this code out in `vfs/cache.go` will fix it if that is the problem.

```go
	// Now tidy up any empty directories
	err = fs.Rmdirs(c.f, "")
	if err != nil {
		fs.Errorf(c.f, "Failed to remove empty directories from cache: %v", err)
	}
```

Can you try that?  If that works then I'll think of a better fix!

PS I see that file was opened with O_EXCL which I think I probably need to take more care with, but I don't think it is the problem in this case.
