Title

Otel logging does not respond to it's config property.

Description
### Describe the bug

Related to [URL] and docs [URL]
Testing with quarkus main snapshot

According to docs, collector endpoint should be configured by property `quarkus.otel.exporter.otlp.logs.endpoint`. But extension does not react to this property. Instead it actually is configured by "quarkus.otel.exporter.otlp.**traces**.endpoint".

In my setup I changed the grafana-otel-lgtm service to use different port than default 4317. Even when I configure it to the `quarkus.otel.exporter.otlp.logs.endpoint=[URL] no logs arrive to the backend and app complains about not being able to connect to the port 4317:
```
Failed to export TraceRequestMarshalers. The request could not be executed. Full error message: Connection refused: localhost/ :4317
Failed to export LogsRequestMarshalers. The request could not be executed. Full error message: Connection refused: localhost/ :4317
```

Problems with both logs and traces export is fixed, when I configure quarkus.otel.exporter.otlp.**traces**.endpoint.

From my testing it seems like property `quarkus.otel.exporter.otlp.logs.endpoint` is ignored entirely. Even when I set it to complete bogus like `quarkus.otel.exporter.otlp.logs.endpoint=[URL] it works, as long as *traces* property is set correctly.
