Title

Beeline should not chop off "describe extended" results by default

Description
By default, beeline truncates long results based on the console width like: 
  
 +-----------------------------+----------------------------------------------------------------------------------------------------------------------+
|          col_name           |                                                                                                                      |
+-----------------------------+----------------------------------------------------------------------------------------------------------------------+
| pat_id                      | string                                                                                                               |
| score                       |  float                                                                                                                 |
| acutes                      |  float                                                                                                                 |
|                             |                                                                                                                      |
| Detailed Table Information  | Table(tableName:refills, dbName: default , owner:hdadmin, createTime:1393882396, lastAccessTime:0, retention:0, sd:Sto |
+-----------------------------+----------------------------------------------------------------------------------------------------------------------+
5 rows selected (0.4 seconds)
 
  
 This can be changed by !outputformat, but the default should behave better to give a better experience to the first-time beeline user.
Discussion
- In this example the length of the row is more than 1000 characters. These kind of outputs showing in table format wont be look good. When ever the row length is bigger than width present that in vertical format (decide this in run time).
