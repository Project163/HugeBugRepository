Title

BUG: filter with a multi-grouping including a datetimelike fails

Description
this was changed in #9921 (worked prior to 0.16.0)
cc @evanpw

so using a multiple grouper where one item is a datetimelike fails as the `name in self.indices` fails. Instead `.get_group()` can be used to fix

```
In [1]: df = DataFrame({'A' : np.arange(5), 'B' : ['foo','bar','foo','bar','bar'], 'C' : Timestamp('20130101') })

In [2]: df
Out[2]: 
   A    B          C
... [Log Snipped] ...
3  3  bar 2013-01-01
4  4  bar 2013-01-01
```
Discussion
- In the meantime, here's a workaround:

``` python
simple = pd.DataFrame({
        'A': pd.Series([pd.to_datetime('2015-01-01')]), 
        'B': pd.Series([1], dtype=np.float64),
        'C': pd.Series([3], dtype=np.float64)})
simple.set_index(['A', 'B'])[simple.groupby(['A', 'B']).apply(lambda x: True)].reset_index()
```

Note: This code drops index. If you need to retain the index, do reset_index before and set_index after to retain index.
