Title

Add a way to disable severity in DynamicEndpointSnitch

Description
I have seen in a few clusters now where severity can out weigh latency in DynamicEndpointSnitch causing issues (a node that is completely overloaded CPU wise and has super high latency will get selected for queries, even though nodes with much lower latency exist, but they have a higher severity score).  There should be a way to disable the use of severity.
Discussion
- [URL]

 That merges up cleanly all the way to trunk.  Adds a -D option to disable using severity in DynamicEndpointSnitch calculations. 

 For the clusters where we were seeing massive latency degredation when a single node was under load applying this patch and settings the -D to disable severity brought things back to normal.
