Title

HMR adds changes twice when using teleport

Description
### Version
3.0.6

### Reproduction link
[Link]







### Steps to reproduce
[URL]

1. Clone the repo, install dependencies and run `npm run dev`
2. Open the app in the browser and click on "Show menu" button. Menu will open.
3. Now go to `App.vue` and after ` 3 ` add one more item ` 4 `
4. Save the file and look at the browser - you will see that hmr added ` 4 `  twice!

### What is expected?
The expected result after adding a new item would be this:

````
 1 
 2 
 3 
 4 
````

### What is actually happening?
Instead HMR has added 4 twice!

````
 1 
 2 
 3 
 4 
 4 
````

---
I'm using Vite 2.0.3 (latest)
Discussion
- same issue in latest @vue/cli.
- The issue is a bit like [URL] the difference is that this issue brings duplicate mounting instead of unmounting. When performing HMR updates, we deliberately fall back to the non-optimized mode, like this [URL] 
So we should check it when the Teleport component performs updating
