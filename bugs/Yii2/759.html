Title

ContentNegotiator "Illegal offset type in isset or empty" error

Description
### What steps will reproduce the problem?
TestController.php:
```
php
//...
public function behaviors()
{
    return [
... [Log Snipped] ...
}
//...
```
Type in the browser:
http:://youhostname/test/index?_lang[test1]=foo&_lang[test2]=bar

### What is the expected result?
Skip wrong language param value without error.

### What do you get instead?
Got error: `"Illegal offset type in isset or empty" in test/vendor/yiisoft/yii2/filters/ContentNegotiator.php at line 219`

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      |  
| PHP version      | 7.0
| Operating system |Ubuntu
Discussion
- That's because `ContentNegotiator` doesn't expect that GET param `_lang` is array:
[URL]

Must be fixed with additional `is_array()` check.
- I fixed it myself because the fix isn't so trivial as I thought. In case of `language` we must skip bad params but in case of `format` must not and throw an exception instead.

Such different logic for formats and languages was initially realized in this component.
