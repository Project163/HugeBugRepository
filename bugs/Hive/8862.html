Title

Alter partition change column cannot use the direct sql

Description
Since   HIVE-28909  , we change the MColumnDescriptor's identity-type to application from datastore in the package.jdo. It makes the getDataStoreId(MColumnDescriptor.class) throw the MetaException, as this IdentityType is no longer the IdentityType.DATASTORE any more, then the direct sql for alter partition would fail and fall back to jdo path.
