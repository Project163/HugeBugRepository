Title

Invalid order of release lock and notification of MVCC manager

Description
We release locks before notifying MVCC manager that operation was replicated.
That could cause issue with sequential commands on the same key, when first operation modifies value and second tries to read and write it.
Second command could miss result of first operation.
Discussion

- It is not recent regression.
New test repeats appropriate scenario 100 times in rows and it fails on 70+ iteration, sometimes it even passes.
- @kmuthukk , no, Jepsen tests we currently have didn't detect this issue.
