Title

alter view fails when hive.metastore.disallow.incompatible.col.type.changes set to true

Description
A view is a virtual structure that derives the type information from the table(s) the view is based on.    If the view definition is altered, the corresponding column types should be updated.  The relevance of the change depending on the previous structure of the view is irrelevant.
