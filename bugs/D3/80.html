Title

d3.time.scale nice should support skipping.

Description
Breaking this out of #1434. It’s currently only possible to time.nice by an exact time interval, without any skipping. This means that time.nice is inconsistent with time.ticks if the tick interval skips.

The difficulty is that there’s currently no implementation of interval.floor or interval.ceil that skips, so it’d be a little bit of work to enable nicing using a skipping interval.
