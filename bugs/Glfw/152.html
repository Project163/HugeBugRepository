Title

Cursor becomes visible with System Notifications in disabled cursor mode

Description
Whenever there is a system notification, such as a "hey please update your OS" or a skype message notification in the top right, the grabbed mouse becomes visible and remains that way.

If the window is alt-tabbed, and then re-tabbed, the mouse becomes invisible again.

Even when the window is full-screened, and a system notification cannot be seen, this is still an issue.
