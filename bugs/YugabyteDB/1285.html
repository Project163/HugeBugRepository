Title

[DocDB] Clone after doing a rename of an index column to a time before the rename fails

Description
Jira Link: [Link: DB-13020]
### Description

Version: 2024.2.0.0-b12
Steps:
1) Create datatbase db1
2) Create table t1
3) Create index ON t1 (indexcol)
4) Load data
5) Create snapshot schedule and take time t1
6) ALTER table t1 RENAME COL indexcol to renamed_col
7) CLONE db1 to db2 at time t1

Observation-
1) Fails to clone to db2 with the following error message
Error message :
`
"abort_message": "Runtime error (yb/util/subprocess.cc:632): Subprocess '/home/yugabyte/yb-software/yugabyte- -b190-centos-x86_64/bin/../postgres/bin/ysqlsh' terminated with non-zero exit status 768: ysqlsh:ysql_dump_FrJfBi:108: ERROR:  column \"renamed_col\" does not exist
`
