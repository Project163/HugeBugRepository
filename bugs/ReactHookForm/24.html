Title

submitFocusError does not work when using yup Validation Schema.

Description
**Bug Description**
When using yup schema validation, the submitFocusError does not focus the first error.

**To Reproduce**
Steps to reproduce the behavior:
1. configure a yup schema
2. use schema in useForm
3. Try to submit
4. It does not focus error

[Link: Example without using validation schema]
[Link: Example using validation schema and it does not autofocus]

**Expected behavior**
It should auto focus first Error, similar to when not using a validation schema.
