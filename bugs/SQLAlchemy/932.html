Title

deprecate case_sensitive engine flag

Description
Years ago, the lookup of columns in a RowProxy was case insensitive.    As this eventually led to problems, it was changed to be case sensitive, but a new flag case_sensitive=False was added to create_engine() to assist with backwards compatibility.   There are no known cases of anyone using this flag and it's time to remove it.  The internal implementation is fairly complicated as well.
