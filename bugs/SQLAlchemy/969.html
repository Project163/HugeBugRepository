Title

util.symbol() interferes with @util.deprecated decorator

Description
**Describe the bug**
Adding an `@util.deprecated` decorator as shown at

[URL]

causes pytest to crash with 

```
text
INTERNALERROR> Traceback (most recent call last):
INTERNALERROR>   File "C:\Users\Gord\git\sqla-gerrit\venv\lib\site-packages\_pytest\main.py", line 189, in wrap_session
INTERNALERROR>     config.hook.pytest_sessionstart(session=session)
INTERNALERROR>   File "C:\Users\Gord\git\sqla-gerrit\venv\lib\site-packages\pluggy\hooks.py", line 286, in __call__
... [Log Snipped] ...
INTERNALERROR>   File " ", line 1, in  
INTERNALERROR> NameError: name 'symbol' is not defined
```

**Expected behavior**
No crash.

**Error**
Using pdb I found that the issue is related to `schema=RETAIN_SCHEMA` in the arguments list for the `tometadata` function, where RETAIN_SCHEMA is

``` python
RETAIN_SCHEMA = util.symbol("retain_schema")
```

When pdb kicks in we can see that

``` text
(Pdb) u
-> exec(code, env)
(Pdb) code
"def tometadata(self, metadata, schema=symbol('retain_schema'), referred_schema_fn=None, name=None):\n    return target(fn, self, metadata, schema=schema, referred_schema_fn=referred_schema_fn, name=name)\n"
(Pdb)
```

**Versions.**
 - OS: Windows 8.1
 - Python: 3.7.5 x64
 - SQLAlchemy: [URL]
 - Database: mssql
 - DBAPI: pyodbc
Discussion
- so usually I would say, just change the signature of tometadata() to have **kw instead of that symbol() directly present, so that the decorator doesn't see it.  it's calling down into to_metadata() in any case.

you can do that here.   but alternatively, here is an enhancement to the `@decorator` function that will pull out those function defaults and allow them to be evaluatable when we make the decorator, this works at least for the tometadata() function which is enough for the moment:

```
diff
diff --git a/lib/sqlalchemy/util/langhelpers.py b/lib/sqlalchemy/util/langhelpers.py
index 52debc517..57d3be83b 100644
--- a/lib/sqlalchemy/util/langhelpers.py
+++ b/lib/sqlalchemy/util/langhelpers.py
... [Log Snipped] ...
     exec(code, env)
     return env[fn_name]
```
- **Gord Thompson** has proposed a fix for this issue in the **master** branch:

**Rename Table.tometadata to to_metadata** [URL]
