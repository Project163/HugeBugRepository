Discussion
- This is due to some behavior changes during submitting spark applications on yarn with client or cluster deloy mode. In 2.0 we convert most of the arguments to use system properties, while in 1.6 for "--py-files" we still use command arguments for yarn cluster mode, and for  PythonRunner  it only checks system property  spark.submit.pyFiles , so that's why it works under 1.6. It is really a issue should be fixed, let me handle it.
