- thanks for reporting, should be pretty simple to fix. PR welcome.
- Maybe just remove 'ctx'? 
In error_wrapper.py 

  ```
def json(self, *, indent: Union[None, int, str] = 2) -> str:
        errors = self.errors()
        for error in errors:
            if 'ctx' in error:
                del error['ctx']
        return json.dumps(errors, indent=indent)
```
