Title

Alamofire 5: Invalidated sessions don't complete requests

Description
Due to Alamofire 5's async request creation, `Session` instances can be `deinit`'d without completing their requests, unlike AF4. It's important this behavior exists so users can catch this implicit behavior, as it's one of the biggest causes of GitHub issues.
