Title

Ternary operator inside a set comprehension raises a parse error

Description
```
$ cat test1.py
import typing
{ i if i > 2 else None for i in range(5) }
$ mypy test1.py
test1.py, line 2: Parse error before "if"
```

It works when the expression is parenthesized:

```
$ cat test2.py
import typing
{ (i if i > 2 else None) for i in range(5) }
$ mypy test2.py
$
```

List comprehensions and generators do not have this problem.

(Latest mypy from git)
