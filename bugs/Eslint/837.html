Title

Cannot un-ignore specific subdirectory in node_modules

Description
I am developing React Native application and I am keeping the code inside `node_modules/mylibrary`. The reason why I keep it there is to avoid relative paths between modules in my library and that's the recommended way to do that according to [Link: this]. I would use symlinks if it wasn't for [Link: this].

I would therefore like to lint code in `node_modules/mylibrary`. Because `node_modules` are by default ignored, I've tried adding the following line to `.eslintignore`, but it didn't help:

```
!node_modules/mylibrary/**/*.*
```

**What version of ESLint are you using?**
v2.2.0

**What configuration and parser (Espree, Babel-ESLint, etc.) are you using?**
My .eslintrc file looks like this:

```
{
  "extends": ["standard"],
  "parser": "babel-eslint"
}
```

**What did you do? Please include the actual source code causing the issue.**
I've created `node_modules/mylibrary/abc.js` with invalid content:

```
abc
```

Basically I am using atom editor and noticed that code is not linted. I confirmed it by calling three commands:

```
./node_modules/.bin/eslint --ignore-path .eslintignore ./node_modules/mylibrary
./node_modules/.bin/eslint ./node_modules/mylibrary
./node_modules/.bin/eslint --no-ignore ./node_modules/mylibrary
```

**What did you expect to happen?**
I would expect the output to be the same for all three commands

**What actually happened? Please include the actual, raw output from ESLint.**
First two commands output nothing (no errors). Third one output:

```
/Users/tomkur/git/myproject/node_modules/mylibrary/abc.js
  1:1  error  'abc' is not defined  no-undef

✖ 1 problem (1 error, 0 warnings)
```
