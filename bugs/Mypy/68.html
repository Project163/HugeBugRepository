Title

Calling super().__new__() in a metaclass gives an error

Description
I wrote this:

```
class MyType(type):
    def __new__(cls, name, bases, namespace):
        return super().__new__(cls, name, bases, namespace)
```

Here I get an error from mypy on the `super().__new__()` call:

```
meta.py: In member "__new__" of class "MyType":
meta.py, line 3: "__new__" undefined in superclass
```
