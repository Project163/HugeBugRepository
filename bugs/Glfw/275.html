Title

Description
error:  description:Win32: Failed to register window class

this in my case resolve the failure.
but it is really thread safe?

```
c++
    if (!GetClassInfoW(GetModuleHandleW(NULL), _GLFW_WNDCLASSNAME, &wc))
    {
        if (!RegisterClassW(&wc))
        {
... [Log Snipped] ...
        }
    }
```

or you can replace all
[Link: win32_window.c#L694] [Link: win32_window.c#L759] [Link: win32_window.c#L766] [Link: win32_window.c#L787] 

``` c++
GetModuleHandleW(NULL)
```

 with:

``` c++
EXTERN_C IMAGE_DOS_HEADER __ImageBase;
#define HINST_THISCOMPONENT ((HINSTANCE)&__ImageBase)
 ...
wc.hInstance = HINST_THISCOMPONENT; // replace > GetModuleHandleW(NULL)

```

this ensure to use the right module hInstances, so we can have same named class, without clash.

and it would also be preferable to give the opportunity to the user to name the windows class.

after loaded the first DLL and create the window,
not allow you to create other window from the other DLL call, because the class is already registered.
