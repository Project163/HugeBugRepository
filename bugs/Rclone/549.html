Title

rclone dedupe fails to remove duplicates (Drive)

Description
#### What is the problem you are having with rclone?
When running rclone dedupe against a remote the files are not actually deduplicated.

Running the same rclone dedupe command multiple times results in the same result (finding dupe files and reporting they are being removed).

I've tried on the raw remote (Drive) as well as the encrypted remote (Drive > Crypt). Same result.

#### What is your rclone version (output from `rclone version`)
```
rclone v1.52.0
- os/arch: linux/amd64
- go version: go1.14.3
```


#### Which OS you are using and how many bits (eg Windows 7, 64 bit)
Linux Debian 10.x


####  Which cloud storage system are you using? (eg Google Drive)
Google Drive


#### The command you were trying to run (eg `rclone copy /tmp remote:tmp`)
```
rclone dedupe -v --fast-list --checkers=24 --dedupe-mode skip Remote:
```


#### A log from the command with the `-vv` flag (eg output from `rclone -vv copy /tmp remote:tmp`)
 Lots of:
```
2020/06/08 19:26:07 NOTICE: Path/To/File: Found 2 duplicates - deleting identical copies
```

- Can you please run the command with -vv and share the log? As a side note, checkers 24 makes thing slower as Google only allows about 10 transactions per second so if you use defaults, it'd go smoother.
