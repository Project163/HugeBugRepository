Title

Calling glfwMakeContextCurrent(NULL) causes segfault

Description
According to the docs at [URL] you can call glfwMakeContextCurrent with "NULL to detach the current context". 
Yet this will always segfaults as glfwMakeContextCurrent() doesn't check for handle/window being NULL:

```
_GLFWwindow* window = (_GLFWwindow*) handle;

    _GLFW_REQUIRE_INIT();

    if (window->context.api == GLFW_NO_API)
... [Log Snipped] ...

    _glfwPlatformMakeContextCurrent(window);
```

Changing that to:

```
_GLFWwindow* window = (_GLFWwindow*) handle;

    _GLFW_REQUIRE_INIT();

    if (window && window->context.api == GLFW_NO_API)
... [Log Snipped] ...

    _glfwPlatformMakeContextCurrent(window);
```

fixes things for me.
