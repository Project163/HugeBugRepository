Title

static star ImportNode has invalid constructor?

Description
I came across something curious in the constructor for static star  ImportNode   s.  This constructor  public ImportNode(ClassNode type)  has the following doc comment: 

  
     /**
     * Represent a  static   import  of a  Class , i.e.  import   static   package .Classname.*
     *
     * @param type the referenced class
     */
 
  

 Yet, inside the constructor,  this.isStatic = false; .  This seems like a bug to me since the generated ImportNode is obviously supposed to be static.  Is there something I'm missing here?
Discussion
- Yes, that was a copy and paste glitch I suspect. I am not sure groovy-core was affected as static star import nodes were placed in a map anyway and used from there but it should be fixed now in any case.
