Title

[bug] `clearMocks` is undefined or null after upgrading from 1.5.0 to 1.5.1

Description
### Describe the bug

```
TypeError: Cannot convert undefined or null to object
```

This wasn't happening in 1.5.0, my tests have remained unchanged but have started failing because of this.

The example [Link: from the documentation] can reproduce this error.
