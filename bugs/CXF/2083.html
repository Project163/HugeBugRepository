Title

Apache CXF kit bin directory is not set with access right

Description
When I extracted Apache CXF 2.7.9-SNAPSHOT kit which I build from 2.7.x-fixes/ branch, I found the bin directory  is not set with access right, I had to use chmod 755 to reset the bin directory access right. 

 BTW, I'm using maven 3.0.5, the assemble maven plugin is 2.4 to build the kit.
