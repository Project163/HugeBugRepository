Title

`[...catchall]` routes do not work with turbopack

Description
### Link to the code that reproduces this issue

[URL]

### To Reproduce


1.  Start the dev server with turbopack : `npm run dev -- --turbo`
2. Open the home page and navigates to`/other` using the links on the header, you will see that only the content of the parallel route in `@parallel/page.tsx` is shown when navigating
3. While on `/other` reload the page, the content will disappear, not even default.tsx is shown.

### Current vs. Expected behavior

Turbopack doesn't consider `[...catchAll]` routes and instead renders an empty content, while it works fine on webpack.
