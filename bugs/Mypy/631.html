Title

Bogus "Function is missing a type annotation for one or more arguments" with attrs

Description
When checking this file with mypy (0.641 or git master) and `--disallow-incomplete-defs`:

```python
import attr

@attr.s
class A:
    a = attr.ib()
```

I get an unexpected:

```
at.py:3: error: Function is missing a type annotation for one or more arguments
```

(line 3 being the `@attr.s` decorator). If I'm interpreting [Link: what `--disallow-incomplete-defs` does] correctly, it should only warn if there's a partial type annotation (as opposed to none at all, which `--disallow-untyped-defs` would warn about).

Also, the error message is confusing - I don't define a function at all there. With `--show-error-context`, it says:

```
at.py: note: In member "__init__" of class "A":
```

FWIW, I (finally) started using mypy with a rather big project ([Link: qutebrowser]) and I'm quite happy with it so far - the approach of gradual typing and the awesome documentation make it very easy to get a benefit without having to annotate the entire codebase at once.
