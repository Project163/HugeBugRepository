Title

@Inject inside JAX-RS Application subclass not working with 2.x (ok with 1.6)

Description
### Describe the bug

After upgrading Quarkus from 1.6.1.Final to 2.5.Final the following `@Inject` fails inside `javax.ws.rs.core.Application` subclass:

```java
@ApplicationScoped
public class MyBean {

    public String foo() {
        retun "bar";
    }
}
```

```
java
@ApplicationPath("/")
public class MyApplication extends Application {

    @Inject
... [Log Snipped] ...
    }
}
```

### Expected behavior

`myBean` instance above should not be null

### Actual behavior

`myBean` instance is null

### How to Reproduce?

See bug description.
