Title

service-worker missing "badge" in "NOTIFICATION_OPTION_NAMES"

Description

## Current behavior
 
When displaying notification on mobile using the service-worker, the ```badge``` in the payload seems to be ignored and only the default notification bell icon is displayed.

## Expected behavior
 
Display the notification badge as sent by the the payload and not use any default icons.

## Minimal reproduction of the problem with instructions
 
Default service-worker setup and send any notification payload containing a ```badge``` url.
The badge will not be displayed. The default notification bell icon will be used instead.

When looking at the generated ```ngsw-worker.js``` I noticed the ```const NOTIFICATION_OPTION_NAMES```. It appears to be listing the option that are used by the service worker to display notifications.
When adding ```badge``` to the array, it will display as expected. The badge option is simply missing from the notification options.
