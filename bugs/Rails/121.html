- Hi, @scambra  @rafaelfranca ,

It's recommended to use `includes` with `references` at the same time after Rails 4.1, but I think there is a small issue when `Relation` is calling `Preloader` while `Relation` isn't eager loading and the association is a HABTM. `Preloader` calls `JoinDependency` finally and only loads one object through the join table because the join table hasn't a primary key.

I pushed a patch here, hope it helps.
