Title

[YSQL] Crash in yb_single_row_update_or_delete_path() when left operand of the clause is a function expr.

Description
Jira Link: [Link: DB-15899]
### Description

```
CREATE TABLE incremental_key(h INT, r INT, v1 INT, v2 INT, PRIMARY KEY(h, r ASC));
INSERT INTO incremental_key VALUES(1, 1, 1, 1);
UPDATE incremental_key SET v1 = 10 WHERE yb_hash_code(h) = yb_hash_code(1);
```
results in
```
server closed the connection unexpectedly
	This probably means the server terminated abnormally
	before or while processing the request.
The connection to the server was lost. Attempting reset: Succeeded.
```

Backtrace:
```
* thread #1, queue = 'com.apple.main-thread', stop reason = signal SIGABRT
  * frame #0:   libsystem_kernel.dylib`__pthread_kill + 8
    frame #1:   libsystem_pthread.dylib`pthread_kill + 288
    frame #2:   libsystem_c.dylib`abort + 180
    frame #3:   postgres`ExceptionalCondition(conditionName="!(ptr == ((void*)0) || (((const Node*)(ptr))->type) == type)", errorType="FailedAssertion", fileName="../../../../../../../src/postgres/src/include/nodes/nodes.h", lineNumber=609) at assert.c:54:2
... [Log Snipped] ...
    frame #25:   postgres`main + 36
    frame #26:   dyld`start + 2236
```

in yb_single_row_update_or_delete_path() :
```
var = castNode(Var, get_leftop(clause));
```

The issue seems to be happening because leftop is a FuncExpr, whereas it is type casted to Var:
```
(lldb) p *get_leftop(clause)
(Node)  (type = T_FuncExpr)
```
