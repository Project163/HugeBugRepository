Discussion
- I get the same error with the following variant:

```Python
from __future__ import annotations
import pydantic
import typing

class WithClassVar(pydantic.BaseModel):
    Instance : typing.ClassVar['WithClassVar']
```

However, if I remove the first line (importing annotations), the example seems to work.

The following class definition passes initial muster

```
Python
```
