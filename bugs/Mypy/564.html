Title

Mypy accepts incompatible methods in multiple inheritance

Description
Mypy accepts this code, even though the methods are incompatible:

```
class A:
    def f(self) -> int: pass
class B:
    def f(self, x): pass
class C(B, A): pass
```

The single inheritance case works right.
