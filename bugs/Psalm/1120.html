Title

PropertyTypeCoercion produces a false positive?

Description
[URL]

```
ERROR: PropertyTypeCoercion - 28:21 - $this->configSet expects 'array , EntityConfigInterface>',  parent type 'non-empty-array )|string, EntityConfigInterface>' provided
```
I cannot figure out where is this `string` in the string `non-empty-array )|string` coming from. It started breaking recently. Before psalm was not producing this error.

Here is another version of this code snippet without a template that produces a tad different result:
[URL]
```
ERROR: PropertyTypeCoercion - 25:21 - $this->configSet expects 'array , EntityConfigInterface>',  parent type 'non-empty-array ' provided
```
Comparing these two errors, I see that the problem could be associated with the presence of `array` vs `non-empty-array`.
Discussion
- The version without the template looks like a bug. The version with template doesn't seem to be sound - imagine the case when ConfigFactory is specialized as `ConfigFactory ` - then having a `case SomeEntity::class:` would be a paradox.
