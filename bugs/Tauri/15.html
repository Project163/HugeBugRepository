Title

rls is reporting non-existent errors in tauri-generated app

Description
**Describe the bug**
After generating an app by `yarn tauri init` and opening it in VSCode or another IDE configured to run checks with rls, ide complains about compilation errors:

[Image: 2020-05-31_17-18-15]

At the same time this app is successfully built in both dev and production mode using `yarn tauri dev` and `yarn tauri build`.

**To Reproduce**
Steps to reproduce the behavior:
1. `mkdir app-test && cd app-test && yarn init && yarn add tauri && yarn tauri init`
2. Open project with VSCode
3. Open main.rs
4. View->Toggle problems

**Expected behavior**
No problems detected by IDE when the app is successfully built by the tauri cli.
