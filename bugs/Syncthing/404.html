Title

lib/sync: Race in non-standard mutexes

Description

```
==================

  github.com/syncthing/syncthing/lib/sync.(*loggedRWMutex).Lock()

  testing.tRunner()
      C:/Go/src/testing/testing.go:610 +0xd0
```

Discussion
- In practice I suspect that thing works, but mixing atomic and locked writes is weird and something we should probably not do.
- This is only meaningful when debugging is enabled, which is not often.
