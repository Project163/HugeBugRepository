Title

[YSQL] yb_get_range_split_clause fails to generate SPLIT AT VALUES clause (Internal error: Unexpected type in the QL value)

Description
Jira Link: [Link: DB-5423]
### Description

`yb_get_range_split_clause` fails to generate SPLIT AT VALUES clause with error message
```
yugabyte=# CREATE TABLE tbl (k2 VARCHAR, k1 INT, PRIMARY KEY(k1 ASC, k2 ASC)) split at values ((1));
yugabyte=# SELECT * from yb_get_range_split_clause('tbl'::regclass);
ERROR:  Internal error: Unexpected type in the QL value
```

The implementation of function yb_get_range_split_clause wrongly makes one assumption that column ordering in the primary key constraint of a CREATE TABLE statement is the same as the column ordering of key columns in the CREATE TABLE statement.
