- Since I still have a lot of issues using Spring Data Jpa with Quarkus, I checked out the source code and started debugging. It seems that in the case where method is annotated with `@Query("SELECT ...")` the code goes wrong at io.quarkus.spring.data.deployment.generate.CustomQueryMethodsAdder line 228. The query is known - no need for method parsing. All it needs to do is create that method an execute the JPA query. Based on the result type (List, Object, ...) the corresponding query method (getResultList(), getSingleResult()) has to be called.

The method name does not matter in this case:
```
@Query("SELECT DISTINCT c FROM Car c WHERE c.horsepower > :minHP")
Set  cucumber(@Param("minHP") int minHP);
```
However, the issue seems to be the missing countQuery. Why is this required here?
