Title

Is it possible to enable client validation on renderPartial?

Description
Hi. This is not really an issue. I was just wondering if it is possible to do client validation  when I render a form with render partial. I was trying to display a form (via ajax call) when user selects some category from drop down list. Forms will be completely different depending on selected category. Thanks.
Discussion
- In Yii 1 there's an option to enable client validation on render partial (processOutput). 
public string renderPartial(string $view, array $data=NULL, boolean $return=false, boolean $processOutput=false).
But in Yii 2 , I couldnt find anything similar to this.
- In Yii 2, you need to insert method calls like `$this->beginPage()`, `$this->endPage()`, etc. (you may refer to your main layout view) if you want `View` to inject the registered scripts.

However, it is generally not a good practice to use ajax to send html code with js code, because the new js code may mess up the existing script dependencies. It's better you render the code in the initial rendering and toggle their visibility later.
