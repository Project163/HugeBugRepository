Title

join condition lost when using select_from

Description
### Describe the bug

It appears like the join condition is lost(?) when using select_from / subquery in combination with polymorphic entities. This worked in 1.2 but does not in 1.4.

- hi 

this appeared in the 1.4 series, with two different bugs that have different effects, the change from bug 1 to bug 2 occurred as a result of #6595 in 1.4.18, but prior to that you still get an incorrect query.

It's not clear that this issue can be fixed, so to solve your problem for now, just alias that inner entity like this:

```
py
e2 = aliased(EntityTwo, flat=True)
query = session.query(e2).filter(e2.name == "test1")

subquery = query.subquery()
```
