Title

Date Validator - Allows invalid dates

Description
Currently the date validator allows invalid dates and does not raise an error for certain invalid dates entered.

For example:
- if the date format for an attribute in the model rules is set to "Y-m-d"
- it allows me to enter a date like "3232-32-32" and save the record. 
- If my backend mysql database has a DATE data type, it naturally does not recognize this invalid input, and saves this data as "0000-00-00".

Can we incorporate a proper date validation check to throw an invalid date error. I know we have calendar and masked input widgets, but for a plain text input, we should have a model validation rule ideally validating the right date formats. For example, to work around the problem, I currently need to write a separate model validation rule like below:

```
php

    /**
     * @model rules
     */
... [Log Snipped] ...
        }
    }
```
