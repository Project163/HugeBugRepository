Discussion
- Could you elaborate on the bug here? There is a [Link: known issue with the `Placeholder` op] where it cannot distinguish between an unknown and a scalar shape, but it does serialize all other shapes correctly.

There is some work underway to figure out if that bug can be fixed without requiring the `PlaceholderV2` operation, but all other shapes should be fine regardless.
