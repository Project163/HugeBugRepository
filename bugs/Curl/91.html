- I followed this and it worked for me:
1. CURL_CONFIG= /bin/curl-config perl Makefile.PL --static-libs
2. Modified Makefile
   a. INC = -I. -I/usr/libcurlnghttp2/include -I/usr/include/nghttp2
   b. OBJECT = $(O_FILES) /usr/libcurlnghttp2/lib64/libcurl.a
   c. EXTRALIBS = /usr/lib64/libnghttp2.so.14.16.2 -lssl -lcrypto -lssl -lcrypto -lz
       LDLOADLIBS = /usr/lib64/libnghttp2.so.14.16.2 -lssl -lcrypto -lssl -lcrypto -lz
   d. PASTHRU_INC='-I. -I/usr/libcurlnghttp2/include -I/usr/include/nghttp2 $(PASTHRU_INC)'
3. make
4. perl -Mblib t/curlbug.t  >/dev/null

Basically, I saw that Makefile is not referring to correct paths.
