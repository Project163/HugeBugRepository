Title

Use private namespace for experimental APIs

Description
Proposal:  experimental APIs should have an "x " prefix ("svn_x_")-. experimental APIs should have a prefix that puts them in our private namespace, so "svn_client__" etc. 

 This is being discussed on dev@ in the thread "API review for 1.11; do we need to mark new APIs as experimental?" started on 2018-09-12.
Discussion
- Attachment   api-x-layout.patch      uses an  svn_x_  prefix in the APIs and  x-  prefix in the command-line option name " --x-viewspec " for the viewspec-output feature.
- Attachment   api-x-shelving.patch      uses an  svn_x_  prefix in the APIs for the shelving feature.
- Resolved, using double-underscore naming as for our existing private APIs. Backported to 1.11.x.
