Title

BaseActiveFixture internal models cache isn't cleared on fixture unload

Description
Private property BaseActiveFixture::$_models is set to something only in BaseActiveFixture::getModel() method. While writing a new model, it replaces the old one, but when only reading the model, it comes from $_models property, **which isn't cleared anywhere**.

So when we run several tests one after one, and these tests use the same models, we receive the models with values from previous test in each running test. This causes bugs, because these models are still in internal cache of BaseActiveFixture, but they don't already exist in database used for storing fixtures.

P.S. Using MongoDb fixtures.
