Title

After using about 45,000 popups, the popups will not be displayed.

Description
In `FontBook`,
If you use a font with about 15,000 characters, the popup (`on_hover_ui_at_pointer()`) is displayed properly.
However, if you use a font with about 45,000 characters, the popup is not displayed.

When the popup is not displayed, the popup of the entire program is not displayed.
If you close `FontBook`, the popup is displayed again.
