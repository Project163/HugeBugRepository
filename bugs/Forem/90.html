Title

Code of Conduct, Privacy Policy, and Terms of Use Nav Links Keep Coming Back After Being Deleted

Description
**Describe the bug**

A number of non-DEV Forems are hoping to remove the default navigation links for Code of Conduct, Privacy Policy, and Terms of Use. They are able to successfully delete these links, but the links eventually come back. We're thinking this is likely happening when a Creator updates their cloud instance to the latest version of Forem.

**To Reproduce**

Here's [Link: a video] that shows how to remove the nav links.

Here's a more recent screenshot of jess.forem.lol (our Forem for testing) that shows the nav links have returned:

[Image: Screen Shot 2022-01-05 at 9 44 23 AM]

**Expected behavior**

Deleted nav links should be removed permanently unless they are added back. Updating the Forem should not revert any removed nav links.
Discussion
- Long shot but maybe the routes get overwritten?

[URL]
- So, the problem here seems to be this:

* We have a Rake task called `navigation_links:create` which adds all the default navigation links.
* This tasks is called from the `forem:setup` task.
* The `forem:setup` task is called from the `app_initializer:setup` task.
* `app_initializer:setup` is called on every deploy (`release-tasks.sh`) and container build (`scripts/entrypoint.sh`)

That last step means that all navigation links from the default set will reappear since this task is completely unconditional. We either have to find a better way to only run this on initial Forem creation or make it conditional in some way (which might be brittle).
