Title

mypy plugin detects Mapped[str] instead of Mapped[MyEnum] for enum column if the enum declaration is in a separate file

Description
**Describe the bug**

mypy plugin detects `Mapped[str]` instead of `Mapped[MyEnum]` for enum column if the enum declaration is in a separate file


**Expected behavior**

Should detect the correct value: `Mapped[MyEnum]`

**To Reproduce**


* myenum.py:
```python
import enum

class MyEnum(enum.Enum):
    FOO = "foo"
    BAR = "bar"
```

* models.py:
```
python
from sqlalchemy import Column
from sqlalchemy import Enum
from sqlalchemy.ext import declarative
from sqlalchemy.orm import Mapped
... [Log Snipped] ...
    __tablename__ = "user"
    bar_or_foo: Mapped[myenum.MyEnum] = Column(Enum(myenum.MyEnum), nullable=False)
```


**Error**

`error: [SQLAlchemy Mypy plugin] Left hand assignment 'bar_or_foo: "MyEnum"' not compatible with ORM mapped expression of type "Mapped[str]"  [misc]`


**Versions.**
 - OS: Linux
 - Python: 3.9.5
 - SQLAlchemy: 1.4.18
 - Database: postgres
 - DBAPI:
