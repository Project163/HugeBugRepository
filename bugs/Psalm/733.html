Title

False-positive MismatchingDocblockParamType depending on union type order

Description
`callable(T):string|int` produces `MismatchingDocblockParamType`, `callable(T):int|string` does not:

[URL]
Discussion
- This is _partly_ by design - an `int` can never be a valid `callable`, but a `string` can. On the other hand this should be a bug:

```php
/**
 * @param string $mapper
 */
function map2(callable $mapper): void {}

map2("foo");
```
- @fantomas662 are you looking to define callable returning `string|int`? If so you will need to wrap the return type in braces, like this: `callable(T):(string|int)`
- @weirdan Yeah, that was it.
- And now Psalm’s error should help you figure that out
