Title

index title override deletes selectable_column

Description
I have a model whose name is an all-caps acronym. As such, I needed to have this as a bare minimum:

``` ruby
ActiveAdmin.register NAME do

  menu :label => 'NAME'

  index :title => 'NAME'

end
```

However, even though I don't pass a block to `index`, the `selectable_column` disappears. This is only a minor issue, but beautiful defaults should stay beautiful.
