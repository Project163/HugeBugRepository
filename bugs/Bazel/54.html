Title

pkg_deb splits on `-` character breaking control file

Description
How to re-produce:
1. Remove this line from the bazel debian build: [URL]
2. Rebuild debian pacakges: `bazel build --embed_label=0.1.2 --stamp //scripts/packages/...`
3. Try to install the debian package. You should get the following error:

```
dpkg: error processing archive bazel-debian.deb (--install):
 parsing file '/var/lib/dpkg/tmp.ci/control' near line 7 package 'bazel':
 `Depends' field, syntax error after reference to package `bash-'
Errors were encountered while processing:
 bazel-debian.deb
```

If we look at the control file it looks like:

```
Package: bazel
Version: 0.1.2
Section: contrib/devel
Priority: optional
Architecture: amd64
... [Log Snipped] ...
Homepage: [URL]
Built-Using: bazel (0.1.1)
```

As you can see the bash-completion dependency has been split between two lines which is invalid syntax. It just so happens that with both of the openjdk-8-jdk and openjdk-8-source dependencies in the depends list it is long enough to split on the next word which does not have a `-` in it. Running the build off master the control file looks like:

```
Package: bazel
Version: 0.1.2
Section: contrib/devel
Priority: optional
Architecture: amd64
... [Log Snipped] ...
Homepage: [URL]
Built-Using: bazel (0.1.1)
```
