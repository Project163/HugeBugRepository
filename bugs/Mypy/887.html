Title

Regression - Module "_typeshed" has no attribute "SupportsLessThan"

Description
**Bug Report**

The example of using `SupportsLessThan` in [Link: the documentation] does not work in mypy 0.941 or 0.940.

**To Reproduce**

[URL]

Works correctly on 0.931, but not 0.941 or 0.940.
Discussion
- We got rid of `SupportsLessThan` from `_typeshed` in [URL] because it wasn't doing a great job at describing the various types at runtime it was trying to describe. We replaced it with a new `SupportsRichComparison` type, which is a little more complicated, but does a much better job at describing the types at runtime.
