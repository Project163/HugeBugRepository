Title

Overwriting sys.excepthook

Description
How do I set my own excepthook? mypy complains about "Invalid assignment target":

```
$ cat hook.py
from types import TracebackType
import sys

... [Log Snipped] ...

sys.excepthook = excepthook
```

```
$ mypy hook.py
hook.py, line 8: Invalid assignment target
```

(Python 3.4, mypy from master)
Discussion
- mypy (currently?) doesn't support redefining a symbol in a module like that.

You could try this instead:

``` python
import sys

def excepthook(type_: type, value: BaseException, tb: TracebackType) -> None:
    sys.__excepthook__(type_, value, tb)

setattr(sys, 'excepthook', excepthook)
```
- Oh, okay. I went with `sys.excepthook = excepthook # type: ignore`, seems less invasive this way.
- The stub for `sys` (`stubs/3.2/sys.pyi`) should define `excepthook` as a variable with a callable type instead of a function (also, mypy should support assigning to functions, but that's a separate issue).
- Can't repro any more.
