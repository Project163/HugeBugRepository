Title

Segmentation fault with TorchScript while scripting a function with an argument Optional[List]

Description
## 🐛 Bug

This bug makes "Segmentation fault: 11" in a MacOS Mojave, Python 3.7 (anaconda) and Pytorch 1.5.1 or 1.6. 

## To Reproduce

Run this code have a segmentation fault
```
from typing import Optional, List
import torch
@torch.jit.script
def buggy_fun(x:torch.Tensor, classes:Optional[List]=None):
    
    # Filter by class
    if classes:
        x = x[(x[:, 5:6] == torch.tensor(classes, device=x.device)).any(1)]
```
This code works well if you change `classes:Optional[List]=None` to `classes:Optional[torch.Tensor]=None`.

## Expected behavior

It works or gives an error message but not to kill the python interpreter without any trace.
