Title

HttpPostRequestDecoder should handle "a&b=c" in application/x-www-form-urlencoded content

Description
Netty Version 4.0.0.Alpha1-SNAPSHOT ([Link: 07-Dec-2011 01:22])

Requests with content type "application/x-www-form-urlencoded" contain a query string as data. These query strings may contain elements without value, e.g. "a&b=c" which should be equal to "a=&b=c".

Netty's application/x-www-form-urlencoded parses "a&b=c" as one attribute with name "a&b" and value "c".

``` http
POST / HTTP/1.0
Content-Length: 5
Content-Type: application/x-www-form-urlencoded

a&b=c
```

Netty returns:
a&b -> c

Netty should return it as two attributes:
a -> (empty string)
b -> c
