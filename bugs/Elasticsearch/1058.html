Title

Nested aggregation in terms aggregation

Description
I have issue with aggregation result then i use nested aggregation in terms aggregation.
Tested with ES 1.4.[1,2].

Create mapping and add documents

```
DELETE test/product/_mapping
POST test/product/_mapping
{
  "properties": {
    "categories": {
... [Log Snipped] ...
  ]
}
```

Aggregation query

```
GET test/product/_search
{
  "size": 0,
  "aggs": {
    "category": {
... [Log Snipped] ...
  }
}
```

Result 

```
...
"aggregations": {
      "category": {
         "doc_count_error_upper_bound": 0,
         "sum_other_doc_count": 0,
... [Log Snipped] ...
   }
...
```

I have no sub aggregation result in aggregation "category" keys 2,3,4
Discussion
- Try to use a single shard (in settings), sometimes there is trouble with several shards and a few documents.
- I temporarily  move category aggregation to nested aggregation, and have correct result, but i need a hierarchy of results with categories at the top.

```
json
GET test/product/_search
{
  "size": 0,
  "aggs": {
... [Log Snipped] ...
  }
}
```

result

```
json
...
   "aggregations": {
      "property": {
         "doc_count": 6,
... [Log Snipped] ...
   }
...
```
