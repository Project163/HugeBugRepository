Discussion
- After very brief debugging I found that there is a difference in  Analyzer.classpath . While within the maven-bundle-plugin it starts with the entry  Jar:.  this entry is not there for the bnd-maven-plugin. All other entries are identical (taken from the project's dependencies). 
Also I am wondering why the sources are set up as relative file names in  [URL] Which base directory do those filenames refer to?
