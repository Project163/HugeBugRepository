Title

Minor UI issue with spacing in advanced settings, e.g. unackednotificationids

Description
### What happened?

## Minor UI issue

Under Advanced settings → Options, there is a setting called [Link: Unacked Notification IDs]. In the UI it has some extra spaces between the `I` and `D` characters which seems odd. I can't find this string in the codebase anywhere, maybe it comes from an external translation file or something.

Unsure if this is new in 2.x or was always like that...

## Screenshot

[Image: Image]

### Syncthing version

v2.0.0-rc.16

### Platform & operating system

macOS 15.5

### Browser version

Chrome 137.0.7151.41
Discussion
- This isn't new in 2.0, and there are some other options that trigger it like "Max Concurrent Incoming Request Ki B".

The advanced config menu is autogenerated, and that is why the weird space is there. And the generator sees the "I" and "Ds" as separate words (likely because of the casing).
- For the record, if you click the `?` icon, you will be forwarded to the Docs where the setting is written correctly with a proper explanation 😅.
- Where is the code that autogenerates the labels? Maybe it can be made a bit smarter? (Yes this is a very minor issue...)
- I worked on an updated `uncamel()` function in [Link: uncamelFilter.js]. I compiled all the config variables I could find in `syncthing/lib/config/*configuration.go` and tested this new function against them, all seems to pass.

I think it looks a bit nicer now. I submitted PR #10131 for this, hope that's OK.
