Title

@template-extends should warn about unknown types used as parent type parameters

Description
[URL]
```
php
 m());
```

**Expected**: unknown type Z
**Actual**: no issues
Discussion
- Basically, type parameter list in `@template-extends` should consist of either known types or type parameters of the generic where `@template-extends` is seen, so that:
```
php
/**
 * This is good
 * @template TT
 * @template-extends SomeParent 
... [Log Snipped] ...
 * @template-extends SomeParent 
 **/
```
- Also, it should not be possible to omit type parameters of the extended class:
```
php
  /** 
   * @template T
   * @template V
   * @template U
... [Log Snipped] ...
   */
  class CC extends A {}
```
This should complain about A expecting three type parameters, but only getting one in `@extends A `.
