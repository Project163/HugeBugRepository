Title

Multiple @var statements in a docblock

Description
For example, [Link: this method] that I'm refactoring:

```
php
    /**
     * Use this to change the configuration settings.
     * Only use this if you know what you are doing.
     *
... [Log Snipped] ...
        return parent::reconfigure($options);
    }
```

...generates this:

```
ERROR: MixedAssignment - src/Reusable.php:61:38 - Cannot assign $val to a mixed type
        foreach ($options as $opt => $val) {
```

Even though the type of $val is declared above the for loop. If I move the declaration for `$opt` (i.e. the diff below) into a separate docblock, it works.

```diff
-         /**
-          * @var string $opt
-          * @var \DateInterval $val
-          */
+         /** @var string $opt */
+         /** @var \DateInterval $val */
        foreach ($options as $opt => $val) {
```

This is a little unexpected.

EDIT: In case it wasn't obvious, this is only visible in `totallyTyped="true"` mode.
Discussion
- Thanks, I'll fix to support multiple `@var` declarations
