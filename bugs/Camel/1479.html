Attachment Names not Encoded Correctly

Description
If attachment file names contain unicode characters, they do not appear correctly encoded in the message.
Discussion

Expected :image/jpeg; name=logo2ë.jpeg 
Actual   :image/jpeg; name="logo2ë.jpeg"
