Title

Require extension's dependencies during extension loading

Description
Reported by @kingthorin.

Steps to reproduce the issue:
1. Run ZAP with the following command line arguments: `-cmd -config extensions.extension.name=ExtensionAlert -config extensions.extension.enabled=false`
2. Note that in the log file there's an exception:
```
[main ] ERROR ExtensionLoader - Parameter extensionAlert must not be null.
java.lang.IllegalArgumentException: Parameter extensionAlert must not be null.
	at org.zaproxy.zap.extension.pscan.PassiveScanThread. (Unknown Source)
	at org.zaproxy.zap.extension.pscan.ExtensionPassiveScan.getPassiveScanThread(Unknown Source)
	at org.zaproxy.zap.extension.pscan.ExtensionPassiveScan.hook(Unknown Source)
... [Log Snipped] ...
	at org.zaproxy.zap.CommandLineBootstrap.start(Unknown Source)
	at org.zaproxy.zap.ZAP.main(Unknown Source)
```
The passive scan extension should not be initialised since it depends on alert extension (which is not enabled).

Remarks:
The extensions' dependencies are only checked/enforced when the enabled state is changed through the GUI.

ZAP version:
Version 2.6.0 (older version are also affected).
