Discussion
- According to the source code `FractionalMaxPool3d.cpp`, it will create a large pool size, causing the value of `poolSizeW` to be much bigger than that of `inputW`.
[URL]

In fact, there is a check to avoid entering the loop, but your `kernel_size` is too large in this case, resulting in an integer overflow and skipping the check.
[URL]

I would like to add more checks for debugging purposes.
