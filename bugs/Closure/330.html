Title

Foo.prototype.eval() is required to return {?Object}

Description
Quite serious issue from my PoV...

/**
 * @constructor
 */
var Foo = function() {}

Foo.prototype = {
  eval: function(a, b)
  {
    var foo = null;
  }
}

Compiling this code will result in:

Foo.js:10: WARNING - Missing return statement. Function expected to return (Object|null).
  eval: function(a, b)
        ^
