Title

Illuminate/database undefined `rescue` function when using SQLite

Description
### Laravel Version

10.37.1

### PHP Version

8.3.0

### Database Driver & Version

SQLite

### Description

When using Illuminate/database as a standalone component, following [Link: the README instructions] and SQLite, the following error is thrown when using `hasTable`:  `Call to undefined function Illuminate\Database\Schema\rescue()`. 

This was not an issue with prior Laravel version (namely Laravel 8). There's either a missing dependency, missing installation step, or the hard requirement on [Link: `rescue`] makes it impossible to use it as a standalone component.

### Steps To Reproduce

1. `composer require "illuminate/database"`
2. Create `index.php`
```
php
 hasTable('users');
```
3. `php index.php`
