Title

Sourcemap generation with ant

Description
What steps will reproduce the problem? 
1. run ant task with following configuration:
  <jscomp compilationLevel="simple" output="./combined.js">
    <sources dir="./">
      <file name="test1.js"/>
      <file name="test2.js"/>
    </sources>
  </jscomp>

  whereas jscomp is the ant task-definition that calls the CompileTask.

 What is the expected output? What do you see instead? 
combined.js that includes minified and combined contents of test1.js and test2.js. There is no way to tell the ant task to generate source-map.

The patch I made makes this possible. Here is a sample configuration from an ant xml-file:
  <jscomp compilationLevel="simple" output="./combined.js" sourceMapOutputFile="./combined.js.map" sourceMapFormat="V3">
    <sources dir="./">
      <file name="test1.js"/>
      <file name="test2.js"/>
    </sources>
  </jscomp>

The patched CompileTask saves the sourcemap to the specified file and also generates a comment in combined.js that points to the sourcemap file (combined.js.map in this case).
