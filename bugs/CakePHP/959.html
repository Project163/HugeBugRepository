Title

Notice error in Database\FieldTypeConverter.php

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.6.9
* Platform and Target: PHP 7.1.2 x64 / MySQL 5.6 x64

Hello,

I came accros the same error message mentioned in issue [Link: 8648] but it looks like another case.

### What you did
When `quoteIdentifier` is On and your statement contains an aliased field, the passed `TypeMap` contains both fields name protected and unprotected by quotes. If one of those field is mapped to any type recognized by `$batchingMap` (and if there's less than 3 fields for this type), when `FieldTypeConverter` is invoked and iterates over `$this->_typeMap`, extra-quote protected field undefined in `$row` throws a Notice.

IMO, testing the field existence may not be enough. I think the TypeMap should be clean upfront.

#### app.php
```
php
$datasources = [
...
  'Datasources' => [
    'mydb' => [
... [Log Snipped] ...
...
];
```

#### Controller
```php
$tbl = TableRegistry::getTableLocator()->get('Tables');
$results = $tbl->find()->select([
	'floatField' => $tbl->find()->func()->sum('intField'), // Float type is defined in batchingMap
	//'duplicatedFloatField' => $tbl->find()->func()->sum('intField'), // Uncomment to avoid notice thrown by FieldTypeConverter.
	'stringField' => $tbl->find()->func()->substr(['strField' => 'identifier', '-4' => 'literal']), // String type is ignored as not defined in $batchingMap
])
->toArray();
```

### What happened
An Notice message is thrown 
```
Notice (8): Undefined index: `field` [CORE\src\Database\FieldTypeConverter.php, line 135]
```

### What you expected to happen
No Notice message...
