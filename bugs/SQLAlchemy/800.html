Title

synonym + single inheritance + mixins

Description
**Migrated issue, originally created by Michael Bayer ([Link: @zzzeek])**

this shouldn't seem to need `@cascading` though it at least works when we do that, but synonyms are inheritable.  if the superclass has the synonym it should be getting mapped or at least warning there's a problem:

```
from sqlalchemy import *
from sqlalchemy.orm import *
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.ext.declarative import declared_attr

... [Log Snipped] ...
# no, there's an unmapped C.data_syn property sitting there blocking it
print(s.query(C.data_syn).filter(C.data_syn == 'foo'))
```

this is a regression due to #4326 in  , that code is causing this to fail.
- **Michael Bayer ([Link: @zzzeek]) wrote:**

Check more specifically for hybrid attr and not mapped property

Fixed regression caused by :ticket:`4326` in version 1.2.12 where using
:class:`.declared_attr` with a mixin in conjunction with
:func:`.orm.synonym` would fail to map the synonym properly to an inherited
subclass.
