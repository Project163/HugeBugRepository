Title

Crash ``'Call' object has no attribute 'value'`` when `typing.cast` is used on dataclass field

Description
Version:
```
❯ pylint --version
pylint 2.10.2
astroid 2.7.3
Python 3.9.4 (default, May 27 2021, 06:13:04)
[Clang 7.1.0 (tags/RELEASE_710/final)]
```
Code:
```python
from dataclasses import dataclass, field
from typing import cast


@dataclass
class Example:
```
