Title

Add v:inf and v:nan values for use in string() output

Description
There is a known (at least, I remember it reported by me and noticed by Bram) bug in string(): if it represents a floating-point value which is either infinite or not a number then it returns `[-]inf` or `[-]nan` (on my system the latter is always `-nan` for some reason), but this output cannot be `eval()`ed back. If there were `v:inf` and `v:nan` variables then it would be possible to represent those values as `[-]v:inf` and `v:nan` respectively and `eval()` the result back. Necessary values are available as `math.h` macros `INFINITE` and `NAN`, latter is optional (it _must_ be present if floating-point implementation supports NaN values, and _must not_ if it does not). Both macros are supposed to have `float` types though, I hope there will be no problems from casting these rather special values to double (which is what (Neo)Vim use for floating-point values).
