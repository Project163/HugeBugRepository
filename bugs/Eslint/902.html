Title

max-statements-per-line conflicting with no-unexpected-multiline

Description
With eslint v2.9.0 and this rules

``` json
    "max-statements-per-line": [2, {
        "max": 1
      }],
    "no-unexpected-multiline": 2,
```

`max-statements-per-line` warn about code like this

``` javascript
const name = 'ESLint'

;(function foo() {
})()
```

with this message

```
This line has too many statements. Maximum allowed is 1  max-statements-per-line
```

I think `max-statements-per-line` should this kind of use of the semicolon.
