Title

[YSQL] Batch nested loops closing connection when querying metadata tables due to invalid cumulative relations when getting batched clauses

Description
Jira Link: [Link: DB-5419]
### Description

When using batched nested loops, queries to information_schema cause the connection to close due to the following error seen on the postgres logs:

```
TRAP: FailedAssertion("!(!bms_overlap(cur_relgroup, cumulative_rels))", File: "../../../../../../../src/postgres/src/backend/optimizer/util/restrictinfo.c", Line: 519)
```
This error occured for the latest debug build for  , and was reproduced by @tanujnay112. This error is identical to [URL] but is caused by a separate issue. Hence tracking this as a separate defect.

Reproduction:

```
set yb_bnl_batch_size = 2;

	  FROM (
```
