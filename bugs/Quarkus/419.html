Title

:remote-dev mode stopped working with 1.1.0.Final

Description
**Describe the bug**
Since 1.1.0.Final, :remote-dev seems to have stopped working (unless I'm missing some additional steps that have to be taken with 1.1.0.Final). Connection from the local to the remote side times out with: 
```
Exception in thread "Websocket ping timer" java.lang.NullPointerException
	at io.quarkus.remotedev.AgentRunner$2.run(AgentRunner.java:62)
	at java.util.TimerThread.mainLoop(Timer.java:555)
	at java.util.TimerThread.run(Timer.java:505)
```
Command on the "local" side:
```
./mvnw  quarkus:remote-dev -Dquarkus.live-reload.url=[URL] -Dquarkus.live-reload.password=somepassword
```
Command on the "remote" side:
```
./mvnw compile quarkus:dev -Dquarkus.live-reload.password=somepassword 
```
(I have some more -D options set, but I left those out for the sake of conciseness.)

- Thanks for reporting, I'll check it out (although we do have integration tests for it)

1) I was able to reproduce your problem
2) The problem goes away if you add something like 

```
quarkus.live-reload.password=somepassword
quarkus.live-reload.url=[URL]
``` 

to `application.properties`
