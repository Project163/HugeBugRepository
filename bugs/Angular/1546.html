Discussion
- It's weird, I didn't have that issue on my @-syntax demo. [URL]

It turns out this issue only happens when the `@if` block isn't wrapped, for example in a div. 

This template throws:
```
@if (condition$ | async) {
  Hello
}
```

This one doesn't: 


```
 
    @if (condition$ | async) {
      Hello
    }
 
```
- This is a confirmed bug in a compiler. For the described situation the generated code is (example):

```
javascript
function CondComponent_Template(rf, ctx) {
    if (rf & 1) {
        jit___pipe_4(0, 'async');
        jit___template_5(1, CondComponent_Conditional_1_Template, 1, 0);
... [Log Snipped] ...
    }
}
```

Notice that the `pipe` instruction is generated before any other instructions. This in practice means that we don't have any active TNode. 

We should swap the order of the pipe / template instructions in that case.
