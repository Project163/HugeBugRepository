Title

'bazel info' gives invalid exection_root, output_path for projects with WORKSPACE name not equal to the root directory name

Description
Happens when building bazel from HEAD.

Steps to reproduce:
1. find a bazel project
2. remove the `workspace(name = x)` line from the WORKSPACE file
3. `bazel clean`
4. `bazel info`

Output artifacts now appear under `[output_base]/execroot/__main__`, and `bazel info` shows the correct corresponding paths for `bazel-bin`, `bazel-genfiles`, etc.

However bazel info lists `execution_root` as `[output_base]/execroot/[project_root_dir_name]`, and `output_path` as `[output_base]/execroot/[project_root_dir_name]/bazel-out`, neither of which exist.

`execution_root` and `output_path` use the root directory name, but should instead use the WORKSPACE name.
