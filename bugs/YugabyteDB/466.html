Title

YSQL: TestPgWriteRestart is failing with "pgaudit stack is not empty"

Description
Jira Link: [Link: DB-4850]
The error happens when the writes are being restarted by postgres.

The test failure stack trace:
```
2020-10-23 01:35:38,106 (Thread-21) [ERROR - org.yb.pgsql.TestPgWriteRestart$ParallelRun.run(TestPgWriteRestart.java:59)] Error encountered
org.postgresql.util.PSQLException: ERROR: pgaudit stack is not empty            
›   at org.postgresql.core.v3.QueryExecutorImpl.receiveErrorResponse(QueryExecutorImpl.java:2440)
›   at org.postgresql.core.v3.QueryExecutorImpl.processResults(QueryExecutorImpl.java:2183)
›   at org.postgresql.core.v3.QueryExecutorImpl.execute(QueryExecutorImpl.java:308)
... [Log Snipped] ...
›   at org.yb.pgsql.TestPgWriteRestart$ParallelRun.run(TestPgWriteRestart.java:54)
›   at java.lang.Thread.run(Thread.java:748)
```

On restart of the writes we have to clear state that is generally saved during the first write. Barring that, causes the state to be accumulated which causes these failures.
