- Example WSDL and XSD's
- there seems to be some issue between cxf and apache.ws.xmlschema. 

 apache.ws.xmlschema seems to use a null as its namespace URI to indicate no-namespace, instead of using an empty stiring "", which is defined in constant javax.xml.XMLConstants#NULL_NS_URI. 

 I think we need to make a small change in cxf's JAXBDataBinding and that will solve this issue, but i'll need to run more tests.
