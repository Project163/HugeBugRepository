Title

docker_context does not check for 'default' context

Description
#### Current Behavior

When including the `docker_context` module, my prompt says (in a folder where a `Dockerfile` exists):

```

❯
```

#### Expected Behavior

Since I am using the `default` context, I expect the module to be hidden:
```

❯
```
