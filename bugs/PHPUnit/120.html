Title

"ant signed-phar" generates scoped PHAR that is too small

Description
Can't see the forest for the trees right now while working on PHAR scoping. Maybe @sebastianfeldmann can help?

#### Looks good
```
$ ant phar
$ ls -lh build/phpunit-8.0.5-21-gede2636e5.phar
-rwxr-xr-x. 1 sb sb 2.7M Mar 26 14:49 build/phpunit-8.0.5-21-gede2636e5.phar
```
```
$ ant scoped-phar
$ ls -lh build/phpunit-scoped-8.0.5-21-gede2636e5.phar 
-rwxr-xr-x. 1 sb sb 2.7M Mar 26 14:50 build/phpunit-scoped-8.0.5-21-gede2636e5.phar
```

#### Does not look good
```
$ ant signed-phar
$ ls -lh build/phpunit-8.0.5-21-gede2636e5.phar
-rwxr-xr-x. 1 sb sb 2.7M Mar 26 14:52 build/phpunit-8.0.5-21-gede2636e5.phar
$ ls -lh build/phpunit-scoped-8.0.5-21-gede2636e5.phar
-rwxr-xr-x. 1 sb sb 959K Mar 26 14:52 build/phpunit-scoped-8.0.5-21-gede2636e5.phar
```
