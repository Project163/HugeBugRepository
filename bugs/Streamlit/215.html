Title

Blank space at start of print

Description
### Checklist

### Summary

The title of my page starts on the bottom of page 1 in the printed view, this seems to be the case when the app has more than one page in it

### Reproducible Code Example

```
Python
main.py:

import streamlit as st
st.write("Test Title")
... [Log Snipped] ...
import streamlit as st
st.write("Test Title 2")
```

### Steps To Reproduce

1. Create the project as specified
2. Save to GitHub
3. Run on streamlit.io
4. Go to ... and choose Print

### Expected Behavior

The page comes up in a printable screen and looks as it goes on the web

### Current Behavior

The title doesn't start until the bottom of the first page or start of the second page (this seems to vary a bit), so we have almost an entirely blank page at the top

### Is this a regression?

- [ ] Yes, this used to work in a previous version.

- Operating System: Windows 10 Home
- Browser: Chrome
