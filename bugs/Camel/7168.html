Title

camel-smb : doesn't recover from TransportException if smb share disappears from network

Description
From the user list : 

  [URL]

   
  
 
I'm using a simple route to consume files from an SMB share and store them in a database.
When the remote server becomes unreachable, the consumer keeps trying to reconnect but seems to reuse a broken connection that wasn’t properly closed.
The only fix is restarting the whole route.
