Title

Converter must not replace existing POM files

Description
When the output folder for the converted feature is set to the local Maven repo (~/.m2/repository) then an existing POM is overwritten by the converter with the generated one. This can and will change the behavior of Maven for other projects. So, if a POM file exists then it should not be replaced and even if the existing POM is the generated it is not necessary as this file should not change otherwise the POM will be placed somewhere else.
