Title

Wrapping cursor causes crash

Description
1. Generate some output (e.g. run `ls -hal`)
2. Input spaces until the cursor wraps to the next line
3. Increase the window width until the cursor no longer wraps to the next line
4. Reduce window width until cursor wraps again
5. Alacritty crashes

This could be related to #3910.

### System

OS: Linux
Version: alacritty 0.5.0-dev (18cf806a)
Linux: X11, dwm (no compositor)
