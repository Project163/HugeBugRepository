Title

Comments in module-info.java break test compile due to parser issue

Description
When a comment exists within module definition (after opening curly braces of module), the test compile fails with  
  [ERROR]  With qdox: syntax error @ [8,8]  in  file:/Users/tomas/IdeaProjects/reproducers/maven-module-info-comments/src/main/java/module-info.java   

 To reproduce: 
 
	 unpack reproducer 
	 go into subdirectory "maven-module-info-comments" 
	 run  "mvn test" 
 

 To workaround: 
 
	 remove comment on line 5 in src/main/java/module-info.java 
	 run "mvn test"
