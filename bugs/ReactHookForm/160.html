Title

prepending to first-level field array when using nested arrays renders wrong second level fields

Description
**Describe the bug**
When using nested field arrays, prepending (or appending) a child to the first level array causes second level fields to render wrong values.

**To Reproduce**
Steps to reproduce the behavior:

1. Go to [URL]
2. Click on 'prepend foo'
3. Notice the newly prepended object has the wrong `bars`.

**Expected behavior**
The prepended `foo` shouldn't have any `bars` rendered.

**Additional context**
I suspect this issue is caused by using two levels of nesting with field arrays (i.e. `foos[0].bars[0].name`.
