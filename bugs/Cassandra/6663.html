Title

Improve metadata log catch up with inter-DC mutation forwarding

Description
We currently try to catch up from the sender when we see a newer epoch in the message. If the message has been forwarded by a peer in the local DC it might not yet have caught up. We should always try to catch up from the originator of the message.
