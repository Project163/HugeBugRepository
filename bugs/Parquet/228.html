Title

Travis kills build after 10 minutes, because "no output was received"

Description
mvn install --batch-mode -DskipTests=true -Dmaven.javadoc.skip=true -Dsource.skip=true > mvn_install.log || (cat mvn_install.log && false)  could take more than 10 minutes, and Travis  kills  the build in this case, since no output is produced (it is redirected to the log file)

    Why do we log to a file to print out its content when the execution fails. Travis captures the output, so I don't think we need to store the logs as a file.
