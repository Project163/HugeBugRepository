Title

MediaSessionConnector DefaultMediaMetadataProvider getMetadata NullPointerException

Description
### [REQUIRED] Issue description
Hello, I found that using `MediaSessionConnector.setPlayer`, in some `vivo` phones, the screen of the mobile phone will appear to go out and enter the unlock interface of the mobile phone.

After investigation, I found that `mediaMetadataProvider.getMetadata(player) `in `MediaSessionConnector.invalidateMediaSessionMetadata` returned invalid data.

However, it is found that only some models of the `vivo` model will have this problem, and other mobile phones can work normally.

```
java

  public final void invalidateMediaSessionMetadata() {
    if (mediaMetadataProvider != null && player != null) {
      mediaSession.setMetadata(mediaMetadataProvider.getMetadata(player));
... [Log Snipped] ...
      ......
}
```

Use `com.google.android.exoplayer:extension-mediasession:2.9.6` to reproduce this problem in `vivo Y55A/Y67`, as long as `MediaSessionConnector.setPlayer` is used
