Title

[YSQL] Idle YSQL connection spews error logs due to "Unknown Session" error

Description
Jira Link: [Link: DB-10182]
### Description

Consider a scenario where YugabyteDB is running on a personal laptop. The user may have several active YSQL connections.
When the user puts the laptop to sleep, these connections expire on the tserver end due to a lack of heartbeats. When the laptop is woken, the connections are initially idle but heartbeats resume.
In such scenarios, we see the following log messages being spewed at regular intervals of 10s: 
```
W0222 11:52:32.320924 1812049920 pg_client.cc:305] Session id 1: Heartbeat failed: Invalid argument (yb/tserver/pg_client_service.cc:1545    ): Connection terminated unexpectedly due to unknown session 1 (pgsql error 08003)
W0222 11:52:42.321225 1812049920 pg_client.cc:305] Session id 1: Heartbeat failed: Invalid argument (yb/tserver/pg_client_service.cc:1545    ): Connection terminated unexpectedly due to unknown session 1 (pgsql error 08003)
W0222 11:52:52.325958 1812049920 pg_client.cc:305] Session id 1: Heartbeat failed: Invalid argument (yb/tserver/pg_client_service.cc:1545    ): Connection terminated unexpectedly due to unknown session 1 (pgsql error 08003)
W0222 11:53:02.326777 1812049920 pg_client.cc:305] Session id 1: Heartbeat failed: Invalid argument (yb/tserver/pg_client_service.cc:1545    ): Connection terminated unexpectedly due to unknown session 1 (pgsql error 08003)
```

This issue seeks to fix this behavior.
