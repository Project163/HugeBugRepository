Title

Parser error for line break when creating composite key using @for

Description
### Which @angular/* package(s) are the source of the bug?

core

### Is this a regression?

No

### Description

If a line break is present in a track statement (I noticed this because Prettier auto breaks the line at the '+' if it is long enough) it will cause a parser error.

This works:

```
    @for(item of items; track (item.id + item.label)){
      {{item.label}}
    }
```

This causes a parser error:

```
    @for(item of items; track (item.id + 
      item.label)){
      {{item.label}}
    }
```
