Title

Possible regression in mypy 0.981: Generics don't work when TypeVar are previously used in a TypedDict

Description
**Bug Report**

When pulling the example of Generics from the [Link: documentation] and specifying a generic TypedDict following the [Link: blog post], I get an error on simple Generic example.

**To Reproduce**
```
python
from typing import Generic, TypeVar
from typing_extensions import TypedDict  # I am using python 3.10.4

T = TypeVar("T")
... [Log Snipped] ...
    def __init__(self) -> None:
        pass
```
Commenting line 5 removes the error. Moving line 5 after the declaration of `Stack` also works.

**Expected Behavior**
That class Stack is a correct Generic and mypy should not error.

**Your Environment**
- Mypy version used: 0.981
- Python version used: 3.10.4
