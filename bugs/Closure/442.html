Title

Function expressions are transformed into function declarations

Description
Function expressions are currently transformed into function declarations.
Since func. expression and func. declarations are evaluated at different
times during program execution, this, of course, results in a different
behavior before and after munging:

  alert(typeof f);
  var f = function(){};

becomes:

  alert(typeof f);function f(){}
