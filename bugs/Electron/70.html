Title

window.open does not open anything when called from an iframe

Description
* Electron version: 1.7.6

### Actual behavior

 
When calling `window.open` from an iframe no popup is open whereas the `new-window` events is fired on the webContents.

### Expected behavior

 
Would expect `window.open`  to open a popup even in iframe.

Note that when using with `nativeWindowOpen` it works fine.
