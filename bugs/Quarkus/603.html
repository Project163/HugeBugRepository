Title

Command mode doesn't exit after unchecked exception

Description
**Describe the bug**
Command mode projects will not exit if an unchecked exception occurs (might not only be that, but that's how I reproduced it.). It will show the stacktrace then sit doing nothing.

**Expected behavior**
I would expect the application to exit after the stacktrace and any following code has executed.

**Actual behavior**
It shows the stacktrace but does nothing afterwards.


**To Reproduce**
Steps to reproduce the behavior:
1. Create an empty quarkus command mode project with the following code:
JavaMain:
```
@QuarkusMain
public class JavaMain
{
  public static void main(String... args) {
    Quarkus.run(Testing.class, args);
  }
}
```
Testing.java:
```
public class Testing implements QuarkusApplication
{
  @Override
  public int run(final String... args) {
    boolean willFail = args[0].equals("foo");
... [Log Snipped] ...
  }
}
```
2. Run either in Intellij or command line. Behavior was observed to be the same in Intellij and dockerized native image.

**Configuration**
No additional configuration is needed.
