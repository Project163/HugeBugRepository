Title

ConstantInitializerTest fails when building with IBM JDK 7

Description
Found by Jörg Schaible during the vote for 3.2.1 RC1  [1] : 

  
 ========================== %< ====================
Failed tests:
  ConstantInitializerTest.testToString:122 Wrong string:
ConstantInitializer@-669671219 [ object = 42 ]
========================== %< ====================
 
  

  [1]   [URL]
Discussion
- We should try to fix this for 3.3
- I'm currently setting up an ubuntu  VM to investigate this.
- The problem seems to be, that the IBM JDK returns a negative number as result of the  Integer.toHexString(hashCode())  of the default toString implementation. Changing the pattern used in the test case to allow an optional dash should fix this.
