Title

Error prone integration is broken

Description
Bazel forked different version for `checker_framework_dataflow` library > 2.0, as used in error prone itself: 1.8.10. To trigger the crash, specific bug pattern checks must be activated (that are not run per default). To reliably reproduce the problem on 0.4.2, apply this patch on Gerrit Code Review [1] and run:

```
$ bazel build gerrit-server:reviewer-predicate
