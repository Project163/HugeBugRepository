Title

Crash when sharing a Heap Dump stored in app data

Description
This happens on master (post 1.5.4), Android O

Repro steps:

* Install LeakCanary sample
* Trigger a leak (prior to having granted sd card permission)
* Once the leak is correctly detected and analysed, grant permissions
* Go into the list of leaks and attempt to share the heap dump for that leak
=> crash

This likely happens because that first leak was created prior to having the sdcard permission, so it was created in the app directly.
