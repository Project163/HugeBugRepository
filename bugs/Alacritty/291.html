Title

Setting window position from CLI works only for one axis

Description
Upgrading from alacritty 0.12 I found myself unable to set *both* `x` and `y` positions from CLI, but I can set either *one*. Examples:

```
# This command applies only `x=444` option and ignores `y=333` option:
alacritty -o window.position.y=333 window.position.x=444

# This command applies only `y=333` option and ignores `x=444` option:
alacritty -o window.position.x=444 window.position.y=333
```
It feels like a latter position drops the former one.

Interestingly, if I set both `x` and `y` in the alacritty.toml and run alacritty with neither `x` nor `y` specified from the CLI, then both positions get applied correctly.

OS: Debian
Version: alacritty 0.13.0
Linux: X11, BSPWM
