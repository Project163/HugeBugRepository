## What you did

- I came across the bug in my game by spawning a level.
- Then exiting the level—all level entities and related asset handles are torn down.
- Then load a second level.
- The game crashes.

## What went wrong

Panic:

```
thread ' ' (569947307) panicked at crates/bevy_pbr/src/lightmap/mod.rs:372:35:
index out of bounds: the len is 2 but the index is 2

```

## Additional information

- I made a repro. I think it's not quite the most minimal repro you could create, but you can reliably use it to repro.
- Drop the code over `lightsmaps.rs` example and run it: `cargo run --example lightmaps`
- Press `SPACE`.
- Then press `A`.
- Then just wait a few moments for the crash. It crashes after the log `Phase 0: Creating 16 lightmaps with SAME asset (cycle 1)`.
- Even though the lightmaps themselves don't look correct in the example, I don't think that is relevant for the underlying bug which is an index out of bounds issue. Happy to be proven wrong here, but I think the meshes I set up are still valid for lightmaps, it's just that they don't _look_ good _at all_.
