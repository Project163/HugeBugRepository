Title

pillow Image.crop function cause python.exe crash

Description
So here is what i encountered:
assume i have an image file named " bmg1.bmp", if i run the script below

``` python
from PIL import Image
aoi = (1, 1, 10, 10) # an example of aoi
img = Image.open('bmg1.bmp')
img2 = img.crop(aoi)
img2.show()
```

everything is fine , but if I run:

``` python
from PIL import Image
aoi = (1, 1, 10, 10)
img = Image.open('bmg1.bmp')
img = img.crop(aoi)
img.show()
```

same error happens if i do:

``` python
from PIL import Image
aoi = (10, 10, 15, 15)
img = Image.open('bmg1.bmp').crop(aoi)
img.show()
```

the python.exe will crash, i am not sure if this is CPython's bug or pillow's bug. 

i doubt the crop function seems to return a Image object that is different from the original one, thus run show() on it gives errors, while does not on the original one.
both python 27 and python 34 have this problem, hope that will be resolved soon.

thanks!
