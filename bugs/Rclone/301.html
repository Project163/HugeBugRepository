Title

Password prompt is output to --log-file

Description
Hi there,

this has been discussed in forum.
When the config password is enabled, the log file displays the password prompt line, and It should not be there.

I use rclone 1.40 on a linux i386 architecture.

Thanks,

Marco
Discussion
- Currently when `--log-file` is engaged it redirects stderr to the log file.

However we write the password prompts to stderr so these end up in the log file too.

What we should probably do is not do the redirection until we've asked for the password, or somehow keep the old stderr handle and get the password prompt routines to use that.
- Just to remember that when using environment variables (which is very comfortable), the log only shows:

```2018/04/04 21:14:30 Using RCLONE_CONFIG_PASS password.```
- This is now fixed in [Link: the latest beta] which will be released in 1.42.
