Title

Karaf features descriptor override the ASM bundle in the jetty feature

Description
CXF defines the ASM bundle in the jetty feature. 

 Installing the jetty feature, due to the ASM bundle refresh (used in the Karaf system bundles), could set Karaf is an unstable state. 

 CXF jetty feature shouldn't define the ASM bundle and should use the one provided by Karaf.
Discussion
- I think we can remove the Jetty feature like camel does, and reuse karaf one by default. 
For the ASM bundle, I just updated the ASM 3.3 bundle version that CXF use, it will not cause ASM bundle refreshing within karaf 2.2.1 anymore.
- Removed the jetty feature from apache-cxf.
