### Issue Description

Throwing an unhelpful error when converting float columns with NaN values to integer.

Original DataFrame:
   roll   age
0  12.0  20.0
1  14.0   NaN
2   NaN  30.0
Data types: roll    float64
age     float64
dtype: object

Attempting to convert 'roll' column to int64:
    raise IntCastingNaNError(
        "Cannot convert non-finite values (NA or inf) to integer"
    )
pandas.errors.IntCastingNaNError: Cannot convert non-finite values (NA or inf) to integer

### Expected Behavior

The error message should provide actionable guidance to help users understand how to handle NaN values when converting to integer types.

- Thanks for the quick response! Here's my proposed improved error message:

IntCastingNaNError: Cannot convert non-finite values (NA or inf) to integer.

Suggested solutions:
• Use .astype('Int64') for nullable integer type (supports missing values)
• Use .fillna(value) to replace missing values before conversion  
• Use .dropna() to remove rows with missing values

Example usage:
    df['column'] = df['column'].astype('Int64')
    df['column'] = df['column'].fillna(0).astype('int64')
    df = df.dropna().astype({'column': 'int64'})
