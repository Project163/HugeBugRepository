Title

Repeating INFO: UPnP parse: unrecognized UPnP device of type upnp:rootdevice

Description
Repeats four times every refresh interval:

```
[MRIW7] 09:48:43 INFO: UPnP parse: unrecognized UPnP device of type upnp:rootdevice
[MRIW7] 09:48:43 INFO: UPnP parse: unrecognized UPnP device of type upnp:rootdevice
[MRIW7] 09:48:43 INFO: UPnP parse: unrecognized UPnP device of type upnp:rootdevice
[MRIW7] 09:48:43 INFO: UPnP parse: unrecognized UPnP device of type upnp:rootdevice
```

Actual request/response:

```
09:47:33.775298 IP (tos 0x0, ttl 1, id 27148, offset 0, flags [none], proto UDP (17), length 193, bad cksum 0 (->9212)!)
     .60300 >  .1900: UDP, length 165
E...j.........!........l....
M-SEARCH * HTTP/1.1
HOST:  :1900
... [Log Snipped] ...
ST: upnp:rootdevice
USN: uuid:3C86D905-39E4-4FDC-963C-04E19F2791BB::upnp:rootdevice
```

We should either recognize (and ignore) this device type or just not logspam about unknown device types. (It's a wireless AP controller.)
