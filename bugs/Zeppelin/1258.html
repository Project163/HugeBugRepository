Title

Zeppelin 0.9.0 cannot create paragraph after call create note http api

Description
Hi 

 With zeppelin 0.9.0, when I call create note http api, like this: 

 POST [http://[zeppelin-server]:[zeppelin-port]/api/notebook] 

 JSON: {"name": "test"} 

   

 The response is OK, but no paragraph is been  initialized, and I can not create any paragraph either.
Discussion
- zBowen  This api is used for zeppelin client api, so no paragraph is created. You can call another rest api to add paragraph. 

 BTW why you would create note via rest api and then add paragraph via ui manually ?
- zjffdu  Thank you for your reply. 

 <BTW why you would create note via rest api and then add paragraph via ui manually ?> 

 Because we want to develop a platform based on zeppelin, but on current stage, we don not have enough front-end resources, so we embeded zeppelin UI in our platform directly, and when we upgade zeppelin to version 0.9.0, we find this problem. 

   

 The API should be stable, and I hope the version 0.9.0 will be consistent with the 0.9.0-preview-2, I will fix this if it is necessay in the near future.
