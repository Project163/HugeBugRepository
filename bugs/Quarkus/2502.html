Title

wrong handling of single jvm option for opening modules

Description
### Describe the bug

Setting `open-lang-package` to `true` for DevMojo fails with runtime exception 

`java.lang.RuntimeException: Unable to parse --add-opens  = : =java.base/java.lang=ALL-UNNAMED`

### Expected behavior

dev mode starts and opens up the lang module for unnamed modules

### Actual behavior

dev mode jvm fails to start

### How to Reproduce?

start any quarkus project with `man clean quarkus:dev -Dopen-lang-package=true`

### Output of `uname -a` or `ver`

macOS

### Output of `java -version`

Java version: 25, vendor: Eclipse Adoptium

### Quarkus version or git rev

3.26.4

### Build tool (ie. output of `mvnw --version` or `gradlew --version`)
