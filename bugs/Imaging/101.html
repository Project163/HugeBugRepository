Title

Fix mvn site failure with JavaNCSS parse error

Description
The build has been failing for a while when ran with `mvn site`, due to JavaNCSS parse error in TiffElement. It appears to be due to the use of a lambda expression. 

 The plugin hasn't been updated in a while, and it was removed from lang some time ago ( [URL]

 We need to fix it before the next release, so I propose we drop this plugin, as other components have done already.
