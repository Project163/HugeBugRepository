Title

Generated service component xml does not conform to XSD

Description
The ServiceComponent xml file generated by maven-scr-plugin does not conform to the declared XML Schema Definition "[URL] Same for other specVersions ("[URL] and "[URL]

 The file is generated with root element "components", e.g.,  
<?xml version="1.0" encoding="UTF-8"?><components xmlns:scr="[URL]
    <scr:component> ...  
    </scr:component> 
</components> 

 The XSD specifies the root element as "component".
Discussion
- Afaik, the XML is correct according to the specification, see section 112.4.3. It is allowed to have a root element which does not have to be in the namespace and can have any name. 

 However, we can skip this element as we're creating a single component per XML anyway
