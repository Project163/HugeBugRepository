Title

public_api_guard: the suggested Bazel command to accept a changed golden file is wrong

Description
For example:

```
Accept the new golden file:
  bazel run //tools/public_api_guard:platform-browser_platform-browser_api_bin.accept
```

The correct command does not include the `_bin`.

```
  bazel run //tools/public_api_guard:platform-browser_platform-browser_api.accept
```
