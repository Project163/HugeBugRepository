Title

ReflectionException: Method yii\base\View::unknown() does not exist

Description
Very hard to explain. But it seems there is a bug in yii2 debug info system.

This exception is raised when trying to get undefined variable in nested view. For example in yii2 basic app with YII_DEBUG sets in true you can change `contact.php` view file to render nested view `contact_form.php`. In that file try to get any undefined variable to raise an exception. Standard debug info will be "broken" - no color highlighting, strange rows in the end.

### What steps will reproduce the problem?
1. Install yii2-basic-app
2. Set YII_DEBUG to `true`
3. Change the view @app/views/site/contact.php to
```
 render("contact_form"); ?>
```
4. Create `contact_form.php` file:
```
 
```
5. Navigate to `/index.php?r=site%2Fcontact` and see broken (not fully colored) debug view.

### What is the expected result?
Correct standard debug view.

### What do you get instead?
Broken (not fully colored) debug view.

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      |  ?
| PHP version      | 7.0.15
| Operating system | Debian 8.1.

This bug is appearing **ONLY** in nested views. If you try to call `$model->text` in main `contact.php` file nothing obvious happens. The debug view will be draw perfectly.
