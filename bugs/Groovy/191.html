Title

Under JDK 1.5 the registration of static meta method seems to result in doubled entries of the instance meta methods

Description
see groovy/inspect/InspectorTest.testStaticMetaMethods 

 The effect may not be problematic for the normal use but its ugly anyway.
Discussion
- needed some changes in MetaClass where the exactly same object was added multiple times.  
Interestingly enough the behaviour of  
list.add(metaMethod) 
was different under JDK 1.4 and 1.5 when metaMethod was already in the list. 
JDK 1.5 returned true in this case while JDK 1.4 correctly returned false. 
They both equally return true when using  
list.contains(metaMethod) 
So I needed to fallback to this slightly less performant solution (sorry to Josh Bloch  . 

 BTW: MetaClass needs some cleanup!
