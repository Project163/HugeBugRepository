Title

Undefined constant "Illuminate\Foundation\Console\SIGTERM"

Description
### Laravel Version

11.x-dev

### PHP Version

8.3.2

### Database Driver & Version

_No response_

### Description

The changes in #49943 use PHP's pcntl extension. In [Link: PHP's documentation], it notes that `this module will not function on non-Unix platforms (Windows)`, so the extension isn't available on PHP run in Windows environments and would result in the following error.

```
[2024-02-09 06:00:37] local.ERROR: Undefined constant "Illuminate\Foundation\Console\SIGTERM" {"exception":"[object] (Error(code: 0): Undefined constant \"Illuminate\\Foundation\\Console\\SIGTERM\" at D:\\laravel\\vendor\\laravel\\framework\\src\\Illuminate\\Foundation\\Console\\ServeCommand.php:143)
[stacktrace]
#0 D:\\laravel\\vendor\\laravel\\framework\\src\\Illuminate\\Foundation\\Console\\ServeCommand.php(90): Illuminate\\Foundation\\Console\\ServeCommand->startProcess(true)
#1 D:\\laravel\\vendor\\laravel\\framework\\src\\Illuminate\\Container\\BoundMethod.php(36): Illuminate\\Foundation\\Console\\ServeCommand->handle()
#2 D:\\laravel\\vendor\\laravel\\framework\\src\\Illuminate\\Container\\Util.php(41): Illuminate\\Container\\BoundMethod::Illuminate\\Container\\{closure}()
... [Log Snipped] ...
#15 {main}
"}
```

Should the trap be wrapped in `if (!windows_os()) { ... }` or, if the issue was present on Windows, perhaps another solution to be investigated?

### Steps To Reproduce

Run `php artisan serve` on Windows on a Laravel version that includes the changes in #49943.
