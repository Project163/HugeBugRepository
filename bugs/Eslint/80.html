Title

Rule 'no-unused-var' does not work in functional expression with identifier

Description
Will trigger violation

``` js
(function() {
    var a = 33;
}());

// a is defined but never used (no-unused-var)
```

Will not trigger violation

``` js
(function g() {
    var a = 33;
}());

// no errors
```
Discussion
- Interesting. This is probably related to a bug fix regarding named functions expressions a little while ago.
