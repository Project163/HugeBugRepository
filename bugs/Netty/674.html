Title

The Promise passed to a StreamChannel.close(..) call will report channel().isOpen() == true in its listeners

Description
### Expected behavior

When the promise is completed, it's channel should report being closed in the handler.

### Actual behavior

The channel still reports open.

### Minimal yet complete reproducer code (or URL to code)
Test case added to `Http2MultiplexCodecTest`:
```
java
    @Test
    public void channelClosedWhenClosePromiseCompletes() {
        LastInboundHandler inboundHandler = streamActiveAndWriteHeaders(inboundStream);
        Http2StreamChannel childChannel = (Http2StreamChannel) inboundHandler.channel();
... [Log Snipped] ...
        assertFalse(channelOpen.get());
    }
```

### Netty version
4.1

### JVM version (e.g. `java -version`)
openjdk version "1.8.0_152"

### OS version (e.g. `uname -a`)
Darwin
