Title

Tree shaking sometimes fails in presence of plusplus expressions

Description
`main.js`:

```js
import './lib'
```

`lib.js` version 1 ([Link: playground link]):

```js
function first() {
  for (let i = -1;;++i) {}
  second
}

function second() {}
```

`lib.js` version 2 ([Link: playground link]):

```js
function first() {
  ++i
  second
}

function second() {}
```

In both cases, the `main` output is:

```js
function second() {}
```

Expected output: empty. Removing the `++` or replacing it with `i += 1` bizarrely solves the problem.
Discussion
- Apparently the `i += 1` [Link: AssignmentExpression] is behaving differently than the `++i` [Link: UpdateExpression]. Should be easy enough to experimentally find the differences. Pull request is welcome.

Although Rollup ought to handle it, any rollup minifier plugin can drop unused functions:
```
$ bin/uglifyjs -V
uglify-es 3.0.28

$ echo 'function first(){++i; second} function second(){}' | bin/uglifyjs --toplevel -mc

$ 
```
