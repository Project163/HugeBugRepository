Title

Incorrect documentation of configuration for REST client providers

Description
### Describe the bug

The documentation for adding providers to a REST client using the `quarkus.rest-client."client".providers` configuration property states that it should specify a map:
[URL]

This does not appear to be the case any longer. Instead, it's just a simple list of class names:
[URL]

### Expected behavior

The documentation states that the `quarkus.rest-client."client".providers` configuration property specifies a string list of class names to register as providers for the client.

### Actual behavior

The documentation incorrectly claims that the configuration property specifies a "class name" → "priority" map.
