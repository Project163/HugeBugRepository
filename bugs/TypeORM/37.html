Title

Query Builder - Update with custom naming strategy

Description
The SELECT & DELETE query builders use escape methods for tables and column names while UPDATE does not:

  
const updateSet = Object.keys(this.updateQuerySet).map( key => key + "=:updateQuerySet_" + key);   

and

  
return "UPDATE " +  tableName  + " " + (alias ? this.escapeAlias(alias) : "") + " SET " + updateSet;
  

Is this intentional, and or should a pull request be submitted?
Discussion
