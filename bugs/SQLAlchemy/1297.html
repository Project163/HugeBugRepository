Title

Attempting to raise NotImplementedError in testing/provision.py causes another error

Description
### Describe the bug

Since the `URL` object is a named tuple, passing it to this style string formatting causes an error
[URL]
leading to:
```
TypeError: not all arguments converted during string formatting
```

### To Reproduce

```python
from sqlalchemy.engine import make_url
raise NotImplementedError(
        "no temp table keyword args routine for cfg: %s" % make_url("sqllite:///")
    )
```
