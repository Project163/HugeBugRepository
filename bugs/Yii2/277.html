Title

Postgresql schema typecasting

Description
Currently postgresql schema does not typecast `boolean` correctly due some bug on php side as noted in [Link: here], but i am not sure if it is already fixed or presents. Maybe we should make correct typecasting or note somewhere in docs for users that this is not expected behavior and they should not use `boolean` for postgresql column types when working with Yii2 ?
Discussion
- what exactly is the problem here? Do you have a query that is not working?
- @cebe when saving `ActiveRecord` with some boolean attribute that is boolean in table too, you will get an exception of types mismatch since Yii just converts boolean to integer that is wrong. See this [Link: one] . 
As for me i am not using boolean on database side for some fields that can be handled by integer but some database guys do, and this causes some problems, yet this is wrong to convert boolean to integer on Yii side. 
In current project there is some workaround with PDO api , will post it here later .
- added unit tests to verify this works.
