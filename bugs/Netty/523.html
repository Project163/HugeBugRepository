Title

missing channelRegistered(...) invocation on first channel handler when added via pipeline.addFirst(...)

Description
Inserting channel handlers into an empty pipeline yields different results depending on the method used for insertion.  When `pipeline.addLast(handlers...)` is used all handlers receive the channel registered event.  However, when `pipeline.addFirst(handlers...)` is used, then `channelRegistered(...)` is not invoked on the _first_ handler (subsequent handlers _do_ receive the event).

The following test case demonstrates the issue.

```
import io.netty.channel.ChannelDuplexHandler;
import io.netty.channel.ChannelHandlerContext;
import io.netty.channel.embedded.EmbeddedChannel;
import org.junit.Test;

... [Log Snipped] ...

}
```
