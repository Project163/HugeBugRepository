Title

schema_translate_map is no longer working for stubbed schemas

Description
**Describe the bug**
If a table has been set up with a schema stub, an incomplete reference, such as `schema_{}`, this schema stub is no longer substituted using a schema_translate_map which contains that stub e.g.  `{'schema_{}': 'schema_one'}` . The stub appears to be supplemented with a prefix `SCHEMA_` e.g. `SCHEMA_schema_{}` and, as such does not match the translate map. If the schema has no curly braces, the map behaves as expected.

**Expected behavior**
I expect the substitution to occur - it did in versions prior to 1.4.

**To Reproduce**
Run the below code after substituting the connection string

```
py
import sqlalchemy
from sqlalchemy import Table, Column, String, Integer

metadata = sqlalchemy.MetaData()
... [Log Snipped] ...

result = connection.execute(user_table.select())
```
