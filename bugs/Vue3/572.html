Title

3.5.29 regression: type error when assigning $attrs.class to :class

Description
### Vue version

3.5.29

### Link to minimal reproduction

[URL]

### Steps to reproduce

The following will produce a type error in both VS Code and vue-tsc in 3.5.29 (but not 3.5.28 and earlier):

```vue
 
	 
 
```

The Stackblitz repro will reproduce the type error too if you run `npm run build`.

### What is expected?

No type error

### What is actually happening?

Type error:
```
error TS2345: Argument of type '{ class: unknown; }' is not assignable to parameter of type 'HTMLAttributes & ReservedProps & Record '.
  Type '{ class: unknown; }' is not assignable to type 'HTMLAttributes'.
    Types of property 'class' are incompatible.
      Type 'unknown' is not assignable to type 'ClassValue'.

 
```

### Any additional comments?

This is a regression caused by #14441 changing the type of HTMLAttributes.class from `any` to `ClassValue | undefined`, while the type of $attrs is just `Record `
