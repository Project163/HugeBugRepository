Title

Overriding Panache methods leads to duplicated method error

Description
**Describe the bug**
I have a class implementng a PanacheRepositoryBase  

```
@ApplicationScoped
public class JpaOwnerRepository implements PanacheRepositoryBase  {

    @Inject
    EntityManager em;
... [Log Snipped] ...
    }
}
```

Error received 
```
org.junit.jupiter.api.extension.TestInstantiationException: TestInstanceFactory [io.quarkus.test.junit.QuarkusTestExtension] failed to instantiate test class [org.springframework.samples.petclinic.service.userService.UserServiceTests]
Caused by: java.lang.ExceptionInInitializerError
Caused by: java.lang.RuntimeException: Failed to start quarkus
Caused by: java.lang.RuntimeException: Failed to initialize Arc
Caused by: java.lang.ClassFormatError: Duplicate method name "findById" with signature "(Ljava.lang.Object;)Ljava.lang.Object;" in class file org/springframework/samples/petclinic/repository/jpa/JpaOwnerRepository
```

**Expected behavior**
The overrided method should take place, having only one method, not 2.

**Actual behavior**
Apparently 2 methods go to the compiled artifact

**To Reproduce**
Steps to reproduce the behavior:
1. Create a class implementing PanacheRepositoryBase 
2. Override *findById* method with the same identity type
3. Build and execute tests

 - Output of `java -version`:  openjdk version "1.8.0_181-ojdkbuild"

 - GraalVM version (if different from Java): 19.2.1
 - Quarkus version or git rev: master branch at today
