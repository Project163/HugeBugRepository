Title

`static` Router Cache is used once, the value of `staleTimes.dynamic` is applied the next time.

Description

[URL]

### To Reproduce

1. `pnpm clean-start`.
2. Access `[URL]

4. Your devtools network tab show that the request is **not** made.

Discussion
- Hi @AkifumiSato -- the names "static" and "dynamic" do not relate to the page rendering type, but rather different categories of "liveness" that can be configured. The actual heuristic of whether to use `dynamic` or `static` is based on the `prefetch` prop. From the [Link: docs]:

The static property is used when the prefetch prop on Link is set to true, or when calling [Link: router.prefetch].


So in this case, `static` will influence:
- How long a `loading.js` segment is held onto before being refetched from the server
- How long a segment with `prefetch={true}` will be held onto before being refetched from the server.

If you modify the Link components to have `prefetch={true}`, you'll see that your `static` staleTime property is used. 

Let me know if I misunderstood your question!
