Title

org.elasticsearch.common.settings.Settings.processSetting causes "GET /_cluster/settings/" throwing ClassCastException

Description
ES_VERSION: 5.6.8 (all likely in all version)
JVM version : JDK1.8.0_112
OS version : linux
Description of the problem including expected versus actual behavior:
Firstly I push several cluster settings to cluster twice:
step 1:
```
PUT /_cluster/settings
{
    "transient": {
        "logger.org.elasticsearch" :"info",
        "logger.org.elasticsearch.transport.netty":"ERROR"
    }
}
```
step 2:
```
PUT /_cluster/settings
{
    "transient": {
        "logger.org.transport.netty":"ERROR"
    }
}
```
