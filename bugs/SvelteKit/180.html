Title

Routing conflicts occur when multiple optional parameters

Description
### Describe the bug

Routing conflicts occur when the routes folder structure is as follows:
```
.
├── +page.svelte
└── path_a
    └── [[parameter_b]]
        └── [[parameter_c]]
            ├── +page.svelte
            └── +page.ts

```

### Reproduction

1.Create a sveltekit project

2.Let the routes folder structure look like this:
```
.
├── +page.svelte
└── path_a
    └── [[parameter_b]]
        └── [[parameter_c]]
            ├── +page.svelte
            └── +page.ts

```

3.Run `npm dev`
