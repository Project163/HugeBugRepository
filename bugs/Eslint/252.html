Title

Rules fail for arrow functions

Description
Several rules rely on escope to calculate strict scopes and so it fails for ES6 arrow functions because escope doesn't support them yet.

These rules need to be updated when escope is ready:
- [ ] no-extra-strict
- [ ] no-redeclare
- [ ] no-shadow
- [ ] no-use-before-define
