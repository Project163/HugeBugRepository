Title

[Bug]: '.' not resolving to splat path even with v7_relativeSplatPath future

Description
### What version of React Router are you using?

6.23.1

### Steps to Reproduce

1. Have a router with future `v7_relativeSplatPath` set to `true`.
2. Have an index/pathless layout route in the tree.
3. Have a splat route as a child (doesn't have to be a direct child).
4. Call `useResolvedPath('.')` in the splat route component.

Minimal example:
[URL]

### Expected Behavior

The result of `useResolvedPath('.')` should include the splat.


### Actual Behavior

The result of `useResolvedPath('.')` is the `pathnameBase`, i.e. lacking the splat part.
