Title

refresh for secondary eagerload with other attributes forces unnecessary addtional select

Description
related to #8703, we have a needless SELECT added to the output:

```
py

from sqlalchemy import *
from sqlalchemy.ext.hybrid import hybrid_property
from sqlalchemy.orm import *
... [Log Snipped] ...

s.refresh(a1, ["name", 'bs'])
```


output includes two SELECTs for a:

```
py
2022-12-16 16:16:31,404 INFO sqlalchemy.engine.Engine SELECT a.name 
FROM a 
WHERE a.id = ?
2022-12-16 16:16:31,404 INFO sqlalchemy.engine.Engine [generated in 0.00016s] (1,)
... [Log Snipped] ...
FROM b 
WHERE ? = b.a_id
```
Discussion
- this is because the PK is expired
- **Mike Bayer** has proposed a fix for this issue in the **main** branch:

**include pk cols in refresh() operations unconditionally** [URL]
