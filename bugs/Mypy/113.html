Title

Doesn't recognize all uses of super

Description
```
class A:
    def __init__(self, a): pass
class B(A):
    def __init__(self, a):
        super(B, self).__init__(a)
        self._inner = super(B, self)
```

Yields: `test.py:6: error: Name 'super' is not defined`
Discussion
- Sorry, closed the wrong issue.
- Moved to 0.4.0 as this doesn't seem very frequent in real-world code.
- I came across this bug today. I agree that this doesn't seem frequent in real-world code. An example of this usage of super here: [URL]
- This an updated example that reproduces the issue:

```py
class A:
    def f(self) -> None: pass

class B(A):
    def __init__(self) -> None:
        s = super(B, self)
        s.f()  # "super" has no attribute "f"
```
