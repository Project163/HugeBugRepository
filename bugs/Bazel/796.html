Title

getting bad gold linker value

Description
### Description of the problem / feature request:

building bazel from source for the first time and getting below error:
            gcc: error: unrecognized command line option '-fuse-ld=--enable-gold=yes'

the issue is unix_cc_configure.bzl where it is trying to determine whether '-fuse-ld=gold' is set. It is going through each line to find first line that contains the word 'gold'. Unfortunately, it found below line and return flag as '--enable-gold=yes':
x86-64.rhel.6 --enable-gold=yes --enable-tls --enable-rpath --enable-shared --enable-languages=c,c++,objc,fortran
