Title

Request path parameters not printed when printing headers

Description
Example:
For `http -v GET '[URL] what gets printed as the request line is

```
GET /foo?q=v HTTP/1.1
```

The `;bar=baz;quux=xyz` part of the URL is missing, although fortunately it _is_ sent to the server.
Discussion
- It looks like `urlparse(url).path` doesn't properly handle semicolons.

[URL]
- It looks like this part gets separated in parsing:

```
% python
Python 2.7.3rc2 (default, Apr 22 2012, 22:35:38) 
[GCC 4.6.3] on linux2
Type "help", "copyright", "credits" or "license" for more information.
ParseResult(scheme='http', netloc='example.com', path='/foo', params='bar=baz;quux=xyz', query='q=v', fragment='')
```
- It looks like [Link: `urlparse.urlsplit`] should be used instead of `urlparse.urlparse`.

We are, in fact, using `requests.compat.urlparse`.
