Title

Problem with $model->loadDefaultValues() and DEFAULT NULL in PostgreSQL

Description
We have a bug here with Yii2 2.0.6 and our PostgreSQL database. When a column is set with `DEFAULT NULL`, Yii2 puts a string `NULL` (NULL written as a text) in the attribute after we call `$model->loadDefaultValues()`.

Example:

``` SQL
CREATE TABLE "test"
(
    "id" SERIAL PRIMARY KEY,
    "name" varchar(255) DEFAULT NULL
);
```

and

``` php
$model = new Test;
$model->loadDefaultValues();
var_dump($model->name);
```

The output is

`string(4) "NULL"`

The expected output would be

`NULL`

 
I believe the problem is in yii\db\pgsql\Schema:

```
php
protected function findColumns($table)
{
    ...
    foreach ($columns as $column) {
... [Log Snipped] ...
    return true;
}
```

In our case, the value of `$column->defaultValue` comes as a string `NULL::character varying`.
