Title

3.0 - MergeVariablesTrait duplicates settings.

Description
When configuring `Components` for example, the non associative items from the arrays are duplicated, from [URL]

Setting something like this

```
    public $components = [
        'Crud.Crud' => [
            'foo'
        ]
    ];
```

ends up being something like this

```
array(
    'Crud.Crud' => array(
        (int) 0 => 'foo',
        (int) 1 => 'foo'
    )
)
```

I noticed it just happened with the outermost level, so for example

```
    public $components = [
        'Crud.Crud' => [
            'foo' => 'bar',
        ]
    ];
```

will became

```
array(
    'Crud.Crud' => array(
        'foo' => array(
            (int) 0 => 'bar',
            (int) 1 => 'bar'
        )
    )
)
```
Discussion
- I can take a look into this. When the two property values are the same we can probably skip merging them. What would you expect to happen when you have mixture of associative, and non associative settings?
- Probably the associative one should take precedence since it would have extra options.
