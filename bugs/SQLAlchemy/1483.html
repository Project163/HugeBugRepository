Title

Values().data return type is invariant in `List[Tuple[Any, ...]]`

Description
### Ensure stubs packages are not installed

- [X] No sqlalchemy stub packages is installed (both `sqlalchemy-stubs` and `sqlalchemy2-stubs` are not compatible with v2)

### Verify if the api is typed

- [Link: X] The api is not in a module listed in [#6810] so it should pass type checking

### Describe the typing issue

`Values().data(...)` works only if my tuples are exact `Tuple[Any, ...]` because `List` is invariant.

### To Reproduce

```
python
from collections.abc import Sequence
from typing import Any

import sqlalchemy as sa
... [Log Snipped] ...
    sa.column("id", sa.Integer), sa.column("name", sa.String), name="my_values"
).data(data)
```

### Error

```
a.py:21: error: Argument 1 to "invariant" has incompatible type "list[tuple[int, int]]"; expected "list[tuple[Any, ...]]"  [arg-type]
a.py:21: note: "List" is invariant -- see [URL]
a.py:21: note: Consider using "Sequence" instead, which is covariant
a.py:28: error: Argument 1 to "data" of "Values" has incompatible type "list[tuple[int, str]]"; expected "list[tuple[Any, ...]]"  [arg-type]
a.py:28: note: "List" is invariant -- see [URL]
a.py:28: note: Consider using "Sequence" instead, which is covariant
``` 

### Versions

- OS: Ubuntu
- Python: 3.11
- SQLAlchemy: 2.0.19
- Type checker (eg: mypy 0.991, pyright 1.1.290, etc): mypy 1.5.1
