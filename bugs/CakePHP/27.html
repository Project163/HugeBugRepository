Title

Model::validateMany() modifies $this -> request -> data

Description
Created by **Nicolas Hachet**, 31st Aug 2013. _(originally [Link: Lighthouse ticket #4035])_:

---
#### Context

CakePHP 2.3.10
PHP 5.3.13
Apache 2.2.22
#### What I did

I would to validate multiple rows using Model :: validateMany().
#### What happened

With options "deep" set to false, $this -> request -> data is modified incorrectly (a model key is added).
With options "deep" set to true, the result is as expected ($this -> request -> data didn't change).

Here is a test code :

```
php
// IN
debug($this -> request -> data);
$this -> Order -> set($this -> request -> data);
if ($this -> Order -> validates() 
... [Log Snipped] ...
// OUT
debug($this -> request -> data);
```

Output :

```
php
// IN
array(
    'Order' => array(
        'id' => '',
... [Log Snipped] ...
    )
)
```
#### What I expected to happen

Model::validateMany shouldn't modify $this -> request -> data with "deep" set to false (default behaviour).
#### Code of ModelValidator::validateMany

Row 211

``` php
if ($options['deep']) {
    $validates = $model->validateAssociated($record, $options);
} else {
    $model->create(null);
    $validates = $model->set($record) && $model->validates($options);
    $data[$key] = $model->data;
}
```
