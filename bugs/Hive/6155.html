Title

HiveMetaStoreFsImpl#deleteDir should check return value of FileUtils#moveToTrash

Description
HiveMetaStoreFsImpl#deleteDir  moves a dir to a the trash, but then doesn't check if  FileUtils#moveToTrash  returns true or not. Then it checks if the file exists, and throes an exception if it doesn't. If  FileUtils#moveToTrash  returns  true  then the  exists  check is not necessary. Before   HIVE-15880   the code was reading the return value of  delete  and then conditionally ran the  exists  check, we should go back to the old behavior. This can also cause problems on filesystems like S3.
