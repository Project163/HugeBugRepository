Title

routerLink and `null` value should remove `href` attribute from link

Description
```
[ ] bug report
[ x ] feature request
[ ] support request
```

**What is the motivation / use case for changing the behavior?**
Currently null or empty value passed to `routerLink` adds current page `href` value to link that is not useful. There is a lot of usecases for 'disabled' links that should not navigate anywhere and should not has `href` attribute at all.
It would be useful to have null/empty value support by `routerLink` that will results with no `href` attribute on link at all to prevent any navigation/link copying.
