Title

CTE outer reference nested in CTE main body cannot be resolved

Description
AnalysisException "Table or view not found" is thrown when a CTE reference occurs in an inner CTE definition nested in the outer CTE's main body FROM clause. E.g., 

  
 
WITH cte_outer AS (
  SELECT 1
)
SELECT * FROM (
  WITH cte_inner AS (
    SELECT * FROM cte_outer
  )
  SELECT * FROM cte_inner
)
