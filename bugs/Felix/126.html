Title

On Windows default maven includes may not work due to backslash issues

Description
The BundlePlugin.getMavenResourcePaths method has a fix to convert backslashes to forwards slashes around line 625 of the class in Rev. 596053. Unfortunately this only fixes the part of the FS location path but not the part of the bundle local path. These names may still have backslashes in them. The fix is to just apply the respective character replacement to the name in addtion to the path.
