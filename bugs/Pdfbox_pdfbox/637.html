Title

ArrayIndexOutOfBoundsException PDImageXObject.applyMask

Description
java.lang.ArrayIndexOutOfBoundsException: 3 
	at java.awt.image.SampleModel.getPixel(SampleModel.java:712) 
	at java.awt.image.Raster.getPixel(Raster.java:1539) 
	at org.apache.pdfbox.pdmodel.graphics.image.PDImageXObject.applyMask(PDImageXObject.java:272) 

 java -cp pdf-box-svn/app/target/pdfbox-app-2.0.0-SNAPSHOT.jar org.apache.pdfbox.tools.PDFToImage out.pdf
Discussion
- For some reason, SampledImageReader.getRGBImage() has returned a RGBA images instead of an RGB image. So I've expanded the array to accept 4 entries in rev 1613204. However I wonder why SampledImageReader.getRGBImage() returns an RGBA image - PDFBox bug or buggy PDF?  jahewson  could you have a look at this?
- SampledImageReader.getRGBImage() returns a RGBA image if the colorKey param isn't null. 
  
   /Name /Im2
  /Type /XObject
  /Length 21 0 R
  /Filter /FlateDecode
  /Subtype /Image
  /Width 88
  /Height 87
  /BitsPerComponent 8
  /ColorSpace /DeviceRGB
  /Mask [255 255 255 255 255 255]   <===  this  is it
  /SMask 16 0 R
- The "RGB" in "getRGBImage" refers to the color space rather than the exact image format, this behaviour is explained in the JavaDoc: 

 
 Returns the content of the given image as an AWT buffered image with an RGB color space. If a color key mask is provided then an ARGB image is returned instead.  

 The image is either RGB or ARGB. Color key masks are very rare and images use a lot of memory and CPU time, especially alpha channels, so we only use ARGB is we really have to. 

 EDIT: The bug fix looks good to me, I'll mark this issue as Fixed.
