Title

Repository 'create' is skipping inherited fields

Description
I have 2 inherited-style models,
and when I create a new entity using repository.create(JSON),
it just skips the inherited fields.

These are my models

```
@Table()
@TableInheritance("class-table")
export class Document {
    @PrimaryGeneratedColumn()
    id: number;
... [Log Snipped] ...
    updatedAt: string;
}
```

```
@ClassTableChild()
export class DeliveryNote extends Document {
    @ManyToOne(type => Customer, customer => customer.deliveryNotes)
    customer: Customer;
    @Column()
    invoice: string = '';
}
```

What can cause this?
I have used repository.create so far, and it's a good automatic way for converting the JSON into an entity. I don't want to manually insert the inherited fields now :)

Also, when will the [Link: table inheritance page] be ready? It's hard for me to guess how to use them by the [Link: samples]
Discussion
- checkout [Link: this page]. But I don't recommend to use class table inheritance because its too complex, have a small value and implementation may have bugs. Alternatively I suggest to simple use abstract tables, inherit them and thats all
