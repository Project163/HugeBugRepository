Title

Can no longer use `%(here)s` in script option in alembic.ini on windows

Description
**Describe the bug**
The change in   has switched to using shlex to split the command line agurment.

Taking the example config:
```ini
hooks=black
black.type=console_scripts
black.entrypoint=black
black.options=--config %(here)s/pyproject.toml
```
The problem is that on windows a path is expanded as `C:\\foo\\bar\\baz` and is transformed to `C:foobabaz` that is definitely not the same.
~~Quoting the path with `"`, like this `"%(here)s/pyproject.toml"`, seem to fix the issue.~~ Also setting `posix=False` on windows seems to be a fix
