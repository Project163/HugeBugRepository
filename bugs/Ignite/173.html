Title

Need to move TPS dependency into a separate dependency folder.

Description
If we keep TPS and H2 dependency in the same folder, users who only need H2, which is licensed under EPL, will also have to agree to LGPL because of TPS. 

 By separating them, licensing of H2 remains as EPL, and LGPL comes in only when users need to also bring TPS dependency for geo-spatial indexing.
Discussion
- In Ignite project we should have a separate module for TPS called  geospatial . 

 In the ZIP release, we should have ignite-tps.jar which will have Ignite integration code for TPS. It should be under  libs/optional/geospatial  folder together with TPS library and LGPL license.
- As I mentioned in the dev@: would it make sense to be totally paranoid and just have a script that will download (L)GPL libraries during the installation process, so user can make a choice to use these or otherwise?
