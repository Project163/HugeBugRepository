Title

Oracle upgrade schema scripts do not map Java long datatype columns correctly for transaction related tables

Description
In Transaction related tables, Java long column fields are mapped to NUMBER(10) which results in failure to persist the transaction ids which are incompatible. Following error is seen: 
  
 ORA-01438: value larger than specified precision allowed for this column
 
  
 NO PRECOMMIT TESTS
Discussion
- Attaching a patch that changes NUMBER(10) to NUMBER(19) datatype for long columns for Oracle metastore schema upgrade scripts.
- We haven't built install scripts for 14 yet as Ashutosh and I were discussing if there was a better method than creating the tables directly in the scripts.  So we can't apply this patch until we make a decision on that.
