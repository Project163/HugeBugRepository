Title

View Class cant be assigned from a Plugin´s View Class

Description
When trying to use a viewClass from a Plugin the following error shows up:

An Internal Error Has Occurred
Error: Class 'Painel\View\PainelView' not found
Stack Trace
CORE\src\Error\BaseErrorHandler.php line 88 → Cake\Error\BaseErrorHandler->handleFatalError(integer, string, string, integer)
[internal function] → Cake\Error\BaseErrorHandler->Cake\Error{closure}()
CakePHP: the rapid development php framework

The line 84:
return new $viewClass($this->request, $this->response, $this->eventManager(), $viewOptions);

The full method:
public function createView($viewClass = null) {
        if ($viewClass === null) {
            $viewClass = $this->viewClass;
        }
        if ($viewClass === 'View') {
            $viewClass = App::className($viewClass, 'View');
        } else {
            $viewClass = App::className($viewClass, 'View', 'View');
        }
        $viewOptions = array_intersect_key(get_object_vars($this), array_flip($this->_validViewOptions));
        return new $viewClass($this->request, $this->response, $this->eventManager(), $viewOptions);
    }
