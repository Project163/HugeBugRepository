Title

Initialize ReplChangeManager before starting actual dump

Description
REPL DUMP calls ReplChageManager.encodeFileUri() to add cmroot and checksum to the url. This requires ReplChangeManager to be initialized. So, initialize Repl change manager when taking a dump.
