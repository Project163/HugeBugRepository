Title

Table contents disappear 2nd run onwards

Description
Table contents disappear on a 2nd run of any SQL command in spark. This only happens for the table view and not for other visualizations. 
Steps to reproduce: 
 
	 Write any sql query such as
  
 %sql
select 10
 
   
	 Run the query 
	 Table will be populated 
	 Run the query again 
	 No table results are shown. 
	 Either refresh the page or switch to a visualization and switch to tabular results again to view the table.
