Title

`confcutdir` not recognised when defined in pytest.ini

Description
The docs mention the [Link: confcutdir] config option, but actually setting it in a pytest.ini gives a warning about it being unknown.

# Steps to minimally reproduce the problem
```
bash
virtualenv -p python3.7 v
. v/bin/activate
v/bin/pip install pytest

... [Log Snipped] ...

pytest
```

output:
```
$ pytest
========================================================== test session starts ==========================================================
platform darwin -- Python 3.7.9, pytest-6.2.5, py-1.10.0, pluggy-1.0.0
rootdir: /Users/cdestigter/f, configfile: pytest.ini
collected 0 items
... [Log Snipped] ...
-- Docs: [URL]
========================================================== 1 warning in 0.01s ===========================================================
```


Using `--confcutdir=.` when invoking pytest _does_ work; it just doesn't work in a pytest.ini

# os/etc

* MacOS 11.6
* pytest 6.2.5
* python 3.7.9
Discussion
- this is indeed a documentation bug

confcutdir currently  can only ever be a cli option

it seems that this oversight has been in the docs for well over 5 years
