Blank Comment Created When Submitting Only Markdown Tags (No Text)

Description
# 🐞 Bug Report — Blank Comment Created When Submitting Only Markdown Tags (No Text)

**Date reported:** 2025-11-12 
**Reported by:** Meshv Patel ([Link: @meshvpatel18])
**Environment:** Blog comment section  dev.to  

---

## 🧩 Description

When a user selects any **Markdown formatting option** (such as **Bold**, *Italic*, or _Underline_) from the comment toolbar **without typing any text**, and then submits the comment,  
a **blank comment** is created successfully.  

Additionally, the newly posted blank comment **automatically receives 1 like** — which appears to be the user's own like applied by default on submission.  
This gives the impression of an active comment even though it’s empty.

Although the editor inserts Markdown symbols (like `**` or `_`), the system should **not allow submission with no actual text** between those tags.

---

## 🔁 Steps to Reproduce

1. Open any blog post.  
2. Scroll to the **Comment section**.  
3. Click inside the comment editor.  
4. Click a Markdown button such as **B**, *I*, or ~U~.  
   - Example inserted text: `** **` or `_ _`  
5. Do **not** type anything between the Markdown symbols.  
6. Click the **Submit Comment** button.  
7. Observe the comment appears blank **and** shows `1 Like` instantly.

---

## ⚠️ Actual Behavior

- The system allows submission of the comment.  
- The comment appears **blank** under the post.  
- Inspecting HTML or API payload shows something like:
  ```json
  "content": "** **"

## ✅ Expected Behavior

- The comment **should not be submitted** if the Markdown text contains **no readable content**.  
- A validation error should appear:
