Title

Make new key updates the key if it already exists

Description
Documentation says that `mk` will create a new key /foo/bar, only if the key did not previously exist. Is this a bug? Or is there a way to create a new key with a value, only if it doesn't already exist?

```
sh
core@node02 ~ $ etcdctl mk /foo bar
bar
core@node02 ~ $ etcdctl get /foo
bar
... [Log Snipped] ...
core@node02 ~ $ etcd --version
etcd version 0.4.9
```
Discussion
- Yes. this is a bug. will fix.
