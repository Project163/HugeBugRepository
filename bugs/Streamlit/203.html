Title

Long markdown code overflows in `st.info`, `st.success`, `st.warning`, `st.error`

Description
### Checklist

- [Link: X] I have searched the [existing issues] for similar issues.
- [X] I added a very descriptive title to this issue.
- [X] I have provided sufficient information below to help reproduce this issue.

### Summary

If you use very long code (through markdown) in `st.info` and any other callout box, it overflows the box instead of scrolling. See the image at the bottom.

### Reproducible Code Example

[Link: [Image: Open in Streamlit Cloud]]

    text = """
    Here is some code:

    ```
    import streamlit as st
    st.write("Hello world!")
    # this is a very long comment just to demonstrate the overflowing behavior it goes on and on and on
    ```
    """
    st.info(text)
    st.success(text)
    st.warning(text)
    st.error(text)



### Steps To Reproduce

Run the code above.

### Expected Behavior

The code should scroll horizontally, similar to how the stacktrace in `st.exception` scrolls:

### Current Behavior

The code overflows:
