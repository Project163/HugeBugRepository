Title

Can't write an executable genrule

Description
Create this BUILD file in an empty directory with an empty WORKSPACE:

```
genrule(
    name = "x",
    srcs = [],
    executable = 1,
    outs = ["out.sh"],
    cmd = "echo echo Hello World > $@",
)
```

`bazel build //:x` works, and then `bazel-genfiles/out.sh` works, but `bazel run //:x` fails.

```
$ bazel run //:x
Unhandled exception thrown during build; message: Attribute 'executable' is potentially configurable - not allowed here
INFO: Elapsed time: 0.089s
java.lang.IllegalStateException: Attribute 'executable' is potentially configurable - not allowed here

... [Log Snipped] ...

    at com.google.devtools.build.lib.bazel.BazelMain.main(BazelMain.java:55)
```
