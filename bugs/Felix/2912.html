Title

SCR can't be wired to recent gogo-runtime versions

Description
SCR can only be wired to gogo-runtime < 1.0.0 which has the status=provisional attribute on the import. 
Since gogo is out for a year now, I think we should upgrade and remove the status=provisional attribute on the package import.
