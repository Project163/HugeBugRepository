Title

.exclusive_system() does not fail if the system has the wrong signature

Description
## Bevy version

bc4fe9b (latest main)

## Operating system & version

Arch linux

## What you did

I accidentally registered a system with a signature including `&mut Commands` and a Query using `.exclusive_system()`

## What you expected to happen

Compile failure, or maybe for it to just work normally.

## What actually happened

The program compiled and the system ran apparently as normal. The query returned results but commands scheduled with Commands never got applied.

## Additional information

In this example you can see that a component is removed using Commands which should cause the Query to stop returning results after the first frame but instead the same entity is returned every frame:

```
rust
 use bevy::prelude::*;

 fn main() {
     App::build()
... [Log Snipped] ...
     }
 }
```
Discussion
- Parallel systems can be constructed as exclusive systems, this is intended. The commands not being applied is a bug, investigating.
- Looks like an oversight on my part, which is odd, as I remember thinking about just this problem. #1531 should fix this.
