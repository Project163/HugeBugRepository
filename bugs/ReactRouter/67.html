Title

[Bug]: every second call to `router.fetch` will bypass calling `shouldRevalidate` and will revalidate instead

Description
### What version of React Router are you using?

@remix-run/router 0.2.0-pre.2

### Steps to Reproduce

In a project using `@remix-run/router` without `React` [Link: rails-remix-demo] I have the following logic:

```
ts
route.shouldRevalidate = () => false

router.fetch(fetcherKey, routeId, action, options)
// wait to finish
... [Log Snipped] ...
// wait to finish
router.fetch(fetcherKey, routeId, action, options)
```

### Expected Behavior

`route.shouldRevalidate` should be called 4 times. No revalidation should happen.

### Actual Behavior

`route.shouldRevalidate` only called 2 times on every second call. Revalidation is happening on calls bypassing `route.shouldRevalidate`
