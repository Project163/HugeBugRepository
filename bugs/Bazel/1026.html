Title

Label flag transitions are cached incorrectly

Description
### Description of the bug:

If you modify which target a label flag points to in a transition, Bazel will fail to invalidate the cache.

I verified this bug is present in versions `8.0.0-pre.20240618.2` and [URL] But it _does not_ reproduce on 7.2.1.
