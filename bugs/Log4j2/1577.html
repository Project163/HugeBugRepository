Title

log4j2 Spring Cloud config integration with MTLS gives NullPointerException

Description
Hello 

   

 I am trying to use the log4j2 Spring cloud config integration capabilities and have been referring to the sample application on the github project  [URL] When I try to configure a MTLS HTTPs URL of my cloud config server in the bootstrap.yaml of my client application which needs to fetch the log4j2.xml, I get a NPE in the  

 org.apache.logging.log4j.core.net.ssl.SslConfiguration.createSslContext(
