- Hi @wellingtonf-souza,

Setting the background image like this isn't officially supported behavior, so we don't provide any guarantees as to whether or not the workaround to use markdown will continue to work with version upgrades. Note that there is a feature request for native support for this here: #2725. Feel free to bump the issue as it's more likely we'll work on it earlier the more community demand there is for it.

All that being said, you can change your code a bit to get the markdown hack for supporting background images to work again. Changing your style tags to what's below should do the trick:
```html
 
.stApp {
  background-image: url("data:image/png;base64,%s");
  background-size: cover;
}
 
```
