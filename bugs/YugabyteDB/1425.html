Title

[DocDB] Segfault in CDC when handling `GetChanges` after beginning graceful shutdown

Description
Jira Link: [Link: DB-18310]
### Description

Enabling graceful shutdown outside of unit tests (#15061) exposed an issue with RPCs. Current we do not block new incoming RPCs and/or wait for currently inflight incoming RPCs to return before calling shutdown on various managers and classes used by RPC handlers. So incoming RPC handler threads can run and call class methods after these stateful classes have been "shutdown". Example stack traces:
