Title

Fix MemTracker garbage collection

Description
There are cases when mem tracker could be requested to release memory, if possible.
Garbage collections could be added to mem tracker for such purpose.

Such a garbage collection request contains the maximum amount of memory that should be kept by mem tracker after releasing memory.
If goal was not reached, it could request its children to release memory.
However, each child receives the same request, but it holds only part of parent memory,
so quite often the child could decide that it already does not hold too much memory and as a result does not have to perform any GC.
