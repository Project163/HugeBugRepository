Title

Syncthing will not fail to start if guiAddress is in use

Description
If I configure syncthing to host a gui at  :8080, and that port is already in use, syncthing will continue without a problem.

syncthing _will_ fail if cannot listen on the listenAddress though.
Discussion
- This is partly as designed, partly historical baggage. There is a warning on the console for the failure to start the GUI, but not being to start the GUI isn't critical - it can still do it's thing. Not being able to open the listen address is fatal, because then it (probably) can't connect to other nodes.
- But syncthing will start the browser if the listen address cannot be opened.
