Title

C++ missing in docs, linux dependencies for Ubuntu

Description
**Bevy version**
0.4.0
The release number or commit hash of the version you're using.

**Operating system & version**

Ex: Windows 10, Ubuntu 18.04, iOS 14.

**What you did**
Followed instructions in [Link: linux dependencies]
Fixed it by installing this: `sudo apt install build-essential`

**What you expected to happen**
bevy to build when following instructions in the docs


**What actually happened**
Build failed because c++ was not installed

Discussion
- Interesting. `build-essentials` installs `g++`, which is a C++ compiler.  The doc says if you want fast compiles to install `clang` ...which is _also_ a C++ compiler.  If you uninstall `g++` and install `clang`...does it still work? If so, maybe `clang` should be merged into the required installs?
- I've done a quick test on Ubuntu Server 20.04.x, where `build-essential` is not installed.

The file `/usr/bin/c++` is installed by the `g++` package. As a consequence, the instructions should have at least `g++` added.

In the issue reported, installing `build-essential` solves the problem because it installs `g++` as dependency.

I've also tested clang, but it doesn't improve the build times. I'm going to open a PR with some clarifications.
