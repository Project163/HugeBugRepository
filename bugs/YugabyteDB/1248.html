Title

[YSQL] Key is not tablet tombstone error occurs in tables with rows >= 100000 upon select query (order by id)

Description
Jira Link: [Link: DB-13928]
### Description

**Description**
Version:  -b91
Steps:
1. Create database and Create table with rows >= 100000
2. Make table with primary keys ASC
3. Load data
4. Do select query with order by id DESC

Observed Error:
`ERROR:  Key   is not table tombstone key.`

Steps:
Create required table with load data
```
CREATE TABLE customer_accounts (
    account_id bigint,
    customer_id bigint,
    account_balance bigint,
    account_number bigint,
... [Log Snipped] ...
    (i * 10000 + 1000)::bigint    
FROM generate_series(1, 100000) AS i;
```
Query giving error:
```
EXPLAIN ANALYZE SELECT account_id FROM customer_accounts
WHERE account_id > 1 ORDER BY customer_id DESC;
```
Query that passes:
```
EXPLAIN ANALYZE SELECT account_id FROM customer_accounts
WHERE account_id > 1 ORDER BY customer_id DESC LIMIT 10000;
```

**Other observations**
Initially was facing this while testing fast backward scan, but then observed the same error with fast_backward_scan turned off. After talking with @arybochkin he could reproduce same issue on the commit before the fast_backward_scan commit. This means that this error is unrelated to fast backward scan.

Also do not get same error with 99999 rows but get with 100000 rows.
Also do not get error when I LIMIT the select query.
Details with queries on JIRA.
