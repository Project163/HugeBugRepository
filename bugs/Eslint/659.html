Title

Conflict between no-undef-init and const

Description
I need to define a variable representing the value `undefined`, value that won't be modify afterward. I would like to use `const`.

By writing:

```
const FOO = undefined;
```

I hit the error: `It's not necessary to initialize 'foo' to undefined`

But if I remove the value:

```
const FOO;
```

I have the error: `Parsing error: const must be initialized`
