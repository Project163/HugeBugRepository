Title

[YSQL] [PG15] Handle create database locale option

Description
Jira Link: [Link: DB-14796]
### Description

[Link: PG13] [Link: introduced] the option of [Link: locale] in create database. 

```
locale
This is a shortcut for setting LC_COLLATE and LC_CTYPE at once. If you specify this, you cannot specify either of those parameters.
```

Currently up to 2024.2 we only support  `C` in `lc_collate` option.
```
CREATE DATABASE music lc_collate 'POSIX' TEMPLATE template0;
ERROR:  Value other than 'C' for lc_collate option is not yet supported
LINE 1: CREATE DATABASE music5 lc_collate 'POSIX' TEMPLATE template0...
```

Though in 2.25.0 (latest Master) : we allow `POSIX` and possibly other values for LOCALE option. 
```
 :5433 yugabyte@yugabyte=# CREATE DATABASE music3 LOCALE 'POSIX' TEMPLATE template0;
CREATE DATABASE
Time: 599.035 ms
```
Ideally `locale` should be limited to 'C'  and this is new option is new in YB-PG15 so likely requires similar blocker as done for collate option : [URL]
Also evaluate if that restriction can be relaxed to include any other collocations e.g ICU collocations.


================================================================================
PostgreSQL12  added the support for non-deterministic collation which should also be blocked in YB as that is currently not supported.
