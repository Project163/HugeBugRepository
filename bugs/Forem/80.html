Title

Make it so @mention of users doesn't occur in code blocks/snippets

Description
**Is your feature request related to a problem? Please describe.**

Yes! Occasionally users are writing code that inadvertently @mentions a user. 

For example, a user may choose the username "import" which would cause issues for anyone trying to write @import in their CSS code. (Shoutout to @vaidehijoshi for this example!)

**Describe the solution you'd like**

When an author writes @anything in code block or code snippets, we should make it so that the @mention functionality doesn't work to avoid interference with the code.

**Describe alternatives you've considered**

We could add words like "import" to our reserved names list.
