Title

`pytest.warns()` asserts when `pytest.skip()` is called

Description
When `pytest.skip()` is used inside `pytest.warns()` (and no warning is emitted), the test fails. I'm not sure if this is intentional but it feels a bit off, given that the test would normally be skipped instead. I've hit this in the wild in [Link: urllib3]'s test suite.

Quick reproducer:

```python
import pytest


def test_foo():
    with pytest.warns(UserWarning):
        pytest.skip("skipping")
```
