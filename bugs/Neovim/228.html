Title

Vim script syntax highlighting messed up after fold marker

Description
- `nvim --version`:  v0.3.8
- `vim -u DEFAULTS` (version: ) behaves differently? no
- Operating system/version: linux
- Terminal name/version: kitty
- `$TERM`: xterm-kitty

### Steps to reproduce using `nvim -u NORC`

Open a .vim file.
Run `:set foldenable | set foldmethod=marker`.
Declare a variable `let g:my_var = 'test'`.
Insert a newline and create a fold on the previous line using `o kzfj`.
Type some vimscript inside the fold.

### Actual behaviour

Syntax highlighting doesn't work correctly inside the fold unless a space is added between the string and the initial fold marker (`"{{{`).

### Expected behaviour

Syntax highlighting works as usual.
