Discussion
- I didn't spend much time on this one yesterday and I won't be able to work on it before tonight, so feel free to take it over if you're able to submit a PR today.
- This one is caused by `HystrixInitializer` which is an `@ApplicationScoped` bean eagerly initialized at application startup. When it is constructed, it injects a `DefaultHystrixConcurrencyStrategy` instance which itself calls `Executors.privilegedThreadFactory()` during its own construction. This last call is forbidden during the native image build time as it initializes the `FilePermission` class.

@mkouba: Would have an idea of a reasonnable way to delay the `HystrixInitializer` initialization? (I tried a few silly things but I'm pretty sure there's a simple solution here)
