Title

Add tags to "created by" metadata in the file footer

Description
Hive has been writing timestamp (without time zone) data incorrectly by converting a timestamp with no time zone to UTC. There is no way to know that Hive definitely wrote the files, so it is difficult to add a recovery mechanism in the object model. Adding a tag for the object model to the "created by" metadata will allow us to detect situations like this in the future.
Discussion
- Implemented a fix that adds  getName  to the  WriteContext  that is automatically included in the footer key-value metadata. In future API versions, we can require this to be defined but it is optional now for compatibility.
- This issue has been migrated to  issue #1451  on GitHub. Please see the  migration documentation  for further details.
