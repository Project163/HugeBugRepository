Title

HLL merges tempList on every add

Description
See comments on   HIVE-18866  ; this has significant perf overhead after the even bigger overhead from hashing is removed.
Discussion
- HLL p value is also changing to 10 in   HIVE-18079  . With that the encoding switch threshold is only 153 but temp list's default size is 1024. So there is no point maintaining temp list. I will probably remove temp list as it will not help and can cut on additional branches.
