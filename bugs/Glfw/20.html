Title

Gamma ramp is set globally, not per monitor

Description
On Windows it appears that glfwSetGammaRamp sets the gamma ramp for all monitors instead of the specified monitor. I have two monitors, attached to different graphics cards, and a call to glfwSetGammaRamp on either monitor changes the gamma for both.

This may be an issue with the call to EnumDisplayDevices in win32_gamma.c. The iDevNum parameter is hard-coded as 0. Doesn't this need to be the index number of the display?
Discussion
- GLFW currently only uses display zero of every adapter, so any `GLFWmonitor` by definition has display index zero. That may change in 3.1 due to Oculus Rift support, but currently this is how it works.

That said, the gamma ramp _should_ be set per monitor and not globally. I will look into it.
- This got fixed as part of my Rift work.
