Title

Unit() function doesn't throw errors

Description
I had to try several variations before I could get the unit function to work.

I did:

```
#1 - font-size: unit(80px/16px,rem);
#2 - font-size: unit(80px/16,rem);
#3 - font-size: unit(80/16,rem);
```

Finally, I guessed that I probably had to write:

```
#4 - font-size: unit( (80px/16px ),rem);
```

Okay, I got bitten by the parentheses within parentheses requirement. That's ok (I guess). But the bigger issue is that no errors were thrown (with perhaps something helpful like, "hey you need 2nd parentheses for math"). Attempts 1-3 output:

```
font-size: NaNrem;
```

The parser should probably throw an error rather than put a non-number value directly in the CSS output.
