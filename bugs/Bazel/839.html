Title

Experimental persistent test runner throws NPEs during test action creation

Description
### Description of the problem / feature request:

Using the experimental persistent test runner via `--test_strategy=local --strategy=TestRunner=worker --experimental_persistent_test_runner` results in null pointer exceptions in the test infrastructure, during sh tests. 

### Bugs: what's the simplest, easiest way to reproduce this bug? Please provide a minimal example if possible.

In our case, we have a sh_test which is a build test, which takes deps and just runs a no-op shell script. When we run with the persistent worker, we get errors during createTestAction:
