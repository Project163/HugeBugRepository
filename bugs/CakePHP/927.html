Title

Regression in UrlHelper::build() for empty argument

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.6.0

### What you did
I use `$url = $this->url->build()` to get an URL pointing to the current controller & action (here: MaterialsController, index()).

### What happened
The URL in $url is malformed as it does not include the base URL path.

### What you expected to happen
In previous CakePHP, $url would contain a valid URL. The URL is also valid if the argument is not empty, e.g. `$url = $this->url->build(['controller' => 'materials'])`, or  `$url = $this->url->build('action' => 'index')`, or `$url = $this->url->build('foo', 'bar')`.
Discussion
- Usually `/materials` and `/materials/index` are functionally equivalent though.
- The problem seems to be more refined than I thought.

The 'index' part is indeed not the problem. The problem is that the base URL path is missing, similar to #11954
