Discussion
- You have two repositories named "default". One explicitly, the other implicitly by having a blank ID. This isn't allowed.

I guess the cause is that you added a repository without setting an ID in the GUI, which it ought to complain about. It also obviously shouldn't _crash_, so two bugs here. But fixing it entails setting the "id" and "directory" attributes to something sensible on that second repository.
- (Notes to self)
- Make ID and Directory mandatory in GUI
- Handle the potential duplicate/missing errors gently: log an error, disable the repos, make it possible to fix it in the GUI.
- So here's a quirk about this...now you can delete the duplicate but it deletes both instead of just one.
- Yeah. And you can still add a new repository with the same ID as an existing one, effectively overwriting it. That sucks...
