Title

--aws-sigv4 is missing the amz-content-sha256 header?

Description
R2 from Cloudflare requires x-amz-content-sha256 to be present on every request. This is part of the SigV4 docs: [URL]


### I did this
```
curl [URL] --user ' : ' --aws-sigv4 "aws:amz:auto:s3"
```

When I use ` ` as the content-sha256 then it seems to works (i.e. `x-amz-content-sha256:  `).

However, this is incorrect for POST requests which fail with:
```
  XAmzContentSHA256Mismatch  The provided 'x-amz-content-sha256' header does not match what was computed.  
```
since ` ` is not the payload.

### I expected the following
A successful get and post.
