Title

Fix licensing and usage of gutenberg files in Spark test

Description
Spark runner tests use couple of Gutenberg files: 

  
 runners/spark/src/test/resources/pg1112.txt
runners/spark/src/test/resources/pg2264.txt
 
  

 At least, the LICENSE file should mention these resources. However, as the Project Gutenberg license is not listed in Apache license categories, we have to ask to legal. 

 In order to simplify our NOTICE file, and avoid any legal concerns, I propose to replace the  pg*  Spark test resources with another kind of resources for the test (handmade for instance).
