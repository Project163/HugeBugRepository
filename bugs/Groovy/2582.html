Discussion
- Just a note about the code example. The compile should report an error, because the line:  

  tokens = map  

 try to assign a Map object to "tokens" which type is "String[]" since it is inferred by the above assignment:  

  def tokens = splitString(line)
- Since  tokens  is declared using  def , it's not an error. It only makes the flow type change.
