- Thank you for opening this.  Which commit is this?  I regret I don't understand your reference to 76-g743c19c97.  The released 1.16 was b99f344, and the current is 4455a6f. 

 I'm guessing by the line number that this is trunk/master.  I'll take a look.
- I corrected the commit to be 1.16-75-g4455a6f08 which is the output of `git describe` (quite useful command as you might figure out - if you don't provide commits of your own branches which no one can find...), so you can check it out just like a hash or you skip the ` [latest tag] - [commits after tag] -g` part and take the hash from there.
- There was a mismatch in the locale settings.  The unit test was taking the locale from POI LocaleUtil, but the parsers were taking the Locale from Locale.getDefault().   I switched the parsers to take the locale from LocaleUtil if a user doesn't specify Locale via the ParseContext. 

 I also added a unit test to make sure that Locale.ITALIAN works.  This failed before the modifications. 

 Many thanks to  krichter  for raising this issue!  Please let us know if this doesn't fix the build for you.
