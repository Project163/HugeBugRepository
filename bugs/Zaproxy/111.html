Title

ZAP Spidering HTML Forms with multiple submit buttons

Description
ZAP when encountering an HTML Form with multiple submit buttons defined

e.g.

```
 
 
 
 
```

it spiders for the following URL
/test.jsp?name=a&submit1=Reload&submit2=Basic

instead of submitting two URLs like
/test.jsp?name=a&submit1=Reload
/test.jsp?name=a&submit2=Basic

Reference: [URL]

Additionally, the "value" attribute of the input type="submit" element can be used as a differentiator in the edge case where the two submit buttons have the same ID/name

e.g.

```
 
 
 
 
```

the spider can generate the following requests
/test.jsp?name=a&submit=Reload

- With this (and #2749 ) we will probably need to first read all of the action values and then submit the form for each value without duplicating the other actions. Sound like a plan @thc202 @kingthorin ?

Both issues could be merged? (It doesn't really matter if they have the same name or not, only one submit button is included.)
