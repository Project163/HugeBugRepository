Title

Olingo2 component doesn't support entity container names for batch requests

Description
Olingo2 component had an underlying assumption that all entity sets for an OData service would be in its default entity container. But designating containers as default is optional in OData.  
So the component needs to account for fully qualified resource paths like entity-container.entity-set
