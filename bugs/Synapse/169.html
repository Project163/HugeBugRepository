Title

Synpase is blocked and does not deliver responses

Description
After a while of normal operation Synapse does not deliver responses and seems to be blocked. Having a look at the threaddump of an instance in this state the client worker threads are waiting for a notifaction which is never send. This issue might be related to IOExceptions which occured before due to some client-side timeouts. 

 Please find attached a threaddump of an instance in this state. There you will also see an issue with duplicated threads which are probably a result of gracefuly restarts via JMX. Although both issues must not be related and could be handled separated.
