Title

DocumentMapping documentMappingForPath looks at the wrong names

Description
DocumentMappings map source document field names to their indexed fields.  In this method, in which we try to look up information about how to index/analyze a particular field, we compare with source document field names, when we should be checking the indexed field names.

This always worked in the simple examples before where the names were the same.  In a test case with @steveyen we introcued a field which we indexed multiple ways.  Later, when searching on the field name that did not match the source field name, we found this problem.

Need test case to test both cases, find field names which are the same, and those were are new field names not existing in the source.
