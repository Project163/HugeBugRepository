Title

flink-queryable-state-runtime not a dependency in flink-dist

Description
flink-dist  requires the  flink-queryable-state-runtime  module to be build since   FLINK-7824   but this is not set as a dependency in the  pom.xml  and thus fails building the sub-project alone, e.g. via  mvn install -pl flink-dist -am
