Title

Frustum Culling when Mesh Parent is Scaled

Description
Hi

I have a mesh that is a child of an object, which in turn is a child of a scene. 

The object has it's x, y, and z scale set to a value that is greater than one. This, or course, causes the mesh to be displayed larger.

However, the object disappears prematurely as it begins to exit the frustum (viewport).

Here is a flddle demonstrating the problem: [URL] .

It appears from looking at the code (and belive me, I am no expert here), that the bounding sphere radius used in the frustum culling routine does not to take into consideration the scale of the parent -- only the scale of the mesh itself.

Is there a work-around? Am I compeltely off-base?

Regards,

WestLangley
