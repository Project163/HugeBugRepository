Title

uppercase breaks block_list

Description
#### Problem Description

using these values for `block_list`

~~~
/~u AccountsSignInUi/444
/~u accountssigninui/444
~~~

neither one is blocking the expected URL:

~~~
[URL]
~~~

this works:

~~~
/~u .ccounts.ign.n.i/444
~~~

why is uppercase character breaking the search?
