Title

Thrift exceptions are not hashable in Python 3

Description
The Thrift-to-Python compiler generates `_ eq  ` but not `  hash _` for Thrift exception classes, which makes them not hashable in Python 3. Due to  [URL] this can lead the Python standard library to throw an error while printing tracebacks involving Thrift exceptions. 

 The attached patch generates `_ hash _` for Thrift exceptions. This can technically be incorrect since Thrift exceptions are mutable (compare  [URL] but in practice it seems unlikely that people would mutate exception instances other than directly after creating them, and without this patch some Thrift exceptions cannot be displayed by the standard library.
