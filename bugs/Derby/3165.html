Title

Fix the release notes generator now that the JIRA SOAP api has been deprecated

Description
The current version of JIRA no longer supports the SOAP api used by the release notes generator to list fixed bugs, their summaries, and detailed release notes. We need to fix this tool before we can produce any more releases.
Discussion
- Attaching derby-6990-01-aa-removeSOAPlogic.diff. This patch removes the invocation of the broken SOAP api by the genrelnotes target. With this patch, you can generate release notes provided that you manually create a fixedBugsList.txt file. Instructions for creating that file can be found at  [URL] which is linked from the master page that describes how to generate release notes:  [URL]

 More work could be done on this issue in order to automate the process of producing the list of fixed bugs. That is a mini-project which deserves some thought. In the meantime, hopefully, this patch will make it possible to proceed with generating 10.14.2 release candidates.
