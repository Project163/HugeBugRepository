Title

Cursor color changes after Tab completing `:help`

Description
- `nvim --version`:      NVIM v0.4.0-610-g773bdd41e Build type: RelWithDebInfo
 - Vim (version: 8.1-1176) behaves differently? Yes, the cursor is correctly drawn.
 - Operating system:     Ubuntu 16.04.6 LTS
 - Terminal emulator:    rxvt-unicode v9.22
 - Terminal multiplexer: tmux 2.9
 - `$TERM`:              tmux-256color
 - Shell:                zsh 5.7.1-dev-0 (x86_64-pc-linux-gnu)

### Steps to reproduce using `nvim -u NORC`

Consider this shell command:

    $ nvim -Nu NONE +'colo evening'

### Actual behaviour

If you type `:help` then press Tab to complete the command, the wildmenu appears and suggests:

    help  helpclose  helpgrep  helptags

But the color of the cursor changes from black to light grey, and the next 2 cells are colored in white, while they should be colored like the rest of the line (i.e. dark grey).
If you insert 3 characters, the cursor color is properly restored.
If you press Tab to get the next suggestion (`helpclose`), the cursor color is, again, properly restored.
If you press Escape, the cells 5, 6 and 7 on the command-line stay in white.

[Image: gif]

I bisected the issue to [Link: `7ede14d`].

It seems related to some colorschemes, because I can't reproduce with the default one, but I can with [Link: seoul256.vim]. OTOH, the terminal doesn't seem relevant, because I can reproduce in st, urxvt, xfce4-terminal and gnome-terminal, inside/outside tmux.

### Expected behaviour

The cursor color should not change after tab completing `:help`.
