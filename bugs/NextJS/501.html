### Describe the Bug

The `./src/app/(public)/not-found.tsx` isn't using the [Link: Root Layout] of `(public)` folder.

```
app
  (admin)
    - layout.tsx
    - page.tsx
  (public)
... [Log Snipped] ...
    - not-found.tsx
    - page.tsx
```


### Expected Behavior

The `./src/app/(public)/not-found.tsx` file should use the [Link: Root Layout] of `(public)` folder, as it's in the same route group and should consider `./src/app/(public)` to be the root of its tree.

So when we visit [Link], we should get "Welcome to public page !" followed by "Not found!"

It was working on [Link: v13.4.9] but according to a Next.js user, a v13.4.10 canary version broke this feature :(
