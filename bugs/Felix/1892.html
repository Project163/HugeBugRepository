Title

[DS] While disposing a component, it's possible to unbind a reference that wasn't bound.

Description
When we dispose of a implementation object, in the ImmediateComponentHandler,  
(1) t1 we set m_implementationObject to null 
(2) t2 Any bind operation will now not succeed since the impl object is not available, but we track it 
(3) t1 the dependency manager gets the tracked objects and proceeds to unbind them. 

 I'm thinking about a different solution to   FELIX-3754   as part of this.
