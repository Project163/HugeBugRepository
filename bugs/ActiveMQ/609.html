Title

Failover transport causes connection / thread leak when broker is unresponsive

Description
We have observed in a production environment cases where an overloaded ActiveMQ broker stops responding to requests in a timely manner – connections can be created, but communication is slow enough to trigger reconnect. 

 Unfortunately, the old connections never get cleaned up, leading to resource exhaustion on the both the clients and the broker.
