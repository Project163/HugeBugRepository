Title

no-init (W0232) on Enum subclasses

Description
Originally reported by: **Anonymous**

---

Given the following code:

```
#!python

"""Sample code for a bug report."""

from enum import Enum
... [Log Snipped] ...
    megashark = 1
    octopus = 2
```

`pylint` will output the following:

```
% pylint -d too-few-public-methods -r n bugreport.py
No config file found, using default configuration
************* Module bugreport
W:  5, 0: Class has no __init__ method (no-init)
```

Would it make sense to suppress no-init on subclasses of Enum?
