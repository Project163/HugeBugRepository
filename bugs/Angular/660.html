Title

inject() not exported from @angular/core

Description
Tree-shakeable injectors with dependencies use `inject()` in generated code to access the injector:


```typescript
import {defineInjectable, inject} from '@angular/core';

export class Service {
  static ngInjectableDef = defineInjectable({scope: SomeModule, factory: () => new Service(inject(Dep))});
  ...
}
```

`inject` is not exported from `@angular/core`, which causes this code to break at runtime.
Discussion
- Tests didn't catch this because of a very weird effect: Angular repo code doesn't run through tsickle or build-optimizer during the tests, so decorators retain their runtime effects. The `@Injectable` decorator is designed to do the same thing that the compiler does, and patch the decorated class with `ngInjectableDef`. Thus, the broken `inject()` call is never executed, as it's replaced at runtime with the decorator side effect version which points to the internally-imported `inject()` function.
