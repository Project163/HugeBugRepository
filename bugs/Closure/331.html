Title

goog.scope aliasing improperly applied to object property names in @typedef

Description
What steps will reproduce the problem? 
1. Compile this file:

goog.provide('foo.bar.baz');
    
goog.scope(function() {
var baz = foo.bar.baz;

/**
 * @typedef {{baz: string}}
 */ 
baz.SomeType;
    
/** 
 * @type {baz.SomeType}
 */ 
baz.instance = {baz: 'Foo'};
    
}); // goog.scope

 What is the expected output? What do you see instead? 

Expected output: No warnings.
Actual output:
foo.js:18: WARNING - assignment to property instance of 
foo.bar.baz
found   : {baz: string}
required: {foo.bar.baz: string}
baz.instance = {baz: 'Foo'};

 What version of the product are you using? On what operating system? 
HEAD on Linux.

 Please provide any additional information below. 

Workarounds:

(1) Enclose the property name in quotes 
or (2) Move the @typedef outside of the goog.scope.
