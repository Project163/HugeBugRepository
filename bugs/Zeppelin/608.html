Title

zeppelin should redirect to login page after browser session expires

Description
Scenario: 
 
	 open zeppelin notebook on a browser 
	 Keep it open for few hour 
	 In between restart zep server 
	 Revisit the browser tab . It will have a pop up with message. " Your ticket is invalid. ..." 
	 click on Ok. 
 

 Current behavior: 
The browser stays at the same stale page.  

 Expected behavior: 
Either It should redirect to the login page after clicking ok on session expire message box or do not show the expired ticket msg (mention that session expired) and redirect to log in page.
