Title

FineGrainedSlotManager cause NPE when clear pending taskmanager twice

Description
When job finished we call processResourceRequirements(ResourceRequirements.empty) and clearResourceRequirements. Both methods trigger  
taskManagerTracker.clearPendingAllocationsOfJob(jobId) to release pending task manager early. 
  
This causes NPE, we need to add a safety net for PendingTaskManager#clearPendingAllocationsOfJob
