Title

Console Options: Wrong help text shown when entering value.

Description
##### Steps to reproduce the problem:

1. Use arrow keys to navigate to random option, e.g. ciphers_client. The help string now is "Set supported ciphers for client connections using OpenSSL syntax."
2. Press enter twice to start and finish edit.
3. The help box now shows the help text of the first option ("Add all certificates of the upstream server to the certificate chain that will be served to the proxy client, as extras.")

##### Any other comments? What have you tried so far?
