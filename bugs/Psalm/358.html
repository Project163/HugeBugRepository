Title

MissingDependency false positive on UNIX

Description
Similar to one of the original bugs in #1135, I am now running into a `MissingDependency` issue only on UNIX (my dev machine is windows 🙄), and it works fine there.

```
ERROR: MissingDependency - app/.../File.php:282:35 - ...\Model\AppModel depends on class or interface model that does not exist
```

Now, the parent class in question is `Model` (notice the capitalization), and throws no error on Windows, which is case-insensitive.

Let me know what else you need to solve this one.
Discussion
- I'm not 100% sure this is a case-sensitivity.

The name resolution of a class-aliased class is insensitive to case: [URL] so at the point this happens Psalm doesn't know about the `class_alias` call.

What's the context of this error - does it appear in CI, or somewhere else? You may need to do some of your own logging here.
- There's no alias here. Also, this class is not namespaced, so I require it
in the psalm init file.

This is in Gitlab CI, which is run within a docker container.
