- I'm getting the same problem.
This problem only occurs when you try to backup your files to the same directory by two remotes. Ex: remote1 on this server and remote2 on another server. Both try to rmdirs directory DATABASE.

the 1st one
`rclone copy /dir1 remote1:DATABASE`
`rclone -q --min-age 30d delete remote1:DATABASE`
`rclone -q --min-age 30d rmdirs remote1:DATABASE`
the 2nd one
`rclone copy /dir1 remote2:DATABASE`
`rclone -q --min-age 30d delete remote2:DATABASE`
`rclone -q --min-age 30d rmdirs remote2:DATABASE`
