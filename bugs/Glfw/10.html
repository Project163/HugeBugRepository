Title

glfwShowWindow restores maximized window

Description
Hi !

When window is maximized and not focused, glfwShowWindow changes focus but restores size of the window to the default (before maximized).

win32_window.c [ line 1155]

```
void _glfwPlatformShowWindow(_GLFWwindow* window)
{
    ShowWindow(window->win32.handle, SW_SHOWNORMAL);
```

from MSDN:

SW_SHOWNORMAL

Activates and displays a window. If the window is minimized or maximized, the system restores it to its original size and position. An application should specify this flag when displaying the window for the first time.

SW_SHOW

Activates the window and displays it in its current size and position.

So maybe there should be SW_SHOW insted of SW_SHOWNORMAL in the code above ? Or some statement that would determine if the show is invoked first time for that window and use SW_SHOWNORMAL once (?).
