Title

Warn about incorrectly-cased classes

Description
While PHP is theoretically case-insensitive, custom autoloaders may not be. So given these two files, the custom autoloader may just look for a file named 'foo.php' which, on a case-sensitive OS like Linux, would return false.

Foo.php
```php
class Foo {}
```
uses_foo.php:
```php
(new foo());
```
