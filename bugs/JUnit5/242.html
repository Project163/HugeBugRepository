Title

StringUtils.nullSafeToString returns null if toString() returns null

Description
## Overview

The original intention of `StringUtils.nullSafeToString` was that it does not throw a `NullPointerException`, not that it never returns `null`.

However, as discussed in [URL] the Javadoc states that `StringUtils.nullSafeToString` never returns `null`, which can occur if the invocation of `toString()` returns `null`. Thus, the implementation is not aligned with the documentation.

## Deliverables

- [x] Change the behavior of `StringUtils.nullSafeToString` so that it returns `"null"` if the invocation of `toString()` returns `null`.
