Title

Grok pipeline definition parameter "pattern_definitions" cause the master node shut down

Description
When I use the api to define an pipeline like this:
`
{
  "processors" : [
    {
      "grok" : {
        "field": "message",
        "patterns": ["..."],
        "pattern_definitions":{
        	"JAVACLASS":"\\s*%{JAVACLASS}
        }
      }
    }
  ]
}`

Note the "pattern_definitions" parameter, I use the old value of "JAVACLASS" pattern  to overwrite JAVACLASS. It cause the master node shut down.

Maybe it is not a correct operate to define a customer pattern like this, but master node shut down immediately is a problem.
