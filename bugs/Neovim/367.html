Title

ShaDa file corruption on nightly

Description
### Problem

Neovim Nightly seems to randomly corrupt the ShaDa File. See the attachment for the corrupted file (remove the .txt extension)
[Link: main.shada.txt]

### Steps to reproduce

1. Create test folder with init.lua following the template and a markdown file with some text
2. Edit `nvim -u init.lua test.md`
3. Make some edits
4. Save & close with `:x`
5. Repeat `2` - `4` until the corruption appears
6. Error message `E576: Failed to parse ShaDa file: extra bytes in msgpack string at position 4083` appears on start

### Expected behavior

No corruption occurs.
