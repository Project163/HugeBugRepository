Title

Compute lag correctly for optimized source changelogs

Description
During KIP-441 we originally decided to leave the special handling of optimized source changelogs as a potential future improvement, since over-estimating lag was acceptable. 

   

 But as always things have changed during the course of implementing this KIP, and the algorithm we ended up with requires accurate computation of lag. We should branch the lag computation in the assignor and use the correct end offset sum when computing lag
