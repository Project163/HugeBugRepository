Crashing code is:

```
internal fun String.createSHA1Hash(): String = encodeUtf8().sha1().hex()
```

LeakCanary depends on Okio 2.2.2 at compile time and generates bytecode based on that. The bytecode for `encodeUtf8()` is:

```
    GETSTATIC okio/ByteString.Companion : Lokio/ByteString$Companion;
    ALOAD 0
    INVOKEVIRTUAL okio/ByteString$Companion.encodeUtf8 (Ljava/lang/String;)Lokio/ByteString;
```

So that definitely seem like it would crash.. but idk how much I can trust the IntelliJ decompiler.
