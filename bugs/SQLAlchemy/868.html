Title

consider allowing dupe cols in select() so that selected cols / tuple matches

Description
this is inconsistent:

```
from sqlalchemy import *
from sqlalchemy.orm import *
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.ext.declarative import declared_attr

... [Log Snipped] ...
print(s.query(A.id, A.data, A.id).all())
print(s.execute(select([A.id, A.data, A.id])).fetchall())
```


```
[(1, 'x', 1)]
[(1, 'x')]

```

for 2.0 this really should be consistent and we should allow dupe cols in SELECT though that probably has huge ramifications
Discussion
