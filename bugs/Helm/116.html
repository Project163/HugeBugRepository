Title

"helm lint" does not complain on duplicate keys in chartfile YAML

Description
Currently, `helm lint` accepts chartfiles which have duplicate mapping keys (this constitutes invalid YAML), e.g. it accepts the following:

```
yaml
apiVersion: v2
name: test
A Helm chart for Kubernetes
type: application
... [Log Snipped] ...
    version: 0.18.0
    version: 0.17.1       ", GitTreeState:"clean", GoVersion:"go1.18.8"}
```
