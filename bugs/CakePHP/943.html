Title

Unicode character property in Route

Description
* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.6.6

### What you did
i need to match ALL unicode characters in routes

in config/routes.php
```
$routes->connect('/:input',
        ['controller' => 'Analyses', 'action' => 'domain'],
        ['_name' => 'analyse.domain', 'input' => '(?i:(?:[\p{Ll}0-9\._-]+\.)+\p{Ll}{2,63})', 'pass' => ['input'], 'multibytePattern' => true]
    );
```
first, i should force `multibytePattern` but this options don't exists in documentation.

### What happened
My route pattern is OK in "_compiledRoute" but the Route\Route::match() method don't use it at end of the method

```php
        if (!empty($this->options)) {
            foreach ($this->options as $key => $pattern) {
                if (isset($url[$key]) && !preg_match('#^' . $pattern . '$#', $url[$key])) {
                    return false;
                }
            }
        }
```
the `'#^' . $pattern . '$#'` should be `'#^' . $pattern . '$#u'`

### What you expected to happen
route match correctly ;)
i've saw the #8332 but it's not exactly the same
