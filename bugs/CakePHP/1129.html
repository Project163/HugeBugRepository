Title

Validation::utf8 does not validate in "extended" utf8 mode

Description
### Description

Validator::utf8Extended and the Validation::utf8 function (in extended mode) bypass validation altogether. In non-extended mode the string is checked with  preg_match('/[\x{10000}-\x{10FFFF}]/u', $value) === 0. In extended mode it simply returns true.

It should  preg_match('//u', $value) === 1 to validate the string.

Additionally we should also disallow NUL bytes (\x00) because even though they are valid utf8 it's not something users expect to find in strings.

### CakePHP Version

4.4.13

### PHP Version

8.1
