Title

switch should be expression like if

Description
The code 
  
 #! /usr/bin/env groovy

def ifClosure = { ->
   if  ( 0 ) { 10 }
   else  { 20 }
}

def switchClosure = { ->
   switch  ( 0 ) {
   case  0 : 10 ;  break 
   default  : 20 ;  break 
  }
}

println ifClosure ( )
println switchClosure ( )
 
  
 produces the output: 
 
 20 
null  
 which seems inconsistent.
