Title

Scope is incorrectly determined when using function expressions.

Description
# Bug report

 
 
 
 

**What is the current behavior?**
The imported function `someFunction` in `index.js` is incorrectly called from within the inline function expression `someFunction` in `index.js` instead of calling itself recursively.

**If the current behavior is a bug, please provide the steps to reproduce.**
Gist:
[URL]

Structure:
`wp.js` 
`src/index.js`
`src/someFunction.js`

**What is the expected behavior?**
The inline function expression `someFunction` in `index.js` should call itself recursively. The imported function `someFunction` should _not_ be called.
