Description
# Bug

```
$ python -c "import pydantic.utils; print(pydantic.utils.version_info())"
             pydantic version: 1.5.1

                 install path: /shared/conda/envs/devl/lib/python3.7/site-packages/pydantic

                     platform: Linux-5.3.0-46-generic-x86_64-with-debian-buster-sid

```

The snippet
```
py
from pydantic import BaseModel, root_validator


class Model(BaseModel):
... [Log Snipped] ...
    # This fails with KeyError in validate_x
    Model().parse_obj({'x': 1})
```
outputs
```
  {'x': 1}
  {}
Traceback (most recent call last):
  File "pydantic_debug.py", line 19, in  
    Model().parse_obj({'x': 1})
```
