Title

Reflective access warning in Qute

Description
We have these warnings in the build logs:

```
Error: -04 15:48:27,954 INFO  [io.quarkus] (main) Quarkus[ERROR] WARNING: An illegal reflective access operation has occurred
Error:  WARNING: Illegal reflective access by io.quarkus.qute.ReflectionValueResolver (file:/D:/a/quarkus/quarkus/independent-projects/qute/core/target/classes/) to method java.util.TreeMap$EntrySet.iterator()
Error:  WARNING: Please consider reporting this to the maintainers of io.quarkus.qute.ReflectionValueResolver
Error:  WARNING: Use --illegal-access=warn to enable warnings of further illegal reflective access operations
Error:  WARNING: All illegal access operations will be denied in a future release
```
Discussion
- Hm, so the `ReflectionValueResolver` fallback is probably not the only one that uses `java.lang.reflect.AccessibleObject.setAccessible(boolean)`. What's the quarkus general strategy in this area?
