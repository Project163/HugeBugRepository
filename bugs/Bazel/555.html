- Sorry for the delay, it's now fixed (as in: it doesn't crash anymore). But I have to point out that you should update your code. You cannot use `package_name` as a default argument.

When bzl files are evaluated, there's no information of package. Multiple BUILD files may reference the same bzl file, so `native.package_name` is failing when you use it in the bzl file (as a default argument or in a global variable). However, the package is defined when a BUILD file calls a function in a bzl file.

Suggested fix:
```
def my_lib(
        name=None,
        srcs=None,
        deps=None):
    name = name or native.package_name()
... [Log Snipped] ...
        deps=deps
    )
```
