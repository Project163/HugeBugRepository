Title

invalid XML file produced after org.jsoup.nodes.Document to org.w3c.dom.Document conversion

Description
I have an XML `org.w3c.dom.Document`, coming from an HTML `org.jsoup.nodes.Document`.

When I serialize the `org.w3c.dom.Document`, it produces an invalid XML file: it does not close the `META` tag.

Why? Is this a bug? from `jsoup`? from java `org.w3c.dom`?

Discussion
- Thanks. The issue was that the default w3c output transformer was seeing a HTML tag and switching to HTML output mode. Resolved by setting output mode = XML.
- Actually, I'm rolling this back. The W3C DOM can be HTML or XML, so hard-coding it to XML doesn't make sense I don't think. I have added a method and helpers to W3CDom to select between HTML and XML mode, and document that if not specified, it will default to checking the document content.
