Title

Relation with NULL breaks Cassandra

Description
Query: SELECT ... WHERE key IN ( UUID, NULL )
Error: Invalid null value for partition key part key
Call stack: 
1. in project/vendor/yiisoft/yii2/yii/db/Command.php at line 414
2. in project/vendor/yiisoft/yii2/yii/db/Command.php –     yii\db\Command::queryInternal() at line 306
3. in project/vendor/yiisoft/yii2/yii/db/ActiveQuery.php –     yii\db\Command::queryAll() at line 103
4. in project/vendor/yiisoft/yii2/yii/db/ActiveRelation.php –  yii\db\ActiveQuery::all() at line 183
5. in project/vendor/yiisoft/yii2/yii/db/ActiveQuery.php –     yii\db\ActiveRelation::findWith() at line 286
6. in project/vendor/yiisoft/yii2/yii/db/ActiveQuery.php –     yii\db\ActiveQuery::populateRelations() at line 107
7. in project/app/controllers/SomeController.php –     yii\db\ActiveQuery::all() at line 113

In controller:

```
$arSomeModel = 
    SomeModel::find()
        ->with('obRelatedHasOne')
        ->where(array(
            'some_field' => $some_value
        ))
        ->all();
```

In SomeModel:

```
public function getObRelatedHasOne() {
    return $this->hasOne('SomeOtherModel',array('key'=>'other_model_uuid'));
}
```

SomeModel->other_model_uuid can be null by the nature of data, and so must be the related object.

Questions:
1) Where the array for IN() is formed, to filter it against NULL's ?
2) Is the 1) the best way to solve the problem ? How it should be solved, based on author's solid view of Yii2 DB architecture ?

I tried to catch reading null in my subclass cassandra\ActiveRecord::__get and return UUID of all zeroes, but to no avail.

P.S. In SQL, `WHERE field IN (NULL)` yields nothing, while `field IS NULL` does - NULL is not equal to anything, even to another NULL, and so can be safely purged from IN() array.
Discussion
- what is `$some_value` in your case? if it is an array it will create IN condition. If it is null it should generate correct SQL `somefield IS NULL`.
- @cebe No, problem is step deeper, then SomeModel array is in place and Yii2 starts to populate relation. `other_model_uuid` can be either UUID or NULL, so it makes query: `SELECT * FROM tbl_some_other_model WHERE key IN(UUID,NULL)`, and this crashes. I need to find way to either filter off the NULL from relation array, or return all-zeroes UUID.
