Title

routerLink type doesn't support null | undefined

Description
# 🐞 bug report

### Affected Package
@angular/router


### Is this a regression?

Yes, this code works with strictTemplates disabled.


### Description

The router link directive test the value with != null, and handles null & undefined as an empty relative route.  We use this when we want to change the fragment of the URL and stay on the same page.

``` A Link ```

This can be worked around by using:
``` A Link ```

But the code does support null and undefined, it's just the type that doesn't.
