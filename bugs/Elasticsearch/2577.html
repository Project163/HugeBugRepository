Title

Improve default format for date_nanos fields

Description
By default, `date_nanos` fields use the `strict_date_optional_time` format. Unfortunately `strict_date_optional_time` accepts and parses dates with nanosecond precision, but when it formats it drops the nanoseconds.

Some search options like `fields` and `docvalue_fields` use the field's format by default to format + return values. This leads to confusing behavior for `date_nanos` fields, where the values are missing nanosecond precision.

It would be good to update the default format for `date_nanos` fields to one that always preserves nanoseconds.

Example reproduction:
```
PUT index 
{
  "mappings": {
    "properties": {
      "@timestamp": {
... [Log Snipped] ...
  "fields": ["@timestamp"]
}
```
