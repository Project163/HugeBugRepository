Title

quoted strings in a JSON path should support ? characters

Description
I think this impacts all versions of Spark after   SPARK-18677  , which made the operator work at all in 2.1.0/2.0.3 

 I comes down to 
  
 
 name <-  '.'  ~>  "[^\\.\\[]+" .r |  "[ '"  ~>  "[^\\' \\?]+" .r <~  "']"  
  
  [URL]

   

 The regular expression/pattern is saying that we want a  [' followed by one or more characters that are not a single quote ' or a question mark ? followed by '] . That question mark looks out of place. When I try to put in a question mark in a quoted string it fails to produce any result, but when I put the same data/path into  [URL] I get a result 

   

 data 
  
 
{ "?" : "QUESTION" }  
  
 path 
  
 
$[ '?' ]  
  
   

 I also see no tests validating that a question mark is not allowed so I suspect that it is a long standing bug.
