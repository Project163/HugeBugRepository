Title

Missing boolean constraint

Description
**Describe the bug**
Creating the same table in two different databases, emits different sql.

When using a boolean constraint name, and a naming convention, the constraint is not emitted, the second time the table is created.

**Expected behavior**
Creating the same table in two different databases, should emit the same sql.

**To Reproduce**
```
py
#!/usr/bin/env python3
# SQLAlchemy==1.3.23
from sqlalchemy import create_engine
from sqlalchemy.ext.declarative import declarative_base
... [Log Snipped] ...
2021-03-05 17:13:49,506 INFO sqlalchemy.engine.base.Engine COMMIT
"""
```

**Versions.**
 - OS: 20.04.1 LTS (Focal Fossa)
 - Python: Python 3.8.5
 - SQLAlchemy: SQLAlchemy==1.3.23
 - Database: sqlite
 - DBAPI: default sqlite?
