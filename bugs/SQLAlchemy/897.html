Title

Missing NCHAR type mapping for colspec in cx_oracle dialect

Description
In order for the so-called blank-padded comparison semantics to work with parameter binding we had to monkey-patch SQLAlchemy as follows. 

```
from sqlalchemy.dialects.oracle import cx_oracle
from sqlalchemy.sql import sqltypes

class _OracleNChar(sqltypes.NCHAR):
    def get_dbapi_type(self, dbapi):
... [Log Snipped] ...
cx_oracle._OracleNChar = _OracleNChar
cx_oracle.dialect.colspecs[sqltypes.NCHAR] = _OracleNChar
```

We believe you may be missing a mapping for the Oracle's NCHAR type, which cx_Oracle DBAPI defines as FIXED_NCHAR. Corresponding mapping for the CHAR (cx_Oracle.FIXED_CHAR) does exist in SQLAlchemy (sqltypes._OracleChar).
