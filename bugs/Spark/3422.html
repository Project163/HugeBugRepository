Title

Oracle FLOAT datatype is not properly handled when reading via JDBC

Description
When trying to read in a table from Oracle and saveAsParquet, an IllegalArgumentException is thrown when a column of FLOAT datatype is encountered. 

 Below is the code being run: 
  
 val jdbcDF = sqlContext.read.format( "jdbc" ).options(
  Map( "url"  -> jdbcConnectionString,
           "dbtable"  ->  "(select someFloat from someTable)" ,
           "fetchSize"  -> fetchSize)).load()

  jdbcDF.saveAsParquetFile(destinationDirectory + table)
 
  

 Here is the exception: 
  
 java.lang.IllegalArgumentException: Unsupported dataType: { "type" : "struct" , "fields" :[{ "name" : "someFloat" , "type" : "decimal(38,-127)" , "nullable" : true , "metadata" :{ "name" : "someFloat" }}]}, [1.1] failure: `TimestampType ' expected but `{'  found
 
  

 From the exception it was clear that the FLOAT datatype was presenting itself as scale -127 which appears to be the problem.
Discussion
- User 'poolis' has created a pull request for this issue: 
 [URL]
- With pyspark this Oracle FLOAT-error appears with exception  
  
 ValueError: (ValueError(u'Could not parse datatype: decimal(38,-127)',)
 
  

 Workaround: in Oracle query, cast FLOAT to NUMBER if precision and scale can be set so that all data can be included. If not, convert FLOATs with TO_CHAR and change type later, eg. 
  
 sql = "(SELECT TO_CHAR(float_column) AS FLOAT_COLUMN FROM some_table)"
df = sc.read.format('jdbc').options(.. table=sql)

df = df.withColumn("FLOAT_COLUMN", df["FLOAT_COLUMN"].cast("float"))
