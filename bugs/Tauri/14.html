Title

"Maximum call stack size exceeded" occur tauri but not in `Boscop/web-view`

Description
**Describe the bug**
A wasm page created by yew.  The page will be blank until right click + Reload.  Following is the Console message after the first open.  
```
wasm-bindgen: imported JS function that was not marked as `catch` threw an error: – "Maximum call stack size exceeded.↵↵Stack:↵get@[URL]

wasm-bindgen: imported JS function that was not marked as `catch` threw an error: – "Maximum call stack size exceeded.↵↵Stack:↵get@[URL]
```

After Reload the page works and no error message showed in Console.

The save page can be opened by raw `Boscop/web-view` Firefox/Safari without any problem.

I think it's tauri's bug.
