Title

Stubgen: Wrong placement of decorators for methods with instance field declarations

Description
Consider the following snippet:

```
python
class A:
    @property
    def x(self):
        self.y = 'y'
... [Log Snipped] ...
    def x(self, value):
        self.y = 'y'
```

The stub generated via `stubgen` contains:

```
python

# Stubs for tests.m (Python 3.6)
#
# NOTE: This dynamically typed stub was automatically generated by stubgen.
... [Log Snipped] ...
    y: str = ...
    def x(self, value: Any) -> None: ...
```

Notice the instance field type declarations are being placed between the decorator and the function declaration lines.

I can reproduce this issue using the latest `mypy` installed from the `master` branch:
```sh
$ pip show mypy | grep Version
Version: 0.650+dev. 
```
