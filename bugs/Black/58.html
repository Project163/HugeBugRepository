Title

Allow .git to be an ordinary file, as well as a directory.

Description
With git, the .git object need not be a directory. It can also be a suitable ordinary file. For me, git works fine with the following:

```sh
$ cat .git
gitdir: /home/jfine/.gitrepos/scratch.git/
```
However, black uses the code
```python
        if (directory / ".git").is_dir():
            return directory
```
(See [URL]

This problem is particularly important when git worktrees are used. (Because git allows .git to be a suitable ordinary file, I regard it as a bug rather than feature, that black doesn't recognise this.)

By they way, there's a great deal I like about black. I've been reading the source, because I want find a configuration file in a similar way. Hence my discovery of the above.
