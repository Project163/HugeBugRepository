Title

ActiveRecord joinWith bug

Description
reproduce code example:

$query = User::find();
$query->joinWith('profile');
$total = $query->count();
$users = $query->all(); // would produce SQLSTATE[42000]: Syntax error or access violation: 1066 Not unique table/alias: 'profile'

It means that i can't invoke count() and all() methods on the same query instance. It would join twice after call either one of these methods.
