Title

Table creation fails if CREATE TABLE has both PK and unique constraints

Description
In create table command if primary key is specified using constraint keyword like below then PostgreSQL throws error.
```
CREATE TABLE "SOE"."public"."PRODUCT_DESCRIPTIONS"("PRODUCT_ID" INT4, "LANGUAGE_ID" VARCHAR(3), "TRANSLATED_NAME" VARCHAR(50) NOT NULL, "TRANSLATED_DESCRIPTION" VARCHAR(2000) NOT NULL, CONSTRAINT "PRODUCT_DESCRIPTIONS_PK" PRIMARY KEY("PRODUCT_ID", "LANGUAGE_ID"), CONSTRAINT "PRD_DESC_PK" UNIQUE("PRODUCT_ID", "LANGUAGE_ID"))
```

The error is

Discussion
- This seems to happen specifically when there are multiple constraints specified in the query:
`CONSTRAINT "PRODUCT_DESCRIPTIONS_PK" PRIMARY KEY("PRODUCT_ID", "LANGUAGE_ID"), CONSTRAINT "PRD_DESC_PK" UNIQUE("PRODUCT_ID", "LANGUAGE_ID"))`
