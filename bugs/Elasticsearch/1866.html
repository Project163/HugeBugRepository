Title

Terms filter doesn't understand _id

Description
A `terms` query can query the `_id` field, as can a `term` filter, but not a `terms` filter:

```
curl -XPUT '[URL] 
curl -XPUT '[URL]  -d '
{
   "foo" : "bar"
}
... [Log Snipped] ...
}
'
```

`terms` query works:

```
curl -XGET '[URL]  -d '
{
   "query" : {
      "terms" : {
         "_id" : [
... [Log Snipped] ...
#    "took" : 0
# }
```

`terms` filter doesn't work:

```
curl -XGET '[URL]  -d '
{
   "query" : {
      "constant_score" : {
         "filter" : {
... [Log Snipped] ...
#    "took" : 1
# }
```

`term` filter works:

```
curl -XGET '[URL]  -d '
{
   "query" : {
      "constant_score" : {
         "filter" : {
... [Log Snipped] ...
#    "took" : 1
# }
```
