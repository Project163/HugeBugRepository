Discussion
- This is actually a bug in the proxy generator. It can be reproduces outside of the context of traits with this code: 

  
  interface  DoStuff {
}
 class  Foo {
   void foo( double  a,  int  b) {}
}

def gp= new  Foo() as DoStuff
 
  

 In any case, runtime traits will generate a proxy, meaning that even if I fix (and I will) this bug, the code won't work as is, because the assignment will fail. See  [URL] for a detailed explanation.
