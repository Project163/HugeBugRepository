Title

[ROCm] PyTorch TunableOps results in Memory Access Fault

Description
### 🐛 Describe the bug

We are seeing a Memory Access Fault by GPU Node error when running the below script `run.py` with PyTorch TunableOps enabled. All the testing was done on systems with 8xMI300X GPUs with ROCm 6.2.1 and the latest compatible GPU firmware. Running the script without TunableOps enabled works.

Error message:
```
Memory access fault by GPU node-2 (Agent handle:  ) on address  . Reason: Unknown.
```
The specific GPU node number changes, and this was reproduced on multiple systems.

Steps to reproduce:
```
pip install -r requirements.txt
PYTORCH_TUNABLEOP_ENABLED=1  python3 run.py
```

`run.py`:
```
#!/usr/bin/env python
from __future__ import annotations

import argparse
import functools
... [Log Snipped] ...
if __name__ == "__main__":
    main()
```

`requirements.txt`:
```
filelock==3.13.1
fsspec==2024.2.0
Jinja2==3.1.3
MarkupSafe==2.1.5
mpmath==1.3.0
... [Log Snipped] ...
torchvision==0.19.1+rocm6.1
typing_extensions==4.9.0
```

### Versions
