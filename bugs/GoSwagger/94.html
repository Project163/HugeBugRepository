Title

Description

I believe there is a regression in release `0.7.4`, specifically 51aca22.  When parameter names include brackets (`var[]`) the generator fails to sanitize the variable names.

NOTE: the expected URL params would be `/foo?groups[]=bar&groups[]=baz`
