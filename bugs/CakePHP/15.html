Just so I understand the problem better, you're connecting via SSL to the proxy as well as the destination server?
- 4th Apr 2013, **Wataru Hirayama** said:

---

Not exactly.

The current implementation of {Http|Cake}Socket for https destination+http proxy is, make ssl connection to the proxy server, then send GET or POST request over the encrypted connection. Most proxy servers(like squid or apache mod_proxy) can't handle it.

The practical way to handle https destination+http proxy is:
1. connect http(not encrypted) connection to the proxy server.
2. send CONNECT request to start ssl tunneling.
3. change the connection to encrypted mode.
4. send normal proxy request (GET or POST).

Please refer to ZendFramework/library/Zend/Http/Client/Adapter/Proxy.php
