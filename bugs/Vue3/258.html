Title

select option value attribute is not set if value is equal to text

Description
### Version
3.2.22

### Reproduction link
[Link: sfc.vuejs.org/]







### Steps to reproduce
Inspect the select options and see that the option with `value === textContent` has no value set. 

### What is expected?
Regardless of the textContent I expected an option to correctly have the value attribute and not silently remove it.

### What is actually happening?
The value attribute is removed.

---
I have verified that this is not happening in vue2. [Link: Reproduction link]

If I'm missing some part of the [Link: option spec] please point me to it. But as far as I am seeing it it is perfectly valid to have an option with value = textContent and I our case needed for e2e testing frameworks like Selenium to select a predefined value.

1. We *first* set the options textContent before the value property
