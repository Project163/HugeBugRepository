Title

LocalTime without seconds is incorrectly serialized to SQL as a value literal

Description
When creating a literal from a LocalTime object without seconds, like LocalTime.of(12, 12), the serialisable string form of the value literal is serialized into invalid SQL expression, in this case TIME '12:12' instead of TIME '12:12:00', resulting in:  
  
 
org.apache.flink.table.api.ValidationException: SQL validation failed: Illegal TIME literal  '12:12' : not in format  'HH:mm:ss'  
  
 This also affects LocalDateTime objects used in the same way: 
  
 
org.apache.flink.table.api.ValidationException: SQL validation failed: Illegal TIMESTAMP literal  '2024-02-03 12:12' : not in format  'yyyy-MM-dd HH:mm:ss'
