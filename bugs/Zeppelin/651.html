Title

Add info level logging when installing node modules and bundling

Description
Add info level logging when installing node modules and bundling helium packages.  

 Because your doesn't get noticed during 30secs ~ few minutes at all. This is usually case if you have multiple enabled helium packages.  

 User might think that Zeppelin hangs or there is other problem If there is no log message.
