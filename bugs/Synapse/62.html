Title

POJOCommand mediator should set the properties back to the message after the execution

Description
POJOCommand mediator only set the properties to the Command object before starting the execution. We should support setting the properties back to the message from the command after execution.
Discussion
- Fixed on the SVN trunk, and now the properties has an optional attribute to specify the action as  [action="get|set"]  defaults to  [action="set"]  

 I will be adding a sample on this soon, and already updated the test cases to check these changes as well.
