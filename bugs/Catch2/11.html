Title

[Reporter] compact reporter misses parentheses for REQUIRE_FALSE() report

Description
In a report of the compact reporter (`--reporter compact`):
```
REQUIRE_FALSE( x != x );
```
yields
```
passed: !x != x for: !(1 != 1)
---------^-----^
```

instead of
```
passed: !(x != x) for: !(1 != 1)
---------^------^
```
I'll create a PR to correct this later.
Discussion
- @horenmar It appears the effect follows from `AssertionResult::getExpression()` in [Link: `internal/catch_assertionresult.cpp(58)`] and [Link: dates from 5 years ago].

`getExpression()` is used in:
- [Link: `catch_reporter_compact.hpp(202)`]
- [Link: `catch_reporter_tap.hpp(180)`]
- [Link: `catch_reporter_xml.cpp(124)`]

? Would it be ok for all reporters to change
```
return '!' + std::string(m_info.capturedExpression);
```
in
```
return "!(" + std::string(m_info.capturedExpression) + ")";
```
c.f. AssertionResult::getExpressionInMacro() at [Link: line 63].
- Yep - that all seems reasonable. I've applied the fix to both 1.x and Catch2 branches - thanks for that!
