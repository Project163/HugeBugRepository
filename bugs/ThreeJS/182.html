Title

TransformControls: Transformation problem with child objects

Description
##### Description of the problem

When an object that have some child objects on scene tree is rotated, the child objects get some malfunction with the TransformControls. In worldSpace cordinate system, there is a difference between the direction of operation and the direction of movement.
And the speed of movement of an object is proportional to the scale of its parents, not to its own scale.
