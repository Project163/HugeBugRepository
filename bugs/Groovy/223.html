Title

no source and line number is shown in exceptions thrown from inside a script

Description
consider the script: 

 throw new Exception("foo") 

 the stack trace should show  the line number and script name of the script which has thrown this exception. Instead the trace shows something like "unknown source"
Discussion
- maybe the reason for this issue was a forgotten line when changing to Asm 2.x. The line number table was there, but the source file attribute was missing. Both parts are requiered to show good traces. I added a source file attribute and that fixed it. Folks we have line numbers back!
