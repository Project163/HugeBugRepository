Title

The Nimbus storm-local directory is relative to the working directory of the shell executing "storm nimbus"

Description
When the storm.local.dir property is set to a relative directory, it should be interpreted as relative to STORM_HOME. This is how it works for "storm supervisor". For "storm nimbus" it is instead relative to the working directory of the shell, so running "storm nimbus" from STORM_HOME/bin will put a storm-local directory in STORM_HOME/bin/storm-local.
