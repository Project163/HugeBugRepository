Title

Test root node type is not reported correctly

Description
The test root used in the jcr tests is created as  nt:unstructured  but calling  testRootNode.getDefinition().getDeclaringNodeType().getName()  will wrongfully return  rep:root  (the node type of the repository root) 

 This also influences the   OAK-900   tests, namely the  ReorderTest  which will throw an  NotExecutableException  on account of the wrong node type. 

 I'll shortly add a test.
Discussion
- Test (ignored) in with  [URL]
- For clarification we have: 

  
 [rep:root] > nt:unstructured
  + jcr:system (rep:system) = rep:system mandatory IGNORE
 
  

 What should  getDeclaringNodeType()  on a child node of the root return? AFAIK Oak returns  rep:root  and Jackrabbit 2 returns  nt:unstructured . Both seems correct to me and the specification seems to be silent on declaring node types under inheritance. For the sake of backward compatibility we should probably change this in Oak.
