Description

 I've just stumbled upon a problem with Groovy 1.5 which was already solved in some previous betas... It's about overriding the asType method on the ArrayList. 

 Doing something like this:

 ArrayList.metaClass.initialize() 

 then 

  [1,2,3]  as /* any class here */ 
or

 does not invoke the closure code... 

 Using emc stuff and asType method with other classes works so far as I can say....
