Title

Html::img() + Data URI's

Description
The issue is that currently with the Html::img() method if you pass a Data URI, for an image for example

```
data:image/jpg;base64*
```

The src attribute for the image gets returned as 

```
/data:image/jpg;base64*
```

which breaks the image, as a quick fix I changed the img method to look like the following.

BaseHTML::img()

```
public static function img($src, $options = [], $dataURI = null)
    {
        if ($dataURI) {
            $options['src'] = $src;
        } else {
... [Log Snipped] ...
        return static::tag('img', '', $options);
    }
```

Obviously I would say the better fix would be to change the BaseURL::to() method to not add a beginning slash if it is a data URI, through like regex_matches or something, but that might be kinda slow, for every BaseURL::to() call.
