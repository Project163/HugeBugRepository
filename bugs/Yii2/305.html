Title

Formatter crashes with fatal error on invalid date.

Description
We should find a better solution for values like this, maybe strtotime() will work.
Discussion
- Since `strtotime` only supports dates between years 1970 and 2038, we must use `DateTime` instead which supports all date values.

With PHP 5.3, the [Link: DateTime construct] throws an exception when an invalid time parameter is passed. This should be captured with `try/catch` probably.
- This applies only to 32-bit systems, in 64-bit system `date('Y-m-d', strtotime('2123-11-02')) === '2123-11-02'`
