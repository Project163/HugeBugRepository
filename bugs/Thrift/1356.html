Title

C++ library unit tests don't compile against the new boost-1.59 unit test framework

Description
BOOST_MESSAGE was deprecated in the past and has finally been removed (tried boost-1.59, possibly removed in an earlier release, but it all works in boost-1.54).  Some of the C++ library unit test code uses BOOST_MESSAGE so it won't compile any more.  In addition, the method to make a test has changed slightly and needs version specific code to handle both old and new.
