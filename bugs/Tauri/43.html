Title

Can't build AppImage without deb

Description
**Describe the bug**
I want to build an AppImage, but I'm not interested in building a .deb file.

**To Reproduce**
- Set tauri.bundle.targets to any **array** excluding `deb`—for example, `["osx", "msi", "appimage", "dmg"]`
- Delete `target/release/bundle`
- Bundle the app (I'm using vue-cli-plugin-tauri, so `yarn tauri:build`)
- Observe the following failure: ``error: Shell Scripting Error:`error running appimage.sh` ``

**Expected behavior**
The build succeeds

**Platform and Versions (please complete the following information):**
 
Operating System - Linux(5.8.10-arch1-1) - linux/x64

Node.js environment
  Node.js - 14.12.0
  tauri.js - 0.12.0

Rust environment
  rustc - 1.48.0-nightly
  cargo - 1.48.0-nightly
  tauri-bundler - 0.9.3

Global packages
  NPM - 6.14.7
  yarn - 1.22.5

**Additional context**
Total guess, but here's my thoughts:
The build process for an AppImage requires a deb to be built. So, it should automatically add a deb target if an AppImage is to be produced. *However*, that logic only occurs when a string is passed into the `targets` property, and not an array. So, this logic should be also extend to passing in an array.
