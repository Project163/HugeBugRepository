Title

tvec2 allows implicit conversion from another tvec2 type.

Description
I just discovered a lot of errors in our code when including an older glm version ( ). We had accidentally implicitly converted vec2 to ivec2 and vice versa when calling some of our functions. With the current glm version ( ), no errors or warnings were produced, which in my opinion is bad.

The reason for this problem is the fix for issue #159 ([Link: commit]). I don't think the construction of a tvec2 from another type of tvec2 should be implicit. It is more inconvenient than convenient, since it can lead to many errors in the user's code. I suggest that this constructor is made explicit again. I also see that the only type that has this constructor not marked as explicit is the tvec2, which is inconsistent.
