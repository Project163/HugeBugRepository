Title

"glm::decompose()" is using float-type instead of templated-type

Description

- "float root, trace = Row[0].x + Row[1].y + Row[2].z;"

(line 156 of "glm\gtx\matrix_decompose.inl" in latest version, last changed 7 August 2018 - commit  )
