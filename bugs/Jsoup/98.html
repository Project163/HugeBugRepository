Title

Pretty print of ``` ``` in html causes extra lines to be added on each subsequent pretty print

Description
Take [URL] and add  doSomething();  to the file as a test.  Run the formatting over and over, watch it keep adding extra empty lines every time it encounters a script block with content.  I've been looking into this but have yet to find where this problem is coming from.  Any pointers to help debug and/or suggest where this might be fixed would be greatly appreciated.  This is pretty print and makes it hard to use formatter-maven-plugin to format when this is encountered.  Issues are present in latest master even though we are still using the older releases at the moment.
Discussion

- @damienhunter30 This is a different issue.  A script tag with content in it triggers a new line.  So each time the file is reformatted, it gets another new line.  So this continues to grow out of control.  Issue #1689 simply is extra space being left at end of various lines (and always a tag ending >).  In that case there is only ever one there, it doesn't add more extra spaces, just leaves them on lines that they exist instead of properly trimming.
