Title

gRPC cannot inject async and ListenableFuture-style client stubs but does not fail during build

Description
The docs is clear that quarkus gRPC can only inject _blocking_ stubs and _reactive_ stubs based on Mutiny. However, if a user attempts to inject an _async_ stub the app fails with `java.lang.NoSuchMethodError` at runtime because the generated synthetic bean implements `Contextual.create(CreationalContext )` incorrectly.

I think that we should either support all types of stubs or detect a wrong injection and fail the build.
Discussion
- We should be text the wrong types and fail at startup.
