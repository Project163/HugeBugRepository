Discussion
- I have seen this in another package recently:
~~~
install(...
    INCLUDES DESTINATION "${concurrencpp_include_directory}"
    COMPONENT concurrencpp_Development
...
~~~~
COMPONENT can't be used after INCLUDES (as nothing is installed, only added to target properties).
[URL]

Maybe another case for post-build checks.
