Title

Broken pipe (Write failed) using Hibernate ORM and MariaDB

Description
Using ```quarkus-hibernate-orm``` along with ```quarkus-jdbc-mariadb``` with the following application.properties doesn't always work after the application been idle for a few hours. After the application been idling during the night the first few transaction fails (see stacktrace). Could it be that stale connections doesn't get evicted from the connection pool properly? 

(Quarkus version 0.14.0, MariaDB 10.2.15, MacOS Mojave and OpenJDK Runtime Environment 18.9 build 11+28)

```
quarkus.datasource.url=jdbc:mariadb://some-url...
quarkus.datasource.driver=org.mariadb.jdbc.Driver
quarkus.hibernate-orm.dialect=org.hibernate.dialect.MariaDB102Dialect
quarkus.datasource.background-validation-interval=PT1M
quarkus.datasource.idle-removal-interval=PT1M
quarkus.datasource.username=someUserName
quarkus.datasource.password=somePwd
```
