Title

`:mkspell` regression

Description
### Problem

Latest versions of neovim cannot generate accurate .spl files for the greek language. I have tested many different dictionaries and they all seem to fail. Vim on the other hand can generate those spellfiles correctly.

### Steps to reproduce

Below is a Makefile that downloads the required dictionary files and executes `:mkspell` on them. Neovim will produce unusable .spl file without any word inside.
```
Makefile
NVIM=nvim

all: el2.utf-8.spl
.PHONY: all clear clean
... [Log Snipped] ...
clean:
	rm el.utf-8.{spl,sug}
```

After `make` i get this output:
```
Reading affix file el_GR.aff...
Reading dictionary file el_GR.dic...
Compressing word tree...
Writing spell file el2.utf-8.spl...
Done!
Estimated runtime memory use: 0 bytes
Reading back spell file...
Performing soundfolding...
```
as you can see with `:spelldump` the file is completely empty.

`nvim --clean -c 'set spelllang=el2.utf-8.spl spell' -c 'spelldump'`

### Expected behavior

`make el.utf-8.spl` uses vim:
```
Reading affix file el_GR.aff...
Reading dictionary file el_GR.dic...
line      2, word      0 - ...line 660068, word 660066 - ...Compressing word tree...
Compressed case-folded: 6308160 of 6820007 nodes; 511847 (7%) remaining
Writing spell file el.utf-8.spl...
... [Log Snipped] ...
Writing suggestion file el.utf-8.sug...
Estimated runtime memory use: 5065814 bytes
```

Both the .spl and .sug files are generated correctly, and `nvim --clean -c 'set spelllang=el.utf-8.spl spell' -c 'spelldump'` shows the full wordlist

### Neovim version (nvim -v)

NVIM v0.10.0-dev-386+ga6dd67f5b

### Vim (not Nvim) behaves the same?

no, vim 9.0.1572

### Operating system/version

archlinux

### Terminal name/version

kitty 0.28.1

### $TERM environment variable

xterm-kitty

### Installation

build from latest master
