Title

Client SSL Cache Timeout default is specified in milliseconds rather than seconds

Description
The Client SSL Cache Timeout default is specified in milliseconds rather than seconds. This means that rather than 24 hours it is currently 1000 days. This should be set to 24 hours instead + documented that it is in seconds, rather than milliseconds.
