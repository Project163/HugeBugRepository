Title

Clarify distinction between `deployUrl` and `baseUrl`

Description
# 📚 Docs or angular.io bug report

## Description

In [URL] we've noticed some users confuse `deployUrl` and `baseUrl`. The former is a compile-time value while the later is for run-time. This might be useful to talk about in our deployment docs to help users identify the right tool for the job. We already seem to have a section on `baseUrl`, maybe we could add some information on `deployUrl` and when you would want one over the other?

/cc @clydin for additional context.
