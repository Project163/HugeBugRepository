Title

wrapper_clang should be compiled with DEVELOPER_DIR in the environment

Description
### Description of the problem / feature request:

`wrapper_clang` should pass `DEVELOPER_DIR` to `xcrun` invocation. Without this, `xcode-select` needs to be set globally, which impacts multiple workspaces.

[URL]

When using `DEVELOPER_DIR` as an `--action_env` to set the Xcode version to compile with, the current behavior results in cache misses that involve `wrapper_clang`, since different versions of Xcode could have been used to compile it.
### Bugs: what's the simplest, easiest way to reproduce this bug? Please provide a minimal example if possible.

`wrapper_clang` being compiled with the correct version of Xcode, based on --action_env=DEVELOPER_DIR`.

### What operating system are you running Bazel on?

macOS 10.15.5

release 3.3.0
