Title

bin/plugin -u url fails silently

Description
When installing a plugin using `-u` ( `--url`) option, it fails silently when you don't provide `-i` (`--install`)  option:

``` sh
$ bin/plugin -u [URL]
$ bin/plugin -l
Installed plugins:
    - No plugin detected in elasticsearch/plugins
```

With `-i`:

```
sh
$ bin/plugin -u [URL] -i rssriver
-> Installing rssriver...
Trying [URL]
Downloading ......................................DONE
... [Log Snipped] ...
Installed plugins:
    - rssriver
```
