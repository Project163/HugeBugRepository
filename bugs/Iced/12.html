### What happened?

When running an iced application on Fedora Asahi Remix 40 using GNOME 46.4, two windows are opened.  The application window as intended, and a second, invisible window.  The second window is only apparent via the application switcher:
 
[Image: Screenshot from 2024-08-28 09-33-04]

The invisible window is named "winit window" in the application switcher, and closes when the application closes.  It does not interfere with the application as far as I can tell, only with the expected operation of the application switcher.

This happens with every iced example program I've tested.  When running the wgpu and winit example programs (`hello_triangle` and `window`, respectively), only one window is launched.

### What is the expected behavior?

Only the application window is opened when it is run.
