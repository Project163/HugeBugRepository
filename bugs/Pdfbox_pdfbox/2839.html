Title

PDFBox 3.0 OSGi bundle requires sun.java2d.cmm.kcms package

Description
We consume PDFBox in the Apache Sling project and recently attempted to upgrade to 3.0.0 . Sling uses OSGi and a new required import appeared in the 3.0.0 bundles: sun.java2d.cmm.kcms .  Our PR is at  [URL] . 

 This prevents us from on applying the update. I looked at the desired usage for kcms and it seems like it is an optional feature. 

 I suspect this addition was triggered by a version update of the maven-bundle-plugin, which added support for transforming "Class.forName" calls as OSGi package imports -  [URL] . 

 I would suggest that this import is removed by disabling the specified bnd instruction.
