Title

QueryStringDecoder constructor taking in URI is broken

Description
The QueryStringDecoder in v3.3.1.Final that takes in a URI does not return correct parameters for a full URI.

Input: [URL]
using constructor,
QueryStringDecoder decoder = new QueryStringDecoder(URI.create("[URL]

Output: 
[URL] -> value1
param2 -> value2
param3 -> value3

It seems that QueryStringDecoder.hasPath is set to false, when using the URI constructor.
