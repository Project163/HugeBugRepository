Title

Python TProcessPoolServer does not spawn expected number of worker processes

Description
When using Python TProcessPoolServer with more than 1 workers, only one worker process will be successfully spawned and all the other processes will reach a pickling error and exit. As a result, with the default settings, only one worker process is processing requests, whereas 10 workers are expected.
