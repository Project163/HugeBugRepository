Title

[bug] Maximizable, Minimizable and Closable config not working on Windows

Description
### Describe the bug

```
"windows": [
      {
        "title": "App Name",
        "label": "main",
        "fullscreen": false,
... [Log Snipped] ...
      }
    ],
```

The above setting don't seem to be disabling minimize, maximize and close buttons in V2 on Windows 11.

### Reproduction

Create a new tauri v2 app using create tauri app. And apply the settings as shown in the description.

Here is my cargo toml:

```
toml
[package]
name = "app
version = "0.0.0"
description = "description"
... [Log Snipped] ...
serde = { version = "1", features = ["derive"] }
serde_json = "1"
```

and main.rs

```
rs
// Prevents additional console window on Windows in release, DO NOT REMOVE!!
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

// Learn more about Tauri commands at [URL]
... [Log Snipped] ...
        .expect("error while running tauri application");
}
```

### Expected behavior

The maximize, minimize and close buttons should be disabled.
