Title

Problem formatting milliseconds using i18nFormat

Description
### Description

I am facing similar problem to [URL] when formatting using the function `i18nFormat`

This line [URL] could be changed to `return (string)static::$formatters[$key]->format($date->format('U.u'));` to allow microseconds when formatting. This should not be a breaking change, since the date us already formatted again within the same line, but I am not sure if this could cause any new problem. 

This is a quick test:

```
$time = new FrozenTime('2014-07-06T13:09:01.523000+00:00');
$this->assertEquals('2014-07-06 13:09:01.523000', $time->format('Y-m-d H:i:s.u'));
$i18nFormat = $time->i18nFormat("yyyy-MM-dd'T'HH':'mm':'ss.SSSxxx", null, 'en-US');
$this->assertEquals('2014-07-06T13:09:01.523+00:00', $i18nFormat); // this will fail returning 2014-07-06T13:09:01.000+00:00
```

This is hapening in many different cakephp versions including 4.x and 5.x and it is independent from php version used


### CakePHP Version

4.4.0
