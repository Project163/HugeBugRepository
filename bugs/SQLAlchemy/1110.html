Title

Infinite recursion with mutually auto-loaded relationships

Description
**Describe the bug**
Upgrading to 1.4.6 from 1.3.24 broke our test cases with an infinite recursion error. The cause is some bad legacy code we had going on where a child and parent both automatically load each other. The parent joined loads the child and the child subquery loads the parent. Regardless this is bad code in our use case and we will fix it so we're not blocked on upgrading because of this change. I'd be highly suspicious of any code that hit this bug but, it looks like a bug all the same. 

**Expected behavior**
Accessing sqlalchemy model attribute should not crash

**To Reproduce**
```
py
from sqlalchemy import Column, ForeignKey, Integer, create_engine
from sqlalchemy.orm import declarative_base, relationship, sessionmaker

Base = declarative_base()
... [Log Snipped] ...

widget.id  # Infinite Recursion happens here
```
