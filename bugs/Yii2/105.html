Title

yii2-authclient error openid

Description
Howdy.. 
Was testing YII2 with the advanced application and yii2-authclient. 
When authenticating with google on the return, in the pop up window I get "Unable to complete the authentication because the required data was not received" Error #400.

I believe CSRF need to be disabled for this action in some fashion, but couldn't find any information on the yii2-authclient project for this. 

I read on another page: You can enable/disable CSRF validation per controller/action by setting Controller::enableCsrfValidation in beforeAction or through some behavior.

So I added this to test:
public function beforeAction($event)
{
$this->enableCsrfValidation = false;
return true;
}

But this didn't seem to work. I am very new to Yii, so I admit, I could be doing something wrong, but it makes sense that the CSRF is causing my issue.. and everything else works great. 

Thanks
