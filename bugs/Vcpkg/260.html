Title

X_VCPKG_APPLOCAL_DEPS_INSTALL=ON fails if object libraries are installed

Description
Consider a project that installs object libraries. For example, Qt does this for its examples asset library.

```
add_library(ExampleIconsPrivate_resources_1 OBJECT  ...)
...
install(TARGETS ExampleIconsPrivate_resources_1 ...)
```

Configure such a project with `X_VCPKG_APPLOCAL_DEPS_INSTALL=ON`. This fails with:

```
CMake Error:
  Error evaluating generator expression:

    $ 

  Target "ExampleIconsPrivate_resources_1" is not an executable or library.
```

This is triggered in `x_vcpkg_install_local_dependencies`:
```
foreach(target IN LISTS arg_TARGETS)
            get_target_property(target_type "${target}" TYPE)
            if(NOT target_type STREQUAL "INTERFACE_LIBRARY")
                install(CODE "message(\"-- Installing app dependencies for ${target}...\")
                    execute_process(COMMAND \"${Z_VCPKG_POWERSHELL_PATH}\" -noprofile -executionpolicy Bypass -file \"${Z_VCPKG_TOOLCHAIN_DIR}/msbuild/applocal.ps1\"
... [Log Snipped] ...
            endif()
        endforeach()
```

The code above excludes interface libraries, but it must exclude object libraries too.
