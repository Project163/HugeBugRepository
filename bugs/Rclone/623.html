Title

--max-duration flag is not respected

Description
#### What is the problem you are having with rclone?
rclone continue to start new transfers even after transfer time limit defined by --max-duration flag is reached.

The test session (log attached) was started at 15:03h and deadline set to 16:03h as per the log: "Transfer session deadline: 2020/08/12 16:03:47".

But even after 16:03h, new transfers are started and completed.

According to log, new sessions were started automatically with new deadlines:
`2020/08/12 16:18:12 INFO  : One drive root 'emuisos/psp': Transfer session deadline: 2020/08/12 17:18:12`
2020/08/12 17:32:36 INFO  : One drive root 'emuisos/psp': Transfer session deadline: 2020/08/12 18:32:36

The session ended only 18:47h apparently due to some errors


#### What is your rclone version (output from `rclone version`)

rclone v1.52.3-298-g770a6f2c-beta
- os/arch: windows/amd64
- go version: go1.15

#### Which OS you are using and how many bits (eg Windows 7, 64 bit)
Windows 10


####  Which cloud storage system are you using? (eg Google Drive)
OneDrive


#### The command you were trying to run (eg `rclone copy /tmp remote:tmp`)

`rclone copy -vv --max-duration 1h --log-file log.txt H:\isos\psp OneDrive-luizamericop:emuisos/psp`

Config:
```
[OneDrive-luizamericop]
type = onedrive
token = {"access_token":"xxx"}
drive_id = yyyy
drive_type = personal
```
