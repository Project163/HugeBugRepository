Title

Decimal should have lower precedence than double in type hierachy

Description
Currently its other way round. Also, decimal should be lower than float.
Discussion
- Both  sql server  and  Oracle  treats decimal lower than double/float
- I think this came to discussion in the past, and was bounced back because of b/c concerns. In essence, decimal is an exact type, while double/float is not. When an exact type operates with a non-exact type, the result is non-exact. Along this line, we should also revisit the case of other exact types (int, long, etc) operating with double/float.
