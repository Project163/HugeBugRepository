Discussion
- @tjgq @coeuvre We have reports from multiple users about these kinds of hangs. They seem to be caused by `--remote_cache_async`. In this particular case, it looks like the RemoteExecutionService is waiting on the `Phaser` even though no uploads are running anymore.
- A fix for this issue has been included in [Link: Bazel 8.1.0 RC4]. Please test out the release candidate and report any issues as soon as possible.
