Title

P->RGBA->resize(LANCZOS)->P messes up transparency

Description
### What did you do?
Given original image [Image: test.png]
and following steps:

```python
from PIL import Image
im = Image.open('test.png')
im.mode # 'P'
im = im.convert('RGBA')
im = im.resize((320,240), Image.LANCZOS)
im = im.convert('P')
im.save('broken.png')
```
### What did you expect to happen?
[Image: good]

### What actually happened?
[Image: bad]

### What versions of Pillow and Python are you using?
Python 2.7.13 / Pillow 4.2.1


However, if I slightly change the script and save RGBA image after convertion and resize to a file and then reopen that file, quantize it to palette, then it's all good:
```
python

im = im.convert('RGBA')
```
