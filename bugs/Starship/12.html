Title

Jobs module in bash always returns 1

Description
#### Current Behavior

Jobs module always returns nothing or `1`:

```
:) ~$ sleep 1000 &
[1] 15998
:) ~[1]$ sleep 1000 &
[2] 16022
:) ~[1]$
```
 

#### Expected Behavior

Jobs module returns the number of jobs. (In the above example, "2" in the last line.)
