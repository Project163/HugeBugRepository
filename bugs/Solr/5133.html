Title

Fix cloud.sh to ignore -slim.tgz

Description
The change that brought us -slim.tgz seems to have broken cloud.sh, because cloud.sh was relying on a single file matching with 'solr-*.tgz' existing in the packaging/build/distributions directory 

 The forthcoming patch will fix this by ignoring -slim.tgz 

 If someone wants to use cloud.sh to test with -slim we can add an option to do that later.
