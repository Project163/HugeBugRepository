Title

2.0.0: tests fail without tox

Description
### Steps to reproduce
1. `tox -e py36`
2.  `. .tox/py36/bin/activate`
3.  `python -m pytest pylint/test`

### Current behavior
1. all tests pass
2. activated
3. 2 tests fail

### Expected behavior
1. all tests pass
2. actiavted
3. all tests pass

### pylint --version output
```
pylint 2.0.0.dev
astroid 2.0.0.dev
Python 3.6.5 (default, Mar 29 2018, 18:20:46) 
[GCC 8.0.1 20180317 (Red Hat 8.0.1-0.19)]
```

### Why is this important

In Fedora, we need to check pylint works when installed into system, not in an isolated environment such as with tox. See the tracebacks from given reproducer:

```
=================================== FAILURES ===================================
______________________________ TestRunTC.test_all ______________________________

self =  >

... [Log Snipped] ...
pylint/test/test_self.py:110: AssertionError
======= 2 failed, 957 passed, 53 skipped, 49 deselected in 83.00 seconds =======
```

Note that in Fedora, we do this differently:

```
python3 setup.py build ...
python3 setup.py install ... # into %{buildroot}
export PYTHONPATH=%{buildroot}%{python3_sitelib} # something like /blah/blah/usr/lib/python3.6/site-packages
python3 -m pytest pylint/test
```

But the failures are the same.
