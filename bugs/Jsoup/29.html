Title

Incorrect handling of self-closing tags noframes, style and title cause remainder of document to be html-escaped

Description
Given the input:

```
html
 
 
	     
 
... [Log Snipped] ...
 
 
```

JSoup 1.8.2 and also [URL] will produce:
```
html
     
       
        
      
... [Log Snipped] ...
      
     
```

With ` ` instead of ` `, the result is different but still wrong (http://try.jsoup.org/~BZ3uoMki-r904fZxUOWJgLJO7r8 ):
```
html
 
   
    
  
... [Log Snipped] ...
  
 
```

That weirdness was fixed for ` ` with Issue #305: [URL]
```
html
 
   
     
   
... [Log Snipped] ...
  
 
```

Looking [Link: at the source], it seems only the HtmlTreeBuilderState handling for ` `, ` ` and ` ` in the methods `handleRawText` and `handleRcData` doesn't get along with the self-closing tags.
Any other tagname I've checked (and I tried to cover all branches of that `case StartTag` switch) results in a good parse similar to the ` ` case, which is what I'd expect.
