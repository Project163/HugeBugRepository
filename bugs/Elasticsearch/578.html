Title

Source filtering in mget doesn't understand 0/1 as false/true

Description
In most places:

```
_source: true | false
```

can also be written as:

```
_source: 1 | 0
```

But this isn't supported in the `mget` api:

```
curl -XPUT '[URL] -d '
{
   "count" : "1",
   "include" : {
      "field1" : "v1",
... [Log Snipped] ...
#    ]
# }
```
