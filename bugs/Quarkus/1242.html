Discussion
- Alright, I think I found something. We are using a multi-module maven project, where we have a dedicated database module with Quarkus dependencies, but it doesn't include any RESTeasy dependencies. Once I add `quarkus-resteasy` to that module the integration tests pass again.

Provided a minimal reproducer here [URL]
- Good catch. The issue is that the new `QuarkusConnectionCache` in Agroal has a hard dependency to Netty... and it compiles because the optional `quarkus-smallrye-health` brings Netty into the compile classpath of the extension.

We have two options here:
- either have Agroal dependent on Netty - not sure it's a good idea,
- or only use this cache if Netty is around.
