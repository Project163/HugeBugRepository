- I introduced this bug with 426be73.  The RecursiveParserWrapper now closes the stream, which it shouldn't do.  When tika-server tries to close the stream, and it is already closed, this exception is thrown.  I can't figure out why this still works on other file types, e.g. docx... 

 This is a bug, though, and I'll have a fix shortly.  Thank you for reporting this!
