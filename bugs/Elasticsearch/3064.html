- OK, I added a check to make sure the currentThread when constructing the profiler is the same thread when using it, and it turns out it isn't. I am guessing we haven't turned off multi-threading when profiling is turned on?

```
Caused by: java.lang.IllegalStateException: Profiler is not thread-safe and can only be used from the thread that created it. Current thread: elasticsearch[node_s0][search_worker][T#3], profiler thread: elasticsearch[node_s0][search][T#4]
```
- This is a multi-threaded search bug. We should not be using search workers and multi-threaded search when `profile: true`. Apparently we still are.
