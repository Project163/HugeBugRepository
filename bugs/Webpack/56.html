Title

No way to get source map with CLI with 2.1.0-beta.8

Description
The change (https://github.com/webpack/webpack/commit/ ) in 2.1.0-beta.8 that by default disables sourceMaps for UglifyJSPlugin makes it, AFAIS, impossible to get source maps from the command line.

For instance, the following produces a source map in beta 7,  but doesn't in beta 8:

```
webpack -p --devtool source-map script.js out.js
```
