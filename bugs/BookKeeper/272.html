Title

Race condition in sync ZKUtils.createFullPathOptimistic()

Description
If multiple threads are calling createFullPathOptimistic() there will be race conditions on creating the intermediate nodes. If the intermediate nodes have been created since we last check, we can just ignore the exception and continue creating the child nodes.
