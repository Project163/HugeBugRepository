Title

unused-import and undefined-all-variable false positive

Description
Originally reported by: **Claudiu Popa (BitBucket: [Link: PCManticore], GitHub: @PCManticore)**

---

Given the following, pylint emits an unused-import and undefined-all-variable for each member from the `__all__` entry. This idiom can be used when wrapping another module and the user wants to export the same `__all__` entry, so we should supress those warnings.

```
#!python

from collections import __all__
```
