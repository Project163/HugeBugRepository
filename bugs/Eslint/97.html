Title

brace-style fails to catch this pattern

Description
Brace-style should fail in this case regardless of the option used:

``` js
function foo() { return; }
```

Both of the brace styles supported require curly braces on separate lines.
Discussion
- Should it also warn on IfStatements of the same style?

``` js
if (foo) { return; }
```
- Yes, all BlockStatements fall under this rule.
- I ask because the IfStatement is a common exception to this style. I often seen one-liner ifs, like the one above. 

Would we want to support this exception in another option?
- AFAIK, the two styles we support don't have this exception. I don't want to get into micro application of brace styles per expression at this point, I fear that would be a rabbit hole from which we would never emerge.
