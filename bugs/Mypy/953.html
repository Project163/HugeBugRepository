Title

`None` incompatible with `SupportsStr`

Description
**Bug Report**

I have a protocol, `SupportsStr`:
```py
class SupportsStr(Protocol):
    def __str__(self) -> str:
        ...
```

`None` is, surprisingly, not compliant with it.

**To Reproduce**

```py
from typing import Protocol

class SupportsStr(Protocol):
    def __str__(self) -> str:
        ...
        
x: SupportsStr = None
```

[URL]

**Expected Behavior**

I expect `None` to be compatible with `SupportsStr`.

**Actual Behavior**

In reality, `None` is not compatible with `SupportsStr`.

**Your Environment**

- Mypy version used: 0.961
- Python version used: 3.10
