Title

@HostListener etc does not appear in generated code

Description
(post ngModules)

The following component when compiled via `ngc` does not have a host listener setup in the compiled ngfactory.

```
typescript
import {Component, HostListener} from '@angular/core'

@Component({
    selector: 'home-view',
... [Log Snipped] ...
    }
}
```

compiled via `ngc` produces:

```
typescript
/**
 * This file is generated by the Angular 2 template compiler.
 * Do not edit.
 */
... [Log Snipped] ...
  return new _View_HomeView0(viewUtils,parentInjector,declarationEl);
}
```

with the collected metadata:

```
json
{
    "__symbolic": "module",
    "version": 1,
    "metadata": {
... [Log Snipped] ...
    }
}
```

However, compiling the same component using the ES5 syntax:

```
typescript
import {Component, HostListener} from '@angular/core'

@Component({
    selector: 'home-view',
... [Log Snipped] ...
    }
}
```

does generate the appropriate bindings:

```
typescript
/**
 * This file is generated by the Angular 2 template compiler.
 * Do not edit.
 */
... [Log Snipped] ...
  return new _View_HomeView0(viewUtils,parentInjector,declarationEl);
}
```

currently breaks the Router etc. cc @tbosch
