Title

Unreliable CI tests

Description
I have been on a mission to find all the unreliable CI tests.

I wrote two tools

- [URL] - to fetch all the logs from GitHub actions
- [URL] - to parse the logs

Then ran them like this

```
fetch-actions-logs -conclusion failure -user ncw rclone/rclone logs
parse-actions-logs -o output logs/*.zip
```

This gives the following directory tree which gives us something to work on!

The zip file is attached with the files here: [Link: action-logs-parsed.zip]


```
action-logs-parsed/
├── github.com／rclone／rclone／backend／cache
│   ├── TestInternalCachedUpdatedContentMatches
│   │   ├── modules_race／10_Race test.txt-35424342.txt
│   │   └── modules_race／10_Race test.txt-38113485.txt
... [Log Snipped] ...
        ├── mac／10_Race test.txt-65412168.txt
        └── mac／10_Race test.txt-86043180.txt
```

So summarising this, most severe first

- cmd/mount2 and cmd/cmount tests are a trash fire
    - cmd/mount probably would be too but we disabled them on CI already
- cmd/cmount
    - TestDirCacheFlush - 17 failures
    - TestDirCacheFlushOnDirRename - 11 failures
    - TestWriteFileFsync - 1 failure
- cmd/mount2
    - all failures are at writes/full so this is probably VFS problems
    - TestWriteFileAppend - 15 failures
- fs/accounting `TestStatsGroupOperations/memory_is_reclaimed` test fails consistently
- cmd/serve/sftp AuthProxy test has a race in it
- backend/cache - TestInternalCachedUpdatedContentMatches and TestInternalCachedWrittenContentMatches both fail sometimes.
- lib/pool TestPool/canFail/Flush fails on macOS sometimes
- rc/jobs TestJobsKickExpire fails sometimes
- rc/jobs TestJobsExpire fails occasionally
- cmd/serve/ftp Normal test is broken but only very occasionaly
Discussion
- I'm declaring this done for the moment :-)
