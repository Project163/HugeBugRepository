Title

Memory Management Plugin does not handle unknown values properly

Description
Maximum and committed memory use of the Memory MBeans may return -1 if the value is unknown. The max value is used to calculate usage percentages which leads to wrong values if max is -1. 

 The plugin should account for -1 values as to be unknown and not calculate the percentages in these cases.
