Title

Loose type of array by assigning to it inside foreach

Description
# Bug report

Have an non-empty array `int[]`.
Add another value to the array by calling user method with `int` return type inside an foreach loop.
Calling `max()` on this array now makes phpstan think the result can be `int|false` instead of `int`.

This issue doesn't appear if:
- you omit the `foreach`
- you assign scalar `int` value instead of making a method call (but type-casting method result to int won't fix it)
