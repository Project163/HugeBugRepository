Title

Deal with java.security.acl

Description
With   CXF-7815    Deal with java.security.acl classes being removed in Java 12 - ASF JIRA  the java.security.acl packages have been removed in Apache CXF 3. 

 The package is still mentioned in the MANIFEST.MF of Apache CXF 4.1.2, which leads to failed OSGi builds with java >= 12. 

 Not used / required packages should be removed from the manifest-file.
