Title

AWT tests: test_jpeg.tiff test affected by JDK-8274735, JDK 17.0.4 EA

Description
### Describe the bug

The decoding of a JPEG compressed image within TIFF container used to throw an `Unsupported Image Type` exception.
The image was valid, not produced by a ImageMagic+Radamsa fuzzer, but a manually crafted in GIMP.

It seems that [Link: JDK-8274735] fixes that and `test_jpeg.tiff` can be decoded now and that makes the test suite fail as it still expects the exception.

With that said, the decoded image still doesn't look right, so there is probably something still wrong in the JDK implementation.

I will fix the TS so as it takes into account older/newer JDKs.

Our goal here is to execute code paths in decoders so as we trigger those in Native image. We are not that much concerned with testing how JDK itself processes images. With that said, it might be worth reporting to the JDK mailing list anyway.
