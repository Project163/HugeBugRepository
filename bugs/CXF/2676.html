Title

the order of attributes in SubjectDN of certificate shouldn't be significant

Description
Per the RFC2253, the order of attributes in SubjectDN isn't significant, and it can vary across different platforms() with different implementations. 
Currently in CXF it assume the order of attributes in SubjectDN is fixed during the SubjectDN comparison, so this can cause some tests failure on some platforms
