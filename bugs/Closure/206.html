Title

Error trying to build try-catch block (AST)

Description
1. EXAMPLE

Node nodeTry = IR.block(
  IR.var(
    IR.name("testing"), 
    IR.number(11)
  )
);
Node nodeCatch = IR.catchNode(
  IR.name("blabla"),
    IR.block(
      IR.var(
        IR.name("testing"),
	IR.number(22)
      )
    )
);
IR.tryCatch(nodeTry, nodeCatch);


2. THROWS ERROR

Please report this problem.

3. SOLUTION
