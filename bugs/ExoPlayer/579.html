Title

CommandReceiver not annotated properly with nullity

Description
MediaSessionConnector.CommandReceiver's method is not annotated with nullity annotations.
This forces kotlin implementers to specify all parameters with not null.

In MediaControllerCompat, the params and the receiver are annotated as nullable:
```kotlin
public void sendCommand(@NonNull String command, @Nullable Bundle params,
            @Nullable ResultReceiver cb) {
        if (TextUtils.isEmpty(command)) {
            throw new IllegalArgumentException("command must neither be null nor empty");
        }
        mImpl.sendCommand(command, params, cb);
    }
```

This makes it impossible to implement the CommandReceiver from kotlin.
