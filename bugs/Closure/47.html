Title

jscomp Ant Task (CompileTask) Does Not Fail Build on Failed JS Compilation

Description
What steps will reproduce the problem? 

1. Using the Closure Compiler Ant task provided by com.google.javascript.jscomp.ant.CompileTask, I noticed that it does not fail a build in the event that an error occurs with compilation.  Even if the JavaScript resource I'm attempting to compile contains blatant syntax errors, Ant claims the CompileTask was successful and continues with the build even though the Closure compiler encountered an error ...

Buildfile: /opt/eclipse-workspace/jscomp-fails/build.xml
compile:
   [jscomp] Compiling 1 file(s) with 36 extern(s)
   [jscomp] /opt/eclipse-workspace/jscomp-fails/dumb.js:3: ERROR - Parse error. syntax error
   [jscomp] if(a=)jjj
   [jscomp]       ^
   [jscomp] 1 error(s), 0 warning(s)
BUILD SUCCESSFUL
Total time: 1 second

Note the "BUILD SUCCESSFUL" here.  Seems silly to want the build to continue if your JavaScript fails to compile.


 What is the expected output? What do you see instead? 

I would expect CompileTask to throw a BuildException if the compilation failed for any reason (e.g., if((result = compiler.compile(...)) != success)).  This halts the build process at the target that generated the error and lets me fix my JavaScript before I continue.

With a proper fix in place (throwing a BuildException on failure) a compilation error would look like this ...

Buildfile: /opt/eclipse-workspace/jscomp-fails/build.xml
compile:
   [jscomp] Compiling 1 file(s) with 36 extern(s)
   [jscomp] /opt/eclipse-workspace/jscomp-fails/dumb.js:3: ERROR - Parse error. syntax error
   [jscomp] if(a=)jjj
   [jscomp]       ^
   [jscomp] 1 error(s), 0 warning(s)

BUILD FAILED
/opt/eclipse-workspace/jscomp-fails/build.xml:9: Compilation failed.

Note the "BUILD FAILED" here.
