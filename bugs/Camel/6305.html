Title

camel-elastisearch-starter - Spring Boot clash with json-api dependency

Description
SB manages a set of dependencies and bring in 

 jakarta.json:jakarta.json-api:jar:1.1.6 

 But ES requires v2 of this library, so we must force it to use that version
Discussion
- This is not possible due to SB 2.7.x is managing and overriding this json-api to be v1. 

 Camel end users that use camel-elasticsearch-starter must then put v2 as dependency in their own pom.xml to override this. 
We cannot do this automatic from Camel Spring Boot.
- I have added a note in the docs about this. Spring Boot v3 is upgraded to ES 8.x so this should work better there out of the box.
