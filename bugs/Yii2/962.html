Title

$model - getPrimaryKey()/getLastInsertId() returns wrong value when tables has triggers

Description
### What steps will reproduce the problem?

```
php
$model = new Model();
$model->name = 'model name';
$model->save();

... [Log Snipped] ...
echo $model->Id;
echo $model->getDb()->getLastInsertId();
```

### What is the expected result?

We expect is a newly assigned ID according to AutoIncrement PK 

### What do you get instead?

Returns the id of the row inserted to the audit/historic table.

### Additional info
We tried directly on sql server like this:

```sql
INSERT INTO table ([Name]) VALUES ('Test');
SELECT SCOPE_IDENTITY() as ScopeID, @@IDENTITY as IdentID;
```

The newly row created, ScopeID returns the correct ID and IdentID the ID of row inserted into Log table.

We checked the method lastInsertId  from PDO ( class yii2\db\mssql\PDO ), and SCOPE_IDENTITY() returns null, so maybe the connection is not the same?! so returns value from @@IDENTITY instead.

```
php
   /**
     * Returns value of the last inserted ID.
     * @param string|null $sequence the sequence name. Defaults to null.
     * @return int last inserted ID value.
... [Log Snipped] ...
        return $this->query('SELECT CAST(COALESCE(SCOPE_IDENTITY(), @@IDENTITY) AS bigint)')->fetchColumn();
    }
```
