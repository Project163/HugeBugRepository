Title

An empty result of the SystemViewTask task when there is no view on any of the processed nodes

Description
The error occurs when some Views are missing on one of the nodes with a thick client where SQL is not configured. For such nodes, SystemViewTask returns null, and in the current implementation of the reduce operation, this will result in the final null result of the SystemViewTask task.
