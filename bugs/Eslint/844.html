Title

The default value of CLIEngine's `options.cwd` is decided when ESLint is loaded.

Description
From [URL]
- [Link: `getRelativePath` function of Atom's `linter-eslint` changes the current directory] and returns a relative path from the new current directory. And it executes linting of the file.
- At the time, `eslint.CLIEngine` uses the default value of `options.cwd`. It should be `process.cwd()`.
  But actually, [Link: the default value of `options.cwd` had been decided when ESLint was loaded].

I think the default value of `options.cwd` should be decided in runtime.
