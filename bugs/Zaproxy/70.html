Title

Inconsistencies in break buttons shown

Description
Steps to reproduce the issue(s):
1. Run ZAP;
2. Change the option ("Options" > "Display" >) "Show break buttons:" to "Only in the break panel" and restart ZAP;
3. Note that in the "Break" panel it's missing the button (or buttons, if "Separate Request and Response buttons" is set) to enable the breakpoints;
4. Enable the breakpoints through the menu "Tools" > "Toggle Break on All Requests";
5. Proxy a request, forward the request and once the response is received note that the button is now shown, as well the "separate" buttons.

ZAP Versions:
Versions >= 2.4.0
