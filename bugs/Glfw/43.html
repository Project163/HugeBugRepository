Title

glfwTerminate() breaking stdout

Description
After calling glfwTerminate(), I no longer see anything I print to stdout. This is a problem because it's suppressing the error messages printed out by my top-level exception handler.

stderr is unaffected. (I can workaround by printing my messages there instead but then it's a bit more awkward to deal with from shells.)

This is happening on an Arch Linux system running X11. Haven't tried any others.

Example program: [URL]
This is a slightly modified version of the Hello World from the docs. In fact if I remove all the stuff with the window, leaving only glfwInit(), glfwTerminate(), and the printf()s, I see the same problem.

One other aside: If I insert another glfwInit() after the glfwTerminate() and before the final printf(), the final printf() still does not show up.
