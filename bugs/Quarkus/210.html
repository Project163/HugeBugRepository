Title

Entities extending PanacheEntityBase are not enhanced in dev mode when located in a dependency

Description
**Describe the bug**
Getters and setters are not generated for an entity extending `PanacheEntityBase` and located in a dependency of a Quarkus project. This dependency contains an empty `beans.xml`.

**Expected behavior**
The Quarkus documentation says entities getter/setter generation should work for entities from dependencies as long as there's an empty beans.xml in the dependencies:

**Actual behavior**
```
org.jboss.resteasy.spi.UnhandledException: java.lang.NoSuchMethodError: com.gwenneg.EntityWithoutGetterSetter.setName(Ljava/lang/String;)V
	at org.jboss.resteasy.core.ExceptionHandler.handleApplicationException(ExceptionHandler.java:106)
	at org.jboss.resteasy.core.ExceptionHandler.handleException(ExceptionHandler.java:372)
	at org.jboss.resteasy.core.SynchronousDispatcher.writeException(SynchronousDispatcher.java:209)
	at org.jboss.resteasy.core.SynchronousDispatcher.invoke(SynchronousDispatcher.java:496)
... [Log Snipped] ...
	at org.jboss.resteasy.core.SynchronousDispatcher.invoke(SynchronousDispatcher.java:477)
	... 50 more
```

**To Reproduce**
Steps to reproduce the behavior:
1. Clone [URL]
2. Run `cd entity-dependency`
3. Run `./mvnw clean install`
4. Run `cd ../jaxrs-resource`
5. Run `./mvnw clean compile quarkus:dev`
6. Call [URL] from browser

**Environment:**
 - Output of `java -version`: `openjdk version "11" 2018-09-25`
 - Quarkus version or git rev: `0.17.0`
Discussion
- It seems this bug only affects dev mode. It's not happening with `./mvnw clean package` followed by `java -jar target/jaxrs-resource-1.0-SNAPSHOT-runner.jar`.

In dev mode, I can see the entity being processed through the `PanacheJpaEntityEnhancer.collectFields()` method while debugging so it's not entirely ignored (and it must explain why it works without dev mode) but the `PanacheJpaEntityEnhancer.apply()` method is only called for entities declared in the `jaxrs-resource` reproducer project and not for entites declared in the `entity-dependency` project.
- I added the missing getters/setters to my entity as a workaround for this issue and now I'm facing a new `IllegalStateException` with the following message when calling the `PanacheEntityBase.find()` method:

The entity is annotated with `@Entity`.

This also happens only in dev mode. Everything's fine if I run a packaged jar like in my previous comment. The getter/setter issue and this one have to be related.

This time, I don't see any workaround.
