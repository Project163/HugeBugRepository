Discussion
- Looks like its an issue on the torch side, here is a repro without keras:
```python
import torch

output = torch.zeros(3, 2, 1, requires_grad=True, device='mps')
target = torch.zeros(3, 2, 1, device='mps')
torch.sum(torch.nn.BCELoss(reduction='none')(output, target)).backward() # crashes
# torch.nn.BCELoss(reduction='sum')(output, target).backward() # works
```
