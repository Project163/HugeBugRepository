Discussion
- This issue is caused by this commit [URL]
which changed:

``` js
value: MUST_USE_PROPERTY | HAS_SIDE_EFFECTS,
```

to

``` js
value: 0,
```

It looks like the key is the `HAS_SIDE_EFFECTS` bit.
Changing the value, even if it's identical to the existing value, knocks off browser helpers in Edge.

I see that `HAS_SIDE_EFFECTS` [Link: was removed] in a later version so that's something to account for.
