Title

CREATE TABLE throw error when session catalog specified

Description
Spark throw error when the session catalog is specified explicitly in "CREATE TABLE" and "CREATE TABLE AS SELECT" command, eg.  
  
 
CREATE TABLE spark_catalog.tbl USING json AS SELECT 1 AS i;
