Title

Public thread pool starvation is cause of deadlock when user's jobs calls cache.size()

Description
The users job are hang when a lot of jobs that calculates cache size are submitted. 

 The log contains message: 
  
 WARNING: Possible thread pool starvation detected (no task completed in last 30000ms, is executorService pool size large enough?)
 
  

 After a while all the thread of a public thread pool are locked on waiting the SizeTask future.
Discussion
- Root cause: SizeJob is always executed in the public thread pool.
