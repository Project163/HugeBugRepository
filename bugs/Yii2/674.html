Title

Yii::$app->formatter->asDateTime(time(), 'php:'.DATE_ATOM) does not return the same as date(DATE_ATOM)

Description
### What steps will reproduce the problem?
Running the below code returns 2 different outcomes. Shouldn't it be the same? or am I missing something.
```
echo date(DATE_ATOM);
echo " ".Yii::$app->formatter->asDatetime(time(), 'php:'.DATE_ATOM);
die();
```
produces:
```
2017-03-07T22:22:40+01:00
2017-03-07\GMT+122:22:40+01:00
```
As you can see the `\T` doesn't get escaped and is evaluated as `\GMT+1`

### What is the expected result?
Expecting the same output for the yii2 formatter when using the `php:` format prefix.
```
2017-03-07T22:22:40+01:00
2017-03-07T22:22:40+01:00
```

### What do you get instead?
Instead the formatter doesn't escape the `\T` and evaluates it as `\GMT+1`
