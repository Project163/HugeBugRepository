Title

Access-Control-Expose-Headers not returned to request

Description
### Describe the bug

The Access-Control-Expose-Headers is only returned during the preflight request but not included in the subsequent request itself. Consequently, the header cannot be accessed through JavaScript in the browser.

### Expected behavior

The Access-Control-Expose-Headers should be returned

### Actual behavior

The Access-Control-Expose-Headers  is not returned.

### How to Reproduce?

1 - Configure the quarkus.http.cors.exposed-headers with some header.
2 - Send a request from browser
