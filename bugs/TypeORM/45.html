Title

Naming strategy of embedded columns

Description
Hello everyone,

I am currently trying to move my schema from mongoose to typeorm. Here's a small example of parts of a document in our MongoDB database:

```
js
{
    "_id" : ObjectId(" "),
    "name" : "Test",
    "contact" : {
... [Log Snipped] ...
    }
}
```
As you can see I got (at least) two fields in our "contact" field.

My current solution is to create the following entities:
```
js
@Entity()
export class House {
    @ObjectIdColumn()
    id: ObjectID;
... [Log Snipped] ...
    contact: HouseContact;
}
```

```
js
@Entity()
export class HouseContact{
    @ObjectIdColumn()
    id?: string;
... [Log Snipped] ...
    business: Contact;
}
```

```
js
@Entity()
export class Contact {
    @ObjectIdColumn()
    id?: string;
... [Log Snipped] ...
    phone: string;
}
```
(Yeah I know, it's a bit tricky but unfortunately I can't change the Schema)

Everything works fine except the naming of the two fields "general" and "business", typeorm names those fields "contact_general" and "contact_business", here's an example:

```
js
{
    "_id" : ObjectId(" "),
    "name" : "Test",
    "contact" : {
... [Log Snipped] ...
    }
}
```


**My question is the following:** Can I somehow change those names to fit my (old) schema?
