Title

camel-jbang - Export to Quarkus should let property keys with their current case

Description
This  
  
 
camel.main.name = cheese
quarkus.hawtio.authenticationEnabled =  false   
  
 Is exported as: 
  
 
camel.main.name=cheese
quarkus.hawtio.authentication-enabled= false 
quarkus. native .resources.includes=camel/foo.camel.yaml
camel.main.routes-include-pattern=camel/foo.camel.yaml
Discussion
- This is a bit wrong as quarkus uses dash for all their config values. So its likely quarkus.hawtio.authenticationEnabled that is wrong and should be a dashed style and be quarkus standard naming instead.
