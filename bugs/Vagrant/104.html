Title

vagrant up netbsd70 fails on waiting for boot (ssh) but vagrant ssh works

Description
To reproduce, using the following `Vagrantfile`

``` ruby
Vagrant.configure(2) do |config|
  config.vm.box = "netbsd70-0.1.0"
  config.vm.box_url = "[URL]
end
```

do:

``` bash
vagrant up
```

In another terminal do:

``` bash
vagrant ssh
```

Discussion
- Configuring the guest sshd with `NoneEnabled yes`  (allow the use of the none chiper, which basically turns ssh into telnet..) solves this. This gives a hint that the probing in `vagrant up` use some other settings than the `vagrant ssh` uses to connect.
- I ran into this too when building a custom base box. I don't have this issue when using [Link: `kja/netbsd-7-amd64`] as my base box, so I looked at its `sshd_config` and it indeed has `NoneEnabled yes` at the bottom. Other OSes that I tried don't recognize `NoneEnabled` as an option.
