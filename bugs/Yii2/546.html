Title

Hard coded table names for MSSQL in RBAC migration

Description
Seems there are some hard coded table names for MSSQL in RBAC migration.

```
php
if ($this->isMSSQL()) {
    $this->execute("CREATE TRIGGER dbo.trigger_auth_item_child
    ON dbo.{$authManager->itemTable}
    INSTEAD OF DELETE, UPDATE
... [Log Snipped] ...
    END;");
}
```

`auth_item` and `auth_item_child` are hard coded and if user adjusted RBAC to use custom table names, created trigger will contain default table names anyways.

I'll send a PR.
