Title

Breadcrumbs: insertAfter

Description
### Description

Hi,

i think there is an issue in BreadcrumbsHelper.

I defined the following Breadcrumbs:
```
php
$this->Breadcrumbs->add(
    'Breadcrum I',
    ['controller' => 'products', 'action' => 'index']
);
... [Log Snipped] ...
    ['controller' => 'products', 'action' => 'index']
);
```
After i do this, Cakephp returns an Error:
```
No crumb could be found at index '1'
```

The `findCrumb`-Method wich is called from `insertAfter` in `BreadcrumbsHelper.php` returns the Value 0.
After check for null, insertAfter calls insertAt with $key+1:
```php
return $this->insertAt($key + 1, $title, $url, $options);
```

In the `insertAt`-Method is an isset-Check:
```php
if (!isset($this->crumbs[$index])) {
    throw new LogicException(sprintf("No crumb could be found at index '%s'", $index));
}
```

This Error is shown, when the key (in this Case "1") not exists.


### CakePHP Version

4.2.0

### PHP Version

7.4.19
