Title

Problems with custom Fact attributes in PCL using xUnit2

Description
Using latest pre release of xUnit on NuGet.
**Testrunners:** Latest Test explorer and xunit.console.

Hosted in a `PCL (Net4.5, Windows store 8+, Windows phone 8)`

If I switch for plain `FactAttribute` the tests are identified.

If I use my custom attribute, no tests are identified. **NOTE!** The attribute works in xUnit1.9.

```
csharp
public class MyFactAttribute : FactAttribute
{
    public MyFactAttribute(params string[] scenarios)
    {
... [Log Snipped] ...
    }
}
```
Discussion
- Custom attributes that has primitive values and not arrays defined in the constructor works. But as soon as you make it an array, it stops finding the tests.

//D
- Tried a workaround with having an array property being initialized instead. Doesn't work either.
- The issue is with CustomAttribute and how it converts arguments. Long story short, this is a problem we'd already had to solve for theories in v1, but is a new problem in v2 for `[Fact]` (owing to the way we create attributes being different in v2).
