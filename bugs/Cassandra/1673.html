Discussion
- Sounds like you're trying to run sstable2json on a columnfamily that isn't present in your schema.
- Instead of trying to process an unknown column family (and exiting with an exception), load the Descriptor at the top of the export process and check to see if the keyspace/column family exists inside the current cassandra setup. If not, print a warning message and exit.
- Note: I worked on this patch against the current (1.2) trunk. I can backport it to earlier versions, if we need.
- patch applies cleanly to 1.1, so committed there as well.  thanks!
