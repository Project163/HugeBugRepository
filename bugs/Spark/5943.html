Title

A deadlock in ALTER TABLE RECOVER PARTITIONS

Description
Recover Partitions in ALTER TABLE is performed in recursive way by calling the scanPartitions() method. scanPartitions() lists files sequentially or in parallel if the  condition  is true: 
  
 
partitionNames.length > 1 && statuses.length > threshold || partitionNames.length > 2
 
  
 Parallel listening is executed on  the fixed thread pool  which can have 8 threads in total. Dead lock occurs when all 8 cores have been already occupied and recursive call of scanPartitions() submits new parallel file listening.
