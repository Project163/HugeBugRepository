Title

[DocDB][xCluster] Data mismatch in Source and Target with Multi-Shard Atomic Transaction

Description
Jira Link: [Link: DB-3844]
### Description

**Version**:  -b72

**Steps**:
1. Create 2 universes(Source and Target)
2. Create similar database and 2 tables at both sides
3. Add below GFLAGS at target side
`Master`
```
"xcluster_consistent_reads": "true",
"enable_replicate_transaction_status_table": "true",
```
`Tserver`
```
"xcluster_consistent_reads": "true",
"TEST_xcluster_simulated_lag_tablet_filter”: “Tablets IDs”
```
4. Setup replication on that database
5. Run below query at target side
`UPDATE pg_settings SET setting = 'tablet' WHERE name = 'yb_xcluster_consistency_level'; `
6. Begin transaction at source and load some data to both tables(100 rows/table) and make the transaction to abort in between and rollback it
7. Check the tables data at source and Target.

**Actual**:
1. There won't be no data at Source and observed some rows at tables at Target side.
