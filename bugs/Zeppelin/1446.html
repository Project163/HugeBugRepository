Title

Add fail-fast check for JavaCompiler in Java interpreter

Description
Background:  
 
	 In the `StaticRepl` class ,  ToolProvider.getSystemJavaCompiler()  is used to obtain a compiler instance. 
 

 
	 This works only in a JDK environment; in a JRE, it returns  null , which can lead to errors later in the execution flow. 
 

 
	 During a recent refactoring review, it was suggested to perform a null check at the earliest point to implement a  fail-fast  mechanism. 
 

  Proposed Solution:  
 
	 Move the initialization of  JavaCompiler compiler = ToolProvider.getSystemJavaCompiler();  to the very beginning of the method. 
	 If  compiler  is  null , throw a clear exception ( Exception ) with a message explaining that a JDK is required.
