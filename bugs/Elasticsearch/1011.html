Title

Aggregations: Geohash grid should count documents only once

Description
If two geo-hashes of the same document fall into the same bucket, then the document count for this bucket will be incremented by 2 instead of 1. Here is a reproduction:

```
DELETE test

PUT test
{
  "mappings": {
... [Log Snipped] ...
  }
}
```

which returns:

```
{
   "took": 3,
   "timed_out": false,
   "_shards": {
      "total": 5,
... [Log Snipped] ...
   }
}
```
