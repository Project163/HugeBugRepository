Title

Intermittent: The FastCGI process exited unexpectedly

Description
Created by **Dan**, 29th Oct 2012. _(originally [Link: Lighthouse ticket #3317])_:

---

I'm running CakePHP with IIS 7, PHP 5.4.0, and SQL Server 2008. Using MySQL I'm experiencing no problems at all.

I'm intermittently receiving the following error:

HTTP Error 500.0 - Internal Server Error
C:\Program Files\PHP\v5.4\php-cgi.exe - The FastCGI process exited unexpectedly

From scanning my logs I can see the error relates to the php_pdo_sqlsrv.dll module, this is the complete error:

Faulting application name: php-cgi.exe, version:  , time stamp:  
Faulting module name: php_pdo_sqlsrv.dll, version: 3.0.3421.0, time stamp:  
Exception code:  
Fault offset:  
Faulting process id: 0x3b0
Faulting application start time:  
Faulting application path: C:\Program Files\PHP\v5.4\php-cgi.exe
Faulting module path: C:\Program Files\PHP\v5.4\ext\php_pdo_sqlsrv.dll
Report Id: 7ecdcc4e-21cf-11e2-a7b5-90fba6e5fdcb

Queries do appear to be running as I can intermittently read and write to the database, but consistently during the write process it will throw the above error and occasionally when reading.

Thanks,
Dan
