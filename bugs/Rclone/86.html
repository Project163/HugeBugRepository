Title

Why `rclone copy` checks file list from S3 bucket?

Description
Probably, one of the common use cases for rclone with S3 is to upload new files from local folder, which could be done via `cron.daily` like `rclone copy --max-age=25h    `.

The problem with this case is that `rclone copy` first checks the bucket file list, which could be very expensive operation (more than 1 hour for my case), while it could just start checking and uploading files from local folder. What is wrong?
