Title

d3.format('0,000') is confused by very small and very large numbers

Description
[d3.format('0,000')(1e+6), d3.format('0,000')(1e+25), d3.format('0,000')(1e-25)]

Expected: ["1,000,000", "1e+25", "1e-25"]
Actual: ["1,000,000", "1e,+25", "1e,-25"]
Discussion
- Good point.  I wonder if we should simply avoid applying thousands grouping if exponent notation is detected.
- Fix staged in #2075 for 3.4.13.
