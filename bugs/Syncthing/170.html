Title

Ignored files are ignored forever, unless .stignore is 0-byte

Description
This behavior happens on all my repositories, every time, with Syncthing v0.10: Once I add patterns to `.stignore`, Syncthing will never recognize these ignored files again.

Reproduce:
1. Add a pattern to `.stignore`.
2. Hit _[Rescan]_ in GUI and notice the change of Local/Global state file count
3. Remove the pattern you've added in `.stignore`
4. Hit _[Rescan]_ in GUI and notice the local/global state file count isn't changing.

Tried rescanning, restarting, none worked. The only way Syncthing recognizes them again is if I **completely** empty the `.stignore` file. As soon as I add even one single character in it, everything is ignored again. This definitely feels like it's cached somewhere...
