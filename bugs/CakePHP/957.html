Title

3.7.0 middleware loading issues

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.6 latest (3.7)

### What you did

I upgraded a 3.5 app to 3.6 latest, and while doing so I kept the middelware loading the same:

	->add(RoutingMiddleware::class);

### What happened
$app going into the middleware is null (see [URL]
This silently fallbacks to some weird thing where now no plugin routes are loaded anymore in Web requests. CLI works fine, though.

So it seems that this is not so bc after all, and as such dangerous to be kept silent.

### What you expected to happen
That it still loads the plugin routes.
Or maybe some deprecation warning here if `$app === null` to make it easier to know that it now requires the $app to be actually passed as object to load plugin routing.

As

	->add(new RoutingMiddleware($this, '_cake_routes_'))

fixes the issue
