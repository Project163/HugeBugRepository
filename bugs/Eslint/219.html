Title

key-spacing won't allow for comments

Description
Comments should be disregarded when determining `key-spacing`.

version `0.11.0`

config:

```
"key-spacing": [ 2, { "align": "colon" } ]
// or
"key-spacing": [ 2, { "align": "value" } ]
```

code:

```
o = {
    longKey: 1,
    key2   : 2,
    // comment explaining key3
    key3   : 3
};
```

error:

```
5:4  error  Extra space after key "key3"  key-spacing
```
