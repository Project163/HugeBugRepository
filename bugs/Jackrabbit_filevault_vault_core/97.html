Title

ZipStreamArchive does not expose correct input source to the META-INF resources

Description
After calling  open  on a given  ZipStreamArchive  the  getInputSource  does not correctly expose access to the input stream of the entries below  META-INF . This is due to the fact that the input stream of those entries are already consumed once  [URL] is reached. The solution would be to first copy to buffer/file and then read the meta inf from there.
