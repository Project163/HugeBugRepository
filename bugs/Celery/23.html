Title

New configuration lowercase settings don't appear to work in 4.1.0.

Description
I have just updated from Celery 3.x to 4.1.0. I changed the broker URL settings from **uppercase** to **lowercase** as described here: [URL]


However, it appears that only the uppercase version of `BROKER_URL` works in 4.1.0. Using the new lowercase settings as described above don't appear to work for me? Why?

## Steps to reproduce
Updated celery to 4.1
```
```

Changed celery setting as per instructions 👍 

FROM: `BROKER_URL = amqp://x:x@broker-staging.x.eu:5672//'`
TO: `broker_url = amqp://x:x@broker-staging.x.eu:5672//'`

## Expected behaviour

```
app = Celery('tasks')

app.config_from_object('django.conf:settings')
# Load task modules from all registered Django app configs.
app.autodiscover_tasks()
print(app.conf.broker_url)
```

## Actual behaviour

```
app.config_from_object('django.conf:settings')
# Load task modules from all registered Django app configs.
app.autodiscover_tasks()
print(app.conf.broker_url)
```


Using: 
* Python 3.6
* Django 1.9.9
* Celery 4.1.0
Discussion
- After some investigation, it appears that Django settings can only be in **uppercase**.  So, if you’re loading Django settings into Celery using `config_from_object` method you cannot use the new lowercase versions as documented. 

The new 4.1 Celery documentation is somewhat misleading. It should be split up into name changes regardless of case i.e `CELERY_QUEUES` changed to `TASK_QUEUES` and lowercase `task_queues` when loading outside of Django.
- @auvipy @glynjackson - this is mentioned in the Django section, and in the what's new in 4.0 section... I'm guessing we just want to reword a bit and add a note in the userguide/configuration? similar issue with documentation seen in #4198
