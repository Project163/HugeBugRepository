Title

[rcd/rc] include/filter options are ignored

Description
#### What is the problem you are having with rclone?

When running rclone as a daemon using `rclone rcd`, the filter/include/exclude options set by client or REST API are ignored.

#### What is your rclone version (output from `rclone version`)

rclone v1.46.0-053-gd233efbf-beta
- os/arch: linux/amd64
- go version: go1.12

The latest stable v1.46.0 is also affected.

#### The command you were trying to run (eg `rclone copy /tmp remote:tmp`)

To reproduce run following:

`touch /tmp/pic.jpg /tmp/pic.png`
`rclone rcd --rc-no-auth`
`rclone rc options/set --json '{"filter": {"IncludeRule": ["*.jpg"]}}'`
{}

`rclone rc operations/list fs="" remote=/tmp | grep Path`
“Path”: “/tmp/pic.jpg”,
“Path”: “/tmp/pic.png”,

The expected result should be just the jpg file.
Discussion
- What is happening here is that the filter options are being set, but they aren't being implemented.

To implement, this needs to be called.

    	filter.Active, err = filter.NewFilter(&filterflags.Opt)

Here is a beta with that fix - can you give it a go?
