Title

[useFieldArray] validation does not work properly on append/remove

Description
**Describe the bug**
When using `useFieldArray` and upon removal of one or many fields, the existing errors are not being removed from the validation.

**To Reproduce**
Steps to reproduce the behavior:
1. Go to the sandbox link below and change the number value to -1. You will see that this field has an error.
2. Delete this input by clicking on the "DELETE" button.
3. Add a new field by clicking on the "APPEND NESTED" button.

You will see that the error is still there.
Same test can be done with several fields in error.

**Codesandbox link (Required)**
[URL]

**Expected behavior**
The form should revalidate when an item is removed from the fields array and get rid of the errors that point to non existing items.

**Screenshots**

**Desktop (please complete the following information):**
 - OS: MacOS
 - Browser chrome
 - Version 83.0.4103.116 (Official Build) (64-bit)

**Additional context**
Tested in v5.7.2 and v6.0.6
