Send email using smtp caused infinite loop

Description
Hi,

The problem is caused by file: \system\libraries\Email.php, function _send_data($data)

```
for ($written = 0, $length = strlen($data); $written  _smtp_connect, substr($data, $written))) === FALSE)
    {

}
```
