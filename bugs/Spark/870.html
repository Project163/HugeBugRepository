Discussion
- I did a little digging hoping to find some post about this, no particular luck. I did find  this post  which recommends using an interval time < pause, which we are not doing. This doesn't seem to explain the services all timing out after the heartbeat interval time (which is currently 1000 seconds), but may be good to know in the future.

- I have similar problem in YARN-client mode. Setting spark.akka.heartbeat.interval to 100 fixes the problem.
