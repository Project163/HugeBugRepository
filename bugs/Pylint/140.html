Title

Incorrect "redundant keyword arg"

Description
Originally reported by: **Antony Lee (BitBucket: [Link: anntzer], GitHub: @anntzer?)**

---

```
class C:
    attr = 0
    def __str__(self):
        return "{self.attr}".format(self=self)
```

(this example is of course silly but you can imagine passing more keyword arguments to `.format`)

Pylinting incorrectly indicates an **error**:

```
C:  1, 0: Invalid class name "C" (invalid-name)
E:  5,15: Argument 'self' passed by position and keyword in method call (redundant-keyword-arg)
R:  1, 0: Too few public methods (0/2) (too-few-public-methods)
```
