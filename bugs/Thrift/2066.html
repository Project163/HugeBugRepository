In the screenshot you provided, the path to lib\jsdoc\fs.js includes the string nodev6. That makes me wonder if you're trying to run JSDoc with Node.js 6.x, not 10.15.3. 

 If so, that would explain the error, because fs.copyFileSync() was added in Node.js 8.5.0. That's one reason why JSDoc 3.6.3 requires Node.js >=8.15.0.
