Title

`mr` replaces the wrong character on the right-hand side

Description
This was probably caused by the fix for #543.
### Reproduction steps
1. Position the cursor within a surround, such as between the parentheses in: `This is (some) text.`
2. Type `mr([` (or a variant).
3. The text becomes `This is [som]) text.`. The left parenthesis was replaced, but the `e` to the left of the right parenthesis was replaced instead of the parenthesis itself. Likewise, any usage of `mr` replaces the character to the left of the character it should replace on the right-hand side.
