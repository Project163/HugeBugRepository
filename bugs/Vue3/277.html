Title

Dynamic template ref name doesn't work since 3.2.25 version

Description
### Version
3.2.25

### Reproduction link
[Link: sfc.vuejs.org/]







### Steps to reproduce
1. Open link to [Link: SFC Playground].

2. Change version of vue to 2.2.25

3. Open console,  you will see that refs values have undefined value

```
input 1: undefined
input 2: undefined
```

4. Change version to 2.2.24, in console you will see that `input1` and `input2` values contain html element

```
input 1:  ​
input 2:  ​
```

### What is expected?
Dynamic template ref names should work as before.

### What is actually happening?
Dynamic template ref (with dynamic name) stopped work since 3.2.25 version
