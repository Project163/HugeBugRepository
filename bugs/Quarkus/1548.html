Title

DEV UI not working with nosniff http header

Description
### Describe the bug

If the _quarkus.http.header."X-Content-Type-Options".value_ set to nosniff the DEV UI will be not rendered. 

### Expected behavior

It should be as html rendered.

### Actual behavior

It shows plain html text. 

### How to Reproduce?

Set application property
`quarkus.http.header."X-Content-Type-Options".value = nosniff`
