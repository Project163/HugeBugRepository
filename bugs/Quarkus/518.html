Title

Slow startup with liquibase extension

Description
**Describe the bug**
I added the liquibase extension to my project.
I have not written any big migrations yet, I just wanted to try and start with the extension present.
My startup time is immediatly around 2.5 seconds worse than without liquibase.

**Expected behavior**
No big impact from just having liquibase extension present.
It is not doing any migrations.
I would understand if it took some time to do migrations. But in this example no migrations are present.

**Actual behavior**
Startup time is 2.5 seconds slower with liquibase present

**To Reproduce**
Steps to reproduce the behavior:
1. Download the reproducer: 
[Link: code-with-quarkus.zip]

2. Start the dev mode.
3. It should say ".. started in 3s"
4. Now, add the "quarkus-liquibase" extension
5. Start devmode
6. It says ".. started in 6s"

**Configuration**
```properties
quarkus.datasource.url=jdbc:h2:tcp://localhost/mem:default
quarkus.datasource.driver=org.h2.Driver
quarkus.datasource.username=username-default
quarkus.datasource.min-size=3
quarkus.datasource.max-size=13
```
