Title

d3.svg.area evaluates the x-accessor twice per element.

Description
This is because it reuses `d3_svg_linePoints` internally:

``` javascript
"M" + interpolator(d3_svg_linePoints(this, d, x, y1), tension) +
"L" + interpolator(d3_svg_linePoints(this, d, x, y0).reverse(), tension)
```

It would be better to evaluate `x`, `y0` and `y1` simultaneously for each element, exactly once. This is considered a bug because the behavior of each accessor should be allowed to be nondeterministic (e.g., a random number generator), and thus evaluating an accessor twice produces invalid results. Also, the order of evaluation should be consistent.
