Title

Running from archive still downloads scripts from the internet

Description
When you have something like 

```js
import faker from 'cdnjs.com/libraries/Faker'
```
k6 will load it from `[URL] and than put it in the archive when you run `k6 archive`. The problem is that then when you `k6 run archive.tar` it will still go get it from the url.
