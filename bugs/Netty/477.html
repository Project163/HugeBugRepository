Title

Spaces in WebSocket URIs not handled correctly

Description
Websocket connections to URIs that have spaces in the path can not be established in Netty 4.0.21.

The problematic code seams to be [Link: this line]. If the URI contains a space encoded as %20, the [Link: getPath] Method decodes this back to a normal space. This decoded space is then send in the HTTP request at some deeper layer without properly reencoding it.
