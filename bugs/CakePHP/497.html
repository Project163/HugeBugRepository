Title

CakePHP 3: Problems with Bake

Description
Hi there,

A freshly baked table class for a "User" model looks like this:

```
/**
* Default validation rules.
*
* @param \Cake\Validation\Validator $validator
* @return \Cake\Validation\Validator
... [Log Snipped] ...
        return $validator;
    }
```

Obviously, the semicolon after `->allowEmpty('email');` should be on the last row.

Moreover, when baking a fresh app with `User` belongsToMany `Project`, CakePHP lists the joinTable in the contain-config for the view-action:

```
public function view($id = null) {
    $user = $this->Users->get($id, [
        'contain' => ['Projects', 'ProjectsUsers']
    ]);
    $this->set('user', $user);
}
```

This causes the following exception when accessing the view-action:
`Users is not associated with ProjectsUsers`
`Error: An Internal Error Has Occurred.`

N.B.: interestingly, the joinTable is only added to the contain-config in the view-action of the UsersController, not to that of the ProjectsController.

So - either, the joinTable should not be part of the contain-config, or additional relationships need to be set-up between entities and joinTables.

Loving CakePHP 3 - I just thought I'd point it out! :-)
