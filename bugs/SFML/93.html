Title

Only lowercase keypresses are handled on Linux

Description
In [Link: WindowImplX11.cpp] function "_keysymToSF(xcb_keysym_t symbol)_" handles only lowercase KeySym's(XK_a, XK_b, e.t.c.). 
This causes SFML to generate sf::Keyboard::Unknown keycodes in button events when CapsLock and/or L/RShift is pressed.
As of [Link: Xlib manual] uppercase presses are generated too and they should be handled as XK_A, XK_B, e.t.c.

I'm running Linux 3.19.0-33-generic Ubuntu-14.04.1 i686
