Title

Callbacks not run on empty fields in some situations

Description
Using latest stable CI3 version this code does not run the validation callback if the `image` field is empty:

```
$this->form_validation->set_rules('image', 'Image', [
    'trim',
    [
        'upload_image',
        [$this, 'upload_image']
    ]
]);
```

This format does:

```
$this->form_validation->set_rules('image', 'Image', [
    'trim',
    function($value) {
        $this->upload_image();
    }
]);
```
Discussion
- I can't think of a situation where having an anonymous function without an error label (example 2) is useful? There is no way to set an error message without using example 1, but I guess this is just by design given you are looking for things that are callable.

Just a thought, but would this syntax be cleaner for assigning a label to a function?

```
$this->form_validation->set_rules('image', 'Image', [
    'trim',
    'label' => function($value) {
        $this->upload_image();
    }
]);
```
- It's not necessarily a validation function ... it could modify the input as well (e.g. like `trim()`). As for the alternative syntax - sure, it's nice, but we already use the other one and this library is becoming a maintenance hell as it is. Introducing another one doesn't really bring any benefit other than being "nice".
