Title

`valid-jsdoc` test does not recognize aliases for `@param`

Description
According to [URL] both `@arg` and `@argument` are aliases for `@param`.
- eslint v.1.1.0 
  - running via grunt-eslint 17.1.0

These fail under the test `valid-jsdoc`:

```
/**
 * @arg {Object} model - The model received from the server.
 */

/**
 * @argument {Object} model - The model received from the server.
 */
```

This passes:

```
/**
 * @param {Object} model - The model received from the server.
 */
```

This cannot be mapped in "prefer" because the aliases aren't acceptable to begin with.
Discussion
- Can you provide eslint output for the failed test?
- Given this jsdoc comment:

```
    /**
     * Matches the JSONAPI relationship link to the included relations.
     * @arg {Object} link - The type and id of the included resource.
     * @returns {Object} The resource corresponding to the type and id in the link.
     * @private
     */
```

It produces this output:

```
53:5  error    Missing JSDoc for parameter 'link'  valid-jsdoc
```
