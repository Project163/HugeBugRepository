Title

Disable materialized view rewriting when plan pattern is not allowed

Description
For instance, currently rewriting algorithm does not support some operators. Or we cannot have non-deterministic function in the MV definition. In those cases, we should fail either when we try to create the MV with rewriting enabled, or when when we enable the rewriting for a MV already created.
