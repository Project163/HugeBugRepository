Title

Malformed URLs in the API git/commits end point for trees

Description
In 1.9-rc2 (and 1.10-dev):

In a the response for the `[URL] there are a bad URLs, one for the HTML Url, the other for the trees URL. Example:

```
{
  ...
  "html_url": "[URL]
  ...
  "tree": {
... [Log Snipped] ...
  ...
}
```

It should be `commit` and not `commits, `/git/trees` not just `/trees`, respectively.
