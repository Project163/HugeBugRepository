Title

Certificates with unsupported public key algorithms trigger assertion

Description
The following certificate, which I believe was generated with wolfSSL/CyaSSL, uses the NTRU lattice-based public-key cryptosystem. Since this is probably not supported by most builds of OpenSSL, it triggers an assertion error at [Link: x509.py:263] upon calling `cryptography.x509.Certificate.public_key()` because the OpenSSL function `X509_get_pubkey()` returns NULL.

Not sure if this an actual bug or not, but reporting nonetheless.
