Title

AbstractMemoryHttpData performance issue when adding many buffers

Description
Ad the moment we use a DefaultCompositeByteBuf with maxNumComponents of 16 in AbstractMemoryHttpData to store the added ByteBufs. 

Unfortunately this is a bad default value for this use case which lead to heavy memory copies. We should Integer.MAX_VALUE here.
