Title

AioCompletionHandler's stackoverflow detection may cause callback to never get executed

Description
While working on #1091 I noticed a problem in our AioCompletionHandler's stackoverflow detection and handling. And I think this is also the problem that we saw on osx when using AIO (like close never returned).

The problem is that we just check if the max stack size is reached and if so return without call the AioCompletionHandler's protected methods. This can lead to not get notified of an event. 

To fix this we need to add the a task that runs the internal methods on the beginning of the taskqueue of AioEventLoop. This will break the recursion but still prevent the right order.
