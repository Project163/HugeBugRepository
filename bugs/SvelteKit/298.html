Title

Netlify Identity not working when using Edge Functions

Description
### Describe the bug

When using `adapter-netlify` and enabling the experimental Edge Functions, Netlify Identity doesn't work. The `[URL] path gets a 404 from SvelteKit, but it should be handled by Netlify (or at least I think so).

Using the adapter without the Edge Functions enabled doesn't break Netlify Identity.

### Reproduction

[Link: Stackblitz fork].

1. Create a project on Netlify.
2. Enable [Link: Identity] and [Link: Git Gateway].
3. Try to login at /admin (or invite yourself and try to accept the invite)
