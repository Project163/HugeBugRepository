Title

stax outTransform may generate duplicate namespace declarations for global attributes

Description
This problem depends on how namespaces are declared for global attributes and when it occurs, the transformed output will contain a duplicate namespace declaration. 

 Concretely, the outTransform feature transforms the input: 
  <soap:Header> 
    <Action xmlns="[URL] href="[URL] class="external-link" target="_blank" rel="nofollow noopener">[URL]
    <customer:CustomerKey xmlns="[URL] xmlns:customer="[URL] xmlns:wsa="[URL] wsa:IsReferenceParameter="1">Key#123456789</customer:CustomerKey> 

 into the non-wellformed output containing a duplicate namespace declaration for wsa: 
  <soap:Header> 
    <Action xmlns="[URL] href="[URL] class="external-link" target="_blank" rel="nofollow noopener">[URL]
   <customer:CustomerKey xmlns="[URL] xmlns:customer="[URL] xmlns:wsa="[URL] xmlns:wsa="[URL]  wsa:IsReferenceParameter="1">Key#123456789</customer:CustomerKey>
