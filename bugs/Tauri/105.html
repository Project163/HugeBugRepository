Title

CLI does not download with `HTTPS_PROXY`.

Description
### **Describe the bug**
When `HTTPS_PROXY` is set, `tauri init` does not successfully use the value. This can make the download of the Rust CLI fail, and therefore the entire `tauri init` fails.

### **To Reproduce**
Steps to reproduce the behavior:
1. Have a `HTTPS_PROXY`
2. Download the Rust CLI through `tauri init`
3. Notice that the Rust CLI fails to download through `tauri init` when needing to use `HTTPS_PROXY`
4. `tauri init` hangs :(

### **Expected behavior**
The CLI sucessfully downloads and installs like typical usages of `tauri init`.
