Title

sf::Window::setSize does not Resize Window without sf::Style::Resize Flag

Description
If a sf::Window (or sf::RenderWindow) is created without the sf::Style::Resize flag, sf::Window::setSize does not change the size of the window. This is confirmed to happen in Linux / Mate desktop environment, both in SFML 2.0 and SFML 2.1. See pertinent thread here: [URL]
