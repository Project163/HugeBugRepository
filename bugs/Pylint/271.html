Title

False 'bad-python3-import' with `import turtle`

Description
### Steps to reproduce
1. Create test.py with `import turtle` or `from turtle import forward`. Script may include also usage of imported names.
2. Check it with `pylint --enable=bad-python3-import test.py`

### Current behavior
Output includes `W1648: Module moved in Python 3 (bad-python3-import)`

### Expected behavior
Should not emit bad-python3-import as the module is actually present (and has same name both in Python 2 and Python 3).
