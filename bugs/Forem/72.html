Title

bug: Very wide code blocks overflow in comment preview

Description
**Describe the bug**

The comment preview with a code block that is very wide overflows.

**To Reproduce**

Example code block:
```
js
function square(value) {
  if (value === 4) {
    return 4 + 4 + 4 + 4;
  }
... [Log Snipped] ...
  }
}
```

1. Go on an article
2. Copy in a comment the example code block above inside a markdown code block
3. Check out the comment preview
4. Notice it overflows

**Expected behavior**

It scrolls horizontally just like it does once the comment is posted.
