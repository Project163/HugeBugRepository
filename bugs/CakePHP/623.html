Title

3.0 Query "first()" does not work after setting "bufferResults(false)"

Description
This works:

```
$query = $clubs->find()->where(['id' => 1]);
$club = $query->first();
```

This does not:

```
$query = $clubs->find()->where(['id' => 1]);
$query->bufferResults(false);
$club = $query->first();
```

$club is null in that second example. Something to do with ResultSet->valid() getting called twice, but I haven't stepped through at a low enough level to follow the logic.
