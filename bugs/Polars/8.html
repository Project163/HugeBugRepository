Title

Passing a `Series` of strings to `np.array` errors

#### Describe your bug.

Passing a `Series` of strings to `np.array` results in `ValueError: could not convert string to float`. Using `to_numpy` is fine workaround, but having this work would make interoperation with some other libraries more convenient.

#### What are the steps to reproduce the behavior?

```python
import polars as pl
import numpy as np

np.array(pl.Series(["one", "two"]))
```

#### What is the actual behavior?

```
---------------------------------------------------------------------------

  in  
----> 1 np.array(pl.Series(["one", "two"]))

... [Log Snipped] ...

```

```
python
In [116]: np.array(["one", "two"]).__array__()

    return self.to_numpy().__array__(*args)
```

to reproduce numpy's behavior exactly, or maybe:

```python
def __array__(self, dtype: Any = None) -> np.ndarray:
    arr = self.to_numpy()
    return arr.__array__(arr.dtype if dtype is None else dtype)
```

to behave how numpy probably should be behaving here.
