Title

Dict update error

Description
In the following example:

```
d = {}  # type: Dict[str, Optional[int]]
d.update({str(i): None for i in range(4)})
```

The second line yields the following error: `Argument 1 to "update" of "dict" has incompatible type Dict[str, None]; expected union type (2 items)`

The function is stubbed as

```
def update(self, m: Union[Mapping[_KT, _VT], Iterable[Tuple[_KT, _VT]]]) -> None: ...
```

but the dict comprehension has inferred type `Dict[str, None]`.
Discussion
- Hmm... This feels like one of the effects of `None` not being a real value in mypy. E.g. just this gives an error:

```
d = {'': None} # E: Need type annotation for variable
```
- it may also have to do with covariance because the following also errors:

```
e = {}  # type: Dict[str, Union[int, str]]
e.update({str(i): i for i in range(4)})  # error: Argument 1 to "update" of "dict" has incompatible type Dict[str, int]; expected "Union[Mapping[...], Iterable[...]]"
```
