Title

Cannot change default delimiters in mustache search templates

Description
### Elasticsearch Version

8.7.0

### Problem Description

If a search template changes the default mustache delimiter using `{{=`, rendering the template will fail with a `MustacheException`, `Disallowed: changing defaul delimiters`.



### Steps to Reproduce

```
PUT _scripts/test_search_template
{
  "script": {
    "lang": "mustache",
    "source": """
... [Log Snipped] ...
  }
}
```

```
POST _render/template
{
  "id": "test_search_template",
  "params": {
    "query_string": "test"
  }
}
```

Result:
```
{
  "error": {
    "root_cause": [
      {
        "type": "script_exception",
... [Log Snipped] ...
  "status": 400
}
```

This was changed when switching to `SafeMustacheFactory` in [URL] which sets [Link: `allowChangingDelimeters`] to `false`.
