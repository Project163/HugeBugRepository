Title

JobRetrievalITCase.testJobRetrieval() does not forward exceptions to parent thread.

Description
The mentioned test seems to fail frequently, without being detected, because the Assert.fail() is called in a separate thread which doesn't forward exceptions.

		 What is the purpose of the change 
	 
	 
 

     This PR contains 2 changes to the `JobRetrievalITCase`. 

     1) We now store exceptions that occur in the submitting thread in a `AtomicReference` that we evaluate at the end of the test. 

     2) It could happen that the lock (preventing the job from terminating) was released before the client had a chance to finish the retrieval. To remedy this we now only release the lock if the thread has terminated, either by successfully connecting or failing with an error.
