Title

Error when creating a functional index with columns after function expressions

Description
When creating a functional index, an error occurs if there are any non-functional expressions found after a function. Using SQLAlchemy 1.3.6.

Sample code:

```
python
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy import create_engine, Column, Integer, String, Index, func

engine = create_engine('sqlite:///:memory:', echo=True)
... [Log Snipped] ...

Base.metadata.create_all(engine)
```

Throws an error:

```
Traceback (most recent call last):
  File "temp.py", line 16, in  
    Base.metadata.create_all(engine)
  File "/home/jmabey/Code/bug/env/lib/python3.7/site-packages/sqlalchemy/sql/schema.py", line 4287, in create_all
    ddl.SchemaGenerator, self, checkfirst=checkfirst, tables=tables
... [Log Snipped] ...
    return obj._compiler_dispatch(self, **kwargs)
AttributeError: 'NoneType' object has no attribute '_compiler_dispatch'
```

With PostgreSQL, it throws a similar error:

```
Traceback (most recent call last):
  File "temp.py", line 24, in  
    Base.metadata.create_all(engine)
  File "/home/jmabey/Code/bug/env/lib/python3.7/site-packages/sqlalchemy/sql/schema.py", line 4287, in create_all
    ddl.SchemaGenerator, self, checkfirst=checkfirst, tables=tables
... [Log Snipped] ...
    for expr in index.expressions
AttributeError: 'NoneType' object has no attribute 'self_group'
```

If I reorder the index to `Index('users_idx', 'value', func.lower('name'))`, then it works fine.
Discussion
- so your DDL isn't going to produce what you want in any case, because you can't feed the string "name" into`func.lower()` and expect it to be interpreted as a column, it will be interpreted as the literal string "name".   For the DDL you probably want you have to make the Index after the column is available:
```

class User(Base):
    __tablename__ = 'users'

    id = Column(Integer, primary_key=True)
    name = Column(String)
    value = Column(String)

    __table_args__ = (Index('users_idx', func.lower(name), value),)

```

**Ensure all Index arguments are counted when matching expr/columns** [URL]
- **Mike Bayer** has proposed a fix for this issue in the **rel_1_3** branch:

**Ensure all Index arguments are counted when matching expr/columns** [URL]
