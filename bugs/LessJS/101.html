Title

Circular Imports cause Less not to complete

Description
Prior to the 1.4 change which made import-once the default behaviour, you could import files with circular imports fine (if you used `@import-once`).  Since the 1.4 change, this no longer works - lessc just fails to complete as it goes through the loop.

Test Files:

**a.less:**

``` less
@import "b.less";
```

**b.less:**

``` less
@import "a.less";
```

**Command to run:**

```
lessc a.less
```

I'm not sure if this is intended behaviour now, but the behaviour of `@import` is not the same as `@import-once` once was.  Tested using 1.4.2.

If you're wondering why anyone would run this, it's an easy way of getting intellisense to work in Visual Studio for mixins and variables declared in other less files.
