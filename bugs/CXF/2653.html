Title

Support newer symmetric signature algorithms with WS-SecurityPolicy

Description
This task is to support using symmetric signature algorithms other than the default (HMAC-SHA1) with WS-SecurityPolicy.
Discussion
- The WS I'm trying to write a client for requires SHA-256 to be used not only for the signature algorithm, but also for references (according to feedback I've finally received from the developers of the WS). 

 Currently CXF 3.1.3 uses SHA-1 for references, regardless of the algorithm-settings for the signatures. Is there a way to force it to use SHA-256 for references as well?
- You can set the digest algorithms via WS-SecurityPolicy AlgorithmSuite policy. For example, "Basic256Sha256" should result in SHA-256 being used to digest the references.
