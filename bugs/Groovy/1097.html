Title

GroovyConsole AST Viewer does find AstBrowserProperties.groovy, so nodes have bad node names

Description
GroovyConsole AST Viewer does find AstBrowserProperties.groovy, so nodes have bad node names.  
That properties file controls the String representation of nodes in the viewer tree.  
It finds the prop file in /user/home/.groovy but not the default on.  

 However, when I run the unit tests from the command line, the property file is picked up.  

 I tested my local codebase and the nightly build binary, and neither finds the default properties file.  

 Is this happening for non-Windows operating systems?
Discussion
- The problem was that the Properties.groovy file was being opened as a File instead of a URL. Since the file was in a JAR, it must be opened as URL. Simple fix once I discovered issue.
