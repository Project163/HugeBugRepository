Title

svelte.config.js does not allow vitePlugin section

Description
### Describe the bug

```
/** @type {import('@sveltejs/kit').Config} */
const config = {
...
  vitePlugin: {
    experimental: {
... [Log Snipped] ...
  },
};
```

leads to Typescript complaining `Object literal may only specify known properties, and 'vitePlugin' does not exist in type 'Config'`. This change hides the error:

```
/** @type {import('@sveltejs/kit').Config & {vitePlugin: unknown}} */
```

Related, the documentation at [URL] is wrong and is missing the `vitePlugin` level in the config.
