Title

interface extends interface and uses static field in default method

Description
Consider the following: 
  
 
 interface  I {
   String  FOO =  'foo' 
}
 interface  J  extends  I {
   default   String  dm() {
    FOO +  'bar' 
  }
}
 class  C  implements  J {
   def  m() {
    dm() +  'baz' 
  }
}

 assert   new  C().m() ==  'foobarbaz'
