Title

Resource path is missing a trailing slash when loading resources with RunnerClassLoader

Description
### Describe the bug

I want to load classes as resources from the class loader and For that I am reusing `org.springframework.core.io.support.PathMatchingResourcePatternResolver`. 

Unfortunately when using the one of the production classloader of Quarkus, the RunnerClassLoader, this latter do not manage to load the resource effectively, as opposed to the System classloader or the dev mode QuarkusClassLoader.

When loading a path resource, the classloader is stripping the last `\` from the resource, i.e: 

When loading the path org/acme/ with RunnerClassLoader :
```shell
URL [jar:file:/User/Projects/Support/Misc/Quarkus/resolver-issue/target/quarkus-app/app/resolver-issue-1.0.0-SNAPSHOT.jar!/org/acme]
```

And when loading the same path with QuarkusClassLoader

```shell
URL [file:/User/Projects/Support/Misc/Quarkus/resolver-issue/target/classes/org/acme/]
```

A typical identical issue has been reported and fixed some years ago on the QuarkusClassLoader, see: [URL]

### Expected behavior

Trailing slash is not stripped out so that I can find my resource to the correct location

### Actual behavior

Trailing slash is removed making the computation of relative resources wrong.
