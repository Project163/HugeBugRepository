Title

`RequestEvent` not generated for a route with a `+layout.server.ts` but no `+page.server.ts`

Description
### Describe the bug

The route-specific `RequestEvent` (i.e. with the route params)  is not added to `./$types.d` when `+layout,server.ts` exists but there is no `+page.server.ts`. 

Pretty sure this is not the correct behavior. 

This happens even if the route has URL params.

### Reproduction

[URL]

```bash
git clone [URL]
cd sk-issue-no-request-event-wo-page-server
npm i 
npm run dev
```

Look at `src/routes/bad/+layout.server.ts`. You should see this:

  3.50.1 
    vite: ^3.1.0 => 3.1.3
```
