Title

API + UI device last seen is empty/Never

Description
### Version Information

Syncthing Version: v1.3.1
OS Version: multiple, Linux 32bit, Android 64bit
Browser Version: (if applicable, for GUI issues)

Starting with v1.3.1 the API endpoint /stats/device returns an empty JSON object.

This leads to the UI showing "Never" as the "Last connected" time.

I'm seeing this on three of my devices already updated, user "yeti" in IRC has confirmed that this is happening for him/her too.

## Steps to reproduce
1. connect two syncthing instances running v1.3.1
2. stop one instance
3. check the UI or API on the other instance
