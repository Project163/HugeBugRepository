Title

URLValidator fails validating domain names with a trailing period, which are valid.

Description
The Apache Commons class org.apache.commons.validator.routines.UrlValidator method isValid() fails on URLS where the hostname has a trailing period, like "[URL]

 A trailing period on the hostname part of the URL is valid according to  [URL] and ANY URL I try does work successfully even when I put a trailing dot on the end of the domain name. 

 Can you add a fix in for this, so I can still use the URLValidator? 

 Thanks, 
-Alex
