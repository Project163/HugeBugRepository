Title

lambda uses vars as objects.

Description
I was playing with some maps and lambdas, and I found this (I think) error:

``` python
from typing import List, Iterator
def f(x: List[List[int]]) -> Iterator[List[int]]:
    return map(lambda y: [y[1], y[0]], x)

f([[1,2], [2,3]])
```

The error is:

```
errors.py: In function "f":
errors.py, line 7: Value of type object is not indexable
```
Discussion
- Good catch!

This might be related to some of the other type inference related bugs.
