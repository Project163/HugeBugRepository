Title

TypeError when calling raw_connection() on engine instance with mysql+pyodbc dialect

Description
### Describe the bug

Getting the following error when calling `raw_connection()` on engine instance when using `mysql+pyodbc` dialect:

`TypeError: MySQLDialect._fetch_setting() missing 1 required positional argument: 'setting_name'`

Looks like the `connection` parameter is not being passed in [Link: sqlalchemy/dialects/mysql/pyodbc.py line 92].

Probable one liner fix:
In [Link: sqlalchemy/dialects/mysql/pyodbc.py line 92] needs to be changed
from: `            value = self._fetch_setting("character_set_client")`
to: `            value = self._fetch_setting(connection, "character_set_client")`



### To Reproduce

```python
from sqlalchemy import create_engine

engine = create_engine('mysql+pyodbc:// : @ / ?driver=MySQL+ODBC+8.0+Unicode+Driver')

engine.raw_connection()
```
