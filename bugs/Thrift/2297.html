Discussion
- The  Tornado 5.1 docs  say that  @gen.engine  has been 

  Deprecated since version 5.1: This decorator will be removed in 6.0. Use    coroutine    or {{ async def }} instead.  

 and accordingly,  @gen.engine  is missing in the  Tornado 6.0+ docs . 

 So we have two options (as described by the deprecation notice): 
 
	 Replace  @gen.engine def  with  @gen.coroutine def . The fix is as simple as replacing it on  this line , the only usage. 
	 Replace  @gen.engine def  with  async def . This seems more complicated in terms of adding  async / await  everywhere. 
 

 I prefer #1 as the fix because it's more straightforward, and I've fixed and tested the tutorial this way. I can make a PR.
