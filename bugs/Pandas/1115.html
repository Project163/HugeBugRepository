Discussion
- Using a Series instead of a list seems to work:

```
In [28]: a = pd.DataFrame([[1,2,3],[4,5,6]])

In [29]: a.clip(lower=pd.Series([1.5,2.5,3.5]), axis=1)
Out[29]: 
     0    1    2
0  1.5  2.5  3.5
1  4.0  5.0  6.0
```

With an array instead of list, it also gives the error.

So given the docs (which say it can be 'array-like'), this is a bug. Or otherwise the docs in not correct.
