Title

Don't skip corrupt sstables on startup

Description
If we get an IOException when opening an sstable on startup, we just  skip  it and continue starting 

 we should use the DiskFailurePolicy and never explicitly catch an IOException here
Discussion
- Patch to catch IOExceptions and rethrow them as CorruptSSTableExceptions - if we get an IOException when opening an sstable, it should be considered corrupt
