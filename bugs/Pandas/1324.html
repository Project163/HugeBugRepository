Title

BUG: TypeError when trying to group on column name and index level at the same time

Description
- [x] I have checked that this issue has not already been reported.

- [x] I have confirmed this bug exists on the latest version of pandas.

- [ ] (optional) I have confirmed this bug exists on the master branch of pandas.

---

#### Code Sample, a copy-pastable example

```
python
import pandas

df = pandas.DataFrame({"col1": ["a", "b", "c"]})
df.groupby("col1", level=0)  # Fine
... [Log Snipped] ...
df.groupby(["col1", "x"]) # Fine
df.groupby("col1", level=0)  # TypeError
```

#### Problem description

Getting a TypeError when specifying `by` and `level` params in `.groupby()` at the same time. It seems that grouping on column name and index level is supported since there is no error when level name is located in `by` parameter, so specifying it with `level` should also be possible.

Discussion
- Doing

    df = DataFrame({"col1": [1, 2, 3]}, index=[1, 1, 2])
    print(df.groupby(level=0).sum())
    print(df.groupby("col1", level=0).sum())

each line produces the same output, so while the groupby construction works, the result is not correct. I don't see a compelling reason this should be supported. Instead, it seems to me the docstring should be updated to specify that both `by` and `level` should not be specified, and the corresponding argument validation should be done in groupby.
