Title

camel-jbang - k8s delete may not work any more

Description
$ camel kubernetes delete timer-log
Deleting all resources from app: timer-log
No deployment found with name: timer-log

$ kubectl get deployment           
NAME        READY   UP-TO-DATE   AVAILABLE   AGE
keycloak    1/1     1            1           169m
timer-log   1/1     1            1           3m4s
traefik     1/1     1            1           172m
whoami      1/1     1            1           172m
Discussion
- Also, there seems to be some redundancy with the labels 

  
 
app=platform-http
app.kubernetes.io/managed-by=camel-jbang
app.kubernetes.io/name=platform-http
app.kubernetes.io/part-of=examples
group=examples
provider=jkube
- It turns out that the jkube maven build also adds labels: app, provider, group and version in addition to these  well-known-labels  

 It also turns out, the delete cannot filter on `app.kubernetes.io/managed-by` because that is only set for kubernetes run, which also explains why delete after run still works.
