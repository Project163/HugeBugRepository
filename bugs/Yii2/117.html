Title

PDO exception if username/password params aren't set in db component config

Description
I use Postgres.app for the Mac.

If I don't set username and password in a db component config, I get PDO Exception with message 'SQLSTATE[08006] [7] FATAL:  role "password=" does not exist' in /path/to/project/vendor/yiisoft/yii2/yii/db/Connection.php:317.'. 
Example:
     'db' => [
            'class' => 'yii\db\Connection',
            'dsn' => 'pgsql:host=localhost;port=5432;dbname=mydb;',
            'charset' => 'utf8',
        ],

I use the following solution:
     'db' => [
            'class' => 'yii\db\Connection',
            'dsn' => 'pgsql:host=localhost;port=5432;dbname=mydb;',
            'username' => null,
            'password' => null,
            'charset' => 'utf8',
        ],
Still, I consider it to be not really obvious.

Setting Connection component username and password properties default values to null can solve this problem.
