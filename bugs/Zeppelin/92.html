Title

use HDFS in tutorial notebook so that it works with yarn-client

Description
The Zeppelin tutorial notebook includes example code that downloads some sample data to the local filesystem then performs some simple queries on it. However, this only works when Zeppelin is configured to use Spark in local mode. If Zeppelin is instead configured to use yarn-client deploy mode, the tutorial notebook does not work anymore. This can be fixed by uploading the sample data to HDFS instead of leaving it on the local filesystem.
