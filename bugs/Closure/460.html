Title

crash on recursive function?

Description
What steps will reproduce the problem? 

At [URL] enter the code
---
var walk_the_DOM = function walk(node, aFunction) {
    walk(node, aFunction);
};
var getElementsByAttribute = function(anAttribute, value) {
    walk_the_DOM();
};
var theAttributes = getElementsByAttribute('src');
for(value in theAttributes) {
    document.writeln(value);
}

The compiler will crash with an exception on the walk() call.

23: java.lang.RuntimeException: INTERNAL COMPILER ERROR.
Please report this problem.
Conflicting externs name: {SyntheticVarsDeclar}
  Node: Input_0:2:4
    walk(node, aFunction);
  Parent: Input_0:2:8
    walk(node, aFunction);


There are two separate problems here:
1) is that the compiler is trying to synthesize a variable during sanity 
checking.
2) is that the compiler is trying to synthesize a variable there at all.
