Title

No compile error on count distinct

Description
## Setup

### Versions

- **Rust:** 1.87
- **Diesel:** 2.2.10 (Also diesel_async 0.5.2)
- **Database:** PostgreSQL
- **Operating System:** Linux

### Feature Flags

- **diesel:** "postgres", "chrono", "serde_json", "uuid"

## Problem Description
I expected to see compile time error for a wrong query, but didn't!

### What are you trying to accomplish?
I had a `distinct_on` query and later added a `count` to it. It's wrong, but the code compiles happily!

### What is the expected output?
To see compile time error.

### What is the actual output?
No error at compile time.

### Are you seeing any additional errors?

### Steps to reproduce

I expected to see an error for this.
```
posts::table
        .filter(posts::status.eq(status))
        .distinct_on(posts::user_id)
        .order_by(posts::user_id)
        .count()
        .get_result(conn)
        .await
```

I know the right query is this, that's not the bug report
```
posts::table
        .filter(posts::status.eq(status))
        .select(count_distinct(posts::user_id))
        .get_result(conn)
        .await
```

For reference this produces the following postgres error:

```
ERROR:  column "posts.user_id" must appear in the GROUP BY clause or be used in an aggregate function
```

which just means that we allow to mix aggregate and non-aggregate expressions there. The good news is that we already have existing infrastructure to check for that kind of issue. It should be as simple as adding a `Selection: ValidGrouping ` bound here:
