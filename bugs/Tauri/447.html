Title

[bug] [NSIS] License agreement screen cannot be omitted

Description
### Describe the bug

There seems to be a change from v2-alpha to v2-beta in the NSIS bundler that causes the license agreement screen to be shown (with empty license text field) even if there's no `license` or `licenseFile` file set or set to `null` in [Link: BundleConfig]. I don't see any configurable option in [Link: NsisConfig] either.

In our case we don't want to show the End-user license agreement (EULA) screen as it's a German software product and showing the user the agreement after he bought the product has no legal effect, see [Link: Endbenutzer-Lizenzvertrag].

Translated quote:

### Reproduction

Create a new Tauri v2-beta app and configure a NSIS bundle to be built. Execute the resulting NSIS installer and advance to second screen. License agreement screen is shown with empty license text.

### Expected behavior

If no license and/or license file is set, don't show the license agreement screen. Or give an option in NsisConfig to omit the screen explicitly.
