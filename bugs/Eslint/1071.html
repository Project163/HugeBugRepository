Title

Errors reported by no-useless-escape have invalid locations on multiline template literals

Description
**Tell us about your environment**

* **ESLint Version:** master
* **Node Version:** 7.2.0
* **npm Version:** 3.10.9

**What parser (default, Babel-ESLint, etc.) are you using?**

default

**Please show your full configuration:**

 
```yml
rules:
  no-useless-escape: error
parserOptions:
  ecmaVersion: 6
```

**What did you do? Please include the actual source code causing the issue.**

 
```js
`this is a multiline template literal with
a useless escape \ character`;
```

**What did you expect to happen?**

```
2:18  error  Unnecessary escape character: \   no-useless-escape
```

**What actually happened? Please include the actual, raw output from ESLint.**

```
1:60  error  Unnecessary escape character: \   no-useless-escape
```
Discussion
- While fixing this bug, I noticed another issue: The locations of reported errors in template literals are all off by one.

```yml
rules:
  no-useless-escape: error
parserOptions:
  ecmaVersion: 6
```

```js
`useless\ escape`;
```

```bash
eslint no-useless-escape-test.js --format codeframe
```

**What did you expect to happen?**

```
error: Unnecessary escape character: \  (no-useless-escape) at no-useless-escape-test.js:1:9:
    |         ^
  2 |
```

**What actually happened? Please include the actual, raw output from ESLint.**

```
error: Unnecessary escape character: \  (no-useless-escape) at no-useless-escape-test.js:1:8:
    |        ^
  2 |
```
- Can we quote the cited useless escape while we're at it? Just having `\ ` (unquoted) makes it hard to tell what the problem is.
