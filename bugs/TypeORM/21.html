Discussion
- I'll try to test it and reproduce this issue, however why do you want to have pool disabled? In what case it does make sense for you?
- I found the bug. It is in in `PostgresDriver` `disconnect` method:

<[URL]

This is the offending conditional:

```typescript
            if (this.databaseConnectionPool) {
```

When `usePool` is false, the value of this member variable during disconnect is `[]` (which makes sense). But in JavaScript the empty array evaluates to true. The fix is to change the conditional to:

```typescript
            if (this.pool) {
```
