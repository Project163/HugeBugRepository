Title

Upgrading Next 14.2 broke how dd-trace is compiled and tries to bring in a devDependency of dd-trace

Description
### Link to the code that reproduces this issue

[URL]

### To Reproduce

We have an `instrumentation.ts` file defined in the root with a register function as follows:

```ts
if (process.env.NEXT_RUNTIME === 'nodejs') {
  await import('./instrumentation/tracer');
}
```

Inside of `tracer.ts`

```
import tracer from 'dd-trace';

if (process.env.NODE_ENV === 'production') {
  tracer.init();
}
```

### Current vs. Expected behavior

Previously when running `next dev` there were no build issues at all. Once upgrading to 14.2.0, I now receive these error messages:

```
Module not found: Can't resolve 'graphql/utilities'
```

When I look at `dd-trace` package.json, graphql is listed as a devDependency.
