Title

TestDox printer does not display details about exceptions raised in before-test methods

Description
Since PHPUnit 10, exceptions that are thrown in `setUp` (as opposed to the actual test body) are not displayed although the test is marked as "E", forcing you to write your own try/catch and see what they are. Since setting up _is_ part of the test I don't think why it should be treated differently. Saying there was an error but not explaining what the error was is most unhelpful.
