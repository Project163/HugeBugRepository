Title

torch.device reporting an error as it should when using msnpu

Description
## 🐛 Bug

 

When specifying MSNPU for `torch.device` it throws a RuntimeError inside the C library instead of catching it and raising it as a Python error.

## To Reproduce

Steps to reproduce the behavior:

1. Create a `msnpu` device with `device = torch.device('msnpu')
2. Boom

 

```
---------------------------------------------------------------------------
RuntimeError                              Traceback (most recent call last)
  in  
      3     a = torch.zeros(1, device=device)
      4     print(a)
... [Log Snipped] ...

RuntimeError: p INTERNAL ASSERT FAILED at C:\w\1\s\windows\pytorch\c10/core/impl/DeviceGuardImplInterface.h:213, please report a bug to PyTorch. DeviceGuardImpl for msnpu is not available
```

## Expected behavior

 

It ought have thrown something like this:

```
RuntimeError: CUDA error: invalid device ordinal
```
