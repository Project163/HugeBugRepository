Title

Inconsistency between code and comment of method Result#as(String)

Description
### Play Version (2.5.x / etc)

2.6.x, 2.7.0

### API (Scala / Java / Neither / Both)

Both

### Expected Behavior

According to the JavaDoc of Result#as(String), it should _return a copy of the result with a different Content-Type header._ (Java version). 

Two alternatives :
* it is expected that the ```session``` and the ```flash``` objects are copied from the original Result instance. That means the constructor ```Result(ResponseHeader, HttpEntity, Session, Flash, List )``` should be called.
* the comment of the method should be rewritten by explicitly declaring that only the headers and the body are copied.

### Actual Behavior

The ```session``` and the ```flash``` objects are dropped because the constructor ```Result(ResponseHeader, HttpEntity)``` is called.
