Title

The default retry policy does not handle RetriableException correctly

Description
The default policy in RetryUtils does not retry RetriableExceptions even when  defaultRetryPolicyEnabled  is true. 

 This was discovered via an HDFS client failing to retry  getFileBlockLocations  after  checkNNStartup  failed.
Discussion
- Effectively a regression since 2.6, although 2.6 was broken differently. 

 One way to fix it is have checkNNState throw RetriableException and also fix the default retry policy.
- Patch for Jenkins run. Needs a test case.
