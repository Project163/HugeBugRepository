Title

Requirement checker for IPv6 gives false warning

Description
### What steps will reproduce the problem?

Run the Yii2 requirement checker without the [Link: PHP sockets] extension.

### What is the expected result?

The Yii requirement checker should not issue a warning about missing IPv6 support.

### What do you get instead?

A warning about potentially missing IPv6 support.

### Additional info

It checks if the `AF_INET6` constant is defined. This probably comes from this comment: [URL]

But this is wrong: `AF_INET6` [Link: is part] of the mentioned socket extension. But this extension is not required for IPv6 validation (also see #13976).

I think, the requirement checker should instead just call `inet_pton()` with a predefined value and compare the result to the expected output.
