Title

TypeScript: Generated Enums are quoted

Description
Currently the generated enums looks like: 
  
  enum  Foo {
    'A'  = 0,
    'B' =1,
    'C' =2
}
 
  
 And they should be: 
  
  enum  Foo {
   A = 0,
   B = 1,
   C = 2
}
 
  

 With this change WebStorm is able to autofill the values of the enum.
