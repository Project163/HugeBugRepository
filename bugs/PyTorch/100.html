Title

A Segmentation Fault can be trigerred in torch._euclidean_dist

Description
### 🐛 Describe the bug

A **Segmentation Fault** can be trigerred in `torch._euclidean_dist` with the following code:
````python
import torch
x1 = torch.rand([1, 1, 1], dtype=torch.float32)
x2 = torch.rand([0, 12,  ], dtype=torch.float32)
res = torch._euclidean_dist(
    x1=x1,
    x2=x2,
)
````
Output:
````
Segmentation fault (core dumped)
````
