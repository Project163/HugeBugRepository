Title

auto_link issue with domain type email

Description
I noticed a problem with auto_link the other day and so tested this on a fresh install of CI 3.1.6 to make sure its not of my own doing. The install has nothing but the following code added to welcome.php

```
 load->helper('url');  
        $string = "this is some text that includes www.email@domain.com which is causing an issue";
        echo auto_link($string);
?>
```

if a user adds text that includes an email that is in the following format and we then use auto link on this 

`this is some text that includes www.email@domain.com which is causing an issue`

the output goes something like this
