Title

Bug: brace-style

Description
Brace-style will mark the following code as warning:

```
if (a &&
b &&
a === b) {
...
}
```

Because opening brace is on the different line then block identifier. Same applies to `functions` with many parameters, where each parameter is on a separate line.
