Title

//src/test/shell/bazel:bazel_bootstrap_distfile_test TIMEOUT flaky

Description
see [URL]

We have timeouts of `//src/test/shell/bazel:bazel_bootstrap_distfile_test` on darwin and freebsd.

The timeout is 3600s; on linux the test passes in 697s, on ubuntu in 489s, and on Windows in 534s. It should be noted that the test runs in parallel with other tests, and the `compile.sh` in the test actions schedules resources as if it had the full machine. So it might be worth marking the test as `exclusive` or change the options in the bootstrapping.
