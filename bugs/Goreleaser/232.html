Title

Goreleaser picks wrong tag if two tags point to same commit

Description
### What happened?

I have a release tagged `v1.22.1-rc1` as a prerelease. After testing and confirming it was ready for release, I tagged it as `v1.22.1`. But goreleaser decided that v1.22.1-rc1 was the "latest" tag and built that instead:

```
    • building...                                    commit=  latest tag=v1.22.1-rc1
```

Potentially related, there's a clearly incorrect warning that we're running an older version of goreleaser:
```
running goreleaser v1.18.2-pro (outdated, latest is v1.18.1-pro)
```
