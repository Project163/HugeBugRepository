 As the exception indicates when we try to connect to Postgres the database is not yet completely ready despite the fact that the respective port is open thus leading to the previous exception.
Discussion
- A similar problem was observed in   HIVE-24395   but unfortunately as it is revealed by this case the fix is not enough to guarantee that the database is ready.
- A solution which seems to guarantee that the database is ready is to check in the log messages that the message  "database system is ready to accept connections"  appears twice. The problem was fixed in testcontainers project in the same way (see the respective  commit ).
