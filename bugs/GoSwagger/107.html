Title

Generator does not support polymorphic and addl props in the same type.

Description
## Problem statement

Adding `additionalProperties: true` to a type containing an array of
polymorphic objects causes the unmarshal and marshal functions to change
to one that doesn't support the polymorphic objects.

## Swagger specification

    Graph:
      type: object
      additionalProperties: true
      properties:
        Nodes:
          type: array
          items:
            $ref: "#/definitions/Node"
    Node:
      type: object
      discriminator: NodeType
      required:
      - NodeType
      properties:
        NodeType:
          type: string
    CodeBlockNode:
      allOf:
      - $ref: "#/definitions/Node"
      - properties:
           Code:
            type: string
