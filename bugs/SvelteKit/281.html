Title

Optional route [[lang]] followed by (group) breaks router

Description
### Describe the bug

When I define a route like this

```
src/routes/
├ [[lang]]/
│ ├ (site)/
│ │ └ +page.svelte
│ │ ├ providers/
│ │ │ └ +page.svelte    // this does not work correctly
│ ├ (auth)/
│ │ └ // auth routes
```

When navigating to `[URL] it loads `[[lang]]/(site)/+page.svelte`. When navigating to `[URL] it now correctly loads `[[lang]]/(site)/providers/+page.svelte`

Navigating to  `[URL] should load `[[lang]]/(site)/providers/+page.svelte`.

Discussion
- possible workaround is to add a param matcher for "lang" that ensures "providers" can't match as a language

rename `[[lang]]` to `[[lang=lang]]` and add /src/params/lang.ts with

```js
export function match(value) {
	return value.length <4; // allows for 3 char language tags, you might want to limit this to languages supported by your app
}
```
