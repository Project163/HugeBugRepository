Title

Attribute selector when running with Ivy

Description
# 🐞 bug report

### Affected Package
ivy renderer


### Is this a regression?

Yes, the behavior changed between 8.0 (no-ivy) and 9.0 (ivy)


### Description

When the bootstrap component uses an attribute selector  (e.g. '[app-component]') instead of an element selector, the first ` ` on the page is used to render the component.


## 🔬 Minimal Reproduction

[URL]

clone, npm install, ng serve
=> the content of AppComponent is rendered inside the first ` ` instead of the second ` ` where the attribute is set.
If Ivy is disabled in tsconfig.json, AppComponent is rendered in the second ` ` as expected.
It seems as if attribute selectors are completely ignored by Ivy.

## 🔥 Exception or Error
the content of AppComponent is rendered inside the first ` ` instead of the second ` ` where the attribute is set.
