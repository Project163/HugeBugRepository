Title

remove default `_all` for `type` and `index` if these are missing in REST tests

Description
If a `type` or `path` is missing in the REST test yaml file, it is automatically replaced with `_all`. This makes it hard to test changes in the api, for example adding the possibility to leave the index blank in addition to `_all` and `*` in the uri.
