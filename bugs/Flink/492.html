Title

Unclosed stream may leak resource

Description
In UdfAnalyzerUtils.java : 
  
         ClassReader cr =  new  ClassReader( Thread .currentThread().getContextClassLoader()
            .getResourceAsStream(internalClassName.replace( '.' ,  '/' ) +  ".class" ));
 
  
 The stream returned by getResourceAsStream() should be closed upon exit of findMethodNode() 

 In ParameterTool#fromPropertiesFile(): 
  
     props.load( new  FileInputStream(propertiesFile));
 
  
 The FileInputStream should be closed before returning.
