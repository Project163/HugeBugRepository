Title

Evaluator.TagEndsWith and Tag disagree in case-sensitivity

Description
In jsoup 1.12.1, when a document is parsed using the XML parser, `Document.select` behaves differently when selecting elements with mixed case and namespace. Using the selector `*|mixedCase`, it is not possible to select the elements.

In `QueryParser.byTag`, the tag names in the selector are normalized.
In `Evaluator.TagEndsWith.matches`, the comparison is case-sensitive.
In `Evaluator.Tag.matches`, the comparison is case-insensitive.

Discussion
- Jsoup 1.11.2 is also affected.
- In jsoup, using `Parser.xmlParser()` to generate the DOM is not the same as using `Parser.htmlParser()`.
E.g.
tagName in `Parser.xmlParser()` - case sensitive 
tagName in `Parser.htmlParser()` - lower case.

And when we use the selector - `*|mixedCase` - the string is converted to lowercase.
Therefore, in the case `Parser.xmlParser()`, the selector will find nothing.
- @dota17 My complaint is that it is not _possible at all_ to select an XML element called `mixedCase` by using a selector. If you know otherwise, please tell me, maybe I didn't get something.
- Thanks for the report and the test cases! 

I fixed it by standardizing on normalized comparisons - so case-insensitive.

Ideally, the QueryParser would know if we are in case-sensitive or insensitive mode, and act accordingly (for tags and attributes). We could pass that in when creating the selector. That way in XML, you could differentiate between tag `Foo` and tag `foo`. But for now, this should do.
