- This method which returns  KeySetView  only exists in jdk 1.8, did you use another version of jdk? 

 Also if this is a problem, then all the examples should be failed, since every SparkContext will have netty rpc layer, did you run into this problem occasionally or in every example?
- Yes, this is a subtle Java version issue. It means this was compiled with Java 8, but run on Java 7, which is almost always entirely fine if the source code itself is targeted at Java 7 and works with Java 7. But in this case the compiled version differs when compiled with Java 8 in a way that's not backwards compatible.
