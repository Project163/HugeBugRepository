Title

Seg fault occured when deleting from table WHERE single-column-primary-key =

Description
postgres=# create table t (a int primary key, b text);
CREATE TABLE
postgres=# insert into t values (1, 'a');
INSERT 0 1
postgres=# insert into t values (2, 'b');
INSERT 0 1
postgres=# select * from t;
 a | b
---+---
 1 | a
 2 | b
(2 rows)
postgres=# delete from t where a = 1;
ERROR:  IO error: Errors occured while reaching out to the tablet servers
Discussion
- This crashes occured when hash_key === primary_key.
To DELETE rows from storage, we initialized the DocDB keys that identify the rows. However, one of the keys for this operation wasn't initialized and caused a crash during the execution.
