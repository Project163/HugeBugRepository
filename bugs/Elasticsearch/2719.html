Title

SQL: Cannot reorder columns in PIVOT query

Description
Given a query like `SELECT a, b, birth_date FROM (SELECT * FROM test_emp PIVOT (SUM(salary) FOR languages IN (1 as a, 2 as b)) LIMIT 10)` the response is 

```
a            |       b       |  birth_date   
------------------------+---------------+---------------
null                    |56415          |null           
null                    |34341          |null           
null                    |39728          |null           
... [Log Snipped] ...
1953-09-19T00:00:00.000Z|null           |44307          
1954-06-19T00:00:00.000Z|null           |56760
```

Expected response would be to have the first column with the dates last.

Note, the bug also applies if you don't select any of the pivoted columns as in `SELECT emp_no, birth_date FROM (SELECT * FROM test_emp PIVOT (SUM(salary) FOR languages IN (1 as a, 2 as b)) LIMIT 10)` and also when not using a subquery as in `SELECT a, birth_date, emp_no FROM test_emp PIVOT (SUM(salary) FOR languages IN (1 as a, 2 as b)) LIMIT 10`.
