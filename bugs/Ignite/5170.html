Title

GeoSpatial index creation fails on client nodes

Description
GeoSpatial indexes work only on server nodes. GeoIndexes are completely broken on client nodes since 2.11 ( [URL] broke it) 

 Client nodes should provide a lightweight index (structure, no data). It's done for sorted indexes (ClientInlineIndex), but doesn't for geospatial.
