Title

legacyTypeId is clobbering checked_tensor_unwrap checks

Description
I was investigating the comment chain over in [URL] and ran into a bug.

To reproduce, you need to get rid of multiple dispatch for multinomial and call it, e.g.:
```
torch.multinomial(torch.rand(2,3, device='cuda'), 5, True, out=torch.randn(2,3, device='cuda').long())
```

You'll get an error like:
```
Unrecognized tensor type ID: VariableTypeId
```

what's happening here is we are trying to pass a variable to a method that only accepts tensors, and this is already checked with a reasonable error message:
[URL]

but the first call of `tensorTypeIdToBackend(impl::dispatchTypeId(expr.type_set())` bails before we get there.
