Title

UrilInfo.getAbsolutePath() missing path separator between servlet url and relative url

Description
@Path( "/bookstore" )
@Produces( "application/xml" )
 public   class  BookStore {
    @Context 
     private  UriInfo ui;

    @GET
    @Path( "/books/{id}" )
     public  Response getBookRoot(@PathParam( "id" )  Long  id) {
         System .out.println(ui.getAbsolutePath());
        Book b = books.get(id);
         if  (b ==  null ) {
             return  Response.status(Status.NOT_FOUND).build();
        }
         return  Response.ok(b).build();
    }
}
 
  

 The GET call prints:  [URL] .
Discussion
- The result of UrilInfo.getAbsolutePath() is dependent on address set in JAXRSServerFactoryBean: 
sf.setAddress("[URL] - works correct 
sf.setAddress("[URL] - produces "[URL]

 IMO we should check this and append path separator, if necessary
- Indeed, UriInfoImpl.getAbsolutePathAsString needs to have an extra check, thanks
