Title

Update Netty to avoid leaking file descriptors during shuffle

Description
Netty 3.2.3.Final has a known bug where writes to a closed channel do not have their futures invoked.  See  Netty-374 .  This can lead to file descriptor leaks during shuffle as noted in   MAPREDUCE-4298  .
Discussion
- Patch to update the Netty dependency to 3.2.4.Final which has the fix for  NETTY-374 .  Manually tested with the issue described in   MAPREDUCE-4298   to verify file descriptors are no longer leaked when I/O errors occur on the channel.
