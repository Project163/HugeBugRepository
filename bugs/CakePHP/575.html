Title

Can't create a plugin's schema with plural name thought SCHEMA shell

Description
Hello, 
I am using CakePHP 2.5.5 and I just have created a plugin named "UserTags".
I placed the schema.php file inside /Plugin/UserTags/Config/Schema/schema.php

This is the code:

```
class UserTagsSchema extends CakeSchema 
{
    public function before($event = array()) 
    {
        return true;
... [Log Snipped] ...
    );
}
```

I tried to execute this command:

```
cake schema create --plugin UserTags
```

this is the output:

```
Welcome to CakePHP v2.5.5 Console
---------------------------------------------------------------
App : app
Path: /vagrant/app/app/
---------------------------------------------------------------
... [Log Snipped] ...
File: /vagrant/app/app/Plugin/UserTags/Config/Schema/schema.php
Name: UserTag
```

(obviously the file exists)

Then I tried 

```
cake schema create --plugin UserTags UserTags
```

and it works! so here the problem is that we can not create schemas for plugins with plural names.
