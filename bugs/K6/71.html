Title

SharedArray doesn't work with forEach

Description
The following code:
```
import { SharedArray } from 'k6/data'
var csvData = new SharedArray("another data name", function() {
    return ["one", "two"];
});
export default function() {
    csvData.forEach((item) => console.log(item));
}
```

Gets 
```
 TypeError: Value is not an object: undefined
```
which needs to be investigated
Discussion
- Maybe the recently added [Link: `goja.DynamicArray`] could help?
- I need to check if it doesn't allow changing the values as that was part of the idea of the SharedArray. 

I mostly made this issue as `forEach` was used in the example in the docs that I edited in [URL] so I don't forget to test it later ;)
