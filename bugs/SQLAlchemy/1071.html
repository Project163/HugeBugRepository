Title

items() / values() methods of sqlalchemy.sql.base.ImmutableColumnCollection removed in 1.4, keys() still present so these can be restored

Description
**Describe the bug**

There seems to be a regression in 1.4, as `sqlalchemy.table('my_table').columns.items()` was working in 1.3, but not in 1.4.

Not sure if I'm missing something, but I'd expect a deprecation warning if removing this method was planned.

Detected when updating SQLAlchemy in Ibis: [URL]

**Expected behavior**

Expecting this same behaviour in 1.4:

```py
'1.3.23'
[]
```

**To Reproduce**

```py
'1.4.0'
```


Discussion
- ColumnCollection has changed to allow for more sequence-like behavior, but as long as it still has a keys() method it should have a items() and values() methods
- **Federico Caselli** has proposed a fix for this issue in the **master** branch:

**Added back ``items`` and ``values`` to ``ColumnCollection`` class.** [URL]
