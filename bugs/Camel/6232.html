Title

camel-tarfile: TarAggregationStrategy throws error when first message is empty

Description
TarAggregationStrategy will skip empty messages, but if the  first  message is empty it will throw an error "java.io.IOException: Cannot create temp file: " on the next non-empty message. 

 I added a test case to reproduce this.
Discussion
- PS: The behavior with only one empty message is also strange: In my test the aggregate will be an empty String object instead of an empty File.
