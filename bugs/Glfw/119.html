Title

Incorrect axis values returned from glfwGetJoystickAxes

Description
OS and version: Windows 10 64-bit
Release or commit: Release 3.2.1 and Commit  
Error messages: None
events output: None relevant

When either the left or right thumbstick on my Xbox 360 controller is located to the far bottom left (i.e. position -1, -1), glfwGetJoystickAxes returns 0 for both axes instead. All other values are unaffected (e.g. -1, -0.9). Other axes remain unaffected (left and right triggers are completely unaffected, and if the left thumbstick should read (-1, -1), then only it's axes will read (0, 0) while the right thumbstick returns the correct values and vice versa).

The issue was reproducible for me via test/joysticks.c. It does not occur in the control panel, or in any games I've tried the controller with.
