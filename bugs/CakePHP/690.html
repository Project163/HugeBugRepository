Title

Problem with ->find()

Description
My CakePHP version 3.0.8
On my Controller i have this function (generated by cake bake) on add and edit functions.

```
$medico = $this->AgendaMedico->Medico->find('list', ['limit' => 200]);
```

I got this error
 Error: SQLSTATE[42000]: Syntax error or access violation: 1064 You have an error in your SQL syntax; check the manual that corresponds to your MariaDB server version for the right syntax to use near 'LIMIT 200' at line 1

Becouse is generating this QUERY with an EMPTY WHERE

```
SELECT Medico.id AS `Medico__id` FROM medico Medico WHERE  LIMIT 200
```

Tested with Cake 2.X

```
$medicos = $this->AgendaMedico->Medico->find('list');
Everything works 
Query Generated
SELECT `Medico`.`id`, `Medico`.`nome` FROM `agenda`.`medico` AS `Medico` WHERE 1 = 1
```

The problem is, in 3.x find() do not put the condition (1=1), the workaround was to edit the find to

```
$medico = $this->AgendaMedico->Medico->find('list', ['conditions' => ['1=1']],['limit' => 200]);
```

So find is broken if you dont pass a condition.
