Title

BUG: itemsize wrong for date32[day][pyarrow] dtype?

Description
### Pandas version checks

- [X] I have checked that this issue has not already been reported.

- [Link: X] I have confirmed this bug exists on the [latest version] of pandas.

- [Link: X] I have confirmed this bug exists on the [main branch] of pandas.

### Reproducible Example

```python
import pyarrow as pa
import pandas as pd

pd.ArrowDtype(pa.date32())  # date32[day][pyarrow]
pd.ArrowDtype(pa.date32()).itemsize  # 8
```

### Issue Description

I think it should show `4`? `pa.date32()` is 32 bits, so 4 bytes

### Expected Behavior

pd.ArrowDtype(pa.date32()).itemsize  # 4
