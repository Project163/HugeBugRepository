Title

Error while removing manual element

Description
**Describe the bug**
I have a scenario where I manually register a component (see example: [URL] but when my app moves to a different view, it tries to unregister and throws an error because the fieldsRef mapping is empty at that time.

`removeEventListenerAndRef` is called from `unregister` with `undefined` as the `field` parameter. This method calls `findRemovedFieldAndRemoveListener` which tries to destructure the field parameter but it is undefined so it crashes.

**To Reproduce**
I tried to reproduce it in a contained scnario, but it seems to work just fine:
[URL]

I don't know what is causing the crash in my application, but it's a more complicated stack with next.js and hot reloading, so probably something causes a delayed unregister or something like that.

**Expected behavior**
If a field no longer exists in the fieldsRef, the unregister method should just ignore it (as it also ignores double registrations.

**Additional context**
Not sure if this a long term issue and a good solution, but I think an extra null check would not be a bad thing?
