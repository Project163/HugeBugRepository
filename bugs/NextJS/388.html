### To Reproduce

1. Create a typescript file, guarded with `import 'server-only'` (SERVER)
1. Create a client component with `use client` (CLIENT)
2. Create a Server Action with `use server` on file level, e.g. `actions.ts` approach (SA)
3. Import SERVER file into SA, then import SA into the CLIENT

### Describe the Bug

Compilation fails with "You're importing a component that needs server-only. That only works in a Server Component but one of its parents is marked with "use client", so it's a Client Component." error.

E.g. when a file with `import 'server-only'` is in a dependency tree of a Server Action, this Server Action is no longer importable into Client Components. 

### Expected Behavior

Provided example works.
