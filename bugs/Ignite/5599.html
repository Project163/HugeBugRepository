- Actually fixed in scope of the   IGNITE-17734    

 Reason of the  zero  case is the same as in   IGNITE-17734  . The C2 Jit broken  PagesList$CutTail::run  is called for old bucket's tail page and generates the exception. Because of the exception two bad things occur: 
 
	 zero nextId is written to page previous to old tail (which makes it looks like new tail one) 
	 pageId of page previous to old tail is not saved as new actual bucket's tail 
 

 So this causes the next  non-zero  case  which occur during removal of the last row.  The last page in bucket looks like tail (nextId is zeroed by mistake in "zero" case above) but it's not listed in list of tails.
