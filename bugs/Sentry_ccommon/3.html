Title

Support log4j configuration for Sentry service

Description
The sentry service should support log4j configuration property file.
Discussion
- A log4j properties file can now be specified in the commandLine like so : 

 $ ./bin/sentry --log4jConf <location of properties file> --command service ..... 

 The 'log4jConf' option and value MUST be the first option after the 'sentry' command..
- Looks like all the command line options which SentryMain does not recognize (the ones SentryService uses, for example) should follow the ones which it does because of stopAtNonOption=false. 

 So even this works:  
bin/sentry --command service --log4jConf /tmp/log4j.properties --conffile /tmp/sentry-site.xml
- Also, config file parameter looks like is being used by all three tools invoked from SentryMain, so might as well bring it into SentryMain. But we can do that in a follow on if you prefer.
