Title

Recursive CTEs create conflicting/ambiguous column names when wrapping a joined query.

Description
Hey there, so recursive CTEs create conflicting/ambiguous column names when wrapping a joined query.   This creates invalid queries.

To reproduce (a toy example rather than a use case):

```
python
from sqlalchemy import *
from sqlalchemy.orm import *

engine = create_engine('sqlite://', echo=True)
... [Log Snipped] ...

rec_cte = session.query(top_q.union_all(bottom_q))
```

Now if I print `rec_cte` I get

```sql
WITH RECURSIVE cte(id, manager_id, id) AS
(SELECT employee.id AS id, employee.manager_id AS manager_id, manager.id AS id_1
FROM employee JOIN manager ON manager.id = employee.manager_id UNION ALL SELECT employee.id AS employee_id, employee.manager_id AS employee_manager_id, manager.id AS manager_id
FROM employee JOIN manager ON manager.id = employee.manager_id JOIN cte ON cte.id = employee.id)
 SELECT cte.id AS cte_id, cte.manager_id AS cte_manager_id, cte.id_1 AS cte_id_1
FROM cte
```

Notice `WITH RECURSIVE cte(id, manager_id, id)` repeats the ID parameter, when it should be `WITH RECURSIVE cte(id, manager_id, id_1)`
