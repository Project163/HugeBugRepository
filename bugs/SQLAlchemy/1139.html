Title

Declarative Base with __iter__ Compatibility with 1.4+ Selectable

Description
In sqlalchemy `1.4`, if a custom declarative base class defines an `__iter__` method, then it cannot be used in `select(SomeModel)` unless it's wrapped with a `list`. Otherwise, an exception is raised (see example and traceback below).

Is this the intended behavior?

**Example**

```
python
from sqlalchemy import create_engine, select
from sqlalchemy.orm import declarative_base

class Base:
... [Log Snipped] ...
stmt = select([User])  #  ", line 3, in  
  File " ", line 2, in select
  File " /lib/python3.9/site-packages/sqlalchemy/sql/selectable.py", line 4893, in _create
    return cls.create_legacy_select(*args, **kw)
... [Log Snipped] ...
    self._raw_columns = [
TypeError: 'DeclarativeMeta' object is not iterable
```

**Versions**
 - OS: MacOS 11.2.3
 - Python: 3.9.4
 - SQLAlchemy: 1.4.8
 - Database: sqlite3
 - DBAPI: sqlite3
