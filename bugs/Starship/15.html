Title

Home directory shows node version if mongo client has been used

Description
## Bug Report

#### Current Behavior
Mongo client places a configuration file called `~/.mongorc.js`, which causes the home directory to be recognized as a Javascript project.

#### Expected Behavior
Starship should ignore this file.

#### Additional context/Screenshots
 

#### Environment
- Starship version: 0.13.1
- Shell type: fish
- Shell version: 3.0.2
- Shell plugin manager: fisher
- Terminal emulator: iTerm
- Operating system: macOS

#### Relevant Shell Configuration
 
[URL]

#### Starship Configuration
Default configuration

#### Possible Solution
Starship should probably have a list of blacklisted file which are ignored even if they are matched by extension
Discussion
- We have a related discussion going on over on #52. Long story short, we're not sure if we want to trigger Javascript project detection for just file suffixes at all in the future, but I don't think a blacklist has been discussed yet. Would be an interesting idea to add!
- I have this working but will need to add some tests.
