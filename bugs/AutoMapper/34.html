Title

Value lost when mapping from Nullable to Nullable

Description
When mapping from `int?` to `decimal?`, I get NULL even when the source is not null, 
as shown in the example below. This is using Automapper 5.0-beta-1. 

`public class C1{public int? X { get; set; }}`
`public class C2{public decimal? X { get; set; }}`
....
`var config = new MapperConfiguration(cfg => cfg.CreateMissingTypeMaps = true);`
`var mapper = config.CreateMapper();`
`var c2 = mapper.Map (new C1 {X = 99});`
`Assert.That(c2.X == 99); // fails, because c2.X = null`

I also tried the same in Automapper 4.2.1 but that resulted in a AutoMapperMappingException.

Also, the problem only occurs when also the source property is nullable.
Discussion
- Try it with CreateMissingTypeMaps false, the default. Create the required maps and see if the behavior is the same.
- I changed configuration to `new MapperConfiguration(cfg => cfg.CreateMap ())`.
