Title

flush() requests made before SSL handshake completion are not executed after completion

Description
`SslHandler` must flush anything left in its outbound buffer once handshake is finished.  Otherwise, any write requests issued before handshake is complete will not be flushed until a user calls flush() one more time.

This issue prevents the HttpSnoopClient's HTTP request from being sent to the server when SSL is enabled.
