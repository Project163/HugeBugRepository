Title

[quarkus-jaeger] extension's sampler-manager-host-name property can not be used

Description
### Describe the bug

The Jaeger client of a component utilizing the quarkus-jaeger extension fails to retrieve sampler strategies from a remote host.

### Expected behavior

When setting the *quarkus.jaeger.sampler-manager-host-port* property to a value of `my-jaeger-agent:5778`, then the Jaeger client retrieves the sampler strategies from that host and uses them during runtime.

### Actual behavior

The Jaeger client does not retrieve the sampling strategies from the configured host and also does not log any error.

### Additional information

The problem seems to be in the *JaegerDeploymentRecorder* class' *initTracerConfig* method where the `JAEGER_SAMPLER_MANAGER_HOST_PORT` system property is set to *InetAddress.toString()* which yields an invalid value like `my-jaeger-host/ :5778`.
