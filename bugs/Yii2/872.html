## Issue 1

### What's expected?

    /**
    * Handles adding `deleted_at`, `deleted_by` to table `accountable_person`.

### What do you get instead?

    */

    $this->addColumn('{{%accountable_person}}', 'deleted_at', $this->dateTime()->notNull()->defaultValue('0000-00-00 00:00:00'));

- @dmirogin, I don't see what's wrong with the "Issue 3".
From this

```
$this->createIndex(
        '{{%idx-accountable_person-deleted_by}}',
...
$this->addForeignKey(
        '{{%fk-accountable_person-deleted_by}}',
```

It will create index and foreign key with prefixed names `prefix_idx-accountable_person-deleted_by` and `prefix_fk-accountable_person-deleted_by`. It seems correct to me.
