Title

Java SDK harness fails to access state during timer callbacks

Description
The FnApiStateAccessor is given a callback to get the current element and it is not handling the case where the current element is a timer.

where the current "element" gets set:  [URL]

Alternatively, we could collapse currentElement and currentTimer to be currentElementOrTimer which would solve the accessor issue.
