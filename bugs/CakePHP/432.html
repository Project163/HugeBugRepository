Title

3.0 - Controller does not load NavigationMenusTable

Description
On a fresh install of the 3.0-dev the following does not load properly:

```
php
namespace App\Controller\Admin;

use App\Controller\AppController;

... [Log Snipped] ...

}
```

```
php
namespace App\Model\Table;

use Cake\ORM\Table;

... [Log Snipped] ...

}
```

Using the following table:

``` sql
CREATE TABLE IF NOT EXISTS `navigation_menus` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `icon` varchar(150) COLLATE utf8_unicode_ci DEFAULT NULL,
  `title` varchar(150) COLLATE utf8_unicode_ci NOT NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB  DEFAULT CHARSET=utf8 COLLATE=utf8_unicode_ci ;
```

Produces the following error:

```
Fatal Error
Error: Call to a member function find() on a non-object 
File /App/Controller/Admin/NavigationMenusController.php    
Line: 17

Notice: If you want to customize this error message, create App/Template/Error/fatal_error.ctp
```

The only thing in the error log is that error. The fix to get it to work was adding `$this->loadModel('NavigationMenus');` before the `$this->NavigationMenus->find();` call. Once the model was loaded manually the problem was solved.

Thanks for all of the hard work you guys do!
