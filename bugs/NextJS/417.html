Title

[NEXT-1122] Numeric Literals with Separators on `revalidate` Configuration throw TS Plugin Error

### To Reproduce

To reproduce this, simply export a `revalidate` option with a `_` separator in it:

```ts
export const revalidate = 86_400;
```

This creates an error because the TS Plugin:

[URL]

On this line, makes use of `Number`, but `Number` doesn't handle separators according to the spec. To handle this, the solution would be to replace it with:

```diff
-      return value === 'false' || Number(value) >= 0
+      return value === 'false' || Number(value.replaceAll("_", "")) >= 0
```

I haven't tested this solution, but it should fix the problem.

### Describe the Bug

The bug is that the export is highlighted with a invalid export type highlighted.

### Expected Behavior

The expected behavior is that an error is not shown.
