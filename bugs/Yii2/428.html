Title

Not updated "assignments" on method call "updateItem" of "PhpManager" class

Description
Hi!

If you run code:

``` php
        $authManager = \Yii::$app->authManager;
        $adminRole = $authManager->createRole('Admin');
        $authManager->add($adminRole);
        $authManager->assign($adminRole, 13);
```

then next files contains:
items.php:

``` php
return [
    'Admin' => [
        'type' => 1,
    ],
];
```

assignments.php:

``` php
return [
    13 => [
        'Admin',
    ],
];
```

But if you then run the code:

``` php
        $adminRole->name = 'SuperAdmin';
        $authManager->update('Admin', $adminRole);
```

Then file "assignments.php" is not updated:

``` php
return [
    13 => [
        'Admin',
    ],
];
```
