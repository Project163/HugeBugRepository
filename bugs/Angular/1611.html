Discussion
- Somehow `data-id="{{1}}"` strips `data-` and becomes `id`
- So, my understanding is that we do `data-` prefix removal for bindings but not static attributes:
[URL]
* `data-type="button"` => `data-type="button"`
* `data-[attr.type]="'button'"` => `type="button"`
* `data-type="{{'button'}}"` => `type="button"`
* `data-[type]="'button'"` => `type="button"`
- I think that we should rationalise the current behaviour as it is too confusing right now. Having said this it might require a breaking change so should be done only around major releases.
