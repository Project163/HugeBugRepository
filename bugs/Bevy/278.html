Discussion
- The problem is that we're binding too many samplers. The example ends up using 18 where M1 GPUs only support 16. I'm first trying to understand if there is any reason to bind multiple samplers of the same type in a shader stage. If not then we should try to minimise the number of samplers we bind somehow.
- Right, it seems like the example itself creates 16 samplers in the sampler binding array, and the view binding contains 2 comparison samplers for the shadow map textures. There only really needs to be 1 comparison sampler, and 1 sampler for the bindless material. @cryscan do you feel like changing the example to use 1 sampler as that is all that it needs?
- Agreed. Also I think it'll be helpful to add a note about the constraints in the example too.
