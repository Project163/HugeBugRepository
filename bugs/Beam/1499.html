- yichi  it looks like you wrote mongodbio, do you have any thoughts on this?
- Hi there, I found the issue.  

 When querying the split-vector from mongo in _get_split_keys, the function returns a list of dicts with the structure { _id: ObjectId(...) } . The split function in L165 the iterates through the list of dicts instead of a list if ObjectIds (at L174). This causes the min statement in L177 to fail. 

 Line numbers all refer to this file:  [URL]

 I tried a local version and unpacked the list of dicts into a list of ObjectIds and that worked. Hope it helps!
