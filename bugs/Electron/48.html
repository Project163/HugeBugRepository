Title

BrowserWindow.webContents.executeJavaScript does not work in 3.0.0-beta.1

Description
* Electron Version: 3.0.0-beta.1
* Operating System (Platform and Version): Arch Linux x64
* Last known working Electron version:  2.0.3

on `did-finish-load` the following code is not executed at all:
```javascript
mainWindow.webContents.executeJavaScript(`console.log("hello world");`);
```

It was working with version 2.0.x
Discussion

```js

```

And the console log appeared as expected, can you provide a minimal repro, it may be a timing issue in your code introduced by a timing change in the C66 upgrade.

- another update: using `dom-ready` instead of `did-finish-load` works even with 3.0.0-beta.2 (javascript code is executed):

```javascript
    mainWindow.webContents.on("dom-ready", () => {
        console.log("finish");
        mainWindow.webContents.executeJavaScript(`console.log("hello");`); // <--- this does does execute even with electron-3.0.0-beta.x
    });
```
However this is not a suitable workaround in my real application because I need to execute my javascript from main process **after**  the `onload` event has been fired on rendering process. And according to documentation, the right one is [Link: did-finish-load]:
