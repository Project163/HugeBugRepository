## Caching
### Reproduce
1. Get fresh advanced template
2. init Development env
3. create db and migrate the user schema
4. rename user table to t_user
5. create tables for RBAC
6. set up the app as follows
   common/main-local:

```
php
return [
    'components' => [
        'db' => [
            'class' => 'yii\db\Connection',
... [Log Snipped] ...
    ],
];
```

common/main:

```
php
return [
    'vendorPath' => dirname(dirname(__DIR__)) . '/vendor',
    'extensions' => require(__DIR__ . '/../../vendor/yiisoft/extensions.php'),
    'language' => 'de_DE',
... [Log Snipped] ...
    ],
];
```
1. try to register or login. it ends up in never ending recursing.
Discussion
- may be related to #2877
- This is because `DbCache` will try to get table schema when saving a value, and generating table schema will involve caching if `enableSchemaCaching` is true.
