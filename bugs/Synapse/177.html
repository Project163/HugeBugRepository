Title

JMS transport uses JMS properties in a way that violates the JMS specifications

Description
According to section 3.5.1 of the JMS specification (version 1.1), "Property names must obey the rules for a message selector identifier." According to section   on selectors, "An identifier is an unlimited-length character sequence that must begin with a Java identifier start character; all following characters must be Java identifier part characters." The JMS transport's use of a property named "Content-Type" is in violation of this specification. 

 Note that some JMS providers (such as qpid) accept illegal identifiers while others (such as WebSphere's SIBus client) don't.
