Title

Vagrant cannot detect CoreOS network interface names

Description
# Issue:

Current regex in plugins/guests/coreos/cap/configure_networks.rb doesn't match on ethX interface naming convention.  Causes issues when trying to configure network interfaces in a cluster.
`comm.sudo("ifconfig | grep 'enp0\\|ens' | cut -f1 -d:") do |_, result|`
## To Reproduce

Vagrant Version 1.7.2
Libvirt Version  
CoreOS LibVirt Base Box available from Atlas: 
vagrant init jharshman/coreos-stable; vagrant up --provider=libvirt
VagrantFile and supporting cloud init files can be found here:
[Link: CoreOS Config Gist]
## Debug Gist from Vagrant Up

[Link: Vagrant Debug Gist]
## Suggested Fix (tested)

Modify regular expression to match on the ethX pattern and be a bit more detailed with matching on the other patterns
`comm.sudo("ifconfig | grep -E '(e[Link: n,t][h,s,p][[:digit:]]?)' | cut -f1 -d:") do |_,result|`
