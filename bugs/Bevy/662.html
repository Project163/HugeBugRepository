Title

Taffy viewport nodes leak

Description
## Bevy version

main

## What you did

```
fn main() {
    App::new()
        .add_plugins(DefaultPlugins)
        .add_systems(Startup, setup)
        .add_systems(Update, update)
... [Log Snipped] ...
    commands.spawn(Node::default());
}
```

## What went wrong

The number of UI nodes stays the same but the number of taffy nodes increases by 1 every frame.

## Additional Information

For most UI node entities theres a 1-to-1 mapping from the entity to an associated taffy node ID. Root UI nodes are an exception though, their corresponding taffy node in the taffy tree is also given a parent that represents the viewport. These viewport taffy nodes are not removed when a root UI node is despawned.

Parenting of an existing root UI node with an associated viewport taffy node also results in the leak of the viewport node.
