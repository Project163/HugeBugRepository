Title

Need to update the default $HCAT_HOME dir in the PIG script.

Description
Looks like we need to update the default HCAT_HOME in /bin/Pig to /usr/lib/hive-hcatalog. 

 This is what it has currently. 

 <snip> 
if [ "$HCAT_HOME" == "" ]; then 
  if [ -d "/usr/lib/hcatalog" ]; then 
    HCAT_HOME=/usr/lib/hcatalog 
  else 
    echo "Please initialize HCAT_HOME" 
    exit -1 
  fi 
  fi 
</snip>
Discussion
- Thanks, Mani. Should  if [ -d "/usr/lib/hive-hcatalog" ]; then  be an else if instead?
- Thanks for taking a look at this Mark. 

 if [ -d "/usr/lib/hive-hcatalog" ]; looks right to me. We only want to check for the existence of this directory if HCAT_HOME is not set. Right?
- But, if  /usr/lib/hcatalog  already exists, should we still go through this check? What should happen in the corner case where both  /usr/lib/hcatalog  and  /usr/lib/hive-hcatalog  exist (say because 2 versions of HCatalog are installed, one from pre-hive times and one from after the project was merged into Hive?
- The first patch replaced checking for /usr/lib/hcatalog with /usr/lib/hive-hcatalog so, if we had both versions of HCatalog side by side I think it would have still worked. But, I agree that if the user only has the previous version installed, this check would have not set the HCAT_HOME and exited incorrectly. 

 Thanks! Updated patch.
