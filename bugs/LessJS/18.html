Title

parameter with variable and space, got a syntax error

Description
I got this syntax error, with this situation, the first is correct and second raise syntax error

.back(@url, @repeat, @position){
    backgounr-image: @url;
    background-repeat: @repeat;
    background-position: @position;
}
@s: "/";
.correct{
    .back("a.png", no-repeat, center center);
}
.error{
    .back("@{s}a.png", no-repeat, center center);
}

when I  user lessc command transfer this , I got a error:

SyntaxError: expected ')' got 'c' in C:\Users\delong\Desktop\a\a.less:11:41
10 .error{
11     .back("@{s}a.png", no-repeat, center center);
12 }
Discussion
- I presume work around is

```
.error{
    @t:"@{s}a.png";
   .back(@t, no-repeat, center center);
}
```

?

I also wonder if it would work if you put the s declaration before the .back declaration?
- I tried again, and found, this error need 2 conditions:
1. one or more parameters contain a string connect operation(@color operation work well);
2. the last parameter should be separate by space(like padding, magin, background-position .etc);
- thanks, think it was a regression in 1.3.0
