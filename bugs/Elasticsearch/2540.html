Title

elasticsearch-node does not load plugins roles

Description
**Elasticsearch version** (`bin/elasticsearch --version`): 7.10, but applies to master as well

**Plugins installed**: [] transform (or another from plugin)

**OS version** (`uname -a` if on a Unix-like system): macos

**Description of the problem including expected versus actual behavior**:
when a node has a role from x-pack (like transform) elasticsearch-node tool will not be possible to run. This possibly is by design as per comment in 
`ElasticsearchNodeCommand:L75` 
```   
 // ... as command-line tools are not loading plugins,...
```

**Steps to reproduce**:
1. set a transform role in elasticsearch.yml
node.roles: [transform, master, remote_cluster_client, data, ml, data_content,data_warm, data_cold, ingest, data_hot]
2. run and stop ES

3. edit elasticsearch.yaml to remove `data_hot`
4. run `elasticsearch-node repurpose`

result:
```
bin/elasticsearch-node repurpose
------------------------------------------------------------------------

    WARNING: Elasticsearch MUST be stopped before running this tool.

... [Log Snipped] ...
	at org.elasticsearch.cli.Command.main(Command.java:90)
	at org.elasticsearch.cluster.coordination.NodeToolCli.main(NodeToolCli.java:49)
```
Discussion
- Pinging @elastic/es-distributed (Team:Distributed)
- Note that without some rework, loading plugins here would be risky. Plugins can execute arbitrary code when they're loaded. So we'd want the security manager in place before we could load plugins in command line tools. The command line tools don't have any infrastructure for that today. That is, addressing this issue correctly is high-hanging fruit.
