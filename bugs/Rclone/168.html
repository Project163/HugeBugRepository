Title

--dry-run --verbose says both "Not deleting" and "Deleted"

Description
v1.36


macOS 10.11.3 El Capitan


Amazon S3, but also happens with local remotes


```
bash
$ mkdir -p a b

$ touch a/same a/new b/same b/old

... [Log Snipped] ...
# 2017/04/04 20:06:51 NOTICE: old: Not deleting as --dry-run
# 2017/04/04 20:06:51 INFO  : old: Deleted
```

The log is as expected in quiet mode (the new default since 1.36). In verbose mode however, `old` says both "not deleting" and "deleted". This seems to be a bug in the log only, since the file was actually not deleted.
