Title

__repr__ broken for Rows instantiated with *args

Description
PySpark Rows throw an exception if instantiated without column names when `_ repr _` is called. The most minimal reproducible example I've found is this: 
  
 
> from pyspark.sql.types  import  Row
> Row(123)
<stack-trace snipped  for  brevity>
<v-env location>/lib/python2.7/site-packages/pyspark/sql/types.pyc in __repr__(self)
-> 1524              return   "<Row(%s)>"  %  ", " .join(self)

TypeError: sequence item 0: expected string,  int  found 
  
 This appears to be due to the implementation of `_ repr _`, which works excellently for Rows created with column names, but for those without, assumes all values are strings ( link here ). 

 This should be an easy fix, if the values are mapped to `str` first, all should be well (last line is the only modification): 
  
 
def __repr__(self):
     """Printable representation of Row used in Python REPL." ""
     if  hasattr(self,  "__fields__" ):
         return   "Row(%s)"  %  ", " .join( "%s=%r"  % (k, v)
                                      for  k, v in zip(self.__fields__, tuple(self)))
     else :
         "<Row(%s)>"  %  ", " .join(map(str, self))
 
  
 This will yield the following: 
  
 
> from pyspark.sql.types  import  Row
> Row( 'aaa' , 123)
<Row(aaaa, 123)>
