Title

LSP: Support for native classes/methods/functions

Description
Psalm currently does not support completing or viewing information of native classes, methods and functions. This would be incredibly beneficial. [Link: PHPStorm stubs] are open source and could be useful.

Psalm currently has a list of classes and methods in `CallMap` which does not contain any documentation and also wouldn't allow for "Jump to definition" as PHPStorm does.
Discussion
- Yeah, I noticed this the other day. It can only currently complete classes it's already seen - I think it would be sufficient for the completion list to just be drawn from `get_declared_classes()` at startup
