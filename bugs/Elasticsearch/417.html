Title

source exclusion mapping prevents geo shape coordinates to be returned in query result source field

Description
ES Version: 0.90.0.RC2

Steps to reproduce:

ok case, without source exclusion:

```
bash
curl -XDELETE '[URL]
curl -XPUT '[URL]
curl -XPUT '[URL] -d '{
    "item" : {
... [Log Snipped] ...
    "query": {"match_all": {}}
}'
```

returns the coordinates for geo_point and geo_shape items:

```
JSON
{
    "took": 1,
    "timed_out": false,
    "_shards": {
... [Log Snipped] ...
    }
}
```

however the same scenario but with a source exclusion mapping of an arbitrary field does not return the geo_shape coordinates any longer:

```
bash
curl -XDELETE '[URL]
curl -XPUT '[URL]
curl -XPUT '[URL] -d '{
    "item": {
... [Log Snipped] ...
    "query": {"match_all": {}}
}'
```

returns only the geo_point coordinates but not the geo_shape coordinates:

```
JSON
{
    "took": 1,
    "timed_out": false,
    "_shards": {
... [Log Snipped] ...
    }
}
```
