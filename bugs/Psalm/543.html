Title

LSP Completion: Completion fails for chained method calls

Description
Completion requests do not work for chained function calls due to `Psalm\Internal\Codebase\Analyzer` returning incorrect offsets for function calls.

For example:

```
$foo->bar()->
             ^ LSP client sends a completion request to Psalm at this offset (13)
```

In this scenario, `Codebase::getCompletionDataAtPosition()` calls `Analyzer::getMapsForFile()` which returns a `type_map` for the file being edited. This `type_map` includes the return type of the `$foo->bar()` call, but the type has start offset 6 and end offset 9, while the completion is looking for a type at offset 11. It seems like the offset of the type in the `type_map` should be defined by the offset of the closing paren of the function call, which is 11, rather than the end of the function name as it is currently.
