Title

invalid error thrown when compressing a file named "window.js"

Description
What steps will reproduce the problem? 
1. create a file window.js containing "alert('hello world');"
2. compile the file using "java -jar compiler.jar --js=_window.js"


What is the expected output?
stdout should show: 
alert('hello world');


What do you see instead?
ERROR - Duplicate input: window.js

1 error(s), 0 warning(s)


 What version of the product are you using? On what operating system? 
using latest closure compiler (20100616) on macOSX with java 1.6.0_17


 Please provide any additional information below. 
Simply renaming the file works allow compression to succeed:

# mv window.js _window.js
# java -jar compiler.jar --js=_window.js
alert('hello world');
