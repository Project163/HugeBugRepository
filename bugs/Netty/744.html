Title

ReplayingDecoderBuffer getByte and getUnsignedByte cause ArrayIndexOutOfBoundsException

Description
In Netty 3.4.6, class ReplayingDecoderBuffer getByte and getUnsignedByte will cause ArrayIndexOutOfBoundsException be thrown instead of throwing ReplayError.

I _think_ that this is because getByte and getUnsignedByte call checkIndex(index) instead of checkIndex(index, 1) because getByte and getUnsignedByte javadocs state the following:

```
 * @throws IndexOutOfBoundsException
 *         if the specified {@code index} is less than {@code 0} or
 *         {@code index + 1} is greater than {@code this.capacity}
```

The other getters for primitives use checkIndex(int, int) as well.
