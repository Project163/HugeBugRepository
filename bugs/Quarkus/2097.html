Title

Alpn property not work in rest client reactive

Description
### Describe the bug

When setting the `quarkus.rest-client.alpn=true`, the http/1.1 is used and not http2.  By [URL] I would expect it work same/similar if the server have enabled http2.

This happen also when the single rest client is used (`quarkus.rest-client.config-key.alpn=true`,)

### Expected behavior

I would expect when using `RestClientBuilder` that the default http will be http/2. The result should be same as when using `quarkus.rest-client.http2=true`.

### Actual behavior

When `RestClientBuilder` use alpn it using http/1.1 not http/2

### How to Reproduce?

1. `git clone -b alpn-client git@github.com:jedla97/quarkus-reproducers.git`
2. `cd quarkus-reproducers`
3. `mvn clean verify  -Dquarkus.platform.version=3.7.0.CR1`

or

3. `mvn quarkus:dev -Dquarkus.platform.version=3.7.0.CR1`
4. `Go to [URL]

You can see which http version is used. Client is created when the endpoint is called (see method GreetingResource#httpsClient or GreetingResource#httpClient ).
