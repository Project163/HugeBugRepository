Title

NPE when searching * against an index with default field set (but field does not exist)

Description
ES 5.5

When an index has a default field defined in the index settings

```
"settings": {
   "index": {
    "query": {
     "default_field": "message"
    },
    "number_of_replicas": "1"
   }
  }
```

but the actual field does not exist, a * query will cause a NPE:

```
{
  "error": {
    "root_cause": [
      {
        "type": "query_shard_exception",
... [Log Snipped] ...
  "status": 400
}
```

See repro and log snippet [Link: here].
Discussion
- Good catch, this would happen whenever one of the queried indices does not have any mappings yet.
