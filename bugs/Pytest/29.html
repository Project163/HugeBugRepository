Title

Global variables are not explained on failure

Description
Originally reported by: **Floris Bruynooghe (BitBucket: [Link: flub], GitHub: [Link: flub])**

---

A global variable is not expanded in the explanation on failure:

```
var = 7

def test_global():
    val = 42
    assert var == val
```

Results in:

```
$ py.test test_global.py 
============================= test session starts ==============================
platform linux2 -- Python 2.7.3 -- pytest-2.2.1
collected 1 items 

... [Log Snipped] ...
test_global.py:6: AssertionError
=========================== 1 failed in 0.01 seconds ===========================
```

I would expect the "E" line to say "assert 7 == 42".
