Title

With code splitting, chunkhash of app.js doesn't change when the required js has changed.

Description
app.js

``` js
require.ensure(['./controllers/a'], function(require) {
  var a = require('./controllers/a');
  console.log(a);
});
```

controllers/a.js

``` js
module.exports = 'a';
```

Changing a.js doesn't change the chunkhash of app.js.

[URL]
Discussion
- Confirmed:

```
$ node build.js
$ md5 dist/*
MD5 (dist/1- .js) =

$ grep src dist/app- .js
/******/            script.src = __webpack_require__.p + "" + ({}[chunkId]||chunkId) + "-" + {"1":" "}[chunkId] + ".js";
```

I was thinking about having index.html be the entry point of a web-app ( #536 ) and relying on hashes so web browsers always get the correct version of everything related to the index.html file they just downloaded, but this breaks that :cry:.
