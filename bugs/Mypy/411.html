Title

Function overloading example does not typecheck

Description
The second code example given on the [Link: function overloading documentation]  gives the error (referred to the last definition of `__getitem__`): `Signature of __getitem__ incompatible with supertype Sequence`.

The whole snippet is:
```
python
from typing import overload, Sequence, TypeVar, Union
T = TypeVar('T')

class MyList(Sequence[T]):
... [Log Snipped] ...
    def __getitem__(self, index: Union[int, slice]) -> Union[T, Sequence[T]]:
        raise NotImplementedError
```
Discussion
- I think this is because mypy checks the _implementation_ signature against base class (while it shouldn't). If I remove the implementation annotation the error goes away.
