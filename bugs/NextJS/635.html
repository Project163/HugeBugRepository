Title

CORS issues with output: "export" due to unnecessary crossorigin attributes

Description
### Link to the code that reproduces this issue

[URL]

### To Reproduce

```bash
npm run build
```

inspect `./out/index.html`

### Current vs. Expected behavior

Generated link and script tags contain `crossorigin=""`, which is equivalent to `crossorigin="anonymous"`. This forces the browser to do CORS checks, even if the resources could be loaded with no-cors otherwise. See: [URL]

Example from the generated index.html:
```html
 .css" crossorigin="" data-precedence="next"/>
```


**Expected behavior:**

Link and script tags are generated without `crossorigin=""` attributes, as is the case when using other `output` modes.

Example:
```html
 .css" data-precedence="next"/>
```
