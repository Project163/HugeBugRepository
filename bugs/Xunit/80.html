Title

Attributes don't support field setters (only property setters)

Description
`TestMethod.Method.GetCustomAttributes(typeof(Attribute))` throws 'Object reference not set to an instance of an object.' when any attribute contains a public field (instead of a property).

I can use `TestMethod.Method.ToRuntimeMethod().GetCustomAttributes(typeof(Attribute), true);` to workaround issue (which will use C# Reflection library, which shows it's the Xunit Extension methods that are the cause).

Sample:
[Link: GetCustomAttributes_repo.zip]

There are two tests, one which runs and one which cancels the run (as the exception is thrown in  `MyTestCase.RunAsync(...)`).

The only different in the tests is that one has an attribute that has a public field `Field` and the other has one with a public property `Property`. I don't even have to try accessing these values for it to throw.
Discussion
- So the current behavior is that this cancels a test run because of a null pointer exception. Somehow I don't think this means it's 'fixed'. Maybe you check for this and return a meaningful exception? 

That might save someone else spending hours of their life finding a workaround for this issue.

Also as this is a normal C# Attribute, not a FactAttribute, then it's possible that the people writing the tests need to use an attribute that they don't have control over (like one from the C# libraries).
