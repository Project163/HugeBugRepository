Title

`COMMENT ON EXTENSION xxx` in Structure.sql causing problems when loading db on Heroku and other services

Description
### Steps to reproduce
 

### Expected behavior
 
We should be able to run `rake db:structure:load` without any trouble on any server where you can run `rake db:schema:load` without issues. 

### Actual behavior
 
the rake `db:structure:load` fails on the line `COMMENT ON EXTENSION plpgsql IS 'PL/pgSQL procedural language';`

[Link: More of an explanation here (essentially super user access is not available)] this also tends to happen on amazon RDS where super user access is similarly not available. However running `rake db:schema:load` on the same system would seem to work just fine. 

### Other Notes
The only reason I decided to file this is that I just noticed [Link: a precedent for it in this Pull request]

I think it would be a good fix to strip out those comments from structure.sql because ... 

- they don't seem to add anything to the db:structure:load process, but are added since [Link: Rails seems to shell out to pg:dump to create them] and the rest of structure.sql
- generated schema.rb seems to do just fine without them

### System configuration
**Rails version**:
6.0 RC1

**Ruby version**:
2.6.3
