Title

Groovy needs to upgrde Ivy lib to upgrade maven hashing algorithm

Description
grape resolve xalan xalan 2.7.1 prints the following error: 

  [FAILED ]  xalan#xalan;2.7.1!xalan.jar: invalid sha1: expected=sha1(xalan-2.7.1.jar)= computed=  (9927ms) 

 The underlying reason is the follwing bug in Ivy 2.0:   IVY-1006  . 

 The bug is fixed in Ivy 2.1, but Groovy 1.6.3 bundles Ivy 2.0 

 The workaround is to use Ivy-2.1.0-rc1 (test done on Groovy 1.6.x branch - build is fine and GroovyWS client works with the fix)
Discussion
- upgraded in trunk and 1_6_X branch (ready for 1.6.4 once that is scheduled)
