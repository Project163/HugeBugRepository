## Additional information

First noticed here: <[URL]
Discussion
- I think the issue is here in `get_vertex_buffer_data()`:

```rust
for attribute_data in self.attributes.values().take(vertex_count) { //  
```

This limits the number of attribute buffers that will be iterated over, not the number of values in the attribute itself. 
The inner loop over chunks of data from the attribute buffer should have the `.take(vertex_count)`. 

```diff
- for (vertex_index, attribute_bytes) in
-                attributes_bytes.chunks_exact(attribute_size).enumerate()
+ for (vertex_index, attribute_bytes) in
+                attributes_bytes.chunks_exact(attribute_size).take(vertex_count).enumerate()
```

Quick testing shows that moving the `.take()` into the inner loop prevents the crash.
