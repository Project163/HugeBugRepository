Title

d3.behavior.zoom's zoom extent is Math.pow(2, scale)

Description
The d3.behavior.zoom scale reports the scale as a scale. However, the extent feature uses a zoom level = Math.pow(2, scale). This is inconsistent; we should standardize on scale, since this is what is used by d3.geo.projection.
