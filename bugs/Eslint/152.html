Title

Using mergeConfigs to copy a config doesn’t work with plugins

Description
There is an bug, introduced with #1150, where you can’t copy a custom config object with a `plugins` property.

`Config.getConfig` copies the `baseConfig` using `util.mergeConfigs({}, this.baseConfig)`.
