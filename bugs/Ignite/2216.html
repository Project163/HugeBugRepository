Title

Hadoop tests affect each other through IgniteHadoopClientProtocolProvider#cliMap

Description
Tests affect each other through map 
org.apache.ignite.hadoop.mapreduce.IgniteHadoopClientProtocolProvider#cliMap that never clears.  

 For example, test org.apache.ignite.internal.processors.hadoop.impl.client.HadoopClientProtocolMultipleServersSelfTest#testSingleAddress sometimes fails if test org.apache.ignite.internal.processors.hadoop.impl.client.HadoopClientProtocolSelfTest#testJobCounters runs before it.
Discussion
- Shall we also invoke org.apache.ignite.internal.client.GridClientFactory#stopAll() ?
- Ivan, 
I would prefer to have more clean way to clear client map - do that when client is closed. We should use method  IgniteHadoopClientProtocolProvider.close  for this. 

 Concurrency should be scalable enough.
