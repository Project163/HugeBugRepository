Title

[YSQL] Backup: sequence's current value is not set up, leading to unique constraint violation

Description
Jira Link: [Link: DB-2903]
### Description

During backup/restore of a sequence, the sequence's current value is not set up. Thus, after restoration, its initial value is set to a default value.
See the example below:
```
# create table and insert data to increment sequence value
yugabyte=# create table tbl (k serial primary key, v int);
yugabyte=# insert into tbl(v) select * from generate_series(1,100);

# take backup
... [Log Snipped] ...
       3
(1 row)
```

Setting up a value for a sequence is part of dumping sequence data in `pg_dump.c`.
`ysql_dump` only uses `pg_dump` to create schema, and skips the dumping data part.
