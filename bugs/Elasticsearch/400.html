Title

0.90.0.RC1 Percolator, Not Matching Properly on Custom Analyzer

Description
I found this bug in 0.90.0.RC1. (Works properly in 0.20.6 and earlier). It seems to have something to do with the custom analyzer/tokenizer being specified.

1) PUT [URL]
{
  "settings": {
    "number_of_shards": 1,
    "number_of_replicas": 0,
    "index": {
      "analysis": {
        "analyzer": {
          "lwhitespacecomma": {
            "tokenizer": "whitespacecomma",
            "filter": [
              "lowercase"
            ]
          }
        },
        "tokenizer": {
          "whitespacecomma": {
            "pattern": "(,|\s+)",
            "type": "pattern"
          }
        }
      }
    }
  },
  "mappings": {
    "doc": {
      "properties": {
        "filingcategory": {
            "type": "string",
            "analyzer": "lwhitespacecomma"
        }
      }
    }
  }
}

2) POST [URL]
{
  "source": "productizer",
  "query": {
    "constant_score": {
      "query": {
        "query_string": {
          "query": "filingcategory:s"
        }
      }
    }
  }
}

3) POST [URL]
{
  "query": {
    "term": {
      "source": "productizer"
    }
  },
  "doc": {
    "filingcategory": "s"
  }
}

Returns (in 0.90.0.RC1): {"ok":true,"matches":[]}

Returns (in 0.20.6 or below): {"ok":true,"matches":["1"]}

Thanks!
