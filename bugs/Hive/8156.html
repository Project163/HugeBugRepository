Title

Incorrect False positive result rows may be outputted in case outer join has conditions only affecting one side

Description
needed 
 
	 outer join 
	 on condition has at least one condition for one side of the join 
	 in a single reducer:
	 
		 a right hand side only row outputted right before 
		 >=2 rows on LHS and 1 on RHS matching in the join keys but the first LHS doesn't satisfies the filter condition 
		 second LHS row with good filter condition 
	 
	 
 

  
 
with
t_y as (select col1 as id,col2 as s from (VALUES(0, 'a' ),(1, 'y' )) as c),
t_xy as (select col1 as id,col2 as s from (VALUES(1, 'x' ),(1, 'y' )) as c) 
select * from t_xy l full  outer  join t_y r on (l.id=r.id and l.s= 'y' );
 
  

 null,null,1,y is a false positive result 
  
 
+-------+-------+-------+-------+
| l.id  |  l.s  | r.id  |  r.s  |
+-------+-------+-------+-------+
| NULL  | NULL  | 0     | a     |
| 1     | x     | NULL  | NULL  |
| NULL  | NULL  | 1     | y     |
| 1     | y     | 1     | y     |
+-------+-------+-------+-------+
Discussion
- Why we are saying unexpected results instead of wrong? I don't thing there are many ways to interpret the query.
- +1 to calling it wrong results.  Thanks for creating a simple repro.  Swapping the order of the rows in the left table produces the correct results with 3 rows: 
  
 with
t_y as (select col1 as id,col2 as s from (VALUES(0,'a'),(1,'y')) as c),
t_yx as (select col1 as id,col2 as s from (VALUES(1,'y'),(1,'x')) as c)
select * from t_yx l full outer join t_y r on (l.id=r.id and l.s='y');
+-------+-------+-------+-------+
| l.id  |  l.s  | r.id  |  r.s  |
+-------+-------+-------+-------+
| 1     | x     | NULL  | NULL  |
| NULL  | NULL  | 0     | a     |
| 1     | y     | 1     | y     |
+-------+-------+-------+-------+
- Why we are saying unexpected results instead of wrong? I don't thing there are many ways to interpret the query.  

 I wanted to highlight that this is not taking away expected results - and thus its a false positive error and not a false negative.
