Title

Stack Overflow inserting value with many columns

Description
I am using CQL to insert into a table that has ~4000 columns 

  
   TABLE_DEFINITION = "
      id uuid,
       "dimension_n"   for  n in _.range(N_DIMENSIONS)
      ETAG timeuuid,
      PRIMARY KEY (id)
    "
