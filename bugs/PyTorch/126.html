Title

Segmentation Fault due to Invalid out_dim Type in `torch.tensor.flatten`

Description
### 🐛 Describe the bug

When attempting to flatten a tensor using PyTorch's `torch.tensor.flatten` method with the `out_dim` parameter set to a string value, it triggers a segmentation fault resulting in a core dump. 

## Error log
```bash
munmap_chunk(): invalid pointer

or

malloc(): unaligned tcache chunk detected
Aborted (core dumped)
```

## Minified Repro
```python
import torch

a = torch.tensor([1, 2, 3])
a.flatten(start_dim=0, end_dim=1, out_dim='a')

```
