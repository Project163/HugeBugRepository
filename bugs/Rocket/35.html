Title

"chained comparison operators require parentheses" when using #[database]

Description
I am using rocket 0.4.0 on Debian testing and rustc `1.32.0-nightly (4a45578bc 2018-12-07)`.

I am playing around with the new built-in DB support (following [URL] but running into compilation issues.  My code is (most things removed to get a minimal example)
```
rust
#[macro_use] extern crate rocket_contrib;

use rocket_contrib::{
    databases::{r2d2_diesel, diesel}
... [Log Snipped] ...

fn main() { }
```
with a `Cargo.toml` saying
```
rocket = "0.4"
rocket_contrib = { version = "0.4", features = ["handlebars_templates", "diesel_postgres_pool"] }
```
and my `Rocket.toml` contains
```
[global.databases]
postgres = { url = "postgres://r@/ff-node-monitor" }
```

This fails to compile, saying
```
error: chained comparison operators require parentheses
  --> src/main.rs:45:1
   |
45 | #[database("postgres")]
   | ^^^^^^^^^^^^^^^^^^^^^^^
... [Log Snipped] ...

error: aborting due to previous error
```
Discussion
- What if you try with

```rust
pub struct DbConn(pub r2d2_diesel::ConnectionManager:: );
```
(notice the `::` after `ConnectionManager`)
- No luck:
```
warning: unnecessary path disambiguator
  --> src/main.rs:45:53
   |
45 | pub struct DbConn(pub r2d2_diesel::ConnectionManager:: );
   |                                                     ^^ try removing `::`
... [Log Snipped] ...

error: aborting due to previous error
```
- ... [Middle Discussions Snipped for Brevity] ...
- Actually, what I really want is
```rust
#[database("postgres")]
pub struct DbConn(pub diesel::PgConnection);
```
I misunderstood the docs and thought I had to wrap the r2d2 pool around that myself.
- We should probably add a type-level assertion that the inner type implements `Poolable`, if there isn't already. And we should fix whatever is causing that infamous warning if possible.

EDIT: This may be the offending line in contrib codegen: `.map(#connection_type::pool);`
