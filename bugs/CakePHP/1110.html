Title

Folder::create: umask has no effect

Description
### Description

In Folder::create the call on `$old = umask(0);` is directly followed by `umask($old)` and therefor is directly reseted to its old value. This leads to unexpected permission set in the filesystem.

Solution: wrap the umask calls around the `mkdir` call.

### CakePHP Version

4.3.0

### PHP Version

8.1
