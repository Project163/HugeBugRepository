Title

Identifiers with "named-color" parts are broken.

Description
since release 2.6.1 less.js changes the `animation-name` value if it starts with a css color name

```
animation: blue-change 5s infinite;
animation-name: green-black;
```

results in

```
animation: blue change 5s infinite;
animation-name: #008000;
```
Discussion
- This is due to the change in [URL] where the regex for named colors was altered.

Technically this should be caught by the parser as a keyword before it attempts any operations. However, I've reverted the regex change which passes all tests, including new ones which test for this case.
- Closing as fixed in [URL]
