Title

All but first test in a class fail if class is annotated @WithFunction

Description
### Describe the bug

Given a project which contains an implementation of a Google Cloud Run Function (`CloudEventsFunction` variant) which was created as shown in the [Link: Google Cloud Functions (Serverless) guide],

Add a test class to this project as shown in the [Link: Testing your function section] and add a second identical test is added to this test class,

When running tests, the second test in this class cannot be instantiated.

### Expected behavior

Both tests pass.

### Actual behavior

The first test passes, the second test fails.


### Additional information

Suspected cause: In [Link: `CloudFunctionTestResource.inject(TestInjector)`] a new invoker is started for each test without stopping an invoker created previously.

Potential remedy: Invokers should either be reused between tests or stopped after each test.
