Title

Crash when clicking the "n Leak Groups" button in ActionBar, after loading first report

Description
### Description

LeakCanary 2.0-beta-3 crashes when the "n Leak Groups" button is pressed, after loading the first report.

### Steps to Reproduce

1. Use an Android 4.2 device
1. Run the library on an app that has a memory leak
2. Click the "Leaks" icon in the home screen, to view the Leak report
3. Click on "Latest: xxx" to view the first report
4. Press the Back button, to go back to the previous screen
5. Press the "n Leak Groups" button at the top left (or top right)
6. Observe the crash:

```
java
E/AndroidRuntime: FATAL EXCEPTION: main
    java.lang.ArrayIndexOutOfBoundsException: length=12; index=-1
        at java.util.ArrayList.remove(ArrayList.java:401)
        at leakcanary.internal.navigation.NavigatingActivity.goBack(NavigatingActivity.kt:111)
... [Log Snipped] ...
        at com.android.internal.os.ZygoteInit.main(ZygoteInit.java:869)
        at dalvik.system.NativeStart.main(Native Method)
```

**Expected behavior:**

* No crash.
* Either exit out of the app
* Or disable the "n Leak Groups" button, like on other Android versions.

### Version Information

* LeakCanary version: LeakCanary 2.0-beta-3
* Android OS version: Android 4.2
* Gradle version: 5.1.1

### Additional Information

I believe the problem is in [Link: this function]:

```
kotlin
fun goBack() {
    onCreateOptionsMenu = NO_MENU

    currentView.startAnimation(loadAnimation(this, R.anim.leak_canary_exit_backward))
... [Log Snipped] ...
    updateActionBar()
}
```

Perhaps try something like this:

```
kotlin

    onCreateOptionsMenu = NO_MENU

    currentView.startAnimation(loadAnimation(this, R.anim.leak_canary_exit_backward))
... [Log Snipped] ...
    }
}
```
