Title

[YSQL] Update on table with multiple FK tables crashes postgres

Description
This is an error seen on debug build only.

To reproduce:
```
yugabyte=# create table pk(b int, a int, y int, x int, primary key(a, b));
CREATE TABLE
yugabyte=# create unique index on pk(x, y);
CREATE INDEX
yugabyte=# insert into pk(a,b,x,y) values(1,10,100,1000);
... [Log Snipped] ...
The connection to the server was lost. Attempting reset: Failed.
!> exit
```
Note that the error only happens if both tables have FK references. Changing the above to use just 1 FK reference (by removing fk_primary table) won't cause the error.
