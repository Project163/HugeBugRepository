Title

getMockBuilder now marked as protected, not public

Description
When upgrading to PHPUnit 5.4, getMockBuilder has become a protected method and is no longer publicly available so a substantial amount of our tests now fail based on this:

```
Error: Call to protected method PHPUnit_Framework_TestCase::getMockBuilder() from context 'BeanHelper'
```

We had some helpers that built mock objects for us, however we could get round this by using traits in our test cases if need be.
Discussion
- PHPUnit 5.4.1 has been released with   to make `PHPUnit_Framework_TestCase::getMockBuilder()` public again.

However, I have to say that I have a hard time understanding why this method has to be `public`. It only makes sense to call from a subclass of `PHPUnit_Framework_TestCase` and for that `protected` is sufficient.
