Title

Discussion
- I have the impression that the repro test can be simplified even more as long as there is a WITH clause that is materialized.
- When executing the CTE materialization the ValidWriteIdList is queried from the JobConf. This is required for reading ACID tables referenced in the CTE. However the value is  null  because this is populated only if the plan has ACID read/writes. ACID read/writes are addressed in the  SemanticAnalyzer.validate()  method but this method checks only the main query plan for ACID tables and ignores materialized CTE plans.
- Merged to master. Thanks  InvisibleProgrammer  and  ayushtkn  for the review.
