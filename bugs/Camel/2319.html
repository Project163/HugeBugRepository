- You should use $simple{ } to avoid spring clashing with this, or set the option on the BridgePropertyPlaceholderConfigurer  to ignore unknown placeholderes. 

 Its a caveat when using this BridgePropertyPlaceholderConfigurer

- Not sure what you mean by $simple{}. Can you please correct the above example? 

 But besides this still think there is a bug. Because when first time it replaces all  {{file.rootdir}}  properties and returns the parsed one with nested spring placeholder it should not pass the whole  ${spring.nested}/${in.header.CamelFileName}  to resolve the nested ones but need to pass only the  ${spring.nested}  part.
- You should do 
  
     .setHeader(Exchange.FILE_NAME, simple( "{{file.rootdir}}/$simple{in.header.CamelFileName}" ))
