Title

camel-jms - TemporaryQueueReplyManager does not inherit doStop method

Description
TemporaryQueueReplyManager     extends   ReplyManagerSupport . Parent class contains method doStop(). But override method does not contains  super  .  doStop  (  )  call: 
  
 
    @Override
     protected  void doStop()  throws  Exception {
        ServiceHelper.stopService(destinationResolver);
    }
 
  
 So,  TemporaryQueueReplyManager  starts some services, but not stop it. This is not big problem in standalone applications, but problem in Karaf environment. If I install route with InOut jms endpoint, and then stop it or even uninstall it, camel-jms continues to use broker connections and temporary queues. Need to add  super  .  doStop  (  )  call: 
  
 
    @Override
     protected  void doStop()  throws  Exception {
        ServiceHelper.stopService(destinationResolver);
         super .doStop();
    }
