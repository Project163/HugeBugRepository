- You could subscribe to the users mailing list, there is a announcement a few days before a release so you can run your tests on a candidate and also an announcement when it's released, but of course there are other mails. 

 If you're using maven, then use the maven versions plugin  [URL] which will tell you what components have updates. 

 mvn org.codehaus.mojo:versions-maven-plugin:2.16.2:display-dependency-updates org.codehaus.mojo:versions-maven-plugin:2.16.2:display-plugin-updates org.codehaus.mojo:versions-maven-plugin:2.16.2:display-property-updates
