## 2.6.x Build fails with GCC 12.1.0 (Arch Linux)

Building SFML from source (2.6.x branch) fails with GCC 12.1.0.

## Environment

* Arch Linux, upgraded with `sudo pacman -Syu`
* 2.6.x branch
* GCC 12.1.0

## Steps to reproduce

1. Upgrade latest packages with `sudo pacman -Syu`
2. Install `ninja` and `cmake` if necessary
3. Build with:

```
bash
git clone -b 2.6.x [URL]
cd SFML
mkdir build
cmake -G Ninja -DCMAKE_C_COMPILER=/usr/bin/gcc -DCMAKE_CXX_COMPILER=/usr/bin/g++ -DCMAKE_BUILD_TYPE=Release -S . -B build
... [Log Snipped] ...
# Run a second time to see the error in question
```
