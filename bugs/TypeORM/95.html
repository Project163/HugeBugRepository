Also, just FYI, got the same issue as in #1686 . The problem was in the having the 2 keys for single relation:
```sql
  UNIQUE KEY `REL_e4a6fffee17f5467d57bff660e` (`communication_uuid`), -> New key name in 0.2
  UNIQUE KEY `IDX_e4a6fffee17f5467d57bff660e` (`communication_uuid`), -> This was produced by migration generator after upgrading from 0.1 to 0.2 
```

Deleting the IDX_ keys for relations solved the problem
