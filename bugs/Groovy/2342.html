Title

'class generation' bug when CompileStatic with HashMap and List

Description
The test.groovy code below throws 
  
 Caught: BUG! exception in phase 'class generation' in source unit 'test.groovy' At line 7 column 13
On receiver: AR.key with message: getAt and arguments: 0
 
  

  
 @groovy.transform.CompileStatic 
 class  MyClass{
  HashMap< String ,List<List>> AR= new  HashMap< String ,List<List>>()
  
  MyClass(){
    AR.get( 'key' ,[[ 'val1' ],[ 'val2' ]])
    println AR. 'key' [0]
  }
}

MyClass c= new  MyClass()
Discussion
- looks like the resolving of AR.key goes wrong and no type is stored for that PropertyExpression. What should have happened is that StaticTypeCheckingVisitor recognizes AR as map and handles AR.key as map access which returns a List<List> and then store that type. What seems to happen is that the type is built, but the case falls though everything in existsProperty. In other words the code fails silently
- fixed
