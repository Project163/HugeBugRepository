Title

[YSQL] Fix incorrect pggate mem tracking for TCMalloc usage

Description
Jira Link: [Link: DB-467]
### Description

In our mem_tracker.h, YB uses TCMalloc properties to retrieve the actual heap usage.
The current calculation for `GetTCMallocActualHeapSizeBytes()` is not accurate. As pointed in the original TCMalloc [Link: header], the `generic.heap_size` doesn't include `tcmalloc.pageheap_unmapped_bytes`. So subtracting 'tcmalloc.pageheap_unmapped_bytes' doesn't make any sense.
Regarding that we want to calculate the actual physical (sort of) usage in the heap, just simply use `generic.heap_size`.
Discussion
- The latest header with the definition of "heap_size" can be found [Link: here]. It turns out they changed the definition at some time. This means that our original implementation was correct. Reverting this commit.
