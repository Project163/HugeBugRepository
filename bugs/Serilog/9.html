Title

LogContext can't be used with System.Data.SqlClient: TargetInvocationException

Description
We have a scenario where we execute some SQL Scripts against a SQL Server. We've found that when  this code executes in the scope of a `LogContext.PushProperty()` the process fails with a `TargetInvocationException`. The stack trace indicates that the `ImmutibleStack<>` leveraged by `LogContext` fails to deserialize in a new AppDomain because the `Serilog.FullNetFx` can't be loaded.

Pertinent parts of the stack trace below:

- Thanks for the report Mike.

The challenge with this one is to find an `ImmutableStack ` type that can be loaded in the remote `AppDomain`... Not many options I can think of, besides trying to re-purpose something from the BCL (`LinkedList`?)

To work around the issue I've implemented the following:

``` csharp
using (LogContext.Suspend())
{
  // Make cross-domain call here
}
```
- whether or not it's an adequate workaround depends more on your scenario, let me know if it helps. Other ideas/suggestions welcome too.

Cheers!
