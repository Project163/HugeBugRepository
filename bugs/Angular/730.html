Title

Error due to reference to inexistant sourcemap in ngsw-worker.js

Description
### Versions
```
cli v6.0.0-rc
angular v6.0.0-rc.5
```

### Repro steps
* `npm install @angular/cli@next -g`
* `ng new helloworld`
* `cd helloworld`
* `ng g service-worker --project helloworld`
* `ng build --prod`

### Observed behavior
`ngsw-worker.js` contains a reference to a sourcemap:
`//# sourceMappingURL=ngsw_worker.es6.js.map`
but the sourcemap file doesn't not exist in distribution files (and should not, as this file is for prod), and as the CLI just copy `ngsw-worker.js` as is, then it produces a message in browser console.

### Desired behavior
No reference to sourcemap in `ngsw-worker.js`.
