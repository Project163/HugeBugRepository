Title

OCI registry being treated as Helm registry with failed update

Description
When running `helm dep up` on a dependency with a chart stored in an OCI registry I'm seeing the message:

```
Getting updates for unmanaged Helm repositories...
object required
...Unable to get an update from the "oci://ghcr.io/mattfarina" chart repository:
	object required
```

This is showing a bad message (i.e. `object required`) and it's trying to treat OCI as if it's a Helm repository.

OCI registries should not be attempted to be updated.

Output of `helm version`: tip of main (also in 3.7)
