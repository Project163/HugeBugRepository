Title

Question over entailment of owl:Class in OWL reasoners

Description
Consider this model: 

 <rdf:RDF 
    xmlns:rdf="[URL]
    xmlns:rex="[URL]
    xmlns:owl="[URL]
    xmlns:xsd="[URL]
    xmlns:rdfs="[URL]
  <rex:Location rdf:about="uri:c6c54ebb-a232-48cd-80fa-e4adf9cc5001#3"> 
    <rex:hasOriginalText rdf:datatype="[URL]
    >Pakistan</rex:hasOriginalText> 
  </rex:Location> 
</rdf:RDF> 

 With an OWL reasoner, rex:Location is not currently inferred to be of rdf:type owl:Class. This is arguably correct in OWL DL, but not in OWL Full. However, because the owl reasoner supports the property 'individualAsThingP', listIndividuals() on an OntModel containing the above fragment returns an empty iterator, which violates user expectations since uri:c6c54ebb-a232-48cd-80fa-e4adf9cc5001#3 appears on the surface to be an individual. 

 Possible resolutions include: more clearly documenting the current behaviour as correct, adding an OWL Full/DL mode to the reasoners, or adopting the less conservative stance that rex:Location should be an owl:Class and hence uri:c6c54ebb-a232-48cd-80fa-e4adf9cc5001#3 should be identified as an individual.
