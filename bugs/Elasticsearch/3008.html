Title

cluster.routing.allocation.awareness.force does not work like promised

Description
### Elasticsearch Version

8.12.0

### Installed Plugins

_bundled_

### OS Version

### Problem Description

According to [Link: docs] if not ALL nodes are available that will form complete list of cluster.routing.allocation.awareness.attributes
then replicas should not be STARTED but should be in UNASSIGNED state. 

In practice it does not work. Not only when node_left cluster which I simulate on my [Link: blog] and that can kill cluster but even when not all nodes that are part of cluster are being started.
