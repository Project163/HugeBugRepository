Title

create_check_constraint condition argument typing incorrect

Description
**Describe the bug**
The typing of condition argument is incorrect according to the documentation.
Definition:
create_check_constraint(constraint_name: Optional[str], table_name: str, condition: **BinaryExpression**, schema: Optional[str] = None, **kw) → Optional[Table]

The definition specifies the type for condition must be BinaryExpression, but in the documentation below.

condition¶ – SQL expression that’s the condition of the constraint. Can be a **string** or SQLAlchemy expression language structure.

[URL]

**Expected behaviour**
The typing for condition should be updated.

create_check_constraint(constraint_name: Optional[str], table_name: str, condition: **Union[str, BinaryExpression]**, schema: Optional[str] = None, **kw) → Optional[Table]

**To Reproduce**

```
py
from alembic import op


def upgrade() -> None:
... [Log Snipped] ...
        "applies_from_time < applies_to_time"
    )
```

Then run mypy test.py

**Error**

```

```
