Title

Shading of paths starting with / ignores excludes

Description
This commit addressed rewriting of resource paths that start with a slash, e.g. /org/my/company/resource.txt :  [URL]

   

 However, this rewriting ignores excludes. 

 It accounts for a leading slash when determining whether a path should be relocated:  [URL]

 And replaces the first occurrence anywhere within it (so also ignores leading slash):  [URL]

 However it applies excludes only at the exact beginning of the path:  [URL]

   

 So /org/my/company/resource.txt gets relocated even if org.my.company.** is in the excludes list.
