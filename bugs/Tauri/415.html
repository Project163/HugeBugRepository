Title

[bug] window is not defined when using 'convertFileSrc' in unit test

Description
### Describe the bug

I can't find anything about it in the changelog, but starting from tauri v1.5.0, I get `ReferenceError: window is not defined` when using `convertFileSrc` in a unit test. 

### Reproduction

1) Create unit test - I used vitest
2) Call function from my own code that contains `convertFileSrc` and test is inside the unit test

### Expected behavior

I would expect that this still works as it did `v1.3.0` and `v1.4.0`

And then for my test environment (I use vitest), I also had to configure it to use `jsdom` instead of the default:

```typescript
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    environment: 'jsdom',
  },
});
```
