Title

Number column gets displaced when multiple signs are used

Description
### Neovim version (nvim -v)

v0.7.0-dev+1242-gab456bc30

### Vim (not Nvim) behaves the same?

no idea

### Operating system/version

Arch Linux 5.16

### Terminal name/version

konsole 21.12.3

### $TERM environment variable

konsole-256color

### Installation

neovim-git (AUR)

### How to reproduce the issue

* `set number signcolumn=auto:3`
* Create a file with 100+ lines
* Go to a line over 100
* Set 2 icon signs on the line

This displaces the number column by one character **only on the line of the signs**.

The issue also occurs with `signcolumn=auto:1-3`.
Presumably it also occurs on files with fewer than 100 lines.

I cannot actually reproduce the issue with `nvim --clean` but reverting #17533 seems to fix it.
That's why I'm submitting it here instead of trying to figure out which plugin was broken by that change.
Feel free to close it if you think everything's working as intended.

### Expected behavior

The number column consistently moves to the right on all lines.

### Actual behavior

The number column is only displaced on a single line.
