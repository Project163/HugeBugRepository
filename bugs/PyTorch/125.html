Title

0-dim input tensor fails with `ArrayRef: invalid index Index` in `nn.Linear`

Description
### 🐛 Describe the bug

Reported in the discussion board: [URL]
Reproduced in the nightly with a minimal code snippet:
```
python
model = nn.Linear(1, 1)
x = torch.randn(1)

print(x.shape)
... [Log Snipped] ...
out = model(x)
# RuntimeError: ArrayRef: invalid index Index =  ; Length = 0
```

### Versions

`torch==2.3.0.dev20240202+cu121`

cc @albanD @mruberry @jbschlosser @walterddr @mikaylagawarecki @malfet
Discussion
- Seems to be related to the bias access, with `nn.Linear(1, 1, bias=False)`, I get the correct error:
```
RuntimeError: both arguments to matmul need to be at least 1D, but they are 0D and 2D
```

Edit:
Error happens here. As `input_sizes.size() == 0`, subtracting 1 underflows. I guess we should error out if `input` is 0D to be consistent with `at::matmul`.
