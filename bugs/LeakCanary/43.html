Title

Unit tests: Could not initialize class leakcanary.AppWatcher

Description
### Description

Unit tests fail with 

```
java.lang.ExceptionInInitializerError
	at leakcanary.AppWatcher.isInstalled(AppWatcher.kt:97)
	at leakcanary.AppWatcher. (AppWatcher.kt:63)
	at com.kolibree.android.sdk.core.LeakCanaryExtensionsKt.detectLeaks(LeakCanaryExtensions.kt:16)
	at com.kolibree.android.sdk.BluetoothStateReceiver$Companion.onAllConnectionObserversUnsubscribed(BluetoothStateReceiver.kt:53)
... [Log Snipped] ...
	at leakcanary.internal.InternalAppWatcher. (InternalAppWatcher.kt:36)
	... 55 more
```

### Steps to Reproduce

I have this dependency in my build.gradle (it's a library, so I think I need to use implementation and not debugImplementation)

```implementation "com.squareup.leakcanary:leakcanary-object-watcher-android:2.0"```

I've tried to use `testImplementation libraries.leakCanaryWatcher` without success

**Expected behavior:** [What you expect to happen]

Unit tests pass

I guess it fails when creating the `InternalAppWatcher` singleton instance

```kotlin
private val mainHandler = Handler(Looper.getMainLooper())
```

Would this work?

```kotlin
private val mainHandler by lazy {
    Handler(Looper.getMainLooper())
}
```

`isInstalled` will then be able to check that `::application.isInitialized` is false
