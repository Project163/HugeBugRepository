Title

Crash when using swagger generate client

Description
I've been trying to generate code for our swaggerfile, but the generator appears to be crashing. [URL] is the swaggerfile and this is the output:

```
% swagger generate client -f swagger.json bitbucket
2016/01/07 13:18:33 building a plan for generation
2016/01/07 13:18:33 planning definitions
2016/01/07 13:18:44 planning operations
2016/01/07 13:18:58 grouping operations into packages
... [Log Snipped] ...
2016/01/07 13:18:58 rendered model template: paginated_issues
template: docstring:1:28: executing "docstring" at  : nil pointer evaluating *generator.GenSchema.Title
```

The swaggerfile is valid, according to this tool.
Discussion
- I know what the issue is, but the fix is less than trivial. The crux of the issue is that the spec uses definitions that nest allOf with additionalProperties and discriminators and the spec nests those. 
Thanks for this spec!
- I've added this spec to my canary tests, meaning on every CI build it will try to generate a client and server for this specification and compile it with `go test ./...`

it would be great if you could send a [Link: PR] when you update your spec, so that we can be reasonably sure that we don't break bitbucket client generation again in the future.
