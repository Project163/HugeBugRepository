Title

Primitive types don't have default values

Description
In the following code, I declare a member as a primitive type.  In Java, it could never have a "null" value, and its value would default to 0.  But in Groovy: 

 groovy> class Foo  
{ public float x }
 groovy> y = new Foo() 
groovy> println y.x 
groovy> go 
null 

 So, when the primitive type is boxed (i.e. changed from float to Float), it should also get a default value if it doesn't already have one. 

 This is part of   GROOVY-683   that somehow got overlooked.
Discussion
- [URL]

 Now non-initialized fields of primitive types have default values like as Java does. 

     int type: default value is 0 
    long type: default value  is 0L 
    short type: default value is (short)0 
    byte type: default value is (byte)0 
    double type: default value is 0.0 
    float type: default value is 0.0F 
    char type: default value is (char) 0 
    boolean type: default value is false
