Title

Incorrect bounding-sphere calculation for BufferGeometry

Description
When multiple BufferGeometry instances are used, the bounding sphere for these instances are computed incorrectly. The bounding sphere for each buffer includes the data of all the preceding buffers.

The root of the bug is in the following var:

var box = new THREE.Box3();

That box should be reset within computeBoundingSphere() for each instance; it is not. 

Fix: add box.makeEmpty().
