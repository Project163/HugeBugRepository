Title

`torch.Tensor.aminmax` crash with `INTERNAL ASSERT FAILED` when input's shape contains 0

Description
### 🐛 Describe the bug

When `torch.Tensor.aminmax` recieves an empty input tensor on cuda, it will crash with `INTERNAL ASSERT FAILED`.
However, the same code can run well on CPU device and return:
```
torch.return_types.aminmax(
min=tensor([]),
max=tensor([]))
```

This unexpected behavior occurs on PyTorch 1.11.0\1.12.0\1.13.0\1.13.1, and even in the nightly version(2.0.0.dev20230219).
It should be related to [Ref: #85439]


### To Reproduce
```
python
import torch

def test(input):
    return torch.Tensor.aminmax(input,dim=0)
... [Log Snipped] ...
x=test(input.to(device))
print(x)
```

The error result is
```
Traceback (most recent call last):
  File "test.py", line 9, in  
    x=test(input.to(device))
  File "test.py", line 4, in test
    return torch.Tensor.aminmax(input,dim=0)
RuntimeError: iter.numel() > 0 && iter.ntensors() - iter.noutputs() == 1 && iter.noutputs() >= 1 INTERNAL ASSERT FAILED at "/opt/conda/conda-bld/pytorch_1670525552843/work/aten/src/ATen/native/cuda/Reduce.cuh":1134, please report a bug to PyTorch.
```

### Expected behavior
I hope this function could maintain consistent behavior on CPU and Cuda (e.g., fix crash behavior on Cuda).
