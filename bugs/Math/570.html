Title

Data race PolynomialUtils::buildPolynomial

Description
If you run PolynomialUtilsTest methods concurrently there will occur problem with ComparisonFailure due to incorrect building of coefficient list.  [URL] should be in synchronized block. Explanation: polynomial of given degree can be created by other thread  and when primary thread access synchronized block, there is already created coefficients for this degree, therefore no coefficients should be added to coefficients list.
Discussion
- Thanks for the report. It has been fixed in the following commits: 

 
	 3.6: fe23c9b04 
	 4.0: 487ac1980 
 

 The synchronization is now also on the coefficient list itself (which must be non-null), and thus there should be a slight performance improvement when creating different polynomials in multiple threads.
- Closing all resolved issues that were included in 3.6 release.
