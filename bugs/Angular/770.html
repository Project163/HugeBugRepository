Title

Router: regression in relativeLinkResolution since 7.0.0

Description
# 🐞 bug report

### Affected Package
The issue is caused by package @angular/router.

### Is this a regression?
Yes, the previous version in which this bug was not present was: `^6.1.0`

### Description
The `relativeLinkResolution: "corrected"` in Angular Router, which was introduced in [URL] is broken in Angular 7.


## 🔬 Minimal Reproduction
[URL]

* Click on the `/lazy/comp/b/comp/c` hyperlink
* Click on the `../../` relative hyperlink
* An error occurs: `Error: Cannot match any routes. URL Segment: 'lazy/comp/b/comp'
* Expected: route changing to `/lazy/comp/b`

This works on Angular 6.1: [URL]
