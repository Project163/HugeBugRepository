Title

[Process] Output fetched on windows platform might be corrupted

Description
This is related to #8953 and #9182. This has been fixed on *nix platforms but remains a problem on Windows. This has been reported in [URL]

The current implementation of reading pipes and controlling if the process is running has been reverted to the behavior were it was working, but the error still remains. The difference is that between now and the latest working version (2.3.3 AFAIK) is that we now use file handles for STDOUT and STDERR whereas it was used for STDOUT only previously.

I'm currently working on fixing this and cover it with unit test (current test suite works and windows on my machine) but I'd be happy if some people knowing low level windows process PHP implementation people could give a hand as we have to work with some unresolved bugs (https://bugs.php.net/bug.php?id=51800 and [URL]

Note : this happen on 2.2 / 2.3 and master branches
