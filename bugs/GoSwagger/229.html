Title

Optional Headers array parameters generated client code doesn't compile

Description
## Problem statement
When generating code for an API describing a header parameter X of array type, I got a "joinedX declared but not used" compilation error.

## Swagger specification
[URL]

```
yaml
swagger: '2.0'
# ...
paths:
  /example:
... [Log Snipped] ...
              type: string
'a reproducer for this ticket'
```

The corresponding generated code is incorrect functionnally (parameter isn't bound to the request) and doesn't even compile:
```go
// WriteToRequest writes these params to a swagger request
func (o *FooParam) WriteToRequest(r runtime.ClientRequest, reg strfmt.Registry) error {
        // ...
	valuesFoo := o.Foo
	joinedFoo := swag.JoinByFormat(valuesFoo , "")
	// nothing else is done with 'joinedFoo' variable before the return of that function, while I assume it should have been bound to 'r' with 'r.SetHeaderParam(...)'

```

## Steps to reproduce
For convenience I've made a reproducer available at this repository:
[URL] (follow instructions in README.md there).

Otherwise, call go swagger generator with a YAML similar to above example and try to include the generated code in a main go function -> go compiler will complain about the declared but not used variable.
```sh
# ...
pkg/example/client/operations/example_post_parameters.go:129:2: joinedFoo declared but not used
```

## Environment
swagger version: 0.25.0
go version: 1.15.6
OS:  Linux (Debian 10)
