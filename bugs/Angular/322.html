Title

A required checkbox should always be invalid if unchecked

Description
**I'm submitting a ...**  (check one with "x")

```
[x] bug report => search github for a similar issue or PR before submitting
[ ] feature request
[ ] support request => Please do not submit support request here, instead see [URL]
```

**Current behavior**

Given an ` ` with the `required` attribute, `ngModel` correctly considers it invalid to start with. Checking it correctly makes it valid, but after unchecking it it's still valid.

**Expected behavior**

A required checkbox should always be invalid if it's not checked.

**Reproduction of the problem**

[URL]

**What is the motivation / use case for changing the behavior?**

HTML5 Form Validation doesn't allow submitting a form if a required checkbox is unchecked. (Or at least that's how Chrome and Firefox work.)
- **Angular version:** 2.0.0-rc.6
- **Browser:** [all] 
- **Language:** [all]
Discussion
- To clarify the use case, suppose you have a typical registration form with a checkbox at the end saying something like "I accept the Terms & Conditions". How do you ensure the checkbox must be ticked if not by declaring it as required?
- Yeh, this looks like a valid bug. 

There are 2 ways of fixing it I can think of:
- quick & dirty: make the `CheckboxControlValueAccessor` write `null` instead of `false` when unchecked - not ideal as it is going to change model value assigned 
- have a separate `RequiredValidator` for checkboxes (we should probably also think of radios)
