### Workaround

If your manifest/icon file is static file like mine, this workaround might help:

Try moving the files into the public folder like this:
```
project-root
├── public
│   ├── manifest.json
│   └── icon.png
├── app
│   ├── layout.tsx
│   └── page.tsx
└── ...
```

Then specify their path in layout file's `metadata` object.
