Title

Wrong SQL string rendered when using both mssql_where and mssql_include dialect keywords on Index creation.

Description
**Describe the bug**
Usage both of mssql_include and mssql_where dialect keywords renders wrong SQL string.

In the provided example, the rendered string is:
```sql
CREATE INDEX idx_name_adult ON person (name) WHERE age > 18 INCLUDE (age)
```

**Expected behavior**
Correct SQL string should be rendered.

In the provided example, the rendered string should be:
```sql
CREATE INDEX idx_name_adult ON person (name) INCLUDE (age) WHERE age > 18
```

**To Reproduce**
Run provided Python code with appropriate SQL_CONN_STRING.
