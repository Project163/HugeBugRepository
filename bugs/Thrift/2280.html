Title

Wrong installation path for static MSVC libs.

Description
With   THRIFT-5109   the LIB_INSTALL_DIR for MSVC libs chanaged from lib/ to bin/ regardless if shared or static libraries were built. 

 While for shared MSVC libraries, installation to bin/ folder is correct, the commonly used installation path of static libraries (not only for MSVC) is the lib/ folder. The changes made in   THRIFT-5109   do not distinguish between static and shared MSVC libs. 

 Static MSVC libraries should be installed into the lib/ folder, as it has been done in 0.13.0.
