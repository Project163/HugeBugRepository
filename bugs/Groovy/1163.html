Title

Enum inside a class

Description
Iteration of enum defined inside a class fails with the following exception: 

 Caught: groovy.lang.MissingMethodException: No signature of method: 
static EnumTest2$Direction.values() is applicable for argument types: () 
values: [] 

 The following example demonstrates the problem    

 class EnumTest2 {   

   enum Direction  
{ North, East, South, West }
   

   static void main(args) {  
    for (d in Direction)  
{ 
      println d
    }

   } 

 }
Discussion
- I've experienced the same issue, but when trying to use the valueOf method. Appears to be looking to the containing class instead of the enum.
- Yes - valueOf(), next(), previous(), values() - all 4 methods are affected by it. Compiler is not adding these 4 methods to the enum when it is an enum defined inside a class due to some issue currently.
