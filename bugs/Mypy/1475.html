Title

Mypy daemon suggest does not accept windows paths

Description
**Bug Report**

 

The mypy daemon does not accept windows paths with the drive letter included properly.
Windows drive letters have colons in them, and 

[URL]

doesn't handle if it's on windows and the path starts with the drive letter.

**To Reproduce**

Use dmypy suggest on a windows machine and specify the path to be an absolute path that contains the drive letter.
```console
dmypy suggest "C:\Users\ \path\to\file.py:315"
```

**Expected Behavior**
Expected dmypy server to accept absolute path properly on windows
 

**Actual Behavior**

 
```
Malformed location for function: C:\Users\ \path\to\file.py:315. Must be either package.module.Class.method or path/to/file.py:line
```

**Your Environment**

 

- Mypy version used: `mypy 1.16.1 (compiled: yes)`
- Mypy command-line flags: N/A
- Mypy configuration options from `mypy.ini` (and other config files): N/A
- Python version used: Python 3.13.4
