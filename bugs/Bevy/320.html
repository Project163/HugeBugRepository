- A previous instance of this bug was dependent on scale factor, and that seems to be the case here too.

Adding
```

    primary_window: Some(Window {
        resolution: WindowResolution::default().with_scale_factor_override(1.),
        ..default()
    }),
    ..default()
}))
```
