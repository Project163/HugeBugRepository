Title

re-defining exception parameter in catch block throws runtime exception

Description
We were attempting to compile some external libraries and came across this issue, it's bad 
javascript and easily fixed, but here's a reduced version of the js that triggers the error if it's 
something you guys are interested in fixing:

 What steps will reproduce the problem? 

1. compile this code at simple or advanced level: (http://gist.github.com/416406)
foo = function() {
  try{
    var a = 0;
  }catch(e){
    var e = 1;
  }
};

 What is the expected output? What do you see instead? 

java.lang.RuntimeException: java.lang.RuntimeException: INTERNAL COMPILER ERROR.


 What version of the product are you using? On what operating system? 

current version up on [URL] and the version I downloaded 
today (5/27/10) can't find a version number)

 Please provide any additional information below. 
If you simply reassign the parameter it works fine.
