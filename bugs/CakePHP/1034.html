Title

Pagination Helper creating wrong links when using root URL

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 4.0.5
* Platform and Target: PHP 7.3, MySQL, Ubuntu

### What you did
I added `$builder->connect('/', ['controller' => 'Pictures', 'action' => 'index']);` to my routes.php to list my pictures at the root of my url in paginated form.

### What happened
The URL generated by `$this->Paginator->first()` and ` $this->Paginator->prev()` (for the first page) is now **mywebsite.com/pictures**. When I remove `$builder->fallbacks();` from routes.php I get Missing-Route-Exception-Error.

### What you expected to happen
I'd expect the first- and prev-functions to return the right URL for the first page, which after my change in the routes.php should be **mywebsite.com** instead of **mywebsite.com/pictures**. Also it shouldn't give me the Missing-Route-Exception-Error after removing the fallback as I already declared the route in my routes.php.
