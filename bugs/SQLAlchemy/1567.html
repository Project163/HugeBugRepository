Title

Date column definition raises `TypeError` since sqlalchemy `2.0.37`

Description
### Describe the bug

After upgrading to sqlalchemy `2.0.37`, a simple ORM table definition involving `Date` columns results in an unexpected `TypeError`.
I can confirm that the bug also occurs with sqlalchemy `2.0.38`, but not `2.0.36` and below.

Discussion
- Hi,

The issue is on your code. The `date` in mapped is not the date class but the `date` column.

You need to either alias it or use `datetime.date`

Use
```
py
import datetime
from sqlalchemy import Date, BigInteger
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

... [Log Snipped] ...
    id: Mapped[int] = mapped_column(BigInteger, primary_key=True)
    date: Mapped[datetime.date] = mapped_column(Date, nullable=False)
```
