Title

Allman brace style is not honored for switch statements

Description
I would expect that if `"allman"` is specified for `brace-style`, ESLint would ensure that the opening brace of a switch statement is on a new line. However, ESLint [Link: always] ensures that the brace is on the same line as the controlling statement. In ESLint 1.5.1, given the input:

``` js
/* eslint brace-style: [2, "allman"] */

switch (1)
{
    case 1:
       break;
}

```

ESLint outputs the error:

```
3:1  error  Opening curly brace does not appear on the same line as controlling statement  brace-style
```
Discussion
- Verified this in the demo. It looks like switch statement is not covered for some reason.
- @ilyavolodin Comparing with "1tbs" is wrong, because "stroustrop" then fails to do the right thing. #4003 is correct.
