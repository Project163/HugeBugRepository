Title

User-Agent changes from configured value

Description
When using the ZAP gui I found that in certain circumstances the default user agent defined in tools-options-connection was not used. Instead an older user agent was used.

To reproduce, set value to 'Firefox 39.0 Win8.1 64-bit' and attack a URL.

Expected behaviour is that all pages will be attacked with the same user agent that has been set as above.
