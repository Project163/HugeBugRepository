# 📚 Docs or angular.io bug report

### Description

"http" text for example purposes in the Location Strategy API page (http://localhost:4200/api/common/LocationStrategy#description) description is linking to the HTTP API (http://localhost:4200/api/common/http)

## 🔬 Minimal Reproduction

### What's the affected URL?**
[URL]

### Reproduction Steps**
- Go to [URL]
- Click on 'http' in [URL] or [URL] in description paragraph

### Expected vs Actual Behavior**
I would expect it to not go to the http API as it is just 'example text' and not pertaining to the http API

## 📷Screenshot
- This is sort of a known limitation of our auto-linking feature (which is heuristic-based).
As a work-around, you can use ` Code here `.

Since in this case we can reliably detect that `[URL] does not refer to the `http` package, we should be able to improve our heuristics to exclude such code snippets from matching auto-linking (I've found 11 occurrences of this across all guides and API docs from a quick search).
