Title

Remove TDZ scopes

Description
From #10227.

```js
for (var key in obj)
    ;
```

In this case, `eslint-scope` makes a TDZ scope around `obj`. The TDZ scope steals reference objects in `ForInStatement#right` then it has caused bugs. TDZ is the word about a timing matter rather than a structure matter, so it's wrong that `eslint-scope` makes TDZ scopes. Actually, all our core rules just ignore the TDZ scopes.

We should remove the TDZ scopes.

However, I think that we should take the removal of TDZ scopes as a breaking change because the TDZ scope has existed in our variable analysis while over 3 years ago.
