Title

max-duration does not stop transfers if retries > 1 are specified

Description
#### The associated forum post URL from `[URL]
[URL]

#### What is the problem you are having with rclone?
`--max-duration` does not stop jobs as expected but instead triggers retries up to the `--retries` specified. This seems unexpected from the docs description of retries:
```
--retries int
Retry the entire sync if it fails this many times it fails (default 3).
```
as I would not consider hitting the specified `max-duration` a failure. The docs for `max-duration` also don't indicate this:
```
--max-duration=TIME
Rclone will stop scheduling new transfers when it has run for the duration specified.
Defaults to off.
When the limit is reached any existing transfers will complete.
```

This seems related to the forum post above (not posted by me), and to these previously filed issues:  [URL] and [URL] However the forum post indicates it should be fixed with the latest 1.58.0 beta, and even with that I still see the issue.

I've included a debug log demonstrating this, but to summarize what I think are the relevant parts: a copy job to an encrypted Backblaze B2 remote with `"--max-duration=5m"` and `"--retries" "3"`.  The job begins by setting a deadline 5 minutes out:
```
2022/02/19 11:01:17 INFO  : Encrypted drive 'b2cryptsse:max_duration_test/Photos/archives': Transfer session deadline: 2022/02/19 11:06:17
```
At the 5-minute mark, the logs indicate it has hit the deadline but then begins a repeat of the same job with a new deadline another 5 minutes later, also doing file comparisons of the files that had already been uploaded:
```
2022/02/19 11:06:17 ERROR : photos_2021.zip.004: Failed to copy: Post "[URL] context deadline exceeded
2022/02/19 11:06:17 ERROR : photos_2021.zip.002: Failed to copy: Post "[URL] context deadline exceeded
2022/02/19 11:06:17 ERROR : photos_2021.zip.001: Failed to copy: Post "[URL] context deadline exceeded
2022/02/19 11:06:17 ERROR : photos_2021.zip.003: Failed to copy: Post "[URL] context deadline exceeded

...[Description Truncated]...
