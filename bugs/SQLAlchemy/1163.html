Title

Error while using conn.execution_options and pool_pre_ping=True

Description
**Describe the bug**
 

I cannot use` conn.execution_options(postgresql_readonly=True)` along with `pool_pre_ping=True` on `create_engine`. If I do, I get a `psycopg2.ProgrammingError: set_session cannot be used inside a transaction` error the second time I try to
execute a query. Not sure if this is expected, but it's not mentioned in [Link: these docs].
