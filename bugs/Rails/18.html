Title

Rails 3.2.13.rc1 regression: distinct select + pluck

Description
## Steps to produce
1. `git clone git://github.com/iamvery/rails-3.2.13.rc1-pluck-regression.git`
2. `cd rails-3.2.12.rc1-pluck-regression`
3. `bundle install`
4. `bundle exec rake db:create:all db:schema:load db:seed`
5. `bundle exec rails c`
### 6. From the console

**Note output from rails 3.2.13.rc1**

``` bash
   (0.1ms)  SELECT "widgets"."name" FROM "widgets"
 => ["thing", "thing", "thing"]
```

**Recall output from rails 3.2.12**

``` bash
   (0.2ms)  SELECT DISTINCT "widgets"."name" FROM "widgets"
 => ["thing"]
```

It seems logical that this regression may have been introduced in #7551, but I have not taken the time to confirm that in code.

**Note**: It's also worth mentioning that according to [Link: the docs], the "right" way to do this is using `Widget.uniq.pluck(:name)`. I believe this would be recommended moving forward, but I still feel it's worth filing a regression because our tests failed post update.
