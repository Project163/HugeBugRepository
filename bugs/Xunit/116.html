Title

`CaptureConsoleAttribute` does not capture console output from constructors for first test case

Description
`CaptureConsoleAttribute` uses `BeforeAfterTestAttribute` to replace console output stream with a captured stream.

Because `.Before` is only called after test classes are constructed and initialized (in the case of `IAsyncLifetime` implementations), any output from the constructor or `.InitializeAsync` methods is not captured by the first test which runs.

To reproduce, you can run any test class with console output 

[Image: Image]

When running the tests together, the first to run has no output.

[Image: Image]

The second test case captures the output as expected.
