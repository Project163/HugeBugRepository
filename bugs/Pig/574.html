Title

New logical plan: self-join fail for some queries

Description
The following script fail:  

  
 A = load  '1.txt'  AS (a0: int , a1: int , a2: int );
B = foreach A generate a0, a1;
C = join A by a0, B by a0;
D = filter C by A::a1>=B::a1;
dump D;
