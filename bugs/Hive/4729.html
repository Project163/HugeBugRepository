Title

Use of USE_DEPRECATED_CLI environment variable does not work

Description
According to  [URL] if we set USE_DEPRECATED_CLI=false it should use beeline for hiveCli. But it doesn't seem to work. 

 In order to reproduce this issue: 
  
 $ echo $USE_DEPRECATED_CLI

$ ./hive
Hive-on-MR is deprecated in Hive 2 and may not be available in the future versions. Consider using a different execution engine (i.e. tez, spark) or using Hive 1.X releases.
hive>
$
$ export USE_DEPRECATED_CLI=false
$ echo $USE_DEPRECATED_CLI
false
$ ./hive
Hive-on-MR is deprecated in Hive 2 and may not be available in the future versions. Consider using a different execution engine (i.e. tez, spark) or using Hive 1.X releases.
hive>
Discussion
- The issue is in ext/cli.sh file 

 The single quotes in the following section of script is what is causing the issue 
  
 # Set old CLI as the default client
if [ -n '$USE_DEPRECATED_CLI' ]; then
  USE_DEPRECATED_CLI="true"
fi
 
  

 In order to confirm 

  
 $ echo $USE_DEPRECATED_CLI
false
$ echo '$USE_DEPRECATED_CLI'
$USE_DEPRECATED_CLI
$
 
  

 The fix should be to remove the single quotes around USE_DEPRECATED_CLI
- I don't think there is a test case that executes cli.sh, and tests were not executed either way.
