Title

Can not setParallelism for FLIP-27 source

Description
The constructor for new Sources in  DataStreamSource  does not set isParallel to true. So if we setParallelism for FLIP-27 source, there will be a validation exception from validateParallelism.
Discussion
- Hi  lzljs3620320  , 

 master  
  
 
/**
 * Constructor  for   new  Sources (FLIP-27).
 */
 public  DataStreamSource(
      StreamExecutionEnvironment environment,
      Source<T, ?, ?> source,
      WatermarkStrategy<T> timestampsAndWatermarks,
      TypeInformation<T> outTypeInfo,
       String  sourceName) {
    super (environment,
          new  SourceTransformation<>(
               sourceName,
                new  SourceOperatorFactory<>(source, timestampsAndWatermarks),
               outTypeInfo,
               environment.getParallelism()));
}
 
  
 I want to change to the following 
  
 
/**
 * Constructor  for   new  Sources (FLIP-27).
 */
 public  DataStreamSource(
      StreamExecutionEnvironment environment,
      Source<T, ?, ?> source,
      WatermarkStrategy<T> timestampsAndWatermarks,
      TypeInformation<T> outTypeInfo,
       String  sourceName) {
    super (environment,
          new  SourceTransformation<>(
               sourceName,
                new  SourceOperatorFactory<>(source, timestampsAndWatermarks),
               outTypeInfo,
               environment.getParallelism()));
    this .isParallel =  true ;
}
