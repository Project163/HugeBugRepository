Title

When using PEP-526 to specify the type of a class variable and then attempting to docstring it, I get "String statement has no effect (pointless-string-statement)"

Description
This issue was first discussed at [URL] . I realize this is a gray area in Python docstrings but this warning is a barrier (for my project at least) to fully embracing PEP-526. As with #193 I would like pylint to ignore this use of docstrings.

### joe.py
```
"""Module docstring"""
class Joe(object):
    """Class docstring"""
    counter: int
    """Data docstring"""
```

### pylint x.py
```
************* Module joe
W:  5, 4: String statement has no effect (pointless-string-statement)

---------------------------------------------------------------------
Your code has been rated at 6.67/10
```
