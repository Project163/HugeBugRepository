Title

Description
### What steps will reproduce the problem?

Attempt to save object into a session variable:

``` php
Yii::$app->session->set('user', Yii::$app->assetManager);
Yii::$app->session->close(); // throws an exception
exit;
```

Session table DDL:

``` sql
create table "session"
(
    "id"  varchar(256) not null,
    "expire" integer,
    "data" bytea,  /* Binary string column has been used as it should be, text - would not work */
    primary key ("id")
);
```
