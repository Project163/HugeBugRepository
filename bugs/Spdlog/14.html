Title

Possible memory bug in spdlog_ex ?

Description
I noticed that spdlog_ex, inherit from runtime_error overwrite  `const char* what()` and returns pointer to function local memory_buffer. 

In my usage case,   a catched exception returns me an garbage string.

It could be that this, is a side effect of something else, but if anyone get similar problem... the following diff make the format early, and let runtime_error save the string internal. (It's not easy to save a string without allowed to throw exception ;)

here the diff to common.h spdlog_ex:
```
diff

--- a/include/spdlog/common.h
+++ b/include/spdlog/common.h
```
