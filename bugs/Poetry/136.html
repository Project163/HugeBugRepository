Unfortunately, this page has relative paths with double dots, and poetry fails to resolve the correct wheel URLs. I believe the issue lies here: [URL]

Once a trailing slash is added, (https://download.openmmlab.com/mmcv/dist/cu113/torch1.12/index.html => [URL] `urllib.parse.urljoin()` fails to properly join the urls here: [URL]
```python

```

Basically, we shouldn't always add trailing slashes to URLs.
