Title

First argument of for loop not evaluated in parent scope

Description
```php
for ($i = 0; $i < 5; $i++);
echo $i;
```

emits a PossiblyUndefinedVariable exception, and it shouldn't, as it's directly equivalent to

```php
$i = 0;
while ($i < 5) {
  $i++;
}
echo $i;
```

which is correctly evaluated
