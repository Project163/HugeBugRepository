Title

2.x - Router and possible duplicate content

Description
CakePHP allows to access content using double slashes in the beginning of the url, which can lead to duplicate content.

Example url:
[URL]

Can also be accessed via:
[URL]

Seems the url is trimmed for/normalized for leading slashes somewhere?

This can be done to all urls in a CakePHP app.

CakePHP doesn't know what is correct. It is depend on application.
