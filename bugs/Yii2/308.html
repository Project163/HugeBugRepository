Title

ActiveField::checkbox() render duplicate labels

Description
When use code

``` php
 field(
    $model,
    'is_registered',
    ['template' => '{input}{label}{error}']
  )->checkbox()->label()
 ?>
```

it render HTML like

``` html
 
   
  My label
 
 My Label 
```

instead 

``` html
 
 My Label 
```
Discussion
- You should use `->checkbox([],  false)` or `->checkbox(['label' => null])`.
- I used 

``` php
->checkbox([], false)
```

and it doesn't work, but 

``` php
->checkbox(['label' => null])
```

works fine. I thank that $enclosedByLabel  = false is disabling enclose by label
- Just checked in a fix. Both should work fine now. Thanks.
