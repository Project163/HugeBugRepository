Title

Building a shared library with shared library dependencies broken on macOS as of Bazel 0.4.4

Description
Currently the macOS GPU build of TensorFlow is broken on Bazel 0.4.4.

A simple test case that works on Bazel 0.4.3 but breaks on Bazel 0.4.4 on macOS:
```
mkdir test
cd test
cp /usr/lib/libz.dylib .
```

BUILD file:
```
cc_library(
  name = "libz",
  srcs = ["libz.dylib"],
)

... [Log Snipped] ...
  linkstatic = 1,
)
```

Empty WORKSPACE.

foo.cc:
```
int blah() {
}
```

`bazel build libfoo.so` works on Bazel 0.4.3 but doesn't work on Bazel 0.4.4. The link flag went from `-lz` to `-Wl,-force_load,-lz`which gives the error `ld: file not found: -lz`
