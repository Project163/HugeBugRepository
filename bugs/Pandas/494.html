Title

Sort broken after unique -> Series with object array

Description
I have no idea why this fails.

```
pandas.Series(pandas.Series(["a","c","b"]).unique()).sort()
```

but this doesn't

```
pandas.Series(np.array(["a", "c", "b"], dtype=object)).sort()
```
