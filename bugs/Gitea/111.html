## Description
A user is not removed from an organization's member list when removed from (the last team). The user has no access to the repositories but she can still enumerate all team members of the organization.

### Steps to reproduce
* Create a new organization
* Add a private repository to the organization (owner team)
* Create a new user: user1
* Add a new team: team1 (read perm with access to the private repository)
* Add user1 to team1
* User1 can clone the repository and inspect it in the UI: OK
* Remove user1 from team1: user1 is no longer a member of any team in the organization. She is, however, still listed under the organization's members list (People).

Therefore, to fully remove a user from an organization, one has to remove it from all teams and remove it from the members list. I expected that the user is automatically removed from the members list as soon as she is no longer part of any team.
