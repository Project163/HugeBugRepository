Title

Precedence of operator not behaving properly

Description
The precedence of the operators ( especially with !== and && ) in Dataframe Columns seems to be messed up. 

 Example Snippet 

 .where( $"col1" === "val1" && ($"col2"  !== "val2")  ) works fine. 

 whereas .where( $"col1" === "val1" && $"col2"  !== "val2"  ) 
evaluates as ( $"col1" === "val1" && $"col2" ) !== "val2"
Discussion
- I can reproduce it. Let me investigate it.
- This is affected by the operator precedence in Scala. There does not exist a simple fix to resolve this issue.  

 For another example, the Scala compiler is unable to recognize the following syntax: 
where ( $"col1" !== "val1" && $"col2" === "val2" )
