Discussion
- You can probably workaround this if you add `--enable-all-security-services` to the `native-image` call that quarkus makes so that all security algorithms are added. By default this is false, since each Quarkus service adds only what it needs. I've not looked at the Quarkus code in detail, but chances are that the Quarkus/Vert.x integration should add RSA as one of the security algorithms it should make available.
- Do you mean by adding "--enable-all-security-services" to docker file image while building or as a run argument to the native file ?
