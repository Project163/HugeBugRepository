Title

SQL: SUM of multiple 0 values returns NULL

Description
Given:
- `SELECT SUM(val) FROM test WHERE val IS NOT NULL GROUP BY name`
- all `val` values are 0 for a certain `name` value

The result of the above query will return NULL, whereas the result should be 0. This boils down to `AggregationInspectionHelper.hasValue(InternalSum)` that will return `true`/`false` if the sum is 0: [URL]
We use these methods to decide if the result of aggregations has a value or not.
