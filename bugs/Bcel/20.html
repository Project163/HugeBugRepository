Title

Verification error when an invoke references a method defined in superclass

Description
Assuming a class A with a method foo() and a class B subclass of A. If an invoke opcode references the method B.foo() then the bytecode verifier raises an error with the following error message: 
 
 Referenced method 'foo' with expected signature '()void' not found in class 'B'. The native verifier does allow the method to be declared in some superinterface, which the Java Virtual Machine Specification, Second Edition does not.  

 I can't find where in the  Java Virtual Machine Specification, Second Edition  this restriction is defined. 

 The verification of the bytecode generated by the following code fails: 
  
  public   class  TestLegalInvokeInterface01{

     public   static  void test1(Interface01 t){
        t.run();
    }
}

 interface  Interface01  extends   Runnable  {
    
}

- Here is some element of the  Java Virtual Machine specification  about this issue 
 [URL]
 
 Method resolution attempts to look up the referenced method in C and its superclasses: 
    If C declares a method with the name and descriptor specified by the method reference, method lookup succeeds. 
    Otherwise, if C has a superclass, step 2 of method lookup is recursively invoked on the direct superclass of C.  
Otherwise, method lookup attempts to locate the referenced method in any of the superinterfaces of the specified class C. 
    If any superinterface of C declares a method with the name and descriptor specified by the method reference, method lookup succeeds. 
    Otherwise, method lookup fails.   
 Since the old revision of the  Java Virtual Machine specification , some precisions have been added to this chapter. You can find the last revision here:  [URL]
