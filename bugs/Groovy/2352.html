Title

groovy compiler throws ArrayIndexOutOfBoundsException when combining @CompileStatic with @ToString/@EqualsAndHashCode with certain property names

Discussion
- from a short look I can tell the following: there is a  dynamic  method call to getaList. With dynamic I mean that there is no set target for this. That means the invocation writer fails to make the direct method call and falls back to calling makeCallSite, which is empty in the static invocation writer. The result is that no value is placed on the stack, resulting in the operend stack related exception seen above.
- fixed by correcting the way property names are build
