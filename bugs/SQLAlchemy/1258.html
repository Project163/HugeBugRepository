Title

raise an error if stream_results is used with async / .execute() / Result, does not seem to be working

Description
program crashes after a few rows, looks like when it tries to re-buffer results.  

by definition this can't work because the Result is not an async object, they should use session.stream().

we have a lot of sync stream_results tests that should be failing for asyncpg etc.   so maybe add more rows and then set up requirement blocks.
