Title

export var a, b, c doesn't get split up

Description
This results in three 'synthetic nodes', allowing a single binding to be included in the bundle:

``` js
var a = 1, b = 2, c = 3;
export { a, b, c };
```

But the same doesn't work if you do it like this:

``` js
export var a = 1, b = 2, c = 3;
```
