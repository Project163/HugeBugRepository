Title

Attribute decorator should allow attribute name as optional

Description
# 🐞 bug report

### Affected Package
@angular/core
@angular/compiler

### Is this a regression?
Not sure, but I think not.

### Description
Attribute decorator is defined in `@angular/core` with `attributeName` as optional, but compiler throws an error when attributeName is missing.

I consider this a bug cause compiler doesn't meet the core specification.

## 🔬 Minimal Reproduction

This works

```typescript
constructor(@Attribute('customAttr') customAttr: string){}
```

This doesn't work

```typescript
constructor(@Attribute() customAttr: string) {}
```
