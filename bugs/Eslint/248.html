Title

es6jsx branch issue with variable not defined in arrow function

Description
The es6jsx branch of eslint says the variable obj is undefined on the second line below:

```
myArr.forEach(obj => {
  console.log(obj);
});
```

This is wrong because obj is a parameter to the arrow function that is passed to forEach.
Discussion
- Related to #917. We use escope to calculate such things, and it only recently was updated to work with ES6. I'll leave this open just to verify when we upgrade.
