Title

Global is different from local state when ignoring files

Description
Syncthing :

add TestDir,
save (No need to share or any special option)

Open file manager into the directory TestDir
create :
- NewDir
- file.txt
- file.pdf
copy file.* into NewDir

Syncthing :
Open TestDir,
check display to see global = local state : 4 files 1 folder

Edit share
Click button Ignore Patterns
enter :

```
(?i)!*.pdf
/*

```
Save,
save.

Check global state : 4/1; local 2/0 Vs reality 4/1

Open file manager into the directory TestDir/NewDir
delete file.txt

Syncthing :
rescan
Check global state : 4/1; local 2/0 Vs reality 3/1

Quite confusing as there is no share with other device already enabled; global should equal local and/or reality. At least, global shouldn’t be greater than reality. 
Thanks !
