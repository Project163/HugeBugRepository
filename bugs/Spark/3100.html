Title

Problem accessing Web UI /logPage/ on Microsoft Windows

Description
A calculated path can be built with a mixture of \ and /. The problem is with the "\" character. This is there because, when using Windows, the "path.separator" System Property used by the java.io.File class is set to "\". This is what is used to create the initial part of the path. The "/" in the rest of the path are hard-coded in the Spark code.
