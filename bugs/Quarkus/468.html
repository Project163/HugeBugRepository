Title

Quarkus gradle build fails with flatDir

Description
**Describe the bug**
I'm using gradle to build quarkus project.
I've got jar dependencies that are in my projects 'lib' folder that I need to include as dependencies.
When trying to build the project it fails

**Expected behavior**
It should build and start

**Actual behavior**
Build fails without any clear reason.


**To Reproduce**
Steps to reproduce the behavior:
1.  Create a sample quarkus project with gradle as a build tool
2.  Create a lib folder in your project, add some jar
(I have downloaded the appache commons lang3)

3.  Add a flat dir repository to your build.gradle file, like:
flatDir {
        name = 'Local lib'
        dir file('lib')
    }
4.  Add a dependency in your project like:
implementation ':commons-lang3-3.9'

**Note**
I ran the quarkusBuild target with **--stacktrace** and it gives this error:

`Caused by: java.lang.ArrayIndexOutOfBoundsException: 2
	at io.quarkus.gradle.AppModelGradleResolver.toAppDependency(AppModelGradleResolver.java:194)
	at io.quarkus.gradle.AppModelGradleResolver.resolveModel(AppModelGradleResolver.java:134)`

So I think it must be an issue with the quarkus gradle plugin.
