Title

Please do not turn off default features for url

Description
### Bug Description

In [URL] , sqlx-core turned off default features for `url` even though `url` didn't have default features at the time. This is disruptive now that `url` has introduced default features in order to manage catering to both the pre-existing MSRV-sensitive audience and to new no_std audience: [URL]

Could you, please, remove `default-features = false` for `url` and publish a release?

### Minimal Reproduction

````sh
rustup default 1.80
cargo new idna-992-repro
cd idna-992-repro/
cargo add sqlx
cargo check
````
