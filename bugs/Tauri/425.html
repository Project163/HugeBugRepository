Title

[bug] What size should the icon use? 1024x1024px or 1240x1240px?

Description
### Describe the bug

As the [Link: official document] demonstrate, which print the icon size is 1024x1024px. 

But I found that is 1240x1240px when I run the command in my computer.

 And I found the [Link: source code] is also 1240px, and there is a TODO marks "Confirm 1240px"

### Reproduction

Run command `npm run tauri icon -h` in terminal.

### Expected behavior

Documentation should be consistent with the actual cli execution prompts, otherwise it will confuse users.
