Title

CompilerConfiguration copy constructor does not copy compilation customizers

Description
Consider the following: 
  
 
 import  org.codehaus.groovy.control.*
 import  org.codehaus.groovy.control.customizers.*

 def  config =  new  CompilerConfiguration()
config.addCompilationCustomizers( new  ImportCustomizer().tap {
  addStarImport( 'groovy.transform' )
})

 def  clone =  new  CompilerConfiguration(config)
 assert  clone.getCompilationCustomizers().size() == 1
 
  

 Trying to copy from a base config (like one set up by STC and SC unit tests) results in missing the compilation customizers.
Discussion
- The changes for this are relatively simple but when applied break gradle somehow. 

  org.gradle.api.internal.tasks.compile.ApiGroovyCompiler$TrackingClassGenerationCompilationCustomizer  is throwing an NPE and  :groovy-macro:compileGroovy  fails. 

 I'd guess gradle is using the copy constructor and assuming that the new config has no customizers but I haven't tracked it down fully yet, so it could be something else.
