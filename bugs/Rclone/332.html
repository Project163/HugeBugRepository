Title

Problem: Azure listChunkSize is not configurable

Description
#### What is the problem you are having with rclone?

In one of my instances, Rclone fails to list the cointainer files when using --fast-list.

I was able to work around this by changing the default value for [Link: listChunkSize] from 5000 to 1000 (tried 2500, but also failed in this host) and rebuilding rclone.

It would be nice to have this as a command line option.
