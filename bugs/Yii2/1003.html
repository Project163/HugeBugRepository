Title

maxlength not present in GridView filter on top by default.

Description
### What steps will reproduce the problem?
I have a Model
I have a FindModel (not a extend of Model, search function of FindModel return DataProvider with Query for Model)
I heve a rule for FindModel [['attribute'], 'string', max=>10]
I have a index view and 
I have a GridView where used dataProvider and search model.

### What is the expected result?
Filter text field within 'maxlength' = 10 in tag
### What do you get instead?
Filter with infinity length text field

note: for ActiveField this behavior is enabled by default.
for filter I must redefine column settings:
```
            [
                'attribute' => 'attribute',
                'filterInputOptions' => ['maxlength' => true],
            ],
```
or
```
            [
                'attribute' => 'attribute',
                'filterInputOptions' => ['maxlength' => 10],
            ],

```
instead of 
```
'attribute',
```
