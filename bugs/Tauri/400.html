Title

[bug] double tap on data-tauri-drag-region doesn't work

Description
### Describe the bug

At least on macOS double tapping data-tauri-drag-region doesn't do anything. Double click does maximize/unmaximize.

### Reproduction

Create an app with a data-tauri-drag-region element and double tap on it.

### Expected behavior

Double tapping should do the same as double clicking.
