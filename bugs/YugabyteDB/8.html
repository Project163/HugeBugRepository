Title

Redis Set options NX and XX return errors instead of null values

Description
Currently when setting a key with the NX option, and the key already exists, we return an error instead of a null reply. Similarly, when setting a nonexistent key with the XX option, we return an error instead of a null reply.

YB output:
```
 :6379> set k 1 nx
OK
 :6379> set k 1 nx
(error) Unknown error
```

Redis output:
```
 :13412> set k 1 nx
OK
 :13412> set k 1 nx
(nil)
```
