Title

remove use of deprecated guava methods

Description
When running in a non-osgi environment it's sometimes necessary to use a more recent version of the guava dependency due to requirements of other components. By changing the use of methods that are deprecated in later version of guava, eg. v 19.0, it is possible to use any guava version between 15.0 (current) and 19.0.
