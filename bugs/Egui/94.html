Title

text rotation doesn't respect anchor

Description
**Describe the bug**

When rotating a TextShape, the center of rotation is the LEFT_TOP, regardless of the anchor used when creating the text with `egui::Shape::text`.  I think the more useful behavior is to rotate about the anchor point.  I can make a PR if folks agree that that is the right behavior.

**To Reproduce**

```
rust 
        let pos = Pos2::new(1000.0, 1500.0);
        let text = "Sample Text";

        let label = ctx.fonts(|f| {
... [Log Snipped] ...
            egui::Color32::DARK_RED,
        ));
```

**Expected behavior**
I _think_ we should rotate about the anchor point. So in this example, the same point on the text would remain on top of the dot.  If not, a lot of complicated math gets pushed back onto the user in order to fix this.
