Title

web-fragment.xml support introduced in 0.16.0 is broken

Description
`ZipPath` does not support `toFile()` so this code won't work:
[URL]
and throw:
```
Caused by: java.lang.UnsupportedOperationException
at com.sun.nio.zipfs.ZipPath.toFile(ZipPath.java:597)
at io.quarkus.undertow.deployment.WebXmlParsingBuildStep.parseWebFragments(WebXmlParsingBuildStep.java:109)
at io.quarkus.undertow.deployment.WebXmlParsingBuildStep.createWebMetadata(WebXmlParsingBuildStep.java:88)
```

This is annoying because as long as you have a jar with a `web-fragment.xml`, you're not able to compile your application anymore.

Note: we should probably have a test for that. We already have a few tests with external jars (for JPA entities). It would be safer.
