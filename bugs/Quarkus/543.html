Title

OIDC initialization race condition in DefaultTenantConfigResolver in the native image

Description
**Describe the bug**
Guillaume has reported it earlier, so we added some checks, and the latest #7940 [Link: native build] failed with:
```
020-03-29 20:07:01,611 ERROR [io.qua.ver.htt.run.QuarkusErrorHandler] (vert.x-eventloop-thread-2) HTTP Request to /public-web-app/access failed, error id: 98f49e48-e695-4598-b7c3-db893cc57fa3-1: java.lang.IllegalStateException: staticTenantsConfig is null
	at io.quarkus.oidc.runtime.DefaultTenantConfigResolver.getTenantConfigFromTenantResolver(DefaultTenantConfigResolver.java:81)
	at io.quarkus.oidc.runtime.DefaultTenantConfigResolver.resolve(DefaultTenantConfigResolver.java:61)
	at io.quarkus.oidc.runtime.DefaultTenantConfigResolver_ClientProxy.resolve(DefaultTenantConfigResolver_ClientProxy.zig:208)
	at io.quarkus.oidc.runtime.OidcAuthenticationMechanism.isWebApp(OidcAuthenticationMechanism.java:42)
... [Log Snipped] ...
	at io.quarkus.vertx.http.runtime.VertxHttpRecorder$1.handle(VertxHttpRecorder.java:99)
	at io.quarkus.vertx.http.runtime.VertxHttpRecorder$1.handle(VertxHttpRecorder.java:90)
```

`staticTenantsConfig` is initialized in `oidcRecorder` and then set as a `DefaultTenantConfigResolver` property. 

I think what I can try to do is to pass it to `DefaultTenantConfigResolver` constructor.
