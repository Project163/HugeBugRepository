Title

ADVANCED_OPTIMIZATIONS: object property incorrectly renamed

Description
What steps will reproduce the problem? 

1.) Create a file "test.js" with the following contents:

window.a = {
    'beer': function() {
        print("beer was called");
    }
};
window.a.beer();

2.) Now run the closure compiler with "ADVANCED_OPTIMIZATIONS"
as the compilation level. For example:

java -jar compiler.jar --compilation_level=ADVANCED_OPTIMIZATIONS --js=test.js


 What is the expected output? What do you see instead? 

The expected output should be:

window.a={beer:function(){print("beer was called")}};window.a.beer();

Instead the output is:

window.a={beer:function(){print("beer was called")}};window.a.b();


 What version of the product are you using? On what operating system? 

I'm using the version in subversion. I'm running my test on Ubuntu Linux.
Discussion
- The compiler keeps the quoted names and renames everything else. If you remove the 
quotes around beer, the compiler won't break your code.

window.a = {
    beer: function() {
        print("beer was called");
    }
};
window.a.beer();

For further details see the tutorial at [URL]
- alternately, you can use quotes in both places:

a[Link: 'beer'];
- This is working as intended.
- Issue 52 has been merged into this issue.
