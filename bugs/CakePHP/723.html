Title

Cake\ORM\Query::contain() $override doesn't work as expected

Description
The `$override` flag in `Cake\ORM\Query::contain()` doesn't reset existing associations as expected unless `contain()` is first called with no associations and then repopulated:

```
class MyController extends AppController {
    public function index() {
        $query = $this->MyModel->find();
        $query->contain(['OtherModel1', 'OtherModel2']);

    }
}
```
