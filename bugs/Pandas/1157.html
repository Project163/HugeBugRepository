Title

MultiIndex.get_leves_values() returns inconsistent Index if there are NaNs

Description
#### Code Sample, a copy-pastable example if possible

```python
In [3]: pd.MultiIndex.from_arrays([['a', 'b', 'b'], [2, np.nan, 2]]).get_level_values(1)
Out[3]: Int64Index([2.0, nan, 2.0], dtype='float64')
```
#### Problem description

An ``Int64Index`` should never have ``dtype='float64'``.

Ironically, this is tested extensively in ``test_get_level_values_na`` inside ``pandas/tests/indexes/test_multi.py``, except that then the result is [Link: explicitly casted] (this came out from [Link: this comment] by Joris).

I'm pretty sure the bug comes from [Link: this line], but at the moment I'm not sure what should replace it.

#### Expected Output
```python
Float64Index([2.0, nan, 2.0], dtype='float64')
```
