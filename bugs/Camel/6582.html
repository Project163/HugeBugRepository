Title

camel-spring-boot - XPath language configuring saxon=true seems to not work

Description
I have a Spring Boot project, and I'm trying to set Saxon as the default implementation for the XPath language. 

 Per the  [documentation] ( [URL] you can set the property  { }camel.language.xpath.saxon{ }  to true to enable it. 

 However, the Spring Boot runtime configures the language by doing a reflective copy of the properties from the configuration to the language instance object. It happens that the property names are different:  [XPathLanguage.java] ( [URL] uses "useSaxon" whereas  [XPathLanguageConfiguration.java] ( [URL] uses "saxon". 

 There's an unit test covering this setting, but it is using  ["useSaxon"] ( [URL]
Discussion
- Yes you are welcome to add a getter/setter for saxon (and deprecate useSaxon) on the language class, and adjust that unit test.
