Title

RemoteTransportException should be instance of CancelTaskException

Description
RemoteTransportException  is thrown when a consuming task is notified about failure at the producer side. This should not be reported as the root cause of the job failure. By making it an instance of  CancelTaskException  it will not be reported as a failure, but as a cancellation.
Discussion
- In the long run, I think it makes sense that this exception is reported to the JobManager. 

 We can use this to learn that the source task manager has a problem, and not deploy further tasks to it unless it has pinged back, for example.
