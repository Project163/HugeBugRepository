Title

[YCQL] SELECT count(column) on a column with null value results in session termination

Description
When executing a query to count the number of rows with `count(column)` where column contains null value results in session termination:

```
cqlsh> create table t (a int primary key, b int);
cqlsh> insert into t (a) values (1);
cqlsh:k> select count(*) from t;
 count
-------
     1
cqlsh> select count(b) from t;
NoHostAvailable:
```
Discussion
- Fixed.
```
cqlsh:q> create table t (a int primary key, b int);
     cqlsh:q> insert into t (a) values (1); 
     cqlsh:q> select count(*) from t;
     count
    -------
... [Log Snipped] ...
         0
     (1 rows)
```
- Additional tests for BIGINT & TEXT:

For BIGINT b:
```
create table t1 (a int primary key, b bigint);
cqlsh:q> select * from t1;
 a          | b
------------+------
         12 |  999
... [Log Snipped] ...
          1000
(1 rows)
```


For TEXT b:
```
create table t2 (a int primary key, b text);
cqlsh:q> select * from t2;
 a  | b
----+------
 55 |  aaa
... [Log Snipped] ...
           bbb
(1 rows)
```
The cases look correct.
