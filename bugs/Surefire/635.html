- I found out the problem. Suppose I have maven project that is JPMS module and maven-surefire-plugin 2.22 is used with junit5. If I place this project in 
  
 
 /home/Jim/Foo 
  
 folder, and run `mvn install` then everything is ok.  However, if I place this project in 
  
 
/home/Jim/Foo Boo 
  
 folder (note space between Foo and Boo) and run `mvn install` then I get the above error. So the problem is in path building.
