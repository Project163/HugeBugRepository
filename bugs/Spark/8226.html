Title

ParquetFileFormat registers task completion listeners lazily, causing Python writer thread to segfault when off-heap vectorized reader is enabled

Description
The task completion listener that closes the vectorized reader is registered lazily in ParquetFileFormat#buildReaderWithPartitionValues(). Since task completion listeners are executed in reverse order of registration, it always runs before the Python writer thread can be interrupted. 

 This contradicts the assumption in  [URL] /  [URL] that task completion listeners are registered bottom-up, preventing that fix from working properly.
