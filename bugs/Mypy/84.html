Title

Bogus complaint about overriding and multiple inheritance

Description
Mypy is overzealous when checking method signatures in multiple inheritance. This code is rejected, even though it should be valid:

```
class A:
    def clear(self): pass

class B:
    def clear(self, x=None): pass

class C(B, A): pass
```

Here's the error:

```
t.py: In class "C":
t.py, line 7: Definition of "clear" in base class "B" is incompatible with definition in base class "A"
```
