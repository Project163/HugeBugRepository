Title

C: improper indent of structs within return

Description
An example:
```C
struct point point_zero() {
    return (struct point){
        0,
            0,
    };
}
```

It's just treating the `{` as the start of a statement and the `,` as a comma operator and getting confused. I think `return` needs to be treated like an lvalue.
