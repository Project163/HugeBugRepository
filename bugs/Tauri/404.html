Title

[bug] WebView Fixed Runtime not found in development

Description
### Describe the bug

I need to develop an application for Windows that ships with a fixed version of the WebView2 runtime.
I followed the instructions provided in the [Link: docs]: downloaded the latest version, unzipped it, and updated the tauri.conf.json file accordingly.
The production application (generated with `npm run tauri build`) works flawlessly.
However, **in development (`npm run tauri dev`) the application crashes during bootstrap due to the following error:**
```sh
thread 'main' panicked at 'error while running application: Runtime(CreateWebview(WebView2Error(WindowsError(Error { code:  , message: The system cannot find the file specified. }))))'
```
This is really strange. It looks like, during development, Tauri is unable to find the correct directory (maybe a working directory issue?) where the runtime is located.
If I change the configuration to not use a Fixed runtime, the application starts without any problem.
