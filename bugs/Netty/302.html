Title

"Promise already done" warning when cancelling ChannelFuture returned by bootstrap.connect()

Description
Netty 4.0.17 (and down to at least 4.0.12) logs a warning when attempting to cancel a `ChannelFuture` returned by `Bootstrap#connect`. Here's a simple test app:

```
java
public class CancelConnectionTestApp {

    private static final Logger log = LoggerFactory.getLogger(CancelConnectionTestApp.class);

... [Log Snipped] ...
    }
}
```

The output from the above is:

```
[main] INFO CancelConnectionTestApp - Future reports self as cancellable.
[nioEventLoopGroup-2-1] INFO CancelConnectionTestApp - Channel registered.
[nioEventLoopGroup-2-1] WARN io.netty.util.concurrent.SingleThreadEventExecutor - A task raised an exception.
java.lang.IllegalArgumentException: promise already done: DefaultChannelPromise@2f354a1a(failure(java.util.concurrent.CancellationException)
    at io.netty.channel.DefaultChannelHandlerContext.validatePromise(DefaultChannelHandlerContext.java:806)
... [Log Snipped] ...
    at io.netty.util.concurrent.SingleThreadEventExecutor$2.run(SingleThreadEventExecutor.java:101)
    at java.lang.Thread.run(Thread.java:722)
```

It looks like a possibly-related thing was fixed in #1986, but this issue remains.

Thanks!
