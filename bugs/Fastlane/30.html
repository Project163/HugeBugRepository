Title

[deliver] Invalid screen resolution images can be uploaded as Apple TV and Mac screenshots

Description
### Issue Description
Similar to #14585 but from a slightly different root cause. If an image in the directory happens to be a rotated version of a valid screen resolution (i.e 2880 x 1800 (the portrait equivalent of a Mac screenshot (2880 x 1800)) then it'll be incorrectly classified as that screen size. 

This is because for all images that aren't in the 'appleTV' directory, it attempts to map both landscape and portrait versions however this can lead to invalid cases with Mac, Apple Watch and legacy iOS screenshots that don't have a status bar.

##### Command executed
`bundle exec fastlane deliver`
