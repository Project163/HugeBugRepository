Title

SparseFileTracker sometimes notifies listener under mutex

Description
In #58477 we introduced a more eager notification mechanism for listeners of ranges of sparse files, but unfortunately these changes now mean we sometimes notify listeners (and therefore perform IO) while holding `SparseFileTracker#mutex`.

Spotted while working on something else, and it will be a bit involved to fix, so I'm opening an issue so we don't forget about it.
