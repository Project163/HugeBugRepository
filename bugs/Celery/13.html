Title

"implicit" chords (chain of group + task) not working with nested chains (celery4)

Description
The following code works fine under celery 3. Under celery 4, it works for ALWAYS_EAGER, but not for redis. Not tested for rabbitmq, because then chords are not working at all (see #3330)

In the following code I define:
- `t1` is an "implicit" chord: a chain that consists of a group followed by a task.
- `t2` replaces the tasks within the group with chains of tasks.
- `t3` is the same as `t2` but written using an explicit chord.

on celery 4, t2 fails with the following error: 
`TypeError: apply_async() got multiple values for keyword argument 'chain'`

```
python
from __future__ import absolute_import, division, print_function
from celery import Celery, chord, chain, group
from celery.utils.log import get_task_logger
```
