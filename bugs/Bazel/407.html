Title

combine_derived_java_srcs.sh uses system "jar", not the one from Bazel

Description
The script `src/combine_derived_java_srcs.sh` used by the target `//src:derived_java_srcs` calls jar simply via its name, thus looking it up on the PATH. This will fail on systems that don't have an installed JDK and where Bazel is using the bundled JDK.

Instead, the "jar" tool of Bazel's current JDK should be passed in as a tools dependency to the script and then used.
