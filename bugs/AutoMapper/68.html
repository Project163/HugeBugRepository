Title

Mapping between different ICollection implementations fails

Description
When creating entities from database, Entity Framework will initialize related ICollections as HashSets. For the analogous ICollections in the view models I use Lists instead. When I want to create/edit entities I map a model to the entity as shown in this [Link: gist]. In previous versions the HashSet would be replaced a List and the database operation would proceed without issue, but since 6.2 you get an AutoMapperMappingException.
