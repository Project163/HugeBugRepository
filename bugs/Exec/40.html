- Further investigation has shown, that the following approaches can be treated as stable: 
 
	 Run the target executable with s-bit set 
	 Run the java program with root user (don’t use sudo) 
 

 In both approaches the executable can be terminated in a stable way. Using sudo execution doesn’t always produce expected results (depending on the executable the processes keep running).
