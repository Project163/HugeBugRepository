Title

Removing sourcemapping comment also removes newline character

Description
I've found a node package called `node-source-map-support` that inconveniently uses a `////# sourceMapURL=foo.js.map` [Link: in their file]. On its own, this is not an issue, but when using rollup it produces an invalid file because the next line is being commented out.

**main.js**
```javascript
////# sourceMappingURL=foo
var val = 42;
console.log(val);
```

**output**
```javascript
'use strict';

//var val = 42;
console.log(val);
```

[Link: Take a look.]

Interestingly enough, when using CRLF as newline character, it doesn't remove the newline. Whereas only using LF as newline character, it does get removed. I assume that there's a regex being too greedy?
