Title

Credentials leak in HTTP metric tags

Description
If you run the following script with `k6 run -o json`:
```js
import http from "k6/http";

export default function () {
    http.get("[URL]
    http.get("[URL] { auth: "digest" });
}
```

you'd currently get metrics like these:
```json
{"type":"Point","data":{"time":"2019-08-06T10:52:01.259896979+03:00","value":164.589459,"tags":{"group":"","method":"GET","name":"[URL]
{"type":"Point","data":{"time":"2019-08-06T10:52:01.568763642+03:00","value":153.52556,"tags":{"group":"","method":"GET","name":"[URL]
```

The `name` and `url` tags for these metrics leak the credentials, which is not what most users would want. And if they want to distinguish between the metrics based on the credentials, they can always manually set the `name` tag or any other custom one.
