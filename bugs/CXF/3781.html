Title

TransportURIResolver prints stack trace to stderr when using HTTP Authentication

Description
The following issue happens when a WSDL document URL requires HTTP Basic authentication to load. 

 I create a default authenticator with the appropriate credentials: 

   
  
 
Authenticator.setDefault( new  Authenticator() {
    @Override
     protected  PasswordAuthentication getPasswordAuthentication() {
         return   new  PasswordAuthentication(userName, password);
    }
}); 
  
 Now, I create a jakarta.xml.ws.Service: 

   
  
 
service = Service.create(endpointUrl, serviceName);  
  
 Where endpointUrl is the URL of the WSDL which requires authentication to load. 

   

 This works perfectly, but unfortunately, the following stacktrace is written to stderr (not even using a logger, but directly), which is misleading to the user:
