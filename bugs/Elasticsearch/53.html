Title

Possible (rare) shard index corruption / different doc count on recovery (gateway / shard)

Description
The problem stems from the reusing of existing index files when doing recovery. Checksums should be added, but, in order to have it performant, they are computed on write.

This menas that existing indices will still work, but might suffer from it. New internal index files will get checksummed, and eventually the index will be fully checksummed, though, it is recommended to reindex the data.
