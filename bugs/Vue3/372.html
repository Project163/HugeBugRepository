You use `?` it's why you get `| undefined`.

---

Another example without any Vue.js code:

```ts
type TypeA = {
  prop1?: boolean
};
const b = {} as TypeA;
const prop1: boolean | undefined = b.prop1; // OK
```

Without `?`:
```ts
type TypeB = {
  prop2: boolean
};
const a = {} as TypeB;
const prop2: boolean = a.prop2; // OK
```
