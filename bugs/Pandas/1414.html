Discussion
- The mean method hasn't been properly implemented yet for nullable ints, but there is this issue [URL] and this PR [URL] open addressing that.

cc @jorisvandenbossche
- The problem isn't with IntegerArray.mean, its with `df.T` being all-object dtype.
- Works on main.  Could use a test (first check to see if one already exists)
- Hello! I tested DataFrame.mean(axis=1) with nullable integer dtype and confirmed the bug.
I created a small example for reproduction and a workaround using apply(lambda row: row.mean(skipna=True), axis=1):

import pandas as pd
df = pd.DataFrame({
    "a": [1, 2, 3, 4],
    "b": pd.Series([1, 2, 4, None], dtype=pd.Int64Dtype())
})
df['row_mean'] = df.apply(lambda row: row.mean(skipna=True), axis=1)
print(df)
