### Description

Infinite recursion in RCTProfileTrampoline

In [Link: Detox Instruments], we have added the ability to record RN profiling events. We do this by providing callbacks using `RCTProfileRegisterCallbacks` and then enabling the profiling on a bridge using `RCTProfileInit`.

To avoid user setup, we swizzle `-[RCTBridge setUp]` to listen to bridge creation and we call `RCTProfileInit` to enable profiling for that bridge.

We are now trying to integrate these Detox Instruments capabilities in Detox, so that we can capture these events when testing.

Our code works until either the user presses CMD+R to reload the bridge. Upon reload, the following can be seen:

- I found the issue. There is an incorrect unhooking here:

[URL]

Instead, it should be

```objc
RCTProfileUnhookInstance([bridge.uiManager viewForReactTag:view]);
```
