- The page has a 90° rotation. For me, it works by changing one line in PDFStreamEngine.java: 
  
 Matrix aa = Matrix.concatenate(matrix, a);
 
  
 to 
  
 Matrix aa = Matrix.concatenate(a, matrix);
 
  
 This change has been sitting around locally for months, so long that I can't even remember why I had it in the first place. I need to test whether it produces any regressions.
