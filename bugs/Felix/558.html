Title

Security errors accessing configurations in the file system

Description
When the FilePersistenceManager is trying to access the configuration files it currently does this in the security context of the calling bundle. If the calling bundle does not have file access permissions, this access fails (unexpectedly). 

 The fix is to ensure running in doPrivileged using the configuration admin bundle's security context to access the files.
