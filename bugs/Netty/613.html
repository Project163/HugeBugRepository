Title

Channel.Unsafe.closeForcibly() fails for EpollSocketChannel if not registered to event loop

Description
### Expected behavior

`Channel.Unsafe.closeForcibly()` should close the connection immediately even if the channel is not registered to an event loop.

### Actual behavior

The connection is closed, but an exception is accompanied.
```
05:53:55.405 [armeria-server-boss-epoll-26-1] WARN  io.netty.channel.AbstractChannel - Failed to close a channel.
java.lang.IllegalStateException: channel not registered to an event loop
	at io.netty.channel.AbstractChannel.eventLoop(AbstractChannel.java:158)
	at io.netty.channel.epoll.AbstractEpollChannel.doDeregister(AbstractEpollChannel.java:140)
	at io.netty.channel.epoll.AbstractEpollChannel.doClose(AbstractEpollChannel.java:117)
	at io.netty.channel.epoll.AbstractEpollStreamChannel.doClose(AbstractEpollStreamChannel.java:721)
	at io.netty.channel.AbstractChannel$AbstractUnsafe.closeForcibly(AbstractChannel.java:703)
```

### Steps to reproduce

Accept an incoming connection from an epoll server socket and close the accepted connection using `Channel.Unsafe.closeForcibly()` before it's registered to an event loop.

### Minimal yet complete reproducer code (or URL to code)

```
java
ServerBootstrap sb = new ServerBootstrap();
...
sb.handler(new ChannelInboundHandlerAdapter() {
    @Override
... [Log Snipped] ...
    }
});
```

4.1.11
