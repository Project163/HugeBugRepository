Title

The validation error disappears when schema is nested.

Description
# Problem
Sorry if this is not an issue in this repository.

sandbox
[URL]

I use yup's schema validation.
The schema is nested as follows.

```js
const schema = yup.object().shape({
  user: yup.object().shape({
    firstName: yup.string().required(),
    lastName: yup.string().required(),
    age: yup.string().required()
  })
```

I want the initial render to be in an error state, so I run trigger in useEffect.
And The mode of validation is onBlur.


```js
  // initial validate
  React.useEffect(() => {
    trigger();
  }, [trigger]);
```

The initial render shows the error as expected, but when I finish entering the first item, the error disappears even though there are items that have not been entered.

[Image: screencast 2020-11-16 21-40-23]


Without nesting the schema, it behaved as expected.
