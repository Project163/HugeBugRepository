Discussion
- In this type1 font the "binary" part is hex encoded, in other type1 fonts I've seen it is pure binary. 

 From the specification: 
  
 Although the encrypted portion of a standard Type 1 font may be in binary or ASCII hexadecimal format, PDF supports only the binary format.
 
  
 So the font is incorrectly stored. But obviously, Adobe supports both, so we should too.
