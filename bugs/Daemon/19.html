Title

Log on tab of Prunmgr ignores current settings

Description
This was  [URL]

 If a valid user and password is specified in the "log on" tab of Prunmgr  then if Prunmgr is closed and re-opened, the log on tab shows the log on as local system account even though the service is configured to start as a specified user. This also makes it impossible to restore the service to use a local system account through the log in tab. 

 The workaround is to use the standard windows service gui.
