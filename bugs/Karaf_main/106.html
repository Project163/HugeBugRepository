Title

Setting the karaf.restart.jvm property to true causes system halt commands to behave as reboots

Description
Currently when the system property karaf.restart.jvm is set to true halt/shutdown operations result in a jvm reboot/restart. The karaf.restart.jvm property should only apply during a reboot and not a system halt. 
There is also an issue in the karaf.bat script when using this option in windows.
