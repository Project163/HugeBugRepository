Title

Manual Channel.read() may not work with OioSocketChannel/OioServerSocketChannel

Description
The problem is when `Channel.isAutoRead()` is false and a user triggers `Channel.read()` but we are not able to read something before the SO_TIMEOUT kicks we never try to read() again and the user will not know it. We need to keep on reading in this cases to also be inline with the behavior of other transports
