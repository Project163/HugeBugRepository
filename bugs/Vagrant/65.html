Title

vagrant login fails behind a proxy

Description
On windows and mac, if you are behind a proxy and have set the env var `http_proxy` and/or `https_proxy`, then `vagrant login` will fail with 

```
Vagrant-proxyconf plugin found...
Setting 'http_proxy'...
Setting 'https_proxy'...
Setting 'no_proxy'...
DEBUG loader: Loading from: root (evaluating)
... [Log Snipped] ...
    from /opt/vagrant/embedded/gems/gems/vagrant-1.7.4/lib/vagrant/environment.rb:301:in `cli'
    from /opt/vagrant/embedded/gems/gems/vagrant-1.7.4/bin/vagrant:174:in ` '
```

An oddness I see is that in the /opt/vagrant/embedded/gems/gems/ there exist more than one version of rest_client.

on mac I have rest-client-1.6.9 and rest-client-1.8.0

on windows I have rest-client-1.6.9 and rest-client-1.8.0-x86-mingw32

We appear to be using the 1.6.9 version.  That version doesn't work when passing the proxy settings in the RestClient::Request.execute(),  (see [URL]
