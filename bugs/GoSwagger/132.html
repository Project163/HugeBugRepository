Title

Generated validation method miss some fields

Description
## Problem statement

Using go-swagger to generate models. However, it miss some fields in `Validate` method. Is this a feature or bug?

Type `ContainerCreateConfig` includes `HostConfig` and `NetworkingConfig`.
```
YAML
 ContainerCreateConfig:
| 
      ...
    allOf:
... [Log Snipped] ...
          NetworkingConfig:
            $ref: "#/definitions/NetworkingConfig"
```
Generated code
```
Go
type ContainerCreateConfig struct {
	ContainerConfig

	// host config
... [Log Snipped] ...
	NetworkingConfig *NetworkingConfig `json:"NetworkingConfig,omitempty"`
}
```
```
Go
// Validate validates this container create config
func (m *ContainerCreateConfig) Validate(formats strfmt.Registry) error {
	var res []error

... [Log Snipped] ...
	return nil
}
```
In my expectation, there should be some code like 
```Go
	if err := m.validateHostConfig(formats); err != nil {
		res = append(res, err)
	}
```
in func `Validate` to validate the `HostConfig` field.
