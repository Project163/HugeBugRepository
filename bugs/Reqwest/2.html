Title

Mulitpart file uploads get stuck after upgrading to 0.9.0

Description
I've received a [Link: pull request] to [Link: pyo3-pack] which upgrades reqwest to 0.9.0. Unfortunately this seems to break uploading.

The 0.8 case works and returns the expected 403:

```
git clone [URL]
cargo run -- publish -u konstin -b bin -r [URL] -m hello-world/Cargo.toml -p notmypassword
```

If we now add the 0.9 upgrade, we are stuck with no network activity

```
git remote add ijl [URL]
git fetch --all
git checkout ijl/up-reqwest
cargo run -- publish -u konstin -b bin -r [URL] -m hello-world/Cargo.toml -p notmypassword
```

Trying to minimize this brought me to the following code. 

```
rust
extern crate reqwest;

use reqwest::{multipart::Form, Client};

... [Log Snipped] ...
        .unwrap();
}
```
