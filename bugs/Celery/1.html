Title

Unable to create chord: "TypeError: group object got multiple values for keyword argument 'task_id'"

Description
On celery master (2fddb876e1), when attempting to run a chord :

```
python
from celery import Celery, group

app = Celery()

... [Log Snipped] ...
c = (group([add.si(1,1), add.si(2,2)]) | xsum.s())
c.delay()
```

The method _apply_chord_incr generates an exception `TypeError: group object got multiple values for keyword argument 'task_id'` on the call to header:

```
def _apply_chord_incr(self, header, partial_args, group_id, body,
                      result=None, options={}, **kwargs):
    self.save_group(group_id, self.app.GroupResult(group_id, result))
    return header(*partial_args, task_id=group_id, **options or {})
```

The options dict already has a value for task_id (a different value from group_id).

I tried removing the task_id key from options:

```
def _apply_chord_incr(self, header, partial_args, group_id, body,
                      result=None, options={}, **kwargs):
    self.save_group(group_id, self.app.GroupResult(group_id, result))
    if options.get('task_id'):
        del options['task_id']
    return header(*partial_args, task_id=group_id, **options or {})
```

Which fixes the immediate error, but when I attempt to .get() the result, the program hangs.

I also tried removing the task_id=group_id keyword argument, but still get a hang.
Discussion
- I traced the hang to a line in `on_chord_part_return`:

``` python
gid = task.request.group
```

results in `gid = None`.  Changing the line to 

``` python
gid = task.request.taskset
```

fixes the problem, but several tests now fail.
