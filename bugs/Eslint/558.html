Title

`no-unused-expressions` behavior does not match docs for `allowShortCircuit: true`

Description
According to the docs, this should not cause warnings:

``` js
/*eslint no-unused-expressions: [2, { allowShortCircuit: true }]*/

a && b()
```

But, it gives:

```
3:1  error  Expected an assignment or function call and instead saw an expression  no-unused-expression
```

The second example given, (`a() || (b = c)`) behaves correctly.
