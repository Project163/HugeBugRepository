Title

deployAtEnd does not deploy artifacts for multi-module project with build extensions

Description
The deploy plugin shows the same behaviour as described in   MINSTALL-102  .  

 We noticed that multimodule projects do not deploy any artifacts if there are modules with packagings that add build extensions (e.g. atlassian-plugin, aar = axis archives). 

 This issue is here for better visibility as discussed in   MINSTALL-102  .  
Please find attached testcase there.
Discussion
- Attached a project, which generate the issue, 
run mvn deploy -Pjar,war,osgi 

 The build is SUCCESSFULL but nothing has been deployed (the worst case).
- deployAtEnd  is an experimental feature (I added that comment too late). It works for most projects, but not all. Hence it is not active by default. Once   MNG-5666   is implemented no-one needs this option anymore.  
I'm pretty sure this can't be resolved within the maven-deploy-plugin itself, it's already stretched to its limits.
