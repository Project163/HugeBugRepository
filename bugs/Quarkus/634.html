Quarkus:dev does not filter resources



add filter a maven
```
         
           
             src/main/resources 
             true 
           
         
```
add a maven property in application.yaml or application.properties
```
my.version=$ {project.version}
```
run mvn clean package quarkus: dev
resources are filtered and the application starts with the property
my.version = 1.0.0-SNAPSHOT

resources are not filtered and the application starts with the property
my.version = $ {project.version}
