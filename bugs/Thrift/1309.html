Title

Thrift generator doesn't exclude 'package' keyword for thrift property names breaking java builds

Description
Thrift allows the word "package" for it's property names which when generating java will not compile.
Discussion
- In what other language is  package  a keyword?  
Are there any, or is this really only a Java specific thing?
