Title

Support PostgreSQL `bpchar` type and array of char type

Description
Attempting to read the following table: 
  
 
CREATE TABLE test_table (
  test_column  char (64)[]
)
 
  
 results in the following exception: 
  
 
java.sql.SQLException: Unsupported type ARRAY
