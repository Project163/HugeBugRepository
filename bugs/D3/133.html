Discussion
- Without a test case (a self-contained example on bl.ocks.org or jsfiddle.net, etc.) to verify this bug, I can’t investigate further. My guess is that one of the arc properties you’re specifying is NaN, so that NaN is being propagated into the resulting path string. I would use a debugger to step through your code and see what values you are passing to the arc generator, and then work backwards from there to see why the property is NaN.

I did notice one bug in your code:

``` js
var range = +y.range();
var yr = d3.interpolate(range, [dy ? selectionRadius : innerBtnRadius, radius-5]);
```

Here you’ve defined `range` by coercing a scale’s range (which is typically an array of numbers) to a number. That probably means that `range`’s value is NaN. Then you’re using d3.interpolate to interpolate from NaN to an array of two numbers. That probably means that the interpolator is always returning the latter array, regardless of the value of _t_.
