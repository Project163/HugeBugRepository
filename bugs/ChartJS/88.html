- Hi @n1c!
You can just enable `usePointStyle` in the legend label options to get a circular shape, like this:
[URL]

```js
const legend = {
  labels: {
    usePointStyle: true
  },
}
```

[Image: Image]

Anyway, I also think it's a good idea to respect the `borderRadius` option.
