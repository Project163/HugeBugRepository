 The test creates and destroys caches with different configurations. 
Sometimes the test fails with NPE. The reason is in the test: 
1. jetty sends create cache query 
2. Checkpoints on nodes take some more time than session timeout. (I found two incident in TC, with checkpoint time 32-35 seconds. Default session timeout is 30 sec) 
3. The test fails with NPE while checking that cache will be created. 

 I suggest to add the additional check after the jetty query(See my PR). This will clarify the cause of the fall.  

 Can we increase session timeout to avoid test failing? Or how correctly handle this error?
