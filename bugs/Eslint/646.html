Title

indent bug with multi-line arrays

Description
Code:

```
js
/* eslint indent: [2, 2, {"SwitchCase": 1}] */
[
  'b',
  'a',
... [Log Snipped] ...
  'b',
]);
```

ESLint Output:

``` cpp
2:1  error  Expected indentation of 2 space characters but found 0  indent
3:3  error  Expected indentation of 4 space characters but found 2  indent
4:3  error  Expected indentation of 4 space characters but found 2  indent
5:1  error  Expected indentation of 2 space characters but found 0  indent
```

Then, if I actually indent lines 2-5 by 2 spaces, ESLint says this:

``` cpp
2:3  error  Expected indentation of 4 space characters but found 2  indent
3:5  error  Expected indentation of 6 space characters but found 4  indent
4:5  error  Expected indentation of 6 space characters but found 4  indent
5:3  error  Expected indentation of 4 space characters but found 2  indent
6:3  error  Expected indentation of 4 space characters but found 2  indent
7:3  error  Expected indentation of 4 space characters but found 2  indent
8:1  error  Expected indentation of 2 space characters but found 0  indent
```

The indentation of that code should not cause an error.

Originally found when using ESLint here: [URL]

Using ESLint version 1.7.1
