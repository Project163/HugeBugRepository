Title

Errors and warnings on Linux with GCC and Clang after updating to latest master

Description
Continuing from [URL] The issue there was fixed, but I was using an older version of GLM when I reported that. After updating to the latest master (61e84326), I'm getting new errors and warnings.

I'm using Ubuntu 15.10 and compiling with both GCC 5.2.1 and with Clang 3.6.2. I usually compile with all possible warnings turned on, but I'm gradually turning on warnings with the below logs.
### tvec4  operator-(tvec1  const & v1, tvec4  const & v2)

Error with both GCC and Clang:

```
cpp
# GCC:
In file included from ../thirdparty/glm/detail/type_vec4.hpp:460:0,
                 from ../thirdparty/glm/vec4.hpp:6,
                 from ../thirdparty/glm/glm.hpp:70,
... [Log Snipped] ...
                return tvec4 (v1) -= v2;
                       ^~~~~~~~~~~~~~
```

The above error can be fixed by this change:

``` cpp
template  
    GLM_FUNC_QUALIFIER tvec4  operator-(tvec1  const & v1, tvec4  const & v2)
    {
-       return tvec4 (v1) -= v2;
+       return tvec4 (v1.x) -= v2;
    }
```

But I'm not sure if there should rather be vec4 constructor which accepts a single vec1, or some kind of conversion from a vec1 to a vec4 (or to a scalar).

The above warning doesn't happen if I remove `GLM_CONSTEXPR_CTOR` from the declaration and the definition, which is a bit weird.
