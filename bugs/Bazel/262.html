Title

bind and alias does not support testonly

Description
`testonly` has been fixed in the latest release but if a testonly attribute is set in the target of a `bind`/`alias` rule we fails miserably and there is no way to set the testonly attribute in the rule.

From floonet:
```
ERROR:  /WORKSPACE:65:1: in bind rule //external:gmock: non-test target '//external:gmock' depends on testonly target '@gtest_git//:gmock' and doesn't have testonly attribute set.
```

This test used to pass and there are no changes in the workspace, so I presume the error has to do with a change in Bazel. I tested changing 
```
bind(
    name = "gmock",
    actual = "@gtest_git//:gmock",
)
```
in WORKSPACE file to
```
bind(
    name = "gmock",
    testonly = 1,
    actual = "@gtest_git//:gmock",
)
```
but that gave me
```
ERROR:  /WORKSPACE:65:1: unexpected keyword 'testonly' in call to bind(*, name, actual = ?).
ERROR: Error evaluating WORKSPACE file.
ERROR: com.google.devtools.build.lib.packages.BuildFileContainsErrorsException: error loading package '': Encountered error while reading extension file 'tools/osx/xcode_configure.bzl': no such package '@bazel_tools//tools/osx': error loading package 'external': Could not load //external package.
```
