the error message describes the problem, which is that it's looking for a column expression, not text(), the latter of which describes a SQL statement.   For textual column expressions, use `literal_column()`, this is mentioned in the docs for case:

```
py
from sqlalchemy import case
from sqlalchemy import func
from sqlalchemy import literal_column
```
