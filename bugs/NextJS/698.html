- @Rnbsov The issue here is actually because there is invalid css.

```
input.defaultCheckbox::before path {
	fill: currentColor;
}

```

There cannot be a selector after the `::before`. If you remove it, it'll work. There is an issue with non-Turbopack Webpack css parser allowing this, so we'll be improving the error for this and with Turbopack (a better error to show that there's invalid css).
