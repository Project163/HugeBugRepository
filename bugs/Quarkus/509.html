Title

Error running @ParameterizedTest in Quarkus 1.3.0.Final

Description
**Describe the bug**
Simple method in a `@QuarkusTest` which is also a `@ParameterizedTest` doesn't work.

To reproduce:

```
@QuarkusTest
public class ExampleResourceTest {

    public enum MyEnum {
        VALUE1,
... [Log Snipped] ...

}
```


if you try to run it you got:

`java.lang.RuntimeException: Could not find method public void net.lucamasini.testcase.ExampleResourceTest.testHelloEndpoint(net.lucamasini.testcase.ExampleResourceTest$MyEnum) on test class`

one for every enum value.

**Expected behavior**
The runtime container should find the enumerated method

**Actual behavior**
Cannot find the public method
