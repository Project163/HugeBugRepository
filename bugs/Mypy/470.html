Title

Allow type aliases be used as variables

Description
It would sometimes be useful to be able to use at least simple type aliases as variables. For example, this code should probably be accepted:

```
import typing
try:
    x = WindowsError
except NameError:
    x = None
```

This affects lib-python/3.2/shutil.py.
Discussion
- This requires an annotation in strict optional mode, which is now on by default, and the annotation removes the error:

```py
from typing import Optional, Type
try:
    x: Optional[Type[Exception]] = WindowsError
except NameError:
    x = None  # This fine
```

Marking as low priority since this only has an effect when using `--no-strict-optional`.
- @JukkaL, do you think this is still worth pursuing, or can this now be closed?
