Title

Provide option to skip Accumulo related Hive tests in itests directory

Description
We shouldn’t be running Accumulo+Hive tests in Windows as Accumulo is currently unsupported on Windows. Hence we should provide an option to disable these tests; that being mentioned, the default behavior would be to enable these tests.
Discussion
- sushanth  Can you please review the patch, I tested this locally. To disable Accumulo related Hive Tests, from itests directory, you need to specify  
mvn clean install -DskipAccumuloTests -Phadoop-2 -DskipTests 

 The default behavior is to enable the accumulo tests, so there should not be any diffs.
