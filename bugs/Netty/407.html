Title

Privacy violation in io.netty.handler.codec.socks.SocksAuthRequest

Description
There are two places in the SocksAuthRequest constructor where an IllegalArgumentException is thrown with a password as part of the exception message.
This constitutes mishandling of confidential information, which can compromise user privacy and is flagged as critical by security scanners.
