Title

Mismatched soname for libgrpc++

Description
A symlink to libgrpc++.so.1.2.0 is [Link: created in the Makefile] with the name libgrpc++.so.1. However, the soname of this library is set to libgrpc++.so.3 on the line above. This causes programs linked with libgrpc++ to fail with the error
`./tests: error while loading shared libraries: libgrpc++.so.3: cannot open shared object file: No such file or directory`

Creating the symlink manually fixes the problem (but I haven't checked if grpc actually works). I'm using OpenSUSE Leap 42.2, with source from the 'v1.2.0' git tag.

Note: I know very little about sonames, so this could be completely wrong. :-)
