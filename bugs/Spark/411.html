Title

Master throws NPE

Description
... if we launch a driver and there are more waiting drivers to be launched. This is because we remove from a list while iterating through this. 

 Here is the culprit from Master.scala (L487 as of the creation of this JIRA, commit  ). 

  
  for  (driver <- waitingDrivers) {
   if  (worker.memoryFree >= driver.desc.mem && worker.coresFree >= driver.desc.cores) {
    launchDriver(worker, driver)
    waitingDrivers -= driver
  }
}
Discussion
- In general, if Master dies because of an exception, it automatically restarts and the exception message is hidden in the logs. In the mean time, the symptoms are not indicative of a Master having thrown an exception and restarted. It took a while for  ilikerps  and I to find the exception as we were scrolling through the logs.
- This is the root cause of   SPARK-2154
