Title

Race between replacements with the same path

Description
If I replace some file with a directory of the same name, there is a race where the directory creation will happen before file deletion and vica versa. I assume it should correct itself, but doesn't always seem to do that for some reason.

Somehow feel there is an existing issue for this.
