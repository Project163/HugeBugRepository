- @huozhi  that doesn’t close this issue out. I get that now between local development and production the URLs are the same, that’s create.

My issue is that Next now adds a hash to the URL as @samcx  pointed out. That’s a BREAKING CHANGE compared to the behavior that was there in Next 14. Going from `/resources/sitemap/0.xml` in production with Next 15 to now having `/resources/sitemap-1jkbc8/0.xml` is breaking. Furthermore, not knowing what causes the hash to change is concerning. Users now have to go into wherever they have their sitemaps and update it. If that hash changes whenever a new item is added, that’s going to cause A LOT is headaches for users.
