Title

[yb-admin] create_snapshot fatal for YCQL system tables

Description
`yb-admin create_snapshot` doesn't seem to work for YCQL system tables and YSQL tables.

YCQL system tables:

```
./bin/yb-ctl create
./build/latest/bin/yb-admin --master_addresses   create_snapshot system peers
```

master logs show

```
F0825 15:01:34.036633   967 flush_manager.cc:68] Check failed: ts_tablet_map.size() > 0 (0 vs. 0)
```

YSQL tables:

```
./bin/yb-ctl create
./bin/ysqlsh -c "CREATE TABLE t (i int)"
./build/latest/bin/yb-admin --master_addresses   create_snapshot ysql.yugabyte t
```

stderr shows

```
Error: Invalid argument (yb/master/catalog_manager.cc:7990): Unable to create snapshot of tables: [yugabyte.t]: Getting indexes for YSQL table is not supported:   (master error 20)
```

I believe YSQL table snapshots aren't supported yet, so the error message for that is probably good left as is.  However, the fatal for YCQL system tables is probably not what we want.
