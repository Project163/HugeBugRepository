Title

[DocDB] Don't clear pending config on CONFIG_CHANGE_OP abort if it was set by a different CONFIG_CHANGE_OP

Description
Jira Link: [Link: DB-2770]
### Description

1. Before KUDU-1330 port (https://github.com/yugabyte/yugabyte-db/commit/ ) we had a sanity check for pending config to be set inside`ReplicaState::SetCommittedConfigUnlocked`:
```

  TRACE_EVENT0("consensus", "ReplicaState::SetCommittedConfigUnlocked");
``` 
