Title

ADJUSTED R SQUARED INCORRECT IN REGRESSION RESULTS

Description
I forgot to cast to double when dividing two integers: 

             this.globalFitInfo [ADJRSQ_IDX]  = 1.0 -  
                    (1.0 - this.globalFitInfo [RSQ_IDX] ) * 
                    (  nobs / ( (nobs - rank))); 
Should be 
            this.globalFitInfo [ADJRSQ_IDX]  = 1.0 -  
                    (1.0 - this.globalFitInfo [RSQ_IDX] ) * 
                    ( (double) nobs / ( (double) (nobs - rank)));
