Title

RuntimeError: false INTERNAL ASSERT FAILED at "../aten/src/ATen/native/BatchLinearAlgebra.cpp":498

Description
### 🐛 Describe the bug

I encountered a bug in PyTorch when I created two random tensors of shape `[3, 3, 5, 5]` with data type `float64`, converted it to sparse CSC format, and used `torch.triangular_solve` to solve a linear system involving triangular matrices.

```python
import torch
tensor1 = torch.rand([3, 3, 5, 5], dtype=torch.float64).to_sparse_csc()
tensor2 = torch.rand([3, 3, 5, 5], dtype=torch.float64).to_sparse_csc()
res = torch.triangular_solve(tensor1, tensor2, upper=False)
```

The error message was as follows:

```shell
Traceback (most recent call last):
  File "/data/torch.triangular_solve-0_csc.py", line 13, in  
    res = torch.triangular_solve(tensor1, tensor2, upper=False)
RuntimeError: false INTERNAL ASSERT FAILED at "../aten/src/ATen/native/BatchLinearAlgebra.cpp":498, please report a bug to PyTorch. triangular_solve: Got an unexpected layout.
```

I have confirmed that above code would crash on `2.5.0.dev20240720+cu121` (nightly-build). Also, I provided that a [Link: colab notebook] to reproduce the error.
