Title

camel-jbang: kamelet catalog should be a runtime dependency

Description
We need to list ` org.apache.camel.kamelets:camel-kamelets `  as a runtime dependency for Camel JBang, otherwise it fails to download the catalogs if the dependency cache is empty.
Discussion
- I don't think we should add this to the pom file, to avoid a cyclic dependency. Instead, this should be listed in the run script (maybe).
- Fixed on the wrapper script.
