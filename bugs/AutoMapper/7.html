Title

.targets file causes AutoMapper to be included by Web Publishing

Description
**Problem:**
The standard Web Publishing target from Microsoft will publish any items of type `Content`. For whatever reason AutoMapper chose `Content` as the item type for its platform extension assembly which causes the Web Publishing target to publish a `\packages\Automapper \ .dll` file.

**Proposed fix:**
Change the item type for the platform assembly from `Content` to `None`. This should have no impact on the platform assembly actually being copied to the output directory since this behavior is governed by the `CopyToOutputDirectory` metadata, not the item type, and the Web Publishing target will ignore it because it's no longer `Content`.
