Hello. My question is about [URL]
I can't use condition "In" at Entity.find method.

```
    Group.find{ name: In(["test"]) }

Argument of type '{ name: FindOperator ; }' is not assignable to parameter of type 'DeepPartial '.
  Types of property 'name' are incompatible.
    Type 'FindOperator ' is not assignable to type 'string'
```
but

```
getRepository(Group).find{ name: In(["test"]) }
still works
```

I compared Repository.find and BaseEntity.find methods interfaces and seen
1.    find(conditions?: FindConditions ): Promise ;
2.   static find (this: ObjectType , conditions?: DeepPartial ): Promise ;

What the reason this differences?
