Title

Server data missing when building URI instance and base info (marshalUriAndBaseFromSapi)

Description
### Description

We are in transition to upgrade our codebase to CakePHP v5 and after upgrading we are getting below error:

```
TypeError: str_contains(): Argument #1 ($haystack) must be of type string, null given
/var/www/passbolt/vendor/cakephp/cakephp/src/Http/UriFactory.php:170
/var/www/passbolt/vendor/cakephp/cakephp/src/Http/UriFactory.php:62
/var/www/passbolt/vendor/cakephp/cakephp/src/Http/ServerRequest.php:281
/var/www/passbolt/vendor/cakephp/cakephp/src/Http/ServerRequest.php:249
... [Log Snipped] ...
/var/www/passbolt/vendor/cakephp/cakephp/src/Console/TestSuite/ConsoleIntegrationTestTrait.php:98
/var/www/passbolt/plugins/PassboltCe/EmailDigest/tests/TestCase/Command/SenderCommandTest.php:84
```

Upon investigation I stumble upon the [Link: Move Uri and base marshalling from ServerRequestFactory to UriFactory] PR. After carefully looking at the changes it seems before the method was merging the `$_SERVER` with the actual `$server` and then normalizing it.
```php
$server += $_SERVER;
$server = normalizeServer($server);
```
But this is not done in the refactored code (`UriFactory::marshalUriAndBaseFromSapi()`). When I put these two lines inside the method the tests starts passing and it seems to be working fine. So what I'm not sure is if this is intentional or if this is missed and needs to be added. There's nothing documented in the migration guide too related to this change if intentional.

5.0.11
