Title

Chart not sizing properly when contained in element with padding

Description
If a chart is generated with the responsive: true setting applied, and the canvas is contained within an element that has padding, it doesn't take the padding into account when determining the width of the chart. 

getMaximumWidth uses container.clientWidth, but should also check for padding and subtract.

As a temporary workaround, I have been putting all of my canvas elements in a container div with no padding.
