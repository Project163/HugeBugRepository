Title

While using bake: Irregular Inflector is not working in Controller relationships

Description
I'm using CakePHP 2.4.6

I have set the following rules in bootstrap.php:

```
php
Inflector::rules('singular', array(
    'irregular' => array(
        'unidades_administrativas' => 'unidade_administrativa',
        'regionais' => 'regional')
... [Log Snipped] ...
        'regional' => 'regionais')
));
```

When I run "$ cake bake all" related to a model that has a relationship with the "unidade_administrativa" class this happens:
ParticipantesController.php

``` php
public function add() {
[...]
        $cargos = $this->Participante->Cargo->find('list');
        $turmas = $this->Participante->Turma->find('list');
        $unidadeAdministrativas = $this->Participante->UnidadeAdministrativa->find('list');
        $this->set(compact('cargos', 'turmas', 'unidadeAdministrativas'));
[...]
```

View\Participantes\add.ctp

``` php
[...]
echo $this->Form->input('unidade_administrativa_id');
[...]
```

The code sets unidadeAdministrativas variable so that the view can load the list information into a select box.

But it should be unidadesAdministrativas (both words in plural).

If i change unidadeAdministrativas to unidadesAdministrativas the combo in view is loaded and everything runs fine.
Discussion
- You might need to provide CamelCase variants of those custom inflections.
