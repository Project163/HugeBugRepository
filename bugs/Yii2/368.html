Title

Bug in ArrayDataProvider, last element is sliced when pageSize=0

Description
Hello. So we have Pagination class with property $_pageSize and it says:
_If it is less than 1, it means the page size is infinite, and thus a single page contains all items._
Ok, then we do:

``` php
$dataProvider = new ArrayDataProvider();
$dataProvider->allModels = [....]
$dataProvider->pagination->pageSize = 0;
```

when the GridView access the data provider:

```
php
protected function prepareModels()
{
...
if (($pagination = $this->getPagination()) !== false) {
... [Log Snipped] ...
}
...
```

so the question is - why do we need to slice the array of models when the page is infinite? What's going on here in array_slice we have $pagination->getLimit():

``` php
return $pageSize < 1 ? -1 : $pageSize;
```

$pageSize is equals to 0, but it slices the last element, why?
