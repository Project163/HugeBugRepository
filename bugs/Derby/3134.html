Title

Deprecate support for building Derby under JDKs 6 and 7

Description
The community voted to stop supporting Java 6 and 7 as of release 10.13. See the 2015-09-12 entry here:  [URL] We no longer need to support building Derby with those JDKs. This issue tracks changes needed to remove that support and simplify the build.
Discussion
- Attaching derby-6857-01-aa-remove6and7.diff. This patch removes support for Java 6 and 7. This patch causes the Derby build to fail when run with any JDK other than JDK 8. This patch causes Derby to compile all sources into the byte code level of JDK 8. 

 After applying this patch, I have successfully built and tested a sane Derby with JDK 8. I have verified that trying to build with JDK 6 or 7 fails. I will now try building and testing an insane Derby with JDK 8.
