Title

Minor improvement for demo apps' layout

Description
In all demo apps, in views/layout/main.php, in the part where navigation is defined:

```
echo Nav::widget([
    'options' => ['class' => 'navbar-nav pull-right'],
    ...
```

should be

```
echo Nav::widget([
    'options' => ['class' => 'navbar-nav navbar-right'],
    ...
```

That prevents wrong aligning on small screens, when navigation is collapsed
