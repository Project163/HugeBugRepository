Title

Can't pass MongoRepository.find where condition due to typings

Description
## Issue Description

Hi, everyone! Thank you for your job)

I encoutered an issue. `MongoFindOneOptions` has wrong `where` typings, so I can't pass `ObjectLiteral` to `find` method.
Maybe I'm doing something wrong.

### Expected Behavior

Pass `ObjectLiteral` in `where` condition without errors:
```typescript
return this.repository.find({
    where: { someId: { $in: ["id1", "id2"] } },
});
```


### Actual Behavior

[Image: image]


```
Type '{ someId: { $in: string[]; }; }' is not assignable to type '((FindOptionsWhere  | FindOptionsWhere []) & (ObjectLiteral | FindOptionsWhere  | FindOptionsWhere [])) | undefined'.
  Type '{ someId: { $in: string[]; }; }' is not assignable to type 'undefined'.ts(2322)
```

### My Environment

 

| Dependency          | Version  |
| ---                 | ---      |
| Operating System    |     Ubuntu 20     |
| Node.js version     | 16.17.0  |  
| Typescript version  | 4.7.4  |  
| TypeORM version     | 0.3.10  |  


### Additional Context

If I change `MongoFindOneOptions` from this:

```
typescript
import { FindOneOptions } from "../FindOneOptions"
import { ObjectLiteral } from "../../common/ObjectLiteral"

/**
... [Log Snipped] ...
    where?: ObjectLiteral
}
```

to this:

```
typescript
import { FindOneOptions } from "../FindOneOptions"
import { ObjectLiteral } from "../../common/ObjectLiteral"

/**
... [Log Snipped] ...
    where?: FindOneOptions ["where"] | ObjectLiteral;
};
```

The problem is gone:
