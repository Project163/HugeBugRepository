Title

Using unique in a returning with sentinel looses the sentinel filter

Description
This is likely an edge case, but it's still a bug
```
py
import sqlalchemy as sa

metadata = sa.MetaData()
t = sa.Table(
... [Log Snipped] ...
    )
    print(r.unique().all())
```
the above prints
```
[('a',), ('b',)]
[('a', 3), ('b', 4)]
```
while it should print `[('a',), ('b',)]` twice.

The issue is likely that `CursorResult` does not set `sentinel_filter` as the tuple filter of the metadata
