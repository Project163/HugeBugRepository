Title

List of out of sync items from remote device is not displayed

Description
There is a bug in the "out of sync items" modal for remote devices. Only the header and folder name are shown although the network log shows that the JSON data is fetched. This happens if the folder name has a space in it and the generated CSS id in data-target (responsible for toggling the list) becomes invalid.
