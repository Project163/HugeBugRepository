Title

Error with constraint names on postgres

Description
On postgres there is a break on db syncing if the same column name is defined on multiple tables with a unique constraint. 

Take the following models as an example :
```
typescript
@Table()
export class A{
    @PrimaryGeneratedColumn()
    id:number;
... [Log Snipped] ...
    name:string;
}
```
The creation of table b will break as `uk_name` is already defined in table a. Perhaps add the table name into the constraint name in the form uk_[table]_[column]. It might be beneficial to add unique constraint names to the naming strategy interface.

@pleerock If you need help just choose a solution and I'll make a pr.
Discussion
- Not sure how to make it in the naming strategy interface, but you can do it in the `PostgresQueryRunner` just replacing `uk_ + columnName`  to `uk- + tableName + _ columnName`. Feel free to create a PR ;)
