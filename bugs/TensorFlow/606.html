### Current behavior?

Conv2D backprop APIs can lead to assertion failure at graph optimization step.
[Link: Error location]:
```C++
  std::vector  strides = GetStrides(op_info);
```
Here It tries to get strides from input. But because there is no guard that checks size of `strides`, it ends up with assertion failure at [Link: `GetStrides`]:
```C++
    DCHECK(strides.size() == 4)
           cfunction_call
Aborted (core dumped)
```
