Title

rest Update and Create actions should report error if saving fails

Description
Even if saving fails (`save()` returned false) these actions return 200 OK and (very confusingly) render  unsaved model. How to reproduce:
1. Configure route to use ActiveController with any model
2. In model's `beforeSave()` return false
3. Try doing requests `POST /models` or `PUT /models/1` and you'll see successful response even though data was not saved

I think for now just returning 500 is enough
