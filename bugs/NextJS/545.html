Title

Redirect Return Type Error for GET Route Handler with 13.5.1

Description
### Link to the code that reproduces this issue

[URL]

### To Reproduce

1. npm install
2. npm run build
3. Should receive type error preventing working build

### Current vs. Expected behavior

As of now, any route handler receives a type error during build since it is looking for a `Response` being returned, however the redirect function returns `never`. The expected behavior should be that a GET route handler ending with a redirect does not receive a type error.

Code:
```typescript
import { redirect } from "next/navigation";

export async function GET(request: Request) {
  redirect("[URL]
}
```

Error:
```bash
src/app/api/route.ts
Type error: Route "src/app/api/route.ts" has an invalid export:
  "Promise " is not a valid GET return type:
    Expected "Response | Promise ", got "Promise ".
      Expected "Promise ", got "Promise ".
        Expected "Response", got "void".
```

As shown in the docs, this interaction should be allowed (unless it was changed with 13.5 and I am unaware): [URL]
