Title

SocketException in CakeEmail::attachments() does not output filename

Description
When using CakeEmail::addAttachments() which in return calls CakeEmail::attachments() to add an attachment, the method throws a SocketException with the Message 'File not found: ""', if the file, trying to be attached couldn't be found.

Unfortunatly the exception doesn't tell which file is not found because $fileInfo['file'] is previously overwritten with realpath($fileInfo['file']) which returns false if the file is not found.
Therefore $fileInfo['file'] doesn't contain the filename anymore but false instead which is then passed as a parameter to the SocketException message.

lib/Cake/Network/Email/CakeEmail.php: Line 1025+

``` php
$fileInfo['file'] = realpath($fileInfo['file']);
if ($fileInfo['file'] === false || !file_exists($fileInfo['file'])) {
    throw new SocketException(__d('cake_dev', 'File not found: "%s"', $fileInfo['file']));
}
```
