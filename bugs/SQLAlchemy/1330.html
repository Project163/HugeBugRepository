Title

Cannot connect to Azure Synapse when lacking "view database state" permission

Description
### Describe the bug

If a user lacks the "view database state" permission for Azure Synapse, that user cannot connect to it with sqlalchemy version 1.4.40, because the user does not have permission to select from the system view `sys.dm_pdw_nodes_exec_sessions`.  Prior to version 1.4.39, this exception was handled within sqlalchemy and Engine.connect() returned a sqlalchemy Connection rather than raising the exception.  This changed with pull request #8233 .

### To Reproduce

```
python
from urllib.parse import quote_plus
from sqlalchemy import create_engine

username = input("Username: ")
... [Log Snipped] ...
engine = create_engine("mssql+pyodbc:///?" + "&".join(f"{key}={value}" for key, value in ce_params.items()))
engine.connect()
```
