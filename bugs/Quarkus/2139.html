Title

UpxCompressionBuildStep Not Executed Since Quarkus 3.8.2

Description
### Describe the bug

When building a native executable with UPX compression enabled, the compression build step is not executed in Quarkus >=3.8.2.

This happens with a direct as well as an in-container build.

### Expected behavior

The executable gets compressed.

### Actual behavior

The executable won't be compressed without any hint or warning.

### How to Reproduce?

1. Create app with Quarkus >= 3.8.2: quarkus create
2. Build the app: mvn package -Dnative -Dquarkus.native.compression.level=1
3. The executable won't be compressed.

### Output of `uname -a` or `ver`

### Additional information
