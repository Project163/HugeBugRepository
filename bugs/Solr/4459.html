Title

NullPointerException in AggregateMetric

Description
The  getMax  and  getMin  methods in  AggregateMetric  can throw an NPE if non- Number  values are present in  values , when it tries to cast a  null   Double  to a  double . 

 This PR prevents the NPE occurring:  [URL]

 (We've also noticed an error in the documentation - see  [URL] - this could be pulled out into a separate ticket if necessary?)
