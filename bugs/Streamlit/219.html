Title

Unecessary warning for date_input widget with default value rewritten by session state api

Description
### Checklist

- [Link: X] I have searched the [existing issues] for similar issues.
- [X] I added a very descriptive title to this issue.
- [X] I have provided sufficient information below to help reproduce this issue.

### Summary

I have a date_input with min, max, default value and a key for a session_state variable as well. And because of that, the streamlit is showing an annoying warning message saying that the default value was rewritten by the session_state variable.

But when I remove the default value so only the key value from session_state is used, I got an error because by default streamlit sets the value as the current date, in which is greater than the max_value I setup in the input.

So I tried in many ways to suppress this warning but I could make it. The only way I've heard was by commenting some lines of code in the streamlit source code. But I don't want to in that way for obvious reasons.

Another person had the same problem as me [Link: in this discussion on streamlit community]. Then I came here to see if anyone had already made an issue for that.

### Reproducible Code Example

[Link: [Image: Open in Streamlit Cloud]]

```
Python
import streamlit as st
import datetime

min_date = datetime.date(2020,1,1)
... [Log Snipped] ...

st.write(st.session_state['custom_date'])
```


### Steps To Reproduce

1. Create a streamlit page with the code snippet above
2. And only for the first time you open it, will show the annoying warning
3. If you remove the default value in the date_input for the warning to not show again, it will give an error as the default date will be set the current date, in which is after the max_value.

### Expected Behavior

I expected that this warning didn't show off, or even have an option on streamlit to suppress it.

- Hey @eduardochaves1 👋 

Here's how you can workaround the issue. Use one session state variable to hold the default value (e.g. "custom_date"), and another to assign as the widget key (e.g. "date_key"). If the widget key doesn't exist in session state, assign the default value to the former variable:

```
python
import datetime
import streamlit as st

min_date = datetime.date(2020, 1, 1)
... [Log Snipped] ...

st.write(st.session_state["date_key"])
```
