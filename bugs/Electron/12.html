Title

App Crash in OS X when using showSaveDialog with filter with no extensions

Description
When trying to use `showSaveDialog` or `showOpenDialog` in OS X, if you pass in a filter object to `options` that has an empty `extensions` array, Electron crashes.

```
js
var remote = require('remote');
var dialog = remote.require('dialog');
dialog.showSaveDialog(remote.getCurrentWindow(), {
    filters: [{
... [Log Snipped] ...
    }]
});
```

This is working in Windows and Linux.
