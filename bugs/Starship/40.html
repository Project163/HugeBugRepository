Generated bug report:
#### Current Behavior
Currently defined rules for detecting rlang projects are not working for the most basic example of an R package. Currently defined detection by *.R files etc doesn't work because those files are located in subdirectories.

#### Expected Behavior

Taking as an example Matrix package which is package that comes with R installation
```sh
git clone [URL]
cd Matrix
## R project should be detected
```

#### Possible Solution
detecting by DESCRIPTION file, which is, and always was, mandatory file in R package. Detecting by NAMESPACE file could be not covering all cases as it was not present in older versions of R.
