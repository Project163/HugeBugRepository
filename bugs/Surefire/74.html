Title

Service providers are not available during unit testing when defined by dependencies

Description
If a dependency defines some service provider by e.g. a file like  META-INF/services/java.nio.charset.spi.CharsetProvider these providers are not available during unit testing. For this example an UnsupportedEncodingException would be thrown when using a charset defined in the file during unit testing. For Reference see: < [URL] or < [URL]
