Title

Added restriction to historic queries on web UI

Description
The HiveServer2 Web UI (  HIVE-12550  ) shows recently completed queries.  
However, a user can see the queries run by other users as well, and that is a security/privacy concern. 
Only admin users should be allowed to see queries from other users (similar to behavior of display for configs, stack trace etc).
