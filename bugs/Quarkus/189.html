Title

Quarkus Test Resources with same order are considered equal

Description
**Describe the bug**
I have implemented a QuarkusTestResourceLifecycleManager with default order (0). When running my tests, the LambdaResourceManager is never started.

**Expected behavior**
All Test Resources should be started.

**Actual behavior**
When debugging into TestResourceManager I noticed that Test Resources are gathered in a TreeSet.
`Set  testResourceRunners = new TreeSet(new QuarkusTestResourceLifecycleManagerComparator());`
So two Test Resources with the same order are considered equal and one replaces the other.

**To Reproduce**
Steps to reproduce the behavior:
1. Implement a QuarkusTestResourceLifecycleManager with default order.
2. Run tests for quarkus-amazon-lambda.

**Environment (please complete the following information):**
 - Output of `uname -a` or `ver`: Linux sku-ubuntu 5.0.0-23-generic #24~18.04.1-Ubuntu SMP Mon Jul 29 16:12:28 UTC 2019 x86_64 x86_64 x86_64 GNU/Linux
 - Output of `java -version`: openjdk version "1.8.0_222"
OpenJDK Runtime Environment (build 1.8.0_222-20190711120915.buildslave.jdk8u-src-tar--b08)
OpenJDK 64-Bit GraalVM CE 19.1.1 (build 25.222-b08-jvmci-19.1-b01, mixed mode)
 - GraalVM version (if different from Java): 
 - Quarkus version or git rev: 0.20.0
