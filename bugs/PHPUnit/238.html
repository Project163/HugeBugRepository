Title

Tests are run more than once if ` ` has overlapping ` `s

Description
| Q                   | A
| --------------------| ---------------
| PHPUnit version     | 10.3.2
| PHP version         | 8.1.22
| Installation Method | Composer

#### Summary

Tests are run more than once if `phpunit.xml` hast ` ` with overlapping ` `s.

The ` ` includes two ` ` elements:

```
    
        
            tests/**/* 
            tests/* 
        
    
```

In PHPUnit 8.5 41 tests have been executed, in PHPUnit 10.3 71 tests have been reported. Test execution time doubled from 5 to 10 seconds.

(Interestingly the number of tests does not double even there are no test files directly below `tests/`. There is one test using a data provider having 7 data sets – if that might be relevant.)

When running PHPUnit with `--testdox-text` both versions of PHPUnit reported 41 tests in the output.

Removing ` tests/**/* ` solves the issue.


#### Current behavior

Tests are run more than once.


#### How to reproduce

Adjust `phpunit.xml` as shown above.


#### Expected behavior

Tests are run only once. (Or there is some hint that tests are run more than once because of overlapping ` ` elements.)
