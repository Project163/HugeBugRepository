Title

Evict last members of a group when the maximum allowed is reached

Description
While analysing  [URL] we found that multiple members of a group can be evicted from a group if the leader of the consumer offset partition changes before the group is persisted. This happens because the current evection logic always evict the first member which rejoins the group. 

 We would like to change the evection logic so that the last members to rejoin the group are kicked out instead.
