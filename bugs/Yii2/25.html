Title

Security::generateRandomKey() OpenSSL

Description
When using the generateRnadomKey function with OpenSSL many time the random key will contain `+` and `/`. The `/` cause problems if you ever want to use the key within a url because even if you use `urlencode` it will still cause problems for apache and other web servers.
