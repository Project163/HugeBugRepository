Title

AsyncIndex stats do not capture execution for runs where no indexing is performed

Description
AsyncIndexStats  currently provides a time series of the stats around when async indexing run and what time it took. Current logic only collect stats when actual indexing is performed. If no change happened in the repository from the last run that stats around that is ignored. 

 Due to this if we see a time series of when runs happen then it might not be true and gives a false impression that async indexing is slow.  

 As a fix we should record execution stats for every run
