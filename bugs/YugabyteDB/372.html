Title

BoundedRocksDbIterator::SeekToLast works incorrectly for 2nd post-split tablet

Description
```
void BoundedRocksDbIterator::SeekToLast() {
  if (!key_bounds_->upper.empty()) {
    iterator_->Seek(key_bounds_->upper);
^^^
  } else {
    iterator_->SeekToLast();
  }
}
```

`key_bounds_->upper` is exclusive, so we need to move to prev key in case if seek was successful and seek to last key otherwise.

Currently, this code path is only used for 2nd post-split tablet which is bounded by `key_bounds_->upper`, for example during the reverse scan.
