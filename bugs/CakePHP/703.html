Title

Regression with date year dropdown and empty value

Description
The form itself has a (upgraded from 2.x to have 0 as empty value key)

``` php
echo $this->Form->input('birthday', ['empty' => [0 => '- -']]);
```

The form is just fine, 3 dropdowns and the year range is as expected:

```
html
...
 
 
     - - 
... [Log Snipped] ...
 2010 
 
```

But once posted the range becomes huge, adding in all values from 0. Whereas it should just stay at the first empty value of the form).

Not sure if the optgroup part is necessary or desired, that wasn't the case with 2.x.
