Title

linebreak-style error message returns position undefined

Description
The following code:

``` js
/*eslint linebreak-style:2*/
var a = 10;
for (var i = 0; i < a; i++) {
    console.log("test");
}
```

Returns a message:

```
1:undefined - Expected linebreaks to be 'LF' but found 'CRLF'.
```

Reproducible in online demo.
