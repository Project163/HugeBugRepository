Title

Fix potential data losing for RocksDBBackend

Description
Currently, when using RocksIterator we only use the  iterator.isValid()  to check whether we have reached the end of the iterator. But that is not enough, if we refer to RocksDB's wiki  [URL] we should find that even if  iterator.isValid()=true , there may also exist some internal error. A safer way to use the  RocksIterator  is to always call the  iterator.status()  to check the internal error of  RocksDB . There is a case from user email seems to lost data because of this  [URL]
