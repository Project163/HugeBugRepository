## Description

I installed Gitea through Docker on my laptop. During the initial configuration, I disabled signup through the web interface. There was nothing about OpenID. As expected, when logged out, there's no "signup" button, only "sign in".

However, I was able to login through OpenID. As the OpenID was unknown, I was redirected to a page where I could choose between connecting this ID to an existing account, or creating a new account. Using this form I was able to create a new account on my local instance, even if signup is disabled.

I checked the config file, and sure enough there was no `[openid]` section.

After creating a new instance and re-running the setup, I edited the config file and added the following:

    [openid]
    ENABLE_OPENID_SIGNUP = true

(as seen [Link: here])
which fixed the issue.

So:
- either the web installer should include a section about OpenID, and make it possible to disable OpenID and/or signups,
- or the global `DISABLE_REGISTRATION` flag should also disable OpenID signups.

Thanks!
