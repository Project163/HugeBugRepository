Title

Numbers in attribute selectors produce parser errors

Description
``` css
ul.wysihtml5-toolbar a[data-wysihtml5-command=bold] {
    font-weight: bold;
}
```

Produces the error:

ParseError: Syntax Error on line 1 ...

1 ul.wysihtml5-toolbar a[data-wysihtml**5-command=bold] {**
2      font-weight: bold;

Where the bold bit is in red on the command line.  There is no way to escape this so I can't fix it.
Discussion
- Interesting. I get the same error. Looks like a bug to me.
- The obvious, non-ideal workaround I guess is to rename that attribute from your HTML document.
- Yeh, I've had to do that to deal with it, but that required changing a lot of code that wasn't mine :)
