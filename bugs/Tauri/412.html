Title

[bug] 1.5.0 xcrun notarytool option error

Description
### Describe the bug

```bash
export APPLE_ID='id@apple.com'
export APPLE_PASSWORD='***'

pnpm tauri build -v
```

## Error

```
   Running [tauri_bundler::bundle::common] Command `xcrun  notarytool submit /var/folders/jh/tpbw_8jx3_q6lhs07k16m6hh0000gn/T/.tmpx8iFjq/xxx.zip --wait --output-format json --username id@apple.com --password ***`
Error: Must provide an Apple ID (--apple-id) to authenticate with an app-specific password.

       Error [tauri_cli_node] failed to bundle project: failed to upload app to Apple's notarization servers.
 ELIFECYCLE  Command failed with exit code 1.
```

## Fix it

```diff
- xcrun  notarytool submit ... --wait --output-format json --username id@apple.com --password ***
+ xcrun  notarytool submit ... --wait --output-format json --apple-id id@apple.com --password ***
```
