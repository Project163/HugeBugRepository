Title

Oauth 1.0 authentication / Wrong signature

Description
* [x] bug

* CakePHP Version: 4.1.5
* Platform and Target: Any.

### What you did
I'm trying to make a post request with Oauth 1.0 authentication with an xml body. like this :

```
php
$http = new Client();
$response = $http->post('[URL] '   ', [
  'headers' => ['Content-Type' => 'text/xml'],
  'auth' => [
... [Log Snipped] ...
  ]
]);
```

### What happened
Everything works fine except that the signature generated is wrong. Cakephp uses the request body to generate it when it shouldn't.

### What you expected to happen
**Section 9.1.1 of Oauth spec (https://oauth.net/core/1.0a/#anchor13) :**

I'm expecting for cakephp dont use the body of the request to generate the Oauth Authorization when it shouldn't do it :)
