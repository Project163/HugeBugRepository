Title

addon-info causes a 'TypeError: "paddingLeft" is read-only' error on React 16

Description
We just changed our project's structure to share code between web and React Native, which currently means using React 16.0.0-alpha.12 (due to RN version 0.47). This cased the error in the title to appear in the component view where we use the info addon. Upgrading to 16.0.0-rc.3 doesn't make a difference, but downgrading to 15.6.1 removes it.
