Title

Spark submit documentation for --deploy-mode is highly misleading

Description
There are a few issues: 

 1. Client mode does not necessarily mean the driver program must be launched outside of the cluster. 

 2. For standalone clusters, only client mode is currently supported. This was the case supported even before 1.0. 

 Currently, the docs tell the user to use cluster deploy mode when deploying "your driver program within the cluster," which is true also for standalone-client mode. In short, the docs encourage the user to use standalone-cluster, an unsupported mode.
