Title

Component.getReferences returns null if a component that has references is not enabled.

Description
The implementation of method  org.apache.felix.scr.Component.getReferences  in class  org.apache.felix.scr.impl.AbstractComponentManager  doesn't use  m_componentMetadata  but  m_dependencyManagers  to return the service references of a component, which causes a calling of  getReferences  to return null before "enable component" is scheduled.
Discussion
- I agree that for management for components this is unsatisfactory. So the attached patch creates the dependency manager list upfront and only enables them in the enableInternal() method. 

 Also I encapsulated all dependency manager operations (load, enable, verify, dispose) into separate methods.
