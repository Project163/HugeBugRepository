Title

SQL: escaped wildcard (*) not accepted in LIKE pattern

Description
For a query like `SELECT name FROM test WHERE name LIKE '%c*'` ES SQL generates an error. `*` is not a special character in a `LIKE` construct and it's expected to not needing to be escaped, so the previous query should work as is.

The generated error is:
```
{
    "error": {
        "root_cause": [
```
