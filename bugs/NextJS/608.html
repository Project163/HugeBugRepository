Title

Layouts of root level parallel routes do not render properly

Description
### Link to the code that reproduces this issue

[URL]

### To Reproduce

1. Start the application in development
2. Notice the UI shows only 
[Image: Screenshot 2023-11-15 at 2 09 35 PM]

3. Change the value of `isRoute1` in `src/app/layout.tsx` to `false` and save
4. Notice the UI now shows 
[Image: Screenshot 2023-11-15 at 2 10 29 PM]


### Current vs. Expected behavior

Following the steps above, at **step 2** I expected to see output of
```
Test route 1 layout
Page 1 content
```

But instead only saw output of
```
Page 1 content
```

For some reason the layout for `route1` parallel route is being ignored but the layout for `route2` is not.

A bandaid solution that allowed both layouts to render properly was to put a `(default)` (or any group name) route group as the direct child of each parallel route and then place all files inside that route group. For some reason this change allows the layout for both parallel routes to work.

**Note:** Ran with both `14.0.2` and `^14.0.3-canary.9` but saw the same output.
