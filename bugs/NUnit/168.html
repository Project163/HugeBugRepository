@SFrank1966 Does you project indirectly reference a different version of System.Buffers? I see 4.6.1 is out.

With .NET (Framework) if any referenced project uses a different version you need to explicitly redirect that one to yours.
.NET doesn't load another version of signed assemblies as it might break things.

Note that the redirect reference the AssemblyVersion, not the NuGet version!

```xml
 
	 "
	  culture="neutral" />
	 - " newVersion=" " />
	 
 
```

At my work we have a whole file of redirects to maintain for all shared project we use (most of them our own) as libraries update at different times. As long as we don't have major version changes with breaking changes even though annoying, it works.

@nunit/core-team We might want to reconsider removing this dependency as there will be both users that use earlier and later versions of System.Memory/System.Buffers.
