Title

A search with an empty fields param causes a NullPointerException or a runaway process

Description
Hiya

An empty fields[] array either returns a NullPointerException, or causes a runaway process.  Try this:

```
curl -XGET '[URL]  -d '
{
   "fields" : [],
   "query" : {
      "matchAll" : {}
   }
}
'
```
