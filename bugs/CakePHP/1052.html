Title

conversion of time-input to time-instance failing

Description
This is a:

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 4.1.3
* Platform and Target: NGINX, mySQL, php7.4.7 in a docker-container

### What you did
Using the form-helper, I created a time-field ([Link]).
Validation setting: 
```
$validator
    ->time('departuretime')
    ->requirePresence('departuretime', 'create')
    ->notEmptyTime('departuretime');
```

### What happened
When entering a time-value without seconds (i.e. 18:45), no time-value is patched into the entity. No validation-error is beeing shown. When I leave the time-field empty, the validation-error shows up. In the request-data-Array the time-value is shown.

```
[
    'name' => 'Test',
'departuretime' => '18:00',
]
```

In the entity the departuretime is missing.

### What you expected to happen
I expected the time-value beeing converted into a time-instance and saved to the database. When I manually alter the time-value in a beforeMarshal()-function in my model (i.e. 18:45:00) or create a time instance everything works out fine.
```
public function beforeMarshal(EventInterface $event, ArrayObject $data, ArrayObject $options)
    {
        if ($data['departuretime']) {
             // creating time-instance
              $data['departuretime'] = new FrozenTime($data['departuretime']);

        }
    }
```
