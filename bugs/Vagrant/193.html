- I tried building a box with bento and then running the test command, it failed as you had raised, however, once I ran a box add command for e.g. `vagrant box add   --provider vmware_desktop --architecture arm64 --name  ` and tried to normally bring up a VM with that box using a simple Vagrantfile like below it works


Could you try adding the box and then running the up command ? While I have not investigated any further I wonder if there's a difference in how the box is getting added in both scenarios, let me know if the `box add` approach works for you while I look why there's a difference.

Edit: I think its the architecture in the `Vagrantfile` that's causing the issue could you try the same `Vagrantfile` with the `box_architecture` removed, and tell if it works, it works fine for me. Will update in case I have more details to share

Edit: Thanks for the report, I was able to find the issue, as in the earlier edit it is to do with `box_architecture`, the parameter was getting passed incorrectly to the `box add action` when adding a box directly from a file, I will raise a PR for the same and hopefully get it merged before the next release. Also I will transition this issue to Vagrant as that is where the issue is.

Cheers!
