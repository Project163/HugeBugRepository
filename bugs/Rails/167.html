Title

Regression - attribute_will_change! doesn't work for nested resources

Description
### Failing Test

```
ruby
begin
  require "bundler/inline"
rescue LoadError => e
  $stderr.puts "Bundler version 1.10 or later is required. Please update your Bundler"
... [Log Snipped] ...
  end
end
```

### Expected behavior
attribute_will_change! should make nested resources dirty, and the post's body should be updated.

### Actual behavior
attribute_will_change! has no effect for nested resources. The post's body remains nil.

It still works when directly updating the resource. This test passes:

```
ruby
  def test_resource_dirty
    user = User.create! name: 'Ruby'
    post = Post.create!(user_id: user.id, body: nil)
    
... [Log Snipped] ...
    assert_equal '1', post.reload.body
  end
```

### System configuration
**Rails version**:
Edge Rails  
**Ruby version**:
ruby 2.4.0p0


I tracked it down to this commit: [URL]
Discussion
- If it worked in 5.0.1, we should fix for 5.1. However, I want to deprecate this behavior. The intention is to require the use of `attribute` if you want it to work with the various attribute methods, including dirty.
- I'm not fully convinced this was ever intended to work, however -- especially given the lack of an `define_attribute_methods` call.
