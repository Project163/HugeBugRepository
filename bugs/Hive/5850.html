Title

Druid storage handler CTAS with boolean type columns fails.

Description
Druid storage handler CTAS fails with the exception below when a Boolean column is included. 
A simple workaround would be to add a cast to string over the boolean column, this will lead to index the column as a druid dimension with value `true` or `false`.

Discussion
- This patch adds support for boolean columns indexing. 
The only downside the actual column will be indexed as dimension string in druid while hive metastore will still consider it as boolean. 
This doesn't lead to any dysfunction, but the underline column will be treated as a metric (thus no filter push down). 
(I think) This annoying behavior can be fixed from the druid-calcite rule-based optimizer.
