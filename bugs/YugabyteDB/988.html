Title

[DocDB] Key is not table tombstone key

Description
Jira Link: [Link: DB-7016]
### Description

## Steps to reproduce

Setup

```
CREATE TABLE t (r1 INT, r2 INT, PRIMARY KEY (r1 ASC, r2 ASC));
INSERT INTO t (SELECT 1, i FROM GENERATE_SERIES(1, 100000) AS i);
```

Query

```
SELECT r2 FROM t WHERE r2   is not table tombstone key.
```
