Title

AccessControl filter should set event as handled after access denied.

Description

```
php
    /**
```

Discussion

- More backgroud info: when we attach multiple actionfilters that handle event in different ways and one does redirect to one page, other does redirect to login and some other displays different page we get conflicting behavior.
