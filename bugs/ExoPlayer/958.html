Title

IllegalStateException when drainToEndOfStream when in tunneling mode

Description
### ExoPlayer Version

2.18.2

### Devices that reproduce the issue

Model: TalkTalk STB
Os: Android
Version: 10

### Devices that do not reproduce the issue

Fire TV Stick (2nd Gen) running Fire OS   (Tunneling was not enabled for this media, tried other media with tunneling enabled but the issue was not present)

### Reproducible in the demo app?

Yes

Turn on tunneling ie in PlayerActivity:

```

              .setTunnelingEnabled(true)
              .build();

```

