Title

Problem saving belongsToMany when using a Behaior that adds an order clause in beforeFind

Description
There seems to be a problem with adding an order clause in a beforeFind method from a Behvaior when saving a belongsToMany association.

Here is my set up.

**Behavior**

``` php
/* OrderBehavior.php */
public function beforeFind(Event $event, Query $query, ArrayObject $options)
{
    if (!$query->clause('order')) {
        $query->order([$this->_table->alias() . '.order' => 'ASC']);
    }
}
```

**Associations**

```
php
/* CoursesTable.php */
public function initialize(array $config)
{
    //...
... [Log Snipped] ...
    $this->addBehavior('Order');
}
```

When trying to save with this set up you get the following SQL which is incorrect.

``` sql

UNION SELECT `course_modules`.`course_id` AS `course_modules__course_id`, `course_modules`.`module_id` AS `course_modules__module_id`, `course_modules`.`order` AS `course_modules__order` FROM `course_modules` `course_modules` WHERE (`course_id` = :c2 AND `module_id` = :c3) ORDER BY `course_modules`.`order` ASC
```

This produces the following error:

```
 Error: SQLSTATE[HY000]: General error: 1221 Incorrect usage of UNION and ORDER BY 
```
