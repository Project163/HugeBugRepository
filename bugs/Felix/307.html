Title

Configuration.getProperty returns a Dictionary which is not entirely private

Description
According to the specification of the Configuration.getProperties() method in  , the dictionary returned "is a private copy for the caller and may be changed without influencing the stored configuration". 

 This is not currently the case for array and vector/collection properties: Updating the array or vector/collection is reflected in the internal data structure kept by the configuration manager because only the internal Dictionary is copied into a new Dictionary while the values are copied by reference. 

 Actually a full deep copy of the dictionary is required.
Discussion
- In Rev. 735651 modified Configuraiton.getProperties() implementation such that not only the internal dictionary is copied but also any array and colleciton stored in the dictionary. In addition I added a number of testcases ensuring we really get deep copies.
- Deep copy of properties is required and Vector (instead of Collection) should be returned. 

 This is now correctly implemented and this issue can be closed.
