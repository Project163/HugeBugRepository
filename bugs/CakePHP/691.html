Title

More meaningful exception messages

Description
When running tests I'm getting this exception, I know what is wrong, me or a workmate somewhere outcommented the indexes in the _indexes array. But that's not the point. The issue here is that we have a ton of fixtures and I already checked them twice and still must have missed it.

It would be awesome if the error message would include the table name or full class name of the object or if the trace would be shown.

```
Configuration read from C:\xampp\htdocs\crm\phpunit.xml.dist

Exception: Indexes must have at least one column. in [C:\xampp\htdocs\crm\vendor\cakephp\cakephp\src\Database\Schema\Table.php, line 409]
```

There are probably other messages as well that could be improved. The messages should not only be informative (Haha, something is wrong! Go figure! :p) but helpful (This Foo in place Bar is wrong!). The framework should support me and not let me make guesses when developing.

If you agree I'll do a PR to improve it with this change:

```
php
    public function addIndex($name, $attrs)
    {
        if (is_string($attrs)) {
            $attrs = ['type' => $attrs];

    }
```
