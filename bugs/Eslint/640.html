Title

Trailing comma detection broken for ternary operator in parens

Description
When configured with:

```
    "comma-dangle": [2, "always-multiline"],
```

This code:

```
    var foo = [
      (bar ? baz : qux),
    ];
```

complains with

```
79 col 18 error| Unexpected trailing comma. (comma-dangle) [javascript/eslint]
```

but if I change the code to

```
    var foo = [
      bar ? baz : qux,
    ];
```

It doesn't complain (correctly).
