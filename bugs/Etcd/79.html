Title

etcd 3.0.1 startup failure on Windows 7 64-bit

Description
The following error is seen when trying to start etcd 3.0.1 on Windows 7 64-bit if the `default.etcd` directory tree is not already present:

```
2016-07-02 01:12:50.368813 I | etcdmain: etcd Version: 3.0.1
2016-07-02 01:12:50.368813 I | etcdmain: Git SHA: a4a52cb
2016-07-02 01:12:50.368813 I | etcdmain: Go Version: go1.6.2
2016-07-02 01:12:50.368813 I | etcdmain: Go OS/Arch: windows/amd64
2016-07-02 01:12:50.368813 I | etcdmain: setting maximum number of CPUs to 8, total number of available CPUs is 8
... [Log Snipped] ...
2016-07-02 01:12:50.368813 I | etcdserver: initial cluster = default=[URL]
2016-07-02 01:12:50.378813 C | etcdserver: create wal error: rename default.etcd/member/wal.tmp default.etcd/member/wa: Access is denied.
```

This will repeatedly fail until you manually rename `default.etcd/member/wal.tmp` to `default.etcd/member/wal`. Then etcd will start normally.

Notably, this problem is **not** seen in etcd 2.3.7 under the same initial conditions.
