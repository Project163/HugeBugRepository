Title

aio: "get started" and "learn more" buttons not working on FF

Description
Those buttons on the home page doesn't work at all in FF. Also I noticed in Chrome that only a specific region of it does the click while the other doesn't.
Discussion
- The problem is that we have a ` ` tag nested in ` ` - this html code is invalid. [According to MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/button
), the only valid child of a button element is "[Link: phrasing content]", which does include ` ` but only if it's not interactive ([spec](https://html.spec.whatwg.org/multipage/form-elements.html#the-button-element
)). 

We have two options to resolve this:

- remove the need for the button element
- wrap the button element into anchor (the opposite of what it is now)

Both of these require CSS changes, so I'm going to leave this up to @sjtrimble or @gkalpak to handle.
