Title

[YSQL][SQLancer] cache lookup failed for type on ANALYZE table after dropping column

Description
Jira Link: [Link: DB-3074]
### Description

Simplified reproducer
```
CREATE TABLE t3(c0 bytea , c1 inet  NULL) WITHOUT OIDS ;
ALTER TABLE  ONLY t3 DROP  IF EXISTS c1;
ANALYZE t3;
```

Output
```
postgres.public> CREATE TABLE t3(c0 bytea , c1 inet  NULL) WITHOUT OIDS
[2022-07-28 17:22:17] completed in 49 ms
postgres.public> ALTER TABLE  ONLY t3 DROP  IF EXISTS c1
[2022-07-28 17:22:17] completed in 79 ms
postgres.public> ANALYZE t3
[2022-07-28 17:22:17] [XX000] ERROR: cache lookup failed for type 0
[2022-07-28 17:22:17] [0A000] 'analyze' is a beta feature!
```
