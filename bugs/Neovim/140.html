Title

mpv's tct video output makes nvim segfault

Description
Yes, you read that right. I tried to play a video file in a `:terminal` buffer using mpv. Why, you ask? I found it in the man page, wanted to try it out as a joke and happened to have a nvim session with a terminal buffer open at the time. Pure coincidence paired with curiosity.

Let me preface this that I have no need to actually see this working. I just felt that, even for abnormal circumstances, it should not be possible to predictably and reliably induce a segfault in a non-alpha/beta/rc/whatever version. Feel free to ignore if you think it's okay to crash for a nonsensical use case like this, I honestly can't bring myself to disagree.
