Title

Wayland window is always resizable

Description
If if I add  `glfwWindowHint(GLFW_RESIZABLE, GLFW_FALSE);` to the [Link: triangle-opengl] example, the window becomes non-resizable in X11 but the hint does not affect Wayland. Even, if one were to reset the window size manually after the resize attempt, the user would still see "resize cursors" and would be disappointed that resize isn't working.

Also there are a load of `Error: Wayland: Standard cursor shape unavailable` errors, when mousing over the wayland window border.
Discussion
- I have noticed this as well with code that I am working on separately. It also seems to ignore the minimum/maximum size hints as well.
- I have same issue, glfwWindowHint(GLFW_RESIZABLE, GLFW_FALSE) is ignored.
- Window is not resizable (Arch, KDE) and glfwWindowHint(GLFW_RESIZABLE, GLFW_TRUE) is ignored.
- With   the GLFW_RESIZABLE window hint and attribute should now work for all decoration paths. Thank you for the bug report!
