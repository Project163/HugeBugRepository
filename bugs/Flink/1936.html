Discussion
- Hi Peter, 
this error occurs due to this task  [URL]
It's not allowed now to have input and feedback streams of different parallelism level. What you can do in your particular example is to change parallelism of the feedback stream: 

  
 it => {
      (it.filter(_ > 0).map(_ - 1).setParallelism(1), it.filter(_ > 0).map(_ =>  'x' )
 
  

 Parallelism level of fromCollection/fromElements is always '1' 
Probably we should at least document that parameter keepPartitioning of DataStream.iterate is ignored
- Since this is kind of non-trivial to detect shouldn't flink somehow handle it (set default parallelism = 1) in this case?
