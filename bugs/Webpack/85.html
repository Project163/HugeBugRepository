Title

Webpack is not replacing default argument values with __WEBPACK_IMPORTED_MODULE_ value

Description
To reproduce this error clone [Link] and modify `car.ts` to: 

```ts
import * as E from './engine';


function fooBar({some, bar = E.V6Engine}) {
  console.log('FooBarBaz');
}
```

And run `npm run webpack-es2015`

The output file at `dist/car.es2015.bundle.js` has following content at the end:

```
js
/***/ },
/* 1 */
/***/ function(module, exports, __webpack_require__) {

... [Log Snipped] ...
    console.log('FooBarBaz');
}
```


**Webpack version:**
2.1.0-beta-25


**Please tell us about your environment:**
OSX 


**Current behavior:**

function default argument value is  not `__WEBPACK_IMPORTED_MODULE_0__engine_.V6Engine`

**Expected/desired behavior:**
function default argument should be `__WEBPACK_IMPORTED_MODULE_0__engine_.V6Engine`


* **Language:** TypeScript 


I believe this is not specific to TypeScript and is a general behavior for ES2015 modules.
