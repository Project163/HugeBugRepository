Title

Quarkus Reactive Resource wrong response on non-existing endpoint

Description
### Describe the bug

Quarkus Reactive  Resources are responding on non-existing endpoints, if I have an endpoint that answers in [URL] I get the same response in [URL] although this is not defined.

Only happens if the part after the last / is only one character, if you call  [URL] you get the expected 404 response.

Same behavior with POST method.

### Expected behavior

A 404 Not found response as the endpoint is not defined

### Actual behavior

200 OK
