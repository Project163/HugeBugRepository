Title

Response format produced is not valid HAL

Description
According to the guide presented [Link: here] the response produced for a request with an `Accept` header of `application/hal+json` looks like this:

```
javascript
{
  "id": 1,
  "name": "John Johnson",
  "birth": "1988-01-10",
... [Log Snipped] ...
  }
}
```

The `_links` section is not valid HAL as [Link: according to the spec], each link is an object and the target URI is held in an `href` property. I.e. the `_links` element would have to look like this:

```javascript
{
  …,
  "_links" : {
    "self" : {
      "href" : "…" // Nested href attribute
    },
    …
  }
}
