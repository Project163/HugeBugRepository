I think it is to do with declaring a type in the form:
```
@psalm-type myType = array {
  field1: string,
  field2: int
}
```

My guess it that if you forget the comma here it is interpreting the first line as part of the LHS (left hand side) of the second field declaration.

```
@psalm-type myType = array {
  field1: string // <- Missing comma here might be the issue?
  field2: int
}
```
