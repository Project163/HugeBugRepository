Title

Eager-loading through associations: Query joins the same table multiple times

Description
When I eager-load multiple `has_many through` associations in the same query, and they are all associated through the same table, it seems to me that the table in between them only needs to be `LEFT OUTER JOIN`'ed once in the query.  However, it's in fact joined once for each through association, even if it has already been eager-loaded directly.

I suspect this comes at a cost, since joining the same table twice in the same query means the DB would have to do twice as much work as if it had only had to join that table once.

I can't think of a reason this would be necessary.  If this behavior is necessary, please enlighten me.

Run the following script.  It generates the SQL used to eager-load multiple through-associations.

```

### Expected behavior
The query should `LEFT OUTER JOIN "ships"` once and use the resulting association for all through associations.

```
SELECT "captains"."id" AS t0_r0, "ships"."id" AS t1_r0, "ships"."captain_id" AS t1_r1, "sails"."id" AS t2_r0, "sails"."ship_id" AS t2_r1, "sails"."color" AS t2_r2, "anchors"."id" AS t3_r0, "anchors"."ship_id" AS t3_r1 FROM "captains"
LEFT OUTER JOIN "ships" ON "ships"."captain_id" = "captains"."id"
LEFT OUTER JOIN "sails" ON "sails"."ship_id" = "ships"."id" AND "sails"."color" = 'red'

```
