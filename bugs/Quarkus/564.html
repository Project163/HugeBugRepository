- I'm going to close this, because it's actually an error in the configuration (`application.properties` the datasource declaration twice in addition to `quarkus.datasource.db-kind` and `quarkus.datasource.driver` being set together).

[URL] should be implemented to make these errors more clear.
- Actually I am reopening this one for the specific issue that we currently can't seem to set both:

```
quarkus.datasource.db-kind=postgresql
quarkus.datasource.driver=org.postgresql.Driver
``` 

Not being able to set them together is fine (I guess, although when they "match", it probably should be allowed), but we at least need a good error message.
