Title

Injecting ConfigProperty of type Optional > not working in the native mode

Description
### Describe the bug

Given code:

```java
    @Inject
    @ConfigProperty(name = "stuff")
    Optional > stuff;
```

will result in an empty optional, even when running in an environment where variable STUFF is set to a valid, non-empty value.


### Expected behavior

That the optional is not empty if the env var STUFF is set to a valid, non-empty value.

### Actual behavior

The optional is empty
