Title

Druid handler might not recognize correct column type when CBO fails

Description
When CBO is not enabled/fails, we should still be able to run queries on Druid datasources. 

 This is implemented as Select query that will retrieve all data available from Druid and then execute the rest of the logic on the data. However, currently we might fail due to wrong inferred type for the Druid datasource columns for numerical types.
