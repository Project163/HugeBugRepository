Title

Replacing method on ExpandoMetaClass doesn't work

Description
Expando.metaClass.foo={-> def directBar=delegate.bar()
    println  "directBar=${directBar}"     
    def invokedBar=delegate.invokeMethod( 'bar' , null )
    println  "invokedBar=$invokedBar" 
}

e= new  Expando()
e.metaClass.bar={->1}
e.foo()
 //directBar=1
  //invokedBar=1
 
e.metaClass.bar={->2}
e.foo()
 //directBar=1
  //invokedBar=2 
 
  

 for some reason delegate.bar() != delegate.invokeMethod('bar',null) 
looks like at the direct call the closure got cached ... 

 if the previous example continues with: 

  
 x= new  Expando()
x.metaClass.bar={->3}
e.foo()
 //directBar=2
  //invokedBar=2 
 
  

 creating the new 'x' object has side effect on the 'e' objects metaclass?
Discussion
- I believe I've run into the same issue: 
  
 class Foo { }
Foo f = new Foo()

for (idx in 1..3) {
  def sound = 'woof' * idx
  def x = { println sound }
  f.metaClass.bark = x
  f.bark()
}
 
  
 The output should be 
  
 woof
woofwoof
woofwoofwoof
 
  
 but is 
  
 woof
woof
woof
 
  

 Note that if we inline the 'sound' expression, it works correctly: 
  
 class Foo { }
Foo f = new Foo()

for (idx in 1..3) {
  def x = { println 'woof' * idx }
  f.metaClass.bark = x
  f.bark()
}
- The following tests pass since version 2.2 and also in master. 

  
 Expando.metaClass.foo = { -> delegate.bar() }

def e =  new  Expando()

e.metaClass.bar = { -> 1 }
 assert  e.foo() == 1

e.metaClass.bar = { -> 2 }
 assert  e.foo() == 2
 
  

  
  class  Foo {}
Foo f =  new  Foo()
def results = []
 for  (idx in 1..3) {
    def sound =  'woof'  * idx
    def x = { sound }
    f.metaClass.bark = x
    results << f.bark()
}
 assert  results == [ 'woof' ,  'woofwoof' ,  'woofwoofwoof' ]
