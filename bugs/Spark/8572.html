Title

The dataframe returned by exceptAll() can no longer perform operations such as count() or isEmpty(), or an exception will be thrown.

Description
As I said, the dataframe returned by `exceptAll()` can no longer perform operations such as `count()` or `isEmpty()`, or an exception will be thrown. 

   

   
  
 
>>> d1 = spark.createDataFrame([( "a" )],  'STRING' )
>>> d1.show()
+-----+
|value|
+-----+
|    a|
+-----+
>>> d2 = d1.exceptAll(d1)
>>> d2.show()
+-----+
|value|
+-----+
+-----+
>>> d2.count()
