- As I mentioned in the PR, the problem isn't solved entirely by that PR. Now the progress indicator stays in one place, but still isn't right:
[Image: bugreport-after-gif]

I found, that the problem lies in the fact, that virtually anything can `console.log()` during the progress output, which breaks Windows' terminal. Long story short: This is something nothing can be done about.

But there is a workaround: don't use prescripts in npm. I.e. instead of this:
```json
"scripts": {
    "clean": "rimraf dist",
    "prebuild": "npm run clean",
    "build": "webpack --progress --hide-modules"
  },
```
use this:
```json
"scripts": {
    "clean": "rimraf dist",
    "build": "npm run clean && webpack --progress --hide-modules"
  },
```
which will work in any terminal, any OS. Seems like this is npm's problem and not webpack's.

Bottom line: it's a `Won't Fix`
