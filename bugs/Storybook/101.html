Title

Storyshots: Incorrect typings for method "test"

Description
**Describe the bug**
In the file `StoryshotsOptions.ts` the method [Link: test] is defined as 

```ts
(story: any, context: any, renderTree: RenderTree, options?: any) => any;
```
But in the [Link: snapshotsTestTemplate], it is called as

```ts
        testMethod({
          story: item,
          context,
          ...testMethodParams,
        }),
```

where `...testMethodParams` is defined in [Link: src/api/index.ts] as 

```ts
{
    renderTree,
    renderShallowTree,
    stories2snapsConverter,
  };
```

**To Reproduce**
Steps to reproduce the behavior:

Create 
1. Create a new project with storybook (usin `sb init` to get some default stories)
2. Add Storyshots
3. Run the following test

```
ts
import initStoryshots from "@storybook/addon-storyshots";

describe("test", () => {
  initStoryshots({
... [Log Snipped] ...
  });
});
```

**Expected behavior**
Based on the typings, I would have expected an output that matches the types, but the output is 



```
{
   story: {id: 'app--default', kind: ...  },
   context: {...}
   renderTree: [Function: getRenderedTree]
   options: ...
```
The actual output is 

```
console.log src/inspect.test.ts:8
    { story:
       { story:
          { id: 'app--default',
            kind: 'App',
... [Log Snipped] ...
      renderTree: undefined,
      options: undefined }
```

It seems like the of the `test`-method should be something like:

```
 test?: (args: {
    story: any;
    context: any;
    renderTree: RenderTree;
    renderShallowTree: RenderTree;
    stories2SnapsConverter: Stories2SnapsConverter;
  }) => any;
```
