Title

JSON datetime ISO 8601 format in find ()

Description
This is a (multiple allowed):
- [x] bug
- [ ] enhancement
- [ ] feature-discussion (RFC)
- CakePHP Version: 3.3 
### What you did

when I call find on a model and add an alias to created field as following:

```
$this->Photos->find('all', [
                            'conditions' => [
                                'related_id' => $brand['id'],
                                'type' => 'brand'
                            ],
... [Log Snipped] ...
                                "time"=> "created"
                            ]]);
```

time value is not formated as ISO 8601 in JSON serialization.
if I removed the alias "time" the created field is formatted correctly to ISO 8601 format by default.
### Expected Behavior

the create date/time field  with alies should return it in ISO 8601 datetime format.
Discussion
- As a workaround when you alias complex fields you need to declare the types you'd like returned into the type map.

``` php
$query->selectTypeMap()->types(['time' => 'time'])
```

The ORM can infer type information for column names in the schema, but not for columns that are aliased/defined with custom functions.

I think inferring types for simple aliases should be doable.
