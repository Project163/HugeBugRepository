Title

JAX-RS providers shared between endpoints or clients with different buses lose injected TL proxies

Description
JAX-RS providers with @Context-annotated fields, being singletons, have thread-local proxies injected. If the same instance is shared between the components with different buses then the component-specific provider handlers may have the proxy references different to the one actually injected into the provider
