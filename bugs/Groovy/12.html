Title

support heredocs to allow text to be easily marked up using <

Description
Folks seem to like heredocs for doing markup without worrying about quote issues etc. 

 blah <<token 
... 
... 
token
Discussion
- Heredocs/verbatim/reports whatever you want to call them are implemented.  The syntax is <<<TOKEN\n....text....\nTOKEN  They act just like double quoted GStrings so you can use them for large template text quite easily: 

 println(<<<EOS 
Hello there! 
EOS) 

 is exactly the same as 
println("Hello there!") 

 Notice there are no trailing or prefixed new lines.  You can see other examples in VerbatimGStringTest.groovy.
