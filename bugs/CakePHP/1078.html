Title

MailContains escapes multiple times if there are multiple mails

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 4.2.1
* Platform and Target: PhpUnit

### What you did
- Send two emails within one PHPUnit test, one of them contains a UUID.
- Use the EmailTrait to test emails
- use assertMailContains($uuid)

### What happened
- one of the mails actually contained a uuid
- assertMailContains($uuid) failed nonetheless

### What you expected to happen
- assertMailContains($uuid) should not fail

### Why it happend
In /src/TestSuite/Constraint/Email/MailContains.php:46 the string to search for is escaped to prevent regexp injection.
Sadly, this is done *inside* the `foreach`-loop that iterates over all mails that have been sent. So if there are 10 mails, the pattern will be escaped 10 times instead of once.

Since our search pattern was a UUID, UUIDs contain dashes and dashes are reserved characters in RegExps, the dash got encoded multiple times and did not match anymore.
