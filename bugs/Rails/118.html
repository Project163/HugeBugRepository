Title

content_tag ignores block with non-string value b/c capture ignores non-strings

Description
Given the following code outside an ERB context returns an empty `  ` tag instead of my assumed ` 1.0 `:

``` ruby
content_tag(:p) do
  1.0
end
```

I find this counter-intuitive and would argue for an implicit `#to_s`, but the underlying [Link: capture] ignores non-String values.

Is the behaviour for `content_tag` intentional? Are there any foul consquences for a `capture` that looks like this?

``` ruby
def capture(*args)
  value = nil
  buffer = with_output_buffer { value = yield(*args) }
  if string = buffer.presence || value.to_s
    ERB::Util.html_escape string
  end
end
```
