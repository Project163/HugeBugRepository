Title

Tests for examples failing on Windows

Description
This change only impacts   tests   on Windows. Post the fix for jvm-opts, command line execution runs fine. 
The start flow via solr.cmd passes a "--script" parameter (which our tests don't) and uses a different executor inside RunExampleTool from what the tests use (RunExampleExecutor). Prior to recently merged fix for jvm-opts, because of these reasons, the tests on Windows would also try to prepare a command line with bin/solr (instead of bin/solr.cmd). Hence those tests would pass getting into the "if" block in this PR, although in an unintended way.
