Title

Date validator is not working properly

Description
### What steps will reproduce the problem?
Input Date: 13-Mar-19
System Format: medium `($this->format used in DateValidator)`
 
When `timestampAttribute` set that time not working. like
```
['approval_date', 'date', 'timestampAttribute' => 'approval_date', 'timestampAttributeFormat' => 'yyyy-MM-dd'],
// That Consider a date is valid but is not a valid
```
```
['approval_date', 'date']
//Working Properly
```

### What is the expected result?
Need invalid date message when configure `timestampAttribute` and `timestampAttributeFormat`.

### What do you get instead?
Date is validated

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.17
| PHP version      | 7.2
| Operating system | Ubuntu 18.04

Investigating it a bit more.
Validation of the date is performed based on whether the date can be parsed without an error or not and 
if ICU format is used (intl extension) `IntlDateFormatter` can parse dates that don't exactly match the format.
For example, it can parse the following dates with this format `yyyy-MM-dd`:

```
0013-03-19
2013-03-19
13-Mar-19
13-March-19
13-03-19
... [Log Snipped] ...
0013-Mar-19
13-Mar-00019
```

Any of those dates are considered a valid date for that format by the intl formatter. So, I'm not sure whether it is a correct approach for validating dates format or not.

Alternatively, php date format is more restrictive and works better for validation.

So, @hirenbhut93 in your case it's better to use php format (if you use dates in English only):

```php
['approval_date', 'date', 'timestampAttribute' => 'approval_date', 'timestampAttributeFormat' => 'php:Y-m-d'],

```
Although two digit year also still be valid in this case (`13-03-19`).

For strict date format validation, I have one idea that we can implement. Maybe add `$strictDateFormat` property to the `\yii\validators\DateValidator` and then add the following code after date parsing [URL]
```php
if ($this->strictDateFormat) {
    $checkDate = $formatter->format($parsedDate);
    if ($checkDate !== $value) {
        return false;
    }
}
```
It will format the parsed timestamp back to the specified format and check whether formated date exactly match the original value, in this case for the list of dates above only such dates `0013-03-19` , `0113-03-19`, `2013-03-19` will pass validation. What do you think?
