Title

GLFWvidmode refreshRate contains a truncated integer (on Linux)

Description
I used `const GLFWvidmode* mode = glfwGetVideoMode(monitor);` to get at the [Link: refreshRate]. This is an integer value in Hz. I observed a value of 59 on my linux machine. The actual refresh rate though is 59.97 as determined by `xrandr`. 

* The integer should be rounded to 60 I think.
* IMO It would be more useful to make the refreshRate value frames/ms no frames/s.
Discussion
- Good point, rounding is a better approach than truncation here.

I agree that the refresh rate shouldn't be integer Hz. It will be addressed in the next API revision, see #230.
- By a stroke of luck this affected only platforms where we can use C99. Fixed with `round` in  .
