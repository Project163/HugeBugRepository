Title

CBO wrongly type cast decimal literal to int

Description
explain   select  100.000BD  from  f 
  
  
 STAGE PLANS:
  Stage: Stage-0
    Fetch Operator
      limit: -1
      Processor Tree:
        TableScan
          alias: f
          Select Operator
            expressions: 100 (type: int)
            outputColumnNames: _col0
            ListSink
 
  

 Notice that the expression 100.000BD is of type int instead of decimal.
Discussion
- This happens due to RexBuilder::makeExactLiteral (in calcite) creating Integer/BigInteger if scale happens to be zero. Hive probably need to create the type own its own and pass it to makeExactLiteral to preserve the type.
