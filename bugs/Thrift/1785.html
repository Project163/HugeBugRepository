Title

Thrift.cabal filename does not match module name

Description
Some haskell environments, including stack ( [URL] require that the cabal file name match the module name (case sensitive). This means that it is difficult to import the (git source repository) thrift library into stack projects ( [URL] The fix is easy: change the name "Thrift.cabal" to "thrift.cabal."
