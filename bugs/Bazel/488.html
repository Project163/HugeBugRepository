Title

select() in rule attribute used in output causes exception

Description
Hello,

I have a custom rule set up as follows:

the_rule = rule(
    implementation = _the_rule_impl,
    attrs = {
        "json_prms": attr.label(allow_files = True, mandatory = True, single_file = True),
        "file_name": attr.string(mandatory = True),
    },
    outputs = {
        "out": "%{file_name}",
    }
)

Now, when invoking:

the_rule(
    name = "run_my_rule",
    .....
    file_name = select({
        ":darwin_x86_64": "osx.source",
        "//conditions:default": "common.source"
    }),
    .....
)
