Title

Mounted filesystem doesn't get updated

Description
Mounting is working perfectly, but the content doesn't get updated, easy to reproduce:
rclone mkdir gdrive:test
rclone copy test1 gdrive:test/
rclone mount gdrive: mnt
cd mnt/test
ls -l test1 # <- this gives a correct result
rclone copy test2 gdrive:test/
ls -l test2 # <- no such file (even after waiting for over an hour)

I can understand that the meta-information is cached, but there should be a timeout for this; maybe something in the range of about 10-15 minutes.
