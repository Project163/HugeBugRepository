Title

Skylark aspects can give rise to IllegalStateException

Description
[URL]

This line throws when two aspects provide the same provider, and the set of providers provided is controllable form Skylark. We also raise the same exception when merging native aspects, which can also be a problem (I'm not sure if we can create native providers from Skylark)
