Title

PHP extension segfaults if reference is used in input

Description
When reference is passed to php extension, it's unreferenced (instead of derefrenced). The next time one tries to use the same variable PHP segaults. Even if not used again, php segfaults on user_shutdown_function_call. 

 Example: 

 Thrift 
  
 
namespace php tt.demo

struct SumInput {
    1: required list<i64> numbers;
}

service DemoService {
    i64 sum(1: SumInput input)
}
 
  
 PHP client: 
  
 
 // Create HTTP Transport
 $transport =  new  \Thrift\Transport\TNullTransport();

 // binary protocol
 $protocol =  new  \Thrift\Protocol\TBinaryProtocolAccelerated($transport,  true ,  true );

 // create a client
 $client =  new  \tt\demo\DemoServiceClient($protocol);

 // at  this  point, client is ready, and we can make RPC calls:
 $numbers = [];
$input =  new  \tt\demo\SumInput();
$input->numbers = &$numbers;

debug_zval_dump($input);

$client->send_sum($input);  // used by sum()
 
$input->numbers = &$numbers;
debug_zval_dump($input);

$client->send_sum($input);  // used by sum()
 var_dump( 'never reached' );
