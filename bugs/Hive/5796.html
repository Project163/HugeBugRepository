Title

ANALYZE TABLE...COMPUTE STATISTICS FOR COLUMNS command shows computed stats for masked tables

Description
As  ANALYZE TABLE...COMPUTE STATISTICS FOR COLUMNS  is rewritten internally as a  SELECT  query, there is an interaction between the rewriting to mask the columns/rows interacts and the ColumnStatsSemanticAnalyzer rewriting that leads to showing the computed stats after running the command.
