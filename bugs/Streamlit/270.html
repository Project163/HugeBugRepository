Title

use_container_width=True not working for Altair facet charts

Description
### Checklist

### Summary

I'm trying to use facet charts and have them sized to fill the container. However, the charts do not get the right width when supplying `use_container_width=True`. I see two different ways they get sized, depending on how the facet is created, however neither makes the chart the width of the container.

See related #4121 which I think should have fixed  #3814 and #2023 (I'm not sure if there has been a regression).
