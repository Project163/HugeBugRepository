Title

Sync hangs with --track-renames and --track-renames-strategy "modtime" flags and correct deletions/transfers are not performed

Description
#### What is the problem you are having with rclone?

When using the --track-renames and --track-renames-strategy "modtime" flags, the checker is skipping many files and is not performing the correct transfers and deletions. See below (note, the 1534 transfers and 2150 deletions are correct and should be performed):

without --track-renames --track-renames-strategy "modtime":

```
root@nas:~# rclone sync "/mnt/user/test" "crypt:current/test" --progress --fast-list --max-backlog 10000000 --transfers 3 --tpslimit 3 --checkers 16 --dry-run --log-file "/mnt/user/scripts/rclone/logs/testing.txt" -vv
Transferred:             0 / 0 Bytes, -, 0 Bytes/s, ETA -
Checks:              4820 / 4820, 100%
Deleted:             2150
Transferred:         1534 / 1534, 100%
Elapsed time:         0.6s
```

with --track-renames --track-renames-strategy "modtime":

```
rclone sync "/mnt/user/test" "crypt:current/test" --progress --fast-list --max-backlog 10000000 --transfers 3 --tpslimit 3 --checkers 16 --log-file "/mnt/user/scripts/rclone/logs/testing.txt" -vv --dry-run --
track-renames --track-renames-strategy "modtime"
Transferred:             0 / 0 Bytes, -, 0 Bytes/s, ETA -
Checks:              2684 / 2684, 100%
Transferred:           11 / 11, 100%
Elapsed time:         0.4s
```

Also, the sync process is hanging at this point - the last log line is:

`2020/07/11 12:22:40 DEBUG : Encrypted drive 'crypt:current/test': Waiting for renames to finish`
