Title

glfwPollEvents aborts program (BadWindow/X_TranslateCoords)

Description
Release 3.3.1 throws the following error from `glfwPollEvents()` on my wayland+sway system:

```
X Error of failed request:  BadWindow (invalid Window parameter)
  Major opcode of failed request:  40 (X_TranslateCoords)
  Resource id in failed request:  0x0
  Serial number of failed request:  132
  Current serial number in output stream:  132
```

I've narrowed down the problem to commit fe57e3c (2020-01-01).  The previous commit, 6b01aff (2020-01-01), works fine.  Both commits work okay under gnome3 though.

I read [Link: somewhere] that this problem might be related to running a tiling window manager with no window decorations, but I tested both with and without window decorations and in my case fe57e3c doesn't work either way.  

Here's my test code:

```
c

    glfwTerminate();
}
```

Note that `error_callback` isn't invoked, and `glfwPollEvent()` doesn't return; the program just aborts.
