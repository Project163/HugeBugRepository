Title

serve ftp doesn't appear to be closing file handles.

Description
I've watched my system run out of open files every few hours since I started using serve ftp.  I check and Just see the open files rises with each incoming file until it dies.

```
cd /proc
for pid in [0-9]*; do     echo "PID = $pid with $(ls /proc/$pid/fd/ | wc -l) file descriptors"; done | sort -rn -k5 | head | while read -r _ _ pid _ fdcount _; do   command=$(ps -o cmd -p "$pid" -hc);   printf "pid = %5d with %4d fds: %s\n" "$pid" "$fdcount" "$command"; done

root@cloudc:/data/bin# ./fds
pid =  2031 with  149 fds: rclone
 
```
