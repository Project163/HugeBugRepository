Title

site_url trims trailing slash

Description
`site_url` trims slashes on the left and right side of the URI passed.  There are cases where I need my relative URLs to keep their slashes on the right, e.g.

```
/segment/case/read/
```

If you pass the above string into `site_url`, it will remove the `/` on the right side, like so:

```
site_url('/segment/case/read/'); // [URL]
```

The desired output should be:

```
[URL]
```

I utilize the `redirect` function for redirects, but if you pass a relative URL it will use `site_url` to prepend your configured URL which affects the relative URL passed.  I have apache configured to force trailing slashes in every request.  If I'm using `redirect` to redirect to a relative URL, apache will force a rewrite and produce a 2nd redirect (303/307 from CI then 301 from apache) which is not the desired output.

`site_url` should only trim the left trailing slash.
Discussion
