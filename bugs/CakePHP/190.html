Title

Failing TableTest after Model baking

Description
By default, when baking a Model, the test files for both the Entity and Table classes are baked along with it. Although, the generated tests for the Table class fail by default:

Only the `setUp()` and `tearDown()` methods are baked into the test file, but nothing else, causing the test to fail immediately after baking.

Since the Table objects by default come with a `initialize()` and `validationDefault()` method, I'm wondering why there are no "dummy" tests for that like for Controller tests? Something like:

``` php
public function testValidationDefault() {
    $this->markTestIncomplete('testValidationDefault not implemented.');
}
```

This would be sufficient to not have the tests fail, but just throw a "OK, but incomplete, skipped, or risky tests!" warning instead.
