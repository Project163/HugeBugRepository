Title

JWT is being processed when permit policy is set

Description
**Describe the bug**
JWT token is processed even if http policy is set to permit.

**Expected behavior**
I expect to see 200 (OK) response with metrics payload.

**Actual behavior**
I see 401 (Unauthorized) response.

**To Reproduce**
1) Define the following in microprofile-config.properties:
     ```
     quarkus.http.auth.permission.metrics.policy=permit
     quarkus.http.auth.permission.metrics.methods=GET
     quarkus.http.auth.permission.metrics.paths=/metrics
     ```

2) Execute the following:
 ` curl --request GET --url [URL] --header 'authorization: Bearer invalid' -v
`
3) Observe 401 (Unathorised response) and error in logs (Token is invalid: JWT processing failed. etc.)

**Environment (please complete the following information):**
 - Output of `uname -a` or `ver`: Windows 7
 - Output of `java -version`:  openjdk version "11.0.2" 2019-01-15
 - Quarkus version or git rev: 1.0.1.Final
