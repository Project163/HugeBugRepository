Title

Editor cannot load .ifc files anymore

Description
**Describe the bug**

The IFCLoader in the three.js editor is broken. It is not possible to load .ifc files in the three.js editor anymore.

I am pretty sure this got introduced with PR #21683, as the issue looks like the web-ifc WASM file is not correctly loaded (or maybe it is not even served on a web server at all). Am I right, @agviegas ?

As I know somebody will ask eventually, the file I used is the one of the IFCLoader example (rac_advanced_sample_project.ifc), but I am confident the issue is the same for any .ifc file.

**To Reproduce**

Steps to reproduce the behavior:
1. Open the three.js editor
2. Drag and drop an .ifc file
3. See error

**Expected behavior**

The loaded .ifc file displays in the three.js editor.
