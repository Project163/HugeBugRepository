Title

Bug: Export crashes when any of the meshes contains texture coordinate names

Description
**Describe the bug**
Export crashes when any of the meshes contains texture coordinate names. `SceneCombiner::CopyScene` doesn't handle this value, so the copied instance refers to the same memory area as the original one.

**To Reproduce**
```
cpp
TEST_F(utScene, deepCopyTest) {
    scene->mRootNode = new aiNode();
    
    scene->mNumMeshes = 1;
... [Log Snipped] ...
    }
}
```
