Title

 INSERT INTO comparator_cf_decimal (id, 15.333) VALUES ('test', 'test')

- FYI, this is the only Type that does this, every other type appears to function properly including Float and Double
- This occurs because the  compose  method in  DecimalType  does not protect itself  by checking for an empty  ByteBuffer  argument which is what occurs if a single item is in the CF.
