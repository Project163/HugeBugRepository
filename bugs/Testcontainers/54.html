### What happened?

I wanted to use function `getContainerByServiceName` to obtain `ContainerState` for further processing. The function mentioned earlier accepts the parameter called `serviceName`. The very same parameter name is used for e.g. `getServicePort` function. The name I used for the service was without any `_[0-9]+` suffix. For `getServicePort` it worked just fine: I got my desired port number, however, for `getContainerByServiceName` I was getting an empty `Option`. After a quick investigation, it turned out that for `getContainerByServiceName` I need to provide `_1` suffix. 

Desired behaviour:

- reuse the internal code that was checking if the name is with suffix also for `getContainerByServiceName` (I've seen in sources you have such logic somewhere for `getServicePort`) and appending it if it is missing, or...
- if it is intended, maybe the Javadoc for that function should be updated to warn users about that pitfall
