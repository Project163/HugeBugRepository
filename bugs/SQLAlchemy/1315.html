Title

TypeDecorator around Array

Description
### Describe the use case

Hello, with the following snippet

```
python
from sqlalchemy import Column, DateTime, ForeignKey, Integer, String, Table, TypeDecorator, create_engine, func
from sqlalchemy.dialects import postgresql
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import backref, contains_eager, joinedload, relationship, sessionmaker
... [Log Snipped] ...
session.flush()
print(session.query(Item.content[0]).all())
```

I have this error

```
raise NotImplementedError(NotImplementedError: Operator 'getitem' is not supported on this expression
```

The only thing that seems to work is making SkipsFirst subclass INDEXABLE.

```python
class SkipsFirst(TypeDecorator, INDEXABLE):
  ...
```

This doesn't seem to be coherent with the `TypeDecorator` philosophy. So I don't know if there is a canonical way to still have all the feature of `postgresql.ARRAY`.

### Databases / Backends / Drivers targeted

PostgreSQL in this case but all databases could be concerned.

Discussion
- so our choices here are:

1. do nothing, and just document that TD around ARRAY needs to be Indexable
2. have TypeDecorator subclass Indexable or some super-interface for that, precedent here is the SchemaEventTarget superclass
3. have TypeDecorator implement ``__getitem__()`` and proxy it separately from Indexable, see that TypeDecorator doesn't subclass Concatenable either but that seems to work (lets make sure that works)

option 3 is likely most appropriate.
