Title

SpdyHttpDecoder fails to decode SpdyFrame to HttpRequest

Description
Netty Version: 5.0.0.Alpha3-SNAPSHOT (latest master)

Issue:
When the `SpdyHttpDecoder` attempts to decode a SPDY Frame into a `FullHttpRequest` a `NullPointerException` is thrown on [Link: this line].  

The reason is that the call to `headers.getAndConvert(METHOD)` returns `null`. `headers` _does_ contain the `:method` pseudo-header, the problem is that `METHOD` is `AsciiString`, but `headers` is looking for a key of type `String`.  If you call `headers.getAndConvert(METHOD.toString())` the lookup succeeds.
