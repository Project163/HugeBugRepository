Title

SemanticException when querying VIEW with DISTINCT clause

Description
Consider the following view "vw_t1" over table "t1". 
  
 
 create   table  t1 (username  string );
 create   view  vw_t1  as   select   distinct  username  from  t1;
 
  
 When authorization is enabled querying the view fails at compile time with a SemanticException. 
  
 
 set  hive. security . authorization .enabled= true ;
 select  *  from  vw_t1;
