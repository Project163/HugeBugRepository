Title

Missing Internal Base Class Dependency

Description
Classes that are extended, but not exported are not included in the output.

``` js
// base.js

export class Base {
  foo() {
    return true;
  }
}
```

```
js
// thing.js

import { Base } from './base'

... [Log Snipped] ...
  }
}
```

``` js
// main.js

export { Thing } from './thing'
```

```
class Thing extends Base {
  bar() {
    return true;
  }
}

export { Thing };
```

My current work around is to explicitly export the base class in the main module. 

I just want es6 module aware concatenation, but this tree shaking is spooking me. 👻  😦
