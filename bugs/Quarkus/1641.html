Title

SecurityConstrainer may cause BlockingOperationNotAllowedException

Description
### Describe the bug

Setup: `resteasy-reactive`, `security`, proactive authentication is **disabled** (`quarkus.http.auth.proactive=false`)

A `BlockingOperationNotAllowedException` is thrown when a resource method is annotated with `@RolesAllowed` and `@NonBlocking` and the method does not return an async type (`Uni `).

It seems that permissions defined via config in `application.properties` work just fine.

### Expected behavior

The build should fail with a more informative error message.

### Actual behavior

An HTTP request fails at runtime.

### How to Reproduce?

1. Checkout [URL]
2. Run `mvn quarkus:dev` in the `security-jpa-quickstart`
3. HTTP GET `[URL]
