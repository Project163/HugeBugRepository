Title

[YSQL] Fix flaky test PgIndexBackfillTest.InsertsWhileCreatingIndexDisableWait

Description
Jira Link: [Link: DB-6626]
### Description

C++ test PgIndexBackfillTest.InsertsWhileCreatingIndexDisableWait of pg_index_backfill-test.cc has been flaky since introduced.  Errors are all like

```
../../src/yb/yql/pgwrapper/pg_index_backfill-test.cc:630
Failed
Bad status: Illegal state (yb/yql/pgwrapper/pg_index_backfill-test.cc:581): row count should mismatch: 402 vs 402
```

Jenkins failures:

```
alma8-master-clang15-asan 	8
alma8-master-clang15-release 	24
alma8-master-clang15-release-aarch64 	15
alma8-master-clang16-debug-aarch64 	1
alma8-master-gcc11-fastdebug 	16
centos-master-clang16-debug 	1
mac11-master-clang-release-x86 	7
```

Notice release build is the most flaky, followed by fastdebug.  This makes sense because the test tries to create/expect corruption, which is more likely to happen on slower binaries.
