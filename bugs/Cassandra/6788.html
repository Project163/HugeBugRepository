Title

The property cassandra.streaming.session.parallelTransfers is partly ignored

Description
The property is ignored when it comes to create the semaphore used to control the streaming slots used, where it is always created using the default size. 

 On the other hand, the netty pool for the transfers is sized accordingly if the property is defined. 

 The fix is a trivial one-line change in  StreamingMultiplexedChannel.java  ( v4.1+) or  NettyStreamingMessageSender.java  ( v4.0 ) where the semaphore size has to be changed from  DEFAULT_MAX_PARALLEL_TRANSFERS  to  MAX_PARALLEL_TRANSFERS
