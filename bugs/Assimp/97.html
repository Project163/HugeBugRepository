Title

Bug: Out-of-bounds Write in Assimp::CSMImporter::InternReadFile

Description
### Summary

Out-of-bounds Write in `Assimp::CSMImporter::InternReadFile`. An attacker could potentially exploit the vulnerability to cause a remote code execution, if they can trick the victim into running assimp on a malformed CSM file.

### Affected

assimp>=5.4.3

### Details

In `code/AssetLib/CSM/CSMLoader.cpp:218`, user can write to arbitrary address with arbitrary data.

```cpp
aiVectorKey* sub = s->mPositionKeys + s->mNumPositionKeys;
sub->mTime = (double)frame;
```

```
bash
gdb-peda$ p *sub
Cannot access memory at address 0x0
gdb-peda$ p *s
$1 = {
... [Log Snipped] ...
  mPostState = aiAnimBehaviour_DEFAULT
}
```
