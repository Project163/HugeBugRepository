Title

unregister method is not working for fields registered with register method

Description
**Describe the bug**
When you have a component that build a set of filters, you can use the methods register and unregister to add and remove filters at will. When the user submits, you should get a object containing the fields that were registered and not unregistered. 

In the latest version of the lib (6.6.0 at the time of writing), the unregister function is ignored/not working.

**To Reproduce**
Steps to reproduce the behavior:

1. Go to the code sandbox here: [URL]
2. Click multiple times on the button add. For each add click, a console log will be outputed with the action made
3. Click submit to see the current form object. Check that all values are there
4. Click on remove one or more times
5. Click submit and you will se the object exactly as it is in the point 3. At least, the object at this point should not contain the fields called with the unregister method.

**Codesandbox link (Required)**
[URL]

**Expected behavior**
When you call the unregister method, you should not see the unregistered fields on form submit .
