Title

Incorrect fold behavior with :move and foldexpr

Description
### Neovim version (nvim -v)

v0.8.0-dev+260-gb3453ea4a

### Vim (not Nvim) behaves the same?

No, Vim 8.2.4987

### Operating system/version

Arch Linux

### Terminal name/version

kitty 0.25.0

### $TERM environment variable

xterm-kitty

### Installation

build from repo

### How to reproduce the issue

1. Run `nvim --clean`
2. Source the following file:
```
vim
set foldmethod=expr foldexpr=indent(v:lnum)

let content = ['', '', 'Line1', '  Line2', '  Line3',
      \ 'Line4', '  Line5', '  Line6',
... [Log Snipped] ...
move 2
move 1
```

### Expected behavior

The empty line at the bottom is not included in the last fold

This is Vim's behavior or Nvim's behavior with `foldmethod=indent shiftwidth=2`

[Image: Expected]

### Actual behavior

The empty line at the bottom is included in the last fold

[Image: Actual]
