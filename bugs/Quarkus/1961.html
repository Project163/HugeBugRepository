Title

Quarkus 3 native image fail to start with NoSuchMethod Exception

Description
### Describe the bug

I have a Quarkus application with hibernate orm and flyway.
I use Discriminator Multitenancy with `@TenandId` annotation and use:
`
    @TenantId
    @Column(name = TENANT_ID_SQL_NAME, length = 40, nullable = false)
    public String tenantId;
`

When I run the app in dev mode , all works fine.
When I build a native image and use it in a container the app does not start:
