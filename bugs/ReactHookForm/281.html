Title

Field using `setValueAs` deemed dirty even though no user interaction has changed it

Description
**Describe the bug**
I'm using `setValueAs` in combination with ` ` in order to use `Date` objects both in and out of my forms.

When focusing and subsequently blurring such an input, it is incorrectly marked as "dirty".
This may be due to [Link: updateTouchAndDirtyState] using `inputValue` directly instead of using `getFieldValueAs` on the value.

**To Reproduce**
Steps to reproduce the behavior:

1. Go to '[URL]
2. Click on 'Submit' and look in the console. Verify that both `touched` and `dirty` are empty - as they should be.
3. Focus the input field and blur it without making any changes to it
4. Click on 'Submit' and look in the console. Now the input is shown as both `touched` and `dirty` - even though it's only been touched.

**Codesandbox link (Required)**
[URL]

**Expected behavior**
The input should only be marked as dirty when the user has actually changed the field
