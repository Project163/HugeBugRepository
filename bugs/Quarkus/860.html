Discussion
- I will change my projects to use JSON-B implementation instead of Jackson.
- I found another classpath issue.

When I am using `keycloak-admin-client` likes this:

```xml
         
             org.keycloak 
             keycloak-admin-client 
         
```

I need to downgrade a dependency - by declaring it in my pom.xml - to the same version used in 1.8.3.Final version of Quarkus:

```xml
         
             org.jboss.resteasy 
             resteasy-jackson2-provider 
             4.5.6.Final 
         
```
However, I've got this error:

```
java.lang.NoSuchMethodError: 'com.google.common.base.Equivalence com.github.fge.jackson.JsonNumEquals.getInstance()'
```
because `keycloak-admin-client` rely on jackson and it clashes with the version of `json-schema-validator`

The main change is the dependency of  `json-patch` given by the version of `resteasy-jackson2-provider`.
- The issue is an incompatibility of `jackson-coreutils` versions. It got upgraded in RESTEasy and `com.github.java-json-tools:json-schema-core` doesn't support this upgrade.

I fixed it by adding the following to your project:
```
         com.github.java-json-tools 
	     json-schema-validator 
	     2.2.14 
	 
```
