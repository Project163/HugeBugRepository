Title

RBAC item inserts NULL name in MSSQL

Description
### What steps will reproduce the problem?

1. Configure `authManager` with `DbManager`
2. Create a Role/Permission
```
$auth = Yii::$app->authManager;
$admin = $auth->createRole('admin');
$auth->add($admin);
```

### What is the expected result?
A new RBAC item created

### What do you get instead?
```
Exception 'yii\db\Exception' with message 'SQLSTATE[07002]: [Microsoft][ODBC Driver 17 for SQL Server]COUNT field incorrect or syntax error
The SQL being executed was: INSERT INTO [auth_item] ([name], [type], [description], [rule_name], [data], [created_at], [updated_at]) VALUES (NULL, 1, NULL, NULL, CONVERT(VARBINARY, NULL), 1538179185, 1538179185)'

in /var/www/html/app/vendor/yiisoft/yii2/db/Schema.php:664

... [Log Snipped] ...
    [2] => [Microsoft][ODBC Driver 17 for SQL Server]COUNT field incorrect or syntax error
)
```
