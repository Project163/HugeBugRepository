Discussion
- The error message says  
 
 'spark-submit2.cmd' is not recognized as an internal or external command, 
operable program or batch file.  

 The execution sequence when launching pyspark on Windows is like this: 

  
 pyspark.cmd
-> pyspark2.cmd
-> spark-submit2.cmd (*1)
-> spark-class2.cmd
-> python.exe with PYTHONSTARTUP
-> python\pyspark\spark.shell.py
-> (...)
-> java_gateway.py
-> spark-submit.cmd
-> spark-submit2.cmd (*2)
 
  

 And the error message is not about (*1), but (*2). 

 The root cause of this problem is that spark-submit.cmd cannot find spark-submit2.cmd (*2).
