Title

[get/get-helm-3] runAsRoot is broken if arguments contains spaces

Description
Currently the `get-helm-3`-script fails if `HELM_INSTALL_DIR` contains spaces, this is due to an issue in the `runAsRoot` function, not wrapping the command properly.

Reproduce: Run `get-helm-3` with a `HELM_INSTALL_DIR` containing at least one space
