Title

camelcase lint error on module import when deconstructing

Description
**ESLint version:** 

3.1.1

---

**Rule:** 

`"camelcase": [2, { "properties": "never" }]` 

---

**Problem**

Lint fails on module import when deconstructing  properties and aliasing.

``` javascript
// this cause lint error
import { no_camel_case_prop as CamelCaseProp } from 'external-module';
```

But with   that rule should ignore camelcase during deconstructing.

_(I know that import deconstructing is not a real object deconstructing, but probably it should follow the same rule)_

For now I have to workaround this issue this way:

``` javascript
// this not cause lint error
import * as externalModule from 'external-module';
externalModule.no_camel_case_prop
```

---

Thank you :)
Discussion
- Hi @lordgiotto, thanks for reaching out!

Just verified that this is true. Even without the `properties` option set to `never`, I would expect the example code to not cause a lint error, for the same reasons outlined in [URL] for object destructuring.

So, to recap:

**Valid**:

``` javascript
/* eslint camelcase: 2*/
import { no_camel_case_prop as CamelCaseProp } from 'external-module';
```

**Invalid**:

``` javascript
/* eslint camelcase: 2*/
import { no_camel_case_prop } from 'external-module';
```

**Invalid**:

``` javascript
/* eslint camelcase: 2*/
import { no_camel_case_prop as no_camel_case_prop } from 'external-module';
```
