Title

Kafka reactive messaging extension incompatible with Micrometer Prometheus extension for Quarkus 3.7.*

Description
### Describe the bug

The error occurs when an incomming channel expects an io.smallrye.reactive.messaging.kafka.IncomingKafkaRecord class, it will then fail when processing the event with a ClassCastException.
The error only occurs with Quarkus 3.7.*, but not with 3.6.9 and it only occurs if the following extension is added to the pom.xml file:
     
       io.quarkus 
       quarkus-micrometer-registry-prometheus 
     

### Expected behavior

I would expect to be able to consume messages using the IncomingKafkaRecord interface as it worked before.
