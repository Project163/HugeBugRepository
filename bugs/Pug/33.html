Title

Cache overrides empty string

Description
So if you pass jade an empty string to render, and also pass it a `filename` in the options, rather than returning an empty string as you would expect, it reads the file and returns the file's contents. For example:

``` js
console.log(jade.render('', { filename: 'some_file_path' }));
```

This will log out the contents of the file at the path, rather than an empty string. Any content at all in the string will negate this:

``` js
console.log(jade.render('p hello', { filename: 'some_file_path' }));
```

This renders the correct string, regardless of whether that's actually the contents of the file, as you'd expect.
