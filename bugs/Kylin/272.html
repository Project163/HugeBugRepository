Title

The time range of logs included in the job diagnostic package is incomplete

Description
task started executing at 13:40, and the start time of schedule.log and kylin.log are both at 13:49, with no previous logs. 
  2022-09-21T13:54:52,089 INFO  [main]  diag : Extract kylin log from 2022-09-21T13:49:00 to 2022-09-21T13:52:33 .
Discussion
- Root Cause 

 The reason for the lack of task creation logs is the addition of TraceID to the logs, which makes it impossible for the canonical rules to get the time of the task creation logs. 

     
    
 Fix Design 

 At the interval of generating task diagnostic package, add a regular rule which can be adapted to traceId. 

 The generated regular, for example, jobId is d0f45b72-db2f-407b-9d6f-7cfe6f6624e8. 
   Before 
   ( [0-9] {4}  [0-9] {2}  [0-9] {2}T [0-9] {2}: [0-9] {2}: [0-9] {2})(.  JobWorker.*jobid:d0f45b72. )| ( [0-9] {4}  [0-9] {2}  [0-9] {2}T [0-9] {2}: [0-9] {2}: [0-9] {2}). *d0f45b72-db2f-407b-9d6f-7cfe6f6624e8  
    
 After 
   ( [0-9] {4}  [0-9] {2}  [0-9] {2}T [0-9] {2}: [0-9] {2}: [0-9] {2}) (.  JobWorker.*jobid:d0f45b72. )| (traceId: ( [0-9a-z] {8}  [0-9a-z] {4}  [0-9a-z] {4}  [0-9a-z] {4}  [0-9a-z] {12}) )? ( [0-9] {4}  [0-9] {2}  [0-9] {2}T [0-9] {2}: [0-9] {2}: [0-9] {2}). *d0f45b72-db2f-407b-9d6f-7cfe6f6624e8
