Title

OBJLoader not loading/naming correctly

Description
I have an OBJ file with a cube in it where every wall is a named (north, east, south, west, top, bottom). When I open the file in blender, everything is as expected, when I open the file in text editor, there are no noticeable discrepancies between walls, but when I load it with OBJLoader, the file has all the sides (well, at least their naming...) completely mixed up.

South is missing (has no children attached to it, therefore mesh cannot be accessed), walls go in order (turning to the right) east, floor, east, north; top is west and bottom is ceiling.

I suspect an issue with OBJLoader, but when I experimented around with it I couldn't find anything standing out.
