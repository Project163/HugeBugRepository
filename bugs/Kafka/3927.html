- I found two issues in the flaky tests: 
 
	 The local state is purged imediately after kafkaStreams.close() timeout (Current timeout = 5 sec). But the asynchronize close thread still trigger RocksDBStore.flush() to write to local state dir. This is the root cause of the  flaky test  that occured on Sep 10 2024 16:55:51 CST. ( Code Link ) 
	 Some partition tasks assigned to first kafkaStream(ks-1), are reassigned to second KafkaStream(ks-2) after rebalancing. However, the reassigned tasks are not started in ks-1 yet, so it’s won’t enter the suspend state. This is the root cause of the  flak test  that occured on Sep 10 2024 11:44:34 CST. ( Code Link )
