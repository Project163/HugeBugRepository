Title

dotnet-xunit: Cannot specify namespace parameter more than once

Description
The dotnet-xunit command line help documentation says:

-namespace "name"      : run all methods in a given namespace (i.e.,
                         : 'MyNamespace.MySubNamespace')
                         : if specified more than once, acts as an OR operation

When I run the command: `dotnet xunit -namespace "Namespace1" -namespace "Namespace2"` I receive the following error.

An item with the same key has already been added. Key: -namespace

Expected behaviour: Tests in both namespaces are executed successfully.
Discussion
- Version 2.3.0-beta1-build3642 - in case a new build drops.
