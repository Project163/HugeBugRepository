Title

Requiring backtick quotes must provide exception for ES modules

Description
Version: v1.0.0-rc-1
Rule: "quotes": [2, "backtick"]

If I require backticks as my quote style, ESLint complains when I use single or double quotes for imports, like so:

``` js
import foo from 'foo.js';
```

However, you can't use backticks to reference imported modules (it isn't valid).
