Title

Multiple windows example panics when closing one of the windows

Description
* Bevy version:   (main as of today)
* Linux/X11

## What you did

* Run the `multiple_windows` example with `cargo run --example multiple_windows`.

## What went wrong

Closing a window results in a panic with the following error:
```

```
