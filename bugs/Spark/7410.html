Discussion
- Stumbled upon the same issue, upon initial investigation looks like change in behaviour in java.lang.DateTimeFormatterBuilder. 
Literal character 'F' currently maps to ChronoField.ALIGNED_DAY_OF_WEEK_IN_MONTH instead of ChronoField.ALIGNED_WEEK_OF_MONTH 

 According to ALIGNED_DAY_OF_WEEK_IN_MONTH definition it formats the timestamp to give the count of the date within that week. Defintion -  [URL]

 Tried the same snippet in Spark 2.4.6, and it's behaviour was inline with the spark documentation. This looks like a regression for Spark 3.x.
