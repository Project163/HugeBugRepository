Title

WadlGenerator does not respect Consumes annotation for form requests

Description
WadlGenerator  invokes  handleRepresentation  with the wrong parameter when creating the  <request>  element.  The last parameter of  handleRepresentation  should be  true  not  false : 
  
   if  (ori.getMethodToInvoke().getParameterTypes().length != 0) {
            sb.append( "<request>" );
             if  (isFormRequest(ori)) {
                handleRepresentation(sb, jaxbTypes, qnameResolver, clsMap, ori,  null ,  false );
            }  else  {
                 for  (Parameter p : ori.getParameters()) {        
                    handleParameter(sb, jaxbTypes, qnameResolver, clsMap, ori, p);             
                }
            }
            sb.append( "</request>" );
 }

That last parameter determines if the representation is for  inbound  communication.  In this case I believe it should be  true  not  false .
