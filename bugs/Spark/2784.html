Title

Speculation Tasks Cause ProgressBar UI Overflow

Description
When there are speculative tasks in stage, the started tasks + completed tasks can be greater than total number of tasks. It leads to the started progress block to overflow to next line. Visually the light blue progress block becomes no longer visible when it happens. 

 The fix should be as trivial as to cap the number of started task by total - completed task.
