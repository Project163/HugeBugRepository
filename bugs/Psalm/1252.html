Title

UndefinedVariable for variable set in by-ref that should be PossiblyUndefinedVariable

Description
Might be i am wrong but i just started to use this tool. 
My problem is this tool set an undefined error e.g.: like this:
```
        if ($someCondition) {
            $command = 'some cli command';
            exec($command, $output, $returnVal);
        }

        if (!isset($returnVal) || $returnVal) {
            throw new RuntimeException('some msg');
        }
```
The error is:
```
ERROR: UndefinedVariable - src/test.php:10:20 - Cannot find referenced variable $returnVal (see [URL]
        if (!isset($returnVal) || $returnVal) {
```
I think this is a false error as the if condition already checks the variable(`isset`).
So The `$returnVal` would exist if the exec was running(`!isset($returnVal)` > the exec was not running) 
if it was running `!isset($returnVal)` would be false so the other part of the condition will be executed and check its value.
the `if` condition processes left to right in case of `or` when the condition becomes false it will quit so in this case the second condition will never run so it is safe.
