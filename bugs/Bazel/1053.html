Title

TMP: Cannot create temp files in Java binaries in actions

Description
For one reason or other, `File#createTempFile()` tries to create the file in `C:\WINDOWS`, which of course fails with an access denied error.

This choice of default behavior in Java is questionable and it probably works because the `TEMP` environment variable is usually set. Except in Bazel actions.
Discussion
- GetTempPath on WIndows looks at:

1. The path specified by the TMP environment variable.
2. The path specified by the TEMP environment variable.
3. The path specified by the USERPROFILE environment variable.
4. The Windows directory.

[URL]

Looks like we need to provide one of those to actions
- Closing because actions now always have a temp directory.
