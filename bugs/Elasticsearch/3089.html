Title

[Script fields] Using script fields to get the second value of an array in a document may get the value in the previous document.

Description
### Elasticsearch Version

elasticsearch8.11

### Installed Plugins

_No response_

### Java Version

_bundled_

### OS Version

centos7

### Problem Description

When all test documents are in the same segment, using script fields to get the second value of an array in a document,
the previous doc has a field named domain_id with value [1, 8], the next doc has the field which has the value [1]
when use
```
"script_fields": {
	"val": {
		"script": {
			"source": "doc.domain_id.values[1]",
			"lang": "painless"
		}
	}
}
```
to get domain_id's second value, the result is 8,8, but 8,0 is right.

### Steps to Reproduce

1、create an index as follows
```
PUT localhost:9200/test
{
	"settings": {
		"refresh_interval": "120s",#ensure all documents is written to the same segment "number_of_shards": 1,
		"number_of_replicas": 0
... [Log Snipped] ...
	}
}
```
2、write some data
```
PUT localhost:9200/_bulk
{ "index" : { "_index" : "test", "_type": "arrays", "_id": 1}}
{"domain_id":[1]}
{ "index" : { "_index" : "test", "_type": "arrays", "_id": 2}}
{"domain_id":[1]}
... [Log Snipped] ...
{ "index" : { "_index" : "test", "_type": "arrays", "_id": 9}}
{"domain_id":[1]}
```

3、execute the query
```
GET localhost:9200/test/_search
{
	"_source": "domain_id",
	"script_fields": {
		"val": {
... [Log Snipped] ...
	}
}
```

4、the result is wrong
```
{
	"took": 105,
	{
		"_index": "test3",
		"_type": "arrays",
... [Log Snipped] ...
	}
}
```
.....
the result in the last hit should be 0,but 8,we think it uses the previous hit result.
