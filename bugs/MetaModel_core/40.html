Title

Excel (xls format) table's have a null TableType

Description
When using MetaModel to read xls files, the tables (representing sheets) come out with a null TableType. It should be TableType.TABLE. 

 This is particularly annoying since MM 5.0.0 since we now also have the VIEW types in there if there is a default table.
