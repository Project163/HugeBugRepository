Title

Baking plugins doesn't handle paths properly

Description
I've just encountered an issue with baking plugins.  When lots of plugin paths are present, lots of invalid plugin paths are presented to the user when baking a new plugin, and some valid paths are not shown.

The problem is this snippet inside the findPath function in /lib/Cake/Console/Command/Task/PluginTask.php:

```
    foreach ($pathOptions as $i => $path) {
        if (!is_dir($path)) {
            array_splice($pathOptions, $i, 1);
        }
    }
```

While $i will increment on each iteration of the loop, it shouldn't increment if the splice line is called.  Here's how I fixed it:

```
    $pathCount = 0;
    foreach ($pathOptions as $i => $path) {
        if (!is_dir($path)) {
            array_splice($pathOptions, $pathCount, 1);
        } else {
            $pathCount ++;
        }
    }
```

I'm not sure if this complies with the cake coding guidelines, so I haven't forked the repository and issued a pull request.  I hope this helps, let me know if I should have issued this in a different manner.
