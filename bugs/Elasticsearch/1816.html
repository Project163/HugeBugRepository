Title

_field_caps API doesn't trigger reconnect to remove cluster

Description
When a remote cluster goes away, and a request to the `_field_caps` API attempts to reach that remote cluster, elasticsearch will not reconnect to the remote cluster even after it has come back online. In order to re-establish a connection a `_search` request to that cluster must be made, which triggers a reconnect and re-enables the `_field_caps` API.

perhaps related (though I'm happy to file as a separate issue) the failure states of the two API's are pretty dramatically different:

`_search` API failure state:
```
json
{
  "error": {
    "root_cause": [
      {
... [Log Snipped] ...
  "status": 500
}
```

`_field_caps` API failure state:
```
json
{
  "error": {
    "root_cause": [
      {
... [Log Snipped] ...
  "status": 500
}
```
