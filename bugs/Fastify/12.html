Description

```

  "$schema": "[URL]
  "type": "object",
  "properties": {
    "someKey": {

```

## To Reproduce

```
js
const fastify = require('fastify')({ logger: true })
const { FluentSchema } = require('fluent-schema')

const bodySchema = FluentSchema()
... [Log Snipped] ...

## Expected behavior

I don't expect the thrown's error. The `$schema` is raccomended by the [Link: standard] so, maybe I'm missing something or this field should be ignored?

```
