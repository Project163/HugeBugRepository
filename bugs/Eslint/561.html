Title

getScope should retrieve module scope instead of global scope for ES6 modules

Description
escope separates `global` scope from `module` scope for ES6 modules by [Link: nesting a `module` scope within the `global` scope]. `getScope` currently [Link: `acquire`s] [Link: the outermost scope] from escope. This leads to the `global` scope being returned when `getScope` is called in context of a top level statement instead of the `module` scope.
