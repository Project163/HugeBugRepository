Title

BUG: Regression in getitem for SparseArray with greater comparison

Description
### Pandas version checks

- [X] I have checked that this issue has not already been reported.

- [Link: X] I have confirmed this bug exists on the [latest version] of pandas.

- [X] I have confirmed this bug exists on the master branch of pandas.


### Reproducible Example
#44955 broke some things with greater comparisons. We should fix them before 1.4 is released or revert here.
```python

s = pd.arrays.SparseArray([1, 2, 3, 4, np.nan, np.nan], fill_value=np.nan)
s[s>2]

```


### Issue Description

This returns 

```
[1.0, 2.0, 3.0, 4.0]
Fill: nan
IntIndex
Indices: array([0, 1, 2, 3], dtype=int32)
```

### Expected Behavior

This returned

```
[3.0, 4.0]
Fill: nan
IntIndex
Indices: array([0, 1], dtype=int32)
```

 before which was correct.
