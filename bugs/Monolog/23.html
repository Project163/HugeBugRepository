Title

DeduplicationHandler causes infinite loop and fills logs with warnings

Description
Our server ran out of diskspace after a cronjob kept writing to a log file in an infinite loop caused by the DeduplicationHandler.

The infinite loop happens here:
[URL]

And the output is these two lines infinitely:
```
PHP Warning:  feof() expects parameter 1 to be resource, boolean given in .../vendor/monolog/monolog/src/Monolog/Handler/DeduplicationHandler.php on line 146
PHP Warning:  fgets() expects parameter 1 to be resource, boolean given in .../vendor/monolog/monolog/src/Monolog/Handler/DeduplicationHandler.php on line 147
```

On further inspection I found out the cause to be insufficient file permissions, there was also a warning:
```
PHP Warning:  fopen(...): failed to open stream: Permission denied in .../vendor/monolog/monolog/src/Monolog/Handler/DeduplicationHandler.php on line 140
```

But anyway, should probably check that `$handle` is not `false` before going into the while loop.
