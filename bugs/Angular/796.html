Title

Unable to update the golden file for core bundling test

Description
# 🐞 bug report

### Affected Package
The issue is caused by the generation of the golden files for @angular/core/test/bundling


### Is this a regression?
I'm not sure, it depends on the cause. It seems to only affect one PR, so that's probably a scenario that we never encountered before.


### Description
In my PR [URL] the CI complains that the golden file is not up to date, and that I need to run the bazel command to update it.
I did that the first time, it updated the golden file, but the CI still asks for an update (both locally and on CircleCI). I tried to rerun the script, it ends successfully but it doesn't change the file anymore.

The error is either that it should update the file and doesn't, or the script used to check the content of the file is wrong and the golden file is correct.


## 🔬 Minimal Reproduction
Checkout my PR: [URL]
Try to update the golden file with `yarn bazel run --define=compile=aot //packages/core/test/bundling/injection:symbol_test.accept`, it doesn't change anything.
Run the tests with `yarn test-ivy-aot //...`, it should fail.
