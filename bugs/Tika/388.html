Title

UTF-8 encoded XML is detected as text/plain because of UTF-8 BOM

Description
Detection of XML fails when encoded as UTF-8. The UTF-8 BOM: 0xEF,0xBB,0xBF causes the XML detector to fail when trying to match "<?xml" at the beginning of the input stream.
Discussion
- We had support for detecting XML files that are ASCII, UTF-8 no-BOM, UTF-16LE and UTF-16BE. 

 In r1328370 I've added detection + unit test for UTF-8 with a BOM 

 We don't detect XML in UTF-32 (with or without BOMs), but I'm not sure if that's worth adding or not?
- Closing as fixed per Nick's comment above. We can open a new issue if someone wants UTF-32 XML detection support.
