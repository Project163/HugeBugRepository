Description

6.2.2

### Steps to Reproduce

Simple example:
```
import { Routes, Route, Link } from "react-router-dom";

```

More real example: [URL]
```
import { Routes, Route, Link } from "react-router-dom";

export default function App() {
  return (
     
... [Log Snipped] ...
  );
}
```

In the User component there is only /balance route, so seems like it should show Not Found on all others (including /example) urls.

### Expected Behavior

Clicking on the "/example" link shows "Not found" page as there is no `/example` routes

### Actual Behavior

Orphan link isn't caught despite there is wildcard route that should catch it
Discussion
- This is expected behavior. Nested instances of ` ` don't report up to their ancestors that they don't match. There is no concept of a root "catch-all" route.
