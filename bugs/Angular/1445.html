Title

AnimationAstBuilderVisitor.visitAnimate() can't handle AnimateTimings

Description
## I'm submitting a...

  
[x] Bug report
  

## Current behavior
When calling AnimationBuilder.build() with metadata that contains metadata of type AnimationAnimateMetadata which in turn contains a timings property as AnimateTimings object the call fails because calling split on that object will fail here: [URL] The error message in Chrome says: "TypeError: strValue.split is not a function"


## Expected behavior
I would expect it to be possible to call AnimationBuilder.build() with metadata that contains metadata of type AnimationAnimateMetadata which in turn contains a timings property as AnimateTimings object as it is documented and indicated by the type system.


## Minimal reproduction of the problem with instructions
```
typescript
animationBuilder.build([   {
    animation: [   {
        styles: {
            offset: null,
... [Log Snipped] ...
    type: AnimationMetadataType.Query
} ]);
```

An easy fix would be to add a return statement before the else clause in line 536 of that file. [URL] The if clause would then look somehow like this:

```typescript
...
if (value.hasOwnProperty('duration')) {
    timings = value as AnimateTimings;
    return makeTimingAst(timings.duration, timings.delay, timings.easing);
} else ... 
```

But I'm not sure if I'm missing an edge case.

## What is the motivation / use case for changing the behavior?
I'm building an app which uses custom animations and therefore I'm using the AnimationBuilder. I'm trying to pass on the metadata in it's raw form to make sure my code does not stringify the metadata just to let the AnimationBuilder parse it again.
