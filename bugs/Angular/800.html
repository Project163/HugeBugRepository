Title

Resetting a form group emits events with dirty state

Description
# 🐞 bug report

### Affected Package
 
The issue is caused by package @angular/forms


### Is this a regression?

Don't think so.

### Description

When calling `reset()` on a form group with a value the `valueChanges` event emits but the form state is still e.g. `dirty` during this event. After the reset is complete the `dirty` state is correct. I would expect, that the provided value should be emitted with an already non-dirty (pristine) state.
