Title

Geo search across anti-meridian doesn't work

Description
It seems that ES does not like bounding boxes that extend across the 
antimeridian (180° meridian). If I specify a box with top left corner 
to the left of the meridian, and bottom right on the right, it treats 
it as if the box wrapped around the wrong (long) way around the Earth.

```
curl -XPUT '[URL] -d'{ index: { number_of_shards: 1, number_of_replicas: 0 } }'
curl -XPUT '[URL] -d '{
  "test" : {
      "properties" : {
            "user" : {"type" : "string", "index" : "not_analyzed"},
... [Log Snipped] ...
    }
}'
```
