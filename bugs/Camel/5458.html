Title

Description

  I’m trying to use this simple route with Camel 3.4.3 and springboot : 
  
 
 from( "timer:hello?repeatCount=1&delay=1000" ).routeId( "hello" )
         .to( "log:1" )
         .pollEnrich( "file:d:\\temp?noop= true &fileName=dummy.csv" ,5000)
         .to( "log:2" );
