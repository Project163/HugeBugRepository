Title

Changes in symlinked bundles not detected with NIO2 WatcherScanner

Description
Since the new NIO2 WatcherScanner was introduced as part of FileInstall 3.4.0, I've noticed that FileInstall no longer detects changes to files symbolically linked to from the deploy directory. Also, there may be additional issues with network-mounted directories as well. These can be worked around by setting the felix.fileinstall.disableNio2 option to true, though this isn't ideal.
