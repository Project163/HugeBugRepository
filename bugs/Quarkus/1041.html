Title

Kafka Streams extension does not read the "default broker configuration" map

Description
## Describe the bug

The Kafka Streams extension does not read the configuration provided by the kafka-client extension.
The Kafka Streams extension used a different approach for configuration which won't work with service bindings as the support of service bindings is based on the "default configuration" approach (basically it produces a `Map ` that any Kafka related application can read.

We need to extend the Kafka Streams configuration to read from the map. 
In `io.quarkus.kafka.streams.runtime.KafkaStreamsProducer#getStreamsProperties`, we could add a lookup for the default configuration and if there, pre-populate the Kafka Streams configuration.
