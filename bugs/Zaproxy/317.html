Title

Concurrent access to Graal.js Input Vector scripts

Description
### Describe the bug

`Multi threaded access requested by thread Thread[ZAP-ActiveScanner-2,3,main] but is not allowed for language(s) js.`

### Steps to reproduce the behavior

1. Create an Input Vector script with Graal.js engine
2. Run the Active Scanner with Script Input Vectors enabled
3. Notice the script gets disabled after some time (might not happen always given it's a concurrency issue).

### Expected behavior

Script is not disabled while used.

### Software versions

Latest main zaproxy/zaproxy@ .
