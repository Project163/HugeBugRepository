Title

LwjglInput setCursorPosition and getY mouse origin inconsistent.

Description
In getY the mouse position is manipulated to make the top left corner of the window the origin, while setCursorPosition uses the lower left corner as the origin.

Because of this the following snippet will cause the cursor to jump up and down on the y axis:

``` java
Gdx.input.setCursorPosition(Gdx.input.getX(), Gdx.input.getY());
```

Relevant methods from LwjglInput.java:

``` java
public int getY () {
    return Gdx.graphics.getHeight() - 1 - Mouse.getY();
}

public void setCursorPosition (int x, int y) {
    Mouse.setCursorPosition(x, y - 1);
}
```
