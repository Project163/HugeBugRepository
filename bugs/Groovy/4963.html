Title

STC: trait extends trait and tries to use static field

Description
Consider the following: 
  
 
 package  p
 trait  A {
  public static final  String  BANG =  '!' 
}
@groovy.transform.TypeChecked
 trait  B  extends  A {
  static staticMethod() {
    BANG  // p_A__BANG works
   }
   def  method() {
    BANG  // p_A__BANG works
   }
}
 class  C  implements  B {
  static main(args) {
    p_A__BANG  // Apparent variable ... was found  in  a static scope but doesn't refer to a local variable, static field or class
     staticMethod()
    method()
  }
}
 
  

 If the trait B is implemented and the methods are called, both produce MissingMethodException.  STC should catch this.
