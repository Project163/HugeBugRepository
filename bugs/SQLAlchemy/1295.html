Title

pool_pre_ping=True doesn't reconnect stale connection with MySQL 8.0.28

Description
### Describe the bug

When using pool_pre_ping=True with MySQL version 8.0.28 and a stale
connection, SQLAlchemy raises the following error instead of
reconnecting:

MySQLdb._exceptions.OperationalError: (4031, 'The client was disconnected by the server because of inactivity. See wait_timeout and interactive_timeout for configuring this behavior.')


### To Reproduce

```
python
# using MySQL 8.0.28 (or at least 8.0.24) set the following in my.cnf

# [mysqld]
# wait_timeout=10
... [Log Snipped] ...
with Session(engine) as session:
    print(session.query(text("1")).all())
```

### Error

```
$ python3 reconnect_test.py
[(1,)]
Traceback (most recent call last):
  File "/Users/karim/huiscan/venv/lib/python3.9/site-packages/sqlalchemy/engine/base.py", line 145, in __init__
    self._dbapi_connection = engine.raw_connection()
... [Log Snipped] ...
    dbapi_connection.rollback()
MySQLdb._exceptions.OperationalError: (4031, 'The client was disconnected by the server because of inactivity. See wait_timeout and interactive_timeout for configuring this behavior.')
```

### Versions

- OS: MacOS 11.6.2 
- Python: Python 3.9.12
- SQLAlchemy: from git main commit  
- Database: MySQL  8.0.28
- DBAPI (eg: psycopg, cx_oracle, mysqlclient): mysqlclient
