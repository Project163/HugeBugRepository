Title

Doesn't support vitest workspaces

Description
### Describe the bug

When trying to use `@sveltejs/kit` in a monorepo that uses Vitest workspaces, SvelteKit fails to resolve its peer dependency `@sveltejs/vite-plugin-svelte`.

### Reproduction

Run `pnpm i && pnpm vitest` (from root)
