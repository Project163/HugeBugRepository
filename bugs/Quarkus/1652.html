Title

NoSuchMethodException in Resteasy-reactive when running in native mode (RestResponse )

Description
### Describe the bug

I'm facing a similar issue to the one described in #25973 fixed by #26021.

In my case the method signature and annotations look like:
```java
  @GET
  @Path("/{fileName:.+}")
  public RestResponse  getStaticFile(@PathParam("fileName") String fileName) throws IOException {
```

Maybe accounting for RestResponse/InputStream in [Link: `ResteasyReactiveProcessor`] might fix it :shrug:.

I can workaround this issue by annotation the affected class with `@RegisterForReflection`

No exception should be thrown, method should pipe an input stream to the response.
