Title

3.0 - $this->enableCsrfToken() fail with many requests in the same testAction

Description
### 1. Bug with `enableCsrfToken()`

```
php
public function testDebug()
{
    $data = [
        'username' => 'mariano',
... [Log Snipped] ...
    $this->assertResponseOk();
}
```

This is caused by [URL]
#### Solution :

```
php
if ($this->_csrfToken === true) {
    $csrfToken = Text::uuid();
    $csrfGenerated = false;

... [Log Snipped] ...
    }
}
```

And it work well.
### 2. Proposal of a new function `disableCsrfToken()`

Also, it would be nice to have a method `disableCsrfToken()`, because when we call `enableCsrfToken()`, it enable the csrf for all requests in the action.
But if for X or Y reason, we need to disable it for a special request, we can't . (Well, we can with `$this->_csrfToken = false`, but it's more logic to use a function called `disableCsrfToken()`)

Exemple usage :

```
php
public function testDebug()
{
    $data = [
        'username' => 'mariano',
... [Log Snipped] ...
    $this->assertResponseOk();
}
```
