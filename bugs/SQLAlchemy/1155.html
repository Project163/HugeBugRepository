Title

SQLAlchemy 1.4 joinedload + case + Single-Table Inheritance

Description
**Describe the bug**
 
Relationships to polymorphic single-table inheritance subclasses where the polymorphic identity is defined using a `case` statement do not generate properly aliased joins in SQLAlchemy 1.4
