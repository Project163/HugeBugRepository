## Summary of Problem

The pydantic dataclass decorator calls `object.__setattr__()` on `self.__dict__` for a dataclass post init, using only the output of `validate_model()`, which removes any other attributes in the object's namespace, causing many issues [Link: including those well described for SQLAlchemy].
