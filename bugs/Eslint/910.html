- Reproduced this. In my project I have an error for every time I use an else statement without brackets. Definitely broken.
- I will work on this.
I think we need to rewrite the traversal way of this rule.

``` js
/*eslint max-statements-per-line:[2, {max:2}]*/

a; if (b) { c; d; }
z;
```

Currently, this `d;` should be warned, but not.
Because the traversal order of this is `a;` → `if (b)` → `z;` → `c;` → `d;`.
