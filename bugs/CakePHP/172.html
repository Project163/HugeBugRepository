Title

3.0 Entity Context not properly detecting multiple child entities

Description
When reloading add.ctp:

```
php
 Form->create($purchase,['onsubmit'=>'return validateForm()']); ?>
     
           
     Form->input('pass_holders.'.$i.'.email',['required'=>false]);
            echo $this->Form->input('pass_holders.'.$i.'.relationship_id', ['options' => $relationships,'empty'=>'(choose one)','required'=>false);
```

Relationships presented validation errors, but FormHelper did not find the error.
altered /cakephp/src/View/Form/EntityContext.php
line 270
From

```
 return false;
```

To: 

```
                if(!is_array($entity))
                    return $entity;
                else 
                    return false;
```

This fixed the problem and the error now shows as expected.
