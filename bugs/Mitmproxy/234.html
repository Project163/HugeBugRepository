Title

Commands that return a list of flows crash when a flow has been loaded from a file

Description
#### Problem Description

Execute `view.flows.resolve @focus` under two conditions:

1. With recorded flows: overlay pops up with result

Discussion
- It took a little digging but the issue is that the `mitmproxy.controller.DummyReply` instance can not be pickled. This is required for copying the object which is done when presenting the overlay.

I added a `__deepcopy__(self, memo)` method to `DummyReply` which seems like a fix. I'm not exactly sure what I'm doing down in this area of code so if someone wants to review this and approves I'll send a PR:

```python
    def __deepcopy__(self, memo):
        cls = self.__class__
        result = cls.__new__(cls)
        memo[id(self)] = result
        result._state = self._state
        result._should_reset = self._should_reset
        return result
```
