Title

Description

```
$ protoc --decode_raw <50572f2dc22e68702534d6943295d4b24d676f70cfe9f9f15702e9fe8ee8bcf5_158 
3 {
  1: "protobuf"
  2: "../../../@bufbuild+protobuf@2.6.0/node_modules/@bufbuild/protobuf"
}
... [Log Snipped] ...
  2: "../../../@bufbuild+protobuf@2.6.0/node_modules/@bufbuild/protobuf"
}
```
