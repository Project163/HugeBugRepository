Title

Cannot recover from bad analysis settings

Description
This problem was reported at [URL] If you update analysis settings with an empty list of keywords in a keyword marker filter on a closed index, the index will fail to reopen and there does not seem to be any way to recover from this situation. This problem was reported on Elasticsearch 5.2 but reproduces on master:

```
DELETE my_index

PUT my_index

POST my_index/_close
... [Log Snipped] ...
  }
}
```

Once we reach this point, it does not seem possible to open the index again. For instance, the commands below that try to set a dummy list of keywords to make the filter valid again fail:

```
POST my_index/_open

POST my_index/_close

PUT my_index/_settings
... [Log Snipped] ...
  }
}
```
