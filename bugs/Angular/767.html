Angular 6 (6.0.7+) @angular/upgrade: Interface 'IAnnotatedFunction' incorrectly extends interface 'Function'.

## Current behavior

The following error is thrown during TS compile from 6.0.7 through 6.1.10:

  Types of property '$inject' are incompatible.
    Type 'ReadonlyArray ' is not assignable to type 'string[]'.
      Property 'push' is missing in type 'ReadonlyArray '.

This error does not occur when using version up to, and including 6.0.6.

## Expected behavior

No TS compile errors occur for any @angular packages in versions after 6.0.7.

## Minimal reproduction of the problem with instructions

Compile a hybrid angular application using Typescript 2.9.2 and the following values in package.json:
"@angular/animations": "^6.1.10",
    "@angular/common": "^6.1.10",
    "@angular/compiler": "^6.1.10",
    "@angular/core": "^6.1.10",
    "@angular/forms": "^6.1.10",
    "@angular/http": "^6.1.10",
    "@angular/platform-browser": "^6.1.10",
    "@angular/platform-browser-dynamic": "^6.1.10",
    "@angular/platform-server": "^6.1.10",
    "@angular/router": "^6.1.10",
    "@angular/upgrade": "6.0.7"

## What is the motivation / use case for changing the behavior?
Upgrading to Angular 6.
