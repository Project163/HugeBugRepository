Title

ServerRequestContext can not be used as parameter of ServerExceptionMapper

Description
### Describe the bug

The documentation for `ServerExceptionMapper` [URL] states:

The list of context objects also includes the [Link: ServerRequestContext].

When I want to use the ServerRequestContext as method parameter, I get an exception on startup, see below.

fails:
```
    @ServerExceptionMapper
    RestResponse  handle(RuntimeException e, ServerRequestContext serverRequestContext) {
        return RestResponse.ok(serverRequestContext.getRequestHeaders().getRequestHeaders().toString());
    }
```

It works perfectly if I instead use an `@Inject`:
 ```
    @Inject
    ServerRequestContext serverRequestContext;

    @ServerExceptionMapper
    RestResponse  handle(RuntimeException e) {
        return RestResponse.ok(serverRequestContext.getRequestHeaders().getRequestHeaders().toString());
    }
```

### Expected behavior

I can use any of the context objects [URL] as method parameter; Since that is what the doc says.
