Title

Issue with `pm2 startup centos`

Description
Hi, I was trying to create a startup script for pm2 on centos 7. I usually do this with these commands
```
$ pm2 update
$ pm2 save
$ sudo PM2_HOME=/home/$(whoami)/.pm2 pm2 startup centos -u $(whoami)
```
But this time I've got an error on `pm2 startup`.

When I downgraded pm2 to 2.1.4 it created the script as expected without any errors.
