Title

Blank field names should be illegal

Description
Today you can create a blank field name, eg:

```
PUT t/t/1
{
  "": 5
}
```

Or

```
PUT t/t/1
{
  "": {
    "foo": 5
  }
}
```

Blank field names should be illegal as they are not accessible via paths
