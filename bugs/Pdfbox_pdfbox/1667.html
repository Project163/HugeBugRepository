Title

ICC_ColorSpace usage is not thread safe

Description
Unfortunately  ICC_ColorSpace  is not thread safe. Even creating  Color  instances and passing an  ICC_ColorSpace  can't be considered thread safe. All color conversion calls lazy initialize a value without a memory barrier:  [URL] . This seems like a bug in Java, but PDFBox triggers it   

 PDFBox seems to attempt to initialize colorspaces/colors in a thread-safe way around  [URL] , but calls to  toRGB / fromRGB  aren't synchronized. I  think  calling all 4 (to/from)(CIEXYZ/RGB) in a locked block  should  initialize the instances enough to be thread safe.
