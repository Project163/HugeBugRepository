Title

Cygwin build make check log message "WARNING: UNPROTECTED PRIVATE KEY FILE!"

Description
Between tests 0581 and 0584 got multiple occurrences of:
```
@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@
@         WARNING: UNPROTECTED PRIVATE KEY FILE!          @
@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@
Permissions 0755 for '$HOME/src/cygwin/curl/curl-8.1.2-1.x86_64/build/tests/' are too open.
It is required that your private key files are NOT accessible by others.
... [Log Snipped] ...
sshd: no hostkeys available -- exiting.
=== End of file $HOME/src/cygwin/curl/curl-8.1.2-1.x86_64/build/tests/log/ssh_server.log
```
See in:
[Link: Cygwin-curl-8.1.2-1-check.log]
Script `sshd-curl-config` was generated under out of tree build dir ...`/build/tests/log/server/`, as were the key files `{curl_client_key,curl_host_rsa_key}{,.pub}`... so it seems that directory, or another created for the keys, should have their permissions limited to 0700, as expected for `~/.ssh/` directories, and if the higher level directory specified in the message is spurious, that should also be corrected.


### I did this
`make check`

### I expected the following
Tests build and run, possibly not all successfully.
