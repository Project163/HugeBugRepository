Title

Handle named pipe clients quickly disconnecting

Description
When using the TPipeServer transport, if a client connects but disconnects before the acceptImpl method is able to create a TPipe instance the resulting exception causing the entire transport to stop. 

 You can cause this issue using the SysInternals accesschk utility ( [URL] to query the permissions of the named pipe. 

 This has also been reported in osquery  osquery/osquery#4280
