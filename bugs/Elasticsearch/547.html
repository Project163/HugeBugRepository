Title

Missing completion fields in nodes stats

Description
The indices stats API supports `fields`/`completion_fields`/`fielddata_fields`:

```
GET /_stats/completion?fields=name
....
     "completion": {
        "size": "20b",
        "size_in_bytes": 20,
... [Log Snipped] ...
        }
     }
```

But the nodes/indices stats only supports `fields` for fielddata, not for completion stats:

```
GET /_nodes/stats/indices/completion?fields=name
....
        "completion": {
           "size": "20b",
           "size_in_bytes": 20
        }
```
