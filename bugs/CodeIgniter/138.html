Title

The helper function img() fails with data URIs

Description
[URL]

When I try to generate an image tag like this one:

```html
 
```

the function img() does not detect that the passed src attribute should not be modified. It mistakenly adds at the beginning the site/base URL in this case.
Discussion
- *How* do you try to do that?
- I've got a helper function display_user() that shows a user avatar and names. The avatar is configurable it could be a custom image, Gravatar,
or Letter Avatar [URL] - with it I found this case.

So, within this helper function I've got this line:

```php
$result = img($ci->user_photo->get($user, $photo_size), false, $attributes);
```
