Title

Qute guide shows examples that do not compile

Description
**Describe the bug**
The Qute Guide shows an example of [Link: Type-safe templates], with the code:

```
`
@Path("hello")
public class HelloResource {

    @CheckedTemplate
... [Log Snipped] ...
    }
}
````

However, non-static inner classes can not have static methods, therefore the code will not compile. The class should be defined as `static` also:

````
    @CheckedTemplate
    static class Templates {
        public static native TemplateInstance hello(); 
    }
````

**Expected behavior**
The code should compile

**Actual behavior**
The code does not compile
