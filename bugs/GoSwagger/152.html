Title

Client generation fails with 0.15.0, works with 0.14.0

Description
## Problem statement

Just tested the `quay.io/goswagger/swagger:0.15.0` docker image as a replacement for 0.14.0 for generating a client.

The error output was:

```
name inlined schema: object has no field /v4/users/%7Bemail%7D/
```

With 0.14.0. the generation works fine based off the identical spec.

## Swagger specification

The spec is in this folder:

[URL]

The main file is `spec.yaml`, there are three more referenced YAML files in the same folder. The place where the generation broke is likely [Link: line 293 or spec.yaml]:

## Steps to reproduce

1. `git clone [URL]
2. Edit `Makefile` to replace `quay.io/goswagger/swagger:0.15.0` with `quay.io/goswagger/swagger:0.15.0`
3. Run `make generate`

This will use the current `master` of the spec linked above. To make sure the exact same version is used, edit `Makefile` once more and change the `BRANCH` variable in the top from `master` to ` `.

## Environment

swagger version: The spec uses Swagger 2.0
OS: Linux (official docker image)
Discussion
- This is a bug with the new default "flatten minimal". 
You can work around with `--with-flatten=full`, which gives you the behavior of v0.14
- The problem is caused here. I don't know yet why it is occurring.
```

    get:
