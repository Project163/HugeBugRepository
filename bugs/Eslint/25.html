Description

Discussion

---

The Rule ID 'no-extra-semi' does _not_ appear to be _on_ by default in eslint v0.1.0 (npm version), node v0.10.21

In the following code, I get a double `Warning - Unnecessary semicolon.` (as expected) from _jshint_, but not from _eslint_:

```
/*global console */
/*eslint no-console:0 */ /*no-extra-semi:1*/

(function() {
    "use strict";
... [Log Snipped] ...
    };
})();
```

eslint output:

```
lint.test.js: line 5, col 4, Error - Expected an assignment or function call and instead saw an expression.
lint.test.js: line 7, col 8, Error - x is defined but never used

2 problems
```

Both of the eslint-reported issues are as currently expected.

But only by changing the eslint directives to  `/*eslint no-console:0 no-extra-semi:1*/` do I get the expected output  `Warning - Unnecessary semicolon.`
- Yup, this all stents from it not being included in the config file.
