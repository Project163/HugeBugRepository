Title

trait conflict resolution not available for static methods

Description
If the case mentioned in  [URL] used static methods instead of instance methods, "T.super.m()" disambiguation is not available. 

 Consider the following: 
  
 
 trait  A {
  static m() {  'A'  }
}
 trait  B {
  static m() {  'B'  }
}
 class  C  implements  A, B {
  void test() {
    print m()  // prints  "B" 
     print A. super .m()  // java.lang.IllegalArgumentException or some other compiler problem
     print B. super .m()  // java.lang.IllegalArgumentException or some other compiler problem
   }
}
 new  C().test()​
Discussion
- SuperCallTraitTransformer#transformMethodCallExpression(MethodCallExpression)  adds "this" parameter, which causes problems for static method calls.
- This also includes static property read and write.
