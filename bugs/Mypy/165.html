Title

mypy crashes at some forward references

Description
### comments

There's no error if the line `Element = Union['Node', 'Tree']` follows the line `Node = NamedTuple('Node', [('ref', int)])`.

Latest version of mypy is installed from github.

```
mypy 0.3.1
```

Element = Union['Node', 'Tree']

Discussion
- Looks like you've hit a point in some very old code where some combination of things hasn't been implemented yet. I don't know how hard it would be to fix and it's an easy work-around, so I think we can live with this a little longer. Marking it as a bug though to keep track. Eventually we'll get to it.
- While mypy should ideally not crash of course, forward references to type aliases aren't supported yet anyway.

```
from typing import Union

Element = Union['Node', str] # E: Invalid type "forward.Node"
Node = int
```
