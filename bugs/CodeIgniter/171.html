Title

Pagination::create_links() not compatible with PHP 8.1

Description
An error occurs in the pagination library when calling the `create_links()` method when the value of the current page is not present in the URL. This is a likely possibility when viewing page 1 of a dataset.

```
A PHP Error was encountered
Severity: 8192
Message: ctype_digit(): Argument of type null will be interpreted as string in the future
Filename: libraries/Pagination.php
Line Number: 518
```

Line 518 is as follows:

```
if ( ! ctype_digit($this->cur_page) OR ($this->use_page_numbers && (int) $this->cur_page === 0))
```

The reason the error occurs is because at this point the value of `$this->cur_page` is NULL.

The fix is to convert the value to a string before checking if it only contains digits.
Line 518 can therefore be changed as follows:

```
if ( ! ctype_digit((string) $this->cur_page) OR ($this->use_page_numbers && (int) $this->cur_page === 0))
```
