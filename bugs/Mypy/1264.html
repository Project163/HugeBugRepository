Title

`@final` decorator is not honored on override with --check-untyped-defs

Description
**Bug Report**

Overriding class methods marked with `@final` [Link: (pep-0591)] are not reported as errors. The example script will not produce an error with `mypy` even though it probably should. 

#9612 is potentially related, but they have a `final` problem in the other direction.

**To Reproduce**

```
python
from typing import final

class Base:
    @final
... [Log Snipped] ...
    def foo(self):
        pass
```

**Your Environment**

```
✗ python --version && mypy --version && mypy foo.py 
Python 3.8.5
mypy 0.790
Success: no issues found in 1 source file
```
