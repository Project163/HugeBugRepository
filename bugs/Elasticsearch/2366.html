- This is the call stack on 7.0, the Attribute source that's `null` in the 6.8 case gets set here by the using the TermCollectors attributes in [URL]

[Image: Screenshot 2020-03-05 at 16 35 01]
- I think I know why this fails in 6.8 inside a boolean filter now. The FuzzyQueryBuilder used to set the rewrite method in filter mode to "constant_score", which was later removed in 7.0 (https://github.com/elastic/elasticsearch/pull/35354/files#diff-82ebdac5b91f2d2f368f55eb1e738a39L329). The surrounding SpanMultiTermQueryBuilder#doToQuery then sees that in [URL] and then uses SpanBooleanQueryRewriteWithMaxClause in the wrapper. 

I was able to reproduce the same NPE on 7.x and master by forcing the fuzzy query rewrite method to "constant_score" like this:
```
GET /test_index/_search
{
  "query": {
    "bool": {
      "filter": [
... [Log Snipped] ...
  }
}
```
