Title

Code example is TestBed.get but description says TestBed.inject in the HTTP guide

Description
# 📚 Docs or angular.io bug report

### Description
The _[Link: Testing HTTP requests]_ section of the HTTP guide has contradictory code and explanation.

The method `TestBed.get` is being used but the description says `TestBed.inject`.

## 🔬 Minimal Reproduction
1. Navigate to [URL]
2. Within that page, go to section _Testing HTTP Requests_ -> _Setup_ (https://angular.io/guide/http#setup-1)
3. Look at the last lines of the block of code named _app/testing/http-client.spec.ts(setup)_ and the description after it

### What's the affected URL?
[URL]

### Expected vs Actual Behavior
`TestBed.get` should be `TestBed.inject`.

Alternatively, explanation should say _TestBed.get()_ instead of _TestBed.inject()_, but because of what is said in [URL] the first option would be prefered.
