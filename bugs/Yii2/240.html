Title

Response sendHeaders

Description
The `sendHeaders` method in `Response.php` uses `header("", false)` to allow for duplicate headers.

Using nginx I'm finding that `header("", false)` is allowing nginx to append it's own headers too.

When trying to set some expires headers.

```
$response->getHeaders()
    ->set('Cache-Control', 'max-age=31536000, must-revalidate')
    ->set('Pragma', 'private')
    ->set('Expires', gmdate('D, d M Y H:i:s \G\M\T', time() + 31536000))
```

I get

```
Cache-Control:  no-store, no-cache, must-revalidate, post-check=0, pre-check=0, max-age=31536000, must-revalidate
Date:       Mon, 16 Jun 2014 08:16:55 GMT
Expires:    Thu, 19 Nov 1981 08:52:00 GMT, Tue, 16 Jun 2015 08:16:55 GMT
Pragma:     no-cache, private
```

If I remove the false from `header`

```
Cache-Control:  max-age=31536000, must-revalidate
Date:   Mon, 16 Jun 2014 08:26:36 GMT
Expires:    Tue, 16 Jun 2015 08:26:36 GMT
Pragma: private
```
