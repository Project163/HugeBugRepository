Title

Hexadecimal escape in host

Description
hi all 

while I used syncthing 12 beta1 I noticed this error logs :

"Failed to parse connection url: tcp://fe80::ccb4:*******_:10d2%{04F829EA-**_**************_-9A6B8511AB9D}:22000 parse tcp://fe80::ccb4:**_****_:10d2%{04F829EA-**_***************-9A6B8511AB9D}:22000: hexadecimal escape in host" 

with the occasional disconnection of the device. 
is this a problem of my configuration?
