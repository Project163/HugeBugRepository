Title

Resizing with fallback decorations can cause viewport protocol error

Description
Easy to reproduce with `examples/triangle-opengl`. Resize the window, until its width and or height become zero or negative. The window closes and the app exits with `wp_viewport@33: error 0: all values must be either positive or -1`.

Remedy: set a minimum window size. glfw should do this during window initialization for wayland windows, because the default behaviour is obviously non-sensible.

Also: When running any of the examples with a wayland window, I always get `libEGL warning: DRI2: failed to create dri screen`.
