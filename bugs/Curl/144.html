Title

curl 7.74.0 causes a crash with pulseUI VPN client

Description
I am using `pulseUI` VPN client at my Arch Linux
```
~ uname -a
Linux wolf.lan 5.9.13-arch1-1 #1 SMP PREEMPT Tue, 08 Dec 2020 12:09:55 +0000 x86_64 GNU/Linux
```

And with the recent curl update (7.73.0 -> 7.74.0) I start getting the binary SIGSEGV crash at start:

```
Program received signal SIGSEGV, Segmentation fault.
  in __strcmp_avx2 () from /usr/lib/libc.so.6
(gdb) bt
#0    in __strcmp_avx2 () at /usr/lib/libc.so.6
#1    in lh_insert ()
... [Log Snipped] ...
#26   in  ()
#27   in  ()
```

so it is some curl/openssl issue that causes invalid memory usage?

And here it is the end of `strace` output

```
futex( , FUTEX_WAKE_PRIVATE, 2147483647) = 0
futex( , FUTEX_WAKE_PRIVATE, 2147483647) = 0
futex( , FUTEX_WAKE_PRIVATE, 2147483647) = 0
futex( , FUTEX_WAKE_PRIVATE, 2147483647) = 0
futex( , FUTEX_WAKE_PRIVATE, 2147483647) = 0
... [Log Snipped] ...
+++ killed by SIGSEGV (core dumped) +++
[1]    76216 segmentation fault (core dumped)  strace -f /usr/local/pulse/pulseUi
```

for me it looks it crashes while parsing `/etc/ssl/openssl.cnf` file.

Reverting curl package back to `7.73.0` fixes the issue for me.
