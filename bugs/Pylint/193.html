Title

Assigning to attribute '__class__' not defined in class slots

Description
I change the `__class__` of objects that were successfully `released()`.
I pasted a short example below, but I have similar code in [Link: ModernGL].
I added slots in [Link: this commit]. In my case it is critical to let the user access objects that were released already, this is why I must change the `__class__`.

I am not sure if other `__magic__` attributes are affected or not.

### Steps to reproduce

```
py
class InvalidFoobar:
    __slots__ = ['foobar']


... [Log Snipped] ...
    def release(self):
        self.__class__ = InvalidFoobar
```

### Current behavior

```py
self.__class__ = InvalidFoobar
```

causes

```
E0237:Assigning to attribute '__class__' not defined in class slots
```

### pylint --version output

```
pylint 1.7.1,
astroid 1.5.2

```
