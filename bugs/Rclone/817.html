Title

Microsoft Office apps can't write on an S3 mount when mounted with nfsmount on MacOS 14.5

Description
#### What is the problem you are having with rclone?
I started using the nfsmount option to mount Amazon S3 drives because it is very problematic to give the proper permissons for the kernel extensions for MacFuse when dealing with remote computers. At first, I thought that the nfs mount worked perfectly. It does, but then I realized that Microsoft Office apps Word, Excel, Powerpoint, can NOT write on the mounted drive. They can only read. All other apps on my Mac can write on the mounted drive, just not the Microsoft apps, which is very weird. I tried playing with these options:

--vfs-cache-mode
--dir-perms
--file-perms

But nothing worked. This makes using Rclone very problematic for us because most of us use MS Office daily. The way we go around it now is to, save the file locally, and then move it to the mounted drive, or vice versa. Definitely not ideal!


#### What is your rclone version (output from `rclone version`)
1.67.0

#### Which OS you are using and how many bits (e.g. Windows 7, 64 bit)
Mac OS Sonoma 14.5, 64 bit, M chip

#### Which cloud storage system are you using? (e.g. Google Drive)
Amazon S3
