Title

DenseVectorField w/ vectorDimension > 1024 no longer works by default

Description
Starting with Solr 9.4, configuring a  DenseVectorField  w/  vectorDimension  > 1024 no longer works by default. There is no error on startup, but when indexing you'll get errors like...

 I think the best long term solution is to change Solr to use  SchemaCodecFactory  as it's implicit default – but i will file & link a distinct issue for that change since it has larger implications (and would probably not be suitable for backporting to include in a bug-fix release)
