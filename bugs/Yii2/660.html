Title

rbac permission error when user id is 0

Description
### What steps will reproduce the problem?
create a user with id=0, then call $auth->getPermissionsByUser(0), the result will be [];
and all permission assigned to this user will not go into effect.

In yii\rbac\Dbmanger.php, line 526,
 if (empty($userId)) {  // here user.id=0 is traded as a empty. 
            return [];
  }

### What is the expected result?
user with id=0 should be run as a normal user.
or we should document the problem to remind the developer of YII2 to avoid using a user with id=0;

### What do you get instead?
I set the user 0 as the admin of my system, and follows the yii2 Authorization programming Tutorial. but can not get the role admin works. So i trace the code and find this. 
Now, I directly edit my DB to avoid all the data associated with user 0. and set a new user with id>0 as the admin Role

| PHP version   | 5.6.3
| Operating system | WIN 10
