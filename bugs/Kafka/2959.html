Title

Fix broker-side client quotas in Raft mode

Description
While integrating the Raft TestKet (  KAFKA-12383  ) I found that client quotas were not working as expected in raft mode. The DescribeClientQuotas RPC is not wired up in Raft mode, so the bug is not exposed, but needs to be fixed regardless. 

 The expectation is that Alter/DescribeClientQuotas work exactly the same in ZK or Raft mode. This can be verified by changing ClientQuotasRequestTest to run with both types of clusters.
