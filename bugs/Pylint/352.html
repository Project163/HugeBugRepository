Title

AttributeError when pylint is run via python -m pylint from src directory

Description
### Steps to reproduce
1. Download pytest src
2. cd pytest/src/_pytest
3. python -m pylint logging.py  # raises AttributeError
4. pylint logging.py  # no AttributeError is raised

### Current behavior

If pylint is run using `python -m pylint` an AttributeError is output

```
Could not import runpy module
Traceback (most recent call last):
  File "/home/thomas/miniconda/lib/python3.6/runpy.py", line 14, in  
    import importlib.machinery # importlib first so we can test #15386 via -m
... [Log Snipped] ...
    warnings.warn("the imp module is deprecated in favour of importlib; "
AttributeError: module 'warnings' has no attribute 'warn'
```

### Expected behavior

No exception
