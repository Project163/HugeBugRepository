Title

Allow setting name attribute in hidden input file upload

Description
Hi Yii2 team.

Currently, one can rename input fields in ActiveForm by passing the name key in $options array. This does work (as I've seen it) in every field but not for the hidden field in a file upload.

I would suggest as fix in this code line:
[URL]

From:
`return static::activeHiddenInput($model, $attribute, ['id' => null, 'value' => ''])`
To:

``` php
$hiddenInputOptions = ['id' => null, 'value' => ''];
if(isset($options['name'])) {
    $hiddenInputOptions['name'] = $options['name'];
}
return static::activeHiddenInput($model, $attribute, $hiddenInputOptions)
```

As this would be the first contribution to this project, I want to first ask whether that is the supposed way and if it suits the code style.
