Title

[Regression] do not modify Cookie::$path on Response::sendCookies()

Description
### What steps will reproduce the problem?

1. Make codeception tests that test sending form data(get CSRF token and submit form)
2. see it fail

### What is the expected result?
I should be able to test my beautiful form

### What do you get instead?
It fails because codeception does not get CSRF cookie any more since `Cookie::$sameSite` is appended to `Cookie::$path`, and now path validation fails
