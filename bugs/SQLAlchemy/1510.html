Title

Behaviour of subqueryload is inconsistent going from 2.0.27 to 2.0.28 (using postgres)

Description
### Discussed in [URL]

 

 Originally posted by **pdmnyberg** March 19, 2024 
I have a system where I would like to filter the sub-items of the items I would like to return in the main query. The way I am doing this can be expressed using the `pytest` below. My problem is that I am getting different results when I update from version `2.0.27` to `2.0.28`. I have only encountered the problem using postres, while sqlite seems to work fine.

Is this a new expected behavior? Am I doing something wrong in this query or the session setup?
