Title

HttpStaticFileServer example double EmptyLastHttpContent results in exception

Description
The HttpStaticFileServerHandler has been observed to write 2 EmptyLastHttpContent for 1 response which results in a exception. HttpStaticFileServerHandler could result in generating a EMPTY_LAST_CONTENT as a result of HttpChunkedInput [Link: here]. HttpStaticFileServerHandler also explicitly writes a `LastHttpContent.EMPTY_LAST_CONTENT` [Link: here]
