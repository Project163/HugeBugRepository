Title

Builds Failing due to use of -X to set non-string during build

Description
Output of `helm version`: tip of main

Output of `kubectl version`: N/A

Cloud Provider/Platform (AKS, GKE, Minikube etc.): N/A

CI builds are failing because of the use of -X in the build scripts to set versions which are not strings.

This happened because of three things:

- The normal tests run on a PR do not test building Helm. The build scripts were not tested until the most recent change landed.
- #8608 made changes around linting. LDFLAGS -X were used to set a constants which are silently ignored.
- #10325 moved those constants to vars so they could be set.

This was not caught by CI on the PR but was caught when the second PR was merged into main.
