import time
from libmproxy.script import concurrent
from libmproxy.protocol.http import HTTPResponse
from netlib.odict import ODictCaseless

@concurrent
def request(context, flow):
    if flow.request.pretty_host(hostheader=True).endswith("example.com"):
        q = flow.request.get_query()
        if q:
            if q["q"]:
                url = "[URL] + ''.join(q["q"])
                resp = HTTPResponse([1, 1], 301, "Moved Permanently",

- Excellent, thanks. You'll have to update netlib, not mitmproxy, by the way. You still may be able to trigger the `Too many open files` error if you send too many requests through mitmproxy at once (see `ulimit -n`). However, we now clear up connections in TCP_WAIT_2 after a minute. In other words, if you run `lsof -n -p PID`, you should still see connections in TCP_WAIT_2 state, but if you wait a minute, the should be cleared up.
