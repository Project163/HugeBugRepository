Title

TypeDecorator / SchemaType combination not firing attachment events

Description
**Migrated issue, originally created by Adrian ([Link: @thiefmaster])**

We are using a custom class handling int-based enums (since 1.0 didn't have python-native enum support) with an autogenerated CHECK constraint. In 1.1 this constraint is not added anymore.

In the [Link: changelog entry] regarding TypeDecorator I couldn't see any reason why _set_table would not be called anymore.

```
python
from sqlalchemy import *
from sqlalchemy.orm import *
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.sql.sqltypes import SchemaType
... [Log Snipped] ...
Base.metadata.drop_all(e)
Base.metadata.create_all(e)
```

SQL emitted in 1.1:

```sql
CREATE TABLE foo (
        id SERIAL NOT NULL,
        enum SMALLINT,
        PRIMARY KEY (id)
)
```

SQL emitted in 1.0
```sql
CREATE TABLE foo (
        id SERIAL NOT NULL,
        enum SMALLINT,
        PRIMARY KEY (id),
        CONSTRAINT valid_enum_enum CHECK (enum IN (1, 2, 3))
)
```
