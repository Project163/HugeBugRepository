Title

Integer overflow with period_asfreq on 32-bit system

Description
This causes a lot of test failures on my system.

```
In [4]: ival_H = Period(freq='H', year=2007, month=1, day=1, hour=0)

In [5]: ival_H.asfreq('S','S')
---------------------------------------------------------------------------
ValueError                                Traceback (most recent call last)
... [Log Snipped] ...

ValueError: Value must be positive
```

The C code is ultimately doing `ival_H.ordinal * 60 * 60`, and trying to store the result in a `long` - which according to [Link: this table] will be 32 bits on my system, and therefore isn't enough to hold it. From the debugger, `lib.period_asfreq()` returns -1121299440, which is equal to `(ival_H.ordinal*60*60 & sys.maxsize) - sys.maxsize - 1`.

I've tried substituing `long long` or `int64_t`, but the problem persisted, so I must be missing something.
