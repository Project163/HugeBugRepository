Title

View missing getName() and return Helper name

Description
* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.7.6
* Platform and Target: nginx, php7.2, mariadb 10.3

### What you did
Working with some custom helpers getting the name of the controller who use the helper dosn't work anymore...

Before : cakephp 3.6.x
`$this->getView()->name`
Return : Administartors (Show screenshot)
[Image: www trombert test box manager login]

Now : cakephp 3.7.x
`$this->getView()->getName()`
Result : Call to undefined method CakeboxManager\View\CakeboxManagerView::getName()

`$this->getView()->get('name')`
Result : null

### What happened

View.php
```
    public function __get($name) {
        if (isset($this->_helperMap[$name]) && !isset($this->{$name})) {
            $config = ['enabled' => false] + (array)$this->_helperMap[$name]['config'];
            $this->{$name} = $this->_View->loadHelper($this->_helperMap[$name]['class'], $config);
            return $this->{$name};
        }
```

Here $name value = Url but it should be related to my Helper context attribute requested so $name = name = (Administrators)

### What you expected to happen

`$this->getView()->getName()` should return the protected attribute name value like `$this->getView()->getPlugin() `return the protected plugin value.
