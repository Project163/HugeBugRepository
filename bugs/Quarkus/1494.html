Qute: Incorrect behaviour with complex expressions

Description
### Describe the bug

I've created bean Validation for validation purposes

```
java
@RequestScoped
@Named("Validation")
public class Validation {

... [Log Snipped] ...
    }
}
```

I've tried to use method getViolations in my tag

```

... [Log Snipped] ...

```

```

```
