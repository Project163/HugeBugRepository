Title

HTTP 1.1 Host header not set correctly with camel-http4

Description
The HTTP 1.1 Host header is not set correctly when using the camel-http4 component as a proxy with bridgeEnpoint=true. 

 The original request Host header is set in the proxied request instead of the host of the service requested by the proxy (ref:  [URL] section 14.23). 

 This simple route shows the problem: 

  <route autoStartup="true" id="TestHost" xmlns:ns2="[URL] xmlns="[URL]
        <from uri="jetty: [URL]
        <to uri="https4://www.google.com?bridgeEndpoint=true&throwExceptionOnFailure=false"/> 
 </route>
