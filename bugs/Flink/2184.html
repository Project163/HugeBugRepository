Title

Incorrect JavaDoc in TypeExtractor.getBinaryOperatorReturnType

Description
The parameter  lambdaOutputTypeArgumentIndices  in the JavaDoc of  
  
  TypeExtractor.getBinaryOperatorReturnType  
  
 is described as a  Table of indices of the type argument specifying the  input  type. See example. , whereas it actually describes the table of indices of the output type.
