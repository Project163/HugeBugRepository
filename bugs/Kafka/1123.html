Discussion
- twbecker , thanks for reporting this.  

 Keeping the old message format during cleaning will be an easy fix. However, converting the message format to the latest version allows us to potentially deprecate the old message format in the future, even though we don't get more information on timestamp during conversion. Another point is that in the future, when copying the messages out to the new segment, we may want to use the compression type specified at the topic level instead of the original compression type. If we do that, the new message size could also be different. So, it's probably worth thinking through how to make the cleaner handle the case of write overflow.
