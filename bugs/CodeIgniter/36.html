Title

Callables returning false in set_rules pass validation

Description
Using the stable CI 3 release code.

The following code passes form validation when it should not:      

```
$this->form_validation->set_rules(
    'title', 'Title', [
        'required',
        function($value) {
            return false;
        }
    ]
);
```

This variation works as expected:

```
$this->form_validation->set_rules(
    'title', 'Title', [
        'required',
        [
            'foo',
... [Log Snipped] ...
    ]
);
```

The docs state either is supported:
