Title

Performing an OPTIONS on a JAX-RS subresource causes CXF to generate a 405 status instead of a 200 status

Description
If you OPTIONS the subresource of a JAX-RS resource, CXF's JAX-RS implementation returns 405 instead of 200. 

 If you OPTIONS a JAX-RS resource directly, CXF generates a 200.
Discussion
- Attaching a potential patch for this issue. 

 This patch copies the behaviour as seen in the working case in  JAXRSInInterceptor.processRequest  and applies it to  JAXRSInvoker.invoke . 

 Also added a systest so that this issue doesn't regress in the future.
