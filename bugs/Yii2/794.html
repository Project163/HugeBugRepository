Title

data param attribute does not allow setting key with name submit

Description
If we try to assign the `key` with the name `submit` when setting the `data-params` attribute, clicking the link will do nothing, maybe because it is reserved and set automatically, because as soon as i change the key name from `submit` to `Submit` it starts working, but it is not documented anywhere in the docs under the [Link: renderTagAttributes()]-detail)

### What steps will reproduce the problem?
```
  $model->id], [
    'class' => 'btn btn-primary',
    'data' => [
        'method' => 'POST',
        'params' => ['submit' => 'my-value'],
    ],
]
)?>
```
### What is the expected result?
clicking the link should submit the page to the desired link 

### What do you get instead?
nothing happens when clicking on the link
