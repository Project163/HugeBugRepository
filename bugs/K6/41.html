Title

Issues using k6/html

Description
I am having a lot of trouble using the k6/html module where the documentation doesn't seem to match reality. 

A couple of examples of issues:

1) Using the .attr (https://docs.k6.io/docs/selectionattrname) says that it should return a string but actually returns an array

2) Attempting to reading the data from an item says that the method doesn't exist, yet is listed in the docs [URL]

Are those not the correct docs?

Thanks.
Discussion
- Can you post the code that you use? With `k6 v0.25.1`, I tried with the example in doc, and it returns a string as expected.
- Sure here is an example of me trying to find all links in a navigation:

```
var home_page = http.get(...);
var parsed_page = html.parseHTML(home_page.body);
var nav_links = parsed_page.find('li.nav_item a').map(function(index, link) {
    return link.attr('href');
  });
```

That would return an array of arrays, where the second element was a boolean. In order to get what I wanted I had to do the following:

```
var home_page = http.get(...);
var parsed_page = html.parseHTML(home_page.body);
var nav_links = parsed_page.find('li.nav_item a').map(function(index, link) {
    return link.attr('href')[0];
  });
```
