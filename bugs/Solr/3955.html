Title

bin/solr {config,healthcheck} ignore ZK_HOST in solr.in.{sh,cmd}

Description
bin/solr config  and  bin/solr healthcheck  should be usable without specifying  -z  or  -solrUrl  params, if  ZK_HOST  is specified in  solr.in.sh / solr.in.cmd .
Discussion
- Some discussion in   SOLR-11108  , where the  bin/solr config  command was introduced, about intentionally not doing param parsing in  bin/solr , with one side-effect being  solr.in.sh / solr.in.cmd  ZK_HOST ignorance. 

 I'm writing up a patch that adds  config  command param parsing to  solr / solr.cmd .
- Attached a patch that pulls out  -z / -zkhost / -zkHost  and  -s / -scheme  cmdline params, and passes through all other params, so that  ZK_HOST  can be pulled from  solr.in.sh / solr.in.cmd  and overridden by cmdline params, and the same for  SOLR_URL_SCHEME . 

 I've manually tested on Linux; todo: test on Windows.
