Title

TypeError: Cannot read property 'type' of null

Description
I get this error when running eslint on my directory. I'm having trouble ignoring vendor files, so this was probably hit on some vendor file, possibly minimized.

```
$ eslint .

/usr/lib/node_modules/eslint/lib/rules/no-constant-condition.js:53
        if (alwaysSimpleConstantCondition.indexOf(field.type) !== -1 ||
                                                       ^
... [Log Snipped] ...
    at processFiles (/usr/lib/node_modules/eslint/lib/cli.js:189:27)
    at Object.cli.execute (/usr/lib/node_modules/eslint/lib/cli.js:251:22)
```
Discussion
- I see, you must have written a `ForStatement` with an empty `test`. Quoting the Spidermonkey AST spec:

The `test` may be `null`, causing an issue here: [URL] The question is whether we consider this a "constant condition" and would like the rule to report it, or if this case should be ignored by the rule. Once we decide that, I'd happily submit a patch.
- I think an empty test in a `for` loop should not trigger a warning. The spirit of this rule is to avoid `if (true)` and similar, I think omitting the condition doesn't fall into the same category.
- I will say, though, that if someone feels strongly that this should trigger a warning, I'm open to that argument.
