Title

yii\web\User::getIdentity() memoizes `null` if exception is thrown & caught

Description
### What steps will reproduce the problem?

1. Write some code that will cause an exception to be thrown somewhere in the course of `yii\web\User::renewAuthStatus()`.
2. Call `yii\web\User::getIdentity()` within a try/catch, catching the exception and letting the app continue running.
3. Call `yii\web\User::getIdentity()` again, but not within a try/catch.

### What is the expected result?

The exception would be thrown again; this time bubbling up to the browser.

### What do you get instead?

`null` is returned, as if no user is logged in.
