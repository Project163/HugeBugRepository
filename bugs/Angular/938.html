Title

Placeholder texts in code examples of angular.io markdown content do not display in the browser

Description
# 📚 Docs or angular.io bug report

### Description
Placeholder texts (enclosed inside angle brackets - like ` `) inside `  ` tags on the markdown content for [Link: angular.io] do not display on browsers. Instead they are treated as opening html tags without matching closing tags.

## 🔬 Minimal Reproduction

### What's the affected URL?

- [Link: Configuring serve for ES5]
- [Link: Configuring the e2e command]

### Reproduction Steps

1. Open the above affected URL(s) in any browser of your choice.
1. Scroll down till the paragraph which contains information about replacing ` ` in the provided configuration. There are two instances:
   - **Instance 1** under [Link: Configuring serve for ES5]:
   - **Instance 2** Under [Link: Configuring the e2e command]:
1. Check the provided configuration above this paragraph for instances of ` `.

### Expected Behavior
I was hoping to find ` ` somewhere in the provided configuration.

### Actual Behavior
I can NOT find any instances of ` ` in the provided configuration.
