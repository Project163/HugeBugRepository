Title

Improve NuGet package README

Description
The [Link: README for the NuGet package] has a few broken bits of HTML due to CSP restrictions and HTML rendering differences compared to when rendered in GitHub which result in a few bits looking broken.

We should either:
1. Change the README to be compatible with rendering in NuGet.org;
2. Create a separate README that's more bare-bones and links back to the main repo README.

I think option 2 is better as it doesn't send us down the path of the lowest common denominator.

Other thoughts?
Discussion
- My vote would be the second option. Right now I feel the info that is provided on NuGet might be too overwhelming for casual viewers.
- Cool - I'll push up a PR for this this morning so we can include it in the alpha, as it's also a good way to check how it renders.
