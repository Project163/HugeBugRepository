Title

Failure to handle && inside || conditional in while

Description
Given classes 

```
php
class Obj {}
class A extends Obj {
    /** @var A|null */
    public $foo;
... [Log Snipped] ...
    public $bar;
}
```

Psalm fails to understand a nested `&&` conditional inside an `||`
```
php
function bar(Obj $node) : void {
    while ($node instanceof A
        || $node instanceof B
        || ($node instanceof C && $node->bar instanceof A)
... [Log Snipped] ...
    }
}
```
Expected: No issue
Actual: Cannot resolve types for $node - docblock-defined type A|C|null does not contain B
