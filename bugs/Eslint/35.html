Title

no-extend-native.js 'length' of undefined

Description
I'm getting the following error with the latest eslint version.

```
Cannot read property 'length' of undefined
```

**File**: [Link: lib/rules/no-extend-native.js line 33]

The `node.left.property` that caused this error looks like this:

```
{ 
  type: 'Literal',
  value: 'flag-asc',
  raw: '\'flag-asc\'',
  range: [ 11392, 11402 ],
... [Log Snipped] ...
   }
 }
```

There isn't a name property so it can't call the length property of the missing property.

A way to fix this would be to change L33 to:

```
var hasLength = node.left.property.name && node.left.property.name.length > 0;
```

I don't know if this creates unexpected behavior or if it's the correct way.

Cheers
