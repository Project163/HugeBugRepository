Title

Mypy thinks `dict[Never, Never]` is a subtype of `Mapping[str, object]`

Description
This behaves as expected: [URL]

```python
from typing import Mapping, Never

def upcast(d: dict[Never, Never]) -> Mapping[str, object]:
    return d  # E: [return-value] (✅ expected)
```

But it breaks here (due to caching?) [URL]

```
python
from typing import Mapping, Never

def get[Link: M: Mapping[str, object]] -> M:
    return arg
... [Log Snipped] ...
def upcast(d: dict[Never, Never]) -> Mapping[str, object]:
    return d  # <-- No error anymore 😱
```
Discussion
- @sterliakov @ilevkivskyi This was only partially fixed; the caching part is adressed but `mypy` still incorrectly reveals `dict[Never, Never]` on master branch.

[URL]

```python
from typing import Mapping, Never

def get[Link: M: Mapping[str, object]] -> M:
    return arg

reveal_type(get({}))  
```

```
main.py:6: note: Revealed type is "builtins.dict[Never, Never]"
```

But `dict[Never, Never]` is not a subtype of `Mapping[str, object]`...
