Title

camel-yaml-dsl - Multicast EIP does not have output added correctly

Description
- multicast:
                steps:
                  - kamelet:
                      name: postgresql-sink
                      parameters:
                        serverName: localhost
                        serverPort:  '5432' 
                        username: postgres
                        password: postgres
                        databaseName: demo
                        query: >-
                          INSERT INTO parcels (id,address) VALUES
                          (:#id,:#address) ON CONFLICT (id)  DO NOTHING
                  - kamelet:
                      name: kafka-not-secured-sink
                      parameters:
                        topic: parcels
                        bootstrapServers: localhost:9092
                aggregationStrategy: >-
                  # class: org.apache.camel.processor.aggregate.UseOriginalAggregationStrategy
                parallelProcessing:  true 
                streaming:  false 
 
  

 The mutlicast EIP has 2 outputs, but the 2nd kamelet is added as output on the 1st kamelet because of yaml dsl flow mode
Discussion
- That was on purpose as kamelet EIP is special as it has outputs, so you should do 
  
 
            - multicast:
                steps:
                  - to:
                      uri:  "kamelet:kafka-not-secured-sink" 
                      parameters:
                        topic: parcels
                        bootstrapServers: localhost:9092
                  - to:
                      uri:  "kamelet:postgresql-sink" 
                      parameters:
                        serverName: localhost
                        serverPort:  '5432' 
                        username: postgres
                        password: postgres
                        databaseName: demo
                        query: >-
                          INSERT INTO parcels (id,address) VALUES
                          (:#id,:#address) ON CONFLICT (id)  DO NOTHING
