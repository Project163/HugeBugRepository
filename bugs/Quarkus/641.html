Title

Security provider configuration not working

Description
* OpenJDK 11u (latest)
* Graal 20.1
* Quarkus and Camel Quarkus master

Security providers configuration does not seem to be working, see [URL]

Adding an `application.properties` with:

```
quarkus.security.security-providers=SunJCE
```

Does not work and the following warning is shown:

```
15:37:55,313 WARN  [io.qua.config] Unrecognized configuration key "quarkus.security.security-providers" was provided; it will be ignored
```

Also, the [Link: documentation] is inconsistent, mentioning both `quarkus.security.security-providers` and `quarkus.security.users.security-providers`. Neither works. The [Link: config reference] only mentions `quarkus.security.security-providers`.
Discussion
- Issue was that the security extension had not been added as dependency. The warning message should provide a hint on that. I'll send a PR tomorrow with this and a fix to docu.
