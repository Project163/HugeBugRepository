Discussion
- This is a bug in ngtsc.

When we statically interpret the `ɵngcc1.UIRouterModule` type expression we lose the fact that it is jumping to another file (probably because of the namespaced import). So then ngtsc thinks that `UIRouterModule` was declared inside `@uirouter/angular-hybrid` rather than `@uirouter/angular`. Therefore it thinks that `UIRouterModule` is an internal non-exported class inside `@uirouter/angular-hybrid`, which is basically what the error message is telling us.

Working on a fix :-)
- Very cool, thanks a lot for looking into this so quickly @petebacondarwin
- Just a note for anyone who gets here through google like I did, this same error messages occurred when I accidentally imported a module from my library using a deep path instead from @scope/mylib.
