Title

Entity methods behavior inconsistency?

Description
This involves four methods in `\Cake\Datasource\EntityTrait` and how each works, their naming seem to have an unexpected behavior.

`get()` function returns the value of a single property, if a property has been changed the new values will be presented. Unchanged values are also presented.

```
php
    /**
     * Returns the value of a property by name
     *
     * @param string $property the name of the property to retrieve
... [Log Snipped] ...
     */
    public function &get($property)
```

`extract()` function returns an array of properties from the requested array of properties. Allows you to get multiple properties all at once, but same as `get()` where changed properties get the new values, and unchanged values are also presented.

```
php
    /**
     * Returns an array with the requested properties
     * stored in this entity, indexed by property name
     *
... [Log Snipped] ...
     */
    public function extract(array $properties, $onlyDirty = false)
```

`getOriginal()` function returns the original value of a single property if changed, **and the current value if was not changed.** Behaves like `get()` in that it is a single value, but ensures only the original data is presented.

```
php
    /**
     * Returns the value of an original property by name
     *
     * @param string $property the name of the property for which original value is retrieved.
... [Log Snipped] ...
        return $this->get($property);
    }
```

Then it is expected that `extractOriginal()` would be an extension of `getOriginal()` but with the `extract()` output. Meaning, I would expect `extractOriginal()` to return an array of properties with their original values if they were changed, otherwise present me with the current value, from the requested array list of properties.

However, `extractOriginal()` only gives the original of the changed values, **and null/unset for where the values remained the same**, not as you would expect it to behave like `getOriginal()`.
