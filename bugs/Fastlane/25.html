### Issue Description

I'm running commands directly in `Spaceship` to fetch the group for each app_id we have in `iTunes Connect`. We have 44 apps now and we do login once first:

`Spaceship::Tunes.login`

Then for each `app_identifier` in iTunes Connect we do the following commands to fetch groups:

- `app = Spaceship::Tunes::Application.find(app_identifier)`
- `external_group = Spaceship::TestFlight::Group.all(app_id: app.apple_id)`

The output from this call is fine for the 1st app:

```
[ ]
```

But when we do this again with a new app_identifier:

- `app = Spaceship::Tunes::Application.find(app_identifier2)`
- `external_group = Spaceship::TestFlight::Group.all(app_id: app.apple_id)`

*We get the exact same result.*

Looking at the source code for [Link: test_flight/client.rb], I can see that the function `get_groups(app_id: nil)` for getting groups does the following`return @cached_groups if @cached_groups`. And I cannot see any way to reset the cache. 

How can I get around this or reset the cache so I can get groups for more than one app in a Test Flight session?
