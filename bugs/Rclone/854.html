Title

Option `--quiet` fails to prevent logging

Description
#### What is the problem you are having with rclone?

When using `rclone config update` the tool will print to stdout the configuration of the remote you updated even if you have the `--quiet` flag set.


#### What is your rclone version (output from `rclone version`)
```
rclone v1.69.0-DEV
- os/version: nixos 24.11 (64 bit)
- os/kernel: 6.6.59 (x86_64)
- os/type: linux
- os/arch: amd64
- go/version: go1.23.3
- go/linking: dynamic
- go/tags: none
```

#### The command you were trying to run (e.g. `rclone copy /tmp remote:tmp`)
`rclone config -q update ari key value`


#### A log from the command with the `-vv` flag (e.g. output from `rclone -vv copy /tmp remote:tmp`)
```
➜  ~ rclone config -q update ari key value
[ari]
host = ari
key_file = /home/jess/.ssh/id_ed25519
type = sftp
user = jess
key = value
```
