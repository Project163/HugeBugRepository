Title

InternalPreserveStackTrace is not supported on all Portable platforms

Description
Attempting to use the portable framework on Windows Phone, I got the following exception,

```
An exception was thrown while loading the test.
System.TypeInitializationException: The type initializer for 'NUnit.Framework.Internal.AsyncInvocationRegion' threw an exception. ---> System.InvalidOperationException: The API 'System.Exception.InternalPreserveStackTrace()' cannot be used on the current platform. See [URL] for more information.
```

The problem code is in `AsyncInvocationRegion`,

```
C#
#if NET_4_0 || PORTABLE
        private static readonly Action  PreserveStackTrace;

        static AsyncInvocationRegion()
... [Log Snipped] ...
        }
#endif
```

I need to check, but I think that the `GetMethod` call is throwing an `InvalidOperationException` rather than returning null. 

This issue is blocking Windows Phone support, nunit/nunit.runners#4
