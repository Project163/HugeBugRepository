## Problem Description
When trying to use `Timestamp` via `NaiveDateTime` using the `MultiConnection` it reports there is no `ToSql`, and probably it will also complain there is no `FromSql`, but i haven't gotten that far yet.

Discussion
- Ok, i did some checking, and it basically is the same issues as it was with #3747.
It is just missing the correct from/to sql impl's generated via `generate_bind_collector`.

The issue i have is that I'm somehow unable to conditionally generate them if chrono is enabled or not.
Adding `chrono = []` to `diesel_derives` and `chrono = ["diesel_derives/chrono", "dep:chrono"]` doesn't seem to pass this feature on. Or something with `quote!` is not handling it for some reason.

If i just ignore the features and just add `use chrono::NaiveDateTime` to `mod multi_connection_impl` and add `(quote::quote!(diesel::sql_types::Timestamp), quote::quote!(NaiveDateTime))` to both the `to_sql` and `from_sql`, it seems to work for me.

Hopefully this makes fixing the issue a bit more easier :)
