Title

Can not post body to custom management endpoint in DEV mode

Description
### Describe the bug

Hi, I am trying to accept simple `plain/text` on a post endpoint.
```
Kotlin
class Management {
    fun registerManagementRoutes(@Observes mi: ManagementInterface) {
        mi.router()
            .post("/test")
... [Log Snipped] ...
    }
}
```

### Expected behavior

```
curl -X POST [URL] -H "Content-Type: plain/text" -d hello --verbose
```
should return "Received: hello"
