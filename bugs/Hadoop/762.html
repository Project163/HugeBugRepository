Title

test-patch.sh fails during mvn eclipse:eclipse if patch adds a new module to the build

Description
test-patch.sh tries running mvn eclipse:eclipse after applying the patch.  It runs this before running mvn install.  The mvn eclipse:eclipse command doesn't actually build the code, so if the patch in question is adding a whole new module, then any other modules dependent on finding it in the reactor will fail.
Discussion
- I found this while working on   HADOOP-8924  , which adds a new module for a custom Maven plugin used to generate version info.  This patch solves the problem by moving the mvn eclipse:eclipse check after the mvn install.
