Title

Load() objects aren't picklable

Description
even though they have a getstate, the context has mappers and relationships in it and these fail to pickle immediately:

```
import pickle

from sqlalchemy import Column
from sqlalchemy import ForeignKey
from sqlalchemy import Integer
... [Log Snipped] ...
l2 = Load(A).selectinload(A.bs)
pickle.dumps(l2)
```

the unboundload object doesn't have a context so *is* picklable.

I'm not really sure how to solve this problem since Load needs to have that context.
Discussion


this appears to occur if you try to pickle a mapper or a relationship object.   don't know what a "quitter" is, looks like locals() are getting in there somehow.
- also pickling mappers and relationships is not practical in any case without the registry approach used by the "serializer" extension.    otherwise you'd get back a new mapper / relatinoship that isn't the one tracking the class and that wouldn't work.
