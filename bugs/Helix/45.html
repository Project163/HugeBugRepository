Title

"backtab" key (S-tab) does not work when remapped

Description
### Reproduction steps

In my `config.toml` I have:
```
[keys.insert]
"backtab" = "normal_mode"
``` 
...but pressing "S-tab" does not exit insert mode as I expect.  (I also tried mapping "S-tab", with no luck either.)

In fact, trying to map "backtab" even during normal mode doesn't work.  I added:
```
[keys.normal]
"backtab" = "move_next_word_start"
```
...and nothing happens on "S-tab".  The same is of course true if I map "S-tab" to the command.

Other shift keymaps work.  For example, "S-ret" is working fine.

  

### Environment

- Platform: Windows 10 
- Helix version: 0.5.0
