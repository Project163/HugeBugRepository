Title

NUnit should apply attributes even if test is non-runnable

Description
See the issue nunit/nunit3-vs-adapter#27 for an example of why this is important.

Currently, NUnitTestCaseBuilder does not apply attributes to a test if it's signature is invalid. We should apply them in general and each attribute must check that the test is runnable if it matters for that particular attribute.
