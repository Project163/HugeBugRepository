Title

Description
Hello.

I'm using MySQLi

        $query  =  $this->db->select( array( 'gebruikers.id as gebrId',
                                             'gebruikers.naam as gebrNaam',
                                             'gebruikers.online as online',
                                             'naw.*')
                                    )
                            ->from('gebruikers')
