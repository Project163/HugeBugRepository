Title

bad kwarg to exception init is not caught

Description
Originally reported by: **Mike Frysinger (BitBucket: [Link: vapier], GitHub: @vapier?)**

---

consider this exception usage.  pylint should have warned, but did not.  using pylint 1.4.0.

```
#!python
class Foo(Exception):
  def __init__(self, val=True):
    self.val = val
    super(Foo, self).__init__()

f = Foo(badarg=1)
```

it is caught when using classes (change "Exception" to "object" in the snippet above) or functions
