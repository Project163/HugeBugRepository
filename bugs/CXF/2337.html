- The fix  is simply to catch the ClassCastException and return it as an InternalServerErrorException: 

 catch (ClassCastException e)  
{ 
            String msg = "Unsupported class: " + source.getName();
            throw ExceptionUtils.toInternalServerErrorException(null, serverError(msg));
 }
