Title

Reflect is broken on `hashbrown::HashMap `

Description
## Bevy version

0.16.0

I have `#[derive(Reflect)]` on a type containing `hashbrown::HashMap ` where K and V are both Reflect. This gives me some compile error saying that the type is not reflectable.

If I switch to `bevy::platform::collections::HashMap ` instead, the error disappears.
Discussion
- `Reflect` is implemented for `HashMap` via the `impl_reflect_for_hashmap!` macro, and in the process of creating a wrapper around it in #18694, we unintentionally removed the impl for the hashbrown version I'm pretty sure.
- I should have a fix up shortly!
