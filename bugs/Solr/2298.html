Title

Unclear error message with solr script when lacking jar executable

Description
Fedora 21 doesn't ship the "jar" executable with the default jdk package, so the attempt to extract "webapp/solr.war" in the solr script can fail without a clear error message. The attached patch adds this error message and includes support for the unzip utility.
