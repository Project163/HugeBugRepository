Title

False positive with Python 2 old-style raise statement

Description
This generates an error, even though it's valid at runtime:
```py
raise Exception(), None, None  # First argument must be BaseException subtype
```

An exception instance is valid if the second object is `None`: [URL]

It looks like python/mypy#11289 forgot to handle this case.

Since this is a regression and we are close to cutting a release branch, I'm planning to revert python/mypy#11289 for now. It can be merged again with a fix to the special case.
