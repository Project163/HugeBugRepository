Title

Device ID should be read-only and "nearby devices" should be hidden when adding a new pending device

Description
1. On Device A, add Device B as a new remote device.
2. On Device B, click the "Add" button on the pop-up asking to add a new device.
3. The ID of Device A is automatically filled in, but at the same time it is also listed below under "you can also select one of these nearby devices".

I think that either the language should be changed (as currently it suggests that the ID below and the ID above belong to different devices despite being actually identical), or the ID listed below should automatically be hidden if the exact same ID is already filled in in the input field above.

Discussion
