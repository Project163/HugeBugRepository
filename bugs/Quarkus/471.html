Title

Spring Data JPA - ContainingIgnoreCase is not working

Description
**Overview**
Seems that not all keywords (or combination between them) from [Link: JPA Query Creation methods] are supported.
**Test Project**
[URL]
**Describe the bug**
- Create a simple project using `quarkus-spring-data-jpa` module
- Create an `@Entity` POJO with string field in it (`name` for example)
- Create a repository extending `JpaRepository`
- Add method to the repository `List  findByNameContainingIgnoreCase(String partialName)`
- Try to start the project

**Expected behavior**
Project to start normally 

**Actual behavior**
Exception is raised that the method/field `NameContaining` is not found

**Additional Notes**
This wasn't tested, but I suspect that will not going to work either: `List  findByNameStartingWithIgnoreCase(String partialName)`
