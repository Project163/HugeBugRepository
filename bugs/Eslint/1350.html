Title

can't get plugin rules by `CLIEngine#getRules`

Description
**Tell us about your environment**

* **ESLint Version:**
6.0.0

`cli.getRules().get(ruleId)` used can get plugin rule, now not.

Is this by design or a bug?



```js
new (require('eslint').CLIEngine)().getRules().has('yoda')
// -> true
```

```js
new (require('eslint').CLIEngine)({plugins: ['unicorn']}).getRules().has('unicorn/no-process-exit')
// -> false, should be true
```
Discussion
- After a few tries, I found after calling `executeOnText` or `executeOnFiles`, rules appeared, but calling `getConfigForFile` (which is I used before and works in  [URL] ) plugin rules are not loaded.
- Yes, currently, it returns core rules and the plugin rules that the last `execute*` method call used.
