Title

AutoTimestamp behaviour issue for creating

Description
Have following configuration for the model:

```
public function behaviors()
    {
        return array(
            'timestamp' => array(
                'class' => 'yii\behaviors\AutoTimestamp',
... [Log Snipped] ...
        );
    }
```

and simple execution:

```
        $comment = new SomeModel;
        $comment->content = 'test';
        $comment->save();
```

After save 

Updated field is generated.
Created field is empty.

Database columns identical and correct.

So some issue with event or AutoTimestamp

With Yii1 was using CTimeStampBehaviour and everything was ok with the models.
Discussion
- You should assign an array of `created` and `updated` to `ActiveRecord::EVENT_BEFORE_INSERT`.
- He probably misused because of the advanced app example
