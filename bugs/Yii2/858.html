Title

yii.activeForm.js multiple select validation problem

Description
When you have a multiple dropDownList like:

` field($model, 'bla')->dropDownList(['test' => 'test', 'foo' => 'foo'], ['multiple' => 'multiple']) ?>`

And the field is validated (it is for example required)
If you go to the view containing the form, and another field is validated (changed of blurred) then this field is also validated.
This is due the getValue function in yii.activeForm.js
This function gets the value for the field as array like ["test", "foo"] (when both selected)
But in the function "validateAttribute" also in yii.activeForm.js, the old value and new value are compared like:

`if (this.value !== getValue($form, this)) {`

This will always match when arrays are compared in javascript, so the field will be always validated even when there are no changes.
