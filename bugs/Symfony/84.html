Title

[Routing][WDT][2.3] Routes parameters are not shown in the debugger panel

Description
On route match, routes parameters are not shown in the debugger panel (when the pattern `/hello/{name}` is used to match the `/hello/world` url, we should see `name => 'world'` in the upper table of the panel - nothing is shown instead).

This seems due to the fact that the table data are based on [Link: request.routeParams] which come from the [Link: RequestDataCollector] however this parameter is not an array as expected but it has been previously [Link: transformed to a string representation].
