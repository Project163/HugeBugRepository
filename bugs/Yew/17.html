Title

Rust-analyzer warnings in #[derive(Properties)] macros

Description
**Problem**
Hello,
rust-analyzer show a warning in every #[derive(Properties)] macro.

For example with:
```rust
#[derive(Properties, Clone, PartialEq)]
pub struct Props {
    pub label: String,
    pub value: String,
}
```
it will show
```
Structure `PropsBuilderStep_missing_required_prop_label` should have CamelCase name, e.g.
`PropsBuilderStepMissingRequiredPropLabel` rust-analyzer(incorrect-ident-case)
Structure `PropsBuilderStep_missing_required_prop_value` should have CamelCase name, e.g.
`PropsBuilderStepMissingRequiredPropValue` rust-analyzer(incorrect-ident-case)
```

**Environment:**
 - Yew version: `git master`
 - Rust version: `latest stable`
 - Build tool: `VS Code`
 - OS: `Windows 10`

Discussion
- Out of interest, do you get this warning with `cargo check` or is it rust-analyzer specific?

If it's not specific to rust-analyzer then one way to fix this would be to add an `#[allow(non_snake_case)]` attribute to the outputted code from the macro (I think).

If you'd like to do that, great! Otherwise I'm happy to submit a patch.
- It's rust-analyzer specific because it check macro generated content. Adding `#[allow(non_camel_case_types)]` works well, tho.
