Title

`config.module.rule[].resolve` didn't merge with `config.resolve`

Description
# Bug report

 
 
 
 

**What is the current behavior?**

### config.module.rule[].resolve not merge with config.resolve

I'm using the `resolve` option in `config.module.rule[]` , because it can be work with  `include` option.

**If the current behavior is a bug, please provide the steps to reproduce.**

```
js
// webpack.config.js
module.exports = {
  resolve: {
    alias: {
... [Log Snipped] ...
  }
}
```

 
 
 
 
 
 

**What is the expected behavior?**

alias `@` work perfectly. but alias `abc` not work in `./src/xxxx.js`.

Because `config.module.rule[].resolve` didn't merge with `config.resolve`.

Unless: 
```
js
module.exports = {
  resolve: {
    alias: {
      abc: 'efg'
... [Log Snipped] ...
  }
}
```

webpack version:  4.29.6
Node.js version:  10.15.0
Operating System:  Windows 10
Additional tools:  yarn
