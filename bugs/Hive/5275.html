Title

HS2 Stopped when running in background

Description
To reproduce, start HS2 in background like  hive --service hiveserver2 & , and run some query from beeline using Tez or Spark as engine. 
I think it's similar to   HIVE-6758  : HS2 uses jline for the in-place progress update, and receives SIGTTOU when trying to call stty.
Discussion
- I think we should add the same check to HS2 as we added to beeline. Wondering whether it makes sense to just put the check in  bin/hive  - to avoid redundancy and prevent user from bypassing the check by directly calling  hive --service .
