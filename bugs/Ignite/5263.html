Title

System Thread pool starvation and out of memory

Description
We are experiencing thread pool starvations and after some time out of memory exceptions in some of our ignite client nodes while the server node seems to be running without any problems. It seems like all sys threads are stuck when calling MarshallerContextImpl.getClassName. Which in turn leads to a growing worker queue.
