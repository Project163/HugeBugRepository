Title

`I as array-key` and `is_string`

Description
[URL]

```
/**
 * @template I as array-key
 * @template T
 */
abstract class Collection {
... [Log Snipped] ...
    }
}
```

Results to 

```
ERROR: DocblockTypeContradiction - 16:14 - Found a contradiction with a docblock-defined type when evaluating $key and trying to reconcile type 'I as array-key' to string

INFO: MixedOperand - 17:22 - Left operand cannot be mixed
```

Same result when replacing `array-key` with `int|string`.
Discussion
- Seems like a regression that has been introduced between 3.4.5 and 3.4.6
- Or, it appears, anything else.
- Simpler repro:

```php
/**
 * @template I
 * @param I $foo
 */
function bar($foo): void {
    if (is_string($foo)) {}
}
```
