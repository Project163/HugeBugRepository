Title

XML NodeList.add(index, Node) does not work as expected

Description
The following test fails - the new node is always inserted at the end of the list 

  
 def xml = "<parent><child id=\"1\"/></parent>"
def parent = new XmlParser().parseText(xml)
def node = new Node(parent, "child", [id:"2"])
parent.child.add(0, node)
assert parent.child[0] == node
 
  

 The following test fails too - In this case, the second assertions fails - the node is inserted twice! 

  
 def xml = "<parent><child id=\"1\"/></parent>"
def parent = new XmlParser().parseText(xml)
def node = new Node(parent, "child", [id:"2"])
parent.children().add(0, node)
assert parent.children()[0] == node
assert parent.children()[2] != node
Discussion
- Hi, 
I looked into this issue a bit and I think I can add a few things here to get started. I am no xml or groovy-xml expert , so I am just going to say things based on what I see in the implementation. 

 So, a few things that should help reduce the confusion: 

 1) As soon as you say "def node = new Node(parent, "child",  [id:"2"] )", you add "node" as a child of node parent. So, if you check the value of "parent.child.size()" before and after the node declaration above, you will see a difference of 1. The explicit add() call is not needed. 

 2) There is a difference in accessing list of child nodes as "parent.child" and "parent.children()". "parent.child" constructs a new node list and adds child nodes to it whereas parent.children() returns the original copy. parent.children() is based on groovy.util.Node API but parent.child is a general feature that can be seen at play in following snippet: 
  
  class  Dummy {
    def id
}
def dlist = []
dlist <<  new  Dummy(id: '1' )
dlist <<  new  Dummy(id: '2' )
println dlist.id  // list.id = a  new  list made-up of id attribute of each Dummy instance that is in dlist 
 
  

 So, coming to your first piece of code: 

  
 def xml =  "<parent><child id=\" 1\ "/></parent>" 
def parent =  new  XmlParser().parseText(xml)
def node =  new  Node(parent,  "child" , [id: "2" ])  // now node is already a child of parent - added after first child
 parent.child.add(0, node)  //  this  does not affect anything as it is working on the nodelist copy
  assert  parent.child[0] == node  // fails because parent.child[0] is the original child1 
 
  

 In your 2nd piece of code, you do: 
  
 def node =  new  Node(parent,  "child" , [id: "2" ])  //  this  adds node as the 2nd child
 parent.children().add(0, node)  // node gets added again at index 0, so parent has node, child1, node as children now. 
 
  

 What you can do is: 
  
 def xml =  "<parent><child id=\" 1\ "/></parent>" 
def parent =  new  XmlParser().parseText(xml)
def node =  new  Node(parent,  "child" , [id: "2" ])  // adds node as 2nd child
 parent.remove(node)  // removes node from parent's children
 parent.children().add(0, node)  // re-inserts node at desired position in child list
  assert  parent.child[0] == node
 
  

 There may be better ways of doing it, but I hope I have highlighted what was wrong in your given code.
