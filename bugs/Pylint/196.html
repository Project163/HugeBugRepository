Title

Description
### Steps to reproduce
1. Create a file named ```bug.py``` with the following lines:
```
#!/usr/bin/env python
# -*- coding: latin-1 -*-
'''Test pylint bug'''

countries = {
    'Åland Islands' # pylint: disable=missing-final-newline
}
```
2. Run ```pylint bug.py```

- Output is:
```
/Users/.../python2.7/site-packages/pylint/checkers/format.py:1012: UnicodeWarning: Unicode equal comparison failed to convert both arguments to Unicode - interpreting them as being unequal
```
