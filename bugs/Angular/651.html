- @titusfx In short, yes. 

The *ngIf directive is a structural directive with the asterisk character * being a syntatic sugar, and it expects you to pass ` ` for the else condition's `TemplateRef` in the [Link: ngIf directive code] to grab the referenced markup correctly. When you write ` Test `, it really becomes this:
```
 
     Test 
 
```

And when you write this:
```
 Test 
 
     Else template 
 
```
It gets desugared to something like this (I'm not 100% sure on this desugaring):
```
 
     Test 
 
 
     Else template 
 
```
