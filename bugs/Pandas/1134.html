Title

uninteded cast to float in pivot_table with margins=True

Description
#### Code Sample, a copy-pastable example if possible

```
python
In [2]: df = pd.DataFrame({"A": [1, 2, 3], "B": [4, 5, 6], "C" : [7,8,9]})

In [3]: df.pivot_table('C', 'A', 'B', fill_value=0)
Out[3]: 
... [Log Snipped] ...
3    0.0  0.0  9.0  9.0
All  7.0  8.0  9.0  8.0
```
#### Problem description

There is no reason why adding the totals row and column should cast to float.

#### Expected Output
```
python
In [5]: df.pivot_table('C', 'A', 'B', fill_value=0, margins=True).astype(int)
Out[5]: 
B    4  5  6  All
A                
... [Log Snipped] ...
3    0  0  9    9
All  7  8  9    8
```
