Title

Json reader crashes when a different schema is present

Description
When using pyspark 3.4, we noticed that when reading a json file with a corrupted record the reader crashes. In pyspark 3.3 this worked fine. 

  Code : 
  
 
from pyspark.sql.types  import  StructType, StructField, IntegerType, StringType
 import  json

data =  """[{" a ": " incorrect ", " b ": " correct "}]" ""
schema = StructType([StructField( 'a' , IntegerType(), True), StructField( 'b' , StringType(), True), StructField( '_corrupt_record' , StringType(), True)])

spark.read.option( "mode" ,  "PERMISSIVE" ).option( "multiline" , " true " ).schema(schema).json(spark.sparkContext.parallelize([data])).show(truncate=False)
