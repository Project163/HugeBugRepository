Title

registerJsFile not seeing webroot correctly when depends used

Description
So I have:

```
$this->registerJsFile('js/models/Product.js', ['backend\assets\BackboneAsset']);
```

Which without the filled in `depends` option creates a URL to:

```
@webroot/js/models/Product.js
```

Which resolves to:

```
[URL]
```

However as soon as I use the depends parameter in the `registerJsFile` function it omits `@webroot` and goes straight for `@root` only creating:

```
[URL]
```

This seems like a bug in how it creates the asset manager here: [URL] (or at least I hope it is a bug, aliases don't work here so I would have to manually write out `system-w` everytime)
