Title

isinstance check does not narrow inferred type correctly on nested Union type

Description
```
py
from typing import Union

class A: pass
class B: pass
... [Log Snipped] ...
    else:
        reveal_type(bar)
```
The last line reveals `Union[A, B, C]` when it should be just `Union[B, C]`. It works if the type of `bar` is replaced by `Union[A, B, C]`.

(Of course you'd probably never directly write `Union[Link: Union[A, B], C]`, but it's reasonable to write `Union[AB, C]` where `AB` is an alias for `Union[A, B]`. And the typing module documentation says [Unions of Unions are flattened].)
Discussion
- Is this still failing on master?
- Yes, I just checked this. Probably this is because interaction of ``restrict_subtype_away`` and ``is_proper_subtype`` misses the case of nested unions.
