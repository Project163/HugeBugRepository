- При работе с табличным вводом и указании нужного id поля к примеру получается вот такое поле :
input type="text" id="1_1_use_duration" class="form-control" name="Prescription[1][1][use_duration]" aria-required="true"
Допустим, поле обязательное и прошла валидация с ошибкой:
"1_1_use_duration":["Необходимо заполнить «Курс в днях»."]

Сейчас виджет activeField формирует вот такой json

jQuery('#w0').yiiActiveForm([
{"id":"prescription-1-use_duration","name":"[1]use_duration","container":".field-1_1_use_duration","input":"#1_1_use_duration","error":".invalid-feedback","enableAjaxValidation":true}
]

А должен
{"id":"1_1_use_duration","name":"[1]use_duration","container":".field-1_1_use_duration","input":"#1_1_use_duration","error":".invalid-feedback","enableAjaxValidation":true}

Чтоб все верно заработало необходимо внести правку, описанную выше
