Title

Missing collision detection

Description
Function _collide_ in _collide_aabb_ misses to detect a collision if the two objects are intersecting but not by a side.
Maybe is my idea of collision but the two following objects should be detected as colliding:

```
let a_pos = Vec3::new(8.0, 0.0, 0.0);

let a_size = Vec2::new(10.0, 10.0);

let b_pos = Vec3::new(8.0, 0.0, 0.0);
... [Log Snipped] ...
let collision = collide(a_pos, a_size, b_pos, b_size);
println!("collision {:?}", collision); // ... I expect to have a collision here
```
It's more evident if we check the behavior on moving objects:

```
let mut a_pos = Vec3::new(0.0, 0.0, 0.0);
let a_size = Vec2::new(10.0, 10.0);

let b_pos = Vec3::new(8.0, 0.0, 0.0);
let b_size = Vec2::new(6.0, 100.0);
... [Log Snipped] ...
	}
}
```
The problem is the heuristics to determine the side of collision.
An easy solution is to add a generic Collision::Intersecting collision.

I attach my proposed patch here (with tests)
