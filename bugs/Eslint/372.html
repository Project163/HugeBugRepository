Title

parens around object confuse "dot-location": [2, "property"] rule

Description
With this rule:

```
    {
        "dot-location": [2, "property"]
    }
```

And this code:

``` js
(console)
  .log("hi");
```

There's this error:

```
  t.js:1:8: Expected dot to be on same line as property.
```

The parens around `console` seems to confuse the rule, because this works without error, as expected:

``` js
console
  .log("hi");
```
