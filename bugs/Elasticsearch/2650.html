Title

SQL: Empty result set on aggregates with filter foldable to false

Description
`select count(*), max(languages) from test_emp where first_name = 'yoda'` retrieves
```
   count(*)    |max(languages) 
---------------+---------------
0              |null           
```

but if the condition is replaced with something that can be folded to false the result set becomes empty:
`select count(*), max(languages) from test_emp where 'vader' = 'yoda'`
```
   count(*)    |max(languages) 
---------------+---------------
```

Note, this only behaves inconsistently if no `GROUP BY` is used. If a `GROUP BY gender` is added to the queries above, both correctly return an empty result set.
