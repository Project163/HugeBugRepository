Title

Improve client error msg when Active/Passive HA is enabled

Description
When Active/Passive HA is enabled and when client tries to connect to Passive HA or when HS2 is still starting up, clients will receive the following the error msg 
  
 
 'Cannot open sessions on an inactive HS2 instance; use service discovery to connect'  
  
 This error msg can be improved to say that HS2 is still starting up (or more user-friendly error msg).
