Title

MarkupBuilder replaces ' characters with the incorrect entity "

Description
When MarkupBuilder escapes both attribute values and element content, it replaces the ' character with the entity ", rather than '
Discussion
- Added a patch to MarkupBuilder and its corresponding unit test.
- The patch I have provided adds a few extra private methods for handling the XML escaping because I wanted to provide slightly different behaviour for escaping attribute values and element content (apostrophes only need escaping inside attribute values). However, this would have meant changing the signature of transformValue(), which I was loath to do because it has "protected" access and changing it may have affected clients that depend on its current behaviour. 

 Having said that, I did fix transformValue() so that it replaces apostrophes with the correct entity (').
