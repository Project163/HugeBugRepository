Title

Packaging targets do not run on Linux

Description
Currently packaging doesn't run on Linux, due to some references to .NET CF. We don't try to build CF on linux, but we do some cleanup in other targets based on the assumption that CF may have been built. Some extra checks need to be added.

Once the current error related to the bin/netcf-3.5 directory is fixed, others may show up. They should all be fixed so that the packages that are capable of being built under Linux all build.
