Title

logger not working if it's set from config

Description
### What steps will reproduce the problem?
Inside any controller, put this:
```php
public function actionIndex()
{
        Yii::info('Hello World');
        return $this->render('index');
}
```

inside the config:
```
php
'log' => [
            'traceLevel' => YII_DEBUG ? 3 : 0,
            'logger' => Yii::createObject('yii\log\Logger'),
            'targets' => [
... [Log Snipped] ...
            ],
],
```

### What is the expected result?
Log inside the `runtime/logs/app.log`

### What do you get instead?
Nothing in `runtime/logs/app.log`

### Additional info
It'll work if  `'logger' => Yii::createObject('yii\log\Logger'),` is removed

I have found location from where it's misbehaving.
**Class** : `yii\log\Logger` 
```
php
public function __construct($config = [])
    {
        // ensure logger gets set before any other config option
        if (isset($config['logger'])) {

        parent::__construct($config);
    }
```
and
```
php
/**

     * @property Logger the logger. If not set, [[\Yii::getLogger()]] will be used.

    }
```
