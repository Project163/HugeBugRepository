Title

ignite-tools may skip classes when assembling classnames.properties

Description
Among other things,  ignite-tools  module is responsible for generating classnames.properties file as part of ignite-core module build routine. 

 It turned out that the way it retrieves and handles classes from external JAR files is broken on Windows platform. This leads to the absence of some important classes that were recently moved out of core module into separate modules like ignite-commons, ignite-binary-api etc.
