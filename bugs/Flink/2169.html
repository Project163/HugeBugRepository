Title

Add COUNT AGG support constant parameter, i.e. COUNT(*), COUNT(1)

Description
COUNT(1) with Group Window, always output 0.  
e.g. 
DATA: 
  
 
val data = List(
    (1L, 1,  "Hi" ),
    (2L, 2,  "Hello" ),
    (4L, 2,  "Hello" ),
    (8L, 3,  "Hello world" ),
    (16L, 3,  "Hello world" ))
 
  

 SQL: 
  
 
SELECT b, COUNT(1) FROM MyTable GROUP BY Hop(proctime, interval  '0.001'  SECOND, interval  '0.002'  SECOND),b
 
  

 OUTPUT: 
  
 
1,0,1, 
1,0,1, 
2,0,1,
2,0,1, 
2,0,2, 
3,0,1,
3,0,1
Discussion
- After I check the detail I find that only  `CountAggFunction ` has this problem. The reason is calcite do the argument optimize. when meet  COUNT   or  COUNT(1) , calcite will ignore the param,so flink will get  COUNT() . we should add  COUNT()  in  CountAggFunction  and  AggregateUtil .
