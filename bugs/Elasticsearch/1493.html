Title

Uncaught exception thrown from PointValues static functions

Description
The static helpers on PointValues throws an exception if a leaf has points indexed but not for the given field. 
When using this function in es the exception is never caught which could lead to error in search request or field stats request.
The problem has been fixed in Lucene: [URL] but we agreed with @jpountz that we should have a temporary fix in es that we could remove afterward.
The proposal is to have a XPointValues which acts exactly like the PointValues with the LUCENE-7257 patch and to use this class to call all the static helpers in es.
