Title

Play does not send a response if any header is set to null.

Description
Play does not send a response if any header is set to null, without throwing any exception.

You can reproduce it very easily with this example:

```
public class Application extends Controller {
    public static Result index() {
        response().setHeader("ETag", null);
        return ok(index.render("Your new application is ready."));
    }
}
```

I think the reason is netty throws NullPointerException if header value is null.
Discussion
- As a first step for this, I've changed logging of all exceptions to be done at error.

I think we should still send a 500 error, rather than send an empty response, but this should help at least debug the issue.
- Nice job, @jroper. Next time I hope Play throws an exception when null value is passed to setHeader method even if the value must not be null.
