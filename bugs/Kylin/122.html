Title

When resource group is turned on, using EnhancedUnitOfWork to write metadata might fail

Description
When resource group is turned on, using EnhancedUnitOfWork to write metadata will check if current owner has the write permission, that is, whether the node is in the build resource group. The new feature of providing more flexible runtime join will force KYLIN to go into maintenance mode when using script to update and write metadata, this will have mocked node IP:0000 owning the epoch and since the mocked node is not in the build resource group, it will cause write failure.
