Title

GWT: utf-8 characters at the end of the buffer can be corrupted by BufferedReader

Description
I've just created a Russian translation for my game, and all is well in the Desktop, Android and iOS versions, but in the GWT version there were errors in the translations.

The top text in the image is what the translation should be, and the bottom is what is being displayed in the browser.

[Image: image]

Logging what's being returned by the call to `bundle.get("Quick_Game")` gives me

```
Translation: Быстрар Игра
```

where as the `.properties` file contains

```
Quick_Game=Быстрая Игра
```

As you can see, the last character for the first word has been changed.

This is just one of numerous errors that are occurring throughout the game with missing or changed characters and I'm struggling to work out the cause.
