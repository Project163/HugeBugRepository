Title

[YSQL] Corruption on TRUNCATE with indexes and tablegroups

Description
Jira Link: [Link: [DB-455]]
### Description

TRUNCATE table in tablegroup with index outside tablegroup does not truncate the index.  TRUNCATE table outside tablegroup with index in tablegroup truncates all tables in the tablegroup.

Related to issue #10912.
