Title

URL with parentheses breaks the AutoURL

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 3.3.6
* Platform and Target: Nginx, Linux 
### What you did
I tried to parse URLS with the `autoLinkUrls()` function, when I ran the following example, the function returned an empty string.
```
$this->Text->autoLinkUrls('[URL] [
        'target' => '_blank',
        'rel'    => 'nofollow'
    ])
```
However when I run the second example, I do get an URL. To me it appears as if the function does not expect the URL to end on parentheses.
```
$this->Text->autoLinkUrls('[URL] [
        'target' => '_blank',
        'rel'    => 'nofollow'
    ])
```

### What happened
The URL ending on parentheses breaks the AutoLinkUrl function. It returns an empty string.
