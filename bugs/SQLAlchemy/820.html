Title

elementtree example doesn't work, uses classical mappers

Description
multiple issues with this example:

1. can't be run as python examples/elementtree/optimized_ai.py becuase it has a file named "pickle" which gets in the way of SQLAlchemy "import pickle"

2. run as a module, has a unicode error on both py3k *and* py2k:

```
Traceback (most recent call last):
  File "/opt/python-3.7.0/lib/python3.7/runpy.py", line 193, in _run_module_as_main
    "__main__", mod_spec)

    exec(code, run_globals)
... [Log Snipped] ...
    callback(*args, **kwds)
TypeError: string argument expected, got 'bytes'
```

3. uses classical mappings which will be going away

4. also uses query.join(..., aliased=True) which would be nice to get rid of, but this is actually a demo of what that flag was intended for.   might be nice though to use aliased() explicitly in any case.
Discussion
- OK we need to put non-classical mappings here, and possibly try to see if we can come up with a more modern pattern than using aliased=True.  but at least the thing runs now.
