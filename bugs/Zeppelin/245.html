Title

Permissions cannot be cleared and need appropriate defaults

Description
note permissions cannot be cleared once set. This is due to a bug in the NotebookAuthorization setters for read,write,owner permissions.  

 Enhancement: 
if you set readers, and writers and owners is empty set them to the user requesting the change 
if you set writers, and owners is empty set it to the user requesting the change
