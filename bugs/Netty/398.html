Title

OSGi Bundle Manifest broken

Description
The declared Import-Package is wrong (here from netty-common)

```
Import-Package: sun.misc;resolution:=optional,javassist;version="[3.19
 ,4)";resolution:=optional,org.apache.commons.logging;version="[1.1,2)
 ";resolution:=optional,org.apache.log4j;version="[1.2,2)";resolution:
 =optional,org.slf4j;version="[1.7,2)";resolution:=optional,org.slf4j.
 helpers;version="[1.7,2)";resolution:=optional,sun.nio.ch;resolution:
 =optional,org.eclipse.jetty.npn;version="[1,2)";resolution=optional,o
 rg.eclipse.jetty.alpn;version="[1,2)";resolution=optional
```

the first few are correct "resolution:=optional" the jetty ones however are incorrect: "resolution=optional"

This is caused by the parent-pom:

```
 sun.misc.*;resolution:=optional,sun.nio.ch;resolution:=optional,sun.security.*;resolution:=optional,org.eclipse.jetty.npn;version="[1,2)";resolution=optional,org.eclipse.jetty.alpn;version="[1,2)";resolution=optional,* 
```

It needs to be:

```
 sun.misc.*;resolution:=optional,sun.nio.ch;resolution:=optional,sun.security.*;resolution:=optional,org.eclipse.jetty.npn;version="[1,2)";resolution:=optional,org.eclipse.jetty.alpn;version="[1,2)";resolution:=optional,* 
```
