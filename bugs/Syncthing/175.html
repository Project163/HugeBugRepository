Title

Files that are updated on remote nodes, that were previously ignored, are not synced.

Description
Flow is something like this...
- remote index update for ignored file comes in
- index update is dropped since the file is ignored
- ignore pattern is removed
- index update is still gone, since it was not accepted on receive

Hence we don't know that we need to sync the file until next reconnect.
Discussion
- We could probably solve this by not overloading the Invalid bit and instead setting a specific Ignored bit, both on received ignored files and locally discovered ignored files...

We could also announce files with that bit set to indicate that we have them / have received info about them but have ignored them, but I'm not sure of the value. It won't necessarily be a complete list, since we don't scan ignored directories so the other devices can't really use the info for much?
