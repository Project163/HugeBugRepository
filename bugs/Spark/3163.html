Title

JDBC data source does not include null value partition columns rows in the result.

Description
Reading from am JDBC data source using a partition column that is nullable can return incorrect number of rows, if there are rows with null value for partition column. 

  
 val emp = sqlContext.read.jdbc( "jdbc:h2:mem:testdb0;user=testUser;password=testPass" ,  "TEST.EMP" ,  "theid" , 0, 4, 3,  new  Properties)
emp.count()
 
  

 Above jdbc read call sets up the partitions of the following form. It does not include null predicate. 

  
 JDBCPartition(THEID < 1,0),JDBCPartition(THEID >= 1 AND THEID < 2,1),JDBCPartition(THEID >= 2,2)
 
  

 Rows with null values in partition column are not included in the results because the partition predicate does not specify is null predicates.
