Title

`object-curly-spacing` shows the incorrect column for opening brace

Description
The column number points to before `{` where as it should point right after when an error occurs. Example:

``` js
var a = { a: 1};  // 1:9 - There should be no space after '{' (object-curly-spacing)
```

Column number here should be `10` instead since that is where the unexpected space is.
