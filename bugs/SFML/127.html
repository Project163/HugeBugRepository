Title

Very minor bug in Window\Win32\WglContext.cpp

Description
In function "String getErrorString(DWORD errorCode)"

`FormatMessage(FORMAT_MESSAGE_FROM_SYSTEM, NULL, errorCode, 0, errBuff, sizeof(errBuff), NULL);`

Should be:

`FormatMessage(FORMAT_MESSAGE_FROM_SYSTEM, NULL, errorCode, 0, errBuff, _countof(errBuff), NULL);`
Discussion
- `sizeof` for compile-time-known-size arrays will return (or rather be replaced by) `size * sizeof(T)` where `T` is type of array's elements. What's more - `_countof` is nonstandard macro defined on msvc only. What you would rather use, if you don't want `sizeof`, is [Link: `std::extent`].
- @LaurentGomila Isn't this a genuine bug? If `sizeof(TCHAR)` is not 1, this might cause a stack buffer overflow.
