Title

Support setting exclusive: true for celeryev.* event queues to avoid RabbitMQ deprecation

Description
RabbitMQ 4.x deprecates queues that are durable: false and exclusive: false (transient_nonxcl_queues).
Currently, celeryev.* event queues are created as classic queues with these exact parameters, triggering the deprecation warning and blocking future upgrades.

Please add a configuration option to allow setting exclusive: true or durable: true on event queues (e.g., when using EventReceiver or pidbox). This would ensure compatibility with newer RabbitMQ versions. Reference: [URL]
