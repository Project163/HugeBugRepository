Title

man.vim: q does not exit, throws E444 instead

Description

alacritty

### Installation

Built commit from source

### How to reproduce the issue

`man man`
Try to quit with `q`

### Expected behavior

Close window, exit process, go back to terminal

### Actual behavior

Encounter "E444: Cannot close last window", window stays open
Discussion
- `git bisect` says this was caused by [URL]
- @runiq please see [Link: this] comment. If this doesn't apply to you, please provide a minimal config for investigation.
- As I mentioned [Link: here], this is because the `ftplugin/man.vim` file creates its own mapping:

```vim
  nnoremap       q :lclose  c
```

This overrides the one set by the autoload file when using `:Man!` as the pager.
