Title

'pid' files cannot be deleted when interpreter is restarted.

Description
When user click 'restart interpreter', pid file about interpreter can be remained. 

 But it can be removed when zeppelin is shutting down so it is not critical bug of zeppelin. 

 But zeppelin's shutdown process can kill another process if OS reuse pid that is used interpreter because 'zeppelin-daemon.sh' kill process with run/*.pid files.
