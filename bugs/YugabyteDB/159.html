Title

[YSQL] Insert failed on temporary table with index

Description
When inserting into a temporary table with index, an error is hit:

```
postgres=# create temporary table t (k int primary key, v int);
CREATE TABLE
postgres=# create index on t (v);
CREATE INDEX
postgres=# insert into t values (1, 2);
ERROR:  Not found: Error loading table with oid 16391 in database with oid 12448: The object does not exist: table_id: " "
```

This happens because the index is a local index but the marked. However, during insert we try to look up the index in the YugaByte storage layer and therefore cannot find the index.
Discussion
- This issue is fixed in commit 5cd59b1.
