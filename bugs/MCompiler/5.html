Title

OOM in reactor build and javac

Description
We are seeing a OOM error when running a medium-sized reactor build (approx 15 projects).  After about 10 modules, the javac plugin fails with an OOM in a module that actually has just a single java file.  Forking the VM actually leads to an immediate error in the first module so I assume forking does not work currently. 

 Setting the max heap memory by using set MAVEN_OPTS=-Xmx512m has no visible effect. 

 The system is out of resources.
