Title

ODBC: SQLFetch fails if result set contains non-primitive column.

Description
If any column of the result set is complex binary object (non primitive type), then  SQLFetch  fails upon call with the following message: 
  
 Error 01S01: Can not retrieve row column.
Discussion
- I found a root cause of the issue. In  OdbcRequestHandler  we now acquire keep-binary cache instance ( withKeepBinary() ), so any complex object returned as an instance of   BinaryObjectExImpl , which serialized as  IGNITE_TYPE_BINARY . Currently, we don't handle objects of type  IGNITE_TYPE_BINARY  in ODBC driver. 
I'm going to implement it.
