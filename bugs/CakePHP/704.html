Title

Some core methods currently don't account for string zero value `'0'` input.

Description
After [URL] it seems that several core methods would false positive !empty() and thus return `false` where they should actually return `true`:
- Cache::writeMany(): `if ($success === false && !empty($data[$key])) {`
  You can't store `'0'`
- ConsoleInput::read(): `if (!empty($line)) {`
  You can't read `'0'`
- ConsoleInputOption::usage(): `if (!empty($this->_default)`
  You can't default to `'0'`

There might be more.
They should use a "more sane" not-empty check.
