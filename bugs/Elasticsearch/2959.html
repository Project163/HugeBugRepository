Title

Elasticsearch crashes on startup when upgrading from 8.10.4 to 8.11.1 when S3 snapshots are in use

Description
### Elasticsearch Version

8.11.1

### Installed Plugins

_No response_

### Java Version

_bundled_

### OS Version

ubuntu:20.04

### Problem Description

I'm orchestrating my Elasticsearch deployment using [Link: Cloud on K8s] 2.9. When attempting to upgrade my Elasticsearch cluster from 8.10.4 to 8.11.1 the first node to restart crashes with the `access denied` stack trace included in the logs section.

This occurs with an unmodified `docker.elastic.co/elasticsearch/elasticsearch:8.11.1` image with no additional plugins installed. I am using S3 based snapshots with this cluster. I have been able to successfully do minor version upgrades of this cluster in the past. 

I suspect this may be related to [URL] or [URL] since they relate to `S3Service.java` which appears in the stack trace and the patch notes for 8.11.0.

### Steps to Reproduce

Starting from a functioning ES 8.10.4 cluster with S3 snapshots configured attempt to upgrade an existing data node to 8.11.1. It will fail to start and produce the above stack trace.
