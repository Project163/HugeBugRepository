Discussion
- The lang code type here only contains valid `[language]-[region]` combinations, not `[language]-[script]`. This is because there're too many valid options according to the spec - and it breaks TypeScript (which has a limitation on the union type size). One solution might be adding `| string` by the end so it technically accepts any string, but the unions before it will still provide autocompletion.
