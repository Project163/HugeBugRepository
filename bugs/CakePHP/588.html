Title

Cache file_map gets overwritten at every request

Description
Starting from a clean cakephp 2.5.6 installation, I noticed that tmp/cache/myapp_cake_core_file_map file gets overwritten at every request (File and Redis Engine used).
I think the problem is generated by the cake bootstrap phase, in fact App::_cacheChange attribute is always set to true causing the App:shutdown() function to write the cache at the end of the request.

I only noticed the problem on a busy app in production (writes on disk was really high).

I tried, unsuccessfully, to find a solution but I finally configured the CacheEngine (File) to write on /run/shm to workaround the problem.
