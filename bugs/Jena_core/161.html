Title

Valid IRI using @ Symbol caues error

Description
Hi there,  

 I found out that the new jena 4.0.0 tdbloader(2) will throw an error and aborts if a URI uses an @ symbol is used, like < [URL] which is valid afaik. 

 Jena 3.17.0 however doesn't throw the error. 

 Minimal Example: 

  
 
<http: //example.com/a> <[URL] <[URL] .
