Title

Cannot disable Keycloak policy enforcement for root path

Description
**Describe the bug**
I want to implement a Quarkus application that hosts its SPA at / and its API at /api. I also want to use Keycloak for controlling API access. When I create an application.properties file like this, it ignores the root path configuration. It is working perfectly for the specific paths. Removing the * does not help. It seems as if specifing a root path is not working.

quarkus.keycloak.policy-enforcer.enable=true

quarkus.keycloak.policy-enforcer.paths.1.name=Root
quarkus.keycloak.policy-enforcer.paths.1.path=/*
quarkus.keycloak.policy-enforcer.paths.1.enforcement-mode=DISABLED

quarkus.keycloak.policy-enforcer.paths.2.name=API
quarkus.keycloak.policy-enforcer.paths.2.path=/api/*
quarkus.keycloak.policy-enforcer.paths.2.enforcement-mode=ENFORCING

quarkus.keycloak.policy-enforcer.paths.3.name=Public
quarkus.keycloak.policy-enforcer.paths.3.path=/hello
quarkus.keycloak.policy-enforcer.paths.3.enforcement-mode=DISABLED

**Expected behavior**
Everything that is not at /api should be accessable anonymously.

**Actual behavior**
/hello is, but / is not.

**To Reproduce**
1. Following the keycloak-integration example at quarkus.io 
2. Use the application.properties from above
3. Try to access / without a valid Bearer-Token
```
