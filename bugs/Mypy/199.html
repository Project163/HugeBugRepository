Title

Crash on double inheritance

Description
The following code:

``` python
from typing import Dict

class DifferentDict(dict, Dict[str, str]):

    def _len(self) -> int: ...
    __len__ = _len
```

crashes mypy with an internal error. (instead of just reporting the duplicate ancestor class).
