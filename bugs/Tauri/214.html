Title

[bug] Panic when menu is triggered while on dev tools window on Mac

Description
### Describe the bug

On a Mac, when you open the dev tools into a separate window, then click on a custom menu, the app crashes.

### Reproduction

0. Use a Mac. 
1. Create a custom menu using `tauri::Builder::default().menu(menu())`
2. Execute app, open dev tools
3. Detatch the dev tool into its own window.
4. While the dev tool window is focused, click on a CustomMenuItem menu.
5. Panic

### Expected behavior

The app should not panic.
