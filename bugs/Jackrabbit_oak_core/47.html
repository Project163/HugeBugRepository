Title

Mixin rep:MergeConflict is not a registered node type

Description
the internal mixin type rep:MergeConflict (aka mix:mergeConflict) is 
not registered with the node type manager. 

 adding the CND definition to the buildin node types list present in 
oak-core resources should help. 
if doing so i would suggest to review the definition. looking at the 
cnd currently present in the javadoc of AnnotatingConflictHandler 
i got the impression that it should have the OPV flag set. according to 
the cnd definition in jsr 283 the default value is COPY if no OPV-flag  
is specified and i am not sure if that is intended.
Discussion
- IGNORE would be the right value for the OPV flag I guess. In practice this doesn't matter though, since a node with mix:MergeConflict cannot be saved and thus not versioned.
