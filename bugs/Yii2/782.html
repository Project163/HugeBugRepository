Title

Client trim validation filter get wrong value with radioList (checkboxList)

Description
Model: 
```
php
public function rules()
    {
        return [
            [
... [Log Snipped] ...
       ];
}
```

View (ActiveFormWidget):
```
form.field(model, 'myAttr').radioList(items)
```

Generated (with yiiActiveForm) javascript validation part:
```
... "validate":function (attribute, value, messages, deferred, $form) {value = yii.validation.trim($form, attribute, []);yii.validation.required(value, messages, {"message":"Required"}); ...
```

Trim function in `yii.validation.js` (`trim: function ($form, attribute, options)`) for radioList gets the value from the container `div` which is always empty string. So all remaining client validators get empty value. In my case requered validator (following after trim) always gets the error.

Maybe is feature?
- I think that the "**trim**" validator is not suitable for the radio button and checkbox button.

If you refer to the documentation "**trim**", 

```js
 /** Removes the leading and trailing white space and line terminator characters from a string. */
    trim(): string;
```

then it becomes logical that it is not necessary here. 
I suggest simply adding an additional check before processing. In addition, this should not cause compatibility problems.

In general, it seems to me that with this validation, in principle, something is wrong.
For example, all the main validators work with "**value**" and only "**trim**" with, unexpectedly, "**form**" !!!

Unless "**trim**" should be executed not on string values?
