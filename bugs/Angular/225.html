Title

Breaking change with RC2: Sending Urls with search params because of encoding search values

Description
**I'm submitting a ...**  (check one with "x")

```
[x] bug report
[ ] feature request
[ ] support request => Please do not submit support request here, instead see [URL]

After upgrade to the RC2 of angular2 I've the following problem with sending http requests to github with using the http service

Before the upgrade the query string was the following:
```

q=repo:janbaer/howcani+type:issue&sort=created&order=desc&page

```
after the upgrade the querystring changed to:

```

q=repo%3Ajanbaer%2Fhowcani%2Btype%3Aissue&sort=created&order=desc&page=1

```

The url was build automatically by the http service with using the RequestOptions object and giving them the searchParams. One of the search params has the following value:

```

repo:howcani-project/howcani-data+type:issue

```

I think the problem here is the usage of the slash and the plus sign. But it's necessary to send the search string in this format to github. [URL]

How can I prevent that my query value will by escaped?

```
