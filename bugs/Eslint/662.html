Title

[Regression] space-in-parens ignores comments again

Description
The following code:

``` js
function f(/* config */ config, /* config.proxies */ proxies) {
  return [config, proxies];
}
f();
```

now (in ESLint 1.8.0) fails if `space-in-parens` is enabled with a message: "There should be no spaces inside this paren"; it didn't in 1.7.3.

I'd expect it to not ignore the leading comment and treat it as not having a space directly after a paren (since there's no space there).
Discussion
- Verified in online demo.
- It doesn't fail if there is no space after the comment:

``` js
function f(/* config */config, /* config.proxies */ proxies) {
  return [config, proxies];
}
f();
```
