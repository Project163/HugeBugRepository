Title

Expression in string is expanded at the begin of the string, not where it is defined

Description
Consider the following snippet: 

 arg     = "test" 
content = "${arg} =" 

 if (arg != "something") 
{ 
    content += "?" 
} 

 content += "= ${arg}." 

 println content 

 This does result in the following output: 

 test =?test= . 

 The expression in the string added to 'content' was expanded at the beginning of the string. 
Strangely this does seem to have something to do with the if statement above it. If the string to which arg is compared to, is changed from "something" to "test", than the output is correct (i.e. test == test.)
Discussion
- The problem turned out to be an error in how the value array was updated when 
a java.lang.String is added to a GString. The following is the corrected contents 
of the method GString.plus(String): 

     public GString plus(String that) { 
        String[] currentStrings = getStrings(); 
        String[] newStrings = null; 
	Object[] newValues = null; 

 	newStrings = new String [currentStrings.length + 1] ; 
	newValues = new Object [getValues().length + 1] ; 
	int lastIndex = currentStrings.length; 
	System.arraycopy(currentStrings, 0, newStrings, 0, lastIndex); 
	System.arraycopy(getValues(), 0, newValues, 0, getValues().length); 
	newStrings [lastIndex]  = that; 
	newValues [getValues().length]  = ""; 

         final String[] finalStrings = newStrings; 
        return new GString(newValues) { 
            public String[] getStrings()  
{
                return finalStrings;
            }
         }; 
    } 

 And the following is an addition to GStringTest to check that this is 
working. (This is a simplified version of the code from the bug report, 
which was a great compact demonstration of the problem.) 

     void testStringInMiddle() { 
    	 arg = "test" 
         content = "${arg} =" 
	 content += "?" 
	 content += "= ${arg}." 
	 assert content == "test =?= test." 
    }
- Patch from issue applied, tests ran successfully.  Test case should still be added.

	 b  = "${a} :" 
	 b += "<<" 
	 b += ">>" 
         b += ": ${a}" 
	 assert b == "--- :<<>>: ---" 
    }        

     void testAlternatingGStrings() { 
    	 a = "---" 
         b = "${a} :" 
	 b += "<<" 
         b += " [ [${a}] ] " 
         b += ">>" 
         b += ": ${a}" 
	 assert b == "--- :<< [ [---] ] >>: ---" 
   }
