Title

Non-runnable assembly has incorrect ResultState

Description
When an assembly can't be loaded for some reason, a special driver is used that returns the assembly info with a result of NotRunnable. That driver is coding the non-runnable state as Skipped rather than Failed, with the result that no report is ever displayed. The assembly appears to be a normal assembly without any tests in it.
Discussion
- In addition, the console report writer is not displaying any messages for invalid suites. I'll treat this as part of the same issue for convenience, although the main problem is in the engine while this one is in the ResultReporter class.
