Title

[YSQL] yb_get_range_split_clause crashes with partitioned table and SPLIT AT clause

Description
Jira Link: [Link: DB-14250]
### Description

```sql
CREATE TABLE test_part (a INT, PRIMARY KEY(a ASC)) PARTITION BY RANGE (a) SPLIT AT VALUES ((5), (10));
SELECT yb_get_range_split_clause('test_part'::regclass);
```

Results in 
```
server closed the connection unexpectedly
	This probably means the server terminated abnormally
	before or while processing the request.
The connection to the server was lost. Attempting reset: Succeeded.
```

Crash occurs at this line:
```
	for (int i = 0; i  indnkeyatts; ++i)
```

in `pg_yb_utils.c:getSplitPointsInfo`  because `rd_index` is null.
