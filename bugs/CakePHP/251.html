Title

3.0 - Baking controllers could lead to an exception

Description
When baking controller classes, if the associated table contains a column `_id*` that is not a reference to another table following conventions, you will get a missing table exception.
- We should both check that the column _ends_ in `_id` not just that it is contained in the string
- Associations should be checked and the actual table be used for the foreignKey
