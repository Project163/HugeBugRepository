Title

Current line number is not highlighted as compared to v0.5

Description
### Neovim Version

`v0.6.0-dev+139-g0f2af87a3`

### Operating system/version:

Linux

### Terminal name/version:

Suckless terminal

### TERM environment variable

`st-256color`

### Installation

Build from repo

### Steps to reproduce

Use a colorscheme not provided by the defaults (since all line numbers are brightly colored in default colorschemes). 

Set `set number relativenumber` in `init.vim`.

A distinction exists between the current line number (colored bright) and the rest of the line numbers (comparatively dimmer). This is the case with v0.5.

However, with the version specified above, all line numbers are colored the same. The main issue being that the current line number is colored the same as the other ones (i.e. dimmer).
