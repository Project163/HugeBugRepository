Title

Frequent rescans due to group ownership issue

Description
### What happened?

I have two Linux machines, each running syncthing as root, keeping multiple directory trees in sync. I know that this is not recommended, but I have multiple users on both machines and I wand to run just one instance of ST. It works as expected. 

However, I noticed full rescans every 10-15 seconds. A large number of files is briefly shown as out-of-sync in the web interface, the same ones again and again.

Finally I found that all those files had group id 1000, which had different names on the two machines, and one group name didn't even exist on the other machine at all. After changing the groups to match, these rescans stopped.

It seems that this situation isn't being handled well right now. There were no helpful log messages.

### Syncthing version

v1.28.0

### Platform & operating system

Linux arm64
