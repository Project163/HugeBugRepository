Title

EquivalentTo isn't compatible with Ignorecase for char

Description
While investigating issue #70, I noticed that IgnoreCase is also not respected for any collections containing chars. For example, I would expect that the following would pass.

`Assert.That( new[] {'A', 'B', 'C'}, Is.EqualTo( new [] {'a', 'b', 'c'}).IgnoreCase );`
Discussion
- Does it even work for

```
Assert.That('A', Is.EqualTo('a').IgnoreCase);
```
