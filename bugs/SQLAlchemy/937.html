Title

Discussion
- the error message here is not well written.    what it should say is:

"Don't know how to join to %s from current auto-detected left hand side; please use "
"the select_from() method to establish an explicit left side, as well as "
"an explicit ON clause, to more clearly establish the left "
"side of this join" % (right,)


the reason it sometimes knows the left side and sometimes not is because the expressions you are giving it each have both orders_cte and leads_cte in each column expression; the logic that extracts the fact that we are joining "from" one of these uses a set() around the FROM elements for each column expression, so sometimes it guesses that "orders_cte" is the left side, and sometimes "leads_cte".  

your query :
```
query = sess.query(
        func.coalesce(orders_cte.c.user_id, leads_cte.c.user_id).label('user_id'),
        func.coalesce(orders_cte.c.country_code, leads_cte.c.country_code).label('country_code'),
        (
            func.coalesce(orders_cte.c.total_conversions, 0)
... [Log Snipped] ...
        full=True,
    )
```

i can update the error message here and forego the use of set() above.
