Title

Error find PK in yii\db\mssql\Schema, method findPrimaryKeys

Description
Wrong primary key with multiple db schema (SQL Server 2012)
Example:

```
[schema1].[table]
[schema2].[table]
```

Method "findPrimaryKeys($table)" return "[ 'ROWID', 'ROWID' ]"
instead of "[ 'ROWID' ]"

Line 300 - Query

```
sql
SELECT
    [kcu].[column_name] AS [field_name]
FROM {$keyColumnUsageTableName} AS [kcu]
LEFT JOIN {$tableConstraintsTableName} AS [tc] ON
... [Log Snipped] ...
WHERE
   ...
```

should be

```
sql
SELECT
    [kcu].[column_name] AS [field_name]
FROM {$keyColumnUsageTableName} AS [kcu]
LEFT JOIN {$tableConstraintsTableName} AS [tc] ON
... [Log Snipped] ...
WHERE
    ...
```
Discussion
- I've got the same issue and second query (with `AND 
    [kcu].[table_schema] = [tc].[table_schema]`) resolves it.
