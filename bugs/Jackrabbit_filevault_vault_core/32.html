Title

"Item is protected" error during vlt rcp copy operation

Description
When you do a vlt rcp copy of a node that has a protected property removed in the source then the "Item is protected" error is thrown because vault rcp attempts to do a node update instead of a replace operation.  If you install a package that has a protected property removed then it does a replace and throws no errors. 

  
 000006 U /content/bhg/decorating/ do -it-yourself/accents/diy-carboard-projects/jcr:content
[ERROR] Error during copy: javax.jcr.nodetype.ConstraintViolationException: Item is  protected
