Title

Series 'print' output truncation

Description
When printing a Series (I haven't checked if the same applies to a DataFrame), the output is truncated in such a way as to change the meaning.

```
python
import pandas as pd

vals = [2.08430917305e+10, 3.52205017305e+10, 2.30674817305e+10, \
        2.03954217305e+10, 5.59897817305e+10]
... [Log Snipped] ...
print s.values == vals # True, ie the numbers stored are unaffected
print s # Should be 'e+10' rather than 'e+1'
```

Oddly, changing a single power to 9 rather than 10 makes the whole thing display properly:

``` python
s[0] = 2.08430917305e+9
print s # Now shows the correct exponent values.
```
Discussion
- The problem appears to be in pandas/core/format.py in the function _trim_zeros().  This function, as I understand it, checks whether it can safely remove a zero from the end of all the non-na elements and if it can, does so.  That process is repeated until it can no longer safely remove a zero from the end of any string.

In order to make it work correctly with numbers such as '123.45e+100' we can just check fro the presence of an 'e' in any of the strings.  This can be done with:

``` python
any(['e' in x for x in non_na])
```

ie it can just be added to the function _cond(values):

``` python
def _cond(values):
    non_na = [x for x in values if x != na_rep]
    return len(non_na) > 0 and all([x.endswith('0') for x in non_na]) and \
         not(any(['e' in x for x in non_na]))
```
