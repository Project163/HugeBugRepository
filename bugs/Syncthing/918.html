Title

"Restore Versions" GUI breaks when path exists as both directory and file

Description
In the latest version of syncthing, if `.stversions` contains both a non-empty directory and a backup for a file with the same name, for example:

```
.stversions/foo
└── bar~20201029-000000
.stversions/foo~20201029-000000
```

then the GUI's "Restore Versions" interface doesn't display any files, with an error in the console coming from the `buildTree` function in `app.js` about `parent.children` being `undefined`.
