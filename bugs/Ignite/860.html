Title

Windows shell scripts don't process NO_PAUSE environment variable

Description
bin\ignite.bat 
bin\ignitevisorcmd.bat 

 Both scripts above has following code: 
  
 if not "%NO_PAUSE%" == "1" pause
 
  

 But really set  NO_PAUSE=0 has no affect to script. It seems the variable redefined somewhere in script
Discussion
- Test in branch ignite-704. 

 After investigation I found that it is expected behaviour. 

 ignite.bat and ignitevisorcmd.bat support several commandline options like "-v" 

 And there is special option "-np" that control pause or not after ignite.bat(ignitevisorcmd.bat) finished. 

 So, I added information about this option into --help option for ignite.bat. 
And implemented support for --help option for ignitevisorcmd.bat 

 To test: execute 
 ignite.bat --help 
 ignitevisorcmd.bat --help 
 ignite.bat -np 
 ignitevisorcmd.bat -np
