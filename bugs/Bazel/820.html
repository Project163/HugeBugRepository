Title

Calling create_linking_context with libraries_to_link as empty list raises NullPointerException

Description
### Description of the problem / feature request:

Calling cc_common.create_linking_context with an empty list for libraries_to_link causes a NullPointerException to be thrown during build. This was not the case prior to bazel 1.2.0.

### Bugs: what's the simplest, easiest way to reproduce this bug? Please provide a minimal example if possible.

- Clone rules_cc repo
- Modify examples/my_c_archive/my_c_archive.bzl to change
    linking_context = cc_common.create_linking_context(libraries_to_link = [library_to_link])
to
    linking_context = cc_common.create_linking_context(libraries_to_link = [])
- Run
$ bazel build //examples/my_c_archive:all

### What operating system are you running Bazel on?

Ubuntu 19.10

### What's the output of `bazel info release`?

release 2.0.0
