Title

[YSQL] Unexpected result by yb_enable_distinct_pushdown

Description
Jira Link: [Link: DB-16091]
### Description

Please see this test case:

```sql
CREATE TABLE t0(c0 INT);
CREATE INDEX i0 ON t0(c0, c0 ASC);
INSERT INTO t0(c0) VALUES(1);
set yb_enable_base_scans_cost_model=on;
set yb_enable_distinct_pushdown=off;
SELECT DISTINCT 'a' FROM t0 WHERE t0.c0<5; -- 0 rows
```

It should return 1 row instead of 0. If we enable `yb_enable_distinct_pushdown`, the result is correct.

build option: `./yb_build.sh debug`

- Thanks for reporting this! 

I've narrowed it down to a simpler repro:

```
sql
create table simple (i int);
create index on simple(i, i asc);
insert into simple values (1);
/*+ IndexOnlyScan(simple) */ explain (analyze, costs off, timing off, summary off) SELECT 'a' FROM simple WHERE i<5;
... [Log Snipped] ...
   Heap Fetches: 0
(4 rows)
```

It looks like this case is incorrect because we're scanning on attribute number 2 in DocDB, but the local filter expects attribute number 1. This doesn't happen on 2024.2, so it's probably a bit more complex than that. I'm looking into it further.
