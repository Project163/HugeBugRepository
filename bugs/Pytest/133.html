Title

pytest deprecated_call context manager doesn't capture PendingDeprecationWarning

Description
pytest `deprecated_call` supports both a contextmanager and non-contextmanager calling form. The contextmanager form does not properly capture `PendingDeprecationWarning`. Sample code that demonstrates this:

```
python
import warnings

import pytest

... [Log Snipped] ...
    with pytest.deprecated_call():
        deprecation()
```

This affects pytest 3.1 and every other version I quickly tested, so it's possible the contextmanager has never properly handled this case.
