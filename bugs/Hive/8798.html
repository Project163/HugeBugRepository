Title

Metastore should also respect the max thrift message size

Description
Per   HIVE-26633  , we can configure the Thrift MaxMessageSize via  
hive.thrift.client.max.message.size, but it only takes effect on the client side, the server still follows the default 100M. If the message the client sent is greater than 100M, Metastore will get the TTransportException(END_OF_FILE), then close the connection silently. On the client side, it can see the odd exception indicating the connection is closed.
