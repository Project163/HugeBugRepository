Title

Rename properties introduced for

Description
HADOOP-15007   introduces the following two properties for tagging configuration properties 
 
	 hadoop.system.tags 
	 hadoop.custom.tags 
 

 This sounds like  tags  fall under  hadoop.system  and  hadoop.custom  related properties, but what we really want to achieve here is to have two sub-division of  tags  namely  system  and  custom  

 For better readability, we can rename them as 
 
	 hadoop.tags.system 
	 hadoop.tags.custom
Discussion
- I support this, but as the tags have shipped in Hadoop 3.1, we'll have to mark the old names as deprecated configs. It's a little bit more work, but will stop things breaking if anyone has used them.
- -1 overall
