Title

ES6 arrow function and no-wrap-func

Description
hi

``` js
opts.ease = opts.ease || a => a * a * a
```

results in:

```
 error  Unexpected token =>
```

so i tried:

``` js
opts.ease = opts.ease || (a => a * a * a)
```

this results in:

```
error  Wrapping non-IIFE function literals in parens is unnecessary  no-wrap-func
```

i think, we need an exception for arrow functions in the _no-wrap-func_ rule, especially the rule is enabled by default.
Discussion
- Will need to double-check that the parser is doing the right thing here, as well.
