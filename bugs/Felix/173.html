Title

NPE on discoverResources with invalid syntax filter

Description
When using the RepositoryAdmin.discoverResources with an invalid syntax filter string it will result into a NPE as the osgi filter creation syntax exception is just sent to System.err but the method flow continues.
Discussion
- Patch to return an empty resource array in case of a filter syntax exception. 
Another alternative will be to throw a runtime exception something like IllegalArgumentException.
- I applied the patch as it; it seemed reasonable to me. Alin, please close this issue if you are satisfied with it.
