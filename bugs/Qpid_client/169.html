Title

SCRAM-SHA mechanism impls erroneously escape "=" and "," in the password during processing

Description
Per discussion on  [URL] the client is erroneously escaping "=" and "," during password handling, whereas the SCRAM mechanisms only require this for the username and some other cases, causing authentication to fail when they are present as the wrong value is used to compute the details sent to the server.
