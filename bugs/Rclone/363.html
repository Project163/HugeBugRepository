Title

Windows rclone mount regression bug v1.43.1->v1.45 - Deadlock?

Description
#### What is the problem you are having with rclone?
VFS Rclone mount freezes on file modify operations under Windows.

#### What is your rclone version (output from `rclone version`)
Occurs with all versions later than rclove v1.43.1.

Does not occur with v1.43.1.

#### Which OS you are using and how many bits (eg Windows 7, 64 bit)
Windows 2012 Server, 64 bit

####  Which cloud storage system are you using? (eg Google Drive)
Google Drive -> Crypt

#### The command you were trying to run (eg `rclone copy /tmp remote:tmp`)

- Open a new text document in notepad and try to save it to the Mount.
- Notepad freezes at the Save screen and the mount drive is also inaccessible to both the command prompt and Windows Explorer.
- After restarting rclone, the mount/drive is accessible and the file shows in the mount folder it was saved/created in.
