Title

WeightedFairQueueByteDistributor may not write all pending bytes when testing HTTP/2 with Chrome.

Description
### Expected behavior
WeightedFairQueueByteDistributor write all pending bytes when testing HTTP/2 with Chrome.

### Actual behavior
WeightedFairQueueByteDistributor does not respond to all images when testing with Chrome, finally Chrome can not display for some images.
On the contrary, All images were displayed when testing Firefox.

### Steps to reproduce
1. Run the HTTP / 2 Tiles example(io.netty.example.http2.tiles).
2. Connect to [URL] using the Chrome browser.
3. Press Ctrl+F5
