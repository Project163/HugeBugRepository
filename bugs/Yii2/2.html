Title

DbSession crashes with autoStart

Description
DbSession initializes "db" field after Session::init():

```
php
    public function init()
    {
        parent::init();
        if (is_string($this->db)) {
... [Log Snipped] ...
        }
    }
```

Session::init() calls Session::open() if "autoStart" is true.

```
php
    public function init()
    {
        parent::init();
        if ($this->autoStart) {
... [Log Snipped] ...
        register_shutdown_function(array($this, 'close'));
    }
```

Session::open() calls DbSession::readSession() but DbSession::$db is string.

```
Fatal Error (yii\base\ErrorException)
```
