Title

PubSubTableProvider tries to set windows after GroupByKey

Description
A SqlTransform may contain a GroupByKey in the global window, this prevents setting windows afterwards. The PubSubTableProvider tries anyway. 

 This was exposed by a INSERT INTO pubsub VALUES (1), (2), which implicitly becomes INSERT INTO pubsub SELECT 1 UNION SELECT 2. This then becomes a GroupByKey union. 

 For now I'm going to simplify the test.
