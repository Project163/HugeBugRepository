Title

[snap7] official demo build failed

Description
**Describe the bug**
When i tryed to build the snap7's official c++ demo `examples/cpp/client.cpp` with vcpkg's snap7 ports, it failed.

**Environment**
- OS: Windows 10 Pro 22H2 19045.3324
- Compiler: MSVC 19.37.32822.0
- snap7 version: 1.4.2#1

**To Reproduce**
Steps to reproduce the behavior:
1. create a minimium demo project with vcpkg manifest mode, add "snap7" dependency in `vcpkg.json`
2. add the snap7's official c++ demo `examples/cpp/client.cpp` to project
3. add `find_package(snap7 CONFIG REQUIRED)` and `target_link_libraries(main PRIVATE snap7::snap7)` to project's `CMakeLists.txt`
4. build... it failed.

**Expected behavior**
It should be succeed.

This issue is about use of `snap7`. I can reproduce this issue locally.
- @LilyWangLL I'm not sure this PR [URL] should have been accepted. snap7.h / .cpp are wrappers that are usually included in the project consuming the snap7 library, like snap7.net.cs for .NET. I kept them away from the original package as it is not part of the library itself.
It could be part of a separate binary, or a separate package if it's needed.

TS7Client and TS7Server are not declared as part of the API. The only way to include them in the same compilation, would be to alter their code and make them part of the API.
