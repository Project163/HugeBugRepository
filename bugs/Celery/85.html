# Description
 
When starting workers like [Link: some examples in the documentation] that uses lowercase `info` as argument to loglevel I get this error: `Error: Invalid value for '-l' / '--loglevel': invalid choice: info. (choose from DEBUG, INFO, WARNING, ERROR, CRITICAL, FATAL)`. I assume this is because of the change to Click in 5.0.

# Suggestions
