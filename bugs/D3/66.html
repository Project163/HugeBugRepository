Title

Resampling should have a minimum sample interval distance.

Description
This is more noticeable now that graticules have 3-point meridians, e.g. when watching the world rotate in [Link: various projections].  I have reproduced this in the past using a contrived projection:

``` js
function(λ, φ) {
  return [λ, Math.sin(λ * 4)];
}
```

The following LineString should be resampled along the sine curve, but it is not at precision(1):

``` js
{type: "LineString", coordinates: [[-45, 0], [45, 0]]}
```

The problem is also noticeable in the [Link: interactive interrupted Bonne].

It seems excessive to take samples at the same interval as the Douglas–Peucker threshold, but hopefully we can derive something sensible without having to add a separate parameter.
