Title

pylint complains about table.insert() ("No value for argument 'dml' in method call [E1120]") / remove util.dependencies

Description
see also [Link: here]

When using `sometable.insert()` pylint complains

`"No value for argument 'dml' in method call [E1120]"`

The first parameter for `insert` set by a decorator, so there is no need to pass it 
explicitly.
