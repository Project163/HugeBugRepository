Title

dropping of a materialized view does not create a snapshot with dropped- prefix

Description
When auto_snapshot: true and MV is dropped, the name of the snapshot does not start with "dropped-" prefix as a normal table would. This is an issue for 3.11.x only. In 4.x, the code was refactored a lot and it does not happen there.
