Title

Form - problem with data => 0

Description
Hi

I've discovered a bug when using a form not related to an entity (when the form is related to an entity, this does not happen in the few tests I have done)

when adding a field to a form like this :
$builder->add('test', 'number', array('data' => 0)) // 0 as int
or like this
$builder->add('test', 'number', array('data' => '0')) // 0 as string

the value of the rendered input is set to "" (empty) instead of being "0" as expected

note : the problems occurs for all types, not only number, but also text and textarea for what I've tested
also note that when data => '00' or with more zero, the value is correctly rendered as 0
