Title

space-before-function-paren does not work for anonymous generator functions

Description
**What version of ESLint are you using?**
2.2.0

**What configuration and parser (Espree, Babel-ESLint, etc.) are you using?**
- babel-eslint

``` js
{
  "rules": {
    "space-before-function-paren": [2, {"anonymous": "always", "named": "always"}]
  }
}
```

**What did you do? Please include the actual source code causing the issue.**
Example:

``` js
var bla = function *() {}

bla()
```

**What did you expect to happen?**
I expected it to not lint, because the documentation for the [Link: generator-star-spacing rule] says:

**What actually happened? Please include the actual, raw output from ESLint.**
Eslint is not complaining about the missing space between the `*` and the `(`.
