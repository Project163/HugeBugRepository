Title

Python THttpClient fails with https sites

Description
THttpClient contains a hard-coded reference to httplib.HTTP() which prevents it from working with any SSL sites. 

 Here's a small patch that will at least use SSL when the port is 443.  I'm not much of a Python expert, but I think (based on the current docs for the 'httplib' module) that a better solution would be to rewrite the THttpClient to take a URL instead of host+port+uri and then use the urllib module instead of the lower-level httplib, but this little patch will at least allow basic interoperability against HTTPS.
