Title

Hive fails to create SslContextFactory when KeyStore has multiple certificates

Description
With Jetty 9.4.40, we should call SslContextFactory.Server(), instead of SslContextFactory(), to create SslContextFactory. Otherwise we get the following error when using a KeyStore with multiple certificates in it. 
  
 
Caused by: java.lang.IllegalStateException: KeyStores with multiple certificates are not supported on the base  class  org.eclipse.jetty.util.ssl.SslContextFactory. (Use org.eclipse.jetty.util.ssl.SslContextFactory$Server or org.eclipse.jetty.util.ssl.SslContextFactory$Client instead)
Discussion
- Jetty's SslContextFactory has been split for Client/Server classes via  [URL]

 Fix has been merged to master. Thank you for the patch  seonggon
