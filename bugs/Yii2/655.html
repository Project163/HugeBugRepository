Title

yii\web\UrlManger::$ruleConfig rule class doesn't change

Description
### What steps will reproduce the problem?
I changed rule class in appliction config `yii\web\RuleManager::$ruleConfig` on my own, which extends from `yii\web\UrlRule`.
### What is the expected result?
UrlManager create UrlRules as my custom class instance.
### What do you get instead?
I get old UrlRules from cache with `yii\web\UrlRule` class names.

### Additional info
Problem has gone when i add some new rules into `yii\web\RuleManager::$rules`. This happens because `yii\web\UrlManager::init()` calculate hash for cache only from rules without `$ruleConfig`.
