Title

JUnit 4 Migration Support incorrectly registers JupiterTestEngine via ServiceLoader

Description
## Overview

As reported in the [Link: Eclipse issue tracker], the `junit-jupiter-migrationsupport` module attempts to register the `JupiterTestEngine` via the `ServiceLoader` mechanism.

This is obviously the result of a copy-n-paste error that occurred when the `junit-jupiter-migrationsupport` Gradle project was created.

## Deliverables

- [x] Delete `/junit-jupiter-migrationsupport/src/main/resources/META-INF/services/org.junit.platform.engine.TestEngine`.
- [x] Document in release notes.
