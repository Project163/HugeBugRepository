Title

Performing an update in OSX when a project is opened trashes the wrong folder

Description
When a user performs an in app update on OSX with a project open, the `process.cwd` is modified to point to the current open project.

When Cypress performs an update, it uses `process.cwd` to trash the currently running `Cypress.app`. This will then incorrectly point to the wrong path, and thus trash a completely different folder causing much stress and panic.
