Discussion
- PDF created with PDFCreator, and PNG created with code in bug report
- The JDK can't read the embedded ICC_profile which leads to inverted colors. 

 I fixed that in revision 1338576. PDFBox now uses an alternate colorspace if a pdf contains such an problematic ICC_Profile
- Yes it is fixed in 1.7.0. Thanks.
