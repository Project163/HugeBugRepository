Title

Bootstrap Method Error on non-void lambda for Consumer

Description
When a method that returns a value is used as a  Consumer , a runtime  Error  is produced.

}

@CompileStatic
 class  Demo {
    List< String > strings = []

    void run() {
        Optional.of( 'hello' )
            .ifPresent(strings::add)
    }
}
