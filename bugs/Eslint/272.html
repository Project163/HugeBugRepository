Title

no-inner-declarations errors inside ArrowFunctionExpression

Description
```
js
// test.js
foo(() => {
    function bar() {
        return 1;
... [Log Snipped] ...
    bar();
});
```

```
js
// config.json
{
    "rules": {
        "no-inner-declarations": [2, "both"]
... [Log Snipped] ...
    }
}
```

``` sh
$ eslint --reset --no-eslintrc -c config.json test.js

test.js
  3:4  error  Move function declaration to program root  no-inner-declarations

✖ 1 problem (1 error, 0 warnings)
```

Since `bar` is declared inside the body of an `ArrowFunctionExpression`, it should be considered valid.
