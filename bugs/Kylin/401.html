Title

Failed to delete a table without an internal table

Description

    
Discussion

    
- Root Cause 

 While loading the data table, the internal table conversion function was performed. Since Gluten was not enabled, an error occurred during the internal table conversion. However, the table in the database had already been marked as an internal table. As a result, deleting the data table led to the error "Internal Table not found." 
   Dev Design 

 When Gluten is not enabled in the configuration, during the process of loading a data source and simultaneously converting it into an internal table, validate the configuration and throw the corresponding exception.
