Title

Using breaks React.Children.map

Description
`React.Children.map` assumes `this.props.children` is either a single child or an array (https://facebook.github.io/react/tips/children-props-type.html). This utility function is used by many libraries (for example, Radium) and is broken by the latest release of react-router, because ` ` turns `this.props.children` into a keyed object.
Discussion
- This is an intentional API decision that lets you use [Link: multiple components as named children] in a single route component.

`this.props.children` is an opaque type that is being used by many different React libraries to mean something other than just node, array, or `null`. In [Link: react-motion]'s ` ` component, for example, `this.props.children` is a function.
