Title

Parquet messes up stdout and stdin when used in Spark REPL

Description
I have a simple Parquet file in "foos.parquet", but after I type this code, it freezes the shell, to the point where I can't read or write stuff:

import qc._ 

 scala> qc.parquetFile("foos.parquet").saveAsTextFile("bar")
