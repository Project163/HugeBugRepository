Title

ML test TempDirectory trait does not clean up properly

Description
org.apache.spark.ml.util.TempDirectory should remove the temp directories it creates, but it does not (at least not locally on my machine). 

 This is an issue for the several new tests for ML model import/export, which leave a bunch of empty temp directories. 

 At first inspection, I don't see why this problem is occurring.  It must mean that  org.apache.spark.util.Utils.deleteRecursively  is successful except for its  finally  section.  That section is tested in UtilsSuite unit tests, so it should be working.
