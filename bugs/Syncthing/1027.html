Title

Clarify log message for ignored folders

Description
### What happened?

`[XXXXX] 2024/12/17 23:52:30 INFO: Ignoring folder "some folder name" (some-folder-id) from device SOME-VERY-LONG-DEVICE-ID since we are configured to`

I try to figure out why a folder does not show on my desktop when offering a folder from my mobile and the log message just cuts out when it gets to the interesting part.

### Syncthing version

v1.28.1

### Platform & operating system

Windows 11 (64-bit Intel/AMD)

### Browser version

Firefox 133.0.3

### Relevant log output

```shell
[XXXXX] 2024/12/17 23:52:30 INFO: Ignoring folder "some folder name" (some-folder-id) from device SOME-VERY-LONG-DEVICE-ID since we are configured to
```
Discussion
- [Link: Quick code search]
 links it to 
[Link: lib/model/model.go 1396]
with 1395 checking for the folder being ignored.
So the "correct" message would be

`[XXXXX] 2024/12/17 23:52:30 INFO: Ignoring folder "some folder name" (some-folder-id) from device SOME-VERY-LONG-DEVICE-ID since it is in the list of ignored folders.`

Maybe a hint to how to "un-ignore" the folder would help as well.
- I suppose this is just a question of writing style / grammatics.  It's meant to say:

`[XXXXX] 2024/12/17 23:52:30 INFO: Ignoring folder "some folder name" (some-folder-id) from device SOME-VERY-LONG-DEVICE-ID since we are configured to` [...ignore it]

Certainly the software speaking of itself in plural form is not the best idea, but the sentence makes sense and is not cut off.  Your proposal is fine, except I'd like to keep the word "configured" or "configuration" in there somehow.  Can't think of a better alternative though.
