Title

Regression 0.11.12 -> 0.11.13: hangs when processing body in `Service`

Description
A `Service` with the following endpoint in its `call` method:

```
rust
(Post, "/endpoint") => {
    debug!("Hang?");
    let fut = body
        .concat2()
... [Log Snipped] ...
    Box::new(fut)
}
```
Hangs under 0.11.13, but not under 0.11.12. As tested with:
```sh
curl -k -XPOST '[URL] -d '[[]]'
```
