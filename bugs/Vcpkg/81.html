Title

Error: Building package g2o:x64-windows failed with: POST_BUILD_CHECKS_FAILED

Description
Unable to build g2o using the command `vcpkg install g2o --head --triplet x64-windows`.
Below is the log

```
C:\Users\SEshwara\.vcpkg\vcpkg>vcpkg install g2o --head --triplet x64-windows
The following packages will be built and installed:
    g2o[core]:x64-windows (from HEAD)
Starting package 1/1: g2o:x64-windows
Building package g2o[core]:x64-windows from HEAD...
... [Log Snipped] ...

C:\Users\SEshwara\.vcpkg\vcpkg>
```
Discussion
- - There is problem in g2o as cmake is autogenerated in `vcpkg/packages/g2o_x64-windows/lib/cmake/`
- to fix this add the following code
   `vcpkg_fixup_cmake_targets(CONFIG_PATH "lib/cmake/g2o")`
- Hi @shanmukhananda , thanks for posting this issue. The PR has been merged to the master. And this issue should be fixed now.
