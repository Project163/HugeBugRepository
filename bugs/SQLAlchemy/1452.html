Title

`DELETE RETURNING` and `UPDATE RETURNING` CTEs no longer compile with ORM API in SQLAlchemy 2.0

Description
### Describe the bug

After upgrading to SQLAlchemy 2.0 from 1.4 according to the [Link: Major Migration Guide], all my queries that `select` from CTEs consisting of `update().returning()` and `delete().returning()` no longer compile. At the same time, `insert().returning()` and `select()` CTEs continue to work as expected.

The compile failure can be triggered both using `print(query)` and `.execute(query)`, and the database driver does not appear to be relevant.

I'm using the ORM API to define my tables. The bug does not occur with the Core API.
