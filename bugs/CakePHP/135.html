Title

Auth Security error due to url endcoding diferences

Description
SecurityComponent causes Auth error due to url encoding differences between FormHelper & SecurityComponent

result of debug($hashParts[0]) in FormHelper:

```
/pl/miedzynarodowe_proxy/kasa?georegion%5B27%5D=1&%3Bgeoregion%5B5%5D=1
```

result of debug($hashParts[0]) in SecurityComponent

```
/pl/miedzynarodowe_proxy/kasa?georegion%5B27%5D=1&georegion%5B5%5D=1
```

Tested on CakePHP v2.5.3

Discussion
- How are you creating the URL for your Form?
- ``` php
$request = Router::getRequest();//we are inside requestAction, we need original request
$url = $this->Html->url('language'=>$request['language'],'controller'=>'home','action'=>'checkout','?'=>$request->query);
...
$this->Form->create('Order',array('url'=>$url));
```

- I don't think your form's URL is going to work in general. It is getting HTML-escaped twice. You should use `Router::url()` to generate your URL as it does not HTML encode the generated URL instead of using `Html->url()`.
- Actually, he should be using the array version here and pass that directly to the create() method via `url`. Using Html::url() before is pointless/unnecessary and creates this issue.
