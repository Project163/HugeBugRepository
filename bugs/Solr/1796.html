Title

Description
Currently, solr tests are failing 90%+ of the time. We've been through this before many times, the argument is always that someone is looking at the failures and knows which ones are bad. 

 This argument is a lie. Nobody is watching these failures, or DistributedQueryComponentOptimizationTest would not have failed repeatedly for two straight days when the fix was trivial (I fixed this last night:  [URL]
