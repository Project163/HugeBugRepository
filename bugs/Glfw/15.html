Title

glfwInit crashes when mirroring 180° rotated to external monitor

Description
The most basic c++ program with glfw:

```
#include  
int main(int argc, char **argv)
{
  glfwInit();
  return 0;
}
```

crashes when compiled/linked/run via:

```
g++ -Wall `pkg-config --cflags glfw3 --static --libs glfw3` -framework OpenGL glfwtest.cpp -o a.out ; ./a.out
```

on osx mavericks with this error:

```
a.out(27456, ) malloc: *** error for object  : pointer being freed was not allocated
*** set a breakpoint in malloc_error_break to debug
Abort trap: 6
```

but ONLY when an external monitor is plugged in. (Without external monitor, it runs fine).

System specs:
Hardware: Macbook Pro i7 NVIDIA GeForce GT 650M 
OS: OS X 10.9.1 (13B42)
Discussion
- Which version/revision of glfw? It certainly doesn't happen to me with 3.0.4, with or without external monitor. Same OS X version and video card.
- Not sure if relevant, but you should be calling `glfwTerminate()` after `glfwInit()`, before return. (And error check `glfwInit()`.)
