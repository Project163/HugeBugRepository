Title

RBAC migration SQLServer cascade problem

Description
When I try to run the auto-generated SQLServer script for RBAC migration, SQLServer gives me the following error:

```
-- The auto generated migration script
create table [auth_item_child]
(
   [parent]               varchar(64) not null,
   [child]                varchar(64) not null,
... [Log Snipped] ...
   foreign key ([child]) references [auth_item] ([name]) on delete cascade on update cascade
);
```

```
The error:
Introducing FOREIGN KEY constraint 'FK__auth__child__7D0E9093' on table 'auth_item_child' may cause cycles or multiple cascade paths. Specify ON DELETE NO ACTION or ON UPDATE NO ACTION, or modify other FOREIGN KEY constraints.
```

We figured the reason for such error could be that SQLServer takes in account the case in which an auth_item is parent of itself, so updating/deleting the auth_item leads to 2 different cascade paths.
Is my assumption correct?

Is there any possible solution other than deleting one of the on update/delete cascade? (not really applicable)

Thank you in advance
