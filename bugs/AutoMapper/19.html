Title

Auto-selecting child class even if you map from the parent one

Description
I'm not sure if it's an issue, but it could be a misleading behaviour (imo).
Consider the following scenario:

```
public class BaseItem {}....
public class ItemA : BaseItem {}...
```

and both mapped to the same object:

```
Mapper.CreateMap ();
MapperCreateMap ();
```

We got a generic method where we use a map like this `...Map ` and this method can receive either the base or any of its implementations.

It turns out that when receiving a child object as input,  instead of getting the base map as we specified in code, it's going for the child map. I guess this is usually not a problem, but it proved to be inconvenient for debugging.
