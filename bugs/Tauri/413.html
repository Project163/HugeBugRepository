Discussion
- Hey 👋 Did you try it with debug builds (`tauri build --debug`) for both versions? If you then change your main function to something like this, it _may_ give you some more info.
```rs
tauri::Builder::default()
  .build(tauri::generate_context!()) // build instead of run
  .expect("error while building application")
  .run(|_, e| match e {
    tauri::RunEvent::Updater(event) => { dbg!(event); },
      _ => (),
  });
```

Maybe you have to start the exe from inside a terminal so the spawned console doesn't close when it's restarting.

Edit: And if that doesn't help, a minimal reproduction may be nice (or your repo if it's public). I just tried it again in my own app and didn't see any issues.
- @FabianLars Thank you so much for the quick response. I haven't had the chance to learn Rust much yet so I wasn't too sure about modifying main.rs.

I figured out the issue! I had a space character in `package.productName` in `tauri.conf.json`. This wasn't an issue with AppImage but it is with nsis. I also think it's not an issue with msi.

Thank you again~ I'd send a pr if I knew more Rust. Perhaps the docs could be updated, however I think I did use spaces in names with electron in the past, so I'm not sure if its intended or not.
