Title

Load balancer stuck with "tablet server ... has a pending delete"

Description
Pattern in master leader logs:

```
I0807 19:49:08.414180 31786 cluster_balance_util.h:388] tablet server   has a pending delete
I0807 19:49:08.414196 31786 cluster_balance_util.h:388] tablet server   has a pending delete
I0807 19:49:08.414204 31786 cluster_balance_util.h:388] tablet server   has a pending delete
```

This issue was manually fixed by restarting the master leader in this case. We need to figure out the root cause and prevent it from happening in the future.
