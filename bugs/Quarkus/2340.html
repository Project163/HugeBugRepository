Title

IllegalArgumentException when parsing Accept Header

Description
### Describe the bug

I've seen [Link: 34858], but it seems that the Issue has resurfaced, because I can reproduce it with version 3.15.1

When sending a request with a header "Accept: Any", the following Stack-Trace can be found in the logs and the HTTP Code is 500. The fix for the former Bug-Report was in ClassRoutingHandler, but this class is not in the Stack-Trace I got:

```
posh
java.lang.IllegalArgumentException: Failed to parse media type Any
    at org.jboss.resteasy.reactive.common.headers.MediaTypeHeaderDelegate.internalParse(MediaTypeHeaderDelegate.java:77)
    at org.jboss.resteasy.reactive.common.headers.MediaTypeHeaderDelegate.parse(MediaTypeHeaderDelegate.java:53)
    at org.jboss.resteasy.reactive.common.headers.MediaTypeHeaderDelegate.fromString(MediaTypeHeaderDelegate.java:128)
... [Log Snipped] ...
    at io.smallrye.mutiny.operators.uni.builders.UniCreateFromKnownItem.subscribe(UniCreateFromKnownItem.java:23)
    at io.smallrye.mutiny.operators.AbstractUni.subscribe(AbstractUni.java:36)
```

### Expected behavior

HTTP 406

### Actual behavior

HTTP 500 and an Exception in the log

### How to Reproduce?

Send request with "Accept: Any" to an endpoint like this:

```
java
@Path("/{context}/files")
```
