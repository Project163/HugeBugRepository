Title

Network Connector Changes via Runtime Config Plugin is order dependent

Description
The processing of changes done by the Runtime Config Plugin to Network Connectors is order dependent, meaning order  must  be preserved when making changes to the network of available brokers. 

 Further, this implies that one can never remove a network connector from the network connectors list, unless that item is at the end of the list.
