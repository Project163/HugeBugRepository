Title

Unable to use IN operator in 2.0.36 to select a list of columns

Description
### Discussed in [URL]

 

 Originally posted by **Apakottur** October 21, 2024 
The following code:
```python
result = await session.execute(
            select(Actor.id).where(
                Actor.id.in_([Actor.id]),
            )
````

Is valid in sqlalchemy==2.0.35 and generates the following correct SQL:
```sql
SELECT actor.id  FROM actor WHERE actor.id IN (actor.id)
```

However, in sqlalchemy==2.0.36 the same expression gives:
```text
sqlalchemy.exc.ArgumentError: IN expression list, SELECT construct, or bound parameter object expected, got [ >].
```

It this a bug or using IN like this is no longer allowed?
