Title

Confusing error when argument 2 of isinstance is alias to Any

Description
The error generated in the following example doesn't make much sense:

```py
from typing import Any
A = Any
isinstance(object(), A)  # Parameterized generics cannot be used with class or instance checks
```
Discussion
- Runtime error is much better: `TypeError: Any cannot be used with isinstance()`
