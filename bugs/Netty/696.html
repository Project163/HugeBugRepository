Title

AbstractChannel swallows potential errors by ignoring throwable

Description
### Expected behavior

AbstractChannel::localAddress() & AbstractChannel::remoteAddress() should not ignore and silently skip errors happened during their invocation.

### Actual behavior

AbstractChannel::localAddress() & AbstractChannel::remoteAddress() both contain such a block of code:

`
            } catch (Throwable t) {
                // Sometimes fails on a closed socket in Windows.
                return null;
            }
`
I.e. they simply ignore all possible errors, including `VirtualMachineError`s.
