Title

DefaultChannelId - Failed to find a usable hardware address on EC2

Description
Running 5.0.0.Alpha2 on EC2 I get the following warning:

WARN  DefaultChannelId - Failed to find a usable hardware address from the network interfaces; using random bytes: xxxxxxxxxxxxxxx

The system has two network interfaces:

eth0      Link encap:Ethernet  HWaddr 22:00:0B:7A:47:BD  
          inet addr:   Bcast:   Mask: 
          inet6 addr: fe80::2000:bff:fe7a:47bd/64 Scope:Link
          UP BROADCAST RUNNING MULTICAST  MTU:9001  Metric:1
          RX packets:13458177 errors:0 dropped:0 overruns:0 frame:0
          TX packets:6024704 errors:0 dropped:0 overruns:0 carrier:0
          collisions:0 txqueuelen:1000 
          RX bytes:14279224426 (13.2 GiB)  TX bytes:6007218439 (5.5 GiB)

lo        Link encap:Local Loopback  
          inet addr:   Mask: 
          inet6 addr: ::1/128 Scope:Host
          UP LOOPBACK RUNNING  MTU:65536  Metric:1
          RX packets:7704 errors:0 dropped:0 overruns:0 frame:0
          TX packets:7704 errors:0 dropped:0 overruns:0 carrier:0
          collisions:0 txqueuelen:0 
          RX bytes:4912763 (4.6 MiB)  TX bytes:4912763 (4.6 MiB)
