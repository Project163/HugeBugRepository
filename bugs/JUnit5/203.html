Title

User Guide does not include all published APIs in Experimental/Deprecated sections

Description
## Status Quo

The "Experimental APIs" and "Deprecated APIs" sections of the User Guide do not cover all published APIs since the `ApiReportGenerator` does not _see_ all published projects on its classpath.

For example, the current [Link: Experimental APIs section] does not include any APIs from the `junit-jupiter-migrationsupport` module. Similarly, prior to commit  , APIs from the new `junit-platform-testkit` were also not included.

## Deliverables

- [x] Ensure that all published APIs are included in the "Experimental APIs" and "Deprecated APIs" sections of the User Guide via an automated process.
