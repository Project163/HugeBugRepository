Title

False-positive: 10053 Apache Range Header DoS (CVE-2011-3192) for nginx

Description
**Describe the bug**
Apache Range Header DoS (CVE-2011-3192) is reported on a Docker file with an nginx server, just because some header "HTTP/1.1 206 Partial Content" is returned.
This is a false-positive.

**To Reproduce**
Steps to reproduce the behavior:
Run the ZAP stable Docker image (full scan) against our project PrivateBin (docker image `privatebin/nginx-fpm-alpine`).
Here via GitHub:
[URL]

See also attached HTML report there.

**Expected behavior**
10053 should not be reported.
