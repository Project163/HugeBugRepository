Title

SparkConf.contains does not consider deprecated keys

Description
This makes it kinda inconsistent with other SparkConf APIs. For example: 

  
 scala>  import  org.apache.spark.SparkConf
 import  org.apache.spark.SparkConf

scala> val conf =  new  SparkConf().set( "spark.io.compression.lz4.block.size" ,  "12345" )
16/03/07 10:55:17 WARN spark.SparkConf: The configuration key  'spark.io.compression.lz4.block.size'  has been deprecated as of Spark 1.4 and and may be removed in the  future . Please use the  new  key  'spark.io.compression.lz4.blockSize'  instead.
conf: org.apache.spark.SparkConf = org.apache.spark.SparkConf@221e8982

scala> conf.get( "spark.io.compression.lz4.blockSize" )
res0:  String  = 12345

scala> conf.contains( "spark.io.compression.lz4.blockSize" )
res1:  Boolean  =  false
