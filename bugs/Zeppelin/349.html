Title

Dialog is displayed multiple times

Description
Bootstrap dialog is being used in many places. For instance,  

 
	 to confirm notebook removal when notebook delete button click 
	 to confirm save when interpreter setting change 
	 and so on. 
 

 Bootstrap dialog is animated down from the top, when it is being displayed. 

 User sometimes press 'enter' key before animation is completed. 
In this case, instead of pressing 'OK' button in the dialog, it creates dialog again.
