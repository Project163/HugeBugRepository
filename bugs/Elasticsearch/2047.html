Title

[ingest] Default ingest node pipeline via index template fails to apply for first document.

Description
A ingest pipeline defined as a default from an index template will not apply the pipeline to the very first document indexed.   

```
curl -XDELETE "[URL]
curl -XPUT "[URL] -H 'Content-Type: application/json' -d'
{
  "description" : "test pipeline",
  "processors" : [
... [Log Snipped] ...
curl -XPOST "[URL]
curl -XGET "[URL]
```

results in 
```
"hits" : {
    "total" : 2,
    "max_score" : 1.0,
    "hits" : [
      {
... [Log Snipped] ...
    ]
  }
```

^^ note the the set pipeline did not take effect on the first document. 

It works fine when creating the index without without a template
```
curl -XDELETE "[URL]
curl -XPUT "[URL] -H 'Content-Type: application/json' -d'
{
  "description" : "test pipeline",
  "processors" : [
... [Log Snipped] ...
curl -XPOST "[URL]
curl -XGET "[URL]
```
output is as expected:
```
"hits" : {
    "total" : 2,
    "max_score" : 1.0,
    "hits" : [
      {
... [Log Snipped] ...
    ]
  }
```
