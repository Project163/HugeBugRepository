Title

Thread leaks in pinned thread mode

Description
SPARK-22340   introduced a pin thread mode which guarantees you to sync Python thread and JVM thread. 

 However, looks like the JVM threads are not finished even when the Python thread is finished. It can be debugged via YourKit, and run multiple jobs with multiple threads at the same time. 

 Easiest reproducer is: 

  
 
PYSPARK_PIN_THREAD= true  ./bin/pyspark
 
  

  
 
>>> from threading  import   Thread 
>>>  Thread (target=lambda: spark.range(1000).collect()).start()
>>>  Thread (target=lambda: spark.range(1000).collect()).start()
>>>  Thread (target=lambda: spark.range(1000).collect()).start()
>>> spark._jvm._gateway_client.deque
deque([<py4j.clientserver.ClientServerConnection object at  >, <py4j.clientserver.ClientServerConnection object at  >, <py4j.clientserver.ClientServerConnection object at  >, <py4j.clientserver.ClientServerConnection object at  >, <py4j.clientserver.ClientServerConnection object at  >])
>>>  Thread (target=lambda: spark.range(1000).collect()).start()
>>> spark._jvm._gateway_client.deque
deque([<py4j.clientserver.ClientServerConnection object at  >, <py4j.clientserver.ClientServerConnection object at  >, <py4j.clientserver.ClientServerConnection object at  >, <py4j.clientserver.ClientServerConnection object at  >, <py4j.clientserver.ClientServerConnection object at  >, <py4j.clientserver.ClientServerConnection object at  >])
 
  

 The connection doesn't get closed, and it holds JVM thread running.
