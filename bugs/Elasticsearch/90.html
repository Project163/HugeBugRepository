Title

Searching while an index is being allocated and no active shards exists within a "shard replication group" can cause search "misses"

Description
While an index is being created, and a shards replication group is not allocated yet (for example, shard id 2 primary and replicas have not been allocated yet), then when performing a search, it might miss data that was indexed (obviously, on a shard replication group that has at least one active shard).
