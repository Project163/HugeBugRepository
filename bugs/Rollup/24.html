Title

Exception parsing arrow functions

Description
I get an exception when using Rollup on arrow functions that return a single identifier:

``` js
// main.js
const f = a => a;
console.log(f(1));
```

```
$ rollup -i main.js
Cannot read property 'type' of null
[...]
```

This also causes an exception:

``` js
const a = 1;
const f = () => a;
console.log(f());
```

This works fine though:

``` js
const f = (a => a);
console.log(f(1));
```
