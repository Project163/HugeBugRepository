Title

webpack 2: ordering problem with mixed import and export * from 'x'

Description
using v2.0.7-beta, I see `Uncaught TypeError: Cannot redefine property: b` on load.

Seems to be using the names from `utility`, `combinatorics`, and `math` for all the re-exports, instead of using each of them. Note that `peekable` is exported next, and imported from later.

When I re-order the `peekable` import before the exports (i.e. just below lodash), the error goes away.

Note:
`./utility` exports `isIterable`, `isEmpty`, `size`, and `iterator`.
`./combinatorics` exports `combinations` and `product`.
`./math` exports `inclusive`.

These 7 names are re-exported for each of the `export *` generated lines.

Error is thrown on line 6 at page load.

js
import { property } from 'lodash'

export * from './utility'
export * from './combinatorics'
