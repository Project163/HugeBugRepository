Title

next/image wrong protocol when in proxy like nginx

Description
### Link to the code that reproduces this issue

no response

### To Reproduce

use an nginx proxy and start the server as usuarl using a optimized image component

### Current vs. Expected behavior

protoclo dont match with the server protocol, protocol must match the server started protocol

### Verify canary release

- [X] I verified that the issue exists in the latest Next.js canary release

### Provide environment information

```bash
13.5.3-canary.4, 13.5.3-canary.3, 13.5.3-canary.2
```

### Which area(s) are affected? (Select all that apply)

Image optimization (next/image, next/legacy/image)

### Additional context

```js
invokeRequest(
  `${getRequestMeta(req, '_protocol')}://${
    this.fetchHostname || 'localhost'
  }:${this.port}${newReq.url || ''}`,
```

that line in the server is matching the request protocol which may or may not match the real server running by next server.

This line should match the protocol have been using by the server not by the request.
