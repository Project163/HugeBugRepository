Title

Sibling Pipeline Aggregations only work if nested in multi-bucket aggregations

Description
Sibling Pipeline Aggregations don't work if their parent aggregation is a SingleBucketAggregation. This is because [1] explicitly casts the parent aggregation to a MultiBucketAggregation. We should check the type of the parent aggregation and process it as now if its a MultiBucketAggregation or process it as a SingleBucketAggregation if not.
