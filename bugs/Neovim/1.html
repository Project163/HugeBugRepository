Title

Linebreak becomes temporarily disabled when change motion used

Description
I have noticed a difference (and possible bug) when switching from Vim to Neovim. When I use `cw` in old vim, the linebreaks (enabled by the setting `linebreak on`) are preserved. In Neovim, after using the change motion the linebreaks become disabled and the cursor will jump position. This can be distracting and breaks the flow. Returning to normal mode the linebreaks reappear. The following screenshot demonstrates this:

[Image: neovim]

Both vim and neovim preserve linebreaks if insert mode is entered by `i`, it seems only for the change motion that this is an issue.

Both versions are on my Ubuntu linux box, and use the same .vimrc:

```
NVIM 0.0.0-alpha+201502021723 (compiled Feb  3 2015 14:08:14)
Commit:  
```

```
VIM - Vi IMproved 7.4 (2013 Aug 10, compiled Oct  2 2014 14:10:49)
Included patches: 1-463
```
