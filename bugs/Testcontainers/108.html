### What happened?

I upgraded to Spring Boot 3.4.0, which inherits Testcontainers version 1.20.4.

The legacy Cassandra container was working fine, but I am trying to migrate to the new one.
With the new cassandra container library I get this error on startup: `Caused by: java.lang.IllegalArgumentException: URI is not hierarchical`.
I need to run a startup script which resides in the testFixtures library, which is used by the project that has this issue.

The problem occurs because the URI is referring to a classpath resource, inside the testFixtures jar: `jar:file:/Users/myName/Code/myProject/libs/test-shared/build/libs/test-shared-0.0.1-test-fixtures.jar!/init_cassandra.cql`, so when instantiate the new file from the URI resource, to get the filename, it throws the upper error.

Example code to reproduce:
```java
CassandraContainer cassandra = new CassandraContainer(imageName);
cassandra.withExposedPorts(9042).withInitScript("init_cassandra.cql").waitingFor(new CassandraQueryWaitStrategy());
cassandra.addEnv("CASSANDRA_DC", "datacenter1");
cassandra.addEnv("CASSANDRA_ENDPOINT_SNITCH", "GossipingPropertyFileSnitch");
```
