Title

Ducktests fail because of new format of control.sh

Description
Output format of the control.sh utility has been changed in PR  [1]  

 In particular the dataCenterId is now printed for GridCacheVersion in the "--tx --info xxx" command. 

 This causes the failure of ducktests which is unable to parse control.sh output now. In particular this one  [2] . 

 control.sh output parser should be fixed to support both old and new format.
