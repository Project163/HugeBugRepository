Title

[patch included] surefire skips all tests and reports succes when encountering a class that doesn't extend TestCase

Description
Some folks have reported that their JUnit test aren't being executed. This happens when one of the test 
classes doesn't extend TestCase. 

 I've improved error handling and confinuation of testcase execution in case of battery execution failure, 
marking failures as errors, and improved recognition of testcase classes: now you JUnitBattery falls 
back to AbstractBattery if it encounters a POJO, after trying to find the TestCase api method signatures 
on the POJO first.
