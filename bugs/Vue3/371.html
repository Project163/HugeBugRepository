Title

toRefs type is wrong when using defineProps with optional boolean props

Description
### Version
3.2.26

### Reproduction link
[Link: stackblitz.com]







### Steps to reproduce
```
import { toRefs } from 'vue'

const props = defineProps ()

const { isLive } = toRefs(props)
```

### What is expected?
According to [Link: fix(runtime-core): ensure declare prop keys are always present] type of `isLive` should be:
```
Ref 
```

### What is actually happening?
The type of `isLive` actually is:
```
Ref  | undefined
```

---
`isLive` couldn't be undefined in no case
