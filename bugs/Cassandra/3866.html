Title

Regression in select count with limit

Description
After   CASSANDRA-4914   the  LIMIT  clause should limit only the number of rows returned to the user not the number of rows used by the aggregates. 
That functionality is currently broken in 2.2.
Discussion
- The patch for 2.2 is  here  and the one for 3.0 is  here  

 I did not find the change that introduced the regression but it seems that the problem was caused by the commands using the  LIMIT  value to limit the number of rows retrieved. 

 The patch for  2.2 : 
 
	 makes sure that for aggregate queries we do not pass the  LIMIT  value to the commands 
	 adds extra unit tests 
	 fix the  NEWS.txt  
 

 The patch for  3.0  fix the  NEWS.txt  and add some extra tests.
