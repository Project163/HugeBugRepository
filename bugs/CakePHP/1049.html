Title

Debug output doesn't preserve white space anymore.

Description
This is a (multiple allowed):

* [x] bug
* [ ] enhancement
* [ ] feature-discussion (RFC)

* CakePHP Version: 4.x

------

I guess this is either an oversight, or a side-effect of the new formatted debug output, but since ` ` has been dropped, white space is not being preserved anymore.

```php
debug("foo    bar\nbaz\t42");
```
displays as:

```
'foo bar baz 42'
```

From a quick test, making `.cake-dbg` preserve white space seems to work fine, but I'm not sure if I'm missing something, as I'm not yet overly familiar with the new formatted HTML output.
Discussion
- Not preserving whitespace is an oversight, not an intentional change.
