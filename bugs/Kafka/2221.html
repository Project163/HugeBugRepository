Title

KStreams documentation Maven artifact table is cut off

Description
In the  Writing a Streams Application doc , the section "LIBRARIES AND MAVEN ARTIFACTS" has a table that lists out the Maven artifacts. The items in the group ID overflow and are cut off by the table column, even on a very large monitor. 

 Note that "artifact ID" seems to have its word break property set correctly. See the attached image.
