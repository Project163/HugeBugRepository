- sdeneefe  are you sure you are using it right? I just tested and it works. 

 Here's a test script you can run a few times : 
  
 define rand RANDOM( '12345' );

lines = load  'random.pig' ;
r = foreach lines generate rand();
dump r;
 
  

 run using `pig -x local random.pig 2>/dev/null`

 I was using it differently, and it didn't work: 

  
 lines = load  'random.pig' ;

 I didn't understand the difference (now I think I do), but thanks for giving this example.  I am glad to see that when using define it works as expected.
- A UDF essentially has a constructor and an exec method. "foreach lines udf(foo)" calls the exec method and passes to it the foo parameter. "define udfinstance udf(foo)" passes foo to the constructor, and makes an instance of the foo udf initialized in that way bound to "udfinstance" (so you can have many differently initialized udfs in the same script).  You can read more info on all this in the docs about "define" keyword and the UDF author's guide.
