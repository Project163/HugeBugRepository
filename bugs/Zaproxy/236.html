Title

Unable to CONNECT to authority with underscore

Description
**Describe the bug**
When an URI with an underscore character ('_') in the authority part, f.e. "ex_ample.something.com" is used with proxy, the CONNECT request, which has no scheme, will make ZAP throw an exception causing an error "ERR_EMPTY_RESPONSE" in the browser. The problem is related to the parse URI method which does not know to handle such URIs 

**To Reproduce**
Steps to reproduce the behavior:
1. Start ZAP UI or a browser using the ZAP proxy
2. Go to the URL "ex_ample.blogspot.com"
3. See error (browser and log)

**Expected behavior**
No error shows up and the website content is loaded.

**Software versions**
 - ZAP: 2.7.0 (but is also happening using the current development branch)
 - OS: Windows 10
 - Java: openjdk version "1.8.0_202"
 - Browser: chrome 72, ZAP built in browser
