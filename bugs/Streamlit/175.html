Title

[visual bug] st.expander doesn't fade when app is in rerunning state

Description
### Summary

All Streamlit widgets and elements fade when the app is rerunning. But this is not happening for st.expander.

### Steps to reproduce

Code snippet:

```
import streamlit as st
import time

time.sleep(10)  # Makes it easier to see the bug

... [Log Snipped] ...
with st.expander("This doesn't fade"):
  st.write("but this fades")
```

1. Run the snippet above
2. Once it's done loading (10s!), click the button to cause the app to rerun

**Expected behavior:**

All widgets fade for ~10s, while rerunning.

**Actual behavior:**

Everything fades correctly, except for the expander.

### Is this a regression?

Don't think so
