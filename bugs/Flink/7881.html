Title

The nullability of function ENCODE return type differs in Table API and SQL

Description
The definition of return type nullability is different in `BuiltInFunctionDefinitions#ENCODE` and `FlinkSqlOperatorTable#ENCODE`. The same issue applies to  DECODE. 

 The test in the attached image will pass, clearly the nullability differs in Table API and SQL. 

 I think we should unify them to enforce nullable return types. And there may exist similar diffs in other functions, though I haven't checked yet.
