Title

Yarn AM not always properly exiting after unregistering from RM

Description
The yarn application master doesn't always exit properly after unregistering from the RM.   

 One way to reproduce is to ask for large containers (> 4g) but use jdk32 so that all of them fail.
Discussion
- Note that in yarn-cluster mode the client side does quit, but the application master is still running on the cluster.
- Note that this also isn't an issue on hadoop 0.23 because there it shoots the containers after unregister.  In hadoop 2.x it doesn't shoot them as aggressively to give the application time to cleanup .
