Title

Validate controller.quorum.fetch.timeout.ms is a positive value

Description
We currently don't have a Validator when defining the controller.quorum.fetch.timeout.ms configuration. Setting it to 0 or a negative value does not make sense and prevents the broker from starting. 

 With a validator, the error would appear when the storage is formatted. Also it would be show a meaningful valid values field in the broker configuration documentation. 

 This is likely to apply to other quorum configurations.
