Title

Function signature is missed

Description
A function signature is missing when it's defined in a file that is not loaded via Composer "directly", but by an autoload file with some logic.

An example: a function [Link: `uri_for()`] is defined in [Link: `functions.php`] that is loaded **inside an if statement** by [Link: `functions_include.php`] that is loaded [Link: by Composer].

[URL]

When I run the analyser on the project, it silently treats usages of the function as `(...):mixed`, what causes arbitrary type errors.

Everything works fine when I comment if statement in `functions_include.php` above.

Initially I thought it's related to #848, but after some experiments the issue seems to be different. Unfortunately, I'm not familiar with the Psalm code base at the moment, so cannot make a fix by myself.
