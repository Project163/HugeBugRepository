Discussion
- FYI, this does not happen when it is read from json RDD. Let me please leave a code to reproduce that self-contains the issue. 

 This does not work (in `JsonSuite.scala`) 

  
 test( "SPARK-16698 - json parsing regression - " . " in keys" ) {
  withTempPath { path =>
    val json = """ {" a.b ":" data "}" ""
    spark.sparkContext
      .parallelize(json :: Nil)
      .saveAsTextFile(path.getAbsolutePath)
    spark.read.json(path.getAbsolutePath).collect()
  }
}
 
  

 This works 

  
 test( "SPARK-16698 - json parsing regression - " . " in keys" ) {
  withTempPath { path =>
    val json = """ {" a.b ":" data "}" ""
    val rdd = spark.sparkContext
      .parallelize(json :: Nil)
    spark.read.json(rdd).collect()
  }
}
- It seems it does not work for all `FileFormat` data sources. The code below also does not work. 

  
 test( "SPARK-16698 - csv parsing regression - " . " in keys" ) {
  withTempPath { path =>
    val csv ="""
        |a.b
        |123
      """.stripMargin
    spark.sparkContext
      .parallelize(csv :: Nil)
      .saveAsTextFile(path.getAbsolutePath)
    spark.read
      .option( "inferSchema" ,  " true " )
      .option( "header" ,  " true " )
      .csv(path.getAbsolutePath).select( "`a.b`" ).show()
  }
}
