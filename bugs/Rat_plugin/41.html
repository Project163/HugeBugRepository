Title

Properly report thread safety to Maven

Description
The rat plugin currently does not properly report its thread safety (assuming it is threadsafe, which I've found some places describe it to be) which results in maven complaining when you try to do parallel builds that run rat. 

 Rat should properly report its thread safety to maven and be updated to be threadsafe if necessary.
