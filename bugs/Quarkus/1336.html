Title

Logging attribute %R / %{RELATIVE_PATH} does not work

Description
### Describe the bug

The logging attribute as described in the Quarkus documentation, [URL] , does not work.


### Expected behavior

I expect the parameter to work as documented

### Actual behavior

When starting the application, errors are logged and attributes are not logged properly:

```
2021-09-28 20:44:06,132 ERROR [io.qua.ver.htt.run.att.ExchangeAttributeParser] (Quarkus Main Thread) Unknown token %R
2021-09-28 20:44:06,137 ERROR [io.qua.ver.htt.run.att.ExchangeAttributeParser] (Quarkus Main Thread) Unknown token %{RELATIVE_PATH}
```


### How to Reproduce?

Create a Quarkus application, and set the following application properties:

```
quarkus.http.access-log.enabled=true
quarkus.http.access-log.pattern=%R %{RELATIVE_PATH}
```

Start the application, and the error will appear in the log
