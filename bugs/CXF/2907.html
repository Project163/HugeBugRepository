Title

Need to log a warning when async method returns a non-void type

Description
According to the javadoc for the @Suspended annotation (  [URL] ), the JAX-RS runtime should be logging a warning message when a user's resource contains an async method (method with a @Suspended-annotated parameter) that returns a non-void type. 

 Currently, CXF will log a FINE trace message, but it ought to be a WARNING so that it highlighted in the log output under normal logging settings.
