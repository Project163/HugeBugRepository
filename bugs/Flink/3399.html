Title

Shouldn't expect HMS client to throw NoSuchObjectException for non-existing function

Description

    
Discussion

    
- When getting functions, we expect HMS client to throw NoSuchObjectException if the function doesn't exist (in  HiveShimV230 ). This is wrong because NoSuchObjectException is not part of the signature of  IMetaStoreClient::getFunction . Therefore let's always handle it like in  HiveShimV100 .
