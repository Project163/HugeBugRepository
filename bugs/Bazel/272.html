Title

Compatibility Issue of lower-version `sed`.

Description
When I tried to build the bazel from some redhat based seLinux system, I encountered the following error

```
INFO:    ./compile.sh compile /path/to/bazel
🍃  Building Bazel from scratch......sed: invalid option -- 'E'
Usage: sed [OPTION]... {script-only-if-no-other-script} [input-file]...

  -n, --quiet, --silent
... [Log Snipped] ...
Be sure to include the word ``sed'' somewhere in the ``Subject:'' field.
fgrep: write error: Broken pipe
```

FYI, sed version

```
sed --version
GNU sed version 4.1.5
Copyright (C) 2003 Free Software Foundation, Inc.
This is free software; see the source for copying conditions.  There is NO
warranty; not even for MERCHANTABILITY or FITNESS FOR A PARTICULAR PURPOSE,
to the extent permitted by law.
```
Discussion
- I think it's due to missing -e flags. I've sent a pull request to add -e to all the sed invocations in compile.sh.
- Unfortunately, this is still an issue on 0.5.2:

INFO: You can skip this first step by providing a path to the bazel binary as second argument:
INFO:    ./compile.sh compile /path/to/bazel
🍃  Building Bazel from scratch.......sed: invalid option -- 'E'
