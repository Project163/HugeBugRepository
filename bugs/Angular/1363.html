Title

AnimationPlayer hasStarted() not returning expected value

Description
## I'm submitting a...
 
  

[x ] Bug report 

  

## Current behavior
I am trying to make use of the AnimationPlayer's method `hasStarted(),` but it looks like it always return `true`, even after pausing or resetting the player. Even inside the `onDone()` callback, it still returns `true`.


## Expected behavior
`hasStarted()` should return `false` when the player has been paused or resetted, and when it has finished animating its assigned DOM element.
