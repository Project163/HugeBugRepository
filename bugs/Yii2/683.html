Title

PHP notice error with different locale in log/Target.php

Description
### What steps will reproduce the problem?
Throw an exception and have logging enabled

### What is the expected result?
No php error

### What do you get instead?
PHP error:
```
Notice:  Undefined offset: 1 in /var/www/myproject/vendor/yiisoft/yii2/log/Target.php on line 362
Stack trace:
  1. yii\base\ErrorHandler->handleException() /var/www/myproject/vendor/yiisoft/yii2/base/ErrorHandler.php:0
```

### Additional info
The bug happens because you split the timestamp by ".".
In my locale (german) it is a ",". Maybe you can fix it with a simple strpos first or maybe you can use some yii-locale functions.
