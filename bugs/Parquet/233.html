Title

Parquet Java uses incorrect stats and dictionary filter properties

Description
In   SPARK-24251  , we found that the changes to use HadoopReadOptions accidentally switched the  properties that enable stats and dictionary filters . Both are enabled by default so it is unlikely that anyone will need to turn them off and there is an easy work-around, but we should fix the properties for 1.10.1. This doesn't affect the 1.8.x or 1.9.x releases (Spark 2.3.x is on 1.8.x).
