Title

to_timestamp should allow numeric types

Description
SPARK-38240   mistakenly disallowed numeric type at to_timestamp. We should allow it back: 

  
 
spark.range(1).selectExpr( "to_timestamp(id)" ).show()
 
  

  Before  

  
 
+-------------------+
|   to_timestamp(id)|
+-------------------+
|1970-01-01 09:00:00|
+-------------------+
 
  

  After  

  
 
+-----------------+
| to_timestamp(id)|
+-----------------+
|              null |
+-----------------+
