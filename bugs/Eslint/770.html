Title

Description
In [Link: `nodejs-api.md`] it says:

But only enumerates 3 parameters. Inspecting the [Link: source code and comments] reveals these differences from what's documented:
- It accepts 3-4 arguments.
- # 3 can be an options object or filename string.
- If # 3 is an object, the value of `saveState` is taken from its prop of the same name. Otherwise its the value of arg # 4 (if passed).

When this is updated it might make more sense to just enumerate the params and their optionality rather than stating the number literally.
