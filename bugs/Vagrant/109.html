Title

config.vm.box does not allow spaces/ is parsed as URI

Description
### Vagrant version
Vagrant 1.9.6

### Host operating systems
Tested on both:
macOS Sierra 10.12.5 (16F73)
Ubuntu 14.04

### Guest operating systems
centos 73 x64
centos 72 x64 ... and others

### Vagrantfile
```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "centos 73 x64"
  # URL below removed due to security requirements, but confirmed correct in our atlas
  config.vm.box_url = "[URL] valid atlas url" 
```

### Debug output
[URL]

### Expected behavior
Vagrant should accept boxes that have spaces in their name. Vagrant versions that use ruby prior to 2.2.0 appear to work fine.  

### Actual behavior
Vagrant throws an exception due to a failure to parse the config.vm.box name. 

### Steps to reproduce
1. Host a vagrant box file that uses spaces (or perhaps other non-escaped characters) in the config.vm.box
2. Perform a vagrant up
