Discussion
- Good point! This is an unwanted side effect of the fact that the [code-example][1] and [code-pane][2] elements as well as the [@example][3] dgeni tag-def expect the example's header to be defined via the `title` attribute (which has a special meaning in browsers).

##
The proper solution would be to change the `title` attribute to something else (e.g. `header`), but that might affect many files through-out the code base (I haven't actually checked how many examples use titles).

A less intrusive alternative would be to have the components remove the `title` attribute from the host element once they read the value (which should be fine because the title cannot change dynamically anyway).
