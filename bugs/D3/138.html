Title

Parsing week numbers using d3.time.format

Description
Hi.
I have a problem parsing weeks.
I'm using d3 v3.4.8.
I have dates in a format like `2014-19` - but the format is not a problem, since I have the same problem using `2014(19)`, `2014 19` and so on...
Is it possible to parse such string using `$Y-$W` or `$Y-$U`? e.g.

``` javascript
d3.time.format('%Y-%W').parse('2014-19');
```

Because I obtain as a result always the date corresponding to the 1st of January 2014

``` javascript
Date {Wed Jan 01 2014 00:00:00 GMT+0100}
```

I'm also parsing months, years, days and it works well. Only weeks are not working.

Thank you
Michele
Discussion
- Actually, there is a workaround, but I'd need to manually add also `%w` with value `0`. E.g.

``` javascript
// I'm getting from elsewhere the 'x' variable, a date in the format YYYY(WW)
x = d3.time.format('%Y-%W-%w').parse(w.replace(/([0-9]{4})\(([0-9]{2})\)/g,"$1-$2-0"));
```

Thank you
- Yes, at the moment we require the day-of-week (`%w`) for the week-of-year (`%U` or `%W`) to be parsed.  I don’t see any particular reason why we can’t drop that requirement and use suitable defaults.
- New behavior:

```
Mon May 12 2014 00:00:00 GMT-0700 (PDT)
Sun May 11 2014 00:00:00 GMT-0700 (PDT)
```
- Fix staged in #2591 for 3.5.7.
