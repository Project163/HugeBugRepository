Title

File not detected due to watching reporting events on old, deleted path

Description
### Does your log mention database corruption?
No

---

When trying to reproduce the issue #7032 I saw that sometimes folders would not sync.

### The setup

First system
+ Linux Mint 20 ulyana
+ syncthing v1.10.0 "Fermium Flea" (go1.15.2 linux-amd64) deb@build.syncthing.net 2020-09-15 17:38:23 UTC [noupgrade]

Second system
+ Ubuntu 18.04 bionic
+ syncthing v1.10.0 "Fermium Flea" (go1.15.2 linux-amd64) deb@build.syncthing.net 2020-09-15 17:38:23 UTC [noupgrade]

### Steps taken

1. Create a new folder in the default sync directory with the linux file browser 'nemo'.
1. Initially the folder is named "Untitled folder".
1. Accept the name by pressing enter.
1. Wait for the folder to be synchronized to the second computer.
1. Rename the folder on the first computer to `tmp`.
1. Wait for the rename to be synced to the second computer.
1. Create a new folder inside `tmp` via Nemo on the first computer.
1. Rename it immediately to `a`.
1. Before the folder is created on the second system create a file inside the folder `a`.
1. The file is initially named `Untitled Document`.
1. Rename the file to `a`.
1. The folder `a` and the document inside it called `a` are never synced to the second system.
