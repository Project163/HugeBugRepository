Title

No namespace assigned in Executor Pod ConfigMap

Description
Since Spark 3.X, Executor pod needs separate executor configmap. But, no namespace is assigned in configmap when building it. K8s views configmap without namespace as global resource. Once pod access is restricted (global resources cannot be read), and executor cannot obtain configmap itself.
