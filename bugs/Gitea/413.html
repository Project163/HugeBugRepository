## Description

I often find multiple `git blame` instances launched by `gitea` sticking around forever. They're not unreaped child processes, they're actually still running.

Sometimes attaching truss/strace/dtrace shows nothing, but other times it shows that they are actively writing:

```
mqudsi@freebsd> sudo truss -p 9222  # this is one of the "stuck" `git blame` processes
write(1,"   )
write(1,"">24  )
write(1,"er;vertical-align:middle;\\" wid"...,4096) = 4096 ( )
... [Log Snipped] ...
write(1," style=\\"text-align:center;vert"...,4096) = 4096 ( )
write(1,"e=\\"text-align:center;vertical-"...,4096) = 4096 ( )
```
