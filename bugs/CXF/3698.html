Title

OSGi bundle manifest are broken since version 4

Description
The CXF Maven jar artifacts are also OSGi bundles because they contain the corresponding metadata in  META-INF/MANIFEST.MF . However, since version 4 the OSGi metadata is broken because the  Bundle-SymbolicName  entry is empty. This makes these files unusable as OSGi bundles.
Discussion

I think we could fix the manifests part, I am wondering which OSGi container you use for deploying Jakarta EE 9+ applications? Thank you.
- We are using CXF for JAX-RS clients in an Eclipse-based desktop application. Hence we need OSGi bundles. 

 It's no problem if the OSGi manifest were completely removed because we can easily create them ourselves (using the p2-maven-plugin). But if there is an existing manifest it won't be touched and if that one is broken...
