Title

3.0 Session::renew() problem

Description
I came to this problem while using AuthComponent, I found that Auth's sessions never persisted.
Seems to be caused by Session::renew(), as it fails to renew current session when no session was started previously, from current renew() implementation:

```
php
if (!$this->_hasSession() || $this->_isCli) {
    return;
}

... [Log Snipped] ...
);
session_regenerate_id(true);
```

I think session_regenerate_id(true) should be used only if a valid session id already exists:

``` php
if (session_id()) {
  // rest of the logic
}
```

PS: Actually 2.x implementation of this method includes this `if (...)` condition
