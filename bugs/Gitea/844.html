Title

Can not set default_delete_branch_after_merge using API

Description
### Description

It is not possible to set default_delete_branch_after_merge using API.

E.g.

```
curl  --header "Content-Type: application/json-patch+json" -H 'Authorization: token TOKEN_HERE'  -X PATCH -d '{"default_delete_branch_after_merge": true}' [URL]
```
