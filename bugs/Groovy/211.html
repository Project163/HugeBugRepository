Title

Problem invoking a method with arrays as arguments

Description
It seems to be impossible to invoke methods that take arrays as arguments. See the included test case.
Discussion
- this is not true in general: 

 list =  [1,2,3,4,5]  
int[] array = list.toArray([] as int[]) 
assert array.class.name == "[I" 

 but it does not work for your example. Maybe it's because the method is static
- In fact, this is not a bug, but rather an error in that script. 
Runtime.getRuntime.exec() should be used instead of Runtime.exec(), since (as Kim spotted) exec() is an instance method of Runtime, not a static method. 
So the problem isn't about invoking a method with an array as parameters.
