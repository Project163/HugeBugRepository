Title

[YSQL] [Index Backfill] Concurrent CREATE INDEX and INSERTs leads to a crash

Description
(Depends on #4585, caused by #4254)

With index backfill for YSQL enabled, if we're doing repeated `INSERT`s while `CREATE INDEX` is issued in a separate thread, `INSERT` thread will crash a `postgres` process with the failure:
```
ts1|pid73116|:14245|[URL] 2020-07-02 00:00:15.811 +05 [73158] LOG:  invalidating table cache entry  
ts1|pid73116|:14245|[URL] 2020-07-02 00:00:15.811 +05 [73158] STATEMENT:  Y*�
ts1|pid73116|:14245|[URL] TRAP: FailedAssertion("!(portal)", File: "../../../../../../src/postgres/src/backend/tcop/postgres.c", Line: 4057)
```
Process itself crashes with this stack trace:
```
Thread 0 Crashed:: Dispatch queue: com.apple.main-thread
0   libsystem_kernel.dylib        	  __pthread_kill + 10
1   libsystem_pthread.dylib       	  pthread_kill + 284
2   libsystem_c.dylib             	  abort + 127
3   postgres                      	  ExceptionalCondition + 78
4   postgres                      	  yb_restart_portal + 408 (postgres.c:4058)
5   postgres                      	  PostgresMain + 3055 (postgres.c:4979)
...
```

This is a regression introduced by read restart work done in #4254 - we're trying to restart a portal that has been destroyed
