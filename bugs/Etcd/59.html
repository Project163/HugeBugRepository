Title

Unix domain socket support

Description
Hi. In the [Link: documentation for --listen-client-urls], the docs say that a unix path like `unix:// ` can be used.

However, due to [Link: this validation code], unix domain sockets cannot actually be used. We get an error like the following:

```
URL address does not have the form \"host:port\": unix:///var/etcd/data/datafile"
```

Is my use of the flag correct? `--listen-client-urls=unix:///var/etcd/data/datafile`

Has anyone had success using unix sockets with etcd?
