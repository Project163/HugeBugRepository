Title

d3.format('-.2f') prepends a minus

Description
There seems to be some issues with the specifier parsing in d3.format()
Here is an example:

d3.format('+.2f')(331.213)
returns +331.213 as expected
d3.format('+.2f')(-331.213)
returns -331.213 as expected

d3.format('-.2f')(331.213)
returns -331.213 but expected 331.213
