Title

ServiceConstructionException thrown when refreshing a child Spring context

Description
The exception "org.apache.cxf.service.factory.ServiceConstructionException: There is an endpoint already running on /childendpoint" is thrown when refreshing a child Spring context containing a JAX-RS server created using the <jaxrs:server> notation and when a JAX-RS server is also defined in the parent Spring context.
Discussion
- Sample application that reproduces the issue
- Proposed patch that fixes the issue by calling the destroy() method of the Server instance created by the SpringJAXRSServerFactoryBean when the factory is destroyed.
- I've applied a slightly modified patch, thanks
