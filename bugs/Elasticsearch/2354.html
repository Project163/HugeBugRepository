Title

SQL: Incorrect error message when the not allowed grouping is used in ordering as well

Description
```
sql> SELECT ROUND(AVG(salary), 2), AVG(salary), COUNT(*) FROM test_emp GROUP BY AVG(salary) ORDER BY AVG(salary) DESC;
Bad request [Found 1 problem(s)
line 1:97: Cannot order by non-grouped column [AVG(salary)], expected [AVG(salary)]]

sql> SELECT ROUND(AVG(salary), 2), AVG(salary), COUNT(*) FROM test_emp GROUP BY AVG(salary);
Bad request [Found 1 problem(s)
line 1:76: Cannot use an aggregate [AVG] for grouping]
```

The first query fails with a confusing error message, whereas I believe it should have failed with the second error message in the first place: AVG cannot be used for grouping.
