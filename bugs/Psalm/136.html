Title

Enhancement: suppress error output with --find-references-to

Description
Currently when you run `psalm --find-references-to='Class\Name'`, in addition to found references it additionally outputs a lot of errors (UnusedVariable and UnusedParam, which are not reported during regular runs).

It clutters the output and is not something you're interested in when you're trying to find where the class is used. Could it be automatically suppressed?
