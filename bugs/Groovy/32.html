Title

NullPointer when calling a java.util.Arrays.asList()

Description
a = [].toArray(); 

 System.out.println(java.util.Arrays.asList(a)); 

 Gives the following error... 

 Caught: java.lang.NullPointerException: Cannot get property: util on null object

Discussion
- This is actually a different problem.  This works: 

    import java.util.Arrays 
   a = [].toArray() 
   println( Arrays.asList( a ) ) 

 The problem is that you can't directly call methods on a fully qualified class name.  So, java.util.Arrays.whatever() will fail because Groovy thinks you're trying to call the whatever() method on a the Arrays property of the util property of a variable named java.
