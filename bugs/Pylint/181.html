Title

pylint incorrectly complains about missing member

Description
### Steps to reproduce
1. Create a Python script containing the lines
   
   ``` python
   import sys
   sys.stdout.buffer.write(b'hey\n')
   ```
2. Execute aforementioned Python script via Python 3.5 (maybe any Python 3.x will do?). It should merely print `hey` and not run into any problems.
3. Run `pylint  `
### Current behavior

Pylint complains with

```
E:  2, 0: Class 'buffer' has no 'write' member (no-member)
```
### Expected behavior

Pylint should not produce any output at all.
### Workarounds
- The `buffer` field can be accessed via `getattr(sys.stdout, 'buffer')`.
- The error can be disabled locally by adding the inline option `# pylint: disable=no-member`.
