Title

SslContextFactory's ciphers doesn't work with control.sh utility

Description
There is no options for control.sh utility if ciphers feature enabled on server 

 If this property enabled on server: 
  
 
        <property name= "sslContextFactory" >
            <bean class= "org.apache.ignite.ssl.SslContextFactory" >
               ...
                <property value= "TLS_RSA_WITH_NULL_SHA256, TLS_ECDHE_ECDSA_WITH_NULL_SHA, TLS_ECDH_RSA_WITH_NULL_SHA"  name= "cipherSuites" />
               ...
            </bean>
        </property>
 
  

 Control.sh utility doesn't work
