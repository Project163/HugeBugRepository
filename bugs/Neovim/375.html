Title

Insert mode spelling completion help text is wrong

Description
### Problem

## Background

When using [Link: insert mode completion], a useful message is displayed on the command line. For instance, pressing `  ` will show the text

```
-- File name completion (^F^N^P) match 1 of 43
```

Here, the `^F^N^P` part is telling you that you can press either  Ctrl - f ,  Ctrl - n , or  Ctrl - p . Pressing  Ctrl - f  will kind of "repeat" the original `  ` action, which will move to the next item in the completion list. Using the `n` and `p` actions are like "next" and "previous", which will go up and down the list.

When using another completion mode, the help text might say `^L^N^P` or `^D^N^P` for example.

## Issue

With the spelling completion, the text is wrong. It should say `^S^N^P`, but it instead says `s^N^P`.

I assume this is becuase the code is just inserting a string corresponding to what the user typed into the message to be displayed. But in this case, following the help text will lead you astray. To move down the list, you need to press  Ctrl - s , not just  s .

### Steps to reproduce

1. Open vim with `vim -u NONE`
2. Run `:set spell` to enable spell check
3. Type `iasd s`
4. You will see that the suggestion is working, and you can press ` ` to move down the list, but the help text on the command line says `s` instead of `^S`.

### Expected behavior

You should expect the help text to match the actual behavior. The help text should say `^S^N^P` instead of `s^N^P`.
