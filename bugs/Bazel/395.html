Description

Discussion
- The reason it fails is because cc_test rules depend on `//tools/defaults:crosstool`, on Unix, bazel creates a dangling symlink pointing to  /tools. But on Windows, symlink doesn't exist, so it fails.
If you create an empty `tools` folder under work workspace root, it should works, 

Thanks for reporting, this is definitely a bug in Bazel we should fix.
