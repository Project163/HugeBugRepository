**Current behavior**
With `enableLegacyTemplate` set to false (must be hardcoded in `CompilerConfig`, see #15555 for issue in disabling this option), ` ` child elements are appended using `templateEl.appendChild(childEl)`. This should be `templateEl.content.appendChild(childEl)` to correctly append child elements to the template's document fragment.

[Image: screen shot 2017-03-28 at 10 25 29 am]

In the above screenshot, the template inside Angular's ` ` is incorrectly rendered. The template outside is rendered correctly in Chrome.

Using `encapsulation: ViewEncapsulation.Native` does not resolve the issue.

**Expected behavior**
If the browser supports ` ` elements, children should be appended to the template element's content attribute.
