Title

I18N format with dotted parameters

Description
When using dotted parameters without parameter formatting everything works fine e.g.

`Yii::t('app', 'date: {dt.test}', ['dt.test' => time()])`

But when you add a parameter the formatter skips this placeholder and displays it without replacing the value provided.

### What steps will reproduce the problem?
Yii::t('app', 'date: {dt.test,date}', ['dt.test' => time()])

### What is the expected result?
To display a string like: "date: Jun 9, 2017"
### What do you get instead?
Displays "date: {dt.test,date}"

### Additional info
The problem lies in the  format method of I18N class on lie 112. The expression is` preg_match('~{\s*[\w]+\s*,~u', $message)` and should be `preg_match('~{\s*[\w.]+\s*,~u', $message)`.
