Title

Asterisk character not displaying properly in Adobe Reader

Description
From Matt B. in the user mailing list: 
 
 I have an odd issue with the asterisk character not displaying properly in Adobe Reader (XI or DC) 
The "*" is displayed on the document as a hollow box, all other characters seem to be ok.  

 I thought it was an issue with my code, so I gave it a try in the HelloWorldTTF.java example, and got the same results...with various different TTF fonts as well. 

 Attached is the test.pdf output file, using the LiberationSans-Regular.ttf font and input message "1*1". 
It was created using a 2.0.0-SNAPSHOT that I built earlier this morning, but I also had the same results using the RC1 binaries.
Discussion
- asterisk.pdf is the user file. helloworld.pdf is mine, it was created with the HelloWorldTTF example, and these parameters: 
  
 args =  new   String []{ "helloworld.pdf" ,
                     "The quick brown fox jumps over the lazy dog !\" #$%&'()***+,-./0123456789:;<=>?@",
                     "C:/windows/fonts/arial.ttf" };        
 
  
 There are three "*" after the "()". These are shown as ' in Adobe Reader.
- Stuff I found out: 
 
	 the "*" appears if the string also contains a "ß" 
	 the font has the symbolic flag. (why?) But changing the value to 32 (non symbolic) doesn't improve anything. 
This is done in TrueTypeEmbedder.createFontDescriptor(). In the PDTrueTypeFontEmbedder constructor the opposite is done (earlier).
- ... [Middle Discussions Snipped for Brevity] ...
- Great fix! 
I just built the latest snapshot, loaded it with my application, and the hollow boxes and/or single quotes are no longer replacing the asterisks in Adobe Reader. 

 Any indication as to why only Adobe Reader was affected, and not the built-in viewers for Chrome and Firefox? 

 Thanks again.
- Chrome and Firefox do it wrong, that is why, i.e. they just read the 0d as a 0d instead of converting it to 0a as in the spec. Ghostscript did it correctly, i.e. your file looked bad. Ghostscript is very high quality, very close to Adobe Reader.
