Title

docs: undocumented use of CELERY_CACHE_BACKEND in result_backend Configuration

Description
When using `django-celery-results` with the `CELERY_RESULT_BACKEND = 'django-cache'` setting, it is possible to use the `CELERY_CACHE_BACKEND`to specify a Django cache other than default.

[Link: Fix 5301] amended the docs for `django-celery-results` but the [Link: Configuration]page of the user guide describes this setting as "no longer used" and suggests it can be set directly in the [Link: results_backend] setting which is not documented.
