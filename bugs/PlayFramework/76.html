Title

Loss `Result` attributes by any modification

Description
### Play Version

`3.0.0`

### API

Java

### JDK

```
openjdk version "21.0.1" 2023-10-17 LTS
OpenJDK Runtime Environment Corretto- .1 (build 21.0.1+12-LTS)
OpenJDK 64-Bit Server VM Corretto- .1 (build 21.0.1+12-LTS, mixed mode, sharing)
```

### Expected Behavior

Adding cookies to an `Http.Result` should not clear the `Http.Result` attrs.

### Actual Behavior

I found this unexpected side effect of the `withCookies()` method by implementing something similar to this inside a [Link: Filter]:

```
java
// pseudo-code
return next.apply(rh)
        .thenApply(result -> {
            if (result.attrs().getOptional(CREATE_FOO_COOKIE).isPresent()) {
... [Log Snipped] ...
            return result;
        });
```

### Workaround

My workaround will probably be to simply do this in a single step, and adding all cookies at once. Since I do not need the attrs at a later stage, this will be sufficient for me. However, I do feel that this is unexpected behavior and a loss of the result's `attrs` may impact anyone who relies on those in their action composition.
