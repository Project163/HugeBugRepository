Title

3.0 patchEntity issue

Description
After patchEntity(), '0' value dissapears.

``` php
$user = $this->Users->newEntity();
$this->request->data('sort', '0'); // posted
$user = $this->Users->patchEntity($user, $this->request->data);
// results: $user->sort = null
```

$user can not be saved because of ['sort' int(10) unsigned NOT NULL].
I think `if ($original == $value) {} (in Marshaller.php)` causes this.
In addition, when creating via newEntity(['sort' => 0]), $user->sort keeps 0,
but passing `''` empty string value also dissapears.
Discussion
- I don't see a problem with this. For an integer column, treating empty string as null is more sensible.
- Pull request #4329 is open now.
