Title

Activefield->checkbox() causes browser to link label to wrong input

Description
**Yii Version** 2.0.0
**Browser** Firefox 31.2.0 on Linux

Activefield->checkbox() generates, with the default behaviour, a hidden input additionally to the checkbox input. 

The label for the checkbox input though isn't connected via _for_, but by enclosing the input by the label tag. What follows is a label linked to a hidden input (well, at least it isn't linked to the visible one, I think ff just takes the first input tag):

View code:

```
 field($model, 'ignoreWeakPassword')->checkbox() ?>
```

Generated HTML:

```
 
 
     
     
    Ignore Weak Password
 
  
 
```
Discussion
- The hidden input is outside of the label tag. Please check the "basic" app for an example.
- Actually it isn't. Same problem with the basic app on the site/login page for the remember me checkbox. Happens in the 2.0.0 but also with --stability=dev. 

```
 
  
Remember Me
 
```
- oh, this happens to `yii\bootstrap\ActiveField`, not `yii\widgets\ActiveField`.
- Fixed, thanks for reporting!
