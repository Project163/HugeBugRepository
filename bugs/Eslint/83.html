Title

Environment rules still enabled after using --reset

Description
We turn on certain rules in certain environments, for instance, the "node" environment enables `no-process-exit`. This rule is still enabled when using the "node" environment and passing `--reset` on the CLI.

We should make sure that environment-specific rules are also turned off when using `--reset`.
