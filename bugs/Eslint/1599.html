Title

Bug: `nodeTypeKey` not being used in `NodeEventGenerator`

Description
### Environment

Node version: v20.10.0
npm version: v10.2.3
Local ESLint version: v9.24.0 (Currently used)
Global ESLint version: Not found
Operating System: darwin 23.6.0

### What parser are you using?

Default (Espree)

### What did you do?

I've created a new ESLint plugin to support PHP using [Link: `php-parser`].

This parser returns the AST with `kind` instead of `type`, so according to the docs I should've set `nodeTypeKey` to `kind`.

Took me a while to figure out why none of my selectors were working (except `*`), but after reading through the code, I noticed that the `NodeEventGenerator` doesn't take the `nodeTypeKey` into account:

[URL]

I have a local patch that works, will open a PR once this issue is accepted 😄 

### What did you expect to happen?

`nodeTypeKey` being taken into account.

### What actually happened?

It wasn't.
