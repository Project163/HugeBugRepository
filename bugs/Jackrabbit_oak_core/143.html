Title

Binaries might get removed by garbage collection while still referenced

Description
The  Microkernel contract  specifies a specific format for references to binaries: ":blobId:<blobId>". Currently oak-core uses a different format and thus risks premature garbage collection of such binaries.
Discussion
- Using ":blobId:" instead of "bin:" to prefix binaries leads to special casing in how the type codes are interpreted. Worse, it might break  PrefixContentIndex  wrt. to the changes from   OAK-182  .
- This patch changes the prefix from "bin:" to ":blobId". All test cases pass. However I suspect  PrefixContentIndex  is now broken for binary properties.
