Title

debugging breaks loop

Description
### Description

After Upgrading from Cakephp v5.0.10 to v5.1 I have an issue with debugging query results in loops.
(I testet with v5.1.6 and v5.1.0, both have this issue)

Example Code
```
$query = $this->find()->all();    // or $this->find();
$i=0;
foreach($query as $row) {
 $i++;
// set a breakpoint within the loop
}
echo $i;
```

The issue happens on Query and ResultSet Objects.
If you enable x-debug and set a breakpoint within the loop, the loop breaks after the first item of the loop with i=1.
It you disable the debugger, the loop works fine.

ResultSet in Cakephp 5.0.10
[Image: Image]

ResultSet in Cakephp 5.1.x
[Image: Image]

I suspect it is related to the __debugInfo method within the ResultSet.
When xdebug parses the ResultSet it probably gets overwritten with this items array.

That's a major problem.
Debugging should never alter the behavior of the code because its purpose is to identify and fix existing issues without introducing new ones, ensuring the program runs as intended in its original context. Modifying the code during debugging risks masking errors or creating unintended side effects, leading to misleading conclusions and potentially new bugs.
