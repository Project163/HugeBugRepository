Title

FVH doesn't highlight nested fields

Description
**Elasticsearch version**: 2.2.2

**JVM version**: 1.8.0_25

**OS version**: OS X 10.11.5

**Description of the problem including expected versus actual behavior**:  
Fast Vector Highlighter doesn't highlight nested fields, whereas Plain Highlighter does (but has a [Link: fragment_size bug] so I can't use it). I would expect FVH to be able to highlight everything.

**Steps to reproduce**:

```
sh
curl -XPUT 'localhost:9200/nested_fvh?pretty' -d '{
  "mappings": {
    "type1": {
      "properties": {
... [Log Snipped] ...
}
'
```

**Output (fvh)**:
 
 

FVH doesn't highlight nested 

```
json
{
  "took" : 3,
  "timed_out" : false,
  "_shards" : {
... [Log Snipped] ...
  }
}
```

 

**Output (plain)**:
 
 

Plain does highlight nested 

```
json
{
  "took" : 3,
  "timed_out" : false,
  "_shards" : {
... [Log Snipped] ...
  }
}
```
