Title

MapperParsingException on percolation with _size enabled

Description
This issue was introduced in v0.19.9.

Steps to reproduce:
1. create test index

```
curl -XPUT localhost:9200/test
```
1. update mapping

```
curl -XPUT '[URL] -d '
{
    "type1" : {
        "_size" : {
            "enabled" : true,
... [Log Snipped] ...
    }
}'
```
1. register percolator query:

```
curl -XPUT localhost:9200/_percolator/test/kuku -d '{
    "query" : {
        "term" : {
            "field1" : "value1"
        }
    }
}'
```
1. percolate a document:

```
curl -XGET localhost:9200/test/type1/_percolate -d '{
    "doc" : {
        "field1" : "value1"
    }
}'
```

This leads to the following error:

```

    ... 11 more

```
