Title

`Decimal` values in `Series` off by factor of a quadrillion when read out using `to_list()`

Description
### Polars version checks

- [X] I have checked that this issue has not already been reported.

- [Link: X] I have confirmed this bug exists on the [latest version] of Polars.


### Issue description

Decimal values can be scaled by enormous multipliers when read out using `to_list`.

**Setup:**

```
python
from decimal import Decimal
import polars as pl

with pl.Config( activate_decimals=True ):

```
