Title

`no-magic-numbers` should ignore parseInt radix param

Description
It seems odd to have to make an exception for this every time, or to declare a DEFAULT_RADIX constant for the entire codebase. Not sure what other people think since it is a fairly narrow (though possibly common) case. This is more of a problem with the `radix` rule.

Code:

```
parseInt("1234", 10);
```

Error:

```
  1:18  error  No magic number: 10  no-magic-numbers
```

Config:

```
"no-magic-numbers": 2
"radix": 2
```

Eslint Version: 1.7.0
