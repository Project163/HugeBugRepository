Description
1.3.0.Final quarkus:list-extensions doesn't work in non-quarkus project directory
`mvn io.quarkus:quarkus-maven-plugin:1.2.1.Final:list-extensions` works in any directory

mkdir foo && cd foo
mvn io.quarkus:quarkus-maven-plugin:1.3.0.Final:list-extensions

- @emmanuelbernard, I often use list-extensions when automating project skeleton creation. I usually run list-extensions in my current terminal session and not jumping into Quarkus project first.

But I see your point, running `mvn io.quarkus:quarkus-maven-plugin:1.1.0.Final:list-extensions` gives the latest available extension. Some people might be thinking those are Quarkus 1.1.0 related extensions.
