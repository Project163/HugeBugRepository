Title

Offline Compiler does not understand `@Component` enums

Description
See [Link: this].

Highlighting the button component in the screenshot, with the button styling. You can see that the `content` id used in the DOM does not match the one used in the style.
Discussion
- Please note that the content attribute _seems_ right (although it seems it always is the content of the root component and not the closest parent). The host attribute is the right one on the element, but it seems that the style was compiled using content everywhere. Putting a break point when the styles are loaded and running the following javascript works:

``` javascript
styles_MdCard[0][0] = styles_MdCard[0][0].replace(/_ngcontent/g, '_nghost');
```

Basically, just replacing `content` for `host` in the styles work, but obviously this is not the right fix.
- Also, note that this works as expected in the same exact app but in dynamic compilation.
