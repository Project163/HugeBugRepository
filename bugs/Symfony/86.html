Title

YAML does not escape hyphens when used in sequences

Description
I was comparing Symfony's compatibility with Spyc and found an issue with Symfony's YAML encoder.

The issue arose when encoding an array like this:

```
php
array(
  0 => 'One',
  1 => 'Two',
  2 => '-',
... [Log Snipped] ...
  5 => 'Four',
);
```

Symfony produces a YAML file like this:

``` yaml
- One
- Two
- -
- Three
- '|'
- Four
```

The hyphen is not quoted, but it should be. Other "Indicators" from the YAML standard seem to be encoded, like the pipe character in this example. Without quoting, when Spyc tries to read this YAML file, it considers the hyphen to be an empty entry, like this:

```
php
array(
  0 => 'One',
  1 => 'Two',
  2 => '',
... [Log Snipped] ...
  5 => 'Four',
);
```

The matching issue at Spyc is here: [URL] but I think this is an issue with Symfony's encoder, considering it's the one generating incorrect YAML.
Discussion
- There is actually 2 bugs here:
- a dumper bug
- a parser bug. The behavior of spyc is consistent with the parsing done by [Link: pyyaml] in Python and the ya2yaml gem (try it on [URL] with the example above)
- This is fixed now.
