Title

Usage of field set to null as value source leads to somewhat cryptic error

Description
Consider the following code snippet.

```
csharp
  public class TestClassFour
  {
    private static string sourceFour = "Rumpelstilzchen";
    public static string sourceFive = null;
... [Log Snipped] ...
    }
  }
```

If one attempts to run tests from such class, he will encounter the following issues:
1. An error being reported is not user friendly enough.

1. Test cases from perfectly valid value source are not discovered and cannot be run until the error is fixed.
