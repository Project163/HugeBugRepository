Title

Package manager applies the acHandling of parent package to all the subpackages

Description
Currently, if you install a package with subpackages then all the subpackages are installed with the acHandling defined in the parent package even if different acHandling is set for individual subpackages. Ideally, the acHandling defined (if any) in individual subpackages should take precedence over the acHandling defined in the parent package.
