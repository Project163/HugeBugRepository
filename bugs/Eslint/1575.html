Title

Rule Change: no-extra-boolean-cast should check final expression in comma operator expressions

Description
A comma operator/sequence expression should have its last expression checked in a boolean context. For example, the following should flag:
```js
if ((1, 2, Boolean(3))) {
    // do something
}
```
since it is equivalent to 
```js
if ((1, 2, 3)) {
    // do something
}
```
