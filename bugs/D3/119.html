Title

d3.time.format bug for some time-zones ahead of UTC

Description
Time-zones ahead of UTC that contain half hour or forty five minute increments don't format properly using d3.time.format. See the following example:

var format = d3.time.format("%Y-%m-%dT%H:%M:%S.%L%Z");
format.parse('2014-09-13T02:02:00.000+0430');
Output:
Sat Sep 13 2014 01:02:00 GMT+0430 (Local Daylight Time)

As you can see, an hour is being subtracted from the time. The time zones this seems to effect are UTC+03:30, UTC+04:30, UTC+05:30, UTC+05:45, UTC+06:30, UTC+09:30.
