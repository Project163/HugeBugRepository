Title

Print a reasonable ETA

Description
#### What is your current rclone version (output from `rclone version`)?

rclone v1.59.1
- os/version: centos 7.9.2009 (64 bit)
- os/kernel: 3.10.0-1160.71.1.el7.x86_64 (x86_64)
- os/type: linux
- os/arch: amd64
- go/version: go1.18.5
- go/linking: static
- go/tags: none

#### What problem are you are trying to solve?

Print a reasonable ETA, like >1yr when it is very slow rather than a negative number
[Image: image]


#### How do you think rclone should be changed to solve that?

When the speed is too low, just print a >1yr or similar in the ETA. 

Also, only showing 2 units seems better to read. For example, when the ETA is longer than 1d, only show `d` and `h`; when longer than 1h, only show `h` and `m`; etc.
