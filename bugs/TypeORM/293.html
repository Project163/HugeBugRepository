- Could you try turn on the query log (see [URL] so we can see exactly what the broken query looks like?
- This isn't a complete example.  `CommonEntity`, `PaymentType`, `OrderStatus`, etc are all missing - in the future, please create a minimally reproducible example & include the actual queries being generated.

However, I made a much smaller version of what you've got:

[URL]

You need to specify a `@JoinColumn()` on your relationships - and specifying them to the values you'd expect them to be.

You're seeing this failure because we always expect a default join condition.

[URL]

The query that is generated is as such:

```sql
SELECT "order"."id" AS "order_id", "order"."carAddressId" AS "order_carAddressId", "address"."id" AS "address_id" FROM "order" "order" INNER JOIN "address" "address" ON  AND ("address"."id" = "order"."carAddressId")
```

I'm going to open a separate issue to tackle the condition-less join after I confirm there are no other issues similar to that - but I am pretty sure this issue is an error in how you've configured your entities.
- Adding `@JoinColumn()` worked for me as well
