Title

Pjax in ENV_TEST gives an warning on ob_end_clean in widget

Description
When using a widget which uses Pjax and the environment is test, gives a warning. This happens because the widget tries an ob_end_clean when a exception is thrown. Pjax itself throws an ExitException sinds the appliction is terminated and before that gets and cleans the output buffer.

Problem in \yii\base\Widget.php in function widget

```
try {
        /* @var $widget Widget */
        $config['class'] = get_called_class();
        $widget = Yii::createObject($config);
        $out = $widget->run();
... [Log Snipped] ...
        throw $e;
    }
```

Possible solution

```
try {
        /* @var $widget Widget */
        $config['class'] = get_called_class();
        $widget = Yii::createObject($config);
        $out = $widget->run();
... [Log Snipped] ...
        throw $e;
    }
```
