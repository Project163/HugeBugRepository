Title

[Transform] Not able to force stop a transform if state has not been written

Description
In the unlikely event of a 

1. transform fails at the very beginning after `_start`
2. no state document got written
3. node is reloaded

it can happen that the transform task is reloaded with the combination indexer:`stopped`, task state: `failed`. In this case the task can not be stopped using `_transform/{id}/_stop?force=true`

## Repro:

- create a transform that immediately fails, you might need to set `defer_validation=true`
- stop the node and restart it

-> The task is loaded and indexer state is stopped
