Title

connect-plugin-path crashes with UnsupportedOperationException on plugins without ServiceLoader manifests

Description
The connect-plugin-path tool crashes when processing plugins that have loadable classes but no ServiceLoader manifest files due to attempting to modify an immutable Collections.emptySet(). 

 Line 329 in ConnectPluginPath.java: 
  
  
 
nonLoadableManifests.getOrDefault(pluginDesc.className(), Collections.emptySet()).remove(pluginDesc.type());    
  
   
When the plugin class doesn't exist in nonLoadableManifests, getOrDefault() returns immutable Collections.emptySet(), causing UnsupportedOperationException on .remove().
