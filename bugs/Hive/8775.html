Title

Hive in-place migration to iceberg fails when there is a timestamp column

Description
Hive in-place migration to iceberg fails when there is a timestamp column 

 Below are the steps to reproduce the issue. 
  
 CREATE EXTERNAL TABLE test(`id` int,`name` string,`dt` timestamp)STORED AS PARQUET;
insert into test values (1, "test name" , cast('2024-08-09 14:08:26.326107' as timestamp));
select * from test;
ALTER TABLE test SET TBLPROPERTIES ('storage_handler'='org.apache.iceberg.mr.hive.HiveIcebergStorageHandler', 'format-version' = '2');
select * from test;
