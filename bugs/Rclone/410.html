Title

standardize rclone webdav implementation valid for duplicacy

Description
#### What is the problem you are having with rclone?

Trying to set up duplicacy webdav respository through rclone webdav sharing.

Linked to [Link: Rclone webdav Storage path test/ does not exist]

In order to do so, I have configured a remote storage (oneDrive, openDrive, JottaCloud, does not matter) and I am sharing it through rclone serve webdav . I can access through davfs to the share and create files and folders however if I try to set up a repository with webdav support within duplicacy, it fails with the error:
**ERROR STORAGE_CREATE Failed to load the WebDAV storage at webdav://iguana@localhost/test: Storage path test/ does not exist**


#### What is your rclone version (output from `rclone version`)

**rclone v1.46.0-028-g972e27a8-beta**


#### Which OS you are using and how many bits (eg Windows 7, 64 bit)

debian in arm rock64 board. But tried also in x86/64.

####  Which cloud storage system are you using? (eg Google Drive)

the issue is not with any storage specifically, but with the webdav implementation of rclone to share files. **rclone serve webdav**.

#### The command you were trying to run (eg `rclone copy /tmp remote:tmp`)

Example of access through webdav.

Setup:

rclone side (htpasswd file contains username and pass, rootCA keys are added to the trusted root CA certs within the system and Duplicacy seems to accept the rootCA correctly). For any other interested in… [Link: Auto generated certs for localhost] and [Link: include your rootCA locally], I am not sure if duplicacy accepts webdav without certs, hence I created a new one based on the links.

Webdav serve:

 `# /usr/bin/rclone serve webdav oneDrive:/Duplicacy/dataReady64/ --addr localhost:443 --htpasswd /root/certs/htpasswd --cert /root/certs/rootCA.pem --key /root/certs/rootCA.key -v -v`
