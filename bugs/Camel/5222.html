Title

camel-blueprint - Using simple language on setProperty() failed with IllegalAccessException in case of blueprint

Description
.setProperty( "MyProperty" ).simple( "${bean:java.lang. System ?method=currentTimeMillis}" )
 
  

 This Java DSL setting Property using simple expression works well in case of the camelContext is created from Spring-DM/Spring configuration. 

 But the IllegalAccessException error will be thrown in case of the camelContext is created from blueprint.

 The minimal project is attached to easy reproduce this issue.
Discussion
- Try with 2.25.1 and 3.0.1
- Checked also on released 2.25.0, 3.0.1, and the master branch, the same IllegalAccessException is thrown. 

 In case of Spring/Spring-DM, the SpringInjector is used to create the bean instance, where the private default constructor of the class is supported properly. 
  
 
applicationContext.getBeanFactory().createBean(type, autowireMode, dependencyCheck);
 
  

 In case of Blueprint, the DefaultInjector is used to create the bean instance, but the ObjectHelper.newInstance() seems not properly support the private default constructor. 
  
 
 return  type.getDeclaredConstructor().newInstance();
