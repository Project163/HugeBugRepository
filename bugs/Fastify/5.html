- Hi, thank you for checking out the project!
The correct way to use `async/await` in your case is to return `isEverythingGreat `.
```js
async(req, res) => {
   // Get a boolean
  const isEverythingGreat = await getFeelings();
  return isEverythingGreat
}
```
You also have encountered a problem that we are fixing in [URL] we'll also update the documentation to explain better how use correctly `async/await` functions.
