Title

Unable to invoke a REST back-end with the OPTIONS verb

Description
Unable to invoke a REST back-end with the OPTIONS verb when going through the pass through transport.
Discussion
- Nuwan, any more info on this. An error log or something?
- This turned out to be more serious than previously expected. Looking into this now. I think I know what the problem is.
- Fixed and added a test case (integration test 10003). Fix was to call setSerializationCompleteWithoutData method for all outgoing requests that don't have an entity body. Requests like OPTIONS and HEAD fall under this category in HTTP Core, so calling the above method triggers the necessary I/O operations at the TargetHandler.
