Title

StatelessXmlReporter#getTestProblems() does not properly reflect report schema structure

Description
According to  [URL] and  [URL] not all nested elements contain  stackTrace ,  system-out  and  system-err  elements, but the code makes it conditional whether there is a stack trace or not. This does not comply with the schema definition. Either the nested element is simple content or complex. In the latter  stackTrace  is mandatory, even if there is no strack trace according to the schema. The system streams are optional.
