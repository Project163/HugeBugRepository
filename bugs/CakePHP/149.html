Title

TableRegistry doesn't respect plugin name for table class

Description
I have two plugins: Motors and CarsDB, and I have two table classes: `Motors\Model\Table\VehiclesTable` and `CarsDB\Model\Table\VehiclesTable`.
When I load first model by `TableRegistry::get('Motors.Vehicles')` I get obvious `Motors\Model\Table\VehiclesTable`, but when I later load `TableRegistry::get('CarsDB.Vehicles')`, I still get `Motors\Model\Table\VehiclesTable`.
TableRegistry::get($name) splits $name into plugin and model name, but remembers only model name. I think, table registry should remember also plugin name.
I know that, table registry simplify usage of model loading and plugin name is optional, but if we specify plugin name, then table registry should respect that. I think, if we doesn't specify plugin name in model name, then registry should return first occurrence of model, but if we specify plugin name, then table registry should return right table.
