Title

Cassandra: Reverse scans don't work correctly with static columns

Description
It looks like, when using reverse scans, the results for the static and regular columns aren't joined properly.

Setup: 
```
create keyspace example;
use example;
create table test(h int, s int static, r int, v int, primary key (h, r));
insert into test(h, s, r, v) values (1, 1, 1, 1);
insert into test(h, s, r, v) values (1, 1, 2, 1);
```

Actual Result:
```
cqlsh:example> select * from test where h = 1 ORDER BY r DESC;

 h | r    | s    | v
---+------+------+------
 1 |    1 | null |    1
 1 | null |    1 | null
```
Expected result:
```

cqlsh:example> select * from test where h = 1 ORDER BY r DESC;

 h | r | s | v
---+---+---+---
 1 | 2 | 1 | 1
 1 | 1 | 1 | 1
```
