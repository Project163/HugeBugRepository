Title

Incorrect javadoc syntax for web links in StaticHostProvider.java

Description
StaticHostProvider#updateServerList  uses wrong syntax to embed https link in the java doc. Previously this issue was not visible because StaticHostProvider was not public of public java doc; after   ZOOKEEPER-2829    StaticHostProvider  is now part of API doc and incorrect syntax leads to java doc warnings, which creates noises in Jenkins pre-commit jobs.

       ZOOKEEPER-2862  : Incorrect javadoc syntax for web links in StaticHostProvider.java. 

     Javadoc does not offer any special tagging for web links - the "@link" etc is for linking with other javadocs of the classes / methods. Use normal html markup instead.
