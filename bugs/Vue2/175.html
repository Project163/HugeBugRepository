Title

Value inside v-slot in a v-for won't update

Description
### Version
2.6.0

### Reproduction link
[Link]
jsfiddle: [URL]






### Steps to reproduce
You can see the problem on a deployed version of [URL] here: [URL]

You run into a problem like that if
1. you have a v-slot inside a v-for and in that v-slot you render an item from v-for
2. you update whole array that drives the v-for

### What is expected?
Rendered item in v-for should behave in a same way as rendered item in v-for inside a v-slot - it should be re-rendered when the whole array driving the v-for changes.

I'd expect no changes in behavior from Vue 2.5.22. You can see how it behaves on the same code with `vue 2.5.22`. I have deployed same code with downgraded Vue version here: [URL]
