Title

LIKE escaping for Cubrid/MSSQL/Oracle/SQLite is wrong in QueryBuilder

Description
Hi!

I'm using Yii 2.0.3 and MSSQL server 2008 R2 and `QueryBuilder::buildLikeCondition()` is currently wrong for MSSQL. It works sometimes, but not if a second operand contains `%`, `_`, `[` or `]`. They should be escaped as `[CHAR_TO_ESCAPE]` or you should add `ESCAPE '\'` in the end of a LIKE statement (and you still need to treat `[` and `]` for MSSQL).

See [URL] for more information.

**2017-02-20**:
While solving this issue in #13623, I discovered that the following drivers are also affected:

Driver | Problem
--- | ---
Cubrid | May or may not have an escape character depending on settings. See [URL]
Oracle | Doesn’t have an escape character by default. See [URL]
SQLite | Doesn’t have an escape character by default. See [URL]
