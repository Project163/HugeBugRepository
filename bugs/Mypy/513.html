Title

Dataclass inheritance: Missing override.

Description
### Version 0.630

### Description
The problem seems to be that mypy derived classes do not override base classes. Looking at the dataclass plugin `collect_attributes` method, it is not clear that it does a reverse MRO lookup as mentioned in the dataclass spec (https://docs.python.org/3/library/dataclasses.html#inheritance). Let me know if you would like me to suggest a pull request.

### To reproduce
```
from typing import Any, Dict

from dataclasses import dataclass


... [Log Snipped] ...
class C(Base):
    some_int: int
```
Discussion
- I think mypy should match whatever happens at runtime here. Feel free to submit a PR.
