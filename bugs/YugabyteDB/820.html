Title

[docdb] The last op in the WAL with id has a term (7) that is greater than the latest recorded term, which is 6

Description
Jira Link: [Link: DB-3883]
### Description

Env:
- run 2 clusters with RF=3 3 nodes c5.xlarge
- setup bi-directional xcluster replication with platform UI (2 replication source   sink)
- create 1 table with 11 columns with different datatypes (column names k primary, v1-v11 with different datatypes)
- cluster/platform version:   -b46 

Steps:
1. Load data for some time (2-15 min) in table on both clusters - with different primary key parts: for example in cluster 1 `k = "[UUID1]:key:1"` in cluster 2 `k = "[UUID2]:key:1"`. Different keys but in one table
2. In same moment in background do nemesis actions on both clusters: Restart VM, Slow network between nodes in cluster, Start/stop VM, start/stop master/tserver process
3. Check that information is replicated
4. Check that cluster has no FATAL logs
