Title

3.0 - Call to a member function quote() on a non-object (playing with Table::createSql)

Description
``` php
    $db = \Cake\Datasource\ConnectionManager::get('default');
    $schema = $db->schemaCollection();
    $table = $schema->describe('matches');
    debug($table->createSql($db));
```

first time generates:

```
[
    (int) 0 => 'CREATE TABLE `matches` (
`id` INTEGER(11) UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '',
`code` VARCHAR(50) NOT NULL COMMENT '',
`home` VARCHAR(50) NOT NULL COMMENT '',
... [Log Snipped] ...
)'
]
```

Refreshing the page, error:

```
Error: Call to a member function quote() on a non-object    
File /home/***/apps/app/vendor/cakephp/cakephp/src/Database/Driver.php  
Line: 208
```

But running:

```
Console/cake orm_cache clear
```

Next refresh is ok, all the others give fatal error again

Bit debugging bring me to line 208 (as suggested in error reporting)

``` php
    return $this->_connection->quote($value, \PDO::PARAM_STR);
```

where $this->_connection is **null** if `$value` is `''`.

Other hints:

`'quoteIdentifiers' => false` gives always the error, the first time already.

My _feeling_ is that quoting is applied only when metadata are generated, not when cache is involved. Also i cannot understand why quoting is needed in that schema where no reserved key is involved.

I will investigate on the issue and i will report other _clue_ if i found some :)
Discussion
- If you turn identifier quoting on it is applied to all columns.

Also i think it is expected that once you set it to **on** all problems (_should_) go away in one shot (at cost that performance issues come in, of course).

3. good, first page loading seems ok, all happy -> _drink_
4. second time i load the page the error comes in.. so quoting is not applied or something there is not ok. -> **error**, _drink more_

Sorry if there is something stupid under my eyes i don't see or if i'm explaining it in a bad way :(
