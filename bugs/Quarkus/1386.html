Title

-DdebugHost= wrong test for debug port already in use

Description
### Describe the bug

Given 2 apps in devmode, run subsequently, trying to run them on different loopback addresses:

Case 1:
`./mvnw quarkus:dev`
ok
`./mvnw quarkus:dev -DdebugHost= `
Error, port 5005 already in use, not running in debug mode. _A little unexpected_

Case 2:
`./mvnw quarkus:dev -DdebugHost= `
ok
`./mvnw quarkus:dev -DdebugHost= `
ok

Case 3:
`./mvnw quarkus:dev -DdebugHost= `
ok
`./mvnw quarkus:dev -DdebugHost= `
Error, port 5005 already in use, not running in debug mode. _Unexpected_

### Expected behavior

Case 3 probably should work ok.

### Actual behavior

It seems that quarkus tests on whether the debug port is open via trying  :5005 , even though debugHost is not   for the current application instance.
