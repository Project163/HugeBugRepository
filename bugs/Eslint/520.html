Title

prefer-arrow-callback and named functions

Description
`prefer-arrow-callback` is incorrectly warning when using a named callback. If the function is named and it's being referenced, it should not warn because arrow functions can only be anonymous. Example:

``` js
// warns but it shouldn't
foo(function bar () {
    bar();
});
```
