Title

AppearanceGeneratorHelper assumes fontscale 1000

Description
The user in the attached SO question noticed that the comb adjustment needed a factor of 2 to work correctly. A look at the font shows UnitsPerEm = 2048. 

 Sample code: 
  
 
doc.getDocumentCatalog().getAcroForm().getField( "field1" ).setValue( "WWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWWW" );
doc.getDocumentCatalog().getAcroForm().getField( "field2" ).setValue( "MMMMMMMMMMMMMMMMMMMMMMMMMMMMMMMMMMMMMMMM" );
Discussion
- At least for TrueType fonts we have to take the value of unitsPerEM into account. In most cases it is 1000 but there are fonts using 2048. 

  org.apache.fontbox.ttf.TrueTypeFont.getUnitsPerEm()   can be used to get that value
- There is a usage in DrawPrintTextLocations.java for the type 0 font too. I thought this issue is a low hanging fruit (just replace FONTSCALE) but it's not 😂

- It's always a bit tricky to fix these layout things as they are not documented.
