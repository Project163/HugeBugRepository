Title

Validator::equals() with strings

Description
### Description

[Link: `Validator::equals()`] does not accept string for `$value`.

So calling `$validator->equals('fieldName', 'test', __('Invalid code.'))`, that was working in cake 4, now producing error.

If only numbers are allowed here, what is the proper replacement for equals? Should we allow strings here?

### CakePHP Version

5.0.0-RC2

### PHP Version

8.1
Discussion
- Actually, [Link: Validator::equals()] uses comparison with `Validation::COMPARE_EQUAL` - not strict comparison.

It means that `$validator->equals('fieldName', 5)` will be passed for value `'005'`.
If we allow strings here, then `$validator->equals('fieldName', '005')` will be passed with `'5'`.

Its ok for numbers but not for strinigs.
- Should we rename `sameAs` to `sameAsField` to align with `equalToField`.

And make new `sameAs` that compares with some value using `Validation::COMPARE_SAME`?
