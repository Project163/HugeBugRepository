Discussion
- The docs indicate that this detection works fine for for-loops, for instance:

``` js
for (var j = 0; j < items.length; ++j) {
    doSomething(items[j]);
}
```

Where it detects that `j` is modified here.
- Well in the example from the documentation `j` is actually modified. In your case, only `i` is modified, but `j` stays static. So your code can be rewritten as:

``` js
var i = 0
while (++i < 10) {
  console.log(i)
}
```

I think the rule is doing the right thing in this case.

Although `j` is not used inside the loop, so I'm not sure if this is correct behavior. @mysticatea any insights?
