Title

Classes should not automatically inherit function signatures from interfaces

Description
This currently isn't caught by Psalm - it doesn't complain about `A::foo` missing a return type, because it supposes it's inherited from `I1`. But `I2` also has a matching docblock.

```
php
interface I1 {
  /** @return string */
  public function foo();
}
... [Log Snipped] ...
  }
}
```

This is a fatal error in PHP, not caught by Psalm

```
php
interface I1 {
  public function foo() : string;
}
interface I2 {
... [Log Snipped] ...
  }
}
```
