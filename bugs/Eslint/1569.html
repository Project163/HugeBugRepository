Title

Bug: `--no-ignore` applies to non-global ignores

Description
### Environment

Node version: v20.12.0
npm version: v10.5.0
Local ESLint version: v9.0.0-rc.0
Global ESLint version: no
Operating System: windows


### What parser are you using?

Default (Espree)

### What did you do?

 
 Configuration 

```
js
module.exports = [
  {
    ignores: ['index.js'],
    rules: {
... [Log Snipped] ...
  },
];
```
 

```js
foo();
```

Command:

```
eslint index.js --no-ignore
```

### What did you expect to happen?

I'd expect that `--no-ignore` affects only global ignores, and thus the config object with `ignores` and other keys is not applied to files that match its `ignores`, so there should be no lint errors.

### What actually happened?

```

```
