Title

Maven surefire provider NPE w/ the Spek TestEngine

Description
## Overview

## Deliverables
Discussion
- Looks like `stackTraceWriter` is `null` here:
[URL]

Apparently (there's no documentation on this), a Surefire `ReportEntry` that is passed to `testFailed()` must have a `stackTraceWriter`. However, our Surefire provider is only setting one when the `TestIdentifier` has a source of type `ClassSource` or `MethodSource`:
[URL]

So, to fix this, we should always set a `stackTraceWriter`. The can follow the look at the ancestors of the `TestIdentifier` until we find a `ClassSource` or `MethodSource`. If we still don't find one, we can fallback to the `Class` that is currently being executed:
[URL]
