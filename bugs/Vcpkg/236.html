Title

[shader-slang] can't start the process on linux platform

Description
**Host Environment**

- OS: Linux, Ubuntu 22.10 
- Compiler: idk (probably gcc)

**To Reproduce**

Steps to reproduce the behavior:

`./vcpkg install shader-slang:x64-linux`

**Failure logs**

 shader-slang[core]:x64-linux is only supported on '((x86 & windows) | (x64 & (windows | linux | osx)) | (arm64 & (linux | osx))) & !uwp & !static'

[Image: image]


**Additional context**

If you proceed to official [URL] of this port you can clearly see that it supports linux platform. So it is a bug and I hope you can fix it in short time.
Discussion
- `x64-linux` builds static libraries, and this library does not support static linkage. Either use `x64-linux-dynamic` or per-port customization.
