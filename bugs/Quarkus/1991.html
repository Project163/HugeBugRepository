Title

SubjectSubstitution.java uses org.graalvm.home.Version

Description
### Describe the bug

The `kafka-client` extension uses `org.graalvm.home.Version` class which is no longer available in GraalVM for JDK 21 (internal version 23.1). It looks like the substitution is only being applied for a GraalVM version `< 22.1` and the minimum supported version is `22.3`. So it appears that substitution can just get removed?

We see the following native image failure due to `SubjectSubstitution` with `23.1`:

