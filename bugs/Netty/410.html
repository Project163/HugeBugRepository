Title

Netty4: "ChunkedInput.isEndOfInput() failed"

Description
Running `4.0.25.Final`, it seems that `ChunkedWriteHandler` is mishandling its input.  From the log below, you can see that first, it is closing its stream (due to a `ClosedChannelException`). Then, in response to the ChannelInactive event, it logs a warning when it attempts to discard the stream because the stream is already closed.

```
DEBUG 20:20:47.870 [nioEventLoopGroup-3-9] java.lang.Thread.getStackTrace(Unknown Source)
    net.pms.io.WaitBufferedInputStream.close(WaitBufferedInputStream.java:78)
    java.io.PushbackInputStream.close(Unknown Source)
    io.netty.handler.stream.ChunkedStream.close(ChunkedStream.java:93)
    io.netty.handler.stream.ChunkedWriteHandler.closeInput(ChunkedWriteHandler.java:325)
... [Log Snipped] ...
    at io.netty.util.concurrent.DefaultThreadFactory$DefaultRunnableDecorator.run(DefaultThreadFactory.java:137) [ums.jar:5.0.1]
    at java.lang.Thread.run(Unknown Source) [na:1.8.0_31]
```

The relevant [Link: calling code] is essentially:

``` java
ctx.writeAndFlush(new ChunkedStream(largeInputStream, 8*1024))
```
