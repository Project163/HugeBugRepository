Title

NPE when CAS encounters empty frozen collection

Description
When a compare-and-set operation specifying an equality criterion with a non- null  value encounters an empty collection ( null  cell), the server throws a  NullPointerException  and the query fails. 

 This does not happen for non-frozen collections. 

 There's a self-contained test case at  github .
