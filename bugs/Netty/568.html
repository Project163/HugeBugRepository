Title

HttpToHttp2ConnectionHandler ignores HttpConversionUtil.ExtensionHeaderNames.STREAM_DEPENDENCY_ID in write(ctx, msg, promise)

Description
Hello. I’m trying to open a dependent HTTP/2 stream but it seems that HttpToHttp2ConnectionHandler.write(ctx, msg, promise) ignores HttpConversionUtil.ExtensionHeaderNames.STREAM_DEPENDENCY_ID header in outbound message (and so all streams depend on connection). Isn’t it necessary to use the following version of writeHeaders version when the mentioned header is specified?

``` java
    ChannelFuture writeHeaders(ChannelHandlerContext ctx, int streamId, Http2Headers headers,
            int streamDependency, short weight, boolean exclusive, int padding, boolean endStream,
            ChannelPromise promise);
```

Netty version: 4.1.5.Final

Thanks.
