Discussion
- I fixed the symlink problem quite easily with this  commit , then I hit a dead end: the cqlsh tests are all based on the  pty   linux-only  module to interact with the cqlsh terminal, and I didn't find any suitable replacement on WIndows. So, I see 3 bad options here: 
 
	 Do our own interacting with the shell via python ctypes and Win32 API (dangerous territory) 
	 Reimplement the tests using deprecated/unmaintained and possibly broken libraries  winpexpect  or  WExpect  
	 Run interactive pseudo-terminal based cqlsh tests only on linux, and use  cqlsh dtests  for non-interactive tests on both platforms.
