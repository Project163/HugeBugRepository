Title

Inconsistencies while changing between panel layouts

Description
Steps to reproduce the issue:
1. Run ZAP with add-ons "Quick Start" and "Script Console" installed (unpin and close its tabs, if not already);
2. While in "Maximise left (Sites) tab" or "Maximise bottom (History etc) tabs" layout switch to "Full Layout" (Options > Display > "Display:" or using the main tool bar options), note the tabs currently visible;
3. Change back to "Maximise left (Sites) tab" or "Maximise bottom (History etc) tabs", note that tabs that were hidden are now shown (for example, "Quick Start" tab), moreover the plus sign is shown with tabs that are visible and that some of the tabs belong to other panels (for example, "Quick Start", "Break", "Scripts" tabs are available in the footer panel).

ZAP Versions:
Versions >= 2.4.0
