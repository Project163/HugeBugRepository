Title

shamrock:create generate non valid test class

Description
The generated project contains a test class that has:

`@ExtendWith(ShamrockTest.class)`

which leads to compilation failure.

I changed to 

`@ExtendWith(ShamrockTestExtension.class)`

but then the test fails
Discussion
- Yes, `@ExtendWith(ShamrockTest.class)`  should be replaced with `@ShamrockTest`. Moreover, `maven-surefire-plugin` 2.22.0+ is needed to run JUnit5 tests.
