Discussion
- Apparently it's possible for meanRowSize to be 0 when meanColumnCount is not, even though both only consider SSTables, and not the memtables, in a rare race condition. Attaching a simple fix.
- Apparently it's possible for meanRowSize to be 0 when meanColumnCount is not  

 How does that work?
- Hypothetically, it would be so if a compaction ends w/ no sstables outputted (possible w/ hints' gc gs = 0) between getMeanColumns() and getMeanRowSize() calls. Now, I can't say that this is in fact what's happening, but it is theoretically possible, and thus should be guarded against. 

 The metrics code looks legit for both gauges, so I really don't know what else could be behind it. The patch fixes the issue.
