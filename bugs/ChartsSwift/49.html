Title

Line charts: Line sections disappear when zoomed in (has PR).

Description
# Line sections disappear when zoomed in

Regularly, line sections of line-based charts (line, area) will disappear when zoomed in (make sure `scaleXEnabled = true`, `scaleYEnabled = true` and `dragEnabled = true`). 

Possibly related issues: #3253, #3933, #3898?

# Steps to reproduce

1. Launch the iOS Charts demo app
2. Open the `Line Chart` demo
3. Zoom in deep (so that the left y-axis ranges from 20 to 70, zoom level > 3.8)
4. Drag the chart so that a sharp line corner will _just_ go below the x-axis
5. Observe the left line section will disappear

[Image: issue-4099]

(View the [Link: full video] for more context)

# Cause of the issue

The issue is caused by some logic in [Link: LineChartRenderer.swift] that determines whether or not a line should be rendered. It does so by checking if a line lies outside the viewport, however it does not take into account that lines might _intersect_ the viewport while its start and endpoint lie outside of the viewport.

In the above gif, the start point of the line was outside of the viewport while the end point lies within the viewport. Dragging the chart downward makes the end point move outside of the viewport, causing the logic below to skip rendering.

```
swift
if (!viewPortHandler.isInBoundsRight(_lineSegments[0].x))
{
    break
}
... [Log Snipped] ...
    continue
}
```

# Fix

In Pull Request #4100 I have improved the logic to determine whether or not a line's start- or endpoint lie within the viewport, _or_ if the line intersects the viewport.

# Environment

- Charts version 3.3.0 (it is also present in 3.2.2)
- Xcode 10.3
- Swift 5
- macOS Mojave 10.14.16
