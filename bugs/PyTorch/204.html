Title

Floating point exception (core dumped) for nonzero_static operator

Description
### 🐛 Describe the bug
Executing the following script led to a core dump. This is a dangerous behavior. 
Note that using the default device for the `empty_tensor` will run well.

```python
import torch

empty_tensor = torch.tensor([], device='cuda:0')
result = torch.ops.aten.nonzero_static(empty_tensor, size=1)
```
