Title

Docker healthcheck fails when run in host network

Description
When syncthing is run in host network configuration as per guidance [Link: here], the container health check fails, however everything seems to work fine.

#### Configuration:
`STGUIADDRESS=` set as environment variable.
Container is behind a reverse proxy which overwrites host header to `localhost`.

Verified by running `nc -z localhost 8384 || exit 1` inside container. Same works fine when run on host.
Discussion
- I'm not 100% sure we have that healthcheck there. I think we should remove it.
- I had the same issue, minus the reverse proxy. For the record, I was able to fix it by setting `STGUIADDRESS=localhost:8384` and changing the healthcheck to `nc -z   8384 || exit 1`. No other combination of localhost/  works for some reason.
