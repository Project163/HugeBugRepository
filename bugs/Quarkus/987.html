Title

Quarkus Guides showing health extension need updating

Description
**Describe the bug**
Some of the Quarkus Guides showing the use of the health extension show the following for adding the health extension:

```bash
./mvnw quarkus:add-extension -Dextensions="health"
```

but when doing that (at least with `1.11.3.Final`, not sure how far back it goes) I get

```bash
[INFO] --- quarkus-maven-plugin:1.11.3.Final:add-extension (default-cli) @ hello-world ---
❌ Multiple extensions matching 'health'
     * io.quarkus:quarkus-smallrye-health
     * org.apache.camel.quarkus:camel-quarkus-microprofile-health
     Be more specific e.g using the exact name or the full GAV.
```

It seems in order for it to work you have to do

```bash
./mvnw quarkus:add-extension -Dextensions="smallrye-health"
```
