- This is usually a sign of a non-deterministic autoloading mechanism.

The easiest way this can happen is if you have class A and class B in the same file and the autoloader only knows about class A. If you first load class A, class B also gets loaded. But if you first ask about class B, it's not found.

Do a little test:

```php
require_once __DIR__ . '/vendor/autoload.php';

var_dump(class_exists(\Atk4\Core\HookTrait::class));
```

And run it with PHP runtime. If it prints false, there's your reason why it doesn't work. If it prints true, please create a small reproducing repository that shows this problem so I can look into it.
