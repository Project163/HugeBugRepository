Title

JDBC v2: getPrimaryKeys always returns constant COLUMN_NAME, KEY_SEQ, PK_NAME

Description
Jdbc v2 driver has hardcoded values for meta attibutes :  
COLUMN_NAME = _KEY  
KEY_SEQ = 1 
PK_NAME = _KEY 

 But this values should be different for different tables. 

 how to reproduce:  
1) connect to the cluser using jdbcv2 driver 
2) CREATE TABLE TAB (ID LONG, SEC_ID LONG, VAL LONG, PRIMARY KEY(ID, SEC_ID)) 
3) check result of connection.getMetadata().getPrimaryKeys()
Discussion
- Suggested fix that copies logic from thin driver: JdbcRequestHandler#getPrimaryKeys  

 This approach doesn't work well. GridQueryTypeDescriptor contains uninitialized properties on driver side. 

 So general rule here, not to use  org.apache.ignite.internal.processors.query.GridQueryProcessor#types
