Title

RocksDB not being pulled in as a transitive dependency

Description
In  pull/10203  we stopped pulling in non-api dependencies and listed the rocksdb dependency as an implementation. However users may need to pull in RocksDB classes (such as Options, and various other sub-options such as TableFormatConfig). We should change this dependency to an api so that it gets pulled in as a transitive dependency and users aren't required to pull it in themselves and maintain compatibility
