Title

Decoupled endpoints are not compatible with @UseAsyncMethod annotation

Description
In case of use decoupled endpoints in combination with @UseAsyncMethod annotation, code in AbstractJAXWSMethodInvoker tries to suspend transport continuation. 
It causes "java.lang.IllegalStateException: IDLE,initial" exception and doesn't make sense, because partial response is already sent to the client and new processing thread is started. Full response will be sent in separate transport connection.
