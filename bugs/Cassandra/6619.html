Title

Non-java types are leaking from snapshots

Description
[URL] brought a major uplift of the snapshot code. A new exception type was introduced for signaling issues related to snapshots ( SnapshotException ). This type however is leaking through JMX. Cassandra only exposes java types through the RMI interface. I encountered the issue in Sidecar when trying to create an already existing snapshot. Here’s the stack trace:
