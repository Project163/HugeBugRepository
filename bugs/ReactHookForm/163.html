```
js
const Form = ({ entityFromProp }) => {
  const { reset } = useForm();

And after couple of `reset` calls I noticed significant performance issue (browser window hangs for some time). I think the root of the problem is [Link: `MutationObserver` usage]. Seems like `form.reset` call creates new observers but does not disconnect old ones.

I think it makes sense to create only one `MutationObserver` instance at all or at least per `useForm` hook to reduce unnecessary browser work even if the leak itself will be fixed.
