Title

Can't handle unknown error in MailTransport.

Description
If an email sending is failed, then method MailTransport::_mail() try to catch error and throw some exception. But if result of `$error = error_get_last()` is empty, then code:

``` php
$msg = 'Could not send email: ' . isset($error['message']) ? $error['message'] : 'unknown';
```

is invalid, because **``` 'Could not send email: ' . isset($error['message'])** ?``` is the statement and always is true, then $error['message'] is passed to $msg variable, and exception with empty message is thrown.
I think the correct statement should be:

``` php
$msg = 'Could not send email: ' . (isset($error['message']) ? $error['message'] : 'unknown');
```
