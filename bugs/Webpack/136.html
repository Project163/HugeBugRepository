Title

ModuleConcatenation Bailout errors snowball on dev-server

Description
**Do you want to request a *feature* or report a *bug*?**

This is a bug.

 
 

**What is the current behavior?**

On repeated incremental builds, the bundle size gets larger and larger per build:

```
app.js   7.16 MB
login.js   1.48 MB

---

... [Log Snipped] ...
  app.js   7.65 MB
login.js   1.57 MB
```

After downloading one of these bloated bundles, I see:

```
js
/* 853 */
/*!*******************************************************************!*\
  !*** ./ui/views/widgets/dialogs/DialogContainer.jsx + 14 modules ***!
  \*******************************************************************/
... [Log Snipped] ...
"use strict";
eval("...
```

Expected behavior:

Webpack should not keep concatenating these error comments to the bundle.

After 100+ reloads, we see Node blow up "CALL_AND_RETRY_LAST", aka ENOMEM, and webpack-dev-server needs to be restarted.
Discussion
