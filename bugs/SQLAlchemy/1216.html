Title

RecursionError: maximum recursion depth exceeded when loading WithinGroup via sqlalchemy.ext.serializer.loads

Description
Create a query with a `.within_group` clause and try to dump/load it:
```
import sqlalchemy as sa
from sqlalchemy.ext.serializer import dumps as sa_dumps, loads as sa_loads

query = sa.select([sa.func.percentile_cont(sa.literal(1)).within_group()])
dumped_query = sa_dumps(query)
loaded_query = sa_loads(dumped_query)
```

This raises the following error:
```
RecursionError                            Traceback (most recent call last)
  in  
      4 query = sa.select([sa.func.percentile_cont(sa.literal(1)).within_group()])
      5 dumped_query = sa_dumps(query)
----> 6 loaded_query = sa_loads(dumped_query)
... [Log Snipped] ...

RecursionError: maximum recursion depth exceeded
```
Discussion
- these issues are usually handled by adding a `__reduce__()` method to the constructs in question, such as here perhaps the `WithinGroup` object.     serialization of queries is not well supported in SQLAlchemy and it's preferable if people dont try to use this.
