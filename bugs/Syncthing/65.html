Title

All files deleted on first sync if repo root is symlink

Description
When first syncing ~/Documents to a new machine (local directory full of stuff, remote directory empty), I get a bunch of disturbing notifications on the local web interface:

```
0:50:07: remove /home/tim/Documents/projects/web/hosted/xsession/timwise.co.uk.git/.git/objects/0f: directory not empty
0:50:07: remove /home/tim/Documents/projects/openmoko/mokopod.git/.git/objects/8a: directory not empty
0:50:07: remove /home/tim/Documents/Phone/fr/sync/card/.e/e/fileman: directory not empty
```

etc.

It seems to correlate with restarts triggered manually while adding more nodes and folders.

It worries me that it's going to delete things it shouldn't from the local ~/Documents. (Though I have backups, it can be hard to spot what's gone awol till later so I'd rather it didn't get it wrong).

Any ideas?
