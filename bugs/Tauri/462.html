Title

[bug] tauri-build build script always rebuild, again

Description
### Describe the bug

A while ago, I reported [URL] that `cargo build` always rebuilds even nothing changes, which is caused by an unconditional `cargo:rerun-if-changed`. After it been fixed, everything worked fine for a while, until the recent beta versions, where the issue happens again. I have no easy suspicion as to where it comes from this time, but since the biggest change in beta is the capability system, it could be a lead.

### Reproduction

1. Create an example app with `pnpm create tauri-app --beta`
2. `cd ./src-tauri`
3. `cargo build`
4. After it successfully builds, `cargo build` again

### Expected behavior

The final executable should not be rebuilt. Instead, I always see a `Building [=======================> ] 360/361: tauri-app(bin)` line.
