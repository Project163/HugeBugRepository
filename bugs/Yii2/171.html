Title

Unknown Method createAbsoluteUrl in Yii\Rest\CreateAction

Description
Getting the following exception after an object is created via POST using Yii\Rest:

```
{ type: "yii\base\UnknownMethodException"
name: "Unknown Method"
message: "Calling unknown method: api\controllers\UserController::createAbsoluteUrl()"
code: 0 }
```

Seems to be coming from line 75 of Yii\Rest\CreateAction

```
$response->getHeaders()->set('Location', $this->controller->createAbsoluteUrl([$this->viewAction, 'id' => $id]));
```

Commenting out the line removes the problem.  Why is this here in the first place?  Why does a successful POST redirect while a successful PUT/PATCH does not?
Discussion
- It's there because after you create a new record the good `API` must return the URL of this record in `Location`. In case with `PUT/PATCH` you already know this URL, and it's not needed.

The code need to be changed to:

``` php
$response->getHeaders()->set('Location', Url::toRoute([$this->viewAction, 'id' => $id], true));
```

or 

``` php
$response->getHeaders()->set('Location', Yii::$app->getUrlManager()->createAbsoluteUrl([$this->viewAction, 'id' => $id]));
```
