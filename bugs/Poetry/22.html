## Issue

When poetry creates a virtual environment, it does not use symlinks on Unix platforms. Symlinks are the default on Unix platforms when creating a virtual environment with `python -m venv` as seen [Link: here]. Using symlinks instead of making a copy of the interpreter has several benefits:

1. Less disk usage (I see 28MB used for python and python3 for a virtual environment for Python 3.7.1)
2. Allows usage of `$ORIGIN` in RPATH/RUNPATH in the `python` executable which is useful for relocatable Python builds
3. Easier automatic loading of `python-gdb.py` for gdb debugging helpers
