Title

Description
**Describe the bug**
(Describe the problem clearly and concisely.)
A mutable jar on OpenShift can't be running with the following error:

Error: Unable to access jarfile /deployments/target/quarkus-run.jar

**Expected behavior**
(Describe the expected behavior clearly and concisely.)
The Quarkus pod(mutable jar) runs well without

**Actual behavior**
(Describe the actual behavior clearly and concisely.)
Pod is CrashLoopBackOff with an Error: Unable to access jarfile /deployments/target/quarkus-run.jar
