Title

Description
We tried to upgrade from 3.5 to 3.11.1 but now IMAP logins fail. In IMAPReply.java a regular expression is changed and now looks like this: 

   
      private static final String TAGGED_RESPONSE = "^ w{1,80} ( S{1,80}).{0,80}";
