Title

shell module doesn't support conditional format strings

Description
#### Current Behavior

The shell module doesn't seem to support conditional format strings, e.g.:

```toml
[shell]
fish_indicator = ""
bash_indicator = "🐚"
format = "($indicator )"
disabled = false
```

Nothing displays for bash or fish. Removing the `format = ...` line displays: ` ❯` for fish (note the space) and `🐚  ❯` for bash.

#### Expected Behavior

`🐚  ` shows up for bash and nothing shows up for fish.
