Title

Description
### What happened?

I'm not sure if I missed something, or if there's an actual issue as of `2.4.0`. The error I'm seeing is `error=failed to build for windows_arm64_v8.0: fork/exec C:\Program Files\Go\bin\go.exe: The parameter is incorrect.:` It is reproducible using this [Link: georeleaser] file and project.

