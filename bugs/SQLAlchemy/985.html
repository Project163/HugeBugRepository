in this case, the execution option only needs to take effect when the SQL statement is executed, which is what we intercept within the before_cursor_execute event.   it won't be copied out to the outermost Query as you've observed.

so how we test these things is by collecting what we see inside of before_cursor_execute and asserting that.  I usually use the mock library to gather data like this, although a plain Python list/dict can work too, likely better in this case:

```
from sqlalchemy import column
from sqlalchemy import create_engine
from sqlalchemy import event
from sqlalchemy.orm import Query
```
