Title

Mixing environment groups and platforms causes a crash

Description
Somewhere in the combination of platforms and auto_cpu_environment_group, a SupportedEnvironmentsProvider is not being added, leading to a crash on bazel build.

BUILD:
```
environment_group(
  name = "cpus",
  defaults = [":k8"],
  environments = [":k8"])

environment(name = "k8")
```

Command:
```
$ bazel build --experimental_auto_cpu_environment_group=//:cpus @bazel_tools//platforms:osx
```

Crash:
```
com.google.common.base.VerifyException: expected a non-null reference
	at com.google.common.base.Verify.verify(Verify.java:122)
	at com.google.common.base.Verify.verifyNotNull(Verify.java:157)
	at com.google.common.base.Verify.verifyNotNull(Verify.java:135)
	at com.google.devtools.build.lib.analysis.constraints.TopLevelConstraintSemantics.checkTargetEnvironmentRestrictions(TopLevelConstraintSemantics.java:131)
```
