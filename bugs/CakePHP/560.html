Title

3.0 & (Probably 2.x) Bug while creating deep path structures with Folder()->create

Description
Hello,
I don't know if it's a bug or not, but it's a little weird if it's not a bug.

```
php
// All those directories already exists
$root = 'D:' . DS . 'Dropbox' . DS . 'Sites' . DS . 'Xeta' . DS . 'tests' . DS . 'test_app' . DS . 'webroot' . DS;

$folder = new Folder($root);
... [Log Snipped] ...
*/
$folder->create('upload\avatar\1');
```

So i expected that the function `create` will create this structure : `D:\Dropbox\Sites\Xeta\tests\test_app\webroot\upload\avatar\1`
But no, it doesn't work. The only way to get it work it's :

``` php
$root = 'D:' . DS . 'Dropbox' . DS . 'Sites' . DS . 'Xeta' . DS . 'tests' . DS . 'test_app' . DS . 'webroot' . DS;
$folder = new Folder($root);
$folder->create($root . 'upload\avatar\1');
```

With this code it's work, but why i should specify the `$root` patch in the `create function`, the instance is already setup with the `$root` path ?
Discussion
- Doesn't look like create() has ever taken the current path into account when creating new directories. One possible option would be to include the current folder object's path when the provided path is not absolute.
- Fixed in #5001
