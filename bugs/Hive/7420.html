Title

Support decimal64 operations for column operands with different scales

Description
Right now, if the operands on the decimal64 operations are columns with different scales, then we do not use the decimal64 vectorized version and fall back to HiveDecimal vectorized version of the operator. In this Jira, we will check if we can use decimal64 vectorized version, even if the scales are different.
