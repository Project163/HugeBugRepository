Title

SoftRefFilesCache logs password when FS is closed

Description
We use DEBUG logging enabled for VFS to diagnose integration problems with external connections. 
Unfortunately it leads to logging of clear text password in logs if use basic auth with SFTP/HTTP4S connectors 
  
 D 240526 060013.993 [ScheduledIpfSynchronizer_Worker-1] SoftRefFilesCache - Close FileSystem: http4s://mylogin:mypassword@my.company.com:8443/
Discussion
- Well, it does log the URL, not the password. You should maybe provide the creds separately. Using auth info is deprecated in recent RFCs.

 Agreed, however I propose that this debug log is changed to getRootName().getFriendlyURL() instead. Same for the throw in SftpFileSystem getChannel.
