Title

Local config messes with global config

Description
It seems local message control configuration overrides global configuration before it is even set.
### Steps to reproduce
test.py:
```python
import invalid1
# pylint: disable=import-error
import invalid2
```
pylintrc:
```
[MESSAGE CONTROL]                                                                   
disable=I,missing-docstring,unused-import,import-error                              
[REPORTS]                                                                        
reports=no
```
Also happens when 'import-error' is disabled from the command line instead of pylintrc.
### Current behavior
```
************* Module test
E:  1, 0: Unable to import 'invalid1' (import-error)
```
### Expected behavior
Nothing since import errors are disabled globally.

pylint 1.6.4,
