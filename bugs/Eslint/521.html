Title

False positive on switch 'no duplicate case'

Description
In EcmaScript after the `case` token there can be any valid expression,
in particular this switch was raising a false `no duplicate case` positive:

```
switch(['a','b'].toString()){
  case (['a','b']).toString():
    console.log('right');
    break
  case (['a']).toString():
    console.log('not right');
    break
}    
```

in this case is because the [Link: getHash function] does not handle ArrayExpression nodes;
the [Link: if else cascade] exit without matching, so the function returns `undefined`.
This happens for every node types that isn't checked.
