Title

Bad bounding box calculation in BufferGeometry.js if there is only a single point

Description
The boundingBox is initialized to +inf, -inf (both in the old version and in the new version that utilizes Box3.)  Then the boundingBox of the points is calculated using a conditional that either updates the min or the max value.  But if there is only a single point, only one of the min or max values will be updated.  This conditional updating can only be done after min and max have been initialized to a valid single point within the box.

Thus the solution is to initialize min and max to the position of the first point so we can use the fast expansion of the bounding box for the rest of the points.
