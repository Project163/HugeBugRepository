Title

Workarounds for missing InternalPreserveStackTrace in mono

Description
When handling async methods exceptions NUnit tries to preserve the stacktrace by invoking a private method of the exception itself to preserve the stacktrace when re-throwing it. This method does not exist in mono and in .NET 4.5 an alternative, public workaround was introduced. NUnit should use the best approach to preserve exception stacktraces depending on the version of the framework it's running on.
