Title

Update API allows conflicting mappings

Description
The update API allows conflicting field mappings to be introduced which can then bring a cluster down as it keeps trying and failing to sync the mappings.  Recreation:

```
PUT t
{
  "mappings": {
    "one": {
      "properties": {
... [Log Snipped] ...

GET t/_mapping
```

returns:

```
{
  "t": {
    "mappings": {
      "one": {
        "properties": {
... [Log Snipped] ...
  }
}
```

From: [URL]
Discussion
