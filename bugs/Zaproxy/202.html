Title

Do not uninstall files that are declared by other add-ons

Description
Steps to reproduce the issue:
1. Run ZAP with Zest and Fuzzer add-ons installed;
2. Uninstall Fuzzer add-on;
3. Create a new (default) Stand Alone Zest script;
4. Try to add a "Loop File" statement and note that nothing happens. In the log there's an exception:
```
99775 [AWT-EventQueue-0] ERROR org.zaproxy.zap.ZAP$UncaughtExceptionLogger  - Exception in thread "AWT-EventQueue-0"
java.lang.RuntimeException: 

	Broken JBroFuzz Installation:

... [Log Snipped] ...
	at org.zaproxy.zap.extension.zest.menu.ZestAddLoopPopupMenu$1.actionPerformed(ZestAddLoopPopupMenu.java:116)
	at javax.swing.AbstractButton.fireActionPerformed(AbstractButton.java:2022)
```
Caused by the missing file "fuzzers.jbrf" that was removed when the Fuzzer add-on was uninstalled (both add-ons use that file).
