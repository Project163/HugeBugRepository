Title

i18n - some trouble

Description
Hi.
1) By default we have:

```
    public $language = 'en';
    public $sourceLanguage = 'en';
```

When I run the next example from docs:

``` php
var_dump(Yii::t('app', 'Balance: {0, number, currency}', 42));
```

I get the wrong result:

```
'Balance: ¤42.00'
```

Then after I make the next change:

``` php
'sourceLanguage' => 'en-US',
```

it works okey:

```
'Balance: $42.00'
```

2) Then the next example:

``` php
'language' => 'ru'  // it does not work okey
'language' => 'ru-RU', // it works okey
```

Should I always use a full name of the language?
Discussion
- Issue confirmed. Application config:

```
php
return [
    ...
    'language' => 'en',
    'components' => [
... [Log Snipped] ...
    ...
];
```

This NOT working:

``` php
echo Yii::$app->formatter->asCurrency($model->price) //show NOTHING
```

This works:

``` php
echo Yii::$app->formatter->asCurrency($model->price, 'USD') //show $10.00
```

Changed config to:

``` php
return [
    ...
    'language' => 'en-US',
    ...
];
```

and all works.

Seems we need change `Application::language` and `Application::sourceLanguage` defaults for `en-US` and deny use short syntax for locales.
