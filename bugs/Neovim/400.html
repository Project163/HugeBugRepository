Title

Different values assigned to '] and '> marks when performing the same operations on multibyte text

Description
### Neovim version (nvim -v)

NVIM v0.6.0-dev+498-gd0f10a7ad

### Vim (not Nvim) behaves the same?

yes

### Operating system/version

macOS 11.6

### Terminal name/version

iTerm2 

### $TERM environment variable

xterm-256colors

### Installation

homebrew

### How to reproduce the issue

`nvim --clean --cmd "set termguicolors" --cmd "1 s/^/тест/" --cmd ":norm diwp" --cmd ":norm viwdp" --cmd ":marks"`

### Expected behavior

Marks `']` and `'>` should point to the same position.

### Actual behavior

Mark `']` points to byte 7, mark `'>` points to byte 6:
