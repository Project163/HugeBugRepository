Title

useUTC incorrect default

Description
## Issue Description

The option `useUTC` for `mssql` specifies an incorrect default value.

### Expected Behavior

All documentation on `useUTC` indicates the default value should be `true` if not provided.

For example: [URL]

This also aligns with the documentation in many related projects including `tedious`, `mssql`, and `@nest/typeorm`. Everything specifies the default should be `true`. 


### Actual Behavior

If not provided, `useUTC` defaults to `false` at the following line.

[URL]


### Steps to Reproduce

 

The following example demonstrates this issue.

```sql
CREATE TABLE timestamptest (
[dateTime2SysUtcDateTime] [datetime2] (3) NULL CONSTRAINT [DF__timestamp__dateT__6754599E] DEFAULT (sysutcdatetime())
)

insert into timestamptest
values(default)
```

Without passing anything for `useUTC`



```sql
-- local time is 3:14 PM
-- database = 2020-11-09 20:14:48.378
-- javascript = 2020-11-10T01:14:48.378Z
```

Passing `useUTC = false`

```sql
-- local time is 3:14 PM
-- database = 2020-11-09 20:14:48.378
-- javascript = 2020-11-10T01:14:48.378Z
```


Passing `useUTC = true`

```sql
-- local time is 3:14 PM
-- database = 2020-11-09 20:14:48.378
-- javascript = 2020-11-09 20:14:48.378
```
