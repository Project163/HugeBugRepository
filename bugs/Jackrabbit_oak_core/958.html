Title

Wrong time unit for async index lease time

Description
The JavaDoc for  AsyncIndexUpdate.ASYNC_TIMEOUT  says the time unit for the timeout is minutes. Within the code the timeout value is rather interpreted as milliseconds, which looks wrong. E.g. the new lease value is calculated as  lease = now + 2 * ASYNC_TIMEOUT . 
It is probably best to change the constant to reflect the timeout in milliseconds. 

 It looks like this issue was introduced with changes for   OAK-1877   and affects the 1.0.1 and 1.0.2 releases.
