Title

`MultiSnapshot` should release each `TranslogSnapshot` when no longer needed

Description
Seen in a heap dump from a node that went OOME: we ran out of memory replaying a translog of 83 generations, each of which ended with an enormous document (all over 100MiB, some over 1GiB, see [URL] It seems that we do not re-use the `TranslogSnapshot#reuse` buffer across generations, but nor do we release it, we just keep the last operation of each generation in memory until the whole translog replay is done.
