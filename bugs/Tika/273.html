Title

Description

[ERROR]   class file for com.sun.image.codec.jpeg.JPEGDecodeParam not found
 
  

 It's possible upgrading to the latest metadata-extractor might fix this... (we use 2.4.0-beta-1 but there's now a 2.5.0-RC2:  [URL]
