Title

`react-dom` version conflict with RN 0.45.1

Description
The CLI's [Link: hardcoded version] of `react-dom` is incompatible with the version of React installed by RN 0.45.1.

Reproduction

```
# install latest RN
npm install -g react-native-cli

# create RN app
react-native init MyApp
... [Log Snipped] ...
# try running storybook
npm run storybook
```

You will get an error due to incompability between `react-dom@15.5.4` and `react@16.0.0-alpha.12`:

```
ERROR in ./~/react-dom/lib/ReactMount.js
Module not found: Error: Can't resolve 'react/lib/React' in '/private/tmp/TesterMeTester/node_modules/react-dom/lib'
 @ ./~/react-dom/lib/ReactMount.js 17:12-38
 @ ./~/react-dom/lib/ReactDOM.js
 @ ./~/react-dom/index.js
... [Log Snipped] ...

...etc..
```

Update the reference of `react-dom` in `package.json` and it should run again (modulo [URL]
