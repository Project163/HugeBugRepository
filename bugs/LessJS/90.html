Title

Is there a way to define mixins which take 2-N arguments?

Description
Hi guys,

As [Link: lesscss.org] says, `...` can be used to match a variable number of arguments.

``` less
.mixin (...) {        // matches 0-N arguments
.mixin () {           // matches exactly 0 arguments
.mixin (@a: 1) {      // matches 0-1 arguments
.mixin (@a: 1; ...) { // matches 0-N arguments
.mixin (@a; ...) {    // matches 1-N arguments
```

So is there a way to specify that a mixin will only take two (three, four, ...) or more arguments?

```
less
.mixin(@a) {
}

.mixin(@a, @b, @rest...) {
... [Log Snipped] ...
  .mixin(1);
}
```

A syntax error occured when compiling the code above:

```
Syntax error: wrong number of arguments for .mixin (1 for 3)
div {  .mixin(1);}
```

I think it is strange that the mixin 'signature' is matched when the number of arguments is wrong.
Discussion
- thats a bug.

If you delete the `@rest...` it works fine (goes to 1 method for 1 arg,the other for 2 args) but that logic doesn't seem to work well then using `...`
