Title

Disabling BWC tests does not disable BWC build

Description
This PR build failed: [URL]

This build is on the `zen2` branch, on which BWC tests are currently disabled:

```
========================= WARNING =========================
         Backwards compatibility tests are disabled!
See [URL]
===========================================================
```

Nonetheless the build failed when trying to build the `next-bugfix-snapshot` version, which I think shouldn't be necessary if the BWC tests are disabled.

```
FAILURE: Build failed with an exception.

:distribution:bwc:next-bugfix-snapshot:buildBwcVersion (Thread[Task worker for ':' Thread 10,5,main]) completed. Took 2 mins 7.955 secs.

... [Log Snipped] ...
Execution failed for task ':distribution:bwc:next-bugfix-snapshot:buildBwcVersion'.
```
Discussion
- Pinging @elastic/es-core-infra
- I think this is because of how we wire these as dependencies and then we trigger dependency resolution sooner than we should. 
We had a similar problem that these were build on `assemble` as well that we worked around specifically. Looks like we need a more elaborate fix.
