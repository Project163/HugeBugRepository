Discussion
- I would like to work on the issue.
The segfault is arising from backward_analytic_function_of_a_matrix function, as it is working with scalar as input eventually causing segfault in 
`
self_transposed_sizes[self.dim() - 2] <<= 1;
self_transposed_sizes[self.dim() - 1] <<= 1;
`

Minimum reproducible code:
```
import torch

A = torch.tensor(0.23565612)
B = torch.rand((1,2))

torch.ops.aten.matrix_exp_backward(A, grad=B)
```
