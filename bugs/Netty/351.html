Title

Authority sections of DNS responses decoded incorrectly causing NPE

Description
The DNS client codec does not handle authority sections gracefully - it tries to decode the section as a name (I think - `readName()` is not an easy read), which causes `DnsResponseDecoder.readName()` to return null (it bails out at the second null-check), which is then passed to the constructor of a DnsResource where it generates a `NullPointerException`.  

[Link: Here is an example project] that demonstrates the problem.
