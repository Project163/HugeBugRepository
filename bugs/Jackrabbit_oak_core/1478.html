Title

Use clock when waiting in ClusterNodeInfo

Description
ClusterNodeInfo currently uses a Thread.sleep() when it waits for a lease to end in waitForLeaseExpiry(). The method should rather use clock.waitUntil() to make use of a potential virtual clock in use by a test. This allows to reduce the time it takes to run lease related tests.
