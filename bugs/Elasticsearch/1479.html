Title

Percolator is ignoring position_offset_gap

Description
I'm testing span queries on percolator and encountered a problem. It seems that percolator is ignoring position_offset_gap. Below there is an example.

```
$ curl "localhost:9200/test1/_mapping/type?pretty" -XPUT -d '{"type" : {"properties" : {"field1" : {"type" : "string", "position_offset_gap" : 100}}}}'
$ curl "localhost:9200/test1/.percolator" -d '{"type" : "type", "query" : {"span_near" : {"slop" : 90, "clauses" : [{"span_term" : {"field1" : "foo"}}, {"span_term" : {"field1":"bar"}}]}}}'
{"_index":"test1","_type":".percolator","_id":"sK3bC-XYQ9SQ4qC3SpyXfg","_version":1,"created":true}
$ curl "localhost:9200/test1/type/_percolate?pretty" -XGET -d '{"doc" : {"field1" : ["foo", "bar"]}}'{
  "took" : 3,

}
```
