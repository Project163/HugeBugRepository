Title

optionengine fails for reflection due to missing "engine" attribute

Description
Engine seems to assign "self.engine = self" which is an unpleasant circular reference in any case, that should likely be a descriptor.  it should also be part of `Connectable`.

```
from sqlalchemy import create_engine, MetaData

e = create_engine("sqlite://")
e = e.execution_options(isolation_level="SERIALIZABLE")

m = MetaData()
m.reflect(e)
```
