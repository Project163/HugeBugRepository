Title

Supported core extensions not available when using experimental DB option

Description
Issue reported in OWASP ZAP User Group: [URL]

Some of the core extensions that support the experimental DB option are not available, e.g.:
 - ExtensionAntiCSRF;
 - ExtensionAuthentication;
 - ExtensionAuthorization;
 - ExtensionCallback;
 - ExtensionHttpSessions;
 - ExtensionParams;
 - ExtensionProxies;
 - ExtensionSessionManagement.

ZAP
Version 2.7.0 (and older versions).
