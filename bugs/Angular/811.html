- There is also a problem in **IE** that `ng-component`s aren't removed when routing animation is done. Thus, all `ng-componet`s stay in the DOM even if we left the route.
Not sure if a separate ticket should be created for that.
- We had a similar problem as in the first post, solved it by adding this to our polyfills: 

```
if (!Element.prototype.matches) {
  Element.prototype.matches = Element.prototype.msMatchesSelector;
}
```
