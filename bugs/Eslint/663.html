Title

eqeqeq autofix should replace operator to avoid clashes with space-infix-ops

Description
Instead of adding one character immediately after the `==` operator, we should replace the whole operator with `===`. It makes more sense semantically and it also ensures that other rules that want to insert immediately after `==` (e.g., space-infix-ops) can do so without interference and without the fixes being applied in the wrong order.

This should help unblock the reversion of (or at least modification of) #4329.

See #4373 for more info.
