Title

[DocDB] deflake java tests that create a pg connection

Description
Jira Link: [Link: DB-19261]
### Description

The ysql lease (enabled in [Link:  ]) introduced a race into tests that create a pg connection immediately after starting or restarting a yb cluster. These races were fixed for many / most of the C++ tests, however many java tests were not flaky.

Unfortunately the recent commit [Link:  ] changed the dynamics of this race, and made it more likely for pg connections to fail after YB startup/restart.

For example, `org.yb.pgsql.TestYbRoleProfile.testTrustLogin[1]`.
