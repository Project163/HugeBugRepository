Title

In zookeeper-jute project generated source should not be in target\classes folder

Description
Currently in zookeeper-jute project jute generated source  code are put in target\classes folder. In eclipse when project is refreshed/cleaned this folder content will get deleted which results in compilation error in other projects
Discussion
- source code generated from zookeeper.jute should go in target/generated-sources folder instead of target/classes
