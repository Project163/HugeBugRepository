Title

Parse error when # type: ignore is followed by another comment on the next line

Description
Found this code:

```
def foobar(cls):
    class C(cls):  # type: ignore
        # another comment
        pass
```

This causes a parse error on the `# type: ignore` comment:

```
/Users/guido/mypy_tests/mypy_class.py:2: error: Parse error before "ignore"
```

Removing `# another comment` makes the problem disappear.
Discussion
- Simpler repro:

```
if x:  # type: ignore
    # blah blah
    b = 12
```

It seems to be limited to cases where the line with the `# type: ignore` line is on something that starts an indented block (such as `if` or `class`) and the following line is a comment too. The indentation of the comment doesn't matter.
- Perhaps related: About half the time when I add `# type: ignore # Explanation` to a line I get a parse error. But other times it works!
- The PR also fixes the "perhaps related" issue I mentioned in my last comment. All the cases where that happened to me were when the `# type: ignore` was at an indent.
