Title

gRPC package not working with CMake

Description
When I include 
find_package(grpc REQUIRED)
in my CMakeLists.txt I get the following errors.

```
Working directory: C:\\Users\\%username%\\AppData\\Local\\CMakeBuild\\32d53fdf-441b-e833-b990-3d8279f01fe8\\build\\x64-Debug
CMake Error at C:/Users/%username%/Documents/vcpkg/installed/x64-windows/share/grpc/gRPCTargets.cmake:138 (message):
  The imported target "gRPC::grpc_csharp_ext" references the file

     "C:/Users/%username%/Documents/vcpkg/installed/x64-windows/debug/bin/grpc_csharp_ext.dll"
... [Log Snipped] ...
  C:/Users/%username%/Documents/vcpkg/installed/x64-windows/share/grpc/gRPCConfig.cmake:13 (include)
  CMakeLists.txt:7 (find_package)
```

The  gRPCTargets.cmake file is checking for the .dll file. However, since gRPC builds as static, the bin directory gets removed after build. It appears that either the gRPCTargets is incorrectly checking for .dll files or the gRPC ports file needs to be updated to support dynamic build.
Discussion
- Thanks for reporting this!

I've patched grpc to prevent the installation of the csharp extension, which should fix this issue.
