Title

BinaryGuesser should treat *.woff2 as binary

Description
WOFF2 files are fonts and should not be checked for licenses. 

 We recently hit this in the Apache Sling builds, where the failure output (trimmed) is: 

  
   B     /home/jenkins/jenkins-slave/workspace/sling-samples-1.7/trunk/slingshot/src/main/resources/SLING-INF/content/slingshot/resources/fonts/glyphicons-halflings-regular.ttf
  B     /home/jenkins/jenkins-slave/workspace/sling-samples-1.7/trunk/slingshot/src/main/resources/SLING-INF/content/slingshot/resources/fonts/glyphicons-halflings-regular.woff
  B     /home/jenkins/jenkins-slave/workspace/sling-samples-1.7/trunk/slingshot/src/main/resources/SLING-INF/content/slingshot/resources/fonts/glyphicons-halflings-regular.eot
 !????? /home/jenkins/jenkins-slave/workspace/sling-samples-1.7/trunk/slingshot/src/main/resources/SLING-INF/content/slingshot/resources/fonts/glyphicons-halflings-regular.woff2 
  

 I guess  woff2  should be added to the list of known binary formats as well.
