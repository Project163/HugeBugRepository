Title

[YSQL] Unexpected postgres crash when running aggregation with join

Description
Jira Link: [Link: DB-8973]
### Description

Initialized a cluster with:
```
bin/yb-ctl create --rf 1 --tserver_flags="yb_enable_read_committed_isolation=true,enable_wait_queues=true"  --listen_ip=" "
```
(MacOS Ventura 13.6.1,  )

Ran the following script to completion: [URL]

Issued the following commands:
```
yugabyte=# create view audit_sums as select user_id, sum(delta) from audit_table group by user_id;
CREATE VIEW
yugabyte=# select * from audit_sums a join users u on a.user_id=u.user_id;
server closed the connection unexpectedly
	This probably means the server terminated abnormally
	before or while processing the request.
The connection to the server was lost. Attempting reset: Succeeded.
```

Saw the following in postgres logs:
```
TRAP: FailedAssertion("!(key->sk_subtype == ((arrayval)->elemtype))", File: "../../../../../../../src/postgres/src/backend/access/yb_access/yb_scan.c", Line: 1365)
2023-11-21 12:15:56.154 EST [89644] WARNING:  server process (PID 91343) was terminated by signal 6: Abort trap
2023-11-21 12:15:56.154 EST [89644] DETAIL:  Failed process was running: select * from audit_sums a join users u on a.user_id=u.user_id;
```

Note I also encountered this crash when running the following:
```
select a.user_id, sum(a.delta), sum(u.bal) from audit_table a join users u on a.user_id = u.user_id group by a.user
_id;
```
