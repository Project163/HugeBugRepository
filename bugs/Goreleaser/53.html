Title

Low-level IP, TCP, TLS/SSL errors on GitLab connection cause fatal crash

Description
**Describe the bug**

GitLab code in CreateRelease() doesn't handle low-level IP, TCP, TLS/SSL errors properly and can attempt to dereference nil in resp.StatusCode. I'll do a PR with a trivial fix.
 
**To Reproduce**

Steps to reproduce the behavior:

```
yaml
builds:
- goos:
    - linux
  goarch:
... [Log Snipped] ...
  download: [URL]
  skip_tls_verify: false
```

**Expected behavior**

Printing out proper net/tls/x509/etc. error and exiting properly.

**Environment (please complete the following information):**

- OS: [Linux]
- OS version: [4.19.0-0.bpo.5-amd64]
- GoReleaser Version [0.113.0]

**Additional context**

Crashes on rereferencing nil in resp.StatusCode in internal/client/gitlab.go:71 whenever there is a low-level connectivity issue as resp doesn't have to be non-nil.
