Title

XCB event handling broken with multiple windows

Description
If an application has multiple windows, event handling will break since the events are handled per-connection (which is shared) and not per-window. Any window can handle any event destined for any window. This leads to broken behaviour such as clicking the close button of one window closing another window instead.

This might have already been the case with the previous Xlib implementation, but I didn't bother to test that.

The fix would be to make windows inspect events for the id of the window they are destined for and queue events that don't belong to them to an event buffer that each window would have to have.
