## Current behavior
 
Currently, ivy will not parse the following into the proper instructions:

```html
div xmlns:foo="[URL] class="my-app" foo:bar="baz" title="Hello">Hello  World ! 
```

## Expected behavior
 

The instructions should look something like:

```ts
$r3$.ɵE(0, 'div', $e0_attrs$);
$r3$.ɵT(1, 'Hello ');
$r3$.ɵE(2, 'b');
$r3$.ɵT(3, 'World');
$r3$.ɵe();
$r3$.ɵT(4, '!');
$r3$.ɵe();
```

## Minimal reproduction of the problem with instructions
 
Create a component with the template above, examine the output of the component to check the `namespaceURI` of the `foo:bar` attribute.

## What is the motivation / use case for changing the behavior?
 
To support namespaced attributes in Angular.
