Title

StoredResponsesMap not threadsafe

Description
The StoredResponsesMap is based on the not so threadsafe LinkedHashMap. This map is filled from multiple threads by the WebPageRenderer, which can lead to the internal table property of hashmap going out of sync with the header property of linkedhashmap. As the hashmap entries are not gc'able this leads to out of memory exceptions.
