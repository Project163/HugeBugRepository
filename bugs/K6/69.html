Title

JSON.parse with reviver option cause panic

Description
`reviver` option in `JSON.parse` causes k6 to panic, no matter what revive function is doing.

## Environment

- k6 version: `k6 v0.26.2 (2020-03-18T11:45:39+0000/v0.26.2-0-g459da79e, go1.13.8, linux/amd64)`
- OS and version: Ubuntu 20.04 LTS

## Expected Behavior

Calling `JSON.parse` with `reviver` option transforms the output with provided function, e.g.

```js
let obj = JSON.parse('{ "a": "foo" }', (k, v) => k === 'a' ? 'bar' : v)
// Outputs: { a: 'bar' }
```

## Actual Behavior

The code above causes panic:

```
panic: interface conversion: goja.Value is goja.valueUndefined, not *goja.Object [recovered]
        panic: interface conversion: goja.Value is goja.valueUndefined, not *goja.Object [recovered]
        panic: interface conversion: goja.Value is goja.valueUndefined, not *goja.Object

goroutine 56 [running]:
... [Log Snipped] ...
created by github.com/loadimpact/k6/core/local.(*Executor).scale
        github.com/loadimpact/k6/core/local/local.go:348 +0x328
```

## Steps to Reproduce the Problem

Run sample script with `k6 run`

```js
export default function main() {
  JSON.parse('{ "a": "foo" }', (k, v) => k === 'a' ? 'bar' : v)
}
```
