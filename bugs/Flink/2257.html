Title

OperatorSubtaskDescriptionText causes failures on Windows

Description
File-based state backends that use the description provided by  OperatorSubtaskDescriptionText  for file names will categorically fail on Windows as they contain characters that aren't allowed in paths "(", ")" and "/".
