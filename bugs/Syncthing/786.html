Title

"Syncing (NaN%, 0 B)" when syncing 0-byte files

Description
How to reproduce:

1. Share an empty folder between Device A and B.
2. Create some empty 0-byte files in the folder on Device A.
3. Let the file watcher detect them and start syncing to Device B.
4. Check the folder status on Device B.

[Image: image]

Tested with `v1.10.0-rc.2`.
Discussion
- This is caused by dividing by zero in the following line in syncthingController.js:
```js
var pct = 100 * $scope.model[folder].inSyncBytes / $scope.model[folder].globalBytes;
```
In your case, globalBytes is 0, so the result becomes NaN.

Extending the third `if` in that function fixes the problem (see commit in my fork above):
```
js
        $scope.syncPercentage = function (folder) {
            if (typeof $scope.model[folder] === 'undefined') {
                return 100;
            }
... [Log Snipped] ...
            return Math.floor(pct);
        };
```
With this, it will always show 95% just like when local deletes still need to happen:
