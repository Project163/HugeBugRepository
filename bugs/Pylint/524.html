Title

conditional import against six.PY2 emits error

Description
### Steps to reproduce
1. Given following code
```
import six
if six.PY3:
    from urllib.parse import urlparse
else:
    from urlparse import urlparse
```
2. run pylint with python2

### Current behavior

```
[E0611(no-name-in-module), ] No name 'parse' in module 'urllib'
```

### Expected behavior
no error reported
