Title

Using Lexplore once, permanently changes g:netrw_chgwin

Description
### Neovim version (nvim -v)

NVIM v0.5.1

### Vim (not Nvim) behaves the same?

yes

### Operating system/version

Debian/Sid

### Terminal name/version

gnome terminal

### $TERM environment variable

xterm-265color

### Installation

system package manager

### How to reproduce the issue


1.    start vim and open :Lexplore
2.    close with :Lexplore again

this triggers the permanent change:

3.    start :Explore
4.    select a file and press enter -> it should open in the same window but opens in a new one

### Expected behavior


1.    start vim and open :Lexplore
2.    close with :Lexplore again
3.    start :Explore
4.    select a file and press enter -> it should open in the same window

As per documentation :Lexplore is a toggle, i.e. you can use the same command to open/close the window. I believe upon closing the window, you should re-set the g:netrw_chgwin to whatever it was before it was opened.

see above (how to reproduce).
