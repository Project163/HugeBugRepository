Title

http-osgi transport not registered on proper id

Description
The OSGi http transport is not propertly registered on the  [URL] transportId.  Thus, the SOAPTransportFactory cannot properly map it and OSGi services fail to start. 

 Workaround is to add a transportId="[URL] to the jaxws:endpoint definitions in the spring-dm beans.xml.
