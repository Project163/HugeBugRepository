Title

Variable redefined false negative

Description
Originally reported by: **Claudiu Popa (BitBucket: [Link: PCManticore], GitHub: @PCManticore)**

---

Here's an example where a redefined error would have been nice from Pylint.
In the given code, there's a function which receives a parameter with a given name, latter in the function body the label being reassigned in a for loop. This introduces a tricky bug,
where the if branch will never be taken if resource_type is a different type than _resource_.

```
#!python

def test(resource):
    for resource in resources:
        if resource.resource_type == resource:
           call_resource(resource)

```

Rewriting the code with other variable names gets rid of the bug, as in:

```
#!python

def test(resource_name):
    for resource in resources:
        if resource.resource_type == resource_name:
           call_resource(resource)

```
