Title

Trigger throws an error when used with useFieldArray

Description
**Describe the bug**
The manual validation via `trigger` throws an error when the `useFieldArray` field name is passed as a parameter (string or array). The `trigger` validation on all fields works normally.

**To Reproduce**

1. Go to Codesandbox
2. Click on button "Trigger Contacts" or "Trigger User Name and Contacts"
3. See error `TypeError: (destructured parameter)._f is undefined`

[URL]

**Expected behavior**
It should not fail and should validate `useFieldArray` fields.
