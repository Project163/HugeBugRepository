Title

calc() with escaped strings removes parenthesis

Description
In 3.0 calculations in `calc()` are now only done on runtime, as stated in [Link: changelog.md]. Previously, since content of `calc()` was being calculated, things that wanted to be kept had to be espaced as such:

```
less
// input
.a {
  @v: 10px;
  height: calc(~'100%' - ((@v  * 3) + (@v * 2)));
... [Log Snipped] ...
  height: calc(100% - 50px);
}
```

After upgrading to **3.0** the result is

```
less
// input
.a {
  @v: 10px;
  height: calc(~'100%' - ((@v  * 3) + (@v * 2)));
... [Log Snipped] ...
  height: calc(100% - (10px * 3) + (10px * 2));
}
```

### Workaround

This can currently be fixed by not escaping;

```
less
// input
.a {
  @v: 10px;
  height: calc(100% - ((@v  * 3) + (@v * 2)));
... [Log Snipped] ...
  height: calc(100% - ((10px * 3) + (10px * 2)));
}
```
