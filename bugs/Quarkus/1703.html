Title

RESTEasy Reactive doesn't provide converters for types like `Optional `

Description
### Describe the bug

Not sure if this is expected to work or not, but while RestEasy Reactive has support for Java Time types (like `LocalDate`) out-of-the-box, this doesn't work when wrapped in an optional (e.g. `Optional `).

### Expected behavior

I would have expected this to be supported. Sample code:

```java
    @GET
    @Produces(MediaType.TEXT_PLAIN)
    public String hello(@QueryParam("when") Optional  when) {
        return "Hello " + when + " from RESTEasy Reactive";
    }
```
