Title

bindValues() with array fails when function is called directly

Description
As [Link: requested], a new issue:
### What steps will reproduce the problem?
Using the `Command::batchInsert()` functionality with the deprecated array notation to specify a data type:

```
php
$rows = [
   ['row1', ':value1'],
   ['row2', ':value2'],
]
... [Log Snipped] ...
]
$db->createCommand()->batchInsert('table', ['name', 'value'], $rows)->bindValues($parameters)->execute();
```

### What is the expected result?
2 rows inserted, as the use of an array for bound values should be deprecated but still functional.

### What do you get instead?
"Array to string conversion" in `db/Command.php:219`

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.14
