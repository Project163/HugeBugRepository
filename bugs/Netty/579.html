Title

Potential endless loop in Recycler.Stack.scavengeSome

Description
### Expected behavior

Recycler.Stack.scavengeSome should never run forever.

### Actual behavior

Recycler.Stack.scavengeSome may not stop and it prevents the event loop from running other tasks.

### Steps to reproduce
