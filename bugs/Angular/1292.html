Discussion
- Update: `Router.navigate` doesn't work either. E.g. the following doesn't work:

```ts
this.router.navigate(["/profile", { outlets: { sidebar: null } }]);
```

Workaround: add a click handler and call navigate a second time, **but** only after the first one completes.

```ts
this.router.navigate(["/profile"]).then(() =>
            this.router.navigate([".", { outlets: { sidebar: null } }]));
```

I did some work around similar to the @tinchou but always going from root, it could be improved using promise instead of `setTimeout` for sure, but basically I do each step at time.

```js
justGo (...args) {
  this.router.navigate(['/']);
  args.map((arg, index) => {
    setTimeout(() => this.router.navigate(arg), 50 * (index + 1));
  });
}
```
