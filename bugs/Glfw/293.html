Title

Description
I've encountered a compilation issue when trying to build GLFW from source on Linux platforms (as part of a simple project that uses [Link: dawn]). The build instructions I have used are below. 
I've tested this on Ubuntu 22.04 LTS with GCC 11.4.0. 

```
git clone [URL]
cd glfw
cmake -B build -G Ninja -DGLFW_USE_X11=OFF
cmake --build build
```
