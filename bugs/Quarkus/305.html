Title

ReflectiveHierarchyStep warning - unable to properly register for reflection

Description
When building Quarkus there are 4 ReflectiveHierarchyStep warning in testsuite saying unable to properly register for reflection.

Some of the warnings are a bit wierd - e.g. io.vertx.core.json.JsonArray case which should be covered in [Link: ResteasyDotNames.java#L62], io.vertx.core.json.Json* were reported in [URL] and fixed in related PRs.

```
quarkus-integration-test-vertx
[WARNING] [io.quarkus.deployment.steps.ReflectiveHierarchyStep] Unable to properly register the hierarchy of the following classes for reflection as they are not in the Jandex index:
	- io.vertx.core.json.JsonArray
	- io.vertx.core.json.JsonObject
```
