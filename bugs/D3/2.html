Title

Don't ignore NaN-value nodes.

Description
The hierarchy layout currently ignores any nodes with nonpositive values. This is the right approach for space-filling layouts that depend on the node value (such as the treemap and partition layouts), but not for node-link layouts (such as the tree and cluster layouts).
