Title

Shaders are not recompiled when fog is applied to a scene after initial render

Description
##### Description of the problem

If fog is added to a scene after it has been rendered, it is not (visibly) applied to the scene. Judging by @mrdoob's comment in #9370, this is probably because shaders are not recompiled when the fog is set.

[Link: Here is a fiddle] showing the problem, button toggles fog (but it isn't applied).
