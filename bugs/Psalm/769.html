Title

and/or not work as expected

Description
According to #98 `and` / `or` should be supported, but they are not fully working.

Consider this: [URL]

Two issues are raised, even if the code works perfectly well: [URL]

If I use the ternary operator, like here: [URL] everything is fine.

I know that usage of `or` in the example is not really ideal (even if fully valid), but I used it a very simple way to demonstrate the issue.

In PHP, when there's `{condition} and {statement}`, then `statement` is executed only if `condition` is true (using `or` only if `condition` is false).

This behavior is completely unsupported in Psalm.

Note how even using `&&` and `||` won't help in this case, in fact, it seems that logic operators are taken into consideration inside `if` or other statements like `while`, but now when outside any of those.
