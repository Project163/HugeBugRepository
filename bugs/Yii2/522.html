Title

Yii2: RadioList and CheckboxList - The for attribute of the label element must refer to a non-hidden form control.

Description
### What steps will reproduce the problem?

$form->field($model, 'attribute')->radioList($model->arrAttributeOptions)
$form->field($model, 'attribute2')->checkboxList($model->arrAttribute2Options)
### What is the expected result?

For example, the checkbox list active field produces this (note label and hidden input):

```
 
    Attribute Label 
    
    
           attributevaluelabel1  
... [Log Snipped] ...
    
 
```
### What do you get instead?

Go to a w3C validator: "Error: The for attribute of the label element must refer to a non-hidden form control."
