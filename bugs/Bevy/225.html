Title

`BlobVec` does not respect alignment for zero-sized types

Description
## Bevy version

 

## Problem

Like `Vec`, `BlobVec` uses a dangling pointer as the backing storage for zero-sized types. However, `BlobVec` does not respect alignment, which results in instant UB when using a ZST with alignment other than 1.

```
rust
#[test]
fn aligned_zst() {
    #[derive(Component)]
    #[repr(align(32))]
... [Log Snipped] ...
    for &Zst in q.iter(&world) {}
}
```

[Link: The offending line]: it creates a dangling pointer which is well-aligned for `u8`, not for the type being stored.
