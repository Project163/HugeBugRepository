Title

When opening project in Cypress (manual dl) on OS Sierra, error writing to file due to translocation

Description
If Cypress is manually downloaded on OS Sierra, translocation error occurs on writing to files on `open:project`. 

**For Reference:** 
- [URL]
- [URL]

**Example Screenshot**
[Image: screen-shot-2016-09-26-at-10 59 39-am EROFS: read-only file system, open]
Discussion
- **Current Workaround**

You need to install Cypress from the CLI and it will work because we invoke the binary directly.

``` bash
npm install cypress-cli
cypress install
```

**Thoughts**
- we may need to switch to packaging OSX in a `.dmg` but that is a lot of work
- we could look into not writing files relatively to where Cypress is installed (but this may still cause updating from within Cypress not to work)
- we may need to account for being translocated and provide an error modal to the user indicating the steps to take to resolve this
- Fixed in [Link: `0.19.2`].
