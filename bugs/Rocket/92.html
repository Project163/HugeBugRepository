Title

Redirection to a route which takes a vector parameter results in an error

Description
### Rocket Version

0.5.0

### Operating System

NixOS 23.11

### Rust Toolchain Version

rustc 1.76.0

### What happened?

Redirecting to a route which takes a vector parameter throws the following error:
```
error[E0277]: the trait bound `Vec : FromUriParam ` is not satisfied
  --> src/main.rs:18:31
   |
18 |     Redirect::to(uri!(test(1, numbers)))
   |                               ^^^^^^^ the trait `FromUriParam ` is not implemented for `Vec `
... [Log Snipped] ...
           and 149 others
   = note: this error originates in the macro `rocket::rocket_internal_uri` which comes from the expansion of the macro `uri` (in Nightly builds, run with -Z macro-backtrace for more info)
```

According to the [Link: Documentation] one should only implement the trait `FromUriParam` if you intend to provide arguments which differ from the parameters in the given function.

After seeking help in the Matrix room I was asked to open an issue regarding this.
