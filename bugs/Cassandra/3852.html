Title

Re-populate token metadata after commit log replay

Description
I've noticed this while working on another task: a node that was currently down was not showed in my nodetool status. The node had joined the cluster and was displayed in the status before. 

 I've attached   mv_repair_test.sh      to reproduce the issue. After the execution of the script, just try a: ccm node3 nodetool status
Discussion
- Attached patch. What happens here is that the node is shutdown before system keyspace flushing, so when the node is back, since token metadata is populated before commit log replay after   CASSANDRA-9317  , the down peers which are loaded into system keyspace after commit log replay are not populated into token metadata until they're UP again. 

 Simple fix is to re-populate token metadata after commit log replay. Would you mind reviewing since it's related to #9317,  krummas ?
