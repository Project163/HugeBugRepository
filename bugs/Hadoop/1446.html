Title

test-patch says "-1 overall" even when all checks are +1

Description
I noticed recently that test-patch is posting "-1 overall" despite all sub-checks being +1.  See   HDFS-7533   and   HDFS-7598   for some examples.
Discussion

- Attaching a patch that removes the extra (( RESULT = $RESULT + $? )) code.
