Title

Creating a SQLite table with "WITHOUT ROWID" & "STRICT" causes exception

Description
### Describe the bug

Using the `sqlite_with_rowid` and `sqlite_strict params` at the same time when creating a table causes an exception.

Likely because there is no comma after the WITHOUT ROWID keyword (see DDL below in the exception).
Refer to the [Link: SQLite docs (5.)] about strict tables which mentions that both options can be used at the same time but need to be comma separated.
