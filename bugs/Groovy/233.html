Title

AntBuilder seems to have a problem with Ant 1.6's attrib task

Description
Andy Paul found this... 

 ant = new AntBuilder() 
ant.attrib(  file:args[0 ], readonly:"false" ) 

 and got; 
27-Feb-2004 16:28:11 groovy.util.AntBuilder createNode 
WARNING: Could not convert tag: attrib into an Ant task, data type or property
Discussion
- attrib is an optional task so it is not guaranteed that the necessary jar file is in the class path. 

 Unless we package the ant-optional jar as well as the ant jar with Groovy then this error is an indication that the user hasn't got the appropriate environment set up.
- The general consensus is that it is up to the user to have the appropriate jar files on their CLASSPATH for the optional tasks to work.  So in this case ant-nodeps.jar needs to be on the C:ASSPATH (the Ant optional jar got split up).
- It's a `Won't Fix'
