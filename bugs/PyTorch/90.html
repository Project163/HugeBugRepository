Title

`adapative_{avg, max}_pool` will crash in the backward pass on cuda on empty output size

Description
### 🐛 Describe the bug

`adapative_{avg, max}_pool` will crash in the backward pass on cuda

```
python
import torch

input = torch.rand([1, 64, 10, 9, 8], dtype=torch.float32, device='cuda', requires_grad=True)
output_size = 0
... [Log Snipped] ...
# Crash
print('backward')
```

It will try to compute the gradient based on an empty tensor.

### Versions

pytorch: 1.11.0
cuda: 11.3
