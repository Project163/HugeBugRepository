Title

Using fallback font 'TimesNewRomanPSMT' for 'Wingdings'

Description
The attached file has the non embedded "Wingdings" font. That one is available on windows, however its name is "Wingdings-Regular" so it doesn't match.
Discussion
- So the code in getFallbackFontName in FontMapperImpl is looking for "Windings-Roman". The question is whether "-Regular" is a popular postfix or just something specific to Windings (because it's a symbol font, not a roman font). I'm thinking it's probably the latter, so we could special-case it in getFallbackFontName.
- Alternatively, because we know that Windings-Regular is actually Windings, and not a fallback, we could modify findFont to try adding "-Regular" to the base name. That way the font mapping won't incorrectly count as a fallback.

- Trying the postfix for all fonts is preferred. Because Windings isn't a base-14 font we'd prefer not to special-case it if possible.
- The current state looks good - it's a general-purpose fix rather than Windings-specific, so we might even improve the situation for other fonts using the "-Regular" postfix. Nice.
