Title

Can't use list argument when The method's first argument class is int

Description
When I run the following codes, I caught  
java.lang.ClassCastException: java.util.ArrayList cannot be cast to java.lang.Number 
at org.codehaus.groovy.reflection.stdclasses.IntegerCachedClass.coerceArgument(IntegerCachedClass.java:37) 
... 
  
 def foo( int  arg0,  String  arg1, arg2){
    println arg0
    println arg1
    println arg2
}
foo([ 1,  "B" , 0.5 ])
 
  

 but I was able to run the next methods 

  
 def foo( Number  arg0,  String  arg1,  int  arg2){...}

def foo( String  arg0,  int  arg1,  int  arg2){...}
 
  

 I tried 
  
   Number GOOD
  String GOOD
  char GOOD
  Object GOOD
  BigInteger GOOD

  int BAD
  BigDecimal BAD
  float BAD
  byte BAD
Discussion
- Are you aware that you are passing in a list? Both of the following work fine for me: 
foo(1, "B", 0.5) 
foo(* [1, "B", 0.5] ) // spread operator 

 Conversely, foo([ 1, "B", 0.5 ]) doesn't work for me no matter which of your method definitions I use. And I'd be surprised if it did.
- in fact there is a special method invocation path for this. So I think it should work... I very dislike that path btw. I prefer the usage of the spread operator
- Fixed on 1.5.8 and 1.7-beta-1. When the 1.6.1 branch is setup, I will fix it there.
- Fixed on 1.6.1 too. Overall fixed on 1.5.8 / 1.6.1 / 1.7-beta-1 branches.
