Title

Nested falsy defaultValues are undefined when using watch()

Description
**Describe the bug**
Falsy values nested inside `defaultValues` are returned as `undefined` by `watch()` on the initial render.

**To Reproduce**
Steps to reproduce the behavior:
1. Pass a falsy nested value to `useForm` in `defaultValues`
2. Add a `watch()` on the path to the nested value
3. On initial render, watched value is `undefined` instead of the actual default value
