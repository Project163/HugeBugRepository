Title

DefaultChannelHandlerContext.fireUserEventTriggered(...) uses wrong ChannelHandlerContext

Description
DefaultChannelHandlerContext.fireUserEventTriggered(...) uses wrong ChannelHandlerContext so the wrong one is notified. This can even cause a NPE if there isn't a next ChannelHandler in the pipeline.
