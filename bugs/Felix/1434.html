Title

ManagedService.update must be called with null if configuration exists but is not visilbe

Description
R 4.3 Configuration Admin Specification (v1.4) prescribes in Section 104.5.3, that ManagedService.update must be called with null if configuration exists but is not visible to the ManagedService. Currently this call with null is only done according to the R 4.2 (v 1.3) specification if configuration does not exist.
Discussion
- Fixed in Rev. 1202591 as stipulated
- Adapted integration test case to MS.update being called with null for invisible configuration (used to not be called at all previously)
