Title

When you unfocus Cypress tab in Chrome, JS stops executing & fails the tests.

Description
When you unfocus the Cypress tab in the middle of running tests, the JavaScript stops executing and the current test fails due to timeout.

[Image: screen shot 2015-03-31 at 10 01 31 am]

Instead of failing, maybe cy could 
- pause the tests
- display a message about being unfocused
- ???
Discussion
- This is due to modern browsers throttling `setTimeout` on inactive tabs from `0.004s` to `1s`. There is no flag to turn this off, it is a constant.

The only way around this is to use `setImmediate` or `requestAnimationFrame`. The problem is `mocha`  as Cypress does not use `setTimeouts` for async.

But an even bigger problem is given we update everything on our end not to use `setTimeout`, the users application will still be throttled if they use `setTimeout`, which would still cause the tests to fail / be flakey.
- There are some potential work arounds work investigating - such as playing silent audio, which prevents Chrome from backgrounding a tab.

Also listed here as a known issue: [URL]
- As of [Link: `0.16.0`], when running a project in the new Cypress browser environment, if a new tab is opened, a message now displays discouraging the use of multiple tabs while testing.
