Title

Culture-dependent NUnit tests fail when running on non-English machine

Description
Around 10 NUnit tests are failing if not run on a English machine. They all fail because of string representation of NaN or infinity.
Discussion
- Is it possible to switch one of the build agents on TeamCity to run as a different culture so that we can catch issues like this in the future? Or is it good enough that one person on the team tends to run using a different culture?
- Ideally it would be nice to be able to do so but we don't have direct
control over the build agents so we can't. We could probably do it straight
in the code by changing the thread culture. In practice, I think it's not
worth doing any of these because the issue showed up in test code and does
not affect NUnit itself.
