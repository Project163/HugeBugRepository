Title

Discussion
- Did some local testing with the attached patch and it seems to fix the issue
- The  tests didn't catch this because TestSQLHandler is using field names like  field_i  which is hardcoded to use trie fields. If it used  field_ti  then the test framework would have randomized b/w trie and point fields.  

 We should just use {[schema.xml}} instead of  "schema-sql.xml"  . A quick glance shows that the test uses three dynamic fields - _t  , _s and _i which is present in schema.xml . _i is also randomized b/w trie and point fields.
