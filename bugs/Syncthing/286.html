Title

Crash on folder removal

Description
I added a shared folder, located on a remote machine, to test transfer speeds to the local machine. So, only two nodes. After the local shared folder was ~5% completed, I removed the folder from the local machine through the web interface. When that happened, Syncthing crashed.

Here is some info about each Syncthing installation, followed by the panic trace.
