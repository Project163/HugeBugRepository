Title

Stub constants not recognized

Description
Hi!

I have a project that uses the PHP radius library and in an attempt to silence Psalm on all kinds of missing/undefined stuff, I added the proper [Link: PhpStorm stub file] to my [Link: project].
It does fix some of the issues, but it seems that constants defined in the stub-file are not [Link: recognized].

Is this a bug? Am I doing something wrong here? Or have I just misinterpreted the way stubs are supposed to work?
Discussion
- The problem is that those constants are defined with `define`. It looks like Psalm doesn't recognize those in stub files.

If you enable the radius extension before running Psalm, it shouldn't need that file.
- Unfortunately installing the radius-library in Travis is sheer impossible... `pecl install` fails horribly and `apt-get install php-radius` appears to not deploy a .so file in the extensions-directory... This stub-file would make my life so much easier
- Not a problem. I checked, and none of those constants need `define`, so you can just change e.g., `define('RADIUS_MPPE_KEY_LEN', 16)` to `const RADIUS_MPPE_KEY_LEN = 16` while this is still an issue.
