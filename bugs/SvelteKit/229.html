Discussion
- As a temporary workaround, you can add `export const ssr = false` to your root `+layout.js` file.
[URL]
I was able to consistently build several times without any errors, although I'm not 100% sure why that fixes it (I just followed a hunch the issue was caused by SSR).

The main issue is that the image files (assets) are not being output as a client asset `/.svelte-kit/output/client/_app/immutable/`. So, while prerendering, the process errors when it can't find the asset at that path. However, they're available in the server assets `/output/server/_app/immutable/`.

This is related to Vite 4.1 [URL] and SvelteKit [URL] separately outputting server assets and client assets:
