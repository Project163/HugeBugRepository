Title

2.4.5: OR array with only one entry produces wrong SQL

Description
I have a condition with the following data:

```
Array
(
    [section] => test
    [OR] => Array
        (
... [Log Snipped] ...
        )
)
```

when I then do a find CakePHP 2.4.5 sends:

```
SELECT `X`.`section`, `X`.`option` FROM `x`.`x` AS `X`   WHERE `section` = 'test' AND option = ('vis')
```

Shouldn't it detect that we only have ONE entry in OR and use = ?
