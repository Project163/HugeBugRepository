Title

Response code is not logged for SOAP responses

Description
If you enable logging through the LoggingIn/OutInterceptors and then send a SOAP request through, the response code is not logged. 

 --------------------------- 
ID: 2 
Encoding: UTF-8 
Content-Type: text/xml 

 The response code is logged fine for rest requests: 

 --------------------------- 
ID: 19 
Response-Code: 200 
Content-Type: application/xml
Discussion
- there seems to be an inconsistency between jaxrs and jaws in how the http code is logged at the server/provider side. 
in any case, we should make this consistent.
- Hi Mandy, 
I just fixed this issue in trunk and the current 2.7.x and 2.6.x snapshots. 
the response code should be included now. 
regards, aki
