Title

Project that depends on Bevy with no default features but just feature [std] fails to compile (use of unresolved module or unlinked crate `bevy_utils`)

Description
## Bevy version

0.16.0-dev

## What you did

I've created a brand new project with `cargo new bevy-example`
and added a bevy dependency to my Cargo.toml like so:

```toml
[package]
name = "bevy-example"
version = "0.1.0"
edition = "2024"

[dependencies]
bevy = { git = "[URL] rev = " ", default-features = false, features = ["std"] }
```
