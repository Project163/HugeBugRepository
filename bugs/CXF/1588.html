Title

Make slf4j-jdk14 optional dependency in http-jetty

Description
slf4j refuses to work properly if two bidings are present, but when I use cxf-rt-transports-http-jetty artifact in maven it pulls also slf4j-jdk14 (as it is transitive dependency). 

 I would like this dependency to be optional, as it really is one of many jars that someone can choose to use in his own tests (I choose to use slf4j-log4j12) and such person is forced to exclude slf4j-jdk14. 

 Another thing is I believe the scope should be 'runtime' as you don't use it for main/test compilation, but only at runtime.
