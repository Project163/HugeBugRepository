Title

Event listener testRunStarting starting position in junit reporter

Description
## Description
 
I want to add my own XML tag with general information in the junit report and I am using the event listener testRunStarting, since I couldn't figure out how to print " 
I am using this custom event listener

	virtual void testRunStarting(Catch::TestRunInfo const& testRunInfo) override {
		std::cout   ";
	}

which results in this output

	 
	  >
	   ` and not in it.

### Extra information
 
* Catch version: **v2.2.1**
Discussion
- I am not quite sure where you want the ` ` element to be, but in the process of looking at this I found out that we have a bug in our support for event listeners. We promise that they will be called _before_ reporters, but right now they are called _after_ reporters.

If I fix this, the output will be
```
xml
 
  
 
   
... [Log Snipped] ...
   
 
```

is that what you intended?
- This is not what I intended, but I found another way to add my own XML by writing a reporter.

Your output wouldn't be a valid XML file. I wanted something like this

```
xml
 
 
    
   
... [Log Snipped] ...
   
 
```

It is also possible to add attributes to ` ` with the current version, but that seems to be the bug you mentioned.

However, with an own reporter it doesn't matter where the output starts.
- Yes, to change the format of the report you'd have to write your own reporter. In this case deriving from the existing one and just overriding the point you need to inject something is probably the way to go (hey, sometimes OOP re-use actual works!).
To write tags you need to use the `XmlWriter` class. It closes tags lazily, so it needs to know the next thing you're writing is a new tag (you can't just start writing the characters `"
