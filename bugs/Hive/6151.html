Title

ObjectStore.getPartitionNamesNoTxn doesn't handle max param properly

Description
As per  this HMS API test case  listing partition names doesn't check tha max param against MetaStoreConf.LIMIT_PARTITION_REQUEST (as other methods do by checkLimitNumberOfPartitionsByFilter), and also behaves differently on max=0 setting compared to other methods. 

 We should bring this into consistency.
