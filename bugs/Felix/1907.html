Title

InventoryPrinter must run on Java 1.4 plattforms (for embedded use)

Description
The new InventoryPrinter module currently compiles with the standard platform setup and uses Java 5 API. This prevents this bundle to run on Java 1.4 plattforms which are typically used on embedded systems. 

 We have to setup the module as follows: 
 
	 compile for Java 1.4 
	 make sure only Java 1.4 API is used
Discussion
- Implemented the Java 1.4 API check and Java 1.4 class file generation in Rev. 1468913 

 Also replaced all non-Java 1.4 API use by Java 1.4 API.
