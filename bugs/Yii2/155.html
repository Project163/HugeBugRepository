Title

Error in MessageSource

Description
i18n/MessageSource.php
string number 116

instead

```
    $this->_messages[$key] = $event->message;
```

must be

```
    $this->_messages[$key][$message] = $event->message;
```
Discussion
- also a return is missing...
- `$this->_messages[$key]` is array of translated messages.
I.e. `$this->messages[$key]['blablabla']` is translated message blablabla
If doing `$this->messages[$key]=$message` then `$this->messages[$key]['blablabla']` is undefined.

In my case if I attach event EVENT_MISSING_TRANSLATION, than after first untranslated message all another messages still untranslated.

Example:
assume that 
string1,string2 - have translations
string3 - has not translation

```
\yii\base\Event::on(
    \yii\i18n\DbMessageSource::className(),
    \yii\i18n\DbMessageSource::EVENT_MISSING_TRANSLATION,
    function($event) { return $event;  }
);
... [Log Snipped] ...
Yii::t('app','string2'); //HAS TRANSLATION, BUT NOT TRANSLATED!
Yii::t('app','string1'); //HAS TRANSLATION, BUT NOT TRANSLATED!
```

If dont attach event than all works properly.
- Return is missing too.
Must be

```
$this->_messages[$key][$message] = $event->message;
return $event->message;
```

But in this case may need to edit and another classes/methods (MessageSource->translateMessage never return false value)

As variant - completly remove string number 116.
In this case we can not change `$event->message;` in event handler. 
But who and why is it necessary?
- Thanks for the detailed explaination, will fix this soon.

`$event->message;` can be used to provide fallback translation maybe using some automated source or even mark the string with special markup so you see all missing translations in red on your page.
