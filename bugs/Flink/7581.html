Title

NettyShuffleMaster not close tiered-storage resources

Description
When Flink's tiered storage is enabled, the NettyShuffleMaster does not close the 
TieredStorageMasterClient. 
This is releated to FLIP-459, which support Flink hybrid shuffle integration with Apache Celeborn. 

 As a result, some threads and memory resources may remain open after the flink job  is completed.
