Title

[YSQL] Attaching a partitioned index fails

Description
Jira Link: [Link: DB-3913]
### Description

```
-- Create partitioned table and index
create table idxpart (a int, b int) partition by range (a, b);
create index idxpart_a_b_idx on only idxpart (a, b);

-- Create partitioned table and index
... [Log Snipped] ...
    @           PostgresServerProcessMain
    @           main
```

In `YBCPrepareAlterTableCmd`, we try to determine the relations for which schema version needs to be incremented due to this alter. Under the case `AT_AttachPartition`, we only consider the case where we attach a partition table - and try to call `heap_openrv` on the entity being attached. This fails because `heap_openrv` is not meant to be called on an index.
