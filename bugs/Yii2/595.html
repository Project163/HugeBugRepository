Title

Issue with URL::to when the URL only contains a default element

Description
### What steps will reproduce the problem?

in the config/main.php add the following rule

`                [
                    'pattern' => ' ',
                    'route' => 'site/index',
                    'defaults' => ['language' => 'en'],
                ], 
`

Then create a URL like that

`Url::to(['site/index', 'language' =>'en'])`

### What is the expected result?
The generated URL should be 

` Home `

### What do you get instead?

` Home `

The slash is duplicated

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      |  
| PHP version      | 7.1.0
| Operating system | Windows 10 and Ubuntu 16.04

Issue is not reproducible on Yii 2.0.10
