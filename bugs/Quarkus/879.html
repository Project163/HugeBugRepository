- Looks like ‘RoutingContext‘ isn't always set in here - [URL]

If that field is null and the cdi producer (that is normal scoped) attempts to return it, it is an error according to cdi specification.
- ... [Middle Discussions Snipped for Brevity] ...
- From what I know the `CurrentVertxRequest` is never set for reactive routes. The main reason being that you can inject it directly in a route method (as a param) and pass to any dependency directly. In other words, the `CurrentVertxRequest` should be normally useless for reactive routes and we'd like to avoid unnecessary allocations...
