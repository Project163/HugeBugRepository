Title

When applying a generic `class-string` to `class-string ` and `return Foo&T`, psalm infers `mixed`

Description
In the following scenario, since a generic `class-string` is used when calling `mock()`, psalm reduces the declared `@psalm-return RequestedType&MockObject ` (presumably inferred as `@psalm-return object&MockObject `) to just `mixed`.

Ideally, this should be inferred as just `MockObject`, which is the the closest "valid" type:

```
php
 checkExpectations();
}
```
