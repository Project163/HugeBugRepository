Title

Trailing comma is removed in complex dict literal

Description
Operating system: Ubuntu 16.04.4
Python version: 3.6.3
Black version: 18.4a2
Does also happen on master: yes (since 18.4a2 == master)

Testcase:

```python
mapping = {
    A: 0.25 * (10.0 / 12),
    B: 0.1 * (10.0 / 12),
    C: 0.1 * (10.0 / 12),
    D: 0.1 * (10.0 / 12),
}
```

```
diff
$ black --diff test.py
--- test.py  (original)
+++ test.py  (formatted)
@@ -1,7 +1,7 @@
... [Log Snipped] ...
+    D: 0.1 * (10.0 / 12)
 }
```

Black actively inserts trailing commas elsewhere, so I guess this is not intended.
