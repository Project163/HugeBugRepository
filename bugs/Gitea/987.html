Title

attachment of review not sent if no main review comment given

Description
### Description

Steps to reproduce:
Do a review of a PR, with some inline comments.
Then click the review button at the top, and in the popup field upload an attachment, but do not enter text into that "main comment" filed.

Expected behaviour: 
The review is submitted, with all inline comments and the attachment.

Observed behaviour:
The review gets submitted with all inline comments, but the attachment is not visible, there is no main comment block where one'd expect it.
