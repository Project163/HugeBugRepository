Title

false array key is converted to integer

Description
[URL]

```php
function foo(): array {
  $array = [];
  $array[false] = '';
  return $array;
}
```



In reality, `false` is just converted to `int` so the returned type is actually just `array `:

[URL]
Discussion
- By definition, an array can only contain `array-key`s as keys.

No matter what you feed it PHP will always either convert it to `int` or `string`:
