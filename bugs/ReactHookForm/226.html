Title

Bug - Previously mounted field arrays cannot have value set to empty array

Description
**Describe the bug**
If:

1. A field array is mounted and then later unmounted
2. We try to set its value to an empty array

then:

1. The field array will be set to the form's default value for the field array instead of an empty array.

**To Reproduce**
Steps to reproduce the behavior:

1. Go to the sandbox
2. Click the toggle hide button to hide the field array component
3. Click the change value button to update the field array's value to an empty array
4. Notice that the field array will instead be set to the default values for the field array

**Codesandbox link (Required)**
[URL]

**Expected behavior**
This operation should result in an empty array. It works fine if the field array is mounted or the value being set is not an empty array (array with some element in it). It is likely an issue with shallow merging. However, a shallow merge should not occur here because the key for the field array does exist in `formValues`. Setting an empty array value is not the same as unregistering the input (deleting its key from form values).
