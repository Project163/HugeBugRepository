Title

ArrayHelper::filter deeper than two levels returns all data after 2nd level

Description
### What steps will reproduce the problem?
Let's say we have the following array:
```
php
$array = [
    'A' => [1, 2],
    'B' => [
        'C' => 1,
... [Log Snipped] ...
    'I' => 1,
];
```
If we filter 1 or 2 levels deep, only the specified field will be returned as expected, e.g. 
```php
ArrayHelper::filter($array, ['B.D'])
```
would return:
```php
[
  "B" => [
    "D" => 2, //Note that only D is set at this level (as expected)
  ]
]
```

Now if we filter 3 (or more) levels all data after the 2nd level will be returned, e.g. 
```php
ArrayHelper::filter($array, ['B.E.G']);
```
would return:

```
php
[
  "B" => [
    "E" =>[
      "F" => 1, //Not expected
... [Log Snipped] ...
  ],
]
```

### What is the expected result?

Only the specified node should be returned
```php
[
  "B" => [
    "E" =>[
      "G" => 2,
    ],
  ],
]
```
