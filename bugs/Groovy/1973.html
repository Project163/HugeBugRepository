Title

groovy.transform.ToString annotation does not handle cycles

Description
The groovy.transform.ToString AST transformation does not handle object graphs with cycles.  See the attached junit tests.  This is a pretty serious issue because these object structures are common with some frameworks (like orm tools)
Discussion
- There is now a partial fix (for the simplest case of a self-reference) but not mutual cycles or collections of self-references or combinations thereof yet. It may be difficult to handle cycles in an arbitrary generic way. It might be easier to just specify a maximum size. Cycles would just continue until the maximum size was reached at which point "..." would be appended and then toString() calculation would stop.
- given that self-cycles are now handled I downgraded priority from critical -> major
