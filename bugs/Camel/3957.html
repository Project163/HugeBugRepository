Title

Versions of swagger-models and swagger-parser in conflict

Description
A change was made to  swagger-modules  in  swagger-core#   (version 1.5.12) that changed  java.lang.Double  type with  java.math.BigDecimal  which in turn made  swager-parser  incompatible in the version used (1.0.22). 

 This was later fixed in  swagger-parser   swagger-parser#   and released as version 1.0.25. 

 Version of  swagger-parser  needs to be updated to 1.0.25.
