Title

No error line number in case of double @

Description
I guess that this is a minor bug. Wrong variable declaration syntax does not report line number.

Input less file:

```
@@demo: "hi";
```

Reported error:

```
ERR:
  type: Syntax
  message: 'null' is null or not an object
  filename: test.less
  column: -1
  extract: ,,
```

Tested on less.js-1.3.1
