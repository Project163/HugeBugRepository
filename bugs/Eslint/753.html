Title

prefer-const rule seems to be confused by expressions in a while condition

Description
**What version are you using?**
2.0.0-beta.1

**What did you do?**
I use this code:

``` javascript
  let parsed;
  let result = '';
  while ((parsed = re.exec(str)) !== null) {
    const [, count, letter] = parsed;
    result += letter.repeat(count);
  }
```

With the "prefer-const" rule, I get `'parsed' is never modified, use 'const' instead. (prefer-const)` which seems incorrect, because it is indeed modified in the while condition.
