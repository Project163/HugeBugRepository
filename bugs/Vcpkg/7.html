Title

OpenCV is not linking to libjpeg-turbo

Description
The build configuration for OpenCV links to libjpeg in the 3rdparty libs folder instead of the libjpeg-turbo installed as a dependency.

Likewise, it also links to libpng in 3rdparty instead of the pre-installed libpng.

Build log:

Discussion
- Thanks for reporting this! I've ensured `opencv` now links against the built `libjpeg-turbo`, `libpng`, `zlib`, and `tiff` by deleting the relevant `3rdparty` directories.

In the future as the other dependencies are added, we should update `opencv` to use them.
