Title

Psalm doesn't correctly detect the number of arguments allowed for PDOStatement::setFetchMode

Description
(Sorry for the crazy title, I couldn't think of anything more succinct and still accurate)

[Link: According to the docs], `PDOStatement::setFetchMode` can optionally take up to 3 arguments, depending on the mode passed in. While trying to use the `PDO::FETCH_CLASS` mode, psalm reports a `TooManyArguments` error.

Example:
```
php
 fetch();
var_dump($a);
```
Discussion
- Apologies--this is my bad. I somehow had an older version globally installed that got picked up instead.
- Nope I take that back--it definitely happens in the latest version too!
- Yup, I added this suppression to Vimeo's own codebase last year. Good catch.

```
/** @psalm-suppress TooManyArguments due to Psalm not yet understanding callmap method options */
$this->getStatement()->setFetchMode(PDO::FETCH_CLASS, $class);
```
- Apparently there's another scenario this happens in as well (passing two values, i.e. `PDO::FETCH_CLASS | PDO::FETCH_PROPS_LATE`)--would you prefer me to create a new ticket for it or reopen this one?
