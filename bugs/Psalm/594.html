Title

Update 3.4.4 has broken splat usage in constructors

Description
It thinks that `EntityTags::$tags` has a type `Tag` instead or `array `
```
php
final class EntityTags
{
    private $tags;

... [Log Snipped] ...
    }
}
```
```
ERROR: InvalidReturnType - EntityTags.php:31:16 - The declared return type 'array ' for EntityTags::getTags is incorrect, got 'Tag'
     * @return Tag[]

ERROR: InvalidReturnStatement - EntityTags.php:35:16 - The type 'Tag' does not match the declared return type 'array ' for EntityTags::getTags
        return $this->tags;
```
PHPStorm infers the type correctly.
I have to use version 3.4.3 to keep this working. There is supposedly `inferPropertyTypesFromConstructor` but this seems to be absent in the XML scheme?
Discussion
- Sorry, will fix momentarily - in the meantime you can work around the problem by adding a `/** @var Tag[] */` docblock to the property
- It's a part of our code style: omit docblocks which can be inferred in the constructors :smile: Thanks!
- Code now works as expected: [URL]
