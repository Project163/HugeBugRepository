Description

tmux-256color

### Installation

brew install --HEAD neovim

### How to reproduce the issue

1. `nvim --clean`
2. Source the [Link: example code for user command previews], which creates a user command `:TrimTrailingWhitespace`.
3. Define a new user command `:TrimWhitespace` with `command TrimWhitespace echo "foobarbaz"`.
4. Start typing `:Trim` in the Vim command-line.

### Expected behavior

Neovim does not segfault. A custom preview is not shown until the typed command is disambiguated.

### Actual behavior

Neovim segfaults.

I think this is because we are missing a NULL check [Link: here]. `find_ex_command` states that [Link: it will return `NULL` for an ambiguous user command]. :Slig
