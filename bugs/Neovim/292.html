Title

missing cursor restore for terminals without altscreen

Description
### Problem

When alternate screen is disabled in my terminal, using `C-z` to send a neovim instance to the background causes rendering in my terminal to break. What happens is my cursor gets returned to somewhere in the middle of the buffer I was before I pressed `C-z`. Expected behavior is to return the cursor and prompt below the buffer that is currently open. I'm pretty sure this did not used to happen before I made the update (from version 0.8 I think) a few weeks ago. I also know this isn't an issue with my terminal because it does not happen with other terminal apps that use alternate screen. 

Here's what I think is relevant from `checkhealth`

```

- key_dc (kdch1) terminfo entry: `key_dc=\E[3~`
- $TERM_PROGRAM="tmux"

... [Log Snipped] ...

```

And my version info:
```
NVIM v0.9.0
Build type: Release
LuaJIT 2.1.0-beta3
```

Moreover, it isn't anything in my config that's causing the issue because `nvim --clean` faces same thing.




### Steps to reproduce

1. As you can see I'm running neovim in a tmux server and in my tmux config I have `set-option -g alternate-screen on`. 
2. From there on just run `nvim` and press `C-z` to send neovim to background.
