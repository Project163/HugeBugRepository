Title

FixedChannelPool race condition when closed during acquire

Description
An AssertionError is thrown when FixedChannelPool is being closed, while somewhere at the same time an acquire occurs. 
The acquire triggers FixedChannelPool::decrementAndRunTaskQueue(), while FixedChannelPool::close() sets                 acquiredChannelCount = 0;

This only happens when objects using the pool are not terminated prior to calling close.
