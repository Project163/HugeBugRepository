- while I agree, in general in sqlalchemy we try to do what the user specifies: so we will try to honor `.offset(0)` if it was specified by the user, since in some cases omitting it may not be the desired outcome.
You can omit it by simply doing `offset(offset if offset else None)`


yes, there is a query cache in sqlalchemy 1.4, so if the first query is invalid subsequent ones will also be. you can disable it for now.
