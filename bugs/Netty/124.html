Title

Using mod-formupload in vert.x fails with attributes bigger than 8192

Description
Vert.x sends down the netty httpRequest, which does not implement HttpContent and falls into this code:

```
if (request instanceof HttpContent) {
        // Offer automatically if the given request is als type of
        // HttpContent
        // See #1089
        offer((HttpContent) request);
... [Log Snipped] ...
        parseBody();
    }
```

As the request is not HttpContent, it is considered the lastChunk and anything bigger than 8192 in a post attributes gets lost.

For the reference, I am creating it as a netty bug and not a vert.x one as Norman asked me to do so in here [URL]
