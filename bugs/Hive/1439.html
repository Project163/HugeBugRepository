Title

RCFile::sync(long) missing 1 byte in System.arraycopy()

Description
this has a bug in this: 
System.arraycopy(buffer, buffer.length - prefix - 1, buffer, 0, prefix); 
it should be  
System.arraycopy(buffer, buffer.length - prefix, buffer, 0, prefix); 
it is missing 1 byte at the end.
Discussion
- Fix from the bug report, with an associated test-case. 

 Before fix, the new test-case will error out with 

  [junit]  Sync at offset 263 skipped sync block at location 17655 (returned 35274 instead) 

 The test fails because sync(264) == 17655, but sync(263) == 35274.
