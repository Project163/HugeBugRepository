Discussion
- Nothing is compromised, but collections import isn't supported by cqlsh, yet, if either keys or values require quoting (ascii, text(varchar), timestamp, and inet types).
- Should we tag it 2.0.1 instead of closing?  Seems reasonably important for COPY to be feature-complete to me.
