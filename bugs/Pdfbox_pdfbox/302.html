PDFBox throws exception with PDFTextStripper.getText

Discussion
- The pdf causing the exception
- I fixed the issue in revision 1469558. 

 The pdf contains a lot of inline images. Obviously only "space" and "carriage return" are allowd as whitespace character when parsing those inline images. Otherwise the parser might prematurely stop reading the image data which leads to a corrupted stream.
