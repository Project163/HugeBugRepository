Title

gui: Favicon not working in Firefox bookmarks

Description
### What happened?

Firefox doesn't show any favicon at all when adding a bookmark to the Syncthing GUI, even with the static favicon introduced by #8850. It looks like Firefox prefers the last favicon that is found in ` ` which is the link to `favicon-{{syncthingStatus()}}.png`. Because that file is not available on initial page load, it is not considered for bookmarks. The favicon logic for Firefox can be found [Link: here].
Switching the order of the favicon links in ` ` fixes the behavior for Firefox while breaking the dynamic favicon for Chromium-based browsers.
A proper fix for this issue was suggested by @ajshea in [URL]
