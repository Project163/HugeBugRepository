Title

Wheel is unusable due to python_tag

Description
# Bug
It is not possible to use the pre-built wheel, or to build a usable wheel using `pip wheel`

* OS: `Ubuntu 16.04`
* Python version: `3.6.5`
* Pydantic version: `0.18.2`

```
vagrant at ubuntu in /tmp
(v3)$ pip install pydantic-0.18.2-py36+-none-any.whl
pydantic-0.18.2-py36+-none-any.whl is not a supported wheel on this platform.

vagrant at ubuntu in /tmp
... [Log Snipped] ...
(v3)$ python --version
Python 3.6.5
```
Discussion
- Simple workaround should be to rename the file to `pydantic-0.18.2-py36-none-any.whl`. Does that work?

More generally, any idea what the correct `python_tag` should be?

I've look at this a lot in the past and couldn't find any good documentation on what the value should be.
