**Describe the bug**

Jetpack compose is (at time of writing) beta 07.  When updating to beta 07, all dependencies must also update to use it.  Lottie does not appear to have done so yet and so results in the following crash when attempting to use a lottie composable:

    java.lang.NoSuchMethodError: No interface method startReplaceableGroup(ILjava/lang/String;)V in class Landroidx/compose/runtime/Composer; or its super classes (declaration of 'androidx.compose.runtime.Composer' appears in /data/app/com.alphero.bach-gJLQhlnFXyfvM_FIorGBAw==/base.apk)
        at com.airbnb.lottie.compose.LottieAnimationStateKt.rememberLottieAnimationState(Unknown Source:7)

The compose docs give a heads up that this will happen - [URL]

[Image: image]

This also happens on the latest snapshot, "com.airbnb.android:lottie-compose:1.0.0-beta04-2-SNAPSHOT"

**Steps To Reproduce**
Steps to reproduce the behavior:

1. Create jetpack compose project using beta07.
2. Add latest lottie dependency 
3. Put `rememberLottieAnimationState()` somewhere in the composition
4. Run app - it will crash when attempting to render that composition
