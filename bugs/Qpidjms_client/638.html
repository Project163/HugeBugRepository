Title

[Qpid JMS AMQP 0-x] An establishment of connection times out if an exception is thrown from ConnectionStartMethoHandler due to unsupported sasl mechanisms

Description
AMQTimeoutException  is reported after waiting for "maximum state wait time", when  QpidException  is thrown from  ConnectionStartMethoHandler  because of unsupported sasl mechanisms. The original exception is reported into  ExceptionListener  if one is configured, but, the application has to wait unnecessary for "maximum state wait time" which is 30 seconds by default.
