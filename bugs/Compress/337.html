Title

OSGi bundle name changed

Description
commons-compress 1.17 had Bundle-SymbolicName `org.apache.commons.compress`.  This changed in 1.18 where it became `org.apache.commons.commons-compress`.
Discussion
- Most likely we've inherited a change of Commons' parent POM and didn't notice. 

 I'm not really sure how to deal with this now, though. If we change it back for 1.20 then people who have adjusted to (or even started using compress with) 1.18 or 1.19 will need to adjust again. 

 The best thing we probably can do is to record this as a known issue and stick with the new name - making sure it won't change again without us noticing.
- [URL] will hopefully ensure this doesn't happen again, but we still need to decide how to deal with it for the 1.20 release.
