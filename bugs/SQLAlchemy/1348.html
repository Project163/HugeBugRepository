Title

declarative cols that have explicit name get placed at the top of the cols list above other attrs, within the mapper only, not the table which is OK

Description
Introduction:
I have used 
df1 = pd.read_sql_query(session.query(TableClass), con)  
and
df2 = pd.read_sql_query('select * from table_name', con)
then I got 2 df with the same data but the first has disordered columns.
For this reason, I start to find the issue.


Main Part:
Later I found that session.query (TableClass) is the matter, its SQL statements have disordered columns.
e.g. for a table with A, B, C, and D 4 columns. With 

query = session.query(TableClass)
stmt = query.statement
print(stmt.compile(con))

we can find in the terminal a SQL sentence like "Select C, D, A, B from `table_name`"
