Title

cassandra-stress doesn't report correctly when profile file is not found

Description
Right now, when there is an error in the profile file name cassandra-stress reports very not understandable error "URI is not absolute" instead of reporting something like "File doesn't exist" or something like. 

 It would be very helpful to improve user experience by reporting correct reason for error.
