Title

bake model QuestionsTags says "Bake cannot generate associations for composite primary keys at this time." but the table is generated correctly

Description
Questions belongsToMany Tags

Doing a Console/cake bake model QuestionsTags is generating this initialize method:

```
    public function initialize(array $config) {
    $this->table('questions_tags');
    $this->displayField('question_id');
    $this->primaryKey(['question_id', 'tag_id']);
}
```

but also saying "Bake cannot generate associations for composite primary keys at this time."

Looks like this message was left behind?
Discussion
- Accidentally pushed to 3.0, there is no pull request but there is a fix!!
- The primary composite key is generated correctly, but any foreign keys referencing this composite key, will not be generated correctly if using bake.
