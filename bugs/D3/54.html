Title

d3.selection() should select the document element, not the document.

Description
Currently `d3.selection()` is equivalent to `d3.select(document)`, but it should instead be equivalent to `d3.select(document.documentElement)` for consistency with the default group parent node returned by d3.select. (Also, it is [Link: documented] to return the document element.)
