Title

MultiProxy Logging Discrepancy

Description
Just noticed a minor logging issue with the new multiproxy functionality:
```
7730 [ZAP-BootstrapGUI] INFO org.zaproxy.zap.extension.proxies.ExtensionProxies  - Starting alt proxy server: localhost:8081
.....
23174 [Thread-9] INFO org.zaproxy.zap.extension.proxies.ExtensionProxies  - Stopping alt proxy server: localhost:8080
```

First there's no logging of the main proxy starting. Then at shutdown there main proxy is referred to as an alt and there's no logging for the actual alt.
