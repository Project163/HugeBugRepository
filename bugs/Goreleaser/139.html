Title

config unmarshal error on []config.Blob

Description
**Describe the bug**

When trying to use the blob storage option in the .goreleaser.yml file an error is thrown stating the following

➜ goreleaser release

   • releasing using goreleaser 0.113.1...
   • loading config file       file=.goreleaser.yml
   ⨯ release failed after 0.00s error=yaml: unmarshal errors:
  line 52: cannot unmarshal !!map into []config.Blob

**To Reproduce**

Download goreleaser release for commit :  
or install version 0.113.1 through brew. 

create .goreleaser.yml file with a blob: field.
run goreleaser release.

```
yaml
# This is an example goreleaser.yaml file with some sane defaults.
# Make sure to check the documentation at [URL]
before:
  hooks:
... [Log Snipped] ...
    - '^docs:'
    - '^test:'
```

**Expected behavior**

goreleaser creates the release and uploads the artifacts to blob storage.

**Environment (please complete the following information):**

- OS: Mac
- OS version: Darwin pepaul01551 16.7.0 Darwin Kernel Version 16.7.0: Tue Jan 30 11:27:06 PST 2018; root:xnu-3789.73.11~1/RELEASE_X86_64 x86_64
- GoReleaser Version version: 0.113.1 commit:   built at: 2019-08-01T11:37:16Z built by: goreleaser

Discussion
- `blob` is a list, so you need to change it to:

```yaml

blob:
- provider: azblob
   bucket: splunkclient
   folder: artifacts/"{{ .Version }}"
```

I'll rename this to `blobs` instead. Thanks for reporting it btw :)
