Title

Overlapping overload checks don't know about union types

Description
Code like this should be valid, since the union types can't be overlapping:

```
from typing import overload, Union, List
@overload
def f(x: Union[int, str]) -> int: return 0
@overload
def f(x: Union[bytes, List[int]]) -> str: return 'x'
```

The type checker thinks that these overlap:

```
t.py, line 3: Overloaded function signatures 1 and 2 overlap with incompatible return types
```

However, this should fail, since both unions have the `int` item:

```
from typing import overload, Union, List
@overload
def f(x: Union[int, str]) -> int: return 0
@overload
def f(x: Union[bytes, int]) -> str: return 'x'
```
