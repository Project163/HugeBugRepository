Title

Using :Explore in one window and clicking back in another tries to open the line as a file

Description
Sorry about the length of the title (and its ambiguity). Basically, if you use netrw in one window with `mouse=a` and then you click back in the other window, neovim attempts to open the contents of the line in the newly-clicked window as a path (but only if the contents match a certain pattern?)

```
neovim -u NORC /usr/share/dict/words
i
build .cache/themes_md5sum: md5sum bower_components/prism/themes | bower_components
#make sure there is no trailing new line, i.e. the cursor is on the same line as the text that was just entered
```
