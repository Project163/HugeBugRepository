Title

Nested describe failed when the alias is not referred in the first foreach inner plan

Description

B = group A by name;
C = foreach B {
    D = distinct A.age;
    generate group, COUNT(D);
}
describe C::D;
 
  

 If we remove group from generate statement, then it works
