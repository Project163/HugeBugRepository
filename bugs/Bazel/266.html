Title

bazel does not enforce testonly

Description
Consider this BUILD file:

```
filegroup(
  name = 'foo',
  testonly = True,
)
filegroup(
  name = 'bar',
  srcs = [':foo'],
)
```

I would expect building `:bar` to not work because it is a non-testonly rule that depends on a testonly one. However, bazel is more than happy to build `:bar`:

```
$ bazel build :bar
INFO: Found 1 target...
Target //:bar up-to-date (nothing to build)
INFO: Elapsed time: 0.387s, Critical Path: 0.00s
```
