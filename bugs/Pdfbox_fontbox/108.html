Description

Discussion
- Some type1 fonts have "noaccess ND" instead of "noaccess def". (ND is shortcut for "noaccess def") 

 The fix is rather simple, e.g. insert  
  
          if  (token.getText().equals( "def" ))
        {
             return ;
        }
 
  
 before the line with the exception in type1parser. However there may be something else that is wrong with that font. At the bottom, "Wenn" is rendered as "W   enn".
