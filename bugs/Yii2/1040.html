Title

Action parameter binding potentially breaking, if omitting optional parameters.

Description
### What steps will reproduce the problem?
Have an action with two parameters, one with type `?int` and the other with type `?string`, both with default values.
`public function actionTest(?int $num = 5, ?string $str = 'ok') { ... }`

Run the action, providing only the `str` parameter.


### What is the expected result?

Action runs without any problems.
