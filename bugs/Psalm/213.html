Title

Second call to templated method fails to resolve type parameter

Description
[URL]
```
php
 map(function(Item $i): Item { return $i;}));
  takesCollectionOfItems($c->map(function(Item $i): Item { return $i;}));
```
Here, second call to `takesCollectionOfItems()` fails because psalm thinks the result of `map` is literal `ArrayCollection `, where `T` should have been actually resolved to `Item`. First call works fine.
