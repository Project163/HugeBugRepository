Title

getServiceReferences() should not return an empty array

Description
When using the (still experimental) filter indices, under certain circumstances you can get an index out of bounds exception in the ServiceDependencyImpl.lookupService() method. The cause is an empty array being returned by BundleContext.getServiceReferences(). The spec states the method should return null in these cases in stead. The problem is in the filter index, which intercepts the bundle context, but does not special case for this, simply returning empty arrays if there were no references (or none were assignable).
