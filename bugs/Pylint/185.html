Title

Spurious unused-variable warning when function-scoped class is used only as metaclass

Description
### Code that reproduces the error:
```
def func_scope():
    class Meta(type):
        pass
    class Class(metaclass=Meta):
        pass
    return Class
```

### Current behavior
Generates a warning: `W:  2, 4: Unused variable 'Meta' (unused-variable)`
(And various valid complaints, mostly about docstrings.)

### Expected behavior
The warning should not be generated.
