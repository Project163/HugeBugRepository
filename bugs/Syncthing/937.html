Title

Xattrs not properly applied to directories, causes rescan/resync loop

Description
Syncthing *thinks* it should apply xattrs to directories, but it doesn't. That results in the next scan picking up the absence of xattrs as a change which gets sent out. The other side "applies" that change (it doesn't, since it doesn't set xattrs), then the next scan it rediscovers the xattrs. Etc.
