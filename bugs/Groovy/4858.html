Title

SC: variable initialized to null and assigned primitive value in loop

Description
Consider the following: 
  
 
@CompileStatic
void test() {
   def  foo =  null   // GroovyCastException: Cannot cast object  ' null '  with class  ' null '  to class  ' int ' 
    for  ( int  i = 0; i < 1; i += 1) {
    foo = i
  }
  print foo
}

test()
 
  

 STC works out the type of "foo" to be  int  and so the initialization to  null  produces a cast exception.
