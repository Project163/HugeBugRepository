Title

@NameBinding not working for ServerResponseFilter

Description
### Describe the bug

A ServerResponseFilter is always executed even when it is constrained by a `@NameBinding` annotation and the annotation is not used. 

In this [Link: example], the annotation alters the response context status code. However, the annotation is not used in the resource, yet the status code changes. 

### Expected behavior

The response filter should not be applied since the @NameBinding annotation is not used.

### Actual behavior

The filter is applied.
