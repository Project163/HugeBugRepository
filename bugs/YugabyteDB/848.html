Title

[DocDB] [xCluster] Drop database allows to drop the database if it is part of replication.

Description
Jira Link: [Link: DB-3861]
### Description

If user tries to delete the database(which is part of replication) it allows to delete the database.

Expected:
It should block the user to drop the database if it is part of replication. It should allow user to drop it only once the user deletes the existing replication.
