Title

FileStreamSource: maxCachedFiles set to 0 causes empty batches

Description
While testing changes from  [URL] it was discovered that setting  maxCachedFiles  to 0 to try to force each batch to perform a full listing was inadvertently causing every other batch to trigger with no files being processed.   

 In this case, the list of  unselectedFiles  from a file listing gets 0 files taken from it and assigned to  unreadFiles  as an empty list, which is re-used in the next batch and only checked if  unreadFiles  is null.
