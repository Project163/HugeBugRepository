Title

Multiple traces in Native mode instead of one trace with multiple spans like in JVM mode

Description
We see multiple traces in Native mode instead of one trace with multiple spans like in JVM mode. Using Quarkus 1.7.0.Final, GraalVM 20.1 JDK11 based.
This issue was Identified using [URL] I created a standalone application which doesn't need OpenShift cluster - [URL]

The expected behavior for Native mode is to see the same behavior as in JVM mode, just one trace with multiple spans.
@Ladicek indicated that it sounds like context propagation not working

### Steps to reproduce:
Terminal 1
```
docker run -p 5775:5775/udp -p 6831:6831/udp -p 6832:6832/udp -p 5778:5778 -p 16686:16686 -p 14268:14268 jaegertracing/all-in-one:latest
```

Terminal 2
```
git clone [URL]
cd tracing-sample

sdk use java 20.1.0.r11-grl && export GRAALVM_HOME=$JAVA_HOME
mvn verify -Dnative
```
