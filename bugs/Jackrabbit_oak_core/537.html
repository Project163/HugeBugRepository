Title

Node#isModified returns true if node has non-readable child

Description
issue reported by  tripod  at  [URL]

 i created a test where a node contains access control content which restricts access to a given child node -> the parent node is marked as modified for the test session that is not allowed to see the child.
Discussion

- quickly debugged one of the test cases: the problem seems indeed to be caused by MutableTree#isModified() as  mduerig  suspected. 
this method compares the original base (NodeState obtained from the NodeStore) with the nodeBuilder, which is a SecureNodeBuilder. This obviously will find differences if there are child nodes or properties that are not accessible... it might even wrongly return true if there are hidden items that are filtered out by one or the other.
