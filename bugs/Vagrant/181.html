Title

vagrant box outdated --global doesn't check provider specific versions

Description
Vagrant is reporting that I have an outdated box. When I try to update it says that I am running the latest version. There is a new version but it is for a different provider. 

Box in question:
[URL]

Provider I am using:
virtualbox

### Vagrant version
Vagrant 2.2.6

### Host operating system
MacOS 10.14.6 Mojave

### Guest operating system
Centos-7 via virtualbox

### Debug output
[URL]
Two files are in the gist, one for the outdated command, one for the update command.

### Expected behavior
```
$ vagrant box outdated --global
* 'bento/centos-7' for 'virtualbox' (v201910.20.1) is up to date
``` 

### Actual behavior
```
$ vagrant box outdated --global
* 'bento/centos-7' for 'virtualbox' is outdated! Current: 201910.20.1. Latest: 201910.21.0
``` 
Then if you try to update the box via `vagrant box update bento/centos-7` the response is
```
Checking for updates to 'bento/centos-7'
Latest installed version: 201910.20.1
Version constraints: > 201910.20.1
Provider: virtualbox
Box 'bento/centos-7' (v201910.20.1) is running the latest version.
```

### Steps to reproduce
1. `vagrant box add bento/centos-7`
2. `vagrant box outdated --global`
3. `vagrant box update --box bento/centos-7`
4. `vagrant box outdated --global`
