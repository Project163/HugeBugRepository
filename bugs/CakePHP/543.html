Title

Model conditions array with one element

Description
There is a problem with generating the SQL query where an array with one element is present within the conditions. The example follows:

``` php
$databases = array('A', 'B');
$this->Model->find('list', array('conditions' => array('database' => $databases)));
```

passes fine and the condition is properly translated into:

``` sql
SELECT ... WHERE database IN ('A', 'B');
```

But when the passed array contains only one element, the SQL is translated incorrectly:

``` php
$databases = array('A');
$this->Model->find('list', array('conditions' => array('database' => $databases)));
```

``` sql
SELECT ... WHERE database=('A');
```

rather than

``` sql
SELECT ... WHERE database IN ('A');
```

This throws an SQL incorrect syntax error. The environment being tested is XAMPP with PHP 5.4.19, MySQL 5.5.32 and CakePHP 2.5.4.
