Title

Filter equality does not work for tuples

Description
From the documentation I understand that it should be possible to  filter a relation based on the equality of tuples.  [URL] ,  [URL]

  However with this data file 

 – indext.txt: 
(1,one) (1,ONE) 
(2,two) (22, twentytwo) 
(3,three)       (3,three) 

 I run this pig script: 
A = LOAD 'indext.txt' AS (t1:(a:int, b:chararray), t2:(a:int, b:chararray)); B = FILTER A BY t1==t2; DUMP B; 
Expecting the output: 
((3,three),(3,three))

 (both equal to and not equal to). I do not make tuple and map supported in  GreaterThanExpr and LessThanExpr. Because I think the comparison meaning in less than and greater than is not clear for tuple and map.
