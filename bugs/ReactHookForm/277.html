Title

`setState` does not update input if `reset` was called before

Description
**Describe the bug**
Since v7.10.0, `setState` does not update the related inputs that are controlled by a controller, but only if `reset` was called before. This issue is slightly different from [URL] but probably related.

**To Reproduce**
Steps to reproduce the behavior:

1. Form "resets" the field `name` to `"initial"` after 500msec delay
2. Click "setValue" button
3. Input is **not** updated
4. Submit the form once: logs correct value `"abc"`

**Codesandbox link (Required)**
[URL]

**Expected behavior**
Step 3: Input should be updated to show correct value `abc`.
Everything works as expected in v7.9.0 (switch between versions in the Codesandbox above). It seems this broke with v7.10.0.
Everything works as expected in v7.10.2-beta.0, but only if `reset` is never called.

**Desktop (please complete the following information):**

- OS: macOS 10.15
- Browser: Firefox, Safari, Chrome -- all the same.
- Version: 89, 14, latest
