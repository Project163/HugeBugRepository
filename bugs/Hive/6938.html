Title

Keytab URI for LLAP YARN Service is restrictive to support HDFS only

Description
llap-server/src/main/resources/package.py restricts the keytab URI to support HDFS only and hence fails for other FileSystem API conforming FSs like s3a, wasb, gs, etc.
