Title

Loading time when network is offline due to npm, helium installation

Description
As of 0.7.0, Zeppelin  

 
	 installs nodejs and npm 
	 downloads helium JSON file 
 

 so it cause larger loading time when  

 
	 network is offline and 
	 at least one helium bundle is enabled

     First set with  
    `String npmCommand = "install —loglevel=error”;` 
    and You don’t connect any ethernet or wireless internet. 
    build & run 

     and set with 
    `String npmCommand = "install —fetch-retries=2 —fetch-retry-factor=1 —fetch-retry-mintimeout=5000 —loglevel=error”;` 
    also don’t connect any networks, build & run. 

     WHY 
    retries = 2 
    factor = 1 
    mintimeout = 5(sec)? 

     npm use  [retry] ( [URL] module to retry. 
    It refers  [this article] ( [URL] for retry algorithms. 
    It is a math which structured  Math.min(Math.round(random * minTimeout * Math.pow(factor, attempt)), maxTimeout) . 

     So before, zeppelin use npm's default setting 
    random = False = 1 
    retry = 2 
    minTimeout = 10(sec) 
    maxTimeout = 60(sec)
