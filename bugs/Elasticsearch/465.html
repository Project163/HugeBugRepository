Title

Partial fields filtering may return false matches and doesn't allow selecting complete objects

Description
To reproduce:

```
curl -XPUT "[URL] -d'
{
   "field": "value",
   "array" : [ 1 , 2],
   "obj" : {
       "field": "value"
   }
}'
```

Then search:

```
curl -XPOST "[URL] -d'
{
  "partial_fields": {
     "obj_selection": {
        "include": [ "obj" ]
... [Log Snipped] ...
  }
}'
```

Results in:

```
{
  ...
   "hits": {
      "total": 1,
      "max_score": 1,
... [Log Snipped] ...
   }
}
```
