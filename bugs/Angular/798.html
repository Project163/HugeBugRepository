Title

Redirect to root url does not work when returning UrlTree from guard

Description
# 🐞 bug report

### Affected Package
 
  The issue is caused by package @angular/router


### Is this a regression?

 
   No.


### Description

 
I use a guard to protect a route. If the user is not allowed to access the route I'd like to redirect to the root url. I'm doing this by returning an UrlTree from the canActivate method. To get the UrlTree for the root url I'm calling router.parseUrl('/'). However when I navigate to the protected page the redirect to the root url does not happen. The protected page isn't displayed either and there are no errors in the console.

If I change the guard to return router.parseUrl('/unauthorized') the redirect to the unauthorized page works as expected. I think this should also work for the root url. Am I missing something or is this a bug?
