Title

2.0: Mapping generics with typing.Annotated does not work if "from __future__ import annotations" is included

Description
### Describe the bug

When `from __future__ import annotation` is included, then it's not possible to map generic collections to SQL types.
Mapping process throws the exception. If we change `list[X]` to `list`, then it works, but won't be fully correct from typing point of view.
My use case is I'm trying to map `list[str]` or `Sequence[str]` or `Sequence[SomeEnum]` to `JSONB` field in PostgreSQL, resulting in JSON array stored in this field.

### To Reproduce

```
python
from __future__ import annotations
from typing import Annotated
from sqlalchemy.orm import DeclarativeBase, registry, Mapped, mapped_column
from sqlalchemy.dialects.postgresql import JSONB
... [Log Snipped] ...
```
