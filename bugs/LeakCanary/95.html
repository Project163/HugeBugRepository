Title

Heap Dump render appears semi-transparent on Android 12

Description
### Description

On Android 12, the Heap Dump render is buggy.
The legend _leaks_ through the "pixel" records (see screenshots below) and the colors feels washed-out.

After some digging, it appears that since Android 12, the `ANTI_ALIAS_FLAG` is set by default on the `Paint()` default constructor [Link: 🔗]).


This explains why drawing points would lead anti-aliasing to blend the individual pixels with the background.

Also, I'd like to point out that directly setting the pixels on the bitmap instance would prevent this issue altogether: `bitmap.setPixel(x, y, recordPositions[recordIndex].first)`.
Tell me which option you prefer, it might be slightly more efficient to directly modify the Bitmap.
