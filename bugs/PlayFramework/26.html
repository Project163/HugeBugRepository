Title

[2.4.0-RC3] Bug: Global.onRequest(request, actionMethod) not called anymore

Description
For a quick a test:

```
java
public class Global extends GlobalSettings {

    @Override
    public Action onRequest(Request request, Method actionMethod) {
... [Log Snipped] ...
    }
}
```

It seems the `onRequest` never gets called (It does not matter if you use `InjectedRoutesGenerator` or not).
Discussion
- What's your configuration for `play.http.requestHandler`? I think the default setup for a Java application is meant to use [Link: `GlobalSettingsHttpRequestHandler`] which calls `GlobalSettings.onRequest`. But I'm a bit confused by the logic in [Link: `HttpRequestHandler`] so I'm not sure whether there's a bug or not.
- Problem is, it was attempting to cast `play.api.GlobalSettings` to `play.GlobalSettings`, which is never the case, rather if it's a Java `GlobalSettings`, then it will be `JavaGlobalSettingsAdapter`.
