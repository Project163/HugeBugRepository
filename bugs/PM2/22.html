Title

pm2 restart sets watching to active

Description
If reporting a bug, please use the following template.
#### Expected behaviour

Not to enable the watch mode as the json config file has 'watch' : false set!
#### Actual behaviour

Watch mode is activated even though in json config file it is deactivated and when starting the app it then also not activated (nor did we enable it after start)!
When restarting using just the appname (pm2 restart TLDINFO), won't activate the watch mode.
#### Steps to reproduce

Have a json config file where watch: false is set as option. Here our example file:

```
{
  "apps": [{
    "name": "TLDINFO",
    "script": "app.js",
    "error_file": "/var/log/frontend/TLDINFO/err.log",
... [Log Snipped] ...
  }]
}
```

pm2 start  
pm2 restart  
#### Software versions used

```
OS         : Debian GNU/Linux 8
node.js    : 4.4.7
PM2        : 2.0.4 (development branch and also pm2@next are affected!)
```
