Title

Async apply ready introduces snapshot inconsistent issue.

Description
We just introduced async apply feature to avoid blocking raft node's progress.

However we apply entries in one routine [URL] and generate merged snapshot in another routine [URL]

Then we might end up with doing a snapshot and applying entries concurrently. This is bad since it can lead to inconsistent snapshot. A simple fix would be merge the apply routine back to the server routine but still keep the buffering logic.
