Title

Fails to shutdown when using grpc and kafka-streams extensions

Description
### Describe the bug

If we have a project with quarkus-grpc (grpc server) and quarkus-kafka-streams, it will fail and hang when shutting down:

```
ERROR [io.qua.ver.cor.run.VertxCoreRecorder] (vert.x-eventloop-thread-0) Uncaught exception received by Vert.x [Error Occurred After Shutdown]: java.util.concurrent.RejectedExecutionException
        at org.jboss.threads.RejectingExecutor.execute(RejectingExecutor.java:20)
        at org.jboss.threads.EnhancedQueueExecutor.rejectShutdown(EnhancedQueueExecutor.java:2119)
        at org.jboss.threads.EnhancedQueueExecutor.execute(EnhancedQueueExecutor.java:801)
        at io.vertx.core.impl.TaskQueue.execute(TaskQueue.java:149)
... [Log Snipped] ...
                at org.jboss.threads.EnhancedQueueExecutor.rejectShutdown(EnhancedQueueExecutor.java:2121)
                ... 19 more
```

This happens when running tests, or a production build. Does not happen in dev mode.

### Expected behavior

Should shutdown graceful

### Actual behavior

Erros is logged and shutdown hangs.
