Title

Reverse Proxy Authentication Without Session Causing Internal Server Error

Description
- Gitea version (or commit ref): 1.15.0+dev-361-ga9daebca2

## Description

Steps to reproduce:
1. Fresh install Gitea using docker, configure with an admin user
2. Configure reverse proxy to pass `Remote-User` and `Remote-Email` headers
3. Add/change the following in app.ini

```
[session]
# session is cleared when restart
PROVIDER = memory

[security]
... [Log Snipped] ...
ENABLE_REVERSE_PROXY_AUTHENTICATION    = true
ENABLE_REVERSE_PROXY_AUTO_REGISTRATION = false
```
4. Restart Gitea.
5. Internal server error when try to load any page.

I briefy checked the codes, seems to be cause by the below lines:
[URL]

My guess is: when using reverse proxy authentication, and there is no session, `sess.Get("uid")` will be `nil`, causing this error.
