Title

Fix components' version information in the web page 'About the Cluster'

Description
In the web page 'About the Cluster', YARN's component's build version(e.g. ResourceManager) is the same as Hadoop version now. It is caused by   calling getVersion() instead of _getVersion() in VersionInfo.java by mistake.
