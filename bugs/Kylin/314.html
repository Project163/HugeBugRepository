Title

Add a write lock when merging v3 dict

Description

    
Discussion

    
- Root Cause 

 Two incremental dictionaries are generated based on the same existing dictionary, and then the dictionaries are merged without checking, resulting in dictionary problems.
- Design 

 Generate an incremental dictionary based on the snapshot version of an existing dictionary, and record that version. 

 When merging the dictionary, compare the version of the existing dictionary with the one just recorded, 
 
	 if they are inconsistent, revoke this step and retry, 
	 if they are consistent, merge the dictionary normally.
