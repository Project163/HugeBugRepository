Title

Nested useFieldArray elements seem to keep default values after reset is called

Description
**Describe the bug**
If default data is set and an attempt to reset data with a new value. useFieldArray seems to return the defaulted value rather than the reset one

**To Reproduce**

1. create a form with nested useFieldArrays with a defaultValue set
2. At the form root create a useEffect and a setTimeout to set the default data via reset.
3. You still see the original defaulted value

**Codesandbox link (Required)**
[URL]

**Expected behavior**
useFieldArray value should be the new value not the default

**Desktop (please complete the following information):**

OS: Mac (Mojave 10.14.6)
Browser: Chrome
Version: 84
