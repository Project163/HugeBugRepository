## Current behavior
 
When ChildService ( which is extended from ParentService) is being passed to Component for DI. Then, it is being resolved to ParentService instead of ChildService. 


## Expected behavior
 
ChildService should be resolved to ChildService NOT ParentService

## Minimal reproduction of the problem with instructions
 
Steps:
1) Create ParentService (providedIn: root)
2) Create ChildService (providedIn: root)
3) Inject in AppComponent
4) console.log(childService instance of ChildService) // false which should be true
