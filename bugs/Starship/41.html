This needs to be a `&&`, not a `||`, at least for the purposes of fixing my config.

However, `Context::detect_env_vars` is actually fundamentally insufficient for expression the logic described in the username module. This is because the function's return value *cannot* differentiate between "A negated variable is set" and "No non-negated variables are set".

This means `detect_env_vars` actually overrules all other detection mechanisms, instead of adding to them and only overruling if a negated variable was found.

I can try to make a PR for this but given that this affects in principle almost every single module I may just add an extra method to `Context`.
