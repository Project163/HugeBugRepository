Title

scope to: 'controller#action' does not work

Description
### Steps to reproduce
- In routes.rb add:

```
scope to: 'some_controller#some_action' do
    get 'some_path'
    put 'some_other_path'
end
```
- Start rails server
### Expected behavior

Both `some_path` and `some_other_path` should have been routed to `some_controller#some_action`
### Actual behavior

This is happening because of this commit: 97d7dc48d

Previously, `options` was first [Link: merged with `scope[:options]`] and then `@to` was set with:

```
@to  = options.delete :to
```

but now `to` is [Link: set in `process_path`] method (which happens before  `scope[:options]` is merged) and passed as params. Thus `Mapping` does not know about `to` option passed with scope.

`via`, `format` and `anchor` would have the same fate but `via` and `format` are saved by `options.delete(:key) { @scope[:key] }` and `anchor` uses `options.delete(:anchor) { true }`. Shouldn't all of them have the same behavior?
