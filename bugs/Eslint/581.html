Title

Apply both "arrow-spacing" and "space-before-blocks"

Description
I'm using eslint 1.4.1, when I define these two rules as below:

"space-before-blocks": 0,
"arrow-spacing": 2

It looks like the first rult overwrites the 2nd, so:

```
let done = () => { // fails (1)
  // ...
}

if(isResolved){ // pass (2)
  done();
}
```

Ideal: it should accept the case 1 as correct because the the second rule is being applied.
