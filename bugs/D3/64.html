Title

Time axes for BC dates

Description
D3's time axes appear to have some issues with BC dates.
1. Low BC dates are given odd year tick labels. For example, 80BC is "0-80" and 8BC is "00-8". This is easy to work around and is presumably because d3_time_formatPad pads without reference to the sign.
2. There is a year zero inserted between 1BC and 1AD. I haven't been able to work out how to remove it, either as a work around or in the d3 code.

Screenshot from a timeline based on [URL] :
[Image: d3timeaxisbcdates]
Discussion
- The format padding fix is implemented in 8dce4f0.

As for year zero, that is working on intended. I don’t plan on implementing Anno Domini year numbering. If you are so inclined, you can do that by implementing a custom tick format for the axis, such as:

``` js
function yearFormat(date) {
  var year = date.getFullYear();
  return year <= 0 ? 1 - year + "BC" : year + "AD";
}
```
- Ah, thanks! For some reason I had been assuming that n BC must be -n. 1-n makes more sense.
- Fix merged into #1285 for 3.2.
