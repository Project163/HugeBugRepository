Title

Built in Exceptions

Description
Created by **kennethfrey (at gmail)**, 25th Oct 2011. _(originally [Link: Lighthouse ticket #2160])_:

---
#### What I did

Threw a new NotFoundException('My error message.')
#### What happened

The built in exception renderer used the 400.ctp template.
#### What I expected to happen

This actually behaves is expected after reading the cookbook and looking into the ExceptionRenderer class. I think any of the built in exceptions should be able to render in it's own template. All the built in cake exceptions use their own template. All the built in status codes should also use their own template: 400,403,404,405, and 500. Instead all codes below 500 use the 400 template.

If you have a file (404.ctp) in your app's Views->Errors directory and throw a NotFoundException it should render the 404.ctp template. I don't think you should have to create your own exception renderer class to use a different template for the built in exceptions.
