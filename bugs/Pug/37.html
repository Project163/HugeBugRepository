Title

Allow duplicate block in layout

Description
Hi,

I can't manage to make Pug works correctly for my use case.
I develop a website where a page can be loaded **completely or partially** (content only, for a Ajax changing page).

I think something like this should works : 

```
// page.pug
block content
  p Hello
```

```
// layout.pug
if (ajax)
  block content
else
  html 
... [Log Snipped] ...
      ...
      block content
```

But it don't work. Maybe because the double "block content".

---

Currently I'm using this ugly workaround : 

```
// page.pug
block content
  block contentAjax
    p Hello
```

```
// layout.pug
if (ajax)
  block contentAjax
else
  html 
... [Log Snipped] ...
      ...
      block content
```

Do you think this should be fixed too ?

```
// page.pug
mixin content()
  p Hello
```

```
// layout.pug
include page.pug
if (ajax)
  +content()
```
