Title

SQLAlchemy 1.2.10 support for over() with range_ or rows is broken.

Description
**Migrated issue, originally created by Juan Jesús García de Soria ([Link: @skandalfo])**

Found this by trying to use the feature with GINO and PostgreSQL.

While the feature is supposedly supported, the proxy functions in classes in sql/elements.py don't support the new arguments.

See, for example:

[URL]

The result of trying to use, for instance, range_=(None, 0) in a call to over() for a window function in a select is Python complaining that over() got an unexpected keyword argument.
