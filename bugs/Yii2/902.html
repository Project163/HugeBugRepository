Title

FileValidator incorrectly validate mimetype with uppercase letter

Description
### What steps will reproduce the problem?

1. Use FileValidator to validate file uploaded
2. Add rule to validate a mimetype that not all lowercase (example in my case, I uploaded a csv that somehow returned `text/x-Algol68` mimetype, so I add `text/x-Algol68` to my rule)
3. Upload a file with that mimetype 

### What is the expected result?
Validate is success

### What do you get instead?
Validate is failed
