Title

NPE while starting an application with @Incoming method

Description
When an application contains method annotated with `@Incoming` method to read Kafka topic the application fails to start with stacktrace
```
2019-04-25 06:32:07,760 ERROR [io.sma.rea.mes.imp.LegacyConfiguredStreamFactory] (main) Unable to create the publisher or subscriber during initialization: java.lang.NullPointerException
	at io.vertx.reactivex.kafka.client.consumer.KafkaConsumer.create(KafkaConsumer.java:131)
	at io.smallrye.reactive.messaging.kafka.KafkaSource. (KafkaSource.java:37)
	at io.smallrye.reactive.messaging.kafka.KafkaMessagingProvider.getPublisherBuilder(KafkaMessagingProvider.java:40)
	at io.smallrye.reactive.messaging.kafka.KafkaMessagingProvider_ClientProxy.getPublisherBuilder(Unknown Source)
... [Log Snipped] ...
	at io.quarkus.runtime.Application.run(Application.java:206)
	at io.quarkus.runner.GeneratedMain.main(Unknown Source)
```
If the dependency
```
     
       io.quarkus 
       quarkus-resteasy 
     
```
is added even if RESTeasy is not used then the NPE disappears and app starts correctly.

Looking at the code it seems that vert.x instance is not `@Inject`ed at time when Kafka consumer is initialized.
