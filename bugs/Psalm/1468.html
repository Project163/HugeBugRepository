Title

Psalm should infer that result of multiplication is never an array.

Description
The same goes for all numeric operations, excluding addition.

This example is used to show the types psalm infers

```
php
 |string|false for $x['value']
// Observed:  PossiblyInvalidOperand - src/array.php:5:23 - Cannot add an array to a non-array int
... [Log Snipped] ...
// Expected: Should warn about $result being numeric
fread($result, 1);
```
Discussion
- Afaik this is sufficiently handled by giving the PossiblyInvalidOperand error, which requires you to take action.
Fixing this would not really improve psalm, as you have an error in your code and psalm reports it.
- Yeah, it's not a big priority indeed but this points to a larger issue where operations that are not specifically handled fallback on a absurd value. Also this may cause even more absurd errors down the way that could look as much or more important: [URL]

The developper will get a list of errors but only the first one is relevant in this case
- No, as I said, while it's not a big priority, there's issue with that who should be fixed one day
- Under my changes these lines will no longer trigger additional errors as `$result` will be of type `int|float`

```php
$result2 = $result + 1;
$result3 = $result * 2;
```
