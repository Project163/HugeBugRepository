Title

[YSQL] Buffering causes writes to be missed during procedure calls

Description
Buffering seems to cause writes to be missed during procedure calls - specifically the last write is missed.

Test case:
```
CREATE OR REPLACE PROCEDURE put_test(IN ecx_sps text[])                                              
LANGUAGE plpgsql                                                                                     
AS $$                                                                                                
DECLARE                                                                                              
    val text;                                                                                        
... [Log Snipped] ...
 1 | 1
(3 rows)
```

If I restart tservers with `--ysql_session_max_batch_size=1`, then I don't see this behavior anymore and all the records are inserted correctly as expected.

```
./bin/yb-ctl restart --tserver_flags ysql_session_max_batch_size=1
./bin/ysqlsh
yugabyte=# truncate test;
TRUNCATE TABLE
yugabyte=# select * from test;
... [Log Snipped] ...
 1 | 3
(4 rows)
```
