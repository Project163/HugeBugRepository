Title

`no-multiple-empty-lines` fails on {max: 0}

Description
I personally use comments as separators to force myself to comment all the code I write instead of just leaving blank lines around. Since nearly all editors have some decent syntax highlighting today, this results in pretty clear and re-usable code for me.

Setting `max: 0` should forbid:

``` js
let req = new XMLHttpRequest();

req.open("get", "api/u/online.json", true);
```

but allow this:

``` js
let req = new XMLHttpRequest();
/* Retrieve list of online users */
req.open("GET", "api/u/online.json", true);
```

But instead, this happens:

``` js
0 ✓ kdex@punchy ~/dev/p $ grunt dev
Running "eslint:lint" (eslint) task
Warning: Cannot read property 'length' of undefined Use --force to continue.

Aborted due to warnings.

```

 Could you make `max: 0` behave the way one would expect it to?
