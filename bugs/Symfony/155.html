Title

testReverseTransformDisallowsNaN2 fails on arm64 with ICU 63

Description
**Symfony version(s) affected**: 3.4.18

**Description**  
both tests called testReverseTransformDisallowsNaN2 (i.e. the one in IntegerToLocalizedStringTransformerTest.php and the one in NumberToLocalizedStringTransformerTest.php) failed in the Ubuntu autopkgtests on arm64 when we upgraded to ICU 63, for example see this log: [URL]

**How to reproduce**  
Run the tests on arm64 with ICU 63, e.g in a lxd container for disco.

**Possible Solution**
