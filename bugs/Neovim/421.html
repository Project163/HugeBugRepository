Title

Running `:!cmd` with `noshelltemp` exits neovim on certain binary files (exit code `0`)

Description
### Problem

*With the same file `./randfile_10k.bin`* (see "Steps to reproduce" below), the following outcomes can happen, at random:

1. In most cases, Neovim immediately exits with exit code `0`, after briefly showing the UI for a few milliseconds.
2. In some cases, Neovim prints the error `E5677: Error writing input to shell-command: EFAULT` and does not exit.

### Additional information

- Tested on master.
- It does not seem to matter what command is run with `:!cmd`.
- Not sure, but it seems to me that increasing the size of the random file increases the likelihood of outcome 1 (i.e. nvim immediately exits).
- This worked fine with `neovim 0.10`, i.e. neovim did not exit and no error was shown, ever.

### Steps to reproduce

1. `dd if=/dev/urandom of=./randfile_10k.bin bs=1k count=10`
2. `nvim --clean +'set noshelltemp' +'%!true' ./randfile_10k.bin`

### Expected behavior

The content of `./randfile_10k.bin` is shown.

### Nvim version (nvim -v)

v0.12.0-dev-26+g6ef5dd5266

### Vim (not Nvim) behaves the same?

I don't have vim installed.

### Operating system/version

Archlinux (up-to-date)

### Terminal name/version

foot version: 1.21.0 +pgo +ime +graphemes -assertions

### $TERM environment variable

foot

### Installation

Downloaded current `nvim-linux-x86_64.appimage`.
