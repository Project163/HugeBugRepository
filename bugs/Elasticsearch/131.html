Title

NPE when using "not" filter

Description
I can get a NullPointerException in 0.16.1 using a not filter.  It seems like a similar issue to 892.  

Steps to Reproduce:
curl -XPUT '[URL] -d '{
"user" : "kimchy",
"post_date" : "2009-11-15T14:12:12",
"message" : "trying out Elastic Search"
}'

curl -XGET '[URL] -d '{"query" : { 
  "filtered" : {
    "query" : {"term" : {"user" : "kimchy"}}, 
    "filter" : {
      "and" : [
        {
            "not":{
              "filter":{
                "query":{"wildcard":{"user":"zzz*"}}}
               }
          }
      ]
      }}}}'
