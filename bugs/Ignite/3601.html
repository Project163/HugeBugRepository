Title

High contention for CacheLockImpl causes AssertionErrors

Description
When multiple threads, running on the same client node, compete for CacheLockImpl this leads to AssertionErrors. 

 Pseudo-code snippet, that is called from multiple threads and causes the assertions, looks like this: 

  
 boolean locked = lock.tryLock(100, TimeUnit.MILLISECONDS);
if (locked)
    lock.unlock();
 
  

 Initially the issue was detected on ignite-1.4.
