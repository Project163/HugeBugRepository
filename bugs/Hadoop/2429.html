Title

ZStandardDecompressor native code sets an integer field as a long

Description
Java_org_apache_hadoop_io_compress_zstd_ZStandardDecompressor_init in ZStandardDecompressor.c sets the  remaining  field as a long when it actually is an integer. 

 Kudos to Ben Lau from our HBase team for discovering this issue.
Discussion
- Attaching a patch that changes the setting from a long field to an int field.  Oddly this was done correctly in the Java_org_apache_hadoop_io_compress_zstd_ZStandardDecompressor_inflateBytesDirect function but was wrong in the init function.
- -1 overall
