Title

Incorrect rate metric with larger window size

Description
The Kafka Rate metric gives incorrect rate when the window size is larger say hourly.  

 I suspect the code for calculating rate is incorrect for metrics which are not emitting rate per second or millisecond. The code for time unit calculation seems wrong:  convert(windowSize(config, now), unit)  i.e. the convert code divides the elapsed time in window to the time unit. 

   

 The problem can be easily reporduced by looking at `rebalance-rate-per-hour` metric.
