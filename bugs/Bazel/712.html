Title

Error surfaced when using fail exception in repository_rule is hard to read/locate

Description
In the Envoy build, we `fail` when a `repository_rule` goes bad (https://github.com/lyft/envoy/blob/ /bazel/repositories.bzl#L28). However, while this ends the execution of the `repository_rule`, the build continues and we get a confusing message later in execution, e.g. [URL] where the build relies on an outcome of the `repository_rule` that is missing. The message in the `fail` is not output to the user.

I think the correct behavior would be for Bazel to hard fail the build and print the error.
