Title

Framework reports org.osgi.framework.version as 1.3

Description
Framework version is tested in ServiceTracker line 248 to check if the framework supports ServiceEvent#MODIFIED_ENDMATCH which is needed in some dosgi scenarios to support ListenerHooks. For this to work the version needs to be 1.5.0 or greater, but the constant appears to be hard coded to 1.3 in FelixConstants? 

 A quick hack to change the version to 1.5 enabled the ListenerHook behaviour but unsure if this has wider consequences?
Discussion
- There are no consequences for changing that property value, it was just a miss on my part. We will change it in the next maintenance release. Thanks.
