Title

Dir/symlink updates overwrite conflicts & unscanned files

Description
Checks if files conflict or if the file on disk fits what we have in the database are missing in the functions that handle update directories and symlinks. I did not experience the issue and am not aware of an issues reported due to it. Reason probably is, that it can only occur if the item at a path is changed from a file to a symlink or directory and at the same time this change is a conflicting change or the file on disk was modified and the pull happened before a scan (which nowadays with watching for changes is even more unlikely).
