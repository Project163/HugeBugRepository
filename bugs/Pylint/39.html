Title

Wrong default for dummy variables

Description
Originally reported by: **Mike Müller (BitBucket: [Link: mmueller], GitHub: @mmueller?)**

---

The default for dummy variable produced with _--generate-rcfile_ has a regex that matches to the end of variable name but it should be just the beginning of name, as the help text suggests:

This

```
#!ini

[VARIABLES]

...
... [Log Snipped] ...
# (i.e. not used).
dummy-variables-rgx=_$|dummy
```

should become this:

```
#!ini

dummy-variables-rgx=_|dummy
```

Otherwise the help text needs to be corrected to match the default values and both __|dummy_ would need to become __$|dummy$_ to be consistent.
