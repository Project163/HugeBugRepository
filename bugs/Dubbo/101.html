### Steps to reproduce this issue

1. simple test
```
java
public class NPETest {

    protected WorldHandler handler = new WorldHandler();

... [Log Snipped] ...

```
2. handler is not null in this step
```java
    public ChannelHandlerDispatcher(ChannelHandler... handlers) {
```
