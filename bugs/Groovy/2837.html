Title

Stackable Traits at runtime don't honor definition order

Description
when defined at runtime, stackable traits don't honor the order in withTraits(), whereas when defined statically they do.  see example code: 

  
 trait D { 
        void methodA() { print  "D" ;  super .methodA() } 
} 
trait C { 
        void methodA() { print  "C" ;  super .methodA() } 
} 
trait B { 
        void methodA() { print  "B" ;  super .methodA() } 
} 
trait A { 
        void methodA() { print  "A"  } 
} 

 class  M  implements  A, D, C, B { } 
 class  Q {} 

 class  MyDelegationTest { 

         static  main(args) { 
                
                println "" ;
                
                def m =  new  M() ;

                print  "Static: "  ;

                m.methodA() ;

                println "" ;
                
                def q =  new  Q().withTraits(A,D,C,B) ;

                print  "Dynamic: "  ;

                q.methodA() ;

                println "" ;

        } 
} 
 
  

 With output:  

 (Correct Order) Static: BCDA  

 (Incorrect Order) Dynamic: DCBA
