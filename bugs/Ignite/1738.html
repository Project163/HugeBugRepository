Title

IgniteCache.replace() returns false instead of true when there is only one node

Description
Test attached.
Discussion
- This is issue with enums handling with BinaryMarshaller: when value if prepared to be stored in cache it is handled as 'primitive' type (see CacheObjectBinaryProcessorImpl.marshalToBinary, BinaryUtils.isBinaryType returns 'true' for enum) on the other side after enum value unmarshalling BinaryEnumObjectImpl is created. I think enums always should be handled in the same way, so 'CacheObjectBinaryProcessorImpl.marshalToBinary' should also createBinaryEnumObjectImpl.
- Fixed in master (commit 8be62f0).
