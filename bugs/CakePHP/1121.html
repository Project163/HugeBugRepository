Title

Shadow table groupTranslations return error when row is null

Description
### Description

When you have a query with a contain like:
```
$query->contain(
  'Articles' => function (Query $q) {
          return $q
              ->find('translations');
      },
);
```
But the contain is empty for the particular entity, in the ShadowStrategy it returns an error but with EavStrategy it returns null. The latter is expected in my opinion.

The difference is that in [URL] there is no `if` condition on the `$row` like in [URL] on line 404.

I think adding the same:
```
 if (!$row instanceof EntityInterface) {
      return $row;
  }
```
would solve the issue I have.

### CakePHP Version

4.4.4

### PHP Version

8.1
