Discussion
- Could you try removing the jline dll and jar from your classpath to see what's happening? 
JLine is used for the groovysh shell only.
- You can tell  groovysh  to use the  unsupported  terminal implementation, which will prevent any fancy loading of dlls with: 

  
 groovysh --terminal=none
 
  

 Can you do me a favor please and run this: 

  
 groovysh --debug
 
  

 And then attach the  full  output (in a log file please) this this issue? 

 I will ping Marc (the Jline guy) and see what he has to say.  Might need to include a 64-bit compat .dll.
