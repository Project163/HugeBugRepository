Title

Semicolon as a mixins parameters separator and comma separated list as default value

Description
Semicolon as mixins parameters separator should allow me to use comma inside default values.

Sample input:

```
.mixin(@color; @padding; @margin: 2, 2, 2, 2) {
  margin: @margin;
}
.selector {
  .mixin(#33acfe; 4);
}
```

expected output:

```
.selector {
  margin: 2, 2, 2, 2;
}
```

actual output less.js-1.4.0 downloaded 4.3.2012 (day.month.year):

```
nothing at all
```

actual output less.js-1.3.3:

```
ERROR:
  type: Runtime
  message: No matching definition was found for `.mixin(#33acfe, 4)`
  filename: test.less
  index: 161
  line: 10
  column: 2
  extract: .some .selector div {,  .mixin(#33acfe; 4);,}
```

Note: space as a separator `.mixin(@color; @padding; @margin: 2 2 2 2) { ... }` works fine in both versions,
Discussion
- it is a problem in 1.3.3 too.. seems to be a problem with the definition. confirmed.
- good spot, glad you found it.
