Title

Incorrect check of date field by DateValidator in PHP 8.2RC3

Description
### What steps will reproduce the problem?
Incorrect check of date field by DateValidator

### What is the expected result?
with following rule for validator date filed must be validate correctly

['date', 'date', 'format' => 'php:d-m-Y', 'message' => 'Invalid date format'],

### What do you get instead?
Add check whether $errors variable is of type bool or array in parseDateValuePHP function (approx 445 line)

I fixed it for myself as code below:

if (
	    !empty($errors)
	    && (
		$date === false 
		|| $errors['error_count']
		|| $errors['warning_count']
		|| ($this->strictDateFormat && $date->format($format) !== $value)
	    )
)
{
     return false;
}
