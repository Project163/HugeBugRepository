Title

Snapshots show box model layers of non-displayed elements

Description
If an element is styled `display: none`, the snapshot that includes it still shows the margin and padding of the element, but should not since the margin and padding are not applied to the page.

[Image: display none margin and padding]

In the example above, there are 4 ` ` tags, but one is `display: none`, and when the snapshot is restored, it shows that elements margin in padding in the top left of the viewport. 

We need to take non-displayed elements into account and not show their box model layers with the snapshot.
