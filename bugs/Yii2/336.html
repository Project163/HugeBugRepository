Title

Query with INTERVAL not working + ActiveDataProvider strage behaviour with this query

Description
I have filtering in controller:

```
$searchModel = new TaskMimicSearch();
$query = $searchModel->search(Yii::$app->request->get());

$dataProvider = new ActiveDataProvider([
    'query' => $query
]);

return $this->render('index', ['dataProvider' => $dataProvider]);
```

`$searchModel->search` returns instance of `\yii\db\ActiveQuery` without joins, only with `WHERE` condition (called `andFilterWhere` methods). Here is part of var_dump of $query variable;

```
...
 ["where"]=>
  array(3) {
    [0]=>
    string(3) "and"
... [Log Snipped] ...
  }
...
```

After executing data provider instance have 0 items. I watched DB Log in Yii Debugger and i see that: [URL]
`COUNT(*)` goes **AFTER** `SELECT(*)` _only for this filtering query_.

As you can see on screenshot, the builded sql statement looks like: 

```
SELECT * FROM `tasks` WHERE (`type`='ipoEvent') AND (`finish_at` BETWEEN (NOW() - INTERVAL 1 MONTH) AND NOW()) LIMIT 20
```

This query **works fine then i execute it in PhpMyAdmin**, returns 4 items (copy from Yii Debugger, paste to PhpMyAdmin query window).

I don't understand why this query returns 0 items if there is 4 items satisfying the specified condition and why ActiveDataProvider queries items first and _then_ queries COUNT of items (all other queries without INTERVAL calcalations works fine and ActiveDataProvider does COUNT first, SELECT - after).
Discussion
- If you look at the timestamp of each statement, the SELECT does happen first before COUNT.

Did you try running the COUNT statement via PhpMyAdmin? Try removing your filter conditions and see if it still returns data.

