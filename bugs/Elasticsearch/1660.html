**Description of the problem including expected versus actual behavior**:
In previous versions of elasticsearch, the `_cat/nodes` api accepted the parameter `full_id` to show the full node ID instead of an abbreviated version. It appears that this parameter is no longer accepted in `5.0`, and now returns a `400` response with an error:

```
json
{
  "error": {
    "root_cause": [
      {
... [Log Snipped] ...
  "status": 400
}
```

I'm not very familiar with the codebase, but according to [Link: these lines], this parameter should still exist, correct?

This causes [Link: elasticbeat] to be unable to collect stats on individual nodes and significantly impairs its effectiveness.

**Steps to reproduce**:
 1. Install and start an Elasticsearch `5.0` node
 2. `GET _cat/nodes?full_id=true`
