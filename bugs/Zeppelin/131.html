Title

Autoscroll on key up/down to wrong position of the document

Description
Cursor can move around paragraph by up/down key of keyboard. 
Zeppelin autoscrolls when cursor goes off the screen, but it does not manage autoscroll very well so cursor still stay in outside of screen. 

 I'd like to improve autoscroll behavior, 

 
	 Autoscroll triggers when cursor moves to top/bottom side of the notebook. 
	 Scroll notebook to put cursor in the middle ~ 1/3 of the screen.
