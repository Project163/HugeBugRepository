Title

MRUNIT-180 requires values be comparable

Description
MRUNIT-180   forces all values to be comparable.
Discussion
- The fix might be easy. Instead of using a (element -> index) structure (ie a Map), we could use a (index -> element) structure (ie an array). The complexity of the check will be higher but that shouldn't be noticeable.
- Proposal. The logic has been changed and as a consequence, the messages too. I believe it is from a user experience point of view not worse than before. I have to add the test in order to prevent a future 'comparable' regression but the issue in itself is fixed.
- Update with anti-regression tests (testUncomparable).
