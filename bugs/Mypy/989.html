Title

Conditional `def` not understood as assignment

Description
Under `--strict-optional`, the following yields an error:

```
    f = None  # type: Optional[Callable[[], None]]
    if f is None:
        def f():
            pass
    f()  # error: None not callable
```

If the `def` within the conditional is replaced by `f = lambda: None`, there is no error.
