Title

Composite configuration list variable interpolation return first element only

Description
CompositeConfiguration.getStringArray, with variable interpolation returns only the first element of the list 
e.g. 
key1=a,b,c 
key2=${key1} 

 CompositeConfiguration.getStringArray(key2) = a
Discussion
- Thank you for the report. In order to easier reproduce the problem, could you please post a short code fragment how the composite configuration is created and initialized? Thanks.
- Hi Oliver, 
Here is an exampe code: 
  
 CompositeConfiguration compositeConfiguration =  new  CompositeConfiguration();
compositeConfiguration.addConfiguration( new  PropertiesConfiguration( "props.properties" ));

 String [] values = compositeConfiguration.getStringArray( "key1" );
 System .out.println(values);  //  "a, b, c," 
 values = compositeConfiguration.getStringArray( "key2" );
 System .out.println(values);  //  "a"  
 
  

 with 
   props.properties   
 key1 = a,b,c
key2 = ${key1}
 
  

 I am expecting the get an array "a, b, c" for key2 but I get only "a" 
thanks!
- When testing I found a general problem with interpolation of properties with multiple values. I created   CONFIGURATION-633   for this problem. This has to be fixed first.
- A fix has been applied to SVN. Together with the fix for   CONFIGURATION-633   interpolation should now work for variables referencing properties with multiple values. 

 However, the current implementation is still limited and does not handle all possible constellations. For instance, if elements in the referenced list or array contain variables themselves, those will not be replaced. Let's wait until anybody actually needs this functionality.
