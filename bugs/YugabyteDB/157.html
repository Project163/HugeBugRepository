Title

Handle EX without NX|XX from Jedis client

Description
The proposal is to add a new API to achieve this:
```
public String set(final String key, final String value,
      final String expx, final long time)
```

Currently, only the following method exists in Jedis, and there is no way to pass `EX` only with upsert semantics:
```
public void set(final String key, final String value, final String nxxx, 
      final String expx, final long time) {
```
Discussion
- Closed by commit   (https://github.com/YugaByte/jedis/commit/ )

This commit provides the new API:
`public String set(final String key, final String value, final String expx, final long time)`
