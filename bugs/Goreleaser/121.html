Title

Golang template actions aren't replaced in release.github.owner (environment variables)

Description
### What happened?

I need to replace `release.github.owner` with a template action (`{{ .Env.GITHUB_REPOSITORY_OWNER}}')`)

See [URL]

```yaml
  github:
    owner: "{{ .Env.GITHUB_REPOSITORY_OWNER }}"
    name: junk
```

`export GITHUB_REPOSITORY_OWNER=rfay` and then

```
$ goreleaser release --rm-dist
   • by using this software you agree with its EULA, available at [URL]
   • running goreleaser v1.9.2-pro
  ...
   • publishing
... [Log Snipped] ...
         • release updated           url=
   ⨯ release failed after 0.79s error=scm releases: failed to publish artifacts: POST [URL] 404 Not Found []
```

Note that it's trying to push without replacing the environment variable, so it fails.

This same replacement does in fact work in `brews` and `aurs`.

### How can we reproduce this?

* Check out [URL]
* Change the details as necessary to something you have access to
* `export GITHUB_REPOSITORY_OWNER=you
* `goreleaser release --rm-dist`

```bash
goreleaser version 1.9.2-pro
```
