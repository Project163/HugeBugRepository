Title

MapFrom not applying Null Checking all of the way in 5.0

Description
In  ()
    .ForMember(dest => dest.NameOfFirstBorn, opt => opt.MapFrom(src => src.Family.Children.FirstOrDefault().Name))
    ;
```

If `src.Family` is null, `.FirstOrDefault()` is never called and the destination receives a null.  In 5.0.0, AssertConfigurationIsValid still succeed, but when called with a source object where Family is null, a MappingException is generated with the inner message being `ArgumentNullException` from `FirstOrDefault`.
