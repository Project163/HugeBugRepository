Title

Kotlin live reload dev mode not working when Tika extension is present

Description
**Description**
Live reload raises a RuntimeException: Unable to invoke Kotlin compiler after a code change in dev mode. `mvnw quarkus:dev`
```
`
java.lang.RuntimeException: Unable to invoke Kotlin compiler
	at io.quarkus.kotlin.deployment.KotlinCompilationProvider.compile(KotlinCompilationProvider.java:78)
	at io.quarkus.dev.ClassLoaderCompiler.compile(ClassLoaderCompiler.java:174)
	at io.quarkus.dev.RuntimeUpdatesProcessor.checkForChangedClasses(RuntimeUpdatesProcessor.java:194)
... [Log Snipped] ...
	at io.netty.util.concurrent.FastThreadLocalRunnable.run(FastThreadLocalRunnable.java:30)
	at java.base/java.lang.Thread.run(Thread.java:834)
````

**To Reproduce**
Steps to reproduce the behavior:
1. create a new Quarkus project with Quarkus Maven plugin
````
mvn io.quarkus:quarkus-maven-plugin:1.3.2.Final:create /
    -DprojectGroupId=com.acme /
    -DprojectArtifactId=rest-test /
    -DclassName="com.acme.test.MyResource" /
    -Dpath="api/test" /
    -Dextensions="tika,kotlin,resteasy-jsonb,openapi,health,metrics,container-image-jib"
````
2. run `mvnw quarkus:dev` open [Link] > hello is correctly displayed
3. Change in code main/kotlin/com/acme/test/MyResource "hello" message by "hello world" and go back to [Link]. RunTimeExceptions occurs in the browser

**Environment:**
 - Output of `java -version`: openjdk version "11.0.6" 2020-01-14 OpenJDK Runtime Environment GraalVM CE 20.0.0
 - GraalVM version (if different from Java): 
 - Quarkus version: 1.3.2 final
