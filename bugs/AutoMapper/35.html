Title

Automapper 5.0.0 can map flags enum to nullable flags enum

Description
Automapper 5.0.0 can map this:

```
[Flags]
    public enum MyEnum
    {
        Value1,
        Value2
... [Log Snipped] ...
        public MyEnum? Test { get; set; }
    }
```

The same code worked on 4.2.1
Discussion
- As a workaround I've added

```
                .ForMember(
                    dto => dto.Test,
                    options => options.MapFrom(x => (int)x.Test));
```
