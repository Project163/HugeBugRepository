Title

[Bug] Active field widget validation error with VALIDATION_STATE_ON_INPUT

Description
Because of [Link: this check], `errorCssClass` added to widget input if only `options` passed in config.

### What steps will reproduce the problem?
Add validation rule to model.
Use form with `VALIDATION_STATE_ON_INPUT`.
Add field on form as widget **without config**.
```php
 field($model, 'attribute')->widget(SomeWidget::className()) ?>
```
Submit with error.

### What is the expected result?
Error css class added to input.

### What do you get instead?
Input without error css class.

### Additional info

| Q                | A
| ---------------- | ---
| Yii version      | 2.0.15
| PHP version      | 7.1
| Operating system | Ubuntu 16.04
