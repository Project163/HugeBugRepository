Title

Indent rule VariableDeclarator doesn't apply to arrow functions

Description
Using ESLint `1.3.1` on this code

```
const someFunction = function (argument) {
        console.log(argument);
    },
    someValue = 'someValue';

... [Log Snipped] ...
    someValue
};
```

with this .eslintrc

```
{
    "ecmaFeatures": {
        "arrowFunctions": true,
        "blockBindings": true,
        "modules": true
... [Log Snipped] ...
    }
}
```

outputs

```
  7:9  error  Expected indentation of 4 space characters but found 8  indent
  8:5  error  Expected indentation of 0 space characters but found 4  indent

✖ 2 problems (2 errors, 0 warnings)
```

I expected regular functions and arrow functions to have the same indentation rules.
Discussion
- Looks like an inconsistency.
