Title

[false-positive] Param incorrectly marked as unused

Description
Apologies for not including a psalm.dev link here, I tried a few things but wasn't able to create a self-contained repro of the issue, it *does* however occur on latest master (at time of reporting: 7ded79bb2). I figured it might be best to just file this anyway rather than leaving  the issue unreported—I'll keep trying on finding a minimal PoC and update this if I track down what causes this.

The issue is reproducible locally and [Link: in travis], and is as follows:

```
$ vendor/bin/psalm --find-dead-code

ERROR: PossiblyUnusedParam - src/Parsedown.php:84:55 - Param #2 is never referenced in this method
    public static function blocks(Lines $Lines, State $State)

... [Log Snipped] ...
Psalm was able to infer types for 99.7719% of the codebase
Script vendor/bin/psalm --find-dead-code handling the test-dead-code event returned with error code 1
```

and the method in question looks like:

```
php
    /**
     * @return array{Block[], State}
     */
    public static function blocks(Lines $Lines, State $State)
... [Log Snipped] ...

        // ...
```

where clearly, param 2 (`$State`) has in-fact been used.

You can obtain a copy of the affected codebase by running:

```bash
git clone [URL] \
  && cd parsedown \
  && git checkout 18ee4ff \
  && composer install
```

and reproduce the issue with:

```bash
vendor/bin/psalm --find-dead-code
```
