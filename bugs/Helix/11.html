Title

Panic upon syntax highlighting

Description
### Reproduction steps
1. Open a file with a highlighted language.
2. Type text that should be highlighted.

As soon as text should be highlighted, Helix panics.

Example of one such panic message:

```
thread 'main' panicked at 'called `Result::unwrap()` on an `Err` value: Byte index out of bounds: byte index 6, Rope/RopeSlice byte length 3'
```

  

### Environment

- Platform: macOS
- Helix version: 0.2.0
