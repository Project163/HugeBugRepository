Title

Finding no tests to run for an assembly should be a warning, not an error

Description
When running tests on multiple DLLs msbuild runner is failing:
`xUnit.net MSBuild runner (32-bit .NET 4.0.30319.34014)
    Discovering: System.Collections.Immutable.Tests
    Discovered:  System.Collections.Immutable.Tests
E:\oss\corefx\bin\tools\tests.targets(17,5): error : System.Collections.Immutable.Tests has no tests to run [E:\oss\corefx\bin\tools\fxbuild.proj]`

This is particularly annoying when you are passing IncludeTraits and one of the assembly doesn't have any tests with that particular trait. I rather expected to see nothing or summary with zeros.
