Title

Missing HiveInterpreter configuration at Configuration.java

Description
HiveInterpreter is introduced by   ZEPPELIN-11  . 
But Configuration.java misses it's class name in zeppelin.interpreters property. 

 Result is, without conf/zeppelin-site.xml defined with HiveInterpreter, it can not be used with default configuration.
