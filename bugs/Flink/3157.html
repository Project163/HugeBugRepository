Discussion
- CC:  xuefuz   phoenixjiangnan
- This is a bug of Hive metastore API. Name is not normalized when a function is created. But it's normalized to lower case when getting a function from HMS. Thus any function created with a name containing upper case characters cannot be retrieved later on. 
Since HiveCatalog is case-insensitive, I think we can normalize the function name on our side.
