Title

Changes to the execution platform don't cause changes to the action key

Description
User reported that changing the execution platform's remote_execution_properties attribute did not cause an action to be re-run, which is not what they expected. If it had re-run a different result would have been obtained from the remote system.

The issue seems to be that the execution platform doesn't affect the action key.
