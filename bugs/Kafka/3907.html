Title

upgrade_test.py tests impossible upgrade scenarios

Description
Because of KIP-902 (Upgrade Zookeeper version to 3.8.2), it is not possible to upgrade from a Kafka version earlier than 3.5 to a version later than 3.5. Therefore, we should not test these upgrade scenarios in upgrade_test.py. They do happen to work sometimes, but only in the trivial case where we don't create topics or make changes during the upgrade (which would reveal the ZK incompatibility).
