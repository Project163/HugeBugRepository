Title

Docker install fails on Fedora guest

Description
Fails when it tries to install epel on Fedora.
Discussion

- Sorry for my sloppy bug report. It was mostly a reminder for me.

To reproduce use:

```
ruby
Vagrant.configure(2) do |config|

  config.vm.box = "bento/fedora-22"

... [Log Snipped] ...
  end
end
```

And then:

``` shell
vagrant up --no-provision
vagrant provision
```

It will fail with the error:

```
The following SSH command responded with a non-zero exit status.
Vagrant assumes that this means the command failed!

rpm -ivh [URL]

... [Log Snipped] ...
error: Failed dependencies:
        fedora-release conflicts with epel-release-6-8.noarch
```

The fix for this in #6288 is to add `plugins/provisioners/docker/cap/fedora/docker_install.rb` which don't try to install _EPEL_, since it's a subset of _Fedora_.
