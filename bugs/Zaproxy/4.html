Title

Guaranteed NPE on AliasCertificate.getName() if getCN()==null

Description
```
In line 56/57 of AliasCertificate alias is returned for getName() if getCN().length()
is zero. If getCN() is null this will raise a NullPointerException.

This is supposedly not the desired behavior. Either getCN()==null should not be a valid
result or getName() should also return alias or null in this case.

for corresponding test case.
```
