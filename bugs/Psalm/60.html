Title

Psalm doesn't process require_once once

Description
Given two files, One.php:

```
require_once __DIR__ . '/Two.php';
```

and Two.php:

```
require_once __DIR__ . '/One.php';
```

Psalm bounces between the two files in an infinite loop and eventually dies:

```
$ psalm One.php

Fatal error: Allowed memory size of 2147483648 bytes exhausted (tried to allocate 20480 bytes) in /data/phplib/vendor/vimeo/psalm/src/Psalm/Provider/CacheProvider.php on line 53
```

The same issue occurs if require_once is changed to include_once.

It seems like it's the ```__DIR__``` special variable that's throwing it off.  Changing these to './One.php' or even './' . 'One.php' allows psalm to run without issue.  (But the . has a different meaning than ```__DIR__```.)
