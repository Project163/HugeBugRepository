Title

Should condition builder operator checks be case-insensitive

Description
I believe this only affects `InConditionBuilder` and `LikeConditionBuilder`.

Using `InCondition` if the operator is lowercase the SQL built is `column<>:qp0` instead of `column=:qp0`
```php
$params = [];
echo \Yii::$app->db->queryBuilder
    ->buildCondition(
        new \yii\db\conditions\InCondition('column', 'in', [1])
    , $params);
```
Using `LikeCondition` if the operator is lowercase an exception is raised.
```php
$params = [];
echo \Yii::$app->db->queryBuilder
    ->buildCondition(
        new \yii\db\conditions\LikeCondition('column', 'like', 'foobar')
    , $params);
```

Could be fixed by either upper casing the operator in the condition class or using case-insensitive checks in the condition builder.
I can do a PR for the preferred method.

| Q                | A
| ---------------- | --
| Yii version      | 2.0.34
Discussion
- I think it's fine to accept operator in any case. That aligns well with Yii 2 approach in general.
- Is it a problem for these two operators only?
- I think so, these are the case comparisons.
