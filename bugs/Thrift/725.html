Title

Compiling namespace and sub-namespace directives for unrecognized generators should only be a warning

Description
Two reasons: 
1) we have another generator that we want to use a different namespace for, and the generator is not part of thrift proper 
2) back compat: so two projects that depend on two different versions of thrift are more likely to be able to share a .thrift file, even if the project using the newer thrift libraries uses a new generator that wasn't in the old thrift libraries
Discussion
- Changing this to a bug hoping it will get more attention. We'd really like to see this patch in Apache's thrift so that future versions will be IDL-compatible with some internal stuff we're doing
