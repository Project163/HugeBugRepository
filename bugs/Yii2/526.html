Title

HttpCache triggers 304 HTTP code when callbacks return null

Description
### What steps will reproduce the problem?

Use `HttpCache` filter with `$lastModified` and/or `$etagSeed` defined and return null.
### What is the expected result?

`HttpCache` won't do anything.
### What do you get instead?

`HttpCache` will trigger `304 Not Modified`. 
### Additional info

| Q | A |
| --- | --- |
| Yii version | 2.0.9 |
| PHP version | 5.6.23 |
| Operating system | Debian |

When `Last Modified` and/or `ETag` both can't be determined (but callbacks exist) `HttpCache` should just `return true` in `beforeAction`. It allows to do some complex logic in an action leaving the behavior simple (without need to enable/disable the behavior in a controller's `beforeAction`).
