Title

Problem with query parameter with type array and collectionFormat: multi

Description
Ran the follow command

```
swagger generate client -f swagger-example.json -A BillForward -c client -a client -O getByAccountID --skip-models
2015/11/12 16:19:48 rendered client parameters template: charges.GetByAccountIDParameters
2015/11/12 16:19:48 get_by_account_id_parameters.go:45:3: expected '}', found 'EOF'
2015/11/12 16:19:48 rendered client responses template: charges.GetByAccountIDResponses
2015/11/12 16:19:48 rendered operation group client template: charges.ChargesClient
2015/11/12 16:19:48 rendered client facade template: client.BillForwardClient
```

It generates this code (`client/charges/get_by_account_id_parameters.go`)

```
go
package charges

// This file was generated by the swagger tool.
// Editing this file might prove futile when you re-run the swagger generate command
... [Log Snipped] ...
  return nil
}
```

Changing the field to required:true only removes changes the check for nil making it "valid" but it still has no code that actually deals with the array parameter at all.

swagger-example.json:

```
json
{
    "swagger": "2.0",
    "info": {
        "version": "1.0.0",
... [Log Snipped] ...
    }
}
```
