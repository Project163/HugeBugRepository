Title

Kafka Streams gets stuck if metadata is missing

Description
When a Kafka Streams application gets started for the first time, it can happen that some topic metadata is missing when  StreamPartitionAssigner#assign()  is called on the group leader instance. This can result in an infinite loop within  StreamPartitionAssigner#assign() . This issue was detected by  ResetIntegrationTest  that does have a transient timeout failure (c.f.  [URL] – this issue was re-opened multiple times as the problem was expected to be in the test – however, that is not the case).
