Title

Non static inner class usage fails with MethodSelectionException

Description
class  Test {
     static  main(args) {
         new  A()
    }
     class  A {
        def A() {}
        def A(num){}
    }
}
 
  

 The above code fails with the following error 
  
 Caught: org.codehaus.groovy.runtime.metaclass.MethodSelectionException: Could not find which method <init>() to invoke from this list:
  public Test$A#<init>(Test, java.lang.Object)
  public Test$A#<init>(Test)
	at Test.main(Try.groovy:3)
 
  

 I think it is happening because the inner class is non-static and no enclosing "this" instance is being passed to it. The compiler should enforce it at compile time instead of letting it get compiled and fail at runtime.
