Title

[YSQL] ALTER TABLE on column referenced by FK in partitioned tables throws cache lookup failed error

Description
Jira Link: [Link: DB-7879]
### Description

Reproduction steps:
```
CREATE TABLE emp (id int unique, name text);
CREATE TABLE address (emp_id int references emp(id)) partition by range(emp_id);
CREATE TABLE address_1_100 PARTITION OF address FOR VALUES FROM (1) TO (100);

ALTER TABLE emp add primary key (id);
```

The `ALTER` operation throws `cache lookup failed for constraint 18872` error.

This issue was present in PG upstream and was fixed in PG11: [URL]
