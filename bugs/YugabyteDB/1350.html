Title

[YSQL] [Transactional DDL] ERROR: EnterSeparateDdlTxnMode called when already in DDL mode while creating index inside transactional block

Description
Jira Link: [Link: DB-16192]
### Description

Create index inside transaction block failed with ERROR:  EnterSeparateDdlTxnMode called when already in DDL mode  However we cannot create concurrent index inside transactional block , error seems to be something different. In master b-299

```
db2=*# create index idx on complex_table (id);
ERROR:  EnterSeparateDdlTxnMode called when already in DDL mode
```

Repro :

```
CREATE TABLE complex_table (
  id SERIAL PRIMARY KEY,                
  uuid_col UUID DEFAULT gen_random_uuid(), 
  name TEXT NOT NULL,  
  created_at TIMESTAMPTZ DEFAULT now(),
... [Log Snipped] ...
  ip_address INET  
);
```
```
BEGIN ISOLATION LEVEL REPEATABLE READ;

CREATE EXTENSION pgcrypto;

... [Log Snipped] ...

create index idx on complex_table (id);
```
Final statement failed with : ERROR:  EnterSeparateDdlTxnMode called when already in DDL mode
