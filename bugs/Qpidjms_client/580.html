Title

[AMQP 1.0] broker attempts to process incoming messages for closed session

Description
If using the proton events API (i.e. any recent version of proton), then if the broker closes the session when there are already incoming delivery events on the event queue, those events will still get dispatched and the broker will try to handle them though proton will fail to retrieve any data for the deliveries.
