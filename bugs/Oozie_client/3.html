Title

GH-62: Support actual time EL function for coordinator actions

Description
Actual time specifies the time when a coordinator time is actually created in oozie. Currently oozie supports nominal time EL function. The same way coordinator should support the actual time EL function. 

 Propose prototype of function: coord:actualTime() 

 Return: Date stamp string in UTC format. 

 Scope: All the places in coordinator xml where current coord:nominalTime() could be used
