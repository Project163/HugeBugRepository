Title

[CDCSDK] Remove existing non eligible tables from existing CDC streams

Description
Jira Link: [Link: DB-11733]


[DB-11733]: [URL]

There is a [Link: bug] where non-eligible tables, such as indexes created after the CDC stream creation, are incorrectly added to the CDC stream metadata. Their corresponding tablet entries are also added to the CDC state table. Consequently, if any tablets of these non-user table splits, their child tablets are also added to the CDC state table unless the non-user table is removed from the CDC stream metadata.
