## Description

When editing Markdown, links to other files in the repo are relative to the location of the file. However, when previewing changes, the rendered preview seem to render links from the repository root.

In the linked example, the link works as expected and links to [URL] But try to edit the file and enable the preview mode: the link will be to [URL] instead (the `a/` part for the relative link is stripped).
