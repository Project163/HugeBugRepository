Title

Inconsistent JSON report format

Description
**Describe the bug**
The JSON report output format looks differently where there is only one site and when there are multiple sites. 
When there is only one site, this is how it looks like:
```
{
    "@version": "2.7.0",
    "@generated": "Thu, 27 Dec 2018 12:41:32",
    "site": {
        "@name": "[URL]
... [Log Snipped] ...
    }
}
```
When there are multiple sites, the `@site` property is an array - not an object:
```
{
    "@version": "2.7.0",
    "@generated": "Thu, 27 Dec 2018 12:42:05",
    "site": [
        {
... [Log Snipped] ...
    ]
}
```
**To Reproduce**
Steps to reproduce the behavior:
1. Proxy one site through Zap
2. Generate JSON report
3. Proxy another site through Zap
4. Generate JSON report

Compare both files
**Expected behavior**
A consistent behavior of `@site` - it should always be an array.

**Software versions**
 - ZAP: 2.7.0
 - OS: mac/docker
