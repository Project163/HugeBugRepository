Title

Automatic compactions are disabled for the table after it is truncated

Description
Jira Link: [Link: DB-13559]
There is a code in `Tablet::OpenKeyValueTablet` which turns off auto compactions:
```
rocksdb_options.disable_auto_compactions = true;
rocksdb_options.level0_slowdown_writes_trigger = std::numeric_limits ::max();
rocksdb_options.level0_stop_writes_trigger = std::numeric_limits ::max();
```
and later it is supposed to be re-enabled in `TabletPeer::Start` by calling 
`tablet_->EnableCompactions`. In case tablet is truncated, `Tablet::Truncate` - it calls `OpenKeyValueTablet` which turns off auto compactions and since tablet peer is not restarted - compactions are not enabled after truncate.
