Title

[Bug]: useResolvedPath is causing 'Rendered more hooks than during the previous render.' if number of rendered links change

Description
### What version of React Router are you using?

6.2.1

### Steps to Reproduce

Create a list of ` ` to loop through and create a button to toggle the amount of links. Inside the ` ` component use the `useResolvedPath` hook.

[Link: Stackblitz example here] 

### Expected Behavior

Toggling between the number of ` ` rendered which use the `useResolvedPath` should not crash

### Actual Behavior

When you change the number of ` ` rendered you'll get the `"Rendered more hooks than during the previous render."` error.
Discussion
- Your code is incorrect. It's rendering out the raw component functions, not element instances of that component: 
```jsx
 {navLinks.map(MyLink)} 
// should be:
 {navLinks.map(link =>  )} 
```
