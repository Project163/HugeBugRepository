Title

Resteasy fails to load abstract subclass of javax.ws.rs.core.Application

Description
## Describe the bug
Since 1.13.0.Final an application using an abstract Base Implementation of an javax.ws.rs.core.Application will not start anymore.


### Expected behavior
The Application should start properly as with previous versions of quarkus (  causes exception mentioned above
