Title

application/xml to application/json is not properly converting

Description
I am using simple proxy to convert application/xml to application/json with latest build  [1] , 

  
 <proxy name= "echoService"  xmlns= "http: //ws.apache.org/ns/synapse" >
     <target>
        <inSequence>
            <property name= "messageType"  value= "application/json"  scope= "axis2"  />
            <log level= "full"  />
            <respond />
        </inSequence>
        <outSequence>
            <send />
        </outSequence>
    </target>
    <publishWSDL uri= "file:repository/conf/sample/resources/proxy/sample_proxy_1.wsdl"  />
</proxy>
 
  

 the input payload is  
  
 <a>
<b>c</b>
</a>
 
  

 and expected output is 
  
 {
   "a" : {  "b" :  "c"  }
}
 
  

 However the out come was  
  
 { "a" :{ "$" : "\n\n" , "b" : "c" }}

 
  
 ============================= 
I have tested the very simple xml  
  
  <a>b</a> 
  
 and the outcome was as expected. 
  
 { "a" : "b" }
