Title

Unintentional breaking change in Renderer (starting from 4.0.0-rc.1)

Description
The plunker says it all: [URL]

Before it was possible to call `Renderer.createText(...)` from a listener registered via `Renderer.listen(...)` but from 4.0.0-rc.1 it blows with an error as seen in the linked plunker.

The error is thrown in the debug mode only - production mode is not affected. Seems like there is some shared state related to debug info and something is not initialized / cleaned up properly.

I fully recognize that this is a corner case but it was [Link: reported against ng-bootstrap] for the real-life use-case (we are using similar code in tooltips / popovers). I can work-around it on my side but again, this is an accidental breaking change and IMO one worth fixing if possible.
