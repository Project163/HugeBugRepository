Title

error during class generation: cannot define closures inside methods of an enum instance

Description

    INSTANCE {
         String  foo() {
            def clos = {
                 "foo" 
            }
            clos.call()
        }
    }

     String  foo() {
    }
}

 assert   "foo"  == MyEnum.INSTANCE.foo()
