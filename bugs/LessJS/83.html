Title

Array.prototype.filter does not pass index to callback

Description
Array.prototype.filter does not pass the index to the callback, this seems to be solved in a newer version of ecma-5.js.

It causes problems in browsers that do not have a native implementation, because underscore will use the version provided by ecma-5.js instead of it's own implementation.
