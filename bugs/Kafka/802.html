Title

Update NOTICE file

Description
According to this page from ASF legal: 

  
 [URL]
 
  

 the years in the NOTICE header should reflect the product name and years of distribution of the current and past versions of the product. The current NOTICE file says only 2012.
Discussion
- The following is the answer that Flavio got from Apache legal. 

 Question: 
I have a couple of questions about the NOTICE file. In this page: 

  [URL]

 it says that it should include the following text, suitably modified to reflect the product name and year(s) of distribution of the current and past versions of the product: 
Apache  [PRODUCT_NAME]  
Copyright  [yyyy]  The Apache Software Foundation 
As I understand it, it means that every year, if there is a release, the year part needs to be modified to add the new year, e.g., 2010-2015 if there is a release in 2015. How much of a problem is it if a release comes out without that year field updated?  

 Answer: 
Unnecessary to have a span of years, and now considered improper form.  The current year (when this specific package is published) is the only year necessary.  The copyrights on individual bits probably go back many years before the first ASF release, but what is important here is the copyright of the collective work that is your current release (here and now).
