Here's the serializer code: 

  
  public   class  TestSerializer  extends  ByteArraySerializer {

     public   byte [] serialize( String  topic,  byte [] data) {
         if  (data ==  null ) {
             return   null ;
        }
         try  {
             System .out.println(data);
            LogEvent logEvent =  this .deserializeLogEvent(data);
             System .out.println(logEvent);
        }  catch  (IOException e) {
             System .out.println( "error happened" );
            e.printStackTrace();
             return   null ;
        }  catch  (ClassNotFoundException e) {
             System .out.println( "error happened" );
            e.printStackTrace();
             return   null ;
        }
         return   super .serialize(topic, data);
    }

     public  LogEvent deserializeLogEvent( byte [] data)  throws  IOException, ClassNotFoundException {
        ByteArrayInputStream bis =  new  ByteArrayInputStream(data);
        ObjectInput ois =  new  ObjectInputStream(bis);
         return  (LogEvent) ois.readObject();

    }
}
 
  

 I'm new to log4j2, so initially I wanted to format  the LogEvent in the kafka serializer before emitting its contents. My previous plan was to use the serializedlayout to transmit the LogEvent object to the serializer, which would extract information from the object. I've since moved to using a custom Layout to perform the formatting, and will use the straightforward kafka ByteArraySerializer on the results of the layout. 

 I came across this issue in my first approach, which I'm no longer using - feel free to downgrade this ticket priority.
