Title

Exported namespaces must have `use()` called

Description
See #203

This snippet

``` js
// export * as ns from './mod';
import * as ns from './mod';
export { ns };
```

yields nothing but

```
js
'use strict';

var ns = Object.freeze({
    a: a,
... [Log Snipped] ...

exports.ns = ns;
```

resulting in a `ReferenceError: a is not defined`.
