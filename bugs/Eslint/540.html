Title

`prefer-template` doesn't consider unary expressions in string concat as warning

Description
`prefer-template` doesn't consider unary expressions in string concat as warning. 

For example:

``` js
// EDIT: wrong one
//var foo = 'bar' + (typeof bar) + 'baz';

var foo = 'bar' + (typeof 100) + 'baz';
```

It can be rewritten as the following; but `prefer-template` doesn't emit a warning:

``` js
var foo = `bar ${typeof 100} baz`;
```

/cc @mysticatea
Discussion
- Oh, `var foo = 'bar' + (typeof bar) + 'baz';` is warned correctly.

``` js
/*eslint prefer-template:2, no-useless-concat:2*/
var foo = 'bar' + 100 + 'baz';
var foo = 'bar' + (typeof 100) + 'baz';
var foo = 'bar' + (typeof bar) + 'baz';
```
