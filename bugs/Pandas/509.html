Title

Period.start_time returns the same value as Period.end_time

Description
If you create a Period object with a non-Day frequency, the start_time property incorrectly returns the end_time value.

ex:

```
python
In [1]: from pandas import *

In [2]: w = period_range('2012-8-20', '2012-9-10', freq='W-MON')

... [Log Snipped] ...
In [6]: w[0].freq
Out[6]: 'W-MON'
```

The expected behavior would return a ` ` object for the Period.start_time property.
