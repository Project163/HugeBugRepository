Title

[bug] http.ClientOptions.maxRedirections not working

Description
### Describe the bug

[Link: `http.ClientOptions.maxRedirections`] provides undesired outcomes when trying to prevent redirects :

| `http.ClientOptions.maxRedirections` | `Cargo.toml` > `tauri` > `features` | Outcome    |
| ------------------------------------ | ----------------------------------- | ---------- |
| `0`                                  | `["api-all"]`                       | Redirected |
| `1`                                  | ^                                   | Redirected |
| `0`                                  | `["api-all", "reqwest-client"]`     | Redirected |
| `1`                                  | ^                                   | `Network Error: error following redirect for url (https://d.cv.vg/8Qa): too many redirects` |

This most likely occurs when trying to limit redirects to a specific amount as well.

### Reproduction

Call [Link: `http.getClient`] with the specified `Cargo.toml` configuration and `maxRedirections` option value.

### Expected behavior

The request is not redirected and succeeds, like the following Node equivalent :
```
js
import axios from 'axios';
(async () => {
    const {
        status,
... [Log Snipped] ...
    ));
})().catch(console.error);
```
Which outputs :
```
json
{
    "status": 302,
    "location": "[URL]
    "data": {
... [Log Snipped] ...
    }
}
```
