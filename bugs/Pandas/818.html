Title

asfreq drops the name of the index

Description
Here's a simple repro

```
In [19]: df = DataFrame(range(3),columns=['foo'],index=pd.date_range('20130101',periods=3,name='bar'))

In [20]: df
Out[20]: 
            foo
... [Log Snipped] ...

In [24]: df.asfreq('10D').index.name
```
