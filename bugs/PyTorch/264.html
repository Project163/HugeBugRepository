Title

`torch.cuda._check_capability` could raise a false-negative warning

Description
The function in question is defined here -- 
[URL]

In my environment, PyTorch is installed with the following env vars: 
- `TORCH_CUDA_ARCH_LIST="8.9 9.0+PTX"`
- `CUDA_HOME=/usr/local/cuda-12.9`
- `CUDNN_LIB_DIR=/usr/local/cuda-12.9/targets/x86_64-linux/lib`
- `CUDNN_INCLUDE_DIR=/usr/local/cuda-12.9/targets/x86_64-linux/include`

Thus my source build PyTorch works in my environment but when I do something on CUDA then I see a warning as follows:
```
$ python -c 'import torch; print(torch.ones((1,), device="cuda"))'
/path/to/torch/cuda/__init__.py:284: UserWarning:
    Found GPU0 NVIDIA RTX 6000 Ada Generation which is of cuda capability 8.9.
    Minimum and Maximum cuda capability supported by this version of PyTorch is
    (8.9) - (9.0)
... [Log Snipped] ...
  warnings.warn(matched_cuda_warn.format(matched_arches))
tensor([1.], device='cuda:0')
```

I'm wondering if this check should respect the minor version of the device being checked, not only the major version.
