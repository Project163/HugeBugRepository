Title

Computed props are not properly handled

Description
Repost of microsoft/typescript#4419

Seems like this problem is related to v8. Following code (using iojs@3.1)

``` javascript
var prop = 'age'
var val = 42
console.log([{ name: "ivan", [prop]: val }])
console.log({ name: "ivan", [prop]: val })
```

produces output

```
[ { name: 'ivan' } ]
{ name: 'ivan', age: 42 }
```
