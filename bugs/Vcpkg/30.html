Title

CMake error consuming freetype

Description
I tried to consume freetype like so:

```
find_package(freetype CONFIG REQUIRED)

...

link_libraries(freetype)
```

When I run CMake through this I get the following error:

```
Imported target "freetype" includes non-existent path

    " /installed/x64-windows/include/freetype2"

  in its INTERFACE_INCLUDE_DIRECTORIES.  Possible reasons include:
... [Log Snipped] ...
  * The installation package was faulty and references files it does not
  provide.
```

I don't see this path present when I ran `vcpkg install freetype`, but I do see that the generated `freetype-config.cmake` has this set

```
set_target_properties(freetype PROPERTIES
  INTERFACE_INCLUDE_DIRECTORIES "${_IMPORT_PREFIX}/include/freetype2"
)
```

Perhaps this commit (https://github.com/Microsoft/vcpkg/commit/ ) is incomplete as the `freetype2` directory is still being referenced in the generated cmake module files.
