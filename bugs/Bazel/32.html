Title

ijar zipper compression corrupts some files

Description
For some files, it's not possible to deflate the zip file created by the ijar zipper:

```
$ bazel-bin/third_party/ijar/zipper Cc test.zip test
$ bazel-bin/third_party/ijar/zipper x test.zip     
zlib returned error code -3 during inflate.
.
$ unzip test.zip
... [Log Snipped] ...
  inflating: test                    
  error:  invalid compressed data to inflate
```

I'm not sure what sorts of files cause this failure, but the following is a small example that fails reliably for me:

```
one
two
three
four
five
... [Log Snipped] ...
ten
eleven
```

It works with only ten lines, so it seems somehow related to file size, but in further experiments it doesn't seem like there's an exact byte count that it breaks after.
