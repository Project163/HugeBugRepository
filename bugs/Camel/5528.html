Title

ClusteredRouteController cannot start clustered routes

Description
The ClusteredRouteController cannot start a clustered route (in Camel 3.4.4, Camel 3.6 and probably other versions of Camel 3). 

 The problem can be reproduced with example camel-example-spring-boot-clustered-route-controller from the examples project ( [URL]

 When an instance is the lead in the cluster and tries to start the routes an exception is thrown: 
 java.lang.UnsupportedOperationException: Operation not supported as route clustered is clustered
Discussion
- The ClusteredRouteController is experimental (see its annotation on the class level).
- Okay so it looks like the problem is that its own startup of routes hits the public API of starting routes, that the route controller would deny the end user to do manually such as via JMX - because a route is under clustering management.
