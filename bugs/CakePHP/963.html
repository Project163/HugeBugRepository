Description

* CakePHP Version: 2.10.14
* Platform and Target: PHP 7.1, OS X 10.14.2

### What I did
1. Set up a new project with a `composer.json` requiring cakephp/database:
```
{
    "require": {
        "cakephp/database": "3.7.1"
    }
}
```
2. `composer install`
3. Run any of the example code from the cakephp/database repository README
