Title

db->close() drops any custom configuration of Query Builder

Description
### What steps will reproduce the problem?

Setup additional expressionBuilders/conditionClasses within the db configuration.
execute `Yii::$app->db->close()` and `Yii::$app->db->open()` within the course of the app

### What is the expected result?

Configurations designated in the config will be reinstantiated in the newly open db.

### What do you get instead?

new instance of `Yii::$app->db->queryBuilder` will have lost custom configurations and contain only default.

### Additional info

In the course of initial configuration of the db, `\yii\db\Connection::setQueryBuilder` is called which pulls a new schema and then loads it with any necessary queryBuilder configurations. Close then sets that schema to null, which when reopened and asked for again, creates a new schema which then creates a new queryBuilder instance with only default configuration.

\yii\db\Connection::close
```
php
    /**
     * Closes the currently active DB connection.
     * It does nothing if the connection is already closed.
     */
... [Log Snipped] ...
            $this->_schema = null;
       ....
```
