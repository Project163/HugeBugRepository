Title

Pages fail to load when a trailing slash is appended

Description
### Checklist

- [Link: X] I have searched the [existing issues] for similar issues.
- [X] I added a very descriptive title to this issue.
- [X] I have provided sufficient information below to help reproduce this issue.

### Summary

When loading a page other than the homepage in a Streamlit application, appending a trailing "/" to the URL prevents the page from loading. Inspecting the console reveals that `main.7994a814.js` contains an HTML file rather than a JS file, and so the browser fails to parse it. The specific error is: `Uncaught SyntaxError: Unexpected token ' `, and it is this character that throws the syntax error. This is understandable, as trying to parse HTML as a Javascript file is a recipe for failure.
