Title

3.0 Template breaks when error happens

Description
When we have an exception like Missing Helper or Element, the content of view.ctp is printed before the layout.
Even if it is the developer's fault, this is bad for production and that code should not be printed, especially if `debug` is false. 
In this case a ` ` was left open and nothing more than positioning broke in my browser, but if we're lucky enough to have a ` ` open there, possibly the whole layout will be show as a link by most browsers.

```
 
     Users 
     
     
          Id  
... [Log Snipped] ...
         
...
```
