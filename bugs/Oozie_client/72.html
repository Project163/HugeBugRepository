Title

Workflow schema 0.4.5 was removed

Description
OOZIE-1244   removed workflow schema 0.4.5 and replaced it with 0.5.  This is a backwards incompatible change because anyone using schema 0.4.5 who upgrades to Oozie 4.0.0 or 4.0.1 will be unable to submit those workflows without updating to schema 0.5.   

 We should add 0.4.5 back and also properly document it (I don't think it was ever added to the schemas list on the Workflow docs page)
Discussion
- The patch adds the 0.4.5 schema back and also properly documented.   
No tests, but I did verify that I could submit a workflow using the 0.4.5 schema. 

 I figured out why 0.4.5 was removed: it was never actually in a released version of Apache Oozie.  For users who were using trunk, patched their own Oozie, or were using a distribution (e.g. CDH), it would be nice to put this back as it doesn't hurt anything to include it.
