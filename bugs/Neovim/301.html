Title

v:argv doesn't use the actual argv nvim was started with

Description
### Problem

Since TUI was moved to another process, the TUI process is spawned with `["/usr/bin/nvim", "--embed", ...]`.
`v:argv` and `v:progname` now always report that, instead of how nvim was actually started.

### Steps to reproduce

Create a symlink to change `argv[0]`:
```
ln -s `which nvim` foo
./foo
```
`:echo v:progname` says `nvim`

### Expected behavior

`:echo v:progname` should say `foo`

### Neovim version (nvim -v)

0.10.0 commit f959753e5
