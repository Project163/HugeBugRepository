- @erw7 is right. The relevant code for handling of `%p1%s` is here [URL]

Neovim sets numeric params and so `%p1` pushes a numeric param. The `%s` pops a string param. Both unibilium and ncurses default to an empty string in the case a numeric param was popped. xterm and Alacritty define `Cs` using `%p1%s`. Neovim currently defaults to `%p1%06x` if `Cs` is missing in terminfo for these terminals, which correctly formats the numeric param it sets: these terminals expect "legacy" hex color input like `#0099ff` or input like `rgb:00/99/ff`.

That's why setting `TERM=rxvt-256color` works: rxvt's terminfo doesn't specify `Cs`.

Perhaps the better behavior would be for Neovim to set a hex color string param, but I'm not sure if there's some broader convention for parameters to `Cs` (or any "user-defined" terminfo capability for that matter).
