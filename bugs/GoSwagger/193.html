Title

Data Race between Serve() and Shutdown()

Description
## Problem statement

Between the functions `Serve()` and  `Shutdown()` is a data race on the variable `servers`. This occurs because the goroutine that starts the server writes into `servers` on [Link: this line]. Before it starts a goroutine to handle shutdowns [Link: here]. In the `handleShutdown()` method `servers` is accessed again which causes a data race:

```
==================
WARNING: DATA RACE
Read at   by goroutine 27:
  goswagger-race/restapi.(*Server).handleShutdown()
      .../goswagger-race/restapi/server.go:418 +0xba
... [Log Snipped] ...
      .../goswagger-race/cmd/example-server/main.go:60 +0x64a
==================
```
