- This patch incorporates the test added by Andras Salamon in PR #1152 but the actual fix is slightly different. 

 This patch changes the buildReplicaPositions method to throw an AssignmentException instead of SolrException in case the maxShardsPerNode is insufficient. It also changes the Create Collection API to return a BAD_REQUEST code instead of SERVER_ERROR in case of assignment exception. I'll note this behavior change in the upgrade notes.
