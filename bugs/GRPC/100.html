Title

Temporary DNS error reported with status code `UNKNOWN`

Description
### What version of gRPC and what language are you using?

C++, v1.65.1

### What operating system (Linux, Windows,...) and version?

Linux.

### What runtime / compiler are you using (e.g. python version or version of gcc)

GCC 13.2

### What did you do?

I am running integration tests for `google-cloud-cpp` on my workstation.  The test creates a client-side streaming RPC call on a newly created channel.  In this environment, I am using user credentials.

### What did you expect to see?

A successful RPC, or many a transient error.

### What did you see instead?

The request fails with `UNKNOWN`.  AFAIK, this is not a retryable error.  My log shows:
