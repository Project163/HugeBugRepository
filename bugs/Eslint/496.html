Title

Unexpected error with assessor-pairs

Description
Running `eslint@1.0.0`:

With the following config:

```
json
{
  "env": {
    "node": true,
    "es6": true
... [Log Snipped] ...
  }
}
```

Against the following file:

``` js
let obj = { set: function () {} };
module.exports = obj;
```

I get the following error:

```
  1:10  error  Getter is not present  accessor-pairs

✖ 1 problem (1 error, 0 warnings)
```

Though I'm not using a setter here and would expect no error.
Discussion
- Oh... Thank you for the report.

Yes, the rule should check whether or not the object literal is inside of `Object.defineProperty`/`Object.defineProperties`/`Object.create`.
- It's the difference between `{ get foo(){} }` and `{ get: function () {}`, so it shouldn't matter where the object literal is being used.
- No, it does matter because the following pattern is detected by this rule:

``` js
Object.defineProperty(o, p, { get: function(){ } });
```
