Title

Support debugging multiple test clusters

Description
We can pass `-Dtests.cluster.debug.enabled=true` to REST tests to enable debugging for the test cluster, i.e. it will attempt to connect to a debugger. The port number begins with 5007 and plus 1 for each additional node in the cluster. This works fine with a single cluster. But when a test have 2 clusters (for CCS tests, e.g. [Link: RemoteClusterSecurityRestIT]), the second cluster will again start with port 5007 as well and conflict with the 1st cluster and fail. 

It would be great to have the 2nd cluster to use a different set of ports. It would be nice to have the port number range to be predicatable for each cluster. It may also be useful if we can enable debugging separately for each cluster.
