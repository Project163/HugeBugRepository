Title

configuration of formatting for sizeFormat is ignored/reset by intl message formatter

Description
```
public function testAsSizeConfiguration()
{
    $this->formatter->thousandSeparator = '';
    $this->assertSame("1023 bytes", $this->formatter->asSize(1023));
}
```

result is '1,023 bytes' even though the settings on the formatter are adjusted to disable the thousand separator. This problem arises from the MessageFormatter plural rule which re-formats the number even though it was formatted already correctly before.

This issue can be fixed after #3906 is merged.
