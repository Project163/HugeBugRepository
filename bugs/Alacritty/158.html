Title

Message bar text unreadable

Description
Message bar has harcoded yellow or red background but foreground color is from `colors.primary.background`. It is easy to see that it cannot work both with light or dark themes.

I think either message bar’s background color could be get from `colors.normal.{yellow,red}` or use also hardcoded (black) foreground color for messages.

### System

Version: `alacritty 0.5.0`
Discussion
- It seems like it got accidentally changed during some refactoring. It always was black on yellow/red.
- I don't really like this change as well tbqh. I'd rather use foreground color in my case, since it's a bit more readable. If anything, I'd use foreground color over red/yellow colors from the config, but that's it.

[Image: picture]
- I think this should be solved by pulling the yellow/red color from the user's theme, to keep things more consistent.
