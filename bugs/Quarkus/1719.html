- Note to self:

This can easily be addressed by registering all Resource methods for reflection. However, in order to keep the native binary footprint low, we don't want to do that unconditionally, we only want that to happen when an access pattern like the one mentioned in this issue is detected (i.e. a `ContainerRequestFilter` or `ContainerResponseFilter` calls `ContainerRequestContext#getMethod`). We can detect this pattern efficiently by using the already built scanned application metadata and an ASM Method Visitor that will look at the method body for the pattern mentioned above.
