Title

correct NPE exception in HiveMetastoreAuthorizer

Description
In some testing, we found it's possible to have NPE if the preEventType does not fall within the several the HMS currently checks. This makes the AuthzContext a null pointer.
Discussion
- AtzContext should is not expected to be null for the events that are currently handled. For any new event types, it could be null. We discussed throwing an exception when this is null but instead of skipping authorization but as it is not expected to be null normally, there is no risk of unauthorized access. 

 Fix has been committed to master. Thanks for the patch  samuelan
