Title

JsonLexer fails to parse number without trailing space

Description
Reproducer: 
  
  
 
reader =  new  StringReader( '-123.456e78' )
lexer =  new  groovy.json.JsonLexer(reader)
lexer.nextToken()
 
  
 Expected: 
  
 
-123.456e78
 
  
 Actual: 
  
 
 null 
 
  
   
I found JsonLexerTest.groovy contains tests for plain numbers which are  surrounded by spaces  but I wonder why this should be required? 

 At least it's unexpected for users like the developers of  REST-assured  who pass json content from http responses without added spaces into JsonLexer (they use  their own slurper ). This makes REST-assured fail to support plain number responses. 

 One more note: Groovy's own JsonSlurper successfully parses the above example, so the behaviour is inconsistent at least.
