Title

Unable to define I18n-localized menu parent's name [0.5.0]

Description
There's no way to use I18n parent menu name in activeadmin 0.5.0.

If I try to do the follwing:

```
menu :label  => proc{ I18n.t('my.key') }, :parent => I18n.t("menu.abcd")
```

translation for parent isn't fetched, propably due the same reason why :label has to be put within proc.

But if I try to apply proc to parent:

```
menu :label  => proc{ I18n.t('my.key') }, :parent => proc{ I18n.t("menu.abcd") }
```

I got error "can't convert Proc into String"
Discussion
- I hadn't expirienced problem with setting:

``` ruby
menu :label  => proc{ I18n.t('my.key') }, :parent => I18n.t("menu.abcd")
```

Seems working for me.

Also added support of Proc object in parent.
- Fixed in #1664.
- @MOZGIII if you want dynamic parent menus, you should specify an ID.

``` ruby
ActiveAdmin.register Foo do
  menu label: ->{ I18n.t 'foo' }, id: 'foo'
end
ActiveAdmin.register Bar do
  menu label: ->{ I18n.t 'bar' }, parent: 'foo'
end
```

This is also explained in the [Link: docs].
