Title

Console commands with two subsequent uppercase letters have missing help and can't be called

Description
## Yii2 version

I use composer and have version   of Yii2 (dev-master) which according to composer website is dated 2014-08-04.
## How to reproduce it

In basic app, open console/HelloController.php and add

``` php
    /**
     * This command echoes the string 'NO'.
     */
    public function actionSayNO()
    {
        echo "NO\n";
    }
```

Then show the help for hello:

``` bash
php yii help hello
```

Output:

```
...
SUB-COMMANDS

- hello/index (default): This command echoes what you have entered as the mes...
- hello/say-no

To see the detailed information about individual sub-commands, enter:
...
```

Note that the help text is missing. The command is suggested to be executed as hello/say-no. However trying to execute the command give an error that the command cannot be found.

``` bash
php yii hello/say-no
```

Output:

```
Error: Unknown command "hello/say-no".
```
## Workaround

If I rename `actionSayNO` to `actionSayNo` it will work as expected
Discussion
- yes, it works as expected, because in your case `actionSayNO` is not a camel case that is used by default in Yii. But `actionSayNo` is correct camel case that is parsed by Yii. Dont see here any exception
