Title

Stop initializing GLFW second time

Description
Hi,

I am using java [Link: imgui] library to draw game editor on top of our existing java game framework that uses GLFW.

The problem as you can see that both, our framework (which I cannot modify) and the graphics library (not ours) does initialize GLFW instance. When one of these frameworks does initialize GLFW second time, application does crash on:

`Win32: Failed to register window class`
(which is expected)

Is there any possible way how to solve this issue? Or how to re-use some GLFW instance or pointer?

Thank you
Discussion
- `glfwInit` can be called any number of times and will succeed immediately if GLFW is already initialized. Instead it sounds like there's more than one copy of GLFW in your process. GLFW doesn't yet support multiple copies of itself in a single process, though I will look into supporting this after 3.3.

In the meantime, if possible try to have all parts of your application call the same copy of GLFW.
