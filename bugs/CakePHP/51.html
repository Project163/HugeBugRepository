Is there any reason you are creating HTTP requests by hand and not using HttpSocket instead? Given your code and direct use of CakeSocket you would need a while loop for sure. `CakeSocket::read()` is intended to read X bytes from the stream and not _all_ the bytes. It is intended to be used inside a loop until `false` is received. For example:

``` php
$results
while ($data = $socket->read()) {
  $results .= $data;
}
```

Is how you would use CakeSocket to read all the bytes from a stream.
