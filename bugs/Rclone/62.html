Title

config: Authentication redirect is wrong when adding the second backend.

Description
It appears there is an issue when re-starting a web server in Go, where old ServeMux functions are used when restarting a server.

I have filed this issue: [URL]

This means that if you add two different backends, the server will redirect to the authURL of _first_ server. For instance, if you add an ACD and then a Drive backend, the Drive authentication will redirect you to the ACD authentication page.

I have tried "clean" ways of fixing this, but I cannot make anything work consistently. The only "sort-of" solution I can come up with is to keep the server running and update the authURL.
