Title

`supportsWebAnimation` check fails if loaded before ` ` tag

Description
Repro:

``` html
 
      
   Hello! 
 
```

Leads to `Cannot read property animate of null`. The problem is this code:

``` ts
  supportsWebAnimation(): boolean {
    return isFunction((document as any /** TODO #9100 */).body['animate']);
  }
```

If `document.body` hasn't been loaded yet, this will fail with the above error.

Maybe we could instead call `isFunction(document.createElement('div')['animate'])`? And possibly memoize/cache the result?
