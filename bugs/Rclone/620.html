Title

setting the new -bwlimit X:off causes buffering

Description
#### What is the problem you are having with rclone?

When i set my --bwlimit as 3M:off the upload speed is respected and the download speed can also exceed the 3M speed, but for some reason this does cause buffering. When i look at my download speed at the time, it starts at 20MB per second and then drops after some time and this seems to correspond with the buffering in plex. 

When i remove the --bwlimit in the rclone gui by setting it to an empty value, this behaviour does not occur. There is no buffering and starting a file is near instant. 

I don't understand why this occurs as the only thing being throtteled should be the upload speed and this should have no impact on playing a file that is already uploaded.
