Title

ChildActivationStart/End events seem to fire too eagerly

Description
It seems that the new `ChildActivationStart` event (and likely `End` as well) fire too frequently. They seem to fire whether the new route will be re-activated or not.

They are intended to only fire if parameters change in some way. Also, new tests are needed as the current tests aren't sufficient to verify this behavior.
