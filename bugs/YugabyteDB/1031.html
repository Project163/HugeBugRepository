Title

[YSQL] ALTER TABLE ALTER COLUMN TYPE fails with range key table

Description
Jira Link: [Link: DB-8178]
### Description

When collation is used with range key table
```
db=# create table t(id int, name text, PRIMARY KEY(id asc));
CREATE TABLE
db=# ALTER TABLE t ALTER COLUMN name TYPE int USING name::integer;
ERROR:  HASH columns must be present to split by number of tablets
```
