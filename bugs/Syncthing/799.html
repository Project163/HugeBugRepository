Title

Dangling symlink prevents filesystem watcher on FreeBSD

Description
### Easy to reproduce

$ cd $HOME/Sync/data
$ ln -snf /link-a-non-existing-file  to-here

or from any sub folders inside your sync path

$ cd $HOME/Sync/data/ebooks
$ ln -snf /usr/local/www/non-existing  book.pdf

then you will see the error message from your browser.

```
Filesystem Watcher Errors: error while traversing /path/to/exists/file_or_dir: no such file or directory
```
