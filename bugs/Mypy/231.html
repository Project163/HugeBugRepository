Title

Crash with IndexError when using TypeVar(..., Sequence, ...)

Description
The following test case crashes on mypy 0.4.6 and up:

```
python
from typing import Sequence, TypeVar

S = TypeVar('S', Sequence)

... [Log Snipped] ...
def crash() -> None:
    my_len((0,))
```

Here's the traceback produced with mypy 0.4.6 installed from pypi:

```
pytb
$ mypy --show-traceback repro.py
repro.py:11: error: INTERNAL ERROR -- please report a bug at [URL]
Traceback (most recent call last):
  File "/home/adrake/ve/app/bin/mypy", line 6, in  
... [Log Snipped] ...
    iter_type = right.args[0]
IndexError: list index out of range
```

This crash also reproduces on master. While I haven't had a chance to dig into it much, I did observe that `Sequence[Any]` does not crash, so I suspect it's a quick fix.
Discussion
- This feels awfully familiar but I can't find a duplicate issue.

Note that the demo code is wrong -- you should use
```python
S = TypeVar('S', bound=Sequence)
```

(But of course it shouldn't crash!)
- Yeah -- the original code pre-testcase-reduction was `S = TypeVar('S', Sequence, Dict[str, str])` or something more complicated (which still crashes).
- Oh wait. I was distracted by the broken `TypeVar`. The crash is on the `my_len((0,))` call. I have a fix, will send the PR soon.
- Ah, sorry. I was so caught up with the typechecker, I didn't even check to see whether the testcase ran! Never thought I'd have that problem in this language ;)
