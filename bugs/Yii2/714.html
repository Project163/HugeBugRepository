Title

NumberValidator does not perform a safe type checking on the value

Description
### What steps will reproduce the problem?
If you assign a resource as value it will pass the first checking. The check do not completely fail since it can't go past the regex, but it give a different result compare to other non scalar value (object and array)


### What is the expected result?
It should give same error message as per object and array '{attribute} is invalid.'
### What do you get instead?
The error message for incorrect number format

### Additional info
Considering that  atm is_resource() is not reliable since it return false for closed resource and cheking for null value is necessary because null is not a scalar
The code in validators/NumberValidator.php should be corrected as follow
```php
protected function validateValue($value)
{
    if (!is_scalar($value) & !is_null($value)) {
        return [Yii::t('yii', '{attribute} is invalid.'), []];
     }
```
