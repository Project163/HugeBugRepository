Title

Unknown methods in yii\web\UploadedFile

Description
Class FileValidator calls $file->getSize(), $file->getName(). 

There are no such methods in UploadedFile, so parent class Object calls static UploadFile::getName() and etc.

``` php
1. in D:\GitHub\yii2\framework\yii\base\Object.php at line 165 1
$func = $this->$getter();
if ($func instanceof \Closure) {
                return call_user_func_array($func, $params);
}
 throw new UnknownMethodException('Unknown method: ' . get_class($this) . "::$name()");

```
Discussion
- 1. UploadedFile has been refactored, so there are no methods with the name
2. __call() first checks if method exists which should not be the case, so what is the problem here?
- Problem, is that FileValidator calls non-existant UploadFile methods.
I've created a simple file upload form. And it doesn`t work.

FileValidator. For example, Line 171.

``` php
    switch ($file->getError()) {
```

There is no such method in UploadedFile, so __call() adds 'get' to the method name  

``` php
    public function __call($name, $params)
    {
        $getter = 'get' . $name;
```

and checks if method exists "getgetError". This is false, and we get UnknownMethodException.

- This implementation is an enhancement that allows calling anonymous functinos that are stored in a magic property.
Asuming $obj has methods `setProperty()` and `getProperty()` you can do the following:

``` php
$obj->property = function() {echo "example";};
$obj->property(); // this will result in a call to __call() because method does not exists. When getter is called he gets the function and executes it
```
