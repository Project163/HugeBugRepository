Title

@variable: none !important; breaks build [3.10.x]

Description

Discussion
- ### Testcase:
- Works with 3.9
- Breaks with 3.10.x
```less
@responsiveCellBoxShadow: none !important;

.test {
  box-shadow: @responsiveCellBoxShadow;
}
```
