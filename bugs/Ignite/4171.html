Title

Web Console: Account email should be unique

Description
I found that if user click several times on "Sign up" it will result in several identical accounts created, but only one is allowed. 

   

 To fix we need add unique index for "email" field and prepare migration that will remove possible duplicates.
Discussion
- Reviewed. Find bugs: 
 
	 error when lastActivity does not exists 
	 `log` function  does not imported 
	 Cluster, Cache, DomainModel, Igfs, Notebook, Notifications and Sessions  does not removed
- Please test. 

 How to test: 
 
	 Start Web Console from  previous  release. Configure DB to external folder. 
	 Go to "Sign up", enter all fields for  new  user and fast click several times on "Sign up" button. 
	 Go to "Admin panel" screen - you should see several lines with same user. 
	 Shutdown Web Console.  
	 Start Web Console  from branch ignite-10914. 
	 On backend startup a special migration should found all duplicates and delete all except one. Check backend output for line "Duplicates found: XX". 
	 Go to "Admin panel" screen - you should see that all user emails now unique. 
	 Try to do the same as #2 (fast click on "Sign up"). Now only  one  user should be created.
- Could we make the error message more user-friendly?
