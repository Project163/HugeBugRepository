Title

Mypy crashes with the pydantic mypy-plugin

Description
# Bug

Mypy crashes with the pydantic mypy-plugin   with assertion `AssertionError: Must not defer during final iteration`

Use case:
I have a bunch of "predicate" functions which get arguments from UI.  I wanted to add json schema and validation so I took the time and converted them from pure functions to Pydantic classes, with a __call__ method.

To get some common functionality I added a metaclass that extends `ModelMetaclass`, and a base class that all predicate classes extend (see code below).

The code works just fine  (thank you for the awesome library!)

but MyPy *with the pydanyic mypy-plugin* crashes when it reaches the class decleration  - see crash below.
I would open an issue for Mypy - but it doesn't crash if I don't use the plugin so I assume its the plugin at fault.
