Title

UI: Renaming a source in the list does not return keyboard or mouse focus to the list

Description
## Platform
 
 
Operating system and version: Windows 10 2004
OBS Studio version: 25.0.8

## Expected Behavior
Keyboard control should not be lost when renaming an item using F2, allowing selection of items via Arrow Keys.
 

## Current Behavior
Keyboard focus is lost after renaming an item with F2, disallowing selection with arrow keys.
The focus is lost completely, no item is now in focus.
 
 

## Steps to Reproduce
 
 
 
1. Create two sources of any kind.
2. Select either of them with the mouse in the sources list.
3. Verify that keyboard control is on the list by moving with arrow keys.
4. Rename the current item with F2, and either cancel (ESCAPE) or finish (ENTER) editing.
5. Try to continue controlling the sources list via Keyboard.
6. Notice that it stopped working.

## Additional information
Does not affect scenes, only sources.
