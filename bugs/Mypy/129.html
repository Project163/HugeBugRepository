Title

internal error with kwargs

Description
Encountered while running mypy on something using polib. Here's a reproducer:

```
import textwrap
def wrap(text, width=70, **kwargs):
    return textwrap.wrap(text, width=width, **kwargs)
```

and here's the traceback:

```
Traceback (most recent call last):
  File "/usr/bin/mypy", line 6, in  
    main(__file__)
  File "/usr/lib/python3.5/site-packages/mypy/main.py", line 50, in main
    type_check_only(sources, bin_dir, options)
... [Log Snipped] ...

tmp.py:3: error: Internal error -- please report a bug at [URL]
```

The problem seems to be in the conditional added in   but I'm not sure how actual_type should be set in this case or what should be used in its place.
Discussion
- I think this is what was intended:

```
 i < len(actual_types) and isinstance(actual_types[i], TupleType)):
```

With that, I don't get an internal error for your code snippet but I do get another error:

```
tmp.py:3: error: Too many positional arguments for "wrap"
```

but that seems due to a bug in the stub file (stdlib/3/textwrap.pyi) in the typeshed repo -- it's missing the `text` positional parameter.
- Makes sense, though actual_types would have to be initialized to an empty list at some point.
