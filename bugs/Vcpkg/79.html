Discussion
- I have to add a definition of 'PROTOBUF_USE_DLLS' in the Makefile of dnn.
```
diff
diff --git a/modules/dnn/CMakeLists.txt b/modules/dnn/CMakeLists.txt
index 7e7a471..7c4b9d4 100644
--- a/modules/dnn/CMakeLists.txt
+++ b/modules/dnn/CMakeLists.txt
... [Log Snipped] ...
   ocv_warnings_disable(CMAKE_CXX_FLAGS /wd4244 /wd4267 /wd4018 /wd4355 /wd4800 /wd4251 /wd4996 /wd4146
                                        /wd4305 /wd4127 /wd4100 /wd4512 /wd4125 /wd4389 /wd4510 /wd4610
```
I noticed that since [Link: this commit], protobuf could be built as shared library, which requires the `PROTOBUF_USE_DLLS` definition.
