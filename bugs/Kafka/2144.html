Title

"IllegalArgumentException: Invalid negative sequence number used" in Kafka Client

Description
When operating Kafka, we have seen Kafka client logging this kind of exception:

Discussion
- With some further debugging, the bug seems at client TransactionManager. incrementSequenceNumber(). 

 Instead of 

  currentSequenceNumber += increment; 

 as the sequenceNumber might overflow, it should  

 currentSequenceNumber = DefaultRecordBatch.incrementSequence(currentSequenceNumber, increment); 

 I am preparing the pull request for the fix.
