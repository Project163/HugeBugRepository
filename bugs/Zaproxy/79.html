Title

Show Tab not working correctly in Full Layout for non-information tabs

Description
Steps to reproduce the issue:
1. Run ZAP with add-on "Quick Start" installed (unpin and close its tab, if not already);
2. Switch to Full Layout (Options > Display > "Display:" or using the main tool bar option);
3. Attempt to show the "Quick Start" tab using the menu item "View" > "Show Tab" > "Quick Start Tab" (or keyboard shortcut Ctrl + Shift + Q) and note that the tab is not shown.

Remarks:
In Full Layout only the information/footer tabs are shown when using the menus/keyboard shortcuts, unless previously shown using the green plus menu.

ZAP Versions:
Versions >= 2.4.0
