Title

http access-logs when rotate as double dots in filename extension

Description
### Describe the bug

When quarkus.http.access-log.rotate is enabled, the filename during rotation is incorrect, example:

```
quarkus2022-08-18..log
quarkus2022-08-19..log
quarkus2022-08-20..log
quarkus2022-08-21..log
quarkus2022-08-22..log
quarkus2022-08-23..log
quarkus.log
```

### Expected behavior

rotated filename should be: quarkus2022-08-18.log or quarkus.2022-08-18.log

### Actual behavior

rotated filename has double dots inside name: quarkus2022-08-23**..**log

### How to Reproduce?

```properties
quarkus.http.access-log.enabled=true
quarkus.http.access-log.rotate=true
quarkus.http.access-log.log-to-file=true
```
