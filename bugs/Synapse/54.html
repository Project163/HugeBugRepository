Title

Setting messageType using property mediator to Axis2MC is not effective

Description
Setting the messageType property of the axis2 MC using the property mediator does not set that correctly. 

 Here is the configuration for setting this property; 

 <property action="set" name="messageType" value="application/atom+xml" scope="axis2"/>
Discussion
- I have fixed this issue. There was a case where one need to set properties in to the client options, and hence I have added the scope "client" to the property mediator which will set the properties on the axis2 message context client options
- I have changed the scope value from "client" to the "axis2-client" in order for it to be meaning full. (as per asankha's comment)
