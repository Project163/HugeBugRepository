Title

is_countable condition is ignored

Description
I am new to Psalm and maybe this is intended behavior. But since it makes me wonder a bit, I post this issue. 

Used PHP: `7.3.6`
Used Psalm: `3.4.1`

```
php

function getObject() : iterable{
   //assemble some iterable
}
... [Log Snipped] ...
   //do other things
}
```

results in a Psalm error like:

```
Argument 1 of count expects array |Countable|SimpleXMLElement|ResourceBundle, iterable  provided

```

Should / can I expect that Psalm takes the `if_countable` condition into account, or is there a way to instruct Psalm to do this?
