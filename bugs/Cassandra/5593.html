- There are a couple problems with this test.  The first is that if messages are dropped, which can often be expected, it results in an NPE that complicates further debugging.  The timeout for this test itself does not actually matter, since it is manipulating timing windows that it later assert results upon.  These all work in a perfect world, but inside the JVM need some relaxing to allow for the real world to get in the way. Patch  here ,  CI here , that addresses both of these.
