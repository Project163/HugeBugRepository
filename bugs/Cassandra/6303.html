Title

CircleCI: Fix BASE_BRANCH in generate.sh for cassandra-5.0

Description
We have hardcoded BASE_BRANCH in the CircleCI script generate.sh. That one is used for the diff comparison when we detect new/changed tests. 

 After adding cassandra-5.0, BASE_BRANCH needs to be updated from trunk to cassandra-5.0 in the newly created branch.
Discussion
- I did not find any easy way to automate the detection of the base branch. Even if we rely on the C* version from build.xml, we still need to update for trunk when branching. If anyone has any quick ideas - I am open to hearing it. We can add a base_branch in build.xml, but it will still be one more thing to update on branching. The only plus will be that it can reside next to the cassandra_version for example so it will be harder to forget about it. We can probably make it one thing for all CIs when CI v2 is ready, and we have same scripts distributed in the different CI systems.
