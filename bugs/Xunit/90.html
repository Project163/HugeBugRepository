Title

XunitTestCollectionRunner - IAsyncLifetime's DisposeAsync and IDisposable's Dispose run in parallel

Description
**Summary:**

When a test collection implements both IAsyncLifetime and IDisposable, corresponding Dispose methods are executed in parallel despite the documentation:
```C#
     ///  
    /// Called when an object is no longer needed. Called just before  
    /// if the class also implements that.
    ///  
    Task DisposeAsync();
```

**Source:**
[URL]

**Workaround**
Just use one or another interface
Discussion
- This is a bug in implementation, rather than documentation. It is intended that these would be run sequentially, not in parallel.
