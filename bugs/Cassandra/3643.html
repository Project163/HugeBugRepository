Title

Warn when an extra-large partition is compacted

Description
We used to log a warning when compacting an extra-large partition (CompactionController.getCompactedRow) but took that out as part of   CASSANDRA-6142  .  Let's add back a warning.  (Perhaps in SSTW.append, since MetadataCollector.update doesn't know the partition key and we will want to include that in the log.) 

 Size threshold should be configurable in cassandra.yaml and default to 100MB.
Discussion
- The previous message format included the offending partition key (yep, that's a 43GB partition in production): 

  
 INFO CompactionController Compacting large row acmeKS/veryWideTable:key5678 (45262476248 bytes) incrementally
 
  

 It would be great if we could maintain this format since it makes it easy to identify the table and partition without having to trawl through the cfstats output.
- jbellis  this is ready for review.  

 The 2.1 patch doesn't apply on 2.2 and so I created a pre-merged 2.2 patch and likewise for 2.2 to trunk.
