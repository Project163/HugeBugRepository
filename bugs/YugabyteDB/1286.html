Title

[DocDB][DB Clone] Clone is failing to the time before index drop if tablet splitting takes place - Index query failure

Description
Jira Link: [Link: DB-12082]
### Description

Version: ** -b558**

Cloning to the time before index drop(if the index is created and tablet splitting took place) is failing
**Steps**:

1. Create universe with below master GFLAGs
```
tablet_split_low_phase_size_threshold_bytes= 1048576
tablet_split_high_phase_size_threshold_bytes= 10485760
tablet_split_low_phase_shard_count_per_node=8
tablet_split_high_phase_shard_count_per_node=80
```
2. Create database and table and create snapshot schedule
3. Load some data(200K rows) to table
4. Create index on table(let index table's tablets also split(>=3 tablets))
5. Collect time(t1)
6. Drop index
7. Clone DB to collected time(t1)
