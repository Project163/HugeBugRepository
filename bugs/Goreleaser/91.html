Title

[Bug]: build fails when copying symlinks

Description
### What happened?

Within a docker build it is failing on copying a symlink within an `extra-files` directory. The desired behavior is that the symlink is copied as is, not followed. This worked up until v0.174.0 and appears to have been broken by [URL]

```
release failed after 83.32s error=failed to copy extra file ' ': failed to open ' / : no such file or directory
```


### How can we reproduce this?

Create a symlink in a directory to be included in a docker image via 'extra-files'
