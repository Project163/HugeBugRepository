Title

Folder restart can leave several folder instances running

Description
Consider this short, scary snippet from a v0.14.50 instance, after sharing/unsharing a folder a couple of times;

```
2018-10-02 14:55:57 progress emitter: registering fldr  \2018-05-26\f.csv
2018-10-02 14:55:57 sendreceive/fldr@  parent not missing  \2018-05-26\14.13.31.zip
2018-10-02 14:55:57 sendreceive/fldr@  taking shortcut on  \2018-05-26\14.13.31.zip
2018-10-02 14:55:57 sendreceive/fldr@  filesystem notification rescan
2018-10-02 14:55:57 sharedPullerState fldr  \2018-05-26\f.csv copyNeeded -> 0
2018-10-02 14:55:57 sendreceive/fldr@  parent not missing  \2018-05-25\14.38.48.csv
2018-10-02 14:55:57 sendreceive/fldr@  filesystem notification rescan
2018-10-02 14:55:57 sendreceive/fldr@  closing  \2018-05-26\14.38.47.zip
```

The three things `sendreceive/fldr@ `, `sendreceive/fldr@ ` and `sendreceive/fldr@ ` should definitely not be seen at the same time here.
