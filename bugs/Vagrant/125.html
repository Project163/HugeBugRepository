Title

Vagrantfile parse error suppressed by WSL version check

Description
Vagrantfile parse errors can cause the WSL version check to fail and hide the actual error. Version check from the WSL should be using the `--version` flag instead of the `version` command which would reduce issues like this. When version cannot be extracted output from command should be included in the error to help with local user debugging of issue.

Source: #9634
Discussion
- I'm having the same exact issue. 

Question, is there a way I can work around this error till a fix is released?

EDIT: Actually, I figured it out after I thought about it for a few more minutes. If I figure out the error that I was getting upon the version check, then the version check won't cause that error, and thus the version check won't fail. 

So, after some digging and tinkering, I got it. Thanks.
