Title

rsync-auto listener doesn't ignore .vagrant folder

Description
### Vagrant version
Vagrant 2.2.4


### Host operating system
Windows 10

### Guest operating system
CentOS 7

### Vagrantfile
```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "centos/7"
   config.vm.synced_folder ".", "/vagrant", type: "rsync"
end
```


### Debug output
[URL]

### Expected behavior
Vagrant shouldn't attempt to sync the .vagrant folder, which contains a VHD which is constantly changing.

Although `.vagrant` is automatically excluded from the rsync options, the "listener" still includes it, which means it is constantly attempting to sync the VHD file.

```
=> default: Watching: C:/temp/vagrant
 INFO rsync-auto: Listening to paths: ["C:/temp/vagrant"]
 INFO rsync-auto: Ignoring 0 paths:                                              :/vagrant"]
DEBUG subprocess: Selecting on IO
```

### Actual behavior

Constantly attempts to sync `.vagrant` folder.

Standard output continuously outputs the line:
```[/c/t/vagrant] ==> default: Rsyncing folder: /cygdrive/c/temp/vagrant/ => /vagrant
==> default: Rsyncing folder: /cygdrive/c/temp/vagrant/ => /vagrant
==> default: Rsyncing folder: /cygdrive/c/temp/vagrant/ => /vagrant
==> default: Rsyncing folder: /cygdrive/c/temp/vagrant/ => /vagrant
==> default: Rsyncing folder: /cygdrive/c/temp/vagrant/ => /vagrant
...
etc
```


### Steps to reproduce
Use Vagrant file above.
Run: `vagrant rsync-auto --debug`
