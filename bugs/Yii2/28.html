Title

bootstrap's NavBar, Nav with Dropdown not work

Description
In example in NavBar.php 'content' => new Dropdown... shows no submenu items, and without 'content' => new Dropdown, just with items massive like in Nav.php it began to give error
Calling unknown method: yii\bootstrap\Dropdown::register()
Discussion
- You miss to pass over view

if you are in the view you can register asset like this:

``` php
use app\config\AppAsset;
AppAsset::register($this);
```

if you are not in view

``` php
$view = $this->getView();
yii\bootstrap\Dropdown::register($view);
```

and pull / update to latest version;)
