Title

ActiveQuery via the getter magic function doesnt work anymore

Description
### What steps will reproduce the problem?
Create a method that begin with *get* and that return a ActiveQuery
```
php
class Dossier extends \yii\db\ActiveRecord
{
	 /**
	 * @return \yii\db\ActiveQuery
... [Log Snipped] ...
	}
}
```
Use this method via the getter magic method

```php
echo $dossier->clientbis->nom;
```

### What is the expected result?
Return a result of the ActiveQuery

### What do you get instead?
An error Invalid argument supplied for foreach()
in yii\vendor\yiisoft\yii2\db\BaseActiveRecord.php line 1732

### Additional info
Return a ActiveQuery without a proper hasOne() or hasMany() seem a bad practice for me, but i am not sure of that.
Still, it work well in Yii < 2.0.14.
Since this is a minor update, maybe a fix could ease the upgrade process, or a new Exception could explain the problem ?

| ---------------- | ---
