Title

Declaring variable named function causes errors to occur

Description
The following code:

```
(function () {
  "use strict";

  var thing = function thing() {
    return true;
... [Log Snipped] ...

}());
```

Causes these issues:
-  4:23  error  thing is already declared in the upper scope  no-shadow
