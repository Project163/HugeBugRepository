Title

Fail to perform SAM conversion using method references

Description
I have the following program 

  
 
 import  java.util.*;
 import  java.util.stream.*;
 import  java.util.function.*;

 class  Main {
   static   final  void test(DoubleStream x, ObjDoubleConsumer< Boolean > y,
                         BiConsumer< Boolean ,  Boolean > z) {
        Spliterator.OfDouble d =  null ;
        StreamSupport.doubleStream(d, x.collect(
            () ->  true , y::accept, z::accept));
  }
}
 
  

   Actual behavior 

  
 
org.codehaus.groovy.control.MultipleCompilationErrorsException: startup failed:
Main.groovy: 10: [Static type checking] - Cannot find matching method java.util.stream.StreamSupport#doubleStream(java.util.Spliterator$OfDouble, U). Please check  if  the declared type is correct and  if  the method exists.
 @ line 10, column 9.
           StreamSupport.doubleStream(d, x.collect(
           ^

1 error
 
  

   Expected behavior 

 Compile successfully 

 Tested against master (commit:  )
Discussion
- Since you already have the types that  DoubleStream#collect  takes, you can pass "y" and "z" directly. 

  
 
 import  java.util.function.*
 import  java.util.stream.*
@TypeChecked test(DoubleStream x,
    ObjDoubleConsumer< Boolean > y,
    BiConsumer< Boolean , Boolean > z) {
  Spliterator.OfDouble d =  null 
  StreamSupport.doubleStream(d, x.collect(() ->  true , y, z))
}
 
  

 It is the code where "y::accept" is mapped onto "<R> R collect(Supplier<R> supplier, ObjDoubleConsumer<R> accumulator, BiConsumer<R, R> combiner)" that fails to connect "R" with "Boolean".
- The use of functional interfaces (e.g., BiConsumer) is irrelevant. I think the issue is caused when passing a reference to method with generics.
