Problems with shaping speed limit in AbstractTrafficShapingHandler (2).

Description
ChannelTrafficShapingHandler writes too fast large volume of data (about 800 Mb with fast connection).
I think this is because the message time is calculated from when it gets to the handler, and no one takes into account all the data is already waiting to be sent.
