Title

Leader term propagation

Description
Most of operations could be done only on leader side.
We have several kinds of checks for leadership, that takes place in different places.

The following issues present:

1. We don't check for leadership during write, the check is done only when operation is added to the raft queue.
So during read-write operation it is possible that read is done while server is not leader, and then it obtains leadership and pushes wrong data to the raft.

2. Transaction related operations check for leadership, but in rare cases it is possible that node is leader when operation is started,
then it looses leadership, and receives it back when operation is added to the raft queue.
