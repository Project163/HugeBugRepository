Title

HttpClient is not releasing connections when a proxy returns status codes != 200

Description
HttpClient is not releasing connections when a proxy returns status codes != 200. 

  How to reproduce:  
 
	 Set up a proxy server that will respond with e.g.:  403 Forbidden  status code. 
It can simply be an HTTP server that responds with ` HTTP/1.1 403 Forbidden `. 
	 Set up HttpClient v5 to use the proxy: 
	 ``` 
 CloseableHttpClient client = HttpClients.custom()  
 .setProxy(HttpHost.create(PROXY_URL))  
 .build();  
``` 
	 Set DEBUG log level for  org.apache.hc.client5.http.impl.io.PoolingHttpClientConnectionManager  to see lease/release logs. 
	 Make requests to e.g.: ` [URL]
``` 
 client.execute(new HttpPost("[URL] response -> response);  
``` 
	 Connections are not released, eventually making the client reach the total limit.  
 

   
The faulty code was introduced in `   ` commit in  org.apache.hc.client5.http.impl.classic.ConnectExec  class.
