- the described exception no longer happens
- Tilman: I can't confirm that, the issue is still there, e.g. on page 54. 

 The problem is an unbalanced number of q/Q-operators in the content stream. I fixed that in revisions 1557389 (trunk) and 1557395 (1.8 branch). PDFBox now just skips the restore if there isn't anything to restore. 

 Maybe that self healing mechanism should be optional so that preflight can detect such issues, see   PDFBOX-1812   for details
