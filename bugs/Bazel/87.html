Title

Permission denied when installed to /usr/local with local .bazelrc

Description
Install Bazel by using

```
$./bazel-0.1.2-installer-linux-x86_64.sh --bazelrc=$HOME/.bazelrc
```

After the installation, if I tried running
$bazel
I'll get an error message

```
Error: mkdir('/home/$USER/.cache/bazel/_bazel_$USER'): Permission denied
```

My solution:

```
$sudo chown $USER:$USER ~/.cache/bazel/
```
Discussion
- Do you know what the permissions on ~/.cache/bazel/... were before you ran chown?
- It belongs to root:root.

BTW, I installed using "$sudo ./bazel-0.1.2-installer-linux-x86_64.sh --bazelrc=$HOME/.bazelrc" because it copied file to /usr/local.......

So, it might be better to initialize the cache when first run bazel but not during the installation.
