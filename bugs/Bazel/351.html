Title

"No such file or directory" error when building an external dependency

Description
New to Bazel, so may be operator error.  Bazel 0.3.2.

BUILD file is empty, WORKSPACE file has this:

```
git_repository(
    name = 'protobuf',
    remote = '[URL]
    tag = 'v3.1.0',
)
... [Log Snipped] ...
    actual = '@protobuf//:protobuf',
)
```

Command "bazel build //external:protobuf_compiler" fails with

```
$ bazel build //external:protobuf_compiler
..........
INFO: Found 1 target...
ERROR: /usr/local/google/home/aalexand/.cache/bazel/_bazel_aalexand/ /external/protobuf/BUILD:73:1: C++ compilation of rule '@protobuf//:protobuf_lite' failed: linux-sandbox failed: error executing command /usr/local/google/home/aalexand/.cache/bazel/_bazel_aalexand/ /execroot/bazel-test/_bin/linux-sandbox ... Target @protobuf//:protoc_lib failed to build
Use --verbose_failures to see the command lines of failed build steps.
```

Is this a bug or am I doing something wrong?
