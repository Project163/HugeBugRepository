Title

http root-path in tests is not getting prefixed with slash

Description
### Describe the bug

```
quarkus.http.root-path=root-path/
```

In my QuarkusTest, url is then set as `[URL]
```
@QuarkusTest
class GreetingResourceTest {

    @TestHTTPEndpoint(GreetingResource.class)
    @TestHTTPResource
    String url;
```

Prefixing the root path with a slash, solves this problem.

As another note, the root path without prefixing slash works when I start quarkus in dev mode.

### Expected behavior

The TestHTTPEndpoint should be built correctly
