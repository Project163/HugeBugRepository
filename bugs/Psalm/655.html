Title

Impure method call in a static factory

Description
[URL]

Hi! Testing new great functionality.  I think, static methods should not be taken into account when checking dynamic part of class for immutability, should it?
Discussion
- Static methods can still be called on the instance e.g. `$foo->someStaticMethod()`. In that example I just think you can use `/** @psalm-suppress ImpureMethodCall */`
- @muglug , static methods can be called on the instance, that's true, but within a static method you cannot mutate the state because you don't have access to `$this`.
- this is also mentioned in the initial proposal you referenced in the release.
[URL]
- Good points, I'll revert static methods to being impure, and clean up the documentation
