Title

getMatchingAccessibleMethod incorrectly returns null if no varargs are provided

Description
If I have a method 
  
 
 String  myFunc( String ... args) { ... } 
  
 and try to invoke getMatchingAccessibleMethod like this 
  
 
getMatchingAccessibleMethod(MyClass.class,  "myFunc" ) 
  
 the expected return would be myFunc but instead null is received. This happens because  [URL] incorrectly assumes at least one vararg type is passed.
