Title

Angle bracket characters in Community Name may prevent email delivery

Description
Seen in a Forem Cloud customer instance: having ` ` characters in the Community Name may prevent email delivery. For example:

```
irb(main):049:0> Settings::Community.community_name
=> " NAME"
```

The 'from' email string is generated [Link: here], which results in this:

```
irb(main):058:0> "#{Settings::Community.community_name}  "
=> " NAME  "
```

...which can lead to the ` ` string being interpreted as the sender address. SendGrid, for example, returns the following, if ` ` is not configured as a "verified Sender Identity" (not to mention, it's not an email at all!):
