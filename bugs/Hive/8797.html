Title

Iceberg: PartitionsTable#partitions returns incomplete list in case of partition evolution and null partition values

Description
Projections with Null and missing field values are considered equal. That leads to incorrect PartitionMap construction: 

 Below 3 StructProjections are considered equal leading to key overwrite in PartitionMap; 
  
 
 "ice_orc(company_id= null )" 
 "ice_orc(company_id= null /dept_id= null )" 
 "ice_orc(company_id= null /dept_id= null /team_id= null )"
