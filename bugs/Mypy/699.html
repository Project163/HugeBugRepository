Title

TypeVar with Any upper bound generates missing attribute errors is used as Type[T]

Description
Imagine the following code:

```
class Foo():
    NAME: ClassVar[str] = ""

T = TypeVar("T", bound=Foo)

def create_foo(object_class: Type[T]) -> T:
    print(T.NAME)  # Generates error in static analysis
    return T()
```

When this code is run through the static analysis, the marked line is flagged as an error because mypy thinks that `T` does not have the `NAME` attribute. When the same code is run through the dynamic analysis, the code works fine.
Discussion
- Surely you meant to write
```py
    print(object_class.NAME)
    return object_class()
```
This seems to work fine.
- Ah, yes.


It works only in dynamic analysis, but not in static analysis. The static analysis generates this error:

```
"Type[T]" has no attribute "NAME"
```

Either adding `# type: ignore` or an explicit `cast(Type[Foo], object_class)` resolves the issue.
