Title

Incorrect parsing of a JSON doc containing a zero-length fieldName

Description
The error generated by [Link: DocumentParser.java#L182] (`object field starting or ending with a [.] makes object resolution ambiguous: [" + fullFieldPath + "]"`) incorrectly rejects the field path "", which is not ambiguous.

This kind of document (edge-case, I know) was accepted in ES v1.x. Ideally (for me) the document would be accepted, but in any case the error description is incorrect - if "" is a special case that is considered illegal by ES (but not JSON), it should be documented as such and reported accordingly.
