Title

[DocDB] Fix AutomaticTabletSplitITest.AutomaticTabletSplittingMultiPhase flakiness

Description
Jira Link: [Link: DB-5133]
### Description

`AutomaticTabletSplitITest.AutomaticTabletSplittingMultiPhase` is failing sometimes with the following error:
```
Value of: first_iter
  Actual: true
Expected: false
Did not expect a split in the first iteration.
```
A tablet may (erroneously) have enough data to split in the first iteration of a phase's loop because we:
1. Were not able to split it in the previous phase (e.g. another split caused us to exceed the phase threshold, so the split failed) AND
2. Write data before checking that we shouldn't split.

Getting rid of (2) is probably sufficient to fix this issue.
