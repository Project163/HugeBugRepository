Title

build failure with gcc-14 (C99)

Description
### What version of gRPC and what language are you using?

grpc-1.66.0

### What operating system (Linux, Windows,...) and version?

Gentoo Linux. 
```
uname -a
Linux b612-dev3-desktop 6.1.69 #1 SMP PREEMPT_DYNAMIC Tue Jan  9 20:28:38 UTC 2024 x86_64 Intel(R) Xeon(R) CPU E5-2680 v3 @ 2.50GHz GenuineIntel GNU/Linux
```

### What runtime / compiler are you using (e.g. python version or version of gcc)

sys-devel/gcc-14.2.1_p20240817


### What did you do?

dev-ruby/grpc-1.66.0 fails to build with gcc-14 with the following error:

```
rb_compression_options.c: In function 'grpc_rb_compression_options_algorithm_value_to_name_internal':
rb_compression_options.c:301:56: error: passing argument 2 of 'grpc_compression_algorithm_name' from incompatible pointer type [-Wincompatible-pointer-types]
  301 |   if (!grpc_compression_algorithm_name(internal_value, &algorithm_name)) {
      |                                                        ^~~~~~~~~~~~~~~
      |                                                        |
... [Log Snipped] ...
      |                                           ~~~~~~~~~~~~~^~~~
make: *** [Makefile:251: rb_compression_options.o] Error 1
```

### What did you expect to see?

Successfull build.

### What did you see instead?

gcc 14 is forcing C99 standard as default standard for C language: [URL] So -Wincompatible-pointer-types is now enabled and build of ruby bindings for grpc fails.
