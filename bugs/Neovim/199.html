```
.. vim:spell
.. vim:spelllang=en_us
```

If I disable vim-spell or change the language to something else (ex. `spelllang=de_ch`), both Vim and Neovim behave normally. However, the faulty behaviour reappears if I use any other English language dictionary (ex. `spelllang=en_gb`). I suspect that it's something to do with my `en.utf-8.add` file. The issue goes away if I remove that entry from the dictionary and rebuild the `spl`file. It also works with other full sentences.
