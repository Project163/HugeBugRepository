Title

SolrCore's perSegmentFingerprintCache Is Not Thread-safe

Description
SOLR-16713   introduced a race condition into the perSegmentFingerprintCache as it changed it from the  thread-safe guava implementation to the thread-UNSAFE WeakHashMap . This flew under the radar for some time because this map previously had very little contention between threads. However after   SOLR-17756   we turbo-charged the race after parallelizing at a much more granular level upstream of this call. The net effect is that WeakHashMap:put can get stuck in an infinite-loop (probably due to a cycle in the underlying linked-list that it modifies):
