Title

v1.23.6 introduces untrusted sharing regression

Description
I upgraded my Syncthing "server"/central peer to 1.23.6 (Linux/docker) and it broke resharing an untrusted folder.

Peer A shares a folder with Server. Peer A considers Server as untrusted. The folder is shared encrypted.
Peer B also shares that same folder with Server. It also considers Server as untrusted.

After updating, syncthing on Server says "Folder \  (\ ) is shared in trusted mode with untrusted device \ ; unsharing".

Downgrading to 1.23.5 fixes it. I also re-upgraded and it broke again, so it seems likely to be a regression.

So my understanding is with 1.23.6, Server no longer considers a folder received as encrypted safe to share with an untrusted peer. I think that's a valid use case as my situation is not too weird :)
