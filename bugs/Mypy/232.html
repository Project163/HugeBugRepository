Title

Unicode module docstring in Python 2

Description
In Python 2, docstrings are str by default, but unicode docstrings generally work. However, mypy disallows them:

```
$ cat unicodedoc.py 
from __future__ import unicode_literals
__doc__ = "documentation"
$ python3 -m mypy --python-version 2.7 unicodedoc.py 
unicodedoc.py:2: error: Incompatible types in assignment (expression has type "unicode", variable has type "str")
```

This makes it harder to prepare a codebase for 2/3 compatibility with the future import for unicode_literals.

It looks like this behavior is hardcoded at [URL] I can prepare a patch if people agree that a change is needed.
