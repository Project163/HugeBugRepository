Title

skipOuterContainers option is incorrectly passed to pjax in handleAction in yii.js

Description
I found this issue during writing tests for `yii.js`.

Here is the current contents of the final formed `pjaxOptions` array to be passed in pjax plugin:

```
js
pjaxOptions = {
    container: pjaxContainer,
    push: pjaxPushState,
    replace: pjaxReplaceState,
... [Log Snipped] ...
    originalTarget: $e
}
```

As you can see, `skipOuterContainers` option is passed as `pjaxSkipOuterContainers`. `pjax` prefix is not needed in the pjax plugin itself.
