Title

NullPointerException in instruction selection phase when having parameterized method

Description
The following (complicated) test case makes the compiler produce an NullPointerException: 

  
 
 class  Foo<T> {
  Foo(T x) {}

  <T  extends   Short > T m(T x) {
    x
  }
}

 class  Test {
   static   final  void test() {
    Foo< Integer > tmp =  new  Foo< Integer >(-76);
     boolean  cond = 5.0 > tmp.m( new  Foo< Integer >(95).m( null ));
  }
}

Discussion
- There are a few compare methods for BigDecimal on LHS. The distance check for short to character is where the NPE is. getPrimitiveDistance could use NUMBER_TYPES.getOrDefault(primType, 9) or some kind of guard for boolean, char and void.
