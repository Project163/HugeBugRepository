Title

wildmode=longest:full,full behaves different then in vim

Description
The behavior of vim vs nvim is different in the following case:

```
nvim -u NORC
:set wildmenu
:set wildmode=longest:full,full
:cd ~/ 
```
vs
```
vim -u NORC
:set nocompatible
:set wildmenu
:set wildmode=longest:full,full
:cd ~/ 
```

Like in vim, nvim probably should not highlight the first occurrence until completion is selected.

```
$ nvim --version
NVIM v0.2.1-885-g460aab395
Build type: Release
$ echo $TERM
xterm-256color
```
