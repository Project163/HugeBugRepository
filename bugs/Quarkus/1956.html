Title

Wrong hibernate dialect version detected for MS Sql Server

Description
### Describe the bug

It's possible to see this [Link: updating one of the quickstart to use MS SQL Server].

Quarkus will start an instance of MS SQL server 2019-latest (shouldn't we update it to 2022?) and use as dialect:
```
HHH035001: Using dialect: org.hibernate.dialect.SQLServerDialect, version: 10.0
```

The workaround is to set a custom dialect using the property `quarkus.hibernate-orm.dialect=org.acme.hibernate.reactive.SqlServerDialect`:

```
java
package org.acme.hibernate.reactive;

import org.hibernate.dialect.DatabaseVersion;
import org.hibernate.dialect.SQLServerDialect;
... [Log Snipped] ...
	}
}
```


I've tested this with Hibernate Reactive and Quarkus 3.1.1
