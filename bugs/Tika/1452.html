Title

Support Android Bundle aab detection

Description
AAB file goes through DefaultZipContainerDetector and gets detected as 

  application/java-archive  since it has MANIFEST.MF via JarDetector.  

 They have their own content type as mentioned in tika-mimetypes.xml  - application/x-authorware-bin 

  [URL]

 The AAB file structure has a AndroidManifest.xml similar to apk archive but in  base/manifest/  directory.
