Title

Detection of stale files not working on Windows

Description
Description 
 The detection of stale files introduced by   MJAVADOC-626   does not work on Windows. 

 The root cause is that file-arguments on the commandline, i.e.  @options  and  @packages , are not recognized as such, because of double-quoting, and are therefore not resolved to individual arguments. 

   Solution Proposal 
 The generated stale data detection key should contain only the arguments passed to the javadoc binary but not the whole commandline. 

 This can be achieved by replacing the usage of  Commandline#getCommandline()  by  Commandline#getArguments()  in  org.apache.maven.plugins.javadoc.StaleHelper#getStaleData(Commandline)
