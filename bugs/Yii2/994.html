Title

FileCache saves all caches in the same subdirectory if keyPrefix is set

Description
If `yii\caching\FileCache::$keyPrefix` is set, then caches will always be stored in a subdirectory based on that value, making `$directoryLevel` basically pointless.

### What steps will reproduce the problem?

1. Configure a `cache` component set to `yii\caching\FileCache`, with `keyPrefix` set to something:

    ```php
    'cache' => [
        'class' => \yii\caching\FileCache::class,
        'keyPrefix' => 'foobar',
        'cachePath' => '@runtime/cache',
    ],
    ```

2. Save a few things to the cache.

### What is the expected result?

The cached items should be stored in `@runtime/cache/ `, where ` ` is the first two characters of the cache key passed to `set()`.

### What do you get instead?

All cached items are all stored in `@runtime/cache/fo`, where `fo` is the first two characters of the `keyPrefix`.

This could be solved by trimming off the `keyPrefix` when determining the path, as we are doing [Link: here].
