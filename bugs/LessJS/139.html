Title

Redudant space in interpolated selectors like `nth(...)`

Description
Example:

```
@i: 3;

ul li:nth-child(@{i}) {
    color: red;
}
... [Log Snipped] ...
    }
}
```

Expected output:

```
ul li:nth-child(3) {
  color: red;
}
ul li:nth-child(3) {
  background: red;
}
```

Actual output:

```
ul li:nth-child(3) {
  color: red;
}
ul li:nth-child( 3) {
  background: red;
}
```

Tested v1.7.0 (but this seems to be introduced in v1.5.0).
