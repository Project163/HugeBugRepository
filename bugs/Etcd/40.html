Title

ETCD Gateway does not work with DNS discovery

Description
ETCD Gateway seems not to strip the http:// or https:// schema from the discovered hostnames.

This one does not work:

```shell
etcd gateway start --discovery-srv="k8s-cluster.intern" --insecure-discovery=true
2017-03-08 14:13:53.928749 I | etcdmain: discovered the cluster [http://etcd-node-3.:2379 [URL] [URL] from k8s-cluster.intern
2017-03-08 14:13:53.929070 I | proxy/tcpproxy: ready to proxy client requests to [ :2379]
```

With TLS

```
shell
etcd gateway start --discovery-srv="k8s-cluster.intern" --listen-addr=" :2379"
2017-03-08 14:29:52.158063 I | etcdmain: discovered the cluster [https://etcd-node-3.k8s-cluster.intern.:2379 [URL] [URL] from k8s-cluster.intern
2017-03-08 14:29:52.158241 I | etcdmain: validating discovered endpoints [https://etcd-node-3.k8s-cluster.intern.:2379 [URL] [URL]
2017-03-08 14:29:52.165461 I | etcdmain: using discovered endpoints [https://etcd-node-3.k8s-cluster.intern.:2379 [URL] [URL]
... [Log Snipped] ...
2017-03-08 14:30:52.166236 W | proxy/tcpproxy: failed to activate endpoint [https://etcd-node-3.k8s-cluster.intern.:2379] due to dial tcp: too many colons in address [URL] (stay inactive for another 1m0s)
2017-03-08 14:30:52.166277 W | proxy/tcpproxy: failed to activate endpoint [https://etcd-node-2.k8s-cluster.intern.:2379] due to dial tcp: too many colons in address [URL] (stay inactive for another 1m0s)
```

Specifying the endpoints manually without the scheme works:

```shell
etcd gateway start --endpoints="etcd-node-1:2379,etcd-node-2:2379,etcd-node-3:2379"  --listen-addr=" :2379"
2017-03-08 14:18:05.391698 I | proxy/tcpproxy: ready to proxy client requests to [etcd-node-1:2379 etcd-node-2:2379 etcd-node-3:2379]
```
