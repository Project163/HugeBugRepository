Title

Query caching when query don't return any row (return false)

Description
For example

```
return $db->cache(
        function ($db) use ($itemName, $userId) {
            /* @var Connection $db */
            return (new Query)
                ->select(['item_name'])
... [Log Snipped] ...
        5
    );
```

I want to cache this query, when it returns false
How can i do it?
Discussion
- ask here on forum ? [URL]
- Out of the box you can't because most of backends i.e. memcache, wincache etc. don't support storing null/false so there's no difference between "key contains false" and "nothing with such key". Since in many cases there's no need to cache "no result" we haven't added any wrappers to our cache layer in order for it to be simpler and more performant.

You still can implement it by choosing a special value such as `NOTHING_RETURNED` and storing/checking it manually in case query returned nothing.
- I think the problem is in Command class which does not cover this case:

[URL]

We should wrap the result in an array there.
