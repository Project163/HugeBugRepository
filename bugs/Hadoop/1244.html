Title

The constructor of Path should not take an empty URL as a parameter

Description
The constructor of Path should not take an empty URL as a parameter, As discussed in   HADOOP-10820  , This JIRA is to change Path constructor at public Path(URI aUri) to check the empty URI and throw IllegalArgumentException for empty URI.
Discussion
- I will submit a patch for this issue.
- This JIRA is similar as   HADOOP-1386  :The constructor of Path should not take an empty string as a parameter. 
Since the string-based constructor checks for an empty string, for consistency it would make sense that the URI-based constructor do the same thing.
